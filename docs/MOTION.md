# 导航与动效

## 首页滚动

[ChapterMotion](../src/components/ChapterMotion.jsx) 观察首页分区。内容从视口下沿进入时向上归位，从上沿进入时反向归位；到达阅读位置后保持稳定。元素完全离开视口时重置，因此来回滚动可以再次看到入场过程。

| 区域 | 滚动时的表现 | 调整时关注 |
| --- | --- | --- |
| 项目介绍 | 标题、简介和筛选器一起入场。宽屏时停在距顶部 138px 的位置 | sticky 的作用范围是项目区；窄屏使用上下排布 |
| 项目卡片 | 卡片在视口两端反向倾转，中央 38% 至 62% 保持正面 | 宽屏最大倾角 36°、间距 16px；窄屏为 26°、12px |
| 文章与论文入口 | 进入可读区域后保持可见，指针离开后收起局部光晕 | 宽屏从项目列表末尾到文章标题约 320px，距离由链接高度与相邻分区间距共同决定 |
| 页尾联系面板 | 根据指针在面板中的相对位置倾斜，离开后回正 | `.contact-inner` 提供稳定的命中区域，`.contact-panel` 承担视觉变换 |

卡片跟随 CSS 滚动时间线。修改曲线后，用慢速滚轮观察卡片分别从顶部和底部进入，再在列表中段切换分类。项目区的裁切边界应能容纳卡片倾转时的外侧边缘。

## 导航与返回

站内翻页提交新页面后，`site-page-rendered` 通知页面交互重新接入。[首页入口逻辑](../src/lib/home-entry.js)负责区分首次进入、刷新与历史恢复。验证时分别从收藏地址、站内项目链接和浏览器后退进入首页，这三种操作对应不同的滚动预期。

详情页左侧「返回」通往上一级，右侧链接通往个人主页。向上滚动时浮出返回栏及当前页的「回到顶部」，向下滚动时收起。首页浮动入口与页脚的回顶入口按位置交接。论文正文采用连续阅读排版。

## 角色光标

桌面端的两套衣装共用 64 × 68 CSS 像素画布与坐标 `(8, 12)` 的指尖热点。首次进入时选择一套，站内跳转与浏览器历史沿用本次衣装，原生刷新时切换。构建把两款光标写入页面 head，让首屏使用与交互层同源的 192 × 204 素材。图片来源与替换规格见[站点素材](ASSETS.md)。

| 操作 | 视觉反馈 |
| --- | --- |
| 普通移动、悬停 | 人物跟随指尖，交互目标提供自己的悬停反馈。头像下方的 GitHub 链接以图标和文字回应，背景保持透明。 |
| 上滚、下滚 | 箭头提示方向，人物绕指尖偏转约 5°，停滚约 260ms 回正。 |
| 拖动 | 姿态轻微倾斜，释放后回正，热点保持在指尖。 |
| 点击头像或喜欢 | 入口播放对应语音；角色通过眼帘和面颊的小幅变化回应。 |
| 减少动态效果 | 保留相同衣装的原生高清指针，页面采用静态阅读布局。 |

静止刷新涉及两层显示：页面提供原生指针样式，Edge 绘制系统指针。调试时先将鼠标停在正文上按 F5，观察首次移动前的指针，再对照当前衣装与图层状态。

## 验证入口

在生产预览上运行 `npm run check:chapters` 检查分区重复入场，`npm run check:navigation` 检查翻页与卡片角度，`npm run check:projects` 检查筛选和项目操作。光标的刷新与历史恢复由 `npm run check:cursor` 覆盖，姿态与减少动态效果由 `npm run check:motion` 覆盖。[预览环境与测试命令](DEVELOPMENT.md)
