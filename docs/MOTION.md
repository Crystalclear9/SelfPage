# 滚动与指针动效

## 页面编排

- 首屏：在宽屏上短暂停留，图文随滚动以不同速度移动，插画轻微旋转、缩小。
- 项目：宽屏侧栏停留在阅读位置，项目依次进入；窄屏使用自然的纵向布局。
- 细节：顶部阅读进度线、项目进入、按钮反馈、弹窗及背景过渡。

由原生 CSS scroll/view timeline 驱动，不拦截滚轮、不改变滚动速度，也不在 React 状态中逐帧存储滚动位置。正文默认可读，不依赖动画结束。实现参考 [MDN scroll-driven animations](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Scroll-driven_animations)。

## 角色光标

`megumi-cursor.svg` 与上一版完全一致，不重新生成角色。动作通过 CSS 围绕指尖热点 `(8, 12)` 旋转和缩放实现，点击位置不随动画偏移。

| 操作或语义 | 反馈 |
| --- | --- |
| 移动、悬停链接 | 轻微倾斜、抬起 |
| 按下、单击、双击 | 按压、回弹、指尖波纹 |
| 拖动、抓取、移动 | 抓取姿态和方向提示；保留浏览器拖拽数据 |
| 滚轮、中键 | 短暂方向反馈 |
| 右键 | 菜单提示，保留原生右键菜单 |
| 文本、选取、竖排文本 | 缩小角色并显示文本标记 |
| 加载、等待、进行中 | 指尖旋转环，角色轻摆 |
| 禁用、不可放置 | 禁止标记 |
| 复制、快捷方式、帮助 | 对应语义标记 |
| 放大、缩小 | 缩放反馈 |
| 水平、垂直、对角线调整尺寸 | 方向标记 |

页面实际拥有的按钮、文本、图片及拖拽自动识别。等待状态来自文档加载或 `aria-busy="true"`，没有人为延迟。尚未使用的缩放、调整尺寸等控件可通过标准 cursor 名称的 `data-cursor` 声明，例如 `data-cursor="ew-resize"`，也支持控件的内联 `style.cursor`。本站没有请求时不会凭空显示加载动画。

动态光标是忽略点击的 manual popover，使用原来的整个人物替代原生光标，不额外挂箭头或头像。位于弹窗之上，事件处理器均不阻止默认操作。参考 [MDN Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using)。浏览器工具栏、系统右键菜单以及浏览器接管的外部拖放仍由系统绘制指针。

## 降级与验证

- 系统选择“减少动态效果”时，停用滚动动画与动态角色，保留同一角色的静态原生光标。
- 触屏不显示鼠标角色；无 JavaScript、图片加载失败或不支持 Popover API 时保留原生光标回退。
- 不支持 scroll timeline 的浏览器保留正常排版和基础交互，正文不会隐藏。
- `npm run check:motion` 验证角色状态、滚动数值变化、侧栏停留、弹窗层级及上述降级；与 UI、静态页面检查一并运行。

## 更丰富的鼠标反馈

- 快速移动：角色倾斜幅度跟随移动速度，附加短暂气流线；停止后回正。
- 悬停链接：指尖出现小型轨道；按钮图标向鼠标靠近，按钮本身的点击区域不移动。
- 单击、双击：指尖粒子扩散，双击的扩散范围更大。
- 长按：停留按住约 0.42 秒开始蓄力，约 1.05 秒完成；松开产生更大的粒子扩散和角色回弹。只提供视觉反馈，不额外执行操作；移动、拖拽、失焦会清理蓄力状态。
- 拖动：抓取轨道与倾斜姿态，结束后自然回落。
- 滚轮：角色随上、下方向分别倾斜，轨道短暂旋转。
- 卡片、插画、联系区与头像：轻量三维倾转；内容区带局部光斑，单击产生局部波纹。

装饰图层不接收鼠标事件。表面动画通过逐帧合并的 DOM 更新实现，不逐帧触发 React 重渲染。粒子固定最多 8 个复用节点，快速连击会取消前一次效果，避免持续累积。触屏和减少动态效果模式不启用这些增强。

## 细节动作

- 快速折返：空白处短时间内连续两次横向折返，角色轻摆一次。触发间隔至少 1.8 秒，进入链接或正文后立即让位于对应状态。
- 按住牵引：按住并移动时，指尖出现朝向起点的短虚线，最长 48px；松手、取消或离开页面时清理。选取文本不显示牵引线。
- 点赞回应：真正从未点赞变为点赞时，角色轻摆并浮出三颗小爱心；取消点赞不播放。使用原有 Phosphor 图标，角色素材不变。

## 内容页面扩展

文章与论文入口随滚动分段进入；项目实现条目使用独立的 view timeline，侧栏目录在宽屏停留。详情页标题滚动上移，下一项目入口随进入视口展开。新增效果只改变位移与缩放，正文不通过透明度隐藏。减少动态效果模式关闭这些动画。

内容链接使用 `data-cursor="read"`，角色轻微前倾并显示阅读标记；PDF 链接使用 `data-cursor="download"`，角色产生轻微下移反馈。角色素材与点击热点不变。新入口增加跟随光斑、图标偏转和点击波纹，与现有交互共享配色与事件调度。

## 项目卡片入场

卡片间距为 16px，窄屏为 12px。入场位移限制在 18px 内，避免动画制造额外留白。

每张卡片的外层提供独立 view timeline，覆盖从进入视口底部到离开顶部的全过程：两端轻微缩小、倾转，中央阅读区保持稳定。反向滚动时按原路径回正，因此从上方或下方重新进入都有反馈。滚动与鼠标倾转分别使用独立变换属性。减少动态效果或不支持 scroll timeline 时使用普通卡片列表。

## 返回导航与页面切换

返回按钮由 `src/components/PageNavigation.jsx` 统一生成，顶部与页脚共用 `HomeLink`。主页地址使用部署前缀，直接打开子页面时也可以返回，不依赖浏览历史。文章与论文正文同时提供所属列表入口。

`src/styles/navigation.css` 使用 [跨文档 View Transitions](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40view-transition)。浏览器执行真实页面导航，正文快照在约 0.5 秒内平移、缩放，导航栏使用独立快照。返回主页时反转平移方向。该效果属于渐进增强，不支持时保持普通导航；减少动态效果模式不启用过渡。

## 头像反馈

`ProfileAvatar` 是原生按钮，可通过点击、触屏或 Enter/空格触发。图片只摆动一次，随后复位，外圈提供反馈；文字问候由已有状态提示显示。重复点击在当前动作结束前不会叠加，计时器在组件卸载时清理。

## 文件位置

样式统一放在 `src/styles/`，由 `src/main.jsx` 按基础、滚动、指针、内容、导航、头像的顺序加载。卡片双向翻转最大角度为 24°，窄屏为 17°；增加角度而不扩大卡片间距，中央 38%–62% 的滚动区间保持正面阅读。
