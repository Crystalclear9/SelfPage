# 导航与动效实现

## 页面结构与滚动

| 区域 | 行为 | 主要文件 |
| --- | --- | --- |
| 首屏 | 宽屏停留、插画展开；保留原生滚动 | `src/styles/chapters.css` |
| 个人介绍 | 上下方向重复浮现，进入后保持正常阅读位置 | `src/components/ChapterMotion.jsx`、`src/styles/chapters.css` |
| 项目列表 | 卡片重复浮现与滚动翻转；标题组进入后在宽屏固定 | `src/components/ChapterMotion.jsx`、`src/styles/motion.css` |
| 文章与论文 | 标题与两个入口分别浮现；正文保留阅读动效 | `src/styles/chapters.css`、`src/styles/content.css` |
| 页面切换 | 进入展开、返回反向收回、相邻项目横向切换 | `src/lib/navigation.js`、`src/styles/navigation.css` |

滚动编排使用 CSS scroll/view timeline，不拦截滚轮或修改滚动速度。卡片间距为 16px，窄屏为 12px；最大翻转角度分别为 36°、26°，中央 38%–62% 区间保持正面。正文不会等待动画结束才显示。

宽屏下项目介绍固定在距视口顶部 138px 的偏上位置；sticky 仅在项目区内生效。卡片倾转的裁切边界设在 `main` 的视口边缘，避免项目区自身截断卡片。窄屏恢复上下排版。

宽屏从项目列表底部到文章标题的整体距离约为 320px，由仓库链接的上间距与高度、项目区底部 padding、文章区顶部 padding 共同构成，不是单个 320px margin。窄屏按既有断点缩小间距。`check:assets` 对两个宽度测量这段距离；调整时不要只改其中一处而忽略叠加值。

`useProjectFilter` 管理分类及切换动画。切换时先淡出列表，在缩短文档前将已滚过的列表开头移回导航下方，再同步更新条目并淡入。快速重复选择会取消过期动画；减少动态效果模式直接更新。卡片的阅读、源码和简介入口统一放在操作行中。

首屏展开节奏参考 [wutaghost](https://wutaghost.github.io/)，本站的文案、插画和页面结构独立维护。

## 模块进入效果

模块进入方式参考 [Awesome RSI Research](https://lee1003-lee.github.io/Awesome-RSI-Research/)，采用进入视口后轻微上移与淡入，而非持续滚动位移。

`ChapterMotion` 仅在首页挂载。它使用 IntersectionObserver 判断进入和离开，不接管滚轮，也不会在播放后永久取消观察。

| 目标 | 标记 | 进入效果 | 显示期间 |
| --- | --- | --- | --- |
| 个人介绍、文章标题、联系区域 | `data-chapter` | 淡入，按进入方向从 ±24px 回到原位，约 0.62 秒 | 保持正常位置 |
| 项目卡片、文章与论文入口 | `data-module` | 淡入，从 ±36px 回到原位，约 0.62 秒 | 项目卡片仍有独立的滚动翻转 |
| 项目标题、说明与筛选栏的整体 | `data-sticky-reveal` | 淡入、±36px 位移、±12° 翻起及缩放恢复，约 0.7 秒 | 宽屏在项目区内固定，位置不随动画持续变化 |

状态流程为“观察区外准备 → 进入播放 → 到位显示 → 完全离开后重新准备”。上滚回看、下滚进入和再次往返均能触发。项目标题组保持的是区内固定位置，不是整次访问只播放一次。

观察器阈值为 0 和 0.12，观察区上方扣除 70px、下方扣除视口高度的 8%。部分进入或离开期间不反复重置，降低边缘抖动。分类切换后，MutationObserver 只观察项目列表的直接子节点变更，移除旧卡片并登记新卡片。

`data-chapter-visible` 和 `data-chapter-entry` 由组件管理，前者控制准备/显示，后者标记从上方或下方进入。不要把它们永久写入 JSX，也不要对 sticky 外容器施加进入变换；项目标题动画作用于内层 `.projects-intro-content`。

初始化时已经位于阅读视口中的内容直接显示，避免刷新和历史恢复时重新隐藏正在阅读的模块。下方模块只有在 JavaScript 已完成增强初始化后才启用进入状态；静态 HTML、脚本不可用或减少动态效果模式下保持可读。键盘焦点进入尚未显示的模块时立即显现。

带可见键盘焦点的模块不会因退出观察区而隐藏。鼠标点击筛选后的普通焦点不阻止重新准备，否则会造成“点击后再返回就没有动画”。切换减少动态效果设置、组件卸载时清理观察器和临时状态。

`check:chapters` 检查多轮上下往返、真实 CSS 过渡、筛选点击后的重复触发、标题组区内固定、卡片重新登记、窄屏溢出与减少动态效果，也检查 SandBoxSim 详情及翻页入口。

## 返回与项目翻页

首页入口行为由 `home-entry.js` 独立处理，不依赖 React 完成加载：

| 进入方式 | 定位行为 |
| --- | --- |
| 新打开首页或旧的首页分区收藏 | 从首屏开始，清理地址中的分区锚点 |
| 已打开首页，再进入带锚点的收藏 | 通过 Navigation API 识别同文档导航，回到首屏 |
| 刷新首页 | 浏览器恢复原位置，恢复期间关闭平滑滚动 |
| 点击站内分区链接 | 定位到对应分区，再清理首页锚点 |
| 浏览器前进、后退 | 保留浏览器历史位置恢复 |

以上“首屏入口”规则只应用于首页，不会把直接访问的项目、文章或论文详情重定向到首页。同文档收藏处理依赖 Navigation API；不支持时保留浏览器原生行为。

顶部导航将文章和论文合并为“文章与论文”，定位到首页 `#writing` 板块。首页按滚动位置更新导航选中态；文章、论文及其正文页保持该项选中。浅色主题使用深色文字，深色主题使用对应的高对比文字。

刷新首页时，head 脚本临时将根元素的 `scroll-behavior` 设为 `auto`，使浏览器直接恢复原阅读位置。`pageshow` 后经过两帧恢复原样式，后续点击分区仍平滑滚动。`check:entry` 逐帧检查刷新位置，避免仅验证最终位置而漏掉恢复过程中的滚动动画。

`src/lib/home-entry.js` 内联于 HTML head。直接访问首页时从顶部开始，旧收藏的分区锚点会被清理；刷新和历史遍历保留浏览器滚动恢复。带同站 referrer 的跨页分区链接先完成定位再清理地址。首页内的锚点点击使用原生滚动，随后通过 `replaceState` 清理地址。Navigation API 还处理页面已打开时从浏览器收藏触发的同文档锚点导航，区分页面内链接点击和历史遍历；这条路径不会重新执行 head 脚本。外部直接链接到首页分区也按首屏入口处理；无 JavaScript 时保留原生锚点行为。

项目介绍弹窗的内容以 6px 位移分层淡入，说明条目悬停时轻微提亮并横移 2px，关闭后恢复焦点但不滚动页面。减少动态效果模式关闭这些位移动画。

`PageNavigation` 统一提供返回主页及所属列表的链接。页首入口离开视口后，向上滚动显示悬浮返回条，向下滚动隐藏。隐藏时使用 `inert` 移出焦点顺序；条内存在键盘焦点时保持可见。

`ScrollToTop` 用于首页及所有子页面：离开页首 80px 后（短页面取可滚动距离的 15%）向上滚动显示，向下滚动隐藏。首页目标为 `#home`，子页面目标为 `#main`，按钮文字统一为“回到顶部”，不离开当前网址。向上滚动时优先显示悬浮顶部按钮，并隐藏页脚顶部按钮；向下滚动时恢复页脚按钮，避免两个顶部入口同时出现；上方的跨页返回导航仍独立保留。

上述组件读取真实滚动位置，4px 阈值过滤轻微抖动，通过 requestAnimationFrame 合并更新。触屏、滚轮和键盘滚动使用相同逻辑，悬浮控件不改变正文布局。

`ProjectPager` 按项目数组顺序提供前后导航，不循环跳回第一项。第一项可返回全部项目，最后一项可继续浏览文章。站内切换由导航处理器提交新页面，主内容使用 `page-arriving` 入场类。发生跨文档导航时，支持 View Transition 的浏览器可通过同名标题快照衔接两页。

## 翻页异常恢复

`src/lib/transition-guard.js` 由 Vite 内联到 HTML head，在应用脚本加载前注册监听。过渡准备失败或超过 1.8 秒时调用 `skipTransition()`，结束视觉快照并显示已加载正文，不刷新页面；历史缓存恢复时清理旧的出站过渡。

`check:recovery` 覆盖人为挂起动画、阻断应用脚本、正常过渡保留及历史返回。这是过渡异常的恢复机制，不替代对网络错误或其他渲染故障的诊断。

支持 Navigation API 时，站内链接复用当前文档，入场动画作用于新页面的正文。指尖和状态提示位于正文外，翻页时继续响应鼠标。

## 头像与角色光标

`ProfileAvatar` 为原生按钮，支持鼠标、触屏、Enter 和空格。触发后头像摆动一次、显示问候，动作期间不叠加重复动画。

每个标签页首次进入时等概率选择过膝白袜或短袜，刷新时重新抽取。站内跨页和历史恢复均沿用本次选择。两套素材分别为 `public/images/megumi-cursor.svg` 和 `public/images/megumi-cursor-short.svg`，热点 `(8, 12)` 对应指尖。`AnimatedCursor` 使用不接收点击的 manual popover，保持在弹窗之上；移动、点击、长按、拖动、文本、等待、复制和方向调整各有反馈。`data-cursor` 可声明额外语义，如 `read`、`download`、`ew-resize`。

`PointerSurfaces` 负责表面倾转、局部光斑和点击波纹。动画帧合并 DOM 更新，固定复用粒子节点；事件处理不改变原生点击、选字、拖拽和右键菜单行为。

文章和论文入口的光晕使用独立伪元素，只有 `data-pointer-inside` 存在时显示；移出时清除指针坐标，滚动、失焦和离开页面时重新命中检测或清理状态。光标在复制与筛选完成后显示简短确认。项目弹窗通过 Clipboard API 复制项目详情地址，成功后同时显示角色反馈和可访问的状态提示，失败时给出手动复制方式。

## 降级与验证

- 减少动态效果模式关闭翻页、滚动、头像摆动和动态光标，保留静态内容、导航和文字反馈。
- 触屏不显示鼠标角色。不支持 Popover API 或角色图片不可用时保留原生光标回退。
- 不支持滚动时间线或跨文档过渡时使用普通布局与导航。
- `check:motion` 检查滚动、光标和弹窗；`check:navigation` 检查返回入口、互斥按钮、翻页方向和头像；`check:recovery` 检查过渡异常恢复。
- `check:projects` 检查偏上停留、筛选定位、操作行间距、实际剪贴板内容、光晕清理和窄屏溢出。

样式加载顺序由 `src/main.jsx` 维护。背景、文字与强调色使用 `base.css` 的主题变量，交互组件卸载时清理监听与计时器。

| 模块和项目标题组浮现 | `components/ChapterMotion.jsx`、`styles/chapters.css` | 多次上下往返、鼠标筛选后重入、区内固定、键盘焦点 |

复制链接只在剪贴板写入成功后显示确认，不能把鼠标释放动画当作操作成功。新增状态应绑定明确的按钮、原生事件或已完成的操作，并为失败路径保留普通文字反馈。

## 调整后的验证顺序

论文页采用静态、连续的阅读排版，不使用章节入场、退场、翻转或透明度变化。章节之间仅保留适度间距，不添加装饰性分隔线。页内目录高亮、返回导航和回到顶部继续使用站点的通用逻辑。

先在减少动态效果模式下确认正文、导航与控件本身可用，再启用完整动效查看实际滚动。对项目区至少覆盖全部项目、两个分类和快速连续切换；对文章入口检查鼠标移出后光晕是否消失。

导航相关修改需同时覆盖新标签页打开、同页收藏、刷新和前进后退。这些进入方式的事件顺序不同，单次点击成功不能代替其他入口验证。涉及 View Transition 的检查应保留一次正常过渡与一次故障恢复，确认恢复保护没有把所有动画都跳过。

样式调试时不要用永久隐藏正文或依赖固定等待时间的方式掩盖过渡问题。保持原生链接、静态 HTML 和减少动态效果路径可用，具体故障记录目标 URL、导航方式、浏览器及失败请求。

参考：[CSS 滚动驱动动画](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Scroll-driven_animations)、[跨文档 View Transitions](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40view-transition)、[Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using)。

### 光标渲染层

首屏的内联样式由 `vite.config.js` 从两份 SVG 原画生成。`cursor-entry.js` 在加载外部样式之前确定衣装。角色显示尺寸为 64 × 68 CSS 像素，SVG 内含 192 × 204 的透明位图。动画层接管后，日常移动使用相同原画作为背景；滚动或拖动使用已解码的角色图像绕指尖旋转。原生层与动画层使用同一热点，便于在页面加载及减少动态效果模式之间切换。

更换原画后，分别观察默认状态、滚轮换向、拖动和打开弹窗。若只有某个姿态模糊，先比较背景图与角色图像的来源；若指尖偏离点击位置，核对原生热点、动画定位偏移和 CSS 旋转原点。
