# 网站使用

## 项目浏览

首页「项目与实践」按「全部」「应用」「系统研究」筛选。卡片上的「项目介绍」打开功能摘要，弹窗内可复制项目链接。「了解项目」进入独立详情页，「查看源码」打开对应仓库。详情页按完整项目列表提供相邻项目导航，首页筛选只影响当前列表。

## 首页与导航

首页依次展示首屏、关于我、项目与实践、文章与论文、GitHub 联系区和页脚。顶部导航随滚动标记当前分区；窄屏菜单提供同一组入口。

| 进入方式 | 预期行为 |
| --- | --- |
| 新打开首页 | 从首屏开始 |
| 打开旧的首页 `#projects` 收藏 | 从首屏开始，并清理首页锚点 |
| 刷新正在阅读的首页 | 直接恢复原来的位置，不播放从首屏滑下的动画 |
| 从详情页点击“全部项目” | 返回首页项目区 |
| 从文章或论文列表返回所属首页板块 | 返回文章与论文区域 |
| 直接打开项目或正文网址 | 显示该独立页面 |
| 浏览器前进、后退 | 保留浏览器历史位置恢复 |

## 文章与论文

首页「文章与论文」分别链接两个索引。AILearning 在文章索引占一项，专题内按分类、主题和章节逐级浏览，也可从阅读指南进入。章节支持前后翻页和小节锚点。目录下的「资料说明与阅读建议」收录当前层级的源资料说明。

论文详情在页首列出作者、发表页面与 PDF。正文目录按二级标题组织，阅读过程中标记当前小节。相邻的对照图共用一组版面，图注随图片显示。

### 返回导航

| 当前位置 | 主返回按钮的目标 |
| --- | --- |
| 项目详情 | 首页项目分区 |
| 文章或论文详情 | 文章列表或论文列表 |
| 教材章节 | 所属主题 |
| 教材主题、分类或阅读指南 | 清单中 `parent` 指定的上级页面 |

「返回个人主页」链接首页，「回到顶部」滚动当前文档。详情页的页首返回栏移出视口后，上滚可调出浮动返回栏。首页上滚显示浮动回顶按钮时，页脚的同名入口隐藏。[返回栏与滚动实现](MOTION.md)

## 个人资料与交互

| 入口 | 操作 |
| --- | --- |
| 头像 | 点击或通过键盘激活，播放问候；再次激活停止。屏幕阅读器可读取播放状态。 |
| GitHub 链接 | 昵称下的链接打开公开资料；页尾面板随指针位置倾斜，移出后回正。 |
| 喜欢 | 点击切换喜欢状态并播放相应回应。问候、点赞、取消点赞共用一个活动音轨。 |
| 主题与拖尾 | 主题默认跟随系统。手动选择的主题及拖尾开关保存在当前浏览器。 |

主题、拖尾和喜欢分别使用 localStorage 的 `spring-theme`、`spring-trail` 和 `spring-liked`。角色衣装按标签页保存。精细指针设备的首次访问随机选择衣装，站内浏览沿用本次造型，原生刷新时切换；开启「减少动态效果」后使用对应的静态角色指针。

## 站外入口配置

[site.js](../src/data/site.js) 中的 `extraLinks` 接受 `title`、`description` 和 `href`。数组有条目时，首页在仓库链接下方生成「其他页面」，按数组顺序显示并在新标签页打开。带有分类、独立详情和相邻项目导航的作品登记在 `projects` 中。[项目字段](CONTENT.md#首页与项目)
