# 站点功能

## 首页与项目

顶部导航标记当前阅读分区。直接访问首页或打开带 `#projects` 的首页收藏时，从首屏开始。刷新已打开的首页时，浏览器恢复刷新前的滚动位置。从项目详情点击「全部项目」则回到项目分区。

项目列表按「全部」「应用」「系统研究」筛选。「项目介绍」在当前页面打开摘要弹窗，可复制项目详情链接；「了解项目」打开独立详情页；「查看源码」在新标签页打开仓库。详情页的上一篇、下一篇按完整项目数组排序。

首页还支持独立的站外入口。`extraLinks` 中每个对象包含 `title`、`description` 和 `href`。数组有内容时，首页在仓库链接下方显示「其他页面」，按数组顺序排列。[首页数据](../src/data/site.js)

## 阅读与导航

文章与论文在首页共用一个分区，各有独立列表。AILearning 从文章列表进入，目录依次展开为分类、主题和章节。章内目录定位小节，前后章链接用于连续阅读。「资料说明与阅读建议」展开后显示源资料说明。

论文页在标题下列出作者、发表页面与 PDF，正文目录随阅读位置标记当前小节。页首的主返回按钮按下表定位。滚过页首后上滚，浮动栏显示同一组链接。

| 当前页面 | 主返回入口 |
| --- | --- |
| 项目详情 | 首页「项目与实践」分区 |
| 文章或论文详情 | 对应的文章列表或论文列表 |
| AILearning 章节 | 本章所属主题 |
| AILearning 主题、分类 | 教材清单中 `parent` 指向的目录 |

「返回个人主页」始终链接首页。「回到顶部」滚动当前页面，首页的浮动入口与页脚入口交替显示。浏览器后退键沿标签页的访问记录返回。

## 首页交互与偏好

| 操作 | 反馈 |
| --- | --- |
| 点击头像，或用 Enter、空格激活头像 | 播放日语问候并轻摆头像，再次激活可停止播放。屏幕阅读器可读取播放状态。 |
| 悬停昵称下的 GitHub 链接 | 文字切换为主题色，箭头向右上移动，链接背景保持透明。 |
| 悬停页尾的 GitHub 面板 | 面板向指针所在位置倾斜，离开后回正。 |
| 点赞或取消点赞 | 保存当前选择，播放对应音轨。新的操作会中止上一段语音。 |

主题、拖尾与喜欢状态分别存于 localStorage 的 `spring-theme`、`spring-trail`、`spring-liked`。首次访问时主题跟随系统。光标衣装存于标签页的 sessionStorage：首次随机选择，站内翻页沿用，原生刷新时切换。触屏使用系统触控，开启「减少动态效果」后使用静态角色指针（精细指针设备）并关闭倾转和拖尾。[交互实现](MOTION.md)
