# 功能说明与使用指南

本站用于展示个人资料、公开项目、技术文章与论文。页面可以直接分享和收藏，不需要登录。本文说明已经实现的行为；具体编辑步骤见 [内容维护](CONTENT.md)，代码职责见 [开发设计](ARCHITECTURE.md)。

## 1. 首页与导航

首页依次包含个人首屏、关于我、项目与实践、文章与论文、GitHub 联系区域及页脚。顶部“首页 / 关于我 / 我的项目 / 文章与论文”用于定位对应板块；滚动进入板块后，导航更新选中状态。

在项目详情中，“我的项目”保持选中；文章、论文列表和正文使用合并的“文章与论文”导航。合并的是顶部入口，文章与论文仍有各自的索引页面。手机端通过菜单按钮展开导航，选中入口后自动收起，也可以按 Escape 关闭。

| 进入方式 | 预期行为 |
| --- | --- |
| 新打开首页 | 从首屏开始 |
| 打开旧的首页 `#projects` 收藏 | 从首屏开始，并清理首页锚点 |
| 刷新正在阅读的首页 | 直接恢复原来的位置，不播放从首屏滑下的动画 |
| 从详情页点击“全部项目” | 返回首页项目区 |
| 从文章或论文列表返回所属首页板块 | 返回文章与论文区域 |
| 直接打开项目或正文网址 | 显示该独立页面 |
| 浏览器前进、后退 | 保留浏览器历史位置恢复 |

同一标签页再次打开带锚点收藏的处理依赖 Navigation API；不支持该 API 时保留浏览器原生行为。无 JavaScript 时保留普通锚点定位，不能套用全部增强导航规则。

## 2. 项目浏览与筛选

目前展示随手办、GameQA、Autellix 和 TimePredictModel，分为“应用”和“系统研究”。筛选栏默认显示“全部”，类别取自项目数据。筛选仅影响首页当前列表，不删除项目页面，也不改变项目间翻页顺序。

切换类别时列表先淡出。如果已经滚过列表开头，会先回到新列表适合阅读的位置，再更新卡片并淡入，避免结果数量减少后落到页面末尾。选择当前类别不重新筛选。筛选结果不保存到本地存储，重新载入页面时默认显示全部。

宽度达到 1000px 时，项目介绍与筛选栏在项目区内保持 sticky，距视口顶部 138px；较窄布局恢复上下排列。卡片随上下滚动翻转，在主要阅读位置保持正面；鼠标移入时另有轻微倾转和光斑反馈。

### 三个操作入口

| 入口 | 作用 | 适合场景 |
| --- | --- | --- |
| 了解项目 | 打开本站独立项目详情 | 阅读问题背景、实现过程与范围说明 |
| 查看源码 | 新标签页打开对应 GitHub 仓库 | 查看实现、安装方式和最新项目文档 |
| 项目介绍 | 打开简介弹窗 | 留在首页快速查看要点 |

项目名称本身也链接到详情页。当前项目没有托管在线演示，因此不提供演示按钮。

## 3. 项目详情与简介弹窗

详情页由概览、实现思路、适用范围、代码与参考组成。侧栏用于正文内定位；页末提供上一个和下一个项目，不循环跳回第一项。第一项可返回全部项目，最后一项可继续浏览文章。如果文章或论文元数据关联了该项目，详情页还会显示“相关记录”。

Autellix 明确标注为非官方论文复现，原论文作为方法参考，不列为站点作者的发表成果。各项目的实现说明与仓库实验记录不等于本站重新完成了性能验证。

简介弹窗可通过右上角按钮、Escape 或点击弹窗外部关闭。打开时禁止背景滚动，关闭后将焦点交还触发按钮，并保持页面位置。

“复制项目链接”复制的是本站项目详情的完整地址。写入成功后显示“项目链接已复制”，角色光标同步给出确认；浏览器拒绝访问剪贴板时会显示手动复制方式。该操作需要 HTTPS 或 localhost 等允许访问剪贴板的环境。

## 4. 文章、论文与附件

首页提供文章、论文两个入口，各自打开索引。索引按日期倒序显示已发布条目；当前没有公开条目时显示空状态，不生成示例文章冒充已发布内容。

文章正文支持 Markdown 标题、列表、引用、代码块、GFM 表格和图片。论文页面可以额外显示作者、发表渠道、PDF 和发表页面链接。未提供的材料不显示对应按钮；本站不内置 PDF 阅读器，PDF 交给浏览器或目标网站打开。

内容由仓库文件发布，当前没有在线编辑后台、评论、搜索、登录账户、数学公式渲染或代码语法高亮。如何上传正文和 PDF 见内容维护指南。

## 5. 返回与回到顶部

子页面页首始终有“返回个人主页”入口。页首导航离开视口后，向上滚动显示悬浮返回条，向下滚动收起；使用键盘聚焦返回条时保持可见，避免焦点所在控件突然消失。

首页离开顶部一定距离后，上滑显示悬浮“回到顶部”，下滑隐藏。滚动到页脚、原有顶部按钮进入视口时，悬浮按钮隐藏，两个入口不同时展示。触屏和键盘滚动也使用相同的位置判断。

## 6. 主题、角色光标与轻量互动

### 主题与拖尾

顶部主题按钮切换浅色与深色。没有保存过偏好时，首次加载参考系统主题；用户选择后保存到当前浏览器。樱花按钮用于开关拖尾，它控制拖尾，不等于关闭所有页面动效。

### 角色光标

精细鼠标设备上使用现有加藤惠角色素材，指尖对应点击热点。角色会根据链接、文本、阅读、下载、等待、复制及拖动等上下文改变反馈。阅读、源码、筛选和复制入口还显示短提示。

移动、长按、快速移动、双击和拖动反馈不会替代浏览器的原生操作：长按蓄力不执行隐藏命令，角色也不会拦截点击或改变选字行为。只有复制、筛选等实际操作完成后，才触发对应完成反馈。

文章与论文入口的粉色光晕只在鼠标交互时显示；移出、滚轮操作或失焦后清理。触屏不显示角色光标，减少动态效果模式关闭动态角色及主要动画。相关 API 或素材不可用时保留原生光标回退。

### 头像与喜欢

点击个人头像会触发一次轻微动作和问候提示，键盘 Enter、空格同样可用。动作进行时不重复叠加。GitHub 区域的“留下一份喜欢”可再次点击取消；这是浏览器内的个人状态，不是服务器统计的点赞数。

## 7. 本地保存的内容

| 存储键 | 保存内容 | 默认与范围 |
| --- | --- | --- |
| `spring-theme` | `light` 或 `dark` | 无保存值时参考系统主题 |
| `spring-trail` | 拖尾开关字符串 | 默认开启，实际显示还受设备和动态效果设置影响 |
| `spring-liked` | 喜欢状态字符串 | 默认未喜欢 |

这些设置保存在当前网站来源的 localStorage，不同步到其他设备。清除站点数据会重置偏好。存储被禁用时，页面仍可操作，但偏好可能不能在下次打开时保留。弹窗、筛选和提示不写入 localStorage；滚动位置由浏览器历史及入口逻辑管理。

## 8. 静态阅读与兼容范围

JavaScript 不可用时，首页、项目正文、文章与论文索引仍可阅读，普通链接仍可使用；主题按钮、筛选、简介弹窗、喜欢等增强控件不提供完整交互。移动端布局至少按 320px 宽度设计，测试覆盖多个宽度，但不表示已经逐一验证所有浏览器和设备。

动画能力是渐进增强：不支持滚动时间线或跨文档 View Transition 的浏览器保留普通页面和导航。过渡保护脚本在动画失败或超时后释放快照，不会解决网络请求失败本身。遇到访问问题请记录完整网址、进入方式及浏览器，按 [部署排查](DEPLOYMENT.md) 定位。
