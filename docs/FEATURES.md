# 站点功能

## 首页与项目

首页从个人介绍进入项目、文章与论文，页尾链接到 GitHub。顶部导航随滚动标记当前分区，手机端通过菜单选择目的地。从收藏打开首页会回到首屏；在已打开的首页刷新会恢复阅读位置。

项目区可以按「全部」「应用」「系统研究」筛选。卡片的简介按钮打开摘要弹窗，「了解项目」进入实现说明，「查看源码」打开仓库。弹窗支持复制项目链接。详情页按首页项目顺序提供前后翻页，选定分类只影响首页列表。

## 阅读与返回

文章和论文共用一个首页分区，分别进入自己的列表。AILearning 在文章列表中保留一个专题入口，里面按分类、主题和章节组织。读者可以从目录选章、沿前后章连续阅读，或者分享某个小节的锚点。专题的「资料说明与阅读建议」可以展开查看源资料说明。

论文页将发表信息、作者、方法、插图和实验结果放在同一页，正文目录用于定位章节，原文和 PDF 从页首进入。页面向上滚动时浮出返回操作。学习资料的主按钮「返回」指向上一级目录，另一入口返回个人主页。「回到顶部」始终定位当前页面；首页页脚和浮动顶部按钮交替显示。

## 首页互动

| 操作 | 页面反馈 |
| --- | --- |
| 点击头像，或聚焦后按 Enter、空格 | 头像轻摆并播放日语问候，再次点击停止；播放与停止状态提供给屏幕阅读器 |
| 移入昵称下的 GitHub 链接 | 文字变为主题色，箭头向右上移动，背景保持透明；点击在新标签页打开个人资料 |
| 移入页尾「在 GitHub 上」面板 | 面板向指针方向倾斜，离开时回正；链接与喜欢按钮可直接操作 |
| 点赞、撤回 | 切换本地喜欢状态并播放相应音轨；连续操作时只播放最后选择的一段 |
| 切换主题或拖尾 | 主题和拖尾偏好保存在当前浏览器，首次打开时主题跟随系统 |

`spring-theme`、`spring-trail`、`spring-liked` 位于 localStorage。衣装记录在标签页的 sessionStorage 中。首次进入随机选择造型，站内浏览沿用当前造型，原生刷新切换到另一套。触屏页面使用标准触控行为，系统的减少动态效果设置会关闭倾转、拖尾等运动反馈。[动效与光标](MOTION.md)

## 首页外部链接配置

首页外部链接由 [site.js](../src/data/site.js) 的 `extraLinks` 数组定义。每个条目使用 `title`、`description`、`href` 三个字段。首页会在项目区的仓库链接下方显示「其他页面」，按数组顺序排列并在新标签页打开。外部链接提供标题、说明和目标网址。带有独立详情页、分类与翻页导航的作品登记在[项目数据](CONTENT.md#首页与项目)中。

## 页面层级与返回目标

| 当前页面 | 主返回入口的目标 | 如何验证 |
| --- | --- | --- |
| 项目详情 | 首页项目分区 | 从首页筛选结果打开详情，再点「全部项目」 |
| 普通文章、论文详情 | 对应的文章或论文列表 | 直接打开详情网址，滚过页首后向上滚动，检查浮层链接 |
| AILearning 章节 | 章节所属主题 | 在新标签页打开章节后点「返回」，主题页应列出该章 |
| AILearning 主题、分类 | 清单 `parent` 指定的上层目录 | 从目录逐级进入，再用主按钮逐级返回 |

上述目标是页面层级的一部分。浏览器的后退键遵循标签页的访问历史；直接访问深层链接的读者仍能凭页面上的返回入口找到所属栏目。
