## 1. 从表格价值到共享函数

<a id="dqn-1-detail-2"></a>

### 1.1 网络输出的每个坐标代表什么

有限离散动作下，DQN 通常让网络输入状态表示，一次输出每个动作的价值估计。若有三个动作，批次大小为四，输出形状应为四乘三；第一个轴对应转移样本，第二个轴对应动作。回放记录实际动作后，训练读取该行对应坐标，而不是对整行平均。相同状态的其他动作可能因共享参数间接受影响，但并没有直接收到当前动作的监督标签。

表格中一次更新只改一个状态动作项，神经网络中更新一组共享参数可能改变许多状态与动作。这个泛化可以利用相似结构，也可能把某处错误传播到不相关区域。网络容量大不等于每个状态动作得到充分证据，输出一个数也不等于该动作后果已被观察。深度价值学习需要同时分析函数类、数据分布和自举目标，不能只把 Q 表换成网络后沿用全部表格结论。

<a id="dqn-1-detail-3"></a>

### 1.2 DQN 仍然需要充分的状态输入

单张图像可能无法区分速度，最近几帧可以提供更多运动信息，但固定帧堆叠不是对任意环境的马尔可夫保证。若时间期限属于任务，剩余时间也可能需要输入；若只是外部采样保护上限，则不是同一个状态变量。DQN 不会因网络深而自动消除部分可观测，必要时应使用历史、循环状态或信念建模，并相应调整回放序列。

输入变换也属于预测函数。图像裁剪、数值标准化、奖励尺度和动作重复会影响任务与学习动态。若标准化统计在训练中变化，同一回放原始状态可能对应不同输入；若直接存归一化后的状态，又可能混合不同统计版本。需要明确存储对象和变换时点，不要把这些问题隐藏在预处理函数名后面。

<a id="sec-1-1"></a>

<a id="dqn-1-detail-4"></a>

### 1.3 从一条回放转移开始核对

一条记录至少包含当前状态、实际执行动作、奖励、真实转移后状态和真正终止标志。外部截断也应记录，因为它决定轨迹边界与重置，但通常不抹去原任务的尾部价值。如果环境自动重置，返回的新初始观测不能替代停止前最终观测。对普通一步 DQN，样本可以打乱；对循环网络或多步目标，还需要保留真实时序和边界。

先构造一个小批，包含不同动作、一次真正终止和一次仅截断，逐条手算预测与目标，再对照批量实现。形状错误常把一维目标与列向量预测广播成批次平方矩阵，损失仍可能下降。明确断言预测和目标都是同一长度向量，比只检查总损失是标量更能防止这类错误。

## 2. DQN 的自举目标与半梯度

<a id="dqn-1-detail-6"></a>

### 2.1 冻结目标分支的具体计算

在线网络参数记为 $\theta$，目标网络参数记为 $\bar\theta$。真正终止指示为 $D$，一步目标为

$$
Y=R+\gamma(1-D)\max_{a'}Q_{\bar\theta}(S',a').
$$

训练最小化采样分布下的平方误差或稳健损失，目标分支停止梯度。固定当前回放批次与目标参数，取带二分之一系数的平方损失 $\ell=\tfrac12(Q_\theta(S,A)-Y)^2$，其梯度为 $(Q_\theta(S,A)-Y)\nabla_\theta Q_\theta(S,A)$。它不包括下一状态目标的参数导数，因此称为半梯度视角。实际目标参数有独立副本时，在线损失本身就是一个普通固定目标回归；目标随后改变，整个算法才成为交替动态过程。

不要把停止梯度只理解为节省显存。若让目标分支与在线参数共享并反向求导，优化对象和更新方向会改变。对采样平方 TD 误差求完整梯度，又不同于对期望 Bellman 残差平方求梯度，后者还涉及条件期望与双采样问题。三者都可能写出类似平方符号，却不是同一种算法。

<a id="dqn-1-detail-7"></a>

### 2.2 手算一个混合边界批次

折扣取零点九。某条非终止转移奖励一，目标网络下一动作值为二、三、负一，目标为 $1+0.9\times3=3.7$。第二条真正终止奖励负二，即使目标网络在末状态错误输出很大数，目标仍为负二。第三条只因采样达到外部上限停止，奖励零点五、下一最大值四，目标仍为四点一。

当前动作预测若分别为一点二、负零点三、二，则误差为负二点五、一点七、负二点一。平方损失对当前预测的导数与这些误差成比例；没有被当前记录选择的输出坐标不直接获得标签梯度。不同层参数共享后，所有输出仍可能一起变化，这正是函数近似与表格更新的关键区别。

<a id="dqn-1-detail-8"></a>

### 2.3 终止掩码和循环停止是两件事

训练采样循环在真正终止或外部截断时停止本段交互，但价值目标通常只对真正终止清尾。有限时域任务的真实期限则属于终止，并需要时间状态或时间索引价值。不能只看接口名叫时间限制就判断，也不能把两个标志按或运算合成后同时用于所有目标。

即使乘零，也应注意非有限目标可能传播：某些运算里零乘无穷或非数值仍会产生非数值。因此可以只对需要自举的样本计算合法下一状态目标，或确保所有输入与输出有限。终点占位输入、动作掩码和批次索引应有明确契约，避免靠乘一个零试图掩盖无效计算。

## 3. 经验回放减少什么耦合

<a id="dqn-1-detail-10"></a>

### 3.1 重用历史数据与打散局部相关

连续轨迹中的相邻状态通常高度相关，直接逐条训练可能让更新方向被短时局部区域支配。回放把历史转移保存在有限缓冲区，再随机抽小批，打散相邻使用顺序，并让一次交互支持多次梯度更新。它提高数据复用和覆盖混合，但不把原始数据神奇变成独立真实环境样本，也不能产生从未执行动作的后果。

给定固定缓冲区，有放回均匀抽索引可得到条件独立的索引样本；但缓冲区内容来自相关轨迹，跨批样本还会重复，网络参数和数据分布也不断变化。因此“回放使数据独立同分布”若不加条件就是过度表述。更准确的是降低局部顺序相关，并定义一个可控的经验训练分布。

<a id="dqn-1-detail-11"></a>

### 3.2 缓冲分布不等于当前策略分布

缓冲区混合旧策略、新策略和探索动作。一步 Q-learning 的目标在给定当前状态动作后使用环境转移，不需要下一行为动作比率，因此可以利用这种离策略数据。但如果环境机制变化，旧转移已来自另一个核；如果状态缺少影响动作后果的隐藏信息，行为选择也可能带来条件偏差。回放不自动解决机制漂移与状态不充分。

数据分布还决定函数近似更重视哪些区域。高频状态动作的拟合误差可能很小，罕见关键动作却被忽略。整体小批损失不说明部署风险低。应监测状态动作覆盖、数据年龄和关键失败事件，而不只记录缓冲区容量。容量是存储上限，不是信息质量的直接指标。

<a id="sec-4"></a>

<a id="dqn-1-detail-12"></a>

### 3.3 容量、替换与数据年龄

先进先出环形缓冲通常保留最近若干转移。容量过小会迅速遗忘早期成功或关键失败，容量很大则可能保留过时数据，尤其环境变化或策略分布快速移动时。若以固定环境步速率采集且缓冲已满，均匀回放的平均数据年龄与容量相关；但插入批量、异步采集和优先抽样会改变年龄分布，不能只凭一个容量数推断。

替换策略可以保留成功、按来源分层或用蓄水池近似全历史均匀样本，但它们改变经验分布。需要说明目标是近期适应、全历史复用还是稀有事件覆盖。一个在旧数据上稳定的值函数，可能对当前部署新状态外推很差。回放策略与任务的时间稳定性必须一起讨论。

<a id="dqn-1-detail-13"></a>

### 3.4 存储副本与边界元数据

若环境反复复用同一个观测数组，直接把数组引用存入缓冲，后续原地修改会让旧样本悄悄变化。应存不可变对象或显式副本，尤其图像帧、可变字典和循环状态。测试可以插入数组后修改原数组，确认缓冲中的旧状态保持不变。这个错误不一定报异常，甚至会产生看似不断改善的训练损失。

记录还应包括必要来源、环境版本和边界信息。多步回报需要连续奖励和真实末状态，随机抽出的相邻内存记录不一定属于同一轨迹。并行环境还需区分实例，防止把一个环境的奖励接到另一个环境历史。一步随机回放与序列回放是不同数据接口，不能只换采样长度而忽略契约。

## 4. 目标网络改变什么动态

<a id="dqn-1-detail-15"></a>

### 4.1 固定一段时间的回归标签

若每次在线参数刚更新，下一状态标签也立即随同变化，模型会同时追逐自己产生的目标。目标网络在若干更新内固定参数，让当前回归问题暂时稳定。在线网络先拟合这份标签，再通过硬复制或缓慢平均改变目标。它减少一种快速相互反馈，但并不保证目标正确，更不等于得到真实最优价值。

固定目标期间，若数据分布也固定且模型足够简单，可以用普通优化分析研究损失下降。但目标刷新后损失可能突然上升，因为标签变了；这种跳变不必然表示优化器错误。相反，长期很低损失也可能只是拟合了一个偏低或偏高的自洽目标。最终仍要用独立策略评价、已知小模型参照和覆盖诊断判断。

<a id="dqn-1-detail-16"></a>

### 4.2 硬复制与软更新的时钟

硬更新每隔 $C$ 个指定更新单位执行 $\bar\theta\leftarrow\theta$。软更新常写为 $\bar\theta\leftarrow(1-\tau)\bar\theta+\tau\theta$，其中 $0<\tau\le1$，小值表示慢更新。不同代码有时把保留系数记成另一个参数，必须核对公式，不能只比较参数名。更新单位可以是环境步、梯度步或回合，三者不等价。

若每个环境步做很多梯度更新，同时按梯度步软更新，目标相对环境数据变化会更快。相同 $\tau$ 在不同更新数据比下并不表示相同时间尺度。报告应同时给采集步数、优化次数、批大小和目标更新计数。只写每隔一百步同步而不说明哪种步，无法复现实验。

<a id="dqn-1-detail-17"></a>

### 4.3 参数平均不等于预测平均

在线参数的指数平均给目标一个历史参数混合，但非线性网络在平均参数上的输出一般不等于历史输出的平均。不同隐藏单元排列或不同优化区域可能让参数平均具有复杂行为。不能把目标网络直接解释成一个严格的预测集成，除非结构和条件支持。它首先是一种缓慢变化参数机制。

复制目标应避免共享可训练张量引用，否则在线更新仍会同步改变目标，名义上的双网络失去作用。硬复制完整状态字典通常也包含模型缓冲，如归一化运行统计；软更新只处理参数时，缓冲怎样同步需要额外规则。对带 dropout 或批归一化的模型，目标评估模式与统计更新时点也应明确。

<a id="dqn-1-detail-18"></a>

### 4.4 梯度关闭、优化器与状态复制

目标计算放在无梯度上下文，目标参数不加入在线优化器，目标通常处于评估模式，这些措施处理不同问题。无梯度不防止某些模块在训练模式更新运行统计；不在优化器里也不自动阻止构建计算图。一个健全实现会明确每一层权限，再测试目标参数在在线反向和更新后保持不变，直到指定同步时刻。

保存正式检查点时，还要记录在线网络、目标网络、优化器、探索日程和计数等，才能精确恢复训练。仅保存在线权重通常足以做冻结推理，却不保证恢复同样训练动态。本章实验均在内存验证，不生成这些文件；这里说明的是未来真实实验的必要身份信息，不是要求留下无用临时产物。

<a id="dqn-1-detail-19"></a>

## 5. 冻结目标回归与 Bellman 理论的边界

<a id="dqn-1-detail-20"></a>

### 5.1 一次拟合不等于一次精确算子应用

表格 Bellman 最优算子对完整价值表在最大范数折扣收缩。DQN 每轮只看到回放样本，用有限网络和有限优化步拟合固定目标，并可能只在经验分布下误差小。实际映射包含投影、优化和目标延迟，不能直接继承精确算子收缩。数据外状态最大误差可能很大，而平均回放损失仍很小。

若函数类是线性子空间，固定标签最小二乘对应某种分布加权投影。投影在该加权二范数非扩张，不自动在最大范数非扩张；转移算子在不匹配分布下也未必具有需要的性质。函数近似、自举与离策略相互作用可能失稳。这个边界不是否定 DQN，而是说明工程稳定机制和完整理论保证不同。

<a id="dqn-1-detail-21"></a>

### 5.2 自举目标带来的分布依赖

固定当前状态动作条件下，一步样本可估计环境期望，但回放加权可能改变条件分布。若抽样概率只依赖当前状态动作，主要改变各项拟合权重；若优先级依赖奖励、下一状态或 TD 误差，未经校正的样本条件分布也可能改变。不能一概说回放只是无害改变状态频率。重要性权重需要对应实际抽样机制。

目标值又在缓冲覆盖不足动作上取最大，可能挑中纯外推高估。在线优化会把这些高估向已见状态传播，形成自我强化。小回放损失甚至可能与错误价值同时改善。独立评价和已知模型诊断能揭示这种现象；单纯增加目标更新间隔或缓冲容量，不会自动补足缺失动作证据。

<a id="dqn-1-detail-22"></a>

### 5.3 训练损失不是策略评价指标

损失下降表示当前经验目标拟合更好，策略回报还取决于动作排序、状态访问和真实环境。动作值整体偏移可能不改排序，策略已经很好但损失仍有噪声；近乎平局处小误差又可能改变决策，整体损失小却影响重要状态。应同时看目标误差、动作间隔、访问覆盖和冻结策略收益。

评价网络不应继续更新参数、目标或归一化统计，不应消耗训练随机流，也不应通过评价结果挑最终报告而没有独立测试。训练探索行为和部署贪心行为对应不同策略，应分别命名回报。第三章会给完整人工导航 DQN 训练，本章先把更新与评估的机制边界讲清。

<a id="sec-3"></a>

<a id="dqn-1-detail-23"></a>

## 6. Double DQN 的入口与限制

<a id="dqn-1-detail-24"></a>

### 6.1 选择和评价分开

普通 DQN 用目标网络同时选下一最大动作并评价其值。Double DQN 通常用在线网络选择 $a^*=\arg\max_aQ_\theta(S',a)$，再用目标网络读取 $Q_{\bar\theta}(S',a^*)$。真正终止依旧清尾，目标分支停止梯度。这个变化针对选择偏向正估计噪声的问题，不处理全部外推、覆盖或状态缺失。

例如在线下一值为三、二，目标下一值为一、四，普通 DQN 选目标最大四，Double 先按在线选第零动作，再评价目标值一。两者目标可以差很大，但没有谁在这个任意数值例子里天然更接近真值。必须结合估计误差相关性与任务评价理解，不能把 Double 的较小数字自动解释为正确。

<a id="sec-6"></a>

<a id="dqn-1-detail-25"></a>

### 6.2 最大化偏差不要求每个动作高估

若两个动作真实价值相同，估计噪声各自均值零，最大值会偏向选择正噪声较大的动作，期望常高于真实最大值。这个选择偏差不要求每个动作都向上偏，也不意味着任意有噪最大值都一定严格高估。若估计误差完全相同，最大值只是共同噪声，额外选择偏差可消失。条件与相关性很重要。

<a id="sec-6-1"></a>

<a id="dqn-1-detail-26"></a>

### 6.3 Double 不保证完全无偏

如果用于选择和评价的误差独立且真实动作值相同，分离可以消除该特定选择噪声偏差；若真实值不同，选错动作可能导致低估真实最大值；若两网络误差相关，仍可残留高估。目标网络由在线历史复制而来，通常不是独立估计器。因此 Double 是有机制依据的修正，不是所有条件下的无偏定理。

第三章会用选择与评价的批量实现和完整训练进一步比较。本章先保留一个原则：每个改进都应对应一个明确误差来源，并在相同任务、数据和预算下评估。一个修正解决最大化噪声，并不意味着它同时解决离线支持、探索困难或多步目标校正。

<a id="dqn-1-detail-27"></a>

## 7. 四个独立 CPU 实验

<a id="dqn-1-detail-28"></a>

### 7.1 实验一：动作索引、掩码与半梯度

下面用直接可训练的输出矩阵代表在线网络在三个状态的预测，便于检查哪些坐标被监督。目标参数单独存放，包含一次普通转移、一次真正终止和一次仅外部截断。代码同时验证目标手算、梯度权限与固定批次损失下降，不把优化成功当作全部正确性的唯一证据。

```python
import torch

torch.set_num_threads(1)
torch.set_default_dtype(torch.float64)
current = torch.nn.Parameter(torch.tensor([[1.2, .1, -.2],
                                           [.7, -.3, .4],
                                           [.8, .3, 2.]]))
next_target = torch.nn.Parameter(torch.tensor([[2., 3., -1.],
                                               [100., 200., 300.],
                                               [4., 1., 0.]]))
actions = torch.tensor([0, 1, 2])
reward = torch.tensor([1., -2., .5])
terminated = torch.tensor([False, True, False])
truncated = torch.tensor([False, False, True])
with torch.no_grad():
    target = reward+.9*(~terminated)*next_target.max(1).values
assert torch.allclose(target, torch.tensor([3.7, -2., 4.1]))
assert truncated[-1] and target[-1] != reward[-1]
chosen = current.gather(1, actions[:, None]).squeeze(1)
assert chosen.shape == target.shape == (3,)
loss = .5*((chosen-target)**2).mean()
loss.backward()
expected = torch.zeros_like(current)
expected[torch.arange(3), actions] = (chosen.detach()-target)/3
assert torch.allclose(current.grad, expected)
assert next_target.grad is None
before = float(loss.detach())
optimizer = torch.optim.SGD([current], lr=.3)
optimizer.step()
with torch.no_grad():
    after = float(.5*((current[torch.arange(3), actions]-target)**2).mean())
assert after < before
print('targets/selected gradients/frozen target/loss:', target.tolist(), before, after)
```

这里没有把目标参数加入优化器，且目标分支不建立梯度。若改成共享参数又移除停止梯度，得到的方向不再是当前半梯度。目标矩阵中终止行故意很大，仍不进入未来项，说明掩码语义正确；若这些数变成无穷，则还应按正文讨论避免零乘无穷的非有限传播。

<a id="dqn-1-detail-29"></a>

### 7.2 实验二：环形回放与观测副本

这个最小缓冲区只演示先进先出替换、样本身份与副本保护，不承担完整训练。插入七个样本到容量五的缓冲区后，应恰好保留最后五个身份；无放回采样不会在同一批重复索引，但跨批可以重复。修改环境复用的原数组后，先前记录应保持不变，验证最隐蔽的引用错误。

```python
import numpy as np

class Replay:
    def __init__(self, capacity):
        if capacity <= 0:
            raise ValueError('positive capacity required')
        self.capacity, self.data, self.position = capacity, [], 0
    def add(self, identifier, state, action, reward, next_state, terminated, truncated):
        row = (identifier, np.array(state, copy=True), int(action), float(reward),
               np.array(next_state, copy=True), bool(terminated), bool(truncated))
        if len(self.data) < self.capacity:
            self.data.append(row)
        else:
            self.data[self.position] = row
        self.position = (self.position+1) % self.capacity
    def sample(self, batch_size, rng):
        if not 0 < batch_size <= len(self.data):
            raise ValueError('invalid no-replacement batch size')
        ids = rng.choice(len(self.data), batch_size, replace=False)
        return [self.data[int(i)] for i in ids]

buffer = Replay(5)
source = np.array([1., 2.])
buffer.add(0, source, 1, .5, source+1, False, True)
source[:] = -100
assert np.array_equal(buffer.data[0][1], [1., 2.])
for identifier in range(1, 7):
    buffer.add(identifier, [identifier, 0], 0, identifier,
               [identifier+1, 0], identifier == 6, False)
assert {row[0] for row in buffer.data} == set(range(2, 7))
sample = buffer.sample(4, np.random.default_rng(401))
assert len({row[0] for row in sample}) == 4
assert all(2 <= row[0] <= 6 for row in sample)
assert len(buffer.data) == 5
print('ring replay identifiers/copied observations:', sorted(row[0] for row in buffer.data))
```

无放回批次内样本不重复，不代表原始轨迹彼此独立；它只是对固定经验集合的一种抽样。若训练代码需要有放回抽样，应明确更换规则。缓冲存储副本也不等于任何复杂嵌套对象都已经深复制，真实状态字典或多帧共享存储需要按接口进一步检查。

<a id="dqn-1-detail-30"></a>

### 7.3 实验三：硬复制、软更新与共享引用

使用一个线性网络和一个注册缓冲值验证完整状态复制。在线参数先变化，目标保持原样，硬同步后两者数值相同但内存不共享。软更新部分用标量轨迹验证指数平均的闭式权重与滞后。实验不使用批归一化，但缓冲值展示只拷参数可能遗漏模型状态的事实。

```python
import copy
import torch

torch.set_default_dtype(torch.float64)
class SmallNet(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = torch.nn.Linear(2, 2)
        self.register_buffer('scale', torch.tensor(1.))
    def forward(self, x):
        return self.linear(x)*self.scale

online = SmallNet()
target = copy.deepcopy(online).eval()
for parameter in target.parameters():
    parameter.requires_grad_(False)
old_target = {key: value.clone() for key, value in target.state_dict().items()}
with torch.no_grad():
    for parameter in online.parameters():
        parameter.add_(1)
    online.scale.fill_(3.)
assert all(torch.equal(value, target.state_dict()[key]) for key, value in old_target.items())
target.load_state_dict(online.state_dict())
for left, right in zip(online.parameters(), target.parameters()):
    assert torch.equal(left, right) and left.data_ptr() != right.data_ptr()
assert target.scale == 3.
with torch.no_grad():
    online.linear.weight.add_(2)
assert not torch.equal(online.linear.weight, target.linear.weight)
tau = .25
bar, initial = 0., 0.
sequence = [1., 2., 4., -1.]
for value in sequence:
    bar = (1-tau)*bar+tau*value
closed = (1-tau)**len(sequence)*initial+sum(
    tau*(1-tau)**(len(sequence)-1-k)*value for k, value in enumerate(sequence))
assert abs(bar-closed) < 1e-12
assert tau*1+(1-tau)*0 == .25
print('hard-copy isolation/registered state/soft EMA:', bar)
```

网络输出的平均并未被本实验验证，因为参数平均不等于预测平均。对于整数计数缓冲或运行统计，软更新应有专门规则，不能把所有状态字典对象盲目乘小数。目标网络虽不需要梯度，仍要明确模块模式，否则某些内部统计可能在目标计算时改变。

<a id="dqn-1-detail-31"></a>

### 7.4 实验四：独立与相关评价误差

所有动作真实值均为零，生成零均值高斯选择噪声。普通最大值出现正均值，用独立评价噪声读取所选动作后均值接近零；若评价噪声与选择噪声高度相关，则残留明显正偏。这个实验只研究估计噪声机制，不训练完整 DQN，也不证明真实网络误差满足独立高斯假设。

```python
import numpy as np

rng = np.random.default_rng(402)
n, actions = 200000, 4
selection = rng.normal(size=(n, actions))
independent = rng.normal(size=(n, actions))
chosen = selection.argmax(1)
rows = np.arange(n)
ordinary = selection.max(1)
double_independent = independent[rows, chosen]
rho = .8
correlated = rho*selection+(1-rho**2)**.5*independent
double_correlated = correlated[rows, chosen]
assert ordinary.mean() > .9
assert abs(double_independent.mean()) < .015
assert double_correlated.mean() > .7
assert np.isclose(double_correlated.mean(), rho*ordinary.mean(), atol=.015)
print('max/independent/correlated means:', ordinary.mean(),
      double_independent.mean(), double_correlated.mean())
```

原始模型真实动作值相等，所以独立评价的期望为零；如果真实值不同，选错动作会改变相对最优值偏差。目标网络与在线网络有共享历史，误差相关是正常可能性，不能把独立实验结果直接拿来宣称 Double DQN 完全无偏。应分别验证机制例子和完整任务表现。

<a id="dqn-1-detail-32"></a>

## 8. 十六道进阶练习与详细答案

<a id="dqn-1-detail-33"></a>

### 8.1 为什么当前动作要用 gather

题目：三动作网络输出一、二、三，回放动作是编号一，当前预测取什么？解答：取二，即第二个动作坐标。三者平均是另一个量，不代表任何指定动作价值。批量时每行动作可不同，应该按行读取并保持目标同样为长度批次的向量。形状正确还需手算坐标对应，不能只确认损失是标量。

<a id="dqn-1-detail-34"></a>

### 8.2 非选动作为什么仍可能变化

题目：损失只监督一个动作坐标，其他动作输出为何更新后改变？解答：输出共享隐藏参数，一条动作误差会改变共同表示，间接影响其他动作和状态。表格参数独立时不存在同样耦合。它既提供泛化也传播错误，因此需要关注经验分布与数据外输出，不能把未监督坐标变化都当程序缺陷。

<a id="dqn-1-detail-35"></a>

### 8.3 停止梯度改变了什么

题目：目标中下一价值也由网络产生，为什么不让它参与反向？解答：DQN 当前步骤把目标当作固定标签，执行半梯度式回归。完整求导采样 TD 平方会改变方向，又不等于期望 Bellman 残差平方梯度。停止梯度是一项算法定义，不只是性能优化。若更换，需要重新命名目标并分析稳定性。

<a id="dqn-1-detail-36"></a>

### 8.4 回放是否创造独立样本

题目：随机抽样后能否说所有环境数据独立同分布？解答：不能无条件这样说。给定固定缓冲区的抽样索引可条件独立，但数据本身来自相关轨迹，跨批还会重复，缓冲内容随策略变化。回放主要打散局部顺序和复用经验。统计分析和误差解释仍需考虑来源、重复与分布变化。

<a id="dqn-1-detail-37"></a>

### 8.5 外部截断后下一状态是哪一个

题目：环境自动重置，返回新起点，能否用其目标价值补尾？解答：通常不能，当前任务转移后状态应为停止前最终观测。新起点属于下一回合，除非任务本来定义跨重置继续。混用会错误串接独立轨迹，改变 Bellman 目标。应按接口保存最终观测与边界标志，而不是只保留一个完成布尔值。

<a id="dqn-1-detail-38"></a>

### 8.6 目标网络不在优化器里就够了吗

题目：目标参数未加入优化器，是否已经完全冻结？解答：不一定。仍可能建立无用梯度图，训练模式下某些运行统计也可能变化。应同时管理梯度权限、计算上下文和模块模式，再验证参数与缓冲只在指定同步时刻改变。每项措施负责不同问题，不能用一个替代全部。

<a id="dqn-1-detail-39"></a>

### 8.7 硬复制为何要检查内存独立

题目：直接把目标变量赋为在线网络对象会怎样？解答：二者引用同一对象，在线更新立即改变所谓目标，失去慢目标机制。需要独立实例并复制状态，或者使用其他明确隔离方式。数值初始化相同是预期，内存共享通常不是。测试在线更新后目标不变，可以直接发现这种错误。

<a id="dqn-1-detail-40"></a>

### 8.8 软更新系数如何解释

题目：公式保留系数零点九九，与更新系数零点零一是否矛盾？解答：可能是同一规则的不同记号，前者乘旧目标，后者乘新在线。必须查看完整公式与调用时钟。相同参数名在不同实现中含义可能相反，更新单位也可能不同。报告应写方程和每环境步执行次数，而非只列一个数字。

<a id="dqn-1-detail-41"></a>

### 8.9 缓冲越大是否必然更好

题目：把容量增加十倍能否无条件提高性能？解答：不能。可能增加覆盖和保留稀有经验，也可能增加过时数据、降低新经验曝光或改变计算成本。效果依赖环境稳定性、替换与抽样策略。应比较数据年龄、事件覆盖与冻结评价，而不是把容量当作信息量的直接替代。

<a id="dqn-1-detail-42"></a>

### 8.10 Double 为什么不等于两个独立网络

题目：在线与目标是两个参数对象，是否意味着误差独立？解答：不意味着。目标来自在线历史复制，二者共享数据、结构与训练轨迹，误差通常相关。独立噪声例子只解释一种理想机制，真实 Double 仍可能残留高估或产生低估。选择评价分离的价值需要用条件和实验说明，不能用对象数量替代统计独立。

<a id="dqn-1-detail-43"></a>

### 8.11 目标损失下降说明最优值正确吗

题目：固定回放损失接近零，是否已学到最优 Q？解答：不一定。可能只拟合错误目标或有限覆盖样本，数据外动作仍任意。目标网络和经验分布变化还会改变当前回归问题。需要独立策略评价、覆盖诊断与小模型参照。优化当前代理损失和解决原控制问题是不同结论。

<a id="dqn-1-detail-44"></a>

### 8.12 概率加权回放为何可能改条件目标

题目：优先级依赖 TD 误差，不加权直接训练是否只改变状态频率？解答：未必，误差还依赖奖励和下一状态，抽样会在同一状态动作内偏向某些结果，改变经验条件分布。重要性权重可在适当支持下修正指定经验目标，但权重指数、归一化和截断都会影响精确性。不能只说离策略就无需任何校正。

<a id="dqn-1-detail-45"></a>

### 8.13 表格收缩能否保证深网训练

题目：Bellman 算子收缩，为什么神经 DQN 仍可能不稳？解答：实际步骤包含采样、有限函数类投影、非线性优化和延迟目标，未必是同一空间同一范数下精确应用 Bellman 算子。任何一环都需要额外条件。收缩提供重要基础，不是所有复合系统的自动保证。

<a id="dqn-1-detail-46"></a>

### 8.14 目标参数平均是否预测集成

题目：指数平均参数是否等于多个历史网络预测平均？解答：非线性网络一般不等价。参数平均和函数输出平均是不同操作，隐藏单元对称和非线性都会影响。可以研究其经验稳定作用，但不能未经证明当作严格集成。若确需预测集成，应明确保存与组合多个输出并计入成本。

<a id="dqn-1-detail-47"></a>

### 8.15 训练回报和贪心评价为何不同

题目：训练行为含探索，评价关闭探索，两条回报为何不能直接相等？解答：它们执行不同策略，探索可能承担额外风险或偶然发现高收益。Q-learning 目标朝贪心最优构造，不代表当前探索行为已获得同样收益。报告应分别命名，并冻结网络与随机流权限，避免把评价继续学习当作部署表现。

<a id="sec-7-1"></a>

<a id="dqn-1-detail-48"></a>

### 8.16 如何验收一个 DQN 基础实现

题目：最低限度需要哪些有判定意义的检查？解答：动作索引与形状、终止截断目标、真实末状态、目标无梯度且无意外同步、回放副本、合法动作和有限数值，再用小模型验证动作与价值，最后独立冻结评价。每项针对不同错误来源。只看损失下降或一条成功轨迹，不足以验收完整学习系统。

<a id="dqn-1-detail-49"></a>

## 9. 回放抽样的数学目标

<a id="dqn-1-detail-50"></a>

### 9.1 均匀经验风险与真实环境风险

给定容量为 $N$ 的固定缓冲区，冻结目标时，均匀经验风险为 $L_N(\theta)=N^{-1}\sum_{i=1}^N\ell(Q_\theta(s_i,a_i),y_i)$。均匀抽索引的小批梯度在常见可微条件下无偏于这份有限经验风险梯度，不等于无偏于真实部署风险。数据源、覆盖、目标估计和环境版本都会造成二者差异。明确“对哪个目标无偏”比只贴一个无偏标签更有意义。

缓冲区更新时，$L_N$ 本身变化；目标同步时，$y_i$ 变化；在线策略变化又影响未来进入缓冲的数据。DQN 因而不是始终优化一份固定监督数据集。可以在某个冻结窗口内分析回归，再研究窗口之间的映射，但需要避免把局部损失下降直接当成全局单调目标改善。

即使缓冲数据来自同一个平稳环境，有限经验转移也可能遗漏稀有失败。模型对已见结果拟合很好，却在部署遇到未见分支。提高回放次数不会增加独立环境证据，只会更充分拟合当前经验集合。数据效率和统计信息量相关，但不能把同一条样本使用十次算作十次独立交互。

<a id="dqn-1-detail-51"></a>

### 9.2 优先抽样的精确修正

若抽样概率为 $p_i>0$，希望仍优化均匀经验风险，可对每个样本梯度乘 $w_i=1/(Np_i)$。因为 $\sum_ip_iw_ig_i=N^{-1}\sum_ig_i$，在固定缓冲与固定抽样概率条件下恢复同一经验梯度。若使用幂次 $w_i^\beta$ 且 $\beta<1$，通常只部分修正；若截断权重，也改变精确期望。稳定与偏差的取舍应明示。

有些实现把权重除以批内最大值，这个分母是随机且与样本相关，不能继续直接引用原始倒概率无偏等式。若除以固定全缓冲常数，只改变统一梯度尺度，配合步长可另行解释。优先级更新时点、零概率保护和重复索引处理也会影响实际机制。算法名称相同不保证每个版本优化同一个目标。

优先级若由 TD 误差绝对值产生，可能过度抽取不可约噪声大的转移。高误差不一定意味着可学习信息多，也可能是奖励随机、观测别名或模型无法表示。应检查优先样本类型和重复曝光，避免少数噪声记录主导训练。这个问题与探索新奇奖励的噪声陷阱类似，但发生在训练数据选择层面。

<a id="dqn-1-detail-52"></a>

### 9.3 稀有事件保留与真实频率

可以专门保留成功或失败经验，防止先进先出遗忘关键事件。但若训练样本比例改变，模型拟合权重也改变，某些目标需要相应校正。对于风险事件，保留证据很有价值，却不应把保留后的频率直接当作真实发生概率。数据管理目标和概率估计目标必须分开。

例如缓冲中成功与失败各占一半，现实失败率却很低，未经说明的均匀回放可能让经验条件估计偏离实际频率。若只是按状态动作分层、各层内结果仍代表真实转移，主要改变拟合权重；若直接按结果筛选，就改变结果分布。仔细追踪抽样依赖变量，才能判断哪种重要性修正或评价是必要的。

<a id="dqn-1-detail-53"></a>

## 10. 一个目标网络不能自动修复的反例

<a id="dqn-1-detail-54"></a>

### 10.1 合法转移与受限线性函数

考虑两个状态、一个动作、零奖励、折扣零点九。无论从哪个状态出发，下一步都进入状态一，因此真实价值全零。只允许一个参数表示两个状态价值，特征分别为一和二，预测为 $(w,2w)$。训练状态权重为零点九九与零点零一，可通过独立重置后收集一步转移构成这种合法数据设计，但它不是目标链的平稳占用。

冻结目标参数为 $\bar w$ 时，两状态的目标都为 $0.9\times2\bar w$。精确最小二乘拟合得到

$$
w_{\rm fit}=c\bar w,\qquad
c=\gamma\frac{\sum_sd_s\phi_s(P\phi)_s}{\sum_sd_s\phi_s^2}
=0.9\frac{2.02}{1.03}>1.
$$

每一轮回归都可以完全、稳定地求出最优参数，但硬同步后目标参数被放大。反复交替会从非零初始化发散。固定标签损失好好优化，并不保证跨标签更新逼近真实零价值。这是函数近似、采样权重和自举相互作用的具体例子，不涉及复杂神经网络或最大动作噪声。

<a id="dqn-1-detail-55"></a>

### 10.2 软目标只能减慢这个特定不稳定

若每轮先精确拟合，再按正更新率 $\tau$ 软同步，则 $\bar w_{k+1}=[1-\tau+\tau c]\bar w_k$。因为 $c>1$，任意正 $\tau$ 都使放大因子大于一，较小更新率只减缓增长。这个反例没有证明所有目标网络无效，只反驳它能对任意表示和数据权重保证稳定的强断言。

修复可以改变特征、状态权重、更新目标或采用专门稳定方法，但每项都需重新分析。若把状态采样改成目标链平稳分布，条件已经不同。理解反例时应保留其具体采样设计，不要误说标准单动作在线轨迹自然会持续以零点九九访问瞬时状态零。

<a id="dqn-1-detail-56"></a>

### 10.3 实验五：精确拟合仍可放大

以下实验直接计算闭式拟合系数，验证每轮满足加权正交条件，再观察硬同步与慢软同步的放大。没有随机采样误差，也没有优化器未收敛问题，因此能明确定位为复合映射结构，而不是把发散归因于学习率过大。

```python
import numpy as np

phi = np.array([1., 2.])
d = np.array([.99, .01])
p = np.array([[0., 1.], [0., 1.]])
gamma = .9
c = gamma*np.sum(d*phi*(p @ phi))/np.sum(d*phi*phi)
assert c > 1.
assert np.allclose(np.linalg.solve(np.eye(2)-gamma*p, np.zeros(2)), 0)
bar = 1.
for _ in range(20):
    labels = gamma*(p @ phi)*bar
    fitted = np.sum(d*phi*labels)/np.sum(d*phi*phi)
    assert abs(np.sum(d*phi*(phi*fitted-labels))) < 1e-8*max(1, abs(fitted))
    bar = fitted
assert bar > 10000
soft, tau = 1., .01
for _ in range(500):
    fitted = c*soft
    soft = (1-tau)*soft+tau*fitted
assert soft > 1.
assert np.isclose(soft, (1-tau+tau*c)**500)
print('fitted amplification/hard target/soft target:', c, bar, soft)
```

目标网络在很多实际任务中提供有用稳定机制，反例并不否认经验价值。它的教学意义是让读者区分局部回归稳定、参数更新缓慢和完整 Bellman 近似动态稳定。三者相关但不等价。研究说明应准确陈述证据来自哪一层，而不是把一个工程组件描述成理论万能保证。

<a id="dqn-1-detail-57"></a>

## 11. 损失函数与更新尺度

<a id="dqn-1-detail-58"></a>

### 11.1 平方损失与稳健损失

平方损失对大误差给出线性增长的梯度，少数极端 TD 误差可能主导更新。Huber 或平滑绝对损失在小误差区像平方、大误差区限制梯度增速，可以改善某些数值行为。但它改变固定分布下的回归目标，在非对称噪声中最优预测未必等于条件均值。不能一边改损失一边继续无条件宣称精确拟合期望 Bellman 标签。

稳健损失不等于消除所有异常。大误差可能来自真实稀有高代价事件，过度压低其影响会改变风险学习。应检查误差分布和样本语义，结合原始任务评价决定。对人工已知模型，可以比较不同损失在固定目标下的拟合偏差，再进入完整控制，避免把数值稳定与目标准确混成一个结论。

<a id="dqn-1-detail-59"></a>

### 11.2 梯度裁剪与奖励裁剪不同

梯度裁剪限制参数更新方向的幅值，奖励裁剪改变训练目标中的结果幅度。前者也可能影响优化路径，但后者直接改变不同收益的相对价值，尤其高额稀有奖励和小额频繁奖励的排序。两种操作不能只统称为稳定化而不说明。原始奖励评价应始终保留，避免只报告被裁剪后的分数。

按全参数范数裁剪和逐元素裁剪也不同，前者大致保留整体方向，后者可能改变方向。优化器动量与自适应尺度又会改变实际更新。可以监测梯度范数、裁剪频率和参数更新范数，帮助判断问题来自目标尺度还是结构性失稳。频繁裁剪并不自动说明算法安全，可能只是把发散速度限制住。

<a id="dqn-1-detail-60"></a>

### 11.3 更新数据比与样本曝光

每个环境步做几次优化、每次抽多大批，决定经验被重复使用的程度。相同环境交互预算下，更多优化可能提高数据利用，也可能过拟合有限回放或放大自举误差。相同梯度次数下，批大小不同又改变总样本读取和噪声水平。比较方法最好同时报告交互、更新、批大小与总样本曝光。

缓冲满前的热身阶段也重要。若只有极少转移就连续优化，目标可能被局部样本锁定；等待一定覆盖后再学，则改变早期信息条件。热身动作如何选择、是否随机重置、是否保留热身数据，都应写清。不能把一个方法获得更多早期覆盖的收益全部归因于目标公式更先进。

<a id="dqn-1-huber-target"></a>

### 11.4 Huber最优预测为何可能改变动作排序

固定目标网络后，平方回归拟合条件标签均值；换成 Huber 后，应重新解总体最优性条件。令误差 $u=q-Y$，阈值 $\kappa>0$，定义

$$
h_\kappa(u)=
\begin{cases}
\tfrac12u^2,&|u|\le\kappa,\\
\kappa(|u|-\kappa/2),&|u|>\kappa.
\end{cases}
\qquad
h_\kappa'(u)=\operatorname{clip}(u,-\kappa,\kappa).
$$

因此可自由选取标量预测时，最优 $q$ 满足 $E[\operatorname{clip}(q-Y,-\kappa,\kappa)]=0$。凸性使该条件足够，但最小点未必唯一。它平衡的是截断残差，平方损失平衡的则是原始残差 $E[q-Y]=0$。只有在合适分布条件下两者才重合，例如关于某中心对称且可积的标签在该中心使两个期望都为零；不能由“梯度更稳定”推出仍在估计任意条件均值。

考虑一个没有自举、单步即终止的奖励标签：九成概率为零，一成概率为十。期望奖励是一，平方回归最小点也为一。取 $\kappa=1$，当 $0\le q\le1$ 时，零奖励样本贡献导数 $0.9q$，十奖励样本贡献 $-0.1$，所以最优点为 $q=1/9$。该点确在假定区间，导数在邻域斜率为 $0.9$，故是唯一最优点。在 $q=1$ 处，总体导数仍为 $0.8>0$，增加样本或把优化做得更精确，都只会更准确地把预测推离均值，而不会自动消除这个差异。

再给同一状态增加一个安全动作，确定奖励为 $0.5$。它的 Huber 与平方最优预测都为 $0.5$。若两个动作有独立参数、充分数据且精确优化，按期望收益应选随机奖励动作，因为 $1>0.5$；按上述 Huber 预测贪心却选安全动作，因为 $1/9<0.5$。动作排序已改变，原因完全不涉及探索不足、目标网络陈旧或神经网络非凸性。这也不意味着安全动作在其他风险偏好下不合理；只是当前标准期望回报目标与训练估计对象不再一致，Huber 数值本身亦不能被直接命名为某个已定义风险指标。

这里的阈值有奖励单位。把全部奖励与标签放大 $c>0$，若希望损失仍对应同一相对形状，就应同时令 $q\mapsto cq$、$\kappa\mapsto c\kappa$，此时 $h_{c\kappa}(cu)=c^2h_\kappa(u)$；固定阈值不变会改变哪些样本进入线性区。PyTorch 的 [HuberLoss 官方定义](https://docs.pytorch.org/docs/2.14/generated/torch.nn.modules.loss.HuberLoss.html) 还说明其与同阈值 SmoothL1Loss 相差一个阈值因子。这个常数不改变固定数据下的最小点，却改变梯度尺度，与学习率、裁剪和混合损失相互作用。因此研究时应分别报告阈值、标签分布与任务收益，并用这样的两动作例子核对“稳健化”究竟带来了优化改善，还是改变了价值估计目标。

<a id="dqn-1-detail-61"></a>

## 12. 进一步研究与结果解释

<a id="dqn-1-detail-62"></a>

### 12.1 把三个时钟分开记录

环境交互时钟决定新数据何时进入，优化时钟决定在线参数变化，目标同步时钟决定自举标签刷新。多环境并行时还要区分总转移数与每环境步数。相同标称一万步可能对应完全不同的数据量和目标刷新次数。复现协议应把计数规则写成可执行关系，而不是只列一串超参数。

如果只想研究目标延迟，应固定回放数据、优化次数和初始网络，改变同步间隔。若同时改变环境步和更新数据比，结果难以归因。随后可以在完整在线任务中比较，明确延迟与数据新鲜度的交互。机制实验和端到端实验各有用途，最好都保留，而不要求一个复杂曲线解释所有因素。

<a id="dqn-1-detail-63"></a>

### 12.2 分布外动作与自我强化

回放只覆盖部分动作时，未覆盖动作输出可能因共享特征被错误抬高。下一状态最大值选择它，目标将高估传播到已见动作，再进一步抬高网络整体估计。目标网络变慢可以延缓反馈，Double 选择评价分离可以减轻某些噪声，却不提供缺失动作真实后果。离线学习尤其需要针对支持与外推的额外约束和评价。

可以用人工小模型故意删除某些动作数据，比较回放训练误差、完整模型价值误差与策略收益。若训练损失低但策略差，便有可追踪的覆盖反例。增加缓冲容量而内容仍缺失这些动作，不会自动解决；增加网络容量可能反而扩大任意外推空间。第四章将进一步讨论离线支撑边界。

<a id="dqn-1-detail-64"></a>

### 12.3 独立评价应该冻结什么

冻结不仅是关闭梯度，还包括不更新优化器、不同步目标、不改变归一化统计、不衰减探索日程和不写入训练回放。评价使用独立环境与随机数流，避免多评一次改变后续训练。若部署采用确定性贪心动作，要明确并列规则；若保留随机性，则报告实际概率和重复评估方法。

多个评价回合估计固定模型的执行随机性，多个训练种子反映算法训练变异，多个任务来源又反映分布泛化，三者不能相互代替。一个模型评一万次可能估计其当前收益很准，却无法说明换初始化仍稳定。报告应围绕实际随机单位组织，而不只给一条平滑平均曲线。

<a id="dqn-1-detail-65"></a>

### 12.4 从本章实跑能得到什么

本章验证五个彼此独立的机制：动作索引与半梯度边界，回放替换与副本，目标复制与平均，最大化噪声相关性，以及精确拟合自举反例。它们均在 CPU 内存运行，不下载游戏、控制环境或模型权重。它们支持的是对应公式与边界，不构成真实机器人或 Atari 性能复现。

继续第三章时，把这些检查嵌入完整人工导航神经 DQN 训练，再比较冻结策略与精确模型参照。若端到端结果异常，先回到单步目标、缓冲与同步测试定位，再研究探索和函数近似。这样可以把每个复杂现象连接到可检查机制，而不是只靠调参让曲线看起来更好。

<a id="dqn-1-detail-66"></a>

## 13. 补充推导：固定目标、滞后与误差分解

<a id="dqn-1-detail-67"></a>

### 13.1 固定平方回归实际估计什么

冻结目标网络和数据分布后，令随机标签为 $Y$，预测函数为 $f(s,a)$。条件平方误差可分解为

$$
E[(f-Y)^2\mid s,a]=\bigl(f-E[Y\mid s,a]\bigr)^2+\operatorname{Var}(Y\mid s,a).
$$

因此无限表达能力下最优平方预测是当前标签的条件均值，最小损失仍保留不可约方差。网络不能把所有真实随机转移的 TD 误差都压成零；若有限训练集误差接近零，可能是在记忆样本，而非消除环境噪声。这个分解也解释为什么训练损失不是单纯价值误差，噪声大小不同的任务不能直接按损失数值排序。

当前标签均值包含目标网络的下一价值，它未必等于真实最优价值。即使条件均值拟合完全正确，也只是完成一轮近似 Bellman 回归；后续投影与同步动态仍需分析。固定目标回归的统计正确性、复合迭代稳定性和最终控制有效性是三个递进问题，不能凭其中一个成立就自动推出另外两个。

<a id="dqn-1-detail-68"></a>

### 13.2 指数平均的年龄权重

在持续软更新且忽略初始残留后，目标参数可形式上写成历史在线参数的权重和，年龄 $k$ 的权重为 $\tau(1-\tau)^k$。这些权重和为一，平均年龄为 $(1-\tau)/\tau$ 个同步调用单位。权重衰减到原先一半所需年龄与 $\log(1/2)/\log(1-\tau)$ 对应，这比只说很慢更具体。

硬复制每隔 $C$ 次在线更新发生，若在一个周期内均匀观察，目标年龄平均约 $(C-1)/2$。可以据此粗略匹配软更新平均年龄，但不表示两种算法等价：硬目标在周期内完全固定后跳变，软目标每次改变，非线性拟合路径和优化器状态也不同。平均年龄只是一个可比较时间尺度，不是完整动态描述。

若同步调用频率改变，真实环境时间上的年龄也改变。例如每次采集后做十次软更新，目标在一份新数据到来前已多次移动。需要把年龄换算到环境交互单位或墙钟时间，才能理解信息新鲜度。多个时钟的关系是实验定义，不应留给读者从循环代码猜测。

<a id="dqn-1-detail-69"></a>

### 13.3 目标误差与优化误差的分层诊断

在已知小模型中，可以分别计算冻结标签误差、回归拟合误差和真实 Bellman 残差。如果标签本身严重偏离真实一步目标，再精细拟合也无法立刻得到正确价值；如果标签合理而拟合不足，应检查容量、优化与分布权重；如果局部拟合好而跨轮失稳，应检查投影和反馈。这样的分层比统一增加训练步数更有针对性。

真实未知环境没有全模型参照时，可以用保留轨迹、不同时间窗口和独立执行回报做部分诊断，但要承认覆盖限制。保留集若来自同一旧行为分布，也可能看不到新策略访问区域。训练和保留损失同时下降仍不能证明数据外动作可靠。证据范围应随数据来源而明确，而不是因网络很大就扩大结论。

<a id="dqn-1-detail-70"></a>

### 13.4 环境版本混合的具体反例

同一观测动作在旧版本下成功率高、新版本下成功率低，缓冲混合两者后学到某种加权平均。这个平均在训练经验上完全合理，却可能不代表当前部署版本。加大容量可能提高旧版本权重，目标网络变慢又延缓适应。此时不稳定或收益下降并非单纯学习率问题，需要记录版本、选择时间窗口或显式建模变化。

若版本在部署时可见，把它纳入状态可以区分机制；若不可见但历史能提供线索，可以维护记忆或信念；若变化无法识别，只能承认不确定性并采用相应稳健或保守策略。回放是一种数据组织机制，不是状态充分性的替代。把环境漂移与参数训练非平稳分开，才能选择正确修复方向。

<a id="dqn-1-detail-71"></a>

### 13.5 读者可以独立复核的关键结果

第一实验固定标签为三点七、负二和四点一，在线一步更新降低该批损失，目标分支无梯度。第四实验四动作最大噪声均值约一点零三一，独立评价均值接近零，相关评价约零点八二四。第五实验精确拟合放大系数约一点七六五，硬同步二十轮参数超过八万，慢软同步仍增长。这些数字分别对应不同机制，不能相互替代。

把结果与定义紧密相连，能够让读者发现误读：较小 Double 估计不自动更真，较慢目标不自动稳定，较低固定损失不自动高回报。每个结论都有具体前提和反例，深入学习应该保留这种精确性。下一步完整训练会增加环境交互、探索和评价，但这些基础检查仍然需要保留。

<a id="dqn-1-detail-72"></a>

### 13.6 合法动作掩码需要覆盖目标选择

某些状态允许的动作不同，行为选动作时要屏蔽非法项，下一状态最大值也要只在合法集合取值。只在环境执行前裁剪非法动作，却让目标最大值读取其任意高输出，会传播不存在的未来收益。若下一状态真正终止，没有合法动作是正常边界，应直接使用当前奖励；若非终止且合法集合为空，则需检查任务定义。

动作编号还需要跨收集、存储和训练保持一致。环境升级后动作顺序改变，旧回放中的编号不能直接按新接口解释。可以保存动作语义版本或做明确迁移。一个维数始终相同的输出头也可能对应完全不同动作，因此仅检查张量形状不足以保证数据兼容。正式实验协议应记录这些输入输出契约。

<a id="dqn-1-detail-73"></a>

### 13.7 状态增广不应随意改变决策语义

对图像做裁剪、翻转或颜色变化，有时可以增加数据效率，但必须检查动作语义与奖励是否保持。左右翻转画面后，向左与向右动作可能也需交换；若只变图像不变动作标签，就构造了错误监督。对数值状态旋转或缩放也应同步处理物理单位与动作映射。数据增广是关于任务对称性的假设，而不是所有视觉技巧都能无条件迁移。

可以先在人工小任务中验证变换后的转移与原转移是否对应，再将它用于回放。若变换只近似保持机制，应把误差作为方法假设研究。增广目标与原始目标之间的差异也可能成为一种正则化，但不能继续声称每个新样本都是原环境严格等价轨迹。保持定义精确，有助于解释增广何时有效、何时伤害控制。

<a id="dqn-1-detail-74"></a>

### 13.8 从机制检查到后续完整训练

完整 DQN 训练还需要合理探索、足够环境数据和独立评价。当前五个机制实验通过后，可以先让网络在固定小批上过拟合，再在已知导航模型中学习，并把价值误差和策略收益分别报告。若固定小批都无法拟合，优先排查优化与索引；若固定批拟合好但在线失败，再研究覆盖、目标变化与外推。这样的分层路线让后续大量实验有可解释基础，而不是不断增加参数寻找偶然成功。

在交付学习结果时，应把已经运行的断言、由公式得到的结论和建议继续探索的问题清楚区分。这里所有实验都不保存脚本、权重或缓存，正文代码即可独立复核；后续真实项目需要的模型身份与数据版本则属于正式交付资料，不能与临时产物混淆。清爽的文件组织应服务于可追溯性，而不是删掉论证所需的关键条件。只要每个数和每项结论都能回到明确对象，长篇内容才能同时详细而不空泛。
