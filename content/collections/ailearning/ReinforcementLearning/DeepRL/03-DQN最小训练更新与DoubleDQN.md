## 1. 本章要把一次更新连到完整行为

<a id="dqn-3-detail-2"></a>

### 1.1 数学公式正确只是起点

第 1 章已经说明经验回放、目标网络与半梯度的机制，本章把这些组件落实到可独立运行的更新和人工导航训练。必须同时回答：当前动作预测取哪个坐标，下一动作由谁选择，目标由谁评价，哪些分支有梯度，何时同步目标，训练如何收集数据，最后怎样冻结评价。漏掉任意一环，都可能出现损失下降却不是所写算法的情况。

本章只使用 CPU、小型神经网络与人工有限状态模型，不安装游戏或导航环境，不下载数据。模型足够小，可以用精确动态规划得到最优动作价值，再把神经估计误差、贪心策略和真实执行回报分别检查。它是机制与管道验证，不是 Atari 或机器人基准，也不把一个简单任务上的结果外推为普遍算法排名。

<a id="deep-dive-1"></a>

<a id="dqn-3-detail-3"></a>

### 1.2 三种结果要分开命名

单步断言验证张量与目标定义，完整训练验证组件能联合工作，独立评价验证冻结策略在规定环境下的收益。训练损失只反映当前回放与目标拟合，精确 Q 误差反映值函数准确程度，策略回报反映控制质量。三者可能不同步改善，因为动作排序、访问分布和目标噪声具有不同作用。

比较 DQN 与 Double DQN 时，应该固定任务、预算、网络、探索和种子集合，并保留全部运行。Double 的目标较小不自动更真，某次平均更好也不构成所有任务都获胜的定理。一个可读实验应报告实际观察和限制，而不是预设哪种名称必须赢，再按结果修改种子。

<a id="dqn-3-detail-4"></a>

## 2. 普通与 Double 目标的逐样本核对

<a id="sec-1-1"></a>

<a id="dqn-3-detail-5"></a>

### 2.1 在线选择与目标评价

普通目标为 $Y_D=R+\gamma(1-D)\max_aQ_{\bar\theta}(S',a)$。Double 目标为 $Y_{DD}=R+\gamma(1-D)Q_{\bar\theta}(S',\arg\max_aQ_\theta(S',a))$。两者都对目标停止梯度，当前动作预测都来自在线网络的实际回放动作坐标。差异在下一动作选择，不在当前 gather 或终止规则。

例如在线下一输出为三、二，目标输出为一、四。普通用四，Double 用一，因为在线选第零动作。若两网络在下一状态排序相同，则目标可相同；若目标刚从在线硬同步，二者在相同输入与模式下通常相同。后续参数分离后才可能产生差异。不能通过某批目标恰好相同就判断 Double 代码没生效。

<a id="dqn-3-detail-6"></a>

### 2.2 真终止与截断共同出现在批次

真正终止后两种目标都只保留当前奖励，不能让目标动作差异影响不存在的未来。外部截断仍保留真实末状态自举，因此普通与 Double 差异仍可出现。批量实现要确保动作索引是整数、终止是逐样本掩码、预测和目标形状相同，防止列向量和一维数组广播成样本两两组合。

合法动作集合若随状态变化，在线选择和目标最大值都需用相应下一状态掩码。不能只在执行时禁止某动作，却让目标利用非法动作的高估。终止状态可直接不做未来选择；非终止却无合法动作，应作为任务接口错误或另行定义处理，而不是默默得到负无穷目标。

<a id="sec-2-1"></a>

<a id="dqn-3-detail-7"></a>

### 2.3 扩展方法修改不同环节

Double 修改下一动作选择与评价关系，优先回放修改抽样分布，Dueling 修改网络参数化，多步目标修改回报长度，分布方法修改价值表示。它们不能因都叫 DQN 扩展就视为同一种修复。组合时也要重新核对概率、目标与梯度，不是把几个名称写在一起就自动兼容。

本章仅改变普通与 Double 的目标选择，其余尽量固定，便于解释机制。没有加入优先回放、奖励裁剪或多步回报，避免在最小完整实验里同时混入太多因素。后续可以逐项增加，但每次应记录到底改变了输入、目标、表示还是数据预算。

## 3. 一次优化的张量与权限

<a id="dqn-3-detail-9"></a>

### 3.1 当前分支、目标分支和优化器

在线当前状态前向保留计算图，按动作索引提取长度为批次的预测。下一状态在线选择与目标评价通常都在无梯度上下文中完成；Double 的 argmax 是离散选择，不作为 Actor 那样对动作求导。损失反向只更新当前在线参数，目标参数不在优化器中，也不应累积梯度。

每次更新前清空旧梯度，反向后检查有限性，再执行优化器，按指定计数同步目标。目标同步不是损失反向的一部分，也不应在每个模块引用赋值时意外发生。若带有运行统计或随机层，在线选择和目标评价的模式也要明确，否则相同参数也可能产生不同输出，影响机制比较。

<a id="dqn-3-detail-10"></a>

### 3.2 平方损失与平滑绝对损失

固定目标时，平方损失梯度随误差线性增大；平滑绝对损失在大误差处限制增长，可改善某些异常更新。它不能修复下一动作选错、终止掩码错误或回放状态串接。损失选择和目标定义是两个独立维度。当前完整训练使用平方损失，方便与期望动作价值的精确参照联系。

梯度裁剪同样只是更新尺度控制，不是证明稳定的万能工具。若频繁裁剪，应检查奖励、目标 Q 与数据外动作是否异常，而不是只看曲线平滑。当前小模型无需复杂数值技巧，也有利于让错误更容易显现。大规模实现增加稳定机制时，应保留这些基础断言。

## 4. 人工导航任务的完整定义

<a id="dqn-3-detail-12"></a>

### 4.1 状态、动作与随机翻转

位置为零到四，零是失败终点，四是成功终点，一到三为非终止位置。动作零意图左移，动作一意图右移，每次以零点一概率翻转方向。到成功奖励一，到失败奖励负一，其他转移奖励负零点零二，折扣零点九五。真实终点之后未来价值零，进入终点奖励只记一次。

训练从三个非终止位置均匀重置，帮助覆盖各区域；独立部署评价从位置二开始。每段训练最多四十步，达到上限是外部截断，最后转移仍自举，并保存真实下一位置。完整评价上限更长，仍记录截断和有限前缀含义，同时使用已知模型精确评价冻结策略，避免用被截断均值冒充完整任务真值。

<a id="dqn-3-detail-13"></a>

### 4.2 输入表示与网络预算

状态使用五维独热向量，网络为一个十六单元 ReLU 隐层和二动作输出。它是共享参数神经近似，规模足够小便于复核，也能精确表达这个任务。独热输入不测试视觉泛化或连续状态迁移，不能把该结果称为从原始像素学会导航。它专注检验训练流程与目标选择。

回放容量固定一千，累计六十四条转移后开始学习，每个环境步最多一次小批更新，批大小三十二，目标每一百次梯度更新硬同步。所有计数单位明确，不把一百环境步与一百梯度步混用。训练预算固定四千环境转移，不按测试成绩提前停或延长。

<a id="dqn-3-detail-14"></a>

### 4.3 多种子和冻结评价

普通与 Double 各运行三个预先指定种子。行为、环境、回放抽样与评价使用独立随机流，评价不改变训练后状态。相同种子只共享初始设置与环境机制，不保证两个控制方法始终经历逐步相同轨迹，因为策略变化会使后续访问分叉。应保留每次运行，而非仅报告最好的一次。

评价同时输出精确模型中的冻结策略价值、采样回报与成功率、Q 误差和动作数组。若某次策略没有学对，应如实报告，不能把断言写成只允许成功然后换种子重跑。有限预算表现是实验观察，不是表格或神经网络渐近定理的替代。

## 5. 精确模型作为独立参照

<a id="sec-5-1"></a>

<a id="dqn-3-detail-16"></a>

### 5.1 枚举一步核而不是复用学习目标

对每个位置动作，列出意图方向和翻转方向两种结果，按概率计算即时奖励与下一价值。用完整期望做价值迭代，得到最优 Q 参照。它不使用神经训练回放，因此不会与某次采样噪声共同偏移。还可固定最终贪心动作，构造非终止矩阵与奖励向量，解线性方程得到部署策略真实期望。

这两种参照回答不同问题：最优 Q 检查值函数离最优多远，固定策略值检查实际动作组合有多好。若动作全对而 Q 仍有偏差，控制可以已经很好；若 Q 总体误差小但某个关键动作排序错，部署收益可能明显下降。把两项并列，有助于准确解释神经价值学习结果。

<a id="dqn-3-detail-17"></a>

### 5.2 终点输出不当作终点未来奖励

网络对终点独热输入仍可能输出任意数，因为训练通常不监督终点动作。目标掩码阻止这些值影响真正结束后的回报。计算 Q 误差时只比较非终止状态动作，不能强制把未定义或无关终点输出当作学习失败。若为了接口把终点值固定零，也要明确这是一种边界定义。

同样，终止动作没有下一行为选择，不能为它凭空采一个动作来构造 SARSA 或 Double 比率。当前一步算法通过真实终止掩码处理，外部截断则继续使用合法下一状态动作值。基础边界清楚，后续任何扩展才有可信起点。

## 6. 三个独立 CPU 实验

<a id="dqn-3-detail-19"></a>

### 6.1 实验一：普通与 Double 目标逐项对照

人工批次刻意让两网络下一动作排序不同，并包含真正终止与外部截断。当前输出作为可训练参数矩阵，便于直接检查哪些坐标有梯度；在线下一分支和目标下一分支都无梯度。固定目标的一次优化应减少对应损失，但这只验证局部回归，不代表完整控制已经学好。

```python
import torch

torch.set_num_threads(1)
torch.set_default_dtype(torch.float64)
current = torch.nn.Parameter(torch.tensor([[.2, .7], [.3, -.4], [1., .5]]))
next_online = torch.nn.Parameter(torch.tensor([[3., 2.], [7., 8.], [1., 5.]]))
next_target = torch.nn.Parameter(torch.tensor([[1., 4.], [9., 10.], [6., 2.]]))
action = torch.tensor([0, 1, 1])
reward = torch.tensor([1., -2., .5])
terminated = torch.tensor([False, True, False])
truncated = torch.tensor([False, False, True])
with torch.no_grad():
    selected = next_online.argmax(1)
    double_tail = next_target.gather(1, selected[:, None]).squeeze(1)
    ordinary_target = reward+.9*(~terminated)*next_target.max(1).values
    double_target = reward+.9*(~terminated)*double_tail
assert torch.allclose(ordinary_target, torch.tensor([4.6, -2., 5.9]))
assert torch.allclose(double_target, torch.tensor([1.9, -2., 2.3]))
assert double_target[2] != reward[2] and truncated[2]
prediction = current.gather(1, action[:, None]).squeeze(1)
assert prediction.shape == double_target.shape == (3,)
loss = .5*(prediction-double_target).square().mean()
loss.backward()
manual = torch.zeros_like(current)
manual[torch.arange(3), action] = (prediction.detach()-double_target)/3
assert torch.allclose(current.grad, manual)
assert next_online.grad is None and next_target.grad is None
print('DQN/Double targets and current gradients:', ordinary_target.tolist(),
      double_target.tolist(), current.grad.tolist())
```

两种目标差异来自选择评价分离，真正终止行则完全一致。这个例子没有真实 Q 参照，不能由数字较小就宣称 Double 更准确。完整训练才会在已知任务中评价估计误差与行为表现，但也只覆盖所选任务、预算和种子。

### 6.2 实验二：完整神经导航训练与独立评价

以下一个代码块包含模型、环境、均匀回放、训练、精确参照和冻结评价，可独立运行。所有样本由人工环境在线生成，数据只存在内存。为让实验可复核，固定双精度 CPU 单线程和三个种子；普通与 Double 共享配置，不按评价成绩选择检查点。输出逐运行结果，不要求 Double 必胜。

```python
import copy
import numpy as np
import torch
from torch import nn

torch.set_num_threads(1)
torch.set_default_dtype(torch.float64)
gamma = .95
states_eye = torch.eye(5)
def outcomes(s, a):
    direction = 1 if a == 1 else -1
    rows = []
    for probability, movement in [(.9, direction), (.1, -direction)]:
        nxt = s+movement
        reward = 1. if nxt == 4 else -1. if nxt == 0 else -.02
        rows.append((probability, nxt, reward, nxt in (0, 4)))
    return rows

def step(s, a, rng):
    rows = outcomes(s, a)
    _, nxt, reward, done = rows[int(rng.random() >= .9)]
    return nxt, reward, done

def exact_optimum():
    q = np.zeros((5, 2))
    for _ in range(2000):
        new = q.copy()
        for s in range(1, 4):
            for a in range(2):
                new[s, a] = sum(p*(r+gamma*(0. if done else q[nxt].max()))
                                for p, nxt, r, done in outcomes(s, a))
        difference = np.max(np.abs(new-q))
        q = new
        if difference < 1e-13:
            break
    assert np.all(q[1:4].argmax(1) == 1)
    return q

truth = exact_optimum()
def policy_value(policy):
    p = np.zeros((3, 3)); r = np.zeros(3)
    for s in range(1, 4):
        for probability, nxt, reward, done in outcomes(s, int(policy[s-1])):
            r[s-1] += probability*reward
            if not done:
                p[s-1, nxt-1] += probability
    return np.linalg.solve(np.eye(3)-gamma*p, r)

def train(seed, use_double, environment_steps=4000):
    torch.manual_seed(seed)
    behavior = np.random.default_rng(seed+1000)
    dynamics = np.random.default_rng(seed+2000)
    replay_rng = np.random.default_rng(seed+3000)
    online = nn.Sequential(nn.Linear(5, 16), nn.ReLU(), nn.Linear(16, 2))
    target = copy.deepcopy(online).eval()
    for parameter in target.parameters():
        parameter.requires_grad_(False)
    optimizer = torch.optim.Adam(online.parameters(), lr=.003)
    buffer = []
    position, updates, train_truncations = 0, 0, 0
    visits = np.zeros((5, 2), dtype=int)
    s, episode_length = int(behavior.integers(1, 4)), 0
    for environment_step in range(environment_steps):
        epsilon = max(.05, .4*(1-environment_step/environment_steps))
        with torch.no_grad():
            values = online(states_eye[s]).numpy()
        if behavior.random() < epsilon:
            a = int(behavior.integers(2))
        else:
            a = int(behavior.choice(np.flatnonzero(values == values.max())))
        nxt, reward, terminated = step(s, a, dynamics)
        episode_length += 1
        truncated = episode_length >= 40 and not terminated
        row = (s, a, reward, nxt, terminated, truncated)
        if len(buffer) < 1000:
            buffer.append(row)
        else:
            buffer[position] = row
        position = (position+1) % 1000
        visits[s, a] += 1
        if len(buffer) >= 64:
            ids = replay_rng.choice(len(buffer), 32, replace=False)
            batch = [buffer[int(i)] for i in ids]
            bs = torch.tensor([row[0] for row in batch])
            ba = torch.tensor([row[1] for row in batch])
            br = torch.tensor([row[2] for row in batch])
            bn = torch.tensor([row[3] for row in batch])
            bd = torch.tensor([row[4] for row in batch], dtype=torch.bool)
            prediction = online(states_eye[bs]).gather(1, ba[:, None]).squeeze(1)
            with torch.no_grad():
                target_values = target(states_eye[bn])
                if use_double:
                    chosen = online(states_eye[bn]).argmax(1)
                    tail = target_values.gather(1, chosen[:, None]).squeeze(1)
                else:
                    tail = target_values.max(1).values
                y = br+gamma*(~bd)*tail
            assert y.shape == prediction.shape == (32,)
            loss = .5*(prediction-y).square().mean()
            optimizer.zero_grad(set_to_none=True)
            loss.backward()
            assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in online.parameters())
            optimizer.step()
            updates += 1
            if updates % 100 == 0:
                target.load_state_dict(online.state_dict())
            assert all(p.grad is None for p in target.parameters())
        if terminated or truncated:
            train_truncations += int(truncated)
            s, episode_length = int(behavior.integers(1, 4)), 0
        else:
            s = nxt
    assert visits[1:4].min() > 0
    return online.eval(), visits, updates, train_truncations

def evaluate(model, seed):
    before = {key: value.clone() for key, value in model.state_dict().items()}
    rng = np.random.default_rng(seed)
    with torch.no_grad():
        q = model(states_eye).numpy()
    policy = q[1:4].argmax(1)
    exact = policy_value(policy)
    returns, success, truncations = [], [], 0
    with torch.no_grad():
        for _ in range(800):
            s, total, factor = 2, 0., 1.
            for time in range(100):
                a = int(model(states_eye[s]).argmax())
                nxt, reward, terminated = step(s, a, rng)
                total += factor*reward
                factor *= gamma
                s = nxt
                if terminated:
                    success.append(s == 4)
                    break
            else:
                truncations += 1
                success.append(False)
            returns.append(total)
    assert all(torch.equal(value, model.state_dict()[key]) for key, value in before.items())
    assert np.isfinite(q).all() and np.isfinite(returns).all()
    return {'policy': policy.tolist(), 'exact_return': float(exact[1]),
            'sample_return': float(np.mean(returns)), 'success': float(np.mean(success)),
            'evaluation_truncations': truncations,
            'q_rmse': float(np.sqrt(np.mean((q[1:4]-truth[1:4])**2)))}

all_results = []
for use_double in [False, True]:
    for seed in [421, 422, 423]:
        model, visits, updates, truncated = train(seed, use_double)
        result = evaluate(model, seed+4000)
        result.update({'double': use_double, 'seed': seed, 'updates': updates,
                       'minimum_visits': int(visits[1:4].min()), 'training_truncations': truncated})
        all_results.append(result)
        print(result)
assert len(all_results) == 6
print('optimal start-two value:', float(truth[2].max()))
print('all runs retained; no universal Double-wins assertion')
```

精确评价不受模拟评价样本噪声影响，采样回报则用于核对执行环境。若评价出现外部截断，代码保留有限前缀并计数，不能把该均值直接称完整继续回报；精确策略值仍提供完整任务参照。训练目标只用真正终止掩码，截断不会被误作零尾部。

### 6.3 实验三：神经自举的截断错误反例

单状态持续任务每步奖励一，折扣零点九，真实价值十。每次采一条转移就人为停止采样，正确目标仍保留未来；错误目标把每个片段当任务终止，最终只能拟合一。使用线性神经输出和慢硬目标同步，表明错误并非表格特有。它验证目标定义，不复用前面导航训练。

```python
import copy
import torch

torch.set_num_threads(1)
torch.set_default_dtype(torch.float64)
def learn(clear_tail):
    online = torch.nn.Linear(1, 1, bias=False)
    with torch.no_grad():
        online.weight.zero_()
    target = copy.deepcopy(online)
    for parameter in target.parameters():
        parameter.requires_grad_(False)
    optimizer = torch.optim.SGD(online.parameters(), lr=.1)
    state = torch.ones(1, 1)
    for update in range(3000):
        with torch.no_grad():
            y = torch.ones(1, 1) if clear_tail else 1+.9*target(state)
        loss = .5*(online(state)-y).square().mean()
        optimizer.zero_grad(set_to_none=True)
        loss.backward()
        optimizer.step()
        if (update+1) % 20 == 0:
            target.load_state_dict(online.state_dict())
    return float(online(state).detach())
correct, wrong = learn(False), learn(True)
assert abs(correct-10.) < .001
assert abs(wrong-1.) < 1e-10
print('neural continuing value/cut-tail value:', correct, wrong)
```

错误版本的固定回归损失也会很低，所以不能靠损失下降判断目标正确。若真正任务就是一步结束，值一当然正确；反例依赖任务持续而采样仅截断的区别。当前所有实验都把任务机制先写清，再给实现，否则同样数字可能被误说成相反结论。

## 7. 十六道实现与推导练习

<a id="dqn-3-detail-23"></a>

### 7.1 两网络排序不同如何手算

题目：在线下一值三、二，目标下一值一、四，奖励一且折扣零点九，两个目标是多少？解答：普通取目标最大四，得到四点六；Double 按在线选第零动作，再读目标一，得到一点九。当前动作预测与这次下一动作选择无关，仍由回放动作索引读取。不能把当前动作也换成贪心，除非另定义算法。

<a id="dqn-3-detail-24"></a>

### 7.2 同步后目标相同是否实现错误

题目：目标刚复制在线，普通与 Double 某批完全相同，是否没实现分离？解答：不一定，同参数同模式下两者排序一致，目标自然相同。差异在参数和估计逐渐分离后出现。应使用人为排序不同的小批验证逻辑，而不是要求每个实际训练批都产生差别。机制定义与当前数值是否恰好相同是两个问题。

<a id="dqn-3-detail-25"></a>

### 7.3 终止行为什么无选择差异

题目：真正终止下一网络输出不同，目标是否仍应不同？解答：不应，任务结束后未来项为零，目标只保留本次奖励。若普通与 Double 在终止行不同，优先检查掩码、广播或奖励索引。外部截断则不同，任务仍有后续价值，需要真实末状态与合法下一动作估计。

<a id="dqn-3-detail-26"></a>

### 7.4 列向量广播会造成什么错误

题目：预测形状批次乘一，目标形状批次，直接相减会怎样？解答：某些框架会广播成批次乘批次，比较每个预测与所有目标，而非逐样本对应。损失仍为标量且可能下降，所以必须先断言两者同为长度批次向量。动作 gather 后明确压缩动作维，并手算一个不同奖励批次，能发现该错误。

<a id="dqn-3-detail-27"></a>

### 7.5 Double 的 argmax 是否需要求导

题目：在线网络用于下一动作选择，是否应让这个分支参与当前反向？解答：标准 Double DQN 把整个目标视固定，argmax 离散选择也不是连续 Actor 梯度。当前损失只通过当前状态动作预测更新在线参数。若设计可微选择或其他目标，需要重新说明算法，不能继续默认沿用同一半梯度解释。

<a id="dqn-3-detail-28"></a>

### 7.6 平滑损失能否修复错误目标

题目：终止误作自举，改成 Huber 是否会解决？解答：不能，它只改变误差如何影响更新，不会恢复正确未来语义。错误目标仍被拟合，只是大误差梯度受限制。应先修目标与数据，再研究数值稳定。相同道理适用于下一动作选错、回放串接或动作编号错误。

<a id="dqn-3-detail-29"></a>

### 7.7 神经输入独热意味着什么

题目：本章用五维独热状态，能否说明学会视觉导航？解答：不能，它避免感知难题，专门检验神经函数近似和完整控制管道。网络具有共享隐层，但输入空间极小且已知。要研究图像泛化，需要新数据、预处理与状态充分性验证。教学结果应限定到当前信息接口。

<a id="dqn-3-detail-30"></a>

### 7.8 环境随机与探索随机如何分离

题目：行为总选右，实际仍向左，是否探索没有关闭？解答：可能是环境零点一滑动概率，与行为探索不同。评价关闭训练探索，仍应保留原环境随机性。分离随机数生成器可以避免评价消费训练流，也让两种随机机制更容易核对。报告不能把全部随机都压成一个探索率。

<a id="dqn-3-detail-31"></a>

### 7.9 四千环境步对应多少更新

题目：累计六十四条后每步一次更新，四千转移共有多少梯度步？解答：若从第六十四条开始更新，共三千九百三十七次。目标每百次梯度更新同步，因此同步时钟不是环境步直接整除一百。热身影响早期计数，复现应写清先插入还是先训练。不能只凭循环总次数推断优化预算。

<a id="dqn-3-detail-32"></a>

### 7.10 回放环位置为什么要循环

题目：容量满后继续追加却不替换，会改变什么？解答：它变成不断增长的全历史缓冲，容量与数据年龄不再符合声明，抽样分布和内存也变化。环形索引应按容量取模，当前长度未满时只从有效样本抽。实际配置是算法数据机制的一部分，不只是容器实现细节。

<a id="dqn-3-detail-33"></a>

### 7.11 终点 Q 输出为何不要求为零

题目：网络终点输入仍有非零输出，是否全部学习失败？解答：当前任务终点后不决策，这些输出未被监督且被掩码隔离，可不具有实际动作价值意义。误差统计只比较合法非终止动作。若接口显式定义吸收零值，也可强制约束，但需一致处理。不能把无关输出和关键边界错误混为一谈。

<a id="dqn-3-detail-34"></a>

### 7.12 Q 误差大但动作全对说明什么

题目：神经估计仍有偏差，冻结策略却达到最优收益，是否矛盾？解答：不矛盾，控制只依赖每状态动作排序，而 Q 误差衡量数值。统一偏移或小于动作间隔的扰动可以不改策略。应同时报告数值和行为，避免仅凭一个指标给算法贴成功或失败标签。

<a id="dqn-3-detail-35"></a>

### 7.13 同种子为何不保证同轨迹

题目：DQN 与 Double 使用相同环境种子，轨迹是否逐步相同？解答：控制策略变化后状态动作可能不同，同一随机数会作用在不同转移上，回合重置时点也可能分叉。可以说共享初始化规则和随机机制，而非严格相同样本。固定数据比较则是另一协议，需要事先收集并冻结回放。

<a id="dqn-3-detail-36"></a>

### 7.14 评价截断后为何保留计数

题目：长评价达到上限，能否直接丢掉该回合？解答：不应静默丢弃，长轨迹往往与策略质量相关，删除会选择样本。应记录有限前缀、截断比例，并延长预算、用解析值或给尾界。当前小模型有精确冻结策略评价，能避免把前缀均值误作完整期望。

<a id="dqn-3-detail-37"></a>

### 7.15 多种子没有 Double 全胜如何解释

题目：三个种子里两种方法接近，是否说明 Double 理论错误？解答：不是，理论修正特定选择噪声，不保证每个简单任务和预算都提高控制。任务动作间隔、估计相关性和采样路径会影响结果。应保留所有运行，报告有限观察，不能重抽种子直到预期名称获胜。

<a id="sec-6-1"></a>

<a id="dqn-3-detail-38"></a>

### 7.16 最终怎样验收完整神经 DQN

题目：至少需哪些相互独立证据？解答：小批目标与梯度断言、回放和同步规则、真实终止截断处理、已知模型参照、固定预算多种子训练、冻结评价与原始失败记录。每层回答不同问题。一个低损失或成功动画不能替代这些证据，也不能从小模型自动外推到真实机器人。

<a id="dqn-3-detail-39"></a>

## 8. 从输出梯度到共享网络更新

<a id="dqn-3-detail-40"></a>

### 8.1 最后线性层怎样接收动作误差

设隐藏表示为 $h(s)$，最后一层输出 $q_a=w_a^Th+b_a$，当前记录动作是 $A$，平方损失为二分之一误差平方。对输出的导数只有坐标 $A$ 非零，因此该动作头的权重梯度为误差乘隐藏向量，偏置梯度为误差。其他动作头本次不直接收到输出梯度，但隐藏层梯度通过 $w_A$ 回传，使共享表示变化。

这解释了为什么按动作 gather 既是正确监督，也不等于网络其他输出完全不动。训练数据偏重某动作时，隐藏表示可能主要适应该动作，另一些动作数值被间接改变。可以把每动作访问量、误差和梯度分开看，判断问题来自直接证据不足还是共享表示干扰。单一总体损失无法说明各动作都学好。

若网络有共享归一化或随机层，批组成还可能影响各样本隐藏表示。当前最小网络没有这些组件，目的是让基本梯度职责清楚。增加复杂模块之前，应保留当前小批断言和独立评价，避免把状态统计变化误归因于 Double 目标本身。

<a id="dqn-3-detail-41"></a>

### 8.2 半梯度回归与完整残差梯度

当前更新固定 $Y$，导数为 $(Q-Y)\nabla Q$。如果在线参数也产生下一目标且允许反向，导数还包含下一值的负项，方向可能明显不同。后者是在优化某种采样残差平方，不是标准 DQN 半梯度。把目标网络替换为在线网络但仍停止梯度，又是另一种快速变化半梯度过程，三者应分别命名。

即使对采样残差做完整梯度，也不自动得到期望 Bellman 残差平方的梯度，因为期望平方与平方期望不同。双采样问题来自同一个下一状态同时参与残差和导数的相关性。当前标准目标不试图解决这个另一目标，而是采用经验上有效的交替回归。正确理解算法比把一切包装成普通监督损失更重要。

<a id="dqn-3-detail-42"></a>

### 8.3 目标同步后损失跳变怎样解释

固定目标期间在线网络逐渐拟合标签，同步时标签随最新价值变化，损失可突然上升。这个跳变可能是算法正常动态，也可能暴露值尺度漂移。应同时查看目标均值、Q 范围、梯度范数和冻结评价，而不是把每次跳变都视为学习率错误。若目标持续增长而回报不变，更应检查自举高估与数据外动作。

本实验按梯度次数每百次硬同步，日志若只按环境步绘制，需要换算热身和更新规则。一次环境交互后可能没有更新，也可能在其他实现中更新多次。把三种时钟分开记录，可以解释为什么相同目标间隔数字在不同代码里表现不同，而不是简单认为某个实现随机不稳定。

<a id="dqn-3-detail-43"></a>

### 8.4 数值稳定措施不改变基本责任

可以加入梯度范数裁剪、平滑损失或奖励缩放，但目标动作选择、掩码与数据时序仍需先正确。一个错误广播造成的损失可以被优化器稳定降低，错误终止目标也可收敛到稳定错误值。机制实验的作用就是提供不依赖最终表现的局部判据，帮助把实现错误与真实算法限制分开。

当增加稳定措施时，应该说明它改变的是目标、损失还是更新尺度，并在原始任务上评价。奖励裁剪可能直接改变偏好，梯度裁剪主要改变优化路径，平滑损失改变回归统计。它们都可能有价值，但不能因同样让曲线平稳就说完全等价。清楚分类有助于公平消融和后续复现。

<a id="dqn-3-detail-44"></a>

## 9. Double 估计偏差的更细推导

<a id="dqn-3-detail-45"></a>

### 9.1 两动作最大噪声的解析均值

设两个动作真实值都为零，独立估计噪声为均值零、标准差 $\sigma$ 的高斯。利用 $\max(X,Y)=(X+Y+|X-Y|)/2$，且差值为方差 $2\sigma^2$ 的零均值高斯，得到最大值均值为 $\sigma/\sqrt\pi$。每个动作都无偏，选择最大后仍出现正均值，这是最大化偏差的一个精确例子。

若误差完全相同，最大值就是共同误差，额外选择偏差为零；若动作真实值间隔很大，误选概率也不同。因此动作数量、误差方差、相关性和真实间隔共同决定偏差，不能只用一个泛化程度或网络大小解释。多动作最大噪声通常更大，但实际网络误差未必独立，需要通过任务数据研究。

<a id="dqn-3-detail-46"></a>

### 9.2 独立评价仍可能低于最优真实值

让选择估计器决定动作，再用条件均值正确且与选择噪声独立的评价估计器读取其值。评价期望等于被选动作的真实值期望。若真实动作值不同，而选择有时选错，该期望不超过真实最大值，可能产生低估。独立评价消除的是选择噪声被重复利用的一部分，不保证总估计恰好等于最优值。

目标网络来自在线历史，与在线选择误差通常相关，所以理想独立条件又不完全成立。第三节的任意小批只能验证算法公式，不能判断偏差方向。完整训练中还存在探索、投影和目标延迟，最终 Q 误差与控制质量必须实际测量。理论机制提供解释框架，不预先规定每个实验的排序。

<a id="dqn-3-detail-47"></a>

### 9.3 相关误差下的残留选择偏差

在真实值相等的简化模型中，可写评价噪声为 $\rho X+\sqrt{1-\rho^2}Z$，其中 $X$ 为选择噪声，$Z$ 独立同分布。选中动作的独立部分均值零，相关部分保留 $\rho$ 倍被选正噪声，因此仍有随相关性增加的残留偏差。第一章四动作实验展示了这一机制，不把它当真实网络误差的完整分布模型。

硬同步刚发生时相关性可能很高，随后随着在线更新和目标滞后变化。延迟更长不一定一味有利，因为评价网络也更过时。偏差、方差和目标新鲜度之间存在取舍，应在固定预算下评价。只为追求更低相关而无限延迟目标，可能让标签长期错误或适应缓慢。

<a id="dqn-3-detail-48"></a>

### 9.4 小批目标差异与最终收益差异

Double 与普通每次目标不同，不代表最终动作必然不同。如果两者都把每个状态的最优动作排第一，控制收益可以相同，而 Q 数值精度不同。当前导航正适合展示这种情形：任务简单、动作方向明显，多种训练配置都可能学对。不能因最终收益饱和就说机制完全无效，也不能因 Q 误差略小就说业务收益已经提高。

更有区分力的研究可以增加噪声动作、减小动作间隔或设计最大化偏差明显的状态，但要预先定义，保留同等预算与独立测试。不能看到简单任务不显著后不断修改直到某方法赢，再把那次结果说成普遍结论。反例和机制任务可以有意构造，只需明确它们检验哪项假设。

<a id="dqn-3-detail-49"></a>

## 10. 导航任务的解析行为参照

<a id="dqn-3-detail-50"></a>

### 10.1 始终向右策略的三条价值方程

如果三个非终止位置都向右，下一步右移概率零点九、左移零点一。将终止分支奖励并入即时期望，三个状态的奖励期望分别为负零点一一八、负零点零二、零点八九八。价值满足 $v_1=-0.118+0.855v_2$，$v_2=-0.02+0.095v_1+0.855v_3$，$v_3=0.898+0.095v_2$。

代入后得到 $v_2=0.73658+0.16245v_2$，因此 $v_2=0.73658/0.83755\approx0.8794460032$。这个手算与代码线性求解、最优 Bellman 参照一致。它验证进入终点奖励、步耗和折扣，而不是仅仅观察轨迹经常向右。若代码回报约零点九却公式不同，仍应先查任务定义。

<a id="dqn-3-detail-51"></a>

### 10.2 成功概率与折扣价值不同

固定向右策略下，成功概率满足没有奖励与折扣的吸收概率方程。偏置随机游走闭式给起点二的成功概率约零点九八七八零五，期望到任一终点步数约二点四三九。成功概率高于折扣价值是合理的，因为回报还包含失败负奖励、途中代价和延迟折扣。不能把成功率直接当作 Q 的正确数值。

当前采样评价成功率在零点九八五到零点九九之间，与这个模型内概率相符，但有限样本仍有波动。评价出现失败不意味着最优策略有错误，环境滑动本来就可能连续把位置推向失败端。正确报告应保留随机失败，而不是重采直到成功率一百，后者会选择结果。

<a id="dqn-3-detail-52"></a>

### 10.3 状态动作值与冻结策略值的区别

最优 Q 的非贪心动作表示当前先执行那次动作，再按最优策略继续。冻结部署策略值表示从当前状态一直按该策略。当前所有最终动作都最优，所以它们最大 Q 的真实参照与部署值一致；神经估计仍可能对左动作误差较大，因为探索访问较少。单看部署回报会看不到这部分数值不准确。

若研究需要价值校准，例如下游规划或风险决策，非最优动作准确性也重要。若只部署固定贪心动作，某些数值误差暂时不影响行为，但环境改变后可能变得关键。报告用途决定重点，不能抽象地说动作对了就所有价值学习都正确，也不能只因某个稀疏动作误差大就否定已验证控制收益。

<a id="dqn-3-detail-53"></a>

### 10.4 训练起点分布提供的便利

训练均匀从一到三重置，使靠近两端状态都较容易出现，降低覆盖难度。若只能从中间开始，探索次数和早期失败路径会不同。真实系统可能不能任意重置，因此当前样本效率不能直接迁移。比较算法时应把起点设计算作信息与交互条件，而不是当作隐藏实现细节。

可以固定模型只改变起点分布，记录每状态动作计数、Q 误差和最终部署值，研究覆盖如何影响学习。这是清楚的后续问题；如果同时改变探索率和网络，很难单独解释原因。小模型研究的优势是能让每项因素都有解析参照与可追踪样本，而不是只生成更多曲线。

<a id="dqn-3-detail-54"></a>

## 11. 实跑结果与统计范围

<a id="dqn-3-detail-55"></a>

### 11.1 六次运行全部保留

三个普通 DQN 的非终止 Q 均方根误差依次约零点零三三六、零点零八零三和零点零六五七；Double 对应约零点零三三零、零点零四七四和零点零六五四。三种子下 Double 数值误差略小或明显小，但三个状态贪心动作都为向右，所以两方法模型内精确部署收益完全相同。这是当前配置的有限观察，不是普遍性能排序。

每次运行都是四千环境转移、三千九百三十七次优化，全部相关动作至少访问九十多次，训练与评价均没有触及外部截断。没有按某个失败种子延长训练，也没有用测试回报选择检查点。结果能支持最小管道工作、最终策略正确与数值误差不同，不能支持在大任务上 Double 总获胜或已经具有统计显著泛化优势。

<a id="dqn-3-detail-56"></a>

### 11.2 相同评价回报并非重复训练结果

两算法在相同种子下最终策略相同，评价又使用相同独立环境随机流，因此该种子的采样回报与成功率也相同。这不意味着训练网络参数、回放或 Q 估计相同，而是冻结动作规则在评价任务中完全一致。若最终策略不同，相同种子也未必提供严格逐步相同轨迹，需要重新解释配对层次。

当前三个评价均值约零点八八二六、零点八八二零和零点八七七零，围绕精确值零点八七九四波动。每次八百回合估计的是固定策略执行随机性，不等于三个训练种子的全部不确定性。三个种子足够演示保留运行和比较方式，却不足以对广泛环境作强统计结论，应明确样本范围。

<a id="dqn-3-detail-57"></a>

### 11.3 成功率区间与原始计数

固定策略下，若每回合独立且从相同起点出发，成功次数可按二项抽样理解。成功概率接近一时，正态近似可能不理想，正式报告可使用合适二项区间或直接给原始成功失败计数。八百回合中少数失败足以使比例变化几个千分点，不应把微小比例差直接解释成控制机制改善。

若多个回合共享同一外部场景或参数，独立单位可能更高层，应按来源组织区间。当前人工环境每步独立滑动，没有这种场景分组，说明简单二项解释的条件。真实任务不能因代码也有回合循环就照搬独立假设。统计单位与任务机制同样需要明确。

<a id="dqn-3-detail-58"></a>

### 11.4 无评价截断不意味着可以忽略分支

本次没有长轨迹达到一百步，但代码仍记录截断。若以后改变滑动、策略或环境结构，长回合可能变多，有限前缀均值就不能直接与完整期望比较。可以延长预算、使用解析值或给折扣尾界，不能删除未完成回合制造更好结果。边界分支的正确性不应依赖某次恰好没触发。

同理，训练没有达到四十步上限，不意味着目标可以把截断合并为终止。正确接口是为任务定义服务，而不是针对当前种子结果简化。第三实验专门构造每步截断的持续任务，显示神经目标一旦清尾会学到一而非十。机制反例弥补完整训练中边界未触发的覆盖。

<a id="dqn-3-detail-59"></a>

## 12. 回放曝光与更新预算的推导

<a id="dqn-3-detail-60"></a>

### 12.1 满缓冲中的平均重复使用

设容量为 $N$，每次插入一条并淘汰最旧记录，每环境步做 $U$ 次独立小批更新，批大小 $B$ 且均匀无放回抽样。一个样本在满缓冲阶段约存活 $N$ 次插入，每次更新被纳入概率 $B/N$，因此期望曝光约为 $UB$ 次。这个数量不随容量线性增加，容量主要改变年龄跨度与同时混合的数据范围。

在固定简化条件下，完全未被抽中的概率约为 $(1-B/N)^{UN}$。这不是所有回放实现的普遍公式：热身、变化更新比、优先级、异步插入和提前删除都会改变。它帮助读者理解容量、批大小与数据复用的不同作用，而不是把容量翻倍误说成每条样本必然多学一倍。

<a id="dqn-3-detail-61"></a>

### 12.2 早期样本与热身阶段

缓冲未满时，抽样集合较小，早期样本可能被重复看到更多次。延迟到六十四条开始训练，避免在极少记录上大量自举，但也意味着前六十三步没有梯度更新。最初样本由随机初始化与较高探索产生，可能对后续值尺度产生影响。热身策略、时长和起点规则都应进入复现说明。

如果要比较不同热身长度，应固定总环境预算，并明确少做或多做了多少优化。某方法收益更好可能来自更多初始覆盖，也可能来自较少早期错误更新。可以在冻结同一数据集上对比，再进入在线训练区分这两项。仅在最终平均回报上观察差别，很难单独归因。

<a id="dqn-3-detail-62"></a>

### 12.3 环境步与优化步的公平比较

相同环境交互数下，一个方法多做十倍更新，可能提高数据效率却增加计算成本；相同优化次数下，批大小不同又改变总样本读取。可以分别报告质量随交互数和随时间的曲线，避免只选择对自己有利的横轴。当前实验每步最多一次更新，普通与 Double 的额外在线下一状态前向也应被视为计算差别。

小网络 CPU 实验的实际时间不代表高维视觉环境或大规模并行训练。数据搬运、卷积和模拟器成本占比会改变哪项更重要。方法报告应把当前测量范围说清楚，不能由几秒级小模型推导出生产吞吐优势。成本结论必须来自对应设备、规模和实现的测量。

<a id="dqn-3-detail-63"></a>

## 13. 诊断顺序与可证伪实验

<a id="dqn-3-detail-64"></a>

### 13.1 固定小批过拟合检查

若完整训练失败，可以先冻结少量转移和目标，检查在线网络是否降低对应回归损失。这个测试排除某些索引、优化器和梯度权限问题，但通过后不代表在线控制可靠。目标一旦更新、数据分布变化，自举反馈会引入新困难。不要把小批过拟合能力当作完整收敛证明。

若固定批都无法拟合，先检查动作维、目标形状、学习率、参数是否加入优化器以及非有限值。若只有某些动作不学，检查它们是否真的被 gather 选中、计数是否增加。相比立即增加网络深度，这些检查具有更明确的解释。复杂模型可能暂时降低损失，却掩盖原始接口错误。

<a id="dqn-3-detail-65"></a>

### 13.2 固定数据比较与在线比较

冻结同一回放可以让 DQN 与 Double 使用完全相同数据，隔离目标构造和优化差异；在线训练则允许目标变化影响行为与后续数据，评价完整控制闭环。两种实验都有效，回答不同问题。不能把固定数据上的效果直接说成探索更好，也不能把在线收益差全部归因于单步目标噪声。

可以先在固定数据中设置覆盖完整和刻意缺失动作两种情况，观察 Q 误差与外推；再进入在线环境看是否能通过探索纠正。这个设计把估计与采集耦合拆开，让失败更有信息。若所有内容都同时变化，结果即使显著，也难说明新方法究竟解决什么机制。

<a id="dqn-3-detail-66"></a>

### 13.3 动作间隔与错误位置

相同总体 Q 误差，分布在大间隔状态与近乎平局状态的控制后果不同。可以按状态列出真实动作间隔和估计差，找出可能改变策略的位置。若所有误差都远小于间隔一半，贪心稳定有明确保证；若超过这个阈值，也只是失去充分保证，不表示一定选错。

当前导航方向明确，容易让控制指标饱和。后续研究可调失败奖励、步耗或滑动，让某些动作接近，再观察目标修正是否更有意义。每个参数改变都要重新计算精确参照，不能沿用原先向右最优的断言。任务变化与算法变化应分开，避免把环境更容易误当方法进步。

<a id="dqn-3-detail-67"></a>

### 13.4 状态表示碰撞的反例

如果把两个需要不同动作的状态编码成同一输入，确定性前馈网络无法为它们输出不同值。增加隐藏层不能消除完全相同输入的歧义；需要额外合法特征、历史或不同模型状态。当前独热表示避免了这种碰撞，所以训练成功不证明算法能处理部分可观测。信息接口是先于优化的条件。

可以在另一个人工任务中故意合并状态，比较真实状态策略与观测策略，验证性能上限如何变化。若不说明额外知情状态权限，就容易把信息优势误归因于算法。深度强化学习研究中，预处理、帧堆叠和时间输入都可能带来这种差别，必须作为完整方法的一部分报告。

<a id="dqn-3-detail-68"></a>

## 14. 从小模型走向更复杂任务

<a id="dqn-3-detail-69"></a>

### 14.1 更大状态空间带来的新问题

把一维位置换成图像后，感知泛化、状态混淆和数据增广成为额外困难。把环境换成长期稀有奖励后，覆盖和信用分配又更重要。当前代码的目标公式可以迁移，但网络、输入和数据管道需要重新验证。不能只把状态维数改大，就假定小模型证据全部自动延伸。

合理扩展应逐项增加复杂性，例如先增加位置数并保持精确模型，再引入无关特征，然后加入部分观测或随机奖励。每一步都保留可计算参照或明确边界。这样失败时能指出新增困难，而不是用一个庞大黑箱把全部原因混在一起。深入学习需要更多问题，也需要每个问题的证据可区分。

<a id="dqn-3-detail-70"></a>

### 14.2 训练恢复与正式交付

若要恢复训练，需要在线网络、目标网络、优化器、探索日程、计数和回放身份等，单一在线权重通常只足以做推理。当前实验的全部状态在内存中维护，示范的是训练更新与评价；若要持久化恢复，应另行保存上述状态并验证后续更新是否一致。未来真实项目保存正式检查点时，应明确用途与版本，而不是把它们当无用中间物一概删除。

复现实验还需记录随机数流分工和终止接口。仅给一个种子无法说明行为、环境、回放与评价何时使用随机数。当前代码将它们分开，使插入评价不会消耗训练流。这个设计不要求不同算法拥有完全相同轨迹，而是确保每个流程的变化可以追踪。

<a id="dqn-3-detail-71"></a>

### 14.3 最小实现并不意味着最少说明

一个训练循环可以写得很短，却可能隐藏状态语义、动作索引、终止边界和评价权限。本章宁愿把这些对象展开讲清，因为它们决定你到底学到了哪个任务。精简应删除重复装饰，不应删除论证条件。代码、手算、反例和实际输出各自承担不同职责，完整资料需要把它们连接起来。

学习者应能从任意一条回放记录重建当前预测和目标，能解释一次参数更新为什么影响其他状态，能说明何时目标刷新，以及最终收益来自哪套冻结动作。具备这些能力后，再研究更复杂扩展会更容易判断其真实贡献，而不只是记住越来越多缩写。

<a id="dqn-3-detail-72"></a>

## 15. 从目标差异到控制误差界

<a id="dqn-3-detail-73"></a>

### 15.1 同一对网络下 Double 目标不大于普通目标

固定同一个非终止样本、在线网络和目标网络，普通读取目标最大坐标，Double 读取在线选中的某个目标坐标，因此两者差为

$$
Y_D-Y_{DD}=\gamma\left[\max_aQ_{\bar\theta}(S',a)-Q_{\bar\theta}(S',\arg\max_aQ_\theta(S',a))\right]\ge0.
$$

真正终止时差为零。这个不等式是固定网络同批比较的精确代数，不需要高斯噪声假设。若实际代码同一输入算出 Double 更大的目标，优先检查两次前向是否使用不同模式、随机性或数据，以及动作读取实现。

但整个训练过程两种算法网络会不同，因此不能把这个逐样本不等式扩展成任意时刻 Double 学到的所有 Q 都更低。更低也不自动更接近真值：普通可能高估，Double 可能低估，二者都可能受模型外推影响。严格区分固定对象比较和动态算法结果，是避免过度解释的关键。

<a id="dqn-3-detail-74"></a>

### 15.2 固定选择规则时的评价算子

如果暂时冻结在线选择规则，Double 目标相当于对这套下一动作规则做一步策略评价，而不是在目标网络上直接最优备份。在线规则继续更新后，选择对象也变化，形成两套参数耦合动态。它不是简单把一个固定最优 Bellman 算子换个名字，所以不能只用单一算子收缩证明整个非线性训练。

在精确表格、适当更新和访问条件下，可以分析相应算法；神经近似与有限回放又需要额外论证。当前实验只验证标准公式、机制与有限任务表现，不声称给出一般收敛证明。理论和实验的分工清楚，读者才能知道哪些结论可以迁移、哪些仍需研究。

<a id="dqn-3-detail-75"></a>

### 15.3 动作价值统一误差怎样控制策略损失

设所有合法状态动作的估计误差不超过 $\varepsilon$，策略对估计 $q$ 贪心。真实最优动作值与所选动作的真实最优 Q 差至多 $2\varepsilon$：最优动作可能被低估一次，所选动作可能被高估一次。将这个一步损失沿策略递推，得到 $\|v^*-v^\pi\|_\infty\le2\varepsilon/(1-\gamma)$。

这是关于完整统一误差的保证，不是只对一个回放批均方误差成立。若已知模型中动作价值 Bellman 最优残差为 $\delta$，可先由收缩界定 $\varepsilon\le\delta/(1-\gamma)$，再得到保守控制界。高折扣使界放大，说明很小训练数字未必对应同样小控制风险。当前小模型可以直接求精确策略值，往往比最坏上界更有解释力。

<a id="dqn-3-detail-76"></a>

### 15.4 均方误差与统一误差的有限关系

当前只有六个非终止状态动作项，若对全部项均匀计算 RMSE，可以用最大误差不超过平方根六倍 RMSE 的简单有限维界。这个关系依赖全部项都被精确评价，不能把从样本分布估计的平均误差直接当作大状态空间最大界。稀有关键区域可能完全不在评估样本里。

因此实际报告同时保留逐状态动作表、总体 RMSE 和冻结收益更有意义。模型规模扩大后，可以按访问频率与关键事件分组，明确哪些区域证据不足。评价指标越多不一定越好，关键是每项回答一个独立问题，而不是堆一串无法解释的分数。

<a id="dqn-3-detail-77"></a>

## 16. 学习完成后的自检路线

先不看训练代码，独立写出一条普通目标、一条 Double 目标和一条真正终止目标，再把它们对应到张量坐标。然后解释为什么目标分支不反向、为何目标网络独立存储、何时同步。再读取完整结果，区分 Q 精度改善与控制收益相同。若每项都能用当前公式和数值解释，就说明已经掌握最小深度价值学习的核心。

继续第四章时，连续动作无法直接枚举最大值，Actor 会参与寻找动作，离线数据又缺乏主动纠错。之前的覆盖、目标误差和评价边界仍然重要，但会以新的形式出现。保留这种从具体对象出发的检查方式，能让后续 DDPG、TD3、SAC 与离线方法之间的区别真正清楚，而不是只记住几个额外网络和损失。

<a id="dqn-3-detail-78"></a>

### 16.1 经验目标中的不可约噪声

同一状态动作在滑动环境里有两种结果，奖励和下一状态目标不同。即使当前预测等于其条件均值，单个样本误差仍会波动，固定目标平方风险的最小值包含条件方差。因此训练后损失非零并不必然说明网络没学会，强行拟合每条随机记录到零也不一定更接近总体期望。应该结合独立模型残差和策略评价判断。

目标网络变化又会让这份条件均值移动，训练损失混合了采样噪声、拟合不足和标签更新。若只看最后一个小批损失，甚至可能被偶然容易样本误导。可以记录固定保留转移上的误差，但它仍受覆盖限制。当前已知模型参照提供更强核验，真实未知任务则需要承认证据范围，而不是用一个低损失代替全部验证。

<a id="dqn-3-detail-79"></a>

### 16.2 代码与说明必须保持同一个任务

任何后续修改都应同时检查说明与实现。把滑动从零点一改为零点三，精确参照与评价也应更新；把奖励改成只在成功给一，负终点代价与步耗分析就不再适用；把训练期限改成真正有限任务，状态和尾部目标也要相应改变。仅修改一处参数却保留原先手算结果，会让教材看似丰富但内部矛盾。

最有效的维护方式是保留少量有唯一正确答案的性质测试和完整任务表。每项测试都应给出输入、预期性质与失败含义，正文代码可用于独立复核。读者既能运行完整实验，也能按自己的好奇心改变一个机制并重新推导，而不会把偶然数字当成永远正确的结论。这种可修改、可反驳、可解释的学习方式，有助于逐步理解更新规则与评价结论之间的关系。

还应检查评价模式是否真的覆盖整个模型状态。当前网络没有批归一化和随机失活，因此冻结参数与评估模式容易核对；换成复杂模型后，运行均值、缓存和循环记忆也可能改变输出。不能只比较参数数组不变就认为评价完全隔离。正式复现需要根据模块语义扩大检查范围。

同时保留所有种子和失败路径，比反复寻找一个更漂亮的结果更有教学价值。当前任务的成功证明管道可以工作，剩余误差与算法差异也被如实保留，读者因此能继续提出明确的新问题，而不必先相信某个方法天然优越。
