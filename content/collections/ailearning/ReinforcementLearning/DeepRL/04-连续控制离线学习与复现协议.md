## 1. 连续Actor-Critic的目标必须逐项定义

确定性策略输出一个动作，随机策略输出条件分布；硬最大、目标 Actor 动作和随机下一动作是不同的备份。它们可以共享回放与缓慢更新的网络，却不意味着目标相同。比较方法前先写出下一状态动作由谁生成、价值由哪个参数评价、是否包含熵、什么时候允许自举，再核对代码实际使用的对象。名字相似不是替换公式的依据。

<a id="deeprl-4-detail-2"></a>

### 1.1 TD3的三个设计改变什么

一种常见 TD3 形式使用目标 Actor 产生动作，再加裁剪噪声并限制到合法范围，目标为奖励加折扣后的两个目标 Critic 最小值。两个 Critic 分别拟合同一停止梯度目标，Actor 主要利用其中一个当前 Critic 更新，Actor 和目标网络按预定延迟频率更新。双估计、动作平滑和延迟更新分别改变估计偏差、局部动作敏感性与更新时标，不能把全部收益都归因于某一项。

写成符号，令 $`\widetilde a'=\mathrm{clip}(\mu_{\bar\theta}(s')+\epsilon,l,h)`$，其中 $`\epsilon`$ 按协议抽取并裁剪，则

```math
y=r+\gamma b\min_{i=1,2}Q_{\bar\phi_i}(s',\widetilde a').
```

$`b`$ 表示真正终止后是否允许自举，外部采样截断不自动令其为零。目标噪声只用于备份，不等于行为探索噪声；两者分布和种子都应记录。动作边界裁剪会改变平滑分布，不能继续把边界附近的噪声当成原高斯。上述形式是具体算法设计，不提供任意函数近似下的收敛保证。

<a id="deeprl-4-detail-3"></a>

### 1.2 SAC软备份与当前随机策略

现代常用双 Q 形式从当前随机策略产生下一动作 $`a'\sim\pi_\theta(\cdot\mid s')`$，以缓慢更新的目标 Q 评价：

```math
y=r+\gamma b\left[\min_iQ_{\bar\phi_i}(s',a')-\alpha\log\pi_\theta(a'\mid s')\right].
```

温度 $`\alpha>0`$ 控制奖励与熵的相对权重，不是优化器学习率。部分早期形式还有独立价值网络，因此实现说明应给变体而非只写 SAC 三个字。下一动作来自随机策略，不能机械照搬确定性目标 Actor。目标通常整体停止梯度，用于 Critic 回归；Actor 更新则另有完整动作梯度链。

给定重参数动作 $`a_\theta=f_\theta(s,\xi)`$，Actor 常最小化 $`E[\alpha\log\pi_\theta(a_\theta\mid s)-\min_iQ_{\phi_i}(s,a_\theta)]`$。冻结 Critic 参数不等于对它的前向整体禁用求导，Actor 仍需价值对动作的导数。温度可以固定，也可按明确的目标熵规则学习；两者条件不同。连续密度允许大于一，log 密度为正并不自动说明程序错误。

<a id="deeprl-4-detail-4"></a>

### 1.3 一个终止目标的手算

即时奖励一、折扣零点九、允许自举、最小目标 Q 为三、温度零点二、log 密度负一时，SAC 目标为三点八八。若真正终止则目标仅为一。若将符号写成加 log 密度，目标会变成三点五二，这不是同一个最大熵目标。先手算这些局部值，再看完整训练曲线，可以及早发现符号或终止语义错误。

熵项还与动作单位有关。把动作整体缩放会改变微分熵中的常数，目标熵与温度协议应跟随坐标约定。均值动作评价、随机采样评价和温度正则训练也需要分别命名。某个随机策略的最大熵目标更高，不等于原始奖励或确定性部署动作必然更好，最终应按共同外部目标评价。

<a id="visual-deeprl-04"></a>
### 图解：离线数据：三个吻合点，无法确定未观测处的好动作

![同一批离线记录可支持对未见动作不同的解释](images/04-img-offline-action-nonidentifiability.webp)

[打开原图放大](images/04-img-offline-action-nonidentifiability.webp)

固定离线记录的三个动作 $`-0.5,0,0.5`$，真实奖励为 $`Q_0(a)=-a^2`$。下面用一族函数表示与图中共同数据相容的不同解释
```math
Q_c(a)=-a^2+c\,a^2\left(a^2-\frac14\right),\qquad c\ge0.
```
新增项在三个记录动作上都为零。因此经验平方误差对任意 $`c`$ 都等于零，更多轮拟合也不能从这些记录中识别 $`c`$。不同函数在记录点吻合，却可以在未覆盖的区间边缘相差很远。现有观测无法区分它们。

再把模型差异转化为行动后果。令 $`t=a^2\in[0,1]`$，则 $`Q_c=ct^2-(1+\frac c4)t`$ 为凸函数，其最大值在区间端点达到。两个候选值分别为 $`Q_c(0)=0`$ 与 $`Q_c(\pm1)=\frac34c-1`$，故
```math
\max_{|a|\le1}Q_c(a)=\max\left(0,\frac34c-1\right).
```
当 $`c>\frac43`$ 时，贪心动作从零跳向边缘。预测最优值继续增加，真实奖励却从零降到负一；临界点平局时，本例约定选零。曲线之差不是由预测值直接计算的误差，因为决策先改变了被评价的动作。

对本例加入已观测动作集合约束，或限制到 $`[-0.5,0.5]`$，可以阻止选择边缘；这说明约束在利用哪些支持信息，并不证明所有离线任务都应采用同一限制。函数近似误差被策略利用的机制可参照 [TD3 原论文](https://arxiv.org/pdf/1802.09477)。

## 2. Tanh策略的密度与梯度

常用未约束变量 $`u=\mu+\sigma\xi`$，再令 $`a=c+d\tanh u`$，其中 $`c=\frac{(h+l)}{2}`$、$`d=\frac{(h-l)}{2}>0`$。这个映射在实数到开区间之间可逆，密度需要同时处理非线性压缩和动作单位缩放。直接把高斯样本硬裁剪到边界，得到的分布可能含边界点质量，不再是同一可逆变换密度。

<a id="deeprl-4-detail-6"></a>

### 2.1 从变量替换得到log密度

一维下 $`\frac{da}{du}=d(1-\tanh^2u)`$，因此

```math
\begin{aligned}
&\log\pi(a\mid s)=\log N(u;\mu,\sigma^2)\\
&\quad -\log d-\log(1-\tanh^2u).
\end{aligned}
```

多维逐坐标变换需要对各维修正求和。若动作分布相关，基础高斯也应使用真实联合密度，而非无条件把边缘密度相乘。用于接受、熵或策略梯度的概率对象必须对应实际采样器。裁剪一个看起来很小的 log 项也可能改变 Actor 目标，不能只检查动作合法。

数值上大绝对值的 $`u`$ 会使 tanh 接近一，直接计算一减平方可能下溢。可用等价稳定表达式或合适库变换实现，但应区分数值稳定与改目标。若为避免非有限数直接把动作截到边界再套原式，数学分布已经不同。开发时可在可积分的一维例子检查密度积分，再核对自动微分与固定随机数的有限差分。

<a id="visual-depth-deeprl-04"></a>

### 图解：Tanh 变换下的区间概率与密度

![tanh 加缩放改变动作区间与密度，但保持对应事件概率](images/04-img-tanh-interval-probability.webp)

[打开原图放大](images/04-img-tanh-interval-probability.webp)

取一个与下方训练示例分开的解析分布：$`U\sim N(0,1)`$，执行动作 $`A=2\tanh U`$，动作范围为 $`(-2,2)`$。变换前的事件 $`0.5\le U\le1`$ 的概率为 $`\Phi(1)-\Phi(0.5)\approx0.149882`$。因为 tanh 严格递增，它恰好对应变换后的事件 $`0.924234\le A\le1.523188`$；这两个区间的概率相同。若画密度图，对应积分面积相等，密度高度和区间长度可以不同。

逐点看 $`u=1`$：原高斯密度 $`\varphi(1)\approx0.241971`$，动作 $`a=2\tanh1\approx1.523188`$，局部导数 $`\frac{da}{du}=2(1-\tanh^2 1)\approx0.839949`$。一个很小的输入区间在动作坐标中变窄，为保留质量，密度应除以这个局部宽度因子，得到 $`p_A(a)\approx\frac{0.241971}{0.839949}\approx0.288078`$。这是局部微分关系；不能用这一个导数乘整个 $`[0.5,1]`$ 的宽度，因为导数沿区间变化。

一般公式为 $`p_A(a)=\frac{\varphi(\mathrm{atanh}(\frac a2))}{2[1-(\frac a2)^2]}`$，只在开区间内部取值。数值积分右侧密度在变换后的动作区间上得到同样的 $`0.149882`$，在全部动作区间上积分为一。若漏掉动作尺度二，积分变成二；若只保留尺度而漏掉 tanh 的非线性修正，积分约为 $`0.605706`$，两种错误都不是合法的执行动作概率。原始变量经过 tanh 的密度修正见 [SAC 原论文补充材料附录 C](https://proceedings.mlr.press/v80/haarnoja18b/haarnoja18b-supp.pdf)，本图额外显式加入动作缩放二并逐项计算。

这张图展示可逆光滑变换，不能用于硬裁剪高斯：硬裁剪会把越界概率堆在端点，产生点质量。有限实数经过 tanh 在精确算术下也不会真正到达端点；浮点饱和则需要稳定 log-Jacobian 实现，不能把数值端点当成理论离散质量。密度可以随坐标改变、甚至大于一；事件概率、熵目标和重要性比率仍须使用与实际采样器对应的分布。

### 2.2 实验一：积分归一化与漏项反例

动作范围负二到三，底层高斯均值零点二、标准差零点七。正确密度在该范围积分为一；漏掉常数缩放项后积分为二点五。另一个错误版本漏掉 tanh 导数，积分通常小于一。这些是密度身份检查，不是完整 SAC 训练，使用 SciPy 数值积分核对当前一维目标。

```python
import numpy as np
from scipy.integrate import quad
mu,sd,center,scale=.2,.7,.5,2.5

def base(u):return np.exp(-.5*((u-mu)/sd)**2)/(sd*np.sqrt(2*np.pi))
def density(a,mode='correct'):
    y=(a-center)/scale
    if not -1<y<1:return 0.
    u=np.arctanh(y)
    if mode=='no_scale':return base(u)/(1-y*y)
    if mode=='no_tanh':return base(u)/scale
    return base(u)/(scale*(1-y*y))

values={mode:quad(lambda a:density(a,mode),-2.,3.,epsabs=1e-10)[0]
        for mode in ['correct','no_scale','no_tanh']}
assert abs(values['correct']-1)<1e-8
assert abs(values['no_scale']-2.5)<1e-8
assert 0<values['no_tanh']<1
print('squashed density integrals',values)
```

### 2.3 实验二：重参数Actor梯度不应断在Critic

以下定义一个已知二次价值，而非学习到的 Critic，用来消除价值拟合误差。固定基础噪声样本，对均值和 log 标准差计算 SAC 式 Actor 目标梯度，再以相同噪声做中心差分。log 密度包含两种 Jacobian 修正，动作范围与积分实验相同。梯度正确不代表完整算法已找到全局最优，但它是训练前必须建立的局部证据。

```python
import math
import torch
torch.set_num_threads(1)
torch.manual_seed(402)
dtype=torch.float64
noise=torch.randn(8192,dtype=dtype)
parameter=torch.tensor([.2,-.3],dtype=dtype,requires_grad=True)

def objective(p):
    mean,log_sd=p[0],p[1]
    u=mean+log_sd.exp()*noise
    action=.5+2.5*torch.tanh(u)
    log_base=-.5*noise.square()-log_sd-.5*math.log(2*math.pi)
    log_jac=math.log(2.5)+2*(math.log(2)-u-torch.nn.functional.softplus(-2*u))
    log_prob=log_base-log_jac
    q=-(action-.8).square()
    return (.2*log_prob-q).mean()

loss=objective(parameter);gradient=torch.autograd.grad(loss,parameter)[0]
for j in range(2):
    delta=torch.zeros(2,dtype=dtype);delta[j]=1e-5
    fd=(objective(parameter.detach()+delta)-objective(parameter.detach()-delta))/(2e-5)
    assert torch.allclose(fd,gradient[j],atol=1e-7)
assert torch.isfinite(gradient).all()
print('actor objective/gradient',float(loss.detach()),gradient.tolist())
```

## 3. 双估计最小值与平滑的偏差

取两个 Critic 最小值可以限制某些乐观误差，但并不构成任意状态动作的真实下界。若两个估计都有同一系统性正偏差，最小值仍可高估；若误差独立零均值，最小值反而有负偏。算法设计的作用依赖误差分布、相关性和策略选择，不能只依据“保守”这个名称判断真实保证。

<a id="deeprl-4-detail-10"></a>

### 3.1 高斯误差下的最小值手算

设两个误差边缘标准差都为 $`\sigma`$、均值零、相关系数 $`\rho`$，联合高斯。利用 $`\min(X,Y)=\frac{(X+Y-\vert X-Y\vert )}{2}`$，差值方差为 $`2\sigma^2(1-\rho)`$，得到最小误差均值为 $`-\sigma\sqrt{\frac{(1-\rho)}{\pi}}`$。相关接近一时校正作用变小，两者完全相同就没有双估计优势。这个公式不是学习网络普遍服从高斯的声明，只是一个可精确验证的模型。

目标动作平滑也会改变对象。对真值 $`Q(a)=-(a-a_*)^2`$，零均值噪声在没有动作边界裁剪时有 $`E[Q(a+\epsilon)]=Q(a)-\mathrm{Var}(\epsilon)`$。平滑压低尖峰但也引入曲率相关偏移；在非二次函数或边界截断后需要重新分析。它不是不改变原始 Q 的纯数值技巧。

<a id="deeprl-4-detail-11"></a>

### 3.2 实验三：相关双误差与平滑曲率

程序比较独立误差与相关零点八的误差最小值，再核对二次函数的平滑偏移。所有采样来自人工噪声，没有训练神经网络，因此结果只验证偏差计算。真实 Critic 共享数据、目标和结构，会有复杂相关性，不能把这里的负偏公式当成逐点可信下界。

```python
import numpy as np
rng=np.random.default_rng(403)
n=200000;sd=.4
z=rng.normal(size=(2,n))
for rho in [0.,.8]:
    e1=sd*z[0];e2=sd*(rho*z[0]+np.sqrt(1-rho*rho)*z[1])
    bias=np.minimum(e1,e2).mean();truth=-sd*np.sqrt((1-rho)/np.pi)
    assert abs(bias-truth)<.004
    print('correlation/minimum bias/theory',rho,bias,truth)
epsilon=.1*rng.normal(size=n)
a,star=.2,.4
raw=-(a-star)**2
smoothed=-(a+epsilon-star)**2
assert abs(smoothed.mean()-(raw-.01))<.001
print('quadratic value/smoothed expectation',raw,smoothed.mean())
```

表中的无偏差列使用第 3.1 节推导的解析均值 $`E[\min(Q_1,Q_2)]=-0.4\sqrt{\frac{1-\rho}{\pi}}`$，不是有限训练成绩。独立时约为 $`-0.225676`$，相关 $`0.8`$ 时约为 $`-0.100925`$，与实验三的采样结果相符；完全相关时两估计一致，额外最小化偏差消失。

表的末列另设一个明确对照：两 Critic 都带共同系统偏差 $`b=0.2`$，即 $`Q_i=b+\epsilon_i`$。取最小不会删除这个共同偏差，因为 $`\min(b+\epsilon_1,b+\epsilon_2)=b+\min(\epsilon_1,\epsilon_2)`$。故期望整体上移 $`0.2`$；在 $`\rho=0.8`$ 时，即使已经取小，均值仍为 $`0.099075>0`$。两估计共享同一数据遗漏或表示错误时，这种共同偏差正是需要额外关注的对象。

“均值为负”和“每次估计都是真实下界”仍不同：表中的均值是对给定联合噪声取平均，单次两个噪声同时为正时，最小值一样为正。它也不是置信下界，没有约定覆盖概率。相关性公式只对这里的高斯模型成立；真实网络还会经历 Actor 主动选动作、目标滞后和数据分布变化，不能把本图当成 TD3/SAC 的完整误差保证。

## 4. 固定离线数据限制了什么能被识别

在线经验回放仍可以通过新交互补充证据，离线任务的训练数据固定，策略挑选未见动作后没有自动反馈。相同日志可以与多个环境相容，它们在未覆盖动作上的后果可能完全不同。网络表达越强，只说明可以外推更多函数，不代表数据已经决定哪一个函数是真实环境。可识别性不足不是调更大学习率或多训练几轮能独自解决的问题。

<a id="scientific-plate-04"></a>

![覆盖内估值可核对，未见动作价值无法由日志直接识别](images/04-img-observed-and-unobserved-actions.webp)

[打开原图放大](images/04-img-observed-and-unobserved-actions.webp)

图左表示数据实际覆盖的动作。该范围内可用记录核对估值。图右表示没有记录的动作，模型即使在这里给出很高预测，现有数据也无法确认该预测。专门挑这个峰值的离线策略可能利用的是外推误差。

<a id="sec-1-1"></a>

<a id="deeprl-4-detail-13"></a>

### 4.1 两个数据不可区分的环境

单一状态、两个动作、都返回原状态，日志只记录动作零且奖励零。环境甲的动作一每步奖励一，环境乙每步奖励负一，两者在日志上完全相同。折扣零点九时，甲选择动作一的价值十，乙最优应一直选零、价值零。任何只凭该日志、不引入结构假设的算法，都无法保证同时识别两个环境的最优动作。

可以引入先验、平滑结构、行为约束或额外可验证模型，但那是新增假设或信息。限制策略不离开动作零可避免当前负奖励环境的未知动作风险，也会错过正奖励环境的改进机会。保守方法的取舍就在这里：证据不足时约束行为与期望探索收益并不自动兼容，研究应准确说明保护什么、牺牲什么。

<a id="sec-2-1"></a>

<a id="deeprl-4-detail-14"></a>

### 4.2 支持外误差怎样通过自举返回日志内

更严重的是，未见动作高估不仅影响 Actor，还能通过下一状态最大值污染已见动作目标。假设 Critic 函数族为 $`Q_w(0)=w`$、$`Q_w(1)=w+c`$，其中 $`c>0`$ 是数据未约束的偏移。只用日志零奖励动作零，若备份最大值，精确更新为 $`w_{k+1}=\gamma(w_k+c)`$，不动点为 $`\frac{\gamma c}{(1-\gamma)}`$。

当 $`c=1,\gamma=0.9`$ 时，日志内 Q 趋于九、未见动作 Q 趋于十，数据上的自举残差却趋于零。真实负奖励环境的最优值仍为零。这个反例说明小训练残差可以与严重控制错误共存，目标网络冻结只改变时标，不会凭空补回缺失动作证据。若目标选择只允许日志动作，则递推变为 $`\gamma w`$，日志内值回到零，但未见动作仍未被识别。

<a id="deep-dive-2"></a>

<a id="deeprl-4-detail-15"></a>

### 4.3 实验四：完整有限备份与支持限制

下段执行两套精确冻结目标回归迭代，核对各自不动点，再枚举两个相容环境的真实策略价值。它是一个完整的人工离线备份过程，函数族故意可解析，不是完整 CQL、IQL 或连续 Actor 训练。正是由于没有优化噪声，错误可以明确归因于支持外选择与自举，而非随机数或训练不充分。

```python
import numpy as np
gamma=.9;c=1.
unconstrained=0.;restricted=0.
for _ in range(300):
    unconstrained=gamma*(unconstrained+c)
    restricted=gamma*restricted
q=np.array([unconstrained,unconstrained+c])
assert np.isclose(q[0],9.) and np.isclose(q[1],10.)
assert abs(q[0]-gamma*q.max())<1e-12
assert restricted==0
# Both environments produce identical data for action zero.
for reward_one in [1.,-1.]:
    data_reward_zero=0.
    value_zero=data_reward_zero/(1-gamma)
    value_one=reward_one/(1-gamma)
    optimal=max(value_zero,value_one)
    selected=int(q.argmax())
    deployed=value_one if selected else value_zero
    print('unobserved reward/true optimal/selected value',reward_one,optimal,deployed)
print('offline estimated Q/residual/restricted value',q,
      q[0]-gamma*q.max(),restricted)
```

<a id="sec-6-1"></a>

<a id="deeprl-4-detail-16"></a>

### 4.4 为什么同一Critic自评不能提供独立证据

Actor 已经依据 Critic 挑动作，再用同一个 Critic 报告收益，选择会放大它的乐观区域。双 Critic 也可能共享同一遗漏，因此没有外部反馈时更高估值不证明策略进步。合法离线评价需要支持、模型或其他可检查假设；若允许独立环境交互，应预先固定预算和策略，不把失败交互删掉。支持外未知应保留为未知，而不是用一个网络分数填成事实。

行为约束、保守价值和不显式最大化未见动作的训练有不同机制。比较它们需说明约束强度、数据覆盖、模型假设和最终评价。不能把一种方法在某个固定数据集上较好改写为对所有离线任务安全。信息不足时不存在仅靠算法名称就自动恢复未观测后果的保证。

<a id="deeprl-4-detail-17"></a>

## 5. 在线、离线与复现的证据层次

在线学习评价至少包含训练期间交互成本与冻结策略外部收益，离线学习还需明确数据采集策略、动作单位、终止语义、数据版本及支持范围。日志中的动作被裁剪、重缩放或延迟执行时，行为概率与环境后果可能不再对应原命令。奖励重标注也会改变训练目标，不能只保存一个没有版本的回放数组。

<a id="sec-3"></a>

<a id="deeprl-4-detail-18"></a>

### 5.1 数据与运行状态应能够追溯

记录原始模拟步与控制步关系、并行环境数、动作重复、观察归一化与奖励处理。每次环境交互对应几次参数更新、目标更新的实际时钟以及回放预热，都影响训练过程。相同网络宽度和学习率不意味着相同算法。随机源可区分环境、探索、初始化与回放采样，改变一项不应无声改变其他数据划分或评价样本。

恢复权重仅证明可以加载参数，续训轨迹还可能依赖优化器、回放内容与指针、随机状态、归一化统计和环境状态。若只恢复一部分，应准确称为从该参数重新开始或部分恢复。不能把文件成功读取等同于原训练过程逐步重现。复现的层次需要在交付中明示，而不是让读者猜测哪些状态已经保存。

<a id="sec-6"></a>

<a id="deeprl-4-detail-19"></a>

### 5.2 统计单位与失败运行

多个评价回合主要估计同一冻结策略的环境波动，多个训练种子才包含学习过程变化。独立数据集或环境实例又对应另一层推广。按实际层次汇总与配对，报告所有预设运行和失败，不把最好种子、最高回合或最有利平滑窗口当算法均值。调参和选择也使用资源，应计入共同预算。

原始奖励、训练处理后的奖励、成功率、长度、动作饱和和关键失败事件应分别保留。某个正则目标更好不代表所有外部指标提高；动作更平滑也不自动等于任务更成功。评价需要回到具体部署目标，解释哪些改善、哪些取舍和哪些未识别，而不靠一条总分曲线代替完整证据。

<a id="deeprl-4-detail-20"></a>

## 6. 最大熵目标的变分解释

给定某状态动作值函数 $`Q(a)`$，考虑在规范动作测度下选择分布。设 $`\alpha>0`$，且 $`Z=\int\exp(\frac{Q(a)}{\alpha})da`$ 有限非零。定义 $`\pi_Q(a)=\frac{\exp(\frac{Q(a)}{\alpha})}{Z}`$。展开 KL 可得

```math
E_\pi[Q]+\alpha H(\pi)=\alpha\log Z-\alpha KL(\pi\Vert \pi_Q).
```

因此在支持与积分条件满足、策略族不受额外限制时，最优分布为该 Gibbs 分布。这个恒等式解释软值与熵的联系，不意味着任意高斯 tanh 策略都能精确表示它。神经策略族的表达限制、采样误差与非凸优化都可能造成间隙，不能把形式上的 softmax 最优解当作训练算法已经达到的结果。

<a id="deeprl-4-detail-21"></a>

### 6.1 连续动作下归一化与单位

有限动作求和常自动有限，连续无界动作却不一定。若 Q 在整条实线上恒为零，指数积分发散，不能定义均匀概率密度；有界动作域与适当有界 Q 可使归一化成立。讨论软策略更新前应声明动作空间、测度和积分范围。将离散熵的直觉直接搬到无限连续空间，可能连优化问题是否有解都没有确认。

以离散两动作值零和一、温度一为手算例子，最优概率正比于一和自然常数 e，软值为 $`\log(1+e)`$。原始奖励最大值是一，软值却更高，因为目标加入熵，二者不是同一个效用。连续微分熵还随坐标缩放变化，本章密度的动作缩放常数必须与目标熵协议一致。不同动作单位下的数值不能直接当同一温度意义的排名。

<a id="deeprl-4-detail-22"></a>

### 6.2 软评估与策略改进的条件

对固定随机策略，软 Bellman 评估将下一动作 Q 减温度乘 log 密度再平均。在奖励和相关熵项有适当有界或可积条件时，同一策略的 Q 差只通过下一 Q 传播，所以可建立折扣收缩。改进若在每个状态使期望 Q 加熵不降低，再结合评估单调性，可得到相应软策略改进。这与硬奖励目标改进不同，也不直接证明有限网络的经验更新稳定。

实际 Actor 通常在回放状态分布上优化代理目标，且只做有限梯度步。即使代理平均下降，也可能在某些重要状态变差；新策略访问分布又会改变。若想把它解释成全局性能保证，需要额外的状态覆盖、优化误差和分布变化控制。不能只因为回放来自环境，就把任意经验分布下的 Actor 梯度称原始初始分布收益的精确梯度。

<a id="visual-insight-deeprl-04"></a>
### 深入图解：熵奖励把确定性贪心解变为温度控制的随机策略

![温度上升时，原始奖励降低而包含熵的软效用增大](images/04-img-soft-policy-temperature.webp)

[打开原图放大](images/04-img-soft-policy-temperature.webp)

**更高的软目标，是否意味着原始奖励也更高？** 表把各温度下的最优动作概率与最大软效用并列。两个动作奖励分别为一与零，目标为高奖励动作概率加上温度乘二元熵。写为 $`J(p)=p+\alpha[-p\log p-(1-p)\log(1-p)]`$，对 $`0\lt p\lt 1`$ 求导得 $`J^{\prime}(p)=1+\alpha\log\frac{1-p}{p}`$。当 $`\alpha>0`$，二阶导数为 $`-\frac{\alpha}{p(1-p)}\lt 0`$，因此 $`p^*=\frac{1}{1+e^{-\frac1\alpha}}`$ 是唯一最大值。将三个温度代入最优概率：温度零点二、零点五、一时，约为零点九九三三、零点八八零八、零点七三一一。温度增大后最优策略更分散，目标已不再等于纯奖励最大化。

本例高奖励动作的奖励为一，另一个为零。因此最优概率一列也等于原始期望奖励，依次下降。最后一列再加上各温度的熵奖励，数值反而上升。每个温度对应不同效用函数。比较控制表现时，应回到共同的原始奖励与部署规则。

图在单状态精确模型下成立，不说明任意训练过程都会达到该解，也不能将离线数据不支持的随机动作视为自动安全。

<a id="deeprl-4-detail-23"></a>

## 7. 离线方法怎样限制未支持的改进

离线问题的核心不是有没有回放缓冲，而是能否继续查询环境。固定数据下，约束策略、改变价值目标或改用数据内备份都在加入归纳偏好。它们能在具体假设下有用，但也会牺牲某些未观测改进空间。研究比较应明说哪些假设来自环境结构、哪些来自数据、哪些是人为保守程度，而不是把所有不确定性藏进一个正则系数。

<a id="deeprl-4-detail-24"></a>

### 7.1 一个可推导的保守相对惩罚

有限动作下可以考虑某类形如 $`\lambda E_{s\sim D}[\log\sum_a e^{Q(s,a)}-E_{a\sim D(\cdot\mid s)}Q(s,a)]`$ 的惩罚，再与 Bellman 拟合结合。对各动作 Q 求导，得到温度为一的 softmax 概率减数据动作频率。因此高于行为支持的相对高估会受到压力，常见数据动作也受到相应补偿。不同算法版本的采样、权重和目标具体不同，这个形式用于解释机制，而非宣称复现某一完整实现。

若只有动作零被记录，两动作项化为 $`\log(1+e^{Q_1-Q_0})`$。它对共同平移两个 Q 完全不变，所以不能仅凭该惩罚证明绝对值已低于真值。固定数据的 Bellman 项、采样分布、系数和理论假设共同决定最终性质。保守方法中的下界结论若存在，也有具体对象与条件，不等于每个未支持动作都被自动准确估计。

连续动作中，离散 log-sum-exp 需要变成积分或按明确提议分布近似，提议密度和支持又影响估计。只随机抽少量动作，不能假定已经找到所有高估区域。若用重要性修正，应记录真实采样机制；若只做启发近似，应准确命名。更复杂的正则目标不会消除最初的可识别性反例，它是在不确定空间中选择一种受约束解。

<a id="deeprl-4-detail-25"></a>

### 7.2 数据内值拟合与行为加权

另一类思路不在价值拟合时显式最大化未见动作。给定数据动作 Q，可通过不对称平方损失拟合状态值，例如 $`L_\tau(u)=\vert \tau-\mathbf1(u\lt 0)\vert u^2`$、$`u=Q(s,a)-V(s)`$。当 $`\tau`$ 大于二分之一，较大的正残差获得更高权重，状态值偏向数据支持内较高价值。它仍依赖 Q 本身是否可靠和数据覆盖，不能直接叫成所有动作的真实最大值。

再用与数据优势有关的权重拟合行为动作，可以偏向较好日志行为，同时避免任意 Actor 在训练目标里搜索所有未见动作。权重温度、截断和策略族改变选择程度；连续策略拟合仍可能在样本间或尾部外推。对本章只含一个动作的数据，这类方法不会凭空发现另一个动作真实奖励。这既是约束的保护作用，也是改进空间的边界。

<a id="deeprl-4-detail-26"></a>

## 8. 支持条件与外部评价的数学边界

设非负误差函数为 $`\ell(s,a)`$，部署访问分布为 $`d_t`$，日志分布为 $`d_b`$。若存在有限常数 C 使 $`d_t\le C d_b`$，则积分直接给出 $`E_{d_t}\ell\le C E_{d_b}\ell`$。这个简单式说明日志误差要控制部署误差，必须限制权重变化。日志上很小的平均误差，如果部署集中到极少覆盖区域，仍可能变成很大错误；支持不重合时更没有有限 C 可直接使用。

<a id="deeprl-4-detail-27"></a>

### 8.1 状态覆盖不等于状态动作覆盖

某状态在日志里频繁出现，不表示每个动作的后果都被观察。对连续动作，仅仅落在合法区间也不表示有足够邻近数据。平滑性或动力学结构可以帮助从相近动作推断，但这是额外模型条件。评价应检查联合支持、关键转移和目标访问，而不是只报告状态数或样本总量。大量重复同一动作不能替代新动作的信息。

还有一个细节：确定性策略在某状态只给单点动作，而连续行为具有普通密度，二者在动作测度上可能不满足普通绝对连续比率条件。不能直接把确定性策略写成一个普通有限密度比来做重要性采样。可以研究带噪声目标策略、结构模型或其他估计器，但需重新说明条件。神经网络能给那个动作一个数值，不代表离线评价公式已经合法。

![同一行为日志可以对应两个不同的目标策略回报](images/04-img-action-without-behavior-support.webp)

[打开原图放大](images/04-img-action-without-behavior-support.webp)

用一步决策把支持条件单独拿出来看：行为策略只选择 A，目标策略对 A、B 各给一半概率，A 的奖励恒为零。无论未观察到的 B 奖励为 $`+1`$ 还是 $`-1`$，全部日志都一模一样；目标策略的期望奖励却分别是 $`+0.5`$ 与 $`-0.5`$。状态已经完全覆盖，缺少的仍是状态内的动作证据。

对日志中可见的 A，重要性比为 $`\frac{0.5}{1}=0.5`$；对目标要求的 B，行为概率为零，$`\frac{\pi(B)}{\beta(B)}`$ 不存在可用的有限权重。只对出现过的记录加权，会漏掉整项未知贡献，而不是得到可靠的零估计。这个离散一步反例说明绝对连续性为何必要；连续动作和长轨迹还要处理密度、访问测度与比率方差，不能仅检查某些动作数值“看起来很接近”。

<a id="deeprl-4-detail-28"></a>

### 8.2 已知模型实验与未知环境结论

本章人工单状态模型明确知道所有动作真值，所以可以独立评估错误策略，展示数据自评与真实值的差异。真实离线任务往往没有这项信息，此时结论应根据支持与假设限定，不能把仿真精确求值直接当现实真值。模型也可能错设，更多模拟次数只会更精确地估计错误模型。计算误差小和环境识别正确依然是两项独立验收。

如果之后允许在线确认，应先冻结策略和选择规则，按预设预算记录成功、失败和成本。若不能确认，则报告无法由当前日志识别的部分。研究的价值不在把所有未知填成一个高收益，而在说明证据在哪些条件下支持改进、哪些条件一变就需要新数据或新假设。这个判断也决定一个离线方法适合解决什么范围的问题。

## 9. DDPG与TD3的完整梯度责任

<a id="deeprl-4-detail-30"></a>

### 9.1 DDPG的一步目标和Actor代理

DDPG 的一个标准形式是 $`y=r+\gamma bQ_{\bar\phi}(s',\mu_{\bar\theta}(s'))`$，其中目标 Actor 与目标 Critic 都缓慢变化，整个目标停止梯度。当前 Critic 用回放实际执行动作拟合 $`Q_\phi(s,a)`$，Actor 则最大化回放状态上的 $`Q_\phi(s,\mu_\theta(s))`$。前者需要当前动作标签正确，后者需要保留 Critic 对动作输入的导数，二者不能共用一个随意冻结所有前向的逻辑。

写成梯度，Actor 代理导数为回放平均的 $`\nabla_\theta\mu_\theta(s)\nabla_aQ_\phi(s,a)`$。这对固定当前 Critic 与状态分布是精确链式求导，但不自动等于任意回放分布下原始起点收益的精确梯度。真实策略梯度定理涉及相应访问测度与动作价值及正则条件，工程近似需要承认这些差异。第二章已给出解析局部核对，本章强调它在完整离策略目标中的位置。

行为通常在 Actor 动作上加入探索扰动，再按真实边界执行；目标 Actor 产生备份动作，不应自动使用同一探索噪声。回放应存与转移对应的实际执行动作。若安全层替换了请求，仍用原请求训练 Critic，学到的条件后果会错位。目标网络、经验回放和算法名称都不能修复动作语义不一致。

<a id="deeprl-4-detail-31"></a>

### 9.2 TD3为何分开三个修改

双 Critic 最小值限制某些乐观误差，延迟 Actor 更新让价值先获得更多拟合机会，目标动作平滑降低备份对狭窄尖峰的敏感性。三者可以共同有效，但各自作用不同。只删除其中一项的消融，应同时检查其改变的更新次数与计算预算，否则观察到的变化可能混合机制和资源差异。

Actor 延迟频率通常按 Critic 梯度次数计数，目标网络也常在这些延迟步骤更新。若另一个实现每环境步都软更新，即使相同系数与网络，也不是相同时标。多个并行环境会进一步改变每环境转移对应的更新量。复现应写出计数关系，不只列一个 policy_delay 数字。

两个 Critic 可能共享数据、结构和目标，因此估计相关。最小值不是置信区间下界，没有自动覆盖概率，也不保证每个动作都低于真值。若共同偏差很大，取小仍错。讨论“保守”时应明确是数值较低、特定噪声模型中的负偏，还是具有证明条件的性能下界，不能混用。

<a id="deeprl-4-detail-32"></a>

### 9.3 平滑的二阶展开与边界影响

在动作内部、价值足够光滑且小噪声均值零时，Taylor 展开给 $`E[Q(a+\epsilon)]\approx Q(a)+\tfrac12\mathrm{tr}(\nabla_a^2Q(a)\Sigma)`$，其中 $`\Sigma`$ 为噪声协方差。凹的尖峰附近 Hessian 负，平滑值降低；凸区域也可能升高。平滑改变了备份对象，不是无损地消除噪声。

动作边界裁剪会使扰动均值不再为零，增加一阶梯度项，二阶近似也可能失准。裁剪目标噪声与裁剪最终动作是两个操作，应按顺序定义。第三节二次函数实验刻意没有动作边界，才能精确隔离方差项；不能把其负零点零一偏移无条件搬到有边界多维控制。

<a id="deeprl-4-detail-33"></a>

## 10. 最大熵更新与温度的研究细节

<a id="deeprl-4-detail-34"></a>

### 10.1 Actor重参数梯度的两条路径

随机策略 Actor 目标包含负价值与 log 密度。动作 $`a_\theta`$ 同时影响 Critic 输入和变换后 log 密度，基础分布均值与尺度也显式进入密度。求导时不能只保留其中一条路径，否则得到另一种估计器。固定基础噪声的有限差分能核对整个采样代理导数，但不等于对所有环境与策略分布完成无偏证明。

第二个实验固定 8192 个噪声，因此自动微分与差分面对同一个有限目标，避免重新抽样噪声掩盖导数错误。若每次差分重新抽样，两个目标值差可能主要来自 Monte Carlo 波动，不能据此判断链式法则失效。解析局部验证应控制随机耦合，再在训练中研究统计方差。

Critic 回归目标下一动作通常也来自当前随机策略，但整个目标无梯度，不因此更新 Actor。Actor 有自己的损失与更新时刻，温度又可能有独立优化器。三个优化对象应分别管理参数权限和清梯度，避免一个损失意外更新另一模块。一个完整训练步骤应能画出每条允许和禁止的梯度路径。

<a id="deeprl-4-detail-35"></a>

### 10.2 目标熵约束与温度方向

若希望策略熵至少达到给定目标 $`H_*`$，温度可作为对应对偶权重。固定当前策略时，一类温度目标为 $`L(\alpha)=\alpha(E[-\log\pi]-H_*)`$，最小化时熵低于目标会推动温度增大，熵高于目标会推动它减小。这个方向检查比只照抄一个负号更有用。

用 $`\alpha=\exp\eta`$ 保证正值，严格换元的导数包含乘子 $`\alpha`$。一些常见实现使用对 $`\eta`$ 线性的代理目标，保留相同零点但改变更新尺度；不应把两种参数化梯度逐项说成完全相同。log 密度通常在温度更新中停止对 Actor 求导，以免同时改变被测约束对象。固定温度与自适应温度是不同实验配置。

目标熵数值还依赖动作坐标、维数与密度定义。不同动作缩放下漏掉 Jacobian 常数，可能让温度追踪另一约束。若需要坐标不变的解释，可以明确参考测度或在标准化动作空间定义熵，再与环境映射一致。不能只因为某个默认目标在一个基准有效，就赋予它所有单位下相同物理含义。

<a id="deeprl-4-detail-36"></a>

### 10.3 软值与原始收益分别评价

最大熵目标奖励多样化行为，软值可能高于硬最大原始 Q，这不意味着系统凭空获得额外任务奖励。评价随机策略与均值动作也对应不同执行规则，不能只用一个最有利回合比较。应共同报告外部原始收益、成功或约束指标，并说明训练熵奖励是否进入日志曲线。

若回合长度可变，每步熵项还可能影响继续还是结束的偏好。动作单位造成的熵常数，在固定长度下只增加共同项，变长任务中却可能改变累计量。需要统一目标定义和终止处理，不能把所有熵常数都当无害。数值实现中的小项也可能承载任务语义。

<a id="deeprl-4-detail-37"></a>

## 11. 离线支持与可识别性的完整推理

<a id="deeprl-4-detail-38"></a>

### 11.1 不可区分日志构成信息论反例

第四节两个环境在所有记录动作上完全相同，因此产生任意长度同类日志的分布也相同。任何只接收这些日志的算法，在两个环境中输出分布相同；但二者最佳未见动作相反，所以无法同时保证识别最优。这不是当前网络训练失败，而是可用信息不足。增加优化轮数不会改变算法输入中没有证据的事实。

如果算法采用随机策略，也不能消除该限制。给未见动作正概率，在负环境承担损失；完全不选它，在正环境错过提升。可以根据先验或保守偏好作选择，但那属于额外假设或风险权衡。结论应说明相对行为策略保护、最坏环境收益或期望先验收益，不能把几种不同保证混成一句安全改进。

<a id="deeprl-4-detail-39"></a>

### 11.2 自举污染为什么跨回数据内

函数族 $`Q_w=[w,w+1]`$ 的未见偏移不受日志约束，最大备份却每次利用它，形成 $`w_{k+1}=\gamma(w_k+1)`$。固定点有限并且训练残差趋零，说明这里不是数值发散，而是稳定地收敛到错误控制对象。目标网络只是让标签阶段固定，不能阻止未识别偏移经备份返回已见坐标。

若把备份动作限制在日志内，已见坐标恢复真实零值，但未见坐标仍可能受函数族偏移影响。只修改备份不等于最终 Actor 自动遵守支持；部署也应采用相应约束或明确风险。训练目标和策略选择都要与方法声称的保护一致，不能一处保守、另一处又无约束取最大。

<a id="deeprl-4-detail-40"></a>

### 11.3 连续支持需要结构而不只是邻近

连续行为密度在一个区间内正，并不意味着有限数据能准确评价每个动作。需要动作平滑性、函数类约束、覆盖量或模型结构来把邻近证据转成新动作推断。若允许任意陡峭函数，一个狭窄未采区域可以隐藏完全不同收益。合法动作域与统计支持、有限样本密度是三个不同概念。

确定性部署在单点取动作还使普通密度比条件更加微妙。给目标加入少量噪声可得到另一随机策略评价问题，但不能自动认为其值等于原确定性策略；需要价值关于动作的连续性和噪声趋零等条件。模型评价也可以绕开显式比率，却引入动力学或价值模型正确性假设。没有一种估计器能凭名称消除最初信息不足。

## 12. 综合验收：公式、数据和评价同时成立

<a id="deeprl-4-detail-42"></a>

### 12.1 按模块列出实际目标

先写 Critic 标签：下一动作来自目标确定性 Actor、当前随机策略还是数据动作；价值取一个目标、两个最小值还是软值；熵项符号和温度如何定义；真正终止如何清尾。再写 Actor 目标与温度目标，标出每个模块允许梯度和实际优化器。公式明确后，才有资格说实现了某个具体变体。

然后写行为执行：内部动作怎样映射到物理范围，噪声加在哪里，是否经过裁剪或安全替换，回放存哪个动作。最后写评价规则：冻结什么、执行均值还是采样、用原始还是处理后奖励、起点和动力学如何选择。三层若不一致，训练分数可能对应另一个系统，不能仅凭网络结构相同称为复现。

<a id="deeprl-4-detail-43"></a>

### 12.2 用已知模型建立局部证据

在完整训练前，用人工 Critic 验证 Actor 链式梯度，用一维积分验证压缩策略密度，用手算目标验证熵符号与终止，用不可区分环境验证离线支持限制。每个检查针对一个独立错误来源。通过它们不证明大任务成功，但能防止把基础实现错误包装成新算法现象。

当前四段代码均已实跑，依次覆盖密度、Actor 梯度、双估计与平滑、离线备份。没有重新安装环境或下载数据，也没有运行完整 SAC 或 TD3 机器人训练。正文后续研究方案应保持建议语气，不把尚未执行的计划写成已经验证的结果。证据层次清楚，比罗列更多算法名更有价值。

## 13. 可独立重建的进阶研究推导

<a id="deeprl-4-detail-62"></a>

### 13.1 expectile的一阶条件与两点手算

令随机数据动作值为 $`X`$，先设 $`E[X^2]\lt \infty`$、$`0\lt \tau\lt 1`$。状态值 $`v`$ 最小化不对称平方风险 $`L_\tau(v)=E[\tau(X-v)_+^2+(1-\tau)(v-X)_+^2]`$。二阶矩保证风险有限，两个权重均为正保证目标对标量 $`v`$ 强凸，强凸参数至少为 $`2\min(\tau,1-\tau)`$，因而最优点唯一。分别对残差正负区域求导，在残差为零处两侧导数同为零，得到

```math
\tau E[(X-v)_+]=(1-\tau)E[(v-X)_+].
```

这里的一阶条件也可独立在一阶矩有限时讨论，但若二阶矩无限，原始不对称平方风险对所有有限 $`v`$ 都可能为无穷，此时不能直接用“最小化有限平方风险”来解释它；需先定义有限风险差等扩展目标。边界 $`\tau=0`$ 或一也失去上述强凸性，不能照搬内部参数的唯一性结论。

它平衡的是上下残差的加权平均，不是某个固定分位概率，因此 expectile 与 quantile 不能混称。平方尾部幅度会影响结果，极端 Q 误差也可能显著拉动拟合。若 Q 本身不可靠，偏向高值并不自动意味着偏向真实好动作。

取数据 Q 以零点八概率为零、零点二概率为二。普通平方对应均值零点四；取 $`\tau=0.8`$ 时，方程为 $`0.8\times0.2(2-v)=0.2\times0.8v`$，解 v 等于一；取零点九时解为十八除以十三，仍小于二。这个例子显示更高不对称权重如何偏向数据内高值，却没有变成所有动作硬最大。若数据从未出现值二的动作，改变权重也不能凭空恢复它。

<a id="visual-iql-action-outcome-separation"></a>

### 机制算例：先平均环境随机性，再强调较好的数据动作

IQL 的两层拟合不能合并成“对任何 TD 标签都取上 expectile”。随机性可能来自**选择不同动作**，也可能来自**同一个动作碰巧得到不同结果**。前者是数据内行动选择的问题，后者在当前期望回报目标中仍应取条件均值。[IQL 原论文第 4.2 节、式 5–6](https://arxiv.org/html/2110.06169)正是用单独的状态值拟合来区分这两层。

![动作 A 的平均奖励较高，动作 B 的少数幸运结果更大](images/04-img-action-mean-versus-lucky-outcome.webp)

[打开原图放大](images/04-img-action-mean-versus-lucky-outcome.webp)

构造一个单步真正终止的状态。动作 A 确定奖励 $`1.5`$；动作 B 以 $`0.9`$ 概率奖励零，以 $`0.1`$ 概率奖励十。行为数据充分覆盖两动作，且各选一半。这里假定总体分布已知、每个动作可以用独立标量精确拟合，暂时消除采样误差、共享参数与自举误差。因此平方 Q 回归得到

```math
\begin{aligned}
&Q(A)=1.5,\\
&\quad Q(B)=0.9\times0+0.1\times10=1.
\end{aligned}
```

若错误地对每个动作的随机奖励直接做 $`\tau=0.9`$ expectile 回归，A 仍为 $`1.5`$，B 却在 $`0\lt v\lt 10`$ 内满足

```math
0.9\times0.1(10-v)=0.1\times0.9v,
\qquad v=5.
```

于是它把平均收益更低的 B 排到前面。表中 A、B 是两个独立的离散动作。问题不在未见动作：即使两动作都有充分数据，直接强调 B 的幸运结果仍改变了统计目标。

正确分层中，先保留上面的两个**条件均值 Q**，再对数据动作所诱导的二点分布 $`P(Q=1)=P(Q=1.5)=\frac12`$ 拟合上 expectile。其状态值满足

```math
\begin{aligned}
&0.9\times\frac12(1.5-V)=0.1\times\frac12(V-1),\\
&\quad V=1.45.
\end{aligned}
```

它位于数据动作均值一与一点五之间，强调较好的 A；没有把偶发奖励十当成某个动作的期望价值。若将两动作的原始奖励混在一起直接取同级 expectile，分布变成 $`P(0)=0.45,P(1.5)=0.5,P(10)=0.05`$，解反而为 $`3.75`$，超过这里所有动作的真实均值。两种运算次序显然不交换。

这个一次决策例子只核对“哪种随机性在哪一层处理”，不是完整 IQL 训练实验。长程算法还要通过平方 Q 备份传播下一状态值、使用数据支持与合适函数近似，并另行提取和评价策略。已有条件均值 Q 不可靠时，上 expectile 也会强调错误高值；分层定义避免一种幸运结果偏好，不能替代覆盖、拟合与独立评价。

<a id="deeprl-4-detail-63"></a>

### 13.2 优势加权行为拟合的分布解释

在有限动作、行为分布 $`\beta`$ 具有给定支持的条件下，最大化 $`E_\pi[A]-T KL(\pi\Vert \beta)`$，可以用拉格朗日乘子得到 $`\pi(a)\propto\beta(a)\exp(\frac{A(a)}{T})`$。这个指数倾斜分布保留行为零概率动作的零支持，同时偏向较高优势。温度控制选择强度，优势误差也会被指数放大，所以截断和数值稳定有实际意义。

对数据动作做带指数权重的对数似然拟合，可以把它解释为拟合这种数据内倾斜分布，但有限策略族、估计权重和连续密度会带来近似。行为克隆式损失本身未必硬限制策略在全部连续样本间的输出支持，不能把分布理想式当作工程 Actor 逐点保证。应检查执行动作和日志覆盖，而不是只看加权似然下降。

KL 方向也有区别。$`KL(\pi\Vert \beta)`$ 在目标给行为零概率区域质量时可发散，具有支持限制；常见数据似然与反向方向的关系不同，允许模型在未采区域分配额外密度。约束形式、策略族和数据近似共同决定实际保护。只说用了 KL 或行为克隆，不足以判断离线支持风险已经消失。

<a id="deeprl-4-detail-64"></a>

### 13.3 不可识别环境中的最坏遗憾

在单状态相容环境例子里，令策略每步以概率 p 选择未见动作一。正奖励环境的策略值为十乘 p，最优十，遗憾为十乘一减 p；负奖励环境策略值为负十乘 p，最优零，遗憾为十乘 p。最坏遗憾是两者最大值，最小化时 p 为二分之一，仍有五的不可消除遗憾。

这个推导把信息不足从口头警告变成定量取舍。完全保守选零在负环境无损，却在正环境错过十；完全冒险相反。随机化平衡两者，也不能达到同时最优。若引入关于环境的先验，可以优化先验平均遗憾，但结论依赖先验。新增数据能区分两个环境时，信息边界才真正改变。

<a id="deeprl-4-detail-65"></a>

### 13.4 数据支持与性能证据的研究矩阵

可构造覆盖完整、缺少部分动作、动作邻域稀疏和机制漂移四类数据，并固定同一真实环境。先测日志内拟合，再测完整模型价值误差，最后测冻结策略外部收益。加入行为约束、保守惩罚或数据内备份时，分别记录牺牲了哪些潜在改进、减少了哪些错误。这样可以检验机制，而不是只在一个有利日志上比较最高分。

若研究连续动作，可选择已知平滑二次真值与窄区数据，再增加数据外尖峰近似，控制平滑常数与覆盖范围。若研究 CQL 式相对项，可独立检查共同平移不变性和各动作梯度。若研究 expectile，可先用两点分布核对一阶条件。局部解析实验与端到端训练应分开报告，避免把一个损失性质当作完整算法性能保证。

<a id="deeprl-4-detail-70"></a>

## 14. 本章已验证结果与尚未验证范围

密度积分实验正确值约一，漏尺度约二点五，漏 tanh 导数约零点七一六五；固定噪声 Actor 目标约一点四五一八，两个参数梯度约负零点二五三三和二点零零五九，有限差分一致。双估计误差独立时最小均值约负零点二二六二，相关零点八时约负零点一零一九，均接近解析公式；二次动作平滑也出现预期方差偏移。

离线单状态备份得到估计九和十、日志残差接近零，但两个相容环境的真实部署值分别正十与负十。限制数据内备份恢复已见值零，却没有识别未见动作。四项结果分别验证概率、局部梯度、偏差机制和信息限制，不构成完整连续控制基准复现。清楚保留这种证据边界，才能把更多内容转化为扎实知识。

<a id="deeprl-4-detail-71"></a>

### 14.1 二次Q对应的Gibbs分布

若动作无界且 $`Q(a)=-\frac{(a-m)^2}{(2s^2)}`$，温度正值时 Gibbs 分布恰为均值 m、方差 $`\alpha s^2`$ 的高斯，归一化常数有限。若动作被限制到区间，最优分布是相应截断高斯，而不是简单把越界样本裁到边界，也一般不等于某个 tanh 高斯。这个例子把变分最优、策略族表达与采样器三个对象分开。

温度增大使该特定二次例子的分布更宽，但在有界、非二次或多峰 Q 中，变化可能更复杂。神经 Actor 只能在给定函数族里近似目标分布，局部目标下降不意味着已经精确达到 Gibbs 解。可以用一维数值积分和 KL 估计研究这种近似误差，但那是额外实验，不应从当前固定梯度核对自动推断。

<a id="deeprl-4-detail-72"></a>

### 14.2 相对保守项的曲率与局限

有限动作 log-sum-exp 的 Hessian 是 softmax 概率的协方差矩阵，因此对 Q 向量是半正定；数据动作线性项不改变曲率。共同平移方向对应零曲率，与前述平移不变性一致。这可以帮助理解该相对正则在固定状态 Q 坐标上的凸结构，但神经参数化后目标通常不再因此成为全局凸问题，自举标签变化又增加动态耦合。

如果只优化相对惩罚而没有合理 Bellman 锚定，整体价值尺度仍未被确定，未见动作被压低也不代表已见价值正确。不同正则系数改变保守与拟合的取舍，需要开发与独立评价。把局部凸性质、经验稳定和完整策略保证分别陈述，能避免一个正确数学片段被扩大成不存在的全面结论。

<a id="deeprl-4-detail-73"></a>

### 14.3 连续保守积分的抽样误差

若用提议密度 q 估计 $`Z=\int e^{Q(a)}da`$，在支持覆盖和可积条件下，样本平均 $`\frac{e^{Q(a)}}{q(a)}`$ 可以无偏估计 Z。但再对这个平均取对数，一般不再无偏估计 logZ，Jensen 不等式显示期望可能偏低。因而一段看似正确的重要性采样代码，也不能自动宣称完整 log 积分正则无偏。梯度中出现比值时还需另行分析有限样本偏差。

若提议分布漏掉高值区域，或者权重极端集中，有限样本近似可能严重低估惩罚，未能压制最危险的外推尖峰。可以扩大提议混合、监测权重和覆盖，并在一维已知函数上先验证积分；每项都增加预算或假设。这个细节连接了动作支持、保守正则和数值复现，说明离线方法不只是换一个损失名称，还必须明确积分近似究竟看到了哪些动作。

这些条件共同决定结果的含义。保留可验证假设、实际运行证据和未识别部分，才能让连续控制与离线学习资料既深入，也保持清楚可靠。
