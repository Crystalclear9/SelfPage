## 1. 价值学习必须先回答“谁的价值”

强化学习里的价值不是某个状态天然携带的分数。它取决于环境、奖励、折扣、终止规则以及此后采取的策略。一个靠近危险边界的状态，对始终谨慎的策略可能很好，对持续随机探索的策略却可能很差。学习算法如果没有说明目标策略，数值即使收敛，也很难被准确解释。蒙特卡洛、时序差分、SARSA 和 Q-learning 的区别，首先在于它们估计哪个对象以及怎样利用已有估计。

本章以有限状态、有限动作的马尔可夫决策过程为基础，先建立可精确求解的价值参照，再推导采样更新。表格情形可以讨论比较清楚的收敛条件；一旦加入函数近似、离策略数据与自举，原有结论不能原封不动地迁移。完整理解需要同时掌握 Bellman 算子、随机估计、访问分布和实际代码，而不是只记四条更新公式。

<a id="sec-1-1"></a>

<a id="value-foundation-2"></a>

### 1.1 状态、动作与奖励的时间约定

时刻 $t$ 先观察状态 $S_t$，选择动作 $A_t$，随后收到奖励 $R_{t+1}$ 和下一状态 $S_{t+1}$。策略 $\pi(a\mid s)$ 给出动作条件概率，环境核给出奖励与下一状态的联合分布。马尔可夫假设要求当前状态足以描述未来条件分布；若观测遗漏重要历史，相同观测可能对应不同真实状态，普通表格价值的解释便需要调整。

折扣回报记为 $G_t=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}$，其中本章继续任务采用 $0\le\gamma<1$ 并假设奖励有界或满足足够可积条件。回合任务也可以在真正终止处截断求和。奖励发生在动作之后，所以第一项没有折扣；把所有奖励都多乘一次折扣会改变价值尺度与比较结果。代码应明确时间下标，而不是依靠变量名猜测。

<a id="value-foundation-3"></a>

### 1.2 状态价值与动作价值

状态价值 $v_\pi(s)=E_\pi[G_t\mid S_t=s]$，动作价值 $q_\pi(s,a)=E_\pi[G_t\mid S_t=s,A_t=a]$。动作价值只固定当前动作，此后仍遵从目标策略。二者满足 $v_\pi(s)=\sum_a\pi(a\mid s)q_\pi(s,a)$。若把一次动作固定后未来也永远固定为同一动作，得到的是另一个策略对象，不能混用。

最优动作价值 $q_*$ 是所有允许策略中的最大期望回报，对应 Bellman 最优方程。它不表示有限训练行为的实际平均回报，尤其当行为仍包含探索时。训练中的奖励曲线与最终贪心策略评价需要分别报告，才能理解算法到底在学习、执行与评价什么。

## 2. 从回报递归到 Bellman 方程

<a id="value-foundation-5"></a>

### 2.1 固定策略的线性方程

回报满足 $G_t=R_{t+1}+\gamma G_{t+1}$。在固定策略下取条件期望，得到 $v_\pi=r_\pi+\gamma P_\pi v_\pi$。这里 $r_\pi$ 是期望即时奖励向量，$P_\pi$ 是策略诱导的状态转移矩阵。有限继续任务中，折扣小于一使 $I-\gamma P_\pi$ 可逆，价值可以写为 $(I-\gamma P_\pi)^{-1}r_\pi$。

这个表达不是要求实际学习必须知道模型，而是提供一个精确参照。无模型算法通过样本近似同一对象。人工小问题应尽量先求出真实价值，再比较学习误差，否则损失下降和策略改善都缺乏可校验基准。矩阵求解还可以发现奖励或终止索引错误，比只看轨迹动画更可靠。

<a id="value-foundation-6"></a>

### 2.2 收缩与唯一不动点

定义策略 Bellman 算子 $T_\pi v=r_\pi+\gamma P_\pi v$。在最大范数下，两个输入的输出差不超过 $\gamma$ 倍输入差，因为转移矩阵每行是概率加权平均。于是当折扣小于一时它是收缩，具有唯一不动点。同步动态规划反复应用这个算子便收敛到该价值。

最优动作价值算子把下一动作期望换成最大值。利用最大值函数的非扩张性，也能证明相应折扣收缩。这个算子性质是表格 Q-learning 收敛分析的重要基础，但它并不自动证明有噪声、异步、有限数据的每种实现都收敛，更不涵盖任意神经网络参数化。还需要访问覆盖、步长和噪声控制等条件。

<a id="value-foundation-7"></a>

### 2.3 终止与外部截断

真正终止表示任务定义中未来回报为零，目标中不再加尾部价值。外部截断只是训练或采样预算耗尽，任务本身可能还会继续，通常仍应对最后状态自举。若把两者合成一个标志并一律清零，会系统性低估接近截断边界的价值。反过来，对真正终止仍加价值，会引入不存在的未来收益。

也可以把有限时域作为任务本身，此时剩余时间应进入状态，价值随时间变化。若环境每一百步必须结束且这正是任务规则，那么时间耗尽可以是终止；若只是为了方便训练临时停止，则是截断。判断依据来自任务语义，不是接口变量恰好叫哪个名字。

## 3. 蒙特卡洛预测：等待完整回报

<a id="value-foundation-9"></a>

### 3.1 首次访问与每次访问

固定策略收集完整回合后，可以用实际回报更新价值。首次访问 MC 每个回合只用某状态第一次出现的回报，每次访问 MC 使用该回合中每次出现的回报。两者都在适当访问与可积条件下有一致性讨论，但同一回合内多次回报通常相关，不能把它们简单视为独立样本来计算标准误。

样本均值更新写成 $V(s)\leftarrow V(s)+[G-V(s)]/N(s)$，也可以使用一般步长。常数步长保留对近期数据的敏感性，适合非平稳情形或追踪，但通常不会收敛到单个无噪声常数。递减步长则有利于稳定估计固定对象，代价是对变化反应变慢。选择应与任务是否平稳一致，而不是默认某个学习率永远正确。

<a id="value-foundation-10"></a>

### 3.2 MC 的无偏需要哪些条件

在固定策略、给定起始状态以及完整回报可观测的条件下，回报样本的条件期望就是相应价值。若用外部截断后的有限和冒充完整回报，会产生尾部偏差；若策略在数据收集过程中变化，所有回报不再来自同一个固定策略对象。初次访问的停止时刻与后续轨迹处理也应符合所声明协议。

还要区分单次完整回报的无偏性与“把所有访问回报合并后取平均”这一随机比值估计器的有限样本无偏性。考虑唯一非终止状态 $s$：每步奖励一，以二分之一概率继续留在 $s$，否则终止，折扣为一。一次回合长度 $T$ 服从参数二分之一的几何分布，$V(s)=E[T]=2$。首次访问估计就是 $T$，期望为二；但只采这一回合时，每次访问平均为 $[T+(T-1)+\cdots+1]/T=(T+1)/2$，期望仅一点五。

这个偏差不与每次访问 MC 的一致性矛盾。独立采 $K$ 个完整回合后，合并估计是 $\sum_iT_i(T_i+1)/(2\sum_iT_i)$；回合级大数定律给极限 $E[T(T+1)/2]/E[T]=4/2=2$。有限回合的随机分母与分子相关，不能直接把两者期望相除宣称无偏。若计算不确定性，也应以完整回合作为独立单位，而不是把同回合的所有访问当独立。

因此“MC 无偏”不等于任意 MC 代码都没有偏差，也不等于有限样本均方误差最小。长回合奖励噪声和稀有高回报可能造成很大方差，有限预算下估计非常不稳定。判断方法需要同时考虑偏差、方差、延迟、数据依赖和实际需要，而不是用一个标签直接排序。

<a id="value-foundation-11"></a>

### 3.3 增量实现与回报递推

从回合末尾向前递推 $G\leftarrow R+\gamma G$，能够一次计算所有时间的回报。若回合真正终止，初始尾部为零；若是截断并采用自举目标，尾部应从当前价值估计开始，这已经是带自举的有限步方法，而非纯粹完整 MC。实现时应准确命名，避免同一函数随标志变化却仍统一叫无偏 MC。

如果状态在回合中重复，首次访问判断需要对应时间顺序。逆序计算回报时简单用一个已见集合保留第一次遇到的状态，实际保留的是正序最后一次访问。正确实现可以先得到各时刻回报，再从正序筛选首次访问。这个细节很容易在循环任务中产生与教材定义不一致的算法。

## 4. TD(0)：从当前估计自举

<a id="value-foundation-13"></a>

### 4.1 一步目标与条件偏差

TD(0) 使用目标 $Y_t=R_{t+1}+\gamma V(S_{t+1})$，更新为 $V(S_t)\leftarrow V(S_t)+\alpha_t\delta_t$，其中 $\delta_t=Y_t-V(S_t)$。真正终止时目标仅为即时奖励。与 MC 不同，TD 无需等待回合结束，可以在继续任务中持续学习，也能利用相邻状态之间共享的马尔可夫结构。

当当前估计并不等于真实价值时，TD 目标的条件均值一般偏离真实价值，其偏差为 $\gamma P_\pi(V-v_\pi)$。但这个偏差随估计改善而变化，不能被当成固定监督标签误差。较短目标通常减少未来噪声传播，却引入自举依赖；具体均方误差取决于问题与训练阶段，没有不加条件的总排序。

<a id="value-foundation-14"></a>

### 4.2 同一轨迹的手算

假设一条两步回合奖励依次为一和二，折扣零点九，当前第二状态估计为五。第一状态完整 MC 目标为二点八，一步 TD 目标为五点五。若第一状态估计为零、步长零点一，两个更新分别得到零点二八和零点五五。差别来自尾部估计，不表示某条公式写错。

如果第二状态随后被更新为二，再多次访问第一状态，它的一步目标会逐渐接近二点八。TD 可以把后面状态已经学到的信息传播回前面，而不必每次等待一整条长回报。这种传播优势依赖正确状态结构和访问覆盖；如果后面估计长期错误，自举也会把错误向前传播。

<a id="value-foundation-15"></a>

### 4.3 TD 误差不是价值真误差

即使 $V=v_\pi$，单次 TD 误差一般仍不为零，因为奖励与转移随机。它的条件期望为零并不意味着每个样本都应为零。若人为训练到所有采样 TD 误差几乎消失，可能是在记忆有限轨迹、降低模型容量或忽略真实随机性，而不是准确恢复总体价值。

反过来，总体 Bellman 残差小在表格折扣问题中可以对价值误差给出上界，但单批样本残差小不等于总体残差小。需要独立数据或已知模型检验。这个区别与监督学习中训练误差和泛化误差类似，却多了自举目标与策略变化带来的依赖。

## 5. 可运行实验一：精确价值与 Bellman 收缩

以下继续任务只有两个状态，奖励与转移模型完全已知。用矩阵方程求真实价值，再用同步 Bellman 迭代逼近，并检验残差。它不依赖任何环境库，是后续采样算法的可靠参照。

```python
import numpy as np
P=np.array([[.7,.3],[.2,.8]])
r=np.array([1.,-.5]);gamma=.9
assert np.allclose(P.sum(1),1)
vstar=np.linalg.solve(np.eye(2)-gamma*P,r)
v=np.zeros(2)
for _ in range(300):v=r+gamma*P@v
assert np.allclose(v,vstar,atol=1e-10)
a=np.array([3.,-4.]);b=np.array([-1.,2.])
assert np.max(np.abs(gamma*P@(a-b))) <= gamma*np.max(np.abs(a-b))+1e-12
assert np.max(np.abs(r+gamma*P@vstar-vstar))<1e-12
print('exact fixed-policy values',vstar,'Bellman iteration',v)
```

已知模型下可以把任何学习到的表格代入同一个残差检查。若代码学到的值不同，应先确认它使用相同奖励、折扣和策略，而不是立即把差异归因于随机性。若行为策略随训练变化，固定策略真实价值也会变化，需要冻结某个策略再做预测比较。

<a id="value-foundation-17"></a>

## 6. 可运行实验二：偏差与方差不能只选一边看

构造两步回报，第一步奖励均值一、方差一，第二步奖励均值二、方差九，噪声独立。精确尾部价值为二时，一步 TD 目标与 MC 都具有正确均值，但 TD 不包含第二步采样噪声；尾部错误设为五时，TD 方差仍低，却出现明显偏差。这个实验固定目标参数，不把它冒充完整学习收敛实验。

```python
import numpy as np
rng=np.random.default_rng(131)
n=200000;gamma=.9
r1=1+rng.normal(size=n)
r2=2+3*rng.normal(size=n)
mc=r1+gamma*r2
td_true=r1+gamma*2
td_wrong=r1+gamma*5
truth=2.8
assert abs(mc.mean()-truth)<.03
assert abs(td_true.mean()-truth)<.02
assert np.isclose(mc.var(),1+.9**2*9,atol=.12)
assert td_true.var()<mc.var()
assert abs(td_wrong.mean()-truth-2.7)<.02
assert np.mean((td_wrong-truth)**2)>np.mean((td_true-truth)**2)
print('MC/TD true/TD wrong means',[x.mean() for x in [mc,td_true,td_wrong]])
print('variances',[x.var() for x in [mc,td_true,td_wrong]])
```

偏差与方差共同决定均方误差。在某些预算与问题上，带一些自举偏差的 TD 可以比高方差 MC 更准确；在另一些问题上，错误尾部会造成明显损害。随着学习进行，尾部误差也在改变，因此方法比较应画出独立评价随数据量的变化，而不是只选一个最有利阶段下结论。

## 7. 从状态价值到 SARSA

<a id="sec-2-1"></a>

<a id="value-foundation-19"></a>

### 7.1 五元组与实际下一动作

SARSA 的名称对应 $S_t,A_t,R_{t+1},S_{t+1},A_{t+1}$。更新目标为 $R_{t+1}+\gamma Q(S_{t+1},A_{t+1})$，其中下一动作确实由当前行为策略选出，并通常会在下一环境步执行。若训练代码每次先采一个动作做目标、随后又重新采另一个动作执行，就不再严格对应同一条样本路径，需要重新解释估计过程。

在固定行为策略下，SARSA 更新可以看成动作价值空间的策略评估。加入贪心改进与持续探索后，它同时改变策略与估计。收敛到最优通常还需要探索保持充分且最终趋于贪心等条件，不是任何固定探索率的 SARSA 都学到纯贪心最优价值。固定非零探索会把探索后果纳入目标，这可能正是某些任务所需要的行为价值。

<a id="value-foundation-20"></a>

### 7.2 Expected SARSA 与采样方差

Expected SARSA 用 $\sum_a\pi(a\mid s')Q(s',a)$ 替代实际下一动作值。若策略概率已知且动作数有限，可以精确求和，消除这一步动作抽样带来的方差，但环境奖励与转移仍有随机性。它的目标策略必须与求和概率一致，不能随意把某个旧策略概率当作当前策略。

计算全部动作值增加部分工作，但在小表格问题中通常很便宜。它也可用于离策略情形：只要当前状态动作样本覆盖合适，下一动作期望可以按目标策略构造。但更一般的状态分布校正和函数近似稳定性仍需要单独讨论，不能由一步求期望就断言所有离策略问题都被解决。

<a id="sec-4"></a>

<a id="value-foundation-21"></a>

## 8. Q-learning 与贪心目标策略

<a id="value-foundation-22"></a>

### 8.1 最大值目标的来源

Q-learning 使用 $Y=R+\gamma\max_aQ(S',a)$，对应最优 Bellman 算子的样本估计。行为可以是带探索的策略，目标则朝当前贪心选择构造，因此是典型离策略控制。它不是在评估实际持续探索策略的回报，而是在学习未来采取贪心最优动作时的价值。

一步转移中，给定当前状态动作后的环境分布不依赖行为在未来怎样选择动作，所以构造这个一步目标不需要对下一动作采样再作重要性加权。这个便利不适用于任意多步离策略回报，因为中间实际动作来自行为策略，会改变路径分布。离策略并不等于所有历史数据都能无条件直接使用。

<a id="sec-3"></a>

<a id="value-foundation-23"></a>

### 8.2 表格收敛条件与实际预算

有限折扣 MDP、奖励有界、所有相关状态动作被充分访问，以及各状态动作步长满足和发散、平方和收敛等随机逼近条件，是经典收敛讨论中的关键。步长条件例如按访问次数适当递减，而不是按全局时间给从未访问的动作极小步长。若某动作从不访问，理论无法替它创造知识。

有限训练不会自动接近渐近极限。探索可能极慢、奖励可能稀有、转移可能需要长时间才能遇到有用路径。常数步长与非平稳目标也改变结论。报告应给出训练步数、访问次数和独立评价，而不是用“算法保证收敛”掩盖有限预算下的明显失败。

<a id="value-foundation-24"></a>

### 8.3 最大化偏差与双估计思路

若多个动作值都带有零均值估计噪声，先取最大通常产生向上偏差，因为最大值偏向选中正噪声。这个偏差不同于环境奖励本身很高，也不同于探索不足。可以用两个估计器分离动作选择与动作评价，减少某些最大化偏差，但这不保证所有设置下无偏，也不解决覆盖与函数近似失稳。

人工检验可以生成多个真实值相同的噪声估计，比较最大值均值与真实值，再比较用独立第二组估计评价第一组所选动作的结果。选择与评价分离的思想也出现于统计模型选择，理解它能帮助避免把乐观估计当作实际策略收益。

<a id="value-foundation-25"></a>

## 9. 可运行实验三：探索后果使两种目标不同

环境有起点与桥头两个非终止状态。起点安全动作立即终止并给一分，冒险动作零奖励到桥头；桥头好动作给三分，坏动作给负三十分并终止。行为采用固定零点二探索率，随机动作均匀，所以桥头即使偏好好动作，也有十分之一概率选坏动作。持续探索的桥头价值为负零点三，贪心价值却为三。

```python
import numpy as np

def train(kind,seed,episodes=60000):
    rng=np.random.default_rng(seed)
    q=np.zeros((2,2));count=np.zeros((2,2),dtype=int)
    def action(s):
        if rng.random()<.2:return int(rng.integers(2))
        ties=np.flatnonzero(q[s]==q[s].max())
        return int(rng.choice(ties))
    for _ in range(episodes):
        a=action(0)
        if a==0:
            count[0,a]+=1;q[0,a]+=(1-q[0,a])/count[0,a]
            continue
        b=action(1)
        target=q[1].max() if kind=='qlearning' else q[1,b]
        count[0,a]+=1;q[0,a]+=(target-q[0,a])/count[0,a]
        reward=3. if b==0 else -30.
        count[1,b]+=1;q[1,b]+=(reward-q[1,b])/count[1,b]
    return q,count
qs,cs=train('sarsa',141)
qq,cq=train('qlearning',142)
assert np.all(cs>0) and np.all(cq>0)
assert qs[0].argmax()==0 and qq[0].argmax()==1
assert np.allclose(qs[1],[3.,-30.]) and np.allclose(qq[1],[3.,-30.])
assert abs(qs[0,1]-(.9*3+.1*(-30)))<.3
assert abs(qq[0,1]-3)<.02
print('SARSA',qs,'visits',cs)
print('Q-learning',qq,'visits',cq)
print('greedy deployment safe/risky returns',1.,3.)
```

这个实验折扣为一，但回合最多两步且总会终止，因此回报有界，不能把它当成一般无折扣继续任务的收敛证明。SARSA 学到安全起点，是对固定持续探索后果的合理反应；Q-learning 学到冒险起点，是对未来贪心动作的合理选择。最终贪心部署时后者获得三分，若部署仍持续探索，实际行为回报又不同，比较必须明确评价策略。

## 10. 半梯度、投影与函数近似

<a id="sec-6-1"></a>

<a id="value-foundation-27"></a>

### 10.1 为什么称为半梯度

使用 $V_w(s)$ 时，常见 TD 更新为 $w\leftarrow w+\alpha\delta\nabla_wV_w(s)$，把目标中的下一价值视为固定。这不等于对采样平方 TD 误差做完整梯度下降，完整梯度还包含下一状态价值的导数。二者优化或求解的对象不同，不能因为都出现平方误差就视为同一个算法。

同样，期望 Bellman 残差平方与采样 TD 误差平方不同，后者还包含条件噪声方差。直接用同一个下一状态样本同时估计期望残差与其导数，通常会产生相关性问题；某些残差梯度目标需要独立双采样或其他方法。这个边界帮助解释为什么简单把监督学习损失套进 TD 代码，并不自动得到想要的总体梯度。

<a id="value-foundation-28"></a>

### 10.2 线性 TD 的投影方程

令 $V_w=\Phi w$，特征矩阵列满秩，状态权重矩阵为对角正矩阵 $D$。在固定策略和平稳采样等条件下，期望 TD 更新为 $b-Aw$，其中 $A=\Phi^TD(I-\gamma P_\pi)\Phi$，$b=\Phi^TDr_\pi$。其零点满足 $\Phi^TD(T_\pi\Phi w-\Phi w)=0$，对应按 $D$ 加权的投影 Bellman 方程。

这与直接最小化真实价值误差得到的正交投影一般不同。TD 在可表示子空间内寻找一个投影 Bellman 不动点，而 MC 平方回归更接近真实价值的加权投影。二者可在表格可精确表示情形一致，在受限特征下不同。讨论哪一个更合适，需要结合状态分布、误差准则与控制用途，而不能只用“无模型”统称。

<a id="value-foundation-29"></a>

### 10.3 离策略权重与失稳

在策略平稳分布下，某些线性 TD 具有良好稳定性；换成不匹配的行为分布后，投影和转移的组合可能不再具有需要的收缩或正定性质。函数近似、自举与离策略常被称为危险组合，重点不是三者单独都错误，而是它们的相互作用会破坏表格直觉。

重要性采样可以在支持覆盖条件下修正某些期望，但可能带来大方差，也不自动修复所有函数近似稳定性问题。需要专门算法、权重或结构条件时，应明确说明其目标与假设。没有这些条件，不能把表格 Q-learning 的渐近结论作为任意深度离策略价值网络的保证。

<a id="value-foundation-double-sampling"></a>

### 10.4 双采样到底在消除哪一项偏差

第 10.1 节区分了半梯度与完整残差求导，但“下一状态参与两次”尚不足以解释为什么出问题。固定策略与不随参数变化的当前状态权重，记单次转移为 $\xi=(R,S')$，采样残差为 $\delta_w(\xi)=R+\gamma v_w(S')-v_w(s)$，条件均值为 $m_w(s)=E[\delta_w(\xi)\mid s]$。在允许交换求导与积分的条件下，单个状态的期望 Bellman 残差平方目标及其梯度为

$$
J_s(w)=\tfrac12m_w(s)^2,\qquad
\nabla J_s(w)=E[\delta_w\mid s]E[\nabla\delta_w\mid s].
$$

若拿同一次转移计算 $\delta_w\nabla\delta_w$，其条件期望却等于上式再加 $\operatorname{Cov}(\delta_w,\nabla\delta_w\mid s)$；向量情形逐坐标定义该协方差。它恰好是另一个目标 $K_s(w)=\tfrac12E[\delta_w^2\mid s]$ 的梯度，因为

$$
K_s(w)=J_s(w)+\tfrac12\operatorname{Var}(\delta_w\mid s).
$$

方差通常也随参数变化，所以多出来的项不是可随手丢弃的常数。自动微分忠实地求出了采样目标的导数，问题在于采样目标与原先声明的目标不同。

手算一个只考察状态 $s$ 的局部目标：令 $v_w(s)=w$，奖励恒为一，折扣为 $1/2$，下一状态等概率具有特征 $X=0$ 或 $X=2$，故 $v_w(S')=wX$。两种残差分别为 $1-w$ 与 $1$，于是

$$
J_s(w)=\tfrac12(1-w/2)^2,\qquad
K_s(w)=\tfrac14[(1-w)^2+1].
$$

前者唯一最小点为 $w=2$，后者为 $w=1$。在 $w=2$ 时，真实残差目标梯度已是零，同样本梯度期望却为 $1/2$，仍会把参数向下拉。这里残差方差为 $w^2/4$，其一半的导数为 $w/4$，恰好解释两个梯度的差。这是特定状态权重与受限函数族的比较，不表示 $w=2$ 已拟合整个环境的所有状态价值。因此检查实验时应同时打印两种总体目标及其梯度，而非只观察某一个训练损失是否下降。不同目标的最小值不能跨定义直接比较，损失下降也不能替代独立策略评价。

若能在同一 $s$ 下获得条件独立转移 $\xi_1,\xi_2$，则 $\delta_w(\xi_1)\nabla\delta_w(\xi_2)$ 的条件期望正是 $\nabla J_s$。枚举本例四种独立组合，平均为 $-1/2+w/4$，在二处归零。要求的是同一条件分布的独立后果，复制一条回放记录不会制造它；随便从两个不同当前状态抽样也不满足条件。可重置生成模型、足量重复访问或另行推导的辅助变量方法各有不同的信息与近似要求。双采样说明及残差目标的定义可对照 [Sharifnassab 与 Sutton 的原论文第 2 节](https://proceedings.mlr.press/v202/sharifnassab23a/sharifnassab23a.pdf)。冻结独立目标网络时，标签不再随当前回归参数变化，因而是另一种普通回归对象，不能据此宣称已经无偏求出了上述 $J_s$ 的梯度。

## 11. 十六道练习与详细答案

<a id="value-foundation-31"></a>

### 11.1 价值是状态本身的属性吗

不是。相同状态在不同策略、奖励、折扣和时域下可以有不同价值。需要同时声明这些对象，才能解释数值。尤其在危险环境里，持续探索与贪心策略对同一位置的价值可能差异很大。比较算法时若一方报告探索行为回报、另一方报告贪心评价，便不是同一个估计对象，不能直接用大小判优。

<a id="value-foundation-32"></a>

### 11.2 为什么第一项奖励不折扣

回报从当前动作之后立即收到的奖励开始，时间距离为零，所以系数是一。下一步奖励才乘一次折扣。若整体多乘一次折扣，会改变价值尺度；在固定折扣且所有路径一致时某些策略排序可能不变，但与 Bellman 公式和终止处理会不一致。应坚持统一时间约定，避免把偶然不影响某个例子当作公式正确。

<a id="sec-7-1"></a>

<a id="value-foundation-33"></a>

### 11.3 完整 MC 是否总优于 TD

不总。完整回报在固定策略下具有正确条件均值，但可能方差很大且反馈延迟长。TD 使用当前尾部估计，可能有偏，却能减少未来采样噪声并在线传播信息。均方误差取决于训练阶段和问题。比较应在相同数据预算下用独立真实价值误差或策略收益，而不是只争论哪个目标是否自举。

<a id="value-foundation-34"></a>

### 11.4 TD 误差为零是否说明价值正确

单样本误差为零只说明这个样本与当前估计自洽，不能证明总体 Bellman 方程成立。即使总体价值正确，随机奖励下单次 TD 误差通常不为零。应检查条件期望或独立残差，在已知小 MDP 中可直接计算。过度追求训练样本误差消失还可能导致记忆有限噪声，损害总体估计。

<a id="value-foundation-35"></a>

### 11.5 外部截断为什么通常自举

因为任务本身尚未结束，未来回报仍存在，采样停止只是资源边界。把尾部清零相当于改变任务。若时间耗尽本来就是任务规则，则应把剩余时间纳入状态并按有限时域终止处理。判断来自任务定义，不来自接口恰好返回一个完成标记。代码应保留足够信息区分两者。

<a id="value-foundation-36"></a>

### 11.6 SARSA 的下一动作能否随便选

它应来自所评估的行为策略，并与轨迹推进保持一致。如果用于目标的动作和实际执行动作不同，需要说明这是额外抽样的估计而非同一条 SARSA 轨迹。Expected SARSA 则明确对目标策略动作概率求和。目标策略、行为策略和实际数据路径必须逐一对应，才能解释更新的期望。

<a id="value-foundation-37"></a>

### 11.7 固定探索率 SARSA 学到最优吗

一般不能直接这样说。固定非零探索把未来随机动作后果纳入价值，目标不同于纯贪心最优。可能在某些任务里最终贪心动作仍与最优一致，但没有普遍保证。若讨论趋于最优，需要探索充分并逐渐趋于贪心等条件，同时满足步长与问题假设。有限运行更应直接评价部署策略。

<a id="value-foundation-38"></a>

### 11.8 Q-learning 为什么不需要下一动作比率

一步目标直接对下一状态所有动作取最大，不使用行为实际采样的下一动作来估计目标动作期望。因此给定当前状态动作的转移可直接用于该目标。多步回报包含中间行为动作，情况不同，通常需要相应校正或专门构造。不能把一步便利推广为所有离策略轨迹都可以不加区分地使用。

<a id="value-foundation-39"></a>

### 11.9 没访问动作能否靠最大值学会

不能。最大值会比较当前估计，但没有数据的估计可能只是初始化或函数近似外推。乐观初始化可以推动探索，却不提供真实转移证据。表格理论要求相关状态动作充分访问，离线数据若缺乏覆盖则尤其困难。应报告访问计数与支持范围，不要把数值很高当作可靠知识。

<a id="value-foundation-40"></a>

### 11.10 常数步长是否违反一切理论

不是，但它通常不满足收敛到无噪声定点的经典递减步长条件。常数步长可以用于追踪变化，估计在定点附近持续波动，具体稳定性有其他分析。应说明目标是渐近精确估计还是非平稳适应。不能一方面使用固定学习率，另一方面不加限定地引用递减步长收敛结论解释有限结果。

<a id="value-foundation-41"></a>

### 11.11 最大化偏差是什么

带噪估计取最大倾向选择正误差，所以最大估计的期望可能高于真实最大值。它不等于每个动作估计本身有偏。选择与评价分离可以缓解某些偏差，但仍受估计相关性和数据覆盖影响。研究时应构造真实动作值已知的反例，分别检查估计偏差和实际策略回报，避免把乐观数字当成收益。

<a id="value-foundation-42"></a>

### 11.12 半梯度是不是错误梯度

它是明确选择的一类更新，不是误把完整梯度少算一项后仍声称同一目标。TD 半梯度可以在相应条件下求解投影 Bellman 方程，具有自身理论与用途。若目标是某种残差平方，则需要重新推导正确梯度与抽样条件。关键在于准确说出算法求解什么，而不是凡非完整梯度都称错误。

<a id="value-foundation-43"></a>

### 11.13 投影 Bellman 解等于最佳价值回归吗

一般不同。一个先应用 Bellman 算子再投影求不动点，另一个直接把真实价值投影到特征子空间。受限表示下两种几何关系不同，只有特定条件或精确可表示时一致。比较应注明状态权重与误差准则。这个差异是函数近似研究的重要对象，不能在推导中把两个投影符号直接互换。

<a id="value-foundation-44"></a>

### 11.14 重要性采样能解决所有离策略问题吗

不能。它需要行为对目标相关事件有支持，并可能产生极大方差。函数近似下的稳定性还受投影、更新结构与状态分布影响。权重截断可以降低方差，却通常引入偏差，需要准确报告。离策略学习不是一句“乘上概率比”就结束，而是目标、覆盖、估计与优化共同决定的问题。

<a id="value-foundation-45"></a>

### 11.15 行为回报差是否算法失败

要看任务。如果算法目标是学习最终贪心策略，训练探索可能暂时牺牲行为回报；若真实应用关心学习期间安全与累计收益，这种代价本身就重要。应分别报告训练行为收益和最终部署评价，并明确应用效用。不能用最终高分忽略危险探索，也不能用探索期损失否定已经学到的目标价值。

<a id="value-foundation-46"></a>

### 11.16 怎样设计一个小型可信实验

先定义有限 MDP并精确求策略价值或最优价值，再固定训练预算、种子和评价策略。检查奖励、终止、步长、访问计数与目标公式，使用独立评价回合或解析值度量误差。比较 MC 与 TD 时固定策略，比较控制方法时说明探索和部署差异。把实现断言、总体理论和有限实验观察分别命名，就能得到清楚的证据链。

<a id="value-foundation-47"></a>

## 12. 可运行实验四：投影解与离策略失稳反例

<a id="value-foundation-48"></a>

### 12.1 两种投影为什么得到不同参数

沿用两个状态的固定策略模型，只允许一个参数，特征为第一状态一、第二状态二，因此表示只能位于一条直线上。先用真实价值做加权最小二乘，得到 MC 回归意义下的最佳参数；再用期望 TD 方程求零点。两种结果一般不同，实验直接核对各自正交条件，而不把某一个误当成另一个算法没有收敛。

后半部分构造一个合法的状态采样设计：每次以固定分布选择待更新状态，再从目标转移核抽下一状态。它可由模型采样或离线一阶转移数据提供，不要求这些状态频率是目标策略平稳分布。零奖励意味着真实价值全零，但同样一维特征下期望半梯度更新会把非零参数向外推。这个反例不含随机误差，因此明确展示不匹配采样与函数近似自举造成的结构问题。

```python
import numpy as np
P=np.array([[.7,.3],[.2,.8]])
r=np.array([1.,-.5]);gamma=.9
phi=np.array([1.,2.]);d=np.array([.4,.6])
assert np.allclose(d@P,d)
v=np.linalg.solve(np.eye(2)-gamma*P,r)
w_mc=np.sum(d*phi*v)/np.sum(d*phi*phi)
A=np.sum(d*phi*(phi-gamma*(P@phi)))
b=np.sum(d*phi*r)
w_td=b/A
assert not np.isclose(w_mc,w_td)
assert abs(np.sum(d*phi*(v-phi*w_mc)))<1e-12
assert abs(np.sum(d*phi*(r+gamma*(P@(phi*w_td))-phi*w_td)))<1e-12
# Sampling distribution deliberately differs from target occupancy.
Pbad=np.array([[0.,1.],[0.,1.]])
dbad=np.array([.99,.01])
Abad=np.sum(dbad*phi*(phi-gamma*(Pbad@phi)))
assert Abad<0
w=1.
for _ in range(100):w-=.1*Abad*w
assert w>100
assert np.allclose(np.linalg.solve(np.eye(2)-gamma*Pbad,np.zeros(2)),0)
print('value projection w',w_mc,'projected TD w',w_td)
print('off-distribution A',Abad,'parameter after 100 expected updates',w)
```

这个反例不是声称所有离策略方法都会发散，也不是说有限状态表格 Q-learning 失效。它使用共享特征与半梯度，且状态采样权重不匹配目标占用。改变算法、权重或特征可能恢复稳定，但需要相应论证。把它作为边界检查，能防止从一个表格收敛结论推断出任何数据分布和网络都安全。

<a id="value-foundation-49"></a>

## 13. 访问分布、预测目标与控制目标

<a id="value-foundation-50"></a>

### 13.1 状态权重决定更重视哪里

函数近似无法在所有状态精确表示价值时，优化或投影必须决定哪些状态更重要。行为的状态访问分布自然形成一种权重，但部署任务可能从另一组起点出发。一个在常访问状态误差很小的表示，可能在关键罕见状态严重错误。总体均方误差与部署收益因此可能不一致，应按起始分布和任务相关区域分层评价。

如果把权重改为均匀状态分布，就改变了预测目标的几何，而不只是改变数据顺序。离线重采样也可能同时改变方差与期望更新。应区分保持同一目标的抽样校正与有意改变目标权重。尤其使用优先回放时，若不作相应校正，某些更新会被更频繁强调，不能再默认原来的状态加权理论完全适用。

<a id="value-foundation-51"></a>

### 13.2 价值误差小不保证动作选择总正确

控制只关心相对动作排序，但小的价值误差也可能在两个动作真实差距很小时翻转排序。相反，所有动作值都加上相同状态偏移，可能使数值误差很大却不改变贪心动作。评价可以同时报告数值误差、动作错误率与实际回报，以区分表示误差与决策影响。不能只凭一个误差指标判断控制系统是否可用。

如果关键动作错误会造成灾难性后果，平均排序正确率也可能掩盖风险。需要明确起始分布、危险状态和失败代价。表格小问题可通过精确计算贪心策略价值来评价，而不是仅看估计最大值。学到的最大动作值是估计，实际策略价值才是部署结果，两者不应互相替代。

<a id="value-foundation-52"></a>

### 13.3 乐观初始化与未知状态

把初始动作值设得较高，可以鼓励贪心策略尝试尚未充分更新的动作。但这种探索机制依赖奖励范围、折扣与更新规则，函数近似共享参数时还可能把一个动作的数据影响到其他动作。乐观数值不是置信上界，除非有明确不确定性构造与证明。不能把初始化偏好当成已经掌握的环境知识。

相反，零初始化也不是中性。如果所有可获得回报都为负，零对未知动作是乐观的；如果好回报为正，零可能是悲观的。奖励平移与终止规则还会改变这种直觉。实验应报告初始化并检查访问计数，而不是把探索成功或失败完全归因于某个算法名称。

<a id="value-foundation-53"></a>

## 14. 收敛、样本效率与非平稳追踪

<a id="value-foundation-54"></a>

### 14.1 渐近定理回答什么

渐近收敛说明在无限更新及明确假设下估计趋于目标，不直接给出有限预算需要多少数据。某些状态虽然理论上最终会访问无穷次，却在实际运行中极难遇到。步长虽满足数学条件，也可能衰减过快，导致罕见状态有效更新不足。应把理论作为边界与设计依据，再用有限样本实验检查实际效率。

有限样本比较最好使用相同环境交互预算，而不是相同回合数，因为不同策略的回合长度可能不同。若某方法每次交互做多次模型更新，也要报告额外计算。训练时使用已知模型做规划与纯样本更新不是同一资源条件，可以比较，但需准确标注。否则所谓“更高样本效率”可能来自未计入的模型访问。

<a id="value-foundation-55"></a>

### 14.2 常数步长与变化环境

在非平稳环境中，旧数据可能不再代表当前目标，递减到极小的学习率会使模型难以追踪。常数步长给近期样本更高权重，能够持续适应，但估计也持续波动。此时评价目标应是随时间的追踪误差、适应延迟或累计收益，而不是期待最终固定值。算法选择由任务变化规律决定，不能机械套用平稳收敛标准。

如果奖励或转移变化没有被纳入状态，当前观测不再满足原来平稳 MDP 假设。可以扩充状态、使用上下文或明确研究非平稳问题。仅增加学习率不能恢复缺失的马尔可夫信息。报告应指出变化是预设机制还是偶然实验噪声，防止把不同问题混在同一条曲线解释。

<a id="value-foundation-56"></a>

### 14.3 参数变化与策略变化的反馈

控制算法的行为策略依赖当前价值，价值又依赖行为收集的数据，因此数据分布会随训练变化。某个动作早期被高估，可能获得更多数据并强化某种访问模式；被低估动作可能长期没有纠错机会。探索规则正是为了打破这种自我确认，但其效果依赖环境可达性和概率安排。

因此只观察平均 TD 误差下降可能具有误导性：策略逐渐避开难状态，训练分布变简单，平均误差自然降低，但未必改善整体知识。应同时记录访问分布、奖励与独立起点评价。固定预测任务比控制更容易隔离估计器差异，研究 MC 与 TD 时通常应先在固定策略下比较，再讨论控制反馈。

## 15. 多步回报的入口与离策略边界

<a id="value-foundation-58"></a>

### 15.1 用步数连接两种信息来源

在没有提前终止时，$n$ 步目标为前 $n$ 个奖励的折扣和，加上 $\gamma^nV(S_{t+n})$。一步时是 TD，覆盖到真正终止时尾部消失，得到完整回报。增加步数让更多真实奖励替代估计尾部，通常减少某些自举误差传播，却增加采样噪声、等待和存储。这些是机制上的趋势，不是所有问题里均方误差随步数单调变化的定理。

如果在第 $n$ 步前真正终止，就只累加到终止，不再加尾部。如果只是片段结束，通常需要从片段末状态自举。目标长度与训练批次长度是不同概念，不能因为数据块结束就假定任务结束。下一章和探索章节会进一步研究实际轨迹实现与资格迹，本章先保证概率对象清楚。

<a id="value-foundation-59"></a>

### 15.2 多步离策略为什么需要额外处理

一步 Q-learning 的当前状态动作转移来自环境，不需要知道行为以后如何选动作；多步目标中包含了行为实际执行的中间动作，它们会影响后续状态与奖励。若目标策略不同，直接使用这些回报一般不再是目标策略的无偏估计。重要性比率、截断、树备份或其他专门目标各自作出不同折中，不能只给末尾加一个最大值便称为任意多步最优目标。

支持条件尤为重要：如果目标会选择某动作而行为从不选择，就无法通过有限权重恢复相应路径。即使支持存在，长路径概率比乘积也可能方差巨大。权重截断降低方差却引入偏差，应按实际目标与评价来判断是否值得，而不是把离策略看成无需付代价的数据复用。

<a id="value-foundation-60"></a>

### 15.3 资格迹的直觉与限定

资格迹把过去访问的状态或特征保留一个随时间衰减的记忆，让当前 TD 误差同时更新多个过去位置。它与多步回报的关系在特定离线或固定参数条件下可以建立精确等价，但普通在线参数不断变化时，不能随意宣称任何迹实现都完全相同。累积迹、替换迹和真在线方法有不同定义，应该逐个说明。

这个边界提醒我们，算法之间的“连接”通常有具体条件，而不是凭相似图示就成立。后续深入时应先证明有限轨迹上的恒等式，再检查实现是否满足固定参数、终止和动作校正条件。这样才能把资格迹理解成可推导的方法，而不是另一个需要背诵的超参数。

## 16. 诊断价值学习的具体顺序

<a id="value-foundation-62"></a>

### 16.1 先检查环境定义与目标

在调学习率前，先检查奖励是否对应预期动作、真正终止是否去掉尾部、截断是否保留正确状态，以及动作编号是否与环境一致。对一个手工短轨迹逐步打印目标，核对 MC、TD、SARSA 与 Q-learning 的差别。基础目标错误往往仍能产生平滑曲线，因此不能靠“损失下降”排除它。

再检查策略采样与评价是否一致。训练探索率、贪心并列动作处理、评价起点与随机种子都可能影响结果。对于并列动作，永远选择最小编号会引入固定方向偏好；随机打破并列可以改善对称探索，但也需要记录随机机制。访问计数是判断是否真的获得证据的基本工具，应与最终价值表一起查看。

<a id="value-foundation-63"></a>

### 16.2 再检查更新与数据依赖

异步表格更新应只修改被访问项，向量化实现要小心重复索引覆盖。一次批次中同一状态出现多次时，顺序更新与先聚合再更新可能不是同一个有限步算法。函数近似中则要检查目标是否按预期停止梯度、优化器是否包含全部相关参数，以及模型状态是否在评价时意外变化。

经验回放中的同一转移被多次使用，不等于获得了同样多独立环境证据。它可以提高计算利用，但统计不确定性仍与原始数据依赖有关。若报告样本效率，应区分环境交互数与梯度更新数。若数据由不同策略混合收集，也应记录来源概率或至少覆盖信息，避免把未知行为数据当成任意可校正样本。

<a id="value-foundation-64"></a>

### 16.3 最后检查容量、探索与稳定性

基础链条正确后，再判断是否需要更多探索、更灵活特征、更合适步长或专门离策略算法。先在可精确表示的小表格上成功，再逐步加入函数近似，能够定位问题来自表示还是更新。若直接使用大网络失败，许多原因会混在一起，难以从结果推出有效结论。

失败也可以是有限预算下算法的真实表现，不应把每个没有达到预期分数的运行都删掉或重启。预先规定种子集合与停止规则，报告全部结果，才能判断某个改进是否稳定。尤其危险环境应保留训练阶段失败与代价，而不只展示最终策略成功，因为学习过程本身可能就是应用关心的对象。

## 17. 本章实跑结果与误读防线

<a id="value-foundation-66"></a>

### 17.1 从解析值到随机目标

两状态精确价值约为二点六三六四与负零点零九零九，Bellman 迭代在双精度容差内与矩阵解一致。噪声目标实验的 MC 均值约二点八零五，一步正确尾部 TD 约二点八零零，错误尾部 TD 约五点五零零。MC 方差约八点二七七，而两种 TD 目标方差都约一。这说明低方差本身不能排除偏差，也不能独立决定正确性。

桥头环境中，SARSA 起点安全动作值为一，冒险动作有限样本估计约负零点一零三；Q-learning 冒险估计约二点九九九九。SARSA 的理论持续探索值为负零点三，有限样本与早期估计造成偏离，不能把这次结果说成精确收敛。但两种方法的起点贪心动作分别为安全与冒险，符合它们不同目标的预期。

<a id="value-foundation-67"></a>

### 17.2 有限实验不能替代理论条件

所有断言只验证本章固定模型和预设种子范围内的公式、更新与方向，不能证明任意环境都收敛。若更换奖励尺度、探索率或初始值，需要重新检查有限预算误差。特别是桥头实验使用访问均值步长，长期值逐渐稳定，而常数步长会保留较大波动；更换步长后不应仍期待完全相同的最终数字。

完整方法比较还应重复多个训练种子，并用独立评价轨迹或精确策略价值计算收益。本章没有使用环境库、外部数据或 GPU，没有把人工模型结果冒充游戏或机器人基准。它的用途是建立能够推导与检查后续复杂系统的基础，让每个后来的技巧都能回到明确概率对象和证据。

<a id="value-foundation-68"></a>

### 17.3 怎样继续提出研究问题

可以固定策略，只改变回报长度，观察不同样本预算下偏差方差与均方误差；也可以固定模型，只改变特征子空间与状态权重，比较投影 TD 与真实价值回归的差别。另一个方向是把行为探索率逐渐降低，研究 SARSA 的目标如何变化，以及最终策略与训练期间风险之间的折中。

每个研究题都应先列出理论预期与可能反例，再决定指标和预算。若方法结果不符合直觉，应依次检查定义、实现、有限采样与假设，而不是立即修改到结果看起来正确为止。能够解释一个负结果为何出现，通常比得到一条漂亮但来源不明的曲线更有学习价值。

<a id="value-foundation-69"></a>

## 18. 进一步推导：投影误差、任务变换与边界

<a id="value-foundation-70"></a>

### 18.1 在合适分布下控制投影 TD 误差

假设固定策略平稳分布为正权重 $D$，特征空间为线性子空间，$\Pi_D$ 是该范数下的正交投影。平稳性与 Jensen 不等式可推出转移算子在该加权二范数下非扩张，因此投影 Bellman 算子具有折扣收缩。这里的分布条件非常关键，任意改变状态权重后不能继续无条件使用这个结论。

记真实价值为 $v$，投影 TD 解为 $\hat v$。利用投影正交分解，有 $\|v-\hat v\|_D^2=\|v-\Pi_Dv\|_D^2+\|\Pi_Dv-\hat v\|_D^2$。再用真实和投影 Bellman 方程，可把第二项的向量写成 $\Pi_D(Tv-T\hat v)$，其范数不超过 $\gamma\|v-\hat v\|_D$。移项后得到 TD 误差不超过最佳投影误差乘以 $1/\sqrt{1-\gamma^2}$ 的一个上界。

这个上界说明在这些条件下，TD 虽不直接等于最佳真实价值回归，也不会任意偏离可表示能力；但折扣接近一时界可能很松。它不是所有线性 TD 的无条件保证，离策略分布、非线性投影或不稳定更新都可能破坏推导。阅读类似定理时，应追踪每一步使用了哪个范数、哪个分布与哪种投影，而不是只摘出最后一个常数。

<a id="value-foundation-71"></a>

### 18.2 无折扣回合任务为什么需要另说

本章一般收缩论证使用折扣严格小于一。若折扣为一且任务会在有限期望时间内终止，可以在适当条件下通过瞬态转移矩阵与其他加权范数分析价值。并不是只要接口最终偶尔结束，所有无折扣学习结论就自动成立；若存在永不终止的循环和正奖励，回报甚至可能发散。

桥头实验每回合最多两步，因而没有这种风险，所有回报都有界。但把同样折扣直接用于一维导航，若允许无限徘徊，就需要明确终止、负步长代价和策略适当性。实际实现常设置最大长度，这个设置若是外部截断，不能被用来悄悄替代原任务的数学假设。有限时域与无限任务是不同模型，需要准确区分。

<a id="value-foundation-72"></a>

### 18.3 奖励平移与终止长度

在固定无限折扣继续任务中，所有每步奖励加常数会给各状态价值加相同的常数除以一减折扣，某些策略排序保持不变。回合任务长度随策略变化时，给每步奖励加常数会奖励或惩罚更长路径，可能改变最优策略。因此所谓“奖励只平移，不影响学习目标”并非普遍成立，应结合终止与吸收状态约定判断。

例如安全动作立即终止，绕路动作多走十步再得到同样终点奖励。每步加正奖励可能鼓励绕路，每步加负代价则鼓励尽快结束。若环境把终止后吸收状态也不断发奖励，定义又不同。奖励变换的实验必须列出完整后续过程，不能只改非终止部分再套用继续任务直觉。

<a id="value-foundation-73"></a>

### 18.4 势函数塑形的望远镜求和

一种有明确结构的变换是加入 $\gamma\Phi(S_{t+1})-\Phi(S_t)$。沿轨迹折扣求和时，中间项相消，有限截断后只剩起点负势与末端折扣势。对于无限折扣且势有界，末端项趋零；回合任务则需要相应终止势条件。此时回报变化只与起点有关，可以在合适条件下保持策略排序。

这个推导说明正确塑形不等于随便给接近目标加分。若末端势处理错误、折扣不一致或状态遗漏时间，原本的排序保证可能不再成立。塑形也不必然提高有限样本学习速度，势函数选择仍影响探索与数值尺度。实验应同时评价原始任务回报，避免只报告被塑形奖励放大的训练曲线。

<a id="value-foundation-74"></a>

### 18.5 区分估计器不确定性与环境随机性

一个状态本身转移高度随机，即使价值估计已经准确，未来回报仍有很大分散；另一个状态环境确定，却可能因访问不足而估计很不可靠。这是两种不同不确定性。普通单个 Q 数值通常没有同时表达二者，不能因为价值高就认定置信度高，也不能因为回报方差大就认定模型无知。

如果研究需要置信区间或探索奖励，应明确估计对象、独立数据单位与覆盖条件。使用多个网络或多个表格的分歧可以提供诊断，但其相关训练数据会影响解释，不能自动当作校准的后验方差。最简单的人工 MDP 中，可以通过重复独立训练与已知真实值检查覆盖率，再决定是否将某种不确定性方法用于更复杂任务。

<a id="value-foundation-75"></a>

### 18.6 投影实验的具体结果与含义

加权真实价值回归的一维参数约为零点三三八，投影 TD 参数约为负零点五一五，二者甚至符号不同，却分别满足各自的正交方程。这不是某个算法实现反号，而是受限特征空间与不同目标几何造成的结果。真实价值一正一略负，特征却强制两个预测同号且第二个幅度更大，无法同时准确表达，因此权重选择与动态关系变得重要。

离分布反例的期望更新系数约为负零点七八八，从参数一开始，一百次固定步长期望更新后达到约一千九百六十八。零奖励的真实价值仍完全为零，说明发散不是任务回报本来很大，也不是单次采样噪声造成。这个实验有意使用精确期望更新，从而把结构性失稳与随机方差分离。实际采样版本可能更复杂，但不能靠减少噪声就自动修复这个负系数。

<a id="value-foundation-76"></a>

### 18.7 状态表示应先于价值网络

如果观测不满足马尔可夫性，相同观测下的下一状态分布可能依赖未记录历史。此时给观测建立一个表格并不是恢复原始完整状态价值，TD 可能把不同隐藏情形混在一起。增加网络宽度无法凭空获得缺失信息，需要更充分状态、历史窗口、记忆结构或明确的部分可观测模型。诊断时可以检查相同观测在不同历史条件下的转移与回报差异。

另一方面，加入无关历史会扩大状态空间，降低访问效率，并不总是有益。状态设计应围绕预测未来和选择动作所需信息，而不是无限堆叠特征。人工问题中可以先使用完整状态建立基准，再故意混淆两个状态，观察 MC 与 TD 预测如何变化。这个实验有助于理解方法依赖的结构假设，也能防止把表示问题误判为单纯学习率问题。

最后，所有学习曲线都应标明横轴究竟是环境交互、回合、更新次数还是模型查询。长回合与短回合使用相同回合数，实际证据量可能相差很大。比较预测方法还应固定策略与来源分布，比较控制方法则要说明数据分布随策略变化这一事实。把这些最基本的单位写准确，通常比增加更多装饰性图表更能提高报告质量。

每次修改任务规则或评价起点后，都应重新计算可用的解析参照，而不是沿用旧最优值。小型模型的优势正是能够把定义、证明、实现与评价闭合起来；充分利用这个优势，才能在以后面对无法精确求解的任务时保持可靠判断。
