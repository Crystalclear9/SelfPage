## 1. 一个小环境也要有完整任务定义

一维导航的价值在于全部概率、最优策略和训练数据都能被理解，而不是代码短。我们用位置零到六组成一条线，零是失败终点，六是成功终点，位置一到五是非终止状态。动作零表示向左，动作一表示向右。执行时以零点一五概率把方向翻转，体现环境随机性；到成功终点奖励一，到失败终点奖励负一，其余转移奖励负零点零二，折扣零点九五。

训练回合从五个非终止位置均匀开始，目的是获得较完整状态动作覆盖；部署评价固定从位置三开始，另做逐起点分层评价。两种起始分布不同，但被明确声明。每回合最多采样八十步，超出是外部截断，原任务并未因此结束，所以最后转移仍保留下一状态价值。这个区别将贯穿环境、目标、训练和评价。

<a id="deep-dive-1"></a>

<a id="tabular-nav-2"></a>

### 1.1 状态是否包含时间

这里任务本身没有硬性八十步截止，状态只需位置。八十步是采样保护，防止一次训练回合无限占用资源。若应用真的要求八十步内到达目标，任务应改成有限时域，并把剩余时间纳入状态，否则同一位置在还剩一步和还剩七十九步时具有不同未来价值，位置表格就不再是完整状态表示。

不要因为训练循环使用一个步数变量，就默认已经解决有限时域问题。是否需要把时间加入状态，来自任务是否依赖剩余时间。代码的终止和截断标志只是表达这个语义，不负责替开发者定义任务。先写清楚模型，才能知道目标中何时应该去掉尾部。

<a id="tabular-nav-3"></a>

### 1.2 随机转移与行为随机不同

环境滑动概率与探索率是两种独立随机性。即使行为总选向右，实际仍可能向左；即使环境完全确定，探索也会让策略选择不同动作。调探索率不会改变环境转移核，调滑动概率却改变了任务最优价值。报告应分别列出它们，不能只说“随机性为百分之十五”。

随机数流也最好分开：训练行为、训练环境、评价环境可以使用独立生成器，避免评价次数改变后续训练轨迹。本章完整实验用不同种子对象，不依赖全局随机状态。这个设计使插入一次评价不会消耗训练噪声，也让独立评价更容易解释。

## 2. 精确模型与最优价值参照

<a id="sec-1-1"></a>

<a id="tabular-nav-5"></a>

### 2.1 枚举一步转移核

对于每个非终止位置与动作，环境只有两个可能结果：按意图移动，或翻转移动。每个结果包含概率、下一位置、奖励和真正终止标志。概率加和必须为一，下一位置必须合法，终点价值按零处理。终点本身不再接受动作；若为了矩阵方便引入吸收自环，也应保证后续奖励为零并保持同一任务含义。

这种枚举使动态规划成为可能。对每个状态动作，计算所有转移概率加权的即时奖励与折扣最大下一值，重复直到收敛。它给出与 Q-learning 同一个 Bellman 最优不动点，但使用已知模型而非环境样本。后续学习误差应相对于这个精确值，而不是相对于另一个随机训练表。

<a id="tabular-nav-6"></a>

### 2.2 为什么最优动作还需要计算

直觉上成功终点在右侧，向右似乎总是最好，但随机滑动、步长代价和折扣可能在其他任务中改变策略。教材不应把直觉当作无需验证的正确答案。先算最优表，可以检查奖励实现是否真的对应预期。若改变奖励、终点位置或转移概率，也应重新计算，而不是沿用旧的“永远向右”断言。

价值表不仅给最优动作，也给非最优动作的价值。探索会访问这些动作，Q-learning 需要正确估计它们的后果。只检查贪心方向正确，可能掩盖很大的数值误差；只检查最大误差，又可能过度强调几乎不影响部署的动作。因此本章同时使用策略、数值误差和实际回报三类结果。

<a id="tabular-nav-7"></a>

## 3. 可运行实验一：枚举模型与 Bellman 最优解

这段代码不调用任何强化学习环境库。它首先给出纯函数转移模型，然后用同步价值迭代求最优动作价值，并验证 Bellman 残差与终点约定。更新使用旧表整体计算新表，避免把同步与顺序原地更新混在一起。

```python
import numpy as np

def outcomes(s,a,slip=.15):
    assert s in range(1,6) and a in (0,1)
    intended=1 if a==1 else -1
    result=[]
    for probability,direction in [(1-slip,intended),(slip,-intended)]:
        ns=s+direction
        reward=1. if ns==6 else -1. if ns==0 else -.02
        result.append((probability,ns,reward,ns in (0,6)))
    assert np.isclose(sum(x[0] for x in result),1)
    return result
q=np.zeros((7,2));gamma=.95
for _ in range(2000):
    nxt=np.zeros_like(q)
    for s in range(1,6):
        for a in range(2):
            nxt[s,a]=sum(p*(r+gamma*(0 if done else q[ns].max()))
                           for p,ns,r,done in outcomes(s,a))
    error=np.max(np.abs(nxt-q));q=nxt
    if error<1e-13:break
assert error<1e-11
assert np.all(q[[0,6]]==0)
assert np.all(q[1:6].argmax(axis=1)==1)
for s in range(1,6):
    for a in range(2):
        backup=sum(p*(r+gamma*(0 if done else q[ns].max()))
                   for p,ns,r,done in outcomes(s,a))
        assert abs(backup-q[s,a])<1e-10
print('exact optimal Q table',q,sep='\n')
```

这里的停止误差对应相邻 Bellman 迭代差，最终又直接核对不动点残差。由于折扣收缩，它们可以用于控制表格数值误差。这个参照没有使用训练轨迹，因此不会与后续训练噪声共同偏移。对小问题充分利用已知模型，是建立可信实验最有效的方法之一。

## 4. 探索、步长与表格更新

<a id="tabular-nav-9"></a>

### 4.1 epsilon-greedy 的完整概率

以探索率选择均匀随机动作，其余时候在最大值动作集合中均匀选择。若有唯一最大动作，它的总选择概率还包括探索时碰巧选中的部分，因此不是简单的一减探索率。并列时随机打破对称，避免动作编号造成固定方向偏好。探索率按回合逐渐降低到正下限，保证有限预算内仍有一定尝试。

固定正下限不满足最终完全贪心的要求，但 Q-learning 目标仍是贪心最优，而非评估行为策略。这个设置用于有限预算实验，不把它包装成全部经典渐近条件都已实现。若要研究严格递减探索，需另行检查每个相关状态动作是否仍被充分访问，而不是只看一个全局探索率趋零。

<a id="tabular-nav-10"></a>

### 4.2 按访问次数递减步长

对被访问状态动作维护计数，采用计数的负零点六五次方作为步长。这样每个表格项按照自身证据量调整，不会因为全局时间很大就让一个刚遇到的动作获得极小步长。这个指数对应的和发散、平方和收敛，是经典随机逼近步长形态，但实际有限收敛速度仍依赖环境与访问。

首次访问步长为一，可以快速替换初始化；后续渐渐平滑。奖励尺度更大时，初期变化也更大，因此应检查数值范围。不能因为采用了一个符合渐近形式的步长，就省略对覆盖与有限误差的评价。访问计数、最小计数和未访问项应与最后的价值表一起报告。

<a id="tabular-nav-11"></a>

### 4.3 目标里的终止掩码

Q-learning 目标为奖励加折扣最大下一值，但真正终止时尾部为零。外部截断不参与这个掩码，最后一个转移仍使用下一状态估计。循环停止与目标清零是两个决策：前者决定本次采样是否继续，后者决定任务未来价值是否存在。把二者使用同一个布尔量，是许多表格实现产生系统偏差的根源。

更新后再检查终止停止循环，能够保证终点奖励进入学习。若在看到完成标志后先跳出循环，最后转移就会被丢弃，模型可能始终学不到真正到达目标的收益。最可靠的排查方式是先用一条一步终止轨迹手算更新，再扩展到完整环境。

## 5. 完整实验：训练与独立贪心评价

<a id="tabular-nav-13"></a>

### 5.1 环境与训练实现

下面把所有必要定义放在同一代码块，复制后可独立运行。环境通过纯函数返回下一状态、奖励与真正终止，训练循环自己管理截断。训练随机起点与评价固定起点使用不同规则，已经在任务定义中声明。训练行为使用独立随机流选择动作，环境转移使用另一随机流。

```python
import numpy as np

def step(s,a,rng,slip=.15):
    if s not in range(1,6) or a not in (0,1):raise ValueError('invalid state/action')
    direction=1 if a==1 else -1
    if rng.random()<slip:direction=-direction
    ns=s+direction
    reward=1. if ns==6 else -1. if ns==0 else -.02
    return ns,reward,ns in (0,6)

def train(seed=151,episodes=8000):
    behavior=np.random.default_rng(seed)
    environment=np.random.default_rng(seed+10000)
    q=np.zeros((7,2));visits=np.zeros_like(q,dtype=int)
    truncated=0;terminal=0
    for episode in range(episodes):
        s=int(behavior.integers(1,6))
        epsilon=max(.05,.4/(1+episode/1000))
        for time in range(80):
            if behavior.random()<epsilon:a=int(behavior.integers(2))
            else:a=int(behavior.choice(np.flatnonzero(q[s]==q[s].max())))
            ns,r,terminated=step(s,a,environment)
            visits[s,a]+=1
            alpha=visits[s,a]**(-.65)
            target=r+.95*(0 if terminated else q[ns].max())
            q[s,a]+=alpha*(target-q[s,a])
            s=ns
            if terminated:
                terminal+=1;break
        else:truncated+=1
    assert terminal+truncated==episodes
    return q,visits,truncated

def evaluate(q,start=3,episodes=4000,seed=152):
    rng=np.random.default_rng(seed)
    returns=[];success=[];lengths=[];truncations=0
    for _ in range(episodes):
        s=start;total=0.;factor=1.
        for time in range(80):
            a=int(q[s].argmax())
            ns,r,terminated=step(s,a,rng)
            total+=factor*r;factor*=.95;s=ns
            if terminated:
                success.append(s==6);lengths.append(time+1);break
        else:
            truncations+=1;success.append(False);lengths.append(80)
        returns.append(total)
    return np.array(returns),np.array(success),np.array(lengths),truncations
q,visits,truncated=train()
before=q.copy();counts_before=visits.copy()
returns,success,lengths,eval_truncated=evaluate(q)
assert np.all(q[[0,6]]==0) and np.all(visits[1:6]>0)
assert np.all(q[1:6].argmax(axis=1)==1)
assert np.array_equal(q,before) and np.array_equal(visits,counts_before)
assert np.isfinite(q).all() and np.isfinite(returns).all()
assert success.mean()>.9
print('learned Q',q,sep='\n')
print('visits',visits,'training truncations',truncated,sep='\n')
print('independent greedy return/success/length/truncations',
      returns.mean(),success.mean(),lengths.mean(),eval_truncated)
```

### 5.2 评价代码刻意保留的边界

评价不更新 Q、不衰减探索率、不修改访问计数，也不共用训练随机数流。贪心并列动作采用固定编号选择，这是明确部署约定；训练时则随机打破并列。若最终仍有大量并列，评价对该约定可能敏感，应作为未充分学习的诊断。当前实验会直接检查五个非终止位置的贪心动作与精确参照一致。

评价截断时记录有限观测回报并标记未完成，未把截断强行算作成功。本任务通常很快终止，但若截断比例不可忽略，有限观测回报不再等于完整折扣任务回报的无偏估计。可以延长独立评价预算、使用解析价值或给出明确尾部界，而不是悄悄删除未完成回合。

<a id="tabular-nav-15"></a>

## 6. 精确策略评价与有限样本对照

<a id="tabular-nav-16"></a>

### 6.1 固定贪心策略的线性系统

训练结束后冻结贪心策略，可以枚举该策略诱导的非终止转移矩阵与奖励向量。解线性系统得到精确折扣价值，还可以解吸收概率方程得到到达成功终点的概率。这样能同时检验有限评价回合是否与理论相符，以及价值表估计是否接近部署策略实际收益。

成功概率不是折扣回报。步长代价与失败奖励会影响回报，路径速度与成功概率也可能冲突。某策略即使成功率较高，若花很多步，折扣收益可能低。报告应保留原始任务目标，同时补充成功率和长度，不把某个辅助指标替换成主要优化目标。

<a id="tabular-nav-17"></a>

### 6.2 可运行实验二：解析吸收评价

```python
import numpy as np

gamma=.95
# This frozen policy always chooses right.
P=np.zeros((5,5));r=np.zeros(5);success_rhs=np.zeros(5)
for s in range(1,6):
    for prob,ns in [(.85,s+1),(.15,s-1)]:
        reward=1. if ns==6 else -1. if ns==0 else -.02
        r[s-1]+=prob*reward
        if ns==6:success_rhs[s-1]+=prob
        elif ns!=0:P[s-1,ns-1]+=prob
v=np.linalg.solve(np.eye(5)-gamma*P,r)
hit=np.linalg.solve(np.eye(5)-P,success_rhs)
length=np.linalg.solve(np.eye(5)-P,np.ones(5))
assert np.all((hit>=0)&(hit<=1))
assert np.all(length>0)
assert np.max(np.abs(v-r-gamma*P@v))<1e-12
# Direct independent Monte Carlo uses its own RNG.
rng=np.random.default_rng(153)
values=[];wins=[];durations=[]
for _ in range(20000):
    s=3;ret=0.;factor=1.;steps=0
    while s not in (0,6):
        s+=1 if rng.random()<.85 else -1
        reward=1. if s==6 else -1. if s==0 else -.02
        ret+=factor*reward;factor*=gamma;steps+=1
    values.append(ret);wins.append(s==6);durations.append(steps)
assert abs(np.mean(values)-v[2])<.02
assert abs(np.mean(wins)-hit[2])<.01
assert abs(np.mean(durations)-length[2])<.15
print('exact start3 return/success/length',v[2],hit[2],length[2])
print('Monte Carlo',np.mean(values),np.mean(wins),np.mean(durations))
```

这个实验评价的是已知固定策略，不需要再次训练。它把策略价值、成功概率和长度分别列出，并使用完全独立随机流抽回合。生成的长回合没有人为截断，吸收过程在此有限链中几乎必然结束，理论期望长度也可计算。若换成可能不吸收的环境，不能直接沿用这个循环而不考虑预算与适当性。

<a id="tabular-nav-18"></a>

## 7. 可运行实验三：终止和截断混淆的定量代价

考虑只有一个非终止状态、每步奖励一、折扣零点九的继续任务，真实价值为十。训练每次只采一步就重置，这是采样截断，不是任务终止。正确目标始终保留尾部；错误实现每次清零，最后只能学到一。另设真正一步结束的任务，其价值本来就是一，帮助区分环境定义而非代码标记。

```python
import numpy as np
correct=0.;wrong=0.;truly_terminal=0.
for _ in range(3000):
    correct+=.1*(1+.9*correct-correct)
    wrong+=.1*(1-wrong)
    truly_terminal+=.1*(1-truly_terminal)
assert np.isclose(correct,10,atol=1e-10)
assert np.isclose(wrong,1,atol=1e-12)
assert np.isclose(truly_terminal,1,atol=1e-12)
assert correct-wrong>8.9
print('truncated continuing/collapsed target/actual terminal',
      correct,wrong,truly_terminal)
```

两个数值一来自不同解释：错误继续任务目标与正确一步终止任务恰好相同。这说明单看最终数值无法判断实现是否正确，必须回到任务定义。若把采样片段边界都当作终止，算法实际上在学习一个由数据切分方式决定的新任务，而不是原来的继续任务。

## 8. 逐起点、逐动作与失败轨迹

<a id="sec-5-1"></a>

<a id="tabular-nav-20"></a>

### 8.1 起点分布为什么重要

从位置五开始几乎一步就能成功，从位置一开始则面临更高失败概率。只报告训练均匀起点平均可能掩盖位置一的风险，也可能与部署固定位置三不一致。应同时给出主要部署起点结果和预先定义的起点分层。分层样本量不足时要标注不确定性，不应删去难起点让平均更好看。

训练均匀起点在本章是获得覆盖的教学选择，并不表示真实任务总允许任意重置。实际系统可能只能从固定初态开始，探索到远处状态的成本更高。将模拟器可任意重置的结果迁移到真实机器人或在线系统时，必须重新考虑可达性与重置资源，不能把这个便利当成算法本身免费拥有的能力。

<a id="tabular-nav-21"></a>

### 8.2 值误差与策略错误分开看

若所有非终止位置的最大动作都向右，部署策略已经与最优一致，但 Q 数值仍可能有有限样本误差。反之，平均值误差很小也可能在某个关键位置翻转动作。可以报告最大绝对误差、按部署访问加权的误差、动作不一致位置以及精确部署价值。每个指标回答不同问题，组合起来比一个损失更清楚。

对于没有访问过的动作，初始化数值不应被当成可靠估计。即使最终策略没有使用它，探索或环境变化时也可能受到影响。访问计数可以解释数值误差为何集中在某些位置，但不能用“很少访问”自动豁免所有错误；如果部署有机会到达那里，就需要更多证据或明确限制使用范围。

<a id="tabular-nav-22"></a>

### 8.3 失败轨迹如何读

失败不一定说明动作选择错，环境滑动可以让最优策略偶尔走向失败终点。应区分不可避免环境风险与策略额外风险。对失败回合记录动作、实际方向和位置，有助于看到是连续滑动还是价值错误导致。不能从一条随机失败轨迹直接否定最优策略，也不能用“环境随机”掩盖系统性选择错误。

长度分布也很有用：异常长回合可能提示策略在两个位置间徘徊、并列动作偏好或错误终止处理。平均长度可能被少量极长尾部影响，应根据任务补充中位数、分位数或截断比例。任何事后挑出的个例都应作为诊断而非总体证据，最终仍需独立抽样或解析评价。

## 9. 十六道练习与详细答案

<a id="sec-6-1"></a>

<a id="tabular-nav-24"></a>

### 9.1 为什么训练从随机位置开始

为了在有限预算下获得五个非终止位置的较完整覆盖，减少靠近失败侧的位置长期缺数据。它是数据收集设计，不是任务必须规则。部署仍可固定从位置三评价。若真实系统不能任意重置，必须按实际起点重新研究探索成本，不能把模拟器便利直接当作现实能力。报告应分别说明训练与部署起始分布。

<a id="tabular-nav-25"></a>

### 9.2 滑动概率和探索率能否合并

不能。探索决定选择哪个动作，滑动决定动作执行后环境如何转移。二者改变不同概率层次，影响价值与数据覆盖的方式也不同。一个固定向右策略仍会因滑动失败，而一个确定环境也会因探索向左。调参应单独记录，评价时通常固定环境随机性并关闭行为探索，才能解释最终策略收益。

<a id="tabular-nav-26"></a>

### 9.3 到终点的奖励是否再减步长代价

本章定义终点奖励直接为一或负一，非终止转移才给负步长代价，因此没有额外再减。也可以定义所有转移都有步长代价、终点再加奖励，但那是另一任务，应重新计算精确值。代码与文字必须一致。不能在训练与动态规划使用两种约定后，把差异归咎于算法误差。

<a id="tabular-nav-27"></a>

### 9.4 为什么终点 Q 固定为零

因为真正终止后没有未来动作和奖励，终点价值作为边界条件设零。终点奖励属于到达它的最后转移，已经进入前一状态动作目标。若再在终点放一个奖励值并自举，就可能重复计入。使用吸收状态也可以，但吸收后奖励应与任务定义一致，本章不允许终点继续动作。

<a id="tabular-nav-28"></a>

### 9.5 评价能否继续更新表格

若目的是评价固定训练结果，就不能继续学习，否则评价同时改变了模型，结果依赖评价顺序与数量。在线适应可以作为另一任务，但要明确定义协议和成本。本章评价冻结 Q 与计数，并用断言检验。评价随机数也独立，避免仅仅多评几次就改变之后训练轨迹。

<a id="tabular-nav-29"></a>

### 9.6 并列动作固定选左有何影响

初始表全零时会产生系统方向偏好，可能增加早期失败或延迟发现右侧收益。随机打破并列可以保持对称，但不保证所有任务探索充分。部署可以使用固定规则，只要明确说明，并检查最终是否仍有大量并列。动作编号本身没有语义优势，不能让偶然编号决定未声明策略。

<a id="tabular-nav-30"></a>

### 9.7 八十步结束为什么不清尾部

因为这是采样预算，不是本章任务硬截止。未来仍可能有奖励，正确一步目标保留下一值。如果把任务改为必须八十步内完成，就需要有限时域价值及剩余时间状态，届时真正结束可清尾部。判断要从任务语义出发，而不是统一套一个完成标志。

<a id="tabular-nav-31"></a>

### 9.8 同回合数是否公平预算

不同策略的回合长度可能不同，因此相同回合数不代表相同环境交互量。应至少报告总转移数与更新数，必要时固定交互预算比较。使用任意重置还涉及额外资源假设。若某方法每步做更多计算，也应报告时间或模型调用，避免把隐藏资源当成算法效率。

<a id="tabular-nav-32"></a>

### 9.9 成功率高是否回报一定高

不一定。路径更长会产生更多负步长代价和折扣损失，失败奖励也影响期望。成功率、长度和折扣回报是相关但不同指标。应以任务原始目标为主，再用辅助指标解释。若应用更在意成功率，应从任务设计层明确，而不是训练一个目标后只挑另一个好看的指标报告。

<a id="tabular-nav-33"></a>

### 9.10 Q 最大值是否实际部署收益

它是有限样本估计，可能有偏或误差。实际部署收益应独立评价或用已知模型精确求策略价值。即使估计最大值很高，贪心动作错误也会造成低收益。反过来，数值误差存在但动作正确时，部署收益可能已经最优。把估计与结果分开，是避免乐观解释的关键。

<a id="tabular-nav-34"></a>

### 9.11 评价截断回合能否删除

不能无说明删除，因为长回合往往与困难或错误有关，删去会改变评价分布。可以报告有限预算回报、未完成率，或延长评价并使用解析尾部信息。若应用有实际超时，超时本身就是失败代价的一部分。任何过滤都应被计入最终系统定义与成本，而不是隐藏在数据清理里。

<a id="tabular-nav-35"></a>

### 9.12 学会向右为何还报告访问计数

因为动作方向正确不证明全部价值可靠，未访问或低访问动作仍可能严重错误。环境变化、探索或其他起点会使这些错误变重要。计数还能帮助定位学习误差来自覆盖还是更新。它不是置信区间，但至少说明数值背后有多少直接证据，避免把初始化与知识混为一谈。

<a id="tabular-nav-36"></a>

### 9.13 为什么不用训练成功率选最终结论

训练行为包含探索，起点也不同于部署，因此训练成功率不是固定贪心策略的同一目标。它可反映学习期间代价，却不能替代独立部署评价。若选择检查点，也应使用预先定义验证协议，最终测试独立。本章采用固定预算末次表格，避免在测试上反复挑最好时刻。

<a id="tabular-nav-37"></a>

### 9.14 固定种子是否证明稳定

固定种子方便复现一个运行，不代表跨训练随机性稳定。完整方法比较需要多个独立训练种子，分别冻结评价，并保留失败。固定模型大量回合只能减少采样误差，不能估计重新训练变异。第四章会进一步展开多种子与分层评价，本章先建立正确单次流水线。

<a id="tabular-nav-38"></a>

### 9.15 如何验证改奖励后的实现

重新枚举每个状态动作的转移奖励，计算动态规划参照，再用手算短轨迹检查目标和终点处理。不能只改训练函数而保留旧解析值或旧断言。任务改变会影响最优策略，原来一直向右的结论未必继续成立。小模型的优势是可完整核对，应充分利用。

<a id="tabular-nav-39"></a>

### 9.16 怎样扩展到更大空间而不丢逻辑

先保持环境语义与评价协议，逐步增加状态或随机性，继续用可计算参照检验。再加入函数近似时，要明确哪些表格保证不再适用，并分别检查表示误差与更新稳定性。不要一次引入大网络、回放和复杂环境，使失败原因混在一起。每个扩展都应有对应假说、断言和独立评价。

<a id="tabular-nav-40"></a>

## 10. 手算导航价值与吸收概率

<a id="tabular-nav-41"></a>

### 10.1 最后两个位置的更新

位置五选择向右，百分之八十五立即成功，百分之十五滑回位置四。根据精确价值，位置四的贪心价值约零点八七六二五，因此该动作价值为 $`0.85\times1+0.15[-0.02+0.95\times0.87625]`$，约零点九七一八七。这个手算同时检查滑动方向、终点奖励和折扣位置，任何一个细节写错都会改变结果。

位置一选择向右则可能滑到失败终点，目标为 $`0.85[-0.02+0.95V(2)]+0.15(-1)`$，约零点三六九四二。虽然位置一右侧仍有希望，失败风险显著压低价值。这个例子帮助解释为什么训练中随机起点平均收益与固定中间起点收益不同，也说明终点附近的转移值得单独核对。

<a id="tabular-nav-42"></a>

### 10.2 成功概率的差分方程

固定一直向右的策略，令 $`h_s`$ 表示从位置 $`s`$ 最终先到六而非零的概率。边界为 $`h_0=0,h_6=1`$，中间满足 $`h_s=ph_{s+1}+qh_{s-1}`$，其中 $`p=0.85,q=0.15`$。求这个二阶差分方程，可得 $`h_s=\frac{[1-(\frac{q}{p})^s]}{[1-(\frac{q}{p})^6]}`$。当左右概率相等时，极限退化为位置除以总长度，而不是直接代入产生零除零。

这个解析式与前面的线性系统是同一对象的两种解法。它能清楚展示靠近右终点成功率更高，也能研究滑动概率变化的敏感性。若把滑动概率调到超过二分之一，意图向右反而更常实际向左，最优动作直觉会反转；必须重新求解，而不能继续套用“动作一总好”的断言。

<a id="tabular-nav-43"></a>

### 10.3 平均吸收步数的推导

每一步位置增量期望为 $`p-q`$。在适当有界停止与可积条件下，终止位置期望等于起点加漂移乘平均步数；终止位置只可能为零或六，因此可得到 $`E_s\tau=\frac{[6h_s-s]}{(p-q)}`$。这个结果与线性方程 $`(I-P)\ell=\mathbf1`$ 一致。它不是任意马尔可夫链的普适公式，而利用了本章常数方向概率与两个吸收边界。

成功概率与平均长度结合起来，可以检查模拟数据是否可信。如果成功率接近解析值但长度明显偏差，可能漏算了某些转移、终点步或自环；如果长度正确而回报不对，可能奖励或折扣索引错误。多个可解析量能够把不同错误分开，而不是只用一个最终分数判断全部代码。

<a id="tabular-nav-44"></a>

## 11. 从价值误差推断动作可靠性

<a id="tabular-nav-45"></a>

### 11.1 动作间隔与误差上界

假设所有状态动作估计误差绝对值不超过 $`e`$，某状态真实最佳动作与次佳动作差距为 $`\Delta`$。若 $`\Delta>2e`$，即使最佳动作被低估、次佳动作被高估各一个误差界，排序仍不会翻转。这个简单不等式说明，数值误差是否影响策略取决于真实动作间隔，而不是只看误差大小。

本次训练最大绝对表格误差约零点零四八四，主要来自位置一的左动作；最小真实动作间隔约零点一二六一，因此两倍误差仍小于最小间隔，足以解释所有贪心动作一致。实际大型任务往往不知道真实动作间隔和统一误差界，不能直接用经验小误差冒充这种保证。人工问题的优势正是可以完整核验。

<a id="tabular-nav-46"></a>

### 11.2 Bellman 残差与价值误差

对于折扣收缩算子，任意表格 $`Q`$ 的最优值误差可以由总体 Bellman 残差除以一减折扣控制。推导来自三角不等式与收缩：估计与真值差不超过残差加折扣倍同一差，再移项。这是总体算子残差，不是一次采样目标误差。用单个随机转移替代期望后，不能把这个确定上界直接套到噪声残差。

在本章可以枚举模型计算总体残差，并与真实误差对照。折扣接近一时上界可能较松，但仍有诊断价值。若残差明显大而动作正确，表示决策可能已稳定但数值尚未准确；若残差小却部署回报异常，优先检查评价策略、环境参数与起始分布是否与残差所用模型一致。

<a id="tabular-nav-47"></a>

### 11.3 误差集中位置的解释

位置一的左动作容易立即失败，通常不是贪心选择，有限预算下访问相对少，因此估计方差较大。它在最终部署中的影响较小，但不能完全忽略，因为环境滑动会把策略带到位置一，行为探索也可能选择左动作。报告误差位置和访问数，比只给一个最大误差更有解释力。

如果应用要求所有起点与动作都准确，可以改变数据收集或安排专门探测，但这些探测也有环境成本。若应用只关心固定策略收益，过度追求所有非使用动作精确可能浪费资源。任务目标决定需要什么证据，不能在训练后根据哪个指标好看才重新定义成功。

<a id="tabular-nav-48"></a>

## 12. 可运行实验四：解析概率与误差判据

以下代码独立核对吸收概率与平均长度的闭式公式，并演示统一误差界如何保护动作排序。它不把一次训练估计误差当成普适界，而是在已知最优表上构造严格受控的扰动，用来验证不等式本身。

```python
import numpy as np
p,q=.85,.15
states=np.arange(1,6)
ratio=q/p
hit=(1-ratio**states)/(1-ratio**6)
length=(6*hit-states)/(p-q)
P=np.zeros((5,5));rhs=np.zeros(5)
for s in range(1,6):
    for probability,ns in [(p,s+1),(q,s-1)]:
        if ns==6:rhs[s-1]+=probability
        elif ns!=0:P[s-1,ns-1]+=probability
assert np.allclose(hit,np.linalg.solve(np.eye(5)-P,rhs))
assert np.allclose(length,np.linalg.solve(np.eye(5)-P,np.ones(5)))
truth=np.array([[.1,.5],[-.3,.2],[.6,.9]])
error_bound=.09
assert np.min(np.diff(truth,axis=1))>2*error_bound
rng=np.random.default_rng(154)
for _ in range(1000):
    estimate=truth+rng.uniform(-error_bound,error_bound,truth.shape)
    assert np.array_equal(estimate.argmax(1),truth.argmax(1))
print('closed-form success',hit,'lengths',length)
print('bounded-error greedy ranking checks passed')
```

当误差超过动作间隔一半时，排序并非必然错误，只是这个充分保证不再适用。不能把充分条件的反面误当必要失败。类似地，没有观察到排序变化也不能推断误差一定很小。清楚区分充分与必要条件，有助于阅读后续更复杂的策略性能界。

## 13. 探索日程与访问证据的进一步分析

<a id="tabular-nav-50"></a>

### 13.1 为什么要看每个动作的计数

全局训练步数很大，并不保证每个动作有足够样本。策略一旦偏向向右，左动作主要依靠探索；远离训练常见位置的动作更可能稀疏。计数表能直接显示这种不平衡。本次位置一左动作只有一百七十四次，而位置四右动作超过八千次，因此两者误差与方差不应被期待相同。

按访问次数递减步长让稀疏动作保持较大更新，但无法凭空增加证据。若某状态动作一次也没有访问，步长设计没有机会发挥作用。可以通过随机起点、专门探索或改变行为日程改善覆盖，但每种设计都有成本与适用限制。对于不能重置的真实系统，覆盖问题通常比本章更困难。

<a id="tabular-nav-51"></a>

### 13.2 探索衰减的有限预算折中

早期较高探索有助于发现不同方向，后期较低探索减少当前行为损失，同时保留基本尝试。衰减过快可能锁定早期随机误判，过慢则持续承担失败代价。最佳日程依赖奖励尺度、转移概率和预算，不存在仅凭环境长度就确定的普适公式。应在验证阶段选择，并在独立种子上检查。

本章固定日程与末次检查点，没有根据评价结果动态延长某个种子。若需要比较多种日程，应报告搜索空间与预算，避免把大量搜索后的最好结果与未经调参基线比较。探索研究还应关心训练期间累计失败，而不是只看最终贪心成功率，因为学习阶段的代价在很多应用中同样重要。

<a id="tabular-nav-52"></a>

### 13.3 不同初始化的可检验影响

初始零表在本任务中对失败动作偏乐观，对成功动作偏悲观。较高初始化可能鼓励尝试尚未下降的动作，但也会产生更大早期过估计；负初始化可能使部分动作长期不被选择，具体取决于并列与探索。可以固定其他条件，只改变初始化，比较访问分布和最终误差，而不是仅报告最后成功率。

若最优动作在所有设置都学对，仍可能观察到不同样本效率和训练风险。这个现象说明成功率接近饱和时，额外指标更有区分力。反过来，如果某设置只在一个种子失败，应保留该运行，并检查早期动作与覆盖，而不是重新跑一个成功种子替换。失败轨迹往往最能揭示探索机制。

<a id="tabular-nav-53"></a>

## 14. 环境接口与程序可靠性

<a id="tabular-nav-54"></a>

### 14.1 输入范围与吸收边界

状态必须是允许位置，动作必须是定义中的两个编号。终点不应继续调用普通转移函数，否则可能越界或重复得到终点奖励。小型示例使用直接检查即可，实际系统还要考虑整数类型与布尔类型的混淆、批次形状和非法值。错误输入应尽早失败，让环境模型问题不会静默传播到训练表。

滑动概率必须在零到一之间，本章函数固定使用已定义参数。若开放配置，应显式检查范围并把配置保存。传入负概率或超过一的概率，简单比较随机数可能仍能执行，却不再表示声明的概率模型。程序能运行与统计机制有效是不同要求，环境接口应服务于后者。

<a id="tabular-nav-55"></a>

### 14.2 状态复制与评价隔离

本章表格数组直接存放在内存，评价只读。断言用副本检查评价前后不变，能够发现常见的意外学习。更复杂环境有内部随机状态、累计步数或隐藏缓存，评价隔离还需要单独环境实例与状态管理。不能只冻结神经网络参数就默认整个系统无变化。

如果插入评价消耗了训练随机数，后续轨迹会改变，使“多评一次”变成另一个训练实验。独立随机生成器解决这一类耦合。它不要求所有不同算法共享相同内部随机序列，而是确保每个流程的随机性来源可解释。复现记录应包含训练与评价种子及其分工。

<a id="tabular-nav-56"></a>

### 14.3 终点奖励与重置奖励

重置只是把环境带到起始状态，不应额外向上一回合或下一回合记入任务奖励。若系统有真实重置代价，应明确把它纳入应用目标，而不是偷偷加在环境包装器里。到达终点的奖励属于最后一次转移，吸收后不再持续奖励。多个包装层可能重复修改奖励，因此需要端到端短轨迹核验。

训练日志常同时记录折扣与未折扣回报，两者应清楚命名。未折扣奖励便于观察步长代价与终点结果，但本章优化对象是折扣回报。不能把两种曲线混在同一个标签下，也不能在理论参照使用折扣而评价报告未折扣均值后直接比较数字。

<a id="tabular-nav-57"></a>

## 15. 任务变化的系统研究

<a id="tabular-nav-58"></a>

### 15.1 改变滑动概率

增大滑动概率会降低动作控制力，改变成功概率、长度和最优价值。接近二分之一时，两动作几乎没有区别，动作间隔变小，需要更多数据可靠区分；超过二分之一时，意图方向与主要实际方向相反。这个变化适合研究动作间隔、估计误差和策略性能之间的关系。

比较时应对每个环境参数重新计算动态规划参照，再报告相对于各自最优策略的差距。不能把更难环境的低绝对分直接当作算法退步，也不能用更容易环境的高分宣称算法改进。环境难度与学习算法的变化必须分开，才能理解具体收益。

<a id="tabular-nav-59"></a>

### 15.2 改变步长代价与折扣

更大的负步长代价强调尽快结束，但可能也改变冒险与安全的权衡；更低折扣弱化远处终点收益。对于不同任务目标，最佳策略可能不再符合原先直觉。应先求解模型而非手动指定一个“合理”策略，再用采样算法学习。奖励与折扣不是单纯为了调曲线好看的数值旋钮，它们定义了任务偏好。

如果研究只想改善优化而不改变任务，可以对整个奖励统一缩放，但还要考虑步长与数值范围。统一平移每步奖励在回合长度可变时可能改变策略，不能当作无害归一化。需要保留原始任务评价，避免训练中变换后只报告放大了的奖励。

<a id="tabular-nav-60"></a>

### 15.3 改成有限时域

若规定十步内必须到达，状态可以扩展为位置与剩余步数，终止包括成功、失败和任务超时。此时同一位置在不同剩余时间下可有不同动作价值，表格大小随时间增加。动态规划可以从末时刻向前计算，而不是求一个时间无关不动点。这个扩展能清楚展示马尔可夫状态设计与任务时域的关系。

外部截断与有限时域超时虽然都让循环停止，却属于不同模型。前者通常保留尾部，后者在任务真正结束时清零。把这个差别落实到状态、奖励和目标三个层次，才能避免仅靠变量名判断。实际环境接口即使提供两个标志，也仍需要使用者正确理解任务。

<a id="tabular-nav-61"></a>

## 16. 学习曲线与可复核报告

<a id="tabular-nav-62"></a>

### 16.1 横轴与独立评价点

学习曲线横轴可以是环境交互数、回合数或计算时间，应明确选择。对不同回合长度方法，交互数通常更能反映数据预算；对不同更新成本方法，还应补充计算量。评价点使用独立固定策略回合，最好预先安排，不让评价频率改变训练随机流。曲线平滑方式也应说明，避免过强平滑掩盖失败。

如果只报告最后结果，仍应给出固定预算与停止规则。本章采用八千训练回合末次表格，未按测试表现挑检查点。后续比较若使用最佳验证检查点，应对所有方法采用相同选择规则，并在独立测试确认。选择预算是实验的一部分，不是可以省略的便利。

<a id="tabular-nav-63"></a>

### 16.2 总体平均与分层结果

从位置三部署的主要结果与均匀起点结果应分开。可以列五个起点的成功率、折扣回报和长度，观察困难位置是否有系统失败。若存在多个滑动环境参数，也可以进一步分层，但不要事后只挑有利层。分层越细，样本量越少，区间也应相应反映信息不足。

多种子结果需要区分训练变异与评价抽样误差。固定表格四千回合能精确估计该策略，但不能代替多个独立训练。若所有种子都学到同一最优动作，回报差异主要来自评价随机性；若部分种子动作不同，则应报告策略失败率与对应原因，而不是把它们平均后隐藏。

<a id="tabular-nav-64"></a>

### 16.3 成功不等于所有数字完全正确

本次实验所有贪心动作与精确最优一致，独立评价平均回报约零点七八三二，成功率约百分之九十九点四七五，平均长度约四点二一八，无评价截断。精确部署回报约零点七八二二，成功概率约百分之九十九点四五三，平均长度约四点二三九，二者在有限采样误差范围内接近。

价值表仍有小误差，最大误差集中在访问较少动作，这是有限样本正常现象。成功率不是百分之百来自环境滑动风险，而非必须修成零失败的程序缺陷。把不可避免随机失败如实保留，才能正确理解策略最优性与实际结果之间的关系。

<a id="tabular-nav-65"></a>

## 17. 下一步实验的明确问题

可以固定任务，只改变训练起始分布，观察覆盖与最终部署误差；可以固定训练策略，只改变步长指数，研究有限样本稳定与适应；也可以改变滑动概率，研究动作间隔变小时需要多少样本。每个问题都应保留相同评价协议，并重新计算需要的解析参照。

更进阶时，可以把位置压成粗糙特征或加入无关观测，比较表格与函数近似差异；也可以故意把截断清零，观察偏差如何随最大长度变化。故意构造错误版本是理解方法边界的有效方式，但应清楚标注，不能把错误实现当作某算法基线来制造改进。研究结论应来自对机制的区分，而不是来自选择一个容易击败的实现。

<a id="tabular-nav-66"></a>

## 18. 从样本学习环境模型的对照路线

<a id="tabular-nav-67"></a>

### 18.1 模型估计与直接价值更新

表格 Q-learning 不显式估计转移概率，而是把每次奖励和下一值直接用于更新。另一条路线是统计每个状态动作的下一状态频率与平均奖励，再在估计模型上做动态规划。两者都使用样本，却在信息组织与计算上不同。估计模型可以重复规划并回答其他策略问题，但需要存储转移统计，模型误差也会影响价值。

在本章环境中，每个动作只有两种结果，转移概率容易估计，可以把模型学习作为清楚基线。对同一批固定数据，比较直接 Q 更新与经验模型规划，观察误差来自稀疏转移还是反复自举。若经验模型使用全部数据多次规划，而 Q-learning 只做一次更新，计算预算不同；若模型查询免费，也要明确这是已知模拟环境的假设。

<a id="tabular-nav-68"></a>

### 18.2 稀有转移不能被零频率抹去

某个状态动作样本很少时，可能一次也没看到滑动，经验模型便会错误地当作确定转移。它在危险终点附近可能严重高估安全性。零观测不代表零概率，尤其部署需要低失败率时更要谨慎。可以使用先验平滑、区间或保守分析，但每种处理都引入额外假设，不能说是没有代价地恢复真模型。

本章训练位置一左动作只有一百多次，而某些向右动作数千次，不同转移概率估计精度自然不同。访问计数只能说明证据数量，实际不确定性还取决于转移概率和相关性。对于连续环境，类似问题更复杂：函数近似会在未见区域外推，更不能把模型输出当成已验证事实。

<a id="tabular-nav-69"></a>

### 18.3 固定数据与在线探索的差别

在线方法可以根据当前不确定性或价值选择新动作，固定离线数据则只能使用已有覆盖。如果数据从始至终只向右，左动作虽因环境滑动仍可能产生某些下一状态，但它本身的动作后果没有被直接观察，不能把“状态到过”误当“所有动作到过”。状态覆盖与状态动作覆盖是不同要求。

离线数据还可能由多个策略与环境版本混合而成。若滑动概率不同却未记录版本，同一状态动作转移不再来自单一固定核。直接合并估计会得到一个混合任务，其部署意义取决于版本分布。实验数据记录应包含必要来源信息，让后续分析知道哪些假设可以成立。

<a id="tabular-nav-70"></a>

## 19. 环境扰动与部署分布变化

<a id="tabular-nav-71"></a>

### 19.1 训练随机性不等于分布外鲁棒

在固定滑动概率下经历很多随机轨迹，只说明模型看到了该概率机制的不同实现，不代表它适应任意新滑动概率。部署概率变化会改变动作价值与最优策略。应把同分布随机评价和参数变化鲁棒性分开报告，避免将随机环境训练自动称为分布外泛化。

可以预先指定一组训练内与训练外滑动概率，冻结表格分别评价，并与每个环境自己的最优策略比较。若仍使用旧表格数值报告收益，会掩盖真实环境变化。对于当前范围内一直向右仍最优的情况，策略可能稳健但数值不校准，这再次说明策略性能与价值准确性需要分开。

<a id="tabular-nav-72"></a>

### 19.2 在线适应需要额外协议

若部署后允许继续学习，应说明探索是否重新打开、学习率是否重置、多少适应数据被允许以及适应期间失败如何计入。只报告适应后的最终结果，会忽略过程代价。旧访问计数很大时，递减步长可能过小，变化环境下适应很慢；重置计数又会增加方差，二者都有折中。

离线测试一个冻结策略与在线适应系统是不同对象，应分别命名。对于真实系统，探索可能有安全限制，不能把任意随机动作当成默认可行。人工导航允许自由试错，因此适合机制演示，但其探索资源假设不应未经说明迁移到高代价环境。

<a id="tabular-nav-73"></a>

### 19.3 感知错误与转移错误

如果位置观测偶尔错误，问题不只是滑动概率变化。智能体可能在真实位置二时以为自己在位置四，选择动作与更新索引都会受影响。位置表格不再直接对应完整状态，可能需要信念状态或历史。把这种情况仍当作普通全观测 MDP，而只调探索率，无法解决缺失信息。

一个循序渐进实验可以先加入已知观测混淆，比较使用真实状态的上界与使用观测的策略，再研究记忆或滤波。这样能隔离感知与控制误差。若直接把所有噪声都叫环境随机性，就很难判断算法失败来自转移、观测还是价值更新，后续改进也缺少针对性。

<a id="tabular-nav-74"></a>

## 20. 复现、记录与交付边界

<a id="tabular-nav-75"></a>

### 20.1 最小可复现记录

任务记录至少包含状态范围、动作含义、滑动机制、奖励、折扣、起始分布与终止语义。训练记录还需初始化、步长、探索日程、预算与随机种子分工。评价记录需冻结策略规则、起点、回合数、截断与统计方式。缺少任何一项，都可能让同一个“表格 Q-learning”名称对应不同结果。

本章实验在内存中完成，复制代码即可重建表格导航训练。扩展时可以保存 Q 表、访问次数、训练步数与随机流状态，并记录评价策略是贪心还是含探索。若结果变化，先核对奖励时点、终止处理和访问覆盖，再比较步长或探索日程；单个种子的较高分数不足以证明方法稳定优越。

<a id="tabular-nav-76"></a>

### 20.2 哪些断言值得保留

概率和为一、状态动作合法、终点值零、目标终止处理、评价不修改训练表，以及解析解和模拟接近，都是具有数学或任务含义的断言。它们能够捕获具体错误。相反，要求任何种子必须超过一个过高成功率，可能把环境随机风险误判成程序错误，也可能诱使开发者挑种子。

断言应围绕可确定的结构与合理容差，实验性能则如实报告。本章对固定预设种子作了有限质量检查，同时给出解析对照，不把它扩展成所有种子的保证。若后续更换环境难度，应重新评估性能阈值是否还有意义，而不是为了通过断言偷偷改变任务。

<a id="tabular-nav-77"></a>

### 20.3 完成标准应能被独立复核

理解本章意味着能从文字重新写出转移核，能手算一个终点附近动作值，能区分截断与终止，能实现不污染训练的评价，并能解释成功概率与折扣回报为何不同。还应能在修改滑动或奖励后重新求解参照，而不是只会运行原代码。

更进一步，应能指出一个看似漂亮结果可能隐藏什么：起点更容易、探索被关闭、评价继续学习、截断被删去、种子被挑选或模型查询未计成本。能够提出这些具体检查，并用小型实验核对，才是从演示走向研究的关键。导航的状态虽少，完整证据链与大型系统的基本要求相同。

<a id="tabular-nav-78"></a>

## 21. 更精确地分析评价截断

<a id="tabular-nav-79"></a>

### 21.1 有限观测回报的矩阵表达

冻结策略后，令 $`P`$ 为只包含非终止状态的转移子矩阵，$`r`$ 为包含到终点奖励的期望一步奖励。最多观察 $`H`$ 步的折扣回报期望为 $`u_H=\sum_{k=0}^{H-1}\gamma^kP^kr`$。完整价值满足 $`v=u_H+\gamma^HP^Hv`$，所以截断偏差具有明确尾部表达，而不是只能凭直觉认为足够小。

这里的 $`P`$ 行和可以小于一，缺失概率正是进入吸收终点的质量。因此 $`P^H`$ 自动只保留仍未结束的路径。若粗略奖励绝对值不超过一，可以用折扣几何级数给出统一尾部界；但该界可能很松，因为它忽略绝大多数路径已经终止。使用吸收子矩阵能够得到更贴近本任务的分析。

<a id="tabular-nav-80"></a>

### 21.2 成功率截断的对应关系

设 $`b`$ 是一步进入成功终点的概率向量，最多 $`H`$ 步内成功概率为前 $`H`$ 项的非折扣矩阵和，完整吸收概率满足 $`h=h_H+P^Hh`$。因此未观察到终止的质量会影响有限预算成功率。把所有截断都记为失败，得到的是预算内成功率，不是无限时间最终成功概率，两者应分别命名。

如果真实应用就是规定时间内必须成功，预算内成功率可能正是主要指标；但本章原任务没有硬截止，所以用它替代最终吸收概率需要说明。数学表达能够把任务改变与估计偏差分清，也能指导选择足够长的评价预算。不能仅因为训练用了八十步，就默认任何任务评价也应使用同样长度。

<a id="tabular-nav-81"></a>

### 21.3 零次截断观察的解释

本次四千个独立评价回合没有截断，说明在这次样本中未见到长于八十步的路径，不能直接推断其概率严格为零。已知模型时可以通过 $`P^{80}`$ 计算真正尾部质量；未知模型时则需要根据样本量表达不确定性。这个区别适用于所有罕见失败统计，而不只是导航。

实际报告可以同时给出预算内结果、截断数量与可用的解析尾部说明。若尾部不小，应延长评价或明确采用有限预算任务，不要删除未完成回合来提高平均。清楚处理极少数困难路径，往往比让主曲线更平滑更能体现评价的可靠性。

在后续复现中，建议先运行所有解析核验，再运行训练与评价。这样若模型参数、奖励或转移配置被修改，参照不一致能尽早暴露。记录结果时保留足够有效数字用于比较即可，不要把打印精度误认为统计精度。评价回报的微小差异应结合独立回合波动与训练种子变化解释。

本章的五段独立代码分别承担模型、完整训练、吸收评价、终止截断反例与闭式判据核验。它们没有依赖前一段遗留变量，能够单独复制执行。阅读时也可以按这个顺序逐步检查，每段都说明自己验证了什么以及没有验证什么，从而把一套小型导航实验真正学成可复用的方法。
