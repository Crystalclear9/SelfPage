## 1. 探索与多步学习解决不同问题

探索决定哪些状态动作会被观察，多步回报决定已经观察到的奖励怎样传播到价值估计。资格迹又提供一种把过去访问与当前误差连接起来的高效实现。三者常被放在同一训练循环里，但不能相互替代：没有探索覆盖，多步目标不会创造没见过动作的证据；回报传播过慢，也不能仅靠随机行动解决。

本章在固定策略预测与控制之间保持清楚区分。先讨论探索分布，再推导有限轨迹上的多步与 lambda 回报恒等式，最后解释离策略概率校正及其方差代价。前向后向等价有明确条件，特别是普通在线参数变化时不能直接套用冻结参数的证明。代码使用人工轨迹与小型决策问题，避免环境复杂度遮盖这些核心边界。

<a id="explore-trace-2"></a>

### 1.1 数据覆盖与决策质量

一个状态出现很多次，不代表每个动作都被尝试；某动作被尝试，也不代表后续关键路径有覆盖。稀有奖励可能需要连续一串动作，逐步都有正概率仍可能在有限预算下极难遇到。因此探索评价应包括状态动作计数、关键路径触达与训练期间代价，而不是只列一个探索率。

同时，更多随机动作不总是更好。它可能增加失败与资源消耗，也可能把大量数据花在无关区域。应用若关心学习期间安全与累计收益，就需要把这些代价作为目标或约束。最终贪心性能高，不会自动抵消学习时的危险行为；反过来，探索期回报低也不必然说明最终知识没有改善。

C：第二次访问、步长零点一、TD误差零点五时，累积迹增量零点零八六，替换迹零点零五，错误计数二则给零点一。迹规则、离策略修正及回合重置必须匹配算法定义，固定参数下的前后向恒等式也不能直接保证任意在线实现等价。

## 2. 常见探索策略与条件

<a id="sec-1-1"></a>

<a id="explore-trace-4"></a>

### 2.1 epsilon-greedy 与并列动作

探索分支均匀抽动作，利用分支在最大值动作集合中按规定分配概率。若唯一最佳动作，它的总概率包含利用与探索两部分。并列动作若总选最小编号，会产生未声明方向偏好；随机打破并列可保持对称，但仍不能保证长路径有效探索。概率定义应精确到动作层，方便后续重要性比率计算。

探索率趋零不自动保证充分访问。若某个关键状态需要连续多次探索才能到达，过快衰减可能让访问总数有限。所谓逐渐贪心且无限探索需要对整个状态动作过程成立，不是只把全局探索率写成时间倒数就完成证明。有限实验也应直接检查覆盖，而不是用渐近术语代替计数。

**为什么每步都还有探索，深层状态却可能永远见不到？** 构造固定两步回合：第一步必须选非贪心动作右，才进入第二个决策状态；第二步也必须选非贪心动作右，才到达目标，其余动作立即失败。两个状态各有两个动作，固定的贪心分支都选左；第 $`k`$ 回合两个位置使用相同预设探索率 $`\varepsilon_k=\frac{1}{k}`$，探索时均匀抽动作。每回合成功的概率精确为

$$
p_k=(\frac{\varepsilon_k}{2})^2=\frac1{4k^2}.
$$

初始状态每回合都会访问，选择右的概率和 $`\sum_k\frac{1}{(2k)}`$ 发散；但目标路径的访问概率和 $`\sum_kp_k`$ 收敛。由第一 Borel–Cantelli 引理，目标路径几乎必然只出现有限次，因而不能满足第二个决策状态上右动作的无限访问要求。这个结论甚至不需要各回合相互独立。

“有限次”也可能是零次。用联合界及 $`\sum_{k=2}^{\infty}k^{-2}\le\int_1^{\infty}x^{-2}dx=1`$，可得一生中至少成功一次的概率不超过 $`\sum_kp_k\le\frac{1}{2}`$，所以永远没到达目标的概率至少为 $`\frac{1}{2}`$。这是保守下界，已经足以说明风险；无需把每个时刻非零探索误当成最终必达。若各回合独立，前 $`K`$ 回合全未到达的概率还可精确写成 $`\prod_{k=1}^K(1-\frac{1}{(4k^2)})`$。

这里固定贪心分支以隔离采样机制，并未断言所有使用 $`\frac{1}{k}`$ 日程的学习算法都会失败；学习后动作偏好可能改变。它证明的是仅凭全局探索率趋零、甚至其和发散，仍不足以推出整个受控过程的无限覆盖。证明 GLIE 时必须落实到相关状态动作访问，有限预算时则应直接查看深层路径的实际计数。

<a id="explore-trace-5"></a>

### 2.2 Boltzmann 选择与温度

以 $`\exp(\frac{Q(s,a)}{\tau})`$ 归一化得到动作概率，可以让较好动作更常被选，同时保留其他动作。温度较小分布更集中，较大更平坦。计算时先减去最大 logit，避免指数溢出。奖励缩放会改变 Q 尺度，因此相同温度并不具有跨任务相同探索强度；必须结合价值单位解释。

Boltzmann 依据估计值而非可信不确定性选择，早期错误高估仍可能垄断概率。它也不保证罕见动作在实际数值精度下得到足够采样。温度衰减、初始化和环境可达性共同影响结果。不能把平滑概率形式自动等同于更聪明探索，需要在共同交互预算下评价覆盖与收益。

<a id="explore-trace-6"></a>

### 2.3 乐观初始化与置信上界

乐观初始化用高初值鼓励尝试尚未被数据压低的动作，依赖奖励范围和更新方式。置信上界则尝试把估计值与不确定性奖励结合，在某些多臂老虎机假设下有清楚理论。把一个简单动作计数奖励直接用于一般 MDP，不会自动继承老虎机结论，因为动作影响后续状态，访问数据也相互依赖。

状态计数、模型分歧和预测误差可以作为探索信号，但各自有盲区。例如不可预测环境噪声可能持续产生高预测误差，吸引智能体反复访问却不增加有用知识。探索奖励与原始任务奖励应分别记录，最终评价回到原任务，防止把内部新奇分数误当实际收益。

## 3. 可运行实验一：探索概率与数值稳定

下面核对 epsilon-greedy 的概率质量、并列动作分配以及稳定 softmax 的边界。它是动作选择器检查，不声称证明某个 MDP 上的全局探索充分。对同一动作值整体加常数不应改变 softmax，但缩放会改变相对温度。

```python
import numpy as np

def epsilon_probs(values,epsilon):
    values=np.asarray(values,dtype=float)
    assert 0<=epsilon<=1
    p=np.full(len(values),epsilon/len(values))
    best=np.flatnonzero(values==values.max())
    p[best]+=(1-epsilon)/len(best)
    return p

def softmax(values,temperature):
    if np.iscomplexobj(values):
        raise ValueError('real action values required')
    values=np.asarray(values,dtype=float)
    if values.ndim!=1 or not values.size or not np.isfinite(values).all():
        raise ValueError('nonempty finite action-value vector required')
    if not np.isscalar(temperature) or np.iscomplexobj(temperature):
        raise ValueError('finite positive scalar temperature required')
    if not np.isfinite(temperature) or temperature<=0:
        raise ValueError('finite positive scalar temperature required')
    # 先平移再除温度；直接 Q/temperature 可能在平移前溢出。
    with np.errstate(over='ignore',under='ignore'):
        logits=(values-values.max())/temperature
        e=np.exp(logits)
    return e/e.sum()
p=epsilon_probs([1.,2.,2.],.3)
assert np.allclose(p,[.1,.45,.45]) and np.isclose(p.sum(),1)
a=softmax([10000.,10001.,9999.],.7)
b=softmax([0.,1.,-1.],.7)
assert np.allclose(a,b) and np.isfinite(a).all()
assert softmax([0.,1.],.1)[1] > softmax([0.,1.],1.)[1]
assert np.array_equal(softmax([1e308,1e308],.1),[.5,.5])
assert np.array_equal(softmax([1e308,-1e308],.1),[1.,0.])
assert np.array_equal(softmax([2.,1.],np.nextafter(0.,1.)),[1.,0.])
for invalid in (0.,-1.,np.nan,np.inf):
    try:
        softmax([0.,1.],invalid)
    except ValueError:
        pass
    else:
        raise AssertionError('invalid temperature accepted')
print('epsilon probabilities',p,'stable softmax',a)
```

稳定化顺序也重要：若先计算 $`\frac{Q}{\tau}`$ 再减最大值，即使所有输入有限，也可能先溢出为正无穷，随后出现无穷减无穷。这里先减原始最大值再除正温度，最大项始终为零；很负的差即使溢出为负无穷，指数也只是零，不会破坏至少一个最大项的指数为一。对 $`Q=(10^{308},10^{308})`$、温度零点一，结果应为 $`(\frac{1}{2},\frac{1}{2})`$；对一正一负的极端值，结果在机器精度下集中于最大项。示例用这两种情况和最小正浮点温度检查顺序，未把所有下溢都当作错误。

即使数学概率正数，浮点数下极小概率也可能下溢为零。若方法依赖严格支持，需要监测这种情况，或采用合适最小探索概率与稳定采样。任何概率下限都改变行为分布，应在重要性采样时使用实际实现概率，而不是理想未截断公式。

## 4. n 步回报的完整定义

<a id="explore-trace-9"></a>

### 4.1 非终止尾部与提前终止

从时刻 $`t`$ 开始，若未来至少还有 $`n`$ 次非终止转移，目标为 $`G_t^{(n)}=\sum_{k=0}^{n-1}\gamma^kR_{t+k+1}+\gamma^nV(S_{t+n})`$。若真正终止发生在此前，就只累加到终止，尾部为零。如果只在片段边界截断，仍需根据任务保留尾部估计。回报长度不是训练批次长度，二者不能混淆。

一步使用一个真实奖励加估计未来，完整回合使用全部真实奖励。步数增加改变自举误差、采样噪声、等待时间和存储，并不保证总体均方误差单调下降。最合适长度依赖奖励噪声、状态结构和当前估计质量，应在独立验证中比较，而不是只凭“更接近 MC”判断优劣。

<a id="explore-trace-10"></a>

### 4.2 用 TD 误差展开 n 步回报

固定一套价值函数，定义 $`\delta_k=R_{k+1}+\gamma V(S_{k+1})-V(S_k)`$，真正终止状态价值为零。展开折扣和后中间价值相消，得到 $`G_t^{(n)}-V(S_t)=\sum_{k=t}^{t+n-1}\gamma^{k-t}\delta_k`$。这是一个有限代数恒等式，而非近似结论。

关键条件是这些误差和目标使用同一套固定价值。如果每一步更新参数后重新计算误差，中间相消不再按同一个函数成立。普通在线算法仍可能有效，但不能用冻结参数恒等式证明它逐步完全相等。这个区别将在前后视资格迹关系中再次出现。

<a id="explore-trace-11"></a>

### 4.3 延迟与缓存

在线 n 步更新需要等待足够奖励，并保存最近状态、动作和奖励。回合提前终止时还要把剩余起点的短目标补完，否则最后若干状态永远少更新。截断片段若采用自举，末状态价值应来自明确检查点或当前估计，算法定义要一致。实现越向量化，越容易遗漏边界补算。

可以先手工构造短轨迹，列出每个起点的目标，再写缓存代码。测试应包含比 n 更短的回合、恰好 n 步、重复状态和外部截断。仅在长确定轨迹上运行通过，不能覆盖这些最容易出错的边界。

## 5. lambda 回报：对多种长度作明确加权

<a id="explore-trace-13"></a>

### 5.1 有限回合的权重归一化

设从当前起点到真正终止还有 $`H`$ 步。定义 $`G^\lambda=(1-\lambda)\sum_{n=1}^{H-1}\lambda^{n-1}G^{(n)}+\lambda^{H-1}G^{(H)}`$，其中 $`0\le\lambda\le1`$。最后完整回报项的权重不是再乘一减 lambda，因为它承接所有更长长度的剩余概率质量。所有权重和为一。

当 lambda 为零时只剩一步目标，为一时只剩完整回报。有限公式避免了对无穷和收敛的额外讨论，但终止和截断仍需区分。对截断片段，可以把最后长度的目标设为带末状态自举的有限目标，这时 lambda 为一也只是片段多步自举，并非真正完整 MC。

<a id="explore-trace-14"></a>

### 5.2 展开为衰减 TD 误差和

将每个 n 步目标的 TD 误差展开代入，加权交换有限求和，某个未来误差获得所有覆盖它的长度权重之和，恰好得到相应 lambda 次方。因此 $`G_t^\lambda-V(S_t)=\sum_{k=t}^{T-1}(\gamma\lambda)^{k-t}\delta_k`$，其中同样要求固定价值与正确终止边界。

这个恒等式解释了 lambda 如何控制未来误差对当前状态的影响。它不是说 lambda 就是另一个折扣，因为环境回报仍按 gamma 定义，lambda 是估计器把不同长度组合起来的参数。改变 lambda 通常改变偏差方差与传播速度，不应被误写成改变任务偏好。

<a id="explore-trace-15"></a>

### 5.3 极端值的理解

lambda 接近一会让较远误差影响更长，通常需要更长记忆并可能带入更多采样噪声；接近零则更局部，依赖尾部估计。若 gamma 也接近一，迹衰减很慢，重复访问可能累计较大更新。步长需要与这些尺度共同考虑，不能只更改 lambda 后期待同样稳定。

不同方法可能使用替换迹或截断迹来控制数值与重复访问，它们不是简单改变同一个标量。比较时应写清楚迹定义、清除时机和步长，而不是只给一个 lambda 数值。算法名相近不代表有限更新完全一致。

<a id="visual-insight-valuebasedmethods-03"></a>
### 深入图解：有限回合 lambda 回报的最后一项吸收剩余权重

![有限回合 lambda 回报的最后一项吸收剩余权重](images/03-insight.svg)

对还剩四步并真正终止的轨迹，前三种长度的权重为一减 lambda 再乘相应幂次，最后完整回报的权重直接取 lambda 的三次方。lambda 为零点五时依次为零点五、零点二五、零点一二五、零点一二五，总和为一。若误把最后一项也乘一减 lambda，总和会少掉尾部质量。图针对有限终止回合的前向定义，外部片段截断、自举尾值、离策略校正及在线参数变化需要按对应规则处理，不能把这个固定目标恒等式直接套到任意实现。

## 6. 后向资格迹与冻结参数等价

<a id="explore-trace-17"></a>

### 6.1 累积迹更新

对线性特征 $`\phi_t`$，累积迹为 $`e_t=\gamma\lambda e_{t-1}+\phi_t`$，初始为零。当前 TD 误差乘这个迹，等于同时影响最近出现的特征，影响随时间指数衰减。表格特征是对应状态的独热向量，所以迹可以理解为带衰减的访问记忆，而不是概率分布。

若同一状态反复出现，累积迹会叠加，不一定小于一。替换迹通常把当前访问状态的迹设为一，改变了重复访问的处理，不能自动使用累积迹证明。迹也应在真正回合边界按算法规定清理；若把外部片段边界当作新任务清迹，会改变跨片段信用传播，需明确这是近似还是新的协议。

<a id="explore-trace-18"></a>

### 6.2 离线前后视等价的推导

固定参数计算整条轨迹的 TD 误差，再把每步后向更新累计为 $`\alpha\sum_t\delta_te_t`$。展开迹并交换求和，得到每个过去特征乘以未来折扣 lambda 误差和。根据上一节恒等式，它恰好等于 $`\alpha\sum_t[G_t^\lambda-V(S_t)]\phi_t`$。这是离线冻结参数前向目标与后向累积迹的精确等价。

如果边走边更新参数，后续 TD 误差使用更新后的价值，前向目标也可能因参数变化而变化，简单离线证明不再直接适用。小步长下差异可能较小，但不能被描述成严格逐步一致。真在线方法引入额外修正，正是为了在相应线性设置下实现更精确的在线前向视图对应。

<a id="explore-trace-19"></a>

### 6.3 真在线与普通在线的区别

真在线 TD 的荷兰迹与权重修正包含步长、当前特征与旧迹的内积，同时使用前后时刻预测差的校正。这些项不是为了装饰公式，而是补偿参数在线变化对前向视图的影响。将普通累积迹直接改名真在线，并不能获得相应等价性质。

本章重点实跑冻结参数恒等式，并用反例比较普通在线结果。若进一步实现真在线算法，应核对原始定义、价值缓存时刻和终止处理，再在每个前缀上与相应在线前向视图比较。仅比较整回合最后值接近，不足以证明逐步等价。

## 7. 可运行实验二：n 步、lambda 与后向迹

人工轨迹包含重复状态，所有价值固定。代码分别计算各长度回报、有限 lambda 混合以及 TD 误差形式，再检查离线向量更新一致。它还显式展示截断尾部非零时，最长目标仍不是完整终止回报。

```python
import numpy as np
states=np.array([0,1,0,2,3])
rewards=np.array([1.,-.5,2.,3.])
values=np.array([.2,-.1,.7,0.])
gamma=.9;lam=.65;H=len(rewards)
def n_return(t,n,tail):
    stop=min(t+n,H)
    total=sum(gamma**(k-t)*rewards[k] for k in range(t,stop))
    return total+gamma**(stop-t)*tail[states[stop]]
delta=rewards+gamma*values[states[1:]]-values[states[:-1]]
forward=np.zeros(4)
for t in range(H):
    remaining=H-t
    mixture=sum((1-lam)*lam**(n-1)*n_return(t,n,values)
                for n in range(1,remaining))
    mixture+=lam**(remaining-1)*n_return(t,remaining,values)
    telescoping=values[states[t]]+sum((gamma*lam)**(k-t)*delta[k]
                                     for k in range(t,H))
    assert np.isclose(mixture,telescoping)
    forward[states[t]]+=mixture-values[states[t]]
trace=np.zeros(4);backward=np.zeros(4)
for t in range(H):
    trace*=gamma*lam;trace[states[t]]+=1
    backward+=delta[t]*trace
assert np.allclose(forward,backward)
truncated=values.copy();truncated[3]=5.
assert np.isclose(n_return(0,H,truncated)-n_return(0,H,values),gamma**H*5)
print('offline forward/backward increment',forward)
```

最后状态在主实验中是真正终止且价值零，截断示例则人为赋予非零尾部，展示目标的语义变化。重复状态使累积迹叠加，如果把代码改成替换迹，前后视向量不再一般相等，正好可以作为方法差异的反例。任何修改都应准确标注，而不是为了通过同一断言而混淆算法。

## 8. 离策略重要性采样的动作范围

<a id="explore-trace-22"></a>

### 8.1 状态价值轨迹比率

目标策略为 $`\pi`$，行为策略为 $`b`$，要求目标正概率动作在行为下也有正概率。给定起始状态，从时刻 t 到回合结束的路径似然比中，环境转移与奖励核抵消，剩下动作概率比乘积 $`\rho_{t:T-1}=\prod_{k=t}^{T-1}\frac{\pi(A_k\mid S_k)}{b(A_k\mid S_k)}`$。这个比率可用于把完整回报的行为期望转换成目标期望。

若只估计 n 步状态价值目标，奖励与末状态受前 n 个动作影响，因此对应动作范围是 t 到 t 加 n 减一。若估计动作价值并已条件固定当前状态动作，当前动作概率不再需要校正，范围从 t 加一开始。把状态价值与动作价值的比率范围混用，会产生多乘或少乘一项的错误。

<a id="explore-trace-23"></a>

### 8.2 普通与加权估计

普通重要性估计用比率乘回报再求平均，在支持与可积条件下可以无偏，但方差可能很大。加权形式把比率回报之和除以比率之和，通常具有有限样本偏差，却可能更稳定；如果分母为零，需要明确处理。不能把“归一化后看起来更稳”说成同时拥有所有无偏性质。

比率乘积随路径增长可能极端集中，少数轨迹主导结果。权重截断会限制极端比率贡献，却通常引入偏差；估计量方差是否降低，取决于权重与回报的联合分布，不能仅凭权重上限变小就判断。截断阈值需要按偏差、方差及均方误差验证。行为概率必须来自实际采样机制，包括并列、探索下限和任何数值修正。事后只根据当前 Q 表推测旧行为概率，通常不足以恢复真实路径比率。

<a id="explore-trace-24"></a>

### 8.3 每决策校正

某个早期奖励只受到它之前动作影响，不应无必要地乘上更远未来动作比率。每决策重要性采样利用这个条件结构，对不同奖励项使用相应前缀比率，常能避免一些无关方差。尾部自举项则需要覆盖影响末状态分布的相应动作范围。具体算法若还有控制变量或目标策略期望，必须重新推导，不能只记“少乘几个比率”。

终止时最后动作是终止前的动作，终止状态没有额外动作比率。外部截断后的尾部估计依赖所选择目标，并不自动等于完整目标策略回报。把终止状态虚构一个动作再乘比率，会让本来正确的有限轨迹校正失去意义。

<a id="visual-example-valuebasedmethods-03"></a>

### 图解算例：轨迹重要性权重：乘积增长、稀有事件与期望校正

![轨迹重要性权重：乘积增长、稀有事件与期望校正](images/03-example.svg)

A：目标与行为在每步选择该动作的概率分别零点八、零点二，这条动作串的每步比率为四，三步权重为六十四。

B：与此同时，该串在行为下越来越稀有，三步概率只有零点零零八，目标下为零点五一二。

C：行为事件概率乘其权重恢复目标贡献，零点零零八乘六十四等于零点五一二；有限样本可能很少看到这种事件，因此方差问题仍严重。并非所有轨迹的权重都增长，完整似然比在适当条件下期望为一。若目标支持在行为下为零，不能用无限权重创造证据，状态价值与已固定动作价值的校正起点也不同。

## 9. 可运行实验三：普通与加权重要性估计

一回合只有一次动作，行为选奖励一动作的概率为零点零五，目标概率为零点八。两动作奖励分别为零和一，真实目标价值为零点八。用许多独立十轨迹数据集比较估计器，能够直接观察普通估计高方差与加权估计有限样本偏差，而不混入网络优化。

```python
import numpy as np
rng=np.random.default_rng(161)
runs,n=30000,10
chosen=rng.random((runs,n))<.05
reward=chosen.astype(float)
ratio=np.where(chosen,.8/.05,.2/.95)
ordinary=(ratio*reward).mean(axis=1)
weighted=(ratio*reward).sum(axis=1)/ratio.sum(axis=1)
truth=.8
assert abs(ordinary.mean()-truth)<.04
assert ordinary.var()>weighted.var()
assert weighted.mean()<truth-.1
assert np.isclose(.05*16+.95*(.2/.95),1)
print('ordinary mean/variance',ordinary.mean(),ordinary.var())
print('weighted mean/variance',weighted.mean(),weighted.var(),'truth',truth)
print('fraction with no rewarding behavior action',np.mean(~chosen.any(axis=1)))
```

很多十样本数据集根本没有见到奖励动作，加权估计在这些数据集里为零，偏差很明显。支持存在只说明理论上可校正，不保证有限数据有足够证据。若行为完全不选该动作，支持条件失效，任何有限比率都无法恢复目标价值，这不是增加网络容量能解决的问题。

## 10. 十六道练习与详细答案

<a id="sec-7-1"></a>

<a id="explore-trace-27"></a>

### 10.1 探索率趋零是否足够

不够。需要状态动作层面的充分访问，关键状态可能需要连续探索才能到达。全局探索率趋零不保证这些路径总概率足够。应检查可达性、衰减速度和实际覆盖。有限预算下更应报告计数与关键奖励触达，而不是仅引用一个探索公式。

<a id="explore-trace-28"></a>

### 10.2 温度与奖励尺度有什么关系

softmax 使用价值除以温度，奖励缩放会改变价值尺度，因此相同温度不再对应相同动作分布。整体平移值会抵消，整体缩放则不会。比较温度策略应固定奖励单位或相应调整温度，并报告实际动作概率，避免把尺度差异误认成探索方法差异。

<a id="explore-trace-29"></a>

### 10.3 n 步越大是否总更准

不是。更多真实奖励替代自举，可能减少某些估计偏差，却增加采样噪声与等待。最优长度依赖当前价值质量与环境随机性。应在相同数据与预算下比较独立价值误差或策略收益，不能仅因为接近 MC 就宣布更好。

<a id="explore-trace-30"></a>

### 10.4 终止前不足 n 步怎么办

累加到真正终止，尾部为零，不再等待不存在的奖励。回合末尾还需要补算剩余起点目标。若只是片段截断，则采用明确末状态自举。把两类边界统一清零会改变任务，忽略末尾补算则会让后半轨迹系统性少更新。

<a id="explore-trace-31"></a>

### 10.5 lambda 最后一项为什么特殊

有限回合里最后完整回报承接所有更长长度的剩余权重，所以系数为 lambda 的相应幂，不再乘一减 lambda。这样权重和为一，lambda 为一时完整回报仍保留。若每项都乘一减 lambda，边界时会丢质量，极端值也错误。

<a id="explore-trace-32"></a>

### 10.6 lambda 等于一是否永远是 MC

只有最长目标确实到达任务终止且尾部为零时才对应完整回报。外部截断片段的最长目标仍含尾部估计，lambda 为一只是该片段多步自举。必须看边界语义，不能只凭参数值给算法命名。

<a id="explore-trace-33"></a>

### 10.7 资格迹能否当概率

不能。累积迹是衰减访问记忆，重复访问会叠加，可能超过一。它的作用是分配当前 TD 误差影响，不要求归一化。替换迹有另一种数值规则，不能因为数值较受限就把它视作同一算法的稳定实现而不说明。

<a id="explore-trace-34"></a>

### 10.8 冻结参数为什么重要

前后视等价利用同一价值函数展开 TD 误差并让中间项相消。在线更新后各时刻价值不同，简单恒等式不再直接成立。普通在线算法仍可有效，但严格逐步对应需要额外修正。证明条件与实现条件必须一致。

<a id="explore-trace-35"></a>

### 10.9 普通在线是否就是真在线

不是。真在线方法有特定迹与权重校正，补偿参数变化。普通累积迹直接在线更新，不自动满足同样前向视图。应查原始算法并在每个轨迹前缀核对，不能仅因整回合结果接近就宣称精确等价。

<a id="explore-trace-36"></a>

### 10.10 为什么动作价值少乘当前比率

因为估计对象已经条件固定当前状态动作，当前动作来源概率不影响条件后的未来环境分布。未来行为动作仍需按目标校正。状态价值没有固定当前动作，因此比率从当前开始。写清条件事件就能避免机械背诵范围。

<a id="explore-trace-37"></a>

### 10.11 支持存在是否数据就够

不。行为虽给目标动作正概率，但概率极小时有限数据可能完全没有相关轨迹，估计方差也可能极大。支持是可识别与校正的必要基础，不是有限精度保证。应报告有效权重、关键轨迹数量和不确定性。

<a id="explore-trace-38"></a>

### 10.12 加权重要性为何有偏

随机分子除以随机分母，其期望一般不等于期望之比。归一化可降低某些极端尺度影响，但有限样本偏差仍在。渐近一致也不意味着十个样本就接近真值。应根据数据量、支持与方差选择，并准确报告性质。

<a id="explore-trace-39"></a>

### 10.13 截断权重是否无害

它减少极端比率贡献，通常改变期望并引入偏差。阈值越低不一定实际误差越小，需要比较偏差方差和下游用途。不能一边截断一边继续声称原普通重要性估计严格无偏。若有补偿项，应完整写出推导。

<a id="explore-trace-40"></a>

### 10.14 迹应何时清零

真正新回合通常清零，避免把不相关起点连接。外部片段边界若任务连续，清迹会改变跨片段传播，需要明确近似协议。离策略控制还可能因非贪心动作采用特定清迹规则，不同算法定义不同，不能统一套用。

<a id="explore-trace-41"></a>

### 10.15 多步离策略只在尾部取最大够吗

一般不够，中间奖励与状态来自行为动作，路径分布已改变。需要相应概率校正或专门目标。末尾最大值只处理尾部动作选择，不能修正此前整条路径。一步 Q-learning 的便利不能无条件推广到任意 n 步。

<a id="explore-trace-42"></a>

### 10.16 怎样验证新资格迹实现

先在固定参数短轨迹上核对前后视恒等式，加入重复状态、提前终止和截断。再明确在线版本是否需要真在线修正，按前缀比较。最后在已知小 MDP 上测试独立价值误差与多个种子，而不是只看训练回报曲线。

## 11. 把有限轨迹恒等式逐项展开

<a id="sec-6-1"></a>

<a id="explore-trace-44"></a>

### 11.1 三步轨迹的手算权重

假设到终止还剩三步，lambda 混合权重依次为一减 lambda、lambda 乘一减 lambda，以及 lambda 平方。一步目标误差只含当前 TD 误差，两步目标误差含当前与折扣下一误差，三步还包含第二次折扣的末误差。收集同一误差系数后，当前误差总权重为一，下一误差系数为 gamma 乘 lambda，最远误差系数为二者乘积的平方。

这份手算能够发现常见的最后权重错误。如果末项也乘一减 lambda，当前误差权重就小于一，lambda 等于一时全部消失。有限回合的剩余质量处理不是可省略细节，它保证混合确实是归一化的长度分布。实现时先检查权重和，再检查各边界值，通常比直接跑复杂环境更容易定位问题。

<a id="explore-trace-45"></a>

### 11.2 截断轨迹上的精确对象

若三步后不是终止而是数据片段结束，最后三步目标仍包含末状态价值。此时同样的有限权重恒等式可以成立，但它对应的是片段自举混合，而不是完整回合混合。末状态值如果来自不同参数检查点，需把它当成明确外部尾部，后向误差也要与之保持一致，不能混用当前网络随意重新计算。

不同并行环境可能在不同时间终止或截断，向量实现需要逐样本掩码。一个环境完成不代表整批迹都应清零，反之也不能让结束环境的迹流入新回合。批次轴和时间轴应明确，尤其将轨迹展平后容易误把相邻内存记录当成同一连续路径。资格迹依赖真实时序，不能无条件随机打乱。

<a id="explore-trace-46"></a>

### 11.3 重复状态与特征共享

一个状态在轨迹中多次出现，前向视图为这些访问分别计算目标，再把更新累加到同一表格项。后向累积迹恰好把过去多次访问的衰减贡献叠加，因此冻结参数时等价仍成立。若改成只保留最后访问、首次访问或替换迹，就改变了对应前向权重，不能继续引用原证明。

线性特征共享时，向量迹同样累加特征，而不只是状态编号。非正交特征会让一个误差同时影响多个状态预测，可能提高泛化也可能传播错误。严格等价的代数与最终稳定性是不同问题：向量更新前后视相同，不保证所用采样分布和步长下算法收敛。

<a id="explore-trace-47"></a>

## 12. 可运行实验四：普通在线与离线更新并不相同

沿用含重复状态的短轨迹，先固定初始价值计算离线累积更新，再真正逐步更新价值和迹。有限步长下两个最终向量不同。实验不是证明在线方法错误，而是反驳不加条件的“任何实现完全等价”。末状态价值保持零，避免把终止问题混入比较。

```python
import numpy as np
states=[0,1,0,2,3];rewards=[1.,-.5,2.,3.]
gamma=.9;lam=.65;alpha=.2
initial=np.array([.2,-.1,.7,0.])
offline=np.zeros(4);trace=np.zeros(4)
for t,r in enumerate(rewards):
    delta=r+gamma*initial[states[t+1]]-initial[states[t]]
    trace*=gamma*lam;trace[states[t]]+=1
    offline+=delta*trace
fixed_final=initial+alpha*offline
online=initial.copy();trace=np.zeros(4)
for t,r in enumerate(rewards):
    delta=r+gamma*online[states[t+1]]-online[states[t]]
    trace*=gamma*lam;trace[states[t]]+=1
    online+=alpha*delta*trace
assert not np.allclose(fixed_final,online)
assert fixed_final[-1]==0 and online[-1]==0
print('frozen offline final',fixed_final,'ordinary online final',online)
```

若步长非常小，二者差异可能缩小，但有限步长下的接近不是严格恒等。研究真在线方法应针对相应在线前向目标作比较，而不是拿冻结参数整回合目标当它必须等于的对象。前向视图本身也有不同版本，阅读论文时应先核对定义，再判断等价性声明。

<a id="explore-trace-48"></a>

## 13. 完整实验：随机游走中的 TD(lambda)

<a id="explore-trace-49"></a>

### 13.1 环境与真实价值

位置零和六为终点，中间每步等概率向左或向右，只有进入右终点奖励一，其余奖励零。回合从位置三开始，折扣为一，最终几乎必然吸收。这个对称随机游走的真实价值为位置除以六，可由吸收概率方程直接证明。它不是一般无折扣继续任务，而是回报有界的回合预测问题。

固定策略与环境，不做控制，便能隔离资格迹对预测学习的影响。比较 lambda 零、零点七和一，使用相同训练回合数量、步长与预定义种子集合。每次训练完成后直接与解析价值计算均方根误差，不需要另抽评价回合，因此评价随机性不混入结果。所有种子都保留，不要求某个 lambda 永远胜出。

<a id="explore-trace-50"></a>

### 13.2 可独立运行的多种子代码

```python
import numpy as np
truth=np.arange(7,dtype=float)/6
truth[[0,6]]=0. # Terminal entries represent future value after arrival.

def train(lam,seed,episodes=300):
    rng=np.random.default_rng(seed)
    value=np.zeros(7);alpha=.04
    for _ in range(episodes):
        s=3;trace=np.zeros(7)
        while s not in (0,6):
            ns=s+(1 if rng.random()<.5 else -1)
            reward=1. if ns==6 else 0.
            done=ns in (0,6)
            delta=reward+(0. if done else value[ns])-value[s]
            trace*=lam;trace[s]+=1
            value+=alpha*delta*trace
            value[[0,6]]=0.
            s=ns
    assert np.isfinite(value).all()
    return np.sqrt(np.mean((value[1:6]-truth[1:6])**2))
results={lam:np.array([train(lam,seed) for seed in range(171,183)])
         for lam in [0.,.7,1.]}
for lam,error in results.items():
    assert error.shape==(12,) and np.isfinite(error).all()
    print('lambda',lam,'mean RMS',error.mean(),'all seed errors',error)
print('all trials retained; no universal winner assertion')
```

终点数组项设零表示到达之后的未来价值，右端奖励已经在转移上发出。真实非终止价值仍是位置除以六，不要因终点数组为零就误解为右端成功概率为零。这个记号区分对所有回合价值代码都重要，重复计入终点价值会让结果看似更高却对应另一任务。

<a id="explore-trace-51"></a>

### 13.3 结果应该怎样讨论

常数步长训练会在真值附近波动，lambda 较大时一次终点误差影响更多过去位置，也可能产生更大波动。较小 lambda 传播较局部，初期可能更慢但更平稳。最终均值依赖步长与预算，不能只取一个设置就声称某个参数普遍最好。可以进一步固定交互数而非回合数，或扫描步长并用独立验证选择。

同一种子在不同 lambda 下使用同样环境随机流，因为固定策略不依赖价值，轨迹完全可以共享，这是一种自然配对。若控制策略依赖价值，方法之间轨迹将分叉，即使种子相同也不再逐步相同。应准确说明配对的层次，不要把相同数字种子当成所有随机因素都相同的保证。

<a id="explore-trace-52"></a>

## 14. 每决策重要性采样的有限枚举

<a id="explore-trace-53"></a>

### 14.1 从条件期望看前缀权重

两步回合中，第一奖励只受第一动作影响，所以校正第一奖励只需第一比率；第二奖励需要两个动作比率。若把完整路径比率乘到第一奖励上，期望仍可能正确，但加入了一个条件均值为一的未来随机因子，往往增加不必要方差。这个论证依赖相同环境核与支持，不是任意相关数据都可随意删权重。

更一般地，第 k 个未来奖励使用直到产生它的动作前缀。若目标是动作价值并固定当前动作，前缀起点也要相应后移。自举尾部则受到到达末状态的全部中间动作影响，是否还包含末动作取决于尾部是状态价值、动作价值还是目标策略动作期望，必须逐个定义。

<a id="explore-trace-54"></a>

### 14.2 可运行实验五：枚举两步轨迹

```python
import numpy as np
behavior=.2;target=.8;gamma=.9
prob=[];ordinary=[];per_decision=[]
for a0 in [0,1]:
    for a1 in [0,1]:
        b0=behavior if a0 else 1-behavior
        b1=behavior if a1 else 1-behavior
        p0=target if a0 else 1-target
        p1=target if a1 else 1-target
        rho0=p0/b0;rho1=p1/b1
        prob.append(b0*b1)
        ordinary.append(rho0*rho1*(a0+gamma*a1))
        per_decision.append(rho0*a0+gamma*rho0*rho1*a1)
prob=np.array(prob);ordinary=np.array(ordinary);per_decision=np.array(per_decision)
truth=target+gamma*target
assert np.isclose(prob.sum(),1)
assert np.isclose(prob@ordinary,truth)
assert np.isclose(prob@per_decision,truth)
var_o=prob@((ordinary-truth)**2)
var_p=prob@((per_decision-truth)**2)
assert var_p<var_o
print('exact target value',truth,'trajectory/per-decision variances',var_o,var_p)
```

这个有限枚举没有蒙特卡洛误差，因此等式精确到浮点舍入。它只证明这个人工设置中每决策版本方差较小，不宜扩大为所有复杂估计器组合上的统一排序。若加入基线、相关奖励、截断或归一化，方差关系可能改变，应重新分析。

## 15. 探索在长路径上的概率代价

<a id="explore-trace-56"></a>

### 15.1 局部正概率不代表快速发现

假设关键奖励需要连续十次选择某动作，而初期策略只在探索分支可能选中它。两动作均匀探索下，每步所需动作概率可能仅为探索率一半，整条路径概率是它的十次方。即使每个动作都有正概率，有限预算也可能完全没有成功样本。这解释了为什么简单逐步随机常难以发现长程稀有收益。

探索率随时间衰减时，路径概率可能衰减得更快。若单步探索率像时间倒数，十步组合的粗略概率可能像时间负十次方，其和有限，不能据此保证无限发现。真实 MDP 的访问过程更复杂，但这个例子足以反驳“全局探索率趋零且一直正，就一定满足所有状态动作无限访问”的简化说法。

<a id="explore-trace-57"></a>

### 15.2 深度探索与随机性持续性

每步独立随机动作容易来回抵消，某些任务需要在一段时间内保持一致探索方向。参数扰动、策略集合或其他结构化方法尝试提供更持久探索，但它们也依赖模型与不确定性质量。持久错误方向可能造成更大代价，不能自动优于局部随机。应根据关键路径触达和训练风险评价，而不是只比较动作熵。

在可重置模拟器里，可以通过起点设计帮助覆盖；真实系统若不能重置，这种便利不存在。探索方法报告应说明是否使用任意起点、演示数据或预训练知识。额外信息与资源都可能有价值，但必须计入比较，不能把它们隐藏在算法名称之后。

**补充图解：单步随机与整段探索的差别**

![单步随机与整段探索的差别](images/03-deep-exploration.svg)

考虑长度为 H 的确定性链：每一步选 R 才能前进，任何一步选 L 就立即结束且失败，只有连续 H 个 R 才能获得末端奖励。每步独立以相同概率选左右动作时，成功概率为 $`2^{-H}`$；而在回合开始时以相同概率选择“全 R”或“全 L”计划，并在本回合内坚持该计划，成功概率始终为 $`\frac{1}{2}`$。图中六步算例分别是 $`\frac{1}{64}`$ 和 $`\frac{1}{2}`$。

下半图使用以 2 为底的对数纵轴，所以独立探索的指数衰减表现为直线；整段计划的曲线保持水平。图上的点对应整数链长，连接线用于引导阅读，不表示环境存在分数步数。

两种机制的预先生成动作序列在每个位置都有相同的左右边际概率，联合分布却不同；环境提前终止后，实际到达后续状态的条件分布也不同，所以不能把这句话误解为二者在每个被访问状态上的行为策略相同。这个构造揭示跨时间相关探索的价值，但并不保证固定计划适用于一般未知环境：如果奖励路径交替需要左右动作，只有两种全同方向计划就可能完全无法成功。

<a id="explore-trace-58"></a>

### 15.3 探索奖励的噪声陷阱

若用预测误差作新奇奖励，环境中不可预测的随机区域可能一直给高分，即使反复访问也不增加任务知识。模型可能偏好观察随机噪声而非寻找真实目标。区分可约减模型不确定性与不可约环境随机性，是探索研究的重要问题。单个预测误差数值通常无法自动分离二者。

可以构造一条无任务收益却有高随机观测的支路，检查新奇方法是否被吸引，再与原任务收益和覆盖一起报告。若辅助奖励改善探索却改变最终行为偏好，需要明确训练和部署怎样处理辅助项。最终只报告内部奖励可能给出完全错误的成功印象。

## 16. lambda 算子的固定点与变化目标

<a id="explore-trace-60"></a>

### 16.1 固定策略下的算子组合

在适当折扣与有界条件下，可以把多步 Bellman 算子按几何权重组合，得到 lambda 算子。真实策略价值对每个多步算子都是不动点，因此也是混合算子的不动点。改变 lambda 在精确表格固定策略下主要改变求解路径与随机估计性质，不是改变真实策略价值本身。

函数近似时，投影与多步算子组合会改变最终近似解的性质，不能把表格同一固定点结论直接迁移为所有特征表示下结果相同。状态权重与离策略数据也会进一步影响稳定性。研究 lambda 时应同时看可表示性、采样分布与步长，不要只讨论一个抽象偏差方差口号。

<a id="explore-trace-61"></a>

### 16.2 策略持续变化时的含义

控制算法每次更新价值后可能改变行为，较长回报跨越多个策略版本。把它们全视为某个固定策略的样本，需要额外近似或校正。资格迹传播过去状态时，也可能把当前误差用于在不同策略下访问的记录。某些控制迹算法采用清迹或特殊权重，正是为了处理这种目标差异。

因此在讲解多步机制时，先用固定策略预测最清楚。随后再加入控制，说明目标与行为如何变化，以及动作概率怎样记录。不能把预测中的精确恒等式直接当成任意控制代码的全部理论依据。实验设计应逐层增加难度，让每个新问题都有对应证据。

<a id="explore-trace-62"></a>

### 16.3 固定尾部与延迟参数

某些实现使用滞后参数或目标网络计算尾部，以减少快速变化。这样可改善部分数值行为，但引入了另一个明确目标版本。前向回报、TD 误差展开和后向迹若分别使用不同检查点，就不能按同一个固定函数相消。应记录尾部来源与更新频率，必要时把它作为外部目标分析。

延迟目标不是无限正确的未来真值，它仍有估计误差。更稳定曲线可能来自目标变化慢，也可能掩盖偏差。最终评价需要回到真实价值或部署收益，避免只比较训练目标自洽程度。理解这些层次有助于后续阅读深度价值学习中的多步回放与目标网络。

<a id="explore-trace-63"></a>

## 17. 资格迹的计算、存储与边界

<a id="explore-trace-64"></a>

### 17.1 稠密迹与稀疏近似

表格迹每步衰减全部状态，成本随状态数增加；线性特征迹通常需要参数维度向量。若只保存非零或较大迹，可以减少计算，但阈值截断改变精确更新。应报告阈值与误差影响，不把近似稀疏实现称为毫无代价的同一算法。状态空间很大时，这种工程折中可能重要。

神经网络参数迹更昂贵，特征梯度本身还随参数变化，简单线性迹理论不能直接照搬。实际深度方法常使用其他多步或优势目标，而不是为每个参数维护完整历史迹。算法选择需要考虑表达、稳定与成本，不能只因为资格迹在小表格有效就认定所有网络都应原样使用。

<a id="explore-trace-65"></a>

### 17.2 回合、片段与并行环境

每个并行环境应有独立迹，真正重置时只清自己的状态。若把多个环境共享一个迹，当前奖励会错误更新另一环境的过去状态。片段截断后是否保留迹取决于是否继续同一轨迹及参数更新协议，应明确说明。随机抽出的离散转移通常没有连续时序，不能直接维护跨样本迹。

若经验回放抽取连续片段，可以在片段内计算多步目标，但片段起始迹未知，常使用零初始近似或额外热身。这个选择影响长程信用，必须计入方法定义。没有连续性信息的数据，不应通过内存排列假装成合法轨迹。

<a id="explore-trace-66"></a>

### 17.3 数值规模与步长

当 gamma 与 lambda 乘积接近一，重复访问可使累积迹很大，单次误差造成大范围更新。减少步长、迹截断或选择不同迹规则都可能改变稳定性，但也改变传播与偏差。应记录迹范数、更新范数和触发截断频率，帮助区分目标错误与尺度问题。

如果出现非有限值，先检查奖励、比率与迹是否极端，再检查实现。把所有大迹强行置零可能让曲线稳定，却也切断真实信用传播。任何数值修正都应有明确目的与独立评价，不要为了获得平滑结果悄悄修改算法。

<a id="explore-trace-67"></a>

## 18. 统计解释与实跑结果

<a id="explore-trace-68"></a>

### 18.1 重要性实验的具体信息

普通重要性估计在三万个十轨迹数据集上的均值约零点七九六，接近真实零点八，但跨数据集方差约一点二零五。加权估计均值约零点三六三，方差约零点一九八，有限样本偏差非常明显。约百分之五十九点九的数据集完全没有奖励动作，直接解释了为什么归一化并不能凭空恢复未见证据。

这个结果不是否定加权估计。它展示了在极端行为目标不匹配与很小样本量下的折中。增加样本量、改善行为覆盖或使用其他信息都可能改变表现。应报告均方误差、偏差和方差，而不是只挑其中一个好看的性质。支持条件、实际证据量和估计器选择必须一起讨论。

<a id="explore-trace-69"></a>

### 18.2 冻结恒等式与在线差异

短轨迹的冻结前后视更新向量约为五点六四九、一点九八九、二点三和零，所有构造方式一致。在线实验则允许后续误差读取已经修改的价值，因此结果不同。二者都可作为合理定义下的算法，但对应对象不同。把差异如实展示，比隐藏它来维持一句过于简单的“完全等价”更有教学价值。

每决策枚举实验使用四条可能轨迹，期望可以精确求和，不受样本波动影响。它验证前缀比率能够在这个设定下保持目标均值并降低方差。真实长轨迹可能有更复杂依赖，需要继续检查行为概率、支持与尾部对象，而不是只照抄代码中的乘积范围。

<a id="explore-trace-70"></a>

### 18.3 公平比较的最小协议

比较 lambda 或探索策略时，固定任务、环境交互预算、训练种子、初始化与评价目标。若调步长，给各方法相同验证预算，最终使用独立评价。固定策略预测可以共享轨迹，控制策略变化时则至少共享初始设置与环境分布，并准确说明配对范围。所有失败种子与截断都应进入结果。

一条漂亮均值曲线不足以证明稳定改善。应展示逐种子或区间、关键状态覆盖与最终目标误差。若方法需要更多存储、参数迹或概率记录，也应报告额外成本。学习效率与计算效率不总一致，不能只固定某一个方便指标就宣称全面更好。

<a id="explore-trace-71"></a>

## 19. 从本章走向研究问题

可以先固定轨迹与价值，验证各种前后视恒等式；再让参数在线变化，观察差异随步长怎样改变；然后在固定策略随机游走中比较最终误差；最后才加入控制和离策略。这样的顺序使每层新增复杂性都有清楚参照，避免一开始把探索、函数近似和目标变化混成一个难以解释的失败。

更进阶的问题包括状态相关 lambda、截断比率的偏差控制、长程稀有奖励的探索与多步传播交互，以及并行片段中的迹近似。每个问题都应先声明估计目标、支持与时序条件，再设计可证伪反例。掌握条件与边界，比记住更多算法缩写更能帮助判断新方法的实际价值。

<a id="explore-trace-72"></a>

## 20. 更深入的算子与真在线边界

<a id="explore-trace-73"></a>

### 20.1 lambda 算子的收缩系数

对固定策略、折扣小于一且有界价值，n 步 Bellman 算子的最大范数收缩系数为折扣的 n 次方。当 $`0\le\lambda<1`$ 时，把它们按归一化权重 $`(1-\lambda)\lambda^{n-1}`$ 组合，收缩系数上界为 $`\frac{\gamma(1-\lambda)}{(1-\gamma\lambda)}`$。推导只需对每项应用收缩再求等比级数，不能把 lambda 当成环境折扣替换掉。lambda 越大，精确算子对初始价值的依赖可以更弱。

端点 $`\lambda=1`$ 必须用极限或完整回报另外定义：若直接把一代入每一个几何权重，所有权重都变成零，所得零算子并不是所需的回报算子。在本节有界、折扣条件下，$`T_\pi^n v`$ 一致趋向 $`v_\pi`$，故 $`T_{\pi,\lambda=1}v`$ 应定义为与输入 $`v`$ 无关的常值 $`v_\pi`$，其 Lipschitz 常数为零，与上界的极限一致。这里固定 $`0\le\gamma<1`$ 且奖励有界，所以完整折扣回报可积，有限步自举尾项由 $`\gamma^n\Vert v\Vert _\infty`$ 控制并趋零。

对前文有限终止回合，定义已显式保留末项 $`\lambda^{H-1}G^{(H)}`$，故直接取 $`\lambda=1`$ 得完整 MC 回报，不会丢失尾部质量；它与无限几何和的逐项代入是不同操作。无折扣但随机终止的问题则需要另外核对终止性和回报可积性，本节折扣收缩界不直接适用。

这个确定算子性质不意味着随机算法方差也更小。更长真实回报可能带来更大噪声，资格迹也可能放大一次误差的影响。精确期望迭代更快与有限样本学习更好是两个问题。本章随机游走在同一步长下 lambda 一的最终平均误差反而更大，正说明不能只看算子收缩就预测完整实验排序。

lambda 等于一时应通过完整回报或相应极限定义，不能把一减 lambda 为零直接代入无限和后得到零算子。有限回合公式已经通过最后剩余质量处理解决这个边界。数学极限、有限轨迹与代码分支应一致，避免在最常用两个端点上发生定义错误。

<a id="explore-trace-74"></a>

### 20.2 真在线线性更新的完整记号

若线性价值为 $`w^Tx`$，当前与下一特征分别为 $`x,x'`$，在更新前计算 $`v=w^Tx,v'=w^Tx'`$，真正终止时下一特征为零。令旧预测缓存初始为零，TD 误差为奖励加折扣下一预测减当前预测。荷兰迹可以写成 $`e\leftarrow\gamma\lambda e+(1-\alpha\gamma\lambda e^Tx)x`$，右侧内积使用更新前的旧迹。

随后权重更新为 $`w\leftarrow w+\alpha(\delta+v-v_{\rm old})e-\alpha(v-v_{\rm old})x`$，最后缓存设为更新前计算的下一预测。这里的运算顺序很重要：如果缓存改成更新后重新计算的值，或内积使用已经衰减叠加的迹，就不是同一个算法。完整实现应根据原始定义核验，而不是仅记住“多一个修正项”。

当 lambda 为零，迹变成当前特征，两项预测差修正抵消，回到普通一步 TD。这个边界是有用检查，但只通过它不能证明一般 lambda 实现正确。更强检查要在每个轨迹前缀与相应在线前向视图比较；本章没有把普通在线代码冒充真在线，也没有声称已经实跑完整真在线前向等价验证。

<a id="explore-trace-75"></a>

### 20.3 迹、步长与预条件

如果每个参数或状态使用不同步长，把统一标量公式简单换成逐坐标数组可能改变荷兰迹修正的内积结构。普通表格累积迹也会受到步长位置影响：先把步长乘进迹与最后乘权重更新，在变化步长下不一定等价。应先定义算法，再推导对应前向视图，而不是认为所有逐项缩放只是实现优化。

自适应优化器带有历史状态，亦不能自动继承线性常步长真在线关系。它可以作为新的工程方法实验，但理论描述要限定。最可靠路线是先验证原始简化设置，再逐项增加变化，每次检查哪些恒等式仍成立、哪些只剩近似。这样能避免把复杂实现的成功误归因于并未满足的定理。

<a id="explore-trace-76"></a>

## 21. 重要性权重的诊断与统计范围

<a id="explore-trace-77"></a>

### 21.1 有效样本量是诊断而非保证

常用有效样本量写成权重和的平方除以权重平方和，衡量有限样本权重是否集中。它很小提示少数轨迹主导，但很大也不能证明目标覆盖充分：如果根本没抽到重要稀有区域，现有权重可能看起来平稳。支持与未见事件问题不会被一个漂亮有效样本量自动消除。

本章一回合实验中，大约六成小数据集没有奖励动作，恰好展示有限覆盖风险。可以同时报告最大权重、权重分位数、关键事件数和估计随样本量的变化。把这些诊断与已知人工真值比较，能检验估计器在什么范围可靠。真实任务没有真值时，更应保留这些边界，而不是只打印一个均值。

<a id="explore-trace-78"></a>

### 21.2 重采样单位应是轨迹

完整路径比率与回报共享整条轨迹，不能把其中每个转移当成独立样本随意 bootstrap。若多条轨迹来自同一训练策略或同一来源组，还可能有更高层依赖。应按实际独立单位重采样，并说明固定目标策略还是把训练不确定性也纳入。不同单位得到的区间回答不同问题。

加权比值估计对极端权重敏感，小样本普通 bootstrap 也可能不稳定，尤其少数重要轨迹没有被观察到时。区间窄不等于识别充分。报告应同时展示原始轨迹数量与权重集中，必要时明确无法可靠评价，而不是通过截断或删除极端值制造稳定表象。任何修正都要重新说明目标与偏差。

<a id="explore-trace-79"></a>

### 21.3 基线与控制变量需要保持期望

在某些重要性估计中，可以利用比率条件期望为一构造零均值控制变量，减少方差。例如常数基线的加入与扣除要配对，才能保持同一目标。直接从回报减一个值却没有补偿，可能改变估计对象。最优基线还依赖比率与奖励相关性，不是简单把样本平均回报放进去就一定最好。

如果基线由同一数据拟合，分析还要考虑额外依赖；可以使用独立拟合或交叉拟合等设计，但它们也增加成本。对于小人工问题，先枚举全部轨迹验证期望，再用模拟研究方差，是非常有效的学习方法。对复杂长轨迹，则应保持同样严谨的对象与条件意识。

<a id="explore-trace-80"></a>

## 22. 多种子随机游走的实际观察

在固定三百回合、步长零点零四与十二个预先指定种子下，lambda 零的最终平均均方根误差约零点零四一八，lambda 零点七约零点零五三七，lambda 一约零点一一零五。所有运行都保留，个别 lambda 一种子误差明显较大。这个结果展示当前预算与步长下较长迹的波动代价，不构成对所有任务或所有调参预算的普遍排序。

若希望公平比较最优可调表现，可以为每个 lambda 预先给相同的步长搜索集合，用独立训练种子或验证数据选择，再在新种子确认。若只给 lambda 零精调步长、其他用相同步长，不应宣称已经比较各方法最佳能力；但固定同一步长作为机制消融是有意义的，只需准确命名。实验目标不同，协议也应相应不同。

两步离策略枚举得到真实目标价值一点五二，完整路径估计方差约三十四点九四六，每决策估计约十三点九二二。这个方差下降来自不再给早期奖励乘无关未来权重。普通在线反例中，冻结离线最终向量约为一点三三零、零点二九八、一点一六、零，而普通在线约一点三一零、零点三零八、一点一六、零，差异虽不巨大但严格存在。

这些数字分别来自不同验证层：解析恒等式、有限枚举、重复数据集统计和完整预测训练。把它们分开解释，能够防止一种证据冒充另一种。读者既可以复现具体运行，也可以沿着明确边界设计新实验，而不必先相信某个算法名称天然优越。

在实际实现中，还可以用一个明确界来理解迹截断。若固定价值下每个 TD 误差绝对值不超过某常数，且 gamma 与 lambda 的乘积严格小于一，忽略距离当前超过 K 步的误差贡献，其绝对尾部不超过该常数乘衰减因子的 K 次方，再除以一减衰减因子。这个几何级数界给出记忆长度与近似误差的关系，但当乘积接近一时可能很松。

若 gamma 与 lambda 都为一，就不能使用这个无限几何界，必须依靠有限回合长度或其他结构条件。非线性网络、在线变化价值或极端重要性比率也可能破坏所假设误差统一界。因而“丢掉很小迹没有影响”需要相对于误差尺度和任务长度判断，而不是看到迹数字小就无条件删除。

这也说明比较实现时需要报告数值截断规则。一个方法保留全部迹，另一个只保留最近十步，实际算法已经不同；如果二者结果接近，可以作为近似有效的实验观察，但不能直接宣布数学上完全等价。性能、计算与存储之间的折中应被明确呈现，而不隐藏在优化代码中。

进一步阅读新方法时，可以依次问：它的目标是哪一个策略，使用哪些未来奖励，尾部来自哪个价值版本，动作比率覆盖哪些时间，迹怎样衰减与清理，等价性是离线还是在线，实际成本是多少。只要这些问题有清楚答案，即使公式复杂也能逐步拆解；如果答案缺失，最好先补齐定义再讨论优劣。

本章六段代码分别检查动作概率、冻结前后视、重要性偏差方差、普通在线差异、多种子预测与每决策枚举。它们彼此独立，不依赖上一段变量，也没有写出脚本、模型或日志。将证明、反例与完整运行放在同一条逻辑链上，才能既满足深入理解，也避免把未经验证的直觉当作结论。

复现时先保持原设置，确认所有断言与实跑结果一致，再一次只改变一个因素。参数变化后出现负结果也应保留，它能够帮助判断收益究竟来自目标、覆盖还是步长。不要通过反复挑种子把失败抹去，否则最需要理解的机制恰好被隐藏。
