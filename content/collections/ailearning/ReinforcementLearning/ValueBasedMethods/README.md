# 价值方法

理解从采样回报到 TD、SARSA 和 Q-learning，并动手训练一个小型表格智能体。

**先修知识：** MDP、Bellman 方程；Python 与 NumPy。

## 学习顺序与覆盖范围

第 1 章先区分估计对象与采样目标，第 2 章完成导航训练，第 3 章扩展探索与多步信用分配，第 4 章用独立评价检查策略和实现。先具备MDP与Bellman基础，再讨论有噪声的异步学习；表格收敛条件不自动覆盖神经网络与离策略自举。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 从价值方程到实际训练目标

第 1 章的半梯度与投影方程之后，读[双采样及其条件协方差偏差](01-蒙特卡洛TD与动作价值.md#value-foundation-double-sampling)，比较“条件期望残差的平方”和“采样残差平方的期望”。具备神经网络回归基础后，再读[Huber 损失为何可能改变动作排序](../DeepRL/01-DQN经验回放与目标网络.md#dqn-1-huber-target)。两例分别改变了求期望的次序和回归损失，应能独立指出各自估计对象发生变化的位置。

## 如何完成本主题

完成各章后，先独立作答[综合研究：固定预算比较完整方案](04-价值学习的评估与失败诊断.md#sec-9-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
