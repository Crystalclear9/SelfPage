## 1. 评价对象是一个完整的决策协议

强化学习的结果不是一个脱离上下文的平均回报。需要同时指定环境及其版本、初始状态分布、奖励、折扣、结束规则、评价动作分布、输入可见范围以及资源预算。训练时带探索的策略、冻结后贪心策略和随机部署策略可能有不同收益。即使都由同一张 Q 表产生，也是在执行不同决策规则，不能把它们的曲线拼成一个没有阶段说明的性能数字。

<a id="value-eval-2"></a>

### 1.1 训练收益和冻结策略收益回答什么

训练回报记录智能体边学习边探索期间实际得到的反馈，包含早期错误和持续探索代价；冻结评价试图估计某个已选择策略在规定条件下的未来表现。前者适合研究交互过程成本和在线学习收益，后者适合比较部署结果。训练曲线较低而最终贪心收益较高并不矛盾，反过来训练偶然高分也不保证冻结策略稳定。

评价代码应有独立环境随机流，不更新价值表、不增加训练访问计数，也不把评价转移写回训练数据。若产品允许上线继续学习，那是另一个明确协议，需要评价适应过程，而不是偷偷在测试中更新后仍称冻结模型。策略中的随机动作、并列最大值规则和动作掩码也属于策略定义。关闭探索只是一种选择，不是所有任务唯一正确的评价行为。

<a id="value-eval-3"></a>

### 1.2 起点分布与目标错配

训练可以从多个状态重置以提高覆盖，部署却可能总从固定入口开始。训练平均回报与入口价值因此不同。可以有意采用覆盖性训练，但报告应分别给训练起点与部署起点。若只关心特定初始分布，有些状态误差对当前收益影响很小；若要求所有状态可靠，就不能只用单一入口成功掩盖未访问区域。

令策略状态价值为 $`v^\pi`$，部署初始分布为 $`\mu`$，目标为 $`J_\mu(\pi)=\sum_s\mu(s)v^\pi(s)`$。改变 $`\mu`$ 就改变加权对象，即使策略和环境没有变化。一个方法在当前入口更好，不等于逐状态支配另一个。可同时报告主目标与预设分层，但不能在看到结果后只挑最有利起点，再把选择后的分数当预先设定目标。

<a id="value-eval-4"></a>

### 1.3 截断评价与真实继续任务

评价设最大步数便于限制成本，但若这不是任务真正终止，截断回报只是部分和。对有界奖励，可以用折扣尾界说明缺失量，或者在已知模型中计算有限与无限目标差。不能把超时轨迹静默丢掉，因为它们可能正是差策略的主要失败；也不能只统计成功结束的回合，再称为完整成功率。

可以预先将超时作为任务失败，此时成功率定义清楚；但折扣回报仍需说明是否在该步实际结束或仅停止观察。报告完成比例、长度和部分回报有助理解成本。学习目标中的截断自举与评价中的有限观察也不同：训练保留尾部估计不表示评价者已经观测到真实未来奖励。估计对象和观测协议应分别写出。

## 2. 多种子与多回合具有不同统计角色

同一训练结果运行许多回合，可以降低对该固定策略价值估计的环境噪声；重新训练多个种子，才包含探索、初始化、数据与优化路径的波动。如果只训练一次后评价一万个回合，分数可以很精确地描述那一次策略，却不能代表算法在重新训练时的稳定性。大量环境回合不是大量独立算法重复，错误的独立单位会制造过窄区间。

<a id="value-eval-6"></a>

### 2.1 层级模型给出一个精确反例

为说明统计结构，设第 $`i`$ 个训练种子的真实收益为 $`\theta_i`$，均值为 $`\mu`$、方差为 $`\sigma_b^2`$，该种子的第 $`j`$ 个评价回合为 $`Y_{ij}=\theta_i+\varepsilon_{ij}`$。假设种子彼此独立，评价噪声独立、均值零、方差 $`\sigma_w^2`$，且与种子收益独立。用 $`n`$ 个种子、每个 $`m`$ 回合的总平均，其方差为

$$
\operatorname{Var}(\overline Y)=\frac{\sigma_b^2}{n}+\frac{\sigma_w^2}{nm}.
$$

推导先对每个种子平均，得到种子效应加平均噪声；两部分独立所以方差相加，再对独立种子平均。若误把所有 $`nm`$ 个结果独立，种子效应也被错误除以 $`m`$，严重低估训练波动。增加 $`m`$ 只能压低第二项，不能消除第一项。真实回合依赖、共同环境或非高斯分布会增加复杂性，但不会让独立单位问题自动消失。

<a id="value-eval-7"></a>

### 2.2 配对比较应以种子还是回合为单位

同一环境实例、相同训练预算和预先安排的随机条件可以帮助配对比较方法。先对每个独立训练重复得到两个最终策略收益，再计算差值，能保留配对相关性。若同一策略还用多个环境种子估计，其噪声可按实际层次处理。训练种子、环境实例和评价回合混合在一起时，需要说明希望推广到哪一层，而不是统一称多次运行。

配对不是魔法。给两个方法同一个整数种子，不保证它们使用相同随机数位置，因为动作改变会改变轨迹长度和调用次数。可以预生成独立的外部随机流，并解释怎样耦合；也可以只用同一个任务实例作为配对。无论怎样，差值的统计单位仍应与真正独立重复一致，不能把依赖轨迹中的每一步当作一个新实验。

<a id="value-eval-8"></a>

### 2.3 实验一：层级方差与错误独立性

这里不训练智能体，而是用明确层级模型核对方差公式。每个外层重复重新生成全部训练种子效应和评价噪声，比较总平均的经验方差与理论值。代码刻意展示把全部回合当独立会得到不同理论数值；它不是对任意强化学习回报都成立的正态假设，而是独立单位错误的可计算反例。

```python
import numpy as np
rng=np.random.default_rng(241)
repeats,n,m=20000,8,40
between,within=.7,1.2
theta=rng.normal(0,between,size=(repeats,n,1))
noise=rng.normal(0,within,size=(repeats,n,m))
averages=(theta+noise).mean(axis=(1,2))
correct=between**2/n+within**2/(n*m)
incorrect=(between**2+within**2)/(n*m)
assert abs(averages.var()-correct)<.003
assert correct>8*incorrect
print('empirical/correct/incorrect variance',averages.var(),correct,incorrect)
```

## 3. 固定资源与记录模型选择

相同回合数不一定表示相同交互预算，策略可能快速失败或长时间循环。相同环境步数又不等于相同计算成本，一个算法可能每步更新很多次，另一个只更新一次。已知模型规划还可以额外调用转移模型，这种信息不应被当作免费样本。报告至少区分环境交互、模型调用、参数更新、评价成本与实际时间，主要公平标准由研究问题预先决定。

<a id="value-eval-10"></a>

### 3.1 检查点选择属于算法的一部分

在开发回报上选择最佳检查点，评价的是整个“训练加选择”程序。直接挑测试曲线最高点会引入选择偏差，即使训练从未读过测试标签。多试种子再挑最好一个同样增加选择自由度。应预先安排选择集或验证环境，最后只对选定程序做确认；也可以报告全部预设种子的结果，明确算法重复的分布。

如果真实部署确实允许训练多个候选并择优，就把总训练预算、选择评价成本和选择误差全部计入。它可以比单次训练更有效，但不能用只算赢家那一次成本的方式比较。失败运行、超时、数值异常与没有找到可行策略的比例也应保留，因为实际用户要为得到成功结果付出这些成本。

<a id="value-eval-11"></a>

### 3.2 平滑曲线不是额外证据

移动平均可以帮助看趋势，却会混合多个时刻与策略。中心平滑还使用未来数据，不适合解释当前时刻实时可知表现。展示应注明原始数据、平滑窗口、横轴单位和每个位置的有效重复数。只画幸存运行或后期补齐曲线，会改变分母。阴影也需要说明是种子标准差、均值标准误还是某种置信区间。

画图不能修复选择偏差，精美曲线也不能替代冻结评价。若某段 Q 值上升而收益下降，应回到实际动作与环境事件检查，而不是再调一个更平滑的窗口让曲线看起来一致。图表的任务是呈现测量对象与不确定性，不是把多种不同对象混成一个上升故事。

## 4. 完整实验：固定交互预算下比较两种步长

本实验延续第 2 章七个位置的导航定义：零和六是真正终端，中间五个状态可向左或右，动作以四分之一概率反向，进入右端奖励一、左端负一，其他转移奖励负零点零二，折扣零点九五。这里反向概率改为四分之一，是预先声明的新环境条件，不沿用第 2 章数值真值。两种方法只有步长规则不同，比较固定环境交互预算下的有限表现。

<a id="value-eval-13"></a>

### 4.1 数据、预算和配对规则

每个训练运行恰好用二百五十次环境交互，探索率固定零点三。回合终止或八十步外部截断后，从均匀非终端位置重置。常数步长零点二五与按访问次数负零点六五次幂递减的步长，使用相同预生成的探索、选择、转移与重置随机流。由于策略会改变轨迹，两者不是相同状态序列；共同随机数只是预设耦合，不是把不同决策后果强制设成一样。

训练结束冻结 Q 表，并在部署入口三计算贪心策略精确价值。已知小模型允许线性求解，消除最终策略收益的 Monte Carlo 测量噪声；这不消除训练随机性。十六个训练种子是统计比较单位。部署并列动作固定取编号较小者，训练并列则按预设随机数打破，两种规则在代码中明确写出。

<a id="value-eval-14"></a>

### 4.2 实验二：训练全部预设种子并保留负结果

代码同时计算每个策略的成功概率、期望长度和相对最优入口价值的损失，记录访问覆盖、训练截断数并核对冻结状态。配对 bootstrap 仅描述这组独立人工训练重复，样本不大时分位区间会不稳定，不能解释成对所有环境的保证。没有断言某种步长必须获胜，也没有根据结果增加预算直到方法排序符合预期。

```python
import numpy as np
GAMMA=.95;SLIP=.25;BUDGET=250

def model_values(policy):
    p=np.zeros((5,5));r=np.zeros(5);hit=np.zeros(5)
    for s in range(1,6):
        direction=1 if policy[s]==1 else -1
        for prob,delta in [(1-SLIP,direction),(SLIP,-direction)]:
            ns=s+delta;reward=1. if ns==6 else -1. if ns==0 else -.02
            r[s-1]+=prob*reward
            if ns==6:hit[s-1]+=prob
            elif ns!=0:p[s-1,ns-1]+=prob
    value=np.linalg.solve(np.eye(5)-GAMMA*p,r)
    success=np.linalg.solve(np.eye(5)-p,hit)
    length=np.linalg.solve(np.eye(5)-p,np.ones(5))
    assert np.max(np.abs(value-r-GAMMA*p@value))<1e-12
    return value[2],success[2],length[2]

def train(seed,mode):
    rng=np.random.default_rng(seed)
    explore=rng.random(BUDGET);choice=rng.random(BUDGET)
    slips=rng.random(BUDGET);resets=rng.integers(1,6,size=BUDGET)
    q=np.zeros((7,2));visits=np.zeros((7,2),dtype=int)
    reset=True;age=0;truncations=0
    for t in range(BUDGET):
        if reset:s=int(resets[t]);age=0
        if explore[t]<.3:a=int(choice[t]*2)
        else:
            ties=np.flatnonzero(q[s]==q[s].max())
            a=int(ties[min(int(choice[t]*len(ties)),len(ties)-1)])
        direction=1 if a else -1
        if slips[t]<SLIP:direction=-direction
        ns=s+direction;done=ns in (0,6)
        reward=1. if ns==6 else -1. if ns==0 else -.02
        visits[s,a]+=1
        alpha=.25 if mode=='constant' else visits[s,a]**(-.65)
        target=reward+GAMMA*(0 if done else q[ns].max())
        q[s,a]+=alpha*(target-q[s,a])
        age+=1;truncated=age==80 and not done
        truncations+=int(truncated);reset=done or truncated;s=ns
    assert visits.sum()==BUDGET and np.all(q[[0,6]]==0)
    frozen=q.copy();policy=q.argmax(1)
    result=model_values(policy)
    assert np.array_equal(q,frozen)
    return result,int((visits[1:6]>0).sum()),truncations

from itertools import product
optimal=max(model_values(np.r_[0,actions,0])[0]
            for actions in product((0,1),repeat=5))
assert np.isclose(optimal,model_values(np.ones(7,dtype=int))[0])
results={name:[] for name in ['constant','decay']}
coverage={name:[] for name in results}
for seed in range(160,176):
    for name in results:
        scores,covered,truncations=train(seed,name)
        assert scores[0]<=optimal+1e-12
        results[name].append(scores);coverage[name].append(covered)
a=np.array(results['constant']);b=np.array(results['decay']);difference=b[:,0]-a[:,0]
rng=np.random.default_rng(242)
means=difference[rng.integers(0,len(difference),size=(10000,len(difference)))].mean(1)
interval=np.quantile(means,[.025,.975])
print('optimal start3 value',optimal)
print('constant mean return/success/length',a.mean(0),'coverage',coverage['constant'])
print('decay mean return/success/length',b.mean(0),'coverage',coverage['decay'])
print('per-seed paired value differences',difference)
print('paired mean and percentile interval',difference.mean(),interval)
```

## 5. 先查语义，再查数值，再查学习

一个实现完全可以稳定拟合错误目标。训练损失低只说明对当前构造的目标一致，不证明奖励、下一状态、动作映射或终止语义正确。诊断应从最小可手算转移开始，保留状态动作、奖励、下一状态、两个结束标志、自举项和实际写入位置。若这些字段错误，调更多轮学习率只是在更精确地优化错误问题。

<a id="sec-2-1"></a>

<a id="value-eval-16"></a>

### 5.1 Q值偏移怎样与动作行为脱离

给同一状态所有动作加同一常数，不改变该状态的贪心动作，但可以显著改变 Q 值均值、尺度和 Bellman 残差。因而“Q 值更大”不是策略更好。反过来，两个动作价值非常接近时，微小误差可能交换动作，价值损失却很小。应同时看真实动作间隔、策略收益和数值自洽，不把动作身份差异或表值变化单独当成整体控制质量。

某个状态访问很少，表值可能保持初始值；这不是系统已经知道该动作没有价值。最大值目标不会凭空创造未知动作的环境证据。检查访问计数能区分覆盖不足和估计器错误。若值表预测很好却实际动作差，还应检查动作编号到环境执行的映射、合法动作掩码和评价时是否仍带探索，而不是只盯更新公式。

<a id="deep-dive-2"></a>

<a id="value-eval-17"></a>

### 5.2 实验三：高Q、错误终止与动作反转

这里构造三个独立的最小反例。给最优单步动作值整体加常数，贪心动作不变但残差改变；真正终止仍加尾部价值会夸大目标；外部截断错误清尾又会低估继续任务。最后动作映射反转使内部最优编号执行成最差动作。所有例子不需学习就能精确核验，帮助把接口错误与优化困难分开。

```python
import numpy as np
gamma=.9
true_q=np.array([1.,2.]);shifted=true_q+100
assert true_q.argmax()==shifted.argmax()
assert shifted.mean()>true_q.mean()
# A one-step terminal bandit has exact Bellman target [1,2].
assert np.max(np.abs(true_q-true_q))==0
assert np.max(np.abs(shifted-true_q))==100
reward=1.;next_value=10.
terminal_correct=reward
terminal_wrong=reward+gamma*next_value
truncated_correct=reward+gamma*next_value
truncated_wrong=reward
assert terminal_wrong-terminal_correct==9
assert truncated_correct-truncated_wrong==9
executed_rewards={0:1.,1:2.}
chosen=int(true_q.argmax())
normal=executed_rewards[chosen]
reversed_mapping=executed_rewards[1-chosen]
assert normal==2 and reversed_mapping==1
print('same greedy action/different residual',chosen,100)
print('terminal/truncated correct and wrong',terminal_correct,terminal_wrong,
      truncated_correct,truncated_wrong)
print('action mapping normal/reversed reward',normal,reversed_mapping)
```

## 6. 收益、成功、长度和风险怎样一起解释

训练奖励是目标代理或任务目标的一部分，成功率可能是另一项业务要求。两者不一致时，不能只挑上升的那个宣布全面改善。应检查奖励是否在完成前反复给分、是否按步扣成本、是否对失败有明确代价，以及成功判定是否忠实表达需求。更长回合既可能表示持续生存，也可能表示拖延终止，需要结合任务机制而不是统一当成好或坏。

<a id="sec-1-1"></a>

<a id="value-eval-19"></a>

### 6.1 一个期望收益高但失败更多的例子

策略甲总获得一且成功，策略乙一半获得四并成功、另一半获得负一并失败。乙的期望回报为一点五，高于甲的一，但成功率只有一半。若目标只有期望回报，乙可以合理胜出；若要求成功率至少九成，乙不满足约束。区别来自目标，而不是哪条统计公式算错。多指标报告帮助发现冲突，最终决策仍需明确偏好或约束。

奖励增加可能通过改变尺度、加生存奖金或调整终止规则实现。此时前后训练回报甚至不在同一目标下，不宜直接比较。可使用共同冻结评价目标检验任务结果，同时报告训练奖励版本。奖励设计本身若是方法的一部分，也需计入开发选择。不要把学会获取代理分数等同于完成真正任务，尤其在可利用循环或边界规则的环境中。

<a id="sec-7"></a>

<a id="value-eval-20"></a>

## 7. 选择偏差可以在没有复杂环境时发生

假设多个候选真实性能相同，每个开发评价都带噪声。选择开发最高者后，其开发分数平均会偏高，因为选择恰好偏向有利噪声。独立确认评价没有同样选择条件，通常回到真实均值附近。这就是为什么最好检查点、最好种子和最好超参数都需要额外评价。它不依赖神经网络，简单高斯测量就可精确演示。

<a id="sec-7-1"></a>

<a id="value-eval-21"></a>

### 7.1 实验四：赢家的开发噪声与独立确认

所有候选真实值设为零，三十个候选各自开发与测试噪声独立。外层重复一万次选择程序，比较被选者的开发均值与测试均值。测试信息不参与选择，实验并未训练任何策略；它隔离了单纯择优带来的偏差。真实强化学习还存在候选相关、环境依赖和训练成本，不能用这个例子直接估计真实偏差幅度。

```python
import numpy as np
rng=np.random.default_rng(243)
validation=rng.normal(size=(10000,30))
confirmation=rng.normal(size=(10000,30))
selected=validation.argmax(axis=1)
rows=np.arange(len(selected))
chosen_validation=validation[rows,selected]
chosen_confirmation=confirmation[rows,selected]
assert chosen_validation.mean()>1.8
assert abs(chosen_confirmation.mean())<.04
print('selected validation/independent confirmation means',
      chosen_validation.mean(),chosen_confirmation.mean())
```

<a id="value-eval-22"></a>

### 7.2 怎样报告失败而保留解释价值

预先说明失败包括什么：数值非有限、覆盖不足、没有找到可行策略、评价超时或收益低于约束。报告全部预设运行，不把失败只记成日志后从平均中删除。若算法需要重试，给获得一个成功策略的总成本或成功概率。不同方法失败机制不同，聚合比例之外还要保留具体转移和行为，才能知道该改数据、接口、目标还是优化。

一个研究假设即使被否定，也可以回答清楚问题。例如某步长在相同预算下覆盖相同，却更容易因早期噪声选错动作；或收益均值相近，但尾部失败严重。前提是保留可复核中间量和预设评价规则。没有证据的解释应写作待验证假设，再用最小干预排除替代原因，不能把每张不理想曲线都附一个确定性的事后故事。

<a id="value-eval-23"></a>

## 8. 从价值误差到策略收益的完整推导

<a id="value-eval-24"></a>

### 8.1 折扣访问分布不是训练计数

给定初始分布 $`\mu`$ 和策略 $`\pi`$，定义归一化折扣状态访问分布 $`d_\mu^\pi(s)=(1-\gamma)\sum_{t\ge0}\gamma^t\Pr_\pi(S_t=s)`$。继续任务在折扣小于一时它是概率分布。回合任务可补上零奖励吸收状态，使同一写法成立；若只列非终止状态，它的质量和可能小于一，解释时应说明。

这个分布由部署策略、环境与起点共同决定，通常不等于训练日志的经验计数。训练含探索、随机重置和预算截断，访问权重自然不同。函数近似在训练常见区域误差很小，并不保证部署访问的重要状态也准确。评价应围绕目标访问，而不是让训练容易到达的状态替真正使用场景决定权重。

<a id="value-eval-25"></a>

### 8.2 性能差异引理的望远镜推导

固定参考策略 $`\pi`$，其优势为 $`A^\pi(s,a)=q^\pi(s,a)-v^\pi(s)`$。沿另一策略 $`\pi'`$ 的轨迹，优势的条件期望等于奖励加折扣下一参考价值减当前参考价值。把它按时间折扣求和，中间价值相消，在有界与折扣条件下尾部消失，得到

$$
J_\mu(\pi')-J_\mu(\pi)
=\frac1{1-\gamma}E_{s\sim d_\mu^{\pi'},a\sim\pi'}[A^\pi(s,a)].
$$

把中间一步明确写出，对任意有限 $`H`$ 有

$$
\sum_{t=0}^{H-1}\gamma^tE_{\pi'}[A^\pi(S_t,A_t)]
=E_{\pi'}\!\left[\sum_{t=0}^{H-1}\gamma^tR_{t+1}\right]
-E_\mu[v^\pi(S_0)]+\gamma^HE_{\pi'}[v^\pi(S_H)].
$$

这是先对下一状态取条件期望，再让相邻的参考价值项逐项抵消。有界价值和 $`\gamma<1`$ 使最后一项趋于零；有界奖励使有限回报和的期望收敛。左侧按新策略的折扣访问概率重新组合，恰等于上述归一化访问分布期望除以一减折扣。这样每一项的来源与消失条件都明确，不能把平均单步优势直接当长期收益而漏掉访问权重和折扣系数。

注意访问分布属于新策略，优势属于参考策略。把二者都换成训练行为分布通常不再是同一等式。这个推导说明策略改进不仅取决于某些状态动作看起来更好，还取决于新策略实际会把系统带到哪里。离线数据上看见局部优势，若部署访问发生显著改变，仍需要覆盖与校正。

<a id="value-eval-26"></a>

### 8.3 表格误差如何给出充分界

假设估计动作价值与真实最优动作价值的统一误差不超过 $`e`$，部署按估计贪心。当前真实最佳动作可能被低估 e，所选动作可能被高估 e，因此真实动作损失至多二 e。把这个一步损失沿部署轨迹累计，可得到策略价值损失不超过二 e 除以一减折扣的粗略界。它依赖全状态动作误差，而非训练集平均误差。

若使用的是状态价值近似，再通过一步已知模型贪心，误差会先乘折扣，常见界相应多一个折扣因子。不能把两种估计对象的界混用。界也可能很松：实际误差可能集中在部署很少访问的地方，动作排序也可能保持正确。人工小环境可以直接算精确策略价值，应该优先使用精确结果，理论界用于理解充分条件和未知任务的限制。

<a id="value-eval-27"></a>

### 8.4 低均方误差为何不能直接保证控制

训练分布加权均方误差对少数低概率状态错误不敏感，而部署可能经常进入这些状态。若没有训练到部署分布的覆盖或密度比控制，不能把一个小训练误差直接转换成小部署损失。即使分布相同，两个动作间隔很小时，小误差也可能改变动作身份；动作改变是否严重，还要看真实优势。

因此报告可以同时保留数值误差、动作不一致位置、访问权重与实际收益。动作身份差异不一定重要，收益相同也不意味着所有状态都可靠。每种指标只是证据链中的一环，最终结论应回到明确的应用目标，而不是选择一个最方便的数字替代全部行为。

<a id="value-eval-28"></a>

## 9. 离线评价的支持与比率条件

<a id="value-eval-29"></a>

### 9.1 有数据不等于能评价所有策略

离线数据由行为策略产生，目标策略可能选择行为几乎不做的动作。若目标需要的动作在相应状态行为概率为零，数据无法直接识别它的后果，重要性权重也不存在有限值。函数近似可以外推，但外推依据来自结构假设，而不是数据已经提供的证据。报告应明确支持范围与未知区域。

状态被访问不等于动作被访问，单步转移覆盖也不等于长路径有足够样本。若行为策略版本、动作概率或环境版本没有记录，轨迹比率很难准确恢复。离线评价的第一步是检查数据生成机制，而不是直接套一个现成估计公式。缺失的记录不能由当前学到的 Q 表自动补回。

<a id="value-eval-30"></a>

### 9.2 轨迹与每决策重要性

在相同环境核、目标与行为支持匹配且相关期望可积时，完整路径概率比由各时刻目标动作概率除以行为概率的乘积组成。环境核抵消，使行为回报可转换成目标期望。状态价值从当前动作开始，条件固定当前状态动作的动作价值则不应再乘当前动作来源比率。终止状态没有额外动作。

初始分布也应相同；若不同且具有支持覆盖，还需相应初始密度比。以状态价值的有限 $`H`$ 步部分回报为例，记 $`\rho_{0:t}=\prod_{k=0}^t\frac{\pi(A_k\mid S_k)}{b(A_k\mid S_k)}`$，在行为 $`b`$ 对所有目标路径有支持的前提下，

$$
E_\pi\!\left[\sum_{t=0}^{H-1}\gamma^tR_{t+1}\right]
=E_b\!\left[\sum_{t=0}^{H-1}\gamma^t\rho_{0:t}R_{t+1}\right].
$$

若回合提前真正终止，求和只到终止前最后一条转移；等价的零奖励延拓可将后续比率增量约定为一，不需要给终止状态虚构动作。当前动作会影响紧随其后的奖励，所以该奖励的前缀包含当前动作比率；如果当前动作已经作为条件固定，则该动作不再需要来源校正。

部分回报与加尾部价值的自举对象又不同，不能不检查尾部随机变量便照搬同一权重范围。这里先使用有限时域与可积条件，避免在无限乘积上未经论证地交换极限与期望。

每个奖励只需要直到它发生的动作前缀比率，未来无关动作可用条件期望积分掉，这给出每决策形式。它可能减少部分方差，但长路径与极端比率仍可能使估计不稳定。归一化、截断和控制变量会改变有限样本性质，应准确说明偏差与方差，而不是把“离策略”当成可以免费复用所有记录。

<a id="value-eval-31"></a>

### 9.3 有效样本量的解释边界

权重和平方除以平方和常用来描述样本权重集中，值小提示少数轨迹主导；值大却不能证明重要未见区域已经覆盖。若某个罕见目标事件根本没被行为采到，现有权重可能看起来很好。应同时报告轨迹数、最大权重、关键动作事件数量及估计随样本量变化，而不是只用一个有效样本量放行结论。

固定策略下反复评价与重新选择策略也不同。如果目标策略根据同一批离线数据反复优化，评价误差会被选择过程利用。独立确认数据、交叉设计或明确保守分析可能有帮助，但各有条件与成本。不能在同一数据上不断挑策略，再把最乐观离线分数当成独立部署验证。

<a id="value-eval-32"></a>

## 10. 本章配对实验的完整统计解释

<a id="value-eval-33"></a>

### 10.1 十六个差值到底说明什么

固定二百五十次交互，常数步长的精确入口价值均值约零点六五六八，递减步长约零点六四八七。递减减常数的配对均值约负零点零零八二。十六个差值中十四个为零，只有一个约正零点零六九一和一个约负零点二零零零。因此均值差主要由极少数离散策略差异决定，不宜把它画成所有种子都有同等小变化的故事。

两个方法在全部十六个运行里都访问了十个非终止状态动作，但覆盖计数非零并不代表样本充分，也不保证表格值准确。最终评价使用已知模型精确求策略价值，消除了评价回合噪声；剩余差异来自训练路径与贪心策略，而不是几千次评价回合抽得不巧。这个设计使有限预算问题更容易解释。

<a id="value-eval-34"></a>

### 10.2 离散 bootstrap 的局限

配对百分位区间约负零点零三七五到正零点零一三零，跨越零。它没有给出当前数据下某方向稳定改善的证据，也不能被解释为两方法已经证明等价。独立种子少、差值高度离散时，经验重采样分布只重复已有几个取值，无法发现尚未观察到的失败模式，区间本身也可能不稳定。

十四个零差值使一些 bootstrap 样本只抽到零，产生明显原子质量。这不是程序错误，而是经验分布形状。应同时展示原始差值、失败策略和均值区间，避免一个平滑密度图掩盖离散结构。增加评价回合不会改变这里的精确策略价值，若要更了解训练方法变异，应增加独立训练重复或研究导致非零差值的机制。

<a id="value-eval-35"></a>

### 10.3 未显著不同不等于等价

区间跨零只能说明在给定设计和信息量下未明确区分方向。要主张实用等价，需要预先定义可接受差异界，并有足够信息把效果范围限制在其中。不能看到差异不显著就临时宣布两者一样，也不能只因均值略负就宣布递减步长更差。统计结论应与实际精度相称。

本实验没有对两种步长分别大规模调参，因此它比较的是两套预设规则在固定预算下的表现，而非所有常数与所有递减规则的最佳能力。若下一步要比较可调最优表现，应给予相同开发预算，冻结选择程序，再用新种子确认。准确限定问题，比扩大一个小实验的结论更有价值。

<a id="value-eval-36"></a>

## 11. 失败诊断应形成可证伪假说

<a id="value-eval-37"></a>

### 11.1 语义层错误

奖励发放位置、动作编号、真正终止与截断是第一层。先用不需要学习的最小环境检验它们，例如一步终止任务目标是否等于奖励，动作反转是否确实改变执行结果。若语义错误，更多训练只能更精确拟合错误任务。训练曲线稳定并不能排除此类问题。

还要检查状态中是否包含所需时间与历史。有限时域剩余步数缺失、观测混淆或环境版本混合，会破坏原来马尔可夫或平稳假设。增加价值网络容量不能凭空创造缺失信息。应先用完整状态基准与受限观测对照，区分表示问题和更新问题。

<a id="value-eval-38"></a>

### 11.2 数据与覆盖层错误

若关键状态动作没有访问，先研究起点、探索、可达性与预算，而非直接更换优化器。记录访问数、稀有奖励触达与行为概率，可以检验“数据不够”是否具体成立。总交互数很大不保证有效证据很多，重复回放也不等于新增环境信息。数据重用与证据增加应分开计算。

如果怀疑某个方法因早期随机噪声选错动作，可以固定同一初始外部流，逐步检查动作与更新，然后在新种子验证该机制。只从一条失败轨迹编一个故事不够，干预应能改变相应结果，并排除奖励或接口替代解释。诊断的目标是定位可修改原因，而不是给每个负结果配一个无法检验的解释。

<a id="value-eval-39"></a>

### 11.3 估计与优化层错误

基础语义和覆盖正确后，再看步长、目标尺度、最大化偏差、自举传播与函数近似。记录参数或表格更新幅度、目标与残差来源，检查是否存在非有限数值或持续过大更新。表格小模型可以计算真实残差，函数近似则需要独立数据和适当理论条件。低训练残差不自动等于真实价值准确。

每次只改变一个主要因素，固定评价协议并保留全部预设运行。若某修改降低误差却增加训练失败，应同时报告。负结果也能回答问题，例如覆盖相同但递减规则在某些早期路径下恢复较慢；不过这仍是待确认机制，需要额外实验，而不能从两个异常种子直接宣称普遍规律。

<a id="value-eval-40"></a>

## 12. 十六道进阶练习与详细答案

<a id="value-eval-41"></a>

### 12.1 为什么一万回合不等于一万次方法重复

这些回合共享同一训练结果，主要估计该固定策略的环境随机性。重新训练的探索、初始化与优化差异没有被覆盖。层级方差中种子间项只能靠增加独立训练重复减少，不能靠无限增加同一策略回合消除。应分别报告训练种子数与每种子评价回合数，让区间对象清楚。

<a id="value-eval-42"></a>

### 12.2 相同整数种子是否严格配对

不一定。方法动作和回合长度不同，会改变随机数消费。可以预生成外部随机流并说明耦合，也可以按同一环境实例配对，但不能声称状态轨迹完全相同。本章预生成每个交互位置的选择与转移噪声，策略改变仍会导致状态不同。配对降低部分比较噪声，不抹除真实决策后果。

<a id="value-eval-43"></a>

### 12.3 为什么高 Q 不代表好策略

同状态所有动作整体加常数，不改变贪心动作，却可让值均值大幅上升。它还可能改变 Bellman 自洽性。实际策略收益需要独立评价或精确模型计算。只看 Q 值上升，会把尺度、偏移或发散误认为进步。应同时检查动作、残差和任务结果。

<a id="value-eval-44"></a>

### 12.4 训练与部署起点不同是否错误

不一定。覆盖性训练可以有意使用更广起点，但评价应围绕明确部署分布，并补充预设分层。错误在于把训练平均成绩冒充固定入口收益，或事后挑容易起点。若真实系统无法任意重置，训练设计的资源假设也应说明，不能把模拟器便利视为免费能力。

<a id="value-eval-45"></a>

### 12.5 置信区间跨零能否说等价

不能。它只说明当前设计未明确区分方向。等价需要预先定义容忍界与足够信息，不能事后用不显著代替。尤其十六种子和离散差值时，区间可能不稳定。应展示逐种子结果，并准确限定结论，避免用一个统计词掩盖证据不足。

<a id="value-eval-46"></a>

### 12.6 全部动作访问过是否足够

非零计数只是最基本覆盖，不代表估计精确。稀有转移、长程奖励和不均衡访问仍可能导致误差。应看计数大小、关键事件与目标策略支持。函数近似还会在未见区域外推，更不能由状态访问推断所有动作可靠。本章全部十项访问只排除完全空白，不证明充分学习。

<a id="value-eval-47"></a>

### 12.7 外部截断评价能否删除

不能静默删除，它们往往对应困难路径。可以报告有限预算回报、未完成率与尾部界，或使用已知模型计算完整价值。若应用本身定义超时失败，就按该任务评价。关键是区分任务结束与观察停止，不让数据过滤替研究者悄悄改变目标。

<a id="value-eval-48"></a>

### 12.8 动作不同是否必然收益不同

不必然。动作可能具有相同或接近真实价值，也可能只在部署几乎不访问的状态不同。应结合真实优势与访问分布解释。相反，少数关键动作错误可能造成大损失，平均动作准确率会掩盖它。性能差异引理说明新策略访问位置与参考优势共同决定收益变化。

<a id="value-eval-49"></a>

### 12.9 奖励增加是否代表任务改善

若奖励定义或尺度改变，前后数字可能不在同一目标下。即使奖励固定，代理漏洞也可能让模型刷分而不完成需求。应使用共同冻结任务评价，报告成功、长度与风险，检查循环奖励和终点规则。不要把更擅长获取代理分数自动解释为更符合实际应用。

<a id="value-eval-50"></a>

### 12.10 重要性采样是否能评价任意策略

不能。目标动作必须在行为下有支持，行为概率与环境假设也要正确。即使支持存在，极端比率会造成高方差，有限数据可能没有关键事件。归一化或截断改变性质，需准确报告。未知区域只能依赖额外结构假设，而不能声称数据已无条件证明效果。

<a id="value-eval-51"></a>

### 12.11 有效样本量大是否可以放心

它只描述现有权重集中程度，不能发现根本没出现的重要区域。应同时检查支持、关键轨迹数、最大权重与样本量敏感性。若策略根据同一数据反复选择，额外选择偏差也不由有效样本量解决。一个诊断不能承担整个证据链。

<a id="value-eval-52"></a>

### 12.12 为什么独立确认不能再参与调参

确认集一旦被用来改引导、步长或检查点，就成为开发信息，下一次最好分数不再独立。需要新的确认或明确承认探索性质。候选真实相同的模拟中，开发赢家均值约二点零四六，独立确认接近零，展示了单纯择优就能制造看似显著收益。

<a id="value-eval-53"></a>

### 12.13 平滑曲线为何可能误导

平滑混合不同时间与策略，中心窗口还使用未来信息。删除失败运行或变化分母会进一步改变对象。应注明窗口、原始数据与阴影定义，保留冻结评价和逐种子结果。图形帮助阅读，不能修复泄露、独立单位错误或任务定义混乱。

<a id="value-eval-54"></a>

### 12.14 更多更新是否样本效率更高

相同交互数据做更多更新，可能提高利用率，但增加计算且可能过拟合旧数据。应分别报告交互数、更新数和实际成本。已知模型规划还使用额外模型信息。若只固定回合数，不同长度又改变证据量，因此公平标准应与研究问题对应，不能只选择最有利横轴。

<a id="sec-9-2"></a>

<a id="value-eval-55"></a>

### 12.15 如何对待两个异常种子

先保留结果，再检查它们的轨迹、覆盖和策略，与其他种子对比形成可证伪假说。不能直接删除，也不能从两个案例推广所有方法。增加独立重复或设计最小干预验证机制，例如固定早期数据再改变步长。案例用于诊断，总体结论仍需适当重复与独立评价。

<a id="value-eval-56"></a>

### 12.16 什么才算评价完成

任务、预算、选择、策略、数据来源、独立单位和失败规则均明确，主要结果有对应证据，辅助指标能解释风险与成本，结论限定在实际范围。若有未知支持或统计不足，就准确说明。完成不是让所有数字漂亮，而是让读者可以复核结果并知道哪些问题仍未解决。

<a id="value-eval-57"></a>

## 13. 三个可完成的研究项目

<a id="sec-9-1"></a>

<a id="value-eval-58"></a>

### 13.1 项目一：固定预算比较完整方案

以本章导航为基础，预先选择常数与递减步长各一小组候选，给每个方法相同开发交互与选择预算。开发完成后冻结选择规则，在新的训练种子上比较固定二百五十次、五百次与一千次交互后的策略。每个预算分别报告精确入口价值、成功概率、长度、访问与训练期间失败。不要把不同预算的最好点合并成一个赢家。

主要问题可以明确为：在给定资源下，哪套选择后程序产生可用策略的概率更高？如果主要收益来自更大调参投入，应计入成本。若方法平均接近但尾部失败不同，就把失败概率与低分位收益作为补充。项目完成的标准是协议、全部种子和结果可复核，而不是必须证明预先喜欢的方法更好。

<a id="value-eval-59"></a>

### 13.2 项目二：部署起点与覆盖错配

固定训练起点分布，分别以中间入口、靠失败侧入口以及混合起点评价。再改变训练重置方式，观察相同交互预算下各起点的收益差异。已知模型允许精确计算每个策略的逐状态价值，可把“整体更好”拆成哪些状态改善、哪些状态退化。这个项目直接检验分布权重如何影响结论。

进一步可以人为限制某些动作数据，比较离线估计与真实策略价值，检验支持不足是否会造成乐观外推。不能用未记录的真实模型帮助某个方法后仍称纯离线学习。模型只作为独立评测参照，算法可用信息必须严格分开，才能知道改进来自数据、先验还是额外环境知识。

<a id="value-eval-60"></a>

### 13.3 项目三：最小故障与恢复

依次引入动作映射反转、终止掩码错误、评价继续更新和随机流共用等故障，每次只改一个因素。预先列出预期受影响的指标，再用最小反例与完整导航检验。随后修复，确认相关现象消失，同时检查其他指标没有意外改变。这个流程训练因果诊断，而非只会在错误曲线后写解释。

对故障实验应清楚标注错误版本，不能把它作为正常算法基线来制造夸大提升。恢复实验也应使用相同协议，而不在修复时同时增加训练预算。最终报告可以形成一张故障到证据的映射：哪个断言捕获、哪个行为指标异常、哪些表面指标仍看起来正常。这样的结果具有实际教学与工程价值。

<a id="value-eval-61"></a>

## 14. 怎样分配训练重复与评价回合

<a id="value-eval-62"></a>

### 14.1 从层级方差推导资源折中

设一个独立训练成本为 $`c_T`$，每个评价回合成本为 $`c_E`$，总预算为 $`C`$。每个种子评价 m 回合、共 n 个种子时，预算约为 $`n(c_T+mc_E)`$。代入层级均值方差，可把不确定性写成 $`\frac{(\sigma_b^2+\frac{\sigma_w^2}{m})(c_T+mc_E)}{C}`$。在简化连续优化且方差为正时，对 m 求导得到一个平方根形式的最优折中。

展开预算约束后的方差，乘以 $`C`$ 得到 $`\sigma_b^2c_T+\sigma_b^2mc_E+\frac{\sigma_w^2c_T}{m}+\sigma_w^2c_E`$。对连续 $`m>0`$ 求导为 $`\sigma_b^2c_E-\frac{\sigma_w^2c_T}{m^2}`$，二阶导数为 $`\frac{2\sigma_w^2c_T}{m^3}>0`$，因此驻点确为这个理想问题的最小值，而不只是量纲相同的猜测。若任一方差为零，内部最优点可能消失，应按边界与最少重复要求处理。

具体地，平衡种子间方差与回合内噪声得到 $`m\approx\sqrt{\frac{\sigma_w^2c_T}{(\sigma_b^2c_E)}}`$。它不是现实中无需估计参数的万能公式，但能解释为什么训练昂贵时值得多评价、训练波动大时值得增加独立种子。实际 m 和 n 必须是整数，还要考虑失败、并行资源和未知方差，不能机械照抄一个小数。

<a id="value-eval-63"></a>

### 14.2 精确模型评价消除了哪部分成本

本章已知小模型直接解策略价值，因此最终评价没有回合抽样噪声，不需要通过增加评价回合减小该项。但训练随机性仍在，十六个训练种子不因精确评价而变成无限证据。精确模型还帮助枚举三十二个确定性策略认证最优参照，避免把一直向右仅凭直觉命名为最优。

真实大环境通常无法这样求解，此时应在训练与评价预算之间作实际折中。近似模拟器也可能有模型误差，不能把模拟器精确求值当成真实世界真值。模型作为评测工具的假设、版本与验证范围都应说明。能够计算得很精确，与估计对象符合现实，是两个不同要求。

<a id="value-eval-64"></a>

### 14.3 不同随机性需要不同重复

环境实例变化、训练初始化变化与评价回合变化可以构成多层结构。若任务总体包含多种地图或设备，只在一个实例上多训种子，不能充分支持跨实例结论。可以预先分配实例、每实例训练种子与每策略评价回合，并按层次分析。样本数不足时保留逐实例结果，比错误池化更可靠。

共同随机数有时降低差值方差，有时因方法结构不同而效果有限。应把它作为明确耦合设计，而不是保证统计结论的标签。配对单位可以是实例、种子或外部流，区间应对应同一单位。若同时跨多个层次推广，重采样与解释也要相应展开，不能只把所有数放进一个数组。

<a id="visual-example-valuebasedmethods-04"></a>

### 图解算例：更多评价回合不能替代更多独立训练种子

![更多评价回合不能替代更多独立训练种子](images/04-example.svg)

设训练种子间方差为四，每个种子内部单回合噪声方差为一。总体平均的方差分成四除以种子数，以及一除以种子数与每种子回合数的乘积。固定四个种子时，增加回合数只能压低后一个分量，无法突破种子间方差造成的平台。最后一组增加了训练种子，成本也随之变化，因此不能直接称其在相同预算下更优。真正分配资源需加入训练与评价单次成本，核验独立性及方差估计，再考虑连续近似解、整数限制与最小重复数量。



<a id="value-eval-65"></a>

## 15. 平均收益之外的风险与约束

<a id="value-eval-66"></a>

### 15.1 罕见失败需要足够证据

零次观测到失败不代表失败概率零，尤其样本量很小时。若关心极低失败率，需要专门样本量与场景覆盖，而非普通几百回合平均。任务可能还有训练期间危险访问、超时或无法恢复状态，应该预先定义并记录。平均回报高可以与严重尾部风险并存，前面的两策略例子已经说明目标冲突。

对于未知高代价环境，本章人工模型不能提供实际安全保证。它只训练如何定义风险与检查证据。若应用要求硬约束，应有相应模型、监控或限制机制，并评价其对收益、覆盖和成本的影响。把探索关闭不自动消除环境随机风险，增加奖励惩罚也不等于严格满足概率约束。

<a id="value-eval-67"></a>

### 15.2 分位数与条件尾部指标

可以报告回报分位数或最差部分回报的平均，帮助描述尾部表现。但有限样本尾部估计很不稳定，需要更大数据量；不同方法样本量不同也会影响比较。应明确尾部比例、排序规则与不确定性，不能只挑一个有利分位数。分位数是补充描述，不会自动替代任务期望目标。

若某方法通过更早失败缩短回合，平均长度可能降低，看起来更快却不是更高效。应把长度与成功、收益和失败类型联合解释。相反，持续生存任务更长可能正是目标。指标方向来自任务，不存在“长度越短越好”或“回报波动越小越好”的普适规则。

<a id="value-eval-68"></a>

### 15.3 约束与效用需要预先说明

如果应用优先要求成功概率至少某阈值，再在合格策略中最大化收益，评价应采用这种约束顺序。若应用允许用收益交换失败风险，应明确权重或容忍范围。研究者不应根据哪个方法获胜再选择偏好。公开多维结果能让不同用户作判断，但主要结论仍应围绕预设问题。

当样本不足以确认约束是否满足时，应报告不确定，而不是把点估计略高阈值当成通过。模型选择还可能把噪声推到阈值上方，需要独立确认。精确人工模型可作为理想参照，真实环境则要更谨慎地处理估计误差与分布变化。

<a id="visual-insight-valuebasedmethods-04"></a>
### 深入图解：平均收益更高的策略仍可能承担更差尾部风险

![平均收益更高的策略仍可能承担更差尾部风险](images/04-insight.svg)

策略 A 每回合收益恒为一，策略 B 有零点九五概率得到二、零点零五概率损失十。B 的期望收益为一点四，超过 A 的一，但最差百分之五收益均值为负十，远差于 A。图中柱高是离散概率质量，总和各为一，横轴按收益类别排列，不把柱间距离解释为连续密度。应在任务开始前明确平均回报、尾部指标和硬约束，避免事后只挑有利指标。有限评估可能漏掉罕见失败，不能因为若干回合未出事就宣称满足安全保证。



<a id="value-eval-69"></a>

## 16. 环境版本、部署变化与可复现记录

<a id="value-eval-70"></a>

### 16.1 环境改变后参照也要改变

本章滑动概率零点二五，与第二章零点一五不同，所以最优入口值从原来的约零点七八二变为约零点六六五。这个变化不是学习算法退步，而是任务更难。任何奖励、转移、起点或终止规则变化，都需要重新计算可用参照，不能沿用旧最佳值判断新系统。

环境包装层也会改变任务，例如动作重复、奖励裁剪或自动重置。报告应说明实际智能体接收的接口，而不仅是底层环境名称。自动重置后若把新起点误当成上一回合下一状态，会严重污染尾部目标；这个错误可能在平均曲线上不明显，需要字段级检查。

<a id="value-eval-71"></a>

### 16.2 冻结系统包含哪些状态

表格本身容易冻结，深度系统还可能有归一化统计、随机层、记忆状态和优化器缓存。评价模式、隐藏状态重置和动作掩码都应明确。只冻结权重不一定冻结整个决策函数。若系统允许记忆跨回合，需要解释它是否符合部署任务，不能让测试历史变成未声明条件。

复现记录至少保留环境配置、策略检查点、预处理、评价动作规则、种子分工与预算。相同权重配不同动作映射或输入归一化，已经是不同系统。清楚记录这些内容，比一个孤立文件名或最高分更能支持他人复核与继续研究。

<a id="value-eval-72"></a>

### 16.3 独立确认与诚实交付

本章四段实验可在普通 CPU 上独立执行。完整导航实验枚举全部确定性策略，以已知模型给出最优参照；训练与配对区间则来自正文规定的随机流和预算。比较结果时保留全部预设种子，不因分数不理想而筛选运行。人工统计模拟用于解释方差与选择偏差，其数值不代表真实机器人或游戏成绩。

真正的完成标准是读者能够从任务定义走到公式、代码、独立测量与结论边界。若一个方法没有在当前预算下稳定改善，就如实记录；若证据只覆盖小模型，就限定在小模型。清楚的负结果与可检验假说，能够为下一轮研究提供可靠起点，比不受条件约束的成功叙述更有用。

<a id="value-eval-73"></a>

## 17. 多任务汇总与指标尺度

<a id="value-eval-74"></a>

### 17.1 奖励尺度不同不能盲目平均

如果一个任务回报通常在零到一，另一个在零到一万，直接平均会让后者主导，即使二者在应用中同样重要。可以预先定义任务权重或归一化参照，但参照选择本身就是评价协议。分母接近零的归一化会不稳定，基线版本变化也会改变分数。应公开原始逐任务成绩与归一化规则，让汇总能够被复核。

中位数、截尾均值和其他稳健汇总可以减少极端值影响，却也可能弱化少数严重失败。它们各自回答不同总体问题，不是一个替代所有风险评价的万能统计。若真实应用要求每个任务都可靠，就必须保留逐任务与失败指标，不能用一个稳健平均把困难场景从结论中消失。

<a id="value-eval-75"></a>

### 17.2 环境集合也是抽样设计

在十个固定环境上训练很多种子，能够估计这些环境下的方法波动，却不直接代表所有未知环境。如果环境是从某个总体随机选取，才可以在相应设计下讨论跨环境推广；若环境是人为挑选，应限定为这套基准。训练种子与环境实例层次不能互相替代，多跑同一简单环境不会自动增加任务多样性证据。

当方法针对公开基准长期开发，基准本身也可能被适应。额外未见环境或新的预设条件能提供补充确认，但它们又需要明确来源和难度。评价不是寻找一个永远不会被影响的数字，而是持续保持问题、数据与结论之间的独立性和透明度。

<a id="value-eval-76"></a>

## 18. 四个实验如何共同支撑结论

层级方差实验得到经验方差约零点零六六八，正确理论值零点零六五七五，而错误独立假设只给零点零零六零三。它隔离了独立单位问题，并不要求真实强化学习收益正态。完整导航实验则把评价噪声通过精确模型消除，只保留训练随机性，说明即使分数测得很准，方法比较仍可能因训练重复少而不确定。

故障实验给最优一步动作值整体加一百，贪心动作不变但残差变成一百；真正终止错误自举把目标一夸大到十，截断错误清尾把十压成一；动作编号反转把收益二变成一。这些都是不需训练就能定位的错误，提醒读者不要把所有异常都推给复杂优化。赢家选择实验进一步表明，即使没有学习算法，开发择优也能制造虚假乐观。

四类证据分工明确：理论反例检查统计逻辑，完整训练检查有限预算表现，最小故障检查语义与接口，选择模拟检查开发流程。它们相互补充，不承担超出范围的证明。最终没有宣称某步长普遍更好，也没有把人工小模型扩展成真实系统保证。读者可以在这些可靠基础上继续提出新问题，而不必先接受未经检验的结论。

本章两种方法覆盖项数量都为十，只表示每个状态动作至少出现一次，完全不表示访问次数分布相同，也不表示同一随机流产生同一轨迹。一个项访问一次与访问一百次，在这个粗覆盖率上没有区别，估计信息量却可能相差很大。后续若要检验覆盖机制，应继续保留完整计数和关键转移，而不是只比较一个满分覆盖率。

同样，十六个种子仅两个非零收益差，使百分位区间主要反映已有少数离散结果的重复组合。区间跨零既不是递减步长稳定获益的证据，也不是两套方法在总体上等价的证明。进一步研究应扩大独立训练或针对异常路径作预设干预，然后使用新的确认种子。把这些限制放在结果旁边，能够让有限实验仍然提供准确而有用的信息。
