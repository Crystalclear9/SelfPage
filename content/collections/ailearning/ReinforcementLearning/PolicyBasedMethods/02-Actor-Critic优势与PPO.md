## 1. Actor 与 Critic 分别估计什么

Actor 参数化动作分布，Critic 估计某个明确策略和目标下的价值。两者可以共享网络，也可以完全分开；关键不是网络数量，而是监督对象、采样分布与更新路径。一个价值输出拟合训练回报很好，不自动说明它适合当前策略梯度；一个 actor loss 降低，也不等于环境回报提高。

沿用上一章的起始折扣目标，动作价值表示从当前状态动作开始的相对折扣回报，状态价值是策略动作平均。优势为二者之差，表达相对当前策略的好坏。有限时域需要时间索引或剩余时间输入，终止之后价值为零，外部截断则按原任务定义处理。本章先推导估计器，再讨论控制更新的替代目标。

<a id="policy-2-detail-2"></a>

### 1.1 为什么需要自举

完整回报要等到轨迹结束或较长未来才能获得，包含许多随机事件。自举使用下一状态价值近似后续回报，可以更早更新并减少某些波动，却把价值误差传入目标。这个交换不是免费提升，也不意味着有了 critic 就不需要独立环境评价。应分别观察估计偏差、方差和最终策略效果。

Actor–Critic 是方法框架，不是单一损失。可以使用单步时序差分、多步回报、GAE 和不同策略更新；也可以采用不同数据复用与价值拟合方式。把整个家族简化成“actor 负责动作、critic 负责评分”，容易漏掉这些评分何时有效，以及如何影响梯度。

<a id="visual-policybasedmethods-02"></a>
### 图解：PPO 的分段激励：正负优势、逐样本裁剪与KL边界

![PPO 的分段激励：正负优势、逐样本裁剪与KL边界](images/02-concept.svg)

**读图。** 固定同一状态、两个动作及采样旧概率 $`(0.5,0.5)`$，新概率改为 $`(0.8,0.2)`$。蓝色动作一的优势设为一，橙色动作零的优势设为负一；旧概率加权优势为零。比率分别为 1.6 与 0.4，既没有被改回裁剪区间，也没有被当作相互独立的自由变量。

取 $`\epsilon=0.2`$，逐样本取原目标与裁剪目标的较小者：动作一得到 $`\min(1.6,1.2)=1.2`$，动作零得到 $`\min(-0.4,-0.8)=-0.8`$。按旧概率平均后的裁剪代理目标为 0.2，未裁剪代理目标为 0.6。两个样本在这个点都进入平台，但完整旧到新 KL 为 $`\frac12\log\frac{0.5}{0.8}+\frac12\log\frac{0.5}{0.2}\approx0.223144`$，并不因此变成零。

下方沿完整二动作分布继续改变 $`p=\pi_{\mathrm{new}}(1)`$，另一个动作的概率始终为 $`1-p`$，因此比率不是两个独立旋钮，而是 $`r_1=2p`$ 与 $`r_0=2(1-p)`$。对全部旧动作精确平均，有
$$
L_{\mathrm{unclip}}(p)=2p-1,\qquad
L_{\mathrm{clip}}(p)=\min(2p-1,0.2).
$$
在 $`p\ge0.6`$ 时两个有利变化都到达各自平台；但
$$
D_{\mathrm{KL}}(\pi_{\mathrm{old}}\Vert\pi_{\mathrm{new}})
=-\frac12\log[4p(1-p)]
$$
仍随 $`p`$ 离开 0.5 而增大。比如 $`p=0.6,0.8,0.95`$ 时，裁剪值都为 0.2，KL 却分别约为 $`0.020411,0.223144,0.830366`$；趋近一时 KL 发散。这里没有遗漏未采到的动作，已经是完整分布枚举，仍然不能从目标平坦推出概率变化受硬约束。图中连续曲线只是给定策略族的解析比较，不表示某次 PPO 更新一定会走到这些点。

本图是已知两动作分布的精确枚举，不是完整训练性能；平台只描述固定优势下的这一项目标。共享网络、其他样本与熵项仍可改变概率。分段公式对应 [PPO 原论文式 7 与图 1](https://arxiv.org/pdf/1707.06347)，后面的分段曲线继续展示另一侧的不利变化为什么不会被裁掉。

## 2. 时序差分残差与优势的条件关系

<a id="policy-2-detail-4"></a>

### 2.1 真实价值下的单步残差

定义 $`\delta_t=R_t+\gamma V^\pi(S_{t+1})-V^\pi(S_t)`$，真实终止处下一价值取零。在当前策略与正确模型下，给定状态和动作，残差期望等于真实优势，因为奖励加后继真实价值的期望就是动作价值。给定状态再对当前动作平均，残差期望为零。

这不表示每次残差就是优势真值，随机转移和奖励仍造成噪声。它也不适用于任意价值网络：若估计误差为 $`e(s)`$，残差多出 $`\gamma e(S_{t+1})-e(S_t)`$。当前状态误差是动作无关基线，但下一状态误差可能随当前动作而变化，因而引入 actor 偏差。

<a id="policy-2-detail-5"></a>

### 2.2 Critic 目标的停止梯度

常见价值拟合把奖励加下一估计值作为固定目标，最小化当前价值与它的平方差，这是半梯度形式。若让目标也反向，会得到不同目标与不同梯度。两者都可以被研究，但不能只因代码都写成平方误差就视为同一算法。目标网络、旧价值与当前价值也要明确身份。

Actor 使用残差或优势时通常分离其梯度，让它作为当前更新权重。共享主干时 critic 的损失仍能更新共同表示，而 actor 不应无意通过优势计算加入额外路径。停止梯度只控制自动微分，不自动修复同批拟合和自举带来的统计偏差。

<a id="sec-1-1"></a>

<a id="policy-2-detail-6"></a>

### 2.3 实验一：精确优势与价值误差

第一动作进入两种第二步状态，之后终止。第一步没有奖励，第二步两个动作奖励分别为零或二、以及一或三。固定策略可以精确计算两个后继价值和起点优势，随后故意加入价值误差，检查 actor 梯度偏差。它把估计误差与优化随机性分开。

```python
import numpy as np
p0,p1,p2,gamma = .4,.25,.75,.9
v1 = (1-p1)*0+p1*2
v2 = (1-p2)*1+p2*3
v0 = gamma*((1-p0)*v1+p0*v2)
q = gamma*np.array([v1,v2])
advantage = q-v0
prob = np.array([1-p0,p0]);score = np.array([-p0,1-p0])
assert np.allclose([v1,v2,v0],[.5,2.5,1.17])
assert np.allclose(advantage,[-.72,1.08])
assert np.isclose(prob@advantage,0)
true_gradient = prob@(score*advantage)
error_current = .3
error_next = np.array([.4,-.2])
approx_delta = advantage+gamma*error_next-error_current
biased_gradient = prob@(score*approx_delta)
expected_bias = prob@(score*gamma*error_next)
assert np.isclose(biased_gradient-true_gradient,expected_bias)
assert np.isclose(true_gradient,.432) and np.isclose(expected_bias,-.1296)
assert np.isclose(prob@(score*(advantage-100)),true_gradient)
print('values',[v1,v2,v0],'advantages',advantage.tolist())
print('actor_gradient exact/approx/bias',true_gradient,biased_gradient,expected_bias)
```

当前状态加常数误差不会改变该梯度，动作相关的后继误差却会。Critic 总损失看似不大，也可能在正好决定策略方向的状态上错得有规律。应在策略访问分布和关键动作分组上分析，而不是只看一个整体均方误差。

## 3. 多步优势与 GAE 的两种表达

<a id="policy-2-detail-8"></a>

### 3.1 从残差和推导多步回报

连续累加若干折扣残差，中间价值项抵消，得到未来若干奖励之和，加边界自举价值，再减当前价值。定义 $`k`$ 步优势估计为 $`\sum_{l=0}^{k-1}\gamma^lR_{t+l}+\gamma^k\hat V(S_{t+k})-\hat V(S_t)`$，它等于 $`\sum_{l=0}^{k-1}\gamma^l\delta_{t+l}`$，前提是边界和终止约定一致。

一步估计更依赖下一价值，多步估计纳入更多真实奖励。更多步不自动更好，因为噪声、轨迹长度和模型误差都在变化。若任务真正终止，自举为零；若只是收集窗口结束，边界价值仍可能需要保留。不能把所有数组末端都当终端，否则目标被采样器改变。

<a id="policy-2-detail-9"></a>

### 3.2 指数加权残差

GAE 使用 $`\hat A_t=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l}`$，其中迹参数通常在零到一之间。它也可以写成不同步数优势的几何混合，有限轨迹需要正确处理最后一项权重。反向递推为当前残差加折扣迹系数乘下一优势，适合线性时间计算。

当迹参数为零，只剩单步残差；为一且到真实终止时，变成完整回报减当前估计价值。后者即使当前基线不精确，也可在相应独立条件下给出正确 actor 梯度，但其数值不一定是无偏真实优势。应区分优势估计本身与乘动作得分后的梯度估计。

<a id="deep-dive-2"></a>

<a id="policy-2-detail-10"></a>

### 3.3 偏差条件到底是什么

若使用真实价值、后续按当前策略行动、终止与自举正确，则未来残差在适当条件下为零均值，任意合理迹参数的条件期望可以恢复当前真实优势。若价值不精确，短迹会把未来误差带入，不能笼统宣称 GAE 无偏。常用说法中的偏差方差交换必须先固定目标与边界。

有限采样和未知价值下，迹参数选择依赖任务。较大值通常更接近回报、较小值更依赖自举，但方差并不在所有环境中严格单调。应在固定参数和共同数据上比较估计器，再通过独立训练评价最终效果。一个经验默认值不是无须检验的理论最优常数。

<a id="visual-insight-policybasedmethods-02"></a>
### 深入图解：GAE 同时受迹衰减和残差符号影响

![GAE 同时受迹衰减和残差符号影响](images/02-insight.svg)

上方将残差和展开成一次可复算的累计过程：取 $`\lambda=0.5`$ 时，$`\gamma\lambda=0.45`$，三个贡献为 $`1,-0.225,0.050625`$。从一开始，第二步的负残差把累计值降到 $`0.775`$，第三步再提高至 $`0.825625`$。中间两根是连接在既有累计值上的增量，最后一根才从零表示总优势，不能把每根柱都读成独立目标。

下方保持同一残差序列与边界，只改变 $`\lambda`$，有 $`A(\lambda)=1-0.45\lambda+0.2025\lambda^2`$。端点分别是 $`A(0)=1`$ 与 $`A(1)=0.7525`$；对 $`0\le\lambda\le1`$，导数 $`-0.45+0.405\lambda<0`$，所以这条特定曲线单调下降。更远项权重增加时，负残差与正残差一起进入，不能凭“看得更远”就断言优势更大。

这是固定数组的路径代数，不是某环境的方差曲线，也不是较小 $`\lambda`$ 一定更好的证据。真实训练中残差由奖励与价值估计产生，策略和 critic 都会改变它们；是否更接近真实优势、是否更利于更新，应再按本章条件期望与价值误差分解分析。真实终止、自举和迹掩码仍须在求和之前正确处理。

## 4. 两种边界掩码

<a id="policy-2-detail-12"></a>

### 4.1 是否自举与是否连接下一回合

残差中的自举掩码回答下一状态是否有原任务未来价值，迹掩码回答当前轨迹是否应继续递推到数组下一条。真实终止两者通常都为零；外部截断可以保留真实最终观察的价值，但必须在重置处切断迹，避免把下一回合优势接上。两个问题不同，不能只用一个混合 done 标志处理全部情况。

如果环境接口自动重置，返回的普通下一观察可能已经属于新回合。截断自举需要原回合的最终观察，而不是重置初态。数据字段身份要明确，价值估计再准确也无法修复用错状态。第三章会把这些要求落实到轨迹结构和批量实现。

<a id="policy-2-detail-13"></a>

### 4.2 实验二：递推、望远镜与边界

下面核对有限残差和与反向递推一致，迹参数一时恢复真实终止回报减价值；再检查外部截断保留自举，以及重置后大回报不能穿越边界。它是确定性数组实验，不训练策略，因此可以直接定位索引和掩码错误。

```python
import numpy as np
def gae(rewards,values,next_values,bootstrap,trace,gamma,lam):
    delta = rewards+gamma*bootstrap*next_values-values
    out = np.zeros_like(delta)
    carry = 0.
    for t in range(len(delta)-1,-1,-1):
        carry = delta[t]+gamma*lam*trace[t]*carry
        out[t] = carry
    return out,delta
r = np.array([1.,2.,3.]);v = np.array([.4,.8,1.1])
nv = np.array([.8,1.1,0.]);boot = np.array([1.,1.,0.]);trace = np.array([1.,1.,0.])
gamma,lam = .9,.7
adv,delta = gae(r,v,nv,boot,trace,gamma,lam)
explicit = np.array([sum((gamma*lam)**l*delta[t+l] for l in range(3-t)) for t in range(3)])
assert np.allclose(adv,explicit)
mc,_ = gae(r,v,nv,boot,trace,gamma,1.)
returns = np.array([1+.9*2+.9**2*3,2+.9*3,3.])
assert np.allclose(mc,returns-v)
cut,_ = gae(np.array([1.]),np.array([.4]),np.array([5.]),np.array([1.]),np.array([0.]),.9,1.)
assert np.allclose(cut,[1+.9*5-.4])
r2 = np.array([1.,2.,100.]);vals = np.zeros(3)
a,_ = gae(r2,vals,vals,np.zeros(3),np.array([1.,0.,0.]),.9,1.)
assert np.allclose(a[:2],[2.8,2.])
print('GAE',adv.tolist(),'MC advantage',mc.tolist(),'truncated bootstrap',cut.tolist())
```

窗口截断和任务期限还要区分。有限任务到期若规定未来无奖励，应该像真实终止；无限任务被采样器中断则可能保留自举。代码接受显式掩码，不能替使用者决定任务语义。先定义任务，再给每条边界赋正确字段，是完整实现的前提。

![自举掩码与迹递推掩码解决不同边界问题](images/02-example.svg)

## 5. 旧策略替代目标与分布变化

<a id="policy-2-detail-15"></a>

### 5.1 概率比的条件意义

固定旧策略收集的状态动作，定义比率 $`r_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{old}(a_t\mid s_t)}`$。在旧策略对新策略关心动作有支持时，动作比可以校正同一状态下动作分布，但不自动把旧状态访问变成新访问。完整轨迹比率可以表达另一种校正，长乘积却可能高方差。

局部替代目标使用旧访问与旧优势，在参数等于旧策略时可匹配相应策略梯度。离开该点后，状态分布变化和优势误差成为近似来源。固定批次多轮更新不是免费获得更多独立交互，必须监测策略偏移并重新收集数据。TRPO 与 PPO 都围绕这个问题设计不同控制。

<a id="policy-2-detail-16"></a>

### 5.2 旧 log 概率必须固定

旧策略 log 概率来自采集时快照或固定数值，更新过程中不能随当前策略重算后替代，否则比率可能一直为一。优势也通常在这一轮更新前构造并固定。当前策略每轮重新评分实际采样动作，分子随参数改变，分母保留行为身份，这才是该替代目标。

如果采样时有动作掩码、温度或变换，记录的旧分布必须对应真实行为。不能用未变换高斯或未掩码分布冒充执行概率。前文对采样分布与执行动作一致性的要求，在这里同样重要：策略、输入、动作与 log 概率必须描述同一个事件。

## 6. PPO 裁剪的分段激励

<a id="policy-2-detail-18"></a>

### 6.1 最小值形式

常见裁剪目标取 $`\min(r\hat A,\operatorname{clip}(r,1-\epsilon,1+\epsilon)\hat A)`$ 并对数据平均，再最大化。优势为正时，过大比率不再获得额外收益；优势为负时，过小比率不再因继续压低坏动作而获得额外收益。另一侧偏离仍保留惩罚方向。这不是简单把所有比率硬限制在区间内。

裁剪只改变目标的某些样本局部梯度，优化器仍可以因其他样本、共享参数、动量或较大步长把比率推到区间外。它也没有直接限制所有状态的 KL，更没有原任务回报逐步单调保证。应准确说目标激励被截断，而不是概率变化被强制投影。

<a id="policy-2-detail-19"></a>

### 6.2 优势符号很重要

正优势在比率低于下界时，目标仍随比率增加而改善；负优势在高于上界时，仍惩罚增大。若不分符号直接裁剪后相乘，会丢掉这些恢复方向。边界处函数不可光滑，自动微分采用具体约定，梯度测试应避开边界或明确比较次梯度。

优势若有估计误差，裁剪也可能保护错误方向。归一化、奖励尺度和价值误差都影响实际更新，不能把裁剪当作万能安全层。训练诊断应同时看回报、比率、KL、裁剪激活比例、熵与价值误差，它们各自测不同问题。

<a id="policy-2-detail-20"></a>

### 6.3 实验三：梯度与非硬约束反例

下面对正负优势和不同区间比率逐项求导，再展示同一批仅含某动作时，裁剪目标已平坦，但全分布 KL 仍可很大。这个反例不宣称某次真实训练必然退化，只证明裁剪公式不是比率或 KL 的硬约束。

```python
import numpy as np
import torch
torch.set_num_threads(1)
ratio = torch.tensor([.5,.9,1.1,1.5,.5,.9,1.1,1.5],dtype=torch.float64,requires_grad=True)
adv = torch.tensor([1.,1.,1.,1.,-1.,-1.,-1.,-1.],dtype=torch.float64)
clipped = ratio.clamp(.8,1.2)
objective = torch.minimum(ratio*adv,clipped*adv)
objective.sum().backward()
assert torch.allclose(ratio.grad,torch.tensor([1.,1.,1.,0.,0.,-1.,-1.,-1.],dtype=torch.float64))
old = np.array([.01,.99])
flat_values = [];kls = []
for new in [np.array([.5,.5]),np.array([.9,.1])]:
    sampled_ratio = new[0]/old[0]
    flat_values.append(min(sampled_ratio,np.clip(sampled_ratio,.8,1.2)))
    kls.append(float(np.sum(old*np.log(old/new))))
assert np.allclose(flat_values,[1.2,1.2])
assert kls[1]>kls[0]>.5
print('clip_values',objective.detach().tolist(),'gradients',ratio.grad.tolist())
print('same sampled objective',flat_values,'full KL',kls)
```

只看被采样动作上的目标，无法约束未被覆盖的状态动作。实际大批次可能提供更多覆盖，但仍是有限样本。平均 KL 早停可以辅助限制偏移，却不等于理论最大状态约束。每种工程监测都有具体范围，应在独立评价中确认实际效果。

## 7. TRPO 联系与理论保证的边界

<a id="policy-2-detail-22"></a>

### 7.1 性能差分与访问替换

在折扣有界任务中，两个策略的性能差可以写为新策略访问下旧优势的期望，带相应访问归一化系数。局部替代目标将新访问换成旧访问，方便利用已有数据。两者差距来自访问变化，不是仅把动作比率算对就自动消失。

如果能在所有状态控制策略距离，并满足优势有界等条件，可以给替代目标与真实性能之间的误差界。它解释小步更新的动机，但实际 TRPO 用采样平均 KL、局部二阶近似和数值求解，已经是对理论方案的近似。不能把论文中的理想单调结论无条件赋给每次有限实现。

<a id="policy-2-detail-23"></a>

### 7.2 Fisher 与局部信赖域

在旧参数附近，KL 的一阶项为零，二阶项由相应 Fisher 或 KL Hessian 描述。约束二次近似下最大化线性替代目标，得到与逆 Fisher 乘梯度相关的方向。实际使用共轭梯度、阻尼与回溯，避免显式构造巨大矩阵。每一步都有近似和容差，不是简单把学习率调小。

PPO 的裁剪形式试图用更简单目标抑制部分过大改动，但不是精确求解同一信赖域约束。二者有共同动机，不是同一个算法。比较时应报告采样、更新次数、约束监测和最终任务结果，而不是只按实现复杂度给出普遍优劣。

<a id="policy-2-detail-24"></a>

## 8. Critic、熵与 actor 目标分别验收

<a id="policy-2-detail-25"></a>

### 8.1 值损失不等于概率裁剪

价值拟合通常最小化预测与固定回报目标的误差；某些 PPO 实现还对价值变化作裁剪，但这是独立选项，不由策略比率公式推出。值裁剪可能抑制更新，也可能限制修正大误差。报告应写具体表达式和参考值，不能只说使用 PPO 就认为所有组件相同。

熵项作用于动作分布多样性，与优势裁剪也不同。熵高不保证到达关键状态，熵低也可能表示已经学会确定策略。系数、归约、动作维度和访问权重都影响尺度。共享主干时，价值和熵梯度可以改变策略，即使 actor 裁剪项局部平坦，因此监测完整更新尤其重要。

<a id="policy-2-detail-26"></a>

### 8.2 实际训练的选择角色

训练交互用于更新，开发回合用于选择超参数或检查点，最终测试在冻结后确认。若在同一环境分布上独立抽样，也应说明随机流与选择次数；若目标是新环境或新来源，需要相应分组留出。一次玩具成功只支持当前机制与范围，不应外推到复杂机器人或大型语言策略。

完整 PPO 循环将在第四章运行，本章三段实验先核验估计、边界与裁剪。它们没有安装环境、训练外部模型或保存权重。代码可以独立运行，观察值与断言对应具体理论对象，避免把一个能跑的算法名当成全部正确性证据。

## 9. 进阶练习与详细解答

<a id="policy-2-detail-28"></a>

### 9.1 题一：残差等于优势吗

题目：真实价值下的一次时序差分残差是否就是确定优势？

解答：通常只是给定当前状态动作后期望等于优势，实际奖励和转移仍随机。用近似价值时还多出前后误差。应区分样本、条件期望与估计器偏差，不把一条残差当成精确评价。

例如本章第一步给定动作后转移确定，使用真实后继价值时首个残差恰好等于该动作优势；如果下一状态本身随机，同一动作的残差还会在多个值之间波动。两种情况都满足条件期望结论。验证代码时先用确定转移排除索引，再增加随机性检验均值，能把公式错误和正常采样噪声区分开。

<a id="policy-2-detail-29"></a>

### 9.2 题二：当前价值误差与下一价值误差

题目：为何当前状态误差常能作为基线抵消，而下一状态误差可能偏置 actor？

解答：当前误差在选动作前固定，得分均值零；下一状态由动作影响，误差可能与得分相关。实验一给出偏差负零点一二九六。Critic 的误差位置和动作相关结构比一个总均方误差更有解释力。

如果两个后继状态都加同一个误差，该部分在当前动作梯度中也可能作为共同常数抵消；本章选择零点四与负零点二，正是为了产生动作相关差异。相同总均方误差可以有不同梯度偏差，误差结构不能被一个平均数完全概括。应该列出当前动作会到哪些状态，以及这些状态的价值误差。

<a id="policy-2-detail-30"></a>

### 9.3 题三：GAE 的两个端点

题目：迹参数为零和一分别对应什么？

解答：零只保留单步残差；一在正确终止边界下为完整相对回报减当前估计价值。后者可作为基线梯度但数值不一定无偏真实优势。截断自举与迹连接需单独处理，不能只看参数值判断目标。

以折扣零点九、迹参数零点五为例，前三项残差系数为一、零点四五和零点二零二五。它不是先对所有奖励平均，也不是把多步优势等权相加。若终止处下一价值未清零，迹参数一的望远镜会留下错误尾项；若只是截断却清零，则会漏掉原任务未来值。端点核验应同时看参数和边界。

<a id="policy-2-detail-31"></a>

### 9.4 题四：真实价值的条件

题目：为什么说真实价值下 GAE 可恢复优势时，还要说明后续策略？

解答：未来残差零均值依赖价值与实际后续动作分布一致。若轨迹来自另一策略，旧价值与新行为不匹配，结论可能失效。离策略修正与数据复用是额外问题，不能因估计器仍叫 GAE 就忽略。

例如一个一步状态旧策略选奖励一动作的概率为零点二，旧价值为零点二；新策略以零点八选该动作，平均奖励变零点八，使用旧基准的残差平均为零点六，并不为零。未来残差零均值的归纳必须使用匹配策略价值。固定旧优势可用于局部替代，但这与声称所有新轨迹残差仍零均值是两回事。

<a id="policy-2-detail-32"></a>

### 9.5 题五：两个掩码

题目：外部截断后自动重置，为什么可能自举掩码为一、迹掩码为零？

解答：原任务仍有未来价值，应从原最终观察自举；但数组下一条属于新回合，不能递推其优势。两掩码回答不同条件。若返回观察已重置，需要另取真正终点，否则估计对象错误。

可以把一条截断记录后接一条新回合的大回报，检查前一优势是否变化。若变化，说明迹越过了重置边界；再单独改变原最终观察的价值，截断残差应按自举规则变化。两个干预分别验证连接和自举，不能只用一份最终数组恰好符合预期来代替两种条件。

<a id="policy-2-detail-33"></a>

### 9.6 题六：样本末端是否终止

题目：收集固定长度后数组结束，是否一律下一价值为零？

解答：不应一律。真正任务结束为零，外部窗口结束可能仍需自举。有限时域到期又取决于任务定义。代码不能根据数组长度替使用者决定，轨迹必须保存停止原因。

若任务明确只允许最后一次动作，之后无任何奖励，那么到期价值为零是模型定义。若无限任务仅因收集器内存满而暂停，下一状态仍有原任务未来，设零改变学习对象。接口可能把两者都表示为循环停止，所以应保留原因字段，而不是根据是否进入下一轮代码来判断。

<a id="policy-2-detail-34"></a>

### 9.7 题七：旧概率随更新重算

题目：每个 epoch 都把当前 log 概率作为 old，可能出现什么？

解答：比率在评分时不断回到一，丢掉采样行为身份，多轮更新不再对应声明目标。旧分母应来自采集快照或固定数值，当前分子每次重算。名字相同不等于状态相同。

采集完成后，可以把旧 log 概率存为分离的独立张量，或者保留真正固定的旧参数快照。简单赋值 old_model=current_model 可能共享同一对象，参数更新会同时改变所谓旧模型。只做 detach 不一定复制存储，若后续原地覆盖仍需留意。验收应在更新前后检查分母数值不变。

<a id="policy-2-detail-35"></a>

### 9.8 题八：正优势越界

题目：正优势比率高于上界时，裁剪项对该比率导数为何为零？

解答：最小值选择较小的裁剪收益，继续增加不再获得该样本额外激励。但其他样本和共享参数仍能改变它，因此不是硬限制。应区分目标平坦和参数被投影。

例如正优势为一，比率从一点五变到二，当前裁剪样本值都为一点二，局部激励相同；但其他数据仍可驱动同一 logit。比率低至零点五时，目标为零点五并保留正导数，鼓励修复被压低的好动作。两侧行为不对称，正是最小值形式的设计，不能简化成区间内才有梯度。

<a id="policy-2-detail-36"></a>

### 9.9 题九：负优势另一侧

题目：负优势比率高于上界，是否也平坦？

解答：不是，乘负数后未裁剪项更小，最小值保留其惩罚方向。负优势只在比率低于下界时停止进一步奖励压低。忽略符号直接裁剪相乘是不同目标。

优势负一、比率零点五时，目标取负零点八，继续减小没有额外收益；比率一点五时，取负一点五，仍有负导数抑制坏动作。这个手算可以避免对乘负数后不等号方向的直觉错误。测试应避开零点八和一点二边界，因为那里导数约定可能不同。

<a id="policy-2-detail-37"></a>

### 9.10 题十：裁剪保证 KL 吗

题目：样本目标都进入平坦区，是否说明全分布 KL 小？

解答：不能，实验三相同裁剪值对应明显不同 KL，未采样区域也可能改变。平均 KL 监测可辅助，但不是所有状态硬界。有限实现没有原任务单调保证，需要独立回报验收。

还要区分被采样动作比率与完整动作分布：一批没有看到某个动作，不表示它没有概率，也不表示更新不会改变它。共享 softmax 的归一化使动作概率相互牵动。即使平均 KL 小，极少数状态仍可能有大变化，理论最大状态约束不能从一个经验均值自动推出。

<a id="policy-2-detail-38"></a>

### 9.11 题十一：动作比率与状态分布

题目：单步概率比是否把旧访问全部转换成新访问？

解答：它只校正给定状态下动作分布，状态访问由历史动作共同影响。局部替代依赖小变化近似，完整轨迹比率又可能高方差。必须说明比较哪一种期望。

一阶段 contextual bandit 的状态由外部固定分布产生，动作不影响后续状态，此时动作校正可能已覆盖主要分布变化；多步任务则一般不同。第一步改变进入第二状态的概率，即使第二步动作比率完全正确，使用旧状态频率仍然是近似。应先检查任务有没有这种控制依赖，再判断简化是否合理。

<a id="policy-2-detail-39"></a>

### 9.12 题十二：TRPO 与 PPO

题目：二者有相同动机，是否意味着裁剪精确解信赖域？

解答：不是。TRPO 近似求带 KL 约束的局部问题，PPO 裁剪改变样本收益的分段激励。实际实现各有近似，理论条件不能互相借用。比较要看完整协议与结果。

二阶 KL 只描述旧参数附近曲率，跨很远时近似误差可能大；共轭梯度求得方向也有残差，阻尼改变矩阵，回溯只在所检查数据上执行。PPO 并没有显式解这组方程。可以说它们共同关注策略改动过大，但不能把一个方法的理论约束直接当作另一个方法的实际性质。

<a id="policy-2-detail-40"></a>

### 9.13 题十三：Critic 目标是否反向

题目：将下一价值也放入平方误差反向，是否仍是普通半梯度 TD？

解答：不是，它加入目标路径导数，改变更新。可作为不同方法研究，但要准确命名和分析。共享参数、旧价值和目标网络身份都应记录。

在一个固定采样目标上停止梯度，表示当前优化只修正预测端。若让下一值也同时移动，网络可以通过改变目标减少误差，而非朝原先固定目标靠近。对带共享参数的时序结构，这种差别尤其明显。不同梯度都能得到有限数字，不能以是否能训练来判断名称是否准确。

<a id="policy-2-detail-41"></a>

### 9.14 题十四：熵梯度越过平坦区

题目：actor 裁剪梯度零，为何策略仍可能变化？

解答：熵、价值共享主干、其他样本、动量和优化器状态都可影响参数。裁剪只是完整目标一部分，不是执行器边界。应观察完整更新后的比率与 KL，而非只看局部导数。

例如 actor 头参数没有直接梯度，价值损失仍可修改它之前的共享表示，最终动作 logits 就会变化。优化器动量还可能在本轮梯度零时继续移动参数。因此应在完整 optimizer.step 后重新测策略，而不是只打印某个损失的反向结果。参数分组、共享层和所有辅助项都属于更新程序。

<a id="policy-2-detail-42"></a>

### 9.15 题十五：价值剪裁是必选吗

题目：策略比率裁剪是否自动要求价值也裁剪？

解答：没有这种必然关系。价值剪裁是独立工程选项，表达式、旧值和系数需要说明。不同 PPO 实现可能在这些部分不同，不能只按算法名字假定完全可比。

假设旧值为一，目标为十，当前值已到十，而值变化宽度只有零点二。原预测误差为零，裁剪预测一点二的平方误差却很大，取较大者会引入不同激励。这个设计可能抑制一次大变化，也可能妨碍修正错误旧值。是否采用应在共同预算下检验，而不是默认越多裁剪越稳定。

<a id="policy-2-detail-43"></a>

### 9.16 题十六：估计器与训练如何分开

题目：怎样比较不同迹参数？

解答：先在固定策略和共同轨迹上与精确参照比较偏差和方差，再在预算一致的完整训练中评价原回报。保持开发选择与最终测试边界，不因一条平滑曲线就宣布普遍更优。

固定策略比较时，使用相同轨迹和价值近似可以减少无关差异，但若想估计采样方差仍需多批独立数据。完整训练时，迹参数会改变后续访问和 critic 拟合，已经不是同一点的估计器问题。两层报告并列，才能解释某个局部低方差方案为何未必有最好最终回报。

<a id="sec-7-1"></a>

<a id="policy-2-detail-44"></a>

### 9.17 题十七：迹参数一与真实优势

题目：完整终止轨迹使用不准确但固定的当前状态基线，回报减基线的数值期望是否等于真实优势？actor 梯度是否仍可能正确？

解答：数值期望是动作价值减估计基线，除非基线恰好为真实状态价值，否则不是同一个优势；但误差只依赖当前状态时，乘动作得分并平均可以抵消，因此梯度仍可正确。这个例子说明无偏优势与正确梯度需要分别命名。外部截断的边界误差、同批拟合自依赖或额外反向路径又会增加其他条件，不能仅凭迹参数一就忽略。

<a id="policy-2-detail-45"></a>

### 9.18 题十八：平均 KL 与最大状态变化

题目：一个稀有状态概率千分之一，其 KL 很大，而常见状态几乎不变，经验平均小能否证明该稀有状态也受控？

解答：不能，平均会按访问频率稀释它，有限批次甚至可能没采到。理论最大状态界需要每个相关状态控制，除非另有覆盖下界和额外推导，否则不能从平均推出。应分组检查关键状态，并在原任务评价少数高代价失败。小平均有诊断价值，但不能承担它未测量的保证。

<a id="policy-2-detail-46"></a>

### 9.19 题十九：裁剪目标的下界对象

题目：裁剪项总小于未裁剪项，能否把它叫真实性能下界？

解答：它只对同一固定数据上的两个替代表达逐项有序。真实性能还涉及新状态访问、真实优势与全部环境期望，未被这个最小值直接控制。要得到任务下界必须加入相应误差界和假设。数学中一个局部不等式不能跨过未分析环节被升级成全系统结论。

<a id="policy-2-detail-47"></a>

### 9.20 题二十：优势平移在裁剪后还等价吗

题目：动作无关基线在普通策略梯度中可抵消，给固定优势统一减常数后，PPO 多轮裁剪目标是否完全相同？

解答：不保证。平移会改变优势符号及其裁剪支路，非线性最小值不再像完整动作期望的未裁剪线性项那样只差常数。旧参数附近的理想一阶关系和有限更新的完整目标不同。优势中心化可以是实用选择，但应准确当作算法配置，而不是由基线定理直接证明全程不变。

<a id="policy-2-detail-48"></a>

<a id="policy-2-detail-51"></a>

## 11. GAE 的完整代数与误差来源

<a id="policy-2-detail-52"></a>

### 11.1 有限几何混合不能漏掉末项

令从当前开始还能使用 $`N`$ 个残差，记第 $`k`$ 步优势估计为 $`A^{(k)}`$。有限 GAE 可以写为前面各步估计按 $`(1-\lambda)\lambda^{k-1}`$ 加权，最后 $`N`$ 步估计的权重则为 $`\lambda^{N-1}`$。全部权重之和为一。若最后仍乘同一个一减迹系数，权重和不足，已经不是原残差和。

把每个多步估计再展开为残差，某个位置残差会出现在所有足够长的项里，几何系数相加恰好得到 $`(\gamma\lambda)^l`$。这就是有限混合与残差和等价的原因。迹参数为一时只有最后多步估计留下，零时只剩第一步。这个证明还要求边界自举相同，不能前一式按终止处理，后一式却保留下一价值。

<a id="policy-2-detail-53"></a>

### 11.2 价值误差的有限窗口分解

固定一条合法轨迹，记估计价值与真实价值之差为 $`e_t`$。两种残差相差 $`\gamma e_{t+1}-e_t`$。将该差乘 GAE 权重求和，逐项整理得到

$$
\hat A_t^{(N)}-A_{t,\mathrm{trueV}}^{(N)}
=-e_t+\gamma(1-\lambda)\sum_{k=1}^{N-1}(\gamma\lambda)^{k-1}e_{t+k}
+\gamma(\gamma\lambda)^{N-1}e_{t+N}.
$$

这个整理可以逐个系数核对。令 $`r=\gamma\lambda`$，误差和先写成 $`\gamma\sum_{l=0}^{N-1}r^l e_{t+l+1}-\sum_{l=0}^{N-1}r^l e_{t+l}`$。当前误差只出现在第二个和中，系数为负一；中间的 $`e_{t+k}`$ 同时出现在两边，净系数是 $`\gamma r^{k-1}-r^k=\gamma(1-\lambda)r^{k-1}`$；末端误差只出现在第一个和中，系数为 $`\gamma r^{N-1}`$。三类位置分别整理，就得到上式，而不是把所有价值误差都近似成一个基线。

取 $`N=3`$、$`\gamma=0.9`$、$`\lambda=0.7`$，路径价值误差依次为 $`(0.3,-0.2,0.4,0)`$。三个残差误差为 $`(-0.48,0.56,-0.4)`$，按 $`1,0.63,0.3969`$ 加权后，优势差为 $`-0.28596`$。从分解式计算则是 $`-0.3+0.27[-0.2+0.63\times0.4]=-0.28596`$。若把末端误差改成 $`0.5`$，还须增加 $`0.9\times0.3969\times0.5=0.178605`$，说明外部截断的价值误差不能因迹已经切断就被忽略。

其中两边比较的是同一轨迹、同一窗口和相同边界下，分别使用近似与真实价值的残差和。它还不是直接减去真实优势，因为真实价值残差和本身仍有采样噪声。先做路径代数，再取条件期望，可以避免混淆三种随机对象。

第一项是当前状态误差，在适当独立条件下作为动作无关基线不改变梯度；中间项包含未来状态误差，可能随当前动作相关；最后是窗口边界误差。迹参数一时中间项消失，但外部截断的边界误差仍可能存在。若真实终止且两种终端价值都为零，最后一项才消失。

<a id="policy-2-detail-54"></a>

### 11.3 无限和条件与梯度无偏

在价值误差有界、折扣迹乘积小于一等条件下，远端项可以趋零，留下当前误差与未来误差加权和。迹参数一时，即使基线价值不准确，完整回报减当前基线仍可产生正确的得分梯度；其条件期望为真实动作价值减估计状态价值，不必数值等于真实优势。无偏梯度与无偏优势不是同一句话。

使用真实价值时，后续各时刻残差在当前策略下条件均值为零，因此对固定当前状态动作，GAE 的期望由首个残差给出真实优势。这里需要价值对应实际后续策略、允许信息和时域。离策略轨迹、错误终止、模型状态不足或同批适应性估计，都可能破坏简单论证。

<a id="policy-2-detail-55"></a>

### 11.4 迹参数与时间抽样的共同作用

GAE 中的折扣决定回报与残差结构，迹参数决定残差混合。起始折扣目标的 actor 更新还需要与上一章一致的时间访问权重，不能因为优势内部已有折扣就自动省略全部外层条件。也可以采用相应访问采样，让权重进入数据分布，但应完整说明。

某些研究把折扣视作降低方差的设计，即便最终关心无折扣任务，这意味着要区分优化的折扣梯度与原始目标。更高任务回报可以是有价值实证，但不能因此说两种数学目标相同。比较迹与折扣时，应使用共同任务评价，并报告改变的是估计、访问还是目标本身。

<a id="policy-2-detail-56"></a>

### 11.5 将数组例子逐项算到目标

实验二的三个残差分别为一加零点九乘零点八再减零点四，得到一点三二；二加零点九乘一点一再减零点八，得到二点一九；终止处三减一点一，得到一点九。折扣迹乘积为零点六三，所以倒推第二优势为二点一九加零点六三乘一点九，等于三点三八七；第一优势为一点三二加零点六三乘三点三八七，等于三点四五三八一。

迹参数一时系数改为零点九，中间价值完全抵消，第一优势变为一加一点八加二点四三再减零点四，等于四点八三。两种结果不同不是代码错误，而是混合步数不同。若将 GAE 加旧价值作为 critic 目标，三个目标约为三点八五三八一、四点一八七和三；它们通常不是该轨迹的纯 Monte Carlo 回报，应该准确称作相应的自举目标。

构造后固定目标，使当前批次多个 epoch 的拟合对象一致；若每轮跟随新值重建，又成为另一种程序。手算到这些具体数字，有助于同时发现残差索引、终端值、迹参数和目标身份四类错误。一个统一函数能运行，并不能替代对其实际统计对象的说明。

<a id="policy-2-detail-57"></a>

## 12. 性能差分与信赖域的细节

<a id="policy-2-detail-58"></a>

### 12.1 从优势的望远镜和证明

取旧策略价值，沿新策略轨迹把 $`R_t+\gamma V_{old}(S_{t+1})-V_{old}(S_t)`$ 折扣求和。中间价值项抵消，若尾项在相应有界与折扣条件下消失，得到新回报减初始旧价值。对初始分布平均，后者就是旧策略目标。因此

$$
J(\pi')-J(\pi)=\frac{1}{1-\gamma}E_{s\sim D^{\pi'},a\sim\pi'}A^\pi(s,a).
$$

状态访问在这里是新策略的归一化折扣分布。这个式子精确，但直接评价所有新策略通常需要新交互。局部替代将其换成旧访问，才可利用已有数据。动作概率比只是实现固定状态下的新动作期望，不负责把访问分布自动换过去。

<a id="policy-2-detail-59"></a>

### 12.2 访问差怎样被动作差控制

设所有状态的新旧动作分布总变差最大值为 $`\alpha`$，转移由固定环境与动作混合产生。每行新旧转移分布的距离可以由动作距离控制。归一化访问满足一个折扣固定点方程，相减后利用随机矩阵的一范数非扩张性，可得访问分布的一范数差不超过 $`\frac{2\gamma\alpha}{(1-\gamma)}`$。

把固定点步骤明确写出来。对有限状态，令 $`d,d'`$ 为旧、新策略的归一化折扣访问行向量，$`P,P'`$ 为对应的行随机转移矩阵，初始分布同为 $`\mu`$。有 $`d=(1-\gamma)\mu+\gamma dP`$、$`d'=(1-\gamma)\mu+\gamma d'P'`$，所以

$$
(d'-d)(I-\gamma P)=\gamma d'(P'-P).
$$

对每个状态，$`\Vert P'(s,\cdot)-P(s,\cdot)\Vert _1\le\sum_a\vert \pi'(a\mid s)-\pi(a\mid s)\vert \le2\alpha`$，因为每个动作条件转移行的概率质量为一。于是 $`\Vert d'(P'-P)\Vert _1\le2\alpha`$。再用逆矩阵的 Neumann 展开 $`\sum_{k\ge0}\gamma^kP^k`$；右乘每个 $`P^k`$ 对行向量的一范数非扩张，级数总系数为 $`\frac{1}{(1-\gamma)}`$，便得到 $`\Vert d'-d\Vert _1\le\frac{2\gamma\alpha}{(1-\gamma)}`$。这里要求相同环境与初始分布；若二者改变，固定点差还会多出相应项。

又因为旧策略下优势动作平均为零，新策略下的优势均值等于新旧动作概率差乘旧优势。若优势绝对值有界，其最大状态均值不超过两倍总变差乘优势上界。将两项放进访问替换误差，得到与总变差平方、优势界及折扣有关的性能界。这解释了为什么理论上控制全状态策略变化有意义，而不仅是任意选小学习率。

<a id="policy-2-detail-60"></a>

### 12.3 理论界中的尺度

在上述记号和条件下，一种直接界为替代值与真实性能差绝对值不超过 $`\frac{4\gamma A_{max}\alpha^2}{(1-\gamma)^2}`$。它来自访问差与优势均值差相乘，不需要假设它们独立。界可能很松，折扣接近一时系数很大，因此不能拿一个很小的样本平均 KL 就直接保证实际提升。

总变差与 KL 可以通过相应不等式联系，但这里需要全状态最大距离和适当支持。经验平均 KL 只测被采样状态上的平均，不排除稀有状态巨大变化。理论最大约束、总体平均约束和有限样本平均是三个不同对象，实际算法采用后两者时必须承认近似。

<a id="policy-2-detail-61"></a>

### 12.4 局部二阶问题的解析方向

设局部替代梯度为 $`g`$，KL 的二阶矩阵为正定 $`F`$，线性目标与二次约束的问题可以用拉格朗日乘子求解。若梯度非零，方向与 $`F^{-1}g`$ 平行，再缩放使二次 KL 达到预算。这是自然梯度与局部信赖域的联系，不是任意预条件优化器都精确等价。

具体设增量为 $`\Delta`$、预算为 $`\varepsilon>0`$，求解 $`\max_\Delta g^T\Delta`$，约束 $`\frac{\Delta^TF\Delta}{2}\le\varepsilon`$。当 $`F`$ 正定且 $`g\ne0`$ 时，最优点必在边界：内部点可以沿有正收益的方向继续放大。拉格朗日驻点给 $`g-\nu F\Delta=0`$，所以 $`\Delta=\frac{F^{-1}g}{\nu}`$；代入边界得到 $`\nu=\sqrt{\frac{g^TF^{-1}g}{(2\varepsilon)}}`$，从而

$$
\begin{aligned}
\Delta_* &= \sqrt{\frac{2\varepsilon}{g^TF^{-1}g}}F^{-1}g,\\[6pt]
g^T\Delta_* &= \sqrt{2\varepsilon\,g^TF^{-1}g}.
\end{aligned}
$$

也可对 $`F^{\frac{1}{2}}\Delta`$ 与 $`F^{-\frac{1}{2}}g`$ 使用 Cauchy–Schwarz 得到同一上界，等号在两者平行时达到。这既给出候选解，也证明它是这个局部子问题的全局最优。若 $`g=0`$，全部可行增量的线性预测收益都为零，不应把零代入上述缩放公式再除零。

例如 $`g=(2,1)^T`$、$`F=\operatorname{diag}(4,1)`$、预算 $`0.01`$，则 $`F^{-1}g=(0.5,1)^T`$，最终 $`\Delta_*=(0.05,0.1)^T`$。它消耗的二次预算是 $`\frac{[4(0.05)^2+(0.1)^2]}{2}=0.01`$，预测收益为 $`0.2`$。若只把欧氏梯度 $`(2,1)`$ 缩到同一预算，系数为 $`\sqrt{\frac{0.02}{17}}`$，预测收益约 $`0.17150`$。差别来自第二个坐标的 KL 代价较低；这解释了自然梯度的度量含义，但不保证较大实际步长后的真实收益仍等于线性预测。

softmax 参数存在冗余时矩阵可能奇异，实际求解常加阻尼或采用适当广义解；这些处理改变局部问题。大网络通常用 Hessian 向量积与共轭梯度近似方向，再回溯检查采样目标和 KL。回溯通过仍不等于真实最大状态约束满足，更不等于原任务严格单调改善。清楚区分各层近似，才是理解 TRPO 而非背诵名称。


![相同二次KL预算下自然梯度方向与欧氏方向的比较](images/02-fisher-trust-ellipse.svg)

图把本节的二维算例放回参数增量平面：椭圆内部满足 $`\frac{4\Delta_1^2+\Delta_2^2}{2}\le0.01`$，横纵坐标使用相同单位长度。蓝色增量 $`(0.05,0.1)`$ 沿 $`F^{-1}g`$ 的方向；橙色增量约为 $`(0.0686,0.0343)`$，沿欧氏梯度 $`g`$，但也被缩到同一个椭圆边界。两者消耗相同二次预算，线性预测收益 $`g^T\Delta`$ 却分别为 $`0.2`$ 和约 $`0.1715`$，因为第一参数坐标的二次代价更高。

椭圆表示给定正定矩阵的局部二阶模型，不是测量到的完整策略 KL 等高线；右侧柱长也是线性预测收益，不是真实训练回报。大步更新、有限样本、矩阵奇异与阻尼等会改变实际问题，仍需本节所述回溯和独立评价。


<a id="policy-2-detail-62"></a>

### 12.5 一个界的数量级例子

设折扣为零点九、优势绝对界为一，若所有状态总变差最多零点零一，前述误差上界为零点零三六；总变差增至零点一，上界变成三点六。平方依赖并不代表界总是紧，折扣分母也会使长期任务的保证很保守。理论界用于理解条件与最坏情况，不应被拿来预测某次训练精确下降多少。

如果真正的最大状态 KL 不超过零点零零零二，适当不等式可以导出上述零点零一总变差界；仅仅样本平均 KL 为这个数，则不能完成同一推理。这里的差异是最大与平均的量词，不是小数点保留位数。每次引用保证时，应把被测统计与定理要求逐项对应。

在复杂任务中，可以把理论界作为设计动机，同时承认实际使用的平均约束、近似优势和数值方向。这样的表述比宣称无条件单调更准确，也让负结果能够指向具体假设失效，而不是被当成算法名称与现实之间无法解释的矛盾。

<a id="policy-2-detail-63"></a>

## 13. PPO 裁剪并没有隐含的全局投影

<a id="policy-2-detail-64"></a>

### 13.1 样本悲观不等于真实性能下界

裁剪目标逐样本取两项最小，因此不超过同样数据上的未裁剪比率优势。这是一种对固定替代项的悲观处理，不意味着它是实际回报的严格下界。旧访问替代误差、优势误差、有限样本和共享参数仍存在。不能把一个 min 符号解释成所有环境安全保证。

如果策略已经在某个样本上超过有利阈值，它不再从该样本获得继续推动的直接激励；但其他样本梯度可能同向影响同一参数，熵和 critic 也会更新共享主干。优化器的动量与有限步长进一步改变结果。因此训练之后实际比率超出区间完全可能，不应通过事后强行截断记录掩盖。

<a id="policy-2-detail-65"></a>

### 13.2 两种裁剪比例不是同一个量

常见诊断统计比率落在区间外的样本比例，但真正目标进入平坦裁剪支路还取决于优势符号。正优势且比率偏低、负优势且比率偏高，都可能在区间外却仍有恢复梯度。可以同时记录越界比例和实际激活的截断比例，帮助判断更新是否过大或优势分布异常。

数值上比率常由新旧 log 概率差取指数，极端差异可能溢出。可记录 log 比率范围并调查根因，不能为了不报错就任意裁剪所有 log 概率而声称目标未变。动作身份、分布支持、学习率和旧状态恢复都值得优先检查。数值修补若改变优化，应准确记录。


![PPO中比率越界与平坦裁剪分支的区别](images/02-clip-activation.svg)

取 $`\epsilon=0.2`$，固定优势后，正优势 $`A=1`$ 的单样本目标是 $`\min(r,1.2)`$，负优势 $`A=-1`$ 的目标是 $`-\max(r,0.8)`$。图中灰色虚线是未裁剪的 $`rA`$，蓝色和橙色实线组成实际裁剪目标。两个比率 $`r=0.5,1.5`$ 分别配上正、负优势，形成四个样本：比率全部在 $`[0.8,1.2]`$ 外，但只有正优势且比率过高、负优势且比率过低的两个样本进入橙色平坦部分。

按 $`(r,A)=(0.5,1),(0.5,-1),(1.5,1),(1.5,-1)`$ 的顺序，目标对比率的局部导数分别是 $`1,0,0,-1`$。所以越界比例为 $`1`$，真正进入平坦支路的比例为 $`\frac{1}{2}`$。这解释了为什么只记录“比率越界率”不能直接当成“actor 已停止更新的样本率”。

这里仅对固定优势下的该单项目标、远离折点的位置讨论比率导数；共享网络、熵奖励、价值损失和其他样本仍可能推动参数变化。裁剪目标也不把比率硬限制在区间内。原式与优势符号的分段图见 [PPO 原论文式 7 与图 1](https://arxiv.org/pdf/1707.06347)。

<a id="policy-2-detail-66"></a>

### 13.3 KL 诊断的两个估计

在旧动作分布采样下，旧 log 概率减新 log 概率的期望是相应 KL，但有限样本均值可能为负。另一个常用表达是比率减一再减 log 比率，在支持充分且旧分布下比率期望为一时，期望同样对应 KL，而每个样本非负。两者的有限样本行为与数值性质不同。

这两种量都条件于所采集状态，不能自动估计最大状态 KL。若动作是连续变换、合法集变化或旧概率不是实际行为，连基础解释也可能失效。诊断字段应注明方向、采样分布与公式，而不是只打印一个名叫 approx_kl 的数。理论符号与代码身份需要对应。

<a id="policy-2-detail-67"></a>

### 13.4 早停是另一个算法规则

按平均 KL 超阈值停止剩余 epoch，可以限制某些经验偏移，但阈值、检查频率和是否回退当前更新都影响结果。只停止后续步骤不一定撤销已经过大的那一步。它与裁剪目标互补，也不是证明原任务单调性的条件替代。应在完整循环中明确执行顺序。

多轮更新次数增加可以提高数据使用，也可能使策略远离行为分布。比较时报告每轮采集数、epoch、小批次和总优化器步数。相同环境步数不代表相同计算，固定计算也不代表相同交互。所谓样本效率改善，应准确说明资源轴。

<a id="policy-2-detail-68"></a>

## 14. Critic 训练与共享参数的相互作用

<a id="policy-2-detail-69"></a>

### 14.1 固定目标与半梯度

用采样回报或 GAE 加旧价值形成 critic 目标时，通常将目标固定，多个 epoch 拟合同一批数值。若每次都用当前值重新构造目标，得到的是另一迭代程序，可能改变稳定性。数据旧不旧、目标旧不旧、策略旧不旧分别是不同身份，不能全用一个 old 前缀含糊处理。

半梯度 TD 不对自举目标求导，与直接最小化某种残差平方不同。后者还涉及目标噪声和双采样等技术问题，不能因为代码能反向就假定是原方法的更完整版本。学习者应先写出预期梯度，再检查计算图，避免自动微分替自己决定算法。

<a id="policy-2-detail-70"></a>

### 14.2 一种可选值裁剪表达

可以把当前值相对旧值的变化裁剪在一个绝对区间，分别计算原预测误差和裁剪预测误差，再取较大者作为损失。这个设计意在抑制某些过大有利改动，但不是所有 PPO 实现都采用，也不把实际值硬投影进区间。它与 actor 的概率比裁剪有不同单位和效果。

奖励整体缩放时，价值、回报和这个绝对裁剪宽度的相对关系会改变。策略比率阈值却是无量纲量。若只缩放奖励而不调整值相关系数，完整算法不一定保持等价。报告必须写具体配置与尺度，不能用一个裁剪系数同时代表所有不同对象。

<a id="policy-2-detail-71"></a>

### 14.3 熵的计算分布

离散策略可以在当前状态上对全部动作精确求熵，条件是合法动作与概率正确归一化。若只用旧策略采出的动作计算负新 log 概率，其期望是旧动作下的交叉熵，未必是新策略熵。多轮更新后这一区别更明显。连续策略还有变换雅可比与熵估计问题，需要对应实现。

**一组数值即可检查梯度是否相反。** 设旧二动作分布为 $`q=(0.5,0.5)`$，当前概率为 $`p=(0.8,0.2)`$，用单个 logit $`\theta`$ 表示第一动作概率 $`p_1=\sigma(\theta)`$。真正的新策略熵与旧动作采样得到的交叉熵分别为

$$
\begin{aligned}
H(p) &=-\sum_a p_a\log p_a\approx0.500402,\\[6pt]
H(q,p) &=-\sum_a q_a\log p_a\approx0.916291.
\end{aligned}
$$

二者对该 logit 的导数是

$$
\begin{aligned}
\frac{dH(p)}{d\theta} &=p_1(1-p_1)\log\frac{1-p_1}{p_1}
\approx-0.221807,\\[6pt]
\frac{dH(q,p)}{d\theta} &=p_1-q_1=0.3.
\end{aligned}
$$

若都作为需要最大化的“熵奖励”，真熵会把当前八成的动作拉向更均匀，误用交叉熵却把它继续推得更极端。这不是两个估计器只有不同常数或方差，而是期望目标已不同。旧策略采到的稀有低新概率动作，会给负对数新概率很大的数值，单纯增大该数并不等于增加新策略随机性。

有支持覆盖时，重要性比率可以在数值期望层面纠正：

$$
E_{a\sim q}\left[\frac{p_a}{q_a}(-\log p_a)\right]=H(p).
$$

但要通过这个表达式求新策略熵梯度，比率也依赖参数，不能一边引用该恒等式、一边无说明地把比率停止梯度。若只对固定权重下的负 log 概率求导，在恰用真实 $`\frac{p}{q}`$ 的展开点，期望为 $`-\sum_a p_a\nabla\log p_a=0`$，反而丢掉需要的熵梯度。离散动作数足够小时，直接对当前完整概率求熵更容易核验；采样估计则应分别验证期望值和实际求导路径。

熵正则可能让 actor 裁剪平坦时策略继续变化，价值共享主干也一样。完整优化器目标通常是几部分加权和，不能只检查其中一项梯度。可以用小网络分别反向各损失，观察共享参数的贡献，再检查总更新。这是机制诊断，不代表根据梯度方向就能预测全部训练结果。

<a id="policy-2-detail-72"></a>

### 14.4 Critic 指标的解释

价值误差低可能来自目标本身简单、奖励尺度小或数据覆盖有限，不必然意味着 actor 方向可靠。解释方差等指标也依赖分母和目标变化，目标方差接近零时数值容易不稳定。应保留原始误差、回报分布和状态分组，再结合优势偏差与任务结果。

如果 critic 拟合当前批很好，却在新策略访问区域失效，多轮 actor 更新可能利用这种误差。可以缩短复用、改善覆盖或调整价值模型，但应通过独立数据确认。与奖励代理类似，优化器会进入估计器未充分约束的区域，不能只用旧批次分数证明整个系统可靠。

<a id="policy-2-detail-73"></a>

## 15. 从数组核对到完整算法验收

<a id="policy-2-detail-74"></a>

### 15.1 三段实验实际说明什么

第一段得到真实起点 actor 梯度零点四三二，后继价值误差使其变为零点三零二四，偏差负零点一二九六；当前状态常数误差抵消。第二段有限 GAE 约为三点四五三八一、三点三八七和一点九，迹参数一恢复完整回报减价值；截断自举结果为五点一，重置后大回报没有越界传播。

第三段八个比率与符号组合的导数逐项吻合分段规则。只观察少数动作时，相同裁剪值一点二可以对应全动作 KL 约零点六三七和二点二二五，证明不是硬约束。它没有运行复杂环境，也没有据此断言真实 PPO 必定失败。每个数值只支持声明的机制范围。

<a id="policy-2-detail-75"></a>

### 15.2 数据角色与调参机会

固定参数估计器实验、完整训练开发选择与最终评价是不同角色。可以用开发环境调迹参数、裁剪宽度和学习率，但最终测试不能反复指导修复后仍当独立证据。若来源或动力学分布不同，应明确分组和留出，而不是只换一个随机种子就声称跨环境泛化。

完整方法比较还要记录失败运行、交互预算和总更新次数。只挑最好种子或最流畅曲线会隐藏不稳定。玩具环境可以验证边界和执行顺序，真实高维应用需要新的数据、模型和资源证据。教学章节的价值是让这些问题可追踪，而不是制造一个无条件成功标签。

<a id="policy-2-detail-76"></a>

### 15.3 错误定位的实际顺序

先核对轨迹字段、终止与截断，再核对回报、优势和目标固定，随后检查新旧 log 概率、分段梯度和优化器状态，最后才讨论网络容量与探索。若小模型都不符合解析值，扩大环境只会让错误更隐蔽。机制检查通过后，再用独立回报判断方法是否有效。

当一次修改改善训练，却损害测试，应分别考虑选择偏差、访问变化、critic 外推与任务分布，而不一概归咎裁剪宽度。每个解释都需要具体干预。保留完整错误台账能让下一轮实验有信息量，也避免对同一曲线不断编造理论故事。

<a id="policy-2-detail-77"></a>

### 15.4 小批次并不保留全部策略覆盖

一个 rollout 中某些状态只出现一次，随机小批次可能完全不含对应动作。多个 epoch 重排提高了这些记录的重复使用，却没有创造新的环境证据。旧优势如果在该点估计错误，重复优化会更充分迎合它；如果某个关键状态从未出现，裁剪也无法约束那里。应记录覆盖与每轮真实交互量，不把优化器更新数当独立样本数。

可以固定同一旧策略，收集多批独立数据，比较少量重复 epoch 与更多新交互的效果。两者计算和环境成本不同，应在目标资源轴下评价。这个研究问题能够明确区分数据复用、估计误差和更新约束，也为第四章的完整循环提供一个具体扩展方向。
