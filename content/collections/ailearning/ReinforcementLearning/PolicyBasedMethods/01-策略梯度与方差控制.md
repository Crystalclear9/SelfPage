## 1. 直接优化策略，先定义要优化的期望

策略方法直接参数化动作分布 $`\pi_\theta(a\mid s)`$，通过环境交互改进期望回报。它并不要求每个动作都确定，也不一定先求完整动作价值再取最大。随机策略可以表达探索、多解和部分可观测下的随机决策，但概率分布的存在不自动解决探索覆盖、长期信用分配和估计方差。

本章固定初始分布与环境机制不依赖策略参数，研究折扣回报 $`J(\theta)=E_\theta[\sum_{t=0}^{T-1}\gamma^tR_t]`$。奖励在动作导致的交互后产生，$`T`$ 可以是固定有限时域或满足条件的终止时间。无限时域需要折扣和有界性等条件保证期望及梯度可处理。平均奖励、有限总回报和折扣目标不能只因都叫策略梯度就混用。

<a id="policy-1-detail-2"></a>

### 1.1 状态输入必须满足声明的信息条件

完全可观测任务可以用马尔可夫状态，有限时域还要包含剩余时间或使用时间索引策略。部分可观测任务可以用完整允许历史、信念或明确近似的记忆摘要。若策略直接读取部署不可见的隐藏状态，优化的就不是原信息条件下问题。梯度公式无法修复输入泄漏，它只会认真优化给定函数。

本章解析例子使用极小已知模型，让目标、采样概率和真实梯度都能枚举。它们用于检查数学与估计器，不代表已经解决未知大环境。后续章节会把相同约定接入 Actor–Critic、GAE 和完整 PPO 循环。先建立清楚目标，才能知道后续近似究竟改变了什么。

<a id="policy-1-detail-3"></a>

### 1.2 离散策略的最小参数化

二元动作用一个 logit 参数，选一概率为 sigmoid，选零为其补数。多动作通常用 softmax，logits 同加常数不改变分布，所以参数表示可能冗余。梯度应基于实际选中动作的 log 概率，而不是对所有动作概率随意平均。动作掩码也属于策略定义，非法动作不能先采出再无声替换成另一个动作。

连续动作可以用高斯等密度，标准差必须为正，维度联合概率通常按 log 密度求和。动作边界、压缩变换和裁剪都会改变执行分布，不能只把未经变换高斯的 log 概率当最终动作概率。连续动作的细节将在本章后部展开；离散和连续共享似然比思想，但支持与数值条件各有区别。

## 2. 似然比恒等式从哪里来

<a id="policy-1-detail-5"></a>

### 2.1 对轨迹概率求导

轨迹包含状态、动作与奖励。若初始分布和环境转移与参数无关，轨迹概率中依赖参数的部分是各时刻策略概率的乘积。因此对轨迹 log 概率求导，只留下各时刻 $`\nabla_\theta\log\pi_\theta(A_t\mid S_t)`$ 的和。环境可以不可微，甚至只提供采样接口，这并不妨碍该恒等式成立。

在可交换微分与求和或积分、支持处理正确、相关期望有限的条件下，有

$$
\nabla J=E_\theta\left[\left(\sum_t\nabla\log\pi_\theta(A_t\mid S_t)\right)\left(\sum_k\gamma^kR_k\right)\right].
$$

它不是对采出的离散动作直接求普通导数，而是通过该动作出现概率的变化估计目标导数。若环境或奖励本身也显式依赖同一参数，还要加入对应导数项，不能自动忽略。若分布支持随参数改变，边界项和正则条件也需要重新分析。

<a id="policy-1-detail-6"></a>

### 2.2 得分均值为零

在上述正则条件下，固定状态下，$`E_{a\sim\pi}[\nabla\log\pi(a\mid s)]=\sum_a\nabla\pi(a\mid s)=0`$。这是后续去掉过去奖励和动作无关基线的关键。连续情形需要对密度积分并满足边界与微分交换条件。它不是对任意数据分布都成立，只对相应策略分布的期望成立。

对二元 logit，得分等于动作减选一概率。若实际数据来自另一行为策略，却不作正确处理，得分期望一般不再为零。把离线轨迹直接当作当前策略样本，会改变估计。重要性采样可以在支持与方差条件下校正某些分布差异，但不是任何旧数据都能免费复用。

<a id="sec-1-1"></a>

<a id="policy-1-detail-7"></a>

### 2.3 去掉过去奖励的因果证明

时刻 $`t`$ 的动作得分乘上动作之前已经确定的奖励，对当前动作条件期望为零。对完整轨迹再平均仍为零。因此只需保留从当前动作起可能受它影响的未来奖励，得到回报到达估计。这个删项减少不相关噪声，不是把历史奖励从任务定义里删掉，而是利用其梯度期望本来为零。

定义相对时间回报 $`G_t=\sum_{k=t}^{T-1}\gamma^{k-t}R_k`$，则针对起始折扣目标的精确形式为 $`\nabla J=E[\sum_t\gamma^t\nabla\log\pi_tG_t]`$。外面的 $`\gamma^t`$ 与里面的相对折扣不是同一项。若把未来奖励写成绝对折扣和，则无需再重复乘外层，两种记法应选一种并保持一致。

<a id="sec-2-1"></a>

<a id="policy-1-detail-8"></a>

### 2.4 一个容易混淆的实现约定

许多实践用均匀采集的时间步和相对回报，却不再显式乘外层折扣。这可能对应不同状态加权或一种常见近似，不能未经解释宣称它对任意起始折扣目标都是同一无偏梯度。也可以通过按折扣访问分布采样，将时间权重纳入采样器，此时公式外观不同但目标一致。关键是把分布和系数一起写清楚。

整体常数缩放在单一目标和简单梯度法中可以通过学习率部分吸收，但与时间相关的相对权重不是统一常数。若同时有熵项、价值损失、裁剪或自适应优化器，整体尺度也可能影响行为。不要用“学习率会补偿”掩盖目标分母与折扣定义不一致。

## 3. 策略梯度定理与折扣访问

<a id="policy-1-detail-10"></a>

### 3.1 从价值递推展开

固定策略的状态价值满足奖励加折扣后继价值的期望。对参数求导，既有当前策略概率的导数，也有后继价值的导数。不断展开后者，得到沿未来访问状态累积的当前动作价值梯度。这个过程把状态分布如何受策略影响的复杂项整理进访问权重，而不是证明状态分布不依赖策略。

记从初始分布出发的非归一化折扣访问为 $`d_\rho^\pi(s)=\sum_{t\ge0}\gamma^tP_\pi(S_t=s)`$，则在相应条件下

$$
\nabla J=\sum_s d_\rho^\pi(s)\sum_a\nabla\pi_\theta(a\mid s)Q^\pi(s,a).
$$

当状态包括吸收终点并按无限持续过程计时，总质量为 $`\frac{1}{(1-\gamma)}`$。归一化后用 $`D=(1-\gamma)d`$，公式变成 $`\frac{1}{(1-\gamma)}`$ 乘对 $`D`$ 和策略动作的期望。若只统计终止前活跃状态，其总质量一般依赖回合长度，不能随意当作同一个归一化常数。

<a id="policy-1-detail-11"></a>

### 3.2 有限时域的时间状态

有限时域中，价值和访问都可带时间索引，梯度为每个时刻的折扣访问乘该时刻动作价值。把时间并入状态也能得到统一表达，但策略输入必须实际获得所需时间。若只用物理位置共享同一动作分布，优化的是受限策略类，最优表现可能低于时间相关策略，这不是定理矛盾。

折扣访问不是训练批次中简单统计次数的同义词。不同回合长度、采样截断和重置会改变经验分布。要估计某个目标，应明确每条轨迹和每个时间步的权重。把所有收集样本平铺再平均，可能让长回合贡献更多，也可能改变原先按回合等权的目标。

<a id="policy-1-detail-12"></a>

### 3.3 定理消除了什么，没有消除什么

策略梯度定理让我们不必显式对环境转移或访问分布求导，但仍需要从策略访问的数据估计动作价值或回报。高方差、长时域和稀有事件仍存在。它也不保证参数目标凸、局部梯度一定指向全局最优，或有限更新必然改善。真正的算法还需要采样、估计、步长和评价。

如果环境模型已知，小任务可以用线性方程或动态规划得到精确价值，再核对解析梯度。未知环境则使用交互估计，样本误差成为核心。把这两个设置分开，能避免用精确模型参照的优势直接宣称某种无模型学习更高效。

## 4. 实验一：两步轨迹的三种梯度核对

<a id="policy-1-detail-14"></a>

### 4.1 已知目标与折扣索引

第一步动作决定第二步所处状态，两个状态各有独立二元策略参数；第一步奖励为动作乘零点一，第二步只有动作与第一步相同才得一。折扣零点八。枚举四条轨迹，直接对期望回报求导，再比较完整轨迹似然比与相对回报加外层折扣，最后故意漏掉外层折扣确认不等价。

```python
import itertools
import torch
torch.set_num_threads(1)
dtype = torch.float64
theta = torch.tensor([.2,-.4,.7],dtype=dtype,requires_grad=True)
gamma = .8
p = theta.sigmoid()
terms = []
for a0,a1 in itertools.product([0,1],repeat=2):
    probability = (p[0] if a0 else 1-p[0])*(p[1+a0] if a1 else 1-p[1+a0])
    r0,r1 = .1*a0,float(a1==a0)
    terms.append((a0,a1,probability,r0,r1))
J = sum(probability*(r0+gamma*r1) for _,_,probability,r0,r1 in terms)
exact, = torch.autograd.grad(J,theta)
full = torch.zeros(3,dtype=dtype)
causal = torch.zeros_like(full);wrong = torch.zeros_like(full)
for a0,a1,probability,r0,r1 in terms:
    score0 = torch.zeros(3,dtype=dtype);score0[0] = a0-p.detach()[0]
    score1 = torch.zeros(3,dtype=dtype);score1[1+a0] = a1-p.detach()[1+a0]
    w = probability.detach();total = r0+gamma*r1
    full += w*(score0+score1)*total
    causal += w*(score0*total+gamma*score1*r1)
    wrong += w*(score0*total+score1*r1)
assert torch.allclose(exact,full,atol=1e-12)
assert torch.allclose(exact,causal,atol=1e-12)
assert not torch.allclose(exact,wrong)
def objective(t):
    pp = t.sigmoid();value = 0.
    for a0,a1 in itertools.product([0,1],repeat=2):
        pr = (pp[0] if a0 else 1-pp[0])*(pp[1+a0] if a1 else 1-pp[1+a0])
        value = value+pr*(.1*a0+gamma*float(a1==a0))
    return value
v = torch.tensor([.3,-.2,.4],dtype=dtype);h = 1e-6
fd = (objective(theta.detach()+h*v)-objective(theta.detach()-h*v))/(2*h)
assert torch.allclose(fd,exact@v,atol=1e-9)
print('objective',J.item(),'exact',exact.tolist(),'wrong_outer_discount',wrong.tolist())
```

这个实验直接展示因果删项在期望上成立，并核验环境虽影响后续状态，仍不必对采样动作路径作普通导数。枚举用于已知小模型，不是要求实际交互能列出全部轨迹。完整训练时可以用同样的有限参照发现折扣、状态索引和 log 概率错误。

## 5. 动作无关基线为何无偏

<a id="policy-1-detail-16"></a>

### 5.1 条件得分恒等式

令 $`g_t=\nabla\log\pi(A_t\mid S_t)`$，基线在当前动作抽取前由状态或允许历史确定。条件于该信息，它不随当前动作变化，因此 $`E[g_tb_t\mid h_t]=b_tE[g_t\mid h_t]=0`$。将回报替换为回报减基线，保留相同目标梯度，同时可能减少随机波动。

基线可以依赖时间、状态和过去随机信息，也可以由另一个网络预测，但应注意估计时是否因使用同一动作和回报产生统计依赖。只看函数签名没有 action 字段，不保证训练出的基线与当前动作独立。若在同一小批上过度拟合回报，再用于该批 actor 更新，可能引入偏差，需要明确算法近似或采用隔离方法。

<a id="policy-1-detail-17"></a>

### 5.2 Actor 损失中的停止梯度

用负 log 概率乘估计优势形成最小化损失时，通常把回报、基线或优势视作当前 actor 更新的固定权重。即使基线共享参数，也不能让 actor 目标无意额外通过基线反向，否则得到的不是上述控制变量估计。Critic 可以通过自己的损失训练，共享表示时要分别理解两条梯度来源。

停止梯度只处理计算图，不能自动消除统计偏差。基线如果利用了当前动作信息，分离张量仍然可能有非零条件相关。正确性要同时检查随机变量关系与自动微分路径，这和前面部分可观测章节中区分信息路径与梯度路径的思想一致。

<a id="policy-1-detail-18"></a>

### 5.3 最小方差基线的条件

固定状态，考虑单项向量估计 $`g(G-b)`$，以协方差迹或平方欧氏范数的期望衡量波动，若二阶矩有限且 $`E\Vert g\Vert ^2>0`$，最优标量基线为

$$
b^*(s)=\frac{E[\Vert g\Vert ^2G\mid s]}{E[\Vert g\Vert ^2\mid s]}.
$$

它来自对 $`E[\Vert g\Vert ^2(G-b)^2\mid s]`$ 关于基线求导，均值项因基线无偏而不变。普通状态价值 $`E[G\mid s]`$ 只有在得分范数平方与回报具备相应关系时才等于这个最优解。不同参数坐标还可能有不同最佳标量，全向量迹标准只是一个明确选择。

<a id="policy-1-detail-19"></a>

### 5.4 局部最优不等于整轨迹最优

整条轨迹梯度是多个时间项之和，其方差包含跨时间协方差。逐项使用上述条件最优基线，不自动证明它最小化全部轨迹和的方差。若允许更复杂控制变量，还会改变可优化集合。应准确说清被最小化的对象，而不是把状态价值网络叫作无条件最优方差控制器。

基线不改变期望也不保证每个有限批次更新更好。估计误差、极端奖励与优化器都会影响实际路径。可以固定参数对多个独立批次测梯度均值和方差，再研究完整训练稳定性；两类实验回答不同问题，不能用一条更平滑曲线替代无偏性证明。

## 6. 实验二：状态价值不总是最佳基线

<a id="policy-1-detail-21"></a>

### 6.1 二元 bandit 的完整枚举

选一概率零点二，动作一奖励一、动作零奖励零。对 logit 的得分是动作减概率，真实梯度为零点一六。状态价值为零点二，按得分范数加权的最优基线却为零点八。这个特殊例子中后者让两个动作产生相同梯度，因此方差为零；这不是一般环境都能达到零方差的结论。

```python
import itertools
import numpy as np
p = .2
prob = np.array([1-p,p])
a = np.array([0.,1.]);score = a-p;reward = a
true = p*(1-p)
optimal = np.sum(prob*score**2*reward)/np.sum(prob*score**2)
assert np.isclose(optimal,.8)
for baseline in [0.,p,optimal]:
    estimate = score*(reward-baseline)
    mean = prob@estimate
    variance = prob@(estimate-mean)**2
    assert np.isclose(mean,true)
    if baseline==optimal:assert variance<1e-25
    print('baseline/mean/variance',baseline,mean,variance)
# 两个独立动作，用本批平均奖励作基线会包含自己的回报。
centered = 0.;leave_one_out = 0.
for pair in itertools.product([0,1],repeat=2):
    aa = np.array(pair,dtype=float)
    weight = np.prod(np.where(aa==1,p,1-p))
    centered += weight*np.mean((aa-p)*(aa-aa.mean()))
    leave_one_out += weight*np.mean((aa-p)*(aa-aa[::-1]))
assert np.isclose(centered,true/2)
assert np.isclose(leave_one_out,true)
print('same_batch_centered/leave_one_out/true',centered,leave_one_out,true)
```

本批平均含自身奖励，二样本例子使期望梯度缩为一半；留一法用另一个独立样本的奖励，恢复无偏。一般批量独立同分布 bandit 的缩放为一减批量倒数，但有序列相关或状态差异时需要重新推导，不能机械套用。优势标准化还包含随机标准差，通常更不是简单常数缩放。

<a id="policy-1-detail-22"></a>

### 6.2 实际价值网络为何仍有用

精确最优基线需要当前策略下得分范数和回报联合分布，获取成本可能很高。状态价值较容易估计，还能用于自举、优势和评价，因此仍是常用选择。它不是理论上在所有方差标准下最佳，实用价值却不因此消失。方法选择应比较误差、计算和最终任务，而不是只追求一个局部解析最优。

若价值网络拟合很差，减去它可能增加方差。可以报告回报与基线残差、按状态分组误差和固定参数梯度统计。解释训练时，不能只看 critic loss 下降，还要确认它对应正确目标和分布。下一章将讨论价值估计偏差如何进入 Actor–Critic。

<a id="policy-1-detail-23"></a>

## 7. 连续动作中的得分与路径导数

<a id="policy-1-detail-24"></a>

### 7.1 高斯策略的 log 密度

一维正态均值为 $`\mu`$、标准差为 $`\sigma>0`$ 时，对均值的得分为 $`\frac{(a-\mu)}{\sigma^2}`$；若参数是 log 标准差，对应得分为 $`\frac{(a-\mu)^2}{\sigma^2}-1`$。独立多维高斯的联合 log 密度按维度相加，得到动作向量的一份概率评分，不是对动作维度随意平均。

连续密度可以大于一，所以 log 密度可以为正，这不违反概率规律。数值计算应使用稳定分布接口，并明确实际动作是否经过变换。若用双曲正切压缩到有界区间，密度需要变换雅可比；若直接裁剪，边界出现质量聚集，不是同一个光滑双射。记录原动作和执行动作有助于核对定义。

<a id="policy-1-detail-25"></a>

### 7.2 似然比与重参数化的区别

对可微奖励，可以写动作等于均值加标准差乘标准噪声，沿动作路径反向；对黑箱环境通常不能这样穿过奖励。似然比只需奖励值和策略 log 概率，不需环境可微，但可能方差更大。两者在适当条件下可以估计同一目标导数，不能因为同一问题存在路径导数就否定得分估计。

如果混用重参数动作和 log 概率损失，应注意动作是否应视作固定样本。让 log 概率同时通过采样动作回传，可能改变原本似然比梯度。不同框架的 sample 与 rsample 语义不同，不能只替换一个函数名。应先用可解析小例子核对，再接入复杂环境。

<a id="policy-1-detail-26"></a>

### 7.3 实验三：解析高斯目标的两种估计

奖励为动作接近目标的负平方误差，固定标准差，目标期望与均值梯度可以精确计算。实验比较似然比、重参数化和理论梯度，同时检查一个解析最优基线能否降低该得分估计的样本波动。它只验证光滑已知奖励，真实环境通常没有可用路径导数。

```python
import numpy as np
rng = np.random.default_rng(97)
mu,sigma,target = .2,.7,1.5
noise = rng.normal(size=400000)
a = mu+sigma*noise
reward = -(a-target)**2
score = (a-mu)/sigma**2
analytic = -2*(mu-target)
lr = score*reward
path = -2*(a-target)
optimal = -((mu-target)**2+3*sigma**2)
controlled = score*(reward-optimal)
assert abs(lr.mean()-analytic)<.05
assert abs(path.mean()-analytic)<.015
assert abs(controlled.mean()-analytic)<.03
assert controlled.var()<lr.var()
assert abs(reward.mean()+((mu-target)**2+sigma**2))<.025
print('analytic/LR/path/control',analytic,lr.mean(),path.mean(),controlled.mean())
print('variance raw/controlled',lr.var(),controlled.var())
```

解析最优基线中的三倍方差来自高斯四阶矩，不能把它推广成任意奖励的公式。采样断言留出统计余量，不是严谨置信界；若要比较估计器稳定性，应固定参数重复独立批次，报告均值误差、协方差与计算成本。一次大样本接近解析值只是重要的实现证据。

## 8. 方差、探索与评价不能互相替代

<a id="policy-1-detail-28"></a>

### 8.1 长回报与稀有成功

回报到达估计包含未来许多随机事件，时域长和稀有高奖励会放大方差。基线可以去掉某些无关变化，却无法凭空增加未探索动作的证据。若策略过早把有用动作概率压得很低，后续采样可能难以发现它。熵奖励和探索策略会改变学习过程，有时也改变目标，需明确区分。

增大批量降低某些采样误差，但数据若来自同一相关轨迹，独立样本数不等于时间步数。更多并行回合、较好基线和自举估计各有作用。应先识别噪声来自环境、策略、长程信用还是模型估计，再选择工具，不能把所有波动都归为学习率太大。

<a id="policy-1-detail-29"></a>

### 8.2 更新尺度与策略变化

正确无偏梯度只描述局部期望方向，有限步长可能让策略大幅变化，旧数据不再代表新策略。KL、概率比和熵可以诊断变化，但它们不是同一指标。梯度范数小也不保证策略变化小，因为参数化和尺度不同。后续 PPO 与信赖域方法将围绕这些问题建立近似控制，不能在本章先假设它们已被解决。

训练回报、开发选择和最终独立评价应分开。若按训练中最好回报挑种子，再只报告该种子，稳定性会被高估。小任务可以精确算期望作为参照；未知环境需要足够独立回合和不确定性说明。任何方法比较都应记录交互预算、更新次数和选择机会。

<a id="sec-6-1"></a>

<a id="policy-1-detail-30"></a>

### 8.3 负 log 概率损失为何不是任务损失

在固定采样数据上，负 log 概率乘优势是一个用于产生目标梯度的替代损失，数值本身不等于负期望回报。策略更新后该数值下降，也不自动证明真实环境回报提高。权重、基线和数据分布一变，其绝对数值更不能直接横向比较。评价应回到原任务与冻结协议。

如果优势全为零，替代 actor 梯度为零，可能是任务无差异、基线错误或数据过少；不是所有情况都表示已经最优。可以在解析环境核对真实优势，再检查采样与归约。把损失当作实现工具、把回报当作任务结果，有助于避免对一条训练曲线过度解释。

## 9. 进阶练习与详细解答

<a id="policy-1-detail-32"></a>

### 9.1 题一：环境不可微能否求策略梯度

题目：离散动作导致黑箱环境跳转，无法对状态转移反向，似然比是否仍可用？

解答：在环境与初始分布不依赖参数、支持与期望条件满足时可以。导数作用于轨迹出现概率，环境只提供奖励样本。它不要求对离散动作路径求普通导数，但估计可能高方差。若环境本身含同一待优化参数，需加入相应导数，不能继续只保留策略项。

<a id="policy-1-detail-33"></a>

### 9.2 题二：过去奖励为何可删

题目：时刻二动作得分乘时刻零奖励，为什么期望为零？

解答：条件于动作二之前的历史，过去奖励固定，当前动作得分在当前策略下均值零。先取条件期望再总体平均得到零。删掉它不改变任务回报定义，而是减少与当前动作无因果关系的估计噪声。离策略数据或信息条件改变时，要重新核对该恒等式。

<a id="policy-1-detail-34"></a>

### 9.3 题三：两层折扣

题目：相对回报已含未来折扣，为何起始折扣目标还可能需要外层时间权重？

解答：相对回报把当前时刻当零点，原目标却从回合起点折扣。两者相差当前时间的折扣因子。也可直接用绝对折扣未来和，或把权重纳入采样分布，但不能重复或遗漏。实验一显示漏项会改变不同时间参数的梯度。

<a id="policy-1-detail-35"></a>

### 9.4 题四：访问分布是否不依赖策略

题目：定理没有显式对访问分布求导，是否说明访问与策略无关？

解答：不是，依赖通过价值递推展开被整理进折扣访问权重。策略改变会改变未来状态分布。定理提供方便的梯度表达，不取消这一事实。旧轨迹更新多轮时仍面临分布变化，不能据此无限复用而不作分析。

<a id="policy-1-detail-36"></a>

### 9.5 题五：基线可依赖历史吗

题目：基线依赖当前动作前的完整允许历史，会破坏无偏吗？

解答：若条件于该历史不再随当前动作变化且相关期望有限，不破坏。它可利用时间、状态与过去信息。但若基线训练使用当前动作回报造成统计依赖，需另外检查。函数输入没有动作字段并非完整证明，随机变量关系才是关键。

<a id="policy-1-detail-37"></a>

### 9.6 题六：分离张量能消除统计偏差吗

题目：把一个依赖当前动作的基线 detach 后，是否就无偏？

解答：不能，detach 只删除自动微分路径，不改变其数值与动作的相关。基线项期望仍可能非零。计算图正确性与统计控制变量条件要分别验证。可以用有限枚举构造反例，比只看梯度能计算更有说服力。

<a id="policy-1-detail-38"></a>

### 9.7 题七：状态价值为何非必然最优

题目：最佳标量基线为什么含得分范数平方？

解答：目标是最小化梯度向量波动，动作对梯度的影响大小不同。展开平方范数并对基线求导，就得到加权回报均值。普通价值只按动作概率平均，忽略得分大小。本章 bandit 最优基线零点八而价值零点二，二者期望梯度都正确但方差不同。

<a id="policy-1-detail-39"></a>

### 9.8 题八：整轨迹方差

题目：每个时间项方差都最小，是否必然让它们和的方差最小？

解答：不必然，和的方差还含跨时间协方差。逐项最优公式有明确条件和目标，不能直接称为全部轨迹最优。更复杂控制变量可有不同选择。研究应先定义最小化的是单项、某坐标还是全向量总方差。

<a id="policy-1-detail-40"></a>

### 9.9 题九：同批均值的自依赖

题目：两个独立 bandit 样本都减本批平均奖励，为何期望梯度减半？

解答：平均包含自身回报，基线与当前动作相关。展开后自身项抵消一部分目标，交叉独立项期望为零，得到一半。留一法在该例中只用另一个独立样本，恢复无偏。一般序列与状态差异需重新分析，不能机械套同一缩放。

<a id="policy-1-detail-41"></a>

### 9.10 题十：连续 log 密度为正

题目：高斯策略某动作 log 概率为正，是否程序一定错误？

解答：连续对象是密度，密度可以大于一，因此 log 密度可以为正。应检查标准差、单位和联合维度，而不是强行要求非正。离散概率质量不超过一，两种对象不同。变换与裁剪也会改变实际执行分布，需要对应处理。

<a id="policy-1-detail-42"></a>

### 9.11 题十一：sample 与 rsample

题目：用可重参数样本直接放入似然比 log 概率损失，是否总是同一梯度？

解答：不总是，动作若带梯度，log 密度还会沿动作路径反传，改变原来视动作实现值固定的得分估计。应根据目标明确停止哪些路径。路径导数可以正确估计另一种表达，但不能无分析混用。用解析高斯例子核对最可靠。

<a id="policy-1-detail-43"></a>

### 9.12 题十二：梯度正确是否回报单调

题目：无偏梯度加一次较大步长，是否保证实际回报提高？

解答：没有，局部梯度、采样噪声、目标曲率和分布变化都会影响有限更新。需要步长、策略变化与独立评价，后续信赖域和 PPO 也只在特定条件或近似下提供控制。不能把一阶方向的正确性扩大成整个训练单调保证。

<a id="policy-1-detail-44"></a>

### 9.13 题十三：终止前访问的总质量

题目：只统计活跃时间步，折扣访问总质量是否总等于折扣几何级数？

解答：不一定，可变终止长度使其等于期望的终止前折扣次数。若显式加入无限吸收终点，总访问质量可恢复几何级数，但终点未来奖励与得分贡献为零。归一化约定应与状态空间一致，不能混用两个对象。

<a id="policy-1-detail-45"></a>

### 9.14 题十四：基线总能降方差吗

题目：随便减一个很大的常数，是否仍无偏且方差更小？

解答：动作无关时无偏可以成立，但方差可能更大。最优基线来自二次目标的特定解，偏离它过多会增加波动。价值预测误差也会影响效果。应比较固定参数下的梯度统计，而不只凭基线存在就宣称稳定。

<a id="policy-1-detail-46"></a>

### 9.15 题十五：替代损失的比较

题目：两个算法 actor loss 数值一小一大，能否据此排名任务质量？

解答：不能，基线、优势尺度、采样分布和归约都影响数值。它主要服务梯度构造，不等于真实负回报。应在同一环境和冻结评价下比较原任务结果、成本与不确定性，避免被内部优化量误导。

<a id="sec-7-1"></a>

<a id="policy-1-detail-47"></a>

### 9.16 题十六：设计方差实验

题目：怎样比较无基线、价值基线和加权最优基线？

解答：固定策略参数、环境和样本预算，重复独立轨迹批次，比较估计均值与已知梯度、协方差迹与成本。再另做完整训练评价，避免把参数变化混进估计器方差。小模型可精确枚举，复杂环境需要可靠参照和充分重复。无偏性、低方差和最终回报是相关但不同证据。

<a id="policy-1-detail-48"></a>

### 9.17 题十七：动作相关基线的反例与校正

题目：在选一概率零点二、奖励等于动作的 bandit 中，基线直接设为当前动作奖励，会发生什么？

解答：回报减基线恒为零，actor 梯度也为零，但真实目标对 logit 导数为零点一六，显然有偏。把基线张量分离计算图也不会修复，因为统计相关仍在。若确实想使用动作相关控制变量，可以额外补回其在当前策略下的得分加权期望；对有限动作可显式求和。这样是带校正的新估计器，不能把未经校正的动作相关项叫作普通无偏基线。

校正本身需要可计算期望或另一个估计器，并可能有额外方差和成本。若基线还依赖参数，要明确当前更新中哪些部分固定、哪些导数属于目标。这个例子体现一个通用原则：降低样本残差并不自动保持目标梯度，控制变量必须同时满足代数和信息条件。

<a id="policy-1-detail-49"></a>

### 9.18 题十八：稀有动作与没有证据

题目：一个有奖励动作概率只有千分之一，独立采样一百次都没选到的概率约为多少？能否把这批零回报理解成策略已最优？

解答：概率为 $`(1-0.001)^{100}`$，约零点九零五，十分常见。该批可能没有任何成功证据，估计梯度接近零不表示真实导数为零。基线可以控制部分噪声，却不能提供未访问动作的真实回报。需要探索、先验或其他合法信息，并记录完整采样成本。若只报告成功后那一批，会夸大学习可靠性。

<a id="policy-1-detail-50"></a>

### 9.19 题十九：漏折扣能否统一调学习率修复

题目：实验一漏外层折扣后，第一个参数梯度相同，后两个扩大四分之一。是否存在一个学习率系数同时恢复所有分量？

解答：不存在一般统一系数，因为第一分量要求系数为一，后两个要求系数为零点八。时间权重改变了相对方向，不只是整体长度。某些特殊参数共享或零梯度情况下可能碰巧一致，但不能作为一般等价。对复杂代码先做这种分量级小模型核验，比观察最终回报是否似乎能学到更清楚。

<a id="policy-1-detail-51"></a>

### 9.20 题二十：多维动作的联合 log 概率

题目：两维独立动作，分别记录 log 概率后取平均而非求和，再用指数差算新旧比率，会得到什么？

解答：联合密度需要乘两维概率，log 密度应相加。取平均后指数得到联合比率的平方根，不再是原动作向量的概率比。对单一似然比梯度，统一缩放有时能部分由步长补偿，但重要性权重和后续剪裁是非线性的，不能这样替换。应明确每个 batch 元素是一整个动作，动作维度在形成联合评分时先求和。

<a id="policy-1-detail-52"></a>

## 10. 综合研究任务

从实验一的有限两步环境出发，比较全轨迹回报、回报到达与不同基线，先枚举真实梯度，再用独立采样估计。改变折扣、第二步状态访问和奖励噪声，观察各参数方差。将有限时域与外部截断分开记录，检查策略输入是否含时间。所有结论都应回到同一明确目标。

随后在不改变评价角色的前提下建立简单实际训练，记录每轮交互、更新、策略概率与独立回报。完整循环将在后续章节实现，本章三段机制实验先固定数学参照。运行只使用内存和 CPU，不下载环境或模型，也不留下脚本与权重文件。

## 11. 策略梯度定理的矩阵证明

<a id="policy-1-detail-54"></a>

### 11.1 先写固定策略的线性方程

在有限状态、折扣严格小于一的模型中，令 $`P_\pi`$ 是策略平均转移矩阵，$`r_\pi`$ 是策略平均即时奖励列向量，初始分布为 $`\rho`$。固定策略价值满足 $`V=(I-\gamma P_\pi)^{-1}r_\pi`$，目标为 $`J=\rho^TV`$。若加入吸收终点，其价值和奖励为零，矩阵仍可统一处理。奖励和转移的策略平均依赖参数，但环境每个动作对应的模型保持固定。

对价值方程微分，得到

$$
(I-\gamma P_\pi)dV=dr_\pi+\gamma(dP_\pi)V.
$$

因此 $`dJ=\rho^T(I-\gamma P_\pi)^{-1}[dr_\pi+\gamma(dP_\pi)V]`$。这一步明确保留了策略改变未来转移的影响，没有把状态分布当常数。直接对逆矩阵求导也能得到同样结果，但从方程微分更容易检查符号与维度。

<a id="policy-1-detail-55"></a>

### 11.2 将逆矩阵识别为访问权重

因为折扣小于一且转移为随机矩阵，可展开逆矩阵为几何级数。行向量 $`\rho^T\sum_{t\ge0}\gamma^tP_\pi^t`$ 正是折扣访问质量。另一方面，对某个状态，括号中的当前微分项等于对动作概率微分乘 $`r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')`$，后者就是动作价值。因此重新得到访问加权策略梯度。

这个推导说明为何定理不需要显式写 $`\nabla d`$：访问变化已经通过后继价值微分递归展开。若只对 $`r_\pi`$ 求导而忘记 $`P_\pi`$ 项，就会漏掉长期影响；若把定理中的访问权重也再次作为普通乘积求导，又可能重复计算不属于该表达的项。使用定理作为梯度公式时，应区分它与一个待再次求导的替代标量目标。

<a id="policy-1-detail-56"></a>

### 11.3 有限时域的块结构

固定期限可以把状态扩展为时间与物理状态，转移只从当前时间进入下一时间，因此对应结构在时间方向是块上三角。价值递推和访问展开都在有限步结束，不需要无限级数。最后时间的奖励、合法动作和终端价值必须明确，不能只把无限公式截断后忘记边界。

这种扩展还解释了共享时间无关策略的限制：即使环境状态相同，早期可以探索，最后一步更可能直接利用；若模型不读取时间，它只能在这些需求间折中。策略梯度仍可优化该受限类，但其最优不等于全部时间相关策略最优。算法正确与策略类充分是两种验收。

<a id="policy-1-detail-57"></a>

### 11.4 平均奖励目标需要另一个对象

长期平均奖励通常使用平稳分布、平均回报和差分价值，要求相应遍历或稳定条件。它不是简单令折扣等于一就能从所有折扣公式中直接获得。访问总质量发散、价值基准改变和极限交换都需处理。教材把折扣目标作为主线，是为了完整核验一个明确对象，而不是暗示其他目标无价值。

阅读论文时应先找目标定义和状态分布记号。某式省略常数可能只是采用非归一化访问，某式不含外层时间折扣可能采用不同采样或目标。应根据定义判断，不要仅凭表面符号相似宣布等价或错误。清楚对齐约定，是比较实现前最重要的工作。

<a id="policy-1-detail-58"></a>

## 12. 基线、优势与价值近似的深入联系

<a id="policy-1-detail-59"></a>

### 12.1 优势形式的精确含义

减去真实状态价值得到优势 $`A^\pi=Q^\pi-V^\pi`$，在同一状态对策略动作平均为零。策略梯度可以用优势替代动作价值，因为状态价值是动作无关基线。优势的正负表示相对当前策略平均表现，而不是绝对好坏；一个所有动作都获得负回报的状态，也可以有正优势动作。

真实优势便于解释选择方向，但实际算法常使用近似值、有限轨迹和自举。其误差可能影响 actor 梯度，尤其当误差与得分相关。不能只因为某个张量叫 advantage，就认为它无偏估计真实优势。下一章会展开具体估计器，本章先给出误差怎样进入目标的通用关系。

<a id="policy-1-detail-60"></a>

### 12.2 价值误差进入梯度的方式

若动作价值估计为真实值加误差，替代梯度偏差是访问分布下动作得分乘误差的期望。用 Cauchy–Schwarz 可以把其范数上界为得分平方范数期望的平方根与误差平方期望的平方根之积，再按访问归一化约定补相应系数。这个界需要同一相关分布下的矩，不能用任意离线数据上的平均误差代替。

如果误差只依赖状态，基线恒等式使它不影响期望梯度；如果误差随动作变化，就可能改变方向。总均方误差低不一定意味着策略更新最好，因为某些误差恰好与得分高度相关。反过来，有些价值近似看似不精确，却在梯度相关方向足够准确。评价 critic 应同时考虑目标、分布与 actor 需要的投影。

<a id="policy-1-detail-61"></a>

### 12.3 兼容特征的一条条件性推导

固定策略参数，用得分向量作动作价值近似的特征，令估计为 $`g(s,a)^Tw`$。若在与策略梯度一致的状态动作权重下最小化真实动作价值的平方误差，并达到关于系数的驻点，则正规方程给出 $`E[g(Q-g^Tw)]=0`$。因此真实梯度与该近似产生的梯度在这个条件下相同。

这里包含很强的前提：特征形式兼容、训练分布匹配、目标确实是真实价值并且拟合达到相应条件。任意神经 critic 并不自动满足，有限样本自举目标也引入额外误差。这个结果解释一种理论可能性，不是为所有 Actor–Critic 提供无条件无偏证明。阅读相关定理应逐项核对假设，而不是只记住兼容这个名称。

<a id="policy-1-detail-62"></a>

### 12.4 基线参数依赖与停止梯度

一个随策略参数变化但对当前动作无关的基线，在每个固定参数点仍可满足控制变量均值零；然而实际构造替代 actor loss 时，若直接沿基线网络反向，会加入额外项。应把用于当前 actor 更新的数值当作固定权重，再通过独立 critic 目标学习它。共享主干并不取消这种区分，只是两条损失都可能作用于共同参数。

即使正确停止梯度，同批拟合的基线仍可能因统计自依赖产生偏差。可以用先前数据训练、交叉拟合、留一或明确接受近似，但应说明。算法的统计关系和计算图分别核验，能够避免用 detach 一词替代完整证明。第二个实验的同批均值反例正展示这种区别。

<a id="policy-1-detail-63"></a>

## 13. 方差控制的条件与局限

<a id="policy-1-detail-64"></a>

### 13.1 最优标量基线的二次目标

固定条件信息，展开单项二阶矩为 $`E[\Vert g\Vert ^2G^2]-2bE[\Vert g\Vert ^2G]+b^2E\Vert g\Vert ^2`$。若二次系数正，配方即可得到唯一最优基线；与最优值的差是得分二阶矩乘基线偏差平方。这清楚说明随便减常数可能增加波动，也说明在得分几乎为零时基线数值可能难估。

如果得分恒零，该项根本不提供参数更新，任何基线都不改变它。出现极大最佳基线估计时应检查分母和样本覆盖，而不是把一个不稳定比值直接送入训练。局部解析最优是已知分布的结果，有限数据估计它还要考虑方差与正则。实践可能选择略偏离解析最优但更稳定的估计器。

<a id="policy-1-detail-65"></a>

### 13.2 不同参数坐标的标准

若只关心某一参数坐标，最佳基线按该坐标得分平方加权；若关心整个梯度欧氏误差，则使用全得分范数平方。对参数做重缩放会改变欧氏范数与相应最优选择，因此所谓最小方差不是脱离参数化的绝对属性。自然梯度或其他度量下的目标可能不同，需要重新推导权重。

整轨迹和的方差还含多个时间项协方差，允许基线共同优化时最优条件可以相互耦合。逐步状态价值是有用近似，但不应称作所有意义下最优。研究报告最好写清单项、总和、坐标或范数标准，让别人能够复算。没有明确定义的方差改善，很容易只是一种图像上更平滑的印象。

<a id="policy-1-detail-66"></a>

### 13.3 回报到达也不是普遍最小方差保证

删除过去奖励利用了零期望项，但随机变量之间存在相关时，去掉一个零均值控制变量并不自动在每个问题中严格降低方差。它通常减少明显不相关噪声，实际效果仍可测量。更强的条件期望化方法需要明确条件集与可计算性。不要把常用低方差技巧升级成未经证明的所有环境定理。

可以在已知小模型枚举全轨迹估计器和因果估计器的协方差，再变化奖励相关结构。这样即使观察到反常结果，也能通过公式解释，而不是先假定结果必须更好再调整样本。机制实验的价值在于允许结论被检验，包括检验我们熟悉的经验规则。

<a id="policy-1-detail-67"></a>

### 13.4 优势中心化与标准化

把一批优势减均值、除标准差，可以改善某些优化尺度，但均值和标准差来自同批随机数据，一般不等同于固定动作无关基线或统一确定常数。小批情况下尤其可能改变期望方向；序列相关、不同状态和剪裁进一步增加差异。应准确称为优化启发式，并通过原任务评价其影响。

如果优势标准差为零，除法需要明确策略，不能用任意微小常数制造巨大更新。全零优势可能表示任务无区分，也可能是回报计算或掩码错误。应先核对原回报与价值，再决定跳过或采取其他处理。数值稳定措施不是目标正确性的替代，触发情况也值得记录。

**不仅是改变一个统一尺度：三动作反例。** 取一步 bandit，三动作的概率为 $`p=(0.6,0.3,0.1)`$、确定奖励为 $`r=(0,1,10)`$，参数是三个 softmax logits。真实目标 $`J=\sum_i p_ir_i=1.3`$，所以梯度第 $`i`$ 维为 $`p_i(r_i-J)`$，完整向量是

$$
\nabla J=(-0.78,-0.09,0.87).
$$

现在每批独立抽两个动作，奖励先减批均值，再除以使用分母二的批标准差；两奖励相等时定义归一化优势都为零，避免除零。两奖励不等时，归一化优势恰为 $`\operatorname{sign}(r_i-r_j)`$ 与其相反数。基线和标准差在 actor 求导时都停止梯度，单批的梯度估计因此为

$$
\widehat g=\tfrac12\operatorname{sign}(r_i-r_j)
\bigl[(e_i-p)-(e_j-p)\bigr]
=\tfrac12\operatorname{sign}(r_i-r_j)(e_i-e_j).
$$

对全部九个有序动作对按 $`p_ip_j`$ 求和，得到第 $`i`$ 个坐标的期望为

$$
\begin{aligned}
E\widehat g_i &=p_i\left(\sum_{j:r_j<r_i}p_j-
\sum_{j:r_j>r_i}p_j\right),\\[6pt]
E\widehat g &=(-0.24,0.15,0.09).
\end{aligned}
$$

中间动作的 logit 期望更新从负变正，整个向量也不是原梯度乘一个共同常数。标准化把两样本的奖励幅度差压成了大小关系：十相对一的巨大收益，在该批的归一化权重中不再比一相对零更强。这解释了偏差来自哪里，而非只说随机分母可能有影响。坐标更新符号也不等于该动作概率变化的符号，因为 softmax 仍耦合全部 logits。

此例针对特定二样本、总体式标准差和零方差约定；加入数值常数、使用无偏标准差或增加批量都会改变具体数字，不能据此给所有实现套同一个修正系数。它足以否定“标准化总是保持原期望梯度方向”，却不意味着标准化在实际优化中必然有害。是否改善原始任务，仍需固定预算后的独立回报评价。

<a id="policy-1-detail-68"></a>

## 14. 连续策略与变换的细节

<a id="policy-1-detail-69"></a>

### 14.1 高斯的解析最优基线

令动作等于均值加标准差乘标准正态，奖励为距离目标的负平方。对均值的得分平方与噪声平方成比例，最优基线涉及噪声四阶矩。利用标准正态二阶矩为一、四阶矩为三，可得本章公式中的均值误差平方加三倍方差，再取负号。普通状态价值只含一倍方差，因此两者不同。

这个解析推导假设只有均值参数且标准差固定。若同时优化 log 标准差，整个得分向量改变，按全梯度范数最优的基线也会改变。不能把一维均值结论复制到多参数神经策略。应先固定要研究的参数集合和度量，再谈方差最优。

<a id="policy-1-detail-70"></a>

### 14.2 双曲正切压缩与雅可比

若实际动作 $`u=\tanh a`$，在内部高斯变量上采样后，执行密度需要减去变换导数绝对值的 log，逐维为 $`\log(1-\tanh^2a)`$。接近边界时该项数值敏感，实际实现需要稳定表达。评分原始变量密度与评分执行动作不是同一对象，尤其当后续用概率比比较新旧策略时，必须保持同一动作表示与变换。

若相同固定双射用于新旧策略，某些概率比中的雅可比可以相消，但熵、绝对 log 密度和参数相关变换未必如此。不能因一个比值碰巧消去就从所有损失中删掉。裁剪又不是双射，边界质量需要不同解释。动作管道应从采样到执行逐步记录，避免隐藏改变。

<a id="policy-1-detail-71"></a>

### 14.3 重参数化与黑箱奖励

对可微模型，路径导数利用奖励随动作变化的局部斜率，往往具有不同方差；对真实黑箱，无法直接获取该斜率。学习一个可微世界模型可以提供近似梯度，但引入模型误差与分布外外推。不能把模型内部反向得到的平滑数值当作真实环境精确导数，需要独立验证与约束。

似然比不要求环境可微，却依赖覆盖和奖励样本。两种方法有不同信息资源，比较应说明是否使用了模型、真实导数或额外训练数据。一个知道解析奖励的路径估计器更稳定，不代表在未知环境中可以免费获得相同优势。理论参照与部署算法的角色要分清。

<a id="policy-1-detail-72"></a>

### 14.4 参数相关支持的反例意识

如果策略均匀分布在随参数移动的区间，密度内部导数和边界贡献都可能重要，直接套得分均值零公式会出错。普通固定支持高斯和有限 softmax 避开了一些这类问题，但硬阈值、截断和参数相关合法集会重新引入。不是所有名为概率分布的接口都满足同一正则条件。

取 $`A\sim\operatorname{Uniform}(0,\theta)`$、$`\theta>0`$，奖励为动作本身，则 $`J(\theta)=E[A]=\frac{\theta}{2}`$，真导数为二分之一。只在区间内部求密度对数导数得到 $`-\frac{1}{\theta}`$，其均值并非零；若机械使用得分乘奖励，结果是负二分之一。直接对积分 $`\int_0^\theta\frac{a}{\theta}\,da`$ 求导，内部导数项为负二分之一，上限移动的边界项为一，两者相加才正确。若改用重参数化 $`A=\theta U`$、$`U\sim\operatorname{Uniform}(0,1)`$，路径导数为 $`U`$，期望同样是二分之一。这个完整手算说明失效的是忽略边界的似然比步骤，而不是目标不可微或所有梯度方法都无效。

对于带约束动作，应明确是先定义合法分布再采样，还是采出后由执行器修正。后者的实际行为分布可能与记录的 log 概率不一致，导致梯度目标偏离执行系统。最好构造边界小例子核对概率质量与动作身份，再扩展到复杂控制。

<a id="policy-1-detail-73"></a>

## 15. 从机制实验到可靠训练研究

<a id="policy-1-detail-74"></a>

### 15.1 固定参数方差和训练稳定性

固定参数重复采样，测到的是某个估计器在该点的随机波动；重复完整训练，测到的是初始化、数据顺序、策略访问和优化共同作用。两者不能用同一个误差条替代。前者可以解释局部机制，后者回答方法实际稳定性。清楚区分，有助于避免一次巨大样本梯度实验被夸大成算法普遍可靠。

训练曲线平滑也可能只是更强的滑动平均、较小步长或较大批量。比较时应保持显示规则和预算一致，并报告真实独立评价。熵和基线可以改变探索与波动，但最终需要原任务结果确认。不能只用内部替代损失或 critic 拟合来证明策略更好。

<a id="policy-1-detail-75"></a>

### 15.2 轨迹单位与重置规则

独立回合需要独立初始化环境和策略记忆，若隐藏记忆跨回合保留，任务可能变成持续过程。状态来源分组、时间变化和环境随机流也会影响独立性。把同一长轨迹切成许多片段不会自动获得同样多独立证据。交互预算应同时报告回合、时间步与更新次数。

开发集可以选择学习率、批量、基线和训练步数，最终测试用于冻结后的确认。若测试失败后继续调参，该集合转为开发或回归，需另设确认。小玩具任务通常作者知道结构，因此更适合机制演示，不应称作对未知任务的严格盲测。完整代码可以可复算，结论范围仍要准确。

<a id="policy-1-detail-76"></a>

### 15.3 当前三段实验的实际观察

两步枚举目标约为零点五六四五零四，精确梯度三个分量约为零点零三八五一四、负零点零八六五二六和零点零九七五二四。完整轨迹、因果折扣形式与方向差分一致；漏外层折扣后后两个分量变化。这个对照直接定位目标权重差异，而非优化器随机性。

二元基线例子中，无基线方差约零点一零二四，价值基线约零点零五七六，加权最优基线在浮点误差内为零。二样本同批中心化的期望为零点零八，留一法为零点一六。高斯例子的理论梯度为二点六，似然比约二点五九零九，路径导数约二点五九七零，带基线约二点六零零七；控制后样本方差由约三十六点五九降到十六点三一。

<a id="policy-1-detail-77"></a>

### 15.4 将一个失败转成可证伪问题

如果梯度方向不符，先检查目标、折扣、log 概率和停止梯度；如果均值正确却噪声大，研究基线、采样和信用分配；如果训练回报好而独立回报差，研究选择、探索与环境分布。每种现象对应不同干预，不应一概加大网络或延长训练。

可以把当前有限模型作为长期回归参照，后续实现 REINFORCE、GAE 和 PPO 时先在这些对象上检验，再接入更复杂环境。新增组件意味着新增假设与近似，应该明确它改变的是估计偏差、方差、更新约束还是任务本身。这样的学习路线能够持续深化，而不只是在多个算法缩写之间切换。

<a id="policy-1-detail-78"></a>

### 15.5 熵奖励也是目标选择

若在每个访问状态加入策略熵作为训练奖励，应明确它怎样随时间折扣、是否属于部署目标，以及是否对访问分布变化完整处理。只在固定采样状态上增加一个熵梯度，是常用局部正则形式，但与任意完整熵回报目标的所有导数并非无需条件地相同。阅读实现时应写出实际 actor loss，而不只记录一个熵系数。

熵可以鼓励保持多种动作概率，却不保证探索到任务关键状态。一个策略在无用状态保持高熵，仍可能永远不到达稀有成功区域。反过来，已充分学习的明确任务可能需要较确定动作，持续较强熵奖励会保留次优随机性。应按原任务回报、覆盖和策略变化评价取舍，不能把熵越高直接当学习越好。

这些区别将影响下一章的 Actor–Critic 和 PPO：actor、critic、熵正则与概率比各有自己的统计对象和归约，名字相同的平均也可能位于不同轴。先写清楚公式，再看小算例与实际训练，能够让后续更多技术建立在同一条可检查的逻辑链上。

<a id="policy-1-detail-79"></a>

### 15.6 固定数据上的局部替代目标

在旧策略采集的状态动作上，把优势固定后，可以用新旧动作概率比乘优势构造一个替代目标。在新旧参数相同时，其一阶动作变化能够匹配相应访问加权策略梯度；离开该点之后，状态访问分布变化和优势估计误差仍然存在。一次正确梯度并不意味着固定数据替代目标在任意远处都等于真实回报。

若反复在同一批数据上更新，采样器没有自动跟着策略改变，动作比率也不必然校正全部状态分布。完整轨迹重要性比在适当支持条件下可以用于某些期望，但长轨迹的乘积比率可能方差很高。实用方法会引入截断、信赖域或重新采样，它们带来自己的偏差与约束。下一章讨论这些方法时，应继续保持局部一致与全局保证的区别。

可以用本章两步模型作一个后续研究：固定旧策略枚举轨迹，比较真实新策略回报、完整重要性加权值和仅动作局部替代值，逐渐增大参数改变量。所有对象都可精确计算，因此能看到误差从哪里产生。这个建议不是已运行实验结果，而是一条明确可证伪的扩展路线，读者无需引入大型环境即可继续深入。

最终验收仍回到原目标、可见信息、采样分布和更新公式四项是否一致。三段已运行实验提供这四项之间的基础参照，更多算法只有在明确改变哪一项后，才容易被可靠理解和比较。
