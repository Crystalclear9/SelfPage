## 1. 先用三状态导航建立可信参照

<a id="mdp-3-detail-2"></a>

### 1.1 写出全部转移而不只画路径

状态零为起点，一为中间位置，二为终点。非终止状态可左移或右移，左边界不能越界，终点不再执行任务动作。进入终点奖励一，其他转移奖励负零点一，折扣零点九。因此零左移仍到零并付代价，零右移到一付代价，一左移回零付代价，一右移进入终点获得一。奖励属于转移，不附带下一次停留奖励。

最优价值手算为 $`v_1=1`$、$`v_0=-0.1+0.9=0.8`$，终点价值零。零左移一步再执行最优策略的动作值为 $`-0.1+0.9\times0.8=0.62`$，低于直接右移。一左移的动作值同为零点六二，右移为一，所以两处都选右。这个例子足够简单，可以在不依赖求解器的情况下确认全部索引和终止约定。

不要只给出“向右显然最好”的直觉。真正有用的是四条转移、奖励归属、终点价值和动作比较均可独立重建。以后扩展随机性、改变步耗或加入等待时，都先重新核对这些对象，再运行规划。算法对错误模型的精确解，不会因为最终路径看起来合理就变成正确答案。

<a id="sec-2"></a>

<a id="mdp-3-detail-3"></a>

### 1.2 同步两轮的逐项数值

从零向量开始，第一轮零的两个动作即时奖励都为负零点一，因此新值负零点一；一可以直接终止得一，因此新值一。第二轮零向左的值为 $`-0.1+0.9\times(-0.1)=-0.19`$；向右为零点八，所以更新为零点八。一仍选择右得一。第三轮值不再改变，完整 Bellman 残差为零。

第一轮零的值不是零，因为它确实付出了本步代价。若某些讲解用零代价链，第一轮起点仍零，那是另一个模型。学习时最常见的混淆之一，是把一个例子的奖励传播直觉直接搬到另一个步耗不同的例子里。每个数都应从当前表重算，不能只记“第二轮会变成某个值”。

<a id="sec-1-1"></a>

<a id="mdp-3-detail-4"></a>

### 1.3 一轮传播几步取决于更新语义

同步更新在每个状态都读取同一旧表，一轮只增加一步前瞻。若原地按靠近终点到远离终点的顺序更新，新的一状态值可立即用于零，同一轮就得到零点八。反向遍历则可能仍需更多轮。两方法中间轨迹不同并非错误，验收应看各自规则、最终残差、策略和实际备份次数。

<a id="visual-mdp-03"></a>
### 图解：有限规划的同一算例：折扣偏好与更新次序

![有限规划的同一算例：折扣偏好与更新次序](images/03-concept.svg)

上排时间线只记录奖励到账：从起点 s 直接结束，第一步得到三；选择绕行则第一步得到零并到达 u，第二步再得到四并终止。两个方案的第一个奖励都不折扣，第二个奖励才乘一次 $`\gamma`$，所以起点动作值分别为三和 $`4\gamma`$。这与“经过两次转移就乘两次折扣”不同，必须从回报定义的奖励下标出发。

下方曲线沿用同一个任务。$`\gamma=\frac34`$ 时两动作相等；折扣更小时直接更优，更大时绕行更优。图包含 $`\gamma=1`$ 作为有限回合的端点，这个任务最多两步终止，回报仍然有限，不是在声称一般无限时域无折扣问题都有有限值。$`\gamma=0.9`$ 时绕行值为 $`3.6`$，超过直接得到的三。

![同步更新读取旧表，原地扫描读取刚写入的新值](images/03-value-read-order.svg)

**相同解，为什么中间表不同？** 每张小表的两格依次保存 $`V(s),V(u)`$，箭头表示算法读写依赖，**不是环境状态转移**。从 $`(0,0)`$ 出发，同步第一轮中的 s 只能读取旧 $`V(u)=0`$，因而写入 $`\max(3,0.9\times0)=3`$；u 则写入终止收益四。第二轮 s 才能读到四，得到 $`3.6`$。

原地扫描若先更新 u，就先把表改成 $`(0,4)`$；随后更新 s 时立即读到新值四，同一轮便达到 $`(3.6,4)`$。上排每个箭头跨过一整轮，下排每个箭头只跨过一次状态备份，两者不能按图中箭头数量直接比较计算成本。对此任务，同步达到稳定值用了四次非终止状态备份，指定顺序的原地扫描用了两次；实际停止判据还可能需要残差或策略检查。同步有限前瞻的解释可对照 [Berkeley CS188 的价值迭代教材](https://inst.eecs.berkeley.edu/~cs188/textbook/mdp/value-iteration.html)。此图是两步确定性教学任务，后文三非终止状态的随机任务需要重新按其转移表计算。

## 2. 扩展为带成功概率的随机任务

<a id="mdp-3-detail-6"></a>

### 2.1 四状态机制与两个动作

现在使用零、一、二三个非终止状态和终止状态三。可以把零理解为准备区，一为工作区，二为修复区。每处有动作零与动作一，但含义由状态决定：准备区可稳步推进或冒险直达，工作区可稳健完成或继续高收益尝试，修复区可维修或改走替代路径。名称只是帮助记忆，真正模型由下列概率和奖励定义。

零的动作零以零点二留在零、零点八进入一，两种结果均奖励负零点一。零的动作一以零点五成功终止得零点六，零点五进入二得负零点五。一的动作零以零点八终止得一，零点二进入二得负零点二。一的动作一以零点五终止得一点二，零点五留在一得负零点四。

二的动作零以零点七回到一、零点三留在二，两种结果均奖励负零点三。二的动作一以零点四终止得零点八，零点六返回零得负零点二。折扣仍为零点九。终止状态自循环奖励零，仅为矩阵表示方便，不属于再次领取成功收益。所有转移行和为一，奖励明确与后继结果相关。

<a id="mdp-3-detail-7"></a>

### 2.2 全模型与非终止子模型

可以构造四状态完整转移张量，也可只保留非终止三状态未来项，得到次随机张量 $`K(s,a,s')`$。它每行和小于等于一，缺少质量正是终止概率。当前期望奖励仍必须包括终止分支奖励，不能因删掉终点列把成功收益也删掉。简化后期望奖励矩阵为

$$
r=\begin{pmatrix}-0.1&0.05\\0.76&0.4\\-0.3&0.2\end{pmatrix}.
$$

非终止未来项分别为：零动作零到零与一的概率零点二、零点八；零动作一到二的概率零点五；一动作零到二的概率零点二；一动作一到一的概率零点五；二动作零到一、二的概率零点七、零点三；二动作一到零的概率零点六。剩余质量终止。这样只需解三维价值，但必须保留完整结果表用于真实采样。

<a id="mdp-3-detail-8"></a>

### 2.3 为什么保留两种表示交叉核对

完整模型适合模拟转移与检查终止奖励，子模型适合线性求解与梯度推导。两者应该给出相同非终止价值。若不同，常见原因是删终点时漏掉进入奖励，或完整模型终点自循环仍给奖励。保存两种独立构造途径能发现这些错误，而不是让所有代码共享同一个错误数组后彼此“验证”。

本章不把状态名称当作真实业务规律，也不声称这个人工任务代表现实维护过程。它是为产生有意义动作取舍、随机失败和可核验数值而设计的有限模型。模型规模小使穷举全部策略成为可能，后续任何近似或采样结果都有精确参照，这正是学习实验的价值。

## 3. 随机模型前两轮完整手算

<a id="mdp-3-detail-10"></a>

### 3.1 第一轮只看即时期望

从 $`v^{(0)}=0`$ 开始，动作值等于期望奖励。零在两动作之间比较负零点一与零点零五，暂选动作一；一比较零点七六与零点四，选动作零；二比较负零点三与零点二，选动作一。于是 $`v^{(1)}=(0.05,0.76,0.2)`$。这只是一步任务的最优值，不是完整无限目标的最终策略。

零的冒险动作即时平均略正，所以第一轮看来更好。但稳步推进会进入价值较高的工作区，这种收益至少需要下一轮才能反映。有限前瞻策略随轮次变化完全合理。不要把第一轮动作标签保存为永久策略，也不要只比较最大状态值来选动作，必须按当前状态动作的后继分布计算一步期望。

<a id="mdp-3-detail-11"></a>

### 3.2 第二轮逐动作展开

零动作零为 $`-0.1+0.9(0.2\times0.05+0.8\times0.76)=0.4562`$，动作一为 $`0.05+0.9\times0.5\times0.2=0.14`$。一动作零为 $`0.76+0.9\times0.2\times0.2=0.796`$，动作一为 $`0.4+0.9\times0.5\times0.76=0.742`$。

二动作零为 $`-0.3+0.9(0.7\times0.76+0.3\times0.2)=0.2328`$，动作一为 $`0.2+0.9\times0.6\times0.05=0.227`$。所以第二轮 $`v^{(2)}=(0.4562,0.796,0.2328)`$，暂时三处都选动作零。二处两个动作只差零点零零五八，很容易随后续价值变化而翻转，这体现动作间隔与策略稳定的关系。

<a id="mdp-3-detail-12"></a>

### 3.3 最优解与最终动作间隔

收敛后最优价值约为 $`(0.63081321,0.85731504,0.54063913)`$，最终动作是零、零、一。动作值矩阵约为

$$
Q=\begin{pmatrix}0.63081321&0.29328761\\0.85731504&0.78579177\\0.38608104&0.54063913\end{pmatrix}.
$$

动作间隔约为零点三三七五三、零点零七一五二与零点一五四五六。工作区动作最接近，若粗糙模型误差或价值近似误差集中在相关后继，它更可能先改变。最终报告不只给动作数组，还给价值、动作值和残差，才能判断策略差异究竟重要还是接近平局。

## 4. 从近似价值提取并独立评价策略

<a id="mdp-3-detail-14"></a>

### 4.1 按动作前瞻而不是按状态排名

贪心策略在每个状态比较 $`r(s,a)+\gamma\sum_{s'}K(s,a,s')v(s')`$。下一状态价值高不代表动作一定好，因为进入概率和即时成本也参与。冒险直达终点的动作还可能失败后进入修复区，不能只沿最成功路径评价。随机模型规划正是把全部结果按概率结合，而不是挑一条看起来最有利轨迹。

提取动作后，固定策略重建 $`K_\pi,r_\pi`$，解 $`(I-\gamma K_\pi)v^\pi=r_\pi`$。再比较 $`v^\pi`$ 与候选价值、检查最优性残差。如果候选尚未收敛，贪心策略的真实价值可能不同；独立评估可区分数值值表和实际执行策略。这个步骤在真实大任务中可能需要采样，但有限例子可精确完成。

<a id="mdp-3-detail-15"></a>

### 4.2 穷举八个策略作为完整参照

三个非终止状态各有两个动作，共八个确定性平稳策略。逐个解线性方程，可以检查最优策略价值逐状态支配其他策略。这个穷举成本随状态指数增长，因此只是小型验收工具，不是通用大规模算法。但在可行时，它提供与迭代逻辑不同的独立证据，帮助发现 Bellman 实现或策略索引错误。

若多个策略达到同值，应保留平局解释。当前模型最终间隔均严格正，所以最优动作组合在非终止状态上唯一；终止状态动作无关，不应把不同终点占位动作当作不同控制方案。策略计数与最优性声明都需要明确哪些状态是真正决策点。

<a id="mdp-3-detail-16"></a>

## 5. 同步、原地与停止协议

<a id="mdp-3-detail-17"></a>

### 5.1 一次扫描不是统一计算单位

同步每轮从旧表计算全部状态，原地扫描则依次覆盖。若用相同扫描次数比较速度，中间值不同且每次可利用信息也不同。更可比的指标是状态动作备份次数、实际时间和达到同一残差阈值的成本。小模型中原地顺序可能很有优势，大模型中同步并行也可能更快，不能只用三状态结果推断普遍性能。

代码应避免意外别名。`new = old`并未复制数组，后续写入会直接改变旧表，原本想实现同步却变成原地。真正复制后，所有动作都读取旧表，才与同步手算一致。这个错误非常常见，而且最终仍可能收敛，所以只检查最终值无法确认迭代语义。

<a id="sec-6-1"></a>

<a id="mdp-3-detail-18"></a>

### 5.2 残差和容差如何选择

完整最优性残差为所有状态上 $`\vert Tv-v\vert `$ 最大值。若只看当前扫描最大更新差，原地算法下它不一定就是同一个量，因此停止前应额外计算完整残差。根据上一章理论，残差除以一减折扣给出价值误差界；若关注策略误差，还需相应控制界或独立策略评价。不要把一个任意小数阈值当作普遍质量保证。

浮点比较应使用绝对与相对容差，并根据奖励与价值尺度解释。过小阈值可能让迭代在舍入尾部浪费预算，过大阈值则可能选错接近动作。若结果接近平局，可以输出动作值差和一个近优动作集合，比强行宣布单一动作更诚实。当前模型间隔明确，适合先做严格参照。

先看上半图的环境：四条合法转移全部保留，状态零向左是付费自循环，状态一向左则退回零；两条向右路径构成到终点的最短通路。边上标的是本次转移奖励，终点 T 的零价值不会再发第二笔奖励。该画法借鉴 [Sutton–Barto 教材的状态—转移图](https://web.stanford.edu/class/psych209/Readings/SuttonBartoIPRLBook2ndEd.pdf)第 3 章图 3.3 中“每条环境边明确标明结果”的原则；本图使用本章自己的确定导航任务。

下半图单独画**价值数据沿依赖边被读取**的方向。同步的左侧状态旁标注的是整轮冻结的旧值，下方文字给出本轮写入值；原地的右侧状态旁标注的是这轮扫描完成后的新值，箭头突出状态一刚写入的一已被状态零使用。因此不能把下图的读取箭头当作小车行动，也不能把两侧圆内数字误认为同一读写时点。把环境图和更新依赖分开，才能解释为什么相同模型、相同备份公式会产生不同中间表。

这次不再切换到“步耗为零”的另一条链，而是直接使用第 1 节及实验一的同一个三状态导航任务。括号仅保存非终止状态零、一，终点值始终为零。同步从旧表 $`(0,0)`$ 计算时，状态零的两个动作都只有即时成本 $`-0.1`$，第一轮得到 $`(-0.1,1)`$；第二轮才传播出向右的目标 $`-0.1+0.9\times1=0.8`$。

原地先更新一，把表改成 $`(0,1)`$，再更新零。此时零向右的目标是 $`0.8`$，向左读取尚未更新的零，目标是 $`-0.1+0.9\times0=-0.1`$，因此写入 $`0.8`$。这一步向左的临时目标与最终最优表下的 $`0.62`$ 不同，两者读取的值表不同；图展示更新过程，不能把其中任一个中间动作值当作最终动作价值。

同步两轮共有四次非终止状态备份，指定顺序的原地一轮共有两次；停止确认和全表残差检查仍可能需要额外计算。本例说明依赖读取次序，没有证明原地在所有任务或硬件上更快。同步可并行，原地有顺序依赖；应在相同模型、容差和实际计算预算下比较。

## 6. 参数化随机策略的精确价值

<a id="mdp-3-detail-20"></a>

### 6.1 用 logits 定义可微策略

为每个非终止状态设置两个实数参数 $`\theta_{s,a}`$，用 softmax 得到 $`\pi_\theta(a\mid s)`$。固定这套策略，$`K_\theta(s,s')=\sum_a\pi_\theta(a\mid s)K(s,a,s')`$，$`r_\theta(s)=\sum_a\pi_\theta(a\mid s)r(s,a)`$，价值由线性方程精确给出。总体目标取从状态零出发，即 $`J(\theta)=\mu^Tv_\theta`$、$`\mu=(1,0,0)^T`$。

softmax 给所有动作正概率，有限参数下一般不能完全表示确定性最优策略，但可以越来越接近。不能因为梯度优化未得到恰好零一概率就认定规划失败。参数空间还具有每个状态行加同一常数不变的冗余，因此梯度每行和应为零。这提供一个很有用的独立检查。

<a id="mdp-3-detail-21"></a>

### 6.2 对线性方程求导

记 $`M=I-\gamma K_\theta`$，方程为 $`Mv=r`$。对参数微分，得到

$$
\begin{aligned}
M\,dv &=dr+\gamma\,dK\,v,\\[6pt]
dJ &=\mu^TM^{-1}(dr+\gamma dK\,v).
\end{aligned}
$$

定义折扣非终止访问量 $`d=M^{-T}\mu`$，于是 $`dJ=d^T(dr+\gamma dK\,v)`$。这不是归一化概率，和可以小于持续任务的 $`\frac{1}{(1-\gamma)}`$，因为终止后不再访问非终止状态。若需要完整访问分布，可以加入吸收状态统一解释，但当前梯度只涉及可决策状态。

利用 softmax 导数，最终得到

$$
\frac{\partial J}{\partial\theta_{s,a}}=d(s)\pi(a\mid s)\bigl[q^\pi(s,a)-v^\pi(s)\bigr].
$$

它将访问频率、动作概率和优势结合。高优势但永不访问状态的参数对当前起点目标没有直接贡献；概率很小的动作也可能梯度很小。这个公式在有限已知模型中可以精确检查，是学习后续采样策略梯度前的重要参照。

<a id="mdp-3-detail-22"></a>

### 6.3 均匀策略的实际数值

所有 logits 为零时策略各半，价值约为 $`(0.36965393,0.78841570,0.34469076)`$，非终止访问量约为 $`(1.21500492,0.72343912,0.39131286)`$。梯度矩阵约为

$$
\nabla J=\begin{pmatrix}0.09996033&-0.09996033\\0.01216414&-0.01216414\\-0.01074591&0.01074591\end{pmatrix}.
$$

符号与最优动作方向一致，但这不是普遍证明每次局部梯度都直接指向全局确定性最优。当前策略的优势随参数变化，访问分布也会变化。数值例子只是展示三个量如何相乘，并用独立自动微分与有限差分验证公式。下一阶段真正策略优化还涉及采样方差、探索和优化路径。

<a id="mdp-3-detail-23"></a>

## 7. 数值模型的验证层次

<a id="mdp-3-detail-24"></a>

### 7.1 概率、奖励和终止一致性

验证完整模型每状态动作概率非负且和一，子模型行和不超过一，缺少质量与终止概率一致。奖励期望应从完整结果表重算，不能只手填一个没有来源的矩阵。终点自循环奖励必须与任务结束语义一致。非法动作若存在，应单独掩码，不要默认填零让负收益合法动作输给虚假动作。

不同计算路径尽量不要全依赖同一个中间结果。若规划、模拟和手算都读取一张错误期望奖励表，它们可能一致却都错。保留原始结果表，独立聚合期望；模拟按结果表采样；梯度按矩阵解计算；手算选择若干条转移核对。这种交叉验证比重复运行同一段代码更有意义。

<a id="mdp-3-detail-25"></a>

### 7.2 解析、迭代与采样回答不同问题

解析线性解验证固定策略期望，价值迭代验证最优不动点，策略穷举验证全局比较，模拟回报验证轨迹实现与模型一致。它们相互支持但不完全替代。模拟均值有随机误差，不能要求每次精确等于解析值；解析结果则依赖模型正确，不证明现实机制有效。实验报告应明确每条证据覆盖哪一层。

所有本章数据由人工模型生成，实验只在 CPU 内存运行，无需外部环境库、数据下载或权重文件。它们旨在把规划、梯度与评估的关系讲透，不声称解决真实导航或维护问题。只有先把这些小型对象做得可复核，扩展到复杂环境时才有可靠参照。

<a id="mdp-3-detail-26"></a>

## 8. 四个独立 CPU 实验

<a id="mdp-3-detail-27"></a>

### 8.1 实验一：导航同步与原地更新

代码显式写出四条非终止转移，比较一次同步扫描与从靠近终点开始的原地扫描。两者第一轮不同，但继续迭代后应得到相同最优值。还检查贪心动作值和终点零值，防止重复领取一次性奖励。这个实验保留最小模型，不把随机扩展中的数字混进来。

```python
import numpy as np

gamma = .9
next_state = np.array([[0, 1], [0, 2]])
reward = np.array([[-.1, -.1], [-.1, 1.]])
def q(v, s):
    return reward[s]+gamma*v[next_state[s]]
v0 = np.zeros(3)
synchronous = v0.copy()
for s in [0, 1]:
    synchronous[s] = q(v0, s).max()
assert np.allclose(synchronous, [-.1, 1., 0.])
inplace = v0.copy()
for s in [1, 0]:
    inplace[s] = q(inplace, s).max()
assert np.allclose(inplace, [.8, 1., 0.])
assert not np.allclose(synchronous, inplace)
v = v0.copy()
for _ in range(10):
    new = v.copy()
    for s in [0, 1]:
        new[s] = q(v, s).max()
    v = new
assert np.allclose(v, inplace)
assert np.allclose(q(v, 0), [.62, .8])
assert np.allclose(q(v, 1), [.62, 1.])
assert v[2] == 0
print('navigation sync/inplace/final value:', synchronous.tolist(), inplace.tolist())
```

终点没有动作更新，因此进入终点的奖励只出现一次。若用完整吸收状态矩阵实现，也应令终点后续奖励为零。不同表示可以等价，但必须统一约定；若把终点值固定一再保留进入奖励一，就会改变结果，不能靠增加迭代轮数修复。

<a id="mdp-3-detail-28"></a>

### 8.2 实验二：随机模型规划与八策略穷举

本块只存非终止子模型与当前期望奖励，先验证前两轮手算，再运行价值迭代，提取策略并独立求值。对全部八个确定性策略逐一计算，检查最优价值支配关系。停止后重新计算完整残差，不把某一轮最大覆盖差冒充残差。所有计算使用双精度数组。

```python
import itertools
import numpy as np

k = np.zeros((3, 2, 3))
k[0, 0] = [.2, .8, 0]
k[0, 1] = [0, 0, .5]
k[1, 0] = [0, 0, .2]
k[1, 1] = [0, .5, 0]
k[2, 0] = [0, .7, .3]
k[2, 1] = [.6, 0, 0]
r = np.array([[-.1, .05], [.76, .4], [-.3, .2]])
gamma = .9
assert np.all(k >= 0) and np.all(k.sum(2) <= 1+1e-12)
def q(v):
    return r+gamma*np.einsum('sak,k->sa', k, v)
v1 = q(np.zeros(3)).max(1)
v2 = q(v1).max(1)
assert np.allclose(v1, [.05, .76, .2])
assert np.allclose(v2, [.4562, .796, .2328])
v = np.zeros(3)
for iteration in range(10000):
    new = q(v).max(1)
    v = new
    residual = np.max(np.abs(q(v).max(1)-v))
    if residual < 1e-12:
        break
else:
    raise AssertionError('iteration budget exhausted')
policy = q(v).argmax(1)
assert np.array_equal(policy, [0, 0, 1])
assert np.allclose(v, [.63081321, .85731504, .54063913], atol=1e-8)
kp = k[np.arange(3), policy]
rp = r[np.arange(3), policy]
exact = np.linalg.solve(np.eye(3)-gamma*kp, rp)
assert np.allclose(exact, v, atol=1e-10)
for choices in itertools.product(range(2), repeat=3):
    choices = np.array(choices)
    value = np.linalg.solve(np.eye(3)-gamma*k[np.arange(3), choices],
                            r[np.arange(3), choices])
    assert np.all(value <= exact+1e-10)
print({'value': exact.tolist(), 'policy': policy.tolist(),
       'residual': residual, 'q': q(exact).tolist()})
```

这里次随机行和代表终止概率，不是转移数据缺失。若误把每行强制重新归一化为一，会抹掉终止机制，得到另一个持续模型。概率检查必须理解表示含义，不能机械要求所有数组行都为一。完整四状态模型才应该每行概率质量为一。

<a id="mdp-3-detail-29"></a>

### 8.3 实验三：精确策略梯度的三重核对

本实验从均匀随机策略出发，用 PyTorch 对线性求解自动微分，同时用访问量和优势公式手工计算，再做一个同时扰动多个参数的方向有限差分。它验证的是已知小模型的精确期望梯度，不涉及采样估计。参数每行整体平移不改变策略，因此梯度行和也应近零。

```python
import torch

torch.set_num_threads(1)
torch.set_default_dtype(torch.float64)
k = torch.zeros(3, 2, 3)
k[0, 0] = torch.tensor([.2, .8, 0.])
k[0, 1, 2] = .5
k[1, 0, 2] = .2
k[1, 1, 1] = .5
k[2, 0] = torch.tensor([0., .7, .3])
k[2, 1, 0] = .6
r = torch.tensor([[-.1, .05], [.76, .4], [-.3, .2]])
gamma = .9
mu = torch.tensor([1., 0., 0.])
theta = torch.zeros(3, 2, requires_grad=True)
def objective(logits):
    pi = logits.softmax(1)
    kp = torch.einsum('sa,sak->sk', pi, k)
    rp = (pi*r).sum(1)
    value = torch.linalg.solve(torch.eye(3)-gamma*kp, rp)
    return mu @ value, (pi, kp, value)
j, (pi, kp, value) = objective(theta)
j.backward()
with torch.no_grad():
    occupancy = torch.linalg.solve((torch.eye(3)-gamma*kp).T, mu)
    q = r+gamma*torch.einsum('sak,k->sa', k, value)
    manual = occupancy[:, None]*pi*(q-value[:, None])
    assert torch.allclose(theta.grad, manual, atol=1e-12, rtol=1e-12)
    assert torch.allclose(theta.grad.sum(1), torch.zeros(3), atol=1e-12)
    direction = torch.tensor([[.3, -.2], [-.4, .1], [.2, .5]])
    eps = 1e-6
    fd = (objective(theta+eps*direction)[0]-objective(theta-eps*direction)[0])/(2*eps)
    assert torch.allclose(fd, (manual*direction).sum(), atol=1e-10, rtol=1e-8)
    assert torch.allclose(value, torch.tensor([.36965393, .78841570, .34469076]), atol=1e-8)
print('value/occupancy/gradient:', value.detach().tolist(), occupancy.tolist(), manual.tolist())
```

自动微分与手算共享相同模型，但使用不同推导路径；有限差分又直接检查目标随参数变化。三者一致有力支持当前实现正确，却仍不证明真实环境模型正确。未来把梯度改成轨迹采样估计时，还需检查采样分布、回报定义、基线与方差，不能把这里的精确核对自动扩展成所有策略梯度代码都可靠。

<a id="mdp-3-detail-30"></a>

### 8.4 实验四：完整结果表采样验证

这里从原始结果表独立构建完整四状态转移与期望奖励，再与非终止矩阵比较。固定最终确定性策略，从状态零模拟独立轨迹。设最大采样步数仅为保护循环，若外部截断则用真实策略价值补尾，真实终止不补尾。统计均值只作模型与采样一致性检查，容差明显宽于当前标准误，不据此选择策略。

```python
import numpy as np

outcomes = {
 (0,0): [(.2,0,-.1), (.8,1,-.1)],
 (0,1): [(.5,3,.6), (.5,2,-.5)],
 (1,0): [(.8,3,1.), (.2,2,-.2)],
 (1,1): [(.5,3,1.2), (.5,1,-.4)],
 (2,0): [(.7,1,-.3), (.3,2,-.3)],
 (2,1): [(.4,3,.8), (.6,0,-.2)],
}
p = np.zeros((3,2,4))
r = np.zeros((3,2))
for (state, action), rows in outcomes.items():
    assert np.isclose(sum(prob for prob, _, _ in rows), 1.)
    for prob, nxt, reward in rows:
        p[state, action, nxt] += prob
        r[state, action] += prob*reward
assert np.allclose(r, [[-.1,.05],[.76,.4],[-.3,.2]])
policy = np.array([0,0,1])
gamma = .9
value = np.linalg.solve(np.eye(3)-gamma*p[np.arange(3), policy, :3],
                        r[np.arange(3), policy])
rng = np.random.default_rng(409)
returns = []
truncations = 0
for _ in range(20000):
    state, total, discount = 0, 0., 1.
    for step in range(200):
        rows = outcomes[(state, int(policy[state]))]
        index = int(rng.choice(len(rows), p=[row[0] for row in rows]))
        _, nxt, reward = rows[index]
        total += discount*reward
        discount *= gamma
        if nxt == 3:
            break
        state = nxt
    else:
        total += discount*value[state]
        truncations += 1
    returns.append(total)
returns = np.array(returns)
mean = returns.mean()
se = returns.std(ddof=1)/np.sqrt(len(returns))
assert abs(mean-value[0]) < .03
assert np.isfinite(returns).all()
print({'analytic': float(value[0]), 'sample_mean': float(mean),
       'standard_error': float(se), 'truncations': truncations})
```

这个固定随机流的二万次模拟平均接近解析值，但具体差异应与标准误一起解释。若一次结果超出经验容差，先检查模拟与奖励逻辑，也要承认随机波动可能发生；这里的断言不是形式概率保证。更严谨的统计实验可以预先规定置信水平或使用有界集中界，具体目标与样本预算需要另外设计。

## 9. 十六道完整算例练习与解析

<a id="mdp-3-detail-32"></a>

### 9.1 第一轮起点为什么是负数

题目：导航从零价值初始化，第一轮状态零是否仍为零？解答：不是，两个动作本步都付负零点一，未来旧价值全零，因此新值负零点一。只有把非终止奖励设零的另一种模型才会得到零。同步层数解释必须与当前奖励一致。将熟悉例子的结果直接搬过来，会使后续手算与代码产生一位或一项偏差。

<a id="mdp-3-detail-33"></a>

### 9.2 原地一次得到答案是否神奇预知

题目：先更新状态一再更新零，一轮就得到最优导航值，是否违反一步传播规律？解答：不违反，因为这次扫描包含按依赖顺序使用新值的多次备份，不是同步一层。把一整次扫描称为一轮，只是计算组织方式。比较算法应注明读取旧值还是新值，以及备份次数，不能只用轮数字面相同判断信息传播范围。

<a id="mdp-3-detail-34"></a>

### 9.3 随机模型零的期望奖励怎么算

题目：零冒险动作成功得零点六、失败得负零点五，各半，期望是多少？解答：零点三减零点二五，等于零点零五。不能只看成功分支，也不能把终止奖励从期望里删掉。当前奖励与是否继续是两个对象：成功分支没有未来价值，但仍有本步成功收益。子模型简化最容易在这里漏项。

<a id="mdp-3-detail-35"></a>

### 9.4 子转移行和不足一是否错误

题目：一稳健动作的非终止行和为零点二，是否必须归一化？解答：不应该，它另有零点八概率终止。子模型只保存继续部分，缺少质量有明确定义。强制归一化会把失败进入修复的概率改成一，抹掉成功终止机制。应检查完整四状态行和一，子模型行和不超过一，并核对两者对应关系。

<a id="mdp-3-detail-36"></a>

### 9.5 第二轮修复区为什么暂选维修

题目：修复区第二轮两个动作值各是多少？解答：维修为负零点三加零点九乘零点七乘旧工作区零点七六，再加零点三乘旧修复零点二，得到零点二三二八。替代路径为零点二加零点九乘零点六乘旧准备零点零五，得到零点二二七。前者略高，但最终后者更优，说明有限前瞻动作可以变化。

<a id="mdp-3-detail-37"></a>

### 9.6 为什么不能沿成功路径算最优

题目：准备区冒险可一步成功，是否应直接选它？解答：不够，还要考虑失败概率、失败代价和修复后的未来。完整动作值包含所有结果的概率加权。成功路径短只是一个分支特征，不代表期望更高。若业务优化最坏情况或成功概率，又应另定义目标，不能把不同风险标准混在同一个期望计算里。

<a id="mdp-3-detail-38"></a>

### 9.7 提取策略后为何再求一次值

题目：价值迭代已有值表，固定贪心策略再解线性方程是否多余？解答：在小模型中它是很有用的独立核对。近似值表未收敛时，实际策略价值可能不同；策略索引错误也可能被发现。若两者相符且最优性残差小，说明数值和执行规则一致。大模型成本较高时可用其他评价，但不能忽略策略实际表现与候选值表的区别。

<a id="mdp-3-detail-39"></a>

### 9.8 八策略穷举证明覆盖哪些策略

题目：枚举八个确定性平稳策略，是否直接枚举了所有历史随机策略？解答：没有，后者数量远大且可无限。穷举结合有限折扣 MDP 存在确定性平稳最优策略的定理，才足以作为最优性参照。单靠八次比较本身只能证明在这八个候选中最好。理论和数值各负责一部分，不能让有限枚举承担未说明的全策略覆盖。

<a id="mdp-3-detail-40"></a>

### 9.9 softmax 为什么难以恰好确定

题目：有限 logits 能否给一个动作严格概率一、另一个零？解答：普通 softmax 的指数均为正，有限参数下不能。可以逐渐增大差值接近确定性策略，或最后单独取贪心部署，但后者是另一执行规则。比较优化结果与确定最优值时，应考虑这个参数化边界，不能把任意小差距都当作梯度实现错误。

<a id="mdp-3-detail-41"></a>

### 9.10 梯度每行和为何为零

题目：均匀策略梯度一行两个数为何相反？解答：同一状态所有 logits 加相同常数不改变 softmax，目标沿这条方向导数为零。也可由公式求和得到访问量乘策略平均优势，而平均优势为零。若数值行和显著非零，应检查 softmax 维度、优势基准和自动微分路径，这是一项与具体参数值无关的不变量。

<a id="mdp-3-detail-42"></a>

### 9.11 访问量为何不是普通概率

题目：准备状态访问量约一点二一五，超过一是否错误？解答：不错误，它是从初始分布出发折扣累计访问次数，允许多次返回。没有乘一减折扣，也未把终止吸收状态纳入归一化。非终止访问量总和反映任务持续程度。把它强制归一化后直接代入梯度，会改变梯度尺度，必须同时调整公式。

<a id="mdp-3-detail-43"></a>

### 9.12 解析梯度与采样梯度有何不同

题目：本章梯度无需轨迹，是否意味着策略梯度通常不需要交互？解答：这里模型全部已知，价值和访问量可精确求解；未知环境通常不能直接得到这些矩阵，需要轨迹估计或学模型。解析实验用来提供参照和理解，不替代采样覆盖、方差和探索问题。已知模型与未知模型是不同信息条件。

<a id="mdp-3-detail-44"></a>

### 9.13 有限差分为什么选方向而非只一个坐标

题目：同时扰动多个 logits 有何意义？解答：方向导数应等于梯度与方向内积，可以检验多个坐标贡献与转置组合。只看一个巧合为零的坐标容易漏错。方向差分仍不是全部可能参数的证明，应结合解析公式和自动微分；步长太大有截断误差，太小有舍入误差，需合理范围。

<a id="mdp-3-detail-45"></a>

### 9.14 采样均值比解析值高是否正常

题目：二万次模拟均值零点六三二九，高于真实零点六三零八，是否说明模型不一致？解答：差约零点零零二一，与标准误约零点零零二同量级，完全可能来自采样波动。应结合样本数、方差和预设检验解释，不要求随机均值逐位等于期望。若反复按结果挑随机种子，则会引入选择偏差，不能继续当独立无偏验证。

<a id="mdp-3-detail-46"></a>

### 9.15 最大模拟步数属于什么停止

题目：人工模型可能继续，但采样循环达到二百步，能否直接当终止？解答：不能，这是外部保护上限。代码若发生这种情况，应保存真实末状态并按目标补尾或说明截断偏差。本次固定模拟没有出现截断，但正确分支仍保留。测试没有触发某边界，不代表可以在定义中把它忽略。

<a id="sec-7-1"></a>

<a id="mdp-3-detail-47"></a>

### 9.16 如何比较两种更新实现

题目：两个程序中间表不同，最终策略相同，如何判断合理？解答：先确认同步与原地语义，再比较最终 Bellman 残差、固定策略评价和模型输入。若这些一致，中间差异可以来自合法更新顺序；若仅策略碰巧相同，仍不足以证明值表与模型正确。比较还要报告备份次数和资源，而不是只比较循环轮数。

<a id="mdp-3-detail-48"></a>

## 10. 精确策略梯度的细节展开

<a id="mdp-3-detail-49"></a>

### 10.1 softmax 导数如何产生优势

对某个状态，策略导数为 $`\frac{\partial\pi(b\mid s)}{\partial\theta_{s,a}}=\pi(b\mid s)(\mathbf1[a=b]-\pi(a\mid s))`$。将它乘到每个动作的一步价值后求和，得到 $`\pi(a\mid s)[q(s,a)-\sum_b\pi(b\mid s)q(s,b)]`$。后面平均项正是当前策略价值，所以优势不是人为额外添加的启发，而是归一化动作概率导数自然产生的中心化项。

再乘折扣访问量，表示该状态参数在当前起点任务中被使用多少。这个因子不是只看一次转移能得到的，因为当前动作改变未来返回概率。通过线性方程隐式求导，所有未来影响已经包含在逆矩阵里。直接只对当前奖励求导，会漏掉转移分布改变带来的长期收益，得到另一个短视目标。

如果把价值在代码中错误地从计算图分离，仍可能得到当前奖励部分梯度，数值也可能非零。但它不再等于完整目标导数。当前实验通过方向差分能发现这类遗漏，因为有限差分直接重新求解目标，不依赖自动微分内部路径。解析、自动微分和差分三者各有不同失误模式，组合核对更可靠。

<a id="mdp-3-detail-50"></a>

### 10.2 为什么对价值求导不用展开无限轨迹

价值公式的逆矩阵可展开为折扣转移幂级数，包含零次、一次、两次等所有未来访问。对方程隐式求导，相当于把无限路径影响用一个线性系统汇总。它不是忽略远期，也不是只看当前策略一步效果。有限已知模型允许这种压缩，正是动态规划的计算优势。

若直接把价值迭代展开固定轮数再自动微分，得到的是截断计算图目标的梯度。轮数足够多时可能接近精确梯度，但收敛误差和梯度误差不一定完全相同。隐式线性求解提供更直接参照。对复杂非线性不动点，隐式微分还需要可逆性与局部条件，不能把当前线性案例无条件推广。

如果数值求解器只近似求解，自动微分实现可能根据其接口返回相应导数；学习者应检查求解残差和导数一致性，而不把工具返回的梯度默认当精确。小矩阵双精度可把这部分误差压得很小，大规模稀疏问题则需权衡求解精度与成本，并明确停止规则。

<a id="mdp-3-detail-51"></a>

### 10.3 起点分布改变梯度权重

当前目标从状态零开始，所以准备区访问权重最大。若初始分布改为修复区，访问量和梯度大小都会变化，即使同一策略的逐状态价值和动作优势不变。因而梯度不是模型固有的一张固定表，它还依赖评价任务从哪里出发。对多来源任务，应按部署频率或明确公平目标设置初始权重。

有些状态在当前策略下不可达，目标梯度可以为零，即使在那里改动作会显著提高它自身价值。这并不矛盾，当前起点目标从未使用该决策。若希望全状态都表现好，可以改变训练起点分布、加入探索或优化更广目标，但应承认目标变化。不能仅看到某状态梯度零就判定自动微分失效。

当前 softmax 全支持和模型连通使多数状态可访问，但确定性策略或不同图结构可能产生完全不可达区域。数据采样时这个问题更严峻：理论上小概率可达也可能在有限轨迹里从未出现。解析访问量揭示机制，实际学习仍需面对有限覆盖和方差，而不是把非零理论概率当作足够证据。

<a id="mdp-3-detail-52"></a>

### 10.4 梯度上升与确定性规划的关系

可以在这个小模型中对 logits 做梯度上升，观察目标逐渐接近最优确定性价值。但步长过大时目标未必每步增加，有限参数也只近似确定性最优。若使用 Adam，优化器内部状态进一步改变更新方向尺度。不能只根据梯度符号与最优动作一致，就跳过实际优化验证或宣称全局线性收敛。

本章已经用精确规划获得参照，所以任何策略优化轨迹都可以直接画出真实目标差，而不依赖噪声回报判断。还可比较不同初始 logits、不同步长和温度，研究饱和概率如何减小梯度。这个实验适合后续章节扩展，但若要报告新结果，应实际运行并区分建议实验与已验证实验。

<a id="mdp-3-detail-53"></a>

## 11. 模型参数变化时怎样重新分析

<a id="mdp-3-detail-54"></a>

### 11.1 改变导航步耗会改变目标排序

三状态导航中，若每次非终止转移得到正奖励 $`c`$，零可以原地持续领取，回报为 $`\frac{c}{(1-\gamma)}`$。直接前进则为 $`c+\gamma`$。当原地回报超过前进时，模型会合理选择拖延。这个现象不是算法钻漏洞的神秘行为，而是给定奖励的最优解。判断奖励是否表达需求，需要先比较这些可手算路径。

在工作区也可能通过反复尝试获得不同风险收益。改变失败代价或终止奖励后，原先最优动作可能切换，不能保留旧策略标签作为固定测试。合适的性质测试应验证数学关系和模型合法性，具体最优值则随参数重新计算。把“永远向右”写死在任何配置的断言里，会把正确策略变化误判为代码错误。

<a id="mdp-3-detail-55"></a>

### 11.2 成功概率与奖励相关不能拆错

冒险动作成功概率变化时，当前期望奖励也随之变化，因为成功与失败奖励不同。若只改转移概率却保留旧平均奖励表，模型不再对应原始结果语义。应从完整结果表同时重建转移和奖励期望，或者明确平均奖励本来是独立给定的新任务。这个一致性问题在使用估计模型时尤为常见。

同样，终止概率降低会让更多未来成本被累计，价值变化不只是成功奖励变少。参数敏感度包含即时奖励与后续访问两条路径。可以固定一套策略先研究其解析价值，再比较最优策略切换。前者在参数处通常光滑，后者因最大动作变化可能出现折点，二者数值差分解释不同。

<a id="mdp-3-detail-56"></a>

### 11.3 动作切换边界不宜用普通梯度硬套

最优值是多个策略价值的上包络。在某些参数区域最优策略不变，可以对该策略解析求导；在两策略平局边界，最优值可能不可微，只存在单侧导数或次梯度。若有限差分跨过边界，结果混合两侧机制，不应拿它与固定策略导数强行相等。当前均匀策略梯度实验避免了这个最大值不可微问题。

研究参数阈值时，可以直接枚举八策略，求各策略价值随参数变化，再找到交点。数值网格能提供候选区域，精确方程可进一步验证。若只画几个点然后宣称全局阈值，需要额外单调性或解析证据。小型模型的优势就在于可以把这些细节彻底弄清，而不是只给一张趋势图。

<a id="mdp-3-detail-57"></a>

### 11.4 折扣变化与成功时间分布

折扣更大通常提高远期收益的相对权重，但最优动作如何变化仍依赖成本与风险。某策略成功概率高却很慢，另一策略成功率略低但收益更早，二者排序可能随折扣切换。仅比较最终成功率不足以解释折扣价值，必须考虑奖励发生时间和期间成本。相同终止概率也不保证相同回报。

可以在固定策略下计算折扣成功指示的期望，或记录成功时间分布，再与总回报分开分析。若目标本来只关心在期限内成功，直接优化成功概率可能比任意设置步耗更贴合需求。目标选择应先于算法比较，本章模型只是提供一个可以验证不同偏好的载体。

## 12. 数值实现的进阶检查

<a id="mdp-3-detail-59"></a>

### 12.1 数组轴必须有可读语义

本章转移张量轴顺序为状态、动作、后继状态。若误把动作与后继轴互换，小模型在恰好两状态两动作时甚至形状仍匹配，错误很隐蔽。每个数组应配合明确的轴说明，再用一条非对称转移验证。扩大到三非终止状态两个动作，也有助于避免所有维数巧合相同掩盖错误。

广播运算同样需要检查。奖励矩阵形状是状态乘动作，价值向量只沿后继轴求期望；若不小心把奖励按后继维重复或把动作均值提前求掉，结果可能仍有限。使用有名字的中间量和小规模逐项循环参照，有时比过度压缩成一个复杂表达式更利于教学和复核。

<a id="mdp-3-detail-60"></a>

### 12.2 线性系统残差与条件数

求解 $`Mv=r`$ 后应计算 $`Mv-r`$ 的最大绝对值，必要时结合相对尺度。残差小通常是必要数值证据，但解误差还与矩阵条件有关。折扣接近一且任务持续很长时，逆矩阵可能放大输入与舍入误差。当前小模型终止机会较大、双精度足够稳定，但不能把它的数值表现推广到任意近乎不终止系统。

显式求逆往往不如直接求解，尤其只需一个右端向量时。梯度里的访问量解转置系统，也可以复用分解结构。大型稀疏模型还可用迭代求解器，需记录容差和未收敛情况。工程加速应保持数学对象一致，不要为了让求解器成功随意给矩阵加正则而不说明目标变化。

<a id="mdp-3-detail-61"></a>

### 12.3 终止概率与期望长度

若固定策略的非终止矩阵为 $`K_\pi`$，未折扣期望到终止步数在适当瞬时条件下满足 $`h=\mathbf1+K_\pi h`$。因此可以解 $`(I-K_\pi)h=\mathbf1`$，独立分析任务长度。它与折扣价值方程相似，但没有折扣保证，矩阵可逆性需要真正终止条件。若某策略形成永不终止闭环，期望长度可能无限。

这项分析能帮助选择模拟保护上限与理解样本成本。当前实验上限二百只是保守保护，并非任务期限。若大量轨迹触及上限，应该报告比例并检查补尾误差，不能默默把它们当失败或丢弃。丢弃长轨迹会按长度选择样本，可能显著偏移回报均值。

<a id="mdp-3-detail-62"></a>

### 12.4 浮点平局与动作容差

若两个动作值只差接近机器误差，直接`argmax`会按实现规则选择其中一个。评价动作数组应使用价值意义上的近优集合，或至少报告差距。当前最优间隔远大于数值误差，因此严格动作断言合理；在参数阈值实验中则不宜沿用同样严格规则。容差选择应与问题尺度和用途对应。

也不要把所有小差异都归为舍入。一个漏掉折扣、奖励或终止质量的错误，有时只在某个参数区域表现为很小差异，但机制仍错。先核对解析不变量和精确小例子，再讨论浮点容差，能够避免用宽松比较掩盖真实实现问题。

<a id="mdp-3-detail-63"></a>

## 13. 从模拟均值到统计结论

<a id="mdp-3-detail-64"></a>

### 13.1 标准误回答的随机问题

固定策略和环境模型后，独立轨迹回报的样本均值估计该策略期望。标准误近似为样本标准差除以样本数平方根，描述重复抽同样轨迹实验时均值波动。它不包括环境模型失真、策略训练随机性或初始分布变化。把一个很小标准误当作现实部署已可靠，是混淆不同误差来源。

当前二万轨迹回报均值约零点六三二八七，解析值约零点六三零八一，标准误约零点零零一九九。差约一个标准误，符合正常波动直觉。这个结果支持模拟和规划模型一致，但不等于严格证明，也不要求每次换种子都落在同一窄区间。概率解释需要明确重复机制，而不是只比较小数前几位。

<a id="mdp-3-detail-65"></a>

### 13.2 配对比较两个策略的条件

比较两个策略时，可以共享同一外部场景或随机结果表，减少任务难度波动。但若随机数按调用顺序取，而策略改变轨迹长度，简单共享种子未必形成同一外部扰动。更明确做法是预先按时间和状态定义独立噪声，或使用具有清楚物理含义的共同随机变量。配对设计必须对应模型语义，不能只依赖种子数字相同。

配对差的方差与两个回报的相关性有关，可能低于独立比较，也可能因不合适耦合而没有收益。统计报告应说明是否配对、单位是轨迹还是场景，以及是否在相同初始条件下评价。当前实验只验证一个固定策略，因此没有声称完成策略间显著性比较。

<a id="mdp-3-detail-66"></a>

### 13.3 学习曲线与最终评估分开

若后续用梯度优化策略，每轮看模拟回报挑最好模型，这些模拟场景就是开发集。最终应使用独立轨迹和冻结策略评估，否则最高观测回报受到选择偏差。已知模型中可以直接用精确目标选点，但如果研究的是采样算法，也应记录它是否获得了额外精确信息。算法信息权限与最终指标必须分开。

可以同时画精确目标曲线与采样估计曲线，解释噪声如何影响选点；这组双曲线比较属于尚需独立运行的扩展研究。正式结果应准确区分已经执行的实验与可进一步探索的方案，避免把计划写成验证结论。扩展结果应注明实现范围与参照，才能判断新增曲线是否支持相应结论。

<a id="mdp-3-detail-67"></a>

### 13.4 罕见失败与均值之外的指标

若策略偶尔出现极低回报，样本均值可能看起来很好却掩盖重要风险。可以同时报告回报分位数、终止原因和长轨迹比例。当前模型规模小，完整回报分布也可通过枚举或递推进一步研究，但期望价值本身不包含这些全部信息。风险目标改变时，最优策略也可能变化，不能默认沿用期望最优动作。

估计罕见事件通常需要远大于普通均值验证的样本量。二万次没有发生某事件，不说明其概率严格为零。若业务有很低失败率要求，应使用专门置信界与覆盖设计，不能把教学模拟的零计数当安全保证。模型内概率已知时可以直接计算相关事件，这也体现已知模型与真实未知系统的区别。

<a id="mdp-3-detail-68"></a>

## 14. 补充分析：终止长度与模型敏感度

<a id="mdp-3-detail-69"></a>

### 14.1 最优策略下的期望终止步数

固定最优策略零、零、一，非终止转移矩阵行分别为 $`(0.2,0.8,0)`$、$`(0,0,0.2)`$、$`(0.6,0,0)`$。从每个状态到终止的期望步数满足 $`h_0=1+0.2h_0+0.8h_1`$，$`h_1=1+0.2h_2`$，$`h_2=1+0.6h_0`$。解得约 $`(2.78409091,1.53409091,2.67045455)`$，说明当前任务通常很短。

步数方程每次先记一，因为当前还要执行一次动作，无论这次是否立刻终止。若把终止分支不记当前步，就会低估长度。期望长度与折扣回报不同：一个动作可能让任务更快但收益较低，另一个可能慢而收益高。只有目标明确惩罚每步，或者成功奖励与时域结构产生特定偏好时，才可把最短和最高收益联系起来。

这种长度分析还支持模拟成本预估。二万条轨迹平均约几步，实际循环调用数量远小于二百上限乘二万。大模型报告采样预算时，最好同时给轨迹数和总环境转移数，因为不同策略长度差异会改变计算与数据量。固定回合数不等于固定交互预算，尤其策略会通过提前结束改变样本成本。

<a id="mdp-3-detail-70"></a>

### 14.2 补充实验：非终止基本矩阵

以下独立代码验证期望长度、最终吸收概率以及有限时域存活质量。没有折扣时的逆存在依赖该策略最终吸收，而不是上一章的折扣收缩条件。代码通过具体矩阵谱半径与方程残差确认当前例子适用，不把它推广到任意策略或任意 MDP。

```python
import numpy as np

k = np.array([[.2, .8, 0.], [0., 0., .2], [.6, 0., 0.]])
identity = np.eye(3)
assert np.max(np.abs(np.linalg.eigvals(k))) < 1
length = np.linalg.solve(identity-k, np.ones(3))
assert np.allclose(length, [2.784090909090909, 1.534090909090909, 2.670454545454545])
assert np.allclose(length, 1+k @ length)
terminal_probability = 1-k.sum(1)
absorption = np.linalg.solve(identity-k, terminal_probability)
assert np.allclose(absorption, np.ones(3))
mass = np.array([1., 0., 0.])
length_partial = 0.
for _ in range(100):
    length_partial += mass.sum()
    mass = mass @ k
assert np.isclose(length_partial, length[0], atol=1e-12)
assert mass.sum() < 1e-20
print('expected lengths/absorption:', length.tolist(), absorption.tolist())
```

利用尾和公式，期望长度等于每个时刻仍未终止的概率之和，所以逐步累加存活质量与线性解一致。这里不需要模拟随机事件，也不存在均值方差。它与前面的轨迹采样互补：一个检验分布递推，一个检验随机结果选择。若两者不一致，优先核对终止时点和当前步是否计数。

<a id="mdp-3-detail-71"></a>

### 14.3 奖励参数的局部敏感度

固定策略下，若某状态奖励增加小量，价值变化由折扣访问结构传播。以准备区即时奖励统一增加 $`\epsilon`$ 为例，从准备区起点的目标变化率等于该策略下准备区折扣访问量，而不是必然等于一。因为轨迹可能多次返回，每次都再次收到这份增量。这个解释把隐式梯度与访问量联系得很直观。

但如果增加量只作用于某个动作，导数还要乘该动作执行概率；若参数同时改变成功概率，当前期望奖励和未来转移都随之变化，必须包含两条项。使用原始结果表定义参数，有助于避免遗漏这种联动。固定策略导数也不等于最优值在动作切换点的普通导数，研究中应清楚区分对象。

<a id="mdp-3-detail-72"></a>

### 14.4 一份完整复核报告如何组织

先给任务与结果表，再给两轮手算，随后给收敛值、动作值、策略与残差，最后给独立线性求解、穷举、梯度和模拟核对。这样的顺序让读者先知道算什么，再知道怎么算对，而不是先读一大段代码猜任务。每个数字应能追溯到具体公式或实际输出，建议研究则明确标为未执行扩展。

本章保留五个独立可运行代码块，不生成任何中间文件。它们覆盖确定导航、随机规划、精确策略梯度、轨迹模拟与吸收长度。完成这些内容后，学习者可以把同一套核对方法迁移到更大任务，但需要重新检查模型、数据覆盖和计算预算。小模型结果的意义在于建立可靠参照，而不是用容易的满分替代复杂世界中的验证。

<a id="mdp-3-detail-73"></a>

### 14.5 重新编号是一项有力的不变量测试

如果只改变状态编号，同时重排转移的当前与后继轴、奖励行、初始分布和终止身份，价值应该对应重排，初始目标保持相同。动作编号也可在每个状态一致重新排列，并同步移动该状态的转移奖励列。这个测试可以发现某些硬编码索引或默认终点编号依赖，比再次从相同数组求解更独立。

但只交换价值向量而不重排模型，或者只交换状态属性而保留转移，已经不是同一个任务重命名。类似的区别在图学习中表现为置换等变，在有限 MDP 中同样重要。算法应依赖任务机制，不应依赖状态恰好排在数组第几行。若某种原地更新的中间轨迹随编号变化，那可以来自遍历顺序；最终固定点和对应策略价值仍应一致。

<a id="mdp-3-detail-74"></a>

### 14.6 梯度测试应该避开什么假象

一个参数坐标梯度为零，可能来自 softmax 冗余、不可达状态、动作平局或恰好正负贡献抵消，不一定是计算图断裂。应结合完整梯度、参数扰动、访问量和优势判断。反过来，所有参数梯度非零也不说明公式正确，错误损失同样可以产生流畅梯度。当前实验用解析公式和方向差分，正是为了避免只看非零这一弱证据。

有限差分步长还需要试探合理尺度。过大时高阶项影响明显，过小时两个近似相等目标相减放大舍入。双精度、小模型和温和参数有利于找到稳定区间。若未来加入硬最大、离散动作采样或非光滑约束，普通梯度核对方法需要相应调整，不能期待所有参数点都具有同一种导数。

<a id="mdp-3-detail-75"></a>

### 14.7 后续研究怎样保留可比性

可以逐项扩大状态数、加入观测噪声、限制合法动作，或者把转移概率改为从数据估计。每次只增加一个新的困难，并保留当前已知模型参照，能够知道误差来自哪里。若同时引入大网络、未知模型与复杂终止，最终失败时很难判断是信息、算法还是实现问题。逐层扩展是研究效率的来源，而不是保守地拒绝复杂任务。

每个扩展都应重新写任务契约和验收边界。加入部分可观测后，表格真实状态规划可以作为知情上界，但观测策略不应直接读取隐藏状态；加入奖励塑形后，原始奖励评估仍需保留；加入采样学习后，应记录交互预算和探索覆盖。第四章将集中讨论这些信息与奖励边界，避免把不同权限或不同目标下的分数直接比较。

最后可以让另一位读者只根据结果表独立重算一个动作值，再依据策略表求固定策略线性解。若他无需依赖作者口头说明就能得到一致结果，说明任务和数值协议表达足够清楚。若无法判断某个奖励是在成功前还是成功后给，或者某行概率是否包含终止，应该先完善正式文本。重算时应逐项对应状态、动作、转移概率与奖励时点，直到表格和方程得到一致结果。

完成本章后，建议保留一张自己的手算表，把当前状态、动作、所有结果、概率、奖励和未来价值逐列排列。这个工具在转向大模型时仍然有用：任何复杂训练流程最终都应与某个明确的转移目标对应。当结果异常时，先回到这张表检查信息和奖励，再检查优化器和网络。这样既能保持求知过程的深入，也能避免在错误模型上反复增加计算却不理解原因。

对任何声称更好的新方法，都可以追问它使用了什么额外信息、改变了什么目标、花费了多少计算，以及在哪些独立条件下被验证。精确小模型使这些问题有明确答案，也为后续未知环境和近似学习建立可信的比较尺度。
