# 马尔可夫决策过程

建立状态、动作、奖励和长期回报的统一描述，理解 Bellman 方程。

**先修知识：** 概率、条件期望；基础优化。

## 学习顺序与覆盖范围

先在第 1 章明确状态、时间和回报，再在第 2 章证明已知模型下的 Bellman 性质，第 3 章把规划算法做成完整数值闭环，第 4 章检验观察不足与奖励改写的边界。规划知道转移模型，不等于已从交互样本学到模型；无模型采样更新接[价值方法](../ValueBasedMethods/README.md)。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合研究：奖励与信息的联合验收](04-部分可观测与奖励建模边界.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
