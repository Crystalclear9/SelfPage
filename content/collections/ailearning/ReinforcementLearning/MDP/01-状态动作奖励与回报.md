## 1. 强化学习先定义交互，再谈优化

<a id="mdp-1-detail-2"></a>

### 1.1 一次动作对应一条转移记录

时刻 $`t`$，智能体获得当前信息，选择动作 $`A_t`$，环境产生下一状态 $`S_{t+1}`$ 和奖励 $`R_{t+1}`$。本章统一使用奖励下标比动作晚一位的记法，表示奖励属于从当前状态出发的这次转移。代码可以把它记作当前调用返回的`reward`，但推导必须始终一致。把进入终点的奖励再在终点停留时重复加一遍，会改变任务，而不只是换一种下标。

一条训练记录至少需要明确当前输入、实际执行动作、转移奖励、转移后的输入，以及为什么停止采样。若环境自动重置，调用返回的画面可能已经属于下一回合，而学习目标需要停止前的最后状态。若动作被环境裁剪或安全规则替换，记录中也应区分请求动作与实际动作，否则模型可能把某个结果归因于没有真正执行的行为。

强化学习的困难不只是标签稀少，而是动作会影响未来输入分布。当前选择可能改变后续可达状态、可用动作和观测机会。一个看似短期收益较低的动作，可能进入长期更好的区域；一个短期奖励很高的动作，也可能使系统陷入无法恢复的状态。定义长期目标之前，无法仅凭即时反馈判断行为优劣。

<a id="mdp-1-detail-3"></a>

### 1.2 一个完整任务的基本对象

有限马尔可夫决策过程可以由状态集合 $`\mathcal S`$、每状态可用动作集合 $`\mathcal A(s)`$、联合转移奖励分布 $`p(s',r\mid s,a)`$、初始分布 $`\mu`$ 与回报规则定义。折扣因子 $`\gamma`$、终止条件和时间范围也是目标的一部分。不同教材把奖励单列为期望函数，或者把终止状态吸收进转移矩阵，形式可变，但实际交互和目标应完全明确。

使用联合分布而不是仅写下一状态概率，有助于处理奖励与下一状态相关的情况。例如同一动作可能以小概率进入故障状态并产生很大损失。只给出平均奖励和平均位置，会掩盖风险分布。若只优化风险中性的期望折扣和，期望奖励常已足够用于 Bellman 递推；若研究方差、尾部风险或概率约束，就需要更多联合信息。

初始分布决定从哪里评价策略。一个策略在常见初始状态很好，可能在很少出现的状态很差；只报告从单一固定起点的收益，不等于对所有状态最优。后续价值函数为每个状态定义条件期望，而总体目标通常再按 $`\mu`$ 加权。把这两层区分开，可以避免把局部改进误说成无条件全局改进。

<a id="mdp-1-detail-4"></a>

### 1.3 策略不是环境的转移规律

策略 $`\pi(a\mid s)`$ 描述智能体如何选动作，环境 $`p(s',r\mid s,a)`$ 描述给定动作后发生什么。确定性策略每个状态选定一个动作，随机策略给动作分布。训练时加入探索会改变行为策略，评估时也可能使用另一策略。比较结果时必须说明实际执行的是哪一个，否则所谓训练收益和测试收益可能对应不同决策规则。

策略还可以依赖完整历史 $`H_t`$ 或时间，而不是只依赖当前状态。环境满足马尔可夫性，并不强迫智能体采用无记忆策略；只是对某些已知、充分状态的标准目标，存在结构更简单的最优策略。若观测不充分，历史依赖就可能必需。把环境假设与策略形式分开，是理解部分可观测与循环策略的基础。

## 2. 状态是对未来有用的充分信息

<a id="mdp-1-detail-6"></a>

### 2.1 马尔可夫条件到底在说什么

令 $`H_t=(O_0,A_0,R_1,\ldots,O_t)`$ 表示当前之前可见历史，状态表示为 $`S_t=f(H_t)`$。受控马尔可夫条件要求，对每个合法动作，在给定 $`S_t,A_t`$ 后，下一状态与奖励的条件分布不再依赖历史中的其他细节。即

$$
P(S_{t+1},R_{t+1}\mid H_t,A_t)=P(S_{t+1},R_{t+1}\mid S_t,A_t).
$$

这里强调每个可能执行的动作，而不只是某个固定行为策略下观察到的混合结果。一个表示在当前策略的数据里看起来足够，换策略后可能暴露遗漏变量。状态充分性是关于控制后的未来分布，而不是只要求能较好预测下一帧平均像素。

真实世界可以具有很长记忆，但把所需记忆包含在状态中后，过程仍可马尔可夫。例如小车的位置状态还需要补充速度，库存系统需要未到货订单，维护系统需要设备退化程度。状态不一定只包含可直接测量的物理量，也可以包括合法历史的统计量。关键在于它是否足以预测动作后果，而不是输入向量长得像不像一个状态。

<a id="sec-2-1"></a>

<a id="mdp-1-detail-7"></a>

### 2.2 同一观测对应不同未来的反例

一维小车当前位置都为零，但一种历史让它向右运动，另一种让它向左运动。若动作是保持当前推力，下一位置分布不同。只输入位置会把两种需要不同决策的情况混在一起。增加速度可以修复这个理想模型的状态缺失；若速度不可直接测量，连续两帧在确定步长和低噪声条件下可以帮助估计，但不保证对任意动力学与观测噪声都充分。

另一个例子是隐含订单。两个仓库当前库存相同，但一个明天有大批到货，另一个没有。若状态只含现货，补货策略就可能错误。订单队列、到货时间和取消概率可能都与未来有关。与其要求网络从不包含这些信息的输入中神奇恢复，不如先检查任务接口是否提供足够历史或合法状态。信息缺失与模型容量不足不能混为一谈。

<a id="mdp-1-detail-8"></a>

### 2.3 有限历史不自动变成充分状态

把最近四帧拼接常是有效工程近似，但没有普遍定理保证四帧足够。若隐藏变量在更早时间决定未来，而近期观测无法识别，任何固定窗口都可能遗漏。循环网络可以维护更长记忆，也不保证训练后恰好得到精确充分统计。应通过任务机制和可检验反例判断，而不是把增加帧数当作马尔可夫性的定义。

完整历史总可以作为一种形式上的信息状态，但它长度随时间增长，通常不便直接规划。部分可观测模型中的信念分布能把历史压成隐藏状态后验，是另一种有明确假设的充分表示。第四章会给出 Bayes 更新和充分性证明。本章只先建立问题边界：观察是传感器输出，状态是为决策定义的充分信息，二者可以相同，也可以不同。

<a id="mdp-1-detail-9"></a>

### 2.4 时间、预算与规则变化也属于状态

有限任务中只剩一步和还剩十步，即使物理位置相同，最佳动作可能不同。若截止时间是任务本身的一部分，剩余时间需要进入状态，或者价值函数显式带时间下标。剩余电量、风险预算和未完成约束同理。它们决定可行动作或未来目标，不能只在环境内部保留，却让智能体面对同一输入承受不同机制。

如果环境参数按已知日程变化，加入时间或阶段可以使扩展状态下的机制平稳。若变化来自未知外部漂移，仅加一个时钟未必足够。平稳指给定状态动作后的规律不随绝对时间另行变化，不表示状态分布一直相同。即使环境平稳，策略更新也会改变访问分布；这两种非平稳现象需要区分。

## 3. 从奖励序列构造回报

<a id="mdp-1-detail-11"></a>

### 3.1 折扣回报的定义与递推

从时刻 $`t`$ 出发的折扣回报为 $`G_t=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}`$，其中通常 $`0\le\gamma<1`$。若奖励绝对值有界于 $`R_{\max}`$，则回报绝对值有界于 $`\frac{R_{\max}}{(1-\gamma)}`$，因此求和绝对收敛。将第一项拆出，得到样本级恒等式 $`G_t=R_{t+1}+\gamma G_{t+1}`$。下一章 Bellman 方程是在这个恒等式上取条件期望。

递推只依赖索引和求和，并不要求奖励独立。强化学习中的奖励和状态通常高度相关，仍可逐项拆分。要把未来条件期望写成仅依赖下一状态的价值，才需要状态充分性和适当策略条件。把样本恒等式与条件期望递推分开，能看出每条假设究竟在哪一步使用。

<a id="sec-1-1"></a>

<a id="mdp-1-detail-12"></a>

### 3.2 三步奖励逐项手算

若未来三次奖励为一、二、四，折扣为二分之一，当前回报为 $`1+\tfrac12\times2+\tfrac14\times4=3`$。下一时刻回报为 $`2+\tfrac12\times4=4`$，再下一时刻为四。反向递推从尾部零开始，依次得到四、四、三，与正向加权求和一致。代码实现可以利用这个反向过程，避免为每个时间点重复求和。

若第二步发生真正终止，第三个奖励不属于当前任务轨迹，则当前回报变为 $`1+\tfrac12\times2=2`$。如果只是采集器在第二步停止，而任务实际上还会继续，则二只是已见部分回报，完整回报还包含尾项。停止原因决定数学对象，不能只因为数组长度为二就默认未来价值为零。

<a id="deep-dive-3"></a>

<a id="mdp-1-detail-13"></a>

### 3.3 折扣改变偏好，也改变估计难度

比较动作甲立即得四并结束，动作乙先付一单位成本、下一步得八并结束。甲回报为四，乙为 $`-1+8\gamma`$。当 $`\gamma>\frac{5}{8}`$ 时乙更好，低于该值时甲更好。这里没有估计误差或训练问题，策略变化完全由目标偏好变化造成。折扣不是只用于数值稳定的技巧，调大调小可能改变真正最优行为。

奖励越远，估计时通常涉及更长轨迹和更多随机性；高折扣使远期误差更重要，也使价值量级增加。可以用总折扣质量 $`\frac{1}{(1-\gamma)}`$ 理解一个尺度，但它不是严格的唯一有效时域。若关注遗漏尾部质量比例，保留前 $`H`$ 步后的比例是 $`\gamma^H`$，要低于 $`\varepsilon`$，应选择满足 $`\gamma^H\le\varepsilon`$ 的长度。不同误差标准会给出不同的“有效视野”。

<a id="mdp-1-detail-14"></a>

### 3.4 截断尾部的确定性误差界

用前 $`H`$ 步部分回报 $`G_t^{(H)}`$ 近似无限回报，在有界奖励条件下

$$
\vert G_t-G_t^{(H)}\vert \le\frac{\gamma^HR_{\max}}{1-\gamma}.
$$

这由尾部几何级数直接得到，是最坏情况界，不要求轨迹独立。若在尾部加估计值 $`\widehat v(S_{t+H})`$，误差还取决于该值相对真实条件期望的偏差。对于样本回报，尾部本身还有随机波动；不能把条件期望误差界误当作每条未来实际轨迹误差界。第二章会进一步区分价值误差和 Bellman 残差。

## 4. 奖励表达偏好但不等于全部目标

<a id="mdp-1-detail-16"></a>

### 4.1 即时奖励与长期价值不同

奖励是一条转移的反馈，价值是从某个条件开始未来回报的期望。一个状态当前没有奖励，仍可能有很高价值；一条动作即时奖励较高，仍可能导致后续损失。价值依赖策略、折扣与终止规则，同一个状态可以在不同策略下具有不同价值。说“这个状态值十分”时，应说明十分对应哪个目标和后续行为。

稀疏奖励只在少数时刻出现，可能让探索与信用分配困难；稠密奖励提供更多反馈，但若设计与最终目标不一致，模型可能优化代理指标。机器人为前进距离得分，可能通过原地摆动传感器获得虚假进度；服务系统为处理量得分，可能牺牲质量。奖励设计问题不是简单增加反馈频率，而是确定反馈累积后是否仍表达原始偏好。

<a id="mdp-1-detail-17"></a>

### 4.2 奖励平移在不同任务下效果不同

所有奖励乘正常数，风险中性的期望回报顺序保持不变；加常数则要看任务长度。固定无限折扣任务中，每步加 $`c`$ 会给每条轨迹增加相同 $`\frac{c}{(1-\gamma)}`$，在统一持续语义下不改变策略排序。变长终止任务若只在结束前加常数，增加量依赖回合长度，可能鼓励拖延或提前结束。不能把无限任务的平移不变性无条件搬到回合任务。

例如动作甲立即获得一并结束，动作乙先得零、再得一结束，未折扣时原本同分。每步加一后，甲得二，乙得三，策略偏好改变。若同时把终止后的吸收状态也持续给常数，又变成另一种任务，需要一致建模。第四章会讨论具有精确策略不变条件的势函数塑形，本章先用最小反例防止误用任意奖励改写。

<a id="mdp-1-detail-18"></a>

### 4.3 期望回报不刻画全部风险

动作甲总获得五，动作乙一半得零、一半得十，期望相同，但风险偏好者可能选择不同。标准期望折扣和把二者视为同分，不代表它们的分布相同。若目标含失败概率、尾部损失或资源约束，需要把这些要求纳入数学目标或约束，不能指望期望奖励自动处理。对安全重要任务尤其要明确评估哪些风险指标。

也不能先把每步奖励做非线性变换，再宣称等价于对总回报施加效用。一般 $`U(\sum_tR_t)`$ 不等于 $`\sum_tU(R_t)`$。二者对应不同跨期风险偏好与时间一致性问题。奖励压缩、裁剪或符号化可能有助数值学习，却会改变目标中的幅度信息，需要明确它是代理训练目标还是最终评价目标。

<a id="mdp-1-detail-19"></a>

## 5. 已知模型、未知模型与数据覆盖

<a id="mdp-1-detail-20"></a>

### 5.1 规划与学习的区分

若转移和奖励模型已知，可以通过计算比较策略，这称为规划。若模型未知，需要从交互或历史数据估计价值、策略或模型。学到模型后再规划是一类路线，直接估计价值或策略是另一类。二者都不是对真实世界的自动保证：模型可能失真，数据可能缺乏关键动作覆盖，策略还可能把系统带入训练中未出现的区域。

一个模拟器即使能生成无限轨迹，也只是在其自身规律下提供样本。若真实动力学、奖励或观测机制不同，模拟最优策略可能失效。评估应区分模型内规划正确性、有限样本学习效果和真实机制迁移。先在小型有限环境验证数学与代码，再研究模型误差，是比直接用复杂模拟器分数解释一切更可靠的顺序。

<a id="mdp-1-detail-21"></a>

### 5.2 历史行为不自动提供所有动作信息

如果某状态下历史策略从未执行动作乙，数据通常无法识别乙的后果。再大的网络也不能从没有相关信息的数据中无条件恢复它。需要额外探索、结构先验、可迁移模型或保守限制。离线强化学习特别重视这种支持覆盖问题，因为新策略可能选择数据外动作，产生不可检验的高价值估计。

即使动作被执行过，若决策者利用了数据中未记录的隐藏信息，观察到的状态动作结果关系也可能有混杂。把行为动作当作随机干预进行建模，需要充分状态和相应因果假设。标准 MDP 在正确状态条件下规定动作后环境规律，但从不完整历史日志估计该规律，还要检查日志是否满足这些条件。预测相关性与动作干预效果不能混为一谈。

<a id="mdp-1-detail-22"></a>

### 5.3 动作可用性与执行约束

每个状态的可用动作集合可能不同，例如库存不足不能发货，预算耗尽不能继续采购。策略必须只给合法动作分配概率，规划也应只在合法集合上取最大。若用固定宽度输出再掩码，需要保证掩码对应当前真正状态，而不是未来才知道的约束。空动作集合应按终止或其他明确定义处理，不能让最大值或 softmax 默默产生错误。

动作还可能具有持续时间。若一次维修占一小时、另一动作占一天，而折扣按决策次数统一应用，目标与按真实时间折扣不同。半马尔可夫建模可按持续时间使用相应折扣与累计奖励。时间粒度是任务定义的一部分，不应只为了代码方便任意改变，否则策略可能偏好人为切得更细的动作表示。

<a id="mdp-1-detail-23"></a>

## 6. 终止、截断与重置的严格区别

<a id="mdp-1-detail-24"></a>

### 6.1 真正终止是任务机制的一部分

任务到达成功、失败或定义好的期限后不再累计当前任务奖励，可以用终止状态表示。令终止后的价值为零，进入终止时仍应保留该次转移奖励。若进入成功状态奖励十，不能因为下一状态终止就把十删掉；屏蔽的是后续价值，不是当前奖励。吸收状态的自循环奖励通常设零，以保持回报语义一致。

有限时域任务的期限到达也是终止，而不是仅因代码用了时间计数就叫截断。相反，一个无限持续任务为了分批采样而每百步重置，是外部截断。两者表面上都在某一步停止，数学目标却不同。如何处理尾部取决于任务是否真正结束，而非变量名是否叫时间限制。

<a id="mdp-1-detail-25"></a>

### 6.2 外部截断保留任务的未来

对于继续任务，在外部采样停止时可以用最后状态的价值补尾。一步目标常写为 $`R_{t+1}+\gamma(1-D_{t+1})\widehat v(S_{t+1})`$，其中 $`D`$ 表示真正终止，不是终止与截断的并集。如果把外部截断误作终止，会系统性低估最后状态后面仍存在的收益。相关接口区分见[Gymnasium 官方说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)。

这里的补尾并非总能精确恢复完整目标，仍依赖价值估计质量和最终状态是否可用。若轨迹因故障中断且末状态缺失，不能凭空使用重置后的初始状态替代。若任务本身也在同一步终止，真正终止应阻止补尾。停止标签需要与状态记录一起保存，不能只保存一个合并的完成标志而丢失语义。

<a id="sec-6-1"></a>

<a id="mdp-1-detail-26"></a>

### 6.3 最后状态与重置状态不要串接

自动重置接口可能同时提供停止前最终观测与下一回合初始观测。前者用于当前转移的价值目标，后者用于新回合决策。把后者当作前者，会把两个独立回合错误连成一条轨迹。即使所有张量形状相同、损失能够下降，目标也已经改变，可能产生难以解释的乐观或悲观偏差。

一种可靠的数据契约是每条转移明确保存真正的转移后观测，以及终止与截断标志；重置后的观测作为下一条新轨迹的起点单独处理。若库有专门最终观测字段，应按接口核对，而不是猜测默认返回值。实验代码可以用人工常量模拟这个边界，无需安装环境库，也能检查核心目标计算是否正确。

<a id="mdp-1-detail-27"></a>

## 7. 四个独立 CPU 实验

<a id="mdp-1-detail-28"></a>

### 7.1 实验一：回报递推与几何尾界

先检查正向折扣求和和反向递推一致，再验证三步手算与奖励索引。随后使用有界交替奖励序列，比较有限部分和与长序列近似，检查几何尾界。代码只使用标准 Python 与 NumPy，所有奖励都在内存生成。它验证数学定义与实现一致，不训练任何策略。

```python
import numpy as np

def returns(rewards, gamma, tail=0.):
    g = float(tail)
    result = []
    for reward in reversed(rewards):
        g = float(reward)+gamma*g
        result.append(g)
    return np.array(result[::-1])

r = np.array([1., 2., 4.])
gamma = .5
result = returns(r, gamma)
assert np.allclose(result, [3., 4., 4.])
for t in range(len(r)):
    direct = sum(gamma**k * r[t+k] for k in range(len(r)-t))
    assert np.isclose(result[t], direct)
assert np.isclose(returns([1., 2.], .5)[0], 2.)
assert np.isclose(returns([1., 2.], .5, tail=4.)[0], 3.)
gamma, reward_bound = .9, 2.
sequence = reward_bound*(-1.)**np.arange(3000)
long_return = np.sum(gamma**np.arange(len(sequence))*sequence)
for horizon in [1, 5, 20, 100]:
    partial = np.sum(gamma**np.arange(horizon)*sequence[:horizon])
    bound = gamma**horizon*reward_bound/(1-gamma)
    assert abs(long_return-partial) <= bound+1e-12
assert -1+8*.9 > 4 and -1+8*.5 < 4
print('return recursion/manual/tail-bound/preference assertions passed')
```

尾部值四乘进递推后，还会经过相应的折扣次数，代码不能直接把四加到最初回报。对固定长度轨迹，可以用直接求和验证每个时间点；对更长轨迹，反向递推计算更高效。若折扣每步不同，需要将它作为转移属性逐步相乘，不能继续使用单一幂次而不修改定义。

<a id="mdp-1-detail-29"></a>

### 7.2 实验二：停止语义与最后观测

一个持续状态每步奖励二，折扣零点九，真实价值为二十。采样器只允许收集三步，这不改变任务仍有后续奖励的事实。使用最后状态真实价值补尾可恢复二十，误把截断当终止只得到前缀和。代码也模拟自动重置后初始状态价值不同的情况，展示错误串接会产生另一种偏差。

```python
import numpy as np

gamma = .9
true_last_value = 2/(1-gamma)
rewards = [2., 2., 2.]
prefix = sum(gamma**k*r for k, r in enumerate(rewards))
correct = prefix+gamma**len(rewards)*true_last_value
wrong_terminal = prefix
assert np.isclose(correct, 20.)
assert wrong_terminal < correct

def target(reward, next_value, terminated, truncated):
    # truncated records collection state but does not erase continuation.
    return reward+gamma*(not terminated)*next_value

assert np.isclose(target(2., 20., False, True), 20.)
assert np.isclose(target(10., 999., True, False), 10.)
assert np.isclose(target(10., 999., True, True), 10.)
reset_initial_value = -5.
incorrect_reset_target = target(2., reset_initial_value, False, True)
correct_last_target = target(2., true_last_value, False, True)
assert not np.isclose(incorrect_reset_target, correct_last_target)
# A truly three-step task does not have the same objective as the continuing task.
finite_task_return = prefix
assert np.isclose(finite_task_return, 5.42)
print('continuing/truncation/termination/reset targets:', correct, wrong_terminal,
      incorrect_reset_target, correct_last_target)
```

这个实验使用真实尾部价值，故可以精确补回期望目标。实际学习只能使用估计值，补尾仍有估计偏差。它的作用是避免把任务本来存在的未来强制设为零，不是保证消除所有学习误差。若停止由于真实任务成功或失败，尾部定义为零，则不应该继续补估计价值。

<a id="mdp-1-detail-30"></a>

### 7.3 实验三：观测别名与时间状态

在小车例子里，当前位置为零的两种隐藏状态具有相反速度，同一个动作后位置不同。仅位置观测不满足当前模型的充分条件，位置与速度共同构成的表示可以区分。随后构造有限时域选择：立即得四，或者先付一再获八。只剩一步与还剩两步时，合理动作不同，说明剩余时间是决策信息。

```python
from collections import defaultdict

hidden = [(0, -1), (0, 1)]
def step(state, force):
    position, velocity = state
    new_velocity = velocity+force
    return (position+new_velocity, new_velocity)

observations = [state[0] for state in hidden]
assert observations[0] == observations[1] == 0
next_positions = [step(state, 0)[0] for state in hidden]
assert next_positions == [-1, 1]
augmented = [(state[0], state[1]) for state in hidden]
assert augmented[0] != augmented[1]
# Identical observed position cannot determine a unique next-observation distribution.
groups = defaultdict(set)
for state in hidden:
    groups[state[0]].add(step(state, 0)[0])
assert len(groups[0]) == 2

immediate = 4.
def delayed_value(remaining_steps, gamma=.9):
    return -1.+(gamma*8. if remaining_steps >= 2 else 0.)
assert immediate > delayed_value(1)
assert delayed_value(2) > immediate
print('observation alias/velocity augmentation/remaining-time assertions passed')
```

相同观测后出现多个下一观测，本身不总能证明非马尔可夫，因为一个合法马尔可夫状态也可随机转移。这里关键在于两类可区分历史确定了相反速度，从而下一分布随历史变化。代码通过两个明确隐藏状态表达这一点，不能把“下一状态有随机性”误当作马尔可夫性失败。时间例子同样固定任务规则，变化的只是剩余期限。

<a id="mdp-1-detail-31"></a>

### 7.4 实验四：轨迹概率与期望回报

最后枚举有限小模型的所有四步轨迹，计算每条路径的策略概率、环境转移概率和折扣回报。概率总和应为一，按路径加权的期望与逐步状态分布计算一致。它帮助区分一条采样回报与策略期望，也展示策略和环境在轨迹似然中分别扮演什么角色。没有模拟噪声，所以断言不依赖偶然样本频率。

```python
import numpy as np

policy = np.array([[.7, .3], [.2, .8]])
p = np.array([[[.9, .1], [.4, .6]], [[.3, .7], [.8, .2]]])
r = np.array([[[1., -2.], [0., 3.]], [[2., 1.], [-1., 4.]]])
gamma, horizon = .8, 4
assert np.allclose(policy.sum(1), 1)
assert np.allclose(p.sum(2), 1)
paths = [(0, 1., 0.)]
for t in range(horizon):
    expanded = []
    for state, probability, total_return in paths:
        for action in range(2):
            for nxt in range(2):
                prob = probability*policy[state, action]*p[state, action, nxt]
                value = total_return+gamma**t*r[state, action, nxt]
                expanded.append((nxt, prob, value))
    paths = expanded
mass = sum(prob for _, prob, _ in paths)
expected = sum(prob*g for _, prob, g in paths)
assert np.isclose(mass, 1.)
state_mass = np.array([1., 0.])
forward_expected = 0.
for t in range(horizon):
    joint = state_mass[:, None, None]*policy[:, :, None]*p
    forward_expected += gamma**t*np.sum(joint*r)
    state_mass = joint.sum((0, 1))
assert np.isclose(state_mass.sum(), 1.)
assert np.isclose(expected, forward_expected)
assert len(paths) == 4**horizon
print('trajectory probability mass/expected return:', mass, expected)
```

若奖励本身也随机，枚举时还需包含奖励分支或使用条件期望。这个例子里的奖励由状态、动作和下一状态确定，但不是只由当前状态决定。只保留一列平均奖励可以用于期望计算，却不能恢复完整回报分布。研究风险或方差时，应重新保留足够联合信息。

## 8. 十六道进阶练习与详细解答

<a id="mdp-1-detail-33"></a>

### 8.1 奖励下标为什么不能混用

题目：动作 $`A_t`$ 得到奖励 $`R_{t+1}`$，若代码变量叫`r_t`是否错误？解答：名字本身不错误，关键是整套推导和记录一致。若一处把它当动作前奖励，另一处当动作后奖励，就会把未来反馈分配到错误动作。可以为每条转移写清状态、动作、奖励、下一状态，再从这张记录重建回报。索引审计比只看数组长度更能发现一位偏移。

<a id="mdp-1-detail-34"></a>

### 8.2 马尔可夫性是否要求确定转移

题目：给定状态动作，下一状态有多个可能值，是否违反马尔可夫性？解答：不违反。马尔可夫性要求条件分布不再依赖更早历史，不要求分布退化为单点。掷骰子就是简单随机机制。真正反例需要找到相同当前表示和动作、不同合法历史下下一分布不同。将随机性误当作状态缺失，会导致无意义地增加记忆输入。

<a id="mdp-1-detail-35"></a>

### 8.3 为什么检查当前策略还不够

题目：某表示能预测当前行为策略下的下一观测，是否足够用于任意策略规划？解答：未必。当前策略可能从未执行某些动作，遗漏状态变量的影响被行为选择掩盖。控制充分性应对每个合法动作考虑后果，而非只对动作混合后的观测分布成立。改变策略可能进入新区域，暴露原先看不到的历史依赖，这也是数据覆盖和状态建模联系紧密的原因。

<a id="mdp-1-detail-36"></a>

### 8.4 同位置为什么可能需要不同动作

题目：两小车位置相同但速度相反，只看位置能否制定精确制动策略？解答：一般不能。相同位置输入对应不同未来惯性，最优制动力方向可能相反。增加速度或维护对速度的信念可改善充分性。增加网络宽度不能从完全相同的可见信息中确定隐藏的相反情况，除非历史或其他合法特征提供了区分依据。

<a id="mdp-1-detail-37"></a>

### 8.5 剩余时间何时必须进入状态

题目：任务要求十步内完成，两个物理状态相同但剩余时间不同，是否可以共用同一个无时间价值？解答：通常不行。可达奖励和可用计划长度不同，价值应带时间索引或把剩余时间加入状态。若时间限制只是外部采样而任务持续，剩余采样步数并非原目标状态。要先区分任务期限与采样期限，再决定输入与终止语义。

<a id="mdp-1-detail-38"></a>

### 8.6 折扣改变最优动作的阈值

题目：立即得四，与先付一下一步得八比较，阈值是多少？解答：延迟动作回报为 $`-1+8\gamma`$，超过四需要 $`\gamma>\frac{5}{8}`$，相等时两者同分。这个阈值在没有任何学习误差时已经存在，说明折扣是目标偏好而不只是训练稳定参数。选择折扣应考虑时间单位、远期价值和估计预算，而非只沿用默认值。

<a id="mdp-1-detail-39"></a>

### 8.7 回报上界需要什么条件

题目：$`\gamma<1`$ 是否保证任何奖励序列都有有限回报？解答：不保证任意增长序列；有界奖励或其他可积条件才支持常见几何界。若奖励增长比折扣衰减更快，和式仍可能发散。标准有限 MDP 中有限奖励通常满足有界假设，但连续或特殊模型需要单独检查。证明中出现的有界条件不能在转述时省略。

<a id="mdp-1-detail-40"></a>

### 8.8 真终止时屏蔽哪一项

题目：到终点奖励十，下一状态价值估计错误地为一百，目标应是什么？解答：真正终止后不再继续当前任务，目标为十。屏蔽未来价值项，不删除进入终点的奖励，也不把奖励再复制到吸收自循环。若终点后还有维护成本，那就不应定义为当前任务完全终止，或者应把相关成本在进入奖励中合法汇总。终止定义必须与目标一致。

<a id="mdp-1-detail-41"></a>

### 8.9 外部截断为何不能当终止

题目：持续状态每步得二，折扣零点九，收集三步后停止，完整价值是否为五点四二？解答：五点四二只是三步前缀，完整价值为二十。若用真实末状态价值补尾，前缀加 $`0.9^3\times20`$ 恢复二十。实际估计尾部会有误差，但把它强行设零会引入另一种系统性目标偏差。采样停止与任务结束是不同事件。

<a id="mdp-1-detail-42"></a>

### 8.10 自动重置后哪张观测用于补尾

题目：截断后环境返回新回合初始画面，能否用其价值作为当前下一状态价值？解答：不能，除非任务本来就定义跨重置继续，并明确包含该转移。通常当前轨迹应使用停止前最终观测，新初始画面属于另一条轨迹。把二者串接会改变转移模型。应查接口的最终观测字段或自定义保存真实末状态，而不是只凭返回张量形状判断。

<a id="mdp-1-detail-43"></a>

### 8.11 奖励加常数为什么可能改策略

题目：两个未折扣回合原本总奖励相同，但长度分别一与二，每步加一会怎样？解答：长回合多加一次常数，原先同分会变成长回合更优。固定无限持续折扣模型中增加的是统一常数，情况不同。任何平移不变结论都要写清终止后是否继续累计，以及任务长度是否受策略影响。任意奖励改写不能只凭直觉宣称保持目标。

<a id="mdp-1-detail-44"></a>

### 8.12 相同均值为什么不是相同风险

题目：固定得五与一半得零一半得十，标准期望目标如何比较？解答：二者同分，但分布和风险不同。如果业务关心亏损概率、尾部损失或最坏结果，需要另加风险目标或约束。不能把风险偏好暗中塞进解释，却仍用风险中性算法和指标。价值期望是一个摘要，不是完整回报分布。

<a id="mdp-1-detail-45"></a>

### 8.13 模型已知是否还需要探索

题目：有限环境转移奖励全部精确已知，求最优策略是否必须真实试遍动作？解答：数学规划不需要再为识别模型而探索，可以直接计算。但若模型只是假设、部分未知或需验证现实准确性，数据仍有价值。模型内正确性与现实有效性应区分。已知模型并不意味着计算总容易，大状态空间仍可能需要近似规划与结构利用。

<a id="mdp-1-detail-46"></a>

### 8.14 没执行过的动作能否直接估值

题目：日志在某状态从未执行动作乙，能否凭同状态动作甲的数据可靠判断乙？解答：一般不能无条件识别，需要结构先验、其他状态迁移信息或额外交互。函数近似可以给出一个数，但数值存在不等于证据充分。若新策略依靠这些数据外高估值，可能严重失败。评价覆盖应针对状态动作对和目标策略访问区域，而不只统计日志总量。

<a id="mdp-1-detail-47"></a>

### 8.15 动作时长为什么改变折扣解释

题目：一步代表一分钟还是一小时，采用同一个折扣是否对应相同时间偏好？解答：不对应。若每小时折扣为 $`\gamma`$，持续半小时的动作可使用 $`\gamma^{\frac{1}{2}}`$ 的时间折扣，并相应定义期间累计奖励。按决策次数折扣会偏向或惩罚人为切分次数不同的行为。时间单位应作为任务说明的一部分，不能只为方便接口随意改变。

<a id="sec-7-1"></a>

<a id="mdp-1-detail-48"></a>

### 8.16 如何验收一份强化学习任务定义

题目：开始训练前，至少应能回答什么？解答：预测或控制对象是什么，状态包含哪些合法历史，动作如何执行，奖励属于哪次转移，目标时域和折扣是什么，哪些停止是真终止，截断如何保存最后状态，以及从什么初始分布评价。再用小轨迹手算回报和反例验证。若这些答案不清楚，训练得分即使提高，也可能在优化一个与原需求不同的任务。

<a id="mdp-1-detail-49"></a>

## 9. 状态压缩与受控充分性的进阶推导

<a id="mdp-1-detail-50"></a>

### 9.1 状态聚合何时仍然是 MDP

假设真实有限状态为 $`x`$，用映射 $`f(x)=s`$ 把多个真实状态合成一个表示。若任意两状态 $`x_1,x_2`$ 映到相同 $`s`$，块内可用动作集合一致，且对每个合法动作、每个下一聚合块和奖励取值，转移到该块并获得该奖励的联合概率均相同，那么可以为聚合状态定义不依赖块内具体成员的联合转移奖励模型。

分别保持奖励边缘分布和下一聚合块边缘分布，只能保证这些边缘一致，不能代替联合核条件；仅做风险中性期望控制时，保持奖励期望与聚合转移则已足以重建相应期望 Bellman 算子。这是一类受控可聚合条件，给出压缩后仍可精确规划的充分依据。

只要求两个状态的单步期望奖励相同还不够。例如它们当前都奖励零，但一个下一步进入高奖励块，另一个进入低奖励块，未来价值仍不同。只要求当前固定策略下聚合转移相同也不够，因为不同动作的差异可能被策略混合掩盖。精确控制抽象需要保留与所有可选择动作相关的未来信息，而不是只重构当前数据平均行为。

在这个条件下，任意只依赖聚合状态的策略都可以在真实系统执行，聚合轨迹分布与抽象模型一致。证明可以按时间归纳：初始聚合分布一致；给定当前聚合状态，策略动作分布一致；可聚合条件保证下一聚合状态与奖励分布一致；因此整个未来回报分布一致。若仅保留期望奖励而不保留奖励分布，通常只能相应保证期望目标，不应声称完整分布都保留。

一个具体反例是，块内状态甲等概率产生“奖励零、下一块 A”和“奖励一、下一块 B”，状态乙等概率产生“奖励一、下一块 A”和“奖励零、下一块 B”。奖励边缘与下一块边缘完全相同，联合分布却不同。若下一步在 A、B 分别确定得零和一并结束，折扣零点九，两状态回报均值都为零点九五，方差分别为零点九零二五与零点零零二五。因此只核对两个边缘，不能支持前文关于完整聚合轨迹和回报分布一致的归纳。

```python
import numpy as np
prob=np.array([.5,.5])
reward0=np.array([0.,1.]);reward1=np.array([1.,0.])
next_value=np.array([0.,1.]);gamma=.9
return0=reward0+gamma*next_value
return1=reward1+gamma*next_value
means=np.array([prob@return0,prob@return1])
variances=np.array([prob@((return0-means[0])**2),
                    prob@((return1-means[1])**2)])
assert np.isclose(prob@reward0,prob@reward1)
assert np.allclose(means,[.95,.95])
assert np.allclose(variances,[.9025,.0025])
print('equal reward/next-block marginals; equal means',means)
print('different return variances',variances)
```

<a id="mdp-1-detail-51"></a>

### 9.2 近似状态并非只有对错两种

真实任务常只能构建近似充分状态。可以研究同一聚合块内，不同历史对下一聚合状态分布和奖励期望的差异，再估计这种差异如何累积到价值。误差是否严重取决于折扣、访问频率和动作选择。一个很少访问区域的大模型误差，可能对当前初始分布影响不大；一个常见决策点的小差异，则可能改变长期最优行为。

因此状态诊断不能只用总体预测均方误差。可以按动作、历史类型和价值相关区域比较预测残差，寻找同输入不同历史下的系统差异。如果加入某段合法历史显著改善动作后果预测，说明原表示可能遗漏信息。这个证据仍受数据覆盖限制：未执行动作的充分性无法仅靠现有日志完全检验。统计检验未发现差异，也不等于证明严格马尔可夫。

<a id="mdp-1-detail-52"></a>

### 9.3 平稳环境与变化的访问分布

一个固定环境在给定状态动作后的规律不随绝对时间变化，可称机制平稳。智能体从保守策略切换到探索策略后，状态分布会变化，但环境仍可平稳。相反，同样温度和动作在设备老化后产生不同故障概率，如果老化未包含状态，模型看到的规律会随时间变化。加入合法退化状态可能恢复平稳；若退化不可观测，则需要记忆或信念。

这一区分直接影响数据复用。访问分布变化可能需要重要性权重或新的覆盖，但不必意味着旧转移本身无效。机制变化则可能让旧数据对应过时动力学，需要时效权重、变化检测或重新建模。简单地把训练损失波动都称为非平稳，无法指出应该修复采样、策略还是环境模型。

<a id="mdp-1-detail-53"></a>

### 9.4 延迟奖励怎样纳入状态

某个动作的经济收益可能几天后才结算。若环境在结算时给奖励，历史动作会通过未结订单影响未来反馈；为了马尔可夫建模，状态可能需要包含待结算事项。若只保留当前余额，相同余额但不同待结订单的未来奖励分布不同。奖励延迟不仅影响信用分配，也可能暴露状态缺失。

不能随意把未来结算奖励提前移到动作时刻而保持其他内容不变。在折扣目标中，提前会改变该奖励的折扣权重；若结算金额还不确定，提前使用真实结算结果又会泄漏未来。可以在模型中使用条件期望或适当折扣补偿，但必须推导等价条件。时间位置本身属于目标定义，而不是可随意调整的日志格式。

<a id="mdp-1-detail-54"></a>

## 10. 轨迹分布、访问测度与总体目标

<a id="mdp-1-detail-55"></a>

### 10.1 策略如何进入路径概率

在固定初始分布和马尔可夫策略下，一条长度 $`H`$ 的状态动作奖励轨迹概率分解为

$$
P_\pi(\tau)=\mu(s_0)\prod_{t=0}^{H-1}\pi(a_t\mid s_t)\,p(s_{t+1},r_{t+1}\mid s_t,a_t).
$$

连续变量时应把概率换成相应密度或概率核解释。这个分解展示策略只直接控制动作项，但通过动作选择间接改变后续状态分布。环境项不是策略参数的显式函数，并不意味着状态分布也与策略无关。后续策略梯度正是从轨迹分布变化出发，但本章先把联合分布结构讲清楚。

若策略依赖历史，动作项应改成 $`\pi(a_t\mid h_t)`$，环境在充分真实状态下仍可使用相同转移核。若观测不充分，直接用 $`p(o_{t+1},r\mid o_t,a_t)`$ 取代真实机制，通常没有同样分解依据。公式里的条件对象必须与状态定义一致，不能因为网络只接受观测就默认观测过程已经马尔可夫。

<a id="mdp-1-detail-56"></a>

### 10.2 折扣访问分布的归一化

给定策略和初始分布，定义状态折扣访问分布

$$
d_\pi(s)=(1-\gamma)\sum_{t=0}^{\infty}\gamma^tP_\pi(S_t=s).
$$

在持续统一状态空间下，对所有状态求和得到一，因此它是概率分布。总体期望回报可以写成

$$
J(\pi)=\frac1{1-\gamma}\sum_s d_\pi(s)\sum_a\pi(a\mid s)\,\overline r(s,a).
$$

推导只是交换有界可积求和并按时刻收集状态动作概率。它解释长期目标也可以看成某种访问加权的即时奖励，但权重 $`d_\pi`$ 本身依赖策略，不能把它当固定监督数据分布优化。若任务终止后不再计步，可以加入零奖励吸收状态统一表示，否则非终止状态上的质量和可能小于一。

初始分布变化也会改变访问权重。一个策略在训练常见起点很好，可能无法处理部署中的异常起点。可以分别报告固定起点、随机起点和压力状态表现，避免把单一 $`J(\pi)`$ 的改进误读为逐状态价值都提高。下一章的策略改进定理会给出更强条件，但本章先明确总体目标本身如何加权。

<a id="mdp-1-detail-57"></a>

### 10.3 数据分布与目标分布的支持

如果日志来自行为策略 $`b`$，而目标策略为 $`\pi`$，直接平均日志回报一般估计的是行为目标。重要性比率可以在适当支持和可积条件下修正轨迹分布，但长轨迹概率乘积可能导致很大方差。若目标动作在行为数据中概率为零，普通比率无法补回未观察后果。这和监督学习中的分布偏移类似，却因动作会改变未来状态而更复杂。

本章不展开离策略估计器，而是强调数据来源必须记录。即使一个回报函数计算完全正确，把不同策略、不同初始分布的轨迹混在一起平均，仍可能回答错误问题。应保存行为策略身份、探索配置、环境版本和重置规则；这些条件决定一个平均回报所对应的策略、任务与初始状态分布。

<a id="mdp-1-detail-58"></a>

## 11. 时域与随机终止的进一步解释

<a id="mdp-1-detail-59"></a>

### 11.1 折扣等价的随机生存视角

设每次转移后以独立概率 $`1-\gamma`$ 停止，在停止前不折扣累计奖励。只要这份外部生存随机性与原环境奖励机制独立，第 $`t+1`$ 个奖励被纳入的概率为 $`\gamma^t`$，因此期望总奖励等于原折扣回报。这个构造帮助理解折扣为何使远期贡献衰减，但它是目标等价的数学表示，不意味着真实环境必须真的随机结束。

若停止概率依赖状态或动作，对应的折扣也会依赖转移，目标不再是统一常数折扣。若把采样器的确定时间限制当成这种随机终止，却不修改任务说明，仍可能错误改变目标。等价构造要求的独立性和停止时点必须写清，不能把任何回合停止都解释成折扣的实现。

<a id="mdp-1-detail-60"></a>

### 11.2 无折扣回合需要哪些可积条件

有限固定时域且奖励有界时，取 $`\gamma=1`$ 没有无限和问题。随机终止时则需关注终止时间 $`T`$。若 $`\vert R_t\vert \le R_{\max}`$ 且 $`E[T]<\infty`$，则绝对回报期望至多为 $`R_{\max}E[T]`$，是一个常用充分条件。仅知道最终以概率一终止，不一定保证期望长度有限，因此也不自动保证期望回报有限。

例如某些重尾停止时间几乎必然有限，但具有无限期望。若每步奖励恒为一，期望总奖励就发散。规划和学习定理中常见的适当策略、瞬时状态或有限期望到达时间条件，正是在避免这类边界。不能因为实践中采集器总会超时停止，就认为原无折扣持续目标已经定义良好。

<a id="mdp-1-detail-61"></a>

### 11.3 平均奖励是另一种目标

对于持续任务，也可考虑长期单位时间平均奖励，而不是折扣总和。它更直接对应稳定产出率，但需要相应遍历、可达性或长期平均存在条件，算法和价值差分定义也有所不同。把 $`\gamma`$ 设得非常接近一，有时可以近似某些长期偏好，却不构成对所有环境的无条件等价。瞬态奖励和初始分布的影响也可能不同。

选择哪种目标应由用途决定。短期活动预算、有限任务成功与持续服务吞吐对应不同数学问题。不能只因为某个算法实现了折扣就倒推需求一定是折扣。学习者应先能够用语言解释目标，再写公式，再选择合适算法。这样的顺序能避免在训练末尾才发现评价指标与优化回报并不一致。

<a id="mdp-1-detail-62"></a>

## 12. 将任务契约变成可复核结果

<a id="mdp-1-detail-63"></a>

### 12.1 一个最小环境说明应该完整到什么程度

可以用连贯文字列出实体与状态、动作执行规则、转移与奖励时点、初始分布、目标时域、终止与采样截断，以及评估策略。对随机机制还应说明随机源与可复核种子，对观测与真实状态不同的情况则明确隐藏变量。无需一开始就编写复杂环境框架，但应能从说明独立重建几条典型轨迹。

然后选三类边界轨迹手算：即时奖励看似更优但长期更差，真实终止阻止尾部，外部截断仍保留未来。再选一个状态别名反例，验证当前输入是否遗漏与动作后果相关的历史。完成这些检查后再训练，可以显著减少在错误目标上浪费计算的可能。复杂网络不会自动修复任务说明中的歧义。

<a id="mdp-1-detail-64"></a>

### 12.2 研究记录中的结果与限制

本章四个实验全部只使用人工常量和内存数组，验证回报、停止语义、状态反例与轨迹概率，没有安装环境库，没有下载数据，也没有生成模型或缓存文件。它们证明对应数学计算可运行，不证明任何真实任务策略已经学好。最终结果文件应保留这些明确边界，避免让读者把教学性质检查当成应用验证。

继续下一章时，将样本回报递推取条件期望，就得到价值函数与 Bellman 方程。此前必须掌握当前状态、当前动作、转移奖励和停止规则，因为任何一处含糊都会进入方程。价值迭代再精确，也只能解它收到的那个 MDP；若状态不充分、奖励错位或截断当终止，数值收敛到一个稳定值仍可能只是稳定地解错问题。

<a id="mdp-1-detail-65"></a>

### 12.3 奖励期望相同但联合模型不同

考虑当前动作以相同概率转向好状态和坏状态。一种奖励机制在好状态给十、坏状态给零；另一种在好状态给零、坏状态给十。它们当前期望奖励都是五，下一状态分布也相同，但奖励与未来价值的相关性不同。对于风险中性的期望总和，单步奖励期望加未来价值期望相同，所以这个差别可能不影响当前期望价值；对于总回报方差与尾部概率，它却很重要。

因为 $`\operatorname{Var}(R+\gamma G')`$ 包含协方差 $`2\gamma\operatorname{Cov}(R,G')`$，只保存奖励边缘均值无法恢复它。由此可见，模型对某个目标充分，不表示对所有目标都充分。若研究分布价值或风险控制，需要保留奖励与下一状态的联合结构。模型简化应以目标为依据，不能把期望控制常用的压缩推广成完整随机过程等价。

<a id="mdp-1-detail-66"></a>

### 12.4 约束不能总靠单一奖励权重解决

若要求失败概率低于某个阈值，可以把失败加入负奖励作为一种拉格朗日思路，但固定惩罚系数未必精确实现原约束，也可能在某些初始状态或子群体违反限制。期望奖励中的一次大惩罚与多次小风险之间如何交换，取决于概率和时域。需要硬约束、概率约束或多目标时，应明确数学要求，再研究惩罚近似是否足够。

例如两策略收益分别为十与九，失败概率分别为百分之二与零。若失败上限为百分之一，前者不可行；一个惩罚系数较小的期望奖励目标仍可能选择它。调大惩罚可能改变选择，但不能仅凭最终平均回报高就宣布满足约束。评估应分别报告收益和约束指标，必要时给出统计不确定性，不能让一项综合分数掩盖关键限制。

<a id="mdp-1-detail-67"></a>

### 12.5 任务变化与实现错误怎样区分

当更改折扣、奖励裁剪、终止规则或动作时间粒度后，策略表现变化可能完全合理，因为任务本身已经改变。与之不同，方向索引错误、自动重置串接和漏记终点奖励属于实现没有忠实表达既定任务。前者需要重新解释目标，后者需要修复并重新验证。将两者都称为超参数调优，会模糊研究结论究竟来自偏好改变还是算法改善。

可以维护一组不依赖训练的小型验收轨迹，任何实现修改后都重算其已知回报；同时维护一份任务版本说明，只在目标或机制改变时更新。验收记录应包含输入轨迹、折扣与终止约定，以及可以重算的期望值。这样后续换网络、换采样器或换框架时，仍能知道优化对象是否保持一致，而不是仅比较一个可能已经换含义的分数。

<a id="mdp-1-detail-68"></a>

### 12.6 从一条轨迹到一组证据

单次高回报可能来自有利随机结果，不足以证明策略好。应在固定目标和可比初始分布下运行独立评估轨迹，报告均值、波动与关键失败类型。若反复根据同一评估种子选策略，这些种子已成为开发集，需要另设最终评估。环境随机性与训练随机性可以分别重复，以便判断差异主要来自策略参数还是一次执行运气。

若轨迹共享同一外部场景或任务实例，独立单位可能是场景而非每一步。把所有时间步当独立样本会低估波动；把同一场景下多次执行当成不同环境来源，也可能夸大泛化证据。下一步学习算法时应继续保留这一区分：回报是轨迹级随机量，价值是条件期望，算法更新可能按转移采样，而最终评价单位未必与更新单位相同。

特别是带有外部随机场景的模拟任务，可以把相同场景分别交给两个策略，形成配对比较，减少场景难度波动。但若策略会改变后续随机事件的使用顺序，简单共享随机种子未必意味着经历相同外部扰动，需要明确随机数在环境中的作用位置。配对实验应对应可解释的共同外部变量，而不只是把两个整数设成相同。

当读者完成本章，可以尝试不用任何环境库，独立写出一个两状态任务的全部转移、奖励和停止条件，再枚举短轨迹验证概率质量与期望回报。随后故意改动一个状态字段或终止规则，解释哪条结论发生变化。能够主动构造并修复反例，才说明理解了定义的约束，而不仅是记住了回报公式。带着这种检查方式进入规划、价值学习和策略优化，后续复杂推导就会始终有明确的计算对象。

最后还要检查每个奖励单位是否一致。把分钟成本与小时收益直接相加，或者在模拟与评估中使用不同金额单位，都会改变实际权重。单位错误可能被网络数值缩放暂时掩盖，但策略偏好已经变化。清楚记录时间、资源和奖励尺度，可以让长期目标真正对应最初想优化的事情，也使后续价值量级和误差容差具有可解释含义。
