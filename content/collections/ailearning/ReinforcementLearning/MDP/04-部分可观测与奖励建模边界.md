## 1. 观察相同，不代表决策问题相同

马尔可夫状态是足以预测未来条件分布的信息，不一定等于传感器当前返回的一张图片或一个数值。两个真实状态可以产生完全相同观察，却需要不同动作；同一个观察也可能在不同历史之后具有不同含义。若把当前观察直接当状态，得到的转移和奖励关系可能依赖被忽略的历史，普通状态价值公式就失去原先前提。

本章从观察别名出发，建立部分可观测模型、信念更新与有限规划，再研究时间边界和奖励塑形。重点不是给所有困难加一个循环网络，而是先问隐藏了什么、历史提供什么信息、奖励是否也透露状态，以及任务真正希望优化什么。只有这些对象清楚，才能判断算法或奖励修改是否合理。

<a id="sec-1-1"></a>

<a id="pomdp-4-detail-2"></a>

### 1.1 一个无记忆策略无法解决的反例

隐藏状态是均匀的零或一。开始时系统显示一次准确提示，下一时刻观察统一变成空白，随后智能体必须猜状态。记住提示的策略可以全对，只根据最后空白选择动作的无记忆策略最多正确一半。随机化不能补回丢失信息：无论以什么概率猜一，均匀隐藏状态下平均正确率都是二分之一。

这个差距不是优化器差，也不是奖励太稀疏，而是策略输入受限。增加训练轮数不能让同一个空白观察同时代表两种不同答案。可以扩大历史窗口、维护信念或使用带记忆的控制器，但每种方案都要说明它能保存哪些信息。短历史窗口只有在覆盖所需依赖时才足够，并不是一般部分可观测问题的万能状态。

<a id="deep-dive-1"></a>

<a id="pomdp-4-detail-3"></a>

### 1.2 状态、观察和历史分别是什么

记隐藏状态为 $`S_t`$，动作 $`A_t`$，观察 $`O_t`$，实际观察到的奖励为 $`R_t`$。历史包含当前之前允许的观察、动作与奖励，以及任务已知时间或可用性信息。隐藏状态是环境模型的一部分，策略不能在部署时直接读取它；训练模拟器可以用于评价或某些特权训练方法，但必须明确其信息边界。

历史也不自动等于完整世界。模型可能仍然存在无法识别的隐藏因素，或者传感器噪声让任何策略都无法确定真值。部分可观测推断的目标是维护与当前证据一致的概率，而不是承诺最终一定知道状态。信念接近一是模型条件下的结论，若转移或观测模型错设，实际校准仍可能有问题。

### 图解：部分可观测：同一观察的行动歧义与信息成本

![部分可观测：同一观察的行动歧义与信息成本](images/04-concept.svg)

**读图。** 普通观察在隐藏状态 A、B 下完全相同，先验各半；A 下选左奖励一，B 下选右奖励一，错误动作奖励零。因此不采集新信息时，无论固定选左、固定选右或独立随机化，期望奖励都是 0.5。

现在增加一个对两种状态都具有 0.8 正确率的信号。图中每个圆点是 0.05 的模型概率质量，不是要求实际二十次试验恰好出现这些计数。A 行十份中八份报告 A、两份报告 B；B 行正好相反。按报告 A 选左、报告 B 选右，二十份概率质量中十六份得到奖励一，期望奖励升至 0.8。信号没有直接改变隐藏状态或奖励规则，只让不同观察分支可以采取不同动作。

若采集信号需付成本 $`c`$，且此单步参照不另计时间折扣，净收益为 $`0.8-c`$；与不采集的 0.5 在 $`c=0.3`$ 相交。低于该成本值得采集，高于则不值得，相等时两方案并列。右下图沿用同一模型，纵坐标是净收益，不是信号准确率。后文两步监听任务另有 0.7 准确率与 0.99 折扣，不能直接套用这里的 0.3 边界。信息动作的作用可对照 [Kaelbling、Littman 与 Cassandra 的 POMDP 教程](https://people.csail.mit.edu/lpk/papers/aij98-pomdp.pdf)；本图的有限概率质量由这里的对称信号模型直接构造。

监听前后的信念平均仍应等于原先信念，可以作为过滤器的独立验算。取先验 $`b=0.65`$、传感器正确率 $`0.7`$，两报告概率为 $`0.56,0.44`$，后验为 $`0.8125,\frac{0.195}{0.44}`$。它们的报告概率加权平均为 $`0.56\times0.8125+0.44\times\frac{0.195}{0.44}=0.65`$。信息使后验分散到不同方向，并不会在取报告期望后凭空提高真实状态为一的概率；价值提升来自报告之后可以选择不同动作。若平均信念被系统性推高，应先检查 Bayes 分母或观察模型。

<a id="pomdp-4-detail-4"></a>

## 2. 用联合模型定义一次交互

<a id="pomdp-4-detail-5"></a>

### 2.1 联合转移、观察和奖励

为了避免漏掉奖励信息，定义核 $`K(s',o,r\mid s,a)`$，表示从当前状态和动作产生下一状态、新观察以及可见奖励的联合分布。它可以分解为转移核与条件观察奖励核，但不应预先假设奖励和观察在给定下一状态后独立。若任务使用连续奖励，将有限求和换成适当积分即可，仍需明确密度与支持。

常见简化写为 $`T(s'\mid s,a)Z(o\mid s',a)`$，并给定期望奖励 $`\bar r(s,a)`$。这种写法只有在已说明奖励不额外提供状态信息，或奖励已经并入新观察时，才能直接用于下文的信念更新。如果奖励本身能揭示隐藏状态，却只用普通观察更新，维护的就不是基于全部可见历史的真实后验。

<a id="pomdp-4-detail-6"></a>

### 2.2 初始分布与终止也属于模型

初始先验、首次观察的生成、终止事件和终止是否可见，都影响决策。开始就收到准确状态提示，与完全不知道状态是不同问题；终止发生在某种隐藏状态时，它也可能提供信息。有限任务可以把吸收终止状态加入状态集合，之后不再有动作和奖励，也可以在递推中单独表示结束，关键是前后一致。

模型中的动作应对应智能体实际能选择的操作。如果某个状态下动作非法而观察又无法确定状态，策略需要根据可见信息处理风险，不能让环境悄悄替它选择合法动作。合法动作集若依赖可见历史，应明确记录；若依赖隐藏状态且只有失败反馈可知，也应把反馈纳入观测模型。

<a id="pomdp-4-detail-7"></a>

## 3. 信念更新与充分统计量

<a id="pomdp-4-detail-8"></a>

### 3.1 从预测到校正

定义信念 $`b_t(s)=P(S_t=s\mid h_t)`$。动作执行后，联合观察奖励记为 $`e=(o,r)`$，则

$$
b_{t+1}(s')=\frac{\sum_s b_t(s)K(s',o,r\mid s,a)}{\sum_{u,s}b_t(s)K(u,o,r\mid s,a)}.
$$

分子是下一状态与本次证据的联合预测，分母是证据概率。若采用无额外奖励信息的简化模型，先计算 $`\hat b(s')=\sum_sT(s'\mid s,a)b(s)`$，再乘观测似然并归一化。先观测后转移或使用错误时间索引，会得到另一个模型，不能只因结果仍和为一就认定正确。

<a id="pomdp-4-detail-9"></a>

### 3.2 零概率证据的含义

如果分母为零，当前模型认为这份证据不可能发生，普通 Bayes 更新未定义。应调查模型支持、传感器错误、数值下溢或数据接口，而不是随意把后验设成均匀并继续假装精确推断。可以设计明确的稳健回退，但那是新策略与近似，需记录触发次数和影响。

小概率不等于零概率。长序列连乘容易下溢，可以用 log 权重和稳定归一化；结构上的不可能事件则不能靠数值技巧修复。教学有限模型适合逐项枚举概率，确认每个核非负并归一化。实际复杂模型还需要检查预测校准，因为错误似然会让后验越来越自信地偏离真实状态。

<a id="pomdp-4-detail-10"></a>

### 3.3 为什么信念足以替代完整历史

假设隐藏状态在给定当前状态和动作后控制下一交互，模型已知，所有决策相关可见信息都进入历史。对两个产生相同信念的历史，任意固定动作下下一证据概率都是对同一个信念加权求和，因此相同；下一信念又由当前信念、动作和新证据决定，所以也具有相同条件分布。当前期望奖励同样由信念决定。

由一步关系归纳，固定同一棵从此刻开始、只根据后续新证据分支的继续决策树，相同信念与相同剩余时间会产生相同未来分布与回报。因此两段历史的未来可实现价值集合相同，可以选择只依赖信念与时间的最优策略。

任意完整历史策略仍可能故意按无关旧历史选不同动作，不能断言它们自身必有相同分布。这是信息充分性证明，不意味着信念计算便宜：有限隐藏状态的信念仍位于连续单纯形，高维和未知模型会带来新的计算问题。

<a id="pomdp-4-detail-11"></a>

### 3.4 未知模型与记忆网络

若转移或传感准确率未知，只维护状态边缘信念通常不足以描述未来学习。可以把未知参数也视为潜在变量，维护状态与参数的联合后验；或者采用其他明确近似。固定模型下的充分性不能直接移到在线辨识问题。模型不确定性与状态不确定性是相关但不同的层次。

循环网络可以学习历史摘要，但没有自动等于 Bayes 信念的保证。应测试长依赖、噪声变化和隐藏状态预测校准，并比较有限模型的精确参照。如果网络摘要把任务相关历史合并，后续策略再强也无法恢复。记忆容量、训练覆盖和信息定义都需要与算法一起检查。

=(0.42,0.58).
$$

左侧四条带状流分别代表 $`0.36,0.04,0.06,0.54`$ 的转移质量；同一颜色从旧状态流向不同新状态，说明信念改变既可能来自真实状态移动，也可能来自后续证据。预测列重新按**新状态身份**着色，因而其蓝色总量为 $`0.36+0.06=0.42`$。

收到报告一后，新状态零、一的观察似然分别为 $`0.2,0.8`$，保留联合质量 $`(0.084,0.464)`$。灰色 $`0.452`$ 是其余观察的总质量，不属于本次证据；彩色总量 $`0.548`$ 才是归一化分母。最后一列共同除以它，得到

$$
b'=\left(\frac{0.084}{0.548},\frac{0.464}{0.548}\right)
\approx(0.153285,0.846715).
$$

前三列的高度都按原概率尺度绘制，最后一列才扩展回总质量一。若漏掉转移，直接拿旧先验筛选，会误得 $`\left(\frac{0.08}{0.56},\frac{0.48}{0.56}\right)=(\frac17,\frac67)`$，虽然仍是合法概率向量，却对应另一个静态模型。这个差别必须靠交互时序核验，不能只检查“和是否为一”。可对照 [Kaelbling、Littman 与 Cassandra 第 3.2–3.3 节的状态估计器与 Bayes 推导](https://people.csail.mit.edu/lpk/papers/aij98-pomdp.pdf)；本图四列数值由本章实际实验独立复算。

作为静态对照，另固定一个传感器：信号 $`e`$ 在 A 下出现概率 $`0.8`$，在 B 下出现概率 $`0.2`$。先验各半时，信号与 A 同时发生的质量为 $`0.5\times0.8=0.4`$，与 B 同时发生为 $`0.5\times0.2=0.1`$；信号总概率为 $`0.5`$，所以 $`P(A\mid e)=\frac{0.4}{0.5}=0.8`$。

仅改变先验：A 为 $`0.2`$，B 为 $`0.8`$。两种联合质量现在同为 $`0.16`$，信号总概率为 $`0.32`$，归一化后后验各半。这些数都是**归一化之前**的质量，不需要加成一，不能把筛选后的质量 $`0.16`$ 当成后验。观测对 A 的似然更有利，但较大的 B 先验恰好抵消这种证据优势。

这个静态对照假设状态静止，或者已经完成动作与转移带来的预测步骤。动态任务应先得到预测信念，再应用同一筛选归一化；如果奖励也可见并携带信息，应将它与普通信号共同条件化。严格模型中，零先验状态不能靠有限似然获得正质量；分母为零则更新未定义。后验是模型与证据共同给出的分布，不代表最大后验状态已被证明为真。

## 4. 实验一：观察别名与 Bayes 枚举

<a id="pomdp-4-detail-13"></a>

### 4.1 可验证的最小反例

先枚举无记忆策略在空白观察上的任意猜测概率，验证均匀隐藏状态下都只有一半正确；再比较带提示记忆的策略。接着构造有状态翻转和噪声观察的核，通过显式联合枚举核对预测校正公式。最后验证奖励可以是额外观察，避免在模型中悄悄丢弃信息。

```python
import numpy as np
for choose_one in np.linspace(0,1,21):
    success = .5*choose_one+.5*(1-choose_one)
    assert np.isclose(success,.5)
memory_success = sum(.5*float(cue==hidden) for hidden,cue in [(0,0),(1,1)])
assert memory_success == 1
b = np.array([.4,.6])
T = np.array([[.9,.1],[.1,.9]])  # 行是旧状态，列是新状态。
Z = np.array([[.8,.2],[.2,.8]])  # 行是新状态，列是观察。
predicted = b@T
assert np.allclose(predicted,[.42,.58])
observed = 1
posterior = predicted*Z[:,observed]
posterior /= posterior.sum()
joint = np.zeros((2,2,2))
for old in range(2):
    for new in range(2):
        for o in range(2):joint[old,new,o]=b[old]*T[old,new]*Z[new,o]
exact = joint[:,:,observed].sum(0)/joint[:,:,observed].sum()
assert np.allclose(exact,posterior)
assert np.isclose(posterior[1],.464/.548)
# 普通观察永远空白，但可见奖励R=S会完全揭示静态隐藏状态。
for reward in [0,1]:
    weights = np.array([.5*float(s==reward) for s in [0,1]])
    updated = weights/weights.sum()
    assert updated[reward] == 1
print('memory/reactive',memory_success,.5,'posterior',posterior.tolist())
```

实验中的奖励揭示状态是专门的诊断例子，不应直接沿用只按普通观察更新的简化公式。后面的监听规划在非终止监听时只给固定成本，因此该奖励不额外暴露隐藏状态；最终猜测奖励发生在任务结束后，不影响剩余决策。每个例子都明确自己采用的信息协议。

## 5. 剩余时间必须进入决策状态

<a id="pomdp-4-detail-15"></a>

### 5.1 任务期限和外部截断

若任务只允许若干次决策，剩余次数影响是否值得花一步获取信息，同一信念在不同期限下可能有不同最优动作。可以使用时间索引价值 $`V_h(b)`$，或把剩余次数加入状态。若环境只是因为训练系统预算停止而截断，原任务未来价值未必为零，不能无条件套用自然终止处理。

例如还有一步时，监听没有时间用于后续猜测，立即猜更合理；还有多步时，可以先监听再决定。把期限从输入中删掉会让相同信念对应矛盾监督。相反，如果原任务是无限时域、采样器任意截取片段，给每个片段末尾设零价值会改变目标并产生系统偏差。

<a id="sec-2-1"></a>

<a id="pomdp-4-detail-16"></a>

### 5.2 自举边界来自任务定义

真正终止之后没有未来回报，价值自举应为零。外部截断如果保留原任务连续性，可以需要从合法下一状态或信念估计后续价值，但具体处理取决于采样协议和可见信息。不能仅凭接口中一个叫 done 的标志决定所有情况，必须区分自然结束、任务到期、执行故障和采样中断。

有限时域里到期本身是任务的一部分，最后一步可用动作和奖励应预先定义。若到期后没完成就失败，应把这一结果体现在模型，而不是仅停止循环。评价总回报、完成率和决策次数也需要同一边界，否则训练优化的任务与报告成功事件可能不同。

<a id="pomdp-4-detail-17"></a>

## 6. 信念上的有限动态规划

<a id="pomdp-4-detail-18"></a>

### 6.1 Bellman 递推

已知模型下，期望即时奖励为 $`r(b,a)`$，证据概率为 $`P(e\mid b,a)`$，更新记为 $`\tau(b,a,e)`$。剩余 $`h`$ 步的价值满足

$$
\begin{aligned}
V_h(b) &=\max_a\left[r(b,a)+\gamma\sum_eP(e\mid b,a)V_{h-1}(\tau(b,a,e))\right],\\[6pt]
V_0 &=0.
\end{aligned}
$$

如果动作会终止，后续价值应相应为零。这里对所有可能观察分支求期望，和先用最可能状态再按完全可观测规划不同。后者把不确定性压成一点，可能忽略获取信息的价值。信念规划允许动作既改变环境，也改变未来知识。

<a id="pomdp-4-detail-19"></a>

### 6.2 二元监听任务的完整定义

隐藏状态零或一在整个任务内保持不变，先验各半。猜零或猜一会终止，猜对奖励一、猜错零。监听消耗一次决策，奖励为负零点零一，传感器以零点七概率报告真实状态，且给定隐藏状态后各次报告独立。折扣为零点九九。监听成本不随状态变化，所以非终止奖励没有额外信息。

假设当前信念中状态一概率为 $`b`$，听到一的概率是零点七乘 $`b`$ 加零点三乘一减 $`b`$，后验按 Bayes 更新。立即猜的价值是 $`\max(b,1-b)`$；监听价值则为成本加折扣后的两个后验最优值。最优动作取决于信念和剩余时间，不是固定次数地一直听。

<a id="pomdp-4-detail-20"></a>

### 6.3 手算一到两步

只剩一步，先验各半，立即猜价值为零点五。剩两步时，监听后信念变成零点七或零点三，第二步按较大概率猜，成功率零点七；折扣后减成本得到零点六八三，大于直接猜。因此信息动作虽然即时奖励为负，整体上仍值得。只贪心最大化当前奖励会错过这种价值。

第 13.2 节还会枚举全部监听子树，求出任意先验 $`b`$ 的两步价值和监听区间；这里的各半先验只是其中一个点。

两个同样准确的独立报告不一定继续提升对称先验下的最优分类成功率，因为冲突时形成平局；第三个报告可以打破一些平局，但还要考虑成本和折扣。不能把“多观察”直接等同于“更高净回报”。动态规划比较的是未来决策收益，而不仅是后验熵。

<a id="pomdp-4-detail-21"></a>

### 6.4 实验二：规划与独立闭环核对

下面代码精确展开小型信念树，不采用网格近似，也不调用环境库。规划器按信念求最优值，另一个执行函数固定真实隐藏状态，只按实际观察概率枚举策略产生的后续分支。最后对初始隐藏状态平均，验证闭环期望与规划结果一致，避免只测试递推函数自身。

```python
from functools import lru_cache
import numpy as np

accuracy, cost, gamma = .7,.01,.99
def outcome(b,o):
    likelihood1 = accuracy if o==1 else 1-accuracy
    likelihood0 = 1-accuracy if o==1 else accuracy
    probability = b*likelihood1+(1-b)*likelihood0
    return probability,b*likelihood1/probability
@lru_cache(None)
def plan(b,h):
    if h==0:return 0.,'stop'
    actions = [(1-b,'guess0'),(b,'guess1')]
    if h>1:
        continuation = sum(probability*plan(posterior,h-1)[0]
                           for probability,posterior in [outcome(b,0),outcome(b,1)])
        actions.append((-cost+gamma*continuation,'listen'))
    return max(actions,key=lambda item:item[0])
def execute(hidden,b,h):
    value,action = plan(b,h)
    if action=='stop':return 0.
    if action.startswith('guess'):
        return float(int(action[-1])==hidden)
    result = -cost
    for o in [0,1]:
        p = accuracy if o==hidden else 1-accuracy
        result += gamma*p*execute(hidden,outcome(b,o)[1],h-1)
    return result
table = [plan(.5,h) for h in range(1,5)]
closed_loop = .5*execute(0,.5,4)+.5*execute(1,.5,4)
assert np.isclose(closed_loop,plan(.5,4)[0])
assert plan(.5,1)[1].startswith('guess')
assert plan(.5,4)[1]=='listen'
assert table[3][0]>table[1][0]>.5
assert plan(.99,4)[1]=='guess1'
print('belief_plan_by_horizon',table,'exact_closed_loop',closed_loop)

```

实际运行中，剩余一、二、三、四步的最优值分别为零点五、零点六八三、零点六八三和约零点七四一五零零。四步初始选择监听，较高置信的零点九九信念则立即猜一。独立隐藏状态枚举的闭环回报与信念动态规划完全一致。这些结果只针对已知静态二元模型，不是通用 POMDP 求解器的性能证明。

## 7. 奖励塑形的策略保持来自哪里

<a id="pomdp-4-detail-23"></a>

### 7.1 势函数差分

在同一折扣任务中，定义附加奖励 $`F(s,a,s')=\gamma\Phi(s')-\Phi(s)`$。长度为 $`T`$ 的轨迹上，折扣塑形和逐项抵消：

$$
\sum_{t=0}^{T-1}\gamma^tF_t=-\Phi(s_0)+\gamma^T\Phi(s_T).
$$

中间状态势恰好抵消，不需要假设转移确定。对于无限时域、折扣严格小于一且势有界，末项趋于零，因此同一初始状态下每个策略的价值都减去同一个势值，策略排序不变。若初始分布固定，对其平均也只改变一个常数。

<a id="pomdp-4-detail-24"></a>

### 7.2 条件不能随意删掉

如果折扣为一，无限时域中有界势并不保证末项趋零；如果势无界，即使折扣小于一也需检查尾项条件。有限截断或可变终止时间会保留末项，若终端势非零并依赖所到终点或终止时间，策略排序可能改变。最简单安全做法是任务终端势为零，并对有限时域采用匹配的时间势约定。

有限时域可写 $`F_t=\gamma\Phi_{t+1}(s')-\Phi_t(s)`$，令最终时间势为零，便只留下初始常数。若使用非零终端势，需要证明残留项对所有候选策略相同，而不是只对某一条轨迹看起来小。证明条件属于奖励定义的一部分，不能被一句“只是给接近目标奖励”代替。

<a id="pomdp-4-detail-25"></a>

### 7.3 完全可观测与部分可观测的额外区别

在信念 MDP 上可以对信念定义有界势，使用相同历史可计算更新，满足对应尾项条件时同样望远镜抵消。但如果直接用隐藏状态势生成可见塑形奖励，新奖励可能额外透露状态，改变智能体可用信息。代数恒等式仍成立，却不能自动比较原来与新增观测后的不同策略类。

因此部分可观测奖励修改要同时检查回报变换和信息结构。若塑形只依赖原本可计算的信念、动作和可见后验，不增加新信息，比较更清楚；若模拟器提供特权状态奖励，应如实说明训练信息，并验证部署策略究竟能否获得同类信号。不能把特权信息收益误称为单纯加速。

<a id="visual-example-mdp-04"></a>

### 图解算例：势函数塑形的中间项会在折扣和中抵消

![势函数塑形的中间项会在折扣和中抵消](images/04-example.svg)

图先把每步塑形奖励拆成两个势贡献，再把该步的时间折扣乘进去。横轴不是四次环境动作，而是两步奖励中的四个代数项：$`-\Phi_0,+\gamma\Phi_1,-\gamma\Phi_1,+\gamma^2\Phi_2`$。纵轴上下分别表示正负贡献，长短按同一数值刻度绘制。中间两根长线为 $`+2.7,-2.7`$，无论轨迹经过怎样的中间状态都逐项抵消；剩下的两端才决定整条路径的塑形总和。

两幅图都使用同一初态势 $`\Phi(s_0)=2`$、中间状态势 $`\Phi(s_1)=3`$，折扣 $`\gamma=0.9`$，原奖励均为零。左图终端势为零，塑形奖励依次为 $`0.9\times3-2=0.7`$、$`0.9\times0-3=-3`$，折扣和为 $`0.7+0.9(-3)=-2`$。中间状态的势被抵消，只剩减去初态势。

右图把终端势改为一，并规定收到进入终端的奖励后立即停止累加。第二步塑形奖励变为 $`0.9\times1-3=-2.1`$，折扣和为 $`-1.19`$；与左图相比多出 $`\gamma^2\Phi(s_2)=0.81`$。一般有限轨迹的准确恒等式为 $`\sum_{t=0}^{T-1}\gamma^tF_t=-\Phi(s_0)+\gamma^T\Phi(s_T)`$，不能只写第一项就宣布策略排序保持。

这个尾项足以改变偏好。沿上述两条同长路径，再分别给最后一步原奖励 $`1`$ 与 $`0.5`$：原折扣回报为 $`0.9`$ 与 $`0.45`$，原任务偏好第一条路径；塑形后却为 $`0.9-2=-1.1`$ 与 $`0.45-1.19=-0.74`$，会偏好第二条路径。两条路径原本都零奖励的图用来隔离塑形项，这里另加的原奖励专用于展示严格的偏好反转。

因此，对停止累加的有限回合，令终端势为零是使尾项消失的直接做法；若终止时间变化，非零常数终端势也可能因 $`\gamma^T`$ 不同产生差别。若改为无限期模拟吸收态并继续计入其塑形奖励，后续项必须一并累加，有界势在 $`\gamma<1`$ 时的极限尾项才会消失。必须明确采用哪种回报和终止约定，不能混用。

策略保持定理、折扣势差形式及其假设见 [Ng、Harada 与 Russell 原论文第 3 节](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf)。奖励塑形仍须使用与原任务一致的折扣和实际可用状态，任意引导性奖励不自动满足这些条件。

## 8. 实验三：策略枚举与错误奖励反例

<a id="pomdp-4-detail-27"></a>

### 8.1 一个可精确解的小 MDP

三个状态分别为起点、中间和吸收终点。起点可直接结束得一，或到中间得零；中间可结束得一点二，或原地循环每次得零点零二；折扣为零点九。原任务更喜欢经中间结束，回报为一点零八，而持续循环只得到较小原始回报。枚举两个非终端状态的确定性平稳策略，用线性方程求值。

```python
import itertools
import numpy as np
gamma = .9
policies = list(itertools.product([0,1],repeat=2))
phi = np.array([.4,.7,0.])
def model(policy,shaping=False,bad=False):
    P = np.zeros((3,3));r = np.zeros(3)
    for s in [0,1]:
        a = policy[s]
        if s==0: new,reward = ((2,1.) if a==0 else (1,0.))
        else: new,reward = ((2,1.2) if a==0 else (1,.02))
        P[s,new] = 1
        r[s] = reward+(gamma*phi[new]-phi[s] if shaping else 0.)
        if bad and s==1 and a==1:r[s]+=.2
    P[2,2] = 1
    return np.linalg.solve(np.eye(3)-gamma*P,r)
original = np.array([model(p)[0] for p in policies])
shaped = np.array([model(p,shaping=True)[0] for p in policies])
wrong = np.array([model(p,bad=True)[0] for p in policies])
assert np.allclose(shaped,original-phi[0])
assert np.argmax(shaped)==np.argmax(original)
assert policies[np.argmax(original)]==(1,0)
assert policies[np.argmax(wrong)]==(1,1)
assert original[np.argmax(wrong)] < original.max()
# 有限停止后留下非零终端势，较早结束会获得不同残留项。
base = np.array([1.,1.08]);lengths = np.array([1,2])
wrong_terminal = base-phi[0]+gamma**lengths*5.
assert np.argmax(base)==1 and np.argmax(wrong_terminal)==0
print('policies',policies,'base',original.tolist(),'potential',shaped.tolist())
print('loop_bonus',wrong.tolist(),'nonzero_terminal',wrong_terminal.tolist())
```

正确势差让所有起点价值统一减零点四，枚举策略的最优者不变。错误循环奖励却让长期停留更有利，代理最优策略在原任务上明显更差。非零终端势的例子说明，即使形式上像势差，提前结束与较晚结束保留的折扣尾项不同，也能改变有限回合排序。核对轨迹边界与奖励公式同样重要。

<a id="sec-5"></a>

<a id="pomdp-4-detail-28"></a>

## 9. 实验四：塑形奖励可能泄漏隐藏信息

隐藏位均匀且没有普通观察。第一步只能等待，原奖励为零；第二步猜隐藏位并结束，猜对得一。取折扣零点九，非终端隐藏状态势为该位数值，终端势零。第一步塑形为负零点一乘隐藏位，若智能体观察到它，就能在猜测前知道状态。原信息条件下最多猜对一半，新增塑形信号后可全对。

```python
import numpy as np
gamma = .9
raw_no_information = .5*gamma
shaped_old_policy = []
for guess in [0,1]:
    value = 0.
    for hidden in [0,1]:
        f0 = (gamma-1)*hidden
        f1 = -hidden
        raw = gamma*float(guess==hidden)
        shaped = f0+gamma*(float(guess==hidden)+f1)
        assert np.isclose(shaped,raw-hidden)
        value += .5*shaped
    shaped_old_policy.append(value)
new_value = 0.
for hidden in [0,1]:
    first_shaping = (gamma-1)*hidden
    inferred = int(first_shaping < 0)
    assert inferred==hidden
    new_value += .5*(first_shaping+gamma*(1-hidden))
assert np.isclose(max(shaped_old_policy),raw_no_information-.5)
assert np.isclose(new_value,gamma-.5)
assert new_value>max(shaped_old_policy)
print('old_information_best',max(shaped_old_policy),'extra_signal_best',new_value)
```

每条轨迹的望远镜恒等式都正确，变化来自策略能够利用新的观察。这个反例不否定势函数结论，而是指出比较时必须固定可用信息与策略类。若把奖励并入观测核，新的问题与旧问题本来就不同；如果塑形信号仅用于训练但部署不提供，也需要解释策略如何避免依赖无法获得的信息。

## 10. 奖励代理与真实目标的距离

<a id="pomdp-4-detail-30"></a>

### 10.1 可测量不等于想要的结果

完成任务、节约资源、避免无效循环和遵守约束可能是多个不同要求。若只奖励每次接近某位置，智能体可能来回移动反复领奖；若奖励输出长度，可能生成冗余；若奖励某个预测器高分，可能寻找该预测器误差。优化更充分时，代理与真实目的的差距可能更明显，不应把代理曲线提升当作唯一成功。

应先写出候选轨迹和真实偏好，再看奖励能否给出相同排序。包括正常完成、提前停止、反复循环、偶然高分、未完成但表面进展和约束违规。小型枚举不能覆盖所有环境，但能提前暴露明显漏洞。奖励修改后要同时评价原始目标与新训练回报，避免只展示被修改指标的进步。

<a id="sec-6-1"></a>

<a id="pomdp-4-detail-31"></a>

### 10.2 硬约束与软罚分

给违规一个有限负奖励，并不在所有问题中保证永不违规；其他奖励可能足够大，或者远期折扣使罚分影响较弱。若任务要求严格禁止某动作，应在合法动作与执行规则中体现，或建立有明确假设的约束优化，而不是默认一个很大的数字代表绝对边界。理论保证需要奖励界、期限和可行性条件。

多目标聚合也会隐藏交换。把成功与成本加权成一个数，需要说明权重来源及允许代价；不同权重可能产生不同最优策略。可以报告完整指标向量或受约束成功率，开发选择后在冻结测试上检验。不能在看到轨迹后随意调整权重，使当前策略显得最优。

<a id="pomdp-4-detail-32"></a>

### 10.3 部分观测中的目标与信息混淆

一个策略失败可能因为奖励偏好错误，也可能因为看不到必要状态。只增加失败罚分无法创造缺失信息；增加传感器则可能改善，即使奖励完全不变。反过来，信息充足但奖励偏向循环时，更好的记忆也无法保证真实任务成功。诊断应分别改变信息、奖励和策略容量，保持其他条件，避免把所有问题都归为探索不足。

评价者可以读取隐藏真值统计正确率，但被测策略不能偷看。训练数据中的隐藏状态、模拟器标志或未来结果若流入策略输入，会改变任务。需要记录每个字段何时可得、给谁可见、如何进入模型。奖励、观察和评价标签都属于信息管道，而不只是分开的三个变量名。

## 11. 进阶练习与详细解答

<a id="pomdp-4-detail-34"></a>

### 11.1 题一：观察别名的最优反应

题目：两个隐藏状态等概率，最后观察相同，正确动作不同。随机无记忆策略能否超过一半？

解答：不能，设选动作一概率为某个数，两状态正确率加权后恒为二分之一。若历史曾提供提示，记忆策略可以更好，但它属于更丰富策略输入。该差距来自可识别信息，不是训练时间。应先确认策略可见内容，再讨论算法最优性。

<a id="pomdp-4-detail-35"></a>

### 11.2 题二：奖励也是观察吗

题目：普通传感器总返回空白，奖励恰好等于隐藏位，只用空白更新信念是否正确？

解答：不正确，奖励已经是可见证据，观察到零或一后应相应更新。可以把奖励并入观测，或使用完整联合核。若故意不给策略看奖励，也要在协议中明确，此时又是不同信息问题。期望奖励公式不自动表达奖励实现值携带的信息。

<a id="pomdp-4-detail-36"></a>

### 11.3 题三：Bayes 更新的次序

题目：动作先使状态翻转，再由新状态产生观察，应先乘旧状态观察似然吗？

解答：不应，应先通过转移得到新状态预测，再用对应新状态似然校正；或直接使用联合核求和。错误次序通常仍能归一化，却表示另一个事件过程。索引和时间顺序是模型定义，不能只凭后验数值范围判断。

<a id="pomdp-4-detail-37"></a>

### 11.4 题四：相同信念为何可合并

题目：两段历史不同但对当前状态后验相同，已知固定模型下是否还需全部保存才能规划？

解答：在所有相关可见信息已纳入且剩余时间相同的条件下，不需要。下一证据、奖励和后验分布都由当前信念与动作确定，归纳可得未来决策等价。若模型未知或历史影响合法动作，则需扩充统计量，不能直接套用这个充分性。

<a id="pomdp-4-detail-38"></a>

### 11.5 题五：最可能状态规划的限制

题目：当前状态一概率零点五一，直接当状态一规划为什么可能错误？

解答：它丢掉接近一半的另一种可能，也忽略信息动作改变后续判断的价值。高代价错误或可选择监听时，这种近似可能很差。可以作为明确基线，但应与精确信念规划比较，不把它称为同一 Bellman 递推的精确实现。

<a id="pomdp-4-detail-39"></a>

### 11.6 题六：期限怎样改变动作

题目：监听当前有负成本，为何剩两步时可能优于剩一步？

解答：剩两步可以利用新观察做更准确猜测，信息收益可能超过成本；剩一步没有后续使用机会。本章先验监听两步价值零点六八三，高于零点五。时间必须进入价值或状态，否则同一信念会面对矛盾目标。

<a id="pomdp-4-detail-40"></a>

### 11.7 题七：零概率证据

题目：更新分母为零时直接设均匀是否仍为精确 Bayes？

解答：不是，模型认为证据不可能，条件概率未定义。应检查支持、测量错误和数值下溢。明确的回退可以提高工程可用性，但要报告其近似与触发，不应伪装成原模型推断。结构不可能与数值太小需要不同处理。

<a id="pomdp-4-detail-41"></a>

### 11.8 题八：多观察是否一定多回报

题目：三次报告比一次有更多信息，净回报是否必然更大？

解答：不必然，监听消耗成本、期限并受到折扣。更多信息在理想决策中可选择忽略，但获取它的动作本身不是免费。应比较整条策略回报，而不是只比后验熵或分类正确率。高置信时立即行动可能最优。

<a id="pomdp-4-detail-42"></a>

### 11.9 题九：势差为什么含折扣

题目：把附加奖励写成 $`\Phi(s')-\Phi(s)`$，是否总保持折扣任务策略？

解答：不总保持，缺少对应折扣因子后中间项不能按原折扣权重完全抵消。正确形式需与任务折扣一致。某些特殊任务可能碰巧排序不变，但不能由此得到一般保证。应逐项写出折扣和检查尾项，而非只记“势的差”。

<a id="pomdp-4-detail-43"></a>

### 11.10 题十：有限终端势

题目：不同策略结束时间不同，终端势都等于五，是否残留同一个常数？

解答：不一定，残留为折扣的终止时间次幂乘五，不同时间不同。本章直接结束与绕行结束因此发生排序翻转。令终端势零是简单充分处理，或者证明其他残留项对所有策略相同。有限回合边界不能从无限时域结论中省略。

<a id="pomdp-4-detail-44"></a>

### 11.11 题十一：隐藏势的新信息

题目：塑形轨迹和确实只差初始势，为什么部分观测策略仍可能更强？

解答：如果新增可见奖励透露隐藏状态，策略能够依赖原来没有的信息，比较的策略类已改变。代数恒等式在固定策略和轨迹上仍正确，不自动给出跨信息结构的等价。应使用可由原历史计算的势，或明确特权信号与部署边界。

<a id="pomdp-4-detail-45"></a>

### 11.12 题十二：外部截断

题目：无限任务训练片段到长度上限就停止，能否总把未来价值设零？

解答：不能，外部采样结束不代表任务自然终止。需要根据原任务和合法下一信念决定自举；若任务本身有期限，则到期是另一终止模型。应区分状态标志和停止原因，避免让采样器悄悄改奖励目标。

<a id="pomdp-4-detail-46"></a>

### 11.13 题十三：循环奖金

题目：给每次靠近目标或停留某区域奖励，为何可能破坏目的？

解答：智能体可能反复循环领取而不完成，尤其累计折扣奖金超过结束收益。应枚举短轨迹与周期，比较原任务和代理排序。势函数形式在合适条件下可避免某些排序改变，但任意进度奖励没有自动保证。

<a id="pomdp-4-detail-47"></a>

### 11.14 题十四：大罚分与硬约束

题目：给违规负一千，是否一定保证从不违规？

解答：不无条件保证，其他回报、期限与折扣可能抵消，模型也可能估计错误。硬要求应通过合法动作、执行边界或明确约束模型表达。若用软罚分，需要奖励界等条件和实际验证，不能把数字大等同于逻辑禁止。

<a id="pomdp-4-detail-48"></a>

### 11.15 题十五：未知准确率

题目：传感器准确率未知，只维护隐藏位概率是否足够？

解答：通常不足，过去报告还提供关于准确率的信息，影响未来观察价值。可以维护状态与参数联合后验，或说明采用的近似。已知模型信念充分性有明确条件，不能未经扩展就用于在线学习全部未知环境。

<a id="sec-8-2"></a>

<a id="pomdp-4-detail-49"></a>

### 11.16 题十六：怎样判断塑形只加速

题目：新奖励让训练更快成功，能否说它只加速而没改任务？

解答：应核对变换形式、折扣、尾项、终止和信息结构，再比较原始目标下的策略与回报。训练曲线本身不足以证明策略不变，有限算法也可能因优化差异得到不同结果。小型精确策略枚举可以验证例子，普遍保证仍依赖完整理论条件。

<a id="sec-8"></a>

<a id="pomdp-4-detail-50"></a>

## 12. 综合研究任务

先用二元监听模型建立精确参照，再比较只看当前观察、固定窗口和信念策略。记录原始任务成功、折扣回报、监听次数与每种停止原因。改变传感准确率、先验和成本，观察策略边界如何变化，开发选择与最终确认分开。若加入未知模型参数，应重新定义推断对象，不把固定模型代码当作通用学习器。

<a id="sec-8-1"></a>

<a id="pomdp-4-detail-51"></a>

### 12.1 奖励与信息的联合验收

为同一模型设计正确势差、循环奖金和隐藏信息塑形，分别检查轨迹恒等式、策略排序及可见信息。至少保留一条失败反例，解释是奖励目标、时间尾项还是信息结构变化。实验仅使用内存中的有限枚举和线性方程，不依赖 Gym、外部模型或下载数据。核对结果时，应能逐项追溯到转移概率、奖励定义与策略可见信息。

<a id="pomdp-4-detail-52"></a>

## 13. 信念空间的几何与精确规划

<a id="pomdp-4-detail-53"></a>

### 13.1 固定策略树的价值对信念线性

本节额外假设动作与完整可见证据集合有限；若奖励取连续值并参与观察，有限策略树计数需要相应改写。有限时域下，一个确定性策略树规定初始动作，以及每种后续证据下采用的子树。固定这棵树后，从每个隐藏状态出发的期望回报可以分别计算，组成向量 $`\alpha`$；初始信念下的价值就是 $`b^T\alpha`$。因此对有限多个策略树取最优，价值是若干线性函数的最大值，具有分段线性和凸的结构。

凸性方向很重要。它表示在不额外收费的正确证据模型下，先获得信息再选择策略，平均价值不会低于先把不确定性混成一个信念再选固定策略。但获取信息的动作可能有成本、折扣和期限，净收益仍需 Bellman 比较。不能把这种结构定理改写成“智能体永远应该多观察”。本章监听成本正是为了显式体现这种差别。

<a id="pomdp-4-detail-54"></a>

### 13.2 Alpha 向量的备份

对动作 $`a`$，为每个可能证据选择一个后续向量 $`\alpha_e`$，可以构造当前向量。简化非信息奖励模型下，其状态分量为即时期望奖励加上折扣后的转移观测加权后续价值；若奖励本身属于证据，则直接用联合核对所有状态、证据和奖励求和。每种后续子树选择组合都产生一个候选向量，再删除在全部信念上不可能最优的候选。

完整写出联合核备份，给动作 $`a`$ 和每种证据 $`(o,r)`$ 指定一个后续向量，得到

$$
\alpha_a(s)=\sum_{s',o,r}K(s',o,r\mid s,a)\left[r+\gamma\alpha_{o,r}(s')\right].
$$

终止分支的后续向量取零，其他分支来自剩余时域的候选向量集。这里后续选择允许依赖实际奖励，正是因为奖励可能提供信息；如果错误地只按普通观察选择同一子树，就限制了策略类。有限动作、状态、证据和时域保证候选树有限，对每种子树组合备份后取上包络。这个表达不需要先把奖励与转移独立分解，因而与本章最初的联合模型一致。

二元猜测任务的立即结束向量分别为一零与零一，对应价值一减信念和信念。监听备份把两种观察分支的后续向量组合起来，形成新的直线，最优价值是这些线的上包络。它与在若干信念网格点上插值不同：前者在有限模型和有限树集合下可以精确，后者通常是近似，需要额外误差分析。

把第 6 节的两步监听任务完整展开。剩一步时只有两个有效终止向量 $`\alpha_0=(1,0)`$、$`\alpha_1=(0,1)`$，信念向量按 $`(1-b,b)`$ 排列。若第一步监听，两种报告各自可以接猜零或猜一，共四种后续组合。听到零猜零、听到一猜一时，对任一真实状态的成功概率均为 $`0.7`$，因此备份向量为 $`(-0.01+0.99\times0.7,-0.01+0.99\times0.7)=(0.683,0.683)`$。

四种子树组合可以放在同一张表中核对。向量的第一、第二分量分别对应真实状态零和一。

| 报告零后的行动 | 报告一后的行动 | 监听后的 Alpha 向量 | 与已有候选的关系 |
| --- | --- | --- | --- |
| 猜零 | 猜零 | $`(0.98,-0.01)`$ | 被立即猜零的 $`(1,0)`$ 逐分量支配 |
| 猜零 | 猜一 | $`(0.683,0.683)`$ | 在中间信念区域可能最优 |
| 猜一 | 猜零 | $`(0.287,0.287)`$ | 被按报告猜的向量逐分量支配 |
| 猜一 | 猜一 | $`(-0.01,0.98)`$ | 被立即猜一的 $`(0,1)`$ 逐分量支配 |

本例用逐分量支配就足以剪枝：信念分量非负且和为一，被支配向量与任意信念的内积都不会更大。一般 POMDP 的全部劣势候选未必都能靠这一简单规则识别，还可能需要比较整个向量集合的上包络。因此删除本例的三个劣势候选后，只剩三条直线，精确两步价值为

$$
V_2(b)=\max\{1-b,\ b,\ 0.683\}.
$$

监听严格最优的先验区间由 $`b<0.683`$ 且 $`1-b<0.683`$ 联立得到，即 $`0.317<b<0.683`$；两端是行动并列点。这说明最优监听阈值既不是固定的 $`0.5`$，也不是直接照抄传感器准确率 $`0.7`$：监听成本和折扣已经进入阈值。比如 $`b=0.65`$ 时立即猜值为 $`0.65`$，监听值为 $`0.683`$；$`b=0.8`$ 时立即猜值为 $`0.8`$，任何监听子树都无法胜出。这个枚举同时展示联合核备份、支配剪枝、分段线性和行动区域，四个概念描述的是同一组具体候选。

策略树数量会随动作、观察和时域快速增长。即使隐藏状态只有两个，信念空间是一条连续区间，也不代表任意长规划便宜。当前实验只展开四步，是为了可以完全检查。更大系统可以使用剪枝、点基方法或在线搜索，但应说明近似范围和预算，不能把小树枚举的精确性直接外推到高维环境。

<a id="visual-alpha-listening-region"></a>

### 机制算例：从 Alpha 上包络读出行动区间与成本边界

![两步POMDP的Alpha上包络与随监听成本收缩的行动区间](images/04-alpha-listening-region.svg)

上图把前面的三条未被支配的价值函数画在同一坐标系中。横轴 $`b=P(S=1)`$ 是初始信念，纵轴是从现在起计算的期望折扣回报。猜零对应 $`1-b`$，猜一对应 $`b`$，先监听一次、再按报告猜对应常数 $`0.683`$。细线代表各个固定策略树，粗线是逐个信念选择最佳策略后的上包络。中间水平段不是“算法不利用信念”，而是在这一范围内同一棵条件策略树最优；它对两个真实状态的成功概率相同，所以固定树价值恰为常数。

必须区分“先监听这个动作的最优价值”与“监听后按报告猜这棵固定树的价值”。在任意先验下，前者还要比较四种后续猜测组合，实际为

$$
Q_{\rm listen}(b)
=-0.01+0.99\max\{1-b,\ b,\ 0.7\}.
$$

图中的水平细线只画按报告猜那一棵树，不能把 $`0.683`$ 当成所有信念下完整的监听动作价值。例如 $`b=0.9`$ 时，听到零后的后验仍为 $`\frac{0.9\times0.3}{0.9\times0.3+0.1\times0.7}\approx0.794118`$，听到一后更高，因此听到什么都应猜一。监听动作价值为 $`-0.01+0.99\times0.9=0.881`$，不是 $`0.683`$；但它仍被立即猜一的 $`0.9`$ 严格压住。删除这条劣势监听子树不改变最优上包络，却不等于它不存在。

在较不确定的 $`b=0.65`$ 处，报告一的概率为 $`0.65\times0.7+0.35\times0.3=0.56`$，报告零的概率为 $`0.44`$。两种后验分别为 $`\frac{0.455}{0.56}=0.8125`$ 与 $`\frac{0.195}{0.44}\approx0.443182`$，所以两个观察分支确实分别猜一与猜零。平均成功率为 $`0.56\times0.8125+0.44\times(1-0.443182)=0.7`$，扣除成本和折扣得到 $`0.683`$，超过立即猜的 $`0.65`$。先把两后验平均回 $`0.65`$ 再选择同一个猜测，会丢掉按分支行动的收益。这正是策略树不同分支对应不同后续 Alpha 向量的实际含义。

下图只改变监听成本 $`c\ge0`$，保持传感器准确率 $`q=0.7`$、折扣 $`\gamma=0.99`$ 与两步期限不变。按报告猜的价值变为 $`a=\gamma q-c=0.693-c`$。其他先监听再固定猜的树仍被立即猜逐分量支配。因此最优价值和严格监听区间是

$$
V_2(b)=\max\{1-b,\ b,\ a\},\qquad
1-a<b<a.
$$

该区间只有在 $`a>\frac12`$ 时才非空，宽度为 $`\max(2a-1,0)`$。成本为零、$`0.01`$、$`0.1`$ 时，宽度依次是 $`0.386,0.366,0.186`$；临界成本为 $`c_\star=0.99\times0.7-\frac12=0.193`$。此时只有 $`b=\frac12`$ 处监听与两个立即猜动作并列，没有严格改进区域；成本再高，监听在所有信念上都劣于立即猜。图中的细竖线表示这个并列点，不表示一个仍有正宽度的最优区域。即使监听免费，折扣仍使其价值低于无延迟取得同样信息的成功概率。

这些边界是当前已知模型、对称准确率、固定隐藏状态与只剩两步的精确结论。若错误猜测有负奖励、两种状态的传感器质量不同、监听会改变状态，或仍有更多步，固定策略树的向量及其上包络都必须重算，不能套用同一个阈值。图展示的是 [Kaelbling、Littman 与 Cassandra 原文](https://people.csail.mit.edu/lpk/papers/aij98-pomdp.pdf)中有限时域策略树与分段线性凸价值结构的一组可手算实例；精确几何来自已知模型，并不自动提供模型失配下的部署保证。

<a id="pomdp-4-detail-55"></a>

### 13.3 价值凸性与信息价值的手算

在零点五信念下直接猜值为零点五。一个免费且无需消耗时间的证据把后验变成零点七或零点三，两分支最优值都是零点七，其期望高于原值。这正是凸函数在随机后验上的期望可以高于函数在平均后验处的值。后验均值仍回到原先零点五，没有凭空制造某一隐藏状态更可能的总体事实。

信息有价值，是因为允许根据不同证据选择不同动作，而不是因为 Bayes 更新会在平均上把信念推向某个真值。若所有可行策略在某区域都是同一个动作，额外证据可能完全没有决策收益，哪怕熵下降明显。奖励与动作集合决定哪些信息重要，单纯最大化信息量可能浪费资源在无关细节。

<a id="pomdp-4-detail-56"></a>

### 13.4 折扣无限时域的算子条件

若奖励有界、折扣严格小于一，信念 Bellman 最优算子在有界价值函数的上确界范数下具有折扣收缩性质。证明利用同一动作下期望差不超过最大价值差，再使用最大化的非扩张性。它给出固定模型下最优价值的唯一性和迭代误差控制，但不表示有限神经网络近似或采样算法自动满足同样收缩。

部分可观测性没有破坏信念过程的马尔可夫性质，却把状态空间从有限集合变为连续分布集合。精确表示、动作搜索和证据积分可能仍昂贵。若使用函数逼近，投影步骤可能不保持收缩；若模型未知，算子本身还在变化。理论条件与实际算法之间应逐层核对，而不是把一个折扣符号当成全部稳定性的保证。

<a id="pomdp-4-detail-57"></a>

## 14. 二元监听任务的进一步解析

<a id="pomdp-4-detail-58"></a>

### 14.1 后验几率的累积

静态隐藏位、给定状态独立报告、正确率固定为零点七时，听到一把后验几率乘以七比三，听到零乘以三比七。对数几率因此按正负固定量累加。在这个特殊模型里，报告顺序只通过两类计数差影响信念；但还剩多少决策仍影响最优动作，所以不能只保存计数差而忘记期限。

从各半先验出发，两个一致的一报告给出状态一后验零点四九除以零点五八，约零点八四四八；一正一反则回到各半。若隐藏状态会转移，旧报告与新报告的意义不同，简单计数通常不再充分。顺序不重要是静态独立模型的特例，不能用它简化所有传感器历史。

<a id="pomdp-4-detail-59"></a>

### 14.2 四步最优策略怎样利用分支

在四步各半先验下先监听一次，后验成为零点七或零点三。还剩三步时再监听，若两次一致，置信约零点八四四八，随后可以直接猜；若两次冲突，则回到各半，利用剩余两步再听一次后猜。策略不是每个回合固定听三次，而是根据证据提前停止，这解释了为什么只比较固定次数策略可能漏掉更好方案。

前两次一致的概率为零点五八，其中正确猜测的无条件质量为零点四九；冲突概率零点四二，第三次报告使该支路正确质量为零点二九四。总正确率为零点七八四，但净折扣回报还要扣三次监听中的分支成本，并按不同结束时间折扣。代码值约零点七四一五零零，不能把零点七八四直接当作训练目标数值。

还可以逐项核对折扣账目。前两次监听在时间零和一发生，成本贡献为 $`0.01+0.99\cdot0.01`$；只有冲突分支还在时间二监听，再加 $`0.99^2\cdot0.42\cdot0.01`$。一致分支的正确猜测发生在时间二，奖励贡献为 $`0.99^2\cdot0.49`$；冲突后第三次报告的正确猜测发生在时间三，贡献为 $`0.99^3\cdot0.294`$。奖励总贡献约零点七六五五一七，成本约零点零二四零一六，相减恰为零点七四一五零零四八六。把猜测奖励错移到监听当步，会得到另一个数。

这个拆解提供独立核对方法：按隐藏状态、观察序列和停止时间逐项求和，应与信念递推相同。若正确率一致但回报不同，优先检查奖励发生时间、成本次数和折扣索引。完整闭环验收不仅要看最优动作名称，还应核对这些可加账目。

#### 将闭环策略展开到每个终止分支

![四步监听策略树，一致报告提前猜测，冲突再听，叶端记录正确联合质量](images/04-adaptive-listening-tree.svg)

节点字符串是已收到的报告序列，不是隐藏状态。连线为给定父节点的条件分支概率；叶端“正确质量”是从起点计算的联合概率，不能把两类数相加。橙色路径在时间二猜测，蓝色在时间三猜测；较早结束的横线延伸到展示区，并未额外等待或增加折扣。

首报零概率为 $`0.5`$，后验 $`P(S=1\mid0)=0.3`$。再报零的条件概率为 $`0.7^2+0.3^2=0.58`$，序列00的质量 $`0.29`$。其中“状态零、报告00”的正确质量是 $`0.5\times0.7^2=0.245`$，后验置信为 $`\frac{0.245}{0.29}=\frac{49}{58}\approx0.844828`$；11由对称性相同。01的质量 $`0.21`$，两报告似然比抵消，信念回各半。第三报各半，所以010、011各有质量 $`0.105`$，按末报猜的正确质量各 $`0.105\times0.7=0.0735`$。10产生另两条相同叶子。

六个终止支路总质量 $`2(0.29)+4(0.105)=1`$，成功质量 $`2(0.245)+4(0.0735)=0.784`$，没有重复计入中途节点。期望监听次数为 $`2+0.42=2.42`$，不是三次。若强制每回合听满三次再多数票，成功率同样为 $`0.784`$：第三报不会改变前两报一致时的多数，只在冲突时起作用；它却额外收费，并延迟一致支路的奖励。

固定三次再猜的折扣回报为

$$
0.99^3(0.784)-0.01(1+0.99+0.99^2)
=0.731013416,
$$

低于闭环树的 $`0.741500486`$，差 $`0.01048707`$。因此相同成功率不等于相同控制价值。提前停止的收益可以在同一传感器、同一报告概率上核算，不必归因于更强的观测或更多训练。

按观察分支选择后续策略可对照 [Kaelbling、Littman 与 Cassandra 第 4 节](https://people.csail.mit.edu/lpk/papers/aij98-pomdp.pdf)。这棵六叶树仅对应已知静态二元模型、四步期限和给定成本；噪声相关性、时域或费用改变后须重算。

<a id="pomdp-4-detail-60"></a>

### 14.3 监听阈值不是固定传感器常数

最优是否监听取决于当前信念、剩余时间、错误代价、监听成本与折扣。提高传感准确率通常增加某些不确定区域的信息价值，但高置信区域仍可能直接行动；若错误代价不对称，猜测阈值也不再是二分之一。应重新推导即时猜测价值，而不能只沿用多数票。

若允许不同传感器，动作还可以选择廉价粗测或昂贵精测。观察既提供信息又消耗预算，规划需要比较它们的后续分支。当前小模型可以扩展作研究，但新增成本与准确率应在开发阶段设定，最终评价保持冻结。不能看到某策略失败后只调参数让它成功，再把修改后的任务当原来问题。

<a id="pomdp-4-detail-61"></a>

### 14.4 信念校准与决策质量分别看

一个过滤器后验准确，不保证策略选择好动作；一个策略在某个简单任务上成功，也不保证其内部信念校准。可以用已知隐藏状态对过滤分布做适当评分，同时评价回报、成功率和观察成本。模拟器真值只用于评价，不应进入部署决策路径。两个层次分开，可以定位失败来自推断还是控制。

若传感准确率从训练时变化，旧过滤器可能过度或不足自信，监听策略边界随之失效。可以先固定策略比较过滤误差，再固定过滤器比较规划，或建立联合适应方法。每种对照回答不同问题，不应一次同时换过滤、奖励和策略后给出单一归因。

<a id="pomdp-4-detail-62"></a>

## 15. 奖励变换的更细条件

<a id="pomdp-4-detail-63"></a>

### 15.1 正缩放与加常数并非总能混称

把同一任务所有回报乘正数，在策略信息不变时保持排序；乘负数则反转偏好。每步加常数只有在额外总贡献对所有策略相同时才不改变排序，例如固定步数或适当无限连续模型。可变长度回合提前停止时，每步常数累积次数和折扣不同，可能奖励拖延或鼓励过早结束。

例如原任务直接结束得一，绕一步结束折扣后得一点零八，本来偏好绕行。若每个实际决策加负零点二，直接路线变零点八，绕行路线变负零点二加零点九乘一，等于零点七，排序翻转。这个反例提醒我们，通用效用的正仿射直觉需要与回合停止协议核对，不能省略持续时间。

<a id="pomdp-4-detail-64"></a>

### 15.2 同一势在不同时间上的尾项

固定状态势在有限时域未必足够，因为终端剩余项可能不同。时间依赖势可以将时域显式纳入模型，最终时间势归零；或者把到期吸收状态统一设零。若任务因外部截断而中断，又不能未经说明把其势当作自然终端清空，因为原无限任务的后续项仍然存在。

以实验中的非零终端势为例，起点势零点四、中间势零点七、终点势五。直接结束的塑形回报为一加零点九乘五再减零点四，即五点一。绕行第一步塑形为零点二三，第二步总奖励为一点二加四点五减零点七，即五；折扣后总和为零点二三加四点五，即四点七三。原先更好的绕行路线反而落后，原因完全可以定位为终端折扣尾项，而不是中间势设置得不够平滑。

对随机终止时间，望远镜等式逐条轨迹成立，但取期望后仍需控制尾项与可积性。如果所有真实终端势零，随机长度本身不会破坏该边界抵消；若终端势相同非零，折扣终止时间不同仍会留下策略依赖。应先看路径恒等式，再看期望条件，避免在两个层次中漏掉假设。

<a id="pomdp-4-detail-65"></a>

### 15.3 信念势与信息增益奖励

在原信息结构下可计算的信念势更容易保持策略类一致。例如根据原后验定义一个有界函数，再使用匹配折扣的前后差。若直接奖励熵下降，却漏掉折扣或终端处理，通常是另一个内在动机目标，不应自动称作同策略塑形。它可能鼓励学习环境细节，但细节未必与原任务相关。

信念势的计算也依赖过滤模型。若每次模型更新后势函数随之变化，普通固定势望远镜推导需要重新检查；可以把时间或模型状态纳入势定义，并保证相邻项真正使用一致对象。随训练参数任意改变奖励，可能改变实际优化目标。方法可以合理，但应准确描述其变化，而不是用固定势定理包办所有动态奖励。

<a id="pomdp-4-detail-66"></a>

### 15.4 原始回报与塑形回报一起保存

训练日志至少分别记录原奖励、附加项与总奖励，并保留终止原因和初始状态。若只存总和，发现策略学会循环时很难判断收益来自哪里。评价应优先按照声明任务的原始目标，同时说明训练使用何种塑形；如果部署目标也变了，则应公开新目标，不把两者混为加速。

在小型环境里，策略枚举和候选轨迹能发现明显偏好漏洞。复杂环境无法穷举，可以建立特定反例族，例如等待、往返、重复触发、边界截断和奖励模型高分但任务未完成。反例没有穷尽保证，但比只看正常成功路径更有诊断力。每次奖励修改都应复查旧漏洞与新引入的策略机会。

<a id="pomdp-4-detail-67"></a>

## 16. 代理误差、稳健性与评价边界

<a id="pomdp-4-detail-68"></a>

### 16.1 有界奖励误差能保证什么

若同一信息与转移模型下，每步代理奖励与真实奖励差的绝对值不超过 $`\epsilon`$，折扣严格小于一，则任一固定策略的价值误差不超过 $`\frac{\epsilon}{(1-\gamma)}`$。比较代理最优策略与真实最优策略，可以用两次该界得到真实回报损失不超过 $`\frac{2\epsilon}{(1-\gamma)}`$。这是误差传播界，不保证实际代理满足全局误差上界。

有限固定时域则把几何级数改为有限和。折扣越接近一，长期小误差累计越明显。若代理在优化后进入的罕见区域误差无界，这种界就不能直接使用。离线平均误差小与全空间一致误差小是不同条件，优化器可能主动寻找代理高估的区域。奖励模型评价需要考虑这种分布变化。

<a id="pomdp-4-detail-69"></a>

### 16.2 平均成功与尾部失败

只报告平均回报可能掩盖少数高代价失败，也可能奖励在多数容易起点上表现好而放弃稀有状态。应按起始信念、来源、噪声、期限和可回答性分层，并记录失败类型。若目标包含风险约束，应在任务定义中表达，而不是事后看到极端案例才临时修改成功规则。

测试回合应独立重置隐藏状态、记忆与随机流。循环控制器若跨回合保留上一题提示，可能形成非预期信息；如果任务本来是持续交互，就应明确持续状态，而不是一会儿当独立回合、一会儿当连续任务。评价单位和重置协议是统计解释的重要部分。

<a id="pomdp-4-detail-70"></a>

### 16.3 历史长度与记忆消融

比较无记忆、固定窗口和信念策略时，应保持模型可见的奖励、动作历史和时间一致。若某基线看不到奖励而另一策略能看，差异不只来自记忆架构。可以构造提示距离逐渐增加的任务，观察何时固定窗口失去必要信息；也可保持距离不变增加观察噪声，区分记忆容量与推断质量。

精确信念策略在已知有限模型下是有价值参照，但真实模型未知时它可能享有额外参数知识。报告应明确这一点，不把它与从零学习策略的样本效率直接公平比较。理想参照用于分离信息与算法瓶颈，实际方法比较需要相同信息和资源条件。

<a id="pomdp-4-detail-71"></a>

### 16.4 反事实模型与任务真实性

模拟器可以让我们控制传感器、隐藏状态与奖励，建立清楚反例，但它的转移机制和噪声结构仍是人为假设。真实系统若不满足这些条件，策略可能失效。应先检验模型预测和可用信息，再讨论部署。当前人工枚举没有测真实机器人、在线服务或复杂感知，不应填入推测的速度与成功率。

可以逐步增加模型错设：相关报告、状态缓慢变化、迟到观察和错误奖励实现。每次只改变一类因素，记录过滤校准、规划动作和最终回报，观察瓶颈转移。这样的路线让负结果也有解释力，而不是在复杂环境里只看到一个失败分数却不知道哪里出问题。

<a id="pomdp-4-detail-72"></a>

## 17. 更进一步的练习与解答

<a id="pomdp-4-detail-73"></a>

### 17.1 题十七：价值为什么是凸的

题目：有限隐藏状态、有限动作观察与有限时域下，最优信念价值为什么是分段线性凸函数？

解答：每棵固定策略树对应每个隐藏状态的期望回报向量，对初始信念线性。有限树集合取最大值，得到线性函数上包络，因而凸且分段线性。它不表示计算便宜，因为树数可能快速增长。模型未知或无限时域需要另外处理，不能把有限构造原样搬过去。

<a id="pomdp-4-detail-74"></a>

### 17.2 题十八：后验均值为何不偏向一侧

题目：静态隐藏位不断获得正确建模的新证据，后验概率在更新前的条件期望是多少？

解答：按全概率公式，对所有下一观察加权平均后，后验回到当前信念。证据会在不同分支推向不同方向，而非总体凭空增加某个状态概率。决策收益来自根据分支选择动作。若实验平均后验系统性偏离原先概率，应检查采样、归一化和条件分布是否一致。

<a id="pomdp-4-detail-75"></a>

### 17.3 题十九：奖励误差界的前提

题目：代理在测试平均误差很小，能否直接使用每步一致误差界证明策略损失很小？

解答：不能，平均误差不等于对所有相关状态动作的绝对误差界。策略优化可能进入代理高估区域，信息和转移条件也必须相同。可以报告已覆盖区域的误差与优化后新分布表现，但不能把局部验证扩大为全局保证。定理中的每个量都需要对应证据。

<a id="pomdp-4-detail-76"></a>

### 17.4 题二十：有界势与折扣一

题目：势始终在零到一之间，折扣为一的无限任务能否直接令尾项消失？

解答：不能，有界只说明尾项不发散，不说明它趋零或与策略无关。需要终止势为零、极限相同或其他额外条件。折扣小于一时的几何衰减是原证明关键，删掉它就要重新证明。不能因为公式看起来相似就继承结论。

<a id="pomdp-4-detail-77"></a>

### 17.5 题二十一：信息奖励与任务奖励

题目：智能体花很多资源学习与成功无关的传感器细节，信息熵确实下降，是否等于原任务更好？

解答：不等于。信息价值依赖未来动作和奖励，某些细节不改变最优决策。直接给信息增益奖励会改变取舍，除非满足明确的等价塑形条件。应同时报告原任务收益与观测成本，检查是否出现无用探索循环，而不只展示后验更确定。

<a id="pomdp-4-detail-78"></a>

### 17.6 题二十二：回合结束的审计

题目：策略在长度上限处停下，如何判断应算完成、失败还是截断？

解答：从任务协议判断，而不是从循环停止判断。自然完成有明确终止条件，任务到期可能附带失败或终端奖励，外部截断则保留原未来任务。分别记录停止原因、剩余目标与是否自举，指标按同一规则计算。否则奖励、规划与评价可能在优化三个不同问题。

<a id="pomdp-4-detail-79"></a>

### 17.7 题二十三：单独报成功率会漏什么

题目：两个监听策略都猜对八成，一个听一次，一个听十次，能否按成功率认定等价？

解答：不能，监听成本、折扣与期限使净回报不同，完成延迟和资源也不同。应同时报告正确率、折扣原回报、动作次数与终止原因。若任务只关心最终正确且观察免费，可以另定义相应协议，但不能在训练有成本时评价却忘记成本。比较事件和优化目标应保持一致。

<a id="pomdp-4-detail-80"></a>

### 17.8 题二十四：规划器知道模型的优势

题目：精确信念规划比从零学习策略好，能否直接说明它的学习算法样本效率更高？

解答：不能直接说明，因为规划器已经获得转移、传感准确率和奖励模型，而学习器可能还要估计这些量。应统一信息预算，或明确把精确模型结果作为理想参照。它有助于分离信息不足、模型估计和控制误差，不自动构成同条件方法比较。理论参照与可部署学习器的角色需要清楚区分。

本次塑形枚举中，原最优起点回报为一点零八，正确势差后为零点六八，恰好统一减初始势零点四；错误循环奖金选择的原任务回报仅零点一八。信息泄漏实验在旧信息策略类中最佳塑形回报为负零点零五，新增可见信号后为零点四。数值与路径代数都可复算，具体变化来源也因此能够分开定位。

<a id="pomdp-4-detail-81"></a>

## 18. 从精确反例走向研究问题

本章四段独立实验分别验证观察别名与 Bayes 更新、信念规划闭环、势函数与错误奖励、隐藏奖励信息扩展。它们将概率恒等式、策略最优性和信息结构分开处理，所有数据只在内存中生成。结果不依赖外部环境库，也没有用大模型评分器替代已知真值。

下一步可以选一个边界深入：有限记忆怎样逼近信念，未知模型怎样联合学习，动态势怎样维持明确目标，或代理奖励怎样在优化后保持可靠。每个问题先写清可见信息、随机过程、比较策略类和评价，再提出方法。这样新增内容会形成可验证的知识链，而不是把更多术语堆在一个无法判断的回报曲线上。
