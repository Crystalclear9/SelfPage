## 1. 贝叶斯更新究竟更新了什么

<a id="prob-3-detail-2"></a>

### 1.1 数据、参数和模型各有自己的位置

设数据为 $`D`$，参数为 $`\theta`$，模型假设为 $`M`$。贝叶斯公式写成

$$
\begin{aligned}
p(\theta\mid D,M) &=\frac{p(D\mid\theta,M)p(\theta\mid M)}{p(D\mid M)},\\[6pt]
p(D\mid M) &=\int p(D\mid\theta,M)p(\theta\mid M)\,d\theta.
\end{aligned}
$$

分子由似然和先验组成，分母是把分子对参数积分后的归一化常数。后验描述在这个模型以及所观察信息下，对参数取值的条件分布。它没有自动把模型假设也变成事实；当观测具有依赖、筛选或测量误差而似然忽略这些机制时，代数仍然可以完全正确，却回答了另一个问题。

似然是固定已经观察到的数据、把表达式视作参数函数。它不必对参数积分为一，也不能因为看起来像某种密度就直接当作后验。后验必须明确相对于什么参数坐标与测度定义。后面讨论 MAP 的参数化问题，正是因为密度高度会随着坐标体积改变，而某个事件的后验概率不会这样任意改变。

例如十次点击中有三次购买，用伯努利模型时，参数可以是每次独立机会的成功概率。若十次点击来自同一个人在一次购买前不断刷新，独立机会的假设就值得怀疑。把十行数据库记录当作十个独立证据，会夸大信息量。建模前先确定重复测量属于同一个人、会话还是设备，通常比更换一种先验更影响结论。

<a id="prob-3-detail-3"></a>

### 1.2 有序样本与计数样本的常数为什么不同

独立同分布的二元序列含 $`s`$ 次成功与 $`f`$ 次失败，特定顺序的概率为 $`\theta^s(1-\theta)^f`$。若只观察总成功数，二项概率还包含组合数 $`\binom{s+f}{s}`$。组合数不依赖参数，因此在同一个数据表示下推导后验可以约掉。两个写法会得到相同的参数后验，这依赖两者包含相同的参数信息。

但不能据此说所有常数都无关。计算某个数据事件的概率、模型证据或比较不同抽样空间时，常数可能决定答案。特定四次序列成功三次的概率，与四次中恰好成功三次的概率相差四倍。你必须先说要预测具体顺序还是总次数，再决定是否乘组合数。

停止规则、缺失和选择机制也应放进生成过程。固定观察十次与观察到第三次成功就停止，产生的数据空间不同。在适当的可忽略停止机制下，已经观察到的完整序列可能给出成比例似然；若停止依赖未记录结果、参数或选择性公布，忽略机制就未必成立。似然原则是有条件的推理原则，不能用来免除对数据怎样被看见的说明。

<a id="prob-3-detail-4"></a>

### 1.3 顺序更新是联合概率的分解

当两批数据给定参数条件独立时，先用第一批更新，再把所得后验当作第二批先验，等价于同时使用两批。原因是两次相乘得到同一个先验乘两批似然，归一化常数最后统一消去。这解释了贝叶斯学习可以顺序进行，并不意味着任何时候只保存一个均值就足够。

后验均值一般不是后验的充分表示。Beta 家族需要两个形状参数，高斯线性模型需要均值与协方差；复杂模型可能需要完整样本或近似分布。若只保留上次的点估计，再把它当新一轮确定参数，参数不确定性就被丢掉了。所谓在线贝叶斯，应说明传播的状态是什么、近似在哪一步发生。

## 2. Beta–Bernoulli：从密度到每一种摘要

<a id="prob-3-detail-6"></a>

### 2.1 共轭更新的逐行推导

对 $`0<\theta<1`$，取形状参数 $`a,b>0`$ 的 Beta 先验：

$$
\begin{aligned}
p(\theta) &=\frac{\theta^{a-1}(1-\theta)^{b-1}}{B(a,b)},\\[6pt]
B(a,b) &=\frac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}.
\end{aligned}
$$

乘上二元样本似然后，成功幂次变为 $`a+s-1`$，失败幂次变为 $`b+f-1`$，所以后验是 $`\operatorname{Beta}(a+s,b+f)`$。这叫共轭，因为更新后的分布仍属于先验家族。它是一种代数便利，不是“这个先验一定真实”的证明，也不意味着所有概率参数都必须选 Beta。

记后验参数为 $`A=a+s,B=b+f`$，其均值和方差为

$$
\begin{aligned}
\mu &=\frac{A}{A+B},\\[6pt]
v &=\frac{AB}{(A+B)^2(A+B+1)}=\frac{\mu(1-\mu)}{A+B+1}.
\end{aligned}
$$

均值的位置与浓度是两个独立维度。Beta(2,2) 与 Beta(200,200) 均值都为二分之一，后者却更集中。只报告一个成功率，无法说明现有证据与先验共同留下了多大参数不确定性。浓度越大，新增同样数量观测对均值的影响一般越小。

当 $`n=s+f>0`$ 时，后验均值还能写成先验均值与经验频率的加权平均：先验权重为 $`\frac{(a+b)}{(a+b+n)}`$，数据权重为 $`\frac{n}{(a+b+n)}`$。这里把 $`a+b`$ 视为均值收缩意义的信息量比较自然；若讨论后验众数，指数中的伪计数又是 $`a-1,b-1`$。伪计数解释依赖你解释的是哪个对象，不能混成一条万能口诀。

<a id="sec-1-1"></a>
<a id="prob-3-detail-7"></a>

### 2.2 均值、众数、中位数与最大似然不同

取先验 Beta(2,2)，观察三次成功和一次失败，后验为 Beta(5,3)。最大似然估计为四分之三，后验均值为八分之五，后验内部众数为三分之二。三个值没有互相矛盾：最大似然只优化观测拟合，均值是特定后验决策的最优摘要，众数寻找后验密度最高处。

内部众数公式 $`\frac{(A-1)}{(A+B-2)}`$ 只在 $`A>1,B>1`$ 时直接适用。若一个参数不大于一，密度峰值可能靠边界；两者都小于一时还可出现两端高、中间低的形状。不能把公式机械代入得到一个区间内数值，就宣布它一定是后验众数。边界处密度可能发散，参数空间是否包含端点也要说清。

后验中位数是把后验质量各分一半的位置，通常没有这么简单的闭式。对平方损失，均值最优；对绝对损失，中位数最优。若业务损失不对称，就可能需要其他分位数。把这些对象分别命名，能防止“贝叶斯估计”在一页里悄悄指代不同计算。

<a id="prob-3-detail-8"></a>

### 2.3 可信区间是条件概率陈述

一个百分之九十五等尾可信区间，可以由后验的百分之二点五和九十七点五分位数给出。在模型与先验成立的条件下，给定已经观察到的数据，参数后验落在该区间的概率为百分之九十五。它与频率置信区间关于重复抽样覆盖率的定义不同；某些情形数值接近，并不消除解释上的差别。

等尾区间不一定最短，高密度可信集合也不一定是一个连通区间。对于边界偏斜或多峰后验，只报告“均值加减两倍标准差”可能越出合法范围或遮住多峰结构。报告区间时应说明构造方式，必要时保留分位数、密度形状和对业务事件的直接后验概率。

下面把手算、数值积分、顺序更新和分位数放在一个独立实验中。积分是小维度参考，不是高维模型的通用计算方案。示例使用 SciPy 的 Beta 接口；其形状参数和分位数定义见[官方分布文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.beta.html)。

```python
import numpy as np
from scipy.integrate import quad
from scipy.stats import beta

prior_a, prior_b = 2.0, 2.0
success, failure = 3, 1
a, b = prior_a + success, prior_b + failure
assert (a, b) == (5.0, 3.0)
assert np.isclose(beta.mean(a, b), 5 / 8)
assert np.isclose((a - 1) / (a + b - 2), 2 / 3)
normalizer = quad(lambda p: p ** (a - 1) * (1 - p) ** (b - 1), 0, 1)[0]
mean_by_integral = quad(
    lambda p: p ** a * (1 - p) ** (b - 1), 0, 1
)[0] / normalizer
assert np.isclose(mean_by_integral, 5 / 8)
lo, hi = beta.ppf([0.025, 0.975], a, b)
assert 0 < lo < 5 / 8 < hi < 1
assert np.isclose(beta.cdf(hi, a, b) - beta.cdf(lo, a, b), 0.95)
first_batch = (prior_a + 2, prior_b + 1)
second_batch = (first_batch[0] + 1, first_batch[1])
assert second_batch == (a, b)
print("posterior", (a, b), "mean", mean_by_integral,
      "equal-tail interval", (lo, hi))
```

## 3. 后验预测：一次、次数与整段未来

<a id="sec-2-1"></a>
<a id="prob-3-detail-10"></a>

### 3.1 单次预测为何恰好等于后验均值

后验预测的基本式为 $`p(y_*\mid D)=\int p(y_*\mid\theta)p(\theta\mid D)d\theta`$。在 Bernoulli 模型中，下一次成功的条件概率就是 $`\theta`$，所以积分等于 $`E[\theta\mid D]`$。这是似然关于参数的特殊线性关系，不能推广成“所有模型只需代入后验均值”。

对非线性条件均值，通常有 $`E[g(\theta)\mid D]\ne g(E[\theta\mid D])`$。即使预测均值偶然相同，预测分布的方差、尾部和多个未来事件之间的关系也未必相同。评价完整概率预测时，需要关注整个分布或与决策有关的事件概率，而不只是比较一个均值。

单次二元结果的预测方差为 $`\mu(1-\mu)`$。全方差分解得到 $`E[\theta(1-\theta)\mid D]+\operatorname{Var}(\theta\mid D)`$，两项相加恰好也是这个值。因此两个后验只要均值相同，单次二元预测就相同，即使参数后验宽度不同。参数不确定性要通过多次共同预测或参数区间，才能显露更多结构。

<a id="deep-dive-2"></a>
<a id="prob-3-detail-11"></a>

### 3.2 给定参数独立，积分后为什么相关

设两个未来结果 $`Y_1,Y_2`$ 给定同一个参数后条件独立。它们共同成功的概率是 $`E[\theta^2\mid D]`$，而分别成功概率的乘积是 $`E[\theta\mid D]^2`$，差值正好为后验方差。于是预测协方差为 $`v`$，在非退化后验下严格为正。这不是违反独立假设，而是条件独立与边缘独立的区别。

以 Beta(2,2) 后验为例，单次成功概率是二分之一，两次共同成功概率为十分之三，超过四分之一。观察未来第一次成功后，会进一步提高对共同参数的判断，因而第二次成功也变得更可信。这种关联来自共享未知参数，并不要求两次试验之间有直接因果影响。

如果每次未来试验都重新独立抽取一个不同参数，则联合预测结构改变。这对应另一个层级模型。模拟代码里“先抽一个参数，再生成整批”与“每生成一个结果就重抽参数”，不能随意互换。它们可能有相同的单次边缘，却有不同的批次波动与极端事件概率。

<a id="sec-6-1"></a>
<a id="prob-3-detail-12"></a>

### 3.3 Beta–Binomial 的额外波动从哪里来

令未来 $`m`$ 次成功总数为 $`K`$。给定参数时 $`K\mid\theta\sim\operatorname{Binomial}(m,\theta)`$，积分后

$$
p(K=k\mid D)=\binom{m}{k}\frac{B(A+k,B+m-k)}{B(A,B)}.
$$

其均值为 $`m\mu`$，方差由全方差公式得到

$$
\operatorname{Var}(K\mid D)=m\mu(1-\mu)+m(m-1)v.
$$

第一项是把后验均值当固定概率时的二项方差，第二项是共享参数不确定性产生的额外波动。未来批次越大，第二项越可能重要。单次点预测很好，并不意味着可以用固定概率二项分布评价批次产能、连续失败或尾部风险。

例如后验 Beta(2,2)，预测十次，均值为五。固定概率二项方差为二点五；后验方差为零点零五，额外项为四点五，总方差为七。相同均值对应明显不同的风险。下面用解析式、分布接口和分层模拟三种方式交叉核对；随机模拟只使用较宽的数值容差，不要求某台机器逐位复现。

```python
import numpy as np
from scipy.special import betaln, gammaln
from scipy.stats import betabinom, binom

rng = np.random.default_rng(20261017)
a, b, m = 2.0, 2.0, 10
mu = a / (a + b)
v = a * b / ((a + b) ** 2 * (a + b + 1))
k = np.arange(m + 1)
log_choose = gammaln(m + 1) - gammaln(k + 1) - gammaln(m - k + 1)
prob = np.exp(log_choose + betaln(a + k, b + m - k) - betaln(a, b))
assert np.allclose(prob, betabinom.pmf(k, m, a, b))
assert np.isclose(prob.sum(), 1)
assert np.isclose((k * prob).sum(), m * mu)
expected_variance = m * mu * (1 - mu) + m * (m - 1) * v
assert np.isclose(((k - m * mu) ** 2 * prob).sum(), expected_variance)
assert np.isclose(expected_variance, 7.0)
assert expected_variance > binom.var(m, mu)
p = rng.beta(a, b, size=100000)
counts = rng.binomial(m, p)
assert abs(counts.mean() - 5) < 0.06
assert abs(counts.var() - 7) < 0.15
print("predictive mean/variance", counts.mean(), counts.var())
```

这里模拟的是许多可能的未来批次，每个批次共享一次参数抽样。不能把这些批次的额外波动解释成真实系统已经被证明存在某种个体间异质性；它首先是当前模型下对共同参数未知程度的表达。若真实成功概率随时间改变，还需要把变化机制放进模型，而不是把所有偏差都交给一个固定参数的宽后验吸收。

## 4. 点估计必须与损失和参数化一起解释

<a id="prob-3-detail-14"></a>

### 4.1 后验决策为什么推出均值与分位数

设动作是报告数值 $`d`$，损失为 $`(d-\theta)^2`$。后验期望损失展开为 $`(d-E[\theta\mid D])^2+\operatorname{Var}(\theta\mid D)`$，第二项与动作无关，所以均值最优。这个结论来自损失的结构，不是均值天生比其他摘要高级。若后验没有有限二阶矩，还要重新检查期望损失是否定义良好。

对绝对损失，在后验一阶绝对矩有限等可积条件下，把积分按参数是否小于动作拆开，导数或次梯度由两侧后验质量决定，最优点是中位数。若一阶绝对矩无限，所有有限动作的原始绝对风险都可能为无穷，此时应先定义有限风险差或改用其他决策目标。对低估与高估代价不相等的分段线性损失，最优动作成为某个后验分位数。库存、风险准备金和服务容量往往关心高分位尾部，把后验均值直接作为容量可能系统性低估短缺成本。

分类决策同样应在后验预测上比较动作损失。若误报代价为 $`c_{10}`$、漏报代价为 $`c_{01}`$，正确决策代价为零，预测正类概率为 $`q`$，报正的期望损失为 $`c_{10}(1-q)`$，报负为 $`c_{01}q`$。报正的阈值是 $`\frac{c_{10}}{(c_{10}+c_{01})}`$。这个公式还假设成本固定、没有额外容量约束，且概率指向目标人群的可用预测。

<a id="prob-3-detail-15"></a>

### 4.2 MAP 与 L2 的系数需要从目标推出

在高斯回归 $`y\mid w\sim N(Xw,\sigma^2I)`$ 与先验 $`w\sim N(0,\tau^2I)`$ 下，去掉与权重无关常数，负对数后验为

$$
\frac{\Vert y-Xw\Vert ^2}{2\sigma^2}+\frac{\Vert w\Vert ^2}{2\tau^2}.
$$

若把数据项写成半均方误差 $`\frac{\Vert y-Xw\Vert ^2}{(2n)}`$，惩罚写成 $`\frac{\lambda\Vert w\Vert ^2}{2}`$，两边同乘 $`\frac{\sigma^2}{n}`$ 得 $`\lambda=\frac{\sigma^2}{(n\tau^2)}`$。若目标使用误差平方和或其他平均约定，系数随之改变。损失函数名字相同并不保证先验强度相同。

特征单位也会影响含义。把某列由米改成厘米，对应系数需要缩小一百倍；若仍给所有系数相同数值的先验方差，函数空间中的约束就变了。合理操作是同时变换先验，或先明确标准化协议并在训练数据内拟合。截距是否惩罚也需单独说明，它并不自动和其他权重具有相同先验解释。

MAP 在这里与岭解一致，只是特定模型的点摘要等价。岭算法给出一个向量，并没有自动输出权重后验协方差、未来噪声或模型证据。若需要这些对象，必须继续完成概率推导。反过来，某个优化器包含权重衰减，也不代表它在所有设置下精确求解上述后验众数。

<a id="prob-3-detail-16"></a>

### 4.3 非线性换坐标为什么改变密度峰值

令 $`\eta=\log(\frac{\theta}{(1-\theta)})`$，则 $`\frac{d\theta}{d\eta}=\theta(1-\theta)`$。同一个后验概率分布，在对数几率坐标中的密度为 $`p_\eta(\eta)=p_\theta(\theta)\theta(1-\theta)`$。对 Beta(A,B)，原坐标密度正比于 $`\theta^{A-1}(1-\theta)^{B-1}`$，新坐标密度正比于 $`\theta^A(1-\theta)^B`$。

当参数都大于一，原坐标众数为 $`\frac{(A-1)}{(A+B-2)}`$，新坐标密度峰值对应的概率却为 $`\frac{A}{(A+B)}`$。Beta(5,3) 的两者分别为三分之二与八分之五。事件概率完全没有变，变化的是单位坐标体积如何分配。这说明 MAP 需要声明参数化，不能被解释成与坐标无关的“最真实参数”。

后验积分具有相应的变换一致性：按变量替换正确带入雅可比，某个可观察事件的预测概率不变。可信集合也可整体变换并保留质量，但在原坐标里最高密度的集合，变换后未必仍具有新坐标最高密度的性质。几何形状、概率质量与密度高度需要分别理解。

<a id="prob-3-detail-17"></a>

## 5. 连续观测：高斯均值与未知方差

<a id="prob-3-detail-18"></a>

### 5.1 已知噪声时用精度相加完成平方

设 $`Y_i\mid\mu\sim N(\mu,\sigma^2)`$，噪声方差已知，先验 $`\mu\sim N(m_0,v_0)`$。负二倍对数后验中关于均值的项是 $`\mu^2(\frac{1}{v_0}+\frac{n}{\sigma^2})-2\mu(\frac{m_0}{v_0}+\sum_i\frac{y_i}{\sigma^2})`$。完成平方得到

$$
\begin{aligned}
v_n &=\left(v_0^{-1}+n\sigma^{-2}\right)^{-1},\\[6pt]
m_n &=v_n\left(\frac{m_0}{v_0}+\sum_i\frac{y_i}{\sigma^2}\right).
\end{aligned}
$$

这里相加的是精度，即方差的倒数；噪声越小的一批数据贡献越大。简单把先验均值与样本均值各占一半，只有在二者精度恰好相等时才成立。连续顺序更新可以保存精度和精度加权均值，不必保留所有旧数据，但这个便利依赖已知噪声、条件独立与共同均值假设。

若先验均值为零、方差为四，噪声方差为一，观察到一与二，先验精度是四分之一，数据精度合计为二，所以后验方差为 $`v_n=\frac{1}{(\frac{1}{4}+2)}=\frac{4}{9}`$。精度加权和为三，因此后验均值为 $`m_n=(\frac{4}{9})×3=\frac{4}{3}`$。它介于先验中心零与样本均值一点五之间。先核对精度、再核对均值的范围，可以避免把先验方差直接当作加权系数。

<a id="prob-3-detail-19"></a>

### 5.2 潜在均值区间与新观测区间

对一个新观测，积分均值后有 $`Y_*\mid D\sim N(m_n,\sigma^2+v_n)`$。其中 $`v_n`$ 表示均值未知，$`\sigma^2`$ 表示即使均值已知仍存在的观测波动。给均值的可信区间与给下一观测的预测区间因此不同。随着数据增加，前者可收缩，后者在噪声固定时仍保留不可消除宽度。

对两个未来观测，预测协方差为 $`v_n`$。若预测未来样本均值，方差为 $`v_n+\frac{\sigma^2}{m}`$，并非 $`\frac{(v_n+\sigma^2)}{m}`$。共同均值的不确定性不会因为把同一个未来批次的观测平均一下就全部消失。这个结论与前面的 Beta–Binomial 共享参数结构相呼应。

若目标是一个新群体或新的时间制度，仍用同一个均值可能不合理。后验变窄只说明在当前假设下参数更明确，不能保证外推到新群体的误差同样变小。预测对象改变时，先更新生成模型，再讨论积分是否精确。

<a id="prob-3-detail-20"></a>

### 5.3 未知噪声带来 Student t 预测

当均值和方差都未知，可取 $`\sigma^2\sim\operatorname{InvGamma}(\alpha_0,\beta_0)`$，并令 $`\mu\mid\sigma^2\sim N(m_0,\frac{\sigma^2}{\kappa_0})`$。这里逆 Gamma 密度与 $`(\sigma^2)^{-(\alpha_0+1)}\exp(-\frac{\beta_0}{\sigma^2})`$ 成正比，所有超参数为正。形状、尺度约定必须写清，以免和倒数或率参数混用。

观察均值为 $`\bar y`$，样本数为 $`n`$，后验参数为

$$
\kappa_n=\kappa_0+n,\quad m_n=\frac{\kappa_0m_0+n\bar y}{\kappa_n},\quad
\alpha_n=\alpha_0+\frac{n}{2},
$$

$$
\beta_n=\beta_0+\frac12\sum_i(y_i-\bar y)^2+
\frac{\kappa_0n}{2\kappa_n}(\bar y-m_0)^2.
$$

最后一项记录数据均值与先验中心不一致产生的额外不确定性，遗漏它会低估方差。积分均值和方差后，新观测服从自由度 $`2\alpha_n`$、位置 $`m_n`$、尺度平方 $`\frac{\beta_n(\kappa_n+1)}{(\alpha_n\kappa_n)}`$ 的 Student t 分布。这个尺度不是方差：自由度大于二时，方差还要乘自由度除以自由度减二。

下面通过分层抽样核对预测均值、方差与分位数。实验选取矩存在的超参数，避免用有限模拟方差为理论上不存在的矩背书。更小的自由度可以产生不存在方差甚至均值的预测，这时应使用分位数和尾部概率描述。

```python
import numpy as np
from scipy.stats import t

rng = np.random.default_rng(47)
y = np.array([1.0, 2.0, 2.5, 0.5])
k0, m0, a0, b0 = 1.0, 0.0, 3.0, 2.0
n, mean = y.size, y.mean()
k = k0 + n
m = (k0 * m0 + n * mean) / k
a = a0 + n / 2
b = b0 + 0.5 * np.sum((y - mean) ** 2) + k0 * n * (mean - m0) ** 2 / (2 * k)
df = 2 * a
scale = np.sqrt(b * (k + 1) / (a * k))
sigma2 = 1 / rng.gamma(shape=a, scale=1 / b, size=150000)
mu = rng.normal(m, np.sqrt(sigma2 / k))
future = rng.normal(mu, np.sqrt(sigma2))
assert abs(future.mean() - m) < 0.025
assert abs(future.var() - t.var(df, loc=m, scale=scale)) < 0.06
assert np.allclose(np.quantile(future, [0.1, 0.5, 0.9]),
                   t.ppf([0.1, 0.5, 0.9], df, loc=m, scale=scale), atol=0.04)
print("posterior parameters", (k, m, a, b), "predictive df/scale", (df, scale))
```

**Student t 是怎样从积分中出现的。** 上面的参数更新可以由同一个平方分解得到：

$$
\sum_i(y_i-\mu)^2+\kappa_0(\mu-m_0)^2
=\sum_i(y_i-\bar y)^2+
\frac{\kappa_0n}{\kappa_n}(\bar y-m_0)^2+
\kappa_n(\mu-m_n)^2.
$$

这先产生条件后验 $`\mu\mid\sigma^2,D\sim N(m_n,\frac{\sigma^2}{\kappa_n})`$，再产生方差边缘后验 $`\sigma^2\mid D\sim\operatorname{InvGamma}(\alpha_n,\beta_n)`$。这里要先识别两个不同分布，不能把联合密度中关于方差的幂次直接当成边缘逆 Gamma 的形状；对均值积分还会带来一个平方根方差因子。

令 $`s=\sigma^2`$、$`c=1+\frac{1}{\kappa_n}`$。先把均值积分掉，则 $`Y_*\mid s,D\sim N(m_n,cs)`$。将它与方差后验相乘，再对 $`s>0`$ 积分，得到

$$
p(y_*\mid D)=
\frac{\beta_n^{\alpha_n}}{\Gamma(\alpha_n)\sqrt{2\pi c}}
\int_0^\infty s^{-(\alpha_n+\frac{3}{2})}
\exp\left[-\frac{\beta_n+\frac{(y_*-m_n)^2}{(2c)}}s\right]ds.
$$

对一般的 $`a,b>0`$，代换 $`u=\frac{b}{s}`$ 给出
$`\int_0^\infty s^{-a-1}e^{-\frac{b}{s}}ds=\frac{\Gamma(a)}{b^a}`$。取 $`a=\alpha_n+\frac{1}{2}`$ 并整理常数，可得

$$
p(y_*\mid D)=
\frac{\Gamma(\alpha_n+\frac{1}{2})}{\Gamma(\alpha_n)\sqrt{2\pi\beta_nc}}
\left[1+\frac{(y_*-m_n)^2}{2\beta_nc}\right]^{-(\alpha_n+\frac{1}{2})}.
$$

与标准 Student t 密度逐项对照，便有自由度 $`\nu=2\alpha_n`$、尺度平方 $`s_t^2=\frac{\beta_nc}{\alpha_n}`$。厚尾来自方差混合：方差后验仍给较大噪声一定质量，积分以后不能继续用单个正态尾部代替。这里的混合不是把若干方差先求平均，再只生成一个正态分布。

前面代码的观测均值为 $`1.5`$、组内平方和为 $`2.5`$，因此更新得到 $`\kappa_n=5,m_n=1.2,\alpha_n=5,\beta_n=4.15`$。于是 $`c=1.2`$，预测自由度为十，尺度平方为 $`0.996`$，但预测方差是 $`0.996\times\frac{10}{8}=1.245`$。还可用全方差独立复核：$`E[s\mid D]=\frac{4.15}{(5-1)}=1.0375`$，加上均值参数方差 $`\frac{E[s\mid D]}{5}=0.2075`$，合计正好为 $`1.245`$。两个推导在同一数值上闭合，才说明没有把尺度、方差和参数不确定性混在一起。

## 6. 贝叶斯线性回归：从点到整个函数

<a id="prob-3-detail-22"></a>

### 6.1 完成平方得到多元后验

设权重先验为 $`N(m_0,S_0)`$，噪声方差 $`\sigma^2>0`$ 已知，且 $`S_0`$ 正定。观测 $`y\mid w\sim N(Xw,\sigma^2I)`$。展开二次型后，后验精度和均值满足

$$
\begin{aligned}
\Lambda_n &=S_0^{-1}+\frac{X^TX}{\sigma^2},\\[6pt]
S_n &=\Lambda_n^{-1},\\[6pt]
m_n &=\Lambda_n^{-1}(S_0^{-1}m_0+\frac{X^Ty}{\sigma^2}).
\end{aligned}
$$

数值实现应用线性求解和分解，而不是在所有位置显式求逆。公式中的逆表达数学对象，代码中的求解表达稳定计算。正定先验能使后验精度正定，即使设计矩阵列相关；这并不证明数据已经辨认每个方向，某些方向仍可能主要由先验决定。

当先验均值为零且协方差为 $`\tau^2I`$，后验均值也是后验众数，并与具有相应系数的岭解一致。高斯后验对称单峰使这两个摘要相等；对一般模型不成立。后验协方差还包含方向关系，独立看每个权重区间会忽略相关性。两个权重各自变化很大，但某种线性组合可能已被数据精确确定。

<a id="prob-3-detail-23"></a>

### 6.2 联合预测协方差为什么不能丢

对新设计矩阵 $`X_*`$，潜在无噪声均值的后验为 $`N(X_*m_n,X_*S_nX_*^T)`$。若各新观测另有独立相同噪声，则预测协方差再加 $`\sigma^2I`$。矩阵的非对角项来自共同权重；只分别抽取每个位置的边缘预测，会丢掉整条预测曲线的联合结构。

计算一个线性汇总时，方差应为 $`c^T\Sigma_*c`$，包括协方差项，而不是只把各位置方差相加。例如预测一片区域的总需求或两个点的差值，协方差可以显著增加或减少不确定性。对于同时覆盖多点的带状区域，逐点百分之九十五区间也不能自动保证整条曲线百分之九十五落入。

下面比较批量公式与逐观测精度更新，并用权重抽样核对联合预测协方差。测试有意使用两个不同新输入，让非对角项成为可见对象；只在一个点上验证均值，无法检测遗漏联合结构的问题。

```python
import numpy as np

rng = np.random.default_rng(83)
x = np.array([-1.0, 0.0, 1.0, 2.0])
X = np.column_stack([np.ones(x.size), x])
y = np.array([-0.8, 0.1, 1.2, 1.8])
sigma2, tau2 = 0.25, 4.0
P0 = np.eye(2) / tau2
P = P0 + X.T @ X / sigma2
h = X.T @ y / sigma2
mean = np.linalg.solve(P, h)
cov = np.linalg.solve(P, np.eye(2))
Ps, hs = P0.copy(), np.zeros(2)
for row, value in zip(X, y):
    Ps += np.outer(row, row) / sigma2
    hs += row * value / sigma2
assert np.allclose(np.linalg.solve(Ps, hs), mean)
assert np.allclose(Ps, P)
Xnew = np.array([[1.0, 0.5], [1.0, 2.5]])
latent_cov = Xnew @ cov @ Xnew.T
predict_cov = latent_cov + sigma2 * np.eye(2)
weights = rng.multivariate_normal(mean, cov, size=120000)
latent = weights @ Xnew.T
observed = latent + rng.normal(0, np.sqrt(sigma2), size=latent.shape)
assert np.allclose(np.cov(latent, rowvar=False), latent_cov, atol=0.004)
assert np.allclose(np.cov(observed, rowvar=False), predict_cov, atol=0.008)
assert abs(latent_cov[0, 1]) > 1e-4
print("weight mean", mean, "predictive covariance", predict_cov)
```

### 6.3 外推、特征变换与模型限制

预测不确定性随输入方向变化，是线性模型中重要的几何现象。训练设计没有充分覆盖的方向，$`x_*^TS_nx_*`$ 可能较大；但若模型不允许真实存在的非线性，后验也可能在错误的函数族里变得非常确定。区间反映给定模型的参数与噪声，不自动覆盖模型错设、测量偏差和部署机制改变。

加入多项式特征能扩大函数族，却改变先验在函数上的含义。高阶特征在远处可能迅速放大，即使系数先验方差不大，也会产生极端预测。应在真正关心的输入范围进行先验预测，观察生成函数的尺度、平滑性与尾部行为。先验应通过可观察量解释，而不仅是说每个参数都“接近零”。

若噪声本身随输入改变，固定同方差模型会把部分异方差误归给权重不确定性。可比较残差随输入、预测均值与群体的变化，再考虑方差模型。不能仅因为贝叶斯方法输出区间，就跳过诊断残差和预测覆盖的工作。

## 7. 先验不是形式附件：先检查它生成什么

<a id="prob-3-detail-26"></a>

### 7.1 从概率尺度与业务范围提出约束

选择先验时，先问参数如何影响可观察量。对一个成功概率，可以讨论哪些范围较可信、接近边界是否合理，以及已有知识相当于多强证据。对回归斜率，应把输入变化多少对应输出变化多少说清楚。给标准差和给方差相同名字的分布，不代表同一个先验；更换单位后不调整先验，也会改变模型。

弱信息先验不等于所有数值都给巨大方差。在非线性链接下，巨大系数方差可能让预测几乎全部挤在零与一，反而形成很强的函数偏好。在层级模型中，尺度先验还会决定群体间差异与收缩强度。先从先验抽参数，再生成与真实设计相同尺度的数据，观察极端值、相关、组间差异和零值比例，通常比盯着参数密度更直观。

先验预测检查使用尚未由当前数据更新的模型来表达哪些数据世界合理。它可以发现单位错误、过强约束与荒谬尾部，但不能用于保证真实世界一定落在模型里。若根据同一数据反复调整先验直到拟合满意，应说明这是模型开发过程，并用独立数据评价最终预测；否则把事后选择包装成事先知识，会夸大证据。

<a id="prob-3-detail-27"></a>

### 7.2 适当先验、非适当先验与边界

适当先验的积分为一。某些形式上均匀的非适当先验，在参数后验可归一时可以用于特定推断，但不能把它无条件当作普通概率分布进行先验预测。后验是否适当还要逐模型检查，参数过多、数据退化或不可识别时，似然未必能补足先验缺失的约束。

用非适当先验计算模型证据尤其危险，因为任意乘法常数会改变所谓证据，从而改变模型比较结果。即使两个模型的参数后验都能归一，也不能直接认为它们的 Bayes 因子已经定义。若确实要比较，应使用有明确概率含义的先验与一致的数据表示，或采用适合该问题的预测评价方式。

对 Beta 先验，形状参数必须严格为正。把零零当成“完全没有先验”并不能得到普通 Beta 分布；在全成功或全失败样本下，还可能产生不可归一的后验。默认超参数不是无哲学负担的开关，应给出选择理由、边界案例与敏感性范围。

<a id="prob-3-detail-28"></a>

### 7.3 先验敏感性应比较结论而非只比较参数

选择几个在观测前都能辩护的先验，比较关键事件概率、决策与预测区间。后验均值略变但决策不变，可能表示当前动作较稳健；均值变化很小却跨过决策阈值，则业务结论可能敏感。敏感性分析应围绕真正要使用的量，而不是机械地列出十种先验名称。

还要区分先验中心变化与强度变化。Beta(1,1)、Beta(10,10) 中心相同但证据强度不同，Beta(8,2) 则同时改变中心。一次实验同时改变两者，不容易判断哪个因素驱动结果。可以固定中心比较浓度，再固定浓度比较中心，最后说明数据量增加时各结论如何变化。

<a id="prob-3-detail-29"></a>

## 8. 后验预测检查：推断很准也可能模型不对

<a id="prob-3-detail-30"></a>

### 8.1 复制数据，而不是复制一个参数均值

后验预测检查先从参数后验抽样，再在相同设计下生成复制数据，最后比较与问题有关的统计量。检查均值只能检验均值层面的表现，不能代替对方差、零比例、最长连续段、尾部和群体差异的检查。统计量应对应模型承诺与潜在失效机制，不能在看到无数结果后只挑最惊人的一个。

复制的单位需要匹配生成过程。如果参数代表全局成功率，一次复制数据集应共享一次抽出的参数；若存在每用户随机效应，应保留真实用户结构。为了检查新用户预测，则要抽新的群体效应，而非继续使用已观察用户的后验。已知组内预测、新组预测与边际总体预测，是不同任务。

[Stan 的预测检查文档](https://mc-stan.org/docs/stan-users-guide/posterior-predictive-checks.html)提供了相应计算接口。本章在标准库与 NumPy 中直接实现一个小型反例：单一 Poisson 模型可以解释均值，却无法解释大量零值和少量大计数带来的离散程度。计算后验没有错，问题出在单一强度的采样假设。

<a id="prob-3-detail-31"></a>

### 8.2 实验：相同均值不能掩盖过度离散

取四十条观测，其中三十个零和十个十二，样本均值为三。Poisson 假设把条件均值与条件方差绑定为同一个强度。取形状为二、率为一的 Gamma 先验，后验形状为二加总计数，率为一加样本数。参数虽有剩余不确定性，但对同一批复制数据的样本方差，其期望主要仍对应后验平均强度，而不是观察到的巨大离散。

```python
import numpy as np

rng = np.random.default_rng(91)
y = np.array([0] * 30 + [12] * 10)
a, rate = 2.0 + y.sum(), 1.0 + y.size
lam = rng.gamma(a, scale=1 / rate, size=8000)
replicated = rng.poisson(lam[:, None], size=(lam.size, y.size))
observed_variance = y.var(ddof=1)
replicated_variance = replicated.var(axis=1, ddof=1)
assert np.isclose(y.mean(), 3.0)
assert observed_variance > 8 * a / rate
assert abs(replicated.mean() - a / rate) < 0.04
assert np.mean(replicated_variance >= observed_variance) < 0.01
assert abs(replicated_variance.mean() - a / rate) < 0.1
print("observed variance", observed_variance,
      "replicated average variance", replicated_variance.mean())
```

结果支持“这个模型遗漏了离散结构”，不唯一支持某一种替代解释。混合群体、时变强度、额外零机制和依赖都可能产生类似现象。下一步应结合数据来源提出竞争模型，并检查它们在任务有关统计量上的表现。仅把先验调得很宽，不一定能够修复每个观测之间共享单一强度的限制。

<a id="prob-3-detail-32"></a>

### 8.3 预测检查、留出评价与计算校验分开

同一数据既用于后验拟合，又用于预测检查，其尾部比较不是普通独立零假设检验，不能自动解释成具有标准均匀分布的频率 p 值。它是模型诊断工具。独立留出或交叉验证则评价对未用于拟合的观测预测得怎样；比较方式仍应匹配用户、时间与群体结构。

计算校验回答的是实现有没有正确逼近所定义的后验。共轭模型可与积分或解析解核对，MCMC 可检查链混合与有效样本量，模拟校准可在模型自身生成的数据上检查推断程序。它们不等同于检查真实数据模型是否正确。一个实现可以完美通过模型内校验，却在真实世界中系统性错设。

<a id="visual-example-probabilisticmodels-03"></a>

![匹配均值仍可能错过计数数据的离散程度](images/03-example.svg)

把四个观测视为一个手算检查样本，均值为二，以样本数为分母的方差为四，零值比例为一半。Poisson 均值二的理论均值也为二，但方差和零值比例与样本摘要不同。图只是提出需要检查的结构，并非四个数据足以拒绝 Poisson 模型的统计检验；有限样本摘要本身会波动。正式后验预测检查应重复抽取参数和整份复制数据，在同样设计下比较统计量分布，而不只把一个插件参数的理论值与样本值机械相减。

## 9. 模型证据与预测评价各自回答什么

<a id="prob-3-detail-34"></a>

### 9.1 证据是先验加权的平均拟合

模型证据 $`p(D\mid M)`$ 对参数先验积分似然，而不是选最好参数后代入。参数空间中只有很窄区域能拟合数据时，积分会受到先验质量分配影响。这常被解释为自动权衡灵活性，但权衡程度依赖先验，并非一种没有选择的客观复杂度罚项。

对 Beta–Bernoulli 的特定有序序列，证据为 $`\frac{B(a+s,b+f)}{B(a,b)}`$；若数据事件是成功总数，还要乘二项组合数。比较同一数据事件的两个模型，公共常数可以约去；把一个模型的有序序列证据与另一个模型的计数证据直接相比，则是在比较不同事件。写出样本空间是模型比较的必要准备。

连续数据证据是密度而非无单位概率，改变观测单位会改变密度数值；在同样观测变换和相同样本空间下比较模型时，应一致带入雅可比。任意省略某个模型的归一化常数，可能让比较完全错误。参数后验优化中可忽略的常数，不一定在模型比较中还能忽略。

<a id="prob-3-detail-35"></a>

### 9.2 Bayes 因子与部署指标不能互相替代

两模型证据之比叫 Bayes 因子，与先验模型赔率相乘得到后验模型赔率。它评价的是各模型连同先验对已观察数据的概率承诺。部署任务若关心特定群体的召回、容量或决策成本，仍应计算相应后验预测与损失，不能只把证据较大的模型宣布成所有任务中最好。

留出对数预测密度按测试对象累计，目标是未见数据预测。若测试包含新群体，应按群体留出；若部署是时间前推，应按时间评价。随机拆分每条记录可能让同一人的后验信息进入测试，得到较好分数但不对应新用户问题。先验、模型选择和划分策略都属于需要记录的协议。

序贯分解 $`p(D)=\prod_t p(y_t\mid y_{<t})`$ 把证据写成连续预测的乘积，但其每步可见信息与任意交叉验证不同。交换顺序不改变在相应独立模型下完整联合证据，不意味着每步预测难度相同。若研究真实时间过程，还需保持训练窗口、漂移与可见信息一致。

<a id="prob-3-detail-36"></a>

## 10. 近似推断：误差来自哪一层

<a id="prob-3-detail-37"></a>

### 10.1 蒙特卡洛平均应平均正确的对象

若有后验样本 $`\theta^{(r)}`$，事件概率可用条件概率 $`p(A\mid\theta^{(r)})`$ 的平均估计；也可每次生成一个未来结果再统计事件。前者通常避免额外模拟噪声，但必须能够计算所需条件概率。二者都需要后验样本代表目标分布，抽样数量大不能弥补链始终停在错误区域。

预测对数密度应先平均各样本的密度，再取对数。平均各自对数密度得到另一个量，由对数凹性通常更小。数值上应使用 log-sum-exp 减去样本数的对数，防止极小密度下溢。比较模型时，若一方错误地平均对数，可能把参数不确定性本身当作额外惩罚而改变排名。

<a id="prob-3-detail-38"></a>

### 10.2 Laplace 与变分近似留下不同风险

Laplace 近似在一个后验众数附近，用负对数后验的局部曲率构造高斯。它依赖局部可微与合适曲率；边界、长尾、多峰和不可识别方向会削弱这种近似。更换参数化可能改善几何，却不能自动让所有后验变成单峰高斯。应将近似与低维积分、模拟或可识别的预测量对照。

变分推断在选定分布族内优化目标。即使目标收敛，分布族可能漏掉相关和多峰；使用某一方向 KL 的目标也具有特定偏好。不要把优化器停止等同于后验不确定性准确。计算速度、点预测和尾部事件准确度应分别评价，必要时使用更丰富近似或抽样方法。

MCMC 的名义样本数与某个统计量的有效样本量不同。通常的正自相关会增加均值估计方差；负相关也可能减少方差，使该统计量的有效样本量超过名义样本数。有效样本量依赖统计量及相关结构，不能仅凭“样本相关”断言信息量一定下降。模型内区间宽度描述参数不确定性，重复计算得到的蒙特卡洛误差描述近似误差；两者不能混为一个误差条。更长链可能减少后者，却不会自动减少真实数据不足造成的前者。

## 11. 一致性、错设与层级收缩

<a id="prob-3-detail-40"></a>

### 11.1 一个能完整证明的后验集中例子

固定 $`a,b>0`$，真实观测独立同分布为 Bernoulli($`\theta_0`$)。大数定律给成功比例 $`\frac{s}{n}\to\theta_0`$，所以后验均值 $`\frac{(a+s)}{(a+b+n)}\to\theta_0`$；后验方差最多为 $`\frac{1}{[4(a+b+n+1)]}`$，趋于零。对任意正的误差容忍度，先让后验均值靠近真值，再用切比雪夫不等式限制参数偏离均值的概率，就得到后验质量向真值集中。

证明明确使用固定先验、正确的共同成功率模型与适当的独立信息增长。若先验随样本量变得压倒性集中，数据未必主导；若参数真值被先验完全排除，更新不能凭空恢复被赋零质量的区域。一般高维或非参数模型需要额外支持、复杂度与可检验性条件，不能仅凭这个共轭例子宣布所有贝叶斯方法一致。

<a id="prob-3-detail-41"></a>

### 11.2 集中可能是集中到错误解释

若复制同一条观测一百次并当作独立样本，形式后验会很窄，真实信息却没有增加一百倍。若概率随时间系统变化，单一固定参数可能集中到某种平均水平，不能描述未来制度切换。模型错设时，后验可能偏向模型族内某个近似目标，而它的区间未必具有想要的频率覆盖。

不可识别也不会被大样本口号消除。若两个参数组合产生完全相同的观测分布，数据只能识别某种等价类；具体分解可能仍由先验决定。应区分参数意义、可观察预测和业务解释，必要时通过额外测量或约束获得识别。预测稳定与每个参数都得到真实机制解释，并不是同一个结论。

<a id="prob-3-detail-42"></a>

### 11.3 从完全合并到部分合并

多群体可以分别估计，或强行共用参数，也可以让群体参数来自一个共同分布。前两者分别对应不合并和完全合并，层级模型提供部分合并。样本少的群体通常更多向总体分布收缩，样本多的群体保留更多自身证据。收缩程度来自噪声、组间差异与样本量，不宜被简化为所有群体统一平均。

对群体成功率，可以令 $`\theta_j\sim\operatorname{Beta}(a,b)`$。若超参数固定，各组有自己的共轭更新；若超参数也未知，所有组共同影响其后验，再由它连接各组。预测已有组的新观测，要保留该组更新后的参数；预测全新组，要从群体分布抽新参数并整合超参数不确定性。

经验贝叶斯把超参数用数据估计后固定，计算方便，但通常没有完整传播超参数不确定性。若用测试组的信息估计超参数，再宣称是完全未见群体预测，评价边界也改变了。完整模型、近似策略、群体划分和预测目标都应一起记录，才能解释部分合并的实际效果。

<a id="prob-3-detail-43"></a>

## 12. 数值验收：让不同概念产生不同答案

<a id="prob-3-detail-44"></a>

### 12.1 用坐标变化检测错误的 MAP 解释

前面已经证明对数几率变换会改变密度峰值，现在用数值优化核对。原概率坐标中优化 Beta 密度，对数几率坐标中必须增加变换的对数雅可比。若省略雅可比，数值程序也许仍顺利收敛，但优化的是另一个密度表达，而不是同一后验在新坐标的密度。

同一实验还检查预测对数密度的平均顺序。两个可能参数对某观测分别给出零点一和零点九的概率，等权混合的预测概率为零点五。其对数不等于两者对数的平均。这个例子不需要复杂模型，已经足以暴露常见实现错误。

```python
import numpy as np
from scipy.optimize import minimize_scalar
from scipy.special import expit, logsumexp
from scipy.stats import beta

a, b = 5.0, 3.0
original = minimize_scalar(lambda p: -beta.logpdf(p, a, b),
                           bounds=(0.001, 0.999), method="bounded")
def negative_log_density_eta(eta):
    p = expit(eta)
    return -(beta.logpdf(p, a, b) + np.log(p) + np.log1p(-p))
transformed = minimize_scalar(negative_log_density_eta,
                              bounds=(-8, 8), method="bounded")
assert original.success and transformed.success
assert np.isclose(original.x, 2 / 3, atol=1e-5)
assert np.isclose(expit(transformed.x), 5 / 8, atol=1e-5)
logp = np.log([0.1, 0.9])
mixture_logp = logsumexp(logp) - np.log(logp.size)
assert np.isclose(np.exp(mixture_logp), 0.5)
assert mixture_logp > logp.mean()
print("MAP in two coordinates", original.x, expit(transformed.x),
      "log predictive", mixture_logp)
```

<a id="prob-3-detail-45"></a>

### 12.2 从解析核对扩展到应用验收

一个实用验收集应包含无数据、少量数据、全成功、全失败、强先验、弱先验、相关重复记录和预测范围改变。不同案例分别检查边界、收缩、采样单位与外推，不能只把正常输入多运行几次。对共轭模型，解析结果是独立于实现的参考；对高维模型，则需要分层建立局部梯度、模拟恢复、预测检查和真实留出评价。

随机实验应把数值误差与统计误差分开。矩阵公式可以用严格浮点容差核对，蒙特卡洛矩的偏差应根据样本量和尾部设定合理容差。偶尔一个抽样结果接近理论值不构成证明，反复更换随机种子直到通过也不是可靠验收。若测试失败，应先判断是代数、参数化、数值稳定还是抽样波动。

## 13. 进阶练习与逐题解析

<a id="prob-3-detail-47"></a>

### 13.1 题一：同均值的先验是否表达相同知识

**题目。** Beta(2,2) 与 Beta(20,20) 都以二分之一为中心。各观察一次成功后，下一次成功预测是否相同？哪种先验改变更小？

**解析。** 两者更新为 Beta(3,2) 与 Beta(21,20)，预测分别为五分之三与四十一分之二十一。后一结果更靠近二分之一，因为原浓度更高。中心描述偏好位置，浓度描述对偏好的坚持程度。若业务只说“成功失败同样可能”，不能据此唯一确定浓度，还应说明证据强度并检查敏感性。

<a id="prob-3-detail-48"></a>

### 13.2 题二：全成功是否应该预测永远成功

**题目。** 先验 Beta(1,1)，观察三次全成功。最大似然、后验均值与后验众数有什么区别？后验众数能否机械套内部公式？

**解析。** 最大似然为一，后验是 Beta(4,1)，均值为五分之四。密度朝右边界上升，内部众数公式的通常适用条件不成立；若允许端点，可描述峰在一处，否则描述在边界处取得上确界。一次预测仍有失败余地。边界峰值与事件概率不是一回事，连续参数恰好等于一的后验质量仍需按分布判断。

<a id="sec-7-1"></a>
<a id="prob-3-detail-49"></a>

### 13.3 题三：均值乘积为何漏掉共同不确定性

**题目。** 后验为 Beta(2,2)，预测两次都成功。为何答案是零点三而不是零点二五？若每次独立重抽一个成功概率，答案又怎样？

**解析。** 共用参数时联合概率是 $`E[\theta^2]=2\times\frac{3}{(4\times5)}=0.3`$，比均值平方多出参数方差零点零五。每次重新独立抽参数，积分分别进行，答案变成零点二五。两种生成机制单次边缘都为二分之一，但批次依赖不同。模拟时应把参数抽样放在正确层级，否则看似正确的每行概率会拼出错误联合分布。

<a id="prob-3-detail-50"></a>

### 13.4 题四：未来平均是否能消除全部不确定性

**题目。** 仍取 Beta(2,2) 后验，预测未来一百次的成功比例。其预测方差会像固定成功率二项模型那样降到零点零零二五吗？

**解析。** 全方差给 $`\operatorname{Var}(\frac{K}{100})=v+\frac{E[\theta(1-\theta)]}{100}`$。此处 $`v=0.05`$，第二项为零点零零二，总和零点零五二。增加未来批次数能减少给定参数的二项噪声，却不能自动补充当前数据对参数的知识。只有真正观察新数据并更新，才可能进一步减少参数不确定性。

<a id="prob-3-detail-51"></a>

### 13.5 题五：同一数据两种表示为何证据不同

**题目。** 四次中成功三次的计数，与一个给定顺序的三成功一失败序列，是否有相同的后验？是否有相同证据？

**解析。** 在独立同参数模型下，两个似然只差不依赖参数的组合数四，所以参数后验相同。计数事件包含四种顺序，其证据是单一顺序的四倍。后验归一化能约去公共常数，不代表事件概率可以任意省略常数。模型比较前要确认比较的是相同观测事件，尤其不能混用计数与序列的概率。

<a id="prob-3-detail-52"></a>

### 13.6 题六：均值区间与预测区间差多少

**题目。** 高斯已知噪声例中 $`m_n=\frac{4}{3},v_n=\frac{4}{9},\sigma^2=1`$。给潜在均值与下一观测的方差分别是多少？哪一个区间更宽？

**解析。** 潜在均值方差为九分之四，新观测预测方差为九分之十三，因此在相同高斯分位数水平下后者更宽。把预测区间误写成均值区间，会遗漏即使参数已知仍存在的噪声。若目标是多个未来观测的平均，应重新计算共同均值与各自噪声的贡献，不能直接把单次预测方差整体除以样本数。

<a id="prob-3-detail-53"></a>

### 13.7 题七：同样 L2 系数是否同样先验

**题目。** 两份代码分别用误差平方和的一半与均方误差的一半作为数据项，却写相同惩罚系数。能否宣称使用相同高斯先验？

**解析。** 不能。目标归约改变了数据项相对于先验项的比例。已知噪声方差与先验方差时，均方形式的系数为 $`\frac{\sigma^2}{(n\tau^2)}`$，平方和形式则相应为 $`\frac{\sigma^2}{\tau^2}`$。还需确认噪声尺度、特征单位和截距处理。只比较配置里名为正则强度的数值，不能判断两个方法的实际约束相同。

<a id="prob-3-detail-54"></a>

### 13.8 题八：换坐标后众数为何改变

**题目。** Beta(5,3) 的概率坐标众数是三分之二。为什么对数几率坐标密度峰值对应八分之五，却没有产生概率矛盾？

**解析。** 密度必须相对于坐标体积定义，换坐标乘上 $`\theta(1-\theta)`$ 的雅可比，峰值位置随之改变。某个概率区间对应的后验质量在正确变量替换下不变；变化的是局部密度的高度排名。MAP 是依赖参数化的摘要，预测事件概率则可以用积分保持一致。若一个结论只依赖密度峰位置，应声明所用坐标。

<a id="prob-3-detail-55"></a>

### 13.9 题九：把尺度当标准差会错在哪

**题目。** 某后验预测为自由度十、尺度二的 Student t 分布。其方差是否为四？用高斯均值加减两倍尺度作为百分之九十五区间合理吗？

**解析。** 自由度十的方差是尺度平方乘十除以八，所以为五。区间应使用 t 的相应分位数乘尺度，而非默认高斯规则。更低自由度时方差可能不存在。分布族、自由度、位置、尺度和矩需要分别记录，不能看到一个名为 scale 的参数就把它当作所有分布的标准差。

<a id="prob-3-detail-56"></a>

### 13.10 题十：后验很窄能否证明数据很多

**题目。** 一个用户的同一次反馈被复制成一百行，独立 Bernoulli 模型给出很窄后验。这是否证明概率估计可靠？

**解析。** 狭窄来自模型把重复行当成一百次独立证据，并不来自真实信息增加。应回到采样单位、去重键和依赖结构，必要时按用户或事件建模。增加 MCMC 样本只会更精确地计算这个错误模型的后验，不能修复重复证据。计算误差、数据问题和模型假设必须分别诊断。

<a id="prob-3-detail-57"></a>

### 13.11 题十一：均值复制成功为何仍应拒绝模型

**题目。** Poisson 模型的复制数据均值与真实均值接近，但真实数据零值比例和方差明显更大。是否只需继续优化参数？

**解析。** 单一 Poisson 强度把条件均值与方差绑定，优化参数无法任意调整二者关系。可以检查群体混合、时变强度、依赖或额外零机制等候选解释，再比较它们能否再现相关统计。一个统计量匹配不证明模型全面正确；反过来，一个不匹配也不能唯一识别真正机制，需要数据来源和区分实验共同支持。

<a id="prob-3-detail-58"></a>

### 13.12 题十二：预测密度应该怎样平均

**题目。** 两个等权后验参数样本对测试结果给出零点一与零点九的概率。对数预测概率是多少？平均对数又是多少？

**解析。** 先平均概率得零点五，再取自然对数约负零点六九三。平均两个对数约负一点二零四，二者不同。预测混合需要前者，数值实现用 log-sum-exp 减去样本数对数。若用后者代替，会改变所评价的分布与模型排序。平均顺序必须由目标定义决定，不能只选择看起来方便的代码。

<a id="prob-3-detail-59"></a>

### 13.13 题十三：已有群体与新群体如何预测

**题目。** 层级成功率模型中，某老用户有大量历史，新用户没有历史。能否都代入同一个总体均值，称为完整后验预测？

**解析。** 老用户应使用其组参数在已有观测下的后验，并整合超参数不确定性；新用户应从群体分布抽新组参数，再生成结果。总体均值可能给出某个单次预测均值，却不能保留不同群体的联合波动和已知信息。若部署主要面对新群体，验证应留出整组，不能只留出老用户的一条记录。

<a id="prob-3-detail-60"></a>

### 13.14 题十四：先验零支持能否被无限数据修复

**题目。** 模型把某个参数区域先验概率设为零，后续观测越来越支持那里。普通贝叶斯乘法能否自动为它恢复概率？

**解析。** 对通常定义的更新，后验仍绝对连续于先验，原先零质量区域不会凭乘以似然产生正质量。若真实机制落在被排除区域，后验可以在剩余族里寻找近似，却不能声称已恢复真值。先验支持是建模承诺，需要通过科学知识与敏感性分析审查；增加计算量并不能替代修正模型。

<a id="prob-3-detail-61"></a>

### 13.15 题十五：非适当先验为何妨碍证据比较

**题目。** 两个模型都用可产生适当后验的非适当先验，是否可以直接积分似然得到可信的 Bayes 因子？

**解析。** 非适当先验的任意乘法常数不影响各自归一后的参数后验，却会改变积分出来的证据。因此后验存在不等于证据比较已定义。应选择有明确概率归一化的先验，或者采用适合任务且定义完整的预测比较方法。任何替代方法也需报告其假设，不能仅把不确定的常数悄悄删掉。

<a id="prob-3-detail-62"></a>

### 13.16 题十六：不对称损失应该报告哪个摘要

**题目。** 报告容量 $`d`$，低估真实需求每单位损失四，高估每单位损失一。后验均值是否必然最优？应怎样计算动作？

**解析。** 期望分段线性损失的最优点满足需求后验分布函数等于四除以五，即百分之八十分位数；离散分布取达到该水平的适当最小容量。均值对应平方损失，不适合自动替代非对称成本。还应确认成本是否固定、是否有硬预算及多任务之间是否共享资源，后两者会使独立逐项决策需要进一步约束优化。

<a id="prob-3-detail-63"></a>

## 14. 研究任务：把模型、推断与决策分别验证

<a id="prob-3-detail-64"></a>

### 14.1 一份可以证伪的实验设计

构造三种世界：共同固定成功率、用户之间成功率不同、成功率随时间变化。分别生成具有明确用户和时间标识的数据，再用单一 Beta–Bernoulli 与层级模型比较。保留训练、模型开发和最终测试角色；如果先观察测试结果再决定使用哪种先验，测试已参与选择，必须重新设计最终评价。

比较表应同时报告单次概率评分、未来批次计数区间、不同群体表现和实际决策成本。固定参数模型可能在单次均值上看起来不错，却遗漏批次波动；灵活模型也可能因数据少而估计不稳。研究目标是理解方法何时改变结论，而不是预先规定复杂模型必胜。

对每一种世界，记录样本单位、真参数、先验、更新、预测对象与损失。先使用解析可解子问题核对实现，再扩大到需要近似推断的模型。如果新算法改变了后验近似但保持相同模型，评价重点应包括计算误差和预测量；若改变了生成模型，就不能把全部改进归因于推断算法。

<a id="prob-3-detail-65"></a>

### 14.2 用失效模式组织交付

可以故意引入五类错误：把同一用户重复记录当独立、把未来多次试验分别重抽参数、在预测时只用 MAP、平均对数代替对数平均、在测试群体上拟合超参数。每类都写一个能击败错误实现的小数据，再解释观察差异来自哪一个被破坏的假设。

最终材料应允许读者从一条预测回溯到输入、模型、先验、后验计算和决策。除了均值，还应保存与任务有关的区间、尾部事件概率和联合结构。若只留下漂亮的概率数值与模型名称，后来的人无法判断结论靠的是数据、先验、近似还是阈值。

<a id="prob-3-detail-66"></a>

## 15. 更进一步：可信程度与覆盖范围

<a id="prob-3-detail-67"></a>

### 15.1 模型内的平均覆盖可以直接推导

若每份数据都构造后验质量为百分之九十五的集合 $`C(D)`$，并且参数与数据确实按先验和似然的联合模型生成，那么

$$
P\{\theta\in C(D)\}=E_D\left[P\{\theta\in C(D)\mid D\}\right]=0.95.
$$

这是对先验生成参数再生成数据的联合平均陈述。它不自动推出对每一个固定真参数，都有百分之九十五频率覆盖。某些参数值上覆盖偏高，另一些偏低，先验加权平均仍可正确。检查区间时必须说明是在模型联合生成下、某个固定参数下，还是目标部署分布下评价。

这个推导也给模拟实验提供清楚目标：按先验抽真参数，再生成数据，反复运行推断并计算秩或覆盖，可以发现计算程序与模型定义不一致。但若真实世界并不按该先验和似然生成，通过这类模型内验证仍不证明部署覆盖。模拟计算校验与现实模型评价需要同时存在。

<a id="prob-3-detail-68"></a>

### 15.2 用预测问题限制不必要的复杂度

不是每次都要估计完整后验的一切细节。如果动作只依赖一个线性期望，能可靠计算该期望也许已经足够；若关心极端联合事件，就需要保留相关与尾部。把所有任务都压成一个点会丢信息，但盲目追求所有参数的复杂分布也会浪费计算。先明确决策所需函数，再选择相应推断与验证精度。

对于新分布、新群体或新机制，合理做法是更新问题定义并检查信息来源，而不是把旧后验的数值置信程度搬过去。贝叶斯推断提供了一套连贯的条件化计算；它的力量来自把假设和信息联系得清楚，实际可靠性则依赖这些假设是否值得相信，以及计算和评价是否忠实于目标。
