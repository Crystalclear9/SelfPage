## 1. 先定义异常相对于谁、发生在何时

异常不是样本携带的一枚永久标签，而是样本与参考机制之间的关系。凌晨大量访问对某种服务可能是正常备份，对另一种服务可能是故障信号；很大的金额可以是正常大客户，也可以是输入单位错误。异常检测首先要区分统计少见、分布外、新颖模式与实际有害事件。它们可能重叠，却没有普遍等价关系。算法分数只有与明确的参考总体和用途结合，才能转成可解释的行动。

设观测为 $x$，上下文为 $c$，参考正常分布为 $P_0(x\mid c)$。上下文可以包括在检测时已知的设备类型、班次或季节；不能使用故障发生后才知道的维修结果。若忽略上下文，将不同正常模式混成一个总体，少数群体可能持续被判异常。若上下文划得过细，每个小组支持不足，估计又会不稳定。条件建模需要在相关性、样本量与预测时可用性之间权衡。

<a id="unsup-3-2"></a>

### 1.1 三类任务的训练数据不同

离群检测面对已经可能包含异常的训练集，需要在污染中识别主要结构；新颖性检测以相对干净的正常参考集为起点，识别后续偏离；监督风险分类则利用已标注的目标事件学习区分。三者可相互补充，但训练假设与评价协议不同。一个在混合训练集中形成紧密小团的有害群体，可能不会被某种局部离群方法发现；在纯正常参考中，它又可能明显新颖。

库的接口也体现这种差异，不能只因类名相同就将训练得分和新数据得分混用。关于离群与新颖性，以及 LOF 两种模式的边界，可核对 [scikit-learn 1.8 异常检测指南](https://scikit-learn.org/1.8/modules/outlier_detection.html)。本章将参考学习、分数、阈值、评价和反馈分别讨论，避免把一次调用返回的负一标签当作已经验证的风险事实。

<a id="unsup-3-3"></a>

### 1.2 点异常、上下文异常与集合异常

点异常可由单条记录的特征判断，例如温度远超设备支持范围；上下文异常依赖时间或群体，例如夜间负载相对夜间基线异常；集合异常则由一组记录的顺序、频率或协同关系体现，单点各自可能普通。将集合问题强行逐行检测，会丢掉关联结构。应先构造窗口、序列或图级特征，并保证窗口不包含检测时尚未发生的未来。

对设备故障，异常是一个持续事件而不是每秒独立事件。若模型连续报警一千次，不应算作发现一千个故障；如果只在故障后很久命中一次，记录级召回可能好看，实际价值却低。评价单位、去重窗口、检测延迟和审核动作需要在训练前明确，否则模型可能优化的是容易计算但无实际意义的指标。

<a id="unsup-3-4"></a>

### 1.3 参考集不是永远正确的正常世界

历史数据可能含漏标故障、维护窗口和系统版本变化。把全部历史当作正常，会使模型逐渐吸收异常；过度清洗则可能只留下特别容易的正常核心，部署后误报真实多样性。参考集应记录来源、时间、筛选依据、已知缺陷和反馈成熟度。必要时使用稳健方法，但稳健假设本身也要核验，不能凭“抗污染”一词忽略污染比例和形状。

还应保留一份独立正常评价集，覆盖少数群体、季节、设备和新批次，检查误报分布。若某群体很少被抽到，平均误报率不能证明它得到合理对待。这里关注的是模型是否正确适应实际正常机制，而不是把所有群体机械设成相同报警率；不同基线与代价可以合理不同，但必须有证据解释。

## 2. 密度、概率质量与高维典型性

连续密度 $p(x)$ 不是点事件概率。连续分布单点概率通常为零，某区域的概率是对该区域积分。密度数值还依赖坐标单位：将长度单位改为厘米，密度会按体积变换缩放。因此用统一的“密度低于零点零一”跨数据集判断风险没有一般意义，必须定义表示与参考模型。

<a id="unsup-3-6"></a>

### 2.1 高斯分布的半径推导

若 $X\sim\mathcal N(0,I_d)$，密度在原点最高，随 $\|x\|^2$ 增大而下降。但随机样本的平方半径 $R^2=\sum_{j=1}^dX_j^2$ 服从自由度为 $d$ 的卡方分布，均值为 $d$、方差为 $2d$。相对标准差为 $\sqrt{2/d}$，维数增加时大部分样本集中在半径约 $\sqrt d$ 的壳层，而不是最高密度的原点附近。

这并不矛盾：壳层单点密度较低，但拥有巨大的体积，积分质量可以很高。原点虽然密度最大，附近极小球的概率仍可能很低。在高维中，“密度高”与“典型样本”不等价；一个比正常更接近均值的输入，也可能不符合正常半径分布。这个推导来自精确已知的高斯模型，不依赖生成模型估计错误就能成立。

<a id="unsup-3-7"></a>

### 2.2 两侧典型性与语义仍有距离

若目标是检测是否来自该高斯分布，可对 $R^2$ 的两侧尾部构造检验，而不是只把半径大视为异常。但现实分布未知、参数估计有误，而且单点典型性未必覆盖全部结构；某输入可以拥有正常半径却在方向或相关性上异常。高维异常没有一个无假设的通用分数，每种统计量只能检验某些偏离方向。

更进一步，语义异常不由密度单独决定。图像中的简单背景可能有高似然，却不是训练对象；有害事件也可能表现为常见行为组合。关于深生成模型似然与分布外检测的研究，可阅读 [典型性检测原论文](https://arxiv.org/abs/1906.02994)。该研究方向提示需要更明确的备择与评价，不应被简化成“所有密度方法都无效”。

<a id="unsup-3-8"></a>

### 2.3 实验一：最高密度点不在典型壳层

实验在一百维标准正态生成五千个样本，检查平方半径平均值，并比较原点与随机样本的对数密度。断言说明正常样本通常远离原点；它不声称所有不在壳层的点都对应真实业务风险。

```python
import numpy as np
rng = np.random.default_rng(31)
d = 100
X = rng.normal(size=(5000, d))
r2 = (X*X).sum(axis=1)
logp = -.5*(d*np.log(2*np.pi)+r2)
origin_logp = -.5*d*np.log(2*np.pi)
assert abs(r2.mean()-d) < 2
assert np.mean((r2 > 60) & (r2 < 140)) > .97
assert np.all(logp < origin_logp)
print('mean radius squared:', round(r2.mean(), 3), 'origin log density:', round(origin_logp, 3))
```

如果将这个实验扩展到协方差不等于单位阵，先用真实或估计协方差构造马氏半径，再区分参数已知和估计场景。估计误差会改变参考分布，不能继续机械使用已知参数的卡方阈值；高维小样本还可能需要正则与独立校准。由简单模型逐步增加困难，比直接相信一个通用阈值更能建立可靠直觉。

## 3. 全局距离与密度基线

最简单的异常分数可从中心距离开始。若正常分布近似单峰且各方向尺度不同，马氏距离 $s(x)=(x-\mu)^T\Sigma^{-1}(x-\mu)$ 比原始欧氏距离更能体现相关性。它仍假定单个椭球可概括正常区域；多峰数据中，两个正常群体之间的空区可能接近全局均值，却根本没有正常样本。

<a id="unsup-3-10"></a>

### 3.1 均值与协方差会被污染

一个极端点不仅在固定模型下距离很大，还可能将均值拉向自己并膨胀协方差，使自己的标准化距离变小，这称为遮蔽问题。多个异常互相支持时更明显。稳健位置与协方差估计试图降低影响，但也依赖污染和正常结构假设；多模态正常总体不一定能由单个稳健椭球代表。

另一类错误是淹没：模型被多数群体主导，将真实正常的小群体判异常。应同时检验明显异常是否因污染被掩盖，以及少数正常是否被误伤。只查看排名最靠前的几个异常案例，可能发现遮蔽失败，却看不到长期存在的群体性误报。需要分层的正常评价与代表性审核。

<a id="unsup-3-11"></a>

### 3.2 核密度和近邻距离

核密度估计用带宽控制局部平滑：太小会让每个训练点附近形成尖峰，太大又可能填平真实空隙。高维中数据稀疏，使精确密度估计困难。近邻距离分数用第若干邻居的距离或平均距离衡量支持程度，避免显式归一化密度，但它仍依赖距离、邻居尺度和样本量，不是自动摆脱维数灾难。

样本量增加时最近邻通常变近，因此不同训练规模下的原始分数阈值不应直接复用。不同正常群体密度差异大时，全局近邻距离可能主要把稀疏群体排到前面；局部相对方法尝试与附近密度比较，但如果邻域跨越群体边界，它也会发生误判。方法选择必须与参考结构相匹配。

## 4. Isolation Forest：通过随机划分衡量隔离难度

隔离森林反复抽样建立随机树，在节点选择特征及分割值，将样本分开。某些孤立或极端点较容易在较浅层被单独分离，常规群体中的点需要更深划分。最终分数结合多棵树的路径长度并作规模归一化。它没有直接拟合密度函数，因此隔离分数不能解释为连续密度，更不能解释成欺诈概率。

<a id="unsup-3-13"></a>

### 4.1 路径长度及归一化

原始方法常以 $s(x)=2^{-E[h(x)]/c(\psi)}$ 表示异常强度，其中 $\psi$ 是子样本规模，$c(\psi)$ 是用于归一化的预期路径长度。平均路径短，原始异常强度更大；节点提前停止且仍有多个样本时，需要对未完全隔离部分补充长度估计。公式说明分数依赖子样本规模和路径约定，不能跨实现直接共用数值阈值。

随机树只看到某个表示中的轴向划分。相关方向、稀疏类别编码和无关维度可能影响隔离效率，旋转后结果不一定不变。子样本较小可能更快暴露异常，也可能漏掉正常少数模式；增加树数降低算法随机波动，但无法修复错误的特征含义。方法原理与路径归一化见 [Isolation Forest 原论文](https://cs.nju.edu.cn/zhouzh/zhouzh.files/publication/icdm08b.pdf)。

<a id="unsup-3-14"></a>

### 4.2 实现分数方向和偏移

scikit-learn 的 `score_samples` 以较低值表示更异常，与常见原论文异常强度方向相反；`decision_function` 进一步减去 `offset_`，以零作为预测边界。比较算法前最好统一约定“越大越异常”，并将转换写进代码，避免因排序方向错误把最正常记录送审。负一和正一是预测标签，不是概率值。

在该实现中，指定数值 `contamination` 主要用于从训练得分分位数设置偏移；同样数据与随机状态下，不同污染参数可得到相同原始排序而不同阈值。这是实现层面的可检验性质，不应推广为所有算法的 contamination 都只影响阈值。接口与方向见 [IsolationForest 1.8 文档](https://scikit-learn.org/1.8/modules/generated/sklearn.ensemble.IsolationForest.html)。

<a id="unsup-3-15"></a>

### 4.3 实验二：污染参数改变阈值而非风险真值

使用完全相同的正常样本与树设置，仅改变污染参数，核验原始分数相同而预测数量变化。合成数据没有被人为植入风险标签，因此标出较多异常不能证明发现了更多真实风险。实验同时核对决策函数与偏移的恒等式。

```python
import numpy as np
from sklearn.ensemble import IsolationForest
rng = np.random.default_rng(41)
X = rng.normal(size=(300, 2))
base = dict(n_estimators=100, max_samples=128, random_state=5, n_jobs=1)
a = IsolationForest(contamination=.05, **base).fit(X)
b = IsolationForest(contamination=.20, **base).fit(X)
sa, sb = a.score_samples(X), b.score_samples(X)
assert np.allclose(sa, sb)
assert np.allclose(a.decision_function(X), sa-a.offset_)
assert np.allclose(b.decision_function(X), sb-b.offset_)
na = int((a.predict(X) == -1).sum())
nb = int((b.predict(X) == -1).sum())
assert na < nb
assert np.array_equal(np.argsort(-sa), np.argsort(-sb))
print('training alerts:', na, nb, 'offsets:', round(a.offset_, 4), round(b.offset_, 4))
```

实际审核需要独立目标事件或反馈。若数据包含重复点，分位阈值处的并列会使预测比例与指定值不完全相等，应报告并列策略。参数名叫污染比例，不表示模型估计到了真实污染；它是在使用一个假设或工作点。只有在明确定义的总体中进行代表性标注，才有依据讨论真实风险率。

<a id="unsup-3-16"></a>

## 5. LOF：比较局部相对密度

局部离群因子关心某点是否比它周围的参考点稀疏，而不是单纯寻找全局密度最低者。一个稀疏但内部一致的正常群体，成员的局部密度可能都较低，彼此比值却接近一；一个处在密集群体边缘、离其他点明显更远的点，局部密度比值可能较大。这一思想适合存在正常密度差异的数据，但仍依赖邻域大小与距离。

<a id="unsup-3-17"></a>

### 5.1 可达距离与局部可达密度

设 $k\text{-dist}(o)$ 为参考点 $o$ 到其第 $k$ 邻居的距离。对点 $p$ 与其邻居 $o$，可达距离定义为 $\operatorname{reach}_k(p,o)=\max\{k\text{-dist}(o),d(p,o)\}$。这个最大值使非常近的局部距离被参考邻域尺度平滑，减少某些微小距离对密度估计的剧烈影响。注意它一般不是对称距离，因为使用的是邻居 $o$ 的局部尺度。

局部可达密度是平均可达距离的倒数，$\operatorname{lrd}_k(p)=[|N_k(p)|^{-1}\sum_{o\in N_k(p)}\operatorname{reach}_k(p,o)]^{-1}$。LOF 再取邻居密度与本点密度的比值平均。接近一表示与邻域支持相近，大于一表示比邻居稀疏；它仍不是异常概率。对重复点造成的零距离，需要实现中的数值平滑，公式不能直接除零。

定义可进一步核对 [LOF 原论文记录](https://sigmodrecord.org/2000/06/07/lof-identifying-density-based-local-outliers/)。实际实现对近邻并列、训练点自身排除和数值稳定有具体约定，手算与库比较时应选择无并列数据或明确这些约定。不要只凭“公式长得差不多”就认定两个接口在训练和新样本场景完全等价。

<a id="unsup-3-18"></a>

### 5.2 邻域尺度决定参照群体

若 $k$ 太小，重复点、测量噪声和偶然邻接可能主导；若 $k$ 太大，邻域跨越不同正常群体，局部性被削弱。一个规模小于 $k$ 的正常群体，成员不得不把外部群体纳入邻居，可能被判异常。应根据有意义的最小正常群体和样本量选择尺度，并在一段范围内观察分数与排序，而不是只以最高验证分选择一个孤立参数。

LOF 对局部密度差异敏感，却不一定识别一个内部紧密、整体偏离训练常态的异常团。如果异常已在混合训练集中形成足够邻居，彼此可能支持为正常；若以纯正常参考进行新颖性评分，同一个团又可能远离所有参考支持。由此可见训练任务设定会改变分数，不能把某方法的失败仅归因于“局部算法不好”。

<a id="unsup-3-19"></a>

### 5.3 离群与新颖性接口不能混用

默认离群模式常用 `fit_predict` 分析训练集合，训练分数在 `negative_outlier_factor_` 中。新颖性模式需在拟合前设置 `novelty=True`，随后 `predict`、`score_samples` 和 `decision_function` 用于未参与拟合的新样本。把训练样本再次送进新样本接口，会使用不同邻域处理，不能期待与默认训练分析逐项相同。官方专门指出这一边界，见 [LocalOutlierFactor 1.8 文档](https://scikit-learn.org/1.8/modules/generated/sklearn.neighbors.LocalOutlierFactor.html)。

样本标识与内容要区分：一条新请求可能数值上恰好与历史记录相同，它仍是新观测；但为了验证训练评分，直接将训练矩阵原样送回新颖性接口，不构成正确对照。教材应明确每个数组的角色，实验日志也应记录拟合样本与评价样本，避免接口恰好能调用便误以为协议正确。

<a id="unsup-3-20"></a>

### 5.4 实验三：两个模式分别使用正确的数据

先在混合数据上做离群检测，再在单独正常参考上拟合新颖性模型，并只对新生成的正常点和远点评分。最后自行根据第二近邻距离，核验远点缺乏参考支持。这种独立基线并不与 LOF 数值相等，但能确认合成样本确实具有所声称的几何关系。

```python
import numpy as np
from sklearn.neighbors import LocalOutlierFactor, NearestNeighbors
rng = np.random.default_rng(51)
reference = rng.normal(scale=.2, size=(120, 2))
far = np.array([[5., 5.], [6., -5.]])
mixed = np.vstack([reference, far])
outlier = LocalOutlierFactor(n_neighbors=15, contamination=.03)
labels = outlier.fit_predict(mixed)
train_strength = -outlier.negative_outlier_factor_
assert labels.shape == (122,)
assert np.mean(train_strength[-2:]) > np.mean(train_strength[:-2])
novel = LocalOutlierFactor(n_neighbors=15, novelty=True, contamination=.05).fit(reference)
new_normal = rng.normal(scale=.2, size=(20, 2))
new = np.vstack([new_normal, far])
strength = -novel.score_samples(new)
assert np.min(strength[-2:]) > np.median(strength[:-2])
assert np.all(novel.predict(far) == -1)
dist, _ = NearestNeighbors(n_neighbors=2).fit(reference).kneighbors(new)
assert np.min(dist[-2:, -1]) > np.max(dist[:-2, -1])
print('new median normal/remote strength:', np.median(strength[:-2]), strength[-2:].tolist())
```

这个容易的合成例子只验证接口方向与数据边界。应继续构造稀疏正常小群体、位于正常高密度区域的目标异常和紧密异常团，观察方法的失败类型。不能因为远点被检出就宣布系统已经能够处理真实欺诈或设备故障；实际异常可能与正常在现有特征上不可区分，需要新的上下文和反馈。

<a id="unsup-3-21"></a>

## 6. 单类边界与重构分数

单类 SVM 通过核映射与正则约束学习参考区域的边界，它不必显式估计归一化密度。核带宽决定局部复杂度，正则参数影响边界与训练违例的折中。它通常适合参考正常数据的支持估计，但对训练污染、尺度和参数较敏感。边界函数值是相对间隔，不是类别后验概率；参数也不是对任意未来总体的精确误报率承诺。

<a id="unsup-3-22"></a>

### 6.1 支持区域与分类边界不同

监督分类边界由两类样本共同确定，单类方法仅利用参考样本和正则偏好；没有出现过的异常方向无法被完整描述。若正常分布中间有空隙，边界是否包住它取决于核与正则。更复杂边界能紧贴训练点，也可能过拟合测量噪声。应使用独立正常样本评价覆盖，并用代表性异常或有意义的扰动评价检出能力。

高维特征尺度差异会改变核距离，因此缩放必须放在训练边界内。若进行核近似以适应规模，近似误差与检测效果应分别检查；不能将线性近似与精确核模型在完全不同预算下直接比较，然后把差异全归因于优化器。支持估计的理论问题可参阅 [原始单类支持估计研究](https://research.google/pubs/estimating-the-support-of-a-high-dimensional-distribution/)。

<a id="unsup-3-23"></a>

### 6.2 PCA 重构误差遗漏哪些异常

PCA 重构分数关注样本离已学线性子空间多远。若一个异常沿子空间方向走得很远，仍可能被精确重构，误差接近零；若正常有一个低方差但合法的方向，截断后反而可能产生误报。因此可同时考虑子空间内部的得分距离与子空间外的残差，但组合方式与阈值需要独立校准，不能简单将两个不同比例的数相加。

自编码器扩展为非线性重构，但容量足够大时也可能重构异常很好，训练分布外的泛化并没有自动的异常保证。网络可能学到近似恒等映射，或利用背景等容易重建的信息掩盖局部关键异常。应按目标事件检查分项误差、表示和训练样本，而不是只看平均重构损失下降。

<a id="unsup-3-24"></a>

### 6.3 实验四：沿子空间远行仍可零残差

训练点位于横轴，PCA 保留一维。新点一类沿横轴远离，一类垂直偏离。前者有很大的投影得分却零重构误差，后者重构误差很大。这个实验不需要神经网络，就足以反驳“异常一定难以重构”的普遍命题。

```python
import numpy as np
from sklearn.decomposition import PCA
train = np.c_[np.arange(-3., 4.), np.zeros(7)]
model = PCA(n_components=1, svd_solver='full').fit(train)
new = np.array([[100., 0.], [0., 5.]])
Z = model.transform(new)
residual = ((new-model.inverse_transform(Z))**2).sum(axis=1)
assert np.allclose(residual, [0., 25.])
assert abs(Z[0, 0]) > abs(model.transform(train)[:, 0]).max()
print('residual:', residual.tolist(), 'absolute score:', np.abs(Z[:, 0]).tolist())
```

真实数据里主方向也有估计误差，因此残差可能不是精确零，反例的机制仍然成立。应根据正常机制决定关注哪一种偏离：幅度超范围、变量关系破坏或时间顺序异常。使用重构分数前明确这些备择，比无差别堆叠更深的模型更有指导意义。

## 7. 从分数到告警：工作点必须单独选择

设统一方向后的异常强度为 $s(x)$，规则为超过阈值 $t$ 则告警。排序模型与阈值策略是两个对象：同一个排序在不同审核容量下有不同精确率和召回；同一阈值在不同总体中又可能产生不同告警量。更改分数的单调变换不会改变排名，却会改变数值阈值，因此不能给所有算法统一设零点五。

<a id="sec-3"></a>

<a id="unsup-3-26"></a>

### 7.1 按容量、误报率或成本选择阈值

按容量可选择每批前若干条，但批次风险变化时，它会强制产出固定数量，可能在低风险日送入较多正常，也可能在高风险日漏掉大量事件。按正常校准分位数设阈值，试图控制参考正常下的尾部比例，但有限样本、并列和未来漂移会影响实际误报。按标注代价选择阈值，则需考虑漏报、误报与调查成本，以及标签是否代表真实部署总体。

若目标为最大化每百次审核的发现量，评价固定预算精确率很直接；若故障漏报代价极高，可评价在可接受误报量下的召回与延迟。应在看最终测试结果前确定主要工作点，不能遍历测试阈值后只报最好值。阈值开发需要独立校准或验证数据，最终测试用于评价冻结规则。

<a id="sec-1-1"></a>

<a id="unsup-3-27"></a>

### 7.2 容量算例与基率影响

一万条记录中真实风险十条，模型检出其中八条，同时误报九十二条。审核一百条的精确率为百分之八，召回为百分之八十；正常中的误报率约为百分之零点九二。总体准确率很高，却不能反映每次审核的收益。若全判正常，准确率仍为百分之九十九点九，但召回为零，因此准确率不适合作为此场景的主要指标。

根据贝叶斯公式，$\mathrm{PPV}=\pi\mathrm{TPR}/[\pi\mathrm{TPR}+(1-\pi)\mathrm{FPR}]$。即使 TPR 和 FPR 不变，风险基率 $\pi$ 降低也会降低精确率。因此在异常比例被人为提高的平衡测试集上得到的精确率，不能直接用于自然总体。可以按真实基率校正，但前提是条件分布或对应性能可迁移，需要明确假设。

<a id="unsup-3-28"></a>

### 7.3 并列、阈值方向与概率校准

若很多记录分数相同，取前一百条的结果依赖并列规则，应使用稳定标识、随机抽取或更高优先级信息，并记录策略。规则为严格大于还是大于等于，也会在分位点改变告警数量。小差异在连续大样本中看似无关，在离散树分数或重复记录很多时可能很明显。

如果希望输出事件概率，需要有代表性标注并对分数做校准，随后在独立数据检查可靠性。标注只来自旧规则挑出的高分记录，训练出的概率可能仅在该选择子总体中有效。不能将任意归一化到零一的分数叫概率；最小最大缩放仅改变数值范围，没有建立频率解释。

<a id="sec-4"></a>

<a id="unsup-3-29"></a>

## 8. 评价协议：分数排序、事件命中和审核偏差

评价首先需要明确正类是什么。若正类为真实故障，统计偏离却未产生故障的记录属于误报；若任务只想发现新模式，它可能反而是成功案例。两种评价都可开展，但不能在结果不好时临时改变正类定义。标签来源、成熟时间、审核规则和无法确认的样本，应与算法结果一起记录，否则任何精确率数字都可能缺少稳定分母。

<a id="unsup-3-30"></a>

### 8.1 PR、ROC 与平均精确率

ROC 展示不同阈值的真正率与假正率，PR 展示精确率与召回；稀有事件下，少量假正率也可能对应大量误报，因此 PR 和具体数量往往更直观。ROC AUC 衡量一种整体排序性质，不表示某个实际工作点能满足调查预算。可以同时报告曲线与冻结阈值的混淆计数，避免只给一个汇总面积。

平均精确率按召回增量加权精确率，与对 PR 点做任意梯形积分不完全相同。库版本与并列处理影响数值细节，应使用明确的接口并保持正类与分数方向一致。少量正例时指标方差很大，一个异常样本的排序变化就可能明显改变 AP；应给重复抽样或合适的不确定性描述，并报告正例数量，不让小数位数制造虚假精确。

<a id="unsup-3-31"></a>

### 8.2 时间与实体划分防止记住个体

同一设备的相邻窗口高度相关，随机逐行划分会让训练与测试几乎重复；同一用户在不同记录中反复出现，也可能使模型记住身份或固定基线。若目标是预测后来时段，应按时间向前划分；若目标是泛化到新设备，应按实体隔离。必要时结合时间和实体，明确究竟允许模型见过哪些历史。

异常特征必须按检测时点构造。使用故障后维修次数、最终状态或未来窗口统计，会让检测看似优秀却无法部署。即使训练目标无监督，这些未来信息也会改变异常排序。将异常发生后的数据用于更新正常参考，还可能使评价间接吸收测试事件。应冻结参考模型或明确在线更新协议，再按真实顺序回放。

<a id="unsup-3-32"></a>

### 8.3 审核选择偏差与未观察真值

如果只有被旧模型报警的记录得到人工标签，那么未报警记录的风险未知。只在已有标签上评价新模型，实际上评价的是旧模型筛选后的子总体；新模型提出的不同候选可能完全没有标签。解决办法包括从全总体随机抽样审核、分层抽样并记录概率，或专门审核新旧模型分歧区域。每种方案有成本和估计假设，不能把未审核自动当正常。

若采用概率抽样，可在已知且非零的抽样概率下用逆概率权重估计总体量，但极小概率造成高方差，且审核质量仍需可靠。若某区域从不抽样，就无法无假设地估计该区域风险。评价报告应列明覆盖盲区，不能用一个加权公式掩盖根本没有观测支持的部分。

<a id="unsup-3-33"></a>

### 8.4 事件级召回和告警去重

将连续窗口报警合并为事件，可减轻同一故障造成的重复调查。合并规则包括同实体、最大间隔、持续时长及恢复后重置。事件匹配也要规定允许提前或延迟多少时间，以及一条告警能否匹配多个故障。定义不同，事件级精确率和召回可能明显变化，必须在看测试结果前固定。

检测延迟可定义为事件开始到首次有效告警的时间；提前量则关注在可行动窗口之前是否预警。仅在故障结束后命中可能没有维护价值，不能因记录上重叠便算成功。也应报告每台设备每周的告警负担，而不只看所有窗口平均误报率，因为相关误报可能集中压垮少数实体或某个班次。

<a id="unsup-3-34"></a>

### 8.5 实验五：固定预算指标和基率算例

下面用可手算排序核验前四条审核的精确率、召回和 AP，并用基率公式比较两个总体。代码没有训练模型，因为其目的是隔离评价逻辑，避免把模型随机性与指标计算混在一起。

```python
import numpy as np
from sklearn.metrics import average_precision_score
labels = np.array([1, 0, 1, 0, 0, 1, 0, 0])
strength = np.array([8., 7., 6., 5., 4., 3., 2., 1.])
order = np.argsort(-strength, kind='stable')
budget = 4
tp = labels[order[:budget]].sum()
precision = tp/budget
recall = tp/labels.sum()
manual_ap = (1 + 2/3 + 3/6)/3
assert np.isclose(precision, .5) and np.isclose(recall, 2/3)
assert np.isclose(average_precision_score(labels, strength), manual_ap)
def ppv(base_rate, tpr=.8, fpr=.01):
    return base_rate*tpr/(base_rate*tpr+(1-base_rate)*fpr)
assert ppv(.001) < ppv(.01)
print('budget precision/recall/AP:', precision, recall, manual_ap)
print('PPV at base .001/.01:', ppv(.001), ppv(.01))
```

本机结果对应前四条命中两条，总共三条正例，因此召回三分之二；AP 是正例所在排名的精确率平均。排序没有并列，使手算清楚；真实数据有并列、样本权重或延迟标签时，应按明确接口与协议处理。相关定义可核对 [平均精确率接口](https://scikit-learn.org/1.8/modules/generated/sklearn.metrics.average_precision_score.html)。

<a id="unsup-3-35"></a>

## 9. 校准尾部：有限样本保证依赖哪些条件

在没有目标风险标签时，可以用独立正常校准集判断一个新分数相对于参考有多极端。设模型已在另一份训练集固定，异常强度越大越异常；用校准分数 $s_1,\ldots,s_m$ 定义新样本的尾部值 $p(x)=[1+\#\{i:s_i\ge s(x)\}]/(m+1)$。较小值表示新样本的强度在校准集中少见，但它不是目标有害事件的后验概率。

<a id="unsup-3-36"></a>

### 9.1 排名论证与边际覆盖

若校准样本与新正常样本在固定评分规则下可交换，且没有破坏规则的数据选择，新的 $m+1$ 个分数中该样本的排名具有对称性。因此以合适的离散阈值判定尾部，可得到对正常新样本的有限样本边际错误控制；使用包含等号的计数对并列通常更保守。这一论证依赖交换性，不依赖分数本身是正确密度。

把排名论证写成完整规则。先用独立训练集固定评分函数，分数越大越异常。记正常校准分数为 $S_1,\ldots,S_m$，新样本分数为 $S_*$，定义上尾值

$$
p_*=\frac{1+\sum_{i=1}^{m}\mathbf1\{S_i\ge S_*\}}{m+1},
\qquad\text{当 }p_*\le\alpha\text{ 时报警}.
$$

分子中的一来自新样本自身，不能随意删去。无并列时，令 $R_*=1+\#\{i:S_i>S_*\}$ 为从大到小的名次。交换性使 $R_*$ 在 $1,\ldots,m+1$ 中均匀，因而

$$
P(p_*\le\alpha)
=\frac{\lfloor\alpha(m+1)\rfloor}{m+1}\le\alpha.
$$

有并列时，先想象在同分组内独立随机排次；使用包含等号的确定计数，相当于把新样本放到该同分组最靠后的名次，只会使尾部值增大。因此上述不等式继续成立，但通常更保守。证明只使用对称排名，没有把分数解释成异常概率。

若 $m=19$ 且 $\alpha=0.05$，只有新分数严格大于全部十九个校准分数才报警，尾部值为 $1/20$；与最大校准分数并列时，尾部值至少 $2/20$，不报警。若希望 $\alpha=0.01$，同样十九个样本下最小尾部值仍是 $0.05$，这条确定规则不会报警；不能把普通经验百分之九十九分位数硬凑成相同的有限样本保证。

这个例子还能具体解释条件保证的缺口。假设正常分数独立服从 $\operatorname{Uniform}(0,1)$，令校准最大值为 $M$。上述百分之五规则在给定校准集后，对新样本的误报率为 $1-M$，不是恒定的 $0.05$；只有再对校准集平均，才有 $E[1-M]=1/20$。例如某次恰好 $M=0.8$，该次已固定系统的条件误报率为百分之二十。因此边际控制不能直接改写为每一份校准集都满足同样误报上限。

“边际”意味着对校准与新样本共同随机性平均的保证，不表示每个群体、每个时刻或给定校准集后的误报率都精确相同。季节变化、同设备相关样本、反复调参后复用校准集，都会破坏简单论证的前提。可阅读 [共形预测教程](https://arxiv.org/abs/2107.07511) 进一步区分交换性、边际保证和条件保证。

<a id="unsup-3-37"></a>

### 9.2 分辨率和重复使用

最小非零尾部值为 $1/(m+1)$，若希望分辨千分之一量级尾部，只有几十个正常校准点显然不足。极小尾部的经验估计还具有明显不确定性，应通过样本量规划或合理尾部分布建模处理。后者增加了参数假设，需要诊断，不能凭外推曲线平滑就声称精确控制极低误报。

同一系统每天做大量检测，即使单次误报受控，总告警数和连续运行错误事件仍是另一层问题。可按实际调查容量设计阈值、分组和去重，或者研究适合序列决策的错误控制。不要把单次边际结论无条件升级成“长期不会有很多误报”，也不要将每个异常尾部值当作独立概率相乘。

<a id="unsup-3-38"></a>

### 9.3 校准集污染与目标漂移

若所谓正常校准集已经含大量高分故障，尾部分布会变厚，阈值变宽，真实故障可能被吸收。若校准集只包含特别容易的核心正常，阈值又可能过严。需要记录筛选机制、审核质量与时间覆盖，必要时做污染敏感性分析。统计校准不能自动修复错误的正常定义。

当新正常模式出现，应先区分总体正常演化与目标风险事件。立即将所有告警加入正常参考，可能让系统失去发现持续故障的能力；永不更新又会让误报不断增长。可以设置反馈成熟期、审核后的参考更新和版本回放，并在保留的旧事件集上检查新模型是否遗忘重要风险。更新策略本身属于被评价系统。

<a id="unsup-3-39"></a>

## 10. 异常强度、事件概率与解释证据

一个分数可以很好地排序统计偏离，却对目标风险没有良好概率解释。要得到 $P(Y=1\mid x)$，需要明确目标事件、代表性标注、基率和校准验证。风险概率还随业务总体变化：从高风险审核队列迁移到全体用户，先验和条件机制都可能不同。解释应区分“为什么这个点偏离参考”与“为什么它会发生目标事件”。

<a id="unsup-3-40"></a>

### 10.1 解释不能只给一个特征排行

可将被报警样本与同上下文的正常近邻比较，展示原始值、正常范围、缺失与数据质量，以及哪些组合关系被破坏。对距离分数，单坐标贡献可有清楚公式；对隔离或局部密度，解释往往需要路径、邻域和对照，不能将某个全局特征重要性直接当作这条告警的原因。

反事实解释也要受可行性约束。若建议同时降低总金额和交易数，却没有保持两者关系，可能得到不存在的样本。解释工具可以揭示模型依据，但不能仅凭改变模型分数就声称改变真实风险。应以领域机制和审核反馈核验，并避免把设备编号、来源等捷径误当作因果因素。

<a id="unsup-3-41"></a>

### 10.2 多分数融合需要共同参照

隔离强度、LOF 和重构误差的单位不同，直接相加可能让量纲最大的一项主导。可在独立正常校准集上转成分位或尾部值，再按预定规则组合，但相关性会影响联合错误控制。取最大、平均或要求多个同时超阈值，分别强调不同偏离，应该用代表性正常与目标事件评价，而不是认为“多个算法同意”就必然正确。

若用标注学习融合权重，它已经成为监督层，需要训练验证划分和独立测试；若用无标签规则，也要明确其假设。特别是不同模型都使用同一错误来源特征时，意见一致可能只是共同偏差。多样性应体现在检测机制和证据上，而不是模型名称数量。

<a id="unsup-3-42"></a>

### 10.3 失败分类比不断调阈值更重要

误报可来自合法少数群体、季节性变化、采集错误和边界不确定；漏报可来自特征不可辨、异常已被参考吸收、局部互相支持或阈值预算不足。每类原因的修复不同。采集错误应修管线，目标不可辨需要新信息，预算不足则可能是运营约束；不能把所有问题都交给更复杂模型或一个更低阈值。

建立失败样本表时，应记录检测时已知上下文、原始证据、分数、阈值、审核结论与结论时间。对无法确认的样本保持未知状态，并检查审核一致性。这种结构使后续更新能区分模型变化与标签变化，也使“分数提高了”能够联系到具体错误减少，而不是只在抽象曲线上移动。

<a id="unsup-3-43"></a>

### 10.4 从决策代价推导为何密度不等于风险

假设正常与目标异常分别具有条件密度 $p_0(x)$ 和 $p_1(x)$，目标先验为 $\pi$，误报代价为 $C_{\mathrm{FP}}$，漏报代价为 $C_{\mathrm{FN}}$。若正确决策代价取零，报警的条件期望代价为 $C_{\mathrm{FP}}P(Y=0\mid x)$，不报警的代价为 $C_{\mathrm{FN}}P(Y=1\mid x)$。比较二者，最优决策需要后验比超过代价比；使用贝叶斯公式，可改写成似然比 $p_1(x)/p_0(x)$ 超过包含先验与代价的阈值。

这个推导解释了为什么只估计正常密度并不能普遍解决风险检测。正常密度低的区域，如果目标异常密度也几乎为零，未必值得优先调查；正常密度高的区域，如果有害机制同样集中并且相对比值更高，仍可能很危险。没有异常数据时可以采用合理备择或偏离分数作为探索工具，但不能宣称已经恢复了代价最优规则。这里不是要求所有应用都必须知道异常分布，而是明确无监督证据缺少了哪一项信息。

若审核本身也有成本和误差，问题进一步变为多阶段决策：先选择谁被审核，再由审核结果决定行动。固定预算下通常关注单位审核收益，但审核时间可能随案例复杂度变化，一百条记录不一定是一百份相同成本。可将成本估计纳入排序与工作点，并检查它是否在预测时可获得。若训练标签只来自既往审核，选择机制又会影响可观察的目标分布，因此评价设计与最优决策推导必须一起考虑。

<a id="unsup-3-44"></a>

### 10.5 真实运行输出怎样约束结论

本机五组实验分别得到平方半径均值约一百点零四、同一隔离排序下十五与六十条训练告警、新颖性远点明显高于正常中位强度、子空间内远点零残差，以及固定预算精确率二分之一和平均精确率约零点七二二二。它们各自只核验一项机制：典型壳层、阈值偏移、接口数据边界、重构盲区和评价计算。不同机制不能合并为一次真实风险系统的有效性证明。

继续学习时可以逐个破坏假设：将正常改为两群密度不同的数据，给参考加入紧密异常团，增加无关维度，或让未来正常整体漂移。每次只改一项并保留相同评价协议，记录哪一种分数首先失效以及为什么。这样得到的失败分析能够指导选择表示、参考和标签，而不是仅积累更多算法名字。若所有分数都失败，也应检查现有特征是否含足够区分信息，统计方法不能从完全相同的观测恢复不可见原因。

## 11. 十六道进阶练习与逐步解析

<a id="unsup-3-46"></a>

### 11.1 为什么节假日报警激增不证明风险增加

**题目。** 历史工作日训练的模型在节假日标出很多异常，能否直接宣布发现大量故障？

**解析。** 只能说明新数据偏离参考评分规则。应核对节假日正常机制、设备与采集版本、目标事件和阈值负担，区分正常变化与风险。可比较相同节假日历史、独立正常审核和目标事件证据。若把这批记录全部加入正常参考，也可能吸收真正故障，因此更新需要成熟反馈，而不是在“全部危险”和“全部正常”之间机械选择。

<a id="unsup-3-47"></a>

### 11.2 原点密度最高为何反而不典型

**题目。** 一百维标准正态中，原点为何不能代表随机正常样本的典型位置？

**解析。** 正常平方半径均值为一百、标准差约十四点一四，大多数质量在远离原点的壳层。原点单点密度高，但附近小球体积很小，概率质量不一定大。典型性需要考虑密度与体积的组合。这个结论不说明原点一定是业务风险，只反驳最高密度与典型样本位置必然一致；目标风险还需另行定义和验证。

<a id="unsup-3-48"></a>

### 11.3 将异常分数缩放到零一是否获得概率

**题目。** 最小最大归一化后的零点八，能否写成百分之八十欺诈概率？

**解析。** 不能，缩放仅改变范围，未使用事件频率和代表性标注。加入一个更极端样本还会改变其他人的归一化值，真实风险并没有因此变化。若需要概率，应明确定义目标事件与总体，用独立标注校准并检查可靠性；审核选择偏差、基率漂移和标签延迟都要纳入。分数排序有用并不要求它已是概率。

<a id="unsup-3-49"></a>

### 11.4 污染参数为何没有估计真实风险率

**题目。** 实验二改变 contamination 后训练告警从少变多，哪些结论成立？

**解析。** 在该实现、相同数据与树随机状态下，原始分数相同，偏移与阈值改变，从而工作点改变。这没有增加任何关于风险真值的信息。不同算法可能将类似参数用于不同训练机制，所以不能无条件推广“污染参数永远只调阈值”。应核对官方接口并通过固定随机状态的对照实验验证具体版本行为。

<a id="unsup-3-50"></a>

### 11.5 局部稀疏与全局稀疏有什么区别

**题目。** 两个正常群体，一个很密一个很稀，为什么全局近邻距离可能误伤后者？

**解析。** 稀疏群体内部距离天然更大，全局阈值可能将其整体判异常。LOF 比较邻域相对密度，有机会保留内部一致的稀疏群体；但若邻域跨群体，或少数群体规模小于邻居数，仍可能失败。应构造不同密度与比例的合成对照，并在独立正常数据分群检查误报，不能只看全体平均表现。

<a id="unsup-3-51"></a>

### 11.6 异常团为什么可能互相掩护

**题目。** 一批有害记录形成紧密小团，默认混合数据 LOF 为什么可能不把它们排在最前？

**解析。** 若它们数量足以构成邻域，局部密度与邻居相近，LOF 可能接近一。它衡量局部相对支持，不知道业务有害定义。若在纯正常参考上做新颖性检测，同一团缺少正常支持，可能更易检出。解决需匹配训练任务、增加目标相关信息或监督反馈，不能只把参数调到恰好分离当前小团后宣称普遍解决。

<a id="unsup-3-52"></a>

### 11.7 为什么不能用新颖性接口复核训练 LOF

**题目。** 设置 `novelty=True` 后对训练矩阵调用评分，与默认训练评分不同，是否一定是库错误？

**解析。** 不是。训练点的邻域构造和作为新查询的邻域处理不同，官方要求新颖性预测接口用于未参与拟合的数据。应使用训练属性核对训练分数，以独立生成或留出的新样本检验预测。数组形状相同不表示数据角色相同。实验三故意将参考、混合分析集和新样本分开，使每个接口的语义可检查。

<a id="unsup-3-53"></a>

### 11.8 零重构误差能否排除异常

**题目。** 一个点被 PCA 或自编码器几乎完美重建，是否可直接标正常？

**解析。** 不能。实验四中沿主子空间走到极远处的点残差为零，却超出训练得分范围。重构检查主要关注离表示流形的偏离，对流形内部的异常幅度可能不敏感。可以结合得分距离与残差，但要统一校准并评价；更大网络也可能学到更宽的重构能力，训练损失低并不等于异常可分。

<a id="unsup-3-54"></a>

### 11.9 固定误报率为什么精确率仍变差

**题目。** 模型 TPR 为零点八、FPR 为零点零一，部署基率变低，审核命中率为何下降？

**解析。** 正常样本数量相对风险样本增加，误报分母变大。代入贝叶斯公式即可得到精确率随基率下降。平衡测试集上的精确率不能直接迁移到自然稀有总体；若条件性能也随来源变化，还不能只做先验校正。应报告真实或假设基率、具体告警数和对应不确定性，而不是仅比较一个 ROC 面积。

<a id="unsup-3-55"></a>

### 11.10 只审核旧告警如何偏置新模型评价

**题目。** 新模型在已有标签集表现不好，是否证明它对全体用户更差？

**解析。** 若标签集仅由旧模型筛选产生，它代表的是旧告警总体。新模型擅长的新区域可能没有标签，未审核也不能当正常。应从总体随机或分层抽样，保留抽样概率，重点审核新旧分歧并估计相应总体量。没有任何样本支持的区域无法无假设估计；应在报告中明确盲区而非强行输出全体精确率。

<a id="unsup-3-56"></a>

### 11.11 连续报警一千次是不是一千次成功

**题目。** 同一故障持续期间每秒报警，记录级召回很高，维护系统就一定有效吗？

**解析。** 应按事件和行动评价。合并重复告警、定义事件匹配窗口、首次检测延迟和每设备负担，避免同一故障被重复计数。若首次报警已经晚于可干预时机，记录级命中可能没有实际价值。评价规则要事先固定，不能为某模型调整事件合并宽度后再与另一模型比较同一列分数。

<a id="unsup-3-57"></a>

### 11.12 正常校准尾部值是不是有害概率

**题目。** 某点的校准尾部值为零点零一，是否意味着它有百分之九十九的风险？

**解析。** 不是。它表示在指定评分规则与正常参照下，该强度处于罕见尾部；有限样本排名保证依赖交换性，且主要控制正常误报的边际行为。事件概率还需异常先验和事件条件机制。一个新而无害的正常模式也可得到很小尾部值。应将统计偏离证据与业务风险证据并列，避免把两种概率方向颠倒。

<a id="unsup-3-58"></a>

### 11.13 五十个正常校准点能控制极小尾部吗

**题目。** 用五十个分数得到经验尾部值，能否精确分辨万分之一的异常程度？

**解析。** 该排名值最小为五十一分之一，远大于万分之一，经验分辨率不足。即使用插值画出平滑曲线，也没有增加尾部样本。可增加校准数据，或在明确分布假设下建立尾部模型并诊断敏感性。极低误报目标还需要考虑时间相关和大量重复检测，单次尾部估计并不自动控制长期告警总量。

<a id="unsup-3-59"></a>

### 11.14 为什么多模型一致也可能一起错

**题目。** 隔离森林、近邻和重构都报警，是否足以确认有害？

**解析。** 它们可能共享同一错误表示，例如把来源编号当连续量，或把合法少数模式排除在参考之外。多模型一致提供的是若干机制的偏离证据，并不替代目标标签。应检查各自依据是否独立、原始数据是否有效、同上下文正常是否类似，并核对审核结果。组合分数也要在共同校准总体上评价，不能直接相加不同比例的数值。

<a id="sec-6-1"></a>

<a id="unsup-3-60"></a>

### 11.15 边界追问：污染比例能否反推真实异常率

**题目。** 指定百分之二污染后恰好输出百分之二负一标签，为什么这不是一次风险率测量？

**解析。** 输出比例受到参数和阈值定义控制，未获取独立真值。真实风险可能集中在统计常见区域，也可能正常少数被误报；并列还可能使实际比例偏离指定值。风险率测量需要代表性样本及明确审核标准，并给出抽样和标签不确定性。不能用自己设定的比例再次证明该设定正确，这会形成循环论证。

<a id="unsup-3-61"></a>

### 11.16 如何设计最小而有说服力的对照

**题目。** 希望判断误报来自尺度还是算法，如何避免同时改变太多因素？

**解析。** 固定样本与划分，在同一算法中仅切换一种有明确含义的缩放，检查分层误报与典型样本；再固定表示比较算法。每一步保持相同校准和审核预算，并记录训练随机性。若先换特征、再换算法、同时调阈值，即使结果改善也无法确定机制。对照应对应一个可证伪解释，再逐步加入真实复杂性。

<a id="unsup-3-62"></a>

## 12. 进阶研究与完整系统交付

分布外检测还应区分协变量变化与目标机制变化。输入总体改变但任务关系保持时，模型可能只需要适应新的正常覆盖；输入分布近似不变而故障概率改变时，纯输入异常分数甚至可能看不见风险变化。可以在合成实验中固定输入分布而改变标签机制，再与只移动正常均值的情形对照，观察哪些指标有响应。这个对照说明监控输入漂移和监控目标结果需要共同进行，二者互相补充，却不能互作充分替代。延迟反馈使后者更困难，应在报告中写明成熟窗口与仍未知的事件。

异常检测研究值得同时建立四类合成偏离：全局远点、局部稀疏点、紧密新团和破坏变量关系但幅度普通的点。逐步改变污染比例、正常小群体规模、维数和无关特征，观察各算法在哪些机制上有效。每种偏离都对应具体备择，避免只用特别容易的远点使所有算法看起来完美。合成实验支持机制分析，现实数据支持外部适用性，两者不能互相替代。

进一步可研究上下文条件化与分布变化。比较全局模型、分群模型与共享参数的条件模型，分别检查总体误报和小群体支持；设计时间向前回放，区分正常季节变化、突发数据质量问题与真实目标事件。评估模型更新时，应在新总体与保留旧事件上共同检验，避免只看近期平均损失而忘记过去重要故障。

最终交付应包含参考集定义、检测时可用特征、评分方向、阈值来源、审核容量、事件去重与拒绝规则，连同模型和校准版本。报告具体正常误报、目标召回、延迟及群体分布，说明标签覆盖和未知区域。若尚未获得代表性事件标签，可以交付有用的探索排序，但应将风险概率与实际收益列为待验证对象，不能因算法输出一个数就越过证据边界。

一个可靠系统不是永远不报警或永远发现新模式，而是能够解释每个告警相对于哪个参照偏离、需要什么证据确认、反馈如何改变后续模型。把统计假设、实现接口、评价单位和业务行动连接起来，才真正理解了异常检测。学习到这里，应能够既推导简单分数，也指出它会漏掉哪一类偏离，并为这类失败设计下一轮可执行实验。
