# 无监督学习

从表示、距离与生成假设出发，推导聚类、降维和异常分数，再用独立对照、稳定性与外部任务核验结构主张。

**先修知识：** 距离、线性代数；NumPy。

## 学习顺序与覆盖范围

第 1 章建立距离、聚类目标与算法不变量；第 2 章从 PCA 重构接到邻域可视化、训练外映射和结构验证；第 3 章区分异常分数、密度、典型性与事件风险；第 4 章把表示、搜索、重采样和外部核验组织成完整实验。线性代数的 PCA 章提供分解基础，本主题重点讨论这些计算在机器学习中的目标和评价边界。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

| [聚类距离与簇的假设](01-聚类距离与簇的假设.md) | 距离与表示；Lloyd 下降和局部固定点；k-means++；DBSCAN、层次、谱及验证条件 | [进入讲解](01-聚类距离与簇的假设.md#deep-dive-2) |

## 如何完成本主题

完成各章后，先独立作答[综合练习：把聚类发现转为外部核验](04-聚类与降维的完整实验协议.md#sec-8-1)，再对照逐步解析与验收要求。

完成后，应能推导一个目标的更新与不变量，构造算法固定点但不符合业务结构的反例；独立核对降维的重构、邻域和拟合边界；区分密度低、局部稀疏、不典型与目标异常；再以共同样本、合理重采样和独立外部信息验证发现。结果稳定、图像分离与任务有效应分别提供证据。
