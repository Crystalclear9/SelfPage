## 1. 从一个可检验的问题开始

聚类的输入是一组没有作为训练目标的类别标签的观测，输出通常是样本的分区，有些方法还输出噪声、层次或软归属。问题的难处首先在于什么应该被放在一起。按购买金额、购买频率和商品偏好分组，研究的是三种不同结构；同一位顾客可以在其中拥有不同邻居。算法只能把已经写进表示和目标的相似性变成计算结果，不能替我们决定什么相似性有用。本章把这一选择拆成样本单位、表示、距离、簇假设、优化和核验六个环节。

例如希望为设备建立维护群组。若每行是一分钟窗口，高频采样的设备会在数据中反复出现，其权重可能远大于其他设备；若每行是整台设备的历史摘要，瞬时故障模式又可能被平均掉。首先写明聚类单位与希望采取的行动，然后说明两条记录在何种条件下可视为重复证据。采样设计不同，经验分布就不同，即使特征名称和算法参数完全相同，也不应期待输出一致。

<a id="unsup-1-2"></a>

### 1.1 分区、重叠群体与连续谱

硬分区将每个非噪声样本分配到一个簇，等价于定义一个同簇关系。关系满足对称性和传递性，而日常的“相似”未必传递：甲像乙、乙像丙，甲与丙仍可能非常不同。因此把局部相似压成全局分区，本身已增加了结构。单链接允许通过很多短边建立长链；最近中心方法则要求每个点接受某一个中心的代表。这两种方式并没有在求同一个答案。

一些人群更适合连续坐标，例如消费能力从低到高平滑变化，没有客观分界。强行指定五组仍能得到五个编号，但边界主要由压缩需求决定。另一些对象兼具多个兴趣，使用混合成员或主题权重可能比互斥群组合理。研究报告应把“便于管理的离散摘要”与“存在分离的生成类别”分开表述，前者有明确用途也完全可以成立，不必借后者为它背书。

<a id="unsup-1-3"></a>

### 1.2 三种常见的聚类用途

压缩用途关注用少量代表替代大量记录，其误差可由重构失真衡量；探索用途关注生成可核验的假设，例如某类故障是否集中在特定设备版本；分层行动用途关注按组采取不同措施后是否更有效。三者可以共享算法，但评价不能互换。压缩误差降低，未必带来更好的干预；人眼看见漂亮团块，未必表示未来样本可以稳定分配。

研究前可完成一句明确的承诺：“对于某时间段内符合条件的某类实体，使用截至观察时点已知的某些特征，建立可用于某项行动的分组，并通过某个独立结果核验。”这句话使信息边界、样本总体和用途同时可查。若目前只有探索目的，也应明确标注；不确定性是探索的正常属性，只有在把探索结果当成已经确认的事实时才成为推理错误。

## 2. 表示与距离怎样改变问题

设样本 $x_i\in\mathbb R^d$。欧氏距离定义为 $d(x,y)=\sqrt{\sum_j(x_j-y_j)^2}$，平方距离常用于优化，但平方距离本身不满足一般的三角不等式。把二者都叫“距离”在交流中很常见，推导近邻索引或理论保证时却应说明使用的是哪一个。单位变换 $x'_j=a_jx_j$ 会将平方差乘以 $a_j^2$，因此换单位等价于改特征权重，不能把它当成无关显示设置。

<a id="unsup-1-5"></a>

### 2.1 标准化是一个具体的权重假设

若收入列以元计，年龄列以岁计，原始欧氏平方距离可能几乎由收入决定。标准化 $z_j=(x_j-\bar x_j)/s_j$ 后，各列差异以其经验波动为单位衡量。这能消除简单的线性单位变换影响，却同时声明“一倍标准差的收入差”和“一倍标准差的年龄差”具有相同初始权重。此声明是否合理，要由任务判断，而不是由数值处理惯例决定。

标准差会受极端值影响；稳健缩放改用中位数和四分位距，又对应另一种尺度。对数变换将金额绝对差转为更接近相对差的量，但零值、负值及变换常数需要明确处理。常数列在标准化前应识别，不能用接近零的分母制造巨大距离。训练外使用时，所有均值、尺度、截断界限都应由训练数据确定并保存，新批次独立标准化会改变原来中心的含义。

<a id="unsup-1-6"></a>

### 2.2 马氏几何与协方差估计

给定正定矩阵 $M$，定义 $d_M^2(x,y)=(x-y)^TM(x-y)$。若 $M=L^TL$，此距离就是变换 $Lx$ 后的欧氏距离，因此很多所谓“距离选择”实际上是在选择一个线性表示。取 $M=\Sigma^{-1}$ 可降低正常共同波动方向的权重，但协方差估计应来自明确参考总体。如果混合群体的均值差被吸收入总体协方差，白化反而可能削弱希望发现的群体差异。

高维小样本时样本协方差可能奇异；直接求逆会失败或放大估计误差。可用收缩、低秩模型或领域指定的权重，随后检查对正则强度的敏感性。伪逆会将零空间方向赋零权重，两个不同点可能得到零距离，此时得到的是半度量。数学名词的区别直接影响解释：某些方向被忽略，不是这些方向已经被证明没有信息。

<a id="unsup-1-7"></a>

### 2.3 角度、类别与混合数据

余弦相似度将方向作为重点，适合长度主要代表规模而方向代表构成的场景。对两个非零且单位归一化的向量，$\|u-v\|^2=2(1-u^Tv)$，所以在固定单位向量之间，欧氏距离和余弦距离给出相同的近邻排序。然而普通 k-means 的均值通常不是单位向量；在归一化输入上运行普通 k-means，与每轮都将中心重新归一化的球面 k-means，仍是不同优化问题。

类别编号不能直接当成连续坐标。“红、蓝、绿”编码成零、一、二，会虚构红绿比红蓝更远的关系。独热编码使不同类别之间距离相同，但一个高基数类别特征与一个连续特征的相对权重仍需设定。混合数据可建立每个字段的有界差异并加权汇总，缺失字段的分母策略也要规定。距离定义中每个细节都应该能用两条实际记录解释，而不只是因为某函数能接收它。

<a id="unsup-1-8"></a>

### 2.4 缺失、重复与组权重

用列均值补缺失，会把缺失记录拉向中心；额外添加缺失标识，则可能产生按数据采集流程形成的簇。二者都有合理用途，取决于缺失机制是否是研究对象。可把缺失模式单独画成交叉表，观察簇是否主要由来源、设备版本或字段可用性区分。若某分组实际识别的是旧采集软件，给它赋予行为语义就缺乏证据。

重复记录相当于增加样本权重。若一个大客户有一百条记录，小客户只有一条，普通聚类压缩的是记录分布，而不是客户均匀分布。可先聚合到客户级，或使用样本权重，但两种做法对组内变化的保留不同。权重也不应只在训练中心时使用而在评价时忘记，否则训练目标与报告目标已经不一致。

## 3. k-means 的目标、几何与完整推导

对 $n$ 个向量和 $k$ 个中心，目标为 $J(c,\mu)=\sum_{i=1}^n w_i\|x_i-\mu_{c_i}\|^2$，其中 $w_i>0$，$c_i\in\{1,\ldots,k\}$。先取所有权重为一理解算法，再推广到加权情形。这里的中心是表示空间中的向量，不要求是某条实际观测；在独热编码空间，中心坐标可解释为组内类别比例，却未必对应任何合法个体。

<a id="sec-2-1"></a>

<a id="unsup-1-10"></a>

### 3.1 分配步骤为什么可以逐点独立完成

固定中心后，目标是每个样本项的和，不同样本的标签没有容量约束等耦合，因此每个样本选择最近中心即可使本项最小。正权重乘在整项上，不改变该点最近中心的选择。若要求每簇至少有一定人数或满足群体比例，分配之间就出现耦合，逐点最近选择不再是正确的子问题求解器。实际规则改变了数学问题，需要相应的约束优化。

任意两个中心 $\mu_a,\mu_b$ 的等距边界满足 $2x^T(\mu_b-\mu_a)=\|\mu_b\|^2-\|\mu_a\|^2$，是超平面。每个中心的最近区域是若干半空间的交，因此为凸的 Voronoi 单元。数据支撑本身可以不连续，但算法的分配边界仍受这一几何约束。同心环的内外关系无法简单靠两个中心的最近区域表达，这比说“算法不适合复杂形状”更具体。

<a id="deep-dive-2"></a>

<a id="unsup-1-11"></a>

### 3.2 更新步骤、方差分解与唯一性

固定一个非空簇 $C$，定义总权重 $W=\sum_{i\in C}w_i$ 和加权均值 $\bar x=\sum w_ix_i/W$。将 $x_i-\mu=(x_i-\bar x)+(\bar x-\mu)$ 展开平方，交叉项包含 $\sum w_i(x_i-\bar x)=0$，故

$$
\sum_{i\in C}w_i\|x_i-\mu\|^2=\sum_{i\in C}w_i\|x_i-\bar x\|^2+W\|\mu-\bar x\|^2.
$$

右侧第一项固定，第二项非负，只有 $\mu=\bar x$ 时为零，所以均值是唯一最优中心。这个证明不仅给出求导结果，还明确了正权重和非空簇的条件。若簇为空，$W=0$，目标对该中心没有约束，不能使用除法公式；实现必须决定保留、重置还是拆分其他簇。异常的负权重更不能套用上述最小化结论。

<a id="sec-1-1"></a>

<a id="unsup-1-12"></a>

### 3.3 一次可以逐项复核的手算

样本为零、二、八、十，初始中心为零和八。最近分配得到前两点一组、后两点一组，当前平方误差为 $0+4+0+4=8$。中心更新成一和九后，误差为 $1+1+1+1=4$。再次分配不变，算法达到该分配的固定点。注意应区分“分配后、更新前的八”和“更新后的四”，否则记录目标曲线时容易把不同状态混在一起。

加入权重后，若点二的权重为三，其所在簇均值变成一点五，簇误差为 $1\times1.5^2+3\times0.5^2=3$；相当于在未加权数据中将点二重复三次。这个等价关系只涉及整数频数的目标；非整数权重可以理解为质量，并不需要真的复制记录。解释中心时，应使用加权的分位数和规模说明，不能只报未加权人数。

<a id="unsup-1-13"></a>

### 3.4 单调、终止和局部稳定是三种结论

最近分配不增加目标，均值更新也不增加目标，所以完整迭代形成非增序列；目标有零下界，因此目标值收敛。仅凭“有界且单调”不能推出标签一定在有限步停止，也不能推出全局最优。对有限数据、确定性平局规则及妥善的非空处理，经典 Lloyd 过程可在有限分配状态中达到稳定；若实现遇到平局反复改标签，就需要额外处理以防无意义切换。

实际程序常按中心移动量或迭代上限停止。此时最后的标签与中心是否严格互为最优，取决于停止后的重新分配与输出规则，不应假定任意实现都完全一致。误差允许极小浮点波动，断言时应给合理容差，但容差不能掩盖明显上升。优化固定点只说明当前两块变量无法各自改进，跨越多个标签的联合变化仍可能降低目标。

<a id="unsup-1-14"></a>

### 3.5 实验一：逐步证明下降，独立核验输出

下面保留每次分配与更新的误差，使用四个点给出手算交叉核验。所有实验均自包含、不读外部文件，随机实验显式给出种子；代码输出只表示本次运行事实，不构成所有数据上的性能保证。

```python
import numpy as np
X = np.array([[0.], [2.], [8.], [10.]])
centers = np.array([[0.], [8.]])
history = []
for _ in range(5):
    dist2 = ((X[:, None, :] - centers[None, :, :]) ** 2).sum(axis=2)
    labels = dist2.argmin(axis=1)
    assigned = float(dist2[np.arange(len(X)), labels].sum())
    assert all(np.any(labels == j) for j in range(2))
    updated = np.stack([X[labels == j].mean(axis=0) for j in range(2)])
    after = float(((X - updated[labels]) ** 2).sum())
    assert after <= assigned + 1e-12
    if history:
        assert assigned <= history[-1][1] + 1e-12
    history.append((assigned, after))
    if np.array_equal(updated, centers):
        break
    centers = updated
assert np.allclose(centers.ravel(), [1., 9.])
assert history == [(8.0, 4.0), (4.0, 4.0)]
print('assignment/update:', history)
```

若把中心更新改成任意成员而仍用平方误差，下降保证就会失去证明基础；若改用绝对误差，则一维中位数才是最优更新。算法的“分配—更新”外形相同，不意味着它们优化同一目标。本实验刻意使用没有空簇和平局的样本，让每个等式都能对应推导；复杂实现应另行覆盖这些边界，而不是在证明中悄悄忽略。

## 4. 初始化、局部解与理论保证的边界

单调下降并不消除初始化的重要性。若两个初始中心落在同一个密集区域，另一个远处群体可能暂时由某中心兼顾，随后形成稳定却较差的折中。一种具体检查办法是固定同一份表示，对多个初始化记录目标分布、最小簇规模和分区相似度。如果目标值近似相同而成员大量变动，可能存在很多几乎等价的划分；若目标差异很大，优化失败与结构不明确可能同时存在，需要分别处理。

<a id="unsup-1-16"></a>

### 4.1 怎样构造一个严格的局部解

考虑一维点零、二、三、四、十、十一，取两个簇。分区 $\{0,2,3,4\}$ 与 $\{10,11\}$ 的中心为二点二五和十点五，边界六点三七五，分配稳定且误差为九点二五。但是仅用某次收敛不能证明这是最优；一维全局最优可以按排序后的所有切分位置枚举，每一侧用均值计算误差。对小数据做穷举，是检验局部算法和建立直觉的实用参照。

为了明显观察坏固定点，可取零、四、五、九、十、十一和两个中心。某些切分可能仍会自行移动到更优状态，因此不能凭画图就宣布构造了局部极小。应实际检查每个点是否位于各中心的最近区域，并列出另一可行分区的更低目标。研究里的反例也应经过这两步核验；仅展示两次随机运行不同不足以说明哪一个更差，更不足以证明全局最优是多少。

一个无需猜测的办法是在一维枚举所有非空连续切分，计算两侧均值，再筛选最近分配与该切分一致的固定点。固定点中目标最大的与全局最小的差距，直接展示交替优化的局限。它同时说明“局部”是相对于何种操作而言：一个固定点无法通过仅更新当前中心或仅重新分配降低目标，却可能通过联合移动中心和成员改进。

<a id="unsup-1-17"></a>

### 4.2 k-means++ 的采样规则与期望界

原始 k-means++ 先从数据中均匀选一个中心，随后按每个点到已有最近中心的平方距离 $D(x)^2$ 比例抽取新中心，直到取到指定数量。这不是简单地每次选最远点：距离大的点概率更大，但仍是随机选择。重复点的零距离不获得额外选择概率；若所有点已经被现有中心完全覆盖，剩余抽样需要单独规定，不能除以零。

在原论文的有限欧氏平方误差设定下，原始采样所得到的初始目标具有相对最优目标的期望对数近似界，常写作 $8(\ln k+2)$ 倍。期望是针对初始化的随机性，不代表每一次运行都落在该比值内；它也不是关于真实类别恢复率的保证。随后执行不增目标的 Lloyd 更新，目标不会更差，因此可承接这一目标上界。不能将这套结论直接移植到任意距离、带容量约束的分配或改写过的中心规则。理论条件与定理见 [Arthur 与 Vassilvitskii 原论文](https://theory.stanford.edu/~sergei/papers/kMeansPP-soda.pdf)。

实际库可能采用每轮尝试多个候选的贪心变体，参数默认值也可能随版本变化。为使比较清楚，本文实验显式给出初始化次数、最大迭代和随机种子；不要把一次贪心初始化的经验表现称作原始采样定理的直接实验验证。理论最坏情况界通常较宽，实际数据上更应记录目标分布与算力消耗，而不是用定理常数预测单次耗时和结果。

<a id="unsup-1-18"></a>

### 4.3 多次重启与停止准则

若单次运行落入目标可接受区域的概率为 $p$，且各重启在给定数据下独立，那么 $r$ 次都未成功的概率为 $(1-p)^r$。这个式子解释重启的作用，但实际的 $p$ 通常未知，不能据此宣布某个固定次数保证成功。使用同一初始化重复运行不会提供独立机会；以不同种子创建数据再比较算法，则同时混入数据变化，应与固定数据上的优化敏感性分开。

比较多次初始化时，应控制总预算。一个方案运行五十次、另一个只运行一次，最终最小误差的差异既包含初始化策略也包含算力。可以同时给出固定重启次数和近似固定运行预算的两套结果，并记录线程数及硬件。若仅为了检查数学正确性，确定性小例子足够；若为了比较优化效率，就需要多数据集、多随机种子和时间分布。

<a id="unsup-1-19"></a>

### 4.4 实验二：枚举一维切分寻找不同固定点

下面对七个一维点列出所有切分，不依赖随机初始化找到坏解。枚举得到的是该一维两中心问题的全局参照：平方距离下存在沿排序连续的最优分配，且每一切分的最优中心可直接算出。输出中的固定点必须重新通过最近中心检验，不能只因中心来自均值便算收敛。

```python
import numpy as np
X = np.array([0., 1., 2., 8., 9., 10., 30.])
options = []
fixed = []
for cut in range(1, len(X)):
    labels = np.r_[np.zeros(cut, dtype=int), np.ones(len(X)-cut, dtype=int)]
    centers = np.array([X[:cut].mean(), X[cut:].mean()])
    loss = float(((X - centers[labels]) ** 2).sum())
    options.append((loss, cut))
    reassigned = ((X[:, None] - centers[None, :]) ** 2).argmin(axis=1)
    if np.array_equal(labels, reassigned):
        fixed.append((loss, cut))
assert len(fixed) >= 2
best = min(options)
assert np.isclose(best[0], 100.) and best[1] == 6
assert max(t[0] for t in fixed) > best[0]
print('global optimum:', best, 'fixed points:', fixed)
```

这个例子中的远点会影响平方误差的资源分配：最优压缩可能让一个中心单独服务远点，其余六点共享另一个中心。若研究希望保留中间两个人群，它与最小平方误差的愿望不同。此时不应把算法按目标做出的选择叫作程序错误，而应重新考虑损失、异常处理或群体约束，并重新评价新问题。

## 5. 从硬分配到高斯混合：联系与不等价

设混合模型 $p(x)=\sum_{j=1}^k\pi_j\mathcal N(x\mid\mu_j,\Sigma_j)$。一般高斯混合不仅有中心，还有混合权重和协方差，后验责任度描述每点对每个分量的相对归属。一个几何上在两中心中间的点，在协方差或权重不同的模型中，未必具有一半一半的责任度。分量是概率模型中的构件，不自动对应互不重叠的自然类别。

<a id="unsup-1-21"></a>

### 5.1 等方差、等权情况下的最近中心

令各 $\Sigma_j=\sigma^2 I$ 且 $\pi_j=1/k$，则后验责任度与 $\exp[-\|x_i-\mu_j\|^2/(2\sigma^2)]$ 成比例。选择责任度最大的分量，等价于选择最近中心。这里等价的是给定参数后的硬归属规则；一般 EM 的更新使用软责任度，所以在有限正方差下，并不等价于 Lloyd 的硬均值更新。

对完整数据的硬标签似然，固定共同方差和等权后，除去常数，最大化似然等价于最小化平方误差。而对边缘似然，需对分量概率先求和再取对数，不能将“和的对数”直接改成最大项。在 $\sigma^2$ 很小时，经过适当缩放的负对数和趋向最小平方距离，这才建立小方差极限联系。极限推导不能反过来证明任意方差下两个算法输出相同。

<a id="unsup-1-22"></a>

### 5.2 不等权与椭圆协方差改变什么

若共同方差保持相同但权重不同，后验最大分配最小化 $\|x-\mu_j\|^2-2\sigma^2\log\pi_j$。较大权重扩大该分量吸收样本的区域，边界相对等权情形移动。若协方差不同，还出现马氏距离和 $\log|\Sigma_j|$ 项，边界一般成为二次曲面。因此把所有混合模型都概括成“软一点的 k-means”，会忽略影响决策的关键项。

协方差使模型能表达长条形群体，也增加估计方差和数值风险。一个高斯分量缩到单个点附近可能导致无约束似然病态增大，实际实现需要协方差正则与收敛检查。模型选择也不能只比较训练似然；更多分量往往更灵活，应考虑惩罚、留出密度或具体任务。即使密度估计很好，分量分解也可能存在多种近似，语义解释仍需外部核验。

<a id="unsup-1-23"></a>

### 5.3 簇中心、原型与稳健损失

平方误差的均值更新会被极端点拉动，因为远点的损失增长更快。改用一维绝对误差时，中位数最优；在多维欧氏距离和而非平方距离下，最优原型是几何中位数；若强制原型必须为观测，则形成 medoid 类问题。这些目标彼此不同，不能随意把“中心取中位数”插入普通 k-means 后继续引用平方误差的单调证明。

稳健化可采用截断、修剪或重加权，但会改变哪些点得到解释。修剪比例若过大，小而真实的群体可能被当作噪声排除。应该同时报告被排除样本的来源与代表，并核验稳健结果是否改善用途。无标签场景无法通过漂亮中心自动判断被删除者是错误记录还是重要罕见模式。

## 6. 密度聚类：核心连通与边界归属

DBSCAN 不以中心平方误差定义簇，而先规定半径 $\varepsilon$ 内的邻域和达到最低样本量的核心点。在本文使用的实现中，计数包括点本身。核心点之间若距离不超过半径便可连接；核心图的连通分量决定密度骨架，非核心点若邻近某个核心点可作为边界加入，否则标为噪声。这样可以连接弯曲结构，但其含义来自局部密度阈值，而不是自动识别一切非球形数据。

<a id="unsup-1-25"></a>

### 6.1 手算核心点与边界点

取点零、零点一、零点二、零点三和一点五，半径零点一一，最低计数三。零点一的邻域包含前三个点，零点二的邻域包含中间三个点，因此二者是核心；两端各只有两个邻域点，是边界；远处一点五是噪声。边界点可以被吸收，却不能作为新的扩展桥梁，否则链状稀疏点会把本应分离的核心分量连接起来。

若一个非核心点同时位于两个核心连通分量的邻域内，两种归属都与局部边界条件兼容。遍历顺序可能决定其最终标签，因此跨运行比较应区别核心分量稳定与歧义边界分配。不能把某个边界点换簇直接解释为算法完全随机；也不能因为核心结构稳定就掩盖边界不确定性。

<a id="unsup-1-26"></a>

### 6.2 半径、最低计数和维数的共同作用

固定半径时，增加最低计数通常让更多点失去核心资格；固定最低计数时，增加半径会增加邻域支持，也可能通过桥接合并群体。两个参数共同决定密度阈值，不能只扫描其中一个就声称完整检查过。高维空间中邻域体积随半径和维数快速变化，样本量有限时局部密度估计会不稳定，低维上看起来合理的半径没有跨维度通用性。

邻居距离曲线可以辅助定位参数尺度，但曲线拐点不是客观真值。若正常群体密度不同，一个全局半径可能同时造成稀疏群体碎裂和密集群体合并。应先核对距离是否有意义，再考虑变密度方法。OPTICS 提供密度连接顺序及可达距离结构，HDBSCAN 从密度层次中选择相对持久的群体；它们减少单一半径的局限，却仍有最低簇规模等选择，也不保证语义正确。

<a id="unsup-1-27"></a>

### 6.3 实验三：用独立邻域计数核对 DBSCAN

实验使用距离矩阵自行计算核心条件，而不是只断言库输出了某个簇号。簇编号可任意置换，真正需要检查的是前四点同组、末点噪声，以及哪些点是核心。固定样本的精确结果见代码；关于参数的接口含义可对照 [DBSCAN 1.8 文档](https://scikit-learn.org/1.8/modules/generated/sklearn.cluster.DBSCAN.html)。

```python
import numpy as np
from sklearn.cluster import DBSCAN
X = np.array([[0.], [.1], [.2], [.3], [1.5]])
eps, minimum = .11, 3
D = np.abs(X - X.T)
expected_core = np.flatnonzero((D <= eps).sum(axis=1) >= minimum)
model = DBSCAN(eps=eps, min_samples=minimum).fit(X)
assert np.array_equal(expected_core, [1, 2])
assert np.array_equal(np.sort(model.core_sample_indices_), expected_core)
assert len(set(model.labels_[:4])) == 1 and model.labels_[0] != -1
assert model.labels_[-1] == -1
print('core:', expected_core.tolist(), 'labels:', model.labels_.tolist())
```

噪声比例应进入报告。若为了提高轮廓分数而不断增加噪声，把困难样本排除后只评价剩余点，比较总体已经改变。应同时给出覆盖率与条件指标，并检查被排除群体。若样本权重用于 DBSCAN，核心条件还会变成邻域权重和，与无权计数实验不完全相同，必须明确解释和测试。

<a id="unsup-1-28"></a>

### 6.4 新样本归属并不是自动存在的接口

对固定数据运行 DBSCAN 得到的是该集合的密度连接结构。加入新点可能使两个旧核心分量连接，甚至使原来的边界点成为核心；因此“把新点分给最近已有核心簇”是一种另行设计的归纳规则，通常不等于对新旧全体重新运行 DBSCAN。二者各有用途，应在部署协议中写清楚采用哪一种。

若选择冻结核心并分配新点，应规定同时接触多个核心簇时的歧义处理、离所有核心过远时的拒绝规则及重拟合周期。若选择全量重拟合，应接受旧成员可能换组并建立版本与标签对齐。不能在报告中同时承诺群组含义永久固定和算法始终反映最新全体连接，而不说明二者如何协调。

<a id="unsup-1-29"></a>

## 7. 层次聚类：合并准则就是结构假设

凝聚层次聚类从单点簇出发，每次合并当前最接近的两个簇，直到形成一棵树。树保留不同粒度的嵌套关系，但嵌套关系来自不可撤销的贪心合并。早期因噪声产生的一次合并，会影响上层结构；树状图的清晰分叉不能单独证明存在天然层次。切树可以指定簇数或距离高度，二者仍是选择，且不同准则的高度具有不同含义。

<a id="unsup-1-30"></a>

### 7.1 单链接、全链接与平均链接

单链接以两簇任意点对的最短距离定义簇间距离，等价地可从最小生成树切掉长边理解其层次。它能沿弯曲支撑连接样本，也容易被少量中间点形成的链桥接。全链接使用最远跨簇距离，偏好控制簇直径，对远端点更敏感。平均链接取所有跨簇点对距离的平均，在这两种极端之间折中，但并没有因此获得适用于所有问题的中立地位。

手算四个一维点零、一、三、七。先合并零和一后，它与点三的单链接距离为二，全链接为三，平均链接为二点五。这些数值对应三种不同的“两个群体接近”定义。若后续要制定组内统一干预，全链接的直径控制可能更贴近目标；若希望发现连续路径，单链接可能更有用。选择应由用途解释，而不是只看树形是否美观。

<a id="unsup-1-31"></a>

### 7.2 Ward 增量的完整推导

对两个簇 $A,B$，样本数为 $n_A,n_B$，均值为 $\mu_A,\mu_B$，合并后均值为 $\mu=(n_A\mu_A+n_B\mu_B)/(n_A+n_B)$。使用前文方差分解，合并后的组内平方误差比合并前增加 $n_A\|\mu_A-\mu\|^2+n_B\|\mu_B-\mu\|^2$，代入均值差可得

$$
\Delta(A,B)=\frac{n_A n_B}{n_A+n_B}\|\mu_A-\mu_B\|^2.
$$

Ward 每次选择该增量最小的合并。它与平方误差有联系，却不等价于每个簇数下求出全局最优 k-means，因为层次合并不能重新拆开历史簇。某些库的树高度使用增量的缩放或平方根表达，阅读树图应查具体约定，不能跨软件直接把同一高度阈值当成同一目标代价。

标准 Ward 依赖欧氏平方误差的均值分解，不应任意换成余弦距离后继续声称优化同一个增量。若先将数据映射到明确的欧氏表示，再使用 Ward，几何意义可以从变换解释；若只有任意相异矩阵，应选择适合该相异度的链接规则，并确认矩阵是否对称、对角是否为零及输入接口到底接收距离还是特征。

<a id="unsup-1-32"></a>

### 7.3 连通约束与计算代价

图连通约束允许只合并满足空间邻接等条件的簇，例如图像中的相邻区域。但这在目标之外加入了先验：两个远处但外观极像的区域不会直接合并。约束能提高效率和解释性，也可能把错误邻接关系固化。应检查图是否断开，图构建参数改变时层次是否敏感，以及实现如何处理多个连通分量。

一般层次方法需要存储大量点对关系，数据规模大时内存可能先于计算耗时成为瓶颈。先抽样、先压缩为原型或使用稀疏邻接图都能减轻负担，但会改变可发现的细结构。小群体若在压缩阶段被吞并，后续精细切树不能将其恢复。因此应把预聚合步骤算作模型组成部分，记录其误差与敏感性。

<a id="unsup-1-33"></a>

## 8. 谱聚类：从样本几何到图的切分

谱方法先将样本表示为带权无向图，权重 $w_{ij}\ge0$ 表示相似，随后借助图拉普拉斯的特征向量构造新的坐标，再进行离散分组。它可以将同心环沿局部连通关系分开，但成败通常取决于相似图，而非仅在最后一步把 k-means 换成另一种标签器。图如果已经错误地跨过两个环，特征向量也只能反映错误图。

<a id="unsup-1-34"></a>

### 8.1 拉普拉斯二次型说明了什么

定义度 $d_i=\sum_jw_{ij}$，度矩阵 $D=\operatorname{diag}(d_i)$ 和非归一化拉普拉斯 $L=D-W$。对任意向量 $f$，展开可得 $f^TLf=\tfrac12\sum_{i,j}w_{ij}(f_i-f_j)^2$。因此小的二次型鼓励相似边相连的节点拥有相近数值。常数向量给零值；若图有多个不相连的分量，每个分量的指示向量都在零特征空间。

为了获得非平凡切分，需要排除常数并加入范数与平衡约束。不同约束得到不同谱问题：非归一化、随机游走和对称归一化拉普拉斯并非可以无条件互换。归一化方式常使用节点度描述体积，避免仅按节点数理解平衡。谱向量是离散切分的连续松弛解，最后的离散化又可能引入额外优化与随机性，不能将连续问题最优性直接写成原始组合切分全局最优。

**把“连续松弛”真正推到特征方程。** 设所有度均为正，选一个非空真子集 $A$，记 $a=\operatorname{vol}(A)=\sum_{i\in A}d_i$、$b=\operatorname{vol}(A^c)$，切边权为 $c=\sum_{i\in A,j\in A^c}w_{ij}$。归一化切分目标是 $\operatorname{Ncut}(A)=c/a+c/b$。令两值向量在 $A$ 上等于 $\sqrt{b/a}$、在补集上等于 $-\sqrt{a/b}$，则 $f^TD\mathbf1=0$、$f^TDf=a+b$。只有跨集合的边对二次型有贡献，所以

$$
\frac{f^TLf}{f^TDf}
=\frac{c(\sqrt{b/a}+\sqrt{a/b})^2}{a+b}
=c\left(\frac1a+\frac1b\right).
$$

原问题要求 $f$ 具有上述特定的两值结构，组合困难正藏在这里。现在放宽为所有满足 $f^TD\mathbf1=0$、$f^TDf=1$ 的实向量，最优值只可能更小。换变量 $g=D^{1/2}f$，目标变成 $g^TL_{sym}g$，其中 $L_{sym}=D^{-1/2}LD^{-1/2}$，约束为 $g\perp D^{1/2}\mathbf1$、$\|g\|=1$。因此由 Rayleigh 原理取第二小特征值对应向量；等价地求广义特征方程 $Lf=\lambda Df$。若图不连通，零特征值有重数，需先讨论连通分量，不能机械地把“第二个”解释为唯一方向。

例如四节点链的边权依次为 $1,0.1,1$，度为 $(1,1.1,1.1,1)$。从中间断开时，两边体积均为 $2.1$，目标为 $0.1/2.1+0.1/2.1=2/21\approx0.09524$；只隔离左端点则为 $1/1+1/3.2=1.3125$。这个手算说明归一化目标为什么会惩罚割出体积很小但切边不轻的集合。连续向量最后仍需按阈值或多维聚类离散化；离散结果的切分值应重新计算，不能把松弛下界冒充已找到的离散最优值。


<a id="unsup-1-35"></a>

### 8.2 图构建参数比图名更具体

径向基相似度 $w_{ij}=\exp(-\gamma\|x_i-x_j\|^2)$ 中，$\gamma$ 太小使所有点近似相连、差异弱；太大使大部分边接近零并可能形成数值孤岛。近邻图的邻居数太小可能割裂同一结构，太大则可能跨越不同结构。近邻关系原本可有方向，使用并集、交集或平均来对称化会产生不同图，需要明确记录。

如果某节点度为零，归一化中会遇到除零问题。不同实现有不同处理，实际研究应先统计孤立点、连通分量、度分布及边权范围，而不是直接信任最终二维谱坐标。所谓“特征间隙提示簇数”也应受图参数敏感性检验：间隙可能来自图构建导致的断裂，并非数据本身拥有唯一群体数。推导与归一化区别可进一步阅读 [von Luxburg 的谱聚类教程](https://arxiv.org/abs/0711.0189)。

<a id="unsup-1-36"></a>

### 8.3 非线性形状并不自动选择谱方法

谱聚类常需要构建和分解图，内存与计算成本受样本量和稀疏结构影响。训练外延伸需要另外的核延伸、近似或学习映射，不能假设已经存在与原模型完全同义的预测接口。若任务是每天向百万新样本稳定分配群组，冻结中心的模型可能在部署上更容易；若任务是探索一个中等规模固定集合的连通结构，谱方法的传导式设定可能很合适。

一种有帮助的比较是先问结构应该由什么维持：到代表的接近、局部密度连接、历史层次还是图切分。然后对每种假设设计反例，观察它是否符合实际需求。只把几种算法跑在同一张图上，选择颜色最清晰的结果，并不能完成这个问题，因为图本身也可能来自另一个有选择偏差的降维器。

## 9. 评价从目标一致走向用途核验

训练惯性衡量平方距离压缩，与固定表示上的 k-means 目标一致；轮廓系数衡量点到本簇和最近其他簇的平均距离关系；密度连通算法却可能有很长的弯曲簇，在这种结构上轮廓未必高。指标低可能表示模型差，也可能表示评价几何不符合研究目标。应给出为何使用某指标的理由，并报告它忽略了什么。

<a id="unsup-1-38"></a>

### 9.1 为什么增大簇数让惯性下降

全局最优的 $k+1$ 中心方案至少可以复用原来的 $k$ 个中心，因此最优惯性不会上升；进一步拆分某个非退化簇通常可降低它。实际有限次初始化得到的结果不必严格单调，因为大簇数运行也可能优化得更差。即使优化理想，$k=n$ 时每点一个中心可得到零误差，但这几乎没有压缩与概括作用。

肘部图寻找收益递减，只是折中线索。某些连续分布没有明显肘部，多尺度结构可能出现多个。可以加入每个群体的最低支持量、业务可操作数量、重采样稳定性、训练外失真和外部用途，形成清楚的选择规则。数据没有足够证据支持精确簇数时，可以报告一段合理范围，而不是为了表格完整强行给出唯一数字。

<a id="unsup-1-39"></a>

### 9.2 轮廓系数的单位与覆盖率

对样本 $i$，$a_i$ 是它到同簇其他样本的平均距离，$b_i$ 是到其他各簇的平均距离中的最小者，$s_i=(b_i-a_i)/\max(a_i,b_i)$。当本簇紧、其他簇远时分数高；单点簇的定义需要实现约定。计算通常要求至少两个簇且不能每点一簇，边界情形应先验证，不应让程序报错后随意把分数填成零。

如果 DBSCAN 的负一标签被当成普通大簇计算，所有噪声点被强行视作同一群体，可能严重误导；如果先删掉噪声，则计算的是被覆盖样本上的条件质量。两种做法都需要明确说明，通常同时报告非噪声覆盖率和条件轮廓更容易解释。不同覆盖率的模型不能仅用条件分数排序，否则模型可以通过放弃困难样本获得表面优势。

<a id="unsup-1-40"></a>

### 9.3 稳定性、标签与业务效用

簇标签可以任意置换，直接比较编号准确率毫无意义。ARI 等指标比较样本对的共同归属，适合消除标签重命名影响；但两次重采样必须比较共有样本或在共同评估集上进行合法的训练外分配。对于没有原生预测接口的方法，不能偷偷使用另一个分类器投影，再把投影一致性称为原算法完整稳定性。

稳定分组也可能稳定地区分数据来源、语言或设备型号，而这些未必是期望对象。外部标签可以检验一种已知结构，却不能自动充当所有聚类的唯一真值。若用标签挑距离、簇数和图参数，标签已参与模型选择，最终结论应在独立数据核验。若目的是行动收益，需要设计对照或其他可靠评价；组间历史结果不同本身不证明按组采取措施会产生因果收益。

<a id="unsup-1-41"></a>

### 9.4 实验四：单位改变与标准化的对照

四个点分别位于一个矩形的角上。第一列按更大单位缩放后，原始 k-means 倾向按第一列切分；标准化后改单位不会改变表示。这是对单位不变性的直接检查，而不是证明标准化后的分区有天然语义。对照只变化一个因素，并使用同一初值预算，才能解释差异来自哪里。

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import adjusted_rand_score
from threadpoolctl import threadpool_limits
X = np.array([[0., 0.], [0., 2.], [1., 0.], [1., 2.]])
changed = X * np.array([100., 1.])
def partition(A):
    with threadpool_limits(limits=1):
        return KMeans(n_clusters=2, n_init=20, random_state=7).fit_predict(A)
a, b = partition(X), partition(changed)
za = StandardScaler().fit_transform(X)
zb = StandardScaler().fit_transform(changed)
assert np.allclose(za, zb)
assert adjusted_rand_score(a, b) < 0
assert adjusted_rand_score(partition(za), partition(zb)) == 1
print('raw unit-change ARI:', adjusted_rand_score(a, b))
```

标准化后的正方形有多种对称且等价的两簇分区；固定种子得到同一结果只是保证当前实验可复核，不表示在轻微扰动后仍存在唯一方案。这恰好体现尺度不变性与结构可识别性不同：变换抵消了单位差异，却不能凭空创造数据没有提供的边界。

<a id="unsup-1-42"></a>

## 10. 计算规模、数值与可复现实验

一次朴素 k-means 分配约需比较 $nkd$ 个坐标量，重复迭代和重启后成本进一步相乘。MiniBatch 更新用小批样本近似全数据过程，通常降低单次更新成本，但每步不再保证全数据惯性下降；学习率、批次顺序和访问次数影响最终结果。应比较最终全量评价目标与预算，而不只比较迭代数字，因为不同算法一次“迭代”的含义不同。

<a id="unsup-1-43"></a>

### 10.1 大数据不能简单先构造全部点对矩阵

完整距离矩阵需要二次存储。假设百万样本，每个距离使用八字节，单个矩阵约需要八万亿字节，尚未计入中间副本。近邻图、分块计算、近似搜索或原型压缩可缓解，但也会改变哪些邻接关系被看见。近似近邻的召回不足可能断开关键桥，尤其影响基于连通的聚类，故应在可精确计算的子集上核验近邻质量。

稀疏高维特征不一定应显式中心化，因为减均值可能使稀疏矩阵变稠密。选择适合稀疏输入的表示、缩放和降维方法，先估算内存再运行。对文本向量使用余弦与归一化有特定解释，对交易金额直接套同一处理则未必合理；优化工程不能替代表示的意义审查。

<a id="unsup-1-44"></a>

### 10.2 数值误差与距离公式

利用 $\|x-y\|^2=\|x\|^2+\|y\|^2-2x^Ty$ 可以高效批量计算，但当坐标很大而两点很近时，两个大数相减会产生消减误差，浮点结果甚至可能轻微为负。可通过适当中心化、使用较高精度或对微小负值按数值容差截断来处理。明显负值或大幅差异应查输入和溢出，不能全部当作正常舍入。

中心移动量、目标下降量和标签变化量衡量不同停止状态；报告一个收敛标识时应说明采用哪个判据。若提前达到最大迭代次数，应记录而不是把它与严格固定点混为一谈。复现需要保存版本、特征顺序、训练均值、尺度、中心和随机状态；仅保存种子不足以控制库版本、并行归约次序及上游数据变化。

<a id="unsup-1-45"></a>

### 10.3 从实验日志判断问题在哪一层

当分组突然改变，先查样本标识、去重与时间范围，再查特征顺序、单位和缺失处理，然后查初始化与参数，最后才推断总体结构发生变化。若把每个异常现象都归于模型随机性，会错过数据管线问题；若强制固定旧结果，又会掩盖真实变化。日志应让这几类原因有证据可分，而不只记录一张最终簇表。

一种可审查的记录是为每次候选保存样本范围、表示版本、完整参数、目标与覆盖率、簇大小分布和运行预算；另保留少量典型、边界、噪声样本的稳定标识用于人工核对。不需要把大量临时图像和生成脚本混入教材目录，学习成果应是可读正文和能够从正文独立执行的实验。

## 11. 十六道进阶练习与逐步解析

先自行写出目标、假设与计算，再阅读解析。能说出算法名称只是第一步；本节更关心能否指出结论依赖的条件，并设计足以区分不同解释的检查。遇到没有唯一数值答案的题，应给出可以实际执行的证据方案。

<a id="unsup-1-47"></a>

### 11.1 为什么不能只比较簇编号

**题目。** 两次运行的成员完全相同，但编号零和一互换，逐编号准确率变成零，是否说明极不稳定？

**解析。** 编号是任意命名，划分没有变化。先把任意一对样本是否同组写成布尔矩阵，两次矩阵完全一致，因此分区一致。ARI 可消除命名差异；若需要展示中心对应关系，可根据共同成员或中心距离做匹配。匹配用于解释对应，不能将真实分裂、合并也强行压成一一对应后宣布稳定。应另外记录簇数量和规模的变化。

<a id="unsup-1-48"></a>

### 11.2 证明均值而非某个样本是最优中心

**题目。** 给定正权重，为什么中心不必选为最接近平均值的观测？

**解析。** 方差分解将任意中心的误差写成均值处误差加总权重乘中心偏离的平方。均值在连续表示空间中达到最小；选实际观测增加了可行域约束，最优值只会不降。若应用要求一个真实案例作代表，选择 medoid 或在均值附近选原型具有解释价值，但应把“展示代表”与“优化中心”分开，不能改完中心后仍报原来的最优误差。

<a id="unsup-1-49"></a>

### 11.3 为什么异常点会吸引一个中心

**题目。** 六个常见点和一个很远的点，两个中心为何可能把远点单独成簇？

**解析。** 远点到常见中心的平方损失可能超过将常见点从两簇合并为一簇造成的代价。比较这两部分代价即可判断，而不是仅看人数。实验二给出明确实例：前六点合为一簇误差一百，远点独占中心误差为零。若这种结果不符合研究用途，可改变损失或约束，但先检查远点是否真实且重要，不应为了得到期望形状直接删除。

<a id="unsup-1-50"></a>

### 11.4 归一化后普通 k-means 等于球面版本吗

**题目。** 输入都在单位球面，是否每轮得到的均值也在单位球面？

**解析。** 不成立。两个夹角非零的单位向量的平均长度一般小于一，方向相反时均值甚至为零。普通 k-means 保留这个长度，分配包含中心范数；球面版本重新归一化中心，优化角度目标。单位点之间的欧氏和余弦近邻等价，不能推导涉及非单位均值的两种算法等价。应分别写出各自的目标再比较。

<a id="unsup-1-51"></a>

### 11.5 构造尺度决定结果的反例

**题目。** 如何在不改变观测对象的情况下，让聚类分区明显改变？

**解析。** 使用矩形四角数据，将短边对应坐标乘以很大常数，便能改变哪种切分的平方误差较低。实验四只改第一列单位，得到原始分区的 ARI 为负零点五。标准化抵消此线性单位变化，但正方形对称意味着仍可能有多个等价分区。这个反例同时区分了单位选择、优化选择和结构唯一性三个问题。

<a id="unsup-1-52"></a>

### 11.6 空簇能直接使用均值公式吗

**题目。** 某轮没有点分给第三个中心，如何证明更新后的目标下降？

**解析。** 空集均值没有定义，原证明不适用。若仅移动空中心而保持其他中心及当前标签，其目标没有变化；随后重新执行最近分配，目标不会增加，这是可分析的一种策略。若同时从别簇搬走样本、修改其中心，就要重新核验整个操作的目标变化。实现策略需明确，不能将所有重置行为都含糊归入标准均值更新。

<a id="unsup-1-53"></a>

### 11.7 边界点是否能连接两个密度簇

**题目。** 两个核心分量之间存在一个同时接触二者的非核心点，DBSCAN 是否必须合并它们？

**解析。** 不必须。扩展沿核心关系进行，非核心边界点不会作为新传播源，因此核心分量仍分离。该边界点可以有歧义归属，具体遍历可能选择其中一个。若错误地让所有被吸收点继续扩展，就实现了另一种连通规则。验证时应分别看核心图连通和最终边界标签，避免把两类性质混为一谈。

<a id="unsup-1-54"></a>

### 11.8 Ward 为什么不能随意换距离

**题目。** 将欧氏距离替成余弦距离，仍引用合并平方误差增量公式，哪里有问题？

**解析。** 增量公式依赖欧氏平方范数的均值分解，任意相异度不具有该恒等式。若先构造一种欧氏嵌入，可在嵌入空间解释 Ward，但目标随嵌入改变。只有一张余弦相异矩阵时，应查它能否对应要求的欧氏结构及接口约定，或改用允许该相异度的链接方法，不能只因函数接受数组就认为理论条件满足。

<a id="unsup-1-55"></a>

### 11.9 图有三个连通分量说明三个真类吗

**题目。** 拉普拉斯出现三个零特征值，能否宣布发现三个自然类别？

**解析。** 在无向非负权图的标准条件下，零特征值重数对应图的连通分量数，这是图的结论。图又由邻居数、半径、距离及截断构成，参数过小可制造断裂。应改变合理图参数并核对原空间近邻、孤立点和外部样本。即使三个分量稳定，也只能说明当前表示的连通结构，语义类别需额外证据。

<a id="unsup-1-56"></a>

### 11.10 内部指标提高是否支持业务命名

**题目。** 轮廓更高的簇能否命名成高价值、中价值和低价值客户？

**解析。** 轮廓没有使用客户价值的定义，它只描述某种距离下的紧密与分离。先在独立的、时间可用的价值指标上比较组内分布与重叠，再检查来源、规模和不确定性。若价值本身已作为主要输入，高低差异可能只是构造结果，不能称为独立验证。若要据此改变措施，还需核验行动效果，历史相关不直接给出因果收益。

<a id="sec-7-1"></a>

<a id="unsup-1-57"></a>

### 11.11 边界追问：较低惯性是否自动选更多簇

**题目。** 候选中十簇惯性最低，是否应直接部署十簇？

**解析。** 训练误差随灵活度增加而下降是目标性质，不能单独定复杂度。比较最低支持量、训练外失真、不同重采样下成员关系、操作成本与独立用途。若十簇只是把几个极端点单独隔离，应说明这些小簇是否有稳定支持及行动意义。实际优化还可能导致曲线非单调，应先检查重启预算，再解释拐点，避免把优化噪声当作结构证据。

<a id="unsup-1-58"></a>

### 11.12 重采样比较应先对齐什么

**题目。** 两次抽样分别含不同记录，直接计算两个标签数组的 ARI 为什么无效？

**解析。** 指标默认数组同一位置对应同一对象。必须按稳定样本标识取交集并对齐顺序，或者使用冻结模型在共同评估集上合法预测。若抽样包含重复记录，还要决定比较实体级还是记录级，否则频数变化会改变权重。报告共有样本数及覆盖哪些群体，少量交集上的高分不足以描述整体稳定性。

<a id="unsup-1-59"></a>

### 11.13 多次重启怎么公平比较

**题目。** 方案甲五十次取最优，方案乙一次，甲目标更低能否证明初始化更好？

**解析。** 不能，比较同时变化了算法与计算机会。可固定重启次数比较单次或最终目标分布，再给近似固定总运行预算的补充结果。种子列表应预先固定，并在同一数据上配对。若只展示最幸运一次，就隐藏了失败风险。生产环境还可能更重视尾部耗时和最差小簇行为，应根据实际约束预先选择主要比较量。

<a id="unsup-1-60"></a>

### 11.14 混合模型的软归属能否当作类别真概率

**题目。** GMM 给出某分量责任度零点九，是否代表真实业务类别概率百分之九十？

**解析。** 责任度是当前拟合混合模型及其分量定义下的后验权重。若分量不对应业务类别，或者模型设定不适合真实分布，这个数没有所声称的类别含义。应核验分量解释与外部标注，并检查校准；一个业务类别也可能需要多个高斯分量近似。概率形式正确并不自动解决目标语义和模型错设问题。

<a id="unsup-1-61"></a>

### 11.15 噪声少就说明 DBSCAN 更好吗

**题目。** 扩大半径后噪声率降到零，是否应优先使用此参数？

**解析。** 半径足够大可把所有样本连成一组，覆盖率完美但失去分群作用。应同时查看簇数、核心比例、群体规模、桥接样本和对参数的敏感性，再按用途判断。相反，极低覆盖率下的高条件轮廓也可能来自只保留极容易的小核心。覆盖与结构质量应联合呈现，任何单一数字都可能被极端参数轻易优化。

<a id="unsup-1-62"></a>

### 11.16 连续总体也能有高稳定分组吗

**题目。** 没有离散真实类别的连续分布，是否必然聚类不稳定？

**解析。** 不必然。固定距离、强不对称分布和压缩目标可以产生很稳定的量化分区，即使生成机制没有类别变量。稳定性衡量数据与算法扰动下的结果一致，不是类别存在检验。可以把这类输出解释为连续谱上的运营区段，并验证用途；若声称发现自然类型，就需要额外的生成假设、分离证据与可反驳预测。

<a id="unsup-1-63"></a>

## 12. 研究延伸：把结构主张变成可证伪实验

一种有价值的研究问题是比较“相同损失下优化更好”与“不同表示下用途更好”。前者应固定表示、目标和预算，使用精确小例子与大数据目标分布评价；后者需要明确允许表示变化，并在独立任务评价。将二者混在一张排行榜里，会让优化进步、先验改变和评价选择无法分辨。报告可以并列两条实验线，分别回答每个问题。

进一步可研究群体不平衡与密度差异：系统改变少数群体比例、方差、中心间距和桥接噪声，观察中心分配、噪声覆盖和成员稳定性的转折。每次只改变一个生成因素，随后加入多个因素交互。合成实验提供已知机制，现实实验提供外部适用性；两者互补，不能只凭一个漂亮合成图宣布算法普遍优越。

还可研究约束和人工反馈。若领域给出必须同组或不得同组的样本对，应先检查约束是否冲突、是否来自未来信息，再选择满足约束的目标与求解器。加入监督信息后的结果可以非常有用，但应准确描述信息来源，不能继续称为完全由未标注数据独立发现。最好的研究结论应说明什么条件下改进、通过哪项机制改进，以及哪些反例仍然无法解决。

最后，将训练外分配、重拟合后的身份变化和拒绝规则视为模型的一部分。一个离线图上优秀的方案，如果对新样本没有可解释的归属规则，就尚未完成可部署分群；一个可稳定部署的量化器，也不必拥有天然类别的含义。数学目标、算法保证、统计证据与实际用途各有层次，把每层写清楚，才能让聚类知识从名词变成可以可靠使用的工具。
