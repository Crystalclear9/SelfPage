## 1. 将模糊探索写成可以审查的问题

无监督实验最容易缺少的是一个稳定的评价对象。没有训练标签，并不意味着没有选择、偏差或过拟合。研究者仍然会选择样本、特征、距离、算法、簇数和图参数，也会根据结果是否符合预期继续修改。完整协议的目的，是让这些选择对应明确问题，使读者能够区分输入结构、优化偶然性和真正获得独立支持的发现。

本章以“为后来到达的新实体建立可复用分组”为主要工作例子，同时说明固定全集探索的区别。前者需要训练表示、冻结规则和未来评价；后者可以用当前全体输入拟合，但结论应限定于该集合。两者不必互相否定，重要的是不要将一种设定的结果当成另一种的证据。实验协议应先写任务，再决定划分与指标。

<a id="unsup-4-2"></a>

### 1.1 一份协议的最小要素

首先定义每行的观测单位、总体范围和样本标识，说明是否一人多行、时间窗口是否重叠、抽样是否加权。接着定义输入在何时可获得，哪些字段可能泄漏未来、哪些来源需要单独审查。然后说明输出是硬分区、噪声集合、层次树、软归属还是低维坐标，因为这些产出不能强制共享同一种评价。

最后写出主要用途与成功条件。例如希望群组在合理重采样下成员稳定、每组支持足够、后来样本覆盖良好，并在独立结果上呈现可解释差异。每个条件都需要操作化：稳定比较哪些对象、支持量阈值为何合理、覆盖如何定义、外部结果是否参与开发。明确这些内容后，才有依据讨论哪个算法更合适。

<a id="unsup-4-3"></a>

### 1.2 探索与确认的证据角色

探索阶段允许广泛查看数据和产生假设，但应记录尝试范围和重要失败。确认阶段冻结关键规则，在未用于开发的数据或独立机制证据上核验。独立可以来自未来时段、新来源、独立标签或预先规定的行动评价，具体取决于主张。只换一个随机种子并不等于得到独立总体证据；它主要检查优化随机性。

若数据很少，可以通过嵌套重采样估计开发流程的表现，并如实描述不确定性；不能把同一小集反复调参后的最佳结果称为无偏泛化。探索本身有价值，不需要为了显得严谨而假装所有选择事先固定，但报告必须准确说明哪些结论已经确认，哪些仍是待检验假设。

<a id="unsup-4-4"></a>

### 1.3 预先列出可能推翻结论的情况

若主张某簇是行为类型，应提前考虑它可能只是设备版本、缺失字段或地域采样差异。若主张某二维轨迹是发展过程，应检查是否只是批次顺序。把这些替代解释列成对照计划，而不是等结果公布后才补一句“也许有偏差”，会使实验更有判别力。好的协议不仅知道希望看到什么，也知道什么结果会迫使自己修改解释。

## 2. 建立同数据、同表示、同预算的比较

比较算法前先固定数据总体与表示，否则差异同时来自多个环节。一种方法使用标准化输入，另一种使用原始输入，不能将全部差异归因于聚类器。可以开展两种实验：固定表示比较算法机制；允许各方法在训练内选择表示，比较完整流程。两者回答不同问题，都应单独报告，避免在一张表里混用。

<a id="unsup-4-6"></a>

### 2.1 数据审计与有效样本量

检查重复实体、重复记录、时间重叠和来源比例。相邻窗口不是独立证据，一万行记录可能只来自十台设备；对行做随机划分会高估未来泛化。应根据部署单位按实体或时间划分，必要时二者结合。重采样时也应抽实体或时间块，而不是把高度相关的行当作独立样本。

缺失处理、单位、类别编码和截断规则必须版本化。若输入列顺序改变，模型仍可能接受相同维度数组，却产生完全不同的距离。可用固定少量回放样本检查变换结果，记录每列含义、训练尺度和合法取值。有效样本量与采集覆盖比总行数更能解释小群体的支持程度，应在报告中清楚体现。

<a id="unsup-4-7"></a>

### 2.2 表示拟合边界与共同评价空间

缩放器、PCA 和其他可学习表示在训练部分拟合，验证与测试复用。如果研究固定全集探索，应明确整体拟合，不宣称未来效果。比较重构误差时，应在同一物理或标准化空间计算；比较轮廓时，也要说明使用输入距离还是各自嵌入距离。不同空间的同名指标通常不能直接排序。

如果每种方法都在自己的二维图上计算轮廓，它们可能因布局压紧程度而得到不同分数，即使原空间分区没有改善。更合适的做法是在共同、任务合理的参考表示中评价成员关系，再把各自图仅作辅助。若目的本来是图布局质量，则改用明确的邻域或距离保真指标，而不是借一个聚类分数替代。

<a id="unsup-4-8"></a>

### 2.3 参数搜索和计算机会

显式给出候选簇数、密度半径、邻居数、保留维数、初始化次数与种子列表。参数范围应有尺度依据，不必让所有算法拥有数量完全相同却毫无意义的参数网格；但总预算、开发标签使用和停止规则应可比较。一方搜索上千组合，另一方只跑默认值，结论针对的是不同开发机会下的流程。

报告运行时间时，应区分表示拟合、近邻图构建、聚类、训练外分配和指标计算，并说明线程与硬件。相同迭代数不表示相同成本，完整距离矩阵的内存峰值也应考虑。教学实验主要核验逻辑，不用几毫秒差异声称性能优越；严肃效率结论需要多次计时与规模曲线。

<a id="unsup-4-9"></a>

### 2.4 实验一：冻结完整表示并核对训练外失真

下面用训练数据拟合标准化、PCA 和 k-means，再在独立生成的样本上按冻结中心分配。使用手动距离计算复核`predict`和测试失真，并断言变换参数不因测试调用改变。这个实验给出可复用规则，不把测试数据重新拟合进模型。

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from threadpoolctl import threadpool_limits
centers = np.array([[-5., 0., 0.], [0., 5., 0.], [5., 0., 0.]])
train, _ = make_blobs(n_samples=180, centers=centers, cluster_std=.5, random_state=10)
test, _ = make_blobs(n_samples=60, centers=centers, cluster_std=.5, random_state=11)
scaler = StandardScaler().fit(train)
A = scaler.transform(train)
pca = PCA(n_components=2, svd_solver='full').fit(A)
Z = pca.transform(A)
with threadpool_limits(limits=1):
    model = KMeans(n_clusters=3, n_init=10, random_state=12).fit(Z)
mean_before, dirs_before = scaler.mean_.copy(), pca.components_.copy()
Znew = pca.transform(scaler.transform(test))
d2 = ((Znew[:, None, :]-model.cluster_centers_[None, :, :])**2).sum(axis=2)
assert np.array_equal(model.predict(Znew), d2.argmin(axis=1))
assert np.array_equal(scaler.mean_, mean_before)
assert np.array_equal(pca.components_, dirs_before)
assert np.isclose(np.mean(d2.min(axis=1)), np.mean(((Znew-model.cluster_centers_[model.predict(Znew)])**2).sum(axis=1)))
print('held-out mean squared distortion:', d2.min(axis=1).mean())
```

测试失真是对冻结表示下量化误差的评价，不是“真实类别恢复概率”。如果要利用合成标签评价恢复，可另行计算置换不敏感指标，并说明标签由何种生成机制定义。若目标是新来源泛化，还要让测试来源发生预先规定的变化，不能仅在同一生成器抽新种子就声称跨域能力已被验证。

## 3. 内部指标：每个分数带着自己的几何假设

内部指标只使用观测和分区，不需要外部类别，但它们并不因此客观中立。平方误差偏好中心压缩，轮廓比较平均距离，密度指标强调连通与稀疏间隔。选择应与目标相容。可以将内部指标作为筛选线索，却不能用某个高分证明业务语义，也不能把不同算法的训练目标直接放在同一列排名。

<a id="unsup-4-11"></a>

### 3.1 轮廓的逐样本含义

对点 $`i`$，本簇平均距离为 $`a_i`$，到最近其他簇的平均距离为 $`b_i`$，轮廓为 $`\frac{(b_i-a_i)}{\max(a_i,b_i)}`$。负值提示该点在平均距离意义上更接近另一簇，接近一表示本簇紧且外簇远。单点簇有实现约定，所有点一簇或每点一簇的情形通常不能正常使用该指标，需要先判定适用范围。

平均轮廓可能掩盖小簇差或边界差，应查看逐簇分布与规模。若算法允许噪声，先排除噪声再计算的是条件质量，应同时报告覆盖率；把负一当普通簇则会将所有噪声强行合成一组，也有解释问题。报告中必须说明选择，不能让模型通过拒绝更多困难点获得表面高分。

<a id="unsup-4-12"></a>

### 3.2 方差比与中心分离指标

Calinski-Harabasz 类指标比较组间离差与组内离差，并按簇数和样本数调整。设组内散度为 $`W`$、组间散度为 $`B`$，典型形式为 $`\frac{\operatorname{tr}(B)}{(k-1)}`$ 除以 $`\frac{\operatorname{tr}(W)}{(n-k)}`$。它依赖中心与欧氏散度，较高并不证明弯曲密度簇更差，只说明当前分区在这种方差分解下更分离。

Davies-Bouldin 类指标比较簇内散布与中心间距离的比值，并对每簇最相似的其他簇汇总，通常越低越好。中心接近或非凸簇中心落在空区时，指标可能不符合实际连通结构。理解公式比记忆“一个高好一个低好”更有价值，因为公式能提示应该构造哪些反例来检验评价是否适用。

<a id="unsup-4-13"></a>

### 3.3 指标与簇数共同变化

最优训练惯性随簇数增加不升，因此不能单独用于选择复杂度。轮廓和方差比虽加入分离信息，也可能偏向某些簇数或群体平衡。可使用最低支持量、操作成本、稳定性和外部用途形成联合选择规则。若多个候选各有优势，可以报告可接受集合，不必为了宣布冠军而将所有量随意加权成一个总分。

当内部指标相互冲突，先解释它们衡量的结构差异，再检查代表、边界和异常样本。冲突不一定是坏事，它可能揭示数据存在不同尺度或不同用途。若决定使用加权综合分，应事先说明权重与归一化规则，并做敏感性分析；训练后为了让偏好方案获胜而改权重，只是把选择藏进公式。

<a id="unsup-4-14"></a>

## 4. 外部评价：比较划分而不是比较名字

当存在外部类别、来源或已知实验条件时，可以比较它们与聚类的关系。外部变量不必是唯一真值：物种、采集地点和测量仪器可能都形成结构，但它们代表不同解释。评价前应声明哪些变量仅用于核验，哪些参与过特征、参数或图选择；否则一个表面无监督的流程，可能已通过开发过程吸收标签信息。

<a id="unsup-4-15"></a>

### 4.1 列联表与样本对计数

设两种划分为 $`U`$ 和 $`V`$，列联表元素 $`n_{ab}`$ 表示同时属于 $`U_a`$ 和 $`V_b`$ 的样本数。行和为 $`a_a`$，列和为 $`b_b`$。两种划分都认为同组的样本对数是 $`A=\sum_{a,b}\binom{n_{ab}}2`$；在第一种划分中同组的总对数为 $`B=\sum_a\binom{a_a}2`$，第二种为 $`C=\sum_b\binom{b_b}2`$。这些量与标签名字无关。

总对数为 $`N=\binom n2`$。若在固定行列边际的随机置换模型下比较，期望共同同组对数为 $`\frac{BC}{N}`$，由此得到调整 Rand 指数 $`\mathrm{ARI}=\frac{[A-\frac{BC}{N}]}{[\tfrac12(B+C)-\frac{BC}{N}]}`$。负值表示低于该偶然参照的期望，不是错误概率为负；一表示划分完全相同，允许标签置换。退化分区分母可能为零，实际接口有专门约定，应查文档，不能自行在所有情形返回未定义值。

<a id="unsup-4-16"></a>

### 4.2 一次可手算的 ARI

四个样本，划分甲为前两个同组、后两个同组，划分乙为第一和第三同组、第二和第四同组。列联表四格都是一，因此 $`A=0`$，$`B=C=2`$，$`N=6`$，偶然期望为三分之二。分母为 $`\tfrac12(B+C)-\frac{BC}{N}=2-\frac{2}{3}=\frac{4}{3}`$，分子为负三分之二，因此 ARI 为负二分之一。这个过程强调有理数的明确核算，避免只记一个小数。

若乙仅交换甲的零一标签，列联表非零格各为二，$`A=B=C=2`$，ARI 等于一。逐编号准确率却可能为零，因此编号比较不适合作为稳定性。ARI 的偶然调整依赖指定参照，并非证明任何随机数据上的有限次结果都恰好为零；样本规模、簇大小和随机机制仍影响分布。接口定义见[ARI 1.8 文档](https://scikit-learn.org/1.8/modules/generated/sklearn.metrics.adjusted_rand_score.html)。

<a id="unsup-4-17"></a>

### 4.3 互信息、同质性与粒度

互信息衡量知道一种划分后另一种不确定性减少多少；归一化方式不同会给出不同尺度，未经偶然调整的量可能偏好更细分区。若每个样本独占一簇，簇标识可以确定任何外部标签，但这并不意味着得到有用压缩。应同时看完整性、同质性与复杂度，或使用具有明确偶然参照的调整指标。

外部标签本身也可能比研究需要更粗或更细。一个物种包含多个稳定亚群时，聚类细分不一定是失败；一个行政区域包含多种行为时，低一致性也不必说明算法无用。应回到用途解释错配，并通过独立证据验证细分，不能在指标不利时任意宣布标签不重要，却在指标有利时又将它称为真值。

<a id="unsup-4-18"></a>

### 4.4 标签匹配回答的是展示对应问题

若两个方案簇数相同，希望在表格中对齐编号，可用列联表求最大重叠匹配；这是一种线性指派问题。匹配后成员一致率容易理解，却与 ARI 不相同，且强制一一对应会掩盖分裂和合并。当簇数不同，可以报告矩形匹配与未匹配簇，但不应把未匹配样本悄悄删掉，再用剩余高一致率声称全局稳定。

使用中心距离匹配时，必须确保中心位于同一表示和尺度；两个独立白化或降维空间中的中心距离未必可比。即使成员重叠匹配最合理，也应保留完整交叉表，让读者看见一个旧簇是否分向多个新簇。匹配是沟通工具，不是将真实结构变化修饰成一致的工具。算法接口可核对[SciPy 线性指派文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linear_sum_assignment.html)。

<a id="unsup-4-19"></a>

### 4.5 实验二：手算 ARI 与最优标签匹配

下面同时核验标签置换、交叉分区和指派结果。使用独立组合计数公式复核库的 ARI，避免仅比较两个同源接口。标签匹配只用于恢复展示名称，不参与 ARI 的计算。

```python
import numpy as np
from math import comb
from sklearn.metrics import adjusted_rand_score
from scipy.optimize import linear_sum_assignment
u = np.array([0, 0, 1, 1])
v = np.array([1, 1, 0, 0])
cross = np.array([0, 1, 0, 1])
def table(a, b):
    _, ai = np.unique(a, return_inverse=True)
    _, bi = np.unique(b, return_inverse=True)
    T = np.zeros((ai.max()+1, bi.max()+1), dtype=int)
    np.add.at(T, (ai, bi), 1)
    return T
def manual_ari(a, b):
    T = table(a, b)
    A = sum(comb(int(x), 2) for x in T.ravel())
    B = sum(comb(int(x), 2) for x in T.sum(axis=1))
    C = sum(comb(int(x), 2) for x in T.sum(axis=0))
    expected = B*C/comb(len(a), 2)
    return (A-expected)/(.5*(B+C)-expected)
assert np.mean(u == v) == 0
assert adjusted_rand_score(u, v) == 1
assert np.isclose(manual_ari(u, cross), -.5)
assert np.isclose(adjusted_rand_score(u, cross), manual_ari(u, cross))
T = table(u, v)
r, c = linear_sum_assignment(T, maximize=True)
assert T[r, c].sum() == len(u)
print('permutation ARI:', adjusted_rand_score(u, v), 'cross ARI:', manual_ari(u, cross))
```

## 5. 稳定性：先规定扰动，再规定比较单位

稳定性不是一个脱离协议的属性。固定数据改初始化，检查的是优化敏感性；改变样本，检查的是抽样支持；改变特征或尺度，检查的是表示假设；改变时间来源，检查的是总体迁移。这些实验都值得做，但混成一个“稳定分数”会让失败原因不可分。应该分层设计，使每轮结果能回答一个清楚问题。

<a id="sec-1-1"></a>

<a id="unsup-4-21"></a>

### 5.1 共同样本、共同顺序与共同权重

两次无放回子采样含不同样本时，比较共有标识，且按同一顺序对齐。不能直接将两个同长度标签数组送进 ARI，因为位置可能不是同一对象。共有样本还可能偏向大群体，应报告交集大小和群体覆盖。若每次抽到的少数群体太少，平均高稳定性可能只是多数结构稳定。

Bootstrap 有重复记录，重复等价于增加权重，会影响中心、局部密度和距离并列。若要研究原始实体的成员关系，应先规定如何将重复副本汇总回实体；若目的是估计抽样分布，又应保留其频数作用。无放回子采样更容易比较，但它也改变样本支持，需要说明抽样比例与重复次数。

<a id="sec-2-1"></a>

<a id="unsup-4-22"></a>

### 5.2 固定评估集与归纳稳定性

对支持合法训练外预测的方法，可以在不同训练子集拟合完整流程，再对同一固定评估集分配，比较其划分。这样避免交集样本过少，但评价对象变成“重拟合后对共同未来输入的预测一致性”。它与训练集合自身分区的稳定性不同，特别是表示也随子样本重估时，需将整个流程一起比较。

对没有原生预测规则的方法，不能悄悄加一个分类器再把结果当作原算法稳定性。可以明确研究“聚类后拟合分类器”的完整流程，或采用共有训练样本比较；二者都应写清。对于密度方法，冻结核心后的分配与对全集重新聚类也不同，稳定性协议必须与真实使用方式相同。

<a id="unsup-4-23"></a>

### 5.3 共归属概率与分母

对样本对 $`(i,j)`$，可记录它们在重复实验中共同出现且同组的次数，除以共同出现的次数。分母不是总实验数，除非每次二者都可评价。低分母的概率估计不稳定，应设置最低支持量或同时展示分母。若算法允许噪声，应规定两点均为噪声是否算同组，通常不能将所有噪声自然视为一个语义簇。

共归属矩阵能揭示稳定核心和不稳定边界，但二次存储在大数据上很昂贵。可用抽样样本对、原型或局部邻接近似，并说明覆盖限制。把矩阵再聚类可形成共识分区，这已经是新的集成方法，应重新评价，不应直接继承每个基础运行的保证。共识也可能稳定地强化共同来源偏差。

<a id="unsup-4-24"></a>

### 5.4 实验三：抽样重拟合后在共同评估集比较

实验使用三个明显分离的合成群体，不以稳定分数很高声称现实普遍有效。每次重新拟合缩放和聚类，然后在固定评估集计算标签；使用 ARI 和共归属矩阵展示编号无关的比较。所有训练只看各自抽到的数据，共同评估集不参与拟合。

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import adjusted_rand_score
from threadpoolctl import threadpool_limits
centers = np.array([[-8., -8.], [0., 8.], [8., -8.]])
train, _ = make_blobs(n_samples=240, centers=centers, cluster_std=.4, random_state=20)
eval_X, _ = make_blobs(n_samples=90, centers=centers, cluster_std=.4, random_state=21)
rng = np.random.default_rng(22)
partitions = []
with threadpool_limits(limits=1):
    for seed in range(6):
        ix = rng.choice(len(train), size=180, replace=False)
        scale = StandardScaler().fit(train[ix])
        model = KMeans(n_clusters=3, n_init=10, random_state=seed).fit(scale.transform(train[ix]))
        partitions.append(model.predict(scale.transform(eval_X)))
aris = [adjusted_rand_score(partitions[0], q) for q in partitions[1:]]
P = np.mean([q[:, None] == q[None, :] for q in partitions], axis=0)
assert P.shape == (90, 90)
assert np.allclose(P, P.T) and np.allclose(np.diag(P), 1)
assert np.min(P) >= 0 and np.max(P) <= 1
assert min(aris) > .9
print('common-evaluation ARIs:', aris, 'uncertain pairs:', int(((P>0)&(P<1)).sum()))
```

这里固定评估集在每轮都出现，所以共归属分母等于六；真实子采样交集协议需要逐对计算分母。若将群体拉近、增加无关特征或缩小少数群体，应预期不稳定上升，并解释来源。稳定性研究的理论和局限可进一步阅读[聚类稳定性综述](https://arxiv.org/abs/1007.1075)。

<a id="deep-dive-2"></a>

<a id="unsup-4-25"></a>

### 5.5 稳定并不等于语义真实

一种规则若只按样本标识奇偶分组，可以非常确定，但与研究对象毫无关系；一个强来源水印也能形成重复性极高的簇。稳定表示在指定扰动下变化小，没有证明分组来自目标生成机制。相反，连续总体可能没有稳定硬边界，却仍有有意义的低维梯度。因此稳定性应与样本审查和独立用途结合，不能单独充当自然类别存在检验。

稳定性还会受到算法偏好影响。强正则和较小簇数通常更难变化，所有样本一簇甚至完全稳定，但失去细分价值。选择簇数时若只最大化稳定性，可能偏向过粗方案。应同时约束分辨能力、最小支持、压缩和用途，明确讨论多个尺度，而不是假定稳定性曲线最大值就是唯一真簇数。

<a id="sec-3"></a>

<a id="unsup-4-26"></a>

## 6. 人工审查：从代表样本走向替代解释

簇中心是均值，不等于每位成员的属性。仅看中心并给簇起名，容易忽略分布重叠、极端值与组内异质性。审查应同时包括典型样本、边界样本、小簇与噪声，且按稳定标识返回原记录。若图中分群主要由缺失字段或采集软件区分，正确结论应指向数据机制，而不是将其包装为行为类型。

<a id="unsup-4-27"></a>

### 6.1 代表、边界与随机样本承担不同作用

中心附近的代表帮助理解最典型模式，却无法检验边界是否合理；最近两个中心距离差很小的样本能暴露分配不确定；低密度或噪声样本提示覆盖盲区；簇内随机抽样则避免研究者只挑符合解释的案例。可以预先设定每类抽样数量，并在多个审查者之间比较判断一致性。

如果审查者已知模型编号和期望名称，可能发生确认偏差。可以在适当场景隐藏编号、随机排列候选，让审查者先描述记录，再与分组比较。人工解释本身也需要证据，不能因几个人都觉得名字合理就宣布存在天然类别。应记录哪些特征支持解释、哪些样本不符合、哪些地方仍无法确定。

<a id="unsup-4-28"></a>

### 6.2 簇画像应包含分布而不只是均值

数值特征可报告中位数、分位区间、缺失率和极端值支持，类别可报告比例及基线差异；小簇的差异可能具有很大抽样波动。比较很多特征后挑最显著的几个，涉及选择和多重比较，应作为探索或在独立数据确认。若某特征本就参与距离，组间差异通常部分来自构造，不能当作独立外部验证。

还应检查同一画像是否适用于未来或其他来源。训练簇中某行为比例高，后来成员分布可能变化；冻结中心仍能分配并不表示簇含义不变。可用版本化画像和共同回放样本监控解释漂移，必要时重新命名或重新设计行动。名称是沟通层，需要随着证据更新，而不是算法自带的永久语义。

<a id="unsup-4-29"></a>

### 6.3 来源混杂与捷径核验

设数据来自两家医院、两种传感器或两个采集平台。来源可能带来单位、分辨率、缺失和样本选择差异，形成非常稳定的几何结构。先计算簇与来源的关系，再在来源内部观察预期结构，并用匹配尺度或去掉明确无关的来源特征作对照。若去掉来源后所有结构消失，应坦率报告，而不是不断调参寻找同样漂亮的图。

但不能机械删除所有来源信息，因为来源也可能与真实机制相关。关键是明确研究目标：若需要识别设备版本，来源相关结构可能有用；若声称发现跨来源行为类型，就必须证明不仅在区分来源。通过独立来源复制和与实际结果的关系，可以逐步区分两种解释。无监督方法不会自动替我们完成因果归因。

<a id="unsup-4-30"></a>

### 6.4 实验四：稳定地发现了错误的解释变量

构造两个平衡且独立的二元变量：来源和目标类别。第一坐标强烈区分来源，第二坐标弱区分类别，未标准化 k-means 会稳定按来源分组。该例子用已知机制证明高稳定性与目标类别一致性不同，不能将模型稳定当作语义正确的充分证据。

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.metrics import adjusted_rand_score
from threadpoolctl import threadpool_limits
rng = np.random.default_rng(30)
source = np.repeat([0, 0, 1, 1], 40)
target = np.repeat([0, 1, 0, 1], 40)
X = np.c_[20*source + rng.normal(scale=.1, size=160),
          target + rng.normal(scale=.05, size=160)]
partitions = []
with threadpool_limits(limits=1):
    for seed in range(5):
        partitions.append(KMeans(n_clusters=2, n_init=10, random_state=seed).fit_predict(X))
assert all(adjusted_rand_score(partitions[0], q) == 1 for q in partitions[1:])
assert adjusted_rand_score(partitions[0], source) == 1
assert adjusted_rand_score(partitions[0], target) < .05
print('ARI source:', adjusted_rand_score(partitions[0], source),
      'ARI target:', adjusted_rand_score(partitions[0], target))
```

此处目标标签只用于验证已知反例，不参与训练。现实中目标可能不可见，因此应通过来源交叉表、原始记录和独立外部资料核验。反例不证明原始尺度总是错误，也不证明标准化总能恢复目标；它证明的是稳定性单独不足。尺度选择仍要由实际用途解释，不能为了合成标签高分一概标准化。

<a id="unsup-4-31"></a>

## 7. 从稳定分区走向可用的未来规则

部署分群时，模型实际包含输入定义、变换、分配、拒绝、版本迁移和监控。k-means 可使用冻结中心，密度或图方法可能需要额外的训练外策略。无论采用何种方案，都应在真实输入边界和计算预算下验证。离线得到标签文件只是完成固定集合描述，不等于已经交付未来分群能力。

<a id="sec-6-1"></a>

<a id="unsup-4-32"></a>

### 7.1 时间向前的验证与新样本覆盖

在历史训练阶段选择表示和分群规则，留出后续时段，检查失真、群体规模、拒绝比例与画像变化。若未来某类实体离所有训练中心都很远，最近中心仍会强制给标签，因此需要覆盖或未知规则。拒绝阈值应在独立校准数据选择，不能看最终测试后为失败点单独改规则。

覆盖变化可能来自正常演化、采集问题或真正新群体。应将异常输入返回数据审查，并在成熟反馈后决定更新，而不是立即加入模型。冻结模型让比较清楚，却可能逐渐过时；全量重拟合适应变化，又会改变身份。两者的取舍应由任务和更新协议明确，不存在所有场景通用的最佳周期。

<a id="unsup-4-33"></a>

### 7.2 重拟合后身份对齐与分裂合并

新旧簇的对应可以用共同样本重叠建立转移表，报告保留、分裂、合并和新生，而不只给一个一一匹配。若旧簇分成两个都有支持的新簇，应承认解释粒度改变；若两个旧簇合并，旧行动规则可能需要重新评价。标签编号不能跨版本自动沿用，因为相同数字不代表相同成员或特征含义。

保存模型版本、变换版本和命名依据，确保下游能追溯一条记录当时如何分配。将新模型编号直接覆盖旧表，会丢失历史语义，影响业务分析和评价。教材中的内存实验无需建立复杂服务，但实际使用必须理解这些状态之间的依赖，避免将文件里的一个整数误当成永久类别。

<a id="unsup-4-34"></a>

### 7.3 外部结果与实际行动

如果某簇在未来结果上表现不同，这提供预测关联证据，但不一定说明按簇采取措施会产生收益。结果差异可能来自簇使用的输入特征、来源或历史策略。若要评价行动，可以设计随机对照或适合场景的因果识别，并考虑干预成本与成员异质性。无监督分组可以帮助形成行动假设，却不能直接推出干预有效。

若用途是下游预测，可比较加入簇特征前后的完整模型，在相同划分和搜索预算下评价，所有无监督步骤仅在训练内拟合。单独报告簇与标签的相关性不足以证明增加了信息，因为原特征可能已经包含同样内容。应比较独立测试上的增益、校准与计算代价，并报告无改善或退化的条件。

<a id="unsup-4-35"></a>

## 8. 降维实验与聚类实验的连接边界

低维图可用于浏览簇，但图上分离不能替代原空间评价。将聚类运行在二维嵌入上，是一个新的完整流程，嵌入参数与训练信息也进入分组。应同时比较原表示聚类、线性降维后聚类和用于展示的非线性布局，明确各自目标。不能让一个方法只负责美观，却用其图上效果为另一个方法背书。

<a id="unsup-4-36"></a>

### 8.1 相同样本、相同评价空间

若比较两个嵌入的邻域保真，应使用同一输入距离、同一评估样本和同一邻域尺度，并确保样本顺序一致。若比较重构，方法需要明确逆映射；没有自然逆映射的方法不必强行填一个不可比数字。若比较下游分类，表示应可对新样本合法应用，或者明确研究传导设定。

对二维布局，改变随机种子主要反映优化路径；改变困惑度或邻居数还改变目标结构。最终损失不同不一定可直接比较，因为高维概率或图本身变了。可用共同参考空间中的外部指标补充，但每个指标仍有偏好。没有一个数字能同时证明局部、全局、密度、语义和部署都正确。

<a id="unsup-4-37"></a>

### 8.2 图后聚类的选择自由度

反复调整布局直到颜色分开，再运行聚类并评价同一颜色，形成标签驱动的多重选择。即使聚类器本身无监督，整个实验已使用标签。可以如实称为探索或半监督开发，并在独立样本上确认；不能只强调损失没有标签来掩盖开发过程。应记录选择哪些图、哪些参数及依据。

如果最终模型要部署，不能每批独立嵌入再沿用旧簇中心。坐标轴、尺度和全局布局可能变化，中心不再处于同一空间。应冻结可应用的变换，或为新布局建立并评价完整重拟合与身份迁移规则。维度相同不表示坐标语义相同，这是连接降维与聚类时尤其重要的边界。

<a id="sec-4"></a>

<a id="unsup-4-38"></a>

## 9. 报告结构：让结论与证据逐项对应

一份可交付报告先写研究问题和样本总体，随后说明信息边界、表示和算法，再给预先指定的主要评价及敏感性。结果包含簇数量、规模、覆盖、画像、边界和来源关系；稳定性分成优化、抽样、表示与迁移几个层次；最后给独立核验与用途限制。读者应能从每条结论找到对应证据，而不是只看到大量图表却不知道支持什么。

<a id="unsup-4-39"></a>

### 9.1 一个具体的结论写法

可以写：“在某时间范围、某实体单位与固定特征下，得到三组；在指定子采样协议的共同评估集上分区一致；小组支持量有限，对某尺度敏感；未来样本大部分可按冻结规则覆盖；独立结果存在某差异，尚未评价行动收益。”每个分句都有可查对象，也明确了未完成的推理。

避免把“发现三类真实用户”当成结论开头，因为这需要远多于一次算法输出的证据。也不必把合理量化分区贬低为没有价值，它可以在压缩、探索和运营上非常有用。准确表述不是削弱成果，而是让读者知道何时可以复用、何时应重新验证。

<a id="unsup-4-40"></a>

### 9.2 失败记录和停止条件

若所有合理参数都只区分来源，应考虑当前数据不支持目标发现；若小群体始终缺少样本，应增加采样而不是无限调参；若多种划分目标近似等价，可以报告多尺度或不确定边界。预先设定停止条件，能避免把长期试错误当成越来越充分的证据。未发现稳定离散簇，也可能是对连续结构的重要认识。

聚类与降维实验应保留样本范围、拟合协议、参数、随机状态、可运行代码与评价口径。本文实验全部在内存中运行，代码可逐段复核。扩展实验时，应说明表示是只在训练集拟合还是包含全部探索样本，并记录新样本如何进入已有表示；这些条件比中间图片的数量更能决定结果是否可复现、是否具有训练外意义。

<a id="unsup-4-41"></a>

## 10. 进阶方法：不确定性、选择偏差与结构强度

当候选很多、样本有限时，最优验证分数往往同时包含真实效果与偶然有利噪声。尝试的距离、表示、算法和图越多，越容易选中一项偶然看起来漂亮的结果。无标签场景也有这种效应，因为内部指标和人工视觉判断同样存在随机变化。应把开发过程看成一个整体算法，最终评价该流程在独立数据上的行为，而不是只评价被选中的那个静态参数。

<a id="unsup-4-42"></a>

### 10.1 配对比较与重复单位

例如两个方案在同一轮抽样上的指标分别为零点七二与零点七五，配对差值为零点零三；另一轮分别为零点六零与零点六二，差值为零点零二。先分析差值可以去除部分共同的数据难度波动，但只有两轮仍不足以精确估计总体分布。若两轮又来自同一实体的相邻窗口，它们甚至不是两份独立支持。这个小算例说明配对有助于提高解释性，却不会自动创造独立样本或保证显著性；重复单位的定义始终先于统计公式。

比较两个方案时，在相同抽样、相同数据划分和预定种子列表上配对，观察每轮差值，比比较两组完全不同数据上的平均更有解释力。差值的不确定性应按独立抽样单位估计：实体相关时抽实体，时间相关时按合理块抽样。把同一数据上的几十个初始化当作几十份独立总体证据，会夸大对统计泛化的确定性。

随机种子重复只能描述给定数据下的优化波动；不同训练样本描述估计波动；不同总体来源描述迁移差异。置信区间必须说明覆盖哪个随机机制。若只有一份小数据，可以诚实报告条件于该集合的优化范围，而不声称获得了对所有现实总体的精确区间。更多小数位不等于更多独立证据。

<a id="unsup-4-43"></a>

### 10.2 预测强度与共同归属

一种思路是在训练部分建立分群规则，将测试样本按训练规则分配；同时在测试集本身聚类，检查测试簇内部样本对是否在训练规则下仍同组。它关注分区的可预测性，而不要求簇编号匹配。若某测试簇含 $`m`$ 个点，可计算其中样本对被训练规则共同分配的比例，再关注各测试簇中的较弱者。

这个量对最差簇有敏感性，但小簇样本对很少时估计不稳，单点簇甚至没有可比较点对。训练外规则与测试自聚类算法也必须明确，不能一边使用复杂全量方法，一边用任意投影代替其预测。相关原始思路可阅读[Prediction Strength 论文](https://doi.org/10.1198/106186005X59243)。它提供一种验证角度，仍不等于语义真实性或唯一簇数的定理。

<a id="unsup-4-44"></a>

### 10.3 零模型应该破坏什么、保留什么

若想检验某结构是否超过简单随机参照，需要定义零模型。逐列独立打乱会保留每列边际分布，却破坏列间关系；按实体打乱某上下文可能保留个体结构而破坏关联；完全随机生成球形数据则同时改变边际、相关和支持。不同零模型回答不同问题，不应选一个最容易使结果显著的参照。

例如观察到来源与簇关联，若零模型将来源标签在全体任意置换，而来源又与时间强相关，可能不符合需要条件化的研究问题。可在可交换的层内置换，但层划分也需要依据。置换检验的有效性来自明确交换性，不是“打乱了很多次”这一动作本身。研究者应说明零模型为何适合要反驳的解释，并报告不适用条件。

<a id="unsup-4-45"></a>

### 10.4 多尺度结构与连续结构

有些数据在粗尺度上有两大类，细尺度上各有多个子群。要求一个唯一最佳簇数，可能会丢失这种层次。可以报告一段尺度范围的稳定结构、分裂顺序与支持量，并将不同层次对应不同用途。若数据更像连续谱，可以改为低维坐标、原型距离或软成员，而不是强制每个样本拥有永久硬类别。

连续性并不意味无法运营分层，离散切分可以作为明确的管理选择。关键是将边界解释为所选行动规则，而非自然界给出的断层。对边界样本可保留软归属或不确定标识，检查轻微测量误差是否导致不合理行动跳变。这样能够把数学结构与决策后果连接，而不是停留在一张分色图。

<a id="unsup-4-46"></a>

### 10.5 复现结果与复现结论

逐位相同的坐标需要严格控制版本、数值库、线程与随机状态；但科学结论的复现应更关注指定结构关系和用途是否保持。例如 PCA 符号翻转不改变子空间，簇标签置换不改变分区，二维布局旋转不改变局部邻近。验收应使用与结论相容的不变量，而不是把任意坐标命名差异当失败。

反过来，代码每次输出完全相同也不表示结论可信。确定性来源捷径可以稳定重现，训练泄漏也可以稳定重现。实验应同时具备计算复核和独立证据核验：前者保证按定义做了什么，后者检查定义是否服务研究问题。两者缺一都会导致“结果可以重跑，但推论站不住”的情况。

## 11. 十六道进阶练习与详解

<a id="unsup-4-48"></a>

### 11.1 相同长度的标签数组为何不能直接比较

**题目。** 两轮子采样都各有一百条记录，直接计算 ARI 是否足够？

**解析。** 不足。指标假定同一位置是同一对象，长度相同并不保证标识相同。应按稳定标识求交集并排序，再比较；或在共同评估集上使用合法训练外规则。还要报告交集大小与群体覆盖。若只剩少数容易样本，交集上的高分可能无法代表全体，不能隐藏分母后声称整体稳定。

<a id="unsup-4-49"></a>

### 11.2 固定数据改种子能证明未来稳定吗

**题目。** 五十个种子分区都一致，是否代表未来新用户也会稳定？

**解析。** 它只说明给定数据与配置的优化敏感性小。未来样本、来源和表示估计发生变化是另外的随机机制。应加入按实体或时间划分、抽样重拟合和共同未来评估，检查覆盖及画像。重复初始化不能代替独立样本证据，尤其当强来源特征使所有优化路径都落到同一无用分区时。

<a id="unsup-4-50"></a>

### 11.3 ARI 为负意味着什么

**题目。** 手算交叉分区得到负二分之一，能否称为负百分之五十准确率？

**解析。** 不能。ARI 经过固定边际随机置换参照调整，负值表示共同同组关系低于该参照期望，量纲不是分类准确率。实验二列出四格为一的列联表，代入共同对数零、边际对数各二、总对数六，得到分子 $`-\frac{2}{3}`$、分母 $`\frac{4}{3}`$，结果负二分之一。应按定义解释，不随意乘百分号赋予概率含义。

<a id="unsup-4-51"></a>

### 11.4 标签最优匹配能否掩盖分裂

**题目。** 旧簇一分为二，选其中重叠最多的新簇匹配后，能否只报该匹配准确率？

**解析。** 不能。其余成员与未匹配新簇仍是结构变化，应在完整转移表中呈现。匹配解决名称对应，不会让两个新簇自动变成一个。应报告分裂、合并、规模变化和边界支持；若任务需要保持旧行动规则，还需评价迁移影响。仅在匹配子集计算分数会改变分母，可能制造虚假的高稳定性。

<a id="unsup-4-52"></a>

### 11.5 噪声排除后轮廓很高意味着什么

**题目。** 某密度方案只覆盖百分之十样本，但条件轮廓最高，应直接获胜吗？

**解析。** 其分数只描述被覆盖的容易子集。应同时报告覆盖、噪声群体与簇规模，比较同等覆盖或符合用途的方案。如果任务只想找到少量非常可信核心，它可能有用；如果要给全部用户分层，它可能不满足要求。不能跨不同总体只排一个内部指标，也不能将所有噪声视为一个自然群体来补足覆盖。

<a id="unsup-4-53"></a>

### 11.6 标准化与算法同时变化如何归因

**题目。** 方案甲原值 k-means，方案乙标准化 DBSCAN，乙更好，能否说 DBSCAN 优于 k-means？

**解析。** 差异包含表示、目标、参数和拒绝机制，无法单独归因算法。可先在共同表示比较两者，再比较各自完整流程，并明确覆盖和预算。若有用途指标，完整流程比较仍有实践价值，但结论应写成该流程在指定协议下更好，而非无条件的算法排名。控制变量的目的在于解释机制，不是禁止合理的流程优化。

<a id="unsup-4-54"></a>

### 11.7 固定评估集是否可以拟合缩放器

**题目。** 为使距离稳定，将共同评估集也加入缩放拟合，是否仍是未来归纳评价？

**解析。** 评估输入影响了训练表示，改变信息边界。若研究明确允许传导式看见该集合，可以这样做，但不能与完全未知未来的归纳设定混同。抽样稳定性实验中，每轮应按实际部署规则拟合缩放，再对共同评估集变换。只有这样，比较才覆盖了表示估计波动，而不是提前用评估集固定它。

<a id="unsup-4-55"></a>

### 11.8 稳定来源水印怎样被发现

**题目。** 五次结果完全一致、内部指标很高，却不符合预期标签，下一步查什么？

**解析。** 检查来源、时间、缺失、单位和设备版本的交叉表，返回原始样本，做仅去除明确无关来源特征的对照，并在来源内部检验结构。实验四展示稳定来源分组与目标类别几乎无关。不能在看到不喜欢的标签关系后随意删列到符合预期，应依据研究目标和独立证据决定哪些变化合理。

<a id="unsup-4-56"></a>

### 11.9 为什么一簇结果不能凭稳定性获胜

**题目。** 所有点一组在每次重采样都一样，是否是最佳分群？

**解析。** 它的共同归属确实稳定，却没有细分能力。评价需同时包含用途所需分辨率、支持量和操作约束。稳定性只能检验某一划分对扰动是否敏感，不会自动惩罚过粗方案。若目标只是一个总体摘要，一组也可能合理；若目标是差异化行动，就需要额外证据说明何种粒度有价值。

<a id="unsup-4-57"></a>

### 11.10 Bootstrap 重复点会改变什么

**题目。** 将含重复抽样的结果直接当作无放回子采样，可能漏掉哪些影响？

**解析。** 重复增加权重，影响中心与局部密度，也制造近邻并列。比较实体成员时需要先规定副本如何汇总，计算共归属分母时也要避免同一实体被当作多个独立对象。Bootstrap 可用于合适统计量的抽样不确定性，但应匹配独立单位与估计对象，不能因其常用就忽略序列相关或实体重复。

<a id="unsup-4-58"></a>

### 11.11 共归属概率分母为什么重要

**题目。** 一对样本在十轮中只共同出现两次且两次同组，概率应写零点二还是一？

**解析。** 若目标是条件于共同出现的同组概率，估计为一，分母是两次；同时应标明只有两次支持，不能与十次都出现且同组的一样自信。若目标是整体出现并同组频率，零点二回答的是另一个问题。先定义估计对象，再选择分母，能够避免看似相同矩阵实际上混合了不同含义。

<a id="unsup-4-59"></a>

### 11.12 图上轮廓更高能证明原空间改善吗

**题目。** 将二维布局压得更紧后分数提高，是否说明输入分组更好？

**解析。** 布局改变了距离尺度和局部安排，分数可能只是反映图更紧凑。应在共同参考表示中评价分区，或用明确的邻域保真指标评价图本身。若布局参数由标签颜色选择，整体流程又引入监督选择。图可用于浏览与提出假设，但原空间结构和下游用途必须有独立量化支持。

<a id="unsup-4-60"></a>

### 11.13 多次尝试后最佳结果如何确认

**题目。** 搜索一百个表示后，某个验证指标明显最好，可以直接作为最终结论吗？

**解析。** 最佳值含选择噪声，应冻结流程在独立测试或新来源核验；数据有限时可嵌套重采样并明确不确定性。报告尝试范围和主要选择标准，不只列冠军。继续在同一测试集修改就会把它转为开发集；若已经发生，应如实说明并寻找新的确认依据，不能仅改名为测试来恢复独立性。

<a id="unsup-4-61"></a>

### 11.14 组间历史结果差异是否证明行动收益

**题目。** 高消费簇历史购买更多，给它更多优惠就必然赚更多吗？

**解析。** 历史差异可能来自原有能力、选择和既往策略，不能直接给出优惠的增量效果。应比较行动带来的额外收益与成本，采用合适对照或因果识别。若消费已是输入，历史购买差异部分由分组构造，独立证据更弱。聚类可以组织假设和实施分层实验，但不能自动替代行动评价。

<a id="sec-8-2"></a>

<a id="unsup-4-62"></a>

### 11.15 边界追问：编号变化与真实变化如何分开

**题目。** 新版本编号全部改变，但成员重叠很高，应怎样向下游解释？

**解析。** 先用完整交叉表识别置换、分裂和合并，再按共同成员建立展示对应，保留未匹配群体。纯重命名可迁移名称；成员与画像改变则需要重新核验含义。版本应同时记录变换、模型和命名依据，避免相同数字被当作永久语义。一个总体 ARI 有帮助，但不能代替对小簇与行动规则的具体检查。

<a id="unsup-4-63"></a>

### 11.16 什么时候应停止调参并补数据

**题目。** 一个重要小群体在每轮只出现几个点，稳定性很差，下一步一定是更复杂算法吗？

**解析。** 先检查支持量与采集覆盖，可能需要更多独立实体或时间，而不是更灵活模型。可以做样本量学习曲线，观察结构随支持增加是否稳定；也可检查现有特征是否能区分该机制。若所有合理表示均无证据，应报告不确定或连续结构。无限调参会增加选择偏差，不能创造未观测信息。

<a id="unsup-4-64"></a>

## 12. 综合研究：从三团图到可复用的分层方案

<a id="sec-8-1"></a>

<a id="unsup-4-65"></a>

### 12.1 研究问题与分阶段交付

**任务。** 一张二维图呈现三个团，希望将其用于新设备分层。需要设计从探索到未来核验的完整实验，使失败也能得到解释，而不只输出三个标签。

**第一步：界定对象。** 每台设备在固定观察期形成一行，特征仅使用分配时已知信息，维护后的最终故障结果不得进入输入。说明设备来源、版本、缺失和重复规则，按时间留出后来设备，若关心新设备泛化还应隔离实体。图用于提出假设，不预先将三个团称为三种故障类型。

**第二步：建立对照。** 在训练部分拟合共同表示，比较原始合理尺度、标准化、线性压缩及必要的领域变换。固定候选范围和预算，分别研究中心压缩、密度连接及图结构。检查每种方法的簇规模、覆盖、内部质量与原样本；若某个方案只在一个很窄参数点产生三团，应记录敏感性。

**第三步：分解稳定性。** 固定数据改初始化检查优化；无放回抽实体重拟合检查支持；扰动测量误差检查边界；在独立来源和后来时段检查迁移。编号用 ARI 或共归属比较，成员转移用完整交叉表解释。小簇消失时，区分样本不足、尺度影响和算法目标，避免直接命名为不重要噪声。

**第四步：冻结未来规则。** 保存输入、尺度、降维与分配模型版本，规定未知点处理。若所用算法没有直接预测接口，明确另行设计的归纳规则，并独立评价它；不能在新批次重新布局后复用旧中心。对拒绝样本返回原始审查，观察是否为新正常、数据质量问题或目标风险。

**第五步：独立核验。** 在未用于挑图的结果上比较画像、故障及维护表现，控制来源和时间等替代解释。若要据此选择维护措施，设计行动评价并计入成本。组间差异支持预测关联，只有适当干预证据才能支持行动收益。最终报告将已确认事实、探索假设和仍未知机制分开，使下游知道可以依据哪一层证据采取行动。

<a id="unsup-4-66"></a>

### 12.2 验收与可能的合理结局

一种合理结局是三组在多个协议下稳定，未来覆盖好，且外部证据支持某些差异；另一种合理结局是只有两组有足够支持，第三组主要是采集版本；还可能数据呈连续谱，离散切分只适合作为运营规则。三者都能形成有价值交付，只要证据与表述一致。实验的成功不是一定得到原先期待的三类，而是让关键解释得到可靠检验。

本章四组实际实验分别核验冻结训练外规则、置换不变评价、共同评估稳定性和稳定来源偏差。它们没有模拟所有现实困难，也不输出业务收益声明。继续研究可沿样本量、群体不平衡、密度差异和信息边界逐项扩展，并将每次改进连接到具体失败减少。完整协议的价值在于让更多计算转化为更多可解释证据，而不是更多无法审查的漂亮结果。
