## 1. 降维先回答保留哪一种信息

降维将高维观测 $`x\in\mathbb R^d`$ 映射到较低维的表示 $`z\in\mathbb R^r`$。当 $`r<d`$，一般不可能对任意输入保持所有信息，因此每一种方法都在选择牺牲什么。PCA 优先保留欧氏重构中的大方差方向，邻域方法优先保留某种局部关系，监督表示则可能优先保留预测目标所需的信息。讨论“保留百分之多少信息”前，必须指出信息所对应的目标、度量与样本分布。

本章围绕三个不同产出展开：压缩器需要可定义的重构误差；二维浏览图需要对局部与全局布局有清楚的解释边界；用于新数据的表示需要合法且固定的训练外映射。三种产出可以来自同一个工具，也可能彼此冲突。一个图很清晰不表示重构好，一个重构好的一维方向也不表示保留了类别信号。先分清问题，才能判断结果是方法失效，还是评价提出了另一种要求。

<a id="unsup-2-2"></a>

### 1.1 维数与内在维数并不相同

一张图像可以有数十万像素坐标，但如果变化主要来自某个物体的少数姿态参数，其观测可能接近低维非线性流形。反过来，样本量小导致数据矩阵秩低，并不证明真实总体内在维数低。有限样本最多支持有限个独立方向，这是一种观测限制。内在维数估计还受噪声、距离、尺度和局部邻域大小影响，不宜把单个估计值写成数据的永久属性。

例如圆周在平面中是一维流形，但不能用单个全局线性坐标无损而连续地表示所有圆周关系。PCA 一维会把圆周压成线段，使不同点重叠；一个角度坐标又存在周期切口。这个简单例子说明局部维数低，不意味着任何线性投影都能保留结构，也不意味着二维布局中的空白可以直接解释为概率低区。

<a id="unsup-2-3"></a>

### 1.2 输入距离与输出用途

降维前的尺度、缺失处理和表示决定方法看见的差异。金额按元或万元表示会改变协方差；文本向量的长度与方向可以代表不同含义。不要因为最终图只有两维，就忽略前面的所有建模选择。报告至少说明每行是什么实体、每列是什么量、哪些变换由训练数据拟合，以及采用哪种距离。

如果目标是诊断一个固定集合，可明确允许整体拟合；如果目标是预测未来样本，就应将缩放和降维放进训练边界。二者都合理，但回答不同问题。本章的实验均用小型合成数据，不下载数据、不生成图像文件，使用数值恒等式和对照断言核验核心结论，避免把视觉美观当成正确性的替代品。

## 2. PCA：从重构问题到最大方差

设数据矩阵 $`X\in\mathbb R^{n\times d}`$，每行一条观测。训练均值为 $`\bar x`$，中心化矩阵为 $`X_c=X-\mathbf1\bar x^T`$。取 $`V\in\mathbb R^{d\times r}`$ 且 $`V^TV=I_r`$，线性编码为 $`Z=X_cV`$，对应正交重构为 $`\hat X=ZV^T+\mathbf1\bar x^T`$。PCA 在这样的正交线性子空间里最小化训练平方重构误差，不是对任意非线性编码器的全局最优声明。

<a id="unsup-2-5"></a>

### 2.1 中心化为何决定子空间经过哪里

没有中心化时，拟合的是经过坐标原点的线性子空间；中心化后再加回均值，拟合的是经过训练均值的仿射子空间。如果所有观测都在很大的共同偏移附近，未中心化分解可能主要描述该偏移，而不是样本间变化。除非原点具有需要保留的物理意义，否则二者不是可随意替换的步骤。

训练外变换必须用训练均值 $`\bar x_{\mathrm{train}}`$。若对测试集重新求均值，坐标原点发生改变，同一个原始点会因所在批次不同得到不同表示。部署时还要固定列顺序与单位；中心化公式数学上很短，但一旦列错位，生成的每个主成分都可能毫无意义。可通过保存特征清单和简单回放样本检查这些问题。

<a id="unsup-2-6"></a>

### 2.2 重构误差与投影能量的恒等式

因为 $`P=VV^T`$ 是对称且幂等的正交投影，$`X_cP`$ 与 $`X_c(I-P)`$ 在 Frobenius 内积下正交。因此 $`\Vert X_c\Vert _F^2=\Vert X_cV\Vert _F^2+\Vert X_c-X_cVV^T\Vert _F^2`$。总能量固定，最小重构误差就等价于最大投影能量。再将投影能量写成 $`\operatorname{tr}(V^TX_c^TX_cV)`$，问题转为选择对称半正定矩阵的最大特征子空间。

当只取一个方向 $`v`$，约束 $`v^Tv=1`$，目标是 Rayleigh 商的分子 $`v^TX_c^TX_cv`$，最大值为最大特征值。取多个正交方向时，可在特征基底上展开：各方向能量权重总和受正交约束限制，最优方案将权重放在最大的若干特征值上。这个论证给出为何不能简单取若干相关的高方差方向，因为它们会重复解释同一能量。

可以把“把权重放在最大特征值上”写成完整不等式。令 $`C=X_c^TX_c=Q\operatorname{diag}(\lambda_1,\ldots,\lambda_d)Q^T`$，此处 $`\lambda_j`$ 是未除分母的散布特征值，按降序排列；不要与下一小节样本协方差的特征值数值混用。对任意 $`V^TV=I_r`$，置 $`B=Q^TV`$，令 $`a_j=\sum_{\ell=1}^r B_{j\ell}^2`$。因为 $`BB^T`$ 是秩 $`r`$ 的正交投影，$`0\le a_j\le1`$，并且 $`\sum_ja_j=r`$。投影能量恰为 $`\sum_j\lambda_ja_j`$。当 $`1\le r<d`$，

$$
\sum_{j=1}^r\lambda_j-\sum_{j=1}^d\lambda_ja_j
=\sum_{j\le r}\lambda_j(1-a_j)-\sum_{j>r}\lambda_ja_j
\ge\lambda_r\left[\sum_{j\le r}(1-a_j)-\sum_{j>r}a_j\right]=0.
$$

这证明多方向的最优性，而不只是单方向 Rayleigh 商。取前 $`r`$ 个特征向量时上界达到。若 $`\lambda_r>\lambda_{r+1}`$，最优投影子空间唯一；基向量的正负号和子空间内部坐标仍可变化。若截断位置跨越重特征值，则不同的最优子空间可有相同能量。这解释了为何重复运行得到不同主方向不一定是算法错：应比较投影矩阵或主角度，并先检查谱间隙。


<a id="unsup-2-7"></a>

### 2.3 协方差、奇异值与维度核对

对中心化矩阵作奇异值分解 $`X_c=U S V^T`$，奇异值按 $`s_1\ge s_2\ge\cdots\ge0`$ 排序。前 $`r`$ 个右奇异向量给出主成分方向，得分为 $`Z=U_rS_r`$。若样本协方差定义为 $`C=\frac{X_c^TX_c}{(n-1)}`$，则特征值为 $`\lambda_j=\frac{s_j^2}{(n-1)}`$。这里分母使用样本方差约定，换成总体方差分母会改变数值尺度，却不改变主方向。

维度可以逐项检查：$`V_r`$ 是特征数乘保留维数，$`Z`$ 是样本数乘保留维数，$`V_rV_r^T`$ 是特征空间的投影矩阵。库中的成分往往按行存储，因此形状可能是保留维数乘特征数，公式中的转置要对应接口。看见矩阵维度不匹配时，应先确定每行代表样本还是方向，不能靠不断添加转置让代码勉强运行。

<a id="unsup-2-8"></a>

### 2.4 最小误差与奇异值尾部

在上述正交重构中，最小平方误差为 $`\sum_{j>r}s_j^2`$。这既可由投影能量恒等式得到，也可与截断 SVD 的低秩近似性质联系。注意这是训练矩阵的总平方误差；除以样本数得到每样本误差，除以样本数和特征数才是逐元素均方误差。不同文献都写 MSE 时，分母可能不同，必须核对。

解释方差比例为 $`\frac{\lambda_j}{\sum_\ell\lambda_\ell}`$，累计比例衡量选中方向在当前输入平方能量中的份额。它不衡量目标变量的信息比例，不评价语义相似，也不保证训练外误差。若数据已标准化，该比例描述标准化空间；不能将标准化前后的比例混在一起，仿佛都是同一物理量的保留率。

### 2.5 低方差信号可以决定全部标签

设第一坐标大幅波动但与标签无关，第二坐标只在很小的正负值之间变化，而标签恰好由正负号决定。PCA 一维保留第一坐标，可解释几乎全部输入方差，却丢掉全部分类信息。这没有违反任何 PCA 定理，因为其目标从未使用标签。若任务是预测，应在完整训练流程里比较降维与不降维，而不能仅凭累计方差选择后宣布分类必然不受损。

一个特别清楚的构造是将第一列取十、十、负十、负十，第二列取一、负一、一、负一。两列正交且方差比一百比一，第一主成分只能保留大尺度列，但每个保留值对应两个相反标签。无论后续分类器多复杂，若只看这一维，也无法把成对观测分开；问题在信息丢失，不在分类器能力不足。

<a id="unsup-2-10"></a>

### 2.6 实验一：重构尾部、协方差与反例

下面用精确小矩阵核验三个量：截断重构误差、奇异值尾部、库中解释方差；随后验证低方差方向确实包含标签。比较子空间时采用投影矩阵，避免奇异向量的任意正负号使正确结果看似不同。

```python
import numpy as np
from sklearn.decomposition import PCA
X = np.array([[10., 1.], [10., -1.], [-10., 1.], [-10., -1.]])
Xc = X - X.mean(axis=0)
U, s, Vt = np.linalg.svd(Xc, full_matrices=False)
manual = (Xc @ Vt[:1].T) @ Vt[:1]
pca = PCA(n_components=1, svd_solver='full').fit(X)
recon = pca.inverse_transform(pca.transform(X))
assert np.allclose(manual, recon)
assert np.isclose(((Xc-manual)**2).sum(), (s[1:]**2).sum())
assert np.allclose(pca.explained_variance_, s[:1]**2/(len(X)-1))
assert np.isclose(pca.explained_variance_ratio_[0], 100/101)
Z = pca.transform(X).ravel()
y = (X[:, 1] > 0).astype(int)
assert np.isclose(Z[0], Z[1]) and y[0] != y[1]
assert np.isclose(Z[2], Z[3]) and y[2] != y[3]
print('retained variance:', pca.explained_variance_ratio_[0], 'SSE:', ((X-recon)**2).sum())
```

实验没有使用随机数据，避免把“第一列恰好与标签有偶然相关”混入反例。真实任务中信号通常不如此干净，需要在训练内选择维度并留出评价。反例的作用是推翻“保留大部分方差必定保留大部分预测信息”的普遍命题，不是证明 PCA 在所有预测任务中都会变差。

## 3. 白化、数值稳定与可识别性

PCA 旋转并截断，白化进一步按每个方向的尺度缩放，使保留坐标具有单位协方差。若样本得分列方差为 $`\lambda_j`$，取 $`z'_j=\frac{z_j}{\sqrt{\lambda_j}}`$，在训练样本方差约定下得到单位方差。白化改变下游欧氏距离，使低方差方向与高方差方向权重接近，可能帮助某些模型，也可能放大噪声。它不是对 PCA 输出无影响的标准清理。

<a id="unsup-2-12"></a>

### 3.1 小特征值为何危险

当某个特征值很小，除以其平方根会放大该方向的估计噪声；零特征值则不能直接除。可截去不可靠方向，或使用 $`\frac{1}{\sqrt{\lambda_j+\alpha}}`$ 的正则缩放，但后者不再精确白化，应如实命名。应根据任务比较白化前后的训练外距离和结果，而不是只验证训练协方差变为单位阵就宣布表示改善。

若使用不同行为的方差分母，单位方差的数值会相差 $`\frac{n}{(n-1)}`$ 等因子。正文实验明确用`ddof=1`，并以本机 scikit-learn 1.8 实测结果为界。部署时应保存实际变换对象，不能只记一句“做过白化”，否则不同实现、样本量或零值处理可能产生不同尺度。接口细节见[PCA 1.8 文档](https://scikit-learn.org/1.8/modules/generated/sklearn.decomposition.PCA.html)。

<a id="unsup-2-13"></a>

### 3.2 重根、符号与子空间

一个主成分可以整体乘负一，投影和重构完全等价；相同特征值对应的子空间内部还可以任意正交旋转。若两个最大特征值几乎相等，轻微扰动就可能大幅旋转单个方向；只有保留的这两个方向与其余方向之间仍有足够大的谱间隙、且扰动相对该间隙足够小时，二维子空间才有稳定性保证。仅知道前两个特征值接近，不能推出该子空间稳定。因此不能仅用每根载荷的逐坐标相关判断 PCA 是否复现，应同时比较投影矩阵、主角度或重构。

例如取 $`0<\varepsilon<\frac{1}{2}`$，协方差 $`\Sigma=\operatorname{diag}(2,2,2-\varepsilon)`$ 的前二维子空间为前两个坐标轴张成的平面。加入 $`E=\operatorname{diag}(0,-2\varepsilon,0)`$ 后，前二维子空间变成第一、第三坐标轴张成的平面。扰动的算子范数仅为 $`2\varepsilon`$，可任意小，两平面的一个主角度却为直角。原因是保留与舍弃方向间的原谱间隙只有 $`\varepsilon`$，扰动并不相对它足够小。稳定性分析的具体推导见[线性代数中的 PCA 子空间稳定性](../../Mathematics/LinearAlgebra/04-从协方差到PCA的完整实践.md#sec-6)。

对重根子空间硬给每个轴命名，容易制造虚假的解释确定性。更合适的做法是描述该子空间联合由哪些原始特征构成，以及哪些线性组合都能解释近似相同的方差。当谱间隙明显时，子空间通常更易估计；间隙很小时，应在重采样中观察方向或子空间的波动，不把样本偶然选定的坐标方向当成总体定律。

<a id="unsup-2-14"></a>

### 3.3 分解方式与稀疏输入

直接对中心化矩阵做 SVD 与先形成协方差再特征分解，在精确算术下给出对应方向；有限精度下，协方差会平方奇异值的条件数，小方向可能更难精确估计。随机化 SVD 在大矩阵上可节省成本，但它是近似算法，过采样和幂迭代影响精度。应在适当规模子集用精确解核验，而不是只以运行不报错判断足够准确。

稀疏文本矩阵若显式减均值，可能迅速变稠密，造成内存问题。截断 SVD 常用于未中心化的稀疏矩阵，其目标与中心化 PCA 有差别。选择应同时考虑数学目标和数据结构，不能把两者在文档中统一写成完全相同的 PCA。对流式数据使用增量算法时，还要检查批次顺序、批量大小和与全量解的误差，不应默认结果逐位一致。

<a id="unsup-2-15"></a>

### 3.4 实验二：白化的正确分母与训练外均值

本实验用三维满秩数据核验训练得分协方差，并展示测试批次自己中心化会丢掉整体偏移。测试偏移可能是正常总体变化，也可能是重要异常；无论解释如何，都不应未经声明就用每批重新中心化将其删除。

```python
import numpy as np
from sklearn.decomposition import PCA
rng = np.random.default_rng(21)
train = rng.normal(size=(100, 3)) @ np.diag([4., 2., .5])
model = PCA(n_components=3, whiten=True, svd_solver='full').fit(train)
Z = model.transform(train)
assert np.allclose(np.cov(Z, rowvar=False, ddof=1), np.eye(3), atol=1e-10)
new = train[:10] + np.array([20., 0., 0.])
correct = model.transform(new)
wrong = model.transform(new - new.mean(axis=0) + model.mean_)
assert np.linalg.norm(correct.mean(axis=0)) > 1
assert np.allclose(wrong.mean(axis=0), 0, atol=1e-10)
assert np.allclose(model.inverse_transform(Z), train)
print('whiten covariance verified; shifted mean norm:', np.linalg.norm(correct.mean(axis=0)))
```

完整保留三维时逆变换可恢复训练观测，说明白化本身可以是可逆缩放；截断后则存在不可恢复的舍弃方向。不要把“白化改变距离”误写成“白化必然丢信息”，也不要把全维可逆性误写成“下游算法不受影响”：对距离敏感的模型会受缩放影响，即使变换可逆。

<a id="visual-insight-unsupervisedlearning-02"></a>
### 深入图解：白化把不同主方向的方差缩放到相同单位

![白化把不同主方向的方差缩放到相同单位](images/02-insight.svg)

设协方差在主方向坐标中为对角阵九、一，中心化后将第一方向除以三、第二方向除以一，得到单位协方差。图画的是相同标准化半径的椭圆与圆的边界，不是某次采样散点，也不是白化后所有样本都落在圆周上。这个变换改变距离度量，低方差方向会获得更高相对权重；若特征值接近零，直接除以平方根会放大数值误差。应按训练数据拟合中心与变换，明确截断或正则化方式，并在后续样本上复用。

## 4. t-SNE：拟合邻域概率而非原始坐标

t-SNE 将高维点之间的邻近关系转成概率，再寻找二维坐标，使二维中的某种邻近概率尽量接近它。它输出的是样本集合的布局，而不是像 PCA 那样由一个固定矩阵给出所有新点的坐标。理解概率构造比记忆“局部结构好”更有帮助，因为目标明确告诉我们哪些误差受到更大惩罚，哪些视觉量没有直接保留承诺。

<a id="unsup-2-17"></a>

### 4.1 条件邻居分布与困惑度

对每个点 $`i`$，以高维距离定义 $`p_{j\mid i}=\frac{\exp[-\frac{\Vert x_i-x_j\Vert ^2}{(2\sigma_i^2)}]}{\sum_{\ell\ne i}\exp[-\frac{\Vert x_i-x_\ell\Vert ^2}{(2\sigma_i^2)}]}`$，且 $`p_{i\mid i}=0`$。带宽 $`\sigma_i`$ 随点调整，使分布熵对应指定困惑度。若所有有效邻居概率均等于 $`\frac{1}{m}`$，熵为 $`\log_2m`$，困惑度为 $`2^H=m`$；一般情况下它是有效邻居数量的软尺度，不是硬取某个整数近邻集合。

同一困惑度下，密集区可使用较小带宽，稀疏区需要较大带宽。这种局部适应有利于比较各处邻域，但也说明二维簇面积未必保留原始密度：高维稀密差异在构造概率时已经被部分重新标定。困惑度必须与样本规模相容，过小更强调非常局部关系，过大可能混合更广范围；它不是可以跨样本量机械照搬的最佳常数。

<a id="unsup-2-18"></a>

### 4.2 对称概率、重尾和目标方向

将条件概率对称化为 $`p_{ij}=\frac{(p_{j\mid i}+p_{i\mid j})}{(2n)}`$，低维使用重尾分布 $`q_{ij}\propto(1+\Vert y_i-y_j\Vert ^2)^{-1}`$，并对所有非对角点对归一化。目标是 $`\mathrm{KL}(P\Vert Q)=\sum_{i\ne j}p_{ij}\log(\frac{p_{ij}}{q_{ij}})`$。较大的 $`p_{ij}`$ 若被低维安排得过远，使 $`q_{ij}`$ 很小，会受到较强惩罚，因此保留高概率近邻是重要重点。

KL 的方向不可随意交换。低维把原本不邻近的点放近，也会通过归一化与其他项影响目标，但不能据此断言两个方向的错误受到同样权重。重尾缓解将高维邻域塞进低维时的拥挤问题，却不提供全局距离等距保证。读者可从[t-SNE 原论文](https://www.jmlr.org/papers/v9/vandermaaten08a.html)核对概率目标及其构造；本文据此分析可解释范围，不将二维布局当作原空间地图。

<a id="unsup-2-19"></a>

### 4.3 梯度、初始化与早期夸大

在标准对称目标下，梯度包含 $`4\sum_j\frac{(p_{ij}-q_{ij})(y_i-y_j)}{(1+\Vert y_i-y_j\Vert ^2)}`$。可以将其理解为目标近邻与当前低维关系之间的吸引和排斥平衡，但不能把每项单独看成不受其他点影响的力，因为 $`q`$ 的归一化耦合了所有点。整体目标非凸，初始化和优化路径会影响布局。

梯度中的系数四可以从有序点对逐步得到，避免把吸引排斥当作无法核对的比喻。令 $`w_{ij}=(1+\Vert y_i-y_j\Vert ^2)^{-1}`$、$`Z=\sum_{a\ne b}w_{ab}`$，则 $`q_{ij}=\frac{w_{ij}}{Z}`$。标准对称定义满足 $`p_{ij}=p_{ji}`$、$`p_{ii}=0`$ 且 $`\sum_{i\ne j}p_{ij}=1`$。固定高维概率后，目标可写成

$$
C=\sum_{i\ne j}p_{ij}\log p_{ij}
-\sum_{i\ne j}p_{ij}\log w_{ij}+\log Z.
$$

因为 $`\nabla_{y_i}\log w_{ij}=-2w_{ij}(y_i-y_j)`$，对称有序项 $`(i,j)`$ 与 $`(j,i)`$ 各贡献一次，中间一项导数为 $`4\sum_jp_{ij}w_{ij}(y_i-y_j)`$。同时 $`\nabla_{y_i}w_{ij}=-2w_{ij}^2(y_i-y_j)`$，所以归一化项导数为

$$
\nabla_{y_i}\log Z
=-\frac4Z\sum_jw_{ij}^2(y_i-y_j)
=-4\sum_jq_{ij}w_{ij}(y_i-y_j).
$$

合起来就是本节的标准梯度。第二部分来自所有低维点对共同决定的分母；若把 $`Z`$ 错当常数，只剩吸引项，优化目标就完全变了。所有梯度向量相加为零，也是平移不改变两两距离的直接结果，可以作为数值实现的独立核对条件。

做一个三点一维算例：低维坐标为零、一、三，设 $`p_{12}=p_{21}=0.2`$、$`p_{13}=p_{31}=0.1`$、$`p_{23}=p_{32}=0.2`$。三个无序对的 $`w`$ 分别为 $`0.5,0.1,0.2`$，但归一化分母按有序对求和，故 $`Z=1.6`$；相应 $`q`$ 为 $`0.3125,0.0625,0.125`$。代入得到三个坐标梯度分别为 $`0.18,-0.345,0.165`$，总和为零。梯度下降把第一个点向左、第二个点向右、第三个点向左推；不能只从两个点的当前距离判断移动方向，因为不同邻居的贡献会相加。该推导对应[t-SNE 原始论文](https://www.jmlr.org/papers/v9/vandermaaten08a.html)的对称目标，改变低维核、概率归一化或近似实现时，应重新对应具体目标。

早期夸大等训练策略改变优化初期的吸引强度，学习率和迭代数也影响是否充分优化。仅固定种子只能复现某条路径，不能验证其稳定性或最优性。应比较多个预先给定的种子和参数，记录最终目标、邻域指标及异常失败；不同困惑度改变了高维概率目标，最终 KL 数值不宜直接当成同一任务下的可比排行榜。

<a id="sec-2-1"></a>

<a id="unsup-2-20"></a>

### 4.4 哪些视觉量没有统一含义

两个二维小岛相距很远，可能表示它们缺乏强局部吸引，也可能受其他群体和初始化影响；距离两倍通常不能解释为语义差异两倍。簇面积受局部带宽、样本数和布局优化影响，不等同原始密度；空白不必代表真实概率为零；旋转和镜像不改变点对距离，因此轴的正负方向没有独立语义。

一条连续流形也可能被画成几段，尤其在采样不均、局部邻域断裂或参数很小时。反之，真实标签不同却有相似局部表示的点可能混合。图适合定位值得核查的近邻与样本，不适合单独证明群体类型数量。应回到原空间检查边界点和桥接点，并比较合理参数范围内同一结构主张是否持续存在。

<a id="unsup-2-21"></a>

### 4.5 接口与训练外样本

本文使用 scikit-learn 1.8 的`TSNE`，显式设置`max_iter`、`perplexity`、`init`、`learning_rate`与`random_state`，不依赖过时参数名。该接口没有与 PCA 相同的通用`transform`方法，因此不能在训练集拟合后默认将新样本直接投到完全同义的坐标。可参考[TSNE 1.8 接口](https://scikit-learn.org/1.8/modules/generated/sklearn.manifold.TSNE.html)核对参数和限制。

将新旧样本合并后重新运行，可能让旧坐标整体改变；学习一个额外映射预测原布局，得到的是新的近似模型；其他参数化或可插入实现也有各自条件。选择哪一种取决于用途，但必须分别评价，不能将训练后坐标数组误当成已经拥有稳定的归纳函数。

## 5. UMAP：局部模糊图与低维布局

UMAP 同样先建立局部邻域结构，再优化低维表示，但其图权重构造和目标不同于 t-SNE。理解到“都重视邻居”还不够：不同的边权、负采样和布局曲线，会影响密度、连接及全局安排。理论动机、实际损失与具体软件接口应分开阅读，不能只用“保持流形”四个字概括所有保真性质。

<a id="unsup-2-23"></a>

### 5.1 从近邻距离到局部权重

对点 $`i`$，先计算若干近邻距离，并使用局部尺度参数把距离转为递减的关联强度，近点通常获得较大权重。局部最近距离的偏移使不同采样密度下的邻域得到自适应调整；再将两个方向的关联以模糊并集组合成对称图。这里的边权不是原始距离本身，也不是业务风险概率，其含义来自邻域构造。

当近邻搜索是近似的、样本密度不均或特征尺度不合理时，初始图可能已丢失或制造连接。后续优化无法恢复从未纳入的关键信息。对重要结论，应在可精确计算的子集检查邻居召回和图连通，再观察改变邻居数及距离度量后结果。若不同表示给出完全不同图，应先解释表示，而不是只比较最终布局美观。

<a id="unsup-2-24"></a>

### 5.2 交叉熵布局与实际优化

具体地，对有向邻域可写 $`p_{j\mid i}=\exp[-\frac{\max(0,d(x_i,x_j)-\rho_i)}{\sigma_i}]`$，其中 $`\rho_i`$ 是局部连接偏移，常与最近非零距离及局部连通设置有关，$`\sigma_i`$ 通过邻域权重总量的尺度条件估计。这个式子只对被纳入的邻域边构造，未列入者通常取零。两个方向合并为 $`p_{ij}=p_{j\mid i}+p_{i\mid j}-p_{j\mid i}p_{i\mid j}`$，例如两个方向权重零点六与零点五，并集权重为零点八，而不是一。在低维使用 $`q_{ij}=\frac{1}{(1+a\Vert y_i-y_j\Vert ^{2b})}`$，正参数 $`a,b`$ 依低维距离曲线及`min_dist`、`spread`的设定拟合，不能对所有配置写成同一固定常数。

全点对二元交叉熵可写为 $`-\sum_{i<j}[p_{ij}\log q_{ij}+(1-p_{ij})\log(1-q_{ij})]`$，省略的高维熵项不影响对低维坐标求最优。吸引项要求高权重边具有较大低维关联，排斥项阻止未连接关系全部坍缩。实际软件通过边采样、负采样与有限步随机更新实现计算，采样权重和排斥强度会形成具体的有效优化行为；不能无条件将其说成逐步精确下降完整全点对表达式。上述公式提供可计算的概念对象，软件输出仍需按版本和实验协议核验。

例如只看一个可自由调整的点对，目标权重为零点八，交叉熵在低维关联同为零点八时最小；把关联硬推到零点九九，反而因排斥项而增加损失。若曲线参数取一、一，距离一给关联二分之一，距离二给关联五分之一，说明低维距离先经过非线性曲线再参与目标。整张图的几何约束使所有点对目标未必能同时满足，所以这些局部算例帮助理解力的方向，不构成全图精确保真的保证。

`n_neighbors`调整局部图尺度，`min_dist`主要影响低维点可以被压紧的程度，两者不是同一个参数。较小的低维最小距离可以让小岛更紧凑，却不意味着原始群体更分离；较大邻域可能更关注广泛关系，也可能跨过真实稀疏边界。方法动机可阅读[UMAP 原论文](https://arxiv.org/abs/1802.03426)，参数解释可核对[官方参数指南](https://umap-learn.readthedocs.io/en/latest/parameters.html)。

<a id="unsup-2-25"></a>

### 5.3 新样本变换仍需要评价

部分 UMAP 实现提供新样本变换，它利用已拟合结构安置新点；这比只输出固定布局更适合归纳任务，但不意味着重拟合新旧全集会得到相同坐标。新数据若远离参考集，最近邻也可能只是“所有坏选择里最近的那个”，强制映射会制造虚假的熟悉感。应增加原空间距离、覆盖率或拒绝检查，而不能只看新点落在已有小岛附近。

本文不假定环境安装 UMAP，也不运行安装操作，因此不提供伪装成已实测的 UMAP 代码。概念比较与接口核对来自上述原始和官方资料；所有实际运行的实验使用已安装的 NumPy 和 scikit-learn。读者后续使用 UMAP 时，应记录实际包版本、种子、线程与变换配置，并按本章协议独立核验，不能把其他方法的实验通过当作它的实现验证。

## 6. 投影图与原空间：逐层核验结构主张

二维中接近的点可能只是在保留维度相近，舍弃方向仍有很大差异。正交投影不增加欧氏点对距离，但会把某些远点压近；非线性布局则连这个统一收缩性质也不必具备。相反，二维看似分开也可能主要由邻域图和布局放大造成。提出任何结构主张时，都应说明它是关于原始特征、某个表示，还是仅关于这张图。

<a id="unsup-2-27"></a>

### 6.1 近邻核查比量图上距离更直接

若图中某两个样本靠近，可列出它们在原空间的距离、各自最近邻，以及决定相似的主要特征。若发现小岛，可检查岛内原始分布是否一致、是否由同一来源或缺失模式构成，以及岛间是否存在原空间连续路径。人工核查不应只选择最典型点，还应包含边界、桥接和异常点，因为这些点最能区分“自然分离”与“布局分离”。

还应核对样本规模的影响。一个大群体包含更多观测，在图中更显眼并不自动代表更高原始概率密度；抽样改变后局部邻域关系也会变化。若按类别平衡抽样作图，应明确这是展示用的重加权总体，不能据此读出真实人群占比。图例里写清采样规则，比给每个岛起一个自信名称更有解释价值。

<a id="unsup-2-28"></a>

### 6.2 旋转对齐只解决坐标任意性

两次布局可能只是旋转、平移、镜像或尺度不同，可用 Procrustes 类对齐辅助比较。但对齐后的坐标差异仍不是全部稳定性：非线性方法的局部邻域可能相近而全局排列改变，或者全局形状类似但边界成员已经替换。应同时比较近邻集合、共同归属或具体结构主张，不仅给一张叠加图。

如果对齐使用了全部点，异常区域的变化可能被整体拟合折中掩盖；也可能因为一个局部旋转使整体坐标误差很大，而重要邻居没有变化。选择对齐指标应服务研究问题。用于识别某个新异常群体时，区域覆盖和原空间近邻比整张图的旋转角度更重要；用于保持交互界面位置时，坐标稳定性本身则可能是产品要求。

<a id="visual-example-unsupervisedlearning-02"></a>

### 图解算例：邻域保留需要把投影邻居与原空间逐项比较

![邻域保留需要把投影邻居与原空间逐项比较](images/02-example.svg)

固定同一对象 X 和邻居数三，原空间邻居集合为 A、B、C，二维投影中变成 A、D、C，交集大小为二，因此邻居召回为三分之二。这个指标衡量特定尺度的局部关系保留，不等价于全局距离、簇间大小或语义类别被正确恢复。并列距离、近邻搜索近似和参考空间预处理都会影响结果，需要声明规则。即使局部召回较高，也不能从二维图直接推断簇间距离有原空间度量含义，更不能只选看起来最清楚的一次随机布局。

## 7. 无标签也能评价，但不能只用一个分数

没有类别标签时，仍可评价重构、邻域侵入、邻居丢失、距离秩关系及稳定性。这些量回答不同问题。一个编码器重构好但邻居差，可能保留大尺度能量而舍弃局部细节；一个图邻域好但无法逆变换，可能适合浏览却不适合压缩重建。建立指标面板时，应从用途出发选择少量有明确解释的量，避免指标越多越容易挑选有利结果。

<a id="unsup-2-30"></a>

### 7.1 信任度惩罚虚假的低维邻居

设低维中出现的近邻在原空间排名很远，称为邻域侵入。信任度按这些侵入者的原空间距离排名给予惩罚，并作归一化，常见形式为 $`T(k)=1-\frac{2}{nk(2n-3k-1)}\sum_i\sum_{j\in U_i^{(k)}}(r(i,j)-k)`$。这里 $`U_i^{(k)}`$ 是低维前 $`k`$ 邻居中不在原空间前 $`k`$ 的点，$`r(i,j)`$ 为原空间排名。

高信任度说明低维近邻较少由原空间远点侵入，不代表原空间所有近邻都保住，也不直接评价全局布局。参数 $`k`$ 改变问题尺度，应报告一组有意义的邻域而不是只挑最高分；输入和嵌入的样本必须严格对应。实现要求与尺度约束可核对[trustworthiness 1.8 文档](https://scikit-learn.org/1.8/modules/generated/sklearn.manifold.trustworthiness.html)。

<a id="unsup-2-31"></a>

### 7.2 连续性、邻居召回与距离指标

连续性重点惩罚原空间近邻在低维中丢失，与信任度方向互补。最直观的邻居召回是每点两个前 $`k`$ 邻居集合交集大小除以 $`k`$，再对样本平均。它容易解释，却不会区分侵入的低维邻居在原空间排名第 $`k+1`$ 还是极远，也不区分被丢失的原空间近邻在低维偏移多远，也可能受距离并列影响。应明确排除样本自身，并对重复点和并列规则保持一致。

全局距离相关可以检查大范围关系，但高相关可能主要来自几个大群体之间距离，对小群体内部近邻失真不敏感。PCA 重构误差还受原始尺度支配。若评价和训练采用不同距离，差异可能来自目标不一致。每个指标都应注明在哪个空间、用哪个度量、对哪些样本计算，避免同一列数值实际比较不同总体。

<a id="unsup-2-32"></a>

### 7.3 实验三：独立计算邻居重叠与布局信任度

下面对同一份六维数据进行 PCA 和 t-SNE，计算信任度及自行实现的邻居重叠。我们不预先断言某方法必须赢，因为方法目标和随机优化并不提供这种普遍保证；断言只检查结果范围、样本一致性和有限值。额外使用原输入作为嵌入，核验邻居重叠与信任度应达到一，形成对指标实现的正向对照。

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE, trustworthiness
from sklearn.metrics import pairwise_distances
from threadpoolctl import threadpool_limits
X, _ = make_blobs(n_samples=90, n_features=6, centers=3, random_state=9)
def neighbors(A, k):
    D = pairwise_distances(A)
    np.fill_diagonal(D, np.inf)
    return np.argsort(D, axis=1)[:, :k]
def overlap(A, B, k):
    na, nb = neighbors(A, k), neighbors(B, k)
    return np.mean([len(set(a) & set(b))/k for a, b in zip(na, nb)])
assert overlap(X, X, 5) == 1
assert np.isclose(trustworthiness(X, X, n_neighbors=5), 1)
with threadpool_limits(limits=1):
    Zp = PCA(n_components=2, svd_solver='full').fit_transform(X)
    Zt = TSNE(n_components=2, perplexity=12, max_iter=500,
              init='pca', learning_rate='auto', random_state=9,
              n_jobs=1).fit_transform(X)
for name, Z in [('PCA', Zp), ('t-SNE', Zt)]:
    assert Z.shape == (90, 2) and np.isfinite(Z).all()
    t = trustworthiness(X, Z, n_neighbors=5)
    o = overlap(X, Z, 5)
    assert 0 <= t <= 1 and 0 <= o <= 1
    print(name, 'trustworthiness:', round(t, 4), 'overlap:', round(o, 4))
```

这个实验故意不使用标签评价，因为它只核验输入邻域保留。若真实任务有标签，可以事后着色或计算外部指标，但使用标签调参会引入监督选择。即使两个指标都高，也不代表图中三个岛就是三类真实对象；输入本身可能包含来源水印或人工构造的尺度，指标只是忠实评价该输入几何。

<a id="unsup-2-33"></a>

### 7.4 对照组与选择范围必须可见

一个完整探索应包含原始或合理标准化后的简单基线、若干保留维数、多个邻域尺度，以及明显失败的对照。故意打乱坐标对应、仅保留无关特征或将嵌入随机置换，都可以测试指标能否识别某类错误。但负向对照的表现应实际计算，不要先假定所有随机数据都必然给零分；指标归一化基准与有限样本分布需要理解。

若尝试一百种布局只展示最符合颜色的一个，读者看不到选择过程。可以保留候选参数表、预先约定主要指标，并展示代表性的稳定与失败情况。这里的“保留记录”指最终报告中足以解释选择的摘要，不要求在教材文件夹堆积大量图片或临时程序。探索可以宽泛，但确认性结论要有独立核验。

<a id="unsup-2-34"></a>

## 8. 拟合边界：探索、传导与归纳

无监督步骤也会使用数据分布。将全部训练和测试输入一起拟合 PCA，会让测试方向、均值和方差影响表示；这虽然没有使用测试标签，却改变了预测任务的信息边界。如果协议允许事先看见所有未标注测试输入，这是传导式设定，应明确声明；若目标是面对未来从未见过的样本，就应该在训练数据拟合表示。

<a id="unsup-2-35"></a>

### 8.1 完整 Pipeline 才是被评价的对象

预测流程中的缺失补全、尺度估计、特征选择、降维与分类器，应一起放在训练折里拟合。只把分类器放进交叉验证，而在此前对全数据做降维，会让每个验证折的信息参与表示选择。搜索维数和白化参数也属于模型选择，需要在训练内部完成；最后独立测试只评价已经固定的规则。

在聚类场景，任务可以是描述当前固定全集，此时全量拟合本身合理。但如果声称群组可用于后来客户，就要冻结表示和分配方案，在时间向前的数据上核验覆盖与稳定。将一张固定全集的漂亮图当作未来归纳能力证据，跨越了未经检验的一步。论文或学习报告应指出结果究竟覆盖哪个样本总体。

<a id="unsup-2-36"></a>

### 8.2 实验四：拟合状态不会被测试变换更新

下面用训练数据拟合缩放加 PCA，并对偏移很大的测试数据调用变换。断言拟合参数不变，且对同一记录在不同批次中变换得到相同结果。然后构造错误的逐批拟合，观察其将偏移消除。这是接口语义测试，不是用随机效果分数替代信息边界分析。

```python
import numpy as np
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
train = np.array([[0., 0.], [1., 2.], [2., 1.], [3., 4.], [4., 3.]])
test = np.array([[100., 100.], [101., 102.]])
pipe = make_pipeline(StandardScaler(), PCA(n_components=1, svd_solver='full'))
pipe.fit(train)
scale_mean = pipe[0].mean_.copy()
components = pipe[1].components_.copy()
Z = pipe.transform(test)
Zsingle = pipe.transform(test[:1])
assert np.allclose(Zsingle, Z[:1])
assert np.array_equal(pipe[0].mean_, scale_mean)
assert np.array_equal(pipe[1].components_, components)
wrong = make_pipeline(StandardScaler(), PCA(n_components=1, svd_solver='full'))
wrongZ = wrong.fit_transform(test)
assert not np.allclose(wrong[0].mean_, scale_mean)
assert not np.allclose(Z, wrongZ)
print('fixed representation:', Z.ravel(), 'refitted batch:', wrongZ.ravel())
```

如果应用真的希望消除每批共同偏移，例如测量仪器有已知且可估计的基线漂移，也可以设计相应校正。但它必须成为训练和测试都一致使用、且在预测时可获得的规则，并独立评价。不能因为逐批拟合让图变得熟悉，就假定它保留了目标信息；异常检测中整体偏移往往正是最重要信号。

<a id="unsup-2-37"></a>

### 8.3 新坐标系不能直接喂旧模型

两个独立拟合的 PCA 可能符号翻转、轴旋转或尺度改变，因此即使都输出两列，也不表示列的语义一致。旧分类器权重是针对旧坐标学得的，新的坐标必须按已知变换对齐或重新训练完整模型。对非线性布局，甚至可能不存在一个全局线性对齐能恢复对应关系。输出维度相同只是形状兼容，不是统计语义兼容。

版本更新应保存旧变换，使用共同回放样本检查坐标变化及下游结果，并说明旧簇或决策阈值如何迁移。若研究只比较可视化，可以将布局分别展示并用共同样本标识追踪；若用于部署，就需要严格管理表示版本与模型版本的配对。这是使用降维结果时常见却容易遗漏的工程逻辑。

<a id="unsup-2-38"></a>

## 9. 方法比较：相同输出维数不表示相同任务

PCA 有明确线性变换、平方重构目标和训练外接口，适合压缩、去相关及某些下游建模；t-SNE 面向固定样本的局部布局，输出轴一般没有独立语义；UMAP 使用局部图与布局目标，某些实现支持近似训练外映射。选择不应由“哪个更先进”决定，而应由想保留的关系、可用预算和预测协议决定。

<a id="unsup-2-39"></a>

### 9.1 核方法与局部线性方法补充了哪些假设

核 PCA 在核所定义的特征空间中做线性主成分分析，在输入空间表现为非线性表示。核和带宽决定相似性，中心化需要在核矩阵中正确处理；低维坐标的逆映射通常不像普通 PCA 那样自然。不能仅因为名称有 PCA，就默认具有原始欧氏空间的重构最优性和简单逆变换。

Isomap 用近邻图上的最短路近似流形测地距离，再寻找低维距离表示；若图出现短路边，测地估计可能被严重扭曲，若图断开，距离又可能无法定义。局部线性嵌入关注邻域重构权重，但邻居选择与局部条件数会影响结果。每种方法都把结构假设变成可计算目标，研究应检查这些假设是否与数据采集机制相容。

<a id="unsup-2-40"></a>

### 9.2 随机投影提供另一种基线

随机投影不试图学习最大方差方向，而以较低成本近似保持有限点集的距离，适合某些大规模预处理。其距离保持需要输出维数随精度和点数变化，不表示任意压到二维都能保真。它还提醒我们：如果目的是保留距离，优化重构并非唯一道路；如果目的是展示局部关系，随机线性压缩也可能只是中间步骤。

比较时应匹配信息和预算。允许一个方法先在大量额外数据上预训练，而另一个只看当前样本，结果差异包含数据量与表示先验；一个方法运行很多种子后选最好，另一个只运行一次，也改变了优化机会。报告应把表示来源、参数搜索范围、运行预算和评价数据分开列清楚。

<a id="sec-6-1"></a>

<a id="unsup-2-41"></a>

### 9.3 低维邻近关系能说明什么

若一个邻域在多个合理尺度、重采样和方法下都反复出现，它值得进一步调查。随后可以查看原始特征、来源、时间与外部结果，提出可反驳的机制假设，例如是否由某个设备固件造成。这样的证据链逐步增强结论，但每一步都不能跳过；图中稳定只是起点，不是语义真相的终点。

如果某个现象仅在很窄参数范围出现，也不必立即丢弃，它可能揭示微尺度结构或样本不足。应明确敏感性并设计补充采样，而不是只隐藏不一致布局。面对复杂数据，诚实报告哪些关系稳定、哪些尚不确定，比强行给出单一“最佳图”更有学习价值。

<a id="unsup-2-42"></a>

## 10. 深入研究：扰动、密度与不确定性

非线性布局的变化可以来自数据抽样、表示估计、近邻图近似和优化随机性。固定数据改种子主要检查优化；固定种子改样本主要检查样本支持；改变尺度和距离检查模型假设；改变近似搜索精度检查工程近似。把四类因素分开设计实验，才能知道不稳定意味着需要更多数据、不同表示还是更充分优化。

<a id="unsup-2-43"></a>

### 10.1 Bootstrap 与共同样本评价

重采样后需要按稳定标识比较共同样本或在固定锚点集合上评价。Bootstrap 含重复观测，会影响局部密度和近邻并列，不能把它当作没有改变权重的普通子样本。若只是研究结构稳定，可以采用无放回子采样并报告比例；若用重采样估计统计不确定性，则要说明估计对象与抽样机制，不能机械套置信区间。

对 PCA，可比较子空间投影与载荷区间；对邻域方法，可比较每点邻居保留频率和桥接关系；对具体小岛，可比较其成员支持及来源变化。一个整图平均分可能掩盖少数群体的不稳定，应同时报告群体级和边界级结果。它们不一定形成单个排序，但更能揭示模型何时可用。

<a id="unsup-2-44"></a>

### 10.2 密度、采样比例与视觉面积

设一个稀少但紧密的群体在均匀抽样中几乎看不见，研究者为方便展示将其过采样。此时图可能清楚展示结构，但点数和面积不能继续代表真实总体概率。局部自适应算法还会重新调整邻域尺度，进一步打破面积与密度的简单关系。展示中应标明是否加权抽样，并单独报告原总体支持量。

如果科学问题本身关心密度，应使用具有明确密度定义的估计方法，在原空间或受控表示中评价；不能用二维图上肉眼数点替代。即使在二维布局上计算核密度，也只是布局坐标的密度，坐标变换的体积变化没有自动校正。可视化与密度估计共享散点形式，不意味着它们回答同一个统计问题。

<a id="unsup-2-45"></a>

### 10.3 不确定性不等于画一条误差棒

一个点的嵌入坐标在不同布局中可能整体旋转，因此直接对未对齐坐标求均值和方差没有意义。对齐后仍应说明允许何种变换及其损失；某些局部关系更适合用邻居出现频率表达。对群体结论，可以给出在多少预先规定设置中仍观察到同一成员关系，而不是给每个点伪造一个绝对位置的置信椭圆。

研究应使不确定性表达匹配主张。若主张是两群可区分，就检查原空间判别与边界；若主张是存在连续轨迹，就检查邻接路径与时间证据；若主张是某变量随嵌入变化，就避免用已经用于构图的同一变量循环验证。每个主张都需要比图形直觉更明确的证据对象。

<a id="unsup-2-46"></a>

### 10.4 如何阅读本章的实测数值

本机运行实验三时，PCA 的五邻居信任度约为零点九三三，邻居重叠为零点四；同一数据、指定种子的 t-SNE 对应约为零点九七零一与零点六二二二。这里可以得出的具体结论是：在该输入欧氏几何和这组参数下，后者更好保留了所评价的局部关系。不能推出它在其他数据、更大邻域、全局距离或下游任务上必然更好。其他版本与平台的小幅变化也不影响恒等式和范围断言的核验目的。

实验一保留方差比例为一百除以一百零一，重构总误差为四；实验二的训练白化协方差为单位阵，偏移测试批次的均值范数明显非零；实验四固定表示得到大幅偏移坐标，而逐批重拟合将其重新放到原点附近。这些事实分别核验数学目标、尺度规则和拟合边界，不是四次独立的算法排名。能够将每个输出对应到一个明确主张，才说明实验真正帮助了理解。

复现时先运行原样代码，核对断言，再改变一个因素。例如只改保留维数观察尾部误差，只改测试偏移观察固定变换，只改邻域尺度观察局部指标。若同时改数据、距离和优化参数，即使图变化明显，也难以解释是哪一步导致变化。记录这种单因素对照及其限制，是从教材实验走向可审查研究的第一步。

## 11. 十六道进阶练习与详解

<a id="unsup-2-48"></a>

### 11.1 保留百分之九十九方差为何仍不能分类

**题目。** 实验一中一维 PCA 保留超过百分之九十九的方差，标签却不可区分，这与最优性矛盾吗？

**解析。** 不矛盾。最优性针对训练输入的欧氏平方重构，标签并未参与目标。保留坐标对成对样本相同，而标签相反，任何只看该坐标的确定性分类器都无法同时正确区分它们。应在完整训练流程选择维数并比较不降维基线；若有监督目标，可研究监督降维，但此时使用信息已经不同，不应继续称作仅按输入方差选择。

<a id="unsup-2-49"></a>

### 11.2 为什么要保存训练均值

**题目。** 新批次到来后用新批均值中心化，再乘旧主成分，会有什么影响？

**解析。** 每批坐标原点不同，同一记录会因同行样本改变而改变坐标。新批整体偏移可能被删除，下游模型面对的表示不再是训练时定义的映射。实验二与实验四用偏移例子直接展示这种差异。若应用有明确的批次基线校正规则，应将其纳入训练和评价，并确认预测时可获得需要的信息，不能临时重新拟合后沿用旧解释。

<a id="unsup-2-50"></a>

### 11.3 载荷整体变负是否说明运行失败

**题目。** 两次 PCA 主成分向量互为相反数，如何核验是否同一个解？

**解析。** 同时翻转方向和对应得分不会改变重构，投影矩阵 $`vv^T`$ 完全不变。比较投影、重构和解释方差即可；有重根时还应比较整个子空间。为展示可以规定最大绝对载荷为正等符号约定，但这是命名规则，不增加统计可识别性。若下游模型没有一起调整，单独翻转输入坐标仍会改变预测，因此保存变换对象很重要。

<a id="unsup-2-51"></a>

### 11.4 白化为什么可能放大噪声

**题目。** 一个方向的方差非常小，白化后为什么不一定更好？

**解析。** 白化乘以方差平方根的倒数，小方向的测量误差与参数估计误差也被放大。若该方向主要是噪声，下游距离会赋予它过高权重。可以截断或正则化，但需在训练内选择强度并评价用途。训练协方差等于单位阵只说明计算实现了缩放目标，不是泛化和任务效用的证明。

<a id="unsup-2-52"></a>

### 11.5 手算重构误差的分母

**题目。** 某中心化矩阵舍弃奇异值为三和一，最小误差是多少？

**解析。** 总平方误差为 $`3^2+1^2=10`$。若有五个样本，每样本平方误差为二；若每样本四维，逐元素均方误差为零点五。若报告解释方差，样本协方差分母是四，对应舍弃方差总量为二点五。数值不同是定义不同，不能将总 SSE、每样本误差和逐元素 MSE 混称同一指标，也不能跨表直接比较。

<a id="unsup-2-53"></a>

### 11.6 困惑度等于精确近邻数吗

**题目。** 困惑度设为三十，是否恰好只有三十个点具有非零相似度？

**解析。** 不等于。困惑度由分布熵指数化而来，描述有效邻居数量；高斯权重在精确算术下通常对许多点都为正，近似实现可能截断候选。均匀支持三十点只是一个特殊例子。应将它理解为邻域尺度，并检查样本量与合理范围，不能直接把它替代另一个算法的硬近邻参数后声称目标一致。

<a id="unsup-2-54"></a>

### 11.7 KL 目标方向为什么重要

**题目。** 将 $`\mathrm{KL}(P\Vert Q)`$ 改为 $`\mathrm{KL}(Q\Vert P)`$ 是否只是符号改写？

**解析。** 两者对误差加权不同，前者以高维概率为权重，后者以低维概率为权重。若高维强近邻在低维被放远，前者会因该对较大权重而明显惩罚；交换方向将改变优化偏好。二者还都受归一化耦合，不能把每个点对孤立分析后给过度简单结论。应从完整目标推导梯度与误差，而不是仅凭名称相似。

<a id="unsup-2-55"></a>

### 11.8 图中两个岛的距离能量化语义差异吗

**题目。** 二维两岛距离为另一对的两倍，能否说语义差异两倍？

**解析。** 一般不能。局部概率或图目标没有统一保留全局距离比例，其他点的排斥、初始布局和局部尺度都能改变岛间安排。若研究关心语义距离，应先定义可检验的度量，在原空间或有明确保真保证的表示中计算，并核对相关外部证据。二维位置可以提示需要比较的对象，不能自动赋予比率尺度的意义。

<a id="unsup-2-56"></a>

### 11.9 信任度高是否表示所有近邻都保住

**题目。** 某图信任度接近一，是否可以停止检查邻居召回？

**解析。** 不可以。信任度重点惩罚低维近邻中的原空间远点侵入，对原空间近邻被丢失的评价不完全相同。应结合连续性或邻居重叠，并观察多个有意义的邻域尺度。总体平均还可能掩盖小群体或边界区域失败，需要分层检查。高分也只相对于指定输入距离，输入表示错误时，忠实保留错误几何仍可能得到高分。

<a id="unsup-2-57"></a>

### 11.10 所有布局旋转后不同如何比较

**题目。** 两次 t-SNE 看起来方向完全不同，是否足以说明结构不稳定？

**解析。** 先检查是否只是平移、旋转或镜像等任意坐标变化，再按研究目标比较邻域和成员。对齐能去除一部分坐标自由度，但不能替代局部关系检查。若重要邻居保持而全局岛位置变化，应报告局部稳定、全局布局敏感；若原来相邻的样本频繁替换，则是不同类型的不稳定。结论应与所比较的结构层次一致。

<a id="unsup-2-58"></a>

### 11.11 在全数据拟合 PCA 但不看标签算泄漏吗

**题目。** 测试标签完全未使用，为什么归纳评价仍可能有问题？

**解析。** 测试输入影响均值和方向，训练过程获得了未来样本的分布信息。若协议允许看见全部未标注测试输入，这是传导式任务，可以研究；若承诺评价全新未知输入，就不符合信息边界。解决方法是将拟合步骤置于训练折内，而不只是删除标签列。是否合理取决于实际任务定义，不能用“无监督”自动豁免数据边界。

<a id="unsup-2-59"></a>

### 11.12 用标签挑最好看的图后还能叫独立发现吗

**题目。** 看颜色效果反复修改参数，最终图很分离，可以证明无监督方法发现标签结构吗？

**解析。** 标签参与选择，即使目标公式未使用标签，整体流程也已受到监督。可将结果作为探索，并记录参数范围；若要确认结构，需要固定规则后在独立样本或外部证据上检验。只展示最后一张会隐藏选择自由度。应明确哪些标签仅用于一次事后评价，哪些用于反复开发，二者在结论中的证据强度不同。

<a id="unsup-2-60"></a>

### 11.13 低维坐标可逆是否代表距离不变

**题目。** 全维白化可逆，为什么 k-means 结果仍可能变化？

**解析。** 可逆只表示信息理论上可恢复，不表示欧氏几何保留。白化按方向不同缩放，相当于改用一种马氏距离，因此最近关系、中心分配与目标都可能改变。正交旋转保留欧氏距离，非均匀缩放通常不保留。比较表示时应同时问是否丢信息、是否改变距离和下游模型是否对该变换不变，这三个问题不能合并。

<a id="unsup-2-61"></a>

### 11.14 为什么新旧数据合并重跑不是固定映射

**题目。** 每次把所有旧点和新点合并做 t-SNE，再用旧分类器，哪里缺少论证？

**解析。** 重拟合改变概率、归一化和优化布局，旧点坐标可能移动，旧分类器所依赖的轴也随之变化。维数相同不能保证语义一致。应使用有明确新样本变换的模型、建立并评价额外映射，或随表示重训整个下游流程。若只是动态探索图，可以允许变化，但要按样本标识比较，不应宣称沿用了固定预测系统。

<a id="sec-7-1"></a>

<a id="unsup-2-62"></a>

### 11.15 边界追问：二维小岛是否证明原空间分离

**题目。** 改变邻居数后小岛合并，应保留更漂亮的一张吗？

**解析。** 应报告敏感性并回原空间检查。小邻域可能断开连续结构，大邻域也可能跨越真实稀疏边界；需要原始近邻、桥接样本和外部机制判断。选择最符合期望的图不能解决两种解释。可预先固定若干参数范围，记录结构主张在哪些设置存在，并设计新增采样检验边界，保留探索价值同时避免过度确定。

<a id="unsup-2-63"></a>

### 11.16 如何设计一个有说服力的失败分析

**题目。** 某方法平均信任度很好，但少数正常群体被压到大群体边缘，下一步是什么？

**解析。** 先按群体检查邻居召回、来源和抽样支持，判断问题来自表示、图连接还是优化。用精确近邻子集比较近似搜索，改变合理邻域尺度，并检查原始特征是否确实支持区分。若群体标签用于开发，应在独立数据再验证。不要仅调整颜色、点大小或选择更好看的种子，因为这些并未改善被研究的邻域错误。

<a id="unsup-2-64"></a>

## 12. 一份可交付的降维研究记录

最终记录应先给用途与信息边界，再给输入总体、表示、算法、参数搜索和评价对象。对于 PCA，报告训练均值与尺度规则、保留维数、累计方差、训练外重构或下游效果，并说明载荷解释的不确定性。对于布局方法，报告距离、邻域尺度、种子范围、优化设置、邻域指标及原样本核查，明确图中哪些关系被确认、哪些只用于提出假设。

展示应配上能够检验结论的样本，而不只是给每个岛一个名字。例如提出“某条轨迹对应设备老化”时，应查看设备时间顺序、维护记录和原特征变化，排除批次或传感器版本。提出“两组有不同响应”时，应在未用于挑图的数据上比较响应及混杂因素。降维图可以引导这些问题，却不能替代所需证据。

研究还应保留失败边界：新来源样本是否远离训练总体、参数变化是否导致岛消失、小群体是否缺乏支持、某些方向是否由极端值主导。把这些信息写进最终正文比无限增加漂亮图更有价值。读者应能据此判断何时复用方法，何时需要重新采样、改变表示或放弃离散群体的解释。

进一步的进阶课题包括子空间估计的扰动理论、随机矩阵下维数选择、密度保持嵌入、可学习的参数化映射，以及在特定下游任务中选择表示。每个课题都可以沿同一逻辑推进：先写目标与假设，再给可检查的数学性质，随后用反例区分不成立的推论，最后以独立实验检验实际用途。这样降维学习才能从“会调用一个画图函数”发展为理解信息在何处被保留、改变和丢弃。
