# 模型评估

把评估对象、独立单位、概率、成本和信息时点连成完整协议，推导指标与区间究竟支持什么结论。

**先修知识：** 机器学习基础；统计基础。

## 学习顺序与覆盖范围

第 1 章从计数和总体风险推导分类、回归、排序与概率指标；第 2 章确定实体、时间、拟合与选择边界；第 3 章将概率校准接到成本、阈值和容量决策；第 4 章处理不确定性、漂移、延迟标签与报告。监督学习和模型评估可以交叉阅读，但调参前应先掌握划分和指标。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 排序比较与持续监控的推导入口

在理解 AUC 的成对排序含义后，继续读[U 统计量方差与配对比较](01-分类回归与概率指标.md#auc-ustat-variance)，复算比较矩阵、行列均值和面积差。进入第 4 章的持续监控前，可先读[随时有效检验的完整构造](../../Mathematics/Statistics/02-假设检验相关性与实验.md#sequential-likelihood-ratio)。前者按冻结模型与独立测试对象讨论抽样方差，后者按条件均值假设控制整个停止程序；实际评价协议应逐项核对相应条件。

## 如何完成本主题

完成各章后，先独立作答[综合练习：模型、校准器和阈值都看过测试集](04-不确定性漂移与评估报告.md#sec-8-1)，再对照逐步解析与验收要求。

完成后，应能从同一组预测手算不同指标，解释平均轴与目标总体；画出训练、选择、校准、阈值和测试的信息边界；按正确独立单位对配对差值构造区间；面对漂移说明哪些量已观察、哪些假设才允许识别。最终报告要能追溯到样本角色、模型版本、成本和可用标签。
