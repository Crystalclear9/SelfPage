# 第 4 章 不确定性漂移与评估报告

[主题目录](README.md) · [分类目录](../README.md) · [总目录](../../README.md) · [上一章](03-阈值选择概率校准与成本决策.md)

前面三章分别确定指标、评价协议和行动规则。本章继续追问：一个提升结论有多稳定，区间覆盖了哪些随机性，未来分布改变后还能使用多少旧证据，监控告警究竟能证明什么？这些问题不能靠给分数多保留几位小数解决，需要把估计对象、信息时点、相关单位与选择过程共同写入分析。

本章代码只使用内存中的人工或合成数据。每个实验都围绕一个可以独立核对的识别边界或统计关系，不需要联网下载数据，也无需额外图像文件。区间并不替代样本代表性，漂移检验也不替代实际性能；以下推导始终说明结论依赖的条件。

本章先区分“模型变了”“评价样本变了”和“部署总体变了”，再为各自选择区间、重采样或迁移假设。组内率、组成权重与总体风险图是入口：先看平均数由什么组成，才知道需要为哪一个随机对象补证据。随后学习支持覆盖、标签成熟与连续查看如何限制结论，最后把可识别内容写入实际的验收与更新流程。

## 1. 先说明随机对象，再讨论不确定性

<a id="eval-4-detail-2"></a>
### 1.1 固定模型风险与学习规则风险

给定已经训练完成的模型 $`f`$，目标总体为 $`P`$，损失为 $`L`$，风险是 $`R_P(f)=E_P[L(f(X),Y)]`$。有限测试数据得到的是它的估计。固定模型时，重复抽取测试样本会产生估计波动；即使模型完全确定、程序每次运行都相同，有限评价数据仍不能精确给出总体风险。

若把训练集 $`D`$、随机种子 $`U`$ 以及整个选择流程都视为随机，模型成为 $`A(D,U)`$，另一个目标是 $`E_{D,U}[R_P(A(D,U))]`$。它描述学习规则在重复训练中的平均表现，与当前交付的某一份模型风险不同。多种子主要改变 $`U`$，不能覆盖训练样本变化；固定数据的测试 bootstrap 主要改变评价样本，也不能替代重新执行学习规则。

当实际关心下一季度时，总体还可能从 $`P`$ 变成 $`Q`$。这不是简单增加一个独立随机种子。若没有关于 $`Q`$ 的假设，过去测试数据不能为任意未来变化提供有限宽度的保证。报告应分别陈述当前总体上的估计、完整训练流程的稳定性、以及跨时间和来源的适用证据，不能用一个区间把所有问题混在一起。

<a id="sec-1-1"></a>
<a id="eval-4-detail-3"></a>
### 1.2 数据噪声、参数未知与算法随机性

回归中的条件波动 $`\mathrm{Var}(Y\mid X)`$ 常称为数据或偶然不确定性；模型参数因有限信息而不确定，常称为认知不确定性；训练初始化、随机小批次和搜索策略还引入算法随机性。这些词在不同文献中用法并不完全一致，最可靠的做法是直接指出被重复抽取或被积分的对象。

重复训练得到的分数标准差并不直接等于参数后验标准差。多个优化终点的出现频率也不是贝叶斯后验权重。一个概率模型输出的预测区间可以整合指定模型内的噪声与参数未知，却通常没有整合模型错设、选择性采样或制度变化。名称相近不表示统计对象相同，应以生成过程和计算公式为准。

分类概率也不是一个不确定性总表。预测接近二分之一可能来自真实类别重叠，也可能来自信息缺失或模型能力不足；接近零一则可能是正确证据，也可能是分布外输入上的错误自信。要区分原因，需要补充数据、模型比较或结构假设，单个输出数值本身不足以完成识别。

<a id="eval-4-detail-4"></a>
### 1.3 用全方差解释分层波动

设 $`\hat R`$ 是随机训练模型在随机测试集上的平均损失。给定训练结果后，仍有测试抽样方差；对训练过程取外层平均，得到

```math
\begin{aligned}
&\mathrm{Var}(\hat R)=E_{D,U}[\mathrm{Var}(\hat R\mid D,U)]\\
&\quad +\mathrm{Var}_{D,U}(E[\hat R\mid D,U]).
\end{aligned}
```

第一项是固定训练结果后的评价波动，第二项是学习结果变化。这个分解是描述层次的工具，不代表一次数据就能无偏分开估计每一项。若所有模型共享同一份测试集，各模型分数还存在共同测试噪声，不能把种子间方差直接与某个测试方差相加而不考虑协方差。

更完整的实验可以在多个独立训练样本上各跑多个种子，再使用共同的独立评价对象，形成分层设计。实际成本较高时，应诚实报告只研究了哪一层。固定数据多种子得出稳定，只能支持对这些随机优化设置不敏感；它不能证明换一批用户、医院或月份也稳定。

### 图解：总体与子群的监测：改善的均值也可能隐藏恶化

![固定目标组成后，组内风险和汇总风险的比较。](images/04-group-errors-and-pooled-monitoring.webp)

[打开原图放大](images/04-group-errors-and-pooled-monitoring.webp)

图 (a) 中，A 组错误率由 $`0.08`$ 降到 $`0.07`$，B 组由 $`0.12`$ 升到 $`0.28`$。令共同目标总体中的 A 组权重为 $`w`$，旧风险为 $`0.12-0.04w`$，新风险为 $`0.28-0.21w`$。图 (b) 列出两个权重下的汇总对照。

两组各占一半时，总体从 $`0.10`$ 升到 $`0.175`$；A 占百分之九十五时，总体从 $`0.082`$ 略降到 $`0.0805`$。令新旧两式相等，得 $`w=\frac{16}{17}\approx94.12\%`$；只有在它右侧，总体加权变化才为负。这个交点让“少数群体恶化被总体掩盖”的条件可以直接核算，。

再按 A 组占百分之九十五计算两千次请求，A 有一千九百次、B 有一百次，按给定风险计算期望错误人数。A 从 $`1900\times0.08=152`$ 降至 $`1900\times0.07=133`$，少十九次；B 从 $`100\times0.12=12`$ 升至 $`100\times0.28=28`$，多十六次；总数从一百六十四略降为一百六十一。B 组错误增加与总体错误减少可以同时发生。这是给定总体率下的期望核算，不是新采集了两千条记录，也不提供三次期望差的统计显著性保证。

总体改善不能消除 B 组恶化的事实，群体指标也不能代替实际总体负担。两者必须同时附上权重、支持数与标签成熟情况；本图本身不识别漂移类型，也不证明因果歧视。

## 2. 区间、重采样与配对比较

<a id="eval-4-detail-6"></a>
### 2.1 置信区间、预测区间与跨运行范围

置信区间按重复抽样覆盖某个固定目标；预测区间覆盖未来随机结果；贝叶斯可信区间在指定模型和先验下表达参数后验质量。跨种子的最小最大值或标准差则是实验分布描述，若没有相应抽样设计，不能自动命名为置信区间。给出一个百分之九十五标签之前，应说明事件与重复机制。

例如固定分类器测试准确率的二项区间，需要测试个体可近似视为独立、同分布且预测规则已冻结。它不包含测试之前大量搜索造成的选择乐观性。如果准确率本身参与挑选模型，再套一个常规二项区间，算出的窄度不恢复被消耗的独立性。区间方法解决的是给定设计下的抽样问题，不会自动修复设计缺陷。

没有观察到错误也不意味着总体错误率为零。独立二项抽样中，零错误时单侧上界可以由 $`(1-p)^n=\alpha`$ 求出，即 $`p=1-\alpha^{\frac{1}{n}}`$。当 $`n`$ 较大、$`\alpha=0.05`$ 时约为 $`\frac{3}{n}`$。这个关系直观展示了稀有失败的证据需求，同时也依赖独立代表性；一千条来自同一模板的副本不能当作一千次独立安全验证。

<a id="eval-4-detail-7"></a>
### 2.2 Bootstrap 需要重现真实独立单位

普通 bootstrap 从评价行有放回抽样，适用于行接近独立且目标统计足够规则等条件。若同一用户产生多条相关记录，逐行抽样会破坏相关结构，通常低估不确定性。可以按用户整组抽取，保留该用户所有记录；但随后如何平均，还要由目标是随机用户还是随机请求决定。

若用户记录数不同，先算每用户平均再平均，估计的是用户等权目标；把所有抽中记录合并平均，则更接近请求加权目标。这不是哪种 bootstrap 更高级，而是目标总体不同。整组抽取后因为样本行数不固定就强行截断到原行数，也可能破坏原设计。抽样单位、损失汇总单位和目标人群权重应该一起定义。

时间序列存在自相关时，可考虑时间块重采样、按独立事件段抽取或适合依赖结构的模型。块长度决定保留多少依赖，并引入偏差方差折中；任意选七天并不自动正确。严重非平稳数据不能仅靠块 bootstrap 变成可交换数据，未来总体的改变仍需单独研究。

<a id="eval-4-detail-8"></a>
### 2.3 比较两个模型时保留样本配对

两个模型在同一批用户上评价，应先形成每个独立单位的损失差，再对差值作分析。因为容易样本和困难样本往往同时影响两个模型，配对能够利用共同波动，通常比把两套独立区间相互比较更直接。两个区间重叠不证明差异为零，不重叠也不是所有场景的唯一显著性标准。

配对还要延伸到训练、划分与搜索协议。若一方用更多时间调参或不同数据清洗规则，最终差异包含整个流程的改变，而不是单一模型结构的纯效应。可以评价完整系统，但报告应如实命名。若希望识别某项改动贡献，应尽量只改变该项，并在多个合理独立单位上保持可比。

<a id="eval-4-detail-9"></a>
### 2.4 实验一：重复记录制造虚假的窄区间

设二十个用户，每人有五十条完全重复的损失差；十个用户为负一、十个为正一。真正独立信息只有二十个用户。逐行 bootstrap 把一千条记录当作独立，估计的波动会显著偏小。以下同时用解析标准差核对模拟，说明问题来自抽样单位，而不是某个区间算法的实现细节。

```python
import numpy as np

rng = np.random.default_rng(104)
user_delta = np.r_[np.full(10,-1.),np.full(10,1.)]
rows = np.repeat(user_delta,50)
B = 6000
row_mean = rows[rng.integers(0,len(rows),size=(B,len(rows)))].mean(1)
user_mean = user_delta[rng.integers(0,len(user_delta),size=(B,len(user_delta)))].mean(1)
expected_row_sd = rows.std(ddof=0)/np.sqrt(len(rows))
expected_user_sd = user_delta.std(ddof=0)/np.sqrt(len(user_delta))
assert abs(row_mean.std()-expected_row_sd)<0.003
assert abs(user_mean.std()-expected_user_sd)<0.015
assert user_mean.std()>6*row_mean.std()
assert np.isclose(expected_user_sd/expected_row_sd,np.sqrt(50))
print('row interval:',np.quantile(row_mean,[0.025,0.975]))
print('user interval:',np.quantile(user_mean,[0.025,0.975]))
```

这里每用户记录数相同，因此用户平均与请求平均在点估计上恰好一致；区间差异仍然很大。真实用户数少时，整组 bootstrap 自身也可能不稳定，应报告组数和敏感性。正确保留相关单位只解决其中一层问题，不会自动保证少样本区间覆盖率精确达到名义水平。

## 3. 从区间走向选择过程与证据范围

<a id="eval-4-detail-11"></a>
### 3.1 最佳模型的区间不能忽略如何被选中

若同时训练一百个候选并按同一测试集分数选最好，选中分数包含向上的抽样波动。只对选中的固定预测重采样，条件在已做选择之后，通常没有完整重现候选间竞争，因此不能代表整个选择过程的泛化不确定性。要评价规则，可以在外层独立数据上重做内部搜索；要评价某份冻结模型，可以另取未参与选择的数据。

搜索范围还包括人工作用：改标签定义、看错例后删样本、改变分组和重新挑指标。即使超参数列表只含一个模型，也可能有大量未记录选择。报告中将所有这些变化视为开发历史，说明最后一次冻结之前看过哪些信息，往往比增加一个复杂区间算法更重要。

<a id="eval-4-detail-12"></a>
### 3.2 多数据集结论与同一数据重复划分

在一个数据集上重复随机划分并不是获得多个独立任务。同一批样本反复出现，划分结果高度相关，不能把运行次数当成独立数据集数量缩小标准误。跨来源数据集提供更强的外部证据，但各任务也可能共享采集方式或预训练资源，仍需检查独立性与代表性。

若要声称一种方法普遍优于另一种方法，需要说明任务总体是什么、怎样抽取任务，以及不同任务之间如何加权。十个非常相似的文本子集不等于十个领域。可以报告每任务配对差异及总体汇总，同时保留异质性；单个平均值会掩盖某些条件下改进、另一些条件下退化。

<a id="eval-4-detail-13"></a>
### 3.3 实用差异与统计差异

大样本可能使极小差异显著，但收益未必覆盖计算成本、维护难度或额外误报。小样本下差异未显著，也不等于证明等效。若任务需要证明新系统不差于既定容忍边界，应预先定义非劣或等效范围、主要损失与置信要求，而不是看到零附近区间就宣称没有区别。

例如模型平均成本下降千分之一，但增加一倍服务延迟；是否有价值需要结合业务量、延迟代价和失败模式。报告应同时给绝对差异、相对差异、原始数量与相关成本。将统计不确定性与行动所需收益阈值连接起来，才能得到可执行结论。

## 4. 分布漂移的三种假设与可识别边界

<a id="eval-4-detail-15"></a>
### 4.1 先写出源域和目标域的联合分布

设开发数据来自 $`P(X,Y)`$，部署数据来自 $`Q(X,Y)`$。所谓漂移可以发生在输入边缘、类别比例、条件关系或标注机制。不同分解帮助提出不同假设，但这些名称并不是互斥的自然事件标签。同一个现实变化可能同时改变多个分布，不能仅凭输入直方图变化就唯一命名原因。

协变量漂移通常假设 $`P(Y\mid X)=Q(Y\mid X)`$，仅输入分布改变；标签漂移通常假设 $`P(X\mid Y)=Q(X\mid Y)`$，仅标签先验改变；概念漂移常指 $`P(Y\mid X)`$ 改变。后两种分解看似都涉及标签，却作了不同不变性假设。尤其纯标签漂移一般也会改变后验条件概率，不能把“概念改变”与“先验变化”当成完全不相交分类。

不变性是否合理需要领域机制和成熟标签证据。例如用户群体构成变化而每种用户行为规律稳定，协变量假设可能较有依据；检测人群阳性比例改变但类内检查分布稳定，标签漂移可能较适合。传感器单位变更、标签规则修改和产品干预则可能直接破坏这些假设。公式提供条件推理，不替代机制研究。

<a id="eval-4-detail-16"></a>
### 4.2 输入改变不必性能下降

固定模型风险可写为 $`R_Q(f)=E_{Q(X)}[r_Q(X)]`$，其中 $`r_Q(x)=E_Q[L(f(x),Y)\mid X=x]`$。若条件风险不变但新总体更多落在困难区域，整体性能会变差；若更多落在容易区域，性能可以改善；若各区域风险恰好相同，输入分布显著变化也不影响总体风险。

因此输入检验显著既不证明性能下降，也不直接说明应该重训。它表明某个被检测的分布特征与参考不同。后续应检查采集口径、覆盖范围、模型敏感区域及成熟指标。反过来，如果输入边缘完全不变，条件关系仍可能改变，性能也可能严重下降。无标签监测只能看到联合分布的一部分。

<a id="eval-4-detail-17"></a>
### 4.3 无标签条件下的不可识别性证明

取二元输入等概率为零或一，固定模型预测 $`f(x)=x`$。世界甲令标签恒等于输入，世界乙令标签恒等于输入的相反值。两个世界有完全相同的输入分布，也有完全相同的预测分布；但甲中准确率为一，乙中为零。任何只读取未标注输入和固定预测的算法，在两个世界看到的分布都相同，因此不可能总是判断哪一个世界正在发生。

这是信息不足，不是检测器还不够复杂。增加更高维的漂移分数或更大的未标注样本，仍然无法区分这两个构造。要估计实际性能，需要成熟标签，或加入可辩护的不变性、代理标签或额外反馈机制。由假设得到的估计应被命名为假设下估计，而不能包装成无条件观察事实。

<a id="eval-4-detail-18"></a>
### 4.4 实验二：输入完全相同，风险可以相反

下例同时构造两个不可区分的无标签世界，并构造输入改变但风险不变的情形。所有数据是有限精确表，因此没有随机显著性的争论。它直接检验监测信息能否识别性能，适合在设计监控方案前作为一个概念边界测试。

```python
import numpy as np

x = np.tile([0,1],500)
pred = x.copy()
y_good = x.copy()
y_bad = 1-x
assert np.array_equal(x,x.copy())
assert np.mean(pred==y_good)==1
assert np.mean(pred==y_bad)==0
source_p = np.array([0.5,0.5])
target_p = np.array([0.9,0.1])
conditional_error = np.array([0.2,0.2])
assert not np.allclose(source_p,target_p)
assert np.isclose(source_p@conditional_error,target_p@conditional_error)
print('same unlabeled input, accuracies:',
      np.mean(pred==y_good),np.mean(pred==y_bad))
print('changed input, unchanged risk:',target_p@conditional_error)
```

第一个反例说明没有无标签万能性能检测器，第二个反例说明分布检测和性能检测有不同目标。真实部署中通常无法直接知道条件风险，所以输入告警仍有价值；它用于发现需要调查的变化，而不是单独给出模型损失的结论。

## 5. 重要性加权：什么时候能够迁移风险

<a id="eval-4-detail-20"></a>
### 5.1 从换测度推导目标风险

在协变量漂移假设下，若目标输入分布对源输入分布绝对连续，可以定义 $`w(x)=\frac{q(x)}{p(x)}`$。此时

```math
R_Q(f)=E_P[w(X)L(f(X),Y)].
```

推导只是将积分中的 $`q(x)q(y\mid x)`$ 替换为 $`w(x)p(x)p(y\mid x)`$。因此必须同时满足条件分布不变和支持覆盖。若目标域出现源域概率为零的区域，密度比无法从源样本恢复该区域的损失；这不是把权重设大一点就能解决，而是没有对应标签证据。

支持不足时仍可给部分识别范围。令 $`S`$ 为源域支持覆盖的目标输入区域，目标域未覆盖质量为 $`\rho=Q(X\notin S)`$，且损失有界于 $`[0,M]`$。假设覆盖区内的目标条件风险可以按既定迁移条件识别，记 $`R_S=E_Q[L\mid X\in S]`$。全概率分解给出 $`R_Q=(1-\rho)R_S+\rho R_{S^c}`$，而未知项只知道属于 $`[0,M]`$，所以整体风险必在 $`[(1-\rho)R_S,(1-\rho)R_S+\rho M]`$ 内。这个范围把已经识别的部分和缺失信息分开，不需要假装支持外区域与支持内一样。

例如零一损失下，未覆盖比例为百分之二十，覆盖区风险为百分之十，则整体风险范围为百分之八至二十八。即使覆盖区有无限多源标签，范围宽度仍为二十个百分点，因为缺口是识别而非抽样。若 $`R_S`$ 本身只有有效区间 $`[a,b]`$，可将端点代入得到更宽的 $`[(1-\rho)a,(1-\rho)b+\rho M]`$；若 $`\rho`$ 也由样本估计，还需相应联合不确定性处理。

<a id="eval4-support-risk-band"></a>

**图解：识别区间与抽样置信区间的区别。**

![覆盖区贡献与支持外的两种风险极端确定整体可行范围。](images/04-support-coverage-and-risk-bounds.webp)

[打开原图放大](images/04-support-coverage-and-risk-bounds.webp)

图中的端点并不是“百分之九十五覆盖”的抽样区间：这里把覆盖比例和覆盖区条件风险暂当精确已知，因此剩余范围完全来自缺失区域的标签不可识别。把支持外的固定预测全配上正确标签得到下界，全部反对预测得到上界；这两种世界在现有源标签和目标无标签信息上完全相同。仅把覆盖区的估计置信区间缩窄，不会排除其中任何一个世界。

若任务要求整体风险不超过 $`0.15`$，当前上界 $`0.28`$ 便不能完成这个保证；点估计 $`0.08`$ 也不能被当作全体风险。可以选择仅对覆盖区服务并另报告覆盖率，或收集支持外标签。若通过额外证据把未知区风险限制到 $`[0.2,0.4]`$，整体范围才缩为

```math
\begin{aligned}
&[0.08+0.2\times0.2,\ 0.08+0.2\times0.4]\\
&\quad =[0.12,0.16]
\end{aligned}
```

新增约束的证据需要独立说明。这个“已识别贡献加未知质量乘损失范围”的计算也适用于有界业务成本，但不能直接用于没有已知上界的平方损失。

增加支持外标签或提出经验证的结构，才能有依据缩小这一部分范围。在零一损失且支持外标签关系不受额外约束的例子中，让该区域标签全部匹配或反对固定预测，便可达到两个端点，因此范围不能仅凭已有信息进一步收紧。

如果权重已知，样本均值 $`n^{-1}\sum_iw_iL_i`$ 在可积条件下无偏估计目标风险。自归一化形式 $`\frac{\sum_iw_iL_i}{\sum_iw_i}`$ 在有限样本通常有偏，但在相应条件下可以一致，且对整体尺度误差更稳定。二者不应混称为同一个无偏估计器。分析区间时也要对应实际使用的形式。

<a id="eval-4-detail-21"></a>
### 5.2 权重估计、支持不足和样本有效量

权重常通过密度估计或源目标域分类器估计。若域标签记为 $`D`$，由贝叶斯公式可把 $`\frac{q(x)}{p(x)}`$ 写成域后验赔率乘抽样先验比。域样本被人为平衡时，不能忘记该先验比；域分类准确率很高往往意味着两域易分，也可能意味着支持重叠差，风险估计方差很大。

常见诊断量为 $`\mathrm{ESS}=\frac{(\sum_iw_i)^2}{\sum_iw_i^2}`$。权重相同时等于样本数，一个权重支配时接近一。它度量权重集中带来的信息损失，不是任意相关数据下真实有效独立样本数，也不是置信覆盖保证。若样本本身成组相关，仍需同时处理组结构。

应记录最大权重、权重分位数、各群体支持和目标未知区域。ESS 很大也不证明条件不变，权重估计准确也不证明标签机制稳定。加权只是建立在一个不变性上的换测度工具。若基础假设不成立，更多源样本会更精确地估计错误目标。

<a id="eval-4-detail-22"></a>
### 5.3 截断权重的偏差方差折中

将权重截成 $`\min(w,c)`$ 会限制极端权重，但一般改变期望，且不保证加权损失估计量的方差降低；这取决于权重与损失的联合分布。对于非负有界损失，未归一截断会丢掉高权重区域的一部分贡献；若再归一，偏差方向还取决于这些区域的相对损失。截断并不是无需说明的数值修复，应报告阈值、未截断诊断和敏感性。

若目标风险恰好主要来自源域罕见的困难区域，截断可能给出非常稳定却明显偏低的估计。合理做法包括收集目标标签、缩小结论覆盖范围、改进采样或明确使用保守界，而不是只选择使区间最窄的截断值。判断方法应围绕偏差来源与行动代价，不能把低方差等同于高可信。

<a id="eval-4-detail-23"></a>
### 5.4 实验三：精确加权、ESS 与支持失败

两个输入区域在源域的比例为九比一，目标域为一比一，条件错误率分别为零点一与零点九。未加权源风险为零点一八，目标风险为零点五。使用精确权重可以恢复目标风险；截断稀有区域权重会低估这一区域贡献。接着人为删去罕见区域，展示没有支持时不能凭剩余样本推断目标风险。

```python
import numpy as np

source_p = np.array([0.9,0.1])
target_p = np.array([0.5,0.5])
loss = np.array([0.1,0.9])
x = np.r_[np.zeros(900,dtype=int),np.ones(100,dtype=int)]
w = (target_p/source_p)[x]
l = loss[x]
source_risk = l.mean()
target_risk = target_p@loss
weighted = np.mean(w*l)
self_normalized = np.sum(w*l)/np.sum(w)
ess = w.sum()**2/np.sum(w*w)
clipped = np.minimum(w,2)
clipped_risk = np.sum(clipped*l)/clipped.sum()
assert np.isclose(source_risk,0.18)
assert np.isclose(target_risk,0.5)
assert np.isclose(weighted,target_risk)
assert np.isclose(self_normalized,target_risk)
assert np.isclose(ess,360)
assert clipped_risk<target_risk
unsupported_source = np.array([1.,0.])
assert np.any((target_p>0)&(unsupported_source==0))
print('source/target/weighted:',source_risk,target_risk,weighted)
print('ESS:',ess,'clipped normalized risk:',clipped_risk)
```

这里计数特意恰好代表源比例，所以加权结果精确相等；一般随机样本仍有波动。代码中的损失是区域条件期望，不是独立伯努利模拟，目的是隔离换测度代数。支持失败断言只是指出不可识别区域，不能把它当作一个已经修复缺失标签的算法。

```math
0.8\times0.5\times0.1+0.2\times3\times0.5=0.34,
```

与直接按目标域平均一致。图中保持了条件分布和支持覆盖；真实任务必须单独验证这些前提。大权重会放大稀少区域的抽样波动，源域完全没有某个目标区域时更不能靠无限权重补出标签。加权的识别条件与交叉验证背景可参考 Sugiyama、Krauledat 与 Müller 原论文。

## 6. 标签漂移与条件变化的诊断

<a id="eval-4-detail-25"></a>
### 6.1 通过固定预测器估计目标先验

若 $`P(X\mid Y)=Q(X\mid Y)`$，固定预测器 $`g`$ 的类条件预测分布也不变。定义矩阵 $`C_{ij}=P(g(X)=i\mid Y=j)`$，目标预测比例为 $`v_i=Q(g(X)=i)`$，则 $`v=C\pi_Q`$。若矩阵有足够列秩、类标签支持存在，并且不变性成立，可由目标未标注预测和源有标签估计目标先验。

这不是无标签识别任意漂移的反例，而是加入了强结构条件。若两列相同，预测器无法区分两个类的混合比例；若矩阵接近奇异，小估计误差会导致大比例误差。有限样本下直接求逆还可能得到负概率，需约束估计并报告不确定性。得到一个非负解也不能证明标签漂移假设本身正确。

**二分类可以直接看见可识别条件和误差放大率。** 令 $`a=P(g(X)=1\mid Y=1)`$ 为检出率、$`b=P(g(X)=1\mid Y=0)`$ 为误报率，目标正类比例为 $`\pi`$，目标预测正比例为 $`v`$。把矩阵式的一行展开即可得到

```math
\begin{aligned}
v &=a\pi+b(1-\pi)=b+(a-b)\pi,\\[6pt]
\pi &=\frac{v-b}{a-b}\quad(a\ne b).
\end{aligned}
```

例如源域给出 $`a=0.9,b=0.2`$，目标未标注样本的预测正比例为 $`v=0.41`$，则在标签漂移成立时推得 $`\pi=0.3`$。这里用的是按真实类别条件化的混淆率，不能误用 $`P(Y=1\mid g(X)=1)`$ 等预测值；后者本身会随先验变化。若只有 $`v`$ 含有小扰动而 $`a,b`$ 暂视为已知，比例误差满足精确关系 $`\Delta\pi=\frac{\Delta v}{(a-b)}`$，所以分类器的区分度直接决定逆问题的稳定性。

若 $`a=0.51,b=0.49`$，同样的 $`\Delta v=0.01`$ 会放大为 $`\Delta\pi=0.5`$；即使目标预测比例看起来估计得很准，类别比例也可能极不稳定。在 $`a=b`$ 时，$`v=b`$ 与 $`\pi`$ 无关，目标样本无限多也无法由这个预测器恢复先验。把源域估计误差也计入，一阶微分为

```math
d\pi=\frac{dv-\pi\,da-(1-\pi)\,db}{a-b}.
```

因此应同时传播源域类条件率和目标预测比例的不确定性，不能只 bootstrap 目标样本便声称覆盖完整。若样本来自相关实体，重采样单位还应保持其结构。

![(a) 类条件混合。(b) 分类器区分度影响先验反解的稳定性。](images/04-label-shift-mixing-and-inverse-error.webp)

[打开原图放大](images/04-label-shift-mixing-and-inverse-error.webp)

图 (a) 先在真实负类、真实正类内部读取固定分类器的判正率 $`b=0.2`$ 和 $`a=0.9`$。用目标真实正类比例 $`\pi`$ 作权重，得到可观测的预测正比例 $`v=0.2+0.7\pi`$。例如 $`\pi=0.3`$ 给出 $`v=0.41`$。若另一个分类器有 $`a=b=0.5`$，所有先验都产生同一个观测值，无法反解。

图 (b) 比较两个不同分类器，都把真实先验暂设为 $`0.5`$，并让各自的观测比例受到相同大小的扰动 $`\pm0.01`$。第一行使用图 (a) 的 $`a-b=0.7`$，对应 $`v=0.55\pm0.01`$，反解后是 $`\pi=0.5\pm\frac{1}{70}`$；第二行使用 $`a=0.51,b=0.49`$，对应 $`v=0.5\pm0.01`$，反解范围恰好扩为 $`[0,1]`$。这两个范围来自对指定扰动的代数传播，尚未计入源域 $`a,b`$ 的估计误差。它说明对可辨识性和稳定性必须分别检查：非零的 $`a-b`$ 让解存在，却不保证有限样本下足够精确。标签漂移与可逆混淆矩阵的原始论述见 Lipton、Wang 与 Smola 的论文。

另一个简单诊断是：在精确标签漂移模型下，$`v`$ 必须落在 $`a,b`$ 之间，因为它是两者的凸组合。若 $`a=0.9,b=0.2`$ 却观测到 $`v=0.95`$，直接反解得到 $`\pi>1`$；它提示抽样噪声、估计误差或不变性失配，不能简单剪成一以后宣称假设已验证。反过来，$`v`$ 落在区间内只说明这条混合方程可行，仍不足以证明完整类条件输入分布保持不变。约束优化能保证输出合法，却不能补出缺失的识别假设。

<a id="eval-4-detail-26"></a>
### 6.2 条件误差变化与标签质量变化

成熟标签到达后，可以比较关键区域的条件错误、校准与成本，尝试区分组成变化和关系改变。但区域切分过细会造成稀疏和多重比较，过粗又可能掩盖变化；应结合任务预先定义少数主要切片，并把探索发现留待后续数据确认。某个区域无样本时应报告无证据，不能填零错误率。

观测标签也可能改变。人工标注指南更新、结果记录延迟、漏报或业务干预会使评价标签与原目标不一致。看见指标退化时，先核查标签定义和成熟口径，再判断模型是否失效。若只对被模型选中的对象收集标签，结果还存在选择性观察，不能把已标注子集直接代表全体部署人群。

<a id="eval-4-detail-27"></a>
### 6.3 漂移修复方案需要匹配原因

采集单位错误应修复数据链路；纯先验变化在合理条件下可修正类别后验；条件关系变化可能需要新标签和重新建模；支持外人群则可能需要拒答、人工接管或扩大采样。任何自动重训流程都应先确定训练数据合法且目标未被悄然改变，否则会把故障快速学习进新模型。

重训后仍需独立回归集、近期代表性评价和预先规定的替换准则。若用告警窗口同时选择新模型并公布改进，那一窗口已经承担开发角色，应继续收集确认数据。监测、诊断、修复、验收是不同证据步骤；一个漂移分数不能独自完成整个闭环。

## 7. 标签成熟与按预测批次重建时间

<a id="sec-2-1"></a>
<a id="eval-4-detail-29"></a>
### 7.1 事件时点、预测时点与记录可得时点

时间评价至少需要区分事件发生、特征可得、预测生成、目标观察窗结束、标签到达和模型更新。一个事件发生在预测之前，不表示其补录字段当时已经可用；一个结果今天到达，也不表示它属于今天生成的预测。只有保留这些时点，才能重放当时信息，避免用今天完整数据库美化过去表现。

若目标是预测未来七天是否出现某事件，即使没有事件，负标签也要等七天观察窗完整结束才能确定。正事件可能更早到达，但把已到达正类与尚未成熟的潜在负类混在一起，会高估发生比例并扭曲召回、精确率和校准。应按预测批次定义统一成熟规则，或建立明确的删失/到达模型，而不是把未收到结果一律当负类。

<a id="deep-dive-2"></a>
<a id="eval-4-detail-30"></a>
### 7.2 滚动评价需要模拟实际更新日历

扩展窗口累计全部可用历史，滚动窗口只保留近期，分别对应稳定积累与适应近期变化的偏好。每个更新日只允许使用那时已经可得且按规则成熟的标签，所有预处理和校准也遵守同一信息边界；然后在之后的预测窗评价。标签虽属于较早事件，若当时尚未到达，仍不能用于这次训练。

间隔或禁运区间用于处理重叠标签窗和相关事件，但长度应依据目标定义和部署信息流确定。简单留七天不一定能隔离长期用户依赖，也不一定需要排除全部早期合法观察。将时点规则写成断言，比仅画一条训练在左、测试在右的示意图更可靠。

固定模型老化与持续更新系统是两个不同对象。前者冻结参数，观察未来窗口；后者按预设日历反复重训，评价完整更新规则。后者某个新模型表现变差，可能来自新训练样本、优化波动、特征版本或总体变化，需要日志才能区分。不能将两条曲线混合后把均值称为单模型泛化能力。

<a id="eval-4-detail-31"></a>
### 7.3 到达日仪表盘与预测日仪表盘

按标签到达日汇总有利于监控结果管线吞吐与延迟，但不宜直接解释为该日模型性能。评价应把每个标签连接到原预测、原模型版本、原特征快照和原决策规则，再按预测批次与成熟状态汇总。一个标签可能经修订，应保留版本以及报告使用的可得截止时间。

仪表盘可以同时展示未成熟数量、成熟比例、标签延迟分位数和已成熟指标，并清楚标注暂报与定稿。若新版本上线不久，其标签主要尚未成熟，而旧版本已经完整，直接比较当前可见结果会产生选择偏差。采用相同成熟期限或明确的延迟模型，才能使比较接近同一对象。

<a id="eval-4-detail-32"></a>
### 7.4 实验四：延迟标签造成虚假的高发生率

人工构造六条预测，统一七天目标窗，正事件标签部分提前到达，而负标签要待观察结束后录入。在第六天按“已到达”统计，看起来全是正类；实际上没有任何完整成熟批次。到第十二天前五条都达到统一成熟条件，按该批次计算得到真实的五分之二，而不是用所有已到达标签拼接不同观察期限。

```python
import numpy as np

prediction_day = np.arange(1,7)
mature_day = prediction_day+7
label_arrival = np.array([3,9,5,11,12,13])
y = np.array([1,0,1,0,0,0])
report_day = 6
arrived = label_arrival<=report_day
mature = mature_day<=report_day
assert arrived.sum()==2 and y[arrived].mean()==1
assert mature.sum()==0
report_day = 12
eligible = (mature_day<=report_day)&(label_arrival<=report_day)
assert eligible.sum()==5
assert np.isclose(y[eligible].mean(),0.4)
assert np.all(prediction_day[eligible]+7<=report_day)
print('day 6 arrived-only rate:',y[arrived].mean(), 'mature count:',mature.sum())
print('day 12 mature cohort rate:',y[eligible].mean())
```

该例把标签延迟安排得完全已知，目的在于展示观察口径差异。真实系统中即使目标窗结束，结果仍可能缺失；仅取已到达样本还可能有非随机缺失偏差，应继续监控完整率并分析采集机制。成熟标签规则是必要信息边界，不是任何缺失数据问题的万能解。

## 8. 上线监控与多次查看

<a id="eval-4-detail-34"></a>
### 8.1 分层指标构成诊断链

第一层检查服务和数据：请求量、来源、单位、缺失、类别新值、特征延迟和模型版本。第二层检查输入与输出分布：关键分位数、联合依赖、预测比例和拒答比例。第三层在标签成熟后检查目标损失、校准、各类错误与关键群体。每层都有不同时间延迟和识别能力，应同时记录而不是只看一个总告警分数。

单变量直方图相同不保证联合分布相同，例如两个特征相关结构可以改变而边缘不变。高维两样本方法或域分类器能补充联合变化信号，却也受特征表示、样本量和检验功效限制。未拒绝分布相同不表示已证明相同；显著差异也应报告效应大小和任务关联，避免大流量下微小变化持续刷屏。

<a id="eval-4-detail-35"></a>
### 8.2 固定时点区间不能任意反复查看

一个固定样本量的百分之九十五置信区间，承诺在预先指定的那次抽样中覆盖目标，并不自动承诺无论何时查看都覆盖。若每天查看并在首次不包含基线时宣布退化，停止规则依赖数据，整体误报概率可能超过百分之五。监控频率越高，越需要明确整个时间范围的错误控制。

简单保守方案是为第 $`t`$ 次查看分配 $`\alpha_t`$，使总和不超过 $`\alpha`$，每次构造失败概率不超过 $`\alpha_t`$ 的区间。并集界保证任一次失败的概率不超过总和，不要求不同查看相互独立。更高效的时间一致置信序列或检验鞅方法可以减少保守程度，但仍有关于损失有界、条件均值或过程结构的条件。

<a id="eval-4-detail-36"></a>
### 8.3 一个可直接推导的时间一致误差界

设固定模型的损失 $`Z_i\in[0,1]`$ 独立同分布，均值为 $`\mu`$。Hoeffding 不等式给出 $`P(\vert \bar Z_n-\mu\vert >\varepsilon)\le2e^{-2n\varepsilon^2}`$。取 $`\alpha_n=\frac{\alpha}{[n(n+1)]}`$，因为 $`\sum_{n\ge1}\frac{1}{[n(n+1)]}=1`$，令

```math
\varepsilon_n=\sqrt{\frac{\log(\frac{2n(n+1)}{\alpha})}{2n}},
```

则所有时点同时满足 $`\vert \bar Z_n-\mu\vert \le\varepsilon_n`$ 的概率至少为 $`1-\alpha`$。将区间与零一范围相交仍保持覆盖。这个简单构造偏保守，但完整展示了如何从固定时点界到整体保证，而不只引用一个复杂方法名。

如果模型在线改变、样本分布漂移或损失相关，固定共同均值假设不再成立，不能原样解释为未来性能置信序列。可以定义分段目标、条件均值平均或采用适合过程的理论，但必须重新说明。用于发现变化的监控和用于估计恒定均值的区间，也不应只因都随时间更新就被当成同一问题。

<a id="eval-4-detail-37"></a>
### 8.4 实验五：同时误差预算的逐项核对

下面计算一个固定损失流的时间一致区间，检查总预算、边界与半径。实验并不以一条样本是否覆盖来证明覆盖率；覆盖保证来自上述不等式与并集界。代码的任务是核对实现的公式和概率预算，避免把 $`\alpha_n`$ 错写为每步相同的 $`\alpha`$。

```python
import numpy as np

rng = np.random.default_rng(208)
alpha = 0.05
n = np.arange(1,1001)
budget = alpha/(n*(n+1))
radius = np.sqrt(np.log(2/budget)/(2*n))
loss = rng.binomial(1,0.2,size=len(n))
mean = np.cumsum(loss)/n
lower = np.maximum(0,mean-radius)
upper = np.minimum(1,mean+radius)
assert np.isclose(budget.sum(),alpha*(1-1/1001))
assert budget.sum()<alpha
assert np.all(lower<=upper)
assert np.all((0<=lower)&(upper<=1))
assert np.allclose(radius,np.sqrt(np.log(2*n*(n+1)/alpha)/(2*n)))
fixed_time_radius = np.sqrt(np.log(2/alpha)/(2*n))
assert np.all(radius>=fixed_time_radius)
print('spent alpha:',budget.sum(),'final interval:',lower[-1],upper[-1])
```

时间一致性需要为反复查看付出更宽区间，而不是靠每天重新画同样的误差条获得。真实告警系统还涉及多个指标、多个群体和多次模型上线，应把这些查看纳入整体监控协议，或分别说明哪些只是探索信号、哪些能触发正式判断。

<a id="eval-4-detail-38"></a>
### 8.5 告警、诊断与响应的职责

告警是调查触发器，不应直接等同于模型替换命令。预先规定处理顺序：核实采样和数据链路，确认标签成熟与版本连接，分析改变区域及严重性，再选择回退、收集标签、调整规则或重训。响应速度应由实际代价决定，同时保留足够日志支撑事后解释。

如果每次看到告警就改变阈值，随后用同一窗口宣布恢复，监控数据已经变成开发数据。应设置冻结后的确认窗口，或者使用明确支持自适应决策的设计。记录为何行动、看过什么数据和什么时候冻结，并不是行政附件，而是判断后续证据是否独立的统计信息。

## 9. 多群体报告与总体组成

<a id="eval-4-detail-40"></a>
### 9.1 总体指标的组成分解

若群体 $`G`$ 的目标比例为 $`q_g`$，各群体风险为 $`R_g`$，总体风险为 $`\sum_gq_gR_g`$。总体变化既可能来自组内风险变化，也可能来自群体构成变化。报告可以同时给出实际总体风险和固定参考组成的标准化风险，前者描述当前负担，后者帮助隔离组成效应；两者目的不同，不能只公布较好看的一个。

群体定义可能来自地区、设备、语言、年龄段或产品渠道，应该与任务机制和使用范围相关。过细切片会产生稀疏、隐私和多重探索问题，过粗又可能掩盖交叉群体风险。应预先选主要群体，补充探索性切片，并对样本量不足处明确写证据不足。总体高分不能自动覆盖所有被测子群体。

<a id="eval-4-detail-41"></a>
### 9.2 小群体估计、同时区间与最差者偏差

挑选所有群体中表现最差的一组，会同时选择真实困难与负向抽样噪声；只对该组套单独区间，可能低估挑选影响。可以使用同时区间、预先定义重点组或在后续数据确认。分层模型能借助共享结构改善估计，但也引入组间可交换假设，不能无条件把每个小组都向总体收缩后宣称差异已消失。

不同公平性指标对应不同条件概率与约束，基率不同时通常存在取舍。不能仅因群体准确率相同就宣布任何公平问题都已解决，也不能把一个统计差异直接解释成某种因果歧视。应说明指标与任务代价、决策政策和相关规范的关系；本章重点是证据与估计，不用单个数字替代价值选择。

<a id="eval-4-detail-42"></a>
### 9.3 一个需要同时报告的群体变化案例

假设旧总体中容易组占九成、困难组占一成，两组错误率为百分之五与二十；新总体比例变为各一半，组内风险完全不变。总体错误率从百分之六点五变成十二点五。不能说条件预测关系必然退化，也不能说系统没有问题：实际用户承受的错误确实增加。

若新模型使两组风险分别降为百分之四与十八，新总体错误率为十一，比旧总体总分仍差，却在每个群体内都改进。比较系统改动应在共同目标组成下配对评价，同时展示实际各期总体负担。标准化揭示不同问题，并不允许忽略真实部署构成造成的风险。

## 10. 把结论写成可复核的评估报告

<a id="eval-4-detail-44"></a>
### 10.1 数据、选择和证据形成一份连续记录

报告首先定义部署对象：评价新用户、已知用户的未来请求，还是新时间与新来源。随后给出数据取得方式、覆盖期限、标签定义、成熟规则和排除条件。读者应能知道哪些样本有机会进入评价，哪些对象没有被覆盖，以及结果记录是否依赖模型行为。没有这层信息，指标的总体含义无法判断。

再说明完整选择过程：特征、模型、搜索、校准、阈值、群体定义和主要指标分别用了哪些数据。被查看后用于修改的测试集应更名为开发证据，另说明最终确认信息来自哪里。冻结模型时保存版本、训练截止日和决策规则，并记录失败配置及尝试预算，使比较对应真实学习流程而非事后最佳片段。

结果表应同时给基线、绝对损失、配对差异、评价数量、独立组数、关键群体和区间来源。若区间只覆盖固定模型评价抽样，应直接这样写；跨种子波动另外列，跨时间表现也另外展示。表格中的不同误差条不能共用一个含糊的“稳定性”标签，让读者误以为全部来自同一种抽样分布。

<a id="eval-4-detail-45"></a>
### 10.2 从点估计到结论范围

一种合适表述是：“在指定月份、已成熟的五千名独立用户上，冻结模型相对基线的每用户平均成本下降某个绝对数值；用户配对重采样区间如表。新地区和未成熟用户未覆盖。”这类句子明确总体、单位、模型状态、比较对象和未知范围，比“效果显著提升且可靠”更有信息。

对于跨时间退化，应区分观察事实与推测原因。可以先陈述输入来源比例与成熟损失同时变化，再提出组成效应、标签机制或条件变化等解释，并标注哪些已经通过分组或额外数据检验。统计相关不自动说明修复方案，更不自动给出因果机制。

<a id="eval-4-detail-46"></a>
### 10.3 失效案例与后续验收

报告应保留少量有代表性的错误机制：分布外输入、标签歧义、支持不足、特征延迟和代价极高的误判。展示案例不是以个别故事替代总体统计，而是帮助理解指标遗漏的结构。挑选时说明标准，避免只展示新模型成功而基线失败的样本。

最后给出适用边界和下一步信息需求，例如新群体需要多少成熟标签、哪种监测触发复核、重训后使用什么确认窗。未知不应只列成泛泛限制，应该连接到可操作的取证计划。完成报告意味着他人能判断结论能用于哪里，也能知道哪些行动尚缺证据。

## 11. 进阶研究：把未知转化成可检验问题

<a id="eval-4-detail-65"></a>
### 11.1 构建组成变化与关系变化的对照研究

选择一个能手工指定联合概率的二元输入模型，先固定条件标签概率，只改变输入比例，再固定输入比例而改变条件标签概率。对于每种情形，记录输入漂移统计、预测比例、真实损失和加权风险估计。这样可以直接观察监测信号分别在哪些变化下有用，在哪些变化下完全没有识别能力。

下一步加入未知权重估计误差、支持缺口和延迟标签，逐项改变一个因素。不要一次把所有复杂性加进去，否则看到结果变差时无法解释原因。研究报告应把真实目标风险作为合成实验参考，展示估计偏差、方差与区间覆盖，而不只比较几条漂移曲线的视觉形状。

<a id="eval-4-detail-66"></a>
### 11.2 对重采样和选择建立外层模拟

可以反复生成带用户相关的数据，每次训练和选择模型，再取独立目标用户作为真实泛化参考。比较逐行 bootstrap、整组 bootstrap 和外层重做选择的区间，统计各自针对哪个目标获得怎样覆盖。对固定模型与完整学习规则分别分析，避免把一个区间故意用于它本来未承诺的目标，然后简单宣布方法失败。

若训练成本较高，可以先使用可解析的小模型或少量候选研究机制。研究价值来自问题能够被清楚证伪，而不取决于模型规模。完整记录随机种子和生成参数后，可以让他人重复发现相关性、选择与总体迁移带来的不同效应，形成可教学也可拓展的基准。

<a id="eval-4-detail-67"></a>
### 11.3 监控策略的误报与发现延迟

在一段稳定过程后人为改变损失均值，比较固定频率告警、简单时间预算与适当序贯方法。评价至少包括稳定阶段误报率、真正改变后的发现延迟、告警数量和行动代价。不能只报告发现最快的一次，因为更激进规则通常同时提高误报。若修改规则时看过同一批模拟结果，最后应使用新的模拟重复作确认。

对现实系统，还要把标签延迟纳入发现延迟，而不是只计算结果到达后算法用了几步。某个无标签信号虽不能证明性能退化，却可能更早提示调查；其价值可以通过减少诊断等待或提高标签采样效率评价。这样就不会在“万能检测器”和“毫无用处”之间作不必要的二选一。

<a id="eval-4-detail-68"></a>
### 11.4 最终验收应回答的四个问题

第一，区间和误差条究竟对哪种随机重复有效；第二，迁移结论依赖什么不变性与支持；第三，标签和特征在预测当时是否真正可得；第四，报告数字是否已经参与选择。每个问题都应能连接到数据字段、数学假设或可复核实验，不能只靠一句“流程标准”回答。

如果四个问题还有缺口，报告应写出缺口的具体后果与补证计划。可以交付一个范围有限但可靠的结论，无需把当前证据扩展到所有未来人群。完成本主题后，读者应能够从指标定义一直追踪到部署报告，理解每个数字由什么信息产生、能支持哪一种决策，以及什么时候需要停止推断并收集新证据。

**延伸算例：有效样本量不能替代目标支持检查。** 重要性权重为一、一、一、一时，常见权重有效样本量等于四，说明这些已观测记录没有权重集中。如果目标总体另外有一半质量落在源分布从不出现的区域，这个四完全看不到那一半的标签风险。对零一损失，若已覆盖区域条件风险为零点一，整体目标风险只能先约束在零点零五到零点五五之间；增加源支持内部样本可更精确地估计零点一，却不能仅靠权重消除支持外未知部分。有效样本量是某种权重离散诊断，既不证明支持重叠，也不证明相关样本已经独立。
