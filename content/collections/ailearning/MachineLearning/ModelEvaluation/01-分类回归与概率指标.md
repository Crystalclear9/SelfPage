## 1. 先定义要估计的量，再决定如何打分

评价的起点不是调用一个函数，而是描述一次预测的完整实验。设输入为随机变量 $`X`$，真实结果为 $`Y`$，模型给出的分数为 $`s(X)`$，概率预测为 $`p(X)`$，实际决策为 $`a(X)`$。这三种输出有不同含义：分数可以只保证大小次序，概率宣称事件发生的频率，决策还加入了阈值、资源和错误代价。把其中一种评价当成另外两种的充分证据，是理解指标时最常见的错误。

假设两个模型对每个人的风险排序完全一致，其中一个输出真实后验概率，另一个把概率全部平方。二者的排序指标可能完全相同；若直接以零点五为阈值，阳性名单却会改变；对概率取对数打分时结果也会改变。因此“模型更好”必须补全宾语：是排序更好、概率预测更好，还是某个明确使用政策下的平均损失更低。本章依次讨论这些对象，下一章讨论如何通过合法数据划分估计它们。

<a id="eval-1-detail-2"></a>

### 1.1 从总体风险到样本指标

用 $`L(Y,a)`$ 表示一次行动的损失，总体风险为 $`R(a)=E[L(Y,a(X))]`$。在来自目标总体的独立同分布测试样本上，经验风险是损失的算术平均。平均数之所以有意义，依赖评价样本与目标总体的关系；若测试集人为过采样了阳性，直接平均对应的就是过采样总体，不能自动宣称为线上平均成本。权重可以改变估计目标，但权重需要有抽样或部署依据。

某些指标是逐例损失的均值，例如误分类率、平方误差和对数损失。另一些指标先汇总计数再取比值，例如精确率与召回率；还有一些依赖样本之间的成对次序，例如排序面积。它们的抽样行为不同。一个样本权重既可能代表重复次数，也可能代表目标总体的重要性，在报告中应写明其含义，不能把所有权重都解释为额外独立证据。

还要确定评价单位。按请求平均回答每次服务的效果，按用户先平均再平均回答典型用户的效果；活跃用户请求多时，这两个量会不同。回归任务中按门店、商品或月份平均，同样会改变估计对象。指标公式本身没有替读者决定谁应获得更大权重。只有总体、单位、输出类型和损失含义一起确定，数值才有可比较的含义。

<a id="sec-1-1"></a>

<a id="eval-1-detail-3"></a>

### 1.2 混淆矩阵：同一批错误的不同条件概率

规定标签一为正类、预测值不小于阈值时行动为正，混淆矩阵的行表示真实类别，列表示预测类别。真负数、假正数、假负数、真正数分别记作 $`TN,FP,FN,TP`$。在二分类中它们构成整个评价样本的一个划分，所以总和必须等于样本量。检查这一恒等式，比直接相信一个小数更容易发现遗漏、重复连接或者标签映射颠倒。

| 真实情况 | 决策为负 | 决策为正 |
| --- | ---: | ---: |
| 真实负类 | $`TN`$ | $`FP`$ |
| 真实正类 | $`FN`$ | $`TP`$ |

准确率为 $`\frac{(TP+TN)}{n}`$，精确率为 $`\frac{TP}{(TP+FP)}`$，召回率为 $`\frac{TP}{(TP+FN)}`$，特异度为 $`\frac{TN}{(TN+FP)}`$，假阳性率为 $`\frac{FP}{(TN+FP)}`$。精确率问被选中的对象中多少是真的，召回率问真正目标中找到了多少。它们的分母定义了不同的条件事件，所以不能根据其中一个推断另一个。假阳性率很低，也不保证人工队列中的错误比例很低。

例如 $`TP=30,FP=10,FN=20,TN=40`$，准确率为零点七，精确率为零点七五，召回率为零点六，特异度为零点八。这些数值同时成立。若系统每天只能审核四十条，精确率和队列大小直接相关；若漏掉目标代价很高，二十个漏报就必须单独呈现。把所有错误压缩成准确率，会隐去错误发生在哪一类以及实际处理后果。

零分母不是罕见的软件小事。模型从不报正时精确率的条件集合为空，真实评价集没有阳性时召回率也没有可用分母。可以为汇总运算设置约定值，但应同时标记指标不可识别或缺少支持，不能把约定的零或者一解释为实测能力。单类数据上的排序面积同样没有普通二分类排序含义，后面会进一步说明。

<a id="eval-1-detail-4"></a>

### 1.3 调和平均、平衡准确率与相关系数

把精确率和召回率调和平均可得 $`F_1=\frac{2TP}{(2TP+FP+FN)}`$。这个公式显示它没有使用真负数。添加大量正确预测的负例，会使准确率明显上升，却不改变已有决策的这一分数。因此它适合表达某些关注正类检出的需求，但不能称为完整错误成本。把漏报成本变成两倍，也不能机械地声称某个调和平均参数就等价于该业务成本。

更一般地，$`F_\beta=\frac{(1+\beta^2)TP}{[(1+\beta^2)TP+\beta^2FN+FP]}`$。增大参数会提高对召回的偏重，不过分母也随预测正例数量变化，最优规则依赖整体得分分布。这与逐例比较固定错误成本的线性风险不同。若目标是钱、工时或延迟，直接定义可解释的损失通常比寻找一个看似接近的通用指标更清晰。

平衡准确率是正类召回和负类召回的均值，即 $`\frac{(TPR+TNR)}{2}`$。它给两个真实类别等权，避免多数类完全主导；但是这种等权本身就是一种总体选择，并不自动等于真实部署成本。若部署中百分之九十九为负类，把两类各赋一半权重，可以用于比较类内辨别能力，却应与部署平均错误数量分开报告。

马修斯相关系数可写为 $`\frac{(TP\,TN-FP\,FN)}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}`$，它等价于非退化二元真实标签与二元决策的皮尔逊相关系数。它同时使用四个计数，仍不指定错误代价。分母退化时需要明确实现约定；相关系数高也不代表少数高成本对象已被妥善处理。指标越复杂，并不意味着其用途越普遍。

**为什么调和分数的最佳阈值依赖全体分布？** 这个结论可以在总体层面直接推导。令 $`\eta(x)=P(Y=1\mid X=x)`$ 是可用信息后的真实后验，确定性报正规则为 $`d(x)\in\{0,1\}`$，正类基率 $`\pi=E\eta(X)>0`$。记真正质量 $`A=E[\eta(X)d(X)]`$、报正质量 $`q=E[d(X)]`$，则总体 $`F_1=\frac{2A}{(\pi+q)}`$。现在增加一块原本报负、概率质量为 $`\delta>0`$、平均真实后验为 $`u`$ 的区域，新分数为 $`\frac{2(A+\delta u)}{(\pi+q+\delta)}`$；交叉相乘可知它改善当且仅当 $`u>\frac{A}{(\pi+q)}=\frac{F_1}{2}`$。

因此在允许按真实后验自由选择行动的总体最优规则中，阈值与最优值自洽：高于 $`\frac{F_1^*}{2}`$ 的位置应选中，低于它的应排除，等于时可有并列最优或随机化。这不是一个训练前已知的固定数，因为 $`F_1^*`$ 本身由整体后验分布决定。它也没有声称任意有限测试集上最优经验阈值精确等于经验分数的一半，更不等同于随机计数比值的期望；这里分析的是总体混淆质量构成的比值。

例如人群等分为后验 $`0.9`$ 与 $`0.4`$ 两组，基率为 $`0.65`$。只报高组时 $`A=0.45,q=0.5`$，分数为 $`\frac{0.9}{1.15}\approx0.78261`$；全报时分数为 $`\frac{1.3}{1.65}\approx0.78788`$，反而略好。分界相应约为 $`0.39394`$，所以后验低于二分之一的那组也进入最优名单。若错误成本对称，贝叶斯零一决策却会排除该组。这一对照把“优化正类调和分数”和“最小化对称错误率”放在同一合法概率模型中区分开；不同目标选出不同政策，并不是概率模型互相矛盾。

### 1.4 实验一：用计数核对库的输出

下面的独立实验先按集合逻辑计算计数，再与库函数核对。断言针对数学恒等式，不依赖显示小数的位数。固定标签顺序非常重要，否则一个只有部分标签的数据切片，可能返回形状不同的矩阵，使后续解包悄悄改变含义。

```python
import numpy as np
from sklearn.metrics import confusion_matrix, precision_score, recall_score, f1_score

y = np.array([1] * 50 + [0] * 50)
hat = np.array([1] * 30 + [0] * 20 + [1] * 10 + [0] * 40)
tp = int(np.sum((y == 1) & (hat == 1)))
fp = int(np.sum((y == 0) & (hat == 1)))
fn = int(np.sum((y == 1) & (hat == 0)))
tn = int(np.sum((y == 0) & (hat == 0)))
assert (tn, fp, fn, tp) == (40, 10, 20, 30)
assert np.array_equal(confusion_matrix(y, hat, labels=[0, 1]), [[40, 10], [20, 30]])
assert np.isclose(precision_score(y, hat), 3 / 4)
assert np.isclose(recall_score(y, hat), 3 / 5)
assert np.isclose(f1_score(y, hat), 2 / 3)
print('计数、分母与三个库指标一致')
```

试着把后五十个负例再复制十次，观察准确率、精确率、召回率如何变化。复制整个负类分布时，假正数和真负数一起增加，假阳性率保持不变，但精确率下降；这与仅添加正确负例时的现象不同。区分“改变基率”和“只添加某一类预测结果”，能防止用不对应的反例解释指标性质。

## 2. 阈值扫描与排序评价

<a id="eval-1-detail-7"></a>

### 2.1 从一个工作点到整条曲线

设分数越大越倾向正类。对阈值 $`t`$ 定义 $`a_t(x)=1\{s(x)\ge t\}`$。随着阈值降低，被选集合单调扩大，真正数和假正数都不减，因此召回率和假阳性率不减；精确率则是两个变化计数的比值，不保证单调。一段新加入的样本若主要是正类，精确率可能上升；若主要是负类，则可能下降。

经验曲线只在不同分数值处改变。若多个样本同分，合法的共同阈值会一次加入整组，不应偷偷用真实标签把同分组排成有利次序。若系统确实会按另一个可用变量打破并列，应把那个变量纳入实际排序规则，并按完整规则重新评价。报告曲线与生产队列是否使用同一并列政策，往往比额外保留几位小数更重要。

ROC 曲线横轴是假阳性率，纵轴是真阳性率。PR 曲线横轴为召回，纵轴为精确率。二者都由同一阈值扫描产生，却强调不同分母。前者比较类内条件检出，后者直接描述被选队列的纯度与真实目标覆盖。没有一条曲线能替代某个实际阈值下的错误数、每日工作量和成本。

<a id="eval-1-detail-8"></a>

### 2.2 排序面积为什么是成对比较

随机抽一个正例得分 $`S_+`$ 和一个负例得分 $`S_-`$，标准二分类排序面积满足 $`A=P(S_+>S_-)+\frac12P(S_+=S_-)`$。在有限样本中，枚举全部正负样本对，严格高于记一分，并列记半分，再除以正负对数量，就得到经验面积。这个表达把面积转化为可手算、可验证的排序统计量。

证明可以从阈值经过每个负例分数时，横轴增加的量考察。没有并列时，每个负例使假阳性率增加 $`\frac{1}{n_-}`$，当时纵轴等于得分高于该负例的正例比例。把所有矩形面积相加，就是正负对中正例分数较大的比例。并列组在端点之间使用梯形连接，相等对贡献一半，便得到完整公式。这里的半分来自对并列的不偏置处理，而不是模型真的能区分这两个样本。

严格单调递增的变换保留所有大于和等于关系，所以面积不变。若变换只是非递减，比如分箱或四舍五入，原来不同的值可能变为并列，面积就可能改变；严格递减变换则反转次序，普通二分类面积变为原值的一减。把“单调变换不影响面积”说得不带方向和严格性，会遗漏真实系统中量化分数的影响。

面积为一只表示在这批评价样本上所有正例都排在负例前，不说明概率正确，不说明极低误报区域的估计稳定，也不说明未来总体仍然可分。面积接近一半不必然意味着完全没有可用信息：某个局部区域仍可能适合审核，也可能存在方向相反而未被翻转的信号。必须把整个曲线和真正使用的区域一起审查。

### 算例：每组 AUC 都为一，合并 AUC 为何只有 0.19？

“总体 AUC 是各组 AUC 的加权平均”通常不成立。AUC 的抽样单位是一对正负记录，合并数据后新增了**跨组正负对**，而组内指标没有评价这些比较。这里的组可以是来源、设备或独立训练模型的业务分区，不是多分类标签。

构造两个各含十条记录的组：

| 组 | 正例数与分数 | 负例数与分数 | 组内 AUC |
|---|---|---|---:|
| A | 9 个正例，分数均为 0.2 | 1 个负例，分数为 0.1 | 1 |
| B | 1 个正例，分数为 0.9 | 9 个负例，分数均为 0.8 | 1 |

分数只是用于排序的实数，不假定是校准概率。组内每个正例都高于每个负例，所以两组 AUC 确实都是一。但合并后共有十个正例、十个负例，需要比较一百对：

![两组内部排序全对，但 A 正例与 B 负例形成的 81 对全部排错，使合并 AUC 仅为 0.19](images/01-auc-cross-group.svg)

- A 正例对 A 负例：$`9\times1=9`$ 对，全部正确。
- A 正例对 B 负例：$`9\times9=81`$ 对，全部错误。
- B 正例对 A 负例：$`1\times1=1`$ 对，正确。
- B 正例对 B 负例：$`1\times9=9`$ 对，全部正确。

因此

$$
\operatorname{AUC}_{\rm pool}
=\frac{9+0+1+9}{100}=0.19.
$$

这里正负例之间没有同分，不需要半分修正。两组等权平均、按组样本数加权平均，甚至按组内正负对数加权平均，结果都为一，仍不能还原合并 AUC，因为它们都遗漏了跨组的八十二对比较。

**一般分解式。** 设正例所属组为 $`G_+`$，负例所属组为 $`G_-`$，并独立从正例总体和负例总体各抽一个样本。定义

$$
\begin{aligned}
w_g^+&=P(G_+=g\mid Y=1),\\
w_h^-&=P(G_-=h\mid Y=0),\\
A_{gh}&=P(S_+>S_-\mid G_+=g,G_-=h)
+\frac12P(S_+=S_-\mid G_+=g,G_-=h).
\end{aligned}
$$

由全概率公式，

$$
\operatorname{AUC}_{\rm pool}
=\sum_g\sum_h w_g^+w_h^-A_{gh}.
$$

对角项 $`A_{gg}`$ 才是组内 AUC；非对角项评价不同组分数是否具有可比较的排序尺度。本例权重向量为 $`w^+=(0.9,0.1)`$、$`w^-=(0.1,0.9)`$，配对矩阵为

$$
A=\begin{pmatrix}1&0\\1&1\end{pmatrix}.
$$

代入即得到 $`0.9\times0.1+0+0.1\times0.1+0.1\times0.9=0.19`$。如果某组没有正例或没有负例，其组内 AUC 不可定义；相关跨组比较却仍可能有观测。因此“删去无法算组内 AUC 的组再平均”又改变了评价对象。

**一个只改跨组尺度的对照。** 保持 B 不变，把 A 的所有分数加 $`0.75`$，得到 A 正例 $`0.95`$、A 负例 $`0.85`$。两组内部的分数次序均未改变，但现在所有正例分数都大于所有负例分数，合并 AUC 变为一。这不违反严格递增变换保持 AUC 的结论：此处按组使用不同变换，不是对全体分数施加同一个严格递增函数。该平移只是展示机制的对照，不能根据测试标签选择平移量后再把结果报告为无偏测试性能。

由此可确定评价与部署的对应关系。若系统在每个来源内独立排队，组内 AUC 或预先约定的组内配对加权指标较贴近用途；若请求进入统一审核队列，跨组次序会直接改变谁先被处理，应检查合并 AUC、跨组配对以及统一阈值下的错误。分数校准可能帮助建立可比尺度，但需要独立校准数据和相应假设，不能仅由组内 AUC 推出已经可比。

二分类 AUC 接收概率分数或未阈值化决策分数的接口定义见 [scikit-learn 官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.roc_auc_score.html)。本节的块分解由成对比较定义与全概率公式得到，重点是明确评价抽取哪些样本对。

<a id="eval-1-detail-9"></a>

### 2.3 部分面积与低误报区的样本量

假设每天面对一百万个负例，只能接受十次误报，实际关心的假阳性率约为十万分之一。若测试集只有一千个负例，经验曲线横轴的最小非零步长就是千分之一，根本无法直接解析该区域。整条面积再高，也不能由这批数据可靠断言极低误报运行的精度。问题在支持度，不在画图是否平滑。

部分排序面积只积分指定假阳性率区间，可以把关注范围写进目标，但不同实现可能做标准化，不能把其输出当作原始几何面积。使用库函数时应核对`max_fpr`对应的标准化定义，并说明所选区间。若该区域内只有极少负例越过阈值，还需要适当区间或额外样本。对零次观测误报报告零风险尤其不合理，有限样本零次不等于总体概率为零。

对于固定审核容量，直接报告前若干名的命中数量与精确率常更贴近服务。若候选池每天变化，则固定数量政策与固定分位数政策不同：前者固定工作量，后者随总量变。评价时必须重放相同批次的候选集合，不能先在全测试期全局排序取前若干名，再声称实现了每日相同预算。

### 2.4 AUC 的有效信息量：U 统计量、方差与配对比较

有 $`m`$ 个独立正例和 $`n`$ 个独立负例，评分规则已在这批测试数据之外冻结，两类样本之间也独立。定义 $`h(x,y)=1\{x>y\}+\tfrac12 1\{x=y\}`$，经验面积为 $`\hat A=(mn)^{-1}\sum_{i,j}h(X_i,Y_j)`$。虽然出现了 $`mn`$ 个比较，这些比较不独立：$`h(X_i,Y_1)`$ 与 $`h(X_i,Y_2)`$ 共享同一个正例。把所有样本对当作独立伯努利试验，会把复用产生的相关性错认成额外数据量。

可把相关性精确拆开。设总体面积为 $`A=Eh(X,Y)`$，定义 $`a(x)=E_Yh(x,Y)-A`$、$`b(y)=E_Xh(X,y)-A`$，以及 $`r(x,y)=h(x,y)-A-a(x)-b(y)`$。条件期望满足 $`E(r\mid X)=E(r\mid Y)=0`$，于是

$$
\hat A-A=\frac1m\sum_i a(X_i)+\frac1n\sum_j b(Y_j)
+\frac1{mn}\sum_{i,j}r(X_i,Y_j).
$$

三部分正交；不同残差对即使共享一个样本，协方差也因其条件均值为零而消失。因此精确总体方差为

$$
\operatorname{Var}(\hat A)
=\frac{\operatorname{Var}(a(X))}{m}
+\frac{\operatorname{Var}(b(Y))}{n}
+\frac{\operatorname{Var}(r(X,Y))}{mn}.
$$

常规非退化情形下前两项主导，标准误主要按独立正负例数量缩小，而非按样本对数量缩小。实际计算行均值 $`v_i=n^{-1}\sum_jh(X_i,Y_j)`$ 和列均值 $`w_j=m^{-1}\sum_ih(X_i,Y_j)`$，常用大样本方差估计为 $`\frac{s_v^2}{m}+\frac{s_w^2}{n}`$，其中样本方差分别使用分母 $`m-1,n-1`$。这是 DeLong 方法的核心结构，不能将有限样本中的这个估计量直接说成上式三个未知总体分量的精确代入；原方法通过[广义 U 统计量处理相关 ROC 面积的协方差](https://pubmed.ncbi.nlm.nih.gov/3203132/)。

手算正例分数 $`(0.9,0.6,0.3)`$，负例分数 $`(0.8,0.5,0.2)`$。比较矩阵三行为 $`(1,1,1)`$、$`(0,1,1)`$、$`(0,0,1)`$，故 $`\hat A=\frac{6}{9}=\frac{2}{3}`$，行均值为 $`(1,\frac{2}{3},\frac{1}{3})`$，列均值为 $`(\frac{1}{3},\frac{2}{3},1)`$。两组样本方差都为 $`\frac{1}{9}`$，得到估计方差 $`\frac{2}{27}\approx0.07407`$、标准误约 $`0.27217`$。若错当九次独立伯努利试验，会算出 $`\frac{(\frac{2}{3})(\frac{1}{3})}{9}=\frac{2}{81}`$，仅为前者三分之一。这批样本太少，数值用于检查公式，不能据此宣称正态区间覆盖已经可靠。

在同一批对象上比较模型一和二时，先计算逐正例的行均值差与逐负例的列均值差，再以两组差值的样本方差除以 $`m,n`$ 并相加，估计面积差的方差。这保留了两个模型的配对协方差；若两模型仅相差严格递增变换，比较矩阵相同，所有差值都为零。零估计差异不证明未来任务上等效。存在同一用户多记录、训练测试重叠、评价后选模型，或总体投影退化时，常规大样本论证需要另作处理；普通 DeLong 方差也没有自动包含重新训练的随机性。

### 图解：把正负配对表与独立对象分开数

![AUC三乘三配对表中共享对象造成的信息复用](images/01-auc-shared-pairs.svg)

左图先保留六个原始对象，再连出九个正负比较：蓝线表示正例分数较高，橙线表示相反。三条粗线都从正例 $`0.6`$ 出发，因此对应右图橙框中的同一整行；这三次比较不是重新抽到三个独立正例。右图格内零、一与边上行列均值完全由左侧分数计算，没有增加新的数据。连线交叉只是配对关系，位置并非额外特征。

矩阵每一行的三个格都使用同一个正例分数。若这条正例换成更容易辨别的对象，该行多个比较可能一起改变；列也有相同依赖。增加负例能给现有正例增加比较，却没有增加正例人群的独立覆盖。两类支持度都应单独报告，不能用九个格数替代“三个正例与三个负例”。图中的小数只是原精确分数的显示近似，正文方差仍用分数计算。

沿行平均得到 $`(1,\frac23,\frac13)`$，其样本方差为 $`\frac19`$；列平均是相反次序，有相同样本方差，因此常用 DeLong 估计为 $`\frac{1}{27}+\frac{1}{27}=\frac{2}{27}`$。若误把九个比较视为独立 Bernoulli，代入 $`\widehat{\rm AUC}=\frac23`$ 会写出 $`\frac{(\frac23)(\frac13)}{9}=\frac{2}{81}`$；这个值只是展示错误模型为何更乐观，并非所有分布中两者都会固定相差三倍。对同批对象上的两个模型，应先把对应行与对应列的贡献作差，保留协方差；分别估计两个面积再假定相互独立，会丢掉这一设计信息。

如果同一用户贡献多条记录，还存在矩阵之外的组内依赖；按记录直接应用该公式没有自动解决重复用户的问题。需按独立单位设计抽样或采用相应分组推断。图没有用重复比较创造训练随机性的证据，也没有给模型选择之后的面积差提供自动校正。原始统计方法见 [DeLong 等的相关 ROC 面积比较论文](https://pubmed.ncbi.nlm.nih.gov/3203132/)，先固定评价对象与模型，再选择与抽样设计一致的方差计算。

## 3. 基率、PR 曲线与平均精确率

<a id="eval-1-detail-11"></a>

### 3.1 用贝叶斯公式解释误报负担

设目标总体正类比例为 $`\pi`$，阈值的正类检出率为 $`r`$，负类误报率为 $`f`$。预测正的概率为 $`\pi r+(1-\pi)f`$，其中真正例部分为 $`\pi r`$，所以精确率为 $`\frac{\pi r}{[\pi r+(1-\pi)f]}`$。这是把条件在真实类别上的率，转成条件在预测结果上的率；两者之间必须经过类别基率。

当 $`\pi=0.01,r=0.9,f=0.01`$，一万条记录中预期有九十个真正例和九十九个假正例，精确率约为百分之四十七点六。把基率降到千分之一而维持两种类内率，预期真正例约九个，假正例约一百个，精确率就不足百分之九。这不一定表示模型类内排序退化，而是目标人群发生了组成变化。

若正负类各自的分数条件分布不变，仅基率改变，理论 ROC 曲线保持不变，而 PR 曲线随基率改变。若类别条件分布也变了，两条曲线都可能改变。所以“ROC 不受类不平衡影响”只能在明确的类内分布固定意义下使用；估计方差、模型训练质量和部署价值仍会受到稀有类别影响。

<a id="sec-6"></a>

<a id="eval-1-detail-12"></a>

### 3.2 平均精确率与梯形面积不是同一数

一种常用的平均精确率定义为 $`AP=\sum_k(R_k-R_{k-1})P_k`$，按召回增加量加权当前精确率。没有同分时，它等于每个正例被检出位置的精确率再对正例平均。有同分时要按完整同分组进行阈值更新，不能任意给组内正例优先位置。该定义是阶梯加权，并不等于把 PR 点用直线连起来后做梯形积分。

手算标签按分数从高到低为一、零、一、零。两个正例分别位于第一和第三位，对应精确率一与三分之二，平均精确率为六分之五。若把曲线端点进行线性插值，得到的数值通常不同。区别不是谁算错，而是积分或插值约定不同。因此报告时应使用准确名称，并附实现与同分规则，不能把所有结果都简称为某种面积。

不含信息的随机排序，在总体意义下 PR 的基准水平与正类比例相关，但有限样本平均精确率有离散效应，常数得分、随机排列和总体随机分类器也不是完全相同的对象。常数得分把所有样本放入一个并列组，在常用阶梯实现下平均精确率等于样本基率。不要据此断言所有有限样本随机排序结果都精确等于基率。

比较两个系统时，若一个在经过负采样的集合上得到较高平均精确率，另一个在完整候选池上评价，直接相减没有解释。应在同一目标总体、同一候选集合上复评，或者在明确抽样概率和重加权规则下重建目标计数。基率标准化有助于可比性，但它仍不能修复类内分布不同造成的变化。

### 3.3 实验二：成对面积、并列与平均精确率

下面直接枚举正负对，核对并列半分。第二组数据区分平均精确率与梯形积分，最后用概率的平方验证排序不变但概率误差改变。所有数组都很小，读者可以逐个元素手算；数值相等的断言使用容差，避免浮点表现掩盖数学关系。

```python
import numpy as np
from sklearn.metrics import roc_auc_score, average_precision_score
from sklearn.metrics import precision_recall_curve, auc, brier_score_loss

y = np.array([1, 0, 1, 0])
s = np.array([0.8, 0.8, 0.4, 0.2])
pairs = [(a > b) + 0.5 * (a == b) for a in s[y == 1] for b in s[y == 0]]
assert np.isclose(np.mean(pairs), 0.625)
assert np.isclose(roc_auc_score(y, s), np.mean(pairs))
ordered = np.array([0.9, 0.8, 0.7, 0.1])
ap = average_precision_score(y, ordered)
precision, recall, _ = precision_recall_curve(y, ordered)
trapezoid = auc(recall, precision)
assert np.isclose(ap, 5 / 6)
assert not np.isclose(ap, trapezoid)
assert np.isclose(roc_auc_score(y, ordered), roc_auc_score(y, ordered ** 2))
assert not np.isclose(brier_score_loss(y, ordered), brier_score_loss(y, ordered ** 2))
assert np.isclose(average_precision_score(y, np.ones(4)), y.mean())
print('并列面积=', np.mean(pairs), 'AP=', ap, '梯形面积=', trapezoid)
```

本章涉及的平均精确率阶梯公式、排序面积参数及二分类概率平方误差缩放，可分别核对官方的[AP 定义](https://scikit-learn.org/1.8/modules/generated/sklearn.metrics.average_precision_score.html)、[排序面积接口](https://scikit-learn.org/1.8/modules/generated/sklearn.metrics.roc_auc_score.html)与[Brier 接口](https://scikit-learn.org/1.8/modules/generated/sklearn.metrics.brier_score_loss.html)。这里把概念与实现并排核对，是为了让公式和代码对同一对象负责。

### 深入图解：相同召回与误报率在低基率下得到较低精确率

![相同召回与误报率在低基率下得到较低精确率](images/01-insight.svg)

从两份各一千人的总体开始，固定检出率 $`\mathrm{TPR}=0.8`$ 与误报率 $`\mathrm{FPR}=0.1`$，只改变类别基率。上半图正类一百人，因此 $`TP=80,FN=20`$；负类九百人，因此 $`FP=90,TN=810`$。全部一百七十个告警中，真正例比例为 $`\frac{80}{80+90}\approx47.1\%`$。图中沿分支把相同的类内条件率乘以各自人数，再只汇集发出告警的两支；每组下方的蓝橙告警带共用一个人数刻度，不把不同人数的告警强行画成等长。于是既能比较真正例比例，也能比较告警总量：一百七十条下降到一百零七条，真正例却从八十条下降到八条。

下半图正类仅十人，同样的类内条件率给出 $`TP=8,FN=2,FP=99,TN=891`$。真正例只剩八个，误报却仍接近一百个，所以精确率下降到 $`\frac8{8+99}\approx7.48\%`$。两侧误报率完全相同，告警中的误报比例却分别约为 $`52.9\%`$ 与 $`92.5\%`$：前者条件在真实负类，后者条件在预测正类，两种分母不能交换。

把人数换成概率就得到 $`\mathrm{Precision}=\frac{0.8\pi}{0.8\pi+0.1(1-\pi)}`$。这是贝叶斯公式的直接结果，并不是一次分类器训练的测量。它解释为何平衡抽样测试集上的精确率不能直接当作稀有部署总体的告警命中率；公式还要求迁移前后相应类内得分分布及工作点保持一致。若来源变化同时改变误报或检出机制，就必须重新评价，不能仅调整基率。精确率、召回与同分阈值的具体定义可核对 [scikit-learn 的 Precision–Recall 官方示例](https://scikit-learn.org/stable/auto_examples/model_selection/plot_precision_recall.html)，本图人数按上述概率独立相乘得到。

## 4. 多分类、多标签与分组归约

<a id="eval-1-detail-15"></a>

### 4.1 单标签多分类：每一类都能作为一次一对其余

设共有若干互斥类别，每个样本恰有一个真类和一个预测类。对第一个类别，把它当正类、其余类别当负类，就得到一套真正、假正和假负计数；对所有类别重复这一过程。每类召回率表示该类样本被识别的比例，每类精确率表示报成这一类的预测有多少正确。完整多类混淆矩阵能进一步显示错误流向，因为仅有每类召回无法区分它经常被混到哪一类。

宏平均先分别计算各类指标，再对类别等权平均。按支持度加权的平均使用每个真实类别的样本数作为权重，代表当前测试组成。微平均则先合并各类真正、假正、假负计数，再计算指标。这三种运算通常不交换：比值的平均不等于总分子除以总分母。尤其不能把宏精确率与宏召回率代入调和平均，冒充每类调和分数的宏平均。

在所有类别都纳入且每例恰好预测一个标签的单标签任务中，每一次错误同时给真实类增加一个假负、给预测类增加一个假正。所以全类别合并后，微精确率、微召回率和微调和分数都等于准确率。这个等式依赖条件；只评价部分标签、允许拒答或者允许多标签时，不能直接沿用。等式成立也不意味着宏平均没有额外信息，它揭示小类是否被多数类掩盖。

<a id="eval-1-detail-16"></a>

### 4.2 一个不平衡多分类的完整手算

考虑三类真实支持度分别为八十、十五、五，混淆矩阵的三行为 $`(76,4,0)`$、$`(6,9,0)`$、$`(4,0,1)`$。正确数共八十六，准确率为零点八六。各类召回分别为零点九五、零点六、零点二，宏召回约为零点五八三。最后一类虽然只有五个样本，却有四个被误判，整体准确率把这一失败稀释了。

各预测列的总数为八十六、十三、一，因此精确率分别为七十六除以八十六、九除以十三、一。第三类精确率为一却召回只有零点二，说明系统只在很少的容易样本上敢报这一类，并没有全面识别该类。把精确率一孤立地写成该类表现完美，会混淆条件事件。读混淆矩阵时应该同时沿行和沿列观察。

支持度加权召回在这个单标签条件下也等于准确率，因为每类召回乘该类样本数，恰好还原该类正确数；加权精确率则不必相等。这种代数关系有利于审查报告：若一张表声称满足上述条件却给出不相等的加权召回与准确率，应检查样本权重、标签子集或者缺失预测，而不是认为算法产生了某种新性质。

<a id="eval-1-detail-17"></a>

### 4.3 多标签：样本和标签是两个不同平均轴

多标签任务中，一条文本可同时带多个主题，一个样本的真实输出和预测输出都是标签集合。把所有样本与所有标签的二元判断铺平，得到微平均；先按每个标签计算再平均，得到标签宏平均；先按每个样本计算集合指标再平均，则得到样本平均。三个轴对应不同问题：频繁标签的总处理质量、典型标签的质量、典型请求的结果质量。

严格子集准确率要求预测集合与真实集合完全一致，哪怕只错一个标签也算整例错误。汉明损失则计算所有样本标签位置中错误的比例。若标签维度很大且每例阳性很少，全空预测可以有很低汉明损失，却让所有有用标签都漏掉。相反，严格集合准确率可能对只有一个细小标签错误的大集合过于苛刻。二者都可报告，但要说明服务到底把部分正确看作多大价值。

设标签全集仅含甲、乙，两条样本真实集合分别为甲乙、甲，预测集合分别为甲、甲乙。共有四个样本标签位置，其中一个漏标签、一个多报标签，两个位置正确、两个错误，汉明损失为二分之一；两条完整集合都不对，严格准确率为零。按样本看，精确率分别为一、二分之一，召回分别为二分之一、一，平均后都为四分之三。先汇总标签位置得到的微精确和微召回都是三分之二。不同数值来自运算轴，而不是库函数互相矛盾。

若真实和预测集合都为空，集合精确率、召回及交并比会遇到空分母。必须事先决定空集合代表成功识别“无标签”、不适用，还是数据缺失；这属于任务语义。若某些标签根本没有完成标注，把未标注直接当负类，会系统性惩罚正确发现的新标签。这时评估前需要建立标注观察机制，而不是更换平均方式掩盖标签质量问题。

<a id="eval-1-detail-18"></a>

### 4.4 多分类概率与排序归约

多分类概率预测每行应给出所有互斥类别的概率，且总和为一。概率列的顺序必须与类别标签一致，不能假设第一列总是某个业务正类。多分类对数损失只取真实类别概率的负对数；多分类平方评分则比较整行概率与独热真值，是否除以二必须明确。多标签概率则不要求每行总和为一，因为多个标签可以同时发生。

多分类排序面积可以一对其余，也可以一对一。前者把某类与剩余所有类别比较，因此“其余”的组成变化会改变结果；宏平均也不能消除这种类内混合变化。后者针对类别对比较，再按约定聚合，回答的是另一种成对区分问题。多分类输出必须注明归约方法和权重，不能把所有实现输出都视为天然相同的面积。

分组评价与按类别评价也不同。来源、地区或用户类型可以与类别交叉；某组只有负例时，该组召回和排序面积就不可直接识别。报告应给出组内标签分布和计数，不能因为软件返回缺失值就悄悄删组。把缺失组删掉后的宏平均，有可能使最缺少证据的群体完全从结论中消失。

<a id="eval-1-detail-19"></a>

## 5. 概率评分为什么鼓励诚实报告

<a id="eval-1-detail-20"></a>

### 5.1 二分类平方评分的严格适当性

设给定输入的真实正类概率为 $`q`$，模型报告 $`p`$。二分类平方评分为 $`(p-Y)^2`$。其条件期望是 $`q(1-p)^2+(1-q)p^2`$，展开并配方得 $`(p-q)^2+q(1-q)`$。后一项由真实条件分布决定，只有前一项随报告值改变，所以最优报告恰好是 $`p=q`$，且离真实概率越远，额外期望损失恰为平方距离。

这个分解说明平方评分评价概率，而不是只评价分类正确。真实概率为零点六时，报告零点六比报告一更优，即使二者都作正类决策。它也说明一个单次观察不能判定概率对错：某人真实概率零点六仍可能出现负结果。评分必须通过一批同一协议下的观察来估计期望；把一次低概率事件发生当作模型必错，违背了概率本身的含义。

严格适当性是总体期望性质，不承诺有限测试样本上真概率每次都胜出，也不保证训练算法能恢复真后验。若模型类别受限、优化不到位或数据偏移，实际输出仍可能失准。若人为给正负类添加不同损失权重，最优报告通常会变为加权总体下的概率；把它直接解释为原始总体风险，必须进行额外修正。

<a id="eval-1-detail-21"></a>

### 5.2 对数损失、信息距离与端点

二分类对数损失为 $`-Y\log p-(1-Y)\log(1-p)`$。取条件期望后，在真实概率为 $`q`$ 时得到交叉熵；减去真概率自身的期望损失，剩余正好是伯努利分布之间的相对熵。相对熵非负，且只有两分布相同时为零，因此报告真实概率也是最优。若某个真实可能发生的结果被赋予零概率，理论损失无穷大。

平方评分有界，对数损失会对极端自信的错误给予很大惩罚，这体现了不同的风险偏好。把错误真实类别概率从百分之一降到百万分之一，对分类准确率没有影响，对数损失却显著恶化。若后续系统需要连乘概率、计算似然或者依据极端风险决策，这种敏感性可能有意义；如果标签本身经常有误，极端惩罚也会放大噪声，需要检查标签和建模假设。

软件为了数值稳定通常会裁剪概率端点，具体阈值可能与浮点类型有关。因此手算理论无穷大与库输出一个大有限数并不矛盾。不要把任意裁剪当成免费改善：裁剪本身改变了预测规则，应在开发中定义并在测试前冻结。报告对数底数也应一致，常用自然对数时单位为奈特，用二为底则是比特，数值尺度不同但排序一致。

<a id="eval-1-detail-22"></a>

### 5.3 校准与分辨能力并非一件事

校准条件写成 $`E[Y\mid P]=P`$。它意味着所有被报同一概率的样本，在总体中平均真实发生率应等于该概率。恒报总体基率的模型可以完全校准，却不能区分高低风险；一个能区分人群且概率准确的模型则在保持校准的同时提供更大分辨能力。因此可靠性曲线贴近对角线只是概率质量的一部分。

在理想总体且以精确预测值分组时，平方评分可分解为不可靠性减去分辨率再加总体不确定性。不可靠性是 $`E[(P-E[Y\mid P])^2]`$；分辨率是 $`\operatorname{Var}(E[Y\mid P])`$；总体不确定性是 $`\pi(1-\pi)`$。这一恒等式由条件期望和全方差公式得到。在同一总体且不可靠性相同时，分辨率越大，平均平方损失越低；若校准同时恶化，则分辨率的改善可能被更大的不可靠性抵消，不能只凭这一项比较最终评分。

例如两组各占一半，真实发生率分别为零点二与零点八。恒报零点五时，不可靠性与分辨率均为零，平方评分期望为零点二五；若把两组概率反着报成零点八与零点二，分辨率增至零点零九，但不可靠性也增至零点三六，平方评分期望反而为零点五二。分组确实携带风险信息，不等于所报告的概率已经正确使用这些信息。

有限样本可靠性图按区间分箱，会把连续概率压成箱均值，额外引入分箱近似和噪声。常见分箱校准误差依赖箱数、边界、样本量和绝对值聚合方式；它不具有对数损失那样的普适严格适当评分解释。比较模型时可以画图发现局部问题，但不要把一个箱数下更小的分箱误差当成已证明概率全面更好。下一章和第三章会讨论校准选择的信息边界。

<a id="eval-1-detail-23"></a>

### 5.4 多分类概率的诚实报告

设真类条件分布为 $`q_1,\ldots,q_K`$，报告分布为 $`p_1,\ldots,p_K`$。多分类对数损失的额外期望风险是 $`\sum_k q_k\log(\frac{q_k}{p_k})`$，同样非负。多分类平方评分的额外风险则是 $`\sum_k(p_k-q_k)^2`$，若采用除以二的约定，整个式子也除以二。通过写出额外风险，能够明确不同缩放不会改变最优概率，但会改变数值单位。

最大类别概率的校准并不等于整个概率向量校准。一个三分类模型可以在所有置信度为零点八的预测中有百分之八十猜对，却把剩余零点二长期分配给错误的替代类。总体最高置信度可靠性图不会发现这种问题；逐类概率评分、类别条件可靠性和下游成本矩阵可能会发现。多分类报告需要保留完整概率，而不仅保存最高类和最高分。

<a id="visual-example-modelevaluation-01"></a>

### 图解算例：Brier 期望风险在真实概率处唯一最小

![Brier 期望风险在真实概率处唯一最小](images/01-example.svg)

**为什么两条损失曲线的交点不是最优报告？** 正类与负类的加权项相等，只表示两种结果贡献相同；最小化总和需要它们的斜率相抵。两项导数分别为 $`-1.4(1-p)`$ 与 $`0.6p`$，相加为 $`2(p-0.7)`$，在七成处才为零。图下按同一颜色堆叠三种报告的期望损失，不把七十个正类、三十个负类当作每次必然出现的样本计数。常数报告的这个条件算例，也不能替代不同输入之间的校准与区分能力比较。

真实正类概率固定为 $`q=0.7`$，Brier 条件风险可以直接展开：

$$
E[(p-Y)^2\mid q]
=q(1-p)^2+(1-q)p^2
=q(1-q)+(p-q)^2
=0.21+(p-0.7)^2.
$$

虚线表示固定的结果不确定性 $`0.21`$；曲线比虚线高出的部分，才是概率报告偏离真值造成的额外风险。报告 $`0.5`$、$`0.7`$ 与 $`1`$ 时，期望评分分别为 $`0.25`$、$`0.21`$、$`0.30`$。因此把概率“变得更自信”并不总会改善评分，报告真实概率才最优。

图展示给定条件分布下的总体期望，不是一个标签上的实际损失。有限测试集上，真概率不必每次击败其他报告；有限模型和优化算法也未必能恢复真概率。这里使用单个正类概率的二分类 Brier 定义，若把两类平方误差相加，数值会整体乘二。定义与校准/区分能力的区别可核对 [scikit-learn Brier 评分说明](https://scikit-learn.org/stable/modules/model_evaluation.html#brier-score-loss)。

## 6. 回归指标是在选择目标分布的哪个特征

<a id="eval-1-detail-25"></a>

### 6.1 平方误差、条件均值与单位

若真实目标在给定输入下仍然随机，输出一个点就必须选择代表这个条件分布的哪个特征。对任意常数预测 $`a`$，$`E[(Y-a)^2\mid X]=\operatorname{Var}(Y\mid X)+(E[Y\mid X]-a)^2`$。因此在二阶矩存在时，平方损失的最优点预测是条件均值。它不是由“常用”得来的，而是由明确损失推导出的最优对象。

均方误差的单位是目标单位的平方；开平方得到均方根误差，恢复目标原单位。对同一个固定测试集，平方根严格递增，所以按均方误差和均方根误差给模型排序一致。跨折或者跨组先开方再平均则不再等于合并全部残差后开方，因为平方根是非线性的。汇总表需要注明是全样本均方根，还是各组均方根等权平均。

平方损失强调大残差，可以适用于尾部错误确实代价更高的任务，也可能被少量异常标注支配。删除大残差前应该追问它们是标注故障还是实际重要的稀有需求。如果线上也会出现这些需求，只因它们拉高指标就删除，会改变目标总体。合理做法是保留总体指标，并按已定义规则单独分析异常来源及稳健替代指标。

<a id="eval-1-detail-26"></a>

### 6.2 绝对误差、分位数与非对称损失

当给定输入后的绝对损失可积（例如 $`E[\vert Y\vert \mid X]<\infty`$）时，$`\vert Y-a\vert `$ 的条件期望最小点是条件中位数。若一阶绝对矩无限，所有有限点预测的原始绝对风险都可能为无穷，不能不加定义地据此区分最优；需改用风险差或另一个可积目标。

直观上，把预测略向右移动，对左边样本增加损失、对右边样本减少损失；当左右概率质量平衡时不能再降低总损失。分布存在原子时可能有一整个中位数区间，所以最优点不一定唯一。与均值不同，中位数不要求有限二阶矩，且对极端目标值更稳健。

若少估的代价高于多估，可以使用分位数的折线损失。令残差 $`u=Y-a`$，定义 $`\rho_\tau(u)=u(\tau-1\{u<0\})`$。它对少估使用系数 $`\tau`$，对多估使用系数 $`1-\tau`$，其期望最优点为相应条件分位数。比如库存短缺比积压更昂贵时，高分位数比均值更贴合目标。参数是损失偏好的表达，不是把预测区间覆盖率随意改大的一种装饰。

一个简单条件分布为以百分之九十概率取零、百分之十概率取十。平方损失最优预测一，绝对损失最优预测零，高于零点九的分位数取十。三个模型可能分别在各自指标上获胜，无法脱离损失说谁预测得最真实。若报告要求均值预测，应使用与均值一致的损失；用绝对误差挑模型，再批评输出偏离条件均值，是目标不一致。

<a id="eval-1-detail-27"></a>

### 6.3 决定系数的分母不是训练基线

在非恒定目标的测试集上，$`R^2=1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y_{test})^2}`$。分母使用该测试集目标的均值，是一个评价用的归一化参照；实际部署时不能事先知道测试目标均值。因此还应单独建立只使用训练数据拟合的均值基线，不能把数学分母的参考预测当作可部署基线。

决定系数可能为负，表示预测平方误差比测试集自身均值参照更大。负值不自动说明程序有错误，可能表示泛化差、分布移位或模型形式不足。不同测试总体的目标方差不同，哪怕绝对平方误差相同，决定系数也会不同；所以它不是跨完全不同任务比较难度或算法能力的通用尺度。

目标完全为常数时，分母为零：完美预测造成零除以零，非完美预测对应负无穷的理论退化。库可能为了网格搜索便利替换成有限值，需核对`force_finite`选项。应在报告中识别恒定切片并给出原单位误差，而不是把一个约定值解释为该群体的强泛化证据。多输出回归还需说明按输出等权还是按方差加权。

<a id="eval-1-detail-28"></a>

### 6.4 相对误差、零点与目标变换

平均绝对百分比误差把绝对残差除以真实值大小。真实值接近零时，微小绝对误差也会被放大；真实值为零时需要额外约定，软件通常使用数值保护，不代表任务中相对成本真的有限。目标可为负、可跨零时，百分比解释更容易失效。业务若对总量比例感兴趣，应明确按总量归一化的聚合损失，而不是逐例百分比简单平均。

对数变换也改变估计对象。对 $`\log Y`$ 最小化平方误差，得到条件对数均值，指数变回原尺度通常不等于条件均值，因为指数是凸函数。若目标近似对数正态且条件方差已知，可出现额外方差修正；一般分布下不能机械套同一常数。评价究竟关心原单位误差还是倍数误差，应在变换前确定。

对不同商品或群体比较时，尺度标准化可以防止大数值目标支配总体误差，但标准化分母必须可定义、可获得且有解释。用测试集目标标准差事后调尺度，会改变估计目标并利用评价信息；如果只为报告无量纲描述，可说明其性质，若要参与训练或选择就必须保持合法拟合边界。零波动商品需要单独处理，不能让除零变成悄悄删样本。

<a id="eval-1-detail-29"></a>

### 6.5 实验三：多类归约与不同回归最优点

这个实验一部分从手写混淆矩阵还原真实与预测标签，另一部分枚举点预测核对平方、绝对和分位数损失的最优值。分位数参数取零点九五，使最优点明确为十，避免在边界质量恰好为零点九时出现一整段等价最优点。最后验证负决定系数与均值基线的关系。

```python
import numpy as np
from sklearn.metrics import recall_score, precision_score, f1_score
from sklearn.metrics import accuracy_score, mean_squared_error, mean_absolute_error
from sklearn.metrics import mean_pinball_loss, r2_score

cm = np.array([[76, 4, 0], [6, 9, 0], [4, 0, 1]])
y, hat = [], []
for actual in range(3):
    for predicted in range(3):
        y.extend([actual] * int(cm[actual, predicted]))
        hat.extend([predicted] * int(cm[actual, predicted]))
acc = accuracy_score(y, hat)
assert np.isclose(acc, 0.86)
assert np.isclose(recall_score(y, hat, average='macro'), (0.95 + 0.6 + 0.2) / 3)
assert np.isclose(recall_score(y, hat, average='weighted'), acc)
for metric in (precision_score, recall_score, f1_score):
    assert np.isclose(metric(y, hat, average='micro'), acc)
values = np.array([0.] * 9 + [10.])
candidates = np.array([0., 1., 10.])
mse = [mean_squared_error(values, np.full(10, a)) for a in candidates]
mae = [mean_absolute_error(values, np.full(10, a)) for a in candidates]
pin = [mean_pinball_loss(values, np.full(10, a), alpha=0.95) for a in candidates]
assert candidates[np.argmin(mse)] == 1
assert candidates[np.argmin(mae)] == 0
assert candidates[np.argmin(pin)] == 10
assert r2_score([0., 1., 2.], [5., 5., 5.]) < 0
print('多类平均恒等式、均值/中位数/分位数目标均已核对')
```

## 7. 把指标组织成可审查的证据

<a id="eval-1-detail-31"></a>

### 7.1 主指标、辅助指标与不可补偿的要求

一份评估不应把几十个分数放在一起，让读者自己猜结论。先确定主指标对应的损失，再列辅助指标解释失败方式。若目标是固定预算下找回重要事件，主表可以使用每日相同预算的命中和漏报成本；排序面积解释更广范围的排序，概率损失解释风险数字是否可信。辅助指标不能在主指标失败时自动替代目标，否则评价会变成事后挑选有利数字。

某些要求不是可以被总体平均补偿的。例如响应时间超过某个硬上限、某类对象完全无法处理、概率中出现非法数值，都可能是验收约束。应先检查可行性，再在可行候选之间比较主指标。这与把所有要求用随意权重加成一个总分不同，后者可能让大量容易样本的微小收益抵消关键群体的严重损失。

比较还应有基线。分类的常数类别、恒定基率概率、简单线性模型，回归的训练均值、训练中位数或季节性历史值，提供不同层次参照。基线也需要遵守同一信息时间边界和拟合协议。一个使用未来目标均值的基线虽然数学上方便，却不是可部署方案；一个故意不调参数的弱基线，也不足以证明复杂方法的实际价值。

<a id="eval-1-detail-32"></a>

### 7.2 群体组成变化与辛普森现象

设两个来源分别容易和困难。某版本在两个来源内都略有改善，但新版测试集困难来源比例大幅上升，总体准确率仍可能下降。反过来，模型在两个来源内都退化，却可能因为新测试集大多是容易来源而得到更高总体分数。总体风险是组内风险与组权重的加权和，改变其中任意一项都会改变总数。

解决办法不是始终只看宏平均，而是同时提供组内计数、组内风险、当前总体加权结果和预定义目标组成下的标准化结果。宏平均相当于指定每组相等权重，可能对应研究问题，也可能与部署需求不符。若某个新来源在历史评价中没有样本，就不能通过重新加权凭空估出该来源性能；这是支持集缺失，而非权重调得不够精细。

群体分析还需限制探索自由度。预定义关键切片可用于正式判断，事后发现的异常切片可提出假设，但要在后续独立数据中复核。把数千个很小的切片全部搜索一遍，找到一个极端差异，并不能直接认定机制稳定存在。要保留每个切片样本数和搜索范围，让读者了解证据究竟来自稳定规律还是有限观察。

<a id="eval-1-detail-33"></a>

### 7.3 误差分析应保存到什么粒度

最小可复查记录至少包含唯一预测标识、模型版本、预测时间、真实结果及其成熟状态、原始分数或概率、实际动作、必要权重与分组标识。只保存最终准确率，无法重新计算新阈值、核对概率列、比较配对错误或追踪标签修订。保存逐例记录也不是要求泄露原始敏感输入，评价所需字段可以与受控数据标识关联。

逐例记录要避免把重复预测当独立样本。一次用户请求如果经过多次重试，可能生成多个技术日志，但业务只产生一次决策；同一用户每天重复出现，也会引入依赖。计数前应明确去重键和评价单位。模型缺失预测的请求不能悄悄从分母删除，应该报告失败率并按照实际服务损失处理，否则越会拒绝困难样本的模型越容易获得高分。

小数精度应与证据相称。在一百个独立对象上，多报告四位小数并没有创造额外信息。若两个模型只差一个样本，展示它们在哪个对象上出现不同，以及这个差异的成本，比只写显著提高更有价值。区间和配对推断在后两章展开；本章的首要任务是保证每个被推断的数字，本来就对应正确的计数和总体。

## 8. 十六道练习与逐步解析

<a id="eval-1-detail-35"></a>

### 8.1 练习一：反推混淆矩阵

**题目。** 测试集一千条，其中一百条为正，模型报正一百五十条，召回率零点八。求所有计数、精确率和假阳性率，并说明为何不能用报正比例代替基率。

**解析。** 真正数为八十，假负数二十。报正中剩余七十为假正，因此真负为八百三十。精确率为八十除以一百五十，约零点五三三；假阳性率为七十除以九百，约零点零七七八。报正比例为零点一五，它由模型与阈值共同产生，真实基率是零点一。二者不是同一随机事件，混用会使贝叶斯换算错误。

<a id="eval-1-detail-36"></a>

### 8.2 练习二：提高阈值是否必然提高精确率

**题目。** 按得分从高到低的标签为零、一、一。比较只选第一名与选前三名，判断精确率的单调性。

**解析。** 只选第一名时精确率零，选前三名时为三分之二。因此提高阈值反而使精确率降低。召回则从一变为零，符合被选集合缩小时不增的性质。精确率取决于新加入或移除样本的正类组成，没有单调保证；不能把常见趋势写成数学定理。

<a id="eval-1-detail-37"></a>

### 8.3 练习三：面积并列半分

**题目。** 两个正例得分为零点八与零点四，两个负例得分为零点八与零点二，手算标准排序面积。

**解析。** 四对贡献分别为二分之一、一、零、一，总分二点五，除以四得到零点六二五。若把同分正例人为排在负例之前会得到零点七五，反向排则零点五，二者都利用了并列组内不被分数支持的次序。共同阈值只能把同分样本一起纳入，所以标准面积使用半分。

<a id="eval-1-detail-38"></a>

### 8.4 练习四：负采样之后精确率如何解释

**题目。** 完整总体正例占百分之一，抽样评价集却让两类各占一半。某阈值正类检出零点八、误报零点零二，分别求两个总体的精确率。

**解析。** 抽样总体为零点八除以零点八二，约零点九七六；完整总体为零点零零八除以零点零二七八，约零点二八八。前提是负采样没有改变类内得分分布，阈值也未变。巨大的数字差异来自基率；如果抽样偏向容易负例，连类内误报率也不能直接转移。

<a id="eval-1-detail-39"></a>

### 8.5 练习五：平均精确率的排名解释

**题目。** 六个样本的标签按分数从高到低为零、一、零、一、一、零，分数互异，计算平均精确率。

**解析。** 正例位于第二、第四、第五位，三个位置的精确率分别为二分之一、二分之一、五分之三，平均得到十五分之八。也可逐阈值计算召回增量，每遇一个正例增加三分之一，再乘该处精确率。若分数同分，必须改为整组阈值更新，不能直接沿任意组内排列套这个位置公式。

<a id="eval-1-detail-40"></a>

### 8.6 练习六：微平均等于准确率的边界

**题目。** 为什么完整单标签三分类的微调和分数等于准确率，而只挑两个类计算就未必相等？

**解析。** 纳入全部类时，每次错误都贡献一个假正和一个假负，每次正确贡献一个真正，三种合并分母都还原样本数。删去某个类别后，涉及被删类的错误只可能在保留侧留下一个计数，守恒关系被打破。若加入拒答类但评价时又删掉它，同样要重新检查等式，不能沿用完整单标签的结论。

<a id="eval-1-detail-41"></a>

### 8.7 练习七：宏调和分数为何不能由宏精确与宏召回计算

**题目。** 两类的精确召回分别为一与零点二、零点二与一，比较两种计算。

**解析。** 每类调和分数都是三分之一，宏调和分数仍为三分之一。宏精确和宏召回都为零点六，二者调和后为零点六。差异来自非线性运算不交换，而不是四舍五入。这个组合确实可以由合法计数产生：按“行是真实类、列是预测类”排列，混淆矩阵为 $`\begin{pmatrix}1&4\\0&1\end{pmatrix}`$。第一类共有五条、预测为第一类的只有一条，因此精确率一、召回率 $`\frac{1}{5}`$；第二类共有一条、预测为第二类的共有五条，因此精确率 $`\frac{1}{5}`$、召回率一。六条记录就能完成这个反例，不必依赖无法实现的指标组合。

<a id="eval-1-detail-42"></a>

### 8.8 练习八：恒定概率也能校准吗

**题目。** 正类总体比例为零点一，模型对每个人都报零点一，解释其校准与区分能力。

**解析。** 在总体意义上，条件于唯一预测值后真实比例仍为零点一，所以满足校准。所有样本同分，无法排序区分，标准面积为二分之一。其平方评分为总体不确定性零点零九，若有可用信息且被正确利用，另一个已校准模型可以获得更低评分。校准是必要的一种概率性质，却不是充分的有用性证明。

<a id="eval-1-detail-43"></a>

### 8.9 练习九：推导平方评分的额外风险

**题目。** 真概率为零点三，分别报告零点三与零点八，比较期望平方评分。

**解析。** 真实不可消除部分为零点三乘零点七，即零点二一。诚实报告的额外项为零，总风险零点二一；报告零点八的额外项为零点五平方，即零点二五，总风险零点四六。不要用一次真实结果替代这个期望计算：若该次恰为正，较高报告可能获得更低单次损失，但长期期望仍更差。

<a id="eval-1-detail-44"></a>

### 8.10 练习十：概率平方之后可以保持什么

**题目。** 二分类正类概率都在开区间零到一，对其平方并把负类概率设为一减新值，哪些性质保持？

**解析。** 平方在该区间严格递增，因此全部排序关系和标准排序面积保持。概率值整体变小，原零点五阈值相当于原概率大于等于根号零点五，决策改变；概率校准、平方评分和对数损失也不保证保持。若先分别平方两类概率再归一化，是另一个严格递增映射，仍须区分具体公式。

<a id="eval-1-detail-45"></a>

### 8.11 练习十一：绝对误差与平方误差的目标

**题目。** 九个目标为零、一个为十，常数预测零、一、十分别计算均方和绝对误差。

**解析。** 三个均方误差分别为十、九、九十，最小为一；三个绝对误差分别为一、一点八、九，最小为零。前者追逐均值，后者追逐中位数。一个模型在这两个指标之间出现名次交换是正常的目标冲突，应根据应用损失选择，不能把其中一个指标当作另一个的替代证明。

<a id="eval-1-detail-46"></a>

### 8.12 练习十二：决定系数为负意味着什么

**题目。** 真实值零、一、二，预测都为五，求决定系数并解释基线。

**解析。** 残差平方和为二十五加十六加九，等于五十；真实值围绕评价均值一的平方和为二，所以决定系数为负二十四。它说明相对该测试集均值的平方误差很大。部署基线应使用训练阶段可获得的均值；本题的测试均值只是决定系数分母定义，不能在真实未知目标上直接作为生产预测。

<a id="eval-1-detail-47"></a>

### 8.13 练习十三：相同总体误差是否代表相同人群效果

**题目。** 两个群体样本量九十与十，甲模型错误九个与一个，乙模型错误五个与五个，总体准确率相同，如何评价？

**解析。** 二者总体都错十个，准确率零点九；甲组内错误率均为百分之十，乙分别约百分之五点六和百分之五十。若小组是关键使用对象，乙的退化很大。应报告组内计数和预设要求，不能仅靠总体平均宣称等价；同时小组只有十例，对其总体真实错误率还存在较大抽样不确定性。

<a id="eval-1-detail-48"></a>

### 8.14 练习十四：没有预测的请求放在哪里

**题目。** 系统一处理一百条、正确九十条；系统二只返回八十条、正确七十八条，能否按各自已返回样本准确率说系统二更好？

**解析。** 第二个系统的条件准确率为百分之九十七点五，但覆盖只有百分之八十，二十条未返回请求的后果被隐藏。若无返回算失败，整体成功为百分之七十八；若允许人工接管，应加入接管成本与容量。必须按同一完整服务政策评价，不能让拒绝困难请求自动制造优胜。

<a id="sec-7-1"></a>

<a id="eval-1-detail-49"></a>

### 8.15 练习十五：极低误报的零观察

**题目。** 一千个独立负例中零次误报，能否证明误报率小于百万分之一？

**解析。** 不能。零观察仍兼容不少正的总体误报率；常见近似上界量级为若干除以样本数，而不是一除以无限大。精确上界可由二项分布零次概率 $`(1-f)^{1000}`$ 反解。仅凭这批样本，要论证百万分之一水平远远不足，必须增加独立负例或引入有根据且可验证的结构假设。

<a id="eval-1-detail-50"></a>

### 8.16 练习十六：多标签空集合与缺失标注

**题目。** 一条记录没有任何标注标签，模型也预测空集，是否应得满分？

**解析。** 若标注协议明确确认该记录无任何目标标签，可把完全一致解释为成功；若空白代表尚未标注，评价没有真值，给满分会把未审核记录变成虚假证据。先区分确认阴性与未知状态，再决定指标的空分母约定。技术默认值无法替代数据语义，且这一约定必须在候选比较前固定。

<a id="eval-1-detail-51"></a>

## 9. 进阶研究：指标背后的识别、稳定性与可优化性

<a id="eval-1-detail-52"></a>

### 9.1 非线性比值的估计对象

精确率是两个总体概率的比值。样本中先算比值是自然估计，但其期望一般不等于总体比值，特别是在预测正例很少时。若一个阈值在多数重复样本中完全不报正，偶尔只报一个且恰为真，采用不同零分母约定会显著影响重复平均。这说明报告支持度不是附加装饰，而是判断估计量是否稳定的必要条件。

可以设计一个研究实验：固定真实联合分布，反复生成大小相同的测试集，对比预测正例数量大与小的两个阈值。分别记录未定义频率、条件于非空的精确率均值和含约定值的均值，再与总体精确率比较。评价实验的成功标准不是出现某个特定偏差方向，而是能够解释条件化与约定如何改变被估计的对象。

<a id="eval-1-detail-53"></a>

### 9.2 排序面积相同为什么仍可能无法替换

构造两个模型，使一个在低误报区更好，另一个在较高误报区更好，通过其他区域补偿让总面积相同。若部署只使用低误报区域，后者仍可能明显更差。这个实验揭示面积是积分摘要，不是曲线逐点支配；相同积分不能推出每个工作点相同。实际比较应预先定义感兴趣的区域，保留整条曲线与支持度。

进一步研究可把每日预算加入评价。让不同日期的样本总量和基率变化，对比固定阈值、每日固定数量和全期全局前若干名。即使它们使用同一个模型，得到的命中、平均等待和群体覆盖也会不同。把决策政策当作模型服务的一部分，才能解释为何排序指标改进未必转化为服务收益。

<a id="eval-1-detail-54"></a>

### 9.3 指标能否直接作为训练目标

逐例可微损失通常便于随机梯度训练，排序面积和调和分数则依赖多样本关系或离散阈值，不能简单把测试公式逐条求导。可以使用代理损失、成对损失或者可微近似，但代理风险更低不自动保证任意有限样本目标指标更好。分析需区分总体一致性、函数类限制、优化误差和评价抽样误差，不能把它们压成一句损失函数不对。

一个可执行研究设计是固定数据生成机制，比较对数损失训练与成对排序训练，分别观察概率评分、不同区域排序和固定成本决策。校准和阈值选择只在开发集进行，最终测试保持固定。若排序训练占优但概率质量较差，这不是实验失败，而是揭示目标之间的分工；若所有指标都提高，也不能据此证明它们在所有分布上等价。

<a id="eval-1-detail-55"></a>

### 9.4 含噪标签时到底评价了什么

若观测标签与真实事件不同，指标首先评价的是对观测标签的预测。独立对称翻转、与输入相关的错误、只对高分对象进行确认，都会产生不同偏差。通过扩大样本量只能减小对同一有偏目标的抽样误差，不能自动恢复真实事件性能。应抽取有代表性的审查样本，记录未知状态，必要时建立标签观察模型，并说明可识别条件。

在选择性确认场景中，低分对象几乎没有标签，直接只对已确认对象计算召回甚至没有完整分母。可以采用随机抽查和已知抽样概率的重加权，但需要正概率覆盖各类对象以及可靠标签。如果某类对象永不被观察，其真实错误率就无法只靠现有日志恢复。本章的各种漂亮指标都建立在这些证据条件之上。
