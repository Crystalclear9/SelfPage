## 1. 欠拟合与过拟合是需要证据的解释

<a id="chapter-foundations-02-heading-3"></a>

### 1.1 训练表现差可能意味着几种完全不同的事

如果模型在训练集和验证集上都差，常被称为欠拟合，但这只是起点。模型可能表达能力不足，例如用直线拟合强烈弯曲关系；输入可能遗漏关键信息；标签可能存在大量不一致；优化可能没有收敛；也可能只是指标本身很严格，而合法信息下的最优风险就不低。不同原因需要不同干预，不能一律通过增加网络层数处理。

例如线性回归面对目标 $`Y=X^2+\epsilon`$，在关于零对称的输入分布上，最优斜率可能为零，模型只能用截距表示平均水平。增加训练轮数无法让直线变成抛物线。若加入 $`X^2`$ 特征，仍使用线性参数估计，却能够表达目标结构。这里改善来自表示变化，算法名称没有改变。

反过来，某个足够强的模型训练误差仍高，可能只是学习率太大导致不稳定。降低学习率后训练误差显著下降，说明此前瓶颈至少部分在优化。这个实验不能自动证明模型不受任何表达限制，但能否定“只有增加容量才有用”的单一解释。好的诊断会设计能够区分竞争解释的实验。

<a id="chapter-foundations-02-heading-4"></a>

### 1.2 训练很好而验证差，也不只有过拟合一种原因

过拟合通常指学习过程适应了训练样本中的偶然性，导致新样本风险恶化。但训练与验证差距也可能来自两个集合难度不同、标签规则不一致、时间变化或预处理实现不匹配。如果训练来自成熟用户、验证主要是新用户，差距可能首先反映总体不同，而非在同一个分布上容量过大。

实现错误也可能制造相同外观。训练与验证阶段的类别索引不一致、标准化使用了不同统计量、模型没有正确切换模式，都可能让训练分数很好而验证失效。统计诊断之前，应先核对输入输出契约、样本标签对齐和评价代码。复杂理论无法修复标签错位。

因此，欠拟合和过拟合应被理解为提出假设的语言。要将它们变成更可信的解释，需要控制信息边界、拟合预算与数据来源，再观察改变容量、样本量、正则化和优化后的结果。仅凭一条曲线不能唯一恢复产生它的机制。

<a id="sec-1-1"></a>
### 基础算例：四个误差数字提供的诊断线索

模型甲训练误差零点一、验证零点四；模型乙训练零点三、验证零点三五。如果损失、数据划分和拟合预算一致，乙虽然训练拟合较弱，却在当前验证集上更好。可以怀疑甲对训练样本更敏感，或乙的约束更合适，但还不能把差值零点三直接叫作方差项。

下一步可以对多个训练子样本重复拟合，在同一个固定验证集上观察预测变化；也可以保持模型族不变而增加独立训练数据，查看甲的验证误差是否下降。如果甲只在某个来源上退化，则应研究来源差异；如果延长训练能同时改善两者，优化未完成也是候选原因。每个实验对应一种可被反驳的解释，而不是围绕一个标签找证据。

<a id="deep-dive-1"></a>
### 深入讲解：先区分三种误差来源

表达限制是函数族无法达到理想规律；估计波动是有限训练样本变化导致拟合函数变化；优化限制是算法没有在给定族与目标下达到足够好的经验解。三者可以同时存在。增加容量可能降低表达限制，也可能改变估计敏感性与优化几何；增加数据通常有助于估计，但数据质量或分布也可能同时变化。

平方损失下偏差方差分解提供精确的数学对象，但偏差并不只等于函数族表达误差。正则化、早停、优化算法以及数据处理都可能改变平均预测，从而进入偏差。方差也不只由参数数目决定，而是由整个学习规则对随机输入的敏感程度决定。后面的收缩算例会把这种关系算到具体数字。

<a id="chapter-foundations-02-heading-7"></a>

### 1.3 一个小数据过拟合实验能回答什么

在一个很小的数据子集上尝试把训练误差压低，可以检查模型和代码是否具有基本拟合能力。若连十几个明显可分的样本都无法拟合，优先检查标签、损失、梯度、学习率和数据管道。这个实验有诊断价值，因为它暂时降低了统计难度，集中检查实现与优化。

但成功记住小样本不能证明最终模型会泛化，也不意味着应继续训练直到全数据完全拟合。它只排除部分实现故障。使用强数据增广、标签平滑或正则项时，训练目标本来就可能无法达到零；诊断时需要暂时明确这些机制的作用，避免把设计目标误作错误。

<a id="sec-2"></a>
## 2. 训练、验证与测试承担什么职责

<a id="chapter-foundations-02-heading-9"></a>

### 2.1 三份数据对应三种信息用途

训练集用于拟合模型和预处理状态，验证集用于选择方案，测试集用于评价已经冻结的方案。划分的本质是控制信息用途，不是把文件名改成三个英文单词。只要某份数据影响了特征、超参数、阈值或人工修改，它就进入了开发过程，无论最初被叫作什么。

一个完整方案包括缺失值处理、标准化、特征选择、模型、概率校准和决策规则。若阈值在验证集上选择，它也是被选择的部分；若校准器在某个数据集上拟合，那些数据也承担训练职责。只冻结神经网络权重，而继续根据测试标签调阈值，不能说整个系统已经冻结。

测试集并非神圣到永远不能查看。它的价值在于提供未参与选择的证据。若测试结果暴露实际问题，需要继续修正系统，当然可以使用这些信息；但应承认其已成为开发知识，安排新的外部、未来或重新保留的独立评价。关键是结论与信息历史一致，而不是禁止合理工程迭代。

<a id="sec-2-1"></a>
### 机制展开：验证选择与最终评价的职责不能混用

假设比较两个真实风险相同的候选，它们的验证估计都带有噪声。选择验证值较小者会偏向噪声恰好有利的候选。即使每个候选的验证估计单独无偏，最小值也通常偏低。这个现象来自选择运算，而不是有人故意作弊。

可以构造一个离散算例。每个候选真实风险均为 $`r`$，验证误差独立地以相同概率取 $`r-d`$ 或 $`r+d`$。两候选最小值在四种等可能组合中有三种为 $`r-d`$，一种为 $`r+d`$，所以其期望为 $`r-\frac{d}{2}`$。被选方案的真实风险仍为 $`r`$。验证最优分数的平均乐观偏差为 $`\frac{d}{2}`$，独立测试则不会因为此前的这种选择而同样偏低。

现实候选的噪声往往相关，幅度也不同，上述数值不是通用估计，但机制相同。不断看验证错误、增加特征、尝试随机种子，也会增加适应程度。记录选择预算和保留最终证据，比声称“没有自动搜索，所以没有调参偏差”更准确。

<a id="chapter-foundations-02-heading-11"></a>

### 2.2 数据有限时如何分配

没有适用于所有任务的固定划分比例。训练数据少会影响拟合，验证数据少会让选择不稳定，测试数据少会让最终结论不精确。应结合目标误差、模型复杂度、类别基率和独立单位数决定。稀有事件任务即使总行数很多，测试集中正例也可能不足以稳定评价召回。

交叉验证可以提高开发数据利用率，但需要额外计算，并且不能自动解决所有选择偏差。若用同一交叉验证结果挑选很多方案，再把挑出的平均分当成独立最终成绩，仍然存在选择效应。嵌套交叉验证将选择放在内层，评价放在外层，回答的是完整调参流程的表现。

此外，时间预测不能为了得到更多训练数据而随机打散未来信息。数据少时也必须优先保持评价问题正确。一个方差较大的真实未来测试，通常比一个精确回答错误任务的随机测试更有解释价值；应通过增加未来观察、合并合理批次或报告不确定性改善证据，而不是改变信息边界追求分数稳定。

<a id="sec-3"></a>
## 3. 从数据冻结到最终重训的工作顺序

<a id="chapter-foundations-02-heading-13"></a>

### 3.1 先冻结问题，再建立可回放的数据版本

在训练前写明总体、单位、预测时点、标签窗口、主要损失和主要比较对象。随后保存数据提取逻辑与版本信息，明确哪些记录被排除、哪些标签尚未成熟。版本并不一定需要复制所有原始数据，但必须能够复现当时输入与标签的含义。

划分应在任何会利用标签的选择之前确定。随后只在允许的训练部分拟合预处理。标准化不使用标签，却仍会从数据估计分布状态；其合法范围取决于部署协议。目标编码、相关性筛选和监督降维更直接依赖标签，必须放进每个训练折内，不能先全表拟合再交叉验证。

<a id="chapter-foundations-02-heading-14"></a>

### 3.2 建立实验账本，把修改与假设连接起来

每次实验记录数据版本、划分、变更因素、训练预算、随机设置、验证指标和计算成本。还要用一句话写清假设，例如“近期行为窗口过长可能稀释信号”，而不是只写“尝试方案七”。这样结果不好时仍能积累信息，避免把实验退化成无记忆的参数抽签。

尽量一次改变一个主要因素。若同时换模型、修改标签、扩大数据和更改阈值，即使表现改善，也难以解释来源。实际工程可以为了效率同时修复多处明显问题，但若要形成方法结论，应补充控制实验。实验设计的严格程度应与想要提出的结论强度相匹配。

<a id="chapter-foundations-02-heading-15"></a>

### 3.3 开发分析与最终重训要遵守同一规则

选择完成后，可以按预先规定使用全部开发数据重训，例如把训练与验证合并以增加拟合样本。超参数、停止规则和校准方案需要事先确定，不能一边看测试一边决定重训方式。若早停依赖验证，合并后如何决定轮数也需要规则，例如使用开发阶段确定的轮数或保留新的内部验证。

最后测试应运行完整冻结流程，并报告与主要基线的比较。若重训得到的模型与验证阶段单次模型表现不同，既可能是随机性，也可能因为训练规模改变。应该评价既定重训规则，而不是从多次最终重训中挑测试最好的一次。后一种做法再次把测试变成选择工具。

<a id="chapter-foundations-02-heading-16"></a>

### 3.4 误差分析要通向可验证的下一步

将验证错误按来源、时间、缺失程度或业务类别分组，寻找集中失败区域。然后提出具体解释：是标签噪声、信息缺失、代表性不足、容量限制还是阈值不匹配？每个解释对应不同的数据或模型干预。只列一批失败例子而不设计验证，容易形成事后故事。

例如某渠道错误率高，可能是该渠道输入缺失，也可能是标签延迟不同。可以分别在完整输入子集和标签成熟一致子集比较，排除竞争解释。分组分析经过反复查看也有选择性，应把发现性分析与后续确认分开。被反复挖掘的验证组中出现一个巨大提升，值得继续研究，却不是天然独立的最终证据。

<a id="sec-4"></a>
## 4. 学习曲线与受控诊断实验

<a id="chapter-foundations-02-heading-18"></a>

### 4.1 三种横轴对应三个不同问题

训练轮数曲线研究固定数据上优化过程随时间的变化；样本量曲线研究不同数据规模下学习规则的表现；容量曲线研究不同函数族或结构的折中。三者都可能被叫作学习曲线，但不能混在一起解释。训练更久不等于看到更多独立信息，网络更大也不等于样本量增加。

样本量曲线应尽量保持测试总体、损失和选择规则固定。可以在同一开发训练池中取多个规模的子样本，用相同外部验证集评价，并对抽样重复。嵌套子样本便于比较增量，但多个点相关；独立抽样更直观地展示波动，却同样需要注意类别与组结构。每个规模是否重新调参也会改变曲线含义：固定超参数研究某一规则的规模效应，重新调参研究完整开发流程的规模效应。

时间数据还多一层困难。用更早历史扩大训练量，同时改变了样本年龄与分布，所以性能变化不只是数量效应。可以对不同回溯窗口、近期抽样规模和时间加权作分开实验。若旧数据降低表现，可能是分布过时，而不是“更多数据会伤害学习”的一般结论。

<a id="chapter-foundations-02-heading-19"></a>

### 4.2 常见曲线模式如何形成假设

训练误差很低、验证误差高，并且增加代表性训练数据使验证改善，这支持估计敏感性较强的解释。训练与验证都高且接近，增加数据后都不改善，则可以优先检查表示、目标噪声与优化。两者只是优先级线索，不是互斥诊断：错误的验证协议也可以制造相似图形。

若更大模型降低训练误差但验证没有改善，可以检查正则化、数据量和信息上限；若训练误差也没有降低，则先核对优化预算是否公平。大模型每步成本高，在相同步数和相同时间两种预算下可能得出不同结论。报告比较采用哪种资源约束，可以让读者判断改善是否值得。

验证误差有波动时，不应把每一个小峰值都解释为机制变化。绘制重复实验的分布、误差范围和单次轨迹，比只画平滑后的最优曲线更诚实。平滑有助于看趋势，但不能消除选择噪声，更不能把平滑曲线的最低点当作独立测试值。

<a id="chapter-foundations-02-heading-20"></a>

### 4.3 早停是一种数据驱动的正则化

训练过程中选择验证损失最低的轮次，相当于在参数轨迹上选择模型。它可能在完全拟合噪声之前停止，也可能仅避免优化不稳定。早停产生的偏好依赖初始化、优化器、学习率和模型结构，不是一个与其他设置无关的固定正则项。

若每轮都看同一验证集，选择最低点同样有乐观偏差。相邻轮次高度相关，因此不能简单把轮数当作独立候选数量，但也不能因此说没有选择效应。最终应使用独立数据评价早停规则，或在外层评估中重新运行完整早停过程。

选定轮次后用全部开发数据重训，需要说明训练规模改变时如何决定步数。固定轮数意味着样本遍历次数相同，固定更新步数意味着计算与数据重复方式不同。两者都可能合理，但应由协议决定，不能看最终测试后再挑更有利的一种。

<a id="sec-5"></a>
## 5. 泛化范围、样本相关性与分布变化

<a id="chapter-foundations-02-heading-22"></a>

### 5.1 泛化是一句带有对象范围的话

同来源随机测试主要支持相近分布的新样本；跨时间测试支持指定时间跨度下的未来表现；跨医院、设备或地区测试研究来源迁移；留出完整实体研究陌生对象。一个测试集可以覆盖多个维度，但不能自动涵盖所有可能部署。应在结论中直接说明证据范围。

训练测试来源相同也不保证真正独立。重复记录、共享设备、家庭成员和同一会话都可能引入相关性。若训练中包含某个病人的早期图像，测试同一病人的后期图像，模型可能利用身份相关信息。对于既有病人的随访预测这可以合法；对于新病人筛查就需要另一种划分。

<a id="chapter-foundations-02-heading-23"></a>

### 5.2 有效样本量的一个可计算例子

设某个平稳序列的单点方差为 $`\sigma^2`$，间隔 $`k`$ 的相关系数为 $`\rho_k`$。展开样本均值方差，可得

$$
\operatorname{Var}(\bar Z)=\frac{\sigma^2}{n}
\left[1+2\sum_{k=1}^{n-1}\left(1-\frac{k}{n}\right)\rho_k\right].
$$

独立样本时所有相关项为零，才恢复 $`\frac{\sigma^2}{n}`$。若相关系数为 $`\rho^k`$ 且 $`\vert \rho\vert <1`$，在样本较大且边界效应可忽略时，括号约为 $`\frac{(1+\rho)}{(1-\rho)}`$。对于 $`\rho=0.8`$，方差约是独立情形的九倍，因此估计均值的有效样本量约为原来的九分之一。

这里的有效样本量仅针对这个均值估计问题及其相关结构，不是可以套用到任意模型复杂度的统一数字。不同统计量、分组和依赖方式会有不同影响。这个算例的意义在于提醒：连续收集九千条强相关记录，可能远不等于九千次独立观察。

分组数据也类似。若每组有 $`m`$ 条记录，组内相关系数约为 $`r`$，在简化的交换相关模型下，均值方差的设计效应为 $`1+(m-1)r`$。增加同组记录仍可能有用，但新增独立组通常提供不同的信息。收集数据前应先明确需要泛化到更多记录还是更多实体。

<a id="chapter-foundations-02-heading-24"></a>

### 5.3 分布变化会让传统诊断失效

若训练和验证输入分布不同，即使模型在各个区域的误差没有变化，总体平均误差也可能改变。比如验证集中困难区域比例更高，平均损失自然上升。应先按区域比较条件表现，再分析组成变化，避免把所有差距解释为参数过多。

若标签条件机制也改变，例如政策更新导致同样行为对应不同结果，单纯重加权输入不一定有效。需要新标签或明确的机制假设。时间验证的价值不仅是模仿未来，还可以暴露这种脆弱性；不过一个时间切片表现稳定，不能保证所有未来都稳定。

<a id="chapter-foundations-02-heading-25"></a>

### 5.4 为什么代表性比重复数量重要

如果错误集中于训练中罕见的设备类型，继续采集大量常见设备数据可能改善总体平均，却无法解决该组问题。若标签错误集中于某个来源，增加同样错误的记录可能强化错误模式。数据扩充要与误差分解和覆盖诊断连接，而不是只追求行数。

主动收集困难区域也会改变训练分布。它可以提高学习效率，但评价仍应按照目标总体，必要时记录采样概率并使用适当加权。选择性采样得到的原始错误比例不能直接代表部署总体。数据获取策略与评价协议必须一起设计。

## 6. 偏差方差分解的完整推导

<a id="sec-6-1"></a>
### 偏差方差分解中的期望范围

固定一个测试输入 $`x`$。设新标签满足 $`Y=m(x)+\epsilon`$，其中 $`E[\epsilon\mid x]=0`$，$`\operatorname{Var}(\epsilon\mid x)=\sigma^2(x)`$。模型来自随机训练集与算法随机性，且新标签噪声在给定输入后独立于训练过程。定义平均预测 $`\bar f(x)=E_{D,U}[\widehat f_{D,U}(x)]`$。

将误差写为三部分：$`\widehat f-Y=(\widehat f-\bar f)+(\bar f-m)-\epsilon`$。平方后有三个平方项与三个交叉项。第一项相对于训练随机性的均值为零，噪声条件均值也为零，结合独立性可知交叉项在相应期望下消失。因此

$$
E_{D,U,Y\mid x}[(\widehat f_{D,U}(x)-Y)^2]
=[\bar f(x)-m(x)]^2
+\operatorname{Var}_{D,U}(\widehat f_{D,U}(x))
+\sigma^2(x).
$$

偏差平方描述平均预测与条件均值的系统差异；估计方差描述重新抽样并训练后预测的波动；噪声项描述固定合法信息下标签的条件不确定性。三个项分别涉及不同随机对象。单个模型在不同输入上输出差异很大，不等于这里的估计方差很大。

<a id="chapter-foundations-02-heading-28"></a>

### 6.1 从固定输入到总体预测风险

再对测试输入分布取期望，就得到总体均方预测误差分解。若噪声方差随输入变化，最后一项是 $`E_X[\sigma^2(X)]`$，不是一个处处相同的常数。训练和测试分布改变时，三个项的加权方式也会改变；因此偏差方差讨论应固定目标输入分布。

如果只研究预测条件均值的误差 $`E[(\widehat f-m)^2]`$，不包括新标签噪声，便只有前两项。若研究相对于最优条件均值预测器的过剩平方风险，也得到前两项。教材中有时省略噪声，是因为分析对象不同，不能把公式表面差异当作互相矛盾。

二阶矩存在是这套分解的基本要求。如果目标重尾到二阶矩不存在，均方风险可能无穷，讨论有限的偏差方差数值就失去依据。可以采用其他损失、稳健方法或尾部假设，但需要重新说明分析对象。

<a id="chapter-foundations-02-heading-29"></a>

### 6.2 训练集随机与优化随机还可以继续分开

利用全方差公式，固定输入上的总预测方差可写为

$$
\operatorname{Var}_{D,U}(\widehat f)
=\operatorname{Var}_D(E_U[\widehat f\mid D])
+E_D[\operatorname{Var}_U(\widehat f\mid D)].
$$

第一项是训练数据变化造成的平均模型变化，第二项是在同一训练数据上由初始化、批次顺序等造成的变化。反复使用同一数据改随机种子主要估计第二种现象，不能直接代表重新收集训练样本的第一种。两者都可能影响工程稳定性，但证据来源不同。

若训练算法完全确定，第二项为零，第一项仍可能很大；若数据量很大而优化对初始化敏感，第二项也可能重要。对结果波动的诊断应先确定随机性来自哪一层。否则增加随机种子次数可能只精确估计了一个并非主要瓶颈的分量。

<a id="chapter-foundations-02-heading-30"></a>

### 6.3 为什么训练验证差距不是方差

训练误差使用的数据同时决定模型，因此误差与拟合过程相关；验证误差使用独立对象。这两个平均值之差包含训练适应带来的乐观性，也受样本难度、正则项、模式和有限波动影响。偏差方差分解中的方差则要求在固定输入上对重复训练过程取方差，两者定义并不相同。

可以构造有偏但低方差的常数模型：无论训练数据是什么都输出零，估计方差为零，但如果训练与测试总体均值不同，两者误差仍可能差很大。也可以有高训练随机方差，但某次训练验证偶然接近。用单次差距当作方差数值，会忽略随机对象与条件完全不同。

<a id="chapter-foundations-02-heading-31"></a>

### 6.4 分类任务中的限制

对零一错误，没有与平方损失同样的“偏差平方加方差加噪声”恒等式直接适用。可以发展其他分类偏差方差定义，但解释和项的符号可能不同。更一般的损失还可以通过条件最优风险、散度和适当评分规则分解，不能机械把回归公式复制过去。

这不妨碍在分类中使用“更稳定”“更有表达能力”的直觉，只是要把直觉与精确数值区分。若需要证明，先指定损失与随机对象，再选择合适理论工具。对数损失的条件过剩风险与 KL 散度关系，可在[决策论与代理损失](05-决策论代理损失与统计一致性.md)继续研究。

## 7. 收缩估计：用精确算例理解正则化

<a id="chapter-foundations-02-heading-33"></a>

### 7.1 一个只有均值参数的模型

设训练标签为 $`Y_i=\theta+\epsilon_i`$，噪声独立、均值为零、方差为 $`\sigma^2`$。样本均值 $`\bar Y`$ 无偏，方差为 $`\frac{\sigma^2}{n}`$。考虑收缩估计器 $`\widehat\theta_a=a\bar Y`$，其中 $`a`$ 是事先固定的实数。其偏差为 $`(a-1)\theta`$，方差为 $`\frac{a^2\sigma^2}{n}`$，估计均值参数的均方误差为两项之和。

若预测一个独立新标签，还要加上新标签噪声 $`\sigma^2`$。因此参数估计误差与未来标签预测误差相差一个不可约噪声项。用这种只有一个参数的模型，就能说明正则化为何可能改善泛化，而不需要把所有现象归结为高维复杂性。

取 $`\theta=2,\sigma=4,n=16`$，样本均值方差为一。不同收缩强度给出下表，所有数字是理论值。

| 收缩系数 | 偏差平方 | 估计方差 | 参数估计均方误差 | 新标签预测均方误差 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 4 | 0 | 4 | 20 |
| 0.5 | 1 | 0.25 | 1.25 | 17.25 |
| 0.8 | 0.16 | 0.64 | 0.8 | 16.8 |
| 1 | 0 | 1 | 1 | 17 |
| 1.5 | 1 | 2.25 | 3.25 | 19.25 |

无偏估计器不是均方误差最优的充分条件。适度收缩引入偏差，却更大幅度降低方差；收缩过强则偏差占优。系数超过一在这个例子中同时增加偏差和方差，表现更差，但这也不是所有估计问题的普遍规律。

<a id="chapter-foundations-02-heading-34"></a>

### 7.2 求出理论最优收缩强度

对 $`M(a)=(a-1)^2\theta^2+\frac{a^2\sigma^2}{n}`$ 求导，得到 $`2(a-1)\theta^2+\frac{2a\sigma^2}{n}=0`$，因此

$$
a^*=\frac{\theta^2}{\theta^2+\frac{\sigma^2}{n}}.
$$

本例为四除以五，即零点八。信号相对噪声越强，最优系数越接近一；样本数增大时，样本均值更稳定，所需收缩也减弱。若真实均值为零，完全收缩恰好最优，但我们事先通常不知道真实均值，所以这是用于理解机制的理想参照，而不是可以偷看答案的调参规则。

若优化平均平方损失加 $`\lambda\theta^2`$，其解为 $`\frac{\bar Y}{(1+\lambda)}`$，即 $`a=\frac{1}{(1+\lambda)}`$。因此本例理想 $`\lambda`$ 为零点二五。真实任务中需要训练或验证方法选择，而不能用测试标签估计最优收缩后再声称独立评价。

<a id="chapter-foundations-02-heading-35"></a>

### 7.3 用模拟核对数学对象

下面代码直接模拟大量独立训练均值，而不是把一个数据集重复当作新数据。正态假设使训练均值可以直接采样；前面的偏差方差公式本身只需要独立噪声与有限方差，不要求正态。代码不写任何文件。

```python
import numpy as np

rng = np.random.default_rng(2026)
theta, sigma, n = 2.0, 4.0, 16
repeats = 200_000
training_means = theta + sigma / np.sqrt(n) * rng.standard_normal(repeats)
new_labels = theta + sigma * rng.standard_normal(repeats)

for a in [0.0, 0.5, 0.8, 1.0, 1.5]:
    predictions = a * training_means
    bias_squared = (predictions.mean() - theta) ** 2
    variance = predictions.var(ddof=0)
    parameter_mse = np.mean((predictions - theta) ** 2)
    prediction_mse = np.mean((predictions - new_labels) ** 2)
    assert np.isclose(parameter_mse, bias_squared + variance)
    expected = (a - 1) ** 2 * theta ** 2 + a ** 2 * sigma ** 2 / n
    print(a, round(parameter_mse, 4), round(expected, 4),
          round(prediction_mse, 4))
```

模拟中的经验偏差平方与经验方差之和，恰好等于相对于真实均值的经验均方误差；这是有限数组的代数恒等式。新标签预测误差只会近似等于再加十六，因为额外噪声和交叉项有蒙特卡洛波动。不要为了让输出完全等于理论值而改随机种子挑结果，波动本来就是实验的一部分。

<a id="chapter-foundations-02-heading-36"></a>

### 7.4 集成如何降低方差，又为何不能消除一切

设多个预测器在固定输入上的方差均为 $`v`$，两两协方差均为 $`c`$，平均 $`B`$ 个模型后的方差为 $`\frac{v}{B}+\frac{(B-1)c}{B}`$。若误差独立，协方差为零，平均可以将方差降至原来的 $`\frac{1}{B}`$；若高度相关，收益明显受限。使用同一数据和相似结构训练的模型通常不是独立的。

若每个预测器具有相同系统偏差，简单平均不会消除它。集成可以平滑随机变化，却不能自动修复标签定义错误、未来泄漏或缺少关键输入。多样性需要与单模型质量一起考虑：随机生成一批很差但不相关的模型，也不保证最终有价值。

## 8. 交叉验证、嵌套选择与评价对象

<a id="chapter-foundations-02-heading-38"></a>

### 8.1 普通交叉验证在平均什么

将开发数据分成 $`K`$ 折，每次用其中 $`K-1`$ 折拟合完整流程，在剩余一折评价，再汇总预测或损失。它主要估计在相应训练规模下，该学习规则对类似新对象的表现。每折训练规模小于使用全部开发数据，最后重训的模型不完全等同于任意一折模型。

若各折大小不同，按折损失简单平均与按全部验证样本平均可能不同。可加性损失通常可以汇总所有折的逐样本损失；非线性指标例如某些排序或宏平均指标，需要说明先按折计算还是合并预测计算，两者回答的对象未必相同。不能只写“使用交叉验证”而省略指标汇总规则。

分类分层可以减少各折类别比例波动，但不能修复实体相关或时间泄漏。分组约束与时间约束优先由任务决定。若某个组只有一个正例，盲目要求每折都含正例可能无法实现，应调整折数、指标或评价设计，并准确说明稀有事件证据不足。

<a id="chapter-foundations-02-heading-39"></a>

### 8.2 为什么预处理必须放在折内

假设有大量纯噪声特征，先在全数据上挑与标签相关性最高的一列，再交叉验证。被挑中的相关性本来就是全数据噪声的幸运结果，验证折标签已经影响特征选择。因此即使后续回归器只用训练折拟合，验证也不再模拟对新样本的真正未知情况。

正确流程是每折重新在训练部分选特征、估计填补数值、拟合缩放、训练模型，再对该折验证数据只做已学变换与预测。对于目标编码，需要进一步避免训练样本通过自身标签直接编码自身；其内部交叉拟合或平滑方式属于训练算法的一部分，同样需要被外层评价包含。

特征工程中的纯确定规则，例如把日期拆成年月，只要不根据当前数据估计状态，通常不需要每折拟合。但规则是否被人工选择仍可能利用开发信息。区分“变换执行时无拟合”与“选择变换时是否看过数据”，可以更完整地描述信息历史。

<a id="chapter-foundations-02-heading-40"></a>

### 8.3 嵌套交叉验证的具体规模

假设有一百个独立对象，外层五折，每次留下二十个作评价，剩余八十个进入内层。内层四折时，每次用六十个训练、二十个验证，从候选中选择方案；随后用该外层的八十个对象按选定规则重训，预测外层二十个。外层所有预测汇总后，评价的是在八十个对象上执行这套选择与重训程序的表现。

最终交付时可以在全部一百个对象上按既定选择程序再拟合，但外层估计并不是对最终某个固定权重的完全相同风险测量，而是对学习流程的外部表现证据。样本量差异可能带来偏差方向或强度变化，不能默认总是某个固定数值。记录外层所选超参数的波动，也有助于判断选择是否稳定。

嵌套设计计算开销较大。若候选和预算在之前数据上已确定，并有可靠独立测试，未必每次都需要嵌套交叉验证。方法选择应服务证据目标，而不是堆叠看似严谨的步骤。重要的是外部评价不被内层选择使用，并准确说明评估的是固定方案还是调参程序。

<a id="chapter-foundations-02-heading-41"></a>

### 8.4 时间与分组交叉验证

滚动时间评价中，每次训练只使用当时已经成熟的样本，再预测后续时间段。若目标观察期跨越边界，需要按真实训练可用性剔除尚未成熟的标签。某些任务还需要间隔或净化规则来减少共享事件和重叠标签造成的依赖，但是否需要、间隔多长，应由预测对象与采样机制决定。

分组交叉验证则让同一实体或来源完整留出。留一医院评价测试跨医院迁移，留一用户评价陌生用户泛化，二者都不能简单视为普通独立样本平均。只有少数来源时，来源间变异的估计会很不稳定，应报告各来源结果而不是仅呈现平均值。

<a id="uncertainty"></a>
## 9. 不确定性、配对比较与实验预算

<a id="chapter-foundations-02-heading-43"></a>

### 9.1 一个分数包含多种不确定性

最终成绩的波动可以来自训练随机性、训练样本变化、测试样本变化和未来环境变化。重复随机种子、重新抽训练集、重采样测试集与跨来源测试分别提供不同证据。没有一个单独的标准差可以自动覆盖全部来源。

对于已经冻结的分类器，如果测试错误指示近似独立同分布，准确率的标准误差可用二项模型近似为 $`\sqrt{\frac{p(1-p)}{n}}`$。准确率约零点九、样本一百时，近似标准误差是零点零三；样本一千时约零点零零九四九。接近边界或样本少时，应使用更合适的区间而不是机械正态近似。

这个计算条件于已经冻结的模型，不包含训练样本变化。若同一用户产生多条测试记录，独立二项假设也可能不成立，需要按组重采样或相应模型。严格说明区间控制什么，比只给出更多小数位更有价值。

<a id="chapter-foundations-02-heading-44"></a>

### 9.2 同一测试集比较应利用配对结构

设两模型在相同样本上的错误指示分别为 $`e_i^A,e_i^B`$，定义差值 $`d_i=e_i^A-e_i^B`$。平均差直接估计错误率差，而其波动取决于模型在哪些样本上意见不同。把两个错误率各自的方差当作相互独立相加，会忽略共享样本的协方差。

例如一千条测试中，甲错乙对有三十条，甲对乙错有十条，其余两者一致。乙的错误率比甲低两个百分点。差值分布有三十个一、十个负一、其余零，均值零点零二，二阶矩零点零四，独立样本近似标准误差约为 $`\sqrt{\frac{(0.04-0.02^2)}{1000}}\approx0.00629`$。这是展示配对信息的计算，不自动涵盖多次模型选择、分组相关或所有显著性检验条件。

只报告平均差仍不够。应结合实际成本、分组退化与区间，判断两个百分点是否有实际意义。统计上可区分不等于工程上值得使用，工程收益很大但区间宽也可能需要补充数据，而不是立刻否定方法。

<a id="chapter-foundations-02-heading-45"></a>

### 9.3 交叉验证折间方差不是简单独立重复

不同折训练集大量重叠，模型和误差估计因而相关。将折成绩标准差除以折数平方根，当成完全独立重复的标准误差，通常缺少依据。重复随机划分也可能共享大量样本，不能只靠增加划分次数让实际信息无限增加。

可以使用更合适的重采样、外层重复或按独立单位设计评价，但仍要说明统计假设。对于少量医院、年份或设备来源，没有任何重采样技巧能够凭空创造更多独立来源。报告来源级结果与限制，往往比一个看似精确的总体区间更有用。

把相关性写进公式，更能看清“多分几折”为什么不会自动获得同等数量的独立证据。若 $`K`$ 个折成绩为 $`E_1,\ldots,E_K`$，则

$$
\operatorname{Var}\!\left(\frac1K\sum_kE_k\right)
=\frac1{K^2}\left[\sum_k\operatorname{Var}(E_k)+2\sum_{j<k}\operatorname{Cov}(E_j,E_k)\right].
$$

在一个仅供说明、各折均值相同的等方差、等相关模型中，设每折方差 $`\sigma^2`$、两折相关系数 $`\rho`$，结果为 $`\frac{\sigma^2[1+(K-1)\rho]}{K}`$。取 $`K=5`$、$`\rho=0.5`$，真实均值方差是 $`0.6\sigma^2`$，假定独立得到的却是 $`0.2\sigma^2`$，标准误差相差 $`\sqrt3`$ 倍。这里相关系数是示意设定，不能从训练集重叠比例直接认定 $`\rho=0.5`$；实际相关性取决于学习器、数据与损失。

更细的一点是：等相关模型下，折间样本方差（以 $`K-1`$ 为分母）的期望为 $`\sigma^2(1-\rho)`$，共享的数据扰动可能在各折一起升降，因而被折间差值抵消。折分数看起来很接近，也不能证明总体不确定性很小。对相同测试单位比较两套固定模型时，可以分析逐单位损失差；对重新训练和选择的整个流程，则必须把相应学习随机性纳入设计。这两种不确定性对象不能用同一个“折标准差”标签混过去。


<a id="chapter-foundations-02-heading-46"></a>

### 9.4 多次试验与选择预算

若尝试很多候选，最好的验证分数通常包含更多幸运成分。对称噪声算例还可以扩展：$`M`$ 个候选的独立噪声各为正负 $`d`$，只有全部为正时最小噪声为正，其余情况均为负，因此最小噪声期望为 $`-d+\frac{2d}{2^M}`$。候选越多，最优估计越趋向负噪声端。

真实候选并不独立，但反复选择仍值得记录。预先确定主要指标与有限实验预算，可以减少无意识的指标挑选。若发现意料之外的分组规律，可以明确将其作为探索结果，再在新数据确认。把探索与确认区分开，允许充分研究，也保持结论可信。

<a id="interpolation"></a>
## 10. 插值、病态方向与双下降

<a id="chapter-foundations-02-heading-48"></a>

### 10.1 零训练误差不是充分诊断

插值指模型完全拟合训练标签。传统直觉认为插值必然过拟合，但现代高容量模型中，插值后仍可能有良好泛化，也可能极差。关键在于哪一个插值解被选择、数据几何如何、标签噪声多少，以及未见输入与训练输入的关系。

线性过参数模型通常有无穷多个插值解，最小范数解与任意添加大幅零空间分量的解可以训练误差完全相同，却在新输入上表现不同。训练目标不能区分这些解，优化路径、初始化或显式约束会带来偏好。这说明只报告参数数量和训练误差，无法完整描述学习系统。

<a id="chapter-foundations-02-heading-49"></a>

### 10.2 奇异值揭示不稳定从哪里出现

对固定设计矩阵 $`X`$，正确线性模型 $`y=X\beta+\epsilon`$，噪声协方差为 $`\sigma^2I`$。在满列秩下，最小二乘参数协方差为 $`\sigma^2(X^\top X)^{-1}`$。若奇异值为 $`s_j`$，相应右奇异方向的参数方差为 $`\frac{\sigma^2}{s_j^2}`$。小奇异值意味着数据对该方向约束弱，噪声却被除以很小的数而放大。

这不是说所有小尺度参数方差都必然造成大预测风险。测试输入在对应方向的变化也很重要，完整预测方差涉及测试协方差与参数协方差的迹。若部署几乎不沿某方向变化，参数不稳定未必显著影响预测；若部署变化很大，则风险突出。参数误差与预测误差需要通过输入几何联系。

<a id="chapter-foundations-02-heading-50"></a>

### 10.3 岭回归逐方向抑制噪声

对平均平方损失加 $`\lambda\Vert \beta\Vert ^2`$，岭解在奇异方向上的信号收缩因子为 $`\frac{s_j^2}{(s_j^2+n\lambda)}`$，噪声方差为 $`\frac{\sigma^2s_j^2}{(s_j^2+n\lambda)^2}`$。它减少小奇异方向的噪声放大，同时引入收缩偏差。这是第七节标量机制在多个不同几何方向上的扩展。

取某方向真实系数为一、奇异值零点一、噪声标准差零点一。最小二乘该方向方差为一、偏差为零。若 $`n\lambda=0.01`$，收缩因子为二分之一，偏差平方为零点二五，方差也为零点二五，参数均方误差由一降为零点五。这个改善完全可以由代数解释，无需依赖模糊的“让模型简单一点”。

<a id="chapter-foundations-02-heading-51"></a>

### 10.4 双下降是现象族，不是普遍定律

某些实验中，风险随模型容量先下降、接近插值阈值时上升、进一步增加容量后又下降，称为双下降。病态方向与噪声放大可以解释其中一些峰值机制，最小范数或优化隐式偏好也可能影响过参数一侧。但并非所有数据、损失和训练流程都出现同样曲线。

容量还可以用特征数量、网络宽度、训练时间等不同方式改变，它们不等价。强正则化、噪声水平和特征结构会改变或消除峰值。遇到非单调结果，应先确认协议和预算，再研究具体机制，避免把任何先升后降都当成同一理论的验证。

<a id="case-study"></a>
## 11. 一个完整项目的诊断与选择记录

<a id="chapter-foundations-02-heading-53"></a>

### 11.1 初始结果与三个竞争解释

假设做一个连续目标预测，现有模型训练均方误差四，验证十六，训练均值基线验证二十。模型已经利用了一些信息，但差距仍大。团队提出三种解释：模型对训练样本敏感，验证来源更难，或者训练阶段的目标与验证计算不一致。

先核对损失，发现训练数字包含增强输入而验证使用原始输入，且训练日志对批次采用不同权重。统一到相同模式、相同损失和逐样本汇总后，训练误差变为五，验证仍为十六。原始差距数字不能直接解释，但差距仍值得研究。然后按来源分层，发现一个新增设备来源贡献了大部分错误。

<a id="chapter-foundations-02-heading-54"></a>

### 11.2 用控制实验区分数据量和来源效应

团队构造两条曲线：在旧来源内部增加训练样本，旧来源验证误差从九降到七；新增来源误差几乎不变。再补充少量有代表性的新来源训练数据，后者误差明显改善。这支持覆盖不足的解释，而不是“只要在旧来源继续堆数据就能解决”。

同时比较正则化强度。在相同来源与相同样本量下，适度正则化降低多次抽样之间的波动，但仍不能完全替代新来源数据。两个干预处理不同瓶颈，可以共同有效。记录这些对照比只报告最后总误差下降，更能说明方法为何改善以及何处仍不确定。

<a id="chapter-foundations-02-heading-55"></a>

### 11.3 最终评价完整流程

团队在开发阶段固定采样策略、特征、正则系数选择规则与重训轮数。最终使用更晚且未参与上述分析的月份评价，按来源给出样本量与损失，并和基线做同样本配对比较。新增来源样本少，因此相应区间较宽，报告同时说明这一限制。

若未来来源继续变化，当前测试不能保证永久有效。团队设置输入覆盖与标签成熟后的误差监控，定期按既定窗口回放更新流程。监控发现问题后可以开启新开发周期，但每次新的选择仍要有相应独立证据。一个可靠流程不是一次性拿到最高分，而是让修改、证据与结论始终对齐。

<a id="sec-7"></a>
## 12. 分层练习与详细解析

<a id="chapter-foundations-02-heading-57"></a>

### 12.1 定义练习：方差究竟对什么取

**题目。** 一个固定模型对输入一输出十，对输入二输出一百。有人说输出差异很大，所以模型估计方差很大。这个说法有什么问题？

**解析。** 偏差方差分解中的估计方差固定输入，对重新抽样的训练集和算法随机性取方差。不同输入对应不同真实规律，输出本来就可以相差很大。需要在同一个输入上重复训练并比较预测，才能研究相关估计波动。还要区分只改变随机种子与重新抽训练集，它们覆盖不同随机来源。

<a id="chapter-foundations-02-heading-58"></a>

### 12.2 计算练习：收缩是否值得

**题目。** 训练数据来自均值三、噪声标准差六的总体，样本量三十六。比较无收缩与系数零点九的参数均方误差和新标签预测误差，并求理想最优系数。

**解析。** 样本均值方差为 $`\frac{36}{36}=1`$。无收缩参数均方误差为一，新标签预测误差为三十七。系数零点九的偏差平方为 $`(-0.1\times3)^2=0.09`$，方差为零点八一，总和零点九，预测误差为三十六点九。理想系数为 $`\frac{9}{(9+1)}=0.9`$。它依赖未知真实均值，因此只能作为理论参照，实际应通过允许的信息选取。

<a id="chapter-foundations-02-heading-59"></a>

### 12.3 选择偏差练习：单个无偏为何最小值有偏

**题目。** 三个同风险候选的验证噪声独立取正负零点零二。求最小验证分数的期望偏差。如果用独立测试评价被选模型，其期望风险是否同样降低？

**解析。** 只有三者噪声全正的情况，即概率八分之一，最小噪声为正零点零二；其余八分之七为负零点零二。期望为 $`\frac{0.02}{8}-7\times\frac{0.02}{8}=-0.015`$。被选模型真实风险并未降低，独立测试在相应无偏条件下仍估计真实风险。最优验证分数的改善包含选择幸运，而不是凭空产生预测信息。

<a id="chapter-foundations-02-heading-60"></a>

### 12.4 管道练习：先全表筛特征的问题

**题目。** 先在全表选择与标签相关性最高的十个特征，再对这十列进行五折交叉验证，为何会乐观？如何修正？

**解析。** 筛选已经使用了每个验证折的标签，那些标签通过特征选择影响最终预测。修正是在每一训练折内独立筛选，再把筛选规则用于该折验证。若还要通过交叉验证选择特征数量，应把这个选择放入内层，由外层或独立测试评价完整流程。只把最后的回归器放进折内并不充分。

<a id="sec-7-1"></a>
### 边界追问：验证更低是否一定泄漏

**题目。** 训练损失零点八，验证损失零点六，是否必然表示验证泄漏？

**解析。** 不必然。训练可能开启强增广或 dropout，包含额外正则项，采用不同样本权重，或训练样本更难。先用同一冻结模型、相同模式、相同损失定义分别评价两份数据，再核对采样差异和拟合边界。如果差异仍存在，也可能是有限抽样波动。泄漏需要从信息流找到证据，不能仅由两数大小推出；反过来，训练低于验证也不能证明没有泄漏。

<a id="chapter-foundations-02-heading-62"></a>

### 12.5 相关性练习：更多行不等于更多独立证据

**题目。** 某平稳序列有九千条记录，相关系数近似为 $`0.8^k`$。用样本均值估计总体均值时，大样本近似有效样本量是多少？为何不能直接把答案用于所有分类模型？

**解析。** 均值方差设计效应约为 $`\frac{(1+0.8)}{(1-0.8)}=9`$，所以有效样本量约为一千。这只针对给定序列结构下的均值估计。分类器的泛化取决于损失、模型、输入依赖和采样方式，不存在由这个单一数值自动决定的通用风险界。若相关结构估计不准，近似也会变化。

<a id="chapter-foundations-02-heading-63"></a>

### 12.6 集成练习：相关性限制收益

**题目。** 十个预测器在固定输入上的方差均为四，两两协方差为三。平均后的方差是多少？若每个模型偏差为二，平均后的偏差平方是否降低？

**解析。** 方差为 $`\frac{4}{10}+9\times\frac{3}{10}=3.1`$，远大于完全独立时的零点四。平均预测的偏差仍为二，偏差平方仍为四。高相关模型提供的独立信息有限，集成不会自动消除共同系统错误。若模型均值不同，则应按实际均值和协方差矩阵重新计算。

<a id="chapter-foundations-02-heading-64"></a>

### 12.7 交叉验证练习：评估的是哪个训练规模

**题目。** 一百个独立对象做外层五折、内层四折嵌套交叉验证。内层单次拟合、外层重训和最终交付分别最多使用多少对象？外层成绩是否就是最后全数据模型的精确风险？

**解析。** 内层单次拟合使用六十个，内层验证二十个；选定方案后外层重训使用八十个，外层测试二十个；最终可按既定流程使用全部一百个。外层成绩评价的是相应训练规模上的完整选择规则，并提供其外部泛化证据，不等于最终某组固定权重的精确总体风险。它还包含有限测试波动，不能通过平均折数消除所有不确定性。

<a id="chapter-foundations-02-heading-65"></a>

### 12.8 研究练习：设计能够区分机制的曲线

**题目。** 某模型增加训练样本后验证误差反而升高。请提出至少四个竞争解释，以及对应检查。

**解析。** 新样本可能来自不同分布，应按来源和时间分组；新样本标签质量可能更差，应复核噪声与成熟条件；固定计算预算可能让更大数据未被充分优化，应比较相同遍历次数与相同时间；正则和学习率可能不适合新规模，应事先规定是否重新调参；还可能只是验证波动，应重复合理抽样并报告不确定性。应先区分这些机制，再讨论是否出现更深的非单调学习现象。

<a id="chapter-foundations-02-heading-66"></a>

### 12.9 理论练习：哪些期望使交叉项消失

**题目。** 在偏差方差推导中，如果测试标签不是独立新标签，而是训练时看过的同一个标签，为什么不能原样得到预测风险分解？

**解析。** 训练预测已经依赖该标签噪声，$`E[(\widehat f-\bar f)\epsilon]`$ 不再必然为零。训练算法可能特意拟合这部分噪声，从而降低训练残差。原推导使用了新标签噪声与训练过程的条件独立性。仍然可以建立包含协方差项的恒等式，但不能把它直接删掉；这个差别正与训练乐观性有关。
