## 1. 表示改变了什么，不能改变什么

<a id="detail-1"></a>

### 1.1 原始数值并不自动等于合适的表示

一列时间戳、一个城市编号或一段字符串，只规定存储方式，没有完整规定模型应该利用的结构。时间戳可以包含趋势、周期和距离某事件的间隔；城市编号通常只是名称；字符串可以同时含语义、格式和数据来源。算法看到的结构由表示与模型共同决定，而不是由人类看到列名后产生的直觉决定。

例如线性模型直接使用小时数，会认为二十三点与零点相距二十三个单位。若任务主要受日周期影响，可以使用正弦与余弦表示：对小时 $h$ 取 $\sin(2\pi h/24)$ 与 $\cos(2\pi h/24)$。这样相邻时刻在圆上接近，且两列合起来能够区分一个周期内的位置。只保留正弦会让某些不同时间具有同样数值，可能丢失必要信息。

表示不是越复杂越好。加入大量高阶交互可以让线性模型形成复杂边界，但也增加估计与计算负担。手工特征还可能引入错误不变性，例如把所有金额按个人均值归一化，会弱化绝对消费规模；这对关注相对变化的任务有用，对预测总金额却可能删掉关键信息。每个变换都应说明希望保留或消除什么。

<a id="detail-2"></a>

### 1.2 确定变换不能创造原始输入中没有的信息

若 $Z=T(X)$ 是确定变换，知道 $X$ 的理想预测器可以自己计算 $Z$，因此用完整 $X$ 的最优风险不会比只用 $Z$ 更差。变换的价值主要在于压缩、结构约束、数值稳定和有限样本学习效率，而不是无中生有地增加关于标签的真实信息。

平方损失下可以把信息损失算清楚。记 $m(X)=E[Y\mid X]$，使用表示后的最优预测为 $E[Y\mid Z]$。由条件期望与全方差关系，表示造成的最优平方风险增加为

$$
E\!\left[(m(X)-E[m(X)\mid Z])^2\right]\ge0.
$$

推导时先将 $Y$ 拆成 $m(X)$ 与条件均值为零的噪声，再在给定 $Z$ 下取期望，交叉项消失。若 $m(X)$ 已经可以写成 $Z$ 的函数，则该项为零，说明对预测条件均值这个目标没有损失。它不意味着表示保留了完整条件分布；预测分位数或其他目标可能仍需要被删掉的信息。

可逆变换在理想信息层面不丢失内容，但有限模型表现可以大不相同。把正数取对数是可逆的，却能把乘法关系变成加法，使线性模型更适合；反过来，不适当的缩放可能造成病态优化。区分信息、表达与求解，才能理解为什么“没有新增信息”的特征仍能改善现实模型。

<a id="sec-1-1"></a>
### 基础算例：同一列在两个预测时点有不同合法性

订单最终退款状态，在成交时预测未来退款属于未来答案；在退款结算后统计已完成订单则可以合法使用。判断标准不是字段是否叫“状态”，而是预测当时可获得什么。还要区分事件发生、系统写入和数据修订时间：退款在周二发起，不代表周一的预测可以使用周五最终确认的原因。

同理，用户累计购买次数需要重建到每条样本的截止点。若今天数据库保存了生命周期总次数，再把它连接到去年的快照，去年样本就看到了未来。随机交叉验证不会修复这个问题，因为非法信息已经存在于输入中。应先重建合法特征，再评价模型，而不是试图用正则化削弱泄漏列。

## 2. 正则化的坐标、几何与统计含义

<a id="detail-3"></a>

### 2.1 惩罚与约束是表达偏好的两种方式

经验损失加惩罚写为 $\widehat R(w)+\lambda\Omega(w)$，约束形式写为在 $\Omega(w)\le t$ 下最小化损失。在适当凸性、可行性和最优性条件下，两者可通过拉格朗日乘子联系，但不能未经条件就声称每个参数值都一一对应。非严格凸时，一个惩罚系数可能对应多个最优解，约束也可能没有激活。

L2 球偏好较小欧氏范数，L1 球具有坐标轴尖角，常产生稀疏解。几何解释有助理解，却不是零系数出现的完整证明。后面将用最优条件推导软阈值，说明梯度落在一个区间时为何系数恰好为零。正则化作用于完整学习规则，而不只是让数字看起来小一些。

正则还可以通过模型深度限制、平滑约束、数据增广和早停实现，但这些方法约束的对象不同。数据增广尝试引入某种不变性，早停偏好优化轨迹中较早的解，参数惩罚直接修改目标。它们可能有联系，也可能产生不同效应，不能仅因都叫正则就认为互换等价。

<a id="sec-2-1"></a>
### 机制展开：惩罚约束的是参数化下的复杂性

设原特征为 $x$、系数为 $w$，把特征改为 $x'=cx$ 后，为保持同一函数需要 $w'=w/c$。若固定使用 L2 惩罚，贡献从 $\lambda w^2$ 变为 $\lambda w^2/c^2$；L1 则变为原来的 $1/|c|$。因此单位变化不仅影响优化速度，也改变不同方向相对于惩罚的价格。

例如一个变量以元计、另一个以万元计，直接对系数施加相同惩罚，不代表对其预测影响施加相同约束。训练内标准化使每个变量按某种尺度比较，通常更便于统一选择正则强度；但标准差本身也可能受异常值影响，且业务上已知不同方向重要性时，统一标准化并不一定是唯一合理方案。

截距常常不受惩罚，以免把总体基线不必要地推向零，但这是目标约定，不是数学强制。若改变目标中心或类别基率，惩罚截距与否可能影响结果。比较实现时应核对损失求和还是平均、截距如何处理以及正则参数的定义，不能只复制同名数值。

<a id="deep-dive-2"></a>
### 深入讲解：特征表达正则化与抽样机制的共同作用

假设某渠道用户平均目标更高，模型加入渠道编码后表现改善。原因可能是渠道包含稳定的需求信息，也可能是渠道决定了哪些结果能被记录，或者渠道只在当前阶段与标签相关。惩罚可以控制拟合幅度，却无法从这些解释中自动选择真实机制。需要按来源与时间验证，检查观察链和标签过程。

换一种编码也会改变正则含义。将一个类别表示为单一编号，模型只需一个系数，但强行引入顺序；独热允许每类独立偏移，参数更多；嵌入约束类别效应通过低维空间共享。参数少不自动意味着假设更弱，某种紧凑表示可能施加更强而错误的结构。

最终应同时检查三件事：变换是否合法并保留所需信息，模型与惩罚是否能合理利用该表示，训练数据是否覆盖希望部署的对象。单独优化其中一项，可能改善训练数值却破坏完整任务。例如更强稀疏性可以降低维护成本，但若删掉罕见群体唯一的有效变量，也需要明确代价。

## 3. 抽样、测量与标签偏差的生成链

<a id="detail-4"></a>

### 3.1 从目标总体到训练表，不止一次筛选

原始总体经过接入系统、事件发生、日志记录、清洗筛选和标签可得等步骤才进入训练表。每一步都可能改变组成。只研究最终表里正例比例，无法知道缺少的群体在哪一阶段消失。应分别统计各阶段数量、时间、来源与关键变量分布，并保留排除原因。

抽样偏差涉及谁被观察，测量偏差涉及同一真实状态如何被记录，标签偏差涉及目标怎样被定义或标注。这些机制可能叠加：低端设备更容易丢日志，缺日志样本又在清洗时被删除，最后仅保留设备较好的活跃用户。模型在最终表上高分，不能证明对原总体都有效。

<a id="detail-5"></a>

### 3.2 选择会制造原本不存在的关联

给出一个精确算例。设两个独立公平二元变量 $A,U$，目标为 $Y=U$；仅当 $C=A\lor U=1$ 时收集样本。在总体中，$A$ 与目标独立，两个 $A$ 组的目标均值均为二分之一。被选择后，若 $A=0$，必须有 $U=1$ 才进入样本，所以目标均值为一；若 $A=1$，两种 $U$ 都可进入，目标均值为二分之一。

因此训练表中 $A$ 与目标产生明显负关联，却没有总体中的预测关系，更没有主动改变 $A$ 的因果效果。选择变量同时受到两个因素影响，条件于被选择就能引入关联。这是审查筛选规则的重要理由：筛选不是只减少样本数，也会改变统计关系。

现实例子包括只研究已住院者、只分析成功曝光记录或只保留交易完成订单。需要问筛选变量由什么决定，以及部署总体是否具有相同筛选机制。如果目标恰好就是被筛选人群，条件关联可以帮助预测，但结论必须限定在该总体；不能忽略条件后扩展到所有人。

<a id="detail-6"></a>

### 3.3 重新加权什么时候有依据

如果目标总体与训练总体只在输入分布上不同、给定输入后的目标机制相同，并且部署区域被训练支持覆盖，可以用密度比权重将目标风险表示为训练分布下的加权风险。这个等式需要条件分布不变与支持条件，不能由“发现群体比例不同”自动推出。

大权重还会放大少数记录。常用描述量 $(\sum_iw_i)^2/\sum_iw_i^2$ 可以提示权重集中程度，但不是所有学习任务的通用有效样本数。若九十九个权重为一、一个为一百，总权重一百九十九，平方和一万零九十九，该量约为三点九二。表面一百条记录的加权估计可能高度依赖那一个大权重点。

裁剪权重可以降低波动，但一般改变估计目标、引入偏差。应报告裁剪阈值与敏感性，而不是把裁剪当成无代价修复。如果某类部署对象完全没有训练记录，无穷权重无法创造标签信息，需要新数据或可明确说明的外推假设。

<a id="sec-4"></a>
## 4. 预测时点、聚合窗口与部署可用性

<a id="detail-7"></a>

### 4.1 时间窗口必须逐行定义

“最近七天消费”应当相对于每条样本的预测时点计算，而不是相对于数据提取当天。窗口可以写为 $[t-7\text{天},t)$，左闭右开避免边界事件重复归属；若事件有入库延迟，还必须要求它在 $t$ 前可查询。事件时间早于截止点但尚未入库，离线知道也不能当作线上已知。

窗口长度本身是超参数。短窗口响应近期变化，但波动大；长窗口较平稳，却可能混合过时行为。不同时间尺度可以共同使用，但它们高度相关，系数解释和正则选择需要注意。可以增加历史覆盖长度、活跃天数和有效观测次数，以区分“确实没有行为”与“只观察到很短时间”。

计算比率时分母需要明确。点击次数除以曝光次数，若曝光为零，该比率不是零点击率，而是没有可定义机会。可以保留分子、分母和缺失指示，或使用带先验的平滑，但每种表示都应解释。简单把所有无定义比率填零，会把从未曝光者与曝光很多但从不点击者混为一谈。

<a id="detail-8"></a>

### 4.2 历史身份信息与冷启动

某用户的历史平均金额对未来该用户预测可能很有用，对全新用户则不存在。若训练测试共享用户，模型可以利用个体历史；若要推广到陌生用户，应按实体隔离，并规定缺乏历史的回退方式。两种任务都合理，关键是评价模拟正确的信息条件。

用户编号通常不是连续数值。若编号随注册时间增加，可能间接编码时间；若按渠道分段生成，可能编码来源。它可以具有预测关联，但这种关联来自生成机制，而不是编号数字间天然距离。研究时可以与显式注册时间、渠道特征对照，检查编号是否只是脆弱代理。

历史标签统计也不是永远非法。若预测时点之前已经成熟并可合法获取，可以使用过去结果形成特征。但要排除当前目标和未来标签，明确更新延迟。比如过去退款率必须只包含当时已完成观察的订单；尚未成熟订单不能直接记为未退款来扩大分母。

<a id="detail-9"></a>

### 4.3 聚合前后的连接也会改变样本权重

订单表与商品明细表是一对多连接。若直接连接后训练，含更多商品的订单会出现更多行，相当于得到更大权重；如果标签仍是订单级，每行并不代表新的独立结果。应先确定样本单位，再把明细聚合成订单级特征，或明确采用能够处理集合结构的模型。

重复连接还可能改变类别频率与目标均值，使看似无标签的编码也偏向高频实体。每次连接应检查主键唯一性、前后行数和每实体重复次数。数据工程的基数检查与统计学习目标直接相连，不只是数据库实现细节。

<a id="sec-5"></a>
## 5. 拟合变换、交叉拟合与信息边界

<a id="sec-5-1"></a>
### 特征变换属于学习流程的一部分

标准化需要估计均值和尺度，填补需要估计替代值，类别编码需要建立词表，特征选择需要估计相关性。这些都是数据驱动的拟合状态。正确评价要在每个训练部分估计，再将固定规则应用到对应验证部分。把它们统称为“清洗”并不能让信息使用变得与评价无关。

某些纯确定变换，例如把已知小时映射为正弦余弦，不需要从当前样本估计状态；但是否选择这种变换仍可能是开发决策。应区分变换执行是否拟合与变换选择是否利用结果。最终独立测试要覆盖整套选择，而不仅是最后一个估计器。

<a id="detail-10"></a>

### 5.1 目标编码的自信息泄漏

设一个高基数类别只有一条训练记录，其标签为一。如果用全训练表该类别的目标均值作为特征，该行编码就等于自身标签。每个唯一类别都如此时，模型可获得近乎直接的答案。预测新类别却没有对应标签，训练与部署的特征含义完全不同。

平滑目标编码可写为 $e_c=(s_c+\alpha\pi)/(n_c+\alpha)$，其中类别目标和为 $s_c$、次数为 $n_c$、训练先验为 $\pi$。它在低样本类别上更接近总体先验，降低极端估计，但若当前行标签仍进入分子，自信息依赖并未完全消失。平滑和防泄漏是两个不同问题。

例如某类别有标签一、零、一，训练先验零点四、平滑强度二，全类别编码为 $(2+0.8)/5=0.56$。若对标签一的当前行排除自身，编码为 $(1+0.8)/4=0.45$；对标签零的行排除自身，编码为 $(2+0.8)/4=0.7$。这说明排除自身后，同类别各行编码也可能不同，不能再把编码简单理解为一个固定类别属性。

<a id="detail-11"></a>

### 5.2 折外编码怎样构造完整流程

在训练数据内部划分若干折，编码某折时，只用其余折的标签估计类别统计，再应用到该折。所有训练行由此获得折外编码；用于外部验证或实际推理时，再使用完整训练部分估计的映射。若外层还有交叉验证，这套内部步骤必须在每个外层训练部分重新运行。

先验、平滑强度选择和未知类别回退同样要处于正确边界。若训练先验来自全数据标签，外层验证信息仍然泄漏。时间任务还需使用历史方向的编码：普通折外方式虽然排除了当前行，却可能使用其未来同类结果，仍不符合部署。

折外编码也不是天然高质量特征。在每类只有两条记录的极端例子中，留一编码等于另一条标签；若两标签恰好相反，会出现训练内反向关系。这是有限样本波动与分布不匹配的风险，不能因“没有自身标签”就认为稳定。需要合理平滑、类别样本量检查以及外部评价。

<a id="detail-12"></a>

### 5.3 特征选择也需要对整个过程评价

按相关性、单变量检验或模型重要性筛选，都是利用数据寻找较有利的表示。即使最终仅保留少量列，也可能是在大量候选中选出的幸运噪声。选择后的参数维数不能概括选择过程的全部复杂度。应将筛选放在折内，必要时用外层评价选择规则。

相关性低不等于无预测价值。目标可能由两个变量交互决定，而各自边缘关联为零；强相关也可能只是泄漏或来源代理。选择规则需要与模型和任务配合。线性单变量筛选适合发现某些关系，但不能作为所有非线性任务的普遍前处理。

## 6. 数值特征：尺度、非线性与目标变换

<a id="detail-13"></a>

### 6.1 标准化与稳健尺度

常见标准化为 $z=(x-\mu)/s$，其中训练均值和标准差固定后复用于验证与部署。零方差列需要特殊处理，因为没有可用尺度；极小方差列也可能把微小噪声放大。稀疏矩阵中心化会把大量零变成非零，造成内存增加，因此表示与实现约束应共同考虑。

均值标准差对极端值敏感。可以考虑中位数与四分位距等稳健尺度，但它们不是自动更优。若极端值是有意义的高风险事件，粗暴压缩可能损害任务；若是单位错误，首先应修复记录。统计稳健性与业务合法性需要分别判断。

缩放还影响距离、核宽度和优化条件。最近邻会把大尺度变量视为更重要，径向核对尺度变化敏感，梯度方法在细长等高线上可能收敛慢。即使不使用显式正则，也不能认为单位完全不影响现实训练。理论无正则最优函数的单位等价，需要相应参数变换和充分求解条件。

<a id="detail-14"></a>

### 6.2 对数、幂与分段特征

对正数取对数，把乘法比例转为加法差异，适合跨数量级的正变量。使用 $\log(1+x)$ 可以处理零，但一的含义依赖原始单位，改变元和万元会改变变换形状。负值则不能未经检查取对数，可采用其他变换或把符号与大小分开表示，选择应服务数据含义。

分箱允许线性模型表示分段常数关系，但丢失箱内次序。样条提供更平滑的非线性表示，其节点数量与位置决定灵活度。按目标寻找最佳切分点属于监督选择，需要折内拟合；按输入分位数设置节点虽不使用标签，也仍需要按协议估计状态。

异常值裁剪限制极端输入影响，却可能把真实高值与错误高值混在一起。应保留原始审计信息，说明阈值来自业务规则还是训练分布。上线超过训练范围时，是裁剪、拒绝还是允许外推，需要写入特征契约；不能让默认库行为决定重要业务语义。

<a id="detail-15"></a>

### 6.3 目标取对数后不能直接指数还原均值

若训练预测 $Z=\log Y$ 的条件均值，得到 $m_Z(x)$，直接输出 $e^{m_Z(x)}$ 一般不是 $E[Y\mid x]$。因为指数非线性，条件期望不能交换。若条件对数目标为正态分布、方差为 $s^2(x)$，则原目标条件均值为 $e^{m_Z(x)+s^2(x)/2}$，而中位数为 $e^{m_Z(x)}$。

例如给定输入后，$\log Y$ 的均值为零、方差为一，则指数还原结果是一，真实条件均值约为一点六四八七。若业务评价原尺度平方误差，直接还原会系统偏低；若评价对数误差或中位数，则它可能正是所需摘要。目标变换不仅改善数值，还改变损失和预测对象。

不满足对数正态时，可以研究残差的重转换修正，但必须估计相应条件分布，并防止用测试标签校正。全局修正因子在异方差任务中可能不足。模型输出要明确是原尺度均值、中位数还是其他量，不能只标“预测金额”。

<a id="categorical"></a>
## 7. 类别、交互与高基数表示

<a id="detail-16"></a>

### 7.1 独热编码与参数可识别性

一个有三类的变量若用三个独热列并加截距，三列之和恒为一，与截距列线性相关。无正则线性参数因此不唯一。可以去掉参考类、施加和为零约束，或使用适当惩罚。不同参数化可以表示相同函数，但系数解释和惩罚几何可能不同。

去掉参考类后，其他类别系数表示相对于参考类的预测差异；换参考类会改变数值，却不应在无惩罚且正确处理的等价模型中改变拟合函数。若对不同参数化直接加同样 L2 惩罚而不调整，函数偏好可能改变。所谓“只是编码不同”不能自动保证带正则后的等价。

未知类别需要预定义策略。可以映射到保留的未知类别、使用先验回退或让所有已知独热列为零，但最后一种在带参考类编码中可能与参考类混淆。应解释其语义，并在验证中模拟未知类别，而不是只确保程序不报错。

<a id="detail-17"></a>

### 7.2 交互项使线性参数模型表达非加性

模型 $b+w_1x_1+w_2x_2$ 假设一个变量的影响不随另一个变量变化。加入 $w_{12}x_1x_2$ 后，对 $x_1$ 的变化率为 $w_1+w_{12}x_2$，允许条件效应不同。它仍对参数线性，但对原始输入不再是简单加法。

二元异或是直观反例：两个输入独立公平，目标是它们是否不同。各输入单独与目标没有边缘关联，单纯加法阈值无法表示所有四个角的类别。交互或合适非线性表示能够补足结构。因此删除所有单变量相关性低的列，可能在模型看到交互前就丢掉必要信息。

交互数量快速增长，需要结构先验、稀疏约束或层级原则。若加入交互同时保留主效应，解释通常更稳定，但是否严格要求层级属于建模选择。不能把“交互系数显著”直接理解为因果协同，相关输入与选择机制仍然存在。

<a id="detail-18"></a>

### 7.3 哈希与嵌入的代价

特征哈希将大量类别映射到固定维度，便于处理高基数和未知类别，但不同类别可能碰撞并共享参数。它减少词表存储，却引入信息混合。维度、哈希规则和符号处理都应固定并版本化，否则同一类别上线后可能映射到不同位置。

嵌入把类别映射到可学习向量，再与其他结构组合，允许共享低维统计规律。稀有类别向量估计仍可能不稳定，维度太高也可能记忆训练标签。类别相似性由训练任务与数据决定，不等于现实中唯一的语义距离。应通过未知类别、低频类别和跨来源评价检查价值。

<a id="missing"></a>
## 8. 缺失值与测量机制

<a id="detail-19"></a>

### 8.1 缺失不是一个统一的数值状态

没有记录可能表示对象没有发生行为、没有机会被观察、传感器故障、用户拒绝填写或字段不适用。把这些情况都填成零，会让同一个数值同时代表多个机制。应尽可能保留缺失原因，至少区分真实零、未知值和不适用。

设 $Z$ 是可能缺失的变量，$V$ 是始终观察到的信息，$R$ 表示 $Z$ 是否被观察。完全随机缺失可以写为 $R$ 与 $(Z,V)$ 独立；在给定 $V$ 后，观察概率不再依赖缺失的 $Z$，是一种随机缺失条件；若仍依赖未观察到的 $Z$，则属于非随机缺失。实际多变量缺失模式更复杂，需要针对具体观察集合定义，不能只按名称机械分类。

比如体检收入字段中，高收入者更不愿报告，即使控制所有已观察信息后仍如此，就可能是非随机缺失。只用已报告人群的均值填补，无法从数据本身恢复沉默者收入分布。缺失机制通常不能完全由观测数据检验，需要领域知识、补充调查或敏感性假设。

<a id="detail-20"></a>

### 8.2 填补值与缺失指示各自做什么

均值填补让线性模型能够处理输入，却会压缩该列方差，并改变与其他变量的协方差；它不是恢复了真实值。如果模型还加入缺失指示，可以允许缺失组有不同截距。但若缺失概率随时间变化，模型利用的流程信号也可能失效。

考虑年龄列的已知值为二十、四十，第三人缺失。均值填补为三十并不意味着第三人确实三十岁，只是数值回退。加一个指示变量后，模型可以分别利用已知年龄差异与缺失组偏移；没有指示时，缺失者会与真实三十岁者混在一起。是否应使用这种流程差异，要通过部署稳定性与任务合法性判断。

模型化填补利用其他变量预测缺失值，可能改善表示，但也受假设与误差影响。若填补模型在全数据拟合，同样会影响评价边界；若填补依赖未来标签，更直接泄漏。多重填补主要用于反映缺失不确定性的某些统计推断任务，其目标与单纯部署预测并不完全相同，不能只复制名称而忽略使用条件。

<a id="detail-21"></a>

### 8.3 测量误差可能系统改变系数

输入记录不等于真实状态。传感器存在误差、问卷有偏、日志抽样丢失，都可能改变学习关系。在简单经典测量误差模型中，真实变量 $X$ 与噪声 $U$ 独立，观测为 $W=X+U$，目标为 $Y=\beta X+\epsilon$，各噪声均值为零且满足独立条件。总体线性回归系数为

$$
\frac{\operatorname{Cov}(W,Y)}{\operatorname{Var}(W)}
=\beta\frac{\operatorname{Var}(X)}{\operatorname{Var}(X)+\operatorname{Var}(U)}.
$$

因此系数向零衰减。若真实变量方差为四、测量误差方差为一，观测系数是原来的零点八倍。该结论只针对明确的经典模型；相关误差、非线性、选择机制或目标测量误差会产生不同结果。它说明系数偏小不一定意味着真实作用小，也不一定由正则化造成。

<a id="detail-22"></a>

### 8.4 训练与推理的测量质量不同

训练可能使用人工修正数据，部署却使用实时原始记录；离线数据包含补录，线上有延迟；历史设备精度高，新设备量化更粗。即使字段名称和单位相同，模型看到的测量过程也已改变。应在贴近生产的输入质量下测试，而不是只用理想清洗表。

可以设计缺失、延迟和噪声压力测试，观察性能与回退行为，但扰动应尽量符合真实机制。随机删列不一定代表实际缺失，独立高斯噪声也不一定代表传感器故障。压力测试提供特定情景证据，不能替代实际来源验证。

<a id="detail-23"></a>

### 8.5 不能识别时，仍可给出可检验的范围

假设目标 $Y$ 只可能位于零到一之间，总体中被观察比例为 $r$，观察者均值为 $\mu_{obs}$。由全期望公式，总体均值为 $r\mu_{obs}+(1-r)\mu_{mis}$，而未观察者均值只能确定在零到一之间。因此无需假定缺失随机，就能得到范围 $[r\mu_{obs},r\mu_{obs}+1-r]$。这不是精确恢复，却把信息不足量化出来。

例如六成人有标签、观察均值零点三，则总体均值可能在零点一八到零点五八之间。直接用零点三填补沉默者，相当于额外假定其均值也为零点三，而不是由观测推导出的事实。如果有领域知识认为沉默者均值不低于观察者，可以收紧下界；若补充随机复核得到更多信息，也能缩窄范围。每次收紧都应说明增加了什么数据或假设。

这个思路称为部分识别：承认多个数据生成机制与现有观测相容，并研究目标的可行集合。预测项目不一定需要完整识别所有缺失值，但当结论涉及总体比例或公平比较时，范围分析往往比给一个没有依据的精确填补值更有解释力。

<a id="penalties"></a>
## 9. 稀疏、收缩与相关变量

<a id="detail-24"></a>

### 9.1 正交设计下 L2 的精确解

考虑中心化数据，$X^\top X/n=I$，目标为 $\|y-Xw\|^2/(2n)+\lambda\|w\|_2^2/2$。忽略与参数无关项，令 $z=X^\top y/n$，目标变成各坐标的 $\tfrac12(w_j-z_j)^2+\tfrac\lambda2w_j^2$。求导得到 $w_j=z_j/(1+\lambda)$。

因此在正交设计下，L2 对每个经验相关系数连续收缩，而不会一般地产生恰好零。非正交设计则由矩阵几何决定各方向收缩，不能直接逐列套这个公式。岭回归总有稳定的矩阵解在正惩罚与适当截距处理下成立，但解释要区分特征坐标与奇异方向。

<a id="detail-25"></a>

### 9.2 L1 的软阈值为何出现零

将惩罚换为 $\lambda\|w\|_1$，每坐标目标为 $\tfrac12(w-z)^2+\lambda|w|$。若 $w>0$，导数为 $w-z+\lambda$，候选解 $z-\lambda$ 只有在 $z>\lambda$ 时有效；若 $w<0$，候选为 $z+\lambda$，只在 $z<-\lambda$ 时有效；在零点，绝对值次梯度为负一到一区间，最优条件是 $|z|\le\lambda$。

所以解为 $\operatorname{sign}(z)\max(|z|-\lambda,0)$。取 $z=(0.2,1.4,-0.8)$、$\lambda=0.5$，得到 $(0,0.9,-0.3)$。L2 同强度下则为约 $(0.1333,0.9333,-0.5333)$。两个目标的惩罚规范不同，数值相同的系数不代表相同约束强度，但例子清楚展示稀疏与连续收缩的差异。

正交条件一旦拿掉，真正保留的是最优性条件，而不是逐列套公式。令残差 $r=y-Xw$，一般 Lasso 目标为 $\|r\|^2/(2n)+\lambda\sum_j|w_j|$，其条件为

$$
\frac{X_j^Tr}{n}=\lambda\operatorname{sign}(w_j)\quad(w_j\ne0),
\qquad
\left|\frac{X_j^Tr}{n}\right|\le\lambda\quad(w_j=0).
$$

这是因为平方项对第 $j$ 个系数的梯度为 $-X_j^Tr/n$，需与绝对值次梯度相抵消。坐标下降固定其他坐标后，使用部分残差 $r_{-j}=y-\sum_{\ell\ne j}X_\ell w_\ell$，若 $a_j=X_j^TX_j/n>0$、$z_j=X_j^Tr_{-j}/n$，更新为 $w_j=\operatorname{sign}(z_j)\max(|z_j|-\lambda,0)/a_j$。相关特征会通过部分残差互相影响，因此一次独立阈值不再等于联合解。

例如两列完全相同且标准化为 $X_1^TX_1/n=1$，目标为 $y=X_1$，取 $\lambda=0.2$。记 $s=w_1+w_2$，平方项为 $(1-s)^2/2$。任意 $w_1,w_2\ge0$ 且和为 $0.8$ 都达到相同目标：$(0.8,0)$、$(0,0.8)$、$(0.4,0.4)$ 一样好。预测可以唯一而系数不唯一，所以“某列被选中”未必是稳定的重要性证据。若把边际相关 $z_1=z_2=1$ 分别软阈值成 $0.8$，总系数会误成 $1.6$；将它代回上述残差最优性条件即可发现错误。


<a id="detail-26"></a>

### 9.3 相关特征下选择可能不稳定

若两列完全相同，预测只依赖系数和 $s=w_1+w_2$。当最优和为正时，所有非负分配都有相同 L1 惩罚 $|w_1|+|w_2|=s$，所以参数可能不唯一。一个实现选择第一列、另一个选择第二列，并不意味着发现了不同的现实机制。

L2 在固定和下最小化 $w_1^2+w_2^2$，由平方差或求导可知最优分配是各为 $s/2$。它更倾向在相关变量间分摊，但系数仍受尺度与结构影响。弹性网同时加入 L1 与 L2，可以兼顾稀疏与某种分组稳定性，却仍不能消除所有相关性问题。

近似相关时，极小数据变化可能改变哪个变量先被选中。应通过重采样观察预测稳定性与选择频率，区分“模型预测基本不变”与“单列解释稳定”。如果研究目标是变量发现，要求可能比纯预测更严格；如果目标是低成本部署，保留一个可替代变量也可能足够，但应明确这是一种工程选择。

<a id="detail-27"></a>

### 9.4 结构化正则与数据增广

组惩罚可以把某一类别的所有独热列、某个传感器的一组特征作为整体选择，避免任意编码导致部分保留。平滑惩罚可以约束相邻时间或空间系数变化；低秩约束允许多任务共享结构。这些方法把领域假设写进目标，效果依赖假设是否合理。

增广则通过构造应保持标签或目标关系的输入变化来限制学习。例如图像水平翻转适合某些对象识别，却可能改变左右方向语义；文本随机删词可能删掉否定词；时间序列随机打乱可能破坏目标机制。增广不是免费数据，它添加的是对标签保持关系的假设，应对不满足假设的场景检查。

<a id="case-study"></a>
## 10. 完整案例：订单延迟预测的特征审计

<a id="detail-28"></a>

### 10.1 固定预测契约

任务是在订单首次交给承运商时，预测是否不能在承诺截止日前签收。输入仅限交接时已经可查询的订单与历史信息；目标需要等到截止日以及合理入库缓冲后成熟。对象是未来订单，其中既包含熟悉承运商也包含新线路，因此需要按时间评价，并额外报告陌生线路。

初始特征包括订单金额、距离、创建小时、承运商编号、最终签收状态、过去三十天同线路延迟率。逐列审计后，最终签收状态属于答案，应删除；线路延迟率必须只使用当时已经成熟的历史订单；编号作为类别而非连续数值；小时需要结合日周期和业务班次分析；金额单位及缺失原因要统一。

<a id="detail-29"></a>

### 10.2 构建一个合法历史比率

某线路过去窗口内有十二笔交接订单，九笔已成熟，其中两笔延迟，其余三笔仍在观察。把未成熟当作未延迟会得到 $2/12\approx0.1667$，但合法的已观测比例应为 $2/9\approx0.2222$。若使用训练历史先验零点二、平滑强度三，平滑率为 $(2+0.6)/(9+3)\approx0.2167$。

同时保存成熟数量九、窗口订单数十二和历史覆盖长度，帮助模型区分同样比例背后的证据量。新线路没有成熟记录时，回退到当时可用先验，并标记冷启动，而不是用未来全表线路均值填补。先验也要按训练截止点估计。

<a id="detail-30"></a>

### 10.3 对照方案与失效检查

方案甲使用合法基础列和简单线性分类模型；乙增加平滑历史率与周期特征；丙加入高基数承运商或线路表示；丁在相同表示下比较更复杂模型。这样可以分辨信息改造与模型容量的贡献。所有方案使用同样时间切分、成熟规则和成本评价，前处理仅在训练部分拟合。

需要检查四类失败：历史率是否通过当前订单或未来标签泄漏；新线路是否没有合理回退；某承运商编号是否只是短期来源代理；高金额极值是否来自单位错误。若乙提升主要来自非法未来统计，不能把丙和丁的后续高分当作有效进步，应重建特征后重新比较。

<a id="detail-31"></a>

### 10.4 正则化与业务成本一起审查

距离和金额缩放后，重新选择正则强度，而不是沿用原数值。对低频线路可以增加平滑或共享结构，避免少量标签造成极端系数。检查稀疏模型删除哪些特征、是否损害陌生线路，以及维护成本是否下降。若删除某列不影响平均分，也要查看关键来源，避免少数组的有效信息被平均掩盖。

最终模型输出延迟概率，后续根据提前干预成本选择行动。若干预会改变是否延迟，历史预测风险并不直接等于干预收益。应该分别评价预测质量与行动效果；特征审计保证信息合法，但不自动解决因果决策问题。

<a id="research"></a>
## 11. 稳定性与研究设计

<a id="detail-32"></a>

### 11.1 预测稳定不等于解释稳定

重采样训练集后，多个相关特征的系数可能大幅变化，但预测几乎一致。这说明模型利用的信息可以被替代，而非必然说明预测不可靠。若研究目标是解释某个变量，应进一步分析参数可识别性、条件相关和选择机制；若目标是部署，重点可以是最终行为在合理扰动下是否稳定。

置换重要性也受相关性影响。打乱一个变量时，其他变量可能仍保留同样信息，使重要性低估其可替代贡献；不合理置换还可能构造现实中不存在的组合，使误差变化难以解释。重要性是针对模型、数据和扰动方案定义的量，不是变量永恒的真实价值。

<a id="detail-33"></a>

### 11.2 消融要避免重新引入不公平比较

删除某特征后是否重调其他超参数，会改变问题。固定其余设置的消融研究该配置对一部分输入的依赖；重新调参研究没有该特征时完整流程能达到的表现。两者都可用，但解释不同。应记录预算并避免只给被偏爱的方案更多优化机会。

研究新特征时可以预先规定来源、变换、对照和主要指标，在独立来源或未来时间确认。若从大量候选中挑出效果最好的新列，应把这一搜索计入选择过程。更有意义的贡献通常是解释它捕捉了什么结构、何时失效，以及是否能在不同模型或数据上重复，而不只是一个平均分增量。

<a id="detail-34"></a>

### 11.3 可逆坐标变化为何仍会改变岭解

把输入作可逆线性变换 $z=Ax$，新坐标系数为 $w$，则原坐标对应系数为 $v=A^\top w$。由于 $w=A^{-\top}v$，在新坐标使用欧氏惩罚，等价于原坐标惩罚 $v^\top A^{-1}A^{-\top}v$。函数集合没有变化，但不同方向的价格由矩阵重新定义，因此有限数据上的最优预测可以变化。

若 $A$ 是正交旋转，L2 范数不变，所以相应无截断模型与完整惩罚可保持旋转等价；L1 则通常不具有这种性质。原来向量 $(1,0)$ 的 L1 为一，旋转四十五度后成为 $(1/\sqrt2,1/\sqrt2)$，L1 为根号二，而 L2 仍为一。因此“稀疏”是相对于特定坐标系定义的；选择坐标意味着选择哪些因素应独立被筛除。

这也解释为何先做主成分变换再 L1，与直接在原变量上 L1 不是同一个变量选择任务。主成分可能混合多个传感器，少量非零主成分不等于少量原始传感器。若部署成本按原设备计算，应在对应结构下设计约束，而不是仅看变换后参数有多少零。

<a id="detail-35"></a>

### 11.4 一种数据增广与二次惩罚的精确联系

对固定输入目标 $(x,y)$，令增广输入为 $x+\xi$，其中噪声条件均值为零、协方差为 $\Sigma_\xi$，且与当前目标的生成误差满足所需独立条件。在线性预测与平方损失下，展开并对增广噪声取期望，交叉项为零，可得 $E_\xi[(y-b-w^\top(x+\xi))^2]=(y-b-w^\top x)^2+w^\top\Sigma_\xi w$。

所以在这个特定模型中，输入加性噪声训练的期望目标等价于原损失加一个二次惩罚。各向同性噪声得到与 L2 相似的形式，相关噪声则对不同组合方向施加不同约束。若一列噪声方差为四、另一列为一，相应惩罚为 $4w_1^2+w_2^2$，并不是两个参数价格相同。

该等价依赖线性模型、平方损失以及噪声条件。对非线性网络、交叉熵或改变标签的增广，不应原样声称等价。实际有限次增广还带有采样波动，不完全等于噪声期望。这个推导提供理解联系的方法，同时明确它何时不适用。

<a id="detail-36"></a>

### 11.5 组稀疏的阈值可以直接推导

在正交组设计中，考虑一组参数目标 $\tfrac12\|w-z\|_2^2+\lambda c\|w\|_2$，其中 $c>0$ 是预定组权重。非零最优解的方向必须与 $z$ 相同，否则旋转到该方向能够降低二次距离而不改变惩罚。设 $w=az$、$a\ge0$，对标量长度最小化得到 $w=(1-\lambda c/\|z\|_2)z$，前提是 $\|z\|_2>\lambda c$；否则整组为零。

例如 $z=(3,4)$，范数五，阈值 $\lambda c=2$，整组收缩为 $(1.8,2.4)$；若阈值达到六，整组同时删除。与逐列软阈值不同，它按组的总体信号作决定。组大小不同通常需要考虑相应权重，否则更大组仅因含更多噪声坐标就容易被保留；具体权重仍应结合设计尺度与任务解释，而不是任意复制。

<a id="detail-37"></a>

### 11.6 平滑类别统计的一个贝叶斯推导

对于某个类别，假设其正例概率为 $\theta_c$，类别内标签在给定概率后独立伯努利，先验为 $\operatorname{Beta}(a,b)$。观察到 $n_c$ 条、其中 $s_c$ 个正例，似然与先验相乘，指数相加，得到后验 $\operatorname{Beta}(a+s_c,b+n_c-s_c)$。后验均值为 $(s_c+a)/(n_c+a+b)$。

令平滑强度 $\alpha=a+b$、先验均值 $\pi=a/(a+b)$，便得到前面的平滑目标编码公式。这个推导说明“伪计数”为什么能在小类别上收缩，也说明它依赖类别内可交换的伯努利模型及先验选择，不是无需假设的真实概率恢复。

例如先验 $a=1,b=4$，均值零点二、强度五。某类别两条记录都为正，原始比例为一，后验均值为 $3/7\approx0.4286$；若二十条都为正，后验均值为 $21/25=0.84$。相同观察比例却得到不同收缩，体现证据量差异。第一种后验方差为 $3\times4/[7^2\times8]\approx0.03061$，并非只有一个精确点。

还要区分类别概率的不确定性与下一条标签的不确定性。后验方差描述未知概率在当前证据下的波动；下一条二元标签的后验预测方差则为 $\mu(1-\mu)$，其中 $\mu$ 是后验均值。全方差公式把它拆成后验平均的 $\theta_c(1-\theta_c)$ 加概率后验方差。即使大量数据使后验概率几乎确定，个体标签仍可能随机，不能把“均值估计精确”误读为“下一次结果几乎确定”。

把这个后验均值当作训练特征时，自身标签依赖仍然存在。贝叶斯解释不能替代折外或历史编码边界；若先验也从数据估计，它必须在允许训练部分拟合。对类别概率会随时间变化的任务，固定交换模型可能过于简单，应比较时间加权、层级共享或近期数据，但仍保持外部评价一致。

<a id="sec-6"></a>
## 12. 分层练习与详细解析

<a id="detail-38"></a>

### 12.1 信息练习：可逆变换与有限模型

**题目。** 输入为正数，真实目标近似与其对数线性相关。取对数没有新增信息，为什么仍能改善线性回归？若把输入只分成大小两箱，结论有何变化？

**解析。** 对数可逆，因此理想预测器拥有同样的信息；但线性函数族在原坐标和对数坐标表达的函数不同，后者与规律更匹配，近似误差可以下降。分箱不可逆，箱内差异被删除，理想最优风险可能增加；有限样本下它又可能减少估计波动。因此评价要同时研究信息损失与学习约束，不能仅按是否压缩判断。

<a id="detail-39"></a>

### 12.2 缩放练习：相同函数为何惩罚不同

**题目。** 模型有一个以米为单位的特征，系数二。换成厘米后，保持同一函数的系数是多少？固定 L2 惩罚贡献变为多少倍？

**解析。** 新输入放大一百倍，系数应变成零点零二。系数平方变为原来的万分之一，所以固定惩罚系数下同一函数更便宜。无惩罚且充分求解时可通过参数变换保持函数，固定惩罚目标却已改变。标准化或相应调整惩罚矩阵可以处理这种差异，但应明确选择的几何。

<a id="detail-40"></a>

### 12.3 目标编码练习：平滑不等于无泄漏

**题目。** 某类别只有当前一条正例，训练先验零点二，平滑强度四。全训练编码与排除自身后的编码分别是什么？为何仍需要外层评价？

**解析。** 全训练编码为 $(1+4\times0.2)/(1+4)=0.36$；排除自身后没有类别记录，回退先验零点二。前者仍利用自身标签，平滑只减弱了依赖。折外编码、先验和未知类别规则还需要完整训练流程；若编码策略本身经过多次选择，也要由外层或独立测试评价。避免一条泄漏路径不等于消除所有选择偏差。

<a id="detail-41"></a>

### 12.4 目标变换练习：指数还原预测什么

**题目。** 给定输入后，目标对数为均值一、方差零点四的正态变量。指数还原对数均值与原目标均值分别是多少？若评价原尺度平方误差，应选择哪个理想摘要？

**解析。** 前者为 $e^1\approx2.7183$，是原分布中位数；均值为 $e^{1+0.4/2}=e^{1.2}\approx3.3201$。平方损失的条件最优是原尺度均值。若改用绝对误差，中位数才是最优摘要。这个差别来自非线性和损失定义，不是模型对某个数字算错。

<a id="detail-42"></a>

### 12.5 稀疏练习：推导零点最优条件

**题目。** 最小化 $\tfrac12(w-0.3)^2+0.5|w|$。不用搜索，证明最优点为零。若经验相关变为零点八，解如何变化？

**解析。** 零点处二次项导数为负零点三，L1 次梯度为 $0.5[-1,1]$，两者相加包含零，凸目标因而在零达到全局最优。相关变为零点八时，正区域最优为 $0.8-0.5=0.3$，满足正区域条件。这个推导依赖目标已经化为正交坐标形式，相关设计中不能独立对原始每列直接软阈值。

<a id="sec-6-1"></a>
### 边界追问：稀疏系数是否代表真实无作用

**题目。** 两个几乎相同的传感器特征中，L1 只保留一个，能否证明另一个没有现实作用？

**解析。** 不能。两列可以携带可替代信息，选择受尺度、噪声和惩罚影响。完全相同列在固定系数和下可能拥有同样 L1 目标，具体实现选择哪列并不唯一。现实因果作用更需要额外识别条件。可以研究重采样选择稳定性、替代成本和传感器失效时的表现，再决定是否为部署删列。

<a id="detail-43"></a>

### 12.6 选择偏差练习：把生成链画清楚

**题目。** $A,U$ 为独立公平二元变量，仅当 $A\lor U=1$ 才观察，目标为 $U$。列出被观察的三种组合，并计算两个 $A$ 组目标均值。

**解析。** 总体四种组合等概率，被观察的是 $(0,1),(1,0),(1,1)$，条件后各占三分之一。$A=0$ 组只有目标一，均值一；$A=1$ 组目标零和一各半，均值二分之一。总体中原本独立，选择后产生关联。若部署仅面向同样被选择者，这种关联可预测；若扩展到总体，结论不成立。

<a id="detail-44"></a>

### 12.7 缺失练习：能否从已报告者恢复所有人

**题目。** 收入越高越不愿报告，现有数据只包含是否报告与已报告收入，没有任何补充变量。用报告者均值填补后，能否声称修正了总体均值？

**解析。** 不能。未报告收入分布并未被观测，相同已报告数据可以对应不同沉默人群分布，因而总体均值不可由这些观测唯一确定。需要额外调查、外部约束或明确敏感性假设。填补使程序可运行，不等于识别了缺失分布。应该报告假设与可能范围，而不是把单个填补值当事实。

<a id="detail-45"></a>

### 12.8 项目练习：设计三组能否定新特征的对照

**题目。** 新增“线路历史延迟率”后准确率显著提升，请设计三组检查，说明什么结果会削弱其有效性结论。

**解析。** 首先按预测时点重建成熟历史，若提升消失，原结果可能依赖未来信息；其次留出陌生线路并使用预定回退，若严重退化，说明价值主要在已见实体；再次跨时间与承运商来源评价，若只在某次活动期间有效，可能是短期代理。还应与不使用当前目标的折外或历史编码比较，检查标签延迟与样本数。新特征可以在限定范围内有价值，但范围必须与证据一致。

<a id="detail-46"></a>

### 12.9 理论练习：特征粗化的风险差

**题目。** 目标条件均值在两种等概率输入上分别为零和二，噪声方差均为一。表示把两输入映成相同值。计算完整输入与粗化表示的最优平方风险。

**解析。** 完整输入可以分别输出零和二，风险只剩噪声方差一。粗化后只能输出总体均值一，平均偏差平方为一，再加噪声得到二。风险增加一，恰好等于条件均值在粗化组内的方差。若有限模型原本无法区分两输入，现实改善与否还受模型限制影响；但理想信息损失可以明确算出。

<a id="detail-47"></a>

### 12.10 开放研究：稳健不是删除所有极端值

**题目。** 训练中极高金额样本占比很小，但业务最关心它们。应如何比较裁剪、对数变换和原值模型？

**解析。** 先核查单位与记录错误，区分真实高值和坏数据。随后在固定合法划分上比较完整流程，同时报告总体损失与高金额组表现，并确认目标损失是否赋予高值更大代价。裁剪可能降低波动但损失高值排序，对数变换改变原尺度关系，保留原值可能需要稳健优化。不要仅凭总体平均改善决定，应结合目标总体、组样本量和行动成本。
