## 1. 将愿望改写为学习任务

<a id="chapter-foundations-01-heading-3"></a>

### 1.1 为什么“预测用户流失”还不是任务定义

“流失”可能指连续七天没有登录、一个月没有消费、取消订阅，也可能指永远不再回来。前几种可以通过有限时间观察得到标签，最后一种往往在有限数据中无法证实。定义不同，正例比例、合法输入、错误成本和模型上线位置都会变化。模型训练得再精确，也只能逼近你实际提供的目标，不能自动恢复你没有定义清楚的概念。

一个完整的任务至少包含六个要素：总体、单位、时点、信息、目标和用途。总体说明希望结论适用于哪些对象；单位说明一行代表用户、订单、设备还是一次曝光；时点决定预测发生在什么时候；信息说明那个时刻真正可以获得什么；目标给出未来结果的操作定义；用途则说明模型输出如何进入行动。六个要素之间必须一致。针对“曾经购买过的活跃用户”训练的模型，不能不经检查就被当作“所有新注册用户”的模型；两者不仅特征缺失模式不同，发生购买的基础概率也可能不同。

单位尤其容易被忽略。同一用户每天一条样本时，一万条记录可能只来自一百个用户。这样的数据量与一万个相互独立用户不等价。若把同一用户的相邻日期随机放入训练和测试，模型可能识别稳定的个人特征，测试回答的是“熟悉用户的新记录是否可预测”，而不是“陌生用户是否可预测”。两种问题都有价值，但必须事先选择。

预测时点不能用原始表的一列日期敷衍过去。业务事件发生时间、数据写入时间和特征实际可查询时间可能不同。例如一次交易在周一发生，风险审核结果周三才写入数据库，那么周二进行预测时，周一交易本身也许已知，审核结论却尚不可见。合法特征的标准是当时可获得，而不只是事件时间早于预测时间。

<a id="sec-1-1"></a>
### 基础算例：将一句业务目标改成预测协议

设需求是“找到下周可能不回来的用户”。可以把它写成如下契约：在每周一零点，对过去三十天至少登录过一次、账号尚未注销且有完整记录的用户生成一条样本；输入仅使用该时点之前已经入库的行为；目标是未来七个完整自然日是否完全没有有效登录；输出一个概率，供运营人员从中选择有限数量的用户进行后续实验。这里将正类定义为“不回访”，因此较高的预测概率对应较高的流失风险。

这个契约仍需补充异常事件的处理规则。系统故障导致的登录记录缺失，不能直接解释为用户没有登录；机器人登录是否算有效登录，需要统一规则；账号在观察窗口内被平台封禁，究竟作为流失、排除还是单独结局，也需要说明。它们会改变标签的含义。合理做法是先写规则，保留可审计的排除计数，再构建训练表，而不是看到某种定义更容易拿高分后才改标签。

观察窗口和预测窗口承担不同职责。过去三十天形成特征，未来七天形成标签，中间是否预留数据延迟缓冲期由生产系统决定。若消息平均晚到一天，周一零点上线只能查询到周日零点前较完整的数据，那么离线特征也应复现这个限制。离线分析使用完整历史表很方便，却可能拥有线上没有的信息。

任务还应规定“之后如何判断成功”。可以先比较概率预测的对数损失、排序前若干比例的召回率和不同用户组的表现，但运营干预的真实增量效果需要另外设计随机实验。高流失概率不等于高可挽回概率：某些用户风险很高，但任何优惠都无法改变其行为；另一些用户本来就会回来，发放优惠只是增加成本。预测契约为后续行动提供信息，却不能替代行动效果的识别。

<a id="deep-dive-1"></a>
### 深入讲解：信息、目标与行动是三个不同对象

可以把时点 $t$ 已经可用的信息集合记为 $\mathcal I_t$。预测规则应当是这个集合的函数：两个世界如果截至时点 $t$ 的可见信息完全相同，部署系统就不应因为未来结果不同而给出不同预测。用这种方式思考，比逐个检查字段名更可靠，因为泄漏常常藏在聚合规则、筛选条件或特征拟合步骤里。一个字段即使叫“历史活跃度”，若统计截止日期是全数据最后一天，也包含未来。

目标 $Y$ 是要预测的结果，行动 $A$ 是预测后采取的操作。行动可能改变目标，所以完整系统存在时间顺序：先看到历史信息，再预测，再行动，最后观察结果。若训练数据来自过去已经实施的优惠策略，那么记录到的回访率包含过去行动的影响。换一套行动策略后，原来的条件分布不一定保持不变。这不是分类器实现错误，而是数据生成机制被系统本身改变。

机器学习任务的难度也依赖输入信息。设某个结果本身有随机性，即使拥有所有合法输入，也可能无法精确预测个体结果；若增加结果发生后的字段，预测可以突然变得容易，却失去部署意义。因此“这个标签可预测吗”必须连同“在什么信息条件下、什么时点、什么总体上”一起回答。后续关于不可约误差的讨论正建立在固定信息集合之上。

<a id="chapter-foundations-01-heading-6"></a>

### 1.2 任务契约如何落到一张表

推荐把每行样本保存为“实体标识、预测时点、特征版本、标签窗口、标签成熟标志、目标值”。实体标识主要用于去重、分组和审计，并不自动成为模型输入。特征版本标识计算口径，以免同名字段在不同月份含义变化。成熟标志说明未来观察是否完整，它和目标值必须分开：未知结果不是负例。

一份可执行契约还应规定缺失值的含义。例如没有交易可能表示确实没有购买、数据没有同步，或该用户根本不属于交易系统。把三者一律填零会改变学习问题。适当情况下可以同时保留数值与缺失指示，但指示本身也可能编码采集渠道、设备型号或业务流程，部署时这些关联是否稳定还要验证。

最后把目标、特征和评价一一对应。预测七天不回访，就不要用三十天回访标签评价；只打算服务移动端新用户，就不能只报告全站老用户的平均分数；输出要用于容量受限的人工审核，就应报告实际容量下的精确率与召回率。评价不是在训练结束后随意选择一个好看的数字，而是任务定义的一部分。

<a id="sec-2"></a>
## 2. 模型、参数与训练算法

<a id="chapter-foundations-01-heading-8"></a>

### 2.1 模型是函数族，训练是选择规则

线性回归模型族可以写为 $f_\theta(x)=b+w^\top x$，参数 $\theta=(b,w)$ 决定具体函数。神经网络同样给出一个参数化函数族，只是组合结构更复杂。决策树也可以看成一组函数，其参数包含分裂变量、阈值和叶节点输出。模型的共同点不是“都需要梯度”，而是规定输入如何映射到输出以及允许哪些映射出现。

训练算法接收数据并产生一个模型，可写为 $\mathcal A(S)=f_S$。同一个线性模型，可以用正规方程、梯度下降或随机梯度下降估计；相同的梯度下降算法，也可以优化线性模型或深层网络。若不区分模型族和训练规则，就容易把优化失败解释为模型表达能力不足，或者把复杂模型的改善归因于某个优化器名称。

还要区分函数表示能力与可学习性。一个函数族能够表示任意训练标签，并不意味着有限样本足以确定部署时的正确函数。极端例子是记忆查表：训练点输出其标签，其他点统一输出零。它可以实现零训练误差，却没有给未见输入提供可靠结构。可学习性需要某种约束、先验、数据分布条件或算法偏好，让已观察点的信息能合理延伸到未观察点。

<a id="chapter-foundations-01-heading-9"></a>

### 2.2 参数、超参数和流程状态

参数通常指训练过程直接拟合的量，例如权重或树的叶节点值；超参数指在更外层规定训练方式的量，例如正则系数、树深、学习率和训练轮数。这个区分是相对于流程而言的，不是变量固有的属性。某个算法可以把学习率作为人工设定的超参数，另一个元学习过程也可以从任务集合中学习更新规则。

数据预处理同样有需要拟合的状态。标准化的训练均值与方差、词表、缺失值填补数值、降维方向以及类别编码映射，都是完整预测系统的一部分。它们未必属于回归器的参数对象，却会影响预测。把测试集用于拟合这些状态，可能已经利用了不应使用的信息；这种利用是否构成泄漏，要根据目标协议判断，不能仅凭“没有用到测试标签”就宣布安全。

<a id="sec-2-1"></a>
### 机制展开：参数由训练学得，超参数由选择流程确定

考虑岭回归目标 $n^{-1}\sum_i(y_i-b-w^\top x_i)^2+\lambda\|w\|_2^2$。固定 $\lambda$ 后，内层训练寻找 $b,w$；外层通过训练集与验证集选择 $\lambda$。若同时比较是否标准化、不同特征子集和三种异常值处理方式，这些选择也属于外层算法。最终被选中的并非一个孤立的权重向量，而是一条完整的数据处理和预测路径。

早停可以说明两层的交互。每轮梯度更新产生一组参数，用验证集决定在哪一轮停止，相当于以验证表现选择训练时间。因此验证集已经参与模型选择，不能再把该次最优验证分数当作完全独立的测试证据。反复人工观察错误并改特征，也会把人工决策纳入选择过程，即使代码里没有显式的网格搜索。

超参数不是“不能学习”的参数，更不意味着可以无限试验而不付出统计代价。它们通常在较小的数据量上被反复比较，容易使选择结果适应验证噪声。合理的评价对象往往是“在给定预算内如何调参的整个流程”，而不是事后挑出的最好一次运行。第二章会进一步解释嵌套评估和独立测试的作用。

<a id="chapter-foundations-01-heading-11"></a>

### 2.3 一次完整手算：损失下降不等于任务完成

设只有一个无截距线性参数 $w$，训练数据为 $(1,2)$、$(2,4)$，目标为平均平方误差 $L(w)=[(w-2)^2+(2w-4)^2]/2$。合并得到 $L(w)=2.5(w-2)^2$，导数为 $5(w-2)$。从 $w_0=0$、学习率 $\eta=0.1$ 出发，第一次更新是 $w_1=0-0.1(-10)=1$，第二次是 $w_2=1-0.1(-5)=1.5$。损失依次为 $10,2.5,0.625$，每次缩小到原来的四分之一。

这个结果证明在这组数据和步长下，算法正在优化规定目标。它尚未证明未来数据仍满足 $y=2x$，更未证明平方误差对应业务成本。若部署时真实规律改变为 $y=-2x$，训练依然可以完美收敛，实际表现却很差；若业务只关心绝对误差，训练目标的选择仍须讨论。优化正确、统计假设合理、决策目标匹配，是三个需要分别检验的条件。

模型还具有随机性。初始化、样本顺序、采样和硬件计算细节可能影响最后参数。复现实验需要记录这些来源，但复现同一个随机种子只说明某次过程可重复，不能说明结果对随机性稳定。对于波动明显的任务，应比较多个事先确定的运行，并解释平均值、离散程度和失败情况，而不是只报告最幸运的一次。

<a id="chapter-foundations-01-heading-12"></a>

### 2.4 表达能力、优化能力与样本信息的三角关系

若模型族不能表示近似正确的规律，即使无限训练也会保留近似误差；若函数族足够表达，但训练算法无法找到合适解，会出现优化误差；即使两者都理想，有限样本与目标分布的差异仍会产生估计误差。这三种来源在真实项目中会混合，不能仅凭训练曲线外形机械诊断。

可以通过干预形成证据。先检查一个很小的数据子集能否被拟合，以排查标签错位和实现错误；增加模型容量观察训练损失是否下降，以判断表达限制；保持模型固定增加训练数据，观察独立验证表现是否稳定改善，以研究数据限制。这些现象提供诊断线索，却不是一般定理。例如增加容量也会改变优化难度，增加数据也可能同时改变数据质量，因此实验要尽量一次控制一个因素。

<a id="sec-3"></a>
## 3. 基线的数学原理与公平比较

<a id="chapter-foundations-01-heading-14"></a>

### 3.1 为什么均值是平方误差下的最佳常数

假设只能输出常数 $c$，训练平方误差为 $Q(c)=n^{-1}\sum_i(y_i-c)^2$。求导得到 $Q'(c)=2(c-\bar y)$，二阶导数为二，所以唯一最优解是训练均值 $\bar y$。在总体层面，若二阶矩有限，恒等式 $E[(Y-c)^2]=\operatorname{Var}(Y)+(E[Y]-c)^2$ 表明总体最优常数为 $E[Y]$，最小风险是方差。

取训练目标 $1,2,3,10$，均值为四。预测四时平方误差和为 $9+4+1+36=50$，平均为 $12.5$。若预测中位数区间内的 $2.5$，平方误差和为 $2.25+0.25+0.25+56.25=59$，平均 $14.75$。这里较大的目标十显著影响平方误差，因此均值向它靠近。所谓“均值受异常值影响”，并不是均值算错了，而是平方损失确实给较大残差更重的惩罚。

<a id="chapter-foundations-01-heading-15"></a>

### 3.2 为什么绝对误差选择中位数

绝对误差目标 $A(c)=\sum_i|y_i-c|$ 在样本点处不可微，但在相邻样本之间，其斜率等于左侧样本个数减去右侧样本个数。若左侧更多，继续向右移动会增加总误差；若右侧更多，向右移动会降低总误差。因而达到左右各至少一半的中位数位置时最优。偶数样本时，两个中间次序统计量之间的所有值都可以最优。

仍取 $1,2,3,10$，任何 $c\in[2,3]$ 的绝对误差和都是十。预测均值四的绝对误差和为 $3+2+1+6=12$。由此可见，“最佳简单预测”没有脱离损失函数的统一答案。把均值基线拿来评价绝对误差虽然可以计算，但它不是该损失下最强的常数基线；若复杂模型只比这个不匹配的基线略好，结论可能被夸大。

更一般地，分位数回归使用非对称的检查损失。低估的代价越大，最优分位数就越高。库存需求预测若缺货成本远高于积压成本，预测中位数不一定符合实际需要。基线推导因此也是理解模型目标的入口：先研究没有任何输入时应该输出什么，再研究特征能带来多少改善。

<a id="chapter-foundations-01-heading-16"></a>

### 3.3 分类基率与概率基线

对于零一损失，常数分类器应选择训练集多数类。若正例比例为 $\hat\pi$，预测正类的错误率是 $1-\hat\pi$，预测负类的错误率是 $\hat\pi$，选择较小者即可。对于概率对数损失，常数概率 $q$ 的目标为 $-[\hat\pi\log q+(1-\hat\pi)\log(1-q)]$。在比例位于零和一之间时，求导并令零得到 $q=\hat\pi$，而不是多数类的硬标签。

例如训练数据正例占两成，概率基线输出 $0.2$。平均对数损失为 $-0.2\log0.2-0.8\log0.8\approx0.5004$，单位是自然对数对应的奈特。若输出 $0.5$，损失约 $0.6931$。若向所有样本输出零而正例确实存在，理想数学定义下损失为无穷大。实际库可能做截断以避免数值溢出，但截断并不会让零概率预测变得合理。

概率基线的比例只能从允许使用的数据估计。用测试集正例比例作常数，再与只见过训练数据的模型比较，相当于给基线额外信息。部署先验已知的某些应用可以合理使用外部比例，但必须在协议中说明来源与时间。基线也属于学习流程，不能因为形式简单就忽略训练和评价边界。

<a id="chapter-foundations-01-heading-17"></a>

### 3.4 基线应该形成阶梯

第一层是常数或随机基线，回答任务是否被基率支配；第二层是已有业务规则，回答学习方法是否改善现实替代方案；第三层是简单但合理的统计模型，回答额外复杂度是否有价值。时间预测还应包括最近一期值和合适的季节性基线。例如每日流量有强烈周周期时，用昨天的流量与用上周同一天的流量可能具有完全不同的竞争力。

所谓公平比较，不仅是使用同一张测试表，还包括相同的信息可用性、标签口径、预处理拟合范围与决策容量。一个模型使用过去一年记录，另一个只使用一天记录，最终差距可能来自信息而非算法；一个方法经过大量人工调试，另一个使用明显不适合任务的默认设置，也不能直接得出普遍优越结论。比较应围绕具体可部署方案展开，而不是围绕算法名称评输赢。

强基线不必复杂。对表格任务，规范处理缺失、加入合理的时间聚合、使用简单线性模型，往往比随意堆叠模型更有解释力。这个经验不能反过来变成“简单模型永远更好”的口号。应把它变成可检验问题：复杂模型改善了哪些样本、改善幅度是否稳定、额外资源是否值得，以及在输入缺失或总体变化时改善是否还存在。

<a id="sec-4"></a>
## 4. 标签不是天然存在的真理

<a id="chapter-foundations-01-heading-19"></a>

### 4.1 潜在概念、操作定义与观测标签

学习任务常常涉及一个难以直接观测的概念，例如满意、欺诈、疾病严重程度或学习能力。数据表提供的却是某种可操作记录，例如是否投诉、是否被审核、某次检测结果或考试分数。概念与记录可以有关联，但通常不完全相同。理解这种差异，首先需要区分真正关心的量、采用的测量规则，以及测量后进入训练集的具体数值。

以“满意度”为例，用户没有投诉可能是满意，也可能是不知道投诉渠道、认为投诉没有作用，或已经离开。若把未投诉统一当成满意，模型学习到的条件概率是“在这套渠道和流程下会不会产生投诉记录”，而不是纯粹的心理满意度。这个模型也许对客服资源分配仍有用，但不能因此声称已经测量了全部用户体验。

操作定义不必完美，却必须公开而稳定。明确“七天没有有效登录”比模糊地声称“真实流失”更可研究，因为前者允许核对数据窗口、重复构造标签和比较方法。定义稳定之后，还可以研究它与长期留存等更深层目标之间的关系。若标签口径在实验中不断变化，模型效果的变化就无法与任务变化区分。

<a id="chapter-foundations-01-heading-20"></a>

### 4.2 标签噪声如何改变学习目标

设真实二分类标签为 $Y$，观测标签为 $\widetilde Y$。假设负例被错标为正例的概率为 $\alpha$，正例被错标为负例的概率为 $\beta$，且给定真实标签后翻转概率不依赖输入。记真实后验概率 $\eta(x)=P(Y=1\mid X=x)$，则由全概率公式得到

$$
P(\widetilde Y=1\mid X=x)=\alpha+(1-\alpha-\beta)\eta(x).
$$

这个公式说明观测概率通常不是原概率加一个均值为零的误差。若 $\alpha=\beta=0.1$，真实概率 $0.9$ 会变成观测概率 $0.82$，真实概率 $0.2$ 变成 $0.26$。当 $\alpha+\beta<1$ 时，映射严格单调，因此理想情况下排序可以保留；然而输出数值已经改变，按原业务成本设置的阈值未必还能直接使用。

对称噪声下，观测概率是否超过二分之一与真实概率是否超过二分之一一致，因此无成本差异的理想分类边界可以保持。非对称噪声则一般不同：令观测概率等于二分之一，得到真实概率阈值 $(0.5-\alpha)/(1-\alpha-\beta)$。例如 $\alpha=0.2,\beta=0.1$ 时，阈值约为 $0.4286$，已经偏离二分之一。这里的结论依赖噪声假设；若难例更易被错标，噪声与输入有关，上述简单校正就不再充分。

更大的困难是噪声率通常未知。仅观察输入与被污染的标签，可能存在多组真实概率和噪声率解释同一观测分布。此时需要额外信息，例如高质量复核子集、重复标注、对噪声机制的假设，或与任务相关的外部约束。不能先把所有不一致样本归为噪声，再用这种解释保护模型；不一致也可能来自模型错误或总体变化。

<a id="chapter-foundations-01-heading-21"></a>

### 4.3 多人标注与“标准答案”

对主观文本、图像边界和复杂决策，多个标注者出现分歧很常见。多数表决是一种汇总规则，不是自动获得真理的仪式。若所有人共同受到同一偏见影响，增加人数未必消除系统误差；若任务本身允许多种合理答案，强行压成单标签可能丢失重要信息。

可以先记录标注指南、标注者背景、是否独立判断及争议解决方式，再查看分歧是否集中于某些类别或群体。重复标注能够帮助估计一致性，但一致性高也只说明标注者彼此接近。若判断都依赖同一个有问题的参考材料，完全一致仍可能错误。评价标准的质量和模型质量需要分别研究。

在部分任务中，保留软标签比抹去分歧更合理。例如五位独立标注者中三位认为某文本有讽刺意味，可以将比例作为不确定性描述的一部分。但比例的含义依赖标注者如何抽样，不能直接当作所有读者中的真实概率。对争议样本还可以设置人工复核、允许多个可接受答案，或把分歧作为独立研究对象。

<a id="chapter-foundations-01-heading-22"></a>

### 4.4 延迟标签、删失与选择性标签

预测未来三十天是否违约时，一个刚刚放款三天的样本还没有完整观察期。它既不是已确认的负例，也不应因为暂时没有违约记录就被填为零。若将大量近期样本误作负例，模型可能学习到“日期越近风险越低”的虚假规律。最简单的处理是等待标签成熟，再将成熟样本纳入训练与评价；如果要使用不完整观察，则需要专门处理删失的模型与假设。

选择性标签更加隐蔽。银行只知道获批贷款的还款结果，不知道被拒申请如果获批会怎样；医生只对部分患者进行昂贵检查，未检查者缺少同一质量的标签。只在有标签子集上学习，得到的是被历史策略筛选后的关系。把未获批或未检查者当作负例，不仅是数值填补错误，还改变了目标事件本身。

解决这类问题通常需要重新审视数据收集策略，而不只是换算法。可以在允许范围内补充随机审核、收集外部后续信息、显式建模选择机制，或者限制结论适用范围。每种方式都有自己的识别假设。应准确说明现有数据能够回答哪些问题，无法从观测数据自动恢复的部分不能用更复杂的网络填补。

<a id="sec-5"></a>
## 5. 时间边界、采样机制与独立性

<a id="chapter-foundations-01-heading-24"></a>

### 5.1 三种时间需要同时检查

事件时间是行为实际发生的时间，入库时间是系统记录可用的时间，预测时间是模型必须输出的时间。离线构造样本时，需要按当时真实可用的信息回放，而不是从今天完整的数据库向过去查询。特别是会被修订的字段，例如最终订单状态、结算金额和审核等级，当前表里的值未必等于历史时点能看到的值。

假设周一发生订单，周二申请退款，周五退款完成。周三预测未来退款是否成功时，可以使用周二申请这一信息；若任务改为周一成交时预测未来退款，周二申请就是未来泄漏。相同字段在不同任务中可能从合法输入变为答案的一部分。因此不存在一个脱离预测时点的“永久安全特征清单”。

特征聚合也必须遵守边界。用户过去七天消费总额可以合法，但若构造方式先按全表计算全生命周期总消费，再把结果回填到每个历史日期，那么早期样本会看到未来交易。类似问题也会出现在累计计数、最后一次活跃时间、类别频率和目标编码中。代码没有直接读取目标列，也可能通过时间和聚合范围间接泄漏结果。

<a id="chapter-foundations-01-heading-25"></a>

### 5.2 随机划分究竟模拟什么

随机划分适合的核心场景是：部署对象与现有样本来自相近分布，且划分单位近似独立。若每个样本是一位互不重叠的用户，用户级随机划分可以模拟相近时期的新用户；若一位用户有多行，按行随机则允许同一用户同时出现在两边。后者可能是合理的个性化任务，但不能伪装成新用户泛化。

时间划分通常更接近未来部署，但它也没有自动解决所有问题。训练标签的观察窗口可能伸入验证特征期；相邻时段可能共享实体与事件；市场促销和系统升级可能造成分布突变。需要绘制时间线，核对每一条训练样本何时产生、何时标签成熟、拟合动作在何时完成。若标签需要七天成熟，月底模拟训练就不能使用月底前一天生成但下月才成熟的目标。

某些任务确实允许在测试时使用同一批无标签输入进行适应，例如预先声明的传导学习或批量领域适应。此时测试特征参与处理未必违反任务定义，但其评价对象已经不同于逐条独立到达的归纳预测。关键不是机械禁止所有测试特征，而是让信息使用方式与真实部署相符，并使比较双方遵守相同协议。

<a id="chapter-foundations-01-heading-26"></a>

### 5.3 重复样本为什么会制造假证据

假设一份文本数据存在大量近重复内容，一篇文章略改标题后出现十次。随机划分后，训练集很可能已经包含测试文章的近似副本。模型的高分反映了重复内容匹配能力，未必说明它能够理解新主题。图像重复、同一病人多次拍片、同一设备连续测量也有类似结构。

重复并不一定都应该删除。若真实业务会频繁遇到相同对象，重复匹配本身可能有价值；但应分别报告已见实体和未见实体的结果。对统计不确定性的估计，也不能把强相关记录当作同等数量的独立证据。分组划分、按组重采样和基于真实采样单元的误差分析，往往比继续增加行数更有意义。

样本权重也要区分用途。为了让高频用户不支配目标，可以按用户调整权重；为了修正抽样概率，也可以使用逆概率权重；为了强调某种业务成本，又可能采用成本权重。三者公式上都可能体现为加权平均，但解释不同。若多个权重同时出现，需要写清它们对应的目标总体和损失，而不是把“加权”当成万能修补。

<a id="chapter-foundations-01-heading-27"></a>

### 5.4 采样分布与部署分布

设训练来自分布 $P$，部署来自分布 $Q$。如果两者不同，经验风险估计的是训练分布下的表现，而部署关心的是 $E_Q[\ell]$。在特定条件下可以使用权重 $w(x)=q(x)/p(x)$，将目标风险写成 $E_P[w(X)\ell]$。这种只按输入加权的表达还要求条件结果分布保持不变，即两边的 $Y\mid X$ 一致，并且目标输入所在区域在训练中有支持。

权重并不创造不存在的信息。若目标总体中有一种设备类型从未出现在训练集，分母为零，对应区域的表现无法通过有限权重估计。即使支持存在，极大权重也会放大少量样本的随机波动。裁剪权重可以减小方差，却一般引入偏差，因此应该解释具体折中并检查敏感性。

许多部署变化不满足条件分布不变。用户偏好改变、标签规则变更或新政策干预，都可能直接改变相同输入下的结果概率。此时简单重加权并不足够，需要新标签、重新训练、分层分析或更明确的变化假设。先判断变化发生在哪一层，再讨论适应方法，比对所有漂移都使用同一种校正更有根据。

<a id="sec-6"></a>
## 6. 经验风险、总体风险与学习保证

<a id="sec-6-1"></a>
### 把任务定义写成可检验的随机对象

固定一个输入输出分布 $P$，模型 $f$ 的总体风险定义为 $R(f)=E_{(X,Y)\sim P}[\ell(f(X),Y)]$。它是对未来随机样本的平均损失，不是已收集表格上的一个确定分数。训练集上的经验风险为 $\widehat R_S(f)=n^{-1}\sum_{i=1}^n\ell(f(X_i),Y_i)$。经验风险最小化寻找函数族 $\mathcal F$ 中使经验风险最小的函数；正则化则在目标中加入对复杂度或参数的约束。

这里的“风险”是损失的期望，不必理解为灾难或金融风险。改变损失，就改变你要求平均优化的东西。零一损失统计分类错误率，平方损失重视数值偏差，对数损失评价给真实结果分配的概率。若任务需要排序或容量约束决策，单样本损失还未必完整描述最终目标，评价应补充相应的集合级指标。

<a id="chapter-foundations-01-heading-30"></a>

### 6.1 固定函数的大数定律为何不够

对一个事先固定的函数，若样本独立同分布且损失满足相应可积条件，经验平均会随样本增多接近总体平均。但训练后的函数 $f_S$ 本身依赖同一组样本。不能在看到数据后选出表现最好的函数，然后把它当成与数据无关的固定函数直接套结论。这种依赖正是训练分数通常偏乐观的来源。

极端例子是在没有可预测信号的随机标签数据上，允许函数族包含所有查表函数。训练算法记住每个训练输入的随机标签，经验错误为零；新的独立输入仍然只有随机标签，因此最佳预测也只能达到相应基率水平。对每个事先固定函数，样本平均仍可具有良好性质，但从巨大函数族中自适应选择，已经改变了分析对象。

这也解释了为什么“样本有十万条，所以根据大数定律一定不会过拟合”缺少条件。十万是否足够，取决于候选复杂度、信号强度、噪声、相关性、选择预算和目标精度。大数定律给出某种极限关系，并不直接提供对任何学习流程都适用的有限样本保证。

<a id="chapter-foundations-01-heading-31"></a>

### 6.2 有限函数族的一致收敛证明

现在给出一个能完整推导的情形。设函数族包含 $M$ 个函数，在看到这批评价样本之前已经固定；损失位于零和一之间；样本独立同分布。对每个固定函数，Hoeffding 不等式给出

$$
P\bigl(|R(f)-\widehat R_S(f)|>\varepsilon\bigr)
\le 2\exp(-2n\varepsilon^2).
$$

“至少有一个函数偏差超过界”的事件是这 $M$ 个事件的并集。联合界不要求各事件相互独立，因此其概率至多为 $2M\exp(-2n\varepsilon^2)$。令这个量等于 $\delta$，得到以至少 $1-\delta$ 的概率，对所有候选同时成立

$$
|R(f)-\widehat R_S(f)|\le
\varepsilon_n=\sqrt{\frac{\log(2M/\delta)}{2n}}.
$$

注意“同时”二字。它意味着即使随后依据同一份样本从这组候选中选择函数，选中的那个也受此界控制。假设 $\widehat f$ 是经验风险最小者，$f^*$ 是族内总体风险最小者，则

$$
R(\widehat f)\le\widehat R_S(\widehat f)+\varepsilon_n
\le\widehat R_S(f^*)+\varepsilon_n
\le R(f^*)+2\varepsilon_n.
$$

中间一步使用经验最优性，两端使用一致偏差界。若数值优化只做到距离最小经验风险不超过 $\zeta$，同样推导会多出 $\zeta$。这明确区分统计误差和优化误差，而不是将所有问题笼统归为“没有训练好”。

<a id="chapter-foundations-01-heading-32"></a>

### 6.3 数值规模与适用条件

取 $M=100,n=10000,\delta=0.05$，则 $\log(4000)\approx8.294$，偏差界约为 $0.02036$，族内过剩风险界约为 $0.04073$。这个界通常较保守，但展示了候选数量、样本数和置信要求如何共同影响保证。它不是对任意深度网络实际误差的精确预测，也不能将连续参数空间中“训练过一百次”直接理解为只包含一百个固定函数。

如果一百个候选模型在独立训练集上训练完成，再使用一批独立验证样本进行选择，可以条件于训练集将这一百个已训练函数视为固定候选，并对验证样本使用上述界。相反，若候选函数反复根据验证错误被人工修改，它们不再是相对于验证样本预先固定的一百个函数；仅计最终保留的候选数不足以概括全部适应过程。

假设也不能随意省略。无界平方损失不直接满足上述有界损失版本；强相关时间记录不满足独立采样；测试总体改变时，界控制的仍是原分布风险。可以通过其他集中不等式、依赖结构假设、稳定性或复杂度工具扩展分析，但每次扩展都需要说明新的条件，不能把公式当作只需代入样本量的装饰。

<a id="chapter-foundations-01-heading-33"></a>

### 6.4 学习误差的三段分解

令 $R^*$ 是所有允许的可测预测规则中的最优风险，$f^*_{\mathcal F}$ 是模型族内最优函数，$\widehat f$ 是经验最优函数，$\widetilde f$ 是实际算法返回的函数。可以研究近似误差 $R(f^*_{\mathcal F})-R^*$、有限样本选择引起的估计误差，以及优化没有精确达到经验最优造成的偏差。实际总体风险中的优化影响不能仅凭训练损失差无条件等同，但在统一偏差控制下，可以用经验优化差参与上界。

更直接地，若实际函数的经验风险距离族内最小值不超过 $\zeta$，并有统一偏差 $\varepsilon$，便得到 $R(\widetilde f)-R^*\le[R(f^*_{\mathcal F})-R^*]+2\varepsilon+\zeta$。三个项分别对应模型限制、统计证据和求解精度。这个关系给出一个重要研究方向：增加容量可能减小第一项，却增加需要控制的统计复杂度；更长训练可以减小第三项，却未必改善第二项。

这里的最优风险还依赖可用输入。若目标即使给定输入仍随机，平方损失下最优函数是条件均值，仍保留条件方差的平均值。所谓不可约误差只是相对于固定信息集合和损失而言。增加新的合法测量可能降低它；使用未来答案虽然也会降低误差，却已经改变了预测任务。

<a id="decision"></a>
## 7. 从概率预测到实际决策

<a id="chapter-foundations-01-heading-35"></a>

### 7.1 条件风险说明应该输出什么

设已经观察到输入 $x$，平方损失下输出数值 $a$ 的条件风险为 $E[(Y-a)^2\mid X=x]$。把 $Y-a$ 拆成 $Y-E[Y\mid x]+E[Y\mid x]-a$，展开平方后，交叉项因为条件均值为零而消失，得到条件方差与 $[E[Y\mid x]-a]^2$ 之和。因此最优输出是条件均值。这个推导与前面常数均值基线完全平行，只是从整体分布改为给定输入后的分布。

绝对损失的最优输出则是条件中位数，非对称绝对损失对应条件分位数。它们都在学习同一条件分布的不同摘要。若目标分布右偏，例如多数订单金额很小、少数金额特别大，均值和中位数预测可以相差很多。不能因为两个模型输出不同就认为其中一个必然错误，先检查它们各自优化的损失。

对二分类，设真实正例概率为 $\eta$，预测概率为 $q$。对数损失的条件风险为 $-\eta\log q-(1-\eta)\log(1-q)$。其导数为 $(q-\eta)/[q(1-q)]$，因此内部唯一最优值是 $q=\eta$。当真实概率等于零或一，最优值在边界上，以通常的极限约定处理。这说明理想的对数损失优化旨在恢复概率，而不只恢复某个分类边界。

<a id="chapter-foundations-01-heading-36"></a>

### 7.2 成本不对称时的阈值推导

假设假正例成本为 $c_{FP}$，假负例成本为 $c_{FN}$，正确决策成本为零。给定正例概率 $p$，采取正类行动的条件成本为 $c_{FP}(1-p)$，采取负类行动的条件成本为 $c_{FN}p$。选择成本较小的行动，因此阈值为

$$
a(x)=1\quad\text{当}\quad p(x)\ge\frac{c_{FP}}{c_{FP}+c_{FN}}.
$$

例如误报成本二，漏报成本八，阈值为 $0.2$。某人的正例概率只有 $0.3$，仍应采取正类行动，因为两种成本分别为 $1.4$ 和 $2.4$。这并不表示模型认为正例“更可能发生”，而是决策成本使较低概率也值得响应。概率阈值二分之一只对应一种特殊的对称成本情形。

若行动还有固定处理费用，应将其加入对应行动成本。如果存在多个行动，例如不处理、自动提醒、人工核查，需要对每个行动计算对不同结果的条件期望成本，选择最小者。此时单一二分类阈值未必充分，尤其当不同用户的核查成本、收益和行动效果不同。决策问题应按自身结构建模，而不是强行全部压成是否超过某个分数。

<a id="chapter-foundations-01-heading-37"></a>

### 7.3 排序能力与概率准确性

模型可能把高风险人群排在前面，却系统高估所有概率。若只允许审核排名前一百人，严格单调变换分数不会改变排序；但若按固定成本阈值行动，单调变换可能改变被选对象。因此排序指标和概率指标回答不同问题。一个排序很好的模型，仍可能因为概率偏差造成成本错误。

例如真实概率是 $0.1,0.3,0.6,0.9$，模型输出其平方 $0.01,0.09,0.36,0.81$，顺序完全一致，但所有中间概率偏低。在阈值 $0.2$ 下，真实最优应选择后三人，模型只选择后两人。若只看排序，无法发现第二人的行动被遗漏。校准方法可以研究概率修正，但其有效性仍依赖校准样本与部署条件。

反过来，一个永远输出总体基率的模型，在总体层面可能看似校准，却没有区分个体的能力。评价概率质量时，要同时考虑校准与信息分辨力；只报告一条平均校准误差，也可能掩盖分组错误或分箱选择的影响。模型评估主题会进一步解释适当评分规则、校准图和阈值选择的关系。

## 8. 不同学习范式在学习什么

<a id="chapter-foundations-01-heading-39"></a>

### 8.1 监督学习与自监督学习

监督学习依赖输入和目标的配对样本，但“人工标注”不是唯一标签来源。价格、传感器读数和后续事件也可以产生监督信号。决定范式的是学习目标的构造方式，而不是标签是否由人工逐个填写。回归和分类的区分取决于目标空间与损失，不能仅根据标签在文件中用整数还是浮点数保存来判断。

自监督学习从数据自身构造预测目标，例如遮住部分内容再恢复，或根据上下文预测下一符号。它没有消除目标设计，而是把目标设计转移到数据变换和预测任务中。遮蔽策略、正负样本构造、上下文范围会决定模型受到什么训练信号。模型可能学到有用表示，也可能主要利用局部捷径，因此仍需通过后续任务与消融实验检验。

预训练得到的表示不是与任务无关的“纯知识”。它压缩并突出训练目标奖励的信息，同时可能忽略对其他任务重要的差异。若增广总是去掉颜色，模型可能形成颜色不变表示；这对某些形状识别有益，却可能损害依赖颜色的任务。理解训练信号如何塑造不变性，是比较表示学习方法的关键。

<a id="chapter-foundations-01-heading-40"></a>

### 8.2 无监督学习中的结构来自假设

聚类常被描述为让数据“自己告诉我们分组”。但算法必须先决定距离、尺度、簇形状和优化准则。欧氏距离下的紧凑球状簇，与基于密度连通的簇不是同一种对象。同一批点可能按地理位置、消费规模或行为模式形成不同分组；没有唯一标签，不表示没有建模假设。

把收入从元改成万元，如果没有重新处理尺度，基于距离的方法就可能改变结果。类别编码为一二三也可能引入不存在的顺序与距离。无监督流程因此更需要解释表示与度量的含义，不能只看图形是否漂亮。低维可视化中的间隔还可能来自算法的局部结构强调，不等价于原空间存在明显分离。

密度估计、降维与聚类也不应混为一谈。密度模型描述概率分布，降维寻找受约束的表示，聚类输出某种分组。一个密度拟合较好的模型未必提供最适合业务的簇；一个保留重建信息的表示，也未必最利于分类。研究问题先明确，再选择与之匹配的无监督目标。

<a id="chapter-foundations-01-heading-41"></a>

### 8.3 强化学习为何不能简单当成分类

强化学习中，行动影响未来状态以及接下来能看到的数据，目标通常是累积回报。当前看似收益较低的行动，可能为了获取信息或进入长期更有利的状态。因此仅把历史“高回报行动”当作分类标签，会忽略状态访问偏差、延迟效果和探索需求。

例如推荐系统只展示了历史策略选择的内容，那么未展示内容的点击结果没有被观察。直接从日志中学习“哪个内容最好”，需要处理行为策略的选择机制与覆盖问题。若某种行动从未在某类用户上尝试，其效果无法仅凭已有结果可靠评估。这与前面选择性标签的困难相通，但序贯决策还叠加了长期路径依赖。

离线强化学习、模仿学习和上下文赌博机分别在不同条件下处理这些问题。它们可以使用类似的网络结构，却优化不同对象并需要不同假设。识别范式的最好方式是画出信息与行动的时间顺序，指出哪些结果被观察、行动会改变什么，以及最终评价是单次预测还是长期策略价值。

<a id="case-study"></a>
## 9. 完整案例：一套用户回访预测协议

<a id="chapter-foundations-01-heading-43"></a>

### 9.1 从原始需求到可训练样本

继续使用“周一预测未来七天不回访”的任务。假设平台在每周一生成符合条件的用户快照，只使用截至上周六已经可靠入库的数据，并等待七天目标窗口及额外一天入库缓冲后确认标签。一个特征可以是最近七天有效登录天数，另一个是最近三十天消费金额。是否允许使用用户标识必须根据部署目标决定：如果目标是适用于新用户，应避免直接把标识当作可记忆类别，并按实体边界设计评价。

为了模拟未来上线，在较早月份拟合模型，在随后月份选择超参数，再用更晚且未参与选择的月份作最终测试。训练集只能包含在模拟训练日已经成熟的标签。若还要研究陌生用户表现，可以在时间测试内另设从未在训练出现的用户组。时间泛化和新实体泛化是两个维度，不必企图让一个平均数字同时回答所有问题。

数据检查先统计候选用户数、被排除数、未成熟标签数以及缺失来源。随后核对每个特征的可用时点，检查近重复记录和异常集中日期。只有这些检查完成，才拟合预处理状态与模型。把审计放到训练后也能发现问题，但反复看测试异常再修改流程，会使最终测试失去最初的独立意义。

<a id="chapter-foundations-01-heading-44"></a>

### 9.2 三种预测方案的逐项比较

设某个独立测试月份有一千位用户，其中一百位实际不回访。方案甲永远预测会回访；方案乙采用一个已有规则，预测一百五十人不回访，其中命中四十人；方案丙使用模型，预测二百人不回访，其中命中七十人。可以整理为下表。

| 方案 | 真正例 | 假正例 | 假负例 | 真负例 | 准确率 | 正类召回率 | 正类精确率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 甲：全负类 | 0 | 0 | 100 | 900 | 90% | 0% | 无正类预测，未定义 |
| 乙：已有规则 | 40 | 110 | 60 | 790 | 83% | 40% | 26.67% |
| 丙：学习模型 | 70 | 130 | 30 | 770 | 84% | 70% | 35% |

如果只看准确率，甲最好；若漏报成本八、误报成本二，甲的总成本为八百，乙为 $60\times8+110\times2=700$，丙为 $30\times8+130\times2=500$。丙虽然准确率低于全负基线，却在规定成本下更好。这没有矛盾，因为两个指标优化的目标不同。应在实验前明确主要决策标准，而不是看到结果后选择对模型最有利的指标。

这里的成本表是假设预测错误对应固定代价。如果实际行动是优惠券，其收益取决于行动对回访的增量影响，那么上述成本不是行动效果的完整模型。它可以帮助评价识别高风险用户的价值，但不能直接把减少的假负例数解释为新增回访人数。要评估干预，应将模型筛选与随机行动实验结合。

<a id="chapter-foundations-01-heading-45"></a>

### 9.3 概率质量需要另外核验

硬分类表格没有展示概率。两个模型在某个阈值上可以产生完全相同的分类，却给出截然不同的置信度。应使用对数损失等概率指标、校准分析和分层分布，检查输出是否适合成本阈值。若测试正例比例是一成，而训练采样时人为平衡到一半，原始模型概率可能对应采样分布，不能未经处理直接当作部署概率。

对于仅改变类别先验、保持类条件输入分布不变的理想情形，可以用先验比修正后验赔率。但这种修正需要相关假设，不是所有过采样训练模型都能自动恢复概率。训练损失中的类权重、模型错设和正则化也会影响输出，应在真实基率的独立数据上验证。

报告还应列出用户分组，例如新老用户、渠道、缺失程度和活跃水平。总体收益可能由人数最多的组贡献，同时某个小组明显退化。小组样本少时估计波动更大，不能凭单次比例作过强判断；但也不能用总体平均掩盖它。应同时呈现样本量、错误数和不确定性，并根据实际用途决定后续数据收集。

## 10. 模型成功和失败的解释边界

<a id="chapter-foundations-01-heading-47"></a>

### 10.1 预测关联不等于行动效果

某个特征与结果有稳定关联，足以帮助预测，却未必适合直接干预。雨伞销量可以预测降雨，但增加雨伞销量不会导致下雨。更接近业务的例子是客服联系次数：联系多的用户也许更容易流失，因为他们原本遇到了严重问题；不能由此推断减少客服联系可以降低流失。

因果问题询问如果主动改变某个行动，结果会怎样，涉及反事实比较。预测问题询问观察到这些信息时，结果的条件分布是什么。两者可以相互支持，却需要不同数据与假设。随机实验、合理的因果识别条件及对混杂的处理，是把预测系统转化为可靠行动系统的重要补充。

<a id="chapter-foundations-01-heading-48"></a>

### 10.2 高分也可能是学习了捷径

模型可能利用背景、设备水印、数据来源或记录流程，而不是你希望它使用的机制。医疗图像中某个医院的标记与疾病比例相关，模型利用标记可以在同分布测试中得分很高；换医院后关联消失，表现就下降。简单的随机划分可能保留这种捷径，因此不能独自证明模型学到了可迁移结构。

诊断可以通过按来源分组测试、遮挡特定区域、检查相似样本和设计反事实扰动形成证据。但解释方法的热力图或特征重要性并不直接等于因果机制，它们也受模型、相关特征和解释算法影响。更可靠的结论来自多个受控实验，而不是对一张可视化作直觉解读。

<a id="chapter-foundations-01-heading-49"></a>

### 10.3 平均改进需要与资源和稳定性共同评价

若复杂模型仅改善很小的平均损失，却显著增加推理延迟、维护成本或失败概率，是否值得使用取决于具体约束。研究中可以在固定预算下比较精度，或画出性能与成本的折中曲线；工程中还要检查输入缺失、服务中断和分布变化时的行为。资源不是独立于模型的附加话题，而是可部署学习系统的组成部分。

一次训练成功不足以说明流程稳定。应区分训练随机性、测试样本随机性和部署环境变化，它们对应不同的不确定性来源。多次训练主要反映第一种，重采样测试主要研究第二种，跨时间或跨来源评价提供第三种线索。把几个随机种子的标准差当作所有泛化不确定性，会低估其他来源。

<a id="research"></a>
## 11. 进阶研究：可识别性、归纳偏置与反馈

<a id="chapter-foundations-01-heading-51"></a>

### 11.1 为什么数据不能单独决定所有答案

给定有限训练点，总存在多个函数在训练点上输出相同，却在未见区域不同。如果不给函数族、平滑性、对称性或数据分布增加约束，就无法唯一确定如何外推。这是归纳学习的根本问题，而不是某种算法尚未足够强大。学习系统通过模型结构、正则化、数据增广和优化路径等方式偏好某些延伸。

归纳偏置并非只指偏差或缺点。卷积利用局部连接与权重共享，适合许多图像结构；时间序列模型利用顺序关系；图模型利用连接结构。这些假设缩小了需要从数据中学习的可能性空间。若假设与任务匹配，会提高样本利用效率；若不匹配，也会系统忽略重要规律。研究方法的价值在于说明偏置何时合理，而不是声称没有偏置。

可识别性则追问观测分布是否足以唯一确定你想要的对象。一个分类后验可以在给定联合分布下被定义，但隐藏因果方向、未尝试行动的效果或标签噪声率，可能无法从同样的观测数据唯一恢复。优化再充分也不能解决没有识别条件的问题，需要额外实验、变量或假设。

<a id="chapter-foundations-01-heading-52"></a>

### 11.2 训练一致性不等于统计一致性

训练损失持续下降是一种优化现象；统计一致性通常描述样本数趋于无穷时，学习规则的风险是否趋近某个最优风险。一个固定而过小的模型族可以在优化上完全收敛，却由于表达限制无法达到总体最优。反过来，一个表达足够丰富的模型族，如果复杂度增长不受控制，也未必具有统计一致性。

还应区分参数一致与预测风险一致。不同参数可能表示同一个函数，尤其在神经网络的置换对称性下，参数本身未必唯一；即使参数不接近某个指定数值，预测也可以接近最优。对于错设模型，真实规律可能根本不在参数族中，此时讨论参数是否恢复“真实值”就要先说明那个真实值是否存在。

一个可研究的问题是让模型容量随样本数增长，在近似误差下降和估计误差控制之间取得平衡。筛方法、结构风险最小化和正则化路径都与此有关。对具体算法证明一致性，需要同时处理函数族、损失、采样和求解条件，不能由“网络具有通用逼近能力”单独推出。

<a id="chapter-foundations-01-heading-53"></a>

### 11.3 上线后的反馈会改变未来训练集

预测系统上线后会影响哪些样本被观察。风险模型可能决定哪些申请获得批准，推荐模型决定哪些内容被展示，审核模型决定哪些记录被人工标注。下一轮训练数据因此受到上一轮模型影响。若把这些数据当作自然产生的独立样本，可能形成自我强化的选择偏差。

例如模型认为某类内容吸引力低，于是减少展示；后续日志中这类内容点击少，训练又把它判得更低。点击总量下降可能来自曝光减少，而不一定是条件点击率下降。需要记录展示机会、行动概率和采样机制，并根据任务设计探索或评估数据。没有覆盖的数据区域，不能靠重复训练同一流程自动变得可靠。

反馈研究还涉及策略稳定性。一个模型在固定旧分布上最优，部署后改变行为分布，新环境下最优点又可能移动。监控性能漂移只是起点，真正的研究需要明确系统如何响应预测与行动，以及在何种条件下迭代更新稳定。学习系统因此既是统计对象，也是与环境相互作用的过程。

<a id="sec-7"></a>
## 12. 分层练习与详细解析

<a id="chapter-foundations-01-heading-55"></a>

### 12.1 基础练习：从需求中找出遗漏

**题目。** 某团队要“根据用户最近行为预测高价值客户”，准备使用注册信息、累计消费金额和当前会员等级，随机划分记录并报告准确率。请指出至少六个尚未确定的关键条件。

**解析。** 首先，高价值究竟按未来金额、未来利润还是现有等级定义，需要明确；其次，一条记录是用户还是用户日期快照，决定独立单位；第三，要规定预测时点与观察窗口；第四，累计金额和会员等级必须重建到当时可见版本；第五，要说明服务新用户还是既有用户，并对应设计划分；第六，标签窗口与成熟条件必须固定。还应补充目标总体、类别基率、行动用途与错误成本。准确率只有在这些对象明确后，才具有可解释的分母和含义。

<a id="chapter-foundations-01-heading-56"></a>

### 12.2 推导练习：加权平方损失的常数基线

**题目。** 样本目标为 $1,3,10$，正权重分别为 $1,2,1$。求加权平方损失下的最优常数，并解释这个权重可能对应的不同任务含义。

**解析。** 令目标为 $Q(c)=\sum_iw_i(y_i-c)^2/\sum_iw_i$，对 $c$ 求导，最优条件是 $c\sum_iw_i=\sum_iw_iy_i$，所以最优常数为加权均值 $(1+6+10)/4=4.25$。二阶导数为二，故唯一最优。权重可以代表样本频率、抽样校正或业务重要性，但这些解释不能混用。若为了纠正抽样偏差，应依据采样机制确定权重；若为了强调高代价对象，则优化的已经是加权成本目标。

<a id="chapter-foundations-01-heading-57"></a>

### 12.3 概率练习：不对称标签噪声

**题目。** 真实正例概率为 $0.7$，负转正噪声率为 $0.1$，正转负噪声率为 $0.2$。计算观测正例概率。若模型准确学习观测概率，能否直接把它当作真实概率？

**解析。** 代入得到 $0.1+(1-0.1-0.2)\times0.7=0.59$。模型输出零点五九可以对观测标签很准确，却低估了真实正例概率。在噪声率已知、类别条件翻转假设成立且分母非零时，可以用 $(\widetilde\eta-\alpha)/(1-\alpha-\beta)$ 恢复真实概率。若噪声率依赖输入或未知，这个反演没有自动依据；有限样本误差还可能导致反演结果越界，需要研究估计方法及其不确定性。

<a id="chapter-foundations-01-heading-58"></a>

### 12.4 理论练习：候选数改变需要多少证据

**题目。** 对固定候选函数族使用第六节的有界损失一致界，希望族内经验最优模型的过剩风险不超过 $0.02$，置信参数 $\delta=0.05$，候选数 $M=100$。求这个上界提供的充分样本量。

**解析。** 要求 $2\sqrt{\log(2M/\delta)/(2n)}\le0.02$。平方并整理得到 $n\ge2\log(4000)/0.02^2\approx41470.25$，因此至少取四万一千四百七十一。这是特定上界给出的充分条件，不是问题的必要样本量。若函数候选依赖同一评价数据，或者损失不满足有界条件，不能直接沿用此答案。

<a id="sec-7-1"></a>
### 边界追问：高准确率是否可能只是基率

**题目。** 某测试集中一万条样本有一百个正例。全负类基线准确率为百分之九十九。模型准确率达到百分之九十九点一，是否足以证明有实用价值？

**解析。** 模型共犯九十次错误，但这个总数不能唯一确定错误组成。一种可能是真正例十、假负例九十、假正例零；另一种可能是真正例九十、假负例十、假正例八十。两者准确率相同，召回率分别为百分之十与百分之九十，人工处理量和成本也不同。需要完整混淆矩阵、阈值、成本与容量，再和真实替代方案比较。若声称差异具有统计稳定性，还要考虑样本相关性、同一测试集上的配对预测和重复选择过程。

<a id="chapter-foundations-01-heading-60"></a>

### 12.5 实验设计练习：识别评估对象的变化

**题目。** 训练包含每个用户过去十二周的记录，测试是这些用户第十三周。研究者据此声称模型能够推广到新用户。请修正结论并提出补充实验。

**解析。** 当前测试主要评价已见用户在后续一周的表现，可以合法回答这一任务。新用户可能缺少历史特征，用户标识也没有学过，因此原结论超出了证据。补充实验应在训练阶段排除一批完整用户，用其后续合法记录评价陌生用户泛化，同时确保时间和标签成熟条件一致。可分别报告已见和未见实体，不能把两个结果混成一个无法解释的平均值。

<a id="chapter-foundations-01-heading-61"></a>

### 12.6 研究练习：预测准确为何未必带来行动收益

**题目。** 系统准确识别了最可能流失的用户，但向这些用户发放优惠后，总回访率没有显著提高。这是否证明预测模型无效？如何区分解释？

**解析。** 不能直接证明。预测模型可能准确描述了不干预或旧策略下的风险，但这些高风险用户不容易被优惠改变；也可能存在执行失败、样本量不足或行动改变数据分布。可以先核对风险预测在适当未干预对照中的校准和排序，再对行动进行随机分配，比较相同风险层内干预与对照的结果。若关心最优发放对象，应研究个体或分组增量效果，而不是仅按基线风险排序。预测有效性与行动有效性需要分开的证据链。

<a id="chapter-foundations-01-heading-62"></a>

### 12.7 开放练习：提出能够反驳自己解释的实验

**题目。** 一个图像分类器在随机测试中表现优秀，你认为它学到了目标物体形状。请设计至少三个可能推翻该解释的实验，并说明结果如何解读。

**解析。** 可以保留背景而遮挡物体，检查性能是否仍异常高；更换拍摄来源或设备，检查来源变化是否导致大幅退化；保持物体形状而改变背景，观察预测是否随背景翻转。还可以对相似形状但不同标签的对象构建对照集。若模型依赖背景，能够削弱“主要学到形状”的解释；若这些实验通过，也只能提供更强证据，不能证明所有情况下都只使用形状。实验扰动本身还要保持语义合理，避免把人为失真造成的困难误作捷径证据。
