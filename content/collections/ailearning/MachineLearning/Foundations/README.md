# 机器学习基础

建立从问题定义到泛化评估的完整思路，理解模型究竟从数据中学到了什么。

**先修知识：** Python、概率与基础线性代数。

**正文篇幅状态：** 本主题现有 5 章均已按长篇教材标准展开，逐章纯正文达到 12000–20000 汉字。完整范围见[长篇教材覆盖表](../../README.md#textbook-status)。

## 学习顺序与覆盖范围

第 1—4 章建立任务、数据、泛化和实验流程，是进入监督学习与模型评估的主线。第 5 章再从条件风险解释损失、决策和一致性；可在学过逻辑回归、概率评分与阈值之后回读，不必先完成其全部证明才开始训练基线。第 4 章的综合流程练习检验主线，第 5 章的研究题检验进阶推导，两者承担不同学习目标。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：检查高分任务是否定义正确](04-从问题定义到上线监测的完整流程.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
