# 机器学习基础

建立从问题定义到泛化评估的完整思路，理解模型究竟从数据中学到了什么。

**先修知识：** Python、概率与基础线性代数。

## 学习顺序与覆盖范围

第 1—4 章建立任务、数据、泛化和实验流程，是进入监督学习与模型评估的主线。第 5 章再从条件风险解释损失、决策和一致性；可在学过逻辑回归、概率评分与阈值之后回读，不必先完成其全部证明才开始训练基线。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。
