## 1. 先定义目标风险与解码规则

<a id="detail-1"></a>

### 1.1 决策规则是损失与条件分布共同决定的

设行动集合为 $`\mathcal A`$，采取行动 $`a`$ 而真实结果为 $`y`$ 时付出损失 $`C(a,y)`$。给定输入后的条件风险为 $`r(a;x)=E[C(a,Y)\mid X=x]`$。理想决策逐点选择风险最小的行动；全局风险是这些条件风险对输入分布的平均。在可测性与最优解存在等通常技术条件下，逐点最小化即可得到总体最优规则。

这个过程说明，模型输出并不是最终目的。概率估计可以服务许多不同成本表；直接训练某种决策分数，则往往只服务一个指定目标。如果成本会变化，保留可信概率通常更有复用价值；如果成本固定而样本有限，针对任务的直接方法也可能更高效。两者优劣不能脱离目标、数据和模型限制比较。

对称零一成本下，预测正类的风险为 $`1-\eta`$，预测负类的风险为 $`\eta`$，所以贝叶斯规则在 $`\eta\ge\frac{1}{2}`$ 时选择正类。最优条件风险为 $`\min(\eta,1-\eta)`$，总体最优错误率为它的期望。这一最优值并不总是零；当相同输入仍可能对应不同结果时，合法信息下存在不可避免的分类不确定性。

<a id="detail-2"></a>

### 1.2 三种需要分开的“最优”

第一种是目标损失的最优行动，例如最小错误率分类器；第二种是代理损失的最优预测，例如最小对数损失概率；第三种是某个受限模型族、某个样本和优化预算下实际返回的函数。代理设计主要连接前两种，学习理论还需要把第三种连接过去。只证明代理的总体最优解有正确分类边界，并不能证明实际神经网络训练已经找到它。

例如一个线性打分模型只能形成超平面边界，而真实最优边界是多个不相连区域。即使逻辑损失具有理想的逐点一致性，线性函数族也可能无法逐点选择最优分数。受限族内最小代理风险的函数，与族内最小分类错误的函数一般不能无条件视为同一个。函数族限制与损失性质必须分别分析。

解码规则同样重要。同一组概率，如果按二分之一阈值解码，优化的是对称错误；如果按成本阈值解码，则回答另一个决策问题。一个代理可能对某个解码规则一致，对另一个不一致。因此提到“这个损失是一致的”时，应补全目标风险、预测空间、允许函数和解码方式。

<a id="detail-3"></a>

### 1.3 过剩风险使不同方法可以比较

目标风险与其理论最优值之差称为过剩风险。分类过剩风险度量因为没有采取贝叶斯最优行动而多犯的错误，不包括合法信息下无法消除的随机性。代理过剩风险则是代理损失距离其总体最小值的差。我们希望证明后者很小时，前者也小，这比仅比较两个损失的绝对数值更有意义。

对于二分类器 $`a`$，给定 $`x`$，若行动与贝叶斯行动一致，条件过剩错误为零；若相反，就等于 $`\vert 2\eta(x)-1\vert `$。因此同样一次分类错误，在真实概率接近二分之一时造成的过剩风险较小，在真实概率接近零或一时较大。这不是说所有业务错误成本不同，而是相对于最优规则，接近不确定边界的决策损失差本来就较小。

## 2. 零一损失、间隔损失与条件最优解

<a id="detail-4"></a>

### 2.1 为什么直接优化零一损失困难

零一损失只看最终类别是否正确。对基于符号的线性打分，只要参数变化没有使某个点跨越边界，该点损失就完全不变。因此经验目标呈现大块平坦区域和跳变，普通梯度无法提供有用方向。困难来自目标几何，而不是错误率没有业务意义。

代理损失用连续或凸的惩罚替换硬跳变，让分数朝正确方向变化时能够获得训练信号。间隔写为 $`m=Tf(x)`$，正间隔表示符号正确，负间隔表示符号错误。不同代理对间隔大小的偏好不同：有的持续奖励增大正确间隔，有的超过一后不再奖励，有的甚至惩罚过大的分数。它们因此可能得到相似分类，却拥有完全不同的数值输出。

<a id="detail-5"></a>

### 2.2 逻辑间隔损失的完整推导

逻辑间隔损失为 $`\phi(m)=\log(1+e^{-m})`$。在给定真实概率 $`\eta`$ 时，条件风险为

$$
C_\eta(f)=\eta\log(1+e^{-f})+(1-\eta)\log(1+e^f).
$$

令 $`\sigma(f)=\frac{1}{(1+e^{-f})}`$，求导得到 $`C_\eta'(f)=\sigma(f)-\eta`$，二阶导数为 $`\sigma(f)[1-\sigma(f)]>0`$。当 $`0<\eta<1`$ 时，唯一最优分数为 $`f^*=\log[\frac{\eta}{(1-\eta)}]`$，经过 sigmoid 后恰好恢复真实概率。其符号也与 $`\eta-\frac{1}{2}`$ 相同，因此可以得到最优分类。

当 $`\eta=0`$ 或一，有限实数中没有达到最小值的分数，而是随着 $`f`$ 趋向负无穷或正无穷逼近下确界。这里应讨论最小风险的下确界，而不能声称所有条件下都有有限唯一最小点。数值训练中的权重衰减、有限步数和分数约束会改变边界情形，实际输出不需要也通常不可能达到无穷大。

例如 $`\eta=0.8`$ 时，最优分数为 $`\log4\approx1.3863`$，对应概率零点八。若分数为零，概率为二分之一，代理风险为 $`\log2\approx0.6931`$；最优风险为二元熵 $`-0.8\log0.8-0.2\log0.2\approx0.5004`$。两者差约零点一九二七，解释为概率预测偏离真值产生的额外对数损失。

<a id="detail-6"></a>

### 2.3 合页损失恢复分类边界，却不恢复概率

合页损失为 $`\phi(m)=\max(0,1-m)`$。当 $`f\in[-1,1]`$ 时，条件风险为 $`C_\eta(f)=1+(1-2\eta)f`$；当 $`f>1`$ 时为 $`(1-\eta)(1+f)`$；当 $`f<-1`$ 时为 $`\eta(1-f)`$。因此当 $`\frac{1}{2}<\eta<1`$ 时唯一最优分数是一，当 $`0<\eta<\frac{1}{2}`$ 时是负一；在概率恰为二分之一时，区间负一到一都最优。

概率为零或一时，最优集合扩展为相应方向上间隔至少一的半直线。无论真实概率为零点六还是零点九，只要都在中间情形，合页条件最优分数同为一。可见这个分数没有保留概率大小信息。把合页输出直接送入 sigmoid 并不会神奇地得到真实概率，它只是对分数做了固定数值变换。

合页的条件最小风险为 $`2\min(\eta,1-\eta)`$。最优分数的符号正确，因此适合分类；但若后续成本阈值需要真实概率，就要额外估计概率或直接针对成本设计学习目标。分类一致性不等价于概率估计的一致性，这一区别会影响模型复用。

<a id="detail-7"></a>

### 2.4 平方间隔损失与指数损失

平方间隔损失为 $`(1-Tf)^2`$，条件风险展开为 $`1-2(2\eta-1)f+f^2`$，最优分数为 $`2\eta-1`$。其符号给出最优分类，经过线性映射 $`\frac{(f+1)}{2}`$ 可以恢复理想概率。但实际受限拟合的分数可能超出负一到一，映射后需处理越界；简单裁剪不改变其定义上的回归性质，也不能替代对概率质量的验证。

指数损失为 $`e^{-Tf}`$，条件风险为 $`\eta e^{-f}+(1-\eta)e^f`$。令导数为零得到 $`e^{2f}=\frac{\eta}{(1-\eta)}`$，所以最优分数是半个对数赔率，而不是逻辑损失的完整对数赔率。若错误地直接使用 sigmoid 而不是 $`\sigma(2f)`$，即使达到总体条件最优，也会得到错误概率。相同符号并不意味着相同概率链接。

这一比较揭示一个常见误解：所有“分类分数”不是同一种量。它可以表示对数赔率、半对数赔率、中心化概率，或只表示某种间隔。要解释数值，必须知道损失、链接以及模型限制；不能看到连续输出就默认它等于概率。

<a id="deep-dive-2"></a>
### 深入讲解：分类一致与概率一致的分界

在不受限的逐点预测层面，若每个条件代理最优解经规定解码后都是目标最优行动，可以称其满足相应的 Fisher 一致性。若进一步要求任何接近代理最优风险的预测也必须接近目标最优风险，需要研究校准性质与过剩风险转换。不同文献可能用相近术语表达略有差异的条件，阅读时应以实际数学定义为准。

合页可以正确恢复零一决策，却不能区分同一侧的概率大小；严格适当概率损失则要求真概率本身是唯一最优报告。它们并非互相矛盾，而是服务不同输出需求。对固定对称分类任务，恢复符号就足够；对成本不断变化的决策系统，概率信息往往更有价值。

还有一层实际限制：条件最优解允许对每个输入单独选择输出，而有限模型参数将不同输入的预测耦合起来。若模型错设，逐点性质不能直接转化为族内最优性质。研究者应明确是在讨论理想不受限函数、某个受限函数族，还是有限样本训练算法，避免将三个层面的结论混用。

## 3. 严格适当评分规则与概率估计

<a id="detail-8"></a>

### 3.1 对数损失的差恰好是 KL 散度

对二分类概率预测，对数损失为 $`-Y\log q-(1-Y)\log(1-q)`$。在真实概率 $`\eta`$ 下，条件风险最小值是二元熵。把任意概率风险减去最优风险，可得

$$
C_\eta(q)-C_\eta(\eta)
=\eta\log\frac{\eta}{q}+(1-\eta)\log\frac{1-\eta}{1-q}
=\operatorname{KL}(\operatorname{Ber}(\eta)\Vert \operatorname{Ber}(q)).
$$

KL 非负，且在适当边界约定下仅当概率分布相同时为零，所以真实概率是唯一最优报告。这称为严格适当性。它意味着一个理想的报告者若知道真实分布，并希望最小化期望损失，就没有动机故意改变报告概率。这个性质属于损失，不保证实际模型已经知道真实分布。

多分类情形类似。真实类别分布为向量 $`\eta`$，预测为概率单纯形上的 $`q`$，交叉熵风险等于真实熵加 $`\operatorname{KL}(\eta\Vert q)`$。softmax 只是把有限分数转换为正概率向量的一种链接；对边界真分布，有些零概率只能在极限逼近。模型族、有限样本与正则化仍会影响实际是否接近条件最优。

<a id="detail-9"></a>

### 3.2 Brier 损失如何衡量概率误差

二分类 Brier 形式可以取 $`(Y-q)^2`$。条件期望展开为 $`\eta(1-\eta)+(q-\eta)^2`$，因此条件过剩风险正是概率平方误差。若采用两类别向量平方误差之和，则数值是这个定义的两倍，比较公式时必须确认规范。两种规范都严格适当，但风险转换常数会相应改变。

例如真实概率零点八，预测零点六时，Brier 条件风险为 $`0.8(0.4)^2+0.2(0.6)^2=0.2`$；最优风险为零点一六，过剩为零点零四，恰好等于两概率差的平方。对数损失过剩则为 $`0.8\log(\frac{4}{3})+0.2\log(\frac{1}{2})\approx0.0915`$。两个数单位不同，不能说前者更小就说明评分更宽松或模型更优秀。

Brier 对极端错误的惩罚有界，而对数损失在给真实事件概率趋零时发散。因此在存在错误标签或过度自信时，两者对异常样本的敏感性不同。这是损失形状的真实区别，但不应只根据是否有界选损失；还要考虑任务概率范围、优化稳定性和最终决策用途。

<a id="detail-10"></a>

### 3.3 概率校准为何弱于恢复条件概率

概率校准的一种总体定义是 $`E[Y\mid q(X)]=q(X)`$。意思是所有收到同一概率报告的样本，其真实正例比例与报告一致。它不要求这些样本之间没有更细的风险差异。永远输出总体基率的模型可以满足这一条件，却没有利用任何输入区分个体。

构造一个例子：一半输入的真实风险为零点二，另一半为零点八，总体基率是零点五。常数预测零点五是校准的，但其 Brier 风险为零点二五；使用真实条件概率时风险为零点一六。差值零点零九就是常数报告丢失分辨力的代价。两者都可以总体校准，只有后者恢复了输入中实际存在的信息。

有限样本中的可靠性图还要分箱，每个箱里样本量、箱宽和数据选择都会影响外观。总体校准也不保证每个业务群体内部校准；不同群体的偏差可能在平均后抵消。校准研究因此需要明确条件层级、评价样本和估计误差，而不能把一张接近对角线的图当作完整概率保证。

<a id="detail-11"></a>

### 3.4 标签平滑保持什么，改变什么

若训练把硬标签变成 $`\widetilde Y=(1-\epsilon)Y+\frac{\epsilon}{2}`$，再用二元交叉熵，其条件最优概率是 $`q^*=(1-\epsilon)\eta+\frac{\epsilon}{2}`$。当 $`0\le\epsilon<1`$ 时，这个映射保持相对于二分之一的方向，因而在理想逐点层面保留对称分类边界；但报告概率向二分之一收缩，不再等于原始真实概率。

例如 $`\epsilon=0.2,\eta=0.9`$，最优报告为零点八二。标签平滑可能在有限样本训练中具有正则效果，但不能同时声称其总体最优输出仍是不变的真实概率。若知道确切变换且假设成立，可以考虑反演；实际模型误差、边界限制和后续变化会让这种处理需要独立验证。

当成本阈值不是二分之一时，直接使用同一个数值阈值通常会改变行动。对原始概率阈值 $`\tau`$，平滑概率对应的阈值应为 $`(1-\epsilon)\tau+\frac{\epsilon}{2}`$。训练目标中的小修改可能沿着概率到行动的链条改变系统行为，这正是必须把链接与决策规则一并记录的原因。

<a id="sec-4"></a>
## 4. 从代理过剩风险到分类过剩风险

<a id="detail-12"></a>

### 4.1 对数损失的一个完整风险转换证明

设预测概率为 $`q`$，采用二分之一阈值。当分类方向与贝叶斯规则不一致时，$`q`$ 和 $`\eta`$ 位于阈值的两侧，因此 $`\vert \eta-q\vert \ge\vert \eta-\frac{1}{2}\vert `$。由条件分类过剩风险公式，无论是否分类错误，都有

$$
\Delta_{01}(x)\le2\vert \eta(x)-q(x)\vert .
$$

接下来用概率对数损失控制右侧。固定 $`q\in(0,1)`$，把二元 KL 看作关于 $`\eta`$ 的函数 $`g(\eta)`$。它在 $`\eta=q`$ 处的函数值和一阶导数都是零，二阶导数为 $`\frac{1}{[\eta(1-\eta)]}\ge4`$。积分两次或使用强凸性可得 $`g(\eta)\ge2(\eta-q)^2`$，边界概率通过极限处理。于是逐点有 $`\Delta_{01}(x)\le\sqrt{2\Delta_{\log}(x)}`$。

最后对输入取期望。平方根是凹函数，Jensen 不等式给出

$$
R_{01}(a_q)-R_{01}^*
\le\sqrt{2\bigl(R_{\log}(q)-R_{\log}^*\bigr)}.
$$

这一结论使用自然对数；若损失使用其他底，对应常数需要改变。它说明只要总体对数过剩风险趋于零，分类过剩风险也趋于零。它不说明任意一步训练对数损失下降都会使零一错误下降，更不说明有限模型的经验损失可以直接代入总体风险位置。

<a id="detail-13"></a>

### 4.2 训练损失改善而分类不变或变差并不矛盾

若所有样本的概率都在阈值正确的一侧，继续提高概率质量可以降低对数损失，但分类完全不变。反过来，一批容易样本的概率得到大幅修正，同时少量边界样本跨到错误一侧，平均对数损失可能下降，零一错误却上升。风险上界约束距离最优的量，并不提供每次变化的单调对应。

可以用两个等权输入说明。真实概率分别为零点九九和零点五一。方案甲输出零点六与零点五一，分类均正确；方案乙输出零点九九与零点四九，第二个分类错误。方案乙在第一点大幅改善概率估计，第二点只发生很小概率偏差，因此总体对数损失更低，但分类过剩风险由零增加到零点零一。这样的结果不否认代理一致性，因为它没有让代理过剩风险趋零时保持固定正的分类过剩风险。

这也提示实际实验的报告方式。优化代理用于训练，可以同时报告最终任务指标；若两者发生短期分歧，需要研究边界样本、阈值与样本量。不能仅因为某次对数损失更低就断言所有分类工作点都更好，也不能因为某次准确率波动就否定代理的总体理论性质。

<a id="detail-14"></a>

### 4.3 Brier 与合页的转换

对于本章定义的二分类 Brier，条件代理过剩风险为 $`(q-\eta)^2`$，同样由阈值关系得到总体分类过剩风险不超过 $`2\sqrt{R_B(q)-R_B^*}`$。这个证明不需要把概率误差先转换为 KL，常数不同源于损失尺度。不同代理的数值风险不能直接横向比较，应转换到共同目标或报告原始任务表现。

合页给出另一种形式。当 $`\eta>\frac{1}{2}`$ 而分数 $`f\le0`$ 时，错误方向约束下的最小合页风险在零分数处为一，无约束最小风险为 $`2(1-\eta)`$，差为 $`2\eta-1`$。另一个方向对称。因此分类条件过剩风险不超过合页条件过剩风险，取平均得到总体同样的线性上界。平局时若解码碰巧正确，分类过剩为零，界仍成立。

逻辑损失可以恢复概率，合页具有更直接的分类风险上界，这并不自动证明谁在有限样本更优。泛化误差、函数族、噪声与优化都影响最终结果。理论风险转换只是证据链中的一环，不能只挑有利常数为某种算法宣称普遍胜出。

<a id="detail-15"></a>

### 4.4 分类校准函数的思想

更一般地，可以问：如果分类过剩至少为某个正数，代理过剩是否必须至少为一个正数？把最小可能代理代价写成分类代价的函数，再进行适当凸化，就能得到风险转换工具。它量化代理惩罚错误决策的力度，而不是只检查最优点符号。

对于凸间隔代理，零点附近的行为尤其重要，因为分类解码由零点符号决定。一个代理如果在错误方向也有同样好的条件最优解，就无法区分正确行动。更完整的一般定理见本章参考资料；阅读时应核对凸性、可微性、下确界和平局处理，而不是只记一句“凸损失都能用于分类”。常数损失显然是凸的，却完全没有学习信号。

<a id="sec-5"></a>
## 5. 成本加权训练改变了什么

<a id="detail-16"></a>

### 5.1 加权交叉熵的总体最优概率

考虑正例损失权重 $`u>0`$、负例损失权重 $`v>0`$，目标为 $`-uY\log q-v(1-Y)\log(1-q)`$。给定真实概率 $`\eta`$，条件风险求导为 $`-\frac{u\eta}{q}+\frac{v(1-\eta)}{(1-q)}`$。令导数为零，得到

$$
q_w^*=\frac{u\eta}{u\eta+v(1-\eta)}.
$$

它是一个重加权后的概率，不是原分布后验。对其按二分之一解码，等价于判断 $`u\eta\ge v(1-\eta)`$，即原概率阈值为 $`\frac{v}{(u+v)}`$。若正类漏报成本为 $`u`$、负类误报成本为 $`v`$，这恰好恢复成本最优边界。在理想逐点层面，加权训练与使用真实概率再调整阈值能够服务同一个成本任务。

然而它们在有限样本和受限模型中未必等价。权重改变了梯度贡献和参数折中，可能改变表示与拟合误差；事后调整阈值只改变行动，不重新拟合概率。实验时应比较完整流程，不能把总体最优代数关系当作所有实现都完全一致的证明。

<a id="detail-17"></a>

### 5.2 为什么“加权后输出仍是真概率”是错误的

取漏报权重四、误报权重一，真实概率零点二。最优加权输出为 $`\frac{0.8}{(0.8+0.8)}=0.5`$。如果将这个零点五解释为原始正例概率，会明显高估风险。它只是新目标下的最优报告。要恢复原概率，可以在假设成立时使用

$$
\eta=\frac{v q_w}{u(1-q_w)+v q_w}.
$$

代入即可恢复零点二。这里反演的是已知的总体变换，实际模型错设或正则化会留下误差，所以仍需独立概率评价。尤其是同时使用过采样、类权重和后处理时，必须记录完整变换链。只根据某个参数名推断概率含义，容易遗漏其他步骤。

另一个常见错误是先用对应成本训练加权模型，再把加权概率按原成本阈值判断，相当于重复调整。上例在加权空间应使用二分之一；若又使用原阈值零点二，便会进一步偏向正类。不是说任何额外阈值都不能选，而是其决策含义需要重新推导，不能声称仍等同于最初成本表。

<a id="detail-18"></a>

### 5.3 过采样与类别权重的关系

若训练采样只依据标签改变样本比例，且在每一类内部保持输入分布不变，那么采样相当于改变类别先验。对无约束概率估计，其后验赔率会按采样概率比放缩，与类别加权具有相似形式。但是在有放回重复采样、有限优化和正则化下，实际路径可能不同；合成样本更不一定只是改变先验，因为它可能改变类内输入分布。

设某次训练把正例采样概率提高到负例的四倍，则训练分布后验赔率是原赔率的四倍。此时又对正例设置四倍损失权重，理想上会累计形成十六倍赔率放缩。若没有记录这一链条，输出过度偏向正类可能被误认为模型“召回能力增强”，而概率意义已完全变化。

处理类别不平衡之前，先问到底要解决什么：是改善稀有类表示学习、适应成本不对称、修正采样比例，还是改变决策容量？这些目标可以需要不同措施。类别数量不平衡本身并不意味着概率损失定义错误；盲目平衡数据可能让部署概率更难解释。

<a id="detail-19"></a>

### 5.4 个体成本与条件行动价值

若不同对象的误报成本不同，最优阈值应随输入变化。例如人工核查复杂案件耗时更长，或者错过某些高价值事件的成本更高。给定可见成本 $`u(x),v(x)`$，条件最优行动阈值为 $`\frac{v(x)}{[u(x)+v(x)]}`$。固定阈值只在成本结构一致或经过适当归一化时成立。

但如果成本依赖行动对结果的因果影响，不能仅把观测风险乘一个收益常数。例如营销优惠的价值取决于优惠是否改变购买，不等于用户不购买概率。应区分结果预测、行动成本和反事实增量收益。成本敏感分类的数学框架解决给定损失表下的决策，不自动识别未知行动效果。

<a id="sec-6"></a>
## 6. 统计一致性需要怎样的完整证明

<a id="detail-20"></a>

### 6.1 三个层次的概念

Fisher 一致性研究总体条件最优解经解码是否给出目标最优行动；分类校准或风险转换研究接近代理最优是否迫使目标风险接近最优；统计一致性研究具体学习算法随着样本增大，其目标风险是否趋于最优。三者相互联系，但不是同一个陈述。它们分别位于损失设计、风险比较和随机学习程序层面。

统计一致性还要说明收敛方式。依概率收敛意味着任意固定误差容忍度下，超出它的概率趋零；几乎处处收敛要求对几乎所有无限样本序列最终收敛，通常更强；期望风险收敛则直接控制随机训练集上的平均表现。不同结论需要不同条件，不能把一种形式的证明随意改写成另一种。

<a id="detail-21"></a>

### 6.2 用逐渐增长的有限函数族构造证明

下面展示一个可以逐项核对的充分条件框架。对样本量 $`n`$，事先指定有限预测族 $`\mathcal F_n`$，其大小为 $`M_n`$。假设损失统一位于零到某个固定 $`B`$ 之间，样本独立同分布；算法返回函数的经验风险距离族内最小值不超过 $`\zeta_n`$。对固定置信参数 $`\delta`$，一致偏差界为 $`B\sqrt{\frac{\log(\frac{2M_n}{\delta})}{(2n)}}`$。

为避免把固定失败概率误当作收敛，可取随样本变化的 $`\delta_n=n^{-2}`$。若 $`\frac{\log M_n}{n}\to0`$，则相应偏差界趋零，同时失败概率也趋零。若代理近似误差 $`a_n=\inf_{f\in\mathcal F_n}R_\phi(f)-R_\phi^*`$ 趋零，且 $`\zeta_n\to0`$，则在高概率事件上

$$
R_\phi(f_n)-R_\phi^*
\le a_n+2B\sqrt{\frac{\log(2M_n n^2)}{2n}}+\zeta_n\to0.
$$

于是代理风险依概率趋于最优；若代理具有合适的风险转换，目标风险也依概率趋于最优。由于 $`\sum_n n^{-2}`$ 有限，若所有样本量定义在同一个无限独立样本序列上，还可结合 Borel–Cantelli 引理说明偏差失败事件只出现有限次，从而在其余确定误差项也趋零的条件下得到几乎处处结论。

这不是一个可直接覆盖所有深度学习算法的定理。它是清楚展示证明骨架的构造：先控制样本误差，再让模型近似误差和优化误差消失，最后通过代理校准转向目标任务。每一项都需要单独证据，不能只验证某一项。

<a id="detail-22"></a>

### 6.3 对数损失无界时为什么要重新分析

对数损失在给真实事件的概率趋零时无界，所以不能未经处理套用固定有界损失的 Hoeffding 版本。可以约束预测概率位于 $`[\epsilon,1-\epsilon]`$，此时单样本损失至多为 $`B=\log(\frac{1}{\epsilon})`$；但固定截断也改变了可达到的最小代理风险，若真实概率靠近边界，留下了截断近似误差。

一种理论路径是让 $`\epsilon_n`$ 随样本量逐渐趋零，从而扩大概率范围，同时控制增长的损失上界 $`B_n=\log(\frac{1}{\epsilon_n})`$。需要满足 $`B_n\sqrt{\frac{\log(2M_n n^2)}{n}}\to0`$，并控制近似和优化误差。若取 $`\epsilon_n=n^{-\frac{1}{4}}`$，则 $`B_n`$ 只以对数速度增长；配合例如 $`\log M_n`$ 不超过常数倍 $`\sqrt n`$，集中项仍趋零。

裁剪造成的近似代价也可以明确控制。若直接把真实概率裁到 $`[\epsilon,1-\epsilon]`$，内部概率不变，只有两端发生误差。对 $`\eta\in[0,\epsilon]`$，函数 $`\operatorname{KL}(\operatorname{Ber}(\eta)\Vert \operatorname{Ber}(\epsilon))`$ 关于 $`\eta`$ 凸，其区间最大值在端点，因而至多为 $`-\log(1-\epsilon)`$；上端对称。这个上界随 $`\epsilon\to0`$ 消失。因此理想概率裁剪本身不阻止渐近逼近，但实际有限族是否能逼近该裁剪函数，仍是独立的近似条件，不能由裁剪代数推出。

上述 $`\epsilon_n=n^{-\frac{1}{4}}`$ 只在足够大的 $`n`$ 下使用，使下界小于二分之一；有限初始项可以另行固定为合法常数，不影响渐近结论。若 $`\log M_n=O(\sqrt n)`$，集中项量级至多为对数因子乘 $`n^{-\frac{1}{4}}`$，确实趋零；但这仍没有自动保证该函数族的近似误差或算法优化误差趋零。

这种构造说明为什么“逐渐允许更极端概率”和“仍能控制采样波动”要平衡。它不是建议实际工程必须采用这个幂次。其他理论可以使用尾部条件、局部复杂度或更细的统计工具处理无界损失，但都要明确替换了什么假设。

<a id="detail-23"></a>

### 6.4 统计一致性不提供有限样本万能保证

一个方法可能最终一致，但在现实样本规模下收敛很慢；另一个受限方法具有不可消除的近似偏差，却在中小样本上表现更稳。渐近性质是研究长期行为的重要依据，不是免除实验的理由。比较应同时关注有限样本误差、计算代价和具体数据结构。

一致性也依赖训练与部署的目标关系。若样本数增加的同时标签口径持续变化，或者部署分布不同于证明中的固定分布，原定理不直接回答新问题。统计保证是带有环境条件的数学陈述，不是给模型贴上的永久标签。对实际系统，应说明哪些条件可通过设计保障，哪些只能监控，哪些仍是未经验证的假设。

<a id="sec-7"></a>
## 7. 分布变化下重建决策链

<a id="detail-24"></a>

### 7.1 类别先验变化的后验赔率修正

设训练分布为 $`P`$，部署分布为 $`Q`$，假设给定类别后的输入分布保持不变，而正类先验从 $`\pi_P`$ 变为 $`\pi_Q`$。由贝叶斯公式，后验赔率满足

$$
\frac{q_Q(x)}{1-q_Q(x)}=
\frac{q_P(x)}{1-q_P(x)}
\frac{\frac{\pi_Q}{(1-\pi_Q)}}{\frac{\pi_P}{(1-\pi_P)}}.
$$

输入的类条件似然比在两边相同，因此变化只通过先验赔率进入。若训练正例先验为二分之一、部署为十分之一，赔率乘数就是九分之一。训练概率零点八对应赔率四，修正后赔率四除以九，部署概率为四除以十三，约零点三零七七。直接沿用零点八会明显高估部署风险。

这个修正依赖真实的类别先验变化假设，而不仅是观察到总体正例比例改变。若同一类内部的输入分布也变化，或者标签定义改变，公式未必成立。部署先验的估计本身也有误差；用少量新标签估计或用无标签混合结构估计，需要额外条件和不确定性分析。

<a id="detail-25"></a>

### 7.2 输入分布变化与条件机制变化

若只改变输入分布而保持 $`Y\mid X`$ 不变，真实条件概率和逐点最优行动可以保持，但总体风险会因输入权重变化而改变。模型在训练中少见的区域如果在部署中变多，平均表现可能下降，即使每个区域内部的概率机制没变。有限模型的拟合权衡也可能因此需要重加权。

若条件机制改变，原概率即使在训练中完美也可能失效。例如相同浏览行为在促销前后对应不同购买概率，或审核政策变化导致相同申请特征对应不同标签。此时只修正先验或输入密度都不一定充分。需要区分数据中可以检验的分布差异与依赖新标签才能发现的机制变化。

支持条件特别关键。如果部署输入落在训练从未覆盖的区域，就没有可靠的局部误差证据。概率模型仍会给出一个数字，但这个数字主要由函数延伸与归纳偏置决定。对未知区域，限制自动行动、补充数据或人工审核可能比继续调整一个全局阈值更合理。

<a id="detail-26"></a>

### 7.3 哪些变换需要按正确次序组合

假设模型先在重采样数据上训练，又使用类别权重，还经过标签平滑，最后部署先验变化。每一步都可能改变最优报告的含义。应先明确网络报告对应哪个目标，再在条件成立时逆向恢复相应训练概率，随后转换到部署概率，最后应用部署成本阈值。若没有完整记录，单独看一个输出值无法可靠推断其含义。

并非所有实际变换都能精确反演。受限模型、校准后处理、截断和有限样本误差可能使代数关系只近似成立。因此实际系统需要保留独立、代表部署的信息来检验整条链。原理推导用于明确检查方向，不能代替终端决策风险的测量。

<a id="sec-8"></a>
## 8. 拒绝预测、审核预算与多行动决策

<a id="detail-27"></a>

### 8.1 允许拒绝时，最优行动多了一段区域

在对称分类错误成本为一、正确成本为零的基础上，增加一个固定成本为 $`c`$ 的拒绝行动，且 $`0<c<\frac{1}{2}`$。给定概率 $`\eta`$，预测负类成本为 $`\eta`$，预测正类成本为 $`1-\eta`$，拒绝成本为 $`c`$。于是当 $`\eta<c`$ 时预测负类，当 $`\eta>1-c`$ 时预测正类，中间区域拒绝，边界平局可按预定规则处理。

例如拒绝成本零点一五，概率零点一时直接预测负类成本更低，概率零点四时拒绝更低，概率零点九时直接预测正类更低。这条规则是给定理想概率与固定成本下的最优行动，不是对每个预测正确的保证。自动处理区域里仍有少量随机错误，拒绝只是改变成本和覆盖率的折中。

如果人工审核也会犯错，拒绝成本应包含审核费用与预期剩余错误成本；如果人工只在某些输入上更可靠，应使用输入相关审核风险。把“交给人工”默认成零错误，会高估拒绝选项价值。决策论框架的优点正是允许把这些不同后果写进同一个行动成本表。

<a id="detail-28"></a>

### 8.2 固定审核预算为何通常需要排序收益

设每个对象都可以采取默认行动或审核行动，二者的条件期望成本差为 $`b_i`$，正值表示审核带来净收益。若每次审核消耗同样资源且最多审核 $`K`$ 人，最优策略是挑选正收益中最大的至多 $`K`$ 个，而不是机械挑概率最接近二分之一的人。只有在特定对称错误成本、审核效果和费用结构下，不确定性排序才与收益排序一致。

如果审核成本因人而异，固定人数约束变成总资源约束，选择问题可能类似背包或连续预算分配。按概率、按收益或按收益除以成本排序，可能得到不同方案；其中哪一个最优取决于行动是否可分割以及约束结构。不能把某个直觉比值规则当作所有离散预算问题的精确解。

预算还会让决策依赖同批其他对象。某人的概率没有变化，但当天高风险对象很多，便可能排不到审核名额。此时部署规则不再只是一个独立的固定阈值函数，评价应在真实批次与预算条件下进行。单样本分类错误率未必充分描述这种系统的价值。

<a id="detail-29"></a>

### 8.3 风险覆盖曲线与保证的对象

选择性预测把自动回答比例称为覆盖率，把已回答对象中的平均错误称为选择性风险。提高拒绝比例通常可以降低已回答错误，但前提是置信排序确实有效。曲线描述这种折中，不自动保证新样本上的风险达到某个阈值。用同一份数据挑选最好的拒绝阈值再报告其误差，会受到选择偏差影响。

可以在独立校准数据上为固定候选阈值构造风险上界，或者使用专门的风险控制方法。需要明确候选集如何固定、样本是否独立、接受样本数量以及置信参数如何分配。这里的覆盖率是系统回答比例，与保形预测集合的标签覆盖概率含义不同；两个术语相似，却控制不同对象。

<a id="sec-9"></a>
## 9. 完整数值案例：训练概率如何走到部署行动

<a id="detail-30"></a>

### 9.1 场景与概率链条

考虑一个二分类风险系统。训练数据经过类别重采样，使正例比例为二分之一；部署总体正例比例为十分之一。暂且假设类条件输入分布稳定，并且模型准确恢复训练后验概率。部署中假负例成本为九、假正例成本为一，因此成本最优的部署概率阈值为十分之一。

对于三个输入，模型训练概率分别为 $`0.2,0.5,0.8`$。由先验赔率修正，部署概率分别为

$$
q_Q=\frac{q_P}{9(1-q_P)+q_P},
$$

得到 $`\frac{1}{37}\approx0.02703`$、$`0.1`$ 和 $`\frac{4}{13}\approx0.30769`$。因此第一位预测负类，第三位预测正类，第二位成本恰好平局。若在训练概率上直接用部署阈值零点一，三位都会被选为正类，第一位的行动就不符合规定成本。

也可以直接推导训练概率空间的等效阈值。部署阈值赔率为一除以九，乘回先验修正的逆因子九，训练赔率阈值为一，因此训练概率阈值为二分之一。两条路径给出相同结果：先修正概率再用成本阈值，或者在原输出空间使用正确变换后的阈值。关键是不能把不同概率空间的数值混用。

<a id="detail-31"></a>

### 9.2 用实际条件成本检查行动

对第一位用户，正类行动成本为 $`1-\frac{1}{37}=\frac{36}{37}\approx0.9730`$，负类行动成本为 $`\frac{9}{37}\approx0.2432`$，所以应选负类。第三位用户的两种成本分别为 $`\frac{9}{13}\approx0.6923`$ 与 $`\frac{36}{13}\approx2.7692`$，应选正类。第二位两种成本均为零点九。直接计算行动风险，是检查阈值推导是否写反的有效办法。

若系统增加一次成本零点五、能完美确认标签的审核行动，则第一位仍选负类，因为零点二四三二低于审核成本；第二位选择审核；第三位也选择审核，因为零点五低于直接正类的零点六九二三。可见“高风险就直接处置，中间风险才审核”并不总成立，是否审核取决于所有行动成本。若正类行动具有更低费用或审核不完美，区域还会变化。

若审核每天只有一个名额，就比较相对默认最优行动的收益。第二位收益为零点四，第三位为约零点一九二三，因此优先审核第二位。这一步使用的是期望成本改善，不只是概率离二分之一的距离。

<a id="detail-32"></a>

### 9.3 再加入加权训练会发生什么

假设网络实际使用正例四倍、负例一倍的加权交叉熵，但开发人员仍把网络输出当作训练后验。对于原训练后验零点二、零点五和零点八，理想加权输出分别为二分之一、五分之四和十六分之十七。正确链条应先用第五节反演恢复原训练概率，再进行先验修正，最后使用部署成本。

如果不反演，直接把加权输出带入先验修正公式，得到的部署概率会系统偏高。例如原训练后验零点二被加权报告为零点五，再经先验修正会得到零点一，而真实部署概率约为零点零二七。这个例子不需要任何模型拟合错误，仅靠概率语义错位就能造成明显行动差异。

因此模型交付中应保存的不仅是权重，还包括训练采样比例、损失权重、概率链接、后处理版本、目标总体和决策成本。它们一起规定一个分数在系统中的含义。独立测试应评价最终完整链条，而不是只测试网络中间输出后便宣称系统可靠。

<a id="detail-33"></a>

### 9.4 实际验证如何尊重理论限制

上述案例故意使用理想概率来隔离机制。在真实数据中，应先使用未参与拟合和选择的代表性样本，验证最终概率与行动成本；再检查先验变化假设在主要类别、来源和时间段是否近似成立。先验估计的误差可以通过敏感性分析展示：把可能的先验范围代入，观察哪些行动稳定、哪些对假设敏感。

不要把同一部署月的全部标签既用于估计先验、挑选阈值，又用来报告完全独立的最终成本。若任务允许每月用一个已成熟校准窗口适应下个月，可以按这个顺序回放整个流程，再用后续月份评价。评价单位应是完整更新规则，而不是事后挑出的最优阈值。

<a id="detail-34"></a>

### 9.5 将概率误差直接转换为不对称成本误差

设假正例与假负例成本分别为 $`v,u`$，阈值 $`\tau=\frac{v}{(u+v)}`$。给定输入，选择错误一侧相对于最优行动多付的成本为 $`(u+v)\vert \eta-\tau\vert `$。若按估计概率 $`q`$ 的相同阈值行动，只有 $`q`$ 与 $`\eta`$ 位于阈值两侧时出现过剩成本，此时 $`\vert \eta-q\vert \ge\vert \eta-\tau\vert `$。因此无论行动是否出错，都有条件成本过剩不超过 $`(u+v)\vert \eta-q\vert `$。

利用第四节已经证明的二元 KL 下界，再取期望，可得总体成本过剩不超过 $`(u+v)\sqrt{\frac{[R_{\log}(q)-R_{\log}^*]}{2}}`$。对称成本各为一时，恢复先前的平方根二倍对数过剩风险界。这个式子明确展示成本尺度：同样的概率误差，在高代价任务中可能意味着更大的实际损失。

例如成本和为十，总体对数过剩风险上界为零点零零二，成本过剩界为 $`10\sqrt{0.001}\approx0.3162`$。这是理论上界，不是模型实际必然损失这个数，也不含训练到总体转换所需的估计误差。若输入相关成本无界，还不能直接取一个固定成本和，需要有界性或可积性等额外控制。

<a id="detail-35"></a>

### 9.6 为什么一个分类一致分数不能服务所有阈值

合页条件最优分数在真实概率零点六和零点九时都为一。对于对称分类，两者行动都为正类，丢失概率差异没有妨碍该任务最优性。但如果新成本阈值是零点八，第一种应选负、第二种应选正。任何只看到同一个分数一、且没有其他信息的后处理，都无法同时区分这两种情况。

这构成一个具体的信息反例：对原任务足够的报告，不一定对另一个任务足够。后处理校准可以利用额外数据学习分数组平均概率，但若同一分数组内混合不同真实风险，单变量后处理仍不能恢复已丢掉的区分。需要更丰富的分数、原始信息或重新估计概率，而不只是换一个阈值数字。

若预计系统会服务多种成本、多个行动或未来政策，概率估计的严格适当目标因此具有复用价值。它不是对所有有限样本问题的最优保证：受限模型中直接针对当前行动学习也可能更好。研究应比较具体数据预算下的风险，而不是把“保留更多概率信息”直接等同于“实际永远更准确”。

<a id="detail-36"></a>

### 9.7 从总体校准到分组决策的细节

设两组等规模，真实概率分别零点二与零点八，模型全报零点五。它满足总体校准。若成本阈值零点六，系统对所有人选负类；然而理想行动只对第二组选正类。因为分数没有区分两组，阈值优化最多在“全选”和“全不选”之间切换，不能达到使用组信息的最优风险。

若成本为假正例三、假负例二，阈值正是零点六。全负策略的平均成本为 $`2\times0.5=1`$；使用真实概率后，第一组选负成本零点四，第二组选正成本零点六，平均零点五。总体校准并未阻止额外成本零点五。这个算例说明校准与分辨力都参与行动价值，评价某个概率性质时要避免把它当作全部充分条件。

<a id="sec-10"></a>
## 10. 分层练习与研究解析

<a id="detail-37"></a>

### 10.1 条件最优解：不要混用链接

**题目。** 对某个输入，真实正例概率为四分之三。分别求逻辑间隔、指数间隔、平方间隔和合页损失的条件最优分数。若将四者都用 sigmoid 转成概率，会发生什么？

**解析。** 逻辑分数为 $`\log3\approx1.0986`$，指数分数为 $`\tfrac12\log3\approx0.5493`$，平方间隔分数为二分之一，合页分数为一。四者符号都为正，均给出同一个最优分类。直接 sigmoid 后分别约为零点七五、零点六三四、零点六二二五、零点七三一一，只有逻辑链接在这里直接正确。指数需要 sigmoid 的两倍分数，平方间隔需要线性链接；合页在这个区间的最优分数没有编码完整概率。

<a id="detail-38"></a>

### 10.2 风险转换：计算一个保证并解释局限

**题目。** 若已证明某概率预测器的总体自然对数损失过剩风险不超过零点零零五，二分之一阈值的分类过剩风险可以保证多少？能否把某次训练集交叉熵零点零零五直接代入？

**解析。** 第四节上界给出 $`\sqrt{2\times0.005}=0.1`$。这是超过贝叶斯最优错误率的部分，不是分类总错误率，也不是实际误差必然达到零点一。不能把训练损失直接代入，因为训练损失不是总体风险，而且这里要求减去代理最优总体风险。还需要泛化、近似与优化分析，才能把经验信息转成所需的总体过剩风险界。

<a id="detail-39"></a>

### 10.3 构造反例：总体校准为何不够

**题目。** 两个等规模群体的真实风险分别为零点一和零点九。预测器始终输出零点五。证明它总体校准，并计算它与真实概率预测器的 Brier 风险差。

**解析。** 因为唯一报告值是零点五，而总体正例比例也为零点五，所以 $`E[Y\mid q=0.5]=0.5`$，满足总体校准。常数预测的 Brier 风险为零点二五；真实概率预测的风险为两组条件方差平均，即零点零九。差为零点一六，等于每组概率偏差零点四的平方。若考察群体内部，常数报告分别高估和低估风险，因此总体校准没有保证分组校准或恢复输入信息。

<a id="detail-40"></a>

### 10.4 加权输出：把重复计成本找出来

**题目。** 漏报成本为九、误报成本为一。训练使用正例九倍权重交叉熵，网络理想加权输出为零点六。求原始真实概率，并说明为什么不能再直接使用原概率阈值零点一。

**解析。** 由反演得到 $`\eta=\frac{0.6}{[9(0.4)+0.6]}=\frac{1}{7}\approx0.142857`$。它超过原概率成本阈值零点一，所以应预测正类；加权空间的对应阈值是零点五，零点六也超过它。若加权输出仅为零点二，反演得到 $`\frac{0.2}{(7.2+0.2)}=\frac{1}{37}`$，应预测负类，但直接用零点一会错误选正类。这说明重复应用成本阈值改变了原任务。

<a id="detail-41"></a>

### 10.5 标签平滑：分类正确不代表概率正确

**题目。** 平滑参数为零点二，真实概率为零点七，求交叉熵总体最优报告。若原业务阈值为零点八，平滑输出对应的正确阈值是什么？

**解析。** 最优报告为 $`0.8\times0.7+0.1=0.66`$。它与真实概率都位于二分之一上方，所以对称分类方向不变；但数值并不相等。原阈值零点八对应平滑阈值 $`0.8\times0.8+0.1=0.74`$。直接使用零点八会要求更极端的真实概率，因而改变决策。这个等价仍是总体理想变换，实际模型应独立验证。

<a id="detail-42"></a>

### 10.6 一致性条件：检查一个看似合理的证明

**题目。** 某证明称：“神经网络能逼近任意连续函数；训练损失比去年更低；因此该学习系统统计一致。”至少指出四处缺失。

**解析。** 第一，通用逼近通常是关于某类函数、某种范数和域上的表示能力，不自动说明目标条件概率满足对应条件。第二，固定网络与随样本增长的函数族不同，需要近似误差趋零的构造。第三，经验损失降低没有控制总体与经验之间的偏差。第四，需要优化误差随样本增长消失或足够小。还需明确损失与目标任务的校准关系、采样条件和收敛方式。去年与今年的数据分布若不同，甚至不是同一个固定总体上的渐近序列。

<a id="detail-43"></a>

### 10.7 开放研究：改变预算后还算同一个模型吗

**题目。** 一个系统在每天审核一百人的条件下成本最优，现在容量变为二十人。能否只保持原固定阈值？应如何设计比较？

**解析。** 原阈值可能产生超过容量的候选，也可能不足以优先分配最有价值对象。需要按新预算比较对象的条件净收益，并考虑审核成本是否一致。可以固定概率模型，分别构建旧阈值、重新选阈值和预算收益排序三种规则，在相同未来批次回放并报告总成本、审核数量与分组影响。如果概率模型本身也重新训练，应将“预测变化”和“行动规则变化”拆开做对照。这样才能知道改善来自哪一环。

<a id="detail-44"></a>

### 10.8 研究练习：风险边界附近的概率误差

**题目。** 两个输入的真实概率分别为零点五一和零点九九，预测都低估零点零二。哪一个更可能改变对称分类？这能否证明第二个概率误差没有价值？

**解析。** 第一个报告零点四九，会跨越二分之一边界；第二个报告零点九七，不改变类别。因此分类错误对靠近边界的概率误差更敏感。但第二个误差仍影响概率评分和成本不同的决策，例如极高阈值行动或风险定价。不同目标对概率误差的权重不同，不能从某个固定分类边界推出其他概率信息没有价值。研究中可以结合边际条件推导更细风险转换，但需要对真实概率接近边界的质量作明确假设。

<a id="detail-45"></a>

### 10.9 方法比较练习：给四种性质画清边界

**题目。** 比较“损失严格适当”“总体概率校准”“分类 Fisher 一致”“学习算法统计一致”四个陈述，说明为什么不能随意互相替换。

**解析。** 严格适当是损失在真分布下唯一偏好真实概率报告的性质；总体校准是某个具体预测器与结果之间的条件平均关系；分类 Fisher 一致讨论理想条件最优输出经过解码是否给出目标最优行动；统计一致讨论一个随机学习流程随着样本增大是否逼近最优风险。

常数基率预测可校准但无分辨力，合页可分类一致却不恢复概率，严格适当损失配上过小模型也可能保留近似误差。统计一致性需要把损失、函数族、采样和求解连成完整证明链。

<a id="sec-11"></a>
## 11. 参考资料与后续研究

本章推导可以继续沿三个方向扩展：研究更一般的代理校准函数和多分类损失；研究局部复杂度、低噪声或边际条件带来的更快收敛；研究目标分布不固定、行动会改变数据的决策系统。每条路线都应保留本章的基本区分：条件最优不等于有限样本达到最优，概率校准不等于恢复全部信息，预测准确不等于行动增量有效。

- [Bartlett、Jordan 与 McAuliffe：Convexity, Classification, and Risk Bounds，原始论文](https://doi.org/10.1198/016214505000000907)：分类代理与风险转换的一般理论，适合与本章手工推导对照阅读。
- [Reid 与 Williamson：Composite Binary Losses，原始论文](https://www.jmlr.org/papers/v11/reid10a.html)：概率损失与链接函数的形式化研究。
- [Reid 与 Williamson：Information, Divergence and Risk for Binary Experiments，原始论文](https://www.jmlr.org/papers/v12/reid11a.html)：进一步连接信息量、散度与二元决策。
- [Understanding Machine Learning，作者公开教材](https://www.cs.huji.ac.il/~shais/UnderstandingMachineLearning/)：系统补充经验风险与统计学习理论。

需要更深入的统计保证，可继续阅读[统计学习理论](../../AdvancedStudies/LearningTheory/README.md)；概率后处理、阈值与评价协议参见[模型评估](../ModelEvaluation/README.md)；分布变化与选择性风险的专门讨论见[不确定性与鲁棒性](../../AdvancedStudies/UncertaintyAndRobustness/README.md)。
