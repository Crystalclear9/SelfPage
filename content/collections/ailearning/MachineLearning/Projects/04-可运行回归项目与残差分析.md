## 1. 先把回归任务写成可以验证的协议

<a id="project-4-detail-2"></a>

### 1.1 一行记录与一次未来使用

设每行是一台设备的一次观测，输入包含负载、温度、传感器读数、设备年龄和站点。目标是同一次合法预测所对应的连续响应。设备标识只用于分组与追踪，不直接进入模型；观测后才生成的维修结果、累计未来量或目标回写字段不能参与输入。数据表有某一列，不等于预测当时可用。

本章的部署问题是从未参与训练的新设备。因此外层按设备留出，开发集内部也按设备分组验证。若实际任务是已有设备未来时刻预测，应重新设计时间边界与可用历史，不应把本章分组得分直接称为这种任务的未来性能。划分规则是问题定义的一部分，而非为了让某个模型得分更高可以随时更换的选项。

设备内多行共享未观测随机效应，所以行之间相关。随机拆行可能让同一设备信息同时进入训练和评价，尤其当输入含身份或其代理变量时，会显著改变难度。即使模型没有直接看到设备号，相同设备的测量分布也可能相似。先识别真实独立单位，再决定如何切分与计算不确定性。

<a id="project-4-detail-3"></a>

### 1.2 目标单位、主要损失和辅助指标

设残差约定为 $`r_i=y_i-\hat y_i`$，正残差表示低估，负残差表示高估。MAE 与目标同单位，RMSE 也与目标同单位但更强调大误差。平均残差描述有方向的偏差，会正负抵消。三者回答不同问题，不能把总体平均残差接近零写成误差很小。

本项目预先以 MAE 选择超参数，同时报告 RMSE 与平均残差。训练岭回归仍优化平方误差加惩罚，验证指标可以与训练目标不同；它表示从这族平方损失拟合结果中，选取在开发协议下绝对误差较小的候选。若真正要直接拟合条件中位数，可另设绝对损失或分位数模型，并按共同预算比较。

还要定义平均单位。按所有请求平均，记录多的设备权重更大；先求设备内平均再平均，表达典型设备的表现。两种指标均可报告，但主要目标应提前决定。群体样本量不等时，简单把若干设备误差均值再平均，不能冒充按请求总体的 MAE。

<a id="project-4-detail-4"></a>

### 1.3 开发、选择、诊断与最终测试

外层冻结测试设备之后，在开发设备上选择预处理、模型与超参数。模型选择后，使用全部开发集重新拟合，并以同一个已冻结预测器评价测试。若查看测试残差后决定增加特征、删除样本或更换主要指标，测试已经参与开发，应把后续结论标为探索，另留新的确认数据。

开发诊断可以使用嵌套分组预测：每个外层开发验证折的预测，由仅在其余开发设备上完成内层搜索的流程产生。这样评估的是一个完整选择规则，而不是先用全开发数据挑好参数，再给同一数据生成表面上的折外预测。后者可以用于部分诊断，但不能自动获得同样的选择独立性。

## 2. 基线与指标：先建立可以手算的参照

<a id="sec-1-1"></a>
<a id="project-4-detail-6"></a>

### 2.1 均值与中位数各自优化什么

对常数预测 $`c`$，平方损失总和的导数为 $`2\sum_i(c-y_i)`$，令其为零得到训练均值。绝对损失的左右导数由两侧样本数决定，中位数使两侧平衡。目标为零、零、九时，均值三的 MSE 是十八，中位数零的 MSE 是二十七；MAE 则分别为四与三。

因此不能只找一个明显不匹配主要损失的弱基线，借此夸大模型收益。本章同时保留训练均值和训练中位数基线。它们的参数只来自开发训练标签，不读取测试均值或测试中位数。测试标签均值出现在 R² 的定义里，并不赋予部署预测器读取测试标签的权限。

<a id="project-4-detail-7"></a>

### 2.2 残差三个摘要与 R² 的分母

若残差是一、负一、四，MAE 为二，均方误差为六，RMSE 为六的平方根，平均残差为三分之四。平方先平均再开方，与先开方再平均不同；总体平均残差也无法从 MAE 反推出。验收时应从同一份逐样本预测复算这些量，避免报告表来自不同版本。

R² 常写为 $`1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y_{\mathrm{eval}})^2}`$。分母使用当前评价集目标均值，表示相对该评价集常数均值的平方误差改进。真实值零、二，预测三、三时，分母二、分子十，结果为负四。这不是概率越界，而是比该参照更差。

若目标在评价集中恒定，分母为零，软件可能对完全拟合与非完全拟合作特殊返回约定。应报告任务情形与接口设置，不能把某个特殊值当作所有回归数据上的一般解释。MAE 和 RMSE 仍有直接单位意义，通常也应同时列出。

```python
import numpy as np
from sklearn.dummy import DummyRegressor
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

y_train = np.array([0.0, 0.0, 9.0])
X_train = np.zeros((3, 1))
mean_model = DummyRegressor(strategy="mean").fit(X_train, y_train)
median_model = DummyRegressor(strategy="median").fit(X_train, y_train)
pm = mean_model.predict(X_train); pd = median_model.predict(X_train)
assert np.allclose(pm, 3)
assert np.allclose(pd, 0)
assert np.isclose(mean_squared_error(y_train, pm), 18)
assert np.isclose(mean_squared_error(y_train, pd), 27)
assert np.isclose(mean_absolute_error(y_train, pm), 4)
assert np.isclose(mean_absolute_error(y_train, pd), 3)
r = np.array([1.0, -1.0, 4.0])
assert np.isclose(np.mean(np.abs(r)), 2)
assert np.isclose(np.sqrt(np.mean(r*r)), np.sqrt(6))
assert np.isclose(np.mean(r), 4/3)
assert np.isclose(r2_score([0, 2], [3, 3]), -4)
print("mean/median baselines and residual arithmetic passed")
```

<a id="project-4-detail-8"></a>

### 2.3 负误差评分是排序接口，不是负损失

GridSearchCV 的评分约定为越大越好，因此负 MAE 等于真实 MAE 取负。负十优于负十二，对应误差十小于十二。报告时恢复正误差，同时保留评分名称与选择规则。若将负分绝对值后仍按越大越好排序，会把最差候选选成最好。

交叉验证中平均各折 MAE，与按所有折预测汇总 MAE，在折大小不同时可能不同。若各折按设备分组，折间设备数量和行数还可能不完全一致。应说明模型搜索采用的库评分归约，以及报告是否另按请求或设备重新汇总。两个数值不同不一定是错误，但必须指向清楚的目标。

## 3. 岭回归的机制、尺度与有效复杂度

<a id="project-4-detail-10"></a>

### 3.1 从目标函数得到唯一的收缩解

对已经中心化的数据，岭回归目标为 $`\Vert y-Xw\Vert ^2+\alpha\Vert w\Vert ^2`$，当 $`\alpha>0`$ 时解满足 $`(X^TX+\alpha I)w=X^Ty`$。实际计算使用稳定线性求解或矩阵分解，公式里的逆不要求代码处处显式求逆。截距通常不惩罚，中心化与恢复截距必须保持一致。

这个目标中的数据项是平方误差和。若另一实现用均方误差并写相同数值惩罚系数，二者约束强度不同。与贝叶斯高斯先验联系时，还要对应噪声尺度、先验方差及样本数。参数名相同不保证数学目标相同，接口以[Ridge 官方定义](https://scikit-learn.org/1.8/modules/generated/sklearn.linear_model.Ridge.html)为准。

<a id="project-4-detail-11"></a>

### 3.2 奇异方向的收缩不是统一缩小系数

设 $`X=USV^T`$，则解在第 $`j`$ 个右奇异方向上的系数乘以 $`\frac{s_j}{(s_j^2+\alpha)}`$，拟合值相对无惩罚投影的收缩因子为 $`\frac{s_j^2}{(s_j^2+\alpha)}`$。小奇异方向更受抑制，大方向相对保留。因此增加惩罚不是简单把每个原坐标系数乘同一个常数。

训练拟合映射 $`H_\alpha=X(X^TX+\alpha I)^{-1}X^T`$ 的迹为这些收缩因子之和，常作为固定设计、线性平滑器下的有效自由度。若另有未惩罚截距，通常相应增加一个方向。交叉验证选择惩罚、数据依赖特征筛选等会引入额外选择复杂度，不能把这个迹直接解释为整个自适应流程的全部复杂度。

<a id="project-4-detail-12"></a>

### 3.3 标准化改变的是惩罚几何

若某列标准差为 $`s_j`$，标准化系数与原单位系数之间有比例关系。对标准化权重施统一 L2，换回原单位后等价于对不同原始方向施不同权重惩罚。它是一个合理但具体的建模选择，不是让所有系数天然公平。类别独热列与连续标准化列的尺度约定也会影响惩罚。

缩放统计必须只从当前训练折估计，缺失填补也一样。把原始列放入 ColumnTransformer，再把整个预处理与 Ridge 放进 Pipeline，可以让搜索克隆整个流程并在各折重新拟合。静态单位换算与从数据估计均值不同；前者可作为固定契约，后者必须遵守拟合边界。

```python
import numpy as np
from sklearn.linear_model import Ridge

X = np.array([[0., 1.], [1., 0.], [2., 3.], [4., 2.]])
y = np.array([0., 1., 2., 3.])
Xc = X - X.mean(axis=0); yc = y - y.mean()
U, s, Vt = np.linalg.svd(Xc, full_matrices=False)
alpha = 2.0
coef = Vt.T @ ((s / (s*s + alpha)) * (U.T @ yc))
reference = Ridge(alpha=alpha, fit_intercept=False).fit(Xc, yc)
assert np.allclose(coef, reference.coef_)
H = (U * (s*s / (s*s + alpha))) @ U.T
assert np.allclose(H @ yc, Xc @ coef)
assert np.isclose(np.trace(H), np.sum(s*s / (s*s + alpha)))
gradient = 2*Xc.T@(Xc@coef-yc) + 2*alpha*coef
assert np.allclose(gradient, 0, atol=1e-10)
assert np.all((s*s/(s*s+alpha) > 0) & (s*s/(s*s+alpha) < 1))
print("coef", coef, "effective df including intercept", 1+np.trace(H))
```

### 3.4 好的基线与拟合目标一起解释

岭回归拥有线性表示与平方损失偏好，MAE 验证只是在候选惩罚之间选择，不能使它变成直接求条件中位数的算法。若数据存在明显非对称尾部，应该增加匹配主要决策的模型作为独立候选，并固定比较预算。模型族和验证目标需要分别记录。

同样，若结果只比训练均值更好，却不比中位数或简单分组基线更好，不能据此声称特征带来充分收益。增加基线是为了检验具体假设，而非为了凑模型数量。每个基线应有清楚可获得的信息，不能让它读取比主模型更多的未来或标签。

## 4. 完整项目：从人工数据到冻结测试

<a id="project-4-detail-15"></a>

### 4.1 生成机制公开，数据角色仍需隔离

程序生成六十台设备、每台八条观测。目标由已见输入、设备共享效应和随负载扩大的噪声共同组成。设备效应没有直接提供给模型，所以新设备上存在当前输入难以消除的误差。生成机制用于教学核对，不应在搜索时读取真实生成系数作为额外信息；即使合成数据知道答案，也应保持实验角色。

数值传感器随机缺失，训练折通过中位数填补并增加缺失标记；站点经过独热编码，训练外未知类别按保存规则处理。这样的预处理是完整预测函数的一部分。若缺失机制本身在部署中改变，或新站点超出已评价范围，接口能够生成数字不等于统计证据已经覆盖。

外层设备划分冻结最终测试。开发集再做三折外层诊断，每一外层训练部分内用三折搜索 alpha，产生真正没有使用该外层标签进行选择的预测。随后在整个开发集重复内层搜索并 refit，最终仅评价一次冻结测试。内层分数、嵌套开发分数和最终测试分数对应不同对象，报告必须分列。

<a id="project-4-detail-16"></a>

### 4.2 可独立运行的全流程

完整代码中所有变量均在本块创建。它不依赖前面两个实验的内存，也不读取用户文件。线程限制只作用于受控代码范围，用于避免小矩阵搜索无谓启动过多线程，不构成任何硬件加速承诺。

```python
import numpy as np
import pandas as pd
from sklearn.base import clone
from sklearn.compose import ColumnTransformer
from sklearn.dummy import DummyRegressor
from sklearn.impute import SimpleImputer
from sklearn.linear_model import Ridge
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.model_selection import GroupShuffleSplit, GroupKFold, GridSearchCV
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from threadpoolctl import threadpool_limits

rng = np.random.default_rng(20261017)
group = np.repeat(np.arange(60), 8)
n = len(group)
load = rng.uniform(0.2, 3.0, n)
temperature = rng.normal(20, 5, n)
sensor = rng.normal(size=n)
age = np.repeat(rng.uniform(1, 8, 60), 8)
site_id = group % 3
site = np.array(["A", "B", "C"])[site_id]
device_effect = np.repeat(rng.normal(0, 1.7, 60), 8)
y = (30 + 4*load + 0.3*(temperature-20) + 2*sensor
     - 0.2*age + np.array([1.5, -1.0, 0.0])[site_id]
     + device_effect + rng.normal(0, 0.8+0.5*load, n))
sensor_seen = sensor.copy()
sensor_seen[rng.random(n) < 0.12] = np.nan
X = pd.DataFrame(dict(load=load, temperature=temperature,
                      sensor=sensor_seen, age=age, site=site))
num = ["load", "temperature", "sensor", "age"]
cat = ["site"]

def make_model():
    numeric = Pipeline([
        ("fill", SimpleImputer(strategy="median", add_indicator=True)),
        ("scale", StandardScaler()),
    ])
    prep = ColumnTransformer([
        ("num", numeric, num),
        ("cat", OneHotEncoder(handle_unknown="ignore", sparse_output=False), cat),
    ])
    return Pipeline([("prep", prep), ("ridge", Ridge())])

def make_search():
    return GridSearchCV(
        make_model(), {"ridge__alpha": [0.01, 1.0, 100.0]},
        scoring="neg_mean_absolute_error", cv=GroupKFold(3),
        refit=True, n_jobs=1, error_score="raise",
    )

dev, test = next(GroupShuffleSplit(n_splits=1, test_size=0.2,
                                  random_state=19).split(X, y, group))
assert not set(group[dev]) & set(group[test])
Xd, yd, gd = X.iloc[dev], y[dev], group[dev]
Xt, yt = X.iloc[test], y[test]
oof = np.full(len(dev), np.nan)
chosen = []
with threadpool_limits(limits=1):
    for tr, va in GroupKFold(3).split(Xd, yd, gd):
        assert not set(gd[tr]) & set(gd[va])
        search = make_search()
        search.fit(Xd.iloc[tr], yd[tr], groups=gd[tr])
        oof[va] = search.predict(Xd.iloc[va])
        chosen.append(search.best_params_["ridge__alpha"])
    final_search = make_search().fit(Xd, yd, groups=gd)
    final = final_search.best_estimator_
    pred = final.predict(Xt)
    baselines = {s: DummyRegressor(strategy=s).fit(Xd, yd)
                 for s in ["mean", "median"]}
assert np.all(np.isfinite(oof)) and np.all(np.isfinite(pred))
assert pred.shape == yt.shape
fill = final.named_steps["prep"].named_transformers_["num"].named_steps["fill"]
assert np.allclose(fill.statistics_, np.nanmedian(Xd[num].to_numpy(), axis=0))
assert np.allclose(final.predict(Xt[Xt.columns[::-1]]), pred)
residual = yt-pred
assert np.isclose(mean_absolute_error(yt, pred), np.abs(residual).mean())
assert np.isclose(mean_squared_error(yt, pred), np.mean(residual**2))
print("nested development MAE", mean_absolute_error(yd, oof), "fold alphas", chosen)
for name, model in {**baselines, "ridge": final}.items():
    phat = model.predict(Xt)
    print(name, "MAE", mean_absolute_error(yt, phat),
          "RMSE", np.sqrt(mean_squared_error(yt, phat)), "R2", r2_score(yt, phat))
report = pd.DataFrame(dict(device=group[test], load=Xt["load"].to_numpy(),
                           y=yt, prediction=pred, residual=residual))
report["abs_error"] = np.abs(residual)
report["load_band"] = np.where(report["load"] < 1.5, "low", "high")
summary = report.groupby("load_band").agg(
    n=("y", "size"), devices=("device", "nunique"),
    mae=("abs_error", "mean"), bias=("residual", "mean"))
assert summary["n"].sum() == len(test)
print("final alpha", final_search.best_params_, "test rows/devices", len(test), len(np.unique(group[test])))
print(summary)
```

### 4.3 从输出反推每个数属于哪里

嵌套开发 MAE 由不同外层训练模型产生，估计的是在对应训练规模与分组协议下运行选择规则的表现。最终 Ridge 使用全部开发数据 refit，测试则只包含外部设备。两者不必相等，差异可能来自训练规模、设备效应或抽样波动，不能只看一个更小的数就认定另一层程序错误。

alpha 的候选与评分在测试前固定。代码打印各开发外折选择，便于观察选择稳定性；它们不同并不需要强行统一。最终搜索使用全开发集，所以可能选择另一候选。不能在看到测试 RMSE 后改选另一 alpha，却继续报告原 MAE 选择协议的性能。

基线的均值与中位数来自相同开发标签，拥有相同测试请求。比较应从同一行对应误差计算差值；模型若拒绝部分请求，覆盖率和拒绝规则也要纳入，不能静默缩小评价集合。这里每个测试设备恰有八行，设备与请求权重相同是人工设计，不应在真实不等记录数据中默认成立。

<a id="project-4-detail-18"></a>

### 4.4 代码里的不变量比一个漂亮分数更有用

设备集合不相交检查划分；填补统计等于开发中位数检查最终 refit 来源；列名重排后预测一致检查命名列选择；残差复算检查指标与预测版本一致。这些断言各自对应一个明确错误，不证明所有潜在泄漏都已排除。未来字段若被加入合法列列表，Pipeline 本身不会识别其时间含义。

本块只是合成世界中的统计项目，没有测服务器延迟，也没有验证真实设备数据。搜索结束、预测数组存在、模型超过某个基线与真实应用有效，分别需要不同证据。报告应保留实际规模、代码身份、参数与数据角色，不把一次内存实验扩展成生产性能承诺。

## 5. 从列到残差：把每一个变换说清

<a id="project-4-detail-20"></a>

### 5.1 数值填补与缺失标记的联合含义

中位数填补把缺失输入映射为一个训练参照值，缺失标记则允许模型区分真实处于中位水平与原本没有观测。它没有恢复缺失值的真实内容，也不保证对任何缺失机制都有效。若缺失与目标或设备状态有关，模型可能依赖缺失模式，这种依赖需要在新环境中单独核验。

SimpleImputer 的缺失标记通常由拟合时存在缺失的列决定；训练时从未缺失的列，在部署首次缺失时不一定获得同样新增标记。应记录具体接口与模式，若任务要求每列都具有固定缺失通道，可显式设计完整表示。全缺失列也要规定保留或拒绝策略，不能让输出维数悄悄改变。

<a id="project-4-detail-21"></a>

### 5.2 类别编码与训练外类别

独热编码把站点变成若干二元列；配合截距会出现线性冗余，正惩罚能使权重求解稳定，但系数解释依赖编码与惩罚。未知类别按本例配置映射为已有类别列全零，这是一种明确回退，并不意味着模型已经学到未知站点的作用。应在输出诊断中标记未知比例，并给未覆盖场景设定评价计划。

若直接把类别编号一、二、三作为连续数值，会引入顺序和等距假设。这个假设也许在某些有序变量上合理，但对无序站点通常没有依据。选编码应从字段含义出发，不应因为某种表示方便 Ridge 接收，就忽略它给函数族加入的结构。

<a id="project-4-detail-22"></a>

### 5.3 残差表需要保留原始标识

残差表至少保留样本标识、设备、预测时点、真实目标、预测、误差及相关输入角色。没有标识，排序或过滤之后就可能把一行预测连到另一行标签；只有一组汇总数，也难以核对错误来源。重建表时使用明确键或共同位置，并断言行数、唯一性与缺失。

按真实目标分箱可以发现高目标低估，但真实目标在预测时不可见，所以这类分组通常用于事后诊断，而非直接服务规则。按输入或预测值分箱更接近可行动分段，同样需要独立选择与足够支持。分箱边界若根据测试误差不断修改，会增加探索自由度，必须记录而非伪装成预设确认。

## 6. 异方差、尾部与有方向的误差

<a id="project-4-detail-24"></a>

### 6.1 平均残差接近零为什么仍可能很差

若一半请求低估十、一半高估十，平均残差为零，MAE 与 RMSE 却都为十。若低负载组持续高估、高负载组持续低估，总体偏差也可能抵消。应同时看各组支持、绝对误差、平方误差与偏差，并从原始输入检查单位、目标对齐和可能遗漏的非线性。

对带截距的无惩罚最小二乘，训练残差和在相应满秩求解条件下为零；它是拟合方程的一项性质，不是训练集无偏就说明未来无偏。岭在未惩罚截距的合适实现中也会满足相应截距条件，但开发外预测与测试残差没有同样必然性。不能把训练代数性质提升为部署校准保证。

<a id="project-4-detail-25"></a>

### 6.2 异方差信号与替代解释

残差随负载扩张可能来自噪声方差增加，也可能来自遗漏均值关系、输入测量误差或某群体分布变化。可先比较有方向残差与绝对残差：均值出现弯曲提示均值函数问题，中心大致对齐但离散变宽提示方差结构。两种现象可同时存在，图形相关不能唯一识别原因。

本章生成器已知噪声标准差随负载增加，但真实项目没有这样的答案。应提出竞争解释，在开发数据上增加非线性项、检查测量与群体，再以新的合法评价比较。提高模型复杂度未必修复不可减少噪声；改损失或区间模型也未必修复错误标签。排错顺序应先核对数据与目标。

<a id="project-4-detail-26"></a>

### 6.3 尾部误差与记录审查

RMSE 明显高于 MAE 常提示较大误差的重要贡献，但没有统一比值能自动判定异常。先列出高损失样本的支持与来源，核对标签单位、时间和数据版本，再区分数据错误、合法困难样本与覆盖不足。仅因某样本误差大而删除，会把评价总体改成模型更容易处理的子集。

若业务确实对极端响应有单独要求，应提前设置相应群体指标或成本，不能等结果出现后只挑有利片段。对极少尾部事件，点估计不稳定，应说明样本量与不确定性，必要时补采样。整体均值改善不能自动补偿某个必须满足的关键约束。

<a id="project-4-detail-27"></a>

### 6.4 残差校准与条件均值最优不是同一个要求

在平方损失且二阶矩存在时，真实条件均值 $`m(X)=E[Y\mid X]`$ 最小化总体风险，并有 $`E[(Y-f(X))^2]=E[(Y-m(X))^2]+E[(m(X)-f(X))^2]`$。交叉项为零来自 $`E[Y-m(X)\mid X]=0`$。它说明模型改进应针对尚可预测的均值差异，而不是把所有噪声都当作需要拟合的结构。

仅检查 $`E[Y-\hat Y\mid\hat Y]=0`$ 更弱。设两个独立对称变量各取正负一，真实响应为两者之和，模型只预测第一个变量。按预测值分组的残差均值为零，但按第二变量分组，残差分别为正一与负一。模型看似在预测尺度校准，却仍遗漏可预测信息。残差分析应结合合法输入与群体，不能只看一条总体可靠性关系。

这个有限例子也解释了为何“残差与预测没有趋势”不等于模型已经最优。若遗漏变量部署不可获得，收益又未必可实现；如果新增字段实际来自结果回写，则会形成非法改善。统计可预测性必须再与信息可用性核对，才能转成合理下一轮特征实验。

## 7. 解读本次运行：数值支持哪种结论

<a id="project-4-detail-29"></a>

### 7.1 先复算指标，再解释模型收益

在本章核对环境和固定生成种子下，嵌套开发 MAE 约二点一八；冻结测试上，均值和中位数基线的 MAE 都约三点六五，岭模型约一点九二，RMSE 约二点三八。它支持在本次合成数据、设备划分和候选空间中，线性特征带来预测收益。换一个合法生成种子，具体数字会变化，不要求读者机器逐位一致。

测试 R² 约零点七三，分母对应测试标签围绕其自身均值的变化。它不能读作“百分之七十三样本预测正确”，也不是某种事件概率。两个常数基线的测试 R² 略负，也不说明程序计算失败；它们使用开发标签拟合，与定义中可读取测试标签的参照常数不是同一个对象。

手工检查可以任选几行，从保存预测求残差、绝对值和平方，再汇总与表格对照。若报告数与手算不一致，先检查样本集合、模型版本和残差符号，不急于归因给浮点误差。数值误差通常很小，错位或不同过滤规则则能造成明显差异。

<a id="project-4-detail-30"></a>

### 7.2 分组发现与确认结论分开

本次测试高低负载组的平均残差都略为正，表示在这次样本上平均有低估。测试只有十二台设备，不能直接把这一符号解释为所有未来设备必然系统性低估。若据此提出截距修正，应该在开发数据或新确认数据上研究，不可把测试残差均值直接加到模型上，再称修正后测试仍独立。

主代码的负载分界在看测试前给定，支持度同时列出。若要探索更多分箱、站点与设备年龄，可以形成问题清单，但必须记录尝试范围，特别是小群体里极端均值可能主要来自少数设备。确认性比较应有独立评价与适当的多重查看控制。

<a id="project-4-detail-31"></a>

## 8. 配对差值与设备级不确定性

<a id="project-4-detail-32"></a>

### 8.1 比较应保留同一请求的对应关系

定义每行改进 $`d_i=\vert y_i-\hat y_i^{A}\vert -\vert y_i-\hat y_i^{B}\vert `$，正值表示模型 B 更好。对同一请求两模型误差往往相关，直接分析差值能保留配对信息。比较两个单独区间是否重叠，既不等价于差值检验，也不直接表达实际改进幅度。

若设备内相关，应以设备作为重采样单位。每次抽取设备并保留它的全部记录，同时保留 A、B 的配对。这里估计的是给定已训练预测器、在相应设备抽样机制下的测试性能不确定性；它不包含重新训练、重新搜索和再次选择造成的所有波动。评价整个学习规则时，需要把相应步骤放进外层重复设计。

<a id="project-4-detail-33"></a>

### 8.2 请求平均和设备平均不能混算

设一台设备只有一行、差值负十，另一台有九行、差值都为一。请求平均为负零点一，设备平均为负四点五。两者方向虽相同，量级截然不同；若改第二组差值还可能出现方向反转。设备抽样方式与统计目标必须一起定义，而不是看到分组相关就机械把所有量改成等设备权重。

对请求总体的目标，设备重采样后应按重新抽到的总行数计算比值；对典型设备目标，可以平均抽到设备的内部均值。不能在 bootstrap 中用一种权重、原始点估计却用另一种。设备大小与误差相关时，差异尤其明显。

```python
import numpy as np

hand = np.array([-10.0] + [1.0]*9)
assert np.isclose(hand.mean(), -0.1)
assert np.isclose(np.mean([-10.0, 1.0]), -4.5)
rng = np.random.default_rng(62)
sizes = rng.integers(2, 9, size=40)
group = np.repeat(np.arange(40), sizes)
shared = rng.normal(-0.15, 0.4, size=40)
loss_a = 2 + np.abs(rng.normal(size=len(group)))
loss_b = np.maximum(0, loss_a + shared[group] + rng.normal(0, 0.1, len(group)))
d = loss_a-loss_b
group_sum = np.array([d[group==g].sum() for g in range(40)])
group_mean = group_sum/sizes
indices = rng.integers(0, 40, size=(3000, 40))
device_boot = group_mean[indices].mean(axis=1)
request_boot = group_sum[indices].sum(axis=1)/sizes[indices].sum(axis=1)
assert np.isclose(group_sum.sum()/sizes.sum(), d.mean())
assert np.all(np.isfinite(device_boot)) and np.all(np.isfinite(request_boot))
assert np.quantile(device_boot, .025) < np.quantile(device_boot, .975)
print("device mean/interval", group_mean.mean(), np.quantile(device_boot, [.025,.975]))
print("request mean/interval", d.mean(), np.quantile(request_boot, [.025,.975]))
```

### 8.3 区间宽度与证据强度

设备数量少时，bootstrap 近似也可能不稳定；把每台设备复制更多行，不能制造更多独立设备。小样本尾部、重尾损失与自适应选择会影响区间解释。应同时报告独立设备数、记录数、点估计与重采样规则，而不是只给一个小数区间。

预设最小实用差异也很重要。某改进即使有稳定统计证据，也可能不足以抵偿推理成本或数据依赖；反过来，区间宽并不证明两模型等价。可以按共同预算增加独立设备、简化选择过程或报告结论尚不确定，不能用“未显著”代替等价检验。

## 9. 目标变换：还原单位不等于还原条件均值

<a id="project-4-detail-36"></a>

### 9.1 对数尺度改变了优化对象

正目标可考虑对数变换，以减弱大值主导或刻画乘性关系。在对数尺度最小化平方误差，估计的是条件对数均值，直接取指数一般不是原单位条件均值。由指数凸性，$`E[e^Z\mid X]\ge e^{E[Z\mid X]}`$；两者相等需要退化等特殊条件。

若对数残差为零均值高斯且方差固定，原单位均值带有 $`e^{\frac{\sigma^2}{2}}`$ 因子。更一般可用适当的训练残差估计还原因子，但它依赖误差分布与拟合方法，不能把一个全局因子用于所有异方差区域而不检查。取对数也要求目标严格为正，任意加一会改变目标与单位解释。

<a id="project-4-detail-37"></a>

### 9.2 一个不依赖高斯假设的还原算例

设 $`\log Y=1+0.5x+\epsilon`$，每个输入处误差等可能为正负零点七。对数回归可精确得到中心直线，但原单位均值为 $`e^{1+0.5x}\cosh(0.7)`$，直接指数预测偏低。若误差幅度随输入改变，正确乘子也随输入改变。下面比较固定幅度与变化幅度，核对“一个全局校正足够”的适用边界。

```python
import numpy as np
from sklearn.compose import TransformedTargetRegressor
from sklearn.linear_model import LinearRegression

x = np.repeat([-1.0, 0.0, 1.0], 2)
X = x[:, None]
eps = np.tile([-0.7, 0.7], 3)
y = np.exp(1+0.5*x+eps)
model = TransformedTargetRegressor(regressor=LinearRegression(),
                                  func=np.log, inverse_func=np.exp).fit(X, y)
u = np.array([[-1.0], [0.0], [1.0]])
naive = model.predict(u)
actual_mean = np.exp(1+0.5*u[:,0])*np.cosh(0.7)
smearing = np.mean(np.exp(np.log(y)-model.regressor_.predict(X)))
assert np.allclose(naive, np.exp(1+0.5*u[:,0]))
assert np.all(naive < actual_mean)
assert np.allclose(naive*smearing, actual_mean)
a = np.repeat([0.2, 0.7, 1.2], 2)
y2 = np.exp(1+0.5*x+np.tile([-1.,1.],3)*a)
m2 = TransformedTargetRegressor(regressor=LinearRegression(),
                               func=np.log, inverse_func=np.exp).fit(X, y2)
global_factor = np.mean(np.exp(np.log(y2)-m2.regressor_.predict(X)))
truth2 = np.exp(1+0.5*u[:,0])*np.cosh([0.2,0.7,1.2])
assert not np.allclose(m2.predict(u)*global_factor, truth2)
print("naive", naive, "conditional means", actual_mean,
      "heteroscedastic global correction fails", global_factor)
```

<a id="project-4-detail-38"></a>

### 9.3 变换选择必须留在开发边界

比较原目标训练与对数目标训练，应在共同原单位与相同测试对象上报告主要损失，也可辅助报告变换尺度误差。目标变换改变了偏好，不是天然提高所有指标的技巧。若调参时只看对数误差，最终又只展示原单位最好的一组结果，就需要说明这种选择是否事先规定。

还原校正、截断负预测、上下界投影都属于后处理，必须保存进预测函数。投影到真实合法范围在某些损失下可有性质，但若范围来自未来标签或测试极值，就改变了信息边界。交付时说明后处理来源、参数与适用条件，下一章会进一步把这些内容写成可执行契约。

## 10. 点预测与预测区间分别验收

<a id="project-4-detail-40"></a>

### 10.1 总体 RMSE 不是每个请求的可信半径

整体误差摘要没有自动提供逐样本区间。把每条预测上下各加一个 RMSE，既未说明覆盖水平，也未处理异方差、偏差与参数不确定性。区间必须定义覆盖哪个未来对象、在什么分布假设下、属于边际还是条件保证，并使用相应数据角色构造。

主项目有设备内相关，不应直接把所有校准行当成独立交换样本。可以研究以设备为单位的覆盖目标、分组校准或符合部署设计的其他方法，但必须先定义是随机设备的一条记录，还是整台设备所有请求同时覆盖。不同目标需要不同分数与验证，不能借用一个简单公式代替问题定义。

<a id="project-4-detail-41"></a>

### 10.2 独立样本下分位数修正的计算

另用一个独立同分布的小实验说明 split conformal：模型只在训练集拟合，校准分数是绝对残差，取 $`k=\lceil(n_{cal}+1)(1-\alpha)\rceil`$ 的顺序统计量作半宽。在相应交换性下，新分数的排名给出边际覆盖保证。若 $`k>n_{cal}`$，采用无穷宽的保守约定，而不是强行拿最大有限残差冒充所需水平。

```python
import numpy as np
from sklearn.linear_model import Ridge

rng = np.random.default_rng(74)
def sample(n):
    X = rng.normal(size=(n, 1))
    y = 2*X[:,0] + rng.normal(0, 0.5+0.3*np.abs(X[:,0]), n)
    return X, y
Xtr, ytr = sample(160)
Xcal, ycal = sample(100)
Xte, yte = sample(400)
model = Ridge(alpha=1).fit(Xtr, ytr)
scores = np.abs(ycal-model.predict(Xcal))
def radius(values, alpha):
    if len(values)==0 or not 0<alpha<1:
        raise ValueError("nonempty calibration and alpha in (0,1) required")
    k = int(np.ceil((len(values)+1)*(1-alpha)))
    return np.inf if k>len(values) else np.partition(values,k-1)[k-1]
q = radius(scores, 0.1)
pred = model.predict(Xte)
coverage = np.mean(np.abs(yte-pred)<=q)
assert np.isfinite(q) and q>=0
assert np.sum(scores<=q)>=int(np.ceil(101*0.9))
assert np.isinf(radius(np.array([1.,2.,3.]), 0.01))
assert 0<=coverage<=1
print("calibration radius", q, "empirical test coverage", coverage)
```

单次测试覆盖率不保证恰好达到名义水平，有限随机测试本身也有波动。这个程序验证顺序统计量的实现，理论保证来自排名论证及假设，而不是某次覆盖数字碰巧较高。异方差情形下，边际覆盖也不自动给每个负载或输入区域同样覆盖。

## 11. 把诊断发现转成下一轮实验

<a id="project-4-detail-43"></a>

### 11.1 每个改动对应一个可反驳假设

若高负载误差更大，可比较补充非线性均值项、方差建模、测量质量与数据覆盖这几种解释。一次只改变能区分假设的因素，保留共同设备划分、预算和指标。若同时换数据、模型、损失与分箱，结果改善也难以判断来自哪一个机制。

如果发现站点类别承担大量作用，先检查它是否是设备身份或标注流程的代理，是否在新站点可获得，是否形成不应推广的来源捷径。删除该特征重训与在固定模型上置换回答不同问题，不能用其中一个替代另一个。第五章将展开这种依赖审查与交付证据。

<a id="project-4-detail-44"></a>

### 11.2 失败运行与选择机会也应记录

不能只保留最佳一次。搜索失败、数值异常、被排除配置和预算消耗都会影响方法比较。若某算法获得更大搜索空间或更多种子，单纯比较最好分数不是公平资源下的结论。记录每个尝试的参数、训练范围和失败原因，才能复核最后为何采用这个方案。

对最终模型，至少保留输入模式、预处理、参数、选择规则、预测与逐样本误差。训练复现、预测复现和统计结论复现有不同范围：重新训练可能因环境稍有变化而数值不同，但固定产物推理应满足明确容差；重新抽设备的指标则具有真实抽样波动。交付记录应分别给出验收方式。

## 12. 更进一步：学习规则、总体与信息量

<a id="project-4-detail-46"></a>

### 12.1 测试区间没有覆盖所有训练波动

记训练数据为 $`D`$，测试统计为 $`T`$。全方差公式把波动拆成 $`E_D[\operatorname{Var}(T\mid D)]+\operatorname{Var}_D(E[T\mid D])`$。第一部分是固定一次训练结果后，评价样本变化带来的波动；第二部分是重新收集训练数据、搜索并拟合后，模型自身变化带来的波动。

对冻结模型做设备 bootstrap，主要接近第一部分的相应抽样问题。增加独立测试设备能减少这部分不确定性，却不能直接说明重新训练也稳定。若要评价学习规则，需要在外层重新进行训练与选择，并保持真实数据结构。把两种区间都叫模型误差条，会让比较对象不清楚。

在平方损失与相应条件下，还可对预测函数误差分解偏差、方差和噪声；但这不是所有损失都具有的同一代数。不能看到 MAE 就机械套用平方误差分解，也不能把训练残差方差当成不可约噪声的无偏估计。分解的条件对象、期望范围与模型族需先写明。

<a id="project-4-detail-47"></a>

### 12.2 学习曲线如何区分数据不足与表示限制

固定评价设备集合，在不同规模开发设备上重新拟合完整流程，观察训练、开发外误差和选择稳定性。若增加独立设备持续改善，补数据可能有价值；若误差平台化，也可能来自表示遗漏、标签噪声或模型限制。平台本身不能唯一证明已达到不可约误差。

学习曲线横轴应是与泛化问题对应的独立单位。在同一设备上增加记录，与增加新设备，可能改善不同部分。若真实目标是新设备表现，应分别比较这两种采样策略，报告设备数和每设备记录分布，而不是只写样本量翻倍。可用合成生成器固定其他因素，研究何种投入真正减少目标误差。

<a id="project-4-detail-48"></a>

### 12.3 从新设备扩展到新站点

按设备划分并不自动保证新站点外推。若训练和测试都包含三个站点，模型只验证这些站点内新设备。真实部署若去往第四站点，未知类别回退仅保证函数可执行，不能保证条件关系稳定。可以增加按站点留出与时间前推的评价矩阵，明确每种结果覆盖的场景。

若目标站点的输入超出训练支持，简单重加权没有足够信息恢复目标误差。即使输入范围重叠，条件响应也可能改变。来源差异与条件机制需要额外标签或科学假设才能区分。遇到范围外问题，合理结论可能是需要新证据，而不是继续扩大同来源超参数搜索。

<a id="project-4-detail-49"></a>

### 12.4 折平均、总体归约与训练规模

若两个评价折分别有一行和九行，MSE 为一和九，合并误差的 MSE 为八点二，RMSE 为八点二的平方根；简单平均两折 RMSE 却是二。这两个数对应不同加权与非线性顺序，不能都称作同一总体的 RMSE。MAE 虽然可逐行相加，折大小不等时也需按目标权重汇总。

嵌套外层不同模型的预测还包含训练规模差异。其分数评价相应规模下的选择规则，最终全部开发集重训可能有不同表现。应保留折支持、参数选择与汇总方式，必要时用学习曲线解释规模影响，而非将多个折当作互相独立的重复实验直接计算标准误。

<a id="project-4-detail-50"></a>

### 12.5 用合成机制区分可预测误差与剩余波动

在本生成器的新设备总体解释下，设备共享效应独立于合法输入，单次噪声在给定负载后为零均值高斯。若传感器已观察，给定输入仍有方差 $`1.7^2+(0.8+0.5\,load)^2`$；若传感器独立缺失，其真实值仍服从标准高斯，缺少的 $`2\,sensor`$ 又带来四的方差。填补为某个常数不能凭空恢复这部分信息。

若已知真实条件均值，并按上述高斯与独立假设对新设备预测，条件 MAE 为总标准差乘 $`\sqrt{\frac{2}{\pi}}`$，条件 MSE 为总方差。它们提供研究生成器时的总体参照，提醒我们并非所有剩余误差都能靠更深模型消除。实际项目没有已知机制，这类参照不能直接从训练残差估计出来，更不能未经诊断就宣称已到达噪声极限。

总体最优风险也不是每次有限测试的硬下界。某批设备效应恰好较小，经验误差可能更低；另一批则可能更高。应在多个独立生成重复中比较平均行为，并分别记录训练与测试抽样。用一次测试低于某个理论期望来宣布算法突破不可约误差，是混淆总体风险与随机样本统计。

## 13. 从模型系数到可审查解释

<a id="project-4-detail-52"></a>

### 13.1 换回原始单位之后再讨论斜率

若标准化变量为 $`z_j=\frac{(x_j-m_j)}{s_j}`$，预测为 $`b_z+\sum_jw_j^zz_j`$，原单位系数为 $`w_j^x=\frac{w_j^z}{s_j}`$，截距为 $`b_x=b_z-\sum_j\frac{w_j^zm_j}{s_j}`$。这只是固定预处理下同一函数的代数展开，不是新的拟合。存在填补、指示列和独热列时，还应分别保留相应规则，不能只导出一组看起来简洁的斜率。

同一预测函数在不同编码下可能有不同参数表示，相关列也会共享信息。岭惩罚选择了一个受约束的解，但不使每个系数自动具有独立因果含义。若实际操作要改变设备负载，还需分析干预、混杂与可行范围；本章预测回归只描述给定输入下的统计关系。

<a id="project-4-detail-53"></a>

### 13.2 不把正则化系数当作普通无偏估计

岭有意引入收缩，其参数估计偏差是方法的一部分。直接沿用无惩罚最小二乘的标准误公式，再把系数是否跨零解释成选定模型里的普遍显著性，忽略了惩罚与模型选择。若需要参数推断，应选择目标明确的方法，并说明设计矩阵、噪声、选择过程与不确定性如何处理。

预测用途通常更关心输入变化时输出依赖怎样、哪一类错误仍存在、移除某信息后是否可替代。可以通过固定模型扰动、删特征重训和不同来源评价形成互补证据。三者目标不同，下一章会把这种区分用于特征审查，避免把一张系数排行当作项目解释的全部。

## 14. 二十道练习与逐题详解

<a id="project-4-detail-55"></a>

### 14.1 题一：为什么应同时列两个常数基线

**题目。** 训练目标为零、零、九，主要指标是 MAE。只拿均值三与模型比较，足以构成合理基线吗？

**解析。** 均值在训练平方误差下最优，但 MAE 的最优常数是中位数零。均值 MAE 为四，中位数为三；如果模型误差为三点五，它超过均值却不超过中位数。因此应保留匹配主要损失的对照，并注明所有常数只来自训练标签。更强基线不是要求它偷看测试，而是让它在相同合法信息下充分发挥简单方法的能力。

<a id="project-4-detail-56"></a>

### 14.2 题二：残差平均为零能否说明效果好

**题目。** 四个请求残差分别为十、十、负十、负十。平均残差、MAE 和 RMSE 分别多少？若两种符号分别来自不同设备群体，应补什么分析？

**解析。** 平均残差为零，MAE 与 RMSE 都为十。总体方向抵消掩盖了每次的大误差。应按预设群体列支持数、偏差和绝对误差，检查单位、对齐与来源差异。若据此形成新假设，应在开发或新确认数据验证，不能用测试后不断分组挑出的最明显差异作为未经选择的结论。

<a id="sec-7-1"></a>
<a id="project-4-detail-57"></a>

### 14.3 题三：测试 R² 为什么能为负四

**题目。** 测试真实值为零、二，预测为三、三。分母使用测试均值，计算 R²，并解释为什么它不等于部署均值基线的实测提升。

**解析。** 测试均值为一，平方离差和为二；模型平方误差和为十，所以结果是 $`1-\frac{10}{2}=-4`$。部署基线只能从开发标签拟合，其常数未必是一，因此需另行实测。R² 参照是指标定义中的评价均值，不是给模型额外读测试标签的权限。负值说明比该参照差，不是概率计算异常。

<a id="project-4-detail-58"></a>

### 14.4 题四：负 MAE 应怎样选择

**题目。** 两个候选的验证评分分别为负八和负十一。若搜索统一要求越大越好，选哪一个？报告时如何还原？

**解析。** 负八较大，对应 MAE 八，优于 MAE 十一。报告恢复正误差并保留评分名称。不能先取绝对值又按越大越好排序。还应说明折分数怎样平均，尤其组大小不等时，折均值与合并预测的总体 MAE 可能不同。选参数和报告最终测试都应对同一主要目标负责。

<a id="project-4-detail-59"></a>

### 14.5 题五：相同 alpha 是否表示相同正则强度

**题目。** 一份代码的数据项为平方误差和，另一份为均方误差，都加 alpha 乘权重平方和。相同 alpha 是否对应同一个优化问题？

**解析。** 不是。均方形式把数据项除以样本数，却未同步缩放惩罚，改变二者比例。应从完整目标对齐系数，而非只看参数名字。特征单位、标准化、截距和类别编码还会继续影响约束几何。比较实现前写出目标及归约，能避免把接口差异误认为算法差异。

<a id="project-4-detail-60"></a>

### 14.6 题六：为什么小奇异方向更被压制

**题目。** 两个奇异值为一和十，alpha 为一。相应拟合值方向收缩因子是多少？能否说两个原坐标系数都缩小一半？

**解析。** 因子分别为二分之一与一百零一分之一百，后一方向几乎保留。收缩发生在右奇异方向中，而原坐标一般是这些方向的组合，所以不是统一乘一个比例。有效自由度可以由这些拟合因子求和，但若 alpha 经过搜索，不能认为该和已经包含全部选择复杂度。

<a id="project-4-detail-61"></a>

### 14.7 题七：同一设备出现在两侧是否总是泄漏

**题目。** 随机拆行让同一设备同时出现在训练和测试。是否在任何任务中都绝对无效？本章为什么拒绝这种划分？

**解析。** 划分应对应部署任务。若目标是已有设备未来预测，可允许其合法历史进入训练，但仍需时间与可用信息约束。本章目标是新设备，随机拆行回答另一个问题，并可能利用设备特有模式。不能仅凭是否出现同设备作脱离任务的判断，也不能把较容易任务的分数替代新设备外推证据。

<a id="project-4-detail-62"></a>

### 14.8 题八：Pipeline 能否自动识别未来字段

**题目。** 所有预处理都放入 Pipeline，但列列表包含预测后才生成的维修结果。是否已经因折内拟合而没有泄漏？

**解析。** 没有。Pipeline 约束统计量在哪些样本上拟合，不知道字段何时在真实系统可用。未来字段即使每折单独处理，仍然向模型提供非法信息。需要字段来源、可得时间与样本截止时点契约，并对提取逻辑做反事实或时间断言。工具生命周期与业务可见性是两层不同的检查。

<a id="project-4-detail-63"></a>

### 14.9 题九：先选参数再生成折外预测的问题

**题目。** 用全开发集选择最佳 alpha，随后固定该 alpha 在同一数据上做交叉预测。这能无条件评价整个选择规则吗？

**解析。** 不能，因为每个外折标签已经参与此前的参数选择。它可提供某些固定配置的诊断，但完整选择过程评价应在每个外层训练部分内部重新搜索，再预测外层。最终用全部开发集 refit 是交付步骤，不与外层评价对象完全相同。明确这三个角色，才能正确解释分数差异。

<a id="project-4-detail-64"></a>

### 14.10 题十：未知类别全零是否等于已验证

**题目。** 新站点在训练中从未出现，独热编码按忽略未知类别处理，程序正常返回预测。是否证明新站点表现可靠？

**解析。** 只证明接口按规定执行回退，不能证明条件关系在新站点不变。应报告未知类别比例与支持缺口，并根据真实部署设置新站点评价。全零编码还受截距及其他特征影响，不能解释成学到了该站点的真实基线。可运行性、覆盖与统计效果需要分别验收。

<a id="project-4-detail-65"></a>

### 14.11 题十一：bootstrap 应如何保持配对

**题目。** 两个模型在同一批设备上预测。分别对 A、B 随机重采样再相减，与按设备同时抽取两模型误差后计算差值，是否等价？

**解析。** 一般不等价。独立重采样丢掉两模型在相同请求上的相关，改变差值方差。应抽同一设备并保留其全部记录与两列预测。若目标是请求平均，还需按抽到的总请求数归一；若目标是设备平均，则使用设备均值。评价单位、配对和权重三者必须同时保持一致。

<a id="project-4-detail-66"></a>

### 14.12 题十二：一行与九行的平均为什么不同

**题目。** 设备甲一行改进负十，设备乙九行改进均为一。请求平均和设备平均分别多少？它们能否交替作为同一报告的点估计和区间？

**解析。** 请求平均为 $`\frac{(-10+9)}{10}=-0.1`$，设备平均为 $`\frac{(-10+1)}{2}=-4.5`$。前者随机挑请求，后者随机挑设备再看其平均，目标不同。不能把一个点估计与另一种加权 bootstrap 区间拼接。若业务同时关心二者，应分列，并给每列清楚的总体与抽样解释。

<a id="project-4-detail-67"></a>

### 14.13 题十三：固定模型区间包括搜索波动吗

**题目。** 冻结模型后对测试设备 bootstrap，得到很窄 MAE 区间。能否据此说重新采集训练数据再搜索也会得到相同模型？

**解析。** 不能。该区间主要处理给定模型下评价设备的抽样变化，未重新执行训练与选择。学习规则还受训练设备、搜索和算法随机性影响。若结论针对重复训练的整个方法，应设计对应外层过程，或明确只评价当前产物。增加测试行数不能消除所有训练过程不确定性。

<a id="project-4-detail-68"></a>

### 14.14 题十四：对数预测直接取指数估计什么

**题目。** 对数响应等于中心一加正负零点七，二者等概率。对数均值取指数是多少？原单位均值又是多少？

**解析。** 直接指数还原得到 $`e`$，原单位均值为 $`e\cosh(0.7)`$，更大。原因是非线性还原与求期望不能交换。若误差幅度随输入改变，校正因子也改变。目标变换应在共同原单位上评价，不能只因对数误差较低就推断原尺度所有指标也更好。

<a id="project-4-detail-69"></a>

### 14.15 题十五：训练残差均值零证明无偏吗

**题目。** 含未惩罚截距的平方损失拟合，训练残差和接近零。这能证明未来所有设备群体的残差均值也为零吗？

**解析。** 训练残差和为零是相应拟合方程的结果，不是分布外保证。设备效应、群体组成和模型错设可使未来偏差改变。应在独立设备上评价，并按合适群体报告支持。把训练最优条件解释为真实部署校准，是将算法内代数性质扩大成未经验证的统计结论。

<a id="project-4-detail-70"></a>

### 14.16 题十六：极少校准样本能承诺极高覆盖吗

**题目。** 校准分数只有三个，目标错误率为百分之一。使用本章加一排名修正，应该取哪个顺序统计量？

**解析。** $`k=\lceil4\times0.99\rceil=4`$，超过已有三个分数，采用无穷宽保守约定。不能直接取最大有限分数并宣称仍有相同名义保证。有限样本分辨率是真实信息限制，不是软件不方便。实际项目可补充独立校准数据，或调整覆盖目标与所愿接受的假设。

<a id="project-4-detail-71"></a>

### 14.17 题十七：边际覆盖是否代表每组覆盖

**题目。** 整体百分之九十预测区间在低负载覆盖很好、高负载偏低，是否与边际保证矛盾？

**解析。** 不一定。边际保证对目标总体平均，不自动为每个输入或群体给相同条件覆盖。高负载噪声更大时固定半宽尤其容易产生差异。可以研究合适的分组或归一化分数，但新增设计应在合法开发信息中完成，并检查支持与假设。不能只挑测试中表现好的群体来证明区间可靠。

<a id="project-4-detail-72"></a>

### 14.18 题十八：测试后加一个截距还算冻结吗

**题目。** 看到测试残差均值为正，直接把该均值加到所有预测，再报告修正后的测试 MAE，是否仍是原模型独立测试？

**解析。** 测试标签已经用来拟合后处理，评价不再独立。可把它作为探索，提出开发集校准或新数据确认计划；若确要把这批数据用于更新，就应改变数据角色并另设评价。后处理也是预测函数的一部分，不应因为只加一个常数就免于训练边界要求。

<a id="project-4-detail-73"></a>

### 14.19 题十九：系数大是否表示最重要

**题目。** 一个温度特征以摄氏度计，另一个负载特征范围很小。能直接比较原始系数绝对值来排序依赖吗？

**解析。** 原始系数受单位影响，数值大小不可直接比较。标准化系数更接近特定尺度扰动，但仍受相关列、惩罚与编码影响。固定模型扰动和删特征重训又回答不同问题。解释前先明确目标，再报告单位、参照和假设；任何一种排行都不能单独证明因果作用。

<a id="project-4-detail-74"></a>

### 14.20 题二十：为什么完整训练代码仍非完整交付

**题目。** 训练脚本能打印测试指标，但没有保存字段模式、最终流程和选择记录。另一人重跑得到近似分数，是否已经足够重建系统？

**解析。** 还缺固定预测函数的身份、预处理、输入语义、后处理与可核对样例。相似汇总分数不能证明每条预测相同，也不能解释不同来源支持。应同时验收数据角色、产物推理、指标复算和适用范围。下一章把这些对象组织成能够加载、拒绝非法输入并独立复查的交付包。

<a id="project-4-detail-75"></a>

## 15. 综合研究：从一个结果进入下一轮证据

<a id="project-4-detail-76"></a>

### 15.1 五阶段项目验收

第一阶段只检查数据与指标：唯一键、设备分组、可见时间、目标单位和基线手算。第二阶段冻结外部设备与开发协议，完成内层搜索和嵌套诊断。第三阶段训练最终流程并产生一次测试预测，保留原始逐行误差。第四阶段按预设群体复算指标，对探索发现标注角色。第五阶段保存产物与运行记录，由独立入口核对预测。

每阶段都应有失败条件。设备交叉、未来字段、负评分方向错误、标签错位和输出模式不符，都应阻止报告生成，而不是在最后附一句笼统提醒。把检查放在相应边界，能够让错误更早变成具体可定位的信号。

<a id="project-4-detail-77"></a>

### 15.2 比较三种有明确动机的扩展

可以比较线性均值、包含负载非线性项的模型、以及针对主要绝对损失的模型。预先写出各自想修复的失败机制，并在同一开发协议和资源预算下选择。评价除总体误差外，保留负载、站点与新设备支持，检查改进是否只来自少数困难点。

若改变数据生成器，可分别调整设备共享效应、缺失机制与异方差强度。一次只改变一个因素，观察随机拆行与设备拆分、不同损失和校正的差别。合成世界允许知道机制，但研究报告仍应区分“在已知机制下验证方法行为”与“在真实数据中识别机制”，不能将前者直接当作后者。

<a id="project-4-detail-78"></a>

### 15.3 报告的最小可复核结果

报告至少给主要目标、独立单位、候选范围、选择规则、最终数据角色、基线与模型、支持和不确定性，以及与结果对应的产物身份。数值表应能从同一保存预测复算，代码应能在小输入上运行，解释应能指出哪些现象仍有多个竞争原因。

如果本轮只完成点预测，就写清没有验证个体区间；如果只是同站点新设备，就不宣称新站点已覆盖；如果未测服务性能，就不写实时承诺。这样的范围说明来自真实实验对象，使读者能判断下一步需要补什么，而非靠模型复杂度猜测可靠性。
