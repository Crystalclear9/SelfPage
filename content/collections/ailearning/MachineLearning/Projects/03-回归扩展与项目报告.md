## 1. 连续目标意味着重新定义问题

把分类器换成回归器，只完成了接口变化，尚未完成任务迁移。类别错误通常可按离散决策计数，连续目标则必须说明单位、偏差方向、大误差代价、允许输出范围与观测机制。设备维护工时为十与二十的差十小时，和预测成本为十与二十元，不是同一个业务量级；把小时转换为分钟会改变绝对误差数值，却不应改变关于相对方案的实质结论。报告需要从目标单位开始，而不是从评分函数名字开始。

本章为第四章的人工设备回归项目做设计准备。每台设备具有重复巡检，目标是维护所需工时，最终希望推广到未见设备。第四章负责运行含数值缺失、类别输入、折内处理、分组搜索和外部留出的完整实验。本章集中解释损失最优点、目标变换、残差机制、配对不确定性、分组探索和报告证据，避免把同一段训练代码再抄一遍。

回归目标也可能具有延迟、删失或截断。例如未完成工单的工时尚未最终确定，系统只记录超过某个金额的维修，设备提前退役导致后续维护不可见。普通最小二乘不会自动修复这些观测机制。若只把当前可见数字放进一列，模型学习的是经过选择后的标签分布，而非必然等于希望预测的完整结果。第一章的成熟与可见时间协议在回归中同样需要执行。

<a id="project-3-detail-2"></a>
### 1.1 输入、预测对象与行动单位继续保持一致

本章定义残差为 $e=y-\hat y$，因此正残差表示低估，负残差表示高估。这个约定贯穿公式、分组表和报告。若另一本资料定义相反方向，数学并不矛盾，但复制其图例时必须转换符号。MAE 和 RMSE 不受符号反转影响，平均残差和方向性代价则会反转。只保存一个没有定义的 `error` 列，会使后续解释容易出错。

预测可以针对单次工单、设备每周总工时或整个现场的资源需求。单条记录预测准确不保证总量预测好，反过来总量误差小也可能由大量正负抵消得到。若行动是在现场层面安排人力，应评价相应聚合与约束；若行动是在设备层面排序，应保留设备级质量和支持。不能因为模型输出连续数，就忽略采样、预测和决策单位之间的关系。

## 2. 损失函数决定理想预测什么

平方损失的理想预测是条件均值，绝对损失的理想预测是条件中位数，分位数损失的理想预测是指定条件分位点。这里的“理想”是给定输入、允许任意可测预测函数并满足相应可积条件的总体结论；有限样本、受限模型族、正则化和优化都会使实际结果偏离。不能因为训练使用 MAE，就声称每个输入上的预测已经精确等于真实中位数。

<a id="project-3-detail-4"></a>
### 2.1 平方损失的条件均值推导

设 $m(x)=\mathbb E[Y\mid X=x]$，并假设条件二阶矩存在。对固定输入的任意预测 $a$，展开得到 $\mathbb E[(Y-a)^2\mid x]=\operatorname{Var}(Y\mid x)+(m(x)-a)^2$，交叉项为零。因此最小值在 $a=m(x)$ 取得。第一项代表在当前输入条件下仍存在的变动，增加模型容量并不保证消除它；补充合法信息有可能改变条件分布，但不能凭训练拟合就宣称噪声消失。

这个分解也说明均值对极端值敏感。一个概率很小但数值极大的目标，可以显著改变条件均值和平方风险。若极端值确实属于目标总体，它们不是自动应该删除的污染；若它们来自单位错误，则应按数据契约修复。选择损失要结合代价和标签生成机制，不能仅因为 RMSE 看起来大就认定数据不干净。

<a id="project-3-detail-5"></a>
### 2.2 绝对损失的中位数推导

对固定输入，考察 $L(a)=\mathbb E[|Y-a|\mid x]$。当分布连续且在 $a$ 无原子时，其导数为 $P(Y<a\mid x)-P(Y>a\mid x)=2F(a\mid x)-1$。导数在累计概率跨过二分之一时改变符号，所以中位数最优。离散或有原子时使用次梯度，满足两侧概率都不超过二分之一的点均可最优，中位数可能不唯一。

例如目标为零、零、九，均值为三，中位数为零。常数三的 MSE 为十八，常数零的 MSE 为二十七；但前者 MAE 为四，后者为三。一个模型在 MAE 上更好而 RMSE 上更差，不是数学冲突，而是对尾部误差的不同权衡。若主要验收是 MAE，无输入基线应至少包含训练中位数；若平方误差为主，则训练均值是自然参照。所有基线参数都必须只由训练标签得到。

<a id="project-3-detail-6"></a>
### 2.3 非对称代价与分位点

若低估与高估具有不同代价，可采用检查损失 $\rho_\tau(e)=\tau e$ 当 $e\ge0$，以及 $(\tau-1)e$ 当 $e<0$。对残差约定 $e=y-a$，当 $\tau$ 较高时低估受到更大权重，最优点为条件 $\tau$ 分位数。导数或次梯度条件对应 $F(a\mid x)$ 跨过 $\tau$。这给人力资源预留一个清晰解释：希望覆盖更大比例的需求，预测对象应从均值转向相应分位点。

分位数预测不是“让均值模型统一加一点安全量”。若条件方差随输入变化，所需安全量也会变化。多个独立训练的分位模型还可能交叉，需要检查低分位不高于高分位；交叉修正本身也是后处理，应明确规则。分位区间的名义覆盖也不自动等于每个设备子群体的条件覆盖，后续章节讨论的共形方法同样需要区分边际与条件目标。

<a id="project-3-detail-7"></a>
### 2.4 实验一：最优常数、尾部和单位

下面用三个小数组检验上述区别。候选常数网格包含经验均值和中位数，因此可以直接核对最优点；尾部例子展示相同 MAE 的模型拥有不同 RMSE；最后验证目标与预测一起乘六十时，绝对误差也乘六十。

```python
import numpy as np

values = np.array([0.0, 0.0, 9.0])
candidates = np.array([0.0, 1.0, 2.0, 3.0, 4.0, 9.0])
mse = np.mean((values[:, None] - candidates) ** 2, axis=0)
mae = np.mean(np.abs(values[:, None] - candidates), axis=0)
assert candidates[mse.argmin()] == 3.0
assert candidates[mae.argmin()] == 0.0
A, B = np.array([0., 0., 6.]), np.array([2., 2., 2.])
assert np.isclose(np.abs(A).mean(), np.abs(B).mean())
assert np.sqrt(np.mean(A ** 2)) > np.sqrt(np.mean(B ** 2))
y, prediction = np.array([1., 2., 4.]), np.array([2., 2., 2.])
original = np.abs(y - prediction).mean()
minutes = np.abs(60 * y - 60 * prediction).mean()
assert np.isclose(minutes, 60 * original)
print("best constants:", candidates[mse.argmin()], candidates[mae.argmin()])
print("MAE:", np.abs(A).mean(), "RMSE:", np.sqrt(np.mean(A ** 2)))
```

注意把目标乘六十而不调整模型正则或训练流程，实际重新训练的模型未必只把输出乘六十。不同估计器对目标缩放和正则化的响应不同。上面验证的是相同预测方案在单位变换下的指标关系，不是对所有学习算法的训练等变性证明。项目迁移单位时应重新检查训练目标、参数尺度和输出约束，不能只改报告的轴标签。

<a id="project-3-detail-8"></a>
## 3. 指标组合：数值背后是什么风险

MAE 报告平均绝对偏差，与目标同单位；RMSE 为平均平方误差开方，也与目标同单位，但对大误差更敏感。RMSE 总不小于 MAE，可由均方不小于平均绝对值平方得到，等号在所有绝对误差相等时成立。二者差距较大提示误差幅度不均匀，却不能单独定位异常点、异方差或标签错误。必须结合分布和来源分析。

<a id="project-3-detail-9"></a>
### 3.1 平均残差、偏移与误差幅度

平均残差为零可能来自预测准确，也可能来自正负大错完全抵消。误差各为正十和负十时，均值零而 MAE、RMSE 均为十。线性最小二乘在含截距、未受其他约束且满足正常求解条件时，训练残差和为零，是优化几何的性质；它不保证测试均值为零，也不证明模型没有系统性子群体偏差。报告不能把训练残差零均值当作独立质量证据。

总体偏移可以由各组方向相反而抵消。若设备甲平均低估五小时，设备乙平均高估五小时且权重相同，总体平均残差为零，两个设备都可能不适合排班。应同时报告方向、幅度和支持，必要时按部署权重汇总。对一个新模型，平均偏移改善而 MAE 变差也可能发生，说明减小系统方向不等于减小个体误差。

<a id="project-3-detail-10"></a>
### 3.2 R² 的参照、负值和退化目标

在通常定义中，$R^2=1-\sum_i(y_i-\hat y_i)^2/\sum_i(y_i-\bar y)^2$，其中 $\bar y$ 是当前评价标签的均值。负值表示平方误差比“事后用评价均值预测所有记录”的参照还大；这个评价均值用于定义指标，不应成为实际基线的训练参数。实际均值基线必须由训练标签拟合，两者的分数不必恰好为零。

当评价目标恒定时，分母为零，原数学定义退化。库可能为便利返回有限替代值，报告应说明这种行为，而不能把一个有限数字误认为正常可比的解释方差比例。测试样本极少或变动很小时，R² 也可能极不稳定。第四章会同时给原单位误差，避免只依赖一个无单位分数判断维护工时预测是否可用。

<a id="project-3-detail-11"></a>
### 3.3 百分比误差与零目标

百分比误差常被误用。若目标接近零，除以目标的绝对值会极度放大很小的绝对偏差；目标为零时需额外定义。scikit-learn 的 MAPE 返回比例形式，零点二表示约百分之二十，而不是零点二个百分点。用机器精度保护分母只解决数值除零，不解决统计解释。维护工时允许零时，不应为了得到一个“百分比”而机械采用 MAPE。

若任务关心总工作量的相对偏差，可以定义总绝对误差除以总真实量，但该指标对样本权重与目标组成敏感，也不等于平均逐样本百分比误差。若任务关心个体相对误差，需要明确低目标处理规则和可接受范围。指标定义应在看到哪种算法得分更好之前确定，不能把分母换来换去直到新方法领先。

## 4. 目标变换改变了条件最优点

当目标为正且长尾，常见做法是在对数空间训练，再指数反变换。它可以压缩大值、使误差更接近相对尺度，或改善某些线性关系；但它不是一个中性的数值小技巧。对数空间平方损失的理想预测是 $\mathbb E[\log Y\mid X]$，反变换得到条件几何中心，通常不等于原尺度条件均值。最终若按原单位 RMSE 验收，必须检查这种目标错配。

<a id="project-3-detail-13"></a>
### 4.1 Jensen 不等式与重变换偏差

由于指数函数凸，$\exp(\mathbb E[Z\mid X])\le\mathbb E[\exp Z\mid X]$。令 $Z=\log Y$，可见简单反变换一般偏离原尺度均值。如果 $Z=m(X)+\varepsilon$，且条件误差为均值零、方差 $\sigma^2(X)$ 的正态分布，则原尺度条件均值为 $\exp(m(X)+\sigma^2(X)/2)$。若方差随输入变化，一个全局修正因子无法同时修复所有输入区域。

这里讨论的“偏离均值”不等于所有目标下都错误。若原尺度任务希望预测条件中位数，并且条件对数误差中位数为零，$\exp(m(X))$ 可以具有合适解释。关键是先问希望估计均值、中位数还是某个分位点，再选择损失和反变换，而不是因为目标看起来偏斜就自动使用对数，然后把输出统称为平均需求。

<a id="project-3-detail-14"></a>
### 4.2 平移对数、可逆性和训练边界

当目标可为零时常用 `log1p` 和 `expm1`，但其合法域仍要求目标大于负一。若目标本身可以为较大负值，例如净收益或温度偏差，这个变换不适用。人为加一个由全数据最小值决定的常数，会把测试信息带入目标规则；固定物理意义的平移与数据估计平移需要区分。反变换后出现不合理负预测时，也不能无声截断再当作同一模型。

`TransformedTargetRegressor` 可把目标变换与回归器组合，但不会自动把反变换预测修正成原尺度条件均值，也不会自动满足业务约束。若变换参数需要拟合，应在每个训练折内学习。交叉验证的评分应清楚说明是在原尺度预测上计算，还是在变换空间计算。前者比较的是原尺度方案表现，后者优化的是另一个损失，不能把分数单位混写。

<a id="project-3-detail-15"></a>
### 4.3 实验二：同一对数中心对应不同原尺度均值

下面构造一个完全可手算的误差分布：对数误差以相同概率取正负二分之一。对数中心为零，简单指数为一；原尺度均值为双曲余弦值，大于一。再给两个输入组设置不同误差幅度，验证一个统一修正因子无法同时匹配两组均值。实验使用精确离散分布，不依赖蒙特卡洛近似。

```python
import numpy as np

z = np.array([-0.5, 0.5])
y = np.exp(z)
naive = np.exp(z.mean())
true_mean = y.mean()
assert np.isclose(naive, 1.0)
assert true_mean > naive
amplitudes = np.array([0.2, 1.0])
conditional_means = np.cosh(amplitudes)
pooled_factor = conditional_means.mean()
assert not np.allclose(conditional_means, pooled_factor)
assert conditional_means[0] < pooled_factor < conditional_means[1]
assert np.isclose(np.mean((y - true_mean) ** 2)
                  + (true_mean - naive) ** 2,
                  np.mean((y - naive) ** 2))
print("naive:", naive, "mean:", true_mean)
print("group means:", conditional_means, "pooled correction:", pooled_factor)
```

实际重变换修正需要估计误差分布，这又引入训练边界与不确定性。若用最终测试真实标签估计修正因子，测试已经参与模型。使用训练残差可能受到拟合乐观性，折外残差可以提供另一种估计但仍需设计。不能把一个理论上存在的修正项当作从数据中无误差获得的常数，更不能在报告中隐去它的拟合来源。

## 5. 残差分析从三个不同条件出发

残差对输入、预测值和真实目标的图或分组表，回答三个不同问题。按输入分组研究可部署对象中的误差结构；按预测值分组研究输出水平与失配；按真实目标分组研究事后哪些结果难以预测。第三种尤其容易误解：模型在高真实值组低估，不自动证明预测函数有一个可通过整体抬高输出消除的系统偏差，因为分组本身使用了目标噪声。

假设模型已经输出真实条件均值，$Y=m(X)+\varepsilon$ 且 $\mathbb E[\varepsilon\mid X]=0$。按很高的实际 $Y$ 筛选，会倾向选入正噪声记录，于是平均残差可能为正，即使模型在每个输入上都无条件均值偏差。这是选择条件改变的结果。目标区间分析仍有描述价值，但不能直接据此构造上线规则，因为预测时未知真实目标。应结合按输入或预测分组的独立分析，形成可部署假设。

<a id="deep-dive-2"></a>
<a id="project-3-detail-17"></a>
### 5.1 异方差不是“模型一定错了”

若不同输入区域的条件方差不同，称为异方差。一个准确估计条件均值的模型仍可拥有随输入扩大的残差幅度；均值预测与方差预测是两个目标。反过来，残差漏掉的非线性均值结构也会制造看似漏斗形的图。应先检查方向性趋势，再研究幅度和尾部，不能只凭一个形状就决定加权最小二乘。

加权平方损失若权重仅为输入的正函数，在无限灵活函数空间中仍以条件均值为逐点最优；但在受限模型族中，权重改变不同输入区域的折中，从而改变拟合函数。若权重依赖目标值，例如按真实工时倒数加权，则条件最优点一般也改变。异方差稳健标准误关注参数推断，异方差加权训练关注拟合效率或目标权重，二者不能混为一谈。项目报告应明确采用权重的目的和估计来源。

<a id="project-3-detail-18"></a>
### 5.2 尾部误差与稳健损失

Huber 损失在小残差区近似平方、大残差区近似绝对，可减少极端残差对拟合的影响。但它并不自动分辨真实困难样本与错误标签，阈值和尺度仍会改变目标折中。若大工时案例正是排班最关心的部分，过度稳健可能使其被系统性低估。应同时报告普通样本与尾部质量，并用开发数据选择损失，不要把“对异常鲁棒”当成无条件优点。

尾部统计可以给误差分位数、超过业务容忍幅度的比例、最差若干设备的损失，以及最大错误的原始记录。极值对样本量高度敏感，两个测试集的最大误差不能在支持数不同的情况下简单排名。分位数也有估计波动，尤其最末百分之一只对应很少样本时。报告原始数量和分母，通常比一条平滑曲线更有解释力。

<a id="project-3-detail-19"></a>
### 5.3 实验三：零均值、异方差与目标分组偏差

以下人工构造没有模型拟合误差：预测函数固定为条件中心，噪声在每个输入位置对称。总体残差为零，但两个输入组的 MAE 不同；按很高真实目标筛选，又会观察到正残差。这说明三个现象可以同时成立，不能互相替代。

```python
import numpy as np

x = np.repeat([0., 1.], 4)
prediction = np.repeat([10., 20.], 4)
error = np.array([-1., 1., -1., 1., -4., 4., -4., 4.])
y = prediction + error
assert np.isclose(error.mean(), 0)
assert np.isclose(np.mean(error[x == 0]), 0)
assert np.isclose(np.mean(error[x == 1]), 0)
mae_low = np.abs(error[x == 0]).mean()
mae_high = np.abs(error[x == 1]).mean()
assert mae_low == 1 and mae_high == 4
high_target = y > 22
assert error[high_target].mean() == 4
opposite_bias = np.array([5., 5., -5., -5.])
assert opposite_bias.mean() == 0
assert np.abs(opposite_bias).mean() == 5
print("group MAE:", mae_low, mae_high,
      "high-target residual:", error[high_target].mean())
```

如果把高目标组的正残差解释为所有预测都要增加四小时，输入较低或负噪声记录就会被过度预测。这个反例不证明真实模型从来不存在低估，它只推翻从“高目标组残差为正”直接推到“可统一修正”的逻辑。真实分析还需要合法输入分组、开发对照和独立评价；研究深度来自能区分解释，而不是给现象贴一个熟悉名称。

## 6. 从残差模式形成一轮有针对性的开发实验

一个有用的改进假设应包含观察、机制、改动、预期与失败条件。例如在开发折外预测中发现缺失多的设备误差高，猜测缺失状态反映传感器工作方式，计划加入当时可见的缺失指示，并要求目标组 MAE 降低且总体没有超过预定退化幅度。还需检查来源、设备类型和缺失之间的关联，防止把来源变化误说成缺失因果效应。

若发现某个连续输入与残差呈弯曲关系，可比较线性模型与预定非线性基函数。若同时更换损失和加入许多特征，就无法局部归因。若按设备外部留出，每个方案都应重新在内层选择参数，并共享外层验证设备。研究对象是完整学习流程时，消融后不重新调参可能不公平；研究固定系统局部敏感性时，不调参又恰好是目标。报告必须说清在回答哪一个问题。

<a id="project-3-detail-21"></a>
### 6.1 训练残差、折外残差与最终测试残差

训练残差最容易偏乐观，可以用于查优化和表示，但不适合独自证明泛化误差结构。折外残差由每个样本未参与拟合的模型产生，更适合开发诊断；若超参数先用全开发数据选定再生成普通折外预测，样本仍参与了参数选择，不能把它称为完全嵌套独立证据。第四章采用外层开发折中重新内层选择的方式，保留完整边界。

最终测试残差可以描述冻结方案的局限，不能被无限用于选择新特征。一个常见问题是报告每次更新都称“仅做错误分析”，但所有更新都根据测试残差决定。信息影响选择的事实不会因名称改变而消失。持续项目可以将原测试改作回归集，记录其开发角色，再安排新来源或未来批次进行确认。这使研究能够继续，又不混淆证据。

<a id="project-3-detail-22"></a>
### 6.2 不要把相关预测解释写成因果原因

某个输入与残差相关，可能是遗漏变量、测量误差、来源混杂或模型表达限制。把输入增加一点再观察预测变化，说明模型函数如何响应，不说明真实世界干预会带来相同工时变化。维护工时还可能受排班和维修策略影响，历史标签反映的是当时的决策过程。若模型用于改变策略，目标分布可能随行动变化，离线预测评价不足以回答收益问题。

可以在报告中分三级措辞：直接观察到的事实，受对照支持的预测机制，以及尚待验证的因果猜测。例如“缺失组 MAE 更高”是事实；“加入合法缺失指示在相同折上改善该组”支持一个预测方案；“修好传感器必然减少维护工时”则需要不同证据。把证据层级写清楚，比使用更强烈的语言更有研究价值。

<a id="sec-6"></a>
<a id="project-3-detail-23"></a>
## 7. 配对比较：先比较同一对象上的损失

比较两个冻结方案时，尽量让它们在同一评价对象上预测。对每条记录定义 $d_i=\ell(y_i,\hat y_i^A)-\ell(y_i,\hat y_i^B)$，正值代表方案 B 损失较小。估计平均差时应直接分析 $d_i$，而不是分别给两个独立误差条后凭是否重叠判断差异。配对利用了同一对象难度带来的相关性，通常更贴近“对当前目标对象，哪种方案更好”的问题。

<a id="project-3-detail-24"></a>
### 7.1 配对差方差的推导

设两方案的单对象损失为 $L_A,L_B$，则差值方差为 $\operatorname{Var}(L_A)+\operatorname{Var}(L_B)-2\operatorname{Cov}(L_A,L_B)$。同一困难对象往往对两者都难，因此协方差可能为正，配对能减少差异估计的噪声。若在不同样本上评价，协方差结构不可直接利用，而且样本组成差异可能混入结果。保持相同测试集合是研究设计的一部分，而非报告阶段才做的格式统一。

设备内重复记录相关时，不能把所有 $d_i$ 当独立。若目标为等权设备风险，应先在每台设备内平均得到 $D_g$，再对设备平均；若目标为记录加权风险，组重采样后还需按每次抽中的记录总数重新汇总。两种方案对应不同参数，不能把组均值平均和行总和平均随意互换。第三章讨论原理，第四章会明确固定其评价权重。

<a id="project-3-detail-25"></a>
### 7.2 组级 bootstrap 的对象与限制

组级自助法每次有放回抽取设备，并带上设备内全部记录，或者对预先计算的等权设备损失差抽样。它模拟的是设备作为基本抽样单位的经验分布。设备数很少时，重采样结果也可能不可靠；大量重复同一批十台设备不会创造新来源。百分位区间是方法选择，有相应近似条件，不能保证任意重尾、退化或依赖数据都拥有标称覆盖。

若不重新训练模型，这类区间条件于已经冻结的模型，只反映评价对象变化，不包含训练集变化与选择流程不稳定性。若希望评价整个学习算法，需要在外层重采样或重复实验中重新执行训练和选择，成本更高、设计也更复杂。报告应明确区间层级，不要把一个便宜的固定预测 bootstrap 描述成模型对所有未来运行都稳定的证明。

<a id="project-3-detail-26"></a>
### 7.3 实验四：配对设备差与可重现的自助区间

下面人工构造八台设备、每台三条记录，两方案在同一记录上评价。先计算绝对损失差，再按设备平均，最后重采样设备均值。断言检查配对差与两方案平均 MAE 的差一致，并验证不同层级汇总在等组大小时相等。区间只描述这两个固定预测器的设备抽样变动，不重训任何模型。

```python
import numpy as np

groups = np.repeat(np.arange(8), 3)
y = np.linspace(10, 30, len(groups))
eA = np.tile([1., -2., 3.], 8) + np.repeat(np.linspace(-.3, .3, 8), 3)
eB = 0.7 * eA + np.tile([.1, -.1, 0.], 8)
pA, pB = y - eA, y - eB
d = np.abs(y - pA) - np.abs(y - pB)
D = np.array([d[groups == g].mean() for g in np.unique(groups)])
assert np.isclose(D.mean(), np.abs(y - pA).mean() - np.abs(y - pB).mean())
assert np.all(D > 0)
rng = np.random.default_rng(91)
replicates = D[rng.integers(0, len(D), size=(4000, len(D)))].mean(axis=1)
low, high = np.quantile(replicates, [0.025, 0.975])
assert low <= D.mean() <= high
assert low > 0
print("MAE improvement B:", D.mean(), "percentile interval:", (low, high))
```

这个数据特意让所有设备上 B 都有改善，因此区间为正并不令人意外。它验证实现和含义，而不展示一种普遍有效的优越性检验。真实项目若区间跨零，应说当前证据未清楚区分；若区间虽为正但小于最小有意义差异，仍可能不值得替换；若某关键设备组退化，平均改善也未必满足验收。统计量必须回到任务约束。

<a id="project-3-detail-27"></a>
### 7.4 RMSE 的配对比较不能平均逐条“RMSE 差”

单条记录的平方误差是可加项，RMSE 是整体均方误差开方。比较 RMSE 时，应在每次重采样对象上分别重算两个整体 RMSE，再取差。逐条对平方误差开方后平均，得到的是 MAE，而非 RMSE。对组均方根再等权平均，也通常不同于先对组内平方误差合并后开方。报告的估计量与代码必须完全一致。

如果目标是平均设备 RMSE，那么先算每台设备 RMSE 再平均可以是合法定义，但应明确命名；如果目标是随机记录的总体 RMSE，就按记录权重合并平方误差。指标本身的非线性意味着汇总顺序会改变参数。多输出、多个时间跨度和多个现场同样如此，不能用一个没有定义的“平均 RMSE”跨层聚合。

<a id="project-3-detail-28"></a>
### 7.5 训练随机性、数据随机性与未来漂移

项目常用同一个“误差条”指代三种不同现象。第一种是固定训练数据、固定测试对象，改变随机初始化或采样种子；第二种是来自同一目标总体的训练或测试样本重新抽取；第三种是未来总体本身改变，例如新设备型号、季节或维护策略变化。前两种可以在明确随机机制下设计重复实验，第三种涉及外推与分布假设，不能从当前经验重采样中无条件得到保证。

如果只重复训练随机森林，测试设备不变，得到的波动不包含“下一批设备恰好更难”的不确定性。如果只对测试设备重采样，模型不变，又不包含训练方案选择的波动。两者可以分别报告，也可以设计更外层的重复生成或重抽训练设备，但必须实际重新完成内层搜索。将这些步骤省去，却把区间命名为整个学习流程的可靠性，会夸大证据范围。

未来漂移还需要描述改变什么。仅目标先验变化、输入分布变化和目标机制变化会影响不同指标；一个在当前测试上很窄的区间并不覆盖任意机制改变。可以用压力测试探索合理扰动，如缺失率增加或新类型输入，但压力测试结果仍局限于所设扰动。报告应分别标记实测总体、受控模拟和未知未来，避免一个“鲁棒”形容词把三者合并。

<a id="project-3-detail-29"></a>
### 7.6 点预测区间与参数置信区间

预测一个新工单工时的区间，需要包含目标在给定输入下的固有变动；回归系数或条件均值的置信区间，则反映参数或均值估计不确定性。即使条件均值估计得很精确，单次工时仍可能波动很大。用一条很窄的均值置信带替代个体预测区间，会低估排班风险。图表应写明区间对象和条件，而不是仅在图例中写“九成区间”。

分位回归可以分别估计低高分位，共形方法可以在相应假设和划分下构造边际覆盖程序，概率模型也可给条件分布。每种方法都需要单独评价覆盖率与宽度，特别是异方差、组结构和时间变化下的表现。宽到包含所有可能结果的区间覆盖很高，却几乎没有行动价值；窄而频繁漏掉大工时的区间也不可用。因此区间评价不是只追求一个接近名义比例的数字。

设备内相关对区间构造同样重要。若校准分数来自同设备密集记录，而部署对象是新设备，普通逐行交换性假设未必合适。应研究以设备为单位的校准或明确其适用限制，不能因为有一个独立数据区域就忽略内部依赖。对未来时间序列，分布变化更使简单随机交换假设需要审查。当前章节只说明设计边界，进一步方法要回到不确定性主题系统学习。

<a id="project-3-detail-30"></a>
### 7.7 最小有意义差异与非劣问题

当旧方案已经稳定运行，研究问题可能不是“新方案误差是否严格更小”，而是“在质量损失不超过可接受幅度时，能否显著降低成本”。这属于带容忍界限的比较，应预先定义单位明确的退化幅度，并报告相应差异区间。普通优越性检验未能发现差异，不等于已经证明非劣；样本量不足时，两种方向都可能没有足够证据。

同样，若希望证明两模型在某个误差范围内等效，需要围绕该范围设计判断，而不是看到均值接近就写成相同。实际项目可以将质量与成本组成一个明确的决策表：质量改善且成本可接受、质量相当且成本明显降低、质量退化越界，各自如何处理。预先表述这些规则，使最后选择不依赖作者对某个模型名称的偏好，也避免为了保留高成本模型而事后缩小或放大容忍幅度。容忍幅度可以来自排班能吸收的工时差、人工复核负担或历史系统的可接受误差，但不应由当前测试标准差反向决定。若有多个关键设备类型，还需要说明总体非劣是否足够，还是每个预定类型都有边界；后者对样本量要求通常更高。研究者可以明确报告证据不足并保持旧系统，而不是把任何未拒绝结论包装成替换理由。保留旧方案的决定同样应记录当时的数据、成本与阈值，使后续新增设备后能够重新评价同一问题，而无需重新发明成功标准。若后续成本结构或用途改变，应给决策协议新版本，解释变化来自业务需求还是统计证据。这样同一模型在不同任务下被接受或拒绝，都有明确可核查的理由。

<a id="project-3-detail-31"></a>
## 8. 多重探索：为什么最差子群体也可能被选择噪声放大

残差表能按设备类型、时间、缺失、目标区间、预测区间以及多种交叉条件切分。尝试的切分越多，越容易找到一个看起来特别差的组，即使所有组真实风险一样。这不是禁止探索，而是要求把发现与确认分开。记录尝试过哪些分组、每组支持和规则来源，后续在独立数据上验证机制。只保留最显著的一张图，会隐藏选择过程。

<a id="project-3-detail-32"></a>
### 8.1 预定子群体与探索子群体

预定子群体来自任务需求或已知机制，例如新型号、特定采集方式、长期缺失设备。它们应在建模前列出，用于主要质量约束或固定辅助报告。探索子群体来自查看数据后的发现，可以更灵活，但结论应标记为生成假设。二者都需要支持数和不确定性；预先指定不使小样本变稳定，探索发现也不意味着必然虚假，差别在证据强度与确认需求。

连续变量分箱尤其需要注意边界。若分箱由全数据目标分位数决定，会使用测试标签并改变解释；若按训练输入分位数定义后冻结，可用于比较不同批次。某个新批次没有落入某箱，不能把该箱误差记零；应表示没有支持。若在每个测试批次重新分箱，同一个“高值组”可能对应不同物理范围，时间变化解释也随之改变。

<a id="project-3-detail-33"></a>
### 8.2 多重比较修正与实际重要性

若将多个子群体差异当作正式检验，需要考虑家族错误率或错误发现率等目标。Bonferroni 之类方法在某些条件下简单但保守，不能自动解决分组规则由同一数据自适应发现的问题；先看数据设计组，再只对最终十组做修正，遗漏了前面的搜索。独立发现与确认样本、预先规则或专门的选择后推断方法才对应这种过程。

显著性修正也不替代效应大小和任务代价。一个很大数据集上的微小 MAE 差异可能统计上容易检测，却没有应用意义；一个高代价小群体的风险增加可能重要，却因样本少无法精确估计。报告应同时给差异单位、支持、区间和已尝试范围，避免把单个阈值的通过与否当成全部判断。

<a id="project-3-detail-34"></a>
### 8.3 实验五：同一无差异世界中的极端探索

下面不拟合模型，只模拟八十个真实均值都为零的组。每组的估计有噪声，取绝对值最大的组会得到一个看似突出的差异。随后为同一组生成独立确认观测，验证探索最大值并不自动复现。断言只核对预定种子下的实现，不把一次模拟当成所有多重比较的定量证明。

```python
import numpy as np

rng = np.random.default_rng(2026)
discovery = rng.normal(0, 1, size=(80, 20)).mean(axis=1)
selected = int(np.abs(discovery).argmax())
confirmation = rng.normal(0, 1, size=(80, 200)).mean(axis=1)
assert np.abs(discovery[selected]) == np.max(np.abs(discovery))
assert abs(confirmation[selected]) < abs(discovery[selected])
assert np.isclose(np.mean(np.zeros(80)), 0)
print("selected group:", selected, "discovery:", discovery[selected],
      "confirmation:", confirmation[selected])
```

真实残差分组还存在组相关、组大小不等和规则搜索，通常比这个独立正态示例复杂。它的核心启示是：探索中的最大偏差同时包含真实效应与被选择的噪声，不能直接拿来估计未来改善空间。可在独立确认数据中重新评价同一规则，并将未复现结果同样记录；否则项目会不断追逐当前最差组，却无法积累稳定认识。

## 9. 报告结构：让每个结论都能找到对应证据

一份回归报告可以按问题、数据协议、候选选择、主要结果、误差结构、成本与限制组织。开头用几句话交代预测对象、目标单位、泛化对象和行动，不必先列算法史。方法部分说明分组与时间、标签成熟、前处理拟合边界、候选预算和选择规则。结果部分先给同对象基线与冻结方案，再给预定子群体和探索发现。最后解释哪些结论已被直接支持，哪些只是下一步假设。

<a id="project-3-detail-36"></a>
### 9.1 结果表的一行应该包含什么

一行结果至少绑定方案身份、评价对象数与独立组数、目标单位、主要误差、辅助误差、方向性偏移和计算条件。若给区间，应注明重采样单位、模型是否重新训练、区间方法与随机种子。不同划分的最好点不能拼成一行；训练集内结果和最终测试结果也不能放在同一排名列中却不标角色。表格简洁不等于省略关键定义。

若主指标 MAE，建议同时报告 RMSE 或误差尾部分位，以展示大错；若主指标 RMSE，建议给 MAE，避免读者无法知道普通样本的平均偏差。R² 可以辅助，但不要让无单位分数掩盖工时误差是否可接受。基线的训练均值或中位数、模型是否截断输出、目标是否变换，都应进入方案说明。每个数字应能从冻结预测表重算，而不是人工从不同日志复制。

<a id="sec-6-1"></a>
<a id="project-3-detail-37"></a>
### 9.2 从指标写到有范围的结论

较好的写法是：“在固定的未见设备测试中，方案 B 的平均绝对误差相对训练中位数基线减少若干小时；差异在当前设备抽样下如何变化；某类设备仍有较大尾部误差，因此当前证据支持什么范围的使用。”需要填写实际实验输出，不能提前猜测高分。若没有运行某项扩展，写成下一步计划，不应在结论中用将来时暗示它已经有效。

不充分的写法是“模型效果很好、泛化能力强、可用于实际维护”。它没有说明对象、指标、成本和证据边界。另一个问题是把“线性系数为正”写成“这个输入增加会导致维护更久”，忽略相关与因果差别。报告的准确程度体现在限定的名词与可核查数字上，而不体现在夸张形容词的数量。

<a id="sec-5"></a>
<a id="project-3-detail-38"></a>
### 9.3 成本、依赖与数据使用约束

训练耗时包括哪些步骤，搜索是否重复，预测耗时是否包括填补和编码，批量与硬件是什么，都应清楚。小人工数据上的毫秒级差异容易被启动、线程调度和缓存噪声主导，不适合给出过强性能排名。可以用固定批量重复测量并报告分布，仍应承认它只描述当前环境。若未来要服务请求，还需另外研究并发、冷启动和输入校验成本。

数据为人工生成时，应明确生成机制和种子，其优势是可以复算与受控对照，限制是不代表真实传感器、维护策略和标签延迟。数据为内置库时，应说明样本范围、来源含义和任务假设。无法公开真实数据时，应描述可复现层级，不要用一个相同形状的随机数组声称重现了真实结论。第五章会把配置、输入模式和固定样例组织成可独立验收的交付物。

<a id="project-3-detail-39"></a>
### 9.4 一个可直接填写的研究摘要

摘要可分成五句。第一句明确目标与总体：“预测未见设备一次维护的工时”。第二句说明协议：“设备级外部留出，开发阶段按设备嵌套验证，全部预处理折内拟合”。第三句给基线和最终结果：“在多少台设备、多少条记录上，相比哪个合法基线，主要误差改变多少”。第四句说明主要限制：“哪些设备或尾部仍困难，区间反映哪一种波动”。第五句提出下一步：“计划在哪个新批次检验哪条机制假设”。

这五句并不取代完整报告，但能检验是否真正知道自己的实验回答了什么。如果无法填写第二句，通常意味着信息边界尚不明确；无法填写第三句，可能是结果没有统一单位和样本；无法填写第四句，往往是只看均值；无法填写第五句，可能错误分析还停留在罗列现象。精简写作可以很有深度，前提是每句话背后都有完整证据。

## 10. 十六道练习与逐题解析

<a id="project-3-detail-41"></a>
### 10.1 为什么训练 MAE 的模型不一定最小化测试 RMSE

**问题：** 两个指标都衡量误差，是否应该选出同一个模型？

**解析：** 两者对残差的加权不同，理想条件最优点分别关联中位数和均值。尾部数据会更强影响平方误差，有限模型的折中也不同。例子中误差为零、零、六与二、二、二的两模型 MAE 相同，RMSE 不同。应根据任务代价预定主要指标，辅助指标展示取舍，而非在结果后切换目标宣称候选全面更优。

<a id="project-3-detail-42"></a>
### 10.2 用测试均值做常数基线为何不合法

**问题：** R² 分母使用测试均值，为何实际基线不能也这样训练？

**解析：** R² 的测试均值是指标定义中的参照，不是可部署预测器拥有的信息。实际无输入预测应从训练标签估计，面对新对象不能提前知道其真实均值。两者用途不同。若训练均值基线在测试上的 R² 不为零，完全正常；它反映训练与测试分布及有限样本变化，不说明指标实现错误。

<a id="project-3-detail-43"></a>
### 10.3 平均残差零能否证明无偏且准确

**问题：** 两个设备分别低估五小时和高估五小时，总平均零，结论是什么？

**解析：** 只能说明在当前权重下方向抵消，不能证明个体准确，也不能证明每个组无偏。需要报告 MAE、RMSE、组均值与支持。若训练含截距最小二乘残差和为零，还可能只是优化条件导致，不能当作独立泛化证据。评价时应使用未参与拟合或选择的预测，并明确残差符号。

<a id="project-3-detail-44"></a>
### 10.4 对数预测反变换为何不是原尺度均值

**问题：** 模型准确估计了条件平均对数，指数后是否就是平均工时？

**解析：** 一般不是，因为非线性变换不与期望交换。Jensen 不等式给出指数平均对数不超过原尺度均值；差距依赖条件误差分布。若对数误差正态，还需方差修正才能得到均值。若目标是中位数，简单反变换可能具有合适解释，但必须满足相应条件。先决定预测对象，再选择损失和变换。

<a id="project-3-detail-45"></a>
### 10.5 全局重变换因子能否修复所有输入区

**问题：** 两组对数误差方差不同，可以统一乘一个修正因子吗？

**解析：** 通常不能同时匹配两组条件均值。实验二的不同幅度对应不同指数误差期望，汇总修正因子只在总体混合权重下折中。若部署组比例变化，这个总体修正还会改变。可以研究条件修正，但需要额外模型、合法训练数据和独立评价，不能用测试组真实均值逐组校正后宣称预测成功。

<a id="project-3-detail-46"></a>
### 10.6 高目标组被低估是否必然说明模型偏低

**问题：** 按真实标签最高十分之一分组，平均残差为正，应怎样解释？

**解析：** 它描述该组确实被低估，但不必然表示条件均值函数估计错误。按高真实目标选择会倾向选到正噪声，即使预测已是条件均值也会出现这种现象。应结合按输入和预测分组分析，区分可部署规律与事后选择。不能使用未知真实标签选择上线修正规则。

<a id="project-3-detail-47"></a>
### 10.7 异方差是否必须改变均值模型

**问题：** 输入较高时残差幅度大，是否应该立即加权回归？

**解析：** 不必。异方差可能是目标条件变动本身，均值模型仍正确；也可能遗漏了均值非线性。先检查残差方向，再研究尺度。输入依赖权重在受限模型族中改变区域折中，未必符合实际任务风险。若希望预测区间，应单独建模分位或尺度，而不是指望均值训练自动给出可靠不确定性。

<a id="project-3-detail-48"></a>
### 10.8 两模型分别给区间能否直接判断差异

**问题：** A 与 B 的 MAE 区间重叠，能否说没有差异？

**解析：** 不能直接这样判断。两者在同一对象上的损失通常相关，应分析配对差。差值方差包含协方差项，分别区间的重叠与差值区间不是等价判断。还需尊重设备相关结构和目标权重。即使差值区间跨零，也只是当前证据未清楚区分，不证明两者在有意义幅度内等价。

<a id="project-3-detail-49"></a>
### 10.9 为什么设备 bootstrap 不能简单重抽所有行

**问题：** 同设备记录相关，逐行重采样是否能增加精度？

**解析：** 逐行重抽会把相关记录近似当独立，可能低估抽样波动。若设备是独立来源，应以设备为重采样单位，并明确组内聚合与权重。独立设备很少时，组 bootstrap 也有局限，增加重复次数不会创造新信息。应报告设备数、组大小与区间条件，而非只给一个很窄的数字。

<a id="project-3-detail-50"></a>
### 10.10 固定预测 bootstrap 包含训练不稳定性吗

**问题：** 对最终预测表重采样四千次，是否说明重新训练也同样稳定？

**解析：** 不说明。模型没有重训，区间条件于当前冻结预测器，只反映评价对象经验分布的变化。训练样本、初始化、超参数选择等波动需要在更外层重新执行流程。可以分层报告不同来源的不确定性，但不能将一个层级的区间命名为所有未来运行的保证。

<a id="project-3-detail-51"></a>
### 10.11 RMSE 为什么不能逐行开方再平均

**问题：** 先对每条平方误差开方再取均值，是否得到 RMSE？

**解析：** 得到的是绝对误差平均，即 MAE。RMSE 必须先平均平方误差，再整体开方，非线性运算顺序不能交换。比较两个 RMSE 的重采样差时，应每次分别重算整体指标。若先算每台设备 RMSE 再平均，则定义了平均设备 RMSE，可能合法但应明确命名，不能与总体记录 RMSE 混用。

<a id="project-3-detail-52"></a>
### 10.12 找到最差子群体后立即定制规则有什么问题

**问题：** 试了一百种分组，找到误差最高的一组，然后专门加规则，是否有依据？

**解析：** 它可以产生探索假设，但最差组同时包含被选择的噪声，直接估计改善空间会偏乐观。需要记录尝试范围，在开发对照中测试规则，并用独立数据确认同一组机制。若规则使用真实目标定义组，预测时还不可执行。多重探索不是禁止分析，而是要求发现与确认区分。

<a id="project-3-detail-53"></a>
### 10.13 MAPE 为零点二该怎样写

**问题：** 是否应写平均百分比误差零点二百分比？

**解析：** scikit-learn 返回比例，零点二通常对应百分之二十。还需审查目标是否接近零或可为负，数值保护不解决解释问题。对于零维护工时样本，小绝对误差可能产生巨大比值。若采用其他相对指标，应完整给公式、权重和零目标政策，不能只换个名字继续比较。

<a id="project-3-detail-54"></a>
### 10.14 预测区间覆盖九成是否足够

**问题：** 总体区间覆盖达到预定比例，是否所有设备类型都可信？

**解析：** 不保证。总体覆盖可以由某些组过宽、某些组不足抵消，且覆盖率本身有抽样波动。应同时报告区间宽度、组支持和预定子群体覆盖，明确方法假设。若区间由独立校准数据构建，校准规则同样需要冻结；不能用最终测试调整宽度后把覆盖称为独立确认。

<a id="project-3-detail-55"></a>
### 10.15 模型预测更准，是否证明某个传感器有因果作用

**问题：** 加入传感器特征后 MAE 降低，可否说改变该传感器值会减少维护工时？

**解析：** 不能。输入可能携带来源、环境或潜在状态信息，预测增益只支持当前条件下的信息价值。干预传感器数值、修理传感器和改变设备状态是不同操作。因果结论需要额外设计与假设。报告可以说该字段在指定对照下改善预测，不能跳到真实干预收益。

<a id="sec-7-1"></a>
<a id="project-3-detail-56"></a>
### 10.16 MAE 改善而 RMSE 变差，怎样完成报告

**问题：** 是否应只展示 MAE 以突出主指标改善？

**解析：** 应报告预定主要指标，同时完整展示辅助指标和尾部取舍。该现象可能表示多数普通样本更好而少数大错更严重，需要查看原始数量、来源和业务代价。若大错触发硬约束，则主指标改善不保证通过验收。若尾部原因尚未验证，应写成假设并提出具体开发实验，不能在结论中补出一个未经运行的成功故事。

<a id="project-3-detail-57"></a>
## 11. 研究拓展：把损失、数据价值和证据层级连起来

第一项研究固定人工设备生成机制，比较原尺度平方、绝对、对数平方与分位数目标。在相同设备外层折中重新选择各方案参数，分别报告均值风险、尾部风险和方向偏差。目标不是找一项通吃的损失，而是观察不同目标在已知条件分布下的取舍。可逐步提高噪声偏斜和异方差，检验理论最优点与有限模型之间的偏离。若只在一种噪声机制下得出结论，应明确该限制。

第二项研究固定总记录数，改变独立设备数和每设备记录数，比较组外误差与差值区间。记录多但设备少时，训练内估计可能更精确，来源覆盖却不足。通过重复生成数据，可以区分数据生成、设备划分和模型训练的波动。统计区间应说明覆盖的是哪个层级，不能将多次同表重采样等同于独立收集新设备。

第三项研究比较探索子群体与独立确认的复现率。先在开发残差中搜索预定数量的规则，再在新设备中评价完全相同的规则和改进方案，记录未复现发现。改变搜索空间大小，观察被选择差异的乐观程度。这个实验能帮助理解为什么“找到一个很差的群体”只是研究起点，以及为什么完整候选历史和失败记录也是知识积累的一部分。

完成本章后进入第四章，把理论选择落实为一份可运行回归流程。运行后返回本章，用真实输出填写结果与误差报告，再进入第五章审查输入模式、模型依赖、独立重建和交付限制。章节之间不是按模型名称排列，而是沿着问题定义、合法训练、证据分析和可复现交付逐层推进。
