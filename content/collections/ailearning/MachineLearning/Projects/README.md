# 机器学习实践项目

完成一个可复现的表格分类实验，再用同样标准扩展到回归与误差分析。

**先修知识：** Pandas、监督学习、模型评估。

## 学习顺序与覆盖范围

第 1—2 章先完成分类闭环。第 3 章给出回归任务、指标和报告的设计，第 4 章将其落实为可运行实验；取得结果后返回第 3 章完善误差分析，再由第 5 章统一交付。分类项目不要求先学完无监督学习或概率模型。

五章分别围绕协议、分类、回归报告、完整回归实验与交付展开。每章都包含推导、可运行算例和逐题解析；第 3 章建立回归分析框架，第 4 章在统一的人工设备任务上落实。第 5 章的双字段交付算例另行构造，用于隔离验证恢复契约，不能把它当作第 4 章训练模型的性能结果。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：从新来源误差形成下一轮实验](05-特征审查模型说明与交付清单.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
