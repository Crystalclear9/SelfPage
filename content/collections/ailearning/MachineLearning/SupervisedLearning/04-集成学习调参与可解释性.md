## 1. 集成究竟在组合什么

<a id="ch4-1-1"></a>
### 1.1 函数平均、概率混合与投票

回归可以平均数值预测，分类可以平均概率、平均分数或投票，三者不是同一操作。概率平均相当于先随机选择一个成员模型，再按它的分布生成结果的混合分布；平均 logit 后 sigmoid，则组合了另一种尺度的信息。若输出没有共同语义，例如一个是加权概率、另一个是原总体概率，直接平均本身就需要解释。

两个模型正类概率零点九与零点五，等权概率平均为零点七；对应 logits 为 $`\log9`$ 与零，平均为 $`\log3`$，再 sigmoid 为零点七五。它们可以给出不同成本行动。平均 logit 对应归一化的几何概率组合，而不是同一个算术混合，不能只因为都叫软投票就忽略区别。

<a id="ch4-1-2"></a>
### 1.2 凸损失给出什么保证

若损失对预测量凸、权重非负且和为一，Jensen 不等式给出集成损失不超过成员损失的加权平均。回归平方损失、概率空间的交叉熵与 Brier 都可在相应预测域使用这个结论。它约束平均成员，不保证超过最强成员。

例如真实标签为一，两个成员报告零点九与零点一，平均概率零点五，对数损失约零点六九三；最好成员损失约零点一零五，最差约二点三零三，平均约一点二零四。集成优于平均成员，却差于最好成员。不能把凸性证明变成“集成必然优于所有单模型”。

硬零一错误不对概率线性凸，所以同样 Jensen 不能直接证明投票错误下降。若成员错误在给定对象下独立且每个正确概率超过二分之一，可以得到多数投票随成员数改善的某些界；共享数据与共同难例往往不满足独立。实际研究应测误差模式，而不是把独立投票故事套给所有森林与深度集成。

<a id="ch4-1-3"></a>
### 1.3 互补性比单榜单排名更具体

两个模型平均分相近，可能在不同样本上擅长不同规律，因此融合有价值；也可能错误几乎完全一致，收益很小。互补性应该在代表部署的开发数据上，通过残差协方差、分类分歧与关键组检查，而不是凭模型名字不同判断。

一个明显较弱模型也可能补上强模型的特定失败，但加入后是否值得，需要成本与独立评价。只在很小验证集上寻找最佳组合容易适应噪声，组合成员与权重越多，选择复杂度越大。集成不是摆脱泛化问题的方法，而是又一个需要评价的学习规则。

<a id="visual-supervisedlearning-04"></a>
### 图解：集成平均的收益：互补误差与共同偏差必须区分

![集成平均的收益：互补误差与共同偏差必须区分](images/04-concept.svg)

左图画两个零均值、单位方差成员误差的联合高斯 95% 概率椭圆，蓝色相关系数为 $`-0.8`$，橙色为 $`0.8`$。横纵单位相同。蓝色长轴接近灰线 $`e_1+e_2=0`$，沿这条线平均会抵消误差；橙色则主要沿两个成员同向波动的方向伸展。椭圆围住的联合概率都是 95%，不能把屏幕椭圆面积当作平均后的方差或概率。

右图使用线性映射 $`\bar e=\frac{e_1+e_2}{2}`$ 得到真实的一维高斯密度。由协方差展开，$`\operatorname{Var}(\bar e)=\frac{1+1+2\rho}{4}=\frac{1+\rho}{2}`$，蓝色方差为 $`0.1`$，橙色为 $`0.9`$。两者都无偏，但相关性不同会使相同两个成员的平均有不同集中程度；联合图不是简单沿某个屏幕方向量宽后就得到概率密度，密度需要把所有映到同一平均值的联合概率汇总。高斯假设只用于把这个汇总画成可解析曲线，方差等式只需二阶矩存在。

灰色密度给两个成员都加上共同偏差二，保留蓝色的中心化协方差：平均方差仍为 $`0.1`$，平均误差均值却变成二，相对于真实回归函数的平方风险为 $`4+0.1=4.1`$。蓝色风险只有 $`0.1`$，橙色为 $`0.9`$；曲线尖锐不能单独代表预测正确。单点也能核对：真实值十时，预测八与十二平均为十，而两个十二平均仍为十二；单点抵消是机制示例，不构成总体风险证明。多成员公式、可行相关范围与权重估计见第 4 节；[《The Elements of Statistical Learning》第 15.2 节、式 15.1](https://hastie.su.domains/ElemStatLearn/download.html)给出等方差、等相关平均的方差结构。图中负相关仅为两个成员的合法教学情形，不能把它无条件推广成任意多个成员的同一负相关矩阵。stacking 还必须遵守折外与独立评价协议。

<a id="sec-2"></a>
## 2. 有顺序且公平的调参

<a id="ch4-2-1"></a>
### 2.1 参数顺序应来自机制而非固定配方

先固定任务、合法划分、主要指标和预算，再选择影响大的轴。森林中叶大小、特征随机性与采样决定基模型强度和依赖；提升中树容量、学习率、轮数与叶约束相互作用。可以先粗后细，但不能假设逐个调一个参数、永远固定其他参数就能找到联合好解。

例如小学习率配太少轮次会显得表达不足，深树配极小叶支持可能追逐噪声，强正则与小步长又可能让训练进度过慢。搜索空间应包含机制合理的组合，并根据预算明确停止。一个没有收敛机会的候选不能公平代表整个方法。

<a id="sec-1-1"></a>
### 基础算例：验证搜索中的一次选择偏差

两个候选真实风险相同，验证噪声使本次准确率为零点八一与零点七九，选择前者并没有证明真实能力更高。若各候选估计噪声独立且取正负零点零一，两候选最大估计的期望噪声为正零点零零五，即使每个单独估计无偏，选择之后也乐观。

增加候选通常增加碰到幸运值的机会，但真实候选噪声相关，不能只数模型个数就精确估计偏差。保留独立测试或外层评价完整搜索规则，记录预算与重复结果。最终保存权重再只调用一次测试，并不会抹去此前已经利用测试信息的历史。

<a id="sec-2-1"></a>
### 机制展开：调参顺序应围绕机制减少无效组合

在正值跨度很大的轴上，对数尺度抽样常比等间隔更合理；某些条件参数只在特定结构启用时有意义，应避免浪费组合。随机搜索、网格、序贯建议与多保真淘汰各有成本结构，不能只比较完成候选数量而忽略每个候选消耗。

提前淘汰依赖“早期表现能够预示最终表现”的假设。学习慢但最终好的候选可能被过早删除；不同模型的曲线速度又不同。可以记录淘汰规则、给足最小资源，并在少量完整运行中检查偏差。搜索算法本身也应被视为方法的一部分。

<a id="deep-dive-2"></a>
### 深入讲解：调参和解释必须围绕完整学习流程

前处理、特征筛选、成员模型、权重、校准与阈值一起决定预测。每个被数据选择的部分都可能适应开发集。外部评价要测完整链，而不是只对最后融合器做一次交叉验证，前面所有步骤却已看过验证标签。

解释同样依赖完整链。原始金额先取对数、再标准化、最后进入模型，某个坐标贡献不一定直接等于原单位变化；组合概率与 logit 的贡献也不同。必须先说解释的是哪一个函数、在哪一分布和尺度上，再谈重要性或局部归因。

<a id="ch4-2-5"></a>
### 2.2 同预算与充分调优回答不同问题

同时间或资源预算比较，回答在现实约束下哪套开发流程更有效；各自充分调优并披露成本，回答更充分资源下的表现。它们都可以合理，但不能把前者结果说成某模型永远更强，也不能隐藏后者花了大量额外搜索。

可画最优开发表现随累计成本的曲线，再用独立测试评价预定预算点。若不断根据测试挑预算，测试又进入选择。基线也需要合理前处理与搜索范围，公平不等于机械让所有模型用同名参数或同样数值。

<a id="ch4-2-6"></a>
### 2.3 嵌套评价与重训

外层训练部分内部完成所有候选搜索与融合，外层留出只评价确定流程。选择结束后，可按既定规则用全部开发数据重训，但其训练规模、折外元特征和停止轮数需要明确处理。最终模型不是任意一折模型的简单复制。

外层折彼此训练数据重叠，折成绩不应无条件当独立重复求标准误差。来源与时间依赖还需要对应分组设计。报告搜索结果时区分训练随机性、样本不确定性与选择稳定性，比只给最优均值更多小数更有意义。

<a id="sec-3"></a>
## 3. 解释方法回答不同问题

<a id="ch4-3-1"></a>
### 3.1 三种经常混淆的对象

固定模型依赖询问当前函数使用了哪些输入；可替代预测信息询问删掉输入再训练后，其他变量能否补偿；因果效果询问现实中主动改变变量会怎样。置换重要性、删列重训和因果实验分别接近不同问题，结果不同不一定矛盾。

例如目标由两个高度重复测量共同表征，模型只用第一列。打乱第二列几乎无影响，删掉第一列重新训练可以让第二列接管；这并不证明第一列“没有信息”，也不证明改变它会影响现实结果。解释报告要写清对象，而不是把所有数都叫真实重要性。

<a id="ch4-3-2"></a>
### 3.2 不纯度重要性的训练选择偏好

树内重要性累计某变量被选分裂所带来的加权纯度下降。它便宜、可直接从结构读取，但高基数或连续变量提供更多候选，可能更容易获得幸运训练收益；相关变量还会竞争分裂机会。排名描述当前训练树，而不是独立标签信息或因果作用。

可以和开发数据置换、分组置换、重采样稳定性对照。若排名只在一个训练种子高，或者在新来源上无收益，应进一步研究。不同尺度、编码与类别组合也可能改变树可选结构，所以解释要与表示版本关联。

<a id="ch4-3-3"></a>
### 3.3 置换重要性的精确定义

固定模型 $`f`$、评价分布与损失，打乱第 $`j`$ 列形成扰动输入 $`\widetilde X`$，重要性可写为 $`E[\ell(f(\widetilde X),Y)-\ell(f(X),Y)]`$。它测量该扰动破坏当前模型行为的程度，而不是自动测量变量与目标的全部关联。

若相关列互为替代，模型可能只使用其中一列；若模型同时使用两列，单独置换又可能产生现实中不存在的组合，重要性被离分布行为主导。可以按组置换或在给定其他变量下条件置换，但后者需要估计条件分布，产生新的假设与误差，不能宣称无代价修正。

<a id="ch4-3-4"></a>
### 3.4 一个线性模型的置换手算

设输入均值零、方差一，目标 $`Y=X_1`$，固定模型 $`f=X_1`$，原平方风险零。将第一列替换为独立同分布的副本，扰动误差为副本减原值，平方期望为二，所以第一列置换重要性二。若第二列等于第一列，但模型不读取第二列，单独置换第二列重要性零。

现在删除第一列并重新训练，第二列可以精确预测目标。于是“固定模型第一列依赖很高”与“删除后最佳预测不变”同时成立。若条件置换第一列且已知第二列精确等于它，允许的条件副本根本不变，重要性又变零。这些数回答不同问题，不能选一个当作全局唯一真相。


<a id="ensemble-permutation-support"></a>

### 四格核对：重要性二、零、零为什么不矛盾

![二元完全相关总体的四格枚举说明普通置换、条件置换和删列重训具有不同目标](images/04-permutation-support.svg)

把第 3.4 节的零均值、单位方差输入具体取成 $`X_1=X_2\in\{-1,1\}`$，两种符号等概率，$`Y=X_1`$。原固定模型 $`f=X_1`$ 的风险为零。用独立边际副本替换第一列时，原值与副本形成四个等概率组合：两个同号格的误差为零，两个异号格的误差绝对值为二、平方为四，故损失期望为 $`\frac{0+4+4+0}{4}=2`$。图中的四格是精确独立副本的总体枚举，并不是声称对只有两行的样本执行某一次排列必然得到二；一次排列可能不动，也可能交换，所得经验增量会不同。

条件副本要求从 $`P(X_1\mid X_2)`$ 抽取。这里该分布集中在唯一值 $`X_1=X_2`$，因此副本不能改变输入，条件置换增量为零。删列重训则允许替换函数为 $`\widetilde f=X_2`$，最优风险仍为零。这两种零不说明原程序没读取第一列：前者表示给定第二列后没有剩余可扰动信息，后者表示另一个模型可以接替；普通置换的二则表示固定函数对这个独立扰动敏感。

图中特别标出了离开观测支持的两格。模型在这些格上仍可计算，但这种函数延拓缺少该总体的直接观察支持。采用哪种重要性，取决于要研究当前模型依赖、独特信息，还是重新训练后的可替代性。更多条件置换的定义、估计难点与群体近似可对照 [Molnar 的作者教材](https://christophm.github.io/interpretable-ml-book/feature-importance.html)；不能把条件抽样简单实现成全局乱排，也不能把任一种增量直接改名为因果作用。

<a id="sec-4"></a>
## 4. 平均、协方差与权重估计

<a id="ch4-4-1"></a>
### 4.1 把共同误差写进风险公式

设同一个待预测对象的真实回归函数为 $`m(x)`$，各个模型都可分解为共同目标与各自误差。更简洁地，对任意成员编号写 $`f_k(x)=m(x)+e_k(x)`$。假定权重之和为一，集成与目标之差就是误差的加权和。这里的期望可以对新对象与训练随机性共同取，也可以条件于一份固定训练集只对新对象取；这两种分析对象要事先区别。

令误差均值向量为 $`b=E[e]`$，协方差为 $`\Sigma=\operatorname{Cov}(e)`$。集成相对于回归函数的平方误差为

$$
E[(w^Te)^2]=(w^Tb)^2+w^T\Sigma w.
$$

若实际标签还含条件均值为零的不可约噪声，预测标签的风险再加噪声方差的期望。等式同时说明两条路线：降低成员共同偏差，或降低平均后保留下来的随机误差。只盯住方差下降，可能忽略所有成员都用同一错误特征而形成的共同偏差；只追求预测分歧，也可能引入大量无规律噪声。

假设所有成员误差无偏、方差相同为 $`\sigma^2`$、两两相关系数相同为 $`\rho`$，等权平均的方差是

$$
\operatorname{Var}(\overline e)=\sigma^2\left[\rho+\frac{1-\rho}{M}\right].
$$

这个式子需要相关矩阵合法；固定成员数时等相关系数至少为 $`-\frac{1}{(M-1)}`$，不能随意让很多成员都保持很强负相关。若方差为四，相关系数为零点二，五个成员平均的方差为一点四四，二十个为零点九六，无限增加的极限为零点八。共同部分形成收益上限，不能用“模型越多误差越接近零”解释结果。

实际中不同成员方差和相关性不同，直接计算残差的二阶矩通常比套等相关假设更有用。对分类概率也可分析相对于标签的残差二阶矩，它直接联系 Brier 风险；但对数损失依赖尾部概率，不能只从误差协方差推出同样的全部结论。尤其某模型偶尔把真实类别概率压到极小值，即便多数时候表现好，也会产生很大的对数损失。

<a id="ch4-4-2"></a>
### 4.2 两个成员的最优权重与边界

先考虑两个无偏成员。第一个权重为 $`w`$，第二个为 $`1-w`$，误差方差分别是 $`v_1,v_2`$，协方差为 $`c`$。展开得到

$$
V(w)=w^2v_1+(1-w)^2v_2+2w(1-w)c.
$$

当 $`v_1+v_2-2c>0`$，求导令零可得

$$
w^*=\frac{v_2-c}{v_1+v_2-2c}.
$$

分母是两个误差之差的方差。若两个误差几乎一致，分母接近零，权重估计会极不稳定；此时从有限开发集估计出的巨大正负权重，通常不能当作有力的互补发现。如果要求概率保持凸组合，应把无约束最优值投影到零到一之间；如果允许负权重，则输出可能超出概率区间，必须另行规定链接函数与评价。

取 $`v_1=1,v_2=4,c=0.5`$，分母为四，最优第一权重为零点八七五，风险为零点九三七五。较弱成员只拿到八分之一权重，却比只用第一成员的一略有改善。这里收益来自它对第一成员误差的互补。若协方差改为一点五，最优无约束权重为一点二五；凸组合最优解则落在只用第一成员的边界，说明第二成员在这一约束下没有必要加入。

需要留意偏差。若两个成员都系统性低估一单位，权重和为一时共同偏差不会消失。可以在融合器中学习截距，但截距同样必须依靠合法训练数据估计。将总体误差直接写成二阶矩矩阵 $`A=E[ee^T]`$，平方风险便是 $`w^TAw`$，其中已经包含偏差项；若只估计中心化协方差而忽略均值，会优化错目标。

<a id="ch4-4-3"></a>
### 4.3 多成员约束优化为什么需要正则化

在误差无偏、协方差可逆且只约束权重和为一时，拉格朗日函数的一阶条件给出

$$
w^*=\frac{\Sigma^{-1}\mathbf1}{\mathbf1^T\Sigma^{-1}\mathbf1}.
$$

这是一条总体层面的解析式，不是建议把小验证集协方差直接求逆。成员多、样本少、预测高度相关时，矩阵可能奇异；即使数值上可逆，小特征值方向也会放大估计误差。权重在开发集上很好，却可能在新样本上剧烈波动。这与投资组合中估计协方差后配置资产的困难具有相同数学结构。

常用限制包括非负单纯形约束、权重二范数惩罚、向等权收缩，以及先减少高度重复成员。它们牺牲样本内最优值来降低估计方差。比如把协方差替换为它与对角矩阵的凸组合，可以弱化不稳定的相关估计；把权重惩罚到均匀向量附近，则直接表达“没有足够证据时不大幅偏离平均”的先验偏好。

对于二分类，更常见的做法是在折外概率上最小化对数损失，采用非负且和为一的权重。此目标在概率混合的内部区域是凸的，但当成员给出零概率时需要明确边界约定。数值实现通常裁剪概率以计算对数；裁剪不是统计校准，裁剪幅度过大也会改变被优化的问题。报告中应保存概率输出方式及裁剪规则，使训练和部署保持一致。

<a id="ch4-4-4"></a>
### 4.4 为什么交叉验证挑出的成员也会污染融合

一个容易忽略的问题是成员候选的来源。即使为融合器生成了折外预测，如果成员超参数先通过同一整份数据的交叉验证选出，那么某个折的标签已经影响了最后被选中的超参数。折外训练没有直接包含该行，却存在经由选择过程的间接信息路径。偏差大小取决于搜索强度和数据，不能因为数组名叫折外预测就断言完全独立。

严格评价整个融合算法时，应在外层训练数据内完成成员搜索、折外特征构造与融合器学习，外层留出只接受最终输出。如果还希望元训练特征对每一行满足更严格的选择独立性，生成某个元验证折时，还要仅在对应元训练部分内部调参。代价更高，但信息边界清晰。实际工程也可以固定来自外部经验的成员配置，避免一层额外搜索，再把剩余估计问题交给独立外部评价。

这里必须区分两个结论：某种做法不能保证元训练特征没有选择泄漏，并不意味着独立外部测试也被泄漏；只要外部测试始终隔离，它仍能评价这套实际开发流程。另一方面，不能拿内部看似漂亮的融合损失直接估计最终风险。内部数据既用于学习也用于选择时，数值应被理解为开发诊断。

<a id="sec-5"></a>
## 5. 函数空间下降与高级提升

<a id="ch4-5-1"></a>
### 5.1 从参数梯度到函数值梯度

设当前模型输出为 $`F(x)`$，训练目标为损失的样本和。把训练点上的函数值暂时看成一个长度等于样本数的向量，负梯度第一个分量到最后一个分量共同构成期望的更新方向。树的结构限制使我们不能任意设置每个训练点的独立更新，而要寻找一个浅树，使其输出尽量贴近这个方向。这解释了梯度提升中“拟合伪残差”的来源。

平方损失取二分之一倍时，负梯度就是真实值减当前预测；逻辑损失对原始分数求导时，负梯度是标签减 sigmoid 概率。两种损失都产生残差形式，但输出空间不同。对概率直接加树并不等于对 logit 加树；后者再经过链接函数，天然保持概率范围。推导时必须写出对哪个变量求导，否则“残差拟合”容易被误读成统一数值配方。

拟合方向以后还可做线搜索，选择沿该树方向降低原损失的步长，再乘一个预定收缩率。收缩率较小可能减缓过拟合，也需要更多轮数；不能把小步长当作免费提升。若模型每一步都追逐当前训练损失，停止轮数本身就是复杂度参数，需要在内部验证中确定。外部测试不得充当每轮监控器。

<a id="ch4-5-2"></a>
### 5.2 二阶近似、叶权重与分裂收益

对一个新树的增量 $`f(x_i)`$，在当前原始分数处对损失做二阶展开。记一阶导为 $`g_i`$、二阶导为 $`h_i`$，忽略不含新树的常数，代理目标是

$$
\widetilde L=\sum_i\left[g_if(x_i)+\frac12h_if(x_i)^2\right]
+\gamma T+\frac\lambda2\sum_{j=1}^T w_j^2.
$$

这里树结构把样本分配给叶，叶内输出相同为 $`w_j`$，叶数为 $`T`$。把同叶样本的导数求和为 $`G_j,H_j`$，目标就分解成多个一元二次式。若 $`H_j+\lambda>0`$，每个叶的唯一最优输出为

$$
\begin{aligned}
w_j^* &=-\frac{G_j}{H_j+\lambda},\\[6pt]
\widetilde L^* &=\gamma T-\frac12\sum_j\frac{G_j^2}{H_j+\lambda}.
\end{aligned}
$$

这个推导的价值在于把结构搜索与叶值优化联系起来：对候选切分，比较左右两叶最优代理目标与原叶最优代理目标。若左右导数和分别为 $`G_L,H_L,G_R,H_R`$，净收益为

$$
\operatorname{Gain}=\frac12\left[
\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}
-\frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right]-\gamma.
$$

叶数增加一，所以只减一次叶惩罚。当前公式没有样本权重、绝对值惩罚或单调约束；若加入这些条件，需要重新确定导数加权与最优叶值，不能把所有软件选项都看成不影响公式的装饰。这个二阶结构可与[XGBoost 原理文档](https://xgboost.readthedocs.io/en/stable/tutorials/model.html)对照，但下面的数值例子可以独立手算。

<a id="ch4-5-3"></a>
### 5.3 四个样本的一次分裂手算

考虑二分类，四个样本当前预测概率都为二分之一，标签为零、零、一、一。逻辑损失对 logit 的一阶导为概率减标签，所以前两个为正二分之一，后两个为负二分之一；每个二阶导均为四分之一。取叶正则系数一，叶数惩罚零点一，按前两个与后两个切分。

左叶导数和一、曲率和二分之一，右叶导数和负一、曲率和二分之一，父叶导数和零、曲率和一。因此两个叶的最优输出分别为负三分之二与正三分之二，未扣叶数惩罚前的代理改进为三分之二，净收益约零点五六六七。父叶输出为零，这次分裂能把原本混在一起的标签推向不同分数。

如果实际收缩率为零点一，原始分数只更新正负十五分之一，概率大约变成零点四八三三与零点五一六七。不能直接把代理收益零点五六六七当作使用小步长后的真实逻辑损失下降；它是未缩小叶更新下的二阶代理比较。训练日志中的原目标、代理目标与结构评分应区分，特别是大步长和强非线性时。

若四个标签交错且特征不提供可分线索，某个候选切分的左右导数和可能都接近零，即使叶中样本很多，也没有相应收益。反过来，少量极端残差可能给出很大梯度，因此还需要叶支持、曲率下限与叶值限制，避免一步被少数对象主导。数量约束与曲率约束有关联但不等价。

<a id="ch4-5-4"></a>
### 5.4 二阶方法的适用限制与常见改造

逻辑损失的曲率为概率乘一减概率。当概率极接近零或一时，曲率很小；若标签与高置信预测矛盾，梯度仍很大，未正则化的 Newton 叶步长就可能很大。分母正则、最小曲率和、最大叶步长与收缩率分别限制不同环节。把很小曲率简单解释为“信息少所以可以完全忽略”是不充分的，它也可能暴露当前模型过度确信。

对于非凸自定义损失，二阶导可能为负，代理不再是凸二次，前面的叶最优式可能不存在最小值。某些实现采用正的近似曲率、截断或其他代理，这是算法定义的一部分，需要明确它优化的究竟是原损失还是安全替代。排序与多分类任务也可能包含跨样本或跨类别的 Hessian 结构，用对角近似时应承认舍弃了耦合项。

直方图提升将连续特征候选切点压缩为分箱边界，以减少计算与内存。它改变结构搜索的候选集合，所以可能漏掉细粒度阈值；分箱数过小会限制表达，过大又增加成本。缺失值默认方向若在训练中被选择，也是一种学习参数。部署数据缺失机制变化，不能只检查数值范围而忽略该路径的含义。

单调约束规定某些输入增大时预测不得下降，可把领域知识带入结构与叶值选择。它保证的是模型函数的形状，不保证现实因果单调，也不保证所有交互解释都简单。若输入中存在同一量的多种变换，约束单个列还可能留下其他路径，因此应基于完整特征表示检查约束语义。

<a id="ch4-5-5"></a>
### 5.5 指数损失与自适应重加权的联系

用标签正负一和基分类器正负一，考虑指数损失 $`\sum_i\exp[-y_iF(x_i)]`$。新增一项 $`\alpha h(x)`$ 时，把当前指数残差归一化为样本权重，正确分类对象的因子是 $`e^{-\alpha}`$，错误对象的因子是 $`e^{\alpha}`$。若当前加权错误率为 $`\epsilon`$，一维目标与 $`(1-\epsilon)e^{-\alpha}+\epsilon e^\alpha`$ 成正比。

对步长求导令零，得到 $`\alpha=\frac12\log[\frac{(1-\epsilon)}{\epsilon}]`$，对任意 $`0<\epsilon<1`$ 都是无约束实数步长的一维最优解；若要求正步长，则还需 $`\epsilon<\frac{1}{2}`$。当 $`\epsilon=\frac{1}{2}`$ 时最优步长为零。错误率为零时最优步长在此理想目标中发散，需要停止或数值限制；错误率大于二分之一时可以翻转分类器方向，但具体实现是否自动处理必须查阅定义。公式说明重加权与加性损失优化是同一机制的两个视角。

由于被持续误分对象的权重上升，错误标签与异常对象也可能长期占据注意力。这与“模型会自动学会所有难例”不同：难例可能含有可学习结构，也可能根本缺乏足够信息。比较指数损失、逻辑损失和更稳健替代时，应研究尾部对象的权重与更新影响，而不是仅比较最终训练准确率。

**从单轮步长推到多轮训练错误上界。** 设初始权重 $`D_1(i)=\frac{1}{n}`$，$`F_0=0`$，每轮按
$`D_{m+1}(i)=\frac{D_m(i)\exp[-\alpha_my_ih_m(x_i)]}{Z_m}`$ 更新，其中 $`Z_m`$ 是让权重和为一的归一化常数。将递推连续代入，可以逐项得到

$$
\begin{aligned}
D_{M+1}(i) &=\frac{\exp[-y_iF_M(x_i)]}{n\prod_{m=1}^MZ_m},\\[6pt]
\frac1n\sum_i e^{-y_iF_M(x_i)} &=\prod_{m=1}^MZ_m.
\end{aligned}
$$

后一个等式来自对前式求和，而不是假设各轮错误相互独立。任何被最终分类器误分的点都满足 $`y_iF_M(x_i)\le0`$，其指数损失至少为一；将零分数平局也计入左侧只会给更保守的界。因此训练错误率不超过 $`\prod_mZ_m`$。代入本节精确线搜索的步长，得到

$$
Z_m=2\sqrt{\epsilon_m(1-\epsilon_m)}.
$$

若每轮都具有 $`\epsilon_m\le\frac{1}{2}-\gamma`$ 的统一优势，$`0<\gamma<\frac{1}{2}`$，且各轮 $`0<\epsilon_m<\frac{1}{2}`$，则
$`Z_m\le\sqrt{1-4\gamma^2}\le e^{-2\gamma^2}`$，从而训练错误率不超过 $`e^{-2M\gamma^2}`$。这把“弱学习器不断集成后能拟合训练集”变成了带条件的推导：优势必须相对于当轮不断变化的权重成立，并非只要求每个成员在原始均匀样本上胜过随机。

取一轮加权错误率 $`\epsilon=0.2`$，则 $`\alpha=\log2`$、$`Z=0.8`$。正确对象权重乘因子 $`\frac{e^{-\alpha}}{Z}=0.625`$，错误对象乘 $`\frac{e^\alpha}{Z}=2.5`$；原来合计占 $`0.2`$ 的错误对象，更新后总质量变为 $`0.5`$，正确对象也合计为 $`0.5`$。如果每轮都确实维持同样加权错误率，十轮指数损失为 $`0.8^{10}\approx0.10737`$，从而给出相应训练错误上界；它不是说十个独立投票恰有这个错误概率。

这个界不直接保证测试错误。样本量、函数族、间隔分布、噪声和选择过程仍会影响泛化；持续追逐错标对象也可能让函数变得不合适。若实际使用学习率收缩、截断步长或改变弱学习器输出范围，权重递推与指数损失乘积等式可按实际更新重新核对，但精确线搜索的 $`2\sqrt{\epsilon(1-\epsilon)}`$ 不能原封不动代入。明确哪些等式依赖哪个算法步骤，才能把理论和实现对应起来。


<a id="stacking"></a>
## 6. Stacking 的折外信息链

<a id="ch4-6-1"></a>
### 6.1 为什么不能用训练集预测直接学习融合器

设一个极深树在训练集几乎记住标签，另一个线性模型保留明显残差。如果把两者在同一训练集上的预测交给元模型，元模型会认为树几乎完美，倾向于把大部分信任给它。但在新对象上，树的记忆优势消失，元模型看到的特征分布发生变化。问题不只是“又训练了一层”，而是元训练阶段观察到的成员能力与真实使用时能力不一致。

折外构造把训练数据分成若干部分。对某一部分的每一行，仅用其他部分训练成员，再为该行生成预测。每一行因此得到一组在未见其标签的拟合条件下产生的元特征。不同元特征列对应不同成员，元模型学习这些预测与标签的关系。若二分类使用两个类别概率，它们和为一，通常只保留正类概率，避免完全线性冗余。

折外并不等于从此不需要正则化。元样本数仍然有限，多个成员预测高度相关，复杂融合网络仍可过拟合。简单逻辑回归、受约束线性组合往往是值得先尝试的元学习器。元模型若接收原始特征，它不再只是全局权重，而能学习按对象变化的组合规则；表达更强，但也增加了评价与解释负担。

<a id="ch4-6-2"></a>
### 6.2 一张索引表说明合法数据流

设十二个开发样本分三折，每折四行。第一轮以第五到第十二行为成员训练数据，预测第一到第四行；第二轮以第一到第四及第九到第十二行训练，预测中间四行；第三轮训练前八行，预测最后四行。对两个成员，最终得到十二行两列元矩阵，其每行来源都能追溯到一个不含该行的训练索引集合。

真正实现时，不应仅检查预测数组形状。还要检查同一人的重复记录、相邻时间窗、原始图像的增强副本是否跨越这条边界。若同一人的其他记录进入成员训练，该行虽然索引不在训练里，实质上仍可能不满足部署时的新主体任务。折外的“外”应按统计独立单位定义，而不是机械按数组行定义。

每一折中的标准化、缺失填补、特征选择及目标编码都属于成员训练。尤其目标编码若在全体训练数据先算一次，再把编码表交给折外成员，验证行的标签会绕过模型拟合直接进入输入。可靠结构是把所有需要拟合的变换放进对应成员流水线，让每次折训练重新估计。无监督变换也应按预定部署协议处理，不能默认任何全体拟合都无影响。

<a id="ch4-6-3"></a>
### 6.3 拟合完成后如何预测新对象

元模型训练完成后，常见方案是在全部开发训练数据上重新拟合每个成员，对新对象生成元特征，再交给已训练的元模型。另一方案保留各折成员，对新对象的成员预测先跨折平均，再提供给融合器。前者成员使用更多数据，后者形成额外平均；它们并不完全等价，也会产生不同计算与存储成本。

第一种方案有一个固有差异：元训练预测来自较少训练样本的成员，而部署预测来自全部训练数据的成员。数据量很小、成员学习曲线很陡时，这个差异可能明显。增加折数可减少训练规模差距，但每个验证折更小、计算更多，且不同元行共享的训练数据更多。不能通过无限增加折数同时得到所有好处。

元模型系数也不宜直接叫“模型重要性”。在相关概率列上，系数受到其他列和正则化影响；负系数可能用于纠正共同偏差，不等于对应成员总体毫无价值。若输入是概率、输出经过 sigmoid，系数表示元 logit 对该概率坐标的条件变化，而不是原模型对最终概率贡献的固定比例。

<a id="ch4-6-4"></a>
### 6.4 三层嵌套中每一层究竟负责什么

可以把流程分成三个角色，而不是只记住“用几折”。最里面的折外构造负责训练元模型；中间的验证负责选择成员及融合超参数；最外面的留出负责评价整个选择规则。中间每次训练一个候选 Stacking 时，内部又必须重新构造元特征。若先在全体开发数据生成一次元矩阵，再在这张矩阵上做中间交叉验证，验证对象的标签可能已经影响其他行的元特征，不能等同于重新拟合完整流程。

例如元训练行甲的基模型可能使用了中间验证行乙的标签；即使后续元模型没有直接训练乙，甲的特征已经间接带入乙的信息。这是一条容易被忽略的信息链。将整个 Stacking 估计器放进搜索器，由搜索器在每次候选训练时完整重新拟合，可以避免这种简单复用导致的问题。预先训练后设置为已拟合模式的成员则需要另一个独立元训练集，不能把方便接口当作自动折外保证。

若需要严格比较“固定简单平均”与“经过搜索的 Stacking”，应同时披露两者调优预算。一个合法比较是为两类流程预先分配相同资源，分别在内部做各自合理选择，再到相同外部对象上评估。另一个合法比较是把平均作为低成本基线，明确说明高级流程多用了多少训练时间，并讨论收益是否值得成本。无论选择哪一种，都不能在看到测试后切换评价口径。

<a id="ch4-6-5"></a>
### 6.5 时间任务、分组任务与多输出任务的特殊性

时间预测中的普通随机折外会让未来数据预测过去，虽然没有包含某一行自身，却违背可用信息的时间方向。应使用滚动或扩张窗口，从过去训练去预测后续。最早的一段数据可能无法得到合法折外预测，元训练需要从可预测区间开始。某些便捷交叉预测接口要求每行恰好被验证一次，不一定适合这种时间结构，手工循环往往更清楚。

分组任务应让同组始终处于同一侧。多标签与多输出任务则要明确元特征是各输出概率拼接、原始分数拼接，还是每个任务独立融合；后者不能利用任务间关系，前者更容易在小数据中放大复杂度。类别映射也必须一致，某折缺少某类别时不能靠默认数组列位置拼接概率。

对于需要动态更新的部署系统，成员和元模型还存在版本耦合。只替换一个成员而不更新融合器，会改变元输入分布；只重新校准成员也可能产生类似问题。应把成员集合、特征定义、概率尺度、元模型与最终行动规则一起版本化，在代表更新后的数据上重新验证，而不是把融合器当作永久通用的插座。

### 图解算例：Stacking 的折外输入：训练身份与记忆噪声反例

![Stacking 的折外输入：训练身份与记忆噪声反例](images/04-example.svg)

图将**基学习算法**与**交叉验证折**分开表示。A 始终是逻辑回归，B 始终是树桩；每一折各拟合一个 A 副本和一个 B 副本，共六个折内拟合对象。第一个折的两个副本只看行 $`3,4,5,6`$，再分别预测行 $`1,2`$，写入折外矩阵的 A 列、B 列；其余两折同理。最后每一行都有两种算法各自的一份折外预测，得到 $`6\times2`$ 的元训练特征，而不是将三个折当成三种不同算法。

数值使用原始单特征 $`x=(1,2,3,4,5,6)`$、标签 $`y=(0,1,0,1,0,1)`$，三折依次留出相邻两行。A 使用带截距的 L2 逻辑回归，$`C=1`$，`lbfgs` 求解；B 使用 `max_depth=1`、`random_state=0` 的分类树。图中只写每种算法的正类概率，保留三位小数。例如行一的 A 概率约 $`0.170080`$，B 概率为零；这两个数均来自没有见过行一及行二标签的拟合副本。没有额外预处理；若增加标准化、填补或特征选择，也必须在各折训练部分内部拟合。

元模型用完整折外矩阵和对应标签拟合。部署前，再分别用全部六行重训 A、B；新对象 $`x=3.5`$ 的两列输入约为 $`(0.5,0.6)`$，按相同列顺序交给已拟合的元模型。折内副本负责生成训练特征，全量副本负责外部预测；标准方式并不直接把三个折副本永久当成三种基算法。全量重训与折外预测的定义见 [StackingClassifier 官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.StackingClassifier.html)。

折外生成是防止元模型读取训练内记忆的机制，不能自动保证最终泛化。另一个极端反例是：基模型对见过的交替标签报告 $`0.01,0.99`$，对未见对象只报告 $`0.5`$，那么训练内平均对数损失为 $`-\log0.99\approx0.010050`$，折外却为 $`\log2\approx0.693147`$。这组记忆模型反例与图中实际逻辑回归、树桩分开构造；不能把两组数误认为同一次拟合的结果。元模型选择、全量与折内模型的差异以及外层测试仍需独立验收。

## 7. 全局曲线与局部贡献

<a id="ch4-7-1"></a>
### 7.1 部分依赖曲线把什么保持不变

对一个固定模型，第一个变量的部分依赖可定义为 $`\operatorname{PD}_1(t)=E_{X_{-1}}[f(t,X_{-1})]`$。做法是把第一列统一改为某个值，其余列仍按背景分布取样，再平均输出。它描述一个人为构造的混合分布下模型的平均函数值，不需要真实标签，也不自动等于现实干预效果。

在独立特征或有充分共同支持时，这条曲线可以帮助理解函数随某坐标的变化。若特征高度相关，把第一列改为极大值而保留原来的其他列，可能制造训练中从未出现的对象。例如总消费与各类消费加总存在确定关系，单独改总额就破坏了约束。此时曲线会受到模型在无数据区域的外推支配，图形平滑也不能保证解释可靠。

个体条件期望曲线对每个背景对象单独画 $`f(t,x_{i,-1})`$，有助于看到被平均掩盖的异质性。若有些对象上升、有些下降，总体平均可能几乎水平；这不是模型完全不使用该变量。可把每条曲线在共同基点中心化，以比较变化形状，但中心化不会修复离分布输入，也不会去除真正存在的交互。

<a id="ch4-7-2"></a>
### 7.2 条件均值与模型直接依赖的反例

设两个标准化特征相关系数为 $`\rho`$，固定模型仅为 $`f(x)=x_2`$。如果联合分布是零均值二元正态，那么 $`E[f(X)\mid X_1=t]=\rho t`$，尽管模型函数根本不读取第一列。这个条件曲线反映第一列提供了第二列的信息，不能当作模型对第一列的直接函数依赖。

相反，部分依赖固定第一列后平均第二列，得到恒为零的曲线。这与条件曲线不同，但两者各有明确问题。前者在依赖特征下可能外推，后者把相关信息带进曲线。解释不能先决定某一种曲线“最真实”，再忽略它究竟对什么分布取平均。

更尖锐的例子是实际数据只满足 $`X_2=X_1`$。模型甲为 $`f_A=x_1`$，模型乙为 $`f_B=x_2`$。两者在可观测支持集上完全相同，所有观测误差指标也相同，但单独扰动第一列得到截然不同结果。数据本身不能决定离开支持集以后哪种延拓更可信。要讨论现实操作，需要额外结构知识，而不只是更复杂的解释算法。

<a id="ch4-7-3"></a>
### 7.3 累积局部效应的构造与中心化

在可微和可积等条件下，一阶累积局部效应先取条件局部导数，再积分：

$$
\begin{aligned}
\widetilde A_1(t) &=\int_{t_0}^{t}E\left[
\frac{\partial f(z,X_{-1})}{\partial z}\mid X_1=z\right]dz,\\[6pt]
A_1(t) &=\widetilde A_1(t)-E[\widetilde A_1(X_1)].
\end{aligned}
$$

与部分依赖的全局替换不同，它在当前变量附近使用对应的条件背景，减少把一个对象跨很远位置硬移动的需要。树不可微时，实际可以分箱，在每个箱内把第一列分别改为箱两端，计算局部预测差，求箱内平均再沿箱累积，最后中心化。其思想与定义可参照[ALE 原始论文](https://arxiv.org/abs/1612.08468)。

取模型 $`f(x_1,x_2)=x_1x_2`$，并设条件均值 $`E[X_2\mid X_1=z]=\rho z`$。局部导数是 $`x_2`$，条件平均为 $`\rho z`$，积分得到二分之一乘相关系数乘平方变量，再减去平均值。若第一列方差为一且均值零，中心化曲线为 $`\frac{\rho(t^2-1)}{2}`$。模型具有交互，一阶曲线不一定是直线，更不能把该曲线当作原函数的无条件主效应系数。

箱太宽会平滑掉局部变化，箱太窄会造成支持不足与高方差；极端尾部尤其需要标出样本数。确定性关系或很稀疏的支持仍可能使局部端点扰动缺乏意义。累积局部效应改善特定外推问题，不会自动提供因果识别，也不会保证所有相关结构下都能唯一分解贡献。

<a id="ch4-7-4"></a>
### 7.4 Shapley 分摊从一个明确的博弈开始

对待解释对象 $`x`$，先定义任意特征子集 $`S`$ 的价值 $`v_x(S)`$。给定价值函数以后，第一个特征的 Shapley 值是它加入各种已有特征集合时边际增益的加权平均。一般形式为

$$
\phi_j=\sum_{S\subseteq\{1,\ldots,d\}\setminus\{j\}}
\frac{\vert S\vert !(d-\vert S\vert -1)!}{d!}
\big[v_x(S\cup\{j\})-v_x(S)\big].
$$

权重对应随机排列中特征前驱集合出现的概率，因此也可以理解成对所有加入次序平均。若价值函数固定并满足完整集取值为模型当前输出，则所有贡献之和等于该输出减去空集基线。这是一种公平分摊公理得到的分解，不是对现实因果的自动证明。其在预测解释中的系统形式见[SHAP 原始论文](https://arxiv.org/abs/1705.07874)。

关键自由度在价值函数。边缘替换常使用 $`E[f(x_S,X_{-S})]`$，把保留变量和背景其余变量重新组合；条件版本使用 $`E[f(X)\mid X_S=x_S]`$，保留观测依赖。两者可以给不直接进入函数的变量不同贡献。有限样本还要选择背景集和条件分布估计方法，这些选择都应进入报告。

用一个只有两列的玩具例子可以看清区别。设两列总是相等，以同等概率取零或一，模型只读取第一列，解释对象为一、一。空集预测均值是零点五，完整输出为一。边缘价值下，只有第一列能改变函数，贡献分别为零点五与零；条件价值下，知道第二列为一也会推知第一列为一，两列贡献各零点二五。这不是计算错误，而是博弈定义不同。

在确定性相关下，边缘替换会计算原支持集之外的函数，而条件版本把信息代理也分到贡献。若希望解释“模型程序实际上读取什么”，前者的一些性质更贴近该问题；若希望解释“观测一个变量传递了多少预测信息”，后者更相关。任何一种版本都不能单凭数值回答主动改变第二列是否改变第一列或现实结果。

### 机制算例：加入次序、相关强度与未使用特征的贡献

![两种特征加入顺序和相关系数揭示Shapley价值函数的不同](images/04-coalition-correlation.svg)

图上半部分把前面的完全相关例子展开成两条加入次序。固定模型始终为 $`f(x_1,x_2)=x_1`$，解释输入为 $`(1,1)`$，背景在 $`(0,0)`$ 与 $`(1,1)`$ 各有一半质量，空集基线是 $`0.5`$。蓝色条是第一列获得的边际增益，橙色条是第二列的增益；没有颜色长度的那一步增益为零。每个次序都从基线 $`0.5`$ 到完整预测一，总增益恒为 $`0.5`$，两种次序各取二分之一权重。

对边缘替换博弈，$`v(\varnothing)=0.5`$，$`v(\{1\})=1`$，$`v(\{2\})=0.5`$，$`v(\{1,2\})=1`$。先加入第一列时，它立即带来 $`0.5`$，之后第二列带来零；先加入第二列时，它带来零，之后第一列仍带来 $`0.5`$。所以贡献为 $`(\phi_1,\phi_2)=(0.5,0)`$。这里把第二列固定为一、第一列仍按背景边际抽样，会计算输入 $`(0,1)`$，虽然它不属于原数据支持；这项计算之所以有确定答案，是因为我们已经把模型函数在整个输入空间上明确规定为第一坐标。

对条件观察博弈，知道任一列等于一，都会推知另一列为一，因此两个单元素集合的价值都变成一。先观察谁，谁先取得全部 $`0.5`$ 信息增益；后观察的列已没有额外信息。对两种次序平均后，两列各得 $`0.25`$。这没有违反给定博弈下的 Shapley 虚玩家性质：第二列虽然是模型程序不读取的变量，却不是**条件价值博弈**里的虚玩家，因为 $`v(\{2\})-v(\varnothing)=0.5`$。把“函数没有这个输入依赖”与“观察这个变量没有预测信息”当成同一句话，才会制造表面矛盾。

图下半部分进一步排除“这只是完全重复特征才有的奇怪边界”。保持两列边际都为等概率二元分布，用 $`0\le\rho\le1`$ 控制相关性：

$$
P(0,0)=P(1,1)=\frac{1+\rho}{4},\qquad
P(0,1)=P(1,0)=\frac{1-\rho}{4}.
$$

这时两列的 Pearson 相关系数恰为 $`\rho`$。模型和解释输入完全不改，条件价值为 $`v(\varnothing)=\frac12`$、$`v(\{1\})=1`$、$`v(\{2\})=\frac{1+\rho}{2}`$、$`v(\{1,2\})=1`$。直接代入两特征分摊公式，得到

$$
\begin{aligned}
\phi_1
&=\frac12\left(1-\frac12\right)
+\frac12\left(1-\frac{1+\rho}{2}\right)
=\frac12-\frac{\rho}{4},\\[6pt]
\phi_2
&=\frac12\left(\frac{1+\rho}{2}-\frac12\right)
+\frac12(1-1)
=\frac{\rho}{4}.
\end{aligned}
$$

例如 $`\rho=0.6`$ 时，联合质量为 $`(0.4,0.1,0.1,0.4)`$，条件贡献为 $`(0.35,0.15)`$，而边缘替换贡献仍为 $`(0.5,0)`$。第一列的程序依赖没有减少，第二列没有突然进入模型；变的是背景分布中第二列能替代多少第一列的信息。两条曲线的和恒为 $`0.5`$，也核对了效率性质。这个二元族还能用四格枚举直接重建，无须依赖某个解释库的近似采样输出。

因此，保存局部解释至少应包含固定模型、解释输入、背景分布、输出尺度与价值函数定义。同一个输出对应多种合法分摊，不由“Shapley 唯一”四个字消除；唯一性是在已经固定的博弈和公理条件下成立。[Sundararajan 与 Najmi 的原论文](https://proceedings.mlr.press/v119/sundararajan20b.html)专门讨论了这些解释定义之间的区别。图中没有指定因果结构；“主动改变第二列会不会影响现实中的第一列或结果”仍需要额外模型，不能从条件贡献或边缘贡献中的任一个数值直接推出。

<a id="ch4-7-5"></a>
### 7.5 输出尺度、背景分布与交互分配

若解释的是 logit，贡献相加得到 logit 差；把每个贡献单独做 sigmoid 再相加，通常不等于概率差。非线性链接使相加结构不保留。应先把基线与所有贡献求和恢复原始分数，再整体变换得到概率。若工具提供概率尺度解释，需确认其价值函数与近似方法，而不是只把图的横轴文字改成概率。

背景集改变基线，也改变各种子集的缺失变量补全，因此局部贡献会变化。以全体用户为背景，解释某对象相对总体为何分数高；以同地区同年龄组为背景，解释相对同类对象为何高。两种问题都可能合理，比较时必须固定或清楚说明背景。用测试群体构造背景本身不等于训练泄漏，但若据此修改模型，就不能再把同一测试评价当作未使用证据。

交互也需要约定如何分摊。对独立均值零的两列，模型只有乘积项，某个对象的乘积输出可在对称博弈下由两个变量平分；这不意味着各变量独立产生了半个现实效果。局部贡献可以随对象变号，绝对值平均把方向与人群差异消掉。全局解释宜同时报告分布、典型对象与异常对象，而不只给一张绝对贡献排名。

<a id="ch4-7-6"></a>
### 7.6 条件置换的收益、难题与核验方法

普通置换把一列替换成无条件副本，条件置换则试图给定其余变量后生成副本。后者保留已有依赖，测量该列超出其他列的增量信息或依赖。若副本采样准确且与标签关系按目标协议处理，它能避免一部分明显不合法组合；但条件采样本身就是高维建模问题，不能靠随机打乱后宣称已经实现。

分箱内置换是一种近似：先按相关变量分组，再在组内交换待解释列。箱宽大时依赖保留不足，箱宽小时样本太少，甚至无法有效改变输入。用回归残差重新排列也依赖误差模型，若残差异方差或分布随条件变化，简单残差置换会造错分布。因此应先检查副本的条件均值、方差、取值约束和联合图形，再讨论重要性数值。

重复多次置换得到的波动主要反映置换随机性，并不包含训练集变化、模型选择和群体抽样的所有不确定性。要研究解释稳定性，可以在合适的主体层级重采样完整拟合流程，比较重要性分布；计算预算不足时至少区分这几类误差来源。稳定的解释也可能稳定地描述一个有偏模型，因此仍需结合预测质量和数据审计。

<a id="visual-insight-supervisedlearning-04"></a>
### 深入图解：相关特征下边际平均曲线与条件曲线不同

![相关特征下边际平均曲线与条件曲线不同](images/04-insight.svg)

固定模型为 $`f(x_1,x_2)=x_1x_2`$，总体满足 $`X_2=X_1`$ 且边际均值为零，例如 $`X_1`$ 在负二到二上均匀分布。蓝色对角线是实际输入支持，蓝点是用来演示经验平均的五个等权背景记录 $`(-2,-2),(-1,-1),(0,0),(1,1),(2,2)`$；这些点是构造的代表记录，不是一次随机抽样结果。

计算 $`x_1=1`$ 的经验 PDP 时，固定每条记录的第一列为一，保留第二列。于是产生 $`(1,-2),(1,-1),(1,0),(1,1),(1,2)`$，模型输出依次为 $`-2,-1,0,1,2`$，平均为零。四个橙点离开真实输入支持；模型在这些位置仍有定义，但数据没有直接提供这些组合的观察证据。连续总体的 PDP 同样是 $`1\times E[X_2]=0`$，这里五点平均恰好给出同一结果，因为函数对第二列线性、背景均值精确为零。

条件响应使用不同信息：知道 $`X_1=1`$，就已知道 $`X_2=1`$，所以 $`E[f(X)\mid X_1=1]=1`$。推广到任意合法第一坐标 $`u`$，PDP 为 $`uE[X_2]=0`$，条件响应为 $`u^2`$。差别来自平均对象，不能说其中一条曲线由绘图程序算错了。

PDP 的离支持组合与条件平均中的相关性均不自动提供因果干预解释。模型函数、背景分布、平均规则和数据支持应同时说明；相关特征下的 PDP 限制可对照 [Molnar 的教材章节](https://christophm.github.io/interpretable-ml-book/pdp.html)。

## 8. 完整项目：搜索、融合与解释

<a id="ch4-8-1"></a>
### 8.1 先冻结问题、数据角色与行动成本

下面构造一个二分类研究实验，目标是学习怎样比较完整流程。数据由固定随机种子生成，不需要下载，也不读取文件。我们让训练样本包含信息列、冗余列与一列近似重复测量，便于研究集成和解释。它不是现实领域结论，已知生成过程也不代表每个估计器都能从有限样本恢复结构。

将全部数据分成三个互不重叠的部分：拟合与搜索部分、行动阈值选择部分、最终测试部分。拟合部分内部通过交叉验证选择全套 Stacking 配置；每个候选的每次训练又生成自己的折外元特征。阈值集仅在最终预测模型固定后选择成本阈值，测试集只在模型与阈值都固定后进行一次评价。当前例子不单独学习概率校准器，避免在小示例中把多种数据角色混在一起。

假定漏掉正类的成本为五，误报正类的成本为一。如果输出是目标总体的准确后验概率，贝叶斯成本阈值为六分之一，因为预测正类的条件成本是一减概率，预测负类的条件成本为五倍概率。但本例概率不保证完全校准，因此在独立行动集上从预先固定的阈值网格选择经验成本较小者。网格事先给定，不根据测试改动。

模型比较的主指标为对数损失，搜索器优化其相反数。我们同时报告 Brier、曲线下面积和固定成本，但不在看到结果后更换主指标。这里给普通逻辑回归基线一个预定配置，给 Stacking 四个候选，所以它是“固定低成本基线与额外搜索流程”的比较，并不是同预算结论。若要研究公平同预算表现，需要另为基线分配同等时间并把完整预算规则预先写入实验。

<a id="ch4-8-2"></a>
### 8.2 可运行实现与逐层信息边界

代码使用 NumPy 与 scikit-learn，成员内部都带缺失填补流水线，线性成员还带标准化。随机森林和逻辑回归分别捕捉不同结构，元模型为正则逻辑回归。实现语义可对照[StackingClassifier 官方接口](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.StackingClassifier.html)。这里没有缓存整份数据的元特征，搜索器每次拟合候选都会重新训练完整对象。

```python
import numpy as np
from sklearn.base import clone
from sklearn.datasets import make_classification
from sklearn.ensemble import RandomForestClassifier, StackingClassifier
from sklearn.impute import SimpleImputer
from sklearn.inspection import permutation_importance
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import brier_score_loss, log_loss, roc_auc_score
from sklearn.model_selection import (
    RandomizedSearchCV, StratifiedKFold, cross_val_score, train_test_split,
)
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = make_classification(
    n_samples=1400, n_features=8, n_informative=4, n_redundant=2,
    n_clusters_per_class=2, weights=[0.7, 0.3],
    class_sep=0.9, flip_y=0.025, shuffle=False, random_state=41,
)
rng = np.random.default_rng(42)
X = np.column_stack([X, X[:, 0] + 0.02 * rng.normal(size=len(X))])
X_fit, X_rest, y_fit, y_rest = train_test_split(
    X, y, test_size=0.4, stratify=y, random_state=43,
)
X_action, X_test, y_action, y_test = train_test_split(
    X_rest, y_rest, test_size=0.5, stratify=y_rest, random_state=44,
)
linear = make_pipeline(
    SimpleImputer(strategy="median"), StandardScaler(),
    LogisticRegression(C=1.0, max_iter=1500),
)
forest = make_pipeline(
    SimpleImputer(strategy="median"),
    RandomForestClassifier(
        n_estimators=64, min_samples_leaf=4,
        random_state=45, n_jobs=1,
    ),
)
meta_cv = StratifiedKFold(n_splits=3, shuffle=True, random_state=46)
selection_cv = StratifiedKFold(n_splits=3, shuffle=True, random_state=47)
stack = StackingClassifier(
    estimators=[("linear", linear), ("forest", forest)],
    final_estimator=LogisticRegression(C=1.0, max_iter=1500),
    cv=meta_cv, stack_method="predict_proba", passthrough=False,
    n_jobs=1,
)
space = {
    "linear__logisticregression__C": [0.2, 2.0],
    "forest__randomforestclassifier__min_samples_leaf": [3, 9],
    "final_estimator__C": [0.2, 2.0],
}
search = RandomizedSearchCV(
    stack, param_distributions=space, n_iter=4,
    scoring="neg_log_loss", cv=selection_cv,
    random_state=48, n_jobs=1, refit=True, error_score="raise",
)
search.fit(X_fit, y_fit)
baseline = clone(linear)
baseline_cv_loss = -cross_val_score(
    baseline, X_fit, y_fit, cv=selection_cv,
    scoring="neg_log_loss", n_jobs=1,
).mean()
baseline.fit(X_fit, y_fit)

# Selection is based only on the fitting subset's cross-validation results.
stack_cv_loss = -search.best_score_
chosen_name = "stack" if stack_cv_loss < baseline_cv_loss else "linear"
chosen = search.best_estimator_ if chosen_name == "stack" else baseline
p_action = chosen.predict_proba(X_action)[:, 1]
thresholds = np.linspace(0.05, 0.8, 76)

def action_cost(labels, probabilities, threshold):
    decisions = probabilities >= threshold
    misses = (labels == 1) & (~decisions)
    false_alarms = (labels == 0) & decisions
    return (5.0 * misses + false_alarms).mean()

costs = np.array([action_cost(y_action, p_action, t) for t in thresholds])
# np.argmin resolves a tie by the predefined ascending grid order.
threshold = float(thresholds[np.argmin(costs)])
p_test = chosen.predict_proba(X_test)[:, 1]
print("sizes", len(y_fit), len(y_action), len(y_test))
print("CV loss", round(baseline_cv_loss, 4), round(stack_cv_loss, 4))
print("chosen", chosen_name, "threshold", round(threshold, 3))
print("test logloss", round(log_loss(y_test, p_test), 4))
print("test Brier", round(brier_score_loss(y_test, p_test), 4))
print("test AUC", round(roc_auc_score(y_test, p_test), 4))
print("test cost", round(action_cost(y_test, p_test, threshold), 4))

# This is a post-freeze audit. It does not trigger model or feature selection.
audit = permutation_importance(
    chosen, X_test, y_test, scoring="neg_log_loss",
    n_repeats=8, random_state=49, n_jobs=1,
)
print("permutation means", np.round(audit.importances_mean, 4))
assert len(p_test) == len(y_test)
assert np.isfinite(p_test).all()
assert ((p_test >= 0) & (p_test <= 1)).all()
assert len(search.cv_results_["mean_test_score"]) == 4
```

对数损失的负分数越高越好；官方置换实现报告原分数减扰动分数，因此在这里正重要性对应置换后对数损失增加。若直接使用原始损失差，符号刚好与这个解释一致。换成某个越小越好的自定义量时，必须检查评分器是否已经取负，不能因为画图方便把方向反过来。

代码中的成员内折与候选选择折都设了固定随机种子，便于复现流程；这不等于估计了跨种子的稳定性。真正比较研究结论时，可以预先选择多个数据生成或数据划分种子，重复完整流程，按相同对象做配对比较。不能先跑很多种子，再只保留融合胜出的那几次作为证据。

<a id="ch4-8-3"></a>
### 8.3 如何阅读结果而不夸大它

在本章给出的固定配置下，一次实际运行得到拟合、行动、测试样本数分别为八百四十、二百八十、二百八十；线性基线的内部交叉验证对数损失约为零点三零一一，最佳融合候选约为零点二零九一，因此按预定规则选择融合器。行动集选择阈值零点三四，最终测试对数损失约零点一七八九、Brier 约零点零四八九、曲线下面积约零点九七三九，平均行动成本约零点一七五。不同软件版本可能出现小幅差异，应首先复现数据角色和选择逻辑。

这组数值不是用来承诺算法优越性，而是用于核对实验产物：内部最佳成绩与最终测试成绩属于不同数据角色，阈值也确实从行动集而非测试集选出。第四列普通置换损失增量约零点四四六，为本次最大；近似重复的第一与第九列分别约零点零三三和零点零三五。这样的分摊现象值得进一步做组置换和对照研究，不能直接据此宣布真实生成机制的唯一排名。

应先核对样本角色，再看搜索是否出错、概率是否有限和标签映射是否一致，然后才讨论哪个方法分数好。模型名字不同不保证互补，若最终选择线性基线，也应完整保留这一结果。对于这个固定数据生成机制，任何一次实验只能说明该规模、该预算和该随机划分下的表现，不能证明 Stacking 在所有表格任务优于单模型。

置换结果中，信息列与近似重复列可能分摊或竞争重要性，某些噪声列也可能出现小幅正负值。负重要性表示本次扰动反而改善了所选评分，可能来自随机波动、过拟合或特定错用依赖，不应立即解释成该特征“具有负信息”。八次重复只探查置换随机性，并不能支持很细的置信结论。

测试审计完成后，如果发现某列疑似泄漏、某群体成本很高，应修订数据协议并启动新的开发周期。原测试集已经参与了问题发现与设计，下一轮最终验证需要新的独立证据，或明确把旧测试降级为开发材料。保持诚实的数据历史，比形式上最后再运行一次测试更重要。

<a id="ch4-8-4"></a>
### 8.4 与校准、阈值及资源约束联合考虑

如果下一阶段要加入校准，可从拟合数据内部建立合法的校准交叉预测，或再划出独立校准集，然后保留另一部分选择行动阈值。不能先在阈值集上拟合校准器，再把同一集上的最优成本当作独立验证成绩。最终测试仍可评价全部已冻结流程，但开发阶段自评的含义不同。

融合器输出经过逻辑回归不代表必然校准。训练分布、正则化、样本量和部署基准率都会影响可靠性；若训练使用类别权重，概率目标也可能改变。平均几个校准成员同样不自动保持严格校准，因为“给定平均概率”的条件分组与给定任一成员概率不同。概率校准和排序性能应各自评价。

在在线系统中，两个成员的串行延迟不一定等于并行墙钟延迟，但并行需要额外资源。应记录端到端分位延迟、吞吐、内存和失败回退，而不仅是纯模型预测时间。若融合只比基线改善很小，却把成本翻倍，最终选择应依据预定业务效用；不能让单一准确率把实际部署约束从讨论中抹掉。

<a id="sec-6"></a>
## 9. 综合练习与详细解析

<a id="ch4-9-1"></a>
### 9.1 概率平均为何可能胜出也可能变差

**题目。** 两个二分类成员在一个真实正类对象上给出概率零点九和零点一。计算等权概率平均的对数损失，判断它是否满足凸性保证。再构造一个三成员例子，使概率平均的总体零一错误率高于每个成员，并说明为什么这不与凸性矛盾。

**解析。** 平均为二分之一，对数损失是自然对数二，约零点六九三。成员损失分别约零点一零五和二点三零三，平均约一点二零四，因此集成不超过成员平均，但明显差于最强成员。凸性对比对象是加权平均损失，不能替换为成员最小损失。

若三个对象的真实标签都为正类，每个成员在自己的一个对象给零点零一、在另外两个对象给零点六，则每个成员只错三分之一。三个模型对每个对象的概率平均都约为零点四零三，在二分之一阈值下集成错误率为一。置信程度不对称使一个很自信的错误压过另外两个较保守的正确判断。硬零一损失不满足前述凸性条件，因而没有矛盾。

这里平均仍然满足对数损失的 Jensen 保证：每个对象上，平均概率对应的对数损失不超过三成员损失的平均。选择何种指标不是细节，同一融合可能改善概率评分却损害某个固定阈值下的行动结果。若改用多数硬投票，本例每个对象有两票正确，结果又与概率平均不同。

<a id="ch4-9-2"></a>
### 9.2 权重估计的计算与不稳定性

**题目。** 两个无偏成员误差方差为一与四，协方差为二。求无约束最优第一成员权重、对应风险，并求凸组合最优解。说明为什么有限数据下不能盲目信任这个答案。

**解析。** 分母为一加四减四，等于一；第一权重为四减二，等于二，第二权重负一。误差方差为四加四减八，等于零。此协方差矩阵行列式为零，意味着第二误差在总体上恰为第一误差两倍，因此两倍第一减第二可完全消去误差。矩阵虽奇异，但一维受约束问题仍能直接求解。

限制权重在零到一后，方差函数在该区间的最小值位于第一权重一，风险为一。现实中从有限样本观察到近似二倍关系，不等于新对象上严格成立；极少的结构变化就会破坏抵消。允许负权重还可能使分类概率越界。答案应同时包含总体代数与估计、部署限制，而不是只报一个看似惊人的零风险。

<a id="ch4-9-3"></a>
### 9.3 二阶分裂收益逐步复核

**题目。** 一个父叶的一阶导数和为二、曲率和为四，候选左右子叶分别为导数和三与负一、曲率和一与三。取叶正则系数一、叶惩罚零点二，计算最佳叶输出与净收益。若只看左叶梯度很大便切分，会遗漏什么？

**解析。** 左叶输出为负三除二，右叶为一除四，父叶为负二除五。分裂前后的最优代理改进为二分之一乘以九除二加一除四减四除五，得到一点九七五；再扣一次新增叶惩罚，净收益为一点七七五。正收益表示在当前二阶代理和给定约束下，这个候选优于不切分。

只看梯度忽略了曲率、正则与父叶已经能取得的改进，也忽略新增结构成本。即便算出正代理收益，实际小步长后的原损失变化仍需按原目标理解；非凸损失、近似 Hessian、其他叶约束又会改变适用范围。若叶样本支持过少，还应拒绝该结构或使用更强约束，而不是只比较一个分数。

<a id="ch4-9-4"></a>
### 9.4 查找两种隐蔽的 Stacking 泄漏

**题目。** 研究者先在全部开发数据上选择特征，再生成折外成员预测；另一研究者先生成一次完整元矩阵，再把元矩阵交叉验证选择融合器。分别画出泄漏路径，并提出可以独立评价的修复方式。

**解析。** 第一种情况下，某验证对象的标签影响全体特征选择，所选输入又进入用于预测该对象的成员，形成标签到特征集合再到预测的路径。修复是把选择放进每个成员训练流水线，在该折可用训练数据上重新拟合。若特征选择只依据外部领域知识并在看本数据前固定，则不存在同一种标签路径，不能机械把所有删列都叫泄漏。

第二种情况下，元验证对象可能影响了元训练对象的成员训练，从而影响元训练特征。简单在元矩阵上划分不能恢复原始数据边界。修复是对每一个融合器候选和中间训练折重新运行完整折外构造；外层保留数据再评价完整选择规则。若计算资源不足，可固定融合器复杂度并保留独立最终测试，明确内部元矩阵分数只用于训练诊断，不能冒充严格外部估计。

<a id="ch4-9-5"></a>
### 9.5 三种解释数值为什么能互相矛盾

**题目。** 目标为第一列，两列都完全相同，固定预测器只读第一列。比较普通置换第一列、给定第二列的条件置换第一列、删除第一列再训练三个结果，并解释各自问题。

**解析。** 若第一列零均值方差一且模型原风险零，普通独立置换后平方风险为二，因此当前函数对第一列的这种无条件扰动高度敏感。条件置换因为第二列已精确决定第一列，合法副本不改变原值，重要性为零。删除第一列后重新训练可让第二列接管，最佳风险仍为零。

第一项描述固定函数在一个可能离分布的扰动下的损失变化，第二项描述在其余信息已知后的剩余变化，第三项描述输入被移除后模型族可以恢复多少预测能力。三者并不争夺同一个真值。完整回答还应指出，真实改变第一列是否同时改变第二列，以及是否改变目标，都需要额外因果结构与操作定义。

<a id="ch4-9-6"></a>
### 9.6 不能把阈值与校准混为一谈

**题目。** 某模型排序很好，但把所有概率都压缩在零点四到零点六之间。调低阈值后业务成本下降，是否证明模型已经校准？若漏报成本为九、误报成本为一，准确后验概率下阈值是多少？

**解析。** 成本改善只说明在本次评价对象与成本函数下该行动规则更合适，不证明每个概率水平对应正确事件频率。模型可能保持良好排序却系统性压缩概率，阈值调整补偿某一决策边界，但没有恢复全部概率语义。可靠性曲线、适当评分与独立校准评价回答另一组问题。

预测正类条件成本为一减概率，预测负类成本为九倍概率，比较得到阈值十分之一。该计算假定概率针对部署总体且成本结构如题设；若有审核容量、收益非线性或群体成本不同，最优行动可能不是同一个全局阈值。利用有限行动集挑选阈值仍有选择不确定性，应报告样本规模与独立测试表现。

<a id="sec-7"></a>
## 10. 进阶研究练习与解析

<a id="sec-7-1"></a>
### 综合练习：判断收益是否来自搜索预算

**任务。** 某实验宣称高级融合比单模型提高两个百分点，但高级方法搜索二百个候选，单模型只用默认值；数据只有一千个对象，并且同一用户有多条记录。设计一个可以支持有限结论的复现实验，列出数据划分、预算规则、统计对象、报告内容与失败判断。

**详细解析。** 先明确部署面对新用户还是既有用户后续记录。若目标是新用户，所有同一用户记录必须在同一侧；若目标是未来记录，还要满足时间方向及特征可用时点。随机按行分割不能回答这两个任务。评价单位和成本汇总也应按用户或预定事件定义，避免记录多的用户无意占更大权重。

接着预先固定预算口径。可以各分配同样墙钟时间并记录硬件、并行度与失败运行；也可以各给适当的拟合次数，但要说明单次拟合成本不等。为单模型制定合理参数空间，为融合制定成员与元模型空间；所有前处理、特征筛选、早停和阈值都在对应开发边界内完成。候选数差异不是自动违规，隐瞒差异或从中推出普遍算法优势才是问题。

使用外层分组评价或独立最终用户测试，在每个外层训练部分内部独立执行整套搜索与融合。报告各预算点的表现、累计资源、模型大小和推理成本；外层测试只测预先规定的预算点，不能逐步查看后挑最佳停止点。各外层折训练数据重叠，不能简单把折均值当作若干独立实验来给极窄置信区间。

不确定性应尽量利用相同评价对象的配对损失差，而不是把两个成绩的独立误差条机械相减。有用户内相关时，可按用户聚合或按用户进行适当重采样。若样本太少导致区间很宽，结论应是证据不足以区分，而不是把不显著说成完全等价。若高级方法收益随预算优势消失，报告资源驱动解释；若仍稳定存在，也只支持当前任务、预算与协议下的收益。

<a id="ch4-10-2"></a>
### 10.1 推导对数损失融合的最优条件

**任务。** 对二分类概率凸组合 $`p_i(w)=\sum_mw_mp_{im}`$，写出训练负对数似然对权重的梯度，解释为何可能出现边界解，以及为何总体凸性不免除模型选择。

**解析。** 单样本损失对组合概率的导数是 $`\frac{(p_i-y_i)}{[p_i(1-p_i)]}`$，再乘成员概率得到对应权重的链式导数。对所有样本求平均后，加上单纯形约束的拉格朗日乘子与非负约束乘子。位于内部的活动成员满足相同的约束调整后梯度；边界成员只需要满足不能沿可行方向降低目标的条件。

损失对概率凸，概率对权重仿射，所以在开区间内目标凸。最优权重可能把某些成员完全舍弃；这并非优化失败，而可能是约束最优解。成员高度重复时，还可能有多组权重给出几乎同一概率。加入强凸正则有助于权重唯一与稳定，但同时改变最优问题。

训练目标凸只能帮助找到给定元训练数据上的全局解，不能保证该解最接近总体风险，也不能修复错误折外特征或先前调参泄漏。若使用同一小验证集反复更改成员，最终问题的候选集合已经适应了数据；应通过完整外部评价判断这套开发策略。优化误差、估计误差和选择误差是不同层面。

<a id="ch4-10-3"></a>
### 10.2 设计一个解释压力测试而不是只画漂亮图

**任务。** 在完整项目中加入近似重复列后，比较普通单列置换、两列联合置换和条件置换近似，并提出能够证伪错误解释的检查。

**解析。** 联合置换应对两列使用同一个随机排列，保留它们之间的配对关系，同时切断该组与其余对象及标签的联系；若分别独立乱排，就不是保留组内关系的组置换。条件近似可以按相关背景分箱，但必须报告每箱样本数与扰动幅度，检查生成副本的取值与相关结构。单列和联合结果的差异可能揭示冗余，也可能混入离分布效应，不能仅用差值定义真实交互。

同时训练一个明确不读取新增列的对照函数。如果条件归因仍给新增列贡献，先检查价值函数是否在分配代理信息；如果普通置换改变了这个对照函数输出，则实现存在错误。再用支持集外的极端不合法组合检验模型延拓对解释的敏感性。一个解释方法只有在问题与假设明确时才能被检验，反例和对照比彩色排名更有研究价值。

最终报告应同时附预测质量、解释对象、背景分布、输出尺度、扰动规则及稳定性范围。若只能证明“固定模型在这种输入扰动下的损失变化”，就直接写这个结论。将它扩大成现实干预建议，需要另外完成因果识别、可行操作与外部验证，而不是换一张贡献图。
