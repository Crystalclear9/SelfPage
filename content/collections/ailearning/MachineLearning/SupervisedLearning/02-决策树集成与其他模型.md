## 1. 树通过分裂逐步细分空间

<a id="detail-1"></a>

### 1.1 从规则到分段函数

二叉决策树在内部节点选择一个条件，例如年龄是否不超过某阈值，把到达该节点的样本分为左右两部分；叶节点给出常数预测、类别或概率。预测新样本时从根开始逐个判断，直到落入叶。单条路径是一组条件的交集，整棵树则把输入空间划成互不重叠的区域。

对数值变量使用轴对齐切分时，每个叶区通常是若干矩形条件的组合。回归树可以写为 $`f(x)=\sum_{m=1}^M c_m\mathbf1\{x\in R_m\}`$，叶区 $`R_m`$ 由树结构决定，叶值 $`c_m`$ 由该区训练目标估计。它不是一条全局平滑曲线，边界处可以跳变；表达复杂关系依赖更多分区或更合适的特征。

树天然包含交互。若先按地区分裂，再只在某地区按收入分裂，收入规则就依赖地区。深度限制决定一条路径最多组合多少条件，但“深度等于交互阶数”只能作为结构直觉：重复同一变量、相关表示与多棵树的加法都会影响实际函数。解释时应看完整路径，而不是只看节点名称。

<a id="detail-2"></a>

### 1.2 为什么树会不稳定

树的阈值与变量由候选之间比较得到。如果两个根分裂收益接近，少量样本变化就可能交换赢家，随后各子节点看到的数据不同，整棵树结构随之改变。预测在大部分区域也许相近，但某些边界会明显变化。深树又会对小叶中的少量标签敏感，因此单树常具有较高估计波动。

这种不稳定并不意味着树没有价值。它可以适应异质关系、混合变量与局部交互，而且许多表格任务不需要平滑外推。需要的是通过叶大小、深度、剪枝、样本量和集成控制，而不是仅凭“可解释规则”认为它一定稳健。一个有几百个叶的树也未必容易被人完整理解。

<a id="sec-1-1"></a>
### 基础算例：一次树分裂减少多少不纯度

四条标签为零、零、一、一，父节点正类比例二分之一，Gini 为 $`1-(\frac{1}{2})^2-(\frac{1}{2})^2=\frac{1}{2}`$。若某阈值将两个负例与两个正例分开，加权子不纯度为零，收益二分之一；若左右各含一个正例一个负例，收益为零。权重应按子节点样本量或规定样本权重计算，不能简单平均不等大的子节点。

这个计算只评价当前一层。一个收益较小的根分裂可能为下一层创造更好组合，一个收益较大的根也可能阻碍有限深度下的最终结构。标准贪心树没有枚举所有深度受限树，所以局部最优不等于全局最优。后面用异或反例进一步说明。

<a id="deep-dive-1"></a>
### 深入讲解：树的局部分裂与集成的整体效果为什么不同

单树训练不断选择当前收益最大的局部细分。集成则改变最终函数的组合方式：平均许多随机树可以平滑结构选择波动；顺序加入小树可以在当前函数基础上纠正损失方向。单树分裂收益并不直接等于集成新增一棵树对总体风险的改善，更不等于部署成本收益。

同样一棵浅树，在随机森林中是完整随机估计器，在提升中是一个增量方向。它们接受的目标、训练样本权重和最终缩放可能不同。理解这一点后，才能正确解释深度、树数和学习率；仅把所有树模型放在同一张参数表里比较，会忽略优化对象差异。

<a id="visual-supervisedlearning-02"></a>
### 图解：一次切分怎样改变空间与叶子纯度

![十二个样本的空间分区、叶子类别计数与 Gini 收益](images/02-concept.svg)

先只看空间中的十二个观测：圆点为正类、三角形为负类。竖线 $`x_1=0`$ 把整个特征空间划成两片，第二个特征不参与这次判断。左边五正一负，右边一正五负；右图仍使用这十二个对象，但把阈值从左向右移动，计算全部相邻不同第一坐标之间的加权 Gini；短水平段表示在同一间隙内移动阈值不改变训练归属。背景仅表示这两片决策区域，多数类预测会把每片中的一个少数类样本分错，总训练错误率为 $`\frac{2}{12}=\frac16`$。

根节点正负各半，所以 Gini 为 $`\frac12`$。两个叶子的类别比例互换，但纯度相同，均为 $`1-(\frac56)^2-(\frac16)^2=\frac5{18}`$。两片各六个对象，按样本数加权之后仍为 $`\frac5{18}`$，收益为 $`\frac12-\frac5{18}=\frac29`$。橙点只评价指定的零阈值，它并非这组数据的最佳候选。右图绿点为 $`t=0.45`$：左叶六正一负，右叶五条均负，所以两叶加权 Gini 是 $`\frac7{12}\cdot2\frac67\frac17=\frac17`$，收益 $`\frac12-\frac17=\frac5{14}`$。图中只要求左右非空，没有额外最小叶大小限制；加入叶约束后，应先删去不合法候选再比较。由此可以分清“给定阈值的效果”与“在训练候选中贪心搜索的结果”，二者都还不是独立测试风险。

继续切分可能把少数类隔离成更纯的叶子，但样本纯度和独立风险不是同一个量。这十二点只能提供当前训练分区的证据；是否泛化更好仍须通过独立数据检查。实际训练还需在训练集内部选择最小叶大小、深度、缺失处理与剪枝规则。

<a id="classification"></a>
## 2. 分类分裂：纯度、概率与损失

<a id="detail-3"></a>

### 2.1 Gini 的两个解释

节点类别概率为 $`p_1,\ldots,p_K`$，Gini 为 $`1-\sum_kp_k^2`$。它在纯节点为零，在各类均匀时较大。可以理解为从该节点类别分布独立抽取两个标签时，它们不同的概率；也等于最优常数概率向量下的多类平方损失期望，规范差异会影响常数。

具体地，对独热标签 $`Y`$ 报告向量 $`q`$，平方损失 $`\sum_k(Y_k-q_k)^2`$ 的条件期望为 $`1-2p^\top q+\Vert q\Vert ^2`$，在 $`q=p`$ 时最小，值为 $`1-\Vert p\Vert ^2`$。因此 Gini 不只是视觉上的纯度数字，也与叶内概率平方评分联系。它不等于最终硬分类错误率。

<a id="detail-4"></a>

### 2.2 熵与分类错误为何不同

熵为 $`-\sum_kp_k\log p_k`$，对应叶内最优常数概率的交叉熵。零比例项按极限取零。分类错误不纯度则为 $`1-\max_kp_k`$，只关注最大类比例，对某些概率变化不够敏感。不同准则可能选择不同切分，不能把它们都描述为直接最大化测试准确率。

例如二分类节点正类比例从零点六变零点八，Gini 从零点四八降至零点三二，熵也下降；如果两个子节点多数类相同，硬类别可能完全不变，但概率分辨力已经改变。用概率损失训练与用错误率评价可以各有意义，应说明目标与最终用途。

<a id="detail-5"></a>

### 2.3 一次不等大分裂的完整计算

父节点六条，四正两负，Gini 为 $`1-(\frac{4}{6})^2-(\frac{2}{6})^2=\frac{4}{9}`$。候选甲左侧两条均正，右侧四条两正两负，子加权不纯度为 $`(\frac{2}{6})\times0+(\frac{4}{6})\times\frac{1}{2}=\frac{1}{3}`$，收益 $`\frac{1}{9}`$。候选乙左右各三条，分别两正一负，子不纯度仍为 $`\frac{4}{9}`$，收益零。这里候选甲更好。

若错误地把甲的两个子不纯度简单平均，会得到四分之一，夸大收益。样本权重存在时，以总权重比例替代数量比例；类权重又会改变节点概率的目标分布。树叶输出的概率因此可能是加权概率，而非原总体概率，需要在评价中核对。

<a id="detail-6"></a>

### 2.4 小叶概率为何容易过度自信

叶中只有一个正例时，经验正类比例是一，但不能由一条观察断言该区域真实概率为一。深树把训练样本分得很纯，可能主要拟合随机标签。增加最小叶样本、平滑、剪枝与集成有助控制，但最终概率质量仍需独立校准和评分。

叶概率也依赖分区选择：分区本身用标签寻找，因此不能把选定叶里的比例简单当作事先固定区域的无偏估计。若进行推断，需要处理自适应划分；某些诚实树方法将划分与叶估计使用不同样本，牺牲部分数据效率换取更清晰的分析。此处先认识到选择与估计的依赖，避免把训练叶频率视作精确真值。

<a id="regression"></a>
## 3. 回归分裂：从叶均值推导收益

<a id="detail-7"></a>

### 3.1 叶内最优常数

在一个节点内最小化 $`\sum_i(y_i-c)^2`$，求导得到 $`c=\bar y`$。所以给定叶区，平方损失回归树的叶值为目标均值。绝对损失则对应中位数，分位数损失对应相应分位数。换损失会改变叶值与分裂评价，不只是改变名字。

对任意划分，父平方和可拆成子内平方和与子均值相对父均值的组间平方和。设左右数量为 $`n_L,n_R`$、总数 $`n`$，均值为 $`\bar y_L,\bar y_R`$，则减少量为

$$
\Delta=\frac{n_Ln_R}{n}(\bar y_L-\bar y_R)^2.
$$

推导时把每个 $`y_i-\bar y`$ 写成 $`y_i-\bar y_g+\bar y_g-\bar y`$，组内残差和为零，交叉项消失。这个公式说明收益同时依赖均值差与组大小，不能只选两个均值差最大的分裂而忽略支持量。

<a id="detail-8"></a>

### 3.2 完整数值例子

输入按大小排序为一、二、三、四，目标为一、二、八、九。父均值五，平方和为 $`16+9+9+16=50`$。阈值二点五将左右分成目标一、二与八、九，叶均值一点五与八点五，子平方和各零点五，合计一，收益四十九。组间公式给出 $`(2\times\frac{2}{4})\times7^2=49`$，结果一致。

阈值一点五时左叶只有目标一，右叶均值 $`\frac{19}{3}`$，右平方和为 $`\frac{86}{3}\approx28.6667`$，收益 $`\frac{64}{3}\approx21.3333`$。这次二点五更优。若规定每叶至少两条，一点五候选本来就不允许，复杂度约束可以在搜索前排除不可靠小叶。

<a id="detail-9"></a>

### 3.3 权重与稳健性

有正样本权重时，叶均值变为加权均值，组间公式中的数量替换为总权重。权重可能表示抽样校正、业务成本或测量精度，解释不同。极端目标在平方损失中影响很大，树可能专门隔离它；若它是记录错误，这种细分会浪费容量，若是合法关键事件，则未必应该压制。

稳健损失、裁剪和异常处理应由任务与数据机制决定。把所有大残差删掉会改变总体，也可能删除正想预测的稀有事件。可分别报告总体与尾部表现，核查标签和单位，再比较合适损失。树的非线性能力并不会自动赋予统计稳健性。

## 4. 搜索、停止与贪心限制

<a id="detail-10"></a>

### 4.1 数值切分为什么只需考虑相邻不同值之间

对某个节点的一列数值排序后，只要阈值在两个相邻不同值之间移动，样本左右归属不变，所以训练损失也不变。常用候选取中点，最多只需检查相邻不同值的间隙。重复值不能被阈值拆开，否则训练规则无法对相同输入给出一致归属。端点、浮点相等与缺失要有明确约定。

回归可以维护左侧计数、目标和、目标平方和，右侧由总量相减，快速计算各候选 SSE。分类可以维护类别计数。这样每次移动分界只更新少量统计量，不必反复重新扫完整左右集合。排序仍有代价，整棵树的实际复杂度依赖缓存、树形、稀疏性与候选策略，不能只给一个对所有实现都精确的时间公式。

<a id="detail-11"></a>

### 4.2 一个零局部收益却有完美深层结构的反例

两二元输入四种组合等概率，目标为异或：两值不同为一，相同为零。在根节点按任意一个单变量切分，左右各含一正一负，Gini 都为二分之一，所以当前收益为零。如果算法规定严格正收益才继续，就会停在根部。

但是允许先作一次零收益分裂，再在两个子节点按另一变量切分，深度二即可得到四个纯叶。这说明局部收益不是所有后续结构价值的充分统计量。标准贪心算法为了计算可行性牺牲了全局搜索能力，特征交互、随机化或不同生长规则可以改变结果。

这也解释为什么同一任务上稍微不同的停止条件可能产生显著差异。不能仅说“树能够表达异或”，就断言任何贪心训练都能找到它。表示能力、搜索规则和停止条件必须分开。

<a id="tree-xor-interaction"></a>

### 图解推导：为什么再多树桩也补不出异或

![异或四角在单变量切分后仍混合，深度二组合切分才得到纯叶](images/02-xor-interaction.svg)

图左先固定 $`x_1`$：两侧的标签都是一零各半，当前 Gini 收益确实为零。图右继续在各侧判断 $`x_2`$，便可把四种组合分别送入纯叶。它不是“第一次切分已经发现类别差异”，而是第一次建立了条件，第二个变量的作用才随该条件改变。

进一步看第 15.17 节的树桩限制。任意多个单变量树桩的分数和，都可以归并成 $`F(x_1,x_2)=u(x_1)+v(x_2)`$，因此必有

$$
F(0,0)+F(1,1)=F(0,1)+F(1,0).
$$

若用零作为二分类阈值，并要求两个异或正角的分数严格为正、两个负角严格为负，那么左侧为负、右侧为正，矛盾。任意固定阈值都可通过减去常数改写成这个形式。即便约定零分归正类，正侧之和非负而负侧之和严格为负，仍不可能；把零分归负类同理。问题是加性模型族缺少交互，而不是训练轮数不够。加入合适交互特征，或允许深度二的小树，才改变可表达的函数集合。

真实树实现可能允许零收益分裂，也可能因最小收益、随机候选或数值容差停止，因此不能把这个反例写成“所有 CART 默认一定失败”。它分别核对表达能力、局部搜索和停止规则。树模型及其类别分裂约定可结合 [scikit-learn 官方决策树说明](https://scikit-learn.org/stable/modules/tree.html)核对。

<a id="detail-12"></a>

### 4.3 深度、叶大小与最小收益控制不同对象

最大深度限制一条路径的长度；最小叶样本限制局部估计支持量；最小分裂样本限制哪些节点有资格尝试；最小收益限制一次细分的训练改善。它们相互作用，但并不完全等价。一个浅树可能拥有很小叶，一个深树也可能因叶大小而无法细分。

类别或目标不平衡时，纯度收益可能倾向大群体。类权重和成本敏感策略可以改变目标，但输出概率含义随之改变。不能只增大正类权重后仍以原始概率解释叶频率。若需要固定审核容量，还应在最终系统层评价排序与阈值，而不是只关注树内部准则。

<a id="detail-13"></a>

### 4.4 候选搜索本身会适应噪声

一列连续变量有很多候选阈值，纯噪声也可能在其中找到一个偶然较好的切分；高基数类别同样提供更多选择。树内不纯度重要性累计这些训练收益，因此可能偏好拥有更多切分机会的特征。它衡量的是当前训练结构中的收益，不是独立泛化贡献。

增加最小叶支持、限制候选、独立验证和剪枝可以缓解，但不能让选择变成没有代价。报告高重要变量时需要检查生成机制、稳定性与相关变量。更完整的置换和局部解释将在第四章讨论，本章先明确训练收益与外部证据之间的距离。

<a id="pruning"></a>
## 5. 生长与剪枝

<a id="detail-14"></a>

### 5.1 预剪枝与后剪枝的不同路线

预剪枝在生长时限制深度、叶支持或最小收益，计算较省，但可能提前阻断需要中间步骤的结构。后剪枝先长较大树，再删除不值得保留的子树，能够比较已经形成的组合结构，却需要更多训练与选择成本。两种方式都引入偏好，没有普遍一方总优。

训练误差随分裂通常不增，因为不分裂的常数预测在分裂后仍可被左右使用同一个值实现；在重新优化叶常数时只会更好或持平。验证误差不具备相同单调性，因为更细分区也更容易估计噪声。后剪枝正是在训练改善与结构成本之间作明确折中。

<a id="detail-15"></a>

### 5.2 代价复杂度目标

令 $`R(T)`$ 为训练上的损失汇总，$`\vert L(T)\vert `$ 为叶数，定义 $`R_\alpha(T)=R(T)+\alpha\vert L(T)\vert `$。这里损失是总和还是平均会改变 $`\alpha`$ 的尺度。对一个内部节点 $`t`$，其整棵子树有 $`m`$ 个叶，子树损失为 $`R(T_t)`$；将它折叠成单叶后损失为 $`R(t)`$。

保留子树相比折叠的净好处由 $`R(t)-R(T_t)-\alpha(m-1)`$ 决定。两者平局时的有效惩罚为 $`\alpha_t=\frac{[R(t)-R(T_t)]}{(m-1)}`$。这给出弱链接剪枝的局部计算：寻找每个新增叶平均带来最少训练收益的子树，按相应临界值逐步折叠。完整算法需要在每次折叠后更新祖先量，而不是一次把初始排序机械用到底。

<a id="detail-16"></a>

### 5.3 三叶子树的手算

某子树三叶的训练 SSE 合计十二，折成一个叶后 SSE 为二十。两种目标分别为 $`12+3\alpha`$ 与 $`20+\alpha`$，临界值为四。若 $`\alpha=2`$，保留目标十八、折叠二十二，保留；若 $`\alpha=5`$，两者二十七与二十五，应折叠。

这个决定只针对给定训练损失与惩罚。最终 $`\alpha`$ 需要开发验证或适当外层程序选择，不能用测试反复挑最佳子树。不同折生长的初始树可能不同，因此评价剪枝流程时应在各训练折重新生长，而不是把全表学到的整棵树交给各折仅调剪枝参数。

<a id="detail-17"></a>

### 5.4 为什么更小树仍可能不可靠

较少叶通常更容易审查、预测更省，但如果关键分裂来自泄漏字段或短期来源代理，小树也会失效。树规则可读并不等于规则有因果意义。反之，较大集成虽然难以逐条阅读，可以通过合法评价与行为检查获得有用证据。

结构大小只是模型选择的一个维度。还要看外部误差、关键群体、概率质量、服务资源与可维护性。不要把剪枝后的规则列表当成现实机制已经被发现，而应把它当作当前数据与目标下的压缩预测方案。

<a id="features"></a>
## 6. 特征、缺失与测量边界

<a id="detail-18"></a>

### 6.1 单调变换何时不改变训练分区

对单个数值特征作严格递增变换，训练样本排序不变，因此能够实现相同训练左右分组；若采用精确候选搜索和相同规则，许多树结果可保持。严格递减也保留相反顺序，可以交换左右。但分箱、有限精度、随机阈值、缺失和实现细节可能改变结果，不能简化成“树对任何变换都不敏感”。

即使训练分组相同，未见点的阈值位置也可能不同。原坐标中点再变换，不一定等于变换后中点，所以落在两训练值之间的新样本可能被不同分派。这是训练排序等价与所有输入函数等价的区别。影响大小取决于测试分布在两条阈值之间分配了多少概率质量，没有只依赖训练排序的统一小误差保证。

<a id="visual-midpoint-transform-gap"></a>

### 机制算例：训练排序不变，为何部署分歧仍可达到百分之百

![单调变换保持训练排序但不保证未见点预测相同](images/02-midpoint-transform-gap.svg)

图中只训练一个二分类树桩，数据为 $`(x,y)=(1,0),(9,1)`$，无样本权重、缺失或并列候选。若实现把相邻不同特征值的算术中点作为阈值，原坐标得到 $`t=\frac{1+9}{2}=5`$。两片叶各有一个纯类样本，所以规则是 $`x\le5`$ 预测零，其余预测一，训练误差为零。此处“中点”不是由观察证明的真实类别边界；从训练损失看，区间 $`[1,9)`$ 内任何阈值都产生同一训练分区，中点只是实现选择的代表。

现在对正数特征作严格递增变换 $`z=\log x`$，重新训练同样的树桩。排序与训练标签完全没变，但新阈值为 $`t_z=\frac{\log1+\log9}{2}=\log3`$。将判断条件映回原坐标，得到 $`x\le3`$ 预测零，其余预测一。图中两条横轴都使用原始 $`x`$，便于直接比较：新样本 $`x=4`$ 在第一棵树中落左叶，在第二棵树中落右叶；两个模型的训练成绩一样，预测函数却不同。这与浮点舍入无关，在精确实数运算下也成立。scikit-learn 1.8.0 的单次树桩核对会得到原阈值 $`5`$、对数阈值约 $`1.09861231`$，映回约为 $`3.00000006`$；末尾微小差异来自浮点表示，不能用它解释从三到五的主要差异。[固定版本的分裂器源码](https://github.com/scikit-learn/scikit-learn/blob/1.8.0/sklearn/tree/_splitter.pyx)明确实现了相邻值中点及其数值保护分支。

**差异影响多大，由测试分布决定。** 两个预测函数在 $`3<x\le5`$ 上相反，在其余位置相同，因此精确实数模型的预测分歧率为 $`P_{\rm test}(3<X\le5)`$。若测试点全在该区间，分歧率就是一；若该区间没有测试质量，分歧率才为零。这里讨论的是两个预测之间的分歧，尚未指定真实标签，不能据此宣布哪棵树更准确。对于同一测试联合分布上的零一风险，逐点有 $`|\mathbf1\{f(X)\ne Y\}-\mathbf1\{g(X)\ne Y\}|\le\mathbf1\{f(X)\ne g(X)\}`$，所以风险差的绝对值不超过上述分歧概率。若整个分歧区真实标签都是零，这个上界可以取到：原坐标树全对，对数坐标树全错。

更一般地，相邻训练值为 $`a<b`$、严格递增变换为 $`g`$ 时，两种规则的原坐标边界分别是 $`\frac{a+b}{2}`$ 与 $`g^{-1}\!\left(\frac{g(a)+g(b)}{2}\right)`$。正斜率仿射变换使二者相同；对数变换在正半轴把第二个变成几何平均数 $`\sqrt{ab}`$。若对给定区间内任意两点都要求连续变换保持中点，它受到比“严格递增”更强的限制。反过来，若**不重新训练**，而把已训练的阈值五直接变换为 $`\log5`$，旧判断与新坐标判断严格等价。学习算法重新选代表阈值，与对一个已确定函数作坐标改写，是两项不同操作。使用树模型时应保存训练时的变换与阈值，必要时检查训练点间空隙的预测，而不是从训练排序不变推断任意部署输入都不变。

<a id="detail-19"></a>

### 6.2 类别编号不能随意当连续量

类别编号一、二、三会让轴对齐阈值只产生连续编号段，任意重新编号可能改变可用分组。独热允许按某个类别与其余分开，但要组合多个类别可能需要更多节点；原生类别分裂则需要定义如何搜索子集及处理高基数。不同实现的模型族与成本并不相同。

这个排序捷径可以在一个明确问题下证明：固定节点中的类别特征，使用平方误差、正样本权重和两个常数叶值；允许每个类别整体分入任一叶，不附加会耦合类别分配的约束。对类别 $`c`$，记总权重为 $`W_c>0`$、加权目标均值为 $`\mu_c`$、类内平方和为 $`H_c`$。若它被送入预测为 $`a`$ 的叶，则

$$
\sum_{i:x_i=c}w_i(y_i-a)^2=H_c+W_c(\mu_c-a)^2.
$$

所有 $`H_c`$ 的和与类别分组无关，问题因此等价于把带权的一维点 $`\mu_c`$ 分成两个平方误差簇。设某个最优分裂的叶值为 $`a<b`$。固定这两个值后，类别应该整体选择较近的叶，因为比较 $`W_c(\mu_c-a)^2`$ 与 $`W_c(\mu_c-b)^2`$，正权重约掉，分界恰好为 $`\frac{(a+b)}{2}`$。若原最优分裂不遵守最近叶值规则，重新分配再更新两个叶均值不会增加目标。

因此存在一个按 $`\mu_c`$ 排序后作连续切分的最优解，枚举相邻类别间的切点即可。若两个叶值相同，则退化为无组间均值收益的情形，排序切分仍可达到同一最优值；同均值类别的并列按固定规则处理。

手算三个类别：A 有两条目标零，B 有一条目标三，C 有一条目标十，权重都为一。均值顺序为零、三、十，类内平方和均为零。切成 A 与 BC，右叶均值为 $`6.5`$，平方和为 $`24.5`$；切成 AB 与 C，左叶均值为一，平方和为六。看似还需枚举的非连续切分 AC 与 B，AC 叶均值为 $`\frac{10}{3}`$，平方和为 $`\frac{200}{3}`$，显然不能胜过六。排序不是把类别编号当数值，而是利用当前节点、当前训练标签估计出的目标均值来消除无须搜索的子集。

这个结论的条件也限定了用途。正权重本身不破坏上述证明，应使用加权均值；但最低叶权重、群体比例等额外约束可能使“每类独立选较近叶”不可行，需要重新分析。多分类目标不再是一维标量均值，不能直接套这条证明。排序还使用标签，属于节点训练过程，必须在允许的训练折内重新估计；不能先用全表目标排类别顺序，再声称后续交叉验证没有泄漏。

<a id="detail-20"></a>

### 6.3 缺失路径也是模型假设

可以先填补并加缺失指示，也可以在训练时学习缺失走左还是右，或使用其他专门策略。关键是线上要复用相同规则，未知类别和缺失原因变化也要评价。一个库支持某类缺失，不代表所有树模型都原生支持同样语义。

缺失本身可能编码设备、来源或业务流程，有时预测有用，有时跨时间脆弱。对缺失样本单独报告，检查真实零与未知是否混合。算法能接受空值，只解决接口可执行性，不自动解决缺失机制偏差。

<a id="bagging"></a>
## 7. Bagging 的统计机制

<a id="detail-21"></a>

### 7.1 从一份数据产生多次扰动

Bootstrap 从 $`n`$ 条训练记录有放回抽取 $`n`$ 次，每棵树使用不同重采样。某记录一次都没被抽到的概率为 $`(1-\frac{1}{n})^n`$，大样本趋于 $`e^{-1}\approx0.3679`$；因此单个重采样中不同记录的期望占比约为零点六三二一。抽取次数仍为 $`n`$，只是包含重复，不是只抽百分之六十三且不重复。

基模型不稳定时，重采样会产生不同函数，平均可以平滑波动。若基模型对样本扰动几乎不变，Bagging 的额外收益可能小。它也不是增加了独立原始信息，所有树仍来自同一训练表；重复抽样不能补齐原本缺少的群体。

<a id="detail-22"></a>

### 7.2 条件随机性与数据随机性

固定训练集 $`D`$ 后，树随机性为 $`U`$，森林平均 $`B`$ 棵独立随机化树。条件于 $`D`$，平均预测方差为 $`\frac{\operatorname{Var}_U(T\mid D)}{B}`$。但若研究重新抽训练集后的总方差，全方差公式还包含 $`\operatorname{Var}_D(E_U[T\mid D])`$，这一项不会因为无限复制同一数据上的随机树而消失。

所以无限树数主要消除森林自身的蒙特卡洛波动，不等于总体风险趋零。偏差、训练数据波动、噪声与分布变化仍然存在。这个条件分解比“每棵树独立，所以无限平均得到完美模型”更准确。

<a id="detail-23"></a>

### 7.3 等相关近似的完整计算

若无条件各树预测方差为 $`v`$、两两协方差为 $`c`$，平均方差为 $`\frac{[Bv+B(B-1)c]}{B^2}=c+\frac{(v-c)}{B}`$。写 $`c=\rho v`$，得到 $`v[\rho+\frac{(1-\rho)}{B}]`$。它是一种易解释的简化，实际树不必拥有完全相同的方差与协方差。

取 $`v=4,\rho=0.25`$，十棵树平均方差为一点三，一百棵约一点零三，极限为一。把树从十增到一百改善零点二七，而把相关性降到零点一、保留十棵树，方差约零点七六。降低相关性可能更重要，但随机化过强也可能使单树能力变差，不能只优化相关系数。

<a id="detail-24"></a>

### 7.4 袋外预测如何产生

对每条训练记录，只聚合没有抽到它的树，得到袋外预测。该样本没有直接进入这些树的 bootstrap 拟合，因此可用于一种内部外部化评价。有限树数下每条记录可用树数量不同，尤其树很少时不稳定，应该检查覆盖。

若先在全数据用标签筛特征，再训练森林，袋外样本标签仍已影响筛选，袋外估计不再覆盖这个选择流程。若有同一用户多条记录，只排除一条而保留其近重复也可能不符合新用户评价。袋外不是绕过完整信息边界的特权，应按任务决定是否还需要分组、时间或独立测试。

### 图解算例：相关误差限制 Bagging 的方差收益

![相关误差限制 Bagging 的方差收益](images/02-example.svg)

假设各成员误差方差均为一，任意两成员的相关系数相同，简单平均后的方差为相关系数加上剩余部分除以成员数。独立误差随成员数增长而显著减小，高相关误差则接近明显高于零的平台。这里分析的是方差分量，不包括共同偏差；成员变多并不能消除所有系统性错误。等方差、等相关和等权平均只是可手算假设，真实森林与其他集成的依赖结构更复杂，仍需在独立数据上评价风险、概率质量及计算成本。

## 8. 随机森林与梯度提升

<a id="detail-25"></a>

### 8.1 随机特征选择的作用

普通 Bagging 中，一个特别强的变量可能几乎总被选为根，导致树相似。随机森林在节点候选特征上随机选择子集，让其他可用结构也有机会参与，降低某种共同波动。它同时可能错过强分裂，所以需要平衡单树强度与相关性。

候选特征数量小，随机性更强但单树可能更弱；数量大，单树更接近全特征树但相关可能更高。合适值依赖信号稀疏度、冗余变量和任务，不应把一个常见默认值视为理论最优。更随机阈值等变体又改变搜索偏好和计算成本，应比较具体实现。

<a id="sec-2-1"></a>
### 机制展开：Bagging 与 Boosting 使用不同组合逻辑

森林的各树可在给定训练集和随机种子后并行拟合，最终平均或投票；提升的下一步取决于当前集成预测，通常具有明确序贯依赖。增加森林树数主要提高平均近似精度，增加提升轮数则推进拟合函数，可能继续追逐噪声。

但这不是“森林绝不过拟合、提升一定过拟合”的普遍定理。森林的深度、叶大小、采样和特征规则仍控制泛化，有限树曲线也会波动；提升在合适收缩和正则下可以表现稳定。应根据机制解释参数，而非给模型名称贴永久标签。

<a id="detail-26"></a>

### 8.2 投票与概率平均不完全相同

分类森林可以聚合各树硬类别，也可以平均叶概率再取最大类，二者可能不同。三个树报告正类概率零点五一、零点五一、零，硬投票选正类，概率平均约零点三四则选负类。哪一种实际使用，应查看模型接口，而不是只说“多数投票”。

平均概率也不自动保证校准。每棵树的分区、叶大小和训练选择影响概率偏差，平均只能改变其中一部分。应分别评价排序、概率与行动成本。对类权重、重采样改变的训练目标，还要重新解释输出概率。

<a id="boosting"></a>
## 9. 梯度提升的逐步推导

<a id="detail-27"></a>

### 9.1 在训练点上的函数空间下降

令当前函数为 $`F_{m-1}`$，训练目标为 $`\sum_i\ell(y_i,F(x_i))`$。对每个训练预测值求负导数，得到伪残差 $`r_{im}=-\frac{\partial\ell(y_i,F_i)}{\partial F_i}`$。这在训练点组成一个下降向量；基学习器族未必能精确表示它，因此训练一棵树去近似该方向。

选定树结构后，可以进一步沿该方向或在各叶内优化步长，再乘收缩学习率 $`\nu`$ 更新。把树拟合到伪残差，与最终叶值求解是两个相关但可分开的步骤。不同算法可能使用一阶、二阶、逐叶线搜索或近似，不能一概说每轮都直接平均原标签。

<a id="detail-28"></a>

### 9.2 平方损失的完整两轮算例

使用半平方损失，初始最优常数为均值。对目标一、二、八、九，$`F_0=5`$，伪残差为负四、负三、三、四。用阈值二点五的树桩拟合，左右叶值为负三点五、三点五。取学习率二分之一，得到第一轮预测三点二五、三点二五、六点七五、六点七五。

第一轮残差为负二点二五、负一点二五、一点二五、二点二五，SSE 为十三点二五，低于初始五十。第二轮同一结构叶均残差为负一点七五、正一点七五，再乘二分之一更新，预测变成二点三七五、二点三七五、七点六二五、七点六二五，SSE 为四点零六二五。

若第一轮学习率为一，直接得到一点五与八点五的叶均值，SSE 为一。小学习率在这个固定结构例子中只是更慢靠近相同叶均值；在真实序贯搜索中，较小步长会改变下一轮残差与结构，所以不一定只是把迭代数按比例延长就完全等价。

<a id="detail-29"></a>

### 9.3 二分类必须区分 logit 与概率

对伯努利交叉熵，若函数 $`F`$ 表示 logit，概率为 $`p=\sigma(F)`$，负梯度为 $`y-p`$。不是 $`y-F`$，也不是把残差当作下一轮的二元标签。初始常数若正类比例在零一之间，最优 logit 是训练正类赔率的对数。

例如四个有序样本标签零、零、一、一，初始 logit 零，概率均二分之一，伪残差为负二分之一、负二分之一、二分之一、二分之一。一个完美分组树桩拟合这些值，学习率一后 logits 为左右负零点五、正零点五，对应概率约零点三七七五与零点六二二五，平均损失约零点四七四一。

概率没有直接增加二分之一，因为更新发生在 logit 空间。若错误地把新树输出当概率相加，可能得到负数或超过一，也会改变目标。训练接口、输出尺度与叶更新公式必须一致。

<a id="detail-30"></a>

### 9.4 叶值的一阶与二阶更新

设某叶内已有分数 $`F_i`$，对共同增量 $`\gamma`$ 最小化 $`\sum_{i\in L}\ell(y_i,F_i+\gamma)`$。平方损失得到平均残差；对逻辑损失，一阶条件是 $`\sum_{i\in L}[\sigma(F_i+\gamma)-y_i]=0`$，一般需要数值解。如果该叶全为正例，无正则最优增量可能趋正无穷，不能假装总有有限解析均值。

在零增量处作二阶近似，可得 Newton 型增量 $`-\frac{\sum_i g_i}{\sum_i h_i}`$，其中 $`g_i=p_i-y_i`$、$`h_i=p_i(1-p_i)`$。二次正则会在分母增加相应项。这是局部近似，不等于精确线搜索；当 Hessian 很小、叶很小或标签极端时，需要收缩与约束控制。高级二阶提升的结构评分留待第四章继续研究。

<a id="detail-31"></a>

### 9.5 学习率、树深、采样与早停相互作用

深度更大，单轮能够捕捉更复杂交互；学习率更小，单轮改变更缓；随机采样可能降低计算和某些依赖，也引入额外波动；迭代数决定走多远。固定一个参数解释另一个的作用，只适用于相应条件。小学习率不是免费的泛化保证，因为需要更多树与推理成本。

早停通过开发验证选择迭代数，是模型选择的一部分。测试集不能逐轮参与挑最优。若最终用更多开发数据重训，需要事先规定轮数或新的内部停止方案。提升可以在噪声标签上持续降低训练损失，最终是否有价值必须由合适外部评价判断。

<a id="visual-insight-supervisedlearning-02"></a>
### 深入图解：弱学习器沿残差方向修正当前拟合

![弱学习器沿残差方向修正当前拟合](images/02-insight.svg)

上下两排追踪同一组四点，横向顺序始终不变。观测值为 $`y=(1,3,2,4)`$，初始常数预测为 $`F_0=2.5`$，所以上排的残差是 $`(-1.5,0.5,-0.5,1.5)`$。橙色线段从零出发，显示残差的方向和大小；蓝色两段常数是在指定分区内拟合出的平均残差，分别为 $`-0.5`$ 与 $`0.5`$。这里明确固定“前两点、后两点”的分区，没有声称它是所有树桩阈值中的最优解。

下排把树桩乘学习率 $`\eta=0.5`$ 再加回旧预测，得到 $`F_1=(2.25,2.25,2.75,2.75)`$。蓝色应当画成阶梯，不能把两个叶子的预测用斜线插值；灰色虚线是旧预测，黑点是真实观测，橙线是更新后的残差。总平方误差从五降到 $`4.25`$，但第二、第三个点的误差绝对值从 $`0.5`$ 增至 $`0.75`$。所以“整体训练损失降低”不等于“每个样本都更接近目标”。

<a id="sec-3"></a>
## 10. kNN 与支持向量机的比较位置

<a id="detail-32"></a>

### 10.1 不同方法各自偏好什么结构

树偏好轴对齐局部规则，线性模型偏好所选表示上的加性关系，近邻依赖度量下的局部相似，支持向量机用间隔与核范数约束分界。它们不是同一复杂度刻度上的前后版本。一个任务适合哪种偏好，取决于数据几何、合法信息、样本量和部署约束。

树通常不要求为切分排序而标准化，但近邻和 RBF 核对尺度明显敏感。类别与缺失处理也不同。公平比较允许各方法使用合理前处理，却要披露差异并纳入训练边界。不能故意不给近邻缩放，再把失败归因于模型本身。

<a id="detail-33"></a>

### 10.2 训练轻不等于查询轻

近邻训练可以主要保存数据，查询却要寻找邻居；核模型预测成本取决于支持向量数量和核计算；森林需要遍历多棵树；线性模型主要做点积。高吞吐、低延迟、批量与内存约束会改变选择。后章将给出核与近邻的完整推导，本章只建立共同决策框架。

<a id="sec-4"></a>
## 11. 如何公平比较与选择

<a id="detail-34"></a>

### 11.1 比较完整流程而非模型名称

固定任务、划分、主要指标与可用输入，再建立常数、现有规则和合理简单模型基线。各方案的预处理、特征选择、超参数与阈值均属于被评价对象。交叉验证时每折拟合完整流程，时间任务要尊重标签成熟与未来信息边界。

给候选可解释的搜索预算。可以比较同计算预算下表现，也可以各自充分调优但报告成本，两种结论不同。只给复杂模型大量试验而基线用明显不合适默认值，不能把分差全部归为模型结构。重复随机种子与配对评价帮助理解波动，但不替代独立测试。

<a id="detail-35"></a>

### 11.2 平均分之外的必要证据

同时查看主要人群、稀有事件、时间来源、概率质量与资源。树集成在总体上略好，可能在陌生实体或训练范围外更差；更复杂规则可能难以维护；较小模型可能已经满足全部约束。选择应把实际收益与增加的成本联系起来，而不是把章节更靠后的算法当作必然升级。

<a id="sec-5"></a>
## 12. 部署约束与外推限制

<a id="detail-36"></a>

### 12.1 路径长度、树数与存储

一棵平衡树单样本预测需要沿路径比较若干次，最坏情况取决于实际深度；森林总成本随树数与路径长度增长。叶数与节点存储影响模型体积，批量实现、缓存和并行方式又影响实际延迟。不能只按理论比较次数断言某个环境下必然更快，应在真实接口上测量。

过多树的微小分数收益可能不值得服务成本。可以考虑减少树数、限制深度、蒸馏或其他压缩，但每种改变都需重新验证最终输出与关键场景。压缩不自动保持概率与阈值行为，尤其接近决策边界时小差异也可能改变行动。

<a id="detail-37"></a>

### 12.2 版本包括数据路径

类别映射、缺失策略、单位与阈值要与模型共同发布。某训练库原生处理缺失，不代表导出接口也具备相同能力。可以用固定原始样例核对离线与服务的中间特征、分数和行动，覆盖未知类别、极值与回退。树规则可读也不能省去这种语义检查。

<a id="sec-6"></a>
## 13. 树模型的外推限制与进阶结构

<a id="detail-38"></a>

### 13.1 普通回归树为什么不会自动延长趋势

叶输出是训练目标均值，所以每个叶值位于相应训练标签范围内，整棵普通回归树预测位于训练目标最小最大值之间。随机森林是非负权平均，同样不自动超出整体训练标签范围。特征值超过已见范围时，仍沿阈值进入某个边缘叶，输出通常保持常数。

若训练 $`y=x`$、输入只在零到十，普通树对二十不会因为“学会非线性”就自然预测二十。它可能返回最高区间叶均值。时间趋势与物理规律任务应设置范围外测试，必要时结合趋势模型、线性叶或已知结构。随机范围内划分可能完全看不到这个限制。

<a id="detail-39"></a>

### 13.2 提升的输出范围与特征外推要分开

提升是多个叶值相加，最终输出可以超过原始标签范围，因此不能把森林的范围凸包结论原样套给提升。然而有限棵轴对齐常数叶树的和仍是分段常数函数；在某特征越过所有已学阈值之后，其他输入固定，预测也不会自动继续线性增长。

所以“能输出超过训练最大标签”和“能在输入范围外延续正确趋势”不是同一性质。加入显式时间或趋势特征也不保证普通树自然延长，除非模型结构和任务表达确实提供这种外推能力。应通过具体外部范围检验，而不是从模型名猜测。

<a id="detail-40"></a>

### 13.3 单调约束、线性叶与诚实估计

某些变体允许单调约束，使选定特征增加时预测不降低；这表达领域先验，可能提高稳定性，也可能在真实关系不单调时引入偏差。线性叶让区域内预测不再常数，能够改变局部拟合与外推，但需要额外样本支持并重新分析正则。

诚实估计将划分选择和叶值估计使用不同样本，降低标签自适应造成的依赖，常用于某些推断型森林研究。它不是所有森林都默认具备的性质，也不会凭空消除采样偏差。阅读进阶方法时应检查真正修改的是结构、目标、随机化还是推断条件。

<a id="sec-7"></a>
## 14. 进阶：CART 分裂与完整实验

<a id="sec-7-1"></a>
### 树的局部分裂与集成降低波动的机制

现在可以把学习链拆清：候选分裂减少训练局部损失，树生长与剪枝控制空间细分，Bagging 平滑重采样敏感性，随机森林进一步改变树相关，Boosting 沿损失方向构建加性函数。每一步的改善对象不同，不能把一个内部训练量直接当成总体风险保证。

例如回归分裂的组间平方和公式是精确代数；森林等相关方差是给定协方差结构下的计算；“某种随机化会改善当前任务”则是需要实验的经验命题。教材中的公式与工程建议有不同证据层级，使用时应明确它们的条件。

<a id="detail-41"></a>

### 完整可运行实验：手算分裂与库实现

下面只使用明确的一维数据核对单层树，并通过固定训练测试划分比较不同叶大小。前半有已知答案，后半是一个具体模拟，不表示某参数在所有任务最优。代码不写任何输出文件。

```python
import numpy as np
from sklearn.tree import DecisionTreeRegressor
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error

x = np.arange(1.0, 5.0).reshape(-1, 1)
y = np.array([1.0, 2.0, 8.0, 9.0])
stump = DecisionTreeRegressor(max_depth=1, random_state=0).fit(x, y)
assert np.isclose(stump.tree_.threshold[0], 2.5)
assert np.allclose(stump.predict(x), [1.5, 1.5, 8.5, 8.5])
assert np.isclose(np.sum((y - stump.predict(x)) ** 2), 1.0)

rng = np.random.default_rng(2026)
train_x = rng.uniform(-3, 3, size=(240, 1))
train_y = np.sin(train_x[:, 0]) + rng.normal(0, 0.25, size=240)
test_x = rng.uniform(-3, 3, size=(2000, 1))
test_y = np.sin(test_x[:, 0]) + rng.normal(0, 0.25, size=2000)

for leaf in [1, 12]:
    model = RandomForestRegressor(
        n_estimators=100, min_samples_leaf=leaf, random_state=7,
        n_jobs=1,
    ).fit(train_x, train_y)
    pred = model.predict(test_x)
    print("leaf", leaf, "test MSE", mean_squared_error(test_y, pred))
```

这份测试集仅用于展示固定的两种设置在模拟中的行为。如果根据它继续改变噪声、样本量和参数直到得到想要的排序，就进入了选择过程。真实项目应使用开发集选择，再用未参与选择的测试确认。随机种子固定帮助复现，但不能让一次模拟成为普遍定理。

这个模拟的标签噪声方差为零点零六二五，即使恢复了正弦条件均值，独立新标签的均方预测风险仍包含它。测试误差高于这个值的部分，才涉及有限样本、模型与求解的额外误差；一次有限测试也会围绕期望波动。

<a id="detail-42"></a>

### 森林也可以被理解为自适应的局部平均

对于普通均值叶回归树，给定已经学好的分区，预测是与查询落在同叶的训练目标平均。若 bootstrap 中某训练行重复出现，令它在第 $`b`$ 棵树的次数为 $`m_{bi}`$，该叶总次数为 $`N_b(x)`$，则森林可以写为 $`\widehat f(x)=\sum_i\alpha_i(x)y_i`$，其中 $`\alpha_i(x)=B^{-1}\sum_b\frac{m_{bi}\mathbf1\{x_i与x同叶\}}{N_b(x)}`$。权重非负、和为一，所以具有局部平均和范围凸包性质。

这些邻域不是预先固定的欧氏球，而是由特征与标签共同学习的树区。它与近邻的相似在于局部加权，不同在于度量和区域自适应。一个变量若频繁用于细分，会显著影响哪些样本共享叶；森林因此可以形成适合某些异质关系的相似性。

但是不能因为写成加权平均，就把它当作对标签线性的固定平滑器。重新改变标签后，分裂与权重也会变化。只有条件于固定分区，或使用特定独立划分设计时，相关线性计算才更直接。这个区别影响自由度、方差和推断，尤其不要把固定叶均值的简单标准误差原样用于高度自适应深树。

<a id="detail-43"></a>

### 旋转特征为什么可能显著改变树的效率

二维分界若为 $`x_1+x_2=0`$，一条斜直线可以精确表达。轴对齐树通常需要多个矩形阶梯逼近，有限深度下仍有边界误差。若加入特征 $`z=x_1+x_2`$，一个阈值就能表达。因此树虽不强依赖单列尺度，却可能强依赖坐标方向与表示。

旋转坐标没有增加原始信息，却改变了轴对齐分裂能够高效表达的函数。与线性模型的旋转性质相比，普通树的结构偏好更明显。是否使用投影、交互特征或斜分裂树，应由样本与预算验证，而不是认为树已经自动解决所有表示问题。

<a id="detail-44"></a>

### Gini 收益其实是两组类别概率的差异

设左侧权重比例为 $`a`$，右侧为 $`1-a`$，类别概率向量分别为 $`p_L,p_R`$，父概率为 $`p=ap_L+(1-a)p_R`$。把 Gini 定义代入，收益等于 $`a\Vert p_L\Vert ^2+(1-a)\Vert p_R\Vert ^2-\Vert ap_L+(1-a)p_R\Vert ^2`$。展开内积并合并，得到 $`a(1-a)\Vert p_L-p_R\Vert ^2`$。

二分类若只记正类概率，由于负类差与正类差大小相同，收益为 $`2a(1-a)(p_L-p_R)^2`$。这说明平衡分组与概率分离共同决定收益。两组概率相同则收益为零；一侧极小，即使概率差较大，整体收益也可能有限。前面六样本例子中 $`a=\frac{1}{3},p_L=1,p_R=\frac{1}{2}`$，公式给出 $`2\times(\frac{1}{3})\times(\frac{2}{3})\times(\frac{1}{2})^2=\frac{1}{9}`$。

熵收益也有精确解释：把左右分支记为二元变量 $`B`$，在当前节点条件下，父熵减加权子熵就是 $`I(Y;B)`$，即这次分支提供的类别信息。这里使用经验频率计算，搜索很多候选会选择较大的经验信息，即使真实关系弱也可能出现幸运值。信息解释不消除有限样本选择偏差，仍需要支持量与外部验证。

<a id="detail-45"></a>

### 条件独立的随机树为何仍有无条件相关

令两棵树在给定训练集后使用独立随机状态，条件均值都为 $`\mu(D)`$。全协方差公式给出 $`\operatorname{Cov}(T_1,T_2)=E_D[\operatorname{Cov}(T_1,T_2\mid D)]+\operatorname{Cov}_D(E[T_1\mid D],E[T_2\mid D])`$。第一项因条件独立为零，第二项为 $`\operatorname{Var}_D(\mu(D))`$。

因此“随机种子独立”与“重新收集数据时预测不相关”完全不等价。两棵树共享同一份训练数据，数据的共同偏移会一起传入它们。单树总方差为这个共同部分加平均条件随机方差，平均增加树数只减小后者，正与第七节的分解吻合。

这个推导还解释等相关公式中的下限来自哪里。在这组理想条件下，协方差非负；一般人为设计的模型误差可能存在更复杂甚至负相关结构，需要使用实际协方差矩阵，而不是强行套同一个随机森林故事。多样性研究应说明比较的是固定数据上的随机差异、重复数据上的预测差异，还是同一测试集的误差模式。

<a id="detail-46"></a>

### 一个可以看清叶大小折中的局部误差界

假设某叶的划分独立于用于估计叶值的标签，叶内有 $`k`$ 条条件独立记录，噪声方差至多为 $`\sigma^2`$，真实条件均值满足 Lipschitz 条件 $`\vert m(x)-m(x')\vert \le L\Vert x-x'\Vert `$。若查询与叶内样本距离至多为叶直径 $`d`$，叶均值的条件偏差绝对值至多为 $`Ld`$，噪声平均方差至多为 $`\frac{\sigma^2}{k}`$。

因此相对于条件均值的均方误差可由 $`L^2d^2+\frac{\sigma^2}{k}`$ 控制。叶更小通常让直径下降，却也减少支持；一致估计往往需要样本增多时区域逐渐缩小且叶支持同时增大，而不是永久固定大叶或永久单样本纯叶。这个简单界揭示空间分辨率与统计精度的双重要求。

普通 CART 用同一批标签选择划分，不能未经处理直接套上述独立划分条件；诚实样本分离正是一种让分析更清楚的设计。实际随机森林一致性还需处理分区随机、维度与采样等条件，不能凭这个局部界声称所有默认森林都已获得一般保证。

## 15. 分层练习与详细解析

<a id="detail-47"></a>

### 15.1 基础计算：Gini 与硬错误

**题目。** 节点十条，七正三负。计算 Gini、熵和多数类训练错误率。它们是否同一个数字，是否都直接等于未来误差？

**解析。** Gini 为 $`1-0.7^2-0.3^2=0.42`$，自然对数熵约零点六一零九，多数类错误率为零点三。前两者反映概率分布纯度，对应不同评分；最后一个只看硬类别。它们都由当前节点数据估计，而且节点经过标签自适应选择，不能直接当作未来精确风险。需要独立评价及足够叶支持。

<a id="detail-48"></a>

### 15.2 权重计算：不能简单平均子节点

**题目。** 父节点八条，左叶两条纯正，右叶六条三正三负。父 Gini、加权子 Gini 和收益分别是多少？

**解析。** 父有五正三负，Gini 为 $`1-\frac{25}{64}-\frac{9}{64}=\frac{30}{64}=0.46875`$。子不纯度为 $`\frac{2}{8}\times0+\frac{6}{8}\times0.5=0.375`$，收益零点零九三七五。简单平均得到零点二五，会夸大分裂价值。若有样本权重，则用总权重与加权类别比例，而非机械照用记录数量。

<a id="detail-49"></a>

### 15.3 回归推导：验证组间平方和

**题目。** 四条目标一、三、七、九，按前两条后两条分组。求父 SSE、子 SSE 与收益，并用组间公式核对。

**解析。** 父均值五，SSE 为十六加四加四加十六，共四十。左右均值二与八，各自 SSE 为二，合计四，收益三十六。组间公式给出 $`(2\times\frac{2}{4})(2-8)^2=36`$。这个等式是给定划分的代数，不证明该划分一定在其他特征候选中最优，更不证明验证误差下降同样多。

<a id="detail-50"></a>

### 15.4 搜索反例：零收益是否意味着无信息

**题目。** 异或数据在根上每个单变量收益零，能否删除两个变量并宣称它们都无用？如何构造一个更强对照？

**解析。** 不能，它们联合包含完整标签信息。允许深度二和必要的中间分裂，或者加入乘积等合适交互表示，可以恢复结构。可以比较纯贪心严格正收益停止、允许中间步骤的树和交互特征树，说明失败来自搜索与表示，而不是数据完全无信号。单变量筛选可能在学习开始前就删除必要变量。

<a id="detail-51"></a>

### 15.5 剪枝计算：损失规范会改变参数

**题目。** 某三叶子树 SSE 为十二，折成单叶 SSE 二十，训练总样本一百。若损失从总 SSE 改成平均 SSE，临界惩罚是否仍为四？

**解析。** 总和规范下临界为 $`\frac{(20-12)}{(3-1)}=4`$。平均规范下损失差为零点零八，临界变为零点零四。两者目标整体尺度不同，不能复制同一个参数数值。若权重总和替代样本数，还需按实际规范核对。剪枝原则相同，但参数的数值解释依赖损失单位。

<a id="detail-52"></a>

### 15.6 重采样计算：袋外概率不是没见过实体

**题目。** 训练十条，从中有放回抽十次，某条一次未被抽到的概率是多少？若它属于一个有多条记录的用户，是否说明该用户完全袋外？

**解析。** 概率为 $`0.9^{10}\approx0.34868`$，不是精确的零点三六七九，后者是大样本极限。未抽到某条不代表同用户其他记录也未抽到。若目标是陌生用户泛化，应按实体设计抽样与评价，普通行级袋外预测可能仍含身份相关信息。近重复与时间窗口也需同样检查。

<a id="detail-53"></a>

### 15.7 统计练习：无限树数消除什么

**题目。** 固定训练集下，单树随机预测方差为九，独立随机化一百棵树，条件平均方差是多少？能否据此得出总体风险为零？

**解析。** 条件方差为九除以一百，即零点零九。总体还包含训练集变化造成的平均预测波动、偏差、目标噪声和可能的分布变化。增加树数主要减小森林随机近似误差，不创造新训练信息。若随机树实际上共享非独立随机状态，条件独立计算还需要相应修改。

<a id="sec-7-2"></a>
### 边界追问：平均更多模型何时收益很小

**题目。** 各树方差四、相关系数零点九，十棵与一百棵平均方差分别多少？它们是否证明只要随机性越大越好？

**解析。** 公式给出 $`4(0.9+\frac{0.1}{10})=3.64`$，一百棵为三点六零四，极限三点六，增树收益很小。但过强随机化可能使单树信号能力下降、偏差增加，不能只追求低相关。应在真实任务上共同比较单树质量、误差相关、总体损失与计算成本。

<a id="detail-54"></a>

### 15.8 概率聚合：硬投票和软平均

**题目。** 三树正类概率分别零点六、零点六、零点一。比较硬投票与概率平均的类别，并说明哪个一定更好。

**解析。** 硬类别为正、正、负，多数选正；平均概率为一点三除三，约零点四三三三，按二分之一选负。两者不同，没有脱离数据与损失的统一赢家。要明确实现聚合规则，再分别评价分类、概率与成本。不能因为平均使用更多数值信息就未经验证宣布所有工作点更优。

<a id="detail-55"></a>

### 15.9 提升计算：残差作用在哪个空间

**题目。** 一个正例当前 logit 为零点八。逻辑交叉熵负梯度是什么？为什么不是一减零点八？

**解析。** 概率为 $`\sigma(0.8)\approx0.689974`$，负梯度为 $`1-p\approx0.310026`$。零点八是 logit，不是概率，标签与其直接相减不对应交叉熵导数。用树拟合伪残差后仍是在分数空间更新，再通过 sigmoid 得概率。若使用不同标签编码或损失规范，常数因子和公式也要一致。

<a id="detail-56"></a>

### 15.10 二阶叶更新：局部近似与精确最优

**题目。** 一个叶有四条，当前概率均二分之一，标签三正一负。求零增量处 Newton 型叶更新，并与只在该叶拟合常数概率的精确最优比较。

**解析。** 梯度和为 $`4\times0.5-3=-1`$，Hessian 和为一，Newton 增量为一。原 logit 零，更新概率为 $`\sigma(1)\approx0.7311`$。精确最优概率为四分之三，对应 logit 为 $`\log3\approx1.0986`$。一次二阶近似不等于精确线搜索，继续迭代可接近；收缩和正则还会进一步改变叶增量。

<a id="detail-57"></a>

### 15.11 叶支持：更纯是否一定更好

**题目。** 一个叶五十条、正例比例零点八；另一个叶一条正例、比例一。能否认为第二个概率估计更可靠？

**解析。** 不能。经验纯度与估计精度不同，小叶比例容易极端。还要考虑分区经过标签选择，不能仅用事先固定区域的二项推断。可以设置叶支持、平滑或诚实估计，并在独立样本检查概率。若小叶对应真实但稀有重要群体，也不应简单合并而不检查代价，需补充数据与结构共享。

<a id="detail-58"></a>

### 15.12 外推反例：超过标签范围与趋势延伸

**题目。** 某提升模型在一个新输入预测超过训练最大目标，是否推翻了“普通树不擅长趋势外推”？随机森林同样能自然做到吗？

**解析。** 提升加法函数可以超过原标签范围，但有限常数叶树的和仍在所有阈值之外保持相应常数，不能由输出超范围推断正确线性延伸。普通均值叶森林为非负权平均，预测位于训练标签凸包内。若使用线性叶或其他变体，结论需要重新分析。应直接测试指定输入范围外的规律，而非仅比较输出数值大小。

<a id="detail-59"></a>

### 15.13 特征合法性：袋外也不能洗去泄漏

**题目。** 先用所有训练标签选择最相关十列，再用随机森林袋外误差报告效果。这是否评价了完整筛选流程？

**解析。** 没有，袋外样本标签已经参与选择输入列，即使没直接进入某棵树，信息仍通过筛选传入。需要在外层评价中重新执行筛选和森林训练，或保留独立测试。类似问题也出现在目标编码、全表监督降维与根据袋外成绩反复挑方案。袋外是有用工具，不是无条件独立证明。

<a id="detail-60"></a>

### 15.14 研究设计：树数曲线为何需要不同解释

**题目。** 分别画森林和提升的训练验证误差对树数曲线，应固定哪些设置？看到某条曲线恶化能推断什么？

**解析。** 固定数据、叶复杂度、特征与采样规则、指标和选择程序；提升还要固定学习率并记录早停。森林树数主要改变随机平均精度，提升轮数改变拟合路径。某次验证恶化可能是有限波动、拟合噪声或其他差异，不能只凭模型名得出定理。可以重复随机化并查看趋势，但最终选择仍需外部评价。

<a id="detail-61"></a>

### 15.15 方法比较：时间预算与参数预算

**题目。** 新方法试一百组、每组十分钟，基线试十组、每组一分钟。最高分差能否直接称为算法结构贡献？怎样补充证据？

**解析。** 开发预算相差很大，分差包含搜索机会与计算资源。可以画性能随总预算变化，或给合理同预算比较，再补各自充分调优但披露成本的结果。固定数据与主要指标，使用独立测试或外层评价完整选择流程。默认设置不合理的基线也应修正，公平不是机械让所有参数取相同数值。

<a id="detail-62"></a>

### 15.16 机制练习：为什么加树不能修复缺少群体

**题目。** 训练只来自地区甲，部署新增地区乙。将树数从一百增到一万，能否保证解决乙地区错误？需要哪些检查？

**解析。** 不能，增加树不补充乙的标签与测量机制。先检查输入支持、标签定义、单位和条件关系；收集代表乙的数据或明确外推假设；分别报告来源与总体。若乙只是落在甲覆盖区域且机制相同，已有模型可能适用，但仍需证据。降低蒙特卡洛波动与获得新总体信息是两种不同任务。

<a id="detail-63"></a>

### 15.17 开放研究：浅树提升是否能表达任意交互

**题目。** 一组只允许使用单变量树桩的加性提升，能否自动表达纯异或？若不能，怎样修改研究设计？

**解析。** 每棵树桩只依赖一个原始变量，有限和仍是各变量函数的加性组合，无法在四个异或角上同时实现正确符号模式。增加很多同类树桩不自动补上交互，需要更深基学习器或合适交互表示。应把表达限制与迭代次数区分，比较不同深度时同时控制学习率、预算和验证选择，避免把更多容量收益误归于树数。
