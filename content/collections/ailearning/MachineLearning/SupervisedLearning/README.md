# 监督学习

掌握线性模型、树模型与距离模型的工作方式，并根据数据特点选择基线。

**先修知识：** 机器学习基础；梯度和概率。

## 学习顺序与覆盖范围

第 1 章先建立线性回归与逻辑回归基线，第 2 章比较树模型和集成。学会这两章并掌握[模型评估第 1—2 章](../ModelEvaluation/README.md)后，即可开始[分类实践](../Projects/02-可运行分类实验.md)。第 3 章的核方法与近邻是模型分支；第 4 章承接第 2 章深入集成、调参与解释。研究 SVM 对偶和 KKT 时按需补[约束优化](../../Mathematics/Optimization/03-凸性二阶方法与约束优化.md)，不把这一证明分支作为完成线性基线的门槛。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：判断收益是否来自搜索预算](04-集成学习调参与可解释性.md#sec-7-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
