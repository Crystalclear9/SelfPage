## 1. 最大间隔分类与几何距离

<a id="detail-1"></a>

### 1.1 超平面得分可以任意缩放

标签记为 $y_i\in\{-1,+1\}$，线性分数为 $f(x)=w^\top x+b$，边界是分数为零的集合。将 $w,b$ 同乘正数，边界与类别不变，但分数大小改变。因此不能直接比较未归一化的 $y_if(x_i)$ 来判断哪条边界离样本更远。

样本到边界的有符号几何距离为 $f(x_i)/\|w\|$，正确方向的距离为 $y_if(x_i)/\|w\|$。公式可由将点沿法向单位向量 $w/\|w\|$ 移动到平面推导：需要移动的长度正好抵消分数，分数沿该方向的变化率为 $\|w\|$。要求 $w\ne0$，零向量没有通常意义上的分割超平面。

<a id="detail-2"></a>

### 1.2 固定尺度后最大化最小距离

若数据线性可分，可以缩放参数，使最小函数间隔等于一，即所有 $y_if(x_i)\ge1$，且至少一个达到边界约束。此时最大化最近样本几何距离 $1/\|w\|$，等价于最小化 $\|w\|^2/2$。两条平行支持平面 $f=1$ 与 $f=-1$ 的总宽度为 $2/\|w\|$，不要把半间隔与总宽度混淆。

范数目标偏好在训练点之间留下较宽空隙，但这种几何取决于输入尺度。把一列乘一千，会改变欧氏距离与参数范数的相对意义。最大间隔不是脱离表示的天然真理，而是一种明确的归纳偏好。合理尺度、特征与外部评价仍然必要。

<a id="detail-3"></a>

### 1.3 间隔能保证哪一种扰动稳定

对固定线性模型，扰动 $\delta$ 引起分数变化 $w^\top\delta$，由 Cauchy–Schwarz 不超过 $\|w\|\|\delta\|$。因此若扰动范数小于 $|f(x)|/\|w\|$，预测符号不会改变。这是给定度量与模型下的确定性结论，说明几何距离与局部边界稳定直接相关。

它不保证真实标签也不变，不保证数据分布变化后仍准确，也不自动覆盖离散类别或现实语义扰动。核空间间隔还需结合映射的变化率才能转换成原输入扰动保证。解释“更稳健”时必须说明对象，不能把一个几何界扩成所有环境下的可靠性。

## 2. 核技巧与正半定性

<a id="detail-4"></a>

### 2.1 显式映射与内积

设特征映射为 $\phi(x)$，内积核为 $k(x,z)=\langle\phi(x),\phi(z)\rangle$。如果训练与预测只需要这些内积，就可以直接计算核而不显式保存高维向量。这能让某些非线性结构计算更方便，但仍需处理样本数量、核矩阵与参数选择。

线性核是最直接特例。二维二次多项式核 $k(x,z)=(1+x^\top z)^2$ 可以使用六维映射 $\phi(x)=(1,\sqrt2x_1,\sqrt2x_2,x_1^2,\sqrt2x_1x_2,x_2^2)$。展开内积可逐项核对常数、线性、平方与交互系数，说明“隐式”并非没有对应的表示。

<a id="sec-2-1"></a>
### 机制展开：核只需内积却仍需合法性

对任意有限输入，Gram 矩阵 $K_{ij}=k(x_i,x_j)$ 应当对称正半定，因为 $c^\top Kc=\|\sum_ic_i\phi(x_i)\|^2\ge0$。这个性质使标准核 SVM 的对偶仍是相应凸二次规划。任意取值看起来像相似度，不保证具有这样的内积解释。

矩阵 $\begin{pmatrix}1&2\\2&1\end{pmatrix}$ 对称且每个元素为正，但特征值为三与负一，向量 $(1,-1)$ 的二次型为负二，所以不正半定。可见对称、非负或自相似较大等直觉并不足够。一个有限数据集通过数值检查，也不证明函数对所有输入都合法，只是发现或排除当前样本中的问题。

<a id="deep-dive-2"></a>
### 深入讲解：最大间隔、对偶与近邻的共同边界

核 SVM 通过训练样本的特征内积组合出一个全局边界，近邻通过局部距离聚合标签。两者都依赖表示中的相似，但学习对象不同：一个解范数正则与间隔违约的优化，另一个选择局部邻域和聚合规则。不能因都使用 RBF 或距离，就认为它们是同一个模型。

核还诱导特征空间距离 $d_k^2(x,z)=k(x,x)+k(z,z)-2k(x,z)$，正半定性保证它非负。不同输入可能被映到同一特征点，距离为零，因此一般可能只是伪度量。原始欧氏远近与核空间远近也可能不同，核参数与尺度共同决定行为。

<a id="detail-5"></a>

### 2.2 RBF 核为什么合法

RBF 核为 $e^{-\gamma\|x-z\|^2}$，其中 $\gamma>0$。可以拆成 $e^{-\gamma\|x\|^2}e^{-\gamma\|z\|^2}e^{2\gamma x^\top z}$，再将最后一项展开成非负系数的幂级数。每个 $(x^\top z)^m$ 都对应张量特征内积，乘以两端相同的标量因子仍保留正半定，有限和及收敛极限也保留。因此它可以具有无限维特征解释。

这不等于无限维一定更好。大 $\gamma$ 让不同点相似很快接近零，模型可以非常局部；小 $\gamma$ 让有限范围内核值相近，区分结构变弱。正则系数与核宽度需要共同选择，重复点、噪声和高维尺度也会影响实际矩阵条件。

<a id="sec-3"></a>
## 3. kNN 的表示、距离与邻居数

<a id="detail-6"></a>

### 3.1 训练规则不只是保存数据

对查询找到最近的 $k$ 个训练样本，分类做投票或概率平均，回归做目标平均。需要事先确定表示、度量、邻居数、权重、相同距离的处理、零距离重复点以及未知或缺失输入规则。训练计算轻，并不意味着没有建模假设。

欧氏距离假设各坐标经尺度处理后能线性组合平方差。曼哈顿距离、余弦相似和基于业务的度量偏好不同结构。若使用监督度量学习，度量本身必须在训练折拟合；先看全表标签学习距离再交叉验证近邻，仍存在泄漏。

<a id="sec-1-1"></a>
### 基础算例：一个尺度变化改变近邻关系

查询为原点，候选甲为一、零，乙为零、二，欧氏距离分别一与二，甲更近。若第一列单位放大十倍，甲距变十，乙仍二，邻居反转。标准化相当于选择一种对角度量，不是从数据中自动恢复唯一真实距离。

例如一列是温度、一列是传感器编号，按标准差缩放仍不能使编号具有合理几何。类别应使用合适表示，时间和地理还可能需要周期或球面结构。距离的数值精确计算不代表语义相似性正确。

<a id="detail-7"></a>

### 3.2 小邻域与大邻域的折中

小 $k$ 保留局部变化，但容易受单个错误标签影响；大 $k$ 降低目标平均噪声，却混合更远对象、抹平边界与稀有群体。距离加权可以平滑部分折中，但权重过集中时又接近最近一个点。所有这些选择都需要开发验证，而不是根据一个固定经验值解决所有任务。

分类时少数类如果处于大类周围，小群体可能被多数投票淹没。应检查局部密度、标签质量与成本，而不是机械提高类权重。若使用不均匀采样数据，近邻频率对应的可能是采样分布，不是部署真实概率。

<a id="sec-4"></a>
## 4. 软间隔与错误代价

<a id="detail-8"></a>

### 4.1 松弛不是只有分类错误才出现

不可分数据引入 $\xi_i\ge0$，要求 $y_if_i\ge1-\xi_i$。若 $\xi_i=0$，达到或超过单位间隔；在零与一之间，点可以仍被正确分类，但已进入间隔；大于一则函数间隔为负，发生分类错误；恰好一可能位于分界面，需按平局约定处理。

目标 $\|w\|^2/2+C\sum_i\xi_i$ 在范数与违约间折中。$C$ 大更重视训练间隔违约，但不意味着对每个点的错误都必然减少，也不保证测试更好。数据噪声、表示尺度与损失规范决定具体关系。

<a id="detail-9"></a>

### 4.2 求和与平均的参数换算

若另一个目标写为 $\lambda\|w\|^2/2+n^{-1}\sum_i\max(0,1-y_if_i)$，整体除以 $\lambda$ 后可见求和规范下 $C=1/(n\lambda)$。因此固定 $C$ 增加样本量，会改变相对平均损失的惩罚尺度；跨实现比较前应核对实际目标。

样本成本可使每个点有不同 $C_i$。它改变优化对训练群体的偏好，不直接把分数变成概率或真实因果价值。如果需要不对称行动阈值，应在适当概率或决策框架下评价，而不是把几何间隔数值直接当作后验。

<a id="sec-5"></a>
## 5. 从原始问题到对偶的完整推导

<a id="sec-5-1"></a>
### 5.1 第一步：消除任意缩放

硬间隔原始问题为最小化 $\|w\|^2/2$，约束 $y_i(w^\top x_i+b)\ge1$。若训练集不可分，该问题无可行解；这不是求解器没有足够努力，而是约束彼此不相容。标签噪声或同一输入对应相反标签，都可能使硬约束失效。

归一化规定最靠近的函数间隔为一，范数才具有几何意义。截距一般不惩罚，因为它平移边界而不改变法向长度；若特定实现将截距当作额外特征并惩罚，实际目标不同，不能直接套相同对偶约束。模型细节往往藏在这种看似无关的实现选择中。

<a id="sec-5-2"></a>
### 5.2 第二步：用松弛表达不可分数据

软间隔原始为 $P=\min_{w,b,\xi}\|w\|^2/2+C\sum_i\xi_i$，约束为 $y_if_i\ge1-\xi_i$、$\xi_i\ge0$。固定 $w,b$，最小可行松弛显然是 $\max(0,1-y_if_i)$，所以约束形式与 hinge 惩罚等价。最小化只需选满足约束的最小松弛，因为每个额外松弛都会增加正成本。

这是凸问题：范数平方凸、松弛线性、约束仿射。取零权重零截距、所有松弛为二，就能严格满足不等式，因此在通常有限维条件下满足 Slater 条件，可以使用强对偶。它说明原始最优值与对偶最优值相同，是后续用对偶解恢复原始模型的依据；不是所有随意构造的不定核问题都继承此结论。

<a id="sec-5-3"></a>
### 5.3 第三步：推导对偶中的内积

把约束写成 $1-\xi_i-y_i(w^\top x_i+b)\le0$ 与 $-\xi_i\le0$，分别配非负乘子 $\alpha_i,\mu_i$。拉格朗日函数为

$$
\mathcal L=\frac12\|w\|^2+C\sum_i\xi_i
+\sum_i\alpha_i[1-\xi_i-y_i(w^\top x_i+b)]
-\sum_i\mu_i\xi_i.
$$

对原始变量取下确界。对 $w$ 的驻点为 $w=\sum_i\alpha_i y_i x_i$；对无约束截距的线性系数必须为零，得到 $\sum_i\alpha_i y_i=0$；对松弛的系数必须为零，得到 $C-\alpha_i-\mu_i=0$。由于 $\mu_i\ge0$，所以 $0\le\alpha_i\le C$。

将这些关系代回，关于 $w$ 的二次项与线性项合为负二分之一范数平方，得到对偶

$$
D=\max_\alpha\sum_i\alpha_i
-\frac12\sum_{i,j}\alpha_i\alpha_jy_iy_jx_i^\top x_j,
\qquad 0\le\alpha_i\le C,\quad\sum_i\alpha_i y_i=0.
$$

出现内积不是一个额外猜测，而是最小化原始范数后自然得到。对偶乘子不是类别概率，既不要求和为一，也可能达到上界。它们反映约束参与最优性的方式，解释时要与分数和后验区分。

<a id="sec-5-4"></a>
### 5.4 第四步：理解支持向量和核

在特征空间使用 $w=\sum_i\alpha_i y_i\phi(x_i)$，预测分数为 $\sum_i\alpha_i y_i k(x_i,x)+b$。零乘子点不直接出现在最终展开，非零点称为支持向量。它们可包括位于单位间隔边界、进入间隔以及被错分的点，而不是只指几何上刚好贴着两条平行线的样本。

令 $Y$ 是标签对角矩阵，核对偶二次矩阵为 $YKY$。如果 $K$ 正半定，则任意 $a$ 有 $a^\top YKY a=(Ya)^\top K(Ya)\ge0$，所以最大化目标是凹函数。对称不定核会破坏这个标准论证。某些专门方法研究不定相似度，但那需要另一个问题定义，不能继续直接援引普通核 SVM 保证。

<a id="detail-10"></a>

### 5.5 原始与对偶可行性如何一起检查

原始可行意味着所有间隔与松弛约束满足；对偶可行意味着乘子在盒内且加权标签和为零。对任何可行对，弱对偶保证 $P-D\ge0$。若 gap 接近零且约束误差可控，便提供有意义的最优性证据。只看分类准确率无法检查是否解了目标问题。

数值求解有容差，极小负乘子或微小约束偏差可能只是浮点误差，但大幅违反应调查。gap 也要按损失规范解释；把原始平均目标与对偶求和目标直接相减没有意义。手写实现时先用小样本核对，远比在大表上只观察最终分数更容易定位错误。

<a id="sec-6"></a>
## 6. KKT、支持向量与核展开

<a id="detail-11"></a>

### 6.1 互补条件的三类点

除了驻点与可行性，还需 $\alpha_i[1-\xi_i-y_if_i]=0$、$\mu_i\xi_i=0$。若 $0<\alpha_i<C$，则 $\mu_i>0$，松弛必须零，同时间隔等于一。这样的自由支持向量可以用来恢复截距。

若 $\alpha_i=C$，松弛可以正，也可以零，且因乘子正有 $y_if_i=1-\xi_i\le1$。它可能仍正确但在间隔内，也可能错分。若 $\alpha_i=0$，互补条件不强制间隔恰好在哪，但原始最优与 $\mu_i=C>0$ 给出松弛零，所以间隔至少一。退化点可以刚好在边界而乘子仍为零，因此这些分类不应被说成每类严格互斥的几何图例。

<a id="detail-12"></a>

### 6.2 截距不能随便用所有支持向量平均

对于自由支持向量，$y_if_i=1$，由于标签平方为一，得到 $b=y_i-\sum_j\alpha_jy_jk(x_j,x_i)$。可以用多个自由点的数值结果平均减小容差影响。边界乘子点可能带非零松弛，套同一公式就会引入偏差。

若没有自由支持向量，需要从 KKT 不等式推导截距可行区间或采用求解器一致的策略，不能捏造一个自由点。截距未必唯一；范数对 $w$ 严格凸可使最优 $w$ 唯一，却不意味着无惩罚的 $b$ 也唯一。这一点会在两点软间隔例子里直接看到。

**把“求可行区间”真正写成可计算的上下界。** 记不含截距的展开为 $h_i=\sum_j\alpha_jy_jk(x_j,x_i)$，并假设标准软间隔问题 $C>0$ 已得到满足 KKT 的最优展开。对 $\alpha_i=0$ 的点，松弛为零，所以正例要求 $b\ge1-h_i$，负例要求 $b\le-1-h_i$。对 $\alpha_i=C$ 的点，间隔不大于一，所以正例要求 $b\le1-h_i$，负例要求 $b\ge-1-h_i$。把这四种情形汇总：

$$
L=\max\left(\{1-h_i:y_i=1,\alpha_i=0\}\cup
\{-1-h_i:y_i=-1,\alpha_i=C\}\right),
$$

$$
U=\min\left(\{-1-h_i:y_i=-1,\alpha_i=0\}\cup
\{1-h_i:y_i=1,\alpha_i=C\}\right).
$$

空下界集合约定为 $-\infty$，空上界集合约定为 $+\infty$。没有自由支持向量时，任意 $b\in[L,U]$ 都满足这些截距条件；若区间有限，取中点只是一个可复现选择。对于自由点 $0<\alpha_i<C$，还需加入等式 $b=y_i-h_i$；精确最优解的所有等式应一致并落在上下界内。若数值上 $L>U$，应先检查优化残差、核值和乘子分类容差，不能交换端点后掩盖不满足 KKT 的问题。

用下一节的两点例子提前核对：$C=0.1$ 时 $h=(-0.2,0.2)$、标签为 $(-1,1)$，两乘子都等于上界。负例给出 $b\ge-0.8$，正例给出 $b\le0.8$，因此截距区间恰为 $[-0.8,0.8]$。任取其中的 $b$，两个最小松弛分别为 $0.8+b$ 与 $0.8-b$，总和恒为 $1.6$；所以原始目标恒为 $0.2^2/2+0.1\times1.6=0.18$。这不只是“可能不唯一”的口头说明，而是把整个最优集合和不变目标都算了出来。按预测阈值零作硬分类时，区间内不同截距仍可能给出不同训练错误，凸目标相同不代表所有下游指标相同。


<a id="sec-6-1"></a>
### 几何间隔、核函数与近邻度量的联系

线性边界距离由 $\|w\|$ 归一化，核模型则在 $\phi$ 空间度量，近邻可以直接采用同一核诱导距离。共享距离不代表共享训练规则：近邻没有标准 SVM 的全局间隔最优化，SVM 也不是按最近支持向量简单投票，而是带符号系数的内积和。

支持向量数量还不是函数复杂度的唯一刻度。相同数量配不同核宽度、范数和数据覆盖，行为可能很不同；推理成本却确实与非零展开项相关。模型比较需要同时看几何假设、统计表现和计算资源，避免只凭稀疏展开数量判断泛化。

<a id="detail-13"></a>

### 6.3 正则路径与噪声敏感性

增大 $C$ 放松盒约束，允许更大乘子、更加重视违反间隔的点；但每个参数与点状态不必单调变化。极端噪声点可能持续影响边界，核宽度大时还可能形成局部孤岛。减小 $C$ 则可能牺牲一些训练间隔以降低范数，是否改善外部风险取决于任务。

对类别不平衡使用不同上界，会改变两个类别贡献。它并不识别哪个标签一定是噪声，也不自动修正采样先验。若高代价少数类被重视，应在真实总体与成本下评价，避免只看加权训练损失或某个单一召回率。

<a id="worked"></a>
## 7. 完整手算与数值核验

<a id="detail-14"></a>

### 7.1 两点硬间隔的原始与对偶

输入负一、一，标签负一、正一，一维带截距。约束为 $w-b\ge1$ 与 $w+b\ge1$，相加得 $w\ge1$。最小范数解为 $w=1,b=0$，原始目标二分之一，最近距离一，总间隔宽度二。

对偶标签和约束要求两乘子相同，记为 $a$。恢复权重为 $w=2a$，对偶目标 $2a-2a^2$，导数为 $2-4a$，最优 $a=1/2$，对偶值也二分之一。两点都在单位间隔，且乘子正；原始、对偶与几何三种检查完全一致。

<a id="detail-15"></a>

### 7.2 软间隔可得到一条分段解析路径

同样两点，选择对称截距零，目标为 $w^2/2+2C\max(0,1-w)$。在零到一之间，导数为 $w-2C$，所以最优权重为 $\min(2C,1)$。对偶仍为 $2a-2a^2$，但上界 $a\le C$，得到 $a=\min(C,1/2)$，与原始一致。

若 $C=0.1$，$w=0.2$、两个松弛均零点八，原始目标 $0.02+0.16=0.18$，对偶 $0.2-0.02=0.18$。两点都正确分类，却都在间隔内且乘子达到上界。若 $C=1$，恢复硬间隔解与零松弛，对偶乘子二分之一小于上界。

<a id="detail-16"></a>

### 7.3 相同最优目标不一定唯一截距

当 $C<1/2$、$w=2C<1$ 时，任何 $b\in[-(1-w),1-w]$ 都使两点间隔不超过一，总 hinge 仍为二减二倍权重，所以目标相同。对称 $b=0$ 是一种解，但不唯一。取 $C=0.1,b=0.8$，两分数为零点六与一，其中负例被错分，两个松弛为一点六与零，和仍一点六。

这不是凸优化矛盾：目标严格惩罚权重却不严格约束截距，多个最优预测规则可以在低 $C$ 时有不同硬分类。实际求解器可能选择对称截距或别的合法值。研究最优性、参数唯一性与分类表现时应分开，不能把一个返回结果当作唯一数学答案。

<a id="detail-17"></a>

### 7.4 显式二次映射与核值

取二维点 $x=(1,2)$、$z=(2,0)$，内积为二，所以二次核为九。显式映射为 $\phi(x)=(1,\sqrt2,2\sqrt2,1,2\sqrt2,4)$，$\phi(z)=(1,2\sqrt2,0,4,0,0)$，内积一加四加四，仍为九。根号二系数不可漏，否则交互与线性项权重就不匹配。

这个小例子展示核技巧不是任意替换相似度，而是在隐式空间保持内积计算。若把映射改成没有缩放的所有单项式，仍可定义一个合法核，但已是另一个核与范数几何，不能声称与原公式完全等价。

<a id="kernel-design"></a>
## 8. 核的构造、尺度与近似

<a id="detail-18"></a>

### 8.1 合法核的组合可以逐步证明

非负权重的核和仍合法，因为 Gram 二次型是非负二次型的非负线性组合。核的乘积也合法：若两个核对应映射 $\phi,\psi$，乘积对应张量映射 $\phi(x)\otimes\psi(x)$，其内积正是两个内积的乘积。这为组合线性、周期、局部或不同数据模态提供一种明确构造方法。

若先作固定变换 $g$，再使用合法核 $k(g(x),g(z))$，也保留合法性，因为只是把映射复合。若 $g$ 从标签学习，则整体仍可以定义合法核，但学习与评价边界要覆盖这一步；合法性与没有泄漏是两个不同问题。负权核差则一般不保证合法，需要额外证明，不能把所有代数操作都视为安全闭包。

核组合还改变范数偏好。线性核与 RBF 核相加，允许函数同时含线性与局部成分；各核系数控制相应成分的相对价格。它不是简单把两个已经训练好的模型投票，训练仍会联合选择展开。是否有益需要在相同数据、尺度与选择预算下检验。

<a id="detail-19"></a>

### 8.2 归一化核对应另一种几何

若 $k(x,x)>0$，可以定义归一化核 $\widetilde k(x,z)=k(x,z)/\sqrt{k(x,x)k(z,z)}$，对应将特征映射除以自身范数。它保留正半定，却移除了某些长度信息。线性核归一化后成为非零向量的余弦相似，适合关注方向的任务，但可能丢掉原始幅度中重要信号。

例如两个计数向量一、二与十、二十方向相同，余弦视为同一点，而欧氏距离很大。若目标取决于主题分布，归一化可能合理；若取决于总规模，就需要保留长度或额外特征。零向量无法直接归一化，必须定义单独策略，不能让除零产生隐蔽缺失。

RBF 对角本来为一，通常不因这种归一化改变。多项式核对角随输入长度变化，归一化则明显改变模型偏好。比较前处理时应说明改变的是优化尺度、相似性还是原始信息，而不是把所有操作都概括成“标准化”。

<a id="detail-20"></a>

### 8.3 RBF 宽度与输入缩放的等价关系

RBF 写为 $\exp[-\|x-z\|^2/(2s^2)]$ 时，$\gamma=1/(2s^2)$。将所有输入乘常数 $c$，若同时把 $\gamma$ 除以 $c^2$，核值完全相同。若只放大某一列，则对应各向异性距离，无法用单一全局宽度完全抵消。

因此特征尺度与宽度不能脱离讨论。标准化后搜索的宽度范围可能与原始单位差几个数量级，直接复制别人的数值没有普遍意义。距离分布可以帮助制定初始范围，但若根据验证结果反复扩大，也属于搜索过程，需要最终外部评价。

很大宽度使所有核值相近，Gram 可能接近低秩；很小宽度使不同训练点近乎正交，模型可形成极局部作用。前者未必完全没有信息，后者也不是必然测试失败，但两端通常值得作为诊断边界。结合正则与支持向量数量看行为，比只看训练准确率更有解释力。

<a id="detail-21"></a>

### 8.4 核中心化与截距的一个细节

特征中心化是将 $\phi(x)$ 减去训练特征均值，训练 Gram 可写为 $HKH$，其中 $H=I-\mathbf1\mathbf1^\top/n$。新查询需要使用同一训练均值，不能把测试批次重新当作中心。该操作常见于核主成分等方法。

但对具有自由未惩罚截距的标准 SVM，中心化在精确数学上可以由截距吸收。对偶令 $a_i=\alpha_i y_i$，满足 $\mathbf1^\top a=0$，所以 $Ha=a$，有 $a^\top HKHa=a^\top Ka$。相同的训练最优目标与相应预测可通过截距转换保持。

这个结论依赖自由截距、相同数据与精确规则。若截距被惩罚、根本没有截距或前处理还改变其他尺度，不能原样使用。它也说明并非所有常见核预处理都一定增加某种能力，应该先问该变换是否已经被模型的其他自由度表示。

<a id="detail-22"></a>

### 8.5 表示定理的核心思想

对具有 Hilbert 空间范数惩罚、经验损失只依赖训练预测的模型，将任意 $w$ 分解为训练映射张成空间中的 $w_\parallel$ 与正交部分 $w_\perp$。正交部分对所有训练内积为零，所以不改变训练损失，却让范数平方增加。存在一个不含无用正交部分的最优解，因此可写成训练点映射的线性组合。

这个论证解释了核展开为何不仅限于 SVM。核岭回归也能写成样本展开，但平方损失通常产生稠密系数，不具备合页约束导致的同样支持向量稀疏性。表示形式相似，损失与正则不同，预测和计算行为仍可能不同。

以无截距核岭为例，采用平均半平方损失与正二次惩罚，常见系数解为 $(K+n\lambda I)^{-1}y$。若 Gram 特征值为 $s$，训练拟合方向被乘以 $s/(s+n\lambda)$，显示对小特征值方向的收缩。矩阵即使奇异，正惩罚也使这个求解矩阵正定；实际应解线性系统，而非显式求逆。

<a id="detail-23"></a>

### 8.6 核矩阵与近似的资源折中

存储完整 Gram 需要数量级为样本数平方的空间，具体训练算法还会反复访问部分元素。核缓存可以减少重算，但无法改变所有规模问题。训练时间不能简单一概说成固定立方，因为求解器、精度、稀疏与数据结构都会影响，至少应明确存储与支持展开成本。

低秩近似可以用少量代表点近似 Gram，随机特征可以显式近似某些平移不变核。它们把精确核问题换成近似表示上的可扩展学习，带来近似误差与随机性。特征数更多通常提高近似能力，也增加训练与推理成本，必须共同评价。不能只报告近似方法训练快，而不检查最终风险与概率行为。

<a id="neighbors"></a>
## 9. 近邻的统计误差与维数

<a id="detail-24"></a>

### 9.1 回归近邻是一个局部条件均值估计

对查询 $x$，均匀近邻回归为最近 $k$ 个目标的平均。若条件均值在邻域变化不大，邻居目标提供相近均值的重复观测；平均又降低标签噪声。这是局部平均有效的核心，而不是“相似对象必然同标签”的绝对断言。

假设邻居输入固定，噪声独立、条件均值零、方差至多 $\sigma^2$，真实均值满足 Lipschitz 常数 $L$，最远邻居距离为 $r_k$。预测偏差绝对值至多 $Lr_k$，平均噪声方差至多 $\sigma^2/k$，所以相对条件均值的均方误差可由 $L^2r_k^2+\sigma^2/k$ 控制。若预测新标签，还要加新标签噪声。

增大 $k$ 降低方差项，却通常扩大半径与偏差项。这是一个带条件的量化折中，不是所有实际近邻误差都精确等于这两项。距离学错、支持缺失或相关记录会破坏假设，需要重新分析。

<a id="detail-25"></a>

### 9.2 为什么固定最近一个点一般不一致

随着样本增多，最近点在合适连续密度与固定维度条件下可以靠近查询，但它的标签噪声不会因只取一条而被平均掉。若某处真实正例概率为 $\eta$，最近标签与新标签近似为两个独立同概率伯努利，则一近邻错误趋近 $2\eta(1-\eta)$，而贝叶斯错误为 $\min(\eta,1-\eta)$。

例如所有输入都没有额外信号，正例概率零点二。一近邻错误约零点三二，多数负类最优错误零点二。更多样本让距离更精确，却不能消除单个邻居标签的随机性。若希望同时局部化与平均，常见一致性条件让 $k$ 趋无穷，同时 $k/n$ 趋零；更完整定理还需明确采样、度量与维度条件。

在上述局部连续条件下，记局部最优错误为 $r(x)=\min(\eta,1-\eta)$，一近邻极限为平均 $2r(x)[1-r(x)]$，由凹性不超过 $2R^*(1-R^*)$。这个经典形式展示一近邻与最优风险的关系，但不能省略条件套到任意相似度或依赖数据。

<a id="detail-26"></a>

### 9.3 维数诅咒的体积计算

在单位立方体内部，若希望一个轴对齐邻域包含约百分之一的均匀质量，其边长为 $0.01^{1/d}$。一维时边长零点零一，十维时约零点六三一，一百维时约零点九五五。为了收集同样比例的样本，高维邻域覆盖几乎整个坐标范围，不再真正局部。边界和非均匀密度会改变精确量，但困难仍清楚可见。

若局部密度有界且规律足够平滑，可以用半径尺度约 $(k/n)^{1/d}$ 思考偏差，代入前面的界得到 $(k/n)^{2/d}+1/k$ 的折中。平衡量级会给 $k$ 随样本数按约 $n^{2/(d+2)}$ 增长、误差按约 $n^{-2/(d+2)}$ 下降。这里省略常数并依赖相应正则条件，不能当作所有数据的实际精确速率。

维度越大，这个下降越慢；无关维度尤其浪费距离分辨力。有效低维结构、表示学习与特征选择可能帮助，但选择本身需要训练数据与外部验证。不能先用全数据监督降维再宣称近邻独立泛化，也不能仅凭二维可视化看见簇就认定高维距离已经合理。

<a id="detail-27"></a>

### 9.4 距离加权改变有效支持

设邻居权重非负、和为一，条件噪声方差相同且独立，则预测噪声方差为 $\sigma^2\sum_i a_i^2$。均匀权重得到 $\sigma^2/k$，若一个邻居几乎占全部权重，则又接近单点噪声。可以用 $1/\sum_i a_i^2$ 描述这一特定平均的有效支持，但不是通用学习样本量。

距离倒数在零距离会发散，需要规则；重复样本可能是同一对象多次记录，而非独立信息。若一个用户复制很多行，它可能在查询投票中占据大部分位置。应按实体、采样和任务单位检查，而不是把库中行数直接当作独立邻居数量。

<a id="detail-28"></a>

### 9.5 Mahalanobis 度量与白化

距离平方 $(x-z)^\top M(x-z)$ 在 $M$ 正定时对应一种线性变换后的欧氏度量；半正定时可能把不同点压到同一位置，形成伪度量。若 $M=A^\top A$，就等于 $\|A(x-z)\|^2$。监督度量学习可以寻找有利的投影，但也会改变模型容量与评价边界。

使用协方差逆进行白化能够消除某些线性相关尺度，但估计协方差本身可能不稳定，尤其维度接近样本量。正则化逆或低维表示可以控制，却引入额外选择。白化不保证任务相关方向获得正确权重，因为输入方差与标签信息不是同一对象。

## 10. 计算、校准与公平比较

<a id="detail-29"></a>

### 10.1 原始与对偶算法适合不同规模

线性高维稀疏数据可以直接优化原始或其等价目标，不必构造全部核矩阵。样本数、特征数、稀疏程度和求解精度决定选择，不能因为对偶推导漂亮就认为任何 SVM 都应存储平方规模矩阵。核版本通常需要访问许多训练对内积，部署还要保存支持样本与预处理状态。

近邻精确查询若逐个算距离，成本随样本库与维度增长。树形索引在某些低维结构中有效，但高维可能退化；近似索引通过允许部分检索误差换速度与内存。检索召回率与最终预测风险不是同一指标，应同时测量。少量邻居变化可能对多数类无影响，也可能正好翻转关键少数类。

<a id="detail-30"></a>

### 10.2 概率不能从间隔直接读取

SVM 输出对训练目标而言是分数，不是后验。对分数套任意 sigmoid 只给出一个零一范围数值；改变分数单位会改变这个数，却不改变分类符号。若希望概率，需要用适当独立开发信息拟合校准，选择评价也要覆盖该步骤。

近邻正类比例也只是某种局部估计，受邻域大小、采样与标签噪声影响。小 $k$ 输出离散且极端，距离权重可能进一步集中。两种方法都应使用概率评分、校准与决策成本检验，而不是只看准确率。最终测试标签不能反复参与挑校准方式与阈值。

<a id="detail-31"></a>

### 10.3 预计算核矩阵的形状与信息边界

训练 Gram 的行列都是训练样本；查询矩阵的行是查询、列仍是同一顺序的训练样本。把测试与测试之间的核当成查询输入，即使矩阵维度偶然相同，也没有正确语义。支持样本顺序、核参数和训练预处理要与模型一起保存。

对于事先固定、不从数据拟合状态的核，提前计算样本对相似本身不等于使用标签泄漏；但全表标准化、中心化、监督表示或按验证结果选择核，都可能改变信息使用。交叉验证应按训练索引取得训练子矩阵、按验证与训练索引取得交叉子矩阵，并在相应折重新拟合任何数据驱动状态。

<a id="detail-32"></a>

### 10.4 公平搜索与外部评价

对 RBF SVM，应联合考虑正则与宽度，通常在正值的对数尺度上制定合理范围；近邻需要同时研究表示、度量、邻居数与权重。给每种方法机制合理的前处理，不要求所有模型机械使用同一错误尺度，但要把差异纳入完整流程并披露搜索预算。

模型在同一开发数据上被反复选择，最佳分数包含选择幸运。使用独立测试或外层评价确定方案，检查不同来源、冷启动、异常输入和资源。核模型若支持向量很多，推理可能很重；近邻若需要全部原始样本，数据维护与访问成本也重要。分数接近时，稳定性与成本可以决定更合适方案。

<a id="detail-33"></a>

### 10.5 可运行核验：解析软间隔、显式核与尺度

代码使用两点解析答案检查求解器，直接核对二次特征内积，并展示尺度改变邻居。它不写文件，也不使用测试来选择模型。数值容差只对应这个小例子，不能由此保证任意实际训练都充分收敛。

```python
import numpy as np
from sklearn.svm import SVC

X = np.array([[-1.0], [1.0]])
y = np.array([-1, 1])
for C in [0.1, 1.0]:
    model = SVC(kernel="linear", C=C, tol=1e-9).fit(X, y)
    expected = min(2 * C, 1.0)
    assert np.allclose(model.coef_[0], [expected], atol=1e-7)
    alpha = np.abs(model.dual_coef_[0])
    assert np.allclose(alpha, min(C, 0.5), atol=1e-7)
    print(C, model.coef_[0], model.intercept_, alpha)

def phi(v):
    a, b = v
    return np.array([1, np.sqrt(2)*a, np.sqrt(2)*b,
                     a*a, np.sqrt(2)*a*b, b*b])

points = np.array([[1.0, 2.0], [2.0, 0.0], [-1.0, 1.0]])
features = np.stack([phi(v) for v in points])
K = (1 + points @ points.T) ** 2
assert np.allclose(K, features @ features.T)
assert np.linalg.eigvalsh(K).min() > -1e-10

candidates = np.array([[1.0, 0.0], [0.0, 2.0]])
assert np.argmin(np.linalg.norm(candidates, axis=1)) == 0
scaled = candidates * np.array([10.0, 1.0])
assert np.argmin(np.linalg.norm(scaled, axis=1)) == 1
```

<a id="detail-34"></a>

### 10.6 回归扩展：误差带与支持样本

支持向量回归常使用不敏感损失 $\max(0,|y-f(x)|-\epsilon)$。在误差带内部不惩罚，超出部分线性增长，再配范数约束。它允许一些小偏差不参与训练压力，输出仍为连续值，不是类别概率。$\epsilon$ 与目标单位有关，金额从元变成分必须对应处理。

约束形式引入两个非负松弛，分别允许预测过高和过低，目标为 $\|w\|^2/2+C\sum_i(\xi_i+\xi_i^*)$。对偶展开系数是两个乘子之差，截距驻点要求这些差的和为零。只有某些位于带边或外侧的样本进入非零展开，与分类支持向量具有类似的约束机制。

例如真实目标十、预测九点七、不敏感宽度零点五，损失零；预测九，损失零点五。宽度过大可能忽略有价值细节，过小又使噪声参与更多支持。它与绝对损失、Huber、分位数回归的目标不同，应根据误差成本与噪声结构比较，而不是仅因名字都含稳健就互换。

<a id="detail-35"></a>

### 10.7 核与近邻的研究问题如何区分

核方法研究特征空间范数、谱、表示与优化，近邻研究局部度量、密度、邻域缩放与检索。可以把同一个核诱导距离用于近邻，也可以用学习表示训练线性 SVM，但那是新的完整流程。实验应控制哪些因素相同，才能解释收益来自全局边界、局部平滑还是表示变化。

在训练范围外，RBF 核与所有训练点相似趋零时，SVM 分数常趋向截距；这不代表合理的未知风险估计。近邻总会返回一些“最近”的点，即使所有点都很远。应记录距离或覆盖信息，研究拒绝与回退，而不是把任何返回结果当作具有足够支持。

<a id="detail-36"></a>

### 10.8 直接研究 RBF 两端的优化，而不是背过拟合口号

若核宽度参数精确取零，所有 RBF 核值都为一，特征映射不再区分输入。对偶中的二次项为 $(\sum_i\alpha_i y_i)^2/2$，在截距约束下恰好为零。平衡类别时，令所有乘子达到 $C$ 可行，对偶为 $nC$；原始选择零权重、截距零、所有松弛一，也得到相同目标。模型没有输入区分能力，这是一个能够精确验证的退化点。

若所有训练输入互不相同、参数趋向正无穷，Gram 趋向单位矩阵。平衡类别、相同上界时，对偶变为 $\sum_i(\alpha_i-\alpha_i^2/2)$，每个乘子取 $\min(C,1)$ 满足标签和零，成为极限最优。截距可选零，每个训练点主要通过自身核项得到正确方向，体现强局部表示。

但是对一个与所有训练点不同的固定查询，每个核项都趋零，分数趋向截距。若截距也为零，极限分数的符号不能直接确定任意有限参数的预测：极小但不相等的项仍可能决定类别。这正提醒我们，分数极限、概率含义与硬分类极限需要分开。不能仅凭 Gram 接近单位，就笼统断言所有外部样本必然随机或必然正确。

实际搜索中两个端点帮助理解容量，但最优参数取决于数据间距、噪声与正则。重复输入会使大参数极限不是完全单位矩阵；类别不平衡时，乘子还受标签和约束，不能原样用每个都取同值的解。分析一个特定极限时，必须说明这些前提。

<a id="detail-37"></a>

### 10.9 平方距离的高效计算也有数值边界

批量欧氏平方距离常写为 $\|x\|^2+\|z\|^2-2x^\top z$，可利用矩阵乘法同时计算许多对。数学上非负，但大而接近的向量可能因相消得到微小负值。将纯舍入量裁到零可以合理处理；若负值很大，应检查精度、广播或数据错误，不能无条件裁剪掩盖问题。

对 RBF，平方距离错误会直接改变核值；若错误变负，甚至出现大于一的自以为相似度。高精度或先减去共同基准有时能改善计算，具体要看数值范围。标准化与科学单位也影响条件，不能只从模型理论推断实现永远稳定。

对近邻，排序可能对极接近距离的微小误差敏感。若这些点标签一致，预测无变化；若冲突，平局规则与重复记录可能决定输出。测试应覆盖这些语义分支，而不是只用随机连续点验证平均查询速度。相似性计算是学习系统的一部分，数值正确和统计合理都要检查。

<a id="detail-38"></a>

### 10.10 局部线性回归为何能减少某些边界偏差

均值型近邻在查询附近直接平均目标，假设局部为常数。若真实函数有斜率，邻居分布又不对称，例如查询在支持边缘，平均输入不等于查询，就可能产生偏差。可以改为在邻域内以距离权重拟合 $a+b^\top(x_i-x)$，再取截距 $a$ 作为查询预测，形成局部线性方法。

以无噪声规律 $y=2x$ 为例，查询在零，训练邻居为零点一、零点二，对应目标零点二、零点四。均值预测零点三，而正确值为零；局部直线能恢复斜率二、截距零。它使用更强的局部结构与更多参数，噪声下可能增加方差，邻居不足或共线时还会病态，需要正则与适当邻域。

这个例子不证明应永远用局部线性。若目标有跳变、邻域跨越不同机制或维度很高，局部线性也可能失效。方法比较应解释偏好，并在边界、稀疏区域与内部区域分别检查。近邻家族并不是只有一个固定的投票规则，局部模型与度量都参与估计。

<a id="detail-39"></a>

### 10.11 把一次查询的噪声和样本库不确定性分开

固定训练库后，确定的近邻程序对同一个查询通常给固定结果；这不代表预测没有不确定性。重新采样训练库会改变邻居与标签，独立新结果也有条件噪声。近似索引还可能带来第三种随机性，即相同库的检索近似变化。需要分别测量，不能把其中一种重复当作全部误差来源。

例如固定查询连续调用一千次精确索引，得到完全相同输出，只证明实现确定；重新抽一千份训练库才能研究数据敏感性。若只更换近似索引随机种子，主要观察检索随机性。对真实系统，样本库随时间更新又会引入来源变化，不能把所有变化都解释为近邻数选择不当。

<a id="detail-40"></a>

### 10.12 两点 RBF 对偶可以精确解到核宽度

仍取输入负一、一与相反标签，记两点 RBF 相似为 $r=e^{-4\gamma}$，对角均为一。对偶约束令两乘子同为 $a$，范数平方为 $2a^2(1-r)$，对偶目标为 $2a-a^2(1-r)$。对正宽度参数有 $r<1$，求导得到 $a=\min(C,1/(1-r))$，对称截距可取零。

取 $\gamma=\log2/4$，两点相似为二分之一；若 $C=3$，乘子为二，两训练分数为负一与一，核空间范数为二，半间隔为二分之一。原输入两点相距二，而核空间映射两点距离为一，因此核空间几何与原始欧氏几何不能混读。

如果只记录支持向量数量，这个例子始终是两个，宽度改变却会改变乘子、范数与查询函数。核模型的复杂度与几何不能由非零点数量唯一决定。若 $C$ 较小，乘子受上界限制、训练点进入间隔，恰好展示正则与宽度共同作用，而非两个彼此独立的开关。

<a id="detail-41"></a>

### 10.13 将近邻概率误差接到分类风险

在邻居由输入而非当前标签选择、给定输入后标签条件独立的条件下，近邻正类比例是一个局部概率估计。若真实概率函数为 Lipschitz，最远距离为 $r_k$，则条件偏差绝对值至多 $Lr_k$；每个伯努利方差至多四分之一，均匀平均方差至多 $1/(4k)$。所以相对查询真实概率的均方误差可由 $L^2r_k^2+1/(4k)$ 控制。

当估计概率与真实概率位于二分之一两侧时，概率绝对误差至少为真实概率距边界的距离，而分类过剩条件风险为这个距离的两倍。因此整体过剩风险至多为两倍平均概率绝对误差，再由 Cauchy–Schwarz 控制为概率均方误差平方根的两倍。这里控制的是超过贝叶斯风险的部分，不是总错误率必然趋零。

这条证据链解释为什么同时缩小邻域并增加邻居数有意义：它让局部偏差与标签平均波动一起下降。若度量使用同批标签自适应学得，或训练记录有依赖，前面的条件分析不自动成立，需要样本分离、完整复杂度控制或其他论证。形式相似的误差界不能忽略邻居是怎样被选出来的。

<a id="detail-42"></a>

### 10.14 平局与训练自邻居不能藏在默认行为里

二分类、均匀权重、邻居数为奇数时，可以避免正负票数恰好相同，但不解决所有平局：多分类三个邻居分属三个类别仍同票，距离权重也可能让不同票数的权重和相等。查询在相同距离边界上有多个候选时，行顺序或索引规则还可能改变选入集合。应明确规则，并检查预测对无意义行重排是否敏感。

评价训练样本的一近邻时，如果允许它自己成为零距离邻居，通常会得到完美或近乎完美的记忆结果，不能作为新对象风险。留一评价需要排除自身，但如果库中还有同实体近重复，也未必模拟陌生实体；应按任务单位设计分组。相反，某些业务确实允许命中完全相同的历史对象，此时重复匹配可以合法，但应与未知对象表现分开。

这些细节不只是软件边角。它们决定一条查询真正使用了哪些标签、结果如何处理，以及评价回答什么问题。理论中的独立新样本假设，需要在数据和接口层获得对应实现，不能只在正文里声明后就默认成立。

## 11. 分层练习与详细解析

<a id="detail-43"></a>

### 11.1 几何练习：缩放不改变边界

**题目。** 分数为 $2x_1-x_2+3$，同时把所有参数乘五，点到边界的几何距离是否改变？函数分数改变多少？

**解析。** 分数乘五，权重范数也乘五，比例不变，所以几何距离不变，符号亦不变。不能仅因分数更大就称间隔变大。若只改变部分参数或输入尺度，则边界或度量发生变化，需要重新计算。最大间隔训练首先固定函数间隔尺度，正是为了排除这种任意性。

<a id="detail-44"></a>

### 11.2 距离练习：确定性扰动界

**题目。** 某线性模型权重范数为二，某点分数为零点六。多大的欧氏扰动以内可以保证符号不变？是否保证真实标签不变？

**解析。** 扰动范数严格小于零点三时，分数变化小于零点六，不能跨零边界。等于界时可能到边界，需看方向和平局。结论仅针对当前模型符号，真实语义标签可能随输入变化，也可能原预测就错。核空间间隔转换到原始扰动，还需映射距离或相应 Lipschitz 控制。

<a id="detail-45"></a>

### 11.3 目标练习：换算正则参数

**题目。** 平均合页损失加 $\lambda\|w\|^2/2$，样本一百、$\lambda=0.02$，对应求和软间隔 $C$ 是多少？样本翻倍而其他规范不变时怎样保持同一个平均惩罚？

**解析。** $C=1/(n\lambda)=1/2$。样本二百、平均惩罚仍零点零二时，对应 $C=1/4$。这只是整体目标尺度等价，不保证不同样本模型相同。若实现惩罚截距或用平方合页，公式对象已变，不能照搬。记录完整目标比只记录参数名更可靠。

<a id="detail-46"></a>

### 11.4 松弛练习：正确分类也可能违反间隔

**题目。** 有符号函数间隔分别为一点五、零点三、负零点二，最小松弛各是多少？哪些点错分，哪些可能成为上界支持向量？

**解析。** 松弛分别零、零点七、一点二。第二点仍正确但在单位间隔内，第三点错分。后两点最优条件下可能对应上界乘子，第一点严格在外通常乘子零。退化与数值容差需要另外考虑，不能仅由粗略图形为每个点指定唯一乘子大小。

<a id="detail-47"></a>

### 11.5 对偶练习：为什么有标签和约束

**题目。** 对偶中的 $\sum_i\alpha_i y_i=0$ 从哪里来？若原始模型固定没有截距，是否仍应强行加它？

**解析。** 它来自对无约束截距取拉格朗日下确界：线性系数不为零时，下确界为负无穷，必须令系数零。没有截距时不存在这个驻点要求，标准对偶相应不同。若把截距作为被惩罚的额外特征，也会得到另一个结构。推导应从真实原始目标出发，而非背诵一个对所有实现通用的式子。

<a id="detail-48"></a>

### 11.6 KKT 练习：自由支持向量与截距

**题目。** 某点 $y=1$，乘子严格在零与 $C$ 之间，核展开不含截距部分为零点七。求截距。若该点乘子等于 $C$、松弛零点四，结果是否相同？

**解析。** 自由点松弛零，分数应为一，所以截距零点三。上界点若松弛零点四，则分数为零点六，截距为负零点一。把所有支持向量都当单位间隔点平均，会算错。实际没有自由支持向量时，需要按完整不等式求截距区间或使用求解器一致策略。

<a id="sec-7-1"></a>
### 边界追问：任意相似度能否替代核

**题目。** 矩阵对角为一，非对角为二，所有数非负且对称，是否足以作为标准核 Gram？如何反驳？

**解析。** 向量一、负一的二次型为负二，说明不正半定，不具备标准内积解释；对偶二次部分也不能直接沿用相应凸性保证。可以研究专门不定相似方法，但必须明确新目标。一个程序愿意接受矩阵，不等于数学条件已经满足。有限 Gram 合法也只检查当前集合，函数全域合法还需构造证明。

<a id="detail-49"></a>

### 11.7 核构造练习：显式特征少了系数

**题目。** 将二次映射的根号二全部去掉，是否仍与 $(1+x^\top z)^2$ 完全一致？是否因此一定不是合法核？

**解析。** 不一致，因为展开中的线性和交互系数变了。只要新相似仍定义为该显式向量的内积，就仍是合法核，只是另一种表示与范数几何。合法性、等价性与任务有效性是三种不同问题。应通过小点内积核对，而不是只看多项式次数相同就宣称完全一样。

<a id="detail-50"></a>

### 11.8 RBF 练习：单位与宽度

**题目。** 所有输入扩大十倍，原 RBF 参数为零点二，怎样调整使每个核值不变？只扩大一列能否同样处理？

**解析。** 距离平方扩大一百倍，参数应改为零点零零二。只扩大一列改变各向异性权重，单一全局参数通常不能同时恢复所有距离。可采用训练内标准化或明确的度量矩阵，再联合选择核参数。单位调整关系是代数，不能替代业务上什么距离合理的判断。

<a id="detail-51"></a>

### 11.9 近邻练习：分类噪声不会凭距离消失

**题目。** 所有输入都没有额外标签信息，正例概率零点三。独立最近邻标签用于预测新标签，一近邻错误率是多少？最优常数分类错误率是多少？

**解析。** 两个独立同概率标签不同的概率为 $2\times0.3\times0.7=0.42$。最优恒负错误率零点三。增加数据可以缩小距离，却不消除单条标签随机性。让邻居数增长可以平均噪声，但同时要保持邻域足够局部；在当前无特征信号例子里，全局多数即可有效。

<a id="detail-52"></a>

### 11.10 权重练习：十个邻居未必有十份支持

**题目。** 三个邻居权重零点八、零点一、零点一，独立同方差噪声为四。预测噪声方差多少？与均匀三邻居比较。

**解析。** 方差为 $4(0.64+0.01+0.01)=2.64$；均匀权重为四除以三，约一点三三三。强集中提高近点影响，也减少噪声平均。它可能降低局部偏差，所以不能仅看方差判定整体更差；需要把邻域均值变化、测量与样本相关一起考虑。重复同实体记录还可能使独立条件失效。

<a id="detail-53"></a>

### 11.11 维数练习：同质量邻域的边长

**题目。** 均匀单位立方体中想覆盖千分之一质量，比较一维和三维所需轴对齐边长。为什么它不直接给任意数据的最近邻半径？

**解析。** 边长为质量的维数次方根，一维零点零零一，三维零点一。它说明高维中同样质量需要更宽区域，但真实数据可能不均匀、位于低维流形、有边界或使用不同度量。体积算例是机制说明，不是无条件精确半径预测。研究时应测实际距离分布与覆盖。

<a id="detail-54"></a>

### 11.12 校准练习：给分数套 sigmoid 是否足够

**题目。** 两个模型分数相差一个正比例，分类符号完全一致。直接 sigmoid 后概率是否相同？这说明 SVM 分数如何解释？

**解析。** 一般不同，分数零以外，放大绝对值会让 sigmoid 更极端。分类等价没有确定概率尺度。若需要概率，应按适当数据与协议拟合校准，再独立评价概率与行动。校准还可能依赖部署先验与来源，不能只证明输出在零一之间就声称可靠。

<a id="detail-55"></a>

### 11.13 计算练习：预计算核的查询形状

**题目。** 训练三百条，查询二十条，预计算核输入通常应是什么形状？为什么二十乘二十不够？

**解析。** 需要二十乘三百，每个查询与同顺序训练样本的核值，供支持展开使用。二十乘二十只给查询间关系，缺少训练参照。若训练核先经过数据拟合的中心化或变换，查询必须复用训练状态，不能独立重做。矩阵维度只是最低检查，列的实体顺序同样关键。

<a id="detail-56"></a>

### 11.14 研究练习：如何区分表示和模型收益

**题目。** 新模型用监督降维后的近邻，基线是原始尺度线性 SVM，前者更好。能否把全部收益归给近邻？设计合理对照。

**解析。** 同时改变了表示与学习规则。可以比较原表示与新表示分别搭配近邻、线性 SVM，前处理训练边界和搜索预算一致，使用独立评价。监督降维必须各训练部分拟合。若新表示普遍改善，主要证据可能指向表示；若只在近邻上改善，则研究交互。结论应来自完整对照，而非算法名称。

<a id="detail-57"></a>

### 11.15 最优性练习：相同目标却不同硬分类

**题目。** 两点例子 $C=0.1,w=0.2$，比较截距零与零点八的原始目标和训练错误。为什么不违反凸性？

**解析。** 截距零时两点正确，松弛均零点八；截距零点八时负例错、正例达到单位间隔，松弛一点六与零。总松弛相同，范数相同，目标均零点一八。目标对截距不严格凸，最优解可以不唯一。凸性保证适当条件下局部最优就是全局最优，不保证所有最优解拥有相同未优化的零一错误。
