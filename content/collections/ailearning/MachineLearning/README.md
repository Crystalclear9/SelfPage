## 贯通实验：把设备监测做成可评价的学习问题

先定义预测对象：每台设备在一个时点，只使用此前已到达的传感器记录，预测随后一段时间是否发生指定事件。设备标识、预测时刻、特征可得时间、标签窗结束和标签记录时间都应保留。按未来设备、已有设备的未来时段或两者组合划分，会回答不同泛化问题；应在选模型前固定目标。

无监督学习可以帮助发现表示、群体和偏离，但聚类颜色与异常分数不能直接充当真实事件标签。先冻结表示与探索范围，比较原空间邻域、群体来源、异常审核覆盖和重采样稳定性。若使用人工反馈解释某簇，这些反馈已经参与发现；需要另外保留外部核验，不能再把同一批标签当作完全独立证据。

概率模型提供不同计算角色：朴素贝叶斯描述已知类别下的生成关系，混合模型积分未知来源，贝叶斯后验整合参数不确定性，HMM 表达状态随时间的依赖。选择应对应数据过程。一个高密度样本仍可能发生目标事件；EM 收敛不证明来源真实；平滑能解释过去，却不能代替只使用当时信息的过滤评价。

模型评估把这些候选放进同一协议。预处理、特征筛选、超参数和校准都放在相应训练边界内；使用完整成熟标签核对分类、排序与概率指标；在独立开发信息上选择阈值与告警容量，再冻结后进行测试。不同系统若使用不同历史长度或标注机会，需要说明额外信息，避免把它们当成算法本身的优势。

最终按设备或真实独立单位给配对比较与区间，同时报告延迟、告警量、覆盖和失效样本。上线后区分输入组成变化、类先验变化与条件关系变化；没有目标标签时，明确哪些性能结论尚不可识别。每条结果都应能回溯到数据角色、选择过程、参数版本与可用信息，而不只有一个最好分数。
