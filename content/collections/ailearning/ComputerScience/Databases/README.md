# 数据库与 SQL

从一行的业务含义出发，推导筛选、聚合、连接和窗口的结果，再用版本重放、一致快照及恢复协议可靠提取训练数据。

**先修知识：** 表格、行列与基本编程概念。

**正文篇幅状态：** 本主题现有 4 章均已按长篇教材标准展开，逐章纯正文达到 12000–20000 汉字。完整范围见[长篇教材覆盖表](../../README.md#textbook-status)。

## 学习顺序与覆盖范围

## 如何完成本主题

完成各章后，先用手工数据验证空值、重复键、同时间事件、迟到修订、删除与分页并发这六类边界，再独立完成[第 4 章练习与详解](04-索引执行计划与可靠数据提取.md#db-4-detail-53)。尝试为每种错误写出最小反例，并说明实验支持的前提。

读完后，应能先写出一行代表什么、键是否唯一、NULL 如何进入分母，再手算一个含空输入与重复键的反例。对历史特征，要独立解释事件时间、可用时间、版本号及样本截止时刻；对提取任务，要说明快照、排序键、分页游标和提交进度分别保证什么。每次改写查询，都用完整行与重数验证语义，再比较资源与运行成本。
