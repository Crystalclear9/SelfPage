# 数据库与 SQL

从一行的业务含义出发，推导筛选、聚合、连接和窗口的结果，再用版本重放、一致快照及恢复协议可靠提取训练数据。

**先修知识：** 表格、行列与基本编程概念。

## 学习顺序与覆盖范围

先在第 1 章建立键、NULL、多重集和指标分母的语义；第 2 章将它们用于连接基数、事务与历史可见性；第 3 章推导窗口帧和双时间特征；第 4 章在结果等价前提下研究执行计划、分页与故障恢复。每章都有可独立运行的 SQLite 实验。初次学习按顺序阅读，已有基础可通过章内目录定位反例与推导。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。
