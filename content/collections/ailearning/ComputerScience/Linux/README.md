# Linux 与命令行

从路径、参数、字节流和进程机制出发，组织可恢复的实验任务，并依据资源指标与反例定位服务器故障。

**先修知识：** 了解文件夹、文件和程序。完整示例需在 Linux 或 WSL 中执行，并具备 Bash；仅有兼容 shell 不足以复现 Linux 内核、信号与文件系统行为。

## 学习顺序与覆盖范围

先在第 1 章区分名称、对象、参数和描述符；第 2 章研究进程生命周期、信号、日志与环境；第 3 章把这些机制组织为明确的脚本输入、并发和完成协议；第 4 章依据资源证据开展监控与故障诊断。正文注明 Linux/Bash 前提，完整实验与解释性命令分别使用。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。
