# Linux 与命令行

从路径、参数、字节流和进程机制出发，组织可恢复的实验任务，并依据资源指标与反例定位服务器故障。

**先修知识：** 了解文件夹、文件和程序。完整示例需在 Linux 或 WSL 中执行，并具备 Bash；仅有兼容 shell 不足以复现 Linux 内核、信号与文件系统行为。

**正文篇幅状态：** 本主题现有 4 章均已按长篇教材标准展开，逐章纯正文达到 12000–20000 汉字。完整范围见[长篇教材覆盖表](../../README.md#textbook-status)。

## 学习顺序与覆盖范围

先在第 1 章区分名称、对象、参数和描述符；第 2 章研究进程生命周期、信号、日志与环境；第 3 章把这些机制组织为明确的脚本输入、并发和完成协议；第 4 章依据资源证据开展监控与故障诊断。正文注明 Linux/Bash 前提，完整实验与解释性命令分别使用。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：为中断与重跑定义完成状态](04-服务器实验的监控与故障排查.md#sec-7-1)，再对照逐步解析与验收要求。

读完后，应能预测参数数组、描述符连接、退出状态与父子进程的变化，再用最小实验核对。针对一次静默、失败或变慢，提出至少两个竞争解释，并写出可以区分它们的观测；对恢复流程，说明输入身份、临时产物、发布边界、重试条件和子进程回收规则。把这些约定交给另一人，应能在一个小任务上独立运行与验收。
