# Git 版本管理

从工作区、索引、对象与引用建立版本模型，理解合并和撤销的语义，为协作交付和机器学习实验留下可核对的版本依据。

**先修知识：** 能在终端运行命令。

## 学习顺序与覆盖范围

第 1 章建立快照、索引与对象图；第 2 章推导祖先关系、三方合并及语义冲突；第 3 章在明确判定条件下检查历史、定位问题和撤销；第 4 章把引用同步与实验清单组织为可审查交付。先画状态和提交图，再预测命令结果，最后运行隔离实验核对。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。
