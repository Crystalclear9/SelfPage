# 数据结构与算法

从输入规模与计算模型出发，用不变量和正确性证明选择数据结构与算法，再研究状态压缩、近似保证、检索与外存处理的边界。

**先修知识：** Python 基础。

## 学习顺序与覆盖范围

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：同一数据流选择排序、堆与分块](04-堆近邻与大数据处理策略.md#sec-8-1)，再对照逐步解析与验收要求。

按 01→02→03→04 阅读：先明确代价模型，再用不变量分析基础算法，接着推导状态与转移，最后围绕输出需求设计精确或近似的大数据流程。每次优化都应保留小规模独立参考，区分最优值、恢复方案与资源代价。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
