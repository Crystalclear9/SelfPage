# 数据结构与算法

从输入规模与计算模型出发，用不变量和正确性证明选择数据结构与算法，再研究状态压缩、近似检索、启发式搜索、约束传播与动作规划。

**先修知识：** Python 基础。

## 学习顺序与覆盖范围

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

| 章节 | 主要内容 | 深入讲解入口 |
| --- | --- | --- |
| [复杂度与基础数据结构](01-复杂度与基础数据结构.md) | 计算模型与增长阶、最坏/平均/期望/摊还；动态数组和哈希假设；容器与表示成本 | [进入讲解](01-复杂度与基础数据结构.md#deep-dive-2) |
| [二分排序与图遍历](02-二分排序与图遍历.md) | 二分半开不变量、稳定排序和比较下界；BFS/DFS/拓扑/SCC、Dijkstra 条件与独立图参考 | [进入讲解](02-二分排序与图遍历.md#deep-dive-1) |
| [递归动态规划与最优子结构](03-递归动态规划与最优子结构.md) | 状态充分性与方案恢复；硬币/背包/编辑距离/区间实验；子集和概率 DP、折扣收缩、近似保证及证书 | [进入讲解](03-递归动态规划与最优子结构.md#deep-dive-2) |
| [堆近邻与大数据处理策略](04-堆近邻与大数据处理策略.md) | 稳定 Top-k 与合并反例、外部归并、方差摘要；分块精确近邻、量化/召回、草图和均匀抽样 | [进入讲解](04-堆近邻与大数据处理策略.md#deep-dive-1) |
| [启发式搜索、约束满足与符号规划](05-启发式搜索约束满足与符号规划.md) | A* 重开与下界、AC-3 与回溯、动作规则与计划重放 | [进入讲解](05-启发式搜索约束满足与符号规划.md#search-state) |

## 阅读顺序

按 01→02→03→04→05 阅读。先明确代价模型，用不变量分析图遍历，再推导状态与转移、学习堆的接口。第 5 章把这些工具用于可验证的搜索、约束传播与确定性规划。只为读规划而来时，第 4 章先读最小堆与优先队列，外存和近似近邻按需回读。每次优化都应保留小规模独立参照，区分最优值、恢复方案与资源代价。
