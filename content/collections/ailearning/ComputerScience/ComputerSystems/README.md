# 计算机系统基础

从执行、虚拟内存与共享状态理解程序行为，再分析缓存、流水线和GPU资源，最后用同条件测量与受控干预定位瓶颈。

**先修知识：** Python；文件与程序运行的基本经验。

## 如何完成本主题

完成第 1—4 章后，先独立作答[综合练习：局部提速能否推算整体提速](04-GPU并行显存与分布式入门.md#sec-7-1)，再对照逐步解析。读完第 5 章后，再完成[性能建模与瓶颈推断研究任务](05-性能建模基准实验与瓶颈推断.md#sec-10)：为同一任务提出竞争瓶颈假设，用受控实验核对，并说明质量约束、计时边界与尚未排除的原因。

按 01→02→03→04→05 阅读：从执行与状态出发，逐步理解并发、数据供给和设备资源，最后建立完整性能证据。GPU 与分布式段落明确区分代数模型、使用条件和本地 CPU 验证；不能把模型估算当成专用硬件实测。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
