# Python 编程基础

从数据处理的小程序入手，掌握写训练脚本所需的语言、文件与组织能力。

**先修知识：** 无需编程基础；需能使用编辑器和终端。

## 学习顺序与覆盖范围

第 1—3 章建立语言、文件与运行基础，第 4—5 章把代码组织成可配置、可验证的小项目。完成前五章后即可进入 NumPy，并在使用框架接口时返回第 6 章研究描述符、类型协议、生成器与协程；不必先掌握全部高级对象机制再开始数据处理。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成第 1—5 章后，先独立作答[综合练习：验证数据变换是否有副作用](05-调试测试与可复现小项目.md#sec-7-1)，再对照逐步解析。完成第 6 章后，再做[流式评分组件综合项目](06-对象协议类型约束与执行模型.md#sec-12)，验收迭代器重建、参数更新、提前退出与状态隔离；两项任务分别覆盖基础项目组织与进阶协议设计。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
