# NumPy 数值数组

掌握形状、广播、索引与向量化，为数据处理和张量计算打基础。

**先修知识：** Python 容器与循环；矩阵基本概念。

## 学习顺序与覆盖范围

第 1—3 章先建立数组操作能力；第 4 章是工具与模型的衔接，在学习[平方损失与梯度下降](../../Mathematics/Optimization/01-目标函数梯度下降与约束.md)后返回。首次阅读可暂缓谱收敛分析，不影响继续学习 Pandas。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：区分语法兼容与样本目标](04-用NumPy实现线性回归训练.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
