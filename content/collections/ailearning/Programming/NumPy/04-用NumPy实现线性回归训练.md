## 1. 前向目标与梯度：先定义程序接受什么

<a id="numpy-4-detail-2"></a>

### 1.1 一个数组接口实际上承诺了什么

设训练数据为 $`X\in\mathbb R^{n\times d}`$，一行对应一个样本，一列对应一个特征；标签为 $`y\in\mathbb R^n`$，系数为 $`w\in\mathbb R^d`$，截距为标量 $`b`$。预测为 $`\widehat y=Xw+b`$。这里每个轴都有含义：一个长度为二十的向量究竟是二十条标签还是某条样本的二十个特征，不能由元素个数自行决定。

本章采用平均半平方损失，并可加入只作用于权重的二次惩罚：

$$
\begin{aligned}
J(w,b) &=\frac1{2n}\Vert Xw+b\mathbf1-y\Vert _2^2+\frac\lambda2\Vert w\Vert _2^2,\\[6pt]
\lambda &\ge0.
\end{aligned}
$$

当 $`\lambda=0`$ 时是普通最小二乘；当 $`\lambda>0`$ 时截距仍不受惩罚。这是模型定义的一部分。若把常数列拼进矩阵，再对全部参数等同惩罚，就已经换成另一个目标。很多看似求解器差异，实际来自这些不显眼的约定。

一个有用的输入契约至少包括二维特征、一维标签、正样本数、相同样本顺序、固定列顺序、有限实数和可接受的数值范围。形状断言只能保证一部分。把标签独立打乱，形状完全正确，程序仍会优化一个失去原配对关系的新问题。因此数据进入数组之前应完成键与顺序核对，训练内部则保持共同索引。

不要把所有输入强制展平成一维当作通用修复。若原任务是多输出回归，标签本来应为 $`(n,k)`$；任意展平把样本轴与输出轴合并，掩盖了任务差异。本章明确只接受单输出，遇到二维标签就报错；扩展任务时再重新定义预测、归约与参数形状。

<a id="numpy-4-detail-3"></a>

### 1.2 从微分到接口中的三个返回量

令 $`r=Xw+b\mathbf1-y`$。固定数据后，目标微分为

$$
dJ=\frac1n r^TX\,dw+\frac1n r^T\mathbf1\,db+\lambda w^Tdw.
$$

所以权重梯度为 $`g_w=\frac{X^Tr}{n}+\lambda w`$，截距梯度为 $`g_b=\operatorname{mean}(r)`$。函数应同时返回目标值、权重梯度和截距梯度，而且三者必须在同一份参数上计算。若先更新权重，再用新权重重新算截距梯度，就不再是这里定义的一次同时梯度下降。

目标值中数据项与正则项可以分别记录。这样能区分训练误差下降、权重收缩和总目标变化。若只记录均方误差，却用含正则的梯度训练，曲线就不能被当作实际优化目标；反过来，拿含正则的训练目标直接比较不同 $`\lambda`$ 的独立预测效果，也没有明确意义。

标量返回量最好转换为普通浮点数，用于日志与接口；梯度保留一维数组。返回梯度后不要让调用者意外改动内部参数，训练状态与临时残差也应分开。小程序中这些边界看似繁琐，但一旦加入检查点、回调和多个实验，别名错误往往比公式错误更难发现。

### 基础算例：只用一条样本核对权重和偏置更新

取一条样本 $`x=(1,2)`$，目标为三，初始权重与截距都是零，暂不加正则。预测为零，残差为负三，半平方损失为四点五。权重梯度为 $`(-3,-6)`$，截距梯度为负三。学习率为零点一时，新权重为 $`(0.3,0.6)`$，新截距为零点三，新预测为一点八，损失为零点七二。

这个例子同时检查了正负号、特征维数、截距和二分之一系数。若得到新预测一点五，可能漏了截距；若梯度为两倍，可能使用了完整平方损失；若权重第二分量不是第一分量两倍，可能发生轴或样本配对错误。先对小例子做独立推算，再谈大数据上曲线是否平滑，诊断效率会高很多。

再取两条一维样本 $`X=(1,2)^T`$、$`y=(2,4)^T`$，先固定截距为零。初始目标为五，梯度为负五；一次零点一步长更新后，权重为零点五，目标为二点八一二五。这里分母是二条样本；若误用特征数一，更新就翻倍。单条样本不能发现所有归约错误，所以至少要准备不相等的样本数和特征数。

### 深入讲解：手写回归训练的每一步怎样对应目标中的一项

训练不是先写循环，再寻找一个损失公式解释它。应先列出固定数据、可变参数、归约方式、正则对象和返回时刻，再逐项映射到数组表达。矩阵乘法实现线性预测，广播只给每条预测加同一个截距，转置乘残差汇总各列贡献，平均提供样本尺度，正则项加入权重梯度。

这条映射还提供了修改模型时的检查表。增加样本权重，就必须改变损失与梯度分母；增加多个输出，要决定按样本求和还是对全部元素平均；改用非均匀抽样，要重新确定梯度估计；标准化特征后加同一个岭系数，也可能改变原坐标中的惩罚。能运行的表达式不自动继承原目标的统计意义。

手写实现最有价值的产物是这种可追踪性。它允许我们构造故障、验证不变性、比较独立求解路径，并准确说明实验改变了什么。若最终只是把所有逻辑包进一个无法解释的函数，就失去了练习的主要收益。

## 2. 完整代码：建立最小而明确的训练器

<a id="numpy-4-detail-7"></a>

### 2.1 一段可以独立运行的全批实现

下面先训练无噪声、尺度温和的人工数据，不引入标准化或早停。这样如果不能恢复已知参数，就能优先调查接口、梯度和迭代预算。函数明确复制参数初值，所有更新使用同一份梯度；历史的第一项对应初值，之后每项对应一次更新后的参数。

代码检查有限输入，但有限输入经过平方或矩阵乘法仍可能溢出。局部浮点异常处理用来暴露这类失败，不意味着算法可以处理任意数值范围。对很大的原始量，首先考虑合理单位、训练统计缩放或更稳妥的目标，而不是关闭异常后继续训练。

```python
import numpy as np

def objective_grad(X, y, w, b, lam=0.0):
    if (X.ndim != 2 or y.ndim != 1 or w.ndim != 1
            or X.shape != (y.size, w.size) or y.size == 0):
        raise ValueError("expected X:(n,d), y:(n,), w:(d,), n>0")
    if not all(np.isfinite(a).all() for a in (X, y, w)):
        raise ValueError("non-finite array")
    if not np.isfinite(b) or not np.isfinite(lam) or lam < 0:
        raise ValueError("invalid scalar")
    with np.errstate(over="raise", invalid="raise", divide="raise"):
        r = X @ w + b - y
        value = 0.5 * np.mean(r * r) + 0.5 * lam * (w @ w)
        gw = X.T @ r / y.size + lam * w
        gb = float(np.mean(r))
    if not np.isfinite(value) or not np.isfinite(gw).all() or not np.isfinite(gb):
        raise FloatingPointError("non-finite objective or gradient")
    return float(value), gw, gb

def fit_full(X, y, steps=500, lr=0.1, lam=0.0, initial=None):
    if np.iscomplexobj(X) or np.iscomplexobj(y):
        raise ValueError("this trainer accepts real data only")
    X = np.asarray(X, dtype=np.float64)
    y = np.asarray(y, dtype=np.float64)
    if X.ndim != 2:
        raise ValueError("X must be two-dimensional")
    if not isinstance(steps, int) or steps < 0 or not np.isfinite(lr) or lr <= 0:
        raise ValueError("invalid steps or learning rate")
    if initial is None:
        w, b = np.zeros(X.shape[1]), 0.0
    else:
        if np.iscomplexobj(initial[0]) or np.iscomplexobj(initial[1]):
            raise ValueError("initial parameters must be real")
        w, b = np.array(initial[0], dtype=np.float64, copy=True), float(initial[1])
    history = [objective_grad(X, y, w, b, lam)[0]]
    for _ in range(steps):
        _, gw, gb = objective_grad(X, y, w, b, lam)
        w = w - lr * gw
        b = b - lr * gb
        history.append(objective_grad(X, y, w, b, lam)[0])
    return w, b, np.asarray(history)

rng = np.random.default_rng(42)
X = rng.normal(size=(200, 2))
truth = np.array([2.0, -1.0])
y = X @ truth + 0.5
w, b, history = fit_full(X, y)
A = np.column_stack((X, np.ones(len(X))))
reference = np.linalg.lstsq(A, y, rcond=None)[0]
assert np.allclose(np.r_[w, b], reference, atol=1e-9)
assert np.allclose(w, truth, atol=1e-9) and abs(b - 0.5) < 1e-9
assert len(history) == 501
assert np.isclose(history[-1], objective_grad(X, y, w, b)[0])
print("parameters:", w, b, "final objective:", history[-1])
try:
    fit_full(X, y, initial=(np.array([1 + 2j, 0]), 0.0))
except ValueError:
    pass
else:
    raise AssertionError("complex initial parameters must be rejected")
```

这里没有显式求逆。最小二乘参考通过分解得到解，避免把正规矩阵的条件数平方当作必需代价。参考结果的角色也有限：无正则目标要与无正则参考比较，含截距训练要与含常数列设计比较，容差则与数值尺度和迭代误差对应。

### 机制展开：训练历史记录的时刻要明确

很多示例每轮先记录损失再更新参数。这样最后一个历史值对应最后一次更新前的模型，直接拿它配最终参数就会有一步错位。本实现把初值单独记录，随后每次记录更新后状态，因此长度为更新次数加一，且末项能够用最终参数重新算出。

记录时刻还影响早停和检查点。如果先评价模型甲、再更新成模型乙、却把评价分数与模型乙一同保存，恢复出来的就不是被选中的模型。应把参数快照、迭代编号和该快照的评价看成一组不可分割的数据。保存数组时需要复制，不能让后续原地更新改写历史最优参数。

本示例每次更新后又完整计算一次目标，便于教学核对，却会增加计算成本。实际训练可以降低评价频率，但应保留清楚的事件定义，例如每个完整训练轮结束后记录一次全量训练目标。不要为了节省计算，把不同参数上的小批损失拼起来后称为某个固定模型的精确训练损失。

<a id="numpy-4-detail-9"></a>

### 2.2 失败输入应该在哪里暴露

训练器中的检查应针对明确契约，而不是靠捕获任意异常后返回零。标签形状错误是调用问题，应立即报告；溢出是数值失败，应保留能够定位的数据尺度与迭代信息；超过预算但仍有限则是未收敛，不能混成同一种“训练失败”。

缺失值在本实现中不被接受。用零替代缺失并非数值修复，而是对数据含义作出假设，应在数据处理层有单独规则。类似地，类别编号作为实数进入回归，隐含了线性距离和顺序；程序无法替学习者判断这一表示是否合理。

为了让练习保持可阅读性，代码没有实现通用数据模式、优化器注册和自动日志系统。把每个失败对象解释清楚，比增加一套复杂接口更重要。当扩展到实际项目时，可把这些契约变成独立验证函数，但仍应保留一条能够手工重建的最小计算路径。

## 3. 扩展到小批量：同一个目标与不同的更新轨迹

<a id="numpy-4-detail-11"></a>

### 3.1 固定参数累积与逐批更新的差别

把全部样本分成若干互不重叠的批次，第 $`j`$ 批大小为 $`n_j`$。在同一参数上计算各批的平均数据梯度 $`g_j`$，全量数据梯度就是 $`\sum_j(\frac{n_j}{n})g_j`$。这只是有限和重新分组，没有随机近似。若最后一批比其他批小，就不能把各批梯度等权平均，否则小批样本得到更大权重。

例如前四条样本的数据梯度均值为一，最后一条为五，全量均值为一点八，而两个批均值的简单平均为三。这两种计算都能得到形状正确的数组，却表示不同的样本目标。把批量大小从四改成五时结果突然变化，首先要调查归约，而不是解释为随机训练的自然波动。

若每处理一批就立即更新，下一批梯度已经在新参数上计算，一个轮次通常不再等于一次全批梯度下降。即使两批大小相同、使用完全相同样本，也只有在特殊结构或零步长极限下才可能一致。这里要区分代数重组、随机估计和迭代算法三个层次，不能用“都看过全部数据”证明更新等价。

正则项同样必须对应更新次数。固定参数累积一个大批梯度时，正则梯度只加入一次；若各批函数都已经包含完整正则，就要按批样本权重加权后相加，权重和为一。逐批更新时每次加入正则，是在定义一个不同的迭代过程，不能把一个轮次中累计的惩罚力度想当然等同于一次全批更新。

<a id="numpy-4-detail-12"></a>

### 3.2 一个可精确复现的顺序效应

取两条一维样本 $`(x,y)=(1,1),(2,0)`$，截距固定为零，初始权重为零，学习率零点一。先看第一条，梯度为负一，权重变为零点一；再看第二条，梯度为零点四，权重变为零点零六。反过来处理，第二条的初始梯度为零，随后第一条把权重推到零点一。

全批目标梯度在初值为负零点五，一次全批更新得到零点零五。三种结果都可以由正确代码产生，只是算法不同。这也说明不能把每轮末权重与某个全批更新结果硬性比较，必须先对齐更新数、学习率、样本顺序和归约规则。

随机打乱通常能避免长期固定顺序造成某些系统性轨迹，但随机重排并不等于每步独立有放回采样。给定前面已经抽到的样本，剩余样本分布会变化，因此简单的条件无偏证明不能直接照搬。实践中可以采用每轮重排，但在理论说明与实验日志里要准确命名抽样方式。

<a id="numpy-4-detail-13"></a>

### 3.3 批损失、轮次损失与在线日志

一次轮次中累加的批损失来自不断变化的参数，按样本加权后可以描述训练经过的平均损失，却不是轮末模型的全量目标。如果要比较不同训练器或画严格的目标曲线，应在共同检查点固定参数，重新遍历训练集计算总残差平方，再除以实际样本数。

这个区别在学习率较大时更明显。前面批次刚被拟合得较好，后面批次又把参数拉向另一方向，在线损失很低并不能保证轮末对所有样本都好。另一方面，额外全量评价会花时间，因此性能比较也应包含或明确排除相同的评价开销，不能让某个算法免费获得更多测量。

损失随更新下降也不是每步必然成立的规律。单批梯度可能让当前批变好、其他批变差；固定步长随机训练在最优点附近也会持续波动。若目标是达到高精度全批解，需要降低步长、增加批量或使用其他策略；若目标是有限预算下的独立预测，则还要比较验证效果而非只比较训练精度。

<a id="numpy-4-detail-14"></a>

### 3.4 随机状态是训练状态的一部分

本章把数据生成与训练打乱放在不同随机流中。否则为了多画一个随机样本图而额外调用生成器，就会改变后续打乱顺序，使训练轨迹变化。独立子流不是不同实验结果必然独立的数学证明，但可以减少程序中无关操作之间的状态耦合，便于复现与调试。

同样的种子只说明生成器从同一个初始位置开始。若恢复模型后重新设种子，打乱顺序也回到了开头，而不是接着中断位置继续。准确恢复还需要生成器状态、轮次编号、当前排列和批次位置；在轮次边界保存时可以省去后两者，因为下一轮尚未生成新排列。

下面在轮次边界恢复，用内存中的深复制保存状态，不生成检查点文件。它验证的是同环境、同代码和同计算顺序下的连续性；跨版本、不同线性代数后端或不同并行归约不能由这个例子获得逐位一致保证。NumPy 的随机接口也没有承诺所有版本保持相同分布变换输出。

```python
import copy
import numpy as np

rng_data = np.random.default_rng(701)
X = rng_data.normal(size=(37, 3))
y = X @ np.array([1.2, -0.5, 0.8]) + 0.3

def train_epochs(X, y, w, b, rng, epochs, batch=8, lr=0.03, lam=0.02):
    w = np.array(w, dtype=np.float64, copy=True)
    b = float(b)
    for _ in range(epochs):
        order = rng.permutation(len(y))
        for start in range(0, len(y), batch):
            idx = order[start:start + batch]
            r = X[idx] @ w + b - y[idx]
            gw = X[idx].T @ r / len(idx) + lam * w
            gb = float(r.mean())
            w = w - lr * gw
            b = b - lr * gb
    return w, b

rng_full = np.random.default_rng(91)
w_full, b_full = train_epochs(X, y, np.zeros(3), 0.0, rng_full, 12)

rng_part = np.random.default_rng(91)
w_part, b_part = train_epochs(X, y, np.zeros(3), 0.0, rng_part, 5)
snapshot = {
    "w": w_part.copy(),
    "b": b_part,
    "epoch": 5,
    "rng": copy.deepcopy(rng_part.bit_generator.state),
}
rng_resumed = np.random.default_rng()
rng_resumed.bit_generator.state = copy.deepcopy(snapshot["rng"])
w_resumed, b_resumed = train_epochs(
    X, y, snapshot["w"], snapshot["b"], rng_resumed, 7
)
assert np.array_equal(w_full, w_resumed) and b_full == b_resumed
print("exact resume:", w_resumed, b_resumed)

# 同一基点的分批累积必须等于全批数据梯度。
w, b = np.array([0.2, -0.1, 0.4]), 0.7
r = X @ w + b - y
gw_ref, gb_ref = X.T @ r / len(y), r.mean()
gw_acc, gb_acc = np.zeros(3), 0.0
for start in range(0, len(y), 8):
    xb, yb = X[start:start + 8], y[start:start + 8]
    rb = xb @ w + b - yb
    gw_acc += xb.T @ rb / len(y)
    gb_acc += rb.sum() / len(y)
assert np.allclose(gw_acc, gw_ref) and np.isclose(gb_acc, gb_ref)
print("accumulation agreement:", np.max(np.abs(gw_acc - gw_ref)))
```

只有权重、截距和随机状态还不构成完整实验。恢复时还应确认数据、特征顺序、标准化统计、目标定义和超参数与中断前相同。如果换了列顺序却沿用旧权重，即使数组长度一致，也无法继续原来的计算。实际检查点需要保存这些元数据，而不是只保存一个参数数组。

## 4. 逐步解释一次训练更新与故障诊断

<a id="numpy-4-detail-16"></a>

### 4.1 参数更新是一个共同基点上的操作

设当前参数为 $`(w_t,b_t)`$，先得到预测、残差、目标和两个梯度，再同时构造 $`(w_{t+1},b_{t+1})`$。这里的“同时”是数学含义，不要求两条赋值在同一机器指令中完成；只要两个梯度已经从旧参数计算好，依次赋值也是正确实现。

真正的问题是把参数更新插进梯度计算中间。例如先改权重、再重新计算残差求截距梯度，得到一种坐标式更新；若理论和参考仍按普通梯度下降写，就发生了算法错配。此类错误可能依然收敛，所以只看最终参数接近并不足以证明每一步实现正确。

对每次更新可保留一个短追踪表：参数版本、预测形状、数据项、正则项、梯度范数和更新范数。表不必永久记录全部数组，但应能在小例子上还原一次更新。更新范数除以参数范数时要考虑零初值，可同时报告绝对量，避免把无定义相对量伪装成异常训练。

<a id="numpy-4-detail-17"></a>

### 4.2 形状正确之外，还需要哪些独立证据

第一层是手算目标与一步更新，检测定义和系数；第二层是有限差分，检测局部导数；第三层是固定参数的全批与分批累积，检测归约；第四层是独立最小二乘解，检测整体优化；第五层才是独立数据表现，检测统计任务。各层提供不同证据，不能让一个测试替代全部。

有限差分也有前提。用中心差分时，应恢复参数、固定数据和随机状态，比较同一函数在两个邻近点的值。步长过小会被舍入淹没，过大会有截断误差；对大尺度坐标可按参数绝对值缩放扰动，再观察多个步长。检查通过支持局部导数一致，不能证明样本配对、泛化或全局最优。

平方目标有一个额外好处：其梯度是仿射函数，Hessian 固定，因此差分和独立线性求解都容易核验。但若实际程序已经错误地把预测与标签广播成方阵，有限差分可能仍然准确验证了那个错误目标的梯度。必须先确认前向值和残差形状，再运行梯度检查。

<a id="numpy-4-detail-18"></a>

### 4.3 一个不依赖训练曲线的方向检查

下面对含岭项的参数做方向差分，同时核对正则梯度与截距处理。方向只需要非零并归一化，多个方向能提高发现特定错误的机会，却不是检查所有坐标的证明。为了避免跨示例隐藏依赖，本段重新定义目标。

```python
import numpy as np

rng = np.random.default_rng(18)
X = rng.normal(size=(11, 4))
y = rng.normal(size=11)
theta = rng.normal(size=5)
lam = 0.3

def value_grad(theta):
    w, b = theta[:-1], theta[-1]
    r = X @ w + b - y
    value = 0.5 * np.mean(r ** 2) + 0.5 * lam * (w @ w)
    grad = np.r_[X.T @ r / len(y) + lam * w, r.mean()]
    return value, grad

value, grad = value_grad(theta)
direction = rng.normal(size=theta.size)
direction /= np.linalg.norm(direction)
for h in (1e-3, 1e-4, 1e-5):
    difference = (value_grad(theta + h * direction)[0]
                  - value_grad(theta - h * direction)[0]) / (2 * h)
    analytic = grad @ direction
    assert np.isclose(difference, analytic, atol=1e-8, rtol=1e-8)
print("directional derivative:", analytic)

# 正则只改变权重梯度，不改变截距梯度。
r = X @ theta[:-1] + theta[-1] - y
unregularized = np.r_[X.T @ r / len(y), r.mean()]
assert np.allclose(grad - unregularized, np.r_[lam * theta[:-1], 0.0])
```

若方向检查失败，应先缩小到一条样本或少量特征，打印预测、残差和每项梯度，再引入正则。盲目改小学习率可能让错误训练变得缓慢而不爆炸，却不会修复导数。类似地，梯度裁剪只是改变更新，不能用来掩盖错误广播产生的巨大梯度。

<a id="numpy-4-detail-19"></a>

### 4.4 浮点范围与停止条件要有可解释含义

训练中出现非有限数，应定位最早产生它的操作。输入有限但矩阵乘法溢出，与损失平方溢出，是不同的尺度问题；计算到一半才出现异常，可能来自不稳定步长。可以先用温和数据验证算法，再改变单一尺度因素，观察 Hessian 最大特征值与稳定步长是否相应变化。

目标改善很小也不必然代表已经接近最优。若学习率极小，即使梯度很大，每次变化仍然很小；若浮点精度不足，参数更新可能小于当地间距而被吞掉；若目标病态，大曲率方向已收敛，小曲率方向仍可能滞后。停止条件应综合更新预算、梯度、参考差距与任务容差。

对于严格凸二次目标，若知道最小特征值为 $`\mu>0`$，可用 $`J(\theta)-J^*\le\frac{\Vert \nabla J(\theta)\Vert ^2}{(2\mu)}`$ 给出目标差证书。推导是在二次坐标中把每个梯度分量平方除以对应曲率，再用曲率下界控制。没有可信的正下界时，这个证书可能无用，不能用一个随意估计值制造精确收敛承诺。

## 5. 综合算例：标准化、模型选择与独立评价

<a id="numpy-4-detail-21"></a>

### 5.1 标准化必须是一份可以保存的训练结果

假设训练特征均值为 $`\mu`$，每列尺度为 $`s_j>0`$，标准化后 $`Z_{ij}=\frac{(X_{ij}-\mu_j)}{s_j}`$。训练、验证和测试都必须使用训练得到的同一组 $`\mu,s`$。分别对每个数据集重新计算均值，表面上都得到标准化数组，实际却让同一原始输入依赖所处批次而改变预测。

对恒定训练列，可以把计算尺度设为一，使训练标准化列为零，避免除零；同时应保存“恒定列”标记，明确该列效应不能从训练数据识别。测试中这列若发生变化，是训练外情形，不应因为程序能计算就认为系数可信。极小尺度也需要依据单位和精度判断，不能只用严格等于零处理所有实际问题。

使用总体式训练方差分母 $`n`$ 或样本式分母 $`n-1`$ 都可以定义缩放，但会得到不同数值尺度，正则和学习率也要与之匹配。这里采用 NumPy 默认的总体式标准差，仅用于表示变换，不把它当作总体方差的无偏估计。名称相似的统计量有不同用途，不能让“无偏”成为选择标准化接口的唯一理由。

标准化统计也属于模型状态。保存权重而丢掉均值、尺度和列顺序，就无法恢复原预测。部署接口应接收与训练同语义的列，对缺列、重复列和未知列给出明确处理。训练代码内部的数组维度检查，不能代替数据进入模型之前的模式验证。

<a id="numpy-4-detail-22"></a>

### 5.2 把参数变回原单位，检查是否真的是同一个函数

在标准化空间拟合 $`\widehat y=Zv+c`$，代入定义得到

$$
\widehat y
=\sum_jX_j\frac{v_j}{s_j}
+\left(c-\sum_j\mu_j\frac{v_j}{s_j}\right).
$$

因此原单位权重是 $`w_j=\frac{v_j}{s_j}`$，原截距是 $`b=c-\mu^Tw`$。这条恒等式适合做部署验证：对同一组原始输入，标准化预测与原单位参数预测应在浮点容差内一致。若不一致，先检查截距与缩放方向，而不是把差异解释为模型随机性。

例如训练均值为十、尺度为二，标准化模型为三倍标准化输入加四，则原模型为一点五倍原输入减十一。原输入十二对应标准化值一，两种计算都给出七。若只把权重除以尺度而保持截距四，就会得到二十二，这不是轻微数值误差，而是漏了平移修正。

但表示等价不意味着“相同数值正则”保持等价。标准化空间的岭惩罚为 $`\frac{\lambda\Vert v\Vert ^2}{2}`$，代回原权重是 $`\lambda\sum_j\frac{s_j^2w_j^2}{2}`$。它对原坐标的不同方向采用不同权重。若目标原本是等权惩罚原单位系数，标准化后应使用对应的逆尺度惩罚，而不能原样沿用各向同性岭项。

也应区分无正则完整求解与有限步训练。满秩无正则最小二乘在可逆表示变换后有相同预测函数，但梯度下降的欧氏几何改变，有限预算得到的轨迹和结果可能不同。标准化既影响数值条件，也可能通过正则和早停改变统计偏好，这三个作用需要分别解释。

<a id="numpy-4-detail-23"></a>

### 5.3 验证集选择的是完整训练规则

本实验预先固定训练、验证、测试划分，只用训练集拟合标准化统计；在同一标准化表示上比较几个正则强度。每个候选都训练到相同的梯度容差，再用验证均方误差选一个，最后只对选中的候选计算测试结果。这样测试评价回答的是这一整套选择程序的外部表现。

如果看完测试结果又改正则、特征、随机种子或迭代预算，测试集就已进入选择链。程序中没有显式反向传播，并不意味着没有使用测试信息。多次探索也需要新的外部证据，或者采用事先设计的嵌套评价，不能靠换一个变量名恢复“独立测试”地位。

本章把验证选择与优化检查分开。每个候选还会和同目标的增广最小二乘参考比较，确认差异主要不是未收敛。若某个候选因曲率更小而收敛更慢，在固定很少更新下表现差，结论只能说明当前预算中的训练效果，不能直接说它的精确最优模型更差。

评价指标也要对齐。训练目标包含半平方误差与正则，验证选择使用不含正则的均方误差；测试同时报告均方误差与其平方根，后者与标签单位相同。每个量都有明确角色，不能把含正则的目标数值当作实际预测误差，或把不同归约的曲线放在同一纵轴比较。

<a id="numpy-4-detail-24"></a>

### 5.4 一个从生成数据到原单位预测的完整实验

下面生成尺度相差很大的四列数据，并加入相关性与标签噪声。人工真值能帮助解释，但训练器不读取真值。数据生成、划分分别使用独立随机流。例子没有文件写入，也没有把真实环境依赖藏进外部配置。

学习率由训练 Hessian 的最大特征值确定，这对小维度教学问题很方便；大规模模型不应默认形成完整 Hessian。参考解使用增广最小二乘，把惩罚转换为额外方程，并通过零截距列保证截距不受惩罚。

```python
import numpy as np

seeds = np.random.SeedSequence(20261016).spawn(2)
rng_data, rng_split = [np.random.default_rng(s) for s in seeds]
latent = rng_data.normal(size=(520, 4))
latent[:, 1] = 0.8 * latent[:, 0] + 0.5 * latent[:, 1]
scale_raw = np.array([1.0, 100.0, 0.01, 1.0])
X = latent * scale_raw + np.array([3.0, 20.0, -0.02, 1.0])
y = X @ np.array([1.5, -0.02, 20.0, 0.7]) + 2.0
y = y + rng_data.normal(scale=0.3, size=len(y))
order = rng_split.permutation(len(y))
train, valid, test = order[:320], order[320:420], order[420:]
mu = X[train].mean(axis=0)
scale = X[train].std(axis=0)
scale = np.where(scale == 0.0, 1.0, scale)
Z = (X - mu) / scale

def fit_candidate(z, target, lam):
    n, d = z.shape
    A = np.column_stack((z, np.ones(n)))
    penalty = np.diag(np.r_[np.ones(d), 0.0])
    H = A.T @ A / n + lam * penalty
    rhs = A.T @ target / n
    L = np.linalg.eigvalsh(H)[-1]
    theta = np.zeros(d + 1)
    threshold = 1e-10 * (1.0 + np.linalg.norm(rhs))
    for step in range(20000):
        grad = H @ theta - rhs
        if np.linalg.norm(grad) <= threshold:
            break
        theta = theta - grad / L
    else:
        raise RuntimeError("budget exhausted before tolerance")
    extra = np.sqrt(n * lam) * np.column_stack((np.eye(d), np.zeros(d)))
    A_aug = np.vstack((A, extra))
    y_aug = np.r_[target, np.zeros(d)]
    reference = np.linalg.lstsq(A_aug, y_aug, rcond=None)[0]
    assert np.allclose(theta, reference, atol=1e-7, rtol=1e-7)
    return theta, step

candidates = []
for lam in (0.0, 0.005, 0.05):
    theta, updates = fit_candidate(Z[train], y[train], lam)
    pred_valid = Z[valid] @ theta[:-1] + theta[-1]
    mse_valid = np.mean((pred_valid - y[valid]) ** 2)
    candidates.append((float(mse_valid), lam, theta, updates))
score, chosen_lam, theta, updates = min(candidates, key=lambda item: item[0])
w_raw = theta[:-1] / scale
b_raw = float(theta[-1] - mu @ w_raw)
pred_test = Z[test] @ theta[:-1] + theta[-1]
assert np.allclose(pred_test, X[test] @ w_raw + b_raw)
mse_test = np.mean((pred_test - y[test]) ** 2)
print("chosen lambda:", chosen_lam, "updates:", updates)
print("validation MSE:", score, "test MSE:", mse_test,
      "test RMSE:", np.sqrt(mse_test))
print("raw coefficients:", w_raw, "raw intercept:", b_raw)
```

在上述核对环境与固定数据下，验证选择了零正则候选，训练经过 287 次更新达到所设梯度容差；验证均方误差约为 0.09990，测试均方误差约为 0.09473，测试均方根误差约为 0.30778。这个结果接近生成机制中噪声标准差 0.3 的量级，但有限样本并不要求二者相等，也不证明下一次实验仍会选择零正则。

原单位第三个系数约为 22.22，而生成真值为 20。该列标准差只有约 0.01，因此原系数相差两点多，对典型输入的预测贡献差异仍只有几百分之一量级；系数误差大小需要结合单位与输入分布解释。第一、二列还彼此相关，它们的个别系数估计会共同波动。若希望评价参数恢复，应重复采样并报告原单位误差；若希望评价预测，应使用独立样本风险，两类标准不能互相替代。

测试结果不必精确等于噪声方差，也不必每次都与验证相同。它们是有限样本上的估计，训练系数也含估计误差。本例用于验证训练与转换链条，不应从一次输出推断某个正则值普遍最优。研究预测稳定性时，应改变数据采样并重复完整选择流程，而不只重复打印相同测试集。

<a id="numpy-4-detail-25"></a>

### 5.5 让负面对照也回答具体问题

一个负面对照是只在训练集内独立打乱标签，保持输入和输出形状不变，重新训练并评价原外部任务。若原来可恢复的关系消失，说明实验对样本对应关系敏感；但在真实任务中，置换必须考虑时间、实体和分组，不能把依赖数据随意打散后套普通独立检验。

另一个对照是不用标准化，采用相同固定学习率训练。若发生发散，应测量原设计的最大曲率，判断步长是否已越过稳定界。这只能说明相同学习率不适合不同尺度，不能证明标准化改变了无正则最优解。公平比较可以同时报告相同步长结果和各自合法步长下的结果，回答不同问题。

还可加入恒定列、重复列或极小方差列。恒定列与截距重叠，重复列造成不可识别，小方差列可能放大原单位系数。每项干预都应有预先写明的预测，再用目标值、参数、预测和数值秩验证。故意制造坏数据的价值在于检验诊断能否区分机制，而不是简单展示程序会报错。

## 6. 进阶：线性回归梯度下降的谱分析

<a id="numpy-4-detail-27"></a>

### 6.1 从参数误差推导每个方向的收缩

把截距并入 $`\theta=(w,b)`$，增广设计记为 $`A=[X,\mathbf1]`$。令 $`D=\operatorname{diag}(1,\ldots,1,0)`$，有

$$
\begin{aligned}
H &=\frac{A^TA}{n}+\lambda D,\\[6pt]
q &=\frac{A^Ty}{n},\\[6pt]
\nabla J(\theta) &=H\theta-q.
\end{aligned}
$$

任取最优解 $`\theta^*`$ 满足 $`H\theta^*=q`$，误差 $`e_t=\theta_t-\theta^*`$ 经过一次更新变为 $`e_{t+1}=(I-\eta H)e_t`$。由于 $`H`$ 对称半正定，存在正交特征基；沿特征值为 $`\mu_j`$ 的方向，误差每步乘以 $`1-\eta\mu_j`$。训练不是一个统一速度的过程，而是多个不同速度方向的叠加。

若所有特征值严格为正，令最小值为 $`\mu`$、最大值为 $`L`$，则 $`0<\eta<\frac{2}{L}`$ 使每个因子的绝对值小于一，参数收敛到唯一解。等于上界时最大曲率方向因子为负一，通常来回振荡；大于上界时该方向被放大。某次初始化恰好没有那一方向的分量，可能暂不暴露不稳定，但不能据此宣称步长普遍合法。

目标差恰为 $`J(\theta_t)-J^*=\tfrac12e_t^THe_t`$，所以参数误差、梯度范数和目标差对各方向采用不同权重。一个小曲率方向可能有较大参数误差，却只贡献很小目标差。若研究目的是系数解释，不能只用目标小证明参数精确；若只关心预测，则也不应把无关零空间参数差当成预测失败。

<a id="numpy-4-detail-28"></a>

### 6.2 条件数、最优固定步长与预算

在严格正定情形中，要最小化最坏方向的收缩因子，可以令端点绝对值相等，得到 $`\eta=\frac{2}{(L+\mu)}`$，收缩因子为 $`\frac{(L-\mu)}{(L+\mu)}`$。条件数 $`\kappa=\frac{L}{\mu}`$ 越大，该因子越接近一，达到相同参数精度需要更多更新。

取两个正交方向曲率一与一百，使用 $`\eta=0.01`$ 时大曲率方向一步消除，而小曲率方向每次保留百分之九十九。更新一百次后慢方向仍约有初始误差的三成六；看见损失最初骤降、后来缓慢，不一定是程序卡住，而可能是曲率差异的直接结果。

标准化能消除部分列尺度差，但不能消除所有相关性。例如两列标准差相同且几乎完全重复，设计仍接近秩亏，Hessian 仍可病态。白化在理想满秩估计下进一步改变几何，但小特征值估计不稳时又会放大噪声。预处理的计算收益与统计影响需要结合数据条件，不能用一个工具替代全部诊断。

对很大维度，完整求特征值本身可能比若干梯度步更贵。可以使用矩阵向量积估计最大曲率、采用回溯步长或明确保守上界；这些算法也有预算和精度。报告训练成本时，要包括为选择学习率预先执行的工作，否则比较会偏向获得额外曲率信息的方法。

<a id="sec-6-1"></a>

<a id="numpy-4-detail-29"></a>

### 解析解、迭代解与可识别性的对照

无正则且秩亏时，$`H`$ 有零特征值，相应误差分量不会被梯度下降改变。因为 $`q`$ 属于 $`A^T`$ 的像空间，梯度始终与 $`A`$ 的零空间正交。若步长对所有正特征值稳定，则极限为

$$
\theta_\infty=A^+y+P_{\ker A}\theta_0.
$$

其中 $`A^+`$ 为伪逆，$`P_{\ker A}`$ 是零空间正交投影。从零开始时选出增广参数的欧氏最小范数最小二乘解；非零初值可以保留零空间分量。这个结论明确依赖普通欧氏梯度下降、固定稳定步长和无正则平方目标，不能直接推广到自适应优化器或任意参数变换。

两列完全相同且没有截距时，数据只能约束系数之和。初值为零会保持两个系数相等，而初值差为二的两个系数，其差在每步都保持二。二者最终预测和训练目标可以相同，参数却不同。若测试输入也满足同样重复关系，预测仍相同；若测试打破这一结构，参数选择就可能影响外部行为。

加入只惩罚权重的正岭系数后，只要样本数为正，增广 Hessian 就严格正定。证明是任意方向的二次型等于 $`\frac{\Vert Au\Vert ^2}{n}+\lambda\Vert u_w\Vert ^2`$：为零迫使权重部分为零，再由常数列迫使截距部分也为零。这里不要求原始特征满列秩，但唯一的正则解仍是改变后的模型，并不等于找回不可识别的“真实系数”。

<a id="numpy-4-detail-30"></a>

### 6.3 早停怎样成为谱滤波

先考虑无正则、无截距或已经统一并入增广设计的情形，从零初值出发。沿奇异值为 $`\sigma_j>0`$ 的方向，$`H`$ 特征值为 $`\mu_j=\frac{\sigma_j^2}{n}`$。经过 $`t`$ 步后，精确最小二乘系数被乘以

$$
f_t(\mu_j)=1-(1-\eta\mu_j)^t.
$$

若 $`0<\eta\le\frac{1}{L}`$，这些因子从零逐步趋近一，大曲率方向较快学到，小曲率方向较晚进入。有限步训练由此抑制某些小奇异值方向，这就是早停具有正则化效果的一条具体机制。它不是提前停止就一定提高预测，而是改变了方向响应，需要用数据与验证判断收益。

比较各向同性岭时，需要先对齐被惩罚的坐标。在无截距模型，或将训练输入与标签中心化、把截距单独恢复的权重子问题中，岭回归在该设计的谱坐标内具有因子 $`\frac{\mu_j}{(\mu_j+\lambda)}`$。若直接使用含常数列的增广设计，而仍只惩罚权重，则惩罚矩阵为 $`D`$ 而非单位阵，通常不能沿增广 $`A`$ 的同一奇异方向逐项套用这个因子；对所有增广参数等权惩罚才会恢复这一形式，但那又改变了本章主目标。

两种滤波形式不同，一般不存在一个标量 $`\lambda`$ 能同时匹配所有方向的有限步早停。若学习率处于一到两倍倒数最大曲率之间，某些因子还会振荡，不能再把所有方向都描述为单调学习。

因此比较早停与岭时，应说明表示、初值、更新次数、步长和评价选择。把“用了少量迭代”直接等同于“训练不充分的坏实现”或“必然更好的隐式正则”都过于简单。它既是优化预算限制，也可能是一种被验证集选择的学习规则。

<a id="numpy-4-detail-31"></a>

### 6.4 目标尺度与预条件改变哪个对象

把整个目标乘正数 $`c`$，同时把普通梯度下降学习率除以 $`c`$，会得到完全相同的精确算术更新。这要求数据项和正则项一起缩放；若只把损失由平均改成求和却保持正则系数不变，相对惩罚已经改变。停止容差与日志量也应同步解释，不能仅比较迭代编号。

更一般地，用正定矩阵 $`P`$ 更新 $`\theta_{t+1}=\theta_t-\eta P\nabla J(\theta_t)`$，相当于在一个不同度量下选下降方向。它可能缓解曲率差，也可能改变秩亏问题的偏好。当同一目标具有唯一解，且更新采用能保证收敛的步长并充分求解时，最终解才不受合法预条件影响；唯一性既可能来自满列秩，也可能来自正则。有限步轨迹不会相同。

这把 NumPy 前三章的数组语义与数学几何连接起来：逐元素缩放、矩阵乘法和坐标变换都能写成简洁表达，但它们代表不同操作。每次为了加速而改变更新式，都应先明确目标是否保持、选解是否保持，再讨论成本与效果，避免把优化技巧默认为无条件等价替换。

## 7. 练习与解析：从数值到可验证的解释

<a id="numpy-4-detail-33"></a>

### 7.1 形状练习：一个广播错误为何仍能下降

**题目：** 两条样本的预测为一维数组 $`[1,2]`$，标签却是二维列数组 $`[[1],[3]]`$。直接相减后求均方误差，会得到什么？如果训练后这个损失下降，能否说明原回归任务在改善？

**解析：** 广播先把两个数组扩成二乘二，残差为 $`[[0,1],[-2,-1]]`$，均方为一点五。正确逐样本残差为 $`[0,-1]`$，均方应为零点五。错误目标把每条预测与全部标签配对，它依然是一个可以优化的函数，所以曲线下降没有纠正语义的能力。验收应同时断言预测和标签都是同长度一维数组，并检查至少一个已知配对的前向值；多输出任务则应另立接口，不能直接展平。

<a id="numpy-4-detail-34"></a>

### 7.2 更新练习：判断截距是否被错误正则化

**题目：** 所有特征都为零，标签都是五，初始参数为零。目标只惩罚权重，学习率为零点二。第一次更新后截距是多少？正则系数从零改为十，会不会改变这一步？

**解析：** 预测为零，残差都为负五，截距梯度为负五，所以截距更新为一。权重梯度仍为零，改变只作用于权重的正则系数不会改变这一步。若实现使截距更新依赖该正则，需检查是否把截距拼成常数列后又整体惩罚。本例只检查零初值第一步，还应在非零截距处验证正则梯度始终不包含截距，避免零值偶然掩盖错误。

<a id="numpy-4-detail-35"></a>

### 7.3 归约练习：不等大小微批怎样组合

**题目：** 两批分别含六条和两条样本，在同一参数上的平均数据梯度为三与负一。求全量梯度。如果每批函数已经加入同一个正则梯度 $`r`$，按什么方式组合？

**解析：** 全量数据梯度为六除八乘三，加二除八乘负一，等于二。对已经含正则的批梯度，仍按样本数权重相加，结果为二加 $`r`$，因为权重和为一。若简单相加，数据项和正则项都改变；若先正确累积数据，又再对每批额外加入一次完整正则，则正则被重复施加。固定参数的分批一致性检查应同时覆盖数据项和惩罚项。

<a id="numpy-4-detail-36"></a>

### 7.4 日志练习：轮末损失为何不能由在线平均代替

**题目：** 一个轮次内先在参数甲计算第一批损失，再更新到乙计算第二批，最后得到丙。两个批损失按样本数加权后，能否称为丙的训练集目标？

**解析：** 不能，两个批损失来自不同函数求值点，拼起来不是任何已指定固定参数的全量计算。它可以被命名为沿训练轨迹的在线平均损失，但若要得到丙的训练目标，必须固定丙重新遍历全部数据。实验报告应写明日志含义和评价时刻；降低全量评价频率可以减少成本，却不能改变已有数值所代表的对象。

<a id="numpy-4-detail-37"></a>

### 7.5 数值练习：有限差分通过为何还不能交付

**题目：** 程序的解析梯度与中心差分高度一致，但发现输入和标签在进入训练前被独立打乱。梯度检查应该被判定为失败吗？训练是否正确？

**解析：** 梯度检查可以真实通过，因为它验证了当前错误配对目标的局部导数；错误位于更早的数据契约层。应把结论限定为“导数与当前前向一致”，同时判定该程序没有实现原任务。修复共同索引后重新核对已知样本前向，再保留差分作为另一层证据。把所有检查统称为正确性，会让一个通过项掩盖另一个关键失败。

<a id="numpy-4-detail-38"></a>

### 7.6 步长练习：稳定区间与特殊初值

**题目：** 二次目标 Hessian 特征值为二和十。学习率零点一五是否对全部初值稳定？零点二和零点二五又如何？如果某个大步长实验恰好收敛，能否推翻谱条件？

**解析：** 零点一五对应因子零点七和负零点五，绝对值均小于一，因此全方向收敛。零点二在第二方向因子负一，除非初始误差在该方向为零，否则持续振荡；零点二五对应负一点五，通常发散。特殊初值可能不激活不稳定方向，有限精度与扰动又可能使其出现。因此一个特殊轨迹不能替代对全部初值的稳定保证，应显式构造相应特征方向测试。

<a id="numpy-4-detail-39"></a>

### 7.7 标准化练习：恢复原单位函数

**题目：** 两列训练均值为 $`(10,-2)`$，尺度为 $`(2,4)`$，标准化模型权重为 $`(3,-8)`$、截距为五。求原单位权重与截距，并对一个原始输入独立验证。

**解析：** 权重逐列除以尺度，得到 $`(1.5,-2)`$；截距为 $`5-(10\times1.5+(-2)\times(-2))=-14`$。取原输入 $`(12,2)`$，标准化后是 $`(1,1)`$，预测为零；原单位计算为十八减四减十四，也为零。只有权重缩放而漏掉截距平移，会得到十九。验收应使用多条非零均值输入，因为恰好在原点或某个抵消点的单例可能漏检。

<a id="numpy-4-detail-40"></a>

### 7.8 惩罚练习：标准化后相同岭系数是否相同模型

**题目：** 两列尺度分别为一和一百，在标准化空间对两个系数采用同样的平方惩罚。换回原单位后，惩罚是什么？它是否仍等权惩罚原系数？

**解析：** 标准化系数为原系数乘各列尺度，所以惩罚变为 $`\frac{\lambda(w_1^2+10000w_2^2)}{2}`$。它等权控制的是标准化空间中的作用大小，而非原单位系数。哪个定义更合理取决于科学单位与先验，不能脱离任务说某个必然正确。如果要保持原单位各向同性岭，应在标准化系数上使用逆尺度平方权重，并对目标和参考解同步修改。

<a id="sec-8-2"></a>

<a id="numpy-4-detail-41"></a>

### 边界追问：参数不同是否说明线性回归实现不同

**题目：** 特征两列完全相同，两个无正则训练器最终系数分别为 $`(1,1)`$ 和 $`(2,0)`$，预测一致。是否必须让它们数值相同？如果第二个训练器声称返回最小范数解，又怎样验收？

**解析：** 数据只能识别两系数之和，两个结果都可以达到同一最小二乘目标。若没有指定选解规则，差异不构成错误；若明确要求欧氏最小范数，和为二的解中 $`(1,1)`$ 范数平方为二，$`(2,0)`$ 为四，后者不满足额外契约。比较模型时先对齐目标、参数化和选解规则，再决定检查预测、目标或参数，不能让单一数值容差承担全部判断。

<a id="numpy-4-detail-42"></a>

### 7.9 状态练习：为什么只存随机种子不能续训

**题目：** 已训练五个轮次，保存权重与最初种子。重启后重新用该种子构造生成器，再训练七轮，是否应等于连续训练十二轮？若只在轮次边界保存，还需什么？

**解析：** 重新设种子会回到随机流起点，重用前面轮次的排列，不能接续第六轮。本章的准确续训保存了生成器当前状态；还需要已完成轮数、模型参数、超参数和原数据变换。在轮次中间保存时，必须额外记录当前排列和下一个批次位置，或保存能重建它们的等价状态。若使用动量或自适应优化，还需要优化器内部状态，仅有权重不足以定义下一步。

<a id="numpy-4-detail-43"></a>

### 7.10 评价练习：相同训练误差是否足以比较

**题目：** 模型甲使用原特征训练，模型乙把所有训练与测试拼起来拟合标准化，再用相同训练标签拟合。二者训练误差相同，是否能把测试分数直接当作相同协议下的比较？

**解析：** 乙使用了测试特征分布信息，是否允许取决于预先定义的任务。若目标是对未知未来样本的归纳部署，测试特征本应未知，该变换越过了信息边界；若任务明确允许看到整批未标注对象，则是另一种协议，也需对其他方法同等开放。训练误差一致不能决定评价是否合法，因为信息使用与优化数值是不同问题。

<a id="numpy-4-detail-44"></a>

### 7.11 停止练习：小目标改善是否意味着小梯度

**题目：** 连续两次目标变化小于十亿分之一，因此程序提前停止。给出至少两个不能据此断言接近最优的原因，并设计更有针对性的检查。

**解析：** 学习率极小时，大梯度乘小步长也会产生微小改善；浮点舍入还可能使更新被吞掉，即使理论梯度不小。病态目标中慢方向也可能未收敛。应同时记录梯度范数、参数是否实际改变、学习率以及固定点目标；小型二次问题还可与稳定求解器比较目标差。有可信最小曲率时才能把梯度范数转换成定量最优性界，不能把任意停止阈值解释成统计置信度。

<a id="numpy-4-detail-45"></a>

### 7.12 零空间练习：初值留下了什么

**题目：** 无截距设计的两列完全相同，真实最小二乘要求系数和为四。分别从 $`(0,0)`$ 和 $`(3,1)`$ 出发，用同一稳定普通梯度下降充分训练，极限是什么？

**解析：** 梯度两个分量相同，因此系数差始终保持初值差。第一种差为零、和趋于四，得到 $`(2,2)`$；第二种差为二，得到 $`(3,1)`$，而它在这个题目中起初已满足最优和，不再改变。这个简单例子直接展示 $`P_{\ker A}\theta_0`$ 的保留。若加入正岭，差也被收缩，最终唯一解通常不再满足无正则最优和四，因此不能只要求两种解变得相等而忽略目标变化。

<a id="numpy-4-detail-46"></a>

### 7.13 多输出练习：展平为何改变归约

**题目：** 从单输出扩成 $`k`$ 个输出，采用全部元素平均的半平方损失。权重矩阵梯度分母应是什么？若改为每个样本先对输出求和，再对样本平均，又如何？

**解析：** 全部元素平均目标是 $`\frac{\Vert XW+\mathbf1b^T-Y\Vert _F^2}{(2nk)}`$，权重梯度分母为 $`nk`$，偏置也对全部元素尺度归约但保留输出向量。先对输出求和、再对样本平均时分母仅为 $`n`$，两者相差输出数。正则和学习率应同步解释。把标签展平没有保留矩阵乘法结构，也没有自动确定哪种任务尺度正确，因此扩展时应重新写目标，而不是机械复用单输出函数。

<a id="numpy-4-detail-47"></a>

### 7.14 不变量练习：共同重排与重复样本

**题目：** 把训练输入和标签共同重排，固定参数下目标与梯度应如何变化？把每条样本都完整复制一次，平均目标与梯度又如何？这些检查能发现什么，不能发现什么？

**解析：** 在精确算术下，共同重排不改变有限和，完整复制也不改变均值和同一正则项；浮点求和顺序可能带来微小差异。若变化明显，可怀疑样本配对、分母或状态依赖。它们不能证明原始标签正确、独立评价有效，也不能要求逐批训练轨迹不变，因为重排与复制改变了更新顺序和更新次数。应在同一参数的目标函数层检查不变性。

<a id="numpy-4-detail-48"></a>

### 7.15 预算练习：谁真正用到了更多计算

**题目：** 甲用一千次梯度更新，乙先精确分解 Hessian，再用一百次更新。乙更新数更少，能否直接称为总计算更快？比较应记录哪些成本？

**解析：** 分解的时间、内存和数据遍历不应免费忽略，尤其维度较大时可能主导开销。应记录预处理、曲率估计、训练、验证和推理，说明是否计入重复超参数试验。固定更新数、固定数据遍历数和固定墙钟时间是不同预算；先完成数值等价核对，再测性能，避免把求了不同精度或不同目标的程序混成纯速度比较。

<a id="numpy-4-detail-49"></a>

### 7.16 研究练习：早停能否精确等于岭

**题目：** 零初值、一轮普通梯度下降，两个正曲率方向为一与四。若学习率零点一，是否存在一个正岭系数，使两个方向的岭收缩都等于这一步早停的响应？

**解析：** 一步早停响应分别为零点一和零点四。第一方向要求 $`\frac{1}{(1+\lambda)}=0.1`$，得到 $`\lambda=9`$；第二方向要求 $`\frac{4}{(4+\lambda)}=0.4`$，得到 $`\lambda=6`$。两者冲突，说明即使最简单的两个方向，也一般不能用一个岭参数同时匹配。早停具有谱抑制并不意味着它就是同一个岭目标；比较效果时需要评价完整选择程序。

<a id="numpy-4-detail-50"></a>

## 8. 进阶研究练习与解析：把训练器变成可审查实验

<a id="sec-8-1"></a>

<a id="numpy-4-detail-51"></a>

### 综合练习：区分语法兼容与样本目标

**任务：** 为一个单输出回归程序设计完整验收，要求能区分错误广播、独立打乱标签、重复施加正则、历史错位和正常的未收敛。不能只用“损失下降”作为通过条件。

**逐步解析：** 先定义数据契约，用人工标识固定每条输入和标签对应，拒绝二维单输出标签；用一条和两条样本分别核对前向及一步更新。随后在同一参数上比较全批梯度和不等长微批累积，专门测试最后小批；把正则系数设成非零，检查完整梯度与数据梯度之差是否只作用于权重。

接着固定参数和随机状态做方向差分，确认局部导数；再在满秩小数据上对照同目标最小二乘参考。若导数通过而参数未对齐，逐步增加预算或根据曲率调整合法步长，观察目标差是否缩小。最后用秩亏例子改为比较预测与目标，除非明确要求最小范数，否则不强制所有系数一致。

日志方面，记录迭代零的参数与目标，每次检查点用同一快照重新算目标，验证末项对应最终返回值。保存历史最优参数时使用独立副本。设计一个不立即崩溃的广播故障，展示它可能有自己的正确梯度与下降曲线，从而说明各层检查为何必须并存。

**验收：** 报告每个故障被哪一层发现，以及那一层无法保证什么。一个合格实验不是检查项数量最多，而是证据与具体错误机制对应；若两个检查都只是调用同一个有错函数，它们可能共同通过，不能被算作真正独立的证据。

<a id="numpy-4-detail-52"></a>

### 8.1 把条件数变化与统计任务变化分离

**任务：** 构造两列相关特征，逐渐减小它们之间的独立噪声，同时保持每列方差接近一。比较原表示、逐列标准化和正岭下的收敛与独立预测。

**解析思路：** 原表示与逐列标准化都可能保留极高相关性，因此最小曲率仍然接近零。先固定同一无正则目标，用各自合法学习率训练到共同目标差，判断标准化究竟改善了多少条件；再加入岭，单独报告因目标改变产生的系数收缩和测试效果。不能把岭提高最小曲率的计算收益全部说成无代价的求解加速。

重复生成训练集，区分一次优化轨迹中的慢方向和不同训练集之间的估计波动。观察参数误差时用原单位，同时观察独立预测误差；在几乎重复的列中，个别系数可能波动很大而预测相对稳定。若只画一张训练损失图，这两种机制会被混在一起。

**研究边界：** 相关性是人工设定的，不能由这个实验推断实际数据的生成因果。它适合检验数值和统计推理链条；真实任务还需要测量误差、分布变化与样本选择的分析。每次干预只改变一个明确因素，结论才能对应到被改变的对象。

<a id="numpy-4-detail-53"></a>

### 8.2 让检查点恢复测试覆盖状态，而非只覆盖文件

**任务：** 在不写任何文件的前提下，用内存快照验证中断恢复。先做轮次边界，再扩展到轮次中间，说明新增状态为何必要。

**解析思路：** 边界测试先固定数据、参数初值和随机流，连续跑十二轮作为参照；另一条路径跑五轮，深复制参数与生成器状态后接着七轮，要求同环境逐位一致。然后在某轮第三批后中断，若只存当前生成器状态，却重新生成整轮排列，就会丢失原排列中未处理的部分。应存当前排列、下一批位置和累计计数，或采用能根据显式轮次标识重建排列的设计。

若加入学习率调度，要保存调度器的步数语义；按轮还是按更新衰减会产生不同结果。若加入动量，要保存动量向量；若加入早停，要保存最佳快照、最佳评价和耐心计数。模型权重定义当前预测，其他状态定义下一次转移，恢复正确必须同时覆盖两者。

**验收：** 故意漏掉一个状态，预测其后果并展示差异；再补齐后恢复一致。逐位一致只适用于当前受控条件，跨机器与并行实现可改成明确定义的数值容差和统计复现实验，不能把两种目标混为同一承诺。

<a id="numpy-4-detail-54"></a>

### 8.3 性能实验先确认是在求同一个答案

**任务：** 比较全批矩阵运算、分块累积和逐批更新的速度，要求先列出哪些结果理论上应一致，哪些只适合统计比较。

**解析思路：** 固定参数的全批与分块累积应实现同一个梯度，可在容差内核对；分块减少峰值临时内存，却可能增加循环开销。逐批更新改变了每次求梯度的位置，不能要求一次轮次后参数相同，只能在共同评价与预算下比较。测量时先预热、固定线程和数组布局，说明数据生成与检查是否计时，避免把首次库加载当作稳定训练成本。

对于较小数据，完整评价和输入验证可能占主要时间；对于较大数据，矩阵乘法、内存访问或高级索引复制可能主导。先使用前章的步幅和复制知识解释成本，再决定是否改用顺序块、缓存数组或减少日志频率。任何优化都要重新核对样本配对与归约，尤其不能为了连续内存把标签忘在旧顺序。

**验收：** 同时报告运行时间、最大临时数组规模、更新次数和达到的目标或独立误差。一个更快但精度更低的结果可以有价值，只需明确折中；一个因为漏掉最后小批而更快的程序则没有实现原任务。

<a id="numpy-4-detail-55"></a>

### 8.4 学完本章应能独立完成什么

完成本章不以记住某段训练循环为标准。学习者应能从任务定义写出数组契约，从目标逐项生成前向和梯度，选择数值安全的实现，用至少两条独立路径核对，再把标准化、模型选择、日志与恢复纳入同一实验。面对异常曲线，能够区分数据语义、导数、归约、步长、精度和统计波动，而不是把全部原因归到学习率。

进一步阅读神经网络训练时，可以保留这套审查习惯，但不要直接套用线性二次目标的特殊保证。深层模型的 Hessian 会变化且可能不定，参数对称性更多，随机层与优化器状态也更复杂。本章的价值在于给出一个能精确解释的基准，使后续每增加一种机制，都能清楚说明失去了哪些简单性质、又获得了什么能力。
