## 1. 从问题到图形：先确定被比较的对象

<a id="plot-1-detail-2"></a>

### 1.1 数据表的一行究竟代表什么

画图之前，先用一句话描述数据表的一行。例如一行可能是一个测试样本、一个训练批次、一个患者的一次复查，或者一个随机种子在某个预算下的评估结果。行数相同不意味着统计单位相同。如果同一个患者贡献十次检查，另一个患者只贡献一次，把所有行等权画成总体分布，会让前者拥有十倍权重。图形程序通常不会指出这个问题，因为从数组形状看，两种输入都完全合法。

进一步区分变量与派生统计量。原始记录是每个样本的预测值和真实值；残差、绝对误差、平方误差、每组平均绝对误差是不同派生量。画“误差”时必须说明究竟采用哪一个。残差可以正负抵消，绝对误差不会；平方误差强调较大偏差，而且物理单位变成原单位的平方。缺乏这个定义，即使轴标签、颜色和排版都很规范，读者依然无法知道图的结论来自哪里。

同样的原则适用于横轴。时间戳是实际采集时刻，样本序号可能只是文件排序后的行号。把它们都写成“时间”会制造并不存在的动态过程。无序类别的编号也不是真正数轴，类别零到一之间的距离没有理由等于类别一到二之间的距离。如果编码顺序由字典排序决定，更不能根据折线斜率讨论变化速度。图表必须继承变量的测量尺度，不能用方便的数组索引替代科学含义。

<a id="sec-1-1"></a>

<a id="plot-1-detail-3"></a>

### 1.2 从问题选择图，而不是先选择样式

考虑房价预测任务。问题“预测值是否接近真实值”需要保留每个样本的成对关系，因此横轴真实值、纵轴预测值的散点图很合适。加入对角参考线以后，可以分别观察系统高估、系统低估和误差随数值变化的现象。问题“误差有哪些常见大小”则关注边缘分布，可以画残差直方图或经验分布函数。这两幅图使用同一份记录，却不能互相替代：两个模型可能有完全相同的残差直方图，但误差集中出现的样本群体不同。

问题“不同区域的平均绝对误差谁更大”已经涉及分组与聚合。可以采用点图或柱状图，但应同时交代每组样本数，并思考误差范围是组内个体波动还是均值估计不确定性。把所有区域的平均值连接成一条线，会暗示区域之间存在天然路径。如果区域只是名称，这个暗示没有根据。若区域确实沿经度排序，连线可以展示空间顺序，但横轴应采用真实经度，不能仍把类别位置解释成等距空间。

选择图形还有信息保留的代价。箱线图压缩了分布，无法完整保留多峰结构；散点图保留个体，但大量重叠可能隐藏数量；热力图把二维空间聚合成格子，能突出密度，却依赖格子大小。不存在对任何问题都最好的图。好的选择是用足够简单的视觉编码保留当前问题所需的信息，再用补充图检查压缩过程是否掩盖重要现象。

<a id="plot-1-detail-4"></a>

### 1.3 一份可执行的图形说明书

可以在写代码前形成一段简短说明：比较对象是哪些模型，观察单位是什么，横纵轴分别是什么量及其单位，每个点或柱子如何计算，颜色代表哪一个变量，是否丢弃缺失值，是否截取范围。这段说明不是额外文书工作，它直接决定输入数组、分组键、归约方式和绘图函数。说明写不清楚，代码通常只是提前把不确定的分析决定固化了。

例如“对三种模型各五次独立训练，画固定测试集上最终平均绝对误差；点表示运行均值，细线连接同一随机种子的配对结果，纵轴单位为万元”已经把许多隐含选择显式化。这里连接的是同一实验单位的配对关系，因此连线有意义。若改成三组互不相关运行，连接第一个点就只是数组位置相同，不再具有配对解释。

还应预先确定图服务于探索还是报告。探索阶段可以频繁改变分箱、范围和配色来发现结构，但报告阶段需要记录最终选择，并检查结论是否只在某个特殊参数下成立。反复尝试后只展示最显著的一幅图，会把显示选择变成未报告的数据筛选。保留原始记录与绘图配置，使未来读者有机会判断哪些结论是稳定结构，哪些只是特定显示方式的产物。

### 图解：数据坐标与画布坐标

## 2. 图形对象树：Figure、Axes、Axis 与 Artist

<a id="plot-1-detail-6"></a>

### 2.1 对象层次不是术语游戏

Matplotlib 把大量可显示对象统称为 Artist。线条、文字、矩形、图像、坐标轴和整个画布都属于这一体系。Figure 是整张画布，通常包含若干 Axes；Axes 是一块承载数据的绘图区，可以拥有自己的横纵轴、标题、线条和图例；Axis 负责一个方向的刻度位置、刻度文字及轴标签。Axes 名称虽然像复数，实际表示一个绘图区对象，不能把它与管理刻度的 Axis 混为一谈。

这种层次决定了修改操作的作用范围。给 Figure 设置总标题影响整张画布；给某个 Axes 设置标题只影响一个面板；修改某条 Line2D 的颜色只影响该条曲线。若不知道对象属于哪一层，就容易把全局设置当作局部设置，或者在多子图中把图例画到错误位置。理解对象归属，比记住更多快捷函数更能减少排版错误。

对象树也意味着函数返回值值得保存。`ax.plot`返回线对象的列表，因为一次调用可能画多条线；`ax.scatter`返回集合对象；`ax.imshow`返回图像对象。保存这些对象以后，可以明确地修改数据、透明度或颜色映射，也可以把正确的颜色映射对象交给 colorbar。颜色条不是自动知道“这张图所有颜色”的全局装置，它需要对应的数值到颜色映射对象。

<a id="plot-1-detail-7"></a>

### 2.2 显式对象接口与 pyplot 状态

`pyplot`维护当前 Figure 和当前 Axes，因此简短的`plt.plot`很方便。但便利来自隐含状态：在创建第二幅图以后，下一次`plt.title`通常作用于当前图，而不一定是你脑中仍在处理的第一幅图。函数之间交叉调用时，这种隐含依赖更难追踪。教材和研究代码优先使用`fig, ax = plt.subplots()`，随后始终通过对应对象操作，就能把绘图目标写在每一行代码上。

显式接口并不要求完全不用 pyplot。使用它创建和关闭图形，再通过 Axes 绘制，是常见且清楚的组合。纯面向对象的`Figure`与画布后端也可以直接使用，但初学时不必为了形式纯粹增加复杂性。重要的是函数契约：函数接收一个 Axes，在该对象上添加内容，并返回创建的 Artist；它不应悄悄清空别人的画布，也不应依赖外部某个“当前图”。

样式同样存在状态问题。全局修改默认字体或颜色可能影响后续所有图，而不是当前一幅。对局部实验采用`plt.rc_context`，可以把默认设置限制在一个代码块内；退出后恢复外部配置。它隔离的是配置，不会自动删除创建的 Figure，也不会撤销对已有线条对象的直接修改。把配置生命周期与对象生命周期区分开，才能设计可复用绘图函数。

<a id="plot-1-detail-8"></a>

### 2.3 自动范围、可见性与对象归属

添加线条时，Axes 通常会更新数据范围并重新确定显示范围，但“数据范围”和“视图范围”不是同一个概念。前者反映对象中的数据边界，后者决定当前实际显示哪一段。显式设置坐标范围以后，自动缩放行为可能被关闭。直接用`line.set_data`修改数据后，也不应假定所有范围都会自动正确更新；在适用场景下需调用`relim`和`autoscale_view`，并检查所用 Artist 是否参与对应范围计算。

隐藏一个对象、移除一个对象、清空一个 Axes 和关闭一个 Figure 是不同操作。隐藏保留对象及其数据；移除解除它与容器的关系；清空删除绘图区内容并重置许多设置；关闭则解除 pyplot 对该 Figure 的管理。关闭以后若 Python 变量仍持有对象，内存中的对象不一定立即消失。资源释放取决于引用关系，不能把“窗口没了”理解为所有数组立刻回收。

多图脚本中可以把创建、使用、导出、关闭作为明确流程。每个 Figure 都有自己的句柄；导出时调用该句柄的`savefig`；无论后面又创建多少图，前面的输出目标都不会改变。需要重复更新时，修改已有 Artist 比不断添加新线条更容易控制图例和内存。若确实要叠加多次结果，就显式保留每条线的实验身份，避免对象树变成无法解释的历史堆积。

## 3. 坐标变换：数据怎样变成屏幕位置

<a id="plot-1-detail-10"></a>

### 3.1 四种常用坐标与变换方向

数据坐标描述观测值，例如训练步数与损失。Axes 相对坐标把绘图区左下角记为零、右上角记为一，适合把面板编号固定在某个角落。Figure 相对坐标对整张画布采用类似约定，适合总说明或跨面板文字。显示坐标则是渲染后的位置；Agg 中通常以像素表示，其他后端可能采用其他显示单位。一个数字对只有连同坐标系，才能确定它在图上究竟位于哪里。

常用的`ax.transData`把数据坐标映射到显示坐标，`ax.transAxes`把轴内相对坐标映射到显示坐标，`fig.transFigure`则从画布相对位置映射到显示坐标。这里的“变换”不只是平移，可能同时包含尺度变换、坐标范围归一化和绘图区几何位置。对数轴、非等比例长宽和布局变化都可以改变最终映射。

如果要把显示位置解释回数据值，可以使用变换的逆，但前提是相应映射在所讨论范围内可逆。对普通二维坐标，这非常适合鼠标交互或定位检查；对投影、分类映射和被截断区域，则要谨慎理解逆的含义。显示范围之外得到的数据坐标也不保证属于实际有效数据域。逆变换只是数学映射，不会替你验证样本是否存在或变量是否满足约束。

<a id="plot-1-detail-11"></a>

### 3.2 线性映射的具体推导

设绘图区左边界为显示位置 $`L`$，宽度为 $`W`$，横轴数据范围为 $`a`$ 到 $`b`$。在线性轴且 $`a\ne b`$ 时，数据点 $`x`$ 的横向位置为

$$
\begin{aligned}
u &=\frac{x-a}{b-a},\\[6pt]
X &=L+Wu.
\end{aligned}
$$

这解释了为什么改动横轴范围会移动同一个数据点，而放在 Axes 坐标 $`u=0.5`$ 的文字仍然位于绘图区中央。若范围反向，使 $`b<a`$，映射斜率也反向，因而递增数据会向左移动。这是有意支持的坐标反转，不是数据排序发生变化。图注需要让读者知道此时视觉方向与通常习惯不同。

二维图像中的纵向像素方向还可能与数学坐标方向不同。数组第一行在上还是在下取决于图像显示的 origin 约定；显示后端的坐标又有自己的方向约定。不要根据截图的行索引反推出 Axes 中的纵坐标，而应使用相应变换。尤其是把模型热图叠加在原图上时，应共同核对数组轴顺序、图像范围和原点，而不是只调整透明度直到看起来大致吻合。

<a id="plot-1-detail-12"></a>

### 3.3 对数尺度、差值与比例

对数轴先把正数映射成对数，再进行视图到屏幕的线性映射。若横轴范围为正数 $`a,b`$，归一化位置可写成 $`u=\frac{(\log x-\log a)}{(\log b-\log a)}`$。相等的显示距离对应相等的比例，而不是相等的原始差值。因此从一到十和从十到一百相距相同，并不意味着后者只增加了九。底数改变会改变刻度表达，但在固定端点的归一化位置中相互抵消。

指数下降 $`y=Ae^{-kt}`$ 在纵轴对数图中变成直线，其斜率对应相对下降率；幂律关系 $`y=Cx^p`$ 则在双对数图中变成直线，斜率对应指数。观察到近似直线只是候选模型的线索，不能据此证明机制。有限范围上的其他函数也可能近似成直线，噪声模型、零值处理与取样密度都会影响拟合。把坐标轴改成对数也不会自动执行统计回归。

普通对数轴没有零和负数的有限位置。丢弃非正数会改变被展示的样本群体；加上一个常数再取对数会改变比例解释；使用对称对数尺度则引入线性核心区和过渡规则。三者解决的问题不同。选择之前应先说明零值的来源，是确实不存在事件、有限精度下溢，还是缺失值被错误填成零。显示技术不能代替数据诊断。

<a id="plot-1-detail-13"></a>

### 3.4 混合坐标与固定偏移

阈值线常需要一个方向遵循数据，另一个方向贯穿整个绘图区。例如`ax.axvline`的横坐标是数据值，而默认纵向起止位置采用 Axes 相对坐标。于是改变纵轴范围，竖线仍从面板底部延伸到顶部。这正是混合变换的用途。若改用普通`plot`绘制两个固定纵坐标，改变范围后线段就可能只覆盖局部。

注释同样可以把目标点放在数据坐标中，而把说明文字相对该点偏移若干 points。数据点移动时箭头跟随，文字与点之间保持大致固定的物理间距。与直接把文字坐标加上一个数据常数相比，这种做法在缩放后更稳定。偏移单位若是 points，则其物理尺寸与字体类似；若是像素，则更依赖输出分辨率。必须明确哪个间距需要随数据变化，哪个需要随排版保持稳定。

在正式渲染之前，布局引擎可能还没确定最终绘图区位置。因此用显示坐标做数值检查前，先触发一次 draw，能让文字测量和布局计算完成。随后如果修改尺寸、字体、标签或范围，就应重新 draw 并重新计算相关位置。把第一次计算的显示位置永久缓存，再改变画布大小，会让这些位置失去原来的意义。

<a id="plot-1-detail-14"></a>

### 3.5 独立实验：验证变换与对象层次

下面的实验不依赖图形窗口，也不创建持久文件。它验证数据到显示再到数据的往返，检查轴内中心点与数据中心在对数轴上的区别，并在内存中完成导出。图中文字采用环境自带的拉丁字形，避免把字体缺失当作变换错误。

```python
from io import BytesIO
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(6.4, 3.8), layout="constrained")
x = np.geomspace(1, 100, 100)
line, = ax.plot(x, np.sqrt(x), label="sqrt(x)")
ax.set(xscale="log", xlim=(1, 100), ylim=(0, 11),
       xlabel="Input", ylabel="Response", title="Coordinates and transforms")
ax.text(0.03, 0.94, "Axes coordinates", transform=ax.transAxes, va="top")
ax.axvline(10, color="0.4", linestyle="--", label="x = 10")
ax.annotate("Geometric center", xy=(10, np.sqrt(10)),
            xytext=(-110, 40), textcoords="offset points",
            arrowprops={"arrowstyle": "->"})
ax.legend(loc="lower right")
fig.canvas.draw()
points = np.array([[1.0, 1.0], [10.0, np.sqrt(10)], [100.0, 10.0]])
pixels = ax.transData.transform(points)
restored = ax.transData.inverted().transform(pixels)
assert np.allclose(restored, points)
center_x = ax.transAxes.transform((0.5, 0.5))[0]
assert np.isclose(ax.transData.transform((10, 5))[0], center_x)
assert line.axes is ax and ax.figure is fig
buf = BytesIO()
fig.savefig(buf, format="png", dpi=130)
assert buf.getvalue().startswith(b"\x89PNG")
print("round-trip error:", np.max(np.abs(restored - points)))
print("image bytes:", len(buf.getvalue()))
plt.close(fig)
```

如果把横轴改回线性，同样端点下中央横坐标变成五十点五；对数轴中央则是十。这不是图形画错，而是中点定义改变。实验同时说明：对象归属可以直接检查，文件是否有效也可以检查，不需要依靠“屏幕上似乎出现了一条曲线”作为唯一证据。后续更复杂的图也应把容易检查的性质写成明确断言。

## 4. 常见图表的视觉编码与统计含义

<a id="plot-1-detail-16"></a>

### 4.1 折线、散点与连线顺序

折线把相邻记录连接成路径，因此输入顺序是图形意义的一部分。`plot`不会自动猜测你想按时间排序。如果时间点为三、一、二，连线就会从三折回一再到二。某些轨迹数据确实需要保留采集路径，不能排序；函数关系或时间趋势通常应先核对顺序。把“所有数据都排序”当成通用规则同样危险，因为它可能破坏真实轨迹中的回返和迟滞。

散点图不连接点，适合观察联合分布，但点的位置、大小、颜色和透明度都必须有明确定义。`scatter`的大小参数以面积相关的平方 points 为单位，数值加倍不等于圆半径加倍。若用大小表达数量，读者比较的是面积，图例也应按相同面积规则制作。使用过大的边框会改变小点的可见面积，使同样的数据量看起来不同；密集图中尤其需要核对边缘颜色和线宽。

重叠会让许多样本看起来只有一个点。降低透明度只能部分缓解，并不使颜色深度严格等于样本数，因为透明度叠加是非线性的，而且受底色和颜色空间影响。若数量本身是核心问题，可使用二维分箱、六边形分箱或密度估计，并附颜色条。此时展示对象已经从个体记录变成区域统计量，应明确网格、归一化和零计数规则。

<a id="plot-1-detail-17"></a>

### 4.2 柱状图、点图与长度基线

柱状图用从基线到柱顶的长度表达量，因此非零基线容易放大相对长度差异。例如九十和九十一若从八十九开始画，柱长变成一和二，视觉上容易被读作翻倍。若关注小差值，可以使用点图、差值图或单独放大面板，并同时提供实际数值。不是任何图都必须从零开始，而是长度编码要求基线与所表达数量一致。

类别顺序也承担信息。按字母顺序适合查找，按数值排序适合比较高低，按业务阶段排序适合理解流程。应选择一种与问题匹配的顺序，并在不同面板保持一致。把每个面板各自按结果排序，会让同一横向位置对应不同类别，增加比较负担。堆叠柱状图中只有最底层拥有共同基线，因此中间层的长度通常难以比较；比例结构与类别之间精确差值可能需要不同图形。

类别数量多、名称长时，横向点图常比密集竖柱更清楚。若柱子表示均值，柱体本身并不展示分布；给柱子加标准差线也无法恢复多峰或偏态。可以叠加透明原始点，或改用箱线与分布图。增加元素的理由应是补足信息，而不是为了让图看起来更复杂。每增加一种编码，都需要相应的说明与阅读成本。

<a id="plot-1-detail-18"></a>

### 4.3 图像、热力图与颜色归一化

热力图需要区分矩阵索引与实际空间位置。若矩阵代表纬度、经度网格，仅用默认像素索引会让坐标标签失去真实单位。`imshow`的 extent 可以指定覆盖范围，但均匀图像网格并不适合随意表达非均匀网格；非等距网格通常应考虑基于单元边界的绘制方式。把不等宽格子强行画成等宽方块，相当于改变了空间测量。

颜色映射可以分为两步：先由 normalization 把数值映射到标准化区间，再由 colormap 选择颜色。同一种配色不保证同一种数值颜色关系。如果两幅图分别自动确定最小最大值，红色可能在左图代表零点一、右图代表十。需要比较绝对水平时，应共享归一化对象或一致的上下界；若各图归一化是有意比较内部形状，应在图注明确说明。

顺序配色适合从低到高的单向量，发散配色适合围绕有意义中心的正负偏差，定性配色适合无序类别。用连续渐变表达无序类别会暗示距离关系；用彩虹式高色相变化表达连续强度，可能制造并不存在的视觉边界。配色选择还应考虑灰度打印、低对比度屏幕和色觉差异。颜色条标出的是数值映射，不会自动解释变量单位和统计定义。

<a id="plot-1-detail-19"></a>

### 4.4 对数颜色、零值与异常值

计数跨越多个数量级时，对数颜色归一化可以让较小结构可见，但零计数没有普通对数值。可以把零单独设为一种标识，或使用适合零附近的其他归一化；不能悄悄把零替换成任意小正数却仍宣称色条代表原始计数。改变下限会改变哪些差异可见，尤其在低计数区。应结合总样本量、格子大小和最低有效计数判断细节是否可信。

极端值会拉伸线性颜色范围，使其余区域看起来几乎一样。按分位数截取颜色范围有助于观察主体，但超过范围的点需要有清楚标记，色条也可用延伸端提示。截取颜色范围与删除数据不同：前者仍保留位置，只压缩颜色差异；后者会改变统计总体。若读者需要判断尾部风险，主体图之外应保留极端值信息，而不是用漂亮的对比度掩盖它们。

对于有正负意义的残差场，中心零通常比数值最小最大值的中点更有解释价值。若正负范围不对称，可以采用以零为中心的归一化，但这会使相同绝对差在两侧的颜色变化速率不同，具体取决于选用方法。颜色编码不是天然客观的距离尺，必须与数值标签、分布摘要和实际研究问题共同解释。

## 5. 直方图与箱线图：从公式检查图形

<a id="plot-1-detail-21"></a>

### 5.1 频数、概率质量和密度的区别

设第 $`j`$ 个箱子的边界为 $`e_j,e_{j+1}`$，宽度为 $`w_j=e_{j+1}-e_j>0`$，箱内计数为 $`n_j`$，被纳入分箱的总数为 $`N_*=\sum_j n_j`$。频数柱高就是 $`n_j`$；概率质量柱高可以定义为 $`\frac{n_j}{N_*}`$；密度柱高则为 $`h_j=\frac{n_j}{(N_*w_j)}`$。于是密度直方图满足 $`\sum_j h_jw_j=1`$，而一般不满足柱高之和为一。

若两个箱子的计数都为十，一个宽度为一，另一个宽度为二，那么两者概率质量相同，但后者密度只有前者的一半。密度表示单位横轴长度中分配的概率量，柱面积才表示区间概率。密度可以超过一，例如所有样本都落在宽度零点一的区间里，平均密度就是十；这与概率不能超过一没有矛盾，因为两者单位不同。

特别注意，指定 range 或 bins 后，范围外样本可能不参加归一化。此时 density 归一到的是被包含样本的条件分布，而不是自动保留全体样本的尾部质量。若原始一千个样本只有八百个落入显示范围，图下面积仍可能为一。读者若以为图展示全体分布，就会低估尾部。应报告范围外数量，或者自行按全体样本数归一，并说明可见面积小于一的原因。

<a id="plot-1-detail-22"></a>

### 5.2 分箱边界与偏差方差权衡

箱子过宽会掩盖多峰和局部结构；过窄会把有限样本的随机波动放大。自动分箱规则提供起点，但不能替代问题判断。数据有测量分辨率或自然阈值时，边界应考虑这些信息。若数值已经四舍五入到整数，使用很细的连续箱可能主要展示记录精度，而非真实连续分布。不同组之间比较时，共同边界尤为重要，否则同一位置的柱子可能对应不同事件。

边界包含规则也有实际影响。NumPy 与 Matplotlib 的常见直方图约定通常是左闭右开，最后一个箱包含右端点。因此恰好等于边界的值会被分配到特定一侧。对连续理想分布，这类事件概率为零；对离散化记录或阈值附近大量重复值，影响可能明显。遇到柱子数量不符合直觉时，应先用计数计算核对边界，而不是假设绘图有随机误差。

平移整个分箱网格也可能改变外观。一个峰恰好被边界切开，就可能看起来像两个相邻峰。稳健的分析会检查几个合理箱宽与起点，或使用不依赖分箱的经验分布函数作补充。敏感性检查不是挑选最喜欢的图，而是判断结论是否依赖偶然的显示参数。若只有某个箱宽下出现的“结构”，应该作为待检验线索，而不是已经确认的分布机制。

<a id="plot-1-detail-23"></a>

### 5.3 箱线图的四分位数与须

典型箱线图用箱体表示第一到第三四分位数，中线表示中位数。常见须规则以四分位距为尺度，延伸到仍落在规定围栏内的最远观测值；须端通常不是围栏数值本身。围栏之外用单独符号表示的点，是相对于这个规则的离群标记，而不是自动证明数据错误。重尾分布即使没有任何记录错误，也可以自然产生大量此类点。

不同软件与参数可以改变须规则，例如以特定分位数为端点。有限样本的四分位数也依赖插值约定。若数值本身需要复核，应该在统计计算环节固定方法，再把结果传给绘图，而不是把图形默认值当作唯一标准。尤其是样本量很小、重复值很多或分布高度离散时，箱体可能退化，默认图看起来很奇怪，但这未必是绘图失败。

箱线图无法唯一确定分布。对称单峰和对称双峰可以具有相同中位数与四分位区间。没有原始点或其他分布图时，读者不应从箱体形状推断所有尾部和峰结构。分组样本量差异也不一定通过普通箱宽表达；若箱宽只是固定样式，就不能按面积推断数量。把各组样本数写在标签或图注里，是一种简单而有效的信息补充。

<a id="plot-1-detail-24"></a>

### 5.4 独立实验：不等宽密度与共享颜色范围

下面先手算密度，再与绘图返回值核对；随后用同一个归一化对象绘制两幅热图。实验明确保留范围外样本计数，避免“图下面积为一”被误读成没有尾部。

```python
from io import BytesIO
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib.colors import Normalize

samples = np.array([-1, 0.2, 0.8, 1.2, 1.8, 2.2, 2.8, 3.6, 4.8, 7.0])
edges = np.array([0.0, 1.0, 3.0, 5.0])
counts, _ = np.histogram(samples, bins=edges)
widths = np.diff(edges)
expected = counts / (counts.sum() * widths)
fig, axes = plt.subplots(1, 3, figsize=(10, 3.1), layout="constrained")
heights, returned_edges, _ = axes[0].hist(samples, bins=edges, density=True,
                                       edgecolor="black", color="tab:blue")
assert np.allclose(heights, expected)
assert np.isclose(np.sum(heights * widths), 1)
assert counts.sum() == 8
axes[0].set(xlabel="Value", ylabel="Conditional density", title="8 of 10 retained")
a = np.array([[0., 1.], [2., 3.]])
b = np.array([[2., 3.], [4., 5.]])
norm = Normalize(vmin=0, vmax=5)
im = axes[1].imshow(a, norm=norm, cmap="viridis", origin="lower")
axes[2].imshow(b, norm=norm, cmap="viridis", origin="lower")
axes[1].set_title("Panel A")
axes[2].set_title("Panel B")
fig.colorbar(im, ax=axes[1:], label="Measured value", shrink=0.85)
fig.canvas.draw()
buf = BytesIO()
fig.savefig(buf, format="png", dpi=130)
print("counts:", counts, "density:", heights)
print("visible mass under full-sample normalization:", counts.sum() / len(samples))
plt.close(fig)
```

计算得到三个箱子的计数为二、四、二，宽度为一、二、二，因而密度为四分之一、四分之一、八分之一。前两个柱子一样高，却分别包含四分之一和二分之一的保留样本。这种具体核对能训练你把图像面积与概率事件联系起来。右侧两幅图共用颜色条后，相同颜色才对应相同测量值；单独为每幅图自动归一化则会回答另一个问题。

<a id="plot-1-shared-color"></a>

### 图解：共享配色不等于共享颜色尺度

![固定矩阵A和B在各自归一化时颜色完全相同，共同归一化后反映原始绝对差异](images/01-shared-color-norm.svg)

图中使用上面程序中的 A 与 B：A 为零、一、二、三，B 在每个对应位置上都比 A 大二。上排分别把 A 的零到三、B 的二到五线性映射到同一个 viridis 配色，所以两幅图的颜色布局完全相同；它保留了各自内部的相对强弱，却抹去了跨图的整体水平差。数值标注和各自色条让这个变化可直接复核，不必凭“看起来相似”猜测。

下排冻结共同范围零到五，相同原值才进入同一个标准化位置。例如 A 的二与 B 的二会有同色，A 的三与 B 的三也一样；B 的五继续使用最高端颜色，而 A 的最大值三不再占满配色。两种画法都可以服务合法问题，但不能用上排同色来声称两组绝对值相同，也不能把下排较弱的 A 对比度当作绘图失误。

这里没有改变矩阵、删除极端值或做统计标准化，只改变数值到颜色的映射。若需要比较差异大小，可以另画 B 减 A，此例所有格子都为二；这与单独给两张图拉满色条回答的问题不同。颜色映射还不保证感知距离严格等于数值距离，所以关键位置仍值得保留少量数值或差值图。

[Matplotlib 的颜色归一化教程](https://matplotlib.org/3.10.8/users/explain/colors/colormapnorms.html)把 normalization 与 colormap 分成两层。本图按实际 Normalize 与 viridis 算出每格颜色，矩阵和色条都使用相同映射，避免手工调色制造未经定义的视觉关系。

## 6. 让视觉元素承担信息，并保留比较条件

<a id="plot-1-detail-26"></a>

### 6.1 标题、轴标签、图例和图注分别回答什么

标题说明当前面板展示的任务或现象，轴标签给出变量及其单位，图例解释不同符号所代表的组别，图注交代统计单位、样本量与处理方法。四者互相支持，但不能互相替代。把所有定义塞进标题，会让标题过长；只在正文远处解释单位，又会让独立查看图片的人失去上下文。理想状态是图像在脱离前后段落时仍能被基本正确地阅读。

标签中的“平均”应尽可能具体。例如平均损失可能按样本、按有效 token、按批次或按文档归约；宏平均准确率和总体准确率也不同。若图上只有一个短标签放不下完整定义，可以使用“每有效 token 平均负对数似然”这样的准确名称，并在图注给出分母与对数底数。名称越接近实际计算，读者越容易发现不公平比较。

图例应连接到真实 Artist，而不是手工随意写几段文字。自动图例可以减少顺序错配，但仍需核对重复标签、被过滤的对象和代表符号。图中若同时出现实线模型曲线与虚线阈值，图例要能让读者区分两种角色。额外添加颜色条时，还应明确颜色编码的是连续量还是类别，不能让同一颜色在同一图里承担彼此无关且容易混淆的含义。

<a id="plot-1-detail-27"></a>

### 6.2 坐标范围与长宽比是分析选择

同一组点在很宽很矮的画布上会显得变化平缓，在很窄很高的画布上会显得陡峭。斜率的数值含义由变量单位决定，视觉角度还受画布比例影响。因此不应根据一条线在纸面上“接近四十五度”判断变化率，除非两个方向单位与显示比例已经约定。回归预测图中的对角参考线也应结合等比例坐标理解，否则几何距离容易被误读。

当横纵轴具有相同物理单位，并且距离、角度或圆形形状本身有意义时，等比例显示常有必要。例如二维位置点云或圆形决策边界，不等比例坐标会把圆画成椭圆。反过来，训练步数与损失没有共同长度单位，强制等比例通常不增加科学意义，反而可能浪费空间。比例设置应服务于测量解释，而不是机械套用某个“专业图形”模板。

局部放大可以合理揭示细节，但要让读者知道全局尺度。可以同时给出完整范围与放大面板，也可以直接画相对基准的差值，并标明基准与单位。用差值图讨论准确率提高零点一个百分点，比把百分比轴截断后让柱子高度翻倍更直接。需要比较多个面板绝对水平时，应尽量共享范围；若不同范围确有必要，每个轴都应清楚显示刻度，避免视觉高度被误认为相同数量。

<a id="plot-1-detail-28"></a>

### 6.3 参考线、阈值和颜色不能替代证据

参考线有助于把问题变成可读关系。残差零线表示单点预测与观测相等的基准，预测对角线表示精确匹配，业务阈值线表示决策边界。但参考线本身不证明模型显著优于另一模型，也不说明阈值具有因果或法律意义。阈值来源应能追溯，不能因为某个位置使结果更好看就把它画成“标准”。 许多残差落在零线两侧，并不能证明模型没有系统偏差；还需按输入、群体或时间检查条件均值，并考虑抽样不确定性。

网格线适合辅助读取数值，过密或过深会与数据争夺注意力。背景装饰、立体柱体和阴影可能引入额外面积或透视，使同一数值看起来不同。对研究图而言，装饰只有在帮助理解时才值得保留。去掉无意义边框和重复刻度并不是追求空白风格，而是把有限视觉注意力让给样本、统计关系和不确定性。

同时也不要把“简洁”误解成删除必要说明。没有样本数、没有单位、没有处理规则的一条干净曲线，可能比稍复杂的图更难评估。可以用分层信息实现简洁：图内保留关键变量与比较，图注解释聚合和过滤，正文讨论机制与限制。读者不应必须猜测曲线是否经过平滑、极端值是否删除、不同组是否采用相同尺度。

## 7. 对象生命周期、布局与可重复实验

<a id="plot-1-detail-30"></a>

### 7.1 为什么先画好再缩小仍可能失败

画布以英寸设置尺寸，字体和许多线宽以 points 设置。若先画很大一幅图，再在报告中缩成四分之一宽，文字与线条也会一起缩小。导出更高 dpi 只会增加栅格像素数量，不会让最终纸面上的八号字自动变成十二号字。应直接以预计展示尺寸设计图，或者明确计算缩放后字号，才能判断图是否真正可读。

布局算法需要知道标签和图例的大小，因此字体、旋转角度和输出后端都可能影响布局。`layout="constrained"`能自动协调许多子图、颜色条和标签，但并不是任意组合都能完全安排。长标签、过小画布和过多面板仍可能挤压数据区域。布局与手工位置调整混用时，最好明确哪一种负责最终几何关系；不断叠加多种自动和手工修正，常让结果更难预测。

固定像素截图并不是最终排版检查。应在最终物理尺寸查看导出结果，确认标题、轴标签、刻度、图例和颜色条没有重叠或裁切。对于图例，除了检查有没有越界，还要检查它是否遮住关键异常点。所有文字都在画布内仍不意味着信息布局合理；关键结论可能恰好被一个不透明图例块盖住。

<a id="plot-1-detail-31"></a>

### 7.2 纯绘图函数与分析计算分离

一个容易验证的组织方式是先用独立函数计算统计量，再让绘图函数只负责把已定义结果映射成 Artist。计算函数可以检查样本数、单位和缺失值策略；绘图函数接收 Axes、数据及明确配置，返回线条或集合对象。这样既能测试计算，也能复用显示，而不需要为了换颜色重新执行训练。

这种分离不是要求所有图都建立庞大框架。即使只有几十行代码，也可以在绘图前给出命名清楚的中间数组，例如`mean_loss_per_token`、`valid_counts`和`bin_edges`。避免把分组、删除异常值、归一化和绘图全塞在一行表达式中，因为后者难以复核哪个环节改变了数据。图形可重复性的核心是能从记录重建每一个显示值，而不是必须使用特定工程架构。

随机模拟应使用固定的生成器种子，并说明随机性来自哪里。模拟结果的可重复不等于现实结论可靠；它只是方便检查代码与机制。若示例展示随机波动，可以刻意换几个种子检查结论是否稳定。正式实验则应保留运行身份，不能为了让图形更平滑不断重抽种子，最后只展示最符合预期的一次。

<a id="plot-1-detail-32"></a>

### 7.3 独立实验：同一数据的三种问题

下面同一批预测记录分别画成预测对应图、残差图和残差直方图。三个面板没有重复表达同一件事：第一个检视预测尺度，第二个检视条件偏差和异方差，第三个压缩成边缘分布。实验对数组形状和有限性先做检查，在函数中显式接收 Axes，并通过返回值验证每幅图确实属于预期位置。

```python
from io import BytesIO
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

rng = np.random.default_rng(8)
truth = rng.uniform(1.0, 10.0, 250)
prediction = 0.6 + 0.88 * truth + rng.normal(size=len(truth)) * (0.08 + 0.06 * truth)
assert truth.shape == prediction.shape and np.isfinite(prediction).all()
residual = prediction - truth

def correspondence(ax, observed, predicted):
    points = ax.scatter(observed, predicted, s=13, alpha=0.55, linewidths=0)
    limits = (min(observed.min(), predicted.min()), max(observed.max(), predicted.max()))
    ax.plot(limits, limits, color="0.25", linestyle="--", label="Ideal")
    ax.set(xlabel="Observed (unit)", ylabel="Predicted (unit)",
           xlim=limits, ylim=limits, title="Correspondence")
    ax.set_aspect("equal", adjustable="box")
    ax.legend()
    return points

fig, axes = plt.subplots(1, 3, figsize=(10, 3.3), layout="constrained")
artist = correspondence(axes[0], truth, prediction)
axes[1].scatter(truth, residual, s=13, alpha=0.55, linewidths=0)
axes[1].axhline(0, color="0.25", linestyle="--")
axes[1].set(xlabel="Observed (unit)", ylabel="Residual (unit)", title="Conditional error")
axes[2].hist(residual, bins=20, density=True, edgecolor="white")
axes[2].set(xlabel="Residual (unit)", ylabel="Density (1/unit)", title="Marginal error")
assert artist.axes is axes[0]
fig.canvas.draw()
buf = BytesIO()
fig.savefig(buf, format="png", dpi=140)
print("MAE:", np.mean(np.abs(residual)), "mean residual:", residual.mean())
print("axes:", len(fig.axes), "png bytes:", len(buf.getvalue()))
plt.close(fig)
```

第三幅图即使近似对称，也不能排除第二幅中的条件偏差。整体正负误差可能抵消，而在小真实值区域持续高估、大真实值区域持续低估。第一幅的等比例坐标使对角线具有直观意义，但不能只按点离对角线的纸面距离替代选定误差指标。不同面板围绕同一记录提供互补证据，远比把同一条曲线反复换颜色更能增加理解。

<a id="plot-1-detail-33"></a>

### 7.4 从图形异常反推错误所在层次

调试时可以沿着数据、统计、映射、渲染四层逐一定位。若某组均值与手算不一致，先查分组键、样本权重和缺失处理，改变字号不会解决问题。若数值正确但对应点落在错误横坐标，查数组配对、排序和坐标变换。若位置正确但颜色意义不一致，查归一化范围、颜色条对象和单位。若这些都正确而标签被裁切，最后才查画布、布局和导出边界。把问题分层能避免无目的地反复修改样式参数。

例如某幅热图上下颠倒，可能来自原点约定，也可能来自数据预处理时翻转了数组。直接反转纵轴虽然能让截图暂时符合预期，却可能导致数值坐标与真实位置仍然不一致。应选取一个已知位置的哨兵值，沿输入矩阵索引、空间边界和显示坐标逐步追踪。这样的可验证小例子比凭整体纹理判断更可靠，也能避免两个错误恰好抵消后被误认为已经修复。

还要区分绘图采样与实际数据。绘制连续函数时，过稀采样可能漏掉快速变化；大量折线点在有限像素上又可能发生重叠或路径简化。屏幕上平滑不等于函数本身没有振荡，屏幕上出现条纹也可能是离散采样与像素网格相互作用。应在关键区间加密采样，检查原始数值，并在需要时放大局部或改变输出尺寸。显示结果是有限分辨率的表示，而不是数学对象的无损副本。

对最终研究图，可以给重要结论安排一个可反驳检查：若声称两组差异主要来自尾部，就单独检查尾部数量；若声称误差随输入增加，就按输入分组计算摘要并保留散点；若声称视觉趋势不依赖分箱，就检查邻近的合理分箱。检查不是追求每幅图都建立复杂检验，而是让图上最重要的解释能够回到数据与计算，而不是停留在肉眼印象。

## 8. 进阶练习与完整解析

<a id="plot-1-detail-35"></a>

### 8.1 练习一：相同数组为何可以需要不同图

**问题。** 两列数组分别是患者年龄和残差。研究者分别画年龄与残差的散点图、残差直方图，哪幅图更正确？

**解析。** 先明确问题。若关心误差是否随年龄变化，散点图保留条件关系，是主要图；若关心整体残差取值范围，直方图更直接。两图都可能正确，但回答的问题不同。可以构造两个数据集：残差取值完全一样，只是与年龄配对顺序不同，于是直方图完全相同，散点图却分别呈现正相关和负相关。这证明边缘分布不能替代联合关系。正式分析还要检查每位患者是否重复出现，并考虑点的观察单位。

<a id="plot-1-detail-36"></a>

### 8.2 练习二：对数轴的中央是多少

**问题。** 横轴范围为一到一万，采用普通对数尺度。中央位置代表多少？如果改用以二为底的对数，是否改变答案？

**解析。** 中央满足对数值为两端对数的平均，所以数值为两端几何平均，即一百。换底只会把所有对数同时乘上一个常数，归一化分子分母相抵消，因此位置不变。刻度文字或主刻度选择可以改变，但坐标映射的相对位置不变。线性轴中央则为五千点五。若混淆算术中点和几何中点，就会错误解释同样大小的视觉间距。

<a id="plot-1-detail-37"></a>

### 8.3 练习三：为什么轴内注释比固定像素稳定

**问题。** 把面板编号放在显示坐标二十、三百像素，调整画布宽度后编号跑出绘图区。应该怎样修复？

**解析。** 面板编号表达的是相对布局角色，而不是某个观测值，因此适合采用 Axes 相对坐标，例如左上角附近。显示像素位置只在特定画布尺寸和布局下成立，重新布局后不再与面板角落保持固定关系。改用`transform=ax.transAxes`后，位置随该面板变化。还应设置垂直和水平对齐方式，并留出文字实际高度；相对坐标本身不保证长文本不会超出边界。

<a id="plot-1-detail-38"></a>

### 8.4 练习四：不等宽箱子的概率

**问题。** 两个箱子的宽度为一和三，密度柱高分别为零点二和零点一。它们各表示多少概率？能否根据柱高判断第一个箱样本更多？

**解析。** 概率质量是高度乘宽度，分别为零点二和零点三。第二个箱虽然更矮，却拥有更大概率质量。剩余零点五概率应分配在其他箱，或者当前图只显示部分范围；必须结合归一化定义解释。若所有箱只有这两个且声称是完整密度分布，总面积零点五就提示归一化或展示范围需要核查。横轴单位变换后密度高度还会随单位改变，但对应区间概率保持不变。

<a id="plot-1-detail-39"></a>

### 8.5 练习五：截取范围后的密度是否保留尾部

**问题。** 一百个观测中十个超过显示上限，调用 density 直方图后，图下面积仍为一。能否认为超过上限的概率为零？

**解析。** 不能。常见实现对被纳入指定箱子的九十个观测重新归一化，得到的是条件分布。应明确记录十个范围外观测，并报告它们占全体的十分之一。如果需要在图中保持全体概率，可以把每箱计数除以一百和箱宽，此时可见面积为零点九。两种图都可用，但含义不同；决定选择哪一种的是分析问题，而不是默认参数。

<a id="plot-1-detail-40"></a>

### 8.6 练习六：箱线图的离群点是不是错误记录

**问题。** 某组箱线图出现很多须外点，分析者全部删除后重新计算平均值，这样是否合理？

**解析。** 须外标记只是相对于四分位距规则的描述，不能自动转化为数据质量标签。重尾收入、延迟或损失分布可以自然产生很多须外点。删除需要外部依据，例如传感器故障、单位录错或不属于目标总体。若只因为数值极端而删除，就改变了研究对象，平均值也可能大幅偏移。应保留原始分析，检查稳健摘要，并对有依据的过滤给出明确规则与敏感性比较。

<a id="plot-1-detail-41"></a>

### 8.7 练习七：两个热图的红色能否直接比较

**问题。** 左热图最大值二，右热图最大值二百，分别自动使用同一渐变配色。两幅图最红位置是否一样大？

**解析。** 一样的颜色只说明各自归一化后位置相同，不能说明原值相等。若要比较绝对量，应共享归一化上下界或同一个 normalization 对象，并给出统一颜色条。若要比较各图内部空间形状，可以分别归一化，但图注必须说明不同色标。共享绝对范围后左图细节可能不明显，这是数值规模本身的信息，不应通过无说明的自动拉伸把它抹掉。

<a id="plot-1-detail-42"></a>

### 8.8 练习八：散点大小加倍意味着什么

**问题。** 用散点面积表示样本数，把大小参数从二十五变成一百，圆的半径如何变化？

**解析。** 面积相关参数扩大四倍，理想圆形半径扩大两倍，因为面积与半径平方成正比。实际可见边缘还受标记形状、线宽与渲染影响，尤其小标记不能只按简单几何推断。若想让数量加倍，大小参数通常应加倍，而不是把半径加倍。应提供大小图例，并检查读者是否可以区分所用范围；面积编码的精确比较通常弱于共同位置编码。

<a id="plot-1-detail-43"></a>

### 8.9 练习九：相同损失曲线为何看起来斜率不同

**问题。** 同一条损失曲线放在宽图中很平缓、窄图中很陡，能否认为第二张图体现更快收敛？

**解析。** 不能，画布长宽比改变了纸面角度，数值变化率没有改变。收敛速度必须在明确预算单位下比较，例如每千次更新的损失下降，而不是比较视觉角度。若两幅图坐标范围也不同，混淆会更严重。可以共享范围、统一尺寸，或者直接计算达到阈值所需预算。图形提供观察入口，正式结论应能回到数值定义。

<a id="plot-1-detail-44"></a>

### 8.10 练习十：修改线数据后为什么没有自动扩大范围

**问题。** 把既有线条的数据从零到一改为零到一百，图中只显示一小段，原因是什么？

**解析。** 线对象的数据已经改变，但视图范围可能仍是原来的，尤其之前显式设置过范围。应先核对是否有意固定比较尺度；若希望重新自动缩放，再依据 Artist 类型更新数据范围并调用适当的自动范围操作。不能为了“看见所有东西”无条件自动缩放，否则多实验对比的共同尺度会被破坏。数据更新与显示范围更新是两个独立决定，应分别写清。

<a id="plot-1-detail-45"></a>

### 8.11 练习十一：为什么负数不适合直接用对数颜色

**问题。** 残差矩阵包含正负值，采用普通对数归一化后一些区域消失。怎样选择替代方案？

**解析。** 普通对数要求正数，负残差没有相应实数对数。若关心符号和大小，可以使用围绕零的发散配色与线性归一化；跨度很大时，可研究带线性核心区的对称变换，并说明核心尺度。若只画绝对残差，就丢失了高估与低估信息，应明确变量已经改变。简单取绝对值不是纯粹的显示修复，而是改换了研究量。

<a id="plot-1-detail-46"></a>

### 8.12 练习十二：无序类别什么时候可以连线

**问题。** 三种模型按名字排序后连接准确率，是否一定错误？

**解析。** 连线不是语法错误，但容易让读者推断有顺序或连续变化。若只是比较三种无序模型，点图更直接。若线连接的是同一随机种子在三种模型上的配对结果，连线可以表达实验单位对应关系，此时应在图注说明连接规则，不能把横轴间隔解释成模型之间的数值距离。同一种线条形式可以承担不同语义，正确性取决于是否清楚传达真实关系。

<a id="plot-1-detail-47"></a>

### 8.13 练习十三：为什么相同四分位数不代表相同分布

**问题。** 两组数据箱线图几乎重合，能否声称两组服从同一分布？

**解析。** 不能。箱线图只保留少量摘要，无限多种分布可以共享这些摘要。可以在固定四分位数的同时，把组内观测集中到两个峰或均匀铺开，箱线图仍相似。应结合经验分布函数、密度图、原始点和与研究问题匹配的统计方法。即使某个检验没有拒绝分布相同，也不等于已经证明两者完全一致，还要考虑样本量与检验敏感方向。

<a id="plot-1-detail-48"></a>

### 8.14 练习十四：当前图状态导致的隐蔽错误

**问题。** 函数内部创建了辅助图，返回后调用`plt.ylabel`，结果标签出现在辅助图上。如何组织代码避免这种错误？

**解析。** 保存主图的 Axes 并调用`main_ax.set_ylabel`，让目标对象显式出现。辅助函数应接收传入的 Axes，或者明确返回自己创建的 Figure 与 Axes，避免无说明地改变全局当前状态。导出也使用`main_fig.savefig`，不要依靠当前图。修复后应检查多个图的对象归属，而不是只看最后出现的窗口，因为错误可能只在特定调用顺序中发生。

<a id="sec-6-1"></a>

<a id="plot-1-detail-49"></a>

### 8.15 练习十五：轴必须从零开始吗

**问题。** 准确率只有零点九到零点九二，是否只有从零开始才算诚实？

**解析。** 不必一概而论。柱形长度编码通常需要零基线；点图或折线图可以合理放大局部范围，但必须明确刻度，提供实际差值和适当的不确定性。也可以画相对基准的差值，使零代表无改善，减少误读。诚实来自尺度透明、单位明确与证据完整，而不是机械固定所有轴起点。若放大面板可能脱离上下文，应配完整尺度或在图注提示范围。

<a id="plot-1-detail-50"></a>

### 8.16 练习十六：设计一份可重复的图形检查

**问题。** 为预测诊断图提出一套既检查计算也检查显示的验证方案。

**解析。** 先检查真实值与预测值形状一致、样本身份对齐、缺失值策略明确；再手算几个残差并核对总体摘要。绘图时验证返回 Artist 属于预期 Axes，坐标标签与实际单位一致，共享尺度符合比较目的。触发渲染后检查文字、图例、数据区域的边界及关键点是否被遮挡，再在最终尺寸查看输出。数值断言无法替代视觉检查，视觉检查也不能证明计算正确，两者应围绕同一个图形说明书互相补足。
