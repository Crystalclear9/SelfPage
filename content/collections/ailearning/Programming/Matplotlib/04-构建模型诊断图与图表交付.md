## 1. 把诊断面板组织成可追溯的证据链

模型诊断图不是对评价结果的事后美化，而是把整体分数拆解成可检查的组成。分类中，排序能力、固定阈值决策、概率校准和系统覆盖率回答不同问题；回归中，平均偏差、误差幅度、尾部风险和来源差异也不能由一个相关系数替代。合理面板让这些证据相互约束，帮助发现数据、模型或评价协议中的具体问题。

本章以二分类为主线，建立从冻结预测记录、计算结构化指标、绘制多面板到实际导出审阅的完整流程。目标是让读者既能生成图，也能从图回到每一个分子、分母和样本范围。此前章节已经介绍对象、坐标和误差条，本章重点是把它们变成能够复算的研究结果。

<a id="deep-dive-1"></a>

<a id="plot-4-detail-2"></a>

### 1.1 每个面板应对应一种失败假设

混淆矩阵回答哪些真实类别被判成什么，阈值曲线回答如何在误报与漏报之间取舍，校准图回答概率是否可信，分组图回答整体表现掩盖了哪些来源差异。把这几种图并列的目的，是避免一个指标好就被误解为所有方面都好。

例如 ROC 曲线很好但校准很差，可能意味着排序仍有价值，却不能把分数直接作为风险概率；总体准确率很高但少数类召回低，可能来自类别不平衡；成功样本准确率提高但覆盖率下降，可能是系统把困难样本更多地转成失败。面板应能揭示这些互相矛盾的变化。

诊断图提出的解释仍是候选假设。观察到某来源误差更高，不能直接断言来源本身导致错误；可能有标签质量、基率或样本难度差异。下一步应设计对照、核对原始记录或补充数据，而不是仅凭颜色深浅作因果结论。

<a id="plot-4-detail-3"></a>

### 1.2 从整体到细分，而不是从漂亮到复杂

一套面板通常先交代有效样本和总体范围，再显示主要错误类型，随后分析阈值、概率与子群，最后列出需要追查的代表样本。读者应在看到细分图之前，已经知道模型版本、评价集合、样本数和指标方向。

每个面板不必承担全部信息。混淆矩阵适合离散决策，概率分布适合观察置信度，时间图适合检查漂移。把所有东西叠到一个坐标轴上，往往迫使读者同时解码过多颜色、线型和双轴。多面板是分解认知任务，不是把单图的混乱分散到更多格子。

如果只有一幅主图的空间，应优先展示与研究主张直接相关的证据，把其他诊断作为补充。声称误报代价下降，主图应展示同一成本定义下的结果；声称置信度更可信，主图应展示校准或适当概率评分。不能用最有利但不直接回答问题的图替代目标验证。

## 2. 冻结预测表是图表流程的事实来源

<a id="sec-1-1"></a>

<a id="plot-4-detail-5"></a>

### 2.1 一条预测记录至少包含什么

一条可复查记录应包含样本标识、真实标签、预测概率或分数、运行状态、分组字段和实验标识。若使用权重，还要保存权重及其含义；若有时间或重复实体，保留相应键，便于正确划分和重采样。记录只是信息载体，不能把能识别个人的内容不加处理地放到公开图中。

样本标识用于对齐模型与标签，不能依赖数组当前行号跨文件配对。若预测文件排序改变，按位置拼接会把不同样本匹配起来，仍可能得到看似合理的图。应检查键唯一、连接覆盖率和预期行数；一对多连接引起的行数扩张也会改变权重。

真实标签有时并非立即可得。延迟标注、删失和标签修订需要记录版本与成熟条件，不能在不同图里使用不同时间的标签。绘图输入应代表一个明确冻结的评价时点，而不是每次运行都从变化的数据源重新抽取。

<a id="sec-2-1"></a>

<a id="plot-4-detail-6"></a>

### 2.2 冻结意味着计算与排版分离

评价阶段产生预测表与必要元数据，汇总阶段计算指标，绘图阶段只读取这些确定结果。改字体或布局不应该重新训练模型、重新选阈值或重新采样测试集。否则同一张图的外观调整可能悄悄改变数值，难以判断差异来自哪里。

冻结可以通过版本化文件、内容摘要、只读数组或不可变记录来帮助实现，但技术机制不是完整保证。程序若先修改副本再绘图，仍需要记录修改规则。重要的是数据路径清楚：原始记录经过哪些过滤、归约和变换，最终进入哪些图元。

每个图表还应关联模型与预处理版本。相同权重配不同类别顺序、词表或标准化参数，预测含义可能改变。只有模型文件名而没有配置标识，往往不足以复算结果。图形是实验产物，实验身份应包含使预测具有相同语义的必要状态。

<a id="plot-4-detail-7"></a>

### 2.3 状态、缺失和非法概率需要分开

成功预测的概率应有限且位于零到一；多分类概率还应按指定容差归一。NaN 不能随意替换为零点五，因为那会把系统失败伪装成一种真实预测。应保留失败状态，并决定失败如何进入覆盖率与整体成本。

缺失标签与预测失败也不同。缺失标签的样本可能无法计算监督误差，但仍属于数据覆盖统计；有标签却预测失败的样本则能支持失败成本分析。若两者合并为一个无效掩码，读者无法判断分母减少来自哪种原因。

不存在某个真实类时，该类召回率未定义；没有任何正类预测时，精确率也未定义。可以在软件内部采用明确的显示策略，但不能把未定义零值解释成真的零性能。图中应以空值、灰格或注释表示，并保留支持数，避免颜色图把缺少证据画成确定结论。

<a id="plot-4-detail-8"></a>

### 2.4 记录验证是防止图表失真的第一道约束

绘图之前先检查数组长度、标签取值、标识唯一性、概率范围与状态一致性。成功状态却缺少概率，应报错而不是自动删除；失败状态保留了旧概率，也应明确是否允许，避免重试记录与最终状态混用。

还应核对样本权重非负且总和为正，分组字段是否包含未知值，阈值是否已经固定，以及两模型是否对相同事件评分。若评价单位是患者、任务或文档，表中可以有多个子记录，但汇总层必须知道如何还原单位。

这些检查不是为了增加形式步骤，而是因为图形接口通常会接受很多语义错误的输入。一个绘制成功的矩阵不能证明行列代表正确类别，一条平滑曲线也不能证明样本按正确时间对齐。越是在大型报告中，越需要用少量明确的不变量保护事实来源。

## 3. 混淆矩阵：计数、归一化与失败列

<a id="plot-4-detail-10"></a>

### 3.1 从一个小表逐步推导分母

约定行是真实标签、列是预测标签。若二分类矩阵为 $`\begin{pmatrix}80&20\\10&40\end{pmatrix}`$，则真实负类共一百，真实正类共五十。正类召回为四十除以五十，精确率为四十除以六十；两者分母分别是真实正类与预测正类。

按行归一后每行和为一，展示给定真实类别的去向；按列归一后每列和为一，展示给定预测类别的来源；全局归一后所有格子和为一，展示联合频率。三个矩阵即使用相同配色，概率条件也不同，不能只看色块位置就混同解释。

原始计数仍应保留。一个格子百分之百可能只来自一个样本，另一个百分之九十来自一万个样本，证据强度不同。可以在颜色表示比例时用文字叠加计数，也可并列计数图和比例图。文字格式应明确，不把比例与计数放在同一行却不说明。

<a id="plot-4-detail-11"></a>

### 3.2 失败列使覆盖问题可见

如果预测失败，增加一列“失败”能让所有有标签样本仍保留在矩阵中。此时矩阵为两行三列，按真实类归一仍以该类全部样本为分母，成功分类与失败共同组成其去向。这样可以观察失败是否集中在某个真实类别。

只对成功样本画普通二乘二矩阵也可以，但应明确称为成功条件下的混淆矩阵，同时报告覆盖率。若模型乙比甲更频繁地放弃困难样本，条件准确率可能上升，整体系统效果却下降。两种视角应并列，不能只选择较好看的一个。

失败不一定等同错误。实际系统可能有人工复核、重试或拒答政策，因此应给出相应成本或后续流程。把失败一律当作正确或错误都可能不合适；关键是评价规则与应用一致，并让失败率保持可见，而不是在作图前静默消失。

<a id="plot-4-detail-12"></a>

### 3.3 多分类、宏平均与微平均

多分类时，微平均常先汇总事件计数，宏平均则先计算每类指标再等权平均，按支持数加权又是另一种目标。某些指标在特定单标签设置下会出现简化关系，但不能把这种关系随意推广到多标签、加权或缺失类情形。

绘图中类别顺序最好固定为任务定义顺序，或使用明确规则排序。若每个模型按自己最混淆的类别重新排序，两个矩阵就难以逐格比较。若研究主要错误对，可另做排序后的补充图，但主比较仍应保留共同类别映射。

类别很多时，热图中的所有数字可能无法读清。可保留整体矩阵显示结构，再单独列出支持充分且错误较多的类别对。选择规则应写出，特别是是否按错误数、错误率或成本排序；三种排序可能突出完全不同的问题。

## 4. 阈值曲线与决策代价

<a id="plot-4-detail-14"></a>

### 4.1 阈值是决策规则，不是模型概率本身

给定正类分数 $`s`$，以 $`s\geq\tau`$ 判为正类。改变阈值会改变混淆矩阵，却不改变冻结分数的排序。可以通过阈值曲线观察召回、误报率、精确率与成本如何变化，从而把模型与决策政策分开分析。

若分数是真实且已校准的后验概率，错误代价分别为假阳性 $`c_{\mathrm{FP}}`$、假阴性 $`c_{\mathrm{FN}}`$，正确决策代价为零，则选择正类的条件为

$$
\begin{aligned}
c_{\mathrm{FP}}(1-p) &\leq c_{\mathrm{FN}}p,\\[6pt]
p &\geq\frac{c_{\mathrm{FP}}}{c_{\mathrm{FP}}+c_{\mathrm{FN}}}.
\end{aligned}
$$

这里假定两种错误成本非负且其和为正。若 $`p=P(Y=1\mid X)`$ 是目标分布下给定全部可用特征的真实后验，上式给出这些特征信息下的 Bayes 最优决策。若只知道某个压缩分数 $`P`$ 满足 $`\mathbb E[Y\mid P]=P`$，同一推导只保证在仅依据该分数决策的规则中最优，不能据此排除利用额外特征还能降低成本。例如两类等量样本的真实后验分别为 $`0.1`$ 与 $`0.9`$，恒定分数 $`P=0.5`$ 完全校准；等错误成本时，仅用此分数的最优错误率为 $`0.5`$，识别两类特征后则可降为 $`0.1`$。

这个阈值推导依赖信息集合、成本定义和目标分布。未经校准的任意分数不能直接套数值阈值。若有人工复核、容量限制或不同样本成本，决策规则还需扩展，不能只调整图中一根竖线就声称达到最优。

<a id="plot-4-detail-15"></a>

### 4.2 ROC 与 PR 衡量不同条件比例

ROC 横轴为假阳性率、纵轴为真阳性率，分别以真实负类和真实正类为分母。PR 则把召回与精确率放在一起，精确率的分母包含所有预测为正的样本，因此对正类基率更敏感。类别稀少任务中，一个看似不大的假阳性率仍可能产生大量误报。

在类条件分数分布保持不变而只有基率变化的理想条件下，ROC 可以保持不变，PR 却通常改变。这个结论不是说 ROC 永远不受分布漂移影响；如果类内难度和分数分布也改变，ROC 同样会变。比较图必须写出数据集与基率。

PR 曲线的面积还有具体积分约定。平均精度通常按召回增量加权精确率，并不必然等于对绘制点做梯形积分。若报告 AP，就应使用相应定义，不要把任何一条 PR 折线面积都叫同一个名字。曲线插值与绘图顺序同样需要核对。

<a id="plot-4-detail-16"></a>

### 4.3 阈值选择必须与最终评价分离

若在测试集上扫描所有阈值，选择成本最低的一个，再把该成本称作独立测试结果，就利用了测试标签进行选择。合理流程是在开发或验证集上决定阈值，再把它冻结应用到最终测试集。测试曲线可作为描述性诊断，但不能把曲线上最优点伪装成预先确定政策。

同时比较很多模型、代价比和分组阈值，也会引入更大的搜索空间。应说明选择规则及数据来源。若应用允许持续在线更新阈值，就应评价这个更新算法，而不是只报告某一时刻事后挑出的最好点。

分数并列时还要明确阈值相等归哪类。不同实现对大于与大于等于的约定可能不同，特别是量化模型中并列很多时，会影响曲线阶梯和固定阈值指标。代码应从同一决策函数计算所有面板，避免矩阵与曲线各有一套边界规则。

<a id="plot-4-detail-17"></a>

## 5. 概率校准、Brier 分数与分箱误差

<a id="plot-4-detail-18"></a>

### 5.1 校准是条件频率，不是每个样本都确定

二分类中，理想校准可写为 $`\mathbb E[Y\mid P]=P`$。直观上，在预测概率接近零点八的样本中，正类频率应接近百分之八十。它不是要求每个概率为零点八的样本都预测正确，也不是要求概率越大一定对应更容易的个体。

一个模型永远输出总体正类比例，也可能满足粗意义上的校准，却没有区分样本的能力。因此校准好与排序强是两个维度；同样，对分数作严格递增变换会保留排序和 AUC，却可能明显改变校准。严格递减变换会反转排序，不能归入这个保序结论；仅非递减的变换还可能引入新并列。诊断面板应避免用一种图替代另一种质量。

校准还依赖目标分布。某群体或时期中校准的模型，在不同基率下可能失准。总体校准不意味着每个子群都校准。反过来，如果分组穷尽同一总体，且每组都满足 $`\mathbb E[Y\mid P,G]=P`$，则由迭代期望必有 $`\mathbb E[Y\mid P]=P`$；不能把这个正向结论误写成还需要某种额外权重条件。应把校准结论限定到明确的数据范围，并检查部署中的分布变化。

<a id="plot-4-detail-19"></a>

### 5.2 可靠性图需要同时显示预测与支持度

把预测概率分成若干箱，对每箱计算平均预测概率 $`\bar p_k`$ 与真实正类比例 $`\bar y_k`$，以二者作横纵坐标。对角线表示这组汇总下两者一致。等宽箱保留固定概率区间，等频箱则改善某些区域的样本量；两种方法的点位置与误差都可能不同。

空箱不应该画在零频率位置，因为没有样本就没有经验频率。小箱的起伏可能主要来自采样噪声，因此应显示箱计数或频率区间。连接不同箱的点只是辅助阅读，不代表箱间真实校准函数一定按直线变化，尤其在样本分布不均匀时。

如果预测在箱内变化很大，用单个平均点会隐藏内部结构。一条看似贴近对角线的粗分箱图，可能由箱内不同方向失准抵消产生。应检查多种预先规定的分辨率或更细诊断，但不能无限调箱直到找到想要的形状，再把该形状当作稳定事实。

<a id="plot-4-detail-20"></a>

### 5.3 Brier 分数同时反映多种质量

二分类 Brier 分数为 $`\frac1N\sum_i(p_i-y_i)^2`$。它评价完整概率预测，越低越好，但并非只测校准。一个更能区分正负样本的模型，可能在某些条件下获得更低分数，即使其分箱校准图不完全贴近对角线。

对于预测概率在每个箱内恰为常数的离散预测，可把经验 Brier 分解为不确定性减分辨率加可靠性：

$$
\operatorname{BS}
=\bar y(1-\bar y)
-\sum_k w_k(\bar y_k-\bar y)^2
+\sum_k w_k(p_k-\bar y_k)^2.
$$

这里 $`w_k=\frac{n_k}{N}`$，分辨率描述各箱真实频率与总体频率的区别，可靠性描述箱内预测与频率的偏差。这个恒等式可通过把每箱平方误差展开并使用二元标签方差得到，不需要把三项视为互不相关的模型能力。

若只是把不同概率粗分成箱，再用箱均值替换所有原预测，上式精确分解的是替换后的预测。原 Brier 还包含箱内概率变化与标签协变的修正，不能无条件把粗分箱三项之和写成原分数。研究报告应说明是否使用近似分解，避免漂亮的三色柱掩盖统计量已经改变。

<a id="plot-4-detail-21"></a>

### 5.4 校准误差标量的分箱依赖

常见的加权绝对分箱差为 $`\sum_kw_k\vert \bar p_k-\bar y_k\vert `$，有时称为 ECE。它依赖分箱数量、边界与样本量，不是一个无需说明就唯一确定的模型属性。极粗分箱可能让正负失准抵消，极细分箱又可能把采样噪声当作失准。

它也不是严格适当评分规则的替代。若用测试集 ECE 直接优化分箱或后处理，会消耗测试信息；若模型在某个固定分箱下得分改善，也不保证所有分辨率下的校准都改善。应配合 Brier、对数损失和可靠性图，并说明各自对象。

概率校准器应在适当的独立数据或交叉验证框架下拟合，不能用最终测试标签拟合后再报告同一测试集的改进。校准只改变预测分数，不自动修复排序、分布漂移或遗漏特征。面板应帮助区分这些能力，而不是把所有改善都归因于一项后处理。

<a id="visual-04-mechanism"></a>

### 图解：同样分类正确，概率质量仍可不同

![同样分类正确，概率质量仍可不同](images/04-mechanism.svg)

在两个样本上，两模型都给正类更高分，并且在 0.5 阈值下全部判对，但 Q 的概率更靠近 0.5。逐行计算预测概率与真实标签之差的平方，再平均，得到两个不同的 Brier 分数。

这两个点足以区分分类准确率和概率损失，不能据此估计总体校准曲线；Brier 同时受校准与分辨能力影响。

## 6. 分组、覆盖率和比较对象的一致性

<a id="sec-5-1"></a>

<a id="plot-4-detail-23"></a>

### 6.1 每个分母都应能从记录表恢复

总体准确率可能按样本等权，类别召回按真实类条件计算，PR 按阈值选中的预测集合计算，校准按成功且有概率的样本分箱。它们出现在同一画布，并不意味着分母相同。需要说明差异的原因，并保证每个面板内部定义清楚。

如果混淆矩阵包含失败列，而 PR 与校准只对成功预测计算，这是可以解释的组合：前者显示整体覆盖，后两者显示成功条件下的分数质量。画布标题或图注必须明确条件范围，否则读者会以为所有图都对全部样本成立。

使用权重时，计数与加权质量也要分开。一个权重为十的样本不自动等于十个独立样本；加权比例的区间不能简单把权重总和当作独立样本数。图中可同时报告记录数与权重和，避免支持度被一种数字替代。

<a id="plot-4-detail-24"></a>

### 6.2 子群差异需要基率与样本量背景

某组精确率更低，可能因为正类更稀少，而不是同样类条件预测机制更差。某组误报数量更多，可能只是该组样本量更大。比较前先决定看数量、条件率还是实际代价，并把相关基率与支持数放在旁边。

小群体的百分比很容易剧烈波动。应保留分子分母，必要时给出适合的区间，并避免按一次极端率直接排名。若发现许多群体后再挑最差者，极值还包含选择效应；可以把它作为探索线索，再用独立数据核对。

不同公平性或群体性能条件可能无法同时达到，尤其在基率不同且预测不完美时。图表可以清楚展示取舍，却不能替应用决定哪种目标最重要。研究者应说明决策背景与代价，而不是仅用一个综合分数隐藏子群冲突。

<a id="sec-7-2"></a>

<a id="plot-4-detail-25"></a>

### 6.3 只保留成功预测会改变研究问题

设模型甲成功覆盖百分之百，准确率百分之九十；模型乙只覆盖一半，成功条件准确率百分之九十八。不能只用后两个数字就认定乙更好。若失败需要昂贵人工处理，乙可能不适合；若失败可以安全拒答且错误代价极高，乙也可能有价值。

比较应同时报告覆盖与条件风险，并根据实际政策定义整体成本。若进一步按置信度拒答，可以绘制风险随覆盖变化的曲线，但选择拒答阈值仍需要独立数据。较好的条件风险可能只是少做了困难问题，并不证明同等覆盖下也更好。

记录失败原因还可以区分模型错误与系统问题。输入解析、超时、设备内存与非法概率属于不同环节，改进手段不同。把它们一律归为模型分类错误，会误导开发；完全删除又会高估整体系统效果。应在总览中保留失败，再在细分诊断中解释原因。

## 7. 实验一：冻结记录与完整分类面板

<a id="plot-4-detail-27"></a>

### 7.1 先在开发集选阈值，再冻结测试协议

下面构造独立开发集与测试集。真实标签来自一个概率机制，模型分数故意带有过度自信；部分预测以明确状态标记失败。开发集按假阳性成本一、假阴性成本四、失败成本二选择固定阈值，随后对测试集使用同一规则。

失败成本在候选阈值之间不变，所以不影响开发集阈值排序，但会影响系统整体成本的解释。代码保留全部测试样本，混淆矩阵增加失败列；PR 与校准只使用成功样本，并在标题中写清。所有面板的数据都来自同一冻结记录，没有重新预测或筛选有利结果。

为了保持实验可独立运行，示例用 NumPy 数组字典而非外部数据库。数组先复制再设为只读，避免排版阶段意外原地修改。只读标记是协作约定的辅助，不能代替数据版本管理；完整项目还应保存数据与配置身份。

```python
from io import BytesIO
import numpy as np
from scipy.special import expit
from sklearn.metrics import precision_recall_curve, average_precision_score
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from PIL import Image

def make_records(seed, n):
    rng = np.random.default_rng(seed)
    x = rng.normal(size=n)
    group = rng.integers(0, 2, size=n)
    eta = 1.1 * x - 0.5 + 0.4 * group
    y = rng.binomial(1, expit(eta))
    p = expit(1.7 * eta + 0.25)
    ok = rng.uniform(size=n) > (0.04 + 0.08 * group)
    p[~ok] = np.nan
    records = {"id": np.arange(n), "y": y, "p": p, "ok": ok, "group": group}
    assert len(np.unique(records["id"])) == n
    assert np.isin(y, [0, 1]).all()
    assert np.isfinite(p[ok]).all() and ((p[ok] >= 0) & (p[ok] <= 1)).all()
    assert np.isnan(p[~ok]).all()
    for key, values in records.items():
        records[key] = values.copy()
        records[key].setflags(write=False)
    return records

def decisions(records, threshold):
    decision = np.full(len(records["y"]), 2, dtype=int)
    ok = records["ok"]
    decision[ok] = (records["p"][ok] >= threshold).astype(int)
    return decision

def mean_cost(records, threshold):
    y, pred = records["y"], decisions(records, threshold)
    costs = np.zeros(len(y))
    costs[(y == 0) & (pred == 1)] = 1.0
    costs[(y == 1) & (pred == 0)] = 4.0
    costs[pred == 2] = 2.0
    return costs.mean()

dev = make_records(31, 700)
test = make_records(32, 900)
grid = np.linspace(0.05, 0.95, 91)
costs = np.array([mean_cost(dev, threshold) for threshold in grid])
threshold = float(grid[np.argmin(costs)])
pred = decisions(test, threshold)
cm = np.zeros((2, 3), dtype=int)
np.add.at(cm, (test["y"], pred), 1)
assert cm.sum() == len(pred)
support = cm.sum(axis=1, keepdims=True)
row_rate = np.divide(cm, support, out=np.full_like(cm, np.nan, dtype=float),
                     where=support > 0)
assert np.allclose(np.nansum(row_rate, axis=1), 1.0)
ok = test["ok"]
y, p = test["y"][ok], test["p"][ok]
precision, recall, _ = precision_recall_curve(y, p)
ap = average_precision_score(y, p)
assert np.isclose(np.sum(np.diff(recall[::-1]) * precision[::-1][1:]), ap)
edges = np.linspace(0, 1, 9)
bins = np.clip(np.searchsorted(edges, p, side="right") - 1, 0, 7)
counts = np.bincount(bins, minlength=8)
assert counts.sum() == ok.sum()
xcal, ycal = [], []
for j in range(8):
    selected = bins == j
    if selected.any():
        xcal.append(p[selected].mean())
        ycal.append(y[selected].mean())

fig, axes = plt.subplots(2, 2, figsize=(10, 7), squeeze=False,
                         layout="constrained")
ax = axes[0, 0]
image = ax.imshow(row_rate, vmin=0, vmax=1, cmap="Blues", aspect="auto")
for i in range(2):
    for j in range(3):
        ax.text(j, i, f"{cm[i, j]}\n{row_rate[i, j]:.1%}",
                ha="center", va="center",
                color="white" if row_rate[i, j] > 0.55 else "black")
ax.set(xticks=[0, 1, 2], xticklabels=["0", "1", "Failed"],
       yticks=[0, 1], yticklabels=["0", "1"],
       xlabel="Decision", ylabel="True class",
       title="All records: count / true-row fraction")
fig.colorbar(image, ax=ax, label="Fraction within true class", shrink=0.8)
ax = axes[0, 1]
ax.step(recall[::-1], precision[::-1], where="pre", color="#0072B2",
        label=f"AP = {ap:.3f}")
ax.axhline(y.mean(), color="0.5", linestyle="--", label="Success-set prevalence")
ax.set(xlim=(0, 1), ylim=(0, 1.03), xlabel="Recall", ylabel="Precision",
       title="Successful predictions only")
ax.legend(fontsize=8)
ax = axes[1, 0]
ax.plot([0, 1], [0, 1], "--", color="0.5")
ax.plot(xcal, ycal, "o-", color="#D55E00", label="Nonempty bins")
ax.set(xlim=(0, 1), ylim=(0, 1), xlabel="Mean predicted probability",
       ylabel="Observed positive fraction", title="Success-set reliability")
ax.legend(fontsize=8)
ax = axes[1, 1]
groups = [0, 1]
coverage = [test["ok"][test["group"] == g].mean() for g in groups]
group_n = [(test["group"] == g).sum() for g in groups]
bars = ax.bar(["G0", "G1"], coverage, color=["#0072B2", "#009E73"])
for bar, n in zip(bars, group_n):
    ax.text(bar.get_x() + bar.get_width() / 2, bar.get_height() + 0.015,
            f"N={n}", ha="center", fontsize=9)
ax.set(ylim=(0, 1.08), ylabel="Successful / all records", title="Coverage by group")
fig.suptitle(f"Frozen test protocol; development threshold = {threshold:.2f}",
             fontsize=12)
fig.canvas.draw()
png = BytesIO()
fig.savefig(png, format="png", dpi=120)
png.seek(0)
with Image.open(png) as image:
    assert image.size == (1200, 840)
print("threshold / test cost / coverage:",
      threshold, mean_cost(test, threshold), ok.mean())
print("all-record confusion:\n", cm)
print("success-set Brier / AP:", np.mean((p-y)**2), ap)
print("calibration bin counts:", counts.tolist())
plt.close(fig)
```

<a id="plot-4-detail-28"></a>

### 7.2 从面板读回数据范围

左上两行都包含失败列，所以每行比例之和为一，分母是真实类全部记录；右上只对成功样本计算 PR，基线也使用成功集合的正类比例；左下校准同样只使用成功样本，空箱不出现；右下覆盖率则明确以各组全部记录为分母。

这些分母不同，但不同是有意且可解释的。如果把失败更多的组从校准中排除后发现曲线更好，不能直接推断该组的整体系统更可靠。应结合覆盖率和失败代价。面板的价值正在于让这种条件化保持可见，而不是强迫所有指标使用不适合的同一分母。

代码的阈值扫描采用固定网格，并列成本时取网格中第一个最小值，这是明确的规则。它未必是连续阈值空间的精确最优，但足以展示选择与测试分离。若实际项目需要在所有唯一分数处求最优，应处理并列分数与边界政策，并仍只在开发数据中完成选择。

<a id="plot-4-detail-29"></a>

## 8. 实验二：排序不变，概率质量仍可改变

<a id="plot-4-detail-30"></a>

### 8.1 一个严格单调变换的反例

设真实后验概率为 $`p`$，把其 logit 放大两倍得到 $`q=\sigma(2\operatorname{logit}(p))`$。在零到一内部，这是严格递增变换，所以样本间的大于关系与并列关系都保持不变，排序型 AUC 不变；但 $`q`$ 比 $`p`$ 更极端，一般不再等于真实后验。

对真实后验为 $`p`$ 的二元标签，条件期望平方误差满足

$$
\mathbb E[(q-Y)^2\mid p]
=p(1-p)+(q-p)^2.
$$

证明是加入并减去 $`p`$，交叉项因 $`\mathbb E[Y\mid p]=p`$ 为零而消失。第一项是不可约的条件标签噪声，第二项是偏离真实后验的代价。因此变换保留排序，却使期望 Brier 增加。有限样本可能有波动，所以代码分别核对精确期望与样本结果。

```python
from io import BytesIO
import numpy as np
from scipy.special import expit, logit
from sklearn.metrics import roc_auc_score
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from PIL import Image

rng = np.random.default_rng(71)
p = rng.uniform(0.05, 0.95, 2500)
q = expit(2 * logit(p))
y = rng.binomial(1, p)
assert np.array_equal(np.argsort(p), np.argsort(q))
assert np.isclose(roc_auc_score(y, p), roc_auc_score(y, q))
expected_p = np.mean(p * (1-p))
expected_q = np.mean(p * (1-p) + (q-p)**2)
assert expected_q > expected_p
fig, axes = plt.subplots(1, 2, figsize=(8.5, 3.6), squeeze=False,
                         layout="constrained")
order = np.argsort(p)
axes[0, 0].plot(p[order], p[order], color="#0072B2", label="True posterior p")
axes[0, 0].plot(p[order], q[order], "--", color="#D55E00", label="Sharper q")
axes[0, 0].set(xlabel="True posterior p", ylabel="Reported probability",
               title="Same ranking, different probability")
axes[0, 0].legend(fontsize=8)
labels = ["p", "q"]
axes[0, 1].plot(labels, [expected_p, expected_q], "o-",
                label="Expected Brier", color="#0072B2")
axes[0, 1].plot(labels, [np.mean((p-y)**2), np.mean((q-y)**2)], "s--",
                label="Observed Brier", color="#D55E00")
axes[0, 1].set(ylabel="Brier score (lower is better)",
               title="Probability error changes")
axes[0, 1].legend(fontsize=8)
fig.canvas.draw()
png = BytesIO()
fig.savefig(png, format="png", dpi=120)
png.seek(0)
with Image.open(png) as image:
    assert image.size == (1020, 432)
print("AUC p/q:", roc_auc_score(y, p), roc_auc_score(y, q))
print("expected Brier p/q:", expected_p, expected_q)
print("observed Brier p/q:", np.mean((p-y)**2), np.mean((q-y)**2))
plt.close(fig)
```

<a id="plot-4-detail-31"></a>

### 8.2 排序评价与概率评价应互相补充

如果只看 AUC，这两个预测完全一样；如果需要直接根据概率计算风险或成本，它们则不等价。严格递增变换仍可能让固定数值阈值对应的样本集合改变，除非阈值也按同一变换映射。因此“阈值无关指标不变”不意味着固定决策规则也不变。

这个实验没有证明过度自信永远比任何其他错误更糟，只展示排序强与概率准可以分离。实际校准可能通过温度、逻辑映射或保序回归等方法进行，各有假设和样本需求。拟合时仍需独立校准数据，不能直接在最终测试图上调参数直到贴近对角线。

对于多分类，概率单纯形、类别不平衡和逐类校准会更复杂。只画最大置信度对应的准确率，可能隐藏其他类别概率错误；逐类分析也会引入更多比较。研究中应按照实际概率使用方式选择诊断，而不是默认一张可靠性图就覆盖全部校准性质。

## 9. 诊断面板的数据与函数边界

<a id="plot-4-detail-33"></a>

### 9.1 汇总函数返回数字，绘图函数接收轴

较清楚的项目结构是把验证、计算和渲染分成不同函数。验证函数检查记录，汇总函数返回矩阵、曲线坐标、区间与支持数，绘图函数接受这些结果及指定 Axes。这样可以在不创建图形窗口的情况下先核对数值，也能把相同汇总放进不同排版。

绘图函数不应该在内部偷偷选择最优阈值、删除离群点或改变类别顺序。如果确需从原始记录计算某个简单量，规则应成为明确参数并返回用于对账的数据。隐藏的默认处理会让同一预测表在不同图中产生不一致结果。

函数边界还可以帮助定位错误。如果表格指标正确而图形不对，应检查坐标、顺序与变换；如果图与表一致却都不符合手算，则问题在汇总或数据。把所有逻辑揉进一个很长的绘图函数，往往让这两种错误难以区分。

<a id="plot-4-detail-34"></a>

### 9.2 用语义不变量校验面板

混淆矩阵计数和应等于相应记录数；有效行归一化后应和为一；校准箱计数应覆盖所有计分概率且无重复；阈值函数应与固定矩阵使用相同并列规则；两模型配对键应完整匹配。它们是定义层面的约束，比检查颜色或图对象数量更能保护结论。

曲线也有可检查结构。随着阈值升高，预测为正的集合应单调缩小；在相同样本集合上，真阳性与假阳性数量不会增加。但精确率不一定单调，不能为了让曲线好看而强行排序精确率。应核对真正由集合包含关系保证的性质，避免加入错误断言。

区间端点、中心和图元位置可以抽样对账。对于不对称误差条，检查绘制长度是否恢复原始端点；对于热图，检查类别文本与矩阵索引是否一致；对于日志曲线，检查横轴是否使用真实预算而非行号。每个检查都对应一种可能产生漂亮错误图的路径。

<a id="plot-4-detail-35"></a>

### 9.3 稳定样式应保留数据语义

同一模型跨图使用相同颜色和标记，同一组别保持相同顺序，同一指标保留相同方向，这能减少读者负担。但全局样式不应抹掉必要差异：计数与比例、线性与对数、成功条件与全部样本必须分别标注。

颜色映射要与量的结构相配。非负计数适合顺序色，正负差值适合以零为中心的发散色；类别颜色则是离散身份，不应暗示连续顺序。两个差值热图若共享颜色条，应使用相同零点与范围；否则同一种红色可能代表不同幅度。

也不要把低样本支持画得与充分支持完全一样。可以用计数字样、空心标记或明确注释提示，而不是只用更淡的颜色让读者猜测。不确定性与缺失有不同含义，不能都用透明度表示而不给说明。

## 10. 从渲染到交付的完整过程

<a id="plot-4-detail-37"></a>

### 10.1 交付对象不只是一个扩展名

PNG、SVG 和 PDF 各有适合场景。位图适合固定像素展示，矢量适合线条和文字缩放，但大规模散点可能让矢量文件很大。选择格式时还要考虑接收方软件、字体支持和后续排版，不能认为改成矢量格式就自动达到出版质量。

图的物理尺寸、字号和面板密度应按最终使用场景设计。提高位图分辨率不会让缩小后的文字更大；使用自动紧边界裁切可能改变最终尺寸与长宽比。若报告要求固定宽高，应在实际导出后核对像素或页面尺寸，而不是只看创建画布时的参数。

透明背景也需明确。浅色文字或半透明带放到深色文档背景上，视觉效果可能与白底预览不同。若没有透明叠加需求，显式背景通常更容易稳定呈现。颜色、线宽和网格都应在目标媒介下审阅，包括灰度打印或低分辨率屏幕。

<a id="plot-4-detail-38"></a>

### 10.2 图注、元数据与版本形成可复算记录

一张结论图至少应说明数据范围、模型身份、指标公式或标准定义、筛选条件、样本数、区间类型和选择规则。若使用开发集选阈值，写出选择目标与数据角色；若只对成功样本评分，写出覆盖率；若做平滑，写出方法与窗口。

在完整项目中，可以保存图表输入表、绘图配置和版本摘要，与最终图一起作为交付包。本文档库只保留学习 Markdown，代码示例使用内存输出演示这些原则，不创建额外脚本。读者实践项目时应根据实际复现需求保存数据，不必把临时运行日志全部当作最终产物。

内容摘要可以帮助判断输入是否变化，但不是自动的数据真实性证明。摘要依赖序列化规则，浮点格式、字段顺序与元数据变化也可能影响结果。应记录规范表示并说明摘要覆盖范围，让它成为版本核对工具，而不是过度承诺的质量标签。

<a id="plot-4-detail-39"></a>

### 10.3 导出后重新打开实际文件

图像成功保存只说明编码过程完成。应重新打开实际文件，以最终尺寸检查标签、刻度、图例、色条、数学符号和边缘裁切。若报告会把图缩小，应直接按缩小比例审阅，不要只在大窗口中放大看细节。

同时核对图中关键数字与指标表。自动布局改变位置不应该改变数据，但手工复制图注、后期编辑数字或使用旧导出文件都可能导致不一致。交付前可以选一个混淆格、一个阈值点、一个校准箱和一个分组比例，从冻结记录逐项复算。

若使用不同渲染后端导出多种格式，需要分别审阅。字体替代、文字换行和图例边界可能不同。不能因为 PNG 通过就断言 SVG 或 PDF 也必然相同。对于大量图，程序化尺寸与文本边界检查有帮助，但仍应对代表图和高风险布局进行视觉检查。

## 11. 研究进阶：漂移、选择与可行动的诊断

<a id="plot-4-detail-41"></a>

### 11.1 时间漂移需要把数据组成纳入分析

按时间画性能下降时，应检查标签成熟、样本来源和基率是否同时变化。若最近时间段的困难样本更早获得标签，而容易样本仍在等待，当前分数可能受到标签可见性选择影响。只有时间轴，没有成熟条件，可能把评价流程变化误当成模型退化。

可以同时展示每期样本量、正类比例、预测分布和条件错误率，帮助区分组成变化与类内性能变化。但这些图仍不是唯一机制识别。若发现关联，应回到采集与部署流程，设计固定组成重加权、分来源对照或新的标注抽样。

阈值与校准也可能随漂移失效。模型排序保持尚可，不意味着原概率和原成本阈值仍合适。应分别监测分数质量与决策政策，并明确何时允许更新、用什么数据更新、更新后如何重新评价。持续调阈值的系统需要评价整个维护流程。

<a id="plot-4-detail-42"></a>

### 11.2 错误样本追踪应服务假设验证

高损失或高置信错误是很有价值的检查入口，但它们不是随机样本。根据这些记录形成的解释，应通过更系统的样本验证。例如怀疑图片方向错误，可在相同来源上做受控旋转对照；怀疑罕见实体问题，可匹配长度和频率后比较。

代表样本最好包含选择规则。只挑最离谱的失败能展示可能性，却不能说明普遍程度；只挑最精彩成功也不能说明可靠性。可以同时给出随机样本、预定义错误类别和高损失极端例子，分别承担不同证据角色。

每次根据诊断图修改模型，原评价集都参与了开发。应保留独立最终测试，或明确报告当前结果为开发性分析。画图并不只是展示阶段，它经常实质影响模型选择，因此也应进入实验设计与数据使用记录。

<a id="plot-4-detail-43"></a>

### 11.3 可行动的结论要匹配证据强度

如果图显示某组覆盖率低，下一步可能是检查输入解析与资源限制；如果排序好但校准差，可能考虑独立校准；如果类别之间严重混淆，可能检查标签定义、特征可分性和类别支持。把症状对应到候选行动，比简单说模型不好更有帮助。

但行动不能被当作诊断已被证明。校准改善后下游成本是否下降，还需用冻结政策验证；增加数据是否修复少数类问题，也可能受标签质量限制。研究应形成“观察—假设—对照—新证据”的循环，而不是“看到图—立刻归因—宣布修复”。

对于教学资料，进阶程度体现在能解释这些推理边界，并给出可实施的下一步。会画复杂图只是工具能力，能让每个数字都有来源、每个比较有共同对象、每个结论有相称证据，才是模型诊断的核心。


<a id="plot-4-detail-44"></a>

### 11.4 标签可见性也可能是一种选择机制

假设系统只对触发人工复核的样本获得准确标签。直接画已标注样本的图，首先改变了评价覆盖范围；但要区分选择机制。如果标签可见性 $`S`$ 只依赖预测概率，满足 $`Y\perp S\mid P`$ 且所讨论概率区域有正覆盖，那么总体精细校准会保留为 $`\mathbb E[Y\mid P,S=1]=P`$，不能仅因按分数选择就宣称条件校准被破坏。

选择会改变概率组成与覆盖，粗分箱图也可能随之改变；若选择还依赖预测概率未捕获的标签相关因素，条件校准关系则可能改变。未覆盖区域没有标签证据，已标注部分正常仍不能证明它们也正常。

应先描述标签获得过程，检查不同分数段、群体与失败状态的标注覆盖。如果可以安排随机审计样本，可以用它建立更接近总体的评价集；如果采用抽样权重，应记录包含概率及其估计假设。缺少可识别条件时，图表应明确限制为已标注总体，而不是通过填补未知标签获得虚假的完整结果。

数据分布改变还可能来自反馈。模型拒绝或推荐某些对象后，后续被观察到的结果与原来不同，评价数据不再是固定外生样本。按时间画图时应把政策变化、复核规则变化与模型版本一起标记，避免把干预后的组成变化全部归因于预测能力。要研究政策效果，需要额外的实验或因果识别设计，预测诊断本身不能完成该任务。

<a id="plot-4-detail-45"></a>

### 11.5 用精确的分箱恒等式检查校准报告

若希望核对粗分箱的 Brier 分解，可以写出遗漏项。对箱内预测均值记为平均概率，标签均值记为平均标签，原预测相对箱均值的偏移记为概率偏移，标签相对箱均值的偏移记为标签偏移。原 Brier 等于分箱替代预测的 Brier，再加概率偏移平方的总体平均，减去两种偏移乘积总体平均的两倍。这来自直接平方展开，而非额外近似。

因此，只报告粗分箱可靠性、分辨率和不确定性三项时，应检验它们之和是否等于所声称的分数。若不相等，不能随意把差值当成数值误差；它可能正是箱内变化产生的项。可以明确报告替代预测分数、保留修正项，或只把三项作为近似诊断。这个对账能把容易混淆的校准图与适当概率评分联系起来。

这些扩展说明，完整诊断不仅需要更多图，还需要知道哪些数据没有进入图、哪些变量在收集过程中被选择、哪些恒等式因粗粒化而改变。把不可见部分与近似过程写清，能让读者判断结论的边界，也能指出下一步最值得补充的数据和对照。

## 12. 进阶练习与完整解析

<a id="plot-4-detail-47"></a>

### 12.1 练习一：恢复混淆矩阵分母

**题目。** 二分类计数为 $`\begin{pmatrix}90&10\\30&20\end{pmatrix}`$。计算正类召回、精确率、准确率和正类基率，并说明各自分母。

**解析。** 召回为 $`\frac{20}{(30+20)}=0.4`$，精确率为 $`\frac{20}{(10+20)}=\frac{2}{3}`$，准确率为 $`\frac{(90+20)}{150}=\frac{11}{15}`$，基率为 $`\frac{50}{150}=\frac{1}{3}`$。它们分别条件于真实正类、预测正类和全体样本，不能因为都显示为百分比就互换。图中若只写百分比而不说明归一方向，很容易把召回误读成精确率。

<a id="plot-4-detail-48"></a>

### 12.2 练习二：失败列的影响

**题目。** 某真实正类有一百个样本，预测正类七十、预测负类十、失败二十。成功条件召回与全体正类中被正确识别的比例各是多少？

**解析。** 成功条件召回为七十除以八十，即百分之八十七点五；全体正类中正确识别比例为百分之七十。两者都能清楚定义，但后者包含系统覆盖影响。失败如果转人工处理，其最终成本还要另算；不能把二十个失败静默丢弃，再把条件召回叫作整体系统召回。

<a id="plot-4-detail-49"></a>

### 12.3 练习三：不存在类别的显示

**题目。** 一次评价没有任何真实正类，按行归一的正类行应该怎样显示？把它填成全零有什么风险？

**解析。** 该行没有有效条件分母，召回未定义。可显示灰格或缺失标记，同时注明支持数为零。填零若没有说明，会让读者误以为模型对实际存在的正类完全失败；反之填单位对角也会伪造完美结果。数值占位是软件策略，不能替代统计解释。

<a id="plot-4-detail-50"></a>

### 12.4 练习四：成本阈值的推导

**题目。** 假阳性成本为二，假阴性成本为八，正确决策成本为零，分数为已校准后验。推导选择正类的阈值。若分数只是任意排名，能否用同一个数？

**解析。** 正类决策期望成本为 $`2(1-p)`$，负类为 $`8p`$，前者不高于后者时应判正，得 $`p\geq0.2`$。任意排名分数没有这个概率意义，不能直接用零点二。可以在独立开发集上按实际成本选阈值，或者先进行符合数据角色的校准，再检验政策在测试分布中的效果。

<a id="plot-4-detail-51"></a>

### 12.5 练习五：基率变化与精确率

**题目。** 某规则真阳性率为百分之八十、假阳性率为百分之十。正类基率从一半降为百分之一，理想类条件分布不变时，精确率如何变化？

**解析。** 基率为一半时，精确率为 $`0.8\times\frac{0.5}{(0.8\times0.5+0.1\times0.5)}=\frac{8}{9}`$；基率为百分之一时，为 $`\frac{0.008}{(0.008+0.099)}`$，约百分之七点五。ROC 操作点不变，实际误报负担却显著改变。该推导依赖类条件率保持不变，现实漂移还可能同时改变这两个率。

<a id="plot-4-detail-52"></a>

### 12.6 练习六：AUC 相同不意味着校准相同

**题目。** 将所有内部概率作严格单调 logit 放大，为什么排序指标可不变，而 Brier 和固定阈值结果可能改变？

**解析。** 严格单调变换保留样本顺序及原有并列，排序型 AUC 因此不变。但概率值变了，与标签的平方误差和对数损失可以变化；固定数值阈值也可能选中另一组样本。若阈值同步按变换映射，决策集合可以恢复。需要明确比较的是排序、概率还是某个固定政策。

<a id="plot-4-detail-53"></a>

### 12.7 练习七：粗分箱可能掩盖失准

**题目。** 一个概率箱中一半样本预测零点二但真实正类频率零点四，另一半预测零点八但真实频率零点六。合并后可靠性点在哪里，能否认为已校准？

**解析。** 合并后平均预测与真实频率都为零点五，点恰在对角线上，但两部分分别低估与高估，细粒度失准相互抵消。单个粗箱不能证明条件校准。应检查合理分辨率、样本量和其他概率评分，同时防止根据结果无限调箱形成新的选择偏差。

<a id="plot-4-detail-54"></a>

### 12.8 练习八：Brier 的精确条件期望

**题目。** 真实后验为零点七，模型输出零点九，求条件期望平方误差，并分解不可约项与偏离后验的项。

**解析。** 直接计算为 $`0.7(0.9-1)^2+0.3(0.9-0)^2=0.25`$；分解为 $`0.7\times0.3+(0.9-0.7)^2=0.21+0.04`$。真实后验输出具有最低条件期望损失，偏离增加平方距离。单个观测可能恰好让更极端概率损失更低，因此总体性质与一次样本结果不能混淆。

<a id="plot-4-detail-55"></a>

### 12.9 练习九：测试集选阈值的偏差

**题目。** 在测试集扫描一百个阈值并报告最小成本，为什么它不等于预先固定规则的独立测试结果？如何修复设计？

**解析。** 测试标签参与了选择，最小值可能利用随机波动，产生乐观性。应在开发集或内层验证中选阈值并冻结，再在最终测试集上评价。若测试曲线仍展示，可以明确它是描述性分析，不能把其最小点当作未使用测试信息的部署政策。重复模型选择还应纳入完整数据使用记录。

<a id="plot-4-detail-56"></a>

### 12.10 练习十：记录连接的错误

**题目。** 模型甲与乙的预测表行数相同，但排序不同，按行计算配对差会发生什么？仅检查行数是否足够？

**解析。** 不足，可能把不同样本当成同一样本，破坏配对和标签对应，结果仍可能具有合理范围。应按唯一样本键连接，检查两侧键集合、连接覆盖与重复键，确认没有一对多扩张。若一个模型缺失部分预测，应保留缺失状态或明确共同样本条件，而不是默默内连接后宣称比较全部数据。

<a id="plot-4-detail-57"></a>

### 12.11 练习十一：权重与独立样本数

**题目。** 一百条记录使用部署权重，总权重一万。计算加权错误率时能否把一万当作独立样本数来构造二项区间？

**解析。** 一般不能。权重表示目标组成或抽样校正，不自动产生新的独立观测。比例点估计可按权重计算，但方差需要与抽样设计、权重来源和聚类结构相符。应同时报告原始记录数与权重和，并用适当加权或设计型推断，不让加权质量伪装成真实证据数量。

<a id="plot-4-detail-58"></a>

### 12.12 练习十二：曲线的单调性

**题目。** 随阈值升高，预测正类数量、召回和精确率哪些有一般单调保证？为什么不能把精确率强行排序后作图？

**解析。** 在固定样本与一致并列规则下，预测正类集合缩小，数量和真阳性数不增，召回不增。精确率是两个同时变化计数的比，可能上下波动。强行排序精确率会把不同阈值的数值重新配对，制造不属于原决策过程的曲线，改变积分和阈值解释。

<a id="plot-4-detail-59"></a>

### 12.13 练习十三：失败率与条件准确率

**题目。** 甲覆盖全部样本，条件准确率九成；乙覆盖六成，条件准确率九成五。若错误成本一、失败成本零点二，计算两者每次请求平均成本，并说明结论依赖什么。

**解析。** 甲成本为零点一；乙成本为 $`0.6\times0.05+0.4\times0.2=0.11`$，在该政策下略差。若失败成本变为零，乙则为零点零三。可见比较依赖实际失败处理政策，而不只依赖条件准确率。真实失败成本可能因样本和人工容量变化，应根据应用定义而不是为某模型选择有利数值。

<a id="plot-4-detail-60"></a>

### 12.14 练习十四：校准与排序的基线

**题目。** 模型总输出正类基率，为什么可以在总体意义上校准却没有个体排序能力？诊断面板怎样揭示这一点？

**解析。** 所有样本预测相同，整体真实频率等于该数，所以粗校准一致；但无法区分哪个样本更可能为正，排序大量并列。可靠性图可能只有一个对角点，应同时展示概率分布、排序指标和适当评分。校准是必要的概率质量维度之一，并不等于有充分判别能力。

<a id="plot-4-detail-61"></a>

### 12.15 练习十五：图表交付的反向复算

**题目。** 审阅者拿到图和冻结预测表，应至少复算哪四类数，才能检查核心口径是否一致？

**解析。** 可以复算一个混淆格及其行分母、一个固定阈值的误报或成本、一个校准箱的预测均值和真实频率、一个分组覆盖率。再核对样本集合与失败规则是否一致。仅检查导出文件能打开或图例颜色正确，不能发现分母错配与测试阈值选择等问题。

<a id="plot-4-detail-62"></a>

### 12.16 练习十六：不同导出格式的审阅

**题目。** PNG 预览正常，是否能直接认定同一画布保存的矢量文件也排版正确？应关注哪些差异？

**解析。** 不能。不同后端可能改变字体替代、文字边界、线条和透明度表现，外置图例与紧边界裁切也可能不同。应分别打开实际输出，按最终尺寸检查，核对文本和关键数值。矢量保证缩放几何的能力，不保证所有软件中的字体与布局自动一致。

## 13. 综合研究任务与验收

<a id="sec-7-1"></a>

<a id="plot-4-detail-64"></a>

### 13.1 用同一预测表回答一个可复核问题

研究问题可以是“模型乙在固定人工复核预算下，是否比甲降低整体错误成本”。先固定开发、测试与分组划分，定义错误和拒答成本，用开发集选择政策，再冻结测试规则。两模型应按相同样本键保留概率、决策、失败状态和组别，不能只留下各自成功部分。

主面板可包括整体成本与覆盖、按真实类的决策去向、相同覆盖下的风险、按组成本与支持数。概率校准和排序作为补充解释，不能替代主成本目标。若模型随机训练，应保留训练运行；若样本按实体聚类，推断应保留实体结构，避免把所有记录视为独立。

验收时让另一个人仅凭图注和预测表恢复主要指标，解释每个分母、阈值来源与区间随机单位。若乙的收益只发生在一个小组，应说明该组样本和部署权重；若收益依赖更多人工处理，应计入资源成本。结论应该描述在哪种政策和分布下有改善，而不是无范围地宣称模型全面更好。

<a id="plot-4-detail-65"></a>

### 13.2 扩展任务：区分排序退化与校准漂移

保持模型固定，构造两种变化：第一种只改变正类基率但保持类条件分数分布，第二种在每个类别内扰动分数排序。观察 ROC、PR、可靠性与固定阈值成本怎样变化，记录哪些现象能够区分两种机制，哪些还需要额外信息。

验收不要求每种图都发生相同方向变化，而要求解释条件。第一种情形可能保留 ROC 却改变 PR 与校准；第二种会影响排序，但概率变化还取决于扰动方式。若实验同时改变多个因素，应避免把一个面板的变化唯一归因于某个因素，必要时拆成单因素对照。
