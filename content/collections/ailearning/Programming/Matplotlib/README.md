# Matplotlib 可视化

从图形对象、坐标变换和统计量选择出发，组织训练比较、误差条与诊断面板，再核对图表的分母、证据范围和最终交付。

**先修知识：** Python；NumPy。

## 学习顺序与覆盖范围

第 1 章可直接用于数据探索；第 2—4 章的训练曲线、误差条和模型诊断在学习[统计](../../Mathematics/Statistics/README.md)与[模型评估](../../MachineLearning/ModelEvaluation/README.md)时返回。先会画图，再判断图中差异能支持什么结论。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：用图回答一个可复核问题](04-构建模型诊断图与图表交付.md#sec-7-1)，再对照逐步解析与验收要求。

按 01→02→03→04 阅读：先理解对象与坐标，再处理训练和分布比较，随后构造统计区间，最后组合成可追溯诊断。图中单位、权重和随机单位不熟悉时，应返回统计学与模型评估主题。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
