## 1. 从一个比较问题设计整张画布

多子图的价值不是在一页内放入更多图，而是让不同证据共同回答一个问题。例如“模型乙是否比甲更可靠”，至少可能涉及平均表现、重复运行波动、误差发生的位置和比较成本。单个均值无法覆盖这些层次，但四张没有联系的图同样不能形成证据链。设计时应先写出主张，再确定每个面板负责验证哪一部分。

本章把多子图组织、误差条构造和统计解释放在一起学习。重点是从原始重复值推导中心与区间，理解配对结构、层级样本和多重比较怎样改变视觉结论，再把这些对象正确交给 Matplotlib。实现不依赖外部数据或专用字体；实验使用英文图内标签，中文说明在正文中给出。

<a id="plot-3-detail-2"></a>

### 1.1 先确定读者应比较什么

若主要问题是两个模型在相同任务上的差异，图中就应保留任务配对，而不只放两组互不相关的均值柱。若问题是预测误差随输入范围怎样变化，就应把输入或拟合值作为横轴，不能只画残差直方图。若问题是训练效率，应明确横轴是更新次数、处理样本量还是时间，三者不能直接互换。

可将画布理解为一条论证路径：第一幅交代总体，第二幅揭示组成，第三幅定位失败，第四幅检验替代解释。每幅图的标题最好能对应一个具体问题，如“相同任务上的差值”“误差是否随预测值扩大”。只有指标名而没有比较对象的标题，往往意味着画布还没有形成明确问题结构。

过多面板会增加读者在不同坐标和图例之间切换的成本。若一幅图必须用很小字号才能塞入全部变量，通常应拆成主图与补充图，而不是继续压缩。信息密度应通过一致编码和合理对齐提高，不能靠缩小文字掩盖组织问题。

<a id="plot-3-detail-3"></a>

### 1.2 每个面板都需要自己的统计定义

一条曲线上的点可能是一个批次损失、一个回合平均、多个随机种子的均值或一个滑动窗口估计。它们虽然都能画成折线，却对应不同随机单位和权重。面板之间若使用不同定义，应在标签或图注中明确，不能因为颜色相同就暗示统计口径相同。

对每个面板可先写一个简短说明：数据集合、横轴单位、纵轴公式、聚合权重、缺失规则和区间含义。例如“每点为同一验证集上一次独立训练的准确率，横轴为累计训练秒数，阴影为五次运行的标准差”。这比只写“平均性能及误差带”更能让读者恢复计算过程。

还应说明哪些内容来自同一数据集。残差散点和残差直方图若来自同一批样本，读者可以把它们作为互补视角；若某图剔除了尾部或缺失值，则必须标出不同样本数。画布上的邻近位置容易让人默认共享数据，因而需要主动防止这种错误推断。

<a id="plot-3-detail-4"></a>

### 1.3 共享坐标是一种比较约束

相同物理量、相同单位且需要直接比较量级时，共享轴有助于避免自动缩放制造差异。不同模型的残差图若分别自动设定纵轴范围，一张误差只有另一张十分之一，也可能看起来同样分散。统一坐标把比较规则固定下来，读者才能依据距离判断大小。

但共享并不是越多越好。把准确率和损失共用纵轴没有意义；把一个很窄区间的细节强行与极宽范围共享，可能压扁重要变化。可以保留一组公共范围的总体图，再用清楚标注的局部图显示细节。局部放大应标出区间与来源，不能让读者误以为尺度仍与总体一致。

对数轴也要统一解释。它表达比值而非相同绝对差，零和负数不能按普通对数显示。若比较加性误差、正负残差或包含零的区间，应选择适合的尺度，并说明任何对称对数或变换后的阈值。尺度是统计表达的一部分，不是最后才加的装饰。

### 图解：配对差值与独立重复

![配对差值与独立重复](images/03-concept.svg)

本图与第五节完整实验共用八个任务及其 A、B 得分，统一定义差值为 **B 减 A**；后文不再需要反转符号。左边一条连线只连接同一任务的两个结果，蓝圆为 A，橙方为 B。任务之间的分数差很大，但这不是模型差值的波动本身；先在配对内相减，才能消去共同难度的部分影响。

右边保留八个原始差值：`0.025、0.012、−0.006、0.019、0.031、0.015、0.009、0.023`。第三个任务为负，明确显示 B 并非处处占优，不能为了让全部线条朝同一方向而删除它。均值为 `0.016`；下方只对这八个差值估计标准误，再用自由度七的 Student 分位数构造区间，而没有把 A、B 的边缘误差条拼成差值区间。

这个人工例子的区间约为 `[0.0064, 0.0256]`，图中端点由与完整程序相同的表达式计算。它描述假设模型下的均值差，不是“八个任务差值有 95% 落在这里”，也不是下一次任意任务的预测范围。任务抽样、代表性、跨任务相关性和选择过程仍需独立论证；真实任务若来自同一个模板，就不能只按八个独立观测套公式。

均值与区间放在单独的汇总位置，不把它冒充第九个任务，也不连接到原始任务形成虚构顺序。均值区间的 Student 构造与覆盖解释可对照 [NIST 均值区间说明](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm)。图中配对连线、零参考线、原始负差值与汇总条各自承担不同证据，不能只看一条窄区间就省掉其他信息。

## 2. 轴数组、网格和图形对象的组织

<a id="plot-3-detail-6"></a>

### 2.1 固定轴数组维度，避免形状偶然改变

调用创建子图的接口时，返回的轴对象形状可能随行列数改变：单个面板可能得到一个 Axes，一行多列可能得到一维数组，多行多列则是二维数组。通用绘图函数若假定始终可以写两重索引，在面板数改变时就容易失败。

本章使用固定二维返回的方式组织规则网格，并显式索引每个位置。这样从二乘二改成一乘二时，循环结构仍清楚。另一种方案是把轴数组展平，按面板顺序遍历；适合每幅图功能相同的场景，但对于具有不同语义的诊断面板，显式命名通常更容易核对。

真正需要保持的不是数组外形本身，而是“这个轴负责哪个问题”的映射。若先按指标名排序数据，再按另一顺序分配轴，很容易出现标题与数据错配。可用字典将语义名称关联到轴，或者让每个绘图函数明确接收目标 Axes，避免依赖当前激活的隐式轴。

<a id="plot-3-detail-7"></a>

### 2.2 GridSpec 与不等宽面板

规则网格适合结构对称的比较；当残差散点需要较大空间，而边缘分布只需窄条时，可以用网格比例安排不同宽度。跨列总览、下方细节和独立颜色条也可通过网格组织。布局比例应由数据阅读任务决定，而不是追求视觉对称。

一个需要展示五十个类别标签的面板，通常需要比只有三个点的面板更高；一个需要精确读时间变化的曲线，需要足够横向长度。若所有面板等大却导致某图标签密集，平均分配面积反而降低可读性。应先估计最终输出尺寸，再安排各面板的有效绘图区。

布局系统能够帮助安排间距，但不会知道研究问题的优先级。它也不能保证任意长标题、外置图例和颜色条在所有尺寸下都合理。因此自动布局之后仍需实际渲染，再检查文字、刻度与主要数据是否被遮挡。不要把“程序未报错”当作排版通过。

<a id="plot-3-detail-8"></a>

### 2.3 图例、颜色条和重复标签

同一颜色跨面板表示同一个模型，可以减少读者记忆负担；若另一个面板把相同颜色改成标签类别，就应明显区分或更换编码。颜色语义冲突比单纯颜色不够漂亮更危险，因为它会让读者在不自觉中建立错误联系。

共享图例适合所有面板包含同一组对象，但不应把只在一个面板出现的含义强行推广到全图。颜色条则对应连续量到颜色的映射，必须绑定明确的归一化范围。两个热图使用相同颜色条时，应保证它们真的共享相同数值尺度，而不是分别自动归一化后共用一个标签。

减少重复轴标签可以节省空间，但不能删除读者恢复单位所需的信息。内部面板可以隐藏重复刻度文字，外层保留清楚的公共标签；若子图使用不同单位，则每个轴都应标注。应区分“重复信息可合并”与“必要信息被省略”。

## 3. 误差条的统计对象先于画法

<a id="sec-1-1"></a>

<a id="plot-3-detail-10"></a>

### 3.1 从原始重复值推导标准差和标准误

对独立同分布重复值 $`x_1,\ldots,x_n`$，样本均值为 $`\bar x=\sum_i\frac{x_i}{n}`$，样本方差为 $`s^2=\sum_i\frac{(x_i-\bar x)^2}{(n-1)}`$。分母使用 $`n-1`$，反映在估计均值后剩余的自由度。标准差 $`s`$ 描述观测或运行之间的离散，而不是均值本身的误差。

若各重复独立且具有相同有限方差，则均值方差为 $`\frac{\sigma^2}{n}`$，以样本方差替代得到标准误估计 $`\frac{s}{\sqrt n}`$。这一步使用了独立性；若重复来自同一长时间序列或同一训练轨迹的多个回合，协方差项不能直接消失。

对于数值一、二、三，均值为二，样本标准差为一，标准误为 $`\frac{1}{\sqrt3}`$。画均值加减标准差是在展示运行的散布，画均值加减标准误是在展示均值估计精度。两条都不自动等于百分之九十五置信区间，更不能按哪条更窄就挑哪条用于证明稳定。

<a id="deep-dive-3"></a>

<a id="plot-3-detail-11"></a>

### 3.2 置信区间需要覆盖率和抽样假设

在独立、同分布、正态总体且方差未知的条件下，均值的双侧区间可写为

$$
\bar x\pm t_{n-1,1-\frac{\alpha}{2}}\frac{s}{\sqrt n}.
$$

这不是因为所有误差条都应该乘一个固定常数，而是相应标准化统计量服从 Student 分布。样本只有三次时，自由度为二，百分之九十五区间的系数约为四点三零三，明显大于常用的一点九六。少量重复下用大样本常数可能给出过窄区间。

频率学派置信区间的覆盖率描述重复抽样中构造程序包含固定参数的比例，不是说这一次算出的区间自动包含参数的概率为百分之九十五。若采用贝叶斯可信区间，则需要后验模型与先验假设，其概率对象不同。图注不必重述全部统计学，但应准确命名区间。

非正态、重尾、相关或经过复杂选择的数据，需要更适合的推断方法。自助法也不是无需条件的万能工具：独立单位、重采样结构与统计量的稳定性仍然重要。对只有三次运行的数据，保留原始点通常比给出看似精确的光滑区间更能表达证据强度。

<a id="plot-3-detail-12"></a>

### 3.3 预测区间与均值区间不能互换

如果目标是总体均值，均值置信区间随样本量增加通常会缩小；如果目标是下一次观测落在哪个范围，则还要包含个体噪声，因此预测区间通常更宽。对于独立正态观测，未知均值与方差时，新观测的区间尺度包含 $`s\sqrt{1+\frac{1}{n}}`$，不是 $`\frac{s}{\sqrt n}`$。

在回归图中，拟合均值的区间与新样本预测区间也不同。前者反映均值函数估计的不确定性，后者还包含条件噪声。若数据异方差，预测区间宽度应随输入变化；用一个固定宽度阴影覆盖所有位置，可能掩盖真正的条件风险。

图上同样是一条半透明带，统计意义却可能完全不同。因此图例应写“均值的置信区间”“运行标准差”或“新观测预测区间”，避免仅写“误差范围”。阴影的透明度和颜色不能替代对象定义。

<a id="plot-3-detail-13"></a>

### 3.4 层级样本中的伪重复

假设进行了五次独立训练，每次在一千个相同测试样本上得到准确率。五个运行分数可用于描述训练随机性；测试样本层面的不确定性则取决于测试抽样。不能把五千条预测简单当成五千个独立训练实验，因为同一模型内和同一样本跨模型的预测具有相关结构。

若每个患者贡献多张图像，图像数量也不等于患者数量。按图像独立重采样可能严重低估跨患者泛化误差。应从研究目标出发决定独立单位：关心新患者就应保留患者内结构，关心同一患者未来图像还需考虑时间。

同样，多折交叉验证的分数由于训练集重叠而有关联；五个折分数不自动等于五次相互独立的实验。画出折分布有诊断价值，但不能不加说明地用独立重复公式计算标准误。图表应揭示数据结构，而不是用点的数量夸大证据数量。

## 4. 配对比较、差值与不对称区间

<a id="plot-3-detail-15"></a>

### 4.1 为什么两组区间重叠不能代替差值分析

同一任务上两模型分数记为 $`A_i,B_i`$，差值为 $`D_i=B_i-A_i`$。它的方差满足

$$
\operatorname{Var}(D)=\operatorname{Var}(A)+\operatorname{Var}(B)
-2\operatorname{Cov}(A,B).
$$

若共同任务难度造成两模型分数高度正相关，差值波动可以很小，即使两个模型各自的分布都很宽。分别画两组置信区间并观察是否重叠，会丢掉协方差信息，不能作为配对比较的通用判断方法。

例如任务分数甲为十、二十、三十、四十，乙总比甲高二分。两组边缘分布大幅重叠，但每个差值都是二。在理想化数据中配对差异没有观测波动；真实研究仍要检查任务代表性、测量精度和未来随机性，不能据此声称所有未来任务必定高二分。

更适合的表达是同时画配对连线和差值图。连线保留任务对应关系，差值图把零作为直接参考。若“越低越好”，应统一差值方向，例如画甲减乙，让正值始终表示乙改善，并在轴标签中写清。方向反复变化会让同一颜色在不同面板里表达相反结论。

<a id="sec-7-1"></a>

<a id="plot-3-detail-16"></a>

### 4.2 均值差区间应直接从配对差构造

在配对差独立同分布且正态的条件下，均值差区间为 $`\bar D\pm\frac{t\,s_D}{\sqrt n}`$。这里用的是差值标准差，而不是把两模型标准差分别除以根号样本数后直接拼接。若数据不适合该模型，可按真实独立任务成对重采样，始终保持同一任务的两模型记录一起移动。

若任务来自几个共同数据源，任务间也可能相关，应考虑数据源层面的重采样或显式层级模型。若跨随机种子与跨任务都有重复，最好保留完整交叉表，明确要推广到新的训练运行、新的任务，还是两者都包括。把所有单元格压成独立长向量通常会低估不确定性。

图中可以保留每个原始差值，再加一个均值及区间。这样读者能看到平均改善是否由少数极端任务驱动，以及是否存在相反方向的子群。一个跨过零的区间不证明没有效果；它只说明在对应假设和样本下，数据还兼容多种差值。

<a id="plot-3-detail-17"></a>

### 4.3 比值和对数变换产生自然的不对称

对耗时、吞吐量和困惑度这类正值，比值通常比绝对差更有意义。若研究每个任务的加速比，可先定义 $`R_i=\frac{T_{A,i}}{T_{B,i}}`$，再决定平均的是原始比值、对数比值还是总耗时比。三个对象不同，不能仅因为都叫平均加速就互换。

若在对数尺度估计 $`\mu=\mathbb E[\log R]`$，指数变换得到几何平均比值 $`e^\mu`$。对数区间 $`[a,b]`$ 变回原尺度为 $`[e^a,e^b]`$，通常不对称。Matplotlib 绘制这种区间时应传入中心到两端的距离，而不是把两端数值直接当误差长度。

还应注意，某些分位数区间不一定包含指定点估计。如果下界高于中心或上界低于中心，误差距离会出现负数，此时应使用独立线段画区间与独立点画估计，而不是取绝对值伪造包含关系。接口限制应促进准确表达，不能反过来修改统计结果迎合接口。

<a id="plot-3-log-retransformation"></a>

#### 进阶图解：指数还原的区间，到底属于哪个均值？

![相同对数均值、不同原尺度均值及两种区间变换](images/03-log-retransformation-target.svg)

上一节的指数区间保留了单调变换的对应关系，但还要核对**被变换的参数是不是最终要报告的参数**。设正值响应满足 $`Z=\log Y`$，且 $`Z\sim N(\mu,\sigma^2)`$。此处 $`\sigma`$ 描述总体在对数尺度上的离散，不是均值估计的标准误。对数正态的参数和密度可核对 [NIST 分布手册](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3669.htm)。

在这个模型中，

$$
\operatorname{median}(Y)=e^\mu,
\qquad
\exp(E[\log Y])=e^\mu,
\qquad
E[Y]=e^{\mu+\frac{\sigma^2}{2}}.
$$

前两项分别是原尺度中位数与总体几何均值；两者在这里相同，不代表对任意正值分布都相同。第三项是原尺度算术均值。它还依赖对数方差，因此仅将对数均值取指数不会把这个量自动还原出来。

**方差修正项从哪里来？** 将期望写成积分并配方：

$$
\begin{aligned}
E[e^Z]
&=\int_{-\infty}^{+\infty}
e^z\frac{1}{\sigma\sqrt{2\pi}}
\exp\!\left[-\frac{(z-\mu)^2}{2\sigma^2}\right]\,dz\\
&=e^{\mu+\frac{\sigma^2}{2}}
\int_{-\infty}^{+\infty}
\frac{1}{\sigma\sqrt{2\pi}}
\exp\!\left[-\frac{(z-\mu-\sigma^2)^2}{2\sigma^2}\right]\,dz\\
&=e^{\mu+\frac{\sigma^2}{2}}.
\end{aligned}
$$

最后一个积分是一份平移后正态密度的总质量。这个推导也说明，修正不是为了让图更好看，而是原尺度右尾对算术均值的实际贡献。

图中两个总体都取 $`\mu=0`$，标准差分别为 $`0.2`$ 和一。两者中位数及几何均值都为一，原尺度算术均值却分别为 $`e^{0.02}\approx1.020201`$ 与 $`e^{0.5}\approx1.648721`$。更宽的对数分布经指数映射后，右尾被放大；“对数均值相同”因此没有推出“平均耗时或平均金额相同”。图画的是理论总体密度，不是模拟运行误差条。

#### 已知方差时，正确的区间也必须跟着目标变

假设已经为 $`\mu`$ 构造某个置信水平的区间 $`[a,b]=[-0.2,0.2]`$。指数函数严格递增，所以 $`[e^a,e^b]`$ 对参数 $`e^\mu`$ 保留同一覆盖事件，约为 $`[0.818731,1.221403]`$。这个结论本身没有错；错误是把该区间的标签改成“原尺度算术均值区间”。

如果 $`\sigma=1`$ 已知，算术均值是 $`e^{\mu+\frac12}`$，相应区间应为

$$
\left[e^{a+\frac12},e^{b+\frac12}\right]
\approx[1.349859,2.013753].
$$

它与前一个区间甚至没有重叠，也不能通过给误差条换一套对数坐标修复。如果 $`\sigma^2`$ 也由样本估计，单纯把估计方差代入上述端点，一般没有自动继承原区间覆盖率。应对目标 $`\mu+\frac{\sigma^2}{2}`$ 的联合估计误差构造推断，或按合适抽样单位重采样整个估计流程，再映回原尺度。

这两种都是参数区间，还不是新观测 $`Y_{\mathrm{new}}`$ 的预测区间。画图时应在图例中明确写出“几何均值”“算术均值”或“新观测”，再决定使用原尺度轴还是对数轴。轴只改变位置的显示方式，不替统计量增加缺少的方差修正或采样不确定性。

#### 从总体变换继续追问估计偏差和异方差

还要把两种非线性效应分开。即使目标确定为几何均值，若独立正态样本的均值为 $`\bar Z`$，样本量为 $`n`$，则

$$
E[e^{\bar Z}]
=e^{\mu+\frac{\sigma^2}{2n}}.
$$

所以 $`e^{\bar Z}`$ 对 $`e^\mu`$ 也有有限样本偏差。这一额外项含 $`n`$，源于参数估计的不确定性；原尺度算术均值中的 $`\frac{\sigma^2}{2}`$ 则源于个体分布的离散，两者不能互相替代。在方差已知的当前正态模型中，$`\exp(\bar Z-\frac{\sigma^2}{2n})`$ 才对总体几何均值无偏；这不是对任意误差分布通用的修正公式。

若研究条件响应，写成 $`\log Y=m(x)+\epsilon`$，一般有

$$
E[Y\mid x]
=e^{m(x)}E[e^\epsilon\mid x].
$$

条件正态且方差为 $`s^2(x)`$ 时，右侧因子为 $`e^{\frac{s^2(x)}{2}}`$；异方差下它随输入改变，不能只用全体数据的一个方差修正所有样本。不作正态假设时，可以研究用残差分布估计重变换因子的 smearing 方法；共同残差分布等条件和估计误差仍需核对，见 [Duan 的原始论文](https://people.stat.sc.edu/hoyen/PastTeaching/STAT704-2022/Notes/Smearing.pdf)。它不是把每个残差都设为零后再取指数。

一个适合读图的练习是：固定两个组的对数均值，只增大其中一组方差，先预测中位数、算术均值和预测区间分别如何改变，再检查图例是否准确。只改对数轴不会改变任何数据汇总值；改成先取对数再汇总，则已经重新定义了统计问题。


<a id="sec-2-1"></a>

<a id="plot-3-detail-18"></a>

### 4.4 保持类别、中心与上下界的顺序一致

一组误差条至少包含类别名称、横坐标、中心、下界和上界，所有数组都应来自同一条记录顺序。若根据中心值排序，必须用同一个排序索引同时重排其他字段。分别排序上下界会让图仍然平滑漂亮，却给每个模型配上别人的区间。

标准误差接口的不对称数组通常是两行：第一行是向下长度，第二行是向上长度；每列对应一个数据点。它接收的是非负距离，并非直接接收区间端点。可以先断言下界不高于中心、上界不低于中心，再堆叠两个距离数组。

对正值使用对数轴时，距离仍要按原数据单位计算，不能先把端点取对数后作为普通数据误差传入。坐标变换由轴完成；统计量在哪个尺度定义、接口接收哪个尺度的数据，是两个需要分别核对的步骤。

## 5. 实验一：原始运行、配对差与误差条

<a id="plot-3-detail-20"></a>

### 5.1 一个可手算核对的完整图

下面构造八个相互独立任务的教学数据。两模型在每个任务上配对，分数越高越好。左图保留所有任务连线，右图画逐任务差值，以及基于独立正态差值假设的均值区间。实验展示统计组织，不把人工数据当真实模型结论。

代码将 PNG 写入内存缓冲区。绘图后实际触发渲染，并检查图像能被解码以及尺寸非空。这些检查不能完全替代人工看图，但能发现未渲染、错误格式和空输出。画布大小、标题长度与标签数量也保持在可读范围。

```python
from io import BytesIO
import numpy as np
from scipy.stats import t
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from PIL import Image

a = np.array([0.61, 0.72, 0.66, 0.81, 0.75, 0.68, 0.84, 0.77])
b = a + np.array([0.025, 0.012, -0.006, 0.019, 0.031, 0.015, 0.009, 0.023])
d = b - a
n = len(d)
mean = d.mean()
se = d.std(ddof=1) / np.sqrt(n)
half = t.ppf(0.975, n - 1) * se
lo, hi = mean - half, mean + half
assert lo <= mean <= hi

fig, axes = plt.subplots(1, 2, figsize=(9, 3.7), squeeze=False,
                         layout="constrained")
left, right = axes[0]
for ai, bi in zip(a, b):
    left.plot([0, 1], [ai, bi], color="0.72", linewidth=1, zorder=1)
left.scatter(np.zeros(n), a, label="A", color="#0072B2", zorder=2)
left.scatter(np.ones(n), b, label="B", color="#D55E00", marker="s", zorder=2)
left.set(xticks=[0, 1], xticklabels=["A", "B"],
         ylabel="Task score (higher is better)", title="Paired tasks")
left.set_xlim(-0.4, 1.4)
left.legend(loc="upper left")
right.scatter(np.arange(n), d, color="0.45", label="Task difference")
right.errorbar([n + 0.8], [mean], yerr=[[mean - lo], [hi - mean]],
               fmt="D", capsize=5, color="#009E73",
               label="Mean, 95% t interval")
right.axhline(0, color="black", linewidth=0.8, linestyle="--")
right.set(xticks=[0, 3, 7, n + 0.8],
          xticklabels=["1", "4", "8", "Mean"],
          xlabel="Task / summary", ylabel="B - A",
          title="Direct difference")
right.legend(fontsize=8, loc="upper left")
fig.canvas.draw()
png = BytesIO()
fig.savefig(png, format="png", dpi=140)
png.seek(0)
with Image.open(png) as image:
    assert image.size == (1260, 518)
print("mean difference / 95% interval:", mean, (lo, hi))
print("image bytes:", len(png.getvalue()))
plt.close(fig)
```

### 5.2 读图时能说什么，不能说什么

左图主要显示任务难度差异与配对改善方向，右图才直接展示差值相对零的位置。若观察到一条负差任务，不应删掉它以获得所有连线都上升的视觉效果。它可能是重要的适用边界，也可能只是噪声，需要回到数据和任务机制检查。

区间建立在独立正态差值假设上。八个任务是否真能视作独立、是否代表未来任务，并不是由画图函数判断的。若任务全部来自同一模板，独立性可能明显不足；若只挑了乙占优的任务，区间计算再规范也无法恢复目标总体的代表性。

右侧汇总点在横轴上不是第九个任务，因此代码用独立位置并明确写均值。把它与普通任务连成折线会制造不存在的任务顺序关系。可见即使数值完全正确，图元之间的连接方式仍可能添加错误语义。

## 6. 残差面板：从模式到可检验假设

<a id="sec-4"></a>

<a id="plot-3-detail-23"></a>

### 6.1 先固定残差的符号和条件变量

本章定义残差 $`r=y-\hat y`$，正值表示模型低估，负值表示高估。如果另一份报告使用相反定义，所有方向解释都要随之改变。图注应写明定义，不能仅用“误差”一词同时指带符号残差、绝对误差和平方误差。

残差对预测值主要检查条件偏差和尺度变化；残差对输入可以发现某些遗漏结构；残差对时间可以发现漂移和自相关；残差直方图只描述边缘分布。它们是不同投影，一张图平坦或对称不能证明其他方向上没有问题。

训练集残差还受到拟合过程约束。例如带截距的普通最小二乘在训练样本上残差和为零，这主要来自正规方程，不是独立证据证明模型无偏。测试集残差或交叉拟合残差更接近外部诊断问题，但仍需检查划分和分布条件。

<a id="sec-6"></a>

<a id="plot-3-detail-24"></a>

### 6.2 扇形、曲线和尾部不是唯一原因的指纹

残差呈扇形，可能来自异方差、单位缩放、目标分布变化或选择机制。出现曲线，可能意味着均值结构不足，也可能来自截断、测量误差或把横轴设为与残差共享噪声的变量。图形提供假设，不直接识别因果机制。

一个特别容易忽略的问题是残差对真实值。由于 $`r=y-\hat y`$ 含有 $`y`$，横轴与纵轴共享同一随机量，即使某些预测误差机制合理，也可能出现机械关联。因此不能把残差对真实值的倾斜直接解释成模型在高值区域存在特定结构性偏差，应该结合预测值、输入和生成机制分析。

尾部离群点也需要追溯。标签错误、单位错误、真实稀有事件和模型失配都能产生极端残差。删除之前应判断它是否属于目标分布，是否存在独立的数据质量证据。按误差大小事后删除会把困难样本从评估对象中移走，得到另一个更容易的任务。

<a id="plot-3-detail-25"></a>

### 6.3 分箱均值与箱内分散必须分开画

把残差按预测值分箱，箱内平均残差可帮助观察局部偏差，但箱宽、边界和每箱样本数会影响结论。等宽箱保留原尺度距离，却可能在尾部很稀疏；等频箱让计数更接近，却有不同宽度，不能把各中心等距摆放后仍声称横轴是原始数值。

每箱均值区间描述局部平均残差估计的波动，箱内标准差描述个体误差分散。二者可能一宽一窄：很多高噪声样本能让均值估计很精确，但个体预测仍不可靠。若主要关心实际预测风险，应同时展示绝对误差、分位数或预测区间，而不只看平均残差是否接近零。

分箱还是一种平滑，可能掩盖箱内非线性与子群差异。应保留低透明度散点或其他分布信息，并报告边界敏感性。通过反复尝试箱数挑出最清晰的趋势，再把它当成预先指定结论，会低估探索选择带来的不确定性。

### 图解：异方差：零均值不代表误差尺度恒定

左图每个横坐标都有一对正负对称残差，细竖段只连接这一对观测，橙方是它们的平均。预测值一到四分别对应残差正负一、正负二、正负三、正负四，因此局部均值均为零，但残差绝对值随横坐标扩大。右图在相同横坐标上计算平均绝对误差，依次为一、二、三、四；两个面板来自同一批八条记录，没有靠改变样本组成制造差异。只看均值线会漏掉这种扇形结构；应同时检查离散程度、分箱残差或适合的方差模型。

## 7. 实验二：异方差、分箱和共同尺度

<a id="plot-3-detail-27"></a>

### 7.1 明确生成机制再解释图形

下面生成一个非线性均值、噪声随输入变化的回归任务，再故意使用线性模型拟合。模型只在训练集上拟合，诊断使用独立测试数据，因此残差图不会仅仅重现训练正规方程的约束。这里知道真实机制，所以可以把图形现象与构造条件对照；真实数据中则需要额外研究才能归因。

四个面板分别展示真实与预测、残差对预测、箱内均值与标准差、箱计数。第三幅同时保留两种不同范围：标准差描述箱内散布，均值区间描述平均残差估计精度。它们共享中心但不共享含义，图例明确区分，不把较窄范围当作个体误差已经很小。

分箱覆盖所有有限预测值，并特别处理最右端点。若简单使用半开区间并忘记最后端点，最大预测样本会被静默丢失。样本计数守恒是很有用的验证条件；每个箱至少两个样本时才估计样本标准差与相应均值区间。

```python
from io import BytesIO
import numpy as np
from scipy.stats import t
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from PIL import Image

rng = np.random.default_rng(23)
def make_sample(n):
    x = rng.uniform(-2.0, 2.0, n)
    mu = 1.0 + 0.8 * x + 0.45 * x ** 2
    y = mu + rng.normal(size=n) * (0.2 + 0.3 * np.abs(x))
    return x, y

x_train, y_train = make_sample(500)
x_test, y_test = make_sample(700)
design = np.column_stack([np.ones(len(x_train)), x_train])
beta = np.linalg.lstsq(design, y_train, rcond=None)[0]
pred = np.column_stack([np.ones(len(x_test)), x_test]) @ beta
resid = y_test - pred
edges = np.linspace(pred.min(), pred.max(), 9)
idx = np.clip(np.searchsorted(edges, pred, side="right") - 1, 0, 7)
counts = np.bincount(idx, minlength=8)
assert counts.sum() == len(pred)
centers = (edges[:-1] + edges[1:]) / 2
means = np.full(8, np.nan)
sd = np.full(8, np.nan)
half = np.full(8, np.nan)
for j in range(8):
    values = resid[idx == j]
    if len(values) >= 2:
        means[j] = values.mean()
        sd[j] = values.std(ddof=1)
        half[j] = t.ppf(0.975, len(values) - 1) * sd[j] / np.sqrt(len(values))
valid = np.isfinite(half)

fig, axes = plt.subplots(2, 2, figsize=(9, 7), squeeze=False,
                         layout="constrained")
axes[0, 0].scatter(pred, y_test, s=9, alpha=0.3, color="#0072B2")
limits = [min(pred.min(), y_test.min()), max(pred.max(), y_test.max())]
axes[0, 0].plot(limits, limits, "--", color="black", linewidth=1)
axes[0, 0].set(xlabel="Prediction", ylabel="Observed", title="Held-out predictions")
axes[0, 1].scatter(pred, resid, s=9, alpha=0.25, color="#0072B2")
axes[0, 1].axhline(0, color="black", linewidth=0.8)
axes[0, 1].set(xlabel="Prediction", ylabel="Observed - prediction",
               title="Residual structure")
ax = axes[1, 0]
ax.errorbar(centers[valid], means[valid], yerr=sd[valid],
            fmt="none", color="0.72", capsize=5, label="Within-bin SD")
ax.errorbar(centers[valid], means[valid], yerr=half[valid],
            fmt="o", color="#D55E00", capsize=3,
            label="Mean, approximate 95% t interval")
ax.axhline(0, color="black", linewidth=0.8)
ax.set(xlabel="Prediction bin center", ylabel="Residual",
       title="Spread differs from mean precision")
ax.legend(fontsize=8)
axes[1, 1].bar(centers, counts, width=np.diff(edges) * 0.85, color="0.5")
axes[1, 1].set(xlabel="Prediction bin center", ylabel="Held-out count",
               title="Support per bin")
axes[1, 0].set_xlim(edges[0], edges[-1])
axes[1, 1].set_xlim(edges[0], edges[-1])
fig.canvas.draw()
png = BytesIO()
fig.savefig(png, format="png", dpi=120)
png.seek(0)
with Image.open(png) as image:
    assert image.size == (1080, 840)
print("test count / MAE / mean residual:",
      len(resid), np.abs(resid).mean(), resid.mean())
print("bin counts:", counts.tolist())
plt.close(fig)
```

### 7.2 为什么区间只能称为近似

在每个预测箱内，残差可能来自不同输入位置的混合分布，未必正态。样本较多且满足适当条件时，均值的正态近似有帮助，但不能把 Student 分位数的使用误写成有限样本精确保证。这里图注特意写近似区间，明确它是局部均值诊断的教学表达。

此外，这些区间主要条件于当前已拟合模型，反映测试样本波动，不包含重新抽取训练集和重新训练的随机性；分箱边界还由本次测试预测的最小值与最大值确定，因此不是预先固定分箱下的精确覆盖承诺。若需要完整训练流程的不确定性，应设计额外训练重复或相应层级重采样，并重新计算分箱规则。

箱内个体异方差并不会自动使均值估计完全不可用，但会影响标准误的解释与效率。如果观测还按患者聚类或按时间相关，独立样本公式就更需要调整。研究报告应依据真实数据结构选择区间方法，而不是因为库能返回一个区间就默认适用。

这幅图主要显示线性均值不足与输入相关噪声的共同后果，不能只凭某个单面板把所有残差模式归因于一个原因。可以增加正确二次模型作为对照，检查曲线趋势是否减弱，再比较噪声散布是否仍随输入变化。通过可控修改检验解释，比给图形贴一个名称更有研究价值。

## 8. 多重比较、同时带与探索性选择

<a id="sec-6-1"></a>

<a id="plot-3-detail-30"></a>

### 8.1 点态区间不是整条曲线的同时保证

对每个时间点构造百分之九十五区间，并不意味着该构造程序对整条曲线具有百分之九十五的同时覆盖率。若有很多近似独立位置，至少一个位置超出点态区间的机会可能显著增加。曲线相关时情况更复杂，但不能因此忽略同时覆盖问题。

如果研究问题是“某个预先指定时间点的均值”，点态区间可能正合适；如果主张是“整个训练阶段都更好”，则需要相应同时推断或更明确的汇总目标。可采用最大偏差统计量、自助同时带或保守多重校正，但每种方案仍依赖抽样结构。

一种可以直接推导的保守构造是 Bonferroni 同时区间。先固定 $`m`$ 个比较时刻，在每个时刻构造覆盖至少 $`1-\frac{\alpha}{m}`$ 的区间 $`C_j`$。令 $`E_j`$ 表示第 $`j`$ 个真均值未落入对应区间，由并集界，

$$
P\left(\bigcup_{j=1}^{m}E_j\right)\le\sum_{j=1}^{m}P(E_j)\le\alpha.
$$

因此所有 $`m`$ 个真均值同时被覆盖的概率至少为 $`1-\alpha`$，不需要各时刻独立。如果比较二十个预先指定时刻并取 $`\alpha=0.05`$，每点应使用百分之九十九点七五区间；若原本采用双侧正态近似，两个尾部各分配 $`0.00125`$，而不是继续用一点九六倍标准误。每点覆盖若只是渐近近似，整体结论也继承这种近似，不能把并集界当作修复小样本区间失效的手段。

这保证的是固定网格，不能仅靠连接区间端点就扩展为连续时间上的带。若要覆盖连续时间，必须额外控制网格之间的变化；若先看图再挑时刻，预先固定的比较族也已经改变。相反，在真正独立且每点精确覆盖百分之九十五的理想情形，二十个点全部覆盖只有 $`0.95^{20}\approx0.3585`$。

这个计算用于解释点态与同时声明的差距，真实训练曲线通常相关，不能直接把该数当作实际覆盖率。两模型比较时还应先对每个独立运行形成整条配对差值曲线，再针对差值均值构造区间，保留同次运行跨时刻和跨模型的关联。

一个简单且清楚的替代，是预先指定最终预算或曲线面积等主要统计量，再对该量做配对比较，曲线作为过程诊断。这样能避免事后在几十个时间点中挑最大优势，却按单次比较解释。选择目标应由实际研究问题决定，而不是只挑最容易得到显著性的指标。

<a id="plot-3-detail-31"></a>

### 8.2 最好检查点和最好随机种子的选择偏差

把每次训练中验证分数最高的位置取出，再报告这些最高值，描述的是“按验证集选择检查点”的算法表现，不是任意固定训练时刻的表现。若同一验证集既用于大量搜索又用于最终性能结论，分数会受到选择效应影响，独立测试仍有必要。

只画最好随机种子会隐藏运行可靠性。若应用实际只能训练一次，随机运行分布很重要；若预算允许训练十次再按验证规则选一次，则应该评估这个完整选择过程，并把十次训练成本计入。两种部署方式可以有不同的合理指标，但不能用前者成本配后者成绩。

画图时还应说明失败运行。某些运行因数值发散、资源超限或提前停止而没有后期点，简单忽略它们会让后期均值看起来更好。应报告每个横轴位置可用运行数，并区分计划性终止与失败缺失。只比较共同范围是一种选择，却也可能忽略长期失败，需要配合失败率说明。

<a id="plot-3-detail-32"></a>

### 8.3 连接和插值可能引入额外假设

两模型在不同时间记录指标时，不能把数组行号当共同时间轴。若采用插值对齐，应明确插值方法和允许的区间，避免超出已观测范围外推。阶梯保持、线性插值和按最近检查点比较，会得到不同曲线面积与局部差值。

记录频率本身也可能与事件有关，例如只在指标改善时记录，会选择性保留好点。图形代码无法修复不完整日志所造成的信息缺失。应尽量在预定预算位置记录，并在汇总前核对时间单调、重复时间戳与缺失规则。

对离散检查点的连线通常只是视觉引导，不表示中间每个时刻都测得该值。若训练发生阶段跳变，阶梯或散点可能更诚实。任何平滑操作都应保留原始值可追踪，不能让看似平稳的曲线掩盖瞬时发散或停止事件。

## 9. 图形语义的数值检查与交付检查

<a id="plot-3-detail-34"></a>

### 9.1 比较正确，比渲染成功更重要

一个图可以通过文件格式检查，却仍把错误数组放在正确标题下。应先核对数据不变量：计数是否守恒、配对键是否唯一、上下界是否对应同一记录、区间单位是否与中心一致、颜色条范围是否一致。只测试图形对象数量不能发现这些语义错误。

可建立从输入记录到图中数值的简短对账表。例如每个任务一行，包含甲、乙、差值、权重与组别；每个误差条一行，包含中心、端点、样本数和方法。图形与报告表格都从同一汇总结果生成，减少重复实现造成的不一致。

对大量样本可以抽取少数记录手算，尤其检查边界、缺失、零权重和极端值。正常随机数据往往无法暴露端点丢失或顺序错配，精心构造的小算例更有效。绘图检查也应选择能破坏错误实现的不变量，而不是仅确认程序再次给出同样结果。

<a id="plot-3-detail-35"></a>

### 9.2 在最终尺寸下审阅而非只看放大窗口

文字字号以物理点计量，图像像素受尺寸与分辨率共同影响。一个宽九英寸的图缩到文章单栏时，所有文字和线条都会一起缩小；提高 PNG 分辨率不能恢复已经过小的物理字号。应先确定最终展示宽度，再决定面板数、字体和线宽。

实际审阅至少包括是否裁切、图例是否遮挡数据、长刻度是否重叠、误差条帽是否过密、颜色是否在灰度下仍可区分。数值密集时可以减少刻度数量，但不能删除必要范围信息。错误率接近零的图还要注意标记是否被轴边界覆盖。

矢量格式能保留几何与文字清晰度，但不自动保证字体在所有环境一致；大量散点也可能导致文件过大。可以对密集图层使用栅格化，同时保留轴与文字为矢量。导出方式应服务最终媒介，并在实际文件上验证，而不是凭格式名称推断效果。

<a id="plot-3-detail-36"></a>

### 9.3 探索图和结论图承担不同责任

探索时可以快速切换尺度、分箱和子群以寻找结构；结论图则需要冻结定义并说明选择过程。如果发现趋势后又据此修改模型，同一数据集便参与了开发。它仍有诊断价值，但不能再当作完全独立的最终证据。

结论图不需要包含所有探索历史，却应保留支撑主张所需的口径、样本数和限制。若某个模式只有一种分箱或一种轴范围下明显，应检查它是否稳健，并说明敏感性。好的排版帮助读者看到证据，而不是帮助研究者隐藏不利情况。

与统计学章节相比，本章的重点是把这些假设落实到可视图元：原始点、连线、零线、区间、计数条和共享轴各自承载什么含义。图中的每一个视觉选择都应能回到一个数据或推断理由，这比记住很多绘图参数更重要。

## 10. 进阶扩展：权重、层级与稳健汇总

<a id="plot-3-detail-38"></a>

### 10.1 加权均值的目标和标准误不能随意拼接

若任务有非负权重 $`w_i`$，加权均值为 $`\bar x_w=\frac{\sum_iw_ix_i}{\sum_iw_i}`$。权重可能表示部署频率、样本重复次数、抽样校正或估计精度，它们的统计解释不同。相同数值公式不意味着可以使用相同方差估计，必须先说明权重来自哪里。

在权重固定、观测独立且方差都为 $`\sigma^2`$ 的简单模型下，均值方差为 $`\sigma^2\sum_i\frac{w_i^2}{(\sum_iw_i)^2}`$。由此可定义一个形式上的有效样本量 $`\frac{(\sum_iw_i)^2}{\sum_iw_i^2}`$，但它依赖这里的同方差与固定权重假设。对于复杂抽样、估计权重或聚类数据，不能只把它塞进根号公式就宣称推断完成。

如果每个任务本身有不同样本数，平均任务准确率与汇总所有预测后的准确率也不同。前者让每个任务等权，后者让每个样本等权。两种图都可以合理，但应标清分母，并避免把总体样本权重的区间画在任务等权中心上。中心与区间必须对应同一统计目标。

<a id="plot-3-detail-39"></a>

### 10.2 层级自助法应保留研究中的相关结构

设多个机构各有若干患者，每个患者有多张图像。如果研究要推广到新机构，可以先重采样机构，再在机构内按设计重采样患者；若只关心当前固定机构中的新患者，则最外层目标不同，不一定需要把机构视作随机总体。层级结构本身不能代替目标定义。

![重采样要保留对象内部的相关结构](images/03-cluster-resampling.svg)

左图是一张相关系数矩阵，不是九个独立患者。设三位患者各有三次观测，$`Y_{gi}=\mu+U_g+\epsilon_{gi}`$；不同患者的 $`U_g`$ 独立、方差为 4，所有 $`\epsilon_{gi}`$ 相互独立且与患者效应独立、方差为 1。因此单次观测方差为 5，同患者两次观测协方差为 4，相关系数为 $`\rho=\frac45=0.8`$。矩阵对角为 1，同一三乘三块内的非对角为 0.8，块间为零。

右图比较同一个总体均值的方差。九项的对角贡献为 $`9\cdot5=45`$；三个患者块各有六个有序非对角项，总协方差贡献 $`3\cdot6\cdot4=72`$。于是 $`\operatorname{Var}(\overline Y)=\frac{45+72}{9^2}=\frac{13}{9}`$。误把九行都当独立会删去全部协方差，得到 $`\frac59`$，把标准误缩小为正确值的 $`\sqrt{\frac5{13}}`$。这个精确算例说明“行数增加”与“独立信息增加”之间缺少哪一项。

在这个平衡随机截距模型中，方差膨胀因子也可写成 $`1+(m-1)\rho=2.6`$，对应的方差等效独立数量为 $`\frac9{2.6}=\frac{45}{13}`$，约 3.46。这个数只是指定相关模型下对均值方差的换算，不是所有指标都可套用的通用样本量。簇大小不等、负相关、非线性指标和多层相关都需要重新推导；有关簇内相关与推断单位的系统讨论见 [Cameron 与 Miller 原论文](https://doi.org/10.3368/jhr.50.2.317)。

底部给出相应的抽样身份：若以患者作为独立推广单位，一次簇自助抽样可以抽到 P2、P2、P1，每次携带患者全部记录，并对两个待比较模型使用同一组身份。它保留了患者内部结构，却不凭空制造更多独立患者；这里只有三个簇，不能由方差算式或一个 bootstrap 接口宣称已得到可靠的名义 95% 区间。若还需要推广到新机构、重新训练模型或患者内部新观测，应分别说明随机层，而不是把这些来源混进同一条阴影。

<a id="plot-3-detail-40"></a>

### 10.3 稳健统计不能成为隐藏失败的工具

均值对极端值敏感，中位数或截尾均值有时更能描述典型运行。但改变中心也改变了研究对象。一个方法可能典型表现很好，却偶尔灾难性失败；只报告中位数会忽略部署风险。可以同时给出中位数、分位数和失败率，形成更完整描述。

截尾比例应预先指定，并解释为何符合任务成本。如果观察到不利样本后才决定截掉最差部分，图形会把真实风险删去。对于耗时实验，超时和失败通常是有意义事件，不能因为没有有限数值就直接从箱线图中消失。应以单独符号或失败率面板明确表达。

稳健汇总的区间也要按该统计量计算。均值标准误不能直接附在中位数上，正态均值区间也不自动适用于分位数。绘图函数只知道中心与长度，不知道统计意义，因此责任仍在汇总层。先计算可解释的统计结果，再选择图元，是本章贯穿始终的顺序。

<a id="plot-3-detail-41"></a>

### 10.4 小样本时表达未知比假装精确更有价值

当只有两三次独立运行，任何分布形状估计都非常有限。小提琴图的平滑轮廓可能让人误以为观察到了稳定多峰，密集抖动点也可能把少量样本装饰成大样本。应直接展示原始点与次数，必要时省略缺乏根据的形状估计。

增加训练回合不等于增加独立运行，增加同一患者图像也不等于增加患者数。预算不足时可以明确报告探索性结果，把后续独立重复列为待完成工作，而不应通过改变统计单位制造虚假的样本量。图表的任务是准确表达已有证据，包括证据不足。

在高级研究中，能够指出一个区间依赖什么、哪些误差来源未被覆盖，本身就是重要能力。它让后续实验有明确方向：增加独立任务、补足小样本群体、重复训练或改善日志。无条件给出一个漂亮且狭窄的误差带，反而容易阻碍真正的问题定位。


<a id="plot-3-detail-42"></a>

### 10.5 分层目标与总体改善的方向可能不同

假设两个任务来源的难度不同，模型乙在每个来源内部都比甲好，但两模型评估时使用了不同来源比例，总体平均可能反而显示乙更差。这类聚合反转并不违反算术，而是比较对象改变了。多面板图若一幅展示总体、一幅展示分组，就应同时报告组权重，避免让读者把不同组成下的总体差解释成模型内部行为。

若目标是部署到固定来源混合，可以按同一目标权重重新加权各组结果；若来源比例本来就属于应用变化，则应分别分析组内性能和组成变化。图中可以把模型差值与组支持数并列，让读者看到总体改善来自哪里。不能只显示百分比而不显示分母，也不能为了让结论一致而悄悄改动组权重。

分组区间还需要留意同时选择。查看几十个来源后只展示差异最大的三个，会夸大局部结论的确定性。探索图可以明确标为发现候选问题；如果要声称这些组存在稳定改善，应在新数据、预先定义分组或适当多重推断下确认。图面板数量增加，并不会自动增加支持主张的独立证据。

另一个常见误解是把平均残差与平均绝对误差混成同一方向。某组正负残差抵消后均值接近零，仍可能具有很大个体误差；另一组平均残差略有偏移，却可能每个样本都很接近真实值。若关心校正系统偏差，可看残差均值；若关心实际预测幅度，则需要绝对误差或平方误差。最好让不同面板明确承担这两种问题，而不是按哪张图更好看选择指标。

<a id="plot-3-detail-43"></a>

### 10.6 图注也是可执行统计协议的文字接口

一份足够完整的图注，应使另一个人知道如何从同一记录表重建中心、区间和筛选。它不需要列出全部程序参数，但应包含随机单位、指标方向、权重、重复次数、区间类型和主要选择规则。如果任一视觉含义只能靠询问作者才能解释，图表的自足性就不够。

可以反向检验图注：隐藏绘图代码，让审阅者根据文字写出统计公式。如果对方得到另一种合理公式，例如把任务平均理解成样本平均，说明表述仍有歧义。随后再核对绘图函数是否忠实表达该公式。这样把文字、数字与图形连成同一协议，比逐个检查颜色值更能保证研究沟通质量。

这种反向复现也能帮助学习者发现自己并未完全理解的地方。若无法解释误差带为何是这个宽度、为什么某个点没有出现、某个类别按何种顺序排列，就应先返回汇总数据和统计定义，而不是继续调样式。排版优化应在语义确定之后进行，否则漂亮的布局只会让错误更难被注意。

A 在易组和难组的正确率分别为 0.9、0.4，B 为 0.8、0.3，但 A 的两组人数是 10、90，B 则是 90、10。加权后总体正确率分别为 0.45 与 0.75，因此逐组比较方向与总体方向相反。

## 11. 分层练习与完整解析

<a id="plot-3-detail-45"></a>

### 11.1 练习一：三种误差条的手算

**题目。** 四次独立运行结果为二、四、四、六，计算均值、样本标准差和均值标准误。哪一个能直接称为百分之九十五区间半宽？

**解析。** 均值为四，离差平方和为八，样本方差为 $`\frac{8}{3}`$，标准差为 $`\sqrt{\frac{8}{3}}`$，标准误为 $`\sqrt{\frac{2}{3}}`$。二者都不是自动的百分之九十五区间半宽。在独立正态模型下还需乘自由度三的相应 Student 分位数；若不满足该模型，应重新选择区间方法。单独把标准误画出来时，图注就应明确写标准误。

<a id="plot-3-detail-46"></a>

### 11.2 练习二：为什么区间重叠仍可能有配对改善

**题目。** 甲在四个任务上为十、二十、三十、四十，乙分别为十一、二十一、三十一、四十一。为什么边缘区间可能很宽，而配对差却稳定？

**解析。** 两组边缘波动主要由任务难度引起，协方差很大；配对相减后共同难度抵消，每个差值都是一。比较应在差值层面进行，而不是观察两组区间重叠。但这四个任务是否代表未来任务仍是独立问题，零观测方差不证明未来差异绝无变化，也不允许忽略任务选择和测量精度。

<a id="plot-3-detail-47"></a>

### 11.3 练习三：不对称区间的数组

**题目。** 三个中心为二、五、八，下界为一、四、六，上界为四、六、十一。写出误差数组。若按中心降序排列，应怎样同步处理？

**解析。** 向下长度为一、一、二，向上长度为二、一、三，构成两行三列数组。按中心降序时索引为二、一、零，类别名、横坐标、中心与两行误差都应使用同一索引。分别排序误差会改变它与模型的对应关系。绘图前可核对每条记录的中心减向下长度是否恢复下界，以发现错配。

<a id="plot-3-detail-48"></a>

### 11.4 练习四：对数轴上的区间

**题目。** 一个加速比中心为二，原尺度区间为一点二到三点六，纵轴使用对数尺度。应传入哪两个误差长度？能否用端点的对数差代替？

**解析。** 若中心和坐标数据仍使用原尺度，误差长度为零点八和一点六。对数轴负责把数据变换到显示坐标，不能混入另一尺度的误差长度。若想直接绘制对数比值，则中心、端点和轴标签都应一致改为对数值，并使用普通线性轴。两种表达可以等价，但不能各取一半。

<a id="plot-3-detail-49"></a>

### 11.5 练习五：重复回合不是独立运行

**题目。** 一次训练记录一百个回合的验证准确率，能否把这一百个值的标准差除以十作为独立运行均值标准误？

**解析。** 不能。它们来自同一条优化轨迹，既有时间依赖，均值还可能随回合变化，不满足独立同分布重复的解释。若研究最后检查点的训练随机性，应进行独立训练重复；若研究轨迹，应明确时间变化和相关结构。更多日志点提高过程分辨率，不自动增加独立实验数量。

<a id="plot-3-detail-50"></a>

### 11.6 练习六：预测区间为何不随样本无限变窄

**题目。** 同方差正态观测中，样本越来越多，均值区间趋窄。新观测预测区间是否也趋于零宽度？解释对应尺度。

**解析。** 均值标准误近似按 $`\frac{1}{\sqrt n}`$ 下降，但新观测仍包含本身的随机噪声。相应尺度 $`s\sqrt{1+\frac{1}{n}}`$ 随样本增长趋于总体标准差，而不是零。把均值区间当作个体预测范围，会在大样本下严重低估个体风险。回归中的均值函数区间与新样本预测区间也有同样区别。

<a id="plot-3-detail-51"></a>

### 11.7 练习七：共享轴与局部放大

**题目。** 两模型残差标准差约为一和十，分别自动缩放后图形看起来同样分散。怎样组织图既公平比较又保留小误差模型的细节？

**解析。** 先提供共享纵轴的对照，明确展示量级差异；再为小误差模型给一个标注范围的局部图或补充面板。局部面板应注明尺度改变，不能让读者拿两张图的视觉高度直接比较。保留相同残差定义、单位和样本范围，否则统一坐标也无法修复口径差别。

<a id="plot-3-detail-52"></a>

### 11.8 练习八：分箱最右端点的丢失

**题目。** 采用左闭右开分箱，最后边界恰好等于最大预测值，为什么最大值可能没有入箱？应检查什么不变量？

**解析。** 半开规则排除了右端点，若没有对最后一个箱作右闭处理或显式调整索引，最大值会落到箱外。应检查所有有效样本恰好分配一次，箱计数和等于有效样本总数，同时没有负索引或越界索引。端点规则应明确，而不是用删除最大样本来让程序通过。

<a id="plot-3-detail-53"></a>

### 11.9 练习九：小箱区间与缺失

**题目。** 一个箱只有一个样本，可以把样本标准差设为零并画零宽均值区间吗？没有样本的箱是否可以画均值零？

**解析。** 都不应这样做。单样本无法通过通常自由度为一以上的样本方差公式估计离散，零宽条会暗示没有不确定性；空箱均值未定义，画零会伪造观测。可以显示计数并省略区间或用明确缺失标记，必要时合并箱，但合并规则也应说明并检查是否改变研究问题。

<a id="plot-3-detail-54"></a>

### 11.10 练习十：总体与任务等权

**题目。** 两任务分别有十和九十个样本，准确率分别为百分之百与百分之五十。任务等权和样本等权准确率各是多少？图注应怎样写？

**解析。** 任务等权为百分之七十五；样本等权为 $`\frac{(10+45)}{100}=55\%`$。前者回答随机任务平均表现，后者回答当前语料随机样本表现。应明确写宏观任务平均或汇总样本准确率，并让区间也按同一目标构造。不能把中心按任务等权、误差按所有样本独立汇总，混成一个没有明确对象的统计量。

<a id="plot-3-detail-55"></a>

### 11.11 练习十一：点态带与同时结论

**题目。** 一百个训练检查点各有百分之九十五点态区间，能否宣称整条曲线有百分之九十五同时覆盖？如何使主要结论更明确？

**解析。** 不能，多个位置的联合覆盖事件不同于单点覆盖。可以为整条曲线使用适当同时带，也可以预先指定一个预算点或曲线汇总量作为主要比较，曲线仅用于诊断。选择后者时仍应说明检查点如何选定，避免看过结果后才把最大优势位置称为主要终点。

<a id="plot-3-detail-56"></a>

### 11.12 练习十二：失败运行的生存偏差

**题目。** 十次训练中五次在后期发散，仅对剩余五次求后期均值，曲线显示明显改善。为什么这一结论不完整，应补什么信息？

**解析。** 后期均值描述的是存活运行的条件表现，失败可能与难度或优化状态有关，不能代表十次尝试的整体可靠性。应保留各时间可用运行数、失败原因与最终失败率，并预先定义失败如何进入主要指标。若应用只允许一次训练，偶发发散本身就是重要风险，不应静默删除。

<a id="plot-3-detail-57"></a>

### 11.13 练习十三：残差平均为零仍有结构

**题目。** 带截距最小二乘在训练集平均残差为零，能否据此证明模型在所有输入范围无偏？怎样继续诊断？

**解析。** 不能，这是训练正规方程的约束。不同区域可以正负偏差抵消，还可能存在非线性与异方差。应在独立数据上画残差对输入或预测值、按预先定义范围统计局部均值与计数，并考虑分组与时间。整体零均值只约束一个汇总数，不约束条件均值函数处处为零。

<a id="plot-3-detail-58"></a>

### 11.14 练习十四：图像像素与字号

**题目。** 一幅宽十英寸、十点字体的图缩到报告五英寸宽，字体视觉大小约变成多少？把导出分辨率翻倍是否能解决字号太小？

**解析。** 按比例缩放后约相当于五点字体，通常过小。提高分辨率能增加像素细节，却不会改变最终物理尺寸下文字占比。应按最终五英寸宽度重新安排面板、字号和线宽，必要时拆图。不能用很高的像素数替代阅读尺寸设计。

<a id="plot-3-detail-59"></a>

### 11.15 练习十五：加权有效样本量的边界

**题目。** 两个固定权重为一与九，在独立同方差模型下，形式有效样本量是多少？为什么不能把它直接当作复杂抽样的通用独立样本数？

**解析。** 结果为 $`\frac{(1+9)^2}{(1^2+9^2)}=\frac{100}{82}`$，约一点二二，说明权重集中降低均值的信息分散程度。推导依赖固定权重、独立与同方差；复杂抽样有分层、聚类和包含概率结构，估计权重本身也可能随机。需要相应方差公式，不能仅替换根号内数字。

<a id="plot-3-detail-60"></a>

### 11.16 练习十六：从异常图形设计对照

**题目。** 残差对预测值呈弧线，提出两个可能原因，并设计一个能够区分解释的下一步实验。

**解析。** 可能是均值模型缺少非线性，也可能是目标截断或采样机制。可以在相同独立测试集上比较线性与预先定义的非线性模型，同时检查原始标签是否存在边界截断，并按采样来源分层。若换模型后曲线消失而计数与采样保持一致，会支持均值失配解释；图形本身不能单独完成归因。



**延伸算例：点态覆盖不能相乘成整曲线保证。** 若二十个预先固定位置的区间各有百分之九十五覆盖，且这些覆盖事件额外满足相互独立，则全部同时覆盖的概率为 $`0.95^{20}\approx0.358486`$。因此“每个位置都是百分之九十五”并不能推出“整条曲线有百分之九十五”。这里的独立条件只用于计算这个反例；一般曲线上的区间往往相关，不能不经分析就直接相乘。若每位置错误率控制为 $`\frac{0.05}{20}=0.0025`$，由并集界可得到同时覆盖至少百分之九十五，且不要求独立；代价通常是更宽区间。位置若由观察数据后选择，或展示连续无限位置，仍需处理选择或函数空间问题，不能直接照搬有限网格的结论。
