## 1. 训练曲线的第一原则：先定义度量

<a id="plot-2-detail-2"></a>

### 1.1 同名 loss 未必是同一个量

训练日志中的 loss 可能是每样本平均、每有效 token 平均、每批总和、多个任务加权和，或额外包含正则化的优化目标。只要这些定义不同，把曲线放到同一坐标轴上就不自动构成公平比较。例如一个模型记录数据负对数似然，另一个记录负对数似然加参数惩罚，即使两个字段都叫 loss，它们的差值也不能直接解释为预测质量差值。应先写清公式，再决定哪些曲线适合共图。

归约还涉及损失的单位。分类交叉熵以自然对数计算时可以称为每样本多少 nat；序列模型则常以每有效预测 token 为分母。回归平方误差的单位是目标单位的平方，平均绝对误差保持原单位。把原值从米换成厘米，平方误差会扩大一万倍，但模型的实际几何误差没有因此恶化。跨数据集或任务比较时，不能把数字大小当作脱离单位的绝对优劣。

训练模式与评估模式也不同。训练可能启用 Dropout、随机增强和混合样本，评估可能使用固定预处理；训练日志还可能包含正则项，而验证日志只计算数据项。因此验证损失低于训练损失并不必然意味着数据泄漏。合理诊断应另行计算可比较的数据损失，核对模式、样本难度、增强与归约，再讨论过拟合，而不是仅凭两条曲线的高低下结论。

<a id="plot-2-detail-3"></a>

### 1.2 分子分母比批均值更基础

设第 $`b`$ 批有效样本数或有效 token 数为 $`n_b`$，损失总和为 $`S_b`$，批均值为 $`m_b=\frac{S_b}{n_b}`$。整轮目标若是每有效单位平均，则应计算

$$
L=\frac{\sum_b S_b}{\sum_b n_b}
 =\frac{\sum_b n_bm_b}{\sum_b n_b}.
$$

直接平均批均值等于给每批相同权重，只有批大小相同或特殊数值巧合时才与上式一致。最后一个小批、不同序列长度和动态批处理都使这个问题频繁出现。最稳妥的日志设计是保存可加的分子与分母，等到明确汇总区间后再相除。

例如第一批一百个样本、平均损失零点二，第二批十个样本、平均损失一点二。等批平均得到零点七；按样本平均得到三十二除以一百一十，约零点二九一。两者不是精度误差，而是两个不同的统计量。若按 epoch 绘图，曲线中的每个点就已经包含这个选择。画图程序不会根据批大小自动纠正记录语义，必须在聚合阶段明确处理。

权重更复杂时，分母未必是样本数。类别加权损失可能按权重总和归约，也可能仍按样本数归约；掩码可能只作用于某些目标；多任务损失可能没有统一自然分母。应依据真正的损失函数定义保存统计量，而不是把所有数值统一套用“乘批大小再求和”。若只有批均值却不知道内部归约，就无法可靠还原总体指标，图注应承认这一限制。

<a id="plot-2-detail-4"></a>

### 1.3 准确率、宏平均与数据分布变化

准确率可以由正确预测数除以总预测数得到，具有可加的分子分母；F1、AUC 和某些排序指标却不能简单通过批次指标平均得到全局值。宏平均强调类别或组别等权，微平均强调个体观测等权。类别比例变化时，总体准确率可能提高，而每一类的表现都没有改善，原因只是测试集变得更容易。这时曲线反映的既有模型变化，也有评估分布变化。

若验证样本随训练阶段改变，应记录样本集合或抽样协议。固定集合便于比较同一批对象上的变化，但反复据此选模型也会带来验证集选择适应；独立刷新集合能减少某些固定样本偶然性，却引入额外抽样噪声。两者都有用途，不能仅根据曲线更平滑就判断哪一种更科学。正式报告应说明验证集是否固定、是否参与超参数选择，以及最终测试是否独立。

当任务关心少数群体或罕见事件时，整体均值可能掩盖关键失败。可以补充分组曲线、尾部分位数或达到阈值的比例，但分组规则也要提前明确。若先看结果再挑最差组，图上差异会受到选择过程影响。可视化适合发现问题，后续确认应在独立数据或明确分析协议下进行。观察到模式与确认机制是不同证据层级。

## 2. 横轴预算、采样时刻与对齐

<a id="plot-2-detail-6"></a>

### 2.1 epoch、step、样本与墙钟时间

epoch 表示遍历某个数据定义的进度，step 表示更新次数，样本或 token 计数表示数据处理量，墙钟时间表示真实耗时。它们回答的效率问题不同。相同 epoch 下，大数据实验可能处理更多记录；相同 step 下，大批实验可能使用更多样本；相同 token 下，硬件、模型规模和实现优化又会改变时间。不存在一个总能代表公平的横轴，应该先明确所比较的资源。

例如 A 每轮更新一百次、B 每轮更新两百次，第十轮对比不是相同更新预算。如果关注样本利用率，应按已处理样本数对齐；如果关注实际部署训练成本，应考虑固定硬件协议下的时间或计算量。时间计量还需说明是否包含数据加载、验证、检查点和编译预热。忽略昂贵验证成本会让频繁评估的方案看起来与少评估方案同样便宜。

梯度累积进一步打破“一个批等于一次更新”的直觉。多个微批共同产生一次参数更新，日志若每微批记录 loss、每更新记录学习率，两个序列的索引含义就不同。横轴应来自真实计数器，而不是画图时简单用行号代替。恢复训练后计数器是否延续、是否重复记录同一步，也需要在读取日志时核对。

<a id="plot-2-detail-7"></a>

### 2.2 曲线采样不规则时怎样比较

不同实验可能在不同预算位置评估。直接把第十条日志互相比较，实际上比较的是记录顺序而不是相同预算。可以限制到共同观测位置，或采用明确插值规则对齐到共同网格。线性插值是显示与估计选择，并不产生新的真实实验；若真实过程存在突变、学习率跳变或失败恢复，跨越这些区间插值可能掩盖重要事件。

插值还需要尊重指标性质。连续损失在短区间内线性近似有时合理，最佳历史值则是阶梯过程，采用保持前值可能更符合定义。类别状态、失败标记和检查点身份不适合随意线性插值。任何方式都不应在运行终止后无说明地外推。图上延伸到更大预算的平坦尾巴，容易被读者理解为继续训练后的实际稳定表现。

若展示平均曲线，要先在每次运行内部完成合法对齐，再跨运行聚合；不能把所有日志点混在一起按横轴附近平均，因为评估更频繁的运行会获得更多权重。对齐网格越密，不会增加独立运行数量。几百个插值点仍来自原来那几次训练，不能据此声称估计精度等同于几百次实验。

<a id="plot-2-detail-8"></a>

### 2.3 提前停止、失败与幸存者偏差

运行在不同时间终止时，某个预算下可用曲线集合可能随预算变化。如果表现差的运行更容易失败或被提前停止，只对剩余运行求均值会让后期曲线显得越来越好，即使没有任何单次运行继续改善。这是样本组成变化，而不是纯粹学习趋势。图上应显示每个位置的可用运行数，并说明缺失与终止原因。

可以采用所有运行共同覆盖的预算区间，保持比较集合固定；也可以继续显示后续区间，但把可用数量变化作为图的一部分。若问题本身就是“在规定失败处理策略下的整体性能”，则需要给失败明确评价规则，例如失败率与条件性能分别报告。不能默认删除失败运行，也不能无条件把失败填为某个任意好坏值；这两种处理都改变目标量。

最佳检查点选择也属于协议。每次运行取验证最优点，然后报告同一验证集上的数值，会偏向乐观，且评估次数更多的实验拥有更多挑选机会。图中可以展示历史最佳曲线帮助理解搜索过程，但应标明它是选择后的序列，并使用独立测试评价最终模型。原始评估曲线与历史最佳曲线承担不同任务，不能只保留后者而掩盖训练回退。

### 2.4 独立实验：从日志分子分母重建训练度量

以下实验构造两种不同批量安排，它们包含完全相同的样本损失。正确汇总不依赖如何切批，简单平均批均值则可能变化。后半部分绘制训练步数与已处理样本数两种横轴，说明相同日志可以回答不同效率问题。

```python
from io import BytesIO
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

losses = np.r_[np.full(100, 0.2), np.full(10, 1.2)]
partitions = [np.array([0, 100, 110]), np.array([0, 55, 110])]
correct, batch_average = [], []
for boundaries in partitions:
    chunks = [losses[a:b] for a, b in zip(boundaries[:-1], boundaries[1:])]
    numerator = np.array([c.sum() for c in chunks])
    denominator = np.array([len(c) for c in chunks])
    correct.append(numerator.sum() / denominator.sum())
    batch_average.append(np.mean(numerator / denominator))
assert np.allclose(correct, losses.mean())
assert not np.isclose(batch_average[0], batch_average[1])
print("sample-weighted:", correct, "batch-weighted:", batch_average)
steps = np.arange(1, 31)
a = 0.2 + np.exp(-steps / 8)
b = 0.2 + np.exp(-steps / 10)
fig, axes = plt.subplots(1, 2, figsize=(8, 3.2), layout="constrained")
for ax, x_a, x_b, label in [
    (axes[0], steps, steps, "Optimizer updates"),
    (axes[1], steps * 32, steps * 128, "Processed examples")
]:
    ax.plot(x_a, a, label="A, batch=32")
    ax.plot(x_b, b, label="B, batch=128")
    ax.set(xlabel=label, ylabel="Mean loss")
    ax.legend()
fig.canvas.draw()
buf = BytesIO()
fig.savefig(buf, format="png", dpi=140)
print("png bytes:", len(buf.getvalue()))
plt.close(fig)
```

这里两种批切分的正确总体损失相同，而错误的等批平均不同。右侧曲线并不宣布某个模型一定更优，只显示横轴定义确实改变了效率问题。真实实验还需核对吞吐、硬件和优化设置。可以把这个例子看成日志读取的单元检查：如果同一批观测仅因切批方式改变就产生不同总体平均，说明聚合定义值得重新审查。

### 图解：相同轮数不代表相同计算预算

![相同轮数不代表相同计算预算](images/02-advanced.svg)

假设两个训练方案每轮分别耗时 2 和 5 分钟，那么同为四轮时，计算时间已相差 2.5 倍。若研究问题是固定等待时间内能得到什么模型，按轮数对齐就不能替代按墙钟时间对齐。

这是恒定轮时的教学模型，现实中验证、编译、数据读取和预热也占预算。比较前必须声明时间边界；图没有据此断言某个方案精度更高。

## 3. 平滑是一个有偏显示算子

<a id="plot-2-detail-11"></a>

### 3.1 移动平均的窗口与延迟

长度为 $`w`$ 的后向移动平均可以写成 $`\widetilde y_t=w^{-1}\sum_{j=0}^{w-1}y_{t-j}`$。它把多个时刻混合，通常减少高频波动，但会把突变摊开，并引入时间响应延迟。若原始趋势为线性 $`y_t=a+bt`$，在完整窗口位置平滑值等于当前值减去 $`\frac{b(w-1)}{2}`$，因此趋势上升时滞后、下降时偏高。这个差异来自算子的定义，而不是训练机制。

居中窗口把前后观测一起平均，能减少视觉位移，却使用了未来信息。用于离线展示完全可以，但不能把它解释为训练当时可得到的在线诊断。窗口还可能跨越学习率切换、数据切换和失败恢复，使事件在图上看起来提前发生。应给出窗口长度及其单位，并在关键事件附近保留原始点或单独标注。

边界处理也改变结果。完整窗口会缩短可显示范围；缩小窗口会使开头的噪声水平与中间不同；补零会把边缘值向零拉动；镜像填充则引入人为延拓。默认库函数可能采用其中某一种，但图注只写“平滑”不足以说明。若比较不同方案，应采用相同规则，并检查平滑前的失败、尖峰和反转是否仍可发现。

<a id="plot-2-detail-12"></a>

### 3.2 指数移动平均的权重与不规则时间

指数移动平均可写成 $`s_t=\alpha y_t+(1-\alpha)s_{t-1}`$，其中 $`0<\alpha\le1`$。展开后可见历史权重按几何速度衰减，越小的 α 产生越长记忆。初始化若取零，早期会产生向零偏移；用第一个观测初始化则避免这一特殊偏移，但仍存在短历史阶段。是否进行偏差修正应与所采用的递推定义一致，不能把不同软件中同名参数假定为完全一样。

当采样间隔不规则时，按日志条数衰减与按实际预算衰减不同。评估频繁的区间会在同样预算长度内更新更多次，导致有效平滑强度改变。若希望按预算差 $`\Delta t`$ 控制记忆，可设置衰减因子为 $`\exp(-\frac{\Delta t}{\tau})`$，其中 τ 是预算时间常数。这样同样跨度拥有同样衰减，但它仍是显示选择，不提供额外独立观测。

平滑参数不应根据谁的曲线更好看来分别设置。A 使用长窗口、B 使用短窗口，就可能让 A 看起来更稳定。若科学问题确实需要不同采样频率下等价的物理平滑，应该统一的是时间尺度而非条数，并把转换规则说明清楚。比较视觉稳定性之前，还要区分批内噪声、单次训练的时间波动和跨独立运行的差异，它们不是同一个方差对象。

<a id="plot-2-detail-13"></a>

### 3.3 原始曲线、平滑曲线与聚合顺序

若平滑算子是固定线性的，且所有运行使用相同完整网格与权重，那么先平均再平滑与先平滑再平均可以交换。但一旦窗口随缺失情况变化、边界采用不同有效长度，或者使用中位数等非线性汇总，交换通常不成立。误差带更不能因为均值可以交换就随意交换计算顺序；带宽取决于运行之间在每个位置的联合变化。

适合多数诊断图的做法是淡色展示每次运行的原始曲线，用较明显线条展示按统一规则得到的趋势，并在图注说明汇总顺序。原始曲线过多时，可以用独立面板或抽取固定代表运行，但不能只留下最漂亮的一条。若不确定性带来自平滑后的运行值，应明确它描述的是平滑统计量的运行差异，而不是原始瞬时值的波动。

平滑造成的相关性也要记住。相邻移动平均共享大量原始点，所以它们高度相关；不能把平滑后曲线上的每一个点当作独立重复来估计均值标准误。时间序列的有效信息量取决于依赖结构，不等于图上像素点数量。图形让曲线看起来规律，不会自动改变实验设计提供的证据量。

<a id="plot-2-detail-14"></a>

### 3.4 独立实验：尖峰、移动平均和时间延迟

```python
from io import BytesIO
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

rng = np.random.default_rng(12)
t = np.arange(120)
raw = 0.25 + np.exp(-t / 30) + rng.normal(0, 0.035, len(t))
raw[64] += 0.8
window = 11
moving = np.convolve(raw, np.ones(window) / window, mode="valid")
alpha = 0.15
ema = np.empty_like(raw)
ema[0] = raw[0]
for i in range(1, len(raw)):
    ema[i] = alpha * raw[i] + (1 - alpha) * ema[i - 1]
assert len(moving) == len(raw) - window + 1
assert np.isclose(ema[1], alpha * raw[1] + (1 - alpha) * raw[0])
fig, ax = plt.subplots(figsize=(7.3, 3.5), layout="constrained")
ax.plot(t, raw, color="0.7", linewidth=0.9, label="Raw")
ax.plot(t[window - 1:], moving, label="Trailing mean, w=11")
ax.plot(t, ema, label="EMA, alpha=0.15")
ax.axvline(64, color="black", linestyle=":", label="Injected spike")
ax.set(xlabel="Evaluation index", ylabel="Mean loss", title="Smoothing changes visibility")
ax.legend()
fig.canvas.draw()
buf = BytesIO()
fig.savefig(buf, format="png", dpi=140)
print("raw spike:", raw[64], "EMA at spike:", ema[64])
plt.close(fig)
```

尖峰在平滑后仍可能有影响，但峰高降低、影响扩散到后续多个位置。若只展示平滑线，读者可能低估一次严重异常；若只展示原始线，又可能难以识别长期趋势。两者并存能保留不同时间尺度的信息。这里横轴是评估索引；换成不规则实际时间后，窗口十一条记录不再等于固定时间长度，应重新选择所需的平滑单位。

## 4. 分布比较：先确定数量、形状还是尾部

<a id="plot-2-detail-16"></a>

### 4.1 不同样本量的频数不能直接代表比例

一组一百个样本，另一组一万个样本，即使来自同一分布，后者的频数柱通常也高约一百倍。这对“事件总量是多少”是正确信息，对“相对分布是否改变”却容易误导。频数、每组归一化概率和联合归一化概率分别回答不同问题。每组密度图抹去了组间规模差异，因此应保留样本数；联合归一化又会让大组贡献更多质量，不能当作每组内部形状比较。

比较误差分布时，还应决定是否按样本或按用户等权。若某个用户产生大量请求，逐请求分布代表系统流量体验，逐用户平均后再看分布则代表用户层面的差异。两者都可能有实际意义，不能用“所有数据都用到了”证明权重合理。图注需要交代观察单位与抽样来源，尤其在日志、医疗、推荐和时间序列数据中，同一个实体常有许多相关记录。

分布范围也不应只按主体决定。延迟模型的大多数请求可能都很快，但少量极端尾部决定服务体验。主体直方图与尾部超越概率图可以互补：前者展示典型形状，后者展示超过阈值的比例。若只截取中心百分之九十九，图会清楚很多，却可能恰好删除真正关心的失败。应把截取作为明确显示选择，并另外报告被截掉的质量和极端值。

<a id="sec-2-1"></a>

<a id="plot-2-detail-17"></a>

### 4.2 共同分箱、密度单位与范围外质量

两组直方图比较应使用相同边界，这让每个柱子对应同一个区间事件。共同边界可以由联合范围或事先约定的阈值生成，但若使用联合数据选择边界，也应记录这一规则。不同组分别自动分箱时，不仅宽度可能不同，起点也可能不同；柱子高度的差异就混合了数据结构和分箱结构。透明叠加不能解决这个语义问题。

密度高度乘以箱宽才得到概率。横轴从秒换成毫秒，箱宽扩大一千倍，密度高度相应缩小一千倍，而区间概率不变。因此密度纵轴应带倒数单位，例如每秒，而不能只写没有单位的“概率”。对于离散整数变量，概率质量图可能比连续密度更直接；若仍画直方图，应选择与离散取值相容的边界，避免一个整数点被视觉上分摊到不明确的范围。

图像范围不等于归一化总体。先删除极端值再作密度图，与在全体上计算分布后仅调整显示范围，得到的纵向归一化可能不同。前者改变被归一化样本，后者只隐藏部分图形。正式比较中应记录清洗前后数量、范围外数量和缺失值数量，使读者能分辨某组尾部确实减少，还是只是更多观测被过滤。数据清洗、分析筛选和显示裁剪应分别命名。

<a id="plot-2-detail-18"></a>

### 4.3 经验分布函数与超越概率

经验分布函数定义为 $`F_n(x)=n^{-1}\sum_{i=1}^n\mathbf1\{X_i\le x\}`$。它在观测值处跳跃，不需要选择分箱或带宽，可以直接读取“不超过阈值的比例”。同一数据的补函数 $`1-F_n(x)`$ 表示严格超过阈值的比例，适合延迟和风险尾部问题。若需要大于等于阈值，遇到重复值时两者不同，必须保持事件定义一致。

两条经验分布曲线不交叉时，可以在样本层面讨论一种整体排序方向；若误差越小越好，更多概率集中在较小数值的一组，其分布函数通常更高。但有限样本排序不自动证明总体随机占优，还需要不确定性分析与抽样假设。曲线交叉则提示“谁更好”依赖阈值或损失函数，单个均值无法概括所有取舍。

经验分布也有局限。有限样本无法观察样本最大值之外的尾部，因此最后跳到一并不证明更大值在总体中不可能。尾部只有一两个观测时，微小计数变化会造成很大相对差异。对数纵轴能显示小超越概率，但零的估计没有有限对数位置，不能任意替换一个很小数后当作真实尾部概率。可以明确标记观测分辨率，保留计数，并说明未观测事件的限制。

<a id="plot-2-detail-19"></a>

### 4.4 核密度估计、带宽与边界

核密度估计把每个观测替换成一个平滑核再求平均，一维形式为 $`\widehat f_h(x)=(nh)^{-1}\sum_i K(\frac{(x-X_i)}{h})`$。带宽 $`h`$ 决定平滑尺度。过小会把随机样本位置画成许多尖峰，过大则把真实多峰合并。默认规则提供起点，不保证适合所有尾部、混合分布和样本规模。比较组间结构时，应检查结论对合理带宽变化是否稳定。

高斯核在整个实数轴上都有正密度。若变量只能为正，例如时延，普通高斯核会把一部分质量平滑到负值区域。这不是观测到负时延，而是估计器的边界偏差。可以采用边界修正、适当变换或直接使用经验分布。对数变换后估计再变回原尺度时，需要包含雅可比因子：若 $`Z=\log X`$，则 $`f_X(x)=\frac{f_Z(\log x)}{x}`$。只把横轴刻度改回去却不调整密度，会改变面积解释。

离散变量、极少样本和所有值相同的情况也不适合机械套用连续核估计。某些实现需要非奇异协方差，退化数据会触发错误。用很小随机噪声扰动数据虽然可能让函数运行，却增加了并不存在的测量变化。应先选择与数据生成方式匹配的表示，例如离散概率质量、原始点或带明确测量分辨率的图形，再考虑是否有必要平滑。

<a id="plot-2-detail-20"></a>

### 4.5 分位数、箱线图与异质性

均值相近的两组可能拥有完全不同的尾部；中位数相同的两组也可能一个集中、一个极分散。箱线图适合压缩多个组的中位数和四分位区间，但不保留完整形状。小提琴图增加密度轮廓，却继承带宽与边界选择。把这两种图叠加并不自动获得完整真相，尤其样本量很小时，平滑轮廓可能比证据本身更细腻。

可以把摘要图与透明个体点结合，但重复观测要标明单位。若每个模型有五次训练、每次测试一千个样本，把五千个误差点全画在一起，并不能让训练随机性样本量变成五千。需要根据问题拆分层次：样本误差分布描述固定模型对不同测试对象的表现，运行级指标分布描述训练过程的随机性。混合层次后，图上看起来大量数据，实际独立信息可能仍然很少。

分组后还可能出现总体与组内方向不同的现象。例如模型 A 在每种难度组内都稍好，但它的评估样本中困难组占比更高，于是总体均值更差。可视化应帮助识别这种组成效应，使用共同分组协议和明确权重，而不是只选有利的聚合方式。最终采用总体流量权重还是组等权，应由部署目标和研究问题决定。

<a id="plot-2-detail-21"></a>

### 4.6 独立实验：直方图、经验分布与带宽敏感性

```python
from io import BytesIO
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from scipy.stats import gaussian_kde

rng = np.random.default_rng(21)
a = np.r_[rng.normal(-1.0, 0.35, 120), rng.normal(1.0, 0.35, 120)]
b = rng.normal(0, 1.05, 600)
edges = np.linspace(-4, 4, 33)
grid = np.linspace(-4, 4, 500)
fig, axes = plt.subplots(1, 3, figsize=(10.6, 3.3), layout="constrained")
for sample, label, color in [(a, "A (n=240)", "tab:blue"), (b, "B (n=600)", "tab:orange")]:
    heights, _ = np.histogram(sample, bins=edges, density=True)
    assert np.isclose(np.sum(heights * np.diff(edges)), 1)
    axes[0].stairs(heights, edges, label=label, color=color)
    axes[1].ecdf(sample, label=label, color=color)
for factor in [0.15, 0.45, 0.9]:
    kde = gaussian_kde(a, bw_method=factor)
    axes[2].plot(grid, kde(grid), label=f"factor={factor}")
axes[0].set(xlabel="Value", ylabel="Density", title="Shared bins")
axes[1].set(xlabel="Value", ylabel="Fraction <= x", title="Empirical CDF")
axes[2].set(xlabel="Value", ylabel="Density", title="A: bandwidth sensitivity")
for ax in axes:
    ax.legend(fontsize=8)
fig.canvas.draw()
buf = BytesIO()
fig.savefig(buf, format="png", dpi=140)
print("A mean / median:", a.mean(), np.median(a))
print("B mean / median:", b.mean(), np.median(b))
print("A fraction above 1.5:", np.mean(a > 1.5))
plt.close(fig)
```

这里带宽参数是 SciPy 对样本协方差尺度使用的因子，不应直接当作原单位的一维带宽数值。两组均值都可能接近零，但 A 的双峰结构与 B 的单峰结构不同；过强平滑会让 A 的双峰难以识别。经验分布函数不需要带宽，却以阶梯形式表达有限样本。三种表示互相检查，比仅凭某一幅最平滑的密度图判断分布更稳妥。

## 5. 区间代表什么：运行、样本与独立单位

<a id="plot-2-detail-23"></a>

### 5.1 标准差带与均值置信区间

假设在某个固定预算下，有 $`R`$ 次独立同协议训练得到指标 $`Y_1,\ldots,Y_R`$。样本标准差描述运行结果的离散程度；均值标准误在独立、同分布、有限方差等条件下可以估计为 $`\frac{s}{\sqrt R}`$。两者回答不同问题。增加运行次数通常会提高均值估计精度，但不会因此使单次训练自身更稳定。画带时应把“均值加减一次运行标准差”与“均值的置信区间”明确区分。

置信区间还依赖构造方法与假设。少量运行下使用固定的一点九六倍标准误并不自动具有可靠覆盖；正态近似、t 区间和 bootstrap 都需要考虑样本量及分布特征。数据明显偏态、重尾或失败质量集中在边界时，普通对称带可能超出指标合法范围。不能仅为了图形美观把超出部分裁掉后仍保持原来的概率解释。

分位数带则描述运行分布的某个中心范围，例如第十到第九十分位，但有限运行的分位数估计也可能很不稳定。只有五次运行却画平滑的百分位带，容易给读者过高精确感。可以直接展示每次运行曲线，并以均值或中位数作为摘要。图形的细腻程度不应超过数据提供的信息分辨率。

<a id="plot-2-detail-24"></a>

### 5.2 重复测试样本不能替代重复训练

固定一个模型，在测试样本上 bootstrap，主要反映测试样本抽样层面的不确定性；固定测试集，重复训练不同随机种子，主要反映训练过程随机性。若希望同时推广到新训练运行与新测试样本，需要匹配两层变异的设计。简单把所有“运行乘样本”的误差当作独立观测，会忽略同一模型共享参数与同一测试样本共享难度，往往夸大有效样本量。

独立单位还可能是患者、用户、文档、会话或站点。一个患者的一百个图像切片通常不是一百个独立患者；一个会话的一千条点击也不是一千个独立会话。重采样与区间构造应在适当簇层次进行，或者使用能表达依赖的模型。图上把每条记录画成点完全合法，但解释不确定性时不能因此把每个点都视为独立实验。

交叉验证折也并非天然独立重复，因为训练数据高度重叠，测试任务与划分过程共同影响结果。把折间标准差直接除以折数平方根，可能缺乏所需独立性。可以报告折间离散程度作为描述，但若要给精确推断，应明确目标与方法。可视化只负责忠实表达已选择的统计对象，不会自动修复实验设计中的依赖。

<a id="sec-6"></a>

<a id="plot-2-detail-25"></a>

### 5.3 点态区间不等于整条曲线同时覆盖

在每个预算点分别构造百分之九十五区间，通常只具有点态解释。即使每个点的覆盖都达到目标，整条真实均值曲线同时落入所有区间的概率也可能低得多。预算点之间相关会影响具体概率，但不能据此把点态区间直接称为“整条曲线百分之九十五置信带”。若研究问题需要同时声明，应采用匹配的同时推断方法，并明确预算集合。

同样，不能看见两个模型的带不重叠就机械推断显著差异，也不能看见重叠就断言没有差异。比较应直接研究同预算、适当配对下的差值，并考虑相关结构。相同随机种子或相同测试样本的配对可能降低差值方差，但配对需要实验单位真正对应，不能只按数组行号拼接。差值曲线与原始性能曲线各有作用，应围绕实际问题选择。

反复查看曲线并在最有利的时刻宣布胜利，也包含多重选择。早停、检查点筛选和预算挑选都可能让报告偏向乐观。诊断阶段可以探索这些现象，但确认结论应明确主要预算和评价协议，或使用处理序贯查看的统计方法。曲线展示得再完整，也不能自动消除选择过程带来的偏差。

<a id="plot-2-detail-26"></a>

### 5.4 独立实验：可用运行数变化的后果

下面人为让两条较差曲线在后期停止。汇总图同时展示可用运行均值与固定完整运行子集的均值；两者差异来自样本组成，不是额外模型改进。阴影明确写作可用运行间标准差，不冒充置信区间。实际研究若终止具有业务含义，还应报告失败率与终止原因。

```python
from io import BytesIO
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

rng = np.random.default_rng(30)
t = np.arange(21)
base = 0.25 + np.exp(-t / 6)
offsets = np.array([-0.06, -0.02, 0.02, 0.13, 0.20])
runs = base[None, :] + offsets[:, None] + rng.normal(0, 0.008, (5, len(t)))
runs[3, 12:] = np.nan
runs[4, 9:] = np.nan
count = np.isfinite(runs).sum(axis=0)
mean = np.nanmean(runs, axis=0)
sd = np.nanstd(runs, axis=0, ddof=1)
complete = np.isfinite(runs).all(axis=1)
fixed_mean = runs[complete].mean(axis=0)
assert count[0] == 5 and count[-1] == 3
fig, axes = plt.subplots(2, 1, sharex=True, figsize=(7.2, 4.8),
                         height_ratios=[3, 1], layout="constrained")
for row in runs:
    axes[0].plot(t, row, color="0.75", linewidth=0.8)
axes[0].plot(t, mean, color="tab:blue", label="Available-run mean")
axes[0].fill_between(t, mean - sd, mean + sd, color="tab:blue", alpha=0.18,
                     label="Available-run mean +/- SD")
axes[0].plot(t, fixed_mean, color="tab:orange", linestyle="--", label="Complete-run subset")
axes[0].set(ylabel="Mean loss", title="Changing membership changes the summary")
axes[0].legend(fontsize=8)
axes[1].step(t, count, where="post", color="black")
axes[1].set(xlabel="Budget", ylabel="Runs", yticks=[3, 4, 5], ylim=(2.7, 5.3))
fig.canvas.draw()
buf = BytesIO()
fig.savefig(buf, format="png", dpi=140)
print("run counts:", count.tolist())
plt.close(fig)
```

固定完整运行子集也不是无偏修复，因为“完整运行”本身可能是一种选择。示例用它只是揭示组成变化，不能据此把失败运行从最终结论中删除。更好的实验协议通常事先规定预算、资源和失败处理，并保留所有启动运行的状态。若缺失原因未知，图和结论应明确哪些统计量可直接识别，哪些需要额外缺失机制假设。

## 6. 导出机制：尺寸、分辨率与文件格式

<a id="plot-2-detail-28"></a>

### 6.1 英寸、points 与 dpi 的计算

栅格输出的像素宽度大致等于画布英寸宽度乘以输出 dpi。例如宽六英寸、输出一百五十 dpi，对应九百像素。字号通常以 points 表示，一 point 为七十二分之一英寸，因此十二 points 的文字在一百五十 dpi 下大约占二十五个像素的标称字号高度。实际字形边界还取决于字体和字符。这些计算帮助理解为什么增加 dpi 增加细节采样，却不改变图在相同物理尺寸下的相对布局。

如果报告只给图三英寸宽，而原图按六英寸设计，整体缩放后原来十二 points 的字只剩相当于六 points。把输出从一百五十 dpi 提高到六百 dpi，会让小字边缘更细致，但在纸面上仍然很小。应先决定最终展示宽度、面板数量与所需字号，再确定栅格分辨率。不能把高 dpi 当作所有可读性问题的万能修复。

线宽与标记也应在最终尺寸检查。太细的线可能在缩放、打印或投影后消失；过密标记可能完全覆盖线形。可以减少标记频率、用线型辅助颜色、调整透明度或拆分面板。若研究问题需要读者准确识别交叉点和尾部，优先为这些区域留空间，而不是把所有图强行压入同一宽度。

<a id="plot-2-detail-29"></a>

### 6.2 PNG、PDF、SVG 与混合输出

PNG 适合固定像素显示和网页预览；PDF 与 SVG 可以保留许多线条和文字的矢量描述，缩放时不依赖固定像素网格。但矢量并不意味着文件一定小，也不意味着所有内容都是矢量。大量散点、复杂路径和透明对象可能让文件非常大，打开与编辑都很慢；图像本身通常仍以栅格嵌入。

混合输出可以把高密度数据层栅格化，同时保留坐标轴和文字的矢量形式。例如给散点集合设置`rasterized=True`，在 PDF 中将该层渲染成图像，其他元素仍保持矢量。栅格层的细节受输出 dpi 影响；这一参数不会把矢量文字也变成同样像素尺寸。需要比较文件大小时应实际测量，而不是保证栅格化对任何图都更小，少量点时额外嵌入开销可能反而增加。

透明度与颜色在不同查看器、打印流程或后端中可能呈现差异。若结果用于出版，最好同时检查目标格式与一份常见栅格预览。矢量文件中的字体处理也影响可移植性：文本可能保留为文字或转为路径，二者对可搜索性、编辑性与文件大小有不同取舍。应根据交付场景选择，并在最终应用里确认，而不是假定扩展名已经保证一切。

<a id="plot-2-detail-30"></a>

### 6.3 tight 边界不是自动保证固定尺寸

`bbox_inches="tight"`会依据被考虑的可见对象重新裁定导出边界，常用于避免外部标签被裁切。但它也可能改变最终文件的物理尺寸和像素尺寸，所以不能一边要求严格固定宽高，一边默认 tight 裁切后仍与原始 figsize 完全相同。若需要严格版式尺寸，应先在固定画布内完成布局，再按未裁切画布导出并检查边界。

tight 也不是解决所有布局问题的替代品。两个标签互相覆盖时，扩大外边界并不会把它们分开；图例遮住数据也不是裁切问题。应先解决对象之间的几何冲突，再决定是否裁掉外部空白。某些对象是否参与布局与边界计算还受设置影响，需要实际渲染检查。把外部图例设为不参与布局虽然可能让数据区变大，却也可能造成导出遗漏。

文件格式与文件名也要一致。给`savefig`显式指定 format 时，应避免文件扩展名与内容格式不一致，尤其传入内存缓冲时更应指定格式。检查 PNG 签名、PDF 文件头和图像像素尺寸，可以发现一些交付错误，但不能证明视觉排版正确。一个完全合法的 PNG 也可能只有空白画布，或者把关键图例裁掉。

<a id="plot-2-detail-31"></a>

### 6.4 字体、中文与可访问性

设置一个中文字体名称只是在请求字体，并不保证环境中已经安装，也不保证它覆盖全部字符。缺字可能表现为方框、空白或替代字体混排。应使用字体管理器检查实际可用字体，并在包含中文、负号、数学符号和特殊单位的测试图中验证。示例代码采用拉丁标签是为了在默认环境自足运行；正式中文资料可以使用本机确认存在的字体，不需要为了作图额外下载来源不明的字体。

字体一致性还涉及数学文字。普通文本与数学表达式可能来自不同字体系统，字号和字重视觉上不完全一致。长公式放进小面板标题往往难读，可以把完整定义放在图注，图中采用简短变量名称。负号与连字符也是不同字符，某些字体只支持其中一种；修改负号配置能够改变显示，但应先理解实际缺字问题，不要盲目覆盖全局设置。

可访问性不能仅靠一种所谓安全配色。颜色之外增加线型、标记或直接标签，可以让灰度打印及不同色觉条件下仍能区分组别。相近颜色在显示器上也许清楚，投影或低质量打印后可能混在一起。应检查关键曲线之间的明度对比、线条宽度与重叠区域，并确保图注能用文字传达主要关系。颜色只是编码渠道之一，不能承担全部身份信息。

<a id="plot-2-detail-32"></a>

### 6.5 独立实验：固定尺寸、tight 裁切与混合 PDF

下例全部输出保存在内存，不会在学习目录留下图片。它读取 PNG 实际尺寸，确认未裁切输出满足英寸乘 dpi 的计算，并测量混合 PDF 的文件大小。实验不预先假定 tight 结果一定更小，因为具体边界由文字与布局共同决定。

```python
from io import BytesIO
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from PIL import Image

rng = np.random.default_rng(44)
x = rng.normal(size=12000)
y = 0.5 * x + rng.normal(size=len(x))
with plt.rc_context({"font.size": 10, "axes.titlesize": 11}):
    fig, ax = plt.subplots(figsize=(6.0, 3.6), layout="constrained")
    ax.scatter(x, y, s=3, alpha=0.22, linewidths=0, rasterized=True,
               label="12000 observations")
    ax.set(xlabel="Feature (unit)", ylabel="Response (unit)", title="Mixed vector-raster export")
    ax.legend(loc="upper left")
    fig.canvas.draw()
    png, tight_png, pdf = BytesIO(), BytesIO(), BytesIO()
    fig.savefig(png, format="png", dpi=150)
    fig.savefig(tight_png, format="png", dpi=150, bbox_inches="tight", pad_inches=0.05)
    fig.savefig(pdf, format="pdf", dpi=150)
    with Image.open(BytesIO(png.getvalue())) as im:
        original_size = im.size
    with Image.open(BytesIO(tight_png.getvalue())) as im:
        cropped_size = im.size
    assert original_size == (900, 540)
    assert png.getvalue().startswith(b"\x89PNG")
    assert pdf.getvalue().startswith(b"%PDF")
    print("fixed PNG:", original_size, "tight PNG:", cropped_size)
    print("PNG bytes:", len(png.getvalue()), "PDF bytes:", len(pdf.getvalue()))
    plt.close(fig)
```

在实际交付中，还应把 PDF 放到目标阅读器里查看文字、透明度与栅格层边界。这里的文件头断言只检查格式一致性，尺寸断言只检查画布几何。它们各自覆盖具体错误，不能替代最终尺寸下的阅读判断。把自动检查与视觉检查组合起来，才能既避免空文件等基础问题，也发现图例遮挡等结构性问题。

## 7. 从诊断图到可复核结论

<a id="plot-2-detail-34"></a>

### 7.1 一次异常应该怎样追踪

发现 loss 尖峰时，先定位对应原始记录，检查有效样本数、批组成、学习率、梯度范数和数据读取状态。尖峰可能来自真实困难样本，也可能来自分母减少、数值溢出、恢复训练后计数器重置或日志重复。只在图中删除尖峰会丢失诊断线索；只把尖峰归因于优化不稳定也可能过早。图的价值在于指出值得追踪的位置，而不是凭形状自动给出原因。

可以用共享横轴面板同时显示损失、学习率和有效数量，帮助核对时间关系。但同时变化并不证明因果，例如学习率切换与数据阶段切换可能发生在同一时刻。需要回到训练配置或控制实验区分。多条曲线叠加双纵轴虽然节省空间，却容易让任意缩放制造视觉同步，独立面板往往更透明。

遇到验证波动时，还应检查评估是否确定性、模型是否切换到正确模式、验证样本是否固定，以及聚合分母是否一致。若每次随机抽取一个很小验证子集，波动可能主要来自样本组成。把曲线平滑以后看起来更稳定，不会增加评估样本。必要时应改善评估设计，而不是只调整可视化参数。

<a id="plot-2-detail-35"></a>

### 7.2 为最终图片保留足够来源信息

最终文件可以只是一张图，但生成它所依赖的记录与配置需要能够重建。至少应知道输入日志身份、指标定义、过滤规则、预算单位、对齐方式、平滑方法、运行列表、区间含义和输出尺寸。信息不一定全部写在图里，可以分别放在图注、实验记录与资料正文中，但不能只存在于某个研究者的记忆。

本套学习资料中的示例采用内存输出，目的是把计算和显示过程完整展示，并避免留下中间生成文件。实际项目若需要持久图像，应给输出明确名称并保留必要原始结果；不要把最终图当作唯一数据存档，因为从像素无法可靠恢复数值、样本身份和缺失原因。可复核性来自完整关系链，而不是文件数量多。

一个简洁的验收顺序是：先验证统计定义，再验证数组与计数，再验证轴和颜色映射，最后验证导出。若前面步骤失败，后续美化应暂缓。这样做不是为了增加流程负担，而是让每项检查都针对一种明确错误。所有步骤通过后，正文结论仍应与图实际支持的范围一致，尤其不能把描述性趋势升级为未经实验支持的机制结论。

## 8. 进阶练习与完整解析

<a id="plot-2-detail-37"></a>

### 8.1 练习一：批均值平均为何可能改变结论

**问题。** 两批有效 token 数为一千和一百，平均损失分别为一和三。整轮每 token 损失是多少？等批平均又是多少？

**解析。** 总损失为一千乘一加一百乘三，得到一千三百；总 token 数一千一百，因此正确平均为十三除以十一，约一点一八二。等批平均得到二，它给小批中每个 token 十倍权重。若小批恰好来自较难长尾样本，错误聚合会显著改变图形。日志应保存损失总和与有效数量，在所有进程和批次上相加后再相除。仅保存“平均 loss”而没有内部归约定义，无法保证事后修复。

<a id="plot-2-detail-38"></a>

### 8.2 练习二：为什么验证损失可以低于训练损失

**问题。** 验证曲线持续低于训练曲线，是否已经证明训练实现出错？

**解析。** 不能。训练增强增加难度，随机层增加噪声，训练目标含正则项，或训练集本身更难，都可能产生这种关系。应在相同数据项定义、相同评估模式和可比样本协议下额外计算指标，再检查差异。若仍异常，再追踪数据泄漏、标签错误或采样偏差。曲线关系只能提出假设，不能单独识别原因；直接把两条不同对象的曲线间距称作泛化误差尤其不严谨。

<a id="plot-2-detail-39"></a>

### 8.3 练习三：同 epoch、同 step 和同时间谁最公平

**问题。** 两模型批大小和每步耗时不同，哪一种横轴能给出唯一公平排序？

**解析。** 没有脱离目标的唯一排序。同 step 比较更新效率，同样本量比较数据利用，同时间比较规定硬件与实现下的实际速度。模型 A 可能更新更少却每步更贵，模型 B 可能样本利用较差却吞吐更高。应选择主要资源问题，并可补充其他尺度，说明硬件、预热、验证和数据加载是否计入。用 epoch 或日志行号代替这些资源定义，会把不同预算混成同一位置。

<a id="plot-2-detail-40"></a>

### 8.4 练习四：平滑窗口十一为什么产生五步滞后

**问题。** 对线性序列 $`y_t=a+bt`$ 采用十一点后向均值，结果与当前值有什么关系？

**解析。** 十一个索引为当前到过去十步，其平均索引为 $`t-5`$，所以平滑结果是 $`a+b(t-5)=y_t-5b`$。下降趋势时 $`b<0`$，平滑值高于当前值，看起来进展落后五步；上升时相反。这个推导要求完整等间隔窗口，边界缩短窗口时延迟不同。居中窗口可以消除这种线性位移，却需要未来数据，因此不应当作当时可用的在线信号。

<a id="plot-2-detail-41"></a>

### 8.5 练习五：提前停止后怎样处理缺失

**问题。** 五次运行中最差两次在预算一半时失败，后续三次均值明显下降。是否可以说算法在后期普遍改善？

**解析。** 不能直接说。后期均值来自不同运行集合，下降可能只是差运行被排除。应展示可用运行数、失败原因与每条曲线，限定共同预算或采用事先规定的失败评价。完整运行子集可以帮助说明组成效应，却不能自动代表所有启动运行。若缺失依赖表现，常见随机缺失假设不成立，简单插值或前值延长也不会消除偏差。报告中应把条件性能与失败率分开解释。

<a id="plot-2-detail-42"></a>

### 8.6 练习六：密度可以大于一吗

**问题。** 某误差密度峰高为五，是否违反概率不超过一？

**解析。** 不违反。密度是每单位横轴长度的概率量，概率由区间积分或柱面积得到。若宽度零点一的箱子高度五，面积为零点五，完全合法。更换单位会改变密度高度，因此纵轴应有倒数单位。若图把密度直接标成“概率”，读者就容易误解。检查归一化时应计算所有高度乘箱宽的和，而不是把柱高直接相加。

<a id="plot-2-detail-43"></a>

### 8.7 练习七：经验分布最后等于一能否排除更大值

**问题。** 测试样本最大延迟为两秒，经验分布在两秒达到一，能否宣布系统不会超过两秒？

**解析。** 不能。经验分布只记录有限样本，未观察到更大值不等于总体概率为零。应给出样本量、采样条件和可能的不确定性；若尾部安全是关键，需要针对罕见事件设计评价。把零超越比例替换成一个任意小正数画在对数轴上，会制造虚假精度。可以显示计数分辨率或明确未观测标记，但不能把显示便利当作概率估计依据。

<a id="plot-2-detail-44"></a>

### 8.8 练习八：对数变换后的密度如何还原

**问题。** 对正值 $`X`$ 先取自然对数得到 $`Z`$，估计了 $`f_Z`$，是否只需把横轴指数化就能得到 $`f_X`$？

**解析。** 还需要雅可比。由区间概率守恒，$`f_X(x)dx=f_Z(\log x)d\log x`$，因此 $`f_X(x)=\frac{f_Z(\log x)}{x}`$。只指数化横轴、不调整纵轴，会使面积解释错误。若仅把原始变量的图设为对数横轴，纵轴仍可以是原单位密度，但此时视觉面积不再直接等于概率，因为屏幕横向距离对应对数而非原始增量。图注应说明展示的是哪个密度。

<a id="plot-2-detail-45"></a>

### 8.9 练习九：阴影标准差与标准误怎样随运行数变化

**问题。** 从五次独立运行增加到二十次，是否应期待运行标准差缩小一半？

**解析。** 不应。运行标准差估计的是算法在给定协议下的离散程度，增加次数主要使该估计更稳定，并不改变真实运行方差。独立同分布且有限方差时，均值标准误大致随运行数平方根的倒数变化，因此从五到二十可近似缩小一半。两种带如果不注明含义，会让读者把“均值估计更精确”误读为“每次训练更稳定”。实际小样本还需考虑区间构造与分布形状。

<a id="plot-2-detail-46"></a>

### 8.10 练习十：测试样本一万是否等于一万次训练

**问题。** 一个模型在一万个测试样本上表现稳定，能否据此声称训练种子几乎没有影响？

**解析。** 不能。测试样本变化与训练过程变化是不同随机性。固定参数模型上的大量测试记录可以提高对该模型条件性能的认识，却没有直接观察其他训练种子。需要独立训练运行才能估计种子影响。若样本又来自少数用户，测试有效独立数量还可能低于记录数。应在图中分清样本级误差分布和运行级性能分布，不用大量细点掩盖训练重复数量不足。

<a id="plot-2-detail-47"></a>

### 8.11 练习十一：曲线上百分之九十五区间是否覆盖整条趋势

**问题。** 每个预算点都有百分之九十五置信区间，是否可以把阴影称为整条曲线的百分之九十五置信带？

**解析。** 一般不可以。点态覆盖只对固定预算成立，多个预算同时覆盖涉及联合事件。预算之间相关性会影响整体概率，但不会自动把点态声明升级为同时声明。如果研究问题只是描述各固定预算的均值估计，可以明确标为点态区间；若要支持整个预算范围上的统一比较，需要相应同时推断。看图后再挑最有利预算还引入选择，必须在结论中考虑。

<a id="plot-2-detail-48"></a>

### 8.12 练习十二：增加 dpi 为什么救不了小字

**问题。** 一幅六英寸宽、十二 points 字体的图在报告中缩成三英寸，提升 dpi 四倍是否能保持十二 points 的阅读大小？

**解析。** 不能。整体缩放一半使物理字号相当于六 points，dpi 只增加栅格采样细节。应按最终三英寸宽度重新设计图，减少面板、简化标签或增大设计字号，再选择足够分辨率。高分辨率的小字仍然是小字。验证时应以最终展示尺寸查看，而不是在图片查看器中放大到全屏后认为清楚。

<a id="plot-2-detail-49"></a>

### 8.13 练习十三：tight 输出为什么尺寸不同

**问题。** 画布设为六乘四英寸，三百 dpi，使用 tight 导出却不是一千八百乘一千二百像素，是否属于错误？

**解析。** 未必。tight 会按对象边界重新裁定范围，最终物理尺寸可能不同，像素尺寸自然变化。若交付要求严格固定宽高，应在固定画布内安排布局，未裁切导出并检查标签是否完整。若允许按内容裁切，尺寸变化是预期行为。关键是不要同时作互相冲突的假设：要求自动裁边，又默认输出完全保留原画布尺寸。

<a id="plot-2-detail-50"></a>

### 8.14 练习十四：矢量文件为什么可能比 PNG 大

**问题。** 几十万个散点导出 PDF 后特别大，是否应该继续增加 dpi？

**解析。** 纯矢量散点可能记录大量路径或对象信息，文件大小主要来自复杂几何，而不是栅格 dpi。可把密集数据层栅格化，保留轴与文字矢量，再实际测量大小与清晰度。若目标只是数量密度，二维聚合图也可能更符合问题。增加 dpi 可能让栅格层更大，并不减少矢量几何复杂度。选择应依据输出用途、数据层含义和最终尺寸。

<a id="sec-7-1"></a>

<a id="plot-2-detail-51"></a>

### 8.15 练习十五：平滑后更稳定是否证明算法更稳定

**问题。** A 用三点窗口，B 用五十一点窗口，B 曲线更平稳，能否据此宣称方差更小？

**解析。** 不能。不同算子本身就会改变可见高频波动；单次曲线的时间噪声也不是独立运行的性能方差。应统一适当的平滑尺度，保留原始曲线，使用多次同协议运行来描述训练随机性。若日志时间间隔不同，统一窗口条数也未必统一实际预算尺度，还需根据预算间隔调整。视觉平滑与统计稳定需要分别定义，不能用前者替代后者。

<a id="plot-2-detail-52"></a>

### 8.16 练习十六：写一份可审计的图注

**问题。** 为五种子训练损失图写出必要信息，并指出哪些信息不应由读者猜测。

**解析。** 图注应说明横轴采用的真实预算单位，纵轴的损失公式与有效单位，五次运行是否独立且同协议，实线是原始均值还是平滑均值，阴影是标准差、分位范围还是某种置信区间，以及缺失和失败如何处理。

例如“横轴为已处理有效 token；损失为自然对数负似然总和除以有效预测数；淡线为五次独立运行原值，实线为统一后向五次评估均值，阴影为平滑后运行间标准差；仅展示五次共同覆盖区间”。这段说明让图的每个组成部分都有可追溯定义，避免把重要分析选择藏在默认参数里。
