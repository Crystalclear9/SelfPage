# PyTorch 深度学习编程

从张量存储、动态求导与参数注册出发，建立可核对的训练、验证、数据管线和恢复流程，区分数学目标、程序状态与设备执行条件。

**先修知识：** Python、NumPy；梯度与神经网络基本概念。

**正文篇幅状态：** 本主题现有 4 章均已按长篇教材标准展开，逐章纯正文达到 12000–20000 汉字。完整范围见[长篇教材覆盖表](../../README.md#textbook-status)。

## 学习顺序与覆盖范围

先读[神经网络前向与损失](../../DeepLearning/NeuralNetworkBasics/01-前向传播激活函数与损失.md)，再用本主题第 1 章理解张量与自动求导；随后将训练循环与反向传播对照。模型训练概念和工具接口交替推进，避免把两个主题互相当作整本先修。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：恢复后从哪一层证明正确](04-检查点恢复与训练代码组织.md#sec-8-1)，再对照逐步解析与验收要求。

按 01→02→03→04 学习：先掌握张量与求导的接口约定，再建立单设备训练闭环，随后分析数据与设备性能，最后核对保存与恢复。CPU 实验用于验证数值和状态，GPU、工作进程与分布式条件按各章说明另行验证。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
