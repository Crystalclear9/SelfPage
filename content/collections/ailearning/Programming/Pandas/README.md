# Pandas 表格处理

用明确的数据类型、索引与连接规则构建可靠的表格数据流程。

**先修知识：** Python；NumPy 数组基本概念。

**正文篇幅状态：** 本主题现有 4 章均已按长篇教材标准展开，逐章纯正文达到 12000–20000 汉字。完整范围见[长篇教材覆盖表](../../README.md#textbook-status)。

## 学习顺序与覆盖范围

本主题代码以 Pandas 2.3.3 验证，Copy-on-Write 等行为按章内前提显式设置。先读第 1—2 章掌握清洗和连接，再配合[模型评估的划分与泄漏](../../MachineLearning/ModelEvaluation/02-交叉验证泄漏与公平比较.md)阅读第 3—4 章。时间特征的实现与合法性需要一起理解，不应仅因表格计算成功就进入训练。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：连接与缺失一起对账](04-从原始表到训练样本的完整流程.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
