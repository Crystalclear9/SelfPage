# Pandas 表格处理

用明确的数据类型、索引与连接规则构建可靠的表格数据流程。

**先修知识：** Python；NumPy 数组基本概念。

## 学习顺序与覆盖范围

本主题代码以 Pandas 2.3.3 验证，Copy-on-Write 等行为按章内前提显式设置。先读第 1—2 章掌握清洗和连接，再配合[模型评估的划分与泄漏](../../MachineLearning/ModelEvaluation/02-交叉验证泄漏与公平比较.md)阅读第 3—4 章。时间特征的实现与合法性需要一起理解，不应仅因表格计算成功就进入训练。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。
