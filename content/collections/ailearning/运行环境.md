## 1. 示例的运行范围

Python 完整代码块均给出了本块需要的导入与数据。NumPy、Pandas、绘图、PyTorch 及各类完整项目示例可以分别保存为 `.py` 文件后运行。解释性的 SQL 片段需要相应模式与数据表；数据库章节中的完整 Python 实验会自行创建 SQLite 表。Git 命令需要仓库上下文，完整实验自行创建隔离仓库。Linux 章节按 Bash 与 Linux 内核机制说明，完整实验需要 Linux 或 WSL；仅有兼容外壳并不足以复现内核、信号和文件系统行为。公式和伪代码用来解释算法，不应当作可直接执行的 Python。

教学示例优先使用人工数据或库内置数据，不需要下载模型权重。示例展示流程和机制，不预先承诺某台设备上的精确分数或速度。训练受库版本、线程、设备和随机性影响，结果可能略有差异。

## 2. 建议使用独立环境

以下为 Windows PowerShell 命令示例，应在准备保存代码的项目目录中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install numpy pandas scipy matplotlib scikit-learn torch
.\.venv\Scripts\python.exe your_example.py
```

最后一行的 `your_example.py` 应替换为实际保存的文件名。建议在独立环境中安装依赖。需要 CUDA 加速时，按照 [PyTorch 官方安装页](https://pytorch.org/get-started/locally/) 选择与系统和驱动适配的安装命令，先确保 CPU 示例工作正常。

Linux 或 WSL 可使用 `python3 -m venv .venv`，然后直接调用 `.venv/bin/python`。如果机器上有多个解释器，检查 `python --version` 和 `python -m pip --version`；始终通过目标解释器调用 pip。

策略方法、深度强化学习、贝叶斯计算与自监督学习示例均采用独立 CPU 实验。策略训练直接实现有限五步链，分别给出完整 REINFORCE、GAE 和 PPO 采样更新；DQN 与 Double DQN 使用另一个显式有限随机链，独立环境交互与回放采样随机源，并保留全部预设种子结果。精确动态规划用于独立参照，未被输入学习更新；没有依赖 Gymnasium、外部环境或预训练策略。

连续控制章的完整优化实验使用已知可微动力学，并明确区分它与未知模型的 DDPG；动作变换密度、双 critic 偏差和离线支持缺失实验分别检验局部机制，没有冒充完整 SAC 或离线强化学习训练。正文给出的指标只适用于这些人工任务，不能据此承诺真实机器人性能。

贝叶斯实验包含共轭与非共轭变分优化、均值场覆盖率机制、有限状态 MH、对数坐标 Gamma 采样、完整高斯 HMC 和多峰诊断反例。一维积分同时核对网格加密、全实轴数值积分与截断尾界；有限计算误差与形式化严格认证分别说明。MCMC 示例中的经典 split-Rhat 不等于完整的秩归一化诊断，未实现 Stan、NUTS 或生产级自动诊断库。

自监督实验包含完整的小型对比编码器、非对比几何正则训练与掩码重建训练。人工视图生成协议、语义与背景因素、冻结探针的数据划分均在代码和正文中明确；重建损失下降、坐标方差达标、谱有效维度与语义可读性分别报告，不将任何单一指标直接当作通用表示质量的证明。示例代码可直接从章节复制运行，数据与模型在内存中构造。

因果推断、连续生成、系统效率与不确定性示例在独立 Python 进程中运行。因果实验包含人工观察研究、前门识别与条件破坏、完整五折辅助模型交叉拟合及独立策略评价；可交换性与支持是建模假设，数值拟合或交叉拟合不能自行建立它们。

连续生成包含完整一维双峰得分网络与流匹配训练、解析高斯反向过程、边缘连续性和密度核对；训练偏差、噪声端与截断端失配和求解误差分别说明。人工分布统计不能代替真实图像质量或大模型采样性能。模型仅在内存中使用，未保存外部权重或数据。

系统实验包括显式字节存活模拟、完整不等长回归训练与累积等价、检查点随机重演、完整 Adam 坐标分片，以及量化语义、单约束二阶补偿和完整人工分类器的无标签校准。保存张量登记量不是设备峰值；反量化模拟没有调用真实低位内核；ring、KV容量、roofline与Amdahl数字由指定参数计算，不是多卡或GPU吞吐测量。量化后输出重构更好但任务准确率略差的负结果保留。

不确定性实验包含独立训练、概率校准、集合校准与测试，异方差组覆盖取舍、来源比估计、完整 groupDRO 人工捷径训练、拒答候选的二项联合认证与多重搜索反例。SciPy用于精确二项及Beta分位计算；校准边缘覆盖、认证外层置信和接受条件风险分别报告。这些实验采用上述依赖版本，在内存中完成训练与评价。

## 4. 复现应保存哪些信息

- Python 与依赖版本、硬件与设备类型。
- 数据名称、版本、划分规则与随机种子。
- 模型结构、预处理、损失、优化器、学习率与训练预算。
- 最佳模型选择规则与最终评估协议。

固定种子是复现的一部分，还需要固定代码和数据。若训练恢复时缺少优化器与调度器状态，后续轨迹可能与连续训练不同。运行结果应与日志和配置一起保存。

## 5. 调试建议

先在 CPU、小数据、短训练预算上检查形状和损失，再切换设备或加速设置。发生错误时保留完整报错，定位最早的异常位置；不要通过随意 reshape、忽略异常或替换 NaN 来掩盖原因。

## 6. 独立进阶篇的运行范围

进阶篇算例使用标准库、NumPy、SciPy、scikit-learn 或 PyTorch CPU，具体依赖以逐章导入为准，主要核对集中界、双重稳健得分、后验几何、马尔可夫不变性、对比梯度、解析流、量化与保形秩阈值，以及 PAC-Bayes 变分目标、离策略评价和拒答风险上界。完整人工训练、解析参照与局部机制验证均在章内说明规模；专业平台、多卡训练和生产级诊断仍需相应环境。各章研究任务给出进一步实验设计，读者实现时应按说明控制数据、假设及预算。

系统篇中的 GB 估算、分片理想值与量化误差不等于目标 GPU 的实测性能；不具备多卡硬件时仍可完成预算推导和局部数值例子。
