## 1. 通用数学符号

符号会随上下文变化，遇到重名时优先采用当前章节定义。例如 $X$ 可表示随机变量，也可表示样本矩阵；$p$ 可表示概率，也可表示密度。

| 符号 | 常见含义 |
| --- | --- |
| $n,d$ | 样本数、特征维度 |
| $B,T,C$ | 批大小、序列长度、类别数或通道数 |
| $X\in\mathbb R^{n\times d}$ | 样本按行排列的数据矩阵 |
| $w,b,\theta$ | 权重、偏置、统称模型参数 |
| $A^T$ | 矩阵转置 |
| $\|x\|_2$ | 欧氏范数 |
| $\odot$ | 逐元素乘法 |
| $E[X],\operatorname{Var}(X)$ | 期望、方差 |
| $P(A\mid B)$ | 在事件 B 条件下 A 的概率 |
| $\nabla_\theta L$ | 损失对参数的梯度 |
| $\eta,\alpha$ | 常用于学习率，具体看上下文 |
| $\lambda$ | 常用于正则系数或折中参数 |
| $\gamma$ | 强化学习中的折扣因子 |
| $\log$ | 未另说明时通常指自然对数 |

## 2. 容易混淆的概念

| 概念 | 区别 |
| --- | --- |
| 参数 / 超参数 | 参数在训练中拟合；超参数决定模型或训练流程，通常用验证选择 |
| 损失 / 指标 | 损失用于优化；指标用于评价，二者可以不同 |
| epoch / step / batch | 遍历一遍训练数据 / 一次更新 / 一组样本 |
| 标准差 / 标准误差 | 个体离散程度 / 估计量的抽样波动 |
| 相关 / 因果 | 共同变化 / 改变一个变量对另一个产生的作用 |
| logits / 概率 | 归一化前实数分数 / 满足概率约束的输出 |
| 单标签 / 多标签 | 每条样本只有一个类别 / 可以同时有多个类别 |
| 训练 / 验证 / 测试 | 拟合参数 / 选择方案 / 最终独立评估 |
| 欠拟合 / 过拟合 | 未捕捉必要结构 / 过度适配训练细节 |
| 梯度消失 / 梯度爆炸 | 传播过程中梯度过小 / 过大 |
| 反向传播 / 优化器 | 计算梯度 / 利用梯度更新参数 |
| 注意力权重 / 特征贡献 | 动态读取比例 / 对最终输出的实际影响，二者不能直接等同 |
| token / 单词 | 模型切分单位 / 自然语言单位，未必一致 |
| terminated / truncated | 任务真正终止 / 因外部条件截断，bootstrap 处理需区分 |
| 奖励 / 回报 / 价值 | 单步反馈 / 多步累计反馈 / 回报的条件期望 |
| on-policy / off-policy | 目标策略是否与采样行为策略一致，不能简单等同于是否使用神经网络 |
| 检索 / 生成 / 微调 | 查找外部证据 / 根据上下文输出 / 用训练改变模型参数 |

## 3. 读公式的固定顺序

先确定公式输出是什么，再列出输入的含义、单位和形状；接着逐步计算，最后检查适用条件。例如 $X^T(Xw-y)/n$ 的输出应与 $w$ 同形，$Xw-y$ 应是一条样本对应一个误差。如果形状与样本含义对不上，应先修正表示，再讨论优化。

不要只背公式的最终形式。常数因子可能来自平方项、样本平均或损失定义；同名方法在不同实现里也可能有不同约定。能够从目标与约定恢复公式，才更容易阅读新论文和新代码。


## 4. 独立进阶篇符号与对象

符号只在所在章节定义下使用，例如 λ 可是正则强度，α 可是错误率或扩散系数，不能跨章机械代入。

| 记号或术语 | 所在问题与含义 |
| --- | --- |
| $R(h),\hat R_S(h)$ | 总体风险与训练样本经验风险 |
| $\beta$-稳定性 | 替换训练样本后损失敏感性，不等于测试输入鲁棒性 |
| $Y(1),Y(0),\tau$ | 潜在结果与指定总体的平均处理效应 |
| $e(x),m_a(x)$ | 倾向得分与处理组条件结果均值 |
| ELBO、$q_\phi$ | 证据下界与变分近似分布 |
| MCMC、ESS、R-hat | 后验采样、有效样本量与多链诊断，各有条件 |
| InfoNCE | 按配对候选构造的对比分类目标 |
| 表示坍塌 | 常数坍塌与维度退化需分开诊断；低有效秩本身不等于任务信息丢失 |
| $\nabla_x\log p_t(x)$ | 密度得分向量，不是生成质量评分 |
| 概率流、速度场 | 搬运边缘密度的动力学，轨迹不等于训练配对连线 |
| NFE | 网络函数评估次数，不一定等于采样步数 |
| scale、zero point | 量化尺度与零点，不等于直接改变权重 dtype |
| 边缘覆盖 / 条件覆盖 | 对随机总体覆盖 / 对给定输入或群体的更强要求 |
| ERM / group DRO | 平均经验风险目标 / 指定群体最坏风险目标 |

## 5. 策略评价与风险控制补充

| 术语 | 需要区分的对象 |
| --- | --- |
| PAC-Bayes 先验 / 后验 | 先验需满足独立性或专门条件；后验可依赖当前训练数据，不必是贝叶斯模型后验 |
| Gibbs 风险 / 集成风险 | 对随机预测器损失求期望 / 对集成决策计算损失，通常不相同 |
| 温度 $T$ / 逆温度 $\lambda$ | 权重写成 $e^{-L/T}=e^{-\lambda L}$ 时，$\lambda=1/T$；升高温度使分布更平缓，升高逆温度使分布更集中。须同时核对损失使用均值还是总和 |
| confidence / top-label 校准 | 令 $S=\max_kp_k(X)$、$\widehat Y=\arg\max_kp_k(X)$、$C=\mathbf1\{Y=\widehat Y\}$。前者要求 $E[C\mid S]=S$；后者进一步要求 $E[C\mid S,\widehat Y]=S$，不能仅核对总体置信度分组就称逐预测类别校准 |
| 轨迹 IS / PDIS | 完整轨迹概率比乘回报 / 各时刻仅使用相应前缀概率比 |
| 离策略评价 / 离策略学习 | 估计给定目标策略价值 / 根据日志选择或训练策略，后者还有选择问题 |
| 选择性覆盖 / 保形覆盖 | 自动回答的比例 / 预测集合包含真值的概率 |
| 选择性风险 | 已接受样本的条件错误率；全部拒答时不能自动记作零 |
