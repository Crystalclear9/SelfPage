## 1. 为什么在普通递归里增加门

<a id="rnn-2-detail-2"></a>
### 1.1 固定衰减面对的矛盾

在 $`h_t=\tanh(Wh_{t-1}+Ux_t+b)`$ 中，写入新信息、保持旧信息和向外暴露信息，都通过同一次非线性变换完成。某个任务可能要求平时忽略输入，在特定事件出现时写入，在另一个事件出现时清除。固定的循环矩阵可以尝试学习这些行为，但很难用一个简单、稳定、输入相关的机制显式控制。

门控引入由当前输入和旧状态计算的乘法系数。系数通常通过 sigmoid 限制在零到一之间，表示对某条支路的连续调节。它们是可训练函数，而不是由人指定的语义标签。名为遗忘门的数值接近一，只说明在当前更新中对旧单元状态的直接乘子接近一；不能据此宣布模型已理解哪些现实事件应该被记住。

<a id="rnn-2-detail-3"></a>
### 1.2 门控是一种条件计算与参数化

可以把门控看作输入相关的更新步长：某一维当前需要快速适应，就给新信息较大权重；当前需要保持，就降低更新幅度。相比固定指数平均，时间尺度随样本与状态变化，这使同一个单元能够在不同上下文使用不同的记忆节奏。但门本身也要被学习，梯度和数据不足时仍可能学不到恰当策略。

门控增加参数、矩阵运算和中间激活。它可能改善优化路径，同时增加过拟合和调参成本。若目标只依赖最近两个输入，简单窗口回归可能更稳定、更容易解释。结构选择应从目标所需的状态和部署约束出发，而不是预设复杂门控总能压倒普通 RNN 或非递归基线。

## 2. LSTM 的前向方程与状态语义
<a id="rnn-2-detail-5"></a>
### 2.1 四组支路逐项定义

以下讨论无窥孔连接、无投影的标准单层单元。设输入 $`x_t\in\mathbb R^d`$，隐藏输出和单元状态都为 $`m`$ 维：

```math
\begin{aligned}
i_t&=\sigma(W_ix_t+U_ih_{t-1}+b_i),\\
f_t&=\sigma(W_fx_t+U_fh_{t-1}+b_f),\\
g_t&=\tanh(W_gx_t+U_gh_{t-1}+b_g),\\
o_t&=\sigma(W_ox_t+U_oh_{t-1}+b_o),\\
c_t&=f_t\odot c_{t-1}+i_t\odot g_t,\\
h_t&=o_t\odot\tanh(c_t).
\end{aligned}
```

![旧状态保留项与候选写入项相加得到新状态，再经过 tanh 和输出门得到隐藏状态](images/02-lstm-combines-keep-and-write-before-hidden-readout.webp)

[打开原图放大](images/02-lstm-combines-keep-and-write-before-hidden-readout.webp)

旧状态先乘遗忘门 $`f`$，候选 $`g`$ 乘输入门 $`i`$，两支在加号处形成新状态 $`c`$。读出支路从这个新状态取 $`\tanh(c)`$，再乘输出门 $`o`$ 得到 $`h`$。三处乘号都表示逐元素乘法。

固定同一步的 $`f,i,g`$，将 $`o`$ 调小，当前 $`c`$ 不变，$`h`$ 分量趋零。下一时刻的门仍可受变化后的 $`h`$ 影响，所以不能推出未来细胞状态始终不变。对照 [D2L 的完整记忆单元图](https://d2l.ai/chapter_recurrent-modern/lstm.html)。

输入门控制候选写入，遗忘门控制旧状态的直接保留，输出门控制当前状态向隐藏输出暴露多少。候选 $`g_t`$ 是可能写入的新内容，不是概率。四组矩阵都有独立参数；实现可以把它们拼成一次大矩阵乘法，再按约定拆分，拼接顺序必须与加载的参数一致。

<a id="rnn-2-detail-6"></a>
### 2.2 为什么同时有单元状态和隐藏输出

单元状态 $`c_t`$ 通过加法更新，隐藏输出 $`h_t`$ 通过有界非线性和输出门提供给后续门与输出头。两者角色不同，也不会一般相等。某一维可以在 $`c_t`$ 中保留较大的累计值，同时因为输出门较小而暂时不明显影响外部输出。后续是否还能读出该内容，依赖输出门、非线性饱和与任务训练。

状态接口因此是二元组。把块末端隐藏输出传下去却把单元状态清零，会改变前向记忆；只 detach 隐藏输出而让单元状态继续保留图，则仍可能沿单元支路跨块反传。实现截断或重置时应对两个状态采取同一明确策略，并检查嵌套结构，而不是假定一个变量`hidden`就概括了全部内部状态。

<a id="sec-1-1"></a>
<a id="rnn-2-detail-7"></a>
### 2.3 一步与多步的手算

取标量 $`c_0=2`$，当前遗忘门为 $`0.8`$，输入门为 $`0.25`$，候选为 $`-0.4`$，则 $`c_1=1.6-0.1=1.5`$。输出门为 $`0.6`$ 时，隐藏输出是 $`0.6\tanh(1.5)`$，约为 $`0.543`$。不能把输出门直接乘在单元状态上写成 $`0.9`$，因为读出还包含 tanh；也不能把负候选解释成负概率。

若后续没有新写入且遗忘门始终为 $`0.8`$，则三步后旧信息贡献为 $`2\times0.8^3=1.024`$。每一步看似保留百分之八十，重复以后仍显著衰减。若同时每步写入常数 $`u`$，递归变为 $`c_t=f c_{t-1}+u`$；当 $`\vert f\vert \lt 1`$ 时趋于 $`\frac{u}{(1-f)}`$。当 $`f`$ 很接近一时，小的持续写入也可能造成很大的稳态幅值。

<a id="rnn-2-detail-8"></a>
### 2.4 门值不是独立概率

标准 LSTM 的输入门和遗忘门独立计算，不要求两者之和为一。某一维可以同时大量保留旧内容和写入新内容，也可以两者都小。把这条更新称为旧值与候选的凸组合通常不正确。它与后文 GRU 的直接插值结构不同，正是理解单元状态可能累积增长的关键。

sigmoid 门严格位于零与一之间，除非考虑浮点舍入或理想极限；因此“完全关门”和“完全保留”通常是近似说法。门在饱和区对预激活的导数很小，可能有利于暂时保持某行为，也可能让改变该行为变得困难。前向门值和门参数的可学习性需要同时观察，不能只凭一幅门激活热图评价结构。

### 图解：LSTM 细胞状态的保留与写入

![同一受控 LSTM 一步的保留、写入、读出，以及二十步时初始贡献与新增贡献](images/02-lstm-retained-content-and-cumulative-write-at-two-time-steps.webp)

[打开原图放大](images/02-lstm-retained-content-and-cumulative-write-at-two-time-steps.webp)

**把一次保留与写入，延长到二十步。** 本图只隔离一个标量细胞通道；状态迭代与输出读出分开画，避免把两者当成同一条“记忆线”：初值 $`c_0=2`$，每步固定遗忘门 $`f=0.9`$、输入门 $`i=0.2`$ 和候选值 $`g=0.5`$。每一步都执行 $`c_t=0.9c_{t-1}+0.1`$，所以图中第一步为 $`1.8+0.1=1.9`$。展开后得到

```math
\begin{aligned}
&c_t=\underbrace{2(0.9)^t}_{\text{初始记忆留下的贡献}}\\
&\quad +\underbrace{0.1\sum_{j=0}^{t-1}(0.9)^j}_{\text{后续写入留下的贡献}}
=1+(0.9)^t.
\end{aligned}
```

状态更新 $`c_t=0.9c_{t-1}+0.1`$ 的固定点为一。第一步先保留 $`0.9\times2=1.8`$，再写入 $`0.2\times0.5=0.1`$。输出门取 $`0.6`$ 时，读出 $`h_1=0.6\tanh(1.9)\approx0.5737`$，存储仍是 $`c_1=1.9`$。沿表读到第二十步，初始内容只贡献约 $`0.2432`$，累计写入贡献约 $`0.8784`$。持续写入接替了遗忘掉的初始内容，因此总状态虽趋近一，初始贡献仍趋近零。

这些门值是受控算例中固定的，并非真实 LSTM 必然恒定。在此条件下 $`\frac{\partial c_t}{\partial c_0}=(0.9)^t`$；若门随隐状态变化，完整导数还包含经过门函数的路径，不能只保留这个乘积。隐藏输出还需输出门与 $`\tanh`$，通常不等于 $`c_t`$。可结合 [《动手学深度学习》的 LSTM 状态通路](https://d2l.ai/chapter_recurrent-modern/lstm.html)把这里的数值分解放回完整单元结构。

**先走一次单元，再读二十步的来源分解。** 图顶端把 $`2\to1.8\to1.9\to0.5737`$ 展开成保留、加写入、隐藏读出三个运算；这些数分属不同阶段，不能只因为画在一条线上就当作同一个状态变量。单元存储仍为 $`c_1=1.9`$，$`0.5737`$ 是另经 tanh 与输出门得到的 $`h_1`$。下方两行用同一组门值和初值分别计算第一步、第二十步。[D2L 的完整 LSTM 图](https://d2l.ai/chapter_recurrent-modern/lstm.html)明确把主状态通路与 tanh 读出分开，这个数值版对应同一结构区别。

**检验问题。** 到第二十步突然停止后续写入，却保持遗忘门不变，下一步状态是 $`0.9(1+0.9^{20})\approx1.009419`$；继续写入则为 $`1+0.9^{21}\approx1.109419`$。两者相差恰好一次新写入的 $`0.1`$。原有写入的残留不会因现在关掉输入门而立即全部消失；应区分“本步新增”与“过去写入的累计贡献”。

## 3. 加法路径的收益与有限保证

<a id="rnn-2-detail-10"></a>
### 3.1 冻结门时的直接保留路径

若暂时把各时刻门值视为固定外生系数，单元状态可展开为

```math
\begin{aligned}
&c_T=\left(\prod_{t=1}^Tf_t\right)\odot c_0\\
&\quad +
\sum_{k=1}^T\left(\prod_{t=k+1}^Tf_t\right)\odot i_k\odot g_k.
\end{aligned}
```

这是逐维形式，空乘积为一。它显示旧信息沿一条不反复经过 tanh 的加法主路径传递，保留程度由遗忘门乘积决定。这是门控能够改善长期梯度的一项核心机制，但公式中的“冻结门”条件不可省略：真实门通常通过隐藏状态间接依赖更早单元状态。

即使只看这条直接路径，若每步 $`f=0.99`$，经过一千步也只剩约 $`4.3\times10^{-5}`$。因此接近一与足以覆盖目标跨度之间有数量差别。不要把某一步 $`0.99`$ 的门值读成“长期不忘”，应根据实际跨度计算乘积或对数和，并检查还存在多少任务相关读出信号。

<a id="rnn-2-detail-11"></a>
### 3.2 半衰期与偏置的数量关系

常数遗忘率 $`0\lt f\lt 1`$ 对应半衰期 $`\tau_{\frac{1}{2}}=\frac{\log(\frac{1}{2})}{\log f}`$。当 $`f`$ 接近一时，可用 $`\log f\approx-(1-f)`$，所以半衰期约为 $`\frac{\log 2}{(1-f)}`$。$`f=0.9`$ 对应约六点六步，$`0.99`$ 对应约六十九步，$`0.999`$ 对应约六百九十三步。这些数字提供初始化尺度直觉，而不是训练后每条轨迹的精确寿命。

若希望静态门值接近某个 $`f`$，sigmoid 预激活应为 $`\log[\frac{f}{(1-f)}]`$。但真实门还接收输入和旧隐藏输出，设置偏置不等于把门固定在该值。偏置初始化改变训练起点，模型仍需学习何时忘记。多偏置实现还要注意有效偏置是两条支路之和，不能在两边都写入完整目标值而误使预激活翻倍。

当门随时间变化时，算术平均门值并不能给出精确保留率。对一个固定坐标，直接路径系数是 $`R_T=\prod_{t=1}^Tf_t`$，因此 $`\log R_T=\sum_t\log f_t`$，等效常数门是几何平均 $`f_{\mathrm{eff}}=\exp(T^{-1}\sum_t\log f_t)`$。两步门值 $`(0.99,0.01)`$ 与 $`(0.5,0.5)`$ 的算术平均都为 $`0.5`$，前者保留率却只有 $`0.0099`$，后者为 $`0.25`$，相差约二十五倍。一次短暂强遗忘可以切断该条直接路径，后续门变大不会自动恢复已经乘掉的旧贡献。

由对数的凹性，$`f_{\mathrm{eff}}\le T^{-1}\sum_t f_t`$，即用平均门值代入其 $`T`$ 次幂会高估或至多等于真实直接保留率。这里比较的是同一组实际门值的乘积，不把门视为独立随机变量；若讨论随机门乘积的期望，还需要另列依赖条件。实际日志宜记录对数保留率及低分位数，避免长序列直接相乘下溢，也避免一个高均值掩盖少数关键清除事件。

还可以量化偏置是否容易学习：在只考虑外生预激活的辅助模型 $`f_t=\sigma(a_t+b)`$ 中，固定 $`a_t`$ 后有 $`\frac{\partial\log R_T}{\partial b}=\sum_t(1-f_t)`$。门接近一时，单步偏置敏感性变小；例如一百步均为 $`0.99`$，保留率约 $`0.366032`$，这个对数导数仍为一。若真实门通过旧隐藏状态反馈依赖偏置，以上求导遗漏了 $`a_t`$ 的间接变化，必须回到第 4 节完整状态雅可比，不能把这个辅助公式充当全部训练梯度。

**遗忘门与记忆跨度。** 本图令遗忘门固定为 sigmoid(b)，只跟踪已写入信息的直接状态路径，后续不再写入。经过 t 步的比例是 sigmoid(b) 的 t 次方。b 从零增加到二，单步门值只从 0.5 变到约 0.8808，二十步后的剩余比例却从约百万分之一变到约 0.07898；一百步还会更小。它说明门偏置对不同跨度的作用不能线性外推。真实门随输入与历史改变，完整状态导数还包含门反馈；表中的保留比例只对应固定门值的直接路径。

```math
r_t=\sigma(b)^t,\qquad \sigma(b)=\frac{1}{1+e^{-b}}.
```

**先看门值序列，再决定怎样汇总。** 另取两步遗忘门 $`(0.99,0.01)`$ 与 $`(0.5,0.5)`$。两者的算术均值同为一半，但直接路径分别只剩 $`0.0099`$ 与 $`0.25`$；后者是前者的约 $`25.25`$ 倍。单步门值需相乘，才得到经过两步的保留率。真实日志中，一条短暂接近零的门足以压低早期信息的残留，高平均值会掩盖这个事件。

更合适的汇总是 $`\log R_T=\sum_t\log f_t`$；对应等效固定门为几何平均。由对数凹性得到 $`R_T\le(\frac1T\sum_tf_t)^T`$，所以把算术均值直接升幂会高估或至多等于实际保留率。本式只把已经给定的门当作外生系数，不假设门在时间上独立。完整门控反馈仍要使用第 4 节的状态雅可比。[D2L 的 LSTM 状态主路与隐藏读出图](https://d2l.ai/chapter_recurrent-modern/lstm.html#hidden-state)有助于定位这里究竟隔离了哪一条路径。

**检验。** 交换两个门的先后顺序，在没有新写入的这个受控标量模型里，最终保留率不变，因为标量乘法交换；但中间状态不同。一旦加入按时刻写入的内容，不同内容会经过不同后缀门乘积，便不能仅凭总乘积判断完整终态。

<a id="rnn-2-detail-12"></a>
### 3.3 保持状态不等于保持可读梯度

若 $`c_t`$ 很大，$`\tanh(c_t)`$ 饱和，输出对单元状态的局部导数很小。即使单元状态沿主路径保留了数值，当前损失也可能难以通过读出头训练这些内容。输出门很小会再进一步削弱外部信号。长期学习需要保留、可读和适当监督共同成立，而不是只有遗忘门大。

持续写入并配合接近一的保留系数 $`f_t`$，还可能造成单元状态幅值增大。这里“保留系数大”表示忘得慢，不能把它误解为每步清除的比例大。它不会像隐藏输出那样天然被 tanh 限幅，因为非线性发生在读出端。可以监测单元状态分位数、读出饱和比例与不同门值，但是否使用单元裁剪或归一化应依据实验。改变这些机制会改变模型函数，不能只当作无害的实现细节。

```math
\begin{aligned}
&c_{20}=r c_0,\qquad r=0.99^{20}\approx0.81790694,\\
&\quad h_{20}=\frac12\tanh(rc_0).
\end{aligned}
```

无论初值取一还是四，直接存储导数都是 $`\frac{\partial c_{20}}{\partial c_0}=r`$。但读出导数为

```math
\frac{\partial h_{20}}{\partial c_0}
=\frac r2\left[1-\tanh^2(rc_0)\right].
```

初态一给出 $`c_{20}\approx0.817907`$，读出导数约 $`0.223215`$；初态四给出 $`c_{20}\approx3.271628`$，读出导数约 $`0.002348`$，相差约 95 倍。表中最后一列给出读出对初态的链式导数。小导数不是初始记忆全部被擦掉，而是当前读出处于较平坦的饱和区。把输出门再减小，两者还会同比缩小。

这里固定了门和写入项，只研究损失到单元状态必须经过的读出环节。它不包含下一节真实门反馈，也不等于整个模型的参数梯度；后续监督、额外读出或其他状态路径都可能改变学习信号。可结合 [D2L 的单元状态与隐藏读出图](https://d2l.ai/chapter_recurrent-modern/lstm.html#hidden-state)区分这两个接口：本图沿相同计算顺序展开数值，但没有把输入相关的真实门简化成结构保证。

## 4. LSTM 的完整状态雅可比

<a id="rnn-2-detail-14"></a>
### 4.1 先把状态坐标选对

将完整状态写成 $`z_t=(c_t,h_t)`$。在对状态转移求偏导时，$`c_{t-1}`$ 和 $`h_{t-1}`$ 是两个独立输入坐标。虽然真实历史使它们相关，但局部雅可比必须同时保留两条支路，随后通过矩阵乘积恢复跨时间全依赖。只求 $`\frac{\partial c_t}{\partial c_{t-1}}`$ 并把隐藏支路默默丢掉，会得到不完整的时间导数。

定义 $`F=\mathrm{diag}(f_t)`$，并以门对旧隐藏输出的雅可比记作 $`I_h,F_h,G_h,O_h`$。例如 $`I_h=\mathrm{diag}(i_t\odot(1-i_t))U_i`$。为避免名称冲突，下面把单元状态对旧隐藏输出的完整偏导命名为 $`A`$：

```math
A=\mathrm{diag}(c_{t-1})F_h+
\mathrm{diag}(g_t)I_h+\mathrm{diag}(i_t)G_h.
```

其中 $`G_h=\mathrm{diag}(1-g_t^2)U_g`$。三项分别来自旧状态保留率变化、写入幅度变化、候选内容变化，任何一项都可能影响真实长期灵敏度。

<a id="sec-6-1"></a>
<a id="rnn-2-detail-15"></a>
### 4.2 四个分块如何出现

令 $`Q=\mathrm{diag}(o_t\odot(1-\tanh^2c_t))`$，$`R=\mathrm{diag}(\tanh c_t)O_h`$，则完整单步雅可比是

```math
J_t=\frac{\partial(c_t,h_t)}{\partial(c_{t-1},h_{t-1})}
=\begin{pmatrix}F&A\\QF&R+QA\end{pmatrix}.
```

左上角确实包含直接遗忘门路径，但右上角和右下角携带门与候选对旧隐藏输出的反馈。多步全导数是这些完整分块矩阵的乘积。不能只挑出左上角相乘，就宣称整个网络梯度一定有界、不会消失或不会爆炸。

这个写法还解释不同 LSTM 变体为何需要重新推导。窥孔连接让门直接依赖单元状态，会修改原来的分块；投影使隐藏输出维度与单元维度不同，矩阵不再是四个同样大小的方块。结构名称相近不代表导数公式可以原封不动复用，应先写真实计算图，再应用链式法则。

<a id="rnn-2-detail-16"></a>
### 4.3 一个遗忘门很大仍会放大的反例

取标量状态，在零附近令 $`f=0.99,i=o=0.5`$，候选为 $`g=\tanh(8h_{t-1})`$。在零状态处，$`A=4,Q=0.5,R=0`$，所以雅可比为 $`\begin{pmatrix}0.99&4\\0.495&2\end{pmatrix}`$，其特征值为零和 $`2.99`$。遗忘门没有超过一，整个状态转移仍有放大方向，因为候选与隐藏输出形成反馈。

这个反例不是说 LSTM 必然不稳定，而是反驳“所有门都在零一之间，所以整个梯度不可能爆炸”的推理。矩阵中的可训练循环权重没有被门值上界自动限制。要判断实际训练的灵敏度，仍需沿轨迹检查完整雅可比或相应向量积，并结合损失读出、参数梯度累积与裁剪情况。

![旧单元和旧隐藏状态沿两条边共同改变新单元，再影响新隐藏状态](images/02-hidden-feedback-and-cell-retention-both-enter-the-state-jacobian.webp)

[打开原图放大](images/02-hidden-feedback-and-cell-retention-both-enter-the-state-jacobian.webp)

图中的三条局部边把本节反例拆开：旧单元到新单元的直接系数为 0.99，旧隐藏到新单元的候选反馈系数为 0.5×8=4，新单元到新隐藏的系数为 0.5。合并路径后，雅可比第二行为第一行的 0.5 倍，扰动方向 (2,1) 被放大为 2.99(2,1)。这些是零状态处、固定门值与指定候选函数的局部导数；有限扰动离开零附近后会受到 tanh 非线性影响，不能把 2.99 当作任意长轨迹上的恒定放大倍数。

## 5. 实验一：LSTM 前向与全部一阶导数

<a id="rnn-2-detail-18"></a>
### 5.1 库参数顺序必须显式写出

下面针对标准`LSTMCell`，按照输入门、遗忘门、候选、输出门的拼接约定重建前向，比较输入、两个状态与四组参数的梯度。输出损失同时依赖新隐藏输出和新单元状态，避免某一条支路因为没有被使用而逃过检查。实验使用双精度 CPU，不训练任何外部数据。

```python
import torch
from torch import nn

torch.set_num_threads(1)
torch.manual_seed(23)
cell = nn.LSTMCell(2, 3).double()
x = torch.randn(2, 2, dtype=torch.double, requires_grad=True)
h = torch.randn(2, 3, dtype=torch.double, requires_grad=True)
c = torch.randn(2, 3, dtype=torch.double, requires_grad=True)
params = list(cell.parameters())
hn, cn = cell(x, (h, c))
loss = hn.square().sum() + 0.7 * cn.square().sum()
expected = torch.autograd.grad(loss, [x, h, c, *params])

xx, hh, cc = [a.detach().clone().requires_grad_() for a in (x, h, c)]
weights = [a.detach().clone().requires_grad_() for a in params]
wi, wh, bi, bh = weights
i, f, g, o = (xx @ wi.T + hh @ wh.T + bi + bh).chunk(4, dim=-1)
i, f, g, o = i.sigmoid(), f.sigmoid(), g.tanh(), o.sigmoid()
manual_c = f * cc + i * g
manual_h = o * manual_c.tanh()
actual = torch.autograd.grad(manual_h.square().sum() + 0.7 * manual_c.square().sum(),
                             [xx, hh, cc, *weights])
assert torch.allclose(manual_h, hn, atol=1e-12, rtol=1e-12)
assert torch.allclose(manual_c, cn, atol=1e-12, rtol=1e-12)
for a, b in zip(actual, expected):
    assert torch.allclose(a, b, atol=1e-11, rtol=1e-11)
print('LSTM values and all seven derivative groups agree')
```

<a id="rnn-2-detail-19"></a>
### 5.2 如何扩展核对而不稀释问题

可以在这段实验外再套两三步循环，并让损失只依赖最终输出，检查初始两个状态仍收到正确梯度。若只核对一步，则尚未覆盖跨时间传递；若直接加入多层、双向、打包与 dropout，失败时又难以定位。合理顺序是先单元，再短序列，再方向与层，最后真实批量协议，每次只增加一类计算依赖。

加载别的框架权重时，先列出门顺序、矩阵朝向、偏置拆分与候选激活，再比较单步值和梯度。即使两个框架都写着 LSTM，也可能存在遗忘门额外偏置、耦合输入遗忘门或投影配置差异。模型迁移的可靠依据是完整方程，而不是类名与张量形状看起来一致。

## 6. GRU：直接插值与重置支路

<a id="rnn-2-detail-21"></a>
### 6.1 先固定更新门的语义

本章采用与 PyTorch 一致的约定，更新门 $`z_t`$ 控制旧隐藏输出的保留比例：

```math
\begin{aligned}
z_t &=\sigma(W_zx_t+U_zh_{t-1}+b_z),\\[6pt]
h_t &=(1-z_t)\odot n_t+z_t\odot h_{t-1}.
\end{aligned}
```

当 $`z_t`$ 接近一时，直接保留旧状态；接近零时，接近候选。另一种常见写法把 $`z_t`$ 定义为新内容比例，表达式中的两个系数交换。两种语义可以通过 $`z\leftrightarrow1-z`$ 对应，但不能直接把同样的参数数字复制过去，还需要对 sigmoid 预激活作相应符号变换。

GRU 只有一个对外传递的隐藏状态，没有标准 LSTM 那样独立的单元状态与输出门。其更新在固定门时是旧状态与候选的逐维凸组合，因此若初始状态和候选都在某个区间，状态不会越出该区间。这种前向范围性质不等于全雅可比范数不超过一，因为门与候选本身也依赖旧状态。

<a id="sec-2-1"></a>
<a id="rnn-2-detail-22"></a>
### 6.2 重置在矩阵乘法前还是后

一种候选写法是 $`n=\tanh(W_nx+U_n(r\odot h)+b_n)`$；PyTorch 的候选写法则是

```math
n=\tanh(W_{in}x+b_{in}+r\odot(U_nh+b_{hn})).
```

前者先按输入状态维度筛选，再由矩阵混合；后者先混合，再按候选维度筛选，同时循环偏置也被重置门缩放。一般矩阵 $`U_n`$ 与对角门矩阵不交换，故二者不是简单调换代码顺序的等价实现。即使前向维度完全相同，也可能计算不同函数。

当 $`U_n`$ 是对角矩阵并且偏置处理兼容时，部分差异可以消失；重置门所有维度都恰好相同也是特殊情形。但一般稠密模型不满足这些条件。迁移权重时应把候选的重置位置与偏置一起核对，不能只检查门顺序。最稳妥的方法是用非对角循环矩阵和不相等门值构造一个小反例。

<a id="rnn-2-detail-23"></a>
### 6.3 直接插值与候选反馈的分工

重置门调节生成候选时旧状态参与的程度，更新门调节候选最终写入多少。重置门很小并不自动清空当前状态，因为更新门可能仍大量保留旧状态；更新门很小也不表示完全无历史，因为候选可以通过循环支路读取旧状态。解释门功能必须沿完整表达式追踪，而不是把两个门各自当独立语义开关。

这类条件路径能让模型在边界事件处快速改变表示，也能在重复背景中近似保持。但门值与现实概念的对应关系通常不是唯一的。通过隐藏坐标重排、候选缩放或其他参数变化，多个内部组织都可能实现近似相同的输入输出行为。研究解释性时应验证干预结果，而不只选择一张符合直觉的门热图。

沿图中两行分别追踪真实中间向量。门矩阵 $`D=\mathrm{diag}(0.2,0.8)`$ 沿当前坐标轴缩放，混合矩阵 $`U`$ 则组合两个坐标。上行先缩放再混合，末向量两个分量都为负。下行先混合，第一分量恰好相消为零，随后缩放仍保留这个零。

**先保留插值约定，再检查候选如何产生。** 若旧状态为二、候选为负一、保留系数为 0.75，直接插值仍为 $`0.75\times2+0.25\times(-1)=1.25`$。但候选不是一个可以随意给定后忽略实现的常数；下面的对照解释同一组权重为什么可能产生不同候选。

图与第 8 节代码使用完全相同的 $`U=\begin{bmatrix}1&2\\3&4\end{bmatrix}`$、$`h=(2,-1)^\top`$ 与 $`r=(0.2,0.8)^\top`$。先重置输入坐标，得到 $`r\odot h=(0.4,-0.8)^\top`$，再混合得到 $`U(r\odot h)=(-1.2,-2)^\top`$；先混合则有 $`Uh=(0,2)^\top`$，再重置得到 $`r\odot(Uh)=(0,1.6)^\top`$。两行的门系数逐项相同，改变的只是它筛选输入坐标还是混合后的候选坐标，结果却连符号都不同。

图只画候选的循环线性部分，省略输入项、偏置和 tanh，以隔离矩阵不交换这一原因。若两者后续都通过 tanh，仍分别得到约 $`(-0.8337,-0.9640)`$ 与 $`(0,0.9217)`$，不会自动恢复等价。实际重置后 GRU 还把循环候选偏置放在门内，迁移权重时应继续核对，不能用这个无偏置反例代替全部计算。它证明一般不等价，不给出两种架构的任务性能排名。

<a id="rnn-2-detail-24"></a>
## 7. GRU 的完整导数与实现差异

<a id="rnn-2-detail-25"></a>
### 7.1 更新门项不能遗漏

记旧状态为 $`h`$，候选为 $`n(h)`$，更新门为 $`z(h)`$，则

```math
\begin{aligned}
&\frac{\partial h'}{\partial h}=\mathrm{diag}(z)
+\mathrm{diag}(h-n)\frac{\partial z}{\partial h}\\
&\quad +\mathrm{diag}(1-z)\frac{\partial n}{\partial h}.
\end{aligned}
```

第一项是直接保留路径，第二项来自插值系数的变化，第三项来自候选变化。如果只保留第一项，就与对 LSTM 只看遗忘门犯了同一类错误。即使前向是凸组合，选择组合权重的函数也可能对输入非常敏感，因而整体导数可以放大。

<a id="rnn-2-detail-26"></a>
### 7.2 按重置后约定继续求候选导数

设 $`a=U_nh+b_{hn}`$，$`r=\sigma(U_rh+\text{输入项})`$，则

```math
\begin{aligned}
&\frac{\partial n}{\partial h}=\mathrm{diag}(1-n^2)\\
&\cdot\left[\begin{aligned}
&\mathrm{diag}(r)U_n\\
&+\mathrm{diag}(a)\mathrm{diag}(r(1-r))U_r
\end{aligned}\right].
\end{aligned}
```

第一项是在固定重置门时通过循环线性支路传播，第二项是重置门自身随旧状态变化的贡献。若使用重置前约定，矩阵乘法位置会不同，导数也应重新写。这个推导既能用于解释长期灵敏度，也能帮助排查手写 GRU 前向相同但反向不正确的自定义算子。

<a id="rnn-2-detail-27"></a>
### 7.3 偏置不是可以随便合并的细节

更新门和重置门的输入、循环偏置直接相加，因此只看前向时可合并；但候选的循环偏置在重置门内部，输入偏置在外部，一般不能合并成一个固定偏置。若 $`r`$ 随样本变化，$`b_{in}+r\odot b_{hn}`$ 也随样本变化。忽略这一点会让权重迁移在部分输入上看似接近，却无法对全部输入等价。

同样，修改框架的`bias=False`不只是移除一个常数项，而是移除多组门的偏置与候选循环偏置调节能力。比较有无偏置时应重新计算参数量和初始化条件。若实验只是想固定遗忘或更新门起始时间尺度，应在实际参数化下写出有效预激活，而不是凭变量名猜测。

## 8. 实验二：GRU 全导数核对与不交换反例

<a id="rnn-2-detail-29"></a>
### 8.1 用库实现验证约定

实验先按重置、更新、候选的拼接顺序手写 GRU，比较前向和输入、旧状态、四组参数的导数。随后用二乘二矩阵直接比较“先门再混合”和“先混合再门”，给出可以复现的非等价证据。两部分不依赖网络训练是否收敛。

```python
import torch
from torch import nn

torch.set_num_threads(1)
torch.manual_seed(31)
cell = nn.GRUCell(2, 3).double()
x = torch.randn(2, 2, dtype=torch.double, requires_grad=True)
h = torch.randn(2, 3, dtype=torch.double, requires_grad=True)
params = list(cell.parameters())
y = cell(x, h)
expected = torch.autograd.grad(y.square().sum(), [x, h, *params])
xx, hh = [a.detach().clone().requires_grad_() for a in (x, h)]
weights = [a.detach().clone().requires_grad_() for a in params]
wi, wh, bi, bh = weights
ir, iz, inn = (xx @ wi.T + bi).chunk(3, dim=-1)
hr, hz, hnn = (hh @ wh.T + bh).chunk(3, dim=-1)
r, z = (ir + hr).sigmoid(), (iz + hz).sigmoid()
n = (inn + r * hnn).tanh()
manual = (1 - z) * n + z * hh
actual = torch.autograd.grad(manual.square().sum(), [xx, hh, *weights])
assert torch.allclose(manual, y, atol=1e-12, rtol=1e-12)
for a, b in zip(actual, expected):
    assert torch.allclose(a, b, atol=1e-11, rtol=1e-11)

u = torch.tensor([[1.0, 2.0], [3.0, 4.0]], dtype=torch.double)
old = torch.tensor([2.0, -1.0], dtype=torch.double)
reset = torch.tensor([0.2, 0.8], dtype=torch.double)
before = u @ (reset * old)
after = reset * (u @ old)
assert torch.allclose(before, torch.tensor([-1.2, -2.0], dtype=torch.double))
assert torch.allclose(after, torch.tensor([0.0, 1.6], dtype=torch.double))
assert not torch.allclose(before, after)
print('GRU six derivative groups agree; reset placements differ')
```

<a id="rnn-2-detail-30"></a>
### 8.2 看到差异以后应该怎样比较模型

反例只说明两类候选一般不完全等价，并不证明哪类对某个任务更好。性能比较需要各自训练、控制预算并固定评价条件。若目标是迁移现成权重，应优先实现原模型方程；若目标是研究结构，则可把两种约定作为明确的架构变量。不要用迁移后的性能下降直接推断原模型的表示能力不足。

当两个实现数值差异很小，也不应立刻接受等价。测试输入可能让重置门各维接近相同，或循环矩阵偶然近似对角。应故意选择能激活差异的非对角权重、不同门值和非零循环候选偏置。好的测试不只是随机生成更多输入，而是把理论上的不等价机制转成能够触发的样例。

## 9. 实验三：半衰期与完整雅可比反例

<a id="rnn-2-detail-32"></a>
### 9.1 把“门接近一”的口头判断数量化

本实验计算三个固定遗忘率的半衰期，再用自动微分核对正文二元状态雅可比。最后比较只看单元直接路径的 $`0.99^{10}`$ 与完整状态扰动的十步传播。所有值在零状态附近计算，展示的是局部线性灵敏度，不宣称非线性有限幅轨迹会无界增长。

```python
import math
import torch

torch.set_num_threads(1)
for forget in (0.9, 0.99, 0.999):
    half = math.log(0.5) / math.log(forget)
    assert abs(forget ** half - 0.5) < 1e-12
    print('forget', forget, 'half-life', round(half, 3))

def transition(state):
    c, h = state.unbind()
    new_c = 0.99 * c + 0.5 * torch.tanh(8.0 * h)
    new_h = 0.5 * torch.tanh(new_c)
    return torch.stack((new_c, new_h))

zero = torch.zeros(2, dtype=torch.double, requires_grad=True)
jacobian = torch.autograd.functional.jacobian(transition, zero)
expected = torch.tensor([[0.99, 4.0], [0.495, 2.0]], dtype=torch.double)
assert torch.allclose(jacobian, expected, atol=1e-12, rtol=1e-12)
eigen = torch.linalg.eigvals(jacobian).abs().max()
assert torch.allclose(eigen, torch.tensor(2.99, dtype=torch.double))
v = torch.tensor([1.0, 0.5], dtype=torch.double)
propagated = torch.linalg.matrix_power(jacobian, 10) @ v
assert torch.linalg.vector_norm(propagated) > 10000
assert 0.99 ** 10 < 1
print('full-state spectral radius', float(eigen), 'direct cell factor', 0.99 ** 10)
```

<a id="rnn-2-detail-33"></a>
### 9.2 局部放大与全局有界如何同时成立

这个单元的隐藏输出始终被 tanh 限制，固定遗忘率小于一且候选有界时，单元状态也有有限范围。但零点附近的无穷小扰动仍会先指数放大，之后离开线性区而受到非线性限制。局部导数大与全局函数值有界并不矛盾，正如陡峭的 sigmoid 可以取值有界却在局部非常敏感。

若想把雅可比乘积与有限差分核对，应使用足够小的扰动并扫描幅度，确认仍处于线性近似区。对很长时间直接使用较大初始扰动，得到的有限幅差异可能早已饱和，不再等于导数预测。把两种测量混用，会导致错误地宣称自动微分或稳定性分析失效。

<a id="visual-mechanism-rnn-02"></a>

### 图解：遗忘系数决定直接记忆路径的半衰期

![门值零点九和零点五对应首次保留不超过一半的步数分别为七和一](images/02-forget-gate-determines-the-first-integer-half-life.webp)

[打开原图放大](images/02-forget-gate-determines-the-first-integer-half-life.webp)

**图中的机制。** 只看固定遗忘系数的直接细胞路径，旧信号经过 k 步后乘以系数的 k 次方。图比较 0.9 与 0.5：前者约七步降至一半附近，后者一步就减半。门值接近一会延长这条直接路径的记忆尺度。

**条件与边界。** 完整 LSTM 导数还包括门值依赖旧状态的间接项，完整状态雅可比与实际可读记忆还需要考虑这些反馈。

**把半衰期落实到整数步。** 对固定 $`f=0.9`$，连续插值解为 $`k_{\frac12}=\frac{\log(\frac12)}{\log(0.9)}\approx6.579`$；实际离散更新在第六步还保留 $`0.531441`$，第七步为 $`0.4782969`$，所以第一次不超过一半发生在第七步。若要求第 100 步仍保留至少一半，必须有 $`f^{100}\ge\frac12`$，即 $`f\ge 2^{-\frac{1}{100}}\approx0.9930925`$。忽略其他输入项、用 sigmoid 偏置产生此固定门值时，对应有效偏置至少约 $`4.9682`$；这给的是直接保留路径的条件，不是完整网络可读记忆的保证。

## 10. 门控诊断、初始化与优化

<a id="rnn-2-detail-35"></a>
### 10.1 该记录哪些量

除了训练损失，建议记录各门分位数、单元状态幅值、候选饱和比例、最早输入梯度、裁剪前范数与实际参数更新范数。门的均值可能掩盖不同样本上的两极化：平均为一半，可能是所有值都在一半，也可能是一半接近零、一半接近一。两种情况对梯度和行为的含义不同，至少应补充分布或条件分组。

诊断必须和任务事件对齐。若门在边界附近变化，应检验打乱边界标记后行为是否变化，或在保持其他输入不变时干预门支路。仅凭相关图无法确定门实现了你期待的语义。对于强相关输入，多个门组织都可能产生类似输出，应把解释作为待验证假设，而不是结构名称赋予的事实。

<a id="rnn-2-detail-36"></a>
### 10.2 初始化时间尺度与可学习性

较大的遗忘偏置可让直接保留路径在开始时较长，但也让 sigmoid 导数较小，门参数变化可能更慢。若任务本来需要快速遗忘，初始化过强保留会增加适应负担。可以在合理范围内比较不同起始时间尺度，同时固定随机种子与其他配置，观察长短跨度性能，而非只看最终训练损失。

门控并不免除输入尺度处理。极大的输入会让多个门一起饱和，模型可能几乎变成固定切换规则；不同单位的传感器也可能主导预激活。标准化应只拟合训练数据，并保存部署时一致的变换。缺失值、时间间隔与异常裁剪都属于输入协议，需要在训练和推理保持相同语义。

<a id="rnn-2-detail-37"></a>
### 10.3 正则化位置需要说明

对循环权重做衰减、对层间输出做 dropout、对时间上共享或不共享的掩码做 dropout，会产生不同随机过程。不能笼统写“LSTM dropout 为零点二”就假定读者知道它作用在哪里。某些库的多层循环 dropout 只作用在层间，不等于对每一步状态转移自动应用同样的机制。

如果对隐藏状态直接独立随机置零，可能破坏时间保留路径；共享时间掩码又是另一种约定。是否有益依赖任务和训练协议，应先核对实现，再比较结果。训练态与评价态必须切换正确，但关闭 dropout 并不会自动修正状态泄漏、填充污染或未来信息使用，这些属于独立边界。

## 11. 多层、双向与投影状态

<a id="rnn-2-detail-39"></a>
### 11.1 层轴和方向轴不能混成时间轴

标准批量序列常用输入形状 $`(B,T,d)`$，但多层隐藏状态仍常以 $`(LD,B,m)`$ 组织，其中 $`L`$ 为层数，$`D`$ 为方向数。`batch_first`改的是序列输入输出轴，不意味着状态张量也变成批量在最前。把状态`view`成另一个形状前，应明确层与方向在第一个轴上的排列。

多层网络中，下层当前输出成为上层同一时刻输入，时间递归则在同一层连接前后时刻。反向传播同时沿层深和时间深展开。若研究长距离困难，应控制层数和监督位置，否则观察到的梯度变化可能混合两种深度效应。小例子中分别改变层数和时间长度，是理解二者差异的好办法。

<a id="rnn-2-detail-40"></a>
### 11.2 双向读出的真实语义

双向网络的前向状态读到当前位置以前的信息，反向状态读到当前位置以后的信息。完整句子已经可见时，双向标注通常合法；实时逐点预测未来时，读取预测时点以后的观测就不合法。但若整个历史窗口在预测起点前已完整到达，在窗口内部双向编码仍可能合法。判断依据是可见信息，而不是“使用双向一定泄漏”的口号。

输出最后时间位置中，前向部分接近前向终态，反向部分只对应其在该位置的反向进度，不一般等于反向读取完整序列后的终态。做整序列摘要时，应按方向和真实长度获取正确终态。使用填充时还要确保反向路径没有把无效尾部当真实输入。第 4 章会用打包与逐样本核对具体处理。

<a id="rnn-2-detail-41"></a>
### 11.3 投影 LSTM 改变什么

投影结构让内部单元状态保持较大维度，再把隐藏输出映射到较小维度，用于减少循环连接和输出成本。此时 $`c`$ 的维度与 $`h`$ 不同，门的循环输入来自投影后隐藏输出，状态接口和参数公式都随之变化。不能把标准 LSTM 的隐藏维、单元维和输出维在代码里全部写成同一个数。

投影可能在某些预算下提供更大内部记忆，但也引入读出瓶颈与额外矩阵。比较时应明确优化的是参数、计算、延迟还是精度，不能只把内部单元维增加后宣布“同大小模型更好”。模型结构图需要同时标出每条边的维度，尤其在多层和双向组合时，下一层输入维度由输出方向与投影共同决定。

<a id="rnn-2-detail-42"></a>
## 12. 参数预算、计算与基线比较

<a id="rnn-2-detail-43"></a>
### 12.1 标准单层参数量逐项算

对于输入维 $`d`$、隐藏维 $`m`$，每组门有 $`md`$ 个输入权重、$`m^2`$ 个循环权重和两组各 $`m`$ 个偏置。因而标准有偏置实现中，普通 RNN 为 $`m(d+m+2)`$，GRU 为其三倍，LSTM 为其四倍。输出头、嵌入、投影、多层和双向应另外计算，不能把单层公式直接套整个模型。

例如 $`d=10,m=20`$ 时，单组参数为六百四十，GRU 为一千九百二十，LSTM 为二千五百六十。相同隐藏维下，三者的参数预算不同；但把隐藏维调到参数量相近，也不保证激活内存、矩阵效率和状态带宽相同。报告应列出实际`numel`统计与主要张量大小，而不是只提供一个名称和隐藏维。

<a id="rnn-2-detail-44"></a>
### 12.2 相同训练轮数未必公平

不同模型每步计算量不同，序列打包后有效 token 数又可能不同。相同轮数比较反映固定数据遍历预算，相同优化步数反映另一种条件，相同墙钟时间则受硬件与内核影响。可以围绕部署最关心的约束选主要协议，再补充其他成本，使读者知道优势是否来自更高预算。

超参数搜索也属于计算预算。若对一个模型尝试二十组学习率，却只对另一个用默认值，最终差异混合了结构与搜索投入。应固定验证集、预先说明搜索范围，并保留独立测试。人工序列任务中尤其容易因为多次查看同一测试长度而过度调整，应把探索性长度与最终外推验证分开。

<a id="rnn-2-detail-45"></a>
### 12.3 简单基线必须对应目标

时间预测至少可比较最后值、季节重复、线性滞后回归和小前馈窗口网络；序列分类可比较池化统计与固定窗口；复制或计数任务则可比较明确算法。基线不仅是争取低分，还帮助判断数据是否真的要求复杂历史。如果仅当前输入就达到类似成绩，门控网络的长记忆叙事就缺乏证据。

比较性能时还应看延迟、状态大小、冷启动、缺失间隔和长尾长度。在短平均序列上快速的实现，可能在少量超长请求上导致难以接受的尾延迟。门控状态较小有利于流式处理，但模型服务仍要管理实体状态、版本与过期规则。算法指标与系统边界需要一起写进模型说明。

<a id="rnn-2-detail-63"></a>
## 13. 研究路线与应用决策

<a id="rnn-2-detail-64"></a>
### 13.1 把记忆分解成写入、保留与读出

设计人工任务时，可分别要求网络在标记出现时写入，在很长背景后保持，在查询时读出。通过独立改变三段长度与干扰强度，能辨别失败发生在哪个环节。若写入就失败，增加延迟只会混淆问题；若状态探针还能解码而最终输出错误，则更应检查读出与监督，而非立即判定记忆已被遗忘。

可以增加需要主动清除的阶段，考察门是否会根据事件切换时间尺度；也可以把同一符号在不同上下文赋予不同保留价值，避免模型使用固定衰减完成任务。训练和测试应让符号、长度、边界位置尽量独立，并保留只看当前输入、只看长度等捷径基线，确保复杂结构确实在解决目标问题。

<a id="rnn-2-detail-65"></a>
### 13.2 从机制实验走向真实序列

真实数据包含缺失、乱序、不同采样间隔与实体迁移，门控不会自动赋予时间语义。若每步间隔不同，相同遗忘门对应的物理半衰期也不同。可以把间隔输入网络，或设计与时间相关的状态衰减，但无论哪种方案，都需要明确零间隔、长间隔与异常时钟的行为。把记录序号当成真实时间，可能让模型在换采样频率后失效。

当状态被长期缓存到服务中，还要定义模型版本升级后的状态兼容性。新模型的隐藏坐标可能与旧模型不同，不能仅凭维度相同就复用旧缓存。可以重置、热身重建或设计明确迁移机制，并按业务允许的冷启动成本评价。状态是模型内部表示，不是天然跨版本稳定的数据格式。

<a id="rnn-2-detail-66"></a>
### 13.3 从循环单元到编码解码器

下一章把这些单元放进编码器与解码器，研究训练条件概率、注意力读出和生成搜索。届时 LSTM 或 GRU 只是状态更新模块，整个系统能否正确学习与评价，还取决于目标右移、源端掩码、停止符与实际自由解码。理解本章的全依赖分析方式，比记住某种结构在排行榜上的名次更有长久价值。

<a id="rnn-2-detail-67"></a>
## 14. 进阶推导：门控、残差与连续时间尺度

<a id="rnn-2-detail-68"></a>
### 14.1 GRU 可以写成可变步长残差更新

将更新式重排为 $`h_t-h_{t-1}=(1-z_t)\odot(n_t-h_{t-1})`$。这显示每一维的变化量等于“当前候选与旧状态的差”乘一个自适应步长。若候选与旧状态恰好相同，即使更新门很小，状态也不变；若二者差异很大，较小的写入比例也可能造成明显变化。因此仅观察门值，不能直接推断实际状态变化量。

对比残差网络 $`h'=h+F(h)`$，GRU 使用受约束的系数调节指向候选的更新，但候选和系数都依赖输入与状态。它不是简单地在普通残差层前加一个常数。前向恒等路径有助于保留，但全导数仍包含更新方向与步长对状态的变化率。残差连接和门控的联系有助于形成直觉，也更要求区分固定系数分析与真实学习系统。

在实验里可以同时画出门值、候选差值与二者乘积，检验是哪一项决定状态变化。若门看起来接近零但候选等于旧状态，就没有实际重置；若门变化明显而候选差值很小，也不应宣称发生了大规模记忆改写。把乘法两侧一同记录，通常比解释单独一条门曲线更准确。

<a id="rnn-2-detail-69"></a>
### 14.2 从离散保留率推导物理时间常数

连续衰减方程 $`\frac{dc}{dt}=-\frac{c}{\tau}`$ 在相隔 $`\Delta t`$ 的两个时刻满足 $`c(t+\Delta t)=\exp(-\frac{\Delta t}{\tau})c(t)`$。因此若希望遗忘系数具有明确物理时间解释，可以令 $`f=\exp(-\frac{\Delta t}{\tau})`$，其中 $`\tau>0`$。在固定采样间隔下，它与常数遗忘门相联系；采样间隔变化时，固定离散门值就不再对应固定物理寿命。

若两段间隔分别为 $`\Delta t_1,\Delta t_2`$，这种指数衰减满足乘积等于总间隔的衰减，是一致的时间分割性质。但实际 LSTM 的门由输入与状态产生，不必满足这种半群关系，所以把一条记录插值成两条可能改变结果。模型是否应满足时间分割不变性，取决于任务和观测含义，需要主动规定，不能指望门控自动学出。

若把可学习时间常数参数化为正数，还需检查极小常数导致的快速下溢、零间隔的处理和时间单位。秒换成小时却不相应变换时间常数，会改变模型。这样的单位测试适合变成可执行断言：相同物理间隔用不同单位表示，经过规范化后应产生一致结果。结构上加入时间变量，不等于自动解决数据时间戳质量问题。

#### 用不规则时钟检验“每步”的单位

![真实间隔不同的四个观测时刻，对照按时间衰减与按记录衰减](images/02-decay-using-elapsed-time-versus-observation-count.webp)

[打开原图放大](images/02-decay-using-elapsed-time-versus-observation-count.webp)

设没有新内容写入，初始记忆为一，记录时刻为零、一、四、五小时。选择每小时保留率 $`0.8`$，相应时间常数是 $`\tau=-\frac1{\ln0.8}\approx4.48142`$ 小时。按真实间隔更新，四个时点的状态为

```math
1,\quad0.8,\quad0.8^4=0.4096,\quad0.8^5=0.32768.
```

若忽略间隔、每到一条记录只乘一次 $`0.8`$，状态则为 $`1,0.8,0.64,0.512`$。区别在一到四小时之间首次出现：这个跨度有三小时，不能只算成一个单位时间。表中第一行由连续时间指数衰减在记录时刻取值得到，第二行只在记录到达时乘门值。普通 LSTM 是否在调用间隙更新，需要由模型另行定义。

还能做一个分割不变量检查。在一到四小时之间补两个**不新增内容、仅推进时钟**的中间节点，按时间的三段乘积为 $`0.8\times0.8\times0.8=0.8^3`$，与直接跨三小时一致；固定“每条一次”的规则却因节点数改变而改变结果。这个检查只适用于假设中的纯衰减子过程，不要求包含真实新观测、非线性门和写入的完整网络也对任意插值不变。秒与小时转换时，$`\Delta t`$ 和 $`\tau`$ 必须同时换单位。

<a id="rnn-2-detail-70"></a>

### 14.3 写入尺度与遗忘尺度相互作用

考虑 $`c_t=fc_{t-1}+u_t`$。若 $`u_t`$ 是均值为零、方差为 $`\sigma_u^2`$ 的独立输入，且与历史独立，稳定时方差为 $`\frac{\sigma_u^2}{(1-f^2)}`$。当 $`f`$ 越接近一，记忆更长，但累积状态方差也越大。这是固定线性条件下的精确关系，解释了为什么延长记忆常常需要同时控制写入尺度，而不是单独增大遗忘偏置。

若写入带非零均值 $`\mu_u`$，稳定均值为 $`\frac{\mu_u}{(1-f)}`$，增长更加显著。真实门控中写入和旧状态通常相关，不能直接套这些方差公式，但可以把它们作为诊断参照：观察均值漂移、状态方差和读出饱和是否随高保留率一起出现。若出现，就应检查候选中心化、输入标准化与学习目标，而非只增加梯度裁剪。

这也说明“候选都在负一到一，所以状态一定很小”是错误的。候选有界只限制单步写入，持续保留可以把很多小写入累积起来。标准 LSTM 的单元状态没有隐藏输出那样的直接 tanh 范围约束。要给出全局状态界，还需要对遗忘率上界、写入幅度和初态作额外假设。

<a id="rnn-2-detail-71"></a>
### 14.4 输入门与遗忘门耦合会改变什么

若强制 $`i_t=1-f_t`$，单元更新变成旧状态与候选的逐维凸组合，省去独立输入门的一部分参数与自由度。这样限制可减少同时大量保留和大量写入导致的累积，也可能削弱需要独立控制两者的任务表达。它是一种明确的结构变体，而非标准 LSTM 可以默认成立的恒等关系。

固定同样的 $`f`$ 和候选时，耦合与非耦合结构可以产生完全不同的状态尺度。比较两者必须重新考虑初始化和参数预算，而不是只删除一组参数后沿用所有解释。若任务只是平滑跟踪，凸组合的归纳偏好可能合理；若任务需要累计计数，则需要研究它如何通过别的动态近似完成，不能从相同输出维就断言能力相同。

<a id="rnn-2-detail-72"></a>
### 14.5 门参数为何可能很难改变

对一个门预激活 $`a`$，sigmoid 导数为 $`\sigma(a)(1-\sigma(a))`$。无论门值接近零还是一，这个导数都很小。若损失要求门从一种饱和行为切换到另一种，必须先通过很小的局部导数更新其参数。较大循环权重又可能使预激活对隐藏状态很敏感，两种尺度同时存在，造成优化上的不均匀性。

因此门饱和既可能是已学到的离散决策近似，也可能是输入尺度或初始化造成的学习障碍。区分它们需要观察训练前后变化、条件性能与可控扰动，而不只是看门是否“很明确”。若训练刚开始所有样本都极端饱和，同时小数据无法拟合，应优先排查尺度和偏置；若训练后只在明确事件处饱和，且干预符合预期，则有更多支持其功能的证据。

<a id="rnn-2-detail-73"></a>
### 14.6 参数共享使语义解释并不唯一

把隐藏坐标按同一置换重排，同时相应重排全部门、循环矩阵与输出头，可以保持整体输入输出函数。由此，单元编号本身没有跨训练运行的天然语义。同一个任务在不同初始化下，可能把相似信息分配到不同维度，甚至以分布式方式表示。不能把某次训练的第七维直接当作所有模型共有的“记忆年龄单元”。

比较表示时可以关注可读出子空间、任务相关干预或适当对齐后的关系，但每种方法都有假设。线性对齐无法证明因果等价，探针高分也不说明下游模型实际使用该信息。教学中展示某个维度的直观行为很有价值，只要把它作为一个具体实现例子，而不是结构保证的固定解释。

<a id="rnn-2-detail-74"></a>
### 14.7 记忆准确性还受到数值精度限制

理论上一个实数可以编码很多信息，但实际张量使用有限精度。长期累加很小的写入时，若当前状态幅值很大，小增量可能被舍入；高保留率反复乘法也会累计误差。精确计数、栈操作或长串复制若依赖越来越精细的状态间隔，长度外推时可能因数值分辨率不足而失效，即使训练分布上看似完美。

可以比较不同精度、状态幅值与输入长度，观察错误是否在某个尺度出现，并分析它属于表示方案还是训练优化。双精度通过不等于低精度部署也通过；相反，低精度失败也不一定说明递归算法本身不成立。评价应与部署精度一致，同时用高精度小实验帮助区分舍入误差与计算图错误。

<a id="rnn-2-detail-75"></a>
### 14.8 从理论反例到负责任的模型结论

本章的反例分别针对特定错误推理：遗忘门上界不能控制完整雅可比，凸组合不能控制全导数，重置位置不能随意交换。它们不建立 LSTM 或 GRU 的普遍优劣排名。真正的应用结论必须把任务、数据分布、预算、精度与评价条件一同写出，说明证据覆盖哪一类使用情境。

若一种模型在某项人工记忆任务中更容易优化，应报告随机初始化成功率与训练预算；若在真实预测中更准，应报告独立时间段和实体分组；若宣称实时优势，应在目标设备或可比环境测量延迟。理论、实现和经验各自回答不同问题，只有把三者边界接清楚，读者才知道哪些结论可以迁移，哪些需要重新验证。

<a id="rnn-2-detail-76"></a>
## 15. 反向计算清单：从损失回到四组门

<a id="rnn-2-detail-77"></a>
### 15.1 单步伴随递推不能遗漏两条状态输入

设后续计算传回新隐藏输出的梯度为 $`\bar h`$，传回新单元状态的梯度为 $`\bar c`$，其中横线仅表示反向伴随量，不是平均。先把隐藏读出支路并入单元伴随：$`d_c=\bar c+\bar h\odot o\odot(1-\tanh^2c)`$。输出门的预激活梯度为 $`d_o=\bar h\odot\tanh(c)\odot o\odot(1-o)`$。顺序很重要：若先计算单元各门梯度再忘记加入隐藏读出，就会丢失主要训练信号。

接着有 $`d_f=d_c\odot c_{prev}\odot f\odot(1-f)`$，$`d_i=d_c\odot g\odot i\odot(1-i)`$，以及 $`d_g=d_c\odot i\odot(1-g^2)`$。这里每个 $`d`$ 都已经是相应预激活的梯度，不能再额外乘一次激活导数。输入梯度由四组输入矩阵转置乘相应 $`d`$ 相加，旧隐藏输出梯度由四组循环矩阵转置乘相应 $`d`$ 相加。

旧单元状态收到直接贡献 $`d_c\odot f`$。在标准无窥孔单元的局部坐标中，这就是对应输入支路；旧隐藏输出则收到门与候选的全部反馈。跨时间继续递推时，两条伴随量在上一单元再次汇合。若只传递单元伴随而忽略隐藏伴随，就相当于人为冻结了部分门控制路径，得到的不会是完整 BPTT。

<a id="rnn-2-detail-78"></a>
### 15.2 参数梯度与批量求和

每组输入矩阵的局部梯度是 $`d_kx^T`$，循环矩阵为 $`d_kh_{prev}^T`$，偏置为 $`d_k`$；跨时间和样本按总损失定义累积。批量行向量实现通常形成`d.T @ x`和`d.T @ h_prev`。若损失已在有效 token 上平均，就不要在手动累积时重复除以序列长度，否则会额外改变梯度尺度。

这个清单可以用于检查自定义单元反向，也可以帮助理解自动微分结果。应先在单步随机双精度输入上核对所有输入和参数，再把单元串联成短序列，确认共享参数贡献累积正确。若矩阵梯度正确而偏置梯度错误，优先检查批量求和轴；若后期梯度正确而初态错误，优先检查状态传递与 detach，而非盲目放宽误差容忍度。

<a id="rnn-2-detail-79"></a>
### 15.3 为什么需要保留中间门值

反向计算需要前向的门、候选、单元值与旧状态。框架可以保存这些中间量，也可以在检查点策略下重计算。保存量随时间与批量增长，是长序列训练内存的重要来源。把这些张量从计算图中 detach 后再用于自定义反向，并不自动构成错误，但必须由你准确补齐全部导数；仅返回看起来合理的梯度是不够的。

因此学习门控单元时，最有用的最终检查是同时写出前向计算图、局部雅可比和反向伴随递推，并让三者在小实验中一致。它们是同一链式法则的不同计算视角。能在这三个视角之间转换，才能判断后续注意力、投影或归一化支路究竟增加了哪条依赖，而不依赖对某个框架内部实现的模糊印象。

另一个实用检查是让损失只依赖新单元状态，再让它只依赖新隐藏输出，分别确认两种伴随入口。前者能突出直接保留和写入支路，后者能检验输出门与读出非线性。最后把两个损失相加，完整梯度应等于分别求导结果之和，这是固定同一前向轨迹下梯度线性的直接体现。若加入随机层，三次前向必须共享相同随机条件，否则这个比较混入函数变化。

对于实际交付，应该保存模型配置中的门约定、投影设置、层数、方向与归一化规则。仅有权重张量和隐藏维度不足以恢复真实计算。即使文件成功加载，也需运行一组具有明确输入、初态与预期输出的参考样例，确认状态顺序和数值一致。这样才能把本章的数学核对延伸为可靠的模型迁移与部署验证。
