# Transformer

在注意力运算之上理解完整网络块、位置编码、训练目标与自回归推理。

**先修知识：** 注意力机制、LayerNorm、神经网络训练。

## 学习顺序与覆盖范围

第 1 章先把注意力、残差与归一化组成完整网络块，第 2 章沿解码器路线推导训练右移、自由生成和缓存；理解这两章后即可进入[语言建模](../../AI-Domains/LargeLanguageModels/01-分词预训练与语言建模.md)。第 3 章另用完整编码器—解码器实践检验三类注意力路径，第 4 章再讨论预算和长上下文。编码器—解码器实践与解码器语言模型是两种架构目标，不要求先训练前者才能理解后者。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合研究：共同任务下的训练、推理与长上下文比较](04-训练预算长上下文与推理优化.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
