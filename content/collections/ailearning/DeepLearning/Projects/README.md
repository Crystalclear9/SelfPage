# 深度学习实践项目

完成一个无需外部下载的小型图像分类项目，并练习训练记录、错误分析和消融。

主项目使用 scikit-learn 自带的 digits 手写数字数据，输入为 8×8 灰度图像。第 4 章的新进程续训与接口算例用于检验状态恢复和输入契约，具体任务及划分以该章说明为准，不能把不同算例的指标拼成主项目的一次实验结果。

**先修知识：** PyTorch、CNN、模型评估。

**正文篇幅状态：** 本主题现有 5 章均已按长篇教材标准展开，逐章纯正文达到 12000–20000 汉字。全库进度见[长篇教材覆盖表](../../README.md#textbook-status)。

## 学习顺序与覆盖范围

完成[PyTorch 训练循环](../../Programming/PyTorch/02-完整训练验证与保存.md)与[CNN 第 1—2 章](../CNN/README.md)后即可开始。第 1—2 章建立可运行闭环，第 3 章分析错误，第 4 章补齐恢复与推理契约，第 5 章汇总可比较的实验报告；无需预先掌握 RNN 或 Transformer。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合研究：预设下一轮比较方案](05-消融设计资源比较与项目报告.md#sec-9-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
