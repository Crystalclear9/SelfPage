## 1. 三种机制解决的不是同一个问题

初始化规定参数起点，归一化规定前向函数如何利用一组统计量，残差规定信息和梯度沿哪些路径传播。三者经常一起出现，却不能互相替代。合适初始化不能保证训练后尺度始终稳定；归一化不能消除错误标签或不合适损失；残差提供直连项也不保证所有方向的梯度永远不消失。只有写出各自改变的数学对象，才知道一个观察支持哪种解释。

贯穿本章的问题是：当某层输出变了，究竟是权重起点、统计集合，还是旁路结构改变了它？先用同一个目标样本追踪 BN/LN 的依赖，再回到尺度推导与残差雅可比，就能把“数值更稳定”拆成可检验的机制。

本章从随机初始化的二阶矩出发，进一步研究归一化雅可比与残差谱。公式使用小尺寸向量推导，实验则在 CPU 双精度环境核对，避免设备差异掩盖机制。矩阵求导基础可查[归一化求导](../../Mathematics/MatrixCalculus/03-Softmax交叉熵与归一化求导.md)，模块使用见[PyTorch 资料](../../Programming/PyTorch/README.md)。本章不会把某个框架默认值当作普遍理论常数。

<a id="nnb-3-detail-2"></a>

### 1.1 先区分平均尺度与方向条件

若一层输出每个坐标的平均二阶矩与输入接近，说明整体信号没有在这种平均意义下明显放大或缩小。但一个方向可能扩大十倍，另一个方向缩小十倍，平均统计仍可能看起来尚可。雅可比奇异值刻画不同局部方向的伸缩，条件数刻画最大最小伸缩的差距。深层优化既受平均尺度影响，也受这些方向条件与层间对齐影响。

把层激活强制成均值零、方差接近一，并不等于整个网络雅可比接近正交。归一化本身会去掉某些平移或尺度方向，还通过统计量引入坐标耦合。因此“输出稳定”与“梯度稳定”需要分别验证。研究中应同时记录前向统计、反向统计和实际训练结果，不让一个方便绘制的指标承担全部结论。

## 2. 线性层随机初始化的二阶矩推导

设 $`z_j=\sum_{i=1}^n w_{ij}x_i`$，权重独立同分布、均值零、方差 $`s^2`$，并独立于当前输入。对初始化权重取期望，交叉项因为不同权重均值零而消失，得到 $`\mathbb E[z_j^2]=s^2\sum_i\mathbb E[x_i^2]`$。若每个输入坐标二阶矩相同为 $`q`$，则为 $`ns^2q`$。这里不必先要求输入坐标全部独立，但需要明确期望是在怎样的权重与输入随机性下计算。

条件在某个已经抽定的权重矩阵上，数据坐标相关性会通过 $`W^T\mathrm{Cov}(x)W`$ 影响输出协方差，不能把初始化总体期望等式当作单次小网络每层的精确值。宽度较大时经验统计可能更接近平均预测，但有限宽度、重尾输入和少量样本会带来波动。教材中的蒙特卡洛实验用确定种子与合理容差验证趋势，而不要求随机样本恰好给出理论常数。

<a id="nnb-3-detail-4"></a>

### 2.1 扇入、扇出与权重存储

扇入是一个输出单元接收多少输入，扇出是一个输入单元连向多少输出。对普通全连接层分别为输入维度与输出维度。对二维卷积，扇入还包含每组输入通道数与核面积，分组结构需要考虑每个输出实际接收哪些输入。把通道数直接当全部扇入，会漏掉核大小造成的尺度变化。

数学上用输入乘右侧权重，库内可能存储输出乘输入的转置布局；若自定义初始化函数按错误布局计算扇入扇出，尤其对非方形矩阵，就可能得到相反尺度。方阵测试不容易暴露这种错误，应另外用输入维度与输出维度明显不同的矩阵验证。初始化规则需要和实际乘法约定共同记录，不能只写一个标准差数字。

<a id="nnb-3-detail-5"></a>

### 2.2 Xavier 的折中为什么不是双重精确保证

对近线性层，维持前向尺度倾向于 $`s^2=\frac{1}{n_{in}}`$；在类似独立近似下，维持反向梯度坐标尺度倾向于 $`s^2=\frac{1}{n_{out}}`$。若两者不同，单个方差通常不能同时满足两项，常见 Xavier 方差取 $`\frac{2}{(n_{in}+n_{out})}`$ 作为折中。其均匀分布版本若区间为 $`[-a,a]`$，由方差 $`\frac{a^2}{3}`$ 得到 $`a=\sqrt{\frac{6}{(n_{in}+n_{out})}}`$。

这种折中并不是说每条样本前向方差与每个参数反向方差都精确恒定。激活函数非线性、坐标相关、有限宽度和训练更新都会改变条件。合理使用方式是把它作为起始尺度选择，再观察真实网络，而不是当成无需诊断的训练保证。对 tanh 等激活，还可能根据近原点斜率或经验采用增益，但应写清具体增益如何进入方差。

<a id="nnb-3-detail-6"></a>

## 3. He 初始化与整流激活的非零均值

若预激活 $`z`$ 关于零对称，ReLU 保留正半轴并截断负半轴，因此 $`\mathbb E[\mathrm{ReLU}(z)^2]=\frac{\mathbb E[z^2]}{2}`$。为了使整流后的二阶矩与前层输入近似相同，令权重方差 $`s^2=\frac{2}{n_{in}}`$。对负半轴斜率为 $`a`$ 的泄漏整流，对称分布下二阶矩因子变为 $`\frac{(1+a^2)}{2}`$，于是前向方差尺度为 $`\frac{2}{[(1+a^2)n_{in}]}`$。

强调二阶矩十分必要。若 $`z`$ 为均值零、方差 $`v`$ 的高斯变量，ReLU 输出均值为 $`\sqrt{\frac{v}{(2\pi)}}`$，中心化方差为 $`\frac{v}{2}-\frac{v}{(2\pi)}`$，并不等于 $`\frac{v}{2}`$。下一层使用零均值独立权重时，自然出现输入二阶矩，因此推导仍可衔接；若直接把 ReLU 输出也当成零均值，就错误混淆了两个统计量。

<a id="nnb-3-detail-7"></a>

### 3.1 对称性被破坏时会发生什么

若偏置强烈为正，大部分预激活为正，ReLU 不再仅保留一半二阶矩，He 系数可能使输出放大。若偏置很负，活动率很小，输出和梯度可能明显缩小。输入重尾、门控结构或归一化偏移也会改变分布。初始化公式无法脱离激活分布使用，尤其不适合在整个网络所有参数上机械套同一种正态标准差。

随机权重打破隐藏单元对称，并不要求所有偏置随机。归一化层常使用缩放一、偏移零作为清晰起点；某些残差末端使用零缩放，让初始块更接近恒等。它们在整张图中的梯度路径不同于把所有隐藏权重全设零。判断初始化是否可学习，应逐层检查最初哪些参数收到梯度，以及对称何时能够被打破。

<a id="nnb-3-detail-8"></a>

### 3.2 实验一：二阶矩与中心方差分别核对

下列实验生成二十万个固定种子的标准正态数，验证整流后的二阶矩和非零均值，并比较普通 $`\frac{1}{n}`$ 方差与 He 方差在一个宽线性层后的输出二阶矩。容差依据有限随机样本设定，实验只支持这组独立高斯条件，不声称训练后的所有分布都如此。

```python
import math
import torch

torch.set_num_threads(1)
gen = torch.Generator().manual_seed(31)
dtype = torch.float64
z = torch.randn(200000, generator=gen, dtype=dtype)
h = torch.relu(z)
assert abs(h.square().mean().item()-.5) < .01
assert abs(h.mean().item()-1/math.sqrt(2*math.pi)) < .01
assert abs(h.var(correction=0).item()-(.5-1/(2*math.pi))) < .01
x = torch.randn(1024, 256, generator=gen, dtype=dtype)
base = torch.randn(256, 384, generator=gen, dtype=dtype)
q_small = torch.relu(x @ (base/math.sqrt(256))).square().mean()
q_he = torch.relu(x @ (base*math.sqrt(2/256))).square().mean()
assert .46 < q_small.item() < .54
assert .92 < q_he.item() < 1.08
assert torch.allclose(q_he, 2*q_small, atol=1e-12, rtol=1e-12)
print('moment checks passed', h.mean().item(), h.var(correction=0).item(), q_he.item())
```

## 4. 归一化首先指定统计集合

对一个包含 $`m`$ 个元素的归一化集合，定义 $`\mu=m^{-1}\sum_i x_i`$、$`v=m^{-1}\sum_i(x_i-\mu)^2`$、$`r=\sqrt{v+\epsilon}`$，输出为 $`y_i=\frac{\gamma_i(x_i-\mu)}{r}+\beta_i`$。集合如何选取，决定哪些元素共享均值方差；缩放平移在哪些轴共享，则决定可学习参数形状。仅说“归一化后均值零方差一”遗漏了最关键的函数定义。

在有限 epsilon 下，标准化值的中心方差是 $`\frac{v}{(v+\epsilon)}`$，通常小于一；再经过可学习缩放平移后，输出均值方差更不必为零和一。因此观察输出不是单位方差，不应马上判定实现错误。应先区分标准化中间值与最后输出，确认统计轴、方差分母和 epsilon，再讨论数值预期。

**先辨认统计集合。** 图左固定一个特征，在同一列沿样本维归约；图右固定一条样本，在同一行沿特征维归约。此处方差以参与统计的元素数为分母。卷积的批归一化还常汇总空间轴，实际层另含稳定项和可学习仿射。

两边输入均使用三行 $`(0,2,4,6),(1,3,5,7),(2,4,6,8)`$。BN 第一列为 $`(0,1,2)`$，均值为一、方差 $`\frac23`$；LN 使用第一行，均值为三、方差五。两套操作最后仍得到三乘四矩阵，尺寸无法告诉我们哪套统计被使用。[Layer Normalization 原论文第 3 节](https://arxiv.org/html/1607.06450#S3)把单样本内共享统计与跨样本统计的区别写进定义，而不是仅改变参数名称。

再干预这个依赖关系：目标样本第一行保持不动，只将第三行所有值加九。原来第一列的 BN 目标输出是 $`-\sqrt{\frac32}\approx-1.2247`$；新第一列为 $`(0,1,11)`$，均值四，方差 $`\frac{74}{3}`$，目标输出变为 $`-\frac4{\sqrt{\frac{74}{3}}}\approx-0.8054`$。其余列只是共同平移，所以四个目标坐标有相同结果。这里不是目标样本变了，而是它共享的统计集合变了。

LN 的目标行既未变，统计集合也未变，因此仍输出 $`\frac{(-3,-1,1,3)}{\sqrt5}`$。本图为看清机制令 epsilon 为零，所用各统计集合方差都非零；有限 epsilon 下需把它加到分母根号内重新计算，不能在近常数输入上照抄零 epsilon 数值。

### 4.1 两条样本的精确轴算例

样本为 $`(1,3)`$ 与 $`(10,12)`$。按各自特征归一，均值分别为二和十一，中心化值都为 $`(-1,1)`$；忽略 epsilon 时输出同为 $`(-1,1)`$。若按批内每个特征归一，两个特征的均值分别为五点五和七点五，中心化值分别为负四点五与正四点五，每条样本的两个坐标此时都同号。两种结果形状相同，但保留与消除的信息不同。

前一种操作去掉每条样本共同偏移，对整体水平变化不敏感；后一种操作比较同特征在批内的相对位置，可能让同一条样本随同伴改变。选择需要来自任务结构。如果绝对水平本身携带标签信息，盲目归一化可能消除有用信号；后续可学习偏移只能恢复固定坐标偏置，不能恢复已经丢弃的每条样本任意共同偏移。

## 5. BatchNorm：参数、缓冲与模式三份状态

对二维输入 $`(B,C)`$，BatchNorm 通常按每个通道在批轴上统计；对卷积输入还把对应空间位置纳入集合，通道之间不共用同一均值。可学习缩放和平移按通道设置，运行均值方差则是缓冲状态。训练和评估使用何种统计由配置与模式决定，必须把这些要素一起记录，不能只比较参数张量。

本章以 PyTorch 2.10 的普通跟踪统计配置为例：训练前向使用有偏批方差，运行方差更新使用相应无偏估计，评估使用运行统计；动量 $`a`$ 的更新形式为旧值乘 $`(1-a)`$ 加新批统计乘 $`a`$。这段接口约定来自[固定版本官方文档](https://docs.pytorch.org/docs/2.10/generated/torch.nn.BatchNorm1d.html)，不是所有软件统一规则。后面的实验直接验证这些具体数值。

[打开原图放大](images/03-current-batch-statistics-feed-training-and-update-persistent-buffers.webp)

图中的当前批统计有两条用途。训练前向用它标准化该批输入，训练过程还用该批统计更新运行缓冲。若启用了运行统计，评估通常读取缓冲。连续小批先后更新同一份缓冲，所以当前批与评估使用的统计可能不同。

学习到的仿射参数可再改输出中心和尺度，方差分母还含稳定项。标准化改变均值和尺度，各批的分布形状和通道依赖仍由数据决定。关闭运行统计跟踪时，评估也可能使用当前批。可对照 [D2L 的 BatchNorm 定义](https://d2l.ai/chapter_convolutional-modern/batch-norm.html)。

<a id="nnb-3-detail-12"></a>

### 5.1 手算一次运行统计更新

取两条样本 $`(1,2)`$、$`(3,6)`$，批均值为 $`(2,4)`$，有偏方差为 $`(1,4)`$，无偏方差为 $`(2,8)`$。初始运行均值为零、运行方差为一，动量为四分之一，则更新后的运行均值为 $`(0.5,1)`$，运行方差为 $`(1.25,2.75)`$。训练输出基于当前批均值和有偏方差，评估输出则基于刚得到的运行统计，两者没有理由逐位相同。

运行统计是沿训练过程积累的估计，不是对全部训练样本一次性精确统计。批次大小、次序、分布与动量都会影响结果；不同大小批次的简单指数更新也不等于每条样本等权的总体估计。若部署分布变化，应检查预处理和统计是否仍合适，而不是假设一次训练得到的运行量永远正确。

<a id="nnb-3-detail-13"></a>

### 5.2 冻结参数与冻结函数不同

将缩放和平移参数设为不需要梯度，不会自动阻止训练模式更新运行缓冲，也不会消除同批样本耦合。若想冻结特征提取器整个函数，应明确模式和缓冲处理；若有意适配目标域统计，应说明使用了哪些目标数据。两种策略都可以研究，但它们的资料权限与风险不同，不能共用一个含糊“冻结”描述。

若关闭运行统计跟踪，评估时也可能继续使用输入批统计，此时单样本预测对同批组成的依赖仍存在。部署系统若把请求随机拼批，输出便可能随拼批策略变化。需要检查这是否是任务允许的行为，而不能仅因为模块处于评估模式就断言每条样本彼此独立。

### 图解：BatchNorm：训练方差和运行方差如何分开计算

![同一平方离差和分别除以批大小与批大小减一，得到不同的方差估计](images/03-variance-divisors-for-training-and-running-statistics.webp)

[打开原图放大](images/03-variance-divisors-for-training-and-running-statistics.webp)

**读图与计算。** 设一个通道的统计集合只有 $`(8,12)`$，均值为十，平方离差和为八。训练前向用分母二得到方差四；PyTorch 更新运行方差时用分母一得到无偏估计八。若初始运行均值为零、方差为一，`momentum=0.1`，更新后分别是 $`0.9\times0+0.1\times10=1`$ 和 $`0.9\times1+0.1\times8=1.7`$。取 $`\gamma=1,\beta=0,\epsilon=10^{-5}`$，训练输出约为 $`(-1,1)`$；随后切换评估模式，对同样输入使用更新后的缓冲，输出约为 $`(5.369,8.437)`$。

**沿时间追踪同一统计规则。** 如果反复输入同一批 $`(8,12)`$ 而不更新参数，缓冲满足 $`m_t=10(1-0.9^t)`$、$`v_t=8-7(0.9^t)`$。每次训练前向都使用表中方差四，随后切换到评估，使用当时的缓冲计算 $`y_t(x)=\frac{x-m_t}{\sqrt{v_t+10^{-5}}}`$。这就把同一输入的训练和评估两条计算路径分开。

即使缓冲完全收敛，评估输出也趋向 $`\frac{(-2,2)}{\sqrt{8+10^{-5}}}\approx(-0.7071,0.7071)`$，仍不等于训练输出 $`\frac{(-2,2)}{\sqrt{4+10^{-5}}}`$。因此本例的模式差异有两个来源：有限步缓冲尚未追上均值方差，以及两元素批的有偏、无偏方差本来不同。重复同一个批只能隔离这两个机制，并没有获得新的独立数据，也不是估计真实部署分布的建议。[官方定义](https://docs.pytorch.org/docs/2.10/generated/torch.nn.BatchNorm1d.html)明确区分了训练前向与运行缓冲的方差估计；这里的收敛极限可由该递推直接计算。

**适用条件。** 本图采用 PyTorch 跟踪运行统计的 BatchNorm 约定，并以单通道的两个统计元素作手算；空间 BatchNorm 的统计元素还包括同通道各空间位置。一次小批更新后的缓冲尚未收敛，评估输出偏大恰好说明不能把当前批统计与运行统计混为一谈。其他框架须核对方差修正和动量定义；`track_running_stats=False` 时评估也会使用当前批统计。

实现约定：[PyTorch BatchNorm2d 官方文档](https://docs.pytorch.org/docs/2.10/generated/torch.nn.BatchNorm2d.html)。

## 6. 归一化雅可比为何耦合多个元素

先忽略可学习缩放，把一个归一化集合看成向量。令 $`c=x-\mu\mathbf1`$，$`r=\sqrt{m^{-1}c^Tc+\epsilon}`$，标准化输出 $`\hat x=\frac{c}{r}`$。对均值微分，$`dc=(I-\frac{\mathbf1\mathbf1^T}{m})dx`$；对尺度微分，$`dr=\frac{c^Tdx}{(mr)}`$。代入可得

```math
J=\frac1r\left(I-\frac{\mathbf1\mathbf1^T}{m}-\frac{cc^T}{mr^2}\right).
```

对上游向量 $`g`$，反向是 $`J^Tg`$；若缩放按坐标不同，先把上游乘对应缩放。这个公式展示：一个输入坐标会通过均值和方差影响集合中其他输出，所以雅可比通常不是对角矩阵。把归一化当成固定的逐元素减均值除标准差，会漏掉统计量对输入的导数。

<a id="nnb-3-detail-15"></a>

### 6.1 平移方向被消除，尺度方向受 epsilon 影响

因为 $`c^T\mathbf1=0`$，有 $`J\mathbf1=0`$，即给集合所有元素加同一常数不会改变标准化值。对中心化方向本身，有 $`Jc=(\frac{\epsilon}{r^3})c`$。若 epsilon 为零，该方向也被消除，对应正尺度变化不改变标准化；若 epsilon 大于零，仍有一个很小但不一定为零的响应。与 $`\mathbf1,c`$ 都正交的方向，局部缩放为 $`\frac{1}{r}`$。

因此近零方差下 epsilon 不只是避免除零，还决定某些方向的导数上限和几何。把 epsilon 从根号内移到根号外，是不同函数；直接忽略它的导数含义也可能导致近常数输入上的解释错误。当集合只有一个特征时，中心化结果恒为零，很多信息都被消除，这也是不能盲目对任意末维长度套 LayerNorm 的原因。

<a id="pair-layernorm-variance-and-directions"></a>

下图 (a) 展示稳定项怎样改变小方差输入的输出方差。图 (b) 对照均值平移和尺度变化，说明两个方向为何不同。

![图 (a) 展示稳定项对方差的影响，图 (b) 对照同一向量的平移与尺度变化](images/03-layer-normalization-centers-first-and-keeps-epsilon-in-the-scale.webp)

[打开原图放大](images/03-layer-normalization-centers-first-and-keeps-epsilon-in-the-scale.webp)

**稳定项改变归一化方差。** 图 (a) 取一个中心化且总体方差为一的向量 u，令输入为 cu，关闭可学习仿射。标准化后方差为 c² 除以 (c²+epsilon)，所以 c 接近零时不会是单位方差。数值比较还要说明实际使用的 epsilon。共同平移仍会被中心化消去，但缩放不变性受 epsilon 破坏；数值测试应核对带 epsilon 的实际函数，而非只核对理想极限。

```math
\mathrm{Var}\!\left(\frac{cu}{\sqrt{c^2+\epsilon}}\right)=\frac{c^2}{c^2+\epsilon},\qquad \mathrm{Var}(u)=1.
```

<a id="visual-depth-nnb-directions"></a>

#### 图解：归一化消除了哪些方向

在[图 (b)](#pair-layernorm-variance-and-directions)中分别跟踪整体平移和中心化后的尺度变化。

**先看图 (b) 的前两行，比较减均值前后。** 为单独研究标准化，令仿射参数 $`\gamma=1,\beta=0`$。A 为 $`(1,3)`$，均值二、中心化结果 $`(-1,1)`$、按元素数作分母的方差为一。B 为 $`(2,4)`$，均值三，中心化结果仍为 $`(-1,1)`$。A→B 在输入坐标中沿公共平移方向移动，却在中心化坐标中落到同一点，因此该方向的变化已被消除。

**再看图 (b) 的第三行，比较尺度变化。** C 为 $`(0,4)`$，均值二，中心化结果变成 $`(-2,2)`$，方差为四。若 $`\epsilon=0`$，A、B、C 的标准化输出全是 $`(-1,1)`$；若 $`\epsilon=1`$，A、B 的输出是 $`\frac{(-1,1)}{\sqrt2}`$，而 C 为 $`\frac{(-2,2)}{\sqrt5}`$。两个标准化向量的正坐标分别约为 0.707 和 0.894。公共平移仍被消除，但尺度变化不再严格不变。

**把数值接回导数。** 对中心化向量 $`c_x`$，本节公式 $`Jc_x=\frac{\epsilon}{r^3}c_x`$ 表明该方向在 $`\epsilon>0`$ 时保留响应；只有在相应零方差边界之外、$`\epsilon=0`$ 的理想化情形，才是精确零方向。图特意取较大 epsilon 使差异可见，真实模型应检查方差相对 epsilon 的量级。若再加入逐特征仿射参数，输出坐标也会变化，但中心化之前被删除的公共平移不能由固定仿射参数恢复。算子定义依据 [PyTorch LayerNorm](https://docs.pytorch.org/docs/2.10/generated/torch.nn.LayerNorm.html)。

**三维局部实验：不能把“归一化后的方差”当成全部梯度。** 二维例子中去掉均值和尺度后几乎没有剩余方向；三维例子能把共同平移、径向变化和切向变化真正分开。

![公共平移、尺度及其正交方向分别具有零、三分之一和一的局部增益](images/03-three-orthogonal-directions-have-distinct-layernorm-gains.webp)

[打开原图放大](images/03-three-orthogonal-directions-have-distinct-layernorm-gains.webp)

取 $`x=(-1,0,1)^\top`$、$`\epsilon=\frac13`$，仍固定 $`\gamma=1,\beta=0`$。此时均值零、总体方差 $`v=\frac23`$、$`r=\sqrt{v+\epsilon}=1`$。令 $`C=I-\frac13\mathbf1\mathbf1^\top`$，标准化的雅可比为

```math
J=\frac{C}{r}-\frac{xx^\top}{3r^3}=C-\frac{xx^\top}{3}.
```

图的三个单位输入扰动分别为 $`u=\frac{(1,1,1)^\top}{\sqrt3}`$、$`r_x=\frac{(-1,0,1)^\top}{\sqrt2}`$、$`t=\frac{(1,-2,1)^\top}{\sqrt6}`$。它们两两正交，直接相乘得到 $`Ju=0`$、$`Jr_x=\frac13r_x`$、$`Jt=t`$。浅柱是输入，深柱是线性响应，同一组纵轴让增益可直接比较。这证明共同平移精确消失，不代表所有其他扰动都一样缩小；切向响应在本例完整保留，而径向响应由 epsilon 决定。这里比较的是无限小扰动 $`J\delta x`$，有限幅度还会改变均值、方差和雅可比。算子的方差分母与 epsilon 位置依照 [PyTorch LayerNorm 定义](https://docs.pytorch.org/docs/2.10/generated/torch.nn.LayerNorm.html)，三个方向的分解由本节雅可比独立推得。

<a id="nnb-3-detail-16"></a>

### 6.2 BatchNorm 的跨样本梯度与批组成

如果集合是同一通道的批内样本，雅可比中的非对角项意味着一条样本的损失可以通过统计量影响其他样本输入的梯度。对批量数据逐样本独立求导再相加，若每次都重新计算单样本统计，就不是原大批函数的分解。需要区分固定批统计下的单样本贡献与重新定义批集合后的函数。

这也影响梯度累积和多设备分片。把同一大批拆成若干小批，各小批各算统计，得到的前向与梯度通常不同；同步统计方法则有额外通信和定义条件。不能仅按优化器更新前累计样本数相同，就认为归一化看见了同样资料。实验协议应分别记录局部批大小、全局批大小和统计同步方式。

<a id="nnb-3-detail-17"></a>

### 6.3 实验二：统计来源、冻结与耦合

实验使用两条样本的精确手算更新，验证训练输出、运行均值方差和评估输出。随后冻结可学习参数，在训练模式再前向，确认缓冲仍变化。最后对一条样本输出求另一样本输入的导数，直接观察跨样本耦合。所有张量都很小，便于把打印值对应到上面的公式。

```python
import torch
from torch import nn

torch.set_num_threads(1)
dtype = torch.float64
bn = nn.BatchNorm1d(2, eps=1e-5, momentum=.25).to(dtype)
x = torch.tensor([[1., 2.], [3., 6.]], dtype=dtype)
bn.train()
y = bn(x)
mean = x.mean(0)
var = x.var(0, correction=0)
assert torch.allclose(y, (x-mean)/torch.sqrt(var+bn.eps), atol=1e-12)
assert torch.allclose(bn.running_mean, torch.tensor([.5, 1.], dtype=dtype))
assert torch.allclose(bn.running_var, torch.tensor([1.25, 2.75], dtype=dtype))
bn.eval()
expected = (x-bn.running_mean)/torch.sqrt(bn.running_var+bn.eps)
assert torch.allclose(bn(x), expected, atol=1e-12)
assert not torch.allclose(bn(x), y)
for p in bn.parameters():
    p.requires_grad_(False)
before = bn.running_mean.clone()
bn.train()
bn(x+10)
assert not torch.equal(before, bn.running_mean)
probe = nn.BatchNorm1d(1, affine=False, track_running_stats=False, eps=.1).to(dtype)
v = torch.tensor([[0.], [1.], [3.]], dtype=dtype, requires_grad=True)
first = probe(v)[0, 0]
g, = torch.autograd.grad(first, v)
assert g[1:, 0].abs().max().item() > .01
assert abs(g.sum().item()) < 1e-12
print('batch statistics and coupled gradient checks passed', g[:, 0].tolist())
```

## 7. LayerNorm：局部统计不等于无条件无损

LayerNorm 常在每个样本的指定特征集合内计算统计，因此不依赖同批其他样本。对序列 $`(B,T,H)`$，仅归一最后 $`H`$ 维时，每个 token 各有自己的均值方差；若归一末尾 $`(T,H)`$ 两维，则同一序列不同时间位置也会共享统计。两者输出形状相同，却是不同函数，可能具有不同信息权限。

在因果序列模型中，若把未来位置纳入当前 token 的归一化统计，即使注意力用了因果掩码，仍可能通过归一化泄露未来。轴检查必须覆盖所有操作，而不只是注意力矩阵。普通按最后隐藏维归一不会因为批量含未来 token 就自动混合时间信息，但把轴扩大后结论改变。结构名称不能替代逐轴的数据依赖审计。

<a id="nnb-3-detail-19"></a>

### 7.1 仿射参数、无状态与模式边界

LayerNorm 的缩放和平移常按被归一化的特征坐标设置，参数数目取决于配置。它通常不维护 BatchNorm 那样的跨批运行均值方差，训练和评估使用当前输入的统计。可是一个包含 LayerNorm 的完整模型仍可因 Dropout 等模块在两种模式下不同，不能把局部层性质推广为全网模式无关。

同样，没有运行缓冲不等于没有信息损失。对单个 token，公共偏移被消除；若 epsilon 很小，公共正尺度也近似被消除。网络可以通过残差保留原表示，或者通过其他通道编码必要信息，但一个孤立归一化操作无法在输出中恢复所有被消除自由度。可学习缩放平移提供坐标灵活性，不是对每个输入自适应恢复丢失均值的逆变换。

<a id="nnb-3-detail-20"></a>

### 7.2 RMSNorm 与中心化的区别

若只除以均方根而不减均值，形式为 $`\frac{x}{\sqrt{m^{-1}\sum x_i^2+\epsilon}}`$，公共平移不再保持不变，信息和雅可比结构也不同。它可以减少某些计算步骤，但不能仅用“也是归一化”就视为与 LayerNorm 完全等价。比较时应考虑是否中心化、是否含偏置、参数形状与具体模型结构。

对输入 $`(1,3)`$，LayerNorm 忽略 epsilon 时输出 $`(-1,1)`$，均方根归一则输出 $`\frac{(1,3)}{\sqrt5}`$，两者方向与均值不同。若任务信号依赖绝对均值，后者可能保留不同信息；若依赖消除公共偏移，前者更直接。是否更好需要在受控架构和预算下测试，不能由操作少或名称流行作结论。

<a id="nnb-3-detail-21"></a>

### 7.3 实验三：逐 token 独立与归一化雅可比

下面直接手写标准化函数，核对精确雅可比与自动微分，并比较根号内 epsilon 带来的尺度方向响应。随后用 LayerNorm 验证批组成变化不影响第一条样本，改变一个 token 不影响同序列另一个 token；最后把时间轴也纳入归一化，展示依赖关系确实改变。

```python
import torch
from torch import nn

torch.set_num_threads(1)
dtype = torch.float64
x = torch.tensor([1., 2., 5.], dtype=dtype, requires_grad=True)
eps = .2

def normalize(v):
    c = v-v.mean()
    return c/torch.sqrt(c.square().mean()+eps)

j_auto = torch.autograd.functional.jacobian(normalize, x)
c = x.detach()-x.detach().mean()
r = torch.sqrt(c.square().mean()+eps)
one = torch.ones(3, dtype=dtype)
j = (torch.eye(3, dtype=dtype)-torch.outer(one, one)/3-torch.outer(c, c)/(3*r*r))/r
assert torch.allclose(j_auto, j, atol=1e-12)
assert torch.allclose(j @ one, torch.zeros(3, dtype=dtype), atol=1e-12)
assert torch.allclose(j @ c, eps*c/r**3, atol=1e-12)
ln = nn.LayerNorm(3, elementwise_affine=False, eps=1e-5).to(dtype)
a = torch.tensor([[[1., 2., 4.], [2., 5., 8.]],
                  [[10., 20., 40.], [3., 7., 9.]]], dtype=dtype)
base = ln(a)
changed = a.clone()
changed[1] += torch.tensor([100., -200., 50.], dtype=dtype)
assert torch.equal(ln(changed)[0], base[0])
changed = a.clone()
changed[0, 1, 0] += 100
assert torch.equal(ln(changed)[0, 0], base[0, 0])
wide = nn.LayerNorm((2, 3), elementwise_affine=False).to(dtype)
assert not torch.allclose(wide(changed)[0, 0], wide(a)[0, 0])
print('normalization Jacobian and axis independence checks passed')
```

## 8. 残差连接：恒等项与变换项共同决定局部行为

普通块为 $`y=F(x)`$，残差块为 $`y=x+F(x)`$。其雅可比是 $`I+J_F(x)`$，因此输入梯度含一条不经过变换分支的直接贡献。这个恒等项有利于表达接近恒等的修正，也改变深层网络的优化参数化。但如果 $`J_F=-I`$，整个雅可比为零；若 $`J_F=10I`$，局部放大为十一。恒等项提供可能的直接路径，不构成绝不消失或爆炸的证明。

若残差带尺度 $`\alpha`$，$`y=x+\alpha F(x)`$，雅可比为 $`I+\alpha J_F`$。当 $`\Vert \alpha J_F\Vert \lt 1`$ 时，可用三角不等式给出奇异值上下界 $`1-\Vert \alpha J_F\Vert `$ 与 $`1+\Vert \alpha J_F\Vert `$。这说明小分支在局部可以接近恒等，但多块乘积仍可能积累差异；单块接近一不能直接推出任意深度组合条件良好。

<a id="nnb-3-detail-23"></a>

### 8.1 投影捷径、广播与秩

输入输出尺寸不同时，可用 $`y=Px+F(x)`$，雅可比直接项变为 $`P`$。若投影降维，可能存在不可逆的信息损失，不能仍称为全维恒等路径。下采样残差也需要检查空间与通道语义，输出形状对齐只是必要条件。自动广播偶尔能让错误分支相加成功，例如把一个通道数误写为一，但实际模型已变成重复同一修正到所有通道。

最小结构测试应令变换分支为零，确认输出等于预期捷径，输入梯度等于捷径转置作用于上游。若零分支时仍有额外非线性或归一化，说明所谓“恒等”需要重新限定。对投影块，可以用低秩矩阵明确展示哪些输入方向被丢失，再讨论是否由其他路径保留，而不是用残差名称掩盖不可逆变化。

<a id="nnb-3-detail-24"></a>

### 8.2 相加前后归一化和激活改变直接路径

预归一化形式 $`y=x+F(N(x))`$ 有显式外部恒等项；后归一化形式 $`y=N(x+F(x))`$ 的雅可比是 $`J_N(I+J_F)`$，归一化位于所有路径之后。若相加后再 ReLU，负区间仍可能把直连梯度截断。这些块都能被称为残差结构，但局部导数不同，不能只按模块名称比较。

预归一化也不是无条件胜利：残差流的尺度可能随深度变化，分支学习信号相对主干可能变弱；后归一化则可能需要不同初始化和学习率策略。研究应固定宽度、深度、归一化配置和训练预算，再把局部推导与实际训练证据结合。一个结构的优势往往依赖整个训练方案，不能从单个雅可比式推出所有任务排序。

![分支恒为零时预归一化保留两种输入，后归一化将两者映到相同输出](images/03-pre-norm-keeps-the-identity-path-when-the-branch-is-zero.webp)

[打开原图放大](images/03-pre-norm-keeps-the-identity-path-when-the-branch-is-zero.webp)

图中令变换分支恒为零，归一化为无仿射且 $`\epsilon=0`$ 的两维 LayerNorm。两个输入 $`(1,3)`$、$`(2,4)`$ 相差一个公共平移。预归一化只作用于变换分支，两个输入通过捷径原样输出。后归一化作用于相加后的整体，两种输入都输出 $`(-1,1)`$。

这展示归一化放在全部路径之后时，可以消去公共平移方向。$`\epsilon>0`$ 时公共平移仍不改变归一化结果，但显示值不再恰好为正负一。此处固定 F 为零以隔离直接路径，并不是声称训练后的变换分支总为零，也不能由此判定某种网络结构在所有任务上更优。

<a id="nnb-3-detail-25"></a>

### 8.3 实验四：恒等、相消、投影与归一化位置

小矩阵实验精确验证残差雅可比，构造 $`F(x)=-x`$ 的完全相消，再测试投影捷径与零分支。最后比较预归一化和后归一化在零变换分支时的结果：前者仍为恒等，后者变成归一化函数。代码通过局部雅可比直接检验机制，不依赖大规模训练曲线。

```python
import torch

torch.set_num_threads(1)
dtype = torch.float64
x = torch.tensor([1., 2., 4.], dtype=dtype, requires_grad=True)
a = torch.tensor([[.1, .2, 0.], [0., -.3, .1], [.2, 0., .1]], dtype=dtype)
eye = torch.eye(3, dtype=dtype)
j = torch.autograd.functional.jacobian(lambda v: v+a@v, x)
assert torch.allclose(j, eye+a, atol=1e-12)
cancel = torch.autograd.functional.jacobian(lambda v: v-v, x)
assert torch.equal(cancel, torch.zeros_like(eye))
p = torch.tensor([[1., 0., 0.], [0., 1., 0.]], dtype=dtype)
projected = torch.autograd.functional.jacobian(lambda v: p@v+0*(p@v), x)
assert torch.equal(projected, p)
assert torch.linalg.matrix_rank(p).item() == 2

def norm(v):
    c = v-v.mean()
    return c/torch.sqrt(c.square().mean()+1e-5)

pre = torch.autograd.functional.jacobian(lambda v: v+0*norm(v), x)
post = torch.autograd.functional.jacobian(lambda v: norm(v+0*v), x)
assert torch.equal(pre, eye)
assert not torch.allclose(post, eye)
assert torch.allclose(post@torch.ones(3, dtype=dtype), torch.zeros(3, dtype=dtype), atol=1e-12)
print('residual, cancellation, projection, and normalization placement checks passed')
```

![逐行相加捷径与分支贡献，一条坐标方向抵消，另一条放大](images/03-residual-branches-cancel-one-direction-and-amplify-the-other.webp)

[打开原图放大](images/03-residual-branches-cancel-one-direction-and-amplify-the-other.webp)

**从标量反例走到方向性反例。** 取线性分支 $`F(x_1,x_2)=(-x_1,0.5x_2)`$。相加后 $`y=x+F(x)=(0,1.5x_2)`$，所以总雅可比为

```math
I+J_F=
\begin{bmatrix}1&0\\0&1\end{bmatrix}
+\begin{bmatrix}-1&0\\0&0.5\end{bmatrix}
=\begin{bmatrix}0&0\\0&1.5\end{bmatrix}.
```

表中给出两个标准基方向。横向扰动 $`(1,0)`$ 被分支精确抵消；纵向扰动 $`(0,1)`$ 则放大到 $`(0,1.5)`$。因此“存在恒等项”与“所有方向可逆或梯度非零”是不同命题。本例的两个奇异值是零与 1.5，平均量也无法表达哪个方向已经丢失。

**把图接回反向传播。** 上游梯度 $`g_y`$ 经过转置雅可比得到 $`g_x=(I+J_F)^Tg_y`$；本例为对角矩阵，所以同样消除第一坐标、放大第二坐标。一般非对称雅可比的前向扰动与反向梯度变换不能画成同一个箭头，应分别使用矩阵和其转置。这个特设分支只是否定无条件保证，并不否定适当初始化和缩放的残差网络能改善训练。

**先分支，再相加，才知道哪个方向被保留。** 表中逐行展开 $`\delta x=e_1=(1,0)^\top`$ 与 $`\delta x=e_2=(0,1)^\top`$：第一行收到直连 $`e_1`$ 和分支 $`-e_1`$，恰好归零；第二行收到 $`e_2`$ 和 $`0.5e_2`$，相加为 $`1.5e_2`$。不是“直连先消失了”，而是它确实到达求和节点，随后与另一路抵消。只看变换分支的梯度大小或只看捷径箭头，都会遗漏这个求和。

对一般单位扰动 $`\delta x=(\cos t,\sin t)^\top`$，输出为 $`(0,1.5\sin t)^\top`$；绕完整个圆，第一坐标永远为零，第二坐标连续扫过区间 $`[-1.5,1.5]`$。整个单位圆经过该映射会覆盖这条竖直线段。[D2L 8.6 的残差块图](https://d2l.ai/chapter_convolutional-modern/resnet.html#residual-blocks)强调捷径与分支在同一节点相加；本图进一步把相加对每个方向的后果画出来。

**自检：** 若将分支第一坐标从 $`-x_1`$ 改为 $`-0.9x_1`$，单位圆的像将变成半轴长 $`0.1`$ 与 $`1.5`$ 的椭圆，最小奇异值不再为零，条件数却仍为十五。有没有精确零梯度与方向条件是否良好，因而也应分开判断。

## 9. 深度增加时，分支尺度如何累计

考虑简化标量块 $`x_{l+1}=(1+a_l)x_l`$，经过 $`L`$ 层后的倍率为 $`\prod_l(1+a_l)`$。即使每层只偏离一很少，若所有 $`a_l=a>0`$，倍率仍为 $`(1+a)^L`$，随深度累积；若 $`a\lt 0`$ 且绝对值较小，则逐步缩小。小残差并不等于任意深度稳定，关键是单层偏差如何随深度缩放、符号和相关性如何分布。

如果残差贡献近似独立、均值零，二阶矩分析可能给出分支方差随深度增长的另一种规律；若分支与主干强相关，协方差项不可忽略。写 $`\mathrm{Var}(x+F)=\mathrm{Var}(x)+\mathrm{Var}(F)`$ 已经隐含协方差为零，而真实网络常不满足。应明确是初始化集合上的近似、数据分布上的统计，还是某个固定训练状态的经验观察。

<a id="nnb-3-detail-27"></a>

### 9.1 深度缩放的确定性与随机性条件

若每层确定性分支雅可比范数有共同上界 $`M`$，把尺度设为 $`\frac{c}{L}`$ 可以用乘积上界 $`(1+\frac{cM}{L})^L`$ 控制为接近 $`e^{cM}`$ 的量。这只是上界，可能很保守，也没有保证最小奇异值在所有深度都良好。若想利用随机均值零假设得到不同缩放，需要证明相关性条件和关注的概率量，不能直接把确定性最坏情况与随机平均结论混在一起。

连续深度观点把小残差更新看成离散动力系统，$`x_{l+1}=x_l+\Delta t F_l(x_l)`$ 类似数值积分。它帮助理解步长与稳定性，但离散网络的有限深度、非光滑激活和参数学习仍有独立问题。并不是所有残差网络都自动近似某个稳定微分方程，尤其当分支尺度很大或层间函数快速变化时，类比需要重新检验。

<a id="nnb-3-detail-28"></a>

### 9.2 恒等起点与分支学习速度

让残差末端缩放初始为零，可以使起始前向接近恒等。此时末端缩放或输出权重可能先获得梯度，而更早分支参数的梯度可能因乘零暂时为零。随着末端参数离开零，内部梯度才逐渐开启。这个过程不必是错误，但必须理解哪些参数在前几步实际学习，不能用“所有参数起始都有梯度”作为无条件要求。

如果所有分支都以同样对称方式初始化，还要检查是否存在无法打破的参数对称。零末端配合不同随机内部特征，与全网所有权重全零不是同一条件。为了避免口号式结论，最小实验可以只训练两步，分别记录各层梯度是否存在和是否为零，观察预期的开启顺序，而不必先跑一个大型数据集。

## 10. 从统计日志到可解释诊断

初始化检查应在优化器更新之前完成，记录固定探针批每层预激活、激活和反向梯度的均值、二阶矩、分位数、活动率与非有限比例。之后用相同探针跟踪少数训练时刻，区分起点已经异常还是更新后才发生异常。不同批的统计波动可能很大，若每次换输入，就难以把变化归因于参数。

日志必须与结构预期相连。ReLU 输出正均值和较多零值通常合理，LayerNorm 后再仿射的均值不一定为零，残差流方差也未必每层相同。机械要求所有层分布相同，可能把正确结构调坏。真正需要追查的是不符合设计的突变、持续非有限、无法激活或更新失衡，并用最小干预定位。

<a id="nnb-3-detail-30"></a>

### 10.1 一个三分支诊断矩阵

若训练和评估输出差异很大，先检查模式、运行统计和输入处理；若只有改变同批伙伴才影响输出，重点检查批统计和错误轴混合；若两种模式都在某层开始溢出，重点检查输入尺度、分支放大、学习率和稳定公式。这三个现象可能同时存在，但各自提出了不同的可检验假设，不能用“归一化没调好”笼统概括。

对同一模型，可以冻结参数并分别改变同批其他样本、样本内公共偏移、样本内尺度和序列其他位置。观察哪类变化影响目标输出，就能实测函数的依赖关系。这个方法尤其适合发现不恰当归一化轴和因果信息泄漏：它直接检验数据流，而不是仅核对张量尺寸。

<a id="nnb-3-detail-31"></a>

### 10.2 小批统计可靠性与样本相关性

批内元素数量多不等于独立信息多。卷积特征图的邻近空间位置相关，时间序列相邻观测相关，同一患者多张图也相关；把所有位置都纳入均值方差时，估计的不确定性未必按独立样本数量缩小。小批训练的不稳定不能只用名义批大小解释，还应考虑数据相关性和分组结构。

如果各批来自不同来源，运行统计可能混合了多个分布，其平均值对任何一个来源都不合适。应先明确部署需要整体模型、来源条件模型还是域适配策略，再决定统计如何估计。不能为了让验证指标更好而偷偷使用测试来源重新估计缓冲，同时仍宣称模型完全固定。资料权限属于实验协议，应与网络结构一样公开。

<a id="nnb-3-detail-32"></a>

## 11. 方法比较：什么条件下可以公平归因

比较 BatchNorm、LayerNorm、无归一化和残差布局时，应固定数据划分、输入处理、宽度深度、损失、优化步数和超参数选择预算。不同方法可能需要不同合理学习率，完全强行共用一个只适合某方法的配置也未必公平。可以分别报告固定公共配置的受控比较与相同搜索预算下的方案比较，两者回答的问题不同。

第一类比较更有利于隔离某个结构变化，第二类比较更贴近实际可达到性能。报告应说明采用哪一种，不能一边给某方法充分调参、一边把另一方法单次失败当作结构劣势。额外通信、内存和推理批依赖也是代价，不能只比较最终准确率而忽略部署需求。

<a id="nnb-3-detail-33"></a>

### 11.1 消融要保留关键混杂变量

去掉归一化后若同时改变初始化与学习率，观察到提升无法只归因于“去掉归一化”。但如果完全不调整，原结构特定超参数也可能让无归一化版本不合理失败。可以分阶段做消融：先固定其余条件观察直接影响，再采用预先规定的同预算搜索研究补偿能力。把两类结果分开，才能解释哪部分来自组件、哪部分来自训练适配。

残差研究还要控制参数量。增加投影捷径可能引入额外参数与计算，改变宽度以匹配参数又改变表示瓶颈。没有唯一完美公平标准，但可以同时报告参数匹配与计算匹配版本，并注明限制。严谨不意味着消除所有差异，而是让差异可见并把结论限定到证据能够支持的范围。

<a id="nnb-3-detail-34"></a>

### 11.2 平均结果、失败率与极端输入

一个方法平均损失较低，但少数种子频繁发散，实际可靠性可能差于略慢却稳定的方案。应同时报告种子分布、非有限失败次数和可恢复性。若实验只保留成功运行，会低估不稳定性。小规模教材实验也可刻意提高分支尺度或改变输入常数，观察何时失效，把失败看成理解条件的证据。

极端输入包括近常数特征、单样本批、巨大共同偏移和极小方差。它们不必对应常见部署数据，但能揭示 epsilon、统计分母和轴选择的作用。测试应说明其目的：验证数值与机制边界，而不是用不现实输入宣称某方法在所有真实任务都差。每类反例都要配合适用范围，防止以偏概全。

<a id="nnb-3-detail-52"></a>

## 12. 更深入的边界：归一化改变了哪些可识别量

考虑一个输入集合先经过公共平移，再送入标准化。平移方向被精确消除，所以仅凭标准化输出不能恢复该集合原来的均值。如果标签只由均值决定，而模型没有旁路保留这一信息，那么再强的后续层也无法区分那些标准化后完全相同的输入。这是信息层面的不可辨识，不是学习率或训练时间能够解决的问题。

类似地，epsilon 为零时正尺度被消除，许多不同幅度输入映成同一方向。真实实现中 epsilon 让这种等价变成近似，但若方差远大于 epsilon，尺度信息仍可能极弱。结构设计应先判断被消除的自由度是否是任务不变性，再把归一化看作有益约束。相同操作在一个任务上消除干扰，在另一个任务上可能删除信号，不能脱离任务语义评价。

<a id="nnb-3-detail-53"></a>

### 12.1 为什么可学习仿射不构成完全逆变换

归一化后的 $`\gamma,\beta`$ 是按约定坐标共享的参数，不知道每条输入原本的任意均值和方差。如果两条不同输入标准化后相同，固定仿射层仍会输出相同结果。因此“有缩放平移所以表达能力完全不受影响”通常过于宽泛。需要额外路径保留统计、改变归一化集合，或依赖任务本来不需要那些信息。

这也解释残差与归一化的协作：预归一化分支可以在适合处理的标准化表示上学习修正，同时主干保留未经该层标准化的原表示；后归一化则把相加结果整体变换。两种设计对于信息保留和尺度控制有不同取舍。局部推导帮助提出假设，但最后仍应在实际堆叠结构中检验，因为后续层和输出归一化可能再次改变信息路径。

<a id="nnb-3-detail-54"></a>

### 12.2 正交初始化与动态等距不能画等号

对线性方阵，如果权重严格正交，欧氏范数可以保持，所有奇异值为一。但加入 ReLU 后，数据相关掩码会改变局部雅可比秩与奇异值；非方形矩阵也不可能在输入和输出两侧都作为全维等距。即使每层权重具有良好谱，乘上归一化和激活导数后，整体条件仍需分析。

动态等距讨论的是相关输入与状态下整体或局部传播的奇异值分布接近理想形状，而不是简单把每个权重矩阵初始化为某种名字。有限宽度、深度、激活与训练更新都会影响这一性质。学习中可以先比较线性正交链与加入非线性后的方向范数，观察哪一步打破等距，再阅读更一般理论；不应把一个线性代数恒等式直接推广到复杂网络。

<a id="nnb-3-scale-sgd"></a>

### 12.3 相同前向函数为什么有不同有效步长

归一化除了改变信息，还会改变参数坐标与优化的关系。先在理想模型中精确说明：设数据损失在非零权重处可微，某个非零权重向量 $`w`$ 的正尺度不影响整个数据损失，即对所有 $`c>0`$ 有 $`L(cw)=L(w)`$。例如在方差非零、$`\epsilon=0`$ 的训练归一化中，同时缩放该支路全部预激活所需参数，可能满足这个条件；仅缩放一个通道、却经跨通道 LayerNorm，或固定推理运行统计时，不能自动使用该假设。

对标量 $`c`$ 求导得 $`w^Tg=0`$，其中 $`g=\nabla L(w)`$；对 $`w`$ 求导又得 $`c\nabla L(cw)=\nabla L(w)`$，所以梯度在放大坐标处缩小为 $`\frac{g}{c}`$。从 $`cw`$ 使用相同步长 $`\eta`$ 做普通 SGD，更新后除以 $`c`$，得到

```math
\frac{cw-\eta\nabla L(cw)}c=w-\frac{\eta}{c^2}g.
```

这给出严格的坐标比较：相同初始预测，参数尺度放大 $`c`$ 倍，相当于在原坐标用 $`\frac{\eta}{c^2}`$ 的步长。令 $`w=ru`$、$`\Vert u\Vert =1`$，正交条件还使 $`\Vert w-\eta g\Vert ^2=r^2+\eta^2\Vert g\Vert ^2`$；纯数据梯度虽不沿径向推动，有限切向更新仍会增大范数。小步下方向变化的一阶项为 $`-\frac{\eta g}{r}`$，结合 $`g(ru)=\frac{g(u)}{r}`$，可见方向学习尺度由 $`\frac{\eta}{r^2}`$ 控制。

举例取尺度不变损失 $`L(w)=-\frac{w_1}{\Vert w\Vert }`$。在 $`w=(0,1)`$ 处梯度为 $`(-1,0)`$，$`\eta=0.1`$ 后方向转动 $`\arctan(0.1)\approx5.7106`$ 度；在 $`2w=(0,2)`$ 处梯度为 $`(-0.5,0)`$，同一步长后方向只转动 $`\arctan(0.025)\approx1.4321`$ 度。前向损失起点完全相同，方向变化却不同；若把后者步长改为 $`0.4`$，两次更新后的方向才一致。

这种尺度与优化耦合也是[归一化和 L2 正则关系研究](https://arxiv.org/abs/1706.05350)的切入点。加入权重衰减会影响范数，因而即使数据函数近似尺度不变，训练仍可能改变；不能由前向不变就推断衰减毫无作用。有限 $`\epsilon`$、残差分支和未同步缩放的其他参数是否破坏不变性，需要分别核对；随机小批本身不必破坏恒等式，在同一批次上若仍满足精确尺度不变性，上述普通 SGD 推导仍成立。Adam 等优化器需要另行分析，不能直接照搬普通 SGD 的有效步长关系。

表中初始参数在同一射线上。使用相同步长更新后，第一组得到 $`(0.1,1)`$，第二组得到 $`(0.05,2)`$。横坐标除以纵坐标分别为 $`0.1`$ 与 $`0.025`$，即相对竖轴转角的正切。第二组初始尺度为第一组的两倍，更新后的转角正切却是第一组的四分之一。

## 13. 状态迁移、推理与部署时的检查

把含归一化网络从训练移到推理，应同时保存可学习参数、运行缓冲、模块配置和输入预处理。遗漏运行方差可能让输出大幅变化，即使所有线性权重都正确。若系统执行融合，例如把固定评估 BatchNorm 合并进前一仿射或卷积层，需要先固定其统计和仿射参数，再推导等效权重偏置；训练模式批统计不能被同样作为固定常数融合。

对线性输出 $`z=xW+b`$，固定归一化后的每个输出通道为 $`\frac{\gamma(z-\mu)}{\sqrt{v+\epsilon}}+\beta`$，可把缩放吸收到对应权重列，把偏置改为 $`\frac{\gamma(b-\mu)}{\sqrt{v+\epsilon}}+\beta`$。这个等价要求统计、模式和 epsilon 完全一致。若后续还有随机层、量化或不同数值精度，必须另行验证，不能只凭代数融合就宣称所有运行环境逐位一致。

<a id="nnb-3-detail-56"></a>

### 13.1 小批部署与请求拼批

服务系统可能每次只收到一条请求，也可能动态把不同用户请求拼成批。如果模型使用固定评估统计，通常可保持普通逐样本函数；若配置仍依赖当前批，某用户输出可能被其他用户的输入改变。这不仅影响复现，也影响接口语义。部署前应使用同一目标输入配不同同伴测试，而不只是跑一个固定测试批。

当统计集合只有一个值时，有些配置会报错，有些数学定义会退化为常数输出。不能通过简单复制同一个样本来假装获得独立批统计，因为复制没有增加信息，且可能改变方差估计含义。可考虑适合任务的归一化方式或明确固定统计，但选择需要基于训练与部署需求共同验证。

具体到 PyTorch 的 BatchNorm，使用当前批统计时，检查的是**每个通道参与统计的值数** $`m=N\prod_k S_k`$，不是只检查批大小 $`N`$。训练态的 `BatchNorm1d` 输入形状 `(1,C)` 会因 $`m=1`$ 报错；`BatchNorm2d` 输入 `(1,C,2,2)` 有 $`m=4`$，则可以计算，而 `(1,C,1,1)` 仍不成立。设 `track_running_stats=True` 并切换到评估态后，使用已有运行统计，单值输入可以通过；若设为 `False`，评估态仍使用当前批统计，不能借 `eval()` 绕过这个边界。LayerNorm 在归一化集合仅一个数时可数学上退化为仿射偏置输出，这与 BatchNorm 的实现检查要区分。参见 [BatchNorm2d 的统计模式](https://docs.pytorch.org/docs/2.10/generated/torch.nn.BatchNorm2d.html)及 [PyTorch 2.10 的单值检查](https://github.com/pytorch/pytorch/blob/v2.10.0/torch/nn/functional.py)。

<a id="nnb-3-detail-57"></a>

### 13.2 域适配与资料使用边界

在新域上重新估计运行统计是一种适配操作，可能有帮助，也可能因小样本或标签混合比例变化而恶化。它使用了新域资料，应记录适配数据量、是否含测试输入、是否按时间在线更新以及评价前后状态。若在线更新，预测系统就是一个随历史请求变化的状态机，离线评价需要模拟相同顺序，而不能把每个样本当作独立固定函数调用。

对于监管或可追溯需求，保存统计版本与更新时间有助于解释同样输入在不同日期为何得到不同结果。即使模型权重版本没变，缓冲变化也会改变函数。学习资料中的“状态”因此不只是工程细节，它直接决定数学对象和实验可复现性，应与参数一并纳入说明书。

<a id="nnb-3-detail-58"></a>

## 14. 归一化的轴、参数共享与数值稳定性

把特征维合并或拆分后，张量元素总数不变，归一化函数却可能改变。对于图像，把通道与空间展平后做一次 LayerNorm，等于在整张特征图共享统计；对每个像素只沿通道归一，则保留不同空间位置的独立统计。这两种操作对空间共同亮度、局部对比和位置信息的处理不同，不能用 reshape 能够还原尺寸就认定数学等价。应从每个输出依赖哪些输入元素出发画图核对。

此外，参数共享和统计共享也需要区别。两个位置可以使用相同缩放参数，却各自计算均值方差；也可以共享统计，但通过不同坐标的仿射参数输出不同值。前者限制可学习变换，后者引入数据依赖耦合，影响机制不同。读论文时要分别记录参数集合与统计集合，避免把“按通道”这类描述当作足够完整的定义。

从数值角度看，方差计算也应采用稳定方式。直接以平方均值减均值平方，在数值很大而真实方差很小时可能发生相消；框架实现通常考虑相应数值策略，但自定义归一化仍应专门用大公共偏移加微小扰动测试。理论上对公共平移不变，浮点实现却可能因有限精度产生差异，这需要通过合理精度、稳定算法和容差判断，而不是把数值误差误当成理论不变性失效。

最后，归一化层与损失尺度共同影响实际优化。若更换归一化后输出头的初始分数尺度变化，观察到交叉熵和梯度不同是整个系统的联动结果。公平对照应记录输出分布与初始化方式，必要时分别比较原始配置和校准尺度后的配置。只有把改变的变量显式列出，才能判断收益主要来自前向表示、局部条件、随机统计还是简单尺度差异。

诊断训练故障时，同一最小输入可用于比较修正前后的前向、反向和参数更新。这样才能区分修复的影响与采样波动。
