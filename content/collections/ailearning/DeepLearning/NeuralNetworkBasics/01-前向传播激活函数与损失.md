## 1. 从一个可执行函数理解神经网络

神经网络首先是由参数控制的函数，而不是一组神经元图标。给定输入、参数、模式和必要状态，前向传播必须规定一个可重复的输出。设一条表格记录含温度、压力、历史计数三个数，网络输出设备故障的分数；输入列的单位、缺失值处理和列顺序都是函数定义的一部分。即使权重完全不变，把摄氏温度换成未经转换的华氏温度也会改变预测。理解网络应先写清“什么信息在预测时可用，输出对应哪个事件”，再考虑层数。

本章把前向计算、表达能力与统计目标连接起来。前向计算回答一组输入如何得到数值，表达能力回答参数变化能够形成哪些函数，统计目标回答训练希望在何种分布上逼近什么量。这三个问题相关却不能互相替代。一个计算没有形状错误的网络可以优化错误标签；一个存在理想参数的网络可以训练失败；一个训练集上拟合很好的函数可以在新分布上失效。每次实验应注明正在检验哪一层结论。

先修矩阵运算可查[线性代数](../../Mathematics/LinearAlgebra/README.md)，微分记号见[梯度雅可比与形状约定](../../Mathematics/MatrixCalculus/01-梯度雅可比与形状约定.md)。本章采用行向量批量约定，库内部权重的存储布局另行说明；这样可以在每条公式旁直接检查输入特征与输出特征。

<a id="nnb-1-detail-2"></a>

### 1.1 模型、预处理与输出解释组成同一契约

完整预测可写为 $`x\mapsto T(x)\mapsto f_\theta(T(x))\mapsto D(f_\theta(T(x)))`$。其中 $`T`$ 是只使用训练资料拟合并固定的预处理，$`f_\theta`$ 是参数化网络，$`D`$ 是把分数解释成概率、数值或决策的规则。阈值和类别字典归入最后一步，不能认为它们是无关紧要的展示代码。若训练时类别零表示正常而部署时表示故障，即使分数逐位一致，实际决策也已经颠倒。

训练目标另写为 $`\widehat R(\theta)=n^{-1}\sum_i\ell(f_\theta(T(x_i)),y_i)`$。批量只是计算这个目标的分组方法，不天然意味着样本彼此相互影响。普通逐样本全连接网络在没有批归一化等耦合操作时，把样本换一个顺序只会相应重排输出。这个性质给出很实用的前向检查：单样本输出应与同一样本放在批量中的对应行一致。后面会说明在哪些结构中这个检查不再成立。

标签生成也要遵守预测时间。如果预测未来一天的故障，却把故障之后填写的维修说明作为输入，网络仍会给出漂亮的损失，但它学到的是信息泄漏。前向公式无法替数据时间契约作证。教材中的小数组消除了这些业务复杂性，真实项目需要另外保存特征可用时间、标签窗口和样本划分规则。

## 2. 逐层形状、参数共享与完整手算

采用 $`X\in\mathbb R^{B\times D}`$，第一层权重 $`W_1\in\mathbb R^{D\times H}`$、偏置 $`b_1\in\mathbb R^H`$，第二层权重 $`W_2\in\mathbb R^{H\times K}`$、偏置 $`b_2\in\mathbb R^K`$。定义

$$
\begin{aligned}
Z_1 &=XW_1+\mathbf1_B b_1^T,\\[6pt]
H_1 &=\phi(Z_1),\\[6pt]
S &=H_1W_2+\mathbf1_B b_2^T.
\end{aligned}
$$

输出 $`S`$ 的形状为 $`B\times K`$。矩阵乘法收缩输入特征轴，激活逐元素作用，偏置沿批轴复用。参数总数为 $`DH+H+HK+K`$，不会因为批大小变化而增加。批大小改变运行内存与损失估计噪声，却没有凭空创造新权重；如果实现把批轴写进参数尺寸，就必须重新检查模型是否意外记住了批中位置。

<a id="sec-2-1"></a>

<a id="nnb-1-detail-4"></a>

### 2.1 两条样本、两个隐藏单元的前向账本

取 $`X=((1,2),(-1,1))`$，$`W_1=((1,-1),(2,1))`$，$`b_1=(0,-1)`$。第一条样本得到 $`(5,0)`$，第二条得到 $`(1,1)`$。应用 ReLU 后数值没有变化。再取 $`W_2=((1,2),(-1,1))`$，$`b_2=(0.5,-0.5)`$，输出分别为 $`(5.5,9.5)`$ 和 $`(0.5,2.5)`$。每一步都应能够从一行输入和一列权重手算出来，而不是只确认最后打印了两个类别。

此网络含 $`2\times2+2+2\times2+2=12`$ 个参数。若把两条样本扩展为两百条，参数仍为十二个；若把隐藏宽度改为三，参数变为十七个，变化来自特征映射而非样本数。偏置不是“额外样本”：它为每条样本相同的隐藏坐标添加同一常数。在反向传播中，这种共享要求跨样本累加梯度，下一章会推导。

实现权重可能采用转置存储。PyTorch 的全连接层通常存储形状为输出维乘输入维的权重，并计算输入乘权重转置。数学上用 $`XW`$ 完全合法，但把本章 $`W`$ 直接复制进库层时需要转置。判断应依据实际矩阵相乘的含义，而不依据变量名中出现了多少次“weight”。

<a id="nnb-1-detail-5"></a>

### 2.2 广播能运行不代表语义正确

设真实预测形状为 $`(B,1)`$，标签误存为 $`(B,)`$。逐元素相减可能广播成 $`(B,B)`$，让每条预测与全部标签比较。程序不报错，损失也可能下降，却优化了一个完全不同的目标。形状检查应使用严格断言，必要时明确扩展最后一维，不依赖自动广播猜测意图。相反，偏置从 $`(H,)`$ 广播到 $`(B,H)`$ 是有意共享，这种广播应该记录在数学模型中。

序列输入通常为 $`(B,T,D)`$。对最后一维应用同一个线性层得到 $`(B,T,H)`$，参数在时间位置共享，但这一步不交换不同位置的信息。把输入展平为 $`(B,TD)`$ 再做全连接则允许不同位置使用不同权重，两者函数族不同。仅把序列维写进张量并不会产生时间建模能力；注意力、卷积或循环结构才定义位置间如何交互。

批处理的行独立性也有边界。训练模式 BatchNorm 使用当前批统计，会使一个样本的输出依赖同批其他样本；注意力若错误地沿批轴归一化，也会造成样本之间混合，但那通常是实现错误。检查独立性前先说明网络设计是否需要耦合，不能把所有非独立现象都归为同一种问题。

### 2.3 实验一：手算、批量与库层三方一致

下列实验只用 CPU 双精度张量，不训练、不读文件。断言同时检验手算值、逐行计算、批内重排和库层转置。它比单独检查输出形状更严格，因为形状正确的错误矩阵也可能通过简单接口测试。

```python
import torch
from torch import nn

torch.set_num_threads(1)
dtype = torch.float64
x = torch.tensor([[1., 2.], [-1., 1.]], dtype=dtype)
w1 = torch.tensor([[1., -1.], [2., 1.]], dtype=dtype)
b1 = torch.tensor([0., -1.], dtype=dtype)
w2 = torch.tensor([[1., 2.], [-1., 1.]], dtype=dtype)
b2 = torch.tensor([.5, -.5], dtype=dtype)

def forward(v):
    return torch.relu(v @ w1 + b1) @ w2 + b2

expected = torch.tensor([[5.5, 9.5], [.5, 2.5]], dtype=dtype)
assert torch.equal(forward(x), expected)
assert torch.equal(torch.cat([forward(row[None]) for row in x]), expected)
assert torch.equal(forward(x.flip(0)), expected.flip(0))
model = nn.Sequential(nn.Linear(2, 2), nn.ReLU(), nn.Linear(2, 2)).to(dtype)
with torch.no_grad():
    model[0].weight.copy_(w1.T)
    model[0].bias.copy_(b1)
    model[2].weight.copy_(w2.T)
    model[2].bias.copy_(b2)
assert torch.equal(model(x), expected)
assert sum(p.numel() for p in model.parameters()) == 12
print('forward checks passed', expected.tolist())
```

## 3. 为什么非线性改变了函数家族

两层仿射映射复合为 $`f(x)=(xW_1+b_1)W_2+b_2=x(W_1W_2)+(b_1W_2+b_2)`$，所以任意多层无激活网络仍是一个仿射函数。新增层改变参数化、可能改变秩限制和优化轨迹，却不会自动获得弯曲决策边界。这个结论要求层间只有仿射操作；归一化、乘法门控和输入依赖的选择也可能引入非线性，不能仅凭“没有 ReLU”就断言整个网络线性。

线性层堆叠的秩上界由最窄中间维度限制。如果输入输出都是十维，中间只有三维，则复合矩阵秩不超过三。增加层数可能使函数族比一个任意十乘十矩阵更受限制。因此“合并后是一个线性层”说的是存在等效映射，不是说所有线性映射都能由给定瓶颈表示。低秩适配和矩阵分解利用的正是这种参数化结构。

<a id="deep-dive-2"></a>

<a id="nnb-1-detail-8"></a>

### 3.1 ReLU 用折点构造非线性几何

ReLU 为 $`\phi(t)=\max(0,t)`$。一个单元 $`\phi(w^Tx+b)`$ 由超平面 $`w^Tx+b=0`$ 划分活动区和零区。在固定激活模式内，多层 ReLU 网络可化为仿射映射；跨越模式边界时，局部映射改变。网络整体连续且分段仿射，非线性来自区域之间的拼接，而不是每个区域内部隐藏了复杂曲线。

标量绝对值可精确写为 $`\vert x\vert =\operatorname{ReLU}(x)+\operatorname{ReLU}(-x)`$。三角帽函数可写为 $`\operatorname{ReLU}(x+1)-2\operatorname{ReLU}(x)+\operatorname{ReLU}(x-1)`$，在区间外为零，在中间形成尖顶。权重负责放置和组合折点，宽度控制同层可用的构件，深度则让前一层构件继续参与组合。这些构造给出具体表达实例，比仅说网络“能学习任意模式”更有可检验性。

在二维中，线性阈值无法分开 XOR 的四个顶点。把坐标和 $`s=x_1+x_2`$ 送入两个 ReLU 单元，可令 $`g(s)=\operatorname{ReLU}(s)-2\operatorname{ReLU}(s-1)`$，在 $`s=0,1,2`$ 处输出 $`0,1,0`$。阈值设为二分之一便能正确分类四点。这是有限点上的精确构造，不意味着该函数在整个平面上符合所有关于“异或”的语义；对连续输入如何定义标签需要额外约定。

<a id="nnb-1-detail-9"></a>

### 3.2 激活比较应追踪值、导数与输出含义

sigmoid 为 $`\sigma(t)=\frac{1}{(1+e^{-t})}`$，导数为 $`\sigma(t)(1-\sigma(t))`$，最大值为四分之一。它将实数映到零与一之间，适合作为伯努利概率的连接函数，但深层隐藏网络反复经过饱和区时会压缩梯度。tanh 输出以零为中心，导数为 $`1-\tanh^2(t)`$，仍存在两侧饱和。零均值输出有时便于尺度管理，却不是训练成功的充分条件。

ReLU 正半轴导数为一，负半轴为零，零点不可微，自动微分必须选择约定。长期在所有训练输入上处于负区间的单元可能收不到该支路梯度，但“本批零值多”不等于永久死亡；输入改变、上游参数改变或偏置变化都可能让它重新激活。Leaky ReLU 在负半轴保留小斜率，降低某类死区风险，同时也改变输出均值、二阶矩与合适初始化尺度。

GELU 写为 $`t\Phi(t)`$，其中 $`\Phi`$ 为标准正态分布函数；SiLU 写为 $`t\sigma(t)`$。它们是平滑门控函数，负区间不等同于简单线性泄漏，某些局部导数也不能凭“平滑”推断始终介于零与一。选择激活时应结合结构、初始化、计算成本和对照实验。单看一张函数曲线不足以预测整个优化过程，更不能把在某任务上的经验排名当作普遍定理。

<a id="nnb-1-detail-10"></a>

### 3.3 实验二：表达构造与线性不可分的代数证据

下面验证两个精确函数构造，并用线性分离不等式说明 XOR 的矛盾。若正类要求 $`w_1+b>0,w_2+b>0`$，负类要求 $`b<0,w_1+w_2+b<0`$，前两式相加给出 $`w_1+w_2+2b>0`$；后两式相加给出同一左侧小于零，不可能同时成立。程序验证构造，不用一次随机训练失败来冒充不可分证明。

```python
import torch

torch.set_num_threads(1)
x = torch.linspace(-3, 3, 121, dtype=torch.float64)
assert torch.equal(torch.relu(x) + torch.relu(-x), x.abs())
hat = torch.relu(x + 1) - 2 * torch.relu(x) + torch.relu(x - 1)
expected = (1 - x.abs()).clamp(min=0)
assert torch.allclose(hat, expected, atol=1e-14, rtol=0)
points = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]], dtype=x.dtype)
s = points.sum(dim=1)
score = torch.relu(s) - 2 * torch.relu(s - 1)
assert torch.equal(score, torch.tensor([0., 1., 1., 0.], dtype=x.dtype))
assert torch.equal(score > .5, torch.tensor([False, True, True, False]))
print('piecewise constructions passed', score.tolist())
```

## 4. 表达能力的保证与无法保证的部分

逼近理论通常指定输入域、目标函数类别、网络结构、参数约束以及误差范数。例如在一个紧区间上，连续函数可以由足够密的分段线性插值逼近，而一维分段线性函数可由仿射项和若干移位 ReLU 的线性组合表示。这给出一个可直接证明的逼近途径：连续函数在紧集上一致连续，网格足够细时线性插值与目标的一致误差足够小，再把每个斜率变化编码为一个 ReLU 折点。

这个构造并未给出所有高维函数的高效表示。网格插值在维数上升时可能需要极多网格点，所需宽度与参数量可能迅速增长。若目标具有组合结构，深层网络可能更有效率，但必须说明函数类与复杂度度量。所谓通用逼近不是“一个很窄网络在有限训练时间内总能学好一切”，更不是分布外安全性的证明。

<a id="sec-6-1"></a>

<a id="nnb-1-detail-12"></a>

### 4.1 近似、估计、优化三个误差来源

理想风险为 $`R(f)=\mathbb E[\ell(f(X),Y)]`$。在选定函数族内寻找风险最小值，与在有限样本上最小化经验风险是不同问题；实际优化器又只能给出某个有限迭代状态。表达不足对应函数族不能接近理想目标，样本不足对应经验目标与总体目标差异较大，优化困难对应实际参数未达到经验目标的好解。三者不能从一条训练曲线中唯一分解，但可以通过有针对性的实验缩小解释范围。

增加宽度可能降低近似误差，也可能改变优化难度和估计方差；降低训练误差不保证总体误差同步下降。反过来，训练误差稍高而验证更好可以来自合适正则或数据噪声抑制。讨论“网络更强”时，应报告使用的是训练损失、样本外指标、参数效率还是计算效率，避免一个模糊形容词承担所有结论。

<a id="sec-4"></a>

<a id="nnb-1-detail-13"></a>

### 4.2 记忆随机标签与学习可迁移结构

足够大的模型可以拟合一组随机对应的输入标签，但新样本上的随机标签不可由输入预测。这个对照分离了记忆能力与结构学习：训练集表现优秀只能说明模型在给定数据上完成拟合。若数据标签包含可重复规律，还要依赖采样、归纳偏好和优化过程把规律优先利用起来。随机标签实验是诊断工具，不宜把它解释为所有大网络必然泛化差。

表示的解释也需要谨慎。同一隐藏表示经过可逆线性变换，再由下一层吸收逆变换，可能保持输出不变。因此隐藏坐标的名字和次序通常不是唯一的“真实概念”。观察某个神经元对一类样本响应较大，只提供相关线索；需要遮挡、消融、干预和跨数据验证才能讨论它对预测的因果贡献。网络内部的可解释性问题不能靠给每层取一个语义名称解决。

## 5. 从分数到概率：输出层定义随机对象

分类网络末端通常先产生无约束实数分数，称为 logits。分数不是概率，负数合法，整体加常数也可能不改变概率。单标签多分类假设每条样本恰有一个类别，令 $`s\in\mathbb R^K`$，采用 $`p_k=\frac{e^{s_k}}{\sum_j e^{s_j}}`$。这使概率非负且总和为一，类别之间存在竞争；提高一个分数同时会降低其他类别的概率，即使那些类别的分数没有变化。

多标签任务则允许多个事件同时发生，例如图片同时包含猫和树。对每个标签设置一个伯努利输出 $`p_k=\sigma(s_k)`$，并把各标签负对数似然相加，是常见建模方式。输出之间没有概率和为一的约束。使用逐标签损失不等于宣称真实标签在所有意义上独立；它可用于分别估计条件边缘概率，而联合事件概率仍需要额外依赖建模。若要计算“猫和树同时出现”的概率，不能无条件把两个边缘概率相乘。

<a id="sec-5"></a>

<a id="nnb-1-detail-15"></a>

### 5.1 单标签、软标签与多标签不可仅看形状区分

单标签整数 $`y\in\{0,\ldots,K-1\}`$ 表示互斥类别；对应独热向量只是一种编码。软标签 $`q\in\mathbb R^K`$ 可以表示同一互斥类别变量上的概率分布，要求各项非负、总和为一。多标签向量的多个分量可以同时为一，其和没有必须等于一的限制。两种目标都可能采用浮点数组，形状也可能完全相同，必须依据语义判断损失。

把多标签 $`(1,1,0)`$ 送入 softmax 交叉熵，即使接口允许计算，也会迫使两个真实事件争夺总概率。反过来，把单标签任务当成彼此无关的二分类，输出总和可能不为一，决策和概率解释不同。它仍可能在某些评价规则下得到有效分类器，却不是同一个条件分布模型。比较时需要同时观察损失、解码规则和校准，而不能因为最终都能执行 argmax 就认定完全等价。

目标缺失与负标签也不同。某标签没有标注，不自动意味着事件为假。若把未标注位置全部编码成零，会鼓励模型压低这些可能为真的事件。需要使用有效性掩码并明确分母，或采用与标注机制匹配的学习目标。这个问题在大规模多标签数据中常比增加几层网络更直接地决定训练上限。

<a id="nnb-1-detail-16"></a>

### 5.2 二分类的一分数与两分数参数化

二类 softmax 的第二类概率为 $`\frac{e^{s_1}}{(e^{s_0}+e^{s_1})}=\sigma(s_1-s_0)`$。因此在没有额外约束时，一个 logit $`a=s_1-s_0`$ 足以描述相同概率。两分数共享平移方向不可识别：同时给两个分数加相同常数不改变结果。参数化冗余可能影响正则项和优化轨迹，所以概率表达相同不等于两套训练配置数值行为完全相同。

例如对两类权重分别加平方惩罚，给定差值时最小惩罚发生在对称分配，而单分数参数化的惩罚尺度需要另行对齐。若只是把输出层从二维改为一维并保留所有超参数，就不能把性能差异完全归因于“sigmoid 比 softmax 更好”。比较要先匹配有效 logit、损失归约和正则强度。

多分类 logits 也只有相对差值影响概率。训练后某个样本的所有 logits 都很大，并不意味着预测一定自信；例如 $`(1000,1000)`$ 仍对应二分之一概率。应该查看差值、熵或明确的概率量，而不是盯着最大分数的绝对值。

<a id="nnb-1-detail-17"></a>

## 6. 交叉熵为何采用 logits 形式

互斥类别的负对数似然为 $`\ell(s,y)=-\log p_y=\log\sum_j e^{s_j}-s_y`$。写成 log-sum-exp 后，可以直接处理大幅度分数。令 $`m=\max_j s_j`$，有

$$
\begin{aligned}
\operatorname{LSE}(s) &=m+\log\sum_j e^{s_j-m},\\[6pt]
\ell(s,y) &=\log\sum_j e^{s_j-m}+(m-s_y).
\end{aligned}
$$

移位后指数输入不大于零，避免直接计算巨大正指数。正确类别概率非常小时，其负对数仍可能是一个有限的大数；若先把概率舍入为零再取对数，则人为制造无穷。稳定损失的价值是尽量保留原本可计算的数学信息，而不是在结果出错之后任意截断。

<a id="nnb-1-detail-18"></a>

### 6.1 梯度与曲率解释类别竞争

对 one-hot 标签向量 $`e_y`$，梯度为 $`\nabla_s\ell=p-e_y`$。正确类别梯度为 $`p_y-1`$，梯度下降会提高它的分数；其他类别梯度为 $`p_k`$，会被压低。梯度分量和为零，与公共平移不影响损失相对应。这个结构还能发现实现错误：如果无权标准交叉熵对某条样本的所有类别梯度之和明显不为零，应重新检查归约、标签或额外项。

Hessian 为 $`\operatorname{diag}(p)-pp^T`$。对任意向量 $`v`$，二次型等于以 $`p`$ 为权重的 $`v_k`$ 方差，因此非负，说明损失对 logits 是凸的。公共常数方向上的曲率为零，所以通常不是严格凸。把 logits 改成非线性网络参数之后，参数到分数的复合会引入额外曲率，不能由 logit 凸性推出整个深层网络训练是凸优化。

对软标签 $`q`$，交叉熵为 $`-\sum_k q_k\log p_k`$，若 $`\sum q_k=1`$，梯度仍为 $`p-q`$。若标签和为 $`c`$ 而不是一，梯度变成 $`cp-q`$，损失尺度和目标解释均改变。某些软件接口不会替用户验证概率合法性，计算结果有限不意味着软标签满足概率契约。应在读取数据时检查非负性、有限性和逐行和，而不是指望损失函数替数据做统计判断。

<a id="nnb-1-detail-19"></a>

### 6.2 伯努利负对数似然的稳定推导

二元标签 $`y\in\{0,1\}`$ 的损失为 $`-y\log\sigma(a)-(1-y)\log(1-\sigma(a))`$，可化为 $`\operatorname{softplus}(a)-ya`$。稳定形式为

$$
\ell(a,y)=\max(a,0)-ya+\log(1+e^{-\vert a\vert }).
$$

它在极端分数下依然避免直接构造接近零的概率。导数为 $`\sigma(a)-y`$，曲率为 $`\sigma(a)(1-\sigma(a))`$。当模型非常自信且预测错误时，梯度幅度接近一，不会因为先经过 sigmoid 的饱和导数就必然消失；似然中的导数组合已经发生抵消。这是理解“隐藏 sigmoid 饱和”和“输出 BCE 梯度”时必须区分的地方。

对概率直接施加平方损失则不同：$`\frac12(\sigma(a)-y)^2`$ 的导数还多乘 $`\sigma(a)(1-\sigma(a))`$。错误且饱和时，修正信号可能非常小。两种损失都可以定义，但对应的优化几何不同。是否采用它们不能仅凭输出同处零到一之间判断，必须明确概率建模和训练动态。

<a id="nnb-1-detail-20"></a>

### 6.3 为什么不能先 softmax 再交叉熵

若损失接口期待 logits，传入已经 softmax 的概率会让内部再次进行 softmax。实际优化概率变成 $`\operatorname{softmax}(\operatorname{softmax}(s))`$，改变可达到的分布范围、梯度和置信度。以两个类别为例，即使第一层概率趋向 $`(1,0)`$，第二次 softmax 的最大概率也只能趋向 $`\frac{e}{(e+1)}`$，损失无法接近零。这不是数值精度问题，而是模型函数被改写。

对应地，期待原始 logit 的二元损失前也不应再加 sigmoid。推理展示概率与训练传入 logits 可以分开，避免为了方便画图而改变目标。若手写损失，应直接实现稳定的 log-probability 或调用匹配接口；不能把取对数前任意加小常数当成与原始似然完全相同的计算，截断和加常数都会在极端区间改变梯度。

<a id="nnb-1-detail-21"></a>

### 6.4 实验三：极端分数、平移不变与梯度恒等式

实验使用四条三分类样本，包含幅度一千的 logits。分别检验稳定公式、公共平移不变性和 $`p-e_y`$ 梯度。二元部分覆盖正负一千与正确、错误标签的组合。最后显式构造重复 softmax，确认它与原目标不同。断言使用双精度容差；没有把浮点小差异解释成理论反例。

```python
import torch
from torch.nn import functional as F

torch.set_num_threads(1)
dtype = torch.float64
s = torch.tensor([[1000., 999., -1000.], [-1000., 0., 1000.],
                  [0., 0., 0.], [2., -1., .5]], dtype=dtype, requires_grad=True)
y = torch.tensor([0, 0, 2, 1])
loss = F.cross_entropy(s, y, reduction='none')
m = s.max(dim=1, keepdim=True).values
manual = (s - m).exp().sum(dim=1).log() + (m[:, 0] - s[torch.arange(4), y])
assert torch.isfinite(loss).all()
assert torch.allclose(loss, manual, atol=1e-12, rtol=1e-12)
assert torch.allclose(loss, F.cross_entropy(s + 1234., y, reduction='none'), atol=1e-12)
grad, = torch.autograd.grad(loss.sum(), s)
expected = s.softmax(dim=1) - F.one_hot(y, 3).to(dtype)
assert torch.allclose(grad, expected, atol=1e-12)
assert torch.allclose(grad.sum(dim=1), torch.zeros(4, dtype=dtype), atol=1e-12)
a = torch.tensor([-1000., 1000., -1000., 1000.], dtype=dtype, requires_grad=True)
b = torch.tensor([0., 1., 1., 0.], dtype=dtype)
binary = F.binary_cross_entropy_with_logits(a, b, reduction='none')
stable = a.clamp_min(0) - a*b + torch.log1p(torch.exp(-a.abs()))
assert torch.allclose(binary, stable, atol=1e-12)
g, = torch.autograd.grad(binary.sum(), a)
assert torch.equal(g, a.sigmoid() - b)
confident = torch.tensor([[20., -20.]], dtype=dtype)
correct = F.cross_entropy(confident, torch.tensor([0]))
wrong = F.cross_entropy(confident.softmax(dim=1), torch.tensor([0]))
assert correct < 1e-12 and wrong > .3
print('stable loss checks passed', loss.detach().tolist(), binary.detach().tolist())
```

## 7. 回归输出的范围、分布与误差尺度

无约束实数回归常使用线性输出。平方损失总体最优预测为条件均值，因为给定输入后，$`\mathbb E[(a-Y)^2\mid X=x]=(a-\mathbb E[Y\mid x])^2+\operatorname{Var}(Y\mid x)`$。第二项与预测值无关，第一项在条件均值处最小。绝对损失的最优点为条件中位数，分位数损失则对应指定条件分位数。改变损失是在改变想要估计的统计量，而不只是给同一个答案换了一种误差刻度。

如果价格必须为正，可让网络输出 $`a`$ 后采用 $`\operatorname{softplus}(a)`$ 或对数链接，但输出变换会改变可表达范围和梯度。对数空间 MSE 对应的是对数目标的条件均值，指数返回后通常不是原尺度条件均值；随机变量指数的期望不等于期望的指数。需要原尺度均值时，应明确分布假设与适当校正，不能只因为预测都为正就认为目标一致。

<a id="nnb-1-detail-23"></a>

### 7.1 有界比例与边界可达性

对零与一之间的连续比例使用 sigmoid 输出，可以保证开区间范围，但有限 logit 无法精确达到零或一。在存在大量真边界值的任务中，最优参数可能不断增大幅度，或需要显式边界概率模型。若标签只是带噪测量的比例，是否使用平方损失、伯努利似然或适合连续比例的分布，要由数据产生机制决定。数值范围相同并不意味着它们是同一种随机对象。

把无约束预测在推理后裁剪到合法范围也不等同于在训练图中使用有界连接函数。后处理裁剪对范围外输出给出固定决策，训练过程仍优化原实数预测；图内裁剪又会产生零梯度区。二者可以服务不同目标，但应说明测评在裁剪前还是裁剪后进行，并防止模型通过非常极端的原始值掩盖尺度问题。

<a id="nnb-1-detail-24"></a>

### 7.2 多输出的单位决定梯度竞争

一个网络同时预测温度和压力，若前者误差约十、后者误差约千，直接相加平方误差往往让压力支配训练。标准化目标可以使数值尺度接近，但这同时改变了原尺度上的相对任务权重。若采用 $`\sum_j\frac{(\hat y_j-y_j)^2}{\sigma_j^2}`$，它相当于按目标尺度平方倒数加权，不是无影响的编码步骤。任务代价、噪声大小和评估规则应共同决定权重。

异方差高斯回归还可以输出均值 $`\mu(x)`$ 与对数方差 $`v(x)`$，负对数似然含 $`\frac12e^{-v}(y-\mu)^2+\frac12v`$。第二项防止通过无限增大方差逃避残差惩罚；只保留第一项会得到退化目标。预测方差能否代表真实不确定性，需要样本外检验和分布假设，不能因输出头名为“不确定性”就自动赋予可靠解释。

<a id="nnb-1-detail-25"></a>

## 8. 决策边界、置信度与校准不是同一个指标

分类决策通常取最大概率类别。由于 softmax 保持分数大小次序，直接对 logits 取 argmax 得到相同类别；但计算概率、交叉熵和阈值时仍需适当变换。二分类默认一分之二概率阈值对应零 logit，并不适合所有代价结构。若假阴性代价远高于假阳性，最优决策阈值可以明显低于一分之二；这属于决策层约定，不应通过偷偷交换标签含义解决。

概率校准讨论：在模型给出某概率的一组样本中，事件实际出现频率是否与该概率相近。准确率只关注类别是否正确，无法判断模型把正确类别概率从零点六提高到零点九九是否合理。交叉熵对自信错误敏感，因此相同准确率下损失可以差异很大。模型选择应依据目标用途：排序、概率估计和固定阈值决策需要的证据各有不同。

<a id="nnb-1-detail-26"></a>

### 8.1 温度缩放改变概率但不改变最大类别

对正温度 $`T`$，使用 $`p_k(T)=\operatorname{softmax}(\frac{s}{T})_k`$。除数为正所以最大类别保持不变；增大温度使分布更平，减小温度使分布更尖。若在独立校准集上选择温度，可以改进某些概率指标，但一个标量温度无法修复类别混淆、样本依赖偏差或分布外输入。若校准数据与部署分布不一致，校准结论也可能失效。

温度拟合使用的数据已经参与模型选择，不能继续当作完全未使用的最终测试资料。若反复用同一测试集调整温度、阈值、类别权重和层数，得到的测试指标会带有选择偏差。这个问题不是神经网络专属，但大网络提供大量可调选项，使把验证与测试职责分开尤其必要。

同时给所有 logits 加常数与调温度不同：加常数不改变任何概率，乘正系数改变概率差距但保持排序。对照这两种变换有助于理解所谓“logit 尺度”：公共平移方向与类间差异方向承担不同作用。记录平均最大 logit 时若不消除公共平移，可能把完全无关的漂移解释为置信度变化。

<a id="nnb-1-detail-27"></a>

### 8.2 分类间隔为什么仍不能证明稳健

对正确类别与最强竞争类的分数差定义间隔。间隔大意味着在固定输入处有较明显的分数优势，但输入稍变时分数变化多快还取决于网络的局部导数。若输入到分数的 Lipschitz 上界为 $`L`$，则可以在相应范数与输出差值条件下推导一个保守扰动半径；仅有 logit 间隔而无变化率信息，不能推出多大的输入扰动仍安全。

最简单的反例是把所有权重连同输入尺度任意放大，某些点上分数间隔很大，但决策边界在输入空间中仍可能离样本很近。神经网络可以在训练点周围构造陡峭区域，也可能在看起来陌生的输入上自信输出某类。分类概率是给定模型和输入下的条件输出，不是“这个输入属于训练分布”的检测证书。

研究分布外可靠性应单独定义偏移类型，例如光照改变、缺失传感器、新类别或采样人群变化，并在对应资料上评价。把训练分布上的校准结论直接推广到所有偏移，是把一个有条件的统计观察扩大为没有证据的保证。应保留模型已知适用范围，说明缺失数据、超范围特征和未知类别怎样处理。

## 9. 输入变换、隐藏表示与函数等价

对每个输入维度做标准化，可以减少由单位差异导致的初始数值失衡，但它也属于训练参数化。若 $`z=\frac{(x-\mu)}{\sigma}`$，后接 $`zW+b`$，可以代数改写为原输入上的另一个仿射层。函数表达能力在可逆变换下可能保持相同，优化器看到的参数几何却不同。相同学习率作用于不同尺度参数，会产生不同的有效函数变化。

预处理统计只应在训练集上拟合；使用验证或测试分布计算均值方差，即使没有读取标签，也可能泄露关于评价分布的信息。某些明确的无监督适配设置允许使用目标域无标签数据，但需要把这种权限作为实验协议公开说明。不能一方面宣称完全未知目标域，另一方面利用完整目标资料调整输入变换。

<a id="nnb-1-detail-29"></a>

### 9.1 缺失值不能只用一个数字掩盖

将缺失值填成零可能把“未观测”与“真实为零”混为一谈。可以增加缺失指示变量，并根据训练统计选择合理填充值；这样网络有机会学习缺失机制的信息，但也可能依赖与部署不稳定的采集流程。若某医院只在病情严重时检查特定指标，缺失标记可能强烈预测标签，换一家医院的检查策略后关系便改变。

在数学实验中，所有输入都是完整有限数，故前向定义简单。真实数据首先需要检查非有限值、数值单位、异常编码与类别字典。一串数字即使能转成浮点张量，也未必表达同一种变量。尤其日期时间、编号与真实连续量，不应因为都能参与矩阵乘法就默认具有相同距离含义。

<a id="nnb-1-detail-30"></a>

### 9.2 单元置换与正比例缩放的等价类

若把隐藏层单元排列为另一个次序，并在下一层使用对应逆排列，整体函数保持不变。这说明隐藏单元编号没有独立意义，也说明参数空间存在许多表示同一函数的位置。直接对两个独立训练模型逐位置平均参数，可能混合语义不对应的单元；输出集成则不需要先解决这种坐标匹配，但计算与存储代价不同。

ReLU 还满足正齐次性 $`\operatorname{ReLU}(ct)=c\operatorname{ReLU}(t)`$，其中 $`c>0`$。将某单元输入权重和偏置乘以 $`c`$，再将它的输出权重除以 $`c`$，可以保持函数不变。可是平方权重惩罚会随这种重参数化变化，参数范数不能脱离具体参数化被解释为唯一的函数复杂度。这个例子也解释为何“权重变小”并不总能直接推出预测函数变化更小。

共享参数则主动限制这种自由度。卷积把同一局部核应用到不同空间位置，序列逐位置投影把同一矩阵应用到各时间位置。共享降低参数量并表达结构假设，也要求数据坐标具有相应可比性。在一个位置共享有效不意味着在所有维度共享都合理；把不同业务含义的特征当作可随意平移的像素，可能错误引入对称性。

<a id="nnb-1-detail-31"></a>

## 10. 研究网络需要区分四类对照

第一类是函数等价对照，例如仿射层合并、隐藏单元置换或 logits 公共平移。目标是证明实现计算了同一函数，可以用代数与逐样本数值比较。第二类是表达能力对照，例如有无非线性的 XOR 构造，目标是说明是否存在可实现解。第三类是优化对照，固定数据和可达到目标，比较学习过程能否到达好参数。第四类是泛化对照，在独立资料上比较迁移表现。这四种证据不能相互替代。

例如观察到更深网络训练得更快，可能来自参数化和优化器的相互作用，不足以证明浅网络无法表达目标。观察到某激活在一次训练中准确率较高，也不足以证明它有更强通用逼近性质。研究报告应把理论断言、受控实验与有限观察分别写清，再讨论它们如何共同支持结论。

<a id="nnb-1-detail-32"></a>

### 10.1 从前向账本建立可证伪假设

提出假设“宽度增加改善了表达瓶颈”时，可以先固定任务，构造明确不足的窄层，再检查训练集极小问题是否可拟合。若宽度改变同时使参数数目、初始化、学习率和训练时间都变化，解释就不再唯一。应记录每个网络的参数量、每步计算量、总步数与超参数选择方式，明确比较按什么预算公平。

提出假设“激活饱和导致训练慢”时，除了最终损失，还应记录饱和区比例、局部导数和相邻层梯度；再使用降低输入尺度或替换激活等最小干预观察变化。单纯看某一层均值偏大无法唯一识别饱和，因为均值可能掩盖不同样本与通道的差异。可重复的局部证据通常比一条漂亮训练曲线更有解释力。

<a id="nnb-1-detail-33"></a>

### 10.2 防止选择性报告与种子偶然性

确定性小实验适合验证代数和接口；随机训练实验则需要考虑种子、数据顺序和样本划分的波动。若只挑表现最好的种子报告，结果反映的是选择过程而非典型性能。对资源有限的学习实验，可以至少固定公开的一组种子，报告所有结果和失败现象；不要把不利结果悄悄当作“运行故障”删除。

统计重复也不能弥补实验对象定义错误。十次重复错误标签映射仍是在稳定优化错误任务，置信区间很窄也不说明结论有用。先以手算、极端输入和函数恒等式验证语义，再使用重复训练评价性能。对于本章三段代码，断言验证的是有限测试点上的明确数学关系；它们不是对任意网络正确性的形式证明。

<a id="nnb-1-detail-34"></a>

## 11. 十六道进阶练习与完整解析

<a id="sec-7-1"></a>

<a id="nnb-1-detail-35"></a>

### 11.1 无激活增加层数是否一定增加容量

**题目。** 输入输出均为四维，比较单个任意仿射层与经过二维瓶颈的两个仿射层。若训练后者效果更好，能否证明其表达能力更强？

**解析。** 两层复合矩阵为 $`W_1W_2`$，秩至多为二，而任意四维仿射层允许秩达到四。因此前者函数族包含后者，后者并没有增加非线性能力。效果较好可以来自低秩约束减少噪声拟合，也可以来自不同参数化的优化行为；需通过控制正则和预算进一步区分。若中间加入非线性，低秩矩阵复合的结论不再直接描述整个函数，但每个固定激活区域的线性部分仍受结构影响。验收需要同时给出代数合并式和秩反例，不能只说层数更多。

<a id="nnb-1-detail-36"></a>

### 11.2 参数量与批大小

**题目。** 输入十维、隐藏十六维、输出三维的两层全连接网络含偏置。批大小从三十二改为六十四，参数量如何变化，哪些内存量会变化？

**解析。** 参数数为 $`10\times16+16+16\times3+3=227`$，批大小变化不增加权重或偏置。前向激活的第一维翻倍，保存反向所需中间量通常也会增长；优化器状态与参数数目有关，未必跟批大小翻倍。若使用梯度累积，可以通过多次小批前向实现更大有效批量，但随机层和批统计可能使其与一次大批不完全等价。答案应把模型参数、运行激活和优化器状态分别计数，而不能笼统地说内存不变或翻倍。

<a id="nnb-1-detail-37"></a>

### 11.3 识别合法但错误的广播

**题目。** 三条样本预测为列向量 $`(1,2,3)^T`$，标签为一维数组 $`(1,2,3)`$。直接相减再平方平均会得到零吗？

**解析。** 按常见广播规则，二者扩展为三乘三矩阵，比较了所有预测标签对。差值平方和为十二，除以九得到三分之四，而正确逐样本误差应为零。修复方式是让两者形状严格相同，再检查每个轴的含义。把标签任意 reshape 成某个能运行的形状之前，应确认样本次序没有改变。这个例子证明有限损失不等于正确目标，形状断言应先于长时间训练。

<a id="nnb-1-detail-38"></a>

### 11.4 一个 ReLU 构造的适用范围

**题目。** 网络 $`g(x_1,x_2)=\operatorname{ReLU}(x_1+x_2)-2\operatorname{ReLU}(x_1+x_2-1)`$ 能表达 XOR，是否因此学会了所有实数输入上的“不同即为真”？

**解析。** 在四个二进制顶点上，它确实输出零、一、一、零；这只是对有限离散域的精确表达。对于 $`(2,0)`$ 它输出零，而把“坐标不同”作为连续扩展的规则会要求为真。连续空间上标签如何定义必须另行说明。构造证明的是指定输入集合上存在参数解，并不说明训练一定找到该解，更不证明域外语义符合某个自然语言概念。回答需明确区分离散任务、连续插值和外推。

<a id="nnb-1-detail-39"></a>

### 11.5 重复 softmax 的损失下界

**题目。** 二类模型先 softmax 得到概率，再把该概率当成 logits 输入交叉熵。正确类别损失能趋近零吗？

**解析。** 第一次 softmax 的两个值都在零到一之间且和为一，两者差最多趋近一。第二次 softmax 的正确类概率因此最多趋近 $`\frac{e}{(e+1)}`$，其负对数下确界为 $`\log(1+e^{-1})`$，约零点三一三。单靠增大原分数无法打破这个限制。若观察到损失停留在附近，应该修正接口而非不断加大学习率。多类情况可类似讨论输入差值范围，但具体界依赖类别数；不要未经推导直接沿用二类数字。

<a id="nnb-1-detail-40"></a>

### 11.6 公共平移与梯度零和

**题目。** 为什么给一条样本的所有 logits 加一百不改变交叉熵？它对梯度和有什么限制？

**解析。** softmax 的分子分母同时乘 $`e^{100}`$，比例不变；稳定损失中的 LSE 增加一百，目标分数也增加一百，两项抵消。沿全一向量方向的方向导数为零，所以各类别 logit 梯度之和为零。该结论针对无额外 logit 惩罚的标准单样本交叉熵；若增加直接约束分数绝对值的项，公共平移不再是整个目标的无效方向。实际数值检验应允许浮点误差，而不是要求所有计算路径逐位一致。

<a id="nnb-1-detail-41"></a>

### 11.7 凸的 logit 损失为何仍难训练

**题目。** 已知交叉熵对 logits 的 Hessian 半正定，为什么不能断言两层网络有唯一全局最小值？

**解析。** 凸性针对自由变量 logits，而网络用共享非线性参数同时决定全部样本 logits。对参数求二阶导数时，除了 logit Hessian 经雅可比变换的部分，还包含损失一阶导数与网络二阶导数的组合。后者可以产生非凸曲率，参数对称性还会造成非唯一表示。即使单层线性分类具有凸目标，可分数据上无正则交叉熵也可能只有无穷大权重处的下确界而没有有限最优解。必须说明变量空间、正则和数据条件。

<a id="nnb-1-detail-42"></a>

### 11.8 BCE 为什么不总有饱和梯度消失

**题目。** 真标签为一，logit 为负一百，sigmoid 导数几乎为零。BCE 对 logit 的梯度是否也几乎为零？

**解析。** 稳定伯努利负对数似然的导数为 $`\sigma(a)-y`$，此处接近负一，仍提供较强修正信号。直接先计算极小概率再手工求导可能遭遇浮点问题，但数学上似然导数与 sigmoid 导数发生组合抵消。若改成概率平方损失，则额外的 sigmoid 导数仍在，梯度可能非常小。应区分激活自身导数、复合损失导数和错误数值实现，不能只看激活曲线就判断最终训练信号。

<a id="nnb-1-detail-43"></a>

### 11.9 一分数二分类与两分数二分类

**题目。** 两类 logits 为 $`(u,v)`$，找到等效伯努利 logit，并说明加权衰减为何使直接比较不公平。

**解析。** 第二类概率为 $`\sigma(v-u)`$，所以等效 logit 为差值 $`a=v-u`$。共同平移方向不影响概率。若分别惩罚 $`u^2+v^2`$，在固定差值下最小值由 $`u=-\frac{a}{2},v=\frac{a}{2}`$ 达到，其值为 $`\frac{a^2}{2}`$；单 logit 上直接使用相同系数惩罚 $`a^2`$，相对强度就不同。对一般输入相关权重也存在类似参数化问题。先对齐函数与惩罚，再讨论学习率和优化器，才能把观察归因于有意义的差别。

<a id="nnb-1-detail-44"></a>

### 11.10 软标签未归一化的后果

**题目。** 一条样本的软标签为 $`(0.8,0.8)`$，实现直接计算 $`-\sum_kq_k\log p_k`$。这是合法的二类分布交叉熵吗？

**解析。** 标签和为一点六，不是概率分布；但表达式仍可计算。其梯度为 $`1.6p-q`$，与把标签归一化为 $`(0.5,0.5)`$ 后的梯度相比整体放大一点六。若不同样本的和不同，就隐式形成不同样本权重。这个目标不一定无用，但必须说明权重来源；不能把它当作标准等权软标签拟合。若原意是两个事件各有零点八概率，应改用多标签伯努利目标而不是简单归一化，因为归一化会改变事件语义。

<a id="nnb-1-detail-45"></a>

### 11.11 对数回归到底预测什么

**题目。** 给定输入时，目标取一和九的概率各为一半。训练对数目标 MSE 后指数返回，结果与原尺度 MSE 的最优预测是否相同？

**解析。** 原尺度条件均值为五。对数目标均值为 $`\frac{(\log1+\log9)}{2}=\log3`$，指数返回三。二者不同是统计目标不同，不是优化器出了问题。若业务按相对误差评价，后者可能更合适；若要估计总成本的期望，则前者更直接。需要额外分布校正时，应在明确假设下推导，不能固定乘一个经验系数后仍声称普遍恢复条件均值。

<a id="nnb-1-detail-46"></a>

### 11.12 置信度与准确率的反向变化

**题目。** 两个模型在十条样本上都预测对九条，一个在错误样本上给真实类概率零点一，另一个给十万分之一。哪个交叉熵更大？能只凭准确率判断概率质量吗？

**解析。** 在其他九条样本概率相同的前提下，后者错误样本贡献为 $`-\log10^{-5}`$，远大于 $`-\log0.1`$，平均损失也更大。准确率只记录 argmax，无法看见这类置信差异。若其他样本概率同时改变，应计算全部损失才能比较，不能只看一个样本。概率质量还包括校准和分布偏移表现，一条极端错误虽有警示意义，却不等于对所有概率性质的完整评价。

<a id="nnb-1-detail-47"></a>

### 11.13 归一化是否改变表达能力

**题目。** 对输入做固定可逆仿射标准化，再接一个无约束线性层，是否扩大函数族？为何训练常会变化？

**解析。** 标准化可被吸收到第一层权重和偏置，因此在没有额外约束时，函数族仍是同一类仿射映射。参数坐标和梯度尺度发生变化，固定学习率、权重惩罚和优化器状态不会自动按等价规则转换，所以训练轨迹可能不同。若标准化丢弃维度、截断异常值或使用输入依赖统计，就不能沿用可逆仿射等价结论。答案应把函数存在性与实际算法分开讨论。

<a id="nnb-1-detail-48"></a>

### 11.14 隐藏单元重排能否改变语义

**题目。** 将隐藏层三个单元次序循环置换，并同步置换下一层输入权重，输出怎样变化？直接平均两个未对齐网络的参数有何风险？

**解析。** 同步逆变换抵消置换，整体输出不变，说明隐藏坐标编号没有固定语义。两个模型可能表示近似相同函数，但单元顺序不同，逐位置平均会把不对应的特征混在一起，得到与二者都不同的函数。模型参数平均在某些共同训练轨迹附近可以有效，但需要相应条件和验证，不能由输出相似自动推出。输出集成避免部分坐标匹配问题，却增加运行成本，也可能有共同偏差。

<a id="nnb-1-detail-49"></a>

### 11.15 温度是否能修正全部分类错误

**题目。** 模型把真实类排在第二，能否仅用正温度缩放使其排在第一？为什么校准集必须独立？

**解析。** 正温度缩放保持 logits 次序，所以不能改变 argmax，也无法修正这条样本的类别错误。它调整概率尖锐程度，可能改善概率损失，但能力受一个公共标量限制。选择温度使用了数据反馈，因此该资料承担校准或验证角色；再用同一资料声称独立测试效果会低估选择偏差。若需要改进类别排序，应研究表示、目标和数据，而不是把所有问题都归入校准。

<a id="nnb-1-detail-50"></a>

### 11.16 设计表达、优化与泛化的三阶段实验

**题目。** 想证明某激活“更适合”一个任务，应如何把三个层次拆开？

**解析。** 首先用构造或理论条件讨论两类网络能否表达目标，并注明宽度深度与输入域。其次在相同训练资料、预算和合理超参数协议下比较训练损失与梯度诊断，观察可达到解及收敛速度。最后在独立资料和明确偏移上比较预测指标，使用多种子报告波动。

不能把一次测试准确率优势直接当作表达定理，也不能把一次训练失败当作不可表达证明。一个可信结论应具体写成“在这些数据、预算和指标下观察到什么”，并清楚标出理论支持到哪里为止。

<a id="nnb-1-detail-51"></a>

## 12. 综合设计：从需求写出一份网络说明书

设任务是用过去七天的传感器摘要预测未来一天是否发生故障。先定义每条样本的预测时刻，只保留该时刻之前可获得的读数和维护记录。输入缺失指示、设备类别和连续量分别编码；均值方差仅在训练时间段拟合。按时间划分验证资料，若同一设备多次出现，还需考虑设备身份带来的相关性，避免随机行划分让相邻记录泄露未来。

网络可以先用两层全连接模型建立基线，写出输入特征数、隐藏宽度和一个输出 logit。标签为未来一天内是否故障，采用伯努利负对数似然。正类稀少不自动要求改用多标签损失；类别权重、采样和阈值需要依据目标代价逐项选择，相关目标变化留待第四章推导。首先在几条确定标签样本上核对输入与输出，再检查稳定损失和梯度，避免从一个复杂架构开始掩盖数据问题。

说明书应附一张形状账本：原始批量、编码后特征、各层预激活、隐藏表示、logit、未归约损失及最终标量。对每个变换写清是否含可学习参数、是否依赖批中其他样本、训练与推理是否相同。这样当单样本和批量预测不同，便能根据结构判断是预期统计耦合还是错误轴操作，而不是笼统地归因于浮点误差。

<a id="nnb-1-detail-52"></a>

### 12.1 从失败案例反推需要补的证据

若训练损失很低而未来月份效果差，优先对比特征分布、故障定义和采样机制，再讨论正则和容量。若模型给未知设备极高概率，应单独检验未知设备和缺失模式，不能让平均准确率掩盖。若改为更深网络后提升，需要控制参数量、优化预算和超参数搜索成本；如果这些条件变化，应把结论限定为整套方案比较，而不是单一深度因素的因果效果。

若线上只允许每小时检查固定数量设备，评价重点可能是前若干名召回与成本；若输出进入资源规划，概率校准和故障数量期望则更重要。训练损失提供可优化替代目标，最终指标要和使用方式连接。一个模型可以在交叉熵上较好却在特定阈值召回上较差，这不必然矛盾，可能是目标和决策约束不同，需要通过验证集选择适当规则。

<a id="nnb-1-detail-53"></a>

### 12.2 本章知识如何连接后续章节

前向传播确定了反向传播的对象。下一章将从相同的行向量约定推导参数梯度，解释共享分支、广播与归约如何生成梯度累加，并用独立数值核对验证。第三章进一步研究深度增加时信号的二阶矩和雅可比谱，说明初始化、归一化与残差为何改变优化条件。第四章则把本章的概率目标扩展到加权、掩码、多任务与正则，并建立从极小样本拟合到恢复训练的诊断闭环。

继续阅读时应保留两份笔记：一份写每个模型到底计算哪个函数，另一份写每次实验支持什么结论。前者防止接口与语义混淆，后者防止把局部证据扩大成普遍保证。能独立推导一个小网络、解释每个输出对应的随机变量，并指出近似理论的适用条件，才算完成本章；单纯记住激活名称和损失函数名称不足以支撑后续研究。
