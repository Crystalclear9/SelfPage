# 神经网络基础

理解网络如何组合函数、反向传播如何分配误差，以及训练时需要检查哪些环节。

**先修知识：** 矩阵乘法、偏导数、监督学习。

## 学习顺序与覆盖范围

先学本主题第 1 章的输入输出和损失，再配合[PyTorch 第 1—2 章](../../Programming/PyTorch/README.md)理解反向传播与训练循环；第 3—4 章在训练实验中继续补齐。理论前向先于工具训练，两个主题其余内容可以交替阅读。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：定位训练不能拟合小样本](04-损失设计正则化与训练排错.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
