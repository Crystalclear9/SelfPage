# 注意力机制

理解查询、键和值如何形成动态加权，以及掩码与多头机制的作用。

**先修知识：** 矩阵乘法、softmax、神经网络。

## 学习顺序与覆盖范围

第 1 章建立 Q、K、V 与加权读取，第 2 章规定自注意力、多头与合法掩码，第 3 章将这些约定落实为可对照的实现。完成前两章后，可与[Transformer 网络块](../Transformer/01-网络块位置与架构类型.md)交替阅读；第 3 章用于补齐前后向验收，第 4 章再研究效率、位置与解释边界。RNN 的编码解码器提供历史背景，但不是独立理解本主题公式的必修前置。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 效率问题的进阶入口

理解多头结构后，读[分组查询注意力的共享约束与梯度](04-注意力效率位置与解释实验.md#attention-4-gqa)，先手算缓存字节数，再检查共享是否改变原函数。分析低位缓存时，继续读[键值误差到聚合输出误差的界](../../AdvancedStudies/EfficientModelSystems/02-量化误差校准与推理瓶颈.md#quant-systems-67)，把缓存容量与输出质量连接起来。

## 如何完成本主题

完成各章后，先独立作答[进阶作业：注意力机制的分阶段验证](04-注意力效率位置与解释实验.md#sec-7-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
