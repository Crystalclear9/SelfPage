## 1. 先把算量、存储和信息范围分开

对查询数 $`n_q`$、键数 $`n_k`$、键维 $`d_k`$、值维 $`d_v`$，单头注意力是 $`O=\operatorname{softmax}(\frac{QK^\top}{\sqrt{d_k}}+M)V`$。两次主矩阵乘的乘加数量分别约为 $`n_qn_kd_k`$ 和 $`n_qn_kd_v`$。若显式保存全部分数和概率，两个中间量各有 $`n_qn_k`$ 个元素。头数和批量再乘上对应倍数。这里的算量与存储是两个不同指标，减少一个并不自动减少另一个。

自注意力中查询和键长度都为 $`n`$，关系数量随平方增长；交叉注意力是两种长度乘积；增量解码当前只有一个新查询，但历史键数继续增长。把所有阶段统一叫“注意力二次成本”会丢掉有用差异。预填充、训练和逐步解码要分别算账，再考虑投影、前馈、缓存和实际内核。关系矩阵只是完整网络的一部分，不能单凭它推断总体瓶颈。

<a id="sec-1-1"></a>
<a id="attention-4-detail-2"></a>
### 1.1 一个长度翻倍的具体账本

单头从一千位置变成两千位置，完整关系从一百万增加到四百万；若有八头与四条序列，关系元素还要乘三十二。按每元素两字节，一个矩阵从约六千四百万字节变成约两亿五千六百万字节，另一个同形中间量还需额外考虑。这个整数例子不包含梯度、工作区、对齐和分配器，也不能直接当运行峰值，但已说明为什么显式关系存储很快变得昂贵。

投影和逐位置前馈通常随长度线性变化，所以长度翻倍并不意味着整个模型恰好四倍计算。因果读取只允许三角区域，实际执行是否跳过另一半取决于内核；数学可见对数和执行操作数不可混为一谈。比较优化时列出形状、精度、模式和输出需求，比只写“复杂度降低”更具体。

<a id="deep-dive-1"></a>
<a id="attention-4-detail-3"></a>
### 1.2 三种优化承担不同证明义务

精确分块重排计算，目标仍是同一稠密注意力，主要验证前向与所需梯度的一致性及真实性能。稀疏或窗口方法改变可见集合，需要重新评价任务可用信息。核特征或低秩方法替换或近似算子，要报告近似条件、数值与质量。位置机制又改变得分中的几何，并不是存储优化。把它们分别定义后，才知道哪一种改动能声称保留原函数。

“精确”在此指实数数学目标相同，不意味着不同浮点顺序逐位一致；“线性内存”也不意味着算术量线性。若最后要求返回完整注意力图，输出本身就有平方大小，不能一边要求保存全图一边声称没有平方输出开销。接口功能是成本的一部分，比较不能悄悄删除用户所需结果。

## 2. 在线 softmax：一行如何逐块合并

先看一行分数 $`s_1,\ldots,s_n`$ 和对应值向量 $`v_j`$。目标为 $`o=\frac{\sum_je^{s_j}v_j}{\sum_je^{s_j}}`$。稳定计算减去整行最大值，但若键分块到达，暂时不知道最终最大值。我们为已处理集合保存三个统计量：最大值 $`m`$、稳定指数和 $`\ell`$、稳定加权和 $`u`$，满足 $`\ell=\sum e^{s_j-m}`$、$`u=\sum e^{s_j-m}v_j`$。输出最后才取 $`\frac{u}{\ell}`$，不能每块各自归一化再直接平均。

<a id="attention-4-detail-5"></a>
### 2.1 合并公式的完整推导

假设旧集合统计为 $`(m,\ell,u)`$，新块最大值为 $`b`$，令 $`m'=\max(m,b)`$。旧集合在新基准下每项由 $`e^{s-m}`$ 变成 $`e^{s-m'}=e^{m-m'}e^{s-m}`$，因此旧和都乘 $`a=e^{m-m'}`$。新块按同一基准累计，得到 $`\ell'=a\ell+\sum_{j\in块}e^{s_j-m'}`$、$`u'=au+\sum_{j\in块}e^{s_j-m'}v_j`$。这正好恢复并集的定义，所以按块归纳得到完整目标。

开始时空集合设 $`m=-\infty,\ell=0,u=0`$。有合法分数的第一个块将基准设为其最大值，旧权重为零。若某块对当前查询全被屏蔽，不应产生有效贡献；若整行永远没有合法键，softmax 本来没有定义，本章接口明确返回零，空行由原允许关系识别。这个零是扩展政策，不是概率分布。真实任务若不允许空行，应在进入计算前拒绝，而不能依赖偶然内核行为。

<a id="attention-4-detail-6"></a>
### 2.2 为什么合并顺序理论等价而数值仍会变

对任意分块和顺序，上述统计量描述同一集合，所以实数结果不变。浮点加法不满足结合律，不同顺序会有舍入差异，低精度与极端尺度时更明显。验收用高精度小例对照并设置合理误差，再测试目标精度范围。稳定减最大值避免指数溢出，却不会神奇消除所有求和误差或精度问题。

不要用每块的局部输出简单平均。若一块指数质量远大于另一块，它应拥有更大总体权重；只有按对应归一化质量合并才正确。一个最小反例是分数零与十，各自块输出分别取两个值，直接平均忽略了指数十的优势。流式实现保存分母不是可有可无的细节，而是整个归一化耦合的核心。

<a id="attention-4-detail-7"></a>
### 2.3 实验一：矩形、因果、填充和空行的分块前向

以下单头实现将查询和键都分块，使用双精度与多种块大小，对照安全处理空行的稠密参考。例子特意让查询七、键十一，避免仅在方阵巧合下通过；还包含尾部无效键和完全屏蔽行。为了审阅方便，示例显式提供完整可见矩阵，所以它本身没有宣称线性总体内存；生产实现可以根据索引逐块生成规则。循环只验证算法，不能当高效设备内核。

```python
import math
import torch

torch.manual_seed(301)
q = torch.randn(7, 4, dtype=torch.float64)*6
k = torch.randn(11, 4, dtype=torch.float64)*6
v = torch.randn(11, 3, dtype=torch.float64)
allowed = torch.arange(11)[None, :] <= (torch.arange(7)[:, None]+2)
allowed[:, 9:] = False
allowed[3] = False

def dense(q, k, v, allowed):
    score = q@k.T/math.sqrt(q.shape[-1])
    score = score.masked_fill(~allowed, -torch.inf)
    safe = torch.where(allowed.any(-1, keepdim=True), score, torch.zeros_like(score))
    a = safe.softmax(-1)*allowed
    return a@v

def online(q, k, v, allowed, query_block, key_block):
    outputs = []
    for start in range(0, len(q), query_block):
        qq = q[start:start+query_block]
        mask = allowed[start:start+query_block]
        m = torch.full((len(qq),), -torch.inf, dtype=q.dtype)
        l = torch.zeros(len(qq), dtype=q.dtype)
        u = torch.zeros(len(qq), v.shape[1], dtype=q.dtype)
        for j in range(0, len(k), key_block):
            s = qq@k[j:j+key_block].T/math.sqrt(q.shape[-1])
            s = s.masked_fill(~mask[:, j:j+key_block], -torch.inf)
            new_m = torch.maximum(m, s.max(-1).values)
            safe_m = torch.where(torch.isfinite(new_m), new_m, torch.zeros_like(new_m))
            factor = torch.exp(m-safe_m)
            e = torch.exp(s-safe_m[:, None])
            u = factor[:, None]*u + e@v[j:j+key_block]
            l = factor*l + e.sum(-1)
            m = new_m
        outputs.append(u/l.clamp_min(torch.finfo(q.dtype).tiny)[:, None])
    return torch.cat(outputs)

expected = dense(q, k, v, allowed)
for qb in (1, 3, 8):
    for kb in (1, 4, 12):
        actual = online(q, k, v, allowed, qb, kb)
        assert torch.allclose(actual, expected, atol=1e-11, rtol=1e-10)
assert torch.all(expected[3] == 0) and torch.isfinite(expected).all()
print('all nine block layouts match; empty row is zero')
```

### 2.4 空行、随机丢弃与实现边界

空行不能直接做负无穷减负无穷。代码用安全基准零让被屏蔽分数的指数保持零，分母为零时通过明确的零输出政策收尾。合法非空行仍使用真实最大值和分母。不要把分母简单加一个较大的常数作为通用修复，那会改变所有正常行的权重总和。边界政策应只作用于边界，并有独立断言。

注意力 Dropout 通常在归一化权重后执行，随机掩码需要与参考目标一致。若为了分块改为对每块单独重新归一化，或改变随机变量的含义，已不再是原函数。训练反向还需要重现相同随机选择。本文先关闭 Dropout，专门验证确定性算子，再说明生产实现必须处理的状态；没有把确定性通过扩张为所有训练配置已验证。

## 3. 分块反向：用输出恢复关键行统计

给定输出梯度 $`G`$，令 $`A=\operatorname{softmax}(S)`$、$`O=AV`$。权重梯度 $`D=GV^\top`$，第 $`i`$ 行分数梯度为 $`\frac{\partial L}{\partial S_{ij}}=A_{ij}(D_{ij}-\delta_i)`$，其中 $`\delta_i=\sum_jA_{ij}D_{ij}`$。交换求和可得 $`\delta_i=G_i^\top O_i`$。因此只要保存输出和行归一化信息，就能在反向按块重建概率，无需永久保存完整权重矩阵。

<a id="attention-4-detail-10"></a>
### 3.1 三组输入梯度怎样累积

若分数为 $`\frac{QK^\top}{\sqrt{d_k}}`$，则查询梯度为 $`\frac{dS K}{\sqrt{d_k}}`$，键梯度为 $`\frac{dS^\top Q}{\sqrt{d_k}}`$，值梯度为 $`A^\top G`$。查询块对应自己的输出行，键和值的梯度需累积来自所有查询块的贡献。忘记累加而用赋值覆盖，是一种前向完全正确、反向却错误的典型实现问题。实验应比较全部输入梯度，不能只看损失值。

可以保存行对数归一化量 $`z_i=m_i+\log\ell_i`$，反向以 $`A_{ij}=e^{S_{ij}-z_i}`$ 恢复块内概率，再按上式累积。被屏蔽位置概率为零；在空行返回常量零的政策下，该行对查询、键和值的梯度贡献均为零，但损失从后续计算传回的输出梯度本身不必为零。实际实现还要考虑并行归约、低精度和重算成本，这些属于执行细节，但不应改变梯度对象。前向少存中间量，常以反向多算一部分换取内存。

<a id="attention-4-detail-11"></a>
### 3.2 实验二：分块解析反向对照自动求导

本实验不复用上一段函数，而直接在小矩形注意力上计算参考前向和自动导数，再按键块重建分数梯度。这样能独立核对数学伴随及“多个块累加”行为。例子有两个屏蔽键，但没有空行，以免将零行接口扩展政策混入普通 softmax 推导。块宽改变不应改变最终三组梯度。

```python
import math
import torch

torch.manual_seed(79)
q = torch.randn(5, 4, dtype=torch.float64, requires_grad=True)
k = torch.randn(8, 4, dtype=torch.float64, requires_grad=True)
v = torch.randn(8, 3, dtype=torch.float64, requires_grad=True)
allowed = torch.ones(5, 8, dtype=torch.bool); allowed[:, 6:] = False
score = (q@k.T/math.sqrt(4)).masked_fill(~allowed, -torch.inf)
a = score.softmax(-1); out = a@v
g = torch.randn_like(out)
reference = torch.autograd.grad((out*g).sum(), (q, k, v))
with torch.no_grad():
    logz = score.logsumexp(-1)
    delta = (g*out).sum(-1)
    for width in (1, 3, 9):
        dq = torch.zeros_like(q); dk = torch.zeros_like(k); dv = torch.zeros_like(v)
        for start in range(0, len(k), width):
            block = slice(start, min(start+width, len(k)))
            s = (q@k[block].T/2).masked_fill(~allowed[:, block], -torch.inf)
            prob = (s-logz[:, None]).exp()
            dp = g@v[block].T
            ds = prob*(dp-delta[:, None])
            dq += ds@k[block]/2
            dk[block] += ds.T@q/2
            dv[block] += prob.T@g
        for got, expected in zip((dq, dk, dv), reference):
            assert torch.allclose(got, expected, atol=1e-11, rtol=1e-10)
        assert torch.all(dk[6:] == 0) and torch.all(dv[6:] == 0)
print('three block schedules reproduce all Q/K/V gradients')
```

<a id="attention-4-detail-12"></a>
### 3.3 自动求导保存图不等于手写内核的内存策略

如果把第一段 Python 循环直接放入自动求导，框架可能保存每块运算所需中间量，训练峰值不一定具有理想手工反向的存储界。要声称训练内存改善，需要实现或使用具有对应重算策略的反向，再真实测量。算法可以流式前向、教学代码使用自动求导、生产内核按块重算，是三个相关但不相同的层次。

理论上可以只保存输入、输出和行统计，反向重算局部得分与概率；实际设备上的块大小还受片上存储、并行度和访存调度约束。块过小会增加循环与启动开销，过大又失去存储优势。CPU 教学循环通常比大矩阵参考慢，所以这里只以一致性为验收，不从算法可行性推断具体设备速度。真实优化必须在相同功能和形状下核对延迟与峰值。

<a id="attention-4-detail-13"></a>
## 4. 稀疏、局部与核特征：改变了什么

把稠密可见集合替换为局部窗口，未保留的位置概率从可学习值变成永久零。它可能降低成本并施加合理局部归纳偏置，但一般不等于原模型。若每层只能读取自己和此前 $`w-1`$ 个位置，没有其他混合路径，堆叠 $`L`$ 层最远可传播 $`L(w-1)`$ 个位置；这可按层归纳证明。残差保留同位置，不会凭空建立更远边；全局 token、跨层跳跃和其他卷积路径则会改变边界。

<a id="attention-4-detail-14"></a>
### 4.1 多层可达不等于同样容易读取

远处信息经过多层中转才能到达，与一层直接读取不是相同计算条件。中间表示宽度、非线性和学习难度都会影响信息保真。因此“堆足够多层最终连通”不能证明局部模型与全局注意力具有相同实际能力。若关键证据超出理论可达范围，相关任务在当前结构中甚至无法依赖该证据，除非存在额外路径。结构图可以排除不可能性，却不能保证可达路径已被训练有效使用。

比较局部和全局模型应给相同数据角色、明确的训练和搜索预算，并同时报告算量、存储与质量。把已训练全局模型的窗口突然缩小，测到的下降是固定模型对删边的敏感性，不等于重新训练局部结构的最佳表现。两种实验都能做，但它们回答的问题不同，不能把一个结论冒充另一个。

<a id="attention-4-detail-15"></a>
### 4.2 核特征关联律为什么能改变计算顺序

设非负特征映射为 $`\phi`$，将相似性定义为 $`\phi(q)^\top\phi(k)`$，则输出为 $`\frac{\phi(q_i)^\top\sum_j\phi(k_j)v_j^\top}{\phi(q_i)^\top\sum_j\phi(k_j)}`$。可以先累计特征与值的外积矩阵，再读取查询，避免显式构造所有查询键对。如果特征维度固定且远小于序列长，存储和算量可能更有利，但算子已经由所选核决定。

普通指数点积核可以研究特定特征近似，但随便选择一个非负映射并不会精确等于 softmax。有限特征的误差、随机性、分母大小和掩码结构都需分析。任意二维可见矩阵也未必允许一个全局累计统计表达；因果结构可以使用前缀累计，局部窗口则可能需要滑动删除。关联律有效的条件来自求和集合与核的可分解性，不是一切注意力都能直接改成线性乘法。

<a id="attention-4-detail-16"></a>
### 4.3 实验三：同一核的稠密与前缀实现一致

实验选取始终正的 ELU 加一映射，构造因果核注意力。显式核矩阵和前缀累计统计应该一致，但与指数点积 softmax 一般不同。后一个差异不是实现失败，而是算子定义改变的预期。这里没有声称该映射是某论文算法的完整实现，更没有给出真实任务质量结论；它是隔离关联律与函数差异的最小例子。

```python
import torch
import torch.nn.functional as F

torch.manual_seed(64)
q = torch.randn(6, 4, dtype=torch.float64)
k = torch.randn(6, 4, dtype=torch.float64)
v = torch.randn(6, 3, dtype=torch.float64)
pq, pk = F.elu(q)+1, F.elu(k)+1
allowed = torch.ones(6, 6, dtype=torch.bool).tril()
weights = (pq@pk.T)*allowed
reference = weights@v/weights.sum(-1, keepdim=True)
state = torch.zeros(4, 3, dtype=torch.float64)
z = torch.zeros(4, dtype=torch.float64)
outputs = []
for i in range(6):
    state += pk[i, :, None]*v[i, None, :]
    z += pk[i]
    outputs.append((pq[i]@state)/(pq[i]@z))
actual = torch.stack(outputs)
assert torch.allclose(actual, reference, atol=1e-12, rtol=1e-10)
soft = (q@k.T/2).masked_fill(~allowed, -torch.inf).softmax(-1)@v
assert not torch.allclose(soft, actual)
print('kernel prefix equality passed; max difference from softmax:',
      (soft-actual).abs().max().item())
```

<a id="attention-4-gqa"></a>
### 4.4 GQA：共享键值如何约束表达并改变缓存

分组查询注意力保留 $`H`$ 个查询头，却只设置 $`G`$ 个键值头。设 $`H`$ 能被 $`G`$ 整除，并令 $`g(h)=\lfloor\frac{h}{(\frac{H}{G})}\rfloor`$，头编号从零开始。对同一输入 $`X`$，分别计算 $`Q_h=XW_h^Q`$、$`K_g=XW_g^K`$、$`V_g=XW_g^V`$，于是

$$
\begin{aligned}
P_h &=\operatorname{softmax}(\frac{Q_hK_{g(h)}^\top}{\sqrt{d_k}}+M),\\[6pt]
O_h &=P_hV_{g(h)}.
\end{aligned}
$$

同组查询读取同一个键值表示，但 $`Q_h`$ 不同，所以注意力权重仍可不同。$`G=H`$ 恢复普通多头结构，$`G=1`$ 是多查询结构；两端之间的共享构成 GQA。[原始研究](https://aclanthology.org/2023.emnlp-main.298/)讨论其结构与已有检查点的继续训练，下面用独立小例分析它的约束。

共享也影响反向。设损失对 $`O_h`$ 的梯度为 $`D_h`$，而 $`E_h`$ 是经 softmax 求导后对缩放分数的梯度，则链式法则给出

$$
\begin{aligned}
\frac{\partial L}{\partial V_g} &=\sum_{h:g(h)=g}P_h^\top D_h,\\[6pt]
\frac{\partial L}{\partial K_g} &=\sum_{h:g(h)=g}\frac{E_h^\top Q_h}{\sqrt{d_k}}.
\end{aligned}
$$

原因是同一变量进入了组内所有读取分支，各分支贡献必须相加。不同头的梯度可能相互促进或抵消；把键值广播到查询头后，仅取一个副本的梯度会遗漏其余分支。这里求和并不意味着必须物理复制缓存，实际内核可以根据组索引读取共享存储。

一个反例能说明“把已有多头参数平均”为什么不保留原函数。只取一个查询和一个可见键，两个头的 softmax 权重都必为一；令输入和每头值维都为一，原值投影分别为 $`W_0^V=0`$、$`W_1^V=2`$，输入 $`X=1`$，输出投影固定为恒等映射。原拼接输出是 $`(0,2)`$。平均值投影得到 $`W^V=1`$，共享后拼接变为 $`(1,1)`$。此时查询、键和得分完全不能弥补差异，因为每头只有一个可见位置。它证明这种参数替换不精确，并未证明重新训练后不可能用其他参数补偿。

缓存的收益可以直接数维度。批量 $`B`$、层数 $`L`$、缓存长度 $`T`$，且键值每头维均为 $`d`$、每元素 $`b`$ 字节时，理想有效载荷为 $`2BLTGdb`$。取 $`B=2,L=24,T=4096,d=64,b=2,H=16,G=4`$，普通多头为 $`768`$ MiB，分组后为 $`192`$ MiB，恰为四分之一。但查询头仍有十六个，读取得分和加权和的主要乘法数量不会仅因 $`G`$ 减四倍就同步减四倍；页面空隙、临时张量和参数也未计入。真正的速度需要按设备和批量测量，质量需要在训练或转换之后重新验收。若键维与值维不同，应把载荷公式中的 $`2d`$ 换成 $`d_k+d_v`$；共享比例不变，绝对字节数则必须重新计算。

## 5. 位置并非附加标签，而是计算几何的一部分

没有位置、边界或其他顺序信号时，共享参数的自注意力对相应输入置换具有等变性。任务若依赖次序，需要某种打破完全置换对称的机制。绝对位置嵌入、相对偏置、旋转查询键、因果读取和局部结构都提供不同顺序条件，不能简单归为“一种位置编码”。理解它们要写出位置信息在哪个乘法或加法进入，而不只列名字。

<a id="attention-4-detail-18"></a>
### 5.1 绝对正弦向量的相对内积

对某频率 $`\omega`$，令位置向量为 $`(\cos\omega t,\sin\omega t)`$，两个位置内积等于 $`\cos\omega(t-u)`$，来自和差角恒等式。多个频率拼接后，内积为各频率相对余弦之和。这个性质解释了固定正弦向量包含相对关系，但将它直接加到内容嵌入后再投影，会产生内容—位置交叉项，整个网络并不因此自动只依赖相对距离。

固定公式可以计算训练外索引，这仅表示表示函数有定义。训练只覆盖某些长度时，参数未必学会在新相位和距离组合下完成任务；低精度大角度计算也可能产生额外数值问题。位置可生成、程序可运行和任务外推可靠应分别验收。位置机制的代数性质有价值，但它不能替代独立长距离任务证据。

<a id="sec-2-1"></a>
<a id="attention-4-detail-19"></a>
### 5.2 RoPE 的二维旋转推导

设 $`R_t`$ 是角度 $`t\omega`$ 的二维正交旋转，旋转后的查询键点积为 $`(R_tq)^\top(R_uk)=q^\top R_t^\top R_uk=q^\top R_{u-t}k`$。多个坐标对各用不同频率，组成块对角旋转。每对向量范数保持，相似性显式包含相对位置。这里的符号方向由旋转矩阵和点积约定决定，代码若交换正负号或坐标配对，也会改变含义，应手算核对。

对于固定未旋转的内容查询键，同时给两个位置加相同偏移，点积保持。这不直接证明完整多层网络对任意文本平移都不变，因为内容表示可能已经受边界、绝对组件、掩码和更早计算影响。证明必须说明哪些变量固定、哪些路径一起变换。局部几何性质不能不加条件扩张成整个模型的语义定理。

<a id="attention-4-detail-20"></a>
### 5.3 缓存位置与逻辑位置的区别

缓存槽位是存储地址，逻辑位置决定旋转或偏置。分页、左填充、请求合并和窗口裁剪后，两者未必相同。若历史键已经按真实位置旋转，新查询却每步按零位置旋转，其相对角度就错了；结果可能形状正确、数值有限，仍不是原函数。增量对照应固定同一逻辑位置并逐步比较，不能仅检查缓存长度增长。

已经旋转的键通常不应在每次读取时再按当前查询位置旋转一次，否则相位被重复叠加。若更改位置缩放或频率参数，旧键与新查询的几何不再相容，需要明确失效与重算政策。共享前缀缓存还要把位置机制配置纳入身份。仅保存键值张量而不保存其约定，很难安全恢复对应计算。

<a id="attention-4-detail-21"></a>
### 5.4 实验四：范数、相对点积与错误位置反例

实验使用两对坐标与两个频率，不依赖第三方旋转库。先验证范数与共同平移不变，再将新查询位置错误重置为零，展示与同一历史键的得分不一致。当前内容固定，验证的是单个查询键对的代数性质；它没有测试语言理解或训练外长度泛化，也没有把相同偏移性质扩张到其他网络路径。

```python
import torch

dtype = torch.float64
q = torch.tensor([.3, -.7, 1.2, .4], dtype=dtype)
k = torch.tensor([1., .2, -.6, .9], dtype=dtype)
freq = torch.tensor([1., .01], dtype=dtype)
def rotate(x, position):
    pair = x.reshape(-1, 2)
    angle = position*freq
    c, s = angle.cos(), angle.sin()
    a, b = pair[:, 0], pair[:, 1]
    return torch.stack((a*c-b*s, a*s+b*c), dim=-1).flatten()
for p in (0, 3, 1000):
    assert torch.allclose(rotate(q, p).norm(), q.norm(), atol=1e-12)
score = rotate(q, 7)@rotate(k, 2)
shifted = rotate(q, 1007)@rotate(k, 1002)
relative = q@rotate(k, -5)
assert torch.allclose(score, shifted, atol=1e-11, rtol=1e-10)
assert torch.allclose(score, relative, atol=1e-12, rtol=1e-10)
wrong = rotate(q, 0)@rotate(k, 2)
assert not torch.allclose(score, wrong)
print('correct / wrong reset score:', score.item(), wrong.item())
```

<a id="attention-4-detail-22"></a>
### 5.5 相对偏置与距离先验

另一种方式在得分中加 $`b(t,u)`$。例如因果条件下按距离加线性惩罚，距离越远先验得分越低；这改变注意力偏好，不是免费保留所有距离同等机会。不同头可以具有不同斜率，具体选择与训练应按实际模型定义。若偏置只依赖位置差，共同平移查询键位置不改变该项，但边界与内容仍可能变化。

偏置会与内容得分的尺度相互作用。查询键范数变化可能压过或弱化固定距离惩罚，因此不能仅看偏置公式判断真实头主要看多远。可以在固定模型上统计内容与偏置项分布，并做预先定义的距离干预；仍需避免把训练外删除位置造成的异常当作一般距离因果。位置机制提供可分析结构，真实使用情况依赖学习与数据。

## 6. 注意力权重究竟解释了哪个中间量

权重是给定查询键和可见集合后的归一化系数。它说明本次值读取如何混合，却不包含值向量大小、输出投影方向、残差、其他头和后续层的全部作用。若要解释某个最终类别 logit，需要先明确目标标量及经过的路径。高权重位置可以在关心的输出方向上值为零，低权重位置也可能承载很大的相关分量，因此颜色强烈不等于最终贡献必然大。

<a id="attention-4-detail-24"></a>
### 6.1 相同输出可以对应不同权重

对固定值矩阵 $`V`$，若某非零行向量 $`d`$ 满足 $`dV=0`$ 且 $`d\mathbf 1=0`$，那么在保持非负的范围内，$`a`$ 与 $`a+d`$ 都是概率行且输出相同。源位置多于有效值空间维度时，可能存在这样的不可辨识方向。即使权重不同但输出相同，后续网络也无法仅从这个读取输出恢复唯一权重解释。需要额外约束或其他观测，不能把一种权重图当成唯一决策理由。

这个反例不声称权重永远没有研究价值。它们可以帮助发现对齐、读取范围和实现故障，但证据范围要适当。对某些任务与结构，权重可能与人工对齐或依赖强相关，仍应通过对照验证；代数上存在不可辨识性提醒我们不要把相关性直接升格为普遍解释保证。研究可以问何时可辨识、哪些条件下有预测价值，而不是二选一地赞成或否定一切可视化。

**图解：注意力权重不可辨识的非退化算例**

![注意力权重不可辨识的非退化算例](images/04-weight-nonidentifiability.svg)

图中固定三个互不相同的标量值，分别使用两组严格为正的权重。把每根柱子的高度乘以横轴对应的值，两组加权和都为零；因此即使没有重复值向量，也可能无法仅由输出恢复权重。这是固定值矩阵存在非平凡仿射依赖的具体例子。两组权重都能通过有限 logits 的 softmax 实现，不能将这种现象解释成零权重或数值下溢。

这个算例只比较一次读取的输出，不能推出所有干预都无效。删除一个位置会改变归一化，替换值向量会改变被读取对象，修改权重还可能影响后续层；开展解释实验前应分别说明干预对象。

<a id="attention-4-detail-25"></a>
### 6.2 实验五：不可辨识权重与干预对象差异

第一部分用两个完全相同的值向量，使大幅改变前两个位置权重后输出仍一致。第二部分让最高权重位置的值为零，低权重位置值很大，比较固定权重下的值替换与删除键后重新归一化。它展示两种干预回答不同问题，不能从“遮挡后变了”直接断言原来的热图含义。示例是手工构造的机制反例，不代替真实输入干预研究。

```python
import torch

dtype = torch.float64
v = torch.tensor([[2.], [2.], [8.]], dtype=dtype)
a = torch.tensor([.7, .2, .1], dtype=dtype)
b = torch.tensor([.1, .8, .1], dtype=dtype)
assert torch.allclose(a.sum(), b.sum())
assert torch.allclose(a@v, b@v)
assert (a-b).abs().max() > .5

weights = torch.tensor([.98, .01, .01], dtype=dtype)
values = torch.tensor([0., 0., 100.], dtype=dtype)
original = weights@values
replace_high = values.clone(); replace_high[0] = 0
replace_low = values.clone(); replace_low[2] = 0
assert torch.allclose(weights@replace_high, original)
assert (weights@replace_low).item() == 0
keep = torch.tensor([False, True, True])
after_deletion = (weights[keep]/weights[keep].sum())@values[keep]
assert original.item() == 1 and after_deletion.item() == 50
print('different weights, same readout:', (a@v).item(), (b@v).item())
print('original / delete high and renormalize:', original.item(), after_deletion.item())
```

<a id="attention-4-detail-26"></a>
### 6.3 梯度、删除、替换和重训分别回答什么

局部梯度描述当前点的微小变化，删除键改变归一化集合，替换输入会经过编码与所有后续路径，删除某头再重训则评价替代学习流程。它们的对象不同，结果不一致并不自动表示某个方法坏了。应在题目中明确想研究当前计算依赖、有限干预敏感性、结构必要性还是重新学习后的可替代性，再选相应方法。

输入遮挡可能生成训练外文本，多个冗余证据又能相互替代；因此应比较高权重、低权重但内容相似和随机匹配位置，并控制替换方式及长度。只删除最显眼的词再发现输出变化，无法排除语法破坏、位置变化或其他路径的影响。可视化应作为生成可检验假设的工具，随后给出有约束的干预与任务证据，而不是展示一张符合预期的图就结束。

<a id="attention-4-detail-27"></a>
## 7. 从分数误差到读取误差的进阶分析

分块保持同一数学算子，但浮点、低位表示与近似得分仍会带来误差。讨论误差前先固定同一合法键集合，排除把删除边也当成小数值扰动。设某行原分数为 $`s`$，扰动为 $`e`$，概率为 $`p`$；沿路径 $`s+te`$ 求导，有 $`\dot p_j=p_j(e_j-\sum_kp_ke_k)`$。这个式子把误差方向、概率与归一化耦合联系起来，比只看每项指数误差更接近最终输出。

<a id="attention-4-detail-28"></a>
### 7.1 一个保守但容易核对的扰动界

若每个合法分数误差绝对值不超过 $`\varepsilon`$，则加权平均误差也不超过该值，从而各项导数绝对和不超过 $`2\varepsilon`$。沿零到一积分，得到概率行的一范数变化不超过 $`2\varepsilon`$；同时它永远不超过二，可取两界较小值。若值向量范数均不超过 $`V_{max}`$，固定值时输出变化不超过 $`V_{max}`$ 乘概率一范数变化。这个界较粗，却明确揭示值尺度和分数误差必须一起考虑。

若值也发生误差，先加减一个相同中间输出，用三角不等式再加上最大值误差范数即可。该界只用于固定支撑的单次读取，后续投影、残差和多层变换还可能放大或压缩误差。离散 argmax 又涉及分类裕量，不能仅由读取向量范数变化小就保证最终 token 一致。数值近似的验收应从局部误差继续走到任务行为。

分数加同一常数不改变 softmax，因此可以先从误差里减任意公共常数，再应用相同推导。实际有意义的是各键之间的相对误差，而不是所有得分整体上移多少。稳定减最大值正利用了这个自由度。比较两个实现时，如果只看原始分数最大差，可能把无关整体平移误判成严重函数差异；应继续比较归一化权重和读取结果。

<a id="attention-4-detail-29"></a>
### 7.2 极端值、抵消和归一化条件

减最大值防止正指数爆炸，但值向量的加权和仍可能发生抵消。若两个大值方向相反，结果很小，舍入造成的相对误差可能很大，即便绝对误差不大。此时用单一相对容差容易误报或漏报，应联合绝对尺度、输入范围和任务输出要求。稳定 softmax 不是整个网络数值可靠性的充分条件，它只解决指数归一化中的一部分问题。

核特征注意力还要检查分母。非负特征不代表分母一定远离零；映射可接近零时，除法可能放大舍入与近似误差。往分母加稳定常数会改变算子，应说明数值政策及受影响范围。若算法本来保证某些下界，可以将条件写入输入和映射契约，再测试边界；没有条件时，不应因一次随机实验分母正常就宣称所有输入安全。

<a id="attention-4-detail-30"></a>
### 7.3 近似分数与改变可见集合不是同一扰动

删除某键相当于把其分数送向负无穷，并重新分配其概率质量，不属于固定有限误差假设。即使被删键当前权重小，多次删除也可能累计显著质量；值的相关方向还影响输出。稀疏化研究可以报告被删概率质量与值范数，作为固定模型局部诊断，但若结构重新训练，概率分布本身会变，又要回到完整学习流程评价。

一个局部窗口还可能删去当前权重不高但在其他输入上关键的远距路径。只在少数示例热图上观察远处颜色淡，不能证明全局删边无损。更稳妥的做法是定义目标任务与长度分布，比较结构可达范围、固定参数敏感性、重训结果和资源，分别说明每项证据。如此才能把数学误差、实现差异与能力代价连接起来，而不让某一个指标替代全部。

<a id="attention-4-detail-31"></a>
## 8. 结构图、位置与可解释性的联合研究

注意力关系不是孤立图。残差、前馈、归一化、嵌入共享和其他模态路径共同构成完整依赖图。要判断过去输出是否隔离未来，或某证据是否可能影响当前任务，应把所有跨位置操作画出来。一个头的可见矩阵满足因果，不代表外部的跨时间统计、全序列池化或未受限支路也满足。性质证明必须覆盖组合，而不能停在最熟悉的注意力公式。

<a id="attention-4-detail-32"></a>
### 8.1 用逐层可达集合建立结构证明

为位置 $`i`$ 定义第零层依赖集合为输入位置自身，下一层把其可读取键对应的前层依赖集合取并集，再加残差同位置路径。逐层归纳得到理论可达范围。局部因果窗口给出有限传播速度，带全局节点的结构会出现快速跨距离路径，多模态交叉读取则连接另一组索引。这个方法可以在不训练模型时排除某些信息依赖，但不能断言所有可达信息都被有效编码。

例如两层窗口三的单向结构，当前位置最多依赖此前四个位置；若任务要求读取距离十的独特符号，且无其他共享汇总路径，结构本身就无法利用它。增加层数会扩大可达集合，却同时改变计算、参数和优化。研究若比较深局部与浅全局，应明确哪种预算匹配，不把路径长度差异隐藏起来。结构图帮助提出公平问题，而不是自动给出哪种结构最好。

<a id="attention-4-detail-33"></a>
### 8.2 内容复制、位置重命名与同一任务

复制一个合法键值会改变归一化质量，即使内容相同，输出也不必保持，因为该内容获得了更多计数。删除重复证据、合并文档和切分文本因此可能改变注意力分布，不能先验视作无害文本格式变换。若任务希望对重复不敏感，需要数据、结构或明确的去重策略支持，并独立测试。重复内容的因果作用与某个位置本身重要也要分开。

位置重命名只有在全部有关量一致变换时才可能保持结构。例如同时置换查询、键、值和可见矩阵，读取可按对应规则等变；固定三角矩阵而随意重排内容，会改变时序关系。RoPE 的共同平移性质又只针对相同内容向量的成对旋转，不能拿来证明任意重排。每个不变性主张都应写清变换对象与任务标签，而不只是给输入做一个看起来对称的操作。

<a id="attention-4-detail-34"></a>
### 8.3 为解释实验设立可以失败的预测

在分析真实模型前，先选定输出标量和研究假设。例如假设某类远处证据通过某头影响当前决策，就应预期：在合法条件下替换该证据会改变目标，隔离相应路径会减弱变化，而匹配的无关位置对照不应产生同样效应。任何一项失败都应促使修订解释，而不是只保留最符合故事的图。通过多条预测约束解释，才能让可视化进入可证伪研究。

还应事先规定干预强度、替换分布和是否允许重训。若删除内容同时改变句法、长度和答案可判定性，就无法将差异单独归于某个注意力系数。可在人工任务中先使用完全合法的替换，再逐步走向真实文本；人工机制清楚但外部效度有限，真实任务复杂但更贴近使用。两者互补，不应互相冒充。

<a id="attention-4-detail-35"></a>
## 9. 一个完整的效率与机制验证流程

第一步建立小型高精度参考，覆盖矩形、因果、填充、空行、极端分数和多种块边界。第二步比较所有需要的输入及参数梯度，并注入漏累加、错位置、错掩码等故障，检查测试能否真正发现。第三步在目标精度和设备测内存、读写与时间，说明前向、训练或解码阶段。第四步在共同数据与合法选择边界内评价任务质量。四步对应不同证据，不能用最后分数很好来掩盖前面实现未核实。

<a id="attention-4-detail-36"></a>
### 9.1 成本测量的输出与模式约定

是否返回全权重、是否保留梯度、是否训练 Dropout、查询键长度、头数、精度和批量都要固定。一个实现只返回最终读取，另一个返回逐层逐头完整权重，内存与速度比较混入了功能差异。若研究本来要分析热图，可以承认多保存信息的成本；若生产不需要热图，就把不返回图作为接口条件。清楚记录功能，比把差异称作某种算法天然更快更诚实。

短序列可能由启动和调度主导，长序列可能受内存容量或带宽限制。至少在相关长度范围检查趋势，避免从一个形状外推整个系统。CPU 教学代码用 Python 循环体现公式，真实设备优化往往依赖融合、片上存储和并行划分；本章只为前者提供已运行证据。没有目标硬件测量时，可以给理论复杂度与待验证预测，但不能填入猜测的加速数字。

<a id="attention-4-detail-37"></a>
### 9.2 报告中保留失败与误差范围

不应只展示最大块或某个种子通过的样例。保留最坏误差、出现条件、失败数和容差定义，尤其关注很小输出、接近并列决策和空行。若某精度不能满足所需行为，应说明限制或选择其他策略；单纯放宽容差直到全部通过，并没有解决任务一致性。容差来自应用和数值分析，不能只是验收后为了得到绿色结果临时调整。

最终交付包含公式、参考代码、实际环境、验证范围、资源测量定义和仍未确认的条件。参考代码可独立复制运行，临时输出由实验自动清理。后续实现者应能据此判断哪些性质已经有证据，哪些仍需在新设备、随机配置或真实任务下复验。复验时先固定输入和误差容差，再分别测量数学等价性、显存与运行时间，避免把不同性质压成一个“更高效”的结论。

## 10. 二十四道练习与逐题详解

<a id="attention-4-detail-39"></a>
### 10.1 分数矩阵变大四倍，整体网络也四倍吗

**问题：** 长度一千增至两千，模型宽、批量和头数固定，应该怎样描述成本？

**解析：** 查询键对数从一百万增至四百万，所以相关矩阵元素和稠密主乘积的长度项四倍。投影与逐位置前馈通常只随长度翻倍，其他开销又可能固定或受执行方式影响。因此整体比例取决于各项占比，不能仅凭注意力关系推断恰好四倍。应把投影、关系计算、前馈、输出和工作区分项，再测目标模式。如果某实现跳过因果上三角，还要说明实际内核处理方式，而不只数理论可见边。

<a id="attention-4-detail-40"></a>
### 10.2 两个单元素块为什么不能直接平均

**问题：** 分数为零和十，值为零和一，各块独立 softmax 后输出是什么？正确全局输出是什么？

**解析：** 单元素块都只有一个合法键，所以局部输出分别零和一，直接平均为二分之一。全局输出却为指数十除以一加指数十，约零点九九九九五。区别来自两个块的归一化质量极不相同。在线统计必须保存指数分母并在共同最大值下重标定；只保存局部平均会丢失合并所需信息。这个反例可以放进实现验收，专门发现“每块结果平均”的错误，而不是仅用随机小分数测试。

<a id="attention-4-detail-41"></a>
### 10.3 手算最大值更新后的旧权重

**问题：** 已处理集合最大值二、稳定和三，新块最大值五，旧集合在新基准下贡献多少？

**解析：** 新基准五比旧基准二大三，所以旧指数质量乘以指数负三，贡献为三乘指数负三；旧加权值和也必须乘同一因子。新块各分数减五再求指数，两部分相加后才取输出比值。如果只缩放分母不缩放值和，读取结果会改变；如果只更新最大值而不重标定，旧项会被错误高估。最大值不是仅为防溢出保存的日志，它决定所有累计量共同的数值基准。

<a id="attention-4-detail-42"></a>
### 10.4 空块与空行有什么区别

**问题：** 当前键块全被屏蔽，但后续块可能合法，是否应立即将整行输出置零并结束？

**解析：** 不应该。空块对已有统计贡献零，可以继续处理；只有全部键处理后分母仍为零，才触发空行政策。若已有合法块，随后空块也不应抹掉其累计值。实现要避免负无穷减负无穷，并分别覆盖首块空、中间空、末块空和整行空四种情况。返回零只是本章对空行的接口扩展，不能把它解释成在空集合上存在一个正常概率分布。

<a id="attention-4-detail-43"></a>
### 10.5 为什么分块顺序改变仍需容差

**问题：** 实数合并满足同一集合定义，何以不同块顺序不必逐位相同？

**解析：** 浮点求和会舍入，不同结合顺序和中间尺度改变误差。稳定减最大值减少溢出，却不能恢复无限精度加法，值方向抵消时相对误差还可能放大。验收应对高精度小参考使用合理绝对与相对容差，再检查目标精度和边界范围。不能为强行逐位相等删除正常优化，也不能以“浮点总会不同”为由忽略足以改变任务结果的大差异；差异大小与用途都要报告。

<a id="attention-4-detail-44"></a>
### 10.6 反向行统计为什么等于输出内积

**问题：** 证明分数梯度中的中心项可以从输出和输出梯度得到。

**解析：** 记权重梯度为输出梯度与每个值的内积，中心项是各权重乘该内积之和。交换有限求和与内积，等于输出梯度与加权值和的内积，而加权值和就是当前输出。于是每行只需保存一个标量中心项，不必先存完整权重梯度行。这一步是分块重建的关键。它依赖这里的输出确为当前注意力加权和；若后面还有投影，应先把梯度按链式法则传回读取输出，不能直接用最终类别梯度替代。

<a id="attention-4-detail-45"></a>
### 10.7 键梯度为什么必须跨查询块累加

**问题：** 每个查询块都计算一份键和值梯度，最后保留最后一块是否可行？

**解析：** 同一个键和值会被多个查询读取，总损失对它们的导数是所有读取路径贡献之和。覆盖赋值只保留最后一个查询块，相当于丢掉前面输出的损失路径；前向完全不受影响，所以只测输出发现不了。应该从零初始化相应梯度并累加所有查询块，再与完整自动求导对照。还应使用多个非零输出梯度，避免偶然只有最后块参与损失，让错误实现侥幸通过。

<a id="attention-4-detail-46"></a>
### 10.8 Python 自动求导循环等于低内存内核吗

**问题：** 第一段在线前向不显式返回完整关系，能否直接宣称训练峰值线性？

**解析：** 不能。自动求导可能保存每块前向需要的中间量，完整可见矩阵本身也已占平方存储。真正的低内存训练还需反向重算、状态保存和实际分配策略。教学实现验证数学与边界，生产内核则需明确生命周期并测峰值。若性能报告只讨论前向，也要标明不求导模式和是否保存输出图，不能把一种模式的节省无声推广到另一种模式。

<a id="attention-4-detail-47"></a>
### 10.9 窗口四、三层，最远能依赖哪里

**问题：** 每层因果窗口包含自己及前三个位置，没有其他跨位置路径，三层最远能读到多远？

**解析：** 第一层最远向前传播三位，第二层再通过已混合表示传播三位，第三层总共九位，所以当前位置最多依赖此前九位。这是可达集合逐层并集的结果。若加入全局节点、跨时间归一化或额外卷积，条件改变，原界不适用。理论可达九位也不保证九位信息都被完整保留和有效学习；它是结构上限，而不是统计成功率。距离十的独特信息在当前限定结构下不可影响输出。

<a id="attention-4-detail-48"></a>
### 10.10 线性核前缀与 softmax 一致吗

**问题：** 实验三前缀累计与显式核矩阵一致，能否说它精确替代指数点积注意力？

**解析：** 不能。两种实现共享同一个特征内积核，所以关联律保证相同；该核本身一般不等于指数点积。实验同时与 softmax 比较并观察差异，正是在划清算法等价与算子变化。若要近似指数核，需要给特征构造、误差和随机条件，再检查归一化输出及任务。把所有可交换乘法顺序的机制都叫“相同注意力”，会掩盖模型实际使用的相似性和归一化条件。

<a id="attention-4-detail-49"></a>
### 10.11 任意掩码都能用一个累计矩阵表示吗

**问题：** 查询各自允许的键集合不同，是否仍可只累计一份全部键值统计？

**解析：** 通常不能。一个全局统计把所有键混在一起，无法自动为不同查询剔除任意子集。因果结构可以按前缀维护统计，固定窗口可能支持添加和删除，其他规则需要对应数据结构或额外分解。效率来自核的可分解性与集合结构共同满足条件，不能只看公式中有一个乘法结合律。若为提速忽略原掩码，就改变了信息边界，应按新模型评价而非声称等价实现。

<a id="attention-4-detail-50"></a>
### 10.12 正弦位置内积只依赖什么

**问题：** 对同频率的余弦、正弦二元位置向量，写出两位置内积并说明局限。

**解析：** 内积为两角差的余弦，所以该纯位置向量的内积只依赖相对差。加入内容并经过一般投影后，还会有内容与位置交叉项，完整注意力不自动只有距离依赖。这个恒等式可以解释一种表示性质，不能证明整个模型平移不变或长长度泛化。需要明确固定的是纯位置向量、内容查询键还是整网输入，数学结论的对象不同，不能直接互换。

<a id="attention-4-detail-51"></a>
### 10.13 RoPE 共同平移如何抵消

**问题：** 固定内容查询键，位置从七与二同时变成一千零七与一千零二，点积为何保持？

**解析：** 正交旋转乘积只保留两位置差，两个例子差都为负五，因此点积相同。实验四用独立旋转代码验证，同时检查向量范数保持。这不表示任意输入文本加一千个前缀后全网结果相同，因为内容表示、边界、可见集合和其他位置路径可能改变。局部公式的共同平移需要所有假设成立，不能凭一个旋转恒等式跳过完整计算图分析。

<a id="attention-4-detail-52"></a>
### 10.14 缓存键为什么不能重复旋转

**问题：** 历史键已按其逻辑位置旋转，读取时又按当前查询位置旋转一次，会发生什么？

**解析：** 额外旋转改变了历史键相位，与新查询的相对关系不再对应原位置差。张量形状和范数仍可能完全正常，所以仅测维度与有限数值发现不了。应与全前缀参考逐步比较，记录每个缓存项的逻辑位置、是否已旋转及位置机制版本。存储槽位可以移动，但逻辑位置语义应保留；改变缩放规则后旧缓存也不能未经验证继续沿用。

<a id="sec-7-2"></a>
<a id="attention-4-detail-53"></a>
### 10.15 位置公式可计算一万是否表示模型会用一万

**问题：** 训练只见一千，公式和数组支持一万，已经验证什么？

**解析：** 只验证表示和接口在该范围有定义，若实际运行成功还验证了当前资源可完成计算。模型能否定位和整合远处证据，需要独立任务，按位置、距离、干扰和长度报告。更改频率或缩放后还需回归短长度，避免原能力退化。训练外长度没有标签参与拟合并不自动意味着成功；公式给出了可能使用的信息形式，学习和泛化仍是统计问题。

<a id="attention-4-detail-54"></a>
### 10.16 相同读取输出能否唯一恢复权重

**问题：** 三个值分别二、二、八，权重零点七、零点二、零点一和零点一、零点八、零点一有何关系？

**解析：** 两者权重和都为一，前两个值相同，合计质量都为零点九，所以输出都为二点六。权重图却在前两位置显著不同，说明单凭读取输出无法唯一确定归因。差向量落在值映射零空间且总和为零，就是一般化条件。这个反例不否认权重可作为中间观测，而是限制“唯一解释”的主张。研究应结合内容、投影、后续路径和可证伪干预，避免把一种可行权重当唯一原因。

<a id="attention-4-detail-55"></a>
### 10.17 高权重值为零为何删除后仍大变

**问题：** 权重零点九八、零点零一、零点零一，值零、零、一百，删除第一键后输出为何从一到五十？

**解析：** 原输出来自最后一键的零点零一乘一百。删除第一键后，剩余总质量零点零二，重新归一化使最后一键权重变成二分之一，输出五十。第一键原值为零，不表示删除它不影响归一化。这说明固定权重替换值与删除键是不同干预。若只用删除造成的大变化解释原来“值贡献”，会把归一化集合变化混入结论；实验必须说明究竟修改了哪个对象。

<a id="attention-4-detail-56"></a>
### 10.18 分数公共平移为何不算有效扰动

**问题：** 所有合法分数都加一百，读取输出应如何改变？

**解析：** 指数共同乘同一正因子，分子分母抵消，所以概率与输出保持。数值实现减最大值也利用这个自由度。对误差分析，可以先减公共常数，研究相对扰动，而不能只看原始分数的最大绝对差就认定函数严重不同。但如果掩码、位置或值同时改变，公共平移论证无法涵盖这些变化；应分项核对，不要把任何看起来相似的分数差都当作可忽略常数。

<a id="attention-4-detail-57"></a>
### 10.19 读取扰动界怎样连接值尺度

**问题：** 固定合法集合、分数误差不超过某值，为什么还要知道值范数？

**解析：** 输出是概率变化乘值的加权和，同样概率误差乘很大的值，可以导致较大向量误差。通过三角不等式可用最大值范数乘概率一范数差控制，再结合本章保守的分数扰动界。若值也量化，要额外加值误差项；后续网络和离散选择又有自己的敏感性。一个单层局部界帮助定位尺度，却不能直接替代全网任务误差或最终准确率保证。

<a id="attention-4-detail-58"></a>
### 10.20 小权重远处证据能直接删吗

**问题：** 几张热图上远处都很淡，改成局部窗口是否已证明无损？

**解析：** 没有。观察样本不覆盖全部任务，低概率位置可能在值方向或其他输入中关键，多次删边还会累计改变归一化和可达性。应先定义目标分布，报告结构边界和固定模型敏感性，再按合法训练与预算比较新结构质量。热图可以提出“远处使用较少”的假设，不能独自证明一般删除无代价。若只改变可见范围，应明确这是模型条件变化而非纯内核重排。

<a id="attention-4-detail-59"></a>
### 10.21 头间权重相近就可以删头吗

**问题：** 两头图形相似，是否一定冗余？

**解析：** 头的值投影和输出投影可能不同，即便权重相似，它们在特征空间承担的方向也可能不同。反过来，权重不同也可能经投影产生相似功能。固定模型删除测试说明当前依赖，删除后重训说明替代学习能力；两者都需要按任务、长度和输出目标评价。不能只计算图相关系数就推断结构必要性。多头是完整参数路径，解释时应把读取系数与传递内容一起看。

<a id="attention-4-detail-60"></a>
### 10.22 遮挡高权重词改变输出就是因果证明吗

**问题：** 删除一个高权重词后答案改变，为什么仍需要对照？

**解析：** 删除可能同时改变语法、长度、位置、信息充分性和训练分布，输出变化不一定由研究者指定的注意力路径引起。应使用合法替换、内容匹配的低权重与随机对照，并在必要时隔离路径，检查竞争解释。因果主张要明确干预对象与适用范围，不能由一次有限输入变化推广所有相关样本。可视化加干预比单图更有力，但干预本身仍需设计和证据边界。

<a id="attention-4-detail-61"></a>
### 10.23 两种实现误差小但 argmax 不同怎么办

**问题：** 读取或 logits 都在数值容差内，却生成不同符号，是否应只报告通过？

**解析：** 应同时报告数值误差与决策裕量。接近并列的类别可以被很小扰动交换，后续生成前缀随之分叉。若应用要求逐步同决策，应定义更严格的行为验收；若允许小数值变化，则评估实际任务影响和发生比例。不能用一个标量误差阈值覆盖全部用途，也不能把每个近并列分叉都叫数学实现错误。先明确精确目标、近似容忍和任务要求，再判断是否可接受。

<a id="attention-4-detail-62"></a>
### 10.24 解释研究如何避免挑图讲故事

**问题：** 从数百个头中挑一张符合预期的图，应该补什么才能支持研究？

**解析：** 先固定关注输出、层头选择规则与假设，再在开发数据提出预测，用独立样本检验干预及对照。记录不符合故事的样本、失败比例和其他路径，不把探索图当确认性证据。若看完所有结果再换解释，应承认它属于探索并设计新验证。完整报告让别人能重复选择过程、重算输出变化，知道哪些条件支持解释，哪些仍不可辨识，而不是只能看到被挑出的漂亮样例。

<a id="attention-4-detail-63"></a>
## 11. 综合研究：把五组机制实验连成证据链

<a id="sec-7-1"></a>
<a id="attention-4-detail-64"></a>
### 11.1 一份可以分阶段完成的进阶作业

第一阶段手算两个块的最大值、分母和加权和，再把第一段实现改为不同分块顺序，比较误差范围。第二阶段独立推导行中心项，故意把键梯度覆盖，验证反向测试能失败。第三阶段用相同输入比较稠密 softmax、局部窗口和特征核，分别说明等价条件、信息变化和可分解集合。第四阶段执行旋转位置的范数、相对关系与缓存位置故障实验。第五阶段在不可辨识值构造中比较热图、值替换和删键，逐项解释结果为什么不同。

每阶段都先写预期和反例，再运行代码，避免根据输出反推一个永远正确的故事。完成标准是能够定位失败源于数学目标、索引、数值政策、求导还是任务分布，而不仅是让断言变绿。对每次修改保留原失败条件及修复理由，确认修复没有破坏其他边界。这样一组小实验可以成为后续真实高效实现的参照，而不需要把整个工程搬进教材。

<a id="attention-4-detail-65"></a>
### 11.2 扩展到真实模型时新增哪些证据

真实模型研究应重新固定参数版本、分词与位置规则、输出目标、数据划分和设备配置。前向一致只是第一步，训练用途还需梯度与随机状态，生产用途还需请求生命周期和性能。解释用途则要明确干预是否保留标签语义，并记录分布外替换的限制。小实验已经证明的局部性质可以指导这些检查，但不能直接继承真实任务质量与设备收益。

本章在线前向九种布局、解析反向三种布局、核前缀、旋转位置和权重不可辨识实验均为 CPU 机制核对。它们没有返回完整真实语言模型的因果解释，没有测 GPU 内核速度，也没有证明训练外长上下文能力。学习的下一步应围绕明确问题补足这些证据，而不是把一个缩写当答案。每种方法都值得继续追问其条件、代价、可反驳预测和未覆盖的边界。
