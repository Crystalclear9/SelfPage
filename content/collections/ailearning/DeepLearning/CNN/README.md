# 卷积神经网络

理解局部连接、参数共享、输出尺寸和视觉特征层次。

## 学习顺序与覆盖范围

第 1—2 章之后即可进入[手写数字项目](../Projects/README.md)。第 3 章的残差与多尺度可接着读；其中视觉 Transformer 先作概览，待完成[注意力](../Attention/README.md)与[Transformer 网络块](../Transformer/01-网络块位置与架构类型.md)后返回。第 4 章用于巩固卷积实验。
