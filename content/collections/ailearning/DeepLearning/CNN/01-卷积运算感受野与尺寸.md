## 1. 从图像函数到共享的局部线性算子

卷积层首先是一种对函数形式的限制。把一张三通道图像展平成向量，任意线性映射允许每个输出与每个输入独立连接；卷积则要求输出只读取附近区域，并让不同位置共享连接系数。前一个要求叫局部连接，后一个叫参数共享。二者可以分别存在：局部连接但不共享得到局部连接层，共享一个覆盖全图的核则不再具有很小的局部范围。理解这两个约束，比把卷积记成“自动提取图像特征”更精确。

图像上的邻近像素往往相关，同样的边缘可能出现在不同位置，因此这种限制常与数据结构相容。限制也会排除一些函数，例如需要在左上角和右下角对相同纹理使用完全不同系数的线性规则。网络可以借助边界、位置通道或后续非共享头表达位置依赖，但这已是在基本卷积之外引入额外信息。归纳偏置意味着偏爱某些函数，而不是对所有任务都更优。

本章约定输入为 $`X\in\mathbb R^{B\times C_{in}\times H\times W}`$，批量、通道、高、宽按顺序排列。卷积核为 $`K\in\mathbb R^{C_{out}\times(\frac{C_{in}}{g})\times k_h\times k_w}`$，分组数为 $`g`$。形状相同不表示轴语义相同：把高宽通道的内存直接重新解释，虽然可能凑出合法形状，却会改变哪些数被视为相邻像素。交换轴应使用明确的排列操作，并核对一个小样本的坐标。

<a id="cnn1-correlation"></a>
### 1.1 互相关与数学卷积的区别

先忽略批量与分组。深度学习常用的运算为

```math
\begin{aligned}
&Y_{o,u,v}=b_o+\sum_{c=0}^{C_{in}-1}\sum_{i=0}^{k_h-1}\sum_{j=0}^{k_w-1}\\
&\qquad K_{o,c,i,j}\widetilde X_{c,us_h+i d_h,vs_w+j d_w}.
\end{aligned}
```

这里 $`\widetilde X`$ 是已经按约定扩展的输入。该式不翻转核，是互相关；数学离散卷积通常把核索引反向。对可学习且无额外约束的核，翻转只是参数的重新编号，二者能表示相同函数族。但加载固定滤波器、复现信号处理算法、解释已训练权重时，方向差异真实存在，不能因为函数族相同就忽略具体系数的位置。

例如一维输入为 $`[1,2,4,8]`$，核为 $`[1,-1]`$，有效互相关给出 $`[-1,-2,-4]`$。若按相反核 $`[-1,1]`$ 计算，则为 $`[1,2,4]`$。它们检测变化的方向相反。把一个边缘滤波器图示与库输出比较时，应先确定核是否被翻转，再讨论图像上边缘的正负号。可学习训练可能自行学出另一方向，但固定权重不会自动替读者修正约定。

通道求和也很重要。一个输出通道并非对应输入的某一种颜色，而是同时读取本组输入通道的不同空间核，再把结果加起来。输出通道数表示学习多少组局部映射。增加输出通道可以提供更多表示维度，却不增加单层的空间跨度；增加核大小扩大局部读取范围，却不自动增加输出表示的通道数。这两个自由度解决不同问题。

<a id="sec-1-1"></a>
### 1.2 一个位置的完整手算

令单通道输入为三行 $`[1,2,3]`$、$`[4,5,6]`$、$`[7,8,9]`$，核为两行 $`[1,0]`$、$`[0,-1]`$，偏置为二，无填充且步长一。左上输出为 $`1-5+2=-2`$；右上为 $`2-6+2=-2`$；左下为 $`4-8+2=-2`$；右下为 $`5-9+2=-2`$。一个核的四个参数在四个位置复用，偏置也在同一输出通道的各位置复用。

若把核复制给第二输出通道并把第二通道偏置改为零，第二通道四个值都为负四。这说明偏置按输出通道存储，而不是为每个像素单独存储。若输入再增加一个值全为一的通道，并让它对应的核四项均为一，每个输出再增加四。可以按输入通道分别计算二维互相关再相加，结果与总公式一致。

这个算例还揭示局部映射与全图连接的差别。输出右下角不会读取输入左上角，因为它不在对应窗口里；若后续层汇总多个输出，这种间接依赖才可能出现。讨论一个输出是否能“看到”全图时，应沿所有层的依赖路径追溯，不能只看最终输出的空间尺寸。

**先追踪一个输出。** 输入按行填入 1 至 25；上排框出左上窗口，右侧给出这个窗口的响应。下排则列出把整张输入的中心像素增加十后，九个输出各自的改变量。核的三行都是 $`[1,0,-1]`$，因此每行都取左值减右值。中间一行展开得到 $`(1-3)+(6-8)+(11-13)=-6`$。向右或向下滑动时，这个线性斜坡的左右差不变，九个输出都等于 −6。均匀响应来自这个特定输入，不能推广到任意图像。采用互相关约定、步幅 1、无填充；按数学卷积翻核会使本例符号反转。

图的上排把局部窗口、共享核和单个响应分开。逐元素乘加作用于一个三乘三窗口。一个输出读取一个三乘三窗口，九个合法起点才构成三乘三输出。空间对应与乘加应一起理解：[《动手学深度学习》的图像卷积](https://d2l.ai/chapter_convolutional-neural-networks/conv-layer.html)用局部输入、共享核和输出逐项说明这种运算；跨层的依赖跨度则见 [Distill 的感受野推导](https://distill.pub/2019/computing-receptive-fields/)。本图是按本章数字重新绘制的静态算例。

**再问一个像素怎样传播。** 以输出中间一行为例，其三个窗口固定在输入第 1 至 3 行，起始列分别为 0、1、2（从零计数）。现在只将输入中心像素从 13 改为 23。这个像素位于全部九个窗口内，但并非九个输出都改变。对输出第零列，中心像素落在核的最右列，系数为负一，所以输出从负六变成负十六；对第一列，它落在核的零系数列，输出仍为负六；对第二列，它落在核的正一系数列，输出变成四。三行使用相同规律。于是理论连接支持与当前非零影响可以不同：窗口覆盖某像素，只说明有一条允许连接，具体系数为零时该连接不贡献数值。

令中心扰动为 $`\delta`$，本图的输出变化就是每行相同的 $`(-\delta,0,\delta)`$。这也直接给出了九个输出对该输入像素的偏导，而无需依赖颜色猜测。[CS231n 的卷积演示](https://cs231n.github.io/convolutional-networks/#conv)强调逐窗口输入与输出的对应；本例再将共享核的同一规则与可复算的干预响应放在一起。

## 2. 从合法起点推导输出尺寸

尺寸公式来自窗口能从哪些位置开始。设一维真实输入长度为 $`L`$，左右填充为 $`p_l,p_r`$，核有 $`k`$ 个采样点，相邻采样间隔为膨胀率 $`d`$。核覆盖跨度为 $`k_{eff}=d(k-1)+1`$。第 $`u`$ 个输出的窗口起点在填充数组中为 $`us`$，最后一次采样为 $`us+d(k-1)`$。合法条件是它不超过 $`L+p_l+p_r-1`$。

由此得到 $`u\le\frac{(L+p_l+p_r-k_{eff})}{s}`$，而起点从零开始计数，最终

```math
L_{out}=\left\lfloor\frac{L+p_l+p_r-d(k-1)-1}{s}\right\rfloor+1.
```

公式默认层接受这一配置，且存在合法输出。若有效核比填充后输入还长，实际库通常报错，而不是产生带负维度的张量。高度与宽度分别代入；不应把长方形输入或不相同步长强行套进一个“边长减二”的口算规则。整数向下取整说明末端可能剩下一些输入没有成为新窗口的起点。

<a id="sec-2-1"></a>
### 2.1 非对称填充、偶数核与 same

以长度七、核三、步长二、膨胀一为例，无填充得到三，左右各填一得到四。若希望长度八的输入经步长一、核四仍输出八，需要总填充三，因此左右不可能相等。选择左一右二与左二右一虽然输出长度相同，采样中心却不同；这会影响后续跳连与定位。输出尺寸只记录数量，没有记录每个位置对应原图哪里。

所谓 same 必须连同库的具体定义阅读。在本章使用的 PyTorch 2.10 中，卷积模块的字符串 same 只支持步长一；其他系统可能用向上取整规则支持更大步长，并在末端分配非对称填充。不能把跨框架同名参数视为完全相同的几何协议。复现网络时，应显式记录左右上下填充和坐标中心。

膨胀率二、核三的采样偏移为零、二、四，跨度五，但只读取三个位置。它与普通五点核具有相同跨度，却缺少中间两个可学习系数。稀疏采样扩大覆盖而不同比增加参数，但可能产生网格式盲区。连续层采用相同膨胀公因子时，某些输出始终只依赖某类输入坐标；交替膨胀率或加入普通卷积可以改变这种连接图。

<a id="deep-dive-2"></a>
### 2.2 三层形状表的逐项计算

输入批量二、三通道、空间三十一乘二十九。第一层核三、步长二、填充一、输出八通道，高为十六、宽为十五。第二层核三、膨胀二、步长一、填充二、输出十六通道，有效核五，高宽保持十六乘十五。第三层核二、步长二、无填充，输出空间八乘七；宽度十五的最后一列未构成完整新窗口。

若把第三层误认为“空间尺寸精确除二”，宽度就会写成七点五或错误向上取八。若接展平线性头，正确输入数为十六乘八乘七等于八百九十六。若改用全局平均池化，头接收十六个通道摘要，但空间信息的处理方式同时改变，不能把它仅当作避免计算展平长度的技巧。

形状表至少写出输入、核、步长、膨胀、填充、输出通道与输出空间。对有分支的网络，还要逐个分支计算后才能相加或拼接。自动前向检查是公式的独立核验：手算可以发现设计意图错误，代码可以发现实现参数错误，两者吻合比反复修改层直到不报错更有解释力。

<a id="cnn1-exp1"></a>
### 2.3 实验一：用显式循环核验分组卷积

以下实验独立运行，不下载数据。参考实现逐元素读取窗口，故意不调用另一个卷积实现作为“答案”。同时覆盖分组、步长、膨胀和非正方形核。张量使用双精度以便观察数值误差；断言检验运算定义，不能代表大规模吞吐量。

```python
import torch
import torch.nn.functional as F

torch.manual_seed(7)
torch.set_num_threads(1)
x = torch.randn(2, 4, 9, 11, dtype=torch.float64)
w = torch.randn(6, 2, 3, 2, dtype=torch.float64)
b = torch.randn(6, dtype=torch.float64)
stride, padding, dilation, groups = (2, 1), (1, 2), (2, 1), 2
actual = F.conv2d(x, w, b, stride, padding, dilation, groups)
padded = F.pad(x, (2, 2, 1, 1))
expected = torch.empty_like(actual)
for n in range(2):
    for o in range(6):
        group = o // 3
        for u in range(actual.shape[2]):
            for v in range(actual.shape[3]):
                value = b[o].clone()
                for c in range(2):
                    for i in range(3):
                        for j in range(2):
                            value += (w[o, c, i, j] *
                                      padded[n, group * 2 + c,
                                             u * 2 + i * 2, v + j])
                expected[n, o, u, v] = value
assert actual.shape == (2, 6, 4, 14)
torch.testing.assert_close(actual, expected, rtol=1e-12, atol=1e-12)
assert w.numel() + b.numel() == 6 * (2 * 3 * 2 + 1)
print(tuple(actual.shape), float((actual - expected).abs().max()))
```

两组输入各有两个通道，每组产生三个输出通道。输出通道零到二只依赖输入零到一，输出三到五只依赖输入二到三。若把参考实现中的组偏移删除，形状仍完全相同，但数值断言失败。这是轴语义错误与形状错误的区别，也是为什么只打印输出尺寸不够。

**有限画布上的平移：边界必须参与比较。** 卷积的共享核建立了空间规则，但零填充和截断会改变边缘可读取的上下文。

![有限零填充下交换右移与互相关的顺序，内部一致而两端不同](images/01-shift-and-cross-correlation-do-not-commute-at-padded-boundaries.webp)

[打开原图放大](images/01-shift-and-cross-correlation-do-not-commute-at-padded-boundaries.webp)

令 $`x=(1,2,3,4)`$，$`S`$ 表示向右移动一格、左端补零并丢掉最右值。用核 $`(1,1,1)`$ 做步幅一、两端各补一个零的互相关 $`F`$，得到

```math
\begin{aligned}
&F(x)=(3,6,9,7),\qquad F(Sx)=(1,3,6,5),\\
&\quad S(Fx)=(0,3,6,9).
\end{aligned}
```

按位置比较表中的两条输出。内部两格一致，边缘两格不同：最左输出的“补零”与先卷积获得的边界响应不是同一个对象；最右输出则在平移输入时失去了原来的值四。这里的矛盾发生于“零扩展后卷积再限制到有限区域”与“有限区域平移截断”的组合，不能据此否定无限网格、相同扩展规则下的平移等变性。若后续还有步幅采样，除边界外还须检查采样相位。卷积运算与输出范围的基本约定可核对 [D2L 7.2](https://d2l.ai/chapter_convolutional-neural-networks/conv-layer.html)；本图专门把有限边界条件加入了数值检验。

<a id="sec-3"></a>
## 3. 理论感受野、采样跳距与起始中心

理论感受野描述一个输出在计算图上可能依赖的原始输入位置。它不等于训练后实际显著利用的区域，也不等于每个位置都有非零导数。先对一条无分支、规则网格路径定义三个量：$`r_l`$ 为覆盖跨度，$`j_l`$ 为相邻输出中心在原图上的距离，$`a_l`$ 为第一个输出中心的位置。以像素中心零点五起算，初始 $`r_0=1,j_0=1,a_0=0.5`$。

第 $`l`$ 层核大小为 $`k_l`$、膨胀为 $`d_l`$、步长为 $`s_l`$，左侧填充为 $`p_l`$，则

```math
\begin{aligned}
r_l &=r_{l-1}+(k_l-1)d_lj_{l-1},\\[6pt]
j_l &=s_lj_{l-1},
\end{aligned}
```

```math
a_l=a_{l-1}+\left(\frac{(k_l-1)d_l}{2}-p_l\right)j_{l-1}.
```

第一式来自最左和最右输入特征中心的间距，再加每个特征原本覆盖的跨度；第二式来自每次跳过若干前层网格；第三式跟踪窗口中点。偶数核使中心落在两个前层位置之间完全合理。边界上的部分理论范围可能是填充值，因此跨度并不等于真实观测数。

<a id="sec-4"></a>
### 3.1 有下采样的完整递推

从输入开始，三点步长一、填充一卷积得到 $`r=3,j=1,a=0.5`$。接两点步长二池化得到 $`r=4,j=2,a=1`$。再接三点步长一、填充一卷积得到 $`r=8,j=2,a=1`$。最后三点膨胀二、步长一、填充二卷积得到 $`r=16,j=2,a=1`$。最后每个输出中心相隔两个原始像素，理论跨度十六，中心起点仍为一。

比较另一条路径：两次三点步长一卷积得到跨度五；随后两点池化得到跨度六。它与先卷积、池化、再卷积的跨度八不同。下采样使后续核的每一步跨越更大原图距离，因此相同层数与核集合，顺序不同也改变感受野。网络结构不是一张只列层数的清单。

存在跳连时，需要把所有路径的依赖集合取并集。用最大跨度概括可能掩盖中心错位、稀疏孔洞或不同路径覆盖不连续的问题。对于空洞卷积，递推得到的是最小包围区间的长度，不保证其中每个点都实际连接。要证明覆盖连续，应进一步分析索引集合的和集，而不能只比较两个跨度数字。

<a id="cnn1-effective"></a>
### 3.2 理论范围与有效贡献为什么不同

考虑一维三层三点卷积，各核全为一且无非线性。中心输出对输入的线性系数来自多条路径的乘积之和。中心像素可经更多路径到达输出，边缘像素路径较少，因此即使所有局部核系数一样，最终影响也不均匀。把三点多项式连续相乘，就得到类似离散分布卷积的中心集中系数。

加入随机权重、激活和数据后，梯度支持还受符号抵消与激活门控制。某像素处梯度为零可能是本次输入的激活状态所致，而不是计算图根本没有依赖。一个样本的梯度图也不是整个模型固定的有效感受野，更不能直接解释为因果重要性。可以汇总多个样本的绝对梯度或平方梯度，但需交代归一化、目标标量和输入尺度。

研究有效感受野时，应先给出理论上界，再报告在何种输入分布和目标输出下测得的贡献分布。若输出是所有空间位置的总和，得到的是多个局部范围的合成；若只取中心特征，才更接近单位置分析。改变任务头就可能显著改变梯度图，故实验目标必须固定。

![六层卷积中，距中心六格、五格和零格的路径数分别为一、六和一百四十一](images/01-center-and-boundary-counts-for-six-stacked-local-kernels.webp)

[打开原图放大](images/01-center-and-boundary-counts-for-six-stacked-local-kernels.webp)

**可达位置与实际路径权重。** 本图是一维、无限网格上的独立算例：连续六层核 (三分之一、三分之一、三分之一)，无激活且不遇边界。总感受野包含十三个位置，但中心经过许多条路径，最边缘只有一条；六次核卷积得到实际权重，不能将十三个位置视为等权。图中给的是路径数，每条路径的权重为 $`3^{-6}`$，所有位置的权重之和为一。这里比较固定线性算子的系数；有激活和学习参数时，有效影响还取决于门与权重。进一步阅读可对照[Distill 的感受野推导](https://distill.pub/2019/computing-receptive-fields/)。

```math
K_{\mathrm{eff}}(z)=\left(\frac{z^{-1}+1+z}{3}\right)^6,\qquad \sum_i K_{\mathrm{eff},i}=1.
```

**从路径数恢复整条曲线。** 六层中每层有左移、原位、右移三种选择，共有 $`3^6=729`$ 条路径。把偏移相同的路径合并，十三个位置的计数依次为

```math
(1,6,21,50,90,126,141,126,90,50,21,6,1).
```

每条路径的权重都是 $`\frac1{729}`$，所以中心位置的系数为 $`\frac{141}{729}`$，最边缘仅为 $`\frac1{729}`$。图从六层的十三个位置中选出中心、最边缘与紧邻边缘的位置，分别列出路径数。增加层数会扩大可达范围，并让更多路径在中心附近汇合。这是固定线性算子的精确系数，并不需要借助训练后的热图猜测。

还可以把核视作六次独立等概率步长 $`-1,0,1`$ 的和：每步均值零、方差 $`\frac23`$，因此总方差为四，标准差为二。中心五点的总权重为 $`\frac{573}{729}\approx78.6\%`$；若把十三个位置误当作等权，只会得到 $`\frac5{13}\approx38.5\%`$。这给出一个可量化的区别：感受野覆盖五个位置，与这五个位置承载多少总影响，是不同的问题。

**检验。** 把所有局部系数同时乘三，路径数和可达位置不变，但总增益变成 $`3^6`$。归一化之后曲线形状仍相同，原始输入梯度的绝对值却改变了。比较梯度图时，必须说明是否做了归一化，也不能将本例的非负路径和结论直接推广到存在负权抵消的网络。

<a id="cnn1-exp2"></a>
### 3.3 实验二：路径计数与梯度支持

```python
import torch
import torch.nn.functional as F

torch.set_num_threads(1)
x = torch.zeros(1, 1, 11, dtype=torch.float64, requires_grad=True)
w = torch.ones(1, 1, 3, dtype=torch.float64)
y = x
for _ in range(3):
    y = F.conv1d(y, w)
y[0, 0, 2].backward()
grad = x.grad.flatten()
expected = torch.tensor([0, 0, 1, 3, 6, 7, 6, 3, 1, 0, 0],
                        dtype=torch.float64)
torch.testing.assert_close(grad, expected)
assert int((grad != 0).sum()) == 7
assert float(grad.max()) == 7
print(grad.tolist())
```

理论跨度七与非零支持长度相同，但贡献从边缘的一到中心的七逐渐增加。这个结果可由生成多项式 $`(1+z+z^2)^3`$ 的系数独立推导。实验没有训练，也没有展示真实图像模型的有效范围，只证明路径数量足以让均匀局部核形成不均匀全局系数。若把一个核改成有正负抵消的形式，即使理论范围不变，部分系数也可为零。

**从路径图恢复每个系数。** 一维两层三点核的路径数是 $`(1,2,3,2,1)`$：偏移 $`t`$ 的次数等于满足 $`i+j=t`$、$`i,j\in\{0,1,2\}`$ 的索引对数。二维行、列偏移可以独立组合，所以右侧矩阵是该向量与自身的外积。每个格子对应一个原始输入位置，格内数字才是经过该位置的路径总数；中心为九、角点为一，所有输入位置的路径数合计 $`3^2\times3^2=81`$。在全一核的当前条件下，每条路径权重为一，路径计数也就是该输入对指定输出的线性系数和偏导。

读完后可以做一次不用颜色的检验：只把中心输入增加 $`\delta`$，指定输出应增加 $`9\delta`$；同样大小的角点扰动只增加 $`\delta`$。这里固定的是同一个第二层输出，改变的是它感受野内的输入位置。因而“能看到五乘五区域”只说明可达范围，不能推出这二十五个位置具有同样贡献。[Distill 的感受野推导](https://distill.pub/2019/computing-receptive-fields/)说明如何追踪可达范围；本图额外展开全一核下的路径重数，二者回答不同层次的问题。

**适用条件。** 本图限定单输入、单输出通道、全一卷积核、无偏置和非线性、步幅一、无膨胀，并选取不受边界填充影响的位置。此时路径数就是输入对该输出的偏导；带正负权重、门控和非线性后会有抵消或截断，不能把这张计数图直接当作任意训练网络的有效感受野，也不能据此断言所有有效感受野都呈高斯形。

上行的两层膨胀率均为二。沿一维，每层采样偏移为 $`\{0,2,4\}`$，复合系数由离散卷积得到：

```math
\end{aligned}
```

其包围长度为九，真正非零位置只有五个。二维核可分离，所以系数矩阵是该向量与自身的外积：包围 $`9\times9=81`$ 格，但只有 $`5\times5=25`$ 格能够影响输出。奇数偏移行或列始终没有路径，中心的九来自两个方向各三条路径的乘积。

下行保持第一层膨胀二，第二层改为普通三点核。一维系数成为

```math
(1,0,1,0,1)*(1,1,1)

```

二维包围范围缩小到 $`7\times7`$，49 格全部非零。两图都使用两层、每层九个核权重，也都有 $`9\times9=81`$ 条复合路径；上行的路径集中在稀疏坐标，下行覆盖连续坐标。比较覆盖密度时，每项都对应一个输入位置。

这组例子说明“感受野更大”与“覆盖更完整”是两个命题，也说明相同路径总数不保证相同空间分配。[Yu 与 Koltun 原论文图 1](https://arxiv.org/pdf/1511.07122)用逐层膨胀展示上下文范围扩张，但其连续覆盖依赖具体膨胀安排；不能从论文图推广为任意重复膨胀都没有孔洞。[Distill 的感受野推导](https://distill.pub/2019/computing-receptive-fields/)也明确区分包围范围、边界与范围中的未用输入。本图另外构造两组可逐格复算的路径计数，突出这一条件。

**连接存在不等于每次梯度非零。** 换成任意可正可负的核，多个路径乘积可能抵消；加入 ReLU 后，激活门也可能把某条路径截断。因此零连接是结构性不可见，非零连接仅说明允许影响，实际有效贡献仍由权重、输入和门状态决定。反过来，后续逐点 $`1\times1`$ 层不会补回这一输出位置缺少的空间采样；若后续加入普通空间卷积或多分支融合，则要重新计算整个连接支持。

**检验问题。** 让上行对应的模型输入除一个奇数行位置外全部为零，再改变该位置，指定输出严格不变；下行对应的模型在其七格范围内同位置的扰动则按两个轴的系数乘积改变输出。若在边界、非线性或不同中心上做实验，必须先同步改变算例条件，不能拿两个不同输出位置的结果反驳这里的固定连接图。

<a id="sec-5"></a>
## 4. 分组、深度卷积与表达约束

标准卷积让每个输出通道读取全部输入通道。分组卷积把输入与输出通道各分成 $`g`$ 组，仅在对应组内连接。输入通道数和输出通道数都必须能被组数整除。忽略偏置，参数数为 $`C_{out}(\frac{C_{in}}{g})k_hk_w`$。组数增加减少通道间连接，也减少乘加，但不会自动让各组共享权重；每组仍有自己独立的核。

深度卷积令组数等于输入通道数。如果输出通道是输入通道的整数倍，每个输入通道可生成多个独立空间响应。常见的深度可分离块先做逐通道空间卷积，再做一点乘一点卷积混合通道。这里“可分离”是网络结构分解，不是声称任意标准卷积都能无损拆开。

当深度乘数为一且两层之间没有非线性时，等效标准核满足 $`K_{o,c,i,j}=P_{o,c}D_{c,i,j}`$。对固定输入通道，各输出通道使用的空间核必须互相成比例，表达能力因此受限。标准卷积允许不同输出对同一输入通道使用完全不同的空间模式。增加深度乘数提供多个空间基，或堆叠非线性块，可以放松限制，但成本与函数族也同时变化。

<a id="cnn1-cost"></a>
### 4.1 参数、乘加与激活各自计什么

含偏置的标准参数数为 $`C_{out}(C_{in}k_hk_w+1)`$。前向乘加数近似为 $`B H_{out}W_{out}C_{out}(\frac{C_{in}}{g})k_hk_w`$。本章把一个乘法加一次累加记为一次乘加；若计为两个浮点运算，应明确说明。偏置加法、激活、归一化、池化以及反向传播没有包含在这条卷积乘加公式里。

例如批量二、输入三通道三十二平方、输出十六通道、三平方核、填充一，参数为四百四十八，前向卷积乘加为八十八万四千七百三十六。输出激活元素为三万二千七百六十八，单精度约占十三万一千零七十二字节。把输入边长翻倍，核参数仍为四百四十八，但输出位置和上述乘加、激活规模都变四倍。

训练峰值内存还包括输入、保存的中间量、梯度、优化器状态与临时工作区。仅用参数数乘以四字节估算训练显存会遗漏大量对象。反过来，一种实现可能通过重算减少保存激活，却增加计算。参数、理论算量、峰值内存与实际延迟是不同维度，不能用一个数字替代另外三个。

<a id="cnn1-costcase"></a>
### 4.2 深度可分离计算的具体比较

输入输出通道均为六十四，核三平方，标准无偏置参数为三万六千八百六十四。深度卷积有五百七十六个参数，点卷积有四千零九十六个，总计四千六百七十二，约为标准的百分之十二点七。若输出位置相同，对应乘加也有同样比例。比例由 $`\frac{1}{C_{out}}+\frac{1}{k^2}`$ 得到，而不是对任意维度都固定节省八倍。

但点卷积常占分离块的大部分乘加。若继续增加通道，点卷积成本按通道乘积增长；只优化深度空间核可能已不再主导整体速度。实际设备上小算子调度、访存、并行度和内核实现还会改变延迟。测量必须固定批量、精度、线程和输入布局，先预热，再报告多次测量的分布；本章没有从 CPU 小实验外推移动端或 GPU 速度。

宽度与分辨率缩放也不同。若中间层输入输出通道都乘以系数 $`\alpha`$，标准卷积主要乘加近似按 $`\alpha^2`$ 变化；若高宽都乘以 $`\rho`$，则近似按 $`\rho^2`$ 变化。第一层输入通道、最后分类头及取整会偏离此近似，故完整网络需逐层计数，不能把单层缩放规律直接当精确总量。

<a id="sec-6"></a>
## 5. 平移等变性的证明与失效条件

定义无限整数网格上的平移 $`T_\delta x[n]=x[n-\delta]`$，互相关算子 $`Cx[n]=\sum_i k[i]x[n+i]`$。则

```math
\begin{aligned}
&C(T_\delta x)[n]=\sum_i k[i]x[n+i-\delta]\\
&\quad =(Cx)[n-\delta]=T_\delta(Cx)[n]
\end{aligned}
```

证明只用了共享核与相同索引集合；偏置若在空间共享，也不破坏结论。二维与多通道只增加求和符号，逻辑不变。

等变指输入平移后特征以相应方式平移；不变指输出数值保持不变。局部卷积特征通常追求等变，分类输出可能借助全局聚合追求某种不变。不能把“相同模式在不同位置触发相同核”误读成整张特征图不随位置变化。若输出图完全不变，它反而无法表示目标位置。

逐位置非线性与共享通道映射保持这种等变，因为同一函数独立应用在每个位置。但含绝对位置的门控、按位置设置的参数或位置相关预处理可能改变性质。训练增强可以鼓励近似稳定，却不等于结构上对所有平移都有严格代数保证。性质属于完整算子组合，不能从某一层的名称推到整个网络。

<a id="sec-6-1"></a>
### 5.1 有限边界与步长的精确限制

有限输入经过零填充卷积，可在输入与输出共同远离边界、所有相关窗口均落在真实可比较区域时保留局部等变。但整体张量的“零填充后平移再裁切”通常与“卷积后平移再裁切”不交换：输入平移先丢弃的边缘信息，可能原本会经卷积传回可见边缘。循环填充在有限周期网格上与循环平移相容，但它引入左右边界相接的周期假设，未必适合真实照片。

步长为 $`s`$ 的卷积可写成先密集卷积再按固定相位抽样。输入平移 $`\delta`$ 若是 $`s`$ 的整数倍，输出可相应平移 $`\frac{\delta}{s}`$ 个网格；若不是，抽样相位改变，通常没有整数输出平移能完全对应。多层累计步长为 $`j`$ 时，同样应检查平移是否与总网格对齐。这个结论不是说非对齐平移一定导致很差分类，而是说严格等变不再由结构自动保证。

最大池化也可能因采样边界发生跳变。一个强响应从某个池化窗移入相邻窗，汇总位置就变化；全局最大值在理想不丢失内容的平移下可保持，但有限裁剪、填充值和后续非线性仍需另外分析。平均池化可平滑局部变化，却也不保证任意一像素平移下输出网格完全等变。

<a id="cnn1-alias"></a>
### 5.2 下采样与混叠：为何先平滑仍不是万能解

考虑一维交替序列 $`[1,-1,1,-1,\ldots]`$。每隔两点取样会得到全一；把输入平移一个点后再取样会得到全负一。原信号只是相位变化，低分辨表示却完全反转。这是下采样对高频成分敏感的简单例子。局部平均可以消除这个特定交替模式，但同时也丢弃它携带的细节。

若任务标签正依赖细条纹的方向或频率，过早平滑会删掉有用信号。若标签应忽略小平移，高频混叠则可能成为不希望的变化来源。合理设计需要把采样理论与任务需求结合：保留足够分辨率，或在降采样前低通，或通过多分支保留细节。没有一种固定预处理能在所有任务上同时保持全部信息又消除全部相位敏感。

抗混叠实验应分别报告输入平移、边界处理、插值方式、共同有效区域以及最终任务性能。只展示一张更平滑的特征图不足以证明更好鲁棒性。尤其使用双线性平移会同时插值像素，与整数平移的代数命题不是同一个问题。研究结论应对应实际执行的变换。

**先核对图中的直接隔点采样。** 取八点信号 $`A=(1,-1,1,-1,1,-1,1,-1)`$ 与 $`B=(1,1,1,1,1,1,1,1)`$。步长二的采样算子是 $`y[m]=x[2m]`$，只保留索引 $`0,2,4,6`$。因此两条原本完全不同的信号都得到 $`(1,1,1,1)`$。交替变化的高频模式在低采样率下冒充了常量；信息在采样时已经合并，后面的确定性网络无法仅凭这四个数判断输入究竟是 A 还是 B。

### 5.3 实验三：周期边界、零边界与步长反例

```python
import torch
import torch.nn.functional as F

torch.manual_seed(4)
torch.set_num_threads(1)
x = torch.randn(1, 1, 7, 9, dtype=torch.float64)
k = torch.tensor([[[[1., 2., 0.], [-1., 1., 3.],
                    [2., 0., -2.]]]], dtype=torch.float64)
def circular(z):
    return F.conv2d(F.pad(z, (1, 1, 1, 1), mode='circular'), k)
shift = (1, 2)
a = circular(torch.roll(x, shift, dims=(-2, -1)))
b = torch.roll(circular(x), shift, dims=(-2, -1))
torch.testing.assert_close(a, b, rtol=1e-12, atol=1e-12)
z = F.conv2d(x, k, padding=1)
zero_error = (F.conv2d(torch.roll(x, shift, (-2, -1)), k, padding=1)
              - torch.roll(z, shift, (-2, -1))).abs().max()
assert zero_error > 1e-3
signal = torch.tensor([[[1., -1., 1., -1., 1., -1., 1., -1.]]])
unit = torch.ones(1, 1, 1)
first = F.conv1d(signal, unit, stride=2)
second = F.conv1d(torch.roll(signal, 1, -1), unit, stride=2)
assert torch.equal(first, torch.ones_like(first))
assert torch.equal(second, -torch.ones_like(second))
print('periodic equivalence passed; zero-boundary error:', float(zero_error))
```

第一部分证明周期边界配合周期平移的有限离散版本；第二部分展示零边界不满足同一周期平移命题；第三部分展示步长二对一像素相位敏感。三者使用不同、明确的条件，不能合并成“卷积不具等变”或“卷积始终等变”这样过宽的结论。精确陈述前提，才知道反例究竟反驳了哪一句话。

## 6. 边界条件、池化与逆问题

填充不是免费补充观测。零填充假设图像外取零，复制填充延续边界值，反射填充以镜像方式延拓，循环填充把对边接上。不同延拓对边缘滤波器的响应不同，也可能让网络推断到绝对位置。即使输入内容在各处统计相似，靠近边界的窗口含有人工值，模型也能利用这种差异。

例如常数输入全为一，三点核也全为一。无边界的内部输出为三，零填充时两端输出为二；复制或合适反射下仍为三。若希望讨论常数保持性质，就必须同时规定核系数和延拓方式。边缘响应并非必然是错误，在自然图像中画面边框也可能是有用结构；但若部署裁剪方式改变，训练中利用的边框线索可能失效。

平均池化的边界还涉及是否把填充值计入分母。相同窗口和填充配置，分母是否包含人工零，会改变边缘平均。最大池化的隐含无效位置通常要按负无穷处理，避免在全负输入上让零成为虚假的最大值。调用库时应核对算子文档，而不是把“填充”统一理解为先补零再执行所有操作。

<a id="cnn1-transpose"></a>
### 6.1 转置卷积是伴随映射，不是普遍逆映射

先固定输入输出形状与边界规则，并令偏置为零；此时把卷积的线性部分写成矩阵 $`y=Ax`$，转置卷积对应 $`A^\top`$ 的作用。它把输出梯度沿原连接反向散射并加和，因此自然出现在输入梯度中。只有非常特殊的矩阵才满足 $`A^\top A=I`$；一般不能把转置卷积称为恢复原输入的数学逆。步长采样常把多个不同输入映成同一输出，信息已不足以唯一恢复。

若原层带偏置，完整映射是 $`f(x)=Ax+b`$，属于仿射映射；偏置不参与输入梯度 $`A^\top g`$。检验伴随恒等式时，应比较 $`\langle Ax,z\rangle=\langle x,A^\top z\rangle`$，不能把左侧换成未经中心化的 $`f(x)`$。例如 $`A=\begin{bmatrix}1&2&0\\0&1&2\end{bmatrix}`$、$`x=(1,2,3)^\top`$、$`z=(3,4)^\top`$ 时，两侧都为 47；若再加 $`b=(1,1)^\top`$，则 $`\langle Ax+b,z\rangle=54`$，差额正是 $`\langle b,z\rangle=7`$。转置卷积层自带的偏置是另一个独立参数，验证上述关系时也要关闭。参见 [PyTorch ConvTranspose2d 的线性梯度与参数定义](https://docs.pytorch.org/docs/2.10/generated/torch.nn.ConvTranspose2d.html)。

一维转置卷积常见输出长度为

```math
\begin{aligned}
&(L_{in}-1)s-2p+d(k-1)\\
&\quad +output\_padding+1
\end{aligned}
```

其中 output padding 用于选择输出形状的一种可能歧义，并不是给输出边缘增加可学习内容。原卷积的向下取整可能让不同输入长度产生同样输出长度，反向操作需要明确目标形状。

图像生成或分割中的上采样还可以用插值后卷积。插值先按固定规则增加采样，再用卷积融合；转置卷积则用可学习核散射。二者的重叠分布与边界行为不同。讨论棋盘状伪影时，应检查核跨度与步长导致的覆盖不均匀，也要检查训练目标和数据；不能见到伪影就仅凭算子名称判断唯一原因。

#### 图解：覆盖均匀为何仍不足以消除棋盘纹

![三个相位周期块分别展示覆盖不匀、均匀覆盖和覆盖均匀但权重不同](images/01-checkerboard-patterns-from-coverage-and-phase-gain.webp)

[打开原图放大](images/01-checkerboard-patterns-from-coverage-and-phase-gain.webp)

**先用常数输入把空间结构单独显露出来。** 固定单输入、单输出通道，输入是 $`3\times3`$ 的全一矩阵，步幅二、无填充、无偏置、膨胀率一。三幅图的二维核都取可分离形式 $`K=vv^\top`$，并统一显示输出零基索引第 $`2,3`$ 行、列构成的一个完整内部相位块。左图 $`v=(1,1,1)`$，中图 $`v=(1,1,1,1)`$，右图 $`v=(1,2,1,2)`$。前两种的核元素全为一，因此输出值直接等于覆盖次数；第三种输出是加权贡献，不能再把数值十六解释成十六个输入位置覆盖。

**从一维散射求出二维数表。** 若输入 $`x=(1,1,1)`$，一维转置卷积是 $`y_n=\sum_{i=0}^{2}x_i v_{n-2i}`$，其中核索引越界时令该项为零。左图一维输出为 $`(1,1,2,1,2,1,1)`$，内部四项为 $`(2,1,2,1)`$；中图一维输出为 $`(1,1,2,2,2,2,1,1)`$，内部四项全为二。由于二维输入和核均可分离，二维响应等于相应一维响应的外积。因此左图出现一、二、四交错，中图内部全为四。覆盖不均不是颜色可视化造成的错觉，而是散射索引逐项加和的结果；二维还把两个轴上的差异相乘。

**整除条件解决了计数，没有约束所有权重。** 步幅为二时，离边界足够远的偶数输出位置读取核的偶数偏移，奇数输出位置读取奇数偏移。对常数输入，相位增益分别是
```math
\begin{aligned}
&g_0=\sum_{j:\,j\equiv0\pmod2}v_j,\\
&\quad g_1=\sum_{j:\,j\equiv1\pmod2}v_j.
\end{aligned}
```
核长度四确实让两个相位各收到两项，但右图中 $`g_0=1+1=2`$、$`g_1=2+2=4`$，二者仍不相等。一维输出内部为 $`(2,4,2,4)`$，二维外积就出现四、八、十六交错。由此可见，“核长是步幅的整数倍”在当前膨胀与边界约定下可以均衡内部项数，却不是所有可学习核都保持常数输出的充分条件。多输入通道时，要继续检查各输入通道到输出通道的相位总和；偶然的通道抵消也不等于结构性保证。

**如何用这张图设计最小诊断。** 在学习之前，把模块输入设成常数，分别检查内部和边缘响应；再按输出坐标模步幅分组，比较每组平均值。若初始化就出现相位差，先追踪核的相位和与连接次数；若常数响应均匀、真实输入仍出现纹理，还要检查频率响应、层间组合、目标函数与数据。共享常数偏置只给所有位置增加同一个数，不能消除相位之间原本的差值。不要通过对每幅输出单独归一化色阶，把幅值变化或棋盘差异隐藏掉；图中逐格标出实际值，可以直接比较幅度。

**插值再卷积改变了什么。** 最近邻放大保持常数输入为常数，之后普通步幅一卷积在完整窗口的内部输出为常数乘核权重总和；这种构造对常数响应施加了不同的权重共享约束。边界填充仍可能产生差异，复杂网络中的伪影也可能来自其他机制，因此不能从本例推导“插值后卷积永远无伪影”。[Odena、Dumoulin 与 Olah 的原文](https://distill.pub/2016/deconv-checkerboard/)同时讨论了覆盖不均和均匀覆盖下仍可能学到的伪影；图中的三个相位块均由上述散射定义计算。

<a id="cnn1-unfold"></a>
### 6.2 展开矩阵解释卷积与内存的关系

把每个窗口展平成列，所有列组成矩阵 $`U`$；把每个输出核展平成行，得到矩阵 $`W`$，于是卷积核心计算是 $`WU`$，再恢复空间形状。这个表示帮助理解为什么卷积能借助矩阵乘法实现，也帮助计算梯度：核梯度汇总所有位置的局部输入，而输入梯度需要把重叠窗口的贡献加回原坐标。

展开矩阵会重复保存重叠像素。三平方步长一卷积在内部使每个像素进入约九个窗口，若显式物化全部展开结果，临时内存可能明显大于原输入。实际库可以采用不同算法避免或分块处理这种展开，不能根据数学等价式断言一定保存完整矩阵。计算公式是实现可能性的解释，不是对所有后端的内存轨迹描述。

梯度共享也有直观意义。同一核参数在所有位置被复用，损失对它的梯度是各位置贡献之和。若训练数据主要包含一种背景，许多位置的小梯度可以合成很强的更新，网络未必自动聚焦人类关注的前景。局部共享降低参数数，却不会保证学到“正确语义”；任务数据和损失仍决定哪些模式被奖励。

<a id="cnn1-research"></a>
## 7. 从算子性质走向可检验的研究问题

可以研究“降采样前平滑是否改善小平移稳定性”。先固定一个合成或真实开发集，定义整数平移范围、共同有效区域和任务标签是否保持。比较相同骨干中直接步长卷积与平滑后下采样，记录未变换准确率、平移后准确率、特征差异、参数、乘加与实际延迟。若平滑改变有效核跨度或边界，应写入设计而不是称其他条件完全相同。

评价稳定性时，归一化分母可能影响结论。例如直接使用特征差值范数，缩小所有激活就能降低数值，却未必保持有用信息。可以同时报告相对特征差异、任务预测变化与原始性能，避免单指标被退化解满足。若使用概率差异，还要考虑置信度整体变平也会降低变化，故不能只看一个鲁棒性分数。

也可以研究“扩大理论感受野是否提高长程依赖任务”。构造局部纹理完全相同、标签由两个远距离标记关系决定的数据，把距离作为控制变量。先证明小感受野模型在给定头部下确实无法同时读取相关位置，再比较扩大核、膨胀和注意力等方案。若分类头把所有位置直接连接，模型可能已经获得全局关系，原来的局部感受野限制就不再适用。必须分析整个网络而非仅骨干。

对实际图像，错误集中于边缘或小目标时，应同时检查预处理、裁剪、分辨率、采样中心与标签质量。结构更复杂不等于证据更强。一个能明确区分边界效应与内容变化的对照，比堆叠许多模块后取得单次高分更有解释力。最后给出适用条件和失败案例，允许研究结论是有限而有用的。

<a id="cnn1-adjoint-proof"></a>
### 7.1 反向传播中的伴随关系怎样逐项成立

令一维有效互相关为 $`y_u=\sum_i k_i x_{us+i d}`$，上游梯度为 $`q_u=\frac{\partial L}{\partial y_u}`$。对核系数求导得到 $`\frac{\partial L}{\partial k_i}=\sum_u q_u x_{us+i d}`$，它把每个使用位置的证据汇总。对输入位置 $`t`$ 求导，则需遍历满足 $`t=us+i d`$ 的所有索引对：$`\frac{\partial L}{\partial x_t}=\sum_{u,i:us+id=t}q_u k_i`$。这个受约束求和就是沿连接散射再相加。

若一个输入被两个相邻窗口读取，反向时应收到两份贡献而非任选其一。手写反向最常见的错误是用赋值覆盖前一份梯度。把卷积写成矩阵后，前向为 $`Ax`$，反向为 $`A^\top q`$，正好把“读取同一个输入的多个输出”变成对应列的累加。这个解释不需要诉诸图像语义，是线性代数层面的准确事实。

还可用内积关系检查伴随实现：对任意兼容向量 $`x,q`$，应有 $`\langle Ax,q\rangle=\langle x,A^\top q\rangle`$。注意这里检查的是固定参数与给定边界下的线性算子；有偏置时，需先移除常数项或只讨论线性部分。训练中的非线性层还要乘以局部雅可比，不能用一个全局固定矩阵代替整个网络。区分线性层伴随与整个网络反向传播，有助避免把转置卷积神秘化。

<a id="cnn1-complete-cases"></a>
### 7.2 共享、局部与全连接的同规模比较

假设输入为单通道八乘八，输出为两个通道六乘六。普通三乘三共享卷积含十八个权重和两个偏置，共二十个参数。若每个输出位置都单独学习自己的三乘三核，则有七十二个输出标量，每个九个权重和一个偏置，共七百二十个参数。若全连接到同样七十二个输出，则每个读取六十四个输入，共四千六百八十个参数。三者输出形状相同，连接图与参数自由度却逐级扩大。

共享模型要求某个局部模式在不同位置受到同一种线性处理，局部非共享模型仍限制依赖范围但允许位置特殊性，全连接则取消局部限制。扩大参数族可以降低某些数据上的近似误差，也会增加有限数据下的估计困难。不能从“模型更灵活”直接推出测试表现更优；如果真实规则确实共享，额外自由度反而可能学习到不稳定的位置偏差。

一个可检验的任务是把同一小图案放到训练时未见过的位置。共享卷积能在局部算子层面复用已学核，但最终分类头若采用位置专属权重，整个模型仍可能在新位置失败。若改为全局聚合，又可能丢失位置作为标签所需的信息。因此不能把骨干的共享性质视为系统泛化保证，必须连同头部和数据划分考察。结构先验既可能帮忙，也可能与目标冲突。

<a id="cnn1-boundary-rf"></a>
### 7.3 边缘位置真正观察了多少像素

以长度五输入、三点核、左右填充一为例，中间三个输出读取三个真实像素，两个边缘输出只读取两个真实像素和一个填充值。若再叠同样卷积，第一输出的理论跨度五，但某些路径经过前一层边缘的填充位置，真实输入贡献与无限网格上不同。简单把理论跨度与输入长度取最小值，不能还原每个真实像素的系数或路径数。

沿计算图逐层追踪有效输入集合，可以区分“理论包围区间”“实际连接到的真实像素集合”和“当前参数下的非零贡献集合”。这三个集合通常从大到小，但线性系数抵消会使最后一个更小。研究边界效应时，应明确自己测量哪个集合；只显示一个感受野矩形会隐藏孔洞、填充和权重退化。

反射填充还会让同一个真实像素在窗口中出现多次，真实观测数与求和项数不一致。例如边缘延拓的一个像素可能通过镜像在左右两个位置被读取。于是重复系数会合并，对输入梯度也产生多条累加路径。这解释了为什么相同核在不同填充方式下，即使输出尺寸相同，边缘梯度和统计分布仍会改变。

<a id="cnn1-memory-analysis"></a>
### 7.4 训练内存怎样做可复核的估算

设某中间特征批量八、通道六十四、空间五十六平方，元素数为一百六十万五千六百三十二。单精度保存一份约六百四十二万字节。若网络有许多同等规模激活，反向所需的保存量可能远大于几百万个权重本身。加宽通道和保留高分辨率都增加这部分成本，但增加方式不同，故不能只比较最终输出的尺寸。

准确峰值还取决于哪些张量在同一时刻存活。顺序前向中，某层输入可能因反向需要而保留；分支结构可能同时保留多个高分辨特征；内存池可能把已经释放的块留作复用。工具报告的保留内存与实际活跃张量内存不是同一概念。若要写实验报告，应说明采用哪一个口径、是否包括优化器和工作区，而不是简单列一个“内存”数字。

重算检查点以额外前向换取少存部分激活，混合精度改变每个元素字节数，梯度累积改变微批量与有效批量的关系。这些都能改变资源，却不完全等价：微批量改变会影响依赖批统计的层，混合精度可能需要数值稳定处理，重算也需保证随机状态正确。资源优化应保留任务与数值验收，不可只以程序不再内存不足为成功标准。

<a id="cnn1-experimental-contract"></a>
### 7.5 如何把算子实验写成可靠的知识证据

实验一的参考循环与库算子采用不同执行方式，但它们仍共享同一索引定义；若定义本身写错，两者可能一起验证错误命题。因此还应手算至少一个输出，并检查参数数与输出尺寸。实验二用路径计数多项式提供第二种推导，实验三使用可直接观察的交替信号给出反例。这种多证据连接比只增加随机种子更能发现概念错误。

数值断言应与数据类型匹配。浮点求和顺序不同会产生微小误差，双精度参考可用较严格容差，但跨设备或低精度不能照搬。对结构性零依赖，可以使用精确索引推理；对实际数值近似，应报告相对和绝对误差。不要为了让测试通过任意放宽容差，也不要把正常舍入差异解释为算子语义不一致。

若未来把本章扩展到真实图像，先保持算子层结论与任务层结论分离。卷积几何正确，只保证实现了所定义的变换；训练能下降，只保证优化对当前数据有效；独立新来源上的表现，才支持一定范围的泛化主张。每一步都需要自己的证据。

对于带非对称填充或多分支的新网络，还应逐轴保存采样起点，并分别检查相加位置是否对应同一原图坐标。若仅尺寸一致而中心偏移，就应先修复几何协议，再比较模型质量。读者完成本章后，应能从一个新配置独立推导形状、连接与成本，并指出哪些真实性能仍需实验，才算掌握了卷积而不只是熟悉术语。

<a id="cnn1-pooling-example"></a>
### 7.6 一个细节消失后无法补救的构造

取一维长度四的两个输入，分别为一、零、一、零与零、一、零、一。用窗口二、步长二的平均池化，两个输入都会变成零点五、零点五。如果标签区分“亮点位于每对的左侧还是右侧”，池化后的任何确定性分类器都面对完全相同的输入，因此至少有一类不能正确区分。这不是后续网络容量不够，而是前处理已经把不同标签合并为同一个表示。

若改为最大池化，两个输入都变成一、一，仍有相同问题。若保留两个采样相位作为不同通道，则可以保存这种差别，但通道与计算成本增加。若标签只是“是否存在亮点”，合并这两种输入却可能完全合理。因此讨论信息损失必须相对于标签；同一个汇总算子对一个任务是有效压缩，对另一个任务是致命瓶颈。

在实际视觉网络中，前层可学习卷积可能先把相位相关模式编码到通道，从而在后续池化后保留标签信息。这不推翻上述构造，因为被池化的表示已改变。分析一条真实网络时应问：信息在哪一层、通过哪些通道保留下来？直接对原像素的下采样反例说明风险，却不足以证明所有带池化网络都无法解决任务。把“存在反例”和“普遍不可能”区分开，是进阶分析的重要习惯。

这个构造也能成为研究实验：固定标签定义，逐步增加目标宽度或随机相位，比较直接池化、先卷积后池化和多相位分支。预先规定训练测试相位的覆盖方式，并记录每相位错误率。若测试引入训练未见相位，测的是这种变化下的泛化；若两边覆盖相同相位，测的是拟合后平均表现。两种结论有不同含义，不应只用一个总体分数概括。

卷积的几何验收可以再加一项独立检查：在输入中只放置一个非零像素，观察它影响哪些输出坐标，再与窗口反向索引的结果比较。分组时只激活一个通道，检查影响是否被限制在对应输出组。这个方法直观检验连接支持，不能替代一般数值一致性，但能迅速定位步长、膨胀或组偏移写错的位置。
