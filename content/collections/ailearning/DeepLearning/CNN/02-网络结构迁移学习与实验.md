## 1. 把视觉网络拆成表示、汇总与任务输出

一个分类网络可以写成 $`f(x)=h_\phi(A(g_\theta(x)))`$。骨干 $`g_\theta`$ 把输入图像转换为空间特征，汇总算子 $`A`$ 把空间组织成任务需要的形式，头部 $`h_\phi`$ 产生预测。三部分的职责不同：骨干决定能保留什么模式，汇总决定保留多少位置信息，头部决定输出对应何种监督。迁移学习首先要明确复用哪一部分，而不是只把最后一层类别数改掉。

早期卷积经常学到边缘、颜色或纹理响应，后续层经非线性组合形成更复杂特征，但这是一种经验概括，不代表每个通道都具有人类可命名语义。一个通道可能混合多种条件，也可能与其他通道共同编码信息。查看单张激活图不能证明某通道“就是眼睛检测器”；需要多样本统计、干预和任务评价共同支持解释。

分类输出通常是每张图一个类别分布，语义分割输出是每个像素一个类别分布，检测还要预测位置与对象数量。相同骨干可用于不同任务，但任务头、匹配方式、损失、空间分辨率和标注协议都可能不同。全局平均后的向量一般不足以恢复原始每像素细节，因此迁移到定位任务时需保留中间空间特征，而非只复用最后分类摘要。

<a id="cnn2-pooling"></a>
### 1.1 全局平均池化的可用性与代价

若特征为 $`Z\in\mathbb R^{B\times C\times H\times W}`$，全局平均给出 $`a_c=(HW)^{-1}\sum_{u,v}Z_{c,u,v}`$。与展平后线性层相比，它把头部输入从 $`CHW`$ 降为 $`C`$，允许一定范围的输入空间变化。对十六通道八乘八特征接十类线性头，展平头含一万零二百五十参数，全局平均头仅一百七十。这个节省来自丢弃显式位置自由度。

若类别由“某种纹理是否出现”决定，全局汇总可能合适；若类别由“同一标记出现在左还是右”决定，过强汇总可能抹掉目标信息。卷积骨干有时可以把位置通过边界或坐标编码进通道，但不能指望它必然成功。选择汇总方式应从标签定义出发，而不是把适应不同尺寸当作唯一标准。

平均还会使小目标响应被大量背景位置稀释。可以考虑更合适的空间权重、保留高分辨分支、区域汇总或任务特定头，但每种方法改变归纳偏置与成本。最大汇总偏好单个强响应，平均偏好总体证据，注意力汇总可学习权重但增加估计难度。没有一种头部能够在不付出代价的情况下适合所有空间任务。

<a id="sec-2"></a>
## 2. 形状正确、数值正确与任务有效的三级验收

形状实验回答接口能否接起来：输入通道是否正确，步长是否导致空间消失，展平长度是否符合线性层。数值实验进一步检查输出和梯度有限、轴含义正确、冻结策略得到预期效果。任务实验才检查网络是否能从输入学习标签，并在独立样本上表现。三层证据不能互相替代，一次虚拟前向成功不表示模型已经具有分类能力。

在正式训练前可以用极小集过拟合检查闭环。若一个有足够容量的网络连几十个确定标签的样本都无法拟合，应检查标签类型、损失输入、梯度、学习率、模式和预处理。极小集拟合成功只是排除部分实现错误，不证明泛化。随机标签也能被大网络记住，因此训练准确率高本身不是模型学到可迁移规律的证据。

<a id="sec-2-1"></a>
### 2.1 展平不能修复轴语义

设两个批次样本，各有三通道四乘四图像。正确展平保持批量轴，得到二乘四十八。若先把整个张量改成三乘三十二，元素总数仍相同，却混合了样本与通道；有些后续层仍能执行，但标签对应关系已破坏。检查必须包括样本轴不被混合，以及每个输出确实对应原始那张图。

图像读取常得到高宽通道布局，而卷积通常期待通道高宽。明确排列轴后再转浮点和归一化，不能用 reshape 代替排列。对彩色输入还要核对颜色顺序与量程。一个网络可以对错误的颜色顺序返回有限数值，因而数值有限也不足以证明输入协议正确；应以有已知像素值的小图手算预处理结果。

<a id="cnn2-exp1"></a>
### 2.2 实验一：逐层形状与分辨率变化

```python
import torch
from torch import nn

torch.manual_seed(11)
torch.set_num_threads(1)
model = nn.Sequential(
    nn.Conv2d(3, 8, 3, padding=1), nn.ReLU(),
    nn.MaxPool2d(2), nn.Conv2d(8, 16, 3, stride=2, padding=1),
    nn.ReLU(), nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(16, 3))
x = torch.randn(2, 3, 31, 29)
expected = [(2, 8, 31, 29), (2, 8, 31, 29), (2, 8, 15, 14),
            (2, 16, 8, 7), (2, 16, 8, 7), (2, 16, 1, 1),
            (2, 16), (2, 3)]
y = x
for layer, shape in zip(model, expected):
    y = layer(y)
    assert tuple(y.shape) == shape
assert torch.isfinite(y).all()
assert model(torch.randn(2, 3, 46, 38)).shape == (2, 3)
assert sum(p.numel() for p in model.parameters()) == 1443
print(expected)
```

第二次输入变大仍能前向，来自自适应池化固定头部输入，不意味着两种尺度有相同准确率。尺度变化会改变对象占据的特征位置数、有效局部纹理和平均方式。部署接受可变尺寸时，应另外验证目标大小分组与真实来源，而不能把可执行接口当作尺度不变保证。

<a id="sec-3"></a>
## 3. 迁移学习到底迁移了什么

设源任务分布为 $`P_s(X,Y_s)`$，目标任务为 $`P_t(X,Y_t)`$。迁移可以复用源数据训练出的参数，也可以复用表示、优化初始化或结构经验。源类别与目标类别不必相同，但标签相关信息必须在表示中仍可获得。若源任务奖励忽略目标任务必须保留的细节，迁移可能受限；如果源数据包含广泛纹理与形状，则可能提供有用起点。

从头训练、固定表示训练头、部分微调和全量微调，是不同的适应程度。固定表示令优化只作用在头参数 $`\phi`$；微调则允许 $`\theta`$ 改变。固定表示训练成本较低，能直接检验当前表示是否包含目标任务线性可用信息；全量微调更灵活，但小样本下也更容易过拟合或破坏有用表示。更多可训练参数不是免费收益。

迁移收益需要相对于基线定义。例如相同目标数据和训练更新数下预训练模型更好，说明该完整初始化方案有收益；但源预训练已经消耗额外数据和计算，不能据此说架构在同总预算下更高效。若研究源数据规模、任务相似度或微调范围，应把相应因素单独变化，并报告总资源口径。

<a id="sec-1-1"></a>
### 3.1 输入协议是预训练函数的一部分

预训练权重与输入处理共同定义可复用函数。像素是零到一还是零到二百五十五，三通道顺序如何，是否减均值除标准差，图像如何缩放裁剪，都会改变进入第一层的数值分布。替换预处理后，虽然参数文件相同，实际函数已不同。先复现权重对应的输入约定，才能把后续差异归因到迁移策略。

如果新数据只有灰度，可以复制为三通道，也可以修改首层。复制三通道时，首层等效灰度核是三个颜色核之和；若将核简单求平均，输出会缩小为原复制方案的三分之一，除非同时调整其他尺度。两种策略都可能训练，但不应称为严格等价。若有不同通道归一化，等效推导还包含常数偏移，不能只看核权重。

目标数据动态范围或噪声显著不同时，标准化也可能要重新设计。此时应设一个保持原协议的迁移基线，再与改变协议的方案比较。把所有变化合在一起后取得提升，可以报告完整方案更好，但不能证明收益仅由某一微调层数造成。

<a id="deep-dive-3"></a>
### 3.2 固定表示、部分解冻与全量适应的选择

固定表示适合快速建立目标任务基线，也便于缓存特征，但缓存必须对应固定预处理与确定的骨干状态。若骨干含训练模式的随机层，或者运行统计还在更新，缓存结果取决于执行顺序，已不是固定函数。训练增强若希望每轮变化，提前缓存一种特征也会改变训练分布，需明确比较的是哪种方案。

部分解冻可以从靠近任务输出的块开始，但并非所有领域都应只改高层。若输入成像机制变化很大，例如从自然照片到某种特殊传感器，低层统计也可能不匹配。应该以验证曲线、每组错误与资源为依据，而不是把“低层通用、高层特定”作为无条件定律。全量微调可能需要更小骨干学习率和适当正则，但具体数值仍需在验证集选择。

渐进解冻时，优化器参数组必须包含新解冻参数；仅修改 requires grad 不会自动把遗漏参数加入已有优化器。反过来，冻结后若保留陈旧梯度或优化器状态，也需要理解更新边界。更稳妥的方式是明确重建参数组或验证每组成员，并在阶段切换后检查哪些参数实际发生变化。训练记录要包含阶段和学习率，而不只写最终模型层数。

<a id="sec-4"></a>
## 4. 参数冻结、状态冻结与随机行为必须分开

PyTorch 中 requires grad 控制参数是否追踪梯度；train 与 eval 改变某些模块的行为；no grad 控制当前计算是否记录自动微分图。它们解决不同问题。一个参数不求梯度的骨干仍可在训练模式更新 BatchNorm 缓冲区；一个 eval 模型仍可对参数求梯度；一次 no grad 前向也不自动把模型设为 eval。必须按目标分别配置。

BatchNorm 通常对每个通道跨批量和空间位置估计均值方差，再做仿射变换。训练时使用当前批统计，并更新运行统计；评价时通常使用运行统计。即使仿射参数冻结，运行均值方差仍可能改变。因此严格固定表示需要同时固定参数和相关状态，并决定随机层是否关闭。调用整个 model train 后，之前对子骨干的 eval 设置可能被覆盖，应在每次训练阶段正确恢复。

小批量或源目标差异较大时，保留源运行统计、使用目标统计或替换归一化，各有代价。目标统计可适应新域，也可能因小样本而不稳定；混合不同来源的批次会让统计受到采样比例影响。选择应通过独立验证和部署条件说明，不能把某种经验设定包装成所有迁移任务的标准答案。

<a id="cnn2-bnformula"></a>
### 4.1 均值方差更新及模式改变的数值影响

对一个通道，设当前参与归一化的元素数为 $`m`$，批均值为 $`\mu_B=m^{-1}\sum_i x_i`$，前向方差通常使用 $`m^{-1}\sum_i(x_i-\mu_B)^2`$。输出为 $`\frac{\gamma(x_i-\mu_B)}{\sqrt{\sigma_B^2+\epsilon}}+\beta`$。运行均值按动量更新，PyTorch 的动量约定是新状态等于一减动量乘旧状态加动量乘当前统计，而不是优化器动量的同一含义。

运行方差更新与前向归一化使用的估计口径还可能不同，实际应以具体版本文档为准。最重要的实验问题是：同一张图放在不同训练批次中，其训练模式输出可能改变；在固定评价状态下则不应依赖同批其他图像。这对缓存、跨来源批处理和在线预测尤其关键。仅检查卷积权重未变化，不足以断言函数固定。

BatchNorm 的训练输出还让样本间产生统计耦合。若把多个独立样本的梯度归因解释为完全独立，可能忽略这种耦合。分布式同步统计又扩大统计集合。理解这些边界后，才知道在迁移实验里冻结状态究竟是在控制什么，而不是机械添加一个 eval 调用。

<a id="cnn2-exp2"></a>
### 4.2 实验二：权重没变，函数状态却在变

```python
import torch
from torch import nn

torch.manual_seed(3)
torch.set_num_threads(1)
backbone = nn.Sequential(nn.Conv2d(1, 2, 3, padding=1, bias=False),
                         nn.BatchNorm2d(2), nn.ReLU())
for p in backbone.parameters():
    p.requires_grad_(False)
weights = {n: p.detach().clone() for n, p in backbone.named_parameters()}
bn = backbone[1]
before = bn.running_mean.clone()
x = torch.ones(4, 1, 8, 8) * 5
backbone.train()
with torch.no_grad():
    train_out = backbone(x)
assert not torch.equal(before, bn.running_mean)
assert all(torch.equal(weights[n], p) for n, p in backbone.named_parameters())
backbone.eval()
frozen_mean = bn.running_mean.clone()
with torch.no_grad():
    eval_out = backbone(x)
    backbone(x + 10)
assert torch.equal(frozen_mean, bn.running_mean)
assert not torch.allclose(train_out, eval_out)
head = nn.Linear(2, 2)
features = backbone(x).mean(dim=(-2, -1))
loss = nn.functional.cross_entropy(head(features), torch.tensor([0, 1, 0, 1]))
loss.backward()
assert head.weight.grad is not None
assert all(p.grad is None for p in backbone.parameters())
print('weights frozen, state change and head gradients verified')
```

本实验没有使用预训练权重，它验证的是迁移策略中独立存在的状态机制。先在训练模式观察运行均值变化，再在评价模式确认不变，同时检查头梯度存在而骨干梯度不存在。真实迁移模型还需逐模块审查其他缓冲区与自定义行为，不能根据一个模块的通过结果推断全部状态都固定。


<a id="visual-example-cnn-02"></a>

### 对照表：参数冻结与运行模式是两条独立轴

| 参数求导 | 模块模式 | 可能发生的事 |
| --- | --- | --- |
| 关闭 | train | BatchNorm 统计仍可能更新 |
| 关闭 | eval | 使用已有运行统计 |
| 开启 | eval | 仍可计算参数或输入梯度 |
| 开启 | train | 常规训练但仍需优化器更新 |

**说明。** 冻结权重只关闭指定参数的梯度积累，不必然改变模块运行模式。反过来，eval 改变 Dropout 或 BatchNorm 的行为，却不自动关闭自动微分。迁移实验应同时记录参数集合、模块模式和运行缓冲，才能说明骨干究竟有哪些部分保持不变。

**适用条件。** 这些选项不是四个等价方案；优化器更新、梯度记录开关和子模块混合模式还要按具体实验核验。


<a id="sec-5"></a>
## 5. 增强是对标签与数据分布的假设

设变换为 $`T`$。分类增强常假设 $`y(Tx)=y(x)`$，但这个等式来自任务定义，不由变换名称保证。水平翻转对某些物体类别合理，对文字、方向、左右关系却可能改变标签。裁剪若删掉决定类别的对象，也不再是合法的标签保持变换。颜色扰动若改变疾病或材料判断所需颜色，同样可能损害监督。

检测与分割的几何增强通常不是标签不变，而是标签按相同几何规则变换。图像翻转后，边界框和像素掩码也要翻转；连续图像与离散类别掩码可能需要不同插值规则。若对类别编号使用双线性插值，会生成没有语义的中间编号。增强正确性应先通过构造样本和标注几何验证，再讨论是否提高准确率。

训练增强定义了模型实际优化的分布 $`Q`$，可以写成对原样本和变换随机变量的联合期望。若增强引入部署不会出现的图像，并不必然无效，因为它可能起正则作用；但必须由目标验证支持。反过来，视觉上“自然”的增强也可能删除标签证据。合法性、自然性和训练收益是相关但不同的判断。

<a id="cnn2-split"></a>
### 5.1 按身份、设备和时间划分才能对应目标问题

同一对象的多张照片、同一视频的相邻帧、同一病人的多次检查常高度相关。随机按图片拆分可能让模型在测试中见到训练对象的近重复。若目标是对新对象泛化，应按对象标识分组；若目标是对已有对象未来状态预测，则可能需要时间划分并限制未来信息。划分方式必须由部署问题决定。

分组后类别比例可能不均匀，甚至某类只在一个来源出现，这不是可以随意忽略的小麻烦，而是揭示标签与来源混杂。如果某类别全部来自一台设备，就难以区分类别模式与设备纹理。应增加交叉来源数据、设置明确外部验证或限制结论范围，不能通过重新随机分图片掩盖问题。

所有从数据学习的预处理也遵守训练边界。目标域均值标准差、阈值、特征筛选和类别重加权应基于训练部分确定，再在验证上选择策略。若仅计算完全无标签的部署统计，属于不同的适应设定，应明确允许获取哪些目标数据。把测试输入提前用于适应，会改变所评估问题，不能与完全独立测试混为一谈。

<a id="cnn2-exp3"></a>
### 5.2 实验三：分组与几何增强的双重验收

```python
import torch

torch.manual_seed(19)
# 同一对象的三张图只能进入同一分区。
groups = torch.arange(12).repeat_interleave(3)
labels = (groups % 2).long()
train_ids, val_ids, test_ids = set(range(8)), {8, 9}, {10, 11}
parts = [torch.tensor([int(g) in ids for g in groups])
         for ids in (train_ids, val_ids, test_ids)]
for i in range(3):
    for j in range(i):
        assert not (set(groups[parts[i]].tolist()) & set(groups[parts[j]].tolist()))
assert sum(int(p.sum()) for p in parts) == len(groups)
# 方向分类：右侧亮点为一，水平翻转会把类别变为零。
x = torch.zeros(2, 1, 6, 8)
x[0, 0, 2, 6] = 1
x[1, 0, 3, 1] = 1
def direction(z):
    return (z[..., 4:].sum((-3, -2, -1)) >
            z[..., :4].sum((-3, -2, -1))).long()
y = direction(x)
flipped = x.flip(-1)
assert torch.equal(direction(flipped), 1 - y)
# 对分割标注，同步翻转图像与离散掩码。
mask = (x[:, 0] > 0).long()
assert torch.equal(flipped[:, 0] > 0, mask.flip(-1).bool())
assert set(labels[parts[1]].tolist()) == {0, 1}
print('group split and label transformation verified')
```

实验中方向标签由亮点所在半区定义，因此翻转必须改变分类标签；同一操作在分割任务则要求同步翻转掩码。这个小例子说明不能根据“图像增强库常用此操作”推断标签不变。分组测试只保证已给定标识不交叉，不能发现错误标识或跨对象近重复，真实数据还需审计来源与重复内容。

**图中的机制。** 同一几何旋转可作为合理的不变性假设，也可能改变方向敏感任务的真实标签。图把箭头图像旋转九十度，并分别列出对象类别与朝向类别的标签关系：对象种类可以不变，朝向需要同步更新。数据增强不是纯粹无害的像素扰动。

**条件与边界。** 是否保留标签必须由任务定义与标注协议确定；医学左右侧、数字方向或文字阅读也可能对翻转和旋转敏感。

## 6. 归纳偏置、源目标差异与负迁移

局部共享偏好在空间重复出现的模式，适合许多视觉任务。若任务依赖绝对坐标，例如固定仪表盘某区域的读数，完全共享加全局汇总可能把必要位置抹掉。可以加入坐标通道、位置嵌入或区域头，但这些改变模型可利用的信息。一个模型靠位置取得高分也未必是捷径：位置是否合理，由部署中该关系是否稳定决定。

源目标差异可以发生在输入边缘分布、标签条件关系和标签空间。输入风格变化但相同语义规则可能需要适应低层统计；相同图像在新任务中有不同标签，则需要新的输出映射；源预训练有时把目标所需细节压掉，单独训练线性头无法恢复。诊断应先区分这些情形，而不是把所有低分都归为学习率不合适。

负迁移指在明确定义的目标评价与预算下，使用源知识反而比合适的目标基线更差。需要说明基线获得相近的调参机会，目标数据划分相同，训练预算口径可比较。若从头训练只试一个很差学习率，而迁移方案搜索很多组合，不能把差异纯粹解释为预训练优势；反过来，故意不给微调方案适合的小学习率，也不能公平证明预训练有害。

<a id="sec-6-1"></a>
### 6.1 参数、状态、输入协议的三张清单

参数清单列出哪些层可训练、每组学习率和正则。状态清单列出 BatchNorm 缓冲区、随机层模式、可能的指数滑动平均或自定义计数器。输入清单列出颜色顺序、量程、归一化、裁剪、插值、标签编码。三张清单共同定义一次迁移试验；只保存最终权重不足以完整复现。

如果采用特征缓存，还要记录生成缓存时骨干的参数版本、评价模式和输入变换版本。训练头期间改变任何一项，旧缓存就不再对应当前模型。缓存验证集特征应采用固定验证变换，不应把训练随机增强的结果不加区分地混入。对于大型任务，还需检查缓存样本与标签的排序是否一致，错位不会总是引发形状错误。

保存最优检查点时应复制张量内容，而不是仅保留一个引用到不断更新的状态对象。恢复后用固定样本比较 logits，再计算最终评价。这个检查能发现保存时机、模式和预处理错配。若最终部署转换格式或精度，还应重新进行输出容差和任务指标验收，不能把训练环境通过当作部署环境通过。

<a id="cnn2-objective"></a>
### 6.2 固定表示下的优化问题与可辨别性

固定骨干后，目标训练为 $`\min_\phi n^{-1}\sum_i\ell(h_\phi(z_i),y_i)+\lambda R(\phi)`$，其中 $`z_i=A(g_\theta(x_i))`$。若头为线性分类器，实验测的是现有表示的线性可分性与有限样本估计效果。线性探测低分不证明表示完全没有标签信息，因为非线性头可能利用其中关系；但增加头复杂度也增加数据需求，应明确问题变了。

如果两个不同标签输入被骨干映成完全相同的表示，任何只看该表示的确定性头都无法同时正确分类。这给出比“头太小”更强的不可辨别性判断。可在合成任务中构造这种情形，理解为何全局汇总、源任务压缩或过早下采样会限制迁移。对真实高维数据，无法仅凭可视化重叠宣布严格相同，应使用可复核的数值或理论条件。

微调改变表示，可解除某些限制，但也可能让少数样本主导更新。比较固定、部分和全量适应时，既看目标验证，也看不同来源、类别和对象大小上的变化；总体提升可能掩盖某组显著退化。源任务能力若仍有实际用途，还需独立评估保持情况。目标任务更高分与保留源能力是两个目标，未必自动一致。

<a id="cnn2-balance"></a>
### 6.3 学习率组与阶段切换的完整手算

假设骨干参数当前值二，梯度零点一，头参数当前值一，梯度零点五。无动量无正则的随机梯度下降中，骨干学习率千分之一，头学习率百分之一，更新分别为负万分之一与负千分之五。不同学习率限制每一步相对变化，却不保证最终骨干一定保持接近源表示，因为许多步可以累积，梯度尺度也可能差异很大。

若第一阶段只训练头，第二阶段解冻骨干，应决定是否保留头的优化器动量与学习率调度状态。重建优化器会改变这些状态，继续原优化器则需正确添加骨干参数。两种方案都能合理使用，但必须记录。所谓“只改解冻层数”若同时重置动量、改变调度或批统计，就不是单因素实验。

正则也需要具体说明。对权重使用衰减与对所有参数使用同样惩罚可能不同，归一化仿射项和偏置是否衰减可成为方案差异。小样本结果对这些细节敏感时，应报告敏感性而非只展示最优一个点。最终建议是条件性的：某个目标数据规模、源模型和预算下，某策略较稳健；不能从一次试验推出通用微调配方。

<a id="cnn2-protocol"></a>
## 7. 可复核的迁移实验协议

先定义目标对象：预测新身份、新地点、未来时间还是已有对象的新照片。固定训练、验证、测试分组，确认没有同一原图的增强版本跨分区。然后写基线：随机初始化全量训练、预训练固定骨干、预训练部分解冻、预训练全量微调。若资源有限，可先在开发阶段小规模筛选，但必须给各方案相近的选择机会。

记录源权重来源、源数据是否可能包含目标样本、输入协议和分类头初始化。若无法确认源数据是否重叠，应限制结论为此来源权重的实际效果，不把结果直接解释为完全未见数据上的纯泛化。源数据规模很大也不意味着一定有泄漏，但其不确定性不能被架构比较忽略。

训练预算至少区分目标阶段更新数、处理图像次数、实际时间和源预训练成本。固定轮数时不同批量改变更新数；固定更新数时不同批量改变处理样本次数；固定时间时不同结构完成的工作不同。先声明要回答哪个问题，再选择匹配方式。不存在一个“所有成本同时相同”的简单配置。

模型选择只使用验证集。可以预先规定以验证损失为主、准确率作补充，或按具体代价选择阈值。多次搜索会适应验证集，因此最终测试应留到方案冻结后使用。若使用多个随机种子，报告均值与离散程度，并尽量配对种子与数据划分，减少数据差异掩盖结构差异。

<a id="cnn2-errors"></a>
### 7.1 从错误模式推导下一步实验

若固定表示训练头训练分数与验证都很低，可能是表示缺少目标信息、头能力不足、预处理错误或优化失败。先核对输入与极小集，再比较更灵活头或部分微调。若训练高而验证低，优先检查独立样本数量、来源差异、增强与正则，而不是简单加层。若某来源全部失败，应检查设备、颜色、标注和采样，而非把总体低分当成均匀问题。

可构造背景替换或遮挡实验来寻找捷径线索，但干预可能把图像推到不自然区域。预测变化说明模型对该干预敏感，不直接证明自然数据中的因果依赖。应与自然新来源、来源分层和目标区域标注结合。错误分析必须服务于可检验假设，而不是挑几张符合叙事的图片。

误差表包含每组支持数、错误数和必要不确定范围。小组零错误不意味着错误概率为零；一个仅有三样本的完美组不能与几千样本组等量看待。若同一对象有多张图，统计重复时应按对象重采样或说明独立单位，避免把相关图片当成大量独立证据。

<a id="sec-7"></a>
## 8. 十六道进阶练习与逐步解析

本节围绕表示、状态与协议做综合推理。每题作答时先说明目标任务和允许改变的条件，再给技术结论。只写“冻结”“加数据”“调学习率”不算完整答案，因为相同操作在不同信息与预算条件下可能有相反效果。

<a id="cnn2-q1"></a>
### 8.1 题一：线性头的参数与信息代价

**题目。** 三十二通道十四乘十四特征用于五类分类。展平头与全局平均头各多少参数？能否由参数少直接判断泛化更好？

**解析。** 展平长度六千二百七十二，线性头参数为三万一千三百六十五；平均后长度三十二，参数为一百六十五。后者减少位置自由度和估计需求，但也可能删除标签依赖的位置。若标签是目标出现方向，平均可能形成瓶颈；若标签与位置无关，则共享与汇总可能有利。需要根据任务规则和独立评价判断，不存在由参数数字直接推出测试排序的定理。

<a id="cnn2-q2"></a>
### 8.2 题二：冻结参数为什么还会漂移

**题目。** 骨干所有参数均不求梯度，但训练几轮后缓存特征不同，原因有哪些？

**解析。** 先检查 BatchNorm 运行统计是否仍更新，再检查 Dropout 等随机层是否开启，输入增强是否随机，以及是否加载不同参数版本。参数梯度关闭只控制参数求导，不控制缓冲区和随机行为。严格固定特征应固定参数、模式、输入变换和随机性，并用同一固定样本比较输出。若目标恰是适应目标统计，则漂移可能是预期行为，但要把缓存失效规则写清楚。

<a id="cnn2-q3"></a>
### 8.3 题三：eval 是否阻止训练

**题目。** 模型处于评价模式，却调用反向传播和优化器更新，参数会变吗？

**解析。** 只要参数求梯度、计算记录图且损失依赖这些参数，就会产生梯度并可更新。评价模式只改变特定模块的前向行为，不是全局停止学习开关。因此迁移中可以让骨干归一化保持评价行为，同时训练某些参数；这是一种明确策略。若希望彻底固定骨干，还要关闭相应参数梯度并控制优化器成员，不能只调用 eval。

<a id="cnn2-q4"></a>
### 8.4 题四：新解冻层为何没有变化

**题目。** 第二阶段把骨干参数改为可求梯度，检查发现有梯度但权重不变，可能缺哪一步？

**解析。** 原优化器若只接收头参数，不会自动发现新解冻参数。需正确增加参数组或重建优化器，并确认学习率非零、梯度未在更新前被清除、没有随后恢复旧状态。应比较一步前后的实际参数变化，而非只看可训练参数计数。重建时还需说明是否重置头动量与调度状态，否则阶段切换同时改变了多个因素。

<a id="cnn2-q5"></a>
### 8.5 题五：灰度复制与首层修改

**题目。** 原首层对三通道输入使用核 $`K_R,K_G,K_B`$，灰度值复制三份。改成单通道时如何严格匹配原线性输出？

**解析。** 在没有通道特异预处理时，新核取三者之和，偏置保留，便得到同一求和。取平均会使线性部分缩小三倍。若每通道先做不同减均值除标准差，新等效核和偏置还需按这些系数重新推导，边界填充与归一化先后也可能影响常数项。先写完整输入函数，再做代数合并，不能仅根据通道数选择平均。

<a id="cnn2-q6"></a>
### 8.6 题六：身份泄漏改变了什么问题

**题目。** 同一患者多张图随机分到训练测试，用于声称新患者泛化，哪里不成立？

**解析。** 测试图虽未逐像素见过，患者身份、设备条件和稳定背景可能已在训练出现。它更接近已见患者的新图评价。若目标是新患者，应按患者分组，再根据部署考虑医院和时间。分组后样本量与类别比例变化应报告，而不是退回图片随机划分以得到更高分。评价正确性首先来自问题匹配，不来自分数好看。

<a id="cnn2-q7"></a>
### 8.7 题七：翻转何时改变标签

**题目。** 标签区分左转与右转箭头，能否对图像水平翻转而保留类别？若是目标检测呢？

**解析。** 箭头方向会反转，分类标签也应交换，否则训练引入矛盾监督。检测若类别仅为“箭头”，类别可能保持，但框坐标需按图宽映射；若类别还含方向，也要交换。分割掩码需同步几何变换且保持离散编号。一个变换可能对某个标签字段不变，对另一个字段等变，必须逐字段定义。

<a id="cnn2-q8"></a>
### 8.8 题八：固定表示低分能否宣布无信息

**题目。** 线性探测只有随机水平，全量微调却很好，能否说源表示完全无用？

**解析。** 线性头只能利用线性可分信息，低分还可能来自优化和样本量。源参数也可能提供良好优化起点，而不是现成可线性读取的目标特征。应比较合理非线性头、训练稳定性及从头基线，并在相同协议下解释。若已证明不同标签映成完全相同表示，才可对固定表示给出更强不可能结论；一般低分不等于这种证明。

<a id="cnn2-q9"></a>
### 8.9 题九：更多源数据意味着公平吗

**题目。** 一个预训练模型用海量源图，另一个从头只用目标图；目标阶段更新数相同，能否称同总预算架构比较？

**解析。** 不能。目标适应预算相同，源数据与计算不同。结果可回答“在这些可用权重条件下哪个方案更好”，不能单独解释为架构在同总资源下更优。若研究架构，需要控制或系统改变源数据和预训练条件。也可同时报告源阶段与目标阶段成本，让读者按实际资源条件选择，而不强行抹平已经不同的设定。

<a id="cnn2-q10"></a>
### 8.10 题十：验证归一化何时泄漏

**题目。** 训练前用所有图片计算目标均值标准差，然后划分训练测试，问题是什么？

**解析。** 预处理已使用测试分布信息，完全独立测试的设定被改变。若部署允许无标签目标域适应，可研究该协议，但要把可用信息范围写清楚并与无适应基线区分。常规独立评价应只在训练部分估计统计量，再固定应用。这里不需要测试标签也可能改变结论，说明泄漏不只来自直接读取测试标签。

<a id="cnn2-q11"></a>
### 8.11 题十一：骨干小学习率保证不遗忘吗

**题目。** 骨干学习率比头小一百倍，是否保证源能力保留？

**解析。** 不保证。梯度尺度、更新步数、优化器状态和目标冲突都会影响累计变化；少数关键参数小变化也可能显著改变源输出。应独立评价源任务或所需旧能力，并视需求采用约束或多目标策略。若项目只关心目标任务，源遗忘未必构成问题；若系统需同时支持两者，就要显式列入选择指标，不能用学习率比例代替验收。

<a id="cnn2-q12"></a>
### 8.12 题十二：把骨干设为 eval 后又调用 train

**题目。** 每轮先骨干 eval，然后整个模型 train，是否保持骨干评价行为？

**解析。** 通常整个模型 train 会递归设置子模块训练模式，覆盖刚才设置。应先设置整体训练，再按策略把骨干或特定归一化层切回评价，或封装明确的模式管理。每轮检查相关模块标志与缓冲区变化，比仅检查代码中出现过 eval 更可靠。尤其框架回调可能再次切换模式，实际行为应通过一步状态对比确认。

<a id="cnn2-q13"></a>
### 8.13 题十三：增强收益能否归于解冻策略

**题目。** 全量微调比固定骨干高三点，但同时用了更强增强和两倍训练，如何解释？

**解析。** 只能说完整方案在该协议下高三点。需增加同增强同预算的固定骨干，以及相同训练条件下的全量微调，才能更接近隔离适应范围的作用。还应给各方案合理学习率选择机会，否则所谓单因素可能包含调参不公平。资源有限时可以诚实保留完整方案比较，不必勉强宣称已证明某个机制。

<a id="cnn2-q14"></a>
### 8.14 题十四：单来源失败如何调查

**题目。** 总体准确率不错，但某设备来源几乎全错，应先做什么？

**解析。** 核对颜色顺序、量程、分辨率、标签编码和设备预处理，再检查源数据中该来源覆盖及类别混杂。分来源列支持数与混淆矩阵，必要时使用新来源验证。若只给网络加宽，可能更好记住其他来源，却不修复协议错误。只有排除数据和输入问题后，结构适应实验才有清晰含义。

<a id="sec-7-1"></a>
### 8.15 题十五：效果差是否必须全量微调

**题目。** 固定骨干目标效果差，给出有顺序的诊断，而不是立即增加训练层数。

**解析。** 先确认标签、输入协议和模式正确，再用小样本闭环检查头优化，随后比较线性与适度非线性头，分析来源和对象大小错误。若表示限制证据充分，再测试部分解冻与全量适应，并记录预算和过拟合。全量微调是候选方案，不是对所有故障的通用修复；若输入颜色颠倒，先修复协议可能比增加参数更新更有效。

<a id="cnn2-q16"></a>
### 8.16 题十六：缓存特征的公平比较

**题目。** 固定骨干方案缓存一次图像特征，全量微调每轮随机裁剪，比较结果包含什么差异？

**解析。** 除了可训练参数范围，还包含增强多样性和骨干计算成本。缓存方案可以缓存多个明确变换或在线重算固定骨干特征，以研究增强因素；也可以保留低成本缓存作为现实方案，但如实报告。不要把速度优势全部归于冻结本身，也不要把准确率差异全部归于可训练层数。设计应对应要回答的资源与机制问题。

<a id="cnn2-advanced"></a>
## 9. 进阶研究：把迁移收益拆成可识别因素

一个有价值的研究问题是“目标标签数量减少时，源表示的优势来自现成可分性，还是更容易优化”。可以固定源权重与目标分组，选择多个训练标注规模，比较固定线性头、固定非线性头、微调和从头训练。每个规模从同一对象层面采样，避免不同方案恰好拿到不同难度数据。报告学习曲线而不是仅报告一个数据量。

如果线性探测在少量标注下很强，说明已有表示能以简单头读出目标信息；如果只有微调强，可能涉及表示适应与优化优势；如果从头训练在充足数据后追平，源优势可能主要体现样本效率。这些是基于对照的解释方向，不是仅凭曲线就能唯一识别的因果结论，因为优化器、正则和选择预算也会影响差异。

还可以固定数据和预训练，系统比较源统计冻结、目标统计更新与其他归一化策略。记录每个批次的来源混合比例，检查评价输出是否依赖批处理组织。若目标域在线适应允许更新统计，要明确什么时候开始、是否可看到未来样本以及状态是否跨测试对象保留。不同顺序产生不同结果时，应把顺序敏感性作为算法性质报告，而不是只选最优顺序。

最终交付包括训练划分规则、输入协议、参数与状态清单、选择日志、独立评价及局限。迁移学习的核心并非神奇复用一个权重文件，而是在明确源知识、目标信息和资源约束后选择合适的适应自由度。读者应能解释某次提升究竟在什么条件下成立，也能设计一个反例说明这种优势何时可能消失。

<a id="cnn2-input-affine"></a>
### 9.1 输入标准化改变函数的完整代数分析

考虑单个输入通道，预处理为 $`z=\frac{(x-\mu)}{\sigma}`$，首层内部某位置的线性输出为 $`\sum_i w_i z_i+b`$。将其展开，等于 $`\sum_i(\frac{w_i}{\sigma})x_i+b-(\frac{\mu}{\sigma})\sum_iw_i`$。因此在窗口全部来自真实像素时，标准化可以代数合并到核与偏置。多通道情形对每个通道分别缩放，再把各通道常数项加到偏置即可。

但边界会使简单合并失效。若先对真实图像标准化，再由卷积补零，边界外的值是标准化空间的零，相当于原始空间的均值。若先在原始空间补零再标准化，边界外变为负均值除标准差。两种完整函数不同，不能只依据内部位置的代数等价就宣称全图等价。复现预处理时，必须包括填充发生在何处。

类似地，灰度复制后的三个通道若各自标准化，等效单通道核是三组颜色核分别除以对应标准差后的和，偏置还吸收三个均值项。若部署为了速度折叠归一化，应使用固定样本逐位置核对，包括边缘与非正方形输入。这样才能发现只在内部像素成立的近似被错误推广到整个张量。

<a id="cnn2-targetshift"></a>
### 9.2 类别先验变化与输入变化的区别

设模型在源数据学到类别后验，但部署中类别比例改变。即使每类图像的成像分布保持不变，后验也可能变化，因为贝叶斯公式同时依赖类别先验。一个源域概率零点九的输出，不自动意味着在新先验下仍有相同可信度。迁移不仅关心特征是否好用，还关心概率、阈值与实际决策成本是否适合目标环境。

如果只在目标数据重训分类头，头可以部分适应新类别与先验；若类别样本过采样，则训练后验对应采样后的分布，直接把它当部署概率可能失准。可在独立验证上检查校准与阈值，并明确验证分布是否代表部署。类别重加权用于优化某种代价，不应同时声称输出天然是未经调整的真实概率。

对于同一标签空间，若严格假设 $`p_t(x\mid y)=p_s(x\mid y)`$，并且目标中可能出现的类在源分布中也有正先验，则可以把先验偏移写成可计算修正。设源后验为 $`\eta_s(y\mid x)`$，源、目标先验分别为 $`\pi_s(y),\pi_t(y)`$。由贝叶斯公式先把类条件密度写成 $`p_s(x\mid y)=\frac{\eta_s(y\mid x)p_s(x)}{\pi_s(y)}`$，再代入目标后验，公共 $`p_s(x)`$ 在归一化中消去，得到

$$
\eta_t(y\mid x)=
\frac{\frac{\eta_s(y\mid x)\,\pi_t(y)}{\pi_s(y)}}
{\sum_k\frac{\eta_s(k\mid x)\,\pi_t(k)}{\pi_s(k)}}.
$$

如果源 logits 确实表示源后验，只需逐类加上 $`\log\pi_t(y)-\log\pi_s(y)`$ 后重新 softmax；这是类别相关的偏移，一般不是一个统一温度所能替代。二分类例子中，源正类先验为二分之一，模型在某图像上给正类概率 $`0.9`$。若目标正类先验降到 $`0.1`$，类条件输入分布保持不变，则正类未归一质量为 $`0.9\times\frac{0.1}{0.5}=0.18`$，负类也为 $`0.1\times\frac{0.9}{0.5}=0.18`$，目标后验恰为 $`0.5`$。源域的“九成把握”在新总体中并不矛盾地变成五成。

这个推导不提供未知目标先验的免费答案，也不能把经验上校准不好的源输出变成精确概率。目标先验的估计需要额外假设或合法目标数据；稀有类逆先验权重还可能放大估计误差。若用独立目标标签重新校准，数据的角色与样本成本应计入方案。理论修正、先验估计和最终阈值选择是三件需要分别验收的事。

更复杂的情况是条件关系也变化，例如某背景在源数据与类别高度相关，在目标域关联消失。单纯调整类别先验不能修复表示依赖错误背景。此时需要新来源数据、合适增强或表示适应。先区分先验变化、条件输入变化与标签规则变化，才能选择有针对性的实验，而不是把所有域差异都交给一个温度参数或一个更大学习率。

<a id="cnn2-freeze-optimizer"></a>
### 9.3 冻结策略与优化器状态的细致边界

训练一步通常包括清梯度、前向、损失、反向和更新。冻结参数时，应检查旧梯度是否仍保留，优化器是否会处理这些参数，以及参数是否被其他机制更新。常见优化器会跳过梯度为无的参数，但若旧梯度张量仍存在，即使为零，也可能与权重衰减或动量状态共同造成变化。为了可复核，冻结阶段应显式清除无用梯度并验证实际参数不变。

另一种情形是把骨干前向放入无梯度上下文，却仍希望优化输入或前置可训练模块。这样会切断经骨干传回输入的梯度，即使骨干参数本来就不需要更新。若任务是训练一个位于冻结骨干之前的适配器，应保留通过骨干对输入的计算图，同时冻结骨干参数。参数不训练与计算不求导不是同一件事，这在提示、适配器和图像优化任务中尤其重要。

若采用指数滑动平均模型做评价，保存和加载时还要说明使用原始训练权重还是平均权重。两者参数不同，归一化状态也可能有不同处理。报告“同一检查点”却混合不同权重版本，会使重现出现不必要差异。迁移策略的状态空间比一组 requires grad 标志更丰富，完整清单是控制这些差异最直接的方法。

<a id="cnn2-small-data"></a>
### 9.4 小数据实验中的不确定性不能靠重复图片消除

假设每个对象拍摄一百张近似照片，训练共有十个对象。按图片计数似乎有一千样本，但对新对象泛化的独立单位仍主要是十个对象。增加同对象近重复图可能改善对已见外观的估计，却不能等价替代增加新对象。误差条若把一千图都当独立，会显著夸大精度。

比较两种微调策略时，最好在相同对象划分上配对，观察每个划分的差值，而非只比较两个不相关均值。若重复次数很少，应报告实际各次结果和范围，不必用复杂统计包装成确定排名。测试集很小时，一两个对象的差异可能改变结论，诚实说明不确定性比给出过多小数更有信息。

模型选择次数也消耗信息。试验几十种增强、学习率与解冻范围后，即使每次都只看验证，最优验证分也会受到选择偏差。最终测试用于估计冻结后的完整选择流程，而不是继续筛选。若资源允许，可使用嵌套选择或多个开发分组；若不允许，就限制结论并完整报告搜索范围。小数据研究的可信度往往首先来自信息边界，而非更复杂结构。

<a id="cnn2-task-mismatch"></a>
### 9.5 分类预训练迁移到密集任务的结构清单

从分类骨干迁移到分割，需要确定输出步幅、多尺度特征位置和解码器。若骨干最后只剩很粗网格，小对象与边界可能在上采样前已经丢失。可以使用中间层跳连或降低某些下采样，再用膨胀保持较大覆盖，但这会改变特征统计与计算，不能假定原分类权重在新结构中表现完全相同。

标签和损失也有新问题。分割的像素类别包含忽略区域、类别不平衡与图像尺寸变化；填充区域不能被当作真实背景参与所有指标。检测还要定义候选、匹配、框参数与后处理。复用骨干只减少一部分表示学习负担，不会自动解决任务输出协议。研究时应把骨干迁移收益与解码器、数据增强和评价实现分开核验。

一个实用验证是使用可手工标注的合成小图，检查网络输出空间与掩码对应，增强后几何一致，忽略区域不进入损失，插值不会混合类别编号。这个任务级验收与源模型加载成功同样重要。若只验证最后张量形状，可能漏掉整体偏移一个像素、框坐标尺度不一致或边界填充被误计的错误。

<a id="cnn2-stopping"></a>
### 9.6 迁移方案的停止条件与可交付结果

一次开发循环应有明确结束条件：预先定义的方案集合完成，验证选择固定，关键数据与状态检查通过，再进行最终评价。若每次看到测试错例就新增增强或解冻策略，测试集将逐渐变为开发集。此时后续可以继续研究，但需要承认评价范围已改变，并为最终主张准备新的独立数据。

结果应同时说明收益、成本和限制。例如固定骨干在少量对象下更稳、全量微调在更多标注下更高、某新设备仍失败，这比只给一个最高分更有实际意义。保存的最终成果包括可加载权重、完整预处理、标签映射与状态策略；学习材料中的实验则通过内存和断言展示机制，不需要留下临时模型文件。可复核并不等于必须产生大量中间文件，而是关键条件足够清楚。

读者可以用三个问题检验掌握程度：源表示保留了目标需要什么，当前哪些量会随训练改变，以及评价是否真正模拟部署对象。能逐一回答，才有依据选择固定、部分或全量适应。若答案仍不清楚，增加训练时长往往只是把不确定机制运行更久，不能替代诊断。

<a id="cnn2-invariance-counter"></a>
### 9.7 位置标签与纹理标签为什么需要不同迁移策略

构造两类合成数据：第一种标签是图案属于圆还是方，图案可在任意位置出现；第二种图案始终一样，标签只表示它在左半区还是右半区。对第一种任务，空间共享与适当全局汇总匹配标签不变性；对第二种任务，如果骨干严格等变且汇总严格平移不变，那么同一图案平移后的表示会相同，头部无法区分标签。这给出一种结构与任务冲突的明确例子。

真实有限卷积有边界，可能通过边缘推断位置，所以不能未经分析就声称任何全局平均 CNN 都不可能做第二题。可以使用周期边界、限制共同有效区域，或明确加入位置编码来区分理论模型与实现。若模型靠边界完成任务，换一种裁剪或输入尺寸后表现可能改变，这也成为需要评价的部署条件。

迁移时，源任务若训练了对位置不敏感的表示，目标需要位置关系，则只训练线性头可能不足；但源特征也可能保留空间图，换一个保留位置的头即可。先检查可用中间表示，再决定是否必须改变骨干。这比把迁移失败直接归于源任务差异更具体，也能降低不必要的全量训练成本。

<a id="cnn2-transform-severity"></a>
### 9.8 增强强度的选择需要看失效曲线

增强不是简单的开关。裁剪比例、颜色扰动幅度与模糊程度都定义强度，过弱可能没有效果，过强则破坏标签证据。可以预先选几个有解释的强度，展示验证性能、目标可见比例和不同子组错误。若总体提升主要来自大目标，而小目标因裁剪退化，选择时应结合实际代价，而不是只保留总体最优值。

增强顺序也影响结果。先裁剪再调整大小，与先缩放再裁剪可能产生不同目标尺度；归一化前后添加同样数值噪声代表不同原始像素扰动。记录完整流水线，才能重现实验。在材料中用构造样本核验标签与几何，是进入强度搜索之前的必要步骤；标签已错误的增强即使偶然提升单次验证，也不能据此合理化错误监督。


比较模型时还应保留失败配置的记录。若某策略只有非常窄的学习率范围有效，而另一策略在较宽范围稳定，最高分接近也不表示使用成本相同。报告搜索范围与稳定区间，能让学习者理解方法对资源和经验的实际要求，避免把偶然找到的一次成功当成容易复现的默认结果。


固定表示也需要核对标签映射。源任务类别编号与目标任务编号通常不同，替换头后应保存目标名称到编号的明确顺序。若训练和评价分别从文件夹重新排序，名称排序规则不同可能让所有输出含义错位，张量形状与损失仍合法。用每类一个已知样本检查标签与输出名称，并在恢复模型后再次核验，可排除这种与结构无关却影响巨大的一致性错误。
