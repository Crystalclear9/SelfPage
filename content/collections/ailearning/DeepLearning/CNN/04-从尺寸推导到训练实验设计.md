## 1. 从可回答的问题开始，而不是先选大型网络

本章完整任务是区分带噪声小图中的水平短条与垂直短条。它足够简单，可以手工理解标签和增强，也足够包含视觉实验的重要环节：对象分组、局部形状、随机位置、输入噪声、下采样、训练选择和错误分析。这里不试图用小任务代表自然图像难度，而是把真实项目常被隐藏的协议全部显式写出。

我们需要回答三个问题：实现是否按预期学习，独立对象上的表现怎样，结构改动的证据能支持多强结论。第一个问题由形状、有限值、梯度与训练下降验证；第二个由分组验证与最终测试回答；第三个需要控制变量、重复和成本统计。把这三个问题混在一个准确率里，就容易把接口成功误当泛化，或把额外预算误当结构优势。

定义标签时要具体。水平条和垂直条方向不同，平移不改变类别，九十度旋转则交换类别。水平翻转与垂直翻转都保留这两种无箭头条纹的方向类型，但任意裁剪可能删掉条纹或只保留方形局部，造成标签歧义。增强是否合理，必须从这样的生成规则推导，而非根据常见教程照搬。

### 1.1 一份最小但完整的实验约定

样本单位是单张十六平方灰度图，独立对象单位是一个生成标识。每个对象有同一方向和大致位置的多个带噪观测，因此同对象图像不能跨训练验证测试。训练对象用于参数更新，验证对象用于选择学习率和检查点，测试对象仅在方案冻结后评价一次。图像生成器、标签映射和分组规则都固定在代码中。

输入为零附近带噪浮点值加正亮条纹，不使用外部标准化统计，也不下载任何数据或权重。网络由两层卷积和分类头构成，损失为交叉熵，输入是原始 logits。优化器只使用训练数据梯度。每个候选从同样初始化种子开始，训练更新数相同；选择依据验证交叉熵，准确率作补充。这样每一个结果都能对应明确的数据与选择条件。

最终输出包括选定学习率、训练和验证指标、测试准确率及混淆矩阵。模型状态保存在内存复制中，并通过重新加载的固定输入输出核对，无需写入图片或检查点文件。真实项目可能需要持久化模型与数据版本，但本章为了展示机制，不把临时文件当作必要成果。

## 2. 先手算形状、参数与感受野

使用单通道十六平方输入，第一层三平方核、填充一、步长一、八通道，输出八乘十六乘十六，参数八十。接二平方最大池化、步长二，输出八乘八乘八。第二层三平方、填充一、步长一、十六通道，输出十六乘八乘八，参数一千一百六十八。全局平均后得到十六维，二分类线性头三十四参数，总计一千二百八十二。

第一层卷积乘加为十六平方乘八乘九，即一万八千四百三十二；第二层为八平方乘十六乘八乘九，即七万三千七百二十八；头为三十二。单样本主要前向乘加九万二千一百九十二。没有把池化比较、激活、偏置、反向和优化器包含在这一数字里，因此应叫主要乘加估计，而不是完整训练浮点运算量。

理论感受野从一开始，第一卷积为三，池化为四且跳距二，第二卷积为八，跳距仍二。全局平均汇总所有第二层位置，因此最终输出依赖全图。这里的“单位置感受野八”和“整图分类输出依赖全图”并不矛盾。若要研究远距离关系，需要进一步分析汇总前是否发生必要交互，而不是只说分类头看到了所有位置。

<a id="cnn4-detail-4"></a>

### 2.1 形状表如何连接到资源与标签

条纹长七、宽三，经过一次池化后仍可能在多个位置留下方向响应。若过早连续下采样到很小网格，方向细节可能混合。增加后层宽度不能保证恢复已丢失的区分信息。相反，完全不下采样保留更多细节，却增加第二层计算和激活。设计应把目标像素大小与特征步幅放在同一表里思考。

全局平均头减少位置自由度，符合本任务平移不改变标签的假设；若改成左右方向标签，它可能需要重新设计。小任务的网络不是通用模板，而是根据任务规则选择的合理起点。一个结构在该任务成功，仅说明它足以学习这个规则，不证明它适合细粒度定位或真实复杂图像。

### 图解：全局平均池化：每个通道归约成一个数

![按通道分别将空间总和除以四，再用线性分类头得到两个分数](images/04-global-average-pools-each-channel-before-the-classification-head.webp)

[打开原图放大](images/04-global-average-pools-each-channel-before-the-classification-head.webp)

**读图说明：** 图中每行对应一个 2 × 2 通道。按通道平均得到 $`(4,4,2)`$：第一通道总和 16，第二通道总和也是 16，第三通道总和 8；每个总和各自除以四个空间位置。通道之间没有相互求平均，实际网络即使有 64 个通道，仍是每个通道输出一个数。

接着补齐分类头的计算：指定无偏置权重 $`W=\begin{bmatrix}1&-1&1\\-1&1&0\end{bmatrix}`$，把三个均值视为列向量，就得到 $`W(4,4,2)^\top=(2,0)^\top`$。这两个数是 logits；若需要概率，还需做 softmax，得到约 $`(0.881,0.119)`$。均值相等的两个通道仍是不同的坐标，分类头可以分别取正权重和负权重，不能因为它们都等于四就先把通道合并。这里的头权重用于算例，独立于本章实际训练的十六通道、二类头。

**将同一个线性头移到空间位置上。** 对这一个线性头，也可以先在每个位置按同一权重混合通道，再取空间平均。第一类的空间分数图为

```math
\begin{aligned}
&M_1=Z_1-Z_2+Z_3=
\begin{bmatrix}-1&5\\-1&5\end{bmatrix},\\
&\quad \frac14\sum_{u,v}(M_1)_{u,v}=2;
\end{aligned}
```

第二类为 $`M_2=-Z_1+Z_2=\begin{bmatrix}1&-1\\1&-1\end{bmatrix}`$，空间平均为零。两条路径得到同样的 logits，因为有限求和与线性通道混合可以交换。这使“汇总后的分类分数”能追溯到当前特征图的逐位置贡献；第一类的正负贡献在平均时都被保留，不能只显示正区域后继续声称总和不变。

这一步限定固定线性头、空间共享权重以及当前特征值；图中的贡献不是已经识别出的真实物体，也不是对原始像素的因果归因。若头部还含非线性或位置相关操作，不能直接交换计算顺序。本算例将池化与头部的机制展开；上方十六通道网络仍以原代码定义为准，不把这里人为指定的特征替换为训练实测结果。

再独立地把第一通道的空间位置旋转 180 度，排列从 $`[[1,3],[5,7]]`$ 变为 $`[[7,5],[3,1]]`$，均值仍为 4。这给出了一个无法由池化结果恢复位置的具体反例：每个通道内的任意置换都保持其均值，而展平会保留位置顺序。这里讨论的是输入给池化层的特征图；不能据此断言整个 CNN 对原始图像任意旋转或置换都不变，因为前面的卷积一般会改变响应。有关全局平均池化如何替代展平分类头，可继续阅读 [《动手学深度学习》的 NiN 章节](https://d2l.ai/chapter_convolutional-modern/nin.html)。

### 2.2 实验一：用断言核验每层与参数账本

```python
import torch
from torch import nn

torch.manual_seed(2)
torch.set_num_threads(1)
layers = nn.ModuleList([
    nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(8, 16, 3, padding=1), nn.ReLU(),
    nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(16, 2)])
expected = [(3, 8, 16, 16), (3, 8, 16, 16), (3, 8, 8, 8),
            (3, 16, 8, 8), (3, 16, 8, 8), (3, 16, 1, 1),
            (3, 16), (3, 2)]
x = torch.randn(3, 1, 16, 16)
for layer, shape in zip(layers, expected):
    x = layer(x)
    assert tuple(x.shape) == shape
assert sum(p.numel() for p in layers.parameters()) == 1282
assert 16 * 16 * 8 * 9 + 8 * 8 * 16 * 8 * 9 + 16 * 2 == 92192
assert torch.isfinite(x).all()
print('shape table and 1282 parameters verified')
```

本实验不训练。它证明代码配置符合形状与参数推导，并检查前向有限。若交换高宽恰好仍为十六，形状不一定发现错误，因此真实流程还需检查轴语义与像素值。若将来修改网络，应先重新推导再运行，而不是保留旧参数数字作为注释。

## 3. 控制变量要服务于具体比较问题

如果想研究池化是否损失方向细节，可以比较有无池化，并记录后层激活、乘加和性能。无池化版本后层处理更大空间，成本改变；这可以是机制实验的一部分，但不能称同计算预算。若进一步缩小通道来匹配乘加，又同时改变宽度，应将两种比较分别报告，而不是混成一个含糊“公平对照”。

若想研究较大模型是否在给定时间更好，可以允许不同宽度与步数，但固定时间预算和选择规则。这个问题与相同更新数下结构差异不同。相同参数、相同主要乘加、相同训练图像数和相同时间并不等价；一份可信报告首先说明采用哪一种，而不是试图用“其他一样”掩盖实际差异。

<a id="cnn4-detail-7"></a>

### 3.1 宽度改动传播到哪些地方

第一层从八通道加宽到十六，当前层参数从八十变一百六十，输出激活翻倍；若第二层仍输出十六，它的输入通道翻倍，参数从一千一百六十八变二千三百二十，主要乘加也翻倍。分类头参数不变，因为最终通道仍十六。总变化要沿整个网络传播，不能只统计被修改那一层。

若第一、第二层输出都翻倍，中间主要通道乘积可变四倍，头输入也翻倍。若最后使用展平头，高分辨率变化还会改变头参数。所谓“只改一个超参数”只表示代码改动一个数，不代表统计容量与计算只改一个因素。理解这种联动，是设计结构消融时最基础的成本意识。

<a id="sec-2-1"></a>
<a id="cnn4-detail-8"></a>

### 3.2 候选选择预算也必须记录

假设基线只试一个学习率，新模型试二十个并挑验证最高者，比较包含额外选择机会。即使训练数据相同，研究者也向新模型投入更多开发信息。可以给相近搜索范围，或直接报告各自搜索成本和选择流程。若目的是实际最佳方案，可以允许不同搜索，但结论应关于整个开发方案，而非孤立结构。

同样，查看测试错误后调整增强，相当于使用测试进行开发。此后可以继续研究，但原测试已不再独立，需要新评价或限制结论。学习材料中的实验也应保留这一边界：验证可以引导改进，测试用来验收已经固定的流程。把角色写在代码变量和文字中，比仅口头说“没有泄漏”更可靠。

### 3.3 从假设到可反驳的证据链

一个完整假设可写成：“在固定对象划分和训练预算下，延后一次下采样能改善三像素宽条纹的方向识别，同时增加计算。”对照只改变该步骤，记录不同条纹宽度的验证表现。若所有宽度都同样改善，可能还涉及容量或优化；若仅细条纹改善，更符合信息保留解释。应允许结果反驳最初动机。

若模型已经近乎完美，增加结构可能没有可测收益。此时应提高任务难度的某个明确维度，例如噪声、遮挡或新位置范围，而不是为了证明模块有效任意改变很多生成条件。新难度应在开发数据定义，再重新固定评价。一个能说明现有任务不足以区分方案的结论，也比人为制造最高分有价值。

## 4. 数据生成、分组与标签合法性

同一对象多个观测共享方向与中心，噪声独立。对象标识承担分组角色，而不是作为输入特征。训练对象与测试对象编号不同，且位置生成不直接依赖类别编号的固定模式，尽量避免标签通过位置泄露。真实数据还需审查文件名、水印、边框、设备与采集时间，这些都可能让模型绕过目标形状。

合成任务容易获得精确标签，但也容易包含生成器捷径。若水平条总放在上方，模型只需位置；若两类背景亮度不同，只需均值。应检查每类的中心、宽度、噪声和背景分布，保证它们不是意外标签线索。即使匹配了这些边缘统计，仍不能宣称完全消除一切捷径，只能说明已控制明确因素。

### 4.1 实验二：标签变换与分组审计

```python
import torch

torch.set_num_threads(1)
images = torch.zeros(2, 1, 9, 9)
images[0, 0, 3:6, 1:8] = 1  # 水平
images[1, 0, 1:8, 3:6] = 1  # 垂直
labels = torch.tensor([0, 1])
def orientation(z):
    grid = torch.arange(z.shape[-1], dtype=z.dtype)
    mass = z.sum((-2, -1)).clamp_min(1)
    mx = (z * grid[None, None, None, :]).sum((-2, -1)) / mass
    my = (z * grid[None, None, :, None]).sum((-2, -1)) / mass
    vx = (z * (grid[None, None, None, :] - mx[..., None, None]) ** 2).sum((-2, -1))
    vy = (z * (grid[None, None, :, None] - my[..., None, None]) ** 2).sum((-2, -1))
    return (vy > vx).long().flatten()
assert torch.equal(orientation(images), labels)
assert torch.equal(orientation(images.flip(-1)), labels)
rotated = torch.rot90(images, 1, (-2, -1))
assert torch.equal(orientation(rotated), 1 - labels)
groups = torch.arange(20).repeat_interleave(4)
train, val, test = [set(range(12)), set(range(12, 16)), set(range(16, 20))]
assert train.isdisjoint(val) and train.isdisjoint(test) and val.isdisjoint(test)
assert len(train | val | test) == len(torch.unique(groups))
print('direction labels and independent groups verified')
```

方差比较是本构造中可手算的几何验收，不用于训练标签推断。水平条横向跨度大，旋转后两轴互换，因此标签交换。真实数据可能有遮挡或非均匀亮度，不能直接把这个公式作为通用方向检测器。它的作用是先证明增强规则与任务定义一致。

<a id="cnn4-detail-12"></a>

### 4.2 裁剪、缩放与方向标签的共同约束

几何增强不仅改变像素，也改变目标可见部分。把七乘三的水平条裁成三乘三方块后，方向已经不可辨认，保留原标签会制造矛盾监督。若随机裁剪允许这种情形，应重新定义标签、限制裁剪或跳过无法判断的样本，而不能依赖网络从不存在的信息中恢复答案。增强越强不意味着资料越丰富，可能只是增加错误标签。

缩放还需要规定插值。连续图像可用平滑插值，离散分割标签若使用同样线性插值，类别编号会变成没有意义的小数；检测框则要同步变换坐标并处理被裁掉部分。分类本章只验证水平垂直标签，但这一思维可推广：先明确变换后的对象与标注各是什么，再实现像素操作。对颜色、模糊和噪声也要检查是否破坏任务证据。

<a id="cnn4-detail-13"></a>

### 4.3 数据单位与有效独立样本

一个对象拍摄一百张相近图，并不等于一百个独立对象。若训练和测试共享对象背景或位置，评价可能主要衡量对已见对象的再次识别。本章按对象标识划分，模拟新对象；若业务只需同对象后续观测，可采用另一种时间协议，但必须说清目标。没有普遍唯一的划分，只有与部署问题一致或不一致的划分。

评价不确定性也应尊重分组。把同对象的观测当作独立试验，会低估波动。可在对象层面汇总错误或按对象重采样；若来源层面还有设备和采集批次，可能需要更高层分组。学习实验样本少，报告支持数比一个看似精确的小数更诚实。不能通过复制图像让置信区间看起来更窄。

## 5. 一段完整、可独立运行的视觉训练实验

下面代码完整包含生成、分组审计、模型、候选训练、验证选择、最佳状态深复制、最终测试及加载核对。图像为十六乘十六灰度，每对象两次观测，共六十四对象；训练四十、验证十二、测试十二。方向按对象交替取值，中心位置由独立随机抽样决定，噪声独立。固定种子保证这次演示可重复，但不代表单种子足以做方法排名。

两个候选学习率使用相同模型初始化，分别训练一百二十个全批更新，每十步在验证对象评价。最佳状态按验证交叉熵选择，测试在全部候选固定后才使用。训练增强只做水平翻转，它对无箭头水平垂直条均保持标签；不使用九十度旋转，也不进行可能裁掉证据的随机裁剪。模型无 Dropout 与 BatchNorm，减少模式差异便于核验。

<a id="cnn4-detail-15"></a>

### 5.1 实验三：生成到最终测试的完整闭环

```python
import copy
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1)
generator = torch.Generator().manual_seed(2026)
images, labels, objects = [], [], []
for group in range(64):
    label = group % 2
    cy = int(torch.randint(4, 12, (), generator=generator))
    cx = int(torch.randint(4, 12, (), generator=generator))
    for observation in range(2):
        image = .1*torch.randn(1, 16, 16, generator=generator)
        if label == 0:
            image[0, cy-1:cy+2, cx-3:cx+4] += 1
        else:
            image[0, cy-3:cy+4, cx-1:cx+2] += 1
        images.append(image)
        labels.append(label)
        objects.append(group)
x = torch.stack(images)
y = torch.tensor(labels)
g = torch.tensor(objects)
train_mask, val_mask, test_mask = g < 40, (g >= 40) & (g < 52), g >= 52
masks = (train_mask, val_mask, test_mask)
sets = [set(g[m].tolist()) for m in masks]
assert all(sets[i].isdisjoint(sets[j]) for i in range(3) for j in range(i+1, 3))
assert [int(m.sum()) for m in masks] == [80, 24, 24]
assert torch.isfinite(x).all() and set(y.tolist()) == {0, 1}

def make_model():
    return nn.Sequential(nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(),
        nn.MaxPool2d(2), nn.Conv2d(8, 16, 3, padding=1), nn.ReLU(),
        nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(16, 2))

candidates = []
for lr in (.01, .03):
    torch.manual_seed(42)
    model = make_model()
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    assert sum(p.numel() for p in model.parameters()) == 1282
    with torch.no_grad():
        initial = F.cross_entropy(model(x[train_mask]), y[train_mask]).item()
    best_value, best_state, best_step = float('inf'), None, None
    for step in range(1, 121):
        model.train()
        optimizer.zero_grad(set_to_none=True)
        batch = x[train_mask]
        if step % 2:
            batch = batch.flip(-1)
        logits = model(batch)
        loss = F.cross_entropy(logits, y[train_mask])
        assert torch.isfinite(loss)
        loss.backward()
        assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in model.parameters())
        optimizer.step()
        if step % 10 == 0:
            model.eval()
            with torch.no_grad():
                value = F.cross_entropy(model(x[val_mask]), y[val_mask]).item()
            if value < best_value:
                best_value = value
                best_state = copy.deepcopy(model.state_dict())
                best_step = step
    assert best_state is not None
    candidates.append((best_value, lr, best_step, initial, best_state))
selected = min(candidates, key=lambda row: row[0])
val_ce, lr, step, initial, state = selected
model = make_model()
model.load_state_dict(state)
model.eval()
with torch.no_grad():
    train_ce = F.cross_entropy(model(x[train_mask]), y[train_mask]).item()
    test_logits = model(x[test_mask])
    prediction = test_logits.argmax(dim=1)
    confusion = torch.bincount(2*y[test_mask]+prediction, minlength=4).reshape(2, 2)
    accuracy = (prediction == y[test_mask]).float().mean().item()
assert train_ce < initial/5 and val_ce < .1
assert accuracy >= .9 and confusion.sum().item() == 24
restored = make_model()
restored.load_state_dict(copy.deepcopy(state))
restored.eval()
with torch.no_grad():
    assert torch.equal(restored(x[test_mask]), test_logits)
print('selected', lr, 'step', step, 'train_ce', train_ce, 'val_ce', val_ce)
print('test accuracy', accuracy, 'confusion', confusion.tolist())
```

### 5.2 如何解读成功而不越界

断言通过说明固定合成规则下，网络能从训练对象学习方向，并在独立生成对象上达到给定标准；同时保存加载没有改变固定输入输出。它不表示已经复现自然图像论文，也不表示真实方向识别问题都容易。生成器只包含有限噪声、位置和形状变化，真实图像有遮挡、纹理、成像和标签歧义，需要新的资料与协议。

测试准确率断言在这里用于固定教学样例回归。如果不断改变模型直到这二十四张测试都通过，测试已经参与开发；真实研究应避免这种循环，把预先固定的验收和探索过程区分。读者若改变生成分布，应重新分出开发与测试，不能以原有断言作为所有新任务理所当然的最低成绩。

候选中的状态只保留权重和必要模块缓冲，用于最终推理；若要严格恢复训练，还需保存优化器、随机源与步数等信息。本章重新加载核对针对预测等价，不能声称实现了完整续跑等价。内存深复制保证最佳状态不会随之后更新漂移，这个细节比仅记录“最好在第几步”更重要。

## 6. 错误分析从支持数与任务条件开始

混淆矩阵的行表示真实类别、列表示预测类别。矩阵告诉我们哪些方向混淆，却没有解释为什么。应按对象位置、噪声、条纹宽度、边界距离和来源分组，给出每组样本数、对象数及错误数；支持极少的组需要保留不确定性，不能把一次错误解释成稳定规律。总体完美也不代表每种未测试条件都可靠。

本章若基准测试零错误，可另外定义开发压力集，逐项增加噪声、遮挡或减小条纹宽度，研究失效曲线。压力集的目的与最终测试不同：它帮助提出下一轮假设，不能把其中挑选出来的最佳条件再包装成独立评价。对真实数据，可记录自然出现的模糊、曝光和背景差异，避免只做不现实的像素破坏。

<a id="cnn4-detail-18"></a>

### 6.1 从现象到竞争解释

若靠近边界的条纹错误多，可能是可见信息被裁掉，也可能是零填充造成统计改变，或训练位置覆盖不足。可以保持完整条纹，改变与边界的距离；也可以只改变填充方式，再比较共同有效区域。若噪声组错误多，可能是信噪比下降，也可能是输入尺度超出训练范围，需要分开控制。

若一类错误明显较多，先查类别数量、标注与采样，再查模型偏好。条纹水平垂直在正方形网格上具有对称关系，但随机有限样本、池化相位和初始化都可能打破经验对称；不能从理论上两类可旋转对应，就要求每次有限实验误差完全一样。对称性提供对照思路，而不是对单次随机结果的逐位预测。

<a id="cnn4-detail-19"></a>

### 6.2 遮挡和背景替换的证据边界

遮挡目标后预测变化，可以支持模型使用该区域，但遮挡本身也可能引入分布外边缘；背景替换后错误增多，也可能因为合成不自然，而不只是模型依赖背景捷径。应配合自然来源变化、多个干预方法和标签检查。干预实验能提供因果线索，不能凭一张热力图或一个遮挡结果断言完整机制。

对于本任务，可以构造相同条纹配多种独立噪声背景，或保持背景而旋转条纹，同时按规则交换标签。如果模型主要根据背景平均亮度分类，这些对照可能暴露问题。真实视觉任务的有效干预更困难，需要领域知识判断变换是否保留语义，不能机械照搬合成图规则。

### 图解：混淆计数比总准确率更能定位失败

![两张矩阵的类条件错误率相同，类比例改变后预测 A 的精确率下降](images/04-confusion-counts-explain-precision-after-prevalence-shift.webp)

[打开原图放大](images/04-confusion-counts-explain-precision-after-prevalence-shift.webp)

**读图与计算。** 这个独立算例有二十个样本，正确十四个，总准确率为百分之七十。但 A 类召回率为百分之八十，B 类只有百分之六十。逐类计数展示了总分隐藏的差异；在真实实验中还应按尺寸、遮挡或数据来源继续切片，记录每组支持数。

**适用条件。** 图中计数用于说明评价机制，不是本章训练程序的实测结果。小切片分数可能非常不稳定，应结合区间和错误样本判断。

**同样召回率，并不固定预测 A 的可信比例。** 左侧混淆矩阵的行是真实类别，列是预测类别。A 类召回率为 $`\frac8{10}=0.8`$，把 B 误报为 A 的比例为 $`\frac4{10}=0.4`$；预测为 A 的十二个样本中八个正确，因此 A 类精确率为 $`\frac8{12}=\frac23`$。精确率和召回率的分母分别来自预测列与真实行，不能交换。

现在只改变总体中 A 的比例 $`\pi`$，假设分类器和阈值固定、两类条件输入分布均保持不变。每单位总体中真正例与假正例的期望比例分别为 $`0.8\pi`$ 和 $`0.4(1-\pi)`$，于是

```math
\mathrm{Precision}_A(\pi)
=\frac{0.8\pi}{0.8\pi+0.4(1-\pi)}.
```

当 A 占一半时，精确率是 $`\frac23`$；当 A 只占十分之一时，精确率降为 $`\frac2{11}`$。右侧一百个单位的矩阵显示期望计数：十个 A 中八个检出、两个漏检；九十个 B 中三十六个误报、五十四个正确。A 召回仍为百分之八十，但预测 A 的四十四个单位中只有八个真正是 A。这里是新总体的期望计数，不是额外运行训练程序得到的观测结果。定义可对照 [Google 机器学习课程的精确率与召回率](https://developers.google.com/machine-learning/crash-course/classification/accuracy-precision-recall)。

**检验与边界。** 在新总体里，全猜 B 的准确率为百分之九十，却完全漏掉 A；图中分类器的准确率为百分之六十二，却检出八成 A。应选择什么模型，取决于漏检、误报的实际代价，而不是单独比较其中一个总分。若两类条件分布也变了，原来的两个条件错误率未必保持不变，必须在新数据上重新测量，不能直接套用这条曲线。

## 7. 尺寸合法之后，还要检查采样与坐标

卷积输出尺寸为 $`\lfloor\frac{(n+2p-d(k-1)-1)}{s}+1\rfloor`$，只回答合法采样位置有多少。一个输出位置对应的输入中心、跳距与覆盖范围也需要记录。两个分支输出同样宽高，中心可能偏半个像素或一个像素；把它们相加会将不同位置语义混合。多尺度融合和分割解码尤其容易出现这种合法但错误的对齐。

理论感受野递推可用 $`j_l=j_{l-1}s_l`$、$`r_l=r_{l-1}+(k_l-1)d_lj_{l-1}`$。起始中心还要考虑左侧填充与有效核跨度。以像素中心为半整数的约定计算时，每层中心偏移可写为 $`[\frac{(k_l-1)d_l}{2}-p_l]j_{l-1}`$，非对称填充应分别处理。公式的坐标原点必须统一，不能一部分采用像素索引、一部分采用几何边界。

<a id="cnn4-detail-21"></a>

### 7.1 小目标与不可逆瓶颈

若两个不同输入经过某次下采样完全相同，后续任何确定网络都不能再区分它们。增加宽度、训练时间或上采样都无法从相同中间表示恢复原本区别。这个结论是函数复合的基本事实：相同输入到后续函数必然得到相同输出。它比“下采样可能损失细节”更强，但前提是确实构造出相同表示。

本章三像素宽条纹在一次池化后仍通常可辨，但如果把方向信息压到一个均值或过小网格，可能产生这种瓶颈。应使用具体反例检验，而不是只根据感受野大就认为一定能看到目标。感受野描述潜在覆盖，分辨率描述保留位置数量，两者可以一大一小；覆盖到某个像素不意味着其信息被无损保留。

<a id="cnn4-detail-22"></a>

### 7.2 混叠与平移测试的正确比较

步长下采样会选择特定相位。输入平移一个像素后，采样位置可能改变，特征不再仅是整格平移；平移恰好为总步幅整数倍时，等变性质在适当边界条件下才可能对应。先平滑可降低高频混叠，却也可能削弱真正依赖高频的标签证据。抗混叠不是无损恢复，也不能替代任务验证。

评价平移稳定性时，应明确边界、插值和比较区域。零填充会改变移入移出区域，循环平移则把边缘内容绕回，两者不是同一种现实变换。对共同有效区域比较能隔离部分边界因素，但不能代表完整部署误差。报告应把理论等变、有限图像边界和实际鲁棒性分开，不因某个结构名称含卷积就推断对所有平移不变。

<a id="cnn4-detail-23"></a>

### 7.3 感受野与有效贡献的实验方案

把网络设为确定状态，对某个输出位置求输入梯度，可以观察当前激活下的局部支持和贡献大小。理论感受野给出可能依赖范围，梯度只反映这次输入和参数的局部变化，零梯度不一定表示结构上永远没有路径。ReLU 掩码、最大池化选择和权重抵消都会让有效支持缩小。

可以先用全一线性核建立路径计数的可手算基线，再逐项加入激活、池化与随机权重，对比变化。不要把梯度热图直接解释成唯一因果解释；它对微小扰动敏感性有意义，但大遮挡和自然概念变化是另一类干预。机制实验与真实错误分析应互补，避免一个漂亮图代替全部证据。

![两种分辨率的单位置梯度不同，全部位置的梯度之和均为一](images/04-average-pooling-spreads-the-same-upstream-gradient-over-more-sites.webp)

[打开原图放大](images/04-average-pooling-spreads-the-same-upstream-gradient-over-more-sites.webp)

**从分配到汇总，不能跳过共享路径。** 图中把上游导数固定为一：$`2\times2`$ 时四个位置各接收 $`\frac14`$，$`4\times4`$ 时十六个位置各接收 $`\frac1{16}`$；位置数乘四与单位置导数除四同时发生，所以各位置导数之和仍为一。这里的边长 $`H`$ 取正整数。再设一个共享参数的对照：令所有输入位置都是同一个可训练标量 $`\theta`$，则均值 $`y=\theta`$，每条位置路径虽变小，总参数导数 $`\frac{\partial y}{\partial\theta}=\sum_{ij}\frac1{H^2}=1`$ 不随分辨率改变。这正说明不能从单位置导数缩小直接推断整网参数梯度缩小四倍；真实共享权重还要乘各条输入导数再汇总。

```math
y=\frac{1}{H^2}\sum_{i=1}^H\sum_{j=1}^H x_{ij},\qquad \frac{\partial y}{\partial x_{ij}}=\frac{1}{H^2}.
```

<a id="cnn4-detail-24"></a>

## 8. 资源比较：参数、算量、内存与时间分别记账

参数量决定一部分存储与优化器状态，但不直接决定推理延迟。相同卷积核在更大图像上重复使用，参数不变而位置数增加。输入高宽各翻倍，主要空间激活与卷积乘加常约四倍；若有展平全连接头，参数也可能随空间变化。全局平均头则避免这一头部参数增长，但它施加了不同汇总约束。

激活内存取决于批大小、空间、通道、精度和反向保存策略。训练还包含梯度、优化器历史和临时工作区；简单把参数字节数乘某个固定常数，不能精确预测峰值。CPU 实验也不能证明 GPU 显存或吞吐。需要报告实际环境和测量范围，把估计成本与实测成本区分清楚。

<a id="cnn4-detail-25"></a>

### 8.1 本网络的逐层内存下界估计

以单精度三十二条十六平方输入为例，第一层输出有 $`32\times8\times16\times16`$ 个元素，字节数约二百六十二千；池化输出约六十五千；第二卷积输出约一百三十一千。这里只是列出的张量本身，不包括库为反向保存的所有数据，也不代表峰值。若批大小翻倍，这些激活线性增加，而一千二百八十二个参数不变。

若改成三十二平方输入，前两层空间位置约四倍，卷积参数仍相同。若改成展平头，第二层输出十六乘十六乘十六，二类线性头就需要八千一百九十四个参数，而原全局平均头只有三十四个。结构选择的资源联动应整网计算，不能只统计骨干卷积。

<a id="cnn4-detail-26"></a>

### 8.2 墙钟时间测量要排除哪些混淆

首次执行可能包含线程池启动、缓存和库初始化；时间还受批大小、数据生成、评估频率和硬件负载影响。应明确测量端到端还是只测模型，说明是否包含数据处理、反向和优化器。若使用异步设备还需正确同步，本章没有进行这种设备实测，因此不报告任何 GPU 加速比。

固定时间比较允许快模型执行更多更新，固定步数比较则允许不同总时间。二者回答不同问题，不能在表格里把一个方法的固定步数结果与另一个方法的固定时间结果称为同预算。教学任务很小，测时噪声可能大于结构差异，宁可只报告可复核主要乘加，也不要对毫秒波动给出强结论。

<a id="cnn4-detail-27"></a>

### 8.3 搜索与失败运行也属于成本

为了找到一个高分方案试了很多学习率、种子与增强，开发总成本可能远高于最终一次训练。若只报告选中模型的运行时间，会隐藏方法的使用难度。可以分别列最终训练成本和搜索总预算，并说明是否使用早停提前终止不佳配置。失败运行不是需要抹去的噪声，它们反映稳定性和资源要求。

同种子比较也不是完美消除随机性。不同结构参数形状改变，会消费不同随机数；相同种子不能保证每个可比权重一一对应。可以通过共享数据顺序与初始化规则减少波动，但仍需多个独立重复估计差异。配对实验有帮助，却要明确配对对象究竟是数据划分、种子、初始化还是训练批次。

<a id="visual-mechanism-cnn-04"></a>

### 图解：分辨率翻倍时空间算量与参数量不同

![输入边长翻倍后空间位置和乘加次数变为四倍，核权重仍为二百一十六](images/04-doubling-spatial-side-length-quadruples-macs-but-reuses-the-kernel.webp)

[打开原图放大](images/04-doubling-spatial-side-length-quadruples-macs-but-reuses-the-kernel.webp)

**图中的机制。** 把比较限定为一层无偏置卷积：输入三通道，输出八通道，核为 $`3\times3`$，步幅一、填充一。因此输出高宽等于输入高宽；边长从 32 增至 64 时，不涉及取整误差，空间位置恰好从 1,024 增至 4,096。表中的空间位置按单个输出通道计数，完整输出标量数还需乘以八。

每个输出标量需要累加 $`3\times3\times3=27`$ 个乘积。于是两种大小的输出标量数分别为 $`32^2\times8=8192`$ 和 $`64^2\times8=32768`$，前向乘加次数分别为 221,184 和 884,736；但两者都只存储 $`8\times3\times3\times3=216`$ 个核权重。参数复用解释了为什么计算量改变而参数量不变。

**条件与边界。** 这里一个乘法并累加计为一个 MAC，统计的是单张图这一层的前向工作，不包括反向、偏置或其他层。如果用一次乘法加一次加法约计两个 FLOPs，须另行说明口径。步幅、边界及其他网络结构可能改变面积比；实际显存与延迟也受批量、算法和硬件利用率影响，不能直接把四倍 MAC 当作四倍运行时间。

## 9. 研究方案：从基准成功走向有解释的困难任务

基准方向任务成功之后，可以系统改变三个轴：信噪比、目标尺度与目标位置。每次只改变一个轴，保持对象独立划分与标签规则，绘制验证指标随难度变化的趋势。若模型在噪声增加时逐渐退化，而在位置变化时稳定，说明当前结构在这些有限条件下更能处理后者；这仍不是对所有噪声和位移的普遍结论。

压力集应在开发阶段定义，最后测试从冻结的目标分布抽取。若每次发现一个有利难度点就报告，得到的是选择性展示。可以预先声明一组难度网格，完整报告所有组合与支持数。资源有限时宁可少设几个有解释的点，也不要生成大量没有重复和分析的数字。研究问题越明确，越不需要用巨大表格掩盖机制不清。

<a id="cnn4-detail-46"></a>

### 9.1 下采样位置的三组消融

第一组保持本章网络，第二组去掉池化、保持通道数，第三组去掉池化同时减少第二层宽度，使主要乘加更接近。第一与第二比较直接结构变化及其成本，第一与第三比较某种算量约束下的折中。第三又改变宽度，所以不能把全部差异单独归因于采样；应把两类对照并列，清楚说明各自回答的问题。

在每组里观察细条纹、粗条纹与不同采样相位。若去池化仅对细条纹明显改善，较符合细节保留假设；若所有组都改善，可能还涉及容量或优化。可以进一步用固定线性滤波器分析下采样前后能否区分输入，再把结果与训练模型联系。机制推导和性能对照共同提供证据，单独一项很难解释全部变化。

<a id="cnn4-detail-47"></a>

### 9.2 位置与背景捷径的反事实配对

对同一条纹生成若干不同中心和背景，形成配对样本，目标是在方向不变时保持预测一致。再保留背景而改变方向，要求输出随标签变化。配对构造能减少部分无关因素，但必须保证改变方向没有同时引入明显亮度或面积差。水平垂直条面积相同有助于控制总亮度，边界裁切仍可能破坏这一点，所以生成范围应让条纹完整可见。

真实图像很难做到完美反事实，可以使用多来源数据和人工审阅辅助。若背景替换造成不自然接缝，模型可能对合成痕迹反应，应把该限制写入解释。因果分析需要对干预质量负责，不是只要把某块像素换掉就获得单因素实验。配对错误分析适合提出假设，最终主张还要自然资料验证。

<a id="cnn4-detail-48"></a>

### 9.3 样本复杂度与对象数曲线

固定验证对象和生成协议，逐步增加训练对象数，观察数据量收益。每个对象始终只生成相同数量观测，避免同时改变对象覆盖与重复观测数。再单独固定对象数增加每对象观测，比较两种扩充方式。前者增加对象多样性，后者增加同对象噪声变化，它们可能具有不同边际价值。

曲线需要重复划分或种子，尤其训练对象少时波动大。若只用同一大训练集前若干编号，可能意外让某些位置或类别分布不均，应检查各规模的分层与覆盖。不要把一次非单调曲线当作“更多数据一定有害”，也不要把平均上升当作任何新来源数据都必然改善。新增数据质量与分布同样重要。

<a id="cnn4-detail-49"></a>

## 10. 评价细节：把一个准确率展开成可复核统计

对二类样本，混淆矩阵可以计算每类召回、精确率和总体准确率。若数据类别均衡，总体准确率容易解释；若部署稀有故障只有百分之一，同样准确率可能对应完全不同实际代价。应在目标分布或明确重加权协议下评价，阈值选择使用验证资料。合成方向任务选择均衡只是为了机制清晰，不是通用数据采样建议。

交叉熵补充概率质量，准确率补充硬决策。二者可能朝不同方向变化：正确类别仍排名第一但概率下降，准确率不变而损失增加；少数极端自信错误可以主导平均交叉熵。选主指标应依据用途，其他指标帮助解释，不要在结果出来后临时换成最有利的那个。若存在多项约束，应预先说明如何综合选择。

<a id="cnn4-detail-50"></a>

### 10.1 按对象评价与按图评价

每对象都有两张图，若对象准确率定义为组内两张图正确率的算术平均，且对象之间等权，那么按图准确率与对象平均准确率严格相等；若对象观测数不同，按图会让高频对象权重大，两种平均一般不再相等。对象级“任一观测正确”“全部观测正确”或多数投票又是不同指标，需要与实际使用规则匹配。多个观察如何汇总属于决策协议，不能在测试后挑最优汇总而不承认新增选择。

置信区间或自助法也要按独立单位抽样。把对象内图像分开重采样会假设它们独立，可能低估不确定性。样本少时区间很宽是资料本身的信息限制，不应靠多打印小数或复制观测消除。报告明确对象数、来源数和观测数，比只给一个百分比更有判断价值。

<a id="cnn4-detail-51"></a>

### 10.2 类别标签与混淆矩阵方向

代码采用真实类别乘类别数加预测类别后计数，矩阵行是真实类、列是预测类。若评价工具采用相反约定，图形也可能合理却解释颠倒。应该用两个手写预测错误案例核对计数，而不是仅看矩阵和总数对不对。标签映射还需与训练、保存和展示一致，交换类别名称会让正确数值产生错误业务结论。

多分类时平均方式也要公开：宏平均给每类相同权重，微平均按样本聚合，带支持数加权又不同。类不平衡情形下差异明显。视觉项目常出现某类图像很多、某类很少，单个总体值可能掩盖少数类完全失败。错误表应包含支持数和相关限制，而不是无限细分到没有统计意义的小格子。

<a id="cnn4-detail-52"></a>

## 11. 交付与复现：完整函数比单个权重更重要

最终学习成果应让读者知道输入如何转为张量、通道顺序是什么、像素范围如何处理、网络配置与标签字典是什么、使用何种模式以及输出怎样解码。权重只有在这些约定下才确定函数。若训练用灰度一通道，部署误把颜色三通道顺序混淆，即使某些适配让形状能运行，函数也已不同。

本章不留下模型文件，而是在内存加载一份独立状态并核对固定测试输出，展示最小预测交付验收。真实持久化项目需要同时保存配置和资料版本，必要时记录模型摘要与校验信息。可运行实验直接保留在 Markdown，采用内存张量和内存状态演示，不产生临时脚本、图片或模型文件；真实项目的持久化与版本管理应按交付需求另行设计。

<a id="cnn4-detail-53"></a>

### 11.1 恢复训练与预测加载分别验收

预测加载只要求选定函数在规定输入上保持输出；严格训练恢复还要求下一步更新与连续训练一致。优化器动量、学习率调度、随机源、数据采样进度和批统计都可能影响后者。不能因为加载后预测相同就宣称严格续跑一致，也不能因为重新优化轨迹不同就否认预测状态保存正确。

若需要恢复实验，可先用无随机小模型在若干步处分支，一路继续、一路加载完整状态再继续，比较下一步参数。随后逐项加入随机增强和数据打乱，确认保存了对应随机源。设备和并行实现还可能有非确定行为，结论应限定环境；CPU 演示不能替代 GPU 或多机验证。复现目标越强，状态契约就需要越完整。

<a id="cnn4-detail-54"></a>

### 11.2 把研究迭代留在明确边界内

一次迭代结束，应冻结候选选择和主张，报告测试、成本与已知失效。之后新想法可以开启下一轮，但已经查看的测试属于已有开发知识。长期项目可以使用滚动时间评价、新来源留出或明确版本化基准，保持最终证据的意义。不能靠每次把同一文件重新命名为测试集恢复独立性。

对学习者最有价值的报告不一定是最高分，而是能够解释每项改动为什么做、哪些结果反驳了假设以及在哪些条件下停止。发现一个简单模型已经满足任务，或发现资料无法区分两个结构，都是合理结果。研究深度来自清楚的问题、机制和证据，而不是持续堆叠架构直到无法审阅。

## 12. 零观测错误与独立测试单位

为隔离相关性，另设十二个独立同分布的测试对象，每对象恰有两次观测，且这两次总是同对同错；每个对象的错误概率为 $`p`$。这是假设明确的辅助构造，沿用“十二对象、二十四图”的规模，但没有声称上方程序的实际图像都完全相关。两次观测没有提供第二次独立试验，因此看到二十四图全对的概率仍是 $`(1-p)^{12}`$，不是 $`(1-p)^{24}`$。

![零错误时按十二个独立对象计数，误按二十四张相关图像独立计数会得到过低上限](images/04-zero-error-bound-depends-on-independent-object-count.webp)

[打开原图放大](images/04-zero-error-bound-depends-on-independent-object-count.webp)

在零错误事件下，单侧 $`95\%`$ 精确二项上限可由 $`(1-p_U)^n=0.05`$ 反解：

```math
p_U=1-0.05^{\frac1n}.
```

真正使用十二个独立对象时，上限约为 $`0.221`$；误把相关图像当二十四个独立单位，得到约 $`0.117`$，看起来更精确，却没有相应独立证据。表中第二行只展示误设独立单位后的结果，实际应以对象为单位计算。

推导采用固定模型、相同对象总体及独立同分布的二项试验假设。对象相关结构、类别分层或误差概率异质时，应按真实抽样协议重新分析，不能直接给上方训练结果套一个未经核验的区间。这里也是单侧上限；双侧等尾 $`95\%`$ 区间的上端使用 $`0.025`$，数值不同。二项概率反演的通用方法见 [NIST 的精确比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。置信水平描述重复抽样程序的覆盖性质，不表示观测后固定参数有九成五概率位于区间内。
