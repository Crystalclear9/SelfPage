# 优化方法

理解模型参数怎样更新，以及学习率、正则化和优化器分别解决什么问题。

**先修知识：** 梯度、矩阵基本运算。

## 学习顺序与覆盖范围

先用第 1 章建立目标、抽样、可行域与下降保证，再在第 2 章研究历史状态；第 3 章处理曲率模型与约束证书，第 4 章把它们组织为可复核实验。已掌握手写回归的读者可直接带着日志和轨迹进入第 4 章，再按故障返回相应推导。数值求解误差与优化误差要分别判断，不能仅靠损失曲线解释所有异常。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：从谱得到稳定学习率](04-优化实验记录与故障定位.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
