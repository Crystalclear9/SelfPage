## 1. 训练就是优化一个明确目标

<a id="optimization-1-detail-2"></a>

### 1.1 参数、损失、目标与可行域分别是什么

经验学习常写为 $`F(\theta)=n^{-1}\sum_{i=1}^n\ell_i(\theta)+\lambda R(\theta)`$，其中样本已经固定，$`\theta\in\mathbb R^d`$ 是要改变的参数，$`\ell_i`$ 是第 $`i`$ 条样本的损失，$`R`$ 表达惩罚，$`\lambda\ge0`$ 决定相对强度。若还有约束，则问题是 $`\min_{\theta\in C}F(\theta)`$。目标和集合必须先定义，算法才能有正确与否的判断标准。

“优化训练损失”是一种简写，不应掩盖正则、样本权重、多个任务和有效元素归约。两个程序一个用求和、一个用平均，若没有同步处理正则与学习率，它们可能在求不同问题。样本权重代表频数、成本或重要性时，归一化也有不同含义，不能只看表达式长度决定分母。

优化变量也要明确。原始输入是固定数据，标准化统计可能是训练前拟合的固定变换，参数是当前更新对象；如果把标准化统计随参数重新计算，函数依赖就发生改变。含随机层时，还需说明目标是某个固定随机状态下的样本函数，还是对随机机制取期望后的函数。没有先确定这些对象，所谓梯度一致很可能只验证了一个临时替代问题。

最后，约束是对解必须满足的要求，而非打印出来的提醒。参数非负、概率和为一、资源成本不超过预算，都需要在算法中维持或在理论中证明最后满足。把违反约束但损失低的参数称为优秀解，实际上忽略了问题定义的一部分。

<a id="optimization-1-detail-3"></a>

### 1.2 最优解不一定存在，更不一定唯一

写下 $`\min`$ 并不自动产生最优点。函数 $`f(x)=e^x`$ 在整个实线上严格为正，下确界为零，但没有任何有限 $`x`$ 达到零；让参数不断向负无穷移动，不能说找到了有限最优解。连续函数在非空紧集合上会达到最小值，这是一个足够条件；在无界集合上，也可以通过适当的强制增长条件保证水平集有界，再建立存在性。

唯一性是另一个问题。$`f(x,y)=x^2`$ 的最优集合是整条 $`x=0`$ 的直线。目标值达到零并不能识别 $`y`$，算法可能由初值或参数化决定最后位置。严格凸目标若达到最小值，则解唯一；仅仅凸并不保证唯一，而严格凸也不单独保证解存在，例如前面的指数函数。

这些区别会直接影响验收。唯一解问题可以比较参数距离；多解问题要先确定是否要求最小范数或其他选解原则，再决定是否允许不同参数；只有下确界的问题则应报告目标差、参数增长和预算。把所有情形都用“权重没有对齐参考值”判断，会把数学结构误认为实现失败。

<a id="optimization-1-detail-4"></a>

### 1.3 负梯度为什么是一个局部方向

在当前位置 $`x`$，可微函数沿位移 $`d`$ 的一阶变化为 $`\nabla f(x)^Td`$。如果限制位移欧氏长度不超过一，Cauchy–Schwarz 不等式说明最小的一阶变化是 $`-\Vert \nabla f(x)\Vert `$，在梯度非零时由 $`d=-\frac{\nabla f(x)}{\Vert \nabla f(x)\Vert }`$ 达到。因此负梯度是欧氏单位球中的最陡局部方向。

这里有两个限制。第一，它依赖“单位长度”的度量，换坐标或换范数就可能改变最陡方向；第二，一阶模型只描述足够小邻域，沿负梯度走很远仍可能升高目标。普通梯度下降把方向与长度合在一起，更新 $`x^+=x-\eta\nabla f(x)`$，实际位移长度是 $`\eta\Vert \nabla f(x)\Vert `$，不是单纯的学习率。

如果梯度为零，一阶模型没有偏好，也不能单凭这一点判断极小。例如 $`f(x)=x^3`$ 在零处导数为零，却在任何邻域都有更小值；$`f(x)=-x^2`$ 的零点是极大。最优性、驻点和算法固定点之间需要条件才能互相推出，后续小节将用可核查的命题连接它们。

### 基础算例：把固定点与步长上界分开判断

取 $`f(w)=(w-4)^2`$，梯度为 $`2(w-4)`$。最优点由目标直接确定为四，更新误差满足 $`w_{t+1}-4=(1-2\eta)(w_t-4)`$。初值为零，学习率零点二五时，序列为零、二、三、三点五，误差每次减半，目标差每次变为四分之一。

若学习率为一，误差因子为负一，参数在零与八之间来回，损失恒为十六；若学习率为一点一，因子为负一点二，误差绝对值逐步增大。梯度公式没有错，失败来自更新步长。稳定条件是 $`\vert 1-2\eta\vert \lt 1`$，即零到一之间的开区间，边界不能不加说明地包含进去。

还要注意目标差和参数误差的下降率不同，因为目标是误差平方。看到图上损失下降很快，并不能直接把同一百分比当成参数接近速度。这个最简单的例子已经包含后面一般二次目标的方向收缩机制，但一般非线性函数的曲率会随位置改变，需要更广的工具。

### 图解：二次目标的步长边界

![比较四种步长的落点和损失，并用 Armijo 门槛判断一次虽下降却不合格的试探](images/01-step-size-and-sufficient-decrease.webp)

[打开原图放大](images/01-step-size-and-sufficient-decrease.webp)

表中固定 $`f(w)=w^2`$、$`w_0=1`$。起点梯度为二，所以一步更新为 $`w_1=1-2\eta`$。步长 $`0.2`$ 与 $`0.8`$ 的落点一正一负，却具有相同的损失 $`0.36`$。步长 $`0.5`$ 恰好到达零，而 $`1.1`$ 让新位置离零更远，损失升到 $`1.44`$。

继续使用同一个步长时，每一步都把参数乘以 $`1-2\eta`$。步长 $`0.2`$ 使参数从同侧收敛，$`0.8`$ 使参数交替收敛。二者的损失都逐步乘以 $`0.36`$。步长 $`1.1`$ 每次乘以 $`-1.2`$，所以符号交替且绝对值增大。要判断收敛，既要读乘数的符号，也要比较其绝对值与一。

表中第一步的损失也给出了该步长每次更新的损失倍率，因为$`f(w_{k+1})=(1-2\eta)^2f(w_k)`$。在非零初值下，$`0\lt \eta\lt 1`$ 才会持续收缩；其中 $`0\lt \eta\lt \frac{1}{2}`$ 从同一侧靠近零，$`\frac{1}{2}\lt \eta\lt 1`$ 则左右交替、振幅减小。$`\eta=1`$ 的倍率为一，构成等幅往返；$`\eta>1`$ 的倍率大于一。$`\eta=0`$ 完全不更新，初值恰为零时则始终不动。

**为什么已经下降，回溯搜索仍可能拒绝？** 对照表下的 Armijo 门槛。固定 $`c=\frac14`$，沿负梯度更新时要求

```math
f(w-\eta g)\le f(w)-c\eta g^2.
```

本例右端为 $`1-\eta`$，左端为 $`(1-2\eta)^2`$，因此正步长下接受条件恰为 $`\eta\le\frac34`$。取 $`\eta=0.8`$，新目标零点三六确实低于一，却高于门槛零点二，所以未满足规定的充分下降。给定试探步长，更新后的目标值必须小于或等于门槛，回溯才会接受。

若回溯从一开始、每次将步长减半，一先失败，二分之一随后通过；这次恰落在一维二次函数的最优点，但一般函数不会如此。回溯只需找到合格步长，不等价于精确最小化整条搜索射线；更小的正步长也可能合格。算法及一般条件可对照 [Boyd 与 Vandenberghe《Convex Optimization》第 9.2 节，算法 9.2](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf)。

这里的上界来自曲率 $`f''=2`$。换成 $`f(w)=\frac{a}{2}w^2`$、$`a>0`$，误差因子就变为 $`1-\eta a`$，稳定条件相应变为 $`0\lt \eta\lt \frac{2}{a}`$。图中的步长不能脱离目标曲率直接照搬。绘图参考 [D2L 的梯度下降教学图](https://d2l.ai/chapter_optimization/gd.html)中“在原函数上观察更新”的方法；此处的落点和损失倍率按本例独立计算。

### 图解：梯度下降中的坐标振荡与损失收缩

![按顺序列出前两步的坐标与目标值，纵坐标换符号，损失每步乘零点三六](images/01-signed-gradient-iterates-and-loss.webp)

[打开原图放大](images/01-signed-gradient-iterates-and-loss.webp)

先沿表从上往下读，纵坐标依次为一、负零点六和零点三六，目标值却持续下降。对欧氏梯度而言，负梯度垂直于当前位置的光滑等高线。连接两个迭代点的线段从这个局部方向出发，经过其他等高线时通常不再保持垂直。

本图独立采用 $`g(x,y)=\frac12(x^2+4y^2)`$，从 $`(x_0,y_0)=(-2,1)`$ 出发。梯度是 $`(x,4y)^T`$，因此更新可以直接写成

```math
x_{k+1}=(1-\eta)x_k,\qquad y_{k+1}=(1-4\eta)y_k.
```

取 $`\eta=0.4`$，两个坐标因子分别为 $`0.6`$ 与 $`-0.6`$：纵向跨过零点，而两坐标的绝对值都缩小。于是 $`x_k=-2(0.6)^k`$、$`y_k=(-0.6)^k`$，目标值精确满足 $`g_k=4(0.36)^k`$。第一步为 $`(-1.2,-0.6)`$、$`g_1=1.44`$；第四步为 $`(-0.2592,0.1296)`$、$`g_4=0.06718464`$。所以坐标振荡与目标下降可以同时发生。

要求任意起点都收敛，需要同时满足 $`|1-\eta|\lt 1`$ 与 $`|1-4\eta|\lt 1`$，即 $`0\lt \eta\lt \frac12`$。若取 $`\eta=0.1`$ 单调收缩两个坐标；$`\eta=0.4`$ 允许纵向振荡；$`\eta=0.6`$ 的纵向因子为 $`-1.4`$，当前起点具有非零纵坐标，因而发散。若恰从 $`y_0=0`$ 出发，则不会激发这个不稳定方向；因此这里的步长范围说的是对所有起点的保证，而非每一个特殊初值的必要条件。

图解参考 [D2L 多变量梯度下降](https://d2l.ai/chapter_optimization/gd.html#multivariate-gradient-descent)将更新落在目标等高线上的方式；本例独立设置目标、初值及步长，再用坐标递推逐行核对表中的坐标和目标值。

## 2. 批量与随机梯度：抽样改变了什么

<a id="optimization-1-detail-7"></a>

### 2.1 固定经验目标中的随机性来自算法

先固定训练集，记 $`g_i(x)=\nabla\ell_i(x)`$。全量数据梯度为 $`\overline g(x)=n^{-1}\sum_i g_i(x)`$。若在给定当前参数与全部历史后，重新均匀抽取一个索引 $`I`$，则 $`E[g_I(x)\mid\mathcal F]=\overline g(x)`$。$`\mathcal F`$ 表示抽样前已有的信息，参数也是其中可确定的量；条件期望写法防止把随历史变化的参数错误当作独立常数。

若目标另有固定正则项，可在每次随机数据梯度上加入精确的 $`\lambda\nabla R(x)`$。这个操作没有引入新的抽样误差，仍对完整目标无偏。若数据批次只包含某一类对象、采样概率依赖未校正的业务规则，方向的条件期望可能已经不是原来的全量梯度。

按轮次随机重排与每步独立有放回抽样是不同算法。重排第一批可能是均匀子集，但条件于已经处理的索引，后续只能从剩余样本抽取；简单的每步条件无偏证明不能原样套用。重排可以很有效，只是理论分析应准确写出它采用的依赖结构，而不能用“有随机种子”替代独立性条件。

<a id="optimization-1-detail-8"></a>

### 2.2 批大小与有限总体修正的准确形式

在固定点 $`x`$，定义样本梯度离散度 $`\sigma_x^2=n^{-1}\sum_i\Vert g_i(x)-\overline g(x)\Vert ^2`$。独立有放回取 $`b`$ 个索引并平均，梯度噪声的平方范数期望为 $`\frac{\sigma_x^2}{b}`$。推导是把中心化和的平方展开，独立使不同抽取之间交叉期望为零，保留 $`b`$ 个相同的对角项。

若从有限总体均匀无放回选一个大小为 $`b`$ 的子集，且 $`n>1`$，则相同量变成 $`\frac{(n-b)\sigma_x^2}{[b(n-1)]}`$。负相关的入选机制减少重复抽到同一记录的波动；当 $`b=n`$ 时恰为零。当 $`b=1`$ 时回到 $`\sigma_x^2`$，这两个边界可以用于检查公式分母。

这些都是在同一参数处比较梯度估计的公式。不能据此断言固定一个训练轮次后，大批一定得到更好的模型，因为更新次数、学习率、参数经过的位置和每步成本也改变。样本相关的总体统计问题也不能只套这条有限训练索引公式，它描述算法抽样，不自动证明训练集代表部署总体。

<a id="sec-2-1"></a>

<a id="optimization-1-detail-9"></a>

### 机制展开：无偏小批梯度仍有抽样方差

令完整目标为 $`f(x)=\frac{x^2}{2}`$，随机梯度以相同概率取 $`x+2`$ 或 $`x-2`$。在 $`x=1`$ 时全梯度为一，但抽到负一并不矛盾；学习率零点一会把参数从一推到一点一，目标从零点五升到零点六零五。无偏只保证两种梯度平均为一，没有保证单次方向与全梯度同号。

在最优点零处，真实梯度为零，两个随机梯度仍为正负二。一次更新反而会把参数推离最优点。要解释随机训练中的持续波动，必须在下降分析里加入噪声二阶矩，不能把每次上升都诊断成错误，也不能因此接受任何发散轨迹。随机性可以解释波动，却不能免除检查步长、抽样和数值范围的责任。

<a id="deep-dive-2"></a>

<a id="optimization-1-detail-10"></a>

### 深入讲解：非均匀抽样怎样保持同一目标

若按正概率 $`p_i`$ 抽索引，使用 $`\frac{g_I}{(np_I)}`$，其条件期望为 $`\sum_i\frac{p_i g_i}{(np_i)}=\overline g`$。若直接用 $`g_I`$，平均方向变为 $`\sum_i p_i g_i`$，通常优化了不同的加权目标。所谓多采困难样本，必须说明是否有意改变目标，还是只为提高估计效率而校正抽样概率。

校正保持无偏却不保证方差降低。固定点上两个梯度为二和负二，均匀抽样方差为四；若概率改成零点九与零点一，校正后的梯度分别为 $`\frac{10}{9}`$ 与 $`-10`$，二阶矩为 $`\frac{100}{9}`$，反而更大。小概率对象被赋予很大补偿，可能成为主要噪声来源。

在固定梯度列表且各非零项有正采样概率时，最小化校正梯度二阶矩，得到概率与梯度范数成正比，可由 Cauchy–Schwarz 推导。但计算所有梯度范数本身有代价，当前位置的最优概率也未必是后续轨迹的最优规则。实际提议若依赖历史估计，需要保持相应信息边界，仍要记录计算预算与支持覆盖。

<a id="optimization-1-detail-11"></a>

### 2.3 梯度累积与立即更新不能混用证明

固定参数，把不等大小微批的梯度按实际样本数加权相加，能够恢复同一个大批梯度；但前面微批已经更新后，后面梯度在另一个点计算，就不再是有限和重排。这个区别在随机优化证明中同样关键：条件期望必须对应当前参数，而不是某个轮次开头的旧参数。

日志也要注明采样对象与记录时刻。沿训练轨迹的批损失平均，不是某个固定模型的精确全量目标；若要判断理论下降界，应在同一固定数据与参数上评价。更新次数、数据遍历次数和墙钟时间分别代表不同成本，后续数值实验会把它们分开使用，而不把一个漂亮的曲线当成唯一证据。

## 3. 正则化与约束：软偏好和硬要求

<a id="optimization-1-detail-13"></a>

### 3.1 惩罚改变了目标，而不是自动恢复真值

以标量问题 $`J(w)=(w-3)^2+\tfrac12w^2`$ 为例，导数为 $`2(w-3)+w`$，最优点为二，不再是无惩罚目标的三。它在拟合和缩小参数之间折中。这个解在训练目标上正确，并不说明原来的三不可信；统计上是否有益，还要考虑估计方差、噪声、样本量和独立评价。

二次惩罚对梯度增加 $`\lambda w`$，但惩罚哪些坐标、是否包含截距、参数单位如何定义，都影响结果。换一个可逆参数化后，原本各向同性的惩罚可能变成不同方向强度不同的二次型。不能因为两个程序都用了同一个名为正则系数的数值，就断言它们表达同样的偏好。

约束则要求 $`w\in C`$。例如限制 $`\vert w\vert \le2`$，无约束最优点三不可行，边界二是这个受限问题的最优解。这个例子与某个惩罚系数的解恰好重合，但不意味着任意惩罚、任意非凸问题都能与任意约束一一对应。二者的联系依赖最优性与对偶条件，后续约束优化章会进一步展开。

<a id="optimization-1-detail-14"></a>

### 3.2 欧氏投影的定义、存在性与证书

对非空闭凸集合 $`C`$，欧氏投影定义为 $`\Pi_C(z)=\arg\min_{u\in C}\tfrac12\Vert u-z\Vert ^2`$。距离平方随点远离 $`z`$ 增大，因此可把最小化限制在一个足够大的有界闭区域上得到存在性；严格凸的距离目标配合凸集合保证唯一。若集合不是闭的，下确界可能在集合外；若不是凸的，最近点可能不唯一。

<a id="scientific-plate-01"></a>

先画出无约束的试探点，再从试探点画到最近可行点。两条线分别对应更新和投影。

![梯度试探从可行半平面进入外部，再沿垂直边界的方向返回](images/01-gradient-trial-and-perpendicular-return.webp)

[打开原图放大](images/01-gradient-trial-and-perpendicular-return.webp)

先从半平面内的 $`P`$ 沿负梯度试走到外部的 $`z`$，再沿垂直边界的方向回到最近可行点 $`Q`$。试探步由目标梯度决定，第二步由集合和欧氏距离决定。闭凸集合的欧氏投影唯一。集合指示函数的近端映射正好等于这个投影，其他惩罚的近端映射要另行求解。

设投影为 $`p`$。对任意 $`u\in C`$，线段 $`p+t(u-p)`$ 在集合内，距离平方沿这条线段在 $`t=0`$ 的右导数不能为负，得到 $`(z-p)^T(u-p)\le0`$。反过来，若这个不等式对全部可行 $`u`$ 成立，展开距离平方便有 $`\Vert u-z\Vert ^2\ge\Vert p-z\Vert ^2+\Vert u-p\Vert ^2`$，所以 $`p`$ 确实是投影。

这个变分不等式既是证明工具，也是数值证书。它说明从投影点指向外部点的向量，与任何从投影点出发的可行位移的内积都不为正。简单集合上可以直接验证，复杂集合则可能需要解另一个优化问题，不能认为投影是无成本的一行裁剪。

对两个外部点分别写投影不等式并相加，可得 $`\Vert p-q\Vert ^2\le(p-q)^T(z-v)`$，再用 Cauchy–Schwarz 推出投影不扩张距离。这种几何稳定性依赖闭凸条件；在离散集合中，输入微小变化可能让最近点突然跳到另一边，不能沿用同样结论。

<a id="optimization-1-detail-15"></a>

### 3.3 盒约束可以裁剪，单纯形需要共同阈值

若 $`C`$ 是逐坐标区间的笛卡尔积，距离平方可分离，投影就是逐坐标裁剪。例如非负正交象限投影为 $`\max(z_j,0)`$。但概率单纯形还要求各坐标之和为一，坐标之间通过总和耦合，不能先独立裁剪再随意归一化就称为欧氏投影。

单纯形投影具有形式 $`p_j=\max(z_j-\tau,0)`$，阈值 $`\tau`$ 由总和一确定。可先把坐标从大到小排序，假设前 $`k`$ 个保持正，得到 $`\tau=\frac{(\sum_{j=1}^kz_{(j)}-1)}{k}`$，再检查正负边界是否与假设相容。这个共同平移加截断来自投影最优条件，不是按原比例分配剩余质量。

例如 $`z=(0.8,0.3,-0.2)`$，前两项保留，阈值零点零五，投影为 $`(0.75,0.25,0)`$。裁剪再归一化则给 $`(\frac{8}{11},\frac{3}{11},0)`$，两者都可行，但后者并非距离最近。可行性与投影最优性是两项不同要求，特别是实现受约束算法时，不能只检查总和正确。

<a id="optimization-1-detail-16"></a>

### 3.4 非光滑惩罚需要改变局部模型

对 $`\vert w\vert `$，零点不可微。次梯度在正侧为一、负侧为负一、零点为区间 $`[-1,1]`$。最优性要求零属于总次梯度集合，不要求普通导数在零存在。若简单给零点随便指定一个导数，再当作光滑目标使用下降引理，就越过了理论条件。

近端梯度把光滑部分线性化并加入平方稳定项，再对非光滑部分精确求解。对目标 $`f(x)+\lambda\Vert x\Vert _1`$，先令 $`z=x-\eta\nabla f(x)`$，再求最小化 $`\frac{\Vert u-z\Vert ^2}{(2\eta)}+\lambda\Vert u\Vert _1`$。逐坐标分解后，正侧最优候选是 $`z-\eta\lambda`$，负侧是 $`z+\eta\lambda`$，中间区域由零点次梯度覆盖，因此得到软阈值 $`\mathrm{sign}(z)\max(\vert z\vert -\eta\lambda,0)`$。

软阈值与硬裁剪不同：它先缩小非零幅度，再把足够小的坐标置零。把 $`\lambda\vert x\vert `$ 当作整个目标时，输入二、$`\eta\lambda=0.5`$ 得到一点五；输入零点三则直接归零。普通固定步长次梯度可能在零附近反复跨越，近端步却能准确停在非光滑最优点。两者是不同算法，不能只因为都产生某种稀疏结果就视为实现等价。

### 图解推导：软阈值的零区间怎样由次梯度条件产生

![按输入范围对照软阈值的三个分支，中间闭区间映到精确零](images/01-subgradient-cases-for-soft-thresholding.webp)

[打开原图放大](images/01-subgradient-cases-for-soft-thresholding.webp)

图中的三段规则都来自同一个近端子问题 $`Q_z(u)=\frac12(u-z)^2+0.5|u|`$。二次项希望 $`u`$ 靠近输入 $`z`$，绝对值希望它靠近零。$`z=0.3`$ 时最优点恰为零；$`z=1`$ 时最优点是 $`0.5`$。两个结果都来自同一个优化问题。

最优条件为 $`0\in u-z+0.5\,\partial|u|`$。若 $`u>0`$，得 $`u=z-0.5`$，但还需 $`z>0.5`$；若 $`u\lt 0`$，得 $`u=z+0.5`$，需 $`z\lt -0.5`$。在 $`u=0`$，次梯度是整个 $`[-1,1]`$，条件变为 $`z\in[-0.5,0.5]`$。三段拼起来，便得到图中的三段规则。精确零来自一整个输入区间，并非数值舍入。

对照之下，单独对 $`0.5|z|`$ 做一次单位步长的显式次梯度更新，结果可能跨过零。$`z=0.3`$ 时它走到 $`-0.2`$，越过尖点；近端则精确求解子问题并停在零。这个对照不证明所有次梯度算法都失败，它说明更新对象不同，不能把一次显式次梯度称为近端。

推广到近端梯度时，先对光滑部分求 $`z=x-\eta\nabla f(x)`$，再使用阈值 $`\eta\lambda`$。改变步长也改变阈值，不能固定阈值后声称同一算法。可分离的 $`L_1`$ 惩罚逐坐标应用本图；组范数等惩罚需要另一种算子。定义与软阈值依据 [Parikh 与 Boyd《Proximal Algorithms》第 1.1、6.5 节](https://web.stanford.edu/~boyd/papers/pdf/prox_algs.pdf)，图中两个输入由最优条件独立核验。

读图时注意中间一栏含有两个端点，整个 $`[-0.5,0.5]`$ 都被送到同一个精确零。这还可验证软阈值的不扩张性：三段斜率分别为一、零、一，因此对任意两输入 $`z_1,z_2`$，都有 $`|S(z_1)-S(z_2)|\le|z_1-z_2|`$。跨过分段点时可将区间分段相加得到同样不等式。它解释了近端映射不会把输入距离放大，但不意味着整个近端梯度迭代无需控制光滑部分步长。

## 4. 为什么标准化有助于优化：坐标与度量

<a id="optimization-1-detail-18"></a>

### 4.1 狭长谷地里的同一步长

取 $`f(x_1,x_2)=x_1^2+100x_2^2`$，Hessian 对角为二与二百。为了对任意初始误差都稳定，普通固定步长需小于零点零一；但在平缓方向，步长很小导致推进缓慢。把迭代次数加大可以继续前进，却没有改变两方向曲率差异这个结构事实。

特征标准化能够消除部分单位引起的尺度差，但两列几乎重复时，即便每列方差都是一，条件仍可能很差。尺度和相关性是两类因素。优化诊断应检查实际作用方向和可辨识性，而不是见到标准差相同就宣布目标已经良态。

这里还要区分坐标缩放与添加惩罚。缩放可以在保持同一个预测函数集合的同时改变迭代几何；正则则通常改变被优化的目标。两者有时都让曲线更平稳，但改善的机制和最终答案不同，实验中应分开改变、分开解释。

<a id="optimization-1-detail-19"></a>

### 4.2 梯度依赖哪一种长度定义

若把单位位移定义为 $`d^TMd\le1`$，其中 $`M`$ 对称正定，那么通过令 $`v=M^{\frac{1}{2}}d`$，最小化一阶变化可得到方向正比于 $`-M^{-1}\nabla f`$。这说明欧氏负梯度不是脱离度量的绝对最陡方向。不同坐标的单位与代价，会改变什么叫走同样远。

可逆线性重参数化 $`x=Sz`$ 也能看出同一关系。对 $`h(z)=f(Sz)`$，梯度为 $`S^T\nabla f(x)`$，在 $`z`$ 中做普通梯度下降，再映回 $`x`$，得到 $`x^+=x-\eta SS^T\nabla f(x)`$。它是在原坐标中预条件的更新，通常与直接欧氏更新不同。

若原目标有唯一解且两种更新都收敛并充分求解，最终解可以相同；但有限步轨迹、稳定步长与到达精度的成本不同。若原目标存在多解，度量还可能影响所选解。解释算法时应把“同一个目标”与“相同迭代”分开，后者是更强的要求。

<a id="optimization-1-detail-20"></a>

### 4.3 大梯度、小梯度与参数单位

梯度分量的数值有单位。若某坐标从米改为毫米，数值参数和梯度尺度都会改变。直接比较两个表示中的梯度范数，并不能自动比较离最优点远近。可采用明确的无量纲化、目标差证书或与问题度量一致的残差，但每个标准都应说明定义。

相对更新量也有边界。参数初值为零时，除以参数范数没有意义；某些坐标本来就应接近零，统一相对误差可能非常大而预测变化很小。实践中通常同时记录绝对更新、相对尺度和目标变化，再结合具体参数解释，而不是依靠一个任意阈值。

梯度裁剪会改变这些量的关系。对确定全梯度做范数裁剪仍保持方向，只是改变步长；对随机梯度分别裁剪，则通常使其条件期望发生改变。例如随机量以零点九概率为一、零点一概率为负九，均值为零；截到正负一以后，均值为零点八。原本的无偏估计不再无偏，不能把裁剪仅解释成没有统计影响的数值保护。

[打开原图放大](images/01-changing-coordinates-versus-recomputing-update.webp)

取目标 $`f(x,y)=x^2+25y^2`$。图中的椭圆表示相同损失：第二方向曲率更大，固定步长需要受该方向限制。令 $`u=x`$、$`v=5y`$ 后，目标变为 $`u^2+v^2`$，等高线成为圆，说明坐标缩放改变优化器看到的几何。图右的两条更新路径追踪同一物理起点 $`(x,y)=(0.5,0.2)`$，换算后得到 $`(u,v)=(0.5,1)`$，不是换了一份初值。

在原坐标下，梯度为 $`g=(1,10)`$，Hessian 为 $`H=\mathrm{diag}(2,50)`$。沿负梯度的精确线搜索步长 $`\alpha=\frac{g^\top g}{g^\top Hg}=\frac{101}{5002}`$，新点约为 $`(0.479808,-0.001919)`$，目标从 $`1.25`$ 降到约 $`0.230308`$。若在新坐标重新执行梯度下降，梯度为 $`(1,2)`$，沿该方向精确线搜索取二分之一，直接到达原点。映回原空间，缩放坐标的负梯度方向与 $`(-x,-y)`$ 平行，而原梯度方向与 $`(-x,-25y)`$ 平行；两条方向一般不同。这里二次型恰好被完全标准化，不能据此推断任意缩放都能一步求解，也不能把精确线搜索自动等同于 Newton 更新。

变换坐标不会自动改变原问题的预测含义；参数正则项、步长与映射回原参数的规则也要一致变换。

图右的两行在同一个新坐标起点 $`(u,v)=(0.5,1)`$ 出发。第一行把原坐标已经算出的更新结果换算到新坐标，第二行则直接用新坐标重新求梯度和步长。第一行保留原来的迭代，第二行才改变更新规则。

## 5. 驻点与约束最优不能混淆

<a id="optimization-1-detail-22"></a>

### 5.1 一阶必要条件的适用范围

无约束可微函数在内部局部极小点满足梯度为零，原因是任何方向及其反方向都可行，方向导数不能一正一负。这个条件是必要的，却一般不充分。对 $`x^2-y^2`$，原点梯度为零，沿纵轴仍能下降；对 $`x^4-y^4`$，原点 Hessian 甚至为零矩阵，仍不是极小。

凸性首先是关于整条线段的定义：在凸定义域中，对任意两点和 $`t\in[0,1]`$，有 $`f((1-t)x+ty)\le(1-t)f(x)+tf(y)`$。它不是仅看某一点的梯度方向。对可微函数，将这条不等式减去 $`f(x)`$、除以正数 $`t`$，再令 $`t`$ 趋于零，就得到 $`\nabla f(x)^T(y-x)\le f(y)-f(x)`$，即全局的一阶下界。反过来，若每点都有这样的一阶下界，在任意线段内点对两个端点分别使用并按线段权重相加，梯度项抵消，便恢复凸性定义。

凸可微目标则不同。由凸性的一阶不等式 $`f(y)\ge f(x)+\nabla f(x)^T(y-x)`$，若梯度为零，就得到所有 $`y`$ 的目标不低于当前值，因此是全局最优。凸性提供从局部信息到全局比较的桥梁；没有这座桥，就不能从小梯度直接得出好目标值。

梯度趋零也不保证参数收敛或最优点存在。指数函数在参数趋负无穷时梯度趋零，却没有有限最优点；存在一串接近驻点的参数，也不代表整条序列有唯一极限。理论应明确控制的是目标差、梯度、最优集合距离，还是参数本身，不能把其中一种自动升级成全部结论。

<a id="optimization-1-detail-23"></a>

### 5.2 可行方向与边界最优

最小化 $`f(x)=x`$，要求 $`x\ge0`$，最优在零，梯度恒为一。零点处允许的方向只朝右，沿它们的一阶变化都非负，因此不存在矛盾。把这个最优解用无约束梯度范数验收，会永远判定失败；约束改变了可接受的局部移动。

对凸集合上的可微问题，局部极小点必须满足 $`\nabla f(x)^T(u-x)\ge0`$ 对所有可行 $`u`$ 成立。必要性来自沿可行线段的右导数；当目标也凸时，一阶下界又说明这足以保证全局最优。一般非凸目标中，它只是一阶驻点条件，不能排除更远处或高阶方向的下降。

这种写法还能连接投影。$`x=\Pi_C(x-\eta\nabla f(x))`$ 的投影变分不等式，恰好等价于上述一阶条件，任意正步长都如此。参数不动有时是边界约束正确地阻止下降，而不意味着梯度已经消失。

<a id="optimization-1-detail-24"></a>

### 5.3 投影梯度映射提供正确的残差

定义 $`G_\eta(x)=\frac{[x-\Pi_C(x-\eta\nabla f(x))]}{\eta}`$。无约束时它等于普通梯度，有约束时衡量合法更新的大小。若 $`G_\eta(x)=0`$，就得到前节的一阶条件；在凸目标下可据此判定最优。非零值的量级依赖步长和度量，报告时要同时注明它们。

令投影后的位移为 $`d`$。对投影不等式取比较点为当前可行点，得到 $`\nabla f(x)^Td\le-\frac{\Vert d\Vert ^2}{\eta}`$。再用光滑上界，可得

```math
f(x+d)\le f(x)-\left(\frac1\eta-\frac L2\right)\Vert d\Vert ^2.
```

因此在目标沿相关线段 $`L`$-光滑、集合闭凸且 $`0\lt \eta\lt \frac{2}{L}`$ 时，非零投影位移也有严格下降保证。这个证明不同于直接代入无约束更新，关键是投影几何提供的内积约束。若所谓投影只是一个随意修补函数，就不能继承这个结论。

### 5.4 可计算的目标差上界与停止规则

对紧凸集合和凸可微目标，可以求线性最小化点 $`s\in\arg\min_{u\in C}\nabla f(x)^Tu`$，定义间隙 $`g_C(x)=\nabla f(x)^T(x-s)`$。由凸性有 $`f(x)-f^*\le\nabla f(x)^T(x-x^*)\le g_C(x)`$。它给出一个真正的目标差上界，而不仅是曲线看起来变平。

在概率单纯形上，线性最小值是梯度最小坐标，所以间隙等于 $`\nabla f(x)^Tx-\min_j\nabla_jf(x)`$。这个证书与普通梯度范数回答不同问题，边界最优点可以有非零梯度却间隙为零。但在线性子问题昂贵或集合不紧时，需要另行处理存在性与计算成本，不能把公式当作免费操作。

停止还可以由预算、验证选择或数值故障触发。它们应分别记录：达到优化容差、耗尽更新、验证早停、非有限值和输入契约失败不是同一状态。一个诚实的实验应说明为什么停下，以及停止标准究竟证明了什么。

## 6. 进阶：从光滑性推导收敛尺度

<a id="sec-6-1"></a>

<a id="optimization-1-detail-27"></a>

### 下降引理怎样把方向变成保证

设函数在相关区域可微，梯度满足 $`\Vert \nabla f(y)-\nabla f(x)\Vert \le L\Vert y-x\Vert `$。沿线段用微积分基本定理写

```math
f(x+d)-f(x)=\int_0^1\nabla f(x+td)^Td\,dt.
```

减去 $`\nabla f(x)^Td`$，用内积上界和梯度 Lipschitz 条件控制余项绝对值，得到不超过 $`\int_0^1Lt\Vert d\Vert ^2dt=\frac{L\Vert d\Vert ^2}{2}`$。所以

```math
f(x+d)\le f(x)+\nabla f(x)^Td+\frac L2\Vert d\Vert ^2.
```

这就是下降引理。它控制一阶模型漏掉多少曲率影响，不要求目标凸。取 $`d=-\eta\nabla f(x)`$，便有 $`f(x^+)\le f(x)-\eta(1-\frac{L\eta}{2})\Vert \nabla f(x)\Vert ^2`$。只要 $`0\lt \eta\lt \frac{2}{L}`$，非零全梯度给出严格下降；取 $`\eta=\frac{1}{L}`$，下降至少为梯度平方除以两倍 $`L`$。

这个保证要求整条更新线段处于相应光滑区域。如果只有当前点 Hessian 很小，却沿大步跨进高曲率区域，不能用起点局部曲率无条件替代 $`L`$。全局上界可能保守，局部回溯则通过实际函数值验证足够下降，两者分别依靠先验曲率与现场检查。

<a id="optimization-1-detail-28"></a>

### 6.1 非凸时首先能控制的是梯度

假设目标有下界 $`f_{\inf}`$，全梯度下降固定使用 $`\frac{1}{L}`$。把下降引理从零步累加到 $`T-1`$ 步，函数值项望远镜相消，得到

```math
\frac1T\sum_{t=0}^{T-1}\Vert \nabla f(x_t)\Vert ^2
\le \frac{2L[f(x_0)-f_{\inf}]}T.
```

因此已观察迭代中最小梯度范数的平方不超过右侧；要保证某次梯度范数小于 $`\varepsilon`$，这个界要求更新数与 $`\frac{1}{\varepsilon^2}`$ 同阶。若从这些迭代中均匀随机选一个点，同一右侧也控制其梯度平方的期望。

这里没有证明目标接近全局最优，也没有证明最后一次迭代就是最小梯度那次。梯度趋零可以对应鞍点，参数也可能没有有限极限。若进一步希望讨论聚点，还需要序列有界或水平集紧等条件；若希望找到二阶局部最优，必须加入曲率分析与更强算法。收敛声明中最容易被省略的，往往正是“哪个量”“哪一个点”和“在什么意义下”。

<a id="optimization-1-detail-29"></a>

### 6.2 凸目标的目标差为什么是反比速度

再假设 $`f`$ 凸且存在最优点 $`x^*`$，令 $`\eta=\frac{1}{L}`$，$`D_t=\Vert x_t-x^*\Vert ^2`$。更新距离展开为

```math
\begin{aligned}
&D_{t+1}=D_t-2\eta\nabla f(x_t)^T(x_t-x^*)\\
&\quad +\eta^2\Vert \nabla f(x_t)\Vert ^2
\end{aligned}
```

凸性使中间内积不小于 $`f(x_t)-f^*`$，而下降引理把最后梯度项与一步目标下降联系起来，合并后得到

```math
2\eta[f(x_{t+1})-f^*]\le D_t-D_{t+1}.
```

累加可得所有更新后目标差之和不超过 $`\frac{D_0}{(2\eta)}`$。因为确定全梯度目标单调下降，最后一项不大于这些项的平均，因此

```math
f(x_T)-f^*\le\frac{L\Vert x_0-x^*\Vert ^2}{2T}.
```

这个证明同时用了光滑性、凸性、最优解存在和固定合法步长。只有目标有下界时，不能跳过凸性直接得到目标差速率；存在多个最优点时，可以针对其中任意一个写界，但参数收敛到哪个点仍是额外问题。

反比上界是一种最坏情形保证，不表示每条曲线都恰好按反比下降。简单二次函数可能更快，具体初值也可能避开慢方向。理论上界不紧与理论错误是不同情况，应通过检查假设和量词判断，而不是要求实验曲线与上界完全重合。

<a id="optimization-1-detail-30"></a>

### 6.3 强凸把梯度大小连到目标差

若 $`f`$ 是 $`\mu`$-强凸，即 $`f(y)\ge f(x)+\nabla f(x)^T(y-x)+\frac{\mu\Vert y-x\Vert ^2}{2}`$，且 $`\mu>0`$，对右侧二次下界在 $`y`$ 上最小化，得到 $`f^*\ge f(x)-\frac{\Vert \nabla f(x)\Vert ^2}{(2\mu)}`$。所以 $`\Vert \nabla f(x)\Vert ^2\ge2\mu[f(x)-f^*]`$。

与步长 $`\frac{1}{L}`$ 的下降界合并，得到 $`f(x_{t+1})-f^*\le(1-\frac{\mu}{L})[f(x_t)-f^*]`$。连续迭代给出几何上界，条件数 $`\frac{L}{\mu}`$ 大时，每一步最坏保证接近原值，收敛较慢。强凸还使最优解唯一，并有 $`\Vert x-x^*\Vert ^2\le\frac{2[f(x)-f^*]}{\mu}`$，从而能把目标差转换为参数距离。

但这些转换依赖可信的全局或相关区域下界 $`\mu`$。在非凸目标上随手取某个正 Hessian 特征值，不能得到全局强凸证书；接近秩亏的二次目标也可能让该界极松。理论参数的估计成本和不确定性应写进实验，不能只把公式中的字母换成希望成立的数值。

<a id="optimization-1-detail-31"></a>

### 6.4 有噪声时，下降界多出一项

令随机梯度为 $`g=\nabla f(x)+\xi`$，条件均值 $`E[\xi\mid\mathcal F]=0`$，并假设在访问区域 $`E[\Vert \xi\Vert ^2\mid\mathcal F]\le\frac{\sigma^2}{b}`$。这个统一二阶矩界是额外假设，有限训练集并不自动使所有无界参数处都满足它。对下降引理取条件期望，交叉噪声项消失，可得

```math
\begin{aligned}
&E[f(x-\eta g)\mid\mathcal F]
\le f(x)\\
&-\eta(1-\frac{L\eta}{2})\Vert \nabla f(x)\Vert ^2
+\frac{L\eta^2\sigma^2}{2b}.
\end{aligned}
```

当 $`\eta\le\frac{1}{L}`$，非凸情形累加后控制平均梯度平方的界包含 $`\frac{2[f(x_0)-f_{\inf}]}{(\eta T)}+\frac{L\eta\sigma^2}{b}`$。固定步长使第二项不消失；按预算选取与 $`T^{-\frac{1}{2}}`$ 同阶的步长，可以平衡这两部分，但同时要满足稳定上界。该结论仍控制梯度，不是全局风险。

在强凸条件下，期望目标差满足因子 $`1-\mu\eta`$ 的递推，再加每步噪声项；长期上界包含 $`\frac{L\eta\sigma^2}{(2\mu b)}`$。这称为常步长噪声地板的一种上界。减小步长或增大批量能压低它，却也改变进展速度和成本，因此不能只展示最终波动较小就宣称整体更高效。

<a id="optimization-1-detail-32"></a>

### 6.5 一个可以精确计算的随机二次模型

设 $`f(x)=\frac{ax^2}{2}`$，随机梯度为 $`ax+\xi_t`$，噪声独立、均值零、方差 $`s^2`$。固定步长给出 $`x_{t+1}=(1-\eta a)x_t-\eta\xi_t`$。当 $`0\lt \eta a\lt 2`$，均值按同一因子收缩，方差满足 $`V_{t+1}=(1-\eta a)^2V_t+\eta^2s^2`$。

从确定初值开始求几何级数，长期方差为 $`\frac{\eta s^2}{[a(2-\eta a)]}`$，长期期望目标差为 $`\frac{\eta s^2}{[2(2-\eta a)]}`$。若 $`a=2,s=3,\eta=0.1`$，参数方差与期望目标差都为零点二五。使用四个独立样本平均噪声时，二者变成原来的四分之一。

这个精确模型说明，保持无偏并不能让常步长最终静止。递减步长可能降低波动，但经典的步长和发散、平方和收敛条件只是某些随机逼近定理的一部分，还需要稳定性、噪声矩和目标结构等条件；不能仅列两条级数就保证任意深层网络收敛。

<a id="optimization-1-detail-33"></a>

### 6.6 不精确梯度与回溯步长的边界

若使用确定近似梯度 $`\nabla f(x)+e`$，步长为 $`\frac{1}{L}`$，直接展开光滑上界可得到 $`f(x^+)\le f(x)-\frac{\Vert \nabla f(x)\Vert ^2}{(2L)}+\frac{\Vert e\Vert ^2}{(2L)}`$。这里不需要误差均值为零，交叉项通过代数抵消；但当误差与真梯度同量级时，下降保证可能消失。这解释了差分精度、压缩或近似计算误差为何必须与目标精度一起考虑。

未知 $`L`$ 时，可以从试探步长开始，反复乘以缩小因子，直到满足 $`f(x-\eta g)\le f(x)-c\eta\Vert g\Vert ^2`$，其中此处 $`g`$ 是准确全梯度、$`0\lt c\lt 1`$。光滑性保证足够小的步长会通过，但实际还要处理非有限值、最小步长和尝试次数。随机小批上通过这个条件，不能自动保证全量目标下降，尤其当用于接受与评价的批次不断改变时。

回溯每次尝试都要计算函数值，可能超过固定步长的开销。比较算法应同时记录接受步数、函数评价数和梯度评价数。一个算法只走十步但每步试一百次，与另一个直接走一百步，不能只按迭代数宣布前者更省计算。

## 7. 完整实验：让理论量对应实际观测

### 7.1 非二次光滑函数与回溯评价成本

设二维目标为

```math
\begin{aligned}
&f(x)=\sum_j[\log(e^{x_j}+e^{-x_j})-\log2]\\
&\quad +0.05\Vert x\Vert ^2
\end{aligned}
```

其梯度为逐坐标双曲正切加零点一倍参数，Hessian 对角在零点一到一点一之间，因此全局强凸且光滑，唯一最优点为零。这比只用固定曲率二次函数多了一层变化，同时仍能清楚解释理论条件。

数值上用稳定的对数加和函数计算，而不是先把正负指数分别算出来。大参数时后者可能溢出，目标数学上有限并不能保证任意写法都安全。函数值和梯度各自计数，回溯只在固定当前位置和准确全梯度上进行；接受后再记录新目标，使历史与参数时刻一致。

```python
import numpy as np

def value(x):
    return float(np.sum(np.logaddexp(x, -x) - np.log(2.0)) + 0.05 * (x @ x))

def gradient(x):
    return np.tanh(x) + 0.1 * x

x = np.array([3.0, -2.0])
history = [value(x)]
function_evals = 1
gradient_evals = 0
accepted_rates = []
for iteration in range(500):
    g = gradient(x)
    gradient_evals += 1
    if np.linalg.norm(g) < 1e-7:
        break
    rate = 8.0
    current = history[-1]
    for attempt in range(60):
        trial = x - rate * g
        candidate = value(trial)
        function_evals += 1
        if np.isfinite(candidate) and candidate <= current - 0.25 * rate * (g @ g):
            break
        rate *= 0.5
    else:
        raise RuntimeError("line search did not accept a step")
    x = trial
    history.append(candidate)
    accepted_rates.append(rate)
else:
    raise RuntimeError("iteration budget exhausted")

assert np.linalg.norm(gradient(x)) < 1e-7
assert np.all(np.diff(history) <= 1e-13)
assert np.linalg.norm(x) < 1e-6
print("updates:", len(accepted_rates), "function evaluations:", function_evals,
      "gradient evaluations:", gradient_evals)
print("final parameters:", x, "final objective:", history[-1])
print("accepted learning rates:", sorted(set(accepted_rates)))
```

在本章核对环境中，这段程序接受了八次更新，调用目标三十二次、梯度九次，接受步长包含一和二，最终梯度满足设定容差。最后一次梯度调用用于检查停止，并没有产生新更新，因此梯度评价数比接受步数多一。这些计数揭示为什么仅写“八轮收敛”会漏掉回溯成本；换一个初值后计数可能改变，不能把一次实验值当作算法的固定复杂度。

应该先预测曲线会下降、参数会接近零、函数评价数会超过接受更新数，再运行核对。若目标最后出现接近机器精度的小负数，应调查稳定表达的相消与舍入，而不是声称理论非负性失败；若出现大负数，则要检查实现。代码的严格停止标准只针对这个受控例子，不能推广为所有目标都应采用同一个绝对阈值。

回溯可能在离原点较远、局部曲率较小时接受大于全局保守值的步长，这与全局光滑上界不矛盾。上界给的是足够条件，不是每个位置允许步长的精确最大值。真正限制每个已接受步的是实际检查的充分下降条件，报告应保留这两种依据的区别。

### 7.2 单纯形投影与非光滑近端的双重核验

下面分别求一个单纯形约束二次问题和一个带绝对值惩罚的二次问题。两者都能写成先走一步再处理结构，但后一步含义不同：投影保证硬可行域，软阈值处理惩罚。代码用已知最优结构对照，并在边界上计算梯度映射，而不要求普通梯度范数为零。

投影实现还利用平移不变性消去所有坐标的共同大偏置。令 $`m=\max_i z_i`$，最优阈值满足 $`m-1\le\tau\lt m`$，所以 $`z_i\le m-1`$ 的坐标投影必为零；把移位后的这些坐标截在 $`-1`$ 不改变解，也避免极端异号坐标相减溢出影响阈值。这里的稳定处理针对已经表示出来的输入，不能恢复输入量化之前丢掉的坐标差异。

```python
import numpy as np

def project_simplex(z):
    if np.iscomplexobj(z):
        raise ValueError("this projection is defined for real vectors")
    z = np.asarray(z, dtype=np.float64)
    if z.ndim != 1 or z.size == 0 or not np.isfinite(z).all():
        raise ValueError("expected a nonempty finite vector")
    # 加共同常数不改变投影；先移除大偏置，避免 z_max - 1 舍入回 z_max。
    # 单纯形总质量为 1，距最大坐标至少 1 的坐标不可能严格为正。
    with np.errstate(over="ignore"):
        shifted = np.maximum(z - z.max(), -1.0)
    ordered = np.sort(shifted)[::-1]
    thresholds = (np.cumsum(ordered) - 1.0) / np.arange(1, len(z) + 1)
    active = np.flatnonzero(ordered > thresholds)
    rho = active[-1]
    return np.maximum(shifted - thresholds[rho], 0.0)

z = np.array([0.8, 0.3, -0.2])
assert np.allclose(project_simplex(z), [0.75, 0.25, 0.0])
assert np.allclose(project_simplex([1e16, 1e16]), [0.5, 0.5])
assert np.allclose(project_simplex([1e308, -1e308]), [1.0, 0.0])
try:
    project_simplex(np.array([1. + 1.j, 0.]))
except ValueError:
    pass
else:
    raise AssertionError("complex coordinates must not lose their imaginary part")
a = np.array([-1.0, 2.0, 0.5])
x = np.full(3, 1.0 / 3.0)
eta = 0.8
for _ in range(60):
    g = x - a
    x = project_simplex(x - eta * g)
reference = project_simplex(a)
mapping = (x - project_simplex(x - eta * (x - a))) / eta
gap = (x - a) @ x - np.min(x - a)
assert np.allclose(x, reference, atol=1e-10)
assert np.isclose(x.sum(), 1.0) and np.min(x) >= 0.0
assert np.linalg.norm(mapping) < 1e-10 and abs(gap) < 1e-10
print("constrained optimum:", x, "ordinary gradient norm:", np.linalg.norm(x - a))

def soft_threshold(z, amount):
    return np.sign(z) * np.maximum(np.abs(z) - amount, 0.0)

target = np.array([2.0, 0.3, -1.0])
lam = 0.5
u = np.zeros(3)
for _ in range(60):
    u = soft_threshold(u - eta * (u - target), eta * lam)
expected = soft_threshold(target, lam)
assert np.allclose(u, expected, atol=1e-10)
assert u[1] == 0.0
print("proximal optimum:", u)
```

第一个问题的解为 $`(0,1,0)`$，普通梯度范数为一点五，而投影梯度映射与线性间隙都为零。这个数值例子直接说明为什么无约束停止标准不适用边界最优。第二个问题的解为 $`(1.5,0,-0.5)`$，中间坐标精确归零来自阈值机制，不是浮点碰巧变小。

代码先去掉共同大偏置，再把无须参与正支撑的差值截在负一，已处理断言中的极端同号、异号输入。其余累计值位于负样本数与零之间，避免直接对原始巨大坐标累加；有限精度仍可能影响很接近阈值的坐标，不能恢复输入表示前已经丢失的差异。应检查可行性和投影条件，而不是仅凭没有异常就验收。真实大规模约束还可能没有廉价闭式投影，其求解误差与成本也要计入外层算法。

### 7.3 固定参数的抽样方差与长期噪声地板

这个实验先枚举有限总体的所有二元素子集，验证无放回方差公式；再用许多独立训练轨迹验证随机二次模型的长期二阶矩。两种随机对象不同：前者是固定点梯度估计，后者是参数在多步噪声下的分布。把它们分开有助于避免把单步方差缩减误读成整个训练过程的精确等价。

```python
from itertools import combinations
import numpy as np

gradients = np.array([-2.0, 0.0, 1.0, 5.0])
mean_gradient = gradients.mean()
sigma2 = np.mean((gradients - mean_gradient) ** 2)
subset_means = np.array([np.mean(gradients[list(idx)])
                         for idx in combinations(range(4), 2)])
variance_without_replacement = np.mean((subset_means - mean_gradient) ** 2)
expected = (4 - 2) * sigma2 / (2 * (4 - 1))
assert np.isclose(variance_without_replacement, expected)
print("finite-population variance:", variance_without_replacement,
      "with-replacement variance:", sigma2 / 2)

rng = np.random.default_rng(1024)
runs, steps = 20000, 300
a, noise_scale, eta = 2.0, 3.0, 0.1
factor = 1.0 - eta * a
for batch in (1, 4):
    x = np.full(runs, 2.0)
    for _ in range(steps):
        count = rng.binomial(batch, 0.5, size=runs)
        noise = noise_scale * (2.0 * count / batch - 1.0)
        x = factor * x - eta * noise
    expected_second_moment = (factor ** (2 * steps) * 4.0
        + eta ** 2 * noise_scale ** 2 / batch
        * (1.0 - factor ** (2 * steps)) / (1.0 - factor ** 2))
    observed = float(np.mean(x ** 2))
    assert np.isclose(observed, expected_second_moment, rtol=0.04)
    print("batch:", batch, "observed E[x^2]:", observed,
          "theoretical:", expected_second_moment)
```

枚举方差应为约二点一六六七，有放回方差为三点二五；随机训练参数二阶矩应分别接近零点二五与零点零六二五，但模拟值无需逐位相等。多条独立轨迹是在检验重复实验分布，单条轨迹在最后三百步中的波动则有时间相关，不能直接当成三百个独立重复。

在固定随机流的这次执行中，两种批量的经验二阶矩约为 0.25061 和 0.06079；与理论 0.25、0.0625 的差异来自有限条独立轨迹。代码中的百分之四相对容差是这个教学核验的预设阈值，不是一个自动具有百分之九十五覆盖率的置信区间。若研究模拟误差，应另行估计平方参数在独立轨迹间的方差、报告蒙特卡洛标准误，或增加独立重复；不能用一次断言通过替代概率误差分析。

同样，最后参数的二阶矩与最后参数的方差只有在均值为零时才相等。本例保留了初值均值按收缩因子衰减的平方项，三百步后它很小；若过早测量，必须把这部分瞬态误差算进去。为了看清噪声地板，应先确定初值影响已衰减，再讨论稳态近似，而不是从任意一段平坦图形猜测长期分布。

若要比较在相同样本梯度预算下的效果，批大小四的每步成本应按四计，而不能只对齐更新数。固定四倍批量让噪声地板降低，但在相同预算中更新次数也减少，瞬态误差可能尚未消失。一个完整研究应同时展示初始误差衰减与长期波动，而不是只选对自己有利的最后一段。

### 7.4 本章与后续优化方法怎样衔接

下一章研究动量和自适应状态，它们改变的不只是当前梯度的倍数，还包括历史信息如何进入更新。因此本章普通梯度下降的缩放等价、无状态恢复和一步下降条件，都需要重新核对。第三章进一步研究二阶局部模型与约束乘子，解决曲率和最优性条件中更深的问题；第四章把多个算法放在公平预算下诊断。

继续学习时保留本章的一条主线：先确定正在求什么，再确定每一步用了什么信息，随后检查保证需要哪些条件，最后让实验观测对应到同一个对象。算法名称不能替代这些问题。一个较慢但解释明确的小基准，常能揭露大型训练中难以定位的错误，也能帮助判断某个改动究竟改善了优化、改变了目标，还是只改变了评价方式。
