## 1. 凸性提供什么保证

<a id="optimization-3-detail-2"></a>

### 1.1 定义首先涉及整个线段和定义域

函数 $`f`$ 在凸集合 $`D`$ 上凸，意味着任意 $`x,y\in D`$、$`t\in[0,1]`$ 都有 $`f((1-t)x+ty)\le(1-t)f(x)+tf(y)`$。定义域本身必须是凸的，否则线段可能离开问题。一个函数在两个互不相连的小区域上分别向上弯，并不能因此给出跨区域的全局凸结论。对有限维二阶可微函数，在开凸域上 Hessian 处处半正定与凸性等价；只检查一个点的 Hessian，不足以判断整个域。

可微凸函数满足一阶下界 $`f(y)\ge f(x)+\nabla f(x)^T(y-x)`$。因此无约束驻点若位于域内，就给出全局最优值；证明只需把该点梯度设为零后应用这条下界。反过来，一般非凸函数的一阶 Taylor 展开也成立，但它的余项没有统一非负符号，不能据此得到全局下界。局部近似和全局证书的差别，正是凸性的重要价值。

若约束是凸集 $`C`$，全局最优点可以有非零梯度；可微凸函数的条件变成 $`\nabla f(x_*)^T(y-x_*)\ge0`$ 对所有 $`y\in C`$ 成立。这表示所有可行方向都不能产生一阶下降。把无约束的零梯度停止规则直接用于边界最优点，会永远报告“尚未收敛”；后面的乘子与投影残差只是把这一几何条件变成可计算形式。

<a id="optimization-3-detail-3"></a>

### 1.2 严格凸、强凸与存在性各管什么

严格凸要求不同两点之间的真内点不等式严格成立，因此最优点若存在必唯一。它不保证解存在：例如实数轴上的指数函数严格凸，下确界为零却取不到。强凸则要求额外的统一二次下界 $`f(y)\ge f(x)+\nabla f(x)^T(y-x)+(\frac{\mu}{2})\Vert y-x\Vert ^2`$，其中 $`\mu>0`$。在整个有限维空间上连续的强凸函数具有强制增长，因而最优点存在且唯一；若定义域被人为限制为开集，仍需检查边界是否被排除。

严格凸不意味着某个统一正曲率常数存在。实数轴上的 $`x^4`$ 严格凸，但在零附近二阶导趋零，不是全局强凸。相反，强凸自然推出严格凸，因为在线段上扣去正二次项后，不同端点的内点得到严格余量。非负的 Hessian 可以具有零特征值；严格凸函数甚至可在孤立点 Hessian 完全为零，所以不能把“处处正定”当作严格凸的必要条件。

对于二次函数 $`f(x)=\tfrac12x^THx-b^Tx`$，对称矩阵半正定给凸性，正定给强凸性，强凸常数可取最小特征值。若矩阵奇异，还需检查线性项是否与零空间相容；若某个零空间方向与线性项内积非零，沿适当方向目标无界下降。这个例子显示半正定既不保证唯一，也不保证存在有限最小值，必须连同线性项和定义域一起判断。

<a id="optimization-3-detail-4"></a>

### 1.3 PL 条件为什么不等于强凸

Polyak–Łojasiewicz 条件写作 $`\tfrac12\Vert \nabla f(x)\Vert ^2\ge\mu(f(x)-f_*)`$。它把梯度大小与函数差联系起来，不直接限制两点之间的曲率。强凸且最小值存在时可推出该条件：在强凸下界中对位移取最小，得到 $`f_*\ge f(x)-\frac{\Vert \nabla f(x)\Vert ^2}{(2\mu)}`$。反方向一般不成立，因此用 PL 分析一阶收敛可能比要求强凸更宽。

秩亏最小二乘可以满足针对函数差的 PL 不等式，但解沿零空间不唯一，显然不强凸。PL 还允许非凸函数，例如令 $`h(x)=x+\tfrac12\sin x`$，$`f(x)=h(x)^2`$。由于 $`h'(x)\ge\frac{1}{2}`$，有 $`\tfrac12f'(x)^2=2h(x)^2h'(x)^2\ge\frac{f(x)}{2}`$；而某些大正数位置的二阶导为负，所以函数不凸。这说明没有次优驻点并不等同于函数整体向上弯。

PL 本身也不自动给出某个固定学习率的线性速率。通常还需梯度光滑性，用下降引理将一次函数下降与梯度范数平方联系，才得到函数差的几何收缩。上述非凸例子的 Hessian 不全局有界，不能不经检查就引用一个全局光滑常数。任何“更弱条件”的使用都要列清还保留了哪些其他条件，而不是只删掉强凸两个字。

## 2. Newton 方向如何从局部模型产生

<a id="optimization-3-detail-6"></a>

### 2.1 解线性系统而不是显式求逆

在当前位置写二次模型 $`m(p)=f(x)+g^Tp+\tfrac12p^THp`$。若 $`H`$ 正定，这个模型严格凸，其唯一最小点满足 $`Hp=-g`$。理论上可以写 $`p=-H^{-1}g`$，实现时应解线性方程组；显式求逆通常增加计算和舍入误差，并不带来额外信息。若 Hessian 奇异或不定，方程可能无解、多解，或解对应模型鞍点，必须改变求方向的方式。

正定时 $`g^Tp=-p^THp<0`$，只要梯度非零就严格下降。这个结论只涉及方向的无穷小性质，不保证完整步长一必然降低真实目标。真实函数与局部二次模型之间有高阶余项，离当前位置越远，模型可能越不准确。Newton 的实际流程至少包含方向、步长与停止判断，不能把解出线性系统视为全部算法。

对精确正定二次目标，Hessian 不变且模型就是原函数，Newton 一步到达最优点，不受特征值条件数对迭代次数的影响。但解这一步线性系统的数值成本和误差仍受矩阵规模、结构与条件数影响。“一步收敛”描述外层迭代，不意味着总计算只需一次廉价操作，也不意味着浮点结果无误差。

<a id="sec-2-1"></a>

<a id="optimization-3-detail-7"></a>

### 机制展开：不定 Hessian 下 Newton 可能走向高处

对 $`f(x)=-x^2`$，在一处梯度为负二，Hessian 为负二，解方程得到方向负一，完整步到零。函数值从负一升到零，恰好走向局部最大点。Newton 本来是在求梯度方程的根，在缺乏正曲率时，“更快到达驻点”不能自动解释为更快最小化。多维不定 Hessian 同样存在这个问题。

即使 Hessian 处处正定，也不能省略全局化。取 $`f(x)=\sqrt{1+x^2}`$，其导数为 $`\frac{x}{\sqrt{1+x^2}}`$，二阶导为 $`(1+x^2)^{-\frac{3}{2}}>0`$。Newton 方向为 $`-x(1+x^2)`$，完整步得到 $`x^+=-x^3`$。从二出发会到负八，再到五百一十二，幅度迅速增长。这是严格凸目标上的失败，根源是初始点离局部收敛区域太远，而不是出现负曲率。

![Newton 完整步的两种失败机制](images/03-newton-failures.svg)

左图沿用负二次目标：在 $`x=1`$ 处，Newton 方向为 $`p=-1`$，因此 $`g^Tp=2>0`$，任何足够小的正步长都先上升。右图采用 $`f(x)=\sqrt{1+x^2}`$：Hessian 虽为正，完整步仍从二跳到负八，目标由 $`\sqrt5`$ 增至 $`\sqrt{65}`$。读图时应分别问“方向是否下降”和“距离是否合适”；曲率修正处理前者，线搜索或信赖域控制后者。橙色连线只指示端点变化，不代表沿线中间的目标值。


<a id="optimization-3-detail-8"></a>

### 2.2 局部二次收敛的证明需要哪些条件

设 $`x_*`$ 为驻点，邻域内 Hessian 正定且最小特征值至少为 $`m>0`$，Hessian 对位置是 $`M`$-Lipschitz。令误差 $`e=x-x_*`$，由积分形式的梯度差有 $`g(x)=\int_0^1H(x_*+te)e\,dt`$。完整 Newton 步的误差为

$$
e^+=H(x)^{-1}\int_0^1[H(x)-H(x_*+te)]e\,dt.
$$

取范数，逆矩阵范数至多为 $`\frac{1}{m}`$，Hessian 差至多为 $`M(1-t)\Vert e\Vert `$，从而 $`\Vert e^+\Vert \le\frac{M\Vert e\Vert ^2}{(2m)}`$。这就是二次收敛的核心不等式：误差足够小时，下一步约为当前误差的平方量级。证明还需要初始点足够近，使后续迭代留在该邻域；仅给出局部不等式却不说明邻域保持，是不完整的收敛论证。

若 Hessian 只连续而没有 Lipschitz 控制，通常可获得不同强度的局部结果，不能原样保留这个二次误差界。若求方向时只近似解方程，线性求解残差又会进入误差递推。浮点精度限制下，误差最终停在数值地板，不能要求平方缩小无限持续；观测到最后几步停止改善，可能是数值精度而非局部理论完全错误。

<a id="optimization-3-detail-9"></a>

### 2.3 Newton 减量能说明什么

正定时定义平方减量 $`\delta^2=g^TH^{-1}g=-g^Tp`$。二次模型预测完整步下降 $`\frac{\delta^2}{2}`$，所以这个量具有局部模型意义；它比单看欧氏梯度范数更能反映曲率尺度。在固定正定二次函数中，它恰等于两倍函数差，可作为精确证书；在一般函数中，这种等式不成立。

有些特殊函数类能将减量转成全局可验证的误差界，例如自协调函数的 Newton 理论，但需要对应假设和步长规则。不能把一般目标的减量小直接说成全局最优差小。它也依赖 Hessian 的可信度：若用粗糙近似曲率替代，所得量应标为近似模型减量，避免赋予超过数据支持的意义。

<a id="deep-dive-2"></a>

<a id="optimization-3-detail-10"></a>

### 深入讲解：二阶模型与约束乘子怎样提供不同信息

曲率描述目标或拉格朗日函数在允许方向上的弯曲；乘子描述可行边界法向如何平衡目标梯度。它们不能互相替代。一个边界最优点可能目标梯度很大，但被约束阻挡；一个无约束驻点即使梯度为零，负曲率仍可能说明它不是极小点。严谨判断需要同时问“能往哪里走”“沿允许方向是否有一阶下降”“一阶平坦方向如何弯曲”。

这条顺序也解释算法结构：先确定约束线性化和可行方向，再建立沿这些方向的二次模型，最后检查真实函数及约束的变化。后面的等式消元、KKT 系统、活跃集和临界锥，都是把这三个问题写成具体线性代数对象的方法，而不是另起一套互不相干的公式。

## 3. 阻尼、线搜索与信赖域

<a id="optimization-3-detail-12"></a>

### 3.1 阻尼步长与曲率修正不同

阻尼 Newton 常指保留正定 Hessian 方向，只用 $`x^+=x+\alpha p`$，其中 $`0<\alpha\le1`$。曲率修正则把方向方程改为 $`(H+\tau I)p=-g`$，选择足够大的正移位使矩阵正定。前者改变沿既定方向走多远，后者直接改变方向。若原方向已经是上升方向，单纯缩小正步长一般不能把它变成局部下降方向；这时要先修正曲率或退回其他下降方向。

正移位在 Hessian 特征方向上的作用为把特征值加上 $`\tau`$，所以负曲率会被抬高，大正移位时方向接近缩放负梯度。但不同单位或参数尺度下，加同一个数到对角线的含义不同，必要时应考虑适当缩放。选择移位需要兼顾下降性、线性求解条件和模型精度，不是越大越安全就越有效。

<a id="optimization-3-detail-13"></a>

### 3.2 Armijo 回溯的有限终止理由

对下降方向 $`p`$，Armijo 条件为 $`f(x+\alpha p)\le f(x)+c_1\alpha g^Tp`$，其中 $`0<c_1<1`$。从某个正初值开始，每次乘 $`\rho\in(0,1)`$。由可微性，$`f(x+\alpha p)=f(x)+\alpha g^Tp+o(\alpha)`$；由于 $`g^Tp<0`$，足够小的步长会满足条件，所以在函数于邻域定义且评价可靠时，回溯有限终止。

这不等于算法整体收敛。若方向几乎垂直于负梯度、矩阵越来越病态或函数下界与水平集条件不足，步长可能很小，整体进展仍可能停滞。对正定近似矩阵特征值上下有统一界、梯度在相关水平集 Lipschitz 且目标有下界的情形，可以进一步把下降量与梯度范数联系起来，建立趋向驻点的结论。每一步“找到可接受步长”与整个序列“到达所需解”之间仍有理论工作。

<a id="optimization-3-detail-14"></a>

### 3.3 为什么局部最终会接受完整步

当 Hessian 正定且变化平缓，Newton 方向满足 $`g^Tp=-p^THp`$，Taylor 展开给出完整步真实变化为 $`-\tfrac12p^THp+O(\Vert p\Vert ^3)`$。若 Armijo 常数严格小于二分之一，足够小的方向会使三阶项相对二阶项可忽略，从而接受步长一。这让全局化与局部二次收敛能够衔接：远处谨慎回溯，近处恢复完整 Newton 步。

论证要求余项可控、方向足够小并且求解精确到所需量级。若始终强制步长固定小于一，局部二次速度通常会退化为线性主导，因为误差中保留了未走完的一阶部分。调试时如果每步都回溯很多次，即使梯度已经很小，也应检查 Hessian、求解残差、目标评价精度和线搜索实现，而不能仅凭“有回溯所以稳定”结束分析。

<a id="optimization-3-detail-15"></a>

### 3.4 信赖域用模型可信范围控制步子

信赖域直接求 $`\min_{\Vert p\Vert \le\Delta}g^Tp+\tfrac12p^THp`$。即使 Hessian 不定，紧球内仍可有全局最小解，方向也可能利用负曲率逃离鞍点。求得候选后，用实际下降与模型预测下降之比评估模型，通常写为 $`r=\frac{[f(x)-f(x+p)]}{[m(0)-m(p)]}`$。比值接近一说明预测准确，过小或为负说明局部模型在该范围不可靠。

只有预测下降为正时该比值才具有预期意义，零梯度又没有负曲率时可能应停止，而不是机械相除。根据比值接受或拒绝候选，并调整半径；拒绝步骤也消耗函数评价成本，比较算法时应计入。对球约束二次子问题，全局最优具有 $`(H+\tau I)p=-g`$、$`H+\tau I\succeq0`$、$`\tau\ge0`$ 与 $`\tau(\Vert p\Vert -\Delta)=0`$ 等特征，困难情形还需处理奇异性，不能以为总是一次普通线性求解即可。

<a id="optimization-3-detail-16"></a>

## 4. 拟 Newton、Hessian 向量积与计算规模

<a id="sec-4"></a>

<a id="optimization-3-detail-17"></a>

### 二阶方法为什么不能盲目全量使用

参数维度为 $`d`$ 时，稠密 Hessian 存储通常需平方量级，直接分解常需立方量级运算。自动微分能帮助取得二阶信息，但不能消除这些规模问题；真正的大模型通常利用稀疏、块结构、低秩、Kronecker 结构、子采样或矩阵向量积。算法外层步数少，未必总时间少，尤其当每步需多次反向和分布式通信时。

若目标来自最小二乘，Hessian 可分为 Jacobian 外积项和残差加权的二阶项。Gauss–Newton 保留外积项，因此半正定，但忽略的部分远离小残差区域时可能重要。它与精确 Newton 的差别是模型近似，不是不同名字指向同一个矩阵。若正则、约束或概率模型改变，曲率结构也需重新推导。

<a id="optimization-3-detail-18"></a>

### 4.1 割线条件提供沿已走方向的曲率

令 $`s_k=x_{k+1}-x_k`$、$`y_k=g_{k+1}-g_k`$。由梯度积分公式，$`y_k`$ 等于沿该段 Hessian 平均作用于 $`s_k`$，所以拟 Newton 近似矩阵希望满足 $`B_{k+1}s_k=y_k`$。这个割线条件只约束一个方向，在多维下不能唯一决定整个矩阵。不同拟 Newton 更新通过对称性、正定性及低秩变化等额外原则选取近似。

若保存逆近似 $`C_k\approx H^{-1}`$，BFGS 更新为

$$
\begin{aligned}
C_{k+1} &=(I-\rho s y^T)C_k(I-\rho y s^T)+\rho ss^T,\\[6pt]
\rho &=(y^Ts)^{-1}.
\end{aligned}
$$

将它乘以 $`y`$，第一项因右侧因子作用而归零，第二项得到 $`s`$，所以满足逆割线条件。若 $`C_k`$ 正定且 $`y^Ts>0`$，新矩阵正定：对非零向量 $`z`$，二次型是一个非负的旧矩阵项加 $`\rho(s^Tz)^2`$；若后一项为零，则前一项作用于的向量就是 $`z`$，仍严格为正。这项短证明解释了曲率条件的重要性。

<a id="optimization-3-detail-19"></a>

### 4.2 Wolfe 条件怎样保护曲率

若 $`s=\alpha p`$、$`g_k^Tp<0`$，弱 Wolfe 曲率条件为 $`g_{k+1}^Tp\ge c_2g_k^Tp`$，其中 $`0<c_2<1`$。于是 $`y^Ts=\alpha(g_{k+1}-g_k)^Tp\ge\alpha(c_2-1)g_k^Tp>0`$。因此在精确梯度与下降方向等前提下，曲率条件保证 BFGS 所需的正内积。仅满足 Armijo 下降，并不一般给出这个结论。

当梯度含噪声或两次梯度来自不同小批时，差分会混入抽样变化，曲率内积可能不可靠。可采用跳过更新、阻尼更新或统一曲率批等设计，但这些设计引入新的假设和成本。不能把确定性 BFGS 的局部超线性结论直接用于任意随机拟 Newton；超线性通常还依赖光滑性、正定极限曲率和近似误差逐渐满足相应条件。

<a id="optimization-3-detail-20"></a>

### 4.3 有限记忆与矩阵无关计算

L-BFGS 不保存完整稠密矩阵，而保存最近若干对 $`s,y`$，利用两次循环计算逆近似作用于向量，时间和内存通常为记忆长度乘参数维度。它用可控制存储换取有限曲率记忆，不等于拥有完整 Hessian。初始尺度、曲率对质量、线搜索和记忆长度都会影响表现，应在实验中明确。

Hessian 向量积可用梯度沿向量的方向导数取得，无需构造全矩阵。对 $`f(x)=\tfrac12\Vert Ax-b\Vert ^2+\tfrac\lambda2\Vert x\Vert ^2`$，有 $`Hv=A^T(Av)+\lambda v`$，可以直接计算。若用有限差分近似 $`Hv\approx\frac{[g(x+hv)-g(x)]}{h}`$，则截断与舍入误差又进入线性求解；不同方向长度也影响实际扰动大小，应固定规范和检验策略。

<a id="optimization-3-detail-21"></a>

### 4.4 不精确 Newton 的残差应随进展变化

若只近似求解 $`Hp=-g`$，令残差 $`r=Hp+g`$，则与精确方向之差为 $`H^{-1}r`$。在局部正定邻域，新的参数误差可界为二次余项加 $`\Vert H^{-1}r\Vert `$。所以残差与梯度保持固定比例通常给线性型局部表现；若相对残差逐渐趋零，可期待更强速度；若残差达到梯度平方量级，才有条件保留二次主导。

这说明早期把线性系统解到机器精度可能浪费，晚期始终使用粗容差又会破坏局部快收敛。内层停止条件应与外层误差目标和求解成本协调。共轭梯度要求所求线性系统正定；非凸 Hessian 中出现非正曲率时，应转向截断或信赖域处理，而不是无条件继续套用正定系统的收敛保证。

## 5. 拉格朗日乘子与等式约束

<a id="optimization-3-detail-23"></a>

### 5.1 切空间上的驻点

考虑 $`\min f(x)`$、$`h(x)=0`$，其中 $`h`$ 有若干个分量。在正则点，等式 Jacobian 满行秩，局部可行位移的一阶部分位于零空间 $`J_h(x)d=0`$。若该点局部最优，目标梯度必须与所有切方向正交，因此位于约束梯度张成的法向空间，存在自由符号的乘子 $`\nu`$ 使 $`\nabla f+J_h^T\nu=0`$。

乘子符号自由源于等式没有单侧方向限制。写拉格朗日函数 $`\mathcal L=f+\nu^Th`$ 后，驻点只是法向平衡，仍需同时满足约束本身。若约束梯度线性相关，乘子可能不唯一；若完全退化，甚至在局部最优点也可能找不到以目标系数为一的这种乘子。后面的约束资格正是控制这些异常的工具。

<a id="sec-1-1"></a>

<a id="optimization-3-detail-24"></a>

### 基础算例：等式约束可以先消元再对照乘子

最小化 $`x^2+y^2`$ 且 $`x+y=1`$。消元得到 $`x^2+(1-x)^2`$，唯一最小点为两者均等于二分之一。拉格朗日函数为 $`x^2+y^2+\nu(x+y-1)`$，驻点给 $`2x+\nu=0`$、$`2y+\nu=0`$，因此乘子为负一。目标梯度并不为零，却恰与约束法向平衡。

把右端改为 $`b`$，最优点为 $`x=y=\frac{b}{2}`$，最优值为 $`V(b)=\frac{b^2}{2}`$。乘子为 $`\nu=-b`$，于是 $`V'(b)=-\nu=b`$。负号来自约束写作 $`x+y-b=0`$，若换另一种符号定义，乘子符号也会改变。所谓影子价格不是脱离约束写法的绝对正负，而是最优值对指定扰动参数的导数关系。

<a id="optimization-3-detail-25"></a>

### 5.2 线性等式二次问题的 KKT 系统

对 $`\tfrac12x^THx-c^Tx`$、$`Ax=b`$，驻点和可行性合并成

$$
\begin{bmatrix}H&A^T\\A&0\end{bmatrix}
\begin{bmatrix}x\\\nu\end{bmatrix}
=\begin{bmatrix}c\\b\end{bmatrix}.
$$

即使 $`H`$ 正定，这个鞍点矩阵也一般不正定，不能直接假定普通 Cholesky 可用。若 $`A`$ 满行秩、$`H`$ 在 $`\ker A`$ 上正定，系统可唯一确定原变量和乘子；证明可考察齐次系统，用可行方向与 $`H`$ 的正定性推出原变量为零，再用满行秩推出乘子为零。

也可选可行点 $`x_p`$ 和零空间基 $`Z`$，写 $`x=x_p+Zz`$，解约化系统 $`Z^THZz=Z^T(c-Hx_p)`$。这个方式只需要在可行切空间上正曲率，解释了为什么约束问题不要求完整 Hessian 处处正定。零空间基的构造、稀疏性和数值正交性会影响实际成本，不能只按约化维度判断一定更快。

<a id="optimization-3-detail-26"></a>

### 5.3 灵敏度公式需要稳定的解分支

若最优点和乘子随右端参数平滑变化，且适当二阶条件与约束资格保持，可通过微分 KKT 系统研究解和最优值的变化。包络关系把最优值的一阶变化写成乘子与约束扰动的内积，但这依赖所研究分支可微及最优性没有突然切换。存在多个最优点或活跃集变化时，最优值可能只有单侧导数，不能无条件使用一个固定乘子做大范围外推。

乘子大也可能提示约束尺度设置不合适。等式约束可乘任意非零常数；按本章 $`g(x)\le0`$ 的固定方向书写的不等式约束，则只能乘正常数而保持同一可行域。保持等价后，乘子按反比例变换。因此比较不同约束的重要性前，应说明单位与归一化；仅按原始乘子绝对值排序，可能只是按约束书写单位排序。灵敏度应始终对应明确的物理或业务扰动量。

## 6. KKT 条件的必要性与充分性

<a id="sec-5-1"></a>

<a id="optimization-3-detail-28"></a>

### KKT 条件中的每一项都承担独立职责

统一采用 $`g_i(x)\le0`$ 和 $`h_j(x)=0`$，定义 $`\mathcal L=f+\sum_i\lambda_i g_i+\sum_j\nu_jh_j`$。KKT 要求原始可行、$`\lambda_i\ge0`$、互补条件 $`\lambda_i g_i(x)=0`$，以及驻点 $`\nabla f+\sum_i\lambda_i\nabla g_i+\sum_j\nu_j\nabla h_j=0`$。互补条件表明非活跃不等式的乘子为零；活跃不等式的乘子可以为零，并非每个边界条件都必须产生正压力。

例如最小化 $`(x-2)^2`$ 且 $`x\le1`$，最优点为一，驻点给出乘子二。若把约束错误写成 $`x-1\ge0`$ 却继续使用相同乘子符号，就改变了可行方向，可能得出完全相反的解释。所有手算和程序应先统一不等式方向，再求乘子，最后逐项核验，不能只看解出的参数值是否“看起来合理”。

<a id="optimization-3-detail-29"></a>

### 6.1 为什么需要约束资格

局部最优的一阶几何条件涉及真实可行方向；KKT 用约束梯度构造线性化方向与法向。若约束退化，二者可能不一致。最小化 $`f(x)=x`$，约束 $`x^2\le0`$，可行点只有零，所以零当然是全局最优。但约束梯度在零为零，驻点方程变成 $`1+\lambda\cdot0=0`$，没有任何乘子能满足。于是 KKT 并非所有写法下无条件必要。

线性独立约束资格要求等式梯度和活跃不等式梯度联合线性独立，它足以在光滑局部最优点保证 KKT，并使乘子唯一。更弱的资格可以允许某些梯度相关性。例如 Mangasarian–Fromovitz 约束资格仍要求等式约束梯度线性独立，并要求存在方向 $`d`$，满足所有等式的 $`\nabla h_j(x)^Td=0`$，以及所有活跃不等式的 $`\nabla g_i(x)^Td<0`$。不能省略等式梯度的独立性：若把前述单点可行集写成等式 $`x^2=0`$，所有方向都满足零梯度给出的等式切条件，且没有活跃不等式需要检查，但最小化 $`x`$ 的 KKT 驻点方程仍无解。资格是一种将局部几何与梯度描述接起来的条件，不是可忽略的技术脚注。

同一个可行集合的不同约束表示可以有不同资格。把 $`x\le0`$ 写成 $`x^3\le0`$，集合不变，边界梯度却由一变成零。优化问题的最优点没变，常规乘子表述的正则性变了。实际建模宜避免不必要的退化变换，这比事后让求解器处理近零约束 Jacobian 更清楚。

<a id="optimization-3-detail-30"></a>

### 6.2 凸问题中 KKT 为什么足以证明全局最优

设目标和不等式均凸可微，等式仿射。若某个可行点及乘子满足 KKT，则拉格朗日函数关于原变量凸，其驻点为全局最小点。对任意其他可行点 $`y`$，由于乘子非负、不等式非正，有 $`\mathcal L(y,\lambda,\nu)\le f(y)`$；而互补性保证候选点处拉格朗日值等于目标值。结合最小性便得 $`f(x_*)\le f(y)`$。

这项充分性证明不需要先假设 Slater 条件。Slater 常用于保证最优解存在相应乘子和强对偶等性质，而已经找到可行 KKT 证书之后，全局最优可以直接由上述链条得到。把必要性所需条件与充分性所需条件混在一起，会导致“没有严格可行点就不能验证任何最优解”的错误推论。

若目标严格凸，且可行集合凸，KKT 原变量解至多一个；乘子仍可能因为冗余约束而不唯一。若只是不等式严格凸而目标不严格凸，不能简单推出原变量唯一，需具体分析最优集合。最优值唯一、最优参数唯一、乘子唯一是三个不同问题。

## 7. 拉格朗日对偶与 Slater 条件

<a id="optimization-3-detail-32"></a>

### 7.1 对偶函数为何总是下界

定义 $`q(\lambda,\nu)=\inf_x\mathcal L(x,\lambda,\nu)`$，对偶问题是在 $`\lambda\ge0`$ 下最大化该函数。对任意原始可行点，拉格朗日值不超过其目标值，所以 $`q`$ 也不超过原始最优值，这就是弱对偶。它不要求原问题凸，因此即使非凸，任意合法乘子得到的有限下界仍然有效，只是可能存在对偶间隙。

对偶函数是仿射函数族的逐点下确界，因而是凹函数，即使原目标不凸也如此。这里“对偶问题是凹最大化”不意味着原问题已容易求解：内层下确界本身可能困难，强对偶也可能失败。对偶的价值之一是提供证书，下界与可行上界接近时，我们才知道原目标距离全局最优不远。

<a id="optimization-3-detail-33"></a>

### 7.2 一个可手算的完整对偶

最小化 $`x^2+y^2`$，约束 $`x+y\ge2`$，即 $`2-x-y\le0`$。拉格朗日函数为 $`x^2+y^2+\lambda(2-x-y)`$。固定非负乘子时，内层最小点为 $`x=y=\frac{\lambda}{2}`$，所以 $`q(\lambda)=2\lambda-\frac{\lambda^2}{2}`$。最大化得到乘子二、对偶值二；原始点两者均为一，目标也是二，因此原始与对偶证书完全吻合。

若随便选择乘子一，对偶值为一点五，仍是合法下界，但不够紧。若给出一个可行点目标为二点一，那么已知全局最优值位于一点五到二点一之间；不断改善原始与对偶候选，间隙就能成为停止证书。若目标整体乘一个正常数，绝对间隙也随之改变，因此跨任务比较应说明单位，并可同时报告相对间隙；相对归一化分母需要稳定项，尤其当最优值接近零或为负时，不能简单除以当前目标值。

一个很小的相对间隙必须建立在真实可行与合法对偶下界之上，归一化本身不能修复失效证书。对于参数恢复，还需曲率或误差界把函数差转换成位置距离；多个最优点时只能期待接近最优集合。若没有这些附加结构，应如实报告目标证书，不要把它扩展成每个参数小数位均已准确。这个证据比只报告迭代前后目标下降更有解释力，因为它指出尚可能改善的上限。

<a id="optimization-3-detail-34"></a>

### 7.3 Slater 提供什么，也不提供什么

对标准有限维凸问题，若存在满足等式且所有凸不等式严格小于零的适当相对内部点，并且最优值有限，则 Slater 条件可保证强对偶和适当的最优乘子存在。对于仿射约束等情形可有更精细的相对内部表述，不应机械要求在整个环境空间内有普通开球。例如等式本来就把可行域限制在低维平面，其自然内部应在该平面中理解。

Slater 不是原始最优点存在的充分替代：在开域或非紧集合中，有限下确界仍可能取不到。它也不是凸性替代，非凸问题即使有严格可行点，一般也不能据此保证强对偶。若最优点已存在、问题凸且符合相关资格，KKT 才把原始最优与乘子证书连接起来。阅读结论时要同时检查域、有限性、可达性与资格，而不是只寻找一个严格可行点。

## 8. 活跃集、临界锥与二阶条件

<a id="optimization-3-detail-36"></a>

### 8.1 活跃集不等于正乘子集合

在候选点，活跃集为所有满足 $`g_i(x)=0`$ 的不等式。它们决定哪些线性化方向必须满足 $`\nabla g_i(x)^Td\le0`$；等式方向仍满足 Jacobian 乘方向为零。若某活跃约束乘子为正，驻点和临界方向条件会迫使该约束的一阶变化为零；若乘子为零，则允许进入内部，不应把所有活跃约束一律当等式锁死。

例如最小化 $`x^2`$ 且 $`x\le0`$，最优点零处约束活跃，但乘子为零。可行方向可以向负侧进入内部，目标在那里二阶增加。如果盲目把活跃约束当等式，只剩零方向，虽不一定错误地选出此解，却会丢失对真实局部几何的分析。活跃集算法的识别步骤需要允许加入和释放约束，不能只会增加。

<a id="optimization-3-detail-37"></a>

### 8.2 二阶必要条件检查拉格朗日 Hessian

为给出清楚的必要条件，本段假设目标与约束二次连续可微，候选为局部极小点且满足 LICQ，使用由此确定的唯一 KKT 乘子。考察临界锥：方向满足等式线性化、活跃不等式的一阶可行性，并使目标一阶变化为零。沿这些方向，一阶信息无法排除下降，所以需要 $`d^T\nabla_{xx}^2\mathcal L\,d\ge0`$ 作为二阶必要条件。

这里使用的是拉格朗日 Hessian，而不是仅目标 Hessian，因为沿曲线保持弯曲约束会产生额外二阶变化。若只采用更弱资格、乘子不唯一，必要条件对方向与乘子的量词需要另外表述，不能随便挑一组 KKT 乘子就沿用本段结论。

在 LICQ 等标准条件下，若对所有非零临界方向都有严格正值，则得到严格局部最优的二阶充分条件，并可推出相应局部增长性质。正定只需在临界方向上成立，而非整个空间；约束法向可以存在负曲率而不影响可行最小化。另一方面，半正定必要条件不充分：无约束的 $`x^3`$ 在零有零梯度和零 Hessian，却不是极小点，高阶项决定了方向。

<a id="optimization-3-detail-38"></a>

### 8.3 弯曲等式说明为何要用拉格朗日函数

在单位圆 $`x^2+y^2=1`$ 上最小化目标 $`y`$。最优点为 $`(0,-1)`$，拉格朗日函数为 $`y+\nu(x^2+y^2-1)`$，驻点给 $`\nu=\frac{1}{2}`$。目标 Hessian 完全为零，但拉格朗日 Hessian 为单位阵，在切向 $`(d_x,0)`$ 上严格正，正确显示该点局部极小。圆顶点 $`(0,1)`$ 的乘子为负二分之一，切向曲率为负，说明它是极大。

这项算例可以通过消元再次验证：下半圆为 $`y=-\sqrt{1-x^2}=-1+\frac{x^2}{2}+O(x^4)`$。可行曲线本身把线性目标变成二次增长，额外曲率来自约束几何。只看目标的欧氏 Hessian，会错误地认为完全没有二阶信息；乘子恰好把这部分曲率补入拉格朗日 Hessian。

<a id="optimization-3-detail-39"></a>

### 8.4 SQP 是在局部联立优化与可行性

序列二次规划在当前点用目标的一阶项、拉格朗日 Hessian 或其近似构造二次子问题，同时将约束线性化。它并非先无约束优化再随意投影，而是让方向同时考虑目标和约束。由于线性化约束只是一阶近似，候选方向完整走出后仍可能违反原约束，需要评价函数、过滤器、可行性恢复或信赖域等全局化机制。

求解器返回成功标志只能说明它的内部停止条件触发，不自动构成全局证书。非凸 SQP 通常寻找局部 KKT 点，可能受初值和约束表示影响。实践中应自行重算原始可行残差、驻点残差、乘子符号、互补残差，并在需要时检查临界方向曲率；对于凸问题，还能结合对偶间隙给出更强证据。

## 9. 完整数值算例：Newton 与约束证书

<a id="optimization-3-detail-41"></a>

### 9.1 严格凸函数上完整步失败、回溯成功

下面以已推导的平方根目标演示 Newton 的全局化。第一项断言检查从二出发的完整步恰到负八，并使目标升高；随后实现 Armijo 回溯，记录真实目标和接受步长，验证最终到达零附近。实验评价的是这个解析目标，结论并非任意函数上回溯 Newton 都自动成功。

```python
import numpy as np

def values(x):
    q = 1.0+x*x
    return np.sqrt(q), x/np.sqrt(q), q**(-1.5)

x = 2.0
f, g, h = values(x)
p = -g/h
assert np.isclose(x+p, -8.0)
assert values(x+p)[0] > f
history = []
for k in range(60):
    f, g, h = values(x)
    if abs(g) < 1e-12:
        break
    p = -g/h
    alpha = 1.0
    while values(x+alpha*p)[0] > f+1e-4*alpha*g*p:
        alpha *= 0.5
        assert alpha > 1e-15
    newx = x+alpha*p
    history.append((k, x, f, alpha))
    assert values(newx)[0] <= f+1e-14
    x = newx
assert abs(x) < 1e-10
print('accepted steps:', [(r[0], r[3]) for r in history])
print('final x:', x)
```

<a id="optimization-3-detail-42"></a>

### 9.2 等式系统、原始对偶与乘子灵敏度

第二段同时检查两种不同证书。等式二次问题直接解 KKT 系统，并用消元得到的解析点核对；不等式问题直接给出最优原始与对偶候选，再逐项验证。最后有限差分最优值对右端的变化，用来核对乘子符号。若换约束方向，应连同对偶式和灵敏度符号一起改。

```python
import numpy as np
H = 2*np.eye(2)
A = np.array([[1.0, 1.0]])
K = np.block([[H, A.T], [A, np.zeros((1,1))]])
rhs = np.array([0.0, 0.0, 1.0])
solution = np.linalg.solve(K, rhs)
x, nu = solution[:2], solution[2]
assert np.allclose(x, [0.5, 0.5])
assert np.isclose(nu, -1.0)
assert np.allclose(H@x+A.T[:,0]*nu, 0)
assert np.allclose(A@x, [1.0])
V = lambda b: b*b/2
h = 1e-5
assert np.isclose((V(1+h)-V(1-h))/(2*h), -nu)

z, lam = np.array([1.0, 1.0]), 2.0
constraint = 2-z.sum()
stationarity = 2*z-lam*np.ones(2)
primal = z@z
dual = 2*lam-lam*lam/2
assert constraint <= 1e-14 and lam >= 0
assert np.linalg.norm(stationarity) < 1e-14
assert abs(lam*constraint) < 1e-14
assert np.isclose(primal, dual)
print('equality solution and multiplier:', x, nu)
print('primal/dual/gap:', primal, dual, primal-dual)
```

<a id="optimization-3-detail-43"></a>

### 9.3 BFGS 割线条件与 HVP 的独立核对

第三段在已知正定二次函数上生成一对曲率向量，验证逆 BFGS 更新满足割线条件且保持正定。随后不构造 Hessian，直接用矩阵乘积实现最小二乘 Hessian 向量积，再用梯度中心差分核对。有限差分只作为独立数值验证，实际 HVP 公式来自解析推导，二者的证据作用不同。

```python
import numpy as np
H = np.array([[4.0, 1.0], [1.0, 3.0]])
s = np.array([0.2, -0.4])
y = H@s
C = np.eye(2)
rho = 1.0/(y@s)
T = np.eye(2)-rho*np.outer(s,y)
Cn = T@C@T.T+rho*np.outer(s,s)
assert np.allclose(Cn@y, s)
assert np.linalg.eigvalsh(Cn).min() > 0

A = np.array([[1.0,2.0],[-1.0,1.0],[2.0,0.0]])
b = np.array([1.0,0.0,2.0])
lam = 0.3
x, v = np.array([0.2,-0.1]), np.array([1.0,-2.0])
grad = lambda q: A.T@(A@q-b)+lam*q
hv = A.T@(A@v)+lam*v
h = 1e-5
fd = (grad(x+h*v)-grad(x-h*v))/(2*h)
assert np.allclose(hv, fd, rtol=1e-9, atol=1e-9)
print('BFGS eigenvalues:', np.linalg.eigvalsh(Cn))
print('HVP and finite difference:', hv, fd)
```

## 10. 练习与逐步解析

<a id="optimization-3-detail-45"></a>

### 10.1 结构判断：半正定为何不保证最优点

**题目：** 对二维目标 $`f(x,y)=x^2-y`$，判断凸性、是否有最优点，以及把线性项删掉后的解集。解释 Hessian 给出和不给出的信息。

**解析：** Hessian 为对角元二和零的半正定矩阵，所以函数凸。但沿正向增大第二坐标，目标无界下降，没有最小值。删掉线性项后，所有第一坐标为零的点都最优，解不唯一。Hessian 描述曲率，却未捕捉零空间方向上的线性趋势；因此检查存在性必须同时检查目标全表达式、定义域和约束，不能仅凭最小特征值非负结束。

<a id="optimization-3-detail-46"></a>

### 10.2 严格与强凸：为什么四次方没有统一曲率

**题目：** 证明实数轴上的四次方严格凸却不是强凸，并解释是否影响唯一最优点。

**解析：** 它的一阶导是严格递增函数，因此可得严格凸；也可沿任意不同两点直接证明严格 Jensen 不等式。若有正强凸常数，在最优点零使用二次下界便要求四次方至少为某个正倍数的平方，但取足够小的非零点即可违反。因此没有统一强凸常数，最优点仍唯一为零。唯一性和局部二次增长并非同一性质，收敛速度分析不能仅依据解唯一。

<a id="optimization-3-detail-47"></a>

### 10.3 PL 条件：唯一解是否必需

**题目：** 最小化 $`\tfrac12x^2`$，参数为二维向量但目标不含第二坐标，说明它满足 PL 条件而不强凸。函数收敛是否要求第二坐标归零？

**解析：** 梯度范数平方为第一坐标平方，恰为两倍函数差，所以 PL 常数可取一。第二坐标完全平坦，强凸不可能成立，因为沿该方向没有二次增长。所有第一坐标为零的点都最优，因此只需到达最优集合，不必让第二坐标趋零。若算法保留初始第二坐标，只要目标和适当最优集距离已满足要求，就不该判为失败。

<a id="optimization-3-detail-48"></a>

### 10.4 Newton 反例：正定 Hessian 为什么还需回溯

**题目：** 对正文的平方根函数，分别从二、二分之一出发计算完整 Newton 步，并说明不同表现由什么条件决定。

**解析：** 更新为负的当前点立方，所以二变成负八，而二分之一变成负八分之一。前者幅度增大，后者幅度迅速缩小；两者 Hessian 都正定，差异来自初始点是否进入局部吸引区域。若初值绝对值恰为一，则两点来回循环不趋零。该例展示局部快收敛与全局安全是两件事，任何完整算法都需要说明初值区域或全局化策略。

<a id="optimization-3-detail-49"></a>

### 10.5 局部证明：不精确线性求解引入什么误差

**题目：** 若方向残差为 $`r=Hp+g`$，推导它对下一步误差的贡献，并说明为什么固定绝对容差会限制最终精度。

**解析：** 近似方向等于精确方向加 $`H^{-1}r`$，所以位置误差至多增加逆矩阵范数乘残差范数。若残差固定为一个很小但不变的数，随着原有二次余项趋小，这一项最终占主导，外层停在对应误差尺度。要保持二次速度，内层残差需要随梯度或误差继续缩小；同时过早使用极严容差会增加成本，因此应协调内外层精度。

<a id="optimization-3-detail-50"></a>

### 10.6 曲率修正：缩小步长能修复上升方向吗

**题目：** 在负平方函数的一点处，Newton 方向指向零。只把步长不断减半，能否满足通常的下降型 Armijo 条件？应怎样修改方向？

**解析：** 该方向与梯度内积为正，根本不是下降方向；充分小的正步长仍使目标上升，因此普通下降回溯的有限终止论证不适用。可以将曲率改为正数、退回负梯度，或用能处理负曲率的信赖域方法。这里原目标本身无下界，所以即使找到下降方向也不能期待有限最优解；方向修正与问题是否有解仍应分开。

进一步把“下降方向”与“满足 Armijo 不等式”区分开。取 $`f(x)=-x^2`$、$`x=1`$，Newton 方向为 $`p=-1`$，所以 $`g^Tp=2>0`$。Armijo 条件 $`f(1+\alpha p)\le f(1)+c\alpha g^Tp`$ 化为 $`\alpha\ge2(1-c)`$，并非对所有正步长都失败。若 $`0<c<\frac{1}{2}`$、初始步长为一并且只不断减半，则无法接受；但取 $`c=0.1`$、$`\alpha=1.9`$，新目标为 $`-0.81`$，高于旧目标 $`-1`$，却仍满足右侧为 $`-0.62`$ 的 Armijo 不等式。因此可靠的下降线搜索应先保证 $`g^Tp<0`$，再用充分下降条件验收；不能把这个不等式脱离方向前提，当作任意候选更新都下降的证书。

<a id="optimization-3-detail-51"></a>

### 10.7 BFGS：为什么正曲率对重要

**题目：** 用正文的逆更新式证明割线条件，并说明负的曲率内积为什么破坏正定性保证。

**解析：** 右侧第一个因子作用于曲率向量后为零，第二项作用后正好给位移，所以割线成立。若曲率内积负，更新中秩一项系数为负，正定性证明不再成立；更直接地，若新逆矩阵正定且满足逆割线，则曲率向量与其像的内积必为正，与负曲率内积矛盾。因此不是仅有某个证明技巧失效，而是这两个要求本身不能同时满足。

<a id="optimization-3-detail-52"></a>

### 10.8 乘子符号：同一约束换写法

**题目：** 等式约束分别写成总和减右端为零与右端减总和为零，原变量和乘子怎样变化？最优值灵敏度是否应改变？

**解析：** 原变量和可行域不变，约束梯度翻转，所以乘子也翻转，二者乘积在驻点中保持不变。对右端微分时，约束对参数的导数同样翻转，因此最优值导数保持一致。报告乘子必须同时报告约束表达式，否则单看正负无法判断增加右端会改善还是恶化目标。这也说明乘子不是与书写形式无关的独立物理量。

<a id="optimization-3-detail-53"></a>

### 10.9 约束资格：最优点为什么没有乘子

**题目：** 最小化线性函数且唯一可行点由平方不等式限制为零，解释为什么 KKT 无解并不推翻最优性。怎样更换等价表示来恢复正常法向？

**解析：** 唯一可行点当然全局最优，但平方约束边界梯度为零，不能平衡目标非零梯度，所以常规 KKT 无乘子。这是约束资格失败。若改成等式变量为零，其梯度非零，取适当自由乘子即可满足驻点。等价集合可以有不同微分正则性，建模时尽量使用能反映局部几何的约束表达，是优化实现的重要组成部分。

<a id="optimization-3-detail-54"></a>

### 10.10 凸证书：KKT 充分性是否依赖 Slater

**题目：** 已找到凸问题的可行 KKT 点，但无法找到严格可行点。能否仍证明全局最优？给出逻辑依据。

**解析：** 可以，只要目标和不等式凸、等式仿射且乘子符号与互补都正确。固定这些乘子后，拉格朗日函数凸，驻点使其全局最小；在其他可行点它不超过目标，在候选处又等于目标，所以形成全局比较链。Slater 常用于保证乘子存在与强对偶，而不是这个已获得证书的充分性证明必不可少的前提。必要性与充分性应分别检查。

<a id="optimization-3-detail-55"></a>

### 10.11 活跃与正乘子：零乘子为什么可能合理

**题目：** 最小化平方函数且变量不大于零，求最优点和乘子，并描述临界方向。为何不能把边界活跃直接等同于正压力？

**解析：** 最优点为零，驻点要求乘子零，约束仍活跃。线性化可行方向为非正方向，目标一阶导为零，所以它们均为临界方向；目标二阶导为正，说明这些方向均二阶增长。活跃只描述位置在边界，乘子是否正还取决于目标梯度平衡。数值上很小的乘子也可能使活跃识别敏感，应结合残差与问题尺度判断。

<a id="optimization-3-detail-56"></a>

### 10.12 二阶约束曲率：目标线性为何能有严格极小

**题目：** 在单位圆上最小化纵坐标，用拉格朗日 Hessian 和局部参数化分别解释底部是严格极小，顶部是严格极大。

**解析：** 底部乘子正二分之一，切向曲率为正；顶部乘子负二分之一，切向曲率为负。直接消去纵坐标时，下半圆在横向小位移下纵坐标增加二次项，上半圆则减小二次项。两条分析一致，说明决定可行二阶变化的是目标与约束共同构成的几何。只计算线性目标的零 Hessian 会漏掉全部信息。

<a id="sec-6-1"></a>

<a id="optimization-3-detail-57"></a>

### 10.13 边界追问：满足驻点与可行条件是否已足够

**题目：** 无约束三次函数在零满足梯度为零且 Hessian 半正定，能否判为局部最优？若改成凸问题，证据链有何不同？

**解析：** 不能，任意小的负方向都降低函数，零 Hessian 让二阶必要条件没有区分力，必须看高阶或直接比较。凸问题的一阶下界能将驻点提升为全局证书；有约束时还需完整 KKT，而不仅原始可行和驻点。二阶必要条件失败可以排除候选，通过却不一定确认；严格二阶充分条件与凸充分证书才各自提供对应范围的肯定结论。

<a id="optimization-3-detail-58"></a>

### 10.14 对偶间隙：怎样把结果变成误差上界

**题目：** 原始可行点目标为二点零五，对偶合法乘子给下界一点九九，能对全局最优值与当前误差作什么判断？如果原始点略微不可行，还能直接使用吗？

**解析：** 全局最优值在一点九九与二点零五之间，当前可行目标的次优差至多零点零六。这不要求最优参数唯一。若原始点不可行，其目标不一定是合法上界，原始对偶差便失去该解释；需先构造可行点、给出可行修复界，或使用专门考虑残差的证书。数值上“约束只差一点”能否接受，应由尺度和业务容差明确，而不是默默当作精确可行。

<a id="optimization-3-detail-59"></a>

### 10.15 研究设计：比较方法时怎样计算成本

**题目：** Newton 十步、梯度下降一百步，是否足以证明前者快？给出能回答实际计算问题的比较方案。

**解析：** 不足以。应固定目标误差或可行证书阈值，分别记录函数、梯度、HVP 和分解次数，报告内存、墙钟与硬件条件；回溯拒绝和内层迭代也计入成本。若比较不同规模，观察稀疏性和通信是否改变主要瓶颈。外层步数描述算法进展的一种单位，而用户真正关心的时间与资源，需要结合每步计算结构解释。

<a id="optimization-3-detail-60"></a>

## 11. 从局部方法走向可靠研究

<a id="optimization-3-detail-61"></a>

### 11.1 用四种残差描述约束解

原始可行残差检查等式偏离和不等式正部，驻点残差检查拉格朗日梯度，互补残差检查乘子与约束值的乘积，双重可行残差检查不等式乘子是否为负。四者作用不同，一个总范数可能掩盖某个单位尺度特别大的分量。报告时应明确使用绝对还是相对尺度，并逐类列出，而不是只打印求解器返回的一个成功标签。

残差小也不自动给原变量误差小：约束 Jacobian 或 KKT 矩阵病态时，小残差可能对应较大位置误差。局部误差界需要正则性和条件数控制；全局非凸问题还可能存在多个低残差驻点。若目标是可部署的可行解，需要额外关注硬约束容差，而若目标是数学证明，还应提供解析条件或可验证上下界。

<a id="optimization-3-detail-62"></a>

### 11.2 参数化与缩放改变数值难度

约束缩放首先要保持可行集合。对等式 $`h(x)=0`$，任意非零常数 $`c`$ 都给出等价式 $`ch(x)=0`$，乘子变为 $`\frac{\nu}{c}`$。对固定方向的不等式 $`g(x)\le0`$，$`cg(x)\le0`$ 仅在 $`c>0`$ 时与原式等价，乘子变为 $`\frac{\lambda}{c}\ge0`$。若乘负数，必须同时反转不等号；仍保留小于等于零会换成另一侧可行域。

例如最小化 $`x^2`$ 且 $`1-x\le0`$，最优点为 $`x=1`$，KKT 乘子为 $`2`$。改写成 $`10(1-x)\le0`$ 后，最优点不变而乘子为 $`0.2`$；若误改成 $`-(1-x)\le0`$，可行域成了 $`x\le1`$，最优点便变成 $`0`$。缩放的单位解释与乘子敏感性可对照 [Boyd 与 Vandenberghe 第 5 章](https://www.seas.ucla.edu/~vandenbe/cvxbook/bv_cvxbook.pdf)。

合法缩放仍会改变 Jacobian、乘子和 KKT 系统条件数。把原变量换单位也会改变梯度与 Hessian 的数值尺度。因此可以合理缩放变量、目标与约束，同时记录映射，以便把乘子和误差转换回原单位。

这种缩放不能当作修改问题的借口。若不同目标项乘了不相同的系数，通常已经改变偏好；若约束容差在缩放后未同步转换，也可能放宽或收紧实际可行标准。严谨实验应先证明表示变化与原问题等价，再讨论它带来的数值收益。前两章的状态对齐与本章的几何对齐在这里汇合：实现比较必须从同一个数学对象开始。


<a id="optimization-3-detail-63"></a>

## 12. 进阶专题：活跃切换、障碍路径与惩罚

<a id="optimization-3-detail-64"></a>

### 12.1 一个随参数切换活跃集的二次问题

考虑最小化 $`\tfrac12[(x-2)^2+(y-a)^2]`$，约束为 $`x\ge0`$、$`y\ge0`$、$`x+y\le1`$。它等于把点 $`(2,a)`$ 投影到一个闭三角形。目标强凸、可行域紧且凸，因此每个实数参数都存在唯一原变量解。取总和上界乘子为 $`\lambda`$，两个非负约束乘子为 $`\mu_x,\mu_y`$，驻点为 $`x-2+\lambda-\mu_x=0`$、$`y-a+\lambda-\mu_y=0`$。

当 $`a\le1`$ 时，候选为 $`(1,0)`$。总和约束及第二坐标下界活跃，第一坐标下界不活跃，所以 $`\mu_x=0`$、$`\lambda=1`$、$`\mu_y=1-a\ge0`$。全部 KKT 成立，故这是唯一全局解。当 $`1<a<3`$ 时，两坐标均正，下界乘子都为零；解总和与两条驻点得到 $`x=\frac{(3-a)}{2}`$、$`y=\frac{(a-1)}{2}`$、$`\lambda=\frac{(a+1)}{2}`$，它们恰在该参数区间内保持可行。

当 $`a\ge3`$ 时，解为 $`(0,1)`$，由第二坐标驻点得 $`\lambda=a-1`$，第一坐标下界乘子为 $`a-3`$，仍全为非负。两个阈值处原变量连续，但相对于参数的导数发生切换；对应即将加入或释放的约束乘子为零。这个例子说明“活跃约束有零乘子”并非孤立异常，而是解分支切换的自然位置。若对这种解映射求超梯度，应说明采用哪一侧或何种广义导数，不能在切换点强行引用普通隐函数定理。

<a id="optimization-3-detail-65"></a>

### 12.2 对数障碍怎样把边界变成可追踪路径

对凸问题，严格可行域内可定义障碍目标 $`t f(x)-\sum_{i=1}^m\log[-g_i(x)]`$，同时保留仿射等式。正参数 $`t`$ 越大，原目标相对障碍越重要，解通常越接近边界最优点。障碍不是简单给不可行点一个大但有限的惩罚，而是在边界处发散，并且只在严格可行域有定义；初值和线搜索必须保留这个定义域。

若精确求出某个障碍子问题的驻点，定义 $`\lambda_i=-\frac{1}{[t g_i(x)]}>0`$，并把障碍等式乘子除以 $`t`$，即可得到原拉格朗日驻点。互补乘积此时不是零，而是统一为负的 $`\frac{1}{t}`$。在凸条件下，该驻点使原拉格朗日函数达到下确界，因而原始与对偶间隙恰为 $`\frac{m}{t}`$。这是中心路径的一个明确误差刻度，不应把子问题已收敛直接等同于原问题已达到精确 KKT。

实际内层只近似求解时，间隙关系需要加入残差影响，不能照搬精确表达。随着障碍参数增大、解靠近边界，Hessian 可能越来越病态，所以“把参数设得极大”未必数值上最好；路径跟踪通过一系列子问题逐渐推进，并用上一解初始化下一问题。每个内层 Newton 步还要同时检查目标下降与严格可行性，这展示了局部曲率、全局化及约束几何怎样在同一算法中协作。

<a id="optimization-3-detail-66"></a>

### 12.3 二次惩罚与增广拉格朗日的角色区别

等式约束可用 $`f(x)+(\frac{\rho}{2})\Vert h(x)\Vert ^2`$ 形成二次惩罚。但有限惩罚一般不保证精确可行。最小化 $`\frac{(x-2)^2}{2}`$ 且要求 $`x=0`$，惩罚解为 $`x=\frac{2}{(1+\rho)}`$，只有当惩罚参数趋无穷才趋于可行。若直接把某个有限惩罚解当作原始可行上界，会破坏前面原始对偶证书的逻辑。

惩罚参数增大还会在约束法向引入越来越大曲率，使无约束子问题病态。增广拉格朗日在惩罚项之外加入乘子线性项，并通过外层乘子更新积累约束信息，目标是在不把惩罚无限推大的情况下逐步实现可行和驻点。它与普通拉格朗日对偶、纯二次惩罚存在联系，但更新规则与内层求解精度决定实际算法，不能仅写一个带平方的损失就宣称实现了完整方法。

对不等式不能机械地把全部约束值平方：严格满足约束的负值也会被惩罚，从而把最优偏好推向边界。可以使用正部惩罚或引入松弛变量等适当构造，随后重新分析可微性和乘子更新。设计新约束算法时，先检查它是否惩罚了本应允许的内部点，是一项非常有效的基本审查。

<a id="optimization-3-detail-67"></a>

### 12.4 数值边界：容差、退化与证书可信度

阈值附近的活跃集可能因舍入而改变，但原变量和目标差仍很小。因此验收不应只比较活跃标签是否完全相同，而应同时比较原始点、乘子残差和目标证书。反之，两个程序给出相同活跃集，也不保证数值解接近；若约束近线性相关，乘子可以非常敏感，需检查 KKT 系统条件数或约化曲率。

在近退化问题上，报告一个乘子的小数位数并不能表示它的可信精度。可轻微扰动数据、约束右端或缩放，观察证书与原变量是否稳定，并把变化与理论灵敏度对应。这不是以随机扰动代替证明，而是识别模型与数值表达是否支持所宣称的精度。若下游决策依赖乘子排名，更应关注单位、相关约束和扰动范围，而不仅看求解器输出的排序。

<a id="optimization-3-detail-extra-1"></a>

### 12.5 信赖域困难情形的可手算证书

用一个二维子问题具体展示为什么不能把信赖域总写成普通求逆。取线性项 $`g=(0,1)`$，Hessian 为 $`\operatorname{diag}(-2,1)`$，半径为一。无约束 Newton 方程给方向 $`(0,-1)`$，它虽在球面上，却只利用第二坐标，模型值为负二分之一。第一坐标存在负曲率，球内还允许利用它取得更低值，单纯解原方程没有找到子问题最小点。

取信赖域乘子为二，则移位矩阵为 $`\operatorname{diag}(0,3)`$，它半正定但奇异。方向方程要求第二坐标为负三分之一，第一坐标不受线性方程约束；再用球面条件可选第一坐标为正或负的 $`\frac{\sqrt8}{3}`$。这两个方向都满足移位方程、球约束、非负乘子与互补条件，模型值为负六分之七，即 $`-\frac{7}{6}`$，严格小于原 Newton 方向的值。

可以直接证明全局性，不必依赖直觉。若候选为 $`p_*`$、移位乘子为 $`\tau`$，任意可行 $`p`$ 与候选的模型差可整理为 $`\tfrac12(p-p_*)^T(H+\tau I)(p-p_*)+\tfrac\tau2(\Vert p_*\Vert ^2-\Vert p\Vert ^2)`$。前一项因移位矩阵半正定而非负，后一项因候选在球面且其他点不超半径而非负，故候选全局最优。这个恒等式也解释了为什么奇异矩阵不妨碍最优证书，却妨碍简单求逆实现。

困难来自梯度与最负曲率特征方向正交，沿该方向的位移必须由边界条件补上。若把奇异方程只取最小范数解，会得到球内的 $`(0,-\frac{1}{3})`$，遗漏负曲率方向，从而不是最优。实际信赖域求解器需要处理这种情况或足够近的数值情形。该例说明求线性方程、找模型驻点、满足半径约束和证明子问题全局最优，确实是不同层次。

```python
import numpy as np
H = np.diag([-2.0, 1.0])
g = np.array([0.0, 1.0])
p = np.array([np.sqrt(8.0)/3.0, -1.0/3.0])
tau = 2.0
model = lambda q: g@q+0.5*q@H@q
assert np.isclose(np.linalg.norm(p), 1.0)
assert np.allclose((H+tau*np.eye(2))@p, -g)
assert np.linalg.eigvalsh(H+tau*np.eye(2)).min() >= 0
assert np.isclose(model(p), -7.0/6.0)
p_newton = np.linalg.solve(H, -g)
assert model(p) < model(p_newton)
print('trust-region / raw Newton model:', model(p), model(p_newton))
```

这里的数值断言核对解析证书中的每一项，不以有限网格搜索代替全局证明。半径若改变，最优乘子和负曲率位移也会变化，应重新求解，而不是把这一组方向用于所有大小的球。对真实非二次目标，这仍只是局部模型子问题最优，完整算法还需根据真实下降决定是否接受候选。
