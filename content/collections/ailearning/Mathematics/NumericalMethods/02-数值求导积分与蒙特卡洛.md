# 第 2 章 数值求导、积分与蒙特卡洛

[主题目录](README.md) · [分类目录](../README.md) · [总目录](../../README.md) · [上一章](01-浮点误差条件数与稳定计算.md) · [下一章](03-线性系统条件数与病态问题.md)

数值求导和数值积分都用有限次函数调用近似连续数学对象，但它们放大误差的方式截然不同。求导需要从相近数中提取微小变化，容易放大函数值噪声；积分通常累积整体信息，却可能漏掉窄峰、奇点与振荡。蒙特卡洛则把积分变成抽样平均，需要用随机误差而非确定网格阶数解释可靠性。

本章在[微积分的泰勒余项](../Calculus/02-积分泰勒展开与曲率.md)与上一章浮点模型基础上，完整推导常用公式、误差阶和计算预算。关于随机采样的完整概率论证，可配合[概率论第四章](../Probability/04-采样大数定律与蒙特卡洛推断.md)；本章侧重它们与确定积分、离散化及函数调用成本的关系。自适应算法的状态、停止与失败处理留在第四章，这里不把一个误差估计数字当作自动认证。

## 1. 有限差分：从局部展开到可计算公式

<a id="numerics-2-detail-1"></a>
### 1.1 先说明求的是哪个导数

给定函数值计算器，我们希望近似 $f'(x)$。这里至少有三个对象：理想数学函数、实现函数值的程序，以及在浮点输入上执行的具体计算。若函数值程序本身使用有限网格、近似求解器或随机样本，差分首先反映这个实现的变化，不会自动消除内部误差。验证时先明确目标，才能解释差分与解析导数不一致的原因。

例如计算一个期望的导数，若每次函数调用重新抽样，差分分子同时包含参数变化与抽样变化；若固定样本，则计算的是该样本平均的局部导数。二者都可能服务于研究，却具有不同偏差与方差。又如内层求解器只迭代十次，差分比较的是十次迭代结果，未必是精确最优值函数。不能仅因为表达式写着同一个 f，就忽略了函数计算器的状态与精度。

多变量问题还需要选择对象。逐坐标差分计算梯度需要随维度增加调用次数，方向差分只需少量调用，却只检查梯度在该方向的投影。若方向与某个错误分量正交，检查可能通过。完整梯度检查的语义已在微积分实践章展开；本章进一步说明其误差常数为什么依赖方向、坐标尺度和函数值噪声。

<a id="numerics-2-detail-2"></a>
### 1.2 前向与后向差分的余项

假设 f 在 x 附近二次连续可微。泰勒公式给出 $f(x+h)=f(x)+hf'(x)+\tfrac12h^2f''(\xi)$，其中中间点位于 x 与 x+h 之间。除以非零 h 得到前向差分 $D_+(h)=[f(x+h)-f(x)]/h$，误差为 $\tfrac12hf''(\xi)$。如果邻域二阶导绝对值不超过 M，那么截断误差不超过 $M|h|/2$。

后向差分 $D_-(h)=[f(x)-f(x-h)]/h$ 的主误差符号相反。在 x 位于定义域左边界时，不能任意调用 x-h，因此单侧公式往往是合法选择。阶数较低不等于方法错误，必须同时满足定义域和可调用条件。为了追求中心差分而把非法输入截断，实际上会改变差分公式及其导数含义。

这里的 $O(h)$ 是当 h 趋零且函数及邻域固定时的渐近描述，隐含常数与二阶导有关。对于曲率极大的函数，某个看起来很小的 h 仍可能不在近似区间。对于 x 很大而 h 小于该点浮点间距，程序甚至不能形成不同输入。理论中的任意实数 h 与机器可表示扰动是两个层次，实验必须同时检查。

<a id="numerics-2-detail-3"></a>
### 1.3 中心差分为何消去偶次项

若 f 三次连续可微，分别在 x 两侧展开并相减，常数项和二阶项抵消，得到 $D_0(h)=[f(x+h)-f(x-h)]/(2h)=f'(x)+O(h^2)$。更具体地，对两侧三阶余项取界，可以得到 $|D_0(h)-f'(x)|\le M_3h^2/6$，其中 $M_3$ 是邻域三阶导上界。公式的二阶精度来自对称性，而非分母里多了一个二。

若进一步光滑，可写 $D_0(h)=f'(x)+h^2f^{(3)}(x)/6+O(h^4)$。奇数次导数留在分子中，偶数次项被相减抵消；再除以 h 后产生偶次误差序列。该展开为外推提供依据，但它比单纯二阶误差界要求更多光滑性。不能只知道三阶导有界，就任意使用四阶外推余项。

对 $f(x)=x^3$，中心差分可直接展开成 $3x^2+h^2$。这不是近似主项，而是精确实数恒等式。因此它特别适合核对实现是否真的使用两侧、分母是否为二 h，以及误差阶是否符合预期。若程序在温和 h 范围内不表现出 h 平方误差，先检查实现与输入，而不是立即责怪浮点随机性。

<a id="numerics-2-detail-4"></a>
### 1.4 从矩条件设计更高阶差分

一般线性差分可以写成 $D_hf=h^{-1}\sum_jw_jf(x+c_jh)$。将泰勒级数代入，要正确提取一阶导，应满足 $\sum_jw_j=0$、$\sum_jw_jc_j=1$；若还希望抵消更高项，需要 $\sum_jw_jc_j^k=0$。这些条件把公式构造变成一个关于权重的线性系统，也解释了节点位置如何决定阶数。

例如五点对称公式为 $[f(x-2h)-8f(x-h)+8f(x+h)-f(x+2h)]/(12h)$。它的常数到四阶相应矩满足要求，在足够光滑时截断误差为四阶。代价是更多函数调用、更大系数绝对值和更广的调用邻域。若函数值带噪，大权重可能放大噪声，因此高阶并不是无条件更准确。

更高阶公式的系数求解也有数值问题。节点极端聚集或间距差异很大时，直接解幂次矩阵可能病态；生产实现通常需要更合适的权重算法。教学中推导矩条件是为了理解机制，不建议在任意维度和节点上盲目形成一个高次 Vandermonde 系统。方法选择必须同时考虑公式误差与构造误差。

<a id="deep-dive-1"></a>
### 深入讲解：误差随步长变化为何常呈 U 形

假设程序返回 $\widehat f(t)=f(t)+e(t)$，且有关调用的绝对误差不超过 $\eta$。前向差分中的函数值误差最多贡献 $2\eta/|h|$；中心差分因为分母为二 h，对两次误差取绝对上界后贡献 $\eta/|h|$。当 h 减小时，截断误差下降，但函数值误差除以 h 被放大，这就形成常见的先改善后恶化现象。

对于正常范围内的稳定函数值实现，可以粗略取 $\eta\approx uF$，F 是附近函数值的绝对尺度。然而 f 接近零、内部有相消或迭代误差时，这个模型未必合适；噪声求解器也可能有远大于 uF 的误差。误差模型应从函数计算器本身来，而不是看到 dtype 就默认所有函数值都满足一个统一相对界。

在前向模型 $Ah+B\eta/h$ 中，求导使两项平衡，得到 $h_\star=\sqrt{B\eta/A}$。中心模型 $Ah^2+B\eta/h$ 则给出 $h_\star=(B\eta/(2A))^{1/3}$。因此常见的平方根与立方根尺度只是特定误差模型的结果，还包括导数常数、函数量级与输入单位。把一个无量纲机器精度直接当成任意物理变量的步长，在量纲上也不完整。

<a id="sec-2"></a>
## 2. 数值积分：公式、精确性与余项

<a id="numerics-2-detail-5"></a>
### 2.1 插值后积分与多项式精确度

数值积分的一个基本思路是在少量节点上构造简单插值函数，再精确积分该插值函数。梯形法使用一次插值，中点法使用区间中心值形成矩形，Simpson 法用三点二次插值。公式的多项式精确度描述它对哪些多项式完全正确；它不是说一般函数也会精确，而是帮助恢复误差依赖的高阶变化。

设区间长度为 h，梯形公式 $T=h[f(a)+f(a+h)]/2$ 对一次及以下多项式精确，中点公式 $M=hf(a+h/2)$ 也对一次多项式精确。两者节点不同，对同一个弯曲函数偏差方向往往相反。Simpson 在两小段总长二 h 上使用 $S=h[f(a)+4f(a+h)+f(a+2h)]/3$，不仅对二次精确，由于对称性也对三次精确。

公式前的区间宽度不能省略。函数值有某种单位时，积分再乘输入单位；如果仅对函数值取平均，得到的是平均高度，只有再乘区间长度才是积分。均匀抽样蒙特卡洛也有同样因子。本章反复保留该尺度，是因为很多数值程序在单位区间测试通过，换到一般区间就出现系统性倍数错误。

<a id="numerics-2-detail-6"></a>
### 2.2 梯形误差的可检查推导

在一小段 $[a,a+h]$ 上，线性插值多项式记为 p。如果 f 二次连续可微，插值余项为 $f(x)-p(x)=\tfrac12 f''(\xi_x)(x-a)(x-a-h)$。因 $\xi_x$ 随 x 变化，不能直接把它当作固定常数，但取绝对值并用二阶导上界 M 后可以积分。区间内二次乘积非正，其绝对值积分为 $h^3/6$，因此单段误差不超过 $Mh^3/12$。

在总长 L 的区间上划分 n 段，步长 $h=L/n$。把各段界相加，复合梯形误差不超过 $LMh^2/12$，也就是全局二阶。单段三阶误差乘上约一除以 h 的段数，才得到全局二阶；混淆局部与全局阶数，是很多误差推导的常见问题。

如果 f 在整个区间凸，真实曲线位于每段弦线下方，因此梯形值不小于真实积分。这种几何符号检查可以帮助发现权重或节点错误，但不能取代大小界。对于凹函数方向相反；当曲率变号时，总误差可能抵消，实际收敛看起来更快，不能据单个实例就给公式更高的通用阶数。

<a id="sec-1-1"></a>
### 基础算例：梯形公式的网格与误差逐次比较

对 $\int_0^1x^2dx=1/3$，单段梯形为二分之一，误差六分之一；两段梯形为八分之三，误差二十四分之一。一般 n 段可以利用平方和公式得到 $T_n=1/3+1/(6n^2)$。因此 n 翻倍，误差恰好缩小四倍，而不是仅在极限中接近四倍。

这个算例同时提供三层核验：权重正确时能恢复具体积分值；不同 n 的误差比例应为四；凸函数的梯形结果应偏大。若只检查其中一条，可能漏掉某种错误。例如某个整体比例错误在比较两次差值时未必立即暴露；偶然接近真值也不能证明端点权重正确。选择解析算例应让多种独立性质同时可观察。

<a id="numerics-2-detail-7"></a>
### 2.3 中点法与梯形法的不同偏差

在每小段中心展开，奇次项积分为零，二次项贡献决定主误差。若 $|f''|\le M$，复合中点法的绝对误差不超过 $LMh^2/24$，其常数是梯形对应界的一半。对凸函数，中点值偏低，梯形值偏高，二者有时可构成一个直观包围；但严格包围依赖凸性在整个区间成立。

这不意味着中点在所有任务上支配梯形。梯形网格在加密时方便复用旧节点，已有采样数据常恰好位于端点网格；周期平滑函数的梯形法还可能因边界项抵消呈现更快收敛。方法优劣需要结合数据获得方式、节点复用、函数结构与预算。单看常数二十四比十二大，不足以完成公平比较。

<a id="numerics-2-detail-8"></a>
### 2.4 Simpson 误差为何是全局四阶

在对称标准区间 $[-1,1]$，定义误差泛函 $L(f)=\int_{-1}^1f(x)dx-[f(-1)+4f(0)+f(1)]/3$。因为它消去所有三次及以下多项式，可以把四阶泰勒积分余项代入，得到 $L(f)=\int_{-1}^1K(t)f^{(4)}(t)dt$。这一步把高阶余项变成核与四阶导的加权积分，避免把一个随 x 变化的中间点直接提出积分。

核的表达可以直接从积分余项恢复。把函数写成三次多项式加上 $\int_{-1}^1f^{(4)}(t)(x-t)_+^3dt/6$，其中正部表示只在 t 小于 x 时保留。误差泛函消去多项式，将余项中的求积与积分交换，便得到 $K(t)=(1-t)^4/24-2(-t)_+^3/9-(1-t)^3/18$。这里交换的是紧区间上的连续积分余项，不涉及未经检查的无穷级数。

当 t 非负时，中间的正部项消失，提取公因式即可得到下一段的负核。负半轴由节点及积分区间的对称性获得相同表达；将两半积分，就能核对负九十分之一的常数。读者还可代入四次多项式：真实积分为五分之二，Simpson 为三分之二，差为负十五分之四，除以恒定四阶导二十四，恰好恢复核积分。这是对抽象推导的独立手算检查。

对 $0\le t\le1$，核为 $K(t)=-(1-t)^3(1+3t)/72$，负半轴由偶对称得到。可以直接验证核非正，且积分为负九十分之一。于是 $|L(f)|\le\|f^{(4)}\|_\infty/90$。若四阶导连续，还能用加权中值定理写成 $L(f)=-f^{(4)}(\xi)/90$。这既给出了阶数，也交代了误差符号的来源。

把标准区间缩放到半宽 h 的两段面板，积分多一个 h，四阶导缩放多出 $h^4$，故单面板误差界为 $M_4h^5/90$。总区间长度 L、有偶数 n 个小段时，面板数为 $L/(2h)$，复合 Simpson 界为 $LM_4h^4/180$。所以这里 h 指相邻采样点距离，而不是整个三节点面板宽度；定义不同会让公式常数相差十六倍。

上述推导假设四阶导有界。对尖点、跳变或端点奇异函数，不能照搬四阶结论。即便函数很光滑，若主误差项恰好为零，观测阶数也可能更高；若尚未进入渐近区间，有限网格比例可能偏离十六。公式阶数、特定函数表现和实际误差估计是三个相关但不同的概念。

<a id="sec-2-1"></a>
### 机制展开：积分误差还依赖区间长度和光滑性

同样步长 h，区间从一米延长到一百米，局部误差要累积更多次；同样区间，二阶导扩大一千倍，梯形误差常数也相应变化。把“二阶”理解为只由节点数决定精度，会忽略这些最主要的尺度。实际设计应同时给出区间、导数界或结构信息、节点数与函数调用精度。

复合公式是在近似积分精确函数值。如果每个节点值都带有绝对误差不超过 eta，且权重非负、权重和为 L，那么额外积分误差不超过 $L\eta$，不会像求导那样出现一除以 h 的显式放大。可是大量求和仍有舍入，权重构造也有误差；高阶公式若含负权重，误差传播还与权重绝对值和有关。不能从“积分平滑噪声”推出任意数值积分都无条件稳定。

<a id="numerics-2-quadrature-conditioning"></a>
### 2.5 求积权重、条件量与抵消积分

对给定节点的线性求积 $Q=\sum_iw_if_i$，如果每个函数值的绝对扰动不超过 eta，输出扰动上界为 $\eta\sum_i|w_i|$；若每个值具有相对扰动上界 epsilon，则界变为 $\varepsilon\sum_i|w_if_i|$。当 Q 非零时，再除以其绝对值，可以得到这个离散问题的分量相对条件量。这与前章求和条件数是同一个机制，只是权重把节点值重新缩放。

梯形、复合中点和标准复合 Simpson 的权重都非负，权重和为区间长度，因此对统一绝对函数值误差具有清楚的控制。某些高次插值求积会出现负权重，使权重绝对值和大于区间长度；它们可能有更高多项式精确度，却对节点误差更敏感。不能仅因插值多项式次数增加，就认为算法在带噪数据上一定更可靠。

还要区分求积公式的稳定性与积分本身的相对条件。正负大面积相互抵消时，真实积分可能很小，即使每一段面积都算得很好，最终相对误差仍可能很大。此时报告绝对误差、被积函数绝对积分或贡献绝对值和，比只报告相对百分比更有解释力。改变节点或提高累积精度能减少算法误差，却不能恢复原函数值测量中已经丢失的抵消信息。

<a id="sec-3"></a>
## 3. 奇异、振荡与高维积分的结构

<a id="numerics-2-detail-9"></a>
### 3.1 端点奇异：先换元再讨论阶数

积分 $\int_0^1x^{-1/2}dx=2$ 是收敛的，但被积函数在零点没有有限值。包含端点的普通梯形或 Simpson 不能直接调用该点，更不能把无穷替换成零后继续宣称使用原公式。可以使用适合奇异权重的方法，也可以换元 $x=t^2$，得到 $x^{-1/2}dx=2dt$，转为光滑常数积分。

这个换元的收益不仅是避免异常，还改变了误差常数和光滑性。对更一般 $x^{-\alpha}g(x)$、零小于 alpha 小于一，可尝试用幂次换元削弱奇性，但是否足够光滑需要重新检查变换后的函数。选择 t 的幂时应同时变换雅可比，省略它会求解另一个积分，即使输出看起来稳定也没有意义。

对于 $\int_0^1\sqrt{x}\,dx=2/3$，函数值在端点有限，但二阶导发散，梯形二阶上界仍不适用。换元 $x=t^2$ 后积分变为 $\int_0^1 2t^2dt$，Simpson 可以精确处理这个二次多项式。这个例子说明“没有 NaN”与“满足误差阶前提”不是同一件事。

<a id="numerics-2-detail-10"></a>
### 3.2 振荡积分与采样混叠

对 $f(x)=\cos(2\pi nx)$ 在单位区间积分，真实值为零。若恰好取 n 个等距小段的端点，所有采样值理论上都是一，梯形结果却是一。函数无限光滑，为什么没有违背误差界？因为其高阶导随频率 n 增长，误差常数同步变大；这里在加密网格的同时也改变了函数，不能套用“固定函数、h 趋零”的结论。

这个例子揭示有限采样可能完全看不见振荡。仅看相邻采样值平坦，不能证明函数在节点之间平坦。已知频率时应采用足以分辨周期的采样或适合振荡结构的积分法；未知结构时，多种节点、随机探测或结构先验可以补充证据，但有限节点始终不能无条件认证任意函数。

若用 $\sin(\omega x)$、$\cos(\omega x)$ 的解析积分作为参考，近零结果应使用绝对误差，避免把除以几乎为零的参考值当成相对精度。大频率下解析参考本身也可能涉及三角函数参数约化，应选可独立验证的频率与区间。所谓解析答案也需要检查其数值实现，不能只因公式短就假定完全准确。

<a id="numerics-2-detail-11"></a>
### 3.3 窄峰、跳变与先验分段

一个很窄的峰如果落在所有节点之间，粗网格和细网格都可能给出接近零的值，从而相互一致却共同错误。对于已知峰位置、分段点或边界层，先分段或变换变量通常比盲目增加全局均匀节点有效。节点应服务于函数结构，不能把加密当成唯一可调整的旋钮。

跳变函数的积分仍可能存在，但光滑误差阶在跨越跳变的小段失效。如果跳变位置已知，把区间从该处分开，分别在光滑子区间使用公式，就可能恢复各段应有的阶数。若位置未知，误差估计要承担发现结构的任务，有限调用下也存在遗漏风险。第四章会据此讨论何时只能返回“预算耗尽而未证实达到精度”。

<a id="numerics-2-detail-12"></a>
### 3.4 张量积网格与有效维度

对 d 维盒子积分，如果每个轴使用 m 个节点，完整张量网格的节点数约为 $m^d$。即使每轴的离散误差阶不错，维度增长也会使预算迅速不可承受。这是蒙特卡洛常被考虑的原因之一，但不能简单说高维必选随机法：可分离结构、低有效维度、稀疏网格和变量变换都可能显著改变成本。

比较时先明确精度依赖于哪个函数类。一个高维但实际只依赖前两个坐标的函数，与一个由所有坐标共同决定罕见事件的函数，难度完全不同。规则网格成本爆炸是某种直接构造的事实，不是关于所有确定积分算法的不可突破定理。随机法的误差阶虽然不显式含 d，方差常数却可能随 d 极端恶化。

<a id="sec-4"></a>
## 4. 蒙特卡洛：误差分解与同成本比较

<a id="numerics-2-detail-13"></a>
### 4.1 从积分写成期望并保留权重

在有限区间 $[a,b]$ 上，若 $U$ 均匀分布，$I=\int_a^bf(x)dx=(b-a)E[f(U)]$，所以估计量为区间长度乘样本平均。独立同分布且二阶矩有限时，其方差为 $(b-a)^2\operatorname{Var}(f(U))/n$。这个公式同时说明误差量级、单位和区间因子，不能只背“标准误等于一除以根号 n”。

更一般地，若从密度 q 抽样，积分可写成 $E_q[f(X)/q(X)]$，前提是 q 覆盖 f 有贡献的区域，并有相应可积性。方差是否有限还取决于 $\int f(x)^2/q(x)dx$。无偏不等于高效，密度在重要区域太小时，权重可以极端集中。本书概率论第四章已详细推导重要性与自归一化估计，这里只保留选择积分方法所需的关键条件。

<a id="numerics-2-detail-14"></a>
### 4.2 有限方差下的均方误差

若 $Y_i$ 独立同分布，均值为 I、方差为 sigma 平方，样本均值无偏，且方差为 sigma 平方除以 n。因此均方误差恰为该值，均方根误差为 sigma 除以根号 n。这个结论不是渐近近似，而是有限样本的二阶矩恒等式；把它解释为正态置信区间，则需要另外的分布近似或概率工具。

样本标准差除以根号 n 是标准误的估计，不是本次实际绝对误差，也不是一个确定上界。一次结果离真值两个标准误并不自动说明代码错误；在理想正态近似下这类事件仍有非零概率。验证随机算法应考虑多次独立重复、理论方差与覆盖比例，不能把“每次都落在一个标准误内”作为应该通过的测试。

如果想把标准误缩小十倍，在方差不变时需要一百倍独立样本。这使降低方差或利用函数结构可能比单纯增加 n 更有价值。但降方差方法若增加每个样本计算成本，公平比较应按实际预算衡量，而不是只看样本数。抽样、密度计算、控制变量拟合与内层求解都可能占成本。

<a id="numerics-2-detail-15"></a>
### 4.3 离散化偏差与抽样误差同时存在

很多应用并不能直接计算真实 f，而是计算步长为 h 的近似 $f_h$。估计量 $\widehat I_{h,n}$ 相对真实 I 可以拆成 $[\widehat I_{h,n}-I_h]+[I_h-I]$，其中 $I_h=E[f_h]$。前一项是随机波动，后一项是离散化偏差。即使 n 趋于无穷，第二项也不会消失。

若抽样估计对 $I_h$ 无偏且方差有限，均方误差为 $b(h)^2+\sigma_h^2/n$，这里 $b(h)=I_h-I$。因此把样本数增加到极大却不细化内层网格，可能只是在更精确地估计一个有偏目标。反过来，内层解得极精确而样本极少，也可能浪费计算。误差预算需要同时分配两者。

假设偏差量级为 $Ch^p$，每条样本成本为 $Kh^{-q}$，方差近似不随 h 恶化。总预算 B 下可用样本约为 $Bh^q/K$，于是均方误差模型为 $C^2h^{2p}+\sigma^2K/(Bh^q)$。求极小可得 $h$ 的量级为 $B^{-1/(2p+q)}$，最优均方误差量级为 $B^{-2p/(2p+q)}$。这说明有内层离散化时，端到端成本规律可能显著慢于单纯一除以 n。

该成本推导依赖偏差阶、方差稳定和成本幂律；实际必须估计常数并检查范围。若 h 改变还显著改变方差，或者内层求解不稳定，模型需要修改。它的价值在于引导测量与分配预算，而不是给所有模拟提供一套固定最佳参数。

<a id="numerics-2-detail-16"></a>
### 4.4 重尾、依赖与失败的标准误

若积分存在但样本贡献方差无限，样本均值仍可能在适当条件下收敛，却没有普通的 sigma 除以根号 n 标准误保证。例如在单位区间均匀抽样估计 $x^{-\alpha}$，当 alpha 小于一时期望有限；只有 alpha 小于二分之一时二阶矩才有限。取四分之三时，积分为四，方差却无限。

一次有限样本中未遇到极靠近零的点，样本方差可能看起来温和，并不能证明尾部安全。对于这种函数，换元或匹配奇异性的抽样密度比盲目相信经验标准误更合适。重尾问题的详细概率分析可回到概率主题，数值工作者至少应先检查二阶矩，而不是对所有积分统一打印一个标准误数字。

相关样本同样需要修改方差。重复使用同一条样本很多次不会产生等量独立信息；马尔可夫链、聚类和公共随机数都有协方差项。对差分比较，恰当正相关可能降低两个估计之差的方差；对单个均值，忽略正相关通常会低估误差。相关性既可能有益也可能有害，取决于估计对象与协方差的进入方式。

<a id="numerics-2-detail-17"></a>
### 4.5 降方差与积分结构的匹配

对于单位区间的平方函数，已知 $E[U]=1/2$，可用 $U^2-\beta(U-1/2)$ 作为贡献。最优固定系数为协方差除以控制变量方差；这里两者都为十二分之一，故 beta 为一。原贡献方差为四除以四十五，改进后为一除以一百八十，降低十六倍。若控制变量几乎免费，这比增加十六倍样本更划算。

对偶抽样把 U 与一减 U 配成一组，组平均为 $[(U^2+(1-U)^2)/2]$。它的方差为一除以一百八十，但每组计算两次函数。因此同等函数调用总数 N 下，其均值方差为一除以九十 N，而普通法为四除以四十五 N，改善八倍。只比较同样组数，会把计算成本差异混入统计效率。

分层抽样则先把区间划分为若干段，在每段内抽样并按段宽加权，减少随机样本恰好聚集在局部的波动。对于光滑低维函数，它可以非常有效；高维全张量分层又会遇到组合爆炸。重要性、控制变量、对偶与分层各自利用不同结构，不能把一种方法在平方函数上的成功推广为所有积分的排名。

<a id="sec-5"></a>
## 5. 从误差阶到可信的实验设计

<a id="numerics-2-detail-18"></a>
### 5.1 解析答案、制造解与结构检查

先选择答案已知但能暴露错误的函数。常数检查权重和，一次函数检查节点方向与区间尺度，平方函数检查梯形与中点偏差，四次函数检查 Simpson 四阶。若只用恰好被公式精确积分的多项式，可能完全看不到误差阶；若只用复杂未知函数，又缺乏独立真值。

对求导，可以用低阶多项式核对系数，再用指数或三角函数检查通用路径。对复杂程序，可以构造一个已知解或已知积分的目标，再经过与真实程序相同的调用接口。制造解并不证明所有情形正确，但能让实现、参数传递、边界和单位获得明确检验。

结构证据也很有价值：积分对被积函数线性，区间方向反转应改变符号，常数缩放应按比例改变结果；导数对常数平移不变，但有限精度下添加巨大常数会恶化差分。后一个现象不违反精确数学性质，而是暴露函数值背景尺度如何进入舍入误差。选择结构测试时应说明哪些只在实数层面精确成立。

另一个有辨识力的差分测试是给目标添加大常数。精确函数 $g(x)=10^{20}+x^2$ 的导数仍为二 x，但在 x 约为一时，binary64 函数值可能把平方项完全舍掉，两侧返回同一巨大值，差分为零。此时调小 h 只会继续观察相同机器值；适当增大 h 也可能离开希望验证的局部区间。应尽可能消去不影响导数的大背景，或直接计算小变化的稳定表达。

这个例子也说明比较自动微分与差分时要明确语义。自动微分通常对程序原语所代表的实数运算求链式导数，不把每一步舍入当成一个处处平滑的函数；有限差分则直接观察具体函数值调用。两者在极端背景尺度下不一致，并不自动意味着链式公式错误，必须先检查前向函数是否保留了待测变化，以及差分是否具有足够分辨率。

<a id="numerics-2-detail-19"></a>
### 5.2 观测阶数的计算与解释

若误差满足 $E(h)\approx Ch^p$，那么网格减半时误差比约为 $2^p$，观测阶数可以写为 $\log_2(|E(h)|/|E(h/2)|)$。当有独立真值时，这个指标容易计算；误差接近舍入地板时，比值会非常不稳定，不能继续把它当作阶数证据。

没有真值时，可以比较三层近似 $Q_h,Q_{h/2},Q_{h/4}$，用相邻差值估计阶数。但若多层网格共同漏掉窄峰或振荡，差值都很小，结果仍可能很错。观测阶数建立在已经进入同一主误差模式的假设上，不能单独证明该假设成立。需要结合函数结构与额外采样证据。

对随机方法不应逐次使用同样的误差比例检验。样本增加后，实际绝对误差可能因为随机方向改变而暂时增大；应比较重复实验的均方根误差、理论标准误与预算关系。固定种子帮助复现某条路径，却不把这条路径变成误差单调的确定序列。

<a id="numerics-2-detail-20"></a>
### 5.3 Richardson 外推及其假设

若 $Q(h)=I+Ch^p+O(h^{p+r})$，且同一展开适用于 h 与 h 除以二，则 $R(h)=[2^pQ(h/2)-Q(h)]/(2^p-1)$ 消去主误差项。对梯形常取 p 为二，对中心差分也常取二；对称光滑结构下后续项往往按偶次递增，但应检查所需高阶导数。

外推只是误差抵消，不会增加新的函数信息。若两个输入近似带有噪声，线性组合会放大某些噪声；若主误差模型错误，如端点奇异或混叠，外推可能失效。对于已知二阶渐近区间，细网格误差可由两层差值除以三估计；这是一种模型依赖的估计，不是对任意函数的确定上界。

在中心差分中，更小 h 的截断误差减少而舍入更大，外推可能提前进入噪声主导。实际应扫描一个范围，观察改进是否稳定，并结合独立公式或解析值。不要无限递归外推，直到输出看起来停止变化，再宣布获得任意位精度；停止变化也可能只是所有输入已舍入为同一个数。

<a id="numerics-2-detail-21"></a>
### 5.4 公平比较需要统一预算与目标

比较梯形、Simpson 与蒙特卡洛时，至少应统一积分目标、输入函数、总函数调用次数和参考。梯形使用 N 个小段通常需要 N 加一节点，Simpson 要偶数小段；蒙特卡洛每条贡献通常一次调用，但重要性密度和控制变量可能额外收费。若函数调用很昂贵，节点复用更影响总成本。

低维平滑函数上，确定高阶公式可能远胜普通蒙特卡洛；高维、复杂区域或只能随机模拟的模型中，随机法可能更自然。比较应该让方法面对各自适合与不适合的案例，并解释原因，而不是从一个算例宣布通用优胜者。表格中除误差外，最好同时给出预算、结构前提和随机重复方式。

<a id="sec-6"></a>
## 6. 噪声差分、复步与自动微分的边界

<a id="sec-6-1"></a>
### 6.1 从误差模型推导可用步长范围

对中心差分，设截断上界为 $Ah^2$，函数值绝对误差项为 $B\eta/h$。若目标绝对误差不超过 tau，一个简单充分条件是分别要求两项不超过 tau 除以二，于是 $h\le\sqrt{\tau/(2A)}$ 且 $h\ge2B\eta/\tau$。只有下界不超过上界时，这个预算才可实现。否则必须改善函数值精度、降低噪声或放宽目标，不能靠继续调 h 解决。

这个区间观点比只背一个最优 h 更适合工程检查。它能明确告诉我们是否存在可行步长，也可以加入定义域与可表示性限制。比如靠近边界时最大合法 h 很小，可能与噪声所需最小 h 冲突；参数尺度差异大时，各坐标需要不同区间。一个全局固定步长并不自然地适合所有维度。

<a id="numerics-2-detail-22"></a>
### 6.2 随机函数值与公共随机数

假设两次中心差分调用的噪声均值为零、方差为 sigma 平方，相关系数为 rho。分子噪声方差为 $2\sigma^2(1-\rho)$，除以 $(2h)^2$ 后，导数估计噪声方差为 $\sigma^2(1-\rho)/(2h^2)$。独立调用对应 rho 为零；恰当共享随机性使 rho 接近一，可以大幅降低差分波动。

但共享随机数的作用取决于函数对随机输入的响应。若两侧贡献负相关，共享反而可能使差值方差变大；若程序含随机分支或不连续阈值，局部行为也需分析。不能把固定同一种子当成数学证明，而应研究配对贡献的差值方差，并将其与独立抽样方案同成本比较。

还有一种不同问题：固定样本求出的样本平均梯度，可能与总体梯度不同。公共随机数降低差分噪声，并不自动消除有限样本统计误差；如果需要总体导数，仍要说明可交换微分与期望的条件和样本误差。微积分中的支配条件与概率中的方差分析在这里必须同时出现。

<a id="numerics-2-detail-23"></a>
### 6.3 复步长为什么避免实数相消

若 f 在实点邻域拥有解析复扩展，并在实轴取实值，展开 $f(x+ih)=f(x)+ihf'(x)-h^2f''(x)/2-ih^3f^{(3)}(x)/6+\cdots$。取虚部再除以 h，可得 $f'(x)-h^2f^{(3)}(x)/6+O(h^4)$。它不需要从两个接近的实函数值相减，因此在兼容实现中常能使用远小于普通差分的 h。

这个优势有严格前提：整个计算链必须保留正确的复数解析扩展。取绝对值、共轭、只取实部、依实数比较选择分支、某些实数专用库调用，都可能破坏条件。一个在实数上可微的函数，不一定能由当前程序自然扩展成解析复函数；不能仅因为语言接受复数输入就断言方法有效。

例如程序 `abs(z) ** 2` 在实轴等于 x 平方，但复输入时返回实数 $|z|^2$，虚部为零，复步会错误给出零导数。若原目标确实是实变量平方，可以用解析表达 z 乘 z 来检查；若目标本来涉及模长，则要使用适合实变量的微分方式。错误来自扩展不满足前提，而非把 h 调大一点就能修复。

复步也不是任意小 h 都安全。虚部乘法可能下溢，库内部可能主动丢弃微小虚部，函数接近奇点或分支切线时泰勒展开不适用。高阶导数也不能直接套同一虚部公式。实验应选择兼容函数核对，再故意加入不兼容操作，确认方法会在哪一层失效。

<a id="numerics-2-detail-24"></a>
### 6.4 自动微分提供什么独立证据

自动微分沿程序中的基本运算传播导数，避免差分步长与函数值相消，但仍会经历浮点舍入，并依赖每个原语的导数约定。它求的是所写程序对应的数学依赖，不会自动修正错误的归约、标签、掩码或内层停止语义。对不可微点，框架采用的局部规则也未必等于一个存在的普通导数。

符号推导、自动微分、有限差分与复步应作为互补证据。符号式容易暴露代数结构但可能写错；自动微分适合大计算图但可能忠实传播错误目标；差分独立于链式实现却受步长与噪声限制；复步精度很好但要求解析兼容。优质验证不是选一种永远相信，而是在各自前提内交叉核对，并解释不一致的来源。

<a id="numerics-2-represented-step"></a>
### 6.5 实际可表示步长与不等距三点公式

程序请求 x 加 h 时，机器实际产生的右点未必与 x 相差精确的 h；左点亦然。若右增量为 a、左增量为 b，直接继续除以二 h，会把节点构造误差混入导数。对温和尺度，这通常只是高阶小量；但在巨大基点、小扰动和低精度下，可能成为主要误差，甚至出现 a 或 b 为零。

若已得到三个不同节点，可以用二次插值求导构造不等距公式：右值系数为 $b/[a(a+b)]$，左值系数为 $-a/[b(a+b)]$，中心值系数为 $(a-b)/(ab)$。验证时先把常数、一阶和二阶多项式代入：常数项消去，一阶项为一，二阶项为零。因此它对二次多项式导数精确，在适当光滑条件下具有由 a 与 b 共同决定的二阶误差。

这个公式不是消除一切表示误差的办法。节点非常偏斜时，权重绝对值和可能很大，噪声进一步放大；若 a 或 b 为零，公式根本不适用。选择扰动时应先检查点是否不同、是否都在定义域内，再计算真实增量。若基点加小变化的表示本身不合适，也可以把变量写成基准加偏移，在偏移坐标中执行计算，但函数接口也必须保留该信息。

## 7. 练习与逐步解析

<a id="numerics-2-detail-25"></a>
### 7.1 练习一至四：差分的阶与尺度

**练习一：立方函数的精确差分。** 对 x 等于二，推导前向与中心差分，并在 h 等于十分之一时求截断误差。

**解析：** 展开立方得前向差分 $3x^2+3xh+h^2$，所以在二处为十二加六 h 加 h 平方，误差零点六一。中心差分为十二加 h 平方，误差零点零一。前者主项一次，后者二次；这反映对称抵消。若只代入一个很小 h，两者看起来都接近十二，难以核对阶数，因此应使用数个可手算的 h，再进入浮点较小步长区间。

**练习二：最优步长的量纲。** 假设导数误差模型为 $Ah^2+B\eta/h$，推导最优 h，并解释为何函数乘一千后不能只按机器精度给固定结论。

**解析：** 对正 h 求导，得 $2Ah-B\eta/h^2=0$，故 $h=(B\eta/(2A))^{1/3}$。若函数整体乘一千，截断常数和函数值绝对误差可能同时按比例变化，最优 h 未必改变；若只有噪声尺度变化，则会改变。必须分别检查 A 与 eta，不能看到输出变大就任意调步长，也不能忽略输入变量单位。机器精度只有无量纲信息，不足以决定所有常数。

**练习三：边界上的中心差分。** 对实函数平方根在零处，为什么把负输入截成零再使用中心差分不能证明导数存在？

**解析：** 平方根的实定义域不包含负输入，零处右侧差商为一除以根号 h，随 h 趋零发散，没有有限普通导数。截断后构造的是另一个函数，其中心差分也不属于原函数的双侧导数公式。合法输入、导数存在和公式误差是先后条件；在前两个条件失败时继续扫描步长，只会得到缺乏目标的数值序列。

**练习四：高阶公式与噪声。** 五点中心公式的函数值误差各不超过 eta，其最坏额外误差上界是多少？这说明阶数比较缺少了什么？

**解析：** 系数绝对值和为十八，分母十二 h，所以误差上界为 $3\eta/(2|h|)$，比两点中心公式的 eta 除以 h 更大。五点截断虽为四阶，却使用更多调用并可能放大噪声。判断最终精度应把截断、函数值误差、范围与成本一起比较，不能只按四大于二排序。若误差相关，最坏界可能保守，但仍需单独的相关模型才能改进。

<a id="numerics-2-detail-26"></a>
### 7.2 练习五至八：积分公式的前提

**练习五：一般区间的梯形误差。** 对 $f(x)=x^2$ 在零到二积分，使用四个等长小段。求真实积分、梯形结果和误差。

**解析：** 真值为八除以三，步长二分之一。二阶导恒为二，复合梯形误差为 $Lh^2f''/12=1/12$，方向为偏大，因此结果为十一除以四。直接用节点零、二分之一、一、三除以二、二来加权，也得到十一除以四。这里特意逐个核对节点，避免把区间长度与节点数混淆；若忘记乘步长，单位和结果都会错误。

**练习六：Simpson 的四次误差。** 在零到一积分 x 的四次方，用两个小段的 Simpson 值是多少？误差与公式是否一致？

**解析：** 步长二分之一，函数值为零、十六分之一、一，结果为五除以二十四，真值五分之一，偏大一除以一百二十。四阶导为二十四，界中的 $Lh^4M_4/180$ 恰好也是一除以一百二十。该例同时检查了面板半宽的定义、四阶导和误差符号。若把 h 误认为整个区间长度，会出现十六倍差异。

**练习七：有限值但不满足光滑界。** 为什么平方根函数在单位区间可以直接采样，却不能据此宣称梯形误差一定二阶？给出改进方案。

**解析：** 函数在零连续且有限，但二阶导在零附近无界，正文使用的统一二阶导上界不存在。可令 x 等于 t 平方，连同雅可比得到二 t 平方的新积分，再使用 Simpson。换元改变了函数正则性，而不是简单增加节点。也可使用适合端点奇异性的专门方法，但必须重新说明误差依据，不应把普通光滑公式的证明直接移植。

**练习八：光滑不代表已分辨。** 对频率与网格相同的余弦例子，为什么 n 个小段得到一却不违背固定函数的梯形收敛定理？

**解析：** 因为该构造随 n 改变被积函数，二阶导幅值按 n 平方增长，抵消 h 平方带来的好处。固定函数的收敛结论要求函数不随网格变化；在给定高频函数上，也需要先细到能够分辨振荡。这个例子说明比较误差时必须固定目标，且多层相近结果可能共同混叠。增加另一组不共振节点可以提供补充证据，但不是对任意未知函数的无条件证明。

<a id="numerics-2-detail-27"></a>
### 7.3 练习九至十二：随机积分与预算

**练习九：积分和平均的尺度。** 在二到五上均匀抽样，直接平均 f(U) 估计什么？如何计算积分的标准误？

**解析：** 直接平均估计区间平均高度，积分应再乘三。若样本标准差为 s、独立样本数为 n，积分标准误估计为三 s 除以根号 n。若函数值有单位，标准误还带积分单位。只在零到一测试程序会掩盖这个因子错误，因此应至少加入非单位长度和反向区间的确定检验；随机抽样接口通常另要求左端小于右端，反向积分可显式加负号处理。

**练习十：均值存在但方差无限。** 均匀抽样估计单位区间上 x 的负四分之三次方积分，求均值并判断普通标准误是否有理论依据。

**解析：** 积分为四，但平方贡献的积分为 x 的负三除以二次方的积分，发散。因此贡献方差无限，普通有限方差中心极限定理和 sigma 除以根号 n 公式不适用。样本标准差仍能算出某个有限数字，却不能因此证明它稳定估计一个不存在的有限总体方差。应优先利用奇异结构换元或改变抽样密度，再检查新贡献的矩条件。

**练习十一：同成本的对偶比较。** 普通平方函数贡献方差为四除以四十五，对偶组平均方差为一除以一百八十。总函数调用 N 下，两者均值方差分别是多少？

**解析：** 普通法用 N 个贡献，方差为四除以四十五 N。对偶每组两次调用，只能有 N 除以二组，所以方差为一除以九十 N，改善八倍。若只按同样 N 组比较会得到十六倍，却花费两倍函数调用。统计效率与计算效率必须共同报告；如果第二个对偶点能复用大量内部计算，真实时间比较还应测量该复用收益。

**练习十二：偏差与方差的分配。** 若偏差量级为 h 平方，每条模拟成本为一除以 h，方差近似常数，总预算 B 下最优 h 与均方误差各是什么量级？

**解析：** 代入 p 为二、q 为一，得到 h 约为 B 的负五分之一次方，均方误差约为 B 的负五分之四次方。偏差平方约为 h 的四次方，抽样方差约为一除以 B h，两项在最优处同量级。若单纯固定 h 增加样本，最终会碰到偏差地板；若只减小 h，样本数下降又加重波动。这种平衡应建立在实际测得的成本和误差阶上。

<a id="sec-7-1"></a>
### 边界追问：更小差分步长为何误差反而变大

**练习十三：复步反例。** 对实轴上等于 x 平方的程序 `abs(z) ** 2` 使用复步，为什么会得到零？自动微分与中心差分应如何参与判断？

**解析：** 复数模平方输出实数，虚部恒零，并非 z 平方的解析扩展，因此复步前提失败。对实变量函数 x 平方，解析导数是二 x；中心差分在温和步长下能核对，自动微分若按实变量语义实现也应得到相应结果。不能因为复步在解析指数函数上很好，就认为所有接受复输入的程序都适用。验证首先要匹配数学对象，而不是按方法名称排序权威性。

**练习十四：多次结果一致仍可能错。** 两层积分网格给出相同数字，三个随机种子也给出相近结果，能否确认六位小数可信？请构造两种失败机制。

**解析：** 确定网格可能共同漏掉窄峰或混叠振荡；随机样本可能共同未见稀有但贡献极大的区域。另有内层离散化偏差可以让所有重复稳定收敛到错误目标。应检查函数结构、支持、二阶矩、内层误差与独立参考，并说明六位精度依据。重复一致是证据之一，却不能单独承担模型、采样和数值三层正确性的全部证明。

## 8. 三组可独立运行的完整实验

<a id="numerics-2-detail-28"></a>
### 8.1 差分扫描与复步的成功及失败

第一组实验固定目标函数与基点，扫描步长而不把最小步长视为最佳。立方函数检验精确截断公式，指数函数比较两种差分与复步，模平方则故意展示复步前提失败。代码不依赖自动微分框架，避免把额外依赖安装当作理解方法的条件。

```python
import math
import cmath

x = 1.0
true = math.e
rows = []
for h in [1e-1, 1e-3, 1e-5, 1e-7, 1e-9, 1e-12, 1e-16]:
    forward = (math.exp(x + h) - math.exp(x)) / h
    central = (math.exp(x + h) - math.exp(x - h)) / (2 * h)
    rows.append((h, abs(forward - true), abs(central - true)))
assert rows[2][2] < rows[0][2]
assert rows[-1][2] > rows[2][2]

h = 0.125
cubic = ((x + h) ** 3 - (x - h) ** 3) / (2 * h)
assert cubic == 3 * x * x + h * h
complex_h = 1e-20
complex_derivative = cmath.exp(x + 1j * complex_h).imag / complex_h
assert abs(complex_derivative - true) < 1e-14
bad_extension = complex(abs(x + 1j * complex_h) ** 2)
bad_derivative = bad_extension.imag / complex_h
assert bad_derivative == 0.0
assert 2.0 * x != bad_derivative
for row in rows:
    print('h, forward error, central error:', row)
print('complex step exp:', complex_derivative, 'bad extension:', bad_derivative)
```

观察这些输出时，不应要求每个末位跨平台完全相同；断言只检查与理论有关的稳健趋势。指数差分扫描中的最优点也不应直接复制到其他函数，因为常数、输入尺度和函数计算误差均可能不同。模平方反例尤其提醒我们，算法前提的失败不能通过更漂亮的输出精度掩盖。

<a id="numerics-2-detail-29"></a>
### 8.2 积分阶数、变量代换与振荡混叠

第二组程序显式实现复合梯形与 Simpson，验证常数、平方和四次函数，再比较平方根的直接积分与换元积分。最后构造一个节点无法分辨的余弦，说明光滑性与足够分辨率必须同时讨论。程序限制输入小段数，避免静默接受奇数 Simpson 网格。

```python
import math

def trapezoid(f, a, b, n):
    if not isinstance(n, int) or n < 1:
        raise ValueError('n must be a positive integer')
    h = (b - a) / n
    interior = math.fsum(f(a + i * h) for i in range(1, n))
    return h * (0.5 * f(a) + interior + 0.5 * f(b))

def simpson(f, a, b, n):
    if not isinstance(n, int) or n < 2 or n % 2:
        raise ValueError('n must be a positive even integer')
    h = (b - a) / n
    odd = math.fsum(f(a + i * h) for i in range(1, n, 2))
    even = math.fsum(f(a + i * h) for i in range(2, n, 2))
    return h * (f(a) + f(b) + 4 * odd + 2 * even) / 3

assert abs(trapezoid(lambda x: 3.0, 2.0, 5.0, 8) - 9.0) < 1e-14
assert abs(trapezoid(lambda x: x*x, 0.0, 2.0, 4) - 2.75) < 1e-14
for n in [2, 4, 8, 16]:
    t = trapezoid(lambda x: x*x, 0.0, 1.0, n)
    st = simpson(lambda x: x**4, 0.0, 1.0, n)
    assert abs((t - 1/3) - 1/(6*n*n)) < 1e-14
    assert abs((st - 1/5) - 2/(15*n**4)) < 1e-14
    print('n, quadratic trapezoid error, quartic Simpson error:', n, t-1/3, st-1/5)

direct = simpson(math.sqrt, 0.0, 1.0, 16)
transformed = simpson(lambda t: 2*t*t, 0.0, 1.0, 16)
assert abs(transformed - 2/3) < 1e-14
assert abs(direct - 2/3) > 1e-5
frequency = 16
aliased = trapezoid(lambda t: math.cos(2*math.pi*frequency*t), 0.0, 1.0, frequency)
resolved = trapezoid(lambda t: math.cos(2*math.pi*frequency*t), 0.0, 1.0, 4*frequency)
assert abs(aliased - 1.0) < 1e-14
assert abs(resolved) < 1e-14
print('sqrt direct/transformed errors:', direct-2/3, transformed-2/3)
print('oscillation aliased/resolved:', aliased, resolved)
```

本组梯形实现的节点由 a 加 i h 构造，适用于所选温和范围；它不是处理巨大 a 与微小区间的通用节点生成器。若 a 与 b 的差已低于输入表示分辨率，节点可能重复，需重新设计坐标表示。代码的范围条件与前章浮点分析一致，不能把解析公式验证通过扩展成任意尺度都可靠的宣称。

<a id="numerics-2-detail-30"></a>
### 8.3 随机积分的重复实验与同成本降方差

第三组程序用固定预算比较普通平方积分、固定最优控制变量和对偶配对。每个重复试验保持相同总函数调用数，对偶组数只有一半。这里的控制变量 U 不需要额外昂贵函数调用，故可与原方法直接比较；若换成昂贵控制模型，必须重新计算成本。四百次重复用于观察方差量级，不要求经验值精确等于理论值。

```python
import numpy as np

rng = np.random.default_rng(20261017)
repeats, budget = 400, 2048
truth = 1.0 / 3.0
u = rng.random((repeats, budget))
plain = np.mean(u*u, axis=1)
controlled = np.mean(u*u - (u-0.5), axis=1)
v = rng.random((repeats, budget//2))
antithetic = np.mean((v*v + (1-v)*(1-v))/2, axis=1)

theory = {
    'plain': (4/45)/budget,
    'controlled': (1/180)/budget,
    'antithetic': (1/90)/budget,
}
for name, values in [('plain', plain), ('controlled', controlled), ('antithetic', antithetic)]:
    mse = float(np.mean((values-truth)**2))
    ratio = mse / theory[name]
    assert 0.65 < ratio < 1.4
    print(name, 'MSE:', mse, 'theory:', theory[name], 'ratio:', ratio)

single = u[0]**2
estimate = float(single.mean())
standard_error = float(single.std(ddof=1)/np.sqrt(budget))
assert standard_error > 0
print('one estimate and estimated standard error:', estimate, standard_error)
print('independent repetitions:', repeats, 'calls per repetition:', budget)
```

这些断言检查特定种子与规模下是否出现合理量级，不是随机算法对所有种子永不失败的合同。真正的数学保证来自正文推导的期望和方差，重复实验用于发现实现、成本与权重问题。如果把独立重复取消、重复使用同一数组复制四百行，经验均方误差就不再具有相同解释；数组形状相同不意味着独立信息相同。

<a id="numerics-2-detail-31"></a>
### 8.4 研究延伸：把三类误差放在同一张预算表

可进一步选择一个只有数值求解器才能返回的函数值，同时记录内部网格 h、每条样本成本、外部样本数 n 和最终误差。先用可解析的小模型核对偏差阶，再用独立随机重复估计方差；按总预算比较几种 h 与 n 的组合，检验正文的成本平衡是否在实际范围成立。

扩展到梯度时，应固定相同输入与随机流比较不同差分步长，单独计算配对噪声的方差，并对照解析或自动微分梯度。扩展到积分时，应同时包含光滑、端点奇异、窄峰与振荡四类函数，解释每种方法在哪个假设上获益或失败。这样得到的资料才是对方法的研究，而不只是对某个漂亮结果的展示。

完成本章后，应能够从误差项推导步长、从光滑条件解释积分阶数、从二阶矩判断标准误，并把确定偏差与随机波动分开。后续可靠求解与自适应计算会在这些基础上加入状态管理、预算耗尽和停止证书；如果这里的误差模型没有建立，后面的停止阈值就只是未经解释的数字。
