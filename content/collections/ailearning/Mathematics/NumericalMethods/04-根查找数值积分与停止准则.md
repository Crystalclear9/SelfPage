## 1. 二分法的可靠前提：先证明区间里有什么

<a id="num4-1-1"></a>

### 1.1 介值定理保证存在，单调性才可能保证唯一

设 $`f`$ 在闭区间 $`[a,b]`$ 连续，端点函数值异号。介值定理保证区间内部至少有一个零点。注意这里有两个不可省略的条件：函数在整个区间有定义且连续，符号判断对应真实函数而非不受控的近似值。算法可以调用若干点，却无法凭有限次调用替使用者证明任意黑箱函数连续。

存在也不等于唯一。函数可能多次穿过横轴，而二分只保留一个仍有符号变化的子区间。若要声明唯一根，可证明函数严格单调，或证明导数在整个区间有固定非零符号。若只知道端点异号，正确输出是区间中至少有一个根以及某个被追踪的根的位置范围，不能宣布已经找到所有零点。

对平方根问题，$`f(x)=x^2-2`$ 在正半轴严格递增，所以区间 $`[0,2]`$ 内唯一正根。对一般振荡函数，同一个异号区间里可能包含许多根。对事件检测、概率分位数与物理平衡点，根的选择有实际意义，应先用领域条件指定有效区间，再讨论求解精度。精确找到错误分支仍然是任务失败。

<a id="sec-1-1"></a>

### 1.2 基础算例：二分迭代预算可以事前计算

设初始宽度为 $`W=b-a`$，执行 $`n`$ 次有效区间折半后宽度为 $`\frac{W}{2^n}`$。精确中点到区间中至少一个根的距离不超过 $`\frac{W}{2^{n+1}}`$，所以要求位置误差至多 $`\varepsilon`$ 时，足够的折半次数为满足该不等式的最小非负整数。这里要区分“完成多少次更新”与“额外评估一次返回点”，不同代码计数方式会相差一次调用。

例如宽度二、目标误差百万分之一，需要 $`\frac{2}{2^{n+1}}\leq10^{-6}`$，最少二十次折半。宽度八、目标误差千分之一，需要十二次折半。预算是从不变量推得的，不要求函数接近线性，也不要求导数存在；但连续性、真实符号与有效折半缺一不可。它不是对任意黑箱程序都成立的通用保证。

浮点实现的中点通常不是精确实数中点，因此最终应报告返回点到两个实际端点距离的最大值，而不是盲目把名义宽度除以二。两者在常规尺度几乎一致，在相邻可表示数附近却可能决定是否达到容差。理论预算负责理解收敛，实际区间负责解释本次返回值，两者应互相补充。

<a id="num4-1-3"></a>

### 1.3 不连续、偶重根与错误符号的三个反例

定义阶跃函数在零左侧为负一、其余位置为正一。它在 $`[-1,1]`$ 两端异号，却处处没有零点。二分区间仍能缩到零附近，说明区间收缩本身不能弥补连续性缺失。函数 $`\frac{1}{x}`$ 则在零处无定义，某次调用可能显式暴露异常，但不是所有不连续函数都会返回无穷或抛出错误。

再看 $`f(x)=(x-0.3)^2`$。根存在且函数光滑，但根两侧符号相同，标准异号二分无法启动。这不表示无根，只表示充分条件不满足。对偶重根，可结合导数结构、最小化或专门的多项式分析寻找候选，再验证根存在性；仅把采样点加密并找变号仍会漏掉这种根。

第三个反例来自不精确求值。如果真实值为 $`10^{-20}`$，内部近似误差却可能达到 $`10^{-16}`$，程序返回的符号不可信。若已知求值误差界为 $`\eta`$，只有近似值绝对值大于 $`\eta`$ 时才能确定符号；否则应增加内层精度或报告符号不确定。外层求根再精密，也无法恢复被内层误差掩盖的信息。

<a id="num4-1-4"></a>

### 1.4 符号比较、计算零与浮点中点

用 $`f(a)f(b)<0`$ 判断异号在实数数学里方便，在浮点程序里可能溢出或下溢。更稳妥的做法是先处理零与非有限值，再比较两个有限非零值的正负布尔状态。这样避免额外乘法，但仍不能保证函数本身没有在先前计算中出错；例如极小指数表达式可能已经下溢成零。

计算值恰好为零需要单独标记。如果函数是精确可判定的多项式且运算可证明无误，这可能支持精确根；对一般浮点函数，它只说明当前实现返回零。教学接口不应把这个状态与夹根区间达到位置容差混在一起。可以返回候选点、当前区间和“计算零”状态，让调用者根据函数实现决定如何解释。

中点计算可用 $`\frac{a}{2}+\frac{b}{2}`$ 降低同号大端点求和溢出的风险，但它在极小数附近也受舍入影响。如果中点等于某个端点，说明这种划分已无法产生新的内部浮点数；无限循环不会得到新信息。此时若容差尚未达到，应报告空间分辨率限制，并考虑更高精度或接受更宽的结果区间。

### 图解：二分法的区间与停止证据

![二分法的区间与停止证据：机制、算例与边界](images/04-concept.svg)

右图每行蓝线是已经完成 $`n`$ 次折半后保留的区间，橙点是该区间的中点，灰色竖线是用于核对的真实根 $`\sqrt2`$。前四个中点依次为 $`1.5,1.25,1.375,1.4375`$，函数值符号依次为正、负、负、正。因此区间依次变为 $`[1,1.5]`$、$`[1.25,1.5]`$、$`[1.375,1.5]`$、$`[1.375,1.4375]`$。

左图把前四个被评估中点放回同一个函数。这里函数严格递增，正值说明根在该点左侧，负值说明根在右侧，因而可与右图的端点更新逐次核对。一般连续但不单调的函数则应比较中点与端点的符号来保留异号半段；不能把“正就保留左边”当成不依赖初始符号的通用规则。本图的左右判断还使用了初始左负右正这一约定。

最后一行的中点为 $`1.40625`$；由于连续性与端点异号一直保持，根在该区间内，中点的位置误差至多为半宽 $`0.03125`$。真实误差约 $`0.007964`$，小于这个保证。图里的“折半次数”是区间更新次数，不包含初始端点求值；是否额外计算最终返回点的函数值，应按接口单独统计。

这份包含证据不能直接迁移到不连续函数。例如 $`\frac1x`$ 在 $`[-1,1]`$ 两端异号，但区间内没有零点，零处反而未定义。程序还可能遇到浮点中点无法再细分、预算耗尽或计算值为零；这些状态与达到区间容差应分别返回。数值积分的近似差也不自动构成根的包含区间，须结合后面的严格积分界例子理解两类证据的差别。

## 2. 完整二分示例：把返回值设计成一份证据

<a id="sec-2-1"></a>

### 2.1 机制展开：停止原因决定能怎样解释结果

下面的实现分别返回区间容差达标、计算零、浮点无法细分和迭代上限。它不把所有退出都映射成同一个成功布尔值。结果包含候选点、实际端点、位置半径和函数调用次数；位置半径以返回点到区间端点的最大距离为依据，并向上取一个浮点邻居，避免把普通减法舍入造成的微小低估当成严格界。

即使这样，它仍不是通用区间算术求根器。结果的夹根解释依赖输入函数连续且求值符号可靠，而这些前提由问题分析或更强的函数求值器提供。代码中的“区间达标”表示在这些前提下位置范围足够小；它没有宣称从有限调用验证了连续性。接口说明应与数学前提同样明确。

绝对容差适合接近零的位置，允许的相对项随位置尺度增大。代码采用半径不超过 $`\text{xtol}+\text{rtol}\vert x\vert `$ 的规则，并用不溢出的比较形式实现。不同库可能把容差定义为返回值与真实根的混合误差，不完全等于区间宽度；比较结果前应读接口定义，不能只让两边参数名称相同。

```python
import math
from dataclasses import dataclass

@dataclass(frozen=True)
class RootResult:
    x: float
    lo: float
    hi: float
    radius: float
    status: str
    calls: int

def bisect_report(f, lo, hi, xtol=1e-10, rtol=0.0, max_iter=200):
    if not (math.isfinite(lo) and math.isfinite(hi) and lo < hi):
        raise ValueError('finite increasing endpoints required')
    if not (math.isfinite(xtol) and xtol > 0 and
            math.isfinite(rtol) and 0 <= rtol < 1):
        raise ValueError('invalid tolerances')
    if not isinstance(max_iter, int) or max_iter < 0:
        raise ValueError('max_iter must be a nonnegative integer')
    calls = 0
    def evaluate(x):
        nonlocal calls
        calls += 1
        value = float(f(x))
        if not math.isfinite(value):
            raise ValueError('nonfinite function value')
        return value
    def result(x, status):
        distance = max(abs(x-lo), abs(hi-x))
        radius = math.nextafter(distance, math.inf)
        return RootResult(x, lo, hi, radius, status, calls)
    flo, fhi = evaluate(lo), evaluate(hi)
    if flo == 0.0:
        return result(lo, 'computed_zero')
    if fhi == 0.0:
        return result(hi, 'computed_zero')
    if (flo > 0) == (fhi > 0):
        raise ValueError('opposite endpoint signs required')
    for iteration in range(max_iter + 1):
        mid = lo/2 + hi/2
        radius = math.nextafter(max(abs(mid-lo), abs(hi-mid)), math.inf)
        if radius <= xtol or radius-xtol <= rtol*abs(mid):
            return result(mid, 'bracket_tolerance')
        if mid == lo or mid == hi:
            return result(mid, 'spatial_resolution')
        if iteration == max_iter:
            return result(mid, 'iteration_limit')
        fm = evaluate(mid)
        if fm == 0.0:
            return result(mid, 'computed_zero')
        if (flo > 0) != (fm > 0):
            hi, fhi = mid, fm
        else:
            lo, flo = mid, fm
    raise AssertionError('unreachable')

r = bisect_report(lambda x: x*x-2., 0., 2., xtol=1e-11)
assert r.status == 'bracket_tolerance'
assert r.lo <= math.sqrt(2.) <= r.hi
assert abs(r.x-math.sqrt(2.)) <= r.radius
flat = bisect_report(lambda x: 1e-20*(x-0.123), 0., 1.)
assert abs(flat.x-0.123) <= 1e-10
short = bisect_report(lambda x: x*x-2., 0., 2., max_iter=1)
assert short.status == 'iteration_limit'
a = 1.0
b = math.nextafter(a, math.inf)
# This discontinuous oracle is only for testing the resolution status.
limited = bisect_report(lambda x: -1. if x == a else 1., a, b,
                        xtol=math.ulp(0.0))
assert limited.status == 'spatial_resolution'
zero = bisect_report(lambda x: x-1., 0., 2.)
assert zero.status == 'computed_zero'
print(r)
print('flat:', flat.status, 'limited:', limited.status,
      'budget:', short.status, 'zero:', zero.status)
```

### 2.2 为什么返回区间比只返回小数更有价值

同样一个小数结果可能来自严格夹根、局部迭代停滞、计算零或预算耗尽。只打印十位数字会抹去这些差别。区间与状态使后续程序能够决定是否接受、提高精度、缩小问题域或继续求解，也能让研究者比较方法的真实可靠性。迭代日志则可以帮助判断区间是否持续收缩、函数调用是否异常昂贵。

若函数在区间有多个根，返回区间还能保留分支信息。若算法后来被用于寻找第一次事件发生时间，应结合时间顺序与单调区间，防止跳到后面的零点。一个一般求根接口不负责自动解决所有事件语义，调用者应把“需要哪个根”的结构转换成合适的有效区间。

对输入类型与异常的处理也属于算法定义。函数求值抛出领域异常、返回复数、出现非有限值或产生随机结果时，需要明确策略。示例选择尽早抛出异常，没有尝试跨过非法点继续夹根，因为那样可能跨越奇点而失去连续性前提。实际项目可采用更复杂的分段处理，但应重新证明每段的保证。

<a id="num4-2-3"></a>

### 2.3 用反例测试理论边界

平方根例子只覆盖良性单根。还应测试端点计算零、同号端点、极平函数、迭代预算不足与相邻浮点端点；测试目的不是让所有输入都返回成功，而是确认程序诚实区分每种情况。对不连续函数，区间可能收缩却不能声称有根，这一失败应出现在教学说明中，而不是通过回避输入来隐藏。

如果使用随机或近似模拟器作为函数，重复调用同一点可能返回不同符号。标准二分的不变量于是没有基础。可以通过共同随机数降低比较方差、使用置信区间决定符号，或改用随机逼近与统计求根理论，但必须把随机误判概率计入整体可靠性。简单加大迭代次数无法修复错误符号不断改变区间的问题。

最后，浮点结果的残差也应按函数尺度解释。把函数整体乘以一个正数，不改变根和符号，却改变残差大小。一个在正比例缩放后立刻宣布成功的“位置求根器”，实际上可能只是在执行未经说明的残差规则。这是很有效的接口检验：同样的位置目标，应在合理尺度变化下保持一致含义。

<a id="sec-3"></a>

## 3. 停止条件的含义：位置、残差、步长不是同一件事

<a id="deep-dive-3"></a>

### 3.1 深入讲解：怎样把停止规则转成误差保证

区间规则以根存在为前提，直接给位置范围；残差规则以方程满足程度为对象，需要灵敏度信息才能转成位置误差；步长规则以迭代轨迹变化为对象，单独只能说明算法最近没怎么移动。这三类量在简单良性问题上常同时变小，却没有一般等价关系。一个可靠报告应说明使用哪种规则以及所需附加条件。

若 $`f`$ 在包含候选与根的区间可微，且 $`\vert f'(x)\vert \geq m>0`$，由中值定理有 $`\vert \widehat x-x_\star\vert \leq\frac{\vert f(\widehat x)\vert }{m}`$。这是可验证上界的形式。如果只知道根处导数非零，通常只能获得局部近似关系，不能把它直接升级为整个搜索域上的保证。导数下界应覆盖连接候选与根的区域。

如果使用近似函数 $`\widetilde f`$ 且已知 $`\vert \widetilde f-f\vert \leq\eta`$，位置界相应为 $`\frac{(\vert \widetilde f(\widehat x)\vert +\eta)}{m}`$。外层残差再小也无法突破内层误差项。这个公式在积分方程、模拟校准和隐式模型中特别有用，因为函数值本身常来自另一次数值计算，不能假装它是精确输入。

<a id="num4-3-2"></a>

### 3.2 小步长可能表示停滞而不是接近根

迭代更新在浮点中可能舍入成零，例如求解位置尺度很大的问题而步长小于一个可表示间距。此时参数不再变化，但残差可能仍显著。导数极大、阻尼过强、内层线性系统求解不准和边界投影也会造成小步长。因此“连续两次答案一样”应作为停滞诊断，而不能无条件当成精度达标。

对不动点迭代 $`x_{k+1}=g(x_k)`$，若有已证明的收缩常数 $`q<1`$，则可以把步长转成后验误差界，例如返回 $`x_{k+1}`$ 时误差不超过 $`\frac{q\vert x_{k+1}-x_k\vert }{(1-q)}`$。这个结论依赖收缩区域与不变性，而不是仅凭观察到若干步变小。没有收缩证明时，相似公式只是启发。

实际停止策略可以同时监测多个量，但组合逻辑要与保证一致。例如“残差小或步长小就成功”会让停滞绕过残差要求；“残差小且步长小”也不能在病态平坦函数中自动给位置保证。合理做法是明确成功依据，并将停滞、非有限值和预算耗尽作为不同的非成功退出状态。

<a id="num4-3-3"></a>

### 3.3 容差必须有单位与可实现性

若未知量是秒，位置绝对容差也应以秒为单位；若函数是能量差，残差阈值则以能量为单位。一个名为`tol`的通用数字若没有指定对象，调用者很难判断结果是否满足任务需求。相对误差在真实值接近零时尤其不合适，通常需要一个有物理意义的绝对下限。

不要把机器精度直接等同于可达到的根误差。位置附近的可表示间距随尺度变化，函数求值还可能包含抵消、噪声或内层近似误差。如果任务需要比当前间距更细的区分，应改变坐标、采用更高精度或重新评估数据是否支持这种要求。单纯把容差设成极小数，只会让算法更频繁进入精度限制状态。

同样，最大迭代次数与最大函数调用次数是预算，不是误差准则。预算耗尽时可以返回当前最好候选和已有区间，但必须标注未达到目标。若调用成本变化很大，还可能需要时间预算；这时应注意计时中止不能破坏结果对象的完整性，保留当前已经证明或估计到的信息比抛弃一切更有用。

<a id="sec-4"></a>

## 4. 根位置与残差的不同尺度：条件性分析

<a id="num4-4-1"></a>

### 4.1 平坦与陡峭函数的对照

对 $`f(x)=10^{-12}(x-1)`$，候选零的残差只有万亿分之一，位置误差却为一。对 $`g(x)=10^{12}(x-1)`$，候选 $`1+10^{-10}`$ 的位置误差很小，残差却约为一百。两者根完全相同，区别只在函数尺度。通用的绝对残差阈值因此不能直接表达通用的位置精度。

局部敏感性可以通过带参数的方程 $`f(x,p)=0`$ 分析。若简单根处 $`f_x\neq0`$，则 $`\frac{dx}{dp}=-\frac{f_p}{f_x}`$。当 $`f_x`$ 很小时，参数或函数值误差会引起较大根移动。这与线性系统小奇异值放大数据误差是一回事的非线性局部版本；求根算法再稳定，也不能消除方程本身的敏感性。

若把函数整体乘以非零常数，$`f_p`$ 与 $`f_x`$ 同时变化，所以物理根对参数的灵敏度保持不变。但一个未归一化的残差阈值会变化，暴露出它不是坐标或尺度无关的任务指标。报告应给原方程残差、位置区间与相关导数尺度，使读者可以判断结果到底精确到什么程度。

<a id="num4-4-2"></a>

### 4.2 多重根产生另一种误差尺度

设根附近 $`f(x)=c(x-x_\star)^m`$，其中 $`m>1`$。则位置误差与残差满足 $`\vert x-x_\star\vert =(\frac{\vert f(x)\vert }{\vert c\vert })^{\frac{1}{m}}`$。残差达到十六位小数，并不意味着位置也有十六位；二重根大致只给一半数量级的位数。简单根的导数下界在根附近不再成立，所以不能套用线性残差误差界。

微小函数扰动还可能分裂或消除多重根。例如 $`x^2-\varepsilon`$ 有两个实根，$`x^2+\varepsilon`$ 没有实根，而未扰动问题只有一个二重根。对数据不精确的多项式或物理模型，宣称“精确发现重根”需要额外结构性证据。数值图形上贴近横轴的一段，并不能区分真正重根与没有实根的近接触。

这也影响算法选择。偶重根不变号，标准夹根法无法提供通常的异号保证；Newton 仍可能从局部收敛，但速率下降且对导数误差更敏感。若重数已知，可以使用修改 Newton；若未知，则需谨慎估计并检查结构，而不是把估计重数当成精确事实。

<a id="num4-4-3"></a>

### 4.3 区间保证与不确定数据怎样共同报告

若真实方程依赖不确定参数，单个固定参数下的数值根区间只是计算误差的一部分。比如常数 $`c`$ 只有三位有效数字，求 $`x^2=c`$ 到十五位并不会让物理答案也有十五位。可以通过参数区间、灵敏度或重复模拟传播数据不确定性，再把数值求解误差控制到比该范围小得多。

当参数不确定性会改变根数量或分支，线性灵敏度近似可能失效。应考察整个允许范围内是否保持简单根、是否仍有同一夹根区间、以及是否会经过导数为零的临界状态。这时分支存在性与稳定性比提高每次局部求解的小数位更重要。一个小残差不会告诉你另一组允许参数下根已经消失。

可靠报告可以分别写：在固定模型与参数下，数值夹根区间多宽；在测量或标定不确定性下，目标根可变化多少；使用哪些前提维持唯一分支。这样读者能区分计算精度与知识精度，也能决定下一步应该改进求解器、提高仪器精度还是补充模型证据。

<a id="visual-detail-numericalmethods-04"></a>

## 5. 进阶：Newton、割线与安全混合

<a id="num4-5-1"></a>

### 5.1 Newton 二阶收敛的误差递推

设 $`f`$ 在简单根附近二阶连续可微，且导数绝对值有正下界。令误差 $`e_k=x_k-x_\star`$，将 $`f(x_\star)`$ 在 $`x_k`$ 处展开：$`0=f(x_k)-f'(x_k)e_k+\frac{f''(\xi_k)e_k^2}{2}`$。代入 Newton 更新，得到 $`e_{k+1}=\frac{f''(\xi_k)e_k^2}{[2f'(x_k)]}`$。若二阶导数有界，便有误差平方控制，这才是局部二阶收敛的依据。

“局部”意味着初值必须进入能够保持迭代不出界的邻域。误差上界中的常数还取决于二阶导数与一阶导数下界之比。仅知道根处可微，不足以保证从任意初值收敛；若导数在某处为零，更新可能无定义；若函数有多个根或复杂分支，切线步可能跳到另一个区域。

以 $`f(x)=x^2-2`$ 为例，Newton 更新是 $`\frac{(x+\frac{2}{x})}{2}`$，正初值下常迅速接近正根。以 $`f(x)=x^3-2x+2`$ 为例，从零出发更新到一，再从一回到零，形成二周期而不收敛。这个反例说明局部高阶定理不等于全局可靠性，记录迭代轨迹和保守区间仍有必要。


<a id="visual-newton-two-cycle"></a>

#### 图解：追踪切线与残差，区分局部速度和全局行为

![两条正确切线产生零与一之间的 Newton 两周期](images/04-newton-cycle.svg)

左图画出的两条切线都由原函数的精确导数得到。零处切线为 $`y=2-2x`$，它的零点是下一步 $`x_1=1`$；一点处切线为 $`y=x`$，其零点又回到 $`x_2=0`$。从横轴上的新候选上移到曲线，再沿对应切线到横轴，就能逐次复原代码中的循环。灰点是真实负根，约为 $`-1.769292`$；候选从未进入它的局部邻域。右表进一步给出残差在二与一之间交替，并没有趋零。

这个失败不依赖有限差分噪声或浮点误差，在精确实数迭代中同样存在。因此更精确地计算相同切线、增加最大轮数，都不能修复这个初值。可先用 $`[-2,-1]`$ 建立连续异号区间，再使用有进展检查的安全混合方法；这时可靠性来自新维护的区间，不来自把“Newton 很快”作为全局保证。[《Fundamentals of Numerical Computation》第 4.3 节](https://fncbook.com/newton/)将切线几何与局部收敛前提分开讨论，本例用两周期具体展示前提不满足时的行为。

<a id="num4-5-2"></a>

### 5.2 重根、导数误差与修改 Newton

若 $`f(x)=(x-x_\star)^m g(x)`$ 且 $`g(x_\star)\neq0`$，普通 Newton 的主导误差约为 $`(1-\frac{1}{m})e_k`$，通常只线性收敛。若重数 $`m`$ 已知，更新 $`x_{k+1}=x_k-\frac{m f(x_k)}{f'(x_k)}`$ 可以消去线性主项，在足够光滑条件下恢复更高局部阶。若重数猜错，速度与稳定性则可能变差。

实际导数常来自有限差分、自动微分或内层近似。自动微分按离散程序的实数运算依赖传播导数，实际实现仍受浮点舍入和基础算子误差影响，但不自动消除原模型近似误差；有限差分则需要平衡截断与舍入。若导数误差不随根误差适当降低，理论上的二阶阶段可能被线性阶段或噪声平台取代。观察不到理想阶不一定是更新公式写错，也可能是求值精度不支持。

若函数值本身只精确到 $`\eta`$，Newton 步中的噪声除以导数会形成位置噪声。接近根后继续要求平方下降可能无意义。应根据残差与内层误差预算调整求值精度，或停止并报告可支持的位置范围。把高阶算法用于低精度黑箱时，最重要的设计常是精度协调，而非再增加一阶形式收敛阶。

<a id="num4-5-3"></a>

### 5.3 割线法为何常有黄金比例阶

割线法用最近两点的差商代替导数，更新为 $`x_{k+1}=x_k-\frac{f(x_k)(x_k-x_{k-1})}{[f(x_k)-f(x_{k-1})]}`$。在简单根附近且函数足够光滑，误差主项满足 $`e_{k+1}\approx C e_ke_{k-1}`$。若假设渐近阶为 $`p`$，则前后误差尺度相容要求 $`p^2=p+1`$，所以得到黄金比例阶约一点六一八。

这只是局部渐近分析，需要分母不退化、两点进入正确邻域以及主导系数不发生特殊消失。对线性函数，割线一步就可找到根，不能硬说只能一点六一八阶；若二阶主项消失，也可能表现不同。实验估阶时应避开初始暂态和舍入平台，否则用三个相邻误差算出的数字没有稳定理论含义。

割线每步通常新增一次函数调用，不需要单独求导，因此在导数昂贵时有吸引力。但若两点函数值几乎相同，分母很小，步长可能巨大；若两点都在根同侧，也没有夹根保证。不能因为它不用导数就认为它自动稳健，安全实现同样需要回退机制、非有限值检查和明确状态。

<a id="sec-5-1"></a>

### 5.4 区间保证与快速步骤怎样组合

安全混合方法维护一个有效异号区间，同时尝试 Newton、割线或插值步。候选若越出区间、分母太小、位置过于贴近端点或预期进展不足，就退回中点。每次获得可信符号后更新区间，从而保留保守定位能力。速度来自局部模型，可靠性来自区间不变量，两个机制承担不同职责。

只要求快速候选在区间内部，仍不足以保证区间迅速收缩。候选可能一直贴近一个端点，使另一端几乎不动。一个简单教学策略是只有候选落在中间一半区间时才接受，否则二分；这样每次至少将宽度缩到原来的四分之三。代价是过于保守的规则可能牺牲某些局部超线性速度，不能同时声称保留了所有纯 Newton 的渐近优势。

成熟 Brent 方法使用更精细的插值与接受条件，兼顾夹根与实际速度。使用时仍需连续函数和正确端点符号；成熟库不会替用户修复错误模型。[SciPy Brent 求根接口](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.brentq.html)明确列出了这些前提与位置容差约定。教学混合器可以帮助理解机制，正式工作优先使用经过充分验证的实现并检查返回状态。

<a id="num4-5-5"></a>

### 5.5 比较算法要计算真实求值成本

比较二分、Newton 与割线时，迭代次数不是统一成本单位。Newton 一轮可能需要函数与导数各一次，导数若来自差分还可能消耗多次模拟；自动微分也有额外内存和计算成本。若函数与导数能共享昂贵中间量，成本又可能接近一次调用。因此实验应记录函数调用、导数调用、总耗时与达到的精度，而不是只排列轮数。

缓存可以减少重复端点求值，但仅当函数确定、输入与状态一致时才合法。若函数依赖随机数、外部文件、时间或可变模型状态，同一点缓存可能改变问题。为了公平比较，先规定函数求值语义和随机机制，再决定是否缓存。对昂贵求解器，还应区分冷启动与热启动成本，避免某方法享受未计入预算的预计算。

下例同时展示良性函数上的求值计数与 Newton 周期反例。库接口使用固定已验证的区间，输出状态用于核查，而不是只取一个浮点数。不同平台下调用次数可能受停止细节影响，重点是计数方法一致、误差目标清楚，以及不把一次良性问题的排名推广成所有问题的结论。

```python
import math
from scipy.optimize import brentq

class Counter:
    def __init__(self, fun):
        self.fun, self.calls = fun, 0
    def __call__(self, x):
        self.calls += 1
        return self.fun(x)

fc = Counter(lambda x: math.cos(x)-x)
r, info = brentq(fc, 0., 1., xtol=1e-12, full_output=True)
assert info.converged and abs(math.cos(r)-r) < 1e-11
print('Brent:', r, 'calls:', fc.calls, 'iterations:', info.iterations)

x = 0.0
trace = [x]
for _ in range(6):
    x -= (x*x*x-2*x+2)/(3*x*x-2)
    trace.append(x)
assert trace == [0., 1., 0., 1., 0., 1., 0.]
print('Newton cycle:', trace)

# An exact double root: ordinary Newton is linear, modified Newton is exact here.
x = 2.0
er = []
for _ in range(5):
    er.append(abs(x-1))
    x -= (x-1)**2/(2*(x-1))
assert all(abs(er[i+1]/er[i]-0.5) < 1e-14 for i in range(4))
x_modified = 2.-2*(2.-1.)**2/(2*(2.-1.))
assert x_modified == 1.
print('double-root errors:', er)
```

## 6. 适应性积分：误差估计何时值得相信

<a id="num4-6-1"></a>

### 6.1 从两个尺度的差推估主导误差

设一个子区间上粗 Simpson 近似为 $`S`$，把区间二分后两份 Simpson 之和为 $`S_2`$。如果函数足够光滑、局部网格已进入主导四阶误差区，二分后总误差约缩小十六倍。于是细近似误差可估为 $`\frac{(S_2-S)}{15}`$，校正近似为 $`S_2+\frac{(S_2-S)}{15}`$。这个十五来自误差缩放假设，不是任何函数上都成立的神奇常数。

估计的是主导误差项，有限网格上的高阶项、导数变化、端点奇异与舍入会影响比例。若两个近似都漏掉同一个窄峰，它们的差可能为零，而真实误差很大。若两个较大误差恰好相互抵消，差值也可能过于乐观。误差估计器提供的是依赖结构的证据，不能仅凭输出名字包含“error”就把它当成严格上界。

适应性细分通过把更多节点放在估计困难的地方提高效率。它比均匀网格更善于处理已被采样发现的局部变化，却不能保证发现所有未知结构。若已知断点、尖峰位置、振荡频率或端点行为，应主动分区、变换变量或使用专门积分器。给算法正确结构信息，常比把最大细分数加十倍更有效。

<a id="num4-6-2"></a>

### 6.2 局部预算如何组合成整体预算

若把绝对误差预算 $`T`$ 按子区间分配为 $`T_i`$，且 $`\sum_iT_i\leq T`$，在每个局部误差界真实有效时，整体绝对误差由三角不等式控制在预算内。递归二分时把预算各分一半，是一种简单可解释的分配方式；它可能不是最高效，但不会因子区间变多而暗中把总容差放大。

若每个区间都独立使用同一个全局容差，再把结果相加，就可能得到子区间数倍的允许误差。若局部误差只是估计值而非证明界，求和仍只是整体估计，不能因为预算管理正确就升级成严格保证。理论上要分别检查误差模型是否有效，以及预算是否被正确传播，两者缺一不可。

相对容差还涉及未知积分值。积分接近零时，相对误差可能没有意义，尤其正负大面积相消。通常使用绝对与相对混合规则，以绝对项处理零附近。递归示例只接受全局绝对预算，便于完整解释；正式库支持的相对规则会在全局自适应过程中与当前积分估计协调，不能简单在每个子区间各自按局部积分大小判断后就宣称整体相对保证。

<a id="num4-6-3"></a>

### 6.3 舍入、抵消与求值误差形成精度下限

数值积分的误差不只有离散化误差。节点上的函数值可能本身不准确，加权求和有舍入，正负面积相消还会放大相对误差。如果积分结果很小而各局部贡献很大，计算更多节点可能增加累计舍入而不是持续改善结果。应结合稳定求和、变量变换与问题结构评估可实现精度。

粗细公式差值也会受舍入影响。当它已经与机器精度乘以局部贡献尺度相当，继续除以十五不代表真的获得更小误差。教学实现可以使用保守的舍入尺度启发来识别明显不现实的预算，但这不等于对所有函数给出严密舍入分析。严格认证需要对函数求值和算术同时采用可靠界，例如区间方法或经过分析的高精度计算。

如果函数来自内层模拟，积分器在许多节点叠加内层误差。已知一致点误差上界为 $`\eta`$ 时，区间长度乘 $`\eta`$ 可以控制对应积分误差；若误差随位置变化，则应积分其上界。外层把网格细化到极致也不能消掉这个来源。误差预算应先分给求值误差与求积误差，而不是把全部预算都交给网格控制。

<a id="num4-6-4"></a>

### 6.4 有限采样不可能认证任意连续函数的积分

假设某个算法只在有限多个点调用函数。总能在这些点之外找到一段没有节点的小区间，并构造一个只在该处非零的光滑窄峰。它在所有已调用点都与零函数相同，积分却可以通过调节峰高而任意改变。因此，没有导数界、带宽限制或其他结构假设时，有限点采样无法对任意连续函数提供统一的确定误差保证。

这不是某个适应性实现的偶然缺陷，而是信息限制。节点加倍、随机抽样或更高阶公式可以改善某些函数类别的效率，却无法消除对函数类的依赖。随机方法可以给概率陈述，但同样需要关于抽样和被积函数的假设。理解这一点，能避免把每一次小误差估计当成对所有未采样位置的证明。

实际做法是把结构信息显式交给算法。已知窄峰位置便分段积分，已知振荡频率便使用振荡权重或相位处理，已知端点奇异便变换变量或选择相应规则。对不熟悉的黑箱，可用不同节点族、独立方法和扰动区间交叉检查，但交叉一致仍只是增强证据，最终可靠性应对应明确函数类别。

## 7. 完整适应性 Simpson 实现与失败状态

<a id="num4-7-1"></a>

### 7.1 预算、缓存和覆盖区间必须一起维护

下面的教学算法复用端点与中点求值，每次细分只新增两个节点。递归返回积分估计、误差估计和状态；若深度或求值预算耗尽，它仍返回覆盖完整原区间的近似，同时把误差标为无穷并保留失败状态。这样不会把只积到一部分区间的结果误报成完整答案。

代码只实现有限递增区间与绝对误差预算，函数必须确定且在测试节点返回有限实数。空间无法细分、舍入尺度不支持目标、深度上限和求值上限分别报告。所谓“estimated_tolerance”表示粗细公式估计达标，含义比严格证明误差达标弱，名称刻意保留这一差别。对于奇异或高度振荡问题，应换用适合结构的方法。

递归深度被显式限制，以免依赖语言运行时的递归上限。函数异常会传播，不会悄悄替换成零。局部公式若溢出，也会显式拒绝；有限节点值并不保证加权和有限。示例适用于适度数值尺度，极端尺度还需更精细的缩放与求和设计，不应以一份短代码承诺覆盖任意浮点输入。

```python
import math
import sys
from dataclasses import dataclass

@dataclass(frozen=True)
class QuadResult:
    value: float
    estimated_error: float
    status: str
    calls: int

def adaptive_simpson(f, a, b, atol=1e-9, max_depth=25, max_evals=100000):
    if not (math.isfinite(a) and math.isfinite(b) and a < b):
        raise ValueError('finite increasing endpoints required')
    if not (math.isfinite(atol) and atol > 0):
        raise ValueError('positive finite atol required')
    if not isinstance(max_depth, int) or not 0 <= max_depth <= 40:
        raise ValueError('max_depth must be between 0 and 40')
    if not isinstance(max_evals, int) or max_evals < 3:
        raise ValueError('at least three evaluations required')
    calls = 0
    def evaluate(x):
        nonlocal calls
        calls += 1
        y = float(f(x))
        if not math.isfinite(y):
            raise ValueError('nonfinite integrand')
        return y
    def simpson(l, r, fl, fm, fr):
        value = (r-l)/6 * (fl+4*fm+fr)
        if not math.isfinite(value):
            raise ValueError('nonfinite quadrature arithmetic')
        return value
    mid = a/2+b/2
    if not a < mid < b:
        raise ValueError('no representable interior midpoint')
    fa, fm, fb = evaluate(a), evaluate(mid), evaluate(b)
    coarse = simpson(a, b, fa, fm, fb)
    def visit(l, r, fl, fm, fr, old, budget, depth):
        m = l/2+r/2
        lm, rm = l/2+m/2, m/2+r/2
        if not (l < lm < m < rm < r):
            return old, math.inf, 'spatial_resolution'
        if calls+2 > max_evals:
            return old, math.inf, 'evaluation_limit'
        flm, frm = evaluate(lm), evaluate(rm)
        left = simpson(l, m, fl, flm, fm)
        right = simpson(m, r, fm, frm, fr)
        fine = left+right
        delta = fine-old
        if not (math.isfinite(fine) and math.isfinite(delta)):
            raise ValueError('nonfinite quadrature combination')
        err = abs(delta)/15
        unit = 50*sys.float_info.epsilon
        floor = unit*abs(left) + unit*abs(right) + unit*abs(old)
        if budget < floor:
            return fine, max(err, floor), 'roundoff_scale'
        if err <= budget:
            corrected = fine+delta/15
            if not math.isfinite(corrected):
                raise ValueError('nonfinite Richardson correction')
            return corrected, err, 'estimated_tolerance'
        if depth >= max_depth:
            return fine, math.inf, 'depth_limit'
        lv, le, ls = visit(l, m, fl, flm, fm, left, budget/2, depth+1)
        rv, re, rs = visit(m, r, fm, frm, fr, right, budget/2, depth+1)
        status = ls if ls != 'estimated_tolerance' else rs
        combined = lv+rv
        if not math.isfinite(combined):
            raise ValueError('nonfinite recursive quadrature sum')
        return combined, le+re, status
    value, error, status = visit(a, b, fa, fm, fb, coarse, atol, 0)
    return QuadResult(value, error, status, calls)

r = adaptive_simpson(math.exp, 0., 1., atol=1e-10)
assert r.status == 'estimated_tolerance'
assert abs(r.value-math.expm1(1.)) < 1e-10
small_budget = adaptive_simpson(math.exp, 0., 1., atol=1e-14, max_evals=3)
assert small_budget.status == 'evaluation_limit'
small_depth = adaptive_simpson(math.exp, 0., 1., atol=1e-10, max_depth=0)
assert small_depth.status == 'depth_limit'
roundoff = adaptive_simpson(lambda x: 1., 0., 1., atol=1e-20)
assert roundoff.status == 'roundoff_scale'
print(r)
print('budget/depth/roundoff:', small_budget.status,
      small_depth.status, roundoff.status)

# Smooth compact bump: all five initial sample values are exactly zero.
c, w = 0.13, 0.01
def bump(x):
    t = (x-c)/w
    return math.exp(-1/(1-t*t)) if abs(t) < 1 else 0.
missed = adaptive_simpson(bump, 0., 1., atol=1e-10)
found = adaptive_simpson(bump, c-w, c+w, atol=1e-10)
assert missed.value == 0. and missed.estimated_error == 0.
assert found.value > 0.001
# 人工采样值只用于检查：修正前有限，Richardson 修正后仍可能溢出。
try:
    adaptive_simpson(lambda x: 2.625e306 if x in (25., 75.) else 0.,
                     0., 100., atol=1e308)
except ValueError as error:
    assert 'Richardson' in str(error)
else:
    raise AssertionError('overflow must not report estimated_tolerance')
print('missed bump:', missed, 'informed interval:', found)
```

<a id="num4-7-2"></a>

### 7.2 代码输出怎样体现理论边界

指数函数足够光滑，常规容差下粗细误差估计与实际误差吻合良好；预算与深度不足时，算法仍给出整个区间的近似，但明确标记没有达到估计精度。对常数函数，极端容差触发舍入尺度状态是保守设计，虽然这个特殊问题的某些运算可能恰好精确；该状态说明通用启发无法支持所要求的认证，并不证明本次误差一定很大。

光滑窄峰反例更重要。初始节点位于零、四分之一、二分之一、四分之三和一，全部落在峰外，所以粗细公式都返回零，误差估计也为零。给出已知峰所在的小区间后，算法才能发现其积分。这一实验没有违反 Simpson 的理论，因为函数虽无限可微，但窄峰导致导数尺度很大，初始网格远未进入适用的渐近区域。

因此“状态成功”也必须带上语义：这里成功只意味着当前采样与误差模型满足预算，而不是证明没有任何未采样结构。正式报告应说明被积函数的已知结构、分区方式、求值精度和交叉检查方法。如果把积分器当成完全不了解函数的万能黑箱，返回的误差小数再漂亮也可能误导。

<a id="num4-7-3"></a>

### 7.3 使用成熟积分库时仍要检查什么

实际工作可使用 SciPy 的自适应求积接口。应检查返回的误差估计、函数求值次数、细分上限与异常消息，并在已知断点处提供分区信息。某些接口在请求完整输出时会把警告信息放入返回对象，而不是继续通过常规警告通道显示，所以不能只看控制台安静就认定成功。[SciPy 的 QUADPACK 包装源码](https://github.com/scipy/scipy/blob/main/scipy/integrate/_quadpack_py.py)说明了这些返回约定。

无限区间、端点可积奇异、振荡权重和主值积分是不同问题。普通实数积分可能不存在，而柯西主值存在；两者不能因数值结果看起来稳定就混同。遇到奇点时，先分析积分定义与存在性，再选择规则。人为绕过一个非法节点可能掩盖发散，也可能错误地改变你实际计算的数学对象。

对高成本函数，节点复用和矢量化可能影响实际效率，但不能只比较墙钟时间而忽略求值精度。一种积分器调用更多低精度函数，另一种调用较少高精度函数，比较的是整个流程。公平实验应对齐最终任务误差与求值成本，把预计算、缓存和内层求解预算都纳入统计。

<a id="num4-8"></a>

## 8. 嵌套计算：积分定义的方程怎样求根

<a id="num4-8-1"></a>

### 8.1 外层精度不能超过内层证据

考虑 $`F(x)=\int_0^x e^{-t^2}\,dt-\frac{1}{2}`$，在 $`[0,1]`$ 上严格递增，导数至少为 $`e^{-1}`$，所以根存在且唯一。若积分近似误差有严格上界 $`\eta`$，则外层候选位置误差不超过 $`e(\vert \widetilde F(x)\vert +\eta)`$。这给出一个清晰误差预算：积分误差与求根残差共同决定最终精度。

更重要的是符号。若积分近似减去二分之一后的区间仍跨零，不能据一个带误差的点估计强行更新夹根区间。可以提高内层精度，直到值域区间确定为正或负；若已经达到求值精度下限，就返回符号不确定状态。要得到严格夹根，需要内层提供真正可靠的值域界，而不仅是未经认证的启发误差估计。

普通求积库的误差输出往往是估计而非严格界，因此可以用它构建实用流程，却要把最终位置结论标为依赖误差模型的估计。若业务要求数学认证，应使用有明确函数界与舍入控制的方法。把两层成熟库简单串联不会自动产生端到端严格证明，保证必须在接口之间被正确传递。

<a id="visual-integral-sign-certification"></a>

### 图解推导：用严格积分区间决定外层是否能够前进

![交错级数积分上下界支持外层求根符号判断](images/04-integral-sign-certification.svg)

继续使用 $`F(x)=\int_0^x e^{-t^2}\,dt-\frac12`$，但这次不用“积分库返回的误差很小”替代严格上下界。在 $`0\le x\le1`$ 上，将积分本身记为 $`I(x)`$，把指数函数的交错级数逐项积分，记

$$
S_N(x)=\sum_{k=0}^{N}\frac{(-1)^k x^{2k+1}}{(2k+1)k!}.
$$

各项绝对值递减到零，因此奇数下标的部分和在积分之下，偶数下标的部分和在积分之上。于是 $`S_3(x)\le I(x)\le S_2(x)`$，进一步还有 $`S_3(x)\le I(x)\le S_4(x)`$。这是从交错余项符号得到的确定性界；在有理数输入处，有限部分和可用有理数运算精确计算，不需要假设随机误差独立或把库的估计量当成证明。

**同一个候选点，精度不同会给出不同的合法操作。** 取 $`x=\frac{551}{1000}`$。用 $`S_3`$ 和 $`S_2`$ 包围 $`F(x)`$，得到的端点约为 $`-4.97434\times10^{-5}`$ 与 $`3.17380\times10^{-4}`$，区间跨过零，故暂时不能判断根在哪一侧。增加一项并用 $`S_4`$ 替代宽松上界，上端降到约 $`-2.80708\times10^{-5}`$，整个区间变成负值。此时才能利用严格单调性，把这个候选点作为新的左侧端点。左图横轴使用 $`10^{-4}`$ 的单位，较短的橙色线段完全位于零的左侧；它的长度本身不是根位置误差。

**再从函数区间推出位置区间。** 先验夹根区间为 $`[0,1]`$，因为 $`F(0)=-\frac12`$，且 $`e^{-t^2}\ge1-t^2`$ 给出 $`F(1)\ge\frac16>0`$；导数在整个区间内满足 $`e^{-1}\le F'(x)\le1`$，所以根唯一。令精化后的完整精确上下界为 $`L=S_3(x)-\frac12`$、$`U=S_4(x)-\frac12`$，其中 $`L\le F(x)\le U<0`$。由中值定理，

$$
-U\le x_*-x\le-eL,
\qquad
x_*\in[x-U,\ x-eL].
$$

这给出约 $`[0.55102807,0.55113522]`$ 的根区间。独立地用误差函数表达式求得根约 $`0.55103942761`$，落在其中；右图只是帮助核对位置关系，严格结论来自部分和不等式与导数界，不来自画图或一次求根器成功返回。

**界的类型必须沿接口传递。** 上述公式使用完整有理数 $`L,U`$，图中舍入小数仅作显示；若要把这个流程实现成机器可验证的区间算法，还应控制涉及 $`e`$ 等数值计算的舍入方向。普通 [SciPy quad 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.quad.html)将返回误差描述为估计，不能直接赋予它这里由交错余项建立的严格性质。可迁移的工作方法是：先确认内层输出究竟是点值、估计误差还是确定界，再决定外层可以使用何种停止和区间更新规则。

<a id="num4-8-2"></a>

### 8.2 由松到紧的内层预算与成本控制

远离根时，函数绝对值很大，不需要极高精度积分就能确定符号。接近根后，内层误差应逐步缩小以支持外层定位。这样的自适应精度可以节省大量调用，尤其每个函数值都涉及昂贵模拟时。固定把所有内层计算都求到极限，会在早期浪费资源，也可能仍在最终阶段不够精确。

误差预算可以按目标位置误差反推。若希望位置误差约为 $`\varepsilon`$，且导数下界为 $`m`$，内层误差应显著小于 $`m\varepsilon`$；余下预算给外层残差与区间误差。没有导数下界时，可以优先使用经过可靠符号确认的夹根区间定位，而不是从残差估计位置。预算选择应服务于最终量，而不是沿用每个库的默认值。

还应记录总积分调用与总被积函数调用。一次外层函数求值可能包含成百上千个内层节点，外层迭代数很少并不意味着计算便宜。若复用积分前缀或共享网格，应重新检查误差相关性与缓存语义。确定性积分可以共享计算，但共享误差不会因为被多个外层步骤使用就自动相互抵消。

<a id="num4-8-3"></a>

### 8.3 一个可执行的嵌套实验与独立核对

下面使用 SciPy 求积与 Brent 求根，并用误差函数的解析表达独立核对。这里的积分误差是库提供的估计，所以打印的传播位置尺度也只是估计；与解析表达的比较检验了本例实现，并没有证明所有类似输入都具有同样可靠性。我们同时统计外层与内层调用，展示真实成本层级。

```python
import math
from scipy.integrate import quad
from scipy.optimize import brentq

outer_calls = 0
inner_calls = 0
max_quad_error = 0.0

def F(x):
    global outer_calls, inner_calls, max_quad_error
    outer_calls += 1
    def integrand(t):
        global inner_calls
        inner_calls += 1
        return math.exp(-t*t)
    value, err = quad(integrand, 0., x, epsabs=1e-12, epsrel=1e-12)
    max_quad_error = max(max_quad_error, err)
    return value-0.5

root, info = brentq(F, 0., 1., xtol=1e-11, full_output=True)
exact_expression_residual = math.sqrt(math.pi)/2*math.erf(root)-0.5
assert info.converged and abs(exact_expression_residual) < 1e-10
residual_estimate = abs(F(root))
position_scale = math.e*(residual_estimate+max_quad_error)
print('root:', root, 'analytic residual:', exact_expression_residual)
print('outer calls:', outer_calls, 'inner calls:', inner_calls)
print('estimated propagated position scale:', position_scale)
```

## 9. 练习与解析：用失败例子检验理解

<a id="num4-ex-1"></a>

### 9.1 预算里的差一从哪里来

**题目。** 初始区间宽度八，要求返回中点到某根距离不超过千分之一，至少需要多少次有效折半？为什么代码可能显示不同迭代计数？

**解析。** 要求 $`\frac{8}{2^{n+1}}\leq0.001`$，所以 $`2^{n+1}\geq8000`$，最少 $`n=12`$。代码可能把初始检查、最后一次中点求值或区间更新前检查算成不同轮次，因此比较次数必须说明定义。只要最终实际区间和返回半径正确，计数差一不一定是算法错误。

**验收。** 手工列出前两次区间更新，再与日志对应，确认预算讨论的是区间折半次数，而非函数总调用数。后者通常还包括两个端点，可能还包括返回点残差的额外计算。

<a id="num4-ex-2"></a>

### 9.2 同号端点能否证明没有根

**题目。** 对 $`f(x)=x^2`$，区间 $`[-1,1]`$ 端点都为正。能否判断没有根？能否直接使用标准异号二分？

**解析。** 不能判断没有根，零就是二重根；也不能直接使用要求异号的标准二分。异号是连续函数存在零点的充分条件，不是必要条件。若已知函数非负，可以研究其最小值是否达到零，但数值最小值接近零仍需结合函数误差、曲率和结构判断，不能把近似接触当成严格根证据。

**延伸。** 将函数改成 $`x^2+10^{-12}`$ 后没有实根，却可能在有限精度图上与原函数几乎相同。这提醒我们多重根问题本身对模型扰动敏感。

<a id="sec-7-2"></a>

### 9.3 边界追问：函数两端异号能否不管连续性

**题目。** 阶跃函数在零左边为负一、其余位置为正一。区间二分能持续缩小，是否证明存在零点？与 $`\frac{1}{x}`$ 的失败有什么不同？

**解析。** 都不能证明根存在。阶跃函数处处有定义且求值有限，程序可能一直正常运行，所以有限值检查不足以识别连续性失败。倒数函数在零处无定义，某些求值会直接触发异常，但如果迭代没有恰好采到零，也仍可能逼近奇点。存在性必须先由函数结构建立。

**验收。** 分别说明程序能检查的性质与数学分析必须提供的性质。不要把“所有调用没有异常”写成“函数在整个区间连续”的证据。

<a id="num4-ex-4"></a>

### 9.4 用导数下界把残差转成位置界

**题目。** 在 $`[1,2]`$ 求 $`x^2-2=0`$，候选残差不超过 $`10^{-6}`$，位置误差如何上界？若函数近似误差另有 $`10^{-7}`$ 呢？

**解析。** 区间内导数 $`2x`$ 至少为二，所以精确残差给位置误差不超过 $`5\times10^{-7}`$。若读到的是近似残差，则真实残差不超过 $`1.1\times10^{-6}`$，位置误差不超过 $`5.5\times10^{-7}`$。此界要求候选与目标根均在所分析区间，且函数误差界有效。

**延伸。** 如果只知道根处导数约为二点八二八，可作更精细局部估计，但不能不加证明就替代全区间下界。可通过缩小可靠夹根区间改进下界。

<a id="num4-ex-5"></a>

### 9.5 二重根的残差精度有多少位置意义

**题目。** $`f(x)=(x-1)^2`$，残差达到 $`10^{-12}`$，位置误差最多是多少？普通 Newton 的误差比例是什么？

**解析。** 此例精确有 $`\vert x-1\vert =\sqrt{\vert f(x)\vert }`$，所以位置误差为百万分之一量级，而非万亿分之一。Newton 更新使 $`x-1`$ 每步减半，因此只有线性收敛。已知重数二时乘二修正可在这个纯二次例子一步得到根，但一般乘有非恒定光滑因子时不能承诺一步精确。

**延伸。** 若给函数增加很小正偏移，实根可能消失，说明求值残差低不等于模型不确定性下仍有稳定根。应分别讨论算法误差和方程扰动。

<a id="num4-ex-6"></a>

### 9.6 一个 Newton 周期说明了什么

**题目。** 对 $`x^3-2x+2`$ 从零开始做 Newton，证明两步循环，并说明这是否反驳局部二阶收敛定理。

**解析。** 零点处函数值二、导数负二，更新到一；一点处函数值一、导数一，更新回零。因此形成周期。它没有进入目标简单根的局部收敛邻域，所以不反驳局部定理。实际实现可检测周期或停滞，但更根本的稳健办法是先建立有效夹根区间并在快速步不安全时回退。

**延伸。** 仅把最大迭代次数增加到一万不会改善此例。失败源于更新动力学，预算增加只会重复同一轨迹，应该改变算法或初始问题组织。

<a id="num4-ex-7"></a>

### 9.7 快速候选在区间内是否就有足够进展

**题目。** 某混合器每次接受任何内部插值点。为什么仍可能非常慢？若限制候选在中间一半，能得到什么宽度保证？

**解析。** 内部点可能无限贴近同一个端点，更新后大部分区间保留，因此仅有内部性不保证统一收缩。若候选与两端距离都至少为原宽度四分之一，则无论保留哪侧，新宽度最多为四分之三。退回中点时宽度减半，所以得到统一线性收缩保证。

**延伸。** 这种保守条件可能频繁拒绝局部极好的 Newton 点，因此不能无条件同时宣称纯 Newton 的二阶速度。更复杂的成熟混合方法在保证与速度之间使用细致条件，比较时要如实说明自己的策略。

<a id="num4-ex-8"></a>

### 9.8 Simpson 差值里的十五依赖什么

**题目。** 已知二分后总误差约为粗网格误差的十六分之一，推导细网格误差估计。若函数有窄峰未被采到，结论哪里失效？

**解析。** 设粗误差为 $`E`$，细误差为 $`\frac{E}{16}`$，则两近似差约为 $`\frac{15E}{16}`$，所以细误差幅值约为差的十五分之一，符号用于 Richardson 校正。窄峰未采到时，两个近似可能都为零，而误差并未按十六倍缩减，主导渐近模型根本不适用。

**验收。** 不要只背常数十五，要明确误差阶、细化比例与渐近区域。更换公式或不等分细化时，这个常数应重新推导。

<a id="num4-ex-9"></a>

### 9.9 局部容差相同为什么可能超出总预算

**题目。** 将积分分成一百段，每段允许绝对误差 $`10^{-6}`$，整体是否也保证 $`10^{-6}`$？怎样分配更合理？

**解析。** 在各局部界真实有效时，三角不等式只能给总误差不超过 $`10^{-4}`$。若总预算为 $`10^{-6}`$，可均分为每段 $`10^{-8}`$，或根据区间长度、困难程度和成本分配，只要预算之和受控。实际局部数值输出若仅是估计，总和也仍是估计而非严格界。

**延伸。** 不应指望正负局部误差自动抵消，因为符号通常未知。除非有正交、随机独立或其他可证明结构，不能用平方和开根号替代确定性最坏界。

<a id="num4-ex-10"></a>

### 9.10 预算耗尽时怎样保证没有漏掉区间

**题目。** 递归积分已完成左半区间，右半尚未细分就耗尽函数调用预算。应该返回什么，怎样避免误报？

**解析。** 可以保留左侧已细化估计，并使用右侧当前已有的粗估计，使两部分仍覆盖完整区间，同时返回预算耗尽状态与未获得目标误差的标记。只返回左半积分却不说明缺失，会把部分结果伪装成完整结果；返回一个数但标记成功也同样错误。

**验收。** 检查递归每个返回分支都对应完整当前区间，错误状态能向父节点传播，预算计数包含实际所有调用。算法接口的可靠性不仅在正常路径上，也在每个提前退出路径上。

<a id="num4-ex-11"></a>

### 9.11 为什么有限采样无法认证所有光滑函数

**题目。** 已在有限节点上观测到函数值全部为零，能否保证积分很小？即使函数无限可微呢？

**解析。** 不能。选择没有节点的小区间，在其中放一个光滑紧支撑峰，所有已采样值仍为零，积分却为正并可随峰高改变。无限可微并不提供统一导数大小界，因此不排除极窄高峰。若另有已知导数上界或带宽限制，才可能获得相应的统一误差控制。

**延伸。** 随机节点可降低某些峰被漏掉的概率，但结论变成概率性的，且取决于峰宽或函数类。不能用“增加随机性”替代明确概率假设与失败概率报告。

<a id="num4-ex-12"></a>

### 9.12 嵌套积分求根怎样分配误差

**题目。** 已知 $`\vert F'\vert \geq0.2`$，目标位置误差 $`10^{-5}`$。若外层近似残差为 $`10^{-6}`$，内层误差界最多还能有多大？

**解析。** 需要 $`\frac{(10^{-6}+\eta)}{0.2}\leq10^{-5}`$，故 $`\eta\leq10^{-6}`$。这里应留安全余量处理其他误差，且误差界必须覆盖候选处真实函数近似。若只有启发误差估计，则最终位置结论也只能相应解释为估计。

**延伸。** 若为了确定符号，当前近似函数值绝对值比内层误差界还小，应先提高内层精度或报告不确定，而不是按当前点估计的正负更新区间。预算传播决定外层不变量是否可信。

## 10. 进阶研究练习与解析：形成完整数值证据链

<a id="sec-7-1"></a>

### 10.1 综合练习：残差与参数误差同时报告

**问题。** 把[上一章的病态线性系统](03-线性系统条件数与病态问题.md)与本章的一维求根放到同一框架：为什么小残差都不必然代表未知量准确？设计一个联合实验报告。

**逐步解析。** 在线性问题中，误差满足 $`x-\widehat x=A^{-1}r`$，小奇异值方向可放大残差；在简单根问题中，局部误差约为残差除以导数，小导数产生类似放大。前者的稳定性刻画依赖矩阵与目标范数，后者依赖根附近导数与分支。若问题本身敏感，提高求解精度不能消除数据误差。

**手算验收。** 对 $`A=\operatorname{diag}(1,0.001)`$，真右端 $`(1,0.001)`$ 的第二维加 $`0.001`$，真解从 $`(1,1)`$ 变成带噪方程解 $`(1,2)`$，新方程残差仍为零。再对 $`f(x)=10^{-12}(x-1)`$ 使用候选零，残差仅为 $`10^{-12}`$ 而位置差一。分别报告数据变化、相应灵敏度、计算残差与目标误差，避免用单个小数概括全部精度。

**研究验收。** 对线性问题加入正则化，对求根问题加入可靠区间或导数下界；比较它们增加了什么信息、改变了什么目标。正则化引入偏好，夹根引入存在与位置范围证据，两者机制不同，不能因都能稳定输出就混同为同一种证明。

<a id="num4-research-2"></a>

### 10.2 建立方法比较的可复现实验协议

选择至少四类函数：单调简单根、平坦简单根、多重根和具有 Newton 失败初值的函数。先分析根存在性、唯一性与有效区间，再比较二分、成熟混合器和局部方法。各方法使用同一位置目标，分别记录求值次数、导数成本、最终残差、区间与停止状态。把失败也保留在结果中，避免只统计收敛样本而夸大平均性能。

积分部分选择光滑函数、已知窄峰、端点结构和正负相消问题。比较不提供结构信息与主动分段后的成本和误差，使用解析值或更高可信独立方法核对。若没有可靠真值，应诚实报告交叉一致性而非真实误差。改变容差后检查结果是否进入稳定区域，同时观察舍入平台和预算限制。

最后研究嵌套问题，把外层轮数、内层总调用与任务位置误差一起展示。比较固定严格内层容差与逐步收紧策略，确保所有方法最终得到可比精度。若使用误差估计代替严格界，应在整份报告中保持这个措辞，不要在结论处悄悄把“估计满足”改成“保证满足”。

<a id="num4-research-3"></a>

### 10.3 从数值答案到可靠知识的检查顺序

先确认数学对象是否存在：区间内是否连续、积分是否收敛、目标分支是否有定义。再确认数据与函数求值是否足够准确，避免求解一个与真实任务不同的近似对象。然后分析条件性，判断残差可以怎样转成目标误差。最后才比较算法阶数、实现效率和默认参数，这个顺序能够减少大量无效调参。

结果交付应包含任务对象、前提、尺度、算法、停止原因、误差含义与成本。不是每个问题都需要严密认证，但每个结论都应该与证据强度相称。若只做了经验核对，就写经验核对；若有导数界、夹根不变量和可靠求值界，就写清这些条件支持的范围。这样的材料才能让读者知道什么已被证实，什么仍需进一步研究。

<a id="num4-research-4"></a>

### 10.4 从误差估计走向严格认证需要补哪些信息

如果能够证明被积函数在每个子区间有已知四阶导数上界，就可以用 Simpson 的确定性余项界替代粗细差值启发。再对节点函数值误差、加权求和舍入和区间端点表示误差分别加界，便有机会建立完整积分范围。这样的范围可以传给外层求根，使符号判断与最终位置区间具有一致的证明基础。仅把计算精度提高，并不自动补齐这些数学信息。

区间 Newton 是另一条研究方向：用包含真实导数的区间与函数值范围约束可能的根位置，并在适当条件下验证唯一性。它需要可靠区间扩张、除法中不跨零的处理和舍入控制，不能把普通浮点导数最小值与最大值临时拼起来便称作区间证明。学习时应先验证一个简单多项式的全部界，再逐渐扩展到复合函数与嵌套计算。

严格认证与经验方法可以共同使用。先用快速算法定位候选，再在小区域集中构造可靠界，通常比从整个大区间一开始就高精度认证更节省成本。但最终保证只能覆盖实际通过认证的区域与假设；快速阶段产生一个很好的候选，不能替代最后的存在性、唯一性或误差证明。
