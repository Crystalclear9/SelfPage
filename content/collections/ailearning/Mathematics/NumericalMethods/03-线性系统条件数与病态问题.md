## 1. 微小扰动为何放大：先说明想恢复什么

<a id="num3-1-1"></a>

### 1.1 正向观测容易，反向恢复未必可行

设未知参数为 $`x_\star\in\mathbb R^n`$，理想测量满足 $`b_\star=Ax_\star`$，实际得到 $`b=b_\star+e`$。正向计算把一个参数送进仪器模型，反向计算则根据读数推断参数。有限维矩阵乘法是连续的；对固定的可逆方阵，逆映射同样连续，但最小奇异值很小时，扰动放大常数可能很大。这里的病态指恢复对误差敏感，不能与逆映射不存在或不连续混为一谈；实际能否可靠恢复，还取决于数据尺度、噪声与待估方向。把正向程序倒着运行，不会自动恢复仪器已经抹去的信息。

一个典型例子是模糊成像。相邻像素的平均值变化平缓，而黑白交替的高频模式经平均后可能几乎消失。仪器因而对某些方向很敏感，对另一些方向几乎看不见。恢复算法若试图把所有观测分量都精确解释，就会把读数里微小的高频噪声放大成强烈条纹。问题不在于条纹“看起来不好”，而在于它们对应的观测证据不足。

在任何计算前，应回答三件事。第一，未知量的单位与允许范围是什么；第二，测量噪声的来源、尺度和相关性是什么；第三，真正关心的是完整参数、某个线性组合还是新位置的预测。三个目标可能要求不同的正则化和验证方式。只说“解方程”会把科学目标藏在一个数学接口后面，使后续精度指标失去解释。

本章默认有限维实数模型，除非另行说明，范数使用欧氏范数，奇异值按从大到小排列。模型不保证正确，噪声不保证独立高斯；当使用这些额外假设时会明确写出。这样做的目的不是罗列限制，而是让每个结论都能追溯到足以支持它的信息。

<a id="sec-1-1"></a>

### 1.2 基础算例：从两条近乎重复方程手算敏感性

考虑 $`x+y=2`$ 与 $`x+1.001y=2.001`$。两式相减得到 $`0.001y=0.001`$，故原解为 $`(1,1)`$。若第二个读数增加 $`0.001`$，相减后变成 $`0.001y=0.002`$，新解为 $`(0,2)`$。测量向量的绝对变化很小，参数却沿 $`( -1,1)`$ 方向移动了显著距离。这一方向在两次测量中的作用近乎抵消，所以不容易分辨。

不要只看右端“第四位小数变化”。应把它与真正区分两个参数的读数差比较：原有区分信息恰好也是 $`0.001`$，因此新增误差与有效信号同量级。总读数约为二，并不能证明差分信息也有很高信噪比。类似现象出现在用两个巨大而接近的计数估计小差值、用相似传感器定位源位置，以及用高度相关特征解释系数时。

新解对新方程的残差严格为零，这完全不妨碍它偏离原真解。残差回答“能否解释当前输入”，参数误差回答“是否接近产生无噪声数据的对象”。在现实中通常没有真解，因此必须用额外信息约束第二个问题，不能把第一个问题的成功当作第二个问题的证据。

<a id="num3-1-3"></a>

### 1.3 条件数是最坏方向的尺度，不是每次误差的预言

对可逆方阵，$`x=A^{-1}b`$，右端扰动产生 $`\Delta x=A^{-1}\Delta b`$，于是相对误差不超过 $`\frac{\kappa_2(A)\Vert \Delta b\Vert }{\Vert b\Vert }`$，其中 $`\kappa_2(A)=\frac{\sigma_1}{\sigma_n}`$。这个上界结合了两个可能分别达到极值的方向：原数据与最大奇异值方向相关，扰动与最小奇异值方向相关。日常某一次扰动未必同时满足，因此实际误差可以远低于上界。

取 $`A=\operatorname{diag}(1,10^{-3})`$。若扰动为 $`(10^{-3},0)`$，参数只变化 $`(10^{-3},0)`$；若扰动为 $`(0,10^{-3})`$，参数变化为 $`(0,1)`$。两者观测扰动范数相同，危险程度相差一千倍。一个总体条件数告诉我们必须警惕的可能性，观测噪声协方差则进一步告诉我们这些方向实际会被激发多少。

对于含矩阵误差的问题，条件数也会影响误差，但必须指定扰动模型。每个元素可以独立相对变化、整矩阵受一个谱范数限制、以及某些标定参数共同变化，形成的可行扰动集合不同。把某个矩阵范数条件数当成所有物理误差的精确刻画，可能过度悲观，也可能忽略真正受约束的结构。

<a id="num3-1-4"></a>

### 1.4 秩亏、病态与部分可识别量

对有 $`n`$ 个未知量的观测模型，若 $`\operatorname{rank}(A)<n`$，即不满列秩，就存在非零 $`z`$ 使 $`Az=0`$。于是 $`x`$ 与 $`x+tz`$ 对任意实数 $`t`$ 都给出相同观测，再精密的算术也无法根据同一份测量区分它们。宽矩阵即使满行秩也可能出现这种不可识别性，例如 $`A=(1,1)`$ 满行秩，但只能确定两个参数的和。

对可逆方阵，病态不影响精确解的唯一性；对一般满列秩矩阵，最小二乘解唯一，但带噪右端未必位于列空间，原等式可能无精确解。即使唯一解存在，小奇异值也可能使某些参数方向的观测变化落在噪声水平以下，形成实际上的近似不可识别。必须区分精确可解性、代数唯一性与数据支持的可分辨性。

完整参数不可识别，并不意味着所有目标都不可识别。要恢复 $`c^\mathsf Tx`$，其对零空间位移的变化为 $`tc^\mathsf Tz`$。因此它在所有等价解上保持不变，当且仅当 $`c`$ 与零空间正交，也就是 $`c`$ 位于 $`A`$ 的行空间。这个判据提供了重新设计问题的方法：与其追逐不可见的每个分量，不如报告由观测支持的线性组合。

例如只测到 $`x_1+x_2`$，两个参数各自不可识别，但总和可以直接估计。如果再加一个“两个参数应该接近”的惩罚，算法可能输出相等的两个数；这反映额外偏好，不表示仪器真的分别测到了它们。科学报告应把数据可识别的量与依靠约束选出来的量分别说明，尤其不能给后者配上只反映读数噪声的过窄置信范围。

## 2. 正则化改变问题：从求逆转为信息取舍

<a id="sec-2-1"></a>

### 2.1 机制展开：岭估计是在新的目标上取最优

考虑目标 $`\Vert Ax-b\Vert ^2+\lambda\Vert x\Vert ^2`$，其中 $`\lambda>0`$。求导得到 $`(A^\mathsf TA+\lambda I)x_\lambda=A^\mathsf Tb`$。即使 $`A`$ 秩亏，加入正数倍单位阵后，二次目标仍严格凸，解唯一。唯一性来自目标中对参数长度的偏好，而不是来自增加测量。用更容易求解的新目标代替原目标，是正则化的核心操作。

将 $`A=U\Sigma V^\mathsf T`$ 代入，有 $`x_\lambda=\sum_{j=1}^r \sigma_j(\sigma_j^2+\lambda)^{-1}(u_j^\mathsf Tb)v_j`$。原本的逆增益为 $`\frac{1}{\sigma_j}`$，现在改成 $`\frac{\sigma_j}{(\sigma_j^2+\lambda)}`$。当奇异值很小时，后者趋近于零，因而不会无界放大相同幅度的测量噪声；与此同时，它也不会完整保留该方向的真实信号。

有人把岭回归写成损失均值加惩罚，或写成惩罚系数的平方。本章始终采用平方和加 $`\lambda\Vert x\Vert ^2`$。如果数据项改成 $`\frac{\Vert Ax-b\Vert ^2}{m}`$，相同解对应的惩罚系数应除以 $`m`$。若文献用 $`\alpha^2`$，则本章的 $`\lambda=\alpha^2`$。不对齐定义，比较“最优正则参数”没有意义。

<a id="deep-dive-2"></a>

### 2.2 深入讲解：病态系统的敏感方向和正则化偏差

仍取 $`A=\operatorname{diag}(1,10^{-3})`$，真解 $`(1,1)`$，实际观测 $`(1,0.002)`$。若 $`\lambda=10^{-6}`$，岭解为 $`(\frac{1}{(1+10^{-6})},1)`$。第二个分量恰好恢复正确，是因为噪声使观测翻倍，而收缩恰好减半。不要据此宣布此参数普遍最优；换成第二个观测为零，相同参数仍返回零，无法凭空重建被噪声抵消的信号。

这一算例表明，单个噪声实现上“有偏”估计也可能比无偏估计更接近真值。偏差是重复采样后的均值偏离，方差是估计围绕其均值的波动；单次误差还受噪声符号影响。理论风险比较通常对噪声取期望，实验则需要多次重复或明确承认只展示一次实现，不能混用两种证据。

更强正则使 $`A^\mathsf TA+\lambda I`$ 的条件数下降，其特征值为 $`\sigma_j^2+\lambda`$。但令 $`\lambda`$ 趋向无穷，条件数趋向一，解同时趋向零。如果真解不为零，这显然不能算恢复成功。矩阵更容易求解只说明算法计算新目标更可靠，不能单独证明新目标更符合科学任务。

<a id="num3-2-3"></a>

### 2.3 截断奇异值：有原则地不回答某些方向

截断奇异值分解保留前 $`k`$ 个方向，定义 $`x_k=\sum_{j=1}^k(\frac{u_j^\mathsf Tb}{\sigma_j})v_j`$。它把保留方向的信号完整通过，把其余方向设成零。因此它对应一个硬筛选：在选定子空间内求最小二乘，并在未观测零空间中选零分量。截断不是认为剩余方向真实为零，而是承认它们不值得根据当前数据进行无约束放大。

硬截断对阈值附近的选择不连续。当两个奇异值非常接近，稍微改变数据、阈值或离散模型，可能让其中一个方向被保留而另一个被剔除。如果它们对应一个近简并子空间，只盯某个单独奇异向量的物理解释也不稳妥；子空间整体可能稳定，内部基底却可以旋转。研究可解释性时，应优先讨论被恢复的子空间及其分辨能力。

岭使用平滑滤波，截断使用硬滤波，两者没有无条件优劣。如果真信号集中在少数可靠方向，截断很直观；如果信号与噪声随谱逐渐过渡，平滑滤波可能更合适。如果已知真信号在某个小奇异值方向特别强，按奇异值大小一刀切也可能舍弃重要信息。这时需要领域先验或目标导向设计，不能只凭算法名称决策。

<a id="num3-2-4"></a>

### 2.4 广义惩罚、中心与约束分别引入什么信息

一般形式为 $`\Vert W(Ax-b)\Vert ^2+\lambda\Vert L(x-x_0)\Vert ^2`$。矩阵 $`W`$ 指定读数误差的度量，$`L`$ 指定哪些参数变化需要受罚，$`x_0`$ 指定参考中心。惩罚一阶差分偏好相邻参数接近，惩罚二阶差分偏好局部接近线性；这些偏好不同于偏好参数绝对值小。应根据未知对象的物理结构解释选择，而不是把平滑看成普遍正确。

当 $`\lambda>0`$，目标唯一的充要条件是 $`\ker(WA)\cap\ker(L)=\{0\}`$。证明只需考察 Hessian 的二次型：任意 $`z`$ 对应 $`\Vert WAz\Vert ^2+\lambda\Vert Lz\Vert ^2`$，只有两个范数同时为零时才可能失去严格正定性。如果 $`L`$ 是一阶差分，常数向量不受惩罚；若测量也看不见常数分量，问题仍不唯一。增加惩罚并不自动解决全部秩亏。

非负约束、总量守恒和稀疏惩罚又是不同类型的信息。它们可能改善恢复，但解不再是固定的线性谱滤波，线性估计器的协方差公式也不能原样套用。使用非负约束应说明为什么参数不能为负；使用稀疏惩罚应说明在哪个表示中预期稀疏。若先验不匹配，稳定输出仍可能稳定地偏离真值。

<a id="sec-3"></a>

## 3. 实验的理论骨架：谱坐标、噪声与误差分解

<a id="num3-3-1"></a>

### 3.1 离散 Picard 条件到底在看什么

记真实观测系数 $`\beta_j=u_j^\mathsf Tb_\star`$，噪声系数 $`\eta_j=u_j^\mathsf Te`$，参数系数 $`\theta_j=v_j^\mathsf Tx_\star`$。在非零奇异方向上，$`\beta_j=\sigma_j\theta_j`$，直接求逆得到 $`\theta_j+\frac{\eta_j}{\sigma_j}`$。问题于是化成一串一维估计：每个读数都要除以自己的可见度，小可见度意味着高噪声增益。

离散 Picard 诊断关心真实系数是否总体上比奇异值衰减更快，从而使求逆后的有效信号仍受控。在有限维里，所有非零奇异值的商当然有限，所以它不是一个凭有限数组就能证明无限维适定性的定理；它是一种联系离散模型与平滑真解的结构假设。不能因某个系数偶尔很小或不单调，就直接宣布条件成立或失败。

实际只能看到 $`u_j^\mathsf Tb=\beta_j+\eta_j`$。若白噪声方差为 $`\tau^2`$，这些投影噪声具有同样方差，不会因为 $`\sigma_j`$ 变小而自动衰减。于是谱前端可能由信号主导，后端逐渐落在噪声平台上。再继续除以越来越小的奇异值，就会把平台抬升成巨大的参数振荡。这个交叉区域解释了正则化为何应在有限信息处分辨停止。

不要把一次 Picard 图中的噪声幅值当成精确常数。高斯噪声的绝对值起伏很大，相关噪声又可能有明显谱形状，而模型误差可能恰好沿结构性方向集中。实践中可结合重复测量估计噪声，考察多个合理模型与参数区间，并报告截断位置的不确定性。[Hansen 对离散反问题与正则化的讨论](https://epubs.siam.org/doi/10.1137/1.9780898718836.ch4)提供了这一分析框架。

<a id="num3-3-2"></a>

### 3.2 固定线性估计器的偏差与协方差

设估计器为 $`\widehat x=Rb`$，且 $`\mathbb E[e]=0`$、$`\operatorname{Cov}(e)=C_e`$。那么均值为 $`RAx_\star`$，偏差为 $`(RA-I)x_\star`$，协方差为 $`RC_eR^\mathsf T`$。平方参数误差的期望等于偏差范数平方加协方差迹。这一步来自展开平方后噪声项均值为零，不需要高斯分布；高斯假设主要用于进一步的概率区间与似然解释。

对白噪声和谱滤波 $`R=\sum_j f_j\sigma_j^{-1}v_ju_j^\mathsf T`$，可识别方向的风险分解为 $`\sum_j(1-f_j)^2\theta_j^2+\tau^2\sum_j\frac{f_j^2}{\sigma_j^2}`$。若真解还含零空间分量，必须再加该分量的范数平方。这个最后项无法通过观测恢复，不能因为只写非零奇异值求和就把它遗忘。

上述公式把滤波因子视为预先固定。如果根据同一份带噪观测选择 $`\lambda`$ 或 $`k`$，最终估计器一般不再对 $`b`$ 线性，且选择过程与噪声相关。此时不能把选出的滤波因子塞回固定参数公式就称作完整风险。可以用该公式理解机制，但评估最终流程需要重做选择的重复实验或真正独立的测试数据。

<a id="num3-3-3"></a>

### 3.3 参数误差、预测误差与残差为何指向不同参数

参数风险对第 $`j`$ 个方向的噪声代价是 $`\frac{\tau^2 f_j^2}{\sigma_j^2}`$，而无噪声观测空间风险 $`\mathbb E\Vert A\widehat x-Ax_\star\Vert ^2`$ 的对应代价是 $`\tau^2 f_j^2`$。小奇异值方向在参数空间很危险，在原测量空间却可能影响很小。因此预测最优参数不保证重建最优参数，低预测误差也不能证明每个物理参数都准确。

训练残差还包含估计与当前噪声的相互作用。记平滑矩阵 $`H=AR`$，残差为 $`(I-H)b`$；减少正则通常允许 $`H`$ 吞掉更多噪声，故残差下降可能伴随参数误差上升。对于可逆方阵，完全求逆的训练残差可以为零，这只表示所有读数都被解释，包括其中的误差。

若未来预测使用另一个算子 $`B`$，任务风险应为 $`\mathbb E\Vert B\widehat x-Bx_\star\Vert ^2`$。某方向在 $`A`$ 下不敏感，却可能在 $`B`$ 下很敏感，原观测上的验证便不能自动保证新仪器或新位置的预测。面对外推任务，应检查 $`B`$ 是否依赖 $`A`$ 几乎看不见的方向，并用领域约束或补充测量处理信息缺口。

<a id="num3-3-4"></a>

### 3.4 分辨率矩阵说明恢复的对象被怎样模糊

定义参数分辨率矩阵 $`S=RA`$。若真实参数是单位脉冲 $`e_i`$，无噪声重建为第 $`i`$ 列 $`Se_i`$；它展示该位置的信号如何扩散到周围。岭的谱表示为 $`S=V\operatorname{diag}(f_j)V^\mathsf T`$，其中 $`f_j=\frac{\sigma_j^2}{(\sigma_j^2+\lambda)}`$，可识别方向被不同程度压缩，零空间方向完全丢失。

分辨率与方差常形成取舍。强正则令 $`S`$ 远离单位阵，特征被模糊，但重复测量产生的重建变化较小；弱正则使 $`S`$ 在更多方向接近单位阵，却增加噪声放大。仅给重建曲线旁边一条很窄的波动带，无法说明系统性模糊有多强。应该同时展示或讨论分辨率、偏差来源与随机波动。

分辨率矩阵也依赖坐标定义。像素大小改变、参数单位改变或基函数重新归一化，都会影响某个单位脉冲代表的物理量。比较不同网格的点扩散行为时，应统一积分权重和物理单位，否则“更尖锐”的重建可能只是脉冲幅值或像素面积不同。数值图形必须与测量模型一起解释。

图使用 41 个等距网格点和周期边界，卷积核定义为 $`k_j=c\exp[-\frac{d_j^2}{2(1.2)^2}]`$，其中 $`d_j=\min(j,41-j)`$，常数 $`c`$ 使全部核权重之和为一。前向矩阵为 $`A_{rc}=k_{(r-c)\bmod41}`$；因此每个读数是相邻参数的加权平均。把中间一个参数设为一、其他设为零，就得到一个明确的测试脉冲，避免把任意“尖峰”绘图当成同一个输入。

## 4. 手工解释病态例子：把信息与计算误差分开

<a id="num3-4-1"></a>

### 4.1 四个方向的完整手算

取 $`A=\operatorname{diag}(1,10^{-1},10^{-2},10^{-3})`$，真解 $`x_\star=(1,1,1,1)`$，无噪声观测 $`(1,0.1,0.01,0.001)`$。令噪声为 $`(0,0,0.001,0.001)`$，实际观测为 $`(1,0.1,0.011,0.002)`$。直接求逆得到 $`(1,1,1.1,2)`$，参数平方误差为 $`0.01+1=1.01`$，而对实际输入的残差为零。

截断到前三个方向得到 $`(1,1,1.1,0)`$，参数平方误差仍是 $`1.01`$，因为第三方向噪声代价加上第四方向舍弃真信号的代价，恰好与原来相同。截断到前两个方向得到 $`(1,1,0,0)`$，平方误差为二，反而更差。这说明“去掉小奇异值”只是稳定化机制，不是每个样本上都会减少误差的承诺。

若第四个噪声改成 $`0.01`$，完全求逆的第四分量变为十一，平方误差贡献为一百，截断前三项仍只损失一个单位的真信号。方法的收益取决于噪声与真实系数在各方向的相对大小。一个公平算例应该同时呈现正则有利和不利的情形，让读者看到选择所依赖的信息，而非只记住“正则化一定更好”的口号。

<a id="num3-4-2"></a>

### 4.2 一个方向的最优收缩揭示无法回避的未知量

只看某个奇异方向，估计为 $`f(\theta+\frac{\eta}{\sigma})`$，其中噪声方差为 $`\tau^2`$。其均方误差为 $`(1-f)^2\theta^2+\frac{f^2\tau^2}{\sigma^2}`$。对 $`f`$ 求导并令其为零，得到理想收缩 $`f_\star=\frac{\theta^2}{(\theta^2+\frac{\tau^2}{\sigma^2})}`$。信号越强越该保留，噪声放大越强越该收缩。

这个公式不是直接可用的选参算法，因为它需要未知真系数 $`\theta`$。它的价值在于说明困难所在：单凭奇异值不能知道该方向有没有重要真实结构，单凭一次观测也难区分信号与噪声。正则参数选择方法都在用某种额外假设、验证信息或聚合结构近似处理这一未知量，不能把任何方法包装成不需要信息的魔法。

岭的所有方向由同一个参数关联，$`f_j=\frac{\sigma_j^2}{(\sigma_j^2+\lambda)}`$，一般不等于逐方向的理想收缩。广义惩罚改变不同方向的偏好，多参数正则则增加灵活性和选参难度。模型更复杂未必更好，因为额外自由度也需要额外证据。数据极少时，清楚解释的简单偏好可能比难以验证的细粒度适应更可靠。

<a id="num3-4-3"></a>

### 4.3 扰动实验怎样区分三类错误

第一类是计算误差：输入 $`A,b`$ 被视为确定，改变求解器、精度或停止容差，比较对同一问题的数值答案。第二类是数据误差：使用同一个稳定算法，对符合噪声模型的多个右端重复求解，观察参数分布。第三类是模型误差：改变边界条件、离散网格、标定参数或核函数，检查结论是否稳健。这三组实验回答不同问题，不能用其中一种替代另外两种。

一个算法后向稳定，说明它的计算结果可解释为附近输入的精确结果。在病态问题中，这一性质非常重要，却不意味着附近输入对应的参数也相近。提高精度可以减少算法引入的扰动，但若传感器已经有千分之一误差，追求十六位参数数字通常没有科学意义。额外数字可能只是对含噪方程的精确拟合。

当计算误差远低于数据误差时，可以把资源用于改进测量或模型；当迭代误差仍大于正则化目标允许的误差时，则应先解决求解过程。实践中可用多个求解容差比较目标值、梯度和关心的预测量，直到算法误差对任务结论不再重要。这里不要求每个中间变量都达到机器精度，而要求误差预算与任务精度一致。

<a id="sec-5"></a>

## 5. 进阶：SVD 滤波与正则化参数选择

<a id="sec-5-1"></a>

### 5.1 奇异值滤波如何体现偏差与方差

用统一记号 $`f_j`$ 表示信号保留比例。直接求逆取一，截断取零或一，岭取介于零与一之间的平滑值。参数估计的观测增益为 $`\frac{f_j}{\sigma_j}`$，信号增益为 $`f_j`$，这两个量不能混淆。有人看到岭对很小奇异值的信号保留比例很低，便说它“方差也按同样比例降低”；正确的方差比例是 $`f_j^2`$，而绝对方差还带有 $`\frac{\tau^2}{\sigma_j^2}`$。

对固定正则参数，增益大小可以直接给出稳定性上界。岭增益函数 $`g(\sigma)=\frac{\sigma}{(\sigma^2+\lambda)}`$ 在 $`\sigma=\sqrt\lambda`$ 达到最大值 $`\frac{1}{(2\sqrt\lambda)}`$。因此 $`\Vert R_\lambda e\Vert \leq\frac{\Vert e\Vert }{(2\sqrt\lambda)}`$，这是控制观测噪声影响的一种简洁方式。它只是上界，不表示所有噪声都沿最大增益方向。

无噪声偏差为 $`(R_\lambda A-I)x_\star`$。在可识别非零方向上，随 $`\lambda`$ 趋零该偏差趋零；零空间分量则始终无法恢复。因此“正则化参数趋零就得到真解”需要至少说明真解是否在所采用的最小范数代表中。在秩亏情形，数据只能确定等价类，不能凭极限选择恢复一个任意指定的零空间分量。

<a id="num3-5-2"></a>

### 5.2 噪声有界时的确定性收敛思路

设无噪声真解位于可识别空间，观测误差满足 $`\Vert e\Vert \leq\delta`$。分解 $`x_\lambda(b)-x_\star=[R_\lambda Ax_\star-x_\star]+R_\lambda e`$，第一项是正则化偏差，第二项是噪声放大。若随 $`\delta\to0`$ 选择 $`\lambda(\delta)\to0`$，同时 $`\frac{\delta}{\sqrt{\lambda(\delta)}}\to0`$，则在固定有限维模型中，上述两项都趋向零。

这组条件是便于证明的充分条件，不是每个固定矩阵都必须遵守的最弱条件。固定满秩有限维矩阵本身有有界逆，只要数据误差趋零，完全求逆也会收敛。正则化理论真正有力量的场景常包含网格不断细化、奇异值不断变小或无限维紧算子的极限，此时需要避免把固定维度的简单结论误当成解决所有离散化问题。

更细的收敛速率需要真解的平滑或源条件。例如假设 $`x_\star=(A^\mathsf TA)^\nu w`$，并控制 $`\Vert w\Vert `$，便把真信号在小奇异方向上的幅度与奇异值联系起来。这样的假设让偏差可以定量上界，但它也是关于未知真解的实质信息。理解速率时，应先问平滑类是否可信，而不是只比较指数哪个更好看。

<a id="num3-5-3"></a>

### 5.3 差异原则：不要比噪声更认真地拟合噪声

若知道 $`\Vert e\Vert \leq\delta`$，差异原则可寻找使残差约为 $`c\delta`$ 的解，安全因子 $`c>1`$。直觉是：观测本来就离理想预测不超过这个尺度，再要求残差远小于噪声预算，可能只是在解释误差细节。对岭的一般情形，残差随 $`\lambda`$ 增大不减，因此可沿正则路径寻找与预算匹配的位置。

残差单调性可以在谱坐标直接看出。可识别部分的残差系数为 $`[\frac{\lambda}{(\sigma_j^2+\lambda)}]u_j^\mathsf Tb`$，其绝对值随参数增大不减；不在列空间中的读数分量无法拟合，始终留在残差里。这也说明为什么某些噪声预算无解：若预算小于不可拟合分量范数，任何参数都达不到；若预算大于零解残差，则可能偏向全部抹去。

若只知道独立同方差噪声标准差 $`\tau`$，$`\sqrt m\tau`$ 是噪声范数的典型尺度，而不是每次都成立的严格上界。需要概率保证时，应利用分布假设选相应分位数；只有二阶矩时可用较保守的概率界。不能在推导中把确定性误差界与均方噪声大小悄悄交换。

模型失配也会进入残差。如果前向算子遗漏某种物理机制，即使用正确参数也不能把残差压到仪器噪声水平。此时差异原则可能选择过弱正则甚至没有可行参数。应先检查残差是否有结构、标定误差是否被计入预算，而不是单纯扩大搜索范围。噪声预算应该对应整个被当成误差的来源。

<a id="num3-5-4"></a>

### 5.4 独立验证与广义交叉验证分别估计什么

若能独立获得同一对象的第二份观测 $`b^{\rm val}=Ax_\star+e^{\rm val}`$，可用 $`\Vert A\widehat x_\lambda-b^{\rm val}\Vert ^2`$ 比较参数。独立且零均值的验证噪声使其期望等于观测空间预测风险加常数噪声能量。因此它主要选择预测准确的解，不直接选择参数重建最优解；这与前面的风险区别一致。

只有一份数据时，线性平滑模型常用广义交叉验证，定义 $`\operatorname{GCV}(\lambda)=\frac{\frac{\Vert  (I-H_\lambda)b\Vert ^2}{m}\,}{[1-\frac{\operatorname{tr}(H_\lambda)}{m}]^2}`$。分母使用平均杠杆值近似逐点留一的校正，惩罚过度贴合观测。这里 $`H_\lambda=A R_\lambda`$，迹是模型在观测空间使用的有效自由度，不等于参数个数，也不等于无偏恢复的方向数。

对固定设计、固定 $`\lambda`$ 的岭或相应二次惩罚最小二乘，若采用损失平方和且删点后保持同一个惩罚强度，并满足 $`1-H_{ii}\ne0`$，逐点留一残差可写成 $`\frac{r_i}{(1-H_{ii})}`$。这是对应拟合规则的代数性质，不能仅凭“线性平滑器”就推广到任意删点重拟合程序。

独立同方差观测误差则服务于这里的验证风险解释。广义交叉验证用共同分母代替每个样本自己的分母，因此在杠杆高度不均时可能与精确留一差异较大。相关噪声、块状依赖、数据顺序与预处理泄漏也会破坏简单解释，需要先调整验证单位或使用相应协方差模型。

无正则可插值时，分子与分母都可能接近零，数值上应避免直接把一个不稳定比值当成可靠最小点。搜索范围、参数网格、迹计算精度和端点行为都要检查。广义交叉验证可以给出有用数据准则，但不是对任意反问题都最优的证明；它同样依赖噪声和设计结构。[参数选择的系统讨论](https://epubs.siam.org/doi/abs/10.1137/1.9780898718836.ch5)可作为进一步阅读。

精确留一校正可以从删去一条方程的正规方程推出。令 $`K=A^TA+\lambda I`$ 可逆，$`a_i^T`$ 是第 $`i`$ 行，$`\hat x=K^{-1}A^Tb`$，$`r_i=b_i-a_i^T\hat x`$。删点后保持同一个平方和惩罚，设 $`\Delta=\hat x_{(-i)}-\hat x`$，相减得到

$$
(K-a_ia_i^T)\Delta=-a_i r_i.
$$

记 $`h_i=a_i^TK^{-1}a_i`$。若 $`h_i\ne1`$，把候选 $`\Delta=-\frac{K^{-1}a_i r_i}{(1-h_i)}`$ 代回便验证方程，因此删点预测误差为 $`b_i-a_i^T\hat x_{(-i)}=\frac{r_i}{(1-h_i)}`$。于是 $`\operatorname{LOO}=m^{-1}\sum_i[\frac{r_i}{(1-h_i)}]^2`$。GCV 用平均值 $`\bar h=m^{-1}\sum_i h_i`$ 替换各个 $`h_i`$，保留相同的整体复杂度修正，却丢掉“哪条记录同时有多大杠杆和多大残差”的对应信息。所有杠杆相同时两式相等，一般情形不能交换求和与分母。

一个不含截距的完整算例取 $`A=(1,2,4)^T`$、$`b=(1,0,0)^T`$、$`\lambda=1`$。此时 $`K=22`$、$`\hat x=\frac{1}{22}`$，拟合值为 $`\frac{(1,2,4)^T}{22}`$，残差为 $`\frac{(21,-2,-4)^T}{22}`$，杠杆为 $`\frac{(1,4,16)}{22}`$。逐点留一残差依次是 $`1,-\frac{1}{9},-\frac{2}{3}`$，故 $`\operatorname{LOO}=\frac{118}{243}\approx0.48560`$。另一方面，残差平方和为 $`\frac{461}{484}`$，$`\bar h=\frac{7}{22}`$，从而 $`\operatorname{GCV}=\frac{461}{675}\approx0.68296`$。这里两者使用相同拟合器、同一数据与同一参数，差异完全来自校正方法。比较参数候选时应真正计算相应准则，而不能把二者视为数值近似必然很好的同义词。

若原目标写成 $`m^{-1}\Vert Ax-b\Vert ^2+\alpha\Vert x\Vert ^2`$，对应平方和惩罚是 $`\lambda=m\alpha`$。删去一行后继续保持同一个 $`\alpha`$，平方和惩罚会变成 $`(m-1)\alpha`$，已不满足上面固定 $`K`$ 的推导。此时应按实际删点规则重新拟合，或者明确固定的是平方和惩罚。尺度约定会改变验证算法，不能只在全数据拟合时对齐一次参数名称。

<a id="num3-5-5"></a>

### 5.5 L 曲线、可视诊断与多准则判断

L 曲线在对数坐标展示残差范数与惩罚范数。强正则时参数长度小、残差大；弱正则时残差小、参数长度可能因噪声膨胀。若曲线上出现明显拐角，它可提示从主要减少偏差过渡到主要放大噪声的区域。这是一种诊断，不是一个无需前提的真值检测器。

曲线不一定存在清楚拐角，可能有多个弯折，也可能因网格范围或数值差分而产生伪曲率峰值。坐标尺度、惩罚矩阵与参数采样密度都会影响图形。若用曲率自动选点，必须说明是在什么参数化下计算、端点怎样处理，以及结果对网格加密是否稳健。把眼睛觉得好看的拐点包装成唯一最优值，会掩盖这些选择。

更可取的研究流程是同时看噪声预算、验证风险、重建结构稳定性与领域约束。不同准则不一致时，应先理解它们优化的目标是否不同。例如验证选出较小参数，因为预测只在可靠方向上计分；重建则需要更强平滑以抑制不可见方向。矛盾可能来自任务定义，而不一定是某个准则实现错误。

<a id="num3-5-6"></a>

### 5.6 单位与网格会改变正则化的含义

若重新定义参数 $`z=Dx`$，同一个物理目标 $`\Vert x\Vert ^2`$ 在新坐标中应写成 $`\Vert D^{-1}z\Vert ^2`$。如果直接改用 $`\Vert z\Vert ^2`$，就改变了各方向的惩罚权重。类似地，观测某一行换单位后，必须相应调整误差度量，否则同一次实验只是换了单位便能改变估计结果。物理上合理的流程应对一致的单位换算保持等价。

连续函数的平方积分用均匀网格近似时通常含网格宽度，例如 $`h\sum_i x_i^2`$；导数平滑惩罚还含差分除以网格宽度的因子。如果细化网格却沿用未经缩放的差分矩阵与同一参数数值，就未必在逼近同一个连续目标。比较不同分辨率时，要写清离散算子、积分权重、边界条件和惩罚的缩放。

粗网格本身也能起正则化作用，因为它限制了可表达的高频方向。但粗网格会带来逼近偏差，细网格则可能增加噪声敏感性。网格选择与参数选择因此相互关联，不应先通过真值挑最漂亮的网格，再把同一真值上的恢复误差称为独立测试。研究中可以使用人工真值分析机制，最终泛化结论仍需要独立设计。

三条密度曲线对应 $`\lambda=0,0.01,0.1`$，均值分别为一、二分之一、十一分之一，标准差也恰好为这三个数。分布越来越尖，却向零收缩而远离真实系数一。它们是固定真值下重复生成观测所得的抽样分布，不是给定一份数据后的贝叶斯后验。正态假设只用于画这些曲线；右图的二阶风险分解只需要前述噪声均值与方差条件。

只画一个已知真实系数的理论例子，实际不能直接观察真值来选λ；交叉验证或其他选参方法必须另行评价。

## 6. 更进一步：相关噪声、先验与实验设计

<a id="num3-6-1"></a>

### 6.1 非白噪声为什么必须改变数据度量

若误差协方差 $`C_e`$ 正定，合理的二次数据项常为 $`(Ax-b)^\mathsf TC_e^{-1}(Ax-b)`$。令 $`C_e=CC^\mathsf T`$ 为 Cholesky 分解，计算 $`\widetilde A=C^{-1}A`$ 与 $`\widetilde b=C^{-1}b`$，便得到白化后的欧氏残差。实现时使用三角求解，而不是显式构造协方差逆矩阵；白化的目标是让各方向按其误差可信度计权。

例如两次测量各自方差相同且正相关很强，它们的平均方向噪声较大，差分方向噪声反而较小。忽略相关性会把两个读数当成近乎独立证据，高估某些信息，低估另一些信息。反过来，如果仪器共模误差占主导，把重复读数简单当成样本数翻倍，会制造虚假的精度提升。

白化后应重新分析奇异谱和 Picard 系数，因为“危险方向”是相对于噪声度量定义的。原坐标下的小奇异值不一定在白化后仍同样小。若协方差本身来自有限重复测量，它也有估计误差；直接求很小协方差特征值的倒数，可能引入新的不稳定性，需要收缩估计、低维噪声模型或灵敏度分析。

<a id="num3-6-2"></a>

### 6.2 贝叶斯解释有帮助，但后验宽度不等于重复采样误差

假设误差为高斯 $`N(0,C_e)`$，先验为 $`x\sim N(x_0,C_x)`$，其中 $`C_e,C_x`$ 均正定，且先验与误差独立。将负对数后验整体乘二并忽略加法常数后，得到二次数据项加 $`(x-x_0)^\mathsf TC_x^{-1}(x-x_0)`$。后验均值与众数相同，由精度矩阵 $`A^\mathsf TC_e^{-1}A+C_x^{-1}`$ 决定。这给广义 Tikhonov 提供了明确概率解释：惩罚强弱反映先验不确定性，而非只为让矩阵好求。

固定真解的重复测量协方差为 $`RC_eR^\mathsf T`$，贝叶斯后验协方差则为 $`(A^\mathsf TC_e^{-1}A+C_x^{-1})^{-1}`$。两者不同，因为前者只随机化噪声、真解固定，后者把真解也视为先验随机变量。混用这两个矩阵，会在不知不觉中改变概率陈述。写置信或可信区间时，应明确概率是针对什么随机机制。

先验错误可能导致看似精确却偏离真实的后验，尤其在数据不敏感方向上。强先验能产生很窄区间，但这个窄度反映对先验的信任，而不是新读数带来的信息。可通过改变合理先验尺度、相关长度或中心检查任务结论的敏感性；在数据无法分辨的方向，坦诚报告先验依赖比增加小数位更有价值。

<a id="num3-6-3"></a>

### 6.3 迭代也可以正则化，但不能只看线性系统残差

考虑 Landweber 迭代 $`x_{t+1}=x_t+\omega A^\mathsf T(b-Ax_t)`$，初值为零，且 $`0<\omega<\frac{2}{\sigma_1^2}`$。沿第 $`j`$ 个奇异方向，它的信号滤波因子为 $`f_j^{(t)}=1-(1-\omega\sigma_j^2)^t`$。大奇异值方向较快进入解，小奇异值方向需要更多迭代才显现。提前停止于是可以把迭代次数当成正则强度。

为方便单调解释，可进一步取 $`0<\omega\leq\frac{1}{\sigma_1^2}`$，此时每个滤波因子从零单调趋一。早期主要减少偏差，后期噪声在小奇异方向逐渐进入，参数误差可能先降后升，而数据残差继续下降。这叫半收敛现象。它说明把内层迭代一律跑到极小残差，可能正好破坏本来依赖早停的恢复效果。

若已经显式加入正则项，再用迭代算法求该目标，必须区分两类停止：一种把未充分求解当成额外正则，另一种希望准确求出既定正则目标。二者都可以研究，但应清楚定义最终方法。不能在选参实验里对不同参数使用差异巨大的未收敛程度，然后把性能差异全归因于参数本身。

<a id="num3-6-4"></a>

### 6.4 改进测量往往比改进求逆更有效

若某方向 $`v`$ 满足 $`\Vert Av\Vert `$ 极小，可以增加对该方向敏感的新测量。例如原来只观测总和，新增差分测量便能分辨两个分量。在白噪声模型中，信息矩阵与 $`A^\mathsf TA`$ 相关；新增一行测量向量 $`a^\mathsf T`$ 增加 $`aa^\mathsf T`$。它是否有帮助取决于该向量是否补充了当前薄弱方向，而不是只看测量数量。

重复完全相同的测量在独立噪声下可以降低该方向方差，却不会消除原零空间。若重复噪声高度相关，收益还会更小。实验设计因此需要同时考虑方向覆盖、噪声协方差、成本和可实施约束。一个更高精度但方向重复的传感器，未必比一个精度一般却提供新方向信息的传感器更有价值。

若只关心目标 $`c^\mathsf Tx`$，应关注该目标在弱方向上的投影，而不是笼统追求所有奇异值都大。设计可以针对任务优化，但不能使用最终测试真值暗中挑选最有利的仪器配置。人工真值可帮助探索设计机制，正式性能结论应来自明确的对象分布、最坏情形集合或独立测试对象。

<a id="visual-extension-numericalmethods-03"></a>
### 图解：白化相关观测噪声需要旋转与缩放

![白化相关观测噪声需要旋转与缩放](images/03-extension.svg)

噪声协方差为 $`C_\varepsilon=\begin{pmatrix}1&0.8\\0.8&1\end{pmatrix}`$。沿单位方向 $`\frac1{\sqrt2}(1,1)`$ 的方差为 $`1.8`$，沿 $`\frac1{\sqrt2}(1,-1)`$ 的方差为 $`0.2`$；所以同样长度的残差，在第二个方向上比第一个方向更值得警惕。逆平方根白化把这两个方向分别缩放 $`\frac1{\sqrt{1.8}}`$ 与 $`\frac1{\sqrt{0.2}}`$，得到单位协方差。

图中的椭圆是固定二次型 $`r^{\mathsf T}C_\varepsilon^{-1}r`$ 在一与四两个水平的等值线，变换后成为相同水平的圆。橙色追踪同一残差 $`r=(1,0)`$，采用对称逆平方根 $`W=C_\varepsilon^{-\frac12}`$ 后变成约 $`Wr=(1.490712,-0.745356)`$。原欧氏平方长度为一，变换后的平方长度约为 $`2.777778`$，恰好等于 $`r^{\mathsf T}C_\varepsilon^{-1}r=\frac{25}{9}`$。白化保持的是这份加权误差，而非普通欧氏长度；低噪声方向会被放大，不能把“白化”理解成每个残差都应缩短。只有另外假设高斯噪声时，才同时是等密度线；单位协方差本身不保证独立，也不能不交代半径就把圆称作某个置信水平。白化后的目标使用 $`\|C_\varepsilon^{-\frac12}(Ax-b)\|^2`$，与随意逐列标准化设计矩阵不同。协方差估计误差、小特征值和正则化选择仍需分别检查。

## 7. 完整可复现实验：谱滤波与合法选参

<a id="num3-7-1"></a>

### 7.1 实验问题、比较对象与验收指标

下面构造已知奇异谱的方阵。正交矩阵改变坐标，几何衰减的奇异值制造不同可见度，真解的谱系数平滑衰减。训练噪声、验证噪声和重复实验噪声来自固定种子的独立随机流。比较完全求逆、截断和岭的训练残差、无噪声预测误差与参数误差，明确三者并非一个指标。

为了展示选参边界，实验会计算一个“知道真解时的最佳参数”，但仅把它作为研究参照；真正数据可用的选择使用独立验证或噪声预算。真值参照不能用于实际部署，也不能在用它调整实验设置后继续称同一真值完全未见。固定种子旨在复现，不代表某一次噪声就是总体平均。

代码只依赖 NumPy，不写文件，不绘图。它使用 SVD 坐标求解正则路径，避免直接形成病态正规方程。完整实验包含固定参数风险的 Monte Carlo 核验、分辨率矩阵检查和 Landweber 半收敛。打印值用于比较趋势，断言检查理论关系和合法性，不要求不同 BLAS 环境下最后一位完全一致。

```python
import numpy as np

rng = np.random.default_rng(20261017)
n = 32
U, _ = np.linalg.qr(rng.normal(size=(n, n)))
V, _ = np.linalg.qr(rng.normal(size=(n, n)))
s = np.geomspace(1.0, 1e-7, n)
A = (U * s) @ V.T
theta = 1.0 / np.arange(1, n + 1, dtype=float)**1.5
x_true = V @ theta
b_true = A @ x_true
tau = 2e-4
b = b_true + rng.normal(0.0, tau, n)
b_val = b_true + rng.normal(0.0, tau, n)
z = U.T @ b
lams = np.geomspace(1e-12, 1e-1, 200)
factors = s[:, None]**2 / (s[:, None]**2 + lams[None, :])
path = V @ (factors * z[:, None] / s[:, None])
pred = A @ path
parameter = np.linalg.norm(path - x_true[:, None], axis=0)
residual = np.linalg.norm(pred - b[:, None], axis=0)
validation = np.linalg.norm(pred - b_val[:, None], axis=0)
assert np.all(np.diff(residual) >= -1e-12)

j_val = int(np.argmin(validation))
j_oracle = int(np.argmin(parameter))
delta = np.sqrt(n) * tau
eligible = np.flatnonzero(residual <= 1.2 * delta)
j_dp = int(eligible[-1]) if eligible.size else None
x_inverse = V @ (z / s)
ks = np.arange(1, n + 1)
x_tsvd = V @ ((np.arange(n)[:, None] < ks[None, :])
               * (z / s)[:, None])
j_tsvd = int(np.argmin(np.linalg.norm(A @ x_tsvd - b_val[:, None], axis=0)))
print('inverse parameter error:', np.linalg.norm(x_inverse - x_true))
for name, j in [('validation', j_val), ('oracle only', j_oracle),
                ('discrepancy', j_dp)]:
    if j is not None:
        print(name, 'lambda=', lams[j], 'parameter=', parameter[j],
              'residual=', residual[j])
print('validation TSVD rank:', ks[j_tsvd])

# Fixed lambda: verify theoretical MSE, without re-selecting lambda per draw.
lam_fixed = 1e-6
f = s*s / (s*s + lam_fixed)
theory = np.sum((1-f)**2 * theta**2) + tau*tau*np.sum((f/s)**2)
noise = rng.normal(0.0, tau, size=(n, 12000))
x_many = V @ ((f / s)[:, None] * (s[:, None]*theta[:, None] + noise))
empirical = np.mean(np.sum((x_many-x_true[:, None])**2, axis=0))
assert abs(empirical/theory - 1) < 0.06
R = (V * (f/s)) @ U.T
S = R @ A
assert np.allclose(S, (V*f) @ V.T, atol=2e-9)
assert np.allclose(S, S.T, atol=2e-9)
print('fixed-lambda MSE theory/empirical:', theory, empirical)

# Landweber uses the spectral recurrence of the same iteration.
# This avoids thousands of small dense products and changes no mathematics.
times = np.unique(np.geomspace(1, 1000000, 200).astype(int))
f_iter = -np.expm1(times[None, :] * np.log1p(-0.8*s[:, None]**2))
x_iter = V @ (f_iter*z[:, None]/s[:, None])
iter_error = np.linalg.norm(x_iter-x_true[:, None], axis=0)
iter_residual = np.linalg.norm(A @ x_iter-b[:, None], axis=0)
assert np.all(np.diff(iter_residual) <= 1e-11)
print('Landweber best sampled t/error:', times[np.argmin(iter_error)],
      np.min(iter_error), 'last error:', iter_error[-1])
```

<a id="num3-7-2"></a>

### 7.2 怎样读结果而不把一次实现当成定理

完全求逆的参数误差通常很大，因为最小奇异值达到千万分之一，而观测噪声远高于这个方向的真实信号。岭和截断在验证选择后通常大幅改善重建，但本次验证选择未必等于参数真值参照选择。这一差异有合理原因：验证优化观测空间风险，而且验证本身也含噪声。不能只因为两个参数不同，就认定某种选择失败。

差异原则这里使用 $`\sqrt n\tau`$ 的典型尺度和安全因子，并没有得到每次噪声范数都小于预算的确定保证。代码故意保留可能没有满足条件候选的情况，输出空状态而不是编造一个成功参数。真实接口还应区分搜索范围不够、模型失配和噪声预算错误，必要时调整模型后重新设计整个实验。

固定参数的经验风险接近理论风险，验证的是线性估计公式与实现是否相符。它不验证通过同一噪声选择参数之后的完整风险，也不验证模型与现实一致。Landweber 部分则说明残差继续下降时参数误差可能重新上升；即使在某个种子或采样区间里上升不明显，滤波机制与一般风险分析依然成立，不应为追求漂亮曲线反复挑种子。

<a id="num3-7-3"></a>

### 7.3 相关噪声白化的独立实现

下面用三维算例检查白化目标与原协方差度量是否一致。第一与第二个读数高度相关，第三个更不精确。代码显式展示普通岭与广义最小二乘岭会产生不同参数；这两个结果的差异本身不证明哪个单次结果更接近真值，而是表明它们使用了不同的误差模型。

```python
import numpy as np

A = np.array([[1., 0.], [1., 0.1], [0., 1.]])
b = np.array([1.1, 1.0, 1.4])
Ce = np.array([[0.01, 0.009, 0.],
               [0.009, 0.01, 0.],
               [0., 0., 0.25]])
C = np.linalg.cholesky(Ce)
Aw = np.linalg.solve(C, A)
bw = np.linalg.solve(C, b)
lam = 0.2
# The augmented least-squares formulation avoids normal equations.
aug = np.vstack([Aw, np.sqrt(lam)*np.eye(2)])
yaug = np.concatenate([bw, np.zeros(2)])
xw = np.linalg.lstsq(aug, yaug, rcond=None)[0]
x_plain = np.linalg.lstsq(
    np.vstack([A, np.sqrt(lam)*np.eye(2)]),
    np.concatenate([b, np.zeros(2)]), rcond=None)[0]
r = A @ xw-b
assert np.allclose(np.dot(np.linalg.solve(C, r), np.linalg.solve(C, r)),
                   r @ np.linalg.solve(Ce, r))
assert np.allclose(Aw.T @ (Aw @ xw-bw)+lam*xw, 0., atol=1e-12)
print('whitened ridge:', xw, 'unweighted ridge:', x_plain)
```

对于大型协方差矩阵，不一定能保存稠密 Cholesky 因子，可能需要利用带状、稀疏或平稳结构。此时真正需要的是可靠地作用误差度量，而不是机械地构造所有逆矩阵。若白化近似本身有误差，应把它纳入灵敏度分析；求解增广最小二乘的精度再高，也不会修正错误的噪声模型。

## 8. 避免逆犯罪：研究结论必须面对模型差异

<a id="num3-8-1"></a>

### 8.1 为什么同一矩阵生成又恢复会过于乐观

人工实验常先选 $`x_\star`$，用同一矩阵 $`A`$ 生成 $`b`$，再用 $`A`$ 恢复。这个流程非常适合检验代码和谱理论，但把所有前向模型误差都排除了。真实测量可能来自更精细的连续过程、不同边界条件、仪器非线性或未知标定。算法在完全匹配的离散世界中表现优秀，不代表现实恢复同样可靠。

为了检查模型差异，可以用更细网格生成信号，再投影到粗网格测量；也可以让生成算子与反演算子使用不同但合理的核宽度、边界条件或传感器位置。关键是明确变化来自哪里，并保持物理对象与单位一致。随意向矩阵每个元素撒同幅度噪声，不一定对应任何合理仪器误差，可能误导稳健性结论。

匹配模型实验并非没有价值。它负责回答算法是否正确实现理论、选参在理想假设下是否工作、误差公式是否吻合。模型失配实验负责回答这些结论能否迁移。应该让两类实验互相补充，避免把一个用于单元核验的理想测试扩张成普遍科学证明。

<a id="num3-8-2"></a>

### 8.2 误差分解要给每个来源一个名字

若真实过程为 $`b=A_{\rm true}x_\star+e`$，反演却使用 $`A`$，则相对于反演模型的有效误差为 $`e+(A_{\rm true}-A)x_\star`$。后面一项依赖未知真解，可能不是零均值，也不与信号独立。把它与仪器噪声混成同方差白噪声，会使差异原则、协方差与验证解释失去基础。

总误差还包括离散逼近偏差、正则偏差和算法误差。一个实用分解是先指定同一离散空间中理想数据对应的目标解，再比较真实连续对象与离散目标、无噪声正则解与离散目标、含噪正则解与无噪声正则解、数值返回值与精确正则解。具体中间对象可以变化，但必须保证每项都有明确数学定义。

分解并不表示各项统计独立，也不保证范数能精确相加。三角不等式给出的误差预算可能保守，平方误差展开还会出现交叉项。报告“总误差等于四项平方和”前，必须证明相关项的期望为零或正交关系成立。对于模型失配与信号相关的情形，交叉项尤其不应被默默省略。

<a id="num3-8-3"></a>

### 8.3 从可行集合而非单个答案理解不确定性

如果只知道 $`\Vert Ax-b\Vert \leq\delta`$，可以研究满足噪声预算的所有参数。病态方向上，这个集合会很长；零空间方向上若无额外限制则无界。正则化从集合中选一个偏好解，却不一定缩小数据本身允许的集合。单点输出看起来稳定，并不等于所有与数据相容的对象都相近。

加入可信约束，例如参数非负、总量范围或平滑上界，可以真正限制可行集合，但应把它们标明为额外信息。对关心的线性量 $`c^\mathsf Tx`$，可以在集合上分别求最小与最大，得到与假设一致的区间。若区间依然很宽，正确结论是现有信息不足，而不是继续调整正则直到出现视觉上满意的单点。

这种视角也有助于解释多个重建方法的分歧。若它们都能解释观测，却在弱方向上不同，分歧可能反映不确定性，而非某个方法必定错误。可比较这些差异经 $`A`$ 作用后是否很小，并寻找能够区分它们的新测量。把分歧转化为实验设计问题，比只争论哪条重建曲线更漂亮更有科学价值。

## 9. 练习与解析：把每个结论落实到可检验对象

<a id="num3-ex-1"></a>

### 9.1 条件数大是否每次都发生巨大误差

**题目。** 对 $`A=\operatorname{diag}(1,10^{-4})`$，比较扰动 $`(10^{-4},0)`$ 与 $`(0,10^{-4})`$ 引起的参数变化。两者是否都达到最坏放大？

**解析。** 乘以逆矩阵后，第一种变化为 $`(10^{-4},0)`$，第二种为 $`(0,1)`$。绝对放大分别为一和一万。条件数反映方向间最坏尺度差，不能仅凭它预测每次扰动结果。若进一步讨论相对条件数是否达到上界，还要指定原始右端方向与范数，不能把绝对增益与相对放大混为同一个数字。

**延伸。** 如果噪声只可能沿第一方向出现，通用条件数上界会非常保守；如果第二方向噪声占主导，它就更接近真实风险。这提示应该结合协方差或结构化扰动模型分析，而不是用一个大数字结束讨论。

<a id="num3-ex-2"></a>

### 9.2 数据只给总和时哪些目标可识别

**题目。** 只观测 $`x_1+x_2=3`$，分别判断 $`x_1`$、$`x_1+x_2`$、$`2x_1+2x_2`$ 是否可识别。最小范数解表达了什么？

**解析。** 零空间由 $`(1,-1)`$ 张成。第一个目标沿该方向变化，所以不可识别；后两个目标与零空间正交，分别固定为三与六。最小范数解为 $`(1.5,1.5)`$，因为在直线约束上均分总量最小化平方长度。这个均分来自选择规则，测量本身并未证明两个参数相等。

**延伸。** 若额外知道两个参数非负，每个分量被限制在零与三之间，但仍不唯一。约束缩小可行范围与完全识别参数不同，报告中应给出这种区间信息，而不是把某个算法选出的点称为唯一事实。

<a id="num3-ex-3"></a>

### 9.3 推导固定滤波的风险

**题目。** 设单方向观测为 $`z=\sigma\theta+\eta`$，噪声均值零、方差 $`\tau^2`$，估计为 $`\frac{fz}{\sigma}`$。推导均方误差并求理想 $`f`$。

**解析。** 误差为 $`(f-1)\theta+\frac{f\eta}{\sigma}`$。平方取期望后交叉项为零，得 $`(1-f)^2\theta^2+\frac{f^2\tau^2}{\sigma^2}`$。求导得到 $`2(f-1)\theta^2+\frac{2f\tau^2}{\sigma^2}=0`$，故 $`f=\frac{\theta^2}{(\theta^2+\frac{\tau^2}{\sigma^2})}`$。若真系数为零应完全收缩；若信号极强则趋向保留。

**延伸。** 理想公式含未知真值，所以它是机制参照而非部署算法。如果用当前观测估计信号再代入，收缩系数便与噪声相关，必须分析整个新估计器，不能继续声称上面的固定系数风险就是最终风险。

<a id="num3-ex-4"></a>

### 9.4 岭的稳定性上界怎样得到

**题目。** 证明 $`\frac{\sigma}{(\sigma^2+\lambda)}\leq\frac{1}{(2\sqrt\lambda)}`$，并说明它控制哪个误差。

**解析。** 由 $`(\sigma-\sqrt\lambda)^2\geq0`$ 得 $`\sigma^2+\lambda\geq2\sigma\sqrt\lambda`$，当 $`\sigma>0`$ 时直接相除即得；零奇异值时左边为零。同样结论可通过求导得到。正交变换不改变范数，所以岭对观测误差的参数增益不超过这个数。

**延伸。** 该上界不控制正则化偏差，也不保证模型误差很小。增大参数会降低噪声影响上界，同时可能丢掉更多真信号，因此不能只最小化这个上界而把参数趋向无穷。

<a id="num3-ex-5"></a>

### 9.5 广义惩罚何时仍不唯一

**题目。** 设 $`L`$ 为一阶差分，$`A`$ 也只测参数差分。即使 $`\lambda>0`$，目标是否必定唯一？如何修正？

**解析。** 常数向量同时位于两个零空间，所以给所有分量加同一个常数不会改变数据项与惩罚项，目标不唯一。可以增加一个测总量的真实观测，或明确固定一个参考水平，或对常数方向加入可信先验。三种修正含义不同，不能把人为固定参考点伪装成额外仪器信息。

**延伸。** 检查唯一性应考察零空间交集，不是只看惩罚矩阵是否非零。差分矩阵通常有非平凡零空间，边界条件和参考约束对最终恢复对象具有实质影响。

<a id="num3-ex-6"></a>

### 9.6 差异原则为何可能没有可行参数

**题目。** 若 $`b`$ 在 $`A`$ 列空间正交补上的分量范数为 $`0.2`$，但噪声预算只有 $`0.1`$，是否存在残差不超过预算的最小二乘或岭解？

**解析。** 不存在。任意 $`Ax`$ 都在列空间中，无法消掉正交补分量，所以残差范数至少为 $`0.2`$。应检查模型失配、预算定义和测量维度，而不是无限增加迭代或缩小正则参数。数值求解器准确返回最小残差，也无法突破几何下界。

**延伸。** 若原模型正确但噪声是随机的，实际噪声范数仍可能超过典型预算。这时必须区分一次概率偏离与持续结构性失配，多次残差诊断比单个失败标志更有信息。

<a id="num3-ex-7"></a>

### 9.7 验证选参为什么未必最优重建

**题目。** 独立验证仍使用同一观测算子 $`A`$。它选择的参数与真解参数误差最优值不同，是否一定说明验证泄漏？

**解析。** 不是。独立验证的期望目标是观测空间预测风险加与参数无关的验证噪声能量。参数误差会强烈惩罚小奇异方向的噪声，而观测风险把这些误差重新乘以奇异值，权重不同。有限验证集还带来随机波动，所以两种最优参数一般不相等。

**延伸。** 若最终目标是完整参数恢复，应该解释为何所用验证指标能支持这一目标，或引入直接关于参数的标注、领域约束和不确定性分析。不能因为验证划分正确，就认为指标选择也自动正确。

<a id="num3-ex-8"></a>

### 9.8 改变单位怎样保持同一个物理惩罚

**题目。** 参数从米换成厘米，$`z=100x`$。原惩罚为 $`\lambda\Vert x\Vert ^2`$，在 $`z`$ 坐标应写成什么？如果仍写 $`\lambda\Vert z\Vert ^2`$ 会怎样？

**解析。** 由于 $`x=\frac{z}{100}`$，相同物理惩罚为 $`\frac{\lambda\Vert z\Vert ^2}{10000}`$。若沿用原系数惩罚 $`z`$，就把实际正则强度提高一万倍。还须将前向矩阵改为 $`\frac{A}{100}`$ 以保持观测一致。只有数据映射与惩罚一起换算，才是在同一问题的不同坐标中计算。

**延伸。** 各参数换算比例不同会产生非均匀惩罚矩阵。特征标准化不是纯粹无害的预处理：若惩罚保持单位阵，它等价于在原空间中引入按尺度加权的先验，应被清楚记录。

<a id="num3-ex-9"></a>

### 9.9 相关噪声下重复测量有多少信息

**题目。** 两次测同一个标量，单次噪声方差为 $`\tau^2`$，相关系数为 $`\rho`$。平均值噪声方差是多少？

**解析。** 平均误差为 $`\frac{(e_1+e_2)}{2}`$，方差为 $`\frac{\tau^2(1+\rho)}{2}`$。独立时减半，完全正相关时没有降低；负相关时可能更低，但协方差必须半正定。这个计算说明仅增加读数数量并不能决定有效信息，测量之间的误差关系同样重要。

**延伸。** 当两次观测的前向灵敏度不同，最优加权更复杂，应联合考虑设计矩阵与协方差。不能只根据相关系数给一个普遍有效样本数，然后忽略具体目标方向。

<a id="num3-ex-10"></a>

### 9.10 后验协方差与采样协方差为什么不同

**题目。** 一维模型 $`b=x+e`$，噪声方差为一，先验 $`x\sim N(0,1)`$。后验均值为 $`\frac{b}{2}`$。比较后验方差与固定真解时估计器的采样方差。

**解析。** 后验精度为一加一，所以后验方差为 $`\frac{1}{2}`$。固定真解后，估计器仅随噪声变化，其方差为 $`\operatorname{Var}(\frac{e}{2})=\frac{1}{4}`$，偏差为 $`-\frac{x}{2}`$。较小的采样方差没有包含收缩偏差，后验方差则使用了真解本身服从先验的概率模型，两者回答不同问题。

**延伸。** 若直接用采样方差画一个围绕收缩估计的窄区间，却忽略偏差，频率覆盖可能很差。若使用后验区间，则应明确先验可信程度，并检查数据薄弱方向上的先验敏感性。

<a id="num3-ex-11"></a>

### 9.11 早停为何可能优于完全迭代

**题目。** 从零开始做 Landweber，为什么小奇异方向后进入，而继续降低残差可能使参数更差？

**解析。** 第 $`j`$ 个方向的滤波因子为 $`1-(1-\omega\sigma_j^2)^t`$。当 $`\omega\sigma_j^2`$ 很小时，早期近似为 $`t\omega\sigma_j^2`$，因此该方向被抑制。随着迭代增加，滤波逐渐接近一，真实信号和观测噪声同时通过；若该方向已由噪声主导，参数风险便会升高。

**延伸。** 最佳停止次数依赖数据、噪声和任务，不能从算法收敛定理直接读出。完全收敛到含噪最小二乘解可能是计算目标上的成功，却是重建目标上的失败。

<a id="num3-ex-12"></a>

### 9.12 怎样设计一个不夸大能力的恢复实验

**题目。** 设计实验比较岭与截断，要求区分数值误差、噪声影响和模型失配，并避免用测试真值调参数。

**解析。** 先在匹配模型和无噪声数据下验证实现及谱公式，再固定若干真值和前向模型，使用多次独立训练噪声与验证噪声选参；测试阶段重新生成噪声并重做允许的选择流程。另开一组使用更精细生成模型或改变标定参数的数据，保持反演模型不变，测量失配敏感性。所有方法使用相同合法信息与同等搜索预算。

**验收。** 分别报告训练残差、无噪声观测误差、参数误差、运行成本与选择参数分布。真值最优参数只作为标注清楚的参照，不能混入可部署方法。若结果只适用于一个平滑真值家族，应限制结论范围，并加入至少一种先验不匹配对象观察失败模式。

<a id="sec-6-1"></a>

### 9.13 边界追问：条件数改善是否等于恢复更准确

**题目。** 把岭参数增大一百万倍后，正则方程条件数接近一，估计也接近零。是否可以宣布恢复质量提升？

**解析。** 只能宣布修改后目标的数值求解通常更容易。若真实参数非零，强收缩会引入显著偏差。应比较任务风险、噪声放大与先验合理性，而不是把条件数当成科学目标。一个永远返回零的程序可能非常稳定，但它并未自动利用测量恢复对象。

**继续追问。** 如果零参数真的符合某些对象，返回零可能确实表现好；关键是应通过独立证据确认对象分布或约束，而不是从求解矩阵容易计算反推出真值接近零。稳定性是必要的计算属性，准确性仍取决于信息与建模。

<a id="num3-ex-14"></a>

### 9.14 完整参数不可识别时怎样合理结束研究

**题目。** 多种合理先验得到的重建明显不同，却都符合测量噪声预算。应该继续调参直到它们一致吗？

**解析。** 应先检查差异是否集中在弱奇异方向或零空间。如果是，这可能说明现有数据不足以支持唯一细节。可报告各先验共同稳定的特征、目标线性量的可行范围，以及需要新增哪些测量才能分辨分歧。强行采用同一个更强惩罚可能让方法一致，却只是统一了偏好，没有增加证据。

**研究延伸。** 对可行重建差 $`d`$，比较 $`\Vert d\Vert `$ 与 $`\Vert Ad\Vert `$。若前者大而后者小，寻找对 $`d`$ 敏感的新测量向量，便把算法分歧转化为可执行的实验设计。这是从“更精确地计算一个点”走向“更可靠地获得知识”的关键一步。
