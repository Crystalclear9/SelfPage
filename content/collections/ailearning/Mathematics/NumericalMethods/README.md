# 数值计算

理解计算机为什么只能近似计算，以及如何让线性代数、概率和梯度运算更稳定。

**先修知识：** 微积分、线性代数；Python 与 NumPy 数组基础。第 2 章的蒙特卡洛部分还需期望、方差与采样误差。

## 学习顺序与覆盖范围

第 1 章建立表示与误差语言，第 2 章推导求导、固定求积和模拟误差；第 3 章把线性求解推进到反问题与正则化，第 4 章研究求根、自适应计算和可靠停止。第 3 章的基础分解与求解器证明可返回[线性代数稳定求解](../LinearAlgebra/03-线性方程组与稳定求解.md)，本主题重点区分输入误差、离散化、正则偏差和计算误差。第 2 章的随机积分可结合[采样大数定律与蒙特卡洛推断](../Probability/04-采样大数定律与蒙特卡洛推断.md)学习：概率论解释估计量为何收敛，本主题比较离散化、随机误差与实际计算预算。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：残差与参数误差同时报告](04-根查找数值积分与停止准则.md#sec-7-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
