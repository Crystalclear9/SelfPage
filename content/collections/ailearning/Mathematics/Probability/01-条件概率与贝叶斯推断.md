## 1. 概率模型：先说明哪些结果可能发生

概率论首先研究推理的一致性，然后才研究怎样从数据中确定模型。一个公式推导完全正确，并不保证它描述了正在讨论的人群。把一枚硬币当作公平硬币，是对实验机制的假设；把一次线上点击当作独立伯努利试验，是对用户、展示时机和反馈机制的进一步抽象。

学习概率时，应同时追问三件事：随机结果是什么，观察到了什么，哪些未知量仍然共同变化。本章通过有限事件、条件化和参数更新建立这种习惯，下一章再系统讨论随机变量与分布。

<a id="probability-1-detail-1"></a>

### 1.1 样本空间、事件与概率测度

样本空间记作 $`\Omega`$，一个结果记作 $`\omega`$。事件是允许讨论其概率的结果集合。有限模型中通常把全部子集作为事件；一般模型需要指定事件族 $`\mathcal F`$。它包含全集，对补集与可数并封闭，因此也对可数交封闭。这种结构称为一个σ代数，其作用是保证逻辑组合后的问题依然可赋予概率。概率测度 $`P`$ 为每个事件指定非负数，满足 $`P(\Omega)=1`$，以及对两两互斥事件列的可数可加性。

有限情形只需给出每个基本结果的非负权重并使总和为一。注意，样本空间有限不意味着结果等可能。投两枚硬币时，如果保留顺序，可以使用四个结果；若只记录正面个数，可以使用三个结果，但对应概率并不均匀。丢掉实验信息之后，必须把原来映到同一记录的概率相加，不能因为记录类型只剩三个，就赋予各自三分之一的概率。

由公理可以推出空集概率为零。由于全集是空集与全集的互斥并，可加性给出这一结论。再由 $`\Omega=A\cup A^c`$ 得 $`P(A^c)=1-P(A)`$。若 $`A\subseteq B`$，将 $`B`$ 拆成 $`A`$ 与 $`B\setminus A`$，得到单调性 $`P(A)\le P(B)`$。这些简单结果是后续计算的检查器：一个子事件不能比包含它的事件更可能，补集的概率必须补足为一。

不互斥时不能直接相加。将两个集合拆成互不重叠的部分，可得

$$P(A\cup B)=P(A)+P(B)-P(A\cap B).$$

减去交集是因为它在前两项中被计数两次。例如某系统百分之三十的请求使用缓存，百分之二十需要访问数据库，百分之十同时做两件事，至少发生一件的概率是百分之四十。若“使用缓存”和“访问数据库”被定义成互斥执行路径，则交集应为零；同样的词在不同系统设计中可能代表不同事件，需要先核对定义。

<a id="probability-1-detail-2"></a>

### 1.2 计数何时能够转化为概率

等可能的有限结果中，事件概率等于有利结果数除以总结果数。这个方法含有两个条件：列举必须覆盖全部可能，而且每个被列举的结果确实等可能。无放回抽样、按顺序抽样和只记录无序集合，可以使用不同样本空间，只要计算权重一致，最终事件概率相同。常见错误是分子按无序计数，分母按有序计数，或忽略某些结果有更多生成路径。

例如从五张不同卡片中不放回抽两张，顺序保留时共有二十种结果；不保留顺序时共有十种组合。特定两张卡片同时出现，有两个有序结果，也有一个无序组合，所以概率分别为二除以二十与一除以十。两种方法相等，是因为每个组合恰好对应两个顺序。若允许重复且只记录不同卡片的集合，这种等重关系便可能消失。

有时可以凭对称性推断等可能，但必须指出对称的对象。随机排列中每个位置拿到某张卡的概率相同；随机挑选一个“出现过的类别”与随机挑选一条记录却是不同实验。频数最大的类别在后者中更容易被选到。推荐系统日志、长度不同的文档和大小不同的用户群中，这种抽样单位的差别会直接改变先验。

<a id="sec-1-1"></a>

### 基础算例：从事件交集核对条件概率分母

一百条记录中，四十条来自来源 $`A`$，其中十二条成功；全体成功二十条。把四格列出来：来源内成功十二、来源内失败二十八、来源外成功八、来源外失败五十二。各格相加为一百，行和四十与六十，列和二十与八十。于是联合概率 $`P(A\cap S)=0.12`$，来源内成功概率 $`P(S\mid A)=\frac{12}{40}=0.3`$，成功记录来自该来源的概率 $`P(A\mid S)=\frac{12}{20}=0.6`$。

三个数字分别回答“同时满足两个条件的总体比例”“固定来源后的成功比例”“固定成功后的来源比例”。条件符号右边决定重新归一化的集合，不是语句中先出现的名词。这张表也能检查独立性：若独立，来源内成功概率应等于总体成功概率零点二，实际为零点三，所以不独立。或者比较交集零点一二与边缘概率乘积零点零八，得到同样结论。

### 图解：贝叶斯更新中的基率

沿图中的分叉追踪每一组的分母，再把两类阳性合并。设产品总量为 10 000，缺陷基率为 1%，灵敏度为 90%，假阳性率为 5%；期望得到 90 件真阳性与 495 件假阳性。圆内是各路径下的期望计数，边旁是以上一个节点为条件的比例。到达真阳性的路径是 $`10\,000\times0.01\times0.9=90`$，到达假阳性的路径是 $`10\,000\times0.99\times0.05=495`$；两个阳性叶子随后汇合，阴性叶子不进入新的条件总体。重新归一化的分母是全部 585 个阳性，而不是 100 件缺陷品，因此阳性后的缺陷概率为 $`\frac{90}{585}=\frac{2}{13}\approx15.4\%`$。这些是模型下的期望计数，不表示实际抽检必然恰好得到这些数量。

## 2. 条件概率、乘法公式与贝叶斯公式

<a id="probability-1-detail-5"></a>

### 2.1 条件化是改变参照总体

若 $`P(B)>0`$，定义

$$P(A\mid B)=\frac{P(A\cap B)}{P(B)}.$$

固定事件 $`B`$ 后，映射 $`A\mapsto P(A\mid B)`$ 仍然满足概率公理。非负性直接来自原概率；全集条件概率是 $`\frac{P(B)}{P(B)}=1`$；互斥事件与 $`B`$ 相交后仍然互斥，故可加性保留。条件化并非一种只对贝叶斯派适用的技巧，而是由原概率模型导出的新概率模型。

条件化会把 $`B`$ 外的结果概率变成零，并把内部概率按相同倍数放大。它不表示物理上改变了实验，也不自动表示干预。知道用户点击了某链接，是在点击者集合中推理；强制每个用户点击，是另一个改变机制的操作。即使两者使用相同事件名称，也不能仅凭条件概率公式将其等同。因果问题需要额外结构，本章只做观察条件下的一致更新。

若 $`P(B)=0`$，上述比值没有定义，不能把零除以零解释成零。连续变量取精确值往往属于零概率事件，但仍可借助条件密度或正规条件分布建立有意义的条件化。那些对象通常只在“几乎处处”的意义下唯一；本章有限事件的公式不能直接代替相应构造。读到条件概率时，先核对分母为正，是最基本的边界检查。

<a id="probability-1-detail-6"></a>

### 2.2 乘法公式与链式分解

把定义移项即得 $`P(A\cap B)=P(A\mid B)P(B)`$。反过来，若 $`P(A)>0`$，也可写成 $`P(B\mid A)P(A)`$。三个事件的交集可逐次展开为

$$P(A\cap B\cap C)=P(A\mid B\cap C)P(B\mid C)P(C),$$

只要所写条件概率的分母为正。这里没有使用独立性。链式公式是恒等式，独立假设才允许把带条件的因子简化。很多“朴素贝叶斯公式错误”实际上是把合法链式展开进一步简化时，省去了没有证据支持的条件依赖。

对事件序列 $`E_1,\ldots,E_m`$，联合概率可以写成逐步条件概率的乘积。后一项必须以之前全部信息为条件。这也解释了自回归概率模型为什么能把联合序列概率写成条件概率之积：分解本身总成立，模型近似出现在各条件概率如何表示以及是否省略历史。一个模型只记有限窗口，是建模选择，不是概率论强迫的结论。

<a id="probability-1-detail-7"></a>

### 2.3 全概率公式来自互斥完备分割

设 $`H_1,\ldots,H_k`$ 两两互斥并覆盖全集，且各自概率为正。事件 $`E`$ 可以拆为互斥的 $`E\cap H_j`$，于是

$$P(E)=\sum_{j=1}^kP(E\mid H_j)P(H_j).$$

分割的两项条件缺一不可：重叠会重复计数，不完备会漏掉来源。若某类先验为零，可在联合概率形式中保留零项，而不必给未定义的条件概率赋值。可数分割也可使用可数可加性推广；连续潜变量则要用积分，本章参数例子会展示这种过渡。

把“正常”与“已知故障”当作全部类别时，常隐含“未知故障不存在”的强假设。计算可能十分精确，模型却因为漏掉一条生成路径而过度自信。实际写出全概率分母时，应将“其他来源”明确列出，或者承认计算只在限定候选集合内部成立。这种承认能避免把模型内后验误当成涵盖全部现实可能的真理。

<a id="sec-2-1"></a>

### 机制展开：后验赔率把先验与证据分开

用两种乘法分解同一交集，并除以 $`P(E)>0`$，得到

$$P(H\mid E)=\frac{P(E\mid H)P(H)}{P(E)}.$$

先验表示观察指定证据之前对假设的概率；似然表示假设成立时证据如何生成；后验是观察该证据后的条件概率。似然是参数或假设的函数时，并不要求对假设求和为一。两个假设下证据概率分别为零点八与零点二，这不意味着假设后验就是八成与两成，先验还没有参与。

二元假设先验概率为 $`p\in(0,1)`$，证据在两假设下概率分别为 $`a,b>0`$。后验赔率为

$$\frac{P(H\mid E)}{P(H^c\mid E)}=\frac{a}{b}\frac{p}{1-p}.$$

令似然比 $`r=\frac{a}{b}`$，后验概率为 $`\frac{rp}{(1-p+rp)}`$。由赔率转回概率要除以一加赔率。先验十分之一、似然比三时，先验赔率是一比九，后验赔率是一比三，后验概率为四分之一。赔率乘三与概率乘三是两种不同运算。

<a id="deep-dive-2"></a>

### 深入讲解：更新的对象、顺序与不变性

贝叶斯公式的每一项必须来自同一个联合模型。不能从甲地区取患病先验、从乙设备取灵敏度、从丙标签标准取误报率，却不说明这些机制如何迁移。它们可以作为近似输入，但输出应被理解为这些假设共同成立时的结论。检查联合一致性，常比增加计算精度更有价值。

在固定模型中，只要联合事件概率为正，先观察 $`E_1`$ 后观察 $`E_2`$，与相反顺序更新得到相同最终后验，因为两者都条件于 $`E_1\cap E_2`$。不过每一步使用的增量似然可能不同：先后次序改变了已有信息。只有在相应假设下条件独立，才可在两种顺序中都复用相同的单条证据似然比。顺序不影响最终数学结果，不等于计算时可以忽略历史。

同一证据被转发两次，第二次条件于第一次后的新增信息可能为零。把同一份检测报告换成两段自然语言，或让两个模型引用同一来源，都不会自动生成独立证据。概率更新关心的是生成机制的新增随机信息，不能通过文本条数、人头数或投票数直接决定相乘次数。

## 3. 基率、筛查与部署总体

<a id="probability-1-detail-11"></a>

### 3.1 用完整频数表重建后验

以下以工业缺陷筛查为教学模型。缺陷率为百分之一，缺陷品阳性率为百分之九十，正常品误报率为百分之五。设 $`D`$ 为缺陷，$`+`$ 为阳性，则

$$P(D\mid +)=\frac{0.9\cdot0.01}{0.9\cdot0.01+0.05\cdot0.99}=\frac{2}{13}\approx0.153846.$$

在一万个产品的期望频数表中，缺陷一百件，其中阳性九十、阴性十；正常九千九百件，其中阳性四百九十五、阴性九千四百零五。阳性共五百八十五件，真正缺陷九十件。频数可以是期望数量，不要求一次实际抽样恰好产生这些整数；它的用途是把分母对应的人群显式展示出来。

灵敏度是缺陷者中阳性的比例，特异度是正常者中阴性的比例，阳性预测值则是阳性者中缺陷的比例。它们使用不同分母。降低阈值往往会提高灵敏度，同时增加误报，但这里给出的两个概率是某个固定规则下的输入，不能在没有分数分布时随意推断完整阈值曲线。

阴性也有自己的似然比：$`\frac{0.1}{0.95}=\frac{2}{19}`$。先验赔率为一比九十九，因此阴性后缺陷赔率为二比一千八百八十一，概率为 $`\frac{2}{1883}`$，约千分之一点零六。阳性似然比与阴性似然比通常不是倒数，不能用“阳性后乘十八”推断“阴性后除十八”。

<a id="probability-1-detail-12"></a>

### 3.2 基率改变为什么会改变预测值

令缺陷基率为 $`\pi`$，检测的灵敏度固定为 $`s`$，误报率固定为 $`f`$，则阳性预测值为

$$g(\pi)=\frac{s\pi}{s\pi+f(1-\pi)}.$$

当 $`s,f>0`$ 时，对基率求导得 $`g'(\pi)=\frac{sf}{[f+(s-f)\pi]^2}>0`$。相同检测机制下，基率越高，阳性后缺陷概率越大。若基率升至十分之一，后验是三分之二。变化来自人群构成，而不是检测突然更精确。若误报率恰为零且阳性确有可能，则阳性排除正常假设，后验为一；这是边界情形，不能从有限数据零误报直接认定真实误报率为零。

反过来问：希望阳性后的缺陷概率至少为 $`q\in(0,1)`$，最低基率是多少？由 $`s\pi\ge q[s\pi+f(1-\pi)]`$，整理得到

$$\pi\ge\frac{qf}{s(1-q)+qf}.$$

若目标为二分之一，代入当前检测得到最低基率为一除以十九。这种反推能说明某个筛查器适合怎样的预筛选人群。它仍以检测条件机制固定为前提，预筛选如果同时改变缺陷严重程度或正常品构成，原来的灵敏度与误报率也可能变化。

<a id="probability-1-detail-13"></a>

### 3.3 先验漂移下的概率修正

假设训练与部署只有类别比例改变，而给定类别后的特征分布保持相同，称为标签先验漂移的一种理想情况。对特征 $`x`$，后验赔率等于特征似然比乘类别先验赔率。因此部署赔率等于训练后验赔率，再乘部署先验赔率除以训练先验赔率。必须有共同的条件特征机制，训练后验也必须校准到训练总体，这个修正才有概率解释。

若训练正类比例为二分之一，模型对某样本给出零点八，则它编码的似然比为四。部署正类先验降至十分之一时，后验赔率为四比九，部署概率为四除以十三。不能继续把零点八解释成目标总体的事件概率。另一方面，若部署中正类的特征分布也改变，仅修正截距可能不够。先验修正不是对任意分布变化的万能补丁。

实践中可以并列报告几组合理先验下的后验，而非把一个不确定基率当作精确常数。敏感性分析应改变真实不确定的输入，不能只机械调整最后一位小数。若误报率从百分之五降至百分之一，原基率下后验从约十五个百分点上升到约四十八个百分点，说明低基率任务里误报率估计的重要性。哪个输入最值得额外采样，由结论对其变化的敏感程度与采集成本共同决定。

<a id="sec-4"></a>

## 4. 信息如何到达：频数表、选择偏差与遗漏来源

<a id="probability-1-detail-15"></a>

### 4.1 被观察到本身也是证据

把 $`S`$ 表示“记录进入数据集”，一般有 $`P(H\mid E,S)`$，而不是自动等于 $`P(H\mid E)`$。如果给定 $`H,E`$ 后入选概率仍随假设改变，选择机制不能忽略。更完整的更新是

$$P(H\mid E,S)\propto P(S\mid E,H)P(E\mid H)P(H).$$

这里分母仍须对全部候选假设求和。实验中按类别过采样、只保存异常告警、仅记录成功请求，都会使日志先验与目标总体不同。记录表很大并不能补回被系统性排除的类型；样本规模解决随机误差，采样机制解决“这些样本代表谁”的问题。

设总体缺陷率一成，收集时全部缺陷品都保留，正常品只保留十分之一。样本中缺陷比例为 $`\frac{0.1}{(0.1+0.9\cdot0.1)}=\frac{10}{19}`$。若直接以这个比例作为全厂先验，会把缺陷率严重高估。如果已知两类入选概率，便能重新计算总体，但如果某类入选概率为零，仅凭现有样本无法恢复其内部结构。逆概率加权也需要正的入选概率及正确机制，具体估计理论留给统计章节。

<a id="probability-1-detail-16"></a>

### 4.2 条件化可能制造关联

取相互独立且公平的两个二元变量 $`A,B`$，再只观察满足 $`S=\{A=1\text{ 或 }B=1\}`$ 的结果。原来四格各占四分之一；筛选后剩三格等可能。此时 $`P(A=1\mid S)=\frac{2}{3}`$，而 $`P(A=1\mid B=0,S)=1`$。原先独立的两变量在选择后变得相关。直觉是：既然保证至少一项为一，如果发现一项为零，另一项就必须为一。

这是一种碰撞点选择的最小例子。不能把筛选后相关解释为总体相关，也不能仅凭观察关联确定因果方向。在只录用“能力或经验至少一项达标”的群体中，能力与经验可能呈负关联，即使总体中独立。要分析此类现象，应明确选择事件怎样依赖各变量，列出联合表，然后再条件化；仅凭相关系数的正负无法还原机制。

<a id="probability-1-detail-17"></a>

### 4.3 同一个事件，不同的报告协议

“两枚公平硬币，得知至少一枚正面”与“随机看其中一枚，看到正面”不是同一种证据。前者排除全反，双正后验为三分之一。后者需要把被查看的位置也纳入样本空间：双正产生正面报告的概率为一，一正一反产生正面报告的概率为二分之一，所以双正后验为二分之一。区别来自报告似然，而非条件概率公式互相矛盾。

类似地，某主持人在看到结果后选择性展示一个成功例子，与事先随机挑一个例子刚好成功，具有不同证据强度。若报告规则是“只要有成功就展示一个”，总体中至少一个成功的概率决定报告似然；若展示对象事先固定，单次成功概率才是适用似然。询问资料是怎样被挑选和转述的，是概率建模的一部分。

<a id="probability-1-detail-18"></a>

### 4.4 分层汇总与辛普森式反转

设方案甲在容易组成功率九成，在困难组成功率三成；方案乙分别为八成与两成。甲在两组都更高。但若甲有九成样本来自困难组，总成功率是三成六；乙有九成来自容易组，总成功率是七成四。总体排序反转由分组权重不同造成，并不违反分组内比较。全概率公式把组内概率与组权重分开，便能看清差异。

要比较部署效果，应先确定目标人群的共同分组权重，再把每个方案的组内结果按相同权重标准化。若某方案在某组从未使用，则对应结果无法从现有表直接识别；不能用没有覆盖的比较宣称总体优劣。分层观察还未等于随机试验，组内也可能有未观测混杂，条件概率计算解决的是表内一致性，而不是自动提供因果识别。

<a id="sec-5"></a>

## 5. 独立、条件独立与证据重复

<a id="probability-1-detail-20"></a>

### 5.1 独立与互斥的严格区别

事件独立定义为 $`P(A\cap B)=P(A)P(B)`$。若 $`P(B)>0`$，等价于 $`P(A\mid B)=P(A)`$。若两个正概率事件互斥，交集为零而概率乘积为正，所以它们不独立。只有至少一项概率为零时，互斥与独立可以同时成立。独立表示信息无增益，互斥表示不能同时发生，两者的逻辑含义完全不同。

独立还会传递到补事件。由 $`P(A\cap B^c)=P(A)-P(A\cap B)`$，代入独立条件得 $`P(A)[1-P(B)]`$，即 $`A`$ 与 $`B^c`$ 独立；继续取补得到其余组合。这个性质可以减少重复计算，但不能把它推广为“独立与任意第三变量条件化都兼容”，下一节的反例会直接否定这种推断。

三个以上事件的两两独立弱于共同独立。取两个独立公平比特 $`U,V`$，定义 $`W`$ 为它们异或。四种结果等可能。每一对比特的四格概率都是四分之一，所以两两独立；但三个同时为零的概率是四分之一，而边缘概率乘积为八分之一。知道前两个就能确定第三个，三者不能共同独立。把很多两两相关系数接近零当作联合独立检验，遗漏的正是这种高阶结构。

<a id="probability-1-detail-21"></a>

### 5.2 条件独立需要在每个条件层内成立

给定事件 $`C`$ 且 $`P(C)>0`$，条件独立要求

$$P(A\cap B\mid C)=P(A\mid C)P(B\mid C).$$

若条件对象是二元状态 $`H`$，通常要求在 $`H`$ 与 $`H^c`$ 两层都成立，才可对两种假设分别连乘证据似然。只验证正类中独立，负类中却强相关，依然会得到错误似然比。条件变量有多个取值时，应理解为对所有正概率的层成立；连续条件的技术细节需要用分布表达。

考虑共同原因：$`H`$ 等可能为零或一，给定 $`H=1`$ 时两个指标各以零点九概率为一，给定 $`H=0`$ 时各以零点一概率为一，并假设层内独立。两指标边缘均值都是零点五，但同时为一的概率为零点四一，超过独立所需的零点二五。层内无关联并不推出总体独立，因为它们共同反映状态变化。

反方向也不成立：先前独立比特在给定“至少一项为一”后变相关，已给出明确反例。因而“给定更多信息只会让独立更可靠”没有普遍依据。条件化有时消除共同原因造成的依赖，有时通过选择制造依赖。应该从联合模型推导，而不是按照条件数量多少判断。

<a id="probability-1-detail-22"></a>

### 5.3 朴素贝叶斯到底简化了什么

对类别 $`Y`$ 与特征 $`X_1,\ldots,X_d`$，朴素贝叶斯假设给定类别后特征共同独立，于是类别后验正比于类别先验乘各特征条件概率。这里不是说特征在全体样本中独立，也不是只要求两两独立。文本中同义词、相邻词和同一事件的多个表述，往往违反该假设，导致证据被重复计数。

即使独立假设不精确，分类边界仍可能有用，因为分类只需要比较各类得分的大小；概率校准却要求更强的一致性。因此“准确率不错”不能证明后验数值可信，也不能证明条件独立。应用时可检查重复特征、比较概率校准、按信息来源分组，并建立包含依赖的替代模型。并非每一种依赖都同样破坏分类，必须把预测任务与概率解释分开验证。

<a id="probability-1-detail-23"></a>

### 5.4 第二次检测何时带来多少信息

在缺陷筛查例中，如果两次检测在给定缺陷状态后独立，且条件阳性率相同，两次阳性似然比为十八的平方。先验赔率一比九十九，后验概率为 $`\frac{324}{(324+99)}=\frac{36}{47}`$，约零点七六六。这远高于一次阳性后的二除以十三。但这是明确模型下的计算，不能因为设备执行了两次操作就自动采用。

若第二次结果与第一次完全相同，联合阳性概率在缺陷与正常中仍分别为零点九与零点零五，后验保持二除以十三。中间状态还可以通过共享随机误差建模。例如给定类别 $`h`$，以概率 $`c`$ 复制第一次结果，以概率 $`1-c`$ 独立重测，单次阳性概率记为 $`a_h`$，则两次阳性概率是 $`ca_h+(1-c)a_h^2`$。当 $`c`$ 从零增加到一，新增证据逐渐减少；这种连续模型比只喊“有关联”更能量化影响。

给定第一次阳性，第二次阳性在类别 $`h`$ 下的条件概率为 $`c+(1-c)a_h`$。真正的第二步似然比应使用这两个条件概率之比。它在 $`c=0`$ 时恢复十八，在 $`c=1`$ 时成为一。先更新再使用历史条件似然，与直接使用联合阳性似然完全一致，这就是链式更新的实际含义。

## 6. 进阶：Bayes 因子、参数不确定性与后验预测

<a id="probability-1-detail-25"></a>

### 6.1 简单假设的证据比与对数更新

如果两个假设完全指定证据分布，Bayes 因子就是似然比。若观察多个离散证据，正确总因子是联合证据概率之比。利用链式分解，可写成各步“给定历史”的条件似然比之积，再取对数成为和。独立是使每步忽略历史的充分条件，而不是链式相乘本身的必要条件。

对数赔率的好处是数值稳定且便于解释：每条证据增加一项对数似然比。支持正类的项为正，支持负类的项为负，中性项为零。多个很小概率直接相乘可能下溢；把对数联合权重减去最大值后指数化并归一，可以保持同一后验。数值技巧改变的是计算路径，不改变证据含义；一个被错误重复的因子在对数空间中仍然错误。

先验为零的假设，在有限且正的证据似然下后验仍为零。零先验不是“非常不相信”的无害近似，而是把该假设排出支持集。若所有候选假设都给证据零概率，贝叶斯分母为零，模型对观测没有定义更新；不能任选一个假设归一。实际工作中这通常提示支持集、观测噪声、量化方式或候选集合有误。

<a id="probability-1-detail-26"></a>

### 6.2 复合假设为什么需要积分

若假设 $`H_j`$ 内还有未知参数 $`\theta`$，其证据概率应为

$$P(E\mid H_j)=\int P(E\mid\theta,H_j)\,\pi_j(\theta)\,d\theta,$$

其中 $`\pi_j`$ 是该假设内的正规先验密度。把最大似然值直接代替积分，得到的是另一种比较标准。最大值只看拟合最好的参数，边缘似然还考虑多大的先验参数区域能解释观测。宽泛模型可以包含极好拟合点，但如果绝大多数先验质量支持完全不同数据，其平均证据仍可能较低。

这种平均有时被称为复杂度惩罚，但不能把它理解为仅取决于参数数量的普遍常数。惩罚程度依赖先验尺度、数据量、模型形状与观测。改变参数坐标并按正确雅可比变换同一个先验，不会改变积分；换成另一个看似“均匀”的坐标先验，则通常真的换了模型。比较模型时必须报告先验，而不仅报告最优参数。

不正规先验可能在单一模型内产生正规的参数后验，却通常不能直接用于模型证据比较，因为任意归一化常数无法在不同模型间确定地抵消。参数估计与模型比较对先验的要求不同。这里只使用正规 Beta 先验，避免把一个未定义的证据当作有效 Bayes 因子。

<a id="sec-6-1"></a>

### 用完整事件树推导后验

事件树的每条路径概率是沿路条件概率的乘积，到达同一个报告事件的路径概率相加。缺陷筛查先按缺陷与正常分支，再按阳性与阴性分支。阳性分支有两条来源，总概率零点零五八五；缺陷且阳性的路径为零点零零九，所以后验为二除以十三。树的用途是确保没有省略正常误报路径，并提醒每个分支的条件对象。

若先过一道预筛选，再做精检，需要把预筛选是否改变后续检测机制写进树。假如只是在同一类别内部均匀抽样，后续条件检测率可以保持原值；若预筛选依据某个与精检共用的信号，类别内部的精检阳性率也可能改变。不能用“先验提高了”一句话覆盖所有选择影响。为每条边写清条件信息，比在最后套一遍公式更可靠。

<a id="probability-1-detail-28"></a>

### 6.3 Beta—Bernoulli 更新的逐步推导

令未知成功概率为 $`\theta\in(0,1)`$。给定 $`\theta`$，各次试验独立且成功概率均为 $`\theta`$。先验取 Beta 分布，参数 $`\alpha,\beta>0`$，密度为

$$
\begin{aligned}
\pi(\theta) &=\frac{\theta^{\alpha-1}(1-\theta)^{\beta-1}}{B(\alpha,\beta)},\\[6pt]
B(\alpha,\beta) &=\int_0^1t^{\alpha-1}(1-t)^{\beta-1}\,dt.
\end{aligned}
$$

观察固定长度的有序序列，成功 $`s`$ 次、失败 $`f`$ 次，似然为 $`\theta^s(1-\theta)^f`$。与先验相乘后，指数分别相加成 $`\alpha+s-1`$ 与 $`\beta+f-1`$，归一化常数正好是对应 Beta 积分。因此后验为 Beta 分布，参数更新到 $`\alpha+s,\beta+f`$。这称为共轭，因为更新后留在同一分布族，不代表先验因此没有争议或模型一定正确。

若只观察总成功次数而没有顺序，似然还带组合系数。它不依赖 $`\theta`$，因此在固定模型的参数后验中抵消；但计算这个“计数事件”的证据概率时，必须保留。对有序序列与成功计数混用证据，是常见的组合因子错误。模型比较中若两模型使用同一种观测表示，公共因子可能相消；不能因此在所有概率问题里都把它删掉。

Beta 均值可以利用积分直接推导：期望为 $`\frac{B(\alpha+1,\beta)}{B(\alpha,\beta)}=\frac{\alpha}{(\alpha+\beta)}`$。类似得到二阶矩与方差。后验预测下一次成功的概率，是在后验下平均 $`\theta`$，因此为 $`\frac{(\alpha+s)}{(\alpha+\beta+s+f)}`$。这里先对条件成功概率平均，而不是把未知参数假装成已知真实值；完整未来联合预测会保留参数不确定性的影响。

<a id="probability-1-detail-29"></a>

### 6.4 一组可手算的后验与未来预测

取均匀先验，即 $`\alpha=\beta=1`$，观察四次试验中三次成功一次失败。后验密度为 $`20\theta^3(1-\theta)`$，是 Beta 参数四与二。后验均值为三分之二，方差为二除以六十三。下一次成功概率也是三分之二。最大似然估计是四分之三，二者不同的原因是先验仍参与推断，并非哪个公式算错。

未来两次都成功的预测概率为后验二阶矩 $`4\cdot\frac{5}{(6\cdot7)}=\frac{10}{21}`$。如果把后验均值直接代入独立试验，会给出四除以九，约零点四四四，低于正确的约零点四七六。给定同一个 $`\theta`$ 时未来试验独立；把未知 $`\theta`$ 积分掉后，它们共享不确定参数，通常正相关。未来两次成功指示变量的协方差正好等于当前后验中 $`\theta`$ 的方差。

未来两次恰有一次成功的概率为 $`2E[\theta(1-\theta)]=\frac{8}{21}`$，两次都失败为 $`E[(1-\theta)^2]=\frac{1}{7}`$，三项相加为一。一般未来 $`m`$ 次成功数的预测分布为 Beta—Binomial，其概率为组合系数乘后验 Beta 函数比。这个分布比固定后验均值的二项分布更分散，额外波动来自仍未知的成功率，而不是每次试验噪声突然加大。

### 图解推导：同一个后验均值，为何不能替代联合预测

![Beta 参数后验与未来两次成功数的积分预测，对照固定后验均值的二项分布](images/01-posterior-predictive.svg)

左图接续四次试验中三次成功的例子。灰线是均匀先验密度一，蓝线是后验密度 $`20\theta^3(1-\theta)`$；每条密度的面积均为一。竖线标记后验均值 $`\frac23`$，它不是密度最高点 $`\frac34`$，更不是说参数已经被确定为这个值。右图蓝柱逐项积分整个蓝色密度，橙柱则把参数直接固定成 $`\frac23`$。

未来一次成功时，两种计算给出相同答案，因为条件概率 $`\theta`$ 对参数是线性的。但两次同时成功要计算 $`\theta^2`$，于是

$$
P(Y_1=1,Y_2=1\mid\text{数据})
=E[\theta^2\mid\text{数据}]
=\bigl(E[\theta\mid\text{数据}]\bigr)^2
+\operatorname{Var}(\theta\mid\text{数据}).
$$

后一项恰为 $`\frac2{63}`$，所以蓝色双成功柱比橙色高。双失败同样受益于共享参数的不确定性，恰有一次成功的质量相应减少。三根蓝柱仍然和为一；它们表示一次联合预测，不能理解成对每次试验分别随机抽一个新的、相互独立的成功率。

令未来成功总数 $`K=Y_1+Y_2`$。两种方法的均值均为 $`\frac43`$，方差却不同：

$$
\operatorname{Var}(K\mid\text{数据})
=2\left(\frac23\right)\left(\frac13\right)
+2\left(\frac2{63}\right)
=\frac{32}{63},
\qquad
\operatorname{Var}\!\left(\operatorname{Binomial}\!\left(2,\frac23\right)\right)
=\frac49.
$$

多出来的是两次未来指示变量的协方差贡献；给定参数后独立，与积分参数后独立，属于不同命题。参数后验预测的关系可结合 [Seeing Theory 的先验到后验交互教学](https://seeing-theory.brown.edu/bayesian-inference/index.html) 阅读，再用图中完整的未来次数分布检验理解。若现实试验还存在时间漂移或设备共享冲击，单个固定参数的 Beta—Bernoulli 模型也需要重新检查，不能把所有依赖都归因于这里这一种机制。

<a id="probability-1-detail-30"></a>

### 6.5 连续先验下的证据比较与交换性

比较 $`H_0:\theta=\frac{1}{2}`$ 与 $`H_1:\theta\sim\mathrm{Beta}(1,1)`$，观察四次中三次成功。计数证据在零假设下是四乘十六分之一，即四分之一；在备择下是 $`4B(4,2)=\frac{1}{5}`$。所以支持备择相对零假设的 Bayes 因子为五分之四，略支持固定公平模型。看到百分之七十五的样本成功率，并不必然构成支持可变参数模型的强证据，因为样本很少，而备择平均了整段参数空间。

若观察的是一个特定排列，例如成功、成功、失败、成功，则证据分别为十六分之一与二十分之一，比值仍为五分之四。这个一致性源自共同组合因子相消。若把一边的计数概率与另一边的有序序列概率比较，就会得到毫无意义的不同结果。概率之比必须比较同一个观测事件。

给定参数后独立同分布的模型，积分后序列概率只依赖成功数而不依赖顺序，称为交换性。交换性允许重排有限序列而不改变联合概率，弱于独立。实际数据若随时间趋势变化、设备磨损或用户重复，成功计数就未必保留全部信息。把一百次结果压成一个成功数，必须先检查这种统计压缩是否符合模型。

<a id="probability-1-detail-31"></a>

### 6.6 证据、不确定性与决策边界

后验回答模型内的不确定性，行动还需要损失。若漏检损失为 $`c_{\mathrm{FN}}`$，误报损失为 $`c_{\mathrm{FP}}`$，正确判断损失设为零，则判为缺陷的后验期望损失是 $`c_{\mathrm{FP}}(1-p)`$，判为正常是 $`c_{\mathrm{FN}}p`$。比较两者得到阈值 $`p\ge\frac{c_{\mathrm{FP}}}{(c_{\mathrm{FP}}+c_{\mathrm{FN}})}`$。因此后验概率低于二分之一，也可能应采取检查行动，只要漏检代价足够高。

这个二动作模型假设成本已知、动作不改变后续信息、没有资源约束。若还有“再测一次”的动作，应计算它的费用和预期信息收益；若一天只能检查固定数量，则阈值还受容量约束。概率推断与决策分析相互衔接，但不能把概率较大直接等同于必须采取某个行动。详细决策论在机器学习基础主题中展开，本章只建立连接。

<a id="probability-1-detail-32"></a>

### 6.7 从先验强度到模型检查

在 Beta 更新中，后验均值可分解为先验均值与样本比例的加权平均。设总试验数为 $`n=s+f>0`$，先验浓度为 $`\kappa=\alpha+\beta`$，则后验均值为 $`[\frac{\kappa}{(\kappa+n)}]\cdot[\frac{\alpha}{\kappa}]+[\frac{n}{(\kappa+n)}]\cdot(\frac{s}{n})`$。因此两个均值相同的先验，可以因浓度不同产生截然不同的更新速度。参数一与一、参数一百与一百都以二分之一为中心，但前者容易被少量观测改变，后者则表达很强的集中判断。

先验浓度不能仅凭希望结果“平滑一点”随意调节而不说明。它代表对参数位置的确信，最好通过可理解的预测量校准：观察前，连续十次都成功的概率有多大？新设备出现接近零或接近一的成功率是否合理？如果先验对现实可能数据给出极低概率，后验更新即使代数正确，也可能长期偏离合理区域。预测检查把抽象参数转化为可以质疑的实验结果。

后验也不只是一个均值。对参数的区间陈述应来自后验分布积分，例如求一个区间内密度面积为某个指定水平。这样的可信区间在当前模型下描述参数不确定性；它与重复抽样意义下的置信区间有不同定义，不能只因二者都画成区间就混用解释。对于固定参数和有限样本，覆盖性质还受先验及似然正确性影响，不能宣称任意贝叶斯区间自动具有指定的频率覆盖率。

可以比较实际数据与后验预测，而不能仅因为模型能给出一个后验就认定拟合良好。如果模型认为试验条件相同，连续成功串与成功分散在时间上应具有相同概率；实际却出现长时间成片失败，可能提示设备状态切换。压缩到总成功数会掩盖这种结构。一个与模型假设直接相关的检查量，如最长失败串、分时段成功率差异或批次间方差，常比只比较总体均值更有诊断力。

但后验预测检查重复使用观测数据，因此其数值不能不加解释地当作经典独立检验的显著性概率。更可靠的预测评估可以预先划出未来时间段或独立批次，比较预测概率与实际频数。若根据留出集反复修改先验和模型，留出集也参与了选择，最终评价需保留新的独立信息。概率模型的检验与机器学习的数据划分原则在此相通。

<a id="probability-1-detail-33"></a>

### 6.8 观察到停止时：似然原则与报告事件

考虑连续抛硬币直到首次成功，恰好在第四次成功。完整序列为三次失败接一次成功，给定成功率的似然是 $`(1-\theta)^3\theta`$。若事先固定四次试验，观察到完全同一个序列，其参数似然相同。因此在相同正规先验、相同参数模型和完整观测记录下，参数后验相同。试验计划不同并不必然改变这一次完整序列所携带的参数似然。

不过这个结论有明确边界。若只被告知“研究者最终得到一次显著结果”，却不知道中间进行了多少试验，观察事件已经不同，必须对未报告的路径求和。若研究者选择性发表成功研究，入选概率也可能依赖未知参数，报告协议就不能忽略。所谓可以忽略停止规则，通常指规则是已知观测历史的确定函数，且相关因子对目标参数不额外依赖；它不是对任何选择性报告的免责条款。

模型比较还需要各假设下报告和停止机制可比较，决策上也可能关心试验成本与时间，而这些信息即使不改变参数后验，仍会影响行动。频率检验的错误率则是在重复整个试验程序时定义，改变停止规则常会改变该程序的错误率。两种讨论分别条件于已观察数据与平均于重复程序，不能把一个框架的结论直接移到另一个问题上。

学习这一点的价值在于分清“没有写进似然的因素为什么能被忽略”。可以忽略应有一个可证明的因子分解理由，例如该因素在候选参数间相同；而不是因为自己拿不到数据，就假定它不存在。面对不完整报告时，应明确列出缺失的实验路径、可能的选择机制和由此产生的识别限制。能够说明哪些结论依赖无法核实的部分，是进阶概率推理的重要能力。

### 图解：相同似然比在不同先验下得到不同后验

![相同似然比在不同先验下得到不同后验](images/01-extension.svg)

图固定似然比为 $`9`$。令先验为 $`p`$，先把概率换成赔率，再乘证据强度，最后变回概率：

$$
O_{\rm prior}=\frac{p}{1-p},\qquad
O_{\rm post}=9O_{\rm prior},\qquad
p_{\rm post}=\frac{9p}{1+8p}.
$$

蓝线是这个映射，橙色对角线是没有更新时的参照。先验 $`0.01`$ 对应后验 $`\frac1{12}\approx0.0833`$；先验 $`0.5`$ 对应后验 $`0.9`$。同样的证据把赔率都乘以九，概率却不会统一增加九倍或增加同一个常数。两端 $`p=0,1`$ 是先验排除一种假设的极限情形，通常应单独讨论，不能把无穷赔率当普通有限数计算。

似然比必须来自同一证据定义和同一对假设。若继续加入第二份证据，应使用它在第一份证据已知后的条件似然比；只有合适的条件独立假设成立时，才能直接连乘各自未条件化的似然比。

## 7. 完整计算实验与详解练习

<a id="probability-1-detail-35"></a>

### 7.1 以精确分数验证事件树与相关检测

下面实验只用 Python 标准库，不创建文件。第一部分用有理数避免四舍五入掩盖错误；第二部分枚举两次检测的四种结果，逐一核对联合总和及链式更新；最后计算 Beta 后验预测。实验检验的是给定模型的代数一致性，不能验证模型是否适用于某座工厂。若实际数据不符合条件独立，应该修改输入机制，而不是调整代码使其碰巧符合期望答案。

```python
from fractions import Fraction as F
from math import comb, lgamma, exp, isclose

prior = F(1, 100)
positive = {1: F(9, 10), 0: F(1, 20)}
posterior_one = prior * positive[1] / (
    prior * positive[1] + (1 - prior) * positive[0])
assert posterior_one == F(2, 13)

def joint_pair(h, a, b, copy_prob):
    q = positive[h]
    pa = q if a else 1 - q
    pb = q if b else 1 - q
    return copy_prob * pa * int(a == b) + (1 - copy_prob) * pa * pb

for c in (F(0), F(1, 2), F(1)):
    for h in (0, 1):
        assert sum(joint_pair(h, a, b, c)
                   for a in (0, 1) for b in (0, 1)) == 1
    q1 = joint_pair(1, 1, 1, c)
    q0 = joint_pair(0, 1, 1, c)
    direct = prior * q1 / (prior * q1 + (1 - prior) * q0)
    updated_odds = posterior_one / (1 - posterior_one)
    updated_odds *= (q1 / positive[1]) / (q0 / positive[0])
    sequential = updated_odds / (1 + updated_odds)
    assert direct == sequential
    print("copy probability", c, "posterior", direct)
assert prior * positive[1]**2 / (
    prior * positive[1]**2 + (1-prior)*positive[0]**2) == F(36, 47)

def log_beta(a, b):
    return lgamma(a) + lgamma(b) - lgamma(a + b)

a, b, m = 4, 2, 2
predictive = [comb(m, k) * exp(log_beta(a+k, b+m-k)-log_beta(a,b))
              for k in range(m+1)]
assert isclose(sum(predictive), 1.0, abs_tol=1e-14)
assert isclose(predictive[2], 10/21, abs_tol=1e-14)
assert isclose(predictive[1], 8/21, abs_tol=1e-14)
print("future count probabilities", predictive)
```

复制概率为零、二分之一与一时，后验依次为三十六除以四十七、七十六除以三百零七、二除以十三。中间模型仍比一次独立证据更强，但远不及真正独立重测。请特别观察代码中的第二步似然：它使用联合阳性概率除以第一次阳性概率，得到“已经第一次阳性时”的概率，再进行赔率更新。这比无条件重复乘十八更忠实于信息到达过程。

### 7.2 练习一：分母由什么决定

**问题。** 一千封邮件中三百封来自某域名，该域名中九十封是垃圾邮件，全体垃圾邮件两百封。计算来源与垃圾邮件的联合概率、来源内垃圾比例及垃圾邮件中该来源比例，并判断独立。

**解析。** 联合比例是九十除以一千，即零点零九。给定来源后只在三百封中计数，得到零点三；给定垃圾后在两百封中计数，得到零点四五。总体垃圾比例零点二，与来源内零点三不同，所以不独立。若仅知道两个边缘比例而不知道交集，无法唯一确定这些条件概率，还需要联合信息。

<a id="probability-1-detail-37"></a>

### 7.3 练习二：不等可能的记录

**问题。** 独立投两枚公平硬币，只记录正面数量。三个可能记录能否各赋予三分之一？如果观察记录至少为一，记录为二的概率是多少？

**解析。** 原始四种有序结果等可能，零正与双正各对应一种，一正对应两种，因此记录概率为四分之一、二分之一、四分之一。至少一正事件概率为四分之三，双正与该事件交集仍是四分之一，条件概率为三分之一。记录种类相同地“有可能”并不意味着概率相同；只有生成路径权重相同才能均匀赋值。

<a id="probability-1-detail-38"></a>

### 7.4 练习三：互斥与独立

**问题。** 两个互斥事件概率分别为零点二与零点三，是否独立？若一个事件概率为零又如何？

**解析。** 前者交集概率为零，边缘乘积零点零六，故不独立。若其中一个概率为零，则交集也为零，确实满足独立的乘积定义。对零概率事件的“给定它之后”却不能使用比值定义，因此不能说独立定义在此失效。乘积定义比条件概率等价式覆盖更多边界情况，使用等价式时必须保留分母为正的前提。

<a id="probability-1-detail-39"></a>

### 7.5 练习四：全概率不能漏掉来源

**问题。** 产品来自三条产线，比例分别为二分之一、三分之一、六分之一，缺陷率分别为百分之一、百分之三、百分之六。求缺陷总率以及缺陷产品来自第三线的概率。

**解析。** 各线贡献为二百分之一、一百分之一、一百分之一，总和为四十分之一。第三线且缺陷的联合概率为一百分之一，因此后验为五分之二。第三线缺陷率最高，不表示全部缺陷主要来自它；产量先验同样重要。三条线须覆盖全部产品，返工线或外包线若未计入，分母就必须重新建立。

<a id="probability-1-detail-40"></a>

### 7.6 练习五：相反证据的似然比

**问题。** 正类先验十分之一，检测灵敏度零点八、误报率零点二。阳性与阴性的似然比分别多少？观察一阳一阴且给定类别后独立，后验多少？

**解析。** 阳性比为四，阴性比为四分之一。此例两比恰好互为倒数，所以联合比为一，后验回到十分之一。互为倒数来自这里恰好对称的检测参数，并非普遍规律。若改误报率为零点一，阴性比为二除以九，两条证据联合比为十六除以九，就不再抵消。观察抵消还是累积，应计算具体比值。

<a id="probability-1-detail-41"></a>

### 7.7 练习六：两两独立不足够

**问题。** 构造三个二元变量，两两独立但并非共同独立，并说明为何只检验成对关联会遗漏问题。

**解析。** 取独立公平比特，第三个为它们异或。四个可能三元结果各有四分之一概率，每一对均匀覆盖四种取值，所以成对独立。三个都为零却占四分之一而非八分之一，违反共同分解。第三变量由前两个完全确定，二阶检查看不到这一高阶约束。朴素贝叶斯需要共同条件独立，不能以成对相关为零替代。

<a id="probability-1-detail-42"></a>

### 7.8 练习七：选择制造负关联

**问题。** 两个独立公平比特，只保留至少一个为一的记录。计算筛选后的联合概率与两个边缘概率，判断是否独立。

**解析。** 筛选概率四分之三，保留三格各为三分之一。两者同时为一概率三分之一，各自为一概率均为三分之二，乘积九分之四，与联合不相等。条件化引入负关联。若再发现第二项为零，第一项必为一。结论针对筛选人群，不能据此推断原总体中两指标具有相互抑制的因果作用。

<a id="probability-1-detail-43"></a>

### 7.9 练习八：同一报告的两种到达方式

**问题。** 两枚公平硬币，一种协议报告“至少一个正面”，另一种随机选一枚并如实报告。两种协议下听到正面相关报告，双正概率为什么不同？

**解析。** 第一种协议的报告事件正是排除双反，因此双正占三种等可能情况之一。第二种协议中双正必报告正面，混合两种情况各有一半机会报告正面，双反不可能报告。用全概率，正面报告概率二分之一，双正且报告概率四分之一，后验二分之一。关键不是自然语言中都有“正面”，而是报告事件在各隐藏结果下的似然不同。

<a id="probability-1-detail-44"></a>

### 7.10 练习九：顺序更新需要条件似然

**问题。** 检测模型中复制概率为二分之一，先验与单次参数使用正文数值。第二次阳性在缺陷及正常、已知第一次阳性条件下的概率分别多少？

**解析。** 由复制混合模型，分别为零点九五与零点五二五，比值为三十八除以二十一。第一次后的赔率二比十一，乘该比得到七十六比二百三十一，后验为七十六除以三百零七。直接方法计算缺陷下双阳零点八五五、正常下双阳零点零二六二五，也得到相同结果。若某段文字给出不同中间分数，应优先回到精确联合事件核对，而不是依赖小数印象。

<a id="probability-1-detail-45"></a>

### 7.11 练习十：Beta 后验不是给参数加任意分数

**问题。** 先验 Beta 参数为二和三，观察六次成功两次失败。求后验、下一次成功概率，并解释先验参数的含义。

**解析。** 后验参数为八和五，下一次成功概率八除以十三。均值可写成先验均值五分之二与样本比例四分之三的加权平均，权重分别为五除以十三与八除以十三。因此先验浓度控制其对后验均值的影响。把参数称为“伪计数”有助直觉，但与先验密度指数之间相差一，不能把所有先验众数、均值及历史真实试验都混为一谈。

<a id="probability-1-detail-46"></a>

### 7.12 练习十一：未来重复试验的边缘依赖

**问题。** 当前参数后验 Beta 为四和二，未来两个成功指示变量给定参数后独立。求其边缘协方差，是否能按固定成功率三分之二计算联合概率？

**解析。** 下一次成功率三分之二，共同成功概率十除以二十一。协方差是十除以二十一减四除以九，等于二除以六十三，恰为参数后验方差。未来变量的关联来自共享未知参数；给定参数独立不意味着积分后独立。两者相关系数等于协方差除以各自方差，结果为七分之一；这个数不等于参数方差，因为二者使用的尺度不同。

<a id="probability-1-detail-47"></a>

### 7.13 练习十二：模型证据需要同一观测表示

**问题。** 四次中三次成功，公平固定参数模型与均匀参数模型的证据分别为四分之一与五分之一。若改用一个特定顺序，如何保持比较一致？

**解析。** 计数事件包含四个等概率排列，所以两边证据都除以四，成为十六分之一与二十分之一。Bayes 因子仍为五分之四。参数后验归一时组合系数与参数无关可约掉，计算某事件的概率时却不能随意删除。应先写出观察对象，再确定采用质量函数还是完整序列概率，最后比较模型。

<a id="probability-1-detail-48"></a>

### 7.14 练习十三：先验漂移修正与失效

**问题。** 训练先验二分之一，样本训练后验零点七五，部署先验零点二。仅类别比例变化时部署后验多少？若正类采集设备也变了还能直接使用吗？

**解析。** 训练赔率三，训练先验赔率一，所以特征似然比三。部署先验赔率四分之一，部署后验赔率四分之三，概率七分之三。设备改变可能同时改变类别条件特征分布，此时原似然比不再保持，不能仅靠先验修正保证正确。样本外概率需要验证迁移假设与校准，而不只是代入新比例。

<a id="probability-1-detail-49"></a>

### 7.15 练习十四：由决策成本反推阈值

**问题。** 工业检查中误报成本一，漏检成本十九，缺陷后验二除以十三，是否应判为需检查？如果检查资源受限，此规则是否仍完整？

**解析。** 二动作无约束模型的阈值为二十分之一，而二除以十三大于它，因此需检查。检查期望损失为十一除以十三，不检查为三十八除以十三。资源约束下还需考虑行动之间的竞争、处理成本以及可检查数量，所以单个样本阈值未必能直接实现全局最优。计算的前提范围与数值答案一样需要报告。

<a id="sec-7-1"></a>

### 边界追问：相同似然比意味着相同后验吗

两个总体先验分别为百分之一与二分之一，似然比都为九。赔率先分别为一比九十九与一比一，更新后后验为十二分之一与十分之九。相同证据强度对应不同起点，后验当然不同。反过来，相同后验也可以来自完全不同的先验与证据组合，所以只比较输出概率无法判断模型究竟从证据中学到了多少。

若希望审查一次概率推断，应要求对方明确事件、总体、报告规则、候选假设、先验来源、似然来源、条件独立假设和零概率边界，再核对归一化。一个可信计算必须能重建联合模型，并能解释替代假设改变后结果怎样变化。概率论提供从假设到结论的清晰桥梁；对桥梁两端的现实解释仍需要实验设计、领域知识与数据检验。
