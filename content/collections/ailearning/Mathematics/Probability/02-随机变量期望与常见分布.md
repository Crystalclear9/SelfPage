## 1. 随机变量把实验结果映射为可计算的量

上一章用事件表达不确定性。现在需要描述损失、等待时间、成功次数和噪声幅度等数值。随机变量不是一个“还没算出的普通数字”，而是从随机结果到数值的函数：实验结果确定后，变量的值才随之确定；在结果未知时，分布描述不同数值如何出现。同一个实验可以定义多个随机变量，也可以把不同实验中的变量安排成相同分布。变量、实现值与分布之间的区别，是理解统计推断和机器学习目标函数的基础。

<a id="probability-2-detail-1"></a>

### 1.1 随机变量、实现值与分布

设概率空间为 $(\Omega,\mathcal F,P)$，实随机变量是可测函数 $X:\Omega\to\mathbb R$。可测性要求对任意实数 $x$，事件 $\{\omega:X(\omega)\le x\}$ 属于允许赋概率的事件族。有限模型里这个条件通常自动满足；一般模型中，它保证关于数值范围的问题确实有概率。写 $X$ 通常表示整条随机函数，写 $x$ 表示一个可能值，写 $X(\omega)$ 表示某次结果下的实现。

例如连续投两枚硬币，可以把 $X$ 定义为正面数，把 $Y$ 定义为第一次是否正面。它们依赖同一底层实验，却不是同一个变量。另一个实验从盒子中抽编号零、一、二的球，只要球的概率为四分之一、二分之一、四分之一，其编号变量就与正面数同分布。但同分布不表示它们与其他变量具有相同关系，联合分布仍可不同。

在训练目标中，损失 $\ell(f(X),Y)$ 也是随机变量，其随机性来自输入与标签。总体风险是这个损失的期望，训练集上的平均损失则是有限实现。把训练平均直接叫作真实风险，会抹去随机样本与总体分布的区别。这个概念连接不需要先讨论任何优化算法：首先必须说明积分是在怎样的数据分布下进行。

<a id="probability-2-detail-2"></a>

### 1.2 分布函数统一离散、连续与混合情形

分布函数定义为 $F_X(x)=P(X\le x)$。它单调不减、右连续，在负无穷与正无穷处的极限分别为零与一。对于 $a<b$，有 $P(a<X\le b)=F_X(b)-F_X(a)$。左极限记为 $F_X(x^-)$，单点概率为 $F_X(x)-F_X(x^-)$。这些公式无论变量是离散、连续还是混合，都保持有效，因此分布函数比“有一条密度曲线”更一般。

右连续可以从事件下降连续性理解：让阈值从上方逐渐趋近 $x$，事件 $\{X\le x_n\}$ 递减到 $\{X\le x\}$，概率也趋于相应极限。离散变量在有质量的点产生跳跃；无原子的连续分布没有跳跃。无跳跃并不保证存在普通密度，概率论中还有奇异连续分布。本章主要处理有质量函数、有密度以及二者混合的常用模型，但不把它们误当成所有可能。

若变量取可数值，质量函数 $p_X(x)=P(X=x)$ 非负且总和为一。若分布对长度测度绝对连续，密度 $f_X$ 满足区间概率为密度积分，且密度非负、全实数积分为一。密度允许在个别点重新定义而不改变分布，因为单点对积分没有贡献；质量函数在有质量点上则不能任意修改。

<a id="probability-2-detail-3"></a>

### 1.3 一个混合分布为什么没有单一普通密度

设服务等待时间有百分之二十概率恰好为零，剩余情况下在零到一秒之间均匀分布。则 $P(X=0)=0.2$，而对于 $0<x<1$，分布函数为 $0.2+0.8x$。它在零处跳跃，之后线性增加。只画常数密度零点八会丢掉零处的原子，导致总概率只有零点八；把零点二写成零点上的有限密度高度也无法通过普通积分恢复这段质量。

这种混合现象在零膨胀计数、无索赔保险记录、稀疏激活和有拒绝动作的策略中都很常见。可以用“原子质量加连续部分”清楚描述，不必强行拟合一个到处光滑的密度。分位数在跳跃处也会形成区间映射，后续求逆不能直接假定严格单调。模型应顺应数据生成结构，而不是为了套公式把结构抹平。

<a id="sec-1-1"></a>

### 基础算例：用离散分布直接求两阶矩

令变量以概率四分之一、二分之一、四分之一分别取零、一、二。期望是零乘四分之一、一乘二分之一、二乘四分之一之和，得到一；二阶矩为零、二分之一、一之和，即一点五。方差为二阶矩减均值平方，结果零点五。定义 $Y=2X+3$，均值为五，方差为二，标准差为根号二。

这个例子可同时检查单位：若数值原本以米计，改为厘米会使均值与标准差乘一百，方差乘一万。概率本身无量纲，密度却具有变量单位的倒数。比较不同特征的原始方差，可能主要比较的是计量单位，而不是某种内在重要性。标准化可以改变数值尺度，但不能把有尾部依赖的变量自动变成高斯或独立变量。

<a id="sec-2"></a>

## 2. 期望、可积性与方差：先检查是否存在

<a id="probability-2-detail-6"></a>

### 2.1 期望是对分布的加权积分

离散变量在绝对可积时有 $E[X]=\sum_xxp_X(x)$，有密度时有 $E[X]=\int xf_X(x)\,dx$。更统一的写法是对分布测度积分。对非负变量，期望允许为正无穷；对有正有负的变量，写成正部与负部之差，只有至少一部分积分有限时才有良好定义。通常说“存在有限期望”，指 $E[|X|]<\infty$，避免正无穷减正无穷的歧义。

随机变量的函数也可直接在原分布下求期望：$E[g(X)]=\int g(x)f_X(x)\,dx$，离散时改为求和。无需先推导 $g(X)$ 的完整分布才能算均值。这个规则称为无意识统计学家定律，名称不重要，关键是对每个原始可能值计算函数，再按其概率平均。其适用条件仍是非负性或可积性，不能因为函数写得简单就忽略积分是否收敛。

在可积条件下期望线性：$E[aX+bY]=aE[X]+bE[Y]$，不要求独立。证明是有限和或积分的线性性质。独立影响乘积的期望与方差交叉项，并不影响和的均值。这一点在估算总损失、总计数与线性预测时经常使用：各项可以强烈相关，均值仍相加，只是总波动不能同样草率处理。

<a id="probability-2-detail-7"></a>

### 2.2 方差展开、最优常数与存在条件

若二阶矩有限，记 $\mu=E[X]$，定义 $\operatorname{Var}(X)=E[(X-\mu)^2]$。展开平方并用期望线性得

$$\operatorname{Var}(X)=E[X^2]-\mu^2.$$

二阶矩有限会推出一阶绝对矩有限，可以用柯西不等式 $E|X|\le\sqrt{E[X^2]}$ 说明，因此上述展开没有隐藏不存在的均值。相反，一阶矩有限并不保证方差有限。方差不是“平均绝对偏差”，平方会对极端值施加更强权重，其量纲也变成原量纲的平方。

对任意常数 $a$，把 $X-a=(X-\mu)+(\mu-a)$，展开可得

$$E[(X-a)^2]=\operatorname{Var}(X)+(\mu-a)^2.$$

交叉项为零，因为中心化变量均值为零。因此均值是在平方损失下最优的常数预测，而且误用常数造成的额外损失正好是偏离均值的平方。在一阶绝对矩有限时，绝对损失的最优常数是任意中位数，未必唯一。对离散标签与精确零一损失 $\mathbf1\{X\ne a\}$，风险为 $1-P(X=a)$，所以最大概率质量点即众数是最优动作。这里不能把“概率质量众数”直接换成连续密度最高点：若分布无原子，每个单点概率都为零，精确命中损失对所有常数的风险都为一，根本无法挑出密度众数；要表达“足够接近就算命中”，还需定义容差或其他损失。由此可见，“代表性中心”应与目标损失及变量类型联系，而不是只背一个平均数。

<a id="probability-2-detail-8"></a>

### 2.3 平移缩放与数值稳定性

若 $Y=aX+b$，由线性性质得到均值 $a\mu+b$；中心化后 $Y-E[Y]=a(X-\mu)$，所以方差为 $a^2\operatorname{Var}(X)$，标准差为 $|a|$ 倍。负缩放不会产生负标准差。常数变量方差为零，反过来有限二阶矩且方差零，意味着变量几乎处处等于其均值，可能在零概率集合上例外。

代数等价公式在浮点数中不一定同样稳定。当变量基线很大、波动很小时，计算平均平方再减均值平方，会相减两个接近的大数，损失有效位。中心化求平方和或稳定在线算法通常更好。总体方差定义与样本方差估计也不同；样本平方偏差除以样本量，和为无偏估计而除以少一项，具有不同统计目的，后者的无偏性需要相应抽样假设。

<a id="probability-2-detail-9"></a>

### 2.4 尾部积分给出另一种理解

对非负变量，可以把每个数值看成从零到该数值的单位高度面积，再交换非负积分次序，得到 $E[X]=\int_0^\infty P(X>t)\,dt$。这个表示说明均值是否有限取决于尾概率衰减得够不够快。极少发生的巨额数值，可能使均值发散，即使绝大多数样本看起来很温和。

更一般地，对正数 $r$，有 $E[X^r]=r\int_0^\infty t^{r-1}P(X>t)\,dt$。推导只需把 $X^r$ 写成从零到 $X$ 的 $rt^{r-1}$ 积分，再使用非负积分交换。无需一开始就要求积分有限；发散也能由公式如实呈现。后文重尾分布将用它区分均值存在与方差存在的不同门槛。

<a id="probability-2-detail-10"></a>

### 2.5 非线性、期望与 Jensen 不等式

期望是线性的，却不能穿过一般非线性函数。若函数 $g$ 为凸，且相关期望有良好定义，Jensen不等式给出 $g(E[X])\le E[g(X)]$。一种证明是使用凸函数在均值处的支持直线：存在斜率 $a$，使每个可能输入都满足 $g(x)\ge g(\mu)+a(x-\mu)$。对两边取期望，线性项均值为零，便得到结论。在函数不可微时，可以使用次梯度作为斜率；若均值处于定义域边界，则需要核对支持线和可积条件，不能机械代入。

平方函数的情形就是二阶矩不小于均值平方，差额恰为方差。指数函数则说明对数尺度平均值的指数，通常低于原尺度平均值。假如变量以相同概率取负一与一，其均值为零，均值的指数为一，而指数的均值为两个相反指数值的平均，严格大于一。这个两点例子不依赖任何高斯近似，足以揭示“先平均再变换”与“先变换再平均”之间的结构差别。

对数是凹函数，方向反过来：正变量在相应可积条件下满足平均对数不超过均值的对数。这解释了几何平均通常不超过算术平均，也解释了对数似然目标与直接平均概率具有不同偏好。概率很小的错误会在对数损失下受到强烈惩罚，因此两个预测器即使平均给真实类的概率相同，也可能有不同平均对数损失。比较目标函数时，不能把其非线性变换随便移到样本求和外。

需要注意，不等式给的是模型内期望关系，不是对任何有限样本估计偏差的完整描述。若还要从训练样本估计参数，函数自身随数据改变，就多了一层随机性与依赖结构。应先固定待比较对象，明确期望针对哪些随机量，再决定能否直接使用不等式。很多看似高深的偏差问题，第一步只是找出被悄悄从期望里面移出来的随机对象。

<a id="probability-2-detail-11"></a>

### 2.6 从非负期望得到一个基础尾界

对非负变量 $Z$ 与阈值 $a>0$，逐点有 $Z\ge a\mathbf1_{\{Z\ge a\}}$，取期望得到 $P(Z\ge a)\le E[Z]/a$。这是Markov不等式，其证明只使用非负性。若把有负值的变量直接代入，负部分可能抵消均值，结论就未必成立。对有限方差变量，令非负量为中心化平方，立即得到超过给定偏差的概率受方差除以偏差平方控制。

这里的意义是将矩信息转化成保守的事件概率约束。矩并未确定完整分布，所以界可能很松；若知道变量非负、有界或服从某个明确族，可以获得不同强度的结论。第四章会进一步讨论误差界与样本量设计，本章先建立推理入口：先构造逐点成立的不等式，再取期望，最后检查全部假设。这比直接背一个尾界公式更容易迁移到新的损失变量。

<a id="sec-2-1"></a>

### 机制展开：三种分布对应不同样本空间

伯努利描述一次是否成功，二项描述固定次数内的成功总数，高斯描述实数连续量。三者的支持集不同，参数含义也不同。将点击次数建模为高斯，可能给负数分配概率；将等待时间建模为二项，甚至连取值类型都不匹配。近似可以有价值，但需要说明在关注范围内为什么可接受，以及边界附近的误差是否影响任务。

分布不应仅由均值选择。同样均值为一，可以是恒定的一、参数为一的泊松、均值为一的指数，也可以是某种重尾分布。它们的零概率、尾概率和方差完全不同。先明确“固定机会中的计数”“一段暴露时间里的到达数”“连续等待”“对称误差”等生成结构，再选择候选族，最后用数据检查未被均值反映的特征。

<a id="deep-dive-2"></a>

### 深入讲解：从分布定义推导均值方差并理解密度的单位

密度与概率不是同一量。区间零到零点一上的均匀密度等于十，但该区间总概率仍为一。变量若以秒计，密度单位为每秒；改成毫秒，相应密度数值缩小一千倍，概率不变。连续模型的似然密度也随坐标改变，因此不能脱离测量尺度比较两份不同坐标的数据密度高度。对同一观测、同一参考测度的模型比较，才具有一致意义。

均值方差公式最好沿着结构推导。例如伯努利满足平方等于自身，因此二阶矩立即等于成功概率；二项可以写成独立伯努利之和，从而得到均值与方差；指数等待时间利用生存概率的乘法关系刻画无记忆；高斯的标准化把均值与尺度分开。掌握这些连接，比孤立记忆一张参数表更容易识别错误假设。

<a id="probability-2-detail-14"></a>

## 3. 伯努利与二项：固定机会中的成功次数

<a id="probability-2-detail-15"></a>

### 3.1 伯努利分布的全部信息

若 $P(X=1)=p$，$P(X=0)=1-p$，参数 $p\in[0,1]$，称为伯努利分布。均值为 $p$，二阶矩同为 $p$，方差为 $p(1-p)$。该方差在二分之一处最大，值为四分之一；在零与一处为零，对应确定性结果。一个变量的均值位于零到一，不代表它一定是伯努利，因为它可能取区间内许多连续值。

指标变量是最普遍的伯努利来源：对任意事件 $A$，定义发生取一、否则取零，其期望等于事件概率。因此计数可以写成指标之和，期望计数等于各事件概率之和，不需要事件独立。比如统计违反若干条件的数量，即使这些违反事件相关，平均数量仍可逐项相加；只有要判断至少发生一次的概率或总计数方差时，依赖结构才必须进一步进入。

<a id="probability-2-detail-16"></a>

### 3.2 二项质量函数的组合证明

若 $X_1,\ldots,X_n$ 独立且同服从伯努利参数 $p$，成功数 $S=\sum_iX_i$ 的取值为零到整数 $n$。一个指定的成功位置排列，概率为 $p^k(1-p)^{n-k}$；恰有 $k$ 个成功的位置集合共有组合数 $\binom nk$，且这些完整序列互斥。因此

$$P(S=k)=\binom nkp^k(1-p)^{n-k}.$$

总和为一来自二项式定理。均值由线性性为 $np$，方差因为独立而为 $np(1-p)$。样本比例 $S/n$ 的均值为 $p$，方差为 $p(1-p)/n$。所有这些结论都以固定试验次数、共同成功率及独立机制为前提。只知道每次边缘成功率相同，不足以推出二项分布。

<a id="probability-2-detail-17"></a>

### 3.3 依赖或不同成功率会改变分布族

若每次独立但成功率各不相同，总数服从泊松二项分布，均值是各成功率之和，方差是各 $p_i(1-p_i)$ 之和。用共同平均成功率代替各自参数，可以匹配均值，却一般不能匹配整个分布。若成功率是共享未知参数，积分后还可能出现上一章的Beta—Binomial，额外相关使总数更分散。

若不放回抽取有限总体中的成功项，成功数通常服从超几何分布。第二次的成功概率依赖第一次抽到了什么，因此不能直接使用二项公式。总体很大且抽样比例很小时，二项近似可能合理；当抽样占总体明显比例时，有限总体修正会降低方差。分布族的差异源于实验机制，而不是给相似的直方图随意换一个名字。

<a id="probability-2-detail-18"></a>

### 3.4 小规模手算与边界自检

取四次独立试验，成功率四分之一。恰好两次成功的概率为六乘十六分之一再乘十六分之九，等于二十七除以一百二十八。至少一次成功，用补事件更方便，为一减四分之三的四次方，即一百七十五除以二百五十六。均值为一，方差为四分之三；均值为一不表示最可能的计数只能是一，也不保证每个批次都接近一。

当参数等于零或一时，公式中的零的零次方应按相应有限乘积的连续边界解释，或者直接把分布写成确定质量。实现时显式处理边界比随意使用对数零更稳妥。对很大的试验次数，直接阶乘和幂可能溢出或下溢，可以用对数组合系数与对数概率；但数值稳定计算不替代对模型独立性的检查。

<a id="probability-2-detail-19"></a>

## 4. 泊松计数与指数等待：共享到达机制的两种视角

<a id="probability-2-detail-20"></a>

### 4.1 泊松分布与参数单位

泊松分布参数 $\lambda\ge0$ 表示给定暴露窗口内的平均到达数，质量函数为 $e^{-\lambda}\lambda^k/k!$，整数 $k\ge0$。指数级数保证总和为一。均值推导中利用 $k/k!=1/(k-1)!$，把求和平移一位，得到 $E[X]=\lambda$。类似计算阶乘二阶矩 $E[X(X-1)]=\lambda^2$，再由平方等于阶乘二阶项加自身，得到方差也为 $\lambda$。

注意平均数与方差相等是泊松模型的限制，不是所有计数的普遍性质。若不同批次有不同到达率，共享环境会产生过度离散；若事件互相排斥或受容量约束，也可能低于泊松方差。观测到样本均值近似方差，并不能证明到达独立，只是一个必要特征的经验检查。还需要查看时间聚集、暴露量、极端计数和零比例。

<a id="probability-2-detail-21"></a>

### 4.2 二项到泊松的稀有事件极限

令试验数增加，单次成功率取 $\lambda/n$，使平均总次数保持为 $\lambda$。对固定整数 $k$，二项质量函数可以整理为组合项乘 $(\lambda/n)^k$，再乘 $(1-\lambda/n)^{n-k}$。前一部分趋于 $\lambda^k/k!$，后一部分趋于 $e^{-\lambda}$，于是得到泊松概率。这说明大量独立小机会中少数事件发生时，为何会出现泊松近似。

这个极限针对固定计数及相应机制，不自动保证任意尾事件的相对误差很小。若单次事件不稀有，或许多机会因共同状态一起成功，近似可能差。把一天请求量直接称为泊松，意味着一个强模型选择；促销、节假日与用户群变化可能使窗口内速率变化。应先按合理暴露与时段建模，再考虑残余计数是否接近泊松。

<a id="probability-2-detail-22"></a>

### 4.3 指数分布与无记忆性质

指数分布的速率参数记为 $r>0$，支持非负实数，密度为 $re^{-rt}$，生存函数为 $P(T>t)=e^{-rt}$。由尾部积分，均值为 $1/r$；再算二阶矩为 $2/r^2$，方差为 $1/r^2$。速率单位为每单位时间，均值单位为时间，二者不可混淆。有些软件使用尺度参数 $1/r$，调用接口之前必须查明参数含义。

无记忆性质为 $P(T>s+t\mid T>s)=e^{-rt}=P(T>t)$，因为生存概率比值约去已经等待的部分。它说在模型内等待多久都不改变剩余等待分布。对正在老化的机械、固定周期批处理、具有排队状态的信息系统，这个性质可能明显不合理。指数分布的方便性不能替代机制验证。

<a id="probability-2-detail-23"></a>

### 4.4 泊松过程连接计数与等待

一个齐次泊松过程假设不重叠时间区间的到达增量独立，区间长度相同则增量分布相同，长度 $t$ 的计数服从参数 $rt$ 的泊松分布。第一次到达时间超过 $t$，等价于这段时间到达数为零，所以生存概率为 $e^{-rt}$，等待时间服从指数分布。这是同一个过程的两种表示：窗口内有几次，与到第一次要多久。

仅知道某个窗口计数服从泊松，并不能保证整条时间序列构成泊松过程，因为独立增量等联合结构尚未确定。同样，单次等待时间近似指数，也不足以证明连续等待独立。分布族描述边缘规律，过程模型还规定跨时间的关联。下一章系统讨论联合分布，这里只用这一例子提醒两者层次不同。

<a id="probability-2-detail-24"></a>

## 5. 高斯分布：标准化、二次指数与使用边界

<a id="probability-2-detail-25"></a>

### 5.1 标准高斯密度为什么有这个归一化常数

标准高斯密度为 $\phi(z)=(2\pi)^{-1/2}e^{-z^2/2}$。若记未归一化积分为 $I$，其平方是平面上 $e^{-(x^2+y^2)/2}$ 的二重积分。改用极坐标，面积元为半径乘径向与角向微元，角度积分给二圆周率，径向积分为一，得到 $I^2=2\pi$，所以常数为根号二圆周率的倒数。这一步使用非负积分与坐标变换，不能只把常数当作不可解释的装饰。

对一般 $X=\mu+\sigma Z$，其中 $\sigma>0$，密度为 $[\sigma\sqrt{2\pi}]^{-1}\exp[-(x-\mu)^2/(2\sigma^2)]$。对称性给标准变量均值零，分部积分给二阶矩一，所以一般均值为 $\mu$、方差为 $\sigma^2$。参数写法 $N(\mu,\sigma^2)$ 的第二项通常是方差，但不同软件可能直接接收标准差，文本与接口必须核对。

<a id="probability-2-detail-26"></a>

### 5.2 标准化解决尺度，不创造高斯性

如果变量确实为高斯，减均值再除标准差得到标准高斯。于是任意区间概率都可通过标准分布函数 $\Phi$ 计算。若变量不是高斯，相同变换只能保证均值零、方差一，不能改变其分布形状为高斯。离散变量标准化后仍然离散，重尾变量也不会因为单位统一就自动有轻尾。

当标准差为零时不能做这种除法，应把变量作为确定常数处理。对接近零方差的训练特征，数值稳定项也会改变变换的准确含义。机器学习中标准化参数必须由训练集估计，再应用到验证与测试集，否则评价信息泄漏。此处的理论均值与实际样本估计需明确区分，不能在公式里使用未知总体参数而在结论中假装完全无估计误差。

<a id="probability-2-detail-27"></a>

### 5.3 平方损失与高斯噪声的联系

设回归噪声独立同分布为均值零、方差 $\sigma^2$ 的高斯，模型均值为 $f_\theta(x)$。给定输入的联合负对数似然等于残差平方和除以两倍方差，再加上包含样本量与方差的常数。若方差固定且不依赖模型参数，最小化负对数似然等价于最小化平方残差和。若方差也未知，或每个样本方差不同，则必须保留相应对数尺度项与权重，不能只留下未加权平方误差。

平方损失也可在非高斯模型中作为估计条件均值的目标，因此“用了平方误差”不意味着数据一定服从高斯。反过来，高斯噪声假设还蕴含尾部和条件对称性等信息，可用于构建概率预测，且这些额外假设可能失效。确定性点预测好用，与完整概率模型校准良好，是两种需要分别检验的性质。

<a id="probability-2-detail-28"></a>

### 5.4 退化、近似与尾部风险

当尺度趋于零，高斯分布趋向集中在均值的点质量；它不再是具有正尺度的普通高斯密度。使用某个极小尺度代表确定性，可能使密度高度极大，但事件概率仍不超过一。密度的峰值与结果的“可信概率”不可混为一谈。

多个小扰动叠加常能产生近似高斯的现象，但所需独立性、方差控制和极端项限制将在第四章讨论。这里不能把中心极限定理当成任何直方图的通用辩护。对损失尾部、安全阈值和稀有异常，即使中心部分近似很好，尾部近似误差也可能主导决策，应单独核对极端区域的适用性。

<a id="sec-3"></a>

## 6. 采样平均、协方差与有效信息

<a id="probability-2-detail-30"></a>

### 6.1 均值的方差来自完整协方差和

若 $X_1,\ldots,X_n$ 都有有限二阶矩，则平均值 $\bar X$ 的方差为

$$\operatorname{Var}(\bar X)=\frac1{n^2}\sum_{i=1}^n\sum_{j=1}^n\operatorname{Cov}(X_i,X_j).$$

证明只需先写中心化和的平方，再展开所有成对项并取期望。若独立同分布，非对角项为零，对角项相同，得到 $\sigma^2/n$。独立是充分条件，实际上共同方差且两两不相关已经足够得到这个方差公式；但并不因此获得任意独立样本下的分布结论。

单次观测的标准差描述个体波动，平均估计的标准误描述重复抽样中平均值的波动。两者量纲相同却不是同一个量。独立有限方差情形下，样本量四倍才能使标准误减半。这个平方根规律只描述方差缩减，不单独提供置信区间，不保证估计无偏，也没有说明遇到无限方差时怎么办。

<a id="probability-2-detail-31"></a>

### 6.2 同样边缘分布可以有三种总方差

两次伯努利试验各自成功率二分之一。若独立，总数方差二分之一；若两次永远相同，总数只有零或二，方差为一；若第二次永远取第一次的相反值，总数恒为一，方差为零。两次的边缘分布完全一样，依赖结构却决定总波动。仅统计每列均值和方差，无法推断合并数据的真实不确定性。

对重复记录而言，把同一观测复制一百遍不会把测量误差缩小十倍，因为所有协方差都与原方差相同，平均仍等于原观测。另一方面，合理负相关的抽样设计确实可能降低方差，不能把任何相关都归类为有害。需要关注的是针对目标估计量的协方差结构，而非简单追求数据表的行数。

<a id="sec-4"></a>

## 7. 独立与不相关：二阶信息的力量和局限

<a id="probability-2-detail-33"></a>

### 7.1 协方差、相关系数与柯西不等式

有限二阶矩下，协方差定义为中心化乘积的期望，等于 $E[XY]-E[X]E[Y]$。相关系数再除以两个正标准差，得到无量纲数。利用任意线性组合中心化平方的期望非负，可推出协方差平方不超过两方差乘积，因此相关系数位于负一到一。若某变量方差为零，相关系数的分母为零，不能默认为零。

协方差依赖单位，相关系数消除正比例尺度。负比例缩放会翻转相关符号。相关等于一或负一，在有限非零方差条件下意味着一个变量几乎处处是另一个的仿射函数；这比“散点大致沿线”是更严格的数学陈述。样本相关系数恰好接近一并不证明总体确定性关系，还可能受样本范围和选择机制影响。

<a id="probability-2-detail-34"></a>

### 7.2 非线性依赖的完整反例

令 $X$ 在负一到一之间均匀分布，定义 $Y=X^2$。由对称性，$E[X]=E[X^3]=0$，因此协方差为零。可是一旦知道 $X$，$Y$ 就被完全确定，当然不独立。甚至不需要直接使用点条件概率：事件 $\{|X|\le1/2\}$ 与 $\{Y\le1/4\}$ 完全相同，概率都是二分之一，交集也是二分之一，而独立要求四分之一。

这个事件证明避免了对连续变量精确值条件化的技术问题，也更清楚地说明独立要求所有适当事件的分解。不相关只约束一个乘积矩，无法排除平方、绝对值、周期或尾部关系。机器学习中，一个特征与标签样本线性相关接近零，不能据此断言它对预测无用；应考虑任务与可能的非线性结构。

<a id="probability-2-detail-35"></a>

### 7.3 高斯中的特殊结论要保留联合前提

如果两个变量联合服从二元高斯，且协方差为零，那么其联合密度中的交叉项消失，可以分解为两个边缘密度，所以独立。这个结论要求联合高斯，仅仅每个边缘单独是高斯不够。例如标准高斯 $Z$ 与独立公平符号 $S$，令 $X=Z,Y=SZ$，两边缘都是标准高斯且协方差为零，但绝对值完全相等，显然依赖。

高斯分布的特殊性在于联合规律由均值向量与协方差矩阵决定；一般联合分布不是如此。因此对相关矩阵做分解或白化，通常只消除二阶相关，不自动消除全部依赖。后续的独立成分、概率图和高维统计学习，都建立在对这一边界的清楚认识上。遇到零相关推出独立的论证，必须寻找它在哪里使用了联合高斯。

<a id="sec-5"></a>

## 8. 变量变换：用概率守恒推导密度

<a id="probability-2-detail-37"></a>

### 8.1 单调变换从分布函数开始

设 $X$ 有密度，变换 $Y=g(X)$ 在相关支持上严格递增，反函数 $h$ 在对应区间可微，并满足通常的密度换元条件（例如变换为导数非零的连续可微双射）。则 $P(Y\le y)=P(X\le h(y))$。求导得到 $f_Y(y)=f_X(h(y))h'(y)$。递减变换需要改变不等号方向，最终统一成 $f_X(h(y))|h'(y)|$。支持集也要一起变换，不能只替换密度中的表达式而保留原区间。

取均匀变量零到一，放大两倍后支持为零到二，密度为二分之一；若再平移，密度形状不变但区间移动。雅可比因子补偿单位区间被放大或缩小的长度，使对应事件概率守恒。它不是人为的概率惩罚，也不说明变换让某个原结果变得更“真实”。

<a id="probability-2-detail-38"></a>

### 8.2 非单调变换必须汇总全部原像

对 $Y=X^2$，若 $X$ 在负一到一均匀，正的 $y<1$ 对应两个原像 $\sqrt y$ 与负根号 $y$。每个分支贡献密度二分之一乘 $1/(2\sqrt y)$，合计为 $1/(2\sqrt y)$。在零附近密度趋于无穷，但可积，区间零到 $\varepsilon$ 的概率为根号 $\varepsilon$，仍趋于零，所以零没有原子质量。

只取正分支会使总概率减半。变量变换前必须检查是否一一映射、有没有平坦区间、是否会把一整段质量压到一个点。例如 $Y=\max(0,X)$ 对连续对称变量，会把所有负值压成零，在零产生点质量，不能只对正半轴写密度后便宣称描述完整。

<a id="probability-2-detail-39"></a>

### 8.3 对数、指数与饱和变换

若标准高斯经指数得到正变量，密度需要除以新变量本身，形成对数正态分布。虽然原变量对称，变换后常明显右偏，均值与中位数也不同。对数变换可以使乘性结构转成加性，但把对数尺度预测均值直接指数回去，一般不是原尺度均值；还要平均指数函数，这涉及非线性与期望不交换。

若 $Y=\tanh X$，其支持在负一到一，反函数导数为 $1/(1-y^2)$。于是变换密度的对数为原对数密度减去 $\log(1-y^2)$。等价地，在原变量处减去 $\log(1-\tanh^2x)$。接近边界时浮点饱和可能使直接计算出现对数零，需要稳定表达式。这个修正来自可逆变换的概率守恒，广泛用于有界动作策略；若真正裁剪而非可逆压缩，则还会产生边界原子，不能使用相同公式。

<a id="probability-2-detail-40"></a>

### 8.4 分位数变换与广义逆

定义分位数 $Q(u)=\inf\{x:F_X(x)\ge u\}$，其中 $u\in(0,1)$。若 $U$ 均匀，则 $Q(U)$ 具有目标分布。严格连续时它就是通常的反函数；离散或混合时需要广义逆，例如伯努利会把一整段均匀数映成零，另一段映成一。必须检查端点与跳跃，不能在没有一一对应时直接用光滑反函数公式。

指数分布可由 $T=-\log(1-U)/r$ 生成。计算机均匀数可能包含零但通常不含一，使用保持小数精度的对数函数有利于边界稳定性。这里说明的是分布变换原理，抽样误差、随机种子与蒙特卡洛估计在第四章展开。能生成一个分布，不意味着少量样本就准确反映其均值和尾部。

## 9. 进阶：有效样本量、重尾与生成函数

<a id="probability-2-detail-42"></a>

### 9.1 有限长度相关序列的精确均值方差

设序列二阶平稳，均值固定、共同方差为 $\sigma^2>0$，滞后 $k$ 的相关系数为 $\rho_k$。将协方差和按滞后分组，对角项有 $n$ 个，每个正滞后有两倍 $n-k$ 个，于是

$$\operatorname{Var}(\bar X)=\frac{\sigma^2}{n}\left[1+2\sum_{k=1}^{n-1}\left(1-\frac{k}{n}\right)\rho_k\right].$$

括号内记作 $\tau_n$。若它为正，可针对“估计这个变量的均值”定义方差等价的有效样本量为 $n/\tau_n$。这是与独立同方差观测比较的定义，不是数据固有的统一信息条数。换成另一个函数的均值，相关结构也会变，因而有效样本量可能不同。若平均方差恰为零，就不应机械除零，应直接说明存在精确抵消。

<a id="probability-2-detail-43"></a>

### 9.2 无穷相关和近似有哪些前提

若自相关绝对可求和，并且长时间方差因子 $\tau=1+2\sum_{k\ge1}\rho_k$ 为正，长序列可用 $n/\tau$ 近似。有限长度公式中的权重与截断不能在短序列里随便丢掉。对于相关 $\rho_k=\rho^k$ 且绝对值小于一，几何级数给 $\tau=(1+\rho)/(1-\rho)$，于是近似有效量为 $n(1-\rho)/(1+\rho)$。

正相关通常降低均值信息，负相关可能让方差等价有效量大于实际行数。这不是凭空创造独立记录，而是目标均值的噪声发生抵消。只因看到某一阶负相关，也不能判定总相关和必为负；其他滞后仍可能主导。实际相关估计具有噪声，长滞后截断方法、非平稳性与多变量目标都会影响估计。本章提供确切方差恒等式，不以一个估计有效量替代所有收敛诊断。

<a id="sec-6-1"></a>

### 从分布参数推到均值与波动

伯努利的成功率决定单次方差，独立重复后方差按次数相加，共享参数或相关误差则引入协方差。泊松把均值与方差绑定为同一参数，指数把标准差与均值绑定为相同尺度，高斯则允许独立设定位置与尺度。这些约束是模型可检验的内容。若观察数据明显违背，应修改族或层次结构，而不是只报告拟合均值看起来合理。

同一均值方差仍不足以确定一般分布。例如公平取正负一的变量，与标准高斯均值零、方差一，但前者不可能超过绝对值一，后者却在任意大阈值之外仍有正概率。依赖均值方差的算法可以把它们当成相同二阶信息，依赖尾部或似然的任务则会明显区分。选择描述层级应由问题决定。

<a id="probability-2-detail-45"></a>

### 9.3 Pareto 尾部区分一阶与二阶存在性

设正变量从尺度 $x_m>0$ 开始，其生存函数为 $(x_m/x)^\alpha$，其中形状 $\alpha>0$。密度为 $\alpha x_m^\alpha x^{-\alpha-1}$。直接积分可得 $r$ 阶矩在 $r<\alpha$ 时有限，等于 $\alpha x_m^r/(\alpha-r)$；当 $r\ge\alpha$ 时发散。因此形状超过一才有有限均值，超过二才有有限方差。

形状在一与二之间时，平均值这个总体量存在，但独立样本均值的方差仍为无穷，不能使用标准误等于标准差除根号样本量的有限方差公式。形状不超过一时，有限期望不存在，很多观测都很小也无法改变这个积分事实。截断模型可产生有限矩，但截断上限是额外假设，必须说明它在物理机制上是否真实。

<a id="probability-2-detail-46"></a>

### 9.4 Cauchy 的对称为何不产生均值零

标准Cauchy密度为 $1/[\pi(1+x^2)]$，关于零对称，中位数为零。但正半轴的一阶矩积分发散，负半轴的负部也发散，所以期望没有定义。对称截断积分的极限为零，那叫主值，不等于通常期望。任意调换积分次序或正负项顺序可能得到不同结果，正是绝对可积条件所防止的问题。

一个有限样本平均总能计算，并不保证它估计的是存在的总体均值。对于独立同分布Cauchy，样本平均仍有同样的Cauchy分布，并不会随数量增加稳定集中；这是该分布的稳定性性质，可通过特征函数证明。不能用一次模拟中平均看起来稳定就推翻理论，也不能用一次极端跳跃证明任意实际数据都应当用Cauchy。尾部模型需要机制、诊断和谨慎的目标选择。

<a id="probability-2-detail-47"></a>

### 9.5 生成函数把矩与加法结构连接起来

对非负整数变量，概率生成函数为 $G_X(z)=E[z^X]$，至少在零到一区间有定义。伯努利为 $1-p+pz$，独立和的生成函数是各生成函数乘积，因此二项为该表达式的整数次方。泊松则为 $\exp[\lambda(z-1)]$，所以独立泊松之和仍为泊松，参数相加。独立性使乘积期望分解，不能仅凭边缘生成函数直接推广到相关和。

在可以合法求导并取极限时，一阶导数在一给均值，二阶导数给阶乘二阶矩。矩生成函数 $M_X(t)=E[e^{tX}]$ 则要求检查其存在范围；有有限若干阶矩不保证在零附近存在矩生成函数。特征函数使用复指数，因绝对值为一总存在，但其展开、唯一性与极限定理需要额外理论。本章把生成函数作为结构工具，避免将形式幂级数操作当成无条件合法。

## 10. 逐步计算实验：分布、变换和相关平均

<a id="probability-2-detail-49"></a>

### 10.1 实验设计与可检验恒等式

下面代码不依赖随机抽样，而是对有限质量、解析密度与协方差矩阵做确定性验证。这样可以区分公式错误与蒙特卡洛噪声：二项归一化和矩、泊松截断尾、混合分布的原子、平方变换的积分、相关平均的精确方差都能直接检查。对无限支持分布截断求和时，必须说明遗漏尾部不会大到改变结论，不能把截断和直接当成完整分布。

这里泊松参数为二，求和到六十，远端剩余质量对当前容差可忽略。平方变换密度在零处发散，直接等距求积可能很差，所以通过精确分布函数计算区间概率，再比较原变量区间。这是选择合适计算表示的问题，不能因为密度不有界就认定分布不合法。相关序列采用有限二十维协方差，分别用矩阵和滞后求和两条路径核对。

```python
import math
import numpy as np

n, p = 4, 0.25
k = np.arange(n + 1)
prob = np.array([math.comb(n, int(j))*p**int(j)*(1-p)**(n-int(j))
                 for j in k])
assert np.isclose(prob.sum(), 1.0)
assert np.isclose(k @ prob, n*p)
assert np.isclose(((k-n*p)**2) @ prob, n*p*(1-p))
assert np.isclose(prob[2], 27/128)

lam = 2.0
poisson = [math.exp(-lam)]
for j in range(1, 61):
    poisson.append(poisson[-1] * lam / j)
v = np.arange(len(poisson))
poisson = np.array(poisson)
assert np.isclose(poisson.sum(), 1.0, atol=1e-14)
assert np.isclose(v @ poisson, lam, atol=1e-13)
assert np.isclose(((v-lam)**2) @ poisson, lam, atol=1e-12)

# Mixed law: mass 0.2 at zero, uniform component of mass 0.8.
assert np.isclose(0.2 + 0.8, 1.0)
assert np.isclose(0.8 / 2, 0.4)  # Mean.
assert np.isclose(0.8 / 3 - 0.4**2, 8/75)

# X uniform on [-1,1], Y=X^2. Check exact interval probabilities.
for upper in (0.01, 0.25, 0.81, 1.0):
    from_original = (2*math.sqrt(upper))/2
    from_transformed_cdf = math.sqrt(upper)
    assert np.isclose(from_original, from_transformed_cdf)

size, rho = 20, 0.8
idx = np.arange(size)
cov = rho ** np.abs(idx[:, None] - idx[None, :])
mean_variance = cov.sum() / size**2
factor = 1 + 2*sum((1-j/size)*rho**j for j in range(1, size))
assert np.isclose(mean_variance, factor/size)
assert np.linalg.eigvalsh(cov).min() > 0
print("binomial probabilities", prob)
print("finite mean variance", mean_variance)
print("finite variance-equivalent n", size/factor)
print("asymptotic approximation", size*(1-rho)/(1+rho))
```

二项质量依次为八十一、一百零八、五十四、十二、一，统一除以二百五十六。相关平均的精确方差约零点三五一一，有限有效量约二点八四八；无穷相关和近似给二点二二二。在二十个记录、相关衰减较慢的情况下，两者差异明显，不能把渐近表达式称为有限样本精确答案。实验还核对协方差矩阵正定，保证所用相关结构是一个合法有限模型。

<a id="probability-2-detail-50"></a>

### 10.2 进阶复核：量纲、尾部与目标

请把泊松窗口长度改成两倍：若到达速率不变，参数应随暴露时间翻倍。再把指数速率翻倍，平均等待应减半；两个相反变化来自参数单位的不同。对高斯把标准差翻倍，密度峰值减半，但同样若干标准差范围内的概率不变。通过这些变换自检，比只看代码能否运行更容易发现参数语义错误。

重尾分布的实验应先问要估计均值、中位数还是某个截断风险。若总体均值不存在，增加模拟长度并不能使它变成存在；若方差不存在，报告常规标准误也缺乏这里的理论依据。可以用分位数或截断均值等不同目标，但它们回答不同问题，需要清楚定义，不能在结果不稳定后悄悄更换而仍称作同一个平均风险。

## 11. 练习与逐步参考答案

<a id="probability-2-detail-52"></a>

### 11.1 练习一：从跳跃与斜率重建混合分布

**问题。** 变量以四分之一概率为零，其余在零到二均匀分布。写出分布函数，求正好为零、落在零到一之间的概率与均值。

**解析。** 负值处分布函数零，零点跳至四分之一，零到二为四分之一加八分之三乘自变量，二以后为一。正好为零概率四分之一，严格大于零且不超过一的概率八分之三。均值为连续部分权重四分之三乘区间均值一，即四分之三。只积分连续密度会遗漏原子，但均值中零原子贡献恰为零，不能因此误认为原子不重要。

<a id="probability-2-detail-53"></a>

### 11.2 练习二：最优常数依赖损失

**问题。** 变量以九成概率为零，一成概率为十。平方损失下最优常数是多少？绝对损失下呢？

**解析。** 均值为一，因此平方损失最优常数为一，可由方差分解验证任何偏离会增加偏离平方。绝对损失下零是中位数且最优：在零到十之间，期望绝对损失为零点九倍预测值加零点一倍十减预测值，随预测值递增，所以最低在零。分布强烈偏斜时，“中心”由损失定义；不能把均值、中位数和众数视作总可互换的数值。

<a id="probability-2-detail-54"></a>

### 11.3 练习三：同样成功率不保证二项

**问题。** 两次成功指标都服从公平伯努利，但第二次恒等于第一次。总成功数分布是什么，均值和方差是多少？

**解析。** 总数以二分之一概率为零，以二分之一概率为二，均值一，二阶矩二，方差一。独立二项会给零、一、二概率四分之一、二分之一、四分之一，方差二分之一。缺失的独立条件使概率质量从中间转移到两端。只对边缘成功率做检查无法发现共享状态，应检查成对与更高阶关系。

<a id="probability-2-detail-55"></a>

### 11.4 练习四：不同成功率的独立和

**问题。** 两次独立伯努利，成功率分别为零点二和零点八。求成功数分布、均值与方差，比较参数为二和二分之一的二项。

**解析。** 零成功概率零点一六，双成功同为零点一六，一成功零点六八。均值一，方差零点三二；共同平均成功率的二项方差零点五，不能精确替代。独立保留了方差相加，同分布假设却失效。极端成功率更接近确定性，解释了在相同总均值下方差为何降低。

<a id="probability-2-detail-56"></a>

### 11.5 练习五：泊松计数的补事件

**问题。** 每小时到达次数服从参数二的泊松，求一小时至少两次的概率。如果不重叠时段独立，三小时总次数分布如何？

**解析。** 至少两次等于一减零次与一次概率，得到 $1-3e^{-2}$。独立三小时计数之和的生成函数是三个相同指数函数之积，故总数服从参数六的泊松。若各小时只是边缘泊松但存在共同强度变化，不能直接合并成参数六的泊松。暴露时间相加需要相应过程或独立和的前提。

<a id="probability-2-detail-57"></a>

### 11.6 练习六：指数等待的条件概率

**问题。** 等待速率每分钟二，已等待三分钟，接下来半分钟仍未到达的概率是多少？它是否等于从零开始等待三点五分钟的生存概率？

**解析。** 无记忆给条件生存概率 $e^{-1}$，从零到三点五分钟的生存概率是 $e^{-7}$，两者不同。条件概率已除以等待三分钟的概率，因此不用再次惩罚已发生的长等待。如果设备会老化，观察长等待可能提供状态信息，无记忆模型就未必合理；计算正确不意味着机制适配。

<a id="probability-2-detail-58"></a>

### 11.7 练习七：密度高度不等于概率

**问题。** 零到零点二的均匀变量密度是多少？精确等于零点一的概率与落在零点零九到零点一一的概率分别是多少？

**解析。** 密度为五，单点概率零，区间概率为长度零点零二乘密度五，即零点一。把测量单位放大一千倍后密度数值除以一千，而对应区间长度乘一千，概率不变。有限精度显示“零点一”往往代表一个舍入区间，若问题指显示值而非数学精确值，应使用相应区间事件。

<a id="probability-2-detail-59"></a>

### 11.8 练习八：平方变换的两个分支

**问题。** 标准高斯平方后的正半轴密度如何得到？为什么不能只取正根分支？

**解析。** 每个正值对应正负两个原像，两边原密度相同，各乘反函数导数绝对值二倍根号的倒数，合计为 $e^{-y/2}/\sqrt{2\pi y}$，支持正半轴。这是自由度一的卡方密度。只取一支遗漏另一半概率，总积分二分之一。零处密度发散却无点质量，判断原子应看分布函数跳跃而非密度是否很高。

<a id="probability-2-detail-60"></a>

### 11.9 练习九：不相关的事件反证

**问题。** 均匀变量在负一到一，平方为另一变量。用事件概率而非精确值条件概率证明不独立，并算原变量与平方的协方差。

**解析。** 对称性使一阶矩与三阶矩均为零，协方差零。绝对值不超过二分之一和平方不超过四分之一是同一事件，概率二分之一，交集二分之一而非边缘乘积四分之一。这个证明同时说明不相关只是一条矩约束，而独立要求所有相关事件组合分解。连续单点概率为零不妨碍用有正概率区间展示依赖。

<a id="probability-2-detail-61"></a>

### 11.10 练习十：正态边缘不够

**问题。** 标准高斯与独立公平符号相乘构造第二变量，证明两个边缘高斯且不相关，但不独立。

**解析。** 高斯对称，乘正负号都保持边缘标准高斯。乘积期望为符号均值零乘原变量二阶矩一，故协方差零。两者绝对值相同，事件各自绝对值不超过一也完全相同，其概率严格在零与一之间，交集不等于概率平方。联合分布集中在两条直线上，并非通常非退化二元高斯，不能使用联合高斯的零协方差结论。

<a id="probability-2-detail-62"></a>

### 11.11 练习十一：有效量的前提

**问题。** 二阶平稳序列的相关系数为半数的滞后次幂，长度很长时均值有效量约为多少？能否说所有统计量都获得这个有效量？

**解析。** 无穷相关和为一，长时间方差因子为三，因此有效量约为长度的三分之一。需要二阶平稳、有限方差、相关可求和及长度足以使用近似。另一个统计量如平方或尾事件指标，其自相关通常不同，不能继承同一个有效量。短序列应回到带有限权重的精确公式，而不是对渐近比例赋予过高精度。

<a id="probability-2-detail-63"></a>

### 11.12 练习十二：重尾的矩门槛

**问题。** Pareto尺度一、形状一点五，均值和方差是否有限？形状改为三时二者是多少？

**解析。** 形状一点五时均值为三，二阶矩发散，所以方差无限；并非均值为三就能用有限标准差计算标准误。形状三时均值为三除以二，即一点五，二阶矩为三，方差为四分之三。矩存在要求阶数小于形状，恰好相等时也发散。尾部边界上的对数发散不能用“几乎够快”忽略。

<a id="probability-2-detail-64"></a>

### 11.13 练习十三：Cauchy 的错误对称积分

**问题。** 为什么对称截断的Cauchy一阶积分恒为零，却不能说期望为零？如果样本平均算出零附近又说明什么？

**解析。** 对称截断强制正负尾按同一速度抵消，但通常期望要求正负两部分能合法相减。此处两部分都发散，因此零只是主值。一个有限样本平均在零附近，是一次实现，既不能建立不存在的总体均值，也不能证明随着样本增加会集中。可以改研究中位数或固定截断目标，但应明确目标已改变。

<a id="probability-2-detail-65"></a>

### 11.14 练习十四：单位变化与对数似然

**问题。** 变量从米换成厘米，连续密度在对应点如何变化？同一批样本的对数密度和变化多少，为什么同坐标下的模型比较仍可保持？

**解析。** 新变量为原变量一百倍，密度除以一百，每个样本对数密度减少自然对数一百，总和减少样本量倍该常数。若两模型都对相同变换后的观测使用正确密度，它们减少同一常数，差异不变。若只给一个模型修正或比较不同观测单位的原始数值，就失去一致性。密度量纲必须与参考测度配套。

<a id="probability-2-detail-66"></a>

### 11.15 练习十五：有限均值不保证矩生成函数存在

**问题。** 对正的对数正态变量，所有非负整数矩都有限，是否意味着其矩生成函数在正数邻域有限？

**解析。** 不意味着。对数正态右尾虽然足以使任意固定次幂可积，却不足以抵消正的指数函数增长，因此对任意正参数，其指数矩发散。形式上把所有矩代入指数级数，不能保证得到收敛的有限函数。使用生成函数推导时，要先核对其定义域和求导换积分条件，不能只看到若干矩存在就无限外推。

<a id="sec-7-1"></a>

### 边界追问：不相关是否足以推出独立

离散反例更容易手算：变量等概率取负一、零、一，平方为第二变量。前者均值零，乘积即立方的均值也为零，因此协方差零。第二变量为零与第一变量为零其实是同一事件，概率三分之一，交集三分之一，与边缘乘积九分之一不同，故不独立。这个结论不依赖是否有光滑密度，也不依赖图看起来是否有趋势。

完成本章后，应能够从支持集和生成机制选择分布，从定义推导主要矩，从概率守恒推导变换密度，并在使用均值、方差和有效量前检查存在性与依赖条件。第三章将把多个变量组织成联合分布，系统解释边缘化与条件期望；第四章讨论样本平均的极限、误差界和数值推断。把这些层次区分开，可以避免用一个平均公式承担它没有证明过的全部统计结论。
