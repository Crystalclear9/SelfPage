# 矩阵微积分

从 Fréchet 微分与内积定义出发，推导矩阵梯度、批量反向传播和归一化算子，再用完整网络的一阶与二阶实验核对推导。

**先修知识：** 线性代数；偏导数与链式法则。

**正文篇幅状态：** 本主题现有 4 章均已按长篇教材标准展开，逐章纯正文达到 12000–20000 汉字。完整范围见[长篇教材覆盖表](../../README.md#textbook-status)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：从形状到梯度所有权](04-从零实现两层网络的梯度检查.md#sec-8-1)，再对照逐步解析与验收要求。

建议按 01→02→03→04 阅读：先明确导数与内积，再处理计算图的归约和分支，之后推导常见算子，最后用完整网络复核。第 3 章的交叉熵作为可微目标可以先求导；若需要理解概率评分的含义，再配合[交叉熵与 KL](../InformationTheory/02-交叉熵KL散度与分类训练.md)阅读。第 4 章使用 NumPy，需先具备数组形状、广播和矩阵乘法的实现基础。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
