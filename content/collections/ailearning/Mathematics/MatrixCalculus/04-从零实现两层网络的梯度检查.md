## 1. 明确数学目标和前向反向接口

本章构建一个可以完整阅读、独立运行并逐项检查的两层网络。目标不是用最少代码画出下降曲线，而是让每个参数块、每个归约系数、每个缓存和每个二阶项都能被解释。前几章已经讨论矩阵微分、批量共享和归一化导数，这里把它们组成一个完整实验，检验数学、程序和检查器三者是否计算同一个函数。

先选择光滑的双曲正切作为隐藏激活，输出使用线性回归。这样在有限参数下所有阶导数都存在，便于把实现错误与非光滑边界分开。多输出、偏置和权重正则全部保留，因为省略这些部分会让错误归约、参数遗漏和广播问题无法暴露。之后再讨论替换成分类输出、ReLU 或随机层时需要怎样修改检查条件。

设批量数为 $`n`$、输入维数为 $`d`$、隐藏宽度为 $`h`$、输出维数为 $`k`$。采用行样本约定，$`X\in\mathbb R^{n\times d}`$，$`Y\in\mathbb R^{n\times k}`$，参数为 $`W_1\in\mathbb R^{d\times h}`$、$`b_1\in\mathbb R^h`$、$`W_2\in\mathbb R^{h\times k}`$、$`b_2\in\mathbb R^k`$。偏置沿样本轴广播，不能把长度为隐藏宽度的数组误解为每条样本独立的偏移。

<a id="m4-1"></a>
### 1.1 前向方程与多输出归约

完整前向定义为

$$
S=XW_1+\mathbf1b_1^T,\quad A=\tanh S,
\quad Z=AW_2+\mathbf1b_2^T,\quad R=Z-Y,
$$

$$
\begin{aligned}
L &=\frac{1}{2n}\Vert R\Vert _F^2+
\frac{\lambda}{2}\left(\Vert W_1\Vert _F^2+\Vert W_2\Vert _F^2\right),\\[6pt]
\lambda &\geq0.
\end{aligned}
$$

这里对样本取平均，对输出维度求和，偏置不正则化。若使用所有输出元素的均值，则数据项应除以 $`nk`$，这是另一种目标。不要在反向实现里随手使用数组的 mean，再在解释中仍写只除样本数。正则项也没有除以样本数，所以改变批量大小不应改变它在目标中的相对定义。

输入和标签在本章视为固定数据，但也会推导输入梯度作为附加检查。若标签依赖参数、输入来自可训练的前置模块或存在共享参数，就需要将相关路径继续连接。数学符号中的独立性假设应在程序接口中体现，否则两个看似相同的数组可能承载不同导数身份。

<a id="sec-1-1"></a>
### 1.2 基础算例：两层标量网络完整反传一次

先使用容易手算的 ReLU 标量网络说明路径：$`a=\max(0,w_1x+b_1)`$，$`z=w_2a+b_2`$，$`L=\frac{(z-y)^2}{2}`$。取 $`x=2`$、$`w_1=1`$、$`b_1=0`$、$`w_2=3`$、$`b_2=0`$、$`y=5`$。隐藏输入为二，激活为二，预测为六，残差为一，损失为二分之一。

输出权重梯度为残差乘激活，即二；输出偏置梯度为一。隐藏激活上游为残差乘输出权重，即三，且此点 ReLU 斜率为一，所以第一层权重梯度为六，第一层偏置梯度为三。四个结果都来自同一组更新前的参数。

若学习率为零点零一，同步更新后参数变为 $`w_1=0.94`$、$`b_1=-0.03`$、$`w_2=2.98`$、$`b_2=-0.01`$。新隐藏激活为一点八五，新预测为五点五零三，损失约零点一二六五。这个下降是指定小步长下的计算结果，并非任何正步长都下降的保证。若先更新输出权重，再用新输出权重反传第一层，得到的就不是原损失在原参数点的梯度。

<a id="deep-dive-1"></a>
### 1.3 深入讲解：从前向缓存到逐项反传

记输出上游 $`D_2=\frac{R}{n}`$。利用矩阵内积与微分，有

$$
G_{W_2}=A^TD_2+\lambda W_2,\quad
G_{b_2}=D_2^T\mathbf1,
$$

$$
D_1=(D_2W_2^T)\odot(1-A^2),\quad
G_{W_1}=X^TD_1+\lambda W_1,\quad
G_{b_1}=D_1^T\mathbf1,\quad G_X=D_1W_1^T.
$$

每个公式都能从内积恒等式验证。例如输出微分为 $`dZ=dA\,W_2+A\,dW_2+\mathbf1\,db_2^T`$，将它放入 $`dL=\langle D_2,dZ\rangle_F`$，把未知微分移到内积右侧，就得到对应梯度。偏置之所以求和，是因为同一个偏置微分同时影响所有样本，而不是因为所有广播反向都可以不看轴地求和。

隐藏层导数使用已缓存的激活 $`A`$，因为双曲正切导数为 $`1-A^2`$。当激活接近饱和，使用缓存避免重复求值造成细小不一致，但无法恢复前向已经舍入丢失的极小斜率。本章使用中等初始化尺度，避免所有路径因为饱和而近乎为零，从而提高检查区分力。

<a id="m4-2"></a>
### 1.4 缓存所有权与同步语义

前向缓存至少需要输入、激活和残差；反向还需要前向时的输出权重。如果缓存只保存数组引用，而训练器在反向前原地更新参数，缓存表达的函数就悄悄变化了。可靠接口可以约定前向与反向之间禁止参数写入，或保存必要快照并验证版本。小教学程序选择立即计算完整梯度，再统一返回更新器处理，避免混合两个阶段。

缓存是否可以复用还取决于用途。若只是同一参数点对不同上游做 VJP，可以复用前向中间值；若参数、输入或随机状态改变，就不能继续使用旧缓存。二阶自动微分还要求保留梯度计算自身的图，普通数值缓存只能支持手工计算，不能自动替代计算图的依赖信息。

将前向、反向、参数打包和优化更新分成清晰接口，有助于定位责任。前向只负责给定输入与参数产生目标和必要中间值，反向只负责该函数的导数，检查器只负责独立扰动，更新器只负责应用所有梯度。接口分离不必增加很多文件，本章仍用自足代码块表达全部逻辑。

### 图解：梯度检查的对照对象

![梯度检查的对照对象：机制、算例与边界](images/04-concept.svg)

左图固定 $`f(w)=w^3,w=1`$，计算中心差分 $`d_h=\frac{f(1+h)-f(1-h)}{2h}`$，分别与正确梯度三、故意写错的梯度三点一比较。灰色参考线来自精确代数式 $`d_h=3+h^2`$；蓝线和橙线则实际以 binary64 浮点数计算函数值和差分，横轴、纵轴直接标注以十为底的对数。相邻采样点以线连接，细小波动不是连续误差函数的解析形状。

在适中的步长区间，正确梯度的误差明显下降，而错误梯度留下约零点一的平台；当步长极小时，两个近似相等函数值相减会放大舍入影响，正确实现也可能变差。这不是“梯度突然变错”，而是验证工具自身失去分辨率。具体谷底和波动依表达式求值顺序与浮点环境变化，不能把图中某个最佳步长机械套用于其他网络。

右图另用二维二次函数 $`F(w)=\frac12\|w\|_2^2`$ 隔离方向选择问题。在 $`w=(1,2)`$ 处真梯度为 $`g=(1,2)`$，假设实现错误地交换了两个分量，返回 $`\widehat g=(2,1)`$。只沿 $`v=(1,1)`$ 检查，二者点积都为三，任何合适步长都无法区分；沿 $`v=(1,-1)`$ 检查，则真值负一、错误值正一。几何上两个梯度在对角方向上的投影重合，而差向量与该方向正交。这里的函数不同于左边三次函数，两图分别研究数值分辨率与方向信息缺失，不应把右图数字代入左图误差曲线。

因此，步长扫描与方向覆盖是两项独立工作。对于二次函数，中心差分在精确算术中对所有非零步长都精确给出方向导数，方向盲点仍然存在；这不是调小 h 可以解决的。小网络可检查全部坐标，大网络可组合独立随机方向与偏置、共享参数、归约等定向扰动。

对照 [PyTorch 的 Gradcheck mechanics](https://docs.pytorch.org/docs/2.10/notes/gradcheck.html) 时，还应区分数值差分与自动微分两条路径。这里的光滑标量例子只隔离步长问题；真实网络仍需要固定随机性、避免原地改变缓存、核对目标归约，并单独处理不可微点。后面的参数块误差图则回到完整两层网络，检验不同故障实际影响了哪些路径。

<a id="sec-2"></a>
## 2. 建立可运行的完整一阶检查

一个单坐标检查只能回答该坐标在该点的导数是否相符。小网络参数总量有限，应先全面检查所有权重和偏置，再把方向方法用于较大网络。检查器本身要避免依赖待测反向逻辑，否则同一种错误可能同时进入解析结果和参考结果，给出虚假的一致。

<a id="m4-3"></a>
### 2.1 参数打包与一维坐标契约

参数打包将多个形状不同的数组按固定次序展平成一个向量，便于统一坐标差分、随机方向和 Hessian 向量积。次序必须固定为明确的参数块顺序，形状元数据必须由接口保存，而不能由不稳定的外部遍历结果猜测。解包后要检查长度完全匹配，既不能漏掉尾部参数，也不能让多余元素被悄悄忽略。

展平与恢复的往返关系应满足逐块数值相等，方向向量也采用同一契约。若解析梯度按另一种顺序打包，标量点积仍可能产生有限数，但语义已经错误。检查器应至少验证每块切片长度、名称和形状，且用一组容易识别的参数测试往返，不只在全零数组上验证。

下面代码将参数形状固定在元组中，切片复制后恢复成数组。复制避免扰动一个打包向量时意外修改原始参数。教学实现优先清晰，在大型模型中可使用视图减少复制，但那需要更严格地处理别名与原地写入。

<a id="m4-4"></a>
### 2.2 完整参数块、正则与方向检查

```python
import numpy as np
rng = np.random.default_rng(24)
n, d, h, k = 4, 3, 5, 2
X = rng.normal(size=(n, d))
Y = rng.normal(size=(n, k))
lam = 0.07
shapes = ((d, h), (h,), (h, k), (k,))
sizes = tuple(int(np.prod(shape)) for shape in shapes)
names = ('W1', 'b1', 'W2', 'b2')

def pack(parts):
    assert tuple(part.shape for part in parts) == shapes
    return np.concatenate([part.reshape(-1) for part in parts])

def unpack(theta):
    assert theta.ndim == 1 and len(theta) == sum(sizes)
    parts, start = [], 0
    for shape, size in zip(shapes, sizes):
        parts.append(theta[start:start+size].reshape(shape).copy())
        start += size
    return tuple(parts)

def loss_grad(theta):
    W1, b1, W2, b2 = unpack(theta)
    A = np.tanh(X@W1+b1)
    R = A@W2+b2-Y
    loss = np.sum(R*R)/(2*n) + lam*(np.sum(W1*W1)+np.sum(W2*W2))/2
    D2 = R/n
    D1 = (D2@W2.T)*(1-A*A)
    grads = (X.T@D1+lam*W1, D1.sum(axis=0),
             A.T@D2+lam*W2, D2.sum(axis=0))
    return float(loss), pack(grads)

theta = pack(tuple(rng.normal(scale=0.3, size=shape) for shape in shapes))
assert np.array_equal(pack(unpack(theta)), theta)
loss, analytic = loss_grad(theta)
step = 1e-5
numeric = np.empty_like(theta)
for j in range(len(theta)):
    direction = np.zeros_like(theta)
    direction[j] = step
    numeric[j] = (loss_grad(theta+direction)[0]-loss_grad(theta-direction)[0])/(2*step)
assert np.allclose(analytic, numeric, atol=1e-8, rtol=1e-6)
start = 0
for name, size in zip(names, sizes):
    print(name, 'max error', np.max(abs(analytic[start:start+size]-numeric[start:start+size])))
    start += size
for _ in range(6):
    direction = rng.normal(size=theta.shape)
    direction /= np.linalg.norm(direction)
    finite = (loss_grad(theta+step*direction)[0]-loss_grad(theta-step*direction)[0])/(2*step)
    assert np.isclose(analytic@direction, finite, atol=1e-8, rtol=1e-6)
print('loss', loss, 'parameters', len(theta), 'all first-order checks passed')
```

本实验包含三十二个参数，四个参数块全部参与前向；两个权重块参与正则路径，两个偏置块明确不正则化。输入、隐藏、输出维度互不相等，有助于暴露错误转置；偏置非零，有助于暴露遗漏广播；输出维数为二，有助于暴露全元素平均与按样本平均的混淆。若把这些维度都设成一，虽然手算方便，但不能作为完整验收数据。

注意数值检查调用同一个前向目标，但并未调用解析梯度的结果来计算差分。因此能发现反向公式与前向不一致；它仍无法发现前向目标本身违背题意，比如把标签顺序错配后前向反向一致。这就是为什么数学目标、数据契约与导数检查必须分别验收。

<a id="sec-2-1"></a>
### 2.3 单坐标检查与方向检查各覆盖什么

逐坐标检查给出每个参数的局部偏导，能够指出具体出错块，代价约为两倍参数数量次前向。随机方向检查将所有坐标混合，只需要两次前向，适合大模型抽查。但错误向量可能恰好与某个方向正交，多方向只能降低漏检风险，不能在有限测试中证明任意实现完全正确。

对一个固定非零错误向量，连续随机方向与它严格正交的概率为零，但有限精度、误差容限和方向维度会影响可观测大小。高维单位方向在任意单一坐标上的分量可能较小，局部错误被稀释。因此大模型可结合全局方向、按层方向、按参数块方向以及少量重点坐标，避免一类检查承担全部职责。

错误相互抵消也是方向检查的现实问题。两个坐标的解析错误恰好相反，若方向在这两个坐标上的权重相等，内积误差就为零。针对偏置、共享参数和正则项使用不同方向分组，可以提高检验能力。选择检查方式应从可能的错误机制出发，而不只追求运行次数最少。

<a id="m4-5"></a>
### 2.4 步长扫描、误差尺度与验收阈值

中心差分在光滑条件下通常具有平方级截断误差，但当步长过小时，两个接近的目标值相减会放大舍入。适宜步长取决于参数、方向和目标的尺度。可以对同一坐标扫描从较大到较小的多个数量级，观察误差先下降后上升的趋势；若整段范围都保持某个固定倍数偏差，更可能是公式或归约错误。

相对误差在真梯度接近零时可能非常大，即使绝对误差已很小。应同时报告绝对误差，并使用绝对与相对容限组合。对于数值接近零的坐标，还应选择另一个不退化参数点验证，避免正确答案和错误答案都接近零而失去区分力。

步长也可以按坐标尺度设置为基础系数乘以参数绝对值与一的较大者，方向检查则先归一方向。这样的缩放不是万能最优，只是让不同坐标的扰动更可比较。若目标包含高曲率或非常不均衡的参数块，还需要分块分析，不能把任何自动步长规则当作无需解释的正确性保证。

<a id="sec-3"></a>
## 3. 失败排查与故障注入

检查失败时，先判断比较的是否同一个函数，再判断求导是否正确，最后才调整数值容限。否则很容易把目标不一致误解释成浮点误差，或者为了让断言通过不断放宽阈值。本节把常见失败模式与可以区分它们的干预对应起来。

<a id="m4-6"></a>
### 3.1 固定比例、局部错误与随机漂移

若所有数据项梯度整体相差批量数或输出维数，优先检查 sum、mean 和二分之一系数。若只有权重出错而偏置正确，检查正则是否遗漏或多除样本数。若只有偏置错误，检查广播反向的求和轴。若仅隐藏层错误，检查激活导数、输出权重转置以及是否使用更新后的权重。

若每次检查结果明显漂移，应先关闭随机层或固定噪声，确认运行统计量和外部数据没有改变。若只有零点附近失败，要检查不可微分支。若误差随着差分步长出现规律变化，则需要进一步区分截断与舍入。根据模式缩小范围，比在整套公式中随机改转置更有效。

还要确认检查器没有修改原参数并忘记恢复。采用生成新向量的加减法，可以减少原地恢复错误。若为了效率必须原地扰动，应使用异常安全的恢复机制，确保即使前向报错也恢复原值；否则后续所有坐标都可能在不同基点比较，产生难以解释的误差图样。

<a id="m4-7"></a>
### 3.2 四种有区分力的故障注入

可以暂时构造四种错误反向结果，观察检查器能否捕捉。第一种把所有数据梯度再除一次批量数；第二种删除权重正则；第三种隐藏层漏乘双曲正切斜率；第四种把隐藏偏置梯度沿错误轴求和或只取第一条样本。每个错误应在精心选择的非退化输入上造成明显差异。

删除正则的故障需要非零权重与非零正则系数才能暴露。如果测试时正则系数始终为零，检查通过不能证明正则实现正确。漏乘激活斜率的故障若恰好在隐藏输入全零处测试，双曲正切斜率全一，也可能被掩盖。优秀检查不仅要覆盖代码行，还要让对应数学因子实际影响结果。

为检查同步语义，可故意先用输出层梯度更新输出权重，再计算隐藏层梯度。把这种错误结果与原参数点的差分比较，通常只在前层出现偏差。随后将学习率逐渐减小，偏差也会减小，但这不意味着算法因此变成正确的同步梯度；它只是错误受到小步长抑制。区分近似接近与数学相同十分重要。

<a id="m4-8"></a>
### 3.3 形状检查为何只能证明一部分

形状是强有力的第一道约束，但相同形状可能承载不同语义。将两个同宽输出列交换、沿错误但同样大小的轴求和、在方阵中漏掉转置，都可能继续产生合法形状。检查数据应主动使用不相等的维度，并用可追踪的小整数样本确认轴含义。

反过来，有些错误通过广播产生看似合理但实际更高维的结果。例如标签原本为单输出向量，预测为二维列矩阵，两者相减可能广播成样本数乘样本数矩阵。最终 mean 仍然给出标量，训练也可能下降，但模型优化的是两两样本之间的错误目标。应在计算残差前严格断言预测与标签形状完全相同，而不是只看最终损失是否标量。

输入梯度也是一条额外检查路径。若第一层权重梯度正确但输入梯度错误，问题可能出在矩阵乘法的伴随方向。对输入进行方向差分能独立检验这一点，也为未来把该网络接到可训练前置模块提供准备。所有接口的返回值都应有清楚的名字与形状，而不是依赖位置猜测。

<a id="sec-4"></a>
## 4. 跟随一个坐标与一个方向追踪全图

矩阵表达压缩了大量标量路径，但不会改变链式法则。为了理解共享参数为什么对样本求和，可以展开第一层某个权重的全部路径，再与矩阵式逐项对应。这个过程也为后面的雅可比乘积和二阶传播建立直觉。

<a id="m4-9"></a>
### 4.1 一个第一层权重如何影响所有输出

对权重 $`(W_1)_{ab}`$，它先改变每条样本的第 $`b`$ 个隐藏输入，变化量为 $`X_{sa}`$。经过激活斜率后，隐藏激活变化为 $`(1-A_{sb}^2)X_{sa}`$。再通过第二层第 $`b`$ 行，影响所有输出维度。因此

$$
\frac{\partial L}{\partial(W_1)_{ab}}
=\sum_{s=1}^n\sum_{j=1}^k
\frac{R_{sj}}n(W_2)_{bj}(1-A_{sb}^2)X_{sa}
+\lambda(W_1)_{ab}.
$$

对输出维度的求和形成隐藏上游，对样本的求和形成共享权重梯度。这两次求和代表不同来源的路径汇合，不能因为都以加法出现就随意改变平均系数。参数正则是独立直达损失的路径，不经过样本、激活和输出，所以不应再次乘激活导数。

偏置梯度与第一层权重类似，只是每条路径中输入因子换成一。若某个特征在全部样本中为零，对应权重的数据梯度为零，但偏置梯度仍可能非零。这个对照可以用来设计定位测试，确认权重梯度确实使用了正确的输入特征。

<a id="m4-10"></a>
### 4.2 前向方向传播与伴随检验

给定参数方向 $`(V_1,v_1,V_2,v_2)`$，把变化记为点号，有

$$
\dot S=XV_1+\mathbf1v_1^T,\quad
\dot A=(1-A^2)\odot\dot S,
$$

$$
\dot Z=\dot A W_2+AV_2+\mathbf1v_2^T.
$$

这是网络输出的 JVP，不需要显式构造输出对全部参数的雅可比。给定任意输出上游 $`U`$，按前面的反向公式传播但不加入损失归约与正则，得到输出映射的 VJP。两者必须满足 $`\langle U,\dot Z\rangle_F=\langle J^TU,V\rangle`$。

这个伴随关系直接检查网络映射，不依赖平方损失。若只对一个固定标签做损失梯度检查，某些输出方向上的错误可能被残差抵消；随机选择多个输出上游可以覆盖不同组合。前向方向传播、反向伴随传播与有限差分三者结合，比单一路径对照更能提供独立证据。

<a id="m4-11"></a>
### 4.3 共享参数、正则和不变性

两层网络存在一些可用于测试的参数对称性。隐藏单元的排列若同时作用于第一层列、隐藏偏置和第二层行，预测保持不变，权重平方和也保持不变，因此整体目标不变。相应梯度应按同样排列变换。这种检查能发现参数块对应关系错误，且无需计算数值差分。

双曲正切是奇函数，如果将某个隐藏单元的第一层权重列与偏置同时取负，再将对应第二层权重行取负，预测同样不变。正则项也不变。这个离散对称性并不直接产生连续零曲率方向，却会产生多个参数表示同一函数。讨论解的唯一性时应注意参数冗余，而不能从一个训练结果稳定就推断参数本身可唯一识别。

若改用齐次激活如 ReLU，还会出现相邻层之间的正尺度变换。前向可保持不变，但权重正则一般改变，因此原有尺度对称性被目标打破。测试不变性之前需要把整个目标包含进去，不能只检查预测后就宣称损失一定相同。

<a id="sec-5"></a>
## 5. 从正确梯度到可解释训练实验

梯度检查应在训练之前完成，但它不能替代训练实验。通过检查说明程序在指定点计算了所写目标的局部导数；训练实验则进一步观察更新规则是否正确使用梯度、目标是否随合理步长变化，以及模型能否拟合一个预先知道结构的小任务。两类证据回答不同问题，应当分别报告。

<a id="m4-12"></a>
### 5.1 下降检验与训练循环

对非零梯度 $`g`$，沿负梯度方向的瞬时方向导数为 $`-\Vert g\Vert ^2<0`$。若函数在当前点可微，足够小的正步长会降低目标。可以尝试一组逐渐缩小的步长，检查实际下降与一阶预测是否逐渐一致。若任意足够小步长都上升，优先检查更新符号、参数对应或目标状态是否改变。

但不能反过来用下降证明梯度正确。任意与真实梯度具有锐角的错误向量，也可能让目标下降。比如把所有梯度乘以二，训练仍然可能顺利，只相当于步长变大；只要某一层贡献足够，遗漏另一层梯度的程序也可能短期下降。因此训练曲线只提供行为证据，不能代替导数核对。

下面的独立实验使用单输出小回归任务，全部参数同步更新，并把正则项纳入同一个标量目标。它不写文件、不保存图片，结果以断言表达。步长是本实验的设置，不能直接迁移到任何数据尺度与网络宽度。

```python
import numpy as np
rng = np.random.default_rng(51)
X = np.linspace(-1., 1., 24).reshape(-1, 1)
Y = np.sin(2.*X)
W1 = rng.normal(scale=0.4, size=(1, 6))
b1 = rng.normal(scale=0.1, size=6)
W2 = rng.normal(scale=0.4, size=(6, 1))
b2 = np.zeros(1)
lam = 1e-4

def evaluate(parts):
    w1, c1, w2, c2 = parts
    a = np.tanh(X@w1+c1)
    r = a@w2+c2-Y
    loss = np.sum(r*r)/(2*len(X))+lam*(np.sum(w1*w1)+np.sum(w2*w2))/2
    d2 = r/len(X)
    d1 = (d2@w2.T)*(1-a*a)
    gradients = (X.T@d1+lam*w1, d1.sum(0), a.T@d2+lam*w2, d2.sum(0))
    return float(loss), gradients

parts = (W1, b1, W2, b2)
initial, gradients = evaluate(parts)
norm_squared = sum(np.sum(g*g) for g in gradients)
small_step = 1e-5
nearby = tuple(p-small_step*g for p, g in zip(parts, gradients))
actual = evaluate(nearby)[0]-initial
assert np.isclose(actual/small_step, -norm_squared, rtol=2e-4)
for _ in range(1500):
    loss, gradients = evaluate(parts)
    parts = tuple(p-0.08*g for p, g in zip(parts, gradients))
final = evaluate(parts)[0]
assert final < initial/10
print('training objective', initial, '->', final)
```

该任务能被两层非线性网络较好近似，但目标下降并没有证明泛化。这里没有从训练曲线推断真实数据表现，只是让更新器的语义可被检验。若进一步比较不同宽度、激活或优化器，应增加独立验证数据，并控制初始化、计算预算和正则定义，避免把更长训练误认为方法优势。

<a id="m4-13"></a>
### 5.2 分类输出如何接入同一反向核心

若输出 $`Z`$ 改解释为分类 logits，隐藏层和矩阵反向公式保持不变，只需替换输出上游。对归一软标签和按样本平均的交叉熵，$`D_2=\frac{(P-Q)}{n}`$，其中概率由稳定 Softmax 获得。正则项仍然在权重梯度末端加入。若类别权重或掩码存在，先按上一章推导正确的输出上游，再交给网络反向。

这体现了反向模块化的价值：网络映射负责把输出上游拉回参数，损失模块负责定义上游。二者接口清楚后，平方损失、交叉熵或其他平滑目标都能共享网络反向，但不能共享不加检查的归约系数。一个损失模块返回的上游如果已经包含批量均值，网络层就不应再次平均。

分类实验还要注意先验检查。目标类别应合法、类别轴应正确、软标签应满足对应约束。若给网络前向接了 Softmax，再送入期待 logits 的组合损失，反向可以完全自洽并通过差分，但优化目标已经错误。梯度正确性仍然只是整体正确性的一部分。

<a id="m4-14"></a>
### 5.3 随机层、运行状态和停止梯度

加入 dropout 后，每次前向可能使用不同掩码。若两次差分使用不同噪声，目标差包含随机波动，不再单纯描述参数方向变化。检查条件随机函数时，应固定同一噪声样本，并让解析反向使用同一掩码。检查期望目标则是另一个统计估计问题，需要处理采样误差和导数交换条件，不能简单把条件检查结果当作期望梯度的证明。

训练态归一化层可能更新运行统计量。即使当前输出使用批统计量，检查过程也可能污染后续评估状态。可以复制并恢复状态，或使用不更新外部状态的纯函数实现；关闭训练模式则改变了被检查函数，不能用评估态通过替代训练态检查。要验证哪个函数，就应把那个函数的全部状态纳入契约。

停止梯度也会影响数值检查。若某个中间值在计算图中被视作常数，而检查器每次扰动都重新生成它，数值差分实际上包含了被停止的路径。此时解析与差分不同可能是检查对象不一致，而不是反向错误。应固定被停止的中间值后做条件差分，或者明确报告正在比较完整函数与代理梯度。

<a id="sec-6"></a>
## 6. 进阶：完整 Hessian 向量积与广义 Gauss–Newton

一阶反传把输出上游拉回参数空间。二阶分析进一步追踪这个梯度如何随参数变化，不必构造庞大的完整 Hessian。只要能够计算任意方向上的梯度变化，就可以研究曲率、执行某些迭代线性求解，并核对自动微分的二阶图。

<a id="m4-15"></a>
### 6.1 对反向公式做方向微分

沿参数方向 $`V`$，先按第四节得到 $`\dot S`$、$`\dot A`$ 和 $`\dot Z`$。平方损失下，$`\dot R=\dot Z`$、$`\dot D_2=\frac{\dot Z}{n}`$。记 $`Q=1-A^2`$、$`B=D_2W_2^T`$，则 $`D_1=B\odot Q`$，所以

$$
\dot D_1=(\dot D_2W_2^T+D_2V_2^T)\odot Q
+B\odot(-2A\odot\dot A).
$$

再对参数梯度微分，得到

$$
\dot G_{W_2}=\dot A^TD_2+A^T\dot D_2+\lambda V_2,
\quad \dot G_{b_2}=\dot D_2^T\mathbf1,
$$

$$
\dot G_{W_1}=X^T\dot D_1+\lambda V_1,
\quad \dot G_{b_1}=\dot D_1^T\mathbf1.
$$

把这些方向梯度按原参数顺序打包，就是完整 $`HV`$。注意输出层梯度有两个乘积法则项，隐藏层也有输出权重变化项与激活斜率变化项。删除其中任何一项，都可能得到某种近似，但不再是完整 Hessian 向量积。

<a id="m4-16"></a>
### 6.2 残差曲率为何会产生负特征值

对平方损失，完整 Hessian 可以写成

$$
H=\frac1nJ^TJ+\frac1n\sum_{s,j}R_{sj}\nabla_\theta^2Z_{sj}
+\lambda M,
$$

其中 $`J`$ 是展平输出对参数的雅可比，$`M`$ 是只在权重坐标上为一的对角选择矩阵。第一项半正定，第二项由残差加权的模型二阶导组成，可能不定。普通 Gauss–Newton 保留第一项与正则项，忽略第二项。它不是通过计算精度提高就会等于完整 Hessian 的方法，而是明确的曲率近似。

如果残差全部为零，第二项消失，平方损失下两者精确相同。若模型对全部参数联合仿射，模型二阶导也为零。若只是某一层固定时对另一层线性，不能推出联合二阶导为零。两层线性网络的参数乘积已经足以形成混合曲率，非线性激活还会增加本层二阶项。

对于分类损失，广义 Gauss–Newton 使用 $`J^TH_ZJ`$，其中输出损失 Hessian 为上一章的类别协方差块。固定非负监督质量时该项半正定，但完整参数 Hessian 仍有输出梯度乘模型二阶导的项。研究报告应明确自己计算的是完整 Hessian、Gauss–Newton 还是其他近似，不应把它们统称为曲率后混用结论。

<a id="sec-6-1"></a>
### 6.3 三条独立路径核对二阶传播

完整二阶证据可以由三条路径组成：解析方向微分、对一阶梯度做中心差分，以及对梯度与固定方向内积再做自动微分。还可用对称性 $`u^THv=v^THu`$ 检查线性算子的伴随结构。对称性是必要条件而非充分条件，零算子同样对称，因此不能替代独立数值核对。

下面代码自足定义前向、一阶、二阶和参数打包，并与 PyTorch 双重反传交叉检查。它还计算 Gauss–Newton 方向，验证其与完整结果在当前非零残差点通常不同。整个实验只保留向量，不构造完整 Hessian。

```python
import numpy as np
import torch
rng = np.random.default_rng(8)
n, d, h, k = 3, 2, 3, 2
X = rng.normal(size=(n, d))
Y = rng.normal(size=(n, k))
lam = 0.09
shapes = ((d, h), (h,), (h, k), (k,))
sizes = [int(np.prod(s)) for s in shapes]

def pack(parts):
    return np.concatenate([x.reshape(-1) for x in parts])

def unpack(v):
    assert v.shape == (sum(sizes),)
    result, start = [], 0
    for shape, size in zip(shapes, sizes):
        result.append(v[start:start+size].reshape(shape))
        start += size
    return tuple(result)

def gradient(theta):
    W1, b1, W2, b2 = unpack(theta)
    A = np.tanh(X@W1+b1)
    D2 = (A@W2+b2-Y)/n
    D1 = (D2@W2.T)*(1-A*A)
    return pack((X.T@D1+lam*W1, D1.sum(0), A.T@D2+lam*W2, D2.sum(0)))

def hvp(theta, vector, gauss_newton=False):
    W1, b1, W2, b2 = unpack(theta)
    V1, v1, V2, v2 = unpack(vector)
    A = np.tanh(X@W1+b1)
    Q = 1-A*A
    D2 = (A@W2+b2-Y)/n
    adot = Q*(X@V1+v1)
    zdot = adot@W2+A@V2+v2
    d2dot = zdot/n
    if gauss_newton:
        d1dot = (d2dot@W2.T)*Q
        w2dot = A.T@d2dot+lam*V2
    else:
        d1dot = (d2dot@W2.T+D2@V2.T)*Q+(D2@W2.T)*(-2*A*adot)
        w2dot = adot.T@D2+A.T@d2dot+lam*V2
    return pack((X.T@d1dot+lam*V1, d1dot.sum(0), w2dot, d2dot.sum(0)))

theta = pack(tuple(rng.normal(scale=0.3, size=s) for s in shapes))
v = rng.normal(size=theta.shape)
v /= np.linalg.norm(v)
w = rng.normal(size=theta.shape)
w /= np.linalg.norm(w)
analytic = hvp(theta, v)
step = 1e-5
finite = (gradient(theta+step*v)-gradient(theta-step*v))/(2*step)
assert np.allclose(analytic, finite, atol=1e-8, rtol=1e-6)
assert np.isclose(w@analytic, v@hvp(theta, w), atol=1e-12)
gn = hvp(theta, v, gauss_newton=True)
assert v@gn >= -1e-12
assert np.linalg.norm(analytic-gn) > 1e-4

t = torch.tensor(theta, dtype=torch.float64, requires_grad=True)
parts, start = [], 0
for shape, size in zip(shapes, sizes):
    parts.append(t[start:start+size].reshape(shape))
    start += size
W1, b1, W2, b2 = parts
xt = torch.tensor(X, dtype=torch.float64)
yt = torch.tensor(Y, dtype=torch.float64)
r = torch.tanh(xt@W1+b1)@W2+b2-yt
loss = (r*r).sum()/(2*n)+lam*((W1*W1).sum()+(W2*W2).sum())/2
(g,) = torch.autograd.grad(loss, t, create_graph=True)
(hv,) = torch.autograd.grad((g*torch.tensor(v)).sum(), t)
assert np.allclose(gradient(theta), g.detach().numpy(), atol=1e-13)
assert np.allclose(analytic, hv.numpy(), atol=1e-13)
print('HVP finite error', np.max(abs(analytic-finite)),
      'full versus GN', np.linalg.norm(analytic-gn))
```

在自动微分实现中，一阶梯度必须保留创建二阶图所需的路径。若先转成 NumPy 数组，或者主动停止梯度，再把数值重新包装成张量，数值虽相同，但依赖已经丢失。重新包装并不能恢复导数历史。手工解析实现不依赖计算图，因为全部乘积法则已显式写出；两种实现方式应分别理解。

<a id="m4-17"></a>
### 6.4 二阶检查的边界与计算代价

Hessian 向量积的存储通常远低于完整矩阵，适用于大参数量网络。但它仍然需要额外前向或反向工作，并可能保留更多中间图。不能因为没有显式矩阵就称其为零成本。比较方法时应报告实际计算次数、峰值内存和是否重用缓存。

差分一阶梯度时，检查质量同时取决于一阶梯度是否正确。如果一阶实现存在系统性错误，差分可能与同一错误实现的解析方向微分保持一致，所以独立自动微分路径尤其重要。反过来，自动微分也不能判断目标是否合理；三种方法一致说明导数实现自洽，仍需回到原始任务审查数据和目标。

非光滑激活的二阶解释需要谨慎。在固定 ReLU 激活模式区域内，可以讨论经典导数，但跨越折点的有限差分混合了不同区域。自动微分在折点采用某种约定，不等于经典 Hessian 在该点存在。研究局部曲率应记录参数点和激活裕度，避免把分支变化造成的差异误写成二阶算法错误。

### 图解：两层网络鞍点中的残差曲率

![两层乘积网络的等损失曲线和穿过原点的两条方向切片](images/04-extension.svg)

**同一网络，两个相反的方向结论。** 为隔离联合参数的二阶项，暂时取无激活、无偏置、无正则的两层标量网络 $`z=ab`$，目标 $`L=\frac{(ab-1)^2}{2}`$。左图画精确等损失曲线，蓝线与橙线分别沿 $`(1,1)`$、$`(1,-1)`$ 穿过原点。右图将这两个路径写成一维函数：

$$
L(t,t)=\frac{(t^2-1)^2}{2},\qquad
L(t,-t)=\frac{(t^2+1)^2}{2}.
$$

两者在零点的一阶导数都为零，二阶导数却分别为 $`-2`$ 与 $`2`$。这里的路径方向长度是 $`\sqrt2`$，因此相应**单位方向**曲率分别为 $`-1`$、$`1`$，与完整 Hessian 的特征值一致，不能把路径二阶导数直接误读成单位方向特征值。

原点处 $`J=(b,a)=(0,0)`$，故 Gauss–Newton 矩阵 $`J^TJ`$ 为零；完整 Hessian 却为

$$
H=\begin{pmatrix}0&-1\\-1&0\end{pmatrix}.
$$

差异全部来自非零残差乘模型二阶导。图像让“完整 Hessian 不一定半正定”变成可见的两个方向：蓝向先下降，橙向先上升，原点是鞍点。它不意味着完整 Hessian 在所有任务上都优于半正定近似；噪声、阻尼与计算预算仍影响选择。第 8.2 节继续用这个小网络解释数值检查。

<a id="sec-7"></a>
## 7. 练习与逐步解析

下列练习覆盖归约、广播、参数路径、缓存、随机性及一二阶结构。建议先画出依赖关系，再写公式，最后设计能够证伪错误实现的输入。答案不仅给结论，还说明哪些条件改变后结论不再成立。

<a id="m4-e1"></a>
### 7.1 多输出均值为何会差一个维数

**问题。** 输出维数为三，目标从样本平均的输出平方和改成所有元素平均，权重正则保持原定义。一阶梯度如何变化？

**解析。** 数据项梯度全部缩小为原来的三分之一，正则梯度不变，因为正则不在数据元素平均内部。若把整体梯度都除以三，连正则也被缩小，得到的是第三种目标。训练曲线可能都下降，但它们的最优平衡不同。检查器应同时使用非零残差、非零权重和非零正则，才能区分这几种情况。

<a id="m4-e2"></a>
### 7.2 共享偏置为什么求和而不再次平均

**问题。** 上游 $`D_2`$ 已经包含样本均值系数，输出偏置梯度还能再对样本求 mean 吗？

**解析。** 不能。每条样本都依赖同一个偏置，链式法则要求把它们的贡献相加。平均系数已在上游中，额外平均会再缩小一个批量数。可用两条完全相同的样本检查：复制样本不应改变按样本平均目标的偏置梯度，而额外平均会使其减半。这个不变性测试比只核对形状更容易发现错误。

<a id="m4-e3"></a>
### 7.3 零输入能检查哪些参数

**问题。** 输入全部为零，第一层权重的数据梯度为零。是否说明该层实现正确？

**解析。** 零输入让任何第一层权重变化都不影响前向，所以该块数据梯度理应为零。错误的零返回实现也会通过。它适合检查偏置和正则，却不适合验收第一层数据路径。应增加非零且各特征不同的数据，并覆盖多个样本。测试不是越简单越好，而是要让目标路径实际被激活。

<a id="m4-e4"></a>
### 7.4 为什么不能边反传边更新

**问题。** 输出权重先更新，再计算隐藏层误差，误差从何而来？

**解析。** 原损失的隐藏上游应使用原输出权重。更新后权重等于原值减学习率乘输出层梯度，所以隐藏上游额外混入一个与学习率成正比的项。它不是原参数点的一阶导数，也不是把所有参数同步移到新点后的完整梯度，因为激活与残差仍来自旧前向。修复方式是先计算并保存所有参数梯度，再统一更新，不能用调小步长代替语义修复。

<a id="m4-e5"></a>
### 7.5 单方向通过是否能排除两个坐标错误

**问题。** 错误梯度与真实梯度相差 $`(1,-1)`$，用方向 $`(1,1)`$ 检查会怎样？

**解析。** 两者与该方向的内积相同，方向检查完全无法发现。增加方向 $`(1,-1)`$ 就会得到明显偏差。高维随机方向降低精确抵消概率，但有限容限仍可能掩盖小分量错误。可结合坐标、分块方向和全局方向，先在小模型全面验证，再在大模型抽查。有限检查提供证据，不构成任意输入下正确性的证明。

<a id="m4-e6"></a>
### 7.6 训练下降为什么不是梯度证明

**问题。** 某实现把真实梯度乘以正数五，训练仍然下降。应怎样评价？

**解析。** 它可能等价于使用五倍学习率，所以行为可以合理，但作为原目标的梯度实现仍然错误。如果优化器具有裁剪、自适应状态或不同块学习率，整体缩放的等价性还会受到破坏。应使用数值差分检验导数，再单独讨论是否有意识地采用缩放更新。不能因为最终训练成功就把错误数学解释视为无关紧要。

<a id="m4-e7"></a>
### 7.7 缓存引用被原地修改会发生什么

**问题。** 前向保存输出权重引用，随后参数数组原地更新，再用缓存反向，是否相当于保存了旧权重？

**解析。** 引用指向同一块存储，原地写入会让缓存看到新值，因此没有保存旧权重。若缓存需要旧值，必须复制或禁止更新。即使语言变量名没有变化，也不能据此推断数值快照存在。可以在前向后故意修改参数，检查反向是否拒绝版本不一致，或是否仍按明确的快照语义运行。

<a id="m4-e8"></a>
### 7.8 ReLU 折点为何使中心差分看似不符

**问题。** 标量函数为最大值零与参数，参数恰好为零，中心差分是什么？

**解析。** 正扰动输出为步长，负扰动输出为零，所以中心差分为二分之一。经典导数在该点不存在，自动微分可能按约定返回零，这并不构成求导错误。应移到远离折点的位置检查光滑区域，或使用单侧导数与次梯度概念讨论边界。若真实网络许多隐藏输入接近零，方向差分也可能跨分支，因此需要记录最小激活裕度。

<a id="m4-e9"></a>
### 7.9 固定 dropout 掩码检查了什么

**问题。** 固定一个随机掩码后一阶检查通过，能否证明期望目标梯度正确？

**解析。** 它直接验证的是该掩码条件下的确定性函数导数。期望目标还涉及对随机性积分，以及能否交换求导与期望。若每个掩码对应导数正确且满足适当条件，可以进一步推导期望梯度；但一个掩码的数值检查本身不提供这些全部条件。实验报告应明确条件检查与统计估计的层次，避免把随机误差当作有限差分误差。

<a id="m4-e10"></a>
### 7.10 停止梯度为何改变检查对象

**问题。** 定义 $`a`$ 为当前参数值的复制并停止梯度，计算 $`L=\theta a`$。参数为二时，解析导数与重新生成复制的差分为何不同？

**解析。** 条件求导中复制值固定为二，所以导数为二。如果每次扰动都重新令复制值等于新参数，实际数值函数变成参数平方，差分导数为四。两者比较的函数不同。应固定复制值后扰动，或承认正在研究一个代理梯度。停止梯度不是数值操作，它改变计算图中的依赖关系。

<a id="m4-e11"></a>
### 7.11 完整 Hessian 和 Gauss–Newton 何时相同

**问题。** 平方损失下，两种曲率何时精确一致？

**解析。** 完整 Hessian 多出残差加权模型二阶项。如果所有残差为零，这项消失；如果模型对全部参数联合仿射，该项也消失。仅残差很小通常只能得到近似，且还要控制模型二阶导大小；仅某层单独线性也不足以消除联合混合项。应从完整公式判断，而不是凭网络名称或损失名称推断。

<a id="m4-e12"></a>
### 7.12 HVP 对称性通过是否足够

**问题。** 某程序总返回零向量，满足任意两个方向的双线性对称关系，是否说明二阶实现正确？

**解析。** 不够。任何对称矩阵都满足该关系，包括零矩阵。应同时比较梯度差分和独立自动微分，并选择具有明显非零曲率的参数点。对称性特别适合捕捉乘积法则遗漏或转置问题，但它只是必要条件之一。还可检查方向缩放与加法的线性关系，判断实现是否真是当前点的线性算子。

<a id="m4-e13"></a>
### 7.13 正则选择矩阵为什么不是单位阵

**问题。** 仅对两层权重施加平方正则，Hessian 正则项是否为整体参数空间的单位阵乘正则系数？

**解析。** 不是。偏置坐标没有正则，因此选择矩阵在权重位置为一，在偏置位置为零。HVP 中只有权重方向需要增加正则系数乘方向，偏置方向不应增加。若把所有参数打包后直接加正则系数乘整个向量，会悄悄惩罚偏置。应分别检查纯权重方向与纯偏置方向，确认二阶正则路径正确。

<a id="sec-8-2"></a>
### 7.14 单一零坐标通过能否验收全图

**问题。** 某偏置梯度恰好为零，数值差分也为零，是否足以验收整个网络？

**解析。** 不足。该坐标可能由于残差抵消、激活饱和或路径对称而退化。应检查所有参数块，选非零残差和不对称输入，加入多个方向及至少一个手算小例子。还要验证参数打包没有遗漏块。通过一个零坐标只支持那一个局部事实，不能外推全部网络，更不能证明标签或目标正确。

<a id="sec-8"></a>
## 8. 综合研究实验与验收路线

本节把前面的检查组合成一个可重复使用的研究流程。重点不是增加断言数量，而是让每条证据对应一种潜在错误。新模型可以更大，算子可以更复杂，但仍然应保留能够手算的小型特例，以及能够在合理资源内运行的独立检查路径。

<a id="sec-8-1"></a>
### 8.1 综合练习：从形状到梯度所有权

**问题。** 先对单层映射 $`Z=XW+b`$ 写出全部伴随，再扩展到本章两层网络，明确每个共享参数的梯度由谁累加。

**逐步解析。** 当输入为四乘三、权重为三乘二、偏置长度二、上游为四乘二时，权重梯度为 $`X^TG`$，输入梯度为 $`GW^T`$，偏置梯度为沿四条样本求和的上游。若上游已含四分之一，不再额外平均。所有样本共同拥有同一个权重梯度累加目标，但各样本输入梯度保留各自位置。

扩展到两层后，先由损失模块产生输出上游，再将它通过第二层伴随拉回隐藏激活，乘激活斜率后传到第一层。每一层只负责本层参数共享的归约，不应重复损失模块的平均。权重正则由目标模块规定，可在最终权重梯度处加入；若多个路径共享同一个参数，所有路径的梯度应先相加，再对该参数执行一次更新。

**验收。** 用两条完全相同的样本验证平均目标对样本复制不变；用不同输出维数验证归约定义；用非零偏置与不等维数检验广播与转置；用隐藏单元排列检验参数块对应；用独立上游检验网络 JVP 与 VJP 的伴随关系。每条检查都应写出预期，而不是只盲目运行程序。

<a id="m4-18"></a>
### 8.2 参数空间负曲率的最小手算反例

考虑无激活、无偏置的标量两层网络 $`z=ab`$，目标为 $`L=\frac{(ab-1)^2}{2}`$。梯度为 $`((ab-1)b,(ab-1)a)`$。在原点，梯度为零，损失为二分之一，但 Hessian 为 $`\left(\begin{smallmatrix}0&-1\\-1&0\end{smallmatrix}\right)`$。沿方向 $`(1,1)`$ 有负曲率，沿 $`(1,-1)`$ 有正曲率，所以原点是鞍点。

Gauss–Newton 在该点为零，因为输出雅可比为 $`(b,a)`$，原点雅可比为零。完整 Hessian 的全部信息来自残差乘模型二阶导。这一例子说明：一阶平稳不等于最小值，半正定近似也可能看不到逃离鞍点的方向。它不证明完整 Hessian 在任何任务上都优于近似，因为代价、噪声与稳定性还需要比较。

可以用中心差分直接核对梯度变化：在小正数方向扰动后，两个梯度约为负的小正数，符合 Hessian 作用于该方向。与大网络的实验相比，这个例子具有完全可解释的符号和特征向量，适合用作二阶实现的基础单元测试。

<a id="m4-19"></a>
### 8.3 构建实验记录而不留下生成杂物

梯度检查记录应包含数学目标、自足代码、参数设置、扰动尺度、检查结果与误差解释。读者应能从同一输入重算解析梯度与差分梯度，并判断误差来自舍入、截断还是实现错误。代码块可以独立执行；扩展实验时保持规模足够小，逐次改变激活、归约或参数共享方式，才容易定位偏差首次出现的位置。

记录结果时应区分可重复的结构结论和机器相关的数值。参数数量、目标定义与导数公式不依赖硬件；最后几位误差和运行时间可能受库版本、线性代数后端及线程设置影响。因此正文给出合理容限与结果量级，避免承诺任意环境逐位一致。若更换类型或计算后端，应重新执行检查。

完成本章后，读者应能够独立审查一个小网络：说清每个数组的轴和所有权，推导每条共享路径的贡献，识别前向状态是否固定，解释一阶和二阶检查各自覆盖什么，并在发现不一致时先缩小问题。这样的能力比单纯记住反向代码更能迁移到注意力、归一化与大型模型训练。

<a id="m4-20"></a>
### 8.4 独立伴随实验与故障定位

下面的实验绕开具体损失，只检查网络输出映射。方向传播把参数扰动推到输出，反向传播把任意上游拉回参数。使用两个不依赖标签的算子，一方面能检查前后向的伴随关系，另一方面能与输出有限差分构成三方对照。故障注入则让隐藏层导数项消失，验证当前数据确实能发现这个错误。

```python
import numpy as np
rng = np.random.default_rng(202)
X = rng.normal(size=(4, 2))
W1 = rng.normal(scale=0.7, size=(2, 3))
b1 = rng.normal(scale=0.2, size=3)
W2 = rng.normal(scale=0.5, size=(3, 2))
b2 = rng.normal(scale=0.2, size=2)
parts = (W1, b1, W2, b2)
V1, v1, V2, v2 = directions = tuple(rng.normal(size=p.shape) for p in parts)
U = rng.normal(size=(4, 2))

def output(values):
    w1, c1, w2, c2 = values
    return np.tanh(X@w1+c1)@w2+c2

A = np.tanh(X@W1+b1)
Q = 1-A*A
adot = Q*(X@V1+v1)
zdot = adot@W2+A@V2+v2
D1 = (U@W2.T)*Q
pullback = (X.T@D1, D1.sum(0), A.T@U, U.sum(0))
left = np.sum(U*zdot)
right = sum(np.sum(g*v) for g, v in zip(pullback, directions))
assert np.isclose(left, right, atol=1e-12)
step = 1e-5
plus = tuple(p+step*v for p, v in zip(parts, directions))
minus = tuple(p-step*v for p, v in zip(parts, directions))
finite_output = (output(plus)-output(minus))/(2*step)
assert np.allclose(zdot, finite_output, atol=1e-8, rtol=1e-6)
# Deliberate fault: omit the activation derivative in the first layer.
wrong_d1 = U@W2.T
wrong = (X.T@wrong_d1, wrong_d1.sum(0), A.T@U, U.sum(0))
wrong_right = sum(np.sum(g*v) for g, v in zip(wrong, directions))
assert abs(left-wrong_right) > 1e-3
# A permutation must act on all three hidden-unit-related parameter blocks.
perm = np.array([2, 0, 1])
permuted = (W1[:, perm], b1[perm], W2[perm, :], b2)
assert np.allclose(output(permuted), output(parts), atol=1e-14)
print('adjoint discrepancy', abs(left-right),
      'injected fault discrepancy', abs(left-wrong_right))
```

这个实验中的上游并不是平方损失残差，因此一阶检查即使在某个目标上出现特殊抵消，也不能轻易掩盖算子错误。故意删除激活导数后，差异应显著大于正常浮点误差；如果换数据后故障差异趋近零，需要检查新数据是否让激活斜率接近一，或方向与错误恰好正交。

隐藏排列测试还体现了梯度所有权：同一个隐藏单元涉及第一层的一列、一个偏置和第二层的一行，三者必须同步变换。只排列其中一块会真正改变函数。模型检查中的参数对应不仅是名称管理，也是计算图中路径的一致性。

<a id="m4-21"></a>
### 8.5 从有限差分到泰勒余项检验

除直接比较导数外，还可以检查泰勒展开剩余量。固定方向 $`v`$，记 $`E_1(t)=\vert L(\theta+tv)-L(\theta)-t g^Tv\vert `$。在足够光滑且步长尚未进入舍入主导区域时，一阶展开余项应通常按步长平方缩小。若加入二阶项 $`\frac{t^2v^THv}{2}`$，相应余项在更强光滑条件下可以按步长三次量级缩小。

这种检验同时涉及目标、梯度和曲率，适合观察阶数是否符合理论。它也有边界：如果选定方向的二阶项恰好为零，一阶余项可能下降得更快；如果目标含不可微分支，阶数规律可能失效；如果步长太小，目标值相消会让剩余量停滞。报告应展示一段合理区间，而不是只展示最小的一个误差值。

对于两层网络，可以选择纯输出偏置方向，此时输出对该方向线性，平方损失沿该方向严格二次，二阶展开在实数数学中完全精确。再选择同时改变两层权重的方向，通常会出现真正的更高阶余项。两种方向形成对照，能够区分检查器自身的误差与模型非线性造成的变化。

还可以比较正方向与负方向的一阶余项。如果只在一个方向跨越激活折点，误差会不对称；如果两边都在同一个光滑区域，中心差分通常具有更好的截断性质。这些观测应服务于定位函数结构，而不是把所有偏离理想阶数的现象都归咎于浮点数。

<a id="m4-22"></a>
### 8.6 参数缩放、坐标与优化几何

参数打包给出一套欧氏坐标，但不同参数块可能有不同单位和尺度。将某个参数改写为一个常数倍的新坐标，预测函数可以保持相同，梯度数值和 Hessian 特征值却会改变。因此报告梯度范数或曲率时，必须说明参数化，不能把它们当作与坐标无关的模型属性。

对线性坐标变换 $`\theta=B\phi`$，梯度变为 $`B^Tg`$，Hessian 变为 $`B^THB`$。若坐标变换非线性，还会多出与原梯度有关的二阶项。即使两个参数化表达同一组函数，简单梯度下降的更新路径也可能不同，这与归一化改变尺度后训练动态变化的现象相呼应。

本章使用标准展平坐标，是为了让内积、方向归一化和数值步长定义明确。若未来引入分块预条件、自然梯度或约束参数，应相应说明更新方向的度量。检查导数仍然可以在选定坐标中进行，但不能把预条件方向直接拿来与普通欧氏梯度逐坐标比较。

<a id="m4-coordinate-curvature"></a>

### 图解：非线性换坐标为何能改变非驻点曲率的符号

![同一目标用原参数和指数参数表示时，在同一点出现不同二阶导数](images/04-nonlinear-coordinate-curvature.svg)

**只保留雅可比夹乘，会漏掉哪一项？** 令 $`\theta=\psi(\phi)`$，$`J=\frac{\partial\theta}{\partial\phi}`$，目标改写为 $`\widetilde L(\phi)=L(\psi(\phi))`$。采用列梯度约定，先求一阶导数，再对它求导，得到

$$
\nabla_\phi\widetilde L=J^{\mathsf T}\nabla_\theta L,
$$

$$
\nabla_\phi^2\widetilde L
=J^{\mathsf T}(\nabla_\theta^2L)J
+\sum_i\frac{\partial L}{\partial\theta_i}\nabla_\phi^2\psi_i.
$$

第一项来自原梯度随 $`\theta`$ 改变，第二项来自坐标映射的雅可比自身也随 $`\phi`$ 改变。线性换坐标时第二项为零；非线性换坐标不能默认它消失。一维形式与 [Boyd 和 Vandenberghe 的凸优化讲义中复合函数二阶导数公式](https://stanford.edu/~boyd/cvxbook/bv_cvxslides.pdf) 一致，也解释了为什么“凸函数再复合一个凸函数”并不足以保证凸性，仍需检查单调性等条件。

**用一个没有复杂网络的算例把符号算出来。** 取正参数上的目标

$$
L(\theta)=\frac12(\theta-2)^2,\qquad \theta>0.
$$

在原坐标中 $`L'(\theta)=\theta-2`$、$`L''(\theta)=1`$，处处严格凸。改用平滑可逆的指数参数 $`\theta=e^\phi`$，则

$$
\widetilde L'(\phi)
=\theta(\theta-2),\qquad
\widetilde L''(\phi)
=\underbrace{\theta^2}_{J^{\mathsf T}HJ}
+\underbrace{\theta(\theta-2)}_{\text{坐标二阶项}}
=2\theta^2-2\theta.
$$

在 $`\theta=\frac12`$、$`\phi=-\log2`$ 这一对对应位置，目标值同为 $`\frac98=1.125`$，但原梯度为 $`-\frac32`$，新梯度为 $`-\frac34`$；原二阶导数为 1，新二阶导数为

$$
\frac14-\frac34=-\frac12.
$$

如果二阶检查只保留 $`J^{\mathsf T}HJ`$，会错误地得到 $`\frac14`$，连符号也不对。图中两条曲线是同一个目标在两套横轴坐标中的精确函数图，不是在表示两个不同训练任务。指数映射改变了横轴尺度与弯曲程度，使 $`0<\theta<1`$ 区域在新坐标中具有负二阶导数。

**出现负曲率，不等于产生了一个鞍点。** 所选位置两种梯度都非零，它不是驻点。在真正的最优点 $`\theta=2`$、$`\phi=\log2`$，梯度为零，额外项消失，原二阶导数为 1，新二阶导数为 4，仍是严格局部最小值。更一般地，对光滑局部可逆、雅可比可逆的换坐标，在驻点处 Hessian 通过合同变换联系，其正、负、零特征值的个数保持不变，数值大小不必保持。若雅可比奇异，不能再引用这个结论。因而“任何位置曲率符号都不随坐标变化”和“换坐标会凭空制造新的驻点”都是错误概括。

**同样学习率也不会给出同样更新。** 在上述位置用学习率 $`\eta=0.1`$ 做一步普通欧氏梯度下降，原参数直接更新为 $`0.5-0.1(-1.5)=0.65`$。新坐标更新后映回去则是

$$
\theta_{\text{new}}
=\exp\!\left(-\log2+0.075\right)
=\frac12e^{0.075}\approx0.538942.
$$

两者都在当前例子中下降，却不是同一条优化轨迹。对小步长展开，新坐标的欧氏梯度步骤映回原坐标近似为 $`-\eta JJ^{\mathsf T}g`$，已经带有坐标诱导的缩放。做导数检查时，应在同一坐标中比较解析导数和数值扰动；研究曲率或学习率时，还应说明坐标与度量。目标值相同，不意味着梯度范数、Hessian 特征值或固定学习率具有坐标无关的意义。

<a id="m4-23"></a>
### 8.7 检查覆盖矩阵与最小充分证据

可以用一份概念上的覆盖矩阵组织实验。参数打包往返检查覆盖坐标身份；多输出与不等维数覆盖轴语义；非零正则覆盖目标附加路径；逐坐标差分覆盖全部小模型参数；伴随关系覆盖网络线性化；步长扫描覆盖数值误差；故障注入覆盖测试区分力；独立自动微分覆盖另一条实现路径。每种证据都应能回答具体问题。

覆盖矩阵并不是要求无穷增加测试。低风险的格式改动不需要重复所有数值实验，而修改了激活、归约、共享参数或二阶公式，就应重跑受影响路径。检查次数应由变化的数学范围决定，既避免不足，也避免无理由地反复执行同一套断言。

若某个新算子难以全面检查，可以先构造退化成已知算子的极限。例如把激活替换为恒等，把第二层固定为单位映射，或把某些参数方向设为零。再逐步恢复复杂性，定位是哪一步引入差异。这种从已知特例向一般情况递进的方法，通常比直接检查大型全图更高效。

<a id="m4-24"></a>
### 8.8 理解本章实验能够支持的结论

本章给出的证据支持以下范围内的结论：在指定目标、类型、参数点和固定状态下，手工一阶与二阶实现和独立数值证据一致；同步更新能够在给定小任务上降低所写目标；算子结构满足相应伴随与对称性质。它们没有自动证明所有初始化都能收敛，也没有证明所写目标最适合真实应用。

把结论范围说清楚并不会削弱实验，反而让后续研究知道下一步应检验什么。若关心收敛，需要讨论光滑性、步长和随机梯度条件；若关心泛化，需要独立数据与评估设计；若关心工程性能，需要资源与并行实验。求导正确是这些工作的基础，但不同问题需要自己的证据。

将学习材料读到这一层，应当能够主动设计新的实验，而不只是运行已有代码。可以改变归约，预测误差会如何按固定比例变化；可以删除一个二阶项，预测哪类方向会首先失败；可以冻结随机状态，分离算法误差与采样噪声。能够在运行前写下可检验的预言，说明已经开始把推导作为研究方法使用。

<a id="m4-25"></a>
### 8.9 从小网络迁移到更大计算图

把方法迁移到注意力或残差网络时，首先寻找可分离的局部算子。线性层沿用矩阵伴随，Softmax 沿用归一化雅可比，归一化层必须保留统计量反馈，残差连接则让上游沿多条路径累加。不要试图直接记忆整个大图的最终梯度；通过局部契约和链式组合，才能在结构扩展后继续解释结果。

共享权重尤其需要明确参数身份。如果同一个权重在多个位置使用，每条路径的贡献必须累加到同一个参数，而不是建立多个数值相同但独立更新的副本。反过来，两个数值相同的独立参数也不能因为内容相等就合并梯度。参数身份属于模型定义，数值内容只是当前状态。可用只激活一条路径的干预，检查共享累加是否符合预期。

大图的检查规模可以缩小，但不能随意改变被验证机制。例如缩短序列和减小宽度通常保留注意力的归一化依赖；把序列缩成单位置则会让 Softmax 恒为一，失去检验类别耦合的能力。类似地，只有一个样本可能使某些归一化退化，只有一个输出可能掩盖归约差异。小型特例应足够小以便解释，也要足够丰富以覆盖关键路径。

最终可以为每个新模块保留一个自足例子，说明目标、轴、参数身份和至少一种故障的可观测表现。当所有局部算子通过，再检查组合图的全局方向和训练行为。这样积累的是可迁移的推理能力与证据，而不只是越来越长的代码。遇到陌生结构时，也能从同样的基本问题开始重新建立理解。

复核完成后，还应能够用自己的语言解释每个断言为何成立，以及删去哪个导数项会使它失败。把这种解释写在实验旁边，才能让可运行代码真正成为可学习的资料。
