## 1. 从单个残差到具有明确轴语义的目标

本章把样本按行排列，输入 $`X\in\mathbb R^{n\times d}`$，权重 $`W\in\mathbb R^{d\times k}`$，偏置 $`b\in\mathbb R^k`$，预测 $`Z=XW+\mathbf1b^T`$，标签 $`T\in\mathbb R^{n\times k}`$。第一个轴表示样本，第二个轴表示输出分量。程序数组能相乘，只说明形状允许运算，并不说明这些轴代表的统计对象正确。

对单输出线性回归，定义 $`L=\frac{\Vert Xw-y\Vert ^2}{(2n)}`$，残差 $`r=Xw-y`$，得到梯度 $`\frac{X^Tr}{n}`$。这里二分之一属于平方误差的标度，$`n`$ 属于样本平均。如果使用不带二分之一的均方误差，梯度多出二；如果使用误差总和，梯度再多出样本数。任何求导公式都必须附带目标定义，否则一个看似很熟悉的表达式仍可能差固定倍数。

多输出时至少有两种常见目标：每样本输出平方和再对样本平均 $`L_1=\frac{\Vert Z-T\Vert _F^2}{(2n)}`$，以及对所有元素平均 $`L_2=\frac{\Vert Z-T\Vert _F^2}{(2nk)}`$。前者每增加一个同等尺度的输出任务，通常会增加总目标；后者相当于在现有输出任务之间分摊权重。它们不只是排版差异，正则系数和学习率不调整时，训练问题也不同。

因此写任何批量目标时，先给每个轴命名，再写求和范围，最后才使用范数或`.mean()`。例如“对样本平均”不能直接翻译为“对数组所有元素平均”，因为输出轴可能保留多个任务、多个类别或多个时间位置。等到反向传播再想补一个分母，通常已经混淆了目标归约和局部导数。

<a id="sec-1-1"></a>

### 1.1 一条样本同时检查三个输入槽

取单条行样本 $`X=(1,2)`$，权重列 $`W=(3,4)^T`$，偏置 $`b=1`$，则预测为十二。对 $`L=\frac{(Z-10)^2}{2}`$，上游导数为二，故权重梯度为 $`(2,4)^T`$，输入梯度为 $`(6,8)`$，偏置梯度为二。权重梯度乘上输入，输入梯度乘上权重，偏置梯度沿常数通路原样接收上游量。

这个例子也说明“训练参数”与“可求导输入”不是同一概念。实际优化器可能只更新权重和偏置，但对输入的导数依然是定义良好的对象，可用于敏感性分析、可微预处理或上游网络。若输入由另一个参数化模块产生，忽略输入梯度就会人为切断总目标的一条依赖路径。

<a id="mc2-output-scaling"></a>

### 1.2 用同一残差比较不同归约

令残差矩阵为 $`R=\begin{pmatrix}1&2\\3&4\end{pmatrix}`$。平方和为三十，按样本平均的半平方损失为 $`\frac{30}{4}=7.5`$，按全部元素平均的半平方损失为 $`\frac{30}{8}=3.75`$。相应上游梯度分别为 $`\frac{R}{2}`$ 和 $`\frac{R}{4}`$。偏置反向仍然执行列求和，所以两种目标分别给出 $`(2,3)`$ 和 $`(1,1.5)`$，不会因为名字都含“平均”就相同。

若两个输出具有不同单位或业务重要性，可显式引入输出权重 $`c_j`$，而不是盲目平均。目标 $`\sum_i\sum_j\frac{c_jR_{ij}^2}{(2n)}`$ 的上游梯度为 $`\frac{R_{ij}c_j}{n}`$。权重的选择属于模型评价定义，不是求导规则的一部分；导数只忠实反映已经写下的目标，不能替我们决定哪个输出应当更重要。

<a id="sec-2"></a>

## 2. 全连接层的三个梯度来自一个微分式

已知上游矩阵 $`G=\nabla_ZL`$，定义是 $`dL=\operatorname{tr}(G^TdZ)`$。仿射层的微分为 $`dZ=(dX)W+X(dW)+\mathbf1(db)^T`$。将三项分别代入并整理内积，得到

$$
\begin{aligned}
\nabla_XL &=GW^T,\\[6pt]
\nabla_WL &=X^TG,\\[6pt]
\nabla_bL &=G^T\mathbf1.
\end{aligned}
$$

这些公式接收任何合法的上游梯度，不仅适用于平方误差。上游可以来自分类目标、多个损失分支、序列任务或下游网络。局部反向规则只处理仿射层的依赖关系；损失分母已经体现在 $`G`$ 里，就不应该在这里重复除以批大小。

从元素角度看，$`Z_{ij}=\sum_aX_{ia}W_{aj}+b_j`$。因此 $`\frac{\partial L}{\partial W_{aj}}=\sum_iX_{ia}G_{ij}`$，参数在样本之间共享导致样本轴被求和；输入元素只属于自己的样本行，所以 $`\frac{\partial L}{\partial X_{ia}}=\sum_jG_{ij}W_{aj}`$，归约的是输出轴。这两种求和源于不同依赖，不能用“批量梯度都要平均”一言概括。

偏置向量在每条样本中重复使用，因此 $`\frac{\partial L}{\partial b_j}=\sum_iG_{ij}`$。若代码内部把偏置保存成形状 $`(1,k)`$，返回梯度也应恢复这一形状。数值相同的 $`(k,)`$ 与 $`(1,k)`$ 不一定有相同的广播行为，接口中应明确使用哪种表示，避免下一层或优化器处理时产生隐含扩维。

<a id="sec-2-1"></a>

### 2.1 两条样本与两个输出的完整手算

取 $`X=\begin{pmatrix}1&0\\0&2\end{pmatrix}`$，$`W=\begin{pmatrix}1&2\\-1&1\end{pmatrix}`$，$`b=(1,-1)^T`$，标签 $`T=\begin{pmatrix}1&0\\0&2\end{pmatrix}`$。前向输出为 $`Z=\begin{pmatrix}2&1\\-1&1\end{pmatrix}`$，残差为 $`R=\begin{pmatrix}1&1\\-1&-1\end{pmatrix}`$。使用每样本平均半平方损失，目标值为一，上游为 $`G=\frac{R}{2}`$。

权重梯度是 $`\begin{pmatrix}\frac{1}{2}&\frac{1}{2}\\-1&-1\end{pmatrix}`$，偏置梯度恰为零，输入梯度是 $`\begin{pmatrix}\frac{3}{2}&0\\-\frac{3}{2}&0\end{pmatrix}`$。偏置梯度为零不是说每个样本没有偏置信号，而是两条样本的贡献正好相消。若只检查最终偏置梯度，可能看不出某一条路径错误；检查每样本贡献能提供更细的定位信息。

沿权重方向 $`H_W=I`$、偏置方向 $`h_b=(1,0)^T`$ 同时变化时，一阶方向导数为梯度与各方向内积之和，即 $`\frac{1}{2}-1+0=-\frac{1}{2}`$。可直接计算输出扰动 $`XH_W+\mathbf1h_b^T`$ 再与 $`G`$ 配对，得到同一结果。两种计算组织不同，却验证同一个联合扰动。

<a id="deep-dive-2"></a>

### 2.2 把反向解释为仿射节点的伴随

固定当前 $`X,W`$，仿射节点的一阶映射把三元扰动 $`(H_X,H_W,h_b)`$ 送到 $`H_XW+XH_W+\mathbf1h_b^T`$。在三个输入空间使用内积之和，这个线性映射的伴随把 $`G`$ 送到 $`(GW^T,X^TG,G^T\mathbf1)`$。这样三个公式作为一个整体出现，转置位置和求和轴都由配对关系唯一确定。

这个视角有助于手写高阶或多输入算子。先实现方向传播，再实现反向伴随，检查两者内积一致；然后把方向传播与真实前向扰动对照。若只检查某个梯度的形状，会遗漏方阵情况下的转置错误，也会遗漏多输入贡献被错误覆盖的问题。伴随测试与真实函数检查结合，才能分别约束数学一致性和程序语义。

<a id="mc2-batch-jacobian"></a>

## 3. 每样本梯度与批量梯度不是同一数组

若目标是 $`L=\sum_i\frac{\ell_i(\theta)}{n}`$，且每个 $`\ell_i`$ 真正只依赖本样本数据和共享参数，那么每样本参数梯度 $`g_i=\nabla_\theta\ell_i`$ 满足 $`\nabla L=\sum_i\frac{g_i}{n}`$。这里每样本梯度保留了额外的样本轴，存储规模约为样本数乘参数数；普通反向传播通常只累加最终和，不会自动保存所有 $`g_i`$。

对仿射层，单样本参数梯度是输入与该样本上游向量的外积。把这些外积相加可以用一次矩阵乘法实现，因此训练代码无需构造形状为 $`(n,d,k)`$ 的巨大中间数组。若研究梯度方差、影响函数、逐样本裁剪或隐私机制，才可能需要保留或间接计算这些对象。选择所需对象比盲目构造完整雅可比更重要。

但当样本之间通过批均值、配对损失或其他操作耦合时，不能把总损失武断地解释为若干独立单样本函数。例如 $`L=\frac12(\sum_i z_i)^2`$ 的输出梯度每项都等于 $`\sum_i z_i`$，不是各自的 $`z_i`$。即使代码表面上保留了一个样本轴，依赖也已经跨样本连接。是否可分必须由计算图判断，而不是由张量第一轴的名字判断。

线性层本身对输入的雅可比在样本维度是块对角的，但对共享权重的雅可比不是互不相关的参数块。前者说明一条样本输入扰动只影响对应输出行，后者说明所有输出行都依赖同一份权重。混淆这两种依赖，会使人错误地认为“批内独立”就能给每条样本维护不同的同名参数而不合并梯度。

<a id="sec-3"></a>

## 4. 有限差分检查应针对联合变量和固定目标

本章不会重复完整的数值求导误差理论，而把检查重点放在张量规则上。选取输入、权重、偏置的方向，计算解析方向导数 $`\langle G_X,H_X\rangle+\langle G_W,H_W\rangle+g_b^Th_b`$，再与同一个固定损失沿联合方向的中心差分比较。一次检查即可覆盖多个输入槽，但若发现错误，应再逐槽定位。

方向检查通过只约束被测方向，错误可能位于与该方向正交的子空间。实践中可使用几个独立方向，并对怀疑的局部参数做坐标检查。对于偏置这种维度很小的参数，逐坐标检查成本低；对于巨大权重矩阵，方向抽查更经济。应根据参数结构安排验证预算，而不是给所有对象采用完全一样的检查策略。

检查时目标分母、样本权重、掩码和随机状态都必须与解析公式相同。若重新抽样 dropout 或数据增强，两次函数值对应不同随机函数，差商会混入随机变化。若想验证随机目标期望的梯度，通常先对固定随机样本的路径导数做检查，再单独研究交换期望与求导所需条件，不要把两个任务混在同一个差商里。

不可微激活点也需单独处理。例如 ReLU 在零点没有普通导数，框架所选局部规则未必等于中心差分。测试可以先避开此类点验证一般位置，再用明确的单侧或广义导数标准研究边界；不能通过把差分容差随意放大，掩盖目标本身不满足普通梯度假设的问题。

<a id="sec-4"></a>

## 5. 逐元素运算、广播与逆向求和

逐元素激活 $`H=\phi(Z)`$ 的微分为 $`dH=\phi'(Z)\odot dZ`$，因此反向为 $`G_Z=G_H\odot\phi'(Z)`$。这要求输出位置只依赖相同位置的输入；归一化、矩阵乘法和 softmax 都不是一般的逐元素运算，不能把它们的反向误写成同形导数数组的逐元素乘法。下章会专门推导有耦合的归一化节点。

广播的前向是一种复制型线性映射。设标量 $`a`$ 被复制为向量 $`z_i=a`$，方向变化每项都是 $`da`$，于是 $`dL=(\sum_iG_i)da`$，反向是求和。更一般地，输入某维长度为一而输出扩展到多项，反向沿该维收集所有复制路径；若输入根本没有这个前导维，也要先归约多出的维度，再恢复原始形状。

对于乘法 $`Z=A\odot B`$，先按输出形状计算临时梯度 $`G_Z\odot B`$ 和 $`G_Z\odot A`$，再分别把它们沿各自被广播的轴求和。两个输入的归约轴可能不同。例如 $`A`$ 形状为 $`(n,1)`$，$`B`$ 形状为 $`(1,k)`$，前者沿列求和，后者沿行求和。使用同一个`.sum(axis=...)`处理两边通常是错的。

广播只表示依赖复制，不表示目标平均。反向局部规则总是按路径相加；如果目标需要平均，平均因子应来自相应归约节点。把“复制的反向是平均”作为记忆口诀，会在任何非平均目标上失败，也会在已经平均的上游信号上重复缩小梯度。

<a id="mc2-shape-contract"></a>

### 5.1 能运行但求错目标的标签广播

设预测形状为 $`(n,1)`$，标签却保存为 $`(n,)`$。两者相减时，广播可能生成 $`(n,n)`$ 的矩阵，其中第 $`i,j`$ 项是第 $`i`$ 个预测减第 $`j`$ 个标签，而不是预期的一一配对。对这个矩阵求平均损失，程序仍然能得到标量和同形参数梯度，但优化的是所有预测与所有标签交叉比较的目标。

以 $`n=2`$、预测 $`(0,2)^T`$、标签 $`(0,2)`$ 为例，正确逐样本残差为零，错误广播残差为 $`\begin{pmatrix}0&-2\\2&0\end{pmatrix}`$。错误目标非零且梯度会推动两个预测向标签总体均值靠近。这类问题不会被“梯度与参数同形”发现，因为自动微分忠实求出了错误前向的导数。

接口层应对关键输入输出执行形状与轴语义断言，尤其检查标签是否与预测完全同形、掩码是否仅沿允许的轴广播。并非所有广播都应禁止，例如同一输出权重跨样本复用就合理；关键是明确允许哪些复制，而不是依赖库根据尾部维度自动猜测意图。

<a id="sec-6-1"></a>

### 5.2 一个可复用的广播反向规则

设目标输入原形状为 $`s`$，临时梯度形状为 $`t`$。先在 $`s`$ 左侧补一，使两者维数相同；对于补出来的维度，以及原来为一而输出不是一的维度，把临时梯度求和并保留维度；最后 reshape 回原形状。这个操作通常叫“求和到原形状”，它是广播复制线性映射的伴随。

如果某个输出维度长度为零，复制和求和仍有形式规则，但损失是否定义需要另行判断。空和可以是零，空集合的平均却涉及零分母。不能因为广播节点本身可处理空数组，就默认整个平均损失有合法值。实际接口应把空批次、全掩码和无有效标签分开制定契约。

<a id="mc2-index"></a>

## 6. 索引、切片与重复使用的反向

固定索引的 gather 操作把输入若干位置取到输出。若输出 $`y_j=x_{i_j}`$，微分为 $`dy_j=dx_{i_j}`$，反向满足 $`g_{x,r}=\sum_{j:i_j=r}g_{y,j}`$。索引没有重复时就是把上游散射回原位置；索引重复时必须相加，而不能覆盖。没有被读取的位置梯度为零，前提是它们没有经过其他依赖路径影响损失。

例取 $`x=(10,20,30)`$，索引为 $`(0,0,2)`$，上游为 $`(1,4,-2)`$。输入梯度应为 $`(5,0,-2)`$。如果写成普通的重复索引赋值或某些带缓冲的高级索引加法，两个零号位置的更新可能没有按预期逐次累加。NumPy 中可使用`np.add.at`明确表达不缓冲的重复索引累加；其性能与替代方案需要根据实际模式另行比较。

反向对输入数值可导，并不意味着对离散索引也可导。若索引由排序、取整或最近邻选择产生，固定索引路径的梯度通常只描述分支内变化，不能描述索引切换的跳跃。需要优化索引选择时，可能使用平滑松弛、连续插值或特定估计器，这些方法各有不同目标和偏差，不能直接把 gather 的输入梯度解释成索引梯度。

切片、转置和 reshape 也是固定的线性重排或选取操作。可逆重排的反向是逆重排，切片反向是在原位置散射加，多个重叠切片共享原输入时再合并贡献。它们即使在内存层面表现为视图，也不改变数学依赖；反过来，复制成新存储也不必然表示停止梯度。存储别名与计算图依赖需要分别理解。

## 7. 参数共享、残差路径与正则项

设同一个 $`W`$ 同时出现在两个分支，最终损失为 $`L=\ell_1(W)+\ell_2(W)`$，则微分中的同一扰动 $`dW`$ 配对两项，梯度为 $`G_1+G_2`$。这条规则覆盖共享编码器、循环网络和卷积核。判断是否共享，应看它们是否代表同一个待优化变量；两个初始值恰好相同但独立维护的数组并不会自动成为同一个参数。

残差连接 $`Y=X+F(X,W)`$ 使输入同时通过恒等路径与变换路径，因此 $`G_X=G_Y+D_XF^*[G_Y]`$，参数梯度来自变换路径。若只反传经过 $`F`$ 的部分，就漏掉恒等贡献。对于更一般的有向无环图，反向执行时只有在一个节点所有下游使用位置的贡献都收集完毕之后，才能把完整上游量继续传给其输入。

若目标加上 $`\frac{\lambda\Vert W\Vert _F^2}{2}`$，正则梯度为 $`\lambda W`$，由目标中出现几次决定，而不是由前向权重被使用几次决定。循环网络使用同一权重十次，并不意味着独立的一个正则项应该加十遍。相反，如果目标明确包含每个时间位置各一个正则惩罚，那么总系数确实改变，但这是另一个目标。

还要区分损失正则与优化器的解耦权重衰减。在普通无动量梯度下降的某些设定下，两者可产生类似更新；在自适应预条件或动量处理下，通常不能不加条件地等同。本章只讨论目标函数的真实导数，不把优化器额外的参数缩减操作塞进反向公式。写研究代码时把二者分开配置，能更清楚地解释超参数含义。

<a id="sec-6"></a>

### 7.1 共享权重出现两次的非线性推导

令行输入 $`X\in\mathbb R^{n\times d}`$，方阵共享参数 $`W\in\mathbb R^{d\times d}`$，前向 $`H=XW`$、$`Z=HW`$。已知 $`G_Z`$，第二个使用位置贡献为 $`H^TG_Z`$，传回隐藏层的信号为 $`G_ZW^T`$，第一个使用位置贡献为 $`X^T(G_ZW^T)`$，故总梯度为两项之和。

也可直接写 $`dZ=X(dW)W+XW(dW)`$，代入标量内积得到相同结果。若把两个权重临时拆成 $`W_1,W_2`$ 再求导，最后必须在约束 $`W_1=W_2=W`$ 下合并两个输入槽。只取某一个槽，不是共享模型的导数。这个例子保留矩阵乘法不交换的特点，能够暴露“共享平方总是二倍某一项”的错误简化。

<a id="mc2-conv-rnn"></a>

### 7.2 卷积与循环其实沿不同位置重复同一规则

一维有效卷积可写成 $`z_t=\sum_a w_ax_{t+a}`$。对权重 $`w_a`$，每个输出位置都贡献 $`g_tx_{t+a}`$，所以梯度沿位置求和；对输入 $`x_r`$，所有覆盖该位置的窗口贡献也要求和。是否翻转卷积核取决于前向采用数学卷积还是交叉相关约定，必须从索引式推导，不能只背某个框架的名字。

循环网络的不同在于共享权重还通过状态间接影响后续时间步。反向不仅汇总每次局部使用的外积，还需把未来状态信号经递归链传回。截断反向传播故意切断某些跨时间路径，一般产生不同于完整序列目标的梯度。它可能是计算上的合理近似，但报告时应说明截断范围，不能声称只是完全等价地节省内存。

## 8. 加权、掩码与分母的导数

令固定非负系数 $`a_{ij}`$ 同时表示有效掩码和权重，设 $`S=\sum_{ij}a_{ij}>0`$。对目标 $`L=\sum_{ij}\frac{a_{ij}R_{ij}^2}{(2S)}`$，上游为 $`G_{ij}=\frac{a_{ij}R_{ij}}{S}`$。若权重按样本定义为 $`a_i`$，而每个样本损失已经对输出平均，则应明确是否再除以输出数，不能把两个不同层级的平均合并而不说明。

在序列任务中，“按有效位置平均”与“先每序列平均，再按序列平均”通常不同。第一种使较长序列贡献更多有效位置，第二种让每条序列在最终目标中权重相同。两者都可能合理，但对应不同数据分布的风险定义。掩码不仅决定哪些项归零，还通过分母影响剩余项的相对尺度。

若 $`S=0`$，这个比值目标没有定义。可选择跳过该批次、返回带明确契约的零损失并不更新、或采取任务特定处理，但不应悄悄用一个任意小常数替代分母后宣称仍是原目标。如果使用平滑分母，应该把它写进数学定义，并分析它如何改变小有效样本数时的尺度。

数值实现还需注意无效位置中的非有限值。先算一个 NaN 损失再乘零，结果仍可能是 NaN；屏蔽值必须在不产生非法运算的阶段进行，或先提取有效位置再计算。某些框架的分支选择也可能在中间生成无效结果，是否污染梯度取决于算子定义。最可靠的原则是让被执行的可导路径本身保持合法，而不只希望最终乘零消除问题。

<a id="mc2-variableweights"></a>

### 8.1 当权重依赖参数，分母也必须求导

设 $`L(\theta)=\frac{N(\theta)}{S(\theta)}`$，其中 $`N=\sum_i a_i(\theta)\ell_i(\theta)`$、$`S=\sum_i a_i(\theta)>0`$。商法则给出

$$\nabla L=\frac1S\sum_i a_i\nabla\ell_i+
\frac1S\sum_i(\ell_i-L)\nabla a_i.$$

第二项体现权重变化及分母归一化的共同作用。若把权重冻结，只保留第一项，那是一个条件目标的导数或特意选择的代理更新，不能称为原始比值函数的完整梯度。可学习置信度、门控和样本重加权模型中，这个区别尤其重要。

手算例取 $`a_1=e^\theta,a_2=1`$、$`\ell_1=0,\ell_2=1`$，则目标为 $`\frac{1}{(1+e^\theta)}`$。在零点梯度为负四分之一。如果冻结权重，只看两个常数损失的梯度，则得到零。两者都可能出现在程序中，但表示的依赖图完全不同，应通过实验设计明确哪一个才符合研究目标。

## 9. 梯度累积怎样保持同一个大批目标

设一个大批被拆成若干微批，第 $`r`$ 块的加权损失分子为 $`N_r`$，固定有效权重和为 $`S_r`$。完整目标是 $`\frac{\sum_rN_r}{\sum_rS_r}`$。若每块返回平均损失 $`L_r=\frac{N_r}{S_r}`$，正确组合为 $`\sum_r(\frac{S_r}{S})L_r`$，其中 $`S=\sum_rS_r`$。简单平均微批均值只有在各块分母相同或某些偶然相消情况下才等价。

例如两块分别有两个和六个有效样本，块均值为二和十。大批平均为 $`\frac{(2\times2+6\times10)}{8}=8`$，简单平均为六。这不只是报告损失的差别，同样的权重会作用在每块梯度上，导致训练方向也不同。最后一个不足大小的微批、变长序列和非均匀掩码尤其容易触发这种错误。

一种稳健实现是在每块计算损失分子，对其梯度累加，最后除以整个大批分母。另一种是在前向已知全局分母后，每块直接使用 $`\frac{N_r}{S}`$。两种都要求整个逻辑大批处理期间参数保持不变；若处理一块就更新参数，后续块在不同点求梯度，已经变成顺序小批优化，不再等于同一点的大批梯度。

正则项在大批目标中只出现一次，可以在累加结束后加一次梯度，或把它按系数和为一的方式分摊到各块。若每块都加入完整正则，然后最后只除数据项的分母，就会把正则强度扩大为块数倍。权重共享和微批切分都是计算组织，不应自动改变目标中的惩罚次数。

<a id="mc2-nonseparable"></a>

### 9.1 大批等价还要求前向依赖可以拆开

即使分母权重完全正确，含有跨样本操作的网络也未必能通过普通微批累积复现整批梯度。训练态批归一化使用当前批的统计量，不同微批会得到不同前向输出和局部导数；批内对比学习的负样本集合也随拆分改变。此时发生变化的是模型前向或损失耦合，而不仅仅是求和顺序。

如果目标依赖全批统计，可设计两阶段计算、缓存足够的中间量或特定的可分解统计方案，但是否等价需要重新推导。冻结统计量有时可让前向变得可分，却也可能改变原训练目标。不能仅凭“我把所有梯度加起来了”就宣布大批等价；必须先确认每个样本项在两种计算组织中确实是同一个函数。

梯度裁剪同样影响等价性。先分别裁剪每块梯度再求和，一般不同于先求完整梯度再裁剪；范数裁剪是非线性操作。逐样本裁剪后求和又是第三种对象，常用于特定机制，但不等于普通大批目标的梯度。需要把目标求导、梯度变换和参数更新作为三个步骤分别定义。

<a id="mc2-distributed"></a>

### 9.2 多设备归约的尺度要从通信契约反推

若多个设备各有不同有效权重和 $`S_r`$，目标仍应使用全局分子与全局分母。通信接口可能对设备梯度求和，也可能求平均；损失本地如何缩放必须与该契约一致。若接口最终对设备数取平均，而本地使用 $`\frac{N_r}{S}`$，还需考虑这个额外平均因子，否则总体梯度会缩小。

一种清晰推导是先写期望得到的全局梯度 $`\sum_r\frac{\nabla N_r}{S}`$，再把实际通信公式代入，求本地损失应乘的系数。这样不用记忆某个框架的口诀，也能适配不同设备数、空分片和有效样本不均匀的情况。本章不假设特定分布式接口，实际使用必须阅读正在运行版本的通信与自动微分契约。

## 10. 批量反向的二阶方向传播

单输出线性回归的梯度为 $`\frac{X^T(Xw-y)}{n}`$，因此沿方向 $`v`$ 的梯度变化为 $`Hv=\frac{X^TXv}{n}`$。先计算输出方向 $`Xv`$，再使用转置乘积传回，不需要构造 $`d\times d`$ 的 Hessian。对于多输出仿射权重，方向 $`V`$ 对应 $`H[V]=\frac{X^TXV}{n}`$，若有输出权重则在输出方向上增加相应收缩。

如果同时包括偏置，应把方向写成 $`(V,v_b)`$，预测方向为 $`XV+\mathbf1v_b^T`$，再按仿射反向规则传回。这自动保留权重与偏置的交叉 Hessian 块。只分别求“权重自己的二阶项”和“偏置自己的二阶项”，会遗漏联合参数方向中的交叉影响，导致 Newton 型更新与真实目标不符。

非线性网络中，可通过对梯度做方向微分计算 Hessian 向量积。这里需要对反向程序再次求导，且保留相应计算依赖；如果把中间梯度转成常量数组或停止梯度，二阶结果可能丢失路径。自动微分的“梯度数值正确”并不自动保证手工定制的反向规则也支持正确的高阶导数。

还有 Hessian 对称性测试：对光滑标量目标，应有 $`u^THv=v^THu`$。这个测试能够发现部分不一致的高阶实现，但同样不能独立证明它等于真实 Hessian。可以再把 $`Hv`$ 与梯度沿 $`v`$ 的中心差分比较，或对小问题构造完整 Hessian 核对。不要用损失的二阶差分替代所有检查，因为它只给某个方向上的标量曲率。

## 11. 一个带分支的双线性图：从局部规则到整体反向

考虑 $`Q=XU`$、$`K=XV`$、$`S=QK^T`$，其中 $`X\in\mathbb R^{n\times d}`$，$`U,V\in\mathbb R^{d\times r}`$，最终标量目标为 $`L=\langle C,S\rangle_F`$。这可以看成相似度矩阵的一部分计算，但本节不加入 softmax，以便把双线性路径和共享输入单独讲清楚。矩阵 $`C`$ 是固定的输出权重。

上游为 $`G_S=C`$。乘法反向给出 $`G_Q=CK`$、$`G_K=C^TQ`$。继续经过两个仿射分支，得到 $`G_U=X^TCK`$、$`G_V=X^TC^TQ`$，而共享输入梯度为 $`G_X=(CK)U^T+(C^TQ)V^T`$。输入同时参与查询和键两条路径，因此即使只优化输入也不能漏掉其中一项。

若进一步绑定参数 $`U=V=W`$，权重梯度为 $`X^T(C+C^T)XW`$。最终 $`S=XWW^TX^T`$ 是对称矩阵，目标只依赖 $`C`$ 的对称部分；反对称部分的配对恒为零。因此公式中出现 $`C+C^T`$ 是结构所要求的结果。这个不变性检查比只看梯度形状更有力，因为两个候选错误项通常都拥有合法形状。

若最终目标改成 $`\frac{\Vert S-T\Vert ^2}{2}`$，上游变为 $`S-T`$，但局部图反向规则不变。再次求二阶导数时，上游也依赖参数，必须连同其变化一起处理；不能把第一次反向中的上游矩阵永久当作常量。这里就能看到真实 Hessian 与固定上游的局部线性化之间的差异。

## 12. 可执行实验：加权掩码仿射层与微批等价

下面代码把掩码和固定权重合并为系数矩阵，明确使用有效权重和作分母。它同时返回输入、权重和偏置梯度，执行联合方向检查，并把大批分子拆成不等大小的三块核对。正则项只在完整梯度中加一次，微批中仅累积数据项，再统一加回正则。

实验的掩码是固定的，不是由参数选择产生；所有有效位置的权重非负且总和为正。代码对标签与预测要求同形，避免错误广播。这里使用小型有限实数输入，真实数据若含非有限值、极端尺度或空有效集合，应按任务契约先处理，而不是指望梯度检查自动解决前向定义问题。

```python
import numpy as np
rng = np.random.default_rng(12)
n, d, k = 7, 3, 2
X = rng.normal(size=(n, d))
W = rng.normal(size=(d, k))
b = rng.normal(size=k)
T = rng.normal(size=(n, k))
a = rng.uniform(0.2, 2.0, size=(n, k))
a[::2, 0] = 0.0
lam = 0.13
S = a.sum()

def objective(x, w, bias):
    r = x@w + bias - T
    assert r.shape == T.shape == a.shape
    return np.sum(a*r*r)/(2*S) + lam*np.sum(w*w)/2

R = X@W + b - T
G = a*R/S
GX, GW, Gb = G@W.T, X.T@G + lam*W, G.sum(axis=0)
HX = rng.normal(size=X.shape)
HW = rng.normal(size=W.shape)
hb = rng.normal(size=b.shape)
eps = 1e-6
numerical = (objective(X+eps*HX, W+eps*HW, b+eps*hb)
             - objective(X-eps*HX, W-eps*HW, b-eps*hb))/(2*eps)
analytic = np.sum(GX*HX) + np.sum(GW*HW) + Gb@hb
np.testing.assert_allclose(numerical, analytic, rtol=2e-6, atol=2e-7)

accW = np.zeros_like(W)
accb = np.zeros_like(b)
for sl in (slice(0, 1), slice(1, 3), slice(3, 7)):
    local_num_grad = a[sl]*(X[sl]@W+b-T[sl])
    accW += X[sl].T@local_num_grad
    accb += local_num_grad.sum(axis=0)
np.testing.assert_allclose(accW/S + lam*W, GW, rtol=1e-12, atol=1e-12)
np.testing.assert_allclose(accb/S, Gb, rtol=1e-12, atol=1e-12)
print('联合方向与不等微批的全局分母检查通过')
```

如果把每块梯度先除以各自的权重和，再无权平均，上述等价断言通常失败。这个失败对应真实目标变化，应修正目标组织，而不是放松容差。由于浮点加法不满足结合律，即使数学等价的累加顺序也未必逐位相同，因此这里用合理误差容限比较，不要求字节完全一致。

## 13. 可执行实验：广播、重复索引与共享参数

本段代码验证两个容易被高层框架掩盖的规则：广播反向沿复制轴求和，重复索引反向沿重复路径相加。随后检查一个共享矩阵在前向中出现两次的梯度。每个断言都针对一个足够小而非退化的例子，能够让读者逐元素查看结果，不依赖训练曲线判断梯度是否正确。

```python
import numpy as np
rng = np.random.default_rng(21)

def sum_to_shape(g, shape):
    shape = tuple(shape)
    padded = (1,)*(g.ndim-len(shape)) + shape
    assert len(padded) == g.ndim
    assert all(s == 1 or s == t for s, t in zip(padded, g.shape))
    axes = tuple(i for i, (s, t) in enumerate(zip(padded, g.shape))
                 if s == 1 and t != 1)
    if axes:
        g = g.sum(axis=axes, keepdims=True)
    return g.reshape(shape)

A = rng.normal(size=(3, 1))
B = rng.normal(size=(1, 4))
G = rng.normal(size=(3, 4))
GA = sum_to_shape(G*B, A.shape)
GB = sum_to_shape(G*A, B.shape)
HA, HB = rng.normal(size=A.shape), rng.normal(size=B.shape)
left = np.sum(G*(HA*B + A*HB))
right = np.sum(GA*HA) + np.sum(GB*HB)
np.testing.assert_allclose(left, right)
idx = np.array([0, 0, 2])
upstream = np.array([1., 4., -2.])
gx = np.zeros(3)
np.add.at(gx, idx, upstream)
np.testing.assert_array_equal(gx, [5., 0., -2.])

X = rng.normal(size=(3, 2))
W = rng.normal(size=(2, 2))
T = rng.normal(size=(3, 2))
H = X@W
R = H@W-T
GW = H.T@R + X.T@(R@W.T)
V = rng.normal(size=W.shape)
f = lambda w: np.sum((X@w@w-T)**2)/2
eps = 1e-6
fd = (f(W+eps*V)-f(W-eps*V))/(2*eps)
np.testing.assert_allclose(fd, np.sum(GW*V), rtol=2e-6, atol=2e-7)
print('广播伴随、重复索引累加与共享权重检查通过')
```

`sum_to_shape`假设临时梯度确实来自合法广播，因此首先检查各维长度兼容。它处理形状恢复，不会替前向判断轴语义是否合理。重复索引示例使用显式累加接口，因为多个上游位置同时对应同一个输入位置；将其改成直接覆盖会丢失贡献，而这些贡献正是链式法则要求保留的路径。

## 14. 可执行实验：联合 Hessian 方向与交叉块

最后验证一个带偏置的加权线性目标。由于模型关于权重和偏置是线性的，Hessian 方向可以直接由预测方向反传，且不依赖标签。代码把这个乘积与梯度的方向差分比较，并检查两个方向之间的对称性。它只构造与参数同形的方向数组，不形成完整 Hessian。

```python
import numpy as np
rng = np.random.default_rng(33)
X = rng.normal(size=(5, 3))
T = rng.normal(size=(5, 2))
a = rng.uniform(0.1, 1.0, size=T.shape)
S = a.sum()
lam = 0.2
W = rng.normal(size=(3, 2))
b = rng.normal(size=2)

def grad(w, bias):
    g = a*(X@w+bias-T)/S
    return X.T@g + lam*w, g.sum(axis=0)

def hv(vw, vb):
    dg = a*(X@vw+vb)/S
    return X.T@dg + lam*vw, dg.sum(axis=0)

def dot(pair1, pair2):
    return sum(np.sum(a*b) for a, b in zip(pair1, pair2))

V = (rng.normal(size=W.shape), rng.normal(size=b.shape))
U = (rng.normal(size=W.shape), rng.normal(size=b.shape))
HV, HU = hv(*V), hv(*U)
eps = 1e-6
gp, gm = grad(W+eps*V[0], b+eps*V[1]), grad(W-eps*V[0], b-eps*V[1])
for exact, plus, minus in zip(HV, gp, gm):
    np.testing.assert_allclose(exact, (plus-minus)/(2*eps), rtol=2e-6, atol=2e-7)
np.testing.assert_allclose(dot(U, HV), dot(V, HU), rtol=1e-12, atol=1e-12)
assert dot(V, HV) >= -1e-12
print('联合 Hessian 乘积、对称性与半正定性检查通过')
```

本例 Hessian 半正定来自加权平方误差与非负岭惩罚，并不是所有批量目标的一般性质。将模型换成共享权重的平方映射后，真实 Hessian 会包含额外残差曲率，可能不再半正定。能够指出一个测试依赖哪些结构，比简单把其结果推广到所有神经网络更有意义。

## 15. 练习与逐步参考答案

<a id="mc2-heading-27"></a>

### 15.1 把损失定义写完整

**问题。** 输入有四条样本、三个输出，残差平方和为二十四。分别计算按样本平均和按元素平均的半平方损失，并说明梯度比例。

**解析。** 按样本平均为 $`\frac{24}{(2\times4)}=3`$，按元素平均为 $`\frac{24}{(2\times4\times3)}=1`$。后者所有参数的数据梯度为前者三分之一，前提是两者使用同一预测与标签。若保持同一个正则系数，整体目标并不只是统一乘三分之一，因为正则项没有同时缩放；因此两种训练的最优解也可能不同。

<a id="mc2-heading-28"></a>

### 15.2 共享偏置的零梯度

**问题。** 两个输出的上游两行为 $`(1,2)`$ 与 $`(-1,-2)`$，偏置梯度是什么？能否据此认为所有样本的偏置依赖都不存在？

**解析。** 沿样本轴相加为零，但两条路径各自非零，只是当前点相消。若丢掉其中一条路径，结果反而不再为零。梯度是局部加权变化的总和，零值既可能来自结构无依赖，也可能来自数据或上游信号的相消。区分这些原因需要查看图和各项贡献，不能只看最终数组。

<a id="mc2-heading-29"></a>

### 15.3 广播乘法两边求和轴

**问题。** 设 $`A=(1,2)^T`$ 为 $`(2,1)`$，$`B=(3,4,5)`$ 为 $`(1,3)`$，输出上游为全一矩阵。求两个输入梯度。

**解析。** 对 $`A`$，每行接收 $`3+4+5=12`$，故梯度为 $`(12,12)^T`$；对 $`B`$，每列接收 $`1+2=3`$，故梯度为 $`(3,3,3)`$。两个归约轴不同，且都不是平均。如果目标是输出均值，上游应先为全一除以六，然后局部规则仍然求和；把平均写在两个输入反向里会造成尺度混乱。

<a id="mc2-heading-30"></a>

### 15.4 重复索引外加一条直接路径

**问题。** $`y=(x_0,x_0,x_2)`$，$`L=y_0+4y_1-2y_2+3x_0`$。求输入梯度，并说明如何按图组织。

**解析。** gather 分支贡献为 $`(5,0,-2)`$，直接路径贡献为 $`(3,0,0)`$，总梯度为 $`(8,0,-2)`$。先在每个局部节点执行相应伴随，再在共享输入汇合点相加。如果先把直接路径写入梯度数组，随后用 gather 结果整体覆盖，就会漏掉三；这种错误与重复索引内部覆盖属于同一种路径丢失问题。

<a id="mc2-heading-31"></a>

### 15.5 不等大小微批

**问题。** 两个微批分别有三个和一个有效元素，未归一化梯度和分别为六与负二。完整平均梯度、微批平均后无权平均各是多少？

**解析。** 完整结果为 $`\frac{(6-2)}{4}=1`$。各自平均后再无权平均为 $`\frac{(\frac{6}{3}-\frac{2}{1})}{2}=0`$，连方向信息都消失。正确做法是分子相加后除四，或把块均值按四分之三和四分之一加权。若分母是权重和而不是元素数，同样规则仍成立，但必须使用真实的各块权重和。

<a id="mc2-heading-32"></a>

### 15.6 参数依赖权重

**问题。** 两个常数损失为一和三，权重为 $`a_1=e^\theta,a_2=1`$。求归一化加权目标在零点的导数，并与冻结权重结果比较。

**解析。** 目标为 $`\frac{(e^\theta+3)}{(e^\theta+1)}`$，商法则得导数 $`-\frac{2e^\theta}{(e^\theta+1)^2}`$，零点为负二分之一。冻结权重后两个损失均为常数，导数为零。提高第一项权重会让整体更接近较小损失一，所以负号也符合直觉；遗漏分母导数会得到错误的正方向或其他尺度。

<a id="mc2-heading-33"></a>

### 15.7 正则项重复计数

**问题。** 目标为数据均值加 $`\frac{\lambda\Vert W\Vert ^2}{2}`$，拆成四个等大小微批。若每块平均数据损失加完整正则，然后四块梯度相加，发生什么变化？

**解析。** 数据梯度也被放大四倍，正则梯度同样为四倍；如果随后整体除四，则恢复原目标。如果只把数据项按四分之一缩放，却让每块保留完整正则，最后会得到数据梯度加四倍正则。不能仅凭“正则加了四次”就判断最终结果，必须追踪所有系数和最后是否整体缩放。

<a id="mc2-heading-34"></a>

### 15.8 残差分支

**问题。** 标量模型 $`y=x+w x`$，损失 $`L=\frac{y^2}{2}`$。求输入与参数梯度，并指出漏掉恒等路径的结果。

**解析。** 上游为 $`y`$，输入导数为 $`y(1+w)`$，参数导数为 $`yx`$。如果只经变换分支反向，输入梯度误写为 $`yw`$，少了 $`y`$。取 $`x=2,w=0`$ 时，正确输入梯度为二，漏路径结果为零，说明即使变换分支权重为零，恒等路径仍然保持依赖，不能被当作可忽略的装饰连接。

<a id="mc2-heading-35"></a>

### 15.9 共享平方的标量特例

**问题。** $`z=xw^2`$，损失 $`L=\frac{(z-t)^2}{2}`$，求 $`w`$ 梯度。把两个权重拆开后怎样恢复？

**解析。** 梯度为 $`2xw(z-t)`$。若写 $`z=xw_1w_2`$，独立梯度分别为 $`xw_2(z-t)`$ 与 $`xw_1(z-t)`$，绑定后相加恢复结果。矩阵模型中两条贡献一般不能写成相同项的两倍，因为乘法顺序不同；标量情形的可交换性不能直接推广到矩阵共享网络。

<a id="mc2-heading-36"></a>

### 15.10 交叉 Hessian 块

**问题。** 单样本标量模型 $`z=xw+b`$，半平方损失。写出联合参数 $`(w,b)`$ 的 Hessian，并说明只保留对角块遗漏什么。

**解析。** Hessian 为 $`\begin{pmatrix}x^2&x\\x&1\end{pmatrix}`$。沿方向 $`(v_w,v_b)`$ 的曲率为 $`(xv_w+v_b)^2`$，包含交叉项 $`2xv_wv_b`$。只保留对角块得到 $`x^2v_w^2+v_b^2`$，改变了联合二次模型。即使每个单变量二阶导数都正确，完整二阶方向仍可能错误，这说明联合扰动检查的必要性。

<a id="mc2-heading-37"></a>

### 15.11 双线性图的反对称上游

**问题。** 绑定模型 $`S=XWW^TX^T`$，若固定上游 $`C`$ 反对称，目标 $`\langle C,S\rangle`$ 及权重梯度是什么？

**解析。** $`S`$ 对称，与反对称矩阵的 Frobenius 内积为零，所以目标恒为零，梯度也为零。公式 $`X^T(C+C^T)XW`$ 同样给出零。如果某个实现只保留查询或键一条路径，一般得到非零结果。这个例子利用结构恒等性验证共享路径，比只在普通随机上游上看差分更容易解释错误来源。

<a id="mc2-heading-38"></a>

### 15.12 按位置平均与按序列平均

**问题。** 两条序列分别有两个和八个有效位置，各自平均梯度为一和三。两种平均方式的最终梯度各是多少？

**解析。** 按有效位置平均为 $`\frac{(2\times1+8\times3)}{10}=2.6`$；先按序列平均再平均为 $`\frac{(1+3)}{2}=2`$。前者随机抽一个有效位置的权重相同，后者随机抽一条序列后在其中抽位置的权重相同。它们对应不同采样分布的风险，并不存在脱离任务定义的统一正确答案，但实现必须与所声称的目标一致。

<a id="mc2-heading-39"></a>

### 15.13 为什么裁剪不能交换累加

**问题。** 一维裁剪把值限制在绝对值一内。两块梯度为二与负一点五。比较先裁剪各块再相加与先相加再裁剪。

**解析。** 前者为 $`1-1=0`$，后者先得到零点五，裁剪后仍为零点五。裁剪是非线性映射，所以不满足对加法的分配律。逐块裁剪可能改变优化方向，必须作为算法选择说明；不能把它当作仅仅调整计算分块而保持大批目标完全不变的实现细节。

<a id="mc2-heading-40"></a>

### 15.14 跨样本目标是否可以独立求导

**问题。** $`L=\frac{(z_1+z_2)^2}{2}`$，比较正确梯度与把它误拆成 $`\frac{(z_1^2+z_2^2)}{2}`$ 的梯度。在 $`(1,-1)`$ 处有什么差别？

**解析。** 正确梯度为 $`(z_1+z_2,z_1+z_2)`$，在指定点为零；误拆目标梯度为 $`(z_1,z_2)=(1,-1)`$。两种目标差一个交叉项 $`z_1z_2`$。这种差别来自统计或计算耦合，而不是广播轴错误；只要损失包含样本间配对，就必须保留这些交叉依赖，不能把样本轴上的所有计算都视作独立。

<a id="sec-7-1"></a>

### 15.15 共享偏置到底求和还是平均

**问题。** 某平均损失返回的上游两行为 $`(1,2)`$ 与 $`(3,4)`$，偏置在两行复用。应如何求偏置梯度，为什么不能再除二？

**解析。** 偏置梯度为 $`(4,6)`$。上游数组已经包含平均损失的全部缩放，局部广播节点只把重复使用位置贡献相加。再除二相当于插入一个前向里不存在的额外平均。如果怀疑上游数字不符合某个具体损失，应回到损失节点核对，而不是在仿射层反向里自行补偿，造成不同层之间隐藏的尺度耦合。

<a id="mc2-einsum"></a>

## 16. 用指标收缩处理多头与高阶张量

当输入同时具有批、时间、头和特征多个轴时，不必把所有对象压成矩阵再猜转置。可先使用指标表达式，明确哪些指标被求和、哪些保留。例如 $`Z_{bth}=\sum_dX_{btd}W_{dh}`$ 表示同一个权重在批和时间位置共享。给定上游 $`G_{bth}`$，权重梯度为 $`\sum_{bt}X_{btd}G_{bth}`$，输入梯度为 $`\sum_hG_{bth}W_{dh}`$，每个求和指标都直接来自依赖式。

若权重还有头指标 $`a`$，写成 $`Z_{btah}=\sum_dX_{btd}W_{adh}`$，则权重梯度对批与时间求和，但保留头指标；输入梯度则必须对头和输出特征一起求和，因为同一个输入同时被多个头使用。如果误把头维看成独立输入副本，只返回某一头的梯度，就遗漏了共享路径。张量维数增加没有引入新原则，只增加了依赖索引的管理要求。

这种推导可自然映射到`einsum`，但字符串本身也可能写错。建议先手写指标等式，再让每个输出梯度指标与对应输入相同，剩余重复指标执行收缩。例如权重梯度的三个指标顺序必须与参数存储一致；仅仅输出元素总数相同并不能保证 reshape 后语义正确。尤其维度数值偶然相同时，错误的轴交换更容易隐藏。

批量矩阵乘法还可能在前导轴广播。此时先对每个广播后的批位置使用矩阵乘法反向，再沿被复制的批维求和恢复原输入。把“矩阵乘法反向”与“广播反向”作为两层规则组合，比记忆每一种多维形状的单独公式更可扩展。这也解释了为什么某些手写实现单批正确、多批共享参数却错误：它们只完成局部乘法，没有完成复制路径的归约。

<a id="mc2-tied-decoder"></a>

## 17. 绑定编码与解码权重的完整梯度

考虑线性重构模型 $`H=XW`$、$`Z=HW^T`$，其中 $`X`$ 为 $`n\times d`$、$`W`$ 为 $`d\times r`$。编码和解码使用同一个参数矩阵及其转置，目标为 $`\frac{\Vert Z-T\Vert _F^2}{(2n)}`$。记上游 $`G=\frac{(Z-T)}{n}`$。解码位置把 $`W^T`$ 当作输入，局部贡献经转置映回原参数为 $`G^TH`$；编码位置贡献为 $`X^T(GW)`$，总梯度是两项之和。

也可以直接对 $`Z=XWW^T`$ 微分：$`dZ=X(dW)W^T+XW(dW)^T`$。两个项分别对应编码路径和解码路径。它们一般不同，即使二者当前使用同一组数值。若直接把解码权重存为独立参数再只在初始化时设置为编码转置，后续训练就不再是绑定模型，除非每次更新都维护明确的绑定依赖。

当 $`T=X`$ 时，该模型与低秩重构相关，但并不自动等同于在所有低秩矩阵上的无约束最优逼近。输出投影形如 $`WW^T`$，若没有正交约束，它不是一般的正交投影；若要联系 PCA，需要说明优化变量、约束和数据中心化条件。求导公式正确并不能替代对模型表达能力和全局最优结构的证明。

这个例子还展示了一个可解释的不变性：对任意正交 $`Q\in\mathbb R^{r\times r}`$，将 $`W`$ 变为 $`WQ`$ 不改变 $`WW^T`$，因此内部表示的坐标旋转不可辨识。沿无穷小正交旋转方向，一阶输出变化为零。若候选梯度在这些不变方向上给出非零方向导数，就可能漏掉某一条绑定路径，或误把转置变量当成独立变量。

<a id="mc2-centered"></a>

## 18. 跨样本中心化节点的反向并非逐样本独立

设 $`Z\in\mathbb R^{n\times k}`$，每个输出列沿样本去均值：$`H=Z-\mathbf1\mu^T`$，其中 $`\mu=\frac{Z^T\mathbf1}{n}`$。定义中心化矩阵 $`C=I-\frac{\mathbf1\mathbf1^T}{n}`$，便有 $`H=CZ`$。矩阵 $`C`$ 对称且幂等，因此给定上游 $`G_H`$，反向为 $`G_Z=CG_H`$，即每列梯度也去掉样本均值。

逐元素看，输入某一行既直接影响本行中心化值，也通过均值影响所有行，所以 $`\frac{\partial L}{\partial Z_{ij}}=G_{H,ij}-\sum_a\frac{G_{H,aj}}{n}`$。如果只保留直接路径就会漏掉均值项。虽然中心化前后的形状完全相同，这个节点绝不是逐元素函数；它与逐元素激活的导数数组相乘规则不同。

由平移不变性可以独立验证结果：给所有样本添加同一输出偏移，中心化结果不变，因此每列输入梯度之和必须为零。如果反向结果不满足这个约束，就与前向的不变性冲突。这个结构检查无需选择差分步长，也不依赖某个随机数例子，是审查耦合节点时十分有力的工具。

若损失是 $`\frac{\Vert CZ\Vert _F^2}{2}`$，梯度为 $`C^TCZ=CZ`$，Hessian 作用也是 $`V\mapsto CV`$。这里可看到跨样本的交叉块确实存在，但仍是线性且半正定的结构。把批次拆成两个微批各自中心化，使用的是两个小中心化矩阵构成的块对角算子，一般不同于原来的全批中心化，所以普通梯度累积不能恢复原目标。

中心化只是最简单的统计耦合。加入方差归一化后，分母依赖所有样本，还会产生更多反向项；下章会从完整雅可比推导这类规则。本节先建立一个明确的过渡：只要一个样本参与公共统计量，其他样本的输出就可能依赖它，必须沿公共统计量路径合并反向贡献。

<a id="mc2-sampling"></a>

## 19. 抽样、梯度方差与逐样本变换

批量梯度不仅是计算组织，也与抽样估计有关。若总体目标是有限训练集的均值，均匀独立抽取样本的单样本梯度在适当条件下是总体梯度的无偏估计；多个独立样本平均可以降低估计方差。但如果对不同样本使用非均匀概率，直接平均抽到的梯度会改变其期望，需要明确目标是否也随采样分布改变。

设训练集大小为 $`N`$，以正概率 $`p_i`$ 抽到样本 $`i`$。若仍要估计均匀均值梯度，可使用 $`\frac{g_i}{(Np_i)}`$，其期望为 $`\sum_i\frac{p_i g_i}{(Np_i)}=\sum_i\frac{g_i}{N}`$。这类重要性修正可能带来较大方差，尤其当某些概率很小时。无偏性与低方差是两个条件，不能因为一个估计器无偏就断言它在有限预算下更好。

如果对每样本梯度先做范数裁剪，再平均，期望一般不再等于原始目标梯度；裁剪引入了非线性。某些算法刻意接受这种变化以限制单样本影响，但应把它描述为算法定义，而不是求导结果自然就该这样。类似地，用每样本梯度范数作为动态权重时，还要说明是否对权重本身求导，前面商法则所揭示的额外路径会再次出现。

梯度方差实验还需区分数据抽样、模型随机性和数值误差。固定参数后改变样本集合估计的是抽样变化；同时改变 dropout 则混入模型随机性；使用不同求解精度则又加入计算误差。它们可能共同影响训练，但研究报告应分别控制或明确组合，才有可能解释某个批量策略为何更稳定。

<a id="mc2-memory"></a>

## 20. 保存、重算与原地更新为何影响反向语义

反向公式通常需要前向中间量。例如仿射权重梯度需要前向输入，激活反向可能需要激活前值或输出，双线性图需要两条分支结果。实现可以保存这些量，也可以在需要时重算。只要重算得到同一个数学函数在同一状态下的对应值，理论导数不变；保存与重算主要改变时间和存储预算。

如果重算时随机状态、可变缓冲区或参数已经变化，得到的中间值就可能不再属于原来的前向。此时反向虽然每个局部公式都像是正确的，却拼接了不同状态的计算图。检查点技术需要管理这些状态条件；手工实现尤其应避免在所有反向贡献计算完成前，原地更新共享参数或覆盖仍被后续节点需要的中间量。

例如共享模型 $`H=XW,Z=HW`$ 的第二条参数贡献需要原来的 $`H`$，第一条贡献需要原来的 $`W`$。如果算完第二条贡献立即更新 $`W`$，再用新权重传回 $`H`$，所得总量不再是同一点上的梯度。优化更新应发生在整个目标梯度完成之后，除非算法明确设计为某种局部或在线更新并分析了这种变化。

浮点运算中的数学等价也不等于逐位相同。改变批分块、收缩顺序或重算路径，可能改变累加舍入；在温和问题中通常只是小差异，在病态或长期训练中却可能逐渐放大。应使用与数值尺度匹配的容限验证局部等价，并把可复现性要求分成算法目标一致、近似数值一致和逐位一致三个层次，避免提出相互矛盾的验收标准。

<a id="mc2-advanced-exercises"></a>

### 20.1 中心化反向的手算题

**问题。** 三条样本的上游为 $`(1,2,6)^T`$，对样本中心化节点求输入梯度。若再接一个共享标量偏置，偏置梯度是什么？

**解析。** 上游均值为三，输入梯度为 $`(-2,-1,3)^T`$，总和为零。共享偏置梯度是三项之和，因此为零，符合“先给全部样本加同一偏置，再中心化，输出不变”的函数恒等性。零梯度来自结构平移不变性，在这里比一般数据相消更强；任何上游都应满足相同的总和约束。

<a id="mc2-heading-48"></a>

### 20.2 绑定重构的旋转方向

**问题。** 对 $`Z=XWW^T`$，令方向 $`H=WK`$，其中 $`K^T=-K`$。证明输出一阶变化为零，并说明它验证了哪些路径。

**解析。** 方向变化为 $`XHW^T+XWH^T=XW(K+K^T)W^T=0`$。编码与解码两条使用路径的变化恰好相消。若只保留其中一项，通常不为零，所以这个测试能检查绑定权重是否完整汇合。它不能单独验证所有其他方向，也不能保证模型在有限步 $`W+tWK`$ 后严格不变；精确正交旋转和一阶切向扰动需要区分。

为把上述结构检查落实为独立证据，下面同时验证中心化上游列和为零，以及绑定权重的方向差分与旋转不变方向。前者不依赖标签数值，后者使用非方权重，避免矩阵尺寸相同掩盖错误的转置位置。随机方向验证一般局部变化，反对称旋转方向验证特定结构恒等性，两者分别约束不同错误模式。

```python
import numpy as np
rng = np.random.default_rng(44)
X = rng.normal(size=(4, 3))
W = rng.normal(size=(3, 2))
T = rng.normal(size=X.shape)
H = X@W
G = (H@W.T-T)/len(X)
GW = X.T@(G@W) + G.T@H
V = rng.normal(size=W.shape)
f = lambda w: np.sum((X@w@w.T-T)**2)/(2*len(X))
eps = 1e-6
fd = (f(W+eps*V)-f(W-eps*V))/(2*eps)
np.testing.assert_allclose(fd, np.sum(GW*V), rtol=2e-6, atol=2e-7)
K = np.array([[0., 2.], [-2., 0.]])
np.testing.assert_allclose(np.sum(GW*(W@K)), 0., atol=1e-12)
up = rng.normal(size=(4, 2))
back = up-up.mean(axis=0, keepdims=True)
np.testing.assert_allclose(back.sum(axis=0), 0., atol=1e-12)
print('绑定重构、旋转不变方向与中心化反向检查通过')
```

## 21. 从完整计算图审查批量梯度

完成一份新模型的手工推导时，先画出变量依赖，标出同一个参数出现的所有位置，再标注每个轴的语义和每个归约的分母。接着按节点写局部微分，把输出梯度通过伴随传回。最后在汇合点累加同一变量的全部贡献，并把数据项、正则项与优化器梯度变换分开记录。

代码验证则使用三个层次：局部规则的伴随一致性、小型完整函数的联合方向差分、真实训练前向中的形状与有效权重契约。第一个帮助定位局部线性规则，第二个覆盖路径连接，第三个防止正确求导了错误目标。它们回答的问题不同，因此不能只保留一个“训练损失下降”的总体验收标准。

研究阶段还可比较不同分块、不同批大小和不同计算图组织是否在同一点产生相同梯度。如果理论应当相同却出现固定比例差异，先检查归约与通信；如果差异依赖数据位置，检查索引、掩码和广播；如果只在某些批次出现，检查跨样本统计和空有效集合；如果仅在边界出现，检查不可微分支及目标定义。

本章建立的是批量计算中的依赖与归约框架。后续 softmax、归一化和完整网络仍遵循相同原则：耦合节点用真实雅可比作用，复制节点反向求和，共享节点合并路径，目标缩放只在明确的位置发生。把这四件事说清楚，才能从“公式看起来像”走向可执行、可审查且能解释失败条件的推导。
