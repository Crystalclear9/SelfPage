# 统计学

从有限样本估计总体，理解不确定性、假设检验与实验设计。

**先修知识：** 概率、期望、方差。

**正文篇幅状态：** 本主题现有 4 章均已按长篇教材标准展开，逐章纯正文达到 12000–20000 汉字。完整范围见[长篇教材覆盖表](../../README.md#textbook-status)。

## 学习顺序与覆盖范围

第 1—2 章先建立估计与检验的含义；第 3 章与[线性回归模型](../../MachineLearning/SupervisedLearning/01-线性回归与逻辑回归.md)配合阅读，关注统计假设与参数不确定性；第 4 章再把不确定性落实到重采样实验。无需先掌握回归才能开始统计学。覆盖实验需先理解[概率论中的采样与极限条件](../Probability/04-采样大数定律与蒙特卡洛推断.md)；代码中的分布分位数使用 SciPy，核对版本与依赖见[运行环境](../../运行环境.md)。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 评估不确定性的两条支线

研究持续收集数据并决定何时停止时，接第 2 章的[似然比超鞅与随时有效检验](02-假设检验相关性与实验.md#sequential-likelihood-ratio)，逐步核对条件期望和首次跨线事件。研究同一批测试对象上的模型差异时，接[模型评估中的 AUC 方差与配对比较](../../MachineLearning/ModelEvaluation/01-分类回归与概率指标.md#auc-ustat-variance)，识别哪些比较共享样本。两者分别处理观察时刻和数据复用结构，不能用增加查看次数或样本对数来代替新增独立信息。

## 如何完成本主题

完成各章后，先独立作答[综合练习：配对比较、置信区间与实际效应](04-重采样实验设计与报告实践.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
