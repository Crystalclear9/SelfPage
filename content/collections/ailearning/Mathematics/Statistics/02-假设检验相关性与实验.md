# 第 2 章 假设检验相关性与实验

[主题目录](README.md) · [分类目录](../README.md) · [总目录](../../README.md) · [上一章](01-参数估计与置信区间.md) · [下一章](03-线性回归的统计解释.md)

本章把检验写成一个可检查的研究程序：先说明比较什么、哪种随机机制使证据可解释，再规定容许的错误和拒绝规则，最后报告效应与决策。我们会从简单正态检验推导到似然比、精确检验、功效、多重比较和随机实验。每一步都保留适用条件，尤其区分“差异没有检出”“已经证明足够接近”与“采取某个行动值得付出代价”。

前一章讲点估计与区间，本章研究哪些数据能使我们拒绝一个假设。两种表述经常可以互相反演，但无法省略研究设计。一个计算正确的 p 值，在随机化单位错误、随意停止或选择性报告之后，仍可能回答错误问题。实验技术与数学推导应当共同参与结论。

## 1. 假设检验回答什么

<a id="hypothesis-rejection"></a>

### 1.1 假设是分布集合，检验是随机决策

设观测分布属于 $\{P_\theta:\theta\in\Theta\}$。原假设为 $H_0:\theta\in\Theta_0$，备择为 $H_1:\theta\in\Theta_1$。检验函数 $\phi(S)\in[0,1]$ 表示给定数据后的拒绝概率；非随机化检验只取零和一。显著性水平控制要求 $\sup_{\theta\in\Theta_0}E_\theta\phi(S)\le\alpha$。原假设含多个参数值时，必须对整个原假设集合控制错误，而不是只挑其中一个容易计算的点。

原假设不必永远表示零效应。在非劣检验中，它可以表示新方法比旧方法差到不能接受；在等效检验中，它可以表示差异超出可接受界限。假设的方向由研究目标和错误代价决定，不能机械地把“希望证明的结论”放在原假设一侧。检验承诺约束的是误拒绝原假设的概率，因此不同假设安排对应不同保护对象。

第一类错误是实际属于原假设却拒绝，第二类错误是在某个指定备择参数下没有拒绝。第二类错误不是一个不依赖备择的常数：效果很小和效果很大时，功效不同。报告“功效百分之八十”应同时给出针对多大效应、多少噪声、哪种设计及哪种检验，否则这个数字缺少对象。显著性水平与功效也不是观察结果出来后再挑选的标签。

<a id="pvalue-definition"></a>

### 1.2 p 值的有效性与“至少同样极端”

一个有效 p 值满足对任意原假设参数及任意 $u\in[0,1]$，$P_\theta(p(S)\le u)\le u$。这个超均匀性质保证以 $p\le\alpha$ 拒绝时控制第一类错误。在连续简单模型中常可恰好等号；离散数据通常保守。p 值由原假设分布和事先规定的极端方向共同决定，不能只把一个观测统计量代入任意尾概率。

例如标准正态统计量 $Z$，事前双侧检验使用 $p=2\{1-\Phi(|Z|)\}$；向上单侧检验使用 $p=1-\Phi(Z)$。观察到正值后选向上、负值后选向下，再报告较小单侧 p，相当于改变了程序。在真实零效应下，以这个挑方向的 p 小于零点零五拒绝，实际错误概率约为零点一。方向选择不是纯粹的语言问题，而会改变拒绝域的概率。

p 值不是 $P(H_0\mid S)$，也不是“结果纯属偶然”的概率。它将原假设及模型条件作为前提，评价一个程序定义的尾部事件。如果某些记录不独立、缺失机制有选择性或统计量经过大量尝试，所用参考分布可能不再正确。很小的 p 值可以提示模型整体不相容，却不能单凭它识别究竟是目标效应、测量错误还是其他假设失效。

<a id="sec-1-1"></a>

### 1.3 基础算例：先写假设再解释检验统计量

假设要比较新旧流程的平均用时，定义 $\delta=\mu_{\mathrm{new}}-\mu_{\mathrm{old}}$，负数表示更快。若目标是寻找任意变化，写 $H_0:\delta=0$ 对 $H_1:\delta\ne0$；若目标事前只关注加速，写 $H_0:\delta\ge0$ 对 $H_1:\delta<0$。同一个估计差值，在两个研究目标下对应不同拒绝域。

若估计差值为负二秒、已知标准误为一秒，正态统计量为负二。双侧 p 约零点零四五五，预先规定向下单侧 p 约零点零二二八。两者都不意味着新流程有某个后验概率更快。若实际最小有意义改善为五秒，方向上的证据也不等于达到了部署门槛。应同时报告估计值、区间和门槛。

<a id="deep-dive-1"></a>

### 1.4 深入讲解：从拒绝域理解 p 值功效和多重比较

想象把全部可能数据排列成一个样本空间。拒绝域在这个空间里划出一块区域，要求它在任何原假设分布下的概率都不超过预算。p 值则可视为与观察数据相容的一族嵌套拒绝域中，最先将其包含进去的水平。这个几何想象说明，单个数据点的“显著程度”来自预先规定的整套空间划分，不是数据本身携带的一个天然属性。

功效是同一拒绝域在备择分布下的概率。提高样本量常使原假设与备择统计量分布相对分离，增加拒绝机会；换一个统计量也会改变分离效率。若不断尝试多个统计量再选择最小 p，实际拒绝域是许多区域的并集，其概率可能大于任何一个区域。多重比较和随意停止本质上都涉及程序扩大了哪些会触发结论的数据路径。

因此研究协议应写出主要假设、统计量、方向、样本量或序贯规则，以及哪些探索不进入确认性结论。探索可以发现新机制，但不应以探索后挑出的拒绝域假装原来就如此规定。记录探索过程并使用独立确认数据，能让发现保留价值，同时避免把选择偏差混进确认强度。

## 2. 进阶：Neyman–Pearson 视角与似然比

<a id="np-proof"></a>

### 2.1 简单假设下最强检验的证明

对两个完全指定的密度 $f_0,f_1$，似然比为 $\Lambda(x)=f_1(x)/f_0(x)$。Neyman–Pearson 检验在比值大于阈值 $c$ 时拒绝，必要时在等号处随机化，使 $E_0\phi^*=\alpha$。对于任何同水平检验 $\phi$，逐点有 $(\phi^* -\phi)(f_1-cf_0)\ge0$。积分后得到

$$E_1\phi^*-E_1\phi\ge c(E_0\phi^*-E_0\phi)\ge0.$$

所以在固定第一类错误预算下，它对该指定备择具有最大功效。证明清楚说明“最强”是相对于哪一个备择，而非对所有可能分布都最强。若无法恰好用完错误预算，阈值上的随机化在理论上可以实现精确水平，实际应用也可采用不随机化的保守规则。

正态均值已知方差时，检验 $\mu=\mu_0$ 对 $\mu=\mu_1>\mu_0$。对数似然比随样本均值单调增加，所以拒绝域为均值超过某个阈值。重要的是，所有向上的简单备择给出同一个排序，因此能够推广到适当的单侧复合备择。双侧备择同时包含向上和向下方向，一般不能直接把这个单侧最强性宣称为无条件的统一最强结论。

<a id="composite-nuisance"></a>

### 2.2 复合假设、干扰参数与最不利边界

实际问题通常有未知方差、基线率等干扰参数。似然比检验常使用 $\lambda(S)=\sup_{\theta\in\Theta_0}L(\theta)/\sup_{\theta\in\Theta}L(\theta)$，小值反对原假设。但最大化是定义统计量的步骤，尚未确定其原假设分布。要得到逐原假设参数都有效的临界值，仍需条件化、使用枢轴、证明最不利参数位置或建立其他统一控制。若采用对干扰参数积分的方案，应说明积分所依据的概率模型和控制对象；任意指定先验后得到的平均错误率，并不自动保证每个固定干扰参数下的频率水平。

对于已知方差正态单侧检验 $H_0:\mu\le\mu_0$，拒绝域为 $\bar X$ 大于阈值，拒绝概率随 $\mu$ 单调增，因此原假设内最不利值在边界 $\mu_0$。用边界分布校准即可控制整个原假设。这个结论依赖单调性，不能把“总在边界算 p”推广到任意复合假设。若拒绝概率非单调或存在多个干扰方向，需要重新取上确界或采用其他严格方法。

常见的 Wilks 近似把负二倍对数似然比近似为自由度等于约束维数差的卡方分布，其背景包含固定维度、内部真值、可识别和足够光滑。方差分量等于零、混合模型中成分不可识别、参数位于不等式边界时，参考分布可能出现混合或其他非标准极限。给统计量套上卡方分位数之前，应先检查这些结构性条件。

<a id="normal-t-tests"></a>

### 2.3 单样本、配对与两独立样本的区别

正态单样本均值检验在方差未知时使用 $T=(\bar X-\mu_0)/(S/\sqrt n)$，自由度为 $n-1$。配对比较应先形成每个独立对象的差值 $D_i=Y_{i,\mathrm{new}}-Y_{i,\mathrm{old}}$，再对差值做单样本分析。这样保留配对协方差，方差为 $\operatorname{Var}(D)=\operatorname{Var}(Y_1)+\operatorname{Var}(Y_0)-2\operatorname{Cov}(Y_1,Y_0)$，正相关配对常能降低无关个体差异。

若两组来自不同独立个体，均值差标准误通常估为 $\sqrt{S_1^2/n_1+S_0^2/n_0}$。Welch 检验使用这个标准误和近似自由度，不要求两组总体方差相等；其常用 t 参考分布一般是近似。合并方差 t 检验在独立正态、共同未知方差下具有精确有限样本分布，但共同方差是需要依据的假设，不应仅为获得整齐自由度而强加。

同一测试集比较两个模型时，每个样本形成的损失差具有配对结构；若比较的是同一批训练种子产生的整体分数，则独立单位可能是种子或完整实验运行。二者回答不同层次的问题。无论哪一种，先画清数据生成层级，再决定 t 检验的样本轴。对一个模型的许多 token 或图像裁剪逐行检验，通常不会自动得到许多独立实验。

<a id="exact-permutation"></a>

## 3. 精确检验、渐近检验与置换的条件

<a id="binomial-exact-test"></a>

### 3.1 二项尾概率与离散 p 值

若 $K\sim\operatorname{Binomial}(n,p)$，检验 $H_0:p\le p_0$ 对 $p>p_0$，可以取 $p_{\mathrm{value}}=P_{p_0}(K\ge k_{\mathrm{obs}})$。二项上尾随真实成功概率增加，因此最不利值在边界 $p_0$。这个 p 值在复合原假设下有效，且无需正态近似。离散性使可达到的拒绝概率跳跃，因此实际水平可能低于名义水平。

双侧精确 p 值没有唯一通用定义。可以使用两倍较小单侧尾概率并截到一，也可以按原假设下概率质量不大于观察计数的点求和，或按其他事前指定的极端性排序。不同定义可产生不同数字和区间反演。报告“精确二项检验”时，最好说明单双侧及软件采用的排序，而不是认为所有精确方法必须数值完全一致。

精确性始终相对于模型。每个成功事件若受共同环境影响，计数可能过度离散而不服从二项分布。此时使用精确二项尾计算，只是精确地处理了不适当的参考模型。关于算法是否精确与模型是否适合，应作为两个问题分别检查；“没有用大样本近似”并不等于“没有假设”。

<a id="exchangeability"></a>

### 3.2 置换检验的交换性不是均值相等

独立两组在原假设下若来自同一分布，合并观测的组标签具有交换性。在固定组大小条件下，枚举所有标签分配得到统计量的置换分布，可构造有限样本精确或保守检验。这里允许置换，是因为原假设下联合分布对这些变换不变，而不是因为计算机能随意打乱列表。

两组均值相同但方差不同，特别在样本量不平衡时，原始均值差的标签置换通常不具有上述精确性。均值为零的一组可以高度分散，另一组很集中，标签明显包含分布信息。适当学生化统计量有时可在额外条件下获得渐近有效性，但这仍不同于有限样本精确交换性。写“非参数检验不需要分布假设”会掩盖真正条件。

配对随机交换要求在每个对子内交换处理标签，保留对子结构；时间相关数据不能逐时点任意置换而期待保持原假设分布。符号翻转对一般均值为零的差值也不自动精确，常需差值分布对称，或随机化设计下的尖锐零效应假设。置换单位与允许的变换群应由设计决定，而非由最容易编程的维度决定。

<a id="sharp-weak-null"></a>

### 3.3 随机化检验的尖锐零假设与平均零假设

在完全随机分配实验中，若假设每个单位的处理效应都为零，所有未观察潜在结果都可由已观察结果补齐。固定结果、枚举随机分配，就得到随机化分布。这是 Fisher 尖锐零假设。它比“平均处理效应为零”更强，因为后者允许有些单位受益、有些受损，未观测潜在结果无法唯一补齐。

因此，拒绝尖锐零假设意味着数据反对所有单位都无效，并不自动给出平均效应方向；不拒绝也不证明每个单位都无效。若研究目标是平均效应，应使用针对该目标的估计和方差分析。随机化检验可通过适当学生化和渐近理论研究弱零假设，但必须明确这是一条额外论证，不能把尖锐检验的精确性直接转移。

采用分层随机化、配对随机化或集群随机化时，参考分配集合必须与实际设计相同。实际只在同一层内随机，却模拟跨层任意打乱，会给错误分配赋予概率。设计记录不仅影响点估计权重，也影响能合法使用的随机化检验。所谓设计驱动的推断，正是把实际随机化机制写进概率计算。

<a id="montecarlo-p"></a>

### 3.4 有限次置换与绝不应报告的零概率

当分配集合太大而只能抽取 $B$ 个随机置换时，常使用 $(b+1)/(B+1)$，其中 $b$ 为随机置换统计量至少同样极端的次数。在符合交换性和相应随机抽样安排的标准构造中，将观察分配一起计入有助于保持有效性。直接使用 $b/B$ 会在没有出现更极端置换时输出零，这不意味着原假设尾概率真的为零。

这里的最小可报告值约为 $1/(B+1)$。如果多重校正后的阈值小于这个分辨率，增加原始样本并不会解决置换次数不足的问题，必须增加随机置换预算或改用精确计算。还应报告随机种子、置换次数、极端方向和是否采用完全枚举。代码中的相等比较也需要谨慎，理论上相等的统计量可能因浮点运算顺序出现极小差异。

本章后面的小实验选择完全枚举，因此精确 p 用尾部计数除以全部允许分配数，不再额外加一。完全枚举本来已包含观察分配；重复加一会改变原定义。区分“随机抽样近似”和“穷尽分配集合”是实现中常见、也容易修正的细节。

<a id="sec-2"></a>

## 4. 显著不等于重要：功效、效应与样本量

<a id="power-formula"></a>

### 4.1 正态均值差的功效函数

若估计量 $\hat\delta\sim N(\delta,s^2)$，标准误 $s$ 已知且设计固定，双侧水平 $\alpha$ 检验在 $|\hat\delta/s|>z_{1-\alpha/2}$ 时拒绝。令非中心位移 $\lambda=\delta/s$，功效为

$$\pi(\delta)=1-\Phi(z_{1-\alpha/2}-\lambda)+\Phi(-z_{1-\alpha/2}-\lambda).$$

零效应时功效恰等于第一类错误率，指定效应增大时通常上升。这个公式精确适用于所写正态已知标准误模型；把样本方差代入后，有限样本应考虑相应非中心 t 分布或近似。功效不是观察到显著后的“结果正确概率”，而是事前在指定真实效应下重复研究的拒绝频率。

对单侧向上检验，功效为 $1-\Phi(z_{1-\alpha}-\delta/s)$。若两组等样本量、共同已知标准差为 $\sigma$，则 $s=\sigma\sqrt{2/n}$。以目标最小效应 $\delta_*>0$ 和目标功效 $1-\beta$ 规划，单侧所需每组样本量满足 $n\ge2\sigma^2(z_{1-\alpha}+z_{1-\beta})^2/\delta_*^2$。双侧常用相应双侧分位数作近似规划，并检查完整功效公式。

样本量规划需要诚实的方差与效应假设。用探索数据中被挑选出的最大效果作规划，常会低估所需样本量，因为观察最大值带有赢家偏差。可以使用外部证据、实际最小重要效应和一组方差场景做敏感性分析。目标不是保证研究必然显著，而是保证在事先有意义的情形下有足够机会检测。

<a id="effect-scales"></a>

### 4.2 绝对效应、相对效应与标准化效应

成功率从百分之十提高到百分之十一，绝对增加一个百分点，相对增加百分之十。二者都可以正确，但含义不同。基线极小时，巨大相对改善也可能对应很小绝对收益；基线接近一时，同样绝对差异可能消耗大量剩余提升空间。报告必须写清分母、时间尺度和目标总体，避免只挑更显眼的表述。

标准化均值差将原始差异除以某个标准差，方便跨量纲比较，却也依赖选择哪一种标准差。配对差值标准差、基线个体标准差和两组的合并标准差不是同一量。异质性更大的总体可以让同一原始改善得到更小标准化效应，因此标准化不能替代实际单位中的意义解释。

AI 模型实验还需区分平均性能增益与尾部损害。总体均值提升，可能伴随重要子群显著下降；但事后尝试许多子群再挑最差者，又涉及多重选择。可事前指定关键安全或公平指标，并对探索性子群分析注明范围和独立验证需求。实际重要性需要任务结构，单个 p 值无法承担这一层判断。

<a id="sec-2-1"></a>

### 4.3 机制展开：置信区间宽度与实际价值分别解释

设改善估计为零点二，区间为零点一到零点三，若最小重要改善为一，结果可有清楚方向却不足以达到决策门槛。若改善估计为二，区间为负一到五，则潜在价值大但精度不足。两者分别体现方向证据、实际规模和不确定性，不应被“显著”或“不显著”两个词压缩成单维评价。

在固定检验与双侧等尾区间相互反演的情形，百分之九十五区间不含零对应双侧百分之五水平拒绝零差异。但不同检验或不同区间定义未必严格对应，离散精确方法尤其要注意反演约定。若区间与检验出现看似矛盾，先核对单双侧、置信水平、方差估计和极端性定义，而不是认为所有软件必须输出相同结论。

观察数据后重新计算所谓“观察功效”，若只是把估计效应代入事前功效公式，它通常与 p 值高度单调对应，没有提供独立信息。研究结束后更有帮助的是效应区间与可排除效应范围：哪些实际重要的改善或损害仍然相容，下一次研究需要怎样提高精度。不要用低观察功效作为不显著结果的自动免责理由。

<a id="sec-5"></a>

## 5. 置信区间、等效性与非劣性问题

<a id="tost"></a>

### 5.1 等效检验为何要求同时跨过两道门

事前定义可忽略差异范围 $(-\Delta,\Delta)$。等效原假设为 $H_0:\delta\le-\Delta\ \text{或}\ \delta\ge\Delta$，备择为区间内部。两单侧检验分别检验 $\delta\le-\Delta$ 对更大，以及 $\delta\ge\Delta$ 对更小，只有两者都拒绝才声明等效。这个交并结构把结论写成“足够大于下界，并且足够小于上界”。

为何每个单侧都用水平 $\alpha$ 而不用再除以二？因为当等效原假设为真时，至少一个单侧原假设为真，错误声明等效要求连这个真原假设也被拒绝，其概率最多为 $\alpha$。这是交并检验的逻辑，与“两个检验任意一个显著就宣称成功”的并集逻辑不同。错误控制不能只按检验数量机械决定。

在对称正态或相应 t 区间与检验匹配时，两单侧各百分之五水平等效检验，对应百分之九十双侧区间完全位于 $(-\Delta,\Delta)$。普通百分之九十五差异区间包含零，只说明没有排除零，不证明整个区间位于可接受范围。可以同时统计显著且实际等效，例如一个极小但精确估计的非零差异；也可以两者都不成立。

<a id="noninferiority"></a>

### 5.2 非劣性需要固定方向和界限依据

设 $\delta$ 越大越好，允许新方法至多差 $\Delta>0$，非劣原假设为 $\delta\le-\Delta$，备择为 $\delta>-\Delta$。若相应单侧置信下界大于负界限，即可在匹配水平下拒绝。非劣不意味着优于零，更不意味着两者在所有指标上一样。若新方法有成本、速度或可用性优势，非劣性可与这些优势共同进入决策，但统计结论与综合权衡应分开陈述。

界限应来自实际可接受损失和领域依据。看过宽区间后把界限放大到恰好包住它，会破坏确认性含义；根据结果在“优效”“非劣”“等效”之间自由切换，也引入选择。可以事前定义有序研究目标与相应错误控制，或者坦诚把后来新增分析标为探索。完整协议比事后措辞更能保护结论。

实验依从性问题在非劣研究尤其棘手。若很多人没有实际接受所分配处理，两组差异可能被稀释到接近零，从而看起来容易非劣；简单删除不依从者又破坏随机化可比性。应明确估计的是分配策略效应还是实际处理效应，并对缺失和依从机制做适当分析。随机分配并不保证任何事后筛选子集仍然随机。

<a id="minimum-effect-test"></a>

### 5.3 检出非零与证明超过实际门槛

若部署要求改善至少为 $\Delta$，合适目标可能是 $H_0:\delta\le\Delta$ 对 $\delta>\Delta$。单纯拒绝零差异没有回答这个问题。把实际门槛写进假设，可以让错误预算直接保护“收益不足却宣称值得”的结论。对应区间下界必须超过门槛，而不只是超过零。

阈值也可能伴随成本与风险的不确定性。如果收益随用户规模变化，而成本含固定维护投入，应以决策模型把效应映射到净收益。统计检验帮助限定证据强度，却不能自动指定行动。即使估计很精确，一个不可逆高风险行动与低成本可逆试验也可能需要不同证据门槛。事前讨论这些代价，有助于选择适当的研究规模和推断目标。

<a id="sec-4"></a>

## 6. 多重比较与预先设计

<a id="fwer-bonferroni"></a>

### 6.1 FWER 与 Bonferroni 的一行证明

设共有 $m$ 个假设，真正原假设的索引集合为 $I_0$，错误拒绝数为 $V$。族错误率为 $P(V\ge1)$。若每个真原假设下 p 值有效，Bonferroni 规则以 $p_i\le\alpha/m$ 拒绝，则由并集界

$$P(V\ge1)\le\sum_{i\in I_0}P(p_i\le\alpha/m)\le |I_0|\alpha/m\le\alpha.$$

证明不需要检验独立，且无论真假假设如何组合都成立，称为强控制。若所有原假设都真、各次拒绝事件相互独立，且每项检验的实际第一类错误率恰为 $\alpha$，未校正的至少一次误报概率为 $1-(1-\alpha)^m$；二十个这样的百分之五检验约为百分之六十四点二。若各项只保证水平不超过 $\alpha$，独立情形中该表达式一般是上界而非必然等式。精确乘积关系依赖独立，而并集界控制不依赖独立，两者的条件应分别标明。

“族”应按要保护的结论集合事前定义。把一个研究中二十个指标拆成二十份报告，并不会自然消除整体选择过程。另一方面，把全部未来研究无限合并成一个族也未必符合具体决策目标。应说明哪些结论共同竞争一次确认性声明，以及为何采用这个错误控制范围。科学透明不等于机械统计检验总数，而是把选择如何影响结论公开。

<a id="holm"></a>

### 6.2 Holm 逐步下降为何比统一门槛更灵活

将 p 值排序为 $p_{(1)}\le\cdots\le p_{(m)}$。Holm 从最小者开始，将第 $j$ 个与 $\alpha/(m-j+1)$ 比较；只要通过就继续，第一次不通过则停止并保留其后全部。它在同样的有效 p 条件下控制 FWER，不要求独立，且至少包含 Bonferroni 的拒绝集合。

证明可看第一次被错误拒绝的真原假设。若共有 $m_0$ 个真原假设，在它之前最多出现 $m-m_0$ 个假原假设，所以它面临的分母至少为 $m_0$，阈值不大于 $\alpha/m_0$。出现任何错误拒绝，必然意味着某个真 p 小于该阈值，联合界给出概率不超过 $\alpha$。这个论证同时解释了为何必须在第一次失败后停止。

例如排序 p 为零点零零一、零点零一二、零点零一八、零点零四，水平零点零五。四个门槛依次为零点零一二五、约零点零一六七、零点零二五和零点零五，四项全部通过。Bonferroni 统一使用零点零一二五，只拒绝前两项。两种方法保护的是同一个族错误目标，差别来自如何利用已通过的次序信息。

<a id="fdr-bh"></a>

### 6.3 FDR、BH 与依赖条件

令总拒绝数为 $R$，错误发现比例定义为 $V/\max(R,1)$，FDR 是该比例的期望。它不是每次研究中错误比例都不超过阈值，也不是每个被拒绝假设为真的后验概率。全部原假设都真时，任何拒绝都是错，FDR 恰等于 FWER；真假混合时，二者保护强度不同。

BH 规则将 p 排序，取满足 $p_{(k)}\le kq/m$ 的最大索引 $k$，拒绝前 $k$ 项；若没有满足者则不拒绝。独立且有效 p 的经典条件下，FDR 不超过 $q m_0/m$。某些正依赖结构也允许该保证，但“相关系数多数为正”并不自动等同于所需的 PRDS 条件。原论文及依赖扩展见本章参考资料，使用时应明确自己依据哪个条件。

任意依赖下可用 BY 的调和因子修正，将门槛改为 $kq/(mH_m)$，其中 $H_m=\sum_{j=1}^m1/j$。它在有效 p 下提供更宽泛依赖保护，通常也更保守。任何多重程序都无法修复原始 p 已经因错误抽样单位或事后停止而失效的问题。先保证每个输入证据有效，再讨论如何组合，是必要顺序。

<a id="bh-proof-intuition"></a>

### 6.4 BH 的自洽性与为什么不能逐项过线就结束

BH 是逐步上升程序：先找最大通过索引，再拒绝它之前的全部项。某个较小索引没通过自己的门槛，并不意味着程序应立即停止。例如五个 p 为零点零零九、零点零一九、零点零二九、零点零三九、零点二，在 $q=0.05$ 下前四个满足各自门槛；而其他数列可出现前面暂不通过、后面通过的情况。把 BH 实现成 Holm 式第一次失败停止，会得到不同方法。

从保证的机制看，一个被拒绝真原假设的 p 必须不大于 $qR/m$。在独立条件下，把该 p 暂时设为零，研究剩余拒绝数，可以将它与其余 p 的随机性分离；有效 p 给出的尾概率界与分母中的拒绝数抵消，最终每个真原假设贡献至多 $q/m$。这个思路说明独立或特定依赖条件为何进入证明，不能只凭排序图形就宣布任意相关数据都有效。

FDR 适合大规模发现筛查时的某些目标，关键少数确认性声明可能更需要 FWER。选择目标应依据错误后果，而非看到某种校正能留下更多显著项才选择它。筛查发现后使用独立数据确认，也能让探索效率与最终结论可靠性分工明确。

<a id="optional-stopping"></a>

### 6.5 反复查看、挑种子与隐形多重比较

若每得到一批数据就做一次固定样本检验，并在首次显著时停止，最终结论由多个时间点的并集触发。各次统计量虽相关，仍不能把每次百分之五水平直接当成整个停止程序百分之五。可事前固定终点，或使用经过设计的组序贯界、错误预算消耗、置信序列等工具。它们各有假设和效率代价，不能只在最终 p 上套一个随意因子替代设计。

挑选最有利训练种子、测试子集、指标定义或数据清洗规则，也会使最终报告依赖多个随机路径。若尝试过程未记录，很难知道应校正哪些比较。保留完整实验日志、预先固定主要指标、使用未参与选择的最终评估集，往往比事后猜测一个检验次数更可靠。探索结果仍可成为下一轮确认性研究的假设来源。

多重校正保护错误事件，却不能解决所有研究质量问题。一个小但系统的测量偏差在大样本下可以让全部方法都给出极小 p；同时校正之后，偏差仍在。检验错误控制必须与测量验证、抽样设计和目标定义共同使用。把校正名称当作质量印章，会忽略统计程序之外的识别环节。

<a id="sequential-likelihood-ratio"></a>

### 6.6 从似然比到随时有效的检验：完整构造与停止证明

反复查看的问题可以用一个明确构造解决。令 $X_t\in\{0,1\}$，$\mathcal F_{t-1}$ 表示第 $t$ 次观察前的全部信息，检验复合原假设 $E(X_t\mid\mathcal F_{t-1})\le p_0$ 对每个 $t$ 成立，其中 $0<p_0<1$。它允许结果相关，但要求每一步的条件成功概率都不超过门槛，不能用“长期平均不超过门槛”替代。事先选定 $q\in(p_0,1)$，定义证据过程

$$
E_0=1,\qquad E_t=\prod_{i=1}^t
\left(\frac q{p_0}\right)^{X_i}
\left(\frac{1-q}{1-p_0}\right)^{1-X_i}.
$$

为何这个乘积有效？记条件成功概率为 $\mu_t$，下一乘子的条件期望恰为

$$
\frac{1-q}{1-p_0}
+\mu_t\left(\frac q{p_0}-\frac{1-q}{1-p_0}\right)\le1.
$$

括号为正，将 $\mu_t\le p_0$ 代入即可得到上界一。因此 $E_t$ 非负，且 $E(E_t\mid\mathcal F_{t-1})\le E_{t-1}$，即非负检验超鞅。若真实数据独立同分布且成功概率恰为 $p_0$，等号成立，它也正是备择 $q$ 对原假设 $p_0$ 的似然比。这里从似然比推广到条件均值限制，必须经过上述条件期望检查。

规定首次达到 $1/\alpha$ 时拒绝，令该时刻为 $\tau$。对任意固定上限 $N$，有界停止时间给出 $E(E_{\tau\wedge N})\le1$；在事件 $\tau\le N$ 上该变量至少为 $1/\alpha$，故 $P(\tau\le N)\le\alpha$。让 $N$ 增大，得到 $P(\exists t:E_t\ge1/\alpha)\le\alpha$。这一步控制的是所有查看时刻的并集，而非每个时点分别百分之五；证明的一般框架可参阅 [Howard 等关于非负超鞅与时间一致界的论文](https://arxiv.org/abs/1808.03204)。

手算取 $p_0=0.5,q=0.75,\alpha=0.05$。每次成功乘 $1.5$，失败乘 $0.5$。连续六次成功的证据为 $1.5^6\approx11.391$，尚未达到二十；连续八次为 $25.629$，首次跨线可以拒绝。如果此前没有拒绝，累计八次成功和两次失败时证据只有 $1.5^8\times0.5^2\approx6.407$，不能只看成功数量。若已经按规则停止，则后续未实际收集的假想数据无需重新决定先前是否跨线；保证始终针对完整停止程序。

$q$ 决定对哪类备择积累证据较快，而非改变允许的错误水平。也可在观察 $X_t$ 之前根据过去选择 $q_t\in[p_0,1)$，逐步检查仍成立；看完当前结果再选有利的 $q_t$ 则破坏条件期望论证。分别尝试许多 $q$ 后取最大证据也不自动有效，预先固定权重的非负混合才保留超鞅性质。未跨线表示证据不足，不等于证明成功概率至多 $p_0$；这一单侧构造也不直接等同于双侧等效检验。

## 7. 相关与因果

<a id="correlation-mechanisms"></a>

### 7.1 一个相关系数容纳了多种机制

相关描述联合分布中的关联。观察到 $X$ 与 $Y$ 同时升高，可能因为 $X$ 影响 $Y$，也可能是 $Y$ 影响 $X$、共同原因影响两者，或筛选条件制造关联。温度同时影响冰淇淋销量与中暑，并不意味着购买冰淇淋导致中暑。相关系数对变量变换和异常值敏感，零线性相关也不代表一般独立，例如对称变量与其平方可以不相关却完全依赖。

因果目标通常涉及干预后的潜在结果，例如 $E[Y(1)-Y(0)]$。它与观察条件均值差 $E[Y\mid A=1]-E[Y\mid A=0]$ 只有在可交换性等识别条件下才相等。统计显著只能说明某个关联不容易用指定零模型解释，不能自动提供这些识别条件。更多样本能缩小关联估计误差，却不能仅凭规模消除混杂。

选择也能制造相关。若只观察“已经被录用的人”，录用同时依赖能力与人脉，则在入选人群中两者可能呈负关联，即使总体中独立。对共同结果或碰撞点进行条件化，会打开原本不存在的关联路径。分析中“控制更多变量”不总是更好，变量处于因果过程的什么位置很重要。完整图模型和识别方法留到因果推断主题，本章先建立不能跳步的意识。

<a id="simpson"></a>

### 7.2 分层与汇总为何可能反向

设两个难度层中，新方法成功率分别高于旧方法，但新方法被更多用于困难对象，汇总后成功率可能反而更低。汇总率是层内率的加权平均，而两组使用了不同权重；方向反转首先是数学上的加权结果。要决定应看汇总还是分层，需要目标总体与处理分配机制，不能单纯挑更符合期望的一种。

若层变量是处理前混杂因素，适当标准化可比较相同目标权重下的结果；若层变量是处理后的中介，条件化可能改变目标，甚至引入选择偏差。分层分析不是无条件正确的“去偏公式”。应先定义所需总效应、直接效应或特定人群效应，再决定变量用途。相关数据中的模型调整只有在连接假设下才具有因果含义。

AI 评测也会出现构成差异。一个模型在每个语言组内都更好，但评测集合的语言比例改变，整体得分就可能发生不同幅度变化。固定目标分布权重、同时报告重要分层和整体指标，有助于区分模型能力变化与样本构成变化。这属于估计对象管理，不能仅靠更复杂的显著性检验补救。

<a id="randomized-design"></a>

## 8. 随机实验的单位、依从与干扰

<a id="randomization-estimand"></a>

### 8.1 随机化保证什么，未保证什么

设固定有限总体中每个单位有潜在结果 $Y_i(1),Y_i(0)$。完全随机分配固定数量到处理组，在无干扰和处理定义一致下，组均值差对该总体平均处理效应无偏。随机性来自分配，而不是假设所有单位都从某个正态总体抽取。若还想推广到未来用户或另一地区，需要额外的抽样代表性与运输假设。

随机化使分配与处理前潜在因素在设计分布下独立，不保证一次实现中所有协变量完全平衡。可以通过分层、配对或合理的事前协变量调整提高精度。基线不平衡的存在不自动证明随机化失败，事后挑选“平衡好看”的子集却可能改变设计。应核查分配代码、执行日志和是否发生系统性脱组，而不是只根据几个基线 p 值判断。

处理后缺失可破坏观察数据的可比性。若新界面使不满意用户更早退出，而研究只比较完成问卷者，完成者集合已由处理影响。随机化的是最初分配，不是最终完成状态。应预先定义失访处理、收集缺失原因，并对无法由数据验证的假设做敏感性分析。随机化不会自动填补未观察结果。

<a id="cluster-interference"></a>

### 8.2 集群、网络干扰与实验污染

若同一家庭、班级或企业内部共享信息，个体处理可能影响他人结果。标准的每人一个处理潜在结果表示就不够，需要依赖整体分配或暴露映射。把整个集群随机化可以减少组间污染，但信息量主要受独立集群数量限制。每组只有两家企业、每家十万条记录，并不等价于几十万个独立随机化单位。

集群大小不等时，还要区分对集群等权的平均效应与对个体等权的平均效应。处理分配概率和目标权重可能需要进入估计量。简单把每个集群的平均数再等权平均，估计的是平均集群，不一定是平均个体。设计、估计对象与方差单位应一致，否则点估计与标准误可能分别指向不同问题。

在线平台还存在市场竞争和网络外溢。例如提高一部分卖家的曝光会减少其他卖家机会，处理组与对照组并非互不影响。用户级 A/B 的直接差异不一定等于全平台上线效果。可以考虑集群、地理或时间切换设计，但这些方案各自引入携带效应、时间趋势等问题。选设计时应先识别干扰路径，而不是默认随机化按钮已解决全部因果困难。

<a id="compliance-itt"></a>

### 8.3 分配效应、实际接受效应与依从

随机分配变量记为 $Z$，实际接受处理记为 $D$。比较随机分配组得到的意向处理效应描述“实施分配策略”的效果。若一部分被分配者未接受处理，直接按实际接受状态比较，可能将自我选择、健康状况或动机混入处理效应。删除不依从者也不能自动恢复随机性。

在工具变量框架下，若有相关性、排除限制、随机工具和单调性等条件，分配对结果的效应除以分配对接受率的效应，可识别依从者中的局部平均处理效应。这里的对象不是全体平均效应，条件也不是由随机分配一个动作全部保证。尤其排除限制要求分配仅通过实际处理影响结果，通知、期待或额外服务都可能使它失效。

实验报告最好同时写出分配、实际接受、分析纳入和结果观察四个流程。计数不一致时要解释来源。这样读者才能判断结论对应哪个策略、哪类人群，以及缺失或依从是否改变可识别对象。完整记录流程比事后给一个更复杂模型名称更有用。

<a id="variance-reduction"></a>

### 8.4 分层、协变量调整与控制变量的精度收益

处理前协变量若能预测结果，可用于分层随机化或事前指定的回归调整，以减少无关个体差异。在合适分析下，随机化保持因果识别，调整主要改善精度。使用处理后变量则不同：它可能是效应路径的一部分，也可能受到处理和潜在结果共同影响，应避免将其当成普通基线变量随意控制。

配对设计适合能够在处理前找到相似单位的情况；分析要保留配对。重复测量可使用基线变化或协变量调整，但“变化分数”与“基线调整”的效率取决于相关结构和模型条件。预先说明方法并用模拟评估方差，有助于避免看到哪个方法显著就报告哪个。若需要灵活机器学习调整，应关注过拟合、交叉拟合和相应推断理论。

减小方差并非唯一设计目标。过度狭窄的样本筛选可能提升内部精度，却损害外部适用性；复杂分层也可能增加执行错误。研究应平衡识别、精度、执行可行性与目标总体覆盖。一个统计上看似高效但无法稳定执行的设计，最终可能比朴素且透明的方案更差。

## 9. 完整小实验：随机化、功效与多重错误

<a id="permutation-code"></a>

### 9.1 八个单位的全部随机分配

下面假设八个单位中恰有四个接受处理，并以组均值差为统计量。为演示尖锐零假设检验，我们固定观察结果，枚举全部七十种允许分配。双侧极端性预先定义为绝对差值至少同样大；这个定义不必与所有软件默认的双侧规则相同，但它明确且可复核。

```python
import itertools
import math
import numpy as np

values = np.array([1., 2., 3., 4., 5., 6., 7., 8.])
observed_treatment = np.array([4, 5, 6, 7])
observed_control = np.array([0, 1, 2, 3])
observed = values[observed_treatment].mean() - values[observed_control].mean()
stats = []
for chosen in itertools.combinations(range(values.size), 4):
    treated = np.zeros(values.size, dtype=bool)
    treated[list(chosen)] = True
    stats.append(values[treated].mean() - values[~treated].mean())
stats = np.asarray(stats)
p_exact = np.mean(np.abs(stats) >= abs(observed) - 1e-12)
assert len(stats) == math.comb(8, 4) == 70
assert np.isclose(observed, 4.0)
assert np.isclose(p_exact, 2/70)
print("difference", observed, "assignments", len(stats), "two-sided p", p_exact)
# Under the sharp null, the rank-based p-value is valid over every assignment.
p_for_each_assignment = np.array([
    np.mean(np.abs(stats) >= abs(value) - 1e-12) for value in stats
])
for alpha in [0.01, 0.05, 0.10]:
    rejection_probability = np.mean(p_for_each_assignment <= alpha)
    assert rejection_probability <= alpha + 1e-12
    print("alpha", alpha, "exact size", rejection_probability)
```

这里处理组恰好拿到最大的四个值，观察差为四；另一个同样极端分配是处理组拿到最小四个值，故双侧 p 为二除以七十。百分之五水平下并没有恰好百分之五拒绝，因为有限分配集合使错误概率只能取特定离散值。代码还把每一种可能分配都视为观察分配，直接检查拒绝比例，从而验证 p 值在这个尖锐原假设下的有效性。

若实际设计是四个对子内各分配一个处理，则允许分配只有十六种，不应继续使用七十种跨对子分配。若实际存在非零且异质的个体效应，固定观测结果并重新分配不再对应原来的尖锐零假设世界。通过修改设计来观察这些区别，比只记住一个 `permutation_test` 函数名更能理解随机化推断。

<a id="power-code"></a>

### 9.2 从目标效应规划样本量并检验功效公式

第二段代码在已知标准误的正态模型下直接生成差值估计，不额外模拟每条个体观测。这是因为该模型已给出差值的精确分布，能用更少计算核验功效公式。代码同时展示同一个效应在样本量增大后更容易显著，和极小效应在大样本中也可以显著这两个事实。

```python
import numpy as np
from scipy.stats import norm

rng = np.random.default_rng(271828)
alpha, target_power = 0.05, 0.80
sigma, minimum_effect = 1.0, 0.30
z = norm.ppf(1 - alpha/2)
planned_n = int(np.ceil(2*sigma*sigma *
                (z + norm.ppf(target_power))**2 / minimum_effect**2))
print("approximate planned per-group n", planned_n)
for n, delta in [(50, 0.0), (50, 0.3), (planned_n, 0.3), (100_000, 0.01)]:
    se = sigma * np.sqrt(2/n)
    shift = delta / se
    exact_power = norm.sf(z - shift) + norm.cdf(-z - shift)
    estimates = rng.normal(delta, se, size=200_000)
    simulated = np.mean(np.abs(estimates/se) > z)
    mc_se = np.sqrt(exact_power*(1-exact_power)/len(estimates))
    assert abs(simulated-exact_power) < 6*mc_se + 1/len(estimates)
    print(n, delta, round(float(exact_power), 6), round(float(simulated), 6))
```

规划数字不是对实际研究结果的保证。方差设定错误、处理效应存在异质性、失访或多重主要指标，都会改变需要的规模。若样本来自集群设计，必须按设计方差重新规划。公式中的每组样本量也不是总样本量，两组相加才得到总数；这种简单的单位错误足以让功效规划偏离一倍。

<a id="multiple-code"></a>

### 9.3 在已知真假标签的模拟世界里计算 FWER 和 FDR

真实研究通常不知道哪些假设真，所以无法直接观察错误发现比例。模拟可指定真假，分别计算 FWER 与 FDR，检验多重程序实现。本段使用相互独立标准正态统计量生成有效双侧 p，满足所用 BH 保证的独立条件；不把这一结果推广到任意依赖结构。

```python
import numpy as np
from scipy.stats import norm

rng = np.random.default_rng(161803)
repetitions, m, m0, q = 30_000, 20, 15, 0.05
z = rng.normal(size=(repetitions, m))
z[:, m0:] += 3.0
p = 2*norm.sf(np.abs(z))
order = np.argsort(p, axis=1)
ordered = np.take_along_axis(p, order, axis=1)
rank = np.arange(1, m+1)
passes = ordered <= q*rank/m
last = np.max(np.where(passes, rank, 0), axis=1)
bh_sorted = rank[None, :] <= last[:, None]
bh = np.zeros_like(bh_sorted)
np.put_along_axis(bh, order, bh_sorted, axis=1)
bonferroni = p <= q/m
uncorrected = p <= q
for name, rejected in [("uncorrected", uncorrected),
                        ("Bonferroni", bonferroni), ("BH", bh)]:
    false = rejected[:, :m0].sum(axis=1)
    total = rejected.sum(axis=1)
    fwer = np.mean(false > 0)
    fdr = np.mean(false / np.maximum(total, 1))
    average_true = rejected[:, m0:].sum(axis=1).mean()
    print(name, "FWER", round(float(fwer), 6), "FDR", round(float(fdr), 6),
          "mean true discoveries", round(float(average_true), 6))
    if name == "Bonferroni":
        assert fwer < 0.06
    if name == "BH":
        assert fdr < 0.05
```

BH 使用最大通过秩的向量化实现，随后将排序状态映射回原假设顺序。错误数必须根据原始真假标签统计，若直接把排序前十五项当成真原假设，会把排序改变误认为科学标签改变。这个实现细节说明，数组轴、索引和统计对象必须对应；代码运行不报错不意味着计算了正确错误指标。

模拟中的容差检查只是宽松实现验证，理论保证来自有效 p 与独立条件。若把统计量改为相关结构，应先说明该结构是否满足所用定理；模拟偶然低于阈值并不能证明任意依赖都有效。也不应把“平均发现更多”解释成每一次研究都更好，随机发现数和错误比例在重复间仍有波动。

<a id="sec-6-1"></a>

### 9.4 把检验结论与决策代价分开

一份完整报告可依次写出目标效应、分配与分析单位、主要假设、方法条件、点估计及区间、多重或序贯安排，以及实际门槛。部署建议再结合资源成本、风险和可逆性。这样读者能够区分“统计证据反对某个原假设”和“整个行动值得实施”两种判断，而不需要从一个显著性星号猜测全部背景。

研究失败也应可解释。未显著时可以说明区间仍容许哪些重要效果，而非简单宣布无效；等效未成立时可以说明精度不足还是点估计偏离界限；多重校正后未保留时可以承认探索线索尚需确认。清楚描述证据范围，比把每个结果包装成肯定结论更有助于下一轮研究。

## 10. 练习与参考答案

<a id="exercise-pvalue"></a>

### 10.1 练习一：倒置条件概率

**问题。** 某检验 p 为零点零三，能否说新方法有百分之九十七概率更好？需要哪些额外信息才能讨论后验概率？

**解析。** 不能。p 将原假设作为条件，评价尾部数据事件；后验概率将数据作为条件，评价假设或参数事件。后者需要先验、原备择下的完整模型及相应似然。即使 p 很小，不同备择尺度与先验也可能给出不同后验。报告效应区间和实际门槛，能提供 p 以外的重要信息，但不能把置信覆盖也自动解释成后验概率。

<a id="exercise-direction"></a>

### 10.2 练习二：事后选择单侧方向

**问题。** 标准正态零效应统计量，看到正值就检验向上、负值就检验向下，每次单侧水平百分之五。实际第一类错误率是多少？

**解析。** 拒绝事件为 $Z>z_{0.95}$ 或 $Z<-z_{0.95}$，两尾互斥且各概率零点零五，合计零点一。方向是根据同一数据选择，因此不能沿用预定单侧程序的零点零五保证。预定双侧检验会使用更远的零点九七五分位数。这个例子没有任何计算误差，问题完全来自程序定义改变。

<a id="exercise-np"></a>

### 10.3 练习三：最强性到底针对谁

**问题。** 已知方差正态均值，向上单侧检验对正均值备择最强，是否因此也是双侧问题无条件最强检验？

**解析。** 不是。它把全部错误预算放在上尾，对负方向备择功效很差。Neyman–Pearson 定理针对指定简单备择，向上复合备择的推广依赖共同单调排序。双侧同时追求两个方向，通常需要其他限制或最优性准则。使用“最优”一词时应写清比较类、错误约束与备择范围，不能删除使定理成立的限定词。

<a id="exercise-permutation"></a>

### 10.4 练习四：均值相等能否任意置换

**问题。** 两组均值都为零，但一组方差一、另一组方差一百，样本量不等。原始均值差的标签置换是否有限样本精确？

**解析。** 一般不是。共同均值不保证观测分布相同，标签携带方差信息，原假设联合分布不对任意跨组交换保持不变。可以考虑与目标匹配的 Welch 方法或在额外条件下渐近有效的学生化置换，但不能保留“任意分布有限样本精确”的描述。精确检验需要明确的交换性或实际随机分配依据。

<a id="exercise-sharp"></a>

### 10.5 练习五：平均零不等于每人零

**问题。** 四个单位处理效应分别为一、一、负一、负一。平均效应为零，是否满足 Fisher 尖锐零假设？

**解析。** 不满足。尖锐零假设要求每个单位处理效应都为零，能够补齐全部潜在结果；本例只是正负效果抵消。用尖锐零假设构造的精确随机化检验，不应被称为对任何平均零异质效应配置都有限样本精确。若关注平均效果，需要相应平均效应估计与方差方法，并可另外研究异质性。

<a id="exercise-power"></a>

### 10.6 练习六：样本量与功效规划

**问题。** 两组已知共同标准差一，想以双侧百分之五水平检测零点三差异，目标功效百分之八十，近似每组需多少样本？若效果减半呢？

**解析。** 代入 $2(1.96+0.842)^2/0.3^2$，向上取整约为一百七十五。效果减半使分母变为四分之一，因此需要约四倍样本。数值是正态已知方差设计下的近似规划，应再检查完整功效，并考虑失访和多重主要指标。这里的每组数不能误当成总人数。

<a id="exercise-equivalence"></a>

### 10.7 练习七：未显著、等效与优效可以如何组合

**问题。** 等效界为正负一。三种百分之九十区间分别为负三到三、零点一到零点三、负零点四到零点四。哪些支持水平百分之五的两单侧等效检验？

**解析。** 第二、第三个完全位于界内，支持等效；第一个不支持。第二个还排除了零，但判断双侧百分之五优效需要匹配的百分之九十五区间或检验，不能直接沿用百分之九十区间。等效与非零差异可同时成立，因为实际微小差异也可以估得很精确。第一种宽区间反映证据不足，不是已经证明无差异。

<a id="exercise-bonferroni"></a>

### 10.8 练习八：为什么不要求独立

**问题。** 十个有效 p 值彼此相关，分别以零点零零五拒绝。是否仍能控制 FWER 为零点零五？

**解析。** 能。任意一次错误拒绝的概率不超过十个真原假设错误概率之和，最多零点零五。独立仅在把联合概率写为乘积时需要，联合界不需要。若 p 值因同一数据上的事后选择已经无效，联合界的单项上界前提就不成立；此时把阈值除以十不能自动恢复保证。

<a id="exercise-holm"></a>

### 10.9 练习九：Holm 停止位置

**问题。** 排序 p 为零点零零四、零点零二、零点零二一、零点零三，水平零点零五。Holm 拒绝哪些？

**解析。** 第一项与零点零一二五比较通过；第二项与约零点零一六七比较失败，程序停止，只拒绝第一项。不能因为第三项小于其后门槛零点零二五而跳过第二项继续拒绝。逐步下降的停止是保证的一部分，不是可随意删改的实现细节。

<a id="exercise-bh"></a>

### 10.10 练习十：BH 必须寻找最大通过秩

**问题。** 五个排序 p 为零点零一一、零点零一九、零点零二九、零点二、零点八，BH 的 $q=0.05$。第一项没过零点零一，是否应直接停止？

**解析。** 不应。第三项零点零二九小于零点零三，最大通过秩为三，因此拒绝前三项。BH 是逐步上升，与 Holm 第一次失败停止相反。是否具有 FDR 保证还需有效 p 及独立或相应依赖条件。实现排序规则正确与满足统计条件，是两道不同检查。

<a id="exercise-fdr"></a>

### 10.11 练习十一：FDR 不是逐次错误比例上界

**问题。** 某程序控制 FDR 在零点零五，一次研究拒绝二十项，能否保证其中至多一项错误？

**解析。** 不能。FDR 控制重复研究中错误比例的期望，并不逐次约束错误数或错误比例。有些研究可以超过百分之五，另一些低于，平均仍符合保证。也不能据此给每个发现赋予百分之九十五正确概率。若需求是高概率限制错误比例或控制至少一次错误，应选择不同错误目标及相应方法。

<a id="exercise-cluster"></a>

### 10.12 练习十二：随机化单位的伪重复

**问题。** 四所学校随机分成两组，每校一千学生。能否把四千学生当独立处理分配单位做普通两样本检验？

**解析。** 不能。处理在学校层分配，学生共享学校环境，且分配组合由学校数量决定。逐学生独立分析会夸大信息，标准误可能严重偏小。可根据学校级设计进行分析，但四个集群本身信息有限，不能通过在每校测量更多学生无限弥补。还应说明目标是平均学校还是平均学生，以及学校大小是否相同。

<a id="exercise-itt"></a>

### 10.13 练习十三：按实际接受处理比较

**问题。** 随机分配邀请参加课程，但只有积极性高的人参加。比较参加者与未参加者，是否保留随机实验因果解释？

**解析。** 不保留。实际参加与积极性相关，而积极性也可能影响结果，比较混入自选择。比较邀请分配组保留随机化，可估邀请策略效应；若想估实际课程效应，需要额外识别条件。工具变量比值在排除限制、单调性等条件下识别的通常是依从者局部效应，不能无条件推广到全体。

<a id="exercise-confounding"></a>

### 10.14 练习十四：相关显著是否解决混杂

**问题。** 一百万条观察记录显示使用某工具者成绩更高，p 极小，是否足以证明工具提升成绩？

**解析。** 不足。使用者可能在基础能力、资源和动机上不同。大样本缩小关联估计的随机误差，并不会消除系统混杂；它甚至可以使很小的混杂偏差高度显著。应考虑随机实验或可辩护的观察识别设计，明确控制变量的位置与未测混杂假设。显著性回答参考零模型下的兼容性，因果解释需要额外连接。

<a id="sec-7-1"></a>

### 10.15 边界追问：检验未显著能否证明两个方案等效

若差异估计为零、区间为负十到十，它同时容许大幅改善与大幅损害，不能支持实际相同。若实际容忍界只有正负一，研究尚未达到等效所需精度。正确报告可以说明“当前数据未排除重要差异”，并据此规划下一次研究；把未拒绝误写成没有效果，会抹掉区间中仍然存在的可能世界。

继续进阶时，可分别研究局部最强检验、不变性、选择后推断、序贯检验和干扰下的实验设计。它们并不是替代本章逻辑的神奇算法，而是在更复杂随机机制下重新定义目标、拒绝域和错误保证。始终追问“哪一种分布下、对哪一个事件、以什么概率保证”，能使繁多检验方法回到统一而清楚的框架。
