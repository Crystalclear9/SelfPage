## 1. 配对比较减少无关波动：先定义重复什么

<a id="stat4-detail-2"></a>

### 1.1 点估计之前先写估计对象

重采样不是给任意数字附上可信区间的自动包装。它试图用手头数据模拟某种重复实验，而重复实验的单位和统计程序决定了所得到分布的含义。本章围绕两个固定预测模型的比较展开，但所有结论都要先回答：未来重复的是测试对象、用户群组、时间段、训练样本，还是随机分组方案。若对象没有说明，再精细的分位数也无法补足解释。

设同一对象有模型损失 $`A_i`$ 和 $`B_i`$，定义改善差 $`d_i=A_i-B_i`$，正值表示模型乙损失较低。若独立对象是用户，目标可以是总体用户等权的 $`E[d_i]`$；若每用户记录数不同，目标也可以是随机一条记录的平均改善。两个量不相同。一个高活跃用户有上千条记录，另一个只有两条，按行平均会给予前者更高权重，按用户平均则各占一份。应先根据实际决策确定目标，再选择估计和重采样方法。

对于固定测试集的有限总体描述，平均差只是这批对象的确定性摘要，无须假装它本身还随机；若希望推广到同来源新对象，就需提出抽样机制。若关心重新训练整个算法的表现，测试对象抽样只是其中一层，训练数据和随机种子也可能变化。把这些目标分开不是繁文缛节，而是避免把“当前预测在当前总体的评价波动”误写为“学习算法以后每次运行都稳定领先”。

<a id="stat4-detail-3"></a>

### 1.2 三层随机性不能由一次 bootstrap 全部覆盖

第一层是评价抽样：模型已固定，换一批独立用户，分数会变化。第二层是训练随机性：相同训练数据下初始化、样本顺序或随机子采样改变，模型会变化。第三层是训练样本与选择流程：更换训练集、数据划分、超参数选择和检查点，最终模型也变化。普通固定预测的配对重采样通常只针对第一层，并条件在已经得到的模型上。

若希望评价第二层，可预先固定种子集合和训练协议，重复训练并在共同评价对象上比较。多个种子的结果仍共享训练数据和测试用户，不能把每个种子乘每个用户的所有单元都当作独立观察。若研究第三层，应把选择与拟合一起放进外层重复，评价数据独立于每一轮选择。计算成本会增加，但这是目标本身包含更多随机来源的结果，不是把重采样次数从一千改成一万就能替代的。

报告应说明区间条件在什么信息上。可写“对已训练并冻结的两个模型，按用户等权评价，并对独立测试用户作配对重采样”；也可写“按预先固定的外层训练评价协议重复全部流程”。这两种区间都可能有用，但回答不同问题，宽窄不能直接作为方法好坏的比较。较窄的条件区间未必覆盖更广的算法不确定性。

<a id="sec-1-1"></a>

<a id="stat4-detail-4"></a>

### 1.3 基础算例：配对差值与独立差值的手算比较

同三次任务，模型甲损失为三、五、七，乙为二、四、六，差值恒为一。任务难度引起的共同波动在差中抵消。若分别抽取两组索引，某次可能抽到甲的困难任务与乙的容易任务，差异就混入对象组成的变化。这个分布对应另一个独立两样本实验，不能因为实现方便就把它当作同对象比较的正确抽样波动。

一般有 $`\operatorname{Var}(A-B)=\operatorname{Var}(A)+\operatorname{Var}(B)-2\operatorname{Cov}(A,B)`$。若两模型常在同一难例上同时受挫，协方差为正，配对可减少方差；若协方差为负，配对差反而可能更波动。保留配对的理由首先是忠实于实验结构，不是为了强行获得更窄区间。并非任何数据都该配对，人为把不同用户按行号拼接也不会创造有效匹配。

<a id="deep-dive-1"></a>

<a id="stat4-detail-5"></a>

### 1.4 从协方差到精度：自然配对与设计配对

自然配对指同一对象被两个固定模型同时预测，两列结果天然相联；设计配对则可能是把相近对象组成区组，再在组内随机分配处理。二者都可利用共同难度，但统计实验不同。自然配对并未随机化模型训练过程，也未识别现实中用户接受某种干预后的因果效应；设计配对则需明确处理分配、潜在结果与是否有携带效应。不要仅凭表格有两列便混用两套推断理由。

对独立同分布对象，平均差的方差为 $`\frac{\operatorname{Var}(d)}{n}`$，可由差值样本方差估计。此时配对重采样是直接重采差值，也等价于共同抽对象索引再读取两列损失。对非线性指标，如两模型总体准确率之比、相关系数差或排序指标差，应在每轮重新执行原统计程序，而不是随便构造逐行差后取均值。能否压成差值向量取决于目标统计量的代数结构。

## 2. 一个均值差的重采样实验：经验分布到底近似什么

<a id="sec-2-1"></a>

<a id="stat4-detail-7"></a>

### 2.1 一轮 bootstrap 不是重新测量世界

独立同分布观察 $`Z_1,\ldots,Z_n`$ 对应经验分布 $`P_n=n^{-1}\sum_i\delta_{Z_i}`$。普通非参数 bootstrap 条件在原数据上，从 $`P_n`$ 独立抽取 $`n`$ 次，得到重采样数据，再用同一统计函数求 $`\hat\theta^*`$。一轮允许重复和遗漏，不能去重，也不能把只抽一次不放回的排列当作同一种方法；后者对样本均值根本不会产生波动。

理想目标是让条件分布 $`\sqrt n(\hat\theta^*-\hat\theta)`$ 近似真实重复实验中 $`\sqrt n(\hat\theta-\theta)`$ 的分布。这里不是声称经验分布等于真实总体，而是在适当稳定性条件下，用经验分布的小扰动模拟统计量对真实抽样扰动的响应。中心化和尺度非常重要：原始重采样估计围绕当前估计变化，真实估计围绕未知参数变化，构造区间时要把这两个中心的关系处理正确。

<a id="stat4-detail-8"></a>

### 2.2 均值为何是一个适合入门的对象

对差值均值，重采样条件期望恰为 $`\bar d`$，条件方差为 $`n^{-1}[n^{-1}\sum_i(d_i-\bar d)^2]`$。它与常用样本方差除以样本量相差有限样本分母因子，但在样本增加时渐近一致。若原差值具有有限正方差，独立同分布中心极限定理给真实标准化均值的正态极限，经验分布版本在适当条件下也有同一极限，这解释了普通均值 bootstrap 的一阶合理性。

关键不是“均值总能放心重采样”。若差值重尾到没有有限方差，经典平方根样本量尺度可能不再适用；若只有极少数独立用户，经验分布无法充分表现尾部；若结果本身是某个训练搜索过程中被选中的最大改善，稳定均值理论也不能自动覆盖完整选择流程。总要明确你重采样的是原始独立单位上的哪个统计函数。

一个样本容量为六的课堂演示可展示索引机制，却不能提供可靠的一般覆盖保证。观察到某类事件零次，不意味着该事件真实概率为零；经验分布只能在已观察支持上抽样，无法自己发明未出现的人群或罕见故障。更多重采样轮次会更精确地计算当前经验世界的答案，不会把这个世界扩展为未观测的真实世界。

## 3. 配对 bootstrap 的计算过程与四种区间

<a id="stat4-detail-10"></a>

### 3.1 百分位区间和基本区间不是同一个反演

记重采样估计分位数为 $`q^*_{\gamma}`$。百分位区间为 $`[q^*_{\frac{\alpha}{2}},q^*_{1-\frac{\alpha}{2}}]`$；基本区间为 $`[2\hat\theta-q^*_{1-\frac{\alpha}{2}},2\hat\theta-q^*_{\frac{\alpha}{2}}]`$。前者直接把重采样估计分布当作参数分布式的反演，后者先近似估计误差分布再反解未知参数。频率学解释依然是重复抽样覆盖，不应因为画出了一个分布就称为参数后验。

若分布近似对称且中心接近当前估计，两种区间可能很相近；偏斜或偏差较大时可明显不同。基本区间对参数尺度的变换一般不具有百分位法那样的单调变换对应性；百分位法的变换便利也不保证小样本覆盖正确。若参数限定非负，基本区间可能越界。

将区间与已知参数域取交，可以使报告满足范围要求；对域内真参数，取交前后包含真值的事件严格相同，因此不会改变它的覆盖率，也不会修复原有的覆盖不足。其他端点移动、强制非空或重新居中规则可能改变覆盖，应分别说明，不能把它们都笼统称为无影响的截断。

<a id="stat4-detail-11"></a>

### 3.2 Studentized：为误差提供自己的局部尺度

若原统计量有标准误估计 $`\hat s`$，每个重采样样本也能估 $`\hat s^*`$，可构造 $`T^*=\frac{(\hat\theta^*-\hat\theta)}{\hat s^*}`$。用其分位数反演得到 $`[\hat\theta-q^*_{T,1-\frac{\alpha}{2}}\hat s,\hat\theta-q^*_{T,\frac{\alpha}{2}}\hat s]`$。局部尺度能适应估计精度随参数或样本组成变化，某些正则问题中可改善近似，但代价是每轮都必须有可信的标准误。

对于独立差值均值，重采样标准误可直接用当轮样本标准差除平方根样本量，不需内层重采样。对于复杂统计量，可能要解析影响函数、删除法或嵌套重采样，计算和稳定性成本都更高。若某轮样本全部相同，标准误为零，学生化分母失效；不能无声丢掉这些轮次并仍声称使用原定方法。应调查统计量与样本容量，必要时更换设计或明确处理规则，并承认其带来的改变。

<a id="stat4-detail-12"></a>

### 3.3 BCa：偏差校正与加速度的计算含义

BCa 用 $`z_0=\Phi^{-1}\{P^*(\hat\theta^*<\hat\theta)\}`$ 描述重采样分布中当前估计所处的位置。再由删除一个独立单位的估计 $`\hat\theta_{(-i)}`$，令其平均为 $`\bar\theta_{(-)}`$，计算加速度

$$
a=\frac{\sum_i(\bar\theta_{(-)}-\hat\theta_{(-i)})^3}
{6[\sum_i(\bar\theta_{(-)}-\hat\theta_{(-i)})^2]^{\frac{3}{2}}}.
$$

把名义概率 $`\gamma`$ 改为 $`\Phi[z_0+\frac{(z_0+z_\gamma)}{(1-a(z_0+z_\gamma))}]`$，再取重采样分位数，即得到对应端点。$`z_0`$ 不是原估计偏差的直接数值估计，加速度也不是随意调节的超参数；它们反映局部偏斜及尺度变化，在光滑、正则条件下才有近似理论支持。

对于样本均值，加速度可以化成更容易理解的式子。因为 $`\hat\theta_{(-i)}=\frac{(n\bar x-x_i)}{(n-1)}`$，且 $`\bar\theta_{(-)}=\bar x`$，所以 $`\bar\theta_{(-)}-\hat\theta_{(-i)}=\frac{(x_i-\bar x)}{(n-1)}`$。分子、分母的三次尺度因子消去，得到

$$
a=\frac{\sum_i(x_i-\bar x)^3}{6[\sum_i(x_i-\bar x)^2]^{\frac{3}{2}}}.
$$

它与样本偏斜有关，却不是直接把常用偏度数值代入：若用分母 $`n`$ 定义经验二阶、三阶中心矩，$`a`$ 等于对应标准化偏斜除以 $`6\sqrt n`$。例如数据 $`(0,1,5)`$ 的均值是二，中心化值为 $`(-2,-1,3)`$，平方和十四、立方和十八，故 $`a=\frac{18}{(6\times14^{\frac{3}{2}})}\approx0.05727`$。删除均值分别为三、二点五、零点五，代入原定义给出同一个结果。这只是核对公式的三点算例，不能据此认为三点样本足以获得可信的高阶覆盖保证。

端点换算也应分步骤：先确定名义尾概率 $`\gamma`$，转成正态分位数 $`z_\gamma`$，再用 $`z_0,a`$ 转成新的尾概率，最后到原来的 bootstrap 统计量分布中取分位数。它不是把标准误乘一个修正系数，也不是把重采样值逐个变成正态。若 $`a=z_0=0`$，校正尾概率恰回到 $`\gamma`$，BCa 才退回普通百分位区间。对于很偏的情况，校正尾部可能极端，有限重采样次数未必有足够分辨率；这时增加轮数只能改善分位数的计算，并不能替代统计正则性。

若重采样统计量退化，严格小于的比例可能为零或一，正态反变换发散；若删除估计完全相同，加速度分母为零。最大值、边界概率和小样本离散统计量都可能暴露问题。不能把无穷大机械截成漂亮数字后宣布区间有效。[SciPy 的 bootstrap 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)提供这些区间选项并提醒退化情况；接口帮助执行方法，适用性仍须由独立单位、统计量正则性和数据结构判断。

<a id="stat4-detail-13"></a>

### 3.4 重采样次数是计算精度，不是新证据

设某尾部真实条件概率为零点零二五，用一万轮估计该概率的蒙特卡洛标准误约为 $`\sqrt{0.025\times\frac{0.975}{10000}}\approx0.00156`$。这意味着尾端分位数仍有计算波动；分位数值本身的误差还受该位置密度影响。可预先设定轮数，或用独立随机流检查端点稳定性，但不能不断换种子直到区间不跨零。

原始样本不变时，增加轮数只使条件重采样分布计算得更精确，不会减少真实抽样误差。十名用户重采一百万次仍只有十名用户的信息。若计算预算有限，先保证重采样单位、统计量和流程正确，再提高轮数；错误的独立性结构计算得再精细，也只是更稳定地产生错误的不确定性。

## 4. Bootstrap 一致性并非无条件：三个失败机制

<a id="stat4-detail-15"></a>

### 4.1 最大值：经验分布的边界会被当成总体边界

设独立样本来自 $`\operatorname{Uniform}(0,\theta)`$，估计参数为最大值 $`M_n`$。真实最大值总小于 $`\theta`$，且 $`\frac{n(\theta-M_n)}{\theta}`$ 收敛到指数分布。普通非参数重采样只能抽原观察，所以 $`M_n^*\leq M_n`$。其等于原最大值的条件概率为 $`1-(1-\frac{1}{n})^n`$，趋近 $`1-e^{-1}`$，有一个不会消失的点质量。

真实标准化估计误差的极限在零处没有这样一个原子，普通同样本量重采样因此不能在正确尺度上复制极值的分布。更直接地，普通百分位区间的上端不可能超过原最大值，而真实上界 $`\theta`$ 几乎必然更大，因此该区间对上界参数的覆盖为零。这是结构性失败，增加轮数也不会修复。它同时说明：某种 bootstrap 在均值上有效，不能靠名称推广到任意统计量。

若可信地知道均匀分布族，可以直接利用最大值的精确分布，或者研究适合边界和极值的专门方法；若只知道很宽泛的总体条件，需要另外的尾部假设。少取样本的重采样和子抽样可能在相应条件下修复某些非正则问题，但尺度、样本大小序列和目标分布都要重新证明，不能只把每轮抽取数量随手减半。

<a id="stat4-detail-16"></a>

### 4.2 非光滑：并非有绝对值就必坏，也非可计算就正则

样本中位数不是处处可微的有限样本函数，但若总体在目标分位点附近有连续正密度，仍有合适的渐近线性表示，普通 bootstrap 可在相应条件下工作。真正关键是统计泛函相对于总体扰动的稳定性，而不是代码里有没有排序、分支或绝对值。把“非光滑都失败”作为口诀，会误伤大量合理方法。

相反，估计 $`\theta=\vert \mu\vert `$，用 $`\vert \bar X\vert `$ 插值时，在真实均值为零处映射发生尖点。平方根样本量尺度的极限涉及绝对正态，重采样会围绕一个随机偏移的当前均值展开，不能不加分析地沿用普通光滑 delta 方法。类似地，取多个模型分数的最大值、在约束边界投影、选择最优检查点都可能引入局部不规则性。应研究目标处的局部行为，而不是看统计量有现成 API 就默认正则。

<a id="stat4-detail-17"></a>

### 4.3 稀有事件与依赖：经验分布缺了什么

若真实故障概率为正而样本中零次故障，普通非参数 bootstrap 的每轮故障率都是零，区间会退化。它准确复现了经验分布没有故障的事实，却不能证明真实概率为零。应根据二项模型、单侧界或合适的事件率设计评估上限，同时说明独立试验与记录窗口条件。真正风险来自未观察尾部时，保留模型不确定性比把退化输出包装成极高确定性更诚实。

若观察存在时间或群组依赖，逐行重采样又会破坏联合结构。即使每个边际分布都近似正确，均值方差还含跨观察协方差。具有正相关的重复记录常使逐行区间过窄，但若负相关占主导，也可能出现不同方向。因此应从生成机制选择保持结构的方案，不能把“逐行一定低估”说成无条件定理。

## 5. 重采样必须保持原实验的配对、层级与时间结构

<a id="stat4-detail-19"></a>

### 5.1 用户等权和记录等权的群组重采样

每用户有 $`m_i`$ 条记录，用户内平均改善为 $`\bar d_i`$。用户等权估计为 $`G^{-1}\sum_i\bar d_i`$；记录等权估计为 $`\frac{\sum_i m_i\bar d_i}{\sum_i m_i}`$。若独立抽样单位是用户，两者都应抽用户，但每轮统计函数不同：前者平均抽中用户的均值，后者同时携带记录数并重新计算总改善除总记录数。不要固定原分母后仅重采分子，否则已改变原估计程序。

重采到某用户两次意味着其整组记录和权重出现两次，不应合并成一个唯一用户。若群组大小与结果相关，两个目标量可显著不同；这不是算法偏差，而是评价权重不同。若总体抽样是先抽用户再在用户内随机抽记录，并希望同时反映两层抽样误差，可能需要层级重采样。每一层是否重采，取决于原实验如何随机产生这些层，不能为了“更全面”机械添加重复。

<a id="stat4-detail-20"></a>

### 5.2 时间块与前向评价

时间序列通常不能把一天内或相邻时刻当作可任意交换的独立点。块重采样通过抽取连续片段保留部分局部相关；移动块、循环块和随机长度块的边界处理不同。块长太短会丢失较长依赖，太长则可用独立块数减少。适用理论常要求平稳性、弱依赖与随样本增长的合适块长，而非任意漂移时间序列都能被同一种块方案解决。

若任务是预测未来，评价数据的时间顺序本身属于目标。对全序列任意打乱后训练与测试，会让未来信息进入过去。应使用符合部署情形的前向划分，并把特征计算、归一化和模型选择限制在对应训练窗口。对已生成的前向损失序列做块重采样，只研究相应评价波动，不能倒过来补救原先泄漏的训练流程。

## 6. 置换检验与随机化推断：相似算法，不同依据

<a id="stat4-detail-22"></a>

### 6.1 交换性决定哪些标签可以打乱

独立两样本置换检验在两组总体分布相同的零假设下，合并观察的组标签具有交换性。固定每组容量，枚举或随机抽取标签分配，计算统计量的零假设分布。若零假设仅为均值相同，但两组方差或分布不同，原始均值差的普通置换分布一般不再给出精确有限样本检验，特别是组大小不平衡时。适当学生化可在额外条件下恢复渐近有效性，仍不能声称获得无条件精确性。

配对观察的置换可以在每对内部交换标签，等价于对差值变号，但需要相应交换性。若只是观察性同对象模型损失，均值差为零不保证差值分布关于零对称，因此不能单凭零均值便随意使用精确符号翻转检验。若实验设计真的在每对中随机分配处理，则可由分配机制支持另一种精确推断，见下一小节。

<a id="stat4-detail-23"></a>

### 6.2 随机化推断条件在潜在结果上

在处理随机分配实验中，随机性来自已知的分配机制。尖锐零假设声明每个单位的处理结果都不变，因此可用已观察结果填补所有分配下的结果，重新按照原设计生成分配，计算统计量分布。完全随机设计、区组随机设计和群组随机设计的允许分配集合不同，不能统一用全表任意打乱标签。处理概率不等时还需保留分配概率，不能默认所有方案等可能。

尖锐“每个人都没有效应”与平均效应为零不是同一个零假设。正负个体效应抵消时，平均为零但尖锐假设为假；后者被拒绝不必然意味着平均改善为正。若存在用户间干扰，潜在结果还依赖他人分配，简单单位级零假设与重分配逻辑都要调整。随机化给予强有力依据，但依据来自真实设计，不能由观察数据表的标签形式事后创造。

<a id="stat4-detail-24"></a>

### 6.3 精确枚举、随机枚举与双侧尾部

小型配对设计有 $`2^n`$ 种组内交换，可精确枚举。双侧统计量可选绝对均值差，精确概率是允许分配中统计量至少与观察值一样极端的比例，平局应计入。若只能随机抽取 $`B`$ 个合法分配，常用加一校正 $`\frac{(b+1)}{(B+1)}`$，将观察安排纳入比较并避免报告零概率；它不是把观测证据增加一条，而是校准蒙特卡洛检验程序。

非对称零分布下，双侧尾部可有不同定义，不能把“两倍较小单侧概率”与绝对统计量尾部总当成同一个数。[SciPy 的置换检验文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html)区分独立样本、配对标签和配对排列。使用工具前应先把你的合法变换集合写成一句话，再核对接口执行的是否恰为这个集合。随机种子和枚举次数也是报告的一部分，但它们不能替代交换性或设计依据。

<a id="visual-extension-statistics-04"></a>

## 7. 实验前固定决策：选择、停止和外部评价

<a id="stat4-detail-26"></a>

### 7.1 交叉验证折不是独立实验重复

交叉验证的多个训练集高度重叠，不同折的评价对象虽可不重叠，预测模型却共享大量训练数据。将折分数的样本标准差除以折数平方根，通常不能自动成为学习算法泛化性能的有效标准误。重复交叉验证也共享原始观察，重复次数增加不会带来同数量的新总体样本。应说明想估计的是给定数据的划分敏感性，还是训练样本改变后的风险波动。

若超参数通过验证选择，再报告相同验证分数，会出现选择乐观。嵌套评价把搜索放进每个外层训练部分，只在外层未参与选择的数据上评价完整流程。所有预处理、特征筛选和阈值选择也要包含在内层，不能只有模型拟合使用内层而归一化先看完整数据。外层折分数仍有依赖，嵌套过程解决的是选择泄漏问题，不会自动给出任意简单的独立折标准误公式。

<a id="stat4-detail-27"></a>

### 7.2 最小有意义差异与固定停止规则

实验前应确定主要指标、改善符号、目标人群、独立单位和最小有意义差异 $`\delta`$。区间完全高于零表示某种方向证据，完全高于 $`\delta`$ 才支持达到预设实际收益；区间完全位于很小的实用无差范围，又是等效性问题。三种结论不能仅靠“显著”一个词概括。区间跨零或跨实际阈值时，应分别说明当前无法排除的情况。

固定样本分析如果反复中途查看，并在最有利的一次停止，原定错误率或覆盖通常被改变。应事先规定观察窗口与停止规则，或者使用明确支持连续监测的序贯方法。不能在报告中仅给最终样本量而隐藏中途看过多少次。同样，先看许多指标再挑最漂亮的一项作为主要指标，也让原本固定目标的区间不再描述整个选择流程。

<a id="stat4-detail-28"></a>

### 7.3 从探索发现到确认性证据

探索有助于发现异质人群、诊断失配和提出机制，但应保留探索标签。若发现某类用户收益特别大，可在新数据中预先固定该分组与指标，再确认其稳定性。若对同一数据重复试验各种分组、重采样单位和区间方法，只挑支持结论的一种，会产生隐蔽的多重选择。保留分析计划和版本变更比事后仅展示一段可运行代码更能说明结论的可信范围。

外部评价数据也不是永久有效的无限查询源。每次依据其结果改变模型，它就参与了选择；最终普通固定模型区间不再覆盖全部自适应过程。可以设置真正封存的最后评价集、预先限定比较数量，或采用专门的自适应评价方案。一次干净的外部确认通常比把同一份基准重复重采样许多轮更接近所需证据。

## 8. 专题实验：配对结构如何改变差异区间

<a id="stat4-detail-30"></a>

### 8.1 用户级配对重采样与多种区间的独立实现

下面模拟八十名独立用户。每用户同时给两个冻结模型提供损失，用户难度是共同项；独立单位为用户，目标为用户等权平均改善。程序在同一轮共同抽取用户，分别计算百分位、基本、学生化和 BCa 区间，再用错误的独立抽取演示协方差丢失。这里没有用户内多记录，也没有重新训练，恰好只展示固定预测评价这一层。

```python
import numpy as np
from scipy.stats import norm
rng = np.random.default_rng(20261016)
n, B = 80, 20000
difficulty = rng.normal(0., 2., n)
a = 10. + difficulty + rng.normal(0., .35, n)
b = 9.7 + difficulty + rng.normal(0., .35, n)
d = a - b
estimate = d.mean()
idx = rng.integers(0, n, size=(B, n))
boot = d[idx].mean(axis=1)
q = np.quantile(boot, [.025, .975])
basic = 2. * estimate - q[::-1]
se = d.std(ddof=1) / np.sqrt(n)
se_star = d[idx].std(axis=1, ddof=1) / np.sqrt(n)
assert np.all(se_star > 0.)
t_star = (boot - estimate) / se_star
studentized = estimate - np.quantile(t_star, [.975, .025]) * se
jack = (d.sum() - d) / (n - 1)
u = jack.mean() - jack
accel = np.sum(u**3) / (6. * np.sum(u**2)**1.5)
prop = np.mean(boot < estimate)
assert 0. < prop < 1.
z0 = norm.ppf(prop)
z = norm.ppf([.025, .975])
adjusted = norm.cdf(z0 + (z0 + z) / (1. - accel * (z0 + z)))
assert np.all((adjusted > 0.) & (adjusted < 1.))
bca = np.quantile(boot, adjusted)
idx_b = rng.integers(0, n, size=(B, n))
wrong = (a[idx] - b[idx_b]).mean(axis=1)
print('estimate', estimate, 'standard error', se)
print('percentile', q, 'basic', basic)
print('studentized', studentized, 'BCa', bca)
print('paired/unpaired SD', boot.std(ddof=1), wrong.std(ddof=1))
assert boot.std(ddof=1) < wrong.std(ddof=1)
```

这段实现显式检查学生化和 BCa 所需分母，避免静默忽略退化轮次。四种区间相近只表明当前数据规模、分布和统计量下近似差异较小，并不证明它们在重尾、稀有事件或选择后同样可靠。独立抽取分布更宽来自本例正相关结构；若把共同难度项改成相反方向，宽度关系也可逆转，但正确方案仍是忠实保留实际配对。

<a id="stat4-detail-31"></a>

### 8.2 一个可精确枚举的配对随机化检验

下面假定六个独立配对区组，每组内部通过公平随机分配决定两种处理标签，并检验每个单位均无处理效应的尖锐零假设。此设计允许六个差值分别变号。枚举所有六十四种分配，用绝对平均差作为双侧统计量，计算精确尾部比例。若把数据解释成仅有零均值的观察性差值，程序虽然还能运行，精确设计依据就不再存在。

```python
import itertools
import numpy as np
d = np.array([2., 1., -1., 3., 2., 1.])
signs = np.array(list(itertools.product([-1., 1.], repeat=d.size)))
null_stats = (signs * d).mean(axis=1)
observed = abs(d.mean())
p_exact = np.mean(np.abs(null_stats) >= observed - 1e-12)
print('mean difference', d.mean(), 'exact two-sided p', p_exact)
assert signs.shape == (64, 6)
assert np.isclose(null_stats.mean(), 0.)
assert 0. < p_exact <= 1.
```

精确表示枚举完整合法分配分布，而非结果必然显著。样本小导致可取得概率值离散，不能通过加更多随机枚举轮次获得原设计没有的分辨率。尖锐零假设下的概率也不直接等于改善均值大于某阈值的可信概率。要报告平均效应区间或实际收益判断，还需要相应估计与反演目标，不能从一个双侧概率值推导所有结论。

<a id="stat4-detail-32"></a>

### 8.3 用极值反例检查百分位法的结构失败

下面反复生成均匀分布样本，再为每批样本构造最大值的普通百分位区间。由于任何重采样最大值都不超过原最大值，上端必然低于真实上界一，覆盖率严格为零。这个测试没有证明所有 bootstrap 都失败，而是把前面已经解析得到的边界问题变成可运行的反例。程序的断言检验的是确定性支持关系，不依赖碰巧抽到某个有利随机种子。

```python
import numpy as np
rng = np.random.default_rng(21)
n, repetitions, B = 40, 300, 500
covered = 0
for _ in range(repetitions):
    x = rng.uniform(0., 1., n)
    idx = rng.integers(0, n, size=(B, n))
    stars = x[idx].max(axis=1)
    lo, hi = np.quantile(stars, [.025, .975])
    assert hi <= x.max() < 1.
    covered += lo <= 1. <= hi
print('percentile coverage for uniform upper endpoint', covered / repetitions)
assert covered == 0
print('bootstrap atom at observed max', 1. - (1. - 1. / n)**n)
```

如果把该例的百分位区间强制改成包含一，就已使用知道真实上界的信息，不能称为对未知参数的通用修复。若改用均匀族的参数方法，应明示模型假设，并在模型可能不均匀时做敏感性研究。反例的学习重点是寻找为什么经验世界无法复制真实误差，而非简单记住某个方法名称永远安全或永远危险。

## 9. 写出可审查结论：统计报告也是方法的一部分

<a id="stat4-detail-34"></a>

### 9.1 报告要让别人能够重建分析对象

报告首先写总体与时间窗口、纳入排除规则、独立用户数和记录数、指标的计算层级以及缺失处理。其次写模型是否冻结、是否曾依据评价结果调整、差值正负代表谁更好。再写重采样单位、是否保留配对、每轮完整统计函数、区间类型、轮数和随机流。最后将点估计、区间和最小有意义差异放在同一单位下解释，而不是只突出是否跨零。

例如“改善零点二，区间负零点五到零点九”说明当前估计偏向改善，但仍与一定退步和更大改善相容。若实际收益阈值为零点一，当前区间既不能确认方向，也不能确认达到实际收益。不能把它写成“两者没有区别”，因为没有足够证据支持改善不等于证明差异足够小；要宣称实用等效，需要围绕预先定义容忍范围开展适当分析。

<a id="stat4-detail-35"></a>

### 9.2 解释范围、敏感性与可复现性

敏感性分析应围绕真实争议：用户等权与记录等权针对不同部署目标，是否排除某类数据改变了目标总体，块长变化影响对依赖的保持，极端损失处理是否对应业务计分规则。每一种变化都应明确其理由，不能罗列大量方案后只保留最支持结论者。主分析与探索分析分开报告，才可能把方法比较当作学习，而不是隐蔽的结果选择。

可复现不只是给一个种子。还要记录数据版本、统计量定义、预处理范围和软件接口语义。代码独立运行可以证明某组数字能被重算，但不能证明数据具有代表性或实验随机化执行无误。若报告依据的是固定模型测试重采样，结论末尾应保留该条件；若存在训练或群组层面的未覆盖随机性，应说明下一轮需要怎样的实验补足。

<a id="stat4-detail-36"></a>

## 10. 练习与逐步解析：从单位选择到失效反例

<a id="stat4-detail-37"></a>

### 10.1 练习一：共同索引的手算

**题目：** 三对损失甲为一、四、五，乙为二、二、四，按零起始索引二、二、零重采一次，平均改善是多少？能否去除重复索引？

**解析：** 差值依次为负一、二、一，重采后为一、一、负一，均值三分之一。重复抽到的对象必须重复计入，因为这是有放回经验抽样。去重会改变样本量与权重，已不再模拟规定的抽样程序。若两列分别用不同索引，则混入对象构成差异，估计的是另一个实验的波动，不能仍称为保留配对。

<a id="stat4-detail-38"></a>

### 10.2 练习二：配对一定让区间变窄吗

**题目：** 两模型单对象损失方差均为四，协方差分别考虑三和负三。求配对差方差，并与误当独立的计算比较。

**解析：** 配对差方差为八减两倍协方差，两个场景分别为二和十四。误当独立都得到八。可见忽略配对既可能放大也可能缩小波动，方向取决于协方差。正确保留结构的理由不需要观察到窄区间才成立；它忠实表示同对象实验。若真实本来是独立两组，则也不能靠硬配对来消除本不存在的共同难度。

<a id="stat4-detail-39"></a>

### 10.3 练习三：百分位与基本区间

**题目：** 当前估计为二，重采样百分之二点五和九十七点五分位为一点四和二点九，求两种区间，并说明差异从哪里来。

**解析：** 百分位区间直接为一点四到二点九；基本区间为四减二点九到四减一点四，即一点一到二点六。基本法反演的是重采样估计相对当前估计的误差，因此分位顺序颠倒后反射。偏斜和偏移使结果不再一致，不能随意挑更有利的一种作为主要结果。选择区间方式应依据统计量和计划，并在必要时做覆盖模拟，而不是看哪一种更容易跨过实际阈值。

<a id="stat4-detail-40"></a>

### 10.4 练习四：学生化端点的方向

**题目：** 当前估计二，标准误零点四，重采样学生化统计量两端分位为负二点五和一点八，求区间。

**解析：** 下端是二减一点八乘零点四，得到一点二八；上端是二减负二点五乘零点四，得到三。反演时需要交换尾部，不能照原顺序直接相加。该方法要求每轮重采样标准误本身有统计意义；若分母经常接近零，极端学生化值可能主导端点，应检查原样本、统计量和重采样单位，不能简单删除难看的轮次。

<a id="sec-8-2"></a>

<a id="stat4-detail-41"></a>

### 10.5 练习五：逐行 bootstrap 在重复记录上是否合适

**题目：** 每用户有一百条几乎相同记录，共三十名用户，逐行抽三千条会把什么当作独立信息？增加到一百万轮能否修复？

**解析：** 逐行方案把同一用户的近似复制视作可独立替换的观察，破坏共同用户效应，常在正相关下严重低估不确定性。应依据目标和真实抽样单位抽取用户并携带整组记录；若目标为记录等权，还要每轮重新计算加权分母。一百万轮只降低对错误经验实验的计算误差，不能创造更多独立用户。三十组是否足够，还需看分布、权重与所用近似。

<a id="stat4-detail-42"></a>

### 10.6 练习六：用户等权和记录等权

**题目：** 两用户改善均值分别为一和负一，记录数分别为一和九，求两种目标的样本估计，并说明群组重采样如何实现。

**解析：** 用户等权为零，记录等权为 $`\frac{(1-9)}{10}=-0.8`$。若用户是独立抽样单位，两种方案都抽用户，但前者对抽中的用户均值取平均，后者同时抽用户的总改善和记录数，再用总和之比计算。固定原总记录数十而只重采改善总和会改变原程序。两种结果不同不代表某个算法算错，而是决策给活跃用户的权重不同，报告应预先选定目标。

<a id="stat4-detail-43"></a>

### 10.7 练习七：最大值百分位区间为何完全失效

**题目：** 样本来自零到未知上界的均匀分布，为什么普通非参数最大值百分位区间无法覆盖真实上界？指出一个比“样本太少”更精确的原因。

**解析：** 每轮只能从原观察中抽取，重采样最大值不超过原最大值；原最大值几乎必然严格小于真实上界，故区间上端也严格小于真实上界。即使样本逐渐增加，这一支持边界关系始终存在，普通百分位覆盖仍为零。更深层地，重采样误差在零处具有不消失的原子，未复制真实极值误差的连续极限。需要改变推断方法或增加可信尾部模型，而不是增加轮数。

<a id="stat4-detail-44"></a>

### 10.8 练习八：零故障是否意味着零风险

**题目：** 独立测试中一千次均无故障，普通非参数重采样故障率为零。能否宣称故障概率精确为零？

**解析：** 不能，经验分布缺少故障不等于总体中没有故障。若独立二项模型可信，可用单侧界评价未观察事件的上限；零次事件的概率为 $`(1-p)^{1000}`$，解相应尾部水平即可得到非零上界。若试验共享设备或时间环境，还需审查独立性，不能直接把一千当独立次数。重采样退化提醒原数据对尾部信息不足，并不是强确定性的证据。

<a id="stat4-detail-45"></a>

### 10.9 练习九：均值相同可以任意置换吗

**题目：** 两组观察独立，均值相同，但方差差十倍、组容量不同。普通未学生化均值差置换是否精确？

**解析：** 一般不精确。零均值差不足以让合并观察的标签交换；精确两样本置换通常依据两组分布相同的更强零假设。方差与组容量不平衡时，置换分布的尺度可能与真实均值差抽样尺度不同。适当学生化在相应正则条件下可获得渐近有效性，但须说明方法与条件。若数据来自真实随机化设计，依据又应回到允许分配与所检验的因果零假设，不能混为一谈。

<a id="stat4-detail-46"></a>

### 10.10 练习十：差值零均值是否允许精确翻号

**题目：** 观察性配对差值分布高度偏斜但均值为零，能否直接用所有符号翻转进行精确检验？若原实验是每对内公平随机分配又如何？

**解析：** 对观察性差值，仅零均值不保证正负翻转后同分布，所以通常没有精确交换性。若真实设计是在每对中随机分配标签，并检验尖锐无效应假设，允许分配可由设计确定，组内翻号便具有随机化依据。两个程序表面相同，零假设和随机来源却不同。报告必须写出设计，不应让读者仅凭一行代码猜测精确性的来源。

<a id="stat4-detail-47"></a>

### 10.11 练习十一：交叉验证折的标准差

**题目：** 做十折交叉验证，直接将十个折分数的标准差除以平方根十，能否保证得到泛化性能的有效标准误？

**解析：** 不能。折模型训练集高度重叠，折分数之间存在由训练样本共享引入的依赖，独立重复均值的标准误公式没有自动适用。重复十次划分也没有得到一百批独立总体样本。应明确评价目标与协议，必要时使用独立外部评价或专门研究的方差估计；嵌套验证避免内层选择污染外层评价，但不让外层折自动独立。把不同问题分别处理，才能避免用一个数字承担过多解释。

<a id="stat4-detail-48"></a>

### 10.12 练习十二：统计方向与实际收益

**题目：** 预设最小有意义改善为零点一。三次结果的区间分别为零点零二到零点零八、零点一二到零点二、负零点零五到零点三，如何解释？

**解析：** 第一种支持正方向但尚不足以达到实际阈值；第二种在该区间方法和设计条件下支持超过阈值；第三种仍同时容许退步与重要改善，证据不确定。不要把第一种写成业务成功，也不要把第三种写成完全等效。所有判断都以目标、单位和区间覆盖条件成立为前提，若阈值是在看结果后改动，应标为探索并另作确认，不能保留原先预设的解释。

<a id="stat4-detail-49"></a>

### 10.13 练习十三：轮数增加改变哪种误差

**题目：** 固定原样本，把重采样轮数从一千增加到四千，计算误差大约怎样变化？真实抽样误差是否也减半？

**解析：** 对平滑的蒙特卡洛概率估计，标准误通常按轮数平方根缩小，因此约减半；端点数值误差还受分位附近密度影响。真实数据的抽样误差没有因此减少，原样本容量和代表性都没变。若端点仍明显波动，可继续增加计算；若区间本身很宽，则通常需要更多适当独立信息或更清晰设计，而非只增加轮数。两种误差应在报告与资源规划中分开。

<a id="stat4-detail-50"></a>

### 10.14 练习十四：中途停止和指标选择

**题目：** 每天重算普通百分之九十五区间，一旦不跨零便结束；同时查看二十个指标，只报告最显著者。最后一个区间是否仍自动具有原名义覆盖？

**解析：** 不会自动保持。停止时间与报告目标都由当前噪声决定，固定样本、固定指标的覆盖解释没有包含这些选择。应预先固定停止和主指标，或采用明确支持连续监测及多重比较的方案。若这已经发生，可以诚实报告探索过程并在独立数据中确认，不能仅把最终样本量写清就恢复原理论。选择规则是统计程序的一部分，必须与估计函数一起被审查。

## 11. 进阶研究练习与解析：搭建完整评价协议

<a id="sec-8-1"></a>

<a id="stat4-detail-52"></a>

### 11.1 综合练习：配对比较、置信区间与实际效应

**问题：** 两个冻结模型在同一批二百名独立用户上评价，每用户二十条相关记录。目标是用户等权改善，最小有意义差异零点一，已经用另一份数据完成调参。请写出主分析、区间、结论规则和不能覆盖的随机性。

**逐步解析：** 先对每用户分别汇总两模型损失，再相减，得到二百个配对用户差值；主估计为这些差值的平均。重采时有放回抽二百个用户索引，共同携带两模型及完整用户记录，按相同统计函数重新汇总。可根据差值分布与样本情况预先选择区间方式，并记录轮数、随机流和退化检查；不能把四千条记录逐行独立重采，不能分别抽两个模型。

把区间与零、零点一分别比较，说明方向证据与实际价值。若上端也小于零点一，结果不支持达到预设价值；若下端高于零点一，可在方法条件下支持该价值；若跨阈值，保留不确定性。还应报告差值分布、群组数和是否存在极端用户，以检查均值是否被少数对象支配。若群组目标本来是记录等权，须更换统计函数并在每轮重新计算分母。

本分析条件在两个冻结模型上，不包含重新训练、调参或训练样本改变的波动。它也只推广到当前抽样来源代表的用户总体，不保证未来漂移地区或完全未覆盖群体的收益。若下一步目标改为评价学习算法，应设计外层独立训练评价重复，并把所有选择放在训练侧，再讨论跨重复结果的依赖，而不是把当前区间的名称改成算法区间。

<a id="stat4-detail-53"></a>

### 11.2 研究设计：比较方法覆盖而不是只比较区间宽度

选择三种可控生成机制：独立近似对称差值、重尾差值、具有用户共同效应的重复记录。每种机制明确真实目标量，重复生成许多原始数据集，在每个数据集内构造候选区间，统计外层覆盖率、平均宽度和失败比例。覆盖的外层重复与估计重采样分布的内层重复不可混淆；一个数据集内做很多轮不能估计真实覆盖率。

方法比较应同时看覆盖与宽度。错误地把记录独立处理可能得到很窄区间，却严重漏覆盖；无限宽区间覆盖很好，也缺乏决策价值。记录计算成本和退化比例，并为所有方法使用同一批外层数据，以减少比较噪声。若据此选择方法再只展示其最有利场景，应另设未用于选择的机制或数据作确认，保留研究过程与适用范围。

<a id="stat4-detail-54"></a>

### 11.3 研究设计：从一份结论反推证据缺口

拿到一份“模型稳定提升”的报告，先问稳定针对什么重复：新测试用户、训练种子、训练数据还是新地区。再问评价和选择是否分离，是否保留自然配对与独立群组，是否区分统计方向和实际阈值，是否记录停止规则。若报告只能回答第一层，就将结论限制为固定预测的评价表现；若某个群体没有样本，不应用重采样区间暗示已研究它。

一份严谨的研究计划不必承诺消除所有不确定性，但要把下一步实验对准最大缺口。缺独立用户就补独立用户，缺训练流程重复就重复完整训练，缺外部代表性就设计新来源评价，缺尾部故障信息就规划适合稀有事件的样本和模型。重采样是近似重复实验的工具，只有在想清楚世界应怎样重复之后，计算出的分布才拥有可靠解释。

<a id="stat4-influence"></a>

### 11.4 从均值推广到光滑统计量：影响函数连接了什么

设目标泛函为 $`T(P)`$。若估计在真实分布附近可写成 $`\hat\theta-\theta=n^{-1}\sum_i\psi(Z_i)+r_n`$，其中 $`E[\psi(Z)]=0`$、影响函数有有限正方差，且 $`\sqrt n r_n`$ 依概率趋于零，那么主导波动是一组独立影响值的平均。适当条件下，重采样统计量也可展开成经验影响值的重采样平均，并且其余项在条件概率意义下同样足够小。两边共享同一个中心极限定理结构，才构成 bootstrap 合理性的核心机制。

这个展开解释为什么仅有原样本统计量的一致性还不够。一个估计可能确实趋向真值，却在边界处使用不同收敛速度，或者局部极限依赖当前估计所在的随机一侧。此时把同样本量经验抽样直接套上去，未必能正确复制标准化误差。最大值反例的正确尺度是样本量本身，而不是平方根样本量；绝对均值在零点也缺少通常的线性导数。找到局部展开中的第一处失效，比单纯观察某次区间异常更有诊断价值。

影响函数还能帮助选择独立单位。如果观察是用户群组，那么一个影响值应概括一个独立用户对目标估计的贡献，而不是把组内每条记录都当作独立扰动。对于群组大小差异很大的数据，某些用户影响可能特别大，普通固定维近似需要更谨慎检查。若少数用户几乎决定总体统计量，增加每轮索引数不会解决原始信息被少数单位支配的问题，应报告有效权重分布与外层敏感性。

<a id="stat4-ratio"></a>

### 11.5 比率指标：为什么不能只重采平均分母

很多业务指标是总成功次数除总机会数，或者总收益除总成本。设独立单位提供随机向量 $`(U_i,V_i)`$，目标为 $`\theta=\frac{E[U]}{E[V]}`$，分母期望非零。估计是样本总和之比。对比率作一阶展开，影响函数为 $`\frac{[U_i-\theta V_i]}{E[V]}`$，所以分子与分母的协方差直接进入方差。分别独立抽取两列会破坏这一协方差；固定原分母则漏掉其波动，二者通常都不是原程序的正确重采样。

例如用户的点击数与展示数天然相关，高活跃用户两者都大。若目标是随机展示的点击率，应每轮共同抽用户的点击数和展示数，再用抽中总点击除总展示；若目标是平均用户点击率，则先按用户定义比率，再平均，且需规定零展示用户如何处理。这两个指标甚至可能产生相反排序。方法选择之前先解决指标语义，才能讨论哪个区间更有效。

若分母可能接近零，光滑展开的稳定性会恶化，比率分布可能具有很长尾部，普通分位区间也可能不可靠。强行把小分母替换成某个常数会改变目标，必须解释业务与统计依据。若某轮分母为零，应按事先定义处理，而不是丢掉这些轮次后忘记报告。研究比率时，展示分母分布和无效轮次比例，与展示最终区间同样重要。

<a id="stat4-missing"></a>

### 11.6 缺失、筛选和预处理必须进入同一统计程序

假设比较两个模型，但只保留两者都成功输出的用户。若失败概率与困难程度或模型有关，估计对象已经从全部目标用户变成共同成功子集。对这个子集进行再多轮重采样，仍无法推断被排除用户的损失。应事先定义失败如何计分、是否将失败率列为关键指标，以及缺失机制需要什么假设。重采样反映给定数据处理后的波动，不会自动纠正选择偏差。

若标准化、阈值拟合或校准参数本身由当前样本估计，而目标包含这些操作的随机性，每轮就应按原协议重新执行它们。若模型和阈值本来在独立训练数据上固定，评价重采样则不应擅自重新拟合，否则变成另一个学习流程。这正是“完整重采原程序”的含义：保留目标中本来随机的步骤，条件化那些本来被冻结的步骤，而不是无差别地把所有计算都重新跑一遍。

研究报告可用一张流程清单审查这些边界：哪些对象被抽样，哪些变量共同携带，哪些参数在评价前固定，哪些步骤每轮重新估计，哪些异常情况触发预设规则。清单应服务于重建真实实验，不能成为形式上的勾选。一个简单但与设计一致的均值区间，通常比未说明对象与选择过程的复杂区间更易解释；复杂方法的价值在于处理明确的困难，而不是名称本身。


最终验收还应区分数值正确、程序正确和研究结论正确三个层面。数值正确是索引、差值和端点没有算错；程序正确是每轮抽样与统计函数忠实实现既定协议；研究结论正确则要求该协议确实对应想推广的总体与重复实验。第一层通过断言和手算核对，第二层通过检查配对、群组和选择边界，第三层需要抽样设计、代表性与科学假设。三者相互支持，却不能互相替代。

实际工作中可先用很小的数据手工列出两三轮重采样，确认重复单位和权重，再扩展到完整计算。对比率或层级指标，刻意构造组大小不等的小例子，往往能迅速暴露固定分母、错误去重或逐行加权的问题。最后选一个有解析答案的场景做外层覆盖核对，再加入真实场景的复杂机制。这样得到的研究材料既有可执行步骤，也保留方法成立的逻辑，不会只留下一个无法解释的区间数字。
