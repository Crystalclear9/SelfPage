# 第 1 章 参数估计与置信区间

[主题目录](README.md) · [分类目录](../README.md) · [总目录](../../README.md) · [下一章](02-假设检验相关性与实验.md)

本章把“从数据算出一个数”推进到完整的统计推断：先确定希望估计的总体量，再说明数据如何随机产生，然后研究估计量的误差，最后构造具有明确保证的区间。重点不是记住某种软件输出，而是能够追问：这个公式估计谁，换一种抽样设计是否仍然成立，所谓最优依赖什么损失，区间覆盖承诺又在哪一步可能失效。

阅读前需要期望、方差、条件概率、常见分布和一元微积分。涉及信息矩阵和多参数变换时，可以先掌握标量情形，再联系线性代数中的二次型。本章的代码使用 NumPy 和 SciPy；所有模拟均服务于检查已写明的数学命题，而不是以一次模拟代替证明。

## 1. 总体参数与样本统计量

<a id="estimand-sampling"></a>

### 1.1 先固定估计对象，再讨论计算公式

设总体分布为 $`P`$，目标写成分布的函数 $`\theta=T(P)`$。总体均值、成功概率、总体中位数和两个总体的均值差，都是不同的估计对象。样本是随机向量 $`S=(X_1,\ldots,X_n)`$，估计量 $`\hat\theta=\hat\theta(S)`$ 是对样本施加的可测函数。样本均值是估计量，观察到的均值是该估计量的一次取值。参数可以固定未知，估计量仍然随机，因为随机性来自我们尚未看到的数据。

例如要估计“未来一个月全部用户的人均使用时长”，只记录当前活跃用户的会话平均时长，至少改变了两个对象：未出现的用户被排除，频繁开启会话的用户又获得更大权重。再精确的均值公式也不能把会话平均自动变成人均平均。应先说明时间范围、目标用户集合、零时长是否纳入、每个用户贡献几条记录，然后才决定统计量。研究问题中的一个词，如“平均”“用户”或“未来”，都可能对应不同的数学定义。

参数模型把总体限制为 $`\{P_\theta:\theta\in\Theta\}`$。这使证明和计算更具体，却也引入假设：正态模型并不由观测值看起来平滑就自动成立。非参数问题则允许更广泛的分布类，例如只假设二阶矩存在。模型越宽，能保证的结论通常越弱；模型越窄，精度承诺越强，也越依赖正确设定。清楚写出分布类，才能知道一个置信区间的保证究竟覆盖哪些世界。

<a id="sampling-units"></a>

### 1.2 抽样单位、独立性与有限总体

独立同分布样本是一种设计，不是电子表格逐行排列后自然具有的性质。一个患者的二十次测量、一个用户的二十次点击、同一天同一服务器的二十次响应，都可能共享潜在因素。若把这些记录当成二十个独立个体，标准误通常会过小。数据数量应至少区分记录数、独立个体数和独立随机化单位数。后两者决定了很多统计推断中的有效信息量。

对任意具有有限二阶矩的观测，样本均值的方差恒有

$$\operatorname{Var}(\bar X)=\frac1{n^2}\left\{\sum_i\operatorname{Var}(X_i)+2\sum_{i<j}\operatorname{Cov}(X_i,X_j)\right\}.$$

只有在独立或合适的不相关条件下，协方差项才消失。若每个观测方差为 $`\sigma^2`$，组内任意两条记录相关系数为 $`\rho`$，每组恰有 $`m`$ 条且各组独立，均值方差相对逐行独立公式增加因子 $`1+(m-1)\rho`$。这个简化的设计效应需要等组大小和等相关假设；真实分组不平衡时，应使用匹配设计的协方差估计，而不是强行套用一个有效样本量。

若总体是固定的 $`N`$ 个对象，随机性仅来自不放回简单抽样，有限总体均值也是固定量。定义有限总体方差为 $`S_N^2=\sum_{j=1}^N\frac{(y_j-\bar y_N)^2}{(N-1)}`$，则抽取 $`n`$ 个对象后的均值方差为 $`\frac{(1-\frac{n}{N})S_N^2}{n}`$。抽样比例很大时，有限总体修正不能忽略；抽遍总体时该方差归零。但这只消除了针对当前固定名单的抽样误差，无法消除测量误差，也不能证明未来总体与当前名单相同。

<a id="bias-variance-mse"></a>

### 1.3 偏差、方差与均方误差的严格分解

在给定参数 $`\theta`$ 下，偏差为 $`b_\theta=E_\theta\hat\theta-\theta`$，方差为 $`E_\theta(\hat\theta-E_\theta\hat\theta)^2`$。当二阶矩存在时，在误差中加减期望并展开：

$$E_\theta(\hat\theta-\theta)^2=\operatorname{Var}_\theta(\hat\theta)+b_\theta^2.$$

交叉项为零，因为中心化变量的期望为零。这个恒等式没有假设正态性，也没有要求无偏。它适用于平方误差风险；若关心绝对误差、相对误差或过度估计的非对称代价，必须重新定义风险，不能把此分解当作全部决策问题的通用准则。

“偏差小”描述重复抽样的平均位置，“方差小”描述估计量在不同样本之间的波动，“这次估计误差小”则涉及尚未知晓的真参数。这三个判断不能互相替代。一个总输出零的估计量方差为零，但对非零参数会系统出错；一个无偏估计量也可能偶尔给出极大值。实际选择方法，应比较目标参数范围内的风险，而不只是挑一个性质好听的形容词。

<a id="consistency-rate"></a>

### 1.4 一致性、收敛速度与可识别性

一致性要求对每个固定参数和每个 $`\varepsilon>0`$，$`P_\theta(\vert \hat\theta_n-\theta\vert >\varepsilon)\to0`$。它描述样本量增长时误差概率是否消失，不说明有限样本是否够用。若独立同分布且方差有限，$`\operatorname{Var}(\bar X)=\frac{\sigma^2}{n}`$，切比雪夫不等式立即给出均值的一致性。只要求绝对一阶矩存在时，大数定律仍可给一致性，但上面的方差证明不再适用。

无偏并不推出一致。只用第一条观测估计总体均值，始终无偏，方差却不随 $`n`$ 下降。有偏也不妨碍一致，例如正态方差的最大似然估计虽然向下有偏，仍然一致；当 $`n>1`$ 时乘上 $`\frac{n}{(n-1)}`$ 可得到无偏的样本方差，二者差异渐近消失。讨论收敛速度时，$`\sqrt n`$ 是常见尺度，却并非自然界的默认尺度：分布端点估计可以达到 $`n`$ 级速度，重尾均值可能没有通常的平方根速度。

比算法更早的一道关卡是可识别性。若 $`P_\theta=P_{\theta'}`$ 而 $`\theta\ne\theta'`$，任何仅凭这些观测的程序都无法一致地区分二者。比如只观察正态变量的平方而均值符号未知，正负均值可产生相同平方分布。优化器精确收敛也不能补回数据中不存在的信息。应先检查不同目标值是否对应不同可观测分布，再研究估计效率。

## 2. 极大似然估计与矩估计

<a id="likelihood-object"></a>

### 2.1 似然是同一份数据下的参数比较

对于独立样本，若相对于共同支配测度存在密度或概率质量函数 $`f_\theta`$，联合似然为 $`L(\theta;x)=\prod_i f_\theta(x_i)`$。此时数据 $`x`$ 固定，参数变化。似然一般不要求对参数积分为一，所以不能把似然曲线直接当成参数的概率密度。对数似然把乘积改成和，但并不会使一个错误的模型变正确。

Bernoulli 样本含 $`k`$ 次成功，忽略与参数无关的常数，有 $`\ell(p)=k\log p+(n-k)\log(1-p)`$。当 $`0<k<n`$，令导数为零得到 $`\hat p=\frac{k}{n}`$，二阶导数为负验证内部极大。当 $`k=0`$ 或 $`k=n`$，最大值位于参数域边界；需要用连续延拓理解 $`0\log0=0`$，而不是让数值程序计算未定义表达式。观察次序不影响这里的似然，前提是独立同分布模型本身成立。

似然最大值可能不存在。二分类逻辑回归在完全可分数据上，某些系数沿分离方向趋于无穷时对数似然不断接近上确界，有限系数没有最大值。加惩罚可以使优化问题有解，但此时解对应惩罚似然而非原始无约束最大似然。关于估计量方差和渐近正态性的证明，不能在目标改变后原样照搬。

<a id="sec-2-1"></a>

### 2.2 机制展开：支持依赖参数时为何不能只求导

设 $`X_i\sim\operatorname{Unif}(0,\theta)`$，$`\theta>0`$，记 $`M=\max_iX_i`$。似然为 $`\theta^{-n}\mathbf1\{\theta\ge M\}`$。在允许的范围内它随 $`\theta`$ 单调下降，所以最大似然估计为 $`M`$。如果只对 $`-n\log\theta`$ 求导并要求零点，就会错误地得出没有解；真正决定最优点的是支持约束。这个例子说明，样本对参数可行域施加的条件也是似然的一部分。

由 $`P_\theta(M\le m)=(\frac{m}{\theta})^n`$，在 $`0\le m\le\theta`$ 上积分可得 $`E M=\frac{n\theta}{(n+1)}`$ 和 $`\operatorname{Var}(M)=\frac{n\theta^2}{((n+1)^2(n+2))}`$。因此 $`\frac{(n+1)M}{n}`$ 无偏，且方差为 $`\frac{\theta^2}{(n(n+2))}`$。其误差尺度为 $`\frac{1}{n}`$，与正则模型常见的 $`\frac{1}{\sqrt n}`$ 不同。参数改变时密度支持也改变，积分求导的边界贡献不能被忽略，这也是通常得分恒等式在此失效的原因。

若把样本得分草率写成 $`-\frac{n}{\theta}`$，其期望显然不是零。此时再把平方期望称为正则 Fisher 信息，套用无偏估计方差下界，会制造虚假矛盾。遇到反例时应回到证明所用的换序条件，而不是说估计量“突破了数学极限”。某个定理的适用模型类有限，超出模型类并不违反定理。

<a id="normal-mle"></a>

### 2.3 高斯均值与方差：两个目标两个分母

正态样本的对数似然除常数外为 $`-\frac{n\log(\sigma^2)}{2}-\sum_i\frac{(x_i-\mu)^2}{(2\sigma^2)}`$。固定方差时，最大化似然等价最小化平方离差和，得到 $`\hat\mu=\bar X`$。再代回并对方差求导，得到 $`\hat\sigma^2_{\mathrm{ML}}=\sum_i\frac{(X_i-\bar X)^2}{n}`$。这是似然优化的答案，分母不是自由度修正后的 $`n-1`$。

恒等式 $`\sum_i(X_i-\bar X)^2=\sum_i(X_i-\mu)^2-n(\bar X-\mu)^2`$ 的期望为 $`(n-1)\sigma^2`$，所以最大似然方差向下有偏。样本方差 $`S^2=\sum_i\frac{(X_i-\bar X)^2}{(n-1)}`$ 则无偏。无偏性推导只需要独立同分布和有限方差，不需要正态；但下面使用卡方分布给精确方差区间时，正态性至关重要。相同统计量可以拥有一个宽泛的期望性质和一个更窄的分布性质。

即使 $`S^2`$ 无偏，$`S=\sqrt{S^2}`$ 一般也不无偏，因为开平方是非线性函数。由凹函数的 Jensen 不等式，$`E S\le\sqrt{E S^2}=\sigma`$，非退化情况下严格小于。所谓最大似然不变性，是指若 $`\hat\theta`$ 最大化似然，适当定义诱导参数的轮廓似然后，$`g(\hat\theta)`$ 是 $`g(\theta)`$ 的最大似然解；它不是说非线性变换保持无偏性。

<a id="moment-estimator"></a>

### 2.4 矩估计如何得到，以及为什么会不稳定

矩估计通过总体矩方程与样本矩对应。若指数分布采用率参数 $`\lambda`$，有 $`E X=\frac{1}{\lambda}`$，由 $`\bar X=\frac{1}{\lambda}`$ 得 $`\hat\lambda=\frac{1}{\bar X}`$。同一模型的似然也给出这个解，二者此处重合，却不代表矩估计一般等于最大似然。对均匀端点模型，$`E X=\frac{\theta}{2}`$，矩估计为 $`2\bar X`$，与最大值型估计不同，而且可能小于观测最大值，落到使当前样本不可能的参数区域。

率参数例子还揭示非线性偏差。因为 $`\lambda\sum_iX_i\sim\operatorname{Gamma}(n,1)`$，$`n>1`$ 时 $`E(\frac{1}{\bar X})=\frac{n\lambda}{(n-1)}`$。因此它向上有偏；当 $`n=1`$，该期望甚至发散。样本均值对期望无偏，不意味着其倒数对率无偏。使用参数变换时，必须检查函数在分母接近零处的行为和相应矩是否存在。

多参数矩估计需要足够多且能识别参数的矩方程。高阶矩对异常值敏感：少量极大观测经四次方、六次方放大后，可能支配解。若理论矩本身不存在，相应样本矩虽可计算，却不能由通常大数定律保证收敛到预期对象。应先确认矩存在与方程可识别，再讨论求根精度。数值求得一个根并不保证根唯一、在参数域内，或具有良好的统计性质。

## 3. 得分、信息与估计效率

<a id="score-identities"></a>

### 3.1 得分恒等式来自哪一次积分求导

在参数位于开区间、共同支持且可将参数导数移入积分等条件下，单条观测得分为 $`u_\theta(X)=\partial_\theta\log f_\theta(X)`$。由密度积分为一，有 $`E_\theta u_\theta(X)=\int\partial_\theta f_\theta(x)\,dx=0`$。Fisher 信息定义为 $`I(\theta)=E_\theta[u_\theta(X)^2]`$。进一步满足二阶换序条件时，$`I(\theta)=-E_\theta\partial_\theta^2\log f_\theta(X)`$。

这不是一个可以无条件替换的公式三件套。若期望或导数不存在、支持随参数变化、参数在边界，得分均值为零和负 Hessian 恒等式都需重新审查。独立样本总得分相加，由零均值与独立性得到总信息 $`nI(\theta)`$；相关数据的交叉协方差一般不为零，因此不能只把行数乘到单条信息上。

Bernoulli 内部参数 $`0<p<1`$ 的单条得分为 $`\frac{(X-p)}{(p(1-p))}`$，信息为 $`\frac{1}{(p(1-p))}`$。靠近边界时这个数很大，却不能据此说“零成功能精确证明概率为零”。信息是正则内部参数的局部曲率尺度，边界附近有限样本分布高度不对称，估计量也可落在边界。局部渐近表述和有限样本区间必须分别判断。

<a id="cramer-rao-proof"></a>

### 3.2 Cramér–Rao 下界的证明与可达到条件

设 $`T`$ 对 $`g(\theta)`$ 无偏，即 $`E_\theta T=g(\theta)`$，且允许对该期望求导。总得分 $`U`$ 满足 $`E U=0`$，于是

$$g'(\theta)=E_\theta[TU]=\operatorname{Cov}_\theta(T,U).$$

用 Cauchy–Schwarz 不等式，$`g'(\theta)^2\le\operatorname{Var}(T)\operatorname{Var}(U)`$，从而独立样本下

$$\operatorname{Var}_\theta(T)\ge\frac{g'(\theta)^2}{nI(\theta)}.$$

这是指定正则模型、指定目标和无偏估计类中的逐参数下界，不是所有估计程序在所有损失下的统一极限。它也不保证存在达到下界的估计量。等号要求中心化估计量与总得分几乎处处成比例，而且同一个统计量须在整个参数族中具有适当形式。

正态方差已知时，均值的信息为 $`\frac{1}{\sigma^2}`$，样本均值方差恰为 $`\frac{\sigma^2}{n}`$，达到下界。Bernoulli 比例也达到内部参数下界 $`\frac{p(1-p)}{n}`$。若目标是估计参数 $`\theta`$ 本身，估计量有偏且偏差可微，同一论证给出 $`\operatorname{Var}(T)\ge\frac{(1+b'(\theta))^2}{(nI(\theta))}`$，再加偏差平方才得到 MSE 约束。因此收缩估计的 MSE 低于“无偏估计的下界”并不矛盾，因为比较类发生了变化。

对多参数模型，信息变成矩阵。估计某个分量而把其他分量当作未知干扰参数时，相应下界一般取信息矩阵逆的对角元素，不能只把该分量的信息对角元素取倒数。两者差异表达了参数之间的耦合。信息奇异可能表示局部不可识别或冗余参数化；先删掉冗余方向，才谈得上普通矩阵求逆和效率。

<a id="mle-asymptotic"></a>

### 3.3 最大似然渐近正态性的核心推导

先看标量参数。在一致性、内部真值、足够光滑、信息为正、导数及余项受控等条件下，由得分方程在真值附近展开：

$$0=U_n(\hat\theta)=U_n(\theta_0)+\ell_n''(\tilde\theta)(\hat\theta-\theta_0).$$

若 $`\frac{U_n(\theta_0)}{\sqrt n}\Rightarrow N(0,I(\theta_0))`$，且 $`-\frac{\ell_n''(\tilde\theta)}{n}\to I(\theta_0)`$，就有 $`\sqrt n(\hat\theta-\theta_0)\Rightarrow N(0,I(\theta_0)^{-1})`$。证明由中心极限定理、局部 Hessian 稳定和 Slutsky 定理连起来；“最大化了似然”本身并不足以推出结论。

对于固定维数的向量参数，不能无条件声称所有得分分量共享同一个中值点 $`\tilde\theta`$。正确的精确写法使用沿参数线段平均的 Hessian：$`0=U_n(\theta_0)+\overline H_n(\hat\theta-\theta_0)`$，其中 $`\overline H_n=\int_0^1\nabla^2\ell_n(\theta_0+t(\hat\theta-\theta_0))\,dt`$。再由邻域内一致控制得到 $`-\frac{\overline H_n}{n}\to I(\theta_0)`$，结合多元得分中心极限定理与信息矩阵正定性，才得到协方差为 $`I(\theta_0)^{-1}`$ 的多元正态极限。单个标量中值定理不能直接充当向量版证明。

固定维度是这一常用表述中的关键背景。若参数维度与样本量一起增长，许多余项不再可忽略，参数一致性也可能改变。边界、混合模型标签交换、完全分离和弱识别同样可能破坏正态近似。软件成功返回一个逆 Hessian，只说明它完成了数值运算，不能代替统计条件检查。

模型设定错误时，最大似然常趋向使真实分布到模型的相对熵最小的伪真值，而非研究者原来想象的参数。在适当条件下，渐近协方差形式是 $`\frac{A^{-1}BA^{-1}}{n}`$，其中 $`A`$ 是负期望 Hessian，$`B`$ 是得分协方差；只有正确设定并满足信息等式时才简化为信息逆。这解释了为何稳健协方差会出现两个“面包”和一个“夹心”，但本章不把它当作抽样偏差或因果混杂的修复器。

<a id="delta-method"></a>

### 3.4 Delta 方法：一阶变换何时够用

若 $`\sqrt n(\hat\theta-\theta)\Rightarrow N(0,v)`$，函数 $`g`$ 在真值可微，且 $`g'(\theta)\ne0`$，Taylor 展开给出 $`\sqrt n(g(\hat\theta)-g(\theta))\Rightarrow N(0,g'(\theta)^2v)`$。估计率、优势比和正参数的对数区间，都经常使用这个思路。标准误按导数的绝对值缩放，区间最好先在适合的变换尺度上构造，再反变换，避免出现不可能的负值。

若 $`\theta=0`$、$`g(t)=t^2`$，一阶导数为零，一阶近似只给退化极限。事实上若 $`\sqrt n\hat\theta\Rightarrow N(0,v)`$，则 $`n\hat\theta^2\Rightarrow v\chi_1^2`$，应使用二阶展开而非宣布估计没有不确定性。类似地，比例的分母接近零时，局部导数可能极大，普通对称区间极不稳定；这时必须研究联合分布和参数约束。

多元版本写成 $`\nabla g(\theta)^\top\Sigma\nabla g(\theta)`$。例如同一数据上两个估计之差的方差包含协方差项；忽略它可能高估或低估标准误。若两个指标来源于相同样本，先分析配对结构，再做函数变换。把所有量分别算标准误再平方相加，只有在相应协方差为零时才成立。

<a id="sec-3"></a>

## 4. 如何理解置信区间

<a id="coverage-definition"></a>

### 4.1 覆盖率是随机集合的性质

一个置信程序给每份样本分配集合 $`C(S)`$。在模型类内，如果对每个参数都有 $`P_\theta(\theta\in C(S))\ge1-\alpha`$，称其具有至少 $`1-\alpha`$ 的有限样本覆盖。参数固定，区间端点随数据随机。得到一次具体区间后，参数是否在其中已经是固定事实；频率保证描述生成这些区间的重复程序，而不是给固定参数自动加上一层后验概率。

应区分点态渐近覆盖和一致渐近覆盖。点态陈述对每个固定参数让 $`n\to\infty`$；一致陈述要求最坏参数的误差也受控。一个方法可能对每个内部固定比例都渐近正确，却在随样本量逼近边界的稀有事件概率上很差。教材里“大样本有效”的一句话，若没有说明参数是否也在变化，很容易掩盖这种差别。

覆盖不是唯一质量指标。永远输出整个实数轴会百分之百覆盖，却没有信息。比较区间应在覆盖合格后，再研究长度、左右尾漏失是否平衡、边界行为和数值稳定。也不能把“更短”作为唯一胜负标准：一个几乎不覆盖的零宽区间当然很短。区间设计是在明确错误承诺下争取信息量。

<a id="normal-exact-ci"></a>

### 4.2 正态均值的精确枢轴推导

若 $`X_i`$ 独立同分布于 $`N(\mu,\sigma^2)`$ 且方差已知，则 $`Z=\frac{(\bar X-\mu)}{(\frac{\sigma}{\sqrt n})}`$ 精确服从标准正态。设 $`z=z_{1-\frac{\alpha}{2}}`$，由 $`P(-z\le Z\le z)=1-\alpha`$ 解出 $`\bar X\pm\frac{z\sigma}{\sqrt n}`$。这里的精确性来自均值在有限样本下的精确正态分布；不是因为任意样本标准化后都会正态。

方差未知时，正态样本满足 $`\frac{(n-1)S^2}{\sigma^2}\sim\chi^2_{n-1}`$，且它与样本均值独立。这两条特殊性质使 $`T=\frac{(\bar X-\mu)}{(\frac{S}{\sqrt n})}\sim t_{n-1}`$。于是将正态分位数换成相应 t 分位数，得到精确均值区间。重尾非正态样本中，t 统计量在有限样本下一般不精确服从 t 分布，不能因为代码调用了 t 分位数就改变事实。

正态样本的总体方差也有精确区间。记 $`q_a`$ 为自由度 $`n-1`$ 的卡方分位数，则区间为 $`[\frac{(n-1)S^2}{q_{1-\frac{\alpha}{2}}},\frac{(n-1)S^2}{q_{\frac{\alpha}{2}}}]`$。除法反转不等号方向，所以下端使用较大的分位数。此区间通常不对称，反映方差参数的分布形状。对它开平方即可得到标准差区间，因为平方根在非负轴上单调递增。

<a id="deep-dive-3"></a>

### 4.3 深入讲解：误差、标准误与区间在同一实验中的位置

设真实均值为十，标准差为二，每次独立抽二十五个正态观测。样本均值的抽样标准差为 $`\frac{2}{5}=0.4`$。某次观察到均值十点三，这次误差是零点三；标准误零点四不是这次误差的精确大小，而是均值在不同样本间的波动尺度。实际总体方差未知时，用本次的 $`\frac{S}{5}`$ 估计它，这个标准误本身也随样本变化。

在这个设计下，t 区间在所有重复样本中的覆盖是百分之九十五。不能先筛选“均值比较大”的样本，再无条件沿用原覆盖结论；筛选改变了用于评价程序的样本分布。同理，先在一百个模型中挑最高准确率，再给被选中的那个模型套固定模型区间，通常忽略了选择带来的额外随机性。可信报告要覆盖完整选择流程，或者使用与选择独立的新数据。

重复抽样也不是要求现实中必须收集无限多批数据，而是数学上用抽样机制定义程序性质。模拟中的真参数已知，可以计算覆盖；真实分析中参数未知，不能只根据一个区间是否“看起来合理”判断覆盖成功。模拟能检查实现和若干场景，却不能证明对所有分布都可靠。应在已知理论、设计核查和敏感性实验之间建立相互支持的证据链。

<a id="asymptotic-ci"></a>

### 4.4 渐近区间与稳健性的边界

独立同分布、方差有限且非零时，中心极限定理与样本方差一致性给出 $`\frac{(\bar X-\mu)}{(\frac{S}{\sqrt n})}\Rightarrow N(0,1)`$。由此构造的正态分位数区间是渐近区间。样本量够不够，没有只看一个固定数字的通用答案：偏斜、重尾、稀有事件和观测相关性都会影响近似。若三阶绝对矩存在，正态近似误差界还会显式依赖标准化三阶矩，而非只依赖样本量。

Cauchy 样本的均值仍服从同尺度的 Cauchy 分布，其总体期望并不存在；增加样本量并不会让样本均值像有限方差情形那样集中。这不是把标准误换成另一个分位数可以解决的问题。应先确定目标是否存在，再考虑中位数、截尾均值等不同目标；若改变目标，报告中必须承认自己回答的问题发生了变化。

对分组相关数据，组级独立且组数足够时，可以研究组均值或使用适配的聚类协方差。对时间序列，可能需要长程方差和混合等依赖条件。稳健标准误的“稳健”总是针对某一种偏离，并不涵盖任意依赖、抽样偏差或测量错误。把一个稳健选项打开后不再写假设，会使分析失去可核查性。

<a id="binomial-ci"></a>

## 5. 成功概率区间：从失效的 Wald 到得分反演

<a id="wald-failure"></a>

### 5.1 零成功为什么不代表零不确定性

通常的 Wald 区间为 $`\hat p\pm z\sqrt{\frac{\hat p(1-\hat p)}{n}}`$。它把未知方差用样本比例代入，并在估计值附近作对称正态近似。若 $`k=0`$，估计标准误为零，区间退化为零点；然而任意小正概率仍有可能产生零成功。截断端点到零和一虽然消除了不可能的端点，却无法修复零宽区间和差覆盖的本质原因。

取 $`n=20,p=0.01`$，零成功的概率为 $`0.99^{20}\approx0.818`$。在这百分之八十多的样本中，Wald 区间完全不包含真值，因此总覆盖至多约百分之十八点二。这是一个不依赖模拟的严格上界，说明所谓“近似百分之九十五”在边界附近可以错得很远。仅因为 $`n`$ 已经达到二十、三十或一百，就放弃检查事件数量，并没有理论依据。

概率区间的困难在于抽样分布离散、偏斜且依赖未知参数。内部区域的对称近似可能不错，边界区域却需要认真处理。一个合理方法应在零次或全部成功时仍给出非零宽度；在参数域内保持端点；并清楚说明覆盖是精确保证还是渐近近似。计算容易不是忽略这些条件的理由。

<a id="wilson-derivation"></a>

### 5.2 Wilson 区间的二次不等式推导

考虑在候选值 $`p`$ 下的得分型统计量。接受条件写成 $`(\hat p-p)^2\le\frac{z^2p(1-p)}{n}`$。注意右侧使用候选参数的方差，而不是先用 $`\hat p`$ 替代。将所有项移到左侧，得到

$$(1+\frac{z^2}{n})p^2-(2\hat p+\frac{z^2}{n})p+\hat p^2\le0.$$

二次系数为正，可接受参数位于两个根之间。整理后中心和半宽分别为

$$
\begin{aligned}
c &=\frac{\hat p+\frac{z^2}{(2n)}}{1+\frac{z^2}{n}},\\[6pt]
h &=\frac{z\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{z^2}{(4n^2)}}}{1+\frac{z^2}{n}}.
\end{aligned}
$$

于是 Wilson 区间为 $`[c-h,c+h]`$。中心不是原始样本比例，而向二分之一收缩；这是检验反演的代数结果，不应只凭形状相似就将它宣称为某种贝叶斯后验区间。零成功时，下端为零，上端为 $`\frac{z^2}{(n+z^2)}`$，不会退化成一个点。

Wilson 仍是基于得分正态近似的区间，不保证每个有限样本参数都达到名义覆盖。其覆盖会随参数与离散计数变化而波动。它的重要意义是让我们看到：同样使用正态分位数，围绕候选真值构造接受域与围绕估计值对称展开，会得到不同有限样本行为。方法比较应同时观察覆盖曲线和平均长度，而不是挑一组漂亮端点下结论。

<a id="clopper-pearson"></a>

### 5.3 Clopper–Pearson：精确尾概率与保守性

对 $`K\sim\operatorname{Binomial}(n,p)`$，等尾 Clopper–Pearson 区间通过反演二项分布尾概率得到。若 $`0<k\le n`$，下端为 Beta 分布 $`\operatorname{Beta}(k,n-k+1)`$ 的 $`\frac{\alpha}{2}`$ 分位数；若 $`0\le k<n`$，上端为 $`\operatorname{Beta}(k+1,n-k)`$ 的 $`1-\frac{\alpha}{2}`$ 分位数。规定 $`k=0`$ 时下端为零，$`k=n`$ 时上端为一。Beta 分位数在这里是计算二项尾反演的恒等式，并不自动引入先验。

“精确”指它根据真实二项分布保证覆盖至少达到名义水平，而非对每个参数都恰好等于名义水平。由于离散性，若不在边界随机化，通常无法精确耗尽每一个尾部错误预算，因此区间可能偏宽。保守性是保证方式的代价，应与错误覆盖带来的后果比较，不能简单把精确方法说成绝对优于全部近似方法。

零成功时，双侧百分之九十五上端为 $`1-0.025^{\frac{1}{n}}`$；若事前只求单侧百分之九十五上界，则为 $`1-0.05^{\frac{1}{n}}`$。两者不是同一个数。常见的“三除以样本量”近似来自后一式在大样本下 $`-\frac{\log(0.05)}{n}\approx\frac{3}{n}`$，不能把单侧和双侧的常数混在一起。对于安全失败率和罕见风险报告，这个差别具有实际含义。

<a id="coverage-experiment"></a>

### 5.4 覆盖实验：精确求和与蒙特卡洛各检查什么

二项样本只有 $`n+1`$ 种可能计数，可以直接枚举每个 $`k`$ 构造区间，再按二项概率加权，得到指定 $`p`$ 的精确覆盖。这比重复模拟更适合检验程序的真实覆盖。模拟仍有价值：它能直观展示区间随样本变化，也能用蒙特卡洛标准误验证采样代码。下面同时给出两种结果，避免把模拟波动错认为区间本身的理论差异。

```python
import numpy as np
from scipy.stats import beta, binom, norm


def intervals(n, alpha=0.05):
    k = np.arange(n + 1)
    phat = k / n
    z = norm.ppf(1 - alpha / 2)
    wald_h = z * np.sqrt(phat * (1 - phat) / n)
    wald = (np.maximum(0, phat - wald_h),
            np.minimum(1, phat + wald_h))
    denom = 1 + z * z / n
    center = (phat + z * z / (2 * n)) / denom
    half = z * np.sqrt(phat * (1 - phat) / n + z*z/(4*n*n)) / denom
    wilson = (np.maximum(0, center - half), np.minimum(1, center + half))
    lo = np.zeros(n + 1)
    hi = np.ones(n + 1)
    lo[1:] = beta.ppf(alpha / 2, k[1:], n - k[1:] + 1)
    hi[:-1] = beta.ppf(1 - alpha / 2, k[:-1] + 1, n - k[:-1])
    return {"Wald": wald, "Wilson": wilson, "CP": (lo, hi)}


rng = np.random.default_rng(20261016)
n, repetitions = 20, 200_000
for p in [0.01, 0.10, 0.50]:
    counts = rng.binomial(n, p, size=repetitions)
    pmf = binom.pmf(np.arange(n + 1), n, p)
    for name, (lo, hi) in intervals(n).items():
        covers = (lo <= p + 1e-14) & (p <= hi + 1e-14)
        exact = float(pmf @ covers)
        simulated = float(covers[counts].mean())
        mc_se = np.sqrt(exact * (1 - exact) / repetitions)
        average_length = float(pmf @ (hi - lo))
        assert abs(simulated - exact) <= 6 * mc_se + 1 / repetitions
        if name == "CP":
            assert exact >= 0.95 - 1e-12
        print(p, name, round(exact, 6), round(simulated, 6),
              round(average_length, 6))
```

这里将随机种子用于复现实验，种子没有赋予区间任何额外统计保证。用于判断蒙特卡洛差异的六倍标准误只是宽松实现检查，不是证明程序对所有输入都正确。端点比较加入很小容差，是防止浮点数恰好落在边界时产生纯数值误判；容差不能设得足以改变有意义的覆盖事件。

平均长度按真实二项概率计算，因此也依赖 $`p`$。不能在一个参数点上同时发现覆盖较高、长度较短，就宣布方法在整个参数域支配另一个方法。若绘制完整曲线，应逐点列出参数网格并保留边界附近的密集检查。对连续参数域的全局覆盖保证，仍须依赖方法的理论，而非有限网格没有发现反例。

## 6. 标准差与标准误差

<a id="sd-se-distinction"></a>

### 6.1 三种“正负误差线”对应三个问题

总体标准差描述个体分布的离散程度；估计量标准误描述重复样本中估计量的波动；置信区间半宽还包含分位数与构造方法。三者的单位可能完全相同，含义却不同。画图或列表时必须标明误差线类型、置信水平和计算单位。只写“均值加减误差”会使读者无法知道你描述的是个体差异还是均值不确定性。

独立同分布且方差有限时，均值标准误为 $`\frac{\sigma}{\sqrt n}`$，用 $`\frac{S}{\sqrt n}`$ 估计。样本量扩大四倍，标准误约减半；总体标准差不会因此自动减半。若希望预测一个新的个体，其不确定性还包括新观测自身噪声。正态独立新观测的预测区间为 $`\bar X\pm t_{n-1,1-\frac{\alpha}{2}}S\sqrt{1+\frac{1}{n}}`$，显著宽于均值区间。均值很精确不意味着个体很容易预测。

模型性能报告也有类似区分。测试集中每个样本的损失标准差描述样本难度差异；平均损失的标准误描述固定模型在重新抽取测试样本时的波动；重新训练模型引入的训练随机性是另一层来源。如果每次换训练集、初始化和测试集，应明确你希望对哪几层随机性平均。一个仅基于测试样本的标准误不会自动包括所有模型开发不确定性。

<a id="sec-1-1"></a>

### 6.2 基础算例：从四条样本算出标准差与标准误

样本为一、二、三、四，均值为二点五，平方离差和为五，因此 $`S^2=\frac{5}{3}`$、$`S\approx1.291`$，均值估计标准误为 $`\frac{S}{2}\approx0.6455`$。若有理由假设四条观测独立来自正态总体，百分之九十五均值区间使用 $`t_{3,0.975}\approx3.182`$，半宽约二点零五四。小样本的分位数明显大于一点九六，不能只因为标准误已经算出，就默认正态分位数精确适用。

同一正态模型下，新个体的预测半宽还需乘上 $`\sqrt{1+\frac{1}{4}}`$ 而不是除以二。它比均值区间宽，因为新个体没有经过四个观测的平均降噪。若这四个数实际上是同一个人的连续测量，则上述独立正态解释也需要重新审查。每个计算符号都可以正确，整套推断仍可能因实验单位误认而错误。

<a id="estimating-equations"></a>

### 6.3 从估计方程理解通用标准误

很多估计量满足 $`\sum_i\psi(X_i,\hat\theta)=0`$。若真值附近可微、估计一致，并满足相应中心极限定理，则一阶展开给出 $`\sqrt n(\hat\theta-\theta)\approx-A^{-1}n^{-\frac{1}{2}}\sum_i\psi(X_i,\theta)`$，其中 $`A=E[\partial_\theta\psi(X,\theta)]`$。标量渐近方差为 $`\frac{B}{A^2}`$，$`B=\operatorname{Var}(\psi(X,\theta))`$。信息矩阵是这一框架在正确似然得分下的特殊简化。

样本均值对应 $`\psi(x,\mu)=x-\mu`$，有 $`A=-1`$、$`B=\sigma^2`$，立即回到熟悉的标准误。这个推导让我们看到，稳健方差不是为每个模型另背一条公式，而是研究统计量对单条观测的局部影响。若观测有依赖，$`B`$ 应替换为包含协方差的长期或组级方差；若估计方程不光滑、局部导数为零或根不唯一，又需要其他论证。

标准误公式的可靠性也受“渐近线性近似是否已有效”限制。强正则化、模型选择、边界约束或稀疏事件可使一阶影响近似失真。不能因为某个估计量可写成程序，就假定它必有平方根样本量的正态标准误。重采样方法可以帮助诊断和近似，但相应有效性同样要检查；具体算法留到本主题第四章。

## 7. 无偏与最小误差不是同一目标

<a id="shrinkage-risk"></a>

### 7.1 一个完整的收缩风险比较

设 $`\bar X\sim N(\mu,\frac{\sigma^2}{n})`$，考虑估计 $`T_c=c\bar X`$，其中 $`0\le c\le1`$ 为事先固定常数。其偏差为 $`(c-1)\mu`$，方差为 $`\frac{c^2\sigma^2}{n}`$，所以风险为 $`R_\mu(T_c)=(1-c)^2\mu^2+\frac{c^2\sigma^2}{n}`$。与样本均值比较，风险差等于 $`(1-c)^2\mu^2-\frac{(1-c^2)\sigma^2}{n}`$。若均值接近零，收缩减少方差的收益可超过偏差代价；均值很远时则相反。

例如 $`n=25,\sigma^2=4,c=\frac{1}{2}`$。样本均值风险为零点一六，收缩估计风险为 $`0.25\mu^2+0.04`$，只有 $`\vert \mu\vert <\sqrt{0.48}`$ 时更小。这个例子说明有偏估计可能更好，也同时说明它不一定对所有参数更好。若事后根据同一数据挑选 $`c`$，上述固定常数风险公式不再直接适用，选择本身也要纳入分析。

若给均值指定先验 $`N(0,\tau^2)`$ 且观测方差已知，后验均值为 $`c\bar X`$，其中 $`c=\frac{\tau^2}{(\tau^2+\frac{\sigma^2}{n})}`$。它最小化先验加权的平方误差风险，而不是声称对每个固定均值都优于样本均值。频率风险与贝叶斯风险可以在同一公式中比较，但必须说清是在逐参数比较，还是在参数分布下平均。

<a id="rao-blackwell"></a>

### 7.2 条件期望如何保留均值并降低风险

假设 $`T`$ 是平方可积估计量，$`U`$ 是某个统计量，令 $`T^*=E(T\mid U)`$。由迭代期望，$`E T^*=E T`$；由全方差公式，$`\operatorname{Var}(T)=E\operatorname{Var}(T\mid U)+\operatorname{Var}(T^*)`$。因此以条件期望替换原估计量，保留偏差同时不增加方差。这是 Rao–Blackwell 思路的数学核心，不依赖估计量原先无偏，但要保证条件期望形成可实际使用的、不含未知参数的统计量。

对独立 Bernoulli 样本，原估计量可取 $`T=X_1`$。给定成功总数 $`K`$，每个位置成为成功的条件概率相同，所以 $`E(X_1\mid K)=\frac{K}{n}`$。方差从 $`p(1-p)`$ 降到 $`\frac{p(1-p)}{n}`$。我们没有凭空增加数据，而是去掉了原程序对第一个位置的任意偏爱。充分统计量使给定它后的样本条件分布不再依赖参数，从而使这种改进更系统。

进一步的“最优无偏估计”结论还涉及充分性和完备性。完备性要求若一个统计量函数对全部参数的期望都为零，它就几乎处处为零。这能排除不同无偏改进之间的歧义。不要把“充分”理解成保留全部关于未来问题的信息：充分性相对于特定参数族成立，换模型或换目标后，原压缩可能不再充分。

<a id="confidence-versus-risk"></a>

### 7.3 点估计精确不保证区间覆盖正确

均方误差小的估计量不一定适合直接加减同一个标准误构造区间。收缩估计中心有偏，若仍用未收缩估计的对称正态区间，覆盖可能随参数改变。反过来，一个比较宽的区间可能覆盖可靠，但对应的中心点估计并非某种风险最优解。点估计和区间估计服务于相关却不同的优化问题，应分别评价。

“误差条更小”尤其容易成为不恰当的评估目标。强收缩、过度平滑、重复数据当独立样本，都可能让误差条看起来更稳定，却未必改进了对目标的推断。报告应至少把估计偏差来源、区间覆盖条件和区间宽度放在一起，必要时用多个真实参数场景做敏感性分析。只展示最有利参数点的模拟结果，会掩盖程序在其他区域的失败。

## 8. 进阶：频率覆盖与贝叶斯可信度的不同条件化

<a id="bayesian-beta"></a>

### 8.1 Beta–Binomial 更新的完整含义

对独立 Bernoulli 样本，给 $`p`$ 指定 $`\operatorname{Beta}(a,b)`$ 先验，密度与 $`p^{a-1}(1-p)^{b-1}`$ 成正比。乘以似然后，后验为 $`\operatorname{Beta}(a+k,b+n-k)`$。后验均值为 $`\frac{(a+k)}{(a+b+n)}`$，可写成先验均值与样本比例的加权平均。这个分解让“先验强度”有具体形式，但把 $`a+b`$ 称作样本量只是共轭模型中的解释，不意味着先验真的等同于收集了那些观测。

给定观察数据，后验等尾区间确实满足后验概率 $`P(p\in C\mid x)=1-\alpha`$。这个概率来自先验和似然共同定义的联合模型。频率区间则固定 $`p`$、让样本变化，两种陈述交换了条件化方向。即使两个区间数值接近，也不能删掉条件再声称它们回答完全相同的问题。

若先验是真实联合生成机制的一部分，对后验可信集合的后验覆盖再对边际数据平均，得到先验平均覆盖为名义水平。这个积分性质不保证每个固定 $`p`$ 的频率覆盖都达到名义水平。某些参数附近可能低覆盖，由另一些参数附近高覆盖补偿。研究者若需要逐参数保证，应单独计算或证明，不能从贝叶斯定义直接推出。

<a id="sec-6-1"></a>

### 8.2 估计量性质与区间覆盖是不同问题

给定同一数据，我们可以同时计算无偏估计、最大似然估计、后验均值和若干区间，它们评价标准并不相同。对 $`k=0,n=20`$，最大似然比例为零，均匀先验后验均值为 $`\frac{1}{22}`$，Wilson 中心又是另一数值。差异首先来自目标函数和区间构造，不应马上解释成某个方法“算错了”。应先核查每个量的定义，再比较其风险、覆盖和先验敏感性。

先验不能由同一数据任意反复调节后，仍把结果当作事前固定先验的简单更新。经验贝叶斯可以合理使用数据估计超参数，但不确定性评估应说明该步骤。频率方法同样不能在看过数据后选择最窄的区间算法，却沿用每个固定算法的名义保证。两种框架都需要诚实记录数据如何参与方法选择。

模型失配是两种框架共同面对的问题。漏记的失败事件、非响应、系统性测量偏差和分布变化，可能同时破坏频率覆盖和后验校准。增大样本通常减少随机波动，却可能把区间更精确地集中在错误目标附近。解释区间前先审查数据来源，是统计推断的一部分，而非计算完成后可有可无的附注。

<a id="selection-stopping"></a>

### 8.3 固定样本区间、停止规则与预测区间

固定样本置信区间承诺在预先给定的样本量下有效。若不断查看区间，直到它不包含零就停止，最终报告的区间经历了选择，其原来逐时点覆盖不等于跨时间同时覆盖。重复查看次数越多，至少一次漏覆盖的概率通常增加。置信序列是针对所有时间同时覆盖的另一类工具，需要专门构造，不能把普通区间重复计算后改个名字。

贝叶斯分析对停止规则的处理也有条件。若停止机制在给定已观测数据后不再额外依赖参数，且先验与模型固定，似然中相关因子可能抵消；但这不意味着任何选择性展示、未观测数据删除或不透明停止都无关紧要。参数推断、频率覆盖评价与研究披露是不同层次，不能用一句“贝叶斯不受停止影响”概括全部问题。

最后，参数置信区间、贝叶斯可信区间和新观测预测区间应在名称上明确区分。预测问题把观测噪声也纳入；参数区间主要描述未知总体量。不确定性可分解为参数与观测两部分，却不能在任意非线性模型中简单把两种半宽相加。先写出联合模型或目标覆盖事件，再决定如何计算。

## 9. 正态均值与方差的完整覆盖实验

<a id="normal-code"></a>

### 9.1 同一数据比较已知方差、估计方差与错误分位数

下面生成独立正态样本，分别检验已知总体方差的正态区间、未知方差的 t 区间、以及把总体方差换成样本方差却仍机械使用正态分位数的程序。第三种并非永远不能用，它在通常条件下具有渐近意义；本实验特意取小样本，使“有限样本精确”和“大样本近似”的区别显现出来。另检查卡方方差区间，以验证分位数顺序没有写反。

```python
import numpy as np
from scipy.stats import chi2, norm, t

rng = np.random.default_rng(314159)
repetitions, n = 100_000, 5
mu, sigma, alpha = 2.0, 3.0, 0.05
x = rng.normal(mu, sigma, size=(repetitions, n))
mean = x.mean(axis=1)
s2 = x.var(axis=1, ddof=1)
se = np.sqrt(s2 / n)
z = norm.ppf(1 - alpha / 2)
tq = t.ppf(1 - alpha / 2, n - 1)
cover_known = np.abs(mean - mu) <= z * sigma / np.sqrt(n)
cover_t = np.abs(mean - mu) <= tq * se
cover_z_plugin = np.abs(mean - mu) <= z * se
var_lo = (n - 1) * s2 / chi2.ppf(1 - alpha/2, n - 1)
var_hi = (n - 1) * s2 / chi2.ppf(alpha/2, n - 1)
cover_var = (var_lo <= sigma*sigma) & (sigma*sigma <= var_hi)
for name, cover in [("known_sigma", cover_known), ("t", cover_t),
                    ("z_plugin", cover_z_plugin), ("variance", cover_var)]:
    print(name, round(float(cover.mean()), 6))
assert abs(cover_known.mean() - 0.95) < 0.005
assert abs(cover_t.mean() - 0.95) < 0.005
assert abs(cover_var.mean() - 0.95) < 0.005
assert cover_z_plugin.mean() < 0.90
print("MLE variance mean", round(float(((n-1)/n*s2).mean()), 6))
print("unbiased variance mean", round(float(s2.mean()), 6))
```

每一行代表一份独立重复样本，列代表同一份样本中的观测。沿列求均值和方差，才是在模拟估计量的重复抽样分布；把整个二维数组展开求方差，会混合实验层级。方差的`ddof=1`对应无偏样本方差，最后再乘 $`\frac{(n-1)}{n}`$ 得到最大似然方差。这里代码参数与数学分母一一对应，避免将软件默认值当成统计学定义。

这个模拟不能证明 t 区间在非正态模型下精确。若把数据生成器改成强偏斜分布，应明确目标均值和真方差，再观察近似质量如何随样本量变化。若改成相关样本，则应先设计正确的依赖协方差。每次修改只改变一个机制，有助于判断失败来自分布形状、独立性还是区间实现。

<a id="report-template"></a>

### 9.2 一份可以复核的估计报告应包含什么

报告首先用自然语言和公式同时定义估计对象，例如“在固定评估月份，对目标用户集合中每个用户等权的平均损失”。随后写明抽样单位、排除规则、缺失处理、权重和样本量。没有这些信息，读者无法判断一个标准误对应什么随机机制，也无法复现总体定义。

其次给出点估计、标准误或完整区间、区间构造方法与关键假设。区间可以保留合适小数位，但不应以大量端点小数制造不真实的精度。若采用渐近方法，应说清适用依据与可能失效的边界；若多个指标或模型经过选择，应记录选择流程及独立评估安排。

最后提供敏感性检查：更换合理的分布假设、处理异常观测方式或独立单位定义，结论是否改变。敏感性检查不是寻找最有利结果，而是暴露结论依赖的环节。若检查后仍存在重要未解决偏差，应把它作为推断范围的一部分，而不是用更窄的抽样区间掩盖。一个可信的估计报告允许读者知道它回答了什么，也知道它还没有回答什么。

<a id="precision-budget"></a>

### 9.3 精度预算：样本量、测量质量与目标漂移

如果总体方差可以近似预估，正态均值区间的目标半宽为 $`h`$，已知方差设计给出 $`n\ge\frac{z^2\sigma^2}{h^2}`$。实际应向上取整，并给失访、分组相关和方差估计误差预留空间。这个计算说明把半宽减半通常需要四倍独立样本；它没有包含非响应偏差或测量系统误差。若传感器始终高估一个固定常数，再多重复测量也只会更精确地估计带偏均值。

可以把目标误差分成数据有限引起的随机波动、抽样与测量偏差，以及目标总体随时间改变引起的偏移。只有第一部分直接由本章的通常标准误量化。改善抽样覆盖、校准测量设备和缩短评估到部署的时间，可能比继续积累同一偏差来源的记录更有价值。资源分配应基于误差来源，而不是默认所有不确定性都可通过增加行数解决。

此外，方差很小的代理指标未必代表最终目标被精确估计。若研究用户长期收益却只记录短期点击，点击区间再窄也没有给出长期收益区间。把代理关系当作确定等式，会漏掉建模不确定性。应明确代理到目标的连接假设，并尽可能使用直接测量或独立验证来审查该连接。精确推断的第一步始终是确认我们正在精确地回答正确的问题。

<a id="sec-7"></a>

## 10. 练习与参考答案

<a id="exercise-estimand"></a>

### 10.1 练习一：会话均值与用户均值

**问题。** 第一个用户只有一次一分钟会话，第二个用户有三次各九分钟的会话。估计当前这两个用户的人均会话平均时长时，直接平均全部记录是否正确？

**解析。** 第一个用户均值为一，第二个为九，对用户等权的目标为五；全部四次会话平均为七。后者对会话等权，使第二个用户拥有三倍权重。计算本身没有算术错误，错误是将一个估计对象冒充另一个。若目标改为随机会话的平均时长，则七恰好是当前经验总体的目标。随机性与总体定义必须跟问题一起写明。

<a id="exercise-mse"></a>

### 10.2 练习二：用偏差方差比较估计

**问题。** 方法甲无偏且方差为四，方法乙偏差为一且方差为一，哪个平方误差风险较小？若损失改为绝对误差，还能直接回答吗？

**解析。** 甲的 MSE 为四，乙为二，故在给定参数点的平方损失下乙更好。绝对误差不能仅由均值和方差唯一决定，需要完整误差分布或额外界。即使乙在这个参数点更好，也不能据此声称它在所有参数点都更好；偏差和方差往往随真参数改变。风险比较要同时指明损失与参数范围。

<a id="exercise-consistency"></a>

### 10.3 练习三：无偏但不一致

**问题。** 独立正态样本估均值，令 $`T_n=X_1`$。证明它无偏却不一致，并与均值比较。

**解析。** $`E T_n=\mu`$，但对任意固定正数 $`\varepsilon`$，$`P(\vert T_n-\mu\vert >\varepsilon)`$ 始终为同一个正态尾概率，不随 $`n`$ 趋于零。均值则方差为 $`\frac{\sigma^2}{n}`$，由切比雪夫不等式证明一致。这个例子把“加入了更多记录”和“估计量真正利用了这些记录”区分开来；一致性属于整个估计程序序列的性质。

<a id="exercise-normal-variance"></a>

### 10.4 练习四：方差的两个分母

**问题。** 为什么高斯最大似然方差除以 $`n`$，无偏样本方差除以 $`n-1`$？无偏样本标准差也无偏吗？

**解析。** 前者由对方差参数优化对数似然得到，后者由平方离差和期望为 $`(n-1)\sigma^2`$ 得到，两个公式服务不同准则。开平方是凹函数，即使样本方差无偏，标准差期望也通常低于总体标准差。若关注方差 MSE，两种估计还可以进一步比较，不能仅看无偏性质就结束选择。若总体非正态，样本方差无偏仍成立，但卡方分布结论一般不成立。

<a id="exercise-uniform"></a>

### 10.5 练习五：端点模型的速度

**问题。** 对均匀端点模型，求 $`P(\frac{n(\theta-M)}{\theta}>t)`$ 的极限，并说明为何不能照搬通常的最大似然正态近似。

**解析。** 对固定 $`t\ge0`$ 且 $`n>t`$，该概率为 $`P(M<\theta(1-\frac{t}{n}))=(1-\frac{t}{n})^n\to e^{-t}`$，所以标准化误差趋于率为一的指数分布。速度为 $`n`$，极限非对称且非正态。支持随参数变化，得分正则恒等式不成立，普通内部参数最大似然定理的前提被破坏。估计量更快并没有违反正则模型下界。

<a id="exercise-fisher"></a>

### 10.6 练习六：Bernoulli 信息与边界

**问题。** 推导内部参数的 Fisher 信息，并解释为何在 $`p=0`$ 时不能用代入信息公式的方法宣布区间宽度为零。

**解析。** 得分为 $`\frac{(X-p)}{(p(1-p))}`$，平方期望为 $`\frac{1}{(p(1-p))}`$。内部参数样本均值方差为信息总量的倒数。边界处参数不在开集内，得分公式分母为零，局部对称正态近似也不适用。零成功数据仍与小正概率相容，应使用适合边界的区间。把内部公式的极限与边界有限样本保证混同，是对定理条件的误读。

<a id="exercise-delta"></a>

### 10.7 练习七：一阶 Delta 的退化

**问题。** $`X_i\sim N(\mu,1)`$，估计 $`\mu^2`$。分别讨论 $`\mu\ne0`$ 与 $`\mu=0`$。

**解析。** 非零时，导数为 $`2\mu`$，故 $`\sqrt n(\bar X^2-\mu^2)\Rightarrow N(0,4\mu^2)`$。零点时一阶导数为零，正确尺度是 $`n`$，且 $`n\bar X^2`$ 精确服从 $`\chi_1^2`$。若仍机械代入估计导数，在零点附近会得到极不稳定的标准误和覆盖。非线性变换必须检查局部展开的首个非零项。

<a id="exercise-t-ci"></a>

### 10.8 练习八：手算 t 区间与解释

**问题。** 独立正态样本量二十五、均值十、标准差二，计算百分之九十五均值区间。能否说所有个体有百分之九十五落在其中？

**解析。** 标准误为零点四，自由度二十四的分位数约二点零六四，区间约为 $`[9.174,10.826]`$。覆盖对象是总体均值，而非个体。个体预测区间还包括新观测噪声，半宽为相应 t 分位数乘 $`2\sqrt{1+\frac{1}{25}}`$，显著更大。区间越窄并不说明个体差异消失，只说明均值被较精确地定位。

<a id="exercise-wilson-zero"></a>

### 10.9 练习九：零成功的三个上界

**问题。** 样本量二十、成功零次，比较 Wald、Wilson 和单侧精确百分之九十五上界。

**解析。** Wald 上界为零；Wilson 双侧百分之九十五上界为 $`\frac{z_{0.975}^2}{(20+z_{0.975}^2)}\approx0.1611`$；单侧精确上界为 $`1-0.05^{\frac{1}{20}}\approx0.1391`$。这里后两者的单双侧不同，数值大小不能作为公平方法排名。若比较双侧精确区间，其上界为 $`1-0.025^{\frac{1}{20}}\approx0.1684`$。练习的关键是先对齐覆盖事件和尾部预算，再比较长度。

<a id="exercise-correlation"></a>

### 10.10 练习十：相关性如何改变标准误

**问题。** 一百组各有十条记录，组内等相关系数为零点二，组间独立。相对逐行独立计算，均值标准误扩大几倍？

**解析。** 设计效应为 $`1+9\times0.2=2.8`$，标准误扩大 $`\sqrt{2.8}\approx1.673`$ 倍。这个公式假设方差相同、等组大小和等相关；实际数据若不满足，不能把结果当作精确校正。有效样本量可作直觉说明，但并不意味着真的存在某个小数数量的独立对象。分析仍应围绕组级抽样设计组织。

<a id="exercise-bayes"></a>

### 10.11 练习十一：同一个 Beta 量为什么有两种来源

**问题。** Clopper–Pearson 区间使用 Beta 分位数，是否说明它就是均匀先验的贝叶斯等尾区间？

**解析。** 不是。均匀先验后验为 $`\operatorname{Beta}(k+1,n-k+1)`$，两端来自同一个后验分布；精确频率下端和上端分别涉及 $`\operatorname{Beta}(k,n-k+1)`$ 与 $`\operatorname{Beta}(k+1,n-k)`$，来自二项尾反演。相同特殊函数不意味着相同推断框架。判断区间解释应追溯构造的覆盖事件或后验条件，而非只看软件调用名称。

<a id="exercise-selection"></a>

### 10.12 练习十二：选择之后的区间

**问题。** 对二十个独立且真实均值都为零的模型分别估计平均改进，最后只报告最大估计及它的普通百分之九十五区间。为什么固定模型覆盖不能直接用于这个报告？

**解析。** 被报告模型由同一批随机误差决定，较大的正误差更容易被选中。固定索引下的抽样分布与最大值选择后的分布不同，区间中心出现选择偏差。可采用独立确认样本、同时覆盖区间或适合选择机制的推断。简单增加小数位或用单个模型更精确的标准误，无法消除选择层面的偏差。

<a id="exercise-exact-enumeration"></a>

### 10.13 练习十三：用枚举检查程序

**问题。** 为什么二项覆盖实验中，直接对所有可能成功次数求和可以消除蒙特卡洛误差，却不能消除模型失配？

**解析。** 给定 $`n,p`$，成功次数只有有限种，按精确二项概率加权就是该模型下的数学期望，不需要随机近似。若实际观测存在组内相关，成功次数可能不服从二项分布，枚举再精确也只回答错误模型中的问题。数值精确性与统计有效性是两个维度。应先验证模型与设计，再选择精确求和或模拟作为计算工具。

<a id="sec-7-1"></a>

### 10.14 边界追问：无偏估计是否必然具有更小均方误差

回到本章的收缩例子，风险比较必须在同一个真参数、同一种损失和同一抽样机制下进行。只比较方差会偏爱常数估计，只比较偏差又可能偏爱波动极大的估计。若参数范围有明确业务约束，可以在该范围比较最坏风险；若有可辩护先验，可以比较平均风险；若主要关心覆盖，则应直接评估区间程序。选择准则应从研究目标产生，而不是从某个容易计算的性质反推。

进一步研究可把标量平方损失推广到向量二次损失，把精确正态模型推广到估计方程，把固定样本覆盖推广到同时覆盖和序贯覆盖。但每一步都应保留本章建立的顺序：先写目标，后写随机机制，再列条件，最后计算并解释。这个顺序能让复杂推断保持可检查，也能帮助我们在一个公式失效时准确定位原因。
