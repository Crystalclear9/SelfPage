## 1. 用另一个分布描述真实数据

上一章的熵描述一个分布自身的平均意外程度。本章增加一个关键角色：数据实际由分布 $`P`$ 产生，预测器却使用分布 $`Q`$。研究问题不再只是“数据有多不确定”，而是“模型怎样分配概率，以及这种分配比知道真实分布多付出多少代价”。全文默认自然对数，单位为奈特；需要编码比特时统一除以 $`\ln2`$。对数底不是无关紧要的排版习惯，它同时决定损失尺度与不等式常数。

首先固定同一个有限结果集合。交叉熵定义为 $`H(P,Q)=-\sum_ip_i\ln q_i`$，KL 散度定义为 $`D(P\Vert Q)=\sum_ip_i\ln(\frac{p_i}{q_i})`$。求和按真实分布 $`P`$ 加权，模型不能通过给难样本更少权重来重新定义评价。如果模型改变的是抽样规则或训练权重，必须另行说明目标总体。只写一个“平均损失”而不说谁在平均，常常隐藏了最重要的假设。

<a id="sec-1-1"></a>

### 1.1 基础算例：同样分类正确也可能有不同交叉熵

真实标签是第一类，两个预测为 $`(0.6,0.4)`$ 与 $`(0.9,0.1)`$，都判对，损失分别约 $`0.510826`$ 与 $`0.105361`$。若真实标签是第二类，后者损失变为 $`2.302585`$，前者约 $`0.916291`$。交叉熵对给真实结果分配的概率敏感，准确率只看最大概率类别是否正确，因此两个指标回答不同问题。

把这一例子提升到总体。若真实第一类概率为 $`0.8`$，模型预测第一类概率为 $`q`$，总体风险是 $`R(q)=-0.8\ln q-0.2\ln(1-q)`$。代入 $`q=0.6`$ 得到约 $`0.591919`$，代入 $`q=0.9`$ 得到约 $`0.544805`$，而真正最优 $`q=0.8`$ 给出约 $`0.500402`$。单个正确样本偏好更高自信，但总体会用实际发生的错误惩罚不合理自信，不能把单样本梯度的方向当作总体概率的最终结论。

<a id="deep-dive-1"></a>

### 1.2 深入讲解：编码失配与额外代价

在相同支持且各项有限时，交叉熵中加减真实分布的对数，得到

$$H(P,Q)=H(P)+D(P\Vert Q).$$

真实分布固定时，最小交叉熵与最小该方向 KL 等价；真实熵是不可由预测器改变的基准。若换了数据总体，真实熵也可能改变，因此跨数据集比较损失不能直接推导模型能力更强。一个标签几乎确定的任务，即使用简单模型也可能有很低损失；一个真实标签含有不可消除随机性的任务，最优损失仍有正的下界。

从编码看，理想化码长是 $`-\log_2q_i`$。在真实数据上平均，得到交叉熵比特数；与真实分布的熵相比，多出的 KL 是模型失配代价。实际前缀编码还有整数取整与码本开销，所以交叉熵是概率模型的理想评分，不等于任何特定压缩文件的精确大小。优秀编码实现无法自动挽救错误概率模型，优秀概率模型也不保证文件封装开销可以忽略。

<a id="it2-support"></a>

### 1.3 支持、零概率与无穷值的定义

若 $`p_i=0`$，KL 对应项约定为零；即使同时 $`q_i=0`$ 也不把零除零当作数值运算，而是在零质量集合上使用积分约定。若 $`p_i>0`$ 且 $`q_i=0`$，交叉熵和 KL 为正无穷。这表示真实可能事件被模型断言不可能。用软件时应通过掩码和显式分支表达定义，不应先制造 NaN，再把所有非有限值替换成零。

以 $`P=(0.5,0.5)`$、$`Q=(1,0)`$ 为例，$`D(P\Vert Q)=+\infty`$，反向却是 $`\ln2`$。如果把 $`q_i`$ 统一加上小数再归一化，就改变为另一个严格为正的模型 $`Q_\epsilon`$；这可能是有意义的平滑，但不是原 KL 的精确计算。评估方案应该记录平滑方法和阈值，不同阈值会显著改变极端错误的贡献。

有限集合之外，需要更谨慎。一般定义要求 $`P`$ 相对于 $`Q`$ 绝对连续，再对对数密度比取期望；否则 KL 为无穷。连续交叉熵和微分熵可能为负或无穷，差式可能出现无穷减无穷，不能把形式代数当作定义。KL 本身通过密度比定义，在适当可测条件下保持非负且对共同可逆坐标变换不变，这一点比单独微分熵更稳定。

<a id="it2-gibbs"></a>

### 1.4 非负性、等号与对数和不等式

当支持条件满足时，使用 $`\ln t\le t-1`$，在 $`p_i>0`$ 处令 $`t=\frac{q_i}{p_i}`$，得到 $`D(P\Vert Q)\ge1-\sum_{p_i>0}q_i\ge0`$。等号要求所有正概率位置 $`p_i=q_i`$，且支持外没有额外质量，因此 $`P=Q`$。这个等号结论决定了对数评分的严格性：不是任意一个同样自信的预测都最优，而是必须在概率分配上正确。

另一个常用工具是对数和不等式。对非负序列 $`a_i,b_i`$，令 $`A=\sum_i a_i>0`$、$`B=\sum_i b_i>0`$。把 $`\frac{a_i}{A}`$ 与 $`\frac{b_i}{B}`$ 当作分布，KL 非负给出

$$\sum_i a_i\ln\frac{a_i}{b_i}\ge A\ln\frac AB.$$

零概率和无穷项仍按前述约定处理。这个结论说明合并若干结果，不会增加相应分组的可区分度。将全部类别压成一个伯努利事件后得到的 KL 只能更小，后面证明 Pinsker 不等式时就会用到。证明工具之间的连接比背诵孤立公式更重要：先归一化成分布，再用非负性，最后恢复总质量。

## 2. 为什么负对数概率能学习条件分布

<a id="it2-proper"></a>

### 2.1 严格适当性：从逐点条件风险到总体风险

设输入为 $`X`$，标签为有限类变量 $`Y`$，真实条件概率为 $`p(y\mid x)`$，预测为 $`q(y\mid x)`$。固定输入 $`x`$ 后，对数损失的条件风险满足

$$\mathbb E[-\ln q(Y\mid x)\mid X=x]
=H(P_x)+D(P_x\Vert Q_x).$$

因此在不受模型族约束的所有预测中，唯一最优条件分布是 $`Q_x=P_x`$。对 $`X`$ 再平均，总体超额风险为 $`\mathbb E_XD(P_X\Vert Q_X)`$。零超额风险意味着在输入总体几乎处处匹配真实条件分布；概率为零的输入点不受这个风险约束。此性质称为严格适当性，含义是报告真实概率能使期望评分最优。

这里有四个条件不能省略：评价标签确实来自目标条件分布；风险按目标输入分布平均；模型允许表示该条件分布；讨论的是总体最优而非有限训练集零损失。现实中模型受限时，只能在模型族内找到 KL 意义下的最佳近似；有限样本、优化误差、正则化与分布漂移又会增加偏差。严格适当性说明评分规则的激励方向，不是对任意训练算法的自动一致性保证。

预测器即使没有完美校准，也可能具有较低平均交叉熵；两个模型的交叉熵排序同样不会强迫每个输入点排序一致。总体改善可以由多数样本上的小幅改进抵消少数群体上的退化。若应用关心最差群体或高风险尾部，就要补充相应条件评估，而不能让总体平均替代所有要求。

<a id="sec-2-1"></a>

### 2.2 机制展开：标签表示、logits 与稳定梯度

单个标签 $`y`$ 可写成一热点向量 $`t`$，损失是 $`-\sum_kt_k\ln q_k=-\ln q_y`$。一般软目标 $`t`$ 若满足非负且总和为一，同一式子仍是交叉熵。若目标总和为 $`S\ne1`$，则它成为带总质量的线性组合，梯度与尺度都会变化，不能继续套用归一目标的所有公式。

令 $`q_k=\frac{e^{z_k}}{\sum_je^{z_j}}`$，以 logits $`z`$ 参数化。归一目标下损失为 $`\log\sum_je^{z_j}-\sum_kt_kz_k`$，梯度为 $`q-t`$，Hessian 为 $`\operatorname{diag}(q)-qq^\top`$。任意向量 $`v`$ 的二次型是 $`\sum_kq_kv_k^2-(\sum_kq_kv_k)^2`$，即一个方差，所以半正定。全一方向是零曲率方向，因为给全部 logits 加同一常数不改变概率。

稳定计算先减最大 logit，使用 $`\log\sum_je^{z_j}=m+\log\sum_je^{z_j-m}`$。即使正确类概率在浮点运算中下溢为零，通过 logits 计算的损失仍可能是有限大数。例如 logits 为 $`(1000,-1000)`$ 而真实类为第二类，损失约二千，不必先生成概率零再取对数。对有限输入也要防止更早的矩阵乘法溢出；稳定 log-sum-exp 只修复指数与对数这一阶段。

<a id="it2-curvature"></a>

### 2.3 概率坐标和 logit 坐标下的曲率

二分类在概率坐标下的条件风险为 $`-p\ln q-(1-p)\ln(1-q)`$，导数为 $`\frac{(q-p)}{[q(1-q)]}`$，最优点 $`q=p`$。在 $`p\in(0,1)`$ 的最优点附近，KL 展开为

$$D(\operatorname{Ber}(p)\Vert\operatorname{Ber}(p+\delta))
=\frac{\delta^2}{2p(1-p)}+O(\delta^3).$$

相同绝对概率误差在尾部通常更昂贵，因为分母较小。但该局部近似要求扰动相对边界足够小，不能用二阶式估算跨越零概率边界的无穷损失。多类情况下，在严格正分布与和为零的小扰动上，局部二次型为 $`\frac12\sum_i\frac{\delta_i^2}{p_i}`$，揭示概率几何的非均匀尺度。

换为单个二分类 logit $`z`$ 后，单样本梯度为 $`\sigma(z)-y`$，二阶导为 $`\sigma(z)(1-\sigma(z))`$，至多四分之一。靠近极端概率时 logit 曲率很小，与概率坐标下边界曲率很大不矛盾，因为坐标变换的导数不同。优化器看到的是参数坐标下经过网络雅可比组合的几何，而不是直接在概率单纯形上移动。

若训练标签可分，未正则化模型可能通过不断增大某些参数使损失趋零，却没有有限参数的最小点。这是参数存在性问题，不能据此否定概率空间的严格适当性。更不能把训练集上的极端概率当作总体条件概率已经接近零或一的证据。噪声标签、有限样本和输入覆盖决定了真正的统计问题。

<a id="sec-3"></a>

## 3. 标签平滑、类别权重与标签噪声

<a id="it2-smoothing"></a>

### 3.1 平滑改变的是监督目标

令平滑标签为 $`t=(1-\epsilon)e_y+\epsilon u`$，其中 $`u`$ 是预先固定的参考分布，$`0\le\epsilon\le1`$。在给定输入后，标签期望为 $`r=(1-\epsilon)p+\epsilon u`$，因此最小化平均软交叉熵的最优预测是 $`q^*=r`$，不是原始 $`p`$。当 $`u`$ 均匀且 $`\epsilon`$ 为正时，目标被拉向均匀分布，错误类别也得到正质量。

这可以限制训练对极端概率的偏好，但是否改善部署校准取决于数据和模型。若原模型已经低估置信度，继续拉向均匀可能恶化；若目标总体不同，训练平滑也不能替代分布校正。对固定 $`\epsilon<1`$ 且确知生成方式，形式上可由 $`p=\frac{(q-\epsilon u)}{(1-\epsilon)}`$ 反推，但有限模型误差可能使反推值为负，且误差被放大，所以不能把简单逆变换当作无条件可靠概率恢复。

不同软件对“平滑百分比”的约定可能不同：有的把质量均匀分给所有类，有的只分给非真实类。二者在同一参数值下不是相同目标。比较实验必须写出具体向量公式。软标签蒸馏同理，教师分布承载的是教师的预测与温度选择，不应未经检验直接称为真实标签分布。

<a id="it2-weights"></a>

### 3.2 类别加权的最优概率与阈值恢复

给类别 $`k`$ 正权重 $`w_k`$，条件风险为 $`-\sum_kw_kp_k\ln q_k`$。令 $`A=\sum_kw_kp_k`$，把 $`r_k=\frac{w_kp_k}{A}`$ 归一化，风险变成 $`A H(r,q)`$，故最优预测为

$$q_k^*=\frac{w_kp_k}{\sum_jw_jp_j}.$$

加权改善少数类决策激励的同时，也系统改变了概率含义。若权重已知且模型确实接近该最优，可以按 $`p_k\propto\frac{q_k}{w_k}`$ 校正后归一化。这个恢复依赖模型与假设，不能仅靠调用一次接口就保证校准。

二分类真实正类概率为十分之一，正类权重九、负类权重一，最优加权输出为二分之一。若把该输出直接解释为“真实事件发生率百分之五十”，就夸大五倍。使用阈值二分之一时，加权最优模型等价于对原始概率采用阈值 $`\frac{w_0}{(w_0+w_1)}`$，这里为十分之一。加权可以服务代价敏感决策，但概率报告与决策门槛必须分别说明。

若权重只依赖输入 $`x`$ 且为正，对每个固定输入它仅整体缩放风险，不改变不受限条件最优概率；但它改变不同输入区域在受限模型中的资源分配。若权重还依赖标签，则条件分布本身被倾斜。样本选择概率、重要性权重和类别代价可能形式相似，却代表不同目标，研究时应先写目标风险再决定权重。

<a id="it2-noise"></a>

### 3.3 标注噪声下究竟学到哪个概率

设真实标签为 $`Y`$，观测标签为 $`\widetilde Y`$，给定输入和真实类别后，标注转移概率为 $`T_{ij}=P(\widetilde Y=j\mid Y=i,X=x)`$。若转移与输入无关，观测条件分布是 $`\widetilde p_j=\sum_iT_{ij}p_i`$。普通交叉熵对观测标签严格适当，因此学到的目标是 $`\widetilde p`$，不是自动去噪的 $`p`$。

二分类对称翻转率为 $`\rho<\frac{1}{2}`$ 时，$`\widetilde p=\rho+(1-2\rho)p`$。原始概率零和一被压到 $`\rho`$ 与 $`1-\rho`$。在噪声完全对称且模型无限灵活的理想条件下，阈值二分之一的分类边界保留，但概率值改变；输入相关噪声、类别非对称噪声或者模型受限时，分类边界也可能移动。不能由一个对称模型结论推出任何噪声都无害。

若转移矩阵已知且可逆，理论上可以尝试恢复真实概率，但接近不可逆时误差会被放大。二分类 $`\rho`$ 接近二分之一时，除以 $`1-2\rho`$ 的恢复极不稳定；当 $`\rho=\frac{1}{2}`$，观测标签与真实标签无关，单凭这些观测无法识别原概率。研究噪声鲁棒方法时，必须区分可识别性、有限样本估计与优化三层问题。

<a id="it2-combined"></a>

### 3.4 多种修正的顺序与联合最优目标

如果先平滑每个观测标签，再对每个类别的目标分量乘权重，条件最优为 $`q_k\propto w_k[(1-\epsilon)\widetilde p_k+\epsilon u_k]`$。如果权重是按原始样本的类别乘到整条损失上，而不是按软目标分量加权，期望目标变为 $`(1-\epsilon)w_k\widetilde p_k+\epsilon u_k\sum_jw_j\widetilde p_j`$，再做归一化。两种实现一般不同。

这一区别在一热点标签时不明显，因为只有一个非零分量；一旦启用软标签，就不能把“类别权重”当作唯一确定的数学操作。正确审查办法是拿两类、两个样本写出所有乘法与分母，比较真实函数，而不是只看配置名称。损失实现是否接受未归一软目标、权重是否进入分母，也要检查。

若还加入按样本置信度选出的动态权重，且权重依赖当前参数，那么是否让梯度穿过权重会再次改变函数。停止权重梯度是在优化每一步冻结权重的局部代理；不停止则包含权重导数。二者都可以有用途，但必须给出各自目标和更新机制，不能把不同训练程序都称作同一个固定交叉熵风险。

<a id="visual-extension-informationtheory-02"></a>
### 图解：标签平滑改变概率目标而非只改梯度大小

![标签平滑改变概率目标而非只改梯度大小](images/02-extension.svg)

二分类硬标签为(1,0)，与均匀分布按ε=0.2混合后变成(0.9,0.1)。在能自由选择概率的单样本模型里，交叉熵最小点从第一类概率1移到0.9，因此平滑确实改变最优预测目标。

实际模型会共享参数且受到数据分布约束，不能把每个样本都独立设成目标概率；平滑也不自动保证真实部署概率校准。



<a id="sec-4"></a>

## 4. 批量归约、统计对象与评价协议

<a id="it2-reduction"></a>

### 4.1 样本、词元与权重分母

一组损失 $`\ell_i`$ 可按样本数平均，也可按总权重归一化：$`\sum_i\frac{w_i\ell_i}{n}`$ 与 $`\frac{\sum_iw_i\ell_i}{\sum_iw_i}`$ 在固定数据和固定权重下相差常数，但梯度尺度、与正则项的相对强度以及跨批统计都会不同。若批内类别比例变化，总权重也变化，逐批权重均值再平均未必等于全数据的总权重归约。

序列任务中，逐序列先平均再等权汇总，和全部有效词元一起平均，是不同抽样对象。两条序列长度为二和八，平均损失分别一和三，序列等权损失是二，词元等权是二点六。若短序列恰好集中于某类用户，归约选择还会改变群体影响。填充位置需要由预先定义的掩码排除，不能混入大量容易预测的填充值来降低损失。

微批梯度累积同样需要按有效权重合并。两个微批的有效词元数分别十和九十，其均值不能简单各乘二分之一；要得到大批目标，应分别乘十分之一和十分之九。分布式训练时，各设备有效数目不等也有相同问题。把一个固定批拆成多个微批后，若数学目标宣称不变，应使用固定参数检查损失与梯度一致性；有训练状态或随机性时另需说明。

<a id="it2-statistics"></a>

### 4.2 平均损失下降不代表所有质量同时改善

总体对数风险是完整概率分配的评分，而准确率、召回率、校准误差和业务收益分别关注不同方面。一个模型可以把大量容易样本的真实类概率从零点七提高到零点八，同时在少数高风险群体上退化，总体交叉熵仍下降。应该报告整体与关键条件群体，附上样本数和不确定性，而不能只挑一个最有利指标。

对数损失无上界，极端错误可能支配均值。有限样本评估中应保留每个样本的配对损失差，检查尾部、异常输入和概率支持。若只报告裁剪损失，需承认目标已经改变；若使用截尾均值或稳健估计，也要说明其与原始期望风险的关系。评价数据出现标签错误时，大损失可能指出标注问题，但不能因为影响分数就自动删除。

重复选择最低验证交叉熵的模型，会让同一验证集上的最低值向下偏。校准温度、平滑强度和阈值也都是选择参数，不能在测试集上选好后再把该测试集称作独立证据。应把训练、模型选择、校准和最终测试的职责安排清楚，数据较少时使用嵌套验证或交叉拟合，并按真正独立的单位划分。

<a id="it2-calibration"></a>

### 4.3 校准与分辨能力：相同均值不等于正确概率

二分类校准的一种定义是 $`\mathbb E[Y\mid Q]=Q`$。如果总正类率为百分之十，一个永远输出零点一的模型在总体上可以校准，却无法区分高低风险个体。另一个能识别不同风险组且同样校准的模型具有更高分辨能力，通常能获得更低适当评分风险。校准不是唯一目标，不能通过把全部预测压成常数就宣称系统已经优秀。

多类任务中，检查最高置信度与正确率的对应，只是置信度校准；逐类概率校准与完整向量校准更强。两个错误类别的概率可能严重互换，却仍有相同最大置信度和正确率。分箱校准误差依赖分箱规则、样本量与估计方式，零或很小的经验值也不证明总体精确校准。

解释校准图时，应同时看每箱样本数、概率范围和不确定区间。若一个稀有高置信度箱只有几个样本，观察到全对或全错都不应过度解读。部署分布改变也可能破坏原有校准；特别是类别先验或输入构成变化时，训练时的总体关系未必保留。交叉熵是严格适当评分，但经验上降低它并不等于所有分箱的校准误差都单调减少。

<a id="it2-prior-shift"></a>

### 4.4 类别先验变化与条件概率校正

部署分布发生变化时，先明确哪一部分机制保持。假设训练与部署的类条件输入分布相同，即 $`P_{\rm deploy}(x\mid y)=P_{\rm train}(x\mid y)`$，但类别先验从 $`\pi_y`$ 变为 $`\pi'_y`$，且训练先验在相关类别上为正。由贝叶斯公式，部署后验满足

$$p_{\rm deploy}(y\mid x)\propto
p_{\rm train}(y\mid x)\frac{\pi'_y}{\pi_y}.$$

这与类别权重的形式相似，但含义不同：这里权重用于把已知训练后验转换到另一个总体，前面类别加权则是在训练风险中主动倾斜目标。恢复是否有效取决于先验变化假设和训练概率质量，不能仅因为公式看起来相同就直接迁移结论。

例如训练正类先验十分之一，部署变为五分之一，某个输入的训练后验为二分之一。正类先验比为二，负类先验比为九分之八，即 $`\frac{(1-\frac{1}{5})}{(1-\frac{1}{10})}=\frac{8}{9}`$，因此校正后正类概率为 $`\frac{2}{(2+\frac{8}{9})}=\frac{9}{13}\approx0.692308`$。类别先验翻倍并不意味着每个后验直接乘二；必须同时校正负类并归一化。若输入机制也改变，同一公式一般不再成立，需要更强数据或模型假设。

在输入协变量漂移假设下，保持的是 $`P(y\mid x)`$，改变的是输入边缘。理想条件概率不用修改，但平均交叉熵和群体构成会改变；受限模型重新训练时，输入权重会影响最佳近似。先验漂移与协变量漂移是不同机制，不能在看到测试损失变化后任选一个方便解释。研究中应比较类条件分布、先验和输入支持，并承认有限数据很难完全验证这些假设。

<a id="sec-5"></a>

## 5. KL 方向、模型限制与信息分解

<a id="it2-direction"></a>

### 5.1 同样叫分布匹配，期望来源可以相反

前向 KL $`D(P\Vert Q)`$ 按目标分布加权，目标常出现而模型概率不足的区域受到惩罚；反向 KL $`D(Q\Vert P)`$ 按模型分布加权，模型把质量放在目标极低甚至零概率区域时受到惩罚。若模型族包含 $`P`$，两者都在 $`Q=P`$ 处达到零；方向差异在模型受限、数值估计与优化路径中才更明显。

不要把“覆盖模式”和“寻找模式”当作无条件定理。模型族可能同时不允许覆盖，也不允许集中；目标也可能单峰或具有有限支持。连续情形还需要保证积分可计算，反向目标常涉及目标归一化常数是否可消去、是否可从模型采样。方向决定期望与支持惩罚，具体几何行为仍需分析可行集合。

取目标 $`P=(0.49,0.02,0.49)`$，限制模型只能在两个候选中选：集中候选 $`Q_a=(0.96,0.02,0.02)`$，宽候选 $`Q_b=(0.3,0.4,0.3)`$。前向 KL 会偏好宽候选，因为集中候选几乎遗漏第三类；反向 KL 会偏好集中候选，因为宽候选在真实稀少的中间类放了过多质量。这个有限候选例子精确展示方向冲突，同时不声称对任意连续混合和任意模型族都如此。

<a id="it2-gaussian"></a>

### 5.2 高斯近似：哪些结论可以直接推导

用单个高斯 $`Q=N(m,S)`$ 近似具有有限二阶矩的连续目标。前向 KL 中与模型相关的部分是 $`\frac12\ln\det S+\frac12\mathbb E_P[(X-m)^\top S^{-1}(X-m)]`$。在协方差正定等正常条件下，对均值和协方差优化得到 $`m=\mathbb E_PX`$、$`S=\operatorname{Cov}_P(X)`$，即匹配前两阶矩。

若目标是两个相隔很远的等权窄高斯，匹配均值落在中间，匹配方差包含峰间距离带来的方差；近似会在两个峰之间分配概率。反向 KL 的目标含有 $`\mathbb E_Q\ln p(X)`$，混合密度的对数不能按分量线性拆开，因此通常没有同样简单的矩匹配闭式解。足够分离的模式和受限窄高斯族下，某个峰附近可能更有利，但必须比较实际目标，而不能把口号替代证明。

连续分布的支持细节也重要。一个高斯对全实轴给正密度，若目标严格截断到有限区间，反向 KL 对任何非退化高斯都为无穷；这时讨论哪个高斯“更接近”需要先改变模型族或目标。给目标加极小尾部虽可得到有限值，却改变原问题，且极小尾部会强烈影响反向目标。

<a id="it2-chain-kl"></a>

### 5.3 联合 KL 的链式分解

在共同有限空间并满足相应支持条件时，联合概率比可拆为边缘比与条件比，取 $`P`$ 下期望得到

$$D(P_{XY}\Vert Q_{XY})=D(P_X\Vert Q_X)
+\mathbb E_{X\sim P_X}D(P_{Y\mid X}\Vert Q_{Y\mid X}).$$

第二项按真实边缘 $`P_X`$ 加权，不能换成 $`Q_X`$。边缘分布差异和条件机制差异被分开：两个系统可以在标签总比例上相近，却在不同输入下给出错误概率；反过来，条件机制相同而输入总体改变，也会导致联合分布变化。

非负性立即给出边缘化不增加 KL。更一般地，经过同一个随机观测通道后，输出 KL 不超过输入 KL；可通过把通道变量加入联合分布，再使用链式或对数和不等式证明。这是分布可区分度的数据处理思想。若两个模型用不同后处理通道，则不能直接引用同一结论；通道本身可能引入额外差异。

在连续或无限离散情形，可以在合适条件下用测度形式表达链式。实际应用仍应检查条件分布版本、绝对连续性与无穷值，避免写出不存在的差。这里建立的是分解工具，互信息的条件链式、特征选择和因果误读在第四章进一步展开。

<a id="it2-centroid"></a>

### 5.4 KL 重心：算术平均与几何平均来自不同方向

假设有若干严格正的教师分布 $`P_j`$，权重 $`\alpha_j`$ 非负且总和为一。若选择学生分布 $`Q`$ 最小化 $`\sum_j\alpha_jD(P_j\Vert Q)`$，所有与 $`Q`$ 有关的项是 $`-\sum_i(\sum_j\alpha_jp_{ji})\ln q_i`$，所以最优学生为算术混合 $`q_i=\sum_j\alpha_jp_{ji}`$。这就是用平均软标签训练不受限学生时的目标。

若改为最小化 $`\sum_j\alpha_jD(Q\Vert P_j)`$，目标与 $`Q`$ 有关的部分为 $`\sum_iq_i\ln q_i-\sum_iq_i\sum_j\alpha_j\ln p_{ji}`$。拉格朗日乘子给出 $`q_i\propto\exp(\sum_j\alpha_j\ln p_{ji})=\prod_jp_{ji}^{\alpha_j}`$，即归一化几何平均。两种融合一般不同：算术平均保留各教师的概率质量，几何平均更强调共同支持。若某个教师把某类概率置零，反向形式可能强制学生也对该类置零，需要显式处理支持交集。

例如两位等权教师分别给出 $`(0.9,0.1)`$ 与 $`(0.6,0.4)`$。算术平均是 $`(0.75,0.25)`$；几何平均的未归一值是 $`(\sqrt{0.54},\sqrt{0.04})`$，归一后第一类约为零点七八六。若把两个教师直接视为独立证据而相乘，则还需要考虑共同先验与证据依赖，不能把这个优化重心自动解释为正确贝叶斯后验。方向性不仅影响近似模式，也影响知识融合的实际结果。

<a id="it2-restricted-projection"></a>

### 5.5 模型受限时，交叉熵最优与校准之间的关系

把真实条件分布投影到有限参数模型族，得到的是 $`\mathbb E_XD(P_X\Vert Q_{\theta,X})`$ 的最佳近似。若模型仅能输出常数，最优常数是总体类别频率；它可能总体校准，却丢掉全部输入分辨力。若模型仅按粗分组输出常数，则各组的最优是组内真实比例，无法区分组内差异。这个层级说明，严格适当性是关于允许报告的全部概率函数，而实际模型能力决定能否接近它。

对满足常规条件且含自由截距的逻辑模型，经验最优的一阶条件常使总体预测均值匹配经验标签均值；这只是边际平衡，不是逐风险水平校准。一个模型可以在全体上平均预测正确，却在高风险区低估、低风险区高估。正则化截距、加权损失与提前停止还可能改变这个平衡关系，因此任何校准结论都应从真实优化条件出发。

模型比较时，应尝试判断误差来自表达受限、数据有限还是优化未收敛。增加模型容量可能减小近似误差却增大估计波动；加平滑可能增加理想目标偏差却减小有限样本方差。将这些机制分开，才能解释为什么一个理论上“偏向错误目标”的正则策略，在真实测试集上仍可能改善原始交叉熵。实验应报告多次划分或合适的不确定性，而不是把单次微小差异当作确定规律。

<a id="visual-detail-informationtheory-02"></a>

## 6. 进阶：替代散度、变分表示与温度

<a id="sec-6-1"></a>

### 6.1 KL 方向怎样改变支持约束

把 $`P=(0.5,0.5)`$ 与 $`Q=(1,0)`$ 再检查一次。前向 KL 必须为目标两种结果都预留概率，反向 KL 却允许模型完全不访问第二种结果。这解释了反向目标可能遗漏某些模式，但若目标在模型访问区域也很小，反向仍会罚得很重。支持条件不是数值边角，它直接决定候选模型是否具有有限目标值。

此外，KL 不对称，也不满足三角不等式。可用伯努利参数零点一、零点二、零点三构造三角不等式反例：从零点一到零点三的 KL 大于经过零点二两段同向 KL 的和。局部 KL 大致像二次距离，而平方距离本来就不满足普通三角不等式。不能因为某次实验中三个值恰好符合，就把 KL 当作度量。

<a id="it2-js"></a>

### 6.2 Jensen–Shannon 散度与总变差

令 $`M=\frac{(P+Q)}{2}`$，定义 $`\operatorname{JS}(P,Q)=\frac12D(P\Vert M)+\frac12D(Q\Vert M)`$。它对称且在自然单位下位于零和 $`\ln2`$ 之间，因为 $`M_i\ge\frac{p_i}{2}`$ 和 $`M_i\ge\frac{q_i}{2}`$。即使两个分布支持不相交，它仍有限；此时值为 $`\ln2`$。不要把 JS 本身直接称为距离，标准度量性质属于其平方根。

总变差定义为 $`\operatorname{TV}(P,Q)=\frac12\sum_i\vert p_i-q_i\vert =\sup_A\vert P(A)-Q(A)\vert `$。第二个等式可取集合 $`A=\{i:p_i\ge q_i\}`$ 验证：所有正差之和等于全部负差绝对值之和。它表示任意一个事件概率最大的可能差别，也连接二元检验的最佳区分能力。

总变差有界，容易解释，但不强调某个稀有事件被赋零概率的无限代价。KL 则可能对这一点无限敏感。选择散度不是选一个数值最温和的指标，而是决定哪些偏差重要、数据能支持什么估计，以及目标与任务损失怎样连接。多个指标并列报告往往比只给一个神奇数字更清晰。

<a id="it2-pinsker"></a>

### 6.3 Pinsker 不等式的条件和一条证明路线

自然对数下，Pinsker 不等式为 $`D(P\Vert Q)\ge2\operatorname{TV}(P,Q)^2`$。若 KL 为无穷，结论显然；否则把类别按 $`A=\{p_i\ge q_i\}`$ 合并成两个事件，由对数和不等式得到原 KL 不小于伯努利参数 $`a=P(A)`$、$`b=Q(A)`$ 的 KL，其中 $`a-b=\operatorname{TV}`$。

固定 $`b\in(0,1)`$，伯努利 KL 对第一个参数 $`a`$ 的二阶导为 $`\frac{1}{[a(1-a)]}\ge4`$，且在 $`a=b`$ 处函数值和一阶导都为零，因此沿区间积分两次得到 $`D(\operatorname{Ber}(a)\Vert\operatorname{Ber}(b))\ge2(a-b)^2`$。端点通过连续延拓或无穷值处理。证明特别说明了求导对象：这里对第一个概率求导，与前面固定真实概率、优化第二个概率的导数不同。

如果 KL 用二为底，常数应改为 $`D_2\ge(\frac{2}{\ln2})\operatorname{TV}^2`$。若 $`0\le f\le1`$，期望差的绝对值不超过总变差；因此小 KL 可以控制所有有界单位范围统计量的差。它不能在没有额外尾部条件时控制任意无界损失的期望差，也不能反过来说总变差很小必定让 KL 很小。极小概率区域的支持不匹配可使总变差很小而 KL 仍无穷。

<a id="it2-variational"></a>

### 6.4 变分表示与可计算下界的区别

在有限支持且 $`P,Q`$ 严格为正时，对任意实值函数 $`f`$，定义倾斜分布 $`Q_f(i)=\frac{q_i e^{f_i}}{Z}`$，其中 $`Z=\sum_iq_ie^{f_i}`$。代入 KL 非负性，得到

$$D(P\Vert Q)\ge\mathbb E_Pf-\ln\mathbb E_Qe^f.$$

取 $`f_i=\ln(\frac{p_i}{q_i})`$ 加任意常数可达等号，因而上确界等于 KL。若概率有零项，需要允许逼近与扩展实值并检查条件，而不能盲目把无穷最优函数塞进有限神经网络。

把函数限制在某个可训练族，就只得到 KL 的一个下界，训练出的值小不代表真实 KL 小；可能只是函数族不够区分、优化不充分或者样本不足。尤其 $`\ln`$ 是凹函数，用样本均值代替 $`\mathbb E_Qe^f`$ 后再取对数会引入偏差；如果同一数据还用于选择 $`f`$，又叠加过拟合。总体不等式不能直接保证每个有限样本计算值仍是高置信下界。

指数项对尾部敏感，少数很大的 $`f`$ 会使估计方差很大。稳定 log-sum-exp 可以避免算术溢出，却不能解决统计方差。应区分表达能力、优化收敛、数值稳定与统计估计这四个层次；修复其中一层不意味着其他层自动解决。互信息下界的估计也面临同类问题，第四章将继续讨论。

<a id="it2-temperature"></a>

### 6.5 温度缩放、凸参数与独立校准集

固定模型 logits 后，温度缩放用 $`q_k(T)=\operatorname{softmax}(\frac{z_k}{T})`$，其中 $`T>0`$。它保持同一样本的类别排序，因此在唯一最大值且使用最大概率分类时不改变预测类别；概率置信度则改变。令逆温度 $`a=\frac{1}{T}\ge0`$，校准集平均损失为 $`\mathbb E[\log\sum_ke^{az_k}-az_y]`$，对 $`a`$ 的二阶导是模型概率下 logits 的方差平均，故凸。

凸性不保证最优点一定在有限正温度。若校准样本全部以正确类严格领先，增大逆温度可以持续降低损失，最优可能位于无限逆温度的边界；若模型反向严重，限制 $`a\ge0`$ 时最优可能在零，对应均匀概率的极限。数值实现应处理边界和有限样本不确定性，而不是假设优化器返回的任何正数都具有稳定总体意义。

温度只调一个全局尺度，不能修复所有类相关或输入相关的校准错误，也不改变错误类别排序。应在独立校准集上选温度，再在未使用的测试集检查损失与条件表现。对蒸馏，教师和学生同时使用温度时，目标本身也变化；常见额外乘 $`T^2`$ 是一种梯度尺度补偿约定，不是概率分布定义的一部分，也不保证所有温度下训练函数完全等价。

<a id="it2-risk-certificates"></a>

### 6.6 从交叉熵超额风险到分类超额风险

交叉熵的价值还在于把概率误差连接到决策误差。给定输入，真实最优类别为 $`a=\arg\max_kp_k`$，模型选择 $`b=\arg\max_kq_k`$。若两者不同，因为 $`q_b\ge q_a`$，有 $`p_a-p_b\le\vert p_a-q_a\vert +\vert p_b-q_b\vert \le\sum_k\vert p_k-q_k\vert =2\operatorname{TV}(p,q)`$。左边正是该输入处使用模型分类而非真实最优分类增加的零一风险。

再用 Pinsker 得到条件超额分类风险不超过 $`\sqrt{2D(p\Vert q)}`$；对输入平均并用平方根凹性，得到总体超额分类风险不超过 $`\sqrt{2\mathbb E_XD(P_X\Vert Q_X)}`$。这里交叉熵超额指减去真实条件熵后的总体差，而不是减去任意基线模型损失，也不是直接把训练交叉熵数值塞入公式。

这个界说明总体概率风险接近理想最优时，零一决策也能接近理想最优，但通常很保守。它不能保证某个固定阈值下的少数类召回，也不适用于未经修改的任意代价矩阵。代价敏感问题应写出相应 Bayes 决策和损失范围，再建立转换。有限数据里真实条件熵未知，通常无法直接精确测量超额风险，因此该界主要提供一致性与机制理解，而不是凭一个测试均值就颁发全面可靠证书。

<a id="it2-finite-evaluation"></a>

### 6.7 有限样本评估：为什么不能随便从损失减一个经验熵

固定预测器后，在独立同分布测试样本上平均负对数概率，是目标交叉熵的自然估计；若期望有限，可应用相应大数定律。模型预测函数若已用这批标签选择，条件于模型的独立性就不再成立，训练均值或重复调参后的最低均值会偏乐观。数据按用户或时间簇相关时，独立单位应是簇，不能把同一用户的一千条记录当作一千个独立证据。

有人把平均条件分类损失减去全体标签的经验边缘熵，称为“模型 KL”。一般不成立。条件任务的不可约基准是 $`H(Y\mid X)`$，而全体频数估计的是 $`H(Y)`$；两者通常不同。即使减去正确对象的估计值，两个估计量的偏差、相关性和不确定性也要处理。模型损失小于标签边缘熵完全正常，表示输入提供了有用信息，不代表 KL 变为负数。

比较两个固定模型时，最好利用同一测试对象上的配对损失差 $`d_i=\ell_i^{(A)}-\ell_i^{(B)}`$。配对保留了同一个样本难度带来的相关性，通常比把两组均值当作独立更有效。若差值尾部重或样本依赖，普通标准误的适用性需要检查；可按真正独立的用户或序列做分组重采样，并报告极端样本对结果的贡献。重采样方法也不是无条件保证，应匹配实际抽样机制。

若预先强制所有类别概率至少为 $`\delta>0`$，损失上界为 $`-\ln\delta`$，更容易使用有界变量集中界；但这种截断约束会改变允许模型族和理想评分对象。在 $`K`$ 类情况下还必须有 $`K\delta\le1`$，否则根本不存在合法分布。合理研究会把截断值、归一方式、独立数据划分和被比较模型的选择过程一起写明。稳定数值计算、统计置信与概率建模是三个不同承诺，不能由其中一个替代其余两个。

### 7.1 支持安全的散度实现和数学断言

下面使用 NumPy 实现有限概率向量的交叉熵、KL、JS 与总变差。输入必须有限、非负、总和为一；不会自动归一化错误输入，因为静默修正会掩盖调用者的对象错误。计算 KL 时只对 $`P`$ 正质量位置取对数，并在目标支持缺失时显式返回正无穷。这样能区分数学上无穷与程序产生 NaN 两种不同问题。

```python
import numpy as np


def prob(values):
    x = np.asarray(values, dtype=np.float64)
    if x.ndim != 1 or len(x) == 0 or not np.all(np.isfinite(x)):
        raise ValueError("expected a finite nonempty probability vector")
    if np.any(x < 0) or not np.isclose(x.sum(), 1.0, atol=1e-12, rtol=0):
        raise ValueError("invalid probability normalization")
    return x


def pair(p, q):
    p, q = prob(p), prob(q)
    if p.shape != q.shape:
        raise ValueError("probability shapes differ")
    return p, q


def entropy(p):
    p = prob(p)
    positive = p > 0
    return float(-np.sum(p[positive] * np.log(p[positive])))


def cross_entropy(p, q):
    p, q = pair(p, q)
    positive = p > 0
    if np.any(q[positive] == 0):
        return float("inf")
    return float(-np.sum(p[positive] * np.log(q[positive])))


def kl(p, q):
    p, q = pair(p, q)
    positive = p > 0
    if np.any(q[positive] == 0):
        return float("inf")
    return float(np.sum(p[positive] *
                        (np.log(p[positive]) - np.log(q[positive]))))


def tv(p, q):
    p, q = pair(p, q)
    return float(0.5 * np.abs(p - q).sum())


def js(p, q):
    p, q = pair(p, q)
    m = 0.5 * (p + q)
    return 0.5 * (kl(p, m) + kl(q, m))


p, q = prob([0.8, 0.2]), prob([0.6, 0.4])
assert np.isclose(cross_entropy(p, q), entropy(p) + kl(p, q))
assert kl(p, q) >= 2 * tv(p, q) ** 2
print("H, CE, KL:", entropy(p), cross_entropy(p, q), kl(p, q))
assert np.isinf(kl([0.5, 0.5], [1, 0]))
assert np.isclose(kl([1, 0], [0.5, 0.5]), np.log(2))
assert np.isclose(js([1, 0], [0, 1]), np.log(2))

P = prob([0.49, 0.02, 0.49])
Qa, Qb = prob([0.96, 0.02, 0.02]), prob([0.3, 0.4, 0.3])
assert kl(P, Qb) < kl(P, Qa)
assert kl(Qa, P) < kl(Qb, P)
print("directions:", kl(P, Qa), kl(P, Qb), kl(Qa, P), kl(Qb, P))

A, B, C = [0.1, 0.9], [0.2, 0.8], [0.3, 0.7]
assert kl(A, C) > kl(A, B) + kl(B, C)
f = np.log(p / q)
bound = float(p @ f - np.log(q @ np.exp(f)))
assert np.isclose(bound, kl(p, q))

rng = np.random.default_rng(73)
for _ in range(100):
    a, b = rng.dirichlet(np.ones(5), size=2)
    assert kl(a, b) + 1e-12 >= 2 * tv(a, b) ** 2
    assert -1e-12 <= js(a, b) <= np.log(2) + 1e-12
print("all divergence checks passed")
```

随机断言用于捕捉实现错误，不替代前面已经给出的数学证明。它不覆盖无限支持、连续奇异分布或极端浮点范围。若概率非常接近，直接计算 KL 可能因舍入出现极小负值；分析时要区分与机器精度相当的残差和明显错误，不能把所有负值无条件截零后就不再调查。

### 7.2 稳定交叉熵、软目标梯度与温度实验

第二段实验对软目标计算稳定 logits 损失，用中心差分核对梯度，并独立展示类别加权和平滑的理想最优。温度实验使用一组人为构造的八个二分类样本：每个样本都给预测类相同置信度，其中六个预测正确。

因为只存在一个绝对 logit 间隔，最优概率可手算为四分之三，适合作为校准代码的闭式基准。稳定移位避免指数上溢，但不能突破浮点表示范围：两个有限 logits 的差仍可能溢出。实现会显式拒绝空批次、空类别轴和无法表示的算术结果，避免零目标权重乘负无穷后悄悄产生 NaN。

```python
import numpy as np
from scipy.optimize import minimize_scalar


def log_softmax(z):
    z = np.asarray(z, dtype=np.float64)
    if z.ndim != 2 or 0 in z.shape or not np.all(np.isfinite(z)):
        raise ValueError("expected finite nonempty matrix of logits")
    with np.errstate(over="raise", invalid="raise", divide="raise"):
        shift = z - z.max(axis=1, keepdims=True)
        return shift - np.log(np.exp(shift).sum(axis=1, keepdims=True))


def loss_grad(z, t):
    z, t = np.asarray(z, float), np.asarray(t, float)
    if z.ndim != 2 or 0 in z.shape or z.shape != t.shape or np.any(t < 0):
        raise ValueError("target contract violated")
    row_mass = t.sum(axis=1, keepdims=True)
    if not np.all(np.isfinite(t)) or not np.allclose(row_mass, 1, atol=1e-12, rtol=0):
        raise ValueError("targets must be probability rows")
    lp = log_softmax(z)
    with np.errstate(over="raise", invalid="raise"):
        value = float(-np.sum(t * lp) / len(z))
    # 保留实际行质量，使容差内的舍入偏差也与所计算损失的导数一致。
    return value, (np.exp(lp) * row_mass - t) / len(z)


z = np.array([[1.2, -0.4, 0.3], [-0.2, 0.8, 0.1]])
t = np.array([[0.8, 0.1, 0.1], [0.1, 0.2, 0.7]])
value, grad = loss_grad(z, t)
fd = np.zeros_like(z)
h = 1e-5
for index in np.ndindex(z.shape):
    plus, minus = z.copy(), z.copy()
    plus[index] += h
    minus[index] -= h
    fd[index] = (loss_grad(plus, t)[0] - loss_grad(minus, t)[0]) / (2 * h)
assert np.allclose(grad, fd, atol=1e-10, rtol=1e-7)
assert np.allclose(grad.sum(axis=1), 0)
assert np.isclose(value, loss_grad(z + 100, t)[0])
extreme = loss_grad([[1000.0, -1000.0]], [[0.0, 1.0]])[0]
assert np.isfinite(extreme) and np.isclose(extreme, 2000)
for invalid in [np.empty((0, 2)), np.empty((2, 0))]:
    try:
        log_softmax(invalid)
    except ValueError:
        pass
    else:
        raise AssertionError("empty axes do not define this mean loss")
try:
    loss_grad([[1e308, -1e308]], [[1., 0.]])
except FloatingPointError:
    pass
else:
    raise AssertionError("unrepresentable logit difference must fail explicitly")
print("gradient error:", np.max(np.abs(grad - fd)), "extreme loss:", extreme)

p = np.array([0.9, 0.1])
w = np.array([1.0, 9.0])
weighted = w * p / (w @ p)
recovered = weighted / w
recovered /= recovered.sum()
assert np.allclose(weighted, [0.5, 0.5])
assert np.allclose(recovered, p)
smoothed = 0.9 * p + 0.1 * np.array([0.5, 0.5])
assert np.allclose(smoothed, [0.86, 0.14])
print("targets:", weighted, smoothed)

# All examples initially predict class 1 with sigmoid(4) confidence.
logits = np.tile([0.0, 4.0], (8, 1))
y = np.array([1, 1, 1, 1, 1, 1, 0, 0])
rows = np.arange(len(y))

def nll_inverse_temperature(a):
    return float(-log_softmax(a * logits)[rows, y].mean())

fit = minimize_scalar(nll_inverse_temperature, bounds=(0.0, 2.0),
                      method="bounded", options={"xatol": 1e-12})
assert fit.success
expected_a = np.log(3) / 4
assert np.isclose(fit.x, expected_a, atol=1e-6)
assert nll_inverse_temperature(fit.x) < nll_inverse_temperature(1.0)
assert np.array_equal(logits.argmax(axis=1), (fit.x * logits).argmax(axis=1))
print("temperature:", 1 / fit.x, "NLL before/after:",
      nll_inverse_temperature(1.0), fit.fun)
```

这里同一八样本用于求解闭式基准和验证实现，属于算法单元实验，不是声称泛化改善的正式评估。真实系统需要另设测试集；如果把温度拟合在测试标签上，这个数就有选择偏差。实验的正确结论是“实现找到了这个校准样本目标的最优值，并保持类别排序”，不能升级为“任何数据上概率均已正确”。

### 8.1 交叉熵、支持与方向

**练习一：一热点目标。** $`P=(1,0)`$、$`Q=(0.25,0.75)`$，计算熵、交叉熵和 KL，并解释第二类概率是否完全无关。

**解答：** 真实熵为零，交叉熵和 KL 均为 $`-\ln0.25\approx1.386294`$。第二类没有直接的加权项，但通过概率和为一的约束影响第一类可用质量；若提高第二类而保持归一，就会降低第一类并增加损失。不能因为求和里某项乘零，就断言模型对其他类别的分配从不重要。多类中，错误类别之间的重分配在真实一热点样本上可能不改当前损失，却会影响其他样本或软目标。

**练习二：交换方向。** 对 $`P=(0.5,0.5)`$、$`Q=(1,0)`$ 比较两个方向，再说明用小常数代替零会发生什么。

**解答：** 前向 KL 为无穷，反向为 $`\ln2`$。把零换成正数并重新归一后得到新模型，前向变为有限，但随着小数趋零仍发散。反向则趋于原来的有限值。这个极限展示方向差异是数学目标的真实性质，不是程序异常。若软件把无穷替成零，会把最严重支持错误误报成完美匹配，完全颠倒评价。

**练习三：熵相同是否交叉熵相同？** 比较 $`P=(0.9,0.1)`$ 与其反转 $`Q=(0.1,0.9)`$。

**解答：** 两者自身熵都约零点三二五零八三，但交叉熵 $`H(P,Q)=-0.9\ln0.1-0.1\ln0.9\approx2.082863`$，显著更大。KL 约一点七五七七八。模型可以拥有恰好正确的总体自信程度，却把高概率分给错误类别。校准与标签对应、类别语义和条件预测都不能由预测熵单独检验。

**练习四：边缘 KL 能恢复联合 KL 吗？** 两个二元联合分布的边缘都均匀，一个总有 $`Y=X`$，另一个总有 $`Y=1-X`$。边缘比较会看到什么？

**解答：** 两个单变量边缘 KL 均为零，但联合支持完全不重叠，联合 KL 两个方向都为无穷。边缘化丢掉了相关结构，因而只能给下界，不能一般恢复联合差异。若研究输入标签关系，只匹配标签频率无法证明模型机制正确；必须检查条件分布或联合结构。给支持加平滑后无穷可变有限，但边缘相同、联合不同的事实不变。

<a id="it2-exercises-b"></a>

### 8.2 训练目标、噪声与梯度

**练习五：平滑后的最优概率。** 真实二分类概率 $`(0.9,0.1)`$，采用十分之一均匀平滑，最优输出是什么？能否直接称为真实概率？

**解答：** 最优输出是 $`0.9(0.9,0.1)+0.1(0.5,0.5)=(0.86,0.14)`$。它对平滑目标严格适当，却偏离原始条件概率。若用同一个未平滑测试风险评分，理想原概率仍更优。平滑在有限模型和有限样本中可能通过正则化效应改善实际泛化，这与理想总体最优改变并不矛盾；应分别讨论统计偏差和方差，而不是宣称目标从未改变。

**练习六：类别加权与恢复。** 正类真实概率十分之一、正类权重九、负类权重一，求加权最优预测及恢复公式。

**解答：** 两类加权质量都为零点九，所以最优正类输出二分之一。恢复时分别除以原类别权重，得到未归一质量 $`(0.5,\frac{0.5}{9})`$，再归一得到 $`(0.9,0.1)`$。这只在权重已知、目标形式正确、模型近似理想最优时成立。若再加入标签噪声、平滑或参数正则，恢复需要针对完整目标重新推导，不能直接套同一逆公式。

**练习七：噪声不可识别边界。** 对称标签翻转率二分之一时，为什么再强的交叉熵优化也无法从观测标签恢复真实条件概率？

**解答：** 观测正类概率恒为二分之一，与真实条件概率无关。所有真实概率函数都产生同样观测标签机制，因此不存在仅靠这些观测区分它们的统计方法。问题出在信息缺失，而非梯度下降不够努力。若增加干净标注、已知锚点、重复独立标注等外部信息，可能重新获得可识别性，但必须显式列出新增假设。

**练习八：未归一软目标的梯度。** 目标向量总质量为 $`S`$，推导 logits 梯度，并说明归一化何时只是尺度变化。

**解答：** 损失为 $`S\log\sum_ke^{z_k}-t^\top z`$，梯度为 $`Sq-t`$，而不是 $`q-t`$。若每个样本的 $`S`$ 都是相同正数，整体归一化只改变数据项尺度；若各样本总质量不同，相当于改变样本权重。正则项未同步缩放时，即使统一尺度也会改变最优参数。这个例子说明输入数据的“看起来像概率”不能代替行和检查。

**练习九：重复 softmax。** 一个接口明确接收 logits，却传入已经归一的概率，会优化原来的交叉熵吗？

**解答：** 不会。接口会再次把概率当作 logits 做 softmax，损失变为 $`-\ln\operatorname{softmax}(q)_y`$。即使原概率趋向一热点，第二次 softmax 的最大值也只能趋向 $`\frac{e}{(e+K-1)}`$，无法达到一，梯度链也改变。应检查函数契约而非依据变量名猜测；概率输入接口与 logits 输入接口属于不同函数，稳定实现的目的不是允许任意混用。

<a id="it2-exercises-c"></a>

### 8.3 散度界、归约与校准

**练习十：Pinsker 的单位。** 某 KL 以二为底等于零点零一比特，给出总变差上界，并解释不能写哪种错误常数。

**解答：** 自然单位 KL 为 $`0.01\ln2`$，所以总变差不超过 $`\sqrt{\frac{0.01\ln2}{2}}\approx0.058871`$。直接把零点零一当作奈特会得到不同而较松的数；若在其他换算中把常数方向颠倒，则可能给出无效保证。所有基于 KL 的风险界应明确对数底，且只在相应条件成立时使用。无界损失还需要额外矩或尾部控制，不能仅凭这个数字推出任意业务风险差都小。

**练习十一：小总变差与无限 KL。** 构造总变差任意小但前向 KL 无穷的两个分布。

**解答：** 取 $`P=(1-\epsilon,\epsilon)`$、$`Q=(1,0)`$，其中 $`\epsilon>0`$ 可任意小。总变差为 $`\epsilon`$，但第二类真实质量为正而模型为零，前向 KL 无穷。这不违反 Pinsker，因为下界只说 KL 不小于一个小数，并未给上界。若想由总变差控制 KL，通常需要额外支持下界等条件；缺少这些条件时反向推理错误。

**练习十二：批均值的均值。** 两批样本数为二和八，平均损失一和三。怎样汇总才等于全数据均值？

**解答：** 用总损失除以总数，得到 $`\frac{(2\times1+8\times3)}{10}=2.6`$，简单平均得到二，对应批等权而非样本等权。若样本带权，应累计加权损失分子与权重分母；若序列含掩码，应累计有效位置数。报告日志和反向传播可能采取不同归约，必须分别核对，不能用日志中的平均值猜测优化器实际看到的梯度。

**练习十三：校准但无分辨力。** 真实总体正类率百分之十，模型总输出零点一。它是否校准？交叉熵最优吗？

**解答：** 在总体稳定且预测常数的意义下，它满足二分类校准定义。若所有输入的真实条件概率都恰为零点一，它也达到最优；若存在不同风险组，则存在更有分辨能力的条件模型获得更低风险。校准只约束相同预测值聚合后的频率，不保证利用所有输入信息。分组校准和整体校准也不等价：两个群体的偏差可能在总体抵消。

**练习十四：温度不改变准确率是否意味没有价值？** 对八个同置信度预测、六个正确的校准样本，原预测置信度为 $`\sigma(4)`$，求最佳温度并解释边界。

**解答：** 在共同置信度这一受限族内，最优概率为经验正确率四分之三，对数几率为 $`\ln3`$，因此逆温度 $`a=\frac{\ln3}{4}`$、温度约三点六四一。类别不变，损失从约一点零一八一五降到约零点五六二三三五。它修正置信度而非类别排序。这个结论只针对该校准目标；若校准样本很少，最优温度仍有估计误差，必须在独立样本上检查效果。

**练习十五：变分下界的误读。** 一个受限函数族训练后只得到很小的 KL 下界，能否宣布两个分布几乎相同？

**解答：** 不能。下界小可能因为真实 KL 小，也可能因为函数族太弱、训练未找到好函数或样本无法识别差异。只有一个可靠的小上界才能直接支持“差异小”，而一个大下界支持“差异至少这么大”。此外，把总体期望替换为训练样本后还可能有选择偏差，未必保持严格下界。应清楚标注是数学总体界、经验目标还是带置信保证的统计估计。

**练习十六：把条件损失减去边缘熵会怎样？** 令 $`X`$ 是公平二元变量，$`Y=X`$，模型完全正确地预测标签。计算平均损失、边缘标签熵和条件标签熵，判断哪一个差才是非负超额风险。

**解答：** 模型给真实标签概率一，所以平均负对数概率为零。边缘标签仍公平，边缘熵为 $`\ln2`$；条件标签完全确定，条件熵为零。用损失减边缘熵得到负的 $`\ln2`$，但这不是条件模型的 KL；正确超额风险是损失减条件熵，即零。输入带来的可预测性恰好解释了两种熵的差。若把输入忽略，最佳常数预测才是均匀分布，其损失为 $`\ln2`$。

这个例子说明评价必须先确定模型是无条件描述标签，还是利用输入做条件预测；相同数据、相同标签频数，也可以对应完全不同的概率建模对象。真实研究中若条件输入连续且几乎不重复，不能通过每个输入只出现一个标签就把条件熵估成零，那只是在有限样本中失去了重复观察，不能证明总体标签机制确定。

<a id="sec-7-1"></a>

### 8.4 边界追问：KL 换方向是否只是符号差

审查一项学习目标时，可以沿四个问题逐层推进。第一，谁是固定目标、谁是可训练模型；第二，期望究竟按谁采样；第三，哪里存在零概率、不可计算归一化或极端尾部；第四，当前模型族能表达什么。回答这些问题之后，才能讨论方向对应的覆盖行为、梯度估计和优化可行性。

还要把统计对象与实现对象连接起来：真实条件分布、噪声标签分布、平滑目标、类别加权目标不是同一个量；概率输入、logits 输入、温度变换也不是同一接口。把这几层写清，许多表面上神秘的现象就能变成可推导的结论。例如高准确率但交叉熵差可能来自少数极自信错误；校准后准确率不变可能是排序保持；类别加权后输出偏高可能是目标分布确实倾斜。

研究结论应同时说明理想总体命题和有限实验事实。严格适当性保证正确概率最优，有限数据不保证学到它；变分表示保证总体上确界等于 KL，受限网络不保证达到；Pinsker 保证小 KL 控制有界事件差异，不保证无界风险；温度缩放是可检验的参数变换，不保证任何分布漂移下仍校准。这些边界不是附加免责声明，而是判断一个方法何时真正有效所必需的组成部分。
