## 1. 从似然到可比较的预测损失

本章要解决一个看似简单却经常造成实验错误的问题：给定一批文本和一个概率模型，怎样把“模型认为这些文本有多可能”变成一个可解释、可复现、可以合理比较的数？答案不是直接调用一次交叉熵函数。必须先说明观测事件、条件信息、预测单位、样本权重和汇总方法，才能谈论交叉熵与困惑度。相同模型在不同统计口径下可能得到不同分数，而不同分数未必代表预测能力发生变化。

上一章讨论交叉熵与 KL 散度的分布性质。本章把它们落实到有限语料与自回归模型的评估过程，重点区分总体目标与经验估计、序列概率与单位平均损失、模型误差与评估协议误差。读完后应能从原始预测概率推导语料困惑度，识别平均方式中的错误，并设计一个不依赖大型模型下载的完整评估实验。

<a id="information-3-detail-2"></a>

### 1.1 似然究竟把什么当作变量

设独立观测为 $`x_1,\ldots,x_n`$，模型给出的概率质量函数为 $`q_\theta(x)`$。似然写作

$$
L(\theta;x_{1:n})=\prod_{i=1}^n q_\theta(x_i).
$$

这里固定的是已经观察到的数据，变化的是参数 $`\theta`$。因此似然是参数的函数；它通常不是参数空间上的概率分布，也没有“对所有参数求和必须为一”的要求。若把数据固定后比较两个参数的似然，只是在比较它们对同一观测的解释程度。若要谈参数的后验概率，还需要先验与贝叶斯归一化步骤。

在离散模型中，单个事件概率不超过一，所以有限样本似然不超过一；但连续模型使用密度，密度可大于一，似然也可以大于一。对数似然为正并不自动说明程序错误。例如区间 $`[0,0.1]`$ 上的均匀密度等于十。这个区别会直接影响后文的困惑度解释：连续密度的指数负对数平均值不能直接当作离散候选数。

只要所有观察事件概率为正，最大化似然等价于最大化对数似然，因为对数严格单调；又等价于最小化负对数似然。独立观测让乘积变为和：

$$
-\log L(\theta;x_{1:n})=-\sum_{i=1}^n\log q_\theta(x_i).
$$

这既便于数值计算，也使各样本贡献可以加总。不过“可以加总”来自对联合分布的建模分解，并不意味着任何有依赖的数据都可以当独立样本。时间序列与文本需要使用条件概率的链式分解。

<a id="information-3-detail-3"></a>

### 1.2 分类计数模型的最大似然解

考虑类别集合 $`\{1,\ldots,K\}`$，第 $`k`$ 类出现 $`n_k`$ 次，总数 $`n=\sum_kn_k`$。令模型参数为概率向量 $`q`$，则忽略与参数无关的组合系数后，对数似然为 $`\sum_kn_k\log q_k`$。约束为 $`q_k\geq0`$ 且 $`\sum_kq_k=1`$。若所有计数均为正，拉格朗日函数给出

$$
\begin{aligned}
\frac{n_k}{q_k}-\lambda &=0,\\[6pt]
q_k &=\frac{n_k}{\lambda},\\[6pt]
\lambda &=n.
\end{aligned}
$$

所以最大似然估计为 $`\hat q_k=\frac{n_k}{n}`$。若某类计数为零，解位于概率单纯形边界，仍是这个频率公式。推导时不能对零计数类别机械使用严格正内部解。可以通过连续延拓约定 $`0\log0=0`$，或把只出现过的类别单独求解，再检查边界。

这个结果解释了训练误差的乐观性。模型可以把概率质量集中到当前样本中出现的事件，甚至给未出现事件零概率。训练集负对数似然可能很好，测试集只要出现一个此前未见的事件，就会得到无限损失。这不是对数损失“过于严厉”的偶然缺陷，而是概率模型对真实发生事件作出了不可能断言的直接后果。

经验分布 $`\hat p_k=\frac{n_k}{n}`$ 下的平均负对数似然等于 $`H(\hat p,q)`$，可分解为 $`H(\hat p)+D_{\mathrm{KL}}(\hat p\Vert q)`$。这个分解说明无约束分类模型的经验最优解是经验分布，却不能说明经验分布就是总体分布。后者涉及采样误差与泛化，必须另行分析。

<a id="information-3-detail-4"></a>

### 1.3 基础算例：整段概率和平均 token 损失

假设两个真实 token 各自得到条件概率 $`0.5`$。整段概率为 $`0.25`$，总负对数似然为 $`\log4`$，平均负对数似然为 $`\log2`$。再增加一个概率同样为 $`0.5`$ 的真实 token，整段概率降为 $`0.125`$，总损失增加到 $`\log8`$，但每个 token 的平均损失仍为 $`\log2`$。

因此，长文本的联合概率通常更小，并不能据此断言模型预测长文本更差。联合概率描述整个事件发生的可能程度，平均损失则描述指定预测单位上的平均惊讶程度。前者依赖事件长度，后者通过归一化消除了直接的长度倍增，却仍依赖分词、上下文和计分位置。

训练时总损失和平均损失的最优参数，在预测位置总数固定且不依赖参数时相同；但它们的梯度大小不同。若小批次的有效位置数量变化，先对各批次取平均再等权更新，会改变长短批次的相对权重。因此评估中的加权问题也会进入优化过程。梯度累积若想模拟一个大批次的 token 平均目标，应按有效 token 数缩放各微批次贡献。

<a id="information-3-detail-5"></a>

### 1.4 自回归分解不要求 token 独立

对于序列 $`x_{1:T}`$，概率链式法则给出

$$
q_\theta(x_{1:T})=\prod_{t=1}^{T}q_\theta(x_t\mid x_{<t}).
$$

这是一种联合概率分解，不是 token 相互独立的假设。模型可以通过条件分布捕捉极强的依赖。把文本训练描述为“假设每个词独立，然后做最大似然”会误解自回归模型的基础。真正的近似往往出现在有限上下文、模型容量、参数共享和训练数据分布等位置。

若提示为 $`c`$，回答为 $`y_{1:T}`$，回答条件似然应是 $`\prod_tq_\theta(y_t\mid c,y_{<t})`$。是否把提示本身计入损失，是另一个目标选择。只计回答并不意味着模型没有读取提示；计分掩码控制的是哪些位置进入统计量，注意力或上下文机制控制的是模型可以使用哪些信息，两者不能混为一谈。

还必须说明序列是否包含结束符。只给出固定长度前缀的概率，与给出“这段内容恰好在这里结束”的完整字符串概率，不是同一个事件。后者通常还要乘结束符概率。若一个模型对内容预测准确，却总倾向于继续生成，包含结束符的评估可能揭示其长度建模问题。忽略结束符的实验也可以有意义，但不能把两种事件的分数混在一起比较。

## 2. 困惑度的定义、单位和解释边界

<a id="sec-2"></a>

<a id="information-3-detail-7"></a>

### 2.1 从平均对数损失得到困惑度

设实际计分的条件概率为 $`p_1,\ldots,p_N`$，且均为正。用自然对数定义平均负对数似然

$$
\begin{aligned}
\bar\ell &=-\frac1N\sum_{i=1}^N\log p_i,\\[6pt]
\operatorname{PPL} &=\exp(\bar\ell).
\end{aligned}
$$

由于指数函数严格递增，对于同一批计分事件和同一计权方式，最小化困惑度与最小化平均负对数似然完全等价。报告困惑度不会改变模型排序；它只是把对数尺度转成乘法尺度。训练中通常直接优化对数损失，因为求导和累加更方便，没有必要每步先取指数。

若模型对每个位置都在 $`K`$ 个候选上均匀分配概率，真实候选概率为 $`\frac{1}{K}`$，困惑度就是 $`K`$。这给出“等效均匀候选数”的直觉。然而一般模型的困惑度并不等于实际候选个数，也不是模型内部真正保留了多少个选项。它是对真实事件所分配概率的一个汇总量；不同形状的预测分布可以给出同样的分数。

离散概率模型的有限困惑度至少为一，因为每项负对数概率非负。困惑度等于一意味着所有计分事件的预测概率都为一，这是非常强的条件。若离散模型得到小于一的困惑度，应检查是否使用了密度、错误的损失符号、未归一化分数，或者损失中混入了与概率解释不一致的项。不能直接把带正则项的总训练目标取指数称为标准困惑度。

<a id="deep-dive-2"></a>

<a id="information-3-detail-8"></a>

### 2.2 几何平均、对数底和相对改善

代数变形得到

$$
\operatorname{PPL}
=\left(\prod_{i=1}^Np_i\right)^{-\frac{1}{N}}
=\left(\prod_{i=1}^N\frac1{p_i}\right)^{\frac{1}{N}}.
$$

因此困惑度是每个计分事件逆概率的几何平均。它不是平均逆概率，也不是平均概率的倒数。比如概率分别为 $`0.9`$ 和 $`0.1`$，几何平均概率为 $`0.3`$，困惑度为 $`\frac{10}{3}`$；算术平均概率为 $`0.5`$，其倒数为二。后者掩盖了第二个事件被严重低估的事实。

使用以二为底的对数时，平均损失单位为 bit，困惑度应写为 $`2^{\bar\ell_2}`$。自然对数损失的单位是 nat，应使用 $`e^{\bar\ell_e}`$。两者满足 $`\bar\ell_e=(\log2)\bar\ell_2`$，因此得到相同困惑度。改变对数底不会改变概率模型的预测，但把 bit 损失直接送进自然指数会产生错误数字。

两个模型在同一协议下的平均损失差为 $`\Delta=\bar\ell_A-\bar\ell_B`$，则困惑度比值为 $`e^\Delta`$。例如损失降低 $`\log2`$ nat，困惑度减半。这是一种单位一致的乘法改善。它不能直接推出问答准确率增加多少，也不能推出用户满意度按同样比例改善，因为这些指标衡量不同目标。

<a id="sec-2-1"></a>

<a id="information-3-detail-9"></a>

### 2.3 为什么必须先加总损失再取指数

设文档 $`d`$ 有 $`N_d`$ 个计分位置，总负对数似然 $`S_d`$。整套语料的 token 平均困惑度应为

$$
\exp\left(\frac{\sum_dS_d}{\sum_dN_d}\right).
$$

若文档困惑度为 $`P_d=\exp(\frac{S_d}{N_d})`$，上式等于加权几何平均 $`\prod_dP_d^{\frac{N_d}{\sum_jN_j}}`$。因此文档长度权重进入的是对数尺度。直接算文档困惑度的算术平均，既改变了指数的处理顺序，也通常改变了文档权重。

考虑两篇文档，长度分别为一和三，平均损失分别为零与 $`\log4`$。语料困惑度为 $`4^{\frac{3}{4}}\approx2.828`$。两篇文档困惑度的算术平均为 $`\frac{(1+4)}{2}=2.5`$。若每篇文档等权平均其对数损失，再取指数，则得到二。三个数字都可由明确的运算得到，但只有第一个是这里定义的 token 平均语料困惑度。

文档等权目标并不天然错误。若应用目标是让每位用户、每次会话或每篇文档获得同等重要性，文档平均损失可能更符合需求。关键是写明目标并保持比较一致。报告“平均困惑度”却不说明平均的对象和顺序，会让实验难以复现，也可能让短文档在结果中获得意外权重。

<a id="information-3-detail-10"></a>

### 2.4 一个可手算的完整数值例子

真实 token 条件概率为 $`0.5,0.25,0.5`$，则联合概率为 $`\frac{1}{16}`$，总负对数似然为 $`\log16`$，平均损失为 $`\frac{\log16}{3}`$，困惑度为 $`16^{\frac{1}{3}}\approx2.519842`$。使用二进制对数时总损失为四 bit，平均为 $`\frac{4}{3}`$ bit，取 $`2^{\frac{4}{3}}`$ 得到同一结果。

若第三个 token 的概率降为 $`0.005`$，总损失增加 $`\log100`$，困惑度乘以 $`100^{\frac{1}{3}}`$。这说明罕见但严重的低概率预测会显著影响结果。对数损失对自信错误较敏感，因此同时检查损失最大的样本，有助于发现标注错误、编码问题、领域偏移或模型支持集缺失。

但不能为了让汇总分数好看而直接删除这些样本。首先应判断它们是否属于预先定义的目标分布，是否存在数据损坏，再决定修订数据协议。若删除规则由当前模型的失败位置决定，评估分布就被模型表现反向筛选，结果会偏乐观。若确需稳健统计，应额外报告截尾规则与原始损失，说明改变了什么估计目标。

## 3. 序列、长度与训练目标的关系

<a id="information-3-detail-12"></a>

### 3.1 token 等权与序列等权不是同一问题

对一组变长序列，最大化完整语料似然得到总损失 $`\sum_d\sum_t\ell_{dt}`$。除以固定的总 token 数不会改变其参数最优点。长文档贡献更多位置，因此会获得更多总权重。这对应随机抽取一个语料 token 时的平均预测表现。

若先在每篇文档内部除以长度，再对文档等权平均，目标变成 $`\frac1D\sum_d\frac1{N_d}\sum_t\ell_{dt}`$。这等价于先均匀抽文档，再在该文档中均匀抽一个位置。两种抽样过程产生不同的位置分布，因而最优参数可以不同。比较训练方案时，应把差别解释为权重选择，而不是简单说其中一种“更标准”。

更进一步，序列归一化评分常被用于搜索候选回答，但搜索时的长度惩罚与训练时的概率似然不是同一个对象。一个未归一化的长度修正分数可以帮助排序，却未必对应定义良好的概率模型。不能把搜索排序分数直接替换成序列概率，再照搬困惑度解释。

<a id="information-3-detail-13"></a>

### 3.2 结束符与可变长度分布的归一化

固定长度序列模型只需保证每一步的条件分布归一化，就能通过链式法则构成该长度空间上的分布。对于任意有限字符串的可变长度模型，还要考虑是否几乎必然终止。每一步都有结束符选项并不单独保证终止；结束概率可能随时间下降得过快，使无限续写仍有正概率。

一个便于检查的充分条件是：所有可达历史下结束符概率都至少为某个 $`\varepsilon>0`$。则生成长度超过 $`T`$ 的概率至多为 $`(1-\varepsilon)^T`$，趋于零，因此几乎必然终止。真实神经模型未必满足统一下界；实际系统的最大生成长度限制会定义另一个截断后的过程，需要在相关概率解释中说明。

这个细节在普通 token 预测评估中常被省略，但在比较字符串概率、压缩率或不同分词方案时很重要。若两个协议对于是否计入结束、是否截断文档的处理不同，它们评分的事件空间可能已经不同，即使都把结果称为困惑度，也不能直接比较。

<a id="information-3-detail-14"></a>

### 3.3 正则化、标签平滑和其他附加目标

标准困惑度对应真实标签的负对数预测概率。若训练目标中加入参数正则项，正则项可以改善测试概率估计，却不是对观测 token 的额外负对数概率。因此报告评估困惑度时应分离数据项与正则项，而不是对两者之和取指数。

标签平滑的交叉熵对一个软目标分布计算期望，真实 token 的负对数概率只是其中一部分。它可以改变优化行为和置信度，但把平滑训练损失直接转成困惑度，不等于原始真实 token 困惑度。类别权重、焦点损失和辅助任务损失也存在类似问题。只有明确定义了相应加权预测事件，才可以讨论新的统计量。

比较模型时还要区分“训练采用什么目标”和“评估使用什么共同规则”。两个模型可以用不同正则化方法训练，却在相同测试集上用相同真实标签负对数似然比较。训练目标不一致不是不能比较的理由；评估对象与协议不一致才是必须先解决的问题。

<a id="information-3-detail-15"></a>

## 4. 分词、字节和跨模型可比性

<a id="information-3-detail-16"></a>

### 4.1 同一字符串为什么会得到不同 token 困惑度

设同一字符串在两种可逆编码下分别有 $`N_A`$ 和 $`N_B`$ 个 token，且暂时假设两种模型给该完整字符串分配同样概率 $`Q`$。那么两种 token 困惑度分别为 $`Q^{-\frac{1}{N_A}}`$ 和 $`Q^{-\frac{1}{N_B}}`$。只要分母不同，数值就不同，即使字符串概率完全相同。这个例子已经足以证明跨分词器直接比较 token 困惑度不可靠。

更直观地，把相邻两个 token 合并成一个复合 token，若对应联合概率保持不变，预测单位数量约减半，困惑度便大致平方。这不是模型突然退步，而是一个预测单位承载了更多信息。不同词表大小的均匀基线也不同，因此“词表更大，困惑度更大”不能直接解释为语言建模更差。

所以任何报告都应写出分词器、词表版本、文本预处理和特殊 token 规则。分词器名称相同也不一定足够，因为词表修订、添加特殊符号、空白处理变化和自动插入起始符都可能改变计分事件。可复现评估需要记录实际配置或稳定的配置标识，而不只写模型系列名称。

<a id="information-3-detail-17"></a>

### 4.2 bits per byte 提供共同分母，但仍需共同事件

若原始文本的 UTF-8 字节总数为 $`B`$，总负对数似然为 $`S`$ nat，可定义每字节位数

$$
\operatorname{BPB}=\frac{S}{B\log2}.
$$

它把分母换为相同原始字节单位，消除了每 token 长度不同造成的一类偏差。若两个协议对同一字节串计算同一类型的条件概率，BPB 比 token 困惑度更适合跨分词比较。注意 UTF-8 字节数不等于字符数；汉字、表情和不同组合字符的编码长度会不同，不能直接使用字符串长度充当字节数。

共同分母不是充分条件。若一个协议删除空白或统一大小写，另一个保留原文，它们评分的事件已经不同；若一个计入提示的损失却只除以回答字节数，也会产生口径错配。字节数应对应被评估的原始内容范围，特殊结束事件虽然没有普通文本字节，是否计入其概率也必须统一说明。

还有更隐蔽的概率问题：分词器通常给出一个规范 token 路径，但模型可能存在多个解码到同一字符串的 token 序列。规范路径的概率不自动等于模型诱导的字符串概率。若要严格比较完整字符串分布，应对所有解码到该字符串的合法路径求和，或者明确所报告的是规范编码路径的码长。实际实验经常采用后者；只要写清限制，就比声称完全消除了分词差异更准确。

<a id="information-3-detail-18"></a>

### 4.3 一个单位转换的实际计算

假设一段相同原文有一千字节，模型甲用四百个 token，总损失两千 nat；模型乙用五百个 token，总损失一千九百 nat。甲的 token 平均损失为五，乙为三点八，二者 token 困惑度相差很大。但在共同字节分母下，甲为 $`\frac{2000}{(1000\log2)}`$，乙为 $`\frac{1900}{(1000\log2)}`$，乙的码长只降低百分之五。

这个例子不意味着字节指标永远更符合下游任务，只说明应把单位选择与结论相匹配。如果研究的是字符串压缩或跨编码的概率拟合，公共字节口径有价值；如果研究某个固定模型内部的训练进度，固定分词器下的 token 损失通常已经足够。应用是否成功仍要通过与任务目标对应的额外指标判断。

对于多语言语料，也不能忽略字节编码本身的差异。相同语义的信息量不一定对应相同 UTF-8 字节数。BPB 是对字节表示的预测或编码效率，不是语言难度的绝对标尺。比较语言时应同时报告样本来源、长度分布、文本类型和编码规则，避免把表示长度差异误认成语言本身的性质。

<a id="information-3-detail-19"></a>

## 5. 上下文窗口、掩码与计分协议

<a id="information-3-detail-20"></a>

### 5.1 非重叠分块改变了哪些条件概率

模型最多读取有限长度时，评估长文档必须选择上下文策略。若直接把文档切成互不重叠的块，每块开头会失去之前文档提供的历史；若采用重叠窗口，可以把一部分 token 仅用作条件，把新出现的位置用于计分。两者都能生成明确的分数，但对应的条件信息不同。

滑动窗口不能把重叠区域的损失重复累加。每个目标位置应有唯一的统计归属，作为上下文出现多次不代表应该计分多次。若重复计分，文档中间位置可能比边界位置获得更多权重，整体分数也会随着步长变化而改变，即使模型对同一历史的预测完全一致。

此外，输入长度和可用历史长度要分清。若一次前向输入包含当前目标对应的前一个 token，那么模型实际看到的历史数量需要根据移位约定计算。不能只看到输入长度为某个数，就宣称每个目标都获得同样长度的历史。文档开头、窗口边界和被保留的前缀都会造成例外，应以明确的目标索引描述协议。

<a id="information-3-detail-21"></a>

### 5.2 更多上下文并不保证每个实际模型都更好

对真实联合分布，条件熵满足 $`H(X\mid Z,W)\leq H(X\mid Z)`$。增加条件变量不会提高最优平均对数损失，这是条件互信息非负的直接结果。但该结论比较的是每种信息条件下的真实最优预测分布，并不是对任意训练好的模型逐点成立。

实际模型可能没有正确利用新增上下文，也可能受位置编码、干扰信息和分布偏移影响。给某个模型更多历史，某些样本乃至整个测试集的损失都可能上升。即使总体最优条件熵下降，一份有限样本上的观测平均损失也不一定下降。报告滑动窗口通常改善估计时，应保留这些条件。

可做一个简单反例：目标真实概率为 $`0.9`$，短上下文模型预测真实事件概率 $`0.8`$，长上下文模型因错误利用干扰信息预测为 $`0.1`$。后者损失显然更大。信息本身具有潜在价值，不等于具体模型必然把价值兑现。这个区分也是研究检索增强、长上下文和记忆系统时应保留的基本逻辑。

<a id="information-3-detail-22"></a>

### 5.3 提示掩码、填充掩码与文档边界

提示 token 可以作为历史参与预测，却不进入回答损失。填充 token 通常既不代表真实内容，也不应该成为计分目标。若批处理中把填充位置误计入损失，模型只要善于预测填充符就能人为降低总体分数，而且分数会随批次长度分布改变。

文档边界则是另一个语义选择。把两篇独立文档直接拼接，允许后一篇使用前一篇作为历史，会改变条件概率。若应用本来就是连续会话，跨段历史可能合理；若目标是独立文档预测，应使用边界符、重置状态或适当的注意力隔离。只在损失中忽略边界位置，并不能自动阻止模型访问前一篇文档。

全被忽略的批次没有有效分母，其平均损失未定义。返回零会伪装成完美预测；将其与普通批次等权平均也会压低结果。稳妥处理是让累加器接受“损失和为零、计分数为零”的空贡献，只在整体计分数大于零时求平均。若整个评估集都为空，应明确报错。

<a id="information-3-detail-23"></a>

### 5.4 评估模式、精度与随机状态

含 dropout 的模型在训练模式下会产生随机预测，因此多次评分可能不同。常规确定性评估应切换到评估模式，并关闭不必要的梯度记录。对于 BatchNorm 之类依赖运行统计的模块，训练和评估模式还会改变计算规则。只关闭梯度并不会自动切换这些行为。

低精度推理也可能改变损失，尤其在极端 logits 和长语料累加中。可以用模型允许的精度计算预测，再把损失和累加到更高精度。分布式评估中最关键的充分统计量是各工作进程的总负对数似然与有效目标数；归并这两个量后再除法，通常比归并各进程的平均数更可靠。

如果评估包含随机裁剪、随机选窗或随机采样候选，随机种子、采样次数和统计单位需要进入报告。固定种子便于复现，但一个固定随机结果不能替代不确定性分析。若研究的是随机预测机制本身，还要区分对每次随机模型先取对数再平均，与先平均概率再取对数，它们对应不同的预测对象。

## 6. 实验一：稳定且可核对的 token 评分器

<a id="information-3-detail-25"></a>

### 6.1 先对齐目标，再汇总有效位置

下面的实验使用 NumPy 构造小型 logits，不下载模型或数据。约定输入数组形状为批次、位置、词表，位置 $`t`$ 的 logits 预测位置 $`t+1`$ 的标签。代码显式移位，避免依赖框架内部是否自动移位。掩码标记目标位置，而不是产生预测的源位置。

稳定对数概率先减去每行最大值，再计算指数和。对有限 logits，这样至少有一个指数项等于一，不会出现指数和下溢为零。先计算 Softmax 概率再取对数则可能把一个极小但正的概率舍入为零，把有限损失误写为无穷大。这仍要求移位差值和累计 NLL 可由所用浮点类型表示；有限输入并不自动保证这两个条件。下面显式检查这些算术阶段，超出范围时抛出异常，而不是返回看似合法的无穷汇总值。

忽略标签可能被写成负数哨兵，例如负一百。应先筛选有效位置，再索引词表；不能先用所有标签执行索引，最后才乘掩码。后者可能越界，也可能让负数悄悄索引到词表尾部。掩码不是允许非法中间计算的理由。

```python
import math
import numpy as np

def score_next_token(logits, labels, score_mask):
    z = np.asarray(logits, dtype=np.float64)
    y = np.asarray(labels)
    mask = np.asarray(score_mask, dtype=bool)
    if z.ndim != 3 or y.shape != z.shape[:2] or mask.shape != y.shape:
        raise ValueError("shape mismatch")
    if z.shape[-1] == 0 or not np.isfinite(z).all():
        raise ValueError("use finite logits and a nonempty vocabulary")
    if not np.issubdtype(y.dtype, np.integer):
        raise ValueError("labels must be integers")
    target = y[:, 1:]
    valid = mask[:, 1:]
    rows = z[:, :-1, :][valid]
    target = target[valid]
    count = int(target.size)
    if count == 0:
        return 0.0, 0
    if np.any((target < 0) | (target >= z.shape[-1])):
        raise ValueError("invalid scored target")
    with np.errstate(over="raise", invalid="raise", divide="raise"):
        shifted = rows - rows.max(axis=-1, keepdims=True)
        logp = shifted - np.log(np.exp(shifted).sum(axis=-1, keepdims=True))
        nll = -logp[np.arange(count), target].sum(dtype=np.float64)
    return float(nll), count

prob = np.array([[[0.5, 0.5], [0.75, 0.25],
                  [0.5, 0.5], [0.5, 0.5]]])
labels = np.array([[0, 1, 1, 0]])
mask = np.ones_like(labels, dtype=bool)
total, count = score_next_token(np.log(prob), labels, mask)
assert count == 3
assert np.isclose(total, np.log(16.0))
assert np.isclose(math.exp(total / count), 16.0 ** (1.0 / 3.0))

extreme = np.array([[[1000.0, -1000.0], [0.0, 0.0]]])
s, n = score_next_token(extreme, np.array([[0, 1]]),
                        np.array([[False, True]]))
assert n == 1 and np.isclose(s, 2000.0)
print("NLL/count/PPL:", total, count, math.exp(total / count))
print("extreme log-PPL:", s / n)
try:
    score_next_token(np.array([[[1e308, -1e308], [0., 0.]]]),
                     np.array([[0, 1]]), np.array([[False, True]]))
except FloatingPointError:
    pass
else:
    raise AssertionError("unrepresentable logit differences require explicit failure")

ignored = np.array([[0, -100]])
assert score_next_token(extreme, ignored,
                        np.zeros_like(ignored, dtype=bool)) == (0.0, 0)
```

<a id="information-3-detail-26"></a>

### 6.2 数值边界与代码职责

极端例子的真实目标损失为两千 nat，仍是有限数；若尝试直接计算其困惑度，会超出常见浮点数的指数范围。正确处理是报告平均负对数似然或对数困惑度，并注明普通困惑度超出表示范围，而不是把损失剪裁后悄悄报告一个有限困惑度。

代码要求 logits 有限，因此不处理正负无穷或 NaN。真实系统若用负无穷表示不允许的候选，需要单独设计支持集检查：有效行至少有一个有限候选，真实目标不能被赋予严格零概率，且所有不允许事件的解释必须明确。把所有异常值统一替换成零，会改变预测分布并隐藏上游错误。

这个评分器只负责目标对齐和数值汇总，不负责保证模型没有看见未来，也不负责自动选择上下文窗口。若产生 logits 的模型错误地访问了未来标签，评分函数仍可能给出很低的损失。低损失并不能证明评估无泄漏；数据流、注意力掩码和预处理顺序需要独立核对。

<a id="information-3-detail-27"></a>

### 6.3 分块累加的守恒关系

把一批有效目标分成若干互不重叠的集合，各集合的损失和相加应恢复整体损失和，计数相加应恢复整体计数。这是评估实现中很有用的不变量。可以用它核对批次拆分、分布式归并和梯度累积的权重是否一致。

但若拆分输入导致上下文发生变化，模型输出也会变化，这时不能要求损失和仍相同。应先固定同一组逐位置预测，再测试统计归并；随后单独测试不同上下文协议。这样能把“统计实现错误”与“模型输入变化”分开定位，避免把两类问题混在一个测试中。

对于大量文档，保留每篇文档的损失和与有效计数还可支持后续诊断、分层报告和按文档重采样。只保存最终困惑度会丢掉这些信息，既难以更换权重，也难以估计不确定性。保存充分统计量通常比保存不可逆的单个汇总分数更有研究价值。

<a id="information-3-detail-28"></a>

## 7. 实验二：计数模型、零概率与平滑

<a id="information-3-detail-29"></a>

### 7.1 从完整生成过程定义一个小模型

为了看清训练似然与测试损失的区别，构造只输出字母 a、字母 b 和结束符的二元上下文模型。上下文可以是起始符、a 或 b；每篇文档从起始符开始，读完正文后还要预测结束符。起始符只作为条件，不作为普通输出候选，这一点通过计数矩阵的行列分工体现。

训练计数给出每种上下文之后各输出出现的次数。无平滑最大似然估计对每个有观测的上下文分别归一化；若某上下文从未出现，它的条件分布没有被训练似然确定，不能把全零行直接称作概率分布。下面的训练语料恰好覆盖所有上下文，避免把这个问题藏在默认值里。

加性平滑使用 $`\frac{(n_{ij}+\alpha)}{(n_i+K\alpha)}`$。对于对称 Dirichlet 先验参数为 $`\alpha`$ 的模型，这是下一次观测的后验预测概率，不是同参数先验下的一般最大后验解。内部最大后验解的公式涉及 $`\alpha-1`$，边界条件也不同。把这两个公式混称为“贝叶斯最大似然”会掩盖它们对不确定性的不同处理。

```python
import math
import numpy as np

contexts = {"<BOS>": 0, "a": 1, "b": 2}
outputs = {"a": 0, "b": 1, "<EOS>": 2}
train = ["ab", "aa", "ba", "ab"]
test = ["bb", "ab", "a"]

def count_transitions(documents):
    counts = np.zeros((3, 3), dtype=np.float64)
    for doc in documents:
        prev = "<BOS>"
        for token in list(doc) + ["<EOS>"]:
            counts[contexts[prev], outputs[token]] += 1
            prev = token
    return counts

def estimate(counts, alpha):
    if alpha < 0:
        raise ValueError("alpha must be nonnegative")
    denom = counts.sum(axis=1, keepdims=True) + 3 * alpha
    if np.any(denom == 0):
        raise ValueError("unidentified empty context")
    return (counts + alpha) / denom

def evaluate(documents, prob):
    total, n = 0.0, 0
    for doc in documents:
        prev = "<BOS>"
        for token in list(doc) + ["<EOS>"]:
            p = prob[contexts[prev], outputs[token]]
            total += -math.log(p) if p > 0 else math.inf
            n += 1
            prev = token
    return total, n

counts = count_transitions(train)
mle = estimate(counts, 0.0)
smoothed = estimate(counts, 0.5)
assert np.allclose(mle.sum(axis=1), 1.0)
assert np.allclose(smoothed.sum(axis=1), 1.0)
assert math.isfinite(evaluate(train, mle)[0])
assert math.isinf(evaluate(test, mle)[0])
assert math.isfinite(evaluate(test, smoothed)[0])
for name, p in [("MLE", mle), ("posterior predictive", smoothed)]:
    for split, docs in [("train", train), ("test", test)]:
        s, n = evaluate(docs, p)
        print(name, split, "NLL/token", s / n,
              "PPL", math.exp(s / n))
```

<a id="information-3-detail-30"></a>

### 7.2 如何解释实验，而不夸大结论

训练数据中没有 b 后接 b，因此无平滑模型给这个转移零概率。测试文档 bb 包含该转移，整个测试损失变为无穷大。平滑模型给所有输出正概率，避免了这一支持集失败，但它必须把部分概率质量从已观察事件移到其他事件，所以训练似然通常变差。

这个取舍说明训练损失更低并不必然对应预测更好。它也不证明任何平滑强度都优于最大似然。若 $`\alpha`$ 过大，分布会过度接近均匀，忽略已有证据；若过小，对未见事件仍可能给出过低概率。合理做法是使用验证集选择平滑强度，最终只在保留测试集上评价一次主要结果。

本实验还满足可变长度生成的一个简单充分条件：平滑后所有可达上下文的结束概率都严格为正，而上下文只有有限个，所以它们的最小值为正，模型几乎必然终止。无平滑模型在本例中也可以检查终止性质，但一般不能只凭每行归一化就跳过这一问题。

<a id="information-3-detail-31"></a>

### 7.3 平滑与未知词处理影响评估事件

若词表只包含训练集中出现的词，测试中新词如何表示必须提前确定。映射到未知词符号会把多个不同词合并成一个事件，模型给未知符号的概率不是每个原词的概率。一个词表很小、把大量内容折叠成未知符号的模型，可能得到看似很好的 token 困惑度，却丢失了区分原文的能力。

子词与字节编码减少了某些未知词问题，但没有消除所有表示选择。特殊字符清洗、非法字节处理和大小写归一化仍会改变事件空间。若研究压缩，必须额外考虑恢复被合并或删除信息所需的码长；若研究固定预处理后的分类或语言建模，可以直接定义该预处理空间，但结论应限定在这个空间。

评估时也不能根据测试集重新扩展计数词表并重新归一化，却仍声称所有参数只由训练集获得。即使没有直接更新神经网络权重，利用测试集决定词表或平滑结构，也可能引入测试信息。是否构成不合理泄漏取决于预先允许的信息条件，关键是协议必须公开一致。

## 8. 经验交叉熵、泛化与不确定性

<a id="information-3-detail-33"></a>

### 8.1 总体风险分解说明了什么

设真实分布为 $`p`$，模型分布为 $`q_\theta`$，且相应期望存在。总体负对数风险为

$$
R(\theta)=\mathbb E_p[-\log q_\theta(X)]
=H(p)+D_{\mathrm{KL}}(p\Vert q_\theta).
$$

真实熵与参数无关，因此在给定模型族内最小化总体对数损失等价于寻找前向 KL 最小的模型。如果真实分布不在模型族中，最优参数只是该族中对当前目标分布最合适的近似，通常称作伪真参数；不能把它解释成恢复了不存在于模型族中的真实机制。

有限样本经验风险替代总体期望，带来采样误差。训练又根据同一份样本挑选参数，带来选择效应。固定参数下经验均值可以是无偏估计，不意味着训练后最小经验风险仍对对应总体风险无偏。模型越灵活、搜索范围越大，这种区别越需要通过独立数据或适当理论控制。

语言数据还存在分布漂移。过去语料上的期望损失不等于未来领域上的期望损失；新闻、代码、对话和专业论文可能对应不同分布。给出一个总困惑度后，仍应检查分领域表现与数据组成。否则总体改善可能主要来自占比最大的容易子集，而关键应用子集反而退步。

<a id="sec-5-1"></a>

<a id="information-3-detail-34"></a>

### 8.2 有依赖的 token 应如何理解样本量

同一文档中的 token 具有依赖，不能把几百万个 token 直接当成几百万个独立重复实验。依赖会影响标准误差和置信区间，但不会阻止按定义计算总损失与总计数。统计量能算出来，与对它的不确定性估计合理，是两个不同层次的问题。

若文档可近似看作独立抽样单位，可以按文档重采样，保留文档内部的所有损失与长度。每次重采样都重新计算总损失除以总 token 数，得到 token 加权目标的自助分布。不能先把每篇文档变成一个平均数，再无视长度平均，否则改变了目标。

若数据是一个长时间流，文档独立假设也不成立，可能需要按时间段或依赖块重采样。块长过短会破坏相关结构，过长又导致有效重复单位过少。任何置信区间都依赖采样与依赖假设；给出更多小数位不能替代这些假设的说明。

<a id="information-3-detail-35"></a>

### 8.3 困惑度变换的偏差与区间

即使平均负对数似然的估计量无偏，指数变换后的困惑度估计一般也不无偏。由 Jensen 不等式，$`\mathbb E[e^{\hat\ell}]\geq e^{\mathbb E[\hat\ell]}`$，只要相应期望存在。这说明多次实验先算困惑度再平均，与先平均对数损失再取指数，会得到不同结果。

还有一个与偏差不同的区别：最小化“有限样本困惑度的期望”未必等于最小化总体负对数损失。以单个二元观测为例，真实正类概率为 $`\frac{4}{5}`$，预测正类概率为 $`q\in(0,1)`$，单观测困惑度的期望是 $`\frac{4}{5q}+\frac{1}{5(1-q)}`$。在真实概率 $`q=\frac{4}{5}`$ 处该期望为 2，在 $`q=\frac{2}{3}`$ 处却降为 $`\frac{9}{5}`$；其最优概率并非真实概率。相反，总体困惑度 $`\exp(E[-\log Q(Y)])`$ 因指数单调，仍与总体对数损失具有相同最优解。需要区分先取总体期望再指数，与先算样本指数再取期望。

若已经得到平均损失的有效区间 $`[a,b]`$，由于指数单调，可以把它变换成困惑度区间 $`[e^a,e^b]`$，覆盖事件完全相同。这个变换通常产生不对称区间，不能为了视觉方便强行写成中心值加减同样宽度。若指数超出数值范围，保留对数尺度区间更准确。

对数损失没有天然的统一上界：预测概率越接近零，损失越大。因此不能不加条件地直接套用针对有界随机变量的 Hoeffding 不等式。若显式规定每个真实事件预测概率至少为 $`\varepsilon`$，则损失上界为 $`-\log\varepsilon`$；但若通过事后剪裁实现，这也改变了计分规则，必须说明估计的是剪裁后风险。

<a id="information-3-detail-36"></a>

### 8.4 配对比较比孤立比较更有效

比较模型甲乙时，可对同一篇文档保存两者损失和与同一有效计数。重采样时使用相同文档索引，形成配对差值。这样保留了“这篇文档对两个模型都很难”的相关性，通常比把两组分数当独立样本更有辨别力。

若两个模型实际计分的位置不同，配对差值就可能混入样本选择差异。应先求共同的有效事件集合，或者清楚说明不同覆盖率带来的限制。例如一个模型拒绝处理长文本，不能只报告它成功处理的短文本分数，却拿来与另一个模型对全部文本的分数比较。

模型选择也要考虑多次试验。不断查看测试集并据此调整提示、平滑强度或检查点，会让测试集逐渐承担验证集角色。最后的单次测试分数已不能解释为完全独立的最终检验。记录搜索过程、保留新的测试数据或使用预先约定的评估方案，比事后声称“没有直接训练测试集”更有说服力。

## 9. 实验三：配对文档重采样

<a id="information-3-detail-38"></a>

### 9.1 对数损失比值的区间计算

下面使用人工给定的逐文档充分统计量。两模型计分位置完全相同，长度不同的文档仍按 token 数贡献权重。每次重采样都对文档索引有放回抽取，并重新计算两个模型的语料平均损失差；其指数是困惑度比值。

这只是教学用非参数自助法示例，不宣称在所有小样本或重尾条件下都有精确覆盖率。真实研究需要足够多的独立文档，并检查文档采样是否代表目标分布。少量文档时，区间看似精细也可能没有可靠的有限样本保障。

```python
import numpy as np

rng = np.random.default_rng(17)
lengths = np.array([15, 40, 22, 60, 31, 80, 19, 55], dtype=float)
mean_a = np.array([1.2, 1.7, 1.4, 1.8, 1.6, 1.5, 1.3, 1.9])
mean_b = np.array([1.1, 1.6, 1.45, 1.65, 1.5, 1.45, 1.35, 1.8])
sum_a, sum_b = lengths * mean_a, lengths * mean_b
delta = (sum_a.sum() - sum_b.sum()) / lengths.sum()
idx = rng.integers(0, len(lengths), size=(5000, len(lengths)))
boot_delta = ((sum_a[idx].sum(axis=1) - sum_b[idx].sum(axis=1))
              / lengths[idx].sum(axis=1))
ci_log = np.quantile(boot_delta, [0.025, 0.975])
print("log-PPL difference:", delta)
print("PPL(A)/PPL(B):", np.exp(delta))
print("illustrative paired interval:", np.exp(ci_log))
assert np.isfinite(boot_delta).all()
assert np.isclose(np.exp(delta),
                  np.exp(sum_a.sum() / lengths.sum())
                  / np.exp(sum_b.sum() / lengths.sum()))
```

<a id="information-3-detail-39"></a>

### 9.2 从统计结果走向研究解释

若困惑度比值区间全部大于一，说明在该抽样假设、该语料和该评估协议下，模型乙的对数预测损失更低具有一定统计证据。它不自动支持跨领域、跨分词器或跨应用目标的广泛结论。统计显著性限定的是当前估计对象，而不是替研究者补上缺失的外推论证。

还要报告效应大小。一个非常大的测试集可能使极小损失差也显著，但收益是否值得更高推理成本，需要结合延迟、内存和应用质量判断。相反，区间较宽也不等于两个模型完全一样，只说明现有数据与假设无法精确区分差异。

可以进一步按文档类型分层，观察差异是否集中在代码、数字、引用、长距离依赖或低频词。但分层规则最好提前设定；若事后尝试许多切分，只挑最大的改善汇报，就会引入新的选择偏差。探索性诊断很有价值，但应与预先指定的主要检验区分。

## 10. 研究扩展：从似然评估到实验设计

<a id="information-3-detail-41"></a>

### 10.1 教师强制评分与自由生成评估

自回归困惑度通常在真实历史上计算：每一步把已经出现的真实前缀作为条件，这常称作教师强制评分。它测量模型对真实数据路径的概率拟合。自由生成时，后续历史由模型自身输出形成，模型可能进入训练语料很少覆盖的区域，因此生成行为与真实前缀评分并非同一实验。

这不意味着困惑度毫无价值。严格适当的评分规则是负对数损失；总体困惑度是其总体均值的指数变换，因此在同一计分协议下保留模型的总体排序，并与编码长度和最大似然有清晰联系。不能将有限样本困惑度的期望当成同一个严格适当评分目标。若研究长程任务成功、事实正确或工具执行可靠性，还要直接测量这些行为。模型在常见措辞上的概率改进，可能主要降低语言形式损失，却没有修复关键推理错误。

解码参数进一步改变自由生成分布。温度、截断采样或候选过滤会修改原始预测概率，而常规困惑度通常用原始模型分布评分。如果要评价某个实际采样分布，必须用其归一化后的概率，并检查被截断的真实事件是否得到零概率。不能把原模型困惑度当作任何解码策略都共享的生成质量保证。

<a id="information-3-detail-42"></a>

### 10.2 随机模型的两种平均方式

若模型包含随机变量 $`Z`$，可以计算 $`\mathbb E_Z[-\log q_Z(x)]`$，也可以先得到混合预测 $`\bar q(x)=\mathbb E_Z[q_Z(x)]`$，再算 $`-\log\bar q(x)`$。由负对数的凸性，后者不大于前者。前者衡量随机抽取一个成员后评分的平均表现，后者衡量真正集成概率的表现。

例如两个成员给真实事件的概率分别为 $`0.9`$ 与 $`0.1`$，平均成员损失为 $`-\frac12\log0.09`$，集成损失为 $`-\log0.5`$，二者不同。若实验通过多次 dropout 前向平均概率近似预测分布，应先平均概率再取对数；若只是报告随机前向损失的波动，应明确所估计的是另一对象。

混合概率本身的数值实现也应在对数域中稳定计算，例如对成员对数概率做 log-sum-exp 再减去成员数的对数。有限次蒙特卡洛近似仍有误差；不能把少数抽样得到的概率当作精确积分。在比较随机方法时，还应统一每个样本使用的计算预算。

<a id="information-3-detail-43"></a>

### 10.3 掩码语言模型与伪似然的边界

掩码语言模型常预测 $`q(x_t\mid x_{\setminus t})`$，条件中可能包含右侧文本。这些条件概率的乘积一般不能直接解释为自回归联合似然；任意给定的一组双向条件分布甚至未必对应同一个一致联合分布。因此把逐位置掩码损失取指数，不能不加说明地与因果语言模型困惑度比较。

一种替代量是伪对数似然，即逐个遮盖目标位置后累加其条件对数概率。它可以作为特定协议下的诊断量，但计算条件、计算成本和概率意义都不同。若一次遮盖多个位置，还会改变每个目标可利用的信息，因此多位置掩码损失与逐位置伪似然也不能自动等同。

这个例子再次说明指标名称不能替代定义。研究报告应给出具体条件概率、计分集合和归一化分母，让读者知道实际计算的是什么。若只写“交叉熵损失”或“困惑度”，却省略可见上下文，就可能把明显不同的推断任务放在同一张表里。

<a id="information-3-detail-44"></a>

### 10.4 从高损失样本建立可证伪的研究假设

观察到数字和罕见实体损失较高后，可以提出模型缺少精确记忆或分词效率不足的假设。但同一现象也可能来自标签噪声、事实变化、文本格式不一致或训练分布差异。下一步应设计能区分解释的实验，例如控制内容不变只改变格式、控制频率匹配样本，或在固定分词下比较记忆机制。

研究中的进阶不只是堆叠更复杂的估计器，而是把替代解释逐一变成可检查的预测。若声称长上下文改善实体一致性，就应按实体依赖距离报告配对损失差，并确认没有重复计分或检索答案泄漏。若声称平滑改善罕见词，应观察未见转移与高频转移之间的收益代价，而不只给一个总分。

在复现资料中保留这些诊断路径，比只记录最终最优分数更有用。一个分数只能告诉读者结果，清楚的假设、对照和误差来源才能帮助读者继续研究。所有扩展实验仍应回到同一个基本问题：正在预测哪个事件，在什么条件下，用什么单位衡量？

## 11. 进阶练习与完整解析

<a id="information-3-detail-46"></a>

### 11.1 练习一：从概率还原三种汇总

**题目。** 三个真实事件的条件概率为 $`\frac{1}{2},\frac{1}{4},\frac{1}{8}`$。计算联合概率、平均 nat 损失、平均 bit 损失和困惑度，并解释为何候选数不必等于答案。

**解析。** 联合概率为 $`\frac{1}{64}`$；总 bit 损失为六，平均为二；平均 nat 损失为 $`2\log2`$；困惑度为四。四是等效均匀预测的候选数直觉，而不是每个位置实际只有四个候选。某个位置可以有上万候选，只要分配给真实事件的概率如题所给，最终困惑度仍为四。

<a id="sec-6-1"></a>

<a id="information-3-detail-47"></a>

### 11.2 练习二：改变对数单位保持同一困惑度

**题目。** 平均负对数似然为三 bit。有人使用自然指数得到约二十点一，另一人报告八，谁正确？若损失从三 bit 降为二点五 bit，困惑度改善多少？

**解析。** 正确困惑度为 $`2^3=8`$。自然指数必须先把损失转成 $`3\log2`$ nat。新困惑度为 $`2^{2.5}`$，新旧比值为 $`2^{-0.5}`$，即大约变为原来的百分之七十点七。这里的百分比描述困惑度，不表示分类准确率或生成成功率也按相同比例改变。

<a id="information-3-detail-48"></a>

### 11.3 练习三：文档长度权重

**题目。** 两篇文档长度分别为二和八，困惑度分别为二和十六。计算 token 平均语料困惑度、文档等权几何平均和文档等权算术平均。

**解析。** token 平均结果为 $`\exp(\frac{(2\log2+8\log16)}{10})=2^{3.4}`$；文档等权几何平均为 $`\sqrt{32}`$；算术平均为九。它们对应不同运算或不同抽样单位。若论文使用第一个量，复现时就必须累加损失和及有效计数，不能仅保存每篇困惑度后取算术平均。

<a id="information-3-detail-49"></a>

### 11.4 练习四：概率平均与损失平均

**题目。** 两个随机模型成员对真实事件赋概率 $`0.8`$ 和 $`0.2`$。计算平均成员困惑度、平均成员损失的指数，以及混合模型的困惑度。

**解析。** 两成员困惑度分别为一点二五和五，算术平均为三点一二五；平均损失的指数为 $`\sqrt{1.25\times5}=2.5`$；混合模型真实事件概率为零点五，困惑度为二。三个数不同，分别描述不同实验。混合模型较好的对数评分来自先平均概率这一预测规则，而不是对指标做了更有利的展示。

<a id="information-3-detail-50"></a>

### 11.5 练习五：提示、移位与有效分母

**题目。** 一个长度为六的序列中，前两个位置是提示，后三个是回答内容，最后一个是结束符。输入位置 $`t`$ 预测下一位置。只评估回答及结束符，应计分多少个位置？是否应从掩码真值数再减一？

**解析。** 应计分四个目标位置。显式移位后，目标索引为原位置一到五，其中原位置二到五被计分。若掩码已经按目标对齐并排除了提示，不能再机械减一，否则把四错算为三。是否需要减去某些位置，取决于实际切片与掩码，而不是一个永远适用的批次数公式。

<a id="information-3-detail-51"></a>

### 11.6 练习六：零概率与概率剪裁

**题目。** 某个真实事件被赋予零概率。把它剪裁为 $`10^{-8}`$ 后，得到有限困惑度，能否宣称原模型测试困惑度有限？

**解析。** 不能。原模型的负对数似然为无穷大。剪裁后评估的是修改后的计分规则；若还重新归一化概率，则评估的是另一个概率模型。可以同时报告原始失败与平滑后结果，但需要明确转换。若零只是数值下溢，应回到 logits 稳定计算对数概率，这与改变真实零概率是两回事。

<a id="information-3-detail-52"></a>

### 11.7 练习七：跨分词的平方效应

**题目。** 一个固定完整事件的概率为 $`2^{-12}`$，编码甲有六个 token，编码乙有三个 token。求两种 token 困惑度；若原文共有二十四字节，求相同事件概率对应的 BPB。

**解析。** 甲为 $`2^{\frac{12}{6}}=4`$，乙为 $`2^{\frac{12}{3}}=16`$，差别完全可以来自单位数量。共同字节口径为 $`\frac{12}{24}=0.5`$ bit 每字节。该比较成立的前提是两者确实给同一事件同一概率；若只是规范 token 路径概率，仍要检查多路径解码与结束事件等限制。

<a id="information-3-detail-53"></a>

### 11.8 练习八：上下文条件熵与模型损失

**题目。** 已知增加上下文使真实条件熵下降，能否推出任意模型在每份测试集上的困惑度都下降？请给出两个独立的反对理由。

**解析。** 第一，真实条件熵对应最优条件预测，具体模型可能错误使用新增信息，条件熵不等式不约束任意模型的实现误差。第二，即使总体期望损失改善，有限样本的随机波动也可能让观测分数变差。要支持实际改善，需要在同一目标集合上做配对评估，并报告足够明确的采样与不确定性分析。

<a id="information-3-detail-54"></a>

### 11.9 练习九：分布式归并错误

**题目。** 进程甲处理十个目标，平均损失为一；进程乙处理九十个目标，平均损失为三。若直接平均进程平均损失，结果有什么问题？

**解析。** 直接平均得到二，而真实 token 平均损失为 $`\frac{(10+270)}{100}=2.8`$。应归并损失和与目标数，再除法。若某进程没有有效目标，不能给它一个零平均损失再等权加入。这个问题同样发生在不等长小批次、分片语料和按设备汇总的训练日志中。

<a id="information-3-detail-55"></a>

### 11.10 练习十：平滑的贝叶斯解释

**题目。** 三类输出计数为四、一、零，采用对称 Dirichlet 先验，每个参数为一。求后验预测概率，并解释它与最大后验估计的区别。

**解析。** 后验参数为五、二、一，后验预测概率分别为 $`\frac{5}{8},\frac{2}{8},\frac{1}{8}`$。最大后验在该例中对应原始频率 $`\frac{4}{5},\frac{1}{5},0`$，因为先验参数减一为零，且最优点在边界。后验预测通过对参数不确定性积分得到，不能与寻找参数密度最高点混为一谈。

<a id="information-3-detail-56"></a>

### 11.11 练习十一：置信区间的单调变换

**题目。** 在明确假设下，平均 nat 损失的百分之九十五区间为 $`[1.8,2.2]`$。困惑度区间是什么？是否一定关于 $`e^2`$ 对称？其有效性是否需要困惑度估计无偏？

**解析。** 区间为 $`[e^{1.8},e^{2.2}]`$，一般不关于 $`e^2`$ 对称。单调变换保留参数落入区间的事件，因此如果原区间有相应覆盖率，变换后也有。这个论证不要求点估计无偏；区间有效性与点估计偏差是不同性质，不能相互替代。

<a id="information-3-detail-57"></a>

### 11.12 练习十二：低困惑度与数据泄漏

**题目。** 某模型在一批公开题库对应文本上的困惑度显著更低，能否据此认定其推理能力更强？提出至少三项进一步检查。

**解析。** 应检查题库是否进入训练或检索库、是否有近重复版本、计分文本是否包含答案提示，以及模型分词和上下文是否一致。还应使用未公开的新题与直接任务评分检验推理结论。低困惑度可以来自熟悉措辞、记忆答案或更好的语言形式建模，不能独自区分这些机制。

<a id="information-3-detail-58"></a>

### 11.13 练习十三：文档重采样的目标

**题目。** 对变长文档做自助重采样时，为什么应在每次重采样后重新计算损失和除以 token 总数？如果目标改为随机文档的平均损失，应如何调整？

**解析。** 原目标是随机 token 的平均损失，重采样后长度组成变化，分母也应随之变化，才能继续估计同一比率型目标。若目标改成先随机文档再随机其内部位置，则应先求每篇文档平均损失，再对重采样文档等权平均。两种方法的差异来自研究目标，而不是某一种重采样公式永远更正确。

<a id="information-3-detail-59"></a>

### 11.14 练习十四：设计一次可复现的改进实验

**题目。** 想验证更长上下文改善长文档预测，应预先固定哪些因素，至少检查哪两个实现不变量，如何报告结论？

**解析。** 固定原始语料、分词器、目标位置、文档边界、模型检查点和数值精度，只改变允许的历史长度。检查每个目标恰好计分一次，以及分块汇总的损失和与计数守恒。报告总体及按依赖距离分层的配对损失差，给出合理的文档或块级不确定性，并说明结果针对该模型和分布，不把条件熵定理当成实测改善的替代证据。
