# 信息论

从编码与概率评分推导熵、KL 和似然，再讨论困惑度的评估协议、互信息的估计误差，以及特征选择和表示学习的研究边界。

**先修知识：** 概率、对数、期望。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合追问：换编码后哪些信息量仍能比较](04-互信息特征选择与估计限制.md#sec-7-1)，再对照逐步解析与验收要求。

建议按 01→02→03→04 阅读：先掌握编码和熵，再理解概率评分，随后核对有限语料的计分协议，最后研究依赖估计与特征价值。第 04 章涉及统计估计与验证，可结合统计学和机器学习基础阅读。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
