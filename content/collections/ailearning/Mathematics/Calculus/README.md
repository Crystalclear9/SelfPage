# 微积分

建立变化率、局部近似与累积量的直觉，为梯度训练和概率计算打基础。

**先修知识：** 函数、指数与对数；第 3 章的向量方程、伴随求解和约束敏感性还需矩阵乘法、可逆性及线性方程组。

**正文篇幅状态：** 本主题现有 4 章均已按长篇教材标准展开，逐章纯正文达到 12000–20000 汉字。完整范围见[长篇教材覆盖表](../../README.md#textbook-status)。

## 学习顺序与覆盖范围

第 1—2 章先掌握导数、积分和局部近似。第 3 章进入解映射与隐式求导，可配合[线性方程组与稳定求解](../LinearAlgebra/03-线性方程组与稳定求解.md)阅读；其中最优解和 KKT 的进阶段落可在学习[约束优化](../Optimization/03-凸性二阶方法与约束优化.md)后返回。第 4 章把导数用于训练目标，基础梯度实验在完成第 1—2 章后即可尝试，不必先读完第 3 章全部研究延伸。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：从局部近似到训练目标的完整审查](04-从导数到训练目标的推导实践.md#sec-7-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
