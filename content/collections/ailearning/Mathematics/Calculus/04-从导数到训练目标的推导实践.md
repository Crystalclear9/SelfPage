# 第 4 章 从导数到训练目标的推导实践

[主题目录](README.md) · [分类目录](../README.md) · [总目录](../../README.md) · [上一章](03-多元微分与隐函数.md)

前三章建立了可微、局部模型、曲率和隐式解的语言，本章把它们组装成一个能够逐项审查的训练实验。重点不只是写出一个梯度函数，而是保证任务、样本、损失、归约、导数、更新与评价表达同一个问题。很多训练错误不会导致程序崩溃，甚至会让损失稳定下降，因此必须用彼此独立的证据检查每一层。

学习时准备纸笔和双精度数值环境。先手算小例子，再运行代码，再改变条件观察哪些性质仍然成立。后续神经网络训练虽然参数更多、结构更复杂，但目标缩放、共享路径、有效样本数和状态管理仍然遵循这里的规则。

## 1. 先写训练目标，再决定怎样求导

<a id="chapter-calculus-04-heading-3"></a>

### 1.1 样本、参数和归约是三个不同对象

设一条样本包含输入与标签，参数决定预测函数，损失评价预测与标签的差异。数据集目标还要说明怎样合并多条样本：求和、平均、加权平均或者先分组再平均，代表不同样本权重。最后加上的正则项又可能只约束部分参数。一个公式只有把这些约定写清楚，才具备可复算意义。

例如线性预测含权重和偏置，半平方误差中的二分之一用于抵消平方求导产生的二；数据前的样本数分母控制平均；正则前的系数控制参数偏好。三个常数都可能被记忆中的“常用公式”漏掉。最稳妥的方式是保留完整目标，再逐项微分，而不是先抄梯度、最后猜测它对应哪种损失。

数据本身也有契约。输入每行是一条样本还是每列是一条样本，特征顺序与单位是什么，缺失记录是忽略还是填补，标签是否在预测时点之后才成熟，都决定训练函数的含义。求导检查无法发现未来标签泄漏，因为泄漏目标同样可以拥有完全正确的导数。

<a id="calculus-4-detail-1"></a>

### 1.2 标量模型的计算图与微分

对预测 $\hat y=wx+b$，设误差 $e=wx+b-y$，半平方误差为 $\ell=e^2/2$。先写 $d\ell=e\,de$，再写 $de=x\,dw+db$，于是权重梯度为 $ex$、偏置梯度为 $e$。每个因子来自一个局部计算，符号由目标确定，不需要凭“参数应该增大还是减小”的直觉猜测。

若再加入权重正则 $\lambda w^2/2$，其微分为 $\lambda w\,dw$，不会凭空出现在偏置梯度中。是否惩罚偏置是建模选择，必须在目标里声明。若目标使用的是绝对误差，零残差处又涉及不可微与次梯度，不能继续沿用平方误差的梯度规则。

<a id="sec-1-1"></a>
### 基础算例：同一基点上的一次同时更新

两条样本输入为一与三，标签为二与四，初始权重一、偏置零。残差均为负一，按平均半平方误差计算，损失为二分之一，梯度为权重负二、偏置负一。学习率取零点一，同时更新到权重一点二、偏置零点一，预测变为一点三和三点七，损失为零点一四五。

如果只更新权重，损失变为零点二；如果先更新权重，再用新权重计算偏置梯度，又是第三种算法。三个结果都可能下降，但不能混在同一个实验叙述里。普通梯度下降的一步需要在同一旧参数上计算全部分量，再同时写入新参数，不能由代码赋值顺序悄悄改变数学规则。

<a id="calculus-4-detail-2"></a>

### 1.3 从逐样本微分装配完整向量梯度

令设计矩阵为 $X\in\mathbb R^{n\times d}$、权重为列向量、偏置为标量，残差为 $e=Xw+b\mathbf1-y$。平均半平方误差加权重正则写为

$$
L(w,b)=\frac1{2n}\|e\|_2^2+\frac\lambda2\|w\|_2^2.
$$

微分为 $dL=e^T(X\,dw+\mathbf1\,db)/n+\lambda w^Tdw$，所以梯度为 $X^Te/n+\lambda w$ 与 $\mathbf1^Te/n$。转置的作用是把样本上的误差信号累加回特征坐标，不是随意为匹配形状而添加的符号。

可把权重与偏置合成一个参数向量，再给设计矩阵追加常数列。此时正则矩阵应在偏置位置为零，不能因为参数被拼接就自动把偏置也惩罚。统一向量表示适合实现与梯度检查，但不应抹去不同参数块的语义。

<a id="calculus-4-detail-3"></a>

### 1.4 加权平均与分母的定义

若样本具有固定非负权重 $a_i$，权重和为正，目标可以写成 $\sum_i a_ie_i^2/(2\sum_i a_i)$。权重梯度为 $X^T(a\odot e)/\sum_i a_i$，偏置梯度为加权残差和除以权重和。把所有权重乘同一正数不改变这个目标，但会改变未经归一化的加权总和。

权重可以代表重复次数、重要性修正或业务偏好，数学表达相似，统计解释却不同。把同一条记录重复一百次不能创造一百个独立观测，重要性权重也需要支持与分布假设。讨论有效样本量、置信区间或泛化时，不能只看到权重公式就把所有语义混为一谈。

还需检查权重是否依赖待求参数。如果分子分母都随参数变化，普通商法则会产生额外项。只对残差反传，相当于把权重冻结，是另一种目标或近似。自适应重加权方法应明确这种选择，而不是因为实现方便就默认忽略依赖。

<a id="sec-2"></a>
## 2. 梯度检查：独立验证局部变化

<a id="chapter-calculus-04-heading-9"></a>

### 2.1 前向值正确是检查导数之前的条件

假设解析梯度和数值差分调用同一个损失函数，若两边都把均值写成总和，它们仍可能高度一致。梯度检查只检验给定函数的局部导数，并不证明这个函数就是原任务。因此应先手算一个小样本的预测、残差和损失，再核对梯度与更新。

把参数设为零可以简化许多前向值，但只在零点检查并不充分。有些交叉项在零点恰好消失，错误公式会侥幸通过。应包含非零、非对称参数与不同尺度的样本，再检查共享参数和正则分支。每组输入都应有具体目的，而不是只生成大量随机数期待碰到错误。

<a id="calculus-4-detail-4"></a>

### 2.2 中心差分的目标与步长

对参数第一个坐标加减一个小量，其他坐标不变，中心差分近似该偏导。光滑条件下截断误差通常随步长平方缩小，但浮点相消误差会随步长过小而放大。因此应扫描多个步长，观察是否存在稳定低误差区域，不能把某个固定微小数视为永远可靠的设置。

差分两侧必须使用同一数据、同一损失归约和适当固定的随机状态。若一侧重新采样批次，分子包含数据噪声；若一侧触发不同分支，可能测到跨边界变化；若模型内部更新了统计状态，即便输入参数相同，也可能不再对应同一个确定函数。

<a id="sec-2-1"></a>
### 机制展开：固定目标与恢复参数为何必要

逐坐标检查时，应从同一个原参数向量构造正负扰动，而不是不断在同一数组上加减却忘记恢复。一个坐标残留的微小改动，会让后续坐标在不同基点求导，比较对象随循环漂移。使用独立副本或显式扰动向量能让这一点更清楚。

若损失还依赖缓存、随机生成器或外部状态，也应把这些条件视为函数输入。固定随机种子不等于每次调用自动使用同一个掩码，若生成器持续前进，两次调用仍会不同。可以保存并恢复相关状态，或在教学小例子中直接移除随机性，再逐层扩大检查范围。

<a id="calculus-4-detail-5"></a>

### 2.3 绝对误差、相对误差与逐分量判断

真实梯度接近零时，除以梯度本身会得到极不稳定的相对误差；梯度整体很大时，只看绝对差又可能过分严格。可以同时报告绝对偏差，并用带安全尺度的整体相对量。但安全尺度也有单位含义，改变目标量级后不应机械沿用同一阈值。

整体范数还会掩盖小分量错误。若一个分量为百万、另一个为一，第二个完全漏掉时整体相对误差仍很小。因此检查要保留逐坐标结果，关注最大误差和具有特殊结构的参数块，再结合方向检查。一个汇总小数并不能表达全部导数质量。

<a id="calculus-4-detail-6"></a>

### 2.4 方向检查覆盖什么，又可能漏掉什么

给定单位方向 $v$，比较 $[L(\theta+hv)-L(\theta-hv)]/(2h)$ 与 $\nabla L(\theta)^Tv$。每个方向只需两次函数计算，适合参数很多而无法逐个扰动时使用。若错误向量恰好与该方向正交，就会漏掉，所以应使用多个方向，并保留少量逐坐标检查定位问题。

可以有意构造错误来理解检查能力：给解析梯度增加一个固定错误向量，再选择与它正交和不正交的方向，比较结果。这样比只看到一次随机方向通过更能解释证据边界。随机化有助于发现一般错误，却不能替代对轴、共享和归约机制的审查。

<a id="calculus-4-detail-7"></a>

### 2.5 非光滑点与数值稳定算式

绝对值在零点的中心差分为零，不证明函数可微；ReLU边界的反向约定也不能与跨分支差分强求一致。先在远离拐点的位置检查光滑规则，再单独讨论边界的左右变化，能够避免把正常的非光滑现象误判为整个实现失败。

同一数学函数的两种浮点实现还可能具有不同稳定性。指数与对数的直接组合可能溢出，而代数等价的稳定形式可以正常计算。若函数值本身已经变成无穷或非数，差分误差不再有意义。先验证数值域，再谈梯度精度；通过放宽容差无法修复不稳定的前向计算。

<a id="sec-3"></a>
## 3. 从梯度到更新：用精确模型解释训练行为

<a id="chapter-calculus-04-heading-16"></a>

### 3.1 一步下降应该与什么比较

设当前位置梯度为 $g$，更新为 $h=-\eta g$。线性模型预测损失变化为 $-\eta\|g\|^2$，真实变化还含曲率。若目标梯度在整条更新线段上满足同一光滑界 $L$，下降引理给出变化上界 $-\eta(1-L\eta/2)\|g\|^2$。因此实际下降与线性预测不完全相同，并不自动说明导数有错。

可以把一次更新记录成四个值：旧目标、梯度范数、线性预测变化和新目标。若步长缩小时实际变化与线性预测越来越接近，说明局部模型符合预期；若始终出现固定倍数差异，应先检查目标缩放；若方向完全相反，应检查符号、变量依赖与状态。

<a id="calculus-4-detail-8"></a>

### 3.2 两参数最小二乘的曲率与精确最优点

使用本章两样本例子，把参数写成权重与偏置组成的向量。目标 Hessian 为 $\begin{pmatrix}5&2\\2&1\end{pmatrix}$，特征值为 $3\pm\sqrt8$，均为正，因此目标严格凸并且最优点唯一。由两条预测精确匹配，可得权重一、偏置一，最优损失为零。

初始参数却是权重一、偏置零，说明权重单独看起来已经“正确”，联合梯度仍会改变它，因为偏置误差与权重误差在当前数据上耦合。更新后权重偏离最优值，不代表算法必然走错；多参数下降依据整体目标，不要求每个参数每一步都更接近最终值。

最大特征值约为五点八二八，普通梯度下降对任意初值稳定的充分必要步长范围为零到约零点三四三之间。取步长零点一会稳定收敛，但狭长方向进展较慢；完整牛顿步对这个正定二次函数一次到达最优，因为局部二次模型就是原函数。换成非二次目标后，一步精确到达的性质一般不再成立。

<a id="calculus-4-detail-9"></a>

### 3.3 参数误差、梯度大小和损失值分别说明什么

参数离最优很远，但位于平坦方向，损失差距可能很小；梯度很小，也可能处于非凸鞍点或平坦区；训练损失低，还可能来自目标定义错误或模型过拟合。不同量提供不同信息，不能给其中一个阈值就宣称整个训练已经可靠完成。

对于本章正定二次模型，参数误差、梯度与损失差可以通过特征值互相控制，因此很适合调试。可以用解析最优解作为参照，核对迭代是否趋近同一个目标。真实大型模型没有这样的参照时，仍应先在一个可解析的小问题上验证优化器更新与归约，再扩大到复杂任务。

如果只监测损失总值，还要警惕无关常数。给目标加一个巨大常数不会改变梯度和最优点，却会让相对总损失变化看起来极小。停止规则最好针对梯度、增量、有效误差或任务相关精度，而不是只使用可能被常数背景主导的百分比。

<a id="calculus-4-detail-10"></a>

### 3.4 目标缩放与学习率匹配的准确范围

将整个目标乘以正数 $c$，普通梯度也乘 $c$。若同时把学习率除以 $c$，在相同初值、数据和精确算术下，普通梯度下降的一步及后续轨迹一致。但若只缩放数据项、不缩放正则项，就已经改变二者相对权重，最优解可能变化，不能仅靠学习率修复。

带动量、自适应归一化、梯度裁剪或独立权重衰减时，还要追踪内部状态与常数。某些缩放关系在理想化条件下仍成立，另一些会被稳定项、阈值或实现顺序破坏。不要从普通梯度下降的线性公式，直接推出所有优化器都能通过一个学习率调整保持等价。

早停标准和数值容差也需要同步解释。如果同一个预测函数只因损失单位改变就更早停止，比较结果已经包含停止规则差异。公平实验应说明函数缩放、正则、优化器与停止条件如何一起处理，而不是只在报告里写“学习率相同”。

<a id="calculus-4-detail-11"></a>

### 3.5 分类目标的链式法则与数值形式

二分类令 $z=x^Tw+b$、$y\in\{0,1\}$，逻辑损失可以写成 $\log(1+e^z)-yz$，精确实数运算下其 logit 导数为 $\sigma(z)-y$。再经线性层反传，权重梯度是输入乘该误差，偏置梯度是该误差。这个简化来自特定损失和sigmoid的配合，不是任意概率损失的通用规则。

数值实现应避免先计算极端概率再取对数。对正标签使用 $\log(1+e^{-z})$，对负标签使用 $\log(1+e^z)$，并采用稳定的softplus计算，可以避免溢出与不必要的相消。即使数学表达等价，直接用“大数减大数”也可能丢失很小但有意义的损失。

梯度同样可以采用稳定的带符号间隔形式。令 $s=2y-1$，损失为 $\operatorname{softplus}(-sz)$，对logit导数为 $-s\sigma(-sz)$。当正确预测极其自信时，这个形式仍能表示很小的导数，而直接算已经舍入成一的概率再减标签可能得到零。浮点下的细微差异需要按数值尺度解释，不应把所有差异都归为数学不一致。

<a id="sec-4"></a>
## 4. 从全量目标到小批量、掩码与累积

<a id="chapter-calculus-04-heading-22"></a>

### 4.1 批量均值不是随意添加的除法

有限数据集平均目标是逐样本损失之和除以样本数。若均匀随机抽一条记录，它的梯度对抽样取期望就等于全量平均梯度；若随机抽一个独立批次，批内平均仍无偏。这里的随机性来自样本索引，参数在计算该条件期望时固定，不能把更新后的参数混进同一等式。

如果抽样不均匀，未加修正的批量平均对应抽样分布，而非原来的等权数据目标。可以使用逆抽样概率权重构造适当估计，但需要所有应贡献的样本具有正抽样概率。很小概率还会造成巨大权重与方差，因此代数无偏不等于实际训练稳定。

固定数据集的梯度估计与总体梯度估计也不同。批量平均可以对当前训练集无偏，却不能由此证明训练集代表部署总体。数据选择、标签偏差和未来信息问题仍然存在；优化随机性与统计采样误差应分别审查。

<a id="calculus-4-detail-12"></a>

### 4.2 加权抽样的一个可核验推导

目标为固定权重归一化的逐样本和，记总权重为 $A$。若按概率 $p_i$ 抽索引，使用单样本估计 $a_i\nabla\ell_i/(Ap_i)$，取期望后概率与分母相消，得到目标梯度。均匀抽样时多出样本数系数；若按权重比例抽样，单样本估计又可以直接使用该记录的普通梯度。

这两种实现对应同一个期望方向，但噪声结构不同。某些样本梯度特别大时，仅按业务权重抽样未必方差最小；为了降低方差而改变抽样，又必须保留正确修正。实际系统还受读取成本与并行组织限制，不能只按一个理论方差表达式宣布某策略最优。

若权重为零，该记录不贡献目标；若所有权重为零，归一化目标没有定义，应该触发明确策略。把分母加一个很小数虽然避免除零，却相当于改写目标，并可能掩盖上游样本筛选错误。教学和调试阶段应首先暴露这种异常状态。

<a id="deep-dive-4"></a>
### 深入讲解：微批累积怎样才等价于一个大批更新

把一个大批分成多个微批，所有微批都在同一参数上前向与求导，先累加损失分子或梯度分子，最后除以总有效样本数，才对应大批平均目标。不同微批大小时，直接平均微批均值会给小批过大权重。例如两批分别含两条与六条样本，应按两比六加权，而不是一比一。

若每个微批都各自更新一次参数，即使总样本相同，也变成多次顺序更新。后面的梯度在不同基点计算，不再与同一个大批梯度相等。优化器内部状态、学习率调度与正则施加次数也会变化，因此“累计看了多少样本”不足以决定算法等价。

即便只在末尾更新，含跨样本统计或交互的模型仍需额外检查。BatchNorm、批内对比目标与某些采样机制会让前向函数依赖批次组成，多个小批与一个大批并不是同一个函数。线性可加损失的梯度归约证明，不能自动覆盖这些前向差异。

<a id="calculus-4-detail-13"></a>

### 4.3 正则项在累积中的施加次数

如果累加的是各微批数据梯度分子，再统一归一，应在最终梯度上加一次正则梯度。若每个微批均值都包含同一个正则梯度，再按样本占比加权，系数和为一，也会保留一次正则。若直接把这些均值相加而不正确缩放，正则和数据项都可能被重复放大。

这类错误常表现为改变累积步数后最优参数与训练行为发生变化。不能仅凭有效批大小数值相同，就断言实现一致。先用本章小型二次目标比较一次完整更新，再扩展到包含随机层的训练；把数学归约等价与模型前向等价分开验证。

<a id="calculus-4-detail-14"></a>

### 4.4 掩码平均需要数真正有效的元素

序列、图像和不完整标签任务常有无效位置。若目标只对有效位置平均，分母应是有效计数，掩码为零的位置既不贡献分子也不贡献分母。先按每条序列有效长度平均，再对序列平均，与把所有有效词元一起平均，对不同长度样本施加的权重不同。

假设两条序列分别有两个和八个有效词元。逐序列平均后等权，会让每个短序列词元拥有长序列词元四倍的权重；全词元平均则按有效位置等权。两种目标都可能适合某些任务，重要的是预先说明独立单位和成本，而不是把其中一种称为唯一正确的平均。

当整个批次没有有效标签时，应决定跳过数据更新、保留何种状态、是否仍施加正则，并与调度规则保持一致。这里没有统一答案，但不能把零除零静默变成一个“正常零损失”，再假装获得了一批无误差样本。

<a id="calculus-4-detail-15"></a>

### 4.5 多类别归约与共享参数路径

多分类交叉熵通常先对类别维汇总成每个样本一个损失，再对样本平均；并不默认再除以类别数。对每个logit的导数具有概率减标签的结构，但最终缩放仍由整个目标的归约决定。类别权重、软标签与有效位置掩码都需要从具体目标重新追踪系数。

共享参数用于多个位置时，梯度贡献沿所有路径累加。一个权重在序列中重复使用一百次，并不产生一百个独立参数；复制数值与共享同一参数对象也不是同一实现。检查共享结构可以临时把各使用点写成独立变量求偏导，再按共享关系合并，观察是否与实际反传一致。

<a id="calculus-4-detail-16"></a>

### 4.6 训练随机性与复现边界

固定种子是复现实验的重要条件，却不保证所有实现逐位一致。随机源数量、调用顺序、并行归约、数据加载和算子实现都会影响结果。梯度核对时最好先缩小成双精度、无随机层的确定性函数，建立解析与数值一致性，再逐步恢复真实训练组件。

比较随机算法应看多次独立运行的分布，而不是只挑最好的一次。若两个方案共享初始参数或数据顺序，配对设计可以降低部分比较噪声，但也应明确这是一种耦合，不能把相关运行当作完全独立样本。可复现的目标是让结果与条件可追踪，不是承诺所有环境都生成同一串浮点数。

<a id="sec-5"></a>
## 5. 进阶核对：从局部数值到结构性证据

<a id="chapter-calculus-04-heading-30"></a>

### 5.1 选择检查方向时先考虑错误模式

完全随机的方向适合发现一般实现偏差，但对具有特殊结构的错误，定向检查通常更有解释力。偏置广播错误可以用只扰动偏置的方向检查；共享权重漏一条路径，可以让两个分支产生不同贡献；归约错误可以改变样本数而保持单样本内容不变，观察梯度是否按目标应有规律变化。

设计小例子时，避免所有输入相同、所有标签相同、所有参数为零或维度恰好相等。这些对称条件会让许多错误被抵消。使用不同轴长、非对称数值和有符号残差，能让错误更容易暴露。测试数量并不是唯一关键，是否能够区分竞争实现更重要。

<a id="calculus-4-detail-17"></a>

### 5.2 用不变性检查目标与梯度

等权平均目标中，把全部样本完整复制一遍，数据损失与梯度应保持不变；固定权重归一目标中，把所有权重乘同一正数也应不变。若结果改变，可能把平均写成总和，或只缩放了分子没有同步分母。这些性质不需要知道每个梯度的正确小数，能够独立核对整体结构。

对线性回归，给全部标签和偏置同时加同一常数，残差与数据梯度不变；若偏置不正则，总目标也不变。特征重排时同步重排权重，预测应保持一致。对类别概率，所有logit共同平移不改变Softmax输出，相应梯度沿全一方向应为零。每个性质都带着明确前提，必须避免在改变了正则或参数化后盲目套用。

这些检查通过仍不能证明任务正确。一个始终返回零的错误梯度也可能满足某些对称性，所以要组合手算、有限差分与结构检查。不同证据应来自不同推理路径，才能降低把同一错误复制到多个实现中的风险。

<a id="sec-5-1"></a>
### 从逐样本损失到批量梯度的独立归约检查

先对每条样本计算明确的标量损失和参数梯度，再按目标权重手动累加；另一路用矩阵公式一次算全量结果。两路数值应在合理精度下相同。这种比较能够发现广播、求和轴和有效样本分母错误，但如果两路都使用同一个错误标签排列，仍然无法验证数据对应关系。

还可以把样本重新分组，使用不同大小的微批累积，要求最终梯度一致。比较时固定参数，关闭跨样本依赖，并明确正则施加规则。故意加入一个很小的末批，能够揭露“平均各批均值”造成的错误加权。最后核对一次更新后的参数，而不只比较中间梯度，因为优化器应用顺序也可能出错。

<a id="calculus-4-detail-18"></a>

### 5.3 停止梯度意味着改变哪一个依赖

考虑一个变量既作为输入，又用来生成本步固定目标。若实现有意不让梯度经过目标分支，就不能在差分两侧重新生成目标，再要求与冻结分支的导数相同。数值检查必须表达实际要优化的条件函数：固定当前目标，只扰动被更新参数。

简单例子是数值表达式 $w\,a$，本步先取 $a=w_0$ 并冻结。基点为二时，目标值为四，对待优化变量的导数为二。如果差分时把目标也改成新参数，实际上检查的是 $w^2$，导数为四。两个结果不同来自依赖定义不同，而不是框架的乘法法则失效。

停止梯度算子按规定保留数值、切断某条导数路径，它不等同于一个在实数意义下具有零导数的恒等函数。解释教师目标、目标网络、交替优化或半梯度方法时，应把被冻结的对象列为本步条件，再讨论这些条件在下一步怎样更新。局部求导正确不代表整个交替过程等价于某个单一固定目标的精确梯度下降。

<a id="calculus-4-detail-19"></a>

### 5.4 雅可比作用量与伴随关系

对向量输出映射，前向方向传播计算雅可比乘输入方向，反向传播计算雅可比转置乘输出权重。可用内积恒等式 $a^T(Jv)=v^T(J^Ta)$ 检查两种作用量是否相容，不必显式保存巨大雅可比。这个关系同时验证形状和转置语义，特别适合自定义算子的局部核对。

但如果两种实现共享同一个错误线性算子，伴随关系仍可能成立。因此应再用原函数有限差分检查前向作用量，或用独立手算例子验证。伴随一致、前向正确和目标语义正确是不同层次，不应压成一个“梯度检查通过”的标签。

<a id="calculus-4-detail-20"></a>

### 5.5 二阶检查与保守结论

光滑标量目标的Hessian对称，可以用两个方向检查 $u^THv$ 与 $v^THu$；也可以比较梯度沿方向的差分与Hessian向量积。若不一致，可能来自二阶实现、自定义反向规则、不可微点或数值误差。先检查条件，再决定是否需要修复实现。

对称性不是充分正确性条件，错误的零矩阵同样对称。真实Hessian也不必正定，非凸目标出现负曲率并不自动说明代码错误。二阶核对要验证给定函数的变化结构，而不是强迫所有结果符合某种理想优化几何。

<a id="calculus-4-detail-21"></a>

### 5.6 把“梯度消失”拆成几种不同机制

梯度小可能是目标接近驻点，也可能是激活饱和、路径被切断、损失归约尺度过小或参数根本没有参与前向。可以依次检查参数扰动是否改变函数值、局部模块导数是否非零、不同路径贡献是否抵消，以及逐样本梯度是否在平均时相互抵消。

若每条样本梯度都很大但均值小，说明当前数据目标上的贡献存在抵消；这与所有路径都没有敏感性不同。若函数值随参数明显变化而自动梯度恒为零，优先检查离散转换和停止梯度。若只有极端输入饱和，结合稳定参数化与目标设计判断。诊断需要区分机制，而不是只增加学习率期待一切恢复。

<a id="sec-6"></a>
## 6. 分层练习与详细解析

<a id="chapter-calculus-04-heading-38"></a>

### 6.1 基础层：恢复目标与一次更新

**题一：** 本章两样本回归例子加入权重正则 $\lambda w^2/2$，取 $\lambda=0.2$，偏置不惩罚。计算旧目标、梯度、学习率零点一的同时更新与新目标。

**解析：** 旧数据损失为零点五，正则为零点一，总目标零点六。梯度由原来的负二、负一变为负一点八、负一，更新到权重一点一八、偏置零点一。残差为负零点七二与负零点三六，数据损失零点一六二，正则零点一三九二四，总目标零点三零一二四。必须比较包含同样正则的旧新目标，不能一边报总目标、另一边只报数据损失。

**题二：** 两个微批分别有两条和六条记录，当前参数上的梯度均值分别为二和十。求大批等权样本平均梯度，并解释直接平均微批均值错在哪里。

**解析：** 第一批贡献梯度和四，第二批贡献六十，总计六十四除以八得到八。直接平均两个均值得六，相当于给每个批次相同权重，从而给第一批每条记录三倍于第二批的权重。错误是目标权重改变，不是浮点近似。若本来想按组等权，六也可以对应另一个合法目标，但必须明确说明，不能称为原大批平均的等价实现。

**题三：** 一条二分类样本输入为 $(2,-1)$，logit为零、标签为一。计算逻辑损失对logit、两权重和偏置的导数，解释更新符号。

**解析：** 当前概率二分之一，logit导数负二分之一，权重梯度为负一与正二分之一，偏置梯度负二分之一。负梯度会提高这条样本的logit，从而增加正类概率并降低其损失。输入第二坐标为负，因此相应权重需要减小才能提高加权和；不能凭“正标签就所有权重增大”的口号判断每个参数的方向。

**题四：** 将全部样本复制十遍，平均数据损失、总和数据损失及固定系数正则分别怎样变化？何时原最优点保持不变？

**解析：** 平均数据项不变，总和数据项放大十倍，固定正则项不变。平均目标保持同一函数，最优点自然相同；总和目标若正则不同比例缩放，数据与正则比例改变，最优点一般会变化。只调整学习率只能处理整个目标共同缩放，无法修复相对权重变化。复制样本也不能被当作新增独立证据来缩小统计不确定性。

<a id="calculus-4-detail-22"></a>

### 6.2 归约层：掩码、权重与参数化

**题五：** 两条序列有效长度为二与八，逐序列平均梯度分别为一与三。计算全有效词元平均与逐序列等权平均，两者各对应什么任务权重？

**解析：** 全词元平均为二十六除以十，得到二点六；序列等权为二。前者每个有效位置等权，后者每条序列等权，因而短序列中每个位置权重更大。若业务关心每个用户平均效果，序列等权可能合理；若每个词元都代表同等代价，另一种更直接。需要先定义评价单位，再选择归约，不能看到不同数字就判断其中一个实现必然错误。

**题六：** 一个固定权重归一化目标保持全部残差不变，将权重都乘一百，梯度应怎样变化？如果实现变化了一百倍，应先检查什么？

**解析：** 分子分母同时乘一百，目标和梯度都不变。若梯度放大，可能只加权分子却仍除以原样本数，实际算的是另一种加权目标；若缩小，可能分母重复归一。先用两三条不同权重样本直接算分子分母，不要立即改变学习率掩盖目标错误。权重的业务含义还要另外说明，数值归一正确不代表抽样修正假设成立。

**题七：** 特征全部乘一百、权重除以一百，预测保持不变。若原正则为欧氏平方惩罚，为保持同一个函数偏好，新正则系数应怎样调整？

**解析：** 新权重平方是原来的一万分之一，所以系数需乘一万，才能保持同一惩罚值。若仍使用原系数，相当于对该方向放松了正则。多维不同缩放时，一般需要各方向不同的惩罚权重，而不是仅调整一个统一系数。这个例子揭示了单位、参数化和模型选择的联系：相同预测表达不保证相同正则目标。

**题八：** 令两个固定损失分别为零和一，权重为 $e^\theta$ 与一，采用权重归一平均。在零点计算目标导数，并解释冻结权重的结果为何不同。

**解析：** 目标为 $1/(1+e^\theta)$，在零点导数负四分之一。若把权重当作常量，只对固定损失反传，会得到零，因为损失本身不依赖参数。这里缺失的是权重和分母的依赖。冻结权重可以是有意的交替优化步骤，但应明确它求的是条件函数，而非原始归一目标的完整导数。

<a id="calculus-4-detail-23"></a>

### 6.3 检查层：识别能够通过检查的错误

**题九：** 假设解析梯度多出了误差向量 $(1,1)$，只沿单位方向 $(1,-1)/\sqrt2$ 做检查，是否一定发现错误？怎样改进？

**解析：** 误差与该方向内积为零，因此这次方向检查完全可能通过。加入逐坐标方向或多个不共线方向可以揭露错误。高维里少量随机方向有助于发现一般问题，但不能承诺定位全部坐标。验收结论应说明检查覆盖范围，不能把某次小误差当成对任意参数位置与任意方向的证明。

**题十：** 一个错误的Hessian实现恒返回零矩阵，它通过了对称性测试。是否可以接受？还应增加什么证据？

**解析：** 不能。对称性只是光滑标量函数Hessian必须具备的一项结构，不足以确定其值。应比较梯度沿方向的差分与该矩阵作用量，或在可手算二次函数上核对曲率。零矩阵也可能满足许多线性恒等式，因此不同证据必须连接到原函数，而不是仅检验导数实现内部是否自洽。

**题十一：** 某参数的数值扰动会改变损失，但自动梯度始终为零。列出三种不同解释，并说明如何区分。

**解析：** 可能有意冻结依赖，可能经过整数转换或离散选择，也可能自定义反向规则错误。先把计算图拆成局部模块，确认参数在哪里影响前向；再检查冻结对象是否应在差分中保持不变；最后在光滑连续路径上对局部算子求导。如果只是极端输入饱和，还应改变输入范围并检查稳定公式。不能仅凭一个零值就断言达到最优。

**题十二：** 平方误差目标的梯度看似正确，但给所有标签和偏置共同加十后，梯度改变了。可以直接判错吗？

**解析：** 若偏置不惩罚且所有其他条件相同，残差不变，梯度应保持一致，变化提示实现或状态问题。若偏置被正则化，正则梯度本来会变，这项不变性便不适用于总目标。结构测试必须把前提写清楚，否则会把合理的目标差异误报为错误。可以分别比较数据项与正则项，定位变化来自哪里。

<a id="calculus-4-detail-24"></a>

### 6.4 更新层：实际损失与局部预测

**题十三：** 本章两参数回归从权重一、偏置零开始，学习率改为零点四，求更新后数据损失。是否说明原梯度符号错误？

**解析：** 梯度仍为负二、负一，新参数为一点八与零点四，预测为二点二与五点八，残差为零点二与一点八，平均半平方误差为零点八二，超过原零点五。步长超出了该正定二次问题对全部初值的稳定范围，梯度方向没有错。减小步长或利用曲率可以修正，翻转梯度符号反而会破坏局部下降性质。

**题十四：** 将目标加上一百万，梯度、Hessian和最优解会变化吗？为什么基于相对总损失变化的早停可能变化？

**解析：** 常数项的导数为零，所以三个数学对象不变；但相同绝对下降除以更大总损失，比例会变小，可能更早满足停止阈值。一个合理的优化精度定义应尽量尊重这种无关常数不变性，可以观察梯度、步长、实际误差或相对可改善量。停止规则也是算法的一部分，不能在比较实现时忽略。

**题十五：** 先在旧参数计算权重梯度，更新权重，再计算偏置梯度，与同时梯度下降有何差别？这种方法是否一定错误？

**解析：** 第二个梯度在新的基点上计算，整个步骤属于某种顺序或分块更新，而非原来的一次同时梯度下降。分块算法可以合理且有效，但应重新分析收敛和步长，不能继续使用同时更新的手算期望。调试时先确定设计意图，再比较实现；“与某段参考代码不同”不足以证明算法无效，但“宣称实现甲却实际运行乙”需要修正。

<a id="calculus-4-detail-25"></a>

### 6.5 研究层：证据边界与公平比较

**题十六：** 两个方案达到相同训练损失，一个迭代少、一个每步快，怎样比较？为什么只报告迭代数或只报告单步时间都不够？

**解析：** 应预先规定相同目标、精度与质量标准，记录端到端耗时、函数与梯度评估次数、必要线性求解、内存和最终独立效果。迭代少可能每步代价高，单步快可能需要更多更新；若随机性不同，还需重复运行分布。比较同一训练目标的优化效率，与比较部署预测质量，是相关但不同的实验问题，两者都应保持条件清楚。

<a id="sec-7-2"></a>
### 边界追问：固定倍数差异能否靠放宽容差通过

解析梯度使用均值，差分使用总和时，误差通常随样本数产生固定倍率。它不会随差分步长进入正确区域而消失，因此不应被解释为普通浮点噪声。先核对目标、样本集合、正则和归约，再看数值精度；若不断扩大容差直到通过，检查已经失去原本意义。

还要区分检查程序自身的错误。基点没有恢复、错误复用输出缓冲、函数调用带状态变化，都可能让正确导数看起来失败。保留一个独立手算小例子，分别检查前向函数和检查器，有助于避免为了迎合错误检查器而修改正确算法。

## 7. 完整实验：把推导、实现与验收闭合起来

<a id="chapter-calculus-04-heading-45"></a>

### 7.1 项目定义与证据顺序

实验使用三条二维输入、非等权记录和独立权重正则，目标是一个能够精确求解的小型二次问题。选择这个规模不是为了模拟真实业务难度，而是让每一步都能人工审查，并由解析解、差分与结构恒等式提供不同证据。复杂模型训练前先通过这种小实验，能够降低把基础错误带进大型系统的风险。

证据顺序应从数据与前向开始，再到一阶导数、微批归约、曲率、一次更新和最终参照解。若前向值已经错误，后面的梯度检查可能只是在验证错误函数。若梯度正确而更新失败，优先核对步长与参数写入；若训练达到参照解但外部任务不佳，则应回到数据与目标，不必继续怀疑已经验证的局部求导机制。

代码只依赖NumPy，不读取文件、不保存中间产物。它把形状与有限性检查放在问题构造阶段，将训练函数保持为无状态确定映射。小型示例为了便于解释显式构造Hessian；大规模问题应改用适合结构的线性求解或作用量方法，不应照搬完整矩阵存储。

<a id="calculus-4-detail-26"></a>

### 7.2 可独立运行的加权最小二乘闭环

```python
import numpy as np

def make_problem(X, y, weights, l2):
    X = np.asarray(X, dtype=np.float64)
    y = np.asarray(y, dtype=np.float64)
    weights = np.asarray(weights, dtype=np.float64)
    if X.ndim != 2 or X.shape[0] == 0:
        raise ValueError("X must contain at least one row")
    n, d = X.shape
    if y.shape != (n,) or weights.shape != (n,):
        raise ValueError("one label and weight per row required")
    if not all(np.isfinite(v).all() for v in [X, y, weights]):
        raise ValueError("all inputs must be finite")
    if np.any(weights < 0) or weights.sum() <= 0:
        raise ValueError("nonnegative weights with positive sum required")
    if not np.isfinite(l2) or l2 < 0:
        raise ValueError("l2 must be finite and nonnegative")
    Z = np.column_stack([X, np.ones(n)])
    total_weight = weights.sum()
    R = np.diag(np.r_[np.full(d, l2), 0.0])
    H = (Z.T * weights) @ Z / total_weight + R
    rhs = Z.T @ (weights * y) / total_weight
    def objective(theta):
        theta = np.asarray(theta, dtype=np.float64)
        if theta.shape != (d + 1,) or not np.isfinite(theta).all():
            raise ValueError("invalid parameter vector")
        error = Z @ theta - y
        value = 0.5 * (weights @ (error * error)) / total_weight
        value += 0.5 * theta @ R @ theta
        gradient = Z.T @ (weights * error) / total_weight + R @ theta
        return value, gradient
    return objective, H, rhs, Z, R, weights

X = np.array([[0., 0.], [1., 0.], [0., 1.]])
y = np.array([1., 2., 2.])
a = np.array([1., 2., 1.])
objective, H, rhs, Z, R, a = make_problem(X, y, a, l2=0.1)
zero_value, zero_gradient = objective(np.zeros(3))
np.testing.assert_allclose(zero_value, 1.625)
np.testing.assert_allclose(zero_gradient, [-1., -0.5, -1.75])

theta = np.array([0.3, -0.2, 0.1])
value, gradient = objective(theta)
step = 1e-5
numerical = np.empty_like(theta)
for j in range(theta.size):
    delta = np.zeros_like(theta)
    delta[j] = step
    numerical[j] = (objective(theta + delta)[0]
                    - objective(theta - delta)[0]) / (2 * step)
np.testing.assert_allclose(gradient, numerical, rtol=1e-7, atol=1e-8)

error = Z @ theta - y
accumulated = np.zeros_like(theta)
for ids in [np.array([0]), np.array([1, 2])]:
    accumulated += Z[ids].T @ (a[ids] * error[ids]) / a.sum()
accumulated += R @ theta
np.testing.assert_allclose(accumulated, gradient)

reference = np.linalg.solve(H, rhs)
learning_rate = 1.0 / np.linalg.eigvalsh(H).max()
current = np.zeros(3)
history = []
for iteration in range(1000):
    old_value, current_gradient = objective(current)
    history.append(old_value)
    if np.linalg.norm(current_gradient) < 1e-10:
        break
    current = current - learning_rate * current_gradient
assert np.all(np.diff(history) <= 1e-12)
np.testing.assert_allclose(current, reference, atol=1e-8)
print("reference", reference)
print("final value and gradient", objective(current))
print("updates", iteration)
```

### 7.3 逐项解释程序证明了什么

初始损失一点六二五与梯度中的三个数可以直接由加权残差手算，因此不是由另一个同样复杂的函数作为唯一真值。差分在非零非对称参数上检查三个坐标，避免零点偶然抵消。随后用大小不同的两个微批重新累加，验证分母与正则施加次数。最后用精确线性系统解作为参照，检查迭代轨迹对应同一个严格凸目标。

正则系数为正且偏置方向具有正数据权重，保证本例Hessian正定，最大特征值提供全局步长界。训练损失单调与最终靠近参照解在这个确定二次问题中都有理论依据，不应不加条件地把同样断言复制到随机非凸训练。若修改为零正则或删去某些输入方向，还需重新检查可逆性与唯一性。

这是一份针对温和数值范围的实数教学实现，不承诺任意有限输入都能安全运算。有限权重相加仍可能溢出，特征平方和矩阵乘法也可能产生非有限中间值；稳定逻辑损失不能修复此前已经溢出的logit。扩展到极端范围时，需要适当缩放、检查中间状态并分析条件数；若输入允许复数或特殊对象，还应另行定义转换契约，而不是默认转成实数后继续计算。

返回的参照参数只是这个人工任务的目标最优点，不是关于任何真实总体的统计保证。样本权重、正则与特征单位改变后，它也会改变。保存一个漂亮的低损失不能替代任务定义；本实验的价值在于让推导、实现和更新的关系完全透明，而非声称它已经完成现实预测。

### 7.4 补充手算：参照解为什么不是逐点完美拟合

本例的Hessian三行分别为 $(0.6,0,0.5)$、$(0,0.35,0.25)$、$(0.5,0.25,1)$，右侧向量为 $(1,0.5,1.75)$。逐行写成线性方程，可以独立求出权重 $35/68$、$15/34$，偏置 $47/34$。将它们重新代回原目标，总损失为 $13/272$，约零点零四七七九四，而不是只相信求解器输出的若干小数。

这组三个参数原本能够在零正则时完全拟合三个样本，为什么现在仍有残差？原因是目标允许用少量数据误差换取更小权重。最优条件要求数据梯度与正则梯度抵消，不要求每条记录误差为零。在偏置方向没有正则，最优加权残差和为零；在权重方向，加权残差与特征的相关贡献则等于负的正则梯度。把这两类条件分开核对，比简单要求所有残差消失更符合实际目标。

当正则系数逐渐增大，模型会更倾向于较小权重。在极限情况下权重趋近零，偏置应接近标签加权均值一点七五，而不是未经权重的普通均值。这个极限常数模型的平均半平方误差为零点零九三七五。它提供另一个独立参照：如果很强正则下偏置趋向其他均值，可能是权重归约或偏置惩罚定义发生变化。

还可以把正则系数当作上一章研究的外部参数。内层最优目标关于该系数的包络导数为最优权重平方长度的一半，但验证损失的导数还要考虑参数重新调整带来的间接项。两者回答不同问题：增加惩罚如何改变训练目标最优值，与增加惩罚是否改善外部预测，不能共用一个数值结论。

这组手算也说明为什么不同检查应使用不同参照。梯度差分验证局部变化，线性系统验证驻点条件，直接代回原式验证目标值，强正则极限验证参数语义。若所有证据只来自同一段向量化代码，很容易让相同的分母或列顺序错误在多个位置同步出现；保留可解释的独立推理路径，才是小型实验最有价值的部分。

### 7.5 第二个实验：稳定逻辑损失与梯度

逻辑模型即使只有一个输入特征，也能展示平方误差没有覆盖的数值问题。下面使用带符号间隔构造损失和导数，正则只作用于权重。先在普通参数上差分，再给出极端logit，要求函数值和梯度保持有限。后一个检查不证明极端位置的所有小导数都精确，只验证没有由直接指数运算导致溢出。

```python
import numpy as np

def logistic_objective(theta, X, y, l2=0.2):
    theta = np.asarray(theta, dtype=np.float64)
    X = np.asarray(X, dtype=np.float64)
    y = np.asarray(y, dtype=np.float64)
    if X.ndim != 2 or y.shape != (X.shape[0],) or X.shape[0] == 0:
        raise ValueError("invalid input shape")
    if theta.shape != (X.shape[1] + 1,):
        raise ValueError("invalid parameter shape")
    if not all(np.isfinite(v).all() for v in [theta, X, y]):
        raise ValueError("finite inputs required")
    if not np.all((y == 0) | (y == 1)):
        raise ValueError("binary labels required")
    if not np.isfinite(l2) or l2 < 0:
        raise ValueError("invalid regularization")
    sign = 2 * y - 1
    z = X @ theta[:-1] + theta[-1]
    signed_margin = sign * z
    losses = np.logaddexp(0.0, -signed_margin)
    derivative = -sign * np.exp(-np.logaddexp(0.0, signed_margin))
    value = losses.mean() + 0.5 * l2 * (theta[:-1] @ theta[:-1])
    gradient = np.r_[X.T @ derivative / len(y) + l2 * theta[:-1],
                     derivative.mean()]
    return value, gradient

X = np.array([[-2.], [-1.], [1.], [2.]])
y = np.array([0., 0., 1., 1.])
theta = np.array([0.2, -0.1])
value, gradient = logistic_objective(theta, X, y)
numerical = np.zeros_like(theta)
for j in range(len(theta)):
    delta = np.zeros_like(theta)
    delta[j] = 1e-5
    numerical[j] = (logistic_objective(theta + delta, X, y)[0]
                    - logistic_objective(theta - delta, X, y)[0]) / 2e-5
np.testing.assert_allclose(gradient, numerical, rtol=1e-7, atol=1e-8)
extreme_X = np.array([[-1000.], [-100.], [0.], [100.], [1000.]])
extreme_y = np.array([0., 0., 1., 1., 1.])
extreme_value, extreme_gradient = logistic_objective(
    np.array([1., 0.]), extreme_X, extreme_y
)
assert np.isfinite(extreme_value) and np.isfinite(extreme_gradient).all()
print("ordinary", value, gradient)
print("extreme", extreme_value, extreme_gradient)
```

<a id="calculus-4-detail-30"></a>

### 7.6 故障注入：让检查确实能够拒绝错误

可以依次故意删除一个正则梯度、把偏置梯度除以特征数、将微批均值等权相加、在差分两侧使用不同样本，观察哪些检查失败。不要同时改很多地方，否则无法判断哪项证据对应哪种机制。每次故障都应有预先写出的错误表现，例如固定比例、某个坐标偏差或随步长变小反而恶化。

然后构造能够漏检的错误：让解析梯度和差分函数共同使用错误标签排列，它们可能依然一致；让两个导数实现共享同一错误归约，结构内部比较也可能通过。用人工前向值与样本身份核对补上证据缺口。通过这种对照，可以理解为什么训练验收需要多层证据，而不是再寻找一个万能断言。

故障注入应在内存的小例子上完成，不必改动真实数据或长期项目产物。实验记录保留故障定义、预期现象、实际输出和修复理由即可。为了让所有测试变绿而删除难例或放宽阈值，不是修复目标或实现，只是在改变验收条件。

<a id="sec-7-1"></a>
### 综合练习：从局部近似到训练目标的完整审查

给定一组新样本与非等权记录，独立写出目标、逐样本梯度、矩阵梯度、Hessian和一次同时更新。先手算零参数与一组非零参数的前向值，再实现中心差分和微批累积。最后通过线性系统求参照最优解，解释哪个假设保证它唯一、学习率为什么稳定、哪些结果只对当前二次任务成立。

接着把目标改为逻辑损失，保留同一套验收思路，但不要继续假设存在精确线性方程解或相同的全局曲率。检查标签支持、稳定损失形式与正则，再做有限差分。如果数据线性可分且不加正则，参数可能持续增大而损失趋近下确界，不能把没有有限最优参数误判为所有梯度实现都错误。

最后把评价数据与训练目标分开。训练验收回答程序是否忠实优化写下的函数，独立评价回答这个学习流程能否完成指定预测任务。特征泄漏、标签机制和部署差异属于后一个层次，不能用训练损失下降证明它们不存在。报告应把这两类证据并列，而不是让其中一类替代另一类。

<a id="calculus-4-detail-31"></a>

### 7.7 研究延伸与比较协议

可以比较全量梯度、小批估计、微批累积与阻尼牛顿步，固定样本、初值、目标和停止精度。分别报告每次更新的代价与达到同一目标精度的总代价，再研究改变特征尺度、权重集中程度与条件数后结果如何变化。对随机方法记录多次运行分布，不要只展示最幸运轨迹。

进一步研究一种看似加速的改动究竟改变了计算还是改变了目标。例如丢掉长序列减少运行时间，却改变样本分布；把平均改成总和改变步幅；降低精度减少存储却改变数值误差。先保持问题不变验证实现收益，再有意识地比较质量与成本的权衡，能够让实验结论更清楚。

本章完成标准是：面对一个训练公式，你能从数据契约重建目标，从目标重建梯度，从梯度预测足够小更新的变化，并用独立证据核对程序；面对一个通过差分的实现，你也能指出仍未验证的任务、统计与部署假设。具备这条完整链后，进入矩阵微积分、PyTorch和神经网络训练时，就可以把新结构放进同一套推理框架，而不是每次重新背一组孤立公式。
