# 第 2 章 积分、泰勒展开与曲率

[主题目录](README.md) · [分类目录](../README.md) · [总目录](../../README.md) · [上一章](01-导数偏导数与链式法则.md) · [下一章](03-多元微分与隐函数.md)

上一章把导数理解为局部线性映射，但只知道“扰动足够小时近似可靠”还不够。本章要回答三个更定量的问题：怎样从局部变化率恢复总变化，怎样估计被忽略的误差，以及怎样利用曲率判断有限步长是否安全。积分、泰勒展开和优化步长看似属于不同章节，实际上可以通过沿路径累积导数连接起来。

先修知识包括一元与多元可微、梯度、链式法则、向量内积和基本矩阵运算。涉及特征值的地方会给出几何解释，完整矩阵分解可返回线性代数专题。阅读时应区分精确等式、局部渐近式、邻域误差界和数值实验：它们提供不同强度的结论。

一条曲线在某点的高度、一个区间下的面积，以及移动区间端点时面积的变化率，是三个不同的量。本章从密度 p(x)=2x 的同一幅面积图进入积分，再把沿路径累积导数的方法用于泰勒余项与步长保证；遇到近似时，同时说明近似对象、误差尺度和可使用的邻域。

## 1. 积分：从局部速率到累积变化

<a id="chapter-calculus-02-heading-3"></a>

### 1.1 黎曼和中的宽度为什么不可省略

在有限区间上划分网格，每个小区间选一个代表位置，把函数高度乘以区间宽度再求和。若网格最大宽度趋零时，无论代表点如何选择，所得和趋于同一有限值，这个值就是黎曼积分。连续函数在闭有界区间上可积，因而多数入门例子能够用这种方式直接理解。

<a id="scientific-plate-02"></a>

以同一个区间和同一条曲线比较两种分割，矩形高度与宽度都可以从图上核对。

![左图用左端点高度作矩形和，右图用新增条带表示累积量的增量](images/02-integral-rectangle-sum-and-endpoint.webp)

[打开原图放大](images/02-integral-rectangle-sum-and-endpoint.webp)

图 (a) 用等宽小矩形近似同一区间的积分，每个高度从该格的左端点读取。加密分割时，逐格缩小宽度并重新取高度。图 (b) 保持积分起点不动，只把右端从 $`x`$ 移到 $`x+h`$。新增部分由这两个端点截出，因此累积量的变化只取决于端点之间的函数值。连续性给出接下来将条带平均高度与 $`f(x)`$ 联系起来的条件。

宽度承担单位转换。速度乘时间得到位移，功率乘时间得到能量，概率密度乘坐标宽度得到概率。如果只把高度相加，随着网格数增加结果会任意变化，没有表示同一个累积量。单位检查不是附加装饰，而是判断离散近似有没有表达正确对象的第一道检验。

积分允许正负抵消。速度为正表示某方向运动，为负表示反方向运动，速度积分是净位移；路程要积分速度绝对值。例如在零到二的时间范围内，速度为时间减一，则净位移为零，路程却为一。把积分一概解释成正面积，会掩盖符号的实际含义。

<a id="sec-1-1"></a>

### 基础算例：面积、密度高度与概率分别计算

取 $`p(x)=2x`$，定义于零到一区间，外部为零。归一化积分为一，因此可以作为概率密度。事件 $`X\le\frac{1}{2}`$ 的概率为四分之一，而密度在二分之一处的值为一。密度高度和事件概率属于不同对象，连续分布下单点概率仍为零。

将区间均匀划成 $`n`$ 段，右端点黎曼和为 $`\sum_{i=1}^n\frac{2(\frac{i}{n})}{n}=\frac{(n+1)}{n}`$，它从一上方趋近归一化积分；中点和恰好为一，因为被积函数是线性函数。后一性质不意味着任意函数的中点和都精确，必须看规则能够精确处理哪一类函数。

同一个密度的期望为 $`\int_0^1x\,2x\,dx=\frac{2}{3}`$。概率较集中于右侧，所以均值大于区间中点。若改成区间零到二上的均匀分布，密度是二分之一而非一，期望计算必须带上这个系数。省去密度后算出的只是普通累积积分，未必是目标分布的平均值。

<a id="calculus-2-detail-1"></a>

### 1.2 微积分基本定理的两个方向

设 $`f`$ 在区间上连续，定义 $`F(x)=\int_a^x f(t)\,dt`$。当 $`h\ne0`$ 时，差商为小区间上函数的平均值：$`\frac{[F(x+h)-F(x)]}{h}=h^{-1}\int_x^{x+h}f(t)\,dt`$。连续性保证区间收缩后，平均值趋于 $`f(x)`$，所以 $`F'=f`$。累积量的瞬时变化率恢复了原速率。

反方向，若 $`G'=f`$ 且满足这里的连续条件，$`F`$ 与 $`G`$ 导数相同，差为常数，于是 $`\int_a^b f(t)\,dt=G(b)-G(a)`$。这说明可以通过原函数计算积分，而不是把“找原函数”当成积分本身的定义。有些可积函数没有初等表达式原函数，但累积量仍然定义良好，也可以数值计算。

连续性在这个入门版本中让每一步都方便成立。更一般的分析会用绝对连续、几乎处处导数与 Lebesgue 积分讨论基本定理，不能简单删除条件后声称所有可导函数都自动满足任意形式的导数积分交换。本章后续推导会明确使用沿路径足够连续的导数。

<a id="calculus-2-detail-2"></a>

### 1.3 换元公式来自链式法则，方向与边界也必须变化

若 $`u=g(x)`$ 在适合区间单调且可微，由链式法则可得一元换元公式。定积分中必须同时变换上下限。例子 $`\int_0^1 2x e^{x^2}\,dx`$，令 $`u=x^2`$，得到 $`\int_0^1e^u\,du=e-1`$。若上限原为二，新上限应为四；只替换被积表达式而保留旧边界，就会计算另一个问题。

若变换反向，积分上下限随之交换，符号自动处理方向。概率密度变换却涉及绝对雅可比，因为概率质量不能因坐标方向反转变成负值。这两种场景经常使用相似符号，却承担不同语义，不能把有向积分的符号习惯未经说明套进密度公式。

分部积分同样来自乘积法则。对可微函数的乘积求导并积分，得到 $`\int u\,dv=uv-\int v\,du`$。边界项必须保留，例如计算指数分布均值时，边界是否趋零决定推导合法。分部积分不是任意移动一个微分符号，而是把乘积的完整变化拆分为两部分。

<a id="calculus-2-detail-3"></a>

### 1.4 无穷区间与奇异点：先检查收敛再操作

广义积分通过截断极限定义，例如 $`\int_1^\infty x^{-p}\,dx`$ 是上限趋向无穷时的极限。当 $`p>1`$ 时收敛，否则发散。有限区间上的奇异点也需要单侧截断，例如零到一上 $`x^{-p}`$ 的积分仅在 $`p\lt 1`$ 时有限。形式上写出一个原函数，不等于积分已经存在。

若在奇异点两侧分别发散，不能把两侧无穷量直接抵消后当作普通积分。对称截断得到的柯西主值是另一种对象，需要明确命名。在概率期望中，正负部分若都为无穷，通常不能赋予一个由对称消去得到的有限期望。许多“看起来算出来了”的错误，根源就在跳过收敛检查。

## 2. 泰勒展开：近似必须同时交代余项

<a id="chapter-calculus-02-heading-9"></a>

### 2.1 从积分恒等式推导二阶模型

设一元函数在所研究线段附近二阶连续可微。基本定理给出 $`f(x+h)-f(x)=\int_0^h f'(x+t)\,dt`$，再把导数写成 $`f'(x+t)=f'(x)+\int_0^t f''(x+s)\,ds`$。交换这个连续函数的有限区间积分顺序，可以得到

```math
\begin{aligned}
&f(x+h)=f(x)+f'(x)h\\
&\quad +\int_0^h(h-t)f''(x+t)\,dt.
\end{aligned}
```

更方便同时处理正负步长的写法是

```math
\begin{aligned}
&f(x+h)=f(x)+f'(x)h\\
&\quad +h^2\int_0^1(1-t)f''(x+th)\,dt.
\end{aligned}
```

若把积分中的二阶导数换成起点值，常数积分为二分之一，就出现熟悉的二阶泰勒多项式。替换并非自动精确，差额正是需要估计的余项。对二次函数二阶导数恒定，所以二阶展开完全精确；对一般函数只能在足够小邻域中近似。

<a id="sec-2-1"></a>

### 机制展开：一阶与二阶近似分别忽略了什么

对 $`f(x)=x^3`$，在 $`x=2`$ 处，精确变化为 $`12h+6h^2+h^3`$。线性近似忽略后两项，二阶近似只忽略立方项。取步长零点一，真实增量为一点二六一，线性预测一点二，二阶预测一点二六。提高近似阶数改善了误差，但这个例子不能推出对任意大步长增加阶数都一定有用。

如果需要绝对误差不超过某个阈值，必须使用邻域内的导数上界。一阶余项由二阶导数控制，二阶余项由三阶导数控制。只知道起点导数很小，不足以限制整条线段上的变化。函数可能在离起点不远处急剧弯曲，忽略邻域条件会让近似误差远超预期。

<a id="deep-dive-2"></a>

### 2.2 三种常见余项形式与不同信息需求

Peano 形式写为 $`f(x+h)=f(x)+f'(x)h+\frac{f''(x)h^2}{2}+o(h^2)`$，表达步长趋零时相对二阶尺度的余项消失。它适合局部性质分析，却不给出一个现成的有限步长数值误差界。把小量符号直接替换成零，等于丢掉了整个近似适用问题。

在足够光滑的条件下，Lagrange 余项写为 $`\frac{f^{(k+1)}(\xi)h^{k+1}}{(k+1)!}`$，其中中间点位于起点与终点之间。通常不知道中间点具体在哪里，但若邻域内高阶导数绝对值有统一上界，就得到显式误差控制。中间点可能随步长改变，不能把它当成某个固定但未知的常数进行不合法比较。

积分余项保留整条路径上的高阶导数，例如二阶多项式后的余项为 $`\frac{h^3}{2}\int_0^1(1-t)^2f^{(3)}(x+th)\,dt`$。对随机模型、向量映射和非均匀曲率，积分形式往往比一个未知中间点更容易估计。三种形式并非谁“更高级”，而是回答渐近、邻域上界和路径累积三类问题。

<a id="calculus-2-detail-4"></a>

### 2.3 两个完整近似算例

估计 $`e^{0.1}`$，在零点取二阶多项式得到一点一零五。三阶导数仍是指数函数，在零到零点一上不超过 $`e^{0.1}`$，所以误差不超过 $`\frac{e^{0.1}(0.1)^3}{6}`$，约为零点零零零一八四二。真实误差约零点零零零一七零九，落在界内。误差界提供的是保证范围，通常不等于实际误差。

估计 $`\log(1.1)`$，二阶近似为零点一减去零点零零五，等于零点零九五。三阶导数为 $`\frac{2}{(1+x)^3}`$，在零到零点一上不超过二，所以余项绝对值不超过零点一的三次方除以三，约零点零零零三三三三；真实值约零点零九五三一零二。若输入改为接近负一，导数上界会迅速变大，相同数值步长未必仍可靠。

### 2.4 光滑不等于解析：所有导数也未必恢复函数

定义 $`r(x)=e^{-\frac{1}{x^2}}`$（$`x\ne0`$），并令 $`r(0)=0`$。先在非零点求导。写 $`u=\frac1x`$，则 $`r^{(j)}(x)=P_j(u)e^{-u^2}`$，其中 $`P_0(u)=1`$，链式法则给出

```math
P_{j+1}(u)=-u^2 P_j'(u)+2u^3P_j(u).
```

这样每阶的 $`P_j`$ 都是多项式。再单独检查原点：若 $`r^{(j)}(0)=0`$，它的差商为 $`uP_j(u)e^{-u^2}`$，在 $`x\to0`$ 时趋于零，因为指数衰减快过任意固定次幂。由 $`r(0)=0`$ 归纳可知各阶导数在原点都存在且为零。原点的泰勒级数因此恒为零，而 $`r(x)`$ 在每个非零点都严格为正。

这个反例区分了无限可微与解析。解析还要求函数在某邻域等于其收敛幂级数，而无限可微只保证各阶局部导数存在。实际学习中通常只需要有限阶局部模型，但不能把“能不断求导”扩大为“无限展开必定恢复原函数”。即便函数解析，收敛半径也由具体函数结构决定，不是任意远处都有效。

## 3. 曲率怎样限制学习率与收敛速度

<a id="chapter-calculus-02-heading-15"></a>

### 3.1 一维二次函数的完整动力学

先研究 $`f(w)=\frac{aw^2}{2}`$，其中 $`a>0`$。梯度为 $`aw`$，固定步长更新满足 $`w_{t+1}=(1-\eta a)w_t`$，所以精确解为 $`w_t=(1-\eta a)^tw_0`$。收敛条件是乘子绝对值小于一，即 $`0\lt \eta a\lt 2`$；这个条件不是经验调参建议，而是从递推式直接得到的必要充分条件，假设初始值非零。

当乘子在零到一之间，参数从同一侧靠近最优点；乘子在负一到零之间，参数跨越零点交替靠近；乘子等于负一时参数永远来回跳，损失不变；绝对值超过一时参数幅度增长。只观察“参数正负交替”不足以判定发散，因为收敛振荡与发散振荡具有不同幅度规律。

取曲率十、初始点一。步长零点零五时，参数依次为一、零点五、零点二五；步长零点一五时为一、负零点五、零点二五；步长零点二五时为一、负一点五、二点二五。前两者损失都以相同倍率缩小，第三种不断增大。沿负梯度选对了方向，仍需要控制有限位移。

这个例子还区分了参数误差与函数误差：参数幅度每步乘 $`\vert 1-\eta a\vert `$，函数差距每步乘其平方。报告收敛率时要说明比较的是参数、梯度还是损失，不能看到不同指数就误以为两个分析相互矛盾。

<a id="calculus-2-detail-6"></a>

### 3.2 多维二次函数沿特征方向独立演化

设 $`H`$ 为实对称正定矩阵，目标 $`f(w)=\frac{w^THw}{2}`$。用正交特征基写 $`H=Q\Lambda Q^T`$，令 $`z=Q^Tw`$，更新变成 $`z_{i,t+1}=(1-\eta\lambda_i)z_{i,t}`$。正交坐标把耦合二次问题拆成多个一维递推，最大特征值限制稳定步长，最小特征值则决定某些方向为何缓慢。

要对所有初始点稳定收敛，需 $`0\lt \eta\lt \frac{2}{\lambda_{\max}}`$。若只对一个特殊初始点分析，某些特征分量可能恰为零，实际稳定条件可以更宽；常用界为了提供统一保证，不依赖这种偶然初始化。若矩阵仅半正定，零特征方向不会收缩，参数可能停在一组极小点中的某个点，而非统一收敛到零向量。

定义 $`\mu=\lambda_{\min}`$、$`L=\lambda_{\max}`$。在正定二次问题中，为最小化最坏方向的绝对乘子，可以让两端等幅反号，解得 $`\eta_*=\frac{2}{(L+\mu)}`$，最坏收缩因子为 $`\frac{(L-\mu)}{(L+\mu)}`$。写成条件数 $`\kappa=\frac{L}{\mu}`$ 后即 $`\frac{(\kappa-1)}{(\kappa+1)}`$。这说明谷地越狭长，单一标量步长越难同时照顾陡峭与平缓方向。

取 $`H=\mathrm{diag}(1,100)`$，最优统一步长约零点零一九八，最坏参数收缩因子约零点九八零二。第二方向限制步长，第一方向却每步只前进很少。这个模型为预条件与动量提供动机，但不代表真实非凸训练全过程拥有固定的 Hessian 或固定特征方向。

<a id="calculus-2-detail-7"></a>

### 3.3 不使用 Hessian 也能得到下降保证

如果梯度在连接两点的线段上满足 $`\Vert \nabla f(u)-\nabla f(v)\Vert \le L\Vert u-v\Vert `$，沿路径 $`\phi(t)=f(x+th)`$ 积分，得到

```math
f(x+h)-f(x)=\int_0^1\nabla f(x+th)^Th\,dt.
```

减去起点线性项，利用内积不等式与梯度变化界，就有

```math
f(x+h)\le f(x)+\nabla f(x)^Th+\frac L2\Vert h\Vert ^2.
```

这称为下降引理。它不要求函数凸，也不要求显式形成二阶矩阵；梯度的邻域 Lipschitz 控制已经足够。若函数二阶连续可微，Hessian 算子范数在邻域内不超过 $`L`$ 是一个常用充分条件，但不是必须从某个单点 Hessian 数值猜出全局常数。

代入 $`h=-\eta g`$、$`g=\nabla f(x)`$，得到下降量至少为 $`\eta(1-\frac{L\eta}{2})\Vert g\Vert ^2`$。非零梯度处，只要 $`0\lt \eta\lt \frac{2}{L}`$ 且整条更新线段满足所用界，就能保证下降。若只知道一个很小邻域内的光滑常数，还需确保更新未走出该邻域，不能用结论反过来替代前提。

<a id="calculus-2-detail-8"></a>

### 3.4 损失下降不自动证明到达全局最优

假设目标有下界、梯度全局 $`L`$-Lipschitz，取固定步长 $`0\lt \eta\le\frac{1}{L}`$。下降引理给出 $`f(x_t)-f(x_{t+1})\ge\frac{\eta\Vert g_t\Vert ^2}{2}`$。累加可得

```math
\min_{0\le t\lt T}\Vert g_t\Vert ^2
\le\frac{2[f(x_0)-f_{\inf}]}{\eta T}.
```

这是某个迭代点接近一阶驻点的保证，不等于参数必然收敛、不等于每一步梯度范数单调下降，更不等于非凸目标找到全局极小。逻辑上应准确陈述被控制的对象，不能因为公式中出现收敛速度就把所有理想性质一并附加。

若再有强凸性，可以把梯度大小与函数差距联系起来，得到更强的线性收敛结果；若存在鞍点，则一阶条件不足以判断极小；若函数在某些方向平坦，参数可能变化但损失几乎不变。曲率信息的价值正在于进一步区分这些情况，而不是把一阶分析全部否定。

## 4. 积分、概率期望与小噪声近似

<a id="chapter-calculus-02-heading-20"></a>

### 4.1 期望是按分布加权的积分

对连续随机变量，$`\mathbb E[g(X)]=\int g(x)p(x)\,dx`$；对离散变量，相应改为按概率求和。两者统一表达为对概率测度积分。教材中把求和换成积分，改变的是分布描述方式，而不是可以省略权重的许可。随机变量若含离散与连续混合成分，还要分别处理质量与密度。

密度 $`p(x)=2x`$ 在零到一区间时，一阶矩为三分之二，二阶矩为二分之一，方差为十八分之一。这三个数可以独立核对：方差是二阶矩减均值平方，而非直接把二阶矩叫作波动大小。若用均匀网格对期望做数值积分，每个网格权重还要乘密度；若直接从目标分布采样，则样本平均已通过采样频率体现权重，不应再无条件乘一次密度。

一个容易误用的例子是均匀抽样估计普通积分。若 $`U`$ 均匀分布于 $`[a,b]`$，则 $`\int_a^b f(x)dx=(b-a)\mathbb E[f(U)]`$。只有单位长度区间，这个长度系数才为一。换成非均匀提议分布后，重要性权重需要相应改变，并要求被积分质量所在位置得到覆盖。

<a id="calculus-2-detail-9"></a>

### 4.2 概率变换中的绝对雅可比

若 $`X`$ 在零到一均匀分布，令 $`Y=X^2`$。对零到一的 $`y`$，分布函数为 $`\Pr(Y\le y)=\sqrt y`$，求导得密度 $`p_Y(y)=\frac{1}{(2\sqrt y)}`$。密度在零附近很高甚至发散，但积分仍为一，说明密度高度没有被限制在一以内，关键是总质量有限。

一般单调可微可逆变换满足 $`p_Y(y)=p_X(g^{-1}(y))\vert (g^{-1})'(y)\vert `$。绝对值保证概率非负；若变换不是单射，需对不同原像分支求和。例如平方作用于正负两侧时，不能只取正根一条分支。这些细节会在归一化流和变量重参数化中再次出现。

坐标变换也解释了同一分布在不同单位下密度值为何不同。把长度单位缩小一百倍，数值坐标变大，单位坐标区间承载的质量变少，密度高度会相应缩小；事件概率保持不变。比较两个密度数值前，应确认坐标与测度一致，不能把密度高度直接当作与单位无关的概率。

<a id="calculus-2-detail-10"></a>

### 4.3 何时允许把求导移进期望

设 $`F(\theta)=\mathbb E[g(\theta,Z)]`$，分布不随参数变化。一个实用充分条件是：存在一个与参数无关的零概率集合，集合外每个固定样本的参数函数在整个区间邻域内可微，导数绝对值由同一个可积随机变量统一控制，并且函数在邻域内某个基点可积。通过中值形式控制差商，再用支配收敛，可以得到 $`F'(\theta)=\mathbb E[\partial_\theta g(\theta,Z)]`$。

这里的“统一”非常关键。每个固定参数的导数可积，不自动保证参数趋近时能够交换极限与积分。若分布本身随参数改变，还会出现分布变化项，不能把它藏进同一个公式里。若目标包含指示函数，逐样本导数可能几乎处处为零，但总体期望仍随参数变化，例如 $`Z`$ 在零到一均匀时，$`\mathbb E[\mathbf1\{Z\le\theta\}]=\theta`$，内部参数处导数为一。

这个反例不是支配收敛定理失效，而是差商缺少适合的统一可积控制，且跳变边界随参数移动。实际使用重参数化梯度、评分函数估计或离散决策时，应先判断随机机制与可微对象，再选估计方法。自动微分只追踪指定程序的局部规则，不会自动证明期望交换的分析条件。

进一步把“分布变化项”算出来。设 $`a(\theta),b(\theta)`$ 可微，$`k(\theta,z)`$ 及其参数偏导在移动区间附近连续，且所讨论的区间有限，则 Leibniz 公式为

```math
\begin{aligned}
&\frac{d}{d\theta}\int_{a(\theta)}^{b(\theta)}k(\theta,z)\,dz
=\int_{a(\theta)}^{b(\theta)}\partial_\theta k(\theta,z)\,dz\\
&\quad +k(\theta,b(\theta))b'(\theta)-k(\theta,a(\theta))a'(\theta).
\end{aligned}
```

可以把差值拆成原区间上函数变化、右端新增薄片、左端移走薄片三部分。第一部分除以步长后给积分内偏导；两个薄片的宽度分别约为 $`b'\,d\theta`$ 与 $`a'\,d\theta`$，连续性使其平均高度趋于端点函数值，因而出现带正负号的边界项。若端点向反方向移动，带符号积分仍给同一公式。这条推导说明，不能仅对固定区间内的密度表达式求导，再忘记支持集合也在移动。

取 $`Z_\theta\sim\mathrm{Uniform}(0,\theta)`$，$`\theta>0`$，目标为 $`F(\theta)=E[Z_\theta]=\int_0^\theta\frac{z}{\theta}\,dz=\frac{\theta}{2}`$。若只对内部密度求导，得到 $`\int_0^\theta-\frac{z}{\theta^2}\,dz=-\frac{1}{2}`$；右边界贡献为 $`(\frac{\theta}{\theta})\times1=1`$，二者相加才是正确导数 $`\frac{1}{2}`$。同样，内部评分函数为 $`\partial_\theta\log p_\theta(z)=-\frac{1}{\theta}`$，其期望为 $`-\frac{1}{\theta}`$ 而非零：常用的零均值评分恒等式在这里缺少支持不变等正规条件。这个错误不能通过增加抽样次数消除。

改用重参数化 $`Z_\theta=\theta U`$、$`U\sim\mathrm{Uniform}(0,1)`$，则分布不变，$`F'(\theta)=E[U]=\frac{1}{2}`$，边界移动已经进入样本路径的导数。若进一步研究阈值事件 $`P(Z_\theta>c)`$，$`c>0`$，结果在 $`\theta\le c`$ 时为零，在 $`\theta>c`$ 时为 $`1-\frac{c}{\theta}`$；右侧导数是 $`\frac{c}{\theta^2}`$，但逐样本指示函数在几乎所有 $`U`$ 上的普通导数仍为零。重参数化解决了支持表示，却没有自动解决不连续目标。需要分别检查路径可微性与交换条件，才能决定使用哪种梯度构造。

### 图解：一个正贡献为什么会被漏掉

![支持从零到二扩张至零到二点四，表中分开原区间减重与新增部分的正贡献](images/02-moving-support-two-contributions.webp)

[打开原图放大](images/02-moving-support-two-contributions.webp)

图 (a) 只比较均匀分布的原支持与新支持。要计算均值的变化，还需要在各区间内积分 $`k(\theta,z)=zp_\theta(z)=\frac z\theta`$。将 $`\theta`$ 从二增加到二点四时，原区间 $`[0,2]`$ 上的被积函数因归一化而降低，新增区间则提供正贡献。图 (b) 分别记下两笔面积，下面逐项复算。

两笔有限变化都能精确积分。固定旧区间内的差为

```math
\int_0^2\left(\frac z{2.4}-\frac z2\right)\,\mathrm dz=-\frac16,
```

新增支持的贡献为

```math
\int_2^{2.4}\frac z{2.4}\,\mathrm dz=\frac{11}{30}.
```

二者相加为 $`\frac15=0.2`$，与均值从一变为一点二完全一致。再除以 $`\Delta\theta=0.4`$，得到总变化率二分之一。有限变化中两笔贡献的变化率分别为 $`-\frac5{12}`$ 和 $`\frac{11}{12}`$，并不是立即等于导数公式里的 $`-\frac12`$ 与一；只有继续让步长趋零，它们才分别趋向那两个数。将有限面积与极限系数区分开，才能理解 Leibniz 边界项来自哪里。

还可以把图中的两笔有限面积各除以步长。固定起点 $`\theta=2`$，取任意正步长 $`h`$，两笔面积的变化率分别为 $`-\frac{1}{2+h}`$ 和 $`\frac{4+h}{2(2+h)}`$。相加恒为二分之一，但它们各自在 $`h\to0`$ 时才趋向内部导数与边界导数。有限区间的换序条件和移动端点公式可核对 NIST DLMF 1.5.22。

若目标换成不连续指示函数，重参数化后的样本路径仍可能不可微；图中的光滑被积函数不能替代那种情形的交换条件。这里已经能看出为什么“内部评分函数期望不为零”不是靠更多 Monte Carlo 样本就能修复的计算噪声：遗漏的是整块概率支持变化。

<a id="calculus-2-detail-11"></a>

### 4.4 二阶展开如何估计非线性均值偏移

设 $`X=\mu+\varepsilon`$，噪声均值为零、协方差为 $`\Sigma`$。在适合的小噪声与余项可积条件下，二阶展开后取期望，线性项消失，得到

```math
\mathbb E[f(X)]\approx f(\mu)+\frac12\mathrm{tr}(H_f(\mu)\Sigma).
```

因为 $`\mathbb E[\varepsilon^TH\varepsilon]=\mathrm{tr}(H\mathbb E[\varepsilon\varepsilon^T])`$。所以零均值噪声通过曲率可以造成非零输出均值偏移。函数为仿射时，先平均再求函数与先求函数再平均精确相等；一般非线性函数则要检查分布与完整函数。曲率项消失，只说明二阶预测的偏移为零；曲率项非零，也不能排除有限噪声下高阶项恰好抵消它。

![相同的等概率正负一经过两种模型，二阶近似期望为一，完整函数期望为零](images/02-two-point-noise-fourth-order-cancellation.webp)

[打开原图放大](images/02-two-point-noise-fourth-order-cancellation.webp)

例如取 $`f(x)=x^2-x^4`$，输入等概率为 $`-s,+s`$，均值为零、方差为 $`s^2`$，且 $`f''(0)=2`$。二阶公式预测输出均值为 $`s^2`$，精确值却是 $`s^2-s^4`$。两者差为 $`s^4`$；当 $`s\to0`$，该差相对二阶尺度趋零，近似成立。取有限幅度 $`s=1`$，高阶贡献恰好抵消二阶贡献，精确均值与 $`f(0)`$ 都为零。

上图用相同的两个概率原子作输入。沿二阶模型计算时，两点各输出一，乘上各自的二分之一后相加，得到期望一。沿完整函数计算时，两点各输出零，所以期望为零。若把幅度恢复为任意 $`s>0`$，近似与精确期望之差是 $`s^4`$，相对二阶尺度的比例为 $`s^2`$，会随 $`s\to0`$ 而消失。有限幅度的抵消说明不能把渐近展开直接当成等式。后面使用 Jensen 不等式时还需检查函数的全局凸性。

一维平方函数给出精确例子：$`\mathbb E[X^2]=\mu^2+\sigma^2`$。指数函数在零均值高斯噪声下的精确均值为 $`e^{\frac{\sigma^2}{2}}`$，小方差时二阶近似为 $`1+\frac{\sigma^2}{2}`$。若噪声很大或尾部导致高阶余项不可积，局部展开再取期望可能不可靠，不能因为均值与方差存在就自动使用所有高阶近似。

<a id="calculus-2-detail-12"></a>

### 4.5 积分确定性误差与蒙特卡洛随机误差

一维光滑函数可以用梯形、中点或更高阶求积规则，误差由网格间距和导数界控制。蒙特卡洛样本均值在独立同分布、有限方差条件下，标准误差按样本量平方根倒数缩小。两者的误差机制不同：一个主要是确定性离散误差，一个是随机抽样波动。

低维光滑问题里，规则网格常常很有效；高维直接网格点数随维度急剧增长，采样方法更有吸引力。但不能从“蒙特卡洛速度对维度没有显式指数项”推出高维积分总是容易，因为被积函数方差、稀有事件和采样分布选择仍可能使实际成本很高。选择方法应结合平滑性、维度、覆盖与可获得的误差证据。

## 5. Hessian、交叉项与多变量局部几何

<a id="chapter-calculus-02-heading-26"></a>

### 5.1 沿一条直线把多变量问题化成一元问题

令 $`\phi(t)=f(x+th)`$。由链式法则，$`\phi'(t)=\nabla f(x+th)^Th`$，若二阶可微，则 $`\phi''(t)=h^TH_f(x+th)h`$。把一元展开应用在零到一的参数区间，即得到

```math
\begin{aligned}
&f(x+h)=f(x)+\nabla f(x)^Th\\
&\quad +\frac12h^TH_f(x)h+r_2(h).
\end{aligned}
```

在二阶连续可微条件下，$`r_2(h)=o(\Vert h\Vert ^2)`$。多变量高阶分析中，这种“先选路径再求导”的方式非常有用：它不会丢失联合变化，反而把全部交叉项自然收进二次型中。若只分别改变坐标再相加，却没有追踪中间位置，就可能遗漏变量之间的相互作用。

取 $`f(x,y)=x^2+3xy+4y^2`$，Hessian 为 $`\begin{pmatrix}2&3\\3&8\end{pmatrix}`$。二次型前的二分之一给出 $`h_1^2+3h_1h_2+4h_2^2`$。非对角元素在完整二次型中出现两次，因此不能只把上三角照抄后再统一乘二分之一。这个错误在手推二阶近似和实现二次目标时都很常见。

### 图解推导：用完整二次型追踪同向与反向扰动

![两条等长扰动只有第二分量符号不同，精确增量分别为零点零八和零点零二](images/02-same-length-steps-cross-term.webp)

[打开原图放大](images/02-same-length-steps-cross-term.webp)

图的左侧从共同起点画出两条扰动。$`h_+=(0.1,0.1)`$ 与 $`h_-=(0.1,-0.1)`$ 的长度都为 $`\sqrt{0.02}`$，两者只差第二分量的符号。对 $`f(x,y)=x^2+3xy+4y^2`$，这个翻号保留平方项，却会改变交叉项，因此不能只用长度预测目标增量。

右图逐项复算：两种扰动的坐标平方项相同，都是 $`0.1^2+4(0.1)^2=0.05`$；混合项分别为 $`0.03`$ 与 $`-0.03`$。所以精确增量分别为 $`0.08`$ 和 $`0.02`$，相差四倍。若把分别沿两个坐标移动的增加量直接相加，两次都只得到 $`0.05`$，一次低估、一次高估，不能靠统一缩放修复。

矩阵表示为 $`H=\begin{pmatrix}2&3\\3&8\end{pmatrix}`$，于是 $`\frac12h^THh=h_1^2+3h_1h_2+4h_2^2`$。两个非对角元素各贡献一次，前面的二分之一把它们合成一个交叉项。本例没有高阶余项；一般二阶连续可微函数只能局部近似，还要保留余项。

$`H`$ 的特征值为 $`5\pm3\sqrt2`$，都为正。因此负交叉贡献不等于负曲率方向，应判断完整二次型。机制可结合 OpenStax 多元二阶导数检验阅读；图中数值是独立构造的算例。

<a id="calculus-2-detail-13"></a>

### 5.2 混合偏导为什么相等，什么时候不能直接使用

若二阶偏导在邻域内连续，混合偏导可以交换，因此 Hessian 对称。一个直观证明是考察一个小矩形四个角的函数增量，以两种方向顺序应用基本定理；相应双重积分相同，缩小矩形后得到混合偏导相等。连续性确保极限能够恢复指定点的局部值。

没有相应正则条件时，混合偏导可能都存在却不相等。不能只因为某个公式被命名为 Hessian，就自动把不对称项替换成相等。另一方面，对任意实矩阵 $`A`$，二次型 $`h^TAh`$ 只依赖其对称部分，因为反对称部分贡献为零；这条代数事实也不能反过来证明原函数满足交换偏导的分析条件。

实际自动微分通常在光滑区域产生符合对称结构的二阶信息，但不可微分支、近似算子、自定义反向规则与数值误差会使观察更复杂。发现对称性偏差时，应先检查函数是否满足假设、导数实现是否对应同一目标，而不只对结果强行取平均。

<a id="calculus-2-detail-14"></a>

### 5.3 驻点判别的证明与半正定的不足

设 $`\nabla f(x_*)=0`$，Hessian 正定，最小特征值为正数 $`\mu`$。二阶项至少为 $`\frac{\mu\Vert h\Vert ^2}{2}`$，余项相对平方尺度趋零，所以在足够小邻域内，余项绝对值不超过 $`\frac{\mu\Vert h\Vert ^2}{4}`$，从而 $`f(x_*+h)-f(x_*)\ge\frac{\mu\Vert h\Vert ^2}{4}>0`$。这证明严格局部极小，而不是仅凭图像猜测。

若 Hessian 有负特征方向，在该方向足够小扰动会使函数下降；若同时有正方向，会出现通常意义的鞍点。若所有方向都负，则得到严格局部极大。Hessian 半正定时，零曲率方向上的二阶项不提供控制，可能需要更高阶或直接结构分析。

例如 $`x^2+y^4`$ 在原点 Hessian 半正定，仍是严格极小；$`x^2-y^4`$ 在原点具有同样 Hessian，却是鞍点；$`x^2`$ 也具有同样 Hessian，但沿纵向所有点函数不变，只是非严格极小。三者说明零特征值对应的是二阶信息不足，而不是某个固定的极值类型。

<a id="calculus-2-detail-15"></a>

### 5.4 牛顿方向：精确最小化局部二次模型

记当前梯度为 $`g`$、Hessian 为 $`H`$，局部二次模型是 $`m(h)=f(x)+g^Th+\frac{h^THh}{2}`$。若 $`H`$ 正定，其唯一最小点满足 $`Hh=-g`$，因此牛顿方向由一个线性系统求解。写成 $`-H^{-1}g`$ 便于公式表达，数值代码通常不需要显式形成逆矩阵。

正定时，$`g^Th=-g^TH^{-1}g\lt 0`$，非零梯度处这是下降方向；但它只最小化局部模型，完整一步是否降低真实函数仍受高阶余项影响。若 $`H`$ 不定，驻点方程给出的方向甚至可能不是下降方向。对 $`f(x)=x^3`$、当前点负一，梯度为三、Hessian 为负六，牛顿步为正二分之一，走到负二分之一后函数反而上升。

这个例子还说明求驻点与求最小值不是同一任务。牛顿法也常用于解方程，它追求导数为零，可能被极大点吸引。优化版本通常需要正定修正、阻尼、线搜索或信赖域，把目标下降与局部方程求解结合起来，而不是只机械调用求逆。

<a id="calculus-2-detail-16"></a>

### 5.5 坐标变化会改变 Hessian 表达

对线性重参数化 $`x=Az`$，复合函数的 Hessian 为 $`A^TH_xA`$，梯度为 $`A^Tg_x`$。如果变换可逆，正定与不定的惯性结构保留，但特征值数值和欧氏条件数一般改变。这解释了特征缩放为何可能改善优化几何，却没有创造新的最优点。

对非线性重参数化，还会出现由原梯度乘坐标变换二阶导数构成的额外项。因此 Hessian 不像一个完全脱离坐标的固定数字表；在驻点处原梯度为零，额外项消失，这时局部二次型的变换更简单。讨论“某个参数化下曲率很平”时，必须同时说明坐标和度量。

本章不把所有坐标敏感现象都归为坏事。计算实现总需要选择表示，好的表示能够改善数值稳定与计算效率。关键是理解哪些性质属于函数的实际极值结构，哪些数值来自表达方式，再选择合理的优化工具。

<a id="hessian-vector-products"></a>

### 5.6 只求 Hessian 的作用，而不保存整个矩阵

若参数有一百万维，完整 Hessian 有一万亿个元素，仅用四字节保存每个元素就需要约四万亿字节，尚未计算生成它的时间与额外工作区。很多二阶算法并不需要全部元素，只需要给定方向上的乘积。由梯度可微定义，梯度沿方向的变化率就是 Hessian 向量积；若对标量 $`\nabla f(x)^Tv`$ 再求梯度，则得到 $`H(x)^Tv`$，在本章的二阶连续可微条件下等于 $`H(x)v`$。

例如二次函数 $`f(x,y)=x^2+3xy+4y^2`$，取方向 $`(1,-1)`$，乘积为 $`(-1,-5)`$，方向曲率为四。这个数是沿未单位化方向参数的二阶响应；若要比较每单位距离的曲率，需除以方向长度平方，得到二。方向长度在一阶响应中按一次方出现，在二阶响应中按平方出现，因此做不同方向对比时必须分别归一。

用自动微分组合计算作用量，可以避免显式矩阵存储，但仍有前向、反向或重计算成本；对含状态和随机性的程序，还要保持同一个局部函数。使用有限差分近似梯度变化，则另有步长与浮点误差。实际二阶优化还需要根据这些作用量求解线性系统，不能把“能计算一个乘积”直接等同于“已便宜获得精确牛顿步”。

## 6. 进阶：定量余项、线搜索与随机更新

<a id="chapter-calculus-02-heading-33"></a>

### 6.1 Hessian Lipschitz 条件给出三阶误差界

假设沿线段有 $`\Vert H(x+th)-H(x)\Vert _2\le M t\Vert h\Vert _2`$。从二阶积分表达减去起点 Hessian 项，得到

```math
\begin{aligned}
&r_2(h)=\int_0^1(1-t)\\
&\qquad h^T[H(x+th)-H(x)]h\,dt.
\end{aligned}
```

于是 $`\vert r_2(h)\vert \le M\Vert h\Vert ^3\int_0^1t(1-t)dt=\frac{M\Vert h\Vert ^3}{6}`$。这个三次界不要求写出完整三阶张量，只需要 Hessian 的变化控制。在高维模型中，算子范数形式往往比逐元素三阶导数表达更清楚。

若二阶模型预测下降很小，三阶余项却可能与之相当，就没有足够证据接受完整更新。信赖域方法通过限制扰动半径控制模型可信范围，并比较实际下降与预测下降；比值很差时缩小范围，比值可靠时可以扩大。半径不是函数固定不变的属性，而是算法对当前局部模型可信度的选择。

<a id="calculus-2-detail-17"></a>

### 6.2 阻尼与正定修正分别解决什么

在 Hessian 后加正数倍单位矩阵，求解 $`(H+\lambda I)h=-g`$，可以提高最小特征值并改善求解稳定性。若修正后矩阵正定，就得到下降方向。随着修正增大，方向趋近于缩放负梯度；修正较小时，更保留牛顿曲率调整的作用。

但“加了一个很小正数”并不保证不定 Hessian 变正定，修正必须足以覆盖负特征方向。即使已经得到下降方向，完整步长仍可能过大，因而常需进一步线搜索。方向构造和步长选择是两个层次，解决其中一个不代表另一个自动完成。

某些近似二阶方法维护正定曲率模型而不计算真实 Hessian，优点是成本和数值结构可控；代价是模型误差与更新条件需要单独分析。不要把名称中含有“二阶”视为精度或速度的无条件排序，最终还要看每步成本、可用曲率和总体任务收敛。

<a id="calculus-2-detail-18"></a>

### 6.3 Armijo 回溯为什么会在下降方向上终止

给定方向 $`p`$ 满足 $`g^Tp\lt 0`$，选择常数 $`c\in(0,1)`$，要求 $`f(x+\alpha p)\le f(x)+c\alpha g^Tp`$。由可微展开，真实变化是 $`\alpha g^Tp+o(\alpha)`$，与右侧的差在足够小步长下为 $`(1-c)\alpha g^Tp+o(\alpha)\lt 0`$，因此充分小的步长必然被接受。

回溯从某个初始步长开始，每次乘以零到一之间的缩减因子，直到条件满足。终止证明依赖可微与严格下降方向，不意味着接受步长一定很大，也不保证算法整体达到全局最优。若函数值带随机波动，直接用不同批次计算两边还可能破坏这个确定性逻辑，需要专门的随机策略。

在梯度 Lipschitz 条件下，还能给出保守接受阈值：若方向为负梯度，充分条件是 $`\alpha\le\frac{2(1-c)}{L}`$。实际回溯可能接受更大步长，因为这个界只使用最坏曲率。线搜索的价值之一，就是在不知道精确全局光滑常数时利用实际函数值寻找可接受更新。

<a id="sec-6-1"></a>

### 用二次模型量化步长与回溯的不同作用

取 $`f(x)=5x^2`$、当前点一，梯度十。初始步长一会走到负九，显然大幅上升。若每次减半，依次测试一步长、二分之一、四分之一、八分之一；在常见的小充分下降常数下，八分之一已经使新点为负四分之一、损失为零点三一二五，明显低于原值五。

这里的回溯是在同一个确定函数上比较实际值，不需要事先输入最大曲率十。它仍然花费额外函数评估，若每次评估昂贵，成本不能忽略。某些大规模训练选择固定或预设学习率调度，正是不同成本约束下的取舍，并不是因为理论上的线搜索无用或永远更优。

<a id="calculus-2-detail-19"></a>

### 6.4 随机梯度中多出的方差项

假设目标梯度全局 $`L`$-Lipschitz，或所有可能更新线段都满足同一光滑界。设随机梯度 $`\widehat g`$ 条件于当前点无偏，且 $`\mathbb E[\Vert \widehat g-g\Vert ^2\mid x]\le\sigma^2`$。下降引理代入随机更新后取条件期望，得到

```math
\begin{aligned}
&\mathbb E[f(x-\eta\widehat g)\mid x]\\
&\quad \le f(x)-\eta\left(1-\frac{L\eta}{2}\right)\Vert g\Vert ^2
+\frac{L\eta^2\sigma^2}{2}.
\end{aligned}
```

无偏性让梯度交叉项恢复真实梯度平方，但噪声的平方贡献并不会消失。靠近驻点时真实梯度很小，方差项可能主导，因此单步甚至期望单步都不一定下降。增加独立批量、降低步长或采用方差控制可以改变这一平衡，但具体收益取决于相关性与额外成本。

若梯度估计有偏，还会多出与偏差有关的项；若方差无界，上述界失去前提。把确定性下降保证直接用于随机训练，通常正是忽略了这些条件。训练曲线中的抖动可能是正常抽样效应，也可能来自错误实现，需要用小规模确定性核对和重复实验区分。

<a id="calculus-2-detail-20"></a>

### 6.5 局部二次收敛需要哪些条件

在一个严格局部极小点附近，若 Hessian 连续且一致正定、其变化满足 Lipschitz 控制，精确牛顿步能够给出误差平方级收缩。记当前误差 $`e=x-x_*`$，利用梯度沿连接线段积分，可把新误差写成

```math
e_{\mathrm{new}}=H(x)^{-1}\int_0^1[H(x)-H(x_*+te)]e\,dt.
```

若逆矩阵范数不超过 $`\frac{1}{\mu}`$，得到 $`\Vert e_{\mathrm{new}}\Vert \le\frac{M\Vert e\Vert ^2}{(2\mu)}`$。这解释了牛顿法在合适邻域里为什么可能非常快：一阶误差被局部曲率模型抵消，剩余由曲率变化造成。

条件中的“附近”“精确求解”和“一致正定”都不能省略。远处可能不收敛，病态求解会产生额外误差，近似 Hessian 也可能改变速度。实际方法常先用阻尼或信赖域进入稳定邻域，再逐渐采用完整步长。理论的局部高速与工程中的全局稳健，需要通过算法设计衔接起来。

<a id="calculus-2-detail-21"></a>

### 6.6 Jensen 不等式与二阶均值偏移怎样互相补充

若函数在凸域上可微且凸，图像位于任一点切平面之上，即 $`f(y)\ge f(x)+\nabla f(x)^T(y-x)`$。把起点选为随机变量均值，再对两边取期望，在相应可积条件下得到 $`\mathbb E[f(X)]\ge f(\mathbb EX)`$。这给出非线性平均偏移的全局符号保证；二阶展开则在小噪声条件下进一步估计偏移的大小。两者各自提供不同信息，不应把一个局部近似当成另一个一般不等式的全部依据。

以平方函数为例，均值偏移精确等于方差，因此不等式差额有明确含义。以严格凸指数函数为例，只要输入不是几乎处处常数且相应期望有限，平均指数通常严格大于均值的指数；但若期望无限，数值大小比较虽可在扩展意义理解，不能继续进行普通有限误差分析。使用任何期望公式之前都要检查对象是否存在。

对非凸函数，均值偏移的符号可以随当前位置与噪声分布改变。一个函数在均值附近二阶导为正，也不能在噪声大量落到远处时保证总体偏移为正。局部曲率与全局概率质量必须结合，不能只看一张局部损失切片就解释整个随机系统的平均行为。

<a id="calculus-2-detail-22"></a>

### 6.7 如何给近似模型规定验收尺度

绝对误差、相对误差与决策误差可能给出不同判断。函数值接近零时，相对误差可以很大而绝对误差很小；函数值含有巨大无关常数时，相对函数值误差又可能掩盖对下降量预测的严重错误。优化中通常更应比较模型对增量或实际下降的预测，而不只是比较两个带常数背景的函数总值。

例如目标加上一百万，梯度、Hessian、最优点和算法轨迹都不变；若用相对总函数值误差验收，一个原本很差的局部模型却会看起来突然很好。这说明验收指标也应尊重问题的不变性。近似绝对精度可以根据任务容忍度设定，下降预测则应与当前能获得的改进量比较，而不是挑选最容易通过的分母。

实验还应保存失败区域。若二次模型只在小半径有效，就明确写出这个边界；若某些方向明显更差，应检查是否存在高曲率方向或交叉项遗漏。把所有方向平均成一个数字可能掩盖最坏情况。对于需要可靠约束的任务，均值表现与统一上界承担不同角色，不能互相代替。

<a id="taylor-probability-constraints"></a>

### 6.8 局部近似还需要尊重输出约束

泰勒多项式近似函数值，却不自动保留原函数的全部结构。一个始终为正的指数函数，线性近似在足够远的负方向可能变成负数；一个位于零到一之间的概率函数，其局部多项式可能跑出概率区间。因此不能因为近似公式来自正确求导，就把任意半径下的结果直接当成合法概率、密度或方差。

比如在零点用一阶式近似指数，得到一加输入；输入取负二时近似为负一，真实值仍为正。这里不是求导错误，而是局部模型被用到了没有误差控制的范围。若再将负近似值取对数、用于概率采样或作为方差，后续计算甚至失去定义。合理做法是限制可信范围、保留适合的参数化，或选择具有所需结构的近似方式，并明确由此改变了什么误差。

把结果裁剪回合法区间可以避免部分程序错误，却不证明得到的是原函数的高精度近似；裁剪还会引入新的非光滑点和偏差。若近似进入一个优化目标，必须重新判断训练时实际使用的是原函数、多项式还是裁剪后的复合函数。数值稳定、约束合法和统计目标一致是三项不同要求，不能由一个裁剪步骤同时保证。

## 7. 泰勒余项与小噪声近似的计算实验

<a id="calculus-2-detail-26"></a>

### 7.1 实验一：比较泰勒实际误差与可证明上界

下面选择指数函数，在若干步长比较一阶和二阶预测。程序使用解析三阶导数上界计算二阶误差证书；真实误差仅用于验证证书，不能在未知真值的问题中反过来充当事前保证。

```python
import math

for h in [0.2, 0.1, 0.05, 0.025]:
    true_value = math.exp(h)
    first = 1 + h
    second = first + h * h / 2
    first_error = abs(true_value - first)
    second_error = abs(true_value - second)
    bound = math.exp(h) * abs(h) ** 3 / 6
    assert second_error <= bound + 1e-15
    print(h, first_error, second_error, bound)
```

步长减半时，一阶误差渐近约缩为四分之一，二阶误差约缩为八分之一。这里的规律依赖函数在该区域足够光滑且高阶系数不退化；若某阶系数恰好为零，观察到的误差阶可能更高。若继续把步长减到极小，浮点消去会干扰比例，不应为了追求图形整齐而删掉不符合渐近直线的数值。

可以将函数改为对数，在靠近奇异边界与远离边界的位置分别测试。预测应先根据邻域导数界写出，再运行。如果发现同样步长在两个位置表现差异很大，解释应落在导数尺度与边界距离上，而不是只说“这个函数更难”。

<a id="calculus-2-detail-27"></a>

### 7.2 实验二：完整检验小噪声均值近似

为避免蒙特卡洛抽样噪声掩盖近似误差，下面先使用零均值高斯下已知的精确指数均值，与二阶近似比较，再用独立采样检查均值与标准误差量级。固定种子保证演示可复现，不代表某一次随机误差必须小于一个标准差。

```python
import numpy as np

rng = np.random.default_rng(19)
for sigma in [0.1, 0.3, 0.6]:
    noise = rng.normal(0.0, sigma, size=200_000)
    values = np.exp(noise)
    exact = np.exp(sigma * sigma / 2)
    second_order = 1 + sigma * sigma / 2
    estimate = values.mean()
    standard_error = values.std(ddof=1) / np.sqrt(values.size)
    print(sigma, exact, second_order, estimate, standard_error)
```

抽样均值与精确值的差，属于随机估计误差；二阶近似与精确值的差，属于确定的近似偏差。两者可以同方向或反方向，某次抽样刚好接近近似值不意味着理论偏差消失。增加样本会压低随机误差，却不会改变固定噪声规模下的二阶截断偏差，这个区分对实验解释非常重要。

进一步可改用具有相同方差的双点噪声，与高斯噪声比较。平方函数输出均值仍相同，但指数输出均值一般不同，差异来自更高阶分布信息。不要用一个高斯实验的拟合结果证明“只有方差影响非线性期望”，因为那是在未经检验时省略了分布假设。
