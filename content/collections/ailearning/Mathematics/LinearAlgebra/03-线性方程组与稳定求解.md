## 1. 在计算之前确定问题与尺度

<a id="three-questions"></a>

### 1.1 存在、唯一、稳定是三道不同问题

对于方阵系统 $`Ax=b`$，可逆保证任意右端有唯一解；奇异时则需比较右端与列空间，区分无解与多解。非方系统通常要额外定义最小二乘、最小范数或其他选择准则。不能只根据某个接口报错或返回值长度，倒推自己解决了哪一种数学问题。

稳定性进一步问输入发生小变化，所选输出会改变多少。一个系统可以始终可逆且唯一，却在某些方向极度敏感；一个有多组系数的最小二乘问题也可能拥有稳定的唯一预测。存在性与数值可靠性没有相互替代关系，必须依次检查。

误差还可能来自不同来源：观测本身有噪声，数据存成浮点数发生舍入，算法运算再引入舍入，提前停止带来迭代误差。求解器最多控制其中一部分，不知道现实输入的真实值。把计算残差压到很小，不能自动恢复测量中已丢失的信息。

<a id="sec-1-1"></a>

### 基础算例：从增广矩阵区分无解、多解与唯一

两条方程 $`x+y=2`$ 与 $`2x+2y=4`$ 相减只剩恒等式，全部解为 $`(2-t,t)`$。将第二右端改成五，消元出现零等于一，原系统无解；将第二方程改成 $`x-y=0`$，则唯一解为 $`(1,1)`$。重复约束不提供新的独立信息，矛盾约束也不会因使用更高精度求解就变得相容。

若对无解情形改求最小二乘，已经换了目标，需要说明误差权重。若对多解情形选最小范数，也加入了选择准则。结果可能很有用，但不能把新定义的最优代表叫作原来已唯一确定的真实参数。前章空间几何负责解释这些对象，本章在此基础上讨论计算误差。

<a id="scaling-units"></a>

### 1.2 单位改变会影响条件与误差解释

把未知量从米改成毫米，数值坐标扩大一千倍；把某个方程左右同时乘常数，精确可解集合保持不变。可是普通欧氏范数下的矩阵尺度、条件数和相对误差分量会改变。一个没有单位与范数说明的“大误差”或“小残差”，往往没有完整含义。

行缩放对不相容最小二乘尤其重要，它改变了各行残差的相对权重。若目的只是改善数值尺度而保持原加权目标，应同时变换误差度量，或采用与目标一致的算法设计。不能只说方程等价，就把任意缩放当作最小二乘目标完全不变。

列缩放相当于参数重表示，求解后需映回原单位。若加入单位矩阵正则或最小欧氏范数选择，缩放还可能改变偏好。报告应区分被动单位转换、主动改变目标权重和数值预条件，否则一次看似有效的改善可能同时换了统计问题。

## 2. 直接方法：消元、主元与结构分解

<a id="elimination-lu"></a>

### 2.1 消元怎样变成可复用的 LU 分解

高斯消元通过把某行的倍数从后续行减去，逐列消除主元下方元素。以方程 $`x+y=3`$、$`2x+3y=8`$ 为例，第二行减两倍第一行得到 $`y=2`$，回代得 $`x=1`$。这些操作在精确算术中保留解集合，记录消元倍数便得到下三角因子。

若不需要换行，可写 $`A=LU`$，其中下三角通常约定对角为一，上三角保存消元后系统。解方程分成先解 $`Lz=b`$ 再解 $`Ux=z`$。分解通常比一次三角回代昂贵得多，所以矩阵固定、右端很多时，应复用分解，而不是每次重新计算完整逆。

零主元并不总代表矩阵奇异，例如交换矩阵第一对角为零却可逆，需要换行继续。实际算法常用置换记录行交换，约定为 $`PA=LU`$，于是右端也必须先变成 $`Pb`$。不同库可能使用转置或不同置换约定，不能只复制某个字母顺序而不检查重构关系。

<a id="pivoting-example"></a>

### 2.2 小主元为什么危险：一个两行例子

考虑 $`A=\begin{pmatrix}\epsilon&1\\1&1\end{pmatrix}`$，其中正数 $`\epsilon`$ 很小。不换行时，第一消元倍数为 $`\frac{1}{\epsilon}`$，后续元素由大数相减得到，浮点误差容易放大。交换两行后，首主元为一，消元倍数为 $`\epsilon`$，避免这次人为制造的大中间量。

部分选主元每步在当前列剩余行中选择绝对值最大的主元，使该列消元倍数不超过一。它通常显著提高实用可靠性，但并不是对所有矩阵都给出与维数无关的小误差常数：后续上三角元素仍可能增长。讨论 LU 稳定性时，还要看增长因子与输入结构，不能把“有主元”当作一切问题已解决。

交换列也可以改变主元选择，但未知量顺序随之改变，求解后要恢复。完全选主元、秩揭示分解与稀疏排列还会有不同成本。数值稳健、稀疏填充和计算效率之间需要权衡，不能只按一个局部主元数值评价整个算法。

<a id="deep-dive-2"></a>

### 2.3 小主元与病态不是同一个诊断

前面的系统在 $`\epsilon`$ 接近零时仍可能条件良好，因为极限矩阵行分别为零、一和一、一，行列式不为零。未经主元的算法可以表现很差，原因是计算路径制造大中间量，而不是原问题本来无法准确求解。这是算法不稳定与问题敏感的区别。

反过来，对角矩阵一与百万分之一没有复杂消元，求解过程很简单，但第二方向输入误差仍会放大一百万倍。一个后向稳定的算法也无法消除这种数据敏感性。要判断错误来自哪里，应同时构造已知真解、检查残差与输入扰动，而不只看某个中间主元。

行列式也不是尺度无关的病态指标。将单位矩阵整体乘极小常数，行列式可以极小，二范数条件数仍为一；反过来某些矩阵行列式并不小，却可能有一大一小奇异值。条件分析应使用相对尺度与方向放大，而非一个裸行列式阈值。

<a id="cholesky-structure"></a>

### 2.4 Cholesky 为什么需要正定条件

实对称正定矩阵可写为 $`A=LL^T`$，其中下三角对角取正。分块看，第一步取主元平方根，再从剩余块中减去相应外积；正定性保证产生的 Schur 补仍正定，因此递归可以继续。这个结构既给出存在性，也说明为什么不必像一般 LU 那样选择符号不定主元。

对称但不定矩阵不能直接要求实正对角 Cholesky，例如对角一与负一。半正定矩阵则可能产生零主元，需要秩处理或其他分解。输入本应正定但数值算法失败时，应检查矩阵是否真的对称、是否因舍入或建模失去正定，以及是否接近奇异，而不是盲目给对角线加一个小数后称原问题已精确解决。

加对角阻尼可以定义更好条件的系统，但一般改变原方程解。若阻尼来自明确正则目标，应报告新目标；若仅作近似，应分析偏差。提高求解可靠性与改变估计问题可以同时有价值，但二者不能混为一个无代价修复。

<a id="sec-2-1"></a>

### 机制展开：QR 避免的是额外平方，不是原问题条件

满列秩最小二乘可用 $`X=QR`$，先计算 $`Q^Ty`$ 再回代 $`Rw=Q^Ty`$。正交作用不放大二范数，$`R`$ 与原设计有相同非零奇异值；正规矩阵 $`X^TX`$ 的特征值却是奇异值平方，因此 $`\kappa_2(X^TX)=\kappa_2(X)^2`$。

这个等式表明形成 Gram 矩阵可能更早丢失小方向的相对信息。QR 避免该步，SVD 还能显示各奇异尺度，但两者都没有使近相关特征突然可辨识。即使算法后向稳定，原问题的参数误差仍可能因敏感性很大而明显。

最小二乘敏感度还与残差和目标夹角有关，不能把所有情况简单等同于方阵求解的一个条件数公式。本章后面会给精确线性化，说明当目标远离列空间时，设计扰动如何产生更强影响。方法选择要依据真正被求解的问题，而非仅按矩阵是否方形分类。

## 3. 条件、残差与误差的定量关系

<a id="residual-forward-error"></a>

### 3.1 先从一个精确恒等式开始

设可逆系统真实解为 $`x`$，计算结果为 $`\widehat x`$，残差定义为 $`r=b-A\widehat x`$。相减立刻得到 $`x-\widehat x=A^{-1}r`$，所以绝对前向误差至多为 $`\Vert A^{-1}\Vert\;\cdot\;\Vert r\Vert `$。残差小只有结合逆算子尺度，才能推断解误差小。

如果右端非零，利用 $`\Vert b\Vert \le\Vert A\Vert\;\cdot\;\Vert x\Vert `$ 可得

$$
\begin{aligned}
\frac{\Vert x-\widehat x\Vert }{\Vert x\Vert } &\le\kappa(A)\frac{\Vert r\Vert }{\Vert b\Vert },\\[6pt]
\kappa(A) &=\Vert A\Vert\;\cdot\;\Vert A^{-1}\Vert .
\end{aligned}
$$

相对量在零右端或零真解处需要改用绝对标准，不能除以零。范数也必须一致选择，不能用矩阵一种范数、向量另一种未经说明的范数拼出相同常数。二范数条件数等于最大与最小奇异值之比，描述最坏方向的相对放大。

这个上界未必达到。残差若避开最敏感左奇异方向，实际误差会小得多；最坏条件数控制所有方向，不是对每次运行误差的精确预测。若任务只关心某个线性输出，也可以对目标相关误差进行更细分析，而不一定需要所有参数一样精确。

<a id="perturbation-theorem"></a>

### 3.2 矩阵与右端同时扰动的完整界

设扰动系统为 $`(A+E)(x+e)=b+f`$，原系统为 $`Ax=b`$。相减得到 $`(A+E)e=f-Ex`$。若 $`\Vert A^{-1}E\Vert <1`$，则 $`I+A^{-1}E`$ 可用 Neumann 级数求逆，因而扰动系统仍可逆，并有

$$
\Vert e\Vert \le\frac{\Vert A^{-1}\Vert }{1-\Vert A^{-1}E\Vert }
\bigl(\Vert f\Vert +\Vert E\Vert\;\cdot\;\Vert x\Vert \bigr).
$$

当 $`b\ne0`$、$`x\ne0`$，令相对矩阵扰动为 $`\epsilon_A=\frac{\Vert E\Vert }{\Vert A\Vert }`$、相对右端扰动为 $`\epsilon_b=\frac{\Vert f\Vert }{\Vert b\Vert }`$，并使用更保守条件 $`\kappa(A)\epsilon_A<1`$，得到

$$
\frac{\Vert e\Vert }{\Vert x\Vert }
\le\frac{\kappa(A)}{1-\kappa(A)\epsilon_A}
(\epsilon_A+\epsilon_b).
$$

分母不是装饰。若矩阵扰动足以接近奇异，不能继续只写一阶的条件数乘误差并当作任意有限扰动保证。小扰动时分母接近一，才恢复常说的一阶尺度。

Neumann 证明也清楚说明条件只是充分而非必要。有些较大范数扰动仍保持可逆，只是上述统一界不给保证。反过来，若只知道一个很小平均元素误差，却没有与相应矩阵范数联系，也不能直接将其填入相对扰动参数。

<a id="directional-condition-example"></a>

### 3.3 同样大小的输入误差，可以得到不同解变化

取 $`A=\operatorname{diag}(1,10^{-6})`$、真实解 $`(1,1)^T`$，右端为 $`(1,10^{-6})^T`$。若右端第一分量增加百万分之一，解第一分量只增加百万分之一；若相同扰动加到第二分量，解第二分量增加一。扰动长度相同，方向不同，输出响应差一百万倍。

如果取近似解 $`(1,0)^T`$，其残差长度只有百万分之一，但解误差长度为一。残差不能单独充当准确性证书。对同一个矩阵，也可以选一个几乎没有敏感方向成分的右端，此时某些相对误差表现较好；不能从单个容易右端实验否认最坏条件数的意义。

现实输入本身若只有六位左右相对精度，最坏条件达到一百万的系统就可能无法提供有用参数位数。换成更精确求解器可以减少计算误差，却不能识别已进入输入的观测噪声。应考虑额外信息、合理正则或任务相关预测，而不是无限增加迭代追求无法由数据支持的精度。

## 4. 非方系统、数值秩与选解原则

<a id="least-squares-perturbation"></a>

### 4.1 最小二乘敏感度为何还包含残差

设设计 $`X`$ 满列秩，最小二乘残差为 $`r=y-Xw`$，满足 $`X^Tr=0`$。设计变化为 $`E`$、目标变化为 $`f`$，对这个最优性方程一阶线性化，得到

$$
X^TX\,dw=X^T(f-Ew)+E^Tr.
$$

前一项类似方程求解的右端变化，后一项来自设计变化使原残差不再与新列空间正交。若原问题完全可拟合，这一项为零；若残差很大，设计微扰可能造成额外参数响应。因此一般最小二乘敏感度不能只看设计条件数，再无条件照搬可逆方阵右端扰动界。

使用伪逆可把第一项写为 $`X^+(f-Ew)`$，第二项仍含正规矩阵逆。这个表达是分析关系，不是建议实际先形成 Gram 求解。若设计接近秩亏，两部分都可能大；若目标几乎正交于可达空间，参数相对误差还可能因为原系数很小而难解释，需要改用绝对或预测标准。

这一推导要求局部保持满列秩并忽略高阶项。秩发生变化时，伪逆映射可能不连续，不能把固定秩导数穿过奇异点。要处理那种变化，应明确截断或正则所定义的新问题，而不是期待一个光滑公式覆盖所有秩。

<a id="numerical-rank"></a>

### 4.2 数值秩是带尺度与精度的判断

精确秩只问奇异值是否为零；数值秩则问某个方向在当前精度与噪声水平下是否足以辨认。常见规则将奇异值与最大奇异值、维度和浮点精度共同构成的阈值比较。它是一种计算约定，不是关于现实数据真实维数的无条件证明。

例如矩阵对角为一与十万亿分之一，在双精度纯数学输入下仍可能具有可分辨的小方向；若输入测量本身有百万分之一误差，小方向就缺乏可信信息。仅知道存储格式是双精度，不能忽略更大的观测误差。数值有效秩与统计信号秩应分别解释。

报告阈值时最好使用相对尺度，并记录采用的范数与数据预处理。如果把矩阵整体乘常数，合理的相对判据应保持相同秩；若只改某列单位，问题几何本来就可能改变，需要同步解释。某个库返回的秩整数，没有这些背景就不足以支撑特征选择结论。

<a id="truncated-solve"></a>

### 4.3 截断伪逆与正则解在求另一个对象

伪逆对非零奇异值取倒数，截断版本只保留高于阈值的方向。这样可以降低小尺度噪声放大，但也主动丢掉可能存在的信号。它返回的是截断模型下的最小范数代表，通常不再是原始精确最小二乘的同一个参数。

岭回归连续衰减奇异方向，也改变目标。两种方法都可以改善统计稳定性或处理有限输入精度，却不能仅凭参数更平稳就说原问题计算更准确。应分别比较原目标数值误差、改变目标后的残差、独立预测风险与选择代价。

对欠定系统，欧氏最小范数也只是一种准则。稀疏、非负、守恒或物理边界会定义不同可接受解。若两个算法使用不同约束，残差相同而参数不同不一定表示其中一个求解器错误。首先确认它们是否在求同一数学对象，再讨论计算可靠性。

<a id="minimum-norm-scaling"></a>

### 4.4 坐标缩放会改变最小范数代表

对约束 $`x_1+x_2=2`$，欧氏最小范数为 $`(1,1)`$。若把第二参数重新表示为 $`x_2=2z_2`$，并在新坐标最小化 $`z_1^2+z_2^2`$，约束为 $`z_1+2z_2=2`$，新代表为 $`(\frac{2}{5},\frac{4}{5})`$，映回原参数得到 $`(\frac{2}{5},\frac{8}{5})`$。它仍满足原方程，但不是原欧氏最小范数。

这不是数值不稳定，而是准则变化。若希望只是换单位而保持同一个几何偏好，必须相应变换参数度量。预条件算法同样要区分改变迭代坐标与改变最终选解规则，尤其在欠定和秩亏系统中，收敛到哪个解本身就是问题的一部分。

<a id="sec-5"></a>

## 5. 迭代方法：收敛对象、结构条件与停止

<a id="stationary-iterations"></a>

### 5.1 固定点拆分与谱半径条件

设 $`A=M-N`$，其中 $`M`$ 易于求解，迭代为 $`Mx_{k+1}=Nx_k+b`$。误差满足 $`e_{k+1}=Be_k`$，$`B=M^{-1}N`$。对所有初始误差收敛的充要条件是谱半径 $`\rho(B)<1`$，因为这等价于矩阵幂趋零；可用 Jordan 块的几何衰减乘有限多项式证明。

更方便但更强的充分条件是某个一致矩阵范数满足 $`\Vert B\Vert <1`$，此时误差范数逐步收缩。谱半径小于一不保证默认二范数每一步都下降，非正规矩阵可能先暂时放大再最终衰减。若要给有限步误差证书，需要相应范数或幂上界，而不是只报告特征值模。

Jacobi 令 $`M`$ 为对角部分，所有坐标用上一步旧值；Gauss–Seidel 将下三角也放入 $`M`$，本步已更新的坐标立即使用。它们的迭代矩阵不同，不能因名字都像逐坐标更新就认为收敛条件与并行结构相同。并行化代价也不只由迭代次数决定。

<a id="jacobi-example"></a>

### 5.2 对角占优例子与一个明确失败情形

取 $`A=\begin{pmatrix}4&1\\1&3\end{pmatrix}`$、$`b=(1,2)^T`$，精确解为 $`(\frac{1}{11},\frac{7}{11})^T`$。Jacobi 递推为 $`x_1^{k+1}=\frac{(1-x_2^k)}{4}`$、$`x_2^{k+1}=\frac{(2-x_1^k)}{3}`$，迭代矩阵无穷范数为三分之一，故有直接收缩保证。

Gauss–Seidel 在第二式使用新的第一坐标，误差第二分量每轮乘十二分之一。它在此例较快，但不是所有系统或并行环境中都优于 Jacobi。矩阵换成 $`\begin{pmatrix}1&2\\2&1\end{pmatrix}`$ 时，Jacobi 迭代矩阵特征值为正负二，普通迭代发散，尽管原方阵可逆。

严格行对角占优给 Jacobi 的无穷范数收缩提供简单充分条件。没有占优不等于必然失败，因为条件只充分；可逆也不意味着任何拆分都收敛。一个求解迭代的可靠性需要对它自己的误差传播矩阵分析，不能从原系统唯一性直接推出。

<a id="spd-energy"></a>

### 5.3 正定系统等价于严格凸二次最小化

对实对称正定 $`A`$，定义 $`q(x)=\frac{x^TAx}{2}-b^Tx`$，梯度为 $`Ax-b`$，唯一最优满足线性系统。若真解为 $`x_*`$，目标差恰为 $`\frac{\Vert x-x_*\Vert _A^2}{2}`$，其中能量范数平方为 $`e^TAe`$。这为迭代方法提供与系统结构一致的误差指标。

沿负梯度也就是残差 $`r=b-Ax`$ 做精确线搜索，步长为 $`\frac{r^Tr}{(r^TAr)}`$，分母由正定性严格为正。这个步长最小化当前直线上的二次目标，却不记住之前方向，所以可能在狭长几何中来回调整。预条件与共轭方向方法希望减少这种重复工作。

若矩阵不对称或不定，二次最小化解释要改变。对于不对称矩阵，梯度只看到对称部分，不能直接把 $`Ax-b`$ 当作该二次式梯度；对于不定矩阵，驻点未必是极小。选择方法前必须确认结构，不能把任何线性系统都塞进正定优化逻辑。

<a id="conjugate-gradient"></a>

### 5.4 共轭梯度的方向为什么比普通梯度多记住信息

共轭梯度用于对称正定系统。它构造方向满足不同方向的 $`A`$ 内积为零，即共轭。沿一个方向最小化后，再沿共轭方向移动不会破坏先前方向上的最优性，因为目标二次交叉项恰好消失。若获得完整独立共轭方向，精确算术中至多维数步便可到达唯一最优。

标准递推从 $`r_0=b-Ax_0`$、$`p_0=r_0`$ 开始，设置

$$
\begin{aligned}
\alpha_k &=\frac{r_k^Tr_k}{p_k^TAp_k},\\[6pt]
x_{k+1} &=x_k+\alpha_kp_k,\\[6pt]
r_{k+1} &=r_k-\alpha_kAp_k,
\end{aligned}
$$

再令 $`\beta_k=\frac{(r_{k+1}^Tr_{k+1})}{(r_k^Tr_k)}`$、$`p_{k+1}=r_{k+1}+\beta_kp_k`$。分母为零时若残差已零应停止，不能继续除；正定性保证非零搜索方向的曲率为正。递推的短记忆形式依赖精确二次结构与正交关系，不是任意非线性优化器都能沿用的恒等式。

它在逐步扩大的 Krylov 空间中最小化能量误差，残差与当前搜索空间正交。具体递推可通过把新残差对旧方向的影响消去推导；下一小节将用二维数字检查所有量。有限精度中共轭性会逐渐受损，所以维数步终止是精确算术结论，不是大规模代码的绝对承诺。

<a id="cg-numerical-example"></a>

### 5.5 两步完整手算与不定矩阵反例

继续使用四、一、一、三的正定矩阵，零初始化时残差与方向都是 $`(1,2)`$，矩阵乘积为 $`(6,7)`$。第一步长度为 $`\frac{5}{20}=\frac{1}{4}`$，得到 $`(\frac{1}{4},\frac{1}{2})`$，新残差为 $`(-\frac{1}{2},\frac{1}{4})`$。新残差平方为 $`\frac{1}{4}+\frac{1}{16}=\frac{5}{16}`$，与旧残差平方五相比明显减小。

因此方向更新系数为十六分之一，新方向为 $`(-\frac{7}{16},\frac{3}{8})`$，矩阵乘积为 $`(-\frac{11}{8},\frac{11}{16})`$。方向曲率为五十五除以六十四，第二步长度为四除以十一。代回得到精确解 $`(\frac{1}{11},\frac{7}{11})`$，残差为零。这个例子检查步长、残差与共轭更新，不依赖反复调用直接求解器。

若矩阵改为对角一与负一，并取右端为 $`(1,1)`$，初始方向的曲率为零，公式第一步就无法继续。原系统仍可逆，但不满足正定条件。需要适合不定或一般系统的其他方法，不能通过给分母随意加常数就宣称仍在运行同一个有保证的共轭梯度算法。

<a id="preconditioning"></a>

### 5.6 预条件是改变求解几何，不是消除信息不足

选取易于求解的正定近似 $`M`$，对称正定问题可变换为 $`M^{-\frac{1}{2}}AM^{-\frac{1}{2}}z=M^{-\frac{1}{2}}b`$，再映回 $`x=M^{-\frac{1}{2}}z`$。若变换后特征尺度更集中，迭代可能更快。实际实现通常只解与 $`M`$ 有关的系统，不显式构造平方根或逆矩阵。

随意左乘 $`M^{-1}A`$ 在普通欧氏内积下可能不对称，因此直接把它交给标准共轭梯度需要谨慎。预条件版本使用与对称变换等价的递推和内积，不能只把矩阵替换一下而忽略算法结构。对于一般非对称系统，也有其他预条件 Krylov 方法，适用逻辑不同。

预条件应计入构造时间、存储、每步应用与复用次数。一个非常强但构造昂贵的预条件，对单次小问题未必划算；多个右端反复使用时又可能有利。它改善数值求解路径，却无法恢复输入噪声中没有的信息；对原问题准确性仍需回到原残差与任务尺度验收。

## 6. 后向稳定、分量误差与可计算验收

<a id="floating-point-model"></a>

### 6.1 舍入模型能解释什么，不能解释什么

在没有上溢、严重下溢等异常的常用浮点模型中，单次基本运算的结果可表示为精确结果乘以 $`1+\delta`$，其中相对舍入误差绝对值不超过单位舍入量 $`u`$。双精度舍入到最近数时，常用单位舍入量为 $`2^{-53}`$；它与一附近下一个浮点数间距 $`2^{-52}`$ 的约定相差一倍，引用数值时应分清。

多次运算的误差会沿计算路径累积。常用 $`\gamma_k=\frac{ku}{(1-ku)}`$ 表示当 $`ku<1`$ 时若干相对因子的保守组合上界。点积误差可被这类量乘以绝对乘积和控制，但相消严重时，精确点积本身很小，相对结果误差仍可能很大。小的逐步舍入不意味着最终相对误差必小。

例如先计算一个很大数加一，再减回那个大数，精确结果为一；若中间加一小于当地浮点间距，它可能先被舍掉，最后得到零。问题不在最后减法突然产生任意巨大舍入，而是中间数表示误差被相消暴露。选择计算表达、缩放与精度都可能影响结果。

标准模型也不覆盖所有程序行为。整数溢出、非法平方根、非有限输入、错误数据布局或未经说明的低精度累加，不应被笼统称为正常浮点误差。先检查目标与实现语义，再用数值误差理论解释微小偏差，才能避免拿理论为明显错误开脱。

<a id="backward-error-definition"></a>

### 6.2 后向误差把计算结果当作附近问题的精确解

计算结果 $`\widehat x`$ 的后向误差，问需要把输入改动多少，它才成为精确解。对方程系统，写成 $`(A+E)\widehat x=b+f`$。这与前向误差比较 $`\widehat x`$ 和原始真解不同；前向结论还要通过原问题条件把输入扰动传播到解。

范数型相对后向误差可以定义为最小的 $`\eta`$，使 $`\Vert E\Vert _2\le\eta\Vert A\Vert _2`$、$`\Vert f\Vert _2\le\eta\Vert b\Vert _2`$ 且扰动方程成立。对非退化分母，它恰好等于

$$
\eta=\frac{\Vert b-A\widehat x\Vert _2}
{\Vert A\Vert _2\;\cdot\;\Vert \widehat x\Vert _2+\Vert b\Vert _2}.
$$

下界来自 $`r=E\widehat x-f`$ 的三角不等式。为了证明可达，令残差方向为 $`u_r=\frac{r}{\Vert r\Vert }`$，选择秩一矩阵 $`E=\frac{\eta\Vert A\Vert u_r\widehat x^T}{\Vert \widehat x\Vert }`$，并取 $`f=-\eta\Vert b\Vert u_r`$，两项共同恰好形成残差。零残差直接取零扰动，零计算解等边界可单独处理，不必除零。

这个公式是一个明确扰动模型下的最小值，不是所有后向误差概念都相同。如果规定只能扰动右端、矩阵必须保持对称、稀疏结构必须不变，允许集合改变，最小后向误差也可能不同。算法与现实输入的误差结构对应，证书才有实用解释。

<a id="componentwise-backward-error"></a>

### 6.3 分量尺度可能比整体范数更重要

若矩阵各行单位相差巨大，整体范数残差可能由大行支配，掩盖小行的相对失败。一个常用分量型尺度是逐行比较残差与 $`\vert A\vert \vert \widehat x\vert +\vert b\vert `$，取各行比值最大。绝对值与乘法在这里按元素与普通矩阵向量运算解释，分母为零的行需要单独约定。

在允许逐元素扰动 $`\vert E\vert \le\eta\vert A\vert `$、$`\vert f\vert \le\eta\vert b\vert `$ 的模型下，这个最大比值给出对应最小后向误差。必要性来自逐行三角不等式；可达性可按每行残差符号分配矩阵与右端扰动，使允许绝对量沿同一方向累加。原来为零的元素在这个模型中不能任意变非零，这比整体范数扰动更贴近某些结构化输入。

范数型后向误差小与分量型后向误差小不是同一件事。若一个极小行被完全忽略，总残差仍可能很小，分量比例却接近一。选择哪种模型应由输入尺度与任务决定，而不是选最容易通过的指标。对于带物理单位、稀疏结构或概率约束的系统，还可能需要更专门的结构后向分析。

<a id="backward-stability-algorithm"></a>

### 6.4 后向稳定算法仍可能给出不准确参数

算法后向稳定，通常意味着在相应条件和舍入模型下，输出精确解决的附近输入扰动与单位舍入量同阶，常数可能依赖维度、增长因子和结构。它不是说每个残差都严格等于机器精度，更不是说面对任意病态数据都能恢复很多真实参数位数。

将后向误差代入前面的有限扰动界，只要条件数乘扰动仍小于一，才能得到相对前向误差控制。若乘积接近或超过一，后向稳定依然可能成立，但前向保证无信息。此时应提高输入或计算精度、改变目标、引入先验，或只评价可可靠识别的输出，而不是责怪求解器没有消除数学敏感度。

LU 的误差受消元因子与上三角增长影响，QR 利用正交作用通常有良好后向性质，SVD 还有各方向尺度信息。具体常数与实现依赖条件，应以相应算法分析为准。不存在一个只由方法名称决定、与矩阵和实现完全无关的可靠性排序。

<a id="sec-6-1"></a>

### 为什么小残差不能替代解的误差分析

对角系统的小方向例子可以同时展示两个层次：近似解遗漏第二坐标时，残差很小，某种相对后向尺度也可以很小，但原解误差却为一。它精确满足了一个把极小右端分量改掉的附近系统。对于整体尺度，这个输入变化很小；对于第二观测本身，它又可能是百分之百相对变化。

因此报告应同时列出原始残差、相对后向尺度、条件估计、输入精度与任务输出。一个指标无法覆盖全部意义。若真实目标只依赖第一坐标，参数第二方向的不确定可能无碍任务；若它用于一个安全阈值决策，就可能非常重要，需要额外约束或信息。

条件数本身通常也要估计。显式形成完整逆再求范数可能昂贵且不必要，实用工具会利用分解与反复求解估计敏感度。估计不是精确证明，报告应说明是二范数精确奇异值比、其他范数估计，还是某种经验扰动观察，不能把这些对象统一叫作同一个精确数字。

<a id="iterative-refinement"></a>

### 6.5 迭代改进怎样利用已有分解

给定近似解，先较准确计算残差 $`r=b-A\widehat x`$，再用已有分解近似求解修正方程 $`Ad=r`$，更新 $`\widehat x+d`$。如果修正能够较准确反映当前误差，前向误差就会减小。复用分解使每轮成本通常小于重新分解，较高精度残差可以避免小差值完全被原精度掩盖。

一个简单模型是修正求解等价于 $`(A+E)d=r`$，而残差精确。设当前误差为 $`e=x-\widehat x`$，有 $`r=Ae`$，更新后误差为 $`(A+E)^{-1}Ee`$。若这个传播矩阵范数小于一，改进收敛；若低精度分解与病态性使它不收缩，就没有该保证。

实际还存在残差舍入、更新舍入与可能的混合精度误差，因此上述模型只是解释机制，不是任意系统都可无限提升精度的承诺。迭代改进不能恢复输入测量中不存在的信息，也不应把正则化改变的解重新拉回一个不合适的原目标。

<a id="stopping-criteria"></a>

### 6.6 停止准则应对应目标误差，而非只看迭代数

固定运行一百步容易复现，但不同条件数和预条件下精度可能完全不同。残差容差更有对象意义，却仍需结合尺度；常用绝对与相对阈值共同控制，避免右端接近零时相对标准失效。若需要前向误差保证，还要加入条件估计或能量范数证书。

在对称正定系统中，误差能量为 $`r^TA^{-1}r`$，它可以由最小特征值下界给出保守控制。对于一般系统，某个输出函数的伴随解也能估计残差对目标的影响。求解精度应服务下游任务，不一定要求所有参数达到同样位数。

迭代递推中的残差与重新计算 $`b-Ax_k`$ 可能因舍入逐渐分离，长期运行应适当复算真实残差。停止报告最好保留方法、预条件、容差、最大步数、是否达到容差与最终原系统残差。达到步数上限但未达标准，应如实记为未满足精度，而不是只打印最后数组就当成功。

### 7.1 同时观察残差、前向误差与方向放大

第一段程序使用精确结构明确的对角系统。它既检查正常直接求解，也构造一个遗漏小尺度坐标的候选，展示残差小而解误差明显。随后对两个方向施加同样长度的右端扰动，比较真实响应。这里的差异来自数学条件，不是为了让某种算法显得更差。

```python
import numpy as np

A = np.diag([1.0, 1e-6])
truth = np.array([1.0, 1.0])
b = A @ truth
solution = np.linalg.solve(A, b)
np.testing.assert_allclose(solution, truth, atol=1e-12)
candidate = np.array([1.0, 0.0])
r = b - A @ candidate
eta = np.linalg.norm(r) / (
    np.linalg.norm(A, 2) * np.linalg.norm(candidate) + np.linalg.norm(b)
)
relative_forward = np.linalg.norm(candidate - truth) / np.linalg.norm(truth)
relative_residual = np.linalg.norm(r) / np.linalg.norm(b)
condition = np.linalg.cond(A, 2)
assert relative_forward <= condition * relative_residual + 1e-12
print({"relative_forward_error": relative_forward,
       "relative_residual": relative_residual,
       "normwise_backward_error": eta, "condition": condition})
for perturbation in [np.array([1e-6, 0.0]), np.array([0.0, 1e-6])]:
    changed = np.linalg.solve(A, b + perturbation)
    print("input change:", perturbation, "solution change:", changed - truth)
```

它没有证明某个黑箱求解器总后向稳定，只是在已知真解问题中把几个误差对象分开。将相同协议用于非对角矩阵时，可以用正交旋转改变敏感方向，同时保留奇异值。记录输入生成与真实参数，不要把由低精度输入产生的观测变化全部归给算法。

### 7.2 一个带停止信息的共轭梯度实现

第二段程序只用于小型对称正定教材例子，显式检查正曲率、返回原系统真实残差，并与直接解核对。它不包含稀疏预条件、重启或所有工业级异常处理，但每个返回值都有明确解释。若不满足精度，程序显式报告，而不是让最后一次迭代冒充收敛。

```python
import numpy as np

def conjugate_gradient(A, b, tolerance=1e-12, max_steps=100):
    x = np.zeros_like(b, dtype=float)
    r = b - A @ x
    p = r.copy()
    squared = float(r @ r)
    scale = max(1.0, float(np.linalg.norm(b)))
    if np.sqrt(squared) <= tolerance * scale:
        return x, 0, True
    for iteration in range(1, max_steps + 1):
        Ap = A @ p
        curvature = float(p @ Ap)
        if curvature <= 0:
            raise ValueError("positive curvature required by this SPD example")
        alpha = squared / curvature
        x = x + alpha * p
        next_r = r - alpha * Ap
        next_squared = float(next_r @ next_r)
        actual_residual = np.linalg.norm(b - A @ x)
        if actual_residual <= tolerance * scale:
            return x, iteration, True
        p = next_r + (next_squared / squared) * p
        r, squared = next_r, next_squared
    return x, max_steps, False

A = np.array([[4.0, 1.0], [1.0, 3.0]])
b = np.array([1.0, 2.0])
x, iterations, converged = conjugate_gradient(A, b)
assert converged
np.testing.assert_allclose(x, [1 / 11, 7 / 11], atol=1e-12)
np.testing.assert_allclose(x, np.linalg.solve(A, b), atol=1e-12)
print("solution:", x, "iterations:", iterations,
      "actual residual:", np.linalg.norm(b - A @ x))
```

小例子会在两步附近达到标准，符合精确二维结构；大规模有限精度问题不应强制断言维数步必然终止。程序只检查沿实际方向的正曲率，也不能代替对输入矩阵整体正定性的先验验证。对于需要一般求解的项目，应使用经过验证、适合结构的成熟接口，并记录其收敛状态。

### 7.3 基础层：先确定误差对象

**题一：小残差反例。** 对角矩阵一与千万分之一，真解为两个一，候选把第二分量设为零。计算绝对残差、绝对解误差与二范数条件数。

**解析：** 残差为零与千万分之一，长度为千万分之一；解误差为零与一，长度为一；条件数为一千万。误差刚好沿最敏感方向，符合逆作用的精确关系。若只看残差的小数位，会误以为参数已很准确。若任务只读第一坐标，任务误差又可能为零，说明所有参数精度与特定输出精度需要分别定义。

**题二：行列式能判断病态吗？** 将二维单位矩阵乘以十亿分之一，求行列式与二范数条件数。再解释为什么对角矩阵一百万与百万分之一具有另一种情形。

**解析：** 前者行列式为 $`10^{-18}`$，条件数仍为一，所有方向同比缩放。后者行列式为一，条件数却为一万亿，方向伸长差极大。行列式是全部特征尺度的乘积，可能掩盖一大一小的补偿。条件数关注最大与最小相对放大，故不能用一个绝对行列式阈值替代它。实际绝对误差还需同时考虑输入与右端单位。

**题三：矩阵扰动界的分母。** 条件数为一千、相对矩阵误差为万分之一，右端相对误差为十万分之一。用本章充分界估计相对解误差；若矩阵误差改成千分之二，能否继续使用同一式保证？

**解析：** 条件数与矩阵误差乘积为零点一，分子为一千乘零点零零零一一，故上界为零点一一除以零点九，约零点一二二二。矩阵误差改大后乘积为二，不满足小于一的条件，不能把负分母当作有意义上界。系统未必真的奇异，只是当前充分证书失效；应重新分析具体扰动方向或使用其他信息，而不是把条件丢掉继续计算。

**题四：范数型与分量型标准。** 一个系统的第二行比第一行小一百万倍，候选完全忽略第二行，却满足第一行。为何整体残差可能很小，分量比例却很大？

**解析：** 整体范数主要由第一行尺度决定，小行全部失败仍可能只产生百万分之一的总体扰动。逐行分量尺度则拿该行残差与该行允许变化比较，完全忽略可能接近百分之百相对误差。哪种标准合适取决于小行是否在任务中同样重要，以及它的观测精度。不能通过只报告更有利的标准隐藏失败，也不能在没有单位背景时宣布某一种标准永远正确。

### 7.4 方法层：主元、结构与收敛条件

**题五：小主元是否证明问题病态？** 对首元素为极小正数、其他三元素为一的二维矩阵，说明直接消元与交换行的区别，并分析极限矩阵是否奇异。

**解析：** 不交换时倍数为小数倒数，产生巨大中间量；交换后倍数变为小数，计算路径更温和。极限矩阵为 $`\begin{pmatrix}0&1\\1&1\end{pmatrix}`$，行列式为负一，可逆，因此这不是由极限奇异造成的问题。算法不稳定与问题敏感可能分别出现，应通过输入扰动和可靠求解对照区分。某次未经主元的失败不能被描述为任何方法都不可能准确解出该系统。

**题六：Cholesky 条件。** 对称矩阵 $`\begin{pmatrix}1&2\\2&1\end{pmatrix}`$ 对角都为正，能否进行标准正对角 Cholesky？用一个方向与一次消元说明。

**解析：** 沿 $`(1,-1)`$ 的二次型为负二，矩阵不正定。首步对角取一，剩余 Schur 补为一减四等于负三，无法继续实正平方根。对角元素正不是整体正定。可以使用适合对称不定系统的其他分解；加足够阻尼也可以定义正定新系统，但它的解一般已改变，应清楚说明目的。

**题七：Jacobi 收敛与系统可逆。** 对矩阵对角一、非对角二，计算 Jacobi 误差矩阵的特征值，说明为何可逆系统仍可能迭代失败。

**解析：** 误差矩阵为 $`\begin{pmatrix}0&-2\\-2&0\end{pmatrix}`$，特征值为正负二，模超过一，所以除特殊零误差等情形外不能收敛。原矩阵行列式为负三，可逆，存在唯一精确解。固定点拆分引入了另一个动力系统，其收敛需要自己的谱条件；可逆性只保证代数解，不保证任何选择的迭代都会找到它。

**题八：非正定系统为什么不能照搬共轭梯度？** 对角一与负一，右端两个一，零初始化，计算第一搜索方向曲率。若分母加一个很小常数，是否恢复了原算法保证？

**解析：** 方向为 $`(1,1)`$，曲率为一减一等于零，标准步长无法定义。任意加数只是改动了递推，既没有让原矩阵正定，也没有证明新方向满足共轭最小化性质。应选择适合不定或非对称结构的方法，或明确建立修改后的优化问题。程序避免除零与数学保证恢复是两件不同事，不能因程序继续输出就称问题已解决。

### 7.5 目标层：伪逆、缩放与正则

**题九：最小范数不等于最稀疏。** 对 $`x_1+x_2=2`$，比较欧氏最小范数与非零坐标尽量少的精确解。

**解析：** 最小二范数是 $`(1,1)`$，平方长度二；稀疏解可为 $`(2,0)`$ 或 $`(0,2)`$，平方长度四。所有解都满足观测，不同准则挑选不同代表。伪逆没有自动执行特征筛选，稀疏约束也不自动给出唯一真参数。若比较两种算法，必须先确认它们是否采用同样准则，再讨论哪个更准确或更适合任务。

### 边界追问：数值上更平稳是否等于同一个答案更准确

**题十：** 近奇异最小二乘经过截断后参数波动显著降低，能否把它报告为原问题前向误差下降？应怎样设计能区分解释的实验？

**解析：** 截断通常已改变选解目标，参数更平稳可能来自主动删去敏感方向。应一组固定精确目标，用高精度或已知真解衡量纯数值误差；另一组含观测噪声与独立评价，衡量正则偏差和预测风险。把两个结果分别报告，才能知道收益来自算法更稳定还是问题定义改变。二者都可能有价值，但不能用一个泛称掩盖差别。

**题十一：最小二乘设计扰动项。** 为什么目标扰动公式只含伪逆作用，而设计扰动还可能含原残差？若原目标完全可达，这个额外项怎样变化？

**解析：** 目标变化保持列空间固定，参数只需调整以拟合新目标的可达部分；设计变化还旋转列空间，原来正交的残差可能投影到新列方向。对正规最优性线性化出现 $`E^Tr`$，这正是额外项。原残差为零时它消失，但近秩亏仍会通过其他逆作用造成敏感。理解这项能避免把所有最小二乘误差都压成一个方阵右端条件数故事。

**题十二：迭代改进的精度来源。** 若当前近似解残差用与原计算相同的低精度求出，发生严重相消，为什么修正可能停滞？提高残差精度是否保证任意系统收敛？

**解析：** 残差本来是两个接近量之差，低精度误差可能覆盖真实误差信息，修正方程便得到不可靠右端。更高精度残差有助恢复这部分信息，但修正求解本身仍需足够好，误差传播矩阵也要收缩。若低精度分解与条件数结合过差，或系统结构不满足方法条件，提高一个环节并不能保证全部成功。还要区分计算精度与观测真实精度，后者无法靠迭代增加。

### 7.6 实验层：报告什么才能解释成功与失败

**题十三：残差递推与真实残差。** 长期迭代打印的内部残差很小，重新计算原系统残差却明显较大，是否一定是公式错误？应补什么检查？

**解析：** 有限精度可以让递推残差逐渐偏离真实残差，即使每步公式本身对应正确算法。应定期复算，检查累积舍入、精度、预条件残差口径和停止标准。若代码混用了不同系统或符号，也会出现相同现象，因此不能只归因浮点而放弃排查。报告应写明验收依据原系统真实残差，避免让内部代理量冒充最终方程精度。

**题十四：目标相关准确性。** 系统有一个非常敏感参数方向，但实际只关心另一个线性输出。为什么全部参数误差上界可能过于保守，怎样用伴随看输出误差？

**解析：** 若目标为 $`c^Tx`$，误差为 $`c^TA^{-1}r`$。解伴随方程 $`A^Tz=c`$ 后，它等于 $`z^Tr`$，可以直接结合残差方向评价，而不是先放大成所有参数的最坏范数。若目标对敏感方向不关心，输出误差可能很小。这个更细结论仍需要正确目标和伴随精度；不能由某个输出可靠就宣称全部参数或其他决策也可靠。

**题十五：公平比较两种求解器。** 一个返回较小残差，另一个返回较小已知参数误差，应该宣布谁胜出？

**解析：** 先确认它们求同一个目标、同一秩与正则约定，再分别报告两类误差、输入精度和成本。病态问题中，小残差不唯一决定前向误差；若任务关心参数恢复，应以相应误差为主要指标，若关心约束满足，则残差重要，若关心预测，还需测试分布。不存在脱离目标的单一获胜标准。特别不能把一个使用正则的新问题与一个精确原问题只按残差排名。

**题十六：停止上限与成功标志。** 迭代达到最大次数但未满足容差，训练流程仍把返回数组用于下一步，报告应怎样写？

**解析：** 应明确这次未达到规定精度，记录最终真实残差、步数和可能影响，而不是因程序没异常就记作收敛。下游可以接受近似结果，但需要相应误差预算或敏感度分析。若外层优化使用这次近似线性解产生梯度，误差还会继续传播。最大步数是资源约束，容差是质量约束，两者应分别记录，便于复现实验和解释失效区域。

### 7.7 进阶证明：短递推怎样保留共轭条件

补充共轭梯度的关键归纳逻辑。假设到当前步骤为止，旧搜索方向两两关于正定矩阵共轭，当前残差与旧搜索空间正交。新方向由残差加前一方向倍数组成，所以它与当前残差的内积等于残差平方长度。沿方向精确最小化，步长便是前面使用的残差平方除以方向曲率。

更新后的残差与当前方向正交；与更早方向也正交，因为它只减去当前矩阵方向，而两搜索方向关于矩阵共轭。这样残差正交不变量在新增一步后仍成立。每个早期残差都能由当时方向和前一方向线性组合表示，因此新残差也与所有早期残差正交。

由残差更新式，$`Ap_j=\frac{(r_j-r_{j+1})}{\alpha_j}`$。对严格早于当前的方向，新残差与右侧两个旧残差都正交，故新残差关于矩阵与这些方向正交。只需再选一个系数，消掉与最后一个方向的矩阵内积，就能让新搜索方向与全部旧方向共轭。

具体计算最后的内积：新残差乘当前矩阵方向等于负的新残差平方除以当前步长；旧方向曲率等于旧残差平方除以该步长。因此需要的系数正是新旧残差平方比。这说明看似只记住一个旧方向的短递推，实际上利用了全部早期正交不变量，并非随意遗忘历史。

只要残差非零，新方向便与旧空间线性独立，因为它含有一个与旧空间正交的非零残差分量。有限维中不能无限产生新独立方向，所以精确算术下至多维数步停止。浮点舍入破坏这些完全正交等式，才需要实际残差、容差与可能的再正交等处理。有限步理论与代码停止现象应按这个边界解释。

<a id="componentwise-complete-example"></a>

### 7.8 一个整体证书很好、分量证书很差的实例

取对角系统一与亿分之一，右端为一与亿分之一，真解两个一，候选为一与零。整体残差长度为亿分之一，矩阵二范数为一，计算解长度为一，右端长度约为一，因此范数型后向误差约为十亿分之五，也就是 $`5\times10^{-9}`$。

逐行看，第一行残差为零；第二行允许尺度是原矩阵绝对值乘候选绝对值再加右端绝对值，等于亿分之一，残差也等于亿分之一，所以分量型后向误差为一。候选完全丢掉了第二条观测的相对信息，整体指标却认为输入变化很小。

两种结果都正确，因为它们回答不同扰动问题。如果第二行代表一项不能忽略的守恒约束，整体范数证书可能不足以验收；如果第二观测本身噪声远大于该尺度，又可能没有必要要求它精确满足。数值指标需要与输入误差模型及任务约束对应，而不是仅以数字更小为优。

<a id="energy-error-certificate"></a>

### 7.9 正定系统中残差到能量误差的精确联系

对称正定系统满足 $`e=A^{-1}r`$，于是误差能量恰为 $`e^TAe=r^TA^{-1}r`$。若最小与最大特征值分别为 $`\mu,L`$，便得到

$$
\frac{\Vert r\Vert _2^2}{L}
\le\Vert e\Vert _A^2
\le\frac{\Vert r\Vert _2^2}{\mu}.
$$

若需要能量误差不超过 $`\epsilon`$，残差小于 $`\sqrt\mu\,\epsilon`$ 是一个充分标准。这比只规定一个与尺度无关的残差小数位更有目标意义。最小特征值下界若只是估计，也要报告其可靠程度；一个过于乐观的下界会导致错误的精度证书。

当右端非零，相对能量误差还可控制为 $`\frac{\sqrt{\kappa_2(A)}\Vert r\Vert }{\Vert b\Vert }`$，因为真解能量平方是 $`b^TA^{-1}b`$，至少为右端长度平方除以最大特征值。这里出现条件数平方根，而普通参数二范数的通用界出现条件数本身，二者不冲突，评价度量不同。

预条件方法中常观察某种预条件残差，它可能与能量相关，但不一定直接等于原系统真实残差。验收应说明采用的内积、预条件是否正定，以及该代理量与真正目标误差之间的界。不能仅因为一个内部量下降很快，就断言原问题所有意义下都同样准确。

<a id="solver-report-checklist"></a>

### 7.10 面向项目的完整求解报告

一个可复算报告至少包含数学目标、矩阵结构、输入来源与精度、缩放约定、求解方法、正则或秩阈值、停止规则与是否达到要求。然后同时给出原系统真实残差、相对误差尺度、可得的条件估计，以及真正任务输出的误差或敏感性。没有真解时，应明确哪些指标只是证书或上界。

实验最好安排条件良好、病态、秩亏、非正定和尺度差异五种对照。每种失败都要区分前提不成立、目标定义改变、数值算法误差和数据不可识别。用高精度参照时也要说明参照解决的是精确存储输入，还是某个已知生成模型；高精度不自动揭示现实真值。

学完本章，应能从残差推导前向误差、从有限扰动证明分母条件、从一个输出目标构造伴随检验，并理解 LU 主元、QR、SVD 与正定迭代各自的边界。后续 PCA 实践会反复用到这些区分：协方差矩阵可以天然半正定，小特征方向可能统计不稳，计算出的主方向也需要按尺度、精度与数据来源解释。

<a id="least-squares-stopping-object"></a>

### 7.11 最小二乘的驻点残差与数据残差也要分开

对不相容最小二乘，目标并不要求原残差 $`y-Xw`$ 趋于零，而要求它与列空间正交。设计为常数列、目标为一与三时，最优系数二仍有残差负一与一，梯度残差 $`X^Tr`$ 却为零。若迭代一直等待原残差接近机器零，便可能永远无法按错误标准成功。

反过来，小梯度残差也需要结合设计尺度与条件判断离最优系数多近，因为参数误差经过正规矩阵映到梯度。报告时应分别保留拟合残差、最优性残差和选解准则，才能知道未达到的是模型表达能力、优化精度还是数值求解要求。这也避免将真实不可消除的观测误差当作算法应继续消除的错误。
