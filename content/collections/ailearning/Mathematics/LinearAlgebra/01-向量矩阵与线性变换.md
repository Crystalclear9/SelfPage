## 1. 从数据到矩阵

一条样本可以写成向量。例如房屋的面积、房龄构成 $`x=(80,10)^T`$。向量的每个分量对应一个特征，分量顺序必须固定。把 $`n`$ 条样本按行堆叠，得到 $`X\in\mathbb R^{n\times d}`$，其中 $`d`$ 是特征数。线性模型写成 $`\hat y=Xw+b`$；权重 $`w\in\mathbb R^d`$ 决定每个特征对预测的影响。

点积 $`x^Tw=\sum_i x_iw_i`$ 把两个同维向量变成标量；它既能表示加权求和，也与夹角有关。欧氏范数 $`\Vert x\Vert _2=\sqrt{x^Tx}`$ 表示长度。余弦相似度是 $`\frac{x^Ty}{(\Vert x\Vert _2\;\cdot\;\Vert y\Vert _2)}`$，只比较方向；任一向量为零时没有定义。

<a id="sec-1-1"></a>

### 基础算例：把一条样本从输入空间映到输出空间

设一条样本 $`x=(2,1)^T`$，变换矩阵 $`A=\begin{pmatrix}1&2\\0&-1\end{pmatrix}`$，则 $`Ax=(4,-1)^T`$。第一行取输入的加权和，第二行只读取第二坐标并取反；每个输出坐标都能沿矩阵的一行解释。若将三条样本按行堆为 X，批量变换应写 $`XA^T`$，而不是 AX。两种写法的差别来自样本摆放约定，不是两个不同线性变换。先用一条样本手算，再检查批量第 i 行是否给出同样结果，可以直接发现转置方向错误。


<a id="linear-algebra-detail-1"></a>

### 1.1 向量先是空间中的对象，再是坐标列表

把向量写成一列数字非常方便，但数字不是向量概念的全部。一个实向量空间有向量加法和实数数乘，满足结合、交换、分配以及零向量等规则。在这些规则下，可以讨论线性组合、张成、独立和维数。二维箭头是向量，多项式在逐项相加和数乘下也是向量，某些函数集合也能构成向量空间。

例如次数不超过二的多项式可以写成 $`p(t)=a+bt+ct^2`$，相对于基 $`(1,t,t^2)`$，坐标是 $`(a,b,c)`$。这时一个三维坐标向量表达的是整条多项式，而不是空间中的物理位置。换成另一组多项式基，坐标会改变，但函数本身可以保持不变。这个例子有助于理解特征表示：不同编码可能表示同一对象，模型看到的是编码，而任务关心的是对象的行为。

机器学习中，一个样本向量的维度通常由特征方案决定。面积和房龄具有不同单位，虽然可以作为两个实数坐标放在同一个数组里，但默认欧氏距离已经做出了单位权重选择。把面积从平方米改成平方厘米，如果不调整距离度量，就会改变近邻关系。数组合法、维数相同，不代表几何解释已经合理。

线性组合 $`\alpha x+\beta y`$ 在数学空间里有定义，是否对应现实中有效样本则需要另查。例如两个用户的年龄与收入向量平均可能有合理数值，但类别编码、缺失标记与受约束特征不能随意平均。线性代数负责描述表示空间的运算，不自动保证每个结果都落在现实数据流形上。

<a id="linear-algebra-detail-2"></a>

### 1.2 点积、外积与相似性不能混为一谈

对列向量 $`x\in\mathbb R^d`$、$`y\in\mathbb R^d`$，内积 $`x^Ty`$ 是标量；外积 $`xy^T`$ 是 $`d\times d`$ 矩阵。取 $`x=(1,2)^T`$、$`y=(3,4)^T`$，内积为十一，外积是行分别为 $`(3,4)`$、$`(6,8)`$ 的矩阵。内积汇总对应坐标的乘积，外积保留所有坐标两两乘积，丢失的信息不同，适用任务也不同。

内积能表示夹角，是因为欧氏内积满足正定、对称和双线性。由 $`\Vert x-ty\Vert _2^2\ge0`$ 对任意实数 $`t`$ 成立，可得 Cauchy–Schwarz 不等式 $`\vert x^Ty\vert \le\Vert x\Vert _2\;\cdot\;\Vert y\Vert _2`$。非零向量时，内积除以两者长度得到余弦，取值在负一与一之间；它忽略长度，但不会消除坐标表示本身的偏差。

例如 $`x=(1,0)`$、$`y=(100,0)`$ 余弦相似度为一，欧氏距离却为九十九。如果任务认为幅值代表重要差异，余弦会有意忽略这种信息；如果幅值只是文档长度或曝光量的干扰，它可能更合适。不能笼统说一种相似度比另一种更准确，应解释哪些变化应被视为相同、哪些必须保留。

<a id="linear-algebra-detail-3"></a>

### 1.3 按行与按列组织样本：同一语义的两种约定

若样本按列组成 $`C\in\mathbb R^{d\times N}`$，线性变换 $`A\in\mathbb R^{m\times d}`$ 的批量输出为 $`AC`$；若样本按行组成 $`X=C^T`$，同一输出按行应写 $`XA^T`$。二者满足 $`(AC)^T=C^TA^T`$。这条等式说明转置来自组织约定，而不是随意调整形状。

一个实际的接口应同时写出形状和轴语义，例如批次、特征、输出。两个长度恰好相同的轴很容易被误换而不触发形状错误；只有追踪每个索引的意义，才能发现计算变成了“样本之间混合”而非“每个样本的特征映射”。先用非对称小矩阵手算，再扩展到批量，是非常有效的防错方法。

<a id="linear-algebra-detail-4"></a>

### 1.4 张成、独立与维数：数量不能替代信息

一组向量的张成集合包含它们的全部线性组合。独立要求只有所有系数都为零时，组合才能得到零向量；如果存在非零系数组合为零，就说明至少一个向量能够由其余向量表达。基同时满足独立与张成，因此既没有冗余，也不遗漏目标空间的方向。仅增加向量数量，既不保证张成扩大，也不保证信息增加。

例如二维平面中的三个向量必然相关，但三个向量可以张成整个平面，也可以只张成一条直线，甚至全为零。判断维数必须看独立方向，而不是对象个数。在特征工程中，把一个特征复制十次不会创造十种线性信息；在数据采集中，重复同一条样本也不会自动探索新的输入方向。

为什么同一个有限维空间的不同基具有相同数量？可以通过替换论证理解：若一组向量独立，另一组向量张成整个空间，就能逐个把独立向量替换进张成组，同时保持张成；每替入一个必须占据一个原有位置，所以独立组数量不会超过张成组。将两组基互换角色，得到两边数量相等。维数因此是空间的性质，而不是某次选择基的偶然结果。

相关并不意味着某个特征在所有建模方式中毫无价值。线性相关针对指定表示和线性组合；一个被其他特征线性表达的列，对纯线性预测没有新增方向，但不同正则、解释约束或非线性预处理可能改变实际算法行为。应先说明模型类与选择准则，再讨论删除特征的影响，不能把代数结论直接扩大成所有学习算法的性能结论。

## 2. 矩阵乘法在做什么

$`A\in\mathbb R^{m\times d}`$ 与 $`B\in\mathbb R^{d\times k}`$ 相乘得到 $`m\times k`$ 矩阵。中间维度相同是必要条件。矩阵可以看成线性变换：$`Ax`$ 将输入向量映射到新空间，而 $`ABx`$ 表示先执行 $`B`$，再执行 $`A`$。通常 $`AB\ne BA`$，因为执行顺序会改变结果。

例如 $`A=\begin{pmatrix}2&0\\0&1\end{pmatrix}`$ 把横坐标放大两倍，所以 $`A(1,3)^T=(2,3)^T`$。神经网络的全连接层也进行类似变换，再加偏置和非线性激活。

<a id="sec-2-1"></a>

### 机制展开：乘法顺序对应复合变换顺序

若先由 A 把输入 x 映到中间空间，再由 B 映到输出，结果是 B(Ax)=(BA)x，右侧矩阵先作用。取二维缩放 A=diag(2,1)，B 为旋转九十度；输入 (1,0) 先缩放再旋转得到 (0,2)，先旋转再缩放得到 (0,1)，所以 AB 通常不等于 BA。交换乘法不仅是形状问题，还改变了函数。批量实现应先确认中间空间维数和变换次序，再选择相应矩阵排列。

<a id="deep-dive-2"></a>

### 深入讲解：矩阵乘法怎样同时表达坐标组合和数据变换

取 $`X=\begin{pmatrix}1&2\\3&4\\5&6\end{pmatrix}`$、$`w=(2,-1)^T`$。按行看，Xw=(0,2,4) 是每条样本特征与权重的内积；按列看，它等于 2 倍第一特征列减第二特征列。两种视角完全相同，却回答不同问题：前者解释预测，后者解释模型能产生哪些输出。

X 的列空间包含全部可达预测。若两列相关，例如第二列恰为第一列两倍，则不同权重可能得到同一输出。训练只观察 Xw，无法辨别参数在零空间方向上的变化。相反，列独立也不保证任意 y 都可精确拟合，因为三维输出空间中的二维平面不覆盖所有目标。

矩阵可看作线性映射，满足 A(u+v)=Au+Av、A(cu)=cAu。加偏置得到仿射映射，不再要求原点映到原点。把图像旋转、特征投影、线性层都视为映射后，乘积 BA 表示先 A 后 B；交换顺序通常改变意义，也可能根本没有合法形状。

转置由内积关系刻画：$`\langle Ax,y\rangle=\langle x,A^Ty\rangle`$。这正是反向传播中 Aᵀ 出现的原因，不是为了凑形状临时转置。例如前向把二维参数映到三条预测，反向 Aᵀ 把三条误差信号合回两个参数。形状检查与这个语义检查应一起做。

正交矩阵 Q 保留欧氏长度和内积，可以主动旋转或反射向量；若用于被动换基，几何向量保持不变，改变的是坐标表示。一般矩阵还可以伸缩或压扁方向。要分析哪种方向被放大，后续用奇异值；要判断哪些方向被完全丢弃，检查零空间。把这些问题连起来，矩阵不再只是二维数字表，而是模型表达能力与信息损失的语言。


<a id="linear-algebra-detail-5"></a>

### 2.1 从基向量的像推导矩阵表示

设 $`T:\mathbb R^d\to\mathbb R^m`$ 是线性映射。任何 $`x`$ 可以写成 $`\sum_jx_je_j`$，由线性性有 $`T(x)=\sum_jx_jT(e_j)`$。把 $`T(e_j)`$ 作为第 $`j`$ 列排成矩阵 $`A`$，就得到 $`T(x)=Ax`$。所以矩阵列不是一组随意数字，而是输入基向量经过变换后的输出。

取矩阵 $`A=\begin{pmatrix}1&2\\0&-1\end{pmatrix}`$，它将第一个基向量映到 $`(1,0)`$，第二个映到 $`(2,-1)`$。输入 $`(2,1)`$ 是两倍第一基向量加一倍第二基向量，因此输出是 $`(4,-1)`$。按行算得到每个输出坐标，按列算得到基像的组合，两种解释应当能够互相恢复。

这也给出识别线性映射的方式：只要知道它在一组基上的作用，就确定了它在整个空间的作用。若一个操作包含平方、截断或非零平移，一般不能仅凭基向量输出推断任意输入结果，因为它不满足线性性。神经网络需要非线性激活，正是为了突破连续线性层复合仍然线性的限制。

<a id="linear-algebra-detail-6"></a>

### 2.2 逐索引证明结合律与转置乘法法则

对于形状兼容的三个矩阵，$`[(AB)C]_{ij}=\sum_k\sum_l A_{il}B_{lk}C_{kj}`$。交换有限求和次序后，等于 $`[A(BC)]_{ij}`$，这说明结合律成立。结合律允许改变计算括号，却不允许任意改变乘法顺序。若维数差异较大，选择不同括号可能显著改变计算量与中间存储。

例如 $`A`$ 为一千乘十、$`B`$ 为十乘一千、$`C`$ 为一千乘一，先计算 $`AB`$ 会产生一千乘一千的中间矩阵，先计算 $`BC`$ 只产生十乘一向量。数学输出相同，计算代价却有巨大差异。实际浮点结果还可能因运算顺序不同产生小差异，因此数学结合律不代表数值逐位一致。

转置法则 $`(AB)^T=B^TA^T`$ 可以从第 $`(i,j)`$ 元素验证：左侧是 $`\sum_kA_{jk}B_{ki}`$，右侧正是同一求和。顺序反转来自输入输出角色互换。类似地，若方阵可逆，$`(AB)^{-1}=B^{-1}A^{-1}`$，其正确性可通过左右相乘还原单位矩阵检查，而不是记忆口诀。

<a id="linear-algebra-detail-7"></a>

### 2.3 转置是内积下的伴随，而不是反向执行

对实矩阵 $`A`$，有 $`(Ax)^Ty=x^TA^Ty`$。它说明对输出方向 $`y`$ 的内积响应，可以拉回到输入空间并与 $`x`$ 比较。这个关系称为欧氏内积下的伴随关系，也是反向传播把输出敏感性映回输入时出现转置的原因。

转置不保证恢复原输入。若 $`A`$ 把二维压到一维，信息已经丢失，$`A^T`$ 只是把一维量送回二维的某个方向，不可能恢复全部原信息。例如 $`A=(1,1)`$，输入 $`(1,0)`$ 和 $`(0,1)`$ 都输出一，任何只依赖输出的操作都无法区分它们。用 $`A^T`$ 代替逆的想法，根本障碍不是公式写错，而是信息不足。

如果输入和输出采用非欧氏内积，伴随的矩阵表达也会变化。输入度量为正定矩阵 $`M`$、输出度量为 $`N`$ 时，要求 $`(Ax)^TNy=x^TM(A^*y)`$，所以 $`A^*=M^{-1}A^TN`$。这再次说明熟悉的转置公式带有内积约定，不是脱离几何结构的普遍反向操作。

<a id="sec-3"></a>

## 3. 线性相关与秩

若某列可以由其他列线性组合得到，它没有提供新的线性方向。秩是独立方向的数量。两个特征分别是米和厘米表示的同一长度时，列相关；这会使参数估计不唯一或不稳定。增加样本数量并不能自动消除这种特征冗余。

形式上，对 $`X\in\mathbb R^{n\times d}`$，若 $`\operatorname{rank}(X)<d`$，即不满列秩，就存在非零 $`v`$ 使 $`Xv=0`$。若 $`w`$ 能产生某个预测，$`w+cv`$ 对任意标量 $`c`$ 都产生相同训练预测，因此参数无法仅由这些观测唯一确定。满列秩要求 $`n\ge d`$；宽矩阵即使满行秩也不满足这一条件，而样本多但列完全重复同样不满列秩。讨论“秩亏”时，应说明参照的是满列秩还是通常的满秩 $`\min(n,d)`$，不能把二者混用。

数值上，几乎相关的列虽可能理论满秩，微小数据误差仍会造成参数大幅变化。用奇异值及条件数检查稳定性，比直接判断行列式是否接近零可靠。正则化、删除冗余特征或引入先验是在加入额外选择准则，需说明它们如何改变解释与估计。


<a id="linear-algebra-detail-8"></a>

### 3.1 列空间、零空间与秩零度定理

矩阵 $`A\in\mathbb R^{m\times d}`$ 的列空间是全部可达输出 $`\{Ax:x\in\mathbb R^d\}`$，零空间是全部被映为零的输入 $`\{x:Ax=0\}`$。它们分别位于输出空间和输入空间，不能因为都由同一个矩阵定义，就把两者当作同一空间中的互补部分。

设零空间维数为 $`k`$，取其一组基并扩展为输入空间的一组基，总共 $`d`$ 个向量。前 $`k`$ 个被映为零，后 $`d-k`$ 个的像张成列空间；这些像还必须独立，否则相应线性组合落入零空间，与扩展基的独立性矛盾。因此 $`\operatorname{rank}(A)+\dim\ker A=d`$。这就是秩零度定理，说明输入自由度被分成可观察变化与完全不可见变化。

考虑 $`A=\begin{pmatrix}1&2&3\\0&1&1\end{pmatrix}`$。第二行方程给 $`x_2=-x_3`$，第一行给 $`x_1=-x_3`$，所以零空间由 $`(-1,-1,1)^T`$ 张成，维数一；前两列独立，因此秩为二，与三维输入的分解一致。沿这个零空间方向改变参数，所有由 $`Ax`$ 表达的观测都完全不变。

<a id="linear-algebra-detail-9"></a>

### 3.2 方程的存在性与唯一性是两个问题

求解 $`Ax=b`$ 时，存在解当且仅当 $`b`$ 位于列空间；若存在一个特解 $`x_0`$，全部解为 $`x_0+v`$，其中 $`v\in\ker A`$。证明很直接：两解之差被 $`A`$ 映为零；反过来特解加任意零空间向量仍给出 $`b`$。唯一解要求零空间只有零向量，也就是满列秩。

对上面的矩阵取 $`b=(4,1)^T`$，令 $`x_3=t`$，得到 $`x_2=1-t`$、$`x_1=2-t`$，所以全部解为 $`(2,1,0)^T+t(-1,-1,1)^T`$。观测可以完全拟合，但参数并不唯一。额外选最小范数、稀疏或满足物理限制的解，是在加入选择准则，不是从原观测中凭空恢复信息。

若方程比未知数多，满列秩仍不保证任意目标都能拟合。例如将两参数映到三条预测，列空间最多二维，一般的三维目标不在其中。这时最小二乘寻找的是可达空间中最接近目标的点，下一章将用正交投影系统推导。样本多、参数少、目标是否可达，应当分别判断。

<a id="linear-algebra-detail-10"></a>

### 3.3 精确秩与数值秩为什么可能给出不同直觉

设 $`A_\epsilon=\begin{pmatrix}1&1\\0&\epsilon\end{pmatrix}`$，只要 $`\epsilon\ne0`$，理论秩就是二。但若目标第二分量含误差 $`\delta`$，解的第二坐标变化为 $`\frac{\delta}{\epsilon}`$。当 $`\epsilon`$ 很小时，很小的观测误差就会引起很大的参数变化。理论可逆不代表数值可靠。

奇异值描述各方向伸缩，极小奇异值对应很难由噪声中识别的方向。数值秩通常通过相对于矩阵尺度与精度的阈值判断，而不是只问某个行列式是否等于零。阈值不同会得到不同有效秩，所以报告应说明标准，不能把数值软件输出当作完全脱离尺度的事实。

这与统计估计也直接相连。特征几乎相关时，不同系数可以产生近似相同预测，因此单个系数解释可能非常不稳定，即使整体预测误差不大。正则化能够减少这种不稳定，却会引入偏好和偏差；“预测稳定”和“参数有唯一可信解释”不是同一结论。

<a id="linear-algebra-detail-11"></a>

### 3.4 行空间与零空间的正交关系

一个向量位于零空间，当且仅当它与矩阵每一行内积都为零，所以零空间是行空间的正交补。这条关系把方程约束变成几何方向：每一行排除一个可能的输入变化，独立行共同确定可观察的输入分量。行空间与零空间位于同一输入空间中，因此可以谈正交补；列空间与零空间一般位于不同空间，不能如此混写。

在有限维欧氏空间中，行空间维数与列空间维数相等，都称为矩阵秩。可以用消元后的主元结构证明：可逆初等行变换保持列间依赖关系，阶梯形矩阵的非零行数等于主元列数，同时给出两种维数。这个结论解释了为何既能按独立约束计数，也能按独立可达方向计数，而最终得到同一个秩。

对任意可解方程，最小范数解应当落在行空间。若解含有非零零空间分量，删去它不改变观测，却会因正交分解减小长度。这是后续伪逆解的几何基础。注意这里选择的是欧氏最小范数；若改变参数度量，最优代表也可能改变，因此最小范数并不是脱离尺度与坐标的无条件自然真值。

<a id="rank-composition-bound"></a>
### 3.5 复合映射丢失了多少独立方向

对于从某个输入空间先经矩阵 B 进入中间空间、再经矩阵 A 输出的复合，乘积秩不仅有熟悉的上界，还能精确说明丢失来源。把 A 限制在 B 的像空间上，这个限制映射的像就是乘积的像，核则是 B 的像与 A 的零空间的交集。对这个限制映射应用秩零度定理，得到乘积秩等于 B 的秩减去上述交集维数。

因此，只有真正落入下一层零空间的中间方向才被完全丢弃，而不是下一层有任何零空间就必然按其全部维数损失。如果中间空间维数为 k，交集维数不超过 A 的零度，于是得到乘积秩至少为两矩阵秩之和减 k。这个下界可能为负，此时只能提供平凡信息；它与较小秩上界一起，限定复合可保留的独立方向范围。

取三维中间空间，B 的像是前两个坐标张成的平面。若 A 只删除第三个坐标，交集为零，乘积仍保留两个方向；若 A 删除第二个坐标，交集一维，乘积只保留一个方向。两种 A 具有相同秩，B 也没有改变，结果却不同，区别来自子空间相对位置。讨论连续线性层或瓶颈表示时，这个视角比只比较矩阵尺寸更能解释信息保留。

## 4. 用维度验证模型

设两套房屋的特征矩阵为 $`X=\begin{pmatrix}80&10\\100&5\end{pmatrix}`$，权重 $`w=(2,-1)^T`$，偏置为 20。先计算每条样本的加权和，得到 $`(150,195)^T`$，再加偏置得到 $`(170,215)^T`$。这只是演示计算，不代表真实房价规律。把面积与房龄交换顺序却保持权重不动，结果会完全不同，因此列名称与列顺序都是模型接口的一部分。

还要区分线性变换与仿射变换：线性变换必须把零向量映射到零向量；加非零偏置后不再满足这一条件。机器学习中“线性层”通常把偏置也包括进来，是常用名称而非严格数学分类。矩阵转置则交换输入输出的索引位置，并不会自动成为原变换的逆。只有满足特定条件，如方阵正交矩阵，转置才等于逆。


<a id="linear-algebra-detail-12"></a>

### 4.1 从单条预测到多输出与多轴张量

对 $`N`$ 条样本、$`d`$ 个特征和 $`k`$ 个输出，令 $`X\in\mathbb R^{N\times d}`$、$`W\in\mathbb R^{d\times k}`$，有 $`Y=XW\in\mathbb R^{N\times k}`$。第 $`i`$ 行第 $`j`$ 列为 $`\sum_l X_{il}W_{lj}`$，它表示第 $`i`$ 条样本的第 $`j`$ 个输出。写出这个索引式，可以直接判断求和轴与保留轴分别是什么。

若再增加时间维，输入可能为 $`B\times T\times d`$。对每个批次、每个时间位置应用同一特征映射，输出为 $`B\times T\times k`$。这里的批次和时间轴是多个输入的组织，不是把所有位置互相线性混合。若需要时间之间交互，必须另外定义沿时间轴的运算。神经网络中很多形状错误，来自把“在每个位置应用同一映射”误解成“任意轴都可以相乘”。

偏置向量 $`b\in\mathbb R^k`$ 加到每个输出行上，完整式为 $`Y=XW+\mathbf1b^T`$。把它明确展开有助于理解广播：沿样本轴重复同一个偏置。若偏置恰好长度等于样本数，某些错误代码仍可能通过广播产生合法数组，却不再是每个输出维共享偏置。形状兼容是必要条件，轴语义正确才是目标。

<a id="linear-algebra-detail-13"></a>

### 4.2 维数相同仍可能把不同任务混在一起

假设有两个样本、两个特征、两个输出，所有轴长度都等于二。此时 $`XW`$、$`WX`$、$`XW^T`$ 都可能具有相同形状，只有一个符合既定参数语义。为了防止这种偶然相容，可以在最小测试里故意使用不同轴长，例如三条样本、两维特征、四个输出，让错误排列更容易暴露。

测试还应检查排列等变性。如果只是逐样本线性映射，交换样本顺序后，输出应按同样顺序交换；改变某一条样本，不应影响其他样本输出。如果错误地沿样本轴混合，后一性质会失败。结构性测试比只比较随机输入某一次输出更能揭示索引意图。

特征顺序变化也可以作为检验。令 $`P`$ 是特征排列矩阵，若新输入为 $`XP`$，对应参数应变成 $`P^TW`$，从而 $`XP P^TW=XW`$。只调换数据列却不调权重，预测一般会改变。这说明列名、顺序和编码版本都属于模型契约，不能在保存模型时只记录一个没有语义的数字数组。

<a id="linear-algebra-detail-14"></a>

### 4.3 仿射映射与齐次坐标

严格线性映射必须满足 $`T(0)=0`$ 和线性组合保持性。仿射映射 $`T(x)=Ax+b`$ 将直线映成直线或点，并保持仿射组合；可逆仿射映射将直线映成直线，但非零偏置通常破坏原点固定性。在线性模型中添加一个恒为一的特征，可以把仿射计算写成扩展空间中的线性形式：$`Ax+b=\begin{pmatrix}A&b\end{pmatrix}\begin{pmatrix}x\\1\end{pmatrix}`$。

齐次坐标也可以把仿射复合写成块矩阵。矩阵 $`\begin{pmatrix}A&b\\0&1\end{pmatrix}`$ 作用于 $`(x,1)`$，输出 $`(Ax+b,1)`$。两个这样的块矩阵相乘，得到线性部分复合和偏置传播。注意最后坐标被限制为一，所以它是把原仿射问题嵌入更大线性空间，并不是原映射在原空间忽然变成了严格线性。

这个表示解释了连续仿射层为何仍然只是仿射层：$`B(Ax+a)+b=BAx+(Ba+b)`$。如果网络中间没有非线性，无论堆叠多少层，表示能力仍受一个总矩阵和总偏置限制。深度还可能改变参数化、正则和优化过程，但不能仅凭层数声称获得任意非线性表达。

<a id="linear-algebra-detail-15"></a>

### 4.4 一个同时检查数值与语义的批量例子

下面程序不仅检查输出形状，还核对单条手算、样本顺序与特征重排。它使用不同大小的样本轴与输出轴，避免两个轴刚好同长而掩盖错误。

```python
import numpy as np

X = np.array([[2., 1.], [0., 3.], [-1., 4.]])
A = np.array([[1., 2.], [0., -1.], [3., 1.], [1., 0.]])
b = np.array([1., 2., 3., 4.])
Y = X @ A.T + b
assert Y.shape == (3, 4)
np.testing.assert_allclose(Y[0], [5., 1., 10., 6.])
row_order = [2, 0, 1]
np.testing.assert_allclose(X[row_order] @ A.T + b, Y[row_order])
column_order = [1, 0]
np.testing.assert_allclose(
    X[:, column_order] @ A[:, column_order].T + b, Y
)
changed = X.copy()
changed[1, 0] += 0.5
np.testing.assert_allclose((changed @ A.T + b)[[0, 2]], Y[[0, 2]])
print(Y)
```

测试通过说明这些具体样本满足预期结构，并不能证明任意实现对所有输入正确。正式推导依赖矩阵索引公式；程序用来捕捉转置、布局与接口错误。两者配合，才能同时检查数学目标和实际代码，而不是让一段错误代码自我验证。

<a id="linear-algebra-detail-16"></a>

### 4.5 把单位检查与维度检查一起使用

形状检查确认运算是否合法，物理单位检查进一步确认加法是否有意义。一个房价模型可以把面积乘以每平方米价格系数、房龄乘以每年折价系数，然后与具有同样货币单位的偏置相加。两个系数的数值不能直接比较大小，因为它们携带不同输入单位的倒数。若将面积单位改变，必须同步变换该系数，才能保持同一预测函数。

多输出模型中，每列还可能对应不同单位，例如同时预测价格与能耗。把两个输出误差直接平方相加，就隐含了一种单位权重选择；即使矩阵公式完全合法，目标函数也可能偏向数值更大的输出。应根据任务成本、噪声模型或明确的标准化策略决定权重，而不能指望矩阵乘法本身解决建模含义。

零均值中心化也改变仿射表示。若新特征为原特征减均值，原权重可以保持，但偏置需要增加权重与均值的内积，才能表示同一个函数；进一步缩放特征时，权重也要同步变化。这个简单推导连接了数据预处理、参数保存和部署一致性，说明数学上可逆的前处理如果没有记录，仍会在实际系统里造成预测错误。

<a id="sec-5"></a>

## 5. 正交基与坐标选择

基是一组线性无关且能张成目标空间的向量。二维平面通常用横纵单位向量作基，但也可选择旋转后的两个独立方向。向量本身与其坐标表示不同：改变基，坐标会变化，所代表的几何对象却可以不变。模型里的特征变换也涉及这种表示选择。

正交基让计算更简单。若 $`q_i^Tq_j=0`$ 且每个向量长度为 1，则沿 $`q_i`$ 的坐标直接由 $`q_i^Tx`$ 得到。正交矩阵 $`Q`$ 满足 $`Q^TQ=I`$，保长度与夹角，因此可以旋转坐标而不改变欧氏距离。一般特征缩放则会改变距离，对依赖距离的模型产生影响。

理解检查：$`(1,1)`$ 和 $`(2,2)`$ 不能作为二维平面的基，因为它们只提供一个方向；$`(1,1)`$ 和 $`(1,-1)`$ 可以，归一化后还构成正交基。先分清“向量数量”和“独立方向数量”，才能正确理解维数。


<a id="linear-algebra-detail-17"></a>

### 5.1 换基公式：保持对象还是主动改变对象

设新基向量在旧坐标中组成可逆矩阵 $`S`$。若同一个几何向量的旧坐标为 $`x`$、新坐标为 $`z`$，则 $`x=Sz`$，所以 $`z=S^{-1}x`$。这里是被动换坐标，向量对象本身没有变化。另一个常见操作是对固定坐标中的向量施加主动变换 $`x\mapsto Sx`$，两者公式相似，含义却不同。

若线性变换在旧坐标中为 $`A`$，输入和输出都使用同一新基，新的矩阵表示为 $`S^{-1}AS`$。证明只需依次写出新坐标转旧坐标、执行原映射、输出转回新坐标。若输入空间和输出空间使用不同的基矩阵 $`S,T`$，表示则为 $`T^{-1}AS`$，不是一律采用相似变换。

例如新基取 $`s_1=(1,1)`$、$`s_2=(1,-1)`$，向量 $`x=(3,1)`$ 的新坐标满足 $`z_1+z_2=3`$、$`z_1-z_2=1`$，得到 $`(2,1)`$。数值从三和一变成二和一，不表示向量缩短；因为新基不是单位基，不能直接拿新坐标的欧氏长度当成原几何长度。

<a id="linear-algebra-detail-18"></a>

### 5.2 非正交坐标中的 Gram 矩阵

对 $`x=Sz`$，旧空间欧氏长度平方为 $`x^Tx=z^TS^TSz`$。定义 $`G=S^TS`$，它是新基的 Gram 矩阵，第 $`(i,j)`$ 元素是两基向量内积。只有当基正交归一时，$`G=I`$，坐标长度才直接等于几何长度。

对上述未归一基，$`G=2I`$，新坐标 $`(2,1)`$ 的几何长度平方是二乘五，等于旧坐标 $`(3,1)`$ 的长度平方十。若基不正交，Gram 矩阵还有非零交叉项。这个例子清楚说明“更换坐标”与“继续用坐标默认欧氏距离”结合起来，可能无意改变几何。

正交归一基的好处不只是方便画图。它使坐标提取、长度计算、投影和误差分解都更简单，也有助于数值稳定。因此很多分解方法寻找正交方向，但若输入各维单位差异很大，选择什么内积仍然需要任务判断，不能认为正交化会自动解决所有尺度问题。

<a id="linear-algebra-detail-19"></a>

### 5.3 Gram–Schmidt 的构造与局限

给定独立向量 $`v_1,v_2`$，先令 $`q_1=\frac{v_1}{\Vert v_1\Vert }`$，再从 $`v_2`$ 中减去沿 $`q_1`$ 的分量：$`r_2=v_2-q_1(q_1^Tv_2)`$，最后令 $`q_2=\frac{r_2}{\Vert r_2\Vert }`$。由于 $`q_1^Tr_2=0`$，得到两个正交单位向量。推广到更多向量时，逐次减去已有方向上的投影。

取 $`v_1=(1,1)`$、$`v_2=(1,0)`$，得到 $`q_1=\frac{(1,1)}{\sqrt2}`$、$`r_2=(\frac{1}{2},-\frac{1}{2})`$、$`q_2=\frac{(1,-1)}{\sqrt2}`$。若第二向量本来就是第一向量的倍数，余量变成零，无法归一，这不是算法偶然故障，而是输入没有提供新方向。

在浮点数中，几乎相关的向量可能使减法丢失有效数字，经典构造还可能逐步丧失正交性。改进的正交化与 Householder 变换等方法用于提高可靠性，具体比较留到矩阵分解和数值方法章节。本章的手算构造建立原理，不应不加判断地替代成熟线性代数库处理病态大问题。

<a id="linear-algebra-detail-20"></a>

### 5.4 投影系数为何需要正交条件

若 $`Q`$ 的列是正交单位向量，投影为 $`QQ^Tx`$，残差满足 $`Q^T(x-QQ^Tx)=0`$。如果列只是独立却不正交，直接使用 $`QQ^T`$ 一般错误，应由系数方程 $`Q^TQ c=Q^Tx`$ 求出投影系数。这里写出的逆形式 $`(Q^TQ)^{-1}Q^Tx`$ 只说明数学表达，数值实现通常应选择更稳定的求解方式。

举例取一列 $`q=(2,0)^T`$，它张成横轴。对 $`x=(1,1)^T`$，直接 $`qq^Tx=(4,0)^T`$，显然不是最近的横轴点；除以 $`q^Tq=4`$ 后得到 $`(1,0)^T`$。这个极小例子足以说明归一条件不能从投影公式中省略。后续最小二乘会把这个思想推广到多列子空间。

<a id="linear-algebra-detail-21"></a>

### 5.5 改变基与降维之间的区别

可逆换基保留全部信息，输入维数不变；降维映射通常从高维送到低维，必然存在非零零空间方向，从而无法恢复所有原输入。二者都可能被称为表示变换，但信息性质不同。若只在一个低维子空间内考虑数据，降维也许对该子空间保持一一对应；必须明确限制对象，不能把子空间上的可恢复性说成整个原空间可逆。

这对 PCA 特别有帮助：保留全部正交主方向相当于正交换坐标，截去部分方向才引入信息损失。被截方向在训练样本中方差小，不代表它对目标任务必然无用；无监督重建目标和监督预测目标可以偏好不同信息。线性代数能准确描述丢失的方向，是否应该丢弃则要结合统计目标检验。

<a id="sec-6"></a>

## 6. 进阶：范数对偶与线性预测的扰动界

由 Cauchy–Schwarz 不等式，$`\vert w^T\delta\vert \le\Vert w\Vert _2\;\cdot\;\Vert \delta\Vert _2`$。因此输入的 L2 扰动不超过 $`\epsilon`$ 时，线性得分变化最多为 $`\epsilon\Vert w\Vert _2`$，且当扰动沿权重方向时取等。这说明权重范数与局部敏感性有直接关系，而不只是经验上的“模型复杂度”。

更一般地，$`\sup_{\Vert \delta\Vert _p\le\epsilon}w^T\delta=\epsilon\Vert w\Vert _q`$，其中 $`\frac{1}{p}+\frac{1}{q}=1`$。L∞ 输入扰动对应 L1 权重，L2 对应 L2。讨论正则与鲁棒性时必须说明输入的度量和单位；不同范数约束保护的扰动集合不同。

**推导练习：** 固定 L2 扰动，取 $`\delta=\frac{\epsilon w}{\Vert w\Vert _2}`$ 验证上界可达；再解释把特征单位放大为何会改变同一数值半径的含义。

<a id="sec-6-1"></a>

### 范数、距离与线性映射的三种角色

向量范数衡量一个对象的大小，距离 $`d(x,y)=\Vert x-y\Vert `$ 衡量两个对象的差异，矩阵算子范数则衡量变换能把输入放大多少。对 $`x=(3,4)^T`$，$`\Vert x\Vert _1=7`$、$`\Vert x\Vert _2=5`$、$`\Vert x\Vert _\infty=4`$；三者不是精度不同的估计，而是对“大”的不同定义。取 $`A=\operatorname{diag}(2,1)`$，单位圆被映成椭圆，最大伸长为 2，因此 $`\Vert A\Vert _2=2`$。

Cauchy–Schwarz 不等式给出 $`\vert w^Tx\vert \leq\Vert w\Vert _2\;\cdot\;\Vert x\Vert _2`$。若线性预测的输入扰动为 $`\delta x`$，则输出变化满足 $`\vert w^T\delta x\vert \leq\Vert w\Vert _2\;\cdot\;\Vert \delta x\Vert _2`$。这解释了参数范数约束如何限制特定度量下的敏感性，但不能直接推出分布外鲁棒性：若特征单位改变，相同范数球对应的实际扰动已不同。

手算时先确认向量在行还是列、内积产生标量还是外积产生矩阵。$`xy^T`$ 的每列均为 x 的倍数，非零时秩为 1；$`x^Ty`$ 却只有一个数。神经网络中的批维只是多个样本的组织方式，不能借广播把这两类运算混为一谈。


<a id="linear-algebra-detail-22"></a>

### 6.1 范数的三条公理与它们各自排除的错误

范数需要非负且仅零向量长度为零、绝对齐次性、三角不等式。第一条避免把非零变化当作完全没有大小；第二条保证把扰动放大若干倍时长度按相同倍数变化；第三条保证分两步走的总成本不会小于直接位移的成本。它们共同使距离 $`d(x,y)=\Vert x-y\Vert `$ 具有适合比较误差的结构。

平方欧氏长度 $`x^Tx`$ 虽然经常出现在损失中，却不是范数，因为数乘两倍会使它变成四倍，违反绝对齐次性。一范数、二范数与无穷范数是不同的长度规则，不是同一真实长度的粗略近似。数据稀疏、坐标独立限制或能量约束等场景，会使不同规则具有自然解释。

若使用正定矩阵 $`M`$ 定义 $`\Vert x\Vert _M=\sqrt{x^TMx}`$，可以通过 $`M`$ 的正定平方根把它解释为变换后向量的欧氏长度。若矩阵仅半正定，可能有非零向量长度为零，此时得到的是半范数，而不是整个原空间的范数。在降维和不可观察方向分析中，这个区别尤其重要。

<a id="linear-algebra-detail-23"></a>

### 6.2 对偶范数的推导，而不仅是结论

对给定向量范数，定义对偶范数为 $`\Vert w\Vert _* =\sup_{\Vert u\Vert \le1}w^Tu`$。由于单位球对称，取绝对值与不取绝对值的上确界相同。定义直接给出 $`\vert w^Tx\vert \le\Vert w\Vert _*\Vert x\Vert `$，而且在线性预测扰动问题中提供可达的最坏方向。对偶描述的是一个线性读出在允许输入集合上最大能产生多大响应。

无穷范数约束下，每个 $`u_i`$ 都能独立选择在负一与一之间，最大化内积时按 $`w_i`$ 符号逐项取端点，所以对偶是一范数。一范数约束下，把全部预算集中在绝对权重最大的坐标即可达到最大值，所以对偶是无穷范数。二范数约束下，Cauchy–Schwarz 给出上界，取与权重同方向的单位向量达到，所以二范数自对偶。

对一般 $`1<p<\infty`$，令 $`\frac{1}{p}+\frac{1}{q}=1`$，Hölder 不等式给出上界。若 $`w\ne0`$，可以取 $`u_i=\frac{\operatorname{sign}(w_i)\vert w_i\vert ^{q-1}}{\Vert w\Vert _q^{q-1}}`$；由于 $`(q-1)p=q`$，这个向量的 $`p`$ 范数为一，内积等于 $`\Vert w\Vert _q`$。这一步展示了上界确实可达，而不是仅有一个方便但松的估计。

在最坏扰动分析中，必须说明扰动集合的坐标单位。像素允许每个通道独立变化一点、文本允许替换一个词、传感器允许总能量受限，属于不同集合，不能仅凭使用了同一个正则项就声称获得同样的实际鲁棒性。

<a id="linear-algebra-detail-24"></a>

### 6.3 算子范数、复合映射与稳定性

诱导算子范数定义为 $`\Vert A\Vert =\sup_{x\ne0}\frac{\Vert Ax\Vert }{\Vert x\Vert }`$，它衡量相应输入输出长度规则下的最大放大。定义立即给出 $`\Vert Ax\Vert \le\Vert A\Vert\;\cdot\;\Vert x\Vert `$，以及 $`\Vert AB\Vert \le\Vert A\Vert\;\cdot\;\Vert B\Vert `$。后者可以逐步作用上界证明，意味着逐层最大放大系数的乘积能控制复合映射的最坏放大。

这个乘积可能很松，因为前一层最大放大的输出方向未必恰好落在后一层最大放大方向。取两个非零投影到正交轴的矩阵，两个算子范数都为一，乘积却为零；于是上界一远大于真实零。这说明逐层界是安全控制工具，不应总被解释为实际敏感性的精确预测。

欧氏诱导范数等于最大奇异值。可先通过 $`\Vert Ax\Vert _2^2=x^TA^TAx`$ 与对称矩阵的最大 Rayleigh 商理解，再在后续分解章完整展开。Frobenius 范数是所有元素平方和的平方根，一般不等于最大奇异值；它满足 $`\Vert A\Vert _2\le\Vert A\Vert _F`$，但可能随有效方向数量带来明显松弛。对二维单位矩阵，前者为一，后者为根号二，已经足以区分。

<a id="linear-algebra-detail-25"></a>

### 6.4 线性分类边界距离与范数正则的联系

二分类得分 $`s(x)=w^Tx+b`$，边界为得分零的超平面。对非零权重，在欧氏扰动下使当前点恰好到边界，需满足 $`w^T\delta=-s(x)`$。Cauchy–Schwarz 给出 $`\Vert \delta\Vert _2\ge\frac{\vert s(x)\vert }{\Vert w\Vert _2}`$，取 $`\delta=-\frac{s(x)w}{\Vert w\Vert _2^2}`$ 达到。因此几何距离是绝对得分除以权重长度，而不是得分本身。

若把全部权重和偏置同时乘以正数，分类边界不变，得分与权重长度同比变化，所以几何距离不变。仅比较不同模型得分大小，容易把任意缩放误判为更可靠的间隔。若参数缩放同时改变概率链接，概率语义还可能变化，需要另行校准，不能把分类边界与概率输出等同。

在一般范数下，到超平面的距离与对偶权重范数相联系。这里的鲁棒半径是对固定线性得分与指定扰动集合的几何结论，不代表标签在这些扰动下必然保持，也不代表未知分布上的错误率得到控制。几何稳定、语义稳定和统计泛化必须分别建立证据。

<a id="linear-algebra-detail-26"></a>

### 6.5 二次型、半正定与协方差的结构入口

对实对称矩阵 $`M`$，二次型 $`x^TMx`$ 描述与方向有关的平方尺度。若它对所有向量非负，矩阵半正定；对所有非零向量严格正，矩阵正定。检查对角线为正并不足以保证正定，例如矩阵行分别为 $`(1,2)`$、$`(2,1)`$，沿 $`(1,-1)`$ 的二次型为负。

形如 $`A^TA`$ 的矩阵总是半正定，因为 $`x^TA^TAx=\Vert Ax\Vert _2^2`$。它正定当且仅当 $`A`$ 零空间为零，即满列秩。这将几何、方程唯一性和二次目标的曲率联系起来，也说明样本协方差为何天然半正定：对任何方向，投影后的方差不能为负。

半正定不意味着矩阵元素都非负，正定也不意味着每个方向伸长相同。把元素符号、特征值符号和二次型性质分开，可以避免很多后续误读。后面的最小二乘、PCA 和优化会分别利用这些结构，但它们依赖的基础都是本章对方向、映射和内积的理解。

## 7. 练习与参考答案

**练习：** $`X`$ 的形状为 $`(100,3)`$，$`W`$ 为 $`(3,2)`$，$`XW`$ 的形状是什么？若第三列等于前两列之和，秩最多是多少？

**答案：** 输出为 $`(100,2)`$，代表每条样本有两个输出。秩最多为 2；若前两列本身也相关，秩还可能更低。

<a id="sec-7-1"></a>

### 边界追问：非零变换的乘积可以为零吗

**问题：** A=diag(1,0)、B=diag(0,1)，二者均非零，AB 的秩是多少？能否据此判断乘积秩总等于较小者？

**推理解析：** AB 为零矩阵，秩为零，而两者秩均为一。B 的像空间落在 A 的零空间中，复合后信息全部消失。一般只有 rank(AB)≤min(rank(A),rank(B))，等号需要额外条件。比较网络线性层时，维度足够并不保证复合映射保留相同数量的独立方向。


<a id="linear-algebra-detail-27"></a>

### 7.1 基础层：用两种视角恢复同一个计算

**题一：** 矩阵 $`A`$ 的三列分别为 $`(1,0)`$、$`(0,1)`$、$`(1,1)`$，输入 $`x=(2,-1,3)^T`$。分别按行内积和列线性组合计算输出，说明两个过程保留的语义。

**解析：** 第一行读取第一与第三坐标，得到五；第二行读取第二与第三坐标，得到二。按列则是两倍第一列、负一倍第二列、三倍第三列相加，同样得到 $`(5,2)^T`$。按行描述每个输出如何读取输入，按列描述输入基向量如何组合成可达输出。不能把同一结果误认为两个恰好数值相同的技巧，它们来自同一矩阵乘法定义。

**题二：** 取 $`x=(1,2,3)^T`$、$`y=(2,0,-1)^T`$，计算内积与外积的形状、数值，并解释外积非零时为何秩为一。

**解析：** 内积为负一，是一个标量；外积三行分别为 $`(2,0,-1)`$、$`(4,0,-2)`$、$`(6,0,-3)`$，是三乘三矩阵。每一列都是向量 $`x`$ 的某个倍数，所以列空间至多一维；又因两个向量非零，至少存在非零列，因此秩恰为一。若任意一个向量为零，秩才降为零。这个判断依赖列空间，而不是看到矩阵中有很多非零元素就猜测秩很大。

**题三：** 一个矩阵有一百行、三列，第三列等于前两列之和。是否能判断其秩恰为二？若不能，还缺什么条件？

**解析：** 只能断言秩至多二，因为前两列自身可能相关，甚至全部为零。若前两列独立，才恰为二。行数很大不意味着存在很多独立特征方向；一个关系可以在所有一百条样本中重复成立。若新增样本破坏了该关系，扩展数据矩阵的秩才有可能提高，所以还要区分偶然由当前样本造成的相关与特征定义造成的恒等冗余。

<a id="linear-algebra-detail-28"></a>

### 7.2 方程层：存在、唯一和稳定分别回答

**题四：** 对矩阵 $`A=\begin{pmatrix}1&2&3\\0&1&1\end{pmatrix}`$ 与 $`b=(4,1)^T`$，求全部解，并在其中找最小欧氏范数解。

**解析：** 全部解为 $`(2-t,1-t,t)^T`$。范数平方为 $`(2-t)^2+(1-t)^2+t^2=3(t-1)^2+2`$，所以最小范数解为 $`(1,0,1)^T`$。它与零空间方向 $`(-1,-1,1)^T`$ 内积为零，说明最小范数解不含多余的不可观察方向。最小范数准则只是从等预测解中选一个，不证明真实物理参数一定等于它。

**题五：** 对 $`A_\epsilon`$ 的例子，令目标为 $`(1,0)^T`$，再把第二分量改成 $`\delta`$，解如何变化？若 $`\epsilon=10^{-6}`$、$`\delta=10^{-5}`$，数字说明了什么？

**解析：** 原解是 $`(1,0)^T`$。扰动后第二坐标为 $`\frac{\delta}{\epsilon}`$，第一坐标为 $`1-\frac{\delta}{\epsilon}`$，变成 $`(-9,10)^T`$。目标仅发生十万分之一量级的变化，参数却改变了十量级，说明某方向严重放大误差。理论满秩与数值稳定不能互相替代；即便代码使用双精度，也不能消除输入本身带来的观测噪声放大。

**题六：** 两个非零矩阵相乘为零，是否意味着其中一个实现有错误？构造反例，并解释像空间与零空间的关系。

**解析：** 取 $`A=\operatorname{diag}(1,0)`$、$`B=\operatorname{diag}(0,1)`$，二者都秩一，但 $`AB=0`$。因为 $`B`$ 的全部输出位于纵轴，恰好是 $`A`$ 的零空间。复合映射保留多少信息，取决于中间像空间与下一层零空间如何相交，而不只取决于每个矩阵各自的秩。一般乘积秩不超过两者较小秩，但可能严格更小。

<a id="linear-algebra-detail-29"></a>

### 7.3 几何层：换坐标不等于改变对象

**题七：** 用基 $`(1,1)`$、$`(1,-1)`$ 表示向量 $`(3,1)`$，再计算新坐标默认欧氏长度和真实几何长度，解释差异来源。

**解析：** 新坐标为 $`(2,1)`$，其默认欧氏长度为根号五，原向量长度为根号十。差异并不矛盾：新基向量长度为根号二，所以对应 Gram 矩阵为两倍单位矩阵。正确几何长度应由新坐标二次型计算，得到根号十。若先将新基归一化，坐标也要相应调整，最终仍表达同一个向量。

**题八：** 给定非单位向量 $`q=(2,1)^T`$ 与 $`x=(1,0)^T`$，求到其张成直线的正交投影，并检查残差是否正交。

**解析：** 投影系数为 $`\frac{q^Tx}{(q^Tq)}=\frac{2}{5}`$，投影为 $`(\frac{4}{5},\frac{2}{5})^T`$，残差为 $`(\frac{1}{5},-\frac{2}{5})^T`$，与 $`q`$ 内积为零。若直接用 $`qq^Tx`$，会得到 $`(4,2)^T`$，既不满足残差正交，也不是最近点。这个核对使用了几何必要条件，而不只是把某个投影公式重新写一遍。

**题九：** 对矩阵 $`M=\begin{pmatrix}1&2\\2&1\end{pmatrix}`$，所有对角线元素都为正。通过两个方向判断其是否能定义一个内积。

**解析：** 方向 $`(1,1)`$ 的二次型为六，方向 $`(1,-1)`$ 的二次型为负二。因此它不是正定矩阵，甚至不是半正定，不能作为实向量空间的正定内积矩阵。只观察标准坐标轴会漏掉混合方向上的负值，这与多元函数只检查坐标轴不足以判断整体结构具有相似的逻辑。

<a id="linear-algebra-detail-30"></a>

### 7.4 扰动层：把上界、达到条件与任务语义分开

**题十：** 线性得分权重为 $`(3,-4)^T`$，输入扰动的二范数不超过零点一。求最大得分变化及实现它的扰动；若改成无穷范数约束，结果如何？

**解析：** 二范数情形的最大变化为零点一乘五，即零点五，扰动取 $`(0.06,-0.08)^T`$。无穷范数约束允许两坐标分别达到绝对值零点一，最优扰动为 $`(0.1,-0.1)^T`$，得分变化为零点七。两种约束对应不同集合，不能因为第二个数字更大就说第一种分析更准确。应由实际允许的输入变化决定集合。

**题十一：** 得分为 $`s(x)=3x_1-4x_2+2`$。在原点到分类边界的欧氏距离是多少？如果把得分整体乘以十，距离是否变化？

**解析：** 原点得分为二，权重长度为五，所以距离为零点四。最短扰动为 $`-\frac{2(3,-4)}{25}=(-0.24,0.32)`$，代入得分恰好为零。整体乘十后分子和权重长度都乘十，距离不变。这个不变性说明原始得分大小不足以跨模型比较几何间隔，也提醒我们不要把任意得分缩放当作模型更有信心的证据。

**题十二：** 已知某层算子范数上界为二，下一层为三。能否断言复合映射对所有方向放大六倍？

**解析：** 不能。六只是最坏放大的上界，还可能不达到；某些方向甚至被压为零。即便两层分别有达到各自上界的方向，这两个方向也未必在复合时对齐。若需要精确最大放大，应分析乘积矩阵或更紧结构。对于非线性网络还要区分固定点的雅可比和整个区域的统一 Lipschitz 上界。

<a id="linear-algebra-detail-31"></a>

### 7.5 研究任务：从坐标运算走向可检验的结构

**任务一：特征重排契约。** 构造一组带列名的输入与多输出模型，先只重排输入列，观察预测变化，再同时重排参数对应维，验证预测恢复。将缺失列、重复列与错误编码作为三个不同失败情况处理。报告应说明语义错误为什么可能在形状合法时发生，以及如何在模型保存和部署时保留列的身份。

**任务二：秩亏与参数解释。** 构造两列完全相关的数据，找出一条零空间方向，沿该方向产生多组参数并核对训练预测相同。再对某列加入微小扰动，比较参数解与预测的稳定性。改变的是精确可辨识性与数值条件，不应仅根据某一次系数符号翻转就断言特征产生了相反的现实效应。

**任务三：度量改变近邻。** 构造至少三条二维样本，其中两个特征单位差异明显。分别在原始坐标、单位转换后、补偿度量后三种方式下计算最近邻。先从公式预测哪些关系应该保持，再运行。任务目的是区分被动换坐标与主动改变距离，而不是机械证明“标准化总能改善效果”。

**任务四：最坏扰动与实际分布。** 对同一个线性分类器，在二范数和无穷范数约束下构造理论最坏扰动，再与随机扰动比较。解释为什么随机方向通常达不到最坏上界，为什么有限次随机实验不能证明不存在更坏方向，以及为什么几何扰动成功不自动代表现实语义发生变化。

研究报告应保留问题定义、假设、解析预期、构造细节、结果与未解决问题。对只验证几个样本的程序，陈述应限定在这些测试；对能够给出一般推导的结论，应写明证明与适用条件。把“我观察到”与“在条件下必然成立”分开，是从计算练习走向研究推理的重要一步。

<a id="linear-algebra-detail-32"></a>

### 7.6 本章完成后应能独立解释的知识链

你应当能够从基向量的像重建矩阵，从列空间判断预测可达性，从零空间解释参数不唯一，再用秩零度定理连接信息保留与输入自由度。遇到转置时，应能说明它是数据组织转换、内积伴随还是某个正交变换的逆，而不只是为了让维数碰巧匹配。

进一步应能说明换基如何改变坐标、何时必须同步改变度量，为什么正交归一基让投影与误差计算简单，以及范数约束如何通过对偶范数转为最坏线性响应。后续学习最小二乘、矩阵分解与 PCA 时，这些结构会反复出现；如果只记住计算按钮，却无法解释空间、方向和信息丢失，应先返回本章手算再前进。
