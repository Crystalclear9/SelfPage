# 自然语言处理

理解文本如何表示、序列任务如何建模，以及数据和指标为什么需要语言层面的检查。

**先修知识：** 入门需要监督学习与模型评估；上下文与生成部分再补 RNN、Transformer。

## 学习顺序与覆盖范围

第 1 章的词袋与 TF-IDF、第 3 章的分类基线可在监督学习后先做；上下文表示和序列生成再补 RNN、注意力与 Transformer。第 2 章建立任务评价，第 4 章扩展生成数据与评价，不能把大型语言模型当作学习文本分类的起点。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：评估生成事实而非只看措辞](04-生成任务数据质量与评价设计.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
