## 1. 先定义输出空间，再选择损失与指标

<a id="nlp-2-detail-2"></a>
### 1.1 分类、结构预测和生成回答不同问题

文本分类通常为整个文档选择标签，序列标注为位置或跨度分配结构，生成任务则输出一段可变长度文本。这三类任务都能使用语言模型作为组件，但它们的样本单位、可行输出和错误代价不同。一个文档分类正确，不代表其中每个实体都被识别；生成句子措辞自然，也不代表其中的事实正确。把所有问题都化成一个准确率，会在评价阶段丢失任务的关键结构。

形式上，分类输出属于有限标签集合，序列标注输出属于受约束的标签序列集合，生成输出属于词表上所有有限序列的集合。序列长度越大，可行输出数量通常越大，因此结构约束和搜索方法可能很重要。训练损失必须对输出空间和监督约定负责，评价器则必须把预测映射回实际业务需要的单位，两者相关却不完全相同。

例如一封邮件被标为“投诉”，可能包含两个不同组织、一个产品故障和一个退款请求。若下游需要自动填表，邮件级分类只是第一步；若下游需要生成回复，除了识别事实还要控制承诺范围。系统应该分别报告分类、抽取和回复质量，必要时再评价端到端任务成功率。不能因为最后界面只显示一段文字，就忽略中间证据结构。

<a id="nlp-2-detail-3"></a>
### 1.2 标签规范与条件不确定性

标签并不总是客观且唯一。情绪可以按作者态度、句子表面词汇或读者感受标注，实体可以按最长名称或最小名称标注，摘要可以偏向简洁或覆盖。定义不清时，模型损失下降可能只是在拟合某位标注者的习惯。应先写出包含边界例、冲突例和不可判定例的规范，再讨论一致性和模型上限。

对于真正多解的样本，单一金标准只是允许答案中的一个。如果评价要求与它逐字一致，合理的替代答案也可能被判错。解决方法可以是收集多参考、定义结构化事实集合、增加人工判定，或者明确任务只要求复现某种固定编码。选择哪一种需要由应用目标决定，不能在看到某个系统得分低以后临时改变规则。

<a id="nlp-2-detail-4"></a>
### 1.3 训练单位与评价单位的对照

一个模型可以按 token 平均交叉熵训练，却按实体精确匹配评价；可以按序列似然训练，却按人类事实判断评价。训练目标是可优化的代理，业务指标则描述实际关心的错误。代理有用不等于完美一致。研究时要解释为何选择它、哪里可能不一致，以及用什么诊断追踪这种差距，而不是把训练损失当作最终质量的充分证据。

数据划分也应围绕评价单位。对同一文档切成句子以后随机划分，模型可能在训练中见到测试文档的其他片段；对同一实体模板做改写后随机划分，也可能夸大泛化。若目标是新来源、新事件或新时间，必须按相应组划分并报告组数。样本数量很多并不能补偿评价单位设计错误。

## 2. 分类目标、概率与决策代价

<a id="nlp-2-detail-6"></a>
### 2.1 单标签交叉熵的推导和稳定计算

设类别分数为 $`z_k`$，单标签概率为 $`p_k=\frac{\exp z_k}{\sum_j\exp z_j}`$，真实标签为 $`y`$，负对数似然为 $`L=-z_y+\log\sum_j\exp z_j`$。对分数求导得到 $`\frac{\partial L}{\partial z_k}=p_k-\mathbf1[k=y]`$。损失推动真实类概率增加，但各类通过分母相互耦合；这与多个互不排斥的二元标签并不相同。

直接对巨大分数取指数容易溢出。可先取最大值 $`m=\max_jz_j`$，把对数求和指数写成 $`m+\log\sum_j\exp(z_j-m)`$。减去同一常数不改变 softmax 概率。实际接口常要求输入原始分数，而不是先手工 softmax 后再当成分数传入。二次归一会改变目标和梯度，尤其在极端概率附近更容易产生难以察觉的错误。

类别权重可以改变不同样本对损失的贡献，但权重不等于概率校准，也不等于部署代价。加权训练的最优概率可能对应经过重加权的标签分布，不能未经说明就把输出解释为真实业务发生率。若后面还使用重采样、阈值调整和类别权重，应分别说明每一步改变的对象，避免把同一种偏好重复施加却无法解释结果。

<a id="nlp-2-detail-7"></a>
### 2.2 多标签与互斥类别不能混用

一篇文档可能同时属于“退款”和“物流”主题，此时可以为每个标签建立独立 sigmoid 和二元交叉熵。标签并不需要概率之和为一，预测可以同时为真，也可以全部为假。将它误当成互斥多类问题会强迫模型在合法标签之间竞争；把互斥类别误当成多标签，又会允许不合规的多重输出，需要额外约束。

多标签评价还要区分逐标签微平均、宏平均和逐样本平均。某个常见标签可能贡献大量真阳性，掩盖稀有标签完全失败。严格子集准确率要求一个样本的全部标签集合都正确，通常比逐标签平均更苛刻。选择指标前应说明下游是否允许部分正确，漏掉一个关键标签与多报一个普通标签是否具有相同代价。

<a id="nlp-2-detail-8"></a>
### 2.3 从概率到行动的阈值推导

二分类中，预测正类的条件期望错误代价为 $`C_{FP}(1-p)`$，预测负类为 $`C_{FN}p`$，这里假设正确行动代价为零。选择正类的条件是 $`p\ge\frac{C_{FP}}{(C_{FP}+C_{FN})}`$。这个公式依赖概率对部署分布的解释以及代价设定，不能把任何分类器分数直接代入，也不能在有复核容量和群体约束时只使用一个全局阈值就结束分析。

F1 不是逐样本可加的固定代价目标，最优阈值与数据分布和其他样本的预测有关。为了最大化 F1 而在验证集上搜索阈值是允许的选择步骤，但最终测试不能再次参与搜索。若不同系统各自按测试集选择最佳阈值，比较就包含了额外的测试适配。应报告冻结阈值、选择依据和最终混淆矩阵，让读者知道提升来自哪里。

![正类权重为九时，原后验零点一对应加权最优输出零点五](images/02-img-weighted-probability.webp)

[打开原图放大](images/02-img-weighted-probability.webp)

**先识别加权目标，再解释输出概率。** 在本章二分类条件风险模型中，正类权重为九，最优输出满足 $`q=\frac{9\eta}{1+8\eta}`$。解这个方程可得 $`\eta=\frac{q}{9-8q}`$，于是加权模型输出二分之一对应原类别后验十分之一。等价地，logit 被整体平移 $`\log9`$；直接以 q 的二分之一分类，实际实现的是原后验十分之一的成本敏感阈值。

反解成立的前提是 q 已达到该条件风险的最优概率目标，权重已知且测试分布保持对应的后验关系。有限模型、优化误差、标签偏差或分布改变都会使它不再是无条件的校准保证。加权可以服务召回与代价目标，但不能把加权后的数值未经解释便称作原始发生概率。

**类别权重改变理想概率输出。** 本图假定模型能自由表达每个输入处的概率，正类损失权重为九，负类为一。代入图中的原条件正类概率 $`\eta=0.1`$，原正负质量为 $`(0.1,0.9)`$；加权后变为 $`(0.9,0.9)`$，归一化就得到 $`(0.5,0.5)`$。这一步已经改变了学习目标所对应的分布。

可以从条件期望损失推导图中的映射。普通交叉熵为 $`-0.1\log q-0.9\log(1-q)`$，最低点在 $`q=0.1`$；加权损失为 $`-0.9\log q-0.9\log(1-q)`$，最低点在 $`q=0.5`$。两种损失的目标和加权质量总和都不同，最低点的函数值无法直接用来比较两个模型。对一般 $`\eta(x)`$，一阶条件给出

```math
p^*(x)=\frac{9\eta(x)}{9\eta(x)+1-\eta(x)}=\frac{9\eta(x)}{1+8\eta(x)}.
```

上述推导可与 PyTorch 的正类加权 BCE 定义逐项对照：正类权重乘在正类对数项上，本图的理想输出则由这个定义的条件期望自行求导得到。

因此，提高少数类损失权重后，输出数值通常不能直接当原总体发生概率；改变决策代价与估计原始概率是两项不同要求。有限样本、优化误差和模型约束还会进一步改变结果，应在目标分布上另做校准检验。

<a id="nlp-2-detail-9"></a>
### 2.4 实验一：稳定损失、梯度与平均方式

```python
import torch
import numpy as np
from sklearn.metrics import f1_score

torch.set_num_threads(1)
z = torch.tensor([[1000., 999., -1000.]], dtype=torch.float64, requires_grad=True)
y = torch.tensor([0])
loss = torch.nn.functional.cross_entropy(z, y)
manual = -z[0, 0] + torch.logsumexp(z[0], dim=0)
assert torch.allclose(loss, manual)
loss.backward()
expected = torch.softmax(z.detach(), dim=-1)
expected[0, 0] -= 1
assert torch.allclose(z.grad, expected)
assert torch.isfinite(loss) and torch.isfinite(z.grad).all()
truth = np.array([0] * 8 + [1] * 2)
prediction = np.zeros(10, dtype=int)
micro = f1_score(truth, prediction, average="micro")
macro = f1_score(truth, prediction, average="macro", zero_division=0)
assert np.isclose(micro, 0.8)
assert np.isclose(macro, 4 / 9)
assert f1_score(truth, prediction, average="binary", zero_division=0) == 0
print("稳定损失", float(loss.detach()), "micro/macro", micro, macro)
```

这个人工例子没有训练文本分类器，而是分别检验损失公式、梯度和评价定义。微平均在完整互斥单标签多类设置下等于准确率，但这不应推广到任意多标签或过滤标签的设置。宏平均把每类同等对待，仍然需要说明未出现类别的处理约定；少数类样本极少时，其数值也可能具有很高方差。

## 3. 实体跨度、BIO 与严格评价

<a id="nlp-2-detail-11"></a>
### 3.1 一个实体不是若干独立正确 token

用左闭右开跨度 $`(s,e,c)`$ 表示从位置 $`s`$ 到 $`e`$ 之前的类型为 $`c`$ 的实体。严格实体匹配要求起点、终点和类型全部相同。若真实实体为“北京大学”，模型只识别“北京”，即使大部分字符标签正确，也没有找对这个实体。背景位置通常很多，因此高 token 准确率可能与低实体召回同时出现。

BIO 中 B 表示某类实体的开始，I 表示同类实体的延续，O 表示背景。一个 I 标签是否允许出现在序列开头，或者接在不同类型实体之后，需要明确规范。严格 IOB2 常禁止这些情况；某些评价脚本会修复非法序列或兼容其他编码。使用不同修复策略会改变实体集合，进而改变分数，不能只写“计算 F1”就认为协议完整。

<a id="nlp-2-detail-12"></a>
### 3.2 精确匹配、部分重叠和类型诊断

严格匹配可以定义预测实体集合为 $`P`$，金标准集合为 $`G`$，真阳性为交集大小，假阳性为 $`\vert P\vert -\vert P\cap G\vert `$，假阴性为 $`\vert G\vert -\vert P\cap G\vert `$。全库合并这些计数得到微平均实体 F1。重复实体应以文档身份和跨度区分，不能把相同字符串在不同文档中的出现合并成一个实体。

部分重叠可以作为诊断，但必须规定一对多匹配时如何分配信用，否则一个很长的预测跨度可能同时碰到多个实体而获得不合理奖励。类型正确、边界错误与边界正确、类型错误应分别统计，因为它们对应不同机制。严格主指标可以保持一致，同时用这些诊断指导改进，避免为了让得分更高而把宽松诊断替换成主任务。

<a id="nlp-2-detail-13"></a>
### 3.3 子词对齐与截断边缘

如果模型按子词输出，评价前应还原到约定的词或原文跨度。仅给首子词监督的方案不能直接把每个子词都当作独立预测评价；复制标签的方案也不能让一个长词贡献多个实体。特殊符号和填充必须排除，原始字符坐标与规范化文本坐标必须建立可追踪对应。

窗口切分使实体可能跨越边界。如果任务输入本来就是完整文档，却在预处理时截断了一半实体，那么应报告不可达金标准比例。可以只评价完全可见实体作为一个诊断切片，但不能悄悄从主测试中删除所有困难样本。跨窗口合并还需要固定去重、边界冲突和置信度聚合方法，并在验证集确定规则。

### 3.4 实验二：高 token 正确率不保证实体正确

```python
def strict_spans(tags):
    spans, start, typ = set(), None, None
    for i, tag in enumerate(list(tags) + ["O"]):
        if tag == "O":
            prefix, current = "O", None
        else:
            prefix, current = tag.split("-", 1)
            if prefix not in {"B", "I"} or not current:
                raise ValueError("invalid tag")
        if prefix == "I" and (start is None or current != typ):
            raise ValueError("illegal IOB2 transition")
        if start is not None and (prefix != "I" or current != typ):
            spans.add((start, i, typ))
            start, typ = None, None
        if prefix == "B":
            start, typ = i, current
    return spans

gold = ["B-ORG", "I-ORG", "I-ORG", "I-ORG"] + ["O"] * 96
pred = ["B-ORG", "I-ORG", "O", "O"] + ["O"] * 96
accuracy = sum(a == b for a, b in zip(gold, pred)) / len(gold)
g, p = strict_spans(gold), strict_spans(pred)
tp = len(g & p)
assert accuracy == 0.98
assert (len(p), len(g), tp) == (1, 1, 0)
assert 2 * tp / (len(p) + len(g)) == 0
try:
    strict_spans(["I-ORG"])
except ValueError:
    pass
else:
    raise AssertionError("illegal start was accepted")
assert strict_spans(["B-X", "B-X"]) == {(0, 1, "X"), (1, 2, "X")}
print("token accuracy", accuracy, "strict entity F1", 0.0)
```

这里显式拒绝非法 IOB2，而不是自动修复。真实项目如果采用另一种规则，需要单独命名并测试。示例中的两个连续 B 标签表示两个相邻实体，这是合法且容易被错误合并的边界。若只比较实体字符串而忽略跨度，这种情况就可能被误判；使用结构化集合可以把评价单位写得非常清楚。

## 4. 线性链 CRF：全局归一化与结构约束
<a id="sec-6-1"></a>
<a id="nlp-2-detail-16"></a>
### 4.1 发射分数、转移分数和整条路径

设标签数为 $`K`$，长度为 $`T`$，输入编码器给出发射分数 $`E_{t,k}`$，转移矩阵 $`A_{i,j}`$ 表示前一标签为 $`i`$、当前标签为 $`j`$ 的分数，另有开始分数 $`b_k`$ 和结束分数 $`e_k`$。一条路径的总分为

```math
\begin{aligned}
&S(y,x)=b_{y_1}+\sum_tE_{t,y_t}\\
&\quad +\sum_{t=2}^TA_{y_{t-1},y_t}+e_{y_T}
\end{aligned}
```

这里所有分数都是未归一化实数，不必分别解释为概率。

用四个词的短序列把局部打分、合法性约束和整条路径的概率接起来。

![十五分的路径起点非法，合法路径中十四分最高](images/02-img-crf-legal-paths.webp)

[打开原图放大](images/02-img-crf-legal-paths.webp)

先沿起点看合法性，再比较整条路径。此人工例固定后三个标签为 B、I、O，分数为四、四、三；首词的 O、B、I 分数为三、一、四，合法转移的附加分数设为零。采用单实体类型 BIO 的硬约束时，START 不能接 I，所以局部逐词最高的 I-B-I-O 虽得十五分，仍不进入候选集合；两条可行路径 O-B-I-O 和 B-B-I-O 得分分别为十四、十二。

Viterbi 在合法路径上取最大，因此选十四分的路径；全局归一化则需要把两条可行路径的指数权重相加，得到 $`Z=e^{14}+e^{12}`$，首条路径概率约为 $`0.881`$。图只展开本例的候选，真实 CRF 的分区函数须对所定义的完整路径集合计算，不能用最高分代替。 相邻两个 B 可分别开始两个实体。前向求和与 Viterbi 取最大之间的区别见 Sutton 与 McCallum 的 CRF 教程第 4.1 节。

条件概率定义为 $`P(y\mid x)=\frac{\exp S(y,x)}{Z(x)}`$，配分函数是所有合法路径分数指数的和。若约束某些转移非法，应从可行路径中排除，或用数学上的负无穷屏蔽。开始和结束约束同样重要。仅在解码时禁用非法转移，但训练配分函数仍包含它们，会使训练目标与最终结构空间不一致，需要明确这是近似设置而不是严格约束 CRF。

<a id="nlp-2-detail-17"></a>
### 4.2 前向动态规划计算配分函数

定义 $`\alpha_1(k)=b_k+E_{1,k}`$，对后续位置递推 $`\alpha_t(j)=E_{t,j}+\mathrm{LSE}_i[\alpha_{t-1}(i)+A_{i,j}]`$，最后 $`\log Z=\mathrm{LSE}_j[\alpha_T(j)+e_j]`$。每个状态汇总以该标签结尾的所有前缀路径，因此不需要显式枚举 $`K^T`$ 个完整序列。时间复杂度为 $`O(TK^2)`$，若只求配分函数，可以只保存上一层状态。

递推的正确性来自路径分解：任何以当前标签 $`j`$ 结束的合法前缀，都有唯一的前一标签 $`i`$；将所有前一状态的前缀分数乘以对应转移权重再求和，恰好覆盖全部且不重复。对数域使用 log-sum-exp 只是数值稳定的表示，不改变求和语义。把求和换成最大值则变成另一种问题，即最佳路径搜索。

<a id="nlp-2-detail-18"></a>
### 4.3 负对数似然和期望计数梯度

一条监督路径的负对数似然为 $`L=\log Z-S(y^*,x)`$。对于某个发射分数，梯度是模型在该位置选择该标签的边缘概率减去金标准指示量；对于转移分数，梯度是模型期望的转移出现次数减去金标准转移次数。这个形式解释了训练为何同时抬高正确路径并抑制竞争路径，而不是只把每个位置独立推向目标标签。

当全部转移、开始和结束分数为零且没有结构约束时，路径概率可以分解成独立位置 softmax，配分函数也分解为各位置配分函数的乘积。此时 CRF 退化为独立分类。加入转移可以表达局部标签依赖，但不能自动表达任意长程约束，例如两个相距很远的实体必须指代同一对象。若要加入这类结构，需要扩展状态、修改图结构或采用额外机制。

<a id="nlp-2-detail-19"></a>
### 4.4 Viterbi 与边缘最大化不同

Viterbi 递推把前向公式中的 log-sum-exp 换成最大值，并保存最佳前驱索引，最后从最优结束状态回溯。它得到联合概率最大的完整路径。逐位置选择边缘概率最大标签则最小化某类逐位置期望错误，但拼接结果未必是概率最大的路径，甚至可能违反结构约束。最优输出依赖评价损失，不存在一种解码器对所有任务都最优。

实体 F1 是非局部指标，最大联合概率路径也不一定最大化期望实体 F1。实际项目常用 Viterbi 因为定义明确且计算高效，但应认识到训练似然、最佳路径与实体指标之间存在差距。研究时可以比较约束独立分类、CRF 和其他结构方案，但必须保持编码器、数据、资源和评价器一致，才能讨论转移建模带来的贡献。

<a id="nlp-2-detail-20"></a>
### 4.5 实验三：枚举、前向、Viterbi 和梯度互相核对

下面使用三个标签 O、B-X、I-X，三个位置信息，以及严格 IOB2 开始与转移约束。样本很小，可以枚举所有路径作为独立参照。真实长序列不应这样枚举；这里的指数级实现只是用于检验动态规划和转移方向，避免程序运行了却悄悄使用了转置的转移矩阵。

```python
import itertools
import torch

torch.set_num_threads(1)
dtype = torch.float64
emission = torch.tensor([[0.2, 0.6, -0.4], [0.1, -0.2, 0.8],
                         [0.7, 0.0, 0.3]], dtype=dtype, requires_grad=True)
transition = torch.tensor([[0.1, 0.2, -0.3], [0.0, -0.1, 0.4],
                           [0.2, 0.1, 0.3]], dtype=dtype, requires_grad=True)
legal_start = torch.tensor([True, True, False])
legal_transition = torch.ones((3, 3), dtype=torch.bool)
legal_transition[0, 2] = False
masked_a = transition.masked_fill(~legal_transition, -torch.inf)
start = torch.zeros(3, dtype=dtype).masked_fill(~legal_start, -torch.inf)
end = torch.tensor([0.0, 0.1, -0.1], dtype=dtype)

def path_score(path):
    value = start[path[0]] + emission[0, path[0]]
    for t in range(1, len(path)):
        value = value + masked_a[path[t-1], path[t]] + emission[t, path[t]]
    return value + end[path[-1]]

paths = [p for p in itertools.product(range(3), repeat=3)
         if legal_start[p[0]] and all(legal_transition[p[t-1], p[t]] for t in range(1, 3))]
scores = torch.stack([path_score(p) for p in paths])
log_z_enum = torch.logsumexp(scores, 0)
alpha = start + emission[0]
for t in range(1, 3):
    alpha = emission[t] + torch.logsumexp(alpha[:, None] + masked_a, dim=0)
log_z = torch.logsumexp(alpha + end, 0)
assert torch.allclose(log_z, log_z_enum)

delta = start + emission[0]
backpointers = []
for t in range(1, 3):
    best, indices = (delta[:, None] + masked_a).max(dim=0)
    backpointers.append(indices)
    delta = best + emission[t]
last = int(torch.argmax(delta + end))
decoded = [last]
for pointer in reversed(backpointers):
    decoded.append(int(pointer[decoded[-1]]))
decoded.reverse()
assert tuple(decoded) == paths[int(torch.argmax(scores))]

gold = (1, 2, 0)
loss = log_z - path_score(gold)
loss.backward()
probability = torch.softmax(scores.detach(), dim=0)
expected = torch.zeros_like(emission)
expected_a = torch.zeros_like(transition)
for weight, path in zip(probability, paths):
    for t, k in enumerate(path):
        expected[t, k] += weight
    for i, j in zip(path, path[1:]):
        expected_a[i, j] += weight
for t, k in enumerate(gold):
    expected[t, k] -= 1
for i, j in zip(gold, gold[1:]):
    expected_a[i, j] -= 1
assert torch.allclose(emission.grad, expected)
assert torch.allclose(transition.grad, expected_a)
assert torch.isfinite(loss) and torch.isfinite(emission.grad).all()
assert transition.grad[0, 2] == 0
print("合法路径", len(paths), "最优路径", decoded, "NLL", float(loss.detach()))
```

实验同时核对了全路径概率、全局最优路径和两类梯度。若只检查损失下降，转移方向错误仍可能在训练时被部分补偿；独立枚举能更直接地定位定义差异。对批量变长序列还应增加长度一、全部填充拒绝、不同长度掩码和金标准非法路径等测试，不能把这个三位置例子当成完整生产实现。

<a id="nlp-2-detail-21"></a>
### 4.6 变长、掩码和数值边界

批量 CRF 常把序列填充到共同长度。掩码应在无效位置保留前一前向状态，不再加入发射和转移；结束分数应只加在最后有效标签上。金标准路径分数也要使用相同掩码。若把填充当成 O 标签参与训练，模型会学习大量无关的 O 到 O 转移，且短序列受到不同程度的额外监督。

约束过严可能导致一个样本没有任何合法路径，使配分函数为负无穷，损失或梯度无定义。训练前应检查标注是否符合规范、约束是否与标签集合一致，并对非法输入明确报错。用一个很大的负数代替负无穷只是数值近似，极端分数仍可能让非法路径获得概率；若使用这种近似，应说明限制并验证边界。

<a id="nlp-2-detail-22"></a>
### 4.7 前向后向与位置边缘的手算思路

前向量汇总当前位置之前的路径，后向量则汇总当前位置之后的路径。令 $`\beta_T(k)=e_k`$，递推 $`\beta_t(i)=\mathrm{LSE}_j[A_{i,j}+E_{t+1,j}+\beta_{t+1}(j)]`$。由于当前位置发射已包含在前向量中，后向量不能再重复加入它。于是标签边缘可写为 $`P(y_t=k\mid x)=\exp[\alpha_t(k)+\beta_t(k)-\log Z]`$，对所有合法标签求和应为一。

相邻标签的联合边缘由前一位置前向、当前转移、当前发射和当前后向相加再减去配分函数得到。把这些边缘在所有位置上求和，就得到转移的期望出现次数。这和实验中枚举所有路径后按概率加权计数的结果相同。一个实现可以先在小样本上比较二者，再用于更长序列；这种独立推导比仅仅依赖自动微分返回了某个梯度更有解释力。

用两个位置、两个标签的例子即可手算验证。设每条路径的未归一化权重依次为一、二、三、四，配分函数就是十。第一位置为第一标签的边缘是权重一与二之和，即十分之三；第二位置为第一标签的边缘是十分之四。联合最优路径来自权重四，而某个位置的边缘来自多条路径共同贡献。这个例子还提醒读者，不能把一条路径的归一化概率与该路径上各个边缘概率简单相乘。

<a id="nlp-2-detail-23"></a>
### 4.8 局部归一化、全局归一化与约束比较

逐位置独立 softmax 不利用标签间转移；局部条件转移模型可能在给定前一状态后对下一状态归一化；链式 CRF 则对整条路径全局归一化。这些目标的条件依赖和竞争方式不同。全局归一化允许来自整个输入的分数参与路径竞争，但不意味着任何任务上都必然优于局部模型。输入编码器已经很强、数据有限或结构约束较弱时，可学习转移的额外收益可能很小。

公平比较可以逐层增加因素：先固定编码器做独立分类，再加入仅解码约束，然后加入训练时也一致的结构空间，最后加入可学习转移。每一步都保持相同划分、标签对齐和调参预算，才能判断改善来自合法性、全局目标还是参数容量。若一个系统使用更大的编码器和更多外部数据，另一个只用局部特征，那么结果并不能单独归因于 CRF。

还应检查标注规范是否适合链式假设。嵌套实体、重叠实体和不连续实体，通常不能由一个普通 BIO 序列完整表达；强行选择一个层级会改变任务。可以改用跨度分类、多层标签或图结构，但需要重新定义候选、损失和匹配方式。数据中的复杂结构不是解码小技巧可以消除的问题，必须在输出空间设计时正面处理。

<a id="nlp-crf-map-marginal"></a>

### 4.9 联合最优与逐位置最优可以明确分离

可以用两位置、两标签的完整概率表，把两种最优性手算出来。令 $`P(00)=0.35`$、$`P(01)=0.30`$、$`P(10)=0.01`$、$`P(11)=0.34`$，四项非负且总和为一。联合概率最大的路径是 $`00`$。第一位置的边缘为 $`P(y_1=0)=0.65`$，第二位置为 $`P(y_2=1)=0.64`$，因此逐位置边缘最大解却是 $`01`$。这个表可以由长度二的链模型表示，不需要长程依赖才会出现差异。

![两位置路径质量的逐列求和与逐列取最大，分别用于前向归约和 Viterbi](images/02-img-path-sum-vs-max.webp)

[打开原图放大](images/02-img-path-sum-vs-max.webp)

**把四格概率展开成真实路径。** 图将原联合概率整体乘一百，列出未归一化路径质量 $`M=\begin{pmatrix}35&30\\1&34\end{pmatrix}`$；行是第一位置标签，列是第二位置标签。可令第一位置的两种初始质量都为一、第二步转移分数为 $`\log M_{ij}`$，构成同一个两位置 CRF。四格中的 35、30、1、34 是正势函数乘积，不是每个节点出边已经归一化的转移概率。

**前向求和与 Viterbi 逐步分开。** 求分区函数时，进入第二位置标签零的质量相加为 $`35+1=36`$，进入标签一的质量为 $`30+34=64`$，再相加得到 $`Z=100`$。求最佳路径时，对相同前驱集合改取最大值，得到 $`\max(35,1)=35`$ 与 $`\max(30,34)=34`$；比较终点后回溯到路径 `00`，概率为 0.35。两种动态规划访问同样的连接，但归约运算与需要保存的信息不同；若只保存前向总质量，就不能从 36 这个数恢复究竟哪个前驱最好。

**为什么逐位最大又得到 `01`。** 第一位置边缘是 $`(0.65,0.35)`$，第二位置边缘是 $`(0.36,0.64)`$，各自取最大拼成 `01`，其联合概率却只有 0.30。下面的风险计算解释了这不矛盾：整串零一损失与逐位错误数对应不同最优决策。实际实现通常在 log 域把前向“相加”写成 log-sum-exp、把 Viterbi 写成 max 加回溯索引，以避免长链质量连乘下溢。图中的势函数与条件分布定义可对照 Sutton 与 McCallum 的 CRF 教材。

若评价的是整条序列是否完全正确，选择路径 $`\hat y`$ 的期望零一错误为 $`1-P(y=\hat y)`$，所以 $`00`$ 的风险为 $`0.65`$，优于 $`01`$ 的 $`0.70`$。若评价两个位置错误数的和，$`00`$ 的风险是 $`0.35+0.64=0.99`$，而 $`01`$ 为 $`0.35+0.36=0.71`$。同一个模型分布，没有谁在所有损失下都更优；差异来自决策目标，而非概率计算发生矛盾。

上例允许所有路径。存在硬约束时，独立选择每个位置的最优边缘还可能拼出非法路径。此时不能先得到非法结果再宣称它是约束空间的最优解；若要最小化约束下的期望位置错误，可以把每位置选择标签的代价设为 $`1-P(y_t=k\mid x)`$，在合法链上用动态规划最小化代价之和。它与 Viterbi 的图结构相同，局部分数却由边缘风险定义，通常不再等于原路径的联合对数概率。

因此项目选解码器时应写出预测损失。对实体 F1 这类集合指标，逐位置风险求和也未必成立；不能把上述代价替换直接当成任意结构指标的通解。它展示的是“先明确风险，再推导解码”的方法，比把所有结构预测都归为“选最大概率”更能指导后续扩展。

## 5. 指标、平均方式与不确定性

<a id="nlp-2-detail-25"></a>
### 5.1 分类混淆矩阵和错误结构

混淆矩阵保留真实标签与预测标签的联合计数。精确率以预测正类为分母，召回率以真实正类为分母，二者回答不同问题。某个模型可以通过极少报正类获得很高精确率，同时遗漏多数目标；也可以通过大量报正类提高召回却使复核成本过高。应在固定阈值下同时报告计数与比例，尤其不能在分母很小时只展示看似完美的百分比。

当类别分布变化时，精确率通常会随基率改变，不能直接把一个数据集的精确率当作部署保证。即使条件召回和假阳性率保持不变，正类更稀少时，假阳性也可能占据多数正类预测。需要用部署基率和成本重新分析行动方案，并检查条件分布是否也发生变化，不能只靠校正一个先验就假设所有漂移都解决。

<a id="nlp-2-detail-26"></a>
### 5.2 宏、微、样本与文档平均

微平均先汇总所有计数再求比值，偏向数量多的类别或单位；宏平均先求每类指标再等权平均，突出类间均衡，但稀有类估计可能不稳定。逐文档平均使每篇文档权重相同，与把长文档所有 token 汇总的指标不同。没有一种平均方式天然最公平，关键在于它代表的目标总体是否与应用一致。

空分母必须固定约定。没有预测正类时精确率如何定义，没有金标准实体时召回如何定义，整个测试无实体时 F1 怎么处理，都会影响小切片结果。工具提供的默认值只是实现约定，应记录并在报告中解释。对很小的群体切片，展示原始计数往往比只给三位小数更有信息。

<a id="nlp-macro-micro-rank-reversal"></a>

### 图解：宏微 F1 如何反转系统排序

![两套系统的混淆矩阵及其宏微 F1，微 F1 偏向 A，宏 F1 偏向 B](images/02-img-macro-micro-rank-reversal.webp)

[打开原图放大](images/02-img-macro-micro-rank-reversal.webp)

把平均方式写成两张完整混淆矩阵，比只说“微平均偏向常见类”更容易检验。测试集有 90 条常见类和 10 条稀有类文本；每条恰有一个标签、一个预测。图中行是真实类别，列是预测类别，两套系统评价完全相同的文本和标签集合：

```math
C_A=\begin{pmatrix}90&0\\10&0\end{pmatrix},
\qquad
C_B=\begin{pmatrix}80&10\\2&8\end{pmatrix}.
```

先把每个类别当作正类，其余类当作负类。对类别 $`c`$，

```math
F_{1,c}=\frac{2TP_c}{2TP_c+FP_c+FN_c}.
```

A 的常见类有 $`TP=90,FP=10,FN=0`$，故 F1 为 $`\frac{180}{190}=\frac{18}{19}`$；稀有类有十个漏报，F1 为零。虽然从来没有预测稀有类，其 F1 分母仍非零，不能因“没有预测”把这一类从平均中删掉。A 的宏 F1 为 $`\frac9{19}\approx0.473684`$。

B 的常见类为 $`(TP,FP,FN)=(80,2,10)`$，稀有类为 $`(8,10,2)`$，所以

```math
\begin{aligned}
&F_{1,\mathrm{macro}}(B)
=\frac12\left(\frac{160}{172}+\frac{16}{28}\right)\\
&\quad =\frac{226}{301}\approx0.750831.
\end{aligned}
```

A 多猜对两条总体文本，B 却在类等权指标下明显更好。这个排名变化不需要改变任何预测或阈值，来自两个评价目标给错误的相对权重不同。

再证明本例的微 F1 为什么等于准确率。设正确条数为 $`C`$、错误条数为 $`E`$。单标签且评价所有互斥、穷尽类别时，每个正确样本贡献一个 TP；每个错误样本向预测类贡献一个 FP、向真实类贡献一个 FN。因此

```math
F_{1,\mathrm{micro}}
=\frac{2C}{2C+E+E}
=\frac{C}{C+E}.
```

A、B 分别得到 $`0.90`$ 和 $`0.88`$。该恒等式需要“全部类别、每条一个预测”的条件，不能直接推广到多标签、只评价某个正类子集或允许拒答且改变分母的任务。scikit-learn 的 F1 官方定义分别规定先汇总计数的 micro 与逐类 F1 等权的 macro；宏 F1 不是“宏精确率与宏召回率再取调和平均”。

**如何用于文本任务？** 若常见意图对应大部分线上请求，文本等权风险可能有明确业务意义；若每个意图都必须可用，宏平均能暴露稀有类失败，但十个稀有样本的估计仍不稳定。可以并列给出两类结果与原始计数，不能从一次排名反转推导哪一种平均绝对公平。实体抽取还需先按跨度和类型做匹配，再谈 TP、FP、FN；不能把这里的“文本单标签错误”直接替换成 token 准确率。

**检验问题。** 若只保留“稀有类为正类”的二分类 F1，A 为零、B 为 $`\frac47`$；若把标签编号对调，宏微分数都不变，但指定正类的接口参数必须同步改变。这是检查标签映射、类别集合和平均约定的简洁测试。

<a id="nlp-2-detail-27"></a>
### 5.3 配对评价和独立重复单位

比较两个系统应在相同样本上做配对分析。如果按文档重采样，就对每次抽到的文档同时重取两个系统的预测，再重新计算整体指标。F1 这类非线性指标不能简单把每篇文档 F1 的差当成微平均 F1 差，除非明确目标本来就是逐文档平均。若同一来源或事件内高度相关，应以组为单位重采样，并说明组数有限的限制。

训练种子、数据抽样和人工判断分别产生不同不确定性。多个种子重复不能代替跨来源数据，多个评价者也不能代替独立任务样本。报告应该说明置信区间针对哪一层随机性，是否把模型当成固定，是否包含重新选择超参数的过程。一个很窄但建立在错误独立性假设上的区间，可能比不提供区间更容易误导。

## 6. 生成目标：教师强制、解码与概率单位

<a id="nlp-2-detail-29"></a>
### 6.1 自回归似然和掩码

条件生成将目标序列概率分解为 $`P(y\mid x)=\prod_tP(y_t\mid x,y_{\lt t})`$，训练负对数似然是有效目标位置的交叉熵之和或平均。教师强制给每步提供真实前缀，而部署时前缀来自模型自己的输出。两者的输入分布不同，因此低教师强制损失不保证多步生成可靠，尤其在早期错误会改变后续语境时。

训练中提示部分、特殊分隔符和填充位置是否计算损失，需要清楚说明。只在答案部分监督与同时预测输入文本，优化的权重分布不同；按 token 平均与先按样本平均，又会改变长答案的相对权重。不能只写“使用交叉熵”而不说明掩码和归约方式。对空答案、全部忽略位置和被截断目标，应有明确拒绝或处理策略。

<a id="nlp-2-detail-30"></a>
### 6.2 贪心、束搜索和采样的目标

贪心每步取最大条件概率，不保证得到整条序列概率最大的输出。束搜索保留若干前缀近似探索更大的候选集合，但仍受束宽、长度惩罚和停止规则影响；概率最大的完整文本也不一定最符合事实或人类偏好。采样可以增加多样性，温度和截断规则则改变输出分布，不能把不同设置的结果混成一个不加说明的模型成绩。

同一输入生成多个候选再挑最好，属于额外的选择资源。如果根据参考答案挑选，得到的是上界式诊断而不是可部署系统；如果使用独立评价器挑选，应把评价器成本和偏差纳入系统。比较方法时需要固定每题候选数量、最大长度、停止条件和调用预算，并区分一次生成表现与多次尝试成功率。

<a id="nlp-2-detail-31"></a>
### 6.3 困惑度与答案质量的边界

困惑度是平均负对数似然的指数，其单位依赖分词器和计数规则。即使同一分词器上困惑度降低，也主要说明模型更能预测参考文本，而不是保证每个生成事实都正确。高概率模板、常见措辞和长度分布都可能影响这个数。生成评价应把概率、措辞相似、事实正确和实际任务完成分开观察。

在开放任务中，参考答案可能只有许多合理表达中的一个。模型为另一个有效表达分配较高概率，却可能在单参考似然或词面指标上不占优势；反过来，复述参考中的错误也可能得高分。应检查数据本身的真实性和参考覆盖，必要时将任务改写为可核实事实或约束集合，再结合人工判断。

## 7. 词面生成指标：BLEU、ROUGE 与约定

<a id="nlp-2-detail-33"></a>
### 7.1 修正 n-gram 精确率和长度惩罚

BLEU 使用候选 n-gram 的计数，并按参考文本中的最大可匹配计数裁剪，避免重复一个常见词就获得无限匹配。不同阶数精确率取加权几何平均，再乘长度惩罚。标准形式的长度惩罚在候选较短时为 $`\exp(1-\frac{r}{c})`$，候选长度不少于参考有效长度时为一。多参考时有效参考长度的选择和计数上限都需要明确。

一个候选不断重复“的”，普通未裁剪匹配可能被夸大，而修正计数限制了它从参考获得的信用。如果高阶匹配为零，无平滑几何平均就为零；句级评价常采用平滑，但不同平滑方式会产生不同数值。因此报告应包含分词、大小写、最高阶数、平滑、多参考长度选择和语料聚合方式，不能把任何一个库返回的数字都笼统视为可直接比较的 BLEU。

![完全匹配、短而精确、等长但少一词匹配三种候选的 BLEU-1](images/02-img-bleu-length-comparison.webp)

[打开原图放大](images/02-img-bleu-length-comparison.webp)

为单独展示长度惩罚，图中明确采用只含一元精确率、权重为 1 的 BLEU-1，并按空格分词、仅使用一条参考。参考长度为 4，短候选“the cat”长度为 2，修正一元精确率虽为 1，$`BP=\exp(1-\frac{4}{2})=\exp(-1)`$，得分约为 0.368；完整参考得 1，等长但最后一词不同的候选得 0.75。它没有计算标准多阶 BLEU，也不证明该分数等同于事实质量；加入高阶匹配、句级平滑或多参考后，应重新按明确约定计算。

<a id="nlp-2-detail-34"></a>
### 7.2 ROUGE 与最长公共子序列

ROUGE 常用于观察参考内容覆盖，但它有多个变体和不同聚合约定。基于 n-gram 的召回侧重参考片段有多少在候选里出现；基于最长公共子序列的方法考虑保持相对顺序但允许中间跳过的匹配。精确率、召回率与调和形式的组合可以反映不同偏好，实际实现还可能涉及句子边界、分词和词干化。

最长公共子序列与最长连续子串不是一回事。“甲 乙 丙”和“甲 丁 乙 戊 丙”的公共子序列可长达三，但没有长度三的连续公共片段。它能容忍插入，却仍不验证事实和逻辑。把实体、时间或否定替换以后，文本可能保留大部分词面结构，因此高重叠只能作为一个证据渠道，不能替代事实核验。

<a id="nlp-2-detail-35"></a>
### 7.3 实验四：重复裁剪、零匹配与事实反例

以下实现只定义一个单参考、最高二元组、无平滑的语料级教学 BLEU，不冒充所有库默认设置。同时计算一个简单 LCS 长度，展示顺序匹配与连续匹配的差异。输入是已经按空格切好的人工 token，因此不涉及外部分词器或真实翻译质量结论。

```python
from collections import Counter
import math

def ngrams(tokens, n):
    return Counter(tuple(tokens[i:i+n]) for i in range(max(0, len(tokens)-n+1)))

def corpus_bleu2(pairs):
    matched, total = [0, 0], [0, 0]
    candidate_length = reference_length = 0
    for candidate, reference in pairs:
        candidate_length += len(candidate)
        reference_length += len(reference)
        for n in (1, 2):
            c, r = ngrams(candidate, n), ngrams(reference, n)
            matched[n-1] += sum((c & r).values())
            total[n-1] += sum(c.values())
    if candidate_length == 0 or any(t == 0 or m == 0 for m, t in zip(matched, total)):
        return 0.0
    bp = math.exp(min(0.0, 1-reference_length/candidate_length))
    return bp * math.exp(sum(math.log(m/t) for m, t in zip(matched, total))/2)

def lcs(a, b):
    previous = [0] * (len(b)+1)
    for token in a:
        current = [0]
        for j, other in enumerate(b, 1):
            current.append(previous[j-1]+1 if token == other else max(previous[j], current[-1]))
        previous = current
    return previous[-1]

assert corpus_bleu2([("甲 乙 丙".split(), "甲 乙 丙".split())]) == 1.0
assert corpus_bleu2([("甲 甲 甲".split(), "甲 乙 丙".split())]) == 0.0
assert sum((ngrams(["甲"]*4, 1) & ngrams(["甲", "乙"], 1)).values()) == 1
assert lcs("甲 丁 乙 戊 丙".split(), "甲 乙 丙".split()) == 3
reference = "甲 公司 已经 支付 乙 公司 款项".split()
wrong = "甲 公司 尚未 支付 乙 公司 款项".split()
score = corpus_bleu2([(wrong, reference)])
assert score > 0.5
print("改变支付事实后二元 BLEU 仍为", round(score, 6))
```

最后一个断言并不说明 BLEU 实现失败。它准确反映了大部分局部片段相同，而任务所关心的支付事实却相反。指标只测量其定义中的对象。若应用需要核实付款状态，应增加事实槽位或证据判定；若任务研究措辞接近程度，词面重叠仍有价值。错误在于把一个局部相似度数字解释为它从未定义过的事实保证。

<a id="visual-mechanism-nlp-02"></a>

### 图解：词面重复需要按参考次数裁剪计数

![候选重复三次的甲只获参考文本提供的一次匹配额度](images/02-img-clipped-unigram-match.webp)

[打开原图放大](images/02-img-clipped-unigram-match.webp)

**把裁剪落实到计数。** 沿用实验四的候选“甲 甲 甲”和参考“甲 乙 丙”，两个文本都长三。候选有三个一元词实例，但参考只能提供一次“甲”的匹配额度，所以裁剪计数是 $`\min(3,1)=1`$，一元修正精确率为 $`\frac13`$。图中的竖线只是显示这份匹配额度，不要求匹配词必须处于相同位置。

**继续检查相邻组合。** 候选的两个二元词对都是“甲甲”，参考的二元词对则是“甲乙”和“乙丙”，没有相同项，因此二元精确率为 $`\frac02=0`$。等长使长度惩罚为一，但不做平滑、两阶等权时
```math
\mathrm{BLEU}_2
=1\cdot\sqrt{\frac13\cdot0}=0.
```
由此可以区分两种失败：重复出现的单词不能重复得分，而高阶相邻结构也没有因为单词“都见过”就自动匹配。这与前面的 BLEU-1 长度惩罚图互补，后者故意只计算一元项。

这是单一候选、单一参考的教学计算。语料 BLEU 先跨样本累计各阶裁剪计数和分母，再取几何平均，不能平均句子 BLEU；句级平滑会改变这里的零值，应报告具体规则。计数裁剪和原论文中的重复词反例见 Papineni 等的 BLEU 论文第 2.1 节。词面匹配仍不直接判定事实或语义正确性。

## 8. 语义评价、事实评价与人工判断

<a id="nlp-2-detail-37"></a>
### 8.1 语义相似不等于事实蕴含

嵌入相似度可能把同主题、同实体且句式相近的文本判得很近，包括立场相反和数字不同的句子。事实评价需要核对主语、关系、宾语、时间、数量、条件和否定范围。对一条复杂回答，可以先拆成可核实的原子主张，再检查每条是否被证据支持、反驳或无法判断，最后根据任务定义汇总，而不是让一个相似度覆盖全部推理。

原子化本身也有歧义。把一个错误事实拆成许多正确的小片段，可能人为提高正确率；把所有信息合成一个超长主张，又可能因一个细节错误使整个回答归零。应预先规定分解单位和重要性权重，并对不同系统一致使用。覆盖与正确也应分开：一个只说一条正确常识的回答可能很准确，却遗漏用户要求的关键内容。

<a id="nlp-2-detail-38"></a>
### 8.2 人工评价需要可重复的规则

人工评价应给出具体标准、示例和不可判定规则，尽量隐藏系统身份并随机化展示顺序。如果让评价者总先看同一个系统，位置偏好可能影响结果；如果先展示参考答案再评价自由表达，评价者可能过度依赖词面一致。应根据目标设计独立事实判断或成对偏好，并记录平局、弃权和证据不足，而不是强迫每题都选出赢家。

评价者分歧不是简单噪声垃圾。有时它暴露任务规范不清、证据不足或不同用户偏好。可以统计一致性并复核高分歧样本，但不应只删除所有分歧样本后声称任务已经客观。若需要多数票，应解释票数、评价者来源与裁决方式；若应用本来有多种合理偏好，应报告分布而不是压成一个唯一标签。

<a id="nlp-2-detail-39"></a>
### 8.3 自动评价器的独立性与顺序

使用另一个模型判断质量时，评价器也会受提示、版本、上下文长度、答案顺序和文风影响。更长的回答可能获得更多表面上的完整感，却也可能包含更多错误；和评价器相似的措辞可能获得偏好。应通过交换顺序、同答案重复、自相矛盾对照和已知事实反例检查稳定性，并用人工样本校准适用范围。

把评价器用于模型选择后，再用相同评价器宣布最终胜利，结论可能更接近“适应了这个评价器”。应尽可能保留独立评价标准和确认集，报告模型选择是否已经针对评价器优化。评价器输出的置信度不是自动真实概率，若没有经过校准，不能据此替代对事实证据和分歧样本的人工复核。

<a id="nlp-2-detail-40"></a>
## 9. 数据质量、污染和完整实验协议

<a id="nlp-2-detail-41"></a>
### 9.1 重复、模板和来源捷径

精确重复只是最容易发现的一类污染。轻微改写、同一模板替换实体、同一事件的多篇转述，都可能跨集合传播。对于文本分类，这会让模型记住格式；对于实体识别，可能让模型记住名称和固定上下文；对于生成，可能直接见过参考答案。检测需要结合规范化哈希、近重复相似度和来源元数据，同时避免过强去重把独立业务事件误合并。

必须先定义划分目标，再定义去重策略。若目标是处理同一已知模板的新实例，模板共享可能是允许条件；若目标是泛化到新模板，就应按模板分组。研究者不能先观察某种划分成绩很好，再反过来声称它代表全部泛化。清楚描述部署情景比给数据集贴上干净或污染两个字更有帮助。

<a id="nlp-2-detail-42"></a>
### 9.2 训练、选择、校准和最终确认

分类器参数、结构转移和语言模型权重在训练数据上学习；模型种类、阈值、解码参数和评价提示在允许的选择数据上确定；最终确认数据用于冻结后的评价。需要概率校准时，还应为校准留出独立信息，或者在交叉拟合方案中清楚说明预测的产生方式。各阶段可以采用严谨的重用设计，但不能把同一批结果既当作选择依据又当作独立确认。

端到端比较应固定数据权限和资源预算，包括外部模型、候选次数、检索库、人工规则、标注成本和推理延迟。若新方法获得更多外部信息，应诚实地把它报告为完整系统条件差异，而不是隐藏后再把提升归给某一个网络层。公平不要求所有系统结构相同，但要求比较的问题和可用资源明确。

<a id="nlp-2-detail-43"></a>
### 9.3 一个报告应允许读者重建什么

读者应能够从报告重建输入如何得到输出、输出如何得到指标，以及哪些数据参与了每次选择。至少需要任务规范、划分单位、样本计数、标签分布、预处理和对齐、损失归约、解码规则、评价实现与关键参数。对失败样本应展示匿名化的最小必要证据和错误分类，避免只给成功截图。

同时应区分代码通过、人工例子符合预期和真实任务有效这三种证据。本章实验只验证数学机制与实现约定，不生成任何真实应用成绩。后续实践章会将管线连接起来，但人工小数据上的高分仍只用于检验流程。要证明真实质量，需要合法来源的代表性数据和与部署一致的评价设计。

<a id="nlp-2-detail-44"></a>
### 9.4 拒答、置信度和覆盖率应联合报告

当系统允许拒答或交给人工处理时，只评价被接受样本的准确率会产生选择效应。模型可以通过只回答最简单的一小部分，把选择后准确率提高得很好看。因此需要同时报告覆盖率，即自动处理的样本比例，以及该覆盖率下的错误或代价。不同系统应在相同覆盖条件或相同成本约束下比较，不能把回答百分之十的系统与回答全部样本的系统直接按准确率排名。

拒答规则也需要验证数据确定。最大 softmax、路径概率和生成平均似然都不是天然可比的通用置信度；序列越长，完整路径概率通常越小，多个候选高度相似也可能产生较高局部确定性而事实仍错。应根据目标错误定义校准规则，并检查来源、长度和类别切片。把不熟悉来源全部拒答可能降低平均风险，却会把某些用户长期排除在服务之外，需要在目标中明确这种代价。

实体抽取的置信度尤其需要注意匹配单位。一条路径概率高，不代表其中每个实体都同样可靠；一个实体可能由多个 token 和边界决策共同构成。若要按实体筛选，应定义可复核的实体分数并在独立数据上验证精确率覆盖关系。不能把一个字符的最高概率直接贴给整个长实体，再把它解释为实体正确的概率。

<a id="nlp-2-detail-45"></a>
### 9.5 暴露偏差、长度偏好与可检验的改进

教师强制与自身生成前缀的差异常被称为暴露偏差，但实际生成失败还可能来自数据质量、搜索目标、知识缺失和任务规范。不能观察到长答案错误多，就把全部原因归给这一机制。可在固定任务上逐步替换前缀，比较真实前缀、模型前缀和受控错误前缀下的下一步分布，观察错误是否因历史偏移持续放大。这样的诊断比一个抽象术语更接近机制证据。

采用混合前缀、序列级奖励或偏好优化时，也会改变训练分布与目标。自生成前缀可能引入新的标注不一致，奖励可能鼓励讨好评价器，偏好数据可能混合事实、文风和长度因素。提出改进时，应说明它试图缓解哪一种具体问题，并安排能够区分替代解释的实验。若所有变化同时发生，就只能报告完整方案效果，不能把提升全部归给某个单独技巧。

长度惩罚和停止规则同样应冻结。过短答案容易漏项，过长答案可能重复或增加无证据内容。按平均对数概率选择会引入不同于总对数概率的偏好，固定最大长度又可能强制截断结论。应同时报告长度分布、提前停止、截断、重复和事实覆盖，避免一个只靠缩短回答取得更高精确率的系统被误认为全面改善。

<a id="nlp-2-detail-46"></a>
### 9.6 标签噪声、歧义和有效监督量

人工标签可能因录入、规范理解和证据不足而出错。训练损失长期集中在少数样本上，可以作为检查信号，却不能自动判定这些样本就是坏标签；它们也可能代表罕见但重要的语言现象。应在不知道模型身份的条件下复核，并区分确实错误、合理分歧和超出规范三类情况。只删除模型难以学习的样本，会让测试越来越接近模型偏好而非真实需求。

序列标注的数据量也不应只报 token 总数。大量背景 token、重复模板和相同实体的反复出现，可能只提供有限的新监督。应同时报告文档数、来源数、实体数、类型覆盖、长度分布和独立实体字符串数量。对生成任务，答案条数之外还需观察独立问题、事实主题与参考多样性。研究者需要理解有效变化来自哪里，而不是用一个巨大的位置计数替代统计独立信息。

如果最终数据包含无法裁决的歧义，可以保留软分布、多参考或专门的不可判定标签，但选择必须与任务行动连接。软标签并非把所有矛盾平均即可，它需要合理的概率来源和明确的训练解释。最终评价也应承认允许答案集合，而不是一边承认多解，一边仍按单一答案零一匹配宣称系统错误。

<a id="nlp-2-detail-47"></a>
### 9.7 从局部正确到端到端成功的概率边界

假设一个流程要求分类、抽取和回复事实全部正确，如果三者错误高度相关，就不能把三个总体正确率直接相乘得到端到端成功率。即使在某种条件独立假设下可以相乘，也需要使用与串联路径相符的条件概率，而不是分别在不同数据集上测得的边际结果。一个分类错误可能使后续抽取根本没有运行，组件测试中的输入分布也就不等同于实际流量。

可以在同一批冻结文档上保存各阶段输出，逐条检查失败最早发生在哪里，区分输入格式、分类路由、实体边界、检索证据和生成事实问题。多个错误同时出现时，可以报告多标签错误归因，或预先规定首次失败归因，但不能随结果选择最有利的解释。人工修正某个阶段后的上界实验有助于定位瓶颈，却不应被当作可部署系统的真实成绩。

完整验收还需要考虑目标用户是否能察觉和纠正错误。一个带明确证据和不确定提示的回复，与一个措辞自信但缺乏来源的回复，即使事实正确率相近，其使用风险也可能不同。验收应保留这些差异，不能让单一总分掩盖关键接口问题。这里不需要用模糊的综合质量分数掩盖差异，而应把证据覆盖、事实错误、拒答和人工复核成本分别记录，再按照实际任务约束决定接受标准。
