## 1. 生成任务首先是一份信息契约

<a id="nlp4-detail-2"></a>

### 1.1 输入、目标和允许知识分别是什么

文本生成不是统一的“根据提示写得好看”。摘要要求在压缩中保持给定原文的关键事实，翻译要求在语言转换中保持含义，基于资料的问答要求答案能够由允许证据支持，开放创作则可能允许虚构。若不先定义允许的信息范围，同一段流畅文字可能在一个任务中优秀，在另一个任务中构成无据新增。评价标准必须从任务契约推出，而不能在看到输出后临时决定。

一条样本至少包括来源身份、输入内容、问题或指令、参考目标、可见证据、标注规则和数据版本。来源身份不是装饰字段，同一报告生成的十个摘要或百个问答共享信息，不能因为字符串不同就当作独立来源。版本记录说明事实在什么时间有效，尤其对于政策、库存或研究结果，同一句话在不同时间可能具有不同真值。

还应区分世界事实与证据支持。真实世界中某命题可能正确，但给定资料没有提供它；若任务只允许依据资料，答案仍然越过了契约。相反，资料本身可能过时或有错，忠实复述与现实正确也不等价。研究可以分别评价来源忠实、外部事实与时间有效性，但不能把其中一个维度的通过当成全部通过。

<a id="nlp4-detail-3"></a>

### 1.2 指令学习到底在哪些位置计算损失

自回归模型通常通过当前位置的隐藏状态预测下一个 token。对序列 $`x_0,\ldots,x_{T-1}`$，手工实现可用位置零到倒数第二的 logits 对齐位置一到最后的目标。部分高层接口内部完成移位，若外部再移一次，会训练成预测隔一个 token。接口能运行不证明目标正确，应把一条短序列的输入位置、预测位置、目标位置和损失掩码打印成表。

只训练回答的指令微调中，提示和资料仍参与前向计算，但它们的目标位置通常不计入直接语言损失；回答与结束符计入，填充位置排除。忽略某位置的直接损失并不意味着该位置没有梯度路径，因为回答可能通过注意力依赖提示表示。需要区分 logits 上的局部梯度与共享参数、上下文表示上的间接梯度，不能把“提示标签设忽略”解释成模型不读取提示。

<a id="nlp4-detail-4"></a>

### 1.3 有效分母改变长短样本的权重

令有效目标掩码为 $`m_{it}`$，样本 $`i`$ 的有效数为 $`n_i=\sum_t m_{it}`$。对纳入目标的 $`N`$ 个样本，先假设每个 $`n_i>0`$，两种平均分别是

$$
\begin{aligned}
L_{\rm token}
&=\frac{\sum_i\sum_t m_{it}\ell_{it}}{\sum_i n_i},\\[6pt]
L_{\rm sample}
&=\frac1N\sum_{i=1}^{N}
\frac{\sum_t m_{it}\ell_{it}}{n_i}.
\end{aligned}
$$

第二式的分母随样本改变，因此先在每个样本内部归一化，再对样本求和。前者让有效目标更长的样本贡献更多，后者让样本等权。两者都可合理，但对应不同训练目标，不应因为默认 reduction 相同就混用。本章交叉熵实验没有设置类别权重，忽略标签后的默认均值按未忽略的目标数归一化，见 [PyTorch 交叉熵定义](https://docs.pytorch.org/docs/2.10/generated/torch.nn.CrossEntropyLoss.html)。

梯度累积时也应对齐这个分母。把两个有效 token 数不同的微批损失各除二再相加，得到微批等权，不一定等于全局 token 等权。正确方式是在同一目标下累积有效损失和有效数，并保证缩放一致。全无效样本或微批应按规则跳过或报错，不能让零除零变成无声的非有限梯度。

<a id="nlp4-detail-5"></a>

### 1.4 截断、打包与结束符定义了实际任务

截断若删除回答所需证据，却保留确定答案，会制造无法根据输入完成的监督。删除回答结尾却没有标记截断，还可能把不完整输出当作正常结束。应分别统计输入证据被截、目标被截和无有效回答 token 的比例，并决定过滤、重新切片或重新生成目标。不能只把最大长度设得更大而不看哪些任务仍受影响。

把多个样本打包进同一序列可以提升吞吐，但需要决定后一个样本是否能注意前一个样本、位置编码如何处理、边界后的第一个目标是否参与损失。只插入结束符并不自动阻断跨样本注意力。若训练允许跨样本信息而部署没有，模型面对的信息条件已经变化。打包属于训练协议的一部分，应有独立的边界和掩码测试。

## 2. 数据质量：来源、去重与污染调查

<a id="sec-2-1"></a>

<a id="nlp4-detail-7"></a>

### 2.1 字符串相同只是最容易识别的一种关联

完全重复可以用内容散列快速识别，但改标点、改排版、换同义词和分段重组都会绕过逐字比较。同一新闻事件的多个转载、同一文档的多个片段、由同一答案模板生成的问题家族，也可能跨集合共享关键信息。去重需要同时利用内容相似度与来源元数据，而不是把某个文本散列列为唯一证据。

规范化可以统一某些字符形式和空白，但必须保留任务相关差别。把数字统一替换成占位符，可能把“增加百分之十”与“增加百分之九十”视为同一个事实；删除否定词可能把“批准”与“未批准”合并。可以为模板检测另建一种规范化视图，但事实判断必须保留原文。不同用途的视图应分开保存，不能为了去重方便直接破坏训练文本。

<a id="nlp4-detail-8"></a>

### 2.2 近重复阈值是带代价的分类规则

把文本转成词组或字符片段集合后，可用交并比等相似度筛选候选。阈值高会漏掉较强改写，阈值低可能误合并合法相近样本。应抽样检查阈值附近的正反例，分别估计漏合并与误合并，并按任务代价选择阈值。没有一个相似度数值能自动证明两个样本共享同一事实来源。

例如两份不同产品说明共享通用模板，却具有不同参数，内容相似不代表它们必须删除其中一个；若任务要学习参数抽取，这些差异可能正是有效监督。另一方面，同一报告被改写成不同措辞，即使相似度不高，也应按来源分组。去重的目的包括减少重复权重、隔离测试和控制记忆，各目的的动作可以不同。

<a id="nlp4-detail-9"></a>

### 2.3 近重复关系不一定传递

样本甲与乙相似、乙与丙相似，不代表甲与丙达到同一阈值。若用连通分量分组，会把相似链全部放在同一组，适合保守隔离泄漏，却可能出现巨大的模板组件。应报告组件大小分布并人工检查大组件，不要把图算法产生的分组当成天然的语义真值。

一种审计方式是保存每条连接的原因：完全重复、近重复阈值、同来源、同版本家族或人工确认。之后任何组件都能追溯连接链。若分组过大，可以改进候选规则或细分来源，但不能为了达到理想的训练测试比例，任意切断已确认共享答案的关联。数据隔离优先保证所声称的泛化单位。

![三个词集合相邻相似却端点不相似的连通分量反例](images/04-near-duplicate-chain.svg)

沿实验一最后三个集合，$`A=\{a,b\}`$、$`B=\{a,b,c\}`$、$`C=\{b,c\}`$。A、B 和 B、C 的交并比分别都是三分之二，超过零点六；A、C 只有共同元素 b，并集有三个，故相似度三分之一，未达阈值。图用两条实线表示真正建立的边，用虚线标出未建立的端点关系。

连通分量仍然把三者放在一起，因为 A 能经 B 到达 C。这个操作可以保证任何已确认连接都不会跨训练与测试，却不证明组件内任意两条文本都是近重复。特别要分开“同组件一起划分”与“只保留一个代表、删除其他数据”：前者是隔离约束，后者还可能损失 B、C 各自独有的事实，需要额外的内容与来源判断。组件突然变大时，应检查连边原因及模板链，而不是把组件标签直接当语义真值。

<a id="nlp4-detail-10"></a>

### 2.4 污染包括训练污染与开发污染

测试题进入训练语料是一种污染，测试回答被用于选择提示、解码参数、检索策略或停止轮数也会使测试参与开发。后者即使没有更新模型权重，仍然使用了测试信息。应设训练、开发、最终测试的职责边界，并保留测试访问与决策记录。多次观察测试分数后挑最好配置，不再是单次独立验收。

公开模型的预训练数据往往无法完全审计，不能仅凭高分认定记忆，也不能凭没有发现重复就排除污染。可以结合时间隔离、新编事实、来源去重、受控改写和答案位置扰动提供多方面证据。每种测试只排查部分机制，报告应区分已发现重叠、未检出重叠和无法确认，而不是把未知写成确定干净。

<a id="nlp4-detail-11"></a>

### 2.5 合成数据的生成器也属于来源

同一生成器和模板批量产生的样本可能共享推理模式、措辞偏好与隐藏缺陷。随机换实体名增加样本数，不等于增加等量独立任务。应按生成器版本、模板家族、基础文档与随机种子记录来源，测试中保留未见模板或真实样本，避免只验证模型能模仿同一生成流程。

合成目标还需要事实与格式审查。若生成器把错误答案稳定写进数据，后续训练可能把错误变得更流畅。基于程序可验证的任务适合用执行结果检查，但程序本身仍有覆盖边界；开放问答不能只检查字段存在。数据规模、可验证比例与人工复核抽样应一起报告，不能用规模代替质量证据。

## 3. 事实、覆盖和引用是三个不同维度

<a id="sec-1-1"></a>

<a id="nlp4-detail-13"></a>

### 3.1 词面相似为什么不足以判断事实

给定原文“试验没有提高产量，处理组平均十单位”，候选改成“试验提高产量，处理组平均一百单位”，大多数词仍然重合，核心命题却在否定与数字上错误。另一候选用“增产效果未被观察到，均值为十”表达同一事实，词面重合可能反而更低。词汇指标可以衡量某些形式相似，却不能独自承担事实支持判断。

正确使用自动指标的方法，是先确定它对哪些失败敏感，再加入针对性对照。把否定翻转、实体互换、数字变化、时间变化与正确改写分别构成小测试集，观察指标排序是否符合任务要求。不要因为一个指标与某个数据集人工分数相关，就把它解释为对所有事实错误都可靠。

<a id="nlp4-detail-14"></a>

### 3.2 将答案拆为可检验的原子命题

一段回答可以包含多个命题，例如某项目在某年启动、负责人是谁、预算多少。把它们拆开后，分别判断证据支持、证据矛盾或证据不足，比整段只给一个好坏标签更容易定位错误。但原子化本身也需要规则：复合句拆成几个、代词怎样消解、比较关系是否独立，都影响分母。

若长答案把一句事实反复改写十次，不能把重复命题当十次独立正确贡献。可以同时报告原始陈述数与去重命题数，对重复单独计冗余。若某命题含多个条件，应避免只证明其中一小部分就给整个命题支持。事实粒度的选择要在标注指南中给出正反例，并检查不同标注者是否一致。

<a id="nlp4-detail-15"></a>

### 3.3 支持精度不等于必要事实覆盖

设答案提出十个命题，其中九个有证据，支持精度为九成；如果任务要求的四个关键事实只覆盖其中一个，内容仍很不完整。反过来，答案覆盖全部关键事实，却新增多个无依据细节，覆盖高而支持精度低。应分别报告所说内容是否有据，以及应说内容是否覆盖，而不是让一个维度替代另一个。

必要事实集合可以来自明确问题、标注指南或源文中的预定要点。它不应在看到某个模型回答后专门扩展或缩减，否则不同模型面对不同分母。开放任务无法穷尽所有合理内容时，应承认覆盖评价的参考边界，允许合法新增事实同时要求支持。参考答案是一种可接受表达，通常不是全部正确输出的枚举。

<a id="nlp4-detail-16"></a>

### 3.4 引用存在、可访问与支持内容

回答附带一个引用编号，只能证明它尝试建立链接。还需要验证编号能解析到实际证据、证据在当前版本可用、引用跨度确实支持相邻命题。把一篇相关主题文章放在句尾，不自动证明句子里的具体数字或因果结论。引用可靠性应沿命题到证据的边逐条检查。

可以区分引用精度，即已给引用中有多少支持对应命题；引用覆盖，即需要证据的命题中有多少得到有效引用。还要避免用一个引用支持整段而实际只支持其中一句。多个来源相互转载也不等于多个独立证据，应保留原始来源链。引用数量不应该直接成为可信度分数。

<a id="deep-dive-3"></a>

<a id="nlp4-detail-17"></a>

### 3.5 证据链诊断怎样定位系统错误

检索增强系统可以分为资料获取、候选检索、证据选择、内容理解、答案生成和引用绑定。正确证据没进入候选，属于召回问题；证据已在上下文但数字写错，属于读取或生成问题；答案事实正确却引用错段，是绑定问题。每个阶段需要不同干预，不能看到错误就统一增加检索数量。

可以提供人工正确证据测试生成上限，再使用真实检索证据测试端到端能力。两者差值有助于诊断，但不一定严格等于检索造成的全部损失，因为增加证据也会改变长度和干扰。公平对照应尽量控制格式与上下文预算，并保留原始检索轨迹。人工证据条件的高分不能直接当成实际系统成绩。

### 图解：生成评估先固定参考与判定规则

![封闭事实库中的命题状态、实际引用边与四种分母](images/04-concept.svg)

图使用[实验三](#nlp4-detail-35)的原始事实和输出，只绘出 alpha 子集。每行是一个去重命题，每列是一个文档编号；蓝色实心圆表示可支持命题的证据，橙叉表示数字矛盾，空心菱形表示所引编号无法解析，浅灰圆仅表示没有支持标记。启动年格旁的“×2”记录原回答重复给出的两条有效引用；预算句实际引用 d1，负责人句实际引用 missing。“未批准”一行的箭头表示一次修复操作：原引 d1 改为能支持该命题的 d2；不是把 d1 的内容移入 d2。

下方四对长度条共用零到一的刻度，蓝色为原回答，橙色为只修复这一条引用之后。事实支持与必要覆盖完全不动，引用边精度和命题引用覆盖分别增长。这让内容正确性、证据绑定和计数单位的区别直接可见。missing 是无法解析的文档编号，不是存在但没有信息的空文档。

先从对象数开始复算。原输出共五次陈述，其中启动年份重复一次，去重后只有四个命题。启动年 2020 与“未批准”受库支持，预算 100 与库中的 10 冲突，负责人 Lin 则没有可核验信息。必要事实集合在看输出之前已经固定为启动年份、真实预算和批准状态三个，所以四项指标是

$$
\begin{aligned}
{\rm support\ precision}&=\frac24=\frac12,\\[4pt]
{\rm required\ coverage}&=\frac23,\\[4pt]
{\rm citation\ precision}&=\frac25,\\[4pt]
{\rm citation\ coverage}&=\frac14.
\end{aligned}
$$

前两项按去重命题和预先定义的必要事实计数；第三项按原始引用边计数；第四项问四个不同命题中有几个至少获得一条有效引用。两条蓝线来自重复的启动年陈述，因此是两条有效边，却只覆盖同一个命题。预算句和批准句都引用 d1，但 d1 不能支持对应的预算 100 与“未批准”；负责人句指向不存在的编号。因此有五条边、两条有效边，且只有一个不同命题获得有效引用。

只把“未批准”的引用从 d1 改成 d2，命题内容完全不变，事实支持精度仍为 $`\frac12`$、必要覆盖仍为 $`\frac23`$，但引用边精度变成 $`\frac35`$、命题引用覆盖变成 $`\frac24`$。这是一种纯粹的绑定修复，不能夸称为增加了事实覆盖。反过来，删掉重复启动年及其重复引用后，原有事实指标不变，引用边精度却从 $`\frac25`$ 变为 $`\frac14`$；这说明原始边计数会受重复表述影响，应与去重命题数共同解释。

原子事实支持评价的思路可对照 [FActScore 原论文](https://aclanthology.org/2023.emnlp-main.741.pdf)；区分内容正确与引用支持可对照 [ALCE 的引用质量定义](https://arxiv.org/html/2305.14627v2#S3.SS3)。本图严格使用人工三元组和集合包含规则，分母、重复处理与多文档支持规则均由本章程序定义，并不是这两套研究系统的完整复现。

<a id="nlp4-detail-18"></a>

## 4. 把评价维度写成可重复的测量规则

<a id="nlp4-detail-19"></a>

### 4.1 量表需要任务边界和锚定例子

“回答很好”不足以指导可靠标注。可以把事实支持、关键覆盖、指令遵循、格式与表达清晰分开，每个维度给明确的等级描述与正反例。事实维度中，证据矛盾与证据不足应分开；格式维度中，字段缺失与字段值错误也应分开。维度拆分帮助定位问题，但过多细项会增加成本，需要围绕真实决策选择。

等级分数未必是等距数值。把一到五分直接平均，隐含相邻等级间差距相等的近似；如果标注指南只定义顺序，报告等级分布或偏好比例可能更稳妥。成对比较降低了标注者对绝对刻度的依赖，却增加了顺序、参照和两者都差时的决策问题。量表选择应服务研究问题，而非默认所有任务都用五分制。

<a id="sec-6"></a>

<a id="nlp4-detail-20"></a>

### 4.2 自动评价器也有自己的误差分布

使用模型评价另一个模型输出，并不会使评价获得天然客观性。评价器可能受候选位置、冗长程度、措辞、格式、自家风格或提示中身份线索影响，也可能无法判断复杂事实。相关研究说明这些风险值得检验，但具体偏差大小必须在自己的任务上测量，不能把某篇研究的数字直接迁移为所有评价器的性能。

应保存评价器版本、提示、资料输入、解码和原始理由，对人工复核集评估错误类型。解释文字流畅不代表分数可靠；理由里重复候选的说法，也不等于它核对了证据。需要设计已知正确与错误的控制样例，确认评价器能识别任务关键差别，再扩大使用。评价器适合快速筛查的范围，应由验证结果限定。

<a id="nlp4-detail-21"></a>

### 4.3 位置互换能够识别哪些偏差

成对比较时把甲乙交换显示顺序，分别评价，再将结果映回模型身份。如果两次都偏好先展示的候选，就出现位置敏感性。可以把这种不一致记为平局、交给人工复核或按预定规则汇总，但不能只保留对目标模型有利的一次。位置互换减少某些混淆，并不保证消除所有提示交互效应。

若用连续潜在评分近似 $`s=d+b\cdot o`$，其中 $`d`$ 是真实差异、$`o`$ 表示顺序符号，交换后平均可以抵消固定加性位置项。但实际评价常输出离散胜负，平均胜负不等于恢复潜在差异；长度偏好、风格偏好与内容质量交互也不会被简单抵消。形式化近似帮助解释设计，不应被夸大为普遍无偏证明。

<a id="nlp4-detail-22"></a>

### 4.4 长度控制不能简单裁掉答案

长答案可能因为包含更多必要事实而更好，也可能因为重复与无据扩写而显得更好。要检验长度偏好，应构造内容质量近似不变、仅改变冗余程度的对照，或按长度分层分析。直接把长答案截成与短答案等长，可能删除结论或证据，反而改变了真正质量。长度既是潜在混淆，也可能是内容完成的中介变量，需要谨慎解释。

可同时报告任务质量、输出 token 数、支持事实数与冗余比例，并绘制质量与成本关系。若长回答确实覆盖更多且无额外错误，不能仅因长就扣分；若增加了大量无据陈述，流畅与篇幅也不能抵消事实风险。评价标准应奖必要而充分的说明，不把简短或冗长本身当作唯一目标。

<a id="sec-6-1"></a>

<a id="nlp4-detail-23"></a>

### 4.5 人工标注不是没有误差的金标准

标注者可能遗漏证据、对指令理解不同、疲劳或受到候选身份影响。应先培训与试标，分析分歧原因，再修订指南并冻结正式规则。双盲、候选匿名和随机顺序可以减少一部分偏差，但不能替代事实核验能力。高一致性只表示标注者相互接近，也可能来自共同误解。

二元标注可比较原始一致率与扣除偶然一致的系数。设观察一致率为 $`p_o`$，由边际比例计算的偶然一致率为 $`p_e`$，系数为 $`\frac{(p_o-p_e)}{(1-p_e)}`$。当正例极少时，原始一致率可能很高而系数不高，提醒我们查看类别构成；当分母为零时该系数没有定义。应同时给混淆表与样本数，不用一个一致性数字替代标注质量说明。

<a id="nlp4-detail-24"></a>

## 5. 配对比较、拒答与覆盖风险

<a id="nlp4-detail-25"></a>

### 5.1 同题比较能够消除哪些变异

让两个系统回答同一组问题，逐题计算差值，可以控制题目难度对两者共同产生的变化。若问题来自同一文档或同一事件，还要以来源为统计单位；逐问配对不消除来源内部相关性。报告应明确题目数、来源数、每来源题目分布，以及主指标是随机题目还是随机新来源的平均质量。

如果每题生成多次，应先决定评价单次随机回答、平均回答质量还是带选择器的候选集合。多个生成共享同一题目，不能把它们当作新增独立问题。两个系统使用相同随机种子编号，也不保证内部随机事件一一对应；配对的主要依据应是同一任务输入与来源，生成随机性另行记录。

人工比较还可以设置平局与不可判定。强制每题选一个赢家，会把近似等价或资料不足的情况随机推给某一方。计分时可把平局计半胜，或单独报告胜平负；两种汇总方式有不同解释。不能在系统甲胜时保留、系统乙胜时称不可判定，应在盲化前固定规则。

<a id="nlp4-detail-26"></a>

### 5.2 配对均值和组重采样

设来源 $`g`$ 内的问题差值为 $`d_{gi}`$。逐问平均用全部差值之和除总题数，逐来源平均先求每来源均值再平均。前者让问题多的来源更重要，后者让每个来源等权。区间估计可抽来源整组重算相应均值，保留两个系统的同题配对。抽样单位和聚合权重是两个独立选择，不能混淆。

区间条件于已生成的这些回答与固定评价规则；重新解码、重新训练、换提示或换评价器会带来其他随机性。若只对固定分数做自助法，不应宣称覆盖了整套系统的不确定性。不同任务的差值也应分层检查，避免总体提升完全来自一类题变多。统计设计应追踪目标总体，而不是只产出一个显著性标签。

<a id="nlp4-detail-27"></a>

### 5.3 拒答不能只看回答部分的准确率

选择性回答系统可以通过只回答最容易的问题提高条件准确率，但覆盖率随之下降。定义覆盖率为已回答题目数除全部有效题目数，选择风险为已回答部分的错误比例。拒绝全部问题时覆盖率为零，条件风险没有定义；不能把它记成零错误后宣布系统完美。应共同报告覆盖与风险，并说明拒答代价。

在固定覆盖率下比较风险，或在固定风险约束下比较覆盖，比只看被回答题目的正确率更可比。阈值必须在开发集选择，测试只运行固定策略。置信分数不一定校准，风险覆盖曲线也依赖排序；如果模型对错误事实很自信，拒答机制可能无法有效筛掉错误，需要专门验证。

<a id="nlp4-detail-28"></a>

### 5.4 从代价推导是否回答

设答错代价为 $`c_w`$、拒答代价为 $`c_a`$、答对代价为零，正确概率为 $`p`$，回答的期望代价为 $`(1-p)c_w`$，拒答为 $`c_a`$。在这些条件下，回答应满足 $`p\ge1-\frac{c_a}{c_w}`$。这个阈值由代价和概率解释决定，不是固定使用最大概率二分之一。若拒答后有人工复核，代价还应包含复核负担与延迟。

若任务允许部分回答，可以分别回答有证据的子问题并明确缺失部分，而不是在整题回答与整题拒绝之间二选一。评价需同时计算子事实覆盖、已答事实正确与不确定说明。避免奖励空泛的“无法确定”模板，也不要把合适拒答当成事实错误。拒答是否合理取决于可用证据与任务要求。


<a id="visual-example-nlp-04"></a>

### 对照表：拒答通过牺牲覆盖换取不同的条件风险

| 阈值策略 | 回答数 | 错误数 | 覆盖率 | 回答内风险 |
| --- | --- | --- | --- | --- |
| 宽松 | 100 | 20 | 100% | 20% |
| 中等 | 60 | 6 | 60% | 10% |
| 严格 | 20 | 1 | 20% | 5% |

**说明。** 同一百个问题在不同置信阈值下，只评价已回答部分会得到不同条件风险。更严格策略在这个人工算例中降低回答内错误率，却让更多用户得不到答案。应同时报告覆盖率与风险，而不是只展示拒答后变好的准确率。

**适用条件。** 表格不是实测曲线，也不保证阈值越高真实风险必然单调降低；置信度校准、样本支持与业务拒答代价仍须检验。



<a id="visual-mechanism-nlp-04"></a>

### 图解：配对 bootstrap：重复抽问题，不拆开系统结果

![配对 bootstrap：重复抽问题，不拆开系统结果](images/04-mechanism.svg)

**读图与计算。** 圆点与方块在同一题内组成一对，横轴是各自的单题得分，细连线只用于显示对应。三个问题的分数仍为 $`A=(1,1,0)`$、$`B=(1,0,0)`$，统一定义分数差为 $`B-A`$，则原均值为 $`\frac{1-2}{3}=-\frac13`$。一次有放回抽样共同取索引 $`(2,1,2)`$，得到 $`A^*=(1,1,1)`$、$`B^*=(0,1,0)`$，本次差值变为 $`\frac{1-3}{3}=-\frac23`$。问题二重复两次时，A、B 两个结果都必须重复两次，不能为两个系统各抽一串索引。负号在这里表示该次比较 B 得分更低；它不是重采样出错。

**适用条件。** 一张图只展示一次重采样，不能据此给出置信区间或显著性。抽样单位应匹配独立性假设：同一主体内相关的问题通常需要主体级分块。BLEU 等非线性语料指标应在每份重采样语料上重新计算，不能用句子分数均值代替。bootstrap 本身也不修复测试污染、评审偏差和事后多次选择。

## 6. 诊断报告与最小可复现材料

<a id="nlp4-detail-30"></a>

### 6.1 每个分数都应能够追溯到样本

保存原始问题、可见资料版本、完整输出、停止原因、检索结果、评价原始记录和最终维度分数。只截取正确句子会隐藏后续无据扩写，只保存一个总分会丢失错误依据。记录不意味着把所有敏感资料无条件公开，而是保证授权环境内能够复核信息链，并在发布材料中明确可复查范围。

版本变化应说明是模型、提示、数据、评价器还是规则改变。若同时修改多个环节，整体改善难以归因，可先交付系统结果，再补最小对照分析。修复已见错误后，保留固定回归集验证没有倒退，同时使用新独立样本检验泛化；固定回归集主要防复发，不能永远充当独立测试。

<a id="nlp4-detail-31"></a>

### 6.2 研究结论要与验证范围一致

人工封闭事实库可以证明核对程序、分母和聚合规则正确，不能证明它理解任意自然语言。模拟评价器可以展示偏差机制，不能据此推断真实大模型偏差有多大。教师强制下损失下降可以验证目标优化，不能证明自由生成事实可靠。每个实验都应说明它隔离了哪个机制，哪些能力没有被测试。

如果结果没有改善，报告仍可以有价值。去重后成绩下降可能说明原先有重复优势，也可能因有效训练量降低，需要进一步控制；引用数量增加但支持精度不变，说明形式引用并未改善证据绑定；拒答提升条件准确率但覆盖骤降，说明资源权衡发生改变。保留这些情况有助于建立完整理解，而不是只收集成功例子。

### 7.1 实验一：规范化、近重复与来源组件

下面使用人工英文短句，便于直接观察词集合交并比。程序保留数字和否定，规范化只处理字符形式、大小写与空白。它通过完全重复、相似度和共享来源建立关联，再用连通分量保证同组件不跨集合。这是可审计的教学去重规则，不能识别任意改写，更不证明未知预训练集合没有污染。

```python
import unicodedata
from collections import defaultdict

def normalize(text):
    return ' '.join(unicodedata.normalize('NFKC',text).casefold().split())

def jaccard(a,b):
    aa,bb=set(normalize(a).split()),set(normalize(b).split())
    return len(aa&bb)/len(aa|bb) if aa|bb else 1.0

rows = [
    ('r0','source-a','Alpha trial yield was 10 units'),
    ('r1','source-b','  ALPHA trial yield was 10 units  '),
    ('r2','source-a','A second question from the same report'),
    ('r3','source-c','Beta protocol started in 2021'),
    ('r4','source-d','Gamma protocol ended in 2022')]
parent=list(range(len(rows)))
def find(i):
    while parent[i]!=i:
        parent[i]=parent[parent[i]];i=parent[i]
    return i

def union(i,j):
    parent[find(j)]=find(i)

edges=[]
for i in range(len(rows)):
    for j in range(i):
        reasons=[]
        if rows[i][1]==rows[j][1]:reasons.append('shared-source')
        if normalize(rows[i][2])==normalize(rows[j][2]):reasons.append('exact-normalized')
        if jaccard(rows[i][2],rows[j][2])>=0.85:reasons.append('near-text')
        if reasons:
            union(i,j);edges.append((rows[i][0],rows[j][0],reasons))
groups=defaultdict(list)
for i,row in enumerate(rows):groups[find(i)].append(row[0])
components=sorted(groups.values(),key=lambda g:g[0])
assert sorted(map(len,components))==[1,1,3]
assignment={item:('train' if k%2==0 else 'test')
            for k,component in enumerate(components) for item in component}
assert all(assignment[a]==assignment[b] for a,b,_ in edges)
assert normalize('not approved')!=normalize('approved')
assert normalize('yield 10')!=normalize('yield 100')

A,B,C={'a','b'},{'a','b','c'},{'b','c'}
sim=lambda x,y:len(x&y)/len(x|y)
assert sim(A,B)>=.6 and sim(B,C)>=.6 and sim(A,C)<.6
print('components',components,'auditable edges',edges)
```

最后三个集合构成相似关系不传递的反例；连通分量会把三者连在一起。正式数据应审查大组件与连接原因，并控制测试集构成。分配代码仅展示组件隔离，不保证训练测试在语言、领域和时间上平衡，真实项目还需要在不破坏隔离的前提下规划这些条件。

### 7.2 实验二：回答掩码、一次移位与有效分母

本段不训练语言模型，只构造可求导 logits 来验证监督接口。每条序列包含起始、提示、分隔、回答与结束符，第二条序列有填充。回答目标位置的掩码在移位后同步切片，提示对应 logits 的直接梯度为零；回答和结束符有梯度。该局部结论不否认真实模型中提示通过上下文参与回答梯度。

```python
import torch
import torch.nn.functional as F

torch.set_num_threads(1)
torch.manual_seed(17)
# ids: 0 padding, 1 start, 2 prompt, 3 separator, 4/5 answer, 6 end
ids=torch.tensor([[1,2,3,4,5,6],[1,2,3,4,6,0]])
answer_position=torch.tensor([[0,0,0,1,1,1],[0,0,0,1,1,0]],dtype=torch.bool)
logits=torch.randn(2,6,7,dtype=torch.float64,requires_grad=True)
pred=logits[:,:-1]
target=ids[:,1:]
valid=answer_position[:,1:] & (target!=0)
assert valid.sum().item()==5
unreduced=F.cross_entropy(pred.reshape(-1,7),target.reshape(-1),
                         reduction='none').reshape(2,5)
loss=(unreduced*valid).sum()/valid.sum()
manual=-F.log_softmax(pred,dim=-1).gather(2,target.unsqueeze(-1)).squeeze(-1)
assert torch.allclose(loss,manual[valid].mean())
labels=target.clone();labels[~valid]=-100
builtin=F.cross_entropy(pred.reshape(-1,7),labels.reshape(-1),ignore_index=-100)
assert torch.allclose(loss,builtin)
loss.backward()
grad=logits.grad[:,:-1]
assert bool((grad[~valid]==0).all())
assert bool((grad[valid].abs().sum(-1)>0).all())
assert bool((logits.grad[:,-1]==0).all())
# Two microbatches need token-count weighting, not equal weighting.
counts=valid.sum(1)
sums=(unreduced.detach()*valid).sum(1)
weighted=(sums/counts*counts).sum()/counts.sum()
equal_samples=(sums/counts).mean()
assert torch.allclose(weighted,loss.detach())
assert not torch.allclose(equal_samples,weighted)
assert target[0].tolist()==[2,3,4,5,6]
print('valid counts',counts.tolist(),'token loss',float(loss.detach()),
      'sample-mean loss',float(equal_samples))
```

断言比较了手工对数归一化、有效 token 聚合与接口忽略标签三条计算路径。它还明确模型最后一个位置没有下一个目标，因此未参与损失。迁移到高层生成模型时，应先确认接口是否内部移位，然后只保留一次移位；不能直接照抄这里的外部切片再叠加内部规则。

### 7.3 实验三：封闭事实库中的支持、引用和覆盖

为了让结果可验证，事实由固定三元组表示，文档身份指向明确命题。支持、矛盾与未知在封闭规则内判定，不使用语言模型或自然语言推断器。程序区分“事实在库中正确”和“给定引用真的支持它”，也区分支持精度与关键事实覆盖。它不能自动从任意自然语言抽取事实，实验范围必须保持清楚。

```python
from collections import Counter

facts={
    ('alpha','start_year'):2020,
    ('alpha','budget'):10,
    ('alpha','approved'):False,
    ('beta','start_year'):2021}
documents={
    'd1':{('alpha','start_year',2020),('alpha','budget',10)},
    'd2':{('alpha','approved',False)},
    'd3':{('beta','start_year',2021)}}
required={('alpha','start_year',2020),('alpha','budget',10),
          ('alpha','approved',False)}
# claim tuple, cited document ids
output=[(('alpha','start_year',2020),['d1']),
        (('alpha','budget',100),['d1']),
        (('alpha','approved',False),['d1']),
        (('alpha','owner','Lin'),['missing']),
        (('alpha','start_year',2020),['d1'])]

def status(claim):
    entity,relation,value=claim
    key=(entity,relation)
    if key not in facts:return 'unknown'
    return 'supported' if facts[key]==value else 'contradicted'

unique={claim for claim,_ in output}
counts=Counter(status(claim) for claim in unique)
supported={c for c in unique if status(c)=='supported'}
support_precision=len(supported)/len(unique)
coverage=len(supported&required)/len(required)
links=[(claim,doc) for claim,refs in output for doc in refs]
valid_links=[(claim,doc) for claim,doc in links
             if doc in documents and claim in documents[doc]]
claims_with_valid_citation={claim for claim,doc in valid_links}
citation_precision=len(valid_links)/len(links)
citation_coverage=len(claims_with_valid_citation)/len(unique)
assert counts=={'supported':2,'contradicted':1,'unknown':1}
assert support_precision==.5 and coverage==2/3
assert citation_precision==2/5 and citation_coverage==1/4
assert status(('alpha','approved',True))=='contradicted'
assert status(('alpha','owner','Lin'))=='unknown'
assert ('alpha','approved',False) not in documents['d1']
# High lexical overlap can coexist with a central fact error.
a='alpha budget is 10 units'.split()
b='alpha budget is 100 units'.split()
assert len(set(a)&set(b))/len(set(a)|set(b))==2/3
print('fact support',support_precision,'required coverage',coverage,
      'citation precision',citation_precision,'citation coverage',citation_coverage)
```

重复的启动年份没有让事实支持精度重复加分，但它仍然贡献一条引用边，因此这里同时出现命题去重与引用边计数两个分母。正式评价需要明确这种选择，也可以对引用边去重后补充报告。被库判定未知的负责人不一定在现实中错误，只是在当前证据契约下不能验证；把未知直接称为造假超出了这个实验的判断能力。

### 7.4 实验四：位置偏差、成对组抽样与风险覆盖

最后一段构造带有固定位置和长度偏好的确定性评分器，目的只是展示测量机制。它不调用任何外部模型，也不测量真实大模型的偏差大小。连续分数对换序后取平均可以消掉设定的位置项，但长度项保留；这为“位置互换不是万能修正”提供可计算反例。随后对固定人工得分按来源配对自助抽样，并验证拒答的覆盖分母。

```python
import numpy as np

def mock_score(quality,length,position):
    return quality + 0.02*length + 0.4*(position==0)

quality_a,quality_b=.8,.7
length_a,length_b=10,30
forward=mock_score(quality_a,length_a,0)-mock_score(quality_b,length_b,1)
reverse=mock_score(quality_a,length_a,1)-mock_score(quality_b,length_b,0)
counterbalanced=(forward+reverse)/2
assert forward>0 and reverse<0
assert np.isclose(counterbalanced,(quality_a-quality_b)+.02*(length_a-length_b))
assert counterbalanced<0  # length bias remains after position cancellation

rng=np.random.default_rng(81)
# Each row: one independent source; four paired questions per source.
a=np.array([[.8,.6,.7,.9],[.4,.6,.5,.7],[.7,.8,.9,.6],
            [.3,.5,.6,.4],[.9,.9,.8,.7]])
b=a+np.array([[.05],[.00],[-.02],[.04],[.01]])
difference=(b-a).mean(axis=1)
point=difference.mean()
replicates=difference[rng.integers(0,len(a),size=(2000,len(a)))].mean(axis=1)
interval=np.quantile(replicates,[.025,.975])
assert np.isclose(point,.016)
assert interval[0]<=point<=interval[1]
assert np.allclose((a+7-(b+7)).mean(1),-difference)

confidence=np.array([.95,.9,.7,.6,.4,.2])
correct=np.array([1,1,0,1,0,0],dtype=bool)
answered=confidence>=.8
coverage=answered.mean()
risk=(~correct[answered]).mean() if answered.any() else np.nan
assert np.isclose(coverage,1/3) and risk==0
answered_all=confidence>=0
assert answered_all.mean()==1 and np.isclose((~correct).mean(),.5)
answered_none=confidence>1
assert answered_none.mean()==0
empty_risk=(~correct[answered_none]).mean() if answered_none.any() else np.nan
assert np.isnan(empty_risk)
print('mock order gaps',forward,reverse,'balanced',counterbalanced)
print('paired source difference',point,'conditional bootstrap interval',interval)
print('selected coverage/risk',coverage,risk)
```

五个来源的自助区间只用于展示流程，不能假装已得到稳定的群体结论；增加模拟重采样次数也不能补足真实来源数。人工置信度例子中只回答两题得到零选择风险，却只覆盖三分之一，这正是需要同时报告两个量的原因。真实系统应在开发集选择阈值，再到独立测试评估，而不是对同一组六题反复挑阈值。

### 图解：从五个来源到差值分布

![实验四五来源的配对均分、来源差值与精确条件自助分布](images/04-source-bootstrap.svg)

顶端两幅图使用实验四的同一批人工分数。每个来源有四道问题，左图先在来源内求平均，再连接 A 的圆点与 B 的方块；右图把同来源配对压缩成 $`d_g=\overline B_g-\overline A_g`$。五项差值依次为 $`0.05,0,-0.02,0.04,0.01`$，所以来源等权平均为 $`\overline d=0.016`$。S3 对 B 不利，其他来源的正差不能让这项退步从图中消失。

这里每个来源题数恰好相同，逐题平均与逐来源平均的点估计相等，但独立抽样单位仍然是来源。一次组自助抽样从五个来源中有放回抽五次；例如索引为 $`(S1,S1,S3,S5,S2)`$ 时，整份 S1 的四个 A、B 配对都重复两次，本次差值为

$$
\overline d^*
=\frac{0.05+0.05-0.02+0.01+0}{5}
=0.018.
$$

底图枚举全部 $`5^5=3125`$ 种有序来源抽法，每一种在条件自助分布中等概率。柱高是某个差值被这些抽法产生的概率质量，所有柱高之和为一，不是连续密度。原差值 0.016 的竖线与两端橙色虚线分别标出点估计和该离散分布的 2.5%、97.5% 分位点；完整枚举给出区间 $`[-0.006,0.038]`$。

程序仅随机抽取其中 2000 份，固定种子运行得到约 $`[-0.008,0.038]`$。下端点相差一个 $`0.002`$ 的格点，属于有限重抽次数的蒙特卡洛误差，不是图与代码采用了不同原数据。枚举能去掉这层模拟误差，却不能解决只有五个原始来源的信息限制，更不能把这个区间自动升级成可靠的大样本群体结论。

还可以用条件方差独立核验图的宽度。对这五个固定差值，

$$
\operatorname{Var}_*(\overline d^*)
=\frac15\left[
\frac15\sum_{g=1}^{5}(d_g-\overline d)^2
\right]
=0.0001328,
$$

条件标准差约为 0.011524。因为人工程序让同来源四题的差值完全相同，若错误地把二十题当独立单位逐题重抽，得到的条件标准差会恰好缩小一半。这是本人工结构的可计算反例，不是所有真实数据都存在同样倍数。它说明“保持 A、B 配对”与“选择正确独立抽样单位”缺一不可。

配对自助法可参见 [Koehn 原论文第 5 节](https://aclanthology.org/W04-3250.pdf)；本图按来源分块，是依据本章数据组织作出的设计。对于 BLEU 等非线性语料指标，每份抽样后应重新算完整指标，不能照搬这里的来源均差运算。区间仍条件于已生成回答、固定评分规则及这五个来源，没有覆盖重新训练、重新解码或更换评价器的随机性。

### 图解：六个请求怎样形成风险覆盖路径

![实验四按置信排序的六请求及各回答前缀的风险覆盖率](images/04-risk-coverage-prefix.svg)

上方直接显示六题的置信排序与真实判定：q1、q2、q4 正确，q3、q5、q6 错误。形状和文字共同区分对错，不要求读者只凭颜色判断。图中数值是人为指定的排序分数；在没有校准检验前，0.95 不能自动解释成真实正确率 95%。

令 $`k`$ 为阈值允许回答的前缀长度，累积错误数依次为 $`(0,0,1,1,2,3)`$，则

$$
{\rm coverage}(k)=\frac{k}{6},
\qquad
{\rm risk}(k)=\frac{E_k}{k},
\quad k\ge1.
$$

因此六个离散点的回答内风险依次为 $`0,0,\frac13,\frac14,\frac25,\frac12`$。阈值 0.8 保留前两题，得到覆盖率 $`\frac13`$、风险零，与程序断言一致；全部回答时覆盖一、风险 $`\frac12`$。从第三题扩到第四题，新增的是一个正确答案，累计错误数保持一，分母从三增至四，所以风险反而下降。降低阈值并不保证经验条件风险单调上升，提高阈值也不保证每一步都更安全。

连接点的折线只是帮助追踪这六个前缀，不是在相邻点之间生成新的独立请求。覆盖零的情况没有已回答总体，风险未定义，因此图中不在原点放一个“零风险”观测。第 5 节的一百题表格采用另一组示意数据，本图才对应实验四的六题，两个总体的错误数和分母不能混用。

本图展示评分规则而非选择部署阈值的证据。真实系统应在开发集依据代价或风险约束确定策略，再对独立测试报告覆盖与错误；不能在这六题上反复挑最有利阈值，然后声称获得稳定的可靠性保证。

## 8. 进阶推导：评价是一个有条件的测量模型

<a id="nlp4-detail-38"></a>

### 8.1 评价器误差会怎样影响系统差值

设某个二元任务真实合格率为 $`\pi`$，评价器灵敏度为 $`s`$、特异度为 $`t`$，则观察到的合格率为 $`s\pi+(1-t)(1-\pi)`$。推导只需要按真实合格与不合格两种情况分解全概率：合格被正确判出的部分加不合格被误判为合格的部分。若两个系统面对相同且稳定的评价误差，观察差值等于 $`(s+t-1)`$ 乘真实差值。

这个简化模型说明测量误差可能压缩差异，但它的条件很强。若评价器对某系统特有的冗长风格更宽容，两个系统的灵敏度或特异度不同，误差就可能改变排序，不能只乘一个统一系数修正。应在模型风格、题型和错误类型切片中审计评价器，并对代表性人工复核样本估计误差。人工复核集如果只挑容易题，也无法支持整体修正。

当 $`s+t`$ 接近一时，观察标签几乎不携带真值信息，反演会非常不稳定。即使形式上能解出真实率，也可能因为误差估计不准得到超出零一范围的数值。更可靠的行动通常是改进测量工具、增加高质量复核和报告敏感性分析，而不是把代数反演当成客观真值恢复器。

<a id="nlp4-detail-39"></a>

### 8.2 内容选择偏差与评价缺失

假设模型甲和乙都生成一百题，但只评价成功解析的输出。若甲有二十个格式失败被删掉，乙全部能解析，剩余答案的质量均值不再对应相同总体。应把格式失败作为任务规定的失败、单独报告，或在明确的条件分析中说明筛选。不能让无法评分的输出从分母无声消失，尤其当缺失与模型质量有关时。

人工标注也可能优先选择有趣、争议或明显错误的例子，这类审计集适合发现机制，不适合直接估计总体错误率。可以分成随机代表性样本与有目的挑战样本，前者用于比例估计，后者用于压力测试。两者都应保留，但不应把它们混在一个平均分里，掩盖抽样机制。

<a id="nlp4-detail-40"></a>

### 8.3 参考答案质量与允许输出集合

对开放生成，单一参考通常只是允许输出集合中的一点。准确措辞匹配会把同义正确表达当错误，而完全放弃参考又可能失去关键覆盖检查。可以将参考拆为必要事实、允许变体、禁止无据新增与格式约束，形成更接近任务的判断规则。若参考本身遗漏合法答案，应版本化修订并对全部系统一致复算。

对于需要推理的答案，还应区分结论正确与解释过程有据。猜中结论但引用错误，和结论错误但部分步骤合理，不应在所有维度得到相同标签。评价可以记录结论、证据和推理关系三个层次，再根据应用确定主标准。不能用解释很长自动弥补核心结论错误，也不能因为结论碰巧正确就忽略虚构的支撑过程。

<a id="nlp4-detail-41"></a>

### 8.4 教师强制与自由生成的分布差别

教师强制训练在真实前缀条件下预测下一个 token，自由生成则条件于模型自己已经产生的前缀。前一步错误可能把后续输入带到训练中较少出现的区域，因此局部损失下降不保证完整回答更可靠。应同时检查 token 目标是否正确和实际解码输出是否完成任务，二者分别回答优化与行为问题。

束搜索、温度、截断概率和停止规则都会改变输出分布。某种解码设置可能提高固定自动指标，却增加重复或无据细节。比较模型时应固定或公平搜索解码预算，记录每题生成次数和选择机制。如果生成十个答案后由能看真值的程序挑最好一个，得到的是带答案选择器的上界，不是单次部署生成性能。

<a id="nlp4-detail-42"></a>

### 8.5 拒答策略的测量对象

拒答可能来自证据不足、指令超范围、模型低置信或资源约束，这些原因不等同。对明明有充分证据的简单问题拒答，可能是能力损失；对缺资料的问题清楚说明不足，可能是任务成功。应在数据中标记可回答性，并同时评价正确作答、合理拒答与不合理拒答，防止所有拒绝都被统一奖励或统一惩罚。

如果在拒答模板里夹带未经支持的猜测，应对猜测本身核验，不能因为开头写了不确定就豁免事实错误。部分回答同样需要明确已支持内容与未知部分的界限。评价目标不是强迫模型永远自信或永远谨慎，而是在给定证据与代价下采取合适动作，并让用户能理解信息边界。

<a id="nlp4-detail-43"></a>

### 8.6 命题级微平均与回答级宏平均

设答案甲包含一个命题且正确，答案乙包含九个命题而全部错误。按回答先算支持精度再平均，结果为二分之一；把所有命题汇总，结果为十分之一。前者让每次回答等权，后者让每个命题等权。若模型主动增加冗长输出，两种分母对新增命题的反应也不同，因此应在报告中固定聚合层级，并补充每答案命题数分布。

不能因为拆分粒度不同，就直接比较两个评价器的微平均。一个评价器把复合事实拆成五项，另一个只拆成一项，会改变权重，即使局部判断相同也可能得到不同总分。需要先对齐命题规范，或把两个流程当作不同测量工具做一致性和敏感性分析。答案为空时支持精度也需要单独约定，并与关键覆盖和拒答状态联合报告，避免空输出借零分母逃避评价。

## 9. 二十二道练习与逐步解析

<a id="nlp4-detail-45"></a>

### 9.1 来源一致但问题不同是否可以跨集合

**问题：** 同一份年报生成一百个不同问答，随机分八十题训练、二十题测试，能否证明新文档泛化？

**解析：** 不能，所有题共享年报的实体、事实与表达，模型可能在训练题中已看到测试所需信息。应以年报或更高层文档家族划分，把整组放进一个集合。若目标只是同一文档上的新问题，这种划分可以回答一个较窄问题，但必须如实命名。划分好坏由声称的泛化目标决定，而不是由字符串是否完全相同决定。

<a id="nlp4-detail-46"></a>

### 9.2 规范化删除数字为什么危险

**问题：** 为提高去重率，把所有数字替换成同一个符号会有什么后果？

**解析：** 它会把日期、金额和实验结果不同的句子压成同一形式，可能误删真正有区别的事实，也可能把事实冲突误当重复。可另建模板视图寻找候选，再用原文和来源核实；不要直接以破坏事实的规范化文本替换训练语料。去重审计应保留原文、规则版本和合并原因，方便发现误合并。

<a id="nlp4-detail-47"></a>

### 9.3 连通分量为什么会产生大组

**问题：** 甲乙、乙丙相似度过阈值，甲丙不过阈值，为何仍被分在一起？

**解析：** 连通分量使用路径可达性，不要求组件内每对都相似。这个保守策略可以阻止通过中间样本形成跨集合关联，但共享模板可能串起大量文档。应审查组件大小和连接链，检查是否来源规则过宽；不能为了均分数据而任意拆开已经确认共享答案的链。若修改规则，需要重新生成全部划分并记录版本。

<a id="nlp4-detail-48"></a>

### 9.4 没查到重复能否证明没有污染

**问题：** 内容散列和近重复检查都没发现测试重叠，是否可以写完全无污染？

**解析：** 不能，检查只覆盖当前可见数据和所选相似机制，未知预训练语料、深度改写与开发期间的人为调参仍可能引入信息。应写明检查范围、未检出结果和剩余不确定性。结合新事实、时间隔离与独立来源能够增强证据，但每种设计仍有边界。把没有发现当成已经证明不存在，会夸大审计结论。

<a id="nlp4-detail-49"></a>

### 9.5 为什么提示不计损失仍影响梯度

**问题：** 提示标签都设为忽略，模型还会从提示中学习吗？

**解析：** 会。忽略的是提示位置直接预测目标的损失，回答损失仍可通过注意力和共享参数回传到提示表示相关计算。实验中提示对应 logits 梯度为零，只是局部张量性质，不意味着真实模型的提示嵌入梯度也为零。应区分损失位置、上下文可见性和参数共享三件事，避免用一个掩码解释全部梯度路径。

<a id="nlp4-detail-50"></a>

### 9.6 两个微批怎样得到全局 token 均值

**问题：** 微批甲有十个有效 token，乙有九十个，各自平均损失为二和四，全局均值多少？

**解析：** 总损失为十乘二加九十乘四，除以一百，得到三点八。把两批均值简单平均得到三，是微批等权目标。若希望 token 等权，累积时必须按有效数加权；若希望样本等权，则应从一开始明确该目标。梯度累积不是自动保持所有平均方式等价的开关。

<a id="nlp4-detail-51"></a>

### 9.7 结束符和填充为什么待遇不同

**问题：** 两者都不属于正文内容，能否全部忽略？

**解析：** 结束符通常承担学习何时停止的监督，填充只是凑齐批次长度，不应被当作答案。全部忽略结束符可能削弱停止行为，计入填充则可能让模型学习大量无意义目标。具体接口还要明确结束符是否与填充值共用编号，如果共用，掩码需依位置语义而非只依 token 编号。应手工检查短样本对齐。

<a id="nlp4-detail-52"></a>

### 9.8 双重移位怎样发现

**问题：** 输入看起来正常、损失也下降，怎样检查是否手工和框架各移位一次？

**解析：** 选一个可逐 token 阅读的短序列，把每个 logits 位置与最终目标编号列成表，确认当前位置预测的是下一个而不是下下个。再用只在正确目标位置给高分的人工 logits 检验损失应接近零。训练能拟合错误目标不证明目标合理，因此接口测试比观察长期学习曲线更直接。

<a id="nlp4-detail-53"></a>

### 9.9 截断删掉证据但保留答案怎么办

**问题：** 长资料被截，回答所需关键段消失，仍保留原确定答案是否合理？

**解析：** 这会形成输入不可辨识却要求确定回答的监督，可能鼓励利用先验猜测。应记录证据位置并检查截断后可见性，选择过滤、重切片、检索相关段或将目标改为资料不足。修改目标需要符合任务规则，不是随意加一句拒答。还要报告这种情况占比，避免只展示处理后容易样本而隐藏选择效应。

<a id="nlp4-detail-54"></a>

### 9.10 高词面重合为什么可能完全错

**问题：** 把“没有批准十万元”改成“批准一百万元”，其余文字不变，重合指标为何可能仍高？

**解析：** 大多数词序仍相同，但否定与金额已经改变核心命题。应对实体、关系、数值、时间和否定建立专门核验，允许同义正确改写同时拒绝关键错误。词面指标可以保留作为表达相似度参考，但不能独立承担事实判定。使用对照错误集检查指标敏感性，比仅报告总体相关系数更有诊断价值。

<a id="nlp4-detail-55"></a>

### 9.11 支持精度与覆盖各是多少

**问题：** 必需五个事实，答案只说其中两个且全有据，没有其他事实，怎样评分？

**解析：** 所说命题的支持精度为一，关键覆盖为五分之二。答案可靠但不完整，不能用满分事实精度宣称任务全部完成。若额外加三个错误命题，覆盖不变而支持精度降为五分之二。两个维度分别反映无据扩写与必要遗漏，建议分开报告而不是用一个总分隐藏取舍。

<a id="nlp4-detail-56"></a>

### 9.12 正确事实配错引用怎样判断

**问题：** 负责人确实叫林某，但引用文档只包含预算，没有负责人信息，这句可以得引用支持分吗？

**解析：** 不可以。外部事实正确与所给引用支持是不同维度，应沿当前引用实际能解析的证据判断。可以在事实维度记正确、引用维度记不支持，并检查是否有正确证据可补。相关主题来源不等于支持具体命题，多个无关引用也不能通过数量补偿证据缺失。

<a id="nlp4-detail-57"></a>

### 9.13 证据不足和证据矛盾为什么分开

**问题：** 资料没写负责人，与资料明确写负责人不是林某，能否同记错误？

**解析：** 主任务可以都判未通过，但诊断应区分未知与矛盾。前者表示当前证据无法判断，后者表示已有反证，修复路线和置信程度不同。封闭事实库里的未知不等于现实必假。报告这种区别能避免把缺少检索结果当成事实反证，也能防止模型以无资料为由忽视明确矛盾。

<a id="sec-8-2"></a>

<a id="nlp4-detail-58"></a>

### 9.14 自动评价器高分是否证明事实正确

**问题：** 一个长答案被评价器打满分，还需要核对证据吗？

**解析：** 需要。评价器可能偏好长度、格式或流畅度，也可能与被评系统共享错误知识。应使用已知事实对照和人工抽查审计其灵敏度与特异度，再限定使用范围。评价理由写得详细不等于真正核对来源，尤其需要检查数字、否定和引用绑定。高分是测量结果，可靠程度取决于测量工具验证。

<a id="nlp4-detail-59"></a>

### 9.15 交换顺序消掉了什么

**问题：** 连续评分含固定先展示加成，交换顺序后平均是否消除了全部偏差？

**解析：** 在固定加性模型中可以消掉位置项，但长度、风格与内容交互仍存在；若输出只是胜负，平均离散结果也不等于恢复潜在质量。应报告换序一致率与不一致样本，按预定规则汇总。不能只挑一次有利结果，也不能把对一个人工机制有效解释成对真实评价器普遍无偏。

<a id="nlp4-detail-60"></a>

### 9.16 怎样检验长度偏好又不破坏内容

**问题：** 把长答案裁成短答案一样长后再评分，是否公平控制长度？

**解析：** 不一定，裁切可能删除关键结论与引用，使真实质量下降。可以构造只增加冗余但不改变必要事实的成对文本，或按事实覆盖和输出长度分层比较。还应记录支持事实数与无据命题数，分析长度增加的具体来源。长度不是纯粹无关变量，既可能承载内容也可能承载偏差。

<a id="nlp4-detail-61"></a>

### 9.17 高一致率为什么仍需看边际分布

**问题：** 两位标注者几乎总判不合格，一致率很高，是否说明量表优秀？

**解析：** 不一定，极端类别比例会使共同选多数类自然获得高一致。应查看完整混淆表、正负例数量、扣除偶然一致的指标与实际事实正确性。两人还可能共同误解指南，因此一致不等于有效。加入锚定样例和专家复核可以检查共同偏差，而不是仅追求一个高一致系数。

<a id="nlp4-detail-62"></a>

### 9.18 拒绝全部能否获得零风险

**问题：** 系统不回答任何题，答错数为零，是否风险最小？

**解析：** 总错误数确实为零，但已回答部分的条件风险是零除零，应记未定义；覆盖率为零。若任务要求提供帮助，还必须计算拒答代价。比较应固定覆盖率或风险约束，并报告完整曲线，不能让从不作答的系统以一个零错误数字胜出。合理拒答与不合理拒答也要按证据充分性分开。

<a id="nlp4-detail-63"></a>

### 9.19 配对统计为什么还要按来源抽样

**问题：** 两系统回答同一千题，题目来自五份文档，直接按题自助抽样够吗？

**解析：** 同文档问题共享事实与风格，相关性使有效独立信息可能远少于一千题。应按文档整组抽样，保留两系统同题差值，再按主目标决定逐题或逐来源权重。五来源本身很少，区间应谨慎解释。重复生成更多自助样本不能替代新增真实文档。

<a id="nlp4-detail-64"></a>

### 9.20 测试分数选提示算不算训练

**问题：** 没改权重，只试十种提示选择测试得分最高的，能否仍称最终测试独立？

**解析：** 不能，测试信息已参与配置选择，属于开发使用。应在开发集选择提示，再用未查看的测试集一次验收；如果测试已反复使用，应重新建立独立验收样本或如实报告探索性质。是否更新梯度不是判断独立性的唯一标准，所有根据结果作出的选择都会消耗测试独立性。

<a id="nlp4-detail-65"></a>

### 9.21 人工评价器实验可以推断什么

**问题：** 程序里给先出现答案加零点四，换序后发现偏差，能否说真实大模型也偏零点四？

**解析：** 不能，数值来自人为设定，只证明设计能够呈现并部分消除该机制。真实评价器需要独立采样、盲化对照和实际运行测量。教学模拟适合验证聚合与统计规则，不替代实证研究。应始终标明人工规则、输入规模和未验证能力，避免把可复现性误当成外部有效性。

<a id="nlp4-detail-66"></a>

### 9.22 如何验收事实评价交付物

**问题：** 只有一个总分和几条漂亮输出，是否足够复查研究？

**解析：** 不足。需要来源与划分、可见证据、完整输出、事实粒度、支持与覆盖分母、引用规则、评价器版本、标注指南及样本级判定。还应保存失败与不可判定样本、拒答覆盖和统计单位。复查者应能从输入证据追踪到每项分数，并重现主要比较。展示例子服务解释，不能替代代表性完整统计。

## 10. 综合研究任务与完成标准

<a id="sec-8-1"></a>

<a id="nlp4-detail-68"></a>

### 10.1 建立一个小而完整的证据约束生成基准

先人工写十到二十份带版本的短资料，每份明确实体、数字、日期、否定和至少一个未知字段。每份生成多个问题，按资料家族而非问题字符串分训练开发测试。为测试准备正确改写、数字错误、否定翻转、遗漏关键事实、错误引用和合理拒答等候选。候选可手工构造，不需要调用任何生成服务。

建立命题表与证据边，定义哪些事实必要、哪些新增允许、哪些信息无法判断。用封闭规则验证可程序判断的部分，再安排盲化人工复核开放表达。将来源清单、分组依据、规则版本与原始判定保存在最终学习材料中；实验临时数据在内存或临时目录处理，不把生成器脚本当成必需交付物。

<a id="nlp4-detail-69"></a>

### 10.2 同时研究系统与测量工具

对两个候选系统或两种人工输出策略做同题比较，同时检验评价器在顺序、长度和事实对照上的可靠性。主结果分开报告事实支持、关键覆盖、引用、格式、成本与拒答覆盖，统计按资料来源配对。可以保留探索性切片，但注明其发现性质，并用新资料确认后再写强结论。

真正的完成标准不是得到一个很高的分数，而是能解释每种错误来自信息缺失、读取错误、生成无据、引用绑定还是测量失准。对于未覆盖的语言、领域和时间范围，明确说明边界。这样即使下一次模型、提示或资料发生变化，仍有一套能够继续验证和修正的研究框架。

<a id="nlp4-detail-70"></a>

### 10.3 继续学习的方向

进一步可以研究长文档证据选择、时间变化事实、跨语言引用、可回答性预测和不同评价器之间的不一致。每个方向都应先给可证伪的具体问题，例如增加资料是否提高必要事实覆盖但降低引用精度，或位置互换是否减少特定题型的偏好。不要把所有可能因素一次性堆进实验，否则即使结果变化也难以解释原因。

本章的核心训练是让“生成得好”变成一组可观察、可比较且有边界的命题。数据组织决定模型看到了什么，损失掩码决定它被要求学习什么，证据规则决定什么算有据，统计设计决定结果能推广到哪里。将这些环节连成完整链条，才能同时满足深入研究与可靠交付，而不依赖单一指标或少数示例。
