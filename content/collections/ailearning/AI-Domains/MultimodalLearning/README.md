# 多模态学习

理解图像、文本、音频等信号如何对齐、融合与生成，并检查配对数据质量。

**先修知识：** Transformer、概率；图文任务需视觉与文本表示基础。

## 学习顺序与覆盖范围

图文任务先具备[视觉表示](../ComputerVision/01-图像表示分类与迁移学习.md)、[文本表示](../NLP/01-文本清洗分词与向量表示.md)和[交叉注意力](../../DeepLearning/Attention/02-自注意力多头与掩码.md)。第 1—2 章定义对齐与融合，第 3 章深入目标与训练阶段，第 4 章扩展时序实验；涉及跨模态生成时按需补[生成模型](../GenerativeModels/README.md)。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立完成[综合研究项目：将同步与理解分开验收](04-音视频对齐与多模态实验.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
