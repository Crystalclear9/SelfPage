## 1. 融合的目标是利用互补证据

对齐解决不同通道能否相互检索，融合进一步要求联合读取证据并形成任务结论。两个模态可能重复、互补或冲突，模型应根据问题与测量条件决定如何组合。把向量拼起来只是一个接口操作，真正的融合行为由后续函数、监督目标和数据覆盖决定。若训练任务总能单靠文本完成，模型即使接收图像，也可能不学习视觉依据。

本章用图像区域、文本词片和人工传感器说明机制。核心问题包括交互发生在哪里、查询怎样选择另一通道信息、缺失是否可识别、条件生成如何表达多解，以及评价怎样区分内容、条件遵从和分布覆盖。网络名称不是答案，必须把它还原为明确输入、函数和可观察事件。

<a id="mm-2-detail-2"></a>

### 1.1 三类融合位置

早期融合把原始特征或较浅表示联合输入，允许较早产生交互，但不同采样率、维度和噪声需要统一处理。中间融合让各模态先提取局部表示，再通过拼接、门控或跨注意力交换信息。后期融合组合各自的预测或分数，便于模块化与缺失降级，却可能丢掉单模态预测之前已经压缩掉的互补信息。

这三类只是描述位置，不是严格互斥家族。系统可以先进行中间交互，再融合多个预测头。比较时应说明具体张量、参数共享和监督，而不是认为早期一定更强或后期一定更稳。较早交互提供更大表达空间，也可能更容易学习来源捷径，且需要更多数据识别真正有用的关系。

<a id="deep-dive-1"></a>

<a id="mm-2-detail-3"></a>

### 1.2 一个相加预测无法表示的关系

两个二元模态分别只提供一位信息，目标是它们是否不同。若最终分数只能写成 $`f(x)+g(y)`$ 再与固定阈值比较，要求两个异位组合为正、两个同位组合为负，将正负不等式分别相加会得到矛盾。因此无论两个单模态函数怎样复杂，这种严格可加的最终形式都不能精确实现该异或关系。

这不是说所有后期融合都做不到。如果后期模块能读取足够信息并加入非线性交互，就不再属于上述可加限制。反例的意义是说明应检查函数形式，而不是仅看融合位置。丢掉每个模态内部的必要信息后，再复杂的组合头也无法恢复；保留原始信息并允许交互，则可能解决。

## 2. 从概率推断理解证据组合

<a id="mm-2-detail-5"></a>

### 2.1 独立高斯测量的精度加权

设潜在标量为 $`z`$，先验 $`N(m_0,v_0)`$ 且 $`v_0>0`$，两个测量为 $`x_r=z+\epsilon_r`$；噪声 $`\epsilon_r\sim N(0,v_r)`$、$`v_r>0`$，相互独立并与 $`z`$ 独立。后验精度为先验精度与观测精度之和，后验均值为对应精度加权和：

```math
\begin{aligned}
v^{-1} &=v_0^{-1}+\sum_r v_r^{-1},\\[6pt]
m &=v\left(\frac{m_0}{v_0}+\sum_r\frac{x_r}{v_r}\right).
\end{aligned}
```

方差较小的测量通常获得较大权重，但这是基于已知误差模型的结果，不是注意力权重天然可靠的证明。若两个通道噪声相关，直接相加精度会重复计算证据；若某通道系统性有偏，方差小也不意味着它接近真值。融合前需要明确校准、单位和误差来源。

<a id="mm-2-detail-6"></a>

### 2.2 冲突不应总被平均

同一温度的两个独立噪声测量可以在明确模型下加权平均；两份文档分别规定不同型号的上限，则不能随意平均。前者是对同一量的随机测量，后者可能是主体或版本不一致。语言与视觉冲突也可能来自遮挡、文本错误或时间错位，系统应先检查冲突类型，再决定信任、保留不确定性或要求澄清。

一个门控网络可以学习权重，但若没有覆盖冲突、噪声和缺失的训练数据，它可能只学到固定通道偏好。应构造对照：同样内容改变某通道噪声，交换哪一侧正确，保留来源不变。如果权重仍只跟随来源，说明门控未学到希望的可靠性规则。权重看似合理不等于概率推断正确。

<a id="mm-2-detail-7"></a>

### 2.3 实验一：交互表达与测量融合

下面在有限状态上验证异或反例所需的交互，并核验独立高斯测量的后验公式。前者强调表达能力，后者强调条件假设。两者都不训练真实多模态模型，适合作为后续复杂网络的机制参照。

```python
import itertools
import numpy as np
states = np.array(list(itertools.product([-1.,1.],repeat=2)))
y = (states[:,0] != states[:,1]).astype(int)
interaction = -states[:,0]*states[:,1]
assert np.array_equal((interaction>0).astype(int),y)
# 可加分数对四个组合的交叉差恒为零，异或目标符号却不能满足这一结构。
f = np.array([.4,-.7]);g = np.array([1.2,.3])
score = f[:,None]+g[None,:]
assert np.isclose(score[0,0]+score[1,1],score[0,1]+score[1,0])
m0,v0 = 0.,4.
x = np.array([1.,3.]);variance = np.array([1.,4.])
precision = 1/v0+(1/variance).sum()
v = 1/precision;m = v*(m0/v0+(x/variance).sum())
assert np.isclose(v,2/3) and np.isclose(m,7/6)
assert v < min(v0,*variance)
# 删除第二个测量后，只保留真正可见的似然项。
v_one = 1/(1/v0+1/variance[0])
m_one = v_one*(m0/v0+x[0]/variance[0])
assert np.isclose(v_one,.8) and np.isclose(m_one,.8)
print('xor labels',y.tolist(),'posterior mean/variance',m,v)
```

该后验例子中的第二个测量数值更大，但因噪声较大权重较低。删除它会增大后验方差，不过实际模型若参数错设，新增错误通道未必改善估计。在本节独立高斯测量、噪声方差已知且严格为正的条件下，加入测量会增加后验精度，所以后验方差不增。这个逐例结论依赖高斯固定方差结构，不能扩大为任何正确模型中的每次观测都必然降低不确定性。一般离散模型在相关熵有限时满足平均意义下的条件熵单调性，具体某次观测反而可能增大后验熵，见[条件熵的贝叶斯算例](#conditional-entropy-per-observation)。

## 3. 跨注意力的输入输出与依赖方向
<a id="mm-2-detail-9"></a>

### 3.1 查询、键和值来自哪里

设目标侧表示 $`H_q\in\mathbb R^{n_q\times d_q}`$，来源侧表示 $`H_s\in\mathbb R^{n_s\times d_s}`$。投影得到 $`Q=H_qW_Q`$、$`K=H_sW_K`$、$`V=H_sW_V`$，跨注意力输出为

```math
O=\mathrm{softmax}_{\mathrm{source}}\left(\frac{QK^T}{\sqrt{d_k}}+M\right)V.
```

<a id="scientific-plate-02"></a>

![猫的位置发起查询，视觉键决定权重，视觉值参与汇合，结果回到同一个词位置](images/02-img-cross-modal-readout.webp)

[打开原图放大](images/02-img-cross-modal-readout.webp)

输入来自文本序列中「猫」所在位置的表示，由此构造查询 $`Q`$。上方三个图像区域提供键和值。查询与键比较后，用得到的权重混合相应的值，聚合结果写回同一个文本位置。这里的「猫位置」指词的位置。区域只表示来源位置，若要判断区域是否影响预测，还需要另做遮挡或替换实验。

每个查询沿来源位置独立归一化，输出长度是查询数，而不是来源数。文本查询视觉区域，表示每个文本位置读取图像信息；视觉查询文本则是另一条信息方向。双向交互需要分别构造，不会因为一个注意力矩阵存在就自动完成两个方向。

<a id="mm-2-detail-10"></a>

### 3.2 缩放、掩码与位置

除以键维度平方根的目的是控制在一定独立方差假设下点积的尺度，并不是对所有训练状态都保证方差固定。缺失区域和填充来源应通过掩码排除，不能只把其值设为零；零键仍可能得到正注意力，从而稀释有效信息。若某查询没有任何合法来源，整行负无穷 softmax 未定义，必须显式选择降级行为。

跨注意力本身对来源的同步重排不敏感：同时重排键和值，输出可保持不变。但空间、时间和对象身份常需要位置信息。若把区域顺序打乱却不带位置，模型可能无法判断左右；若把位置编码与内容错配，得到的又是另一输入。评价应明确是否要求集合不变，还是序列或空间结构需要保留。

<a id="sec-2-1"></a>

<a id="mm-2-detail-11"></a>

### 3.3 局部绑定与关系推断

一个词查询多个区域，可以得到与当前词相关的上下文，但注意力权重不是对象关系正确性的完整证明。模型可能把属性绑定到错误主体，或通过语言先验猜答案。应测试属性交换、对象交换、数量改变和遮挡，让正确答案确实依赖视觉证据。一个高权重区域也可能只提供背景捷径。

跨注意力提供交互接口，真正会不会使用它取决于训练任务。若问题中已经泄漏答案，模型不必读取来源；若训练图像总与某类文本模板绑定，模型可能记住模板。可以在保持问题文字不变的情况下改变关键视觉事实，观察回答是否同步改变。成对反事实比单条可视化更能检验证据使用。

**一个看得见的绑定信息丢失反例。**

![红圆和蓝方与蓝圆和红方拥有相同边际属性，但绑定关系不同](images/02-img-color-shape-binding.webp)

[打开原图放大](images/02-img-color-shape-binding.webp)

场景 A 为左边红圆、右边蓝方，场景 B 为左边蓝圆、右边红方。两幅图各有一个红物体、一个蓝物体、一个圆、一个方，也各有左右两个位置。对同一个问题“红色物体是什么形状”，答案却分别是圆形、方形。红色数量与形状数量都正确，并不代表模型知道哪一个形状属于红色对象。

把信息丢失明确落实到一个编码器，而不是笼统归咎于池化。假定每个对象用六维向量表示：红/蓝两个颜色独热分量、圆/方两个形状独热分量、左/右两个位置独热分量，将三组拼接后对两个对象取均值。两场景都得到 $`(0.5,0.5,0.5,0.5,0.5,0.5)`$，交叉属性关系在进入问答器前已经被丢掉。任何只接收该摘要与同一问题的确定性问答器，都必须给两场景相同输出，因而至少答错一个；若这两个场景等概率且答案只在这两类中选择，最优成功率也至多一半。

这个结论只针对上述分组独热再平均的编码，不能推广成“所有全局池化都不可能绑定”。池化前保留颜色与形状的联合特征，或保留对象 token 并让查询参与对象读取，都可能区分两场景；仍需训练和反事实测试验证模型确实使用了绑定关系。图是自建二维诊断算例，不是 CLEVR 数据样本或性能实验。[CLEVR 原论文](https://arxiv.org/pdf/1612.06890)用可控对象属性与问题检验组合推理，正是为了把这种能力与语言、场景频率的捷径区分开。

<a id="mm-2-detail-12"></a>

### 3.4 实验二：手算权重、来源重排与空行

下面构造一个查询和两个来源，使注意力概率恰好为四分之一与四分之三，输出为二点五。随后验证来源同步重排不改变结果，掩码排除某来源，以及全部来源不可见时主动报错。实验实现故意把验证放在 softmax 前，避免得到无效数值后再替换为零。

```python
import math
import torch
torch.set_num_threads(1)
def cross(q,k,v,mask):
    if mask.shape != (len(q),len(k)) or not mask.any(dim=1).all():
        raise ValueError('each query needs an allowed source')
    score = q@k.T/math.sqrt(q.shape[1])
    p = score.masked_fill(~mask,-torch.inf).softmax(1)
    return p@v,p
q = torch.tensor([[1.]],dtype=torch.float64)
k = torch.tensor([[0.],[math.log(3)]],dtype=torch.float64)
v = torch.tensor([[1.],[3.]],dtype=torch.float64)
mask = torch.ones(1,2,dtype=torch.bool)
out,p = cross(q,k,v,mask)
assert torch.allclose(p,torch.tensor([[.25,.75]],dtype=torch.float64))
assert torch.allclose(out,torch.tensor([[2.5]],dtype=torch.float64))
order = torch.tensor([1,0])
assert torch.allclose(cross(q,k[order],v[order],mask[:,order])[0],out)
only_first = torch.tensor([[True,False]])
assert cross(q,k,v,only_first)[0].item() == 1
try: cross(q,k,v,torch.zeros_like(mask))
except ValueError: pass
else: raise AssertionError('all-masked row accepted')
print('attention',p.tolist(),'output',out.item())
```

同步重排不变并不表示可以把键和值分别重排。若某区域的键描述红球，值却来自蓝盒，模型读取关系会被破坏，形状和概率和仍可能完全正常。实际管道要共同维护区域身份、位置、掩码和内容；仅检查注意力矩阵归一化，无法发现来源错配。

<a id="mm2-cross-source-ledger"></a>

### 图解：同一次读取的归一化、身份与可见性

![比较正确绑定、键值同步交换、只换键与屏蔽来源四种读取](images/02-img-key-value-binding-interventions.webp)

[打开原图放大](images/02-img-key-value-binding-interventions.webp)

先沿同一个原始算例走完计算：键宽度为一，故缩放因子也是一；查询与两个键的点积为 $`(0,\log3)`$，指数为 $`(1,3)`$，沿来源的分母为四。得到的权重与输出是

```math
a=\left(\frac14,\frac34\right),
\qquad
o=\frac14\times1+\frac34\times3=\frac52.
```

这里 $`\frac34`$ 的含义是当前查询对第二个**值消息**的读取权重，不是“第二模态有四分之三概率正确”，也不是高斯融合中的观测精度。不同机制可能都出现加权平均，却只有各自条件模型才能赋予系数相应概率解释。注意力定义与缩放依据可对照 [Transformer 第 3.2.1 节](https://arxiv.org/html/1706.03762v7#S3.SS2.SSS1)。

让第二个值连续变化，三种操作对应的输出函数分别为正确绑定 $`o(v_2)=\frac14+\frac34v_2`$、只交换键 $`o(v_2)=\frac34+\frac14v_2`$、删除第二来源 $`o(v_2)=1`$。在 $`v_2=1`$ 时三种操作碰巧同输出，单点通过不能证明绑定与掩码正确，而原始 $`v_2=3`$ 可区分三者，具体结果列在表中。

随后核对同一输入的其他对照。同步交换键和值后，权重顺序变成 $`(\frac34,\frac14)`$，对应值同时变成 $`(3,1)`$，所以输出仍为 $`\frac52`$。只交换键却保留原值时，归一化权重同样完全合法，输出却变成 $`\frac34\times1+\frac14\times3=\frac32`$。这不是浮点误差，而是键描述的来源与实际被读取的消息已经错绑。区域位置、时间戳和掩码也属于来源身份的一部分，应共同移动。

删除第二来源与把它的值改成零也不同。正确屏蔽将它的 softmax 指数贡献从三变成零，剩余分母为一，因此输出是一。若只把第二个值清零，分母仍是四，输出为 $`\frac14`$；连键一起清零，两个指数变成一和一，输出也只是 $`\frac12`$。这两种填零都没有实现“没有第二来源”。它们可以作为某种特定模型输入，但不能偷偷替代掩码协议。

全部来源被屏蔽时，分母为零，不能按普通 softmax 公式计算合法权重。本章函数选择在计算前拒绝这类行；一个实际系统也可以进入训练过的空来源分支，但必须明确该分支的含义。事后把无效输出替换成零，只改变了数值表现，并没有自动定义概率路由或缺失推断。后面的缺失高斯图进一步说明，即使点输出也恰好为零，观测状态仍可能完全不同。

<a id="mm-2-detail-13"></a>

## 4. 缺失模态不是普通的零输入

<a id="mm-2-detail-14"></a>

### 4.1 缺失状态与观测值分开

零可以是合法温度、静音片段或黑色像素。用零代替缺失却不提供掩码，会让模型无法区分真实零和未观测。应把可用性作为显式输入，或使用经过训练的缺失标记，并定义相应融合分支。部署时临时输入一个从未训练过的全零张量，不等于模型已经具备缺失降级能力。

缺失模式也可能携带信息。例如某个采集流程只有特定状态才拍照，模型可能通过是否有图像预测标签。这个关联可以在当前数据上有效，却在流程变化后失效。需要区分随机缺失、依赖已知信息的缺失和依赖未观测状态的缺失，并在相应假设下设计训练与评价，不能只随机丢模态就声称对所有缺失机制稳健。

<a id="mm-missingness-selection-shift"></a>

### 图解：从缺失掩码预测到采集规则变化

![相同的零内容下，状态依赖采集使掩码携带信息，独立采集则不会](images/02-img-missingness-selection-shift.webp)

[打开原图放大](images/02-img-missingness-selection-shift.webp)

前面的“未观测项不参与测量更新”有一个条件：缺失机制不再提供关于潜在状态的额外证据。现在故意打破它。设二元标签 $`Y`$ 的先验各为二分之一，唯一模态的真实内容恒为零，因而内容值本身完全不能区分标签。$`M=1`$ 表示已采集，$`M=0`$ 表示未采集；零填充后两种状态的数值张量都为零，但掩码不同。

在训练总体中，规定

```math
\begin{aligned}
&P(M=1\mid Y=1)=0.9,\\
&\quad P(M=1\mid Y=0)=0.1.
\end{aligned}
```

用一百人复算该比例，可设两个类别各五十人，分别有四十五人和五人被采集。贝叶斯公式给出

```math
\begin{aligned}
&P(Y=1\mid M=1)\\
&\quad =\frac{0.9\times0.5}{0.9\times0.5+0.1\times0.5}
=0.9,
\end{aligned}
```

同理，$`P(Y=1\mid M=0)=0.1`$。模型只读掩码，按“采集了就判正，没采集就判负”，即可达到九成准确率。这个系统甚至不需要查看任何图像或声音；它学到的是采集过程与目标的关联。标签在训练时用于监督、在推理时未知，图中没有把标签作为预测输入。

部署时改成普遍随机采集：两个标签的采集概率都为二分之一，其余标签先验和模态内容保持不变。若仍取一百人的整数计数，每种掩码都包含 25 个正例和 25 个负例，因此

```math
P_{\mathrm{deploy}}(Y=1\mid M)=\frac12.
```

冻结的原分类规则准确率降至二分之一。若它仍报告训练时的 $`0.9`$ 或 $`0.1`$，则部署总体上的期望负对数似然为

```math
\begin{aligned}
&-\frac12\log0.9-\frac12\log0.1\\
&\quad =-\frac12\log0.09
\approx1.203973,
\end{aligned}
```

比始终报告二分之一的 $`\log2\approx0.693147`$ 更差。这里不仅阈值决策失效，置信概率也失配了。图中每个条带对应五十条记录，颜色长度表示正负例比例。

**能推断什么，不能推断什么？** 显式掩码有必要，因为它防止真实零和缺失被强制混同；但掩码可见不保证关联可迁移。随机模态丢弃覆盖的是指定随机化规则，不能据此证明已经覆盖真实状态相关的采集。在同一采集机制下，利用掩码可以是合理预测；若目标是跨医院、设备或流程泛化，就要按机制变化设置验证。没有机制或其他识别假设，也不能只靠观察表格证明关联的因果来源。

可参考 [Le Morvan 等关于缺失数据预测的原论文](https://proceedings.mlr.press/v108/morvan20a/morvan20a.pdf)：预测目标一般依赖已观测内容和缺失模式，不能把“补全原值”和“得到最佳预测”视为同一问题。此处二元表是独立构造的最小反例，并未声称该论文证明任意缺失机制变化下都能保持性能。

**检验问题。** 保持总采集率二分之一，但把两类采集概率交换成 $`0.1,0.9`$，冻结规则准确率会进一步降到十分之一。只匹配总体缺失率不能发现这种反转；应同时检查分群体、标签或可获取代理状态下的模式分布。

<a id="mm-2-detail-15"></a>

### 4.2 模态丢弃训练与其覆盖范围

训练时随机丢弃某通道，可以让网络学习在若干可用性组合下工作。但丢弃概率决定各组合的有效监督量，若两个通道同时缺失，模型只能依赖先验或其他输入。随机丢弃主要覆盖人为指定的缺失分布，不保证适应某群体设备故障或某类事件特有缺失。应按真实缺失模式分层评价。

完整输入质量提高而缺失输入变差，可能是模型越来越依赖某通道。可以设定缺失场景为硬约束或多任务目标，记录每种组合的损失与样本数。不能只报告所有场景混合平均，因为占比大的完整输入会掩盖降级失败。对齐、融合和缺失能力可以共享参数，但需要各自明确验收。

<a id="mm-2-detail-16"></a>

### 4.3 实验三：只对可见测量更新后验

这个例子把观测值与可用性分开，要求噪声方差有限且严格为正。改变一个不可见字段的数值，不应影响输出；真实零与缺失则应有不同解释。它使用正确指定的高斯模型，验证的是可见信息边界，而不是训练一个能够自动发现缺失机制的网络。

```python
import numpy as np
def posterior(values,available,noise_variance):
    values = np.asarray(values,dtype=float)
    available = np.asarray(available,dtype=bool)
    noise_variance = np.asarray(noise_variance,dtype=float)
    if values.shape != available.shape or values.shape != noise_variance.shape:
        raise ValueError('shape mismatch')
    if (not np.isfinite(values[available]).all()
            or not np.isfinite(noise_variance).all()
            or not (noise_variance>0).all()):
        raise ValueError('invalid observed values or variance')
    precision = 1.+np.sum(1/noise_variance[available])
    mean = np.sum(values[available]/noise_variance[available])/precision
    return mean,1/precision
m1 = posterior([0.,999.],[True,False],[1.,1.])
m2 = posterior([0.,-999.],[True,False],[1.,1.])
assert m1 == m2 == (0.,.5)
missing = posterior([0.,0.],[False,False],[1.,1.])
assert missing == (0.,1.) and missing != m1
both = posterior([0.,2.],[True,True],[1.,1.])
assert np.allclose(both,(2/3,1/3))
assert both[1] < m1[1] < missing[1]
print('observed_zero',m1,'all_missing',missing,'both_observed',both)
```

后验均值相同并不代表状态相同：真实零测量后均值仍零，但方差缩小；全部缺失时方差保留先验。若只看点预测，可能漏掉这种不确定性差异。生成与决策系统需要根据任务考虑分布信息，而不总把一个均值当作完整输出。

<a id="visual-local-multimodallearning-02"></a>

### 图解：融合前先辨认模态缺失

![真实零与缺失状态的高斯后验精度不同，错误填零会高估证据](images/02-img-missing-vs-real-zero.webp)

[打开原图放大](images/02-img-missing-vs-real-zero.webp)

表使用实验三的先验 $`N(0,1)`$ 与单位观测噪声方差。四种情况都从先验精度一开始。每个真实可见测量增加一单位精度，错误填入的零若被当成测量也会虚增精度。令 $`\tau`$ 表示后验精度、$`\eta`$ 表示精度加权和，则

```math
\begin{aligned}
\tau&=1+\sum_{r:\,M_r=1}1,\\[4pt]
\eta&=\sum_{r:\,M_r=1}x_r,\\[4pt]
m&=\frac{\eta}{\tau},
\qquad
v=\frac1{\tau}.
\end{aligned}
```

按这份账本逐项读图：两项都缺失时，没有任何观测项，$`(\tau,\eta)=(1,0)`$，后验等于先验；第一项真实观测为零时，虽然 $`\eta`$ 仍为零，精度增加到二，方差变成 $`\frac12`$。这说明信息可以只改变不确定性、不改变点均值。第二个槽中的 $`999`$ 没有被观测，不能参加求和；改成 $`-999`$ 或其他占位值，结果仍应不变。

两项真实观测为零和二时，$`(\tau,\eta)=(3,2)`$，所以后验为 $`N(\frac23,\frac13)`$。最后一行对应一种错误操作。两项其实都缺失，却把填入的两个零当成真实测量。它会给出 $`N(0,\frac13)`$，均值看似平静，方差却凭空缩小了三倍。密度曲线更尖不能证明证据更充分，要核对尖锐程度来自哪些真实观测。

这张图并未证明任意缺失场景都能只删除似然项。人工程序把可用性视为外部指定、对潜变量不提供额外证据的选择。如果上传行为本身依赖状态，通常应写成

```math
\begin{aligned}
&p(z\mid x_{\mathrm{obs}},M)
\propto
p(z)
\int
p(x_{\mathrm{obs}},x_{\mathrm{mis}}\mid z)\,\\
&p(M\mid z,x_{\mathrm{obs}},x_{\mathrm{mis}})\,
dx_{\mathrm{mis}}.
\end{aligned}
```

只有在相应假设允许把缺失机制项从关于 $`z`$ 的更新中消去时，才能退回图中的简单更新。例如，若固定已观测信息后，$`M`$ 与 $`(z,x_{\mathrm{mis}})`$ 条件独立，该机制项就与 $`z`$ 无关。否则缺失本身可能改变后验，后验甚至不再是高斯；这与 [12.1 节](#mm-2-detail-55) 的采集流程例子一致。缺失过程能否忽略需要条件，可参见 [Rubin 原论文摘要及出版记录](https://dash.harvard.edu/entities/publication/73120378-8764-6bd4-e053-0100007fdf3b)。[MVAE 第 2 节](https://arxiv.org/html/1802.05335v3#S2) 则展示了在给定条件独立生成模型后，如何为不同观测子集组合推断因子；这仍不能替代对真实采集机制的判断。

## 5. 条件生成的目标与多解性

<a id="mm-2-detail-18"></a>

### 5.1 自回归条件序列

根据图像、音频或结构化输入 $`c`$ 生成文本时，可定义 $`p(y\mid c)=\prod_t p(y_t\mid y_{\lt t},c)`$。训练时真实前缀已知，推理时前缀包含自身生成；因果掩码必须同时维护文本未来不可见和允许来源可见。跨注意力通常把条件编码为来源记忆，语言网络逐位置读取，但也可以采用其他桥接方式。

最大似然训练强调参考序列，并不意味着只有这一种正确表达。若每个条件只标一个参考，模型无法仅由该标注知道全部同义答案。评价应允许语义等价、结构正确和必要事实覆盖，而不是只做逐字匹配。另一方面，过于宽松的相似度评价也可能接受主体、数字或否定错误，需要明确不可替代的事实字段。

<a id="mm-2-detail-19"></a>

### 5.2 连续信号生成与分布匹配

条件图像、音频或动作生成可能有多种合法结果。平方误差的最优点预测是条件均值，它可以在多峰分布中落到不典型位置；从模型随机采样则可能保留多解，但单次样本与某个参考之间误差较大。这两种行为回答不同目标，不能只用一种点误差评价全部生成质量。

条件扩散等模型还需要明确噪声过程、条件输入和引导规则。改变引导强度可能提高条件遵从却减少覆盖，筛选输出也改变最终分布与成本。应同时报告条件正确、样本有效、类内多样和失败率，而不是挑最好的几个例子。生成越自由，越需要先定义什么构成合法输出。

<a id="mm-2-detail-20"></a>

## 6. 评价生成时区分四个问题

<a id="mm-2-detail-21"></a>

### 6.1 内容、依据、遵从和覆盖

内容正确评价输出是否满足任务事实；依据评价这些事实是否由允许条件支持；遵从评价是否按要求格式、对象和约束生成；覆盖评价多次生成是否保留合理变化。一个回答可以事实碰巧正确却未使用图像，一个图像可以视觉漂亮却对象数量错误，一个系统也可以每次输出同一合理样本却遗漏多数模式。

指标应与这些事件分别对应。文本重叠分数可以帮助比较措辞，不能独立证明视觉依据；外部表示距离可以衡量某类语义接近，可能忽略文字和精确数量；人评也需要盲化、标准和分歧处理。评价器本身应有已知反例集合，防止生成器优化了指标捷径而不改善目标。

<a id="sec-1-1"></a>

<a id="mm-2-detail-22"></a>

### 6.2 实验四：点误差与条件分布的区别

先让真实输出等概率为负一或一。始终预测零能最小化平方误差，却不产生任何真实模式；独立随机生成合法模式会有更大单样本平方误差。再构造两个条件的二元结果概率，说明忽略条件也能匹配总体频率，但条件对数评分更差。两部分分别对应多解与条件利用。

```python
import numpy as np
rng = np.random.default_rng(73)
y = rng.choice([-1.,1.],size=40000)
sample = rng.choice([-1.,1.],size=len(y))
mse_mean = np.mean(y*y)
mse_sample = np.mean((y-sample)**2)
assert mse_mean == 1 and abs(mse_sample-2) < .05
assert np.all(np.abs(sample)==1) and not np.any(np.zeros_like(y)==y)
condition = rng.integers(0,2,size=50000)
truth_p = np.where(condition==0,.2,.8)
label = (rng.random(len(condition)) < truth_p).astype(float)
def nll(p):
    return -np.mean(label*np.log(p)+(1-label)*np.log1p(-p))
conditional = nll(truth_p)
blind = nll(np.full_like(truth_p,.5))
assert conditional < blind-.15
assert abs(label.mean()-.5) < .015
print('point/random sample MSE',mse_mean,mse_sample)
print('conditional/blind NLL',conditional,blind,'global positive frequency',label.mean())
```

这个实验没有证明随机输出总比均值更好，而是说明必须先决定要点估计还是完整分布。条件二元例子也提醒我们，总体样本比例正确不足以证明按条件生成正确。应在每种条件内部检查，再按真实请求权重汇总，而不是让不同条件的错误互相抵消。

<a id="mm2-generation-score-targets"></a>

### 图解：点、随机样本与条件分布的三种评价

![点预测和独立采样的均方误差，以及条件概率评分与采样错误率](images/02-img-predictive-scores.webp)

[打开原图放大](images/02-img-predictive-scores.webp)

左表对应实验四的第一个分布。真实 $`Y`$ 在 $`-1`$ 与 $`1`$ 各占一半，因此 $`E[Y]=0`$、$`\mathrm{Var}(Y)=1`$。若任务要求一个点 $`a`$，则

```math
E[(Y-a)^2]=1+a^2,
```

最优点预测确实是零，风险为一。若任务要求独立生成一个同分布样本 $`\widehat Y`$，两次抽样有一半概率不同，届时平方距离为四，故

```math
\begin{aligned}
&E[(Y-\widehat Y)^2]\\
&\quad =E[Y^2]+E[\widehat Y^2]-2E[Y]E[\widehat Y]
=2.
\end{aligned}
```

一个准确复现真实模式的生成分布，仍会输给点均值的这项误差。这是评价目标发生变化的结果，不能把它解读为生成器没有学到分布。同样，若两次样本不独立，例如共享了参考答案或按真值筛选，交叉项不再等于均值乘积，比较已经换了信息条件。

右表对应实验四的第二个任务。条件 $`C=0`$ 与 $`C=1`$ 等频，真实正例概率分别为 $`0.2`$ 与 $`0.8`$。正确模型报告对应概率，忽略条件的模型一律报告 $`0.5`$。两者生成的总体正例比例都为一半，但只有正确模型复现了每个条件的概率。表中分别保留概率评分和独立采样的不匹配率。

图中指标全部采用这一明确分布上的**理论期望**，与代码的有限随机估计区分。使用自然对数时，正确条件模型的 NLL 为

```math
\begin{aligned}
&-\frac12\sum_{c=0}^{1}
\left[
p_c\log p_c+(1-p_c)\log(1-p_c)
\right]\\
&\quad =-0.2\log0.2-0.8\log0.8\\
&\quad \approx0.500402,
\end{aligned}
```

忽略条件的 NLL 为 $`\log2\approx0.693147`$。两者差距约 $`0.192745`$ nat；在这个真实条件模型中，它也是 $`I(Y;C)`$。原程序观察到约 $`0.5019`$ 并不矛盾，因为有限样本的条件数量和标签频率都存在随机波动。

二元 Brier 在此按 $`E[(Y-q_C)^2]`$ 定义，仅使用一个正例概率；对应理论值为 $`0.16`$ 与 $`0.25`$。若采用两个类别的平方差之和，两个数都会翻倍，方法次序不变，但报告时必须统一约定。关于 log 与二次概率评分的性质，可参见 [Gneiting 与 Raftery 的原论文第 3 节](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)。

最后一行评价的是另一个对象：先按模型概率随机生成一个标签，再与同条件下独立抽到的真实标签比较。正确条件采样的不匹配率为 $`2p_C(1-p_C)=0.32`$，忽略条件采样则为 $`0.5`$。它们都不是 Brier，因为后者直接评价报告的概率，而前者增加了一次抽样随机性。若目标是最小错误率的单次决定，条件众数的错误率反而是 $`0.2`$；它也没有因此证明随机生成的完整分布更差。

读图时应先选择要交付的对象：一个点、一次可用样本，还是一套条件概率。之后再把事实合法性、条件依赖与合理模式覆盖分别核验。给点预测使用 MSE、给概率使用适当评分、给样本检查合法性与分布关系，才能避免让指标替任务作决定。

## 7. 证据使用的因果式诊断

<a id="mm-2-detail-24"></a>

### 7.1 移除、交换与冲突对照

只比较有无某模态，可能混淆信息增量与输入分布变化。更细对照是保持问题、来源和格式不变，只交换关键事实；或者保持事实不变，只改变风格与背景。若答案随无关背景改变却不随关键对象改变，说明模型依赖错误线索。干预必须真实改变可见信息，不能把隐藏标签偷偷加入输入。

冲突实验应分别安排视觉正确文本错误、文本正确视觉错误和双方都不足三种情况，并说明可靠性规则来自哪里。若没有外部真值或来源优先规则，系统可能只能表达冲突。不能预先规定永远相信某模态，然后把遵守该规则当成普遍推理能力。可靠性判断需要相应证据与训练覆盖。

<a id="mm-2-detail-25"></a>

### 7.2 归因图与注意力图的边界

权重较高可以提示模型读取了某来源，但输出还受值向量、残差、其他头和后续层影响。某来源权重高而值与平均相近，对输出的敏感度可能很小；某来源权重低却携带独特信息，也可能重要。应结合输入干预和可检查输出，而不是把热力图直接翻译成因果解释。

梯度归因也依赖局部参数点与基线选择，遮挡又可能生成分布外输入。多种方法一致可以增强诊断，但不自动消除共享偏差。好的解释报告会说明测量对象、干预方式和替代解释，而不是只展示一张最符合故事的图。第三章会用解析梯度把这些依赖展开。

## 8. 更深入的概率融合：依赖与信息增量

<a id="mm-2-detail-46"></a>

### 8.1 相关高斯测量的完整公式

把多个观测写成向量 $`x=\mathbf1 z+\epsilon`$，噪声 $`\epsilon\sim N(0,R)`$ 与 $`z`$ 独立，协方差为正定矩阵 $`R`$，先验仍为 $`N(m_0,v_0)`$ 且 $`v_0>0`$。将先验和观测的 log 密度中关于 $`z`$ 的二次项收集起来，得到后验精度 $`v^{-1}=v_0^{-1}+\mathbf1^TR^{-1}\mathbf1`$，均值 $`m=v(\frac{m_0}{v_0}+\mathbf1^TR^{-1}x)`$。独立噪声只是 $`R`$ 为对角矩阵的特例。

若两个通道噪声方差均为一、相关系数为零点九，它们合计观测精度为 $`\frac{2}{(1+0.9)}`$，只比一个观测略高，而不是独立假设下的二。完全相同的复制测量会使协方差奇异，此时不能直接使用普通矩阵逆，应从独立信息维度重新建模。复制字段增加了记录长度，却没有增加同等数量的独立证据。

在更一般的相关与偏差结构下，最优线性组合甚至可能包含负权重，用于抵消共同噪声。这与 softmax 注意力只产生非负归一化权重不同。后者仍可通过值投影与多层网络表达复杂函数，但单个权重不能简单解释成统计最优测量精度。比较概率模型和神经模块时，应区分函数表达与某个中间系数的含义。

<a id="visual-correlated-fusion"></a>

#### 算例：一个更大的读数为什么反而应当被减去

![观测误差强正相关时，后验均值对第二条读数的系数为负](images/02-img-correlated-observation-weight.webp)

[打开原图放大](images/02-img-correlated-observation-weight.webp)

固定实验一的先验 $`N(0,4)`$ 和两次读数 $`x=(1,3)^\mathsf T`$，但这次明确改变噪声模型。取

```math
R=\begin{pmatrix}1&\frac32\\[2pt]\frac32&4\end{pmatrix},\qquad
\det R=\frac74>0.
```

它是合法正定协方差，噪声相关系数为 $`\frac34`$。直接求解 $`Rj=\mathbf1`$ 得 $`j=(\frac{10}7,-\frac27)^\mathsf T`$，因此总精度为 $`\frac14+\frac87=\frac{39}{28}`$，后验为

```math
\begin{aligned}
&v=\frac{28}{39},\\
&\quad m=\frac{40}{39}x_1-\frac8{39}x_2=\frac{16}{39}\approx0.410256.
\end{aligned}
```

第二观测的系数为负并不表示方差为负。两次误差高度正相关，且第二通道噪声尺度更大；当第二读数相对第一读数偏高时，模型将其中一部分解释为共同噪声的迹象，并作抵消。若错误地保留独立噪声假设，同样两个读数会得到实验一的 $`m=\frac76`$、$`v=\frac23`$。两者差异来自统计模型改变，不能把一个模型的均值与另一个模型的方差拼成答案。

若把相关系数从零改变到 $`0.95`$，可在每个相关系数下重新求解同一后验公式。第二系数在 $`\rho=\frac12`$ 时为零，此后变负；先验的系数也随相关性变化，因此观测系数之和不必为一。这里讨论的是原始标量读数在完整后验均值中的系数，不是某个注意力头的非负 softmax 权重。神经网络可以通过值投影、多头与后续层表达抵消，但不能因此把它的单个权重直接解释成这套概率模型中的观测精度。

<a id="mm-2-detail-47"></a>

### 8.2 后验专家乘积为什么要除一次先验

在给定潜变量时两观测条件独立的模型中，联合后验正比于先验乘两项似然。若已经分别得到两个单模态后验，则它们的乘积包含两次先验，因此联合后验正比于两个后验的乘积再除以一次先验。该比值在先验为正的共同支持上定义，并要求归一化常数有限且非零。直接相乘单模态后验，会重复使用共同背景信息，可能产生过度收缩和过度确定。

这个等式要求每个单模态后验确实对应同一个先验和兼容观测模型。任意两个神经网络输出的向量或概率，不能因为被称作专家就自动满足该公式。若每个网络都已使用共享文本或共同元数据，条件独立假设更可能被破坏。应明确专家各自看到什么，避免隐藏的信息重复。

专家乘积倾向于保留多个约束共同支持的区域，专家混合则表示从若干替代解释中选择或平均。前者类似交集，后者类似并列可能性，但这种直觉仍要对应具体归一化密度。如果某专家在真实区域给出严格零支持，乘积可能无法恢复；若专家互相冲突，归一化常数可能极小，数值与语义都需要检查。融合不是越尖锐越好，应该保留真实不确定性。

<a id="mm-2-detail-48"></a>

### 8.3 用条件互信息定义理想增量

在 log 评分下，只读第一模态的最优平均风险为条件熵，读取第二模态后的风险为更细条件熵，两者之差是目标与第二模态在第一模态给定后的条件互信息。这个量说明新增通道对该目标的理想信息价值，而不是对所有任务的普遍价值。若第二模态只重复第一模态，它的增量可以为零。

若目标记为 $`Z`$、两模态为 $`X,Y`$，上述差可以具体写成

```math
\begin{aligned}
&R_X^*-R_{X,Y}^*\\
&=E_{X,Y}D_{\mathrm{KL}}\bigl(p(Z\mid X,Y)\Vert p(Z\mid X)\bigr)\\
&=I(Z;Y\mid X).
\end{aligned}
```

在有限离散目标上这些熵与风险通常有限；更一般的情形需要条件分布、共同参考测度和相应可积性，才能把两项最优 log 风险直接相减。连续变量的微分熵不一定为正，也可能为无穷，不能机械计算无穷减无穷；条件 KL 的定义才是非负信息增量的可靠起点。这个条件避免把对有限标签成立的风险差推导不加限制搬到奇异连续分布上。

该结论比较的是同一真实分布上理想最优预测器。有限网络、有限数据和优化误差会让实际加入模态后表现变差，可能因为模型没有学会忽略噪声。不能用信息论的非负增量证明某个实际架构一定改善，也不能因一次负结果就断言输入没有信息。应分别测可表达性、优化和独立泛化。

不确定性减少通常是对总体期望而言，不要求每个具体新观测都让所有不确定性指标下降。某条证据可能推翻原先过度集中的判断，暴露更多可能性。高斯固定协方差例子具有特殊结构，后验方差只取决于可见性而不取决于测量值，不能把这一点推广到所有非线性多峰任务。精确说明条件，能避免把合理的概率更新误判为系统不稳定。

<a id="visual-mechanism-multimodallearning-02"></a>

### 图解：额外证据可能使单次预测更不确定

<a id="conditional-entropy-per-observation"></a>

![证据出现和未出现的两条分支产生不同后验，有时单次方差会增加](images/02-img-evidence-uncertainty-branches.webp)

[打开原图放大](images/02-img-evidence-uncertainty-branches.webp)

**用全方差公式复核同一份证据表。** 定义指示变量 $`Y=\mathbf{1}\{Z=1\}`$，其先验方差为 $`0.9\times0.1=0.09`$。出现 E 的概率为 $`0.18`$，其后验参数为二分之一，方差为四分之一；不出现 E 的概率为 $`0.82`$，后验参数为 $`\frac{81}{82}`$。于是平均后验方差为 $`0.18\times0.25+0.82\times\frac{81}{82}\times\frac1{82}\approx0.054878`$，低于先验方差。

后验均值本身在两个分支上波动，其方差约为 $`0.035122`$；两部分相加恰好恢复 $`0.09`$。全方差分解先在两个分支之间平均条件方差，再加上条件均值的方差。具体证据可能把后验推向更模糊的二分之一，但平均意义下不确定性的减少仍与信息增益相容；这里的方差与下文以 nat 计量的熵是不同指标。

**从联合权重读出两个分支。** 图中同时保留证据出现与未出现两条路径，避免只展示增熵分支而让读者误以为与平均结论矛盾。第一类在两条路径的联合权重为 $`0.9×0.1=0.09`$ 与 $`0.9×0.9=0.81`$，第二类则为 $`0.1×0.9=0.09`$ 与 $`0.1×0.1=0.01`$。四个联合权重合计为一。每条路径分别按自己的总权重归一化，得到右侧两个后验，不能把两分支的类别权重混用同一个分母。

**条件与边界。** 可取合法似然 $`P(E\mid Z=1)=0.1`$、$`P(E\mid Z=2)=0.9`$。原类别概率为 0.9 与 0.1 时，$`P(E)=0.9\times0.1+0.1\times0.9=0.18`$，贝叶斯更新给出 $`P(Z=1\mid E)=\frac{0.09}{0.18}=0.5`$，另一类同样为 0.5。未出现该证据时，第一类后验为 $`\frac{0.81}{0.82}\approx0.9878`$。按两种证据结果取平均，条件熵约 0.1788 nat，低于原熵约 0.3251 nat；因此单次增熵与平均减熵完全相容。这个平均结论针对同一真实联合分布的后验，不能保证任意训练模型添加模态后预测熵或错误率下降。

平均条件熵的精确表达为

```math
\begin{aligned}
&H(Z\mid \mathbf1_E)
=0.18\,h\!\left(\frac12\right)
+0.82\,h\!\left(\frac{81}{82}\right)\\
&\quad \approx0.178772460,\\
&\quad h(p)=-p\log p-(1-p)\log(1-p).
\end{aligned}
```

未出现证据时的后验熵约为 $`0.065860936`$ nat。用同样单位计算的先验熵约为 $`0.325082973`$ nat，所以信息增量约为 $`0.146310513`$ nat。平均后验熵按两类观测的发生概率加权，所有项统一使用 nat。固定高斯噪声的后验方差逐例缩小，与本图二元后验熵单次增大也并不冲突，因为模型族和不确定性函数不同。

## 9. 跨注意力的结构、序列与压缩

<a id="mm-2-detail-50"></a>

### 9.1 注意力是内容寻址，不是自动事实验证

查询和键决定路由，值决定被传递的内容。一个正确的路由可以读取错误值，一个主题相似的键也可能对应不支持答案的内容。把键和值分离理解，有助于解释为什么相似度高不等于证据可靠。来源身份、版本、单位和权限应由数据与执行协议维护，不能完全交给点积自行发现。

在一个头内，每个查询输出位于值向量的凸包，因为 softmax 权重非负且和为一。但投影、残差和后续非线性会改变完整模块的表达，不能据此说整个网络只能做原始输入的凸组合。局部数学性质适合诊断某一步，不能未经推导就限制全部深层系统。反过来，整体表达强也不保证训练一定学会所需关系。

<a id="mm-2-detail-51"></a>

### 9.2 文本因果掩码与来源可见性

生成文本时，第一个答案 token 可以读取条件来源和先前提示，但不能读取未来答案。若图像被编码为前缀 token，需要检查这些前缀自身的可见结构；若使用独立跨注意力，需要检查来源时间是否允许。训练时让来源编码器读取完整未来视频，而部署只见当前帧，会制造不合法条件信息，语言侧因果掩码并不能修复这一点。

同一批次的不同样本还需要隔离。把多个图像和文本拼成长序列后，如果跨样本注意力没有屏蔽，模型可能读取其他样本答案或来源。序列打包应保留样本边界、角色、位置与损失掩码。一个训练 loss 下降的系统仍可能通过这些边界错误获得优势，因此应使用只改变另一条样本的隔离测试。

<a id="mm-2-detail-52"></a>

### 9.3 位置编码与几何不变量

二维区域通常需要行列位置、尺度或边界框，音频与视频需要时间。位置是语义的一部分，却也可能引入不希望的绝对坐标依赖。若任务要求平移等变，应明确图像变换后位置如何同步改变；若任务需要绝对位置，例如仪表盘固定区域，绝对编码可能合理。选择不变量必须来自任务，而不是一概追求所有变换不变。

如果只对内容做重排而位置保持原槽位，输入含义已经改变；如果内容与位置一起重排，只是存储顺序改变，集合式来源模块可以保持输出。两种测试不能混淆。对来源置换的数学证明，应把全部输入字段包含在内，而不是只看特征矩阵。身份绑定的正确性往往比注意力公式本身更容易出错。

<a id="mm-2-detail-53"></a>

### 9.4 学习查询的压缩瓶颈

一些系统使用固定数量的可训练查询，从大量视觉或音频来源中抽取较短表示，再交给语言模型。这样可降低后续序列成本，但查询数量不自动等于对象数量，也不保证每个查询负责一个可解释实体。多个查询可能重复读取相同区域，或共同编码分布式信息。解释应由干预与任务证据支持，而不是给每个槽位随意起名。

压缩可以保留任务充分统计，也可能丢失细节。若目标问任意小字、精确计数或长时间顺序，固定少量查询可能成为瓶颈。可以按来源长度、对象数量和问题粒度分层测试，判断失败是否随信息需求增长。增加查询又带来语言侧成本，因此应报告质量与预算折中，而不是仅凭短序列就认定系统更高效且无损。

<a id="mm-2-detail-54"></a>

## 10. 缺失机制、插补与部署变化

<a id="mm-2-detail-55"></a>

### 10.1 缺失标记本身也是随机变量

记可用性为 $`M`$，正确目标一般是 $`p(z\mid x_{obs},M)`$，其含义可能与忽略可用性后的后验不同。若缺失依赖未观测状态，是否缺失就携带信息；若采集流程改变，这种关系也可能变化。模型使用可用性并非天然错误，但结论必须绑定采集机制，不能把当前相关性当成永恒规律。

例如只有警报发生时才上传音频，缺少音频可能暗示无警报。若新系统改为随机上传，同样的缺失标记不再有相同含义。单纯随机模态丢弃训练无法模拟所有这种变化。可以独立控制内容与可用性，构造采集策略迁移测试，检查模型是否依赖脆弱的流程线索。

<a id="mm-2-detail-56"></a>

### 10.2 插补均值不等于已观测事实

用模型预测缺失模态可以提供有用线索，但插补本身有不确定性。把预测均值当成真实观测输入融合器，可能让系统重复使用同一侧信息并过度自信。例如从文本生成一个图像特征，再把它与同一文本当作两项独立证据，实际上没有新增外部信息。应标记插补来源，并在评价中区分真实与合成条件。

如果使用多次插补，应在后续预测中正确传播不确定性，而不是只选最符合答案的一次。平均多个后验预测与对平均插补值运行非线性模型一般不相同，这是非线性期望的差异。可以在低维例子中手算，再测试实际系统对不确定性扩大的反应。插补质量不能仅按单个重构误差评价，还要看下游校准和任务表现。

<a id="mm-2-detail-57"></a>

### 10.3 缺失降级策略的选择

一种策略是使用共享模型并输入掩码，另一种是为不同可用性组合训练专门分支，还可以采用门控或专家组合。共享模型节省维护，但组合之间可能干扰；专门分支更清楚，却增加参数与稀有组合的数据需求。无论哪种，都要预先定义所有合法状态，尤其全部模态缺失或某模态无效时的行为。

服务端应区分没有上传、解析失败、质量不足和明确空内容。静音可以是有意义观测，损坏音频则是执行状态。把它们统一成同一个零向量，会丢掉诊断与概率含义。最终界面可以简洁，但内部数据契约应保留足够状态，才能解释错误并选择后续行动。

<a id="mm-2-detail-58"></a>

### 10.4 模态质量与选择性使用

有时某模态存在但质量很低，系统可以选择忽略或请求更清楚输入。质量指标必须与任务有关，图像清晰不代表关键对象可见，音频信噪比高不代表说话内容相关。门控应接受必要质量和可用性信息，并在独立场景验证，不能只用模态是否存在决定信任程度。

评价可以同时报告覆盖率和保留请求上的风险，观察拒绝低质量输入是否真正降低错误。若系统大量拒绝困难样本，剩余准确率会上升，因此必须保留总完成率。选择性回答是一个明确决策策略，不应被包装为底层模型无条件更准确。阈值需要在开发角色选择，最终确认冻结。

<a id="mm-2-detail-59"></a>

## 11. 条件生成的评分与多样性

<a id="mm-2-detail-60"></a>

### 11.1 对数评分为什么对应分布正确

对一个真实条件分布 $`p`$，模型分布为 $`q`$，期望负 log 概率等于真实熵加上 $`KL(p\Vert q)`$。在支持和期望条件适当时，理想最优是匹配完整分布，而不是只输出众数或均值。这解释了对数评分作为概率预测准则的价值。有限数据估计与模型错设仍会影响实际结论，不能把一次小测试当成总体分布已恢复。

二元 Brier 评分的期望也可分解为不可约方差加预测概率与真实概率的平方差，适合检查概率校准。它与采样后的单个零一结果误差不同。若只评价采样字符串是否恰好等于一个参考，可能惩罚合理多样性。应先区分要评价概率预测、点决策还是生成样本，再选择相应分母和准则。

<a id="mm-2-detail-61"></a>

### 11.2 参考数量与开放输出空间

同一条件可能有许多正确描述，一份参考无法穷尽。增加参考可以改善覆盖，但参考也可能共享风格或遗漏关键变化。可以建立结构化事实检查与开放措辞评价组合，明确哪些字段必须一致，哪些允许替换。对于创作或开放生成，评价标准还需要用户目的，不能假设所有输出有唯一客观排序。

多次生成的最佳匹配指标会随采样次数提高，即使模型没有变化。若用最优样本误差衡量多解覆盖，应统一次数，并同时报告平均质量与无效比例。只保留最佳样本会隐藏大量错误，若部署实际也会筛选，应把筛选器、信息条件和成本计入完整方法。评价协议要模拟真实交付，而不是给某方法额外机会。

<a id="mm-2-detail-62"></a>

### 11.3 多样性不能通过噪声伪造

无关随机变化可以增大向量距离或样本差异，却不增加有意义模式覆盖。应将合法性与多样性共同评价，例如先检查对象与条件约束，再统计允许变化的覆盖。对于人工混合分布，可以明确模式和概率；真实任务则可能需要可靠标签、外部验证和代表性人评，不能把像素方差直接叫创造力。

条件很具体时，合理输出本来可能变化很小；条件模糊时，单一输出可能遗漏大量可能性。因此多样性目标也条件相关。可以按条件歧义程度分层，观察模型是否在信息不足时保留多解、在信息充分时遵守精确约束。统一追求更大熵不一定有用，统一压低熵也可能过度确定。

<a id="mm-2-detail-63"></a>

### 11.4 事实依据与语言流畅分开

一个模型可以在视觉事实错误时仍给出非常自然的解释。语言评价器可能被流畅度影响，尤其当它没有真正读取原始模态。事实支持评价应提供必要来源或结构化真值，并测试数字、否定、主体与关系交换。对于音视频，还应核对时间位置，不能把整个片段的主题相关当作某一时刻事件证据。

解释过程也可能只是事后生成。若希望研究模型使用了哪个通道，应结合反事实条件替换和中间状态诊断，限定可观察结论。不能因为回答引用了某区域编号，就认定它的内部计算一定依据该区域。系统可以通过结构化绑定提高可审计性，但仍需验证绑定规则和数据身份。

<a id="mm-2-detail-64"></a>

## 12. 进阶研究设计：把融合收益拆开

<a id="mm-2-detail-65"></a>

### 12.1 单模态基线与联合必要性

融合模型优于任一单模态，并不一定说明学习了复杂互补。它可能只是对两个独立有用预测做平均，降低噪声。若研究重点是跨模态关系，应加入任一单侧都无法识别的任务，以及只需单侧的对照。两类结果分开，才能说明收益来自联合信息、集成稳定性还是额外参数。

反过来，联合必要任务上失败也不必然是融合层表达不足。编码器可能已经丢掉关键属性，标签可能存在歧义，训练样本可能不足。可以先提供理想特征检验融合函数，再恢复真实编码器。这种分阶段干预将表示瓶颈与交互瓶颈区分开，比直接比较最终分数更有诊断力。

<a id="mm-2-detail-66"></a>

### 12.2 参数与预算匹配的多种问题

固定参数量、固定训练样本、固定计算时间和固定输出延迟是不同公平问题，通常无法全部同时相同。应选与应用相关的主要预算，并报告其他资源。跨注意力成本随查询与来源长度乘积增长，压缩来源可以降低成本，却可能损失细节。真实速度还取决于设备和实现，本章只演示逻辑，不推测生产吞吐。

调参机会也属于资源。一个方法在开发集试验许多组合，另一个只用默认值，最好成绩不能直接归因于结构。报告搜索范围、评价频率和失败配置，有助于判断收益的获得成本。若资源有限，只能运行一次，也应如实保留限制，再用机制实验提供补充，而不是给单次结果加上不存在的稳定性保证。

<a id="mm-2-detail-67"></a>

### 12.3 来源组、时间和条件分层

多模态记录常由同一事件派生，视频帧、字幕和音频片段之间高度相关。按片段随机切分可能让模型在测试中见过同一事件背景。若目标是新事件或新主体，应按对应单位隔离；若目标是在线预测，还要限制未来帧和迟到文字。输入窗口的时间可见性应与标签时刻一致。

总体指标可以掩盖缺失模式、低质量输入、少数语言和细粒度关系的失败。分层表应给样本数、完成率和错误类型，避免小分组比例看起来很精确。模型比较采用同一查询的成对差异，相关来源可按组重采样。统计区间不能修复不代表部署分布的测试集，因此来源覆盖仍需单独讨论。

<a id="mm-2-detail-68"></a>

### 12.4 评价器也需要反例

给评价器准备事实正确但措辞不同、语言流畅但数值错误、引用存在但主体错配、视觉漂亮但数量错误等样本。检查它是否真正测量希望的事件。若评价器依据生成器的解释而不读取来源，可能被共同语言偏差误导。规则、人工和模型评价各有边界，可以组合，但不应把一致意见当作无需外部真值的证明。

评价器升级后应对全部比较方法一致重评，不能只给新方法放宽等价答案。若发现原标签错误，可以修订并记录版本，但旧新分数的差异不全是模型改进。可靠研究需要同时冻结输入、输出、判定和选择规则，让每个数字都能追溯到清楚事件。

<a id="mm-2-detail-69"></a>

## 13. 融合实验结果

<a id="mm-2-detail-74"></a>

### 13.1 本次实验结果与下一步问题

四段实验全部在 CPU 上运行通过。高斯后验例子得到均值约一点一六六七、方差约零点六六六七；跨注意力权重为四分之一和四分之三，输出二点五。缺失例子在真实零观测时方差为零点五，全部缺失时为一，说明点均值相同仍有不同证据量。它们是明确模型下的机制结果。

生成评价例子中，条件均值预测的平方误差为一，合法随机模式样本约一点九九四；条件二元预测 NLL 约零点五零一九，忽略条件约零点六九三一，总体正例比例仍约一半。这些数字让多解和条件利用的区别可复算。后续完整训练应检验网络能否学到这些关系，而不是把当前解析验证冒充已训练的大模型能力。
