## 1. 时间轴首先是测量对象

音频数组、视频帧列表和字幕片段不是天然共享的三个序列。每个数据流都有采集设备、起点、时间单位、采样间隔、缓存延迟与缺失机制。即使文件时长一致，也可能在中间经过剪辑或变速；即使数组长度相同，也不能说明第几个元素发生于同一时刻。学习前需要先说明观察对象与时间坐标，而不是直接把序列截成一样长再拼接。

<a id="av-4-detail-2"></a>

### 1.1 事件时间、设备时间和到达时间

事件时间描述现实中声音或动作发生的时刻；设备时间是采集系统为观察记录的时间；到达时间是数据进入处理端的时刻。缓存、网络和解码使三者不同。离线完整视频允许读取后续帧，在线系统在当前时刻只能使用已到达的信息。相同模型若换成在线任务，输入可见范围就改变，不能继续使用包含未来片段的特征而保留原结论。

可以为每个片段保存来源编号、原始时间戳、统一时间区间、到达时间、变换版本及有效性标记。这里的字段不是为了增加表格，而是为了回答具体问题：某句回答是否依赖尚未到达的字幕，偏移校正在哪个版本执行，某个声学窗口是否跨过缺口。对于历史回放，先按当时可见范围构造输入，再运行模型，避免离线清理后的完整资料偷偷提高在线评价。

<a id="av-4-detail-3"></a>

### 1.2 仿射时钟模型及其识别条件

短时间内可以用仿射模型连接两套时钟。令$t_a$为音频设备时间，$t_v$为视频参考时间，设

$$
t_v=\alpha t_a+\beta+\eta,
$$

其中$\alpha>0$表示时间尺度差，$\beta$表示起点偏移，$\eta$包含标注与测量误差。若只估计一个常量偏移，相当于假设$\alpha=1$；长片段中微小尺度差也会累积成明显错位。比如每秒相差千分之一，经过一千秒就相差一秒，开头同步不保证结尾仍同步。

给定至少两个时间不同的可信共同事件，设计矩阵两列为$t_a$与常数一。当两列线性独立时，最小二乘可以识别尺度与偏移。若所有标志都挤在同一时刻，尺度难以识别；若只知道一个对应事件，则有无穷多组尺度偏移都能通过该点。增加同一时刻的重复标注可以降低某类噪声，却不能创造原本不存在的时间跨度信息。

最小二乘隐含误差模型。异常匹配、非线性设备漂移或分段剪辑会破坏一个全局仿射关系，此时应检查残差随时间的形状，考虑分段模型与独立验证事件。若两套时间戳都有显著误差，普通最小二乘将一侧视为无误差的假设也需重新评估。好的拟合数值不自动证明所有事件匹配正确，先验来源与可识别性仍不可省略。

<a id="sec-1-1"></a>

<a id="av-4-detail-4"></a>

### 1.3 手算偏移与漂移怎样分开

假设两个共同标志在音频时钟上分别为零秒与一百秒，在视频时钟上分别为零点二秒与一百点三秒。由两个方程相减得到尺度一千分之一的正偏差，再由第一点得到起点偏移零点二秒。只把第一点对齐会在后一百秒留下零点一秒残差。若任务区分先后只差几十毫秒，这个残差足以改变标签。

校正应明确方向。若已拟合从音频时间到视频参考时间的映射，音频窗口端点也应按同一映射变换；不能对开始时间加偏移、却忘记窗口长度同样被尺度改变。逆映射为先减偏移再除以尺度，直接把两个参数取负通常不正确。独立实现时用正向再逆向的往返检验，有助于发现这种看似细小却影响全链路的方向错误。

## 2. 采样粒度决定可观察的事件

视频每帧表示某个曝光区间或近似时刻，音频特征往往来自一个短窗，字幕常给句子级区间。它们并非同样精细的时间观察。时间戳相同也不代表观察范围相同：一个二十五毫秒声学窗与一个半秒字幕块可能都以同一时刻为中心，但后者混合了更多事件。需要将位置和感受范围一起保存，才能解释同步和因果可见性。

<a id="deep-dive-1"></a>

<a id="av-4-detail-6"></a>

### 2.1 从采样相位推导短事件的漏检概率

考虑间隔为$\Delta$的理想瞬时抽帧，事件持续$w$且满足$0<w\leq\Delta$。若事件起点相对网格的相位在一个间隔内均匀，至少一个采样点落在事件内的概率为$w/\Delta$，漏检概率为$1-w/\Delta$。证明只需观察一段长度为$\Delta$的相位轴：使下一采样点进入事件的起点位置区间长度恰为$w$。端点的开闭不改变连续相位概率。

当$w\geq\Delta$时，理想无限网格必然命中，概率为一。因此一般式是$\min(1,w/\Delta)$。这个结论依赖均匀相位、完整网格和瞬时观察，不包含缺帧、曝光积分、遮挡或识别错误。它给的是输入覆盖，不是模型准确率。即使覆盖概率很高，内容可能仍不可识别；反过来，未命中事件却答对，也可能靠其他线索而非真的观察到它。

若模型需要至少两个采样点辨认方向，仅命中一次又不够。可把事件窗口覆盖的网格点数作为随机变量，分析不同相位下有几个点，而不能沿用“至少一次命中”公式评价动作识别。任务需要的时间证据越细，采样设计越应围绕该证据而不是围绕固定帧数。短事件失败首先应检查实际输入是否包含足够观测，再讨论编码器容量。

<a id="av-4-detail-7"></a>

### 2.2 抽帧、重采样和混叠

均匀抽样可能让不同连续信号产生相同离散序列。对理想带限信号，采样定理给出避免这种频率混叠的条件；真实视频动作通常并不满足简单严格带限假设，因此不能机械用一个理论频率保证语义事件可辨。降低采样率前的低通滤波可以减少某类信号混叠，但也会抹去快速变化。保留高速细节与节省预算存在真实取舍。

音频重采样也不等于随意每隔几个点取一个。目标采样率降低时，先滤除超出新频带的成分，再按合适算法重采样，才有明确的信号意义。插值到更多点不会恢复采集时未记录的信息。视频补帧生成的是估计内容，可能帮助展示，却不能自动作为真实事件证据。报告应区分原始测量、确定性变换与生成填补，避免后处理改变证据身份。

<a id="av-4-detail-8"></a>

### 2.3 声学窗口的中心与在线延迟

长度为$L$、步长为$H$的声学窗，其第$k$个窗口覆盖从$kH$开始的$L$个采样点。标中心时常写为$(kH+(L-1)/2)/f_s$，标左边界则为$kH/f_s$。两种约定都可使用，但跨模态比较必须统一。只看特征帧序号会遗漏窗口长度和中心偏移，尤其当音频帧率与视频帧率不等时。

对在线系统，中心在当前时刻的对称窗口通常包含未来半个窗。若未来样本尚未到达，就需要等待或改为因果窗口，二者会改变延迟或特征。应报告算法需要的右侧上下文、缓存和推理耗时，而不只报告网络一次前向的时间。一个离线系统在完整片段上准确，并不能由此声称它在事件刚发生时就能给同样答案。

<a id="av-4-detail-9"></a>

### 2.4 句子时间戳不能充当词级精确标签

字幕给一段句子的起止时间，只说明这一整段话大概覆盖该区间，不证明每个词在区间中均匀排列。语速、停顿和口头修正都使简单等分失效。把等分位置用于可视化可以作为粗略占位，但拿来监督细粒度唇音同步会引入结构化噪声。若需要词级或音素级对齐，应使用额外标注或经过验证的对齐器，并保留其不确定性。

时间标注不确定时，可以将允许区间而非单一时点纳入任务。评价预测偏移时给容忍范围，并解释它来自标注精度、感知容忍还是应用要求。模型误差小于标签本身不确定性时，许多小数位并不代表更可信能力。对齐精度与语义粒度必须一致，才能避免用粗标签训练、再用精细术语夸大系统所学。

## 3. 按时间区间构造配对而非按索引凑齐

令视频观察区间为$V_i=[s_i,e_i)$，音频窗为$A_j=[u_j,v_j)$。二者重叠长度为$\max(0,\min(e_i,v_j)-\max(s_i,u_j))$。半开区间使相邻窗共享边界但不重复计算时间质量。可以用重叠长度作为匹配权重，再归一化成每个视频窗对音频窗的读取分布；无重叠时应有明确缺失状态，不能强行把最近一帧视为同步真值。

<a id="av-4-detail-11"></a>

### 3.1 硬匹配与软匹配的区别

最近中心匹配成本低，却把一个不确定范围压成单一索引；按重叠加权保留多个候选，适合表示窗口交叉，但不等于自动识别语义事件。若声学窗口中同时存在多个人说话，时间重叠只能说明共现，无法说明对应哪张脸。时间配对与实体配对是两个问题，需要额外空间、说话者或任务条件。不能让一个重叠公式承担没有输入的信息。

权重归一化还可能掩盖覆盖不足。一个视频窗口只有极短一截音频重叠，归一化后该片段权重仍可能为一，但实际观察覆盖很低。因此同时保存归一化权重与总重叠或覆盖比例。若窗口重叠本身很多，总重叠长度相加还会重复计算同一时间；计算覆盖应取区间并集，而非盲目加和。每个数字的分母和单位都要对应其物理含义。

<a id="av-4-detail-12"></a>

### 3.2 实验一：时钟校正、窗口重叠与覆盖

本实验先用已知公共标志拟合仿射时钟，再把音频窗口映射到视频参考轴。用半开区间公式验证重叠矩阵和无覆盖行，并对随机相位做短事件命中模拟。标志没有噪声是有意简化，用来准确检验方向、尺度和单位；真实漂移估计还需要异常点处理与独立标志验证。

```python
import numpy as np
rng = np.random.default_rng(51)
ta = np.array([0., 20., 50., 100.])
tv = 1.001*ta+.2
alpha, beta = np.linalg.lstsq(np.c_[ta, np.ones_like(ta)], tv, rcond=None)[0]
assert np.isclose(alpha, 1.001) and np.isclose(beta, .2)
assert np.allclose((tv-beta)/alpha, ta)
audio = np.array([[0., .05], [.05, .10], [.10, .15]])
video = np.array([[.2, .25], [.25, .30], [.5, .6]])
aligned = alpha*audio+beta
weights = np.maximum(0., np.minimum(video[:,None,1], aligned[None,:,1])-
                          np.maximum(video[:,None,0], aligned[None,:,0]))
total = weights.sum(1)
normalized = np.divide(weights, total[:,None], out=np.zeros_like(weights),
                       where=total[:,None]>0)
assert np.allclose(normalized[:2].sum(1),1)
assert total[2] == 0 and np.all(normalized[2] == 0)
assert weights[0,0] > .049 and weights[0,1] == 0
delta, width = .1, .025
phase = rng.uniform(0., delta, size=200000)
hit = phase+width >= delta
assert abs(hit.mean()-width/delta) < .004
print('clock',alpha,beta,'coverage',total,'short-event hit',hit.mean())
```

零覆盖行在程序中保持零，而非除零产生非有限数。后续模型还需要独立的有效性标记；零向量可能是合法静音特征，不足以表达“没有录到”。实验中的命中率只检查采样相位机制。它没有模拟真实帧曝光、声音传播或识别模型，因此不能把结果解释为短动作检测准确率。

<a id="av-4-detail-13"></a>

## 4. 从互相关估计延迟

若两个标量序列确实记录同一变化过程，延迟可以先用互相关估计。为避免符号争议，本章定义$C(k)=\sum_t v_t a_{t+k}$，只在两个索引都有效处求和。若音频序列相对视频晚$k_0$个采样步，即$a_{t+k_0}=v_t$，则理想匹配在$k=k_0$达到较大值。换一个库函数可能采用相反方向，必须读定义并用已知人工延迟核验。

<a id="av-4-detail-14"></a>

### 4.1 均值、能量和重叠长度的影响

直流背景会让许多延迟都获得高分，可以先去均值；能量不同可使用归一化互相关。一个常见形式是在每个重叠区域分别去均值，再除以两个区域的范数乘积。若某段几乎常数，分母接近零，就不应把结果当精确同步证据。归一化处理改变了比较对象，需要写清是在全局还是每个重叠区间计算均值和方差。

不同延迟对应不同重叠长度，短重叠可能偶然产生很高相关。因此应限制允许延迟与最小重叠，不仅取全范围最大值。真实信号还可能存在多个声源和不同频带，简单标量相关并非总合适。手工信号提供的是方向与可识别性检查，学习到的跨模态表示才可能把视觉运动和声学变化映射到可比空间，但学习方法同样需要这些时间条件。

<a id="av-4-detail-15"></a>

### 4.2 周期信号的不可识别反例

若$v$严格以$P$步重复，延迟$k$与$k+P$可能产生完全相同的相关分数。在循环边界模型中，这种歧义可以精确成立；在有限非循环信号中，边界和重叠会改变分数，但仍可能有多个近似峰。返回一个最大索引只是打破并列的程序规则，不证明真实偏移唯一。应报告候选峰、峰间距和允许范围，必要时使用额外事件标志。

若画面动作有节律而声音来自持续背景音乐，高相关还可能源于共同节拍，不能证明发声对象就是当前可见动作。要检验事件对应，可加入相同场景不同声源、同声源不同时段和近邻时间负例。负例越接近真实条件，越能揭示只学场景或身份的捷径，但也更容易存在语义正确的替代配对，不能机械标成绝对错误。

<a id="av-4-detail-16"></a>

### 4.3 实验二：符号约定与周期歧义

程序直接实现上述相关定义，不依赖库的索引约定。随机信号被非循环延迟四步，搜索小范围并限制重叠。随后构造周期为四的循环信号，显示零延迟与四步延迟不能区分。两个部分刻意使用不同边界模型，避免用循环滚动模拟现实剪辑却不说明环绕。

```python
import numpy as np
rng = np.random.default_rng(52)
v = rng.normal(size=80)
a = np.zeros_like(v)
a[4:] = v[:-4]
def score(v,a,k):
    left=max(0,-k); right=min(len(v),len(a)-k)
    if right-left<40:return -np.inf
    x=v[left:right];y=a[left+k:right+k]
    x=x-x.mean();y=y-y.mean()
    denom=np.linalg.norm(x)*np.linalg.norm(y)
    return float(x@y/denom) if denom>1e-12 else -np.inf
lags=np.arange(-8,9)
scores=np.array([score(v,a,int(k)) for k in lags])
estimate=int(lags[np.argmax(scores)])
assert estimate==4 and scores[lags==4][0]>.999999
periodic=np.tile([1.,0.,-1.,0.],8)
circular=np.array([periodic@np.roll(periodic,-k) for k in range(8)])
assert circular[0]==circular[4] and circular[0]==circular.max()
print('noncircular delay',estimate,'circular indistinguishable peaks',
      np.flatnonzero(circular==circular.max()).tolist())
```

搜索区间在本实验中预先规定。若在验证或测试上反复扩大范围、筛掉难例，最终同步成功率也包含选择偏差。将估计值与金标准偏移比较时，需要明确单位与容忍阈值，并保留无法估计或多峰不确定的样本。只统计有尖锐峰的样本会把困难案例从分母移走，不能代替完整任务成功率。

## 5. 动态时间规整处理局部速度变化

固定偏移和仿射漂移不能描述所有节奏变化。一个人说同一句话可能在不同词间停顿，某段视频也可能有局部变速。动态时间规整将两条序列的位置组成网格，寻找单调路径，用局部匹配代价累积比较。它假设允许的次序对应具有单调性，不适合任意打乱事件顺序后仍宣称保持语义对齐。

<a id="av-4-detail-18"></a>

### 5.1 状态、递推与最优子结构

设长度分别为$n,m$，局部代价$c(i,j)=\|x_i-y_j\|^2$。路径从第一个格点走到最后一个格点，每步只能向右、向下或对角前进，累计代价为路径访问格点代价之和。令$D(i,j)$表示到达该格点的最小累计代价，则

$$
D(i,j)=c(i,j)+\min\{D(i-1,j),D(i,j-1),D(i-1,j-1)\}.
$$

边界设为除起点前的虚拟零格外均不可达，可用无穷大统一处理。证明来自最后一步的三种可能：最优路径若到达前驱时不是该前驱的最优路径，用更便宜前缀替换就会得到更便宜整体路径，矛盾。动态规划可在二次时间内求出该离散允许路径集合的精确最小值，不是原始连续时间同步问题的无条件最优解。

<a id="av-4-detail-19"></a>

### 5.2 路径约束、复杂度与归一化

只求最小值可用两行存储将内存降到线性；恢复完整路径通常需保存前驱或采用额外重算。限制路径在某条带内可以减少计算，但也排除真实偏移较大的匹配。两序列长度不同时，简单围绕$i=j$的窄带可能使终点不可达，应围绕适当比例的参考线或明确边界设计。不可达不是程序应该静默修复的情况，而是当前约束与数据不相容。

累计代价还随路径长度与局部度量变化，直接跨样本比较可能受时长影响。把最优累计代价除以它的路径长度是一个可报告统计，但一般不等于“平均代价最小的路径”，因为先最小化总和再除长度改变了目标顺序。若真正想优化比率，需要单独推导算法。不要因为结果叫距离，就默认它满足所有数学距离公理或可无条件用于任意核方法。

<a id="av-4-detail-20"></a>

### 5.3 低代价不证明事件语义相同

重复模式会允许多条零代价路径，过度伸缩还能将一个事件匹配到很长区间。局部描述只保留强度时，不同动作的相似强度曲线也可得到很小代价。可以增加斜率约束、持续时间惩罚或更有辨别力的表示，但这些都改变了模型与可行集，应在开发条件下选择。时间规整负责的是给定表示与路径约束的优化，不能替代事件定义与来源审核。

在多模态应用中，原始音频波形与图像像素量纲不同，直接计算它们的欧氏差没有合理含义。应先构造可比较的事件特征或学习跨模态表示，再使用路径方法。若特征器在全部测试配对上训练或选择，路径算法再精确也无法消除评价泄漏。算法的正确性、特征的有效性和泛化的证据应分开验证。

<a id="av-4-detail-21"></a>

### 5.4 实验三：最优路径与多解边界

序列中重复一个观测位置可以表示局部停顿。以下代码求标准三步路径、恢复前驱，并核对每个路径格点单调合法。再通过递推记录所有最优路径的数量，展示常量序列虽然总代价为零，却没有唯一时间对应。计数只用于小例子，长度大时路径数会快速增长。

```python
import numpy as np
def dtw(x,y):
    n,m=len(x),len(y)
    d=np.full((n+1,m+1),np.inf);d[0,0]=0.
    ways=np.zeros((n+1,m+1),dtype=object);ways[:]=0;ways[0,0]=1
    prev={}
    for i in range(1,n+1):
        for j in range(1,m+1):
            options=[(i-1,j),(i,j-1),(i-1,j-1)]
            best=min(d[a,b] for a,b in options)
            winners=[(a,b) for a,b in options if d[a,b]==best]
            d[i,j]=(x[i-1]-y[j-1])**2+best
            ways[i,j]=sum(ways[a,b] for a,b in winners)
            prev[i,j]=winners[0]
    path=[];i,j=n,m
    while (i,j)!=(0,0):
        path.append((i-1,j-1));i,j=prev[i,j]
    return float(d[n,m]),path[::-1],int(ways[n,m])
value,path,count=dtw(np.array([0.,1.,2.]),np.array([0.,1.,1.,2.]))
assert value==0 and path[0]==(0,0) and path[-1]==(2,3)
assert all((b[0]-a[0],b[1]-a[1]) in {(1,0),(0,1),(1,1)}
           for a,b in zip(path,path[1:]))
zero,_,ambiguous=dtw(np.zeros(3),np.zeros(3))
assert zero==0 and ambiguous>1
print('DTW cost/path/count',value,path,count,'constant optimal paths',ambiguous)
```

程序没有处理空序列，使用前提是两侧均非空且数值有限；这属于接口条件。浮点近似相等时的最优路径计数也需要容差规则，本例整数值恰可精确表示。一个严谨实现既要声明支持范围，也要用独立边界测试验证，不能因为最简单的一条路径正确就宣称完整音视频对齐已经解决。

<a id="av-4-method-comparison"></a>

### 5.5 方法选择取决于误差模型

| 方法 | 明确使用的结构 | 能直接解决的问题 | 不能由它自动保证的性质 |
| --- | --- | --- | --- |
| 公共标志的仿射校正 | 同一事件配对、稳定尺度与偏移 | 全局时钟单位和起点差 | 非线性漂移、错误标志和语义对应 |
| 小范围互相关 | 可比较特征、较稳定的固定延迟 | 在规定边界和搜索范围中估计滞后 | 周期唯一性、发声实体与复杂变速 |
| 动态时间规整 | 单调路径和局部代价 | 给定可行路径中的最小累计代价 | 语义一致、唯一对应和平均代价最优 |
| 学习的软对齐 | 训练目标和输入表示 | 在训练条件下学习跨位置读取 | 物理时钟、单调性和因果贡献 |

这些方法可以串联，例如先做设备标定，再在局部窗口估计残余延迟，最后让模型处理语义关系。但串联增加了误差传播与选择因素，需要记录每阶段输入输出。一个阶段的理想条件可能被上一阶段破坏，不能把各自单独正确拼成整体无条件正确。没有可信共同事件、没有可比较特征或根本没有同步证据时，应允许返回不可估，而不是强制输出一个看似精确的数字。

## 6. 怎样判断模型是否利用两个模态

联合输入分数高，不代表两个模态都作出了不可替代贡献。视觉可能已经足以预测标签，音频也可能只携带来源身份。反过来，单模态接近随机也不自动证明联合信息一定有用：两侧可能同样不含任务证据。需要同时明确数据生成关系、单模态可用信息、联合决策所需关系和实际训练能力，才能解释联合模型的提升来自何处。

<a id="sec-2-1"></a>

<a id="av-4-detail-23"></a>

### 6.1 冗余、互补和协同的区别

冗余任务中，两个模态都包含同一充分线索，去掉一个仍可答；互补任务中，不同题或不同条件各自依赖不同模态；协同任务中，单独每侧不足，关系本身才提供答案。三者可能混在同一数据集。总体单模态差值是这些组成的加权结果，不能直接等同于模型内部的一种普遍融合机制。先按任务所需信息分层，再比较模型，往往比堆一个更复杂注意力结构更有解释力。

考虑离散例子：两个独立均匀二元变量分别由视觉与音频给出，标签为异或。每个单变量与标签独立，联合却完全确定标签。这严格证明某个任务存在协同信息，不证明某个网络已经学会它。若给其中一侧再加一个与标签相关的文件名，模型就可能绕过关系。构造协同标签之外，还要审核所有实际输入字段，否则理想生成关系与程序看到的数据可能不同。

<a id="av-4-detail-24"></a>

### 6.2 打乱配对的差值不是自动的因果贡献

将音频跨样本打乱可能破坏语义和统计关系，也可能把相同标签的多个合理配对当成错误。成绩下降说明模型对该干预敏感，但敏感可能来自身份、录制条件或错误检测，而不一定来自目标语义。若不下降，可能任务冗余、模型忽略音频、干预没有改变关键信息，或模型通过其他输入恢复了信息。需要保留竞争解释，而不是一张消融表就确定唯一机制。

更有力的对照保持场景、来源与采集质量相近，仅改变目标关系，例如同一动作的不同发声时序；同时标注干预后正确答案是否应变化。若干预改变了真值，却仍沿用旧标签，低分可能恰恰来自正确响应，而非模型失败。反事实样本应有明确任务语义，真实自然反例也应补充，因为人工变换可能带来部署中不存在的伪影。

<a id="av-4-detail-25"></a>

### 6.3 缺失、静音和零特征不是同一个状态

音轨确实静音、文件未录到、解码失败与编码器输出零向量具有不同含义。用全零统一表示会让模型无法辨别这些情况，甚至把缺失模式学成标签捷径。应使用有效性掩码和原因状态，训练时如何模拟缺失、部署时如何回退也要一致。对缺失数据插值，可以提供估计输入，但不能把它当作额外测量证据。

评价至少分别给完整模态、真实缺失、人工遮蔽和质量变化结果。仅报告在随机丢模态训练上的成功，不等于对所有真实故障都鲁棒。真实缺失可能与设备、说话者或任务难度相关，和独立随机丢弃不同。若系统选择拒答，报告覆盖与保留回答风险；若回退到单模态，说明哪些问题仍有足够信息。行为策略应跟证据状态连接，而不是所有输入都给同样自信答案。

<a id="av-4-detail-26"></a>

## 7. 完整人工实验：学习相对时序而非静态总量

前面的实验验证时间算子，本节增加完整训练、开发选择与冻结测试。数据不是声音和视频，而是两条长度十二的人工事件轨迹。视觉有一个峰，音频峰在循环时间轴上相对视觉前移或后移三格，标签指示两种方向。采用循环时间是有意定义的有限任务，避免边界让单模态的位置泄漏方向；它不是现实视频剪辑的默认边界。

<a id="av-4-detail-27"></a>

### 7.1 为什么单模态在总体上没有标签信息

设视觉峰位置$U$在十二个位置均匀取值，标签$Y$均匀取零或一且与$U$独立，音频峰位置为$U+3$或$U-3$模十二。对任意固定标签，音频位置仍在十二个位置均匀，因为加固定偏移只是置换。因此单独视觉和单独音频的位置分布都与标签无关。在两类先验相同且没有其他标签相关噪声时，任何单模态分类规则的总体最优准确率都是二分之一。

联合则可以计算有向相对位移，准确区分类别。这是可证明的协同结构。实验加入与标签无关的幅值和测量噪声，并在每个来源遍历全部位置与两种标签，减小有限样本中的相位偏差。训练、开发和测试使用不相交来源编号和独立随机流，但共享这个人工机制；因此测试检验新的噪声与来源实例，不是未见动作类别或真实跨设备迁移。

<a id="av-4-detail-28"></a>

### 7.2 模型、对照和选择规则

模型先在时间维去均值并作范数归一化，再计算两个预设相对位移处的跨模态相关，最后学习线性分类头。两种位移来自预先给定任务定义，不是根据测试样本挑出的搜索位置。它包含可微时序关系特征，但没有从原始声波或像素学习编码器，不应将它叫作通用音视频基础模型。完整训练的价值在于把信息结构、优化与评价串成可复核闭环。

静态均值特征不能表达峰的相对位置；去掉任一模态后，相关特征为零，模型退化为常量分类。对时间反转，两个位移交换，真值应相应翻转。反转后按旧标签评分可以很低，但这种低分不能叫鲁棒性变差，因为任务语义已经变化。应同时核对反转预测与新标签的一致性，再讨论模型是否响应了目标时序。

<a id="av-4-detail-29"></a>

### 7.3 实验四：训练、选点、梯度与干预

每个来源产生二十四个样本，训练十个来源、开发四个、测试六个。开发交叉熵用于选择参数状态，测试在选择结束后才评分。代码核对每个来源的标签平衡、来源隔离、有限梯度、完整模态预测以及同时反转时的标签变化。遮蔽结果只描述这个人工协同任务，不推广为所有多模态任务都应在缺失时退化到随机。

```python
import copy
import numpy as np
import torch
from torch import nn
torch.set_num_threads(1)
torch.set_default_dtype(torch.float64)
torch.manual_seed(54)
T=12

def make(groups,seed):
    rng=np.random.default_rng(seed)
    xs=[];ys=[];sources=[]
    for source in groups:
        gain_v=rng.uniform(.9,1.3);gain_a=rng.uniform(.9,1.3)
```

### 7.4 实验结论和不应外推的部分

若完整模型在新来源噪声实例上成功，而遮蔽音频后回到常量基线，说明此实现确实使用了该任务定义的跨模态关系。双侧时间反转后按新标签仍正确，是方向响应的额外检查。它们共同支持有限机制，却不证明对自然视频的语义理解。任务仅含两个预设相位差，也没有真实采集延迟、说话者身份、背景声和复杂缺失，需要在更真实条件下逐项扩展。

开发集选择使用了多个训练状态，因而开发分数不能当独立确认；测试来源虽隔离，仍来自同一人为生成器。单次固定种子的高分也不提供训练稳定性的总体估计。进一步研究可改变噪声强度、时间抖动和允许相位，但应预先决定哪些是开发因素、哪些留作确认。不能看到某种新噪声失败后只删去它，再声称对噪声全面鲁棒。

## 8. 多模态时序评价需要明确对象与分母

同步估计、事件定位、检索、问答和生成不是同一个任务。同步估计输出偏移或分布，定位输出时间区间，检索输出候选排序，问答输出命题，生成还可能产生新信号。共同输入是音视频，不意味着可以共享一个未定义的总分。每个任务先写清查询、允许输入、正确对象、候选或时间范围，再确定评价与失败处理。

<a id="av-4-detail-32"></a>

### 8.1 同步误差与可估覆盖

偏移误差应给物理单位，例如毫秒；若用帧误差，还需说明帧率与变帧率情况。成功率定义为绝对误差不超过阈值，阈值来自任务要求或标注精度。仅报告平均绝对误差可能掩盖少数严重错位，因此可以配合分位数、阈值曲线和无法估计比例。模型返回多峰分布时，点估计误差与不确定性校准又是不同对象。

若删除无声、遮挡或弱对应样本，必须明确评价总体已经条件于“有明显可同步证据”。这类子集研究可以合理，却不能将其分数当全部自然视频的覆盖。对无法唯一识别的周期片段，允许多个正确偏移或标注不确定区间，比强迫一个任意标签更符合信息条件。评价错误也可能来自真值定义，而非模型没有学好。

<a id="av-4-detail-33"></a>

### 8.2 时间区间交并比和短事件敏感性

对预测区间与真实区间，可用交集长度除以并集长度衡量重叠。相同绝对边界误差对短事件影响更大，因此总体平均可能被长片段支配。应按持续时间分层，必要时同时报告起止时间误差。多个预测对应多个事件时，还需定义匹配规则、类别条件、重复检测如何计数及未检出事件如何进入分母，不能把每个预测都匹配最方便的真值。

采样输入没有覆盖事件时，定位失败仍属于端到端任务失败，但诊断应标记观察缺失；不能把它从总体分母删掉后声称更好，也不能全归因于定位头。分层结果可以说明在充分可见事件中的识别能力与采样瓶颈。信息覆盖、模型利用与输出定位的三个阶段应同时记录，方便判断增加采样预算还是改模型更合理。

<a id="av-4-detail-34"></a>

### 8.3 跨模态检索中的多个正例与候选难度

一段声音可能对应多个正确视频片段，一段视频也可能对应多个合理文本描述。检索评价先定义方向、候选库和正例集合，再按预设规则计算前若干位命中。只把原始文件中的唯一配对视为正例，可能把同事件替代来源当成假负例。若采用任一正例命中率，它与召回全部正例的比例又不同，名称与公式都需明确。

候选库规模和干扰类型决定难度。随机跨场景负例可能让场景分类就足以成功，同来源临近片段则更强调时间差，但也可能真正语义等价。报告分别说明候选组成与标签审核，不把不同库规模下的分数直接排行。并列分数的排名约定、重复来源和无正例查询的处理也应固定，否则相同分数表可以产生不同的评价结果。

<a id="av-4-detail-35"></a>

### 8.4 问答与生成的时间证据绑定

回答“先发生哪件事”需要两个事件及其顺序，回答“发生几次”需要足够覆盖整个计数范围。一个恰好展示部分事件的截图不能证明总体次数。生成答案时应将关键命题绑定可核查片段，区分看到、听到、由字幕得到和根据先验猜测。语言流畅与证据支持不同，不能只用表达质量评价多模态理解。

引用一个时间段也不自动证明答案正确。片段可能没有目标对象、时间偏移或缺少必要前文。评价至少区分引用区间合法、相关事件是否出现、命题是否受到支持以及答案是否完成任务。生成虚构片段或补全缺失声画时，更要说明输出是模型推测，不能把其细节当作原始测量事实用于反向证明答案。

<a id="av-4-detail-36"></a>

## 9. 更深一层：可识别性、测量误差与目标冲突

时间同步不是把所有模态强行变得完全一致。语义事件可能本来有合理延迟，例如动作先于声音到达，语句与姿态也不一定逐帧对应。需要区分要消除的采集误差和要保留的任务关系。若标签正是“谁先发生”，把每对输入都自动对齐到零偏移反而会删除答案信息。一个对检索有益的时间不变性，对先后判断可能是有害的不变性。

<a id="av-4-detail-37"></a>

### 9.1 校正误差怎样传递到下游位置

真实映射为$\alpha t+\beta$，估计映射为$\widehat\alpha t+\widehat\beta$。若输入时间还带误差$\delta t$，输出误差为

$$
(\widehat\alpha-\alpha)t+(\widehat\beta-\beta)+\widehat\alpha\delta t.
$$

由三角不等式，其绝对值不超过三项绝对值之和。这个简单分解说明尺度估计误差随时间范围放大，起点误差是常量，采样时间误差则被估计尺度放缩。若任务允许最大时间误差，便可反过来给各项分配误差预算，而不是只说校正拟合很好。也能理解为什么应在整个时长范围放置验证标志，而非只在开头检查。

区间端点分别带误差时，事件顺序是否可靠取决于事件间隔。若两个事件估计时刻之差大于两侧误差上界之和，可保证先后关系不变；若差距落在该范围内，当前测量不足以确定顺序。模型输出再自信也不能消除输入不确定性。可以返回区间或未知，将这种不可判定与网络预测错误区分。误差上界需要可信来源，不能拿样本平均残差假充每次必然成立的最大界。

<a id="av-4-detail-38"></a>

### 9.2 时间抖动为什么优先破坏快速变化

设理想连续特征为$x(t)$，随机时间误差为$\varepsilon$，观察为$x(t+\varepsilon)$。若误差独立且已知分布，平均观察相当于对特征做相应平滑。对单一复频率成分$e^{i\omega t}$，平均后乘上$E[e^{i\omega\varepsilon}]$，也就是误差分布的特征函数。若误差为均值零、方差$\sigma^2$的高斯，该因子为$e^{-\sigma^2\omega^2/2}$。

因此高频成分被更强地衰减：相同毫秒级抖动对缓慢背景变化可能影响很小，对快速唇部动作或敲击瞬间却更明显。这个结论描述平均信号与独立高斯时间噪声的理想模型，不等于一次神经网络预测的准确率公式。它能指导分层：按照事件时间尺度评价同步误差，而不是认为同一偏移阈值对所有任务都同样宽松。

若误差与说话者、设备或标签相关，平均不再只是统一平滑，还可能产生系统性偏差。训练中随机抖动可以让模型适应某类误差，却可能同时鼓励忽略细粒度顺序。增强幅度应与目标一致，并记录它会使哪些标签不再确定。把所有时间变化都当“保持语义”的增强，是没有任务条件的过强假设。

<a id="av-4-detail-39"></a>

### 9.3 软对齐的概率解释和边界

可以对每个视觉位置计算候选音频位置的分数，经softmax得到行归一化权重。它给出“这个视觉查询读取哪些音频位置”的一个分布，但不会自动保证每个音频位置只被使用一次，也不会保证随视觉时间单调移动。多个查询可以同时读取同一个音频峰，单个查询也可以分散到不相邻位置。行和为一只是归一化性质，不是时间规整约束。

若任务需要近似一对一匹配，可以研究双侧质量约束；若需要保持顺序，可研究单调路径分布；若存在一对多持续事件，就不能机械要求双射。选择约束来自事件关系，而不来自模型名称。注意力图好看并不证明学到物理时钟，权重也不能直接当因果贡献。应使用可控偏移、重复事件和多声源反例检验对齐结果是否符合声明目标。

<a id="av-4-detail-40"></a>

### 9.4 异或例子与信息量的精确区别

在前述二元协同例子中，$A,V$独立均匀，$Y=A\oplus V$。于是$H(Y)=1$比特，$H(Y\mid A)=H(Y\mid V)=1$，但$H(Y\mid A,V)=0$。单模态互信息均为零，联合互信息为一。这严格表明两个分别看似无用的输入可以通过关系包含完整答案。检查单模态分数低，不应因此提前丢掉它们。

条件互信息又揭示“已知另一侧之后”的价值，例如$I(Y;A\mid V)=1$，而$I(Y;A)=0$。这不是互信息公式矛盾，而是条件对象不同。真实多模态数据很难直接准确估计这些量，有限样本估计器也受表示影响。因此可以用离散人工结构验证概念，用真实任务对照检验具体系统，而不能凭一个神经互信息估计值宣称完成全部模态贡献的因果分解。

## 10. 数据、干预和复现应怎样组织

时序数据最常见的划分错误之一，是把同一长视频的邻近片段随机分散到训练与测试。相同人物、背景、设备噪声和事件持续片段会跨集合共享，模型可能只需识别来源。应按实际推广目标确定分组：新片段、新会话、新人物、新设备和新场景对应不同难度。不存在一个对所有问题都合适的“按视频划分”口号，必须写出允许共享与需要隔离的因素。

<a id="sec-6-1"></a>

<a id="av-4-detail-42"></a>

### 10.1 来源隔离与预处理拟合范围

若同一原始记录经过多种裁剪或变速形成多个文件，应保留共同来源身份再分组，不能让文件路径掩盖谱系。标准化统计、偏移阈值、负例采样规则和模型选择都应遵守训练开发测试角色。对新视频内部运行预先固定的无监督时间戳变换，可能是部署允许的处理；根据测试标签选择哪种校正最好，则是另一种信息条件，两者不要混为一谈。

更进一步，时间校正若使用整段中的未来公共标志，对离线分析可以合理，对在线即时输出则可能不可用。实验记录要标明校正参数来自预先标定、当前片段前缀还是完整片段。把完整片段拟合的映射悄悄用于前缀预测，会使可见性承诺失真，即使算法从未直接读过最终任务标签也一样。信息使用边界既包括监督标签，也包括未来测量。

<a id="av-4-detail-43"></a>

### 10.2 负例应针对竞争解释

随机换一个完全不同场景的音轨，容易让模型学背景区别；同来源但相隔很远的片段能控制部分身份线索；短时间偏移更接近同步任务，却可能仍在同一个持续事件内。三种负例回答不同问题。应记录偏移分布、来源组成、事件持续时间和语义替代正例，不把“不是原始配对”直接等同于语义错误。

如果标签来自人工偏移生成，文件剪辑边缘、补零或音量变化可能成为捷径。正负例应尽量使用一致裁剪规则，并在没有真实错位的边界反例上检查分类器。还可从同一长流选相同长度的有效重叠区域，减少填充伪影，但这会改变可用时间范围，需要一并记录。控制这些因素不是为了让实验看起来复杂，而是为了确保模型解决的是宣称的问题。

<a id="av-4-detail-44"></a>

### 10.3 随机性、成本和可复核记录

同一来源的多个片段并非独立实验。比较模型时可以在相同来源上配对，按来源重采样分析不确定性，再将训练种子的变化另行记录。固定某些提示和采样位置时，结论首先针对这组输入。测试条件若经过反复修正，也已参与开发，需另设确认数据。大量相邻帧不能自动弥补独立人物或来源太少的问题。

成本包括解码、重采样、抽帧、特征编码、对齐、融合与输出，不只是某层注意力。离线特征缓存的构建与在线请求成本也要分别计入。报告延迟应说明等待未来上下文的算法延迟和实际运算时间，吞吐与单请求延迟也不相同。本章只实跑CPU机制与人工训练，没有测真实解码、实时流媒体或GPU服务，因此不给这些场景填写推测性能数值。

## 11. 十六道进阶练习与详细解析

<a id="av-4-detail-46"></a>

### 11.1 一个标志能否识别两个时钟参数

**题目：** 只知道音频十秒对应视频十点二秒，能否唯一确定仿射校正？

**解析：** 不能。方程只约束十倍尺度加偏移等于十点二，无穷多组参数满足。若额外假设尺度严格为一，可以确定偏移，但那是引入假设而非数据证明。至少需要不同时间的两个可靠对应，且时间跨度越窄，含噪情况下尺度越不稳定。可以在独立时间点检查残差趋势，并说明是否允许分段漂移。重复标记同一个事件不能增加设计矩阵秩，因此不能解决可识别性；它只能在误差机制允许时改进该点的位置估计。

<a id="av-4-detail-47"></a>

### 11.2 为什么逆时钟映射不能只改参数符号

**题目：** 正向映射为一点零零一乘音频时间再加零点二，逆映射是否为乘零点九九九再减零点二？

**解析：** 精确逆必须先减零点二，再除以一点零零一。直接将尺度误差改符号只是近似，偏移在展开后的系数也应除以原尺度。长时间范围内，小近似误差会积累。实现可以对多组测试时间执行正向再逆向并检查容差，同时验证两个窗口端点，避免只修中心而忘记持续时间。可逆算子检查证明当前公式往返正确，不证明现实设备确实遵循该仿射模型；模型残差还需另外验证。

<a id="av-4-detail-48"></a>

### 11.3 短事件为什么不能只靠更强网络补救

**题目：** 每零点一秒抽一帧，事件只持续零点零二五秒，均匀随机相位下理想命中率多少？

**解析：** 为四分之一，来自持续时间与采样间隔之比。剩余相位完全没有抽中事件，即使网络无限强，也不能从这些采样点直接看到它。可以利用其他模态或先验猜测，但这改变了证据来源，应分开评价。真实曝光、遮挡和识别错误会改变实际准确率，理想覆盖不是性能保证。若需要方向而非出现性，一帧可能仍不足；应按任务所需最少观测数量重新分析，而不能用命中一次的概率代表完整时序理解。

<a id="av-4-detail-49"></a>

### 11.4 相同中心时刻为什么仍可能泄漏未来

**题目：** 在线系统在一秒钟时使用中心为一秒、宽度零点二秒的声学窗，它是否只利用当前及过去？

**解析：** 对称窗覆盖到一点一秒，包含尚未到达的未来。系统要么等待零点一秒，要么改成左侧因果窗，或通过预测填补但承认它是估计。三种选择的延迟、特征和证据地位不同。离线预计算特征会隐藏这类等待，不能仅用网络前向时间声称即时处理。还需核对编码器感受范围：即使输入窗因果，后续双向时序层也可能读取未来上下文。可见性应沿完整计算图检查。

<a id="av-4-detail-50"></a>

### 11.5 零重叠为什么需要独立掩码

**题目：** 没有任何音频窗与当前视频片段重叠，把融合向量置零是否足以表达缺失？

**解析：** 数值上置零可以避免除零，但语义上不充分。正常静音或编码结果也可能为零，模型无法知道是有效观察还是缺测。应同时给有效性标记和必要原因，再定义回退或拒答策略。归一化重叠权重还需保存总覆盖，否则很小重叠被归一成一会掩盖信息不足。这个例子区分数值稳定与数据语义：没有非有限数只是实现的最低要求，不能由此认定缺失处理正确。

<a id="av-4-detail-51"></a>

### 11.6 延迟正负号怎样用最小反例核对

**题目：** 定义相关为视频位置乘音频后移位置的求和。音频相对视频晚四格，峰应出现在哪个方向？

**解析：** 按本章定义，在正四格读取音频就与视频对应，所以峰在正四。若库函数使用另一个定义，结果可能相反。先用非周期脉冲或随机信号制造明确延迟，手工写出几个对应索引，再与函数返回的滞后数组核验。不能只看峰值大小。还要说明边界是补零截断还是循环环绕，以及不同滞后的重叠区域是否足够，避免一个符号测试被周期歧义或极短重叠干扰。

<a id="av-4-detail-52"></a>

### 11.7 两个同高相关峰意味着什么

**题目：** 零格与四格偏移的相关都达到相同最大值，程序返回较早的零格，能否报告偏移已被唯一识别？

**解析：** 不能。程序只是按索引打破并列，数据可能允许多个同样好的解释。周期重复是精确反例，低信噪比也会产生近似多峰。可缩小有外部依据的允许范围、加入非周期共同事件，或返回多解与不确定性。不能根据知道的测试答案专门选一个峰再称自动估计成功。若评价只接受唯一偏移，必须确保标注与信息条件足以支持它，否则错误会混入任务定义本身。

<a id="av-4-detail-53"></a>

### 11.8 时间规整零代价是否证明唯一同步

**题目：** 两侧都是三个零，动态时间规整总代价为零，为什么仍无法确定哪个时刻对应哪个？

**解析：** 所有局部配对代价均为零，许多单调路径都最优。本章算法数出十三条允许路径，任选一条不增加证据。加入路径约束可以减少歧义，却是先验选择，而非从常量观测恢复了时间信息。要识别具体同步需要有辨别力的事件、额外时间标志或更强观测。零优化目标只说明在当前度量与可行路径下达到最小，不等同于语义正确或物理可识别。

<a id="av-4-detail-54"></a>

### 11.9 总代价最小后除路径长度是否优化平均代价

**题目：** 先找最小累计距离路径，再除以该路径长度，能否声称找到平均距离最小路径？

**解析：** 一般不能。不同路径长度不同，一个总和稍大但很长的路径可能有更低平均值。最小化总和和最小化比值的排序不必一致，需要单独建模。报告归一化统计可以合理，但要称为已选路径的平均代价，而非另一个目标的精确最优。若引入每步惩罚或长度约束，又改变了可行集与目标，应重新推导动态规划状态和递推，不能沿用旧证明只改输出公式。

<a id="av-4-detail-55"></a>

### 11.10 单模态完全无关怎样与联合完全可答共存

**题目：** 视觉和音频分别提供独立均匀的二元变量，标签为异或。为什么每侧单独都只能猜，而两侧合起来完全确定？

**解析：** 固定其中一个变量时，另一个仍均匀，因此标签两种取值各半；联合给出两个变量后可直接计算异或。用熵表示，单侧条件熵仍为一比特，双侧条件熵为零。这证明关系型信息可能只在联合出现，不说明任意网络都能有效学习。若实际输入还包含标签相关文件名或背景，单模态无信息的理论前提就被破坏。对照必须检查程序真正读取的全部输入，而不只检查理想变量。

<a id="av-4-detail-56"></a>

### 11.11 缺失音频回到随机是否总是好现象

**题目：** 本章协同实验遮蔽音频后准确率二分之一，能否据此规定真实任务的好模型也必须如此？

**解析：** 不可以。这里总体上单模态没有标签信息，退化由任务定义决定。真实任务可能冗余，视觉已经能独立支持答案，遮蔽后仍准确完全合理。应先分析哪些样本必须使用音频，再在该子集检查必要信息是否被利用。总体不降分可能来自任务冗余或忽略模态，两者需要额外对照区分。缺失策略也可能合理拒答，评价应同时记录完成率与保留答案风险，而不是只追求某个固定退化幅度。

<a id="sec-8-2"></a>

<a id="av-4-detail-57"></a>

### 11.12 反转时间后分数下降怎样解释

**题目：** 同时反转两条事件轨迹，按旧标签评分从满分降为零，是否说明模型时序鲁棒性差？

**解析：** 对本章任务，反转将相对位移的方向交换，正确标签本应翻转。按旧标签评分为零可能恰好表示模型正确响应了变化。应先给出干预后真值，再评分。对于动作类别等可能保持标签的任务，规则又不同，不能把同一变换笼统叫语义保持增强。人工干预的价值取决于它检验哪条命题；没有标签变换说明的消融差值，往往无法区分正确敏感性与真正失败。

<a id="av-4-detail-58"></a>

### 11.13 相邻片段随机划分为什么危险

**题目：** 把同一场会议切成几秒片段再随机分训练测试，测试很高能否说明对新会议有效？

**解析：** 不能。相邻片段共享人员、设备、背景和连续事件，模型可能识别来源，甚至看到同一事件的延续。新会议推广应按会议来源隔离；若目标还包括新人物或新设备，需要更严格分组。随机片段测试并非没有意义，它回答的是已知来源中的新片段，但应准确命名。评价协议来自目标分布，不能在拿到高分后把原本局部条件的结果改称更广泛泛化。

<a id="av-4-detail-59"></a>

### 11.14 未配对片段为什么不必然是负例

**题目：** 原数据没有把某音轨与某视频配成一对，是否足以证明它们语义不对应？

**解析：** 不足。可能来自同一持续事件的另一视角、等价描述或相同声音类别。同步任务、事件语义任务和检索任务的正例定义也不同，同类别并不一定同步，同步也不一定是唯一语义匹配。训练和评价应明确哪种关系被标注，允许多个合法正例或标记未审核候选。困难负例若存在漏标，会同时误导损失与评价。增加审核和解释负例为何不支持当前任务，比单纯增大负例数量更重要。

<a id="av-4-detail-60"></a>

### 11.15 时间校正能否删掉有用标签信息

**题目：** 标签区分声音先于或后于画面，预处理将每对数据最大相关峰都移到零，可能有什么后果？

**解析：** 预处理可能直接消除标签所需相对延迟，使两类在新表示中难以区分。若目标是去除设备误差，需要独立标定哪些延迟来自设备、哪些属于真实事件关系，不能按目标样本的全部相关性一概校正。可以保存估计偏移作为额外特征，但此时模型又读取了被移除信息，解释应说明。对齐不变性没有普遍正确性，它必须与下游任务要求的可区分因素一致。

<a id="av-4-detail-61"></a>

### 11.16 准确率相同为什么仍不能说明两个系统等价

**题目：** 两个模型总体准确率相同，其中一个漏掉所有短事件，另一个在长事件偶尔出错，能否称能力无差异？

**解析：** 不能。总体是按当前样本比例加权的结果，错误分布不同会影响新的任务组成与应用成本。应按事件时长、证据模态、来源和时间误差分层，并在相同问题上配对比较。若关心关键短事件，预先定义相应指标或约束，而非看到结果后挑有利子集。成本、延迟和覆盖也可能不同；相同总分只支持该评价对象上的相同点估计，不证明内部机制、风险或资源等价。

## 12. 综合研究项目：将同步与理解分开验收

<a id="sec-8-1"></a>

<a id="av-4-detail-63"></a>

### 12.1 建立可以区分竞争解释的实验链

选择一个具体时序问题，例如同一来源下的动作与声响先后判断。先明确时间基准、允许观察窗口和在线或离线条件，再保存各模态原始时间戳与变换记录。用人工已知偏移验证符号、窗口与边界；再使用人工时间尺度变化验证漂移校正。只有这些测量不变量成立后，才进入更复杂表示学习。若原始配对本身错位，增加模型容量不能使评价标签自动正确。

构造至少三类任务子集：视觉足够、音频足够、必须利用两侧关系。保留自然有效输入，同时构造有明确新标签的偏移、反转和配对替换。设计能区分“任务冗余”和“模型忽略模态”的对照，不把总体不降分当唯一证据。缺失、静音和解码失败分开记录，时间支持不足时允许明确定义的未知。对无法确定唯一对齐的周期片段，保留多解，不用任意标注强迫系统猜。

按目标隔离来源，冻结开发选择后在最终确认集评价。报告输入覆盖、同步误差、条件任务正确率、缺失行为与成本，附独立来源数量和失败实例。若使用学习到的对齐器，单独验证其偏移与路径，不只看最终答案。若最终答案很好却对齐失败，可能存在旁路；若对齐很好但答案差，读取或任务建模可能是下一个瓶颈。这些是待检验解释，需通过进一步干预区分。

<a id="av-4-detail-64"></a>

### 12.2 本章四段实验实际证明了什么

第一段拟合时钟并核对来源窗口，短事件随机相位命中率实际为零点二四八七九，接近理论四分之一。第二段恢复预设四步非循环延迟，同时保留周期零与四步的并列峰。第三段在局部停顿例子中找到零代价合法路径，并在常量例子中数出十三条最优路径。三者检查不同性质，不能用其中一项替代全部时间同步验收。

第四段完整训练的交叉熵从约零点九七三二降到开发选择状态下的训练零点零一零一，开发选择第一百六十个训练后状态，测试准确率为一；去音频后为零点五，双侧反转并更新标签后仍为一。代码内轮次从零计，打印所选索引为一百五十九。结果只说明预设循环事件关系可被这个可微相关分类头学会，未执行原始音视频编解码、真实唇音同步或开放域多模态生成。

验收应保留这些边界和未解决的问题：真实时钟可能分段漂移，事件可能多声源，标签可能粗糙，在线预算可能禁止读取未来。把已证性质与待测性质写清楚，读者才能据此设计下一步研究。进阶学习不是积累更多方法名字，而是知道每一步观察、变换、模型和评价支持了什么结论，以及改变哪条条件就需要重新验证。
