# 图机器学习

在关系结构上学习表示，理解消息传递、图任务和图数据特有的泄漏。

**先修知识：** 图结构、线性代数、神经网络。

## 学习顺序与覆盖范围

先补[图遍历](../../ComputerScience/DataStructuresAndAlgorithms/02-二分排序与图遍历.md)。第 1 章定义消息传递，第 2 章建立图可见性与评价边界，第 3 章手算并比较具体聚合器，第 4 章扩展任务。第 2 章从固定线性传播推到谱、采样与评价；第 3 章比较可学习聚合器的表达力。也可在第 1 章后先读第 3 章手算，再回到第 2 章分析深度与采样。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：怎样验收完整图任务](04-图级任务异质图与评估实践.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
