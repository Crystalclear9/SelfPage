## 1. 先定义要评价的对象，再选择指标

<a id="cv2-detail-2"></a>

### 1.1 分类、检测、语义分割和实例分割

图像分类给整幅图像分配类别或类别集合，目标检测还要给出每个对象的位置与类别，语义分割为每个有效像素赋类别，实例分割进一步区分同类的不同对象。它们共享图像输入，但预测单位不同。一张图里两个人相互接触，语义标签可以都写成人，实例标签却必须说明每个像素属于哪一个人。输出张量的高宽相同，不代表解决的是同一任务。

检测标注一般是一组对象，每个对象有类别、框、可选实例掩码与忽略标记。语义标注通常是一张离散类别图，可另有无效像素掩码。实例掩码可以重叠吗、遮挡部分是否标注、边界是否包含不确定带，都属于标注协议。若训练使用可见区域掩码，测试却按完整物体轮廓评价，失败可能来自目标定义不一致，而不是分割网络不够强。

全景分割还要求对画面中的可数对象与不可数区域统一分配语义和实例身份。道路、天空等区域与人、车等实例具有不同组织方式。不能把语义图里的连通域直接等同真实实例，因为同类对象可能接触，一个对象也可能因遮挡而分成多个可见区域。连通域是几何属性，实例身份是标注语义。

<a id="cv2-detail-3"></a>

### 1.2 预测集合为什么需要匹配

真实对象没有与模型输出天然对应的编号。模型可能输出五个框，真实只有三个对象，必须规定哪个预测能领取哪个真实对象的正确贡献。通常既要求类别一致，也要求重叠足够，并限制普通真实对象被重复领取。没有匹配规则，两个几乎相同的框可能被错误当作识别了两个对象。

训练中的匹配与评价中的匹配也可能不同。训练可以依据代价矩阵进行全局分配，评价可能按置信度顺序逐个分配。训练时降低某个代价不必然使评价指标单调改善，因为评价还包含阈值、排序和离散匹配。学习算法优化的是代理目标，最终指标检验的是规定任务，二者应建立联系而不是混为同一函数。

<a id="cv2-detail-4"></a>

### 1.3 一个完整评价协议的最小清单

协议至少要说明类别集合、坐标约定、有效图片、忽略规则、匹配门槛、预测过滤、最大候选数、排序与并列分数处理、聚合方式和空类别处理。对于分割，还要说明是否包含背景、忽略像素、边界容忍度与逐图还是全局汇总。两个程序都输出平均精度，并不足以证明它们计算的是同一个量。

评价程序本身应有微型单元算例：完全正确、完全空预测、完全空真值、重复框、错误类别、恰在阈值边界、无效坐标、并列分数与忽略区域。先确保这些情况与文字约定一致，再对大数据集运行。数千张图片得到的小数很精细，并不抵消评价实现中一处坐标错误。

## 2. 区域重叠与坐标的手算基础

<a id="cv2-detail-6"></a>

### 2.1 半开边界框、面积与退化输入

本章采用连续边界或半开矩形 $`[x_1,x_2)\times[y_1,y_2)`$，要求右边界不小于左边界，下边界不小于上边界。面积是宽度乘高度，不额外加一。对于离散像素闭区间标注，某些历史实现会使用端点加一的面积方式，那是另一种契约。比较前必须统一坐标含义，不能只看到四个数字就直接代入。

两个框的交集宽度为 $`\max(0,\min(x_2^A,x_2^B)-\max(x_1^A,x_1^B))`$，高度同理。重叠度定义为交集面积除以并集面积。非有限坐标、反向框与非正面积框应按协议拒绝或处理；随意把负宽度裁成零会掩盖上游错误。零面积框与零面积框的并集为零，数学比值没有定义，不应通过任意小常数偷偷变成一个具有语义的成绩。

<a id="sec-1-1"></a>

<a id="cv2-detail-7"></a>

### 2.2 完整手算：交集五十不代表重叠一半

真实框为左上零零、右下十十，面积一百；预测框向右平移五，边界为五零到十五十，面积也一百。交集宽五、高十，面积五十；并集为一百加一百减五十，即一百五十，因此重叠度为三分之一。把交集除以真实面积会得到二分之一，但那是覆盖率的另一种定义，不能代替交并比。

如果预测只覆盖真实框内部的五乘十区域，交集五十，预测面积五十，并集一百，交并比才是二分之一。两个例子交集相同，差别来自预测是否额外覆盖背景。因此该指标同时惩罚遗漏与过度包围。把框无限放大虽然能覆盖真实目标，却会增加并集，不能得到高分。

<a id="sec-4"></a>

<a id="cv2-detail-8"></a>

### 2.3 同样的一像素误差对小目标更严重

对于边长 $`s`$ 的正方形，只沿水平方向平移距离 $`d<s`$，重叠度是 $`\frac{(s-d)}{(s+d)}`$。要求达到阈值 $`\tau`$，可得 $`d\le\frac{s(1-\tau)}{(1+\tau)}`$。这个表达式直接显示允许的绝对误差与目标尺寸成比例。阈值为二分之一时允许平移不超过边长三分之一；阈值为四分之三时只允许不超过边长七分之一。

边长四像素的目标平移一像素，重叠度是五分之三；边长四十像素的目标平移一像素，则是三十九除四十一。相同像素偏差在小对象上明显更严苛。因此小目标评价还受到标注量化与缩放策略影响，不能只解释为模型看不懂小物体。应同时检查坐标解码精度、下采样步幅、标注一致性和真实成像分辨率。

<a id="cv2-detail-9"></a>

### 2.4 掩码重叠、Dice 与空集

对有效像素集合中的二元区域，设交集为 $`I`$、预测面积为 $`P`$、真实面积为 $`G`$，则交并比是 $`\frac{I}{(P+G-I)}`$，Dice 是 $`\frac{2I}{(P+G)}`$。当分母非零时，两者满足 $`D=\frac{2J}{(1+J)}`$。这是同一对区域之间的单调关系，不意味着逐类平均后仍可把一个平均值代入公式得到另一个平均值。

当预测和真值都为空，两种比值都是零除零。可以规定空空得一、排除该样本或报告未定义，但必须写明。若逐图评价中大量图片没有前景，空空得一会使“永远预测背景”的模型获得很高平均分。若全局合并像素后评价，空图片不贡献前景分母，则回答另一个问题。空集处理绝不是只影响极少数边界的代码细节。

## 3. 从匹配到精确率召回率

<a id="sec-2-1"></a>

<a id="cv2-detail-11"></a>

### 3.1 本章教学匹配规则的完整定义

为了能逐步手算，本章先定义一个有限的教学协议：每次只评价一个类别、一个重叠阈值；普通非忽略真实对象一对一匹配；预测按分数降序，分数相同按输入顺序；每个预测只在同图未匹配真实对象中找最大重叠，达到阈值便记真阳性，否则记假阳性；没有候选上限、面积切片和拥挤区域。这个协议足以解释排序与重复，但不是完整公共基准实现。

匹配仅在同图同类内发生，完成后再把各图片的预测按分数合并，累计真阳性与假阳性。类别错误的预测对所报类别是额外假阳性，而真实类别的对应对象仍是漏检。评估时若先忽略类别去匹配，就变成另一种定位诊断，不能把该结果叫分类感知检测精度。

<a id="cv2-detail-12"></a>

### 3.2 两个目标、四个预测的逐项计算

设两幅图各有一个同类真实对象，预测分数依次为零点九五、零点九、零点八、零点七。第一项是图甲的正确框，第二项是图甲重复框，第三项是图乙正确框，第四项是图乙背景框。匹配序列为真、假、真、假。累计真阳性为一、一、二、二，累计假阳性为零、一、一、二，因此精确率依次为一、二分之一、三分之二、二分之一，召回率为二分之一、二分之一、一、一。

如果把两个正确框排在前面，序列变为真、真、假、假，召回提升之前没有额外假阳性，平均精度达到一。注意这两个模型在保留所有四个预测时具有相同的最终精确率与召回率，但排序质量不同。平均精度评价整个排序过程，单一阈值下的一个混淆统计无法表达这种差别。

<a id="cv2-detail-13"></a>

### 3.3 精确率包络与面积定义

对达到召回水平 $`r`$ 的预测前缀，取后续可达精确率最大值，定义非增包络 $`\tilde p(r)`$。教学中的全召回插值面积写成 $`AP=\sum_k(r_k-r_{k-1})\tilde p(r_k)`$，仅在召回提升的位置累加。上例第一次提升覆盖零到二分之一，精确率一；第二次提升覆盖二分之一到一，精确率三分之二，所以面积为六分之五。

如果改用一百零一个固定召回点的平均，零到二分之一共五十一个点取一，后面五十个点取三分之二，结果为二百五十三除三百零三，约零点八三五。两者很接近但不完全相同。另一些分类库使用不插值的召回增量加权精确率，也有历史十一点插值协议。报告中应说明采用哪种定义，不能只写“调用了平均精度”。

<a id="cv2-detail-14"></a>

### 3.4 为什么低阈值过滤会改变面积

部署为了减少误报可以设置分数阈值，但评价完整排序通常需要保留足够低分候选。如果先删除低分正确框，可达召回上限降低，遗漏部分召回区间贡献为零。反之，把所有低分背景框保留在已达完全召回之后，在某些插值面积定义下并不降低之前的面积。这不说明背景误报无关紧要，而是该指标与指定工作点的业务代价不同。

候选数上限也会限制召回。一张图有一百二十个真实对象，若只允许保留一百个预测，即使定位与分类全部正确，可达召回仍不可能超过六分之五。不同候选上限的结果不应混比。对于密集场景，除总体指标，还要报告每图目标数量与资源限制，检查系统是否在结构上已经丢失部分对象。

<a id="deep-dive-2"></a>

<a id="cv2-detail-15"></a>

### 3.5 分母是对象，不是预测文件数

召回率分母是有效真实对象数量，精确率分母是纳入评价的预测数量。若某张图没有真实对象，模型输出框会增加假阳性；若某张图有对象但没有预测，它增加召回分母而不增加排序列表。若整个类别没有有效真值，该类别的检测召回和平均精度通常应标记不可评价，再按规定处理宏平均，而不是把所有预测当成一个正常类别的零分结果。

忽略对象既不一定进入正常召回分母，也不一定使所有覆盖它的预测成为假阳性。拥挤区域、未穷尽标注与不可判定区域需要专门规则。简单地从真值列表删去忽略对象，却把其上的预测全计为误报，可能把合法识别惩罚成错误。正确实现应遵从具体数据集政策，并用专门算例验证。

## 4. 公共基准口径与教学实现的边界

<a id="sec-6-1"></a>

<a id="cv2-detail-17"></a>

### 4.1 多阈值、面积与最大候选数是协议参数

以常见公共检测评估器为例，评价张量包含重叠阈值、召回采样点、类别、面积范围与候选上限等维度，汇总数字只是其中若干维度的平均或切片。跨重叠阈值平均和固定低阈值结果衡量不同定位要求；小、中、大对象还依赖面积定义。应直接保存评估器版本与参数，不能凭指标名称猜测所有默认值。

本文后面的代码只实现前述单类普通对象教学协议，不处理公共评估器的全部机制，也不把结果标为完整基准成绩。真实论文比较应使用对应官方实现或经过逐例一致性验证的替代实现。即使增加同样数量的重叠阈值，也不自动补齐面积、候选、忽略与拥挤规则。

<a id="cv2-detail-18"></a>

### 4.2 拥挤区域和忽略区域为何不能简单删去

在一些基准中，拥挤区域表示多个难以逐一标注的同类对象，评价时可能允许多个预测与该区域关联，并使用与普通区域不同的覆盖分母。普通对象一对一限制不能照搬到这些区域。相关预测是否忽略、如何与普通对象优先匹配，也有具体规则。实现细节应对照所用评估器，而非从本文的普通对象教学代码外推。

面积范围还可能让某些真实对象在当前切片中被忽略，并对未匹配预测按其面积决定是否纳入。只按真实对象面积筛选，然后对所有预测照常计错，未必复现官方口径。分割评价时框面积与掩码面积也不是同一个量，应核对结果输入格式与工具如何读取面积字段。

<a id="cv2-detail-19"></a>

### 4.3 稳定排序与并列分数

相同分数时，不同预测顺序可能改变哪个框先匹配，以及假阳性出现在召回提升前还是后。严格复现应规定稳定排序和原始输入顺序，尽量保留原始置信度精度，避免过早四舍五入造成大量并列。不能在评价阶段用真值打破并列，因为那会为排序注入答案。

在一些特定例子中，交换并列的真假预测不会改变最终检测集合，却改变平均精度。合理报告可以给出原始确定性顺序，并在需要时分析并列敏感性。把分数统一设为一再比较排序型指标，实际上将大量评估权交给文件顺序；这与模型有可靠置信排序是不同能力。

<a id="cv2-detail-20"></a>

### 4.4 工作点指标与平均精度相互补充

生产系统常关心每图误报数、某召回下的精确率、单位时间人工复核量和特定类型漏检。这些指标通常依赖一个预先选定的阈值，而平均精度概括一串阈值。高平均精度不保证特定阈值下成本最小，反之单一工作点好也不证明整个排序优良。应在验证集选工作点，再在测试集固定执行。

不同来源的置信度可比性也重要。若模型在某相机上整体给高分、另一相机上给低分，全局排序可能优先服务前者，即使各相机内部排序都不错。按来源诊断可以揭示这种差异，但主评价是否采用全局阈值、来源专用阈值或统一资源分配，必须由真实应用决定并事先说明。

<a id="cv2-detail-21"></a>

## 5. 语义分割：聚合顺序决定问题

<a id="cv2-detail-22"></a>

### 5.1 从混淆矩阵推导各类重叠

设混淆矩阵的行是真实类，列是预测类，$`C_{ij}`$ 表示真实为 $`i`$ 而预测为 $`j`$ 的有效像素数。类别 $`k`$ 的真阳性为对角元素，假阴性为该行其余元素之和，假阳性为该列其余元素之和。因此类别交并比为 $`\frac{C_{kk}}{(\sum_jC_{kj}+\sum_iC_{ik}-C_{kk})}`$。这个定义将漏掉该类与错报该类都计入并集，且可从可加的整数统计量累积。

像素准确率为对角和除以所有有效像素数。若背景占百分之九十九，永远预测背景就有百分之九十九准确率，却完全没有检出前景。按类平均的交并比让每个有效类别获得相同权重，频率加权交并比则再次偏向常见类。三者回答的权重问题不同，不能把指标名称中的“平均”当成相同分母。

<a id="cv2-detail-23"></a>

### 5.2 一个四格混淆矩阵的完整手算

设背景真实像素九十，其中八十五预测背景、五预测前景；前景真实像素十，其中四预测前景、六预测背景。前景真阳性四，假阳性五，假阴性六，因此前景交并比是四除十五，Dice 是八除十九。背景交并比是八十五除九十六，像素准确率为八十九除一百，包含背景的平均交并比约零点五七六。

如果永远预测背景，像素准确率升到零点九，但前景交并比降为零，背景交并比为零点九，包含背景的均值为零点四五。一个指标上升而另一个下降没有逻辑矛盾，而是权重不同。任务若关注细小病灶，应明确前景、病灶实例与病人层面的代价，不可用整体像素准确率替代全部评价。

<a id="cv2-detail-24"></a>

### 5.3 先合并像素还是先平均图片

图片甲真实前景十像素且全部正确，图片乙真实前景一千像素且全部漏掉，没有假阳性。逐图前景交并比平均为二分之一；合并像素后则只有十除一千零十，约百分之一。前者让两张图等权，后者让前景面积大的图贡献更多分母。若图片代表独立病人，逐病人平均可能更贴近任务；若目标是随机有效像素，合并统计更自然。

实际数据还存在分辨率差异与每人多张切片。逐图平均不等于逐人平均，统一缩放后评价也改变了小结构权重。应先确定最终应用的决策单位，再规定聚合层级。可以同时报告多个层级，但必须给出各自分母与空集政策，避免读者误以为差异来自模型而实际来自算分方法。

<a id="cv2-detail-25"></a>

### 5.4 忽略像素必须在统计之前排除

忽略标签表示这个位置不参与监督或评价，不应简单改成背景。建立有效掩码后，只用有效像素累积混淆矩阵；预测在忽略区是什么类别，都不应改变此项像素评价。如果目标边界附近设置了不确定带，需要记录带宽与产生方式，因为它会降低边界定位要求。训练忽略政策与测试忽略政策可以不同，但必须解释来源。

对多类标签图，要先检查有效真值与预测值都落在合法类别范围，不能让越界编号在数组索引中被意外折回或被静默舍弃。输出概率需要先按规定转成类别，插值时是先插值 logits 再取最大，还是先取类别再最近邻，可能产生不同边界，应固定流程。评价代码面对无效输入时应明确报错，而不是生成一个看似正常的分数。

<a id="cv2-detail-26"></a>

### 5.5 空类、宏平均与类别集合

若某类在全测试集中没有真值也没有预测，其并集为零。把它记一会奖励未被测试的类别，把它记零会惩罚没有机会出现的类别，排除它则使平均的类别集合依数据而变。没有一个选择能脱离任务自动成为唯一正确答案，因此应固定政策并报告实际被评价的类。若该类没有真值但模型确实预测了它，并集非零，交并比应为零，不能因为真值缺失就忽略所有假阳性。

验证不同模型时，宏平均的类别集合应保持可比。如果一个实现按“模型预测过的类别”决定是否纳入，就可能让完全不预测困难类别的模型逃避惩罚。更稳妥的是以既定标签空间和真值可评价性定义规则，再对非空预测执行一致处理。对稀有类还应给出真实对象数与像素数，区分类别没出现和出现但完全漏掉。

<a id="cv2-detail-27"></a>

## 6. 实例、边界与全景质量

<a id="cv2-detail-28"></a>

### 6.1 语义正确不代表实例正确

两个人的所有像素都被预测为人，语义分割可以完全正确；若模型把两个人合成一个实例，实例分割仍错误。反过来，把一个人切成两个实例，即使二者并起来像素区域正确，也增加了实例层面的拆分错误。实例评价必须对预测区域与真实区域进行类别感知匹配，不能只把所有同类掩码合并后计算一次交并比。

拥挤、遮挡与相互接触会使实例划分尤其困难。评价时应检查同类合并、过度拆分、漏实例与边界偏差，不要把全部失败压成一个区域均值。若任务只关心总体覆盖面积，语义合并可能足够；若任务需要数细胞、数果实或追踪个体，实例身份就是核心目标。模型选择应由下游问题决定。

<a id="cv2-detail-29"></a>

### 6.2 全景质量的分解与使用条件

在给定匹配集合的条件下，可定义区域质量为匹配对的交并比之和，除以 $`TP+\frac12FP+\frac12FN`$。它可以分解成匹配对平均重叠乘以识别质量，即 $`SQ\times RQ`$。前者衡量已匹配对象分割得多好，后者惩罚漏检与额外实例。若没有任何匹配，平均重叠项需要专门约定，不能直接计算零除零。

完整全景评价还要处理类别、可数与不可数区域、无效区域与拥挤等细节，本文的简单数字分解不替代完整实现。这个分解的教学意义在于展示：区域边界更准与对象数量更准是不同改进方向。如果匹配都很准但漏掉很多对象，只提高边界精度不会自动修复识别质量。

<a id="cv2-detail-30"></a>

### 6.3 边界指标为什么需要物理尺度

两个区域交并比相同，边界误差分布可以很不同：一个可能整体略膨胀，另一个可能漏掉细长分支。边界距离、容忍带内精确率召回率或特定轮廓误差可以补充区域指标，但它们依赖像素间距、边界提取方法和空边界规则。医学或遥感图像中，横纵像素的物理尺寸还可能不同，直接用像素欧氏距离会误导。

边界容忍度越大，匹配越容易。比较两个结果时必须统一容忍度单位，不能在高分辨率图上用十像素、低分辨率图上也用十像素，然后宣称物理精度相同。若边界标注本身有明显不确定性，评价应反映这种限制，并使用多标注者一致性作为背景信息，而不是要求模型达到超出观测可靠性的精度。

## 7. 三段可独立验证的 CPU 程序

<a id="cv2-detail-32"></a>

### 7.1 实验一：坐标、尺寸敏感性与二元区域恒等式

本段拒绝非有限或退化框，采用半开边界面积。断言验证平移公式、交并比的对称性以及 Dice 与交并比之间的关系。空空区域使用显式返回未定义值，读者可以按照自己的协议在聚合层决定如何处理，不能把数值稳定用的小常数悄悄当成语义规则。

```python
import numpy as np

def area(box):
    b = np.asarray(box, dtype=float)
    if b.shape != (4,) or not np.isfinite(b).all():
        raise ValueError('finite four-coordinate box required')
    if b[2] <= b[0] or b[3] <= b[1]:
        raise ValueError('positive-area half-open box required')
    with np.errstate(over='ignore', under='ignore', invalid='ignore'):
        result = (b[2]-b[0])*(b[3]-b[1])
    if not np.isfinite(result) or result <= 0:
        raise ValueError('box area is not representable as a positive finite float')
    return result

def iou(a, b):
    aa, bb = area(a), area(b)
    w = max(0.0, min(a[2],b[2])-max(a[0],b[0]))
    h = max(0.0, min(a[3],b[3])-max(a[1],b[1]))
    with np.errstate(over='ignore', invalid='ignore'):
        intersection = w*h
        union = aa+bb-intersection
    if not np.isfinite(union) or union <= 0:
        raise ValueError('box union is not a positive finite float')
    return intersection/union

assert np.isclose(iou([0,0,10,10],[5,0,15,10]), 1/3)
assert np.isclose(iou([0,0,10,10],[0,0,5,10]), 1/2)
for size in (4, 40):
    actual = iou([0,0,size,size],[1,0,size+1,size])
    assert np.isclose(actual, (size-1)/(size+1))
    assert np.isclose(actual, iou([1,0,size+1,size],[0,0,size,size]))
try:
    area([0,0,0,1])
except ValueError:
    pass
else:
    raise AssertionError('degenerate box accepted')

pred = np.array([1,1,0,1,0], dtype=bool)
true = np.array([1,0,1,1,0], dtype=bool)
intersection = np.logical_and(pred,true).sum()
union = np.logical_or(pred,true).sum()
jaccard = intersection/union
dice = 2*intersection/(pred.sum()+true.sum())
assert np.isclose(jaccard, 0.5)
assert np.isclose(dice, 2*jaccard/(1+jaccard))
print('box and mask identities passed')
```

有限坐标仍可能使宽度、面积或并集的浮点中间量溢出，极小的正面积也可能下溢为零。两段框实现会明确拒绝这些不可表示的算例，避免相同框因 NaN 被误记为零重叠；它们并未承诺覆盖任意数量级。需要处理超大坐标时，可先按共同尺度变换全部坐标并验证精度，再计算尺度不变的交并比。

这里的拒绝策略用于让输入错误尽早显现。真实评估器可能有不同的合法性约定，迁移代码时应核查具体接口。尤其不能把某个数据源的左上宽高框直接当成左上右下框；即使四个数都为正，面积含义仍可能完全错误。实践中应在少量带可视化的样本上逐个核对原始标注与解码结果。

### 7.2 实验二：普通对象教学 AP 的完整实现

程序定义单类别、多图像、单重叠阈值、无忽略区域的协议。每条预测包含图像编号、分数与框，真值按图像存储，缺失图像视为没有真值。代码显式检查阈值与输入值，并用稳定排序处理同分。它同时计算全召回插值面积和一百零一点插值平均，二者名称明确分开，不宣称复现完整公共评估器。

```python
import numpy as np

def box_iou(a,b):
    a, b = np.asarray(a,float), np.asarray(b,float)
    for z in (a,b):
        if z.shape != (4,) or not np.isfinite(z).all():
            raise ValueError('invalid coordinates')
        if np.any(z[2:] <= z[:2]):
            raise ValueError('nonpositive box')
    with np.errstate(over='ignore', under='ignore', invalid='ignore'):
        areas = np.array([(a[2:]-a[:2]).prod(), (b[2:]-b[:2]).prod()])
        wh = np.maximum(0, np.minimum(a[2:],b[2:])-np.maximum(a[:2],b[:2]))
        inter = wh.prod()
        union = areas.sum()-inter
    if not np.isfinite(areas).all() or np.any(areas <= 0):
        raise ValueError('area outside positive finite floating-point range')
    if not np.isfinite(union) or union <= 0:
        raise ValueError('union outside positive finite floating-point range')
    return inter/union

def teaching_ap(ground_truth, predictions, threshold=0.5):
    if not 0 < threshold <= 1:
        raise ValueError('threshold outside (0,1]')
    for boxes in ground_truth.values():
        for box in boxes:
            box_iou(box,box)
    for image,score,box in predictions:
        if not np.isfinite(score):
            raise ValueError('nonfinite score')
        box_iou(box,box)
    total = sum(len(v) for v in ground_truth.values())
    if total == 0:
        return None
    matched = {im: np.zeros(len(v),dtype=bool)
               for im,v in ground_truth.items()}
    ordered = sorted(enumerate(predictions), key=lambda t: (-t[1][1],t[0]))
    flags = []
    for _,(im,score,box) in ordered:
        candidates = ground_truth.get(im,[])
        best, best_iou = None, -1.0
        for index,truth in enumerate(candidates):
            if matched[im][index]:
                continue
            overlap = box_iou(box,truth)
            if overlap > best_iou:
                best, best_iou = index, overlap
        hit = best is not None and best_iou >= threshold
        if hit:
            matched[im][best] = True
        flags.append(int(hit))
    tp = np.cumsum(flags, dtype=float)
    precision = tp/np.arange(1,len(flags)+1)
    recall = tp/total
    envelope = np.maximum.accumulate(precision[::-1])[::-1]
    delta = np.diff(np.r_[0.0,recall])
    area = float(np.sum(delta*envelope))
    sample_values = [float(envelope[np.searchsorted(recall,r)])
                     if np.searchsorted(recall,r)<len(recall) else 0.0
                     for r in np.linspace(0,1,101)]
    return area, float(np.mean(sample_values)), flags, precision, recall

box = [0,0,10,10]
truth = {'a':[box], 'b':[box]}
preds = [('a',.95,box),('a',.9,box),('b',.8,box),
         ('b',.7,[20,20,30,30])]
area, ap101, flags, precision, recall = teaching_ap(truth,preds)
assert flags == [1,0,1,0]
assert np.allclose(precision,[1,.5,2/3,.5])
assert np.allclose(recall,[.5,.5,1,1])
assert np.isclose(area,5/6) and np.isclose(ap101,253/303)
perfect_order = [('a',.95,box),('b',.9,box),('a',.8,box)]
assert teaching_ap(truth,perfect_order)[0] == 1
assert teaching_ap(truth,[])[0] == 0
assert teaching_ap({},preds) is None
# 有限坐标也可能让宽度、面积、并集溢出或让面积下溢。
for extreme in ([0, 0, 1e200, 1e200], [0, 0, 1e-200, 1e-200],
                [-1e308, 0, 1e308, 1]):
    try:
        teaching_ap({'a': [extreme]}, [('a', .9, extreme)])
    except ValueError:
        pass
    else:
        raise AssertionError('unrepresentable geometry accepted')
try:
    box_iou([0, 0, 1e154, 1e154], [0, 0, 1e154, 1e154])
except ValueError:
    pass
else:
    raise AssertionError('overflowing union intermediate accepted')
shifted = [('a',.9,[2,0,12,10])]
assert teaching_ap({'a':[box]},shifted,.5)[0] == 1
assert teaching_ap({'a':[box]},shifted,.75)[0] == 0
print('teaching AP',area,ap101,'flags',flags)
```

最后的移位框交并比为三分之二，因此通过二分之一门槛、不能通过四分之三门槛。这是相同分类与相同置信度因定位要求改变而产生不同成绩的最小例子。程序没有实现类别循环、拥挤和面积切片；扩展时应先写每个新增规则的算例，不应只在函数名中加上某个基准缩写。

该实现对重复框的定义也是明确的：如果另一个未匹配对象仍满足条件，预测可以匹配那个对象；如果只重叠已领取对象而没有其他合格对象，则计为假阳性。真实密集场景中的匹配可能受框顺序和标注模糊影响，不能用单个框的最大重叠独立判断所有预测，因为那会允许多个预测重复领取同一真值。

<a id="cv2-detail-34"></a>

### 7.3 实验三：有效像素混淆统计与平均次序

本段检查二类混淆矩阵、忽略像素不影响结果、预测越界报错，以及逐图平均与合并面积的差别。空类用缺失值表示，不通过任意平滑常数伪造成绩。这个实现只提供全局语义统计，没有包含实例匹配、边界距离或数据集特定标签映射，范围与前两个实验一样有限而清楚。

```python
import numpy as np

def confusion(true,pred,classes=2,ignore=255):
    true, pred = np.asarray(true),np.asarray(pred)
    if true.shape != pred.shape:
        raise ValueError('shape mismatch')
    if not np.issubdtype(true.dtype,np.integer) or not np.issubdtype(pred.dtype,np.integer):
        raise ValueError('integer labels required')
    valid = true != ignore
    t,p = true[valid],pred[valid]
    if np.any((t<0)|(t>=classes)) or np.any((p<0)|(p>=classes)):
        raise ValueError('class outside range')
    return np.bincount(classes*t+p,minlength=classes**2).reshape(classes,classes)

def class_iou(matrix):
    intersection = np.diag(matrix).astype(float)
    union = matrix.sum(0)+matrix.sum(1)-intersection
    result = np.full(len(intersection),np.nan)
    np.divide(intersection,union,out=result,where=union>0)
    return result

true = np.array([0]*90+[1]*10+[255,255])
pred = np.array([0]*85+[1]*5+[0]*6+[1]*4+[0,1])
mat = confusion(true,pred)
assert np.array_equal(mat,[[85,5],[6,4]])
assert np.allclose(class_iou(mat),[85/96,4/15])
assert np.isclose(np.trace(mat)/mat.sum(),.89)
pred[-2:] = [1,0]
assert np.array_equal(confusion(true,pred),mat)
invalid = pred.copy(); invalid[0]=2
try:
    confusion(true,invalid)
except ValueError:
    pass
else:
    raise AssertionError('invalid prediction accepted')

small = np.array([[0,0],[0,10]])
large = np.array([[0,0],[1000,0]])
per_image = np.mean([class_iou(small)[1],class_iou(large)[1]])
merged = class_iou(small+large)[1]
assert np.isclose(per_image,.5)
assert np.isclose(merged,10/1010)
empty = class_iou(np.array([[5,0],[0,0]]))
assert np.isnan(empty[1])
false_positive_only = class_iou(np.array([[4,1],[0,0]]))
assert false_positive_only[1] == 0
print('segmentation statistics passed',per_image,merged)
```

若程序返回的某类为未定义，报告应说明原因，而不是删除显示后让平均类别数不透明。若以背景作为合法类别，是否纳入主指标也应固定。将这个程序用于真实标签时，还需核对数据集原始编号与连续类别索引之间的映射，尤其是“未标注”“其他”和“背景”经常不是同一个意思。

## 8. 评价结果怎样支持合理的研究结论

<a id="cv2-detail-36"></a>

### 8.1 类别错、定位错、重复与背景误报

一个未匹配预测可能来自类别错误、位置偏差、重复检测或纯背景响应。可以通过受控诊断逐项检查：先查看同类最大重叠，再看异类对象重叠，再看它是否与已匹配对象高度重合。这个诊断顺序本身也有约定，应保持一致。不能简单把所有未匹配框都称为“幻觉”，因为有些可能准确框住了物体但类别错了，有些可能发现了未完整标注的真实对象。

同一个错误在两个类别的统计中还可能同时表现为假阳性与漏检。例如把猫检测为狗，狗类收到一个假阳性，猫类仍少一个真阳性。这不是重复惩罚的实现错误，而是类别感知检测的目标决定的。若要单独分析定位能力，可以做忽略类别的辅助实验，但必须明确它只回答位置问题，不能替代主指标。

<a id="cv2-detail-37"></a>

### 8.2 门槛改变时必须重新建立匹配

提高重叠门槛使定位合格条件更严格，低门槛成绩通常优于高门槛成绩。但不能把低门槛已经产生的匹配身份固定下来，只删除重叠不足的那几项，就认为完成了高门槛评价。多个对象有竞争时，一个早期预测不再合格，会释放真实对象，使后续预测的可选对象改变。每个门槛都应独立执行协议规定的匹配过程。

例如高分框仅与对象甲有中等重叠，后一个框与甲重叠很高、与乙中等重叠。低门槛可能先由前框领取甲，后框转而领取乙；高门槛前框失败，后框改为领取甲。此时即使两个门槛的总体趋势符合直觉，具体错误身份已经改变。调试应比较完整匹配表，而不只看最终均值或把某个框永远标成真阳性。

<a id="cv2-detail-38"></a>

### 8.3 置信度、排序与概率校准的区别

对全部预测分数施加同一个严格单调函数，在没有额外阈值和候选变化的条件下，排序不变，平均精度也保持。但概率校准可以明显改变，例如把所有分数平方，排序不变而数值解释不同。反过来，重新校准若按来源或类别分别处理，可能改变跨来源或跨类别的排序，不能再保证总体排序指标不变。

一个检测分数通常混合类别可信度、对象性或定位质量的某种信息，具体含义由模型训练决定。把零点九分数直接解释成“这个框有百分之九十概率满足所有评价要求”，需要独立验证。不同重叠阈值对应不同事件，针对粗定位校准的分数也未必能直接解释精细定位成功率。指标报告应区分排序质量与数值可靠性。

<a id="cv2-detail-39"></a>

### 8.4 阈值附近的标注噪声

如果真实框边界只有一两像素的不确定，而目标本身只有四像素宽，高阈值评价可能对标注差异极其敏感。模型预测与两个合理标注的交并比可能分别落在阈值两侧，成绩发生离散跳变。这不是说应该随意降低门槛，而是要理解数据的可测精度，并通过复标、尺寸分层和多阈值报告展示限制。

边界宽度、模糊遮挡与实例可见性也应纳入标注指南。把标注员之间的不一致当成无穷精确真值，会导致过度解释很小的指标差异。研究中可抽样进行双人复标，报告一致性并观察结论是否对合理标注变化稳健。模型比较的有效分辨率受数据质量约束，不由输出小数位数决定。

<a id="cv2-detail-40"></a>

### 8.5 自助区间应按独立来源重算完整指标

检测平均精度是整个预测排序与匹配的非线性函数，不能简单给每个预测算一个平均精度再求标准误。可以按独立图像或更高层来源重采样，在每个重采样集合重新计算指标；如果同一视频或病人的图片相关，应整组抽取。重复抽到同一图像时要使用独立副本标识，避免评价器按原图编号错误合并。

比较两个模型时使用同一重采样组计算差值，保留配对结构。这样的区间条件于已经训练好的模型，不反映重新训练或重新搜参的不稳定。若测试只有少数来源，区间方法本身可能不可靠，应直接报告来源数与逐来源差异。增加重采样次数只能减少数值蒙特卡洛误差，不能增加真实来源的信息量。

<a id="cv2-detail-41"></a>

## 9. 进阶手算与指标结构

<a id="cv2-detail-42"></a>

### 9.1 Dice 和交并比为什么不能先平均再转换

设两个样本的交并比分别为零与一，平均交并比为二分之一；逐样本 Dice 也分别为零与一，平均为二分之一。若先把平均交并比二分之一代入 $`\frac{2J}{(1+J)}`$，得到三分之二，显然不是平均 Dice。原因是变换非线性，平均与非线性函数一般不能交换。

这个例子也说明比较不同论文的均值必须知道在哪个层级计算。逐图 Dice 平均、逐类 Dice 平均和合并像素 Dice 都可能合法，却不是同一指标。若只提供均值，没有分子分母或样本级统计，通常无法从一种均值精确恢复另一种。需要复算原始预测，不能靠公式变换一个总体数字完成换算。

<a id="cv2-detail-43"></a>

### 9.2 微小对象在整体交并比中怎样消失

设一个模型正确分割一万个大对象前景像素，却完全漏掉十个小对象各一个像素，合并前景交并比接近一。若任务是数对象，则小对象召回为零，数量错误非常严重。区域指标按面积加权的特性决定了这种现象，不是评价程序出错。应增加对象级召回、尺寸切片或与业务代价一致的加权方式。

反过来，若每个小对象都算一次等权指标，极微小区域的边界噪声可能造成很大方差。因此不能把某个平均方式当成包治百病。应根据任务同时呈现面积层面、对象层面与来源层面的证据，说明主指标为何对应实际决策。指标多样性服务于问题完整性，而不是为了挑出对模型最有利的数字。

<a id="cv2-detail-44"></a>

### 9.3 匹配不是对每一行独立取最大值

考虑两个预测都与同一个真实对象重叠很高，而另一个真实对象与它们都不重叠。若每个预测独立取最大值并判断通过，会错误得到两个真阳性、完全召回；合法的一对一匹配只能得到一个真阳性和一个重复假阳性，仍有一个漏检。这个极小反例足以检验评价实现是否真的维护已匹配状态。

即使做全局二分图匹配，也要区分它优化的目标：最大匹配数、最大重叠总和和按分数贪心不是同一规则。某些评价协议选择高分优先，是要衡量置信排序；某些训练分配选择最小总成本，是为了为输出提供监督。用更复杂的全局算法替代既定评价器，不会自动变得更正确，只是换了问题。

<a id="cv2-detail-45"></a>

### 9.4 预测框完全包含拥挤区域的直觉陷阱

普通交并比会惩罚覆盖大量背景的大框，但拥挤区域的特殊处理可能使用不同的覆盖判断。一个完全包含拥挤区的大框与一个完全落在拥挤区的小框，普通交并比和按预测面积归一的覆盖率会有不同结果。研究者应针对实际使用的特殊规则写出具体算例，不能只凭普通交并比直觉推断所有匹配结果。

同样，忽略规则不应成为逃避困难样本的工具。忽略对象的产生应由标注政策决定，不能在看到模型预测错误后临时标记。若新增标注发现原测试遗漏，应版本化整个数据集与评价结果，并对全部模型一致复算。修改真值后只更新某个模型的成绩，会破坏比较的公平基础。

## 10. 二十一道练习与完整解析

<a id="cv2-detail-47"></a>

### 10.1 两个面积一百的框交集六十

**问题：** 交并比和 Dice 分别多少，为什么不等于六成？

**解析：** 并集为一百加一百减六十，即一百四十，交并比为七分之三；Dice 为一百二十除二百，即零点六。交并比同时考虑两区域各自额外的部分，不能只用交集除真实面积。Dice 的分母也不是并集，因此数值刻度不同。只要两区域固定，可以用单调公式相互转换；跨样本平均后则不应直接转换。

<a id="cv2-detail-48"></a>

### 10.2 左上宽高为什么不能直接当边界

**问题：** 标注四个数为二、三、四、五，前两个是左上、后两个是宽高，边界框是什么？

**解析：** 右边界应为二加四等于六，下边界为三加五等于八，面积二十。若误当成左上右下，面积会变成二乘二等于四，位置与尺寸都改变。输入仍是四个合法数字，数值检查未必发现，因此应保存格式元数据并用可视化或手算样本验证转换。交换接口时不能依赖字段顺序猜测坐标语义。

<a id="cv2-detail-49"></a>

### 10.3 同一对象三个正确框怎样计数

**问题：** 只有一个真实对象，三个预测均达到门槛且同类，是否有三个真阳性？

**解析：** 普通对象一对一评价中，最高分的合格预测领取真阳性，其他重复预测记假阳性，除非它们还能合法匹配别的未领取对象。召回最多为一，精确率在保留三个预测时为三分之一。模型需要同时发现对象和避免重复，不能用重复框增加召回。忽略或拥挤区域有特殊规则，不能套用此例替代全部场景。

<a id="cv2-detail-50"></a>

### 10.4 四预测手算插值面积

**问题：** 两个真值，真假序列为真、假、真、假，计算全召回插值面积。

**解析：** 累计精确率为一、二分之一、三分之二、二分之一，召回为二分之一、二分之一、一、一。逆向取最大得到包络一、三分之二、三分之二、二分之一。只有第一次与第三次预测提升召回，各占二分之一宽度，因此面积为二分之一加三分之一，即六分之五。最后假阳性不改变已达到的两个召回区间的包络值。

<a id="cv2-detail-51"></a>

### 10.5 一百零一点和连续面积为何不同

**问题：** 上题的一百零一点平均是多少，差别来自哪里？

**解析：** 零至二分之一包含五十一个采样点，精确率一；余下五十个点精确率三分之二，因此平均为二百五十三除三百零三。离散点平均的端点权重与连续区间宽度不同，结果略高于六分之五。协议差异不代表某一程序一定有错。比较成绩时应统一定义，而不是只看两个数字足够接近。

<a id="cv2-detail-52"></a>

### 10.6 所有预测都为空时怎样评分

**问题：** 某类有十个有效真值，没有任何预测，平均精度和召回如何处理？

**解析：** 可达召回为零，平均精度为零。排序数组可以为空，不能因为没有预测而把该类排除出平均，否则完全漏掉的类别反而逃避惩罚。若整个类别没有任何真值，则是另一种不可评价情况，应按既定空类政策处理。区分没有预测与没有评价机会，是指标实现的重要边界。

<a id="cv2-detail-53"></a>

### 10.7 没有真值的图片上的预测去哪了

**问题：** 某类在其他图片有真值，但在一张纯背景图预测了框，这个框是否可以忽略？

**解析：** 正常穷尽标注条件下，该预测是此类的假阳性，进入全局排序。纯背景图是检验误报的重要组成部分，不能因为这张图没有真值就跳过全部预测。若数据集没有穷尽标注，则要遵从其忽略政策，不能用普通假阳性规则盲目惩罚。先确认标注完整性，再确定评价集合。

<a id="cv2-detail-54"></a>

### 10.8 类别错但位置完美怎样算

**问题：** 真值是猫，模型框完全正确却输出狗，类别感知检测如何计数？

**解析：** 狗类得到一个假阳性，猫类保留一个漏检；位置正确不能覆盖类别错误。若另做类别无关定位评价，可以把它视为定位成功，但那是辅助诊断。两项结果共同说明模型会找位置却不会分种类，比只报告一个总错误更有解释力。不得把类别无关结果冒充类别感知成绩。

<a id="sec-7-1"></a>

<a id="cv2-detail-55"></a>

### 10.9 高低定位门槛差距怎样解释

**问题：** 低门槛成绩好而高门槛明显差，下一步应查什么？

**解析：** 先核对框格式、缩放逆变换、坐标偏移与匹配规则，排除接口错误；再按尺寸和来源查看定位误差、标注不确定性及回归残差。如果主要是边界不准，单调改变置信度不会自动修正框。可研究更细特征、回归目标与后处理，但必须用统一预算和固定评价协议验证。

<a id="cv2-detail-56"></a>

### 10.10 小正方形的一像素误差

**问题：** 边长四与四十的框水平平移一像素，交并比分别多少？

**解析：** 代入平移公式，分别是三除五与三十九除四十一。相同绝对误差对应不同相对尺度，因此小目标在高门槛下更容易失败。应检查分辨率与量化误差，并报告按尺寸分层的结果。不能直接用大对象上的容许像素偏差来评价小对象定位能力。

<a id="cv2-detail-57"></a>

### 10.11 图像级平均和合并像素平均

**问题：** 十像素目标全对、一千像素目标全漏，两种前景交并比是多少？

**解析：** 逐图平均是二分之一，合并统计为十除一千零十。前者图片等权，后者前景面积等权。哪个作为主指标取决于任务决策单位，不能因为逐图结果更高就临时选择它。若一人有多张图片，还需要明确是否先按人聚合，逐图并不自然等于逐人。

<a id="cv2-detail-58"></a>

### 10.12 背景占优为何掩盖完全漏检

**问题：** 一千像素中只有十个前景，永远预测背景的准确率是多少，前景交并比是多少？

**解析：** 像素准确率为九百九十除一千，即百分之九十九；前景交并比为零。高准确率来自背景频率而非识别前景能力。若任务关心前景，应报告前景重叠、对象召回与关键错误代价。把背景作为类别纳入均值也应说明，不可让读者仅从一个高百分比判断系统可靠。

<a id="cv2-detail-59"></a>

### 10.13 忽略标签为什么不能改成背景

**问题：** 真实边界不确定区域标为忽略，转成背景会怎样？

**解析：** 原先不参与统计的像素会变成正常背景，模型在那里预测前景将被计为假阳性，改变分母与监督含义。应先建立有效掩码再统计。忽略区内预测变化不影响当前指标，是可执行的不变性检查。若模型需要对这些区域部署决策，应另外研究其不确定性，而非通过评价时改标签掩盖问题。

<a id="cv2-detail-60"></a>

### 10.14 空空掩码得一为什么可能误导

**问题：** 一百张图只有一张有前景，永远预测空，逐图空空得一会得到什么？

**解析：** 九十九张空图各得一，唯一有前景的图得零，平均为零点九九。这个数字主要反映无前景样本多，不能证明分割成功。可以保留该指标同时单独报告有前景图片与对象层面表现，或采用明确的全局聚合规则。重点是让空集约定和样本构成透明，而不是机械认定某种约定永远错误。

<a id="cv2-detail-61"></a>

### 10.15 没真值但有预测的类别能排除吗

**问题：** 某类全测试无真实像素，却被预测了很多，能否以空类为由不计？

**解析：** 它的并集并不为空，交并比应为零，假阳性具有评价意义。只有真值和预测都为空时才出现零分母问题。若实现仅按真值是否出现就排除类别，需要检查是否符合既定协议，并补充假阳性统计。不能让模型通过从未正确发现类别来逃避错误预测的惩罚。

<a id="cv2-detail-62"></a>

### 10.16 单调分数变换改变 AP 吗

**问题：** 所有分数都在零一之间，统一平方，没有阈值过滤，排序型平均精度怎样变？

**解析：** 严格单调变换保持排序，因此在匹配、候选和并列关系不变时，平均精度保持。概率数值却改变，所以校准可以变差。若仍用原来的固定阈值，保留预测集合可能改变，工作点指标也会变。必须区分完整排序协议与预过滤后的工作点。

<a id="cv2-detail-63"></a>

### 10.17 语义图正确为何计数错误

**问题：** 两个接触细胞都标成细胞类，模型合成一个实例，语义和实例评价各说明什么？

**解析：** 语义评价可以很高，因为像素类别正确；实例评价会反映合并与漏实例，因为对象身份错误。若任务需要计数或追踪，实例错误不能被区域重叠掩盖。连通域后处理依赖对象不接触等额外假设，不能从语义标签唯一恢复所有实例。

<a id="cv2-detail-64"></a>

### 10.18 全景质量怎样分解

**问题：** 三个匹配实例重叠和为二点四，另有一个假阳性和两个漏检，简单区域质量是多少？

**解析：** 分母为三加二分之一加一，即四点五，因此质量为二点四除四点五；匹配平均重叠为零点八，识别质量为三除四点五，两者乘积相同。该手算假设匹配集合已经确定，不涵盖忽略与类别等完整细节。它显示定位与实例发现两个方向可以分开诊断。

<a id="cv2-detail-65"></a>

### 10.19 为什么按预测框抽样低估不确定性

**问题：** 为两个检测器差异做区间，直接随机抽预测框是否合理？

**解析：** 通常不合适，框共享图像与来源，且平均精度依赖全局排序和真值匹配。应按独立图像或更高层来源重采样，保留同组真值与两个模型预测，重新计算差值。若复制图像，需要避免编号合并。这个区间条件于固定模型，不反映重新训练的随机性，应在报告中明确。

<a id="cv2-detail-66"></a>

### 10.20 怎样发现简化实现冒充完整基准

**问题：** 程序只计算一类一阈值面积，却把输出名写成公共基准平均精度，如何验收？

**解析：** 逐项检查类别循环、召回插值、重叠阈值、面积范围、候选上限、忽略和拥挤处理、稳定排序与空类政策。缺失机制应明确标注，结果更名为教学单类单阈值指标。需要正式比较时使用官方实现或验证逐例一致性。改函数名不能补齐协议，漂亮的小数也不能证明复现成立。

<a id="cv2-detail-67"></a>

### 10.21 去重门槛和评价门槛是不是同一个参数

**问题：** 非极大值抑制使用的重叠门槛与判定真阳性的门槛都叫交并比阈值，能否设为同一个后只调一次？

**解析：** 二者比较对象不同。去重比较预测与预测，决定哪些候选保留；评价比较预测与真实对象，决定定位是否合格。较强去重可能减少重复误报，也可能抑制拥挤中的真实邻近对象；提高评价门槛则提高定位要求。应在验证集选择后处理，在测试时固定，并独立报告既定评价门槛。名字相似不代表它们承担相同决策。

<a id="cv2-detail-68"></a>

## 11. 研究任务：把评价变成可审计证据

<a id="cv2-detail-69"></a>

### 11.1 先用微型数据写一份协议契约

构造两张图片、两个类别和若干矩形掩码，刻意加入重复预测、错类、低分正确框、空图片、忽略像素与小对象位移。先在纸上列出每个对象和预测的身份，再写出匹配表、排序表与混淆矩阵。对每种边界分别给预期，逐项用断言验收。这样建立的不是一个黑箱分数，而是对评价过程的可检查理解。

随后只修改一个因素：提高定位门槛、改变排序、删掉低分预测或切换聚合层级。每次先预测指标变化原因，再实际运行。如果结果不符合预测，检查是直觉错误还是实现错误。读者应能够解释分子、分母和匹配身份的变化，而不是仅记住某个库函数的调用方式。

<a id="cv2-detail-70"></a>

### 11.2 真实项目报告应包含什么

报告至少保留数据版本、有效来源数、类别与尺寸分布、评价器版本及参数、预测预处理、阈值选择来源、主要指标和关键切片。对检测给出排序能力与固定工作点，对分割给出区域与必要的实例或边界指标。对于少样本类别，避免只写百分比，应同时写对象数、像素数与不确定性。

如果某个模型总体上升却在关键来源或小目标下降，应如实保留并解释代价权衡。若标注不完整影响误报判断，应补标或限定结论，不应偷偷忽略不利图片。若官方工具与自写程序结果不同，应先查协议与输入，再判断是否存在实现问题。可复现评价的价值在于让别人能定位差异，而不是要求所有数字都符合预期。

<a id="cv2-detail-71"></a>

### 11.3 与下一章的连接

评价指出错误在哪里，模型流程解释错误如何产生。下一章将沿特征提取、候选生成、框回归、匹配、去重与掩码上采样讨论结构。读完本章后，应能判断某项结构修改主要影响类别、定位、重复还是像素边界，并选择相应诊断。不能只在一个总分上比较，而应说明结构假设怎样进入训练目标和最终评价。

完成标准是能从原始坐标和标签重建所有统计，能说明简化实验的范围，能识别匹配与平均顺序改变的结论，并能为关键业务问题选择适当评价单位。充分细致的评价不只是排名工具，也是发现数据问题、标签矛盾和模型机制的研究方法。
