## 1. 先定义部署中真正新的单位

同一视频的邻帧、同一工件的多视角、同一患者的多次检查和同一原图的裁剪，往往不是独立样本。随机按文件划分可以让训练与测试共享对象、背景、设备或近重复内容，评价的更接近已见来源插值。若目标是新对象，应按对象隔离；若目标是新设备，应按设备或合适来源隔离；若目标是未来，应明确时间与标签可得边界。不同划分没有无条件谁更正确，正确性来自所要估计的应用问题。

<a id="cv-4-detail-2"></a>
### 1.1 文件身份、内容身份与对象身份

文件路径是存储入口，字节摘要描述某个编码内容，对象身份描述现实实体。重新压缩会改变字节却保留几乎相同图像；同一对象不同视角也可能视觉差异很大。只按文件摘要去重能发现一类重复，却不足以保证对象独立；只看视觉距离又可能误合并外观相似但确为不同的对象。应保留来源记录、变换谱系与人工核验，按所需关系决定分组。

数据经过裁剪、旋转、增强和多次导出后，要记录子图来自哪张原图、哪次会话和哪个对象。先随机拆分增强结果，再发现原图跨集合，是常见泄漏路径。合理流程通常先按实际独立单位分角色，再在各自边界内生成训练变换。测试中同源多视图仍可以存在，但支持数与不确定性应按真实依赖说明，不能把每张导出文件都算新独立来源。

<a id="sec-1-1"></a>
<a id="cv-4-detail-3"></a>
### 1.2 分组关系可能需要传递闭包

如果甲与乙属于同一对象，乙与丙又是同一内容的别名，那么若独立处理每条关联却未统一对象别名和分组身份，可能漏掉应一并分配的关联链。可以把不可跨角色的关系作为图边，按连通分量整体划分。关键是边的语义：若任务是新对象，不能仅因使用同一相机就无条件把全部对象连成一组；若任务是新相机，设备本身才是更外层的隔离单位。图算法很简单，分组政策却必须来自研究问题。

同一连通分量中标签冲突也是审计信号，但不能立即强行投票修正。静态对象分类中同对象异标签可能是错误或别名问题，病程随时间变化的任务则可能合理。先核对标签定义、时间和来源，再决定是否修订。审计不是把所有复杂数据压成一个一致标签，而是让不一致有可解释的语义和可追踪处理。

<a id="cv-4-detail-4"></a>
### 1.3 实验一：按不可跨界谱系构造连通分量

例子有六条记录，前两条同对象，第二与第三条是重复内容别名，后两条同另一个对象。代码只把这两类关系纳入边，计算分量后分配训练与测试，并核对没有边跨界。摄像头字段只作为元数据保留，没有自动并组。它不从图像像素神奇识别真实身份，而是验证已有审计关系怎样落实到划分。

```python
rows = [
    {'id': 'a', 'object': 'p1', 'content': 'h1', 'camera': 'c1'},
    {'id': 'b', 'object': 'p1', 'content': 'h2', 'camera': 'c1'},
    {'id': 'c', 'object': 'alias-p1', 'content': 'h2', 'camera': 'c2'},
    {'id': 'd', 'object': 'p2', 'content': 'h3', 'camera': 'c1'},
    {'id': 'e', 'object': 'p3', 'content': 'h4', 'camera': 'c2'},
    {'id': 'f', 'object': 'p3', 'content': 'h5', 'camera': 'c2'}]
parent = list(range(len(rows)))
def find(i):
    while parent[i] != i:
        parent[i] = parent[parent[i]]
        i = parent[i]
    return i
def union(i, j):
    parent[find(j)] = find(i)
edges = []
for i in range(len(rows)):
    for j in range(i):
        if rows[i]['object'] == rows[j]['object'] or rows[i]['content'] == rows[j]['content']:
            union(i, j); edges.append((i, j))
groups = [find(i) for i in range(len(rows))]
assert groups[0] == groups[1] == groups[2]
assert groups[3] != groups[0] and groups[4] == groups[5]
train_groups = {groups[0], groups[3]}
role = ['train' if g in train_groups else 'test' for g in groups]
assert all(role[i] == role[j] for i, j in edges)
assert rows[0]['camera'] == rows[3]['camera'] and groups[0] != groups[3]
print('connected groups:', groups, 'roles:', role)
```

<a id="cv-4-detail-5"></a>
### 1.4 来源缺失时应承认什么

缺少作者、设备或会话字段时，不能因为文件名不同就确认独立。可以审查摘要、近重复候选和现有元数据，描述未能识别的来源关系，并将结论限制在当前协议。若真正需求是新来源泛化，应补采集或分组证据，而不是用更严格措辞包装同一随机图片划分。数据缺口是研究限制，不是调大模型能够解决的实现问题。

分组后类别覆盖可能不均，尤其某类别只来自一个地点时，新地点评价同时改变类别支持。应先列来源与类别交叉表，检查是否存在可识别的比较。既要来源隔离又要每侧完全同分布未必可实现，可以分别设计新来源与共同类别任务，明确各自总体。不能为了维持高分而把困难来源移回训练，又继续声称测了来源外泛化。

## 2. 背景捷径：从观测关联到可控干预

图像标签可能与背景、边框、水印、采集设备或压缩方式相关。训练风险最小化并不会自动知道哪些相关性将在部署保留，模型可以利用容易预测的线索。背景利用本身不必在所有任务都错误；判断取决于标签定义和目标分布。例如环境识别本来需要背景，而物体类别在更换无关背景后通常希望保持。先定义应不变的内容，再讨论捷径，避免把任何模型偏好都道德化地叫错误。

<a id="cv-4-detail-7"></a>
### 2.1 一个可以明确操纵的生成机制

人工图像中心有横或竖条纹决定二类标签，外围亮度作为背景。训练与同机制验证中，背景和标签完全相关；另生成背景与标签相反的测试机制，并对同一图像只替换外围做配对干预。因为渲染器明确规定中心决定标签，所以背景替换在这个人工任务中合法，中心像素保持可以逐项断言。真实照片的前景分离与伪影会更复杂，不能直接继承相同因果解释。

比较三个事先固定流程：全部像素逻辑回归、只读取中心的模型，以及在训练内补入背景翻转副本的全部像素模型。它们使用相同内容标签，但输入范围或训练变换不同，所以这是完整方案对照，不是参数完全相同的单因素证明。我们不根据测试挑正则、强度或窗口，也不声称裁掉背景在所有视觉任务都更好。实验目的在于展示训练相关性不能唯一决定跨机制规则。

### 2.2 实验二：完整人工图像捷径对照

下面直接生成十六乘十六灰度图，不下载数据，也不使用外部预训练。训练二百四十、验证八十、测试一百二十，分别用独立生成器；对象只含一张图，角色不共享源实例。训练设置的背景相关是已知机制，测试背景翻转也是预设干预。模型只在训练拟合，验证和测试都不参与参数选择。结果由代码实际打印，较低或较高分都保留，不以某种排名作为测试必须通过条件。

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from threadpoolctl import threadpool_limits

outer = np.ones((16, 16), dtype=bool); outer[4:12, 4:12] = False
def render(n, seed):
    rng = np.random.default_rng(seed)
    y = np.arange(n) % 2
    rng.shuffle(y)
    image = np.empty((n, 16, 16), dtype=float)
    for i, label in enumerate(y):
        image[i] = .2 + .6*label
        image[i, 4:12, 4:12] = .2
        if label == 0:
            image[i, 4:12, 7:9] = .8
        else:
            image[i, 7:9, 4:12] = .8
        image[i] += rng.normal(0, .025, (16, 16))
    return image.clip(0, 1), y

def reverse_background(image, y):
    changed = image.copy()
    changed[:, outer] += (.6*(1-2*y))[:, None]
    assert np.allclose(changed[:, outer]-(.2+.6*(1-y))[:, None],
                       image[:, outer]-(.2+.6*y)[:, None])
    assert changed.min() >= 0 and changed.max() <= 1
    assert np.array_equal(image[:, 4:12, 4:12], changed[:, 4:12, 4:12])
    return changed

def flat(image):
    return image.reshape(len(image), -1)
def center(image):
    return image[:, 4:12, 4:12].reshape(len(image), -1)
train, yt = render(240, 601)
val, yv = render(80, 602)
test, ye = render(120, 603)
shifted = reverse_background(test, ye)
augmented = reverse_background(train, yt)
with threadpool_limits(limits=1):
    full = LogisticRegression(C=1., max_iter=300).fit(flat(train), yt)
    crop = LogisticRegression(C=1., max_iter=300).fit(center(train), yt)
    mixed = LogisticRegression(C=1., max_iter=300).fit(
        flat(np.concatenate((train, augmented))), np.tile(yt, 2))
    for name, model, transform in [('full', full, flat), ('center', crop, center),
                                    ('background-mixed', mixed, flat)]:
        val_acc = (model.predict(transform(val)) == yv).mean()
        clean = model.predict(transform(test))
        altered = model.predict(transform(shifted))
        print(name, 'val / test / changed-background / flip-rate:',
              val_acc, (clean == ye).mean(), (altered == ye).mean(),
              (clean != altered).mean())
assert np.array_equal(center(test), center(shifted))
print('label-defining pixels are identical in all paired background changes')
```

<a id="cv-4-detail-9"></a>
### 2.3 这个实验的可识别与不可识别范围

训练里中心与背景都预测标签，单看同机制验证分数无法区分两种规则。额外的干预机制提供新信息，观察到背景改变时输出变化，结合已知渲染规则，可以更明确地分析此人工任务的依赖。它不证明真实图像模型一定采取同样捷径，也不证明人工补背景一定适用于自然照片。每次从机制实验走向实际数据，都需要重新验证内容、伪影和覆盖。

模型不同还改变可见信息：中心模型无法用外围，但也不能处理物体离开中心的情况；训练补入背景翻转增加了每个原图的曝光与变换支持，不创造新的独立对象。若研究具体效率，应匹配相应更新或计算预算再比较。一个对照可以解释一类机制，不能顺便承诺所有分辨率、遮挡和位置下的鲁棒性。解释中保留这些代价，才能形成真实可用结论。

本机实际运行中，三个方案的同机制验证和原始测试准确率均为一；全部像素模型在配对背景改变后准确率为零、预测翻转率为一，中心模型与背景混训模型均保持准确率一且翻转率零。结果符合预设人工机制，但只证明这些固定输入和流程的响应，不构成真实自然域性能估计。保留全部方案结果也不能替代不同内容位置、强度和新对象上的独立检验。

<a id="cv-4-detail-10"></a>
### 2.4 自然反例与合成替换互补

真实来源外图像同时改变成像、内容组成和标注机制，代表性较强，但变量不容易隔离；合成替换能固定更多条件，却可能引入边缘伪影和分布外纹理。二者适合结合。先在开发区提出背景依赖假设，再用多种合法替换和自然新背景确认，避免只挑最能让模型失败的一个生成器就宣称发现唯一原因。

还应设置不改变任务标签的普通处理对照，例如不触碰前景的同强度调整，以及匹配的无关位置变化。若任意微小处理都引起大差异，可能是前处理、数值或输入分布问题，而非特定背景机制。使用相同对象的配对变化有助于控制内容差异，但统计独立单位仍是原对象，不是变化版本总数。分析和区间都要保持这层身份。

## 3. 总体指标、分层风险与组成变化

总体准确率是各组准确率按样本占比加权的和，因此总体变化可能来自组内质量，也可能来自组占比。若新测试集里困难小目标更少，即使模型在小目标组更差，总体仍可能更高。审计应同时给组支持数、组内质量和共同参考权重下的标准化结果。三者分别描述实际请求组成、条件表现与固定组成比较，不能只拿一个平均数否认关键群体退化。

<a id="sec-2-1"></a>
<a id="cv-4-detail-12"></a>
### 3.1 用代数分解总体变化

令版本甲乙的组占比为 $`w_{Ag},w_{Bg}`$，组质量为 $`q_{Ag},q_{Bg}`$。总体差可以写成 $`\sum_gw_{Ag}(q_{Bg}-q_{Ag})+\sum_g(w_{Bg}-w_{Ag})q_{Bg}`$。第一项在甲组成下比较组内变化，第二项描述按乙质量评估的组成变化。换另一参考也可得到其他精确分解，所以两项名称与基准要清楚，而不是把一种分解看成唯一因果答案。

标准化要求组的定义和质量具有可比意义，且有足够支持。若乙没有某关键组，无法仅靠重新加权凭空知道其质量；若标签机制或目标变化，数学加权也不能恢复同一任务。分层表帮助发现问题，但零支持或极小支持应明确标记，不用补零或沿用旧值制造完整结果。来源、类别、尺寸与遮挡可能交叉，过细切片还会引入稀疏与探索选择。

<a id="cv-4-detail-13"></a>
### 3.2 小目标为什么容易在大分母中消失

语义分割按像素统计时，背景占绝大多数，预测全部背景可能获得很高像素准确率，却完全漏掉前景。按类平均 IoU 能揭示不同问题，按对象或按图等权又是其他目标。目标检测还受置信排序、匹配、面积定义与忽略规则影响。应把真实代价映射到指标和聚合单位，不因为某个指标常用就假定它覆盖全部需求。

小目标经缩放后可能只剩几个像素，插值、量化、阈值和标注边界都更敏感。退化可能来自输入已丢信息、模型读取范围或后处理过滤，需要分别核对原始尺寸、变换坐标、匹配与输出。不能只增加网络层数来修一个被预处理删掉的目标。审计应保存变换链和可视化抽样规则，让错误能追到最早出现的位置。

<a id="cv-4-detail-14"></a>
### 3.3 IoU 与 Dice 的逐项关系及平均陷阱

对非空并集，交集为 $`I`$、并集为 $`U`$，两个区域面积和等于 $`U+I`$，所以 $`D=\frac{2I}{(U+I)}=\frac{2J}{(1+J)}`$，其中 $`J=\frac{I}{U}`$。该变换二阶导数为负，因此是凹函数；在相同权重与合法定义下，先逐项变换再平均一般不等于对平均 IoU 变换，且前者不大于后者。只有特殊情形，例如各项相同，才可相等。

空真值与空预测需要额外约定，并集零时原比值没有定义。忽略空项、记一或其他政策会改变分母和总体，必须与评价实现一致。不能从一篇报告的平均 IoU 直接推另一篇的平均 Dice，更不能跨逐图与全局像素聚合换算。数值转换只有在对象、权重和空项处理都一致时才有明确含义。

<a id="cv-4-detail-15"></a>
### 3.4 实验三：组成反转与全背景反例

以下人工计数让总体正确数从九百六十二升到九百八十六，但小目标组从百分之八十降到六十；固定原组比例后，乙反而更低。另建百分之一前景的掩码，展示全背景预测的百分之九十九像素准确率与零前景 IoU。最后核对 Dice 非线性平均。这些是评价算术反例，不是某个真实模型成绩。

```python
import numpy as np

n_a = np.array([100, 900]); correct_a = np.array([80, 882])
n_b = np.array([10, 990]); correct_b = np.array([6, 980])
q_a, q_b = correct_a/n_a, correct_b/n_b
w_a, w_b = n_a/n_a.sum(), n_b/n_b.sum()
overall_a, overall_b = correct_a.sum()/n_a.sum(), correct_b.sum()/n_b.sum()
standardized_b = w_a@q_b
within = w_a@(q_b-q_a)
composition = (w_b-w_a)@q_b
assert overall_b > overall_a and q_b[0] < q_a[0]
assert standardized_b < overall_a
assert np.isclose(overall_b-overall_a, within+composition)

truth = np.zeros((100, 100), dtype=bool); truth[0] = True
prediction = np.zeros_like(truth)
accuracy = (truth == prediction).mean()
intersection = (truth & prediction).sum(); union = (truth | prediction).sum()
assert accuracy == .99 and intersection/union == 0
j = np.array([0., 1.]); dice = 2*j/(1+j)
assert not np.isclose(dice.mean(), 2*j.mean()/(1+j.mean()))
print('overall A/B / B on A weights:', overall_a, overall_b, standardized_b)
print('within / composition contributions:', within, composition)
print('all-background pixel accuracy / foreground IoU:', accuracy, intersection/union)
print('mean Dice / transform(mean IoU):', dice.mean(), 2*j.mean()/(1+j.mean()))
```

## 4. 扰动测试必须保持标签和可判定性

亮度、噪声、压缩、模糊、裁剪和遮挡描述不同变化机制，强度应来自目标场景或明确压力问题。一个模型在某种高斯噪声下稳定，不等于新相机、夜间和新地点都可靠；这些自然变化还可能改变色彩、光学、内容组成与标注。合成扰动帮助隔离敏感性，代表性自然来源帮助评价真实外部范围，两者互补而不能替代。

<a id="cv-4-detail-17"></a>
### 4.1 不变标签与同步变换标签

分类中某些变换期望标签不变，检测和分割则常需要同步改变框、掩码或关键点。几何变换之后，坐标约定、插值和裁剪应一致，不能只改图不改标注。即使标签坐标正确，裁掉唯一可识别内容后，原分类答案也可能不再可判定。保留标签编号不代表语义条件仍成立，要检查任务允许的可见性。

也不能用一个统一可见比例阈值保证所有类别可判定。某些类别依赖局部特征，损失少量关键区域就模糊；另一些即使遮挡较大仍可识别。比例可作为可复算审计字段，再结合任务规则或人工核验决定有效性。报告同时给合法覆盖和被排除原因，不把无效样本静默删掉后只展示改善的准确率。

<a id="cv-4-detail-18"></a>
### 4.2 实验四：几何可见性与强度饱和

构造一个已知前景掩码，对完整、半裁剪和完全裁掉三个窗口计算保留面积；同步检查翻转。另用过大亮度变换把两种不同输入都裁剪到同一全白图，说明强扰动可消除判别信息。代码没有训练模型，它直接检验输入与标注机制，因此不会把不可判定后的错误归为模型单独失效。

```python
import numpy as np

mask = np.zeros((8, 8), dtype=bool); mask[2:6, 3:7] = True
assert mask.sum() == 16
crops = [(0, 8, 0, 8), (0, 4, 0, 8), (0, 2, 0, 8)]
fractions = []
for y0, y1, x0, x1 in crops:
    transformed = mask[y0:y1, x0:x1]
    fractions.append(transformed.sum()/mask.sum())
assert fractions == [1., .5, 0.]
image = np.where(mask, .8, .2)
assert np.array_equal(image[:, ::-1] > .5, mask[:, ::-1])
other = np.where(mask.T, .8, .2)
assert not np.array_equal(image, other)
saturated_a = np.clip(image+1., 0, 1)
saturated_b = np.clip(other+1., 0, 1)
assert np.array_equal(saturated_a, saturated_b)
assert np.all(saturated_a == 1)
print('retained foreground fractions:', fractions)
print('excessive brightness maps distinct contents to identical input')
```

<a id="cv-4-detail-19"></a>
### 4.3 同源扰动曲线需要成对保存

对同一原图生成多档强度，记录原图身份、参数、有效性和预测。报告原始质量、各档质量、配对差、失效类型与支持数，不只给相对下降比例。两个模型的原始质量不同，单纯相对退化排名可能反转绝对质量；应用需要同时知道干净和变化后的表现。分母与覆盖改变时，也应单列，不能将被判无效的困难样本悄悄移出。

同一原图的多个版本相关，区间与检验应按原对象保留整组。若从许多扰动里挑最差一项再当预先主结果，会有探索选择；可以报告探索谱系，再用独立确认。强度曲线不一定单调，插值与模型边界可能带来局部变化；不应为了“合理”强行平滑成单调线。先保留真实结果，再检查实现与机制。

<a id="cv-4-detail-20"></a>
<a id="sec-8-2"></a>
### 4.4 对抗、常见损坏和自然来源是三类问题

常见损坏按某个随机或固定变换机制生成；最坏扰动在约束集合内针对当前模型寻找；自然来源数据来自实际采集分布。它们的风险定义和验证方式不同。一次攻击没有找到错误，不等于数学证明整个约束集合安全；一个损坏基准高分，也不保证新的自然域。报告应给对应问题及预算，而不将“鲁棒”视作无条件属性。

真正部署还包含输入质量无法保证和未知内容，此时可定义拒绝、补拍或人工复核策略。策略本身会改变覆盖与成本，也需要评价，而不是只在模型分数低时随意丢样本。将任务、变化集合和决策政策写清，才知道当前系统对什么条件有证据、对什么条件仍未知。视觉审计最终服务于这些具体边界。

<a id="cv-4-detail-21"></a>
## 5. 高置信、拒答与零错误的证据边界

softmax 最大值是模型内部概率变换，不是自动的输入合法性或分布外可靠性证明。来源变化可能让模型在错误捷径上更自信，简单提高阈值未必降低保留样本风险。应在合法开发数据上选策略，并在目标来源评价覆盖和条件错误。只展示被保留部分准确率而不报告拒绝数量，会隐藏系统到底服务了哪些请求。

<a id="cv-4-detail-22"></a>
### 5.1 风险与覆盖的分母

令策略 $`g(x)`$ 表示是否接受，覆盖为总体接受概率，条件风险为接受且错误的概率除接受概率。若覆盖为零，条件风险不能随便记零当成功；它是没有服务的边界。两个策略覆盖不同，风险数字不宜直接比较而忽略任务量。可以预设最低覆盖或共同覆盖下比较，并报告各来源的保留与错误，避免把困难群体整体拒绝后伪装公平质量改善。

置信与错误关联取决于数据分布，来源外可能逆转。校准在某总体上成立也不自动迁移到新总体，校准本身只约束概率语义的某些平均条件，不保证每类、每来源和每个输入安全。若无法获取目标标签，很多错误风险并不可识别。应说目前只观察到输入或分数变化，不能仅凭无标签分布检测给出具体准确率下降保证。

<a id="cv-4-detail-23"></a>
### 5.2 零观察错误不是零总体风险

固定系统在 $`n`$ 个独立同分布单位上没有错误，若每单位错误概率为 $`p`$，零错误概率为 $`(1-p)^n`$。给定单侧错误水平 $`\alpha`$，反演得到相应精确二项上界 $`1-\alpha^{\frac{1}{n}}`$。例如三十个独立来源全无错误，百分之九十五单侧上界仍约百分之九点五。这个结论要求单位和目标明确，不能拿同对象上千帧替代三十个真正独立来源。

若把事件定义为“一个来源内至少一张失败”，得到的是来源级失败概率，不等于随机帧风险。两者分母和相关结构不同。若观察样本不是目标总体随机代表、阈值在同样本上选过，或来源变化，二项假设也需重审。一个有限样本上界可以帮助量化证据不足，不能为未覆盖场景提供无限外推保证。

<a id="cv-4-detail-24"></a>
### 5.3 实验五：置信筛选反例与独立单位计数

人工固定八条预测，最高置信的两条故意错误，阈值提高后风险反而上升。另计算三十来源与一千图像作为独立单位时的零错误上界，说明错误分母怎样制造虚假精确。两种计数不能随意互换；实验只是把假设变化的后果显示出来，不宣称这些八条概率来自真实视觉模型。

```python
import numpy as np

confidence = np.array([.99, .98, .95, .90, .80, .70, .60, .55])
error = np.array([1, 1, 0, 0, 0, 0, 0, 0], dtype=float)
accept = confidence >= .9
coverage = accept.mean()
conditional_risk = error[accept].mean()
assert coverage == .5 and conditional_risk == .5
assert error.mean() == .25 and conditional_risk > error.mean()
alpha = .05
source_bound = 1-alpha**(1/30)
image_bound = 1-alpha**(1/1000)
assert source_bound > .09 and image_bound < .0031
assert source_bound > image_bound
print('overall error / selected risk / coverage:', error.mean(), conditional_risk, coverage)
print('zero-error upper bound n=30 / n=1000:', source_bound, image_bound)
```

<a id="cv-4-detail-25"></a>
### 5.4 风险证据还需要更新与漂移监测

模型或前处理更新后，旧风险结论未必继续成立，应回归关键来源和失败模式。监测输入质量、覆盖与分数有助于发现变化，但要评价真实错误还需适当标签、延迟与抽样政策。若只对已接受样本获取标签，拒绝区域的风险通常无法直接估计，需额外审核或明确未知。数据反馈机制也是完整系统的一部分。

阈值不能在监测中不断无记录地调整，却继续引用最初测试成绩。每次策略变更记录版本、选择信息和覆盖，必要时安排新确认。某群体被大量拒绝或失去可用输入时，应报告功能损失，不能仅用保留样本错误低宣布系统稳定。鲁棒性与服务范围一起定义，才能让改进与退化都有清楚含义。

## 6. 标签与采样审计：先确认要学习的事实

<a id="cv-4-detail-27"></a>
### 6.1 标签来自图像内容还是采集流程

一个视觉标签可能来自人工观察、设备测量、后续事件或管理规则。它们代表不同的目标：图中是否出现裂纹，与工件最终是否被报废不是同一个问题；图中存在某种形态，与某个专家作出某种决策也不相同。若数据集标签实际上由采集站点或设备型号间接决定，模型学会这些线索并非实现意义上的异常，但它未必回答研究者声称的内容识别问题。审计首先要追踪标签如何产生，而不是默认表格最后一列就是无误真值。

来源记录应包含标注者可见的证据、时间和适用规范。如果后续检测结果用来补充标签，需要确认训练时能否合法获得对应特征，避免把事后信息混入输入。若标签依赖图像之外的背景，应明确模型是否也能读取这些信息；仅凭图像不可判定的目标，不能通过强迫单一标签就变成可解任务。模型持续错误的样本有时暴露的是目标不可达，而不是网络容量不足。

<a id="cv-4-detail-28"></a>
### 6.2 标注分歧与边界模糊

检测框、分割边缘和细粒度类别常存在合理分歧。一个物体被遮挡时，是标可见区域还是完整外形；边缘半透明时，是硬阈值还是软掩码；多个紧贴对象是否拆分，都需要规范。应在代表性样本上检查标注者间差异，并保存裁决条件。把所有分歧通过多数票变成一个数，可以形成操作标签，但不意味着真实不确定性已经消失。

对边界误差敏感的小目标，少量像素差异会引起很大 IoU 变化。应结合标注重复性解释指标，必要时给出容忍边界的诊断，但主评价约定必须冻结。不能在看到新模型边界略偏以后临时放宽匹配阈值，再把改进解释为模型质量提升。标签修订有价值，却需要新数据版本、明确理由和一致重评，而不是只修正某个系统表现不好的记录。

<a id="cv-4-detail-29"></a>
### 6.3 类别、来源与缺失机制的交叉表

至少按类别与来源列出样本数、独立对象数、缺失标签数和无法使用的图像数。若某类别只由某设备采集，设备与类别高度纠缠，来源外质量可能无法分离估计。若困难样本更容易无法标注，删除缺失标签会让剩余集合偏向容易样本。表面上数据清洗提高了准确率，实际可能只是改变了目标总体和覆盖范围。

缺失不能一律当负类。没有标框可能表示图中没有目标，也可能表示该类别尚未审核；没有测量可能表示设备失败，不能自动解释成正常。应使用独立状态区分已确认不存在、未标注、无法判断和无效输入，并在训练及评价中明确处理。如果标注覆盖只针对部分区域或类别，评价器也要遵守忽略规则，不能把所有额外预测都当成误报。

<a id="cv-4-detail-30"></a>
### 6.4 抽样与权重决定目标人群

按类别均衡采样有助于训练，但均衡后的测试准确率不等于部署请求准确率。若部署某类更常见，需要明确按部署比例加权还是按类别等权；二者各有用途，不能混淆。对于主动挑选的困难样本，可以用来诊断特定失败，却不能直接估计总体失效率。审计记录应保存采样规则、被抽中概率是否可知，以及未被覆盖部分有哪些。

逆概率权重有时能够修正已知抽样差异，但需要正支持和正确概率。某类来源从未被抽到时，不能给零概率求倒数后凭空恢复其质量；权重极大还会放大方差。若缺失依赖未观察到的难度或真实标签，单靠现有可见字段未必可识别。应把能够通过数据支持的标准化，与必须依赖额外假设的校正区分开。

<a id="cv-4-detail-31"></a>
### 6.5 数据修订的冻结边界

发现重复、坏图和错标之后，应保留原始身份、修订原因和新版本映射。若在最终测试中只修改模型失误样本的标签，会引入选择偏差；应按独立规则复核相应范围，并对所有比较方法一致重评。修订后的测试也已经提供开发信息，后续根据这些观察改变系统，需要新的确认设计或明确探索性质。

删除样本并不总是正确修复。有些极难样本本来就属于真实需求，应保留并明确质量边界；有些损坏输入需要定义补拍或拒绝，而不是从报告中消失。每次修订都要说明对总数、来源、类别与覆盖的影响，让读者知道指标变化来自模型、标签还是样本组成。数据治理的价值在于可追踪和任务一致，不在于把最终表清理得毫无困难。

<a id="cv-4-detail-32"></a>
## 7. 域变化的可识别性与部署决策

<a id="cv-4-detail-33"></a>
### 7.1 输入变化、先验变化和条件关系变化

可以把联合分布写为输入分布与给定输入的标签分布之积，也可以写为标签先验与给定标签的输入分布之积。所谓协变量变化、先验变化和概念变化，分别要求某些因子保持不变。这些是研究假设，不是看到图像亮度变了就能直接确认的类别。真实新相机可能同时改变噪声、拍摄对象和标签质量，因此多个机制可能一起发生。

无标签目标图像可以帮助观察像素、特征和分数分布变化，却通常无法唯一确定目标错误率。两个世界可能拥有相同输入分布和相同模型输出，一个保持旧标签规则，另一个改变标签含义；没有目标标签或额外假设就无法区分。检测到分布差异也不必然意味着任务质量下降，未检测到差异更不证明标签关系没有变化。监测信号与风险证据必须分开命名。

<a id="cv-4-detail-34"></a>
### 7.2 重加权和适应方法需要支持条件

若假设目标与训练的条件标签关系相同，而且目标输入落在训练有支持的区域，可以尝试根据输入分布比例重新加权。但密度比难以稳定估计，高维特征和极端权重会引入问题；训练中完全没有覆盖的新对象不能只靠权重创造知识。应用重加权前应说明不变假设、支持重叠和估计方式，并用有标签的目标审查检验，而不是把方法名字当成保证。

测试时适应可能更新归一化统计或参数，它改变了部署函数及其状态依赖。若一个请求的输出受此前请求影响，应报告顺序、批量和重置策略；把测试集整体一起适配，与逐条在线处理不是同一权限。适应还可能吸收错误伪标签或让某类输入主导统计，因此需要独立对照与回退政策。旧模型的固定测试结论不能自动转给更新后的动态系统。

<a id="cv-4-detail-35"></a>
### 7.3 来源泛化与最坏群体的有限证据

多个训练来源为研究跨来源稳定性提供信息，但有限来源不等于覆盖所有未来环境。一个在已知来源最差组上表现更好的方法，仍可能在新的组合上失败。应说明群体如何定义、是否预先指定、每组支持和选择过程。若在大量切片中找最差一组，它可以作为探索信号，却与预设主群体的确认性结果不同。

最坏群体指标也受样本量影响：小组估计噪声更大，观察到的最小值可能受偶然极端影响。不能只给一个最差数字而省略来源表和区间，也不能因小组不稳定就把它删除。可以预先规定最小证据要求、补采样和单独不确定标记，同时报告服务范围。目标是让重要失败可见，而不是通过统计门槛让困难人群从评价中消失。

<a id="cv-4-detail-36"></a>
### 7.4 鲁棒性取舍应面向具体干预集合

增强、裁剪和背景混训可能改善某种变化，却损害其他能力。中心裁剪在本章人工任务中保留了定义标签的区域，但真实对象可能移动到边缘；颜色归一化可能抑制设备差异，也可能移除任务所需色彩；模糊增强可能帮助噪声适应，却降低微小纹理区分。应逐项说明保持和牺牲的证据，不能把单一扰动改进写成全面鲁棒。

合理比较至少同时观察原始质量、预设变化下质量、覆盖、成本和重要群体。如果变化强度超出合法语义范围，结果应标为压力边界而非普通任务错误。若系统需要在质量和资源间选择，应先定义可行约束，再展示取舍；没有需求时可以保留多个候选，不必用任意加权总分创造一个看似唯一的赢家。

<a id="cv-4-detail-37"></a>
## 8. 交付、更新与持续审计

<a id="cv-4-detail-38"></a>
### 8.1 完整视觉函数的接口契约

交付函数包括解码、通道顺序、方向处理、尺寸变换、数值缩放、模型模式、阈值和类别映射。相同权重配不同裁剪或颜色空间，就是另一预测函数。推理入口应明确接受原始字节还是已解码张量、允许的形状和单位、空输入与损坏输入如何处理。不能根据一批图像的最大值临时猜单位，因为低对比图本身也可能处于较小数值范围。

固定参考样本可以核对加载前后的中间张量、分数和区域坐标，但不能覆盖所有图像。检测与分割还需比较变换坐标、有效区域和后处理，避免模型分数相同却映回原图位置错误。单张与批量一致性只有在评估模式、逐样本前处理及无跨请求模块等条件下才应成立；发现差异应定位条件，而不是简单归咎于浮点或重新训练。

<a id="cv-4-detail-39"></a>
### 8.2 更新要同时检查质量、覆盖与回归

新版本修复某个来源后，应回归原有来源、关键错误和接口契约，并在未参与修改的新证据上确认目标收益。旧失败集适合检查修复，却已不是完全独立测试。若阈值、预处理或标签表改变，应使用新版本身份，报告变化所用信息。把多个版本最好的指标拼成一行，会制造不存在的实际系统，无法支持部署选择。

在线监测应区分输入异常、分数变化、人工标签和实际业务结果。某些标签有延迟，某些只来自被系统选中的样本，因而需要抽样复核和成熟窗口。若只审核低置信样本，得到的错误率不能直接代表全部请求；若只审核已接受样本，又无法了解拒绝区域。采样政策和复核成本同样应进入报告，而不是把监测仪表中的一个数字当作总体质量。

<a id="cv-4-detail-40"></a>
### 8.3 实验归档与临时产物管理

教学资料应保留完整 Markdown、可执行代码、环境与实际结果说明，实验图像和模型可在内存或自动清理目录中验证。本章五段代码不要求留下训练脚本、缓存或模型文件。真实研究交付则需要保留重建函数和复算结论的必要状态，不能删掉唯一的类别映射或划分身份后仍声称结果可复现。清理取决于用途和依赖，不是简单按后缀一律删除。

完成前检查目录链接、锚点、代码语法与实际实验记录，确认每个结论都能追到对应对象。人工计数不应写成真实相机成绩，受控渲染器的因果解释不应推广为自然图像普遍规律。交付的价值是让学习者能够理解、重建、质疑和继续实验，并明确什么时候需要新数据，什么时候只是实现检查，不用更多漂亮数字遮住证据边界。

<a id="cv-4-detail-41"></a>
## 9. 二十四道练习与逐题详解

<a id="cv-4-detail-42"></a>
### 9.1 文件不同为何仍可能泄漏

**问题：** 同一视频导出的相邻帧文件名和摘要都不同，随机拆分是否能评价新场景？

**解析：** 不能仅凭这两种不同确认独立。邻帧共享对象、背景和采集条件，模型可能利用近重复证据，得到的更接近已见场景插值。应先明确目标是新帧、新视频还是新地点，再以对应身份分组。字节摘要只检查特定编码内容，不能代替视频或对象谱系。若缺少来源元数据，应报告限制并补审查，不能把文件数量当作独立来源数量。

<a id="cv-4-detail-43"></a>
### 9.2 连通分量为什么有时必要

**问题：** 甲乙同对象，乙丙同内容别名，甲丙没有直接记录，可以分到两边吗？

**解析：** 若两种关系都被定义为不可跨角色，则应取传递闭包，三者属于同一连通分量。仅检查直接相同字段可能漏掉组合路径。关键仍是关系语义，不能把所有同相机样本无条件连在一起，除非目标确实要求相机隔离。算法只执行政策，不能替研究者决定独立单位；错误的边定义可能让整个库被无意义地并成一组。

<a id="cv-4-detail-44"></a>
### 9.3 同对象不同标签是否必为错标

**问题：** 同一对象两次图像标签不同，是否应直接改成多数标签？

**解析：** 先检查任务和时间。静态类别通常应一致，病程、工况或故障状态却可能真实改变。还要排查身份别名、标签范围和证据可得性。多数票是某种裁决政策，不自动恢复真实事实；强行一致可能删除任务所需的变化。应保留复核依据与修订版本，并在所有比较系统上使用相同新规范，而不是只修模型错误的样本。

<a id="cv-4-detail-45"></a>
### 9.4 同机制验证满分为何不足

**问题：** 人工条纹图的验证准确率为一，能否确认模型依赖中心内容？

**解析：** 不能，因为训练和同机制验证中，中心与背景都预测标签，两种规则都能获得高分。需要额外干预或新机制区分。本章配对改变外围而保持中心及原纹理残差，全部像素模型从正确变为错误，才提供更直接依赖证据。它仍只针对这个已知渲染器，不能据此断言真实照片模型具有相同内部机制，更不能把验证满分当成条件外保证。

<a id="cv-4-detail-46"></a>
### 9.5 配对背景改变应该固定什么

**问题：** 换背景同时重新采样噪声，输出变化能全归背景吗？

**解析：** 不能，因为噪声和背景一起改变。应尽量固定原对象、定义标签的内容和其余随机因素，再操纵研究变量。本章通过加上背景亮度差保留原外围残差，并逐像素断言中心相同。真实抠图还可能产生边缘伪影，需要额外处理对照和自然背景验证。配对控制增加可解释性，却不让不现实的合成操作自动具有部署代表性。

<a id="cv-4-detail-47"></a>
### 9.6 中心模型满分能否推荐永久裁中心

**问题：** 中心模型在背景翻转下保持一，是否应所有视觉任务都中心裁剪？

**解析：** 该结果依赖人工任务规定目标总在中心且中心足以确定标签。真实对象可能偏移、被裁断，任务也可能需要场景信息。裁剪改变可见信息与任务范围，应检查目标覆盖和位置分布。它可以作为隔离背景线索的受控对照，却不是无条件产品建议。采用前还要评价原始质量、边缘对象、资源与失去的上下文证据。

<a id="cv-4-detail-48"></a>
### 9.7 背景混训是否增加独立对象

**问题：** 二百四十原图再加二百四十翻转背景图，能说有四百八十独立对象吗？

**解析：** 不能，它增加了训练曝光和变化支持，但同一原图的版本仍共享中心和身份。统计单位仍需保留原对象分组，划分应在生成这些副本之前完成。比较效率时，额外曝光和计算也要记录。若只匹配轮数，新方案每轮处理更多输入，收益混合了变换政策与资源；应根据研究问题控制更新、时间或样本曝光并说明剩余差异。

<a id="cv-4-detail-49"></a>
### 9.8 总体提高为何小目标可能退化

**问题：** 总准确率从零点九六二到零点九八六，小目标从零点八到零点六，矛盾吗？

**解析：** 不矛盾，困难小目标占比从十分之一变成百分之一，组成变化足以掩盖组内退化。按旧组成标准化，新版本约为零点九五零九，反而更低。应同时报告组支持、组内质量和总体，明确参考权重。标准化是描述同组成比较，不自动给出因果解释；组定义、标签和支持必须可比，缺失组不能凭空补出质量。

<a id="cv-4-detail-50"></a>
### 9.9 两项总体分解是否唯一因果归因

**问题：** 用旧权重算组内效应、用新质量算组成效应，是否就是唯一真原因？

**解析：** 这是一个精确代数分解，换参考也能得到另一种同样精确的表达。它说明总体数字如何由条件质量与比例构成，不能单凭代数证明造成变化的现实机制。若新来源同时改变标签、难度和采样，仍需独立信息解释。报告应给公式和基准，避免把一个方便分账的表达直接包装成已识别的因果效应。

<a id="cv-4-detail-51"></a>
### 9.10 百分之九十九像素准确率能说明前景好吗

**问题：** 前景只有百分之一，全背景预测获得百分之九十九准确率，能验收吗？

**解析：** 若目标是识别前景，这个结果没有完成核心任务，前景交集为零、IoU 为零。像素总体被背景主导，应增加前景、按类或按对象指标，并对应实际代价。不能因为一个常见指标很高就省略关键单位；也不能随意把所有指标混成平均总分。先定义任务需要找什么，再选择分母与聚合，才知道高分代表哪种能力。

<a id="cv-4-detail-52"></a>
### 9.11 平均 IoU 能直接换平均 Dice 吗

**问题：** 报告平均 IoU 零点五，是否可直接得到平均 Dice 三分之二？

**解析：** 逐项的非空比值满足非线性变换，但平均通常不与变换交换。两项 IoU 为零和一时，平均 Dice 是二分之一，而变换平均 IoU 得三分之二。还要检查空项和权重约定。只有对象、聚合与条件一致时才可做对应换算，不能跨逐图、全局像素和按类平均使用公式，遗漏这些条件会制造无法复核的数字。

<a id="cv-4-detail-53"></a>
### 9.12 裁剪后保留旧类别编号够吗

**问题：** 原图类别没有改，但唯一识别区域被裁掉，模型答错算普通鲁棒性失败吗？

**解析：** 任务可能已经不可判定，标签编号保留不等于语义条件保留。需要检查变换是否合法、关键证据是否仍在，并报告有效覆盖。检测与分割还要同步变换坐标和掩码。可把极端裁剪作为压力边界，但不能不加区分地与保持语义的普通变化混合，再把全部错误归因模型缺陷。输入证据丢失的问题无法靠模型恢复保证解决。

<a id="cv-4-detail-54"></a>
### 9.13 为什么不能统一用可见面积判定有效

**问题：** 保留一半前景就一定可以识别吗？

**解析：** 不一定，关键证据可能只占很小区域。某些类别保留大部分轮廓仍模糊，另一些少量特征足够。可见比例是可复算审计字段，不是普遍语义定理，应结合任务规则和必要人工核验。若人为筛除无效样本，要固定规则并报告数量与来源，避免只剩容易样本后误称模型改进；覆盖变化本身就是结果的一部分。

<a id="cv-4-detail-55"></a>
### 9.14 亮度增强为什么可能改变问题

**问题：** 加大亮度再截断到合法范围，为何不能始终要求标签不变？

**解析：** 截断可能把不同内容都映为相同全白输入，判别信息已消失。本章实验直接构造了这样的碰撞，后续模型无法从同一表示恢复两个不同标签。弱亮度变化在某任务中可能合法，极端强度却不一定。增强强度应来自任务范围并检查语义，不能因为函数名叫亮度调整，就把所有参数都当保真操作，训练与评价都需要这条边界。

<a id="cv-4-detail-56"></a>
### 9.15 多档扰动为何不能当独立样本

**问题：** 一百原图各生成十档噪声，是否有一千次独立风险观察？

**解析：** 它们共享原内容和可能的来源因素，不能当一千个新对象。可以记录强度曲线和配对变化，重采样时保留原对象整组；若对象又共享会话，需要更外层分组。更多变化提供敏感性证据，却不等于更多独立来源。把同一图复制更多次会让朴素区间变窄，但没有新增真实独立信息，正是审计应避免的虚假精确。

<a id="cv-4-detail-57"></a>
### 9.16 对抗攻击没找到错误是否证明安全

**问题：** 某次优化攻击失败，能否保证约束集合内都正确？

**解析：** 不能，攻击是有预算的搜索，可能停在局部或受实现影响。证明需要针对完整集合的相应认证条件，与一次经验搜索不同。还要区分常见随机损坏和自然来源变化，它们各有风险定义。报告攻击参数、预算和成功标准，只能支持所运行条件的经验结论；不能把没发现错误翻译成所有未来图像、所有扰动都可靠。

<a id="cv-4-detail-58"></a>
### 9.17 提高置信阈值为何风险反而升高

**问题：** 全体风险四分之一，接受高置信一半样本后风险二分之一，是否计算错误？

**解析：** 本章人工反例中最高置信的两个样本恰好错误，筛选保留了它们而排掉许多正确样本，所以条件风险上升。置信排序与真实错误的关系需要目标数据证据，尤其在来源变化下不能假设保持。评价必须同时报告覆盖和风险，零覆盖也不能记成零风险成功。阈值应在合法开发数据上选择，再独立确认，而不是看到测试后挑最有利点。

<a id="cv-4-detail-59"></a>
### 9.18 校准以后是否自动识别分布外

**问题：** 一个模型在旧测试校准良好，最高概率能否作为所有新输入的可靠性保证？

**解析：** 不能，校准是关于某总体及某些条件平均关系的性质，不自动迁移到新来源，也不保证每个子群或每个样本。模型可能在背景捷径上极其自信。需要新来源的质量、覆盖和事实标签证据，并独立定义分布外与拒答任务。把 softmax 变换称为置信并不会增加信息；无标签分数变化也无法唯一确定新域错误率。

<a id="cv-4-detail-60"></a>
### 9.19 三十个零错误为何上界仍接近一成

**问题：** 三十个独立同分布单位全部正确，为什么不能直接说风险为零？

**解析：** 有限样本可能偶然没有遇到失败。零错误概率为一减错误率的三十次方，反演百分之九十五单侧二项上界约为百分之九点五。这个数字不是说真实风险就是九点五，而是所述模型下证据仍容许的边界。若样本经过选择、来源不匹配或单位不独立，连这个解释都需重审。更多证据要来自合适的新单位，不是重复同一成功样本。

<a id="cv-4-detail-61"></a>
### 9.20 一千帧能代替三十来源吗

**问题：** 同一批三十来源共有一千帧，能直接用一千计算很低的零错误上界吗？

**解析：** 只有在相应独立同分布帧假设和目标确实合理时才有这种解释，不能忽略帧内相关。若目标事件是来源内至少一次失败，应按来源定义事件，得到来源级风险而不是帧风险。二者不能任意互换。应记录源身份与依赖结构，明确总体和事件，再选统计方法；数据表有一千行并不证明获得了一千份独立来源证据。

<a id="cv-4-detail-62"></a>
### 9.21 无标签漂移监测能识别什么

**问题：** 新设备特征分布变了，能否直接估算准确率下降十个百分点？

**解析：** 仅凭输入差异通常不行，标签关系未知，变化可能影响或不影响任务。可以报告漂移信号、受影响比例和需要复核的区域，但具体错误率需要标签或额外可验证假设。反过来，输入分布看似不变也不保证标签机制未改。监测是触发进一步证据收集的工具，不是无需真值的万能质量仪，结论必须与可观察信息相符。

<a id="cv-4-detail-63"></a>
### 9.22 主动复核样本能直接估计总体风险吗

**问题：** 只标注模型最不确定的图像，再用错误比例报告总体，哪里有问题？

**解析：** 这些样本经过选择，难度和总体不同，比例主要描述被挑中的区域。应保留代表性随机审查，或在已知抽样概率和正支持等条件下使用合理校正。主动标注可以服务训练和诊断，不自动服务无偏评价。还要注意评价者看到模型答案后的锚定效应，以及反馈延迟。样本怎样产生与有多少样本同样重要，不能在统计时省略选择过程。

<a id="cv-4-detail-64"></a>
### 9.23 更新后沿用旧报告为何不够

**问题：** 权重没改，只换了归一化和阈值，可以继续引用原测试吗？

**解析：** 完整函数和决策政策已经变化，旧结论不自动覆盖。需要新版本身份、接口回归、关键来源评价和适当独立确认。若变更来自查看旧测试，那批数据已参与开发，可以保留作回归集但要承认角色。版本不是只给权重命名，所有影响输入输出的状态都应追踪；多个版本最好的指标也不能拼成一个不存在的交付方案。

<a id="cv-4-detail-65"></a>
### 9.24 完整审计怎样避免成为形式清单

**问题：** 写满来源、指标和鲁棒性术语，为什么仍可能没有实际证据？

**解析：** 每个检查都应对应可观察对象、故障假设和实际结果。来源独立要有谱系或分组关系，标签合理要有规范与复核，鲁棒性要有合法变化和覆盖，风险要有适当统计单位，交付要能重建完整函数。缺失时明确未知与下一步，而不是勾一个通过。审计的完成标准是别人能复算、质疑和设计新实验，不是表格看起来项目齐全，更不是用术语代替真数据。

<a id="sec-8"></a>
<a id="cv-4-detail-66"></a>
## 10. 综合研究：为一个真实目标建立分层证据

<a id="sec-8-1"></a>
<a id="cv-4-detail-67"></a>
### 10.1 从部署问题提出可被否定的假设

选择一个明确目标，例如新设备上的工件缺陷识别，先定义标签、独立对象、来源、时间和输入可见范围。列出可能的背景、设备与采样捷径，画出采集、标注、变换和划分关系。先在人工机制上验证接口和分析方法，再在合法真实资料上检验目标来源。人工结果帮助隔离机制，真实资料帮助评估代表性，二者不能互相冒充。

在开发部分预先规定基线、干预集合、强度、主指标、重要分组、覆盖要求与预算。安排原始输入、配对合法变化、自然来源外以及不可判定压力边界几个不同角色，逐项保存身份和有效性。模型选择、阈值和适应策略只使用允许的信息。最后冻结系统和评价器，在未参与调整的证据上确认，同时保留全部支持数与失败结果，而不是只展示成功样例。

<a id="cv-4-detail-68"></a>
### 10.2 解释结果并留下真正的研究入口

若背景变化下退化，先检查前景是否保持、处理是否有伪影、普通处理是否也退化，再比较替代机制。若总体提高而重要群体下降，分解组成并报告取舍；若拒答改善质量，报告服务范围和人工成本；若零错误，说明独立单位与上界假设。每个结论都应标明是实测、人工算术还是尚待验证的解释，避免把一个图或一个分数无限外推。

最终交付包括清楚组织的正文、完整实验、评价约定、环境与证据边界，临时生成物按依赖清理。下一轮新增来源、改变标签或引入预训练，都使用新版本协议，说明额外信息和资源，并回归旧场景。一个成熟的学习项目不需要假装全部问题已经解决，而需要让问题、推导、实验和未知彼此连接，使求知欲可以沿着可检验的路径继续推进。
