## 1. 从现实场景到数组：模型究竟看见什么

<a id="cv1-detail-2"></a>

### 1.1 成像是测量过程，不是把物体原样放入文件

一张图像可以从连续辐射场、光学系统、传感器响应、曝光、量化与编码六个环节理解。物体反射的光先经过镜头和点扩散函数，传感器在有限面积与有限时间内积分，再经过增益、颜色响应和数值量化。计算机最终得到的是这些测量的离散近似，不是物体本身。相同物体在不同光照、距离、相机和压缩率下可以产生差别很大的数组；两个不同物体也可能因为遮挡与低分辨率产生相同数组。因此分类问题首先受可观察信息约束，不能把任何识别失败都归因于网络容量不够。

用简化表达式写出单个像素测量：

$$
x_{ijc}=Q\left(\int_{t_0}^{t_1}\int_{\Omega_{ij}}(h*L_c)(u,v,t)\,du\,dv\,dt+\epsilon_{ijc}\right).
$$

这里空间积分说明像素具有覆盖面积，时间积分说明运动模糊与曝光有关，卷积核表示光学模糊，噪声项表示测量误差，量化器将连续量变成有限数值。这个模型不是要求每个项目都反演物理过程，而是帮助定位可恢复与不可恢复的信息。已经饱和成纯白的高光通常不能由简单归一化恢复；物体只剩一个像素时，放大图像也不会凭空产生可验证的纹理。

训练样本还包含选择机制。哪些场景被拍摄、哪些图像被上传、哪些疑难样本被删除，会改变模型所见的数据分布。若训练集只收录晴天正面图，验证集同样如此，即使分类准确率很高，也没有检验阴雨、侧面和遮挡条件。把数据来源写进问题定义，往往比继续堆叠卷积层更能解释部署后的落差。

<a id="cv1-detail-3"></a>

### 1.2 数值范围、颜色编码与线性光强

八位彩色文件经常用零到二百五十五的整数存储颜色，但除以二百五十五只改变量程，不等于把非线性编码恢复为线性光强。以常见的标准颜色编码为例，归一化通道值与线性亮度之间存在分段非线性关系。因此直接在编码值上取平均，与先解码到线性光强再取平均，得到的中间灰可能不同。普通分类预处理应遵循预训练约定；需要模拟真实曝光叠加或光照混合时，则必须明确在哪个空间计算。

对归一化编码值为零与一的两端做平均，编码均值为零点五；在线性光强中平均后再编码，数值会明显高于零点五。这个差别提醒我们：看起来同样叫亮度变化，乘像素、加像素和改变曝光并不完全相同。不要把某个库提供的颜色扰动直接解释成真实相机的物理模型，也不要用训练时的数值随机化替代真实域外光照测试。

通道标准化写成 $z_c=(x_c-\mu_c)/\sigma_c$。均值和标准差来自哪里必须说明：若使用固定预训练常数，常数是既定模型接口的一部分；若从项目数据估计，应只使用训练部分。验证集与测试集的像素即便没有标签，参与统计也可能改变真实部署时可获得的信息条件。是否允许这种无监督适应，需要在实验协议中预先定义，而不是因为没用标签就自动认为没有泄漏。

<a id="sec-1-1"></a>

<a id="cv1-detail-4"></a>

### 1.3 轴顺序和内存排列：追踪一个像素

图像逻辑布局常写为高、宽、通道，卷积批次常写为批量、通道、高、宽。设一张两行三列三通道小图，第一行第二列的三个通道是十、二十、三十。布局变换后，这三个数仍必须出现在同一空间位置，只是通道轴移到最前面。转置或置换表达轴的语义转换，重塑只表达按存储次序重新解释形状；形状相同不代表物理含义相同。

在输入检查中挑选三个哨兵像素，比只打印最大最小值更有效。分别选左上、右下与中间带有不同通道值的位置，追踪解码、通道转换、转置、缩放、标准化各阶段。若模型期待红绿蓝但读取器返回蓝绿红，图像尺寸和数据类型全部正确也可能失效。若图像先以整数除法缩放，大部分像素还可能变成零；若已经除过一次又除一次，输入动态范围会缩小两个数量级。

可视化要检查模型实际输入的逆变换，而不只是磁盘原图。逆变换时先乘标准差、再加均值，恢复通道顺序后才能显示。裁剪到可显示区间只应服务展示，不应掩盖训练数据中异常的大值。对异常值应记录数量和来源，分清合法高动态范围、错误量程和损坏数据。

<a id="cv1-detail-5"></a>

### 1.4 采样、混叠与缩小图像的损失

连续信号的频率高于新采样网格所能表示的范围时，直接降采样会把高频伪装成低频，这就是混叠。黑白棋盘格每隔一个像素抽取一次，可能全部变黑或全部变白；原图平均亮度相同，采样相位却决定结果。先低通再降采样可以减小这种相位敏感性，但也会削弱真正的小纹理，因此抗混叠不是无代价的准确率开关。

对于宽度只有两像素的细裂纹，四倍缩小后可能没有任何中心采样点落在裂纹上。若先平均，裂纹会变成弱灰度信号，仍可能被压缩与噪声淹没。解决路线包括提高输入分辨率、分块处理、调整成像距离或重新定义可检出对象尺寸。不能仅把小图放大并宣称恢复了细节，也不能把大目标任务中有效的缩放策略直接迁移到微小缺陷。

<a id="deep-dive-1"></a>

<a id="cv1-detail-6"></a>

### 1.5 表示改变的是整个学习问题

预处理是预测函数的一部分。完整预测可以记为 $F(x)=h_\theta(T(x))$，其中解码和量程转换也属于变换。若训练使用中央裁剪、部署使用拉伸，两个流程即使加载相同权重，也不是同一个函数。拉伸可能改变物体长宽比，裁剪可能删除对象，填充可能引入边界线索。选择哪种策略，要结合类别定义、目标位置和相机视场，而非只满足网络要求的固定尺寸。

变换还改变任务中的有效观察范围。整图分类回答画面里是否具有某种属性，目标裁剪分类回答已定位对象属于哪类，两者可用的信息不同。若训练时使用人工精确裁剪、部署时只得到有误差的检测框，应显式评估定位误差如何传到分类结果。把人工裁剪测试准确率直接当成端到端系统准确率，忽略了最容易出错的前置步骤。

## 2. 分类目标、损失与概率解释

<a id="sec-2-1"></a>

<a id="cv1-detail-8"></a>

### 2.1 单标签、多标签和开放类别

单标签互斥分类的目标是一个类别索引，输出向量经归一化后总和为一。例如图像已经由标注规范确定为猫或狗中的一种，单标签形式合理。多标签分类的每个输出对应一个可以同时成立的事件，一张图同时包含猫和狗并不矛盾，此时通常分别估计各类别的二元边缘概率，并使用逐类损失。这里的“分别”不要求真实标签统计独立；只有把各边缘概率相乘来解释联合事件概率时，才引入相应的条件独立模型假设。两个任务的输出维度可以相同，但概率约束、标签格式和评价单位不同，不能仅靠把阈值调低相互转换。

现实中还存在未知类、不可判定和不可见。已知类别内部的最大归一化概率再高，也不证明输入属于已知类。一个只见过猫狗的模型必须在猫狗之间分配概率，即使输入是一辆卡车。增加拒绝规则需要用独立验证样本、代价函数和覆盖率定义检验，不能把最大概率直接当成可靠的未知类检测器。类别层级也应说明：小狗与动物可能具有包含关系，不能既把它们当互斥平级标签，又要求模型同时输出两者。

<a id="cv1-detail-9"></a>

### 2.2 交叉熵为什么对 logits 求导很简单

对互斥类别，设分数为 $z_k$，概率 $p_k=\exp(z_k)/\sum_j\exp(z_j)$，目标分布为 $q$。损失为 $-\sum_kq_k\log p_k$。在目标非负且和为一时，展开归一化项并求导得到 $\partial\ell/\partial z_k=p_k-q_k$。这个形式解释了错误类别概率过高时为何受到正梯度、正确类别概率过低时为何受到负梯度。目标若不是合法分布，这个导数的简化条件就不成立。

稳定计算应从原始分数计算对数归一化，使用减去最大值等价式避免指数溢出。先手工归一化再把概率传给期望 logits 的接口，相当于重复施加归一化，会改变损失与梯度。多标签任务的稳定二元损失则可以写成 $\max(z,0)-zy+\log(1+\exp(-|z|))$；每个类别的事件并不共享一个总和为一的限制。

标签平滑将单点目标与某个参考分布混合，缓和对极端分数的鼓励，但它不会修复错误类别定义。若两类之间存在严格方向区别，把标签变得柔和也不能使水平翻转自动合法。混合图像和混合标签同样是训练目标假设，需要通过任务证据检验，而不是因为软标签在数学上可输入，就认为混合后的图像有真实的类别概率解释。

<a id="cv1-detail-10"></a>

### 2.3 权重、采样和先验改变

类别权重改变训练目标中各类的相对贡献，重采样改变训练时看到的类别频率，两者可能产生相似的期望梯度，却不保证具有相同的方差、归一化和运行统计。若先把稀有类采样概率放大，又乘逆频率权重，可能重复强调同一类别。权重设置应与真实错误代价或希望平衡的评价单位对应，并在报告中写清楚。

在一个理想化二分类条件下，对正类乘权重 $a$、负类乘权重 $b$，加权损失的最优输出为 $p_w=ap/(ap+b(1-p))$。它一般不等于原始总体中的事件概率 $p$。如果这些条件成立，可以用代数关系恢复原先验概率；若模型受限、数据选择复杂或存在条件分布变化，这个简单修正不保证有效。需要概率用于风险排序时，应独立检验校准，不要把训练时的加权概率直接解释成现实发生率。

<a id="cv1-detail-11"></a>

### 2.4 从分类准确率到可行动决策

零一错误最小化在等代价条件下选择最大后验类别；当漏掉缺陷比误报昂贵时，最优动作依赖代价矩阵。二分类中，若正确决策代价为零，假阳性代价为 $c_{FP}$、假阴性代价为 $c_{FN}$，选择正类的阈值是 $c_{FP}/(c_{FP}+c_{FN})$，前提是概率对应目标总体且代价固定。这个结论来自比较两种动作的条件期望代价，不是所有任务都默认用二分之一阈值。

阈值应在验证数据上确定，然后固定用于测试。若边看测试错误边调整阈值，最终数字包含人为适配测试集的收益。类别少样本时还应给出样本数和区间，避免把一次正确率上升解释成稳定改善。对同一对象多张照片，先决定是逐照片决策还是汇总为一次对象决策，否则重复拍摄多的对象会主导总体准确率。

## 3. 增强的数学假设与标注同步

<a id="cv1-detail-13"></a>

### 3.1 不变性、等变性与任务对称性

分类中常希望 $f(gx)=f(x)$，检测或分割中则通常需要 $f(gx)=\rho_g f(x)$，即输出按相应坐标规则变化。前者是不变性，后者是等变性。输入翻转后框也翻转，是保持任务一致的等变关系；把框坐标原封不动保留，是制造错误监督。旋转使六变九时，输入变换还会改变类别，因此既不能固定标签，也不能简单把这种变换视为噪声。

增强训练近似优化 $\mathbb E_{(x,y)}\mathbb E_g\ell(f(gx),\rho_gy)$。这不仅增加样本数量，还改变了学习目标的分布权重。若某种变换在现实中极少发生，却在训练中占一半，模型会被迫牺牲部分原分布精度来适应它。是否值得取决于测试分布与任务代价，不能只用“增强越强越好”的口号解释。

<a id="sec-6"></a>

<a id="cv1-detail-14"></a>

### 3.2 变换集合为何不一定构成群

左右翻转具有可逆性，连续平移在无限平面上可以组合为群作用；裁剪、缩小和随机擦除通常不可逆，不能把所有增强都严格称为对称群。群平均可以在适当条件下构造不变函数，但对删除关键信息的裁剪进行平均，可能把有判别信息的输入与无信息输入硬性绑定。理解可逆与不可逆的差别，有助于分清几何对称与信息破坏。

例如标签是图像右上角是否有红点，随机裁掉右上角之后仍继承原标签，会出现同样的纯背景同时配正负标签。此时目标条件分布发生变化，训练损失不可能靠无限容量降为零。应限制裁剪条件、重算标签或把问题改为可见区域标签；选择取决于标注语义。不要将监督冲突误诊为优化器不够强。

<a id="sec-6-1"></a>

<a id="cv1-detail-15"></a>

### 3.3 一个几何变换必须共享同一次随机参数

图像、框、实例掩码与关键点应使用同一次采样的几何变换，颜色变换则通常只作用于图像。连续边界坐标采用半开框 $[x_1,x_2)\times[y_1,y_2)$ 时，宽度为 $x_2-x_1$。水平翻转后的横坐标为 $[W-x_2,W-x_1)$。像素中心索引的翻转为 $j'=W-1-j$，两个公式针对不同对象，不能互相拼接。

裁剪先减去裁剪原点，再与新视野求交，移除空框，并根据可见比例与标注政策决定保留哪些目标。分割标签是类别编号，连续插值可能产生不存在的中间编号；最近邻保留离散取值，但坐标对齐规则仍需核查。边界坐标、像素中心与插值采样点应各自定义，不能把尺寸对齐当成空间对齐已经证明。

<a id="cv1-detail-16"></a>

### 3.4 颜色、混合与遮挡增强的边界

颜色是干扰还是语义，取决于任务。识别汽车类别时适度颜色变化可能保持标签，识别红绿交通灯时则可能改变标签；组织染色与植物病害也可能依赖颜色变化。合理做法是写出哪些变化在真实任务中允许，再做小规模人工审核和分组实验，而不是因为某一公开基准使用了颜色扰动就照搬。

混合两个样本的像素与标签，等价于约束模型在所选路径上具有某种平滑行为，并不要求混合图像真的属于两类按比例组成的现实场景。区域替换时以像素面积作为标签比例，隐含判别证据与面积有关；若小区域恰好包含全部对象，大背景面积不能代表类别贡献。更稳妥的研究是比较面积比例、对象可见比例和标签重算，并分别报告对小目标的影响。

<a id="cv1-detail-17"></a>

### 3.5 测试时增强必须计入计算与融合规则

多裁剪、翻转预测平均可以降低对特定采样方式的敏感性，但增加推理成本，并不保证任何单张输入都改善。平均 logits 与平均概率是两个不同算子，前者受分数尺度影响，后者直接组合归一化分布；检测还涉及坐标逆变换与重复合并。比较时应同时报告单视图结果与总推理预算，不能把多次运行的收益全部归给模型架构。

如果方向会改变类别，融合前必须先把类别映射回原坐标语义；否则两次高置信预测可能因为标签索引未转换而相互抵消。验证阶段可以用于选择变换集合与融合规则，测试阶段只执行固定规则。对每个测试图像尝试多种增强后挑正确结果，是使用标签进行选择，不属于合法的测试时增强。

<a id="cv1-detail-18"></a>

## 4. 迁移学习：迁移的是什么，哪些状态会变化

<a id="cv1-detail-19"></a>

### 4.1 特征迁移、线性探针与端到端微调

预训练骨干把输入映射为表示 $\phi(x)$，新任务头计算 $W\phi(x)+b$。固定骨干只训练头部，测量的是当前表示对新标签的可分性；允许骨干更新，则同时改变表示和分类边界。线性探针便于控制训练成本和排查数据接口，但探针差不证明所有信息都不存在，可能是相关信息以非线性形式编码。探针好也不证明表示完全依赖对象语义，因为背景捷径同样可以线性可分。

微调的潜在收益来自新任务允许修正不合适的特征，风险来自小数据过拟合、破坏原来有用的表示以及训练分布偏离部署分布。常见策略是先训练新头，再逐步解冻高层，用较小的骨干学习率适应。但策略顺序不是定理，何时解冻、使用多少轮与是否早停都应以训练内验证选择，并和合理的从零训练基线比较。

预训练与从零模型的公平比较不止匹配网络结构，还涉及额外数据、训练轮数与搜索预算。预训练模型拥有外部信息，这是迁移能力的来源，也应如实报告。若目标测试图像曾出现在预训练集合，甚至可能存在直接记忆，不能用“没有在本项目训练过”排除污染。公开权重的来源与去重能力不足时，应承认边界并通过新来源数据补充检验。

<a id="cv1-detail-20"></a>

### 4.2 冻结参数不等于冻结所有状态

参数的梯度开关只控制是否计算参数梯度，不自动切换归一化层与随机失活层的行为。批归一化含运行均值与方差等缓冲状态，训练模式下即使所有可学习参数都冻结，运行统计也可能变化。若目标是固定特征提取，应明确骨干的评估模式；若有意重估统计，则属于另一种适应策略，需要单独记录。

把整个模型切到训练模式后，再把骨干切到评估模式，可以让头部训练而骨干保持固定推理行为；也可以在训练循环内明确控制各部分模式。每次再次调用全模型训练模式都会递归影响子模块，因此状态设置应与训练循环组织一致。验证时关闭梯度记录与切换评估模式负责不同事情，二者不能互相代替。

冻结后的参数不应继续被错误的优化器更新。优化器参数组、学习率、权重衰减和动量状态要与当前可训练集合一致。中途解冻时需要将新参数纳入优化器或重建合适的参数组；只把梯度开关打开而优化器仍只含头部参数，骨干即使获得非零梯度也不会改变。检查参数前后差值比只看梯度是否存在更直接。

<a id="cv1-detail-21"></a>

### 4.3 表示缓存的收益与失效条件

当骨干固定、输入处理固定、模型处于确定的评估模式时，可以预先计算特征并重复训练头部，降低搜索成本。缓存需要记录骨干权重版本、解码与归一化规则、图像身份、裁剪方式和特征层位置。任何一个条件改变，缓存的特征都可能不再对应当前学习问题。简单使用文件名作为键，无法区分图像内容替换或预处理版本更新。

随机增强与缓存之间有明确取舍。每张图只缓存一个特征，训练头部看不到每轮重新采样的增强；缓存多个视图则定义了有限视图经验分布，并增加存储。先用所有数据拟合白化或降维再缓存，也可能把验证信息融入表示。每折依赖训练数据估计的变换必须在对应训练折拟合，而不是因为骨干固定就允许把全部步骤提前统一完成。

<a id="cv1-detail-22"></a>

### 4.4 微调可以用局部线性化理解

在初始权重附近写出 $f_{\theta+\Delta}(x)\approx f_\theta(x)+J_\theta(x)\Delta$。线性探针只允许最后一层方向变化，微调允许沿更多参数方向改变输出。这些方向可能包含修正域偏移所需的特征，也可能包含拟合噪声的自由度。小学习率和有限训练时间可以约束变化范围，但它们不能保证模型一定保留语义或防止遗忘。

若新旧任务在低层边缘统计上相近而高层类别不同，解冻高层可能足够；若图像来自不同传感器、不同谱段或不同动态范围，低层也可能需要适应。这是可检验假设，而不是由“早期层总是通用”推导出的普遍结论。应比较冻结、部分解冻、完全微调，并同时看训练误差、组外误差、参数漂移与成本。

## 5. 观察范围、数据划分与误差诊断

<a id="cv1-detail-24"></a>

### 5.1 标签针对画面、对象还是拍摄事件

假设同一工件拍了十张照片，标注为是否存在划痕。如果工件有划痕，但某一角度完全看不见，图像级标签仍设为阳性，就会把不可见信息作为监督。模型可能转而学习工件编号、台面纹理或拍摄批次。需要分清物理对象标签与当前图像可见标签，必要时增加可见性标记或采用多视图对象级模型。

标签分歧不一定是低质量标注员造成的，也可能来自类别边界模糊或观察范围不足。建立标注指南时，应包含正反例、边界例、不可判定规则和复审机制。把所有不可判定样本删除会让测试集变容易，因此还应报告筛除比例和实际工作流中这些样本如何处理。拒绝输出可以是合法动作，但必须计算覆盖率与剩余错误代价。

<a id="cv1-detail-25"></a>

### 5.2 划分单位由部署对象决定

随机分图片只在新图片足以近似独立部署样本时合理。同一视频相邻帧、同一人的不同角度、同一设备连续拍摄具有相关性，应按视频、个体或设备分组。如果目标是未来时段，还需要时间外推测试；如果目标是新医院或新工厂，应考虑来源外推。一次划分不能同时证明所有泛化方向。

组内图片数量不等时，逐图准确率和逐组准确率回答不同问题。前者对应随机请求，后者可以对应随机新对象；一个拍了一千张的容易对象会主导逐图结果，却在逐组平均中只占一个权重。先根据应用选主指标，再提供另一种作为补充，不要看到哪种指标更高就临时更换主要报告方式。

<a id="cv1-detail-26"></a>

### 5.3 从混淆矩阵分解可改进的错误

总体错误可以按类别、对象尺寸、遮挡、来源、拍摄距离和亮度分层，但切片越多越容易偶然发现极端结果。应预先指定关键切片，探索性切片明确标记，并在独立样本中确认。每个切片至少报告分母，只有两个样本的百分之五十与两千样本的百分之五十，证据强度明显不同。

错误分析要区分信息缺失、标签问题、预处理错误、表示不足与决策阈值不合适。图像中根本看不到缺陷时，增加模型深度没有依据；通道顺序错时，训练更久可能只是适应错误接口；类别概率排序不错但阈值不匹配代价时，重新训练全部模型也可能不是最高效的修正。为每种解释设计能区分原因的小实验，比笼统地说模型不够鲁棒更有价值。

<a id="cv1-detail-27"></a>

### 5.4 解释图能提出假设，不能自动证明机制

对特征图作加权组合可以显示哪些空间位置与当前分数相关。例如使用全局平均池化和线性头时，类别分数可展开为空间位置上通道权重加和，因此得到一种自然的类别激活图。这个代数关系解释的是特定模型的分数贡献结构，不直接给出真实因果机制。非线性后处理、分辨率限制与背景相关性都可能影响解释。

若热图集中在背景，值得进一步做背景替换、对象遮挡与来源外推实验；若集中在对象，也不能排除使用了对象上的水印或标注痕迹。遮挡试验同样可能制造分布外边界，因此应比较多个干预方式，并保留未干预对照。解释的用途是提出可检验假设，证据强弱取决于后续干预和任务约束。

<a id="cv1-detail-28"></a>

## 6. 三个可独立运行的 CPU 实验

<a id="cv1-detail-29"></a>

### 6.1 实验一：轴、量程、混叠与几何同步

下面只依赖数组库。第一部分用唯一值追踪通道与空间，证明相同形状的错误重塑并不保持像素身份；第二部分用棋盘格证明直接抽样受采样相位影响；第三部分用半开框与布尔掩码验证水平翻转的坐标关系。每个断言都有明确的数学预期，程序运行成功只能证明这些局部契约，不代表真实图像解码器也已经被验证。

```python
import numpy as np

image = np.arange(2 * 3 * 3).reshape(2, 3, 3)
chw = image.transpose(2, 0, 1)
assert np.array_equal(chw[:, 0, 1], image[0, 1, :])
wrong = image.reshape(3, 2, 3)
assert not np.array_equal(wrong, chw)
unit = image.astype(np.float64) / 255.0
mean = np.array([0.2, 0.3, 0.4])[:, None, None]
std = np.array([0.1, 0.2, 0.3])[:, None, None]
z = (unit.transpose(2, 0, 1) - mean) / std
restored = (z * std + mean).transpose(1, 2, 0)
assert np.allclose(restored, unit)

grid = np.indices((8, 8)).sum(axis=0) % 2
phase0 = grid[::2, ::2]
phase1 = grid[::2, 1::2]
assert np.all(phase0 == 0) and np.all(phase1 == 1)
averaged = grid.reshape(4, 2, 4, 2).mean(axis=(1, 3))
assert np.allclose(averaged, 0.5)

height, width = 6, 10
box = np.array([2, 1, 6, 4])
mask = np.zeros((height, width), dtype=bool)
mask[box[1]:box[3], box[0]:box[2]] = True
flipped = mask[:, ::-1]
yy, xx = np.where(flipped)
recovered = np.array([xx.min(), yy.min(), xx.max()+1, yy.max()+1])
expected = np.array([width-box[2], box[1], width-box[0], box[3]])
assert np.array_equal(recovered, expected)
assert flipped.sum() == mask.sum() == 12
print('layout, aliasing, box-mask synchronization passed')
```

这个实验也揭示为什么“看图正常”不是充分检查。错误重塑得到的张量仍有合法尺寸和有限数值，若接入网络，程序未必报错。棋盘格的两个相位结果则说明数据增强中的一像素位移可能改变低分辨率输入的统计。若模型对这种位移很敏感，应同时检查采样策略与模型结构，而不是直接将全部问题归于分类头。

<a id="cv1-detail-30"></a>

### 6.2 实验二：损失梯度、软标签与代价阈值

本段使用双精度张量，对两个目标分布检查解析梯度。分数很大时仍要求损失有限，说明接口从 logits 做稳定运算。多标签例子则允许两个正类概率同时接近一。最后的代价计算使用已知真实概率，验证最优动作阈值与零一准确率阈值的差别；现实应用中的概率还需要校准，不能把这里的已知概率假设省略。

```python
import torch
import torch.nn.functional as F

torch.set_num_threads(1)
z = torch.tensor([[4.0, -2.0, 1.0]], dtype=torch.float64,
                 requires_grad=True)
q = torch.tensor([[0.8, 0.1, 0.1]], dtype=torch.float64)
loss = F.cross_entropy(z, q)
loss.backward()
assert torch.allclose(z.grad, z.detach().softmax(1)-q, atol=1e-12)
extreme = torch.tensor([[1000.0, -1000.0]], dtype=torch.float64)
assert torch.isfinite(F.cross_entropy(extreme, torch.tensor([1])))

multi_z = torch.tensor([[8.0, 8.0, -8.0]], dtype=torch.float64,
                       requires_grad=True)
multi_y = torch.tensor([[1.0, 1.0, 0.0]], dtype=torch.float64)
F.binary_cross_entropy_with_logits(multi_z, multi_y).backward()
assert torch.allclose(multi_z.grad,
                      (multi_z.detach().sigmoid()-multi_y)/3)
assert bool((multi_z.detach().sigmoid()[0, :2] > 0.99).all())
assert abs(float(multi_z.detach().softmax(1)[0, 0])-0.5) < 1e-6

p, c_fp, c_fn = 0.2, 1.0, 9.0
threshold = c_fp / (c_fp+c_fn)
risk_positive = c_fp*(1-p)
risk_negative = c_fn*p
assert p > threshold and risk_positive < risk_negative
assert p < 0.5
print('gradient and decision contracts passed', float(loss.detach()))
```

不要将最后一段解释为降低阈值总能提高业务价值。只有当概率、代价和部署总体的假设合适时，解析阈值才直接适用。若正类概率被加权训练或过采样改变，先要说明输出对应什么分布。若人工复核能力有限，还要增加资源约束；固定百分比的最高风险样本送审，与统一概率阈值属于不同决策问题。

<a id="cv1-detail-31"></a>

### 6.3 实验三：冻结骨干与冻结运行统计

下面在内存中构造小网络，不下载预训练权重，因此它不是验证任何公开视觉模型的迁移效果。它专门检验工程状态：可学习参数全部冻结后，训练模式的归一化运行均值仍变化；切到评估模式后运行均值保持；给固定特征训练线性头可以降低一个人为可分任务的损失。数据与标签直接由固定特征构造，降低损失属于接口和优化的阳性对照。

```python
import torch
from torch import nn
import torch.nn.functional as F

torch.set_num_threads(1)
torch.manual_seed(31)
backbone = nn.Sequential(nn.Conv2d(3, 4, 3, padding=1),
                         nn.BatchNorm2d(4), nn.ReLU(),
                         nn.AdaptiveAvgPool2d(1), nn.Flatten())
for parameter in backbone.parameters():
    parameter.requires_grad_(False)
x = torch.randn(80, 3, 8, 8) + 2.0
backbone.train()
before = backbone[1].running_mean.clone()
with torch.no_grad():
    backbone(x)
assert not torch.equal(before, backbone[1].running_mean)
backbone.eval()
frozen_mean = backbone[1].running_mean.clone()
with torch.no_grad():
    features = backbone(x)
assert torch.equal(frozen_mean, backbone[1].running_mean)
score = features[:, 0]-features[:, 1]
y = (score > score.median()).long()
mu, sigma = features.mean(0), features.std(0).clamp_min(1e-6)
features = (features-mu)/sigma
head = nn.Linear(4, 2)
optimizer = torch.optim.Adam(head.parameters(), lr=0.05)
old_parameters = [p.detach().clone() for p in backbone.parameters()]
initial = float(F.cross_entropy(head(features), y).detach())
for _ in range(250):
    optimizer.zero_grad(set_to_none=True)
    loss = F.cross_entropy(head(features), y)
    loss.backward()
    optimizer.step()
final = float(F.cross_entropy(head(features), y).detach())
assert final < initial*0.4
assert all(torch.equal(old, new) for old, new in
           zip(old_parameters, backbone.parameters()))
assert all(p.grad is None for p in backbone.parameters())
assert torch.equal(frozen_mean, backbone[1].running_mean)
print('head loss', initial, final, 'backbone fixed')
```

若把循环中的模型改成真实预训练网络，还需增加输入约定、类别顺序、参数版本和来源划分。这个小实验没有测试新来源泛化，也没有比较不同微调策略，更没有证实随机骨干可以替代预训练骨干。它让读者在几秒内看清状态变化边界，再把同样的检查移到真实项目。

## 7. 方法比较与研究设计

<a id="cv1-detail-33"></a>

### 7.1 三种表征方案的适用条件

手工特征加线性模型具有明确的归纳偏置、低训练成本和易于构造的解释，但对复杂视角和纹理变化适应有限；卷积模型通过局部连接和共享参数处理空间结构，但边界、步幅和池化会影响细节；基于图像块的注意力模型可以表达远距离关系，同时受块划分、位置表示和训练数据量约束。比较时应把输入分辨率、外部数据、总训练预算与评价单位列成表，再解释性能差异。

模型参数少不必然推理快，算子实现、访存、输入尺寸和硬件都影响延迟。参数多也不等于必然更容易过拟合，因为优化、预训练和正则化共同决定实际行为。适合本项目的方案应在目标约束下比较：固定时延、固定内存、固定标注预算或固定训练成本分别产生不同的优胜者。

<a id="cv1-detail-34"></a>

### 7.2 设计一个能区分解释的消融实验

设某模型增加颜色增强后组外准确率提高。有至少三种解释：它减少了颜色捷径，它相当于一般正则化，或者验证样本刚好受益。可以增加只做几何增强、只做颜色增强、二者组合三组，固定划分、初始化种子集合与训练步数，同时评估颜色敏感和颜色不敏感类别。如果只看总准确率，无法区分对合法语义的破坏与对错误相关性的纠正。

还可以对同一对象生成成对的原背景与替换背景，计算每个对象的预测变化，再按对象重采样估计差值区间。这里的成对性降低不必要的对象差异，但替换背景如果引入明显合成边缘，又会形成新的分布外因素。应在多个替换方案和真实新背景中复核，避免从一个方便的人工干预跳到普遍因果结论。

<a id="cv1-detail-35"></a>

### 7.3 预注册主问题与保留探索空间

进阶研究不必把所有想法都压成一个主指标。可以先明确主要问题，例如在新设备上识别小缺陷是否改善，再指定主要比较、样本单位、阈值选择和排除规则。其他切片与解释图作为探索结果展示，并单独说明尚需独立验证。这样既保留好奇心，又避免把大量尝试中最漂亮的一项包装成唯一预期结果。

报告失败同样能增加知识。若微调仅降低训练损失而组外结果变差，应保留这个结果并检查参数漂移、数据量与域差异；若强增强损害方向类别，应分析标签对称条件；若高分辨率改善小目标但成本过高，应报告准确率与成本的权衡。充分解释边界，比把所有实验都写成成功故事更有学习价值。

<a id="cv1-detail-36"></a>

## 8. 进一步推导：信息、对称性和迁移风险

<a id="cv1-detail-37"></a>

### 8.1 不可逆变换的贝叶斯错误为什么可能增大

设原观察为随机变量 $X$，处理后为 $Z=T(X)$。任何只使用 $Z$ 的分类器，也都可以看作先从 $X$ 计算 $T$ 再分类，因此使用 $Z$ 的最优零一风险不会小于使用完整 $X$ 的最优风险。这个结论比较的是拥有无限适当决策能力的理想最优函数，不是在说实际有限数据网络不应降维。实际模型可能因删去干扰而更容易学习，所以有限样本测试误差可以下降，二者并不矛盾。

例如原图包含对象形状和相机水印，真实标签只由形状决定。理想分类器能够忽略水印，裁掉水印不会增加所需信息；有限模型却可能因为水印与标签在训练集高度相关而依赖它，裁剪反而改善组外泛化。相反，如果裁剪同时删除了辨别两类所需的细节，最优可达风险也会变差。区分信息上界与学习难度，能够避免把“更多像素总更好”与“删除信息总更好”都当成定律。

<a id="cv1-detail-38"></a>

### 8.2 有限变换集合的平均预测

如果有限集合确实形成群，定义 $\bar f(x)=|G|^{-1}\sum_{g\in G}f(gx)$，则对任意 $h\in G$，由于右乘 $h$ 只对群元素重新排列，有 $\bar f(hx)=\bar f(x)$。这里的不变性是代数保证，不依赖网络是否训练充分。但它保证的是输出对所选变换不变，不保证这些变换都保持真实标签，也不保证平均后的分类风险降低。

若真实任务中的左右方向有语义，强制翻转不变会把两个应区分的类别压到同一表示。若输出本身随变换改变，则平均前需要对输出施加逆作用，构造 $\rho_g^{-1}f(gx)$ 再平均。检测框、关键点或方向类别都属于这种情况。学习对称性之前先明确标签怎样变换，是把形式推导落到真实任务的关键。

<a id="cv1-detail-39"></a>

### 8.3 先验偏移修正的条件与局限

假设训练与部署的类条件图像分布相同，只有类别先验改变，则部署后验与训练后验满足 $p_t(y\mid x)\propto p_s(y\mid x)\pi_t(y)/\pi_s(y)$。推导来自贝叶斯公式，把相同的类条件密度消掉，再用部署先验替代训练先验。该关系要求训练后验有合理概率含义，先验比可估计，并且相关类别在训练中具有非零概率。

相机颜色响应变化、对象外观变化或标签定义变化通常不只是先验偏移，直接套用比例修正不能解决。若目标域正类图像更模糊，类条件分布已经改变；若标注将轻微缺陷从负类改为正类，条件标签机制也改变。应先陈述为何先验偏移近似可信，再用无标签目标数据或少量标注评估，不要从看到类别比例变化就认定全部问题都是先验偏移。

<a id="cv1-detail-40"></a>

### 8.4 冻结表示对线性探针的限制

设两幅图的固定表示完全相同，而标签相反，任何只读取这个表示的确定性头部都无法同时正确。即使换更复杂的头也无济于事，因为区分信息已经在表示中丢失。若表示只是线性不可分，非线性头部可能有帮助；若表示完全合并了不同标签，必须改变表示或输入。这个简单区分能指导诊断：增加分类头容量之前，先检查类间距离、最近邻冲突和表示退化。

但在高维表示里观察到近邻异类不自动证明不可分，距离度量、缩放和样本密度都会影响近邻。可以构造明确的控制样本，例如只改变任务相关的小标记，检查表示变化和输出变化。这个干预提供比随机查看降维散点更直接的证据。二维可视化用于提出假设，不能替代高维分类能力的定量评估。

<a id="cv1-detail-41"></a>

### 8.5 训练随机性与统计单位不能混为一谈

重复训练种子测量优化与初始化的不稳定，重复抽取测试对象测量有限测试样本的不确定，两者来源不同。只对一个固定测试集跑十个种子，不能代替新来源数据；对一套固定权重进行对象自助重采样，也不能反映重新训练时的不稳定。研究报告应明确区间条件于哪一层随机性，若资源允许，可以在多个训练种子下分别计算成对对象差值。

当一段视频有数百帧时，把所有帧当独立样本进行自助抽样会低估共享拍摄条件带来的相关性。按视频或对象抽取整组更符合泛化单位，但组数很少时区间仍可能不稳定。应该同时报告组数与帧数，并承认当前数据对新场景结论的限制。统计程序不能凭空补足只有几个来源的事实。

## 9. 二十道练习与详细答案

<a id="cv1-detail-43"></a>

### 9.1 两次归一化为什么不只是单位变化

**问题：** 网络要求输入在零到一之间，加载流程已经除以二百五十五，训练循环又除一次，会发生什么？

**解析：** 第二次除法使动态范围进一步缩小。若随后减去固定均值并除固定标准差，所有像素会聚集到接近负均值除标准差的位置，既改变均值也压低变化幅度。网络首层看到的分布与预训练条件明显不同。应追踪一个有已知数值的像素，检查每一步数据类型与量程；不能靠训练损失下降证明接口正确，因为网络可能花费容量重新适应错误接口。

<a id="cv1-detail-44"></a>

### 9.2 为什么重塑不等于换轴

**问题：** 高宽通道转换为通道高宽，元素个数相同，为什么不能直接重塑？

**解析：** 重塑保持线性元素顺序而重新分配索引，换轴保持每个元素所代表的空间位置与通道含义。给每个像素通道唯一编号后，换轴满足新数组的通道行列索引等于原数组的行列通道索引，重塑一般不满足。验证至少追踪不同位置的三个通道，不能仅比较形状或元素集合，因为错误重塑也完全保留元素集合。

<a id="cv1-detail-45"></a>

### 9.3 棋盘格缩小后的黑白结果是否矛盾

**问题：** 同一棋盘格从不同起点隔点抽样，为什么可以分别全黑和全白？

**解析：** 原信号频率超过新网格可分辨范围，采样相位决定读到哪一类像素。两种结果都是真实的抽样结果，却都不能代表原图的平均结构。先对每个二乘二区域平均可得到半灰，但同时丢失棋盘纹理。这说明抗混叠减少伪影并不等于保留全部信息。应结合任务需要选择分辨率，尤其不要在细裂纹任务中忽视高频证据。

<a id="cv1-detail-46"></a>

### 9.4 放大低分辨率图片是否恢复小目标

**问题：** 原图中一个目标缩小后消失，再放大四倍能否恢复？

**解析：** 若降采样已经把目标与背景映为同一个数值模式，插值无法知道原来是否有目标。放大只依据现存样本做平滑或重建，不提供缺失观测。学习式超分辨也可能产生符合训练先验的纹理，不能自动作为真实存在细节的证据。应从成像分辨率、分块或更近拍摄解决，并把最小可检测尺寸写入任务边界。

<a id="sec-7-1"></a>

<a id="cv1-detail-47"></a>

### 9.5 一张图同时有猫和狗怎样定义输出

**问题：** 能否使用两个互斥输出，把两类阈值都设得低一点？

**解析：** 互斥归一化迫使两类概率相加为一，无法表达两种事件都接近必然存在。应先决定是画面级多标签还是逐对象检测。多标签分别估计各事件的边缘概率，检测还需要位置和实例数量。仅调阈值最多改变动作，不能修复输出空间与标注语义的冲突。训练标签、损失和评价必须一同变更。

<a id="cv1-detail-48"></a>

### 9.6 高置信已知类预测能否排除未知类别

**问题：** 猫狗分类器对卡车输出百分之九十九的猫，是否违反概率归一化？

**解析：** 没有，归一化只保证在模型定义的类别之间分配总概率，不保证输入属于这些类别。需要未知类数据、拒绝机制和覆盖率评价来判断系统是否可靠。最大概率阈值可以作为候选规则，但必须独立验证其对未知与难例的区分能力。把置信度当成模型已经认识整个世界，是超出了训练目标的解释。

<a id="cv1-detail-49"></a>

### 9.7 颜色增强怎样破坏红绿灯任务

**问题：** 随机交换红绿通道后保留原标签，会引入什么问题？

**解析：** 变换可能把红灯证据变成绿灯证据，却保留红灯标签，从而产生监督冲突。若颜色决定类别，应限制变换到不会改变语义的范围，或同步重算标签，但后者还要求理解整个场景语义。增强是否合理由任务对称性决定，不由某个预处理函数是否流行决定。应对受影响类别单独审查增强样本与误差。

<a id="cv1-detail-50"></a>

### 9.8 水平翻转的两个公式如何统一

**问题：** 框用宽度减右边界，像素却用宽度减一再减索引，哪一个对？

**解析：** 两者描述的对象不同。连续边界半开区间的左右端点变换是 $[W-x_2,W-x_1)$，离散像素中心索引是 $W-1-j$。若框覆盖索引二到五，其边界是二到六；翻转后像素和边界关系仍一致。错误通常来自把闭区间整数框、半开边界框与中心坐标混用，因此数据接口必须明确约定。

<a id="cv1-detail-51"></a>

### 9.9 裁剪后只保留原框是否合理

**问题：** 从左侧裁掉一部分图像，只将框横坐标减去裁剪原点够吗？

**解析：** 不够，还需要与新图像视野求交，检查宽高是否为正，并根据可见比例与标签政策决定保留对象。框可能完全落在视野外，也可能只剩很小碎片。图像分类标签是否保留同样取决于对象是否仍可见。几何代码只能完成坐标转换，保留与忽略属于任务规则，二者应分别测试。

<a id="cv1-detail-52"></a>

### 9.10 冻结后验证表示为什么仍改变

**问题：** 所有骨干参数都不求梯度，同一输入的输出为什么仍可能变化？

**解析：** 批归一化运行统计可能在训练模式更新，随机失活也会让输出随机。参数冻结、模型模式和梯度上下文是三个不同开关。若希望固定特征，应设置合适的评估模式，并核对缓冲区与参数的前后差值。只检查优化器不含骨干参数，不能排除这些非参数状态改变。

<a id="cv1-detail-53"></a>

### 9.11 解冻参数但模型不更新的原因

**问题：** 骨干梯度非零，训练多个步骤后权重却完全相同，应先查什么？

**解析：** 先确认优化器参数组是否包含这些参数、学习率是否为零、是否误在前向后重新加载旧权重。解冻梯度开关不会自动把参数加入先前创建的优化器。对一个已知参数保存更新前副本，执行一步后比较差值，再检查梯度和参数组身份。排错应建立可观察的更新链条，而不是只依赖日志中的梯度范数。

<a id="cv1-detail-54"></a>

### 9.12 特征缓存什么时候必须重建

**问题：** 只改变输入归一化常数，骨干权重没变，旧缓存还能用吗？

**解析：** 不能默认可用，因为特征是骨干与预处理的组合输出。即使权重相同，输入分布与激活都会改变。缓存键应覆盖图像内容、变换版本、权重版本和抽取层；改变随机增强视图也改变缓存含义。只有证明变更不影响特征，或者明确把旧缓存作为另一种实验条件，才可继续复用。

<a id="cv1-detail-55"></a>

### 9.13 加权训练输出为何不是原始概率

**问题：** 正类权重九、负类权重一，真实正类概率十分之一，理想加权输出是多少？

**解析：** 代入加权最优概率，分子为零点九，分母为零点九加零点九，得到二分之一。模型输出变高不意味着现实事件发生率增高，而是训练目标改变了两类错误的相对权重。若用于概率解释，应说明修正条件并独立校准；若用于决策，也要避免在权重和阈值两个环节重复施加同一种代价偏好。

<a id="cv1-detail-56"></a>

### 9.14 为什么新对象划分优先于随机图片

**问题：** 每个对象拍一百张，随机图片划分准确率很高，能否说明新对象识别可靠？

**解析：** 不能，同一对象的纹理、背景与拍摄设置可能跨集合重复，测试只检验了已见对象的新视角。若部署目标是新对象，应让对象身份在训练和测试间不重叠。若同时关心新相机，需增加相机外推条件。泛化结论必须对应划分单位，而不是把任何保留的文件都叫独立测试。

<a id="cv1-detail-57"></a>

### 9.15 逐图和逐对象指标为什么不一样

**问题：** 对象甲有九十张且全对，对象乙有十张且全错，两个平均分别多少？

**解析：** 逐图准确率为百分之九十；逐对象先求各自准确率再平均，为二分之一。前者重视请求量，后者让两个对象权重相同。哪一个作为主指标由应用抽样方式决定，不能因为其中一个更高就事后选择。应同时给出对象数和图片数，帮助读者理解分母。

<a id="cv1-detail-58"></a>

### 9.16 热图落在对象上为何仍不够

**问题：** 热图一直覆盖对象，是否证明模型没有使用捷径？

**解析：** 对象上也可能存在水印、粘贴标签或生产批次符号，热图本身分辨率也可能不足。需要改变疑似线索而尽量保持对象语义，检查预测是否跟随线索变化，并结合真实新来源评价。遮挡可能引入人工边缘，所以应使用多种干预与对照。解释图提供研究方向，不能单独完成因果论证。

<a id="cv1-detail-59"></a>

### 9.17 增强平均为何不保证准确率提升

**问题：** 两个视图各自概率看似合理，平均后是否一定更准确？

**解析：** 不保证。如果某个变换破坏类别证据，它会向错误方向投票；即使都合法，有限模型的误差结构也可能使边界样本被平均到错误一侧。应在固定验证协议中选择融合方式，并报告额外成本。群平均的代数不变性与风险降低是两个命题，前者成立不能替代后者的实证检验。

<a id="cv1-detail-60"></a>

### 9.18 线性探针差是否意味着表示无信息

**问题：** 线性头准确率接近随机，能否直接丢弃骨干？

**解析：** 还应排除标签索引错位、预处理不匹配、优化失败与表示缩放问题。即使这些都正常，任务信息也可能需要非线性读取。可以增加受控非线性头、近邻和少样本过拟合测试。如果不同类别的表示已经完全相同，再复杂的头也无法恢复；关键在于区分读取受限和信息丢失。

<a id="cv1-detail-61"></a>

### 9.19 如何识别多次尝试后的偶然最优

**问题：** 搜索五十种增强后最好的一种高出一个百分点，下一步做什么？

**解析：** 最优结果经过了选择，不能把它看作预先固定的一次无偏比较。应保留搜索记录，在独立验证或新的测试来源上确认，并用多个训练种子评估稳定性。主要指标与关键切片应尽量预先指定。若没有新数据，应如实把结果标为探索性，不把微小差值写成确定改善。

<a id="cv1-detail-62"></a>

### 9.20 怎样验收一套完整分类交付物

**问题：** 一份权重文件加准确率数字是否足够复现预测？

**解析：** 不足。至少需要解码约定、通道顺序、量程、尺寸策略、归一化、类别索引、阈值、权重版本和推理模式，并提供固定输入的参考输出。还应说明训练和测试对象如何划分、外部预训练来源及适用边界。验收从原始图像进入流程到最终决策结束，逐阶段核对接口，才能发现同权重不同预处理造成的静默偏差。

<a id="cv1-detail-63"></a>

## 10. 综合研究任务与完成标准

<a id="cv1-detail-64"></a>

### 10.1 从可观察事实构造一份研究计划

选择一个包含对象身份与拍摄来源的分类问题，先写清楚标签针对图像还是物理对象，定义哪些因素应保持标签、哪些会改变标签。建立无增强的简单基线，再独立加入几何增强、颜色增强与迁移策略。每个实验只改变可以解释的因素，记录搜索预算和选择规则。若没有真实图像，可先用人工形状验证接口，但结论应停留在人工生成机制。

验收不仅看最终准确率，还检查类表是否一致、原始像素是否能追踪到模型输入、同一对象是否跨集合、随机状态是否记录、冻结参数与运行统计是否符合策略。对错误样本给出至少三种互相竞争的解释，并为每一种设计能推翻它的小实验。这样形成的是可继续研究的知识结构，而不是一串只能背诵的最佳实践。

<a id="cv1-detail-65"></a>

### 10.2 阅读下一章前应掌握的连接

分类给整张图一个或多个类别，检测进一步要求对象位置与数量，分割要求每个像素的类别或实例身份。前面讨论的输入量程、采样、标签不变性和来源划分仍然适用，但评价分母会从图片转为对象、像素或区域。下一章将从坐标、匹配与聚合出发说明为什么看似同名的准确率和平均精度不能直接比较。

真正掌握本章的标志，是能够解释一次预处理选择怎样改变可观察信息、一次增强怎样改变监督假设、一次冻结怎样影响参数与状态、一次划分怎样限制结论。遇到不符合预期的实验时，先沿这些条件逐项检查，再考虑增加模型复杂度。每个条件都能用具体输入、手算结果与断言落实，而不是停留在口头经验。
