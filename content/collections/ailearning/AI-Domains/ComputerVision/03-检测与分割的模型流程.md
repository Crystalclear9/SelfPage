## 1. 从输出对象反推整个系统

<a id="cv3-detail-2"></a>

### 1.1 分类、检测和分割不是只差最后一层

图像分类每张图通常输出一个类别分布，目标检测输出一个数量可变的对象集合，每个对象具有类别、位置和分数。语义分割输出与空间网格对应的类别分布，实例分割还需要区分同类的不同对象。输出对象的结构不同，会改变标签格式、组批方式、匹配、损失归约和评价，因此不能把检测理解为分类网络多输出四个数。

本章使用人工构造的框、特征和像素标签，逐步研究检测与分割流程，不训练真实检测器，也不声称获得任何数据集精度。所有代码只依赖 NumPy、SciPy 和 PyTorch CPU，不安装 torchvision，不下载模型与图片。局部机制可以被独立检查，但完整系统性能仍然需要真实数据、训练和独立评价。

一个系统可以拆成输入坐标变换、特征提取、多尺度处理、目标分配、输出预测、损失与更新、解码、后处理、反坐标变换和评价。任何一环不一致，都可能让网络输出看似合法却无法完成任务。比如框在缩放图上正确，却被当作原图坐标输出，最终错误属于接口链条，不是模型缺乏定位能力。

<a id="cv3-detail-3"></a>

### 1.2 先定义目标集合与像素网格

对第 $`i`$ 张图，检测标签可以写为 $`G_i=\{(b_j,c_j)\}_{j=1}^{m_i}`$，其中 $`m_i`$ 可以不同，也可以为零。框 $`b_j`$ 必须注明坐标格式与单位，类别 $`c_j`$ 必须关联类别字典。训练批次通常保留每张图的可变长标签列表，而不是强行把目标数量补成相同后忘记掩码。

语义分割标签可以写为高度乘宽度的整数网格，另有忽略区域。实例标签则包含对象身份，每个实例可以有一个二值掩码和类别。相邻的两个同类对象在语义图中可能具有完全相同的类别值，因此只凭语义图未必能恢复真实对象数量。连通域方法依赖额外假设，例如实例不接触，不能当作一般性的身份恢复算法。

输出结构还决定错误种类。检测会漏掉对象、重复预测、类别错误或定位不准；语义分割会有像素分类、区域覆盖和边界错误；实例分割还会发生合并与拆分错误。用一个总损失或一个像素准确率无法区分这些问题，必须保留与任务结构对应的中间证据。

## 2. 坐标契约是模型函数的一部分

<a id="sec-1-1"></a>

<a id="cv3-detail-5"></a>

### 2.1 连续框与像素索引必须分清

本章框使用连续坐标 $`(x_1,y_1,x_2,y_2)`$，面积为 $`(x_2-x_1)(y_2-y_1)`$，要求右下坐标严格大于左上坐标。它不采用离散端点包含式的加一面积公式。图像宽二百、高一百时，合法边界坐标可以到二百和一百；像素整数索引则分别只到一百九十九和九十九。边界位置与像素索引属于不同对象。

框也可以用中心宽高表示，中心为两端平均，宽高为两端差。两种格式可以互相转换，但不能在格式不明时直接比较四个数字。归一化框把横坐标除以宽、纵坐标除以高，使数值相对于图像尺寸表达；解码时必须使用与编码相同的尺寸与顺序，不能误把高宽交换。

同样的四维向量可能表示角点、中心尺寸、相对偏移或归一化值。形状检查发现不了语义错误。应在接口中明确命名，并用一两个可手算框验证。例如原图二百乘一百，框从横二十到六十、纵十到五十，缩小一半后应从横十到三十、纵五到二十五。这个不变量能直接暴露坐标次序和缩放因子错误。

<a id="cv3-detail-6"></a>

### 2.2 缩放、裁剪、填充和翻转的复合变换

若先等比例缩放，再在左侧和顶部填充，则坐标先乘缩放因子，再加相应偏移。反变换应按相反顺序先减填充再除缩放。若采用非等比例缩放，横纵需要不同因子，框宽高比例会变化。模型可能接受这种输入，但训练与推理必须采用一致规则，并理解它改变了物体几何。

裁剪需要减去裁剪原点，再把框裁到新图范围，随后处理退化框和被截目标。删除目标的规则会影响训练分布，例如只保留剩余面积比例超过阈值的目标。阈值应明确，不应因增强后框看起来不方便而静默丢弃。裁剪还可能留下无标注的对象残片，这些区域如何参与背景监督也需要任务规则。

水平翻转连续框时，新左边界为图宽减旧右边界，新右边界为图宽减旧左边界。直接分别用图宽减两个横坐标但不交换顺序，会得到负宽框。掩码必须同步翻转，关键点还可能需要交换左右语义。几何增强不是只变图像的视觉操作，而是对所有关联标签实施同一个几何变换。

<a id="cv3-detail-7"></a>

### 2.3 实验一：编码、缩放和反变换闭环

下面同时检查坐标缩放、裁剪平移、水平翻转与锚框编码解码。所有框均为人工构造，连续面积约定贯穿全程。编码的平移由锚框宽高归一化，尺度变化使用对数，解码是其明确逆函数。

```python
import numpy as np

box = np.array([20.,10.,60.,50.])
small = box * np.array([0.5,0.5,0.5,0.5])
assert np.allclose(small, [10,5,30,25])
shifted = small - np.array([5,0,5,0])
assert np.allclose(shifted, [5,5,25,25])
restored = (shifted + np.array([5,0,5,0])) / 0.5
assert np.allclose(restored, box)
flipped = np.array([200-box[2], box[1], 200-box[0], box[3]])
assert np.allclose(flipped, [140,10,180,50])

def center(b):
    assert b[2] > b[0] and b[3] > b[1]
    return np.array([(b[0]+b[2])/2,(b[1]+b[3])/2,b[2]-b[0],b[3]-b[1]])
def encode(anchor, target):
    a, g = center(anchor), center(target)
    return np.r_[(g[:2]-a[:2])/a[2:], np.log(g[2:]/a[2:])]
def decode(anchor, delta):
    a = center(anchor)
    c = a[:2] + delta[:2]*a[2:]
    size = a[2:]*np.exp(delta[2:])
    return np.r_[c-size/2,c+size/2]
anchor = np.array([0.,0.,20.,20.])
target = np.array([5.,2.,35.,22.])
delta = encode(anchor,target)
assert np.allclose(delta,[0.5,0.1,np.log(1.5),0])
assert np.allclose(decode(anchor,delta),target)
assert np.allclose(encode(anchor,anchor),np.zeros(4))
print(delta, decode(anchor,delta))
```

闭环通过证明本章两段函数在这些有效输入上一致，不证明任意真实增强管道都正确。实际工程还应检查空目标、边界框、极小框和图像高宽不同的情况。若只用正方形图测试，高宽交换可能完全不显形，故机制测试应刻意包含不对称尺寸。

## 3. 锚框与位置回归的推导

<a id="cv3-detail-9"></a>

### 3.1 为什么位置偏移要归一化

设锚框中心宽高为 $`(a_x,a_y,a_w,a_h)`$，目标为 $`(g_x,g_y,g_w,g_h)`$。常见编码为
$$
t_x=\frac{(g_x-a_x)}{a_w},\quad t_y=\frac{(g_y-a_y)}{a_h},\quad
t_w=\log(\frac{g_w}{a_w}),\quad t_h=\log(\frac{g_h}{a_h}).
$$
同样移动十像素，对宽十像素框意味着移动一整框，对宽一百像素框只意味着十分之一。按锚框尺度归一化，使偏移具有相对意义。对数宽高把乘法尺度变成加法，宽度扩大两倍和缩小两倍分别得到相反数。

解码时，预测中心为锚中心加预测偏移乘锚宽高，预测宽高为锚宽高乘指数尺度。指数保证正尺寸，但极大尺度分数可能造成数值溢出或巨大框，因此实际实现可能对尺度作限制。任何限制都属于解码规则，会影响梯度或推理边界，必须与训练实现核对。

某些实现还对四个编码分量加不同权重。那时解码必须先除以这些权重。不能把一种模型的回归头输出直接送进另一种模型的解码函数，即使二者都是四维向量。参数化是学习目标的一部分，不是可以随意交换的格式包装。

<a id="visual-depth-cv-box-chain"></a>

#### 图解：框回归的三层坐标链

![锚框几何编码解码及中心坐标梯度链](images/03-box-coordinate-chain.svg)

**先在左图验证几何。** 蓝色锚框为中心宽高 $`(4,4,4,2)`$，边界是 $`[2,6]\times[3,5]`$；橙色真值为 $`(6,5,8,4)`$，边界是 $`[2,10]\times[3,7]`$。图按同一坐标比例绘制，中心向右移二、向上移一，宽高都翻倍。因此编码目标是 $`(t_x,t_y,t_w,t_h)=(0.5,0.5,\log2,\log2)`$，不是把四条边的像素差直接当作四个输出。

**再从编码走回像素。** 取一个只在横向中心有误差的预测 $`\hat t_x=0.25`$，按 $`\hat c_x=a_x+a_w\hat t_x`$ 解码得到中心五，距离目标六差一个像素。若为了单独观察链式法则，定义像素中心损失 $`L=\frac12(\hat c_x-6)^2`$，则 $`\frac{\partial L}{\partial\hat c_x}=-1`$，而 $`\frac{\partial L}{\partial\hat t_x}=a_w(\hat c_x-6)=-4`$。右图的两个梯度不是同一坐标中的冲突答案，而是通过解码导数相连。

**更换锚宽的对照。** 保持锚中心四与预测中心五，若锚宽改为八，达到同一像素位置只需 $`\hat t_x=\frac18`$，但相同像素损失对编码的梯度变成 −8。反过来，若损失直接定义在编码残差上，优化的就是另一目标。此处平方损失只用于说明坐标链，不冒充下一节的 Smooth L1 或 IoU 损失。[Faster R-CNN 式 (2)](https://arxiv.org/html/1506.01497v3)给出相应中心宽高参数化；加权编码、尺度裁剪和其他框约定需要另外代入。

<a id="cv3-detail-10"></a>

### 3.2 平滑绝对误差的导数与尺度

设编码残差为 $`r`$，平滑绝对损失的一种定义为：当绝对值小于正阈值 $`\beta`$ 时使用 $`\frac{r^2}{(2\beta)}`$，否则使用 $`\vert r\vert -\frac{\beta}{2}`$。导数在小残差区为 $`\frac{r}{\beta}`$，在大残差区为残差符号。小误差区平滑，大误差区梯度不再线性增大，有助于避免少数很大偏移主导。

这并不表示它直接优化框重叠率。编码各分量的小变化对最终框坐标的影响不同：中心偏移导数与锚框宽高成正比，尺度分量导数与预测宽高成正比。因此同样的编码损失下降，在不同尺度框上可能对应不同的像素误差。位置损失、解码和评价之间需要通过具体案例理解。

交并比损失更直接关联重叠，但完全不相交的框可能缺乏有效局部梯度，某些推广形式通过包围区域或中心距离提供额外信号。选择哪种回归目标应考虑几何性质、初始匹配和训练稳定性，不能只因评价使用交并比就断言原始交并比损失在所有阶段最合适。

<a id="cv3-detail-11"></a>

### 3.3 实验二：编码残差的梯度与解码尺度

这个实验用双精度自动微分检查平滑绝对损失的手工梯度，再检查解码宽度对尺度分量的导数。输入选在各分支内部，便于逐项核对解析梯度。正阈值下，该损失在正负阈值处的一阶导数连续，仅二阶导数分段变化，不能将这些连接点称作一阶不可微点。它不训练检测器，只验证局部机制。

```python
import torch
import torch.nn.functional as F

r = torch.tensor([0.1,-0.8,0.4],dtype=torch.float64,requires_grad=True)
beta = 0.5
loss = F.smooth_l1_loss(r,torch.zeros_like(r),beta=beta,reduction="sum")
loss.backward()
expected = torch.tensor([0.2,-1.,0.8],dtype=torch.float64)
assert torch.allclose(r.grad,expected)
t = torch.tensor(0.3,dtype=torch.float64,requires_grad=True)
width = 20*torch.exp(t)
width.backward()
assert torch.allclose(t.grad,width.detach())
eps = 1e-6
numeric = (20*torch.exp(t.detach()+eps)-20*torch.exp(t.detach()-eps))/(2*eps)
assert torch.allclose(numeric,t.grad,atol=1e-7,rtol=1e-7)
print(loss.item(),r.grad.tolist(),width.item(),t.grad.item())
```

## 4. 目标分配决定梯度落在哪里

<a id="deep-dive-1"></a>

<a id="cv3-detail-13"></a>

### 4.1 锚框匹配的前景、背景和忽略区

给定一组锚框和真实框，可以计算两两交并比。常见分配依据每个锚框与真实框的最大交并比，把高于正阈值的锚框分为前景，低于负阈值的分为背景，中间区域忽略。不同检测器使用不同规则，有些还保证每个真实对象至少匹配一个候选。必须读取具体算法，而不能把某套阈值当成所有方法的定义。

匹配之后，分类损失作用于有效候选，位置损失通常只作用于前景。背景没有需要回归的真实对象，给背景随意填一个零框并参与回归，会制造无意义监督。忽略候选既不是正类也不是普通背景，归约分母中也应处理清楚。一个候选被分给谁，会直接决定它收到哪一种梯度。

强制最佳候选匹配在小目标或锚框覆盖不足时有帮助，但也可能让很差的候选承担大偏移。若一个候选同时是多个真实对象的最佳项，冲突解决规则尤其重要。匹配不是纯粹的数据准备，它与模型可学习性、梯度密度和拥挤目标表现紧密相关。

<a id="cv3-detail-14"></a>

### 4.2 无锚框也需要目标分配

一些方法不预设多种宽高锚框，而在特征位置预测到目标边界的距离或中心点信息。这减少了某些锚框设计，但仍然需要决定哪个位置监督哪个对象、哪些位置是背景、重叠对象如何冲突以及尺度范围如何划分。没有显式锚框不等于没有匹配规则。

若一个位置同时位于两个对象内部，可以按面积、中心距离或其他规则选择目标。中心采样可以限制监督区域，但会改变正样本数量和位置分布。距离编码必须与特征步长、原图坐标和缩放处理一致。理解检测器时，应先画出一张图中每个位置究竟对应什么标签，再阅读损失公式。

训练分配与推理后处理也不是同一件事。前者决定监督关系，后者处理多个预测对同一对象的重复响应。即使训练中每个真实框匹配多个位置，推理仍可能需要抑制重复；即使采用一对一匹配，实际系统是否使用额外后处理也应以具体实现为准。

<a id="cv3-detail-15"></a>

## 5. 多尺度特征和区域提取

<a id="cv3-detail-16"></a>

### 5.1 特征金字塔解决什么，不能解决什么

深层特征空间分辨率较低、语义更抽象，浅层特征空间分辨率较高、细节更丰富。特征金字塔通过跨层连接和上采样融合，让不同尺度的预测层获得较丰富语义。它提供多尺度表示，但不能恢复下采样过程中已经完全丢失的所有细节，也不能保证每个小目标都被看见。

设某层相对原图步长为十六，原图上宽八像素的对象可能只覆盖半个特征间距。即使理论感受野很大，采样网格仍然可能不足以定位它。提高输入分辨率、使用更高分辨率层或重新设计采样，都可能帮助，但会增加计算。感受野大小与空间采样密度是不同概念，不能用前者替代后者。

跨层相加要求通道一致，也要求空间位置对齐。把一个七乘七特征简单按倍数扩大可能得到十四乘十四，而旁路是十三乘十三，应该依据目标尺寸上采样并核对采样原点。张量尺寸对上只是必要条件，若中心坐标偏移，融合仍会把不同空间位置混在一起。

<a id="cv3-detail-17"></a>

### 5.2 目标尺度与金字塔层级分配

区域方法可以根据目标面积平方根，将不同尺寸候选送到不同层级。典型规则会相对于一个参考尺度取对数，再限制在可用层级范围内。具体参考常数和取整方式属于实现细节，不能在没有核对时跨模型照抄。这个规则的目的通常是让不同尺寸目标在特征空间占据相近数量的位置。

层级分配会形成离散边界。两个尺寸很接近的框可能落在相邻层，产生不同特征响应。某些方法通过多层融合或软分配缓解，但同时增加复杂性。研究层级规则时，应观察边界附近目标和计算预算，而不只看整体平均分数。

<a id="cv3-detail-18"></a>

### 5.3 区域池化与对齐的区别

候选框通常具有不同尺寸，而后续分类头需要固定大小特征。区域提取把候选区域采样成固定网格。若直接对坐标取整，边界量化会造成空间误差，特别影响小目标和掩码。基于连续采样的区域对齐使用插值，在浮点坐标位置取得特征，但它仍依赖明确的坐标映射和采样规则。

区域对齐不是把原图重新裁一遍那么简单，它通常在共享特征图上执行，坐标需要按特征步长映射。半像素偏移、边界处理和采样点数量都会影响输出。自写实现时应先用线性变化的特征图测试，因为双线性插值在这种图上具有容易手算的结果；随机输入不容易发现系统性偏移。

<a id="cv3-detail-19"></a>

## 6. 解码与重复抑制

<a id="cv3-detail-20"></a>

### 6.1 分数阈值、排序与截断

回归输出解码成框以后，分类分数用于过滤和排序。若在重复抑制前只保留前若干候选，就引入一个召回上限：被截掉的真实目标无法在后续恢复。分数阈值和候选数量应在验证阶段确定，并在报告中记录。不能只比较模型权重而忽略后处理参数差异。

分数并不一定是可直接解释的真实目标概率。有的方法把类别分数与目标存在性相乘，有的方法还引入位置质量估计。排序分数与训练分类概率的关系需要具体分析。若要用分数做跨类别阈值或风险控制，必须验证它在相关任务中的含义。

<a id="cv3-detail-21"></a>

### 6.2 非极大抑制的贪心机制

普通非极大抑制按分数从高到低选择框，保留当前最高分，再删除与它交并比超过阈值的候选，重复直到没有候选。它是一种局部贪心去重，不会全局优化“覆盖所有真实对象”的目标。两个真实相邻对象高度重叠时，可能被误当作重复；同一对象多个低重叠框也可能同时保留。

通常按类别分别抑制，避免两个不同类别的重叠框无条件互相删除；但若一个对象被预测为多个类别，按类抑制也可能保留跨类重复。类别无关抑制有另一组取舍。阈值越低抑制越强，并不意味着结果越好，拥挤场景尤其容易损失召回。

分数完全相同时，需要规定稳定排序或可接受的不确定性。某些后端的并列选择顺序可能不同，最终保留框也不同。教学实现可以用原索引作为次级键，使行为确定；真实部署应检查后处理是否具备所需的可重复性。

<a id="cv3-nms-conflict-chain"></a>

#### 图解：重叠冲突不具有传递性，分数微变会改变保留集合

![NMS 冲突链在分数微扰下保留集合的变化](images/03-nms-conflict-chain.svg)

**先固定几何，只改变一个分数。** 取三个同类别连续坐标框，均有竖直范围 $`[0,1]`$：

$$
A=[-1,0,1,1],\qquad
B=[0,0,2,1],\qquad
C=[1,0,3,1].
$$

每个框面积为二。相邻框相交面积为一，联合面积为三，所以 $`\operatorname{IoU}(A,B)=\operatorname{IoU}(B,C)=\frac13`$。首尾两框仅边界接触，相交面积为零，因此 $`\operatorname{IoU}(A,C)=0`$。图左把三个框的水平投影分行画出，方便比较区间；图中的上下排版位置不表示它们的真实竖直坐标不同。

固定 NMS 阈值 $`\tau=0.3`$，并规定交并比严格大于阈值才抑制。把超过阈值的一对候选连一条“冲突边”，得到 $`A-B-C`$。这张图连通，却不是一个所有节点两两冲突的团：$`A`$ 与 $`B`$ 冲突，$`B`$ 与 $`C`$ 冲突，不能推出 $`A`$ 与 $`C`$ 冲突。因此不能先用传递闭包把它们当成一个“重复框等价类”，再规定整组只能留一个。

令 $`s_A=0.800`$、$`s_C=0.799`$。若 $`s_B=0.801`$，最高分 $`B`$ 先被保留，同时抑制 $`A,C`$，输出只有 $`B`$。若只把 $`s_B`$ 降到 $`0.7995`$，则 $`A`$ 先被保留并抑制 $`B`$，剩余 $`C`$ 与 $`A`$ 不冲突，最终输出 $`A,C`$。没有任何并列分数，也没有改变坐标、类别或阈值；仅 $`0.0015`$ 的排序变化就让输出数量从一变成二。由此可见，解决并列排序的可重复性并不能消除硬 NMS 自身的离散跳变。

**贪心算法究竟保证什么？** 若候选池预先固定、不提前截断输出数量，并运行到候选耗尽，保留集合中的框两两无冲突；每个被删框都与某个已保留框冲突，所以已无法再加入任一被删框而不制造冲突。图论中称其为“极大独立集”。“极大”只表示不能直接再加元素，不表示元素数最多，也不表示总分最大。在本例中 $`\{B\}`$ 和 $`\{A,C\}`$ 都满足前者，后者数量却更多；若人为把分数之和当作目标，$`0.800+0.799=1.599>0.801`$。真实检测质量当然不等于分数总和，这个求和只是用来证明贪心过程没有全局最大总分保证。

还能把后处理阈值与评价阈值分开检验：假设两个真值框恰好是 $`A,C`$，评价匹配要求 IoU 至少为 $`0.5`$。仅留下 $`B`$ 时，它与任一真值的 IoU 都只有 $`\frac13`$，两个对象都未匹配；留下 $`A,C`$ 时则分别精确匹配。这里的 $`0.3`$ 比较预测框之间是否互相抑制，$`0.5`$ 比较预测框与真值是否匹配，它们回答两个不同的问题，不能互换。

**Soft-NMS 如何改变这个算例？** 线性 Soft-NMS 在重叠超过阈值时，把未选框分数乘以 $`1-\operatorname{IoU}`$，然后重新排序，而不是立即删除。[Soft-NMS 原论文，第 4 节](https://arxiv.org/html/1704.04503v2)

仍从 $`s_B=0.801`$ 开始，先选 $`B`$ 后，两侧分数变为

$$
s_A'=0.800\left(1-\frac13\right)=\frac{8}{15}\approx0.533333,
\qquad
s_C'=0.799\left(1-\frac13\right)\approx0.532667.
$$

随后选 $`A`$ 不会再降低 $`C`$ 的分数，因为二者交并比为零。如果衰减后的最低保留分数为 $`0.5`$，三个框都会留下，两个真值候选得以保留，但 $`B`$ 这个评价假阳性也仍然存在；如果最低分数设为 $`0.6`$，两侧候选仍会被过滤。这说明软化抑制只是改变取舍，不会自动识别哪个候选对应真实对象。比较两种后处理时，应固定候选池与类别策略，分别交代重叠阈值、衰减规则、分数过滤和最大输出数量，再观察拥挤场景的召回与误检。

### 6.3 实验三：人工框上的交并比、匹配与抑制

下面采用连续框面积，实现纯 NumPy 交并比和同类非极大抑制。前两个候选是高度重叠的重复，第三个是远处目标。阈值低时只保留两个对象，阈值提高到接近一时重复也会保留。最后按人工阈值展示正、负、忽略三种分配，不声称这是某个真实检测器的全部策略。

```python
import numpy as np

def iou_matrix(a,b):
    a=np.asarray(a,dtype=float);b=np.asarray(b,dtype=float)
    assert a.ndim==2 and b.ndim==2 and a.shape[1]==b.shape[1]==4
    assert np.all(a[:,2:]>a[:,:2]) and np.all(b[:,2:]>b[:,:2])
    lo=np.maximum(a[:,None,:2],b[None,:,:2])
    hi=np.minimum(a[:,None,2:],b[None,:,2:])
    inter=np.maximum(hi-lo,0).prod(2)
    area_a=(a[:,2:]-a[:,:2]).prod(1)
    area_b=(b[:,2:]-b[:,:2]).prod(1)
    return inter/(area_a[:,None]+area_b[None,:]-inter)

def nms(boxes,scores,threshold):
    order=np.lexsort((np.arange(len(scores)),-np.asarray(scores)))
    keep=[]
    while len(order):
        i=order[0];keep.append(int(i))
        rest=order[1:]
        order=rest[iou_matrix(boxes[i:i+1],boxes[rest])[0]<=threshold] if len(rest) else rest
    return keep

boxes=np.array([[0.,0.,10.,10.],[1.,1.,11.,11.],[20.,20.,30.,30.]])
scores=np.array([0.9,0.8,0.7])
assert np.isclose(iou_matrix(boxes[:1],boxes[1:2])[0,0],81/119)
assert nms(boxes,scores,0.5)==[0,2]
assert nms(boxes,scores,0.9)==[0,1,2]
quality=iou_matrix(boxes,boxes[:1])[:,0]
assignment=np.where(quality>=0.7,1,np.where(quality<0.3,0,-1))
assert assignment.tolist()==[1,-1,0]
print(quality.tolist(),assignment.tolist(),nms(boxes,scores,0.5))
```

### 对照表：重复抑制同时依赖分数与空间重叠

| 候选框 | 置信分数 | 与最高分框 IoU | 处理 |
| --- | --- | --- | --- |
| 框 A | 0.90 | 自身 | 首先保留 |
| 框 B | 0.80 | 0.75 | 阈值 0.5 时抑制 |
| 框 C | 0.70 | 0.10 | 继续保留 |

**说明。** 硬 NMS 先选最高分框，再抑制与它高度重叠的候选。表中的 B 虽然分数第二高，但与 A 的交并比超过阈值，被视为重复；C 的重叠很小则保留。后续还要对剩余候选继续执行同样过程，而不是仅与第一个框比较一次。

**适用条件。** 同类相邻目标可能高度重叠，重复抑制也可能误删真目标；类别范围、阈值与 Soft-NMS 等变体必须单独说明。

## 7. 集合预测与一对一匹配

<a id="sec-5"></a>

<a id="cv3-detail-24"></a>

### 7.1 固定查询数如何表示可变对象数

集合预测模型可以输出固定数量的查询，每个查询给出类别和框，并包含无对象类别。当真实对象数量少于查询数时，未匹配查询学习无对象。这样不需要预先为每个查询规定它永远对应哪个空间位置，但仍要通过训练匹配决定本次哪个查询负责哪个真实目标。

目标集合没有天然顺序。把第一个标注框永远配给第一个查询，会让模型对文件中任意排序敏感。应寻找使总匹配代价最小的一对一对应，代价可以结合类别、框距离和几何重叠。匹配求解在当前预测上决定离散分配，随后对选定对应计算可微损失；不是对离散排列本身直接求普通梯度。

若真实目标比查询更多，固定查询容量就无法一对一覆盖全部目标。训练和部署必须考虑最大目标数与拥挤场景。无对象损失权重也影响背景与目标之间的平衡，不能因为使用集合结构就认为前景背景不平衡自动消失。

<a id="sec-5-1"></a>

<a id="cv3-detail-25"></a>

### 7.2 匹配代价与训练损失可以不同

匹配代价用于比较哪种对应更合适，训练损失用于更新已经配对的预测。它们可以使用相关但不完全相同的项，例如分类代价用真实类别概率的负值，训练分类用交叉熵。两者尺度影响各自行为，不应把同一组权重不加分析地套用。

最小代价匹配具有全局耦合。一个查询改进对某目标的适合度，可能改变其他查询的对应，因此分配会在边界处发生离散切换。训练仍可在当前选定对应下计算梯度，但优化目标具有由匹配引入的分段结构。理解这一点有助于解释训练早期的不稳定，而不是把匹配当成完全无影响的数据排序。

<a id="cv3-detail-26"></a>

### 7.3 实验四：匈牙利匹配不等于逐行贪心

人工代价矩阵有三个查询、两个目标。若第一个查询贪心拿走它最便宜的目标，会迫使其他查询付出更大代价；全局匹配可以选择一个局部稍贵的对应以降低总和。我们同时枚举所有合法小规模分配，验证求解器结果，再对选定预测计算梯度。

```python
import itertools
import numpy as np
import torch
from scipy.optimize import linear_sum_assignment

cost=np.array([[1.,2.],[1.1,100.],[100.,100.]])
rows,cols=linear_sum_assignment(cost)
total=cost[rows,cols].sum()
all_totals=[]
for chosen in itertools.permutations(range(3),2):
    all_totals.append(sum(cost[chosen[j],j] for j in range(2)))
assert np.isclose(total,3.1)
assert np.isclose(total,min(all_totals))
assert set(zip(rows.tolist(),cols.tolist()))=={(0,1),(1,0)}
prediction=torch.tensor([0.3,0.7,0.9],dtype=torch.float64,requires_grad=True)
target=torch.tensor([0.6,0.2],dtype=torch.float64)
loss=((prediction[rows]-target[cols])**2).sum()
loss.backward()
assert torch.allclose(prediction.grad,torch.tensor([0.2,0.2,0.],dtype=torch.float64))
print(rows.tolist(),cols.tolist(),total,prediction.grad.tolist())
```

这段梯度只是选定人工对应后的平方误差梯度，不是完整检测器损失，也没有声称代价矩阵由这些一维预测生成。分开构造是为了分别看清全局匹配与匹配后监督。真实模型应把代价定义、预测框格式和损失目标明确连接起来，并检查无对象查询如何参与分类损失。

## 8. 语义分割中的网格与上采样

<a id="sec-2"></a>

<a id="cv3-detail-28"></a>

### 8.1 编码器压缩后如何恢复空间输出

编码器通过下采样获得上下文，解码器通过上采样和浅层跳连恢复更高分辨率表示。上采样增加网格点数，不会凭空恢复全部丢失细节；跳连能提供较浅层信息，但也可能引入噪声与计算开销。输出边界质量取决于特征、标签、采样和损失共同作用。

若最终分数图低于标签分辨率，可以把连续分数插值到标签尺寸再计算损失，也可以按明确规则降低标签分辨率。二者不是等价操作，尤其对细小前景和边界。下采样标签可能使小目标消失，从而改变任务。应根据对象尺度和评价分辨率选择，并在训练、推理与评价中保持清楚。

插值坐标约定影响边界位置。双线性插值中是否对齐角点会改变采样网格，不能在训练和部署转换时随意切换。对于奇数尺寸和非整数缩放，差异更容易显现。显式指定目标高宽并核对坐标，比依赖连续多次乘比例更容易避免累计尺寸误差。

<a id="sec-2-1"></a>

<a id="cv3-detail-29"></a>

### 8.2 标签插值与分数插值不能混用

整数类别标签不是连续测量值。把类别一与类别三做双线性平均可能得到类别二，即使原图中没有二。离散 mask 通常应使用最近邻一类保持类别身份的规则；若研究软标签，需要明确其构造与损失语义，不能把插值产生的中间数直接当作新类别。

连续概率或分数可以插值，但先对分数插值再 softmax，与先 softmax 再对概率插值通常不相同。前者与后者分别混合不同空间的对象，需要由模型设计确定。实例掩码常在各自框坐标中预测，再映回原图，这时还需处理框缩放、裁剪和实例重叠，不只是把一个全图语义图放大。

边界像素的标注本身也可能不确定。标注者对细线、遮挡和模糊边界存在差异，输出分辨率再高也不能消除标签歧义。评价应考虑任务实际需要：区域覆盖、边界精度和对象完整性可能具有不同重要性，不应只优化最容易提高的一个汇总数字。

## 9. 分割损失必须先说清有效像素

<a id="sec-3"></a>

<a id="cv3-detail-31"></a>

### 9.1 像素交叉熵的分母

设每个像素的真实类别为 $`y_i`$，类别分数为 $`z_{i,c}`$，有效掩码为 $`m_i`$。等权有效像素平均交叉熵为
$$
L_{\mathrm{CE}}=\frac{\sum_i m_i[-z_{i,y_i}+\log\sum_c e^{z_{i,c}}]}{\sum_i m_i}.
$$
忽略区域不应贡献损失，也不应进入分母。若整张图没有有效像素，需要预定处理策略，例如跳过该图或返回与图连通的零损失并记录，不能直接除以零或把无效标签改成背景。

按整批有效像素平均，会让有效面积更大的图像拥有更高总权重。先对每张图取平均再对图像平均，则让每张有标签图等权。两者都可能合理，但对应不同目标。如果一张图有十万个有效像素，另一张只有一千个，两个归约方式会产生显著差异。报告中应说明评价与训练究竟给像素、图像还是实例等权。

类别加权进一步改变分母。内置损失在某些配置下会按目标类别权重和归一化，而不是简单除以有效像素数。若手写实现采用另一种分母，数值与梯度尺度会不同。不能只比较参数名都叫均值就认为实现一致，必须从实际分子分母推导。

<a id="cv3-detail-32"></a>

### 9.2 背景不平衡的三个不同来源

背景像素数量多，使普通平均交叉熵大量关注背景；容易背景即使损失小，数量足够多时仍能主导总和。类别重加权可以改变代价，采样可以改变训练分布，聚焦类损失可以降低某些容易样本的贡献。三者不是完全等价，尤其会改变概率解释、梯度方差与空间上下文。

聚焦损失的一种二分类形式是对交叉熵乘上 $`(1-p_t)^\gamma`$，其中 $`p_t`$ 为真实类别概率。容易样本的 $`p_t`$ 接近一，其权重较小。这个权重依赖模型预测，因此梯度不仅是交叉熵梯度乘一个常数，还包括权重自身对分数的导数。把权重分离后再计算梯度会得到不同目标，应明确是否有意如此设计。

不平衡也可能来自图像级稀有前景，而不只是每张图的面积比例。若大多数图没有目标，过采样有目标图会改变看到目标的频率，却也可能过拟合少数来源。若前景标注不完整，把未标对象当背景会产生错误监督。损失技巧不能修复所有数据问题，先检查标签覆盖和来源分布通常更重要。

<a id="cv3-detail-33"></a>

### 9.3 soft Dice 的耦合梯度

一种二值 soft Dice 损失为
$$
L_D=1-\frac{2\sum_i m_i p_i y_i+\epsilon}
{\sum_i m_i p_i+\sum_i m_i y_i+\epsilon}.
$$
记分子为 $`A`$、分母为 $`B`$，对有效像素概率的导数为 $`\frac{(A-2y_iB)}{B^2}`$。同一像素的梯度依赖整片区域的总和，因此它不是独立像素损失。一个位置的预测变化会通过分母影响其他位置的梯度解释。

当真实前景为空时，平滑项和归约规则尤其重要。上述形式下，预测前景越多，损失越接近一；全部预测零时损失为零。若完全去掉平滑项，空真值且空预测会出现零除零。若直接跳过所有空前景图，又会让模型失去学习不产生假阳性的部分监督。因此空图处理必须与应用需求对应，而不是只为避免异常。

空前景虽然仍有梯度，却不代表梯度足够有用。令所有 $`y_i=0`$，有效预测概率和为 $`S`$，则上述损失化为 $`L_D=1-\frac{\epsilon}{(S+\epsilon)}`$，每个有效概率的导数是 $`\frac{\epsilon}{(S+\epsilon)^2}`$。若 $`p_i=\sigma(z_i)`$，还要再乘 $`p_i(1-p_i)`$ 才是 logit 梯度。因此在 $`S\gg\epsilon`$ 时，损失几乎恒为一，概率导数反而很小；一个看似很大的损失值不保证强监督。

例如一百个背景像素都预测 $`p_i=0.1`$，平滑量取 $`10^{-6}`$。此时 $`S=10`$，损失约 $`0.9999999`$，每个概率导数约 $`10^{-8}`$，每个 logit 梯度约 $`9\times10^{-10}`$。作为对照，同一图像上的平均二元交叉熵，对每个 logit 的梯度为 $`\frac{p_i}{100}=0.001`$，约为前者一百一十一万倍。这只是固定归约和这个点上的比较，不意味着所有 Dice 梯度都弱；有前景、不同归约或不同平滑量时需要重算。

它解释了为什么空图策略和组合交叉熵不仅是避免零除零，也是在设计假阳性的训练信号。简单增大平滑量会同时改变非空图的目标，不能只把它当作无影响的数值常数。

Dice 的多种变体使用平方分母、逐类平均、排除背景或不同平滑常数，数值和梯度并不相同。把论文中的名称直接当作唯一公式会造成复现偏差。组合交叉熵与 Dice 时，应分别记录各项数值和权重，必要时检查共享层梯度，避免某项因尺度而完全支配训练。

<a id="cv3-detail-34"></a>

### 9.4 实验五：忽略区域、标签缩放与空前景

这个独立 CPU 实验检查有效像素交叉熵与内置忽略标签实现一致，忽略位置梯度为零，并验证最近邻保持类别集合。最后检查本章 Dice 公式在空前景与完美前景中的行为。所有张量均为人工构造，不是某个数据集的分割成绩。

```python
import torch
import torch.nn.functional as F

torch.set_num_threads(1)
logits=torch.tensor([[[[1.,2.],[3.,4.]],[[0.,1.],[2.,0.]]]],
                    dtype=torch.float64,requires_grad=True)
target=torch.tensor([[[0,1],[255,0]]],dtype=torch.long)
valid=target!=255
safe=target.masked_fill(~valid,0)
per=F.cross_entropy(logits,safe,reduction="none")
manual=per[valid].sum()/valid.sum()
builtin=F.cross_entropy(logits,target,ignore_index=255,reduction="mean")
assert torch.allclose(manual,builtin)
manual.backward()
assert torch.equal(logits.grad[:,:,1,0],torch.zeros((1,2),dtype=torch.float64))
label=torch.tensor([[[[0.,2.],[2.,0.]]]])
nearest=F.interpolate(label,size=(5,5),mode="nearest")
bilinear=F.interpolate(label,size=(5,5),mode="bilinear",align_corners=False)
assert set(nearest.unique().tolist())=={0.,2.}
assert any(0<float(v)<2 for v in bilinear.unique())
def dice_loss(p,y,mask,eps=1e-6):
    numerator=2*(p*y*mask).sum()+eps
    denominator=(p*mask).sum()+(y*mask).sum()+eps
    return 1-numerator/denominator
zero=torch.zeros(4,dtype=torch.float64)
one=torch.ones(4,dtype=torch.float64)
mask=torch.ones(4,dtype=torch.float64)
assert dice_loss(zero,zero,mask)==0
assert dice_loss(one,zero,mask)>0.999
assert dice_loss(one,one,mask)==0
print(manual.item(),builtin.item(),nearest.unique().tolist(),dice_loss(one,zero,mask).item())
```

## 10. 实例分割与全景标签的额外结构

<a id="cv3-detail-36"></a>

### 10.1 两阶段实例掩码与类别关系

一种实例分割路线先产生候选框，再对每个候选提取区域特征，预测类别、修正框与局部掩码。训练时局部掩码需要由对应实例的原图掩码裁切并缩放得到。框与 mask 如果来自不同实例，即使两者形状完全合法，监督也会互相矛盾。因此匹配身份必须贯穿分类、回归和掩码分支。

掩码头可以对每个类别输出一张图，再选择真实类别对应分支计算损失，也可以使用类别无关掩码。前者允许类别相关形状，后者共享更多信息。两种设计对参数、监督密度与类别泛化有不同取舍，不能把输出通道多就等同于效果更好。实际使用时要核对背景类别是否有掩码以及未匹配候选如何处理。

推理中局部掩码映回预测框，再放到原图坐标。若框越界，需要裁剪并同步处理掩码位置。多个实例掩码可能重叠，输出格式应保留实例身份，而不是直接覆盖成一张类别图。若应用要求每像素只有一个标签，就需要额外冲突规则，这已经接近全景分割的输出问题。

<a id="cv3-detail-37"></a>

### 10.2 语义、实例与全景目标的关系

语义分割回答每像素是什么，实例分割回答哪些像素属于同一个可数对象，全景标签还要把可数对象与不可数背景区域统一到一个空间解释中。一个道路区域通常不需要给每块连通片独立对象身份，而每辆车需要区分。任务定义决定哪些类别是可数对象，不能只靠网络输出自动发现这一约定。

实例身份在单张图内通常是任意编号，换一组编号不应改变评价。若涉及视频跟踪，跨帧身份又有额外约束，单帧实例分割并不自动解决。把对象二编号成五通常无关紧要，把同一对象在下一帧换身份则可能是跟踪错误。标签结构的对称性决定匹配和评价应该忽略什么、保留什么。

## 11. 多任务损失和完整系统验证

<a id="sec-4"></a>

<a id="cv3-detail-39"></a>

### 11.1 各分支数量差异如何影响梯度

检测损失可能组合分类、框回归、目标存在性、位置质量和掩码项。分类候选可能成千上万，前景回归候选可能只有几十个，每个实例掩码又有许多像素。若都直接求和，总量随图像尺寸和目标数量变化，学习率的有效尺度也会变化。应明确每一项按什么单位归一化，再讨论组合权重。

即使损失数值相近，对共享骨干的梯度范数也可能不同。一个项通过很深的分支传播，另一个直接作用于大量位置，两者对表示更新的影响不能只看标量大小。可以在开发实验中记录各项对共享参数的梯度范数和夹角，但这些诊断也有噪声，不应仅凭一次测量自动决定权重。

某些任务之间存在冲突，例如背景分类希望压低某些响应，而细粒度定位需要保留空间细节。组合训练的收益取决于共享与分支结构、标签质量和权重。多任务并不必然互相促进。若一个分支改善而另一个退化，应分别报告，而不是只用总损失下降宣布系统进步。

<a id="cv3-detail-40"></a>

### 11.2 空图、空目标和退化输入

检测图像可能没有任何目标。此时分类或目标存在性仍然有背景监督，回归应产生合理的零贡献而不是对不存在的目标求均值。若整个批次没有正样本，回归分母需要安全处理，并保持损失与计算图连接，避免分布式训练或梯度统计出现意外分支。

空目标列表与无标注图像不是同义词。前者表示已经确认没有目标，后者可能只是标签缺失。把未标注对象当背景会造成系统性错误监督。数据接口应区分完整标注、部分标注和忽略区域。模型再复杂，也无法从普通背景损失中知道某个未标对象其实应该被忽略。

无效框、负面积框、超范围类别和非有限像素应在进入训练前拒绝或按明确规则修复。自动裁剪所有坏框虽然能让程序继续跑，也可能掩盖坐标格式错误。修复规则应记录计数和来源，必要时回到标注流程。静默修复不应成为逃避数据审计的办法。

<a id="cv3-detail-41"></a>

### 11.3 从训练到原图输出的闭环

一个最小闭环测试可以从人工图像和已知框开始，执行与训练相同的缩放填充，构造恰好正确的编码预测，再解码并反变换到原图，检查恢复误差。分割则可以从简单几何 mask 开始，检查上采样、裁剪与原图拼接。这样的测试隔离接口错误，不需要先训练一个模型。

然后检查评价接口使用同一种坐标与标签约定。若训练用连续框，评价却用了包含端点加一面积，会对小框产生明显差异。若输出掩码尺寸与原图不一致，评价前隐式插值可能改变边界。必须把隐式步骤显式化，避免“同一模型”在不同脚本下得到无法解释的分数。

本章局部实验已经覆盖编码逆变换、梯度、匹配、抑制、忽略像素和标签插值，但没有覆盖任何真实数据集的完整训练性能。下一章的数据审计与鲁棒性讨论将进一步研究来源、标注、扰动和失效。机制正确是必要条件，独立泛化证据仍然需要另外获得。

## 12. 十六个进阶练习与详细解析

<a id="sec-6"></a>

<a id="cv3-detail-43"></a>

### 12.1 练习一：连续框为何不加一

问题：框从横坐标零到十、纵坐标零到十，面积是百还是一百二十一？

解析：本章把框看作连续边界，宽高都是十，因此面积为一百。包含端点的离散整数索引约定会使用不同公式，但不能混用。相同四个数字在不同约定中代表不同区域。若训练和评价约定不一致，小框的相对误差尤其明显。应在接口中记录连续或离散、绝对或归一化、角点或中心尺寸，并用非正方形的小框作闭环测试。四维形状正确并不能证明几何语义一致。

<a id="cv3-detail-44"></a>

### 12.2 练习二：翻转为什么要交换左右

问题：宽二百的图中，框横坐标二十到六十，水平翻转后横边界是多少？

解析：新左边界为二百减六十，即一百四十；新右边界为二百减二十，即一百八十。若逐个坐标直接相减而不交换，会得到左一百八十右一百四十，产生负宽。纵坐标不变，掩码需要同步翻转。关键点任务还可能要交换左眼与右眼等语义字段。几何变换必须作用于所有关联标签，而不是只让图像看起来翻转成功。反向再翻转一次应恢复原框，可作为不变量检查。

<a id="cv3-detail-45"></a>

### 12.3 练习三：锚框尺度改变如何影响编码

问题：目标中心相对锚框向右移动十像素，锚宽分别为二十和一百，横向编码有什么不同？

解析：归一化偏移分别为二分之一和十分之一。相同像素位移对小框是更大的相对变化，因此使用锚宽归一化具有尺度意义。若直接回归像素偏移，不同尺度目标的目标量级会更不一致。解码时必须乘回对应锚宽，不能拿另一个层级的锚尺度。若编码额外乘了权重，解码也要除去该权重。参数化与尺度选择共同定义回归任务，不能只看输出都是四个数。

<a id="cv3-detail-46"></a>

### 12.4 练习四：对数宽高的梯度为何会放大

问题：预测宽度为锚宽乘指数尺度，为什么大框可能具有更大的像素梯度？

解析：对尺度分量求导，结果就是预测宽度本身。因此相同尺度分量变化，对更宽框产生更大像素变化。编码空间误差相同不代表原图坐标误差相同。指数虽然保证正宽，也会在极大输入下溢出或生成离谱框。实际系统可能限制尺度范围，但限制方式会影响训练与推理，应明确记录。损失、参数化和评价几何必须一起分析，不能从损失标量下降直接推断每种尺度的定位都改善。

<a id="cv3-detail-47"></a>

### 12.5 练习五：背景为何不参与框回归

问题：背景候选没有真实框，能否随便填零框并计算回归损失？

解析：这会迫使背景预测朝无意义坐标移动，改变共享特征和回归头的更新。通常只对正样本回归，背景只承担适当的分类监督，忽略候选则按规则不参与。若整批没有正样本，需要返回安全零贡献并记录，而不是对空数组直接取均值。这里的掩码既决定分子也决定分母，忘记分母处理会使不同目标数量批次的梯度尺度难以解释。目标分配不是前处理细节，它决定监督结构。

<a id="cv3-detail-48"></a>

### 12.6 练习六：无锚框为何仍需匹配

问题：模型在每个特征位置直接预测四边距离，是否已经摆脱目标分配？

解析：仍然需要决定哪个位置属于哪个对象、哪些位置是背景，以及多个框覆盖同一位置时选择谁。还可能限制中心区域或目标尺度范围，这些都是分配规则。无锚框减少了预设宽高模板，但没有消除监督对应关系。理解方法时应画出每个位置的标签，再分析输出和损失。若只知道回归形式，却不知道正负样本与冲突规则，就还没有理解完整训练算法。

<a id="cv3-detail-49"></a>

### 12.7 练习七：NMS能否区分重叠真实对象

问题：两个同类真实对象高度重叠，普通非极大抑制会怎样？

解析：它只看预测框重叠和分数，没有真实身份信息，因此可能把一个对象的正确预测当作另一个的重复而删除。降低阈值会加强这种抑制，提高阈值又可能保留更多重复假阳性。可以研究其他后处理或集合训练，但需要实际拥挤场景评价。NMS 是贪心规则，不是理解对象数量的全局推理器。阈值应在验证阶段决定，并记录分类分组、候选截断和并列排序方式，才能复现最终结果。

<a id="cv3-detail-50"></a>

### 12.8 练习八：匈牙利匹配为何不逐行选择最小值

问题：第一个查询到两个目标代价一和二，第二个为一点一和一百，应该怎样分配？

解析：若第一个贪心拿代价一，第二个被迫承担一百，总和一百零一。全局匹配让第一个拿第二目标，代价二，第二个拿第一目标，代价一点一，总和三点一。目标集合无固定顺序，一对一约束使局部最优不一定产生全局最优。匹配后再对选定对应计算可微损失，离散分配不是普通连续梯度的一部分。小矩阵可以枚举所有分配验证求解器，是理解全局耦合的直接方式。

<a id="cv3-detail-51"></a>

### 12.9 练习九：查询数量不够会发生什么

问题：集合预测器只有一百个查询，图像中有一百五十个真实对象，能否全部一对一匹配？

解析：不能，一对一容量最多覆盖一百个对象。需要增加容量、改变任务设计或采用其他机制，并评估计算和训练影响。查询多也不代表自动更好，无对象比例会增加，匹配和优化可能变化。应根据目标数量分布和部署场景设计，报告拥挤图像表现。固定查询结构并没有消除对象数量问题，而是把它转化为显式容量与监督平衡问题。训练数据未覆盖的高密度场景不能仅凭结构推断可靠性。

<a id="cv3-detail-52"></a>

### 12.10 练习十：标签双线性插值为什么危险

问题：标签只有类别零和二，插值后出现一，是否可以直接作为类别一监督？

解析：不可以，中间值来自数值混合，不代表图像中真的存在类别一。离散类别不是有序连续测量，应使用保持类别身份的缩放规则，或有意构造具有明确概率含义的软标签。分数图可以连续插值，但先插分数与先归一化再插概率也不等价。应明确模型设计、采样网格和训练评价分辨率，尤其关注小目标是否在标签降采样中消失。尺寸正确只是必要条件，语义正确更重要。

<a id="cv3-detail-53"></a>

### 12.11 练习十一：忽略区域应不应该进入分母

问题：一张图四个像素只有三个有效，损失总和应除以四还是三？

解析：若目标定义为有效像素平均，应除以三。忽略像素既不贡献损失，也不贡献有效数量。若错误地除以四，会把标签缺失更多的图像整体梯度缩小。按图平均与按全部像素平均又是不同目标，需要明确。类别权重还可能改变归一化分母，应核对内置实现。所有无效图需要预定安全处理，不能依赖零除零后再把异常替成零，因为那可能切断计算图并掩盖数据问题。

<a id="cv3-detail-54"></a>

### 12.12 练习十二：空前景为什么不能总跳过

问题：Dice 在空前景图上容易出现特殊情况，是否直接删除所有空图最简单？

解析：这样会失去关于不要生成假阳性的监督，并改变训练图像分布。可以用平滑项、交叉熵或明确空图规则处理，但需要与应用风险对应。本章 Dice 公式在空真值空预测时为零，在空真值却预测大量前景时接近一。其他公式未必如此，因此不能仅凭名称判断。空目标列表、无标注图和确认无对象图也应区分，后两者的信息含义不同，不能一律当背景。

<a id="cv3-detail-55"></a>

### 12.13 练习十三：相同总损失为何不代表相同训练

问题：两个系统总损失都为一，但分类和定位分量不同，能否直接说训练状态相同？

解析：不能，总损失是加权组合，分量尺度、候选数量和梯度传播都可能不同。一个系统主要优化分类，另一个主要优化框，两者共享表示的更新方向不一样。应记录未加权分量、组合权重、有效分母和必要梯度诊断。即使分量数值相近，对共享层的梯度范数也不一定相近。评价还需要分别看漏检、误分类、定位和分割质量，不能用总损失替代任务结果。

<a id="cv3-detail-56"></a>

### 12.14 练习十四：语义连通域能否恢复实例

问题：两个人在图中相互接触，语义标签都是人，连通域是否一定能得到两个人？

解析：不能，相连同类区域会合成一个连通域，而同一个被遮挡对象也可能分成多个不连通部分。语义图没有完整实例身份信息，连通域只能在特定假设下作为启发式。实例分割需要额外对象表示、中心或边界线索、查询或其他结构。标签信息不足不是单纯上采样分辨率问题，不能靠更清晰语义边界自动保证真实身份恢复。任务输出应在设计前明确，而不是在推理后随意解释。

<a id="cv3-detail-57"></a>

### 12.15 练习十五：增强后框合法是否足够

问题：所有框坐标都在图像范围且宽高为正，能否证明增强标签正确？

解析：还可能发生高宽交换、坐标格式混用、错误实例关联或图像与标签使用不同随机变换。范围检查只能发现部分异常，应增加可手算几何闭环、增强后可视化和身份一致性检查。特别要测试非正方形图、边界目标、裁剪退化和无目标输入。随机图像不容易显示系统偏移，人工几何图形更适合机制验证。最后还要核对原图反变换与评价接口，避免训练坐标正确但交付坐标错误。

<a id="sec-6-1"></a>

<a id="cv3-detail-58"></a>

### 12.16 练习十六：如何描述本章实验的证据范围

问题：五个机制实验全部通过，能否说已经实现高质量检测分割系统？

解析：不能，它们验证了人工输入上的坐标、导数、匹配、抑制和掩码归约，没有训练真实模型，也没有独立数据集性能。可以说这些局部实现符合所声明机制，并把它们作为完整系统的前置检查。要研究泛化，还需真实标注、数据划分、训练预算、模型选择和独立评价。局部正确是必要但不充分条件，清楚标明证据范围能帮助读者知道下一步缺什么，而不是把机制演示误读成完整性能验证。

<a id="cv3-detail-59"></a>

## 13. 进一步研究的组织方式

<a id="cv3-detail-60"></a>

### 13.1 先选择要解释的错误类型

若主要问题是小目标漏检，可以研究输入尺度、特征步长与分配覆盖；若是重复预测，检查候选与后处理；若是框系统偏移，先查坐标和采样对齐；若是边界粗糙，研究输出分辨率、标签与解码器。不同问题需要不同对照，不能一律通过增加骨干深度解决。

研究应先固定数据与评价单位，再改变一个明确因素，并记录计算和搜索预算。单次总分上升只能说明具体流程的经验改善，机制解释还需要与预测对应的切片或干预。若同时改动输入、分配、损失与后处理，最终可以评价整套方案，但不能把收益唯一归因给其中某项。

<a id="cv3-detail-61"></a>

### 13.2 从机制检查走向真实评价

真实训练前，把本章闭环扩展到实际数据管道，检查框、mask 和身份同步。训练中监控各损失分量、正负候选数量、空图比例和梯度有限性。训练后恢复实际选择状态，再固定后处理参数，在独立评价中报告整体与关键切片。每一步都对应前面讨论的一个信息或几何边界。

最后，把失败保留下来。若某种目标尺度始终没有正候选，若某个类别掩码长期为空，或某种增强频繁删除小目标，这些现象都应进入分析，而不是只保留最终分数。完整流程的价值在于让研究者能定位错误、提出可检验假设，并知道需要哪一种新增证据才能继续前进。


<a id="cv3-detail-62"></a>

### 13.3 聚焦损失的梯度为何不能只乘权重

考虑二分类真实标签为一，模型分数为 $`z`$，概率为 $`p=\sigma(z)`$，聚焦项取 $`L=-(1-p)^\gamma\log p`$。利用 $`\frac{dp}{dz}=p(1-p)`$，可得
$$
\frac{dL}{dz}
=\gamma p(1-p)^\gamma\log p-(1-p)^{\gamma+1}.
$$
当 $`\gamma=0`$，它回到普通二分类交叉熵的梯度 $`p-1`$。当正确概率接近一，两个项都变小，容易正样本的贡献被抑制。若把 $`(1-p)^\gamma`$ 当作不参与求导的外部权重，就会漏掉第一项，得到另一个更新规则。因此解释某种损失如何聚焦难例，不能只看前向加权公式，还要看它实际产生的梯度。

这一推导也说明损失权重与采样不完全等价。采样改变哪些样本进入梯度估计，聚焦权重则随当前参数动态变化。两者都可能减弱背景主导，但方差、概率含义和训练轨迹不同。若要比较，应保持其他条件并明确随机机制，不能把方法名称不同但“都解决不平衡”视为同一个干预。
取 $`\gamma=2`$、$`p=0.9`$，完整导数约为 $`-0.0028965`$，停止梯度版本为 $`-0.001`$，普通交叉熵为 $`-0.1`$。在困难正样本 $`p=0.1`$ 时，完整导数约为 $`-1.1020`$，绝对值甚至超过普通交叉熵的 $`0.9`$。所以它不只是把所有样本的交叉熵梯度缩小；权重自身的变化会改变困难样本的作用。

当 $`p\to1`$，利用 $`\log p=-(1-p)+O((1-p)^2)`$，导数的主导项为 $`-(\gamma+1)(1-p)^{\gamma+1}`$，说明容易样本被更高阶地抑制；当 $`p\to0`$，$`p\log p\to0`$，导数趋近 $`-1`$。这两个极限帮助定位为何它能重新分配梯度，却不能凭此推出概率仍然校准、少数类一定改善或标签噪声会自动被忽略。噪声标签往往也是困难样本，可能长期保留较大梯度，应与标签完整性审查和独立评价一起处理。


<a id="cv3-detail-63"></a>

### 13.4 不相交框与几何损失的局部信息

当两个连续框彼此分离且仍保持不相交，交集面积为零，交并比在这一局部区域恒为零。单独最小化一减交并比，可能无法告诉预测框应往哪个方向移动。加入最小包围区域或中心距离，可以在不相交时提供额外几何信号，但这些项也具有自己的尺度、边界和权重，应检查其导数而不是仅比较公式名称。

反过来，编码距离小也不一定意味着高交并比。一个极小目标稍有中心误差，重叠比例就可能大幅下降；一个大目标同样像素误差影响相对较小。因此多尺度评价应关注小目标、边界和长宽比，而不仅看总体定位损失。训练目标提供可优化信号，评价指标表达任务需求，两者需要建立联系，却不必处处相同。

<a id="cv3-giou-direction"></a>

#### 图解：GIoU 增加了哪个方向的信息，又在哪些方向失效

![分离框的IoU与GIoU损失曲线和包含框反例](images/03-giou-direction.svg)

**先限制成一个可手算的几何方向。** 真值框为 $`[-\frac12,\frac12]\times[-\frac12,\frac12]`$，预测框大小相同，中心只向右移动距离 $`d\ge0`$。两框都是连续坐标单位方框，交集面积 $`I=\max(0,1-d)`$，并集面积 $`U=2-I`$，最小包围矩形面积 $`C=1+d`$。这里的 $`C`$ 表示面积，不是类别数。[GIoU 原论文第 3 节与算法 2](https://arxiv.org/html/1902.09630v2)定义
$$
\operatorname{GIoU}=\frac I U-\frac{C-U}{C},\qquad
L_{\mathrm{GIoU}}=1-\operatorname{GIoU}.
$$
当 $`0\le d\le1`$ 时，并集恰好填满包围矩形，附加项为零；当 $`d>1`$ 时，中间空隙开始提供额外几何信息。图左侧 $`d=2`$ 对应 $`I=0,U=2,C=3`$，因此普通 IoU 为零，GIoU 为 $`-\frac13`$。

**将损失化为距离函数。** 沿这个固定大小、固定竖直位置的方向，
$$
L_{\mathrm{IoU}}(d)=
\begin{cases}
\frac{2d}{1+d},&0\le d\le1,\\
1,&d\ge1,
\end{cases}
\qquad
L_{\mathrm{GIoU}}(d)=\frac{2d}{1+d}.
$$
所以在严格分离区间 $`d>1`$，普通 IoU 损失导数为零，GIoU 损失导数则为 $`\frac{2}{(1+d)^2}>0`$。在 $`d=2`$ 处，后者为 $`\frac29\approx0.22222`$，负梯度方向会减小中心距离。这才是“不重叠也有学习信号”在该构造中的精确含义。图中蓝线在接触位置以后变平，橙线继续上升；但距离越远，橙线斜率也越小，不能把非零导数等同于任意距离都有同样强的优化信号。

**接触点和完全重合点要单独说明。** 普通 IoU 在 $`d=1`$ 处左右导数分别为 $`\frac12`$ 与零，不能套用唯一普通导数；GIoU 在这条特定路径上恰好消除了该处的折点。若改用可正可负的中心位移 $`u`$，距离变为 $`d=|u|`$，完全重合的 $`u=0`$ 又形成绝对值式边界。自动微分的 min、max、截断算子会采用特定边界约定，有限差分最好先选远离这些位置的点；沿一个方向平滑，也不证明整个框坐标空间处处光滑。

**右图给出“所有方向都有梯度”的反例。** 固定真值为边长一的方框，预测框边长为三，竖直中心对齐，水平中心位移满足 $`|u|<1`$。只要保持严格包含，交集面积始终为一，并集和包围矩形面积始终为九。因此 $`\mathrm{IoU}=\mathrm{GIoU}=\frac19`$，两种损失对这种水平平移的导数均为零。图中实线与虚线表示两个不同的预测框位置，均完整包住同一小框。这并不说明 GIoU 对所有参数的梯度都为零：若允许大框边长 $`b`$ 改变且仍严格包含，损失为 $`1-\frac1{b^2}`$，对 $`b`$ 的导数为 $`\frac2{b^3}`$，仍可推动收缩。一个损失能提供某种几何信号，与它能分辨所有局部几何变化，是两个不同命题。

**把结论接回实际回归头。** 图中的导数是对框中心或边长求导；若网络预测的是锚框偏移、对数宽高或归一化坐标，还要通过解码函数继续使用链式法则。改变中心、改变尺寸和改变长宽比也会经过不同分段。这个算例说明为何可以组合互补的定位项，以及为何需要核对特定参数方向；它没有证明 GIoU 在所有数据集、所有框配置或所有训练阶段都优于其他损失。

<a id="cv3-detail-64"></a>

### 13.5 可微流水线仍然包含离散决定

检测系统常被称为端到端，但内部可能仍有离散匹配、候选筛选或阈值决定。这个说法通常强调模块可以联合训练，不应被理解为每一步都对所有输入处处可微。普通自动微分沿当前选择的路径计算梯度，无法自动推导任意离散分配变化的全部影响。研究者需要理解哪些决定被当作常量，哪些位置存在分段切换。

因此，梯度检查应选取远离匹配切换、分段折点和阈值边界的测试点，先核对局部连续部分。若要研究边界行为，可以专门构造相等代价或相等分数反例，检查稳定排序和约定，而不把边界数值差异误判成导数实现错误。把连续机制与离散规则分别验证，能使完整系统更容易解释和维护。

在复现报告中，还应逐项写清哪些机制已经通过实际运行验证，哪些只是理论推导或未来计划。当前五个独立实验均已在 CPU 上执行并通过断言，覆盖人工坐标与损失关系；它们没有包含真实检测训练、GPU 性能或生产延迟。若读者扩展到真实数据，应重新检查数据接口、标注完整性和评价协议，并保留所有失败记录。让证据范围与结论范围一致，是把复杂视觉系统学懂的最后一道必要检查。
