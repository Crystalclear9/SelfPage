## 1. 先写清楚要估计的对象

评价生成模型不能从“选哪个指标”开始，而应从任务、目标总体与使用方式开始。模型可能用于无条件采样、给定条件的生成、训练数据扩增、科学模拟或交互创作，这些任务对质量、覆盖、控制和成本的要求不同。一次完整评价需要定义真实参考分布、生成条件的抽样规则、允许的后处理、每次生成的计算预算以及失败如何计数。否则同一个模型可以通过改筛选策略得到完全不同的报告。

本章把评价看成一条证据链：任务定义决定需要估计的量，数据划分决定信息是否独立，指标决定能发现哪些差异，抽样与重复决定不确定性，模型选择决定结果是否被过度乐观地报告。公式和代码服务于这条链条，而不是把更多指标堆在表里就自动完整。最重要的能力是给每个结论指出依据，同时列出这个依据尚不能排除的反例。

<a id="sec-1-1"></a>

<a id="geneval-detail-2"></a>

### 1.1 生成质量有多个平行维度

局部质量描述样本是否合理，覆盖描述总体中的合法变化是否出现，概率校准描述出现频率是否正确，条件一致性描述是否满足输入要求，记忆分析关注与训练记录的关系，成本则包括所有尝试与后处理。它们彼此相关但不可互换。一个模型可以生成非常清晰却只属于一个类别的样本，也可以覆盖许多类别却频繁违反物理约束。

因此报告最好把这些维度作为平行结果，而不是先用任意加权和压成一个总分。如果应用确实需要总效用，可以明确权重与代价，例如每次不满足约束的生成要承担多少重试成本。总分的结论应限定于这套效用假设，不能把某个应用偏好解释为所有生成任务上的全面优越。

<a id="geneval-detail-3"></a>

### 1.2 固定模型与完整训练方法是不同估计对象

对一个固定检查点生成一万次，能够估计这个检查点的采样表现，却不能估计重新训练一次会得到什么结果。完整训练方法的稳定性还包括初始化、训练数据抽样、优化过程和检查点选择。若比较两个方法，独立单位通常至少包含训练种子或数据划分，而不是把全部生成图片都当作独立的方法重复。

同样，给定一组固定条件的平均分只代表这组条件。若想推广到更大的提示或任务总体，需要说明条件怎样抽取，是否包含罕见组合，是否存在来源依赖。条件、训练种子和采样噪声构成不同层次，统计设计应与想推广的层次对应。把层次写清楚，是理解置信区间含义的前提。

## 2. 数据划分与评价泄露

<a id="sec-2-1"></a>

<a id="geneval-detail-5"></a>

### 2.1 训练、验证与最终测试

训练集用于拟合生成模型，验证集用于选择超参数、引导强度、采样器和检查点，测试集用于选择结束后的最终评价。生成系统的后处理、拒绝阈值与条件模板也属于需要选择的部分。如果它们根据测试结果反复调整，测试就已经参与开发，不能再承担独立确认的角色。

按文件随机划分不一定足够。同一人物、同一来源图像的裁剪、同一文档片段或同一设备记录可能高度相关，应按相应来源组划分。近重复检测与数据清理也需要有明确规则；若只清理某个方法不利的样本，会改变比较目标。最终报告应说明独立单位与重叠检查，而不只是给一个训练测试百分比。

<a id="geneval-detail-6"></a>

### 2.2 参考表示与外部评价器

图像特征提取器、文本嵌入和条件分类器都是额外模型。它们可能具有特定训练数据、偏差与盲区，不能被当成中立的真理仪器。评价器如果对重要关系不敏感，生成器在该指标上改善可能并未解决真实问题。应先用可控错误样本检验评价器是否能发现任务关心的差异。

在专业任务中，通用表示可能忽略关键异常或科学属性。可以结合领域约束、人工检查和多个独立指标，但这些补充也应有清楚抽样协议。人工评价若只展示成功样本，或者评价者知道方法名称，都可能受到选择与期待影响。盲评、随机顺序和明确评分标准能够降低某些偏差，却不能自动消除样本选择问题。

## 3. FID 背后的高斯二阶搬运距离

<a id="sec-5"></a>

<a id="geneval-detail-8"></a>

### 3.1 公式与成立对象

对于两个具有均值 $`m_1,m_2`$、协方差 $`C_1,C_2`$ 的高斯分布，平方二阶 Wasserstein 距离为

$$
\Vert m_1-m_2\Vert ^2+\operatorname{tr}\left(C_1+C_2-2(C_1^{\frac{1}{2}}C_2C_1^{\frac{1}{2}})^{\frac{1}{2}}\right).
$$

协方差必须对称半正定，分布要有有限二阶矩。对一般分布，代入均值和协方差得到的是高斯近似之间的距离，而非原分布的完整 Wasserstein 距离。图像 FID 在特定图像特征空间中估计这些量，其意义依赖特征提取、预处理和有限样本估计。不能把任意二维数据上的这条公式都直接命名为标准图像 FID。

高斯距离同时比较均值与协方差，但只看二阶统计。若两个非高斯分布有相同均值协方差，这个值可以为零，而模式、尾部或支持完全不同。因此较小值是特定表示和二阶近似下的证据，不是完整分布一致的证明。写报告时应准确说明使用何种特征、多少样本、怎样计算协方差以及是否进行了数值修正。

<a id="geneval-detail-9"></a>

### 3.2 从一维到矩阵的推导直觉

一维高斯之间的最优单调搬运把标准化坐标一一对应，平方搬运成本就是均值差平方加标准差差平方。多维情况下，均值平移成本可以先分离，剩下的问题是如何最优耦合两个中心化高斯的相关方向。协方差平方根与迹项描述了这些方向的最佳对齐，而不是逐元素对两个协方差开平方。

如果两个协方差可以同时对角化，公式退化为各共同特征方向上的一维结果之和。若它们不对易，不能简单把协方差元素相乘再逐项开根号。实际常见写法涉及 $`C_1C_2`$ 的平方根，但这个乘积未必对称；使用对称夹心形式更便于理解与稳定计算。任何数值实现都应对称化并监测小负特征值究竟来自舍入还是输入错误。

<a id="geneval-detail-10"></a>

### 3.3 有限样本与维数

经验均值和经验协方差都是随机估计，代入非线性矩阵函数后通常产生样本量相关偏差。样本量不足时协方差还可能秩亏，尤其特征维数高于有效样本数。对角加小常数可以改善数值稳定，却也改变距离，需要报告所加正则与敏感性。不能让某方法使用更多生成样本，然后直接把更低估计值解释为模型更好。

比较小差异时应统一参考与生成样本量、特征版本和预处理，必要时进行重复子抽样。相同的参考集可以减少比较噪声，但反复围绕它调参也带来适应性。最终测试仍需要独立协议。指标小数点后许多位通常只是计算精度，不代表估计对象有同样高的统计精度。

## 4. 可运行实验一：高斯距离与二阶失明反例

下面实现对称半正定矩阵平方根，核对同分布零距离、对称性以及一维解析结果。再构造两个均值方差相同的一维非高斯分布，说明高斯二阶距离为零却没有完整分布一致。实验特意称为玩具高斯距离，不把它冒充图像特征 FID。

```python
import numpy as np
from scipy.stats import wasserstein_distance

def sqrt_psd(a):
    a = (a+a.T)/2
    values, vectors = np.linalg.eigh(a)
    assert values.min() > -1e-10
    return (vectors*np.sqrt(np.maximum(values,0)))@vectors.T

def gaussian_w2_sq(m1,c1,m2,c2):
    root = sqrt_psd(c1)
    value = np.sum((m1-m2)**2)+np.trace(c1+c2-2*sqrt_psd(root@c2@root))
    assert value > -1e-9
    return max(float(value),0.)
c1 = np.array([[2.,.6],[.6,1.]])
c2 = np.array([[1.,-.2],[-.2,3.]])
m1 = np.array([0.,1.]);m2=np.array([1.,-.5])
a = gaussian_w2_sq(m1,c1,m2,c2)
b = gaussian_w2_sq(m2,c2,m1,c1)
assert np.isclose(a,b)
assert gaussian_w2_sq(m1,c1,m1,c1) < 1e-10
assert np.isclose(gaussian_w2_sq(np.array([0.]),np.array([[4.]]),
                    np.array([3.]),np.array([[9.]])),10.)
p = np.array([-1.,1.]);pw=np.array([.5,.5])
q = np.array([-np.sqrt(2),0.,np.sqrt(2)]);qw=np.array([.25,.5,.25])
assert np.isclose(p@pw,q@qw)
assert np.isclose((p*p)@pw,(q*q)@qw)
w1=wasserstein_distance(p,q,u_weights=pw,v_weights=qw)
assert w1>0.5
print('toy Gaussian W2 squared',a,'same-moment actual W1',w1)
```

这里实际一阶搬运距离为正，明确反驳了“二阶距离零就等于分布相同”。两个指标比较的是不同对象，因此不是公式互相矛盾。可以进一步构造尾部质量不同但矩相同的分布，检验某个评价器的盲区。如果模型只针对二阶指标优化，也可能利用这些盲区而不改善完整生成质量。


<a id="geneval-gaussian-coupling"></a>

### 图解：同一对高斯的最优耦合与成本分解

![实际二维高斯的马氏椭圆、配对点及独立和最优耦合成本](images/05-gaussian-coupling.svg)

左图直接使用程序中的 $`m_1,m_2,C_1,C_2`$。蓝圆是源均值，橙菱形是目标均值；两层椭圆分别满足马氏半径为一与二。它们是由已知协方差精确画出的等密度轮廓，**不表示所有样本都在椭圆内，也不是一维正态的百分之六十八区间**。四条细箭头只展示四对对应位置，不把四个点当作完整的高斯经验分布。

在当前正定条件下，最优确定性搬运可写为

$$
Y=m_2+A(X-m_1),
\qquad
A=C_1^{-\frac12}
\left(C_1^{\frac12}C_2C_1^{\frac12}\right)^{\frac12}
C_1^{-\frac12}.
$$

本例数值约为

$$
A=
\begin{pmatrix}
0.774024&-0.332298\\
-0.332298&1.878339
\end{pmatrix}.
$$

先核对均值：$`E[Y]=m_2`$；再核对协方差：$`AC_1A^T=C_2`$。线性变换后的高斯仍是高斯，因此这两项在当前模型族里足以验证目标分布。图中的箭头不是把蓝点直接搬到目标中心，而是在移动中心的同时保留恰当的随机变化。

两者的平方搬运成本可按零均值误差分开：

$$
\begin{aligned}
E\|Y-X\|^2
&=\|m_2-m_1\|^2
+\operatorname{tr}\!\left((A-I)C_1(A-I)^T\right)\\
&=3.25+0.9447409326\\
&=4.1947409326.
\end{aligned}
$$

交叉项为零，是因为 $`E[X-m_1]=0`$。右侧同尺度条形图还给出另一个合法耦合：独立抽取 $`X,Y`$。它的两个边缘分布完全相同，但随机部分的期望成本为 $`\operatorname{tr}(C_1)+\operatorname{tr}(C_2)=7`$，总成本便是 $`10.25`$。因此“边缘分布确定了”并不意味着“怎样配对都具有同一成本”；最优距离还要在合法配对中取最小。

高斯近似如何进入 FID，可核对 [Heusel 等人的原论文](https://arxiv.org/pdf/1706.08500)。本图在二维已知分布上解释搬运结构，并未使用图像特征网络；[第 20 节](#geneval-detail-73)进一步给出最优交叉项的矩阵推导。下一张离散反例说明，一旦离开高斯族，仅匹配均值与协方差就不再足够。


<a id="visual-example-generativemodels-05"></a>

### 对照表：相同均值方差不等于相同生成分布

| 分布 | 可能取值 | 概率 | 均值与方差 |
| --- | --- | --- | --- |
| A | −1、＋1 | 各二分之一 | 0，1 |
| B | −√2、0、＋√2 | 四分之一、二分之一、<br>四分之一 | 0，1 |

**说明。** A 只在两个端点取值，B 还有一半质量集中在零，但两者均值同为零、方差同为一。仅比较一阶和二阶矩，无法分辨这个明显的支持与形状差异。这个反例解释了为什么特征分布指标的数值接近不能自动证明生成分布完全一致。

**适用条件。** 两分布虽有相同矩，但不是高斯；在严格高斯族内部均值与协方差可以确定分布，前提不能省略。


<a id="geneval-moment-cdf"></a>

### 图解：从离散质量到累计概率间的面积

![同矩异分布的离散质量及累计分布曲线之间的搬运面积](images/05-moment-cdf.svg)

左图的每根竖线都是程序中一个离散原子的质量，不是连续密度曲线。$`P`$ 在 $`-1,1`$ 上各有二分之一；$`Q`$ 在 $`-\sqrt2,0,\sqrt2`$ 上分别有四分之一、二分之一、四分之一。二者的一阶矩都是零，二阶矩都是一，所以高斯替代分布都为 $`N(0,1)`$，高斯二阶距离恰好为零。

右图保留了完整的累计信息。沿横轴从左向右走，$`Q`$ 先在 $`-\sqrt2`$ 增加四分之一，$`P`$ 到负一才增加二分之一；到零时，$`Q`$ 又增加二分之一。四个非零差异区间上的累计概率高度差都为四分之一。由一维一阶 Wasserstein 恒等式，

$$
\begin{aligned}
W_1(P,Q)
&=\int_{\mathbb R}|F_P(x)-F_Q(x)|\,dx\\
&=\frac14\left[
(\sqrt2-1)+1+1+(\sqrt2-1)
\right]\\
&=\frac{\sqrt2}{2}
\approx0.7071067812.
\end{aligned}
$$

所以阴影面积是非零的，即使两个低阶矩已经完全一致。它不是相邻原子间任意连线产生的三角形面积；累计分布在区间中保持常数，应该按矩形逐段求和。原子位置的单点跳跃不贡献积分宽度。SciPy 的 [wasserstein_distance 定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.wasserstein_distance.html)同时说明了最优搬运与累计分布面积的等价，本例用两种表示核对同一个一阶距离。

还可以用同一组质量直接计算原分布的平方二阶距离。按递增分位数配对：负一处的二分之一质量分别送往负根号二与零，各送四分之一；正一处对称处理。这个单调耦合对一维平方成本最优，得到

$$
W_2^2(P,Q)
=\frac12(\sqrt2-1)^2+\frac12
=2-\sqrt2
\approx0.5857864376.
$$

因此即使统一成平方二阶距离，原始分布之间的值仍为正，而高斯替代之间为零。上一图的阴影选择 $`W_1`$，是因为其累计曲线面积最直观，并不是依靠换一个阶数才制造差异。

这里比较的是**原始离散分布的 $`W_1`$** 与**高斯替代分布的平方 $`W_2`$**，并非声称同一个距离既为零又非零。指标使用的分布对象与阶数都要写清。即便增加无限多样本并精确恢复这些矩，高斯替代的盲区仍然存在；这属于指标所保留信息的限制，而不是估计还不够精确。

## 5. 特征空间 precision 与 recall 的边界

<a id="geneval-detail-13"></a>

### 5.1 局部邻域的几何解释

生成评价中的 precision 通常试图衡量生成样本有多少落在真实数据流形附近，recall 则试图衡量真实数据区域有多少被生成样本覆盖。具体算法会用近邻半径、局部球或其他集合近似，它们不是分类任务中的同名指标，也没有一个在所有实现中完全相同的定义。使用前应给出具体算法、距离、近邻数以及参考和生成样本量。

这些方法依赖特征空间几何。半径太大可能接受明显错误样本，太小则把正常变异判为不合理。高维距离集中、有限样本稀疏和局部密度差异都会影响结果。它们可以提供质量与覆盖的分离诊断，但不自动校准概率质量：某个模式只被极少生成一次，就可能在集合覆盖上看起来已经覆盖。

<a id="geneval-detail-14"></a>

### 5.2 概率频率与支持覆盖不同

假设真实四种状态等概率，生成器虽然四种都能产生，却把百分之九十七质量放在其中一种。基于支持集合的 precision 与 recall 可能都很好，而分布频率严重错误。这个反例说明需要同时检查模式质量分配、分层指标或其他两样本差异。不能因为两个集合都互相接近，就认为总体概率也匹配。

另一个问题是特征折叠。若表示只保留绝对值，正负两个模式会映射到同一个特征，完全遗漏负模式的生成器也可能显得覆盖完美。选择更好的邻域算法无法恢复表示已经丢掉的信息。评价体系应同时包含表示本身的反例测试，必要时增加任务特定属性，而不是只在同一盲区里换一个距离公式。

<a id="geneval-detail-15"></a>

## 6. 可运行实验二：支持指标与频率错误

以下是一个故意简单的半径邻域版本，只用于展示集合指标的局限，并不声称复现某篇图像 precision/recall 实现。两个集合都包含全部四个状态，但生成频率高度偏斜，半径指标仍然等于一。随后用绝对值表示演示模式身份丢失。

```python
import numpy as np

def radius_pr(reference,generated,radius=.01):
    distance = np.abs(reference[:,None]-generated[None,:])
    precision = np.mean(distance.min(axis=0)<=radius)
    recall = np.mean(distance.min(axis=1)<=radius)
    return float(precision),float(recall)
reference = np.array([-2.,-1.,1.,2.])
generated = np.r_[np.full(97,2.),[-2.,-1.,1.]]
p,r=radius_pr(reference,generated)
assert p==1 and r==1
assert generated.mean()>1.8 and reference.mean()==0
true_modes=np.array([-2.,2.]);missing_negative=np.array([2.,2.,2.])
raw=radius_pr(true_modes,missing_negative)
folded=radius_pr(np.abs(true_modes),np.abs(missing_negative))
assert raw[1]==.5 and folded==(1.,1.)
print('support precision/recall',p,r,'mean mismatch',generated.mean())
print('raw versus collapsed-feature recall',raw[1],folded[1])
```

改进这个实验时可以增加局部高斯噪声，再研究样本量与半径的交互。若真实罕见模式只有少量参考样本，局部半径可能不稳定。评价者应该报告这些局限，并把支持覆盖与概率质量偏差分开呈现。完美的某个指标值通常意味着通过了某类检验，而不是不再需要其他证据。

<a id="visual-local-generativemodels-05"></a>

### 图解：支持覆盖与概率频率需要分别检查

![支持覆盖与概率频率需要分别检查](images/05-concept.svg)

图直接使用实验二的四个参考位置 $`(-2,-1,1,2)`$ 与一百个生成位置。参考四点各占四分之一的质量，生成计数为 $`(1,1,1,97)`$；右上每个圆点代表一次真实计数，颜色对应左侧的同一位置，九十七个橙点直接显示了质量堆积。四个参考点表示四个等权原子，不假装它们也是一百次独立抽样的结果。下图则比较各自归一化后的累积分布，因此不把不同总数的计数直接当作概率比较。

半径零点零一的判定只问“附近有没有对方的点”。每个生成位置都恰好命中一个参考位置，故 precision 为一；每个参考位置也都至少出现一次，故 recall 为一。重复九十七次的正二不会让其余三个位置从集合里消失，所以这两个支持指标没有惩罚频率失衡。它们通过了当前支持检验，不代表完成了分布校准。

频率差异可以直接量化。参考均值为零，生成均值为 $`\frac{-2-1+1+97\times2}{100}=1.92`$；这两个离散概率向量的总变差为

$$
\operatorname{TV}(P,Q)
=\frac12\sum_{i=1}^{4}|p_i-q_i|
=\frac12(0.24+0.24+0.24+0.72)
=0.72.
$$

事件“位置为正二”已经实现了这个差值：生成概率为零点九七，参考概率为零点二五。累积分布中，在 $`1\le x<2`$ 上参考累计质量为零点七五，生成累计质量只有零点零三，阴影高度因此为零点七二。这里的最大累积分布差恰好等于总变差，因为所有缺失质量都堆到了同一个最右端原子；对一般离散分布，这两个距离并不总相等。三个少量颜色各出现一次，证明支持仍在，却远没有保留四分之一的模式质量。

生成 precision/recall 的局部流形路线可参见 [Kynkäänniemi 等人的原论文第 2 节](https://arxiv.org/html/1904.06991v2#S2)。论文通过每个参考点的近邻距离估计球半径；本程序故意采用固定的一维半径，不能把图中的数值称作论文实现的图像成绩。它保留的教学问题是：无论采用哪种具体几何近似，都应另查概率频率与表示是否丢失了任务身份。程序后半部分的绝对值映射把两个符号模式合并，正是第二类盲区。

## 7. 条件可控性需要分解要求

<a id="geneval-detail-17"></a>

### 7.1 标签正确只是最简单的一层

条件生成可以包含类别、数量、空间关系、颜色、文本内容、物理参数或多个模态约束。单个类别分类器高分只证明某种类别可识别，不保证数量和关系正确。应把条件拆成可检验的属性及组合，并事先定义完全满足、部分满足和失败的判定规则。若某个要求无法自动评价，可以使用盲评或领域工具，但仍要清楚抽样与成本。

例如“两个红球在蓝盒左侧”至少包含对象类别、数量、颜色绑定和空间关系。一个只识别“球”和“盒”的嵌入可能给错误数量的图很高相似度。评价数据应包含这些可区分错误的反例，并按错误类型报告。条件组合的难度也要分层，避免总体平均被大量简单条件主导。

<a id="geneval-detail-18"></a>

### 7.2 条件遵从与条件内多样性

每个条件只输出一个固定模板，可以满足某些属性，但不具备条件内覆盖。评价可以在同一条件下生成多个独立样本，检查合法变化、重复率与近邻结构，同时确保差异不是来自违背条件。单纯奖励样本间距离可能鼓励错误颜色、错误数量或噪声，因此多样性必须在满足条件的样本中解释，也要报告被拒绝比例。

如果只对成功样本计算多样性，容易隐藏成功率低的问题。应同时报告所有尝试中的成功率、成功子集的多样性以及取得一个成功样本需要的平均成本。三者共同描述实际使用体验。把筛选后的十张漂亮图当作模型原始分布，会让结论过度乐观。

<a id="geneval-detail-19"></a>

### 7.3 未见组合与外推

训练中分别见过红色和球，不等于一定能够正确组合红球；训练中见过某些关系，也不等于支持任意复杂关系。应区分已见条件、未见组合和超出范围的外推条件。每一类都需要独立样本量与评价，否则总体平均可能掩盖组合泛化失败。

对于连续物理参数，边界附近和范围外条件尤其重要。模型如果只能在训练区间内插值，报告应明确限制。条件本身也可能有噪声或缺失，需要测试相应鲁棒性。不能在训练时使用生成后才知道的属性作为条件，再把这种信息优势当作部署可用的控制能力。

## 8. 配对比较、置信区间与选择偏差

<a id="sec-6-1"></a>

<a id="geneval-detail-21"></a>

### 8.1 配对能降低哪一种噪声

比较两个方法时，让它们面对相同条件、相同数据划分与预先定义的随机种子集合，可以使差值更容易解释。配对不意味着两个系统的所有随机数消费顺序必须相同，尤其调用结构不同的方法很难逐步完全对齐。需要明确共享的是条件、初始噪声还是训练划分，以及这种共享是否有合理含义。

对每个独立训练种子先计算条件平均差，再对种子差值做推断，能够反映该固定条件集合下的训练变异。如果目标还要推广到随机条件总体，需要额外设计条件抽样或双层重采样。不能把种子与条件交叉表中的每个单元都当成独立重复，因为同一种子共享模型，同一条件也共享难度。

<a id="geneval-detail-22"></a>

### 8.2 置信区间的解释范围

置信区间对应一个明确随机机制，不是“真实效果有百分之九十五概率在这里”的万能描述。固定模型下重抽生成样本、重抽训练种子、重抽数据来源以及重抽条件，估计的是不同层次的不确定性。报告应写明重采样单位与保持固定的对象，让读者知道结论可以推广到哪里。

种子数量很少时，bootstrap 区间也可能不稳定。可以同时报告逐种子差值和描述统计，避免一个看似精确的区间掩盖信息不足。若方法在某些种子完全失败，不能悄悄删除失败后再计算成功子集平均。失败处理规则应预先确定，并与成功率或总效用一起报告。

<a id="geneval-detail-23"></a>

### 8.3 搜索越多越容易选到乐观噪声

即使所有候选方法真实效果相同，从很多有噪声的验证成绩中选最优，也会得到偏乐观的验证结果。搜索的引导强度、步数、检查点、种子和提示模板都构成选择空间。独立测试可以评估选择后的方案，但不能让测试再参与选择。应报告候选数量与搜索预算，避免把更大调参投入当作算法本身收益。

<a id="geneval-detail-24"></a>

## 9. 可运行实验三：种子配对与赢家诅咒

实验先构造种子与条件交叉成绩，固定条件集合，按独立种子重采样差值。随后模拟所有候选真实效果相同的验证搜索，观察最优验证值偏乐观，而独立测试均值仍接近零。这个例子不依赖任何生成网络，专门检验评价设计中的统计逻辑。

```python
import numpy as np
rng=np.random.default_rng(91)
seeds,conditions=12,8
base=rng.normal(size=(seeds,1))+.5*rng.normal(size=(1,conditions))
a=base+.08*rng.normal(size=(seeds,conditions))
b=base+.15+.08*rng.normal(size=(seeds,conditions))
difference=(b-a).mean(axis=1)
indices=rng.integers(seeds,size=(5000,seeds))
boot=difference[indices].mean(axis=1)
lo,hi=np.quantile(boot,[.025,.975])
assert lo<difference.mean()<hi
assert difference.shape==(seeds,)
validation=rng.normal(0,1,size=(4000,30))
test=rng.normal(0,1,size=(4000,30))
chosen=validation.argmin(axis=1)
selected_val=validation[np.arange(len(chosen)),chosen]
selected_test=test[np.arange(len(chosen)),chosen]
assert selected_val.mean() < -1
assert abs(selected_test.mean()) < .08
print('paired difference',difference.mean(),'seed-bootstrap interval',lo,hi)
print('selected validation/test',selected_val.mean(),selected_test.mean())
```

这里的区间只对固定八个条件下的种子平均差进行推断。条件不是从某个大提示总体随机抽来的，因此不能宣称区间已经覆盖提示泛化不确定性。赢家诅咒模拟也不是说验证选择没有意义，而是说明被选中方案的验证成绩不能被无修正地当作独立测试成绩。

![相同真实效果候选的验证选择乐观偏差](images/05-selection-optimism.svg)

图把实验三的四千次搜索完整汇总成同一横轴上的分布，不是挑一次最夸张的结果。每次先生成三十个真实均值相同的验证噪声分数，再选最小的索引；蓝线读取同一个索引对应的独立测试分数。验证均值约 $`-2.0340`$，测试均值约 $`-0.00956`$，全部候选的真实均值则都为零。阶梯线是固定宽度 $`0.25`$ 的经验密度直方图轮廓，并非理论概率密度的精确形状。

从条件期望也可以直接解释蓝线为什么没有同样的优势。令选择索引 $`J=\arg\min_jV_j`$，测试向量 $`T`$ 与所有验证分数独立，且各 $`E[T_j]=0`$，则

$$
E[T_J]
=\sum_jP(J=j)\,E[T_j\mid J=j]
=0.
$$

而 $`E[V_J]=E[\min_jV_j]<0`$，这个负值来自选择噪声，不是候选本身更好。若候选真实质量不同，合法验证选择仍然有价值，但被选中的验证成绩通常仍带有乐观成分；独立测试、搜索预算与全部候选记录依然必要。模型选择过拟合的分析可参见 [Cawley 与 Talbot 的原研究](https://jmlr.org/papers/v11/cawley10a.html)，本图使用本章已公开的正态模拟，不复用论文数据。

## 10. 记忆、近邻与原创性判断

<a id="geneval-detail-26"></a>

### 10.1 最近邻证据能支持什么

生成样本异常接近某个训练记录，可能提示复制或记忆，但距离依赖表示与数据本身的重复性。低维或高度规则的数据天然可能出现很近的合法新样本。应同时比较生成到训练集、生成到独立参考集以及参考集内部的近邻距离，并检查样本量差异。更大的训练集更容易拥有近邻，不能忽略这个基数效应。

相反，没有找到近邻也不能证明不存在记忆。模型可能对训练样本作轻微变换，所选表示可能不敏感，也可能只有罕见提示触发复制。需要结合多种距离、具体实例与有针对性的测试。最终结论应表述为“在这些检测条件下未观察到某类近复制”，而不是泛化成绝对原创或绝无训练记忆。

<a id="geneval-detail-27"></a>

### 10.2 相似性、隐私与下游使用

相似样本是否可接受取决于任务与数据来源，不能仅靠一个数值阈值自动决定。科学模拟中的重复结构、商品目录中的标准形状与人脸或敏感文本的风险各不相同。评价报告应描述检测对象和证据，不应把技术近邻距离直接当成法律或伦理结论。若需要领域判断，应使用相应专业标准与人工复核。

下游数据扩增还需要独立真实测试集，防止合成数据只是重复训练信息。生成样本看起来新颖并不保证提高下游泛化，加入低质量或偏置合成数据也可能损害少数群体或罕见条件。应与相同预算的真实数据重采样、简单增强等基线比较，才能判断复杂生成管线提供了多少实际新增价值。

<a id="geneval-detail-28"></a>

## 11. 拒绝采样改变了最终分布

<a id="geneval-detail-29"></a>

### 11.1 接受函数与归一化

设原生成分布为 $`q(x)`$，样本以概率 $`a(x)\in[0,1]`$ 被接受。接受后的分布为 $`q_a(x)=\frac{q(x)a(x)}{Z}`$，其中 $`Z=E_qa(X)`$ 是总体接受率。若接受函数依赖条件，归一化也随条件变化。因此筛选会改变模式概率，哪怕每个保留样本看起来更好，也可能严重损害覆盖。

取得一个接受样本的平均尝试次数在独立同分布且接受率固定的条件下为一除以接受率。若还有最大重试次数，部分请求会失败，应把失败率也计入。筛选器调用、生成器调用、条件编码和后处理都属于成本。只报告保留样本的生成时延，会低估实际使用代价。

<a id="geneval-detail-30"></a>

### 11.2 条件成功后的多样性需要总体背景

如果某个方法接受率百分之十，另一个百分之九十，只在各自成功样本上比较清晰度不构成完整公平比较。可以统一尝试预算比较成功产出，也可以统一成功样本数量比较总成本，但要明确采用哪种协议。两种方案回答不同使用问题，都应保留拒绝率与条件分层结果。


<a id="visual-mechanism-generativemodels-05"></a>

### 图解：筛选账本：保留比例与总接受率必须同时计算

![筛选账本：保留比例与总接受率必须同时计算](images/05-mechanism.svg)

图采用实验四的同一参数：原模式概率各半，接受概率分别为一与零点一。带宽以每一百次提议的**期望计数**绘制：A 的五十份全部保留，B 的五十份中期望保留五份、拒绝四十五份。蓝、橙与灰带共同守恒，拒绝部分没有从生成成本中消失。随机运行一百次并不保证恰好出现这些整数。

接受前的联合质量是 $`(0.5,0.05)`$，总接受率为 $`Z=0.55`$。归一化后，

$$
q_{\mathrm{keep}}(A)=\frac{0.5}{0.55}=\frac{10}{11},
\qquad
q_{\mathrm{keep}}(B)=\frac{0.05}{0.55}=\frac{1}{11}.
$$

因此 B 仍在最终支持中，却只占约百分之九点零九。接受率与保留集比例的分母不同：前者除以全部提议，后者除以全部接受。若只说“B 保留了百分之十”，还要说明指的是 B 内部接受率，不能把它直接当作最终输出比例。

在独立同分布提议与固定接受函数下，直到首次接受的提议次数为几何变量，均值为 $`\frac1Z=\frac{20}{11}`$。本程序每次提议消耗两次去噪器调用和一次筛选器调用，所以长期平均单位调用成本为

$$
\frac{2+1}{Z}=\frac{60}{11}\approx5.454545.
$$

这与三次“内部调用”不是同一个分母。有限预算下程序计算的是实际总调用除以实际成功数，该随机比值会波动，不能把期望成功数代入后的数字称为每次运行必然达到的结果；成功数为零时还必须报告失败，不能继续计算普通比值。不同调用的墙钟耗时也可能不同，这里的单位调用账本不自动等于实际秒数。

若每个请求最多允许三次提议，失败概率为 $`(1-Z)^3=0.091125`$，返回成功率约为零点九零八八七五；这已经是一个需要连同失败请求一起报告的系统。任意质量筛选都不保证恢复目标分布。严格拒绝采样需要合适的目标/提议密度比、支持与包络条件，相关理想假设和实践偏差可参见 [Discriminator Rejection Sampling 第 2.4 与 3 节](https://arxiv.org/html/1810.06758v3#S2.SS4)。本例只是明确指定接受函数，展示它如何改变质量分配和成本。

## 12. 可运行实验四：筛选后的模式偏移与全成本

```python
import numpy as np
rng=np.random.default_rng(101)
p=np.array([.5,.5]);accept=np.array([1.,.1])
expected=p*accept/(p@accept)
n=100000
mode=rng.choice(2,size=n,p=p)
keep=rng.random(n)<accept[mode]
frequency=np.bincount(mode[keep],minlength=2)/keep.sum()
assert np.allclose(frequency,expected,atol=.01)
assert abs(keep.mean()-p@accept)<.01
# Every proposal uses two denoiser calls and one filter call.
denoiser_calls=2*n;filter_calls=n
cost=denoiser_calls+filter_calls
cost_per_success=cost/keep.sum()
assert cost_per_success>3
print('accepted mode distribution',frequency,'theory',expected)
print('acceptance',keep.mean(),'calls per success',cost_per_success,
      'theory',3/(p@accept))
```

原分布两个模式各一半，筛选后第二模式只占约十一分之一。这个变化来自接受概率而非原生成器突然忘记模式。若只评价保留集，就必须把它称为筛选后的系统，并按实际模式分布解释。全流程成本约为每个成功样本五点四五次单位调用，而不是表面上的三次，接受率更低时差距还会扩大。

![筛选改变生成分布](images/05-selection-changes-distribution.svg)

**筛选改变生成分布。** 本图设原生成器有十分之一概率产生某稀有类型，每次独立抽 k 个，只要有这个类型就优先挑选。最终输出该类型的概率变为 1−0.9ᵏ，k=10 时约为 0.6513，已不是原始十分之一。筛选可以有实际价值，但展示筛后样本时必须说明选择规则与候选成本，否则读者无法还原原始生成分布。

$$
P(\text{筛后稀有类型})=1-(1-0.1)^k.
$$

## 13. 十六道练习与详细答案

<a id="sec-8-1"></a>

<a id="geneval-detail-33"></a>

### 13.1 更低二阶距离是否证明完全更好

不能。它说明在指定表示、样本量和高斯二阶近似下更接近参考统计。相同矩的非高斯反例表明模式与尾部仍可能错误。应结合局部质量、覆盖、条件一致性与任务约束。若差异很小，还要考虑有限样本偏差和不确定性。指标的用途是提供某类证据，而不是宣布所有维度都获胜。

<a id="geneval-detail-34"></a>

### 13.2 任意特征距离能否叫 FID

不宜。标准图像 FID 具有特定特征流程与约定，任意低维向量套用高斯公式更准确的名称是该特征空间中的高斯二阶距离。可以说明数学形式类似，但必须避免混淆指标身份。特征、预处理与样本量都影响数值，跨协议结果不能直接排名。准确命名本身就是可复现报告的一部分。

<a id="geneval-detail-35"></a>

### 13.3 为什么协方差不能逐元素开平方

矩阵平方根要满足矩阵乘法意义下根与自身相乘得到原矩阵，逐元素开根通常不满足这个条件，也不保持相关方向。对称半正定矩阵可以通过特征分解构造主平方根。若出现明显负特征值，应检查输入而不是直接全部截断。对小舍入误差的修正也应有明确容差与记录。

<a id="geneval-detail-36"></a>

### 13.4 precision 与 recall 都高为何仍错误

有限邻域指标可能只检查支持接近，而不严格检查模式概率。一个模式占绝大多数、其他模式偶尔出现的生成器仍能覆盖所有参考点。表示折叠还可能直接抹去重要差异。因此应增加频率与分层统计，并用反例测试评价器。两个高分表示通过两类检查，不等于完整分布一致。

<a id="geneval-detail-37"></a>

### 13.5 多生成图片是否等于多次独立训练

不是。固定模型下的样本共享同一个训练结果，只能估计其采样分布。完整训练方法的稳定性需要独立训练种子或数据重复。将一万个样本当成一万个方法重复会低估训练变异。报告应分别注明模型数、每模型样本数与独立条件数，让不确定性的来源清楚可见。

<a id="geneval-detail-38"></a>

### 13.6 配对为什么通常有帮助

相同条件与来源共享难度，使方法差值消除一部分共同波动。配对后的统计单位仍应与独立机制一致，例如先按训练种子平均再做推断。若两方法结构不同，不必强求每个内部随机数逐项相同；应说明共享哪些外部随机因素。错误地把相关单元当独立，可能比不配对更误导。

<a id="geneval-detail-39"></a>

### 13.7 最好验证种子能否代表方法

不能。挑最好种子相当于搜索，结果具有选择偏差。应报告预先指定种子集合的全部表现，或明确把“选择后系统”作为对象并用独立测试评价。失败种子也必须进入稳定性报告。若实际部署会多次训练再选择，成本与选择规则也属于方法定义，而不是免费获得的优势。

<a id="geneval-detail-40"></a>

### 13.8 条件分类准确率为何不够

它通常只检验类别，不能保证数量、关系、属性绑定或物理约束正确。还可能忽略条件内多样性。应把条件分解为可检验部分，构造能够区分错误类型的评价集，并报告完全成功率与分项结果。外部分类器本身也有错误，需要反例与必要的人类复核，不能把其输出当成绝对真值。

<a id="geneval-detail-41"></a>

### 13.9 为什么只看成功样本有偏

成功子集是经过选择的条件分布，可能排除某些困难模式。它的质量不能代表所有尝试。应同时报告成功率、成功后的质量与多样性，以及每个成功样本的总成本。若设置最大重试次数，还要报告最终请求失败率。筛选可以是合理系统设计，但必须作为完整系统评价。

<a id="geneval-detail-42"></a>

### 13.10 最近邻很远能否证明没有记忆

不能。所选表示可能对某种复制不敏感，模型也可能经过变换复现训练内容，或只在特定条件下触发。应使用多个诊断、独立参考对照与有针对性的测试。结论应限定于实际检测能力。相反，近邻很近也可能来自合法重复或低维结构，需要结合基数效应和具体案例解释。

<a id="geneval-detail-43"></a>

### 13.11 接受率一半是否成本正好翻倍

若每次独立尝试成本相同且只有接受与拒绝，取得一个成功样本的平均尝试次数为二。但条件编码可复用、筛选器成本不同、批量处理和最大重试都会影响实际资源与延迟。应按完整流程测量，并区分平均调用量与尾部时延。数学期望提供参照，不能代替真实系统全部成本。

<a id="geneval-detail-44"></a>

### 13.12 共同测试集是否自动公平

不自动。方法可能使用不同预处理、特征版本、生成数量、引导搜索或后处理预算。共同参考集只统一一部分条件。需要把数据、选择、评价与成本协议都列清楚。若某方法在测试集上反复调参，最终共同测试也失去独立确认作用。公平来自完整协议，而不是一个相同文件夹名称。

<a id="geneval-detail-45"></a>

### 13.13 小置信区间是否说明方法稳定

要看重采样单位。如果只是固定模型下大量生成样本的区间，它可能很窄，却没有包含重新训练的变异。条件集合固定也没有包含条件泛化。应解释区间对应哪个随机机制，同时展示逐模型结果。种子数量少时，精确小数并不能弥补独立重复不足，应避免过强结论。

<a id="geneval-detail-46"></a>

### 13.14 更少采样步是否一定更快

网络调用更少通常减少部分计算，但每步结构、条件双分支、批次与后处理都可能不同。应在同设备、精度和输出大小下测量全流程，并同时报告质量。若为了达到相同成功率需要更多重试，总成本可能反而增加。不能只比较循环次数而忽略最终可用产出。

<a id="geneval-detail-47"></a>

### 13.15 如何评价数据扩增用途

用独立真实测试集比较下游泛化，并与真实重采样、简单增强等同预算基线对照。要防止生成器或评价器接触测试信息，也要检查少数组与罕见条件。生成样本漂亮不保证有用，重复训练数据可能只增加训练次数而非新增信息。应把生成成本计入，并报告不同合成比例的收益与风险。

<a id="geneval-detail-48"></a>

### 13.16 一个合格报告最少写什么

写明任务与目标总体、来源划分、模型选择规则、最终采样分布、全部筛选与重试、指标定义和盲区、独立单位、随机种子、样本量及成本。再给出主要结果、分层结果与失败条件。对每个强结论都指出对应证据，并说明尚未检验的范围。这样即使没有巨大表格，报告仍然能够被复核与继续研究。

<a id="geneval-detail-49"></a>

## 14. 完整低维基准：边缘正确仍可能条件错误

<a id="geneval-detail-50"></a>

### 14.1 预先定义四个条件

下面把条件定义为中心符号与局部噪声尺度的组合，共有四种，评价条件均匀抽取。真实条件分布都是已知一维高斯，因此既能计算条件精确高斯距离，也能直接检验条件遵从和方差。这里不训练网络，而是构造三个有清楚概率定义的人工生成系统，专门检验评价协议能否识别预设错误。模型训练好坏与评价器有效性需要分开，已知失败模型是检验评价器的有用工具。

第一个系统忠实复制真实条件分布；第二个把中心符号反过来，其他设置不变；第三个保留正确中心，却把所有条件的局部标准差压到零点零二。第二个系统在均匀条件混合后可以拥有正确边缘分布，却完全违背输入符号。第三个系统的样本更靠近条件中心，可能在点误差或严格邻域成功率上显得很好，却遗漏真实局部变化。

<a id="geneval-detail-51"></a>

### 14.2 可独立运行的条件评价

```python
import numpy as np
rng=np.random.default_rng(121)
means=np.array([-2.,-2.,2.,2.])
scales=np.array([.2,.6,.2,.6])
n=6000
z=rng.normal(size=(4,n))
reference=means[:,None]+scales[:,None]*z
systems={
    'faithful':(means,scales),
    'wrong_condition':(-means,scales),
    'collapsed_variation':(means,np.full(4,.02)),
}
summary={}
for name,(mu,sigma) in systems.items():
    sample=mu[:,None]+sigma[:,None]*z
    correct_sign=(np.sign(sample)==np.sign(means[:,None])).mean(axis=1)
    variance_ratio=sample.var(axis=1)/(scales**2)
    exact_conditional_w2=(mu-means)**2+(sigma-scales)**2
    # Proper log score: held-out true observations evaluated under q.
    nll=(.5*np.log(2*np.pi*sigma[:,None]**2)
         +.5*((reference-mu[:,None])/sigma[:,None])**2).mean()
    summary[name]=(exact_conditional_w2.mean(),float(nll))
    assert np.isfinite(sample).all()
    print(name,'global mean/variance',sample.mean(),sample.var(),
          'sign adherence',correct_sign,'variance ratios',variance_ratio,
          'exact conditional Gaussian W2 squared',exact_conditional_w2,
          'reference NLL',nll)
assert summary['faithful'][0]==0
assert summary['wrong_condition'][0]==16
assert summary['collapsed_variation'][0]>0
assert summary['faithful'][1]<summary['collapsed_variation'][1]
assert summary['faithful'][1]<summary['wrong_condition'][1]
print('known-distribution conditional checks passed')
```

共享同一组标准噪声是这个人工比较中的配对设计，降低了部分统计差异，不能把它称为独立训练种子比较。条件高斯距离使用已知参数，因此是这些人工高斯条件分布之间的精确值，不是图像 FID，也不是依靠经验协方差估计的指标。负对数似然在独立真实观测上评价，能够惩罚过窄分布对正常真实变化赋予过低密度，但仍需要模型提供可计算密度。

<a id="geneval-conditional-location-scale"></a>

### 图解：同一条件内比较中心、尺度与总体混合

![四个已知高斯条件下忠实、条件翻转及局部坍缩的同尺度区间对照](images/05-conditional-location-scale.svg)

每一行固定一个条件，每一列固定一个生成系统。三列共享相同的横坐标范围；灰带表示该行真实分布的均值正负两个标准差，彩色线段表示候选分布的同样区间，圆、叉、菱形则直接标出候选均值。这里画的是**分布尺度区间**，不是均值估计的置信区间，也不是样本全部可能取值的范围；对于这些正态分布，区间内概率约为百分之九十五点四五。

忠实系统的中心与宽度都与灰带相合；翻转系统保留宽度，却移到相反的中心；坍缩系统仍在正确中心，但所有条件的标准差都只有零点零二。后者的细线在图上接近点，不意味着真实变化本来就很小，而是候选把标准差零点二或零点六都压缩了。

为什么总体混合会掩盖条件翻转？令四个条件等频，真实边缘密度为

$$
p(x)=\frac14\sum_{c=1}^{4}
\mathcal N(x;\mu_c,\sigma_c^2).
$$

把所有 $`\mu_c`$ 取反，只是在四个等权分量之间重排，理论边缘密度完全不变；它的均值仍为零，方差仍为 $`4+\frac{0.2^2+0.6^2}{2}=4.2`$。有限次生成结果并不逐点相同，但增加样本也无法让只看边缘的评价发现“给定条件却去了另一侧”这类错误，因为总体目标确实已经被匹配。

在当前一维高斯族中，逐条件平方搬运距离同时看中心和尺度：

$$
W_{2,c}^2
=(\widehat\mu_c-\mu_c)^2
+(\widehat\sigma_c-\sigma_c)^2.
$$

翻转系统每个条件的中心差绝对值都是四，所以每行距离均为十六。坍缩系统的两种尺度损失分别为 $`(0.2-0.02)^2=0.0324`$ 与 $`(0.6-0.02)^2=0.3364`$，四条件平均为零点一八四四。它的边缘方差仍有 $`4.0004`$，很大程度来自两个相距较远的中心，不能用这个“大方差”证明每个条件内部仍有足够变化。

还可解释程序中的负对数似然。真实观测来自 $`N(\mu_c,\sigma_c^2)`$，候选报告 $`N(\widehat\mu_c,\widehat\sigma_c^2)`$ 时，条件期望为

$$
E[-\log q_c(X)]
=\frac12\log(2\pi\widehat\sigma_c^2)
+\frac{\sigma_c^2+(\mu_c-\widehat\mu_c)^2}
{2\widehat\sigma_c^2}.
$$

这把错中心与过窄尺度都写进了分母明确的惩罚中。坍缩虽然让样本更靠近中心，却会把正常真实偏移判成极不可能，导致很大的 NLL。程序使用独立真实观测的有限平均来估计该期望；图中的位置、宽度和距离来自已知参数，没有把随机估计值与理论值拼成一套“精确成绩”。

<a id="geneval-detail-52"></a>

### 14.3 为什么这个基准比一个总分更有用

只比较边缘均值方差，会漏掉错误条件系统，因为均衡正负条件混合后仍然对称且尺度相同。只比较条件中心误差，又可能偏爱坍缩变化系统，因为它总在中心附近。完整条件分布评价同时考虑中心和尺度，才能发现两种不同错误。对于真实图像，我们通常没有完整解析分布，因此需要用多个代理指标与反例，而不能假装一个数字已经承担所有工作。

进一步可以把条件概率改为不均衡，再分别报告按部署频率加权和按条件均匀加权的结果。两种汇总都合理，但回答不同问题：前者描述实际请求总体，后者防止常见条件淹没罕见条件。若只报告其中一种，应说明选择理由，最好同时保留逐条件表，让读者能够根据自己的使用分布重新理解结果。

<a id="geneval-detail-53"></a>

## 15. 从估计量到实际决策

<a id="geneval-detail-54"></a>

### 15.1 平均质量与尾部失败

平均分可能被大量普通成功样本主导，而实际应用更在意少数严重失败。可以报告分位数、约束违反率、最大重试后的请求失败率以及按条件分层的尾部指标。尾部事件稀少时需要更大样本量，零次观察也不证明概率为零。应根据事件定义和样本量给出可解释的范围，避免把“这次没看到”写成“永远不会发生”。

不同严重程度失败也不必强行混为一类。例如轻微颜色偏差、完全错误数量和物理上不可能的样本，其应用代价不同。可以先按类型统计，再根据明确效用函数汇总。若效用权重没有共识，就保留多维结果，比隐藏在一个看似客观的总分里更诚实。决策者可以据此选择更符合实际容错要求的系统。

<a id="geneval-detail-55"></a>

### 15.2 实用等价与统计显著不同

一个很小的指标差异在样本足够多时可能统计显著，但实际效果未必重要。应预先考虑应用上值得关注的差异尺度，而不是只看区间是否跨零。反过来，独立训练数量太少导致区间宽，也不能把未显著差异解释为两方法等价。等价或非劣判断需要相应设计、界限与足够信息。

对于生成成本，可以把质量收益与资源代价共同展示，例如每千次尝试获得多少满足条件的多样样本。某方法局部质量略好却需要十倍重试，是否值得取决于应用。报告应提供支撑这种判断的数据，而不是先替所有用户选定唯一赢家。复杂模型带来的额外维护、条件编码和筛选成本也应进入解释。

<a id="geneval-detail-56"></a>

### 15.3 多指标与多次检验

评价二十个指标后只挑两个有利指标报告，会带来明显选择偏差。可以预先指定主要指标与次要诊断，并公开完整结果。若做正式假设检验，需要考虑多次比较；若主要是探索性研究，也应明确其探索性质，避免给事后发现套上预先确认的语气。指标越多不等于证据越强，关键在于每个指标与问题的关系。

探索发现仍然有价值，例如发现某条件特别难，可以形成后续独立实验的假说。合理流程是把探索用于提出问题，再用新的数据或预设协议确认。不能在同一测试集反复发现、调整并宣称最终确认。把这两阶段分开，能够减少过拟合评价体系，也让研究结论更容易积累。

<a id="geneval-detail-57"></a>

## 16. 公平加速协议与全流程成本

<a id="geneval-detail-58"></a>

### 16.1 相同调用次数和相同质量是两种问题

比较采样加速可以固定网络调用预算，看哪种采样器获得更好质量；也可以固定目标质量，看需要多少资源。两种协议不能混用。若一个方法每步需要条件与空条件双分支，另一个只需一次前向，即使步数相同，调用量也不同。更大的网络、额外解码器和筛选器也应单独计入，而不是只把采样循环长度当成本。

同设备测量时，应固定精度、批次、输出大小和预热规则，并区分首次加载延迟与稳态生成。批量吞吐与单请求延迟回答不同使用问题。内存峰值也可能限制可用批次，某方法看似每步快却无法在目标设备运行。因此成本表应围绕实际部署方式，而非挑一个最有利硬件条件。

<a id="geneval-detail-59"></a>

### 16.2 质量相同需要怎样定义

不能在加速方法上降低分辨率、增加筛选或换更宽松评价，再声称相同质量更快。应统一输出规格、条件集合与评价规则，同时给出质量差异的不确定性。若用某个主要指标设阈值，还应检查其他关键维度没有明显退化，例如覆盖、条件遵从和罕见模式质量。一个指标接近并不自动意味着整体质量等价。

如果需要调节引导强度来达到相同条件成功率，这个调参应在验证阶段进行，最终配置冻结后再测试。达到阈值所需的搜索预算也可以报告，尤其在实际使用需要反复调参时。加速收益应限定于已验证的任务和硬件，不能从一维 CPU 玩具运行时间推断大型图像模型速度。

<a id="geneval-detail-60"></a>

### 16.3 失败尝试与超时也属于结果

系统可能因数值溢出、显存不足、超时或最大重试失败而没有返回样本。若只统计成功运行，会低估成本并夸大质量。应预先定义失败如何进入总体统计，例如以请求成功率和成功请求条件质量分别报告。需要人工修复或重启的运行也应记录，不能视作没有发生。

对于批量生成，一部分样本失败可能导致整个批次重跑，实际代价与独立逐样本重试不同。对交互任务，尾部延迟可能比平均吞吐更关键。评价设计要与真实使用流程一致，必要时模拟完整请求到返回结果的过程。资源优化的目标是提高可用产出，而不是只让一段内部算子更快。

<a id="geneval-detail-61"></a>

## 17. 近邻诊断、数据覆盖与敏感性分析

<a id="geneval-detail-62"></a>

### 17.1 近邻距离需要对照分布

如果训练集很大，任何新样本都可能找到很近邻居。应构造独立参考到训练集的近邻距离作为基准，再比较生成样本的距离是否异常。训练与参考样本量、表示尺度和重复记录都影响结果，必要时通过相同规模子集重复计算。只给几个最相似样本的图，能发现个例，却不能表达总体比例。

同时应检查生成内部近重复，因为模型可能没有复制训练记录，却反复输出同一种新模板。内部多样性与训练记忆不同，两个问题都需要评价。若输出包含结构化文本或程序，简单向量距离可能漏掉语义复制或等价改写，需要更符合任务的检测。任何检测都应明确可发现的变换范围与盲区。

<a id="geneval-detail-63"></a>

### 17.2 距离阈值不应事后挑选

把复制判定阈值从严格逐步放宽，会改变检测到的比例。合理做法是预先根据独立对照或任务标准设主阈值，并附敏感性曲线。若阈值是在看到某方法结果后挑的，结论容易被选择影响。同样，邻域 precision/recall 的近邻数与半径也应遵循固定选择协议，不能对每个方法单独挑最有利设置。

对于真实数据，标签噪声与自然近重复不可避免。可以抽样人工复核近邻报警，估计报警的实际含义，同时保留未报警样本的对照。只检查报警案例容易产生确认偏差，只检查随机少量案例又可能漏掉稀有问题。分层抽样与权重还原能够提高诊断效率，但必须把抽样设计计入总体比例估计。

<a id="geneval-detail-64"></a>

### 17.3 覆盖不等于复制

覆盖真实分布需要生成与真实样本在某些结构上相似，因此“相似”本身不是坏事。真正需要区分的是总体结构学习、有限记录记忆和敏感内容复现。一个极端的最近邻复制器可以提供清晰样本与良好训练参考距离，却缺乏独立新信息；一个完全随机噪声生成器没有复制，却也没有任务价值。评价体系必须同时防止把两种极端误判为成功。

下游效用可以提供补充证据，但仍需要严格独立测试。若合成数据帮助某个任务，可能是平衡类别、正则化或重复训练次数带来的收益，并不一定意味着生成分布整体更好。通过简单重采样与增强基线，可以分离其中一部分机制。结论应围绕实际观察到的效用，而非自动扩大到“理解了真实世界”。

<a id="geneval-detail-65"></a>

## 18. 一个从计划到报告的研究流程

<a id="geneval-detail-66"></a>

### 18.1 在运行前冻结关键决定

先写一个简短协议，说明目标总体、条件抽样、主要指标、预设样本量、训练种子、选择预算和失败规则。再列出已知盲区与补充诊断。协议不需要繁琐，但应能阻止看到结果后任意移动成功标准。探索阶段可以灵活调整，确认阶段则要冻结，并明确两者使用不同证据。

然后用本章的已知失败分布检验评价器：同矩异分布应被某些补充指标发现，条件翻转应被条件评价发现，局部坍缩应被方差或分布指标发现，拒绝采样应在概率与成本上显露变化。如果评价器连这些明显反例都区分不了，就应先修正评价设计，而不是立即拿大模型填充更漂亮的表格。

<a id="geneval-detail-67"></a>

### 18.2 运行中保留可核查记录

记录每个模型、条件与种子的完整结果，不仅保存平均值。样本选择规则、失败次数和筛选率应可回溯。本章教学实验的所有数据在内存中构造；真实大型实验则可以在专门实验目录管理原始证据，归档时关联协议、可复现代码和必要结果，使每次筛选的影响能够追溯。

发现异常时先检查实现与数据协议，再判断是否需要改变模型。如果进行了修正，应重新运行受影响实验，并说明哪些结果来自修正后版本。不要把不同配置结果混在同一表中却不标注。可核查记录的目的不是增加负担，而是让自己能够解释一个看似显著的变化究竟来自模型、指标还是操作过程。

<a id="geneval-detail-68"></a>

### 18.3 报告要让读者看见代价

主要结果应同时给出效果、变异和成本，必要时用逐条件表或质量成本曲线呈现折中。失败条件与无收益设置同样值得保留，它们限定方法适用范围。结论应区分确认性发现、探索性线索和未验证推测，不把一个人工数据反例直接当成所有图像系统的实证结论。

一份可靠报告不一定有最多指标，但应让每个数字都有对象、单位、抽样来源和解释边界。能够清楚说出某个指标为什么可能被骗，往往比记住公式本身更重要。生成研究的评价能力最终体现为：当一个结果看起来很好时，仍然能够提出合理反例，并设计独立检查去排除它。

<a id="geneval-detail-69"></a>

## 19. 本章实跑结果与跨章节联系

<a id="geneval-detail-70"></a>

### 19.1 四个基础实验的数值证据

高斯距离实验的二维对称计算约为四点一九四七，而同矩异分布例子的实际一阶搬运距离约零点七零七一，清楚展示二阶失明。支持邻域实验对频率严重偏斜的生成器给出 precision 与 recall 都为一，但生成均值为一点九二，真实均值为零；绝对值表示还把遗漏负模式的 recall 从二分之一变为一。

配对实验在固定八条件下得到平均差约零点一四七三，按十二个独立种子重采样的区间约零点一二九一到零点一六五五。三十候选搜索模拟的最佳验证均值约负二点零三四，而独立测试约负零点零零九六，说明选择如何制造乐观成绩。拒绝实验的接受率约零点五四九二，保留模式比例约零点九零九七与零点零九零三，每个成功样本平均单位调用约五点四六二。

<a id="geneval-detail-71"></a>

### 19.2 与前四章怎样衔接

VAE 中的重构与先验生成需要分开评价，ELBO 改善不能替代覆盖。GAN 中的判别器损失不是固定外部指标，模式占用与离群比例应同时看。扩散中的验证噪声 MSE 不是最终分布质量，引导、步数与筛选改变了质量成本折中。自回归或流模型即使拥有显式似然，也仍需要条件、覆盖与下游任务评价，因为密度能力与应用价值并非完全相同。

因此，本章没有寻找一个能够结束所有争论的总指标，而是建立能够不断检验模型与评价器的逻辑。后续读论文时，可以先寻找目标对象、选择预算、指标盲区与独立单位，再看作者的主要改进。若这些信息缺失，即使表格中提升明显，也要把结论限定在实际证据支持的范围内。

<a id="geneval-detail-72"></a>

### 19.3 条件基准的实际结果

忠实系统与条件翻转系统的总体均值都约为零点零零零四，总体方差分别约四点一八八和四点二一零，单靠边缘矩很难发现后者严重错误。但逐条件符号遵从在忠实系统中接近一，在翻转系统中接近零，条件精确高斯距离平方也从零升到十六。局部坍缩系统符号遵从全为一，却把条件方差压到真实值约百分之一或千分之一，清楚揭示“更靠近中心”不等于正确分布。

在独立真实观测上的平均负对数似然，忠实系统约零点三六零，条件翻转约一百一十一点四三五，局部坍缩约二百四十六点一二七。这里观测确实来自已知高斯条件分布，且候选系统提供了对应密度，因此这个比较具有清楚概率含义。真实图像 GAN 通常没有这种直接密度接口，不能把本实验方法不加修改地套用，也不能把这个玩具结果当作图像方法排名。

<a id="geneval-detail-73"></a>

## 20. 进一步推导：高斯二阶距离为何出现矩阵平方根

<a id="geneval-detail-74"></a>

### 20.1 耦合中的交叉项

先把两个高斯中心化，任何耦合的平方距离期望都可以展开为两个协方差迹之和，减去两倍的交叉内积期望。因此最小化搬运成本等价于在合法耦合中最大化交叉内积。若协方差正定，可以先把两边白化为标准正态，再研究它们之间允许的相关矩阵。这个相关矩阵的算子范数不能超过一，否则联合协方差不再半正定。

具体地，写 $`X=m_1+C_1^{\frac{1}{2}}U`$、$`Y=m_2+C_2^{\frac{1}{2}}V`$，其中 $`U,V`$ 均为标准正态向量，记 $`K=E[UV^T]`$。联合协方差为块矩阵 $`\left[\begin{smallmatrix}I&K\\K^T&I\end{smallmatrix}\right]`$，由 Schur 补可知它半正定当且仅当 $`\Vert K\Vert _2\le1`$。中心化交叉内积期望等于 $`\operatorname{tr}(MK)`$，其中 $`M=C_2^{\frac{1}{2}}C_1^{\frac{1}{2}}`$。因此问题归结为在算子范数不超过一的矩阵上最大化这个迹。

令 $`M=A\Sigma B^T`$ 为奇异值分解，则 $`\operatorname{tr}(MK)=\operatorname{tr}(\Sigma B^TKA)`$。矩阵 $`B^TKA`$ 的算子范数仍不超过一，所以每个对角元素不超过一，迹至多为 $`\sum_i\sigma_i(M)`$；取 $`K=BA^T`$ 恰好达到此界。这个 $`K`$ 可由 $`V=K^TU`$ 的确定性高斯耦合实现，因此不是只有形式上的上界。又有 $`M^TM=C_1^{\frac{1}{2}}C_2C_1^{\frac{1}{2}}`$，故最优交叉项正是 $`\operatorname{tr}[(C_1^{\frac{1}{2}}C_2C_1^{\frac{1}{2}})^{\frac{1}{2}}]`$。加回均值平方差和两个协方差迹，便得到本章公式。

这里的奇异值属于协方差平方根的乘积 $`M`$，不能误写为任意相关矩阵自身的奇异值。平方根项来自最佳相关耦合，而非为了图像指标随意选择的运算。协方差奇异时可以通过合适极限或半正定耦合处理，但白化时不能直接求普通逆。

<a id="geneval-detail-75"></a>

### 20.2 为什么只能对高斯保证完整表达

高斯分布由均值与协方差完全决定，所以这些统计足以描述它们的全部分布，最优高斯耦合也达到相应搬运成本。非高斯分布并不由前两阶矩唯一决定，因此保留相同计算式只得到高斯替代分布之间的距离。这个区别不是数值实现误差，增加样本量也无法消除。即使精确知道所有均值协方差，二阶失明反例仍然存在。

因此研究中应同时区分估计误差与表达不足：有限样本导致经验矩不准确，是估计误差；只看二阶矩看不见模式，是指标表达不足。增加样本量可以改善前者，不能解决后者。换特征有时能让重要差异进入前两阶统计，但仍需要反例核验，而且特征丢失的信息不会被矩阵平方根恢复。这种逐层定位也适用于其他复杂指标。

<a id="geneval-detail-76"></a>

### 20.3 从指标差异形成可检验假说

如果某模型高斯距离改善但条件遵从下降，先检查是否牺牲了条件依赖来匹配边缘；如果 precision 提升而 recall 下降，检查是否缩窄了输出或增加了拒绝；如果近邻距离增大而质量下降，检查是否只是加入无关噪声。每一种矛盾指标组合都可以转化为具体机制假说，而不是马上挑选有利指标宣布胜利。

后续实验应针对假说增加独立证据，例如逐条件分布、拒绝前后模式质量、已知属性与噪声敏感性。把指标当成诊断工具，才能从分数表走向对生成机制的理解。评价的目标并非让每个数字都好看，而是让系统的能力、代价和边界尽可能清楚，使下一步改进有可验证方向。

最终交付时，还应让结果表与配置一一对应。至少保留模型标识、条件集版本、评价器版本、样本数量、随机种子、筛选规则与成本单位。模型权重相同但采样器或引导配置不同，已经是不同的生成系统；评价器名称相同但预处理不同，也可能产生不同指标。清楚的标识比一个孤立的最好分数更有复用价值。

如果某次实验只做了人工低维验证，就把结论写成机制与公式核验；如果已经运行真实领域数据，才报告该领域的实测成绩。把理论推导、玩具反例和真实基准三类证据分别命名，能够防止读者误解完成范围。这种准确性并不会削弱教材，相反，它让后续研究者知道哪些基础已经可靠，哪些部分仍需要新的独立实验来支持。
