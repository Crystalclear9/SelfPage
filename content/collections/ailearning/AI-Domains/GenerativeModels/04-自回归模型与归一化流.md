## 1. 生成模型首先必须定义概率对象

生成模型不只是一台能够产生看似合理样本的机器。若要训练和比较密度，还必须明确随机变量、取值空间、概率质量或密度的单位，以及采样算法与所定义分布的关系。离散图像像素、连续测量、文本符号和潜变量属于不同对象。把连续密度直接当作离散事件概率，会导致对似然和评价的根本误解。

本章比较两种可直接计算似然的思路。自回归模型把联合分布拆成一串条件分布；归一化流把易处理的基分布经过可逆变换映射到数据空间，再用变量替换公式计算密度。两者都需要具体条件才能实现精确计算，也都存在计算与表达上的取舍。精确似然是计算属性，不自动保证拟合正确、采样有用或异常检测可靠。

<a id="gm-4-detail-2"></a>

### 1.1 离散概率质量与连续密度

对离散变量，某个值的概率可以为正，所有可能值的概率之和为一。对连续变量，单点概率通常为零，区间概率由密度积分得到。密度可以大于一，例如均匀分布在长度为十分之一的区间上，密度为十，但总概率仍是一。负对数密度因此也可以为负，这不是概率计算出错。

密度依赖坐标单位。把米改成厘米，数值区间扩大一百倍，一维密度相应缩小一百倍，log 密度相差固定常数。若训练和测试采用不同预处理却直接比较似然，结论可能只是单位变化。公平比较必须固定数据表示、变换和补偿项，并说明报告的是每样本、每维度还是每离散符号的信息量。

<a id="gm-4-detail-3"></a>

### 1.2 似然、采样和推断是三个计算问题

给定样本求密度、从模型抽样、给定观测求潜变量或条件分布，可能具有不同难度。一个模型可以容易抽样却难以算密度，也可以容易给观测评分却需要顺序采样。流在满足可逆条件时能把样本映回唯一潜变量，但这不等于任意缺失变量的条件推断都容易；后者可能需要积分或约束求解。

选择方法前应说明主要工作负载。若每天要给大量观测评分，密度计算方向很重要；若需要实时生成，采样方向更关键；若要频繁处理任意缺失模式，就不能只看完整数据似然。评价中应分开记录这些计算任务，而不是用一个“推理速度”混称所有过程。

## 2. 自回归分解的数学基础

<a id="gm-4-detail-5"></a>

### 2.1 链式法则不要求独立

对向量 $`x=(x_1,\ldots,x_d)`$，在固定顺序下有

$$
\begin{aligned}
p(x) &=\prod_{i=1}^d p(x_i\mid x_{<i}),\\[6pt]
\log p(x) &=\sum_{i=1}^d\log p(x_i\mid x_{<i}).
\end{aligned}
$$

这来自概率链式法则，不是假设维度独立。模型能力限制体现在条件分布如何参数化、能读取多少前缀以及是否有足够训练数据。每个条件分布都归一化时，离散情形可逐层求和证明联合分布归一化；连续情形在适当可积条件下可逐层积分，得到同样结论。

顺序改变不会破坏链式法则，却会改变有限模型的学习难度。图像按像素、颜色通道或块排列，文本按符号顺序排列，表格按字段排列，都引入不同条件结构。某个顺序下关系简单，另一个顺序下可能需要复杂多峰条件分布。比较顺序时应保持模型容量与预算清楚，而不把顺序影响误认为概率法则失效。

<a id="gm-4-detail-6"></a>

### 2.2 条件族决定表达能力

离散变量可以用分类分布，连续变量可以用高斯、混合分布或更灵活的单调变换条件族。若每个条件都被限制为单峰高斯，某些复杂联合结构可能难以表示，即使网络输出参数的函数很强。增加神经网络深度无法自动突破输出分布族的限制。需要区分“条件参数函数”与“条件随机分布”两种表达能力。

连续自回归中的方差必须为正，可以通过指数或带下界的正值函数参数化。若允许方差无限趋近零，有限训练点的似然可能被局部尖峰无限提高，尤其在过强模型或重复数据中。独立测试、噪声模型和适当约束因此重要。训练似然提高不总意味着更平滑、更合理的总体密度。

<a id="gm-4-detail-7"></a>

### 2.3 训练并行与生成顺序

训练时完整真实样本已知，可以在因果掩码下同时计算多个条件分布；这通常称为教师强制。并行并不表示未来变量被允许泄漏，掩码和输入移位必须维护依赖结构。采样时真实前缀尚不存在，需先生成前一个变量，再使用它预测下一个，因此通常按顺序推进。

如果某个实现生成时仍读入真实后续值，得到的不是无条件采样。若评价只看教师强制下单步预测而不看完整生成，也可能低估错误累积。应同时报告似然与任务相关样本评价，并检查生成历史一旦偏离训练前缀后模型如何表现。两种评价互补，不能任意取代。

## 3. 实验一：枚举联合分布并验证采样

<a id="gm-4-detail-9"></a>

### 3.1 一个二元自回归模型

设第一个二元变量取一的概率为零点七，第二个在前者为零时取一的概率为零点二，在前者为一时为零点九。四种组合可以完全枚举，联合分布归一化、边际概率与采样频率都可核验。这比先使用复杂网络更适合检查条件概率方向。

```python
import numpy as np
p1 = 0.7
p2 = {0: 0.2, 1: 0.9}
prob = {}
for a in (0, 1):
    for b in (0, 1):
        pa = p1 if a else 1 - p1
        pb = p2[a] if b else 1 - p2[a]
        prob[a, b] = pa * pb
assert np.isclose(sum(prob.values()), 1)
assert np.isclose(prob[1, 1], 0.63)
marginal_b = prob[0, 1] + prob[1, 1]
assert np.isclose(marginal_b, 0.69)
rng = np.random.default_rng(41)
a = (rng.random(30000) < p1).astype(int)
b = (rng.random(30000) < np.where(a == 1, p2[1], p2[0])).astype(int)
assert abs(a.mean() - 0.7) < 0.015
assert abs(b.mean() - 0.69) < 0.015
for state, p in prob.items():
    frequency = ((a == state[0]) & (b == state[1])).mean()
    assert abs(frequency - p) < 0.015
print('joint', prob, 'sample_marginals', a.mean(), b.mean())
```

注意第二个变量的总体概率不是两个条件概率的简单平均，而要按第一个变量的概率加权。这个例子也揭示依赖性：第二个变量与第一个高度相关，但联合分布仍由合法条件分布组成。若采样时把第二个变量独立按零点六九生成，边际分布看似正确，联合相关性却会错误，因此不能只核验边际直方图。

<a id="gm-4-detail-10"></a>

### 3.2 反向顺序与条件推断

同一联合分布也能先采第二个变量，再用贝叶斯公式采第一个。例如两者同时为一的概率除以第二个为一的边际概率，得到反向条件概率。两个生成顺序都能表示该有限联合分布，但对应的参数不同。若把正向条件直接拿来当反向条件，就会混淆事件与条件。

在高维模型里，完整联合分布可算，并不代表任意反向条件都能高效求得。缺失变量求和的组合数可能很大。自回归模型对前缀条件生成很自然，但对任意中间字段缺失的补全可能需要专门方法。方法选择应根据实际条件模式，而不是仅因为模型有联合密度就假设所有推断都简单。

<a id="gm4-binary-ledger"></a>

### 图解：二元模型的生成树与反向条件

![二元自回归模型的路径概率、相同边际反例与反向条件](images/04-binary-autoregressive-ledger.svg)

图中完整使用实验一的参数。先在起点选择 $`A`$，再沿所选分支选择 $`B`$。边上是条件概率，叶端是联合概率：例如 $`(A,B)=(0,1)`$ 的权重为 $`0.3×0.2=0.06`$，$`(1,1)`$ 的权重为 $`0.7×0.9=0.63`$。每个中间节点向外的条件概率和为一，因此四片叶子的权重也相加为一。若只沿一条路径相乘，会得到一个联合事件；若要求 $`B=1`$，就必须把来自不同 $`A`$ 分支的两片叶子相加。

反向生成没有使用新的联合分布。它只是先聚合 $`B`$ 的两种边际，再把每个边际内部重新归一化。完整的反向条件为

$$
\begin{aligned}
P(B=1)&=0.69,&
P(A=1\mid B=1)&=\frac{0.63}{0.69}=\frac{21}{23},\\[6pt]
P(B=0)&=0.31,&
P(A=1\mid B=0)&=\frac{0.07}{0.31}=\frac{7}{31}.
\end{aligned}
$$

按这些反向条件先采 $`B`$、后采 $`A`$，仍可恢复原来的四个联合概率；直接交换原条件中的字母则不能。这也是“联合概率可算”与“给定任意观测后的条件概率已经直接给出”之间的区别：后者还需要求边际并归一化，在这里只因只有四种状态而特别简单。

右表故意构造了一个错误生成器：保留 $`P(A=1)=0.7`$ 和 $`P(B=1)=0.69`$，却独立抽取两者。两个一维直方图都正确，$`P(A=1,B=1)`$ 却从 $`0.63`$ 变成 $`0.7×0.69=0.483`$。原模型的协方差为 $`0.63-0.7×0.69=0.147`$，独立模型则为零。由此可见，检查采样器不能停留在“每一列均值差不多”；至少还要检验联合频率或对应条件关系。

## 4. 变量替换公式从哪里来

<a id="gm-4-detail-12"></a>

### 4.1 一维概率守恒

设 $`x=g(z)`$ 是一维可微双射，逆映射为 $`z=f(x)`$，局部区间长度满足 $`dx\approx \vert g'(z)\vert dz`$。同一小区域的概率必须相等，即 $`p_X(x)dx\approx p_Z(z)dz`$，于是

$$
p_X(x)=p_Z(f(x))\vert f'(x)\vert .
$$

绝对值来自长度不允许为负。若映射方向反转，导数可以为负，但密度仍非负。公式要求在相应区域有可逆性；若映射多对一，就要对所有原像分支求和，而不能随便选一支。平方映射在整个实数轴上不是双射，正是一个典型反例。

<a id="sec-1-1"></a>

<a id="gm-4-detail-13"></a>

### 4.2 一维缩放与二维面积的手算

若 $`Z`$ 为标准正态，$`X=2Z+3`$，则 $`p_X(x)=\frac{\phi(\frac{(x-3)}{2})}{2}`$，log 密度为标准正态项减去 $`\log 2`$。尺度扩大使分布变宽，峰值密度降低；样本概率仍由区间积分得到。若漏掉二分之一，积分变成二，不再是概率密度。这个归一化检验能迅速发现行列式方向错误。

二维线性变换 $`x=Az+b`$ 把小方形变成平行四边形，面积缩放为 $`\vert \det A\vert `$。旋转的绝对行列式为一，只改变方向；对角缩放的行列式是各轴尺度乘积。剪切也可以保持面积，即使各坐标明显变化。只看输出数值是否变大，不能判断体积是否变化，必须看雅可比整体。

<a id="gm-4-detail-14"></a>

### 4.3 多维推导与符号方向

设 $`g:\mathbb R^d\to\mathbb R^d`$ 为可微双射，并在关心区域雅可比非奇异。微小体积满足 $`dx=\vert \det J_g(z)\vert dz`$，因此

$$
\log p_X(x)=\log p_Z(f(x))+\log\vert \det J_f(x)\vert
=\log p_Z(z)-\log\vert \det J_g(z)\vert .
$$

前一个公式使用数据到潜变量方向，后一个使用潜变量到数据方向。两者完全一致，因为逆雅可比行列式互为倒数。写代码时应在函数名和返回值里明确方向，不要仅命名为 forward 后凭习惯决定正负号；不同库的前向约定可能不同。

### 图解：可逆缩放如何保持概率质量

![可逆缩放如何保持概率质量](images/04-concept.svg)

上排两块密度矩形的总面积都为一，横轴单位相同。源变量 $`X\sim U(0,1)`$ 经 $`Y=2X`$ 后，支持长度变成二，密度变成二分之一。深色部分也逐一对应：$`[0,\frac14]`$ 的长度为四分之一、密度为一；它的像 $`[0,\frac12]`$ 长度为二分之一、密度为二分之一，所以两块深色区域的概率都为四分之一。保持的是对应区域的概率，而不是密度高度。

下排另用二维例子明确“体积”是什么意思：$`A=\begin{pmatrix}2&1\\0&1\end{pmatrix}`$ 将单位正方形变成顶点为 $`(0,0),(2,0),(1,1),(3,1)`$ 的平行四边形。行列式为二，因此每一片网格的面积都翻倍。原来面积四分之一的深色小方块变成面积二分之一的小平行四边形，乘以目标密度二分之一后，概率仍为四分之一。二维图采用相同的横纵单位，没有把形变后的图形重新缩放为一样大。连续单点的概率仍为零，密度变换不能与离散路径概率相混。耦合层怎样把这一修正推广到可学习变换，见 [Real NVP 第 3.2—3.3 节与图 2](https://arxiv.org/html/1605.08803v3#S3.SS2)。

**为什么不能把任意网络代入单支换元公式。** 体积修正只解决局部缩放；如果不同输入被折到同一输出，还必须合并全部原像的概率。

![平方映射把两个潜变量原像折到同一输出时必须相加两支密度](images/04-square-map-two-preimages.svg)

令 $`Z\sim N(0,1)`$、$`X=Z^2`$。对任何 $`x>0`$，原像同时有 $`\sqrt x`$ 与 $`-\sqrt x`$。将潜空间划为正、负两支，每支分别换元再相加，得到

$$
p_X(x)=\frac{\phi(\sqrt x)}{2\sqrt x}+\frac{\phi(-\sqrt x)}{2\sqrt x}
=\frac{\phi(\sqrt x)}{\sqrt x},\qquad x>0.
$$

左图的同一水平线在两个位置穿过抛物线；右图实线保留两支，虚线错误地只计算正支。例如 $`x=1`$，正确密度为 $`0.241971`$，单支仅为 $`0.120985`$；漏支公式在整个正轴的积分只有二分之一。零点的普通可逆导数公式失效，但 $`P(X=0)=P(Z=0)=0`$：密度在靠近零时发散不等于在那里出现概率原子。标准可微双射流避免原像枚举；若主动采用分段可逆或混合流，则需明确分支集合及其概率，不能宣称与单支公式完全一样。一般分支求和形式见 [Papamakarios 等综述第 5.2 节、式 93](https://arxiv.org/html/1912.02762v1#S5.SS2)，本图用平方映射将求和对象具体化。

### 对照表：可逆缩放怎样改变密度而保持总质量

| 变量变换 | 区间长度 | 区间内密度 | 积分质量 |
| --- | --- | --- | --- |
| x 在零至一均匀 | 1 | 1 | 1 |
| y=2x | 2 | 二分之一 | 1 |

**说明。** 把零至一上的均匀变量放大两倍，支持区间长度翻倍，密度必须减半，总概率质量才能保持一。换元公式中的雅可比正是修正这种体积变化；不能只把样本坐标放大，却继续沿用原来的密度高度。

**适用条件。** 多维情况使用雅可比行列式绝对值。流模型要求可逆与可计算的体积修正，不能把任意降维网络当作同样的密度变换。

## 5. 仿射耦合让逆与 log 行列式都可计算

<a id="gm-4-detail-16"></a>

### 5.1 三角雅可比的结构

把输入拆成两部分，令 $`y_a=x_a`$，$`y_b=x_b\odot\exp(s(x_a))+t(x_a)`$。第一部分保持不变，第二部分的尺度与平移只依赖第一部分。雅可比是块三角矩阵，其对角块为单位阵和对角指数尺度，因此 log 绝对行列式为 $`s(x_a)`$ 各分量之和。内部网络可以很复杂，却不需要计算其完整行列式。

逆变换直接得到 $`x_a=y_a`$，再计算 $`x_b=(y_b-t(y_a))\odot\exp(-s(y_a))`$。不需要对内部网络求逆，因为逆过程仍能从保持不变的那部分计算相同尺度和平移。这是耦合结构的核心价值。若让尺度依赖同时被变换的未知部分，就不再能直接套用这个逆公式。

![尺度变换中的体积修正](images/04-flow-volume-correction.svg)

**尺度变换中的体积修正。** 本图固定正尺度 a、z 为标准正态。变量替换给出 log pₓ(x)=log p_z(x/a)−ln a，图只画后面的体积修正。a 大于一时质量摊到更宽空间，密度需要下降；小于一时相反。修正项独立于具体 x，但完整密度中的潜坐标也同时变为 x/a，不能只减 ln a 却仍代入原来的 x。

$$
\ln p_X(x)=\ln p_Z\!\left(\frac{x}{a}\right)-\ln a,\qquad a>0.
$$

<a id="gm-4-detail-17"></a>

### 5.2 多层组合与交替分区

单层保留一部分不变，表达能力有限。可以交替变换不同子集，或插入固定置换，使所有维度逐渐互相影响。组合 $`f=f_K\circ\cdots\circ f_1`$ 的 log 行列式等于各层在对应中间状态上的 log 行列式之和。逆映射则必须倒序执行各层逆，不能按原顺序逐层求逆。

固定置换矩阵的绝对行列式为一，所以 log 绝对行列式为零，即使其行列式符号为负。更一般的可逆线性混合会产生非零 log 行列式，需要稳定参数化与计算。耦合层和混合层的设计共同决定信息传播与成本。增加层数可以提高灵活性，也增加数值误差和训练难度。

<a id="gm-4-detail-18"></a>

### 5.3 限制尺度以控制数值范围

指数尺度理论上始终为正，但极端正值会溢出，极端负值会接近奇异。常用有界函数限制 log 尺度，既保持可逆又改善数值稳定性。这个限制同时约束每层可实现的体积变化，可能需要更多层表达强变换。稳定性与表达能力之间的取舍应通过独立似然和逆误差观察，而不是仅看训练是否不报错。

平移网络不直接贡献三角行列式，却仍影响输出、基分布密度和梯度。不能因为它不在 log 行列式公式里就冻结它。类似地，尺度网络既影响变换坐标，也影响体积项，两个路径的梯度都必须保留。手写密度时若对尺度错误地停止梯度，损失仍可下降，但优化目标已经错误。

<a id="deep-dive-2"></a>

<a id="gm-4-detail-19"></a>

### 5.4 自回归流与计算方向的交换

某些流使用自回归结构产生逐维尺度与平移。若数据到潜变量方向的每维参数由已知数据前缀决定，密度计算可以并行，而采样需要逐维求解；相反方向的设计可以让采样更快，却使对任意观测求逆更顺序化。具体名称和实现要根据方向核对，不能只记“自回归流很快”。

这与普通自回归概率模型具有联系，但二者不是完全相同的表示。普通模型直接指定条件分布，流则通过可逆变换与基分布定义连续密度。单调逐维变换可以构造丰富条件族，但其可逆性、导数和边界都要维护。方法比较应列出训练评分、采样和逆映射各自的复杂度。


<a id="visual-mechanism-generativemodels-04"></a>

### 图解：仿射耦合一部分坐标固定另一部分可逆变换

![仿射耦合一部分坐标固定另一部分可逆变换](images/04-mechanism.svg)

**先看整张网格，再跟住一个点。** 三个面板依次画输入、第一层和第二层后的同一批网格线，横纵单位保持一致。这里实际使用的两层变换为

$$
b_1=b\exp(0.3\tanh a)+0.2a^2,
\qquad
a_2=a\exp(-0.2\tanh b_1)+0.1b_1.
$$

第一层固定每点的横坐标 $`a`$，只沿竖直方向移动：固定 $`a`$ 的整根竖线仍在原横坐标，原先水平的线则随 $`a`$ 弯曲并改变间距。第二层固定的是中间状态 $`b_1`$，只沿水平方向移动。它并不保证原始网格的水平线最后仍水平，因为这些线经过第一层后已经不是等 $`b_1`$ 线。蓝线是坐标网格的像，不是密度等高线；橙色区域是一块有限小区域的完整像，不把它的面积比当作中心点行列式的精确替代。

图中橙点使用下节 `transform` 的同一输入 $`v=(0.7,-0.4)`$。第一层保留 $`a=0.7`$，得到 $`s_1=0.3\tanh(0.7)\approx0.181310`$，再把第二坐标变成 $`b_1\approx-0.381515`$。第二层从这个**已更新的** $`b_1`$ 计算 $`s_2\approx0.072804`$，最后得到 $`(a_2,b_1)\approx(0.714713,-0.381515)`$。如果第二层仍使用原始 $`b=-0.4`$，就已经换了函数；维度合法也不意味着计算对象正确。

**为什么局部体积容易算。** 将未展开的非对角导数记为星号，两层雅可比的结构是

$$
J_1=\begin{pmatrix}1&0\\ *&e^{s_1}\end{pmatrix},
\qquad
J_2=\begin{pmatrix}e^{s_2}&*\\ 0&1\end{pmatrix}.
$$

星号通常不为零，但第一层是下三角、第二层是上三角，所以各层行列式分别是 $`\exp(s_1)`$ 和 $`\exp(s_2)`$。乘积的雅可比未必仍为三角矩阵，仍有

$$
\log\lvert\det J_g(v)\rvert
=s_1+s_2
\approx0.2541147956,
\qquad
\lvert\det J_g(v)\rvert\approx1.2893198040.
$$

逆过程先把 $`a_2`$ 恢复为 $`a`$，此时 $`b_1`$ 已知；再利用恢复出的 $`a`$ 撤销第一层，得到原始 $`b`$。不需要对尺度网络或双曲正切函数求逆。逆方向的 log 绝对行列式是 $`-0.2541147956`$，与生成方向相消。注意这只是局部体积的互逆，不是说两个坐标的数值改变量也彼此相消。

若把输入 $`v`$ 视为标准二维高斯潜变量，$`\log p_Z(v)=-\log(2\pi)-0.325\approx-2.1628770664`$；生成点的 log 密度还要减去体积项，得到约 $`-2.4169918620`$。这一步把“坐标往返正确”和“密度方向正确”连在一起：漏掉行列式不会破坏重建，却会给出错误评分。下节代码分别验证逆映射、体积项和梯度，正是因为它们不能互相替代。仿射耦合及其逆的原始结构见 [Real NVP 第 3.2–3.3 节](https://arxiv.org/html/1605.08803v3#S3.SS2)。

## 6. 实验二：归一化、逆映射与多层雅可比

<a id="gm-4-detail-21"></a>

### 6.1 一维积分和二维自动微分核对

下面先对缩放正态密度做数值积分，再构造两个交替更新坐标的耦合层。用自动微分直接计算二维雅可比，与手算 log 行列式求和比较；再验证逆映射和反向 log 行列式抵消。数值积分只检验这一维例子的归一化，多维流的归一化由满足条件的变量替换定理保证。

```python
import math
import numpy as np
import torch
from scipy.integrate import quad
torch.set_num_threads(1)
def density(x):
    z = (x - 3.0) / 2.0
    return math.exp(-0.5*z*z) / (2.0*math.sqrt(2*math.pi))
area, error = quad(density, -np.inf, np.inf)
assert abs(area - 1.0) < 1e-9

def transform(v):
    a, b = v[0], v[1]
    s1 = 0.3 * torch.tanh(a)
    b1 = b * torch.exp(s1) + 0.2*a*a
    s2 = -0.2 * torch.tanh(b1)
    a2 = a * torch.exp(s2) + 0.1*b1
    return torch.stack([a2, b1]), s1+s2

def inverse(v):
    a2, b1 = v[0], v[1]
    s2 = -0.2 * torch.tanh(b1)
    a = (a2 - 0.1*b1) * torch.exp(-s2)
    s1 = 0.3 * torch.tanh(a)
    b = (b1 - 0.2*a*a) * torch.exp(-s1)
    return torch.stack([a, b]), -s2-s1
v = torch.tensor([0.7, -0.4], dtype=torch.float64, requires_grad=True)
y, logdet = transform(v)
back, inverse_logdet = inverse(y)
jac = torch.autograd.functional.jacobian(lambda u: transform(u)[0], v)
sign, actual = torch.linalg.slogdet(jac)
assert sign > 0
assert torch.allclose(actual, logdet, atol=1e-12)
assert torch.allclose(back, v, atol=1e-12)
assert torch.allclose(logdet + inverse_logdet, torch.zeros_like(logdet), atol=1e-12)
assert torch.autograd.gradcheck(lambda u: transform(u)[0], (v,))
print('density_integral', area, 'jacobian_logdet', actual.item())
```

这类小维度直接雅可比检验适合验证公式，但不应成为高维训练的常规路径。完整行列式计算成本很高，正是结构化流要避免的部分。正确开发流程是在小维度核对结构公式，再在高维使用高效解析项，并用随机逆检验和有限梯度检查保留必要诊断。

<a id="gm-4-detail-22"></a>

### 6.2 需要继续测试的边界

本实验只在一个普通点检查梯度，不能保证所有输入都稳定。应加入大幅值、接近边界和不同批量形状，观察逆误差是否随尺度增长。对随机变换还需保证逆过程使用相同状态；带训练时随机性的层不能未经处理就被当成确定双射。归一化层的统计量若依赖当前批量，其密度解释也需要仔细定义。

浮点逆误差不为精确零并不意味着理论上不可逆。应根据精度、尺度和条件数设定容差，并区分正常舍入与指数溢出。若误差随层数急剧放大，可以检查每层尺度、输入范围和累计条件数，而不是只在最终输出上放宽断言直到通过。容差是测量协议，不应成为掩盖错误的工具。

## 7. 最大似然训练的真实含义

<a id="gm-4-detail-24"></a>

### 7.1 目标与 KL 方向

在固定数据分布下，期望负 log 密度可分解为数据微分熵加上从数据到模型的 KL 散度，前提是相关量定义良好。最小化它会惩罚模型对真实数据区域给出过低密度，但有限样本只能近似这一期望。模型可能在训练点附近制造尖峰，因此独立测试和模型约束仍不可缺少。

所谓精确似然，通常指给定模型和观测，log 密度可按明确公式直接计算，区别于需要变分下界或不易计算归一化常数的方法。它不表示优化找到了全局最优，也不表示数据分布已被精确恢复。计算精确性、统计误差和优化误差是三个不同层次，应在研究报告中分开。

<a id="gm-4-detail-25"></a>

### 7.2 覆盖与样本质量

数据到模型方向的 KL 对遗漏真实数据模式有强惩罚，但实际有限容量和优化可能仍漏掉模式。高似然还可能偏重低层统计，未必对应人类感知最重要的结构。生成评价需要同时检查模式覆盖、相关结构和任务约束，不能仅凭几张漂亮样本或一个平均似然决定模型全面优劣。

对于有真值的人工数据，可以检验均值、协方差、条件方差、尾部概率和多峰比例。只比较边际均值方差，可能漏掉弯曲依赖；只画散点，也可能漏掉尾部差异。本章训练实验采用已知非线性可逆生成机制，使部分结构能够从公式推导，再与模型学习结果对照。

<a id="gm-4-detail-26"></a>

### 7.3 对数行列式为什么防止简单压缩作弊

若只把所有样本映到基分布高密度中心，而忽略体积项，模型会倾向于缩小数据坐标。正确密度公式同时加入变换体积补偿，防止把坐标压缩误当成无成本提高概率。对一维 $`z=ax`$，基密度项鼓励小 $`a`$，但 log 行列式为 $`\log\vert a\vert `$，它会惩罚接近零的压缩。

这个平衡不等于永远防止过拟合。高表达模型仍可以在样本附近局部变形，在其他区域补偿体积，从而提高有限样本似然。体积补偿保证分布归一化，却不替代泛化控制。理解这一点有助于避免把数学正确的密度公式当成自动的数据质量或统计可靠性保证。

## 8. 实验三：训练一个可解释的人工流

<a id="gm-4-detail-28"></a>

### 8.1 数据机制和模型族

先从二维标准正态采样，让第一维平移缩放，第二维加上第一潜变量平方的弯曲项，并具有随第一潜变量变化的尺度。这个变换可逆，目标密度已知。模型学习平移、第一维尺度、第二维尺度系数和弯曲系数四个参数，足以包含真实机制。独立测试样本使用不同随机抽样，避免把训练拟合当作泛化。

```python
import math
import torch
torch.set_num_threads(1)
torch.manual_seed(59)
dtype = torch.float64

def make_data(n, seed):
    gen = torch.Generator().manual_seed(seed)
    z = torch.randn(n, 2, generator=gen, dtype=dtype)
    x0 = 0.8 + 1.3*z[:, 0]
    x1 = torch.exp(0.35*torch.tanh(z[:, 0]))*z[:, 1] + 0.7*(z[:, 0]**2-1)
    return torch.stack([x0, x1], dim=1)

train = make_data(2048, 61)
test = make_data(4096, 67)
param = torch.nn.Parameter(torch.zeros(4, dtype=dtype))
def encode(x):
    mu, logscale, a, b = param.unbind()
    z0 = (x[:, 0]-mu)*torch.exp(-logscale)
    s = a*torch.tanh(z0)
    z1 = (x[:, 1]-b*(z0*z0-1))*torch.exp(-s)
    z = torch.stack([z0, z1], dim=1)
    logdet = -logscale-s
    return z, logdet

def decode(z):
    mu, logscale, a, b = param.unbind()
    x0 = mu + torch.exp(logscale)*z[:, 0]
    s = a*torch.tanh(z[:, 0])
    x1 = torch.exp(s)*z[:, 1] + b*(z[:, 0]**2-1)
    return torch.stack([x0, x1], dim=1)

def nll(x):
    z, ld = encode(x)
    return (0.5*z.square().sum(1)+math.log(2*math.pi)-ld).mean()
initial = nll(test).item()
opt = torch.optim.Adam([param], lr=0.025)
for _ in range(1200):
    opt.zero_grad(); loss = nll(train)
    loss.backward()
    assert torch.isfinite(param.grad).all()
    opt.step()
final = nll(test).item()
with torch.no_grad():
    encoded, _ = encode(test[:32])
    assert torch.allclose(decode(encoded), test[:32], atol=1e-10, rtol=1e-10)
    true = torch.tensor([0.8, math.log(1.3), 0.35, 0.7], dtype=dtype)
    assert torch.max(torch.abs(param-true)) < 0.15
    assert final < initial - 0.3
    z = torch.randn(10000, 2, dtype=dtype)
    samples = decode(z)
    zback, _ = encode(samples)
    assert torch.allclose(zback, z, atol=1e-9, rtol=1e-9)
    assert torch.isfinite(samples).all()
print({'test_nll_before': initial, 'test_nll_after': final,
       'learned_parameters': param.detach().tolist()})
```

本次 CPU 运行中，独立测试负对数密度从约四点零五七降到三点一零四。四个参数分别约为零点八三五、零点二七六、零点三四八和零点七二一，与已知机制相近；双向重建与有限梯度断言全部通过。这是一次固定人工分布上的机制检验，不代表真实图像或其他高维任务的性能。

这里的模型族特意包含真实机制，所以参数接近真值是合理预期；真实应用往往不存在这种保证。训练损失和测试损失可能不同，有限样本最优参数也不会恰好等于生成参数。实验断言使用有余量的误差阈值，目的在于发现实现或优化严重失败，而不是声称一次随机训练提供了严格统计置信界。

<a id="gm-4-detail-29"></a>

### 8.2 如何解读学到的形状

第一潜变量控制第一维位置，也通过平方项改变第二维均值，因此数据形成弯曲关系。第二维噪声尺度随第一潜变量双曲正切变化，体现异方差。只拟合一个二维高斯，可能近似整体协方差，却无法完整表达这种条件弯曲和方差变化。流的可逆结构在这个例子中正好匹配机制，因此容易解释。

进一步研究可以故意错设模型：固定弯曲系数为零、固定尺度系数为零，分别观察独立测试 NLL 和条件残差。应按相同训练数据、步数与选择协议比较，不能给完整模型更长训练后把差异全部归因于结构。还可以生成不在模型族内的多峰数据，检验表达限制与优化问题怎样区分。

### 图解：人工流的网格、条件均值与异方差

![实验三人工流的潜空间网格、输出弯曲、条件均值与标准差](images/04-artificial-flow-geometry.svg)

$$
\begin{aligned}
X_0&=0.8+1.3z_0,\\[4pt]
X_1\mid Z_0=z_0
&\sim
\mathcal N\!\left(
0.7(z_0^2-1),

\right).
\end{aligned}

这里正态分布的第二参数是**方差**。图下表列出的条件标准差则是 $`\sigma(z_0)=\exp(0.35\tanh z_0)`$。把 $`0.35`$ 直接写到方差公式的指数中，就会漏掉平方。因为 $`X_0`$ 与 $`Z_0`$ 一一对应，也可以在给定 $`X_0=x_0`$ 后以 $`z_0=\frac{x_0-0.8}{1.3}`$ 代入，得到同一条件分布。

从左图追踪横线 $`z_1=0`$，它变成右图的蓝色均值曲线；$`z_1=\pm1`$ 则变成浅蓝带的两条边界。这个带在每个固定 $`z_0`$ 的截面上，都包含约 $`68.27\%`$ 的条件概率，但其高度随 $`z_0`$ 改变。$`z_0=-1`$ 与 $`z_0=1`$ 的条件均值都为零，标准差却分别约为 $`0.766012`$ 与 $`1.305463`$。只展示一条弯曲均值线，会把本例的一半结构——异方差——隐藏起来。

$$
\lvert\det J_g(z)\rvert
=1.3\exp\!\left(0.35\tanh z_0\right)
$$

解释输出单元为何一侧变宽、另一侧变窄。图中 $`z_0=-1`$、$`0`$、$`1`$ 对应的 log 体积项分别约为 $`-0.004194`$、$`0.262364`$、$`0.528922`$。平方平移项可以强烈弯曲网格，却不直接改变三角雅可比的行列式；体积变化来自两个尺度因子。

这也给错设模型提供了更具体的诊断。若忽略弯曲项但仍除以真实标准差，候选残差

$$
\widetilde Z_1
=\frac{X_1}{\sigma(Z_0)}
=Z_1+\frac{0.7(Z_0^2-1)}{\sigma(Z_0)}
$$

在各个截面上仍保留条件均值偏差；若减去正确均值但错误地把尺度固定为一，残差的条件均值虽为零，条件方差却仍为 $`\exp(0.7\tanh Z_0)`$。这两种失败应分别用条件均值和条件方差识别，不能只看总体残差是否近似居中。把数据映回潜变量后诊断模型拟合的思路可参见 [MAF 第 3.1 节](https://arxiv.org/html/1705.07057v4#S3.SS1)；本图的数值与曲线完全来自本章人工机制。

## 9. 连续流用于离散数据时的去量化

<a id="gm-4-detail-31"></a>

### 9.1 为什么直接给整数点密度不够

图像像素是有限整数，而连续流给出的是相对于体积的密度。在整数点上计算密度，不等于该整数事件的概率。若每个整数对应一个单位小格，离散概率应是连续密度在小格上的积分。一个密度可以在整数点附近形成非常窄的尖峰，提高点密度却不改善合理的离散建模，这正是需要区分两种对象的原因。

均匀去量化给整数数据加上单位区间噪声，把每个离散值扩展到一个小格。训练连续密度等价于优化某种离散概率下界，而非自动得到精确离散似然。若还把数据缩放到零一附近，需要加入缩放的雅可比常数。不同论文或代码若是否计入这些常数不一致，报告的每维位数就不可直接比较。

<a id="sec-5"></a>

<a id="gm-4-detail-32"></a>

### 9.2 Jensen 下界的完整形式

设离散观测为 $`v`$，对应小格为 $`v+[0,1)^d`$，连续密度为 $`p`$，离散概率 $`P(v)=\int_{[0,1)^d}p(v+u)du`$。若 $`u`$ 均匀，则由对数凹性有 $`\log P(v)\geq E_u\log p(v+u)`$。因此最大化带均匀噪声的连续 log 密度，提高的是这个下界，二者差距来自小格内密度变化。

更一般地，若使用条件噪声密度 $`q(u\mid v)`$，可以把积分写成对 $`q`$ 的期望，得到 $`\log P(v)\geq E_q[\log p(v+u)-\log q(u\mid v)]`$。需要 $`q`$ 的支持与积分区域匹配，并对重要区域有适当覆盖。学习噪声分布可能收紧下界，但引入新参数与优化问题。此时“流本身密度精确”仍不意味着离散概率积分精确。

<a id="sec-5-1"></a>

<a id="gm-4-detail-33"></a>

### 9.3 从缩放到每维位数

若 $`y=\frac{(v+u)}{K}`$，则从单位小格变量到缩放变量的雅可比绝对值为 $`K^{-d}`$。连续 log 密度要减去 $`d\log K`$ 才与原单位小格上的密度对应。再把负 log 概率除以维度和 $`\log 2`$，得到每维位数的协议。符号方向可以用最简单的均匀分布检查：共有 $`K^d`$ 个等概率离散值时，每维应需要 $`\log_2 K`$ 位。

预处理若还有对数几率变换、裁剪或边界收缩，也应加入相应雅可比与支持说明。裁剪通常不可逆，会把多个原始值合并，不能只补一个普通双射行列式就假装无损。应保存原始数据到模型输入的完整函数，逐步判断每步是可逆变换、随机增广还是信息丢弃，才能正确解释最终似然。

<a id="gm4-dequantization-ledger"></a>

### 图解：同一分箱的质量、下界与噪声后验

![二元分箱的连续密度积分、均匀去量化下界与真实条件噪声](images/04-dequantization-ledger.svg)

用一个可精确积分的例子把第 9 节和第 15 节连接起来：设 $`Y`$ 在 $`[0,1)`$ 上具有密度 $`p_Y(y)=2y`$，按 $`V=\lfloor2Y\rfloor`$ 分成两个合法整数。这里连续支持恰好被两个格子覆盖，故不会遗漏区间外质量。分箱概率是

$$
\begin{aligned}
P(V=0)&=\int_0^{\frac12}2y\,dy=\frac14,\\[6pt]
P(V=1)&=\int_{\frac12}^{1}2y\,dy=\frac34.
\end{aligned}
$$

图上三角形的两部分面积才是整数事件概率；某一点的曲线高度不能代替这些面积。改用单位格坐标 $`R=2Y=V+U`$ 时，$`p_R(r)=\frac r2`$，因此给定离散记录 $`v`$，均匀去量化训练使用的期望是

$$
L_v
=\int_0^1
\left[
\log p_Y\!\left(\frac{v+u}{2}\right)-\log2
\right]du
=\int_0^1\log\frac{v+u}{2}\,du.
$$

这一步的 $`-\log2`$ 不是可随意忽略的记账习惯，而是从缩放坐标恢复单位格密度的雅可比。计算可得 $`L_0=-1-\log2\approx-1.693147`$，$`L_1=\log2-1\approx-0.306853`$；对应的精确 log 质量分别约为 $`-1.386294`$ 和 $`-0.287682`$。两者的差距都非负，却不相同，因为两个小格内部的相对密度变化不同。$`v=0,u=0`$ 处密度为零，但这个端点是零测集，$`\int_0^1\log u\,du=-1`$ 仍有限；实现数值估计时应避免把恰好取到的端点直接送进 $`log`$。

格内真实条件噪声可以直接归一化求出：

$$
\begin{aligned}
p(u\mid V=0)&=2u,\\[4pt]
p(u\mid V=1)&=\frac{2(1+u)}{3},
\qquad 0\leq u<1.
\end{aligned}
$$

因此从均匀噪声 $`q(u\mid v)=1`$ 出发，两个差距正是

$$
\begin{aligned}
\operatorname{KL}(q\Vert p(\cdot\mid V=0))
&=1-\log2
\approx0.306853,\\[4pt]
\operatorname{KL}(q\Vert p(\cdot\mid V=1))
&=1+\log3-3\log2
\approx0.019171.
\end{aligned}
$$

若让去量化器采用图中的蓝线或橙线，即对应的真实条件密度，那么 $`\log p_R(v+u)-\log q(u\mid v)`$ 几乎处处等于常数 $`\log P(v)`$，下界便达到精确 log 质量。这解释了“学去量化噪声为什么有帮助”：它匹配格内条件分布，从而减少变分差距；并非把一个较大的点密度直接解释为较大的离散概率。一般化推导见 [Flow++ 第 3.1 节](https://arxiv.org/html/1902.00275v2#S3.SS1)，图中二元三角密度是为逐项复算构造的例子。

## 10. 可逆性带来的限制与机会

<a id="gm-4-detail-35"></a>

### 10.1 维度、支持与拓扑

标准流通常在相同维度之间使用可微双射。若基分布在整个实空间密度严格为正，连续双射推送后也不会轻易产生真正的断开零密度区域。它可以把某些区域密度压得很低，近似多峰，但要精确表达断开支持或严格低维流形，可能需要不同基分布、增广维度或其他模型设计。近似能力与精确支持性质应分开讨论。

真实数据如果严格位于低维曲面，而模型是全维连续密度，微分熵和最大似然可能出现退化问题。加入测量噪声可以建立全维观测模型，但噪声大小成为假设。不能一边把数据当无噪声流形，一边直接用普通全维密度解释全部概率。明确观测过程通常比单纯增加网络层数更重要。

<a id="gm-4-detail-36"></a>

### 10.2 潜空间不自动具有语义

流提供从样本到潜变量的确定逆映射，便于重建和插值。但基分布坐标并不自动对应人类概念。许多不同可逆变换都可能产生相似似然，潜变量含义存在不唯一性。沿某个潜坐标移动得到平滑变化，是可观察现象，不等于该坐标已识别某个真实因果因素。

若要研究可控生成，应定义希望控制的属性、独立测量器和保持不变的其他属性。观察属性变化是否局部、稳定且跨样本一致，并检查是否损害样本有效性。仅展示几个成功插值容易产生选择偏差。潜空间探索很有启发性，但语义或因果结论需要更强监督与实验设计。

<a id="gm-4-detail-37"></a>

### 10.3 高密度不等于典型或正常

高维分布中，最高密度点可能处于很小体积区域，而大多数概率质量位于一个壳层。标准高斯的原点密度最高，但随机样本通常不会靠近原点。异常检测若只按点密度排序，可能忽略这种密度与体积的差异。数据预处理和低层统计也可能主导评分，使某些外部分布获得意外高似然。

这不表示似然没有价值，而是说明异常事件必须根据任务定义。可以结合似然比、典型性、表征和任务相关异常标签评价，但每种方法都有假设。不能因为模型具有精确密度，就宣布它天然知道哪些样本语义异常。应在代表性的正常与异常分布上验证，并检查阈值迁移。

![二十维标准高斯的点密度与半径概率密度](images/04-density-radius-typicality.svg)

**同一个高斯，两个不同的纵轴。** 左图画相对点密度 $`\frac{p(x)}{p(0)}=\exp(-\frac{r^2}{2})`$，其中 $`r=\|x\|`$；它在原点最高。右图画随机半径 $`R=\|X\|`$ 的密度。对于 $`d`$ 维标准正态，把半径为 $`r`$ 的整层球面面积计入后，

$$
f_R(r)=\frac{2^{1-\frac d2}}{\Gamma(\frac d2)}
r^{d-1}e^{-\frac{r^2}{2}},
\qquad r\ge0.
$$

当 $`d>1`$，对 log 径向密度求导得 $`\frac{d-1}{r}-r`$，峰值在 $`r=\sqrt{d-1}`$，与点密度的峰值零不同。图取 $`d=20`$：数值积分得到 $`P(R\le1)\approx1.70967\times10^{-10}`$，而 $`P(3\le R\le6)\approx0.967526`$。右侧橙色阴影是后一个区间的面积；左图的曲线面积不具有这个概率含义。

这说明“更高点密度”与“更常见的半径事件”为什么可能背离。它仍不直接提供现实数据的异常阈值：若异常也刻意落在相同半径壳层，仅检查半径同样会失明。典型性应被当作一个明确分布下的事件统计，结合所关心的异常机制检验，而非替代语义判断的通用答案。

## 11. 进阶练习与详细解答

<a id="gm-4-detail-39"></a>

### 11.1 题一：密度大于一

题目：均匀分布在零到零点二之间，密度是多少？零点一这个单点的概率是多少？

解答：密度为五，区间积分为一；单点概率为零。密度的数值乘以区间长度才对应小区间概率，它不是单点概率。若改用不同长度单位，密度数值还会变化。因此负 log 密度可以为负，不应为了让损失非负而随意裁剪。离散概率质量与连续密度必须在训练和报告中明确区分。

<a id="gm-4-detail-40"></a>

### 11.2 题二：反向条件概率

题目：实验一中第二变量为一时，第一变量为一的概率是多少？

解答：两者同时为一的概率为零点六三，第二变量为一的边际为零点六九，反向条件为二者之比，约零点九一三。它不是原先的零点九，因为事件条件已经交换。这个计算说明联合分布允许推导不同方向条件，但高维情况下相应边际可能需要昂贵求和或积分，不能据此假设任意补全都高效。

<a id="gm-4-detail-41"></a>

### 11.3 题三：漏掉尺度因子

题目：把 $`X=2Z`$ 的密度误写成 $`\phi(\frac{x}{2})`$，会发生什么？

解答：积分为二，不再归一化。正确密度应除以二，log 密度应减去 $`\log 2`$。可以通过变量替换直接算积分，也可以用数值积分检查。这个错误常来自混淆生成方向和评分方向；最简单的线性缩放测试应作为任何流实现的早期断言。

<a id="gm-4-detail-42"></a>

### 11.4 题四：负行列式

题目：二维交换坐标的行列式为负一，是否导致负密度？

解答：不会，密度公式使用绝对行列式，体积缩放为一，log 绝对行列式为零。符号表示方向翻转，不表示负概率。数值实现可使用返回符号和 log 绝对值的稳定接口，并单独检查非奇异。直接对负行列式取普通对数会产生无效数值。

<a id="gm-4-detail-43"></a>

### 11.5 题五：为什么耦合不需要逆网络

题目：尺度和平移由复杂神经网络给出，为什么逆映射仍可直接计算？

解答：它们只依赖保持不变的坐标部分，逆时这部分已经可见，可以重新运行同一个网络得到相同参数。随后对被变换部分做逐元素减法和除法。若网络依赖被变换后的未知原坐标，直接逆公式就不成立。可逆性来自依赖结构，不是因为神经网络本身恰好可逆。

<a id="gm-4-detail-44"></a>

### 11.6 题六：多层逆的顺序

题目：先做甲层再做乙层，逆变换应该先逆哪一层？

解答：先逆乙，再逆甲。函数复合的逆顺序必须倒过来，log 行列式也在相应中间状态计算。只有某些特殊可交换变换才可能碰巧按原顺序得到同样结果，不能把这种偶然当一般规则。实现应保存或重建正确中间状态，并用随机样本往返测试。

<a id="gm-4-detail-45"></a>

### 11.7 题七：精确似然的边界

题目：模型能直接算 log 密度，是否证明它达到真实分布？

解答：没有。它只说明给定参数时评分计算可处理。有限数据估计、模型族限制和优化误差仍然存在。还需要独立测试和结构诊断。精确评分也不保证任意边际或条件推断容易，因为这些任务可能涉及高维积分。应将计算性质与统计质量分开陈述。

<a id="gm-4-detail-46"></a>

### 11.8 题八：自回归的训练泄漏

题目：训练时同时计算所有位置，为什么不一定泄漏未来？

解答：若因果掩码与输入标签对齐正确，每个输出只能依赖允许前缀，向量化计算不改变条件结构。泄漏来自错误可见性，而不是来自并行本身。可以扰动未来 token，断言更早位置 logits 不变；再检查真实标签没有以同一位置输入直接暴露。这样的不变量比只观察训练 loss 更可靠。

<a id="gm-4-detail-47"></a>

### 11.9 题九：连续密度与整数概率

题目：某整数像素点连续密度为三，能否说这个像素值概率为三？

解答：不能。整数事件应对应一个离散质量，若由连续模型诱导，需要对相应小格积分。点密度可以大于一，而概率不能。去量化训练给出对离散概率的下界目标，仍需说明噪声与缩放。直接比较整数点密度可能奖励不合理的尖峰。

<a id="gm-4-detail-48"></a>

### 11.10 题十：Jensen 不等式方向

题目：均匀去量化中，期望 log 密度是离散 log 概率的上界还是下界？

解答：是下界，因为对数是凹函数，期望对数不大于对期望取对数。若小格内密度为常数，两者相等；变化越大，差距可能越明显。把不等式写反会错误宣称训练评分过于乐观或过于悲观，因此应从最简单的两点平均例子核对方向。

<a id="gm-4-detail-49"></a>

### 11.11 题十一：单位转换与似然

题目：把一维数据从米改成厘米，模型密度怎样调整？

解答：新数值坐标扩大一百倍，密度除以一百，log 密度减去 $`\log 100`$。对应物理区间的概率不变。若两模型使用不同单位却直接比较 NLL，差异含有坐标常数而非纯建模质量。多维各轴转换时补偿项按 log 尺度求和。

<a id="gm-4-detail-50"></a>

### 11.12 题十二：体积项是否足够防过拟合

题目：加入正确 log 行列式后，能否永远避免训练点尖峰？

解答：不能。它保证整体归一化和坐标概率守恒，但灵活模型仍能在训练点附近集中质量，在其他区域补偿。有限样本似然可能继续上升而泛化变差。需要独立数据、合理噪声与容量约束，并检查尾部和未见区域。数学合法分布不等于统计上可靠分布。

<a id="gm-4-detail-51"></a>

### 11.13 题十三：全支持基分布的限制

题目：标准正态经全空间光滑双射，能否精确变成两个完全断开的非零密度区域，中间严格零密度？

解答：在通常的连续双射和正密度条件下不能直接实现这种支持改变。可以让中间密度非常低来近似，但精确零区域与拓扑结构受限制。若任务需要严格断开支持，应考虑不同基分布或其他结构。近似足够好与数学上精确表示是不同层次。

<a id="gm-4-detail-52"></a>

### 11.14 题十四：高密度与典型性

题目：高维标准高斯原点密度最高，为什么典型样本不在原点？

解答：概率质量由密度和体积共同决定。原点附近小球体积很小，许多样本位于半径接近维度平方根的区域。点密度排序不能完整描述典型性。因此异常检测需要明确事件和数据分布，不应把最高密度位置当作所有正常样本应靠近的中心。

<a id="gm-4-detail-53"></a>

### 11.15 题十五：两维边际都正确是否足够

题目：两个生成器具有相同的一维直方图，是否表示联合分布相同？

解答：不够。它们可能具有完全不同的相关、非线性依赖或尾部共同事件。实验一独立采样可以保留边际却破坏相关。应检查联合统计、条件分布和任务相关关系。对于人工流，可利用已知机制计算条件残差，让诊断比肉眼散点更明确。

<a id="sec-6-1"></a>

<a id="gm-4-detail-54"></a>

### 11.16 题十六：容易采样是否就能算似然

题目：给一个随机噪声经过普通神经网络生成样本，能否直接用本章公式评分？

解答：只有满足相应维度、双射、可微和可计算雅可比等条件时，才能使用简单变量替换公式。普通网络可能降维、多对一或具有难求的逆，需对原像积分或求和，不能直接代入。容易执行生成函数不等于容易求输出密度，这正是不同生成模型在计算属性上的重要区别。

<a id="gm-4-detail-55"></a>

### 11.17 题十七：人工流的理论熵参考

题目：实验三的真实变换中，为什么总体平均负 log 密度应接近标准二维高斯熵加第一维 log 尺度？

解答：连续双射的熵变换公式为 $`H(X)=H(Z)+E\log\vert \det J_g(Z)\vert `$。标准二维高斯熵为 $`\log(2\pi e)`$，本例生成方向 log 行列式为 $`\log 1.3+0.35\tanh Z_0`$。由于标准正态对称而双曲正切为奇函数，后一项期望为零，所以理论参考为 $`\log(2\pi e)+\log1.3`$，约三点一零零。平移和平方弯曲项不直接改变该三角变换的行列式，因此不进入熵变化。

这不是说弯曲项对拟合无影响。若模型没有正确恢复弯曲，潜变量会偏离标准正态，交叉熵会增加。独立测试的有限样本平均也会围绕理论值波动，不能要求每次运行恰好等于该值。这里的解析参考可以帮助判断结果数量级是否合理，比只说损失下降更有解释力。

<a id="gm-4-detail-56"></a>

### 11.18 题十八：log 行列式的参数梯度

题目：对依赖标量参数的非奇异矩阵 $`A`$，log 绝对行列式的微分是什么？为什么不建议在高维每步显式求逆？

解答：在非奇异区域，微分为 $`d\log\vert \det A\vert =\operatorname{tr}(A^{-1}dA)`$。绝对值不改变该局部微分形式，但不能跨过奇异点忽略可微性问题。这个公式用于理解梯度和设计结构；实现时显式求逆通常比线性求解更不稳定且更昂贵。耦合层通过三角结构直接把 log 行列式化为尺度和，避免了一般矩阵路径。

如果某参数只影响平移，当前层的局部体积项对它梯度为零，但基密度和后续层体积项仍可依赖它。因此不能由局部公式推断该参数总梯度为零。应结合完整复合计算图，必要时用小维度有限差分和自动微分核对。把数学简化与实际梯度路径对应起来，才能避免前向数值正确而训练方向错误的实现。

<a id="gm-4-detail-57"></a>

## 12. 综合研究作业

从实验三出发，建立真实机制已知、模型可控的比较。完整模型、去掉弯曲项模型和去掉异方差模型使用同一训练与测试数据，分别报告 NLL、条件残差、参数估计和逆误差。预先定义训练步数和模型选择规则，避免看到测试结果后继续调整。对于模型错设，应解释哪一项统计关系无法表达，而不是只给排名。

再构造离散网格版本，对每个格子的概率用数值积分或高精度近似求参考，比较均匀去量化下界与格概率之间的差距。明确缩放常数和每维位数，检查单位变化后物理事件概率不变。所有实验仅用人工数据与 CPU，在内存中运行，不需要下载数据或留下模型文件。最终报告应让别人从公式和代码复算每个结论。

<a id="gm-4-detail-58"></a>

## 13. 进一步推导：可逆结构的梯度与几何

<a id="gm-4-detail-59"></a>

### 13.1 复合映射的 log 行列式为什么能相加

设中间变量满足 $`h_k=f_k(h_{k-1})`$。链式法则给出总雅可比为各层雅可比按顺序相乘，行列式的乘法性质将其变成各行列式的乘积，取 log 绝对值后得到和。每层项必须在该层真实输入 $`h_{k-1}`$ 上计算，不能把所有尺度网络都放在原始输入上求值。后者即使维度匹配，也不再对应实际复合变换的体积变化。

计算图中，较早一层既通过最终潜变量影响基密度，也通过改变后续层输入影响它们的 log 行列式。只对每层局部体积项求梯度、忽略中间状态的依赖，会漏掉梯度路径。因此手写损失时应让自动微分完整穿过所有变换，除非有经过证明的解析简化。密度公式短，不代表参数梯度只有局部一项。

可以用两层二维例子做手工核对：第一层改变第二坐标，第二层的尺度依赖改变后的第二坐标。第一层参数因此会影响第二层 log 行列式。把第二层输入停止梯度，正向 log 密度数值仍相同，反向却错误。仅测试损失值不足以检验训练实现，梯度检查正是为了发现这类数值表面正确的错误。

<a id="gm-4-detail-60"></a>

### 13.2 体积、奇异值与条件数

行列式绝对值等于奇异值的乘积，描述总体积变化；条件数则与最大最小奇异值之比有关。一个变换可以体积保持，却把某方向极度拉长、另一方向极度压缩，导致逆运算数值敏感。例如对角尺度一百万与百万分之一的乘积为一，log 行列式为零，但浮点计算仍可能非常不稳定。

因此仅监测 log 行列式范围不够。可以检查往返误差、局部雅可比范数、尺度分布和对微扰的敏感性。高维完整奇异值分解可能昂贵，但小维度诊断、随机方向估计和逐层统计仍有帮助。若出现不稳定，应先调查条件数和输入尺度，而不是因为 log 行列式看似正常就排除变换问题。

在模型设计上，限制每层 log 尺度和使用合理混合，有助于控制极端变形，但多层相乘仍可能积累条件问题。正交线性变换保持范数，其他可逆混合则可能有不同成本与表达优势。稳定性不能完全由某个单层性质推出，需要在完整组合上验证。理论双射与有限精度可靠双射是相关但不同的要求。

<a id="gm-4-detail-61"></a>

### 13.3 一维单调流与累积分布变换

若目标连续分布具有严格递增的累积分布函数，理论上可以把目标样本映为均匀变量，再通过基分布逆累积分布函数映到基空间。这说明一维足够灵活的单调变换可以表示非常丰富的密度。但在尾部，累积分布接近零或一，逆函数与导数可能数值敏感；数据有限时，经验分布也不能直接提供平滑可靠的真实变换。

这个构造把表达存在性和可学习性区分开。数学上存在某个变换，不代表所选神经网络易于训练，也不代表有限样本能识别尾部。实际单调流要维护正导数、可求逆和稳定边界，可能使用分段结构或其他参数化。方法选择不能只引用存在性，而应报告实际近似误差与计算代价。

多维中可以通过逐维条件累积分布构造三角变换，但每个条件分布的学习仍可能复杂。变量顺序会改变这些条件的难度，这又把自回归分解与流联系起来。一个清楚的研究问题是：在固定数据上，换顺序是否让某些条件更接近简单分布？先用低维可视化和条件诊断回答，再扩大架构，比盲目增加层数更有针对性。

<a id="gm-4-detail-62"></a>

## 14. 统计目标、数据机制和可识别性

<a id="gm-4-detail-63"></a>

### 14.1 从训练点密度到总体风险

经验负 log 密度是有限样本平均，总体风险是对未来分布的期望。二者接近需要数据代表性和适当统计条件，不能由训练目标形式自动保证。时间相关、同源重复和选择偏差都会让有效信息量低于记录数。对于测量数据，应按设备、时间段或来源划分，而不总按行随机拆分；生成模型同样不能绕过数据边界。

若训练样本来自混合来源，最大似然按暴露频率拟合混合分布。稀有模式可能被总体均值掩盖，应按模式或来源报告似然和覆盖。人为提高稀有来源权重可以改变目标，但此时学到的是重加权分布。生成样本比例可能因此偏离原始总体，报告应说明这种变化是有意设计还是采样器错误。

<a id="gm-4-detail-64"></a>

### 14.2 连续 MLE 的尖峰问题

考虑只有一个观测的正态模型，均值可以设在该点，方差趋于零时，该点密度趋于无穷，经验 log 似然没有有限上界。多个点配以足够灵活的混合或变换，也可能产生类似局部集中。这个反例说明连续最大似然需要模型限制、正则、测量噪声或独立选择，不能只追求训练损失越低越好。

对于离散数据，质量函数每个值概率不超过一，但连续密度没有这个上界，因此把整数观测直接当连续点训练尤其要谨慎。去量化让模型对小格内分布负责，可以减弱对孤立点的无意义尖峰偏好，但它不是对所有过拟合的普遍免疫。噪声分布和数据划分仍决定实际统计问题。

<a id="gm-4-detail-65"></a>

### 14.3 潜变量的不可识别性

假设基分布具有某些保持分布不变的变换，例如标准高斯对正交旋转不变。将一个学到的潜映射再接这样的变换，输出数据密度可以保持相同，但潜坐标含义改变。因此仅凭似然通常无法唯一确定每个潜维度的语义。不同随机训练得到不同潜表示，并不必然表示其中一个模型错了。

如果希望潜变量对应真实生成因素，需要额外假设、监督、干预或结构约束。即便提供部分标签，也要检查是否出现相关因素混合。可逆重建是信息保持的性质，语义解耦是表示组织的性质，两者不能互相推出。学习资料应让读者理解这种区别，避免把漂亮的插值图当成可识别性的证明。

<a id="gm-4-detail-66"></a>

### 14.4 似然比与异常任务

对于两个明确定义分布，似然比可以用于比较观测更支持哪个假设；这与单独使用一个正常模型的密度不同。若背景分布模型不合理，似然比也可能失效。实际异常类型往往未知，必须根据任务构造代表性评价，并检查不同异常族的表现。不存在一个由“密度精确”直接推出的普遍异常识别规则。

典型性检测也要说明参考统计量、维度和阈值。高维集中现象提供直觉，但真实数据并非独立标准高斯。若预处理改变低层统计，检测结果可能主要追随这些变化。可以采用配对干预区分语义异常与简单亮度、尺度或噪声变化，避免把对低层扰动敏感误称为理解语义。

<a id="gm-4-detail-67"></a>

## 15. 去量化与预处理的完整账本

<a id="gm-4-detail-68"></a>

### 15.1 变分去量化下界的差距

一般噪声分布下，可以把离散格内的真实条件密度写为 $`p(u\mid v)=\frac{p(v+u)}{P(v)}`$。将其代入下界，得到离散 log 概率与下界的差正是 $`KL(q(u\mid v)\Vert p(u\mid v))`$，只要相关支持与积分条件满足。这个等式解释了为什么更灵活的噪声模型可能收紧下界，也说明下界差异不完全等同于主密度模型差异。

如果比较两个系统，一个使用更强去量化器、另一个只用均匀噪声，下界提升可能来自噪声近似更紧，也可能来自连续密度更好。要解释贡献，需要控制或分别评价组件。精确连续密度与变分离散下界并存，并不矛盾；它们对应不同随机变量和不同计算步骤。报告时应给指标准确命名，避免把下界当作精确离散 log 概率。

<a id="gm-4-detail-69"></a>

### 15.2 支持边界和对数几率预处理

将零一范围数据映到实轴的对数几率变换，在边界零和一处发散。实际流程常先做边界收缩，但这会改变支持与雅可比。若收缩后只覆盖实轴中的有限区间，而主模型在区间外仍分配质量，诱导到原数据空间的解释需要说明。不能因为每一步都有一个公式，就忽略整体支持是否匹配。

预处理账本可以逐行记录：输入空间、输出空间、是否双射、是否随机、是否丢信息、log 雅可比或噪声熵项。遇到裁剪、舍入和缺失填补，应单独处理，因为它们通常不是普通等维双射。这样的记录不仅帮助计算似然，也能发现训练与推理不一致，例如训练带噪声、评价却只取整数中心。

有限离散字母表还需要单独检查总质量。例如只有两个合法值 $`v\in\{0,1\}`$，分别对应区间 $`[0,1)`$、$`[1,2)`$，却在整条实线上使用标准高斯密度。按区间积分得到的两项之和为 $`\Phi(2)-\Phi(0)\approx0.47725`$，并不等于 1。若样本空间取覆盖实线的全部整数区间，积分质量可以组成归一化分布；若样本空间只允许这两个值，得到的只是一个次概率分布。要得到严格的二元生成模型，需要让连续支持匹配合法区间，或对合法区域作条件归一化，并把相应对数归一化常数计入似然。也可增加显式的区间外符号来吸收剩余质量，但这已扩展了原来的二元样本空间。不能只因为连续密度在实线上归一化，就断言任意有限分箱也已归一化。

缩放常数同样不能省略。对 $`D`$ 维离散向量，取 $`u\sim\mathrm{Uniform}([0,1)^D)`$、$`y=\frac{v+u}{K}`$，则相应分箱质量的 Jensen 下界为 $`\log P(v)\geq\mathbb E_u[\log p_Y(y)]-D\log K`$；这里 $`K^{-D}`$ 来自变量替换的体积。若报告平均每维 bits，还需除以 $`D\log2`$ 并取负号。连续 log 密度、离散分箱 log 质量和每维 bits 必须在同一尺度下比较。去量化的分箱定义与变分推导可参见 [Flow++ 第 3.1 节](https://arxiv.org/html/1902.00275v2)。

<a id="gm-4-detail-70"></a>

### 15.3 数值积分和蒙特卡洛评分

低维小格积分可以用数值积分作参考，高维通常难以精确计算。对去量化噪声进行多次采样，可以估计相关期望；若要估计 log 格概率，应注意先平均密度再取 log，与平均 log 密度对应不同量。有限样本的 log 平均还具有偏差，增加采样数和报告收敛诊断有助于理解误差，但不应宣称一次有限估计就是精确值。

重要性采样使用噪声提议分布时，要包含密度比并保证支持覆盖。若权重集中在极少数样本，估计方差可能很大，表面稳定的小数位也不可靠。可检查权重分布、重复估计和有效样本代理。计算协议应在比较前固定，否则不同采样预算会给某方法额外优势。

<a id="gm-4-detail-71"></a>

## 16. 方法选择与可复现研究

<a id="gm-4-detail-72"></a>

### 16.1 将四个能力放在同一张决策表里

自回归模型通常直接评分、顺序生成，对任意缺失模式条件推断未必方便；耦合流同时提供可计算密度和直接逆，但要维护等维可逆结构；变分模型通过潜变量和下界换取灵活性；隐式生成模型可能容易采样却难算归一化密度。这里的描述是常见结构属性，具体实现还需要单独核对，不能把整个方法族压成绝对快慢排名。

选择时先列出硬需求：是否必须精确评分、是否要低延迟采样、数据是否离散、支持是否低维、是否需要来源可解释的控制。再给出资源预算和质量指标。某模型在一项基准上表现最好，不代表适合所有工作负载。完整方法比较应把目标、假设和代价写清楚，而不是只展示一个综合分数。

<a id="gm-4-detail-73"></a>

### 16.2 实验断言与统计结论分工

逆映射相等、log 行列式一致、概率和为一，是适合确定性断言的机制性质；独立样本 NLL 提高、参数接近真值和模式比例则包含统计波动。后者可以设置合理的机制诊断范围，但不能把通过断言当成严格置信证明。本章第三实验的参数误差阈值用于发现明显错误，正式统计研究还需要重复运行与不确定性分析。

复现实验时记录随机数生成方式、训练和测试种子、数据规模、线程、精度、优化器和步数。若改动任何一项，应注明新运行身份。种子相同也不保证跨硬件逐位一致，尤其涉及并行归约或不同内核。对教学机制使用双精度与单线程有助于稳定核验，但没有测量真实大规模系统的性能。

<a id="gm-4-detail-74"></a>

### 16.3 失败诊断的顺序

出现负无穷或非有限损失，先检查输入范围、尺度指数、基分布评分和 log 行列式；出现逆误差，检查方向、逆序和中间状态；训练正常而测试差，检查数据边界、过拟合与模型错设。若样本边际合理却联合关系错误，增加条件诊断，而不是只调视觉展示。每种现象都应对应一个可检验假设。

不要一次同时修改网络深度、学习率、预处理和基分布，然后宣称某个单项修复有效。工程上有时需要组合改动，但研究归因应如实限定为完整配置。可以在修复后做必要消融，确认哪些项是关键。清楚记录失败和限制，让下一位学习者能够继续推导和实验，而不是只重复一段能运行的代码。

<a id="gm-4-detail-75"></a>

### 16.4 生成实验的复现记录

最终章节应保留定义、条件、推导、最小例子、反例、代码和观察结果，使读者能在没有中间生成器的情况下理解并复算。脚本、下载缓存、模型权重和临时图像并不是阅读本章所必需。代码使用人工数据和内存对象，运行完成后不在资料目录产生其他文件，便于把学习材料作为清楚的知识库维护。

更进一步的研究可以从某条限制出发：如何在不牺牲可计算性的情况下改善条件分布，如何处理断开支持，如何提高采样并行度，或如何建立更可靠的异常评价。每个问题都应回到明确的随机变量、目标与预算。强烈的好奇心最适合由一串可以逐步验证的问题承接，而不是由更多未解释的术语替代。
