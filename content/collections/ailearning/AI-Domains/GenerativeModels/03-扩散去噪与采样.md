## 1. 扩散模型的核心是学习逆转逐步扰动

扩散生成并不是把一张任意噪声图片“直接变清晰”的神秘过程。它先规定一个可计算的前向扰动链，使数据逐渐接近简单噪声分布，再学习每个噪声水平下的逆向条件分布。训练时可以直接从干净样本构造任意时刻的含噪观测，采样时则从终点分布出发逐步反向运行。前向链是人为选择的统计机制，逆向链才包含需要学习的参数。

本章集中研究离散时间 DDPM，明确列出前向核、精确后验、变分目标、噪声参数化与祖先采样。连续时间随机微分方程、概率流常微分方程和确定性流模型属于相关但不同的构造，不能因为它们也画出从噪声到数据的箭头就视为同一个采样器。尤其不能把随机 DDPM 的方差直接删掉后宣称已经得到理论上等价的确定性方法。

<a id="sec-1-1"></a>

<a id="ddpm-detail-2"></a>

### 1.1 时间方向与记号约定

干净数据记为 $x_0\in\mathbb R^d$，噪声时刻为 $t=1,\ldots,T$。选择 $0<\beta_t<1$，令 $\alpha_t=1-\beta_t$，累计乘积 $\bar\alpha_t=\prod_{s=1}^t\alpha_s$，并约定 $\bar\alpha_0=1$。前向时间越大，信号通常越弱；采样循环则从大时间走向小时间。代码中最常见的错误是把从零开始的数组下标和从一开始的数学时间混用。

所有标量系数都要扩展到与样本特征可广播的形状。若批次中每个样本有不同时间，系数应该沿样本轴变化，再复制到它的所有特征维度，不能把某个特征坐标误当作时间。二维向量和图像张量的广播维度不同，移植代码时必须明确批次轴、通道轴和空间轴，而不是依赖碰巧能运行的形状。

<a id="ddpm-detail-3"></a>

### 1.2 一个可解释的人工任务

本章完整训练使用一维双峰分布：先等概率选择中心负二或正二，再加标准差零点三的高斯噪声。它有明确的两个模式、已知概率和可计算总体矩，便于独立评价生成覆盖。小型一维实验不能代表图像模型的视觉质量，却足以检验时间索引、后验方差、噪声预测目标和反向采样链是否连接正确。

评价将同时检查正负模式占比、样本均值、二阶矩以及靠近两个中心的比例。只要输出分布关于零对称，均值就可以很好，即使它只生成中心零附近的错误样本。因此均值不能单独证明学到双峰。反过来，最近中心占比接近一半也不排除样本离两个中心都很远，需要局部距离共同诊断。

## 2. 前向链与任意时刻的闭式抽样

<a id="sec-2-1"></a>

<a id="ddpm-detail-5"></a>

### 2.1 马尔可夫高斯扰动

规定 $q(x_t\mid x_{t-1})=N(\sqrt{\alpha_t}x_{t-1},\beta_tI)$，等价写法是 $x_t=\sqrt{\alpha_t}x_{t-1}+\sqrt{\beta_t}\epsilon_t$，其中每步噪声独立标准正态。信号在每一步收缩，新增噪声补入方差。如果起点本身是标准正态，每一步仍是标准正态；对于一般数据，重复扰动逐渐削弱原始结构。

注意方差是 $\beta_t$，标准差是其平方根。直接把 $\beta_t$ 乘噪声会得到另一个前向过程，后面所有闭式公式随之不再匹配。同样，信号系数是 $\sqrt\alpha_t$，不是 $\alpha_t$。代码能输出平滑曲线并不说明过程正确，必须从条件均值与方差逐项核对。

<a id="ddpm-detail-6"></a>

### 2.2 闭式边缘的归纳证明

若 $x_{t-1}\mid x_0$ 均值为 $\sqrt{\bar\alpha_{t-1}}x_0$、方差为 $(1-\bar\alpha_{t-1})I$，再经过一步扰动，均值变为 $\sqrt{\alpha_t\bar\alpha_{t-1}}x_0$，方差为 $\alpha_t(1-\bar\alpha_{t-1})+\beta_t=1-\bar\alpha_t$。以第一步为基础便得到

$$q(x_t\mid x_0)=N(\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I).$$

因此训练时可以一次生成 $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$，无需真的运行前面所有步。这里的 $\epsilon$ 是累计扰动的等效噪声，不是某一步原始噪声的简单复制。不同时间的独立闭式抽样只保证各自边缘正确，并不自动构成同一条前向链的联合轨迹。

<a id="ddpm-detail-7"></a>

### 2.3 终点接近标准正态的条件

当 $\bar\alpha_T$ 很小时，条件均值中残留信号较弱，条件方差接近一。但“很小”取决于数据尺度，如果数据均值或方差巨大，终点仍可能明显偏离标准正态。训练前的尺度处理与噪声日程必须共同考虑。有限时间下终点一般只是近似简单先验，而非数学上精确等于标准正态。

可计算 $D_{\rm KL}(q(x_T\mid x_0)\Vert N(0,I))$ 作为终点失配的一个解析参照，公式为二分之一乘以信号均值平方和、条件方差迹、维数与对数方差项的相应组合。对数据取平均后，它也是变分目标中的终点项。该项不依赖逆向网络参数，但会影响模型的实际先验匹配，不能因为训练梯度不受它影响就假定它必然为零。

## 3. 精确前向后验的完整推导

<a id="sec-5"></a>

<a id="ddpm-detail-9"></a>

### 3.1 两个高斯因子的乘积

训练时知道 $x_0$，所以可以计算 $q(x_{t-1}\mid x_t,x_0)$。根据前向马尔可夫性，它正比于 $q(x_t\mid x_{t-1})q(x_{t-1}\mid x_0)$。把两个高斯对数密度中关于 $x_{t-1}$ 的二次项收集起来，其精度是 $\alpha_t/\beta_t+1/(1-\bar\alpha_{t-1})$。取倒数得到后验方差

$$\tilde\beta_t=\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t.$$

一次项再乘这个方差，得到后验均值

$$
\tilde\mu_t=\frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t}x_0
+\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}x_t.
$$

这个后验条件包含真实干净样本，训练时可用，生成时不可直接用。逆向网络的任务就是在只看到 $x_t$ 与时间时提供合适的条件分布近似。若在生成代码里偷偷使用真实 $x_0$，看起来完美的去噪将是信息泄露，而不是生成能力。

<a id="ddpm-detail-10"></a>

### 3.2 第一时刻为什么特殊

当 $t=1$，$\bar\alpha_0=1$，后验方差为零，条件后验退化为已知 $x_0$ 的点质量。此时不能把普通正方差高斯 KL 公式直接套进去，也不能在代码里对零后验方差取对数。变分分解通常把第一步作为观测重构似然单独处理，其分布需要根据连续或离散观测假设定义。

采样时常在最后一步不再加入新随机噪声，输出预测均值作为样本近似。这是一个具体采样约定，与训练中的第一步观测似然应该区分。若要精确评价似然，需要明确最后分布的方差或离散化形式，不能只凭一条均值采样路径声称拥有完整归一化密度评价。

<a id="sec-6"></a>

<a id="ddpm-detail-11"></a>

### 3.3 噪声形式的后验均值

由闭式扰动反解 $x_0=(x_t-\sqrt{1-\bar\alpha_t}\epsilon)/\sqrt{\bar\alpha_t}$，代回后验均值并整理，得到

$$
\tilde\mu_t=\frac1{\sqrt{\alpha_t}}
\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon\right).
$$

因此可以让网络预测等效噪声 $\epsilon_\theta(x_t,t)$，再把它代入这个式子定义逆向均值。噪声目标不是随意选择的标签，它与后验均值具有明确线性关系。网络仍不知道这一次具体加入的噪声，平方误差最优预测是条件期望，而不是对每个含噪输入都能完美还原那次随机扰动。

## 4. 变分目标与噪声平方误差的联系

<a id="ddpm-detail-13"></a>

### 4.1 从整条路径的联合分布开始

逆向生成模型写为 $p_\theta(x_{0:T})=p(x_T)\prod_{t=1}^Tp_\theta(x_{t-1}\mid x_t)$，前向变分分布是 $q(x_{1:T}\mid x_0)$。对路径应用与上一章相同的变分恒等式，负 ELBO 为前向期望下 $\log q(x_{1:T}\mid x_0)-\log p_\theta(x_{0:T})$。

把前向链反向分解为 $q(x_T\mid x_0)\prod_{t=2}^Tq(x_{t-1}\mid x_t,x_0)$，可整理成终点 KL、各中间后验与逆向核的 KL，以及第一步负观测对数似然。中间项对 $x_t\mid x_0$ 的期望仍然存在，不能把某一个噪声样本上的 KL 当成精确总体目标。这个分解解释了为什么可计算的前向后验能够监督学习逆向核。

<a id="ddpm-detail-14"></a>

### 4.2 固定逆向方差时的权重

若逆向核为 $N(\mu_\theta,\sigma_t^2I)$ 且 $\sigma_t$ 固定，中间高斯 KL 对均值相关的部分是 $\|\tilde\mu_t-\mu_\theta\|^2/(2\sigma_t^2)$。采用噪声参数化后，得到

$$
\frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar\alpha_t)}
\|\epsilon-\epsilon_\theta(x_t,t)\|^2.
$$

其余方差相关项在固定方差时不依赖均值网络参数，但若学习方差，就不能继续一律丢掉。公式适用于中间非退化时刻，第一时刻需要前述单独处理。若把 $\sigma_t^2$ 设为 $\tilde\beta_t$，某些权重在低噪声处会很大，训练数值与时间抽样策略均需要谨慎。

<a id="ddpm-detail-15"></a>

### 4.3 简化目标并非原权重的同义写法

常用简化训练从时间均匀抽样，最小化未加权的噪声平方误差。它把不同噪声水平的相对强调方式改了，通常不能直接称为原始负 ELBO 的逐项无偏估计。它仍然有清楚的去噪与得分学习解释，但目标名称应准确。若按维度平均，也需要说明与逐样本求和的尺度差异。

如果要无偏估计某个给定时间加权和，可以从任意正概率时间分布抽样，再除以抽样概率并乘相应权重。不同抽样策略影响估计方差与计算效率，但不应在公式里遗漏这一步。若有意采用新的时间权重，那就是新的目标折中，应使用独立生成评价说明收益，而不是只比较数值大小不同的训练损失。

<a id="ddpm-detail-16"></a>

## 5. 可运行实验一：闭式边缘与链式扰动

本实验固定一个干净值，比较逐步扰动与直接闭式抽样的条件均值、方差。两组随机数独立，所以不要求逐样本相同；要求的是统计矩符合各自同一个理论分布。同时检查日程边界与累计乘积单调性，防止时间数组错位。

```python
import numpy as np
rng = np.random.default_rng(11)
T = 30
beta = np.r_[0., np.linspace(.01, .08, T)]
alpha = 1-beta
abar = np.cumprod(alpha)
assert abar[0] == 1 and np.all(np.diff(abar) < 0)
x0 = 2.5
n = 120000
chain = np.full(n, x0)
for t in range(1, T+1):
    chain = np.sqrt(alpha[t])*chain+np.sqrt(beta[t])*rng.normal(size=n)
direct = np.sqrt(abar[T])*x0+np.sqrt(1-abar[T])*rng.normal(size=n)
mean = np.sqrt(abar[T])*x0
variance = 1-abar[T]
for sample in [chain, direct]:
    assert abs(sample.mean()-mean) < .015
    assert abs(sample.var()-variance) < .015
print('theory', mean, variance, 'chain', chain.mean(), chain.var(),
      'direct', direct.mean(), direct.var())
```

这个验证没有把独立边缘样本当成一条联合轨迹。如果需要研究同一路径的时间相关性，必须实际保存链式扰动，或构造具有正确联合协方差的闭式耦合。简单地对每个时刻独立抽噪声，虽然每一张含噪图都正确，却不会具有原始马尔可夫链的跨时间关系。这种区别在推导轨迹目标或测试采样器时十分重要。

<a id="ddpm-detail-17"></a>

## 6. 可运行实验二：后验系数与 ELBO 权重

下面对某个非退化时刻，分别用精度相加与闭式系数计算后验，再核对噪声均值形式。接着选一个人为预测噪声，检查高斯 KL 中的均值误差与加权噪声误差完全相等。这个实验不需要训练网络，能够把推导错误与优化误差分开。

```python
import numpy as np
T = 40
beta = np.r_[0., np.linspace(.005, .09, T)]
alpha = 1-beta; abar = np.cumprod(alpha)
t = 17; x0 = np.array([1.2, -0.7]); eps = np.array([.3, -1.1])
xt = np.sqrt(abar[t])*x0+np.sqrt(1-abar[t])*eps
v = beta[t]*(1-abar[t-1])/(1-abar[t])
c1 = np.sqrt(abar[t-1])*beta[t]/(1-abar[t])
c2 = np.sqrt(alpha[t])*(1-abar[t-1])/(1-abar[t])
mean = c1*x0+c2*xt
precision = alpha[t]/beta[t]+1/(1-abar[t-1])
mean_precision = (np.sqrt(alpha[t])*xt/beta[t]
                  +np.sqrt(abar[t-1])*x0/(1-abar[t-1]))/precision
assert np.isclose(v, 1/precision)
assert np.allclose(mean, mean_precision)
mean_noise = (xt-beta[t]/np.sqrt(1-abar[t])*eps)/np.sqrt(alpha[t])
assert np.allclose(mean, mean_noise)
pred = np.array([-.4, .2])
mean_pred = (xt-beta[t]/np.sqrt(1-abar[t])*pred)/np.sqrt(alpha[t])
sigma2 = beta[t]
mean_kl = np.square(mean-mean_pred).sum()/(2*sigma2)
weight = beta[t]**2/(2*sigma2*alpha[t]*(1-abar[t]))
assert np.isclose(mean_kl, weight*np.square(eps-pred).sum())
assert np.isclose(beta[1]*(1-abar[0])/(1-abar[1]), 0)
print('posterior variance', v, 'mean', mean, 'weighted error', mean_kl)
```

若学习逆向方差，完整 KL 还包含方差比、对数方差比和维数项，不能用这段只核对均值项的断言证明完整目标正确。也不能把这里固定某个时间的等式直接推广成均匀时间抽样下的原始 ELBO，后者仍需要正确时间权重与第一步观测项。

## 7. 噪声预测、干净值预测与得分

<a id="ddpm-detail-19"></a>

### 7.1 平方误差最优解是条件期望

对给定含噪输入 $x_t$，平方误差风险在条件均值处最小，所以理想噪声预测为 $E[\epsilon\mid x_t]$，不是每条训练记录具体噪声的可逆恢复。当多个不同干净值和噪声组合都可能产生相同的 $x_t$ 时，确定性网络无法分辨不可识别的单次来源。更精确地，最小总体平方风险为 $E[\operatorname{tr}\operatorname{Cov}(\epsilon\mid x_t)]$，只有条件方差确实非零时才有正的不可约误差；若干净值固定且已知，噪声反而可以由 $x_t$ 精确反解。有限固定训练对仍可能被大网络记忆到零误差，这与总体风险的结论不同。本章不断重抽干净值与噪声，因此应看独立重抽条件下的风险，不能用零训练误差作为唯一正确性标准。

同理，直接预测 $x_0$ 的平方误差最优解是 $E[x_0\mid x_t]$。在低噪声与高噪声时，这两种参数化的尺度不同，等价的后验均值需要相应权重转换。只把网络输出名字从噪声改成干净值而不修改目标与采样公式，会构造出不一致的系统。

<a id="sec-7-1"></a>

<a id="ddpm-detail-20"></a>

### 7.2 得分恒等式的推导

记扰动后边缘密度为 $q_t(x_t)$。对高斯卷积的积分求导，在适当可交换条件下，得分为条件期望下的高斯得分：

$$
\nabla_{x_t}\log q_t(x_t)
=-\frac{E[\epsilon\mid x_t]}{\sqrt{1-\bar\alpha_t}}.
$$

等价地，$E[x_0\mid x_t]=[x_t+(1-\bar\alpha_t)\nabla\log q_t(x_t)]/\sqrt{\bar\alpha_t}$。得分指对输入的对数密度梯度，不是样本质量分数，也不是概率值。它的方向描述局部密度增大的方向，幅度与噪声尺度有关，不能跨时刻不加归一化直接比较。

<a id="ddpm-detail-21"></a>

### 7.3 速度参数化只是线性坐标变换

定义 $v=\sqrt{\bar\alpha_t}\epsilon-\sqrt{1-\bar\alpha_t}x_0$。与 $x_t$ 联立可反解出 $x_0=\sqrt{\bar\alpha_t}x_t-\sqrt{1-\bar\alpha_t}v$，以及 $\epsilon=\sqrt{1-\bar\alpha_t}x_t+\sqrt{\bar\alpha_t}v$。这个两变量变换具有清楚的代数关系，不能因为名字叫速度就把它自动理解为连续时间普通微分方程的速度场。

不同参数化可以在有限网络、损失权重与训练日程下产生不同表现。比较时必须保持相应反解公式和采样器一致，明确是否转换了时间权重。输出变量形式的改变本身不保证更好的覆盖或更少的采样步数，需要在共同预算和外部评价下验证。

<a id="sec-3"></a>

<a id="ddpm-detail-22"></a>

## 8. 逆向采样与方差选择

<a id="ddpm-detail-23"></a>

### 8.1 祖先采样的完整步骤

先抽 $x_T\sim N(0,I)$，对 $t=T,\ldots,1$ 预测噪声，计算逆向均值，再按规定方差抽 $x_{t-1}$。如果采用 $\tilde\beta_t$ 并在第一步不加噪声，那么每个中间时刻都应抽新的独立噪声，而不是重复使用起始噪声。重复使用会改变整个轨迹联合分布，不能再称为原先定义的祖先采样。

实际前向边缘的逆向条件一般不是单个高斯，尤其噪声步长很大或数据多峰时。网络高斯核是对真实逆向核的近似，小步长有助于使局部近似合理，却增加采样成本。精确知道条件均值也不等于精确知道完整逆向分布，这也是有限步数、方差选择与生成质量互相作用的原因。

<a id="ddpm-detail-24"></a>

### 8.2 减少步数需要新公式

把训练时间表中的若干步直接跳过，同时沿用相邻一步的均值和方差，通常不能得到正确的跳步采样器。跨多个时间的前向条件具有不同累计系数，对应后验也需要重新计算。确定性采样路线还会改变随机性注入方式，不能仅在原 DDPM 循环里把全部噪声置零就宣称理论等价。

比较采样器应报告网络调用次数、随机噪声使用方式、时间子序列与最终评价。更少步数可能节省调用却降低质量，也可能因更好的离散化带来收益，必须实际测量。CPU 小型模型的运行速度不能直接外推到大图像模型，内存、批次和设备会改变每次调用成本。

<a id="ddpm-detail-25"></a>

## 9. 完整实验：人工双峰 DDPM

<a id="ddpm-detail-26"></a>

### 9.1 模型、日程与固定评价

本实验使用八十个离散时间，噪声方差从零点零零五线性增加到零点一二。时间通过归一化数值和正余弦特征输入小型网络，与一维含噪坐标拼接。训练使用均匀抽时间的简化噪声平方误差，明确不把它报告成精确负 ELBO。验证集干净值、时间与噪声都固定，用于比较训练前后同一有限样本目标。

反向采样使用精确前向后验方差作为固定逆向方差，在最后一步不再加入噪声。它是一个教学用有限步高斯逆向模型，不承诺精确恢复真实双峰分布。断言只要求验证去噪目标下降与样本有限，模式覆盖与局部形状由统计量如实报告，不通过反复挑种子强制出现某个漂亮结果。

```python
import math
import torch
from torch import nn

torch.set_num_threads(1)
torch.manual_seed(61)
T = 80
beta = torch.cat([torch.zeros(1), torch.linspace(.005, .12, T)])
alpha = 1-beta; abar = alpha.cumprod(0)
posterior_var = beta[1:]*(1-abar[:-1])/(1-abar[1:])
posterior_var = torch.cat([torch.zeros(1), posterior_var])
rng = torch.Generator().manual_seed(62)
def data(n, generator):
    signs = 2*torch.randint(2, (n,1), generator=generator)-1
    return 2*signs.float()+.3*torch.randn(n,1,generator=generator)
class Denoiser(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(4,64),nn.SiLU(),
                                 nn.Linear(64,64),nn.SiLU(),nn.Linear(64,1))
    def forward(self,x,t):
        u = t.float().reshape(-1,1)/T
        features = torch.cat([x,u,torch.sin(math.pi*u),torch.cos(math.pi*u)],1)
        return self.net(features)
model = Denoiser(); opt = torch.optim.Adam(model.parameters(),lr=.002)
eval_rng = torch.Generator().manual_seed(63)
x_eval = data(4096,eval_rng)
t_eval = torch.randint(1,T+1,(4096,),generator=eval_rng)
e_eval = torch.randn(4096,1,generator=eval_rng)
def noisy(x,t,e):
    a = abar[t].reshape(-1,1)
    return a.sqrt()*x+(1-a).sqrt()*e
xt_eval = noisy(x_eval,t_eval,e_eval)
def evaluate():
    with torch.no_grad():return float((model(xt_eval,t_eval)-e_eval).square().mean())
before = evaluate()
for step in range(3500):
    x0 = data(256,rng)
    t = torch.randint(1,T+1,(256,),generator=rng)
    eps = torch.randn(256,1,generator=rng)
    prediction = model(noisy(x0,t,eps),t)
    loss = (prediction-eps).square().mean()
    opt.zero_grad();loss.backward();opt.step()
after = evaluate()
with torch.no_grad():
    sampling_rng = torch.Generator().manual_seed(64)
    sample = torch.randn(6000,1,generator=sampling_rng)
    for t in range(T,0,-1):
        times = torch.full((len(sample),),t,dtype=torch.long)
        pred = model(sample,times)
        mean = (sample-beta[t]/(1-abar[t]).sqrt()*pred)/alpha[t].sqrt()
        if t>1:
            sample = mean+posterior_var[t].sqrt()*torch.randn(
                sample.shape,generator=sampling_rng)
        else:sample = mean
    near = ((sample.abs()-2).abs()<.8).float().mean()
assert after < before and math.isfinite(after)
assert torch.isfinite(sample).all()
assert 0 < abar[T] < .02 and posterior_var[1] == 0
print('noise MSE before/after',before,after,'terminal alpha bar',float(abar[T]))
print('positive fraction',float((sample>0).float().mean()),'near modes',float(near))
print('sample mean',float(sample.mean()),'second moment',float(sample.square().mean()))
```

<a id="ddpm-detail-27"></a>

### 9.2 如何读这些结果

真实分布均值为零，二阶矩为四点零九。若生成均值接近零但二阶矩明显偏低，可能把质量放在两个峰之间；若二阶矩偏高，可能有过宽局部方差或离群尾部。正负比例接近一半只能说明粗略模式分配，邻域比例可以进一步发现过渡样本。任何一个指标都不能替代全部分布评价。

模型预测的是含噪条件下的平均噪声，低噪声时目标更依赖局部细节，高噪声时目标更接近对输入噪声结构的估计。总体 MSE 下降可能主要来自容易的高噪声区域，因此进一步可按时间分箱报告验证误差。若某些关键时段误差很大，采样链可能逐步放大误差，即使整体训练平均看起来良好。

## 10. 条件生成与无分类器引导

<a id="ddpm-detail-29"></a>

### 10.1 条件与空条件共同训练

条件模型可以预测 $\epsilon_\theta(x_t,t,c)$。无分类器引导通常在训练中以一定概率丢弃条件，使同一网络也学会空条件预测。空条件应有明确表示，且训练时确实出现，不能在推断时临时把任意零向量当成已学过的无条件分支。条件缺失概率影响两条分支的训练预算，是需要报告的超参数。

推断时常使用 $\epsilon_{\rm guided}=\epsilon_u+w(\epsilon_c-\epsilon_u)$，其中本章约定 $w=0$ 为无条件、$w=1$ 为普通条件预测、大于一为外推增强。其他资料可能使用不同参数记号，因此比较引导强度时应看完整公式。一次有条件预测加一次空条件预测通常意味着约两次网络求值，可通过批次拼接提高硬件效率，但计算并未凭空消失。

<a id="ddpm-detail-30"></a>

### 10.2 得分组合的边界

在两条分支都精确且使用相同噪声尺度时，同样线性组合对应条件得分与无条件得分的组合。对固定时刻，它形式上是 $q_t(x\mid c)^wq_t(x)^{1-w}$ 的对数梯度，前提是该表达式能够归一化。这个逐时刻表达并不自动保证整条反向过程的最终干净样本恰好服从同一幂次组合，因为不同时间的密度族可能不相容，数值离散和模型误差也会影响结果。

增大引导可能提高条件一致性，却降低覆盖、增大极端值或放大两分支误差。应在固定调用预算下报告条件遵从与多样性的折中。只展示引导后最符合条件的几张样本，会隐藏被压制的模式和失败样本；若再加拒绝筛选，必须记录拒绝率与完整采样代价。

<a id="ddpm-detail-31"></a>

## 11. 可运行实验四：线性参数化与引导的解析检查

下面先验证噪声、干净值和速度之间的反解，再在两个同方差高斯得分上检验引导的代数形式。这个解析例子只证明单时刻得分组合关系，不假装已经训练了一个条件扩散网络。它还清楚显示大引导权重会把平均位置推到条件分布均值之外。

```python
import numpy as np
rng = np.random.default_rng(81)
a = .37
x0 = rng.normal(size=(20,3)); eps = rng.normal(size=(20,3))
xt = np.sqrt(a)*x0+np.sqrt(1-a)*eps
v = np.sqrt(a)*eps-np.sqrt(1-a)*x0
assert np.allclose(np.sqrt(a)*xt-np.sqrt(1-a)*v,x0)
assert np.allclose(np.sqrt(1-a)*xt+np.sqrt(a)*v,eps)
x = np.linspace(-3,5,21)
mu_u,mu_c,var = 0.,1.5,2.
for w in [0.,1.,3.]:
    score_u = -(x-mu_u)/var;score_c = -(x-mu_c)/var
    guided = score_u+w*(score_c-score_u)
    effective_mu = mu_u+w*(mu_c-mu_u)
    assert np.allclose(guided,-(x-effective_mu)/var)
print('parameterization inverses passed; guidance means',[0.,1.5,4.5])
```

真实无条件分布一般是各条件分布的混合，并不必与这里任取的单高斯相同，所以这个例子不应被当成一个完整数据生成模型的联合一致性证明。它的作用是核对公式、说明外推效应，并提醒读者分清单时刻代数、跨时间概率路径与最终生成质量这三个层次。

## 12. 十六道进阶练习与详细答案

<a id="ddpm-detail-33"></a>

### 12.1 累计系数为什么不是单步系数

问题：训练直接抽 $x_t$ 时能否用 $\alpha_t$ 替代 $\bar\alpha_t$？不能。单步系数描述从前一个时间到当前时间的信号收缩，累计系数描述从干净值经过全部前向步骤后的收缩。替换会使高时间仍保留过强信号，训练网络看到的噪声分布与采样公式不一致。应在简单常数日程下核对累计乘积，并用闭式矩实验发现错位。

<a id="ddpm-detail-34"></a>

### 12.2 各时刻边缘正确为何轨迹仍可能错误

独立从每个 $q(x_t\mid x_0)$ 抽样可保证边缘分布，但原始链的不同时间共享前面累积噪声，存在特定相关性。轨迹目标、耦合采样或跨时间估计需要这个联合关系。训练单时间去噪通常只需要边缘，因此直接抽样合理；不能把这一便利无条件推广到所有依赖整条路径的任务。

<a id="ddpm-detail-35"></a>

### 12.3 零终点信号是否必须精确达到

有限时间内只需终点与选择先验足够接近，但接近程度应相对于数据尺度与评价精度判断。终点 KL 项提供一个可计算参照，生成表现也受残留失配影响。若信号仍明显，直接从标准正态开始可能引入系统误差。增加时间、调整日程或采用更合适先验都可能改变问题，但应同时考虑计算与反向近似代价。

<a id="ddpm-detail-36"></a>

### 12.4 为什么不能在第一步套普通高斯 KL

精确条件后验在第一步方差为零，退化成已知干净样本的点质量，不满足普通正定高斯密度公式的条件。正确变分分解把第一步写成观测负对数似然。数值上给零方差随意加一个小数可以避免报错，却改变目标，不能被说成纯粹无害的实现修补。应先定义观测分布，再决定稳定计算方式。

<a id="ddpm-detail-37"></a>

### 12.5 噪声 MSE 是否就是精确似然

不是。常用均匀时间未加权 MSE 改变了变分各时间项的权重，还通常省略第一步与终点项。即使网络训练得很好，MSE 数值也不能直接标注为负对数似然。若需要似然相关评价，应按完整模型和变分分解计算相应估计，并报告蒙特卡洛误差与观测模型。训练目标与评价指标可以不同，但名称必须准确。

<a id="ddpm-detail-38"></a>

### 12.6 网络为何不能恢复每次真实噪声

同一个含噪值可由多个干净值和噪声组合产生，因此没有额外信息时，具体单次噪声不可识别。平方误差最优预测是条件期望，它在条件不确定性存在时仍有不可约误差。训练 MSE 不能降到零不一定代表模型容量不足。应与可解析人工分布的最优条件均值或其他参照比较，而不是强行让网络记住训练噪声。

<a id="ddpm-detail-39"></a>

### 12.7 预测干净值为何需要改权重

噪声误差与干净值误差通过时间相关系数线性关联。高噪声时反解干净值会除以很小的信号系数，误差尺度被放大。若只切换输出目标而保持未加权 MSE，便改变不同时间的相对优化重点。正确比较需要说明是否维持同一个数学目标，以及采样器怎样把输出转换回逆向均值。

<a id="ddpm-detail-40"></a>

### 12.8 得分是概率吗

得分是对输入的对数密度梯度，是一个与输入同维度的向量；它不是归一化概率，也不是单个质量标量。某点得分为零可能是密度极大、极小或鞍点，不能单凭零向量判断样本优秀。得分场还必须来自合适密度或近似模型，任意向量场不自动拥有可归一化密度解释。这个区分有助于避免把“打分模型”与得分匹配混淆。

<a id="ddpm-detail-41"></a>

### 12.9 最后一步为什么常不再加噪声

常用采样约定在最后一步输出均值，避免在已经接近数据时再注入额外扰动。若固定逆向方差取前向后验方差，第一步正好为零。但这不等于第一步观测似然可以不定义，也不代表所有扩散模型都必须采用相同约定。似然评价、连续观测采样与工程均值输出需要分别说明。

<a id="ddpm-detail-42"></a>

### 12.10 跳过一半步骤能否沿用原公式

不能默认可以，因为原公式对应相邻时刻条件，跳步涉及不同的累计扰动与后验。需要选择明确支持跳步的采样器，并使用它的时间序列与系数。减少调用次数可能改善速度，却也可能损害覆盖或稳定性。比较时报告实际调用数与质量，而不是仅把循环次数减半就称为等价加速。

<a id="ddpm-detail-43"></a>

### 12.11 引导权重一在不同资料为何不同

有的公式写成无条件加权差，有的写成条件加上额外差项，因此同一个数字可能对应不同混合。应把公式完整列出，并注明哪个值表示普通条件预测。比较生成结果时还需统一模型、噪声日程与采样器，否则数值相同也不能直接对照。符号约定差异不是理论冲突，先代入边界值检查即可澄清。

<a id="ddpm-detail-44"></a>

### 12.12 引导能否无限增大

不能期待无限增大持续改善质量。外推会放大分支误差，并可能把样本推到训练支持不足区域，导致极端值、覆盖下降或其他伪影。应预先选择范围并绘制条件一致性与多样性的折中，同时记录调用成本。最合适权重依赖任务与评价，不存在无需检验的普适常数。

<a id="ddpm-detail-45"></a>

### 12.13 模型知道时间为什么重要

同一个含噪坐标在不同噪声水平下具有不同后验含义。接近数据时的局部去噪与高噪声时的整体模式选择不是同一映射。若不给时间，网络只能在多种不同条件目标之间折中。时间编码可以有多种形式，但必须训练与采样一致，特别注意时间归一化范围、整数索引以及外推到未见时刻的问题。

<a id="ddpm-detail-46"></a>

### 12.14 什么情况下整体 MSE 会误导

若多数时间都容易预测，平均误差可以较低，而少数决定精细结构或模式分配的时段仍很差。按时间分箱、按模式分层以及检查采样链中间统计能够发现这种不均衡。另一个问题是不同目标权重导致 MSE 数值不可直接比较。训练目标下降是必要诊断之一，却不能替代最终样本分布评价。

<a id="ddpm-detail-47"></a>

### 12.15 更长链为何不保证质量更好

更小步长可能改善局部高斯近似，但也增加网络调用与误差累积机会。若训练预算固定，每个噪声区域得到的有效学习可能变化，采样时长也增加。日程与时间参数化是否匹配同样重要。应在共同调用预算或明确成本条件下比较，而不是把步数当作单调质量旋钮。

<a id="ddpm-detail-48"></a>

### 12.16 如何设计一个可复核的扩散实验

固定人工数据机制、时间日程、网络、训练目标、优化预算、随机种子与采样方差，再明确验证噪声和最终生成评价。先通过解析闭式与后验权重检查，再训练小模型，最后报告所有样本的覆盖、局部质量与矩。若研究引导，另加条件与空条件训练，并独立评估条件遵从和类内多样性。每个新增机制都应有对应断言或反例，避免把全部问题混在一次大训练里。

<a id="ddpm-detail-49"></a>

## 13. 用可解析双峰分布理解最优去噪器

<a id="ddpm-detail-50"></a>

### 13.1 扰动后的分布仍是高斯混合

令干净分布为两个等权高斯的混合，中心为负 $m$ 与正 $m$，局部方差为 $s_0^2$。经过任意时刻扰动，每个分量仍是高斯，中心变为对应的 $\pm\sqrt{\bar\alpha_t}m$，共同方差变为 $v_t=\bar\alpha_ts_0^2+1-\bar\alpha_t$。这给出一个完整可解析的扰动边缘，而不是只知道均值和方差。

对某个含噪位置，正分量的后验责任概率等于两个分量密度归一化后的比值。整理等方差高斯密度比，可得它是一个以含噪坐标为输入的 sigmoid，logit 与 $2\sqrt{\bar\alpha_t}mx_t/v_t$ 成正比。低噪声时，远离零的位置通常被某个分量明确解释；高噪声时，两个分量高度重叠，责任概率趋向混合先验。这描述了模式身份在前向链中如何逐渐丢失。

通过这个例子可以给网络一个更严格的参照：不是要求它猜中每条记录的模式，而是要求它逼近正确的条件平均。接近模式分界处时，两种解释都可能合理，最优去噪均值会折中。这个折中并非模型一定生成中间错误样本，因为完整逆向过程还包含随机性和后续更新；不能只把某一时刻的条件均值可视化就代表最终生成分布。

<a id="ddpm-detail-51"></a>

### 13.2 解析得分与网络目标

高斯混合的得分是各分量得分按责任概率加权后的和。对当前对称例子，它可以写成 $[-x_t+\sqrt{\bar\alpha_t}m\tanh(\sqrt{\bar\alpha_t}mx_t/v_t)]/v_t$。乘以负的噪声标准差，就得到最优条件噪声预测。这个表达式提供了不依赖训练结果的理想函数，适合检查网络是否在不同时间和坐标上偏离真实目标。

低噪声时，这个函数需要在两个局部团簇附近表达细致斜率；高噪声时，它更接近一个总体收缩形式。若只用一个不依赖时间的线性网络，就不可能同时精确表达整个函数族。增加网络容量可以改善逼近，但需要有训练覆盖和合适时间特征。只看最终平均 MSE，可能掩盖分界附近或某些噪声时刻的结构性偏差。

进一步可以按固定时间画出解析得分与网络预测得分，并在数据高密度区和低密度区分别计算误差。低密度区误差可能对普通验证平均影响较小，却在采样轨迹偏离后变得重要。这也是训练分布与实际采样输入之间存在差异的一个来源：采样中的模型误差可能把状态推到训练含噪样本很少出现的区域。

<a id="ddpm-detail-52"></a>

### 13.3 精确均值也不等于精确逆向核

给定模式标签与当前含噪值，前一时刻的条件分布可以是高斯；但当模式标签未知时，完整逆向条件通常仍是多个分量的混合。单高斯网络核即使均值完全正确，也可能无法表达这种多峰条件结构。步长足够小时，局部近似更合理，但有限大步下这种结构误差可能明显。它与神经网络预测误差不同，不能通过无限训练自动消除。

因此，一个有价值的控制实验是将网络替换为解析最优条件均值，保持相同高斯方差与时间表采样。如果生成仍有偏差，这部分偏差可归因于有限步高斯逆向近似、终点先验或方差选择，而不应全部归咎于训练不足。随后再与学到的网络比较，就能更清楚地区分概率近似误差和函数学习误差。

<a id="ddpm-detail-53"></a>

## 14. 时间权重、信噪比与目标设计

<a id="ddpm-detail-54"></a>

### 14.1 信噪比表达了哪一种尺度

在本章标准扰动中，常把 $\bar\alpha_t/(1-\bar\alpha_t)$ 称为信噪比系数。它只比较模型规定的信号乘子与噪声方差；若干净数据自身方差不是一，实际方差比还要乘相应数据方差。不同坐标具有不同尺度时，单一信噪比并不完全描述每个坐标的可恢复程度。数据标准化因此直接影响时间日程的含义。

噪声预测误差与干净值预测误差满足时间相关比例：由反解公式，干净值误差平方等于 $(1-\bar\alpha_t)/\bar\alpha_t$ 乘噪声误差平方。因此未加权噪声损失等价于对干净值误差施加信噪比系数。这个代数关系解释了为什么目标变量和时间权重必须一起讨论，不能只说某种输出参数化天然关注细节或天然关注全局。

<a id="ddpm-detail-55"></a>

### 14.2 重要性时间抽样怎样保持目标

假设希望优化 $\sum_tw_tE[\ell_t]$，从时间分布 $r_t>0$ 抽一个时刻，使用 $w_t\ell_t/r_t$ 就能得到该和的无偏估计。若希望优化时间平均，则还要包含相应总时间数的归一化。这个修正让抽样分布可以偏向高方差或高损失时段，同时保持同一个期望目标；省略修正就会改变目标。

不过无偏不等于低方差。若某些时间概率极小，逆概率权重会非常大，造成偶发巨幅梯度。设计抽样分布时通常需要概率下限和方差监控，但这些选择也要说明。比较一种“更快收敛”的策略时，应确认是否真的保持原目标，以及更快指固定步数、固定网络调用还是固定实际时间，否则可能把目标变简单误认为估计器更高效。

<a id="ddpm-detail-56"></a>

### 14.3 对目标变体保持诚实命名

某些研究会截断信噪比权重、强调特定噪声区间或给不同维度不同权重。这些设计可以有合理动机，但它们回答的是新的折中目标。训练曲线数值变小可能只是权重变小，不能直接推出模型变好。应使用共同的独立评价协议比较最终分布，并尽可能报告各噪声区间的误差变化，以了解收益来自哪里。

如果目标变体改善局部清晰度却损害罕见模式覆盖，结果仍然有价值，但需要呈现代价。没有必要把所有新目标都强行解释为完全相同的原始 ELBO。研究沟通的准确性在于说明改变了什么、为何改变以及实际影响，而不是为每个工程技巧寻找一个超出证据范围的理论包装。

<a id="ddpm-detail-57"></a>

## 15. 图像与潜空间扩散的建模边界

<a id="ddpm-detail-58"></a>

### 15.1 图像张量与独立噪声

把一维实验扩展到图像时，前向噪声通常在所有像素和通道上独立标准正态。时间系数对一个样本的所有特征相同，但不意味着噪声数值相同。误把一个标量噪声广播到整张图，会使扰动协方差变成低秩结构，完全改变训练问题。正确实现应检查噪声张量形状与经验相关性，而不是只检查输出图像看起来变花了。

图像网络可以使用卷积、注意力和多尺度结构，但这些结构不会改变前向概率公式。损失按像素求和或平均会改变整体尺度，若同时存在条件辅助项或方差学习项，相对权重也会变化。把小型向量代码迁移到高维图像前，应先逐项标注轴和归一化规则，避免网络大了之后才发现目标并非预期。

<a id="ddpm-detail-59"></a>

### 15.2 潜空间压缩引入第二个生成模型

潜空间扩散先用另一个编码器把数据变为低维表示，在这个表示空间学习扩散，再用解码器恢复观测。它降低计算成本，但最终质量还受压缩模型影响。压缩丢掉的细节，后续扩散未必能够可靠恢复；解码器可能生成看似合理却不忠于原始观测的细节。因此需要分别评价压缩重构与潜变量生成，而不是把所有错误都归因于扩散网络。

潜变量尺度同样关键。编码器输出的分布若方差很大或各维差异明显，直接套用某个预设噪声日程会改变有效信噪比。训练与采样需要使用一致的缩放，并保存对应尺度参数。推断时忘记逆缩放，可能产生严重失真；这种问题来自部署函数不一致，不是模型理论失效。

<a id="ddpm-detail-60"></a>

### 15.3 条件表示与训练可用性

文本条件、类别条件和其他模态条件都需要可用且一致的表示。若条件编码器在训练与推断中使用不同分词、不同版本或不同归一化，去噪网络接收的条件分布会改变。模型参数之外，条件处理流程也是最终生成器的一部分。资料应清楚区分本章已经实跑的一维无条件实验与更大系统的概念扩展，避免让读者误以为本章代码已经包含文本图像系统。

条件输入还可能被错误地当成真实观测约束。一个描述“红色球”的条件只提供语义倾向，并不保证每次生成都满足颜色、数量或空间关系。需要专门评价每一类条件要求。对于物理或工程任务，如果条件包含硬约束，应另外设计有效性检查或有约束生成机制，并报告拒绝与修复对分布的影响。

<a id="ddpm-detail-61"></a>

## 16. 训练稳定、滑动平均与状态复现

<a id="ddpm-detail-62"></a>

### 16.1 参数滑动平均究竟平均什么

一些实现维护训练参数的指数滑动平均，用于采样评价。它可能平滑随机更新导致的波动，但得到的是另一组参数，并非当前网络的同义表示。应明确平均衰减、开始时间、更新频率，以及最终评价使用原参数还是平均参数。若网络还有缓冲区或非参数状态，也需要说明怎样处理，不能只平均权重后忽略归一化统计。

公平比较应避免某方法评价最佳平均检查点、另一方法评价末次原始参数。滑动平均本身增加存储和状态管理成本，虽然采样调用次数不变。若结果改善，仍需要在多个种子上验证稳定性；一个检查点偶然更好不能证明所有任务都应采用相同衰减。对于本章小型实验，未使用参数平均，结果完全来自固定训练预算的末次网络。

<a id="ddpm-detail-63"></a>

### 16.2 恢复训练需要更多状态

如果需要中断后精确延续，不仅要保存网络参数，还要保存优化器状态、训练步数、随机数状态以及时间日程和预处理配置。学习率日程与随机时间抽样都会影响后续更新。只保存一个权重文件可以支持某些采样任务，却不能证明能够恢复同一训练轨迹。最终资料保留代码和协议即可，运行时临时文件应自动清理，不应混入学习结果目录。

采样复现也需要记录起始随机种子、每步噪声规则、时间子序列、参数检查点与引导配置。只写“相同种子”但更改批次顺序或采样器，随机数消费顺序可能不同，输出也会不同。合理复现标准应包括统计结论与数值容差，而不是默认跨设备逐位一致；若研究需要精确轨迹，应另外固定软件与设备条件。

<a id="ddpm-detail-64"></a>

### 16.3 数值故障应沿路径定位

如果采样中出现非有限值，应记录最早异常时刻，检查累计系数、平方根参数与网络输出尺度。累计乘积接近零时，反解干净值会放大误差；某些表达式中一减去接近一的数又会发生消减误差。适当精度、稳定系数计算与范围检查可以减少问题，但简单把全部异常值替换成零会改变采样分布并隐藏根因。

裁剪预测干净值可能限制极端输出，但它也修改了逆向均值。若数据原本有真实尾部或不在裁剪范围内，质量可能因此受损。应报告裁剪范围及触发比例，并与不裁剪版本比较。数值稳定措施一旦影响输出分布，就不再只是无需说明的内部实现细节，而是最终生成器定义的一部分。

<a id="ddpm-detail-65"></a>

## 17. 评价、误差分解与研究设计

<a id="ddpm-detail-66"></a>

### 17.1 将误差来源逐层分开

完整生成误差至少包含终点先验失配、有限步逆向分布近似、网络预测误差、数值离散或实现错误，以及有限样本评价误差。不同改进针对不同层次：训练更多可能降低网络误差，却不能自动修正错误时间索引；采用解析得分可隔离学习误差，却仍受有限步核近似影响；增加生成样本量只减小评价抽样误差，不会改善模型本身。

设计实验时可以先用标准正态数据作为最简单参照，因为前向边缘保持标准正态，某些统计容易核对。再用单高斯检查尺度与收缩，最后用双峰检查模式结构。这样的递进比直接训练复杂图像更容易定位错误。每一级都应有独立的解析预期，避免只靠“结果看起来差不多”判断正确性。

<a id="ddpm-detail-67"></a>

### 17.2 采样链中的误差累积

训练时的输入来自真实数据前向扰动，而采样时的输入来自模型自己上一时刻的输出。如果早期反向步骤产生偏差，后面的网络可能遇到训练中较少见到的位置，进一步放大误差。这种分布偏移解释了为什么低验证 MSE不一定转化成同等好的生成。可以记录中间状态的均值、方差和模式结构，与真实前向边缘作比较。

但中间统计偏差也不是完整诊断。两个分布可能共享矩却有不同模式，所以在人工问题上最好直接比较已知混合密度或分位数。在真实图像上则需要多种外部表示与分层评价。若只在最终图片里挑选少量成功样本，就无法观察偏差是在何时产生、是否集中于罕见模式，也无法指导下一步研究。

<a id="ddpm-detail-68"></a>

### 17.3 成本应该按完整生成流程计算

生成一次样本的成本不仅是网络参数量，还包含反向调用次数、条件与空条件双分支、条件编码、解码器和后处理。批次拼接可以提升硬件利用率，却不等于调用计算量被消除。比较低步数与高步数采样器时，应在相同图像大小、批次、设备与精度下测量，同时报告质量与覆盖变化。

本章仅运行普通 CPU 上的一维小网络，能够验证概率与代码链条，没有测量图像系统速度，也没有使用预训练权重或外部服务。后续扩展时应重新建立预算表，而不是把本章几秒钟运行时间按维数线性外推。大模型中的注意力、内存访问与批次限制都会破坏这种简单估算。

<a id="ddpm-path-kl"></a>

### 17.4 从路径 KL 推出终点误差界

“误差可能累积”还可以变成一个有明确条件的数学结论。令 $Q$ 是从真实数据 $q_0$ 出发执行前向扰动得到的整条路径分布，$P_\theta$ 是从先验 $p_T$ 出发执行逆向模型得到的路径分布。以下假定相关条件分布存在、$Q$ 对 $P_\theta$ 绝对连续，所写 KL 有限，且使用自然对数。真实前向马尔可夫链也可反向分解，所以路径密度比逐项取对数、再取真实路径期望，得到

$$
D_{\rm KL}(Q\Vert P_\theta)
=D_{\rm KL}(q_T\Vert p_T)
+\sum_{t=1}^T E_{x_t\sim q_t}
D_{\rm KL}\!\left(q(x_{t-1}\mid x_t)\Vert p_\theta(x_{t-1}\mid x_t)\right).
$$

这里的真实逆向核只条件于 $x_t$，不是训练时额外给定干净样本的 $q(x_{t-1}\mid x_t,x_0)$。两者不能混称为同一个“精确后验”。再将路径分布按 $x_0$ 和其余变量条件分解，路径 KL 等于 $D_{\rm KL}(q_0\Vert p_{\theta,0})$ 加一个非负条件 KL，因而

$$
D_{\rm KL}(q_0\Vert p_{\theta,0})\le D_{\rm KL}(Q\Vert P_\theta),\qquad
\operatorname{TV}(q_0,p_{\theta,0})
\le\sqrt{\frac12D_{\rm KL}(Q\Vert P_\theta)}.
$$

总变差定义为所有可测集合概率差绝对值的上确界，第二个不等式是该约定下的 Pinsker 界。这是一项充分控制：先验匹配好、每一步在真实边缘上的逆向 KL 总和小，最终分布差异就受到控制。界可能很松；某一步 KL 大并不反向证明最终误差必然大，因为后续映射可能抹去差异。

用一个三步标量例子核对尺度。真实数据是标准正态，每一步前向方差为 $\beta=0.01$、$\alpha=0.99$，所以各时刻边缘都保持标准正态，真实逆向核是 $N(\sqrt\alpha x_t,\beta)$。令模型先验完全正确，但每步逆向均值都多 $\delta=0.02$，方差仍为 $\beta$。每步条件 KL 是 $\delta^2/(2\beta)=0.02$ nat，三步路径 KL 为 $0.06$，从而总变差上界约 $0.1732$。均值误差平方仅为 $0.0004$，却还必须除以噪声方差；这解释了低噪声处的小绝对误差为何值得单独检查。此例生成终点仍为方差一的高斯，其均值为 $\delta(1+\sqrt\alpha+\alpha)$，可进一步直接核对终点 KL 确实小于路径 KL。

最后把这个结论接回噪声训练。在同一时刻令 $\epsilon^*(x_t)=E[\epsilon\mid x_t]$，平方误差正交分解给出

$$
E\|\epsilon-\epsilon_\theta\|^2
=E\|\epsilon-\epsilon^*\|^2+E\|\epsilon^*-\epsilon_\theta\|^2.
$$

第一项是条件噪声本身的不可约方差。因此原始验证 MSE 非零，并不直接说明网络没有学到最优去噪器。对第 4.2 节固定方差、相同均值参数化的中间时刻，网络相对最优均值网络的额外 KL 恰由第二项乘该节权重得到。最优单高斯逆向核自身仍可能有第 13.3 节的结构误差；若还改变采样步数或方差，上述同一目标下的比较需要重新建立，不能把一条未加权 MSE 曲线直接当作最终分布保证。

## 18. 本章实跑结果的具体解释

<a id="ddpm-detail-70"></a>

### 18.1 解析实验与完整训练

前向矩实验的理论均值约一点二四八六，方差约零点七五零六，逐步和直接抽样都在预先设定容差内。后验系数实验得到方差约零点零三六四，精度形式、系数形式与噪声形式的均值一致；加权噪声误差也与高斯均值 KL 项一致。参数化实验通过全部反解，并展示引导权重零、一、三对应的示例均值零、一点五、四点五。

完整双峰模型的固定验证噪声 MSE 从约零点九六零八降到零点三零七五，终点累计信号系数约零点零零五四三七。六千个生成样本中，正半轴比例约百分之五十一点三八，距离任一模式中心小于零点八的比例约百分之九十九点六二，样本均值约零点零五二七，二阶矩约四点一零四五。它们与真实均值零、二阶矩四点零九较接近，但不是总体分布相等的证明。

生成正负比例的偏差可能同时包含有限采样波动与训练分布偏差。若需要作方法比较，应固定训练结果增大采样量估计计数不确定性，再重复完整训练观察种子差异。这里没有只挑最好检查点，也没有根据最终样本调阈值。结果限定为本章给定数据、网络、日程和末次参数的机制演示。

<a id="ddpm-detail-71"></a>

### 18.2 三个逐步深入的研究题

第一个题目是终点失配：固定网络预算，改变日程使终点残留信号分别较大与较小，检查终点解析 KL、验证误差和生成覆盖的关系。应避免同时改变训练时间范围而不报告，因为那会让问题混入新的时间分配影响。这个题目帮助理解为什么“最后看起来像噪声”不是充分检验。

第二个题目是有限步近似：使用解析双峰得分代替神经网络，在不同步数与正确对应系数下采样，观察高斯逆向近似带来的残余偏差。第三个题目是学习误差：固定日程与采样器，比较不同时间编码或网络容量，按时刻报告相对解析得分的误差。三个题目分别针对不同误差层，不需要一开始就训练巨大的图像模型。

<a id="ddpm-detail-72"></a>

### 18.3 什么算完成了本章学习

应能从前向条件独立高斯噪声推导闭式边缘，能通过配方推导非退化后验，能解释第一步为何特殊，能把噪声误差与变分均值项权重对应起来。还应能在不看代码的情况下写出正确祖先采样流程，说明哪些噪声必须独立，哪些参数需要与训练保持一致。仅记住一个去噪网络名字还不足以完成这些要求。

更进一步，应能指出一个论文或实现把简化 MSE、精确 ELBO、得分、速度和确定性采样混用时的具体错误，并给出修正条件。能区分理论恒等式、有限模型近似与实验观察，就能更可靠地阅读后续扩散、潜空间生成与流模型研究。求知的重点不是收集更多缩写，而是把每个缩写背后的概率对象、条件和代价真正连接起来。

<a id="ddpm-detail-73"></a>

### 18.4 用标准正态数据建立额外理论参照

如果干净数据本身就是标准正态，前向每个边缘也都是标准正态，边缘得分恒为负的当前坐标。最优噪声预测于是为噪声标准差乘当前坐标。这个结果可以直接通过联合高斯条件期望推导，而不需要训练。它是检查噪声与得分符号的简单参照：若实现得到反号，反向过程通常会把状态推向不合理区域。

这个例子还揭示固定后验方差的近似。已知干净值时的前向后验方差是本章的 $\tilde\beta_t$，但只给当前含噪值、不再给干净值时，标准正态平稳链的真实逆向条件方差是 $\beta_t$。二者并非同一个条件对象。若把已知干净值的后验方差当成边缘逆向的绝对真值，即使均值正确，也可能产生不匹配的方差。标准 DDPM 可以采用不同方差设置，选择需要与目标和采样协议一起说明。

对于双峰数据，这个区别更明显，因为未知模式带来额外条件不确定性。使用前向条件后验作为训练监督有严格变分依据，但学习到的单高斯逆向核仍是近似。理解“条件中多知道一个变量会减少不确定性”，能够避免把训练中精确可计算的后验与生成时实际需要的逆向分布混淆。这个区分也适用于其他隐变量模型，而不只是扩散。

<a id="ddpm-detail-74"></a>

### 18.5 去噪均值、随机生成与测量反演

在观测反演任务中，已知一张真实含噪图，希望估计对应干净图，条件均值可能是合理的平方误差最优输出。但无条件生成的任务是恢复整个数据分布，需要保留合法的不确定性。反复应用一个确定性均值映射可能把多种解释压缩到平均值，不能直接视为完整概率采样。相同去噪器在不同任务中的使用方式，决定了需要评价误差还是评价分布。

若还有额外测量 $y=Ax+\eta$，生成条件应包含测量模型、噪声假设与可用信息。把扩散先验的输出直接投影到满足测量的集合，有时是有用策略，但改变了原先逆向链，不能无条件称为精确后验采样。需要检查测量一致性、先验合理性和不确定性覆盖，而不是只展示一张符合测量的漂亮结果。对于不可识别反演，多个合法答案本来就可能存在。

因此，从本章走向图像修复、条件生成或科学反演时，第一步应重新写清目标分布：是在求某个点估计，还是从条件分布抽样？条件信息在何时可获得？测量误差是否建模？只有这些对象明确，才有依据判断网络输出、引导项与后处理是否合理。否则再复杂的采样循环也可能只是一个无法清楚说明统计含义的变换管线。

另一个值得记录的边界是固定验证噪声。它让训练前后比较共享随机扰动，从而降低差值的估计噪声，但如果反复围绕同一组验证噪声选择网络和日程，也会产生适应性。最终方法比较可以在新的独立干净样本、时间和噪声上重新评价，并把时间分箱结果与总体结果一起报告。增加验证样本数只能提高估计精度，不能消除选择过程对验证集的依赖。

模型选择应事先规定主要指标与预算，尤其不能在看到某个种子生成偏差后随意延长训练，再只报告它的最终成功。如果确实因诊断改变了设置，应把它作为新实验完整记录。训练失败、非有限值、模式失衡和超出预算的运行，都属于方法实际表现的一部分。保留这些证据能够让读者判断收益是否稳定，也避免把一个成功演示误认为普遍保证。
