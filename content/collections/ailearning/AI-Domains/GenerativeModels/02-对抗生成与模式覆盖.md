## 1. 对抗学习首先是一个分布比较问题

生成对抗网络由生成器与判别器组成，但两张网络不是它最本质的定义。它先提出一个分布比较任务：真实样本来自 $`P`$，生成样本来自 $`Q_\theta`$，能否用一个可学习的测试函数发现二者差异？生成器根据这个测试函数提供的反馈调整自己的分布。实际训练把总体期望替换成有限样本，把无限函数族替换成有限网络，并把精确最优替换成若干步更新，这三层近似决定了理论公式与真实实验之间的距离。

生成器通常写为 $`x=G_\theta(z)`$，其中 $`z`$ 来自简单噪声分布。这个映射直接定义了可采样分布，却未必提供可计算密度。若隐变量维数小于输出维数且映射足够规则，分布可能集中在低维集合上，对全空间的普通密度并不存在。因此描述 GAN 时不应默认所有分布都能用处处有限的密度函数表示；需要使用相对于共同支配测度的密度，或者直接使用概率测度语言。

<a id="sec-1-1"></a>

<a id="gan-detail-2"></a>

### 1.1 训练、推断与评价各自需要什么

训练阶段需要从数据与噪声抽样，计算两方损失并交替更新。无条件推断通常只需要生成器，不再需要判别器。评价则需要独立参考数据、固定采样规则和覆盖诊断，不能只把训练中判别器的损失当成最终质量。判别器经过共同训练，它既受到生成器影响，也受到自身优化程度和容量影响，不是一个稳定的外部评测仪。

例如生成器复制训练样本，训练判别器仍可能难以区分真实与复制，训练目标看起来很好。但独立总体的覆盖和隐私风险并未因此解决。反过来，一个容量不足的判别器对真实和随机噪声都输出二分之一，也不意味着随机噪声已经与真实分布相同。只有在明确函数族、优化和数据条件的前提下，判别器表现才具有相应解释。

<a id="gan-detail-3"></a>

### 1.2 什么叫模式与模式覆盖

本章用已知人工分布中的独立概率质量团簇作为模式，便于计算覆盖。在真实数据上，“模式”通常依赖表示和任务，例如一种姿态、一种类别或一种语义组合，并没有总是唯一的分割。模式覆盖评价应先声明怎样划分、罕见模式占比多少、是否把不合理样本也分配给最近模式，否则看似精确的覆盖率可能误导。

生成质量包含至少两个维度：样本是否落在合理区域，以及这些合理区域的概率是否分配正确。只生成一个清晰类别会获得高局部质量但低覆盖；遍历所有类别却生成大量离群点则可能有较高覆盖而低可信度。最近中心计数与到中心距离需要联合使用，因为任何远离所有中心的点也会被最近邻规则强行归入某个中心。

## 2. 原始 GAN 目标的推导与条件

<a id="sec-2"></a>

<a id="gan-detail-5"></a>

### 2.1 从二分类风险到极小极大

令 $`D_\psi(x)\in(0,1)`$ 表示样本来自真实分布的概率，在真实与生成来源等概率抽取的分类问题中，判别器最大化

$$
V(D,G)=E_{x\sim P}\log D(x)+E_{x\sim Q_\theta}\log(1-D(x)).
$$

生成器在原始极小极大形式中最小化这个值。第一项在固定判别器时与生成器无关，第二项让生成器尝试提高生成样本的判别概率。此处的等概率来源是人为定义的训练分类任务，不是现实世界真实图片与假图片的自然比例。改变分类来源权重会改变最优后验公式以及对应的分布比较形式。

如果 $`D=\sigma(a)`$，其中 $`a`$ 是 logit，判别器的负目标应使用稳定的带 logits 二元交叉熵，等价于真实样本的 $`\operatorname{softplus}(-a)`$ 与生成样本的 $`\operatorname{softplus}(a)`$。先做 sigmoid 再手工计算对数在极端输入处容易饱和，导致无穷或舍入为零。损失表达式虽然数学等价，数值路径却可能不同，工程实现应优先使用稳定形式。

<a id="sec-2-1"></a>

<a id="gan-detail-6"></a>

### 2.2 固定生成器时的最优判别器

设 $`p,q`$ 是相对于同一支配测度的密度。对每个 $`x`$，最大化 $`p\log D+q\log(1-D)`$。导数为 $`\frac{p}{D}-\frac{q}{(1-D)}`$，二阶导数在相关区域为负，因此当 $`p+q>0`$ 时，最优值是

$$D^*(x)=\frac{p(x)}{p(x)+q(x)}.$$

当 $`p=q=0`$ 时，该点对目标没有贡献，判别器取值不影响积分；当其中一个为零时，最优值在区间端点，有限 sigmoid 网络通常只能逼近。将两个分布的和作为支配测度，可以在不要求全空间普通密度的情况下理解同一表达式。这个细节对于集中在不同流形上的分布尤其重要。

最优判别器表达的是训练来源后验，不是样本的绝对真实程度。若某区域 $`p=q`$ 都很小，判别器仍给二分之一；若某合法稀有区域生成器从不覆盖，则最优判别器趋近一。由此不能把判别器分数直接当作美学质量、物理可行性或异常概率，它依赖两个当前比较的分布。

<a id="gan-detail-7"></a>

### 2.3 代入后得到 Jensen–Shannon 散度

记混合分布 $`M=\frac{(P+Q)}{2}`$，代入最优判别器，整理得到

$$
V(D^*,G)=-2\log2+D_{\rm KL}(P\Vert M)+D_{\rm KL}(Q\Vert M)
=-\log4+2\operatorname{JS}(P,Q).
$$

因为 $`M`$ 同时支配两个分布，相关 KL 在这个构造中不会因对方零密度而直接发散。JS 非负，并在两分布相等时为零，因此在无限函数能力、精确判别器最优与可优化全部分布的理想情形下，目标最小值对应分布一致。这个结论描述的是分布层面的最优点，不是有限神经网络交替梯度必然收敛的证明。

实际训练的判别器没有在每次生成器更新前达到精确最优，生成器也不能任意改变分布。更重要的是，计算机沿当前判别器的空间梯度更新生成样本，而不是直接在所有概率测度上执行理想下降。把上述全局最优结论解释成“只要训练久就能覆盖所有模式”，跳过了最关键的优化与表达条件。

## 3. 支持不重叠时为什么会遇到困难

<a id="gan-detail-9"></a>

### 3.1 两个点质量的反例

取 $`P=\delta_0`$，$`Q_\theta=\delta_\theta`$。只要 $`\theta\ne0`$，两个分布完全可区分，JS 等于 $`\log2`$；当 $`\theta=0`$ 时突然变为零。于是一个从很远移动到很近的生成点，在 JS 这个指标下没有连续改善，直到恰好重合。这不是样本移动毫无价值，而是这个散度在该分布族上无法提供平滑的几何距离。

对于一维 Wasserstein 一阶距离，同一例子得到 $`\vert \theta\vert `$，它持续反映搬运距离。这个比较解释了为什么度量选择会影响优化信号。但它不证明任何 WGAN 网络总能学到真实 Wasserstein 梯度，因为网络容量、Lipschitz 约束、采样与交替优化仍会引入误差。理论距离有良好性质与实际估计器可靠，是两个需要分别论证的问题。

![点质量接近时JS平台与Wasserstein距离的对照](images/02-js-wasserstein.svg)

左图空心圆排除 θ=0 处的 ln 2，实心原点表示两个分布重合时 JS=0；只要 θ>0，JS 都等于 ln 2。右图使用一维绝对距离作为搬运代价，唯一的质量从 0 搬到 θ，因此 $`W_1=\theta`$。两图并排展示的是理想分布距离，不是有限判别器或 critic 的实际训练曲线；也不能将 JS 的平台直接替换成任意非饱和生成器损失对参数的导数。

<a id="gan-detail-10"></a>

### 3.2 有限判别器的空间梯度并不唯一

当两个分布集中在不同集合上时，分类目标主要约束这些集合上的函数值，而对它们之间的变化形状约束不足。多个判别器可以达到相似分类损失，却在生成样本附近给出不同方向和大小的输入梯度。生成器恰好依赖这些梯度，因此分类准确率相同不意味着训练反馈同样有用。

加入输入噪声可能让两分布支持更有重叠，缓和分类过易，但也改变了被比较的分布。噪声尺度过大可能掩盖细节，过小又不能改善分离问题。合理实验应明确噪声是训练策略、数据模型还是评价的一部分，不能在训练目标中悄悄改变数据后仍把结果说成原分布上的精确优化。

## 4. 饱和与非饱和生成器目标

<a id="gan-detail-12"></a>

### 4.1 对 logit 的导数

令生成样本上的判别 logit 为 $`a`$。原始饱和生成器损失是 $`\log(1-\sigma(a))=-\operatorname{softplus}(a)`$，其对 logit 导数为 $`-\sigma(a)`$。当判别器确信样本为假，即 $`a`$ 很负时，这个导数接近零。即使从图像角度看生成样本还很差，沿这一条路径也可能收到很弱的训练信号。

非饱和损失改为 $`-\log\sigma(a)=\operatorname{softplus}(-a)`$，对 logit 导数是 $`\sigma(a)-1`$。在 $`a`$ 很负时它接近负一，提供更强的局部激励。真正对生成器参数的梯度还要乘 $`\nabla_xa`$ 与 $`\nabla_\theta G`$，所以非饱和形式只缓解其中一个因子的消失，不能保证判别器空间梯度方向正确或生成器雅可比良好。

<a id="gan-detail-13"></a>

### 4.2 相同理想固定点不等于相同目标

饱和与非饱和形式都鼓励生成样本获得较高真实判别概率，在理想分布一致点可以共享期望平衡。但非饱和生成器损失不再是原始同一个零和极小极大值函数的简单下降，因此不能把原始 JS 代入推导原封不动地用于它的每一步优化解释。实际使用时应分别写出判别器与生成器各自最小化的损失。

此外，标签平滑、翻转、输入噪声与正则项也会改变目标或最优判别器。把所有训练技巧统称为“稳定 GAN”而不写具体表达式，会使实验无法被复核。本章完整实验使用真实标签一、生成标签零、非饱和生成器损失，不叠加其他技巧，以便读者清楚追踪梯度路径。

## 5. 可运行实验一：最优判别器、JS 与支持反例

下面先在离散分布上验证代入恒等式，再用点质量检查 JS 与一阶搬运距离的差异。这里的状态空间是人工指定的有限集合，因此概率质量可以精确计算，不依赖密度估计。对于零概率项使用零乘对数的连续延拓，而不是直接计算零的对数再乘零。

```python
import numpy as np

def kl(p, q):
    mask = p > 0
    assert np.all(q[mask] > 0)
    return float(np.sum(p[mask]*np.log(p[mask]/q[mask])))
def js(p, q):
    m = (p+q)/2
    return (kl(p, m)+kl(q, m))/2
p = np.array([0.5, 0.25, 0.25])
q = np.array([0.2, 0.5, 0.3])
d = p/(p+q)
v = float(np.sum(p*np.log(d)+q*np.log1p(-d)))
assert np.isclose(v, -np.log(4)+2*js(p, q))
assert np.isclose(js(p, p), 0)
# delta at index 0 versus index 1: disjoint supports.
a = np.array([1., 0.]); b = np.array([0., 1.])
assert np.isclose(js(a, b), np.log(2))
for theta in [0.001, 1.0, 100.0]:
    wasserstein = abs(theta)
    assert wasserstein > 0
print('D*', d, 'V', v, 'JS', js(p, q))
print('disjoint JS', js(a, b), 'point distances', [0.001, 1., 100.])
```

这个例子里 JS 始终使用同样两个非重合点作为不同状态，坐标距离只进入搬运成本。若状态空间本身没有距离结构，Wasserstein 距离也无从凭空定义。图像空间使用像素欧氏距离带来一种特定几何假设，可能不符合语义相似性，因此改用 Wasserstein 目标并不自动解决所有感知质量问题。


<a id="visual-example-generativemodels-02"></a>

### 对照表：真实与生成支持不重叠时的判别器

| 区域 | 真实概率质量 | 生成概率质量 | 理想判别 |
| --- | --- | --- | --- |
| 区域 A | 1 | 0 | 真实概率 1 |
| 区域 B | 0 | 1 | 真实概率 0 |

**说明。** 两个分布完全分居不同区域时，理想判别器可以把来源分开。这个表格说明判别准确率极高不等于生成器已经获得有用的移动方向；在某些目标和参数化下，饱和与支持几何会使生成器梯度贫乏。应直接检查生成器目标及梯度，而非只看判别器分数。

**适用条件。** 这是离散支持示意，不声称所有 GAN 在支持分离时梯度必定为零；非饱和目标与 Lipschitz 约束具有不同分析。


<a id="gan-detail-15"></a>

## 6. 可运行实验二：生成器梯度与更新隔离

下面先核对两个目标对 logit 的解析梯度，再检查交替更新中最容易出错的计算图边界。判别器步使用分离的生成样本，生成器步冻结判别器参数但保留它对输入的导数。冻结参数与关闭整个自动微分不是同一操作，后者会切断生成器需要的梯度。

```python
import torch
from torch import nn
import torch.nn.functional as F

torch.set_num_threads(1)
a = torch.tensor([-20., 0., 20.], dtype=torch.float64, requires_grad=True)
sat = -F.softplus(a).sum()
non = F.softplus(-a).sum()
gsat = torch.autograd.grad(sat, a, retain_graph=True)[0]
gnon = torch.autograd.grad(non, a)[0]
assert torch.allclose(gsat, -a.detach().sigmoid())
assert torch.allclose(gnon, a.detach().sigmoid()-1)
assert abs(gsat[0]) < 1e-8 and abs(gnon[0]) > 0.99

torch.manual_seed(7)
G = nn.Linear(2, 2); D = nn.Sequential(nn.Linear(2, 8), nn.Tanh(), nn.Linear(8, 1))
og = torch.optim.SGD(G.parameters(), lr=.01)
od = torch.optim.SGD(D.parameters(), lr=.01)
z = torch.randn(16, 2); real = torch.randn(16, 2)+1
before_g = [p.detach().clone() for p in G.parameters()]
od.zero_grad(); og.zero_grad()
ld = F.softplus(-D(real)).mean()+F.softplus(D(G(z).detach())).mean()
ld.backward(); od.step()
assert all(p.grad is None for p in G.parameters())
assert all(torch.equal(p, b) for p, b in zip(G.parameters(), before_g))
for p in D.parameters(): p.requires_grad_(False)
before_d = [p.detach().clone() for p in D.parameters()]
og.zero_grad(); lg = F.softplus(-D(G(z))).mean(); lg.backward(); og.step()
assert any(not torch.equal(p, b) for p, b in zip(G.parameters(), before_g))
assert all(torch.equal(p, b) for p, b in zip(D.parameters(), before_d))
for p in D.parameters(): p.requires_grad_(True)
print('logit gradients', gsat.tolist(), gnon.tolist(), 'update isolation passed')
```

这个实验不要求所有参数每一步都发生非零变化，因为某些参数在特定输入下可能恰好没有梯度。它检查生成器在判别器步没有被更新，以及生成器步确实存在参数变化而判别器数值固定。更复杂模型还要考虑缓冲区：即使参数冻结，训练模式下的批归一化运行统计仍可能变化，因此参数值检查不是完整状态检查。

## 7. Wasserstein 目标与 Lipschitz 约束

<a id="sec-6"></a>

<a id="gan-detail-17"></a>

### 7.1 从搬运问题到对偶测试函数

一阶 Wasserstein 距离定义为所有具有指定边缘分布的耦合中，期望搬运距离的最小值：$`W_1(P,Q)=\inf_{\pi\in\Pi(P,Q)}E_\pi\Vert X-Y\Vert `$。在适当空间与有限一阶矩条件下，其对偶形式为 $`\sup_{\Vert f\Vert _{\rm Lip}\le1}(E_Pf-E_Qf)`$。这里的测试函数称为 critic，它输出实数分数，不是零到一的类别后验。

一 Lipschitz 约束意味着任意两点的函数值之差不超过输入距离。若取消这个约束，只要存在可区分的方向，任意放大函数就能任意增大期望差，目标不再表示有限的搬运距离。约束必须与输入空间选定的距离一致；对坐标做缩放会改变几何以及梯度约束的含义，因此数据预处理仍是方法的一部分。

<a id="sec-6-1"></a>

<a id="gan-detail-18"></a>

### 7.2 梯度惩罚的正确含义

对于可微函数，在合适的凸区域内，处处梯度范数不超过一能给出相应 Lipschitz 上界。WGAN-GP 常在真实与生成样本之间随机插值，惩罚 $`(\Vert \nabla_{\hat x}f(\hat x)\Vert _2-1)^2`$。它让抽样到的位置倾向单位梯度，既不是检查所有位置，也不等同于只限制梯度不超过一。于是它是有动机的软约束，不能被描述为精确执行全局 Lipschitz 条件。

计算该惩罚时，需要输入梯度本身保留可微图，才能把惩罚反传到 critic 参数。若只算出输入梯度的数值，再分离计算图，critic 就收不到这项约束的梯度。还有一个维度陷阱：梯度范数应按每个独立样本的所有特征求范数，再在批次中平均，不能把整个批次的梯度压成一个标量后称为逐样本约束。

<a id="gan-gp-soft-constraint"></a>

#### 图解：有限梯度惩罚为何不能当作精确 Wasserstein 距离

![梯度惩罚的软约束最优点与 Wasserstein 真值对照](images/02-gp-soft-constraint.svg)

**把采样误差完全去掉，软约束仍可能越界。** 设真实分布为集中在零的点质量 $`P=\delta_0`$，生成分布为 $`Q=\delta_a`$，其中 $`a>0`$，输入距离采用普通绝对值。全部质量必须从零搬到 $`a`$，因此真实搬运距离为 $`W_1(P,Q)=a`$。限制 critic 为 $`f_w(x)=wx`$；加常数偏置会在两个期望的差中抵消。它的 Lipschitz 常数恰好是 $`|w|`$，原始分差为

$$
\mathbb E_P f_w-\mathbb E_Q f_w=-aw.
$$

若严格要求 $`|w|\le1`$，最大值在 $`w=-1`$ 取得，恰好等于 $`a`$。现在改用有限系数 $`\lambda>0`$ 的梯度惩罚。这个线性函数在整个实轴上的输入梯度都是 $`w`$，所以无论插值点取多少、取在哪里，惩罚都能精确算出，不存在“漏查某个尖峰”的借口。采用最大化方向书写，目标为

$$
J_\lambda(w)
=-aw-\lambda(|w|-1)^2.
$$

原始 WGAN-GP 通常以最小化 critic 损失的方向表达同一分差与惩罚；使用前应先统一符号，避免把惩罚变成奖励。[Improved Training of Wasserstein GANs，第 4 节](https://arxiv.org/pdf/1704.00028)

**完整求解软约束最优点。** 同样的 $`|w|`$ 下，负的 $`w`$ 给出更大的分差，因此只需令 $`u=-w\ge0`$，求解严格凹二次函数

$$
J_\lambda(-u)=au-\lambda(u-1)^2,
\qquad
\frac{\mathrm dJ_\lambda(-u)}{\mathrm du}
=a-2\lambda(u-1).
$$

令导数为零即可得到

$$
u^*=1+\frac{a}{2\lambda},
\qquad
w^*=-\left(1+\frac{a}{2\lambda}\right).
$$

对任意有限 $`\lambda`$，最优梯度范数都严格大于一。越过约束边界带来的分差收益，在足够小的越界幅度内超过二次惩罚成本。这个现象发生在惩罚处处精确、优化也精确的极简问题中，因而增加插值采样点不能消除它。

还要区分三个常被日志混用的量：

$$
\begin{aligned}
\text{真实距离}&=a,\\
\text{原始分差}&=a+\frac{a^2}{2\lambda},\\
\text{减去惩罚后的目标}&=a+\frac{a^2}{4\lambda}.
\end{aligned}
$$

最后一行来自扣除惩罚值 $`\lambda(u^*-1)^2=\frac{a^2}{4\lambda}`$。图中固定 $`a=2`$：$`\lambda=1`$ 时三者为 $`2,4,3`$；$`\lambda=10`$ 时为 $`2,2.2,2.1`$；$`\lambda=100`$ 时为 $`2,2.02,2.01`$。后两列都超过真值，因为对应 critic 不满足原始对偶问题的可行性要求；不能把其原始分差称为由可行 critic 提供的 Wasserstein 下界。

**这个反例说明的是目标含义。** 在本例中令 $`\lambda\to\infty`$，最优点确实趋向硬约束边界；这不证明任意神经网络在无限惩罚、有限优化预算下都能收敛到精确距离。单位梯度惩罚还会惩罚小于一的梯度，而硬 Lipschitz 上界允许这些梯度。梯度惩罚可以作为有用的训练正则，但需要同时记录分差、惩罚值与梯度范数，结合生成样本评价，而不能把某一训练标量直接标成真实搬运距离。

<a id="gan-detail-19"></a>

### 7.3 权重裁剪、谱约束与容量

权重裁剪容易实现，却通过每个参数的范围间接限制整个函数，可能严重压缩 critic 的表达能力。对线性层施加谱范数约束，可以控制欧氏算子范数；多个层的 Lipschitz 上界还要与激活函数及结构组合。有限步幂迭代只是谱范数的数值近似，残差连接与归一化层也要纳入整体分析。

不同约束方案改变了可学习函数族和优化问题，不能只用“都满足稳定性”来视为等价。比较时需要固定目标方向、critic 更新次数、参数量与计算预算，并检查输入梯度分布和生成结果。critic 目标下降不等于真实 Wasserstein 距离被精确测量，尤其在约束只是局部软惩罚且 critic 尚未优化充分时。

<a id="gan-detail-20"></a>

## 8. 可运行实验三：输入梯度惩罚可反传

用一维线性 critic $`f(x)=wx+b`$，输入梯度范数恰好是 $`\vert w\vert `$。当 $`w=2`$ 时，单位梯度惩罚为一，对 $`w`$ 的导数为二。这个最小例子能够精确检验二阶自动微分路径，避免把复杂 GAN 训练失败全部归因于学习率。

```python
import torch
from torch import nn

torch.set_num_threads(1)
critic = nn.Linear(1, 1, dtype=torch.float64)
with torch.no_grad():
    critic.weight.fill_(2.0); critic.bias.fill_(0.3)
x = torch.linspace(-1, 1, 13, dtype=torch.float64).reshape(-1, 1)
x.requires_grad_(True)
y = critic(x)
grad = torch.autograd.grad(y.sum(), x, create_graph=True)[0]
penalty = (grad.flatten(1).norm(2, dim=1)-1).square().mean()
dw = torch.autograd.grad(penalty, critic.weight)[0]
assert torch.allclose(penalty, torch.tensor(1., dtype=torch.float64))
assert torch.allclose(dw, torch.tensor([[2.]], dtype=torch.float64))
print('linear gradient penalty', float(penalty.detach()), 'weight derivative', dw.item())
```

这个实验没有声称梯度惩罚已经保证全局 Lipschitz，因为线性函数的特殊结构使检查简单，而多层网络在未抽样区域仍可能有很大梯度。对于复杂模型，可以同时画出或统计随机插值位置、真实位置与随机外部位置的梯度范数，但有限抽样始终只提供诊断证据。约束范围与理论全局条件之间的距离必须在报告中保留。

<a id="gan-detail-21"></a>

## 9. 完整实验：四峰人工数据上的非饱和 GAN

<a id="gan-detail-22"></a>

### 9.1 数据和评价协议

下面用二维四峰混合分布训练一个小型 GAN。每次真实样本从已知分布独立抽取，因此不存在文件读取与训练集复用问题。生成器输入二维标准正态，输出二维连续点；判别器使用平滑激活，输出一个 logit。两方每轮各更新一次，采用同一类优化器但独立参数集合与优化器状态。

评价预先固定四个中心及半径零点六。报告所有生成样本的最近中心占用、落在任一中心邻域的比例以及邻域内各模式的实际质量占比。这样能够同时识别遗漏模式、离群点与概率失衡。还报告样本均值和协方差的粗略差异，但不把矩匹配当作分布一致证明，因为不同的多峰分布可以具有相同前两阶矩。

<a id="gan-detail-23"></a>

### 9.2 可独立执行的训练与采样代码

```python
import torch
import numpy as np
from torch import nn
import torch.nn.functional as F

torch.set_num_threads(1)
torch.manual_seed(42)
centers = torch.tensor([[-2., -2.], [-2., 2.], [2., -2.], [2., 2.]])
rng = torch.Generator().manual_seed(43)
def real_batch(n):
    ids = torch.randint(4, (n,), generator=rng)
    return centers[ids]+0.15*torch.randn(n, 2, generator=rng)
def noise(n): return torch.randn(n, 2, generator=rng)
G = nn.Sequential(nn.Linear(2, 48), nn.Tanh(), nn.Linear(48, 48),
                  nn.Tanh(), nn.Linear(48, 2))
D = nn.Sequential(nn.Linear(2, 48), nn.LeakyReLU(.2), nn.Linear(48, 48),
                  nn.LeakyReLU(.2), nn.Linear(48, 1))
og = torch.optim.Adam(G.parameters(), lr=.001, betas=(.5,.9))
od = torch.optim.Adam(D.parameters(), lr=.001, betas=(.5,.9))
initial_g = [p.detach().clone() for p in G.parameters()]
last = None
for step in range(3000):
    for p in D.parameters(): p.requires_grad_(True)
    real, z = real_batch(128), noise(128)
    od.zero_grad()
    fake = G(z).detach()
    loss_d = F.softplus(-D(real)).mean()+F.softplus(D(fake)).mean()
    loss_d.backward(); od.step()
    for p in D.parameters(): p.requires_grad_(False)
    og.zero_grad()
    loss_g = F.softplus(-D(G(noise(128)))).mean()
    loss_g.backward(); og.step()
    last = (float(loss_d.detach()), float(loss_g.detach()))
for p in D.parameters(): p.requires_grad_(True)
with torch.no_grad():
    ev = torch.Generator().manual_seed(44)
    sample = G(torch.randn(8000, 2, generator=ev))
    distances = torch.cdist(sample, centers)
    best, ids = distances.min(1)
    occupancy = torch.bincount(ids, minlength=4).float()/len(sample)
    near = best < .6
    near_mass = torch.bincount(ids[near], minlength=4).float()/len(sample)
assert torch.isfinite(sample).all() and np.isfinite(last).all()
assert any(not torch.equal(p,b) for p,b in zip(G.parameters(), initial_g))
assert torch.isclose(occupancy.sum(), torch.tensor(1.))
assert near_mass.sum() <= 1.000001
print('last discriminator/generator losses', last)
print('occupancy', occupancy.tolist(), 'near mass by mode', near_mass.tolist())
print('near fraction', float(near.float().mean()), 'mean', sample.mean(0).tolist())
```

<a id="gan-detail-24"></a>

### 9.3 结果怎样解释才不越界

断言只核对有限性、参数确实更新与概率质量计算一致，不要求训练后每个模式都达到特定覆盖阈值。模式坍塌正是需要观察的潜在结果，如果把“必须覆盖四峰”写成断言再不停调种子直至通过，就会把方法缺陷从实验记录中抹去。完整报告应保留预先指定种子，必要时增加一组独立重复，并报告全部结果。

最后一步判别器与生成器损失通常没有单调关系。判别器可能因为生成器改善而暂时变差，也可能因为自身训练不足而变差。两方状态都在变化，因此不能像单网络固定目标那样解读每一步曲线。应把训练信号与外部样本质量统计同时展示，且清楚说明本实验没有运行大图像任务，也没有测量任何 GPU 吞吐。

## 10. 模式坍塌的机制与反例

<a id="sec-7-1"></a>

<a id="gan-detail-26"></a>

### 10.1 为什么逐点激励可能聚集到一个区域

固定判别器时，生成器的每个噪声输入都倾向移向判别器给分较高的位置。如果许多输入共享同一参数变化方向，它们可能一起收缩到少数区域。当前判别器随后能识别这种失衡，但生成器在下一阶段又可能移向另一片区域，形成追逐或振荡。因此模式坍塌并不一定是目标最优点本身鼓励遗漏，也可能来自有限网络与交替优化的动态。

有时生成器能覆盖多个模式，但给它们分配错误概率，这也是分布错误。若真实四峰各占四分之一，生成器一峰占百分之九十，其余三峰各少量，展示每峰一张样本会掩盖严重失衡。随机抽样展示与预定义计数比人工挑选更可信。条件 GAN 若每个标签都能生成一种图，也仍可能在每个标签内部遗漏姿态、背景或其他因素。

<a id="gan-detail-27"></a>

### 10.2 非零噪声不保证输出多样

输入噪声的熵很高不意味着输出熵很高，因为确定性网络可能忽略部分乃至全部噪声坐标。检查噪声与输出敏感性、不同输入输出距离以及生成器雅可比有助于发现压缩，但这些局部诊断仍不等于全局覆盖。一个映射可以局部变化丰富却始终局限于一个合法模式，也可以跨模式跳变却在每个模式内缺乏变化。

加入多样性正则或互信息辅助目标可能鼓励使用噪声，但会引入额外权重与假设。若只奖励任意输出距离增大，模型可能生成更多离群点。设计辅助项时必须把“差异”限制在任务相关的合理空间，并独立评价质量与覆盖。任何新正则都应先给出它防止哪种具体退化的反例，再用实验检验是否出现新的退化。


<a id="visual-mechanism-generativemodels-02"></a>

### 图解：逼真度与模式覆盖要在同一分布图上分开看

![逼真度与模式覆盖要在同一分布图上分开看](images/02-mechanism.svg)

**图中的机制。** 真实分布有三个相互分离的簇。生成器可能在其中一个簇内给出非常逼真的样本，却几乎不生成另外两个簇。图把簇内细致程度与跨簇覆盖分开，说明单张漂亮样本无法支持整体分布正确的结论。

**条件与边界。** 簇与点均为人工示意；真实数据的模式往往没有清晰离散边界，覆盖统计还受表示空间和样本量影响。

## 11. 十六道练习与详细答案

<a id="gan-detail-29"></a>

### 11.1 判别器概率是否绝对可信

问题：某生成样本被判别器赋值零点九九，能否说明它有百分之九十九概率来自真实世界？不能。这个值至多是在所定义训练来源混合、当前模型与判别器校准条件下的来源后验，且有限网络未必达到最优。真实世界的来源基率可能不同，判别器也可能受伪影或数据泄露影响。绝对质量与来源后验不是同一个任务，需要另外的有效性标准。

<a id="gan-detail-30"></a>

### 11.2 真实与生成样本数量不等怎么办

如果先分别计算两类样本各自的平均损失再相加，两类仍被赋予相同总体权重，样本数量影响估计方差而不直接改变目标。若把两类拼接后直接整体平均，类别比例便进入训练来源先验，最优判别器公式也相应改变。必须先明确希望实现哪一种权重，再检查代码的求和轴与归一化。小批次数量不等并不自动错误，但默认实现可能悄悄改变理论目标。

<a id="gan-detail-31"></a>

### 11.3 为什么二分之一不证明成功

最优无限容量判别器在分布相同时为二分之一，但反命题在有限训练中不成立。一个常数网络、优化失败的网络或对某些差异不敏感的函数族，也可能输出同样数值。需要独立质量、覆盖与泛化评价，并检查判别器是否能识别已知简单反例。否则“骗过判别器”可能仅说明对手能力不足，而非分布真正一致。

<a id="gan-detail-32"></a>

### 11.4 非饱和损失是否保证不消失

它在生成 logit 很负时对 logit 的梯度较大，但参数梯度还包含判别器输入梯度与生成器雅可比。如果判别器在相关区域几乎常数，或者生成器有饱和单元，最终梯度仍可能很小。因此应分层检查梯度路径，而不是只观察一个公式因子。这个区分还帮助理解为什么同样采用非饱和形式的两个网络，训练行为仍可能差异很大。

<a id="gan-detail-33"></a>

### 11.5 判别器步为何分离生成样本

判别器步只希望更新判别器参数，生成样本可以视为当前固定生成分布的观测。分离计算图避免为生成器计算无用梯度，也降低图存储。如果未分离但只调用判别器优化器，生成器参数未必被更新，但会留下不需要的梯度，可能与后续生成器步错误累积。应在每方更新前清理正确梯度，并显式检查优化器参数归属。

<a id="gan-detail-34"></a>

### 11.6 冻结判别器为何不能用无梯度上下文

生成器步需要判别器相对于输入的导数。将判别器参数设为不求梯度，可以保留输入路径；把整个前向放进无梯度上下文则会切断路径，使生成器无法从该损失得到梯度。对于包含状态缓冲区的网络，还需决定训练与评价模式，以防冻结参数时统计量仍变化。概念上“对手固定”应说明固定哪些状态，而不只是一句口号。

<a id="gan-detail-35"></a>

### 11.7 JS 有界为什么仍难训练

有界只说明数值范围，不说明沿参数变化有良好的连续性或有效梯度。两个移动点质量的例子中，非重合时 JS 恒定，即使几何距离持续减小也不反映改善。有限判别器可能产生某种梯度，但它受网络延拓方式影响。评价一个散度用于优化的效果，需要结合分布族与参数化拓扑，不能只看是否有限。

<a id="gan-detail-36"></a>

### 11.8 critic 的分数能否当概率

不能，Wasserstein critic 输出任意实数，其有意义的量通常是两个分布上的期望差。在满足约束时，加上常数不改变这个差，因此单个分数零点没有绝对概率意义。若对输出再加 sigmoid，就改变函数族与尺度，需要重新理解目标。判断符号也应看代码约定：critic 最小化负期望差与最大化正期望差是同一优化方向的两种写法。

<a id="gan-detail-37"></a>

### 11.9 梯度惩罚为何不等于全局约束

它只在有限插值点施加软代价，而且常惩罚偏离一而非超过一。网络在未抽样区域可能存在更大梯度，有限惩罚权重也允许局部违约。因此它是近似约束策略，不能据此宣称目标值就是精确 Wasserstein 距离。可以报告梯度分布与违约诊断，必要时结合更强结构约束，但每一种结构也有自己的近似与容量代价。

<a id="gan-detail-38"></a>

### 11.10 输入单位改变会怎样

Wasserstein 依赖选定距离，坐标从米变成毫米会放大相应搬运成本，并改变梯度约束的尺度。若不同特征量纲差异极大，距离可能主要被某个特征支配。应先根据任务定义几何，再确定标准化与约束。标准化不是完全中性的操作，特别是在混合连续特征或图像与其他模态联合比较时，需要明确各部分权重。

<a id="gan-detail-39"></a>

### 11.11 四峰各出现一次是否覆盖充分

不充分。模式概率可能严重失衡，且人工挑选每峰一个样本会隐藏这种失衡。应随机生成足够多样本，计算每个模式的质量占比及不确定性，并同时检查样本是否真的接近模式。对于稀有模式，还要根据其真实概率确定采样量；少量样本未见到它，可能是统计波动，也可能是模型遗漏，不能不加区分地下结论。

<a id="gan-detail-40"></a>

### 11.12 只看均值和协方差会漏掉什么

不同分布可以有完全相同的均值与协方差。一个围绕四个角的混合分布与一个中心附近的连续分布，在适当尺度下可能共享前两阶矩，却具有不同模式结构。因此矩匹配是有限诊断，必须结合局部质量、覆盖或更丰富的两样本检验。反过来，矩不匹配可以明确发现某类错误，不能因为它不完整就完全忽略它。

<a id="gan-detail-41"></a>

### 11.13 更多判别器步是否一定更好

更多更新有机会让判别器更接近当前最优，但也增加计算，并可能让分类过度分离或过拟合有限训练集。生成器更新之间对手变化程度同样影响动态。比较时应区分每轮步数与总计算预算，检查泛化差距和梯度质量，而不是把某个固定比例当成普适规则。理想最优判别器的理论与实际有限步策略需要分别验证。

<a id="gan-detail-42"></a>

### 11.14 GAN 为什么通常没有直接似然

生成器的前向映射提供样本，却不一定可逆，也不一定有易计算雅可比。多个隐变量可以映射到同一个输出，低维映射还可能使分布在环境空间中奇异。因此不能直接将生成器输出代入一个标准密度公式。若需要显式似然，应选用具有相应结构的模型或额外估计方法，并说明估计假设与误差，不能把判别器分数冒充似然。

<a id="gan-detail-43"></a>

### 11.15 怎样检查是否记住训练集

需要独立参考集，比较生成样本到训练与独立数据的距离分布，并检查距离表示是否符合任务。异常贴近训练样本可能提示记忆，但自然重复与低维数据也会造成近邻。还可在严格划分的来源组上评价覆盖与质量。仅展示一些看起来新颖的样本无法排除记忆，同样，发现一个近邻也不足以证明所有生成都是复制，需要有总体统计与具体实例共同支持。

<a id="gan-detail-44"></a>

### 11.16 怎样公平比较 GAN 与 VAE

先固定数据、预处理、划分、计算预算与主要任务，再分别报告各自可获得且有意义的指标。VAE 的 ELBO 与 GAN 的对抗损失不能直接按大小排序。可以统一比较外部质量与覆盖、条件一致性、训练稳定性和采样成本，同时保留似然相关评价是否可计算的差异。方法各自的优势与失败条件应明确呈现，不能用一个最有利指标宣布全面胜出。

<a id="gan-detail-45"></a>

## 12. 研究报告需要保留的证据链

一个完整报告应列出真实分布或数据来源、噪声分布、生成器与判别器结构、两方精确损失、优化器及更新比例、正则项、训练预算、随机种子和最终采样规则。还应说明是否选择了最好检查点、选择使用什么验证指标，以及最终测试是否独立。若展示样本，优先使用固定噪声网格与随机抽样，而非人工筛选。

更进阶的研究从明确失败模式开始：是覆盖不足、局部质量差、概率失衡、训练振荡，还是评价器失灵？分别提出可证伪的假说，再改变一个关键因素。对抗学习的难点正在于两方相互作用，单个损失曲线无法解释全部行为。能够把分布理论、梯度路径和外部统计连接起来，才能判断一个新技巧到底解决了什么问题。

<a id="gan-detail-46"></a>

## 13. 博弈动态为什么不能套用单目标直觉

<a id="gan-detail-47"></a>

### 13.1 双线性博弈的精确反例

考虑最简单的零和问题 $`\min_x\max_y xy`$，唯一鞍点是原点。若两方同时使用步长 $`\eta`$ 更新，则 $`x'=x-\eta y`$，$`y'=y+\eta x`$。平方半径满足 $`(x')^2+(y')^2=(1+\eta^2)(x^2+y^2)`$，所以任何非零初值都会向外扩张。这个问题没有复杂网络、没有数据噪声，也没有模式，普通同时梯度仍然不收敛。

若改成先更新 $`x`$ 再用新 $`x`$ 更新 $`y`$，动态矩阵的行列式为一，在某些步长范围内可能围绕原点运动，却未必收敛。于是“损失没有持续下降”不一定说明代码写错，也可能反映向量场中的旋转部分。GAN 的高维动态更复杂，但这个可手算例子足以提醒我们：两个相互改变目标的学习者，与一个固定损失函数的梯度下降有本质区别。

在实际训练中，动量、适应学习率、不同更新频率和正则项共同改变动态。它们可能降低振荡，也可能使某些方向不稳定。仅给生成器降低学习率，不一定能解决 critic 过拟合；增加 critic 步数，也不一定能解决生成器雅可比退化。应通过局部梯度、参数变化和外部指标组合诊断，而不是看到振荡就盲目堆叠训练技巧。

这个反例还能推导一种针对旋转的修正，而不只停在“普通梯度会失败”。先从旧点做一次试探 $`\bar x=x-\eta y,\bar y=y+\eta x`$，再从**原来的点**沿试探点的向量场更新：$`x'=x-\eta\bar y,\ y'=y+\eta\bar x`$。第二次更新不是把试探点当成新起点连续走一步；后者仍是两次普通同时梯度。消去试探变量得到

$$
\begin{pmatrix}x'\\y'\end{pmatrix}
=\begin{pmatrix}1-\eta^2&-\eta\\\eta&1-\eta^2\end{pmatrix}
\begin{pmatrix}x\\y\end{pmatrix},\qquad
(x')^2+(y')^2=(1-\eta^2+\eta^4)(x^2+y^2).
$$

当 $`0<\eta<1`$ 时，平方半径的系数严格小于一，故确定性迭代几何收敛到原点；$`\eta=1`$ 时只旋转而不收缩，$`\eta>1`$ 则仍会放大。取 $`(x,y)=(1,0)`$、$`\eta=0.5`$，试探点为 $`(1,0.5)`$，校正点为 $`(0.75,0.5)`$，平方半径从一变为 $`0.8125`$；普通同时更新却变为 $`(1,0.5)`$，平方半径为 $`1.25`$。将 $`u=\eta^2`$ 配方为 $`1-u+u^2=(u-\frac{1}{2})^2+\frac{3}{4}`$，可见这个单位耦合例子的最佳固定步长为 $`\frac{1}{\sqrt2}`$，每步平方半径缩为四分之三。

这种两次计算向量场的做法称为外梯度；相关双线性研究可见[外梯度在双线性博弈中的研究](https://arxiv.org/abs/2107.00464)。上面的结论是本节确定性标量问题的直接代数结果，不是任意 GAN 的收敛定理。若目标改为 $`a xy`$，决定稳定性的变为 $`\vert \eta a\vert `$；高维耦合对应多个奇异方向，随机小批又增加噪声。实际比较还应按梯度计算次数计预算：一次外梯度包含试探与校正两次求场，不能与一次普通更新仅按步数宣称同成本。

<a id="gan-detail-48"></a>

### 13.2 局部平衡与全局分布匹配

一个参数空间中的局部平衡，可能只是当前模型族中两方都无法通过小步改进，并不代表分布真正相同。生成器容量不足可能无法表达某些模式，判别器容量不足可能无法发现差异，参数化还可能产生梯度为零的坏点。理论上在全部概率分布与全部测试函数中存在正确最优，并不排除受限参数空间里存在其他平衡或驻点。

因此评价不能只说两方损失“稳定了”。一个停止学习的坏模型也会稳定。应对比简单基线，例如完全复制训练数据、单峰高斯、真实数据重采样或已知错误分布，检查评价器能否按预期识别差异。如果复杂 GAN 的指标不比简单基线好，需要说明真实收益，而不是用网络规模或训练时间替代效果证据。

<a id="gan-detail-49"></a>

### 13.3 两时间尺度与预算报告

让判别器比生成器更新更频繁，可以近似“对当前生成器充分优化判别器”的思路。但实际理论通常依赖步长、光滑性、噪声与稳定性等条件，不能把一个固定五比一比例当成自动满足理论。更频繁更新还消耗额外前向、反向与可能的输入梯度计算，尤其梯度惩罚需要更昂贵的图。

比较方法时可以同时报告每个生成器更新对应的 critic 步数，以及总网络调用量或实际训练耗时。若只固定生成器更新次数，critic 更昂贵的方法实际上获得更多预算。若只固定墙钟时间，不同实现效率又可能影响结论。两种比较都可以有价值，但应准确说明所回答的是算法效率、实现效率还是给定资源下的最终质量。

<a id="gan-detail-50"></a>

## 14. 条件对抗生成与条件覆盖

<a id="gan-detail-51"></a>

### 14.1 条件进入哪一方

条件 GAN 可以写成生成器 $`G(z,c)`$ 与判别器 $`D(x,c)`$。真实训练样本是联合对 $`(x,c)`$，生成样本则由预定条件分布抽 $`c`$ 后生成 $`x`$。如果生成器看到条件而判别器看不到，训练可能只约束边缘样本分布，使模型忽略条件仍获得较好边缘质量。若判别器看到错误配对的条件，需要明确这些配对在分类任务中被如何使用。

条件抽样分布同样重要。真实数据中某类别占百分之一，而生成条件均匀抽类别时，两方比较的是怎样的联合分布？可以对真实数据做相同类别重加权，也可以明确目标为重平衡条件分布，但不能把不匹配的条件基率默认为无关细节。即使每类内部生成完美，类别频率差异也会给判别器提供简单捷径。

<a id="gan-detail-52"></a>

### 14.2 条件正确与类内多样性

评价条件生成至少需要两层检查：输出是否满足给定条件，以及在条件固定时是否覆盖允许的变化。一个生成器对每个标签永远输出同一张清晰图片，可能获得很高的类别一致性，却完全缺乏类内覆盖。相反，输出丰富但经常违背条件的模型也不满足任务。两者应该分别报告，避免把单一分类器准确率当作全部质量。

如果条件来自文本，评价还要考虑组合关系、数量、空间关系和否定条件等具体要求。一个外部嵌入相似度可能对某些关系不敏感，不能自动证明指令已被完整执行。对于本章二维人工数据，可以把中心类别作为条件，检查每类均值、协方差、尾部与邻域质量，从而建立一套完全可解释的最小条件评价。

<a id="gan-detail-53"></a>

### 14.3 缺失条件、错误条件与外推

实际条件可能缺失或包含错误标签。训练时从未见过缺失条件，推断时简单填零可能落在没有训练支持的区域。可以定义专门的空条件表示或条件缺失策略，但应同时评价无条件与有条件行为。条件本身若在部署时不可获得，训练收益也不能直接视为可用收益，尤其是使用未来信息或目标派生属性时。

对于训练范围外的连续条件，模型通常没有保证的外推能力。让年龄条件从训练中的二十到六十外推到一百，不是普通插值测试。应标注支持范围并设置专门验证；若需要保证物理约束，最好把约束纳入模型或后处理定义，并测量其对分布与覆盖的影响。任何后处理都应计入最终生成机制，不能只评价筛选后的幸存样本而忽略拒绝率。

<a id="gan-detail-54"></a>

## 15. 覆盖统计、罕见事件与样本量

<a id="gan-detail-55"></a>

### 15.1 没抽到并不总是模型遗漏

如果某个真实模式概率为 $`r`$，独立生成 $`n`$ 次仍未观察到该模式的概率是 $`(1-r)^n`$。例如真实概率千分之一、只生成一百个样本，未见到该模式是相当常见的事件。评价稀有覆盖时，必须根据概率与置信要求选择样本量，而不是把一个小网格里没有出现的类别立即判为坍塌。

反过来，只出现一次也不能证明概率正确。应给出模式频率估计以及相应不确定性，并考虑多个模式同时检验的问题。若所有样本来自同一固定训练模型，计数的不确定性主要反映采样；如果比较完整训练方法，还需要跨种子的模型间变异。把几万个生成样本当作几万个独立训练重复，会严重夸大方法结论的确定程度。

<a id="gan-detail-56"></a>

### 15.2 评价半径与模式分配

最近中心分配让所有样本都有模式标签，但不能排除离群点。本章先计算最近中心，再用固定半径标记有效邻域，并分别报告总体占用与有效邻域质量。半径太大可能把连接模式之间的低密度样本算作成功，半径太小又会拒绝真实分布的正常尾部。因此最好同时计算真实参考样本在同一半径下的基准比例。

若改变半径，应把敏感性分析作为附加结果，不能根据测试生成结果挑一个最有利半径。模式中心也必须来自已知人工机制或独立训练信息，不能用生成样本自己聚类后宣称“所有生成模式都覆盖了”。后者只描述模型自身，不回答它是否遗漏真实模式。评价标准需要来自任务与参考分布，避免循环定义成功。

<a id="gan-detail-57"></a>

### 15.3 条件分层与最差组

总体指标可能掩盖某些稀有条件的严重失败。可以按类别、来源或其他预定义组分层报告质量与覆盖，同时给出组样本量。小组估计不稳定时应诚实标注，而不是删掉难看的组。最差组指标具有重要诊断价值，但若从大量组中事后挑最差者，还要考虑选择带来的统计波动。

在人工四峰分布里，每个峰都可以作为一个组，真实目标质量各为四分之一。若生成占用接近均衡而某峰邻域比例明显偏低，说明模型在该峰生成了更多偏离样本。这个问题与该峰完全缺失不同，需要不同的修复假说：可能是局部形状、梯度方向或共享参数造成的不均衡，而不只是缺少噪声维度。

<a id="gan-detail-58"></a>

## 16. 对抗过拟合、数据增强与表示距离

<a id="gan-detail-59"></a>

### 16.1 判别器为何会记住训练样本

判别器反复看到有限训练数据，可以利用样本级细节把训练真实样本与生成样本区分，而这些细节未必代表总体结构。训练分类性能越来越好、独立真实样本表现却下降，是过拟合的重要信号。此时生成器可能追逐训练集特征，造成记忆或不稳定。应设置独立真实数据诊断判别器泛化，而不只看训练准确率。

数据增强可以限制判别器使用某些无关细节，但增强必须与任务不变性一致。对方向具有语义的数据随意旋转，可能改变真实类别；对物理测量随意缩放，可能破坏量纲与约束。若增强同时作用于真实和生成样本，需要说明它比较的是增强后的分布；若只增强一方，判别器可能直接利用增强伪影作为来源捷径。

<a id="gan-detail-60"></a>

### 16.2 外部表示距离的收益与偏差

将样本映射到一个预训练表示再比较，能够降低像素细节的影响，强调某些语义因素。但表示是另一个学习系统，可能忽略颜色、文字、细粒度关系或罕见类别。因此在该表示中接近，不意味着在所有任务相关维度上都接近。选择表示时需要解释它与目标任务的关系，并辅以直接约束和分层评价。

如果外部表示曾在测试参考数据上训练，评价仍可能具有复杂依赖，至少要公开来源。对于私有或专业数据，通用图像表示可能完全不适合，甚至把重要异常当作无关噪声。小型研究可以先用可解释的低维分布验证评价器是否发现已知错误，再扩展到真实任务。评价方法本身也需要反例，而不能只被用来给模型排序。

<a id="gan-detail-61"></a>

### 16.3 距离估计不是无偏真值

许多样本质量指标基于有限样本统计、拟合高斯或近邻距离，本身有样本量依赖与估计偏差。两个模型使用不同生成样本数，可能得到不公平结果。应统一参考与生成样本量，必要时报告多次子抽样结果。比较小差异时尤其需要谨慎，不能把小数点后多位当作实际可靠精度。

训练中反复监控同一个指标并选择最佳检查点，也会对该指标及参考集产生适应性。最终应使用独立测试评价，或明确结果只是验证集模型选择成绩。若报告最好样本、最好检查点、最好种子与最好指标组合，选择偏差会层层叠加。完整记录失败种子和训练中断同样重要，它们反映方法实际稳定性，而不只是论文图表中的平均成功情况。

<a id="gan-detail-62"></a>

## 17. 从错误现象到可操作的排查顺序

<a id="gan-detail-63"></a>

### 17.1 首先核对目标与计算图

出现生成质量差时，先检查判别器输出是否为 logits、损失符号是否一致、真实与生成标签是否正确、生成器步是否误用分离操作。再检查两方优化器是否包含正确参数集合，是否清理了上一步梯度，是否存在意外共享参数或共享优化器状态。基础错误不排除，直接调学习率会把问题隐藏在大量无效实验中。

其次检查尺度：真实与生成样本是否经过相同预处理，输出激活是否与真实范围一致，输入噪声维数与分布是否符合设定。真实在负一到一，生成却被限制在零到一时，判别器会利用范围差异轻易区分。对于连续测量，坐标单位错误也会造成类似捷径。可先把两方输入的简单统计打印出来，与理论造数机制逐项比较。

<a id="gan-detail-64"></a>

### 17.2 再核对对手与更新动态

若判别器几乎完美，检查是否存在简单来源伪影、训练过拟合或生成器梯度过弱；若判别器始终随机，检查容量、学习率、损失实现与输入信息。两种极端都不自动等于成功或失败的唯一原因。可以在固定生成器下单独训练判别器，确认它能区分已知不同分布，再恢复共同训练。

记录梯度范数与参数更新范数时应按模块分开，避免一个大层掩盖另一个断梯度层。梯度裁剪可以控制极端更新，却不能修正方向错误或目标符号错误。若使用裁剪，报告阈值与触发频率，并检查是否几乎每一步都在裁剪。持续高频裁剪往往提示需要重新检查尺度与优化，而不是继续提高阈值直到曲线平滑。

<a id="gan-detail-65"></a>

### 17.3 最后才判断是否需要更复杂方法

在基础链条正确后，再考虑改变对抗目标、正则、结构或训练日程。每次只改变一类因素，建立能够解释结果的比较。如果同时加谱约束、梯度惩罚、增强与新优化器，即使结果改善，也很难知道哪个因素起作用。消融实验应与主要训练使用相同选择规则，避免对某个方法精调而对基线使用不合适默认值。

对无法达到预期的实验，应保留有限性、更新与评价断言，通过后如实报告结果，而不是把所有未达到高质量阈值的训练都称为程序错误。算法可能在给定预算下就是不稳定。研究价值在于准确找出失败条件以及可能原因，并用后续实验区分假说，而不是确保每一段演示都得到漂亮样本。

<a id="gan-detail-66"></a>

## 18. 本章实跑结果与进一步研究设计

<a id="gan-detail-67"></a>

### 18.1 四段实验实际验证了什么

离散最优判别器实验得到约零点零五五六的 JS，代入值与负对数四加两倍 JS 完全吻合。点质量例子在任何非零距离下都得到对数二的 JS。梯度实验确认极负 logit 处饱和导数接近零，非饱和导数接近负一，并通过参数更新隔离检查。线性 critic 的梯度惩罚为一，权重导数为二，证明该实现保留了所需的自动微分路径。

完整 GAN 的末次判别器损失约一点三六九，生成器损失约零点七四六。四峰最近中心占用约为百分之二十五点一、二十七点九、二十二点四和二十四点六，落在半径零点六邻域内的总体比例为百分之九十三点一五。有效邻域内各峰占总体质量约百分之二十三点七、二十五点五、二十点三和二十三点六。这些结果说明本次训练覆盖了四个峰，同时仍存在概率失衡和一部分过渡或离群样本。

不能把这些占用差异全部解释为采样波动，因为它们既可能来自有限生成样本，也可能来自训练后分布的真实偏差。进一步应固定模型增加采样量以减小计数误差，再重复完整训练测量种子差异。若只有一次训练，本章结论就限定在这一固定设置的机制演示，不能宣称这种结构普遍稳定或优于其他生成路线。

<a id="gan-detail-68"></a>

### 18.2 一个可完成的小研究计划

可以把真实模式概率从均匀四峰改为一个稀有峰，保持中心和局部方差不变，比较原始非饱和 GAN 与加入某个明确正则的版本。预先固定训练步数、种子集合、评价半径与生成样本数，报告每峰真实概率、生成有效质量、离群比例以及总计算成本。这样可以直接观察正则是否改善罕见覆盖，以及是否通过牺牲其他模式质量实现。

另一个计划是保持分布不变，只改变两方更新比例，记录训练轨迹和最终独立评价。若某比例只在部分种子成功，应展示成功与失败的分布，而不是只给平均漂亮图。还可在固定生成器时比较不同 critic 的输入梯度，研究分类表现相近时为何更新方向不同。所有这些问题都把理论条件、优化动态与可测量结果连接起来，比单纯增加网络层数更能训练研究判断力。

<a id="gan-detail-69"></a>

### 18.3 不等来源先验的进一步推导

如果分类来源真实概率为 $`\pi`$，生成来源概率为 $`1-\pi`$，目标变为 $`\pi E_P\log D+(1-\pi)E_Q\log(1-D)`$。逐点求导得到 $`D^*=\frac{\pi p}{[\pi p+(1-\pi)q]}`$。令混合分布为 $`M_\pi=\pi P+(1-\pi)Q`$，代入后得到加权 KL 和，再加上 $`\pi\log\pi+(1-\pi)\log(1-\pi)`$ 的常数项。这说明来源类别比例并非只影响数值缩放，而会改变判别器后验与散度权重。

因此从判别器输出恢复密度比时，也必须使用正确来源先验。等概率时密度比为 $`\frac{D}{(1-D)}`$；不等概率时还需乘以 $`\frac{(1-\pi)}{\pi}`$。有限训练判别器未必校准，所以这个比值即使公式正确也可能在接近零或一时极不稳定。若研究中要用判别器进行重加权或拒绝采样，应另外检验校准、支持覆盖与权重尾部，而不能把理论最优式直接当作可靠估计器。

<a id="gan-detail-70"></a>

### 18.4 特征匹配可以怎样被反例检验

有些生成器目标比较判别器中间特征的期望，而不直接追求最终分类概率。这能改变训练动态，但匹配有限维特征均值通常不保证完整分布一致。例如中间表示只保留坐标平方时，正负号不同的分布可能具有相同特征均值；只保留一阶特征时，单峰与多峰也可能匹配。因此应明确特征函数及其能够区分的差异，把它视作某个受限比较族。

一个实际可做的消融是固定外部评价，把原始非饱和目标与特征匹配目标在相同架构和预算下比较，记录模式质量、概率失衡与离群比例。若特征匹配改善稳定性但降低某些细节质量，应同时呈现。尤其不能用训练中正在被匹配的同一组特征均值作为唯一最终评价，否则方法天然容易在自己的目标上显得成功，却可能漏掉与任务有关的其他差异。

对于四峰结果，还有一个有价值的对照：从真实造数分布独立抽取相同数量的点，使用完全相同的半径、最近中心和计数流程评价。真实样本的局部噪声标准差为零点一五，因此半径零点六已经覆盖大部分真实局部质量；生成器仍有约百分之六点八五的样本处于这个邻域之外，不能全部归因于评价半径过苛刻。这个对照能够把指标尺度与数据机制联系起来，而不需要主观挑图。

不过本次训练使用每轮新造真实样本，真实信息的供应比有限固定数据集更理想。因此它主要检验对抗训练机制与模式统计，不能检验小数据过拟合，也不能证明真实图片任务中的记忆风险已经受控。如果要研究有限数据，应该先固定一个训练样本集合，再保留独立来源生成的验证与测试集合。数据供应机制改变后，应把它当作新的实验设置，不能直接把两组损失曲线混在一起比较。

最后，生成器没有显式观测噪声层，局部方差完全由输入噪声经过网络映射形成。这与上一章固定高斯解码噪声的模型不同。两者的先验采样流程、噪声来源和尾部行为均应分别解释；相同二维输出并不意味着它们具有相同的概率建模假设。
