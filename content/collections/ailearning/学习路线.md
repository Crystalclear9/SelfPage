## 基础学习路线

### 数据处理、建模与评估

基础主线从数据处理出发，经过建模与评估，再通往视觉、语言、生成和强化学习等方向。

### 编程与数据表达

**顺序：** [Python](Programming/Python/README.md) → [NumPy](Programming/NumPy/README.md) → [Pandas](Programming/Pandas/README.md) → [Matplotlib](Programming/Matplotlib/README.md)。同时了解[Git](ComputerScience/Git/README.md)。

第一遍先完成 Python 基础、NumPy 第 1—3 章、Pandas 第 1—2 章和 Matplotlib 第 1 章。NumPy 第 4 章涉及回归目标与梯度，留到第二阶段之后；Pandas 的时间特征和训练样本章节、Matplotlib 的模型诊断章节，在第三阶段配合实验补齐。这样先掌握操作，再补统计与建模含义，不必在第一次学习数组时就理解优化收敛。

### 建模所需的数学

**主线：** [线性代数](Mathematics/LinearAlgebra/README.md)、[微积分](Mathematics/Calculus/README.md)、[概率](Mathematics/Probability/README.md)，然后学习[统计](Mathematics/Statistics/README.md)与[优化](Mathematics/Optimization/README.md)。

线性代数与微积分可以并行；连续分布的积分细节放在微积分第 2 章之后。先读统计第 1—2 章，线性回归统计解释配合第三阶段的回归模型阅读。理解梯度下降后，返回 NumPy 第 4 章跑通手写回归；线性代数中的 PCA 可先理解投影，再在概率的期望与方差之后补协方差解释。这里的“阶段”表示建立基础的先后，不要求先读完全部数学进阶内容。

[矩阵微积分](Mathematics/MatrixCalculus/README.md)用于推导批量梯度，[数值计算](Mathematics/NumericalMethods/README.md)用于理解浮点和稳定性，[信息论](Mathematics/InformationTheory/README.md)连接概率与损失。可以在对应机器学习章节遇到问题时返回补学，不必先证明所有定理。

### 机器学习与实验评估

[机器学习基础](MachineLearning/Foundations/README.md)之后，可交叉阅读[监督学习](MachineLearning/SupervisedLearning/README.md)与[模型评估](MachineLearning/ModelEvaluation/README.md)。[贯通案例](MachineLearning/Projects/README.md)将分类、回归、误差分析和模型交付放到可运行的实例中。[无监督学习](MachineLearning/UnsupervisedLearning/README.md)和[概率模型](MachineLearning/ProbabilisticModels/README.md)分别展开数据结构探索与显式概率建模。

把评估放在模型改进之前：先写清划分和指标，再尝试更复杂的方法。时间或分组数据需要相应协议，不要因为随机划分分数更高就采用它。

### 神经网络与深度学习

**顺序：** [神经网络基础](DeepLearning/NeuralNetworkBasics/README.md)与[PyTorch](Programming/PyTorch/README.md)并行 → [CNN 第 1—2 章](DeepLearning/CNN/README.md) → [手写数字项目](DeepLearning/Projects/README.md)。先走通训练与验证，再选择网络结构分支。

视觉方向继续 CNN 的多尺度与实验章节；序列方向读[RNN 第 1—2 章](DeepLearning/RNN/README.md)，再进入[注意力](DeepLearning/Attention/README.md) → [Transformer](DeepLearning/Transformer/README.md)。RNN 第 3 章的注意力桥接可与注意力第 1—2 章交叉阅读；CNN 第 3 章的视觉 Transformer 部分在理解注意力和 Transformer 块后返回。注意力主线也可从神经网络基础直接进入，RNN 提供历史背景与另一种序列建模方案。

CNN 和 RNN 提供不同结构假设，注意力与 Transformer 解释更灵活的信息交互。先理解前向接口、损失和梯度，再研究训练加速。补充[计算机系统](ComputerScience/ComputerSystems/README.md)有助于判断内存与性能问题。

### 应用与强化学习方向

| 方向 | 阅读入口 |
| --- | --- |
| 图像分类、检测、分割 | [计算机视觉](AI-Domains/ComputerVision/README.md) |
| 文本任务 | [NLP](AI-Domains/NLP/README.md) |
| 语言模型系统 | [大语言模型](AI-Domains/LargeLanguageModels/README.md) |
| 分布建模与采样 | [生成模型](AI-Domains/GenerativeModels/README.md) |
| 关系数据 | [图机器学习](AI-Domains/GraphMachineLearning/README.md) |
| 图文或音视频 | [多模态](AI-Domains/MultimodalLearning/README.md) |
| 长期决策 | [MDP](ReinforcementLearning/MDP/README.md) → [价值方法](ReinforcementLearning/ValueBasedMethods/README.md) → [策略方法](ReinforcementLearning/PolicyBasedMethods/README.md) → [深度强化学习](ReinforcementLearning/DeepRL/README.md) |

这些方向是分支，不是表格自上而下的必修链。视觉的 CNN 路线无需先学语言模型；NLP 的词袋与分类基线无需先学完 Transformer；图学习先补图遍历，图文多模态先具备视觉和文本表示基础，生成章节按所用概率目标补信息论。强化学习从数学和 Python 基础即可开始 MDP 与表格价值学习，进入神经网络策略和深度强化学习时再补 PyTorch，不必等待全部应用方向学完。

进一步选章时，按问题走支线：

- **语言模型：** 预训练 → 指令与偏好 → 微调数据验收；或预训练 → RAG 与工具 → 检索系统评价。微调不是构建 RAG 的前置条件。
- **生成模型：** 先理解共同的分布对象，再比较 VAE、GAN、离散扩散与精确似然模型，最后统一实验协议。
- **图学习：** 消息算子、谱与采样 → 聚合表达力 → 图级、异质关系与链接预测。各任务都需重新确认图的可见性，传导式实验不能自动作为新图泛化证据。

### 工程基础

[数据结构与算法](ComputerScience/DataStructuresAndAlgorithms/README.md)帮助分析数据规模与访问模式；[数据库](ComputerScience/Databases/README.md)帮助可靠提取特征；[Linux](ComputerScience/Linux/README.md)帮助在服务器上运行和观察任务。它们可以随项目推进学习，无需全部精通后再开始建模。

若想学习经典 AI，可由图遍历、动态规划和最小堆进入[启发式搜索、约束满足与符号规划](ComputerScience/DataStructuresAndAlgorithms/05-启发式搜索约束满足与符号规划.md)。先用 A* 求可重放的最短路线，再用约束传播和动作规则区分排班与规划。遇到随机转移时，继续进入[有限状态动态规划](ReinforcementLearning/MDP/03-有限状态动态规划完整算例.md)，将动作序列扩展为策略。

| 核心内容 | 进阶专题 | 先修入口 |
