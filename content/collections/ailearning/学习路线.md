## 基础学习路线

### 1. 先确定学习主线

原有 40 个主题构成基础与应用知识框架，不要求一口气学完。先把“处理数据—训练模型—正确评估”的闭环走通，再选视觉、语言、生成或强化学习方向深入。进度以能完成任务为依据，不以看完多少页为依据。

建议每次学习一章：按“概念 → 对应算例与机制 → 进阶 → 基础练习与边界追问”阅读，再在主题末完成研究与综合练习。先合上资料复述和作答，再看解析；涉及代码时改变一个输入或参数，预测变化后运行验证。公式可分两遍读，先理解各量与计算过程，再补条件和推导。

### 2. 第一阶段：能用程序表达数据

**顺序：** [Python](Programming/Python/README.md) → [NumPy](Programming/NumPy/README.md) → [Pandas](Programming/Pandas/README.md) → [Matplotlib](Programming/Matplotlib/README.md)。同时了解 [Git](ComputerScience/Git/README.md)。

第一遍先完成 Python 基础、NumPy 第 1—3 章、Pandas 第 1—2 章和 Matplotlib 第 1 章。NumPy 第 4 章涉及回归目标与梯度，留到第二阶段之后；Pandas 的时间特征和训练样本章节、Matplotlib 的模型诊断章节，在第三阶段配合实验补齐。这样先掌握操作，再补统计与建模含义，不必在第一次学习数组时就理解优化收敛。

这一阶段目标不是背完所有 API，而是读入数据、检查类型与缺失、完成筛选聚合、画出有标注的图。遇到数组运算时，能解释每个轴代表什么；遇到表连接时，能解释行数为什么变化。

**验收任务：** 构造一张含缺失值的订单表，按用户统计总金额并连接用户属性；核对汇总金额与原表一致，画出用户金额分布，把代码和说明作为一次清楚的 Git 提交。

### 3. 第二阶段：理解模型里的数学

**主线：** [线性代数](Mathematics/LinearAlgebra/README.md)、[微积分](Mathematics/Calculus/README.md)、[概率](Mathematics/Probability/README.md)，然后学习 [统计](Mathematics/Statistics/README.md) 与 [优化](Mathematics/Optimization/README.md)。

线性代数与微积分可以并行；连续分布的积分细节放在微积分第 2 章之后。先读统计第 1—2 章，线性回归统计解释配合第三阶段的回归模型阅读。理解梯度下降后，返回 NumPy 第 4 章跑通手写回归；线性代数中的 PCA 可先理解投影，再在概率的期望与方差之后补协方差解释。这里的“阶段”表示建立基础的先后，不要求先读完全部数学进阶内容。

[矩阵微积分](Mathematics/MatrixCalculus/README.md) 用于推导批量梯度，[数值计算](Mathematics/NumericalMethods/README.md) 用于理解浮点和稳定性，[信息论](Mathematics/InformationTheory/README.md) 连接概率与损失。可以在对应机器学习章节遇到问题时返回补学，不必先证明所有定理。

**验收任务：** 计算线性回归的一次梯度更新，解释每个矩阵的形状；用条件概率完成一个基率算例；区分标准差、标准误差和置信区间。

### 4. 第三阶段：完成可靠的机器学习实验

**顺序：** [基础](MachineLearning/Foundations/README.md) → [评估第 1—2 章](MachineLearning/ModelEvaluation/README.md)与[监督学习](MachineLearning/SupervisedLearning/README.md)交替阅读 → [项目](MachineLearning/Projects/README.md)。先完成分类项目，再按第 3 章确定回归协议、第 4 章运行回归实验、第 5 章完成交付；误差分析与报告内容在取得结果后返回完善。[无监督学习](MachineLearning/UnsupervisedLearning/README.md)和[概率模型](MachineLearning/ProbabilisticModels/README.md)是后续分支，可按方向选择，不是开始第一个监督学习项目的前置门槛。

把评估放在模型改进之前：先写清划分和指标，再尝试更复杂的方法。时间或分组数据需要相应协议，不要因为随机划分分数更高就采用它。

**验收任务：** 完成[人工设备分类项目](MachineLearning/Projects/02-可运行分类实验.md)，按设备分离基础训练、概率校准、行动阈值开发和最终测试。报告多数类基线、分组交叉验证、三分类指标与复检行动代价，解释为什么填补和标准化必须放在 Pipeline 内。葡萄酒数据作为该章的迁移练习，在主流程完成后再做。

### 5. 第四阶段：理解并训练神经网络

**顺序：** [神经网络基础](DeepLearning/NeuralNetworkBasics/README.md) 与 [PyTorch](Programming/PyTorch/README.md) 并行 → [CNN 第 1—2 章](DeepLearning/CNN/README.md) → [手写数字项目](DeepLearning/Projects/README.md)。先走通训练与验证，再选择网络结构分支。

视觉方向继续 CNN 的多尺度与实验章节；序列方向读 [RNN 第 1—2 章](DeepLearning/RNN/README.md)，再进入 [注意力](DeepLearning/Attention/README.md) → [Transformer](DeepLearning/Transformer/README.md)。RNN 第 3 章的注意力桥接可与注意力第 1—2 章交叉阅读；CNN 第 3 章的视觉 Transformer 部分在理解注意力和 Transformer 块后返回。注意力主线也可从神经网络基础直接进入，RNN 提供历史背景与另一种序列建模方案。

CNN 和 RNN 提供不同结构假设，注意力与 Transformer 解释更灵活的信息交互。先理解前向接口、损失和梯度，再研究训练加速。补充 [计算机系统](ComputerScience/ComputerSystems/README.md) 有助于判断内存与性能问题。

**验收任务：** 基础闭环要求完成手写数字项目，保存最佳验证模型，检查混淆矩阵；选择序列或语言方向后，再要求手工说明因果掩码和下一词标签错位规则。

### 6. 第五阶段：选择一个方向深入

| 目标 | 继续学习 | 建议产出 |
| --- | --- | --- |
| 图像分类、检测、分割 | [计算机视觉](AI-Domains/ComputerVision/README.md) | 按来源划分的视觉实验和分类错误分析 |
| 文本任务 | [NLP](AI-Domains/NLP/README.md) | TF-IDF 基线与上下文模型比较 |
| 语言模型系统 | [大语言模型](AI-Domains/LargeLanguageModels/README.md) | 带检索分项评估的文档问答原型 |
| 分布建模与采样 | [生成模型](AI-Domains/GenerativeModels/README.md) | 质量、多样性、条件一致性的评估方案 |
| 关系数据 | [图机器学习](AI-Domains/GraphMachineLearning/README.md) | 明确图可见性与时间边界的实验 |
| 图文或音视频 | [多模态](AI-Domains/MultimodalLearning/README.md) | 单模态、联合模态与打乱配对消融 |
| 长期决策 | [MDP](ReinforcementLearning/MDP/README.md) → [价值方法](ReinforcementLearning/ValueBasedMethods/README.md) → [策略方法](ReinforcementLearning/PolicyBasedMethods/README.md) → [深度强化学习](ReinforcementLearning/DeepRL/README.md) | 多种子回报、成功率与预算比较 |

这些方向是分支，不是表格自上而下的必修链。视觉的 CNN 路线无需先学语言模型；NLP 的词袋与分类基线无需先学完 Transformer；图学习先补图遍历，图文多模态先具备视觉和文本表示基础，生成章节按所用概率目标补信息论。强化学习从数学和 Python 基础即可开始 MDP 与表格价值学习，进入神经网络策略和深度强化学习时再补 PyTorch，不必等待全部应用方向学完。

进一步选章时，按问题走支线：

- **语言模型：** 预训练 → 指令与偏好 → 微调数据验收；或预训练 → RAG 与工具 → 检索系统评价。微调不是构建 RAG 的前置条件。
- **生成模型：** 先理解共同的分布对象，再比较 VAE、GAN、离散扩散与精确似然模型，最后统一实验协议。
- **图学习：** 消息算子、谱与采样 → 聚合表达力 → 图级、异质关系与链接预测。各任务都需重新确认图的可见性，传导式实验不能自动作为新图泛化证据。

### 7. 按需补齐工程基础

[数据结构与算法](ComputerScience/DataStructuresAndAlgorithms/README.md) 帮助分析数据规模与访问模式；[数据库](ComputerScience/Databases/README.md) 帮助可靠提取特征；[Linux](ComputerScience/Linux/README.md) 帮助在服务器上运行和观察任务。它们可以随项目推进学习，无需全部精通后再开始建模。

进入下一阶段前，如果只能跟着例子运行，却无法解释输入、输出、假设和错误类型，应先做一个小变体。能迁移到稍有不同的问题，比重复运行同一段代码更能说明掌握程度。

### 1. 阅读一个结论时先写出五件事

1. **对象**：结论对 logits、网络参数、总体风险、经验损失，还是实际算法轨迹成立？
2. **假设**：是否要求独立样本、有限方差、光滑、凸、满秩、状态充分或行为覆盖？
3. **推导**：关键等式、上界和被丢掉的交叉项分别来自哪里？
4. **反例**：拿掉一个假设，能否构造结论失效的情况？
5. **证据**：程序验证的是公式、局部实现、有限数据表现，还是外部泛化？

例如，交叉熵对 logits 的 Hessian 半正定，不代表深网对参数凸；Bellman 收缩需要相应折扣和算子条件，不能直接推广到神经网络采样拟合；固定模型的测试区间也不覆盖全部调参选择不确定性。

### 3. 方法比较要比较完整流程

模型结构、前处理、训练预算、调参范围、选择规则和部署成本共同组成一个方案。若新方法同时用更多数据、更久训练和更强增强，就不能把全部收益归于一个新模块。

区分以下三类问题：同预算谁表现好、达到某质量谁成本低、在什么数据条件下谁更稳定。它们需要不同实验设计。候选更多还会增加选择偏差，应保留开发与独立评价边界。

### 5. 读论文的记录格式

每篇论文写下：具体问题、相对基线的新假设、核心目标或定理、证明依赖、实现变化、数据与预算、消融证据，以及结论不能覆盖的情况。不要把摘要中的整体描述直接当作所有条件下的定理。

复现时先实现最小核心变化，核对小算例与参考输出，再扩大数据和预算。若结果不一致，分别检查数据、目标、数值、优化和评价，不同时改变所有条件。失败结果也保存配置和日志，使后来能够追踪。

### 6. 何时算掌握

能够不看资料重建关键推导，解释至少一个失效反例，写出一个独立实现检查，并设计区分竞争解释的对照实验。只记住算法名、默认参数或论文分数，还不足以回答研究问题。

各主题的参考资料用于继续查证完整理论和实现。本文不是新的算法排名；选择方法应围绕具体任务、数据和预算。
