## 1. 先定义想改变的世界

<a id="causal-1-detail-2"></a>

### 1.1 预测、干预和个体反事实

观察关联问的是：已经接受处理的人，其结果和未接受者有何不同。干预问题问的是：对于同一目标总体，如果我们把处理规则改变，结果会怎样。个体反事实再问：这个已经接受处理的人，如果没有接受，会发生什么。三者需要不同信息，预测误差很小并不意味着后两个问题已经解决。历史数据往往同时记录了人们如何被选择和处理如何作用，模型容易把两者混在一起。

设单位为人、学校或一次独立实验，二元处理为 $`A`$，结果为 $`Y`$，处理前变量为 $`X`$。潜在结果 $`Y(1),Y(0)`$ 描述该单位在两种明确干预下的结果。平均处理效应定义为 $`\tau=E[Y(1)-Y(0)]`$。同一单位的两种潜在结果都是模型中的随机变量，但通常只能观察其中一个。这个缺失不是普通随机漏填，缺哪个与实际处理直接绑定。

即使随机试验识别了两个潜在结果的边际分布，也不自动识别它们的联合分布。因此可以估计平均获益，仍不知道某个具体人是否获益，甚至不知道总体里获益者比例。把群体平均效果包装成每个人的确定变化，是从边际跨到联合的额外推断。若要跨越这一步，需要秩保持、单调性或结构模型等更强假设，并说明其合理性。

<a id="causal-1-detail-3"></a>

### 1.2 估计对象必须带总体和时点

ATE 针对预先定义的目标总体，ATT 为 $`E[Y(1)-Y(0)\mid A=1]`$，针对实际处理者，CATE 为 $`E[Y(1)-Y(0)\mid X=x]`$，针对协变量层。它们可能都合理，却不能互相替代。如果高风险人接受处理更多，而高风险人的效应也更大，处理者效应就可能明显高于总体平均。不是哪一个天然更正确，而是研究问题需要先决定比较谁。

结果还要带时间窗口。一个月的学习成绩、半年留存和长期职业收入，不是同一个结果。处理开始、资格判定和随访开始需要对齐，否则把只有活到后来才能接受处理的人提前归入处理组，会产生不正确的比较机会。精确的因果问题往往先是一张时间表，然后才是一条估计式。

<a id="causal-1-detail-4"></a>

### 1.3 一致性背后的处理版本与干扰

一致性写为 $`Y=Y(A)`$，意思是实际接受版本与所定义干预相符时，观察结果等于对应潜在结果。它不是让含糊处理自动变得清楚的符号。“上过课程”若包含不同教师、时长和考核强度，二元标记可能对应许多不同干预。应定义具体方案，或明确按什么版本分布随机实施，从而使潜在结果有稳定含义。

无干扰指一个单位的结果不依赖其他单位的处理。在传染、社交、市场和学校资源竞争中，这往往不成立。此时可以写 $`Y_i(\mathbf a)`$，让整个处理向量决定第 $`i`$ 个单位结果，或定义邻居暴露映射。直接效果、溢出效果和覆盖率政策效果需要不同对比。单位间相关性影响标准误，处理相互作用则进一步改变估计对象，二者不能混为一谈。

<a id="visual-causalinference-01"></a>
### 图解：混杂分叉与干预的区别

![混杂分叉与干预的区别：机制、算例与边界](images/01-concept.svg)

图采用第四节代码的同一个风险分层机制，而不是另起一套成功率。处理前高、低风险各占一半，接受处理概率分别为 $`0.9`$ 与 $`0.1`$。在观察到的处理组中，由 Bayes 公式，高风险比例是 $`\frac{0.5\times0.9}{0.5}=0.9`$；筛选 $`A=1`$ 因而同时筛选了人群构成。

设置 $`do(A=1)`$ 则删除 $`X\to A`$ 的原分配机制，把所有人的处理固定为一；高、低风险仍各占一半。假定这张图描述完整的共同原因、其他机制保持不变，图中两种平均分别为

$$
\begin{aligned}
E[Y\mid A=1]&=0.9(0.4)+0.1(0.9)=0.45,\\[6pt]
E[Y\mid do(A=1)]&=0.5(0.4)+0.5(0.9)=0.65.
\end{aligned}
$$

两式采用相同层内结果机制，差别在外层权重。划掉的箭头表示**替换分配方程**，不是从数据里删除所有带箭头的记录，也不表示处理与结果间的作用被删除。这个图把标准化公式的机制含义提前展示出来；其因果解释仍取决于下面逐项说明的一致性、可交换性、正性及正确变量定义。

## 2. 识别、估计与推断分三步

<a id="causal-1-detail-6"></a>

### 2.1 识别是总体分布层面的唯一性

识别问的是：若无限观察数据让我们精确知道观察分布，在声明的假设下，目标效应是否有唯一值。估计是在有限样本中近似这个函数，推断则衡量抽样误差。没有识别时，增加数据可以把观察关联算得更准，却不会自动决定多个相容因果机制中哪一个是真的。这个层次区分能避免用更高模型容量回答一个原本没有唯一答案的问题。

识别结论总是相对于一个模型类。若允许任意未测混杂，某个效应可能不可识别；若增加随机化、合法调整变量或满足前门条件的中介，便可能识别。反过来，换成错误的目标总体、删除必要变量或混合不同时间机制，也可能破坏原来的结论。因此“已经识别”不能脱离变量、假设和目标单独使用。

<a id="causal-1-detail-7"></a>

### 2.2 三个条件如何进入调整公式

本章先采用一致性、条件平均可交换性和正性。对于平均效应，只需 $`E[Y(a)\mid A=a,X]=E[Y(a)\mid X]`$ 这样的均值限制；常用更强写法是 $`Y(a)\perp A\mid X`$。后者要求整个条件分布独立，不仅是均值。用较强条件便于解释，但不能把均值识别所需条件误说成必须识别所有反事实联合结构。

若目标协变量分布为 $`P_X`$，正性要求在其几乎处处支持上 $`P(A=a\mid X=x)>0`$。然后逐步得到

$$
\begin{aligned}
E[Y(a)]
&=E_X\{E[Y(a)\mid X]\}\\
&=E_X\{E[Y(a)\mid A=a,X]\}\\
&=E_X\{E[Y\mid A=a,X]\}.
\end{aligned}
$$

第一步来自全期望，第二步使用可交换性，第三步使用一致性。正性不是某一行代数等式的替换，而是保证所需条件均值在目标层中确实能由相应观察组决定。两个处理水平相减，才得到针对相同目标权重的 ATE。对连续 $`X`$，求和变积分，不能要求有限样本恰好有完全相同的每一个实数协变量值。

<a id="causal-1-detail-8"></a>

### 2.3 调整分布必须属于目标总体

设 $`m_a(x)=E[Y\mid A=a,X=x]`$，目标是 $`\int[m_1(x)-m_0(x)]\,dP_X(x)`$。若分别在两组自身的 $`X`$ 分布下求均值，就得到观察组差，而不是标准化后的同总体对比。调整的核心是让两个干预世界共享同一外层人群。回归、匹配和加权之所以可能有不同结果，一部分原因正是它们采用的目标权重不同。

若研究样本与目标总体协变量构成不同，可在结果可迁移等附加条件下换用目标分布。但不能只把权重替换就假定迁移成立，抽样还可能选择了不同的潜在响应。识别需说明条件效应或条件结果分布在哪些变量给定后保持稳定，以及目标支持是否被样本覆盖。外推到未见人群是另一个科学假设，不是打印更多小数。

<a id="deep-dive-2"></a>

<a id="causal-1-detail-9"></a>

### 2.4 两个观察上完全相同的世界

机制甲先抽公平的二元随机变量 $`U`$，令 $`A=U,Y=A`$。机制乙使用同样的 $`U`$，令 $`A=U,Y=U`$。观察时两者都只有零零与一一，各占一半，任何基于观察联合分布的算法都不能区分它们。但在甲中替换处理方程为 $`A=a`$ 后，$`Y=a`$，效应为一；乙中替换处理方程不改变 $`U`$，结果仍各半，效应为零。

甲的潜在结果为零和一两个常数，乙的两个潜在结果都等于 $`U`$。这同时说明结构方程与潜在结果之间的联系，以及为何干预不是在原数据里筛出 $`A=a`$ 那些人。在乙中，筛选 $`A=1`$ 也筛出了 $`U=1`$；真正设置 $`A=1`$ 并没有筛选 $`U`$。观察条件化改变所研究的人群，干预替换生成规则，这是差异的来源。

<a id="causal-1-detail-10"></a>

### 2.5 正性的理论与有限样本版本

结构性不重叠是某类人永远不可能获得某处理，例如规则禁止某人群接受某方案。即使无限数据，也无法直接识别那一层的未观察处理均值。实际不重叠则可能是概率非零却很小，在有限样本中没有足够信息。两者都让结果脆弱，但前者是识别缺口，后者还涉及估计方差和有限样本支撑。

不需要把每个倾向得分都强行拉到零点五。随机化概率可以不均等，观察研究中也常不均衡；关键是目标支持内有可比较信息，并认识接近零概率带来的不稳定。截断权重、限制样本或改用重叠人群可以缓和问题，但会引入偏差或改变对象，不能只把估计变稳作为仍然回答原问题的证明。

## 3. 从结构方程读出干预规则

<a id="causal-1-detail-12"></a>

### 3.1 因果图不只是相关方向图

有向无环图中每个节点由其父节点和外生噪声决定，例如 $`X=f_X(U_X)`$、$`A=f_A(X,U_A)`$、$`Y=f_Y(A,X,U_Y)`$。若外生变量相互独立，得到相应的 Markov 分解。若存在共同外生原因，要显式加入潜变量或用合适的混合图表达，不能在口头承认隐藏混杂后仍使用无混杂的因子分解。

图的一条边表示允许某变量的机制依赖另一变量，缺边则表达一种机制限制。观察到相关为零不一定支持删边，因为不同因果路径可能抵消。观察到相关非零也不决定边的方向，因为共同原因和选择都可能造成关联。图应综合时序、干预知识、领域机制和数据约束，而不是把预测特征的重要性排序直接画成因果箭头。

<a id="causal-1-detail-13"></a>

### 3.2 干预与截断分解

对于所有相关变量都已显式建模的独立噪声 DAG，观察密度分解为 $`\prod_j p(v_j\mid \mathrm{pa}_j)`$。实施 $`do(A=a)`$ 是删除原处理方程，把 $`A`$ 固定为 $`a`$，其他机制保持不变。干预后对未固定节点保留其原条件因子，形成截断分解。这个不变性是因果解释的内容，不是任意统计分解都自动具备的性质。

例如混杂图中干预密度是 $`p(x)p(y\mid a,x)`$，对 $`x`$ 求和得到调整式；观察条件密度则是 $`p(x\mid a)p(y\mid a,x)`$，两者权重不同。若处理会直接改变测量方式，所谓其他机制不变需要把测量过程也纳入模型。否则干预前后的同名结果可能已经不是同一个量。

<a id="causal-1-detail-14"></a>

### 3.3 三种局部结构与路径规则

链 $`A\to M\to Y`$ 和叉 $`A\leftarrow X\to Y`$ 在不条件化时通常可传递关联，对中间非碰撞点条件化会阻断该路径。碰撞结构 $`A\to C\leftarrow U`$ 则默认阻断，条件化碰撞点或其后代可能打开。路径是否开通需要按整条路径检查，不能只记住某个变量的固定标签，因为同一节点在不同路径上可以扮演不同角色。

d 分离说的是图所蕴含的条件独立性。在满足因果 Markov 条件的分布里，图上所有路径被阻断就推出独立；反向从观察独立推图结构还需要额外条件，常涉及忠实性，且多个图可能 Markov 等价。不能把“数据未拒绝独立”当作确认没有因果路径，样本不足和参数抵消都可能造成这种现象。

<a id="causal-1-detail-15"></a>

### 3.4 后门集合的充分性与边界

经典后门条件要求调整集合不含处理的后代，并阻断所有以箭头指向处理开始的路径。在这个充分条件下，可用该集合标准化识别总效应。它为一类合法调整给出简单规则，不是所有可识别问题的必要条件，也不是说任何处理后变量都永远不能用于任何识别；前门与纵向 g 公式会在不同条件下使用处理后信息。

选择集合时应逐条列出非因果路径，检查共同原因是否被阻断，碰撞路径是否被误开。包括更多变量既可能降低残余混杂，也可能打开路径、加剧重叠困难或增加估计负担。合法性与效率是不同问题：两个集合都能识别同一效应，有限样本方差仍可能不同。先讨论能否识别，再比较估计质量。

<a id="sec-3-1"></a>

<a id="causal-1-detail-16"></a>

### 3.5 碰撞点选择的逐格计算

令 $`A,U`$ 独立且各半，$`Y=U`$，只要 $`A=1`$ 或 $`U=1`$ 就令 $`C=1`$。四种组合各占四分之一，处理对结果没有任何作用。全体中两组结果均值均为二分之一。筛到 $`C=1`$ 后，零零组合被删除；当 $`A=0`$，只能是 $`U=1`$，结果均值一；当 $`A=1`$，两种 $`U`$ 仍各半，均值二分之一，因此观察差变成负二分之一。

这不是样本随机波动，而是总体条件分布已经变化。即使样本无限大，筛选后的回归也会稳定看到负关联。选择变量可以表示入院、被录取、通过审核或保留到随访结束；如果同时受处理和结果相关因素影响，条件化就可能制造偏差。处理前发生的选择也可能是碰撞点，因此只按测量时刻判断是否应调整是不够的。

![碰撞点选择的四格概率图](images/01-collider-selection.svg)

每个格子对应一个 $`(A,U)`$ 组合。左图是未筛选总体，四格各占 $`\frac14`$；右图先删除零零格，再按剩余概率 $`\frac34`$ 归一化，三格各占 $`\frac13`$。计算组内均值时还要在每一行重新条件化：零处理组只剩结果一，处理组保留零和一各半，因此筛选后的差为 $`-\frac12`$。格子的变化来自选择规则，结构方程始终为 $`Y=U`$，不能把负关联解释为处理造成伤害。

### 3.6 实验一：枚举非识别与选择反例

以下代码独立运行，只枚举有限概率质量，不训练预测器。相同联合表与不同干预效应验证非识别反例，筛选均值验证碰撞偏差。它证明这几个明确定义机制的数学关系，没有声称实际观察数据一定由其中一个机制产生。

```python
import numpy as np
joint_causal=np.zeros((2,2))
joint_common=np.zeros((2,2))
for u in (0,1):
    joint_causal[u,u]+=.5
    joint_common[u,u]+=.5
assert np.array_equal(joint_causal,joint_common)
causal_do=np.array([0.,1.])
common_do=np.array([.5,.5])
assert np.allclose(causal_do[1]-causal_do[0],1.)
assert np.allclose(common_do[1]-common_do[0],0.)
rows=[(a,u,.25) for a in (0,1) for u in (0,1)]
means=[]
for a in (0,1):
    selected=[(u,p) for aa,u,p in rows if aa==a and (aa==1 or u==1)]
    means.append(sum(u*p for u,p in selected)/sum(p for _,p in selected))
assert np.allclose(means,[1.,.5])
print("same_joint",joint_causal.tolist(),"do_ATE",[1.,0.],"selected_means",means,"collider_difference",means[1]-means[0])
```


实际运行得到两个观察联合表相同，干预 ATE 分别为一和零；选择后的零组均值一、一组均值零点五，差为负零点五。所有断言通过。精确枚举没有 Monte Carlo 误差，因此不需要用大样本显著性检验解释差异。

## 4. 分层效应与总体反向

<a id="causal-1-detail-19"></a>

### 4.1 组成差异如何改变符号

目标总体低风险与高风险各半，未处理成功率分别为零点八与零点三，处理后为零点九与零点四。每层风险差都是正零点一。如果高风险接受处理概率零点九，低风险为零点一，则总体处理比例为一半，处理组九成高风险，对照组九成低风险。粗处理均值是零点四五，粗对照均值零点七五，观察差负零点三。

标准化把两个世界都放回低高风险各半的人群，处理均值为零点六五，对照为零点五五，差正零点一。这个反向不是数学矛盾，因为外层权重不同。它也不是看到分层后反转就必然该相信分层结果；如果分层变量是碰撞点或处理后变量，反转可能由错误条件化制造。因果图和识别条件决定应使用哪一种比较。

若把总体差拆开，一部分来自层内结果差，一部分来自两组的层构成差。不同拆法可以选择不同参照权重，因此不能用一个“解释比例”替代明确估计对象。本章选择预先给定目标权重，让问题清楚地对应同一总体两种干预。下一章的加权与双重稳健估计也都应有这个明确目标，而不只是机械套公式。

<a id="causal-1-detail-20"></a>

### 4.2 实验二：完整人工观察研究

现在完整生成八万条观察记录，而不直接把真值当估计值。先生成二元风险层，按层分配不同处理概率，再按对应结果概率生成二元结果。估计器只使用观察到的 $`X,A,Y`$，在每个层和处理组内求样本均值，然后按预先声明的各半目标权重标准化。真值来自生成机制，用于最后核验，不进入条件均值估计。

```python
import numpy as np
rng=np.random.default_rng(20261019)
n=80000
x=rng.integers(0,2,n)
a=(rng.random(n)<np.where(x==1,.9,.1)).astype(int)
p=.8-.5*x+.1*a
y=(rng.random(n)<p).astype(float)
means=np.array([[y[(x==xx)&(a==aa)].mean() for aa in (0,1)] for xx in (0,1)])
counts=np.array([[((x==xx)&(a==aa)).sum() for aa in (0,1)] for xx in (0,1)])
target_weights=np.array([.5,.5])
standardized=float(target_weights@(means[:,1]-means[:,0]))
crude=float(y[a==1].mean()-y[a==0].mean())
oracle=float(target_weights@np.array([.1,.1]))
assert counts.min()>3000
assert abs(standardized-oracle)<.015
assert -.33<crude<-.27
assert standardized>0 and crude<0
print("counts",counts.tolist(),"conditional_means",means.tolist())
print("crude",crude,"standardized",standardized,"true_target_ATE",oracle)
# Equal subgroup effects do not imply equal subgroup composition.
for xx in (0,1):
    assert abs((means[xx,1]-means[xx,0])-.1)<.025
```


实际样本四个格的数量为三万五千九百一十九、四千零四、四千零六十、三万六千零一十七。低风险两组均值约零点八零零四与零点八九五一，高风险约零点二九四三与零点三九五三。粗差为负零点三零三七二七，标准化差为正零点零九七八二二，生成真值正零点一，全部断言通过。有限样本值不应强制等于真值，也不能因为误差落在容差内就宣称有通用保证。

这个完整流程包括任务定义、数据生成、估计和真值核验，却仍是极简单的已测混杂模型。现实研究没有可读取的潜在真值，且每层结果模型可能复杂得多。当前各格有数千样本，也未出现严重有限支持问题。它验证实现能纠正这一机制的组成差异，没有验证忽略其他共同原因仍可得到正确结论。

<a id="causal-1-detail-21"></a>

### 4.3 不同效应尺度的差别

二元结果可用风险差、风险比或优势比。风险差比较成功概率的绝对变化，风险比比较相对倍数；优势比比较成功与失败比值之比。它们回答不同问题，不能把一个数直接当另一个。零点四增加到零点五与零点八增加到零点九，风险差相同而风险比不同，所谓效应是否异质取决于尺度。

优势比还有非可塌缩性：即使处理随机化、没有混杂，条件优势比与边际优势比也可能不同。因此增加合法协变量后逻辑回归处理系数变化，不足以证明原模型有混杂。应先将模型预测标准化到所需边际概率，再计算目标尺度，并区分统计模型参数与人群效应。处理系数本身未必就是研究者想要的 ATE。

<a id="causal-1-detail-22"></a>

### 4.4 平均效应不识别获益者

若干预成功率分别为 $`q_1,q_0`$，令 $`b=P(Y(1)=1,Y(0)=0)`$ 表示获益者比例。只知道两个边际时，有

$$
\max(0,q_1-q_0)\le b\le\min(q_1,1-q_0).
$$

下界来自获益至少覆盖净增加，上界来自获益者既属于处理成功者，也属于对照失败者。以标准化均值零点六五与零点五五为例，获益比例可以在零点一与零点四五之间，平均效应仍都为零点一。净效应可能来自少数人获益而无人受损，也可能同时有许多人获益和受损。识别平均并没有恢复每个单位丢失的那一半结果。

## 5. 前门识别：中介为何有时能够帮忙

<a id="causal-1-detail-24"></a>

### 5.1 条件不是“记录一个中介”这么简单

考虑 $`A\to M\to Y`$，同时有隐藏的 $`U\to A,U\to Y`$。直接调整观察到的处理前变量可能不足，但如果所有从 $`A`$ 到 $`Y`$ 的有向路径经过 $`M`$，$`A`$ 到 $`M`$ 没有未阻断后门路径，且 $`M`$ 到 $`Y`$ 的所有后门路径被 $`A`$ 阻断，就有经典前门识别。还需相应处理和中介组合有支持，以便条件分布可从数据决定。

这些条件很强。第一条排除绕过中介的直接效应，第二条排除处理和中介之间未控共同原因，第三条要求处理足以处理中介与结果之间的后门关联。一个变量时间上在处理之后，不会自动满足这些性质。若存在处理诱发的中介结果混杂，简单前门公式通常不能直接使用，必须重新分析图与目标。

<a id="causal-1-detail-25"></a>

### 5.2 前门公式的两段调整

先识别设置处理后的中介分布，因为处理到中介没有后门，得到 $`p(m\mid do(a))=p(m\mid a)`$。再考虑设置中介对结果的作用，处理阻断其后门，故

$$
p(y\mid do(m))=\sum_{a'}p(y\mid m,a')p(a').
$$

由于处理到结果的作用全部由中介传递，设置 $`a,m`$ 后，处理不再留下额外有向作用；在上述图的干预分布中，对中介干预结果按设置处理产生的中介分布混合，得到

$$
p(y\mid do(a))
=\sum_m p(m\mid a)\sum_{a'}p(y\mid m,a')p(a').
$$

内部对 $`a'`$ 的平均用于处理原本中介与结果间经过处理及隐藏原因的后门，外部按目标处理所产生的中介分布加权。内部不能把 $`a'`$ 直接换成外层固定的 $`a`$，否则又把隐藏原因的选择分布带回来。公式中同一个处理变量出现在两个不同角色里，需要靠求和下标区分。

<a id="causal-1-detail-26"></a>

### 5.3 一个可逐步算完的前门模型

令隐藏二元 $`U`$ 各半，处理概率为 $`P(A=1\mid U=u)=0.2+0.6u`$，中介概率为 $`P(M=1\mid A=a)=0.1+0.7a`$，结果概率为 $`0.1+0.4m+0.3u`$。不同机制的随机扰动相互独立。观察到处理的人中，$`U=1`$ 概率为零点八，未处理组为零点二，因而粗差包含零点一八的混杂贡献。

真正设置处理不改变 $`U`$ 的各半分布，所以两种干预均值是零点二九与零点五七，效应零点二八。观察均值却是零点二与零点六六，差零点四六。前门内部平均先恢复设置中介的结果均值零点二五与零点六五，再按中介概率零点一或零点八混合，恢复正确干预均值。这是识别条件产生的代数结论，不是中介回归系数相乘在任意模型中都有效。

**两次平均各自消除哪一种选择。**

![前门识别从观察条件均值到中介干预均值，再到处理干预结果](images/01-frontdoor-two-stage-average.svg)

图沿用本节生成器。由于给定 $`A`$ 后，中介的独立随机扰动不再携带关于 $`U`$ 的额外信息，$`P(U=1\mid A=0,M)=0.2`$、$`P(U=1\mid A=1,M)=0.8`$。将它们代入结果机制，四个可观察条件均值按“中介为行、处理为列”排列为

$$
\bigl(E[Y\mid M=m,A=a]\bigr)_{m,a}
=\begin{pmatrix}0.16&0.34\\0.56&0.74\end{pmatrix}.
$$

第一步将每一行都按同一边际处理比例 $`p(A)=(0.5,0.5)`$ 平均，得到 $`h(0)=0.25,h(1)=0.65`$。这里不是按 $`p(A\mid M=m)`$ 平均；后者恢复观察条件均值，会重新带入中介选择的处理组成。第二步才使用想设置的处理水平所产生的中介比例：$`a=0`$ 时是 $`(0.9,0.1)`$，$`a=1`$ 时是 $`(0.2,0.8)`$，故干预结果分别为 $`0.29,0.57`$。右图的两个端点固定为 $`h(0),h(1)`$，圆面积编码这一步的中介权重，三角标记是其加权重心；两行重心移动来自分配比例改变，不是端点结果机制被替换。

前门的两层求和及其图条件见 [Pearl 原论文第 3.2 节、图 3、定理 2 与式 (9)](https://bayes.cs.ucla.edu/R218-B.pdf)。图中的数值是本章独立构造，不是论文中的经验数据。以下加入直接作用的反例会使这条识别路线失效，即使四格、权重与最终概率依然全部合法；计算可执行和假设成立需要分别核对。

<a id="causal-1-detail-27"></a>

### 5.4 实验三：精确枚举并故意破坏排除条件

以下代码枚举隐藏原因后得到完整观察联合表，再仅使用这张表计算前门函数。第二个模型在结果机制中加上零点一乘处理的直接项，故意破坏所有效应均经过中介的条件。它不改变中介分配，检验同一公式在条件失效时会怎样，而不是只展示一个成功算例。

```python
import numpy as np
def enumerate_joint(direct):
    p=np.zeros((2,2,2))
    for u in (0,1):
        for a in (0,1):
            pa=(.2+.6*u) if a else (1-(.2+.6*u))
            for m in (0,1):
                pm=(.1+.7*a) if m else (1-(.1+.7*a))
                py=.1+.4*m+.3*u+direct*a
                for y in (0,1):
                    p[a,m,y]+=.5*pa*pm*(py if y else 1-py)
    assert np.isclose(p.sum(),1.)
    return p
def frontdoor(p):
    pa=p.sum((1,2))
    pm_a=p.sum(2)/pa[:,None]
    mean_y=p[:,:,1]/p.sum(2)
    return pm_a@(pa@mean_y)
for direct in (0.,.1):
    p=enumerate_joint(direct)
    fd=frontdoor(p)
    naive=p[:,:,1].sum(1)/p.sum((1,2))
    true=np.array([.1+.4*(.1+.7*a)+.15+direct*a for a in (0,1)])
    assert np.allclose(fd,[.29+direct*.5,.57+direct*.5])
    assert np.isclose(true[1]-true[0],.28+direct)
    if direct==0:
        assert np.allclose(fd,true)
        assert np.isclose(naive[1]-naive[0],.46)
    else:
        assert np.isclose((fd[1]-fd[0])-(true[1]-true[0]),-.1)
    print("direct",direct,"frontdoor_means",fd.tolist(),"true_do_means",true.tolist(),"naive",naive.tolist())
```


无直接项时，前门均值为零点二九与零点五七，与真实干预完全一致；粗差为零点四六。加入直接项后，真实干预均值为零点二九与零点六七，效应零点三八，前门函数给零点三四与零点六二，差仍零点二八，低估零点一。所有断言通过。一个公式在成功机制上成立，不代表它能自行检测排除条件被违反；失效可能仍输出很平滑的数值。

## 6. 随机试验、依从性与选择

<a id="causal-1-detail-29"></a>

### 6.1 随机分配建立的是哪个独立性

若随机分配 $`Z`$ 独立于潜在结果，分配对结果的意向处理效应可由分配组差识别，在失访等问题被妥善处理的条件下不需要用观察回归补出分配独立性。但实际接受处理 $`A`$ 可能不同于分配 $`Z`$，由依从性、资源和个人选择决定。按实际接受者直接分组，可能重新引入混杂。因此随机化的是哪一个变量，应从设计开始写清。

工具变量分析在排除限制、独立性、相关性和适当单调性下可以识别局部依从者效应等对象，但它不是自动恢复全体 ATE 的通用按钮。本章不把意向处理、实际处理或局部效应混称。若不愿接受工具变量假设，可以直接报告分配策略的效应，前提是它符合实际问题。

<a id="causal-1-detail-30"></a>

### 6.2 失访与完整案例不是无害删行

即使初始随机分配，随访留存若受处理和预后因素共同影响，完整案例比较也可能打开选择路径。应定义目标结果在失访者身上是否仍有含义，说明观察过程，考虑合适的删失可交换性和正性，或给出敏感性范围。仅报告两组失访率相同，也不能排除失访者构成不同。

同理，把“是否完成培训”作为分析条件，可能同时选择了处理后的动力、健康和时间资源。完成者比较不是原始随机分配效果。可以定义不同问题，但必须重新论证识别，不能把随机试验的独立性原封不动搬到处理后筛选子集。

<a id="causal-1-detail-31"></a>

### 6.3 随机误差、系统偏差与设计收益

随机化不会保证有限样本协变量恰好平衡，它保证分配机制在重复随机化意义上独立。基线偶然不平衡可以通过预设调整改善精度，但并不等于随机化失败。相反，观察研究调整后均值非常平衡，也只能说明所检查变量与统计特征平衡，不会自动验证未测量因素。

标准误刻画所选抽样或随机化机制中的波动，不能覆盖所有未测混杂、测量错误和干预版本不清的系统问题。一个很窄的置信区间可能只说明错误目标被估计得很精确。完善分析应同时给出设计、识别、估计和敏感性论证，而不是把统计显著性当作因果认证。

<a id="causal-1-detail-32"></a>

## 7. 把一个问题写成可审查的研究

<a id="causal-1-detail-33"></a>

### 7.1 模拟目标试验的时间协议

在分析前依次写出入选资格、处理方案、分配时点、随访窗口、结果、因果对比和分析计划。这里的“目标试验”是帮助明确问题，不是声称观察研究已经获得随机化。如果两个方案要求不同持续时间或依从规则，应说明何时开始、何时偏离以及如何处理偏离，不能在知道未来结果后重写基线资格。

以培训为例，可以比较合格人在某日开始规定课程与不开始课程的半年结果。若把处理定义成未来半年内曾参加，就可能让后来参加者必须先保留到参加时点，造成不公平的时间比较。把时间零点、可比较资格和处理定义对齐，是估计器之前的任务。再好的机器学习模型也不能自动识别这种时间协议错误。

<a id="causal-1-detail-34"></a>

### 7.2 变量清单要记录因果角色

对每个变量写测量时间、可能原因、测量误差、缺失机制，以及它在图中可能打开或阻断的路径。处理前收入可为混杂变量，处理后收入可为中介，同一个名称在不同时间并非同一个节点。结果发生后的信息不应被模型当成基线预测特征，否则不仅泄漏，还可能改变比较人群和因果角色。

应讨论替代合理图。若一个变量可能既是混杂指标又是碰撞点，需说明哪种机制更可信，以及各图会要求怎样调整或收集新信息。选择一个图并画得整齐，不会替代对其假设的论证。数据可反驳某些图蕴含的独立关系，却常不能从多个未被反驳的图中唯一选出真实机制。

<a id="causal-1-detail-35"></a>

### 7.3 重叠诊断与平衡诊断回答不同问题

重叠诊断检查目标协变量区域是否有两种处理信息，可查看倾向分布、分层样本量和极端权重。平衡诊断检查调整后被测协变量的分布是否更接近，除了均值还可检查非线性变换、交互和尾部。即便二者看起来都好，依然不能证明未测混杂消失；它们是对可观察问题的检查，不是对不可观察假设的闭合验证。

如果某层只有一组，先报告这个缺口，再决定收集数据、改变目标还是接受模型外推。若改为倾向在某区间的人群，要同时修改估计对象与解释。可以展示全体模型依赖结果和重叠人群结果，但不能把不同对象差异全部归因于估计器更好。目标变化本身可能改变效应。

<a id="causal-1-detail-36"></a>

### 7.4 数据拆分不能创造可交换性

开发集用于选择模型和分析配置，最终留出集用于评价预测或预设估计流程的样本外行为。拆分可以减少过拟合与选择影响，却不会随机化历史处理。观察数据被随机分成两半后，每半内的处理和未测共同原因依然相关。交叉拟合也解决辅助模型估计与得分评价的依赖问题，而不是替代识别条件，下一章会精确推导它的作用。

人工实验知道生成机制，才可以直接计算效应误差。真实观察研究的留出集通常不能提供个体反事实标签，因此预测误差低不等于因果偏差低。应区分辅助回归的样本外拟合检查、因果估计的统计推断和设计假设的实质依据。三者协同，但任何一项都不能包办其他项。

<a id="causal-1-detail-37"></a>

## 8. 不可识别时还能学到什么

<a id="causal-1-detail-38"></a>

### 8.1 结果有界带来的部分识别

若 $`Y`$ 为零一结果，只使用一致性，不假设处理可交换，定义 $`p_{11}=P(A=1,Y=1)`$、$`p_{01}=P(A=0,Y=1)`$、$`p_1=P(A=1)`$、$`p_0=P(A=0)`$。已接受处理者的处理潜在结果已知，未处理者的处理潜在结果只能在零和一之间，故

$$
\begin{aligned}
p_{11} &\le E[Y(1)]\le p_{11}+p_0,\\[6pt]
p_{01} &\le E[Y(0)]\le p_{01}+p_1.
\end{aligned}
$$

所以 ATE 落在 $`[p_{11}-p_{01}-p_1,\;p_{11}-p_{01}+p_0]`$。这些界来自为未观察的潜在结果取极端值，可以在不额外耦合限制下达到。对于零零、一一各半的观察表，区间是零到一，与前述两个相容机制的效应一致。数据确实排除了一些值，但没有唯一决定答案。

<a id="causal-1-detail-39"></a>

### 8.2 敏感性参数应对应机制

考虑简单加性模型 $`Y(a)=\alpha+\tau a+\beta U+\epsilon(a)`$，其中隐藏二元 $`U`$ 影响处理分配，且明确要求 $`E[\epsilon(a)\mid A,U]=0`$，即给定处理分配与隐藏因素后残差条件均值仍为零。粗差为 $`\tau+\beta\{P(U=1\mid A=1)-P(U=1\mid A=0)\}`$。令括号中的差为 $`\delta`$，则偏差是 $`\beta\delta`$。该式依赖加性、常数效应和正确残差条件，不是任意非线性问题的通用敏感性公式。

例如观察差零点四六，如果隐藏因素对结果的平均影响为零点三、组间隐藏比例差为零点六，则偏差零点一八，净效应零点二八。若只知道 $`\beta`$ 和 $`\delta`$ 的可信范围，可以把其乘积范围映射成效应范围。应让这些范围能与领域知识或已测变量规模对照，而不是任意挑一个能使结论消失的数后称作证明。

<a id="causal-1-detail-40"></a>

### 8.3 测量误差与代理变量

记录到混杂因素的有噪代理，不等于已经给定真正共同原因。若 $`X^\ast`$ 只是 $`U`$ 的误分类指标，给定 $`X^\ast`$ 后，处理仍可能携带关于 $`U`$ 的信息，残余混杂仍在。加大代理数量可能有帮助，但是否足以识别需要具体测量模型与额外条件。不能用“模型能学出隐藏因素”跳过这一步。

负对照可帮助发现某些未控偏差，但负对照暴露或结果应有明确的无因果作用与共享偏差路径依据。发现异常关联能反驳简单假设，未发现异常则可能是低功效、代理太弱或偏差抵消。正式的代理因果识别还需要更强完整性等条件，超出本章简单调整；本章强调先知道普通分析在哪一步不足。

<a id="causal-1-detail-41"></a>

### 8.4 缺失、选择与迁移的不同层

处理缺失、结果缺失和只观察入选者，会影响不同分布。不能把所有缺失都补成一个数后继续使用原识别证明。插补模型对缺失机制的条件独立假设，应和因果模型一起讨论。某个变量预测缺失很好，不表示所采用的随机缺失假设就成立；缺失者的未观察结果仍可能系统不同。

研究总体与目标总体不一致时，同样要检查选择是否依赖效应修饰变量，是否存在目标支持缺口。一个在源样本中可靠估计的效应，可能因目标构成变化而不适用。迁移不是默认属性，需说明允许哪些机制变化、哪些条件响应保持相同，以及目标权重来自何处。

<a id="visual-extension-causalinference-01"></a>
### 图解：不可识别时应报告多个相容世界

![不可识别时应报告多个相容世界](images/01-extension.svg)

在同一组观测治疗组与对照组结果下，未观测的潜在结果可以有多种补全方式。图用两名个体的实心观测端点与空心反事实端点说明：仅看到每人实际接受处理后的结果，并不能同时看到其反事实结果。

<a id="causal-iv-local-effect"></a>

### 8.5 工具变量识别的是谁的效应

若实际处理 $`A`$ 与潜在结果混杂，但有一个随机鼓励或随机分配 $`Z\in\{0,1\}`$，识别路线可以改变。令 $`A(z)`$ 为分配为 $`z`$ 时实际是否接受处理，结果潜在值仍记为 $`Y(a)`$。标准二元 LATE 论证需要逐项说明：$`Z`$ 与 $`(A(0),A(1),Y(0),Y(1))`$ 独立且两种分配均有正概率；排除限制要求分配只经实际处理影响结果；一致性与无干扰使观测对应相应潜在结果；相关性要求两分配下处理率不同；单调性 $`A(1)\ge A(0)`$ 排除被鼓励后反而从处理变为不处理的人。这些条件中，处理率差可从数据检查，排除限制和个体单调性一般不能仅凭观察分布验证。

在这些条件下，处理类型只有从不处理 $`(0,0)`$、服从分配 $`(0,1)`$、总是处理 $`(1,1)`$。对所有类型，

$$
Y(A(1))-Y(A(0))
=(A(1)-A(0))(Y(1)-Y(0)).
$$

从不处理与总是处理者右侧均为零，只有服从者留下其处理效应。因而

$$
\begin{aligned}
E[Y\mid Z=1]-E[Y\mid Z=0]
&=P(\mathrm{complier})\,
E[Y(1)-Y(0)\mid\mathrm{complier}],\\
E[A\mid Z=1]-E[A\mid Z=0]
&=P(\mathrm{complier}).
\end{aligned}
$$

两个可识别分配效应的比值，就是服从者平均效应 $`\operatorname{LATE}`$，不是自动得到总体 ATE。推导对象与条件可对照 [Angrist、Imbens 与 Rubin 原论文命题 1 及表 1](https://users.nber.org/~rdehejia/%21%40%24AEM/Topic%2004%20IV/readings/angrist_imbens_rubin_JASA_1996.pdf)。

![随机分配只改变服从者处理，Wald比值与总体ATE不同](images/01-iv-complier-effect.svg)

图使用一个独立构造的总体：三类比例依次为 $`0.2,0.5,0.3`$，每个人 $`Y(0)=2`$，三类处理效应分别为 $`2,4,8`$，并让 $`Z`$ 独立随机分配。没有鼓励时只有总是处理者接受处理，故处理率 $`0.3`$、结果均值 $`0.2\times2+0.5\times2+0.3\times10=4.4`$；有鼓励时服从者也处理，处理率 $`0.8`$、结果均值 $`0.2\times2+0.5\times6+0.3\times10=6.4`$。于是

$$
\operatorname{Wald}=\frac{6.4-4.4}{0.8-0.3}=4,
\qquad
\operatorname{ATE}=0.2\times2+0.5\times4+0.3\times8=4.8.
$$

图中的类型及效应是生成模型的潜在设定，不能在真实数据里逐人同时读出 $`A(0),A(1)`$。同一份工具变量研究通常只能识别这批服从者的平均效应，而不能认定谁就是服从者，也不能靠更复杂回归自动扩展成总体效应。更换鼓励方式可能改变服从者组成，LATE 因此也可能改变。

若允许违背者，分子与分母都成为服从者和违背者贡献的差，普通 Wald 比值不再是上述服从者均值；若分母很小，有限样本比值还可能极不稳定。因此“有工具变量”不是省略识别条件的捷径，识别、估计精度与外推总体仍应分别讨论。

<a id="causal-1-detail-42"></a>

## 9. 从效应走向干预策略

<a id="causal-1-detail-43"></a>

### 9.1 确定性与随机性规则

若政策根据处理前变量选择 $`g(X)`$，在相应一致性、可交换性和支持条件下，其价值为 $`E[m_{g(X)}(X)]`$。随机规则 $`q(a\mid X)`$ 的价值为 $`E[\sum_a q(a\mid X)m_a(X)]`$。只需在政策可能选择的动作上有观察支持，但若要比较所有任意政策，就需要更广的覆盖。政策规则本身必须能在实际决策时获得所用变量。

效应为正并不自动说明所有人都应处理，因为成本、资源、公平和风险偏好可能进入目标。可以把净结果定义为收益减成本，也可以设约束优化，但都要先明确量纲与目标。因果识别提供可比较干预后果的一部分基础，不会替研究者决定什么结果更值得追求。

<a id="causal-1-detail-44"></a>

### 9.2 学习策略与评价策略的区别

如果根据同一批结果挑选最优规则，再用同一批估计值宣称规则有效，会产生选择乐观。需要把政策开发、模型选择与最终评价分开，或采用理论支持的交叉拟合与推断程序。即便每个固定政策估计近似无偏，最大值也往往向上偏，这与预测中挑最高验证分数的现象有关，但因果评价还多了支持和识别要求。

多阶段决策进一步要求每步处理前历史被正确记录，历史中的变量可能受过去处理影响。把所有时点变量当作普通基线一次调整，可能阻断旧处理路径或引入偏差。第三章将从完整历史分布推序贯评价，说明何时轨迹比率与分步比率有效，而不是把单次 ATE 公式机械重复。

## 10. 进阶习题与详细解答

<a id="causal-1-detail-46"></a>

### 10.1 题一：观察差的目标是谁

题目：处理组高风险占九成，对照组高风险占一成，每层处理均提高成功率零点一。为什么粗差仍可能负？

解答：分别使用实际组内组成，处理均值为 $`0.9\times0.4+0.1\times0.9=0.45`$，对照为 $`0.1\times0.3+0.9\times0.8=0.75`$，差负零点三。两组不是同一目标人群。若目标高低各半，则处理均值零点六五，对照零点五五，差正零点一。符号不同来自混合权重，并不违反每层的算术。但分层是否合理仍需因果依据，不能只因结果更符合预期就接受调整。

<a id="causal-1-detail-47"></a>

### 10.2 题二：两种潜在结果能否同时识别

题目：随机试验识别处理成功率零点六五、对照成功率零点五五，能否断言只有一成人获益？

解答：不能，净风险差零点一等于获益比例减受损比例。获益比例下界为零点一，上界为零点四五。可以有一成获益、无人受损，也可以有四成获益、三成受损，剩余人结果不变，这两种结构有相同净差并可满足给定边际。随机化支持两个干预边际的估计，没有让同一人两种结果同时出现。若加单调不受损假设，才会把获益比例限定为净差。

<a id="causal-1-detail-48"></a>

### 10.3 题三：ATT 应如何使用目标权重

题目：高风险人的效应零点二、低风险零点零五，目标总体高风险各半，处理者九成高风险。求 ATE 与 ATT。

解答：ATE 是 $`0.5\times0.2+0.5\times0.05=0.125`$。在分层内可交换等条件下，ATT 使用处理者的协变量分布，得到 $`0.9\times0.2+0.1\times0.05=0.185`$。二者差异不表示某个估计器有错，而是目标不同。ATT 的反事实对照需要在处理者支持区域有未处理信息；没有必要为了 ATT 额外要求对纯未处理区域也有处理者，但不能外推处理者本身缺少对照的区域。

<a id="causal-1-detail-49"></a>

### 10.4 题四：哪个条件用于哪一步

题目：有人把调整式第一行换成观察组条件均值后说只用了全期望，问题在哪里？

解答：全期望只允许把总体潜在均值写成协变量条件潜在均值的平均，不允许随意加入 $`A=a`$ 条件。把 $`E[Y(a)\mid X]`$ 换成 $`E[Y(a)\mid A=a,X]`$ 使用可交换性；再换成观察 $`Y`$ 使用一致性。正性保证这组条件分布在所需支持上有定义且可获知。逐步标注每个等式，可准确指出观察数据之外的假设进入哪里，而不会把整个推导误称为纯概率恒等式。

<a id="causal-1-detail-50"></a>

### 10.5 题五：预测完美为什么仍不够

题目：观察数据只有零零与一一，且各半，预测准确率一。求两个相容模型的效应。

解答：令公平 $`U`$ 决定 $`A`$。模型甲为 $`Y=A`$，干预零得到零，干预一得到一，效应一。模型乙为 $`Y=U`$，两种干预都让结果均值为一半，效应零。两个模型预测上完全一样，因为观察时 $`A=U`$。任何只读取同一观察表的算法都会接收到相同输入，因此无法保证同时对两个模型输出正确唯一效应。需要额外机制假设或干预信息，而不是更复杂分类器。

<a id="causal-1-detail-51"></a>

### 10.6 题六：筛选成功者会发生什么

题目：独立公平二元 $`A,U`$，结果 $`Y=U`$，选择条件是两者至少一个为一。处理对结果为零，筛选后差是多少？

解答：选中集合包含零一、一零、一一三个等概率格。给定处理零，只剩零一，均值为一；给定处理一，剩一零和一一，均值一半，故差负一半。处理与隐藏因素本来独立，筛选打开碰撞路径后不再独立。把样本增到无限也不会消除这项差异，因为它来自条件概率而非波动。合法修正需要讨论选择机制和目标分布，不能只加一个“是否入选”作为常数特征。

<a id="causal-1-detail-52"></a>

### 10.7 题七：处理前变量一定安全么

题目：一个在处理之前测量的变量同时受两个独立原因影响，其中一个影响处理，另一个影响结果，是否必然应该调整？

解答：不必。若结构为 $`A\leftarrow U_1\to C\leftarrow U_2\to Y`$，未调整 $`C`$ 时该路径被碰撞点阻断；调整后会打开非因果关联。测量在前只能排除某些反馈方向，不能决定路径角色。应逐条检查图，而不是用“所有处理前变量”作为不加论证的规则。若还有其他路径，整体结论还要联合考虑它们，不能只依据这一条局部路径决定全部分析。

<a id="causal-1-detail-53"></a>

### 10.8 题八：调整中介后系数变小意味着什么

题目：真实机制是 $`M=2A+\epsilon_M`$、$`Y=3M+A+\epsilon_Y`$，独立均值零噪声且处理无混杂。总效应与控制直接效应各多少？

解答：设置处理增加一单位，会让中介均值增加二，间接贡献六，直接贡献一，总效应七。若同时把中介固定为同一个值，处理变化只剩直接项一。在线性独立噪声模型下相应回归可表现为七与一，但差异反映目标改变，不是自动证明其中一式遗漏变量。非线性、交互或中介结果混杂下，系数相减还不能直接解释为自然间接效应，需要更严格的反事实定义与识别条件。

<a id="causal-1-detail-54"></a>

### 10.9 题九：理论正性与样本空格

题目：某层接受处理概率千分之一，有限样本没有处理者；另一层按规则永远禁止处理。这两种问题相同吗？

解答：前者在总体上可能满足正性，但有限信息极弱，估计会高度依赖平滑、样本规模或外推；后者即使无限数据也缺少对应条件结果，属于结构性支持缺口。二者都需要明确报告，但处理方式不同。增加该层样本可能改善前者，却不会改变后者的分配规则。若限制到其他人群，应改写目标，不能继续把新结果称为原全体效应而省略限制。

<a id="causal-1-detail-55"></a>

### 10.10 题十：前门内部为什么还要平均处理

题目：在标准前门图中，能否用 $`\sum_m p(m\mid a)E[Y\mid m,a]`$ 代替完整前门公式？

解答：这只按固定处理组内中介分布混合，恢复的是该组观察均值，仍带处理组所选择的隐藏因素构成。正确内部平均应是 $`\sum_{a'}p(a')E[Y\mid m,a']`$，用于识别设置中介后的结果，再由外层目标处理产生的中介分布混合。两处处理变量角色不同，一个是想实施的设置，一个是后门标准化求和。混同下标会把最关键的去混杂步骤删掉。

<a id="causal-1-detail-56"></a>

### 10.11 题十一：前门条件破坏后数值如何偏

题目：本章前门模型结果中增加零点一乘处理的直接项，前门风险差与真实风险差各多少？

解答：原经中介风险差为 $`0.7\times0.4=0.28`$。直接项使真实总差增加零点一，成为零点三八。前门内部对处理边际平均，把直接项平均成共同的零点零五，两个外层干预世界都得到这项常数，因此前门差仍零点二八。两个前门均值变为零点三四和零点六二，真实则为零点二九和零点六七。错误公式仍能输出合法概率，数值合法并不验证排除条件。

<a id="causal-1-detail-57"></a>

### 10.12 题十二：二元结果的最弱界

题目：观察到 $`P(A=1,Y=1)=0.3`$、$`P(A=0,Y=1)=0.2`$，处理比例零点四，只假设一致性和二元结果，求 ATE 范围。

解答：处理潜在均值在零点三与零点九之间，因为未处理比例为零点六；对照潜在均值在零点二与零点六之间，因为处理比例为零点四。差的下界零点三减零点六为负零点三，上界零点九减零点二为零点七。要达到下界，把缺失的处理潜在结果设零、缺失的对照潜在结果设一；上界取反。没有额外耦合限制时，这些填法与观察数据相容，不能只给一个中点假装识别完成。

<a id="causal-1-detail-58"></a>

### 10.13 题十三：敏感性偏差怎样算

题目：在本章简单加性隐藏混杂模型中，观察差零点一二，隐藏因素影响结果零点四，两组隐藏因素比例差零点二五，净效应为多少？

解答：混杂偏差为零点四乘零点二五，即零点一，净效应为零点零二。若比例差的方向相反，偏差为负零点一，净效应则为零点二二。由此可见方向与幅度都需要实质依据。这个计算依赖加性恒定效应和残差条件均值零，并不适用于所有二元结果模型；在逻辑模型中不能直接拿 log 优势系数乘比例差冒充风险差偏差。

<a id="causal-1-detail-59"></a>

### 10.14 题十四：随机化后按实际处理分组

题目：随机邀请参加课程，但只有有空闲时间的人真正参加。为何比较实际参加者仍可能有偏？

解答：邀请变量随机不等于实际参加变量随机。空闲时间可能影响学习结果，也影响依从性，所以实际处理与潜在结果相关。按随机邀请组分析可识别邀请政策效应，在随访等条件满足时保留随机化基础；按实际参加者分析需要额外调整或工具变量等条件，且可能识别不同对象。不能用“数据来自试验”替代对具体分析变量的论证，尤其不应先筛掉不依从者再声称原独立性仍成立。

<a id="causal-1-detail-60"></a>

### 10.15 题十五：失访率相同能排除选择偏差吗

题目：两个随机分配组都失访两成，是否可以直接认为完整案例比较无偏？

解答：不能。处理组失访可能主要是预后差者，对照组失访主要是预后好者，人数相同但留存构成不同。完整案例条件化的是一个可能受处理与预后共同影响的节点。需要说明给定哪些历史信息后失访与潜在结果可交换，并检查留存支持，或进行有界与敏感性分析。只比较失访率是重要描述，但没有验证所有选择机制；数量平衡与原因平衡不是同一个命题。

<a id="causal-1-detail-61"></a>

### 10.16 题十六：随机拆分能否消除混杂

题目：把观察数据随机分成训练和测试，两份都很大，为什么测试中的处理差仍可能有偏？

解答：拆分随机的是进入哪份数据，不是接受什么处理。原来的共同原因仍影响每份样本内的处理与结果。例如高风险更常接受处理的机制，在两份里都会保留。拆分能帮助防止模型拟合与评价复用，但不会把条件不可交换变成可交换。交叉拟合也一样，它让每条得分使用其他折训练的辅助函数，降低估计依赖问题；识别条件仍须由设计与机制论证。

<a id="causal-1-detail-62"></a>

### 10.17 题十七：总体改变与模型改变

题目：原目标高低风险各半，后来改为高风险占八成，且两层效应分别零点二和零点零五。新的总体效应为何不同？

解答：旧效应零点一二五，新效应 $`0.8\times0.2+0.2\times0.05=0.17`$。即使两个条件结果模型一个参数都不变，外层目标分布变化也会改变边际效应。若源样本未覆盖某些目标层，还需额外外推；若给定风险后效应仍因地区或时代变化，单纯换权重也不足。迁移分析应把构成变化与条件响应变化分开，而不是把不同总体结果硬解释成估计器误差。

<a id="causal-1-detail-63"></a>

### 10.18 题十八：策略价值如何得到

题目：低风险处理与对照成功率零点九和零点八，高风险为零点四和零点三，目标各半。只给高风险处理的策略价值多少？

解答：策略在低风险选对照、高风险选处理，因此价值是 $`0.5\times0.8+0.5\times0.4=0.6`$。全不处理价值零点五五，全处理零点六五。若处理有成本，需把成功收益与成本放到明确的效用尺度后再选策略，不能只看风险差。在当前无成本成功率目标下全处理更好，但不代表存在资源约束时仍然如此。识别该策略只需其实际选择的层动作有支持。

<a id="causal-1-detail-64"></a>

### 10.19 题十九：条件优势比变化是否证明混杂

题目：处理随机化，加入预测结果很强的基线变量后逻辑回归处理系数改变，能否断言未调整模型有混杂？

解答：不能。优势比具有非可塌缩性，条件与边际参数可以不同，即使没有混杂。应明确目标是边际风险差、边际优势比还是条件模型系数，必要时用预测概率在共同目标总体上标准化再计算相应量。还需考虑模型设定和有限样本误差。随机化的设计独立性不会因一个回归系数改变而自动失效，也不能把任何系数变化都解释为控制了遗漏共同原因。

<a id="causal-1-detail-65"></a>

### 10.20 题二十：什么时候应该停止给唯一答案

题目：多个符合观察分布与领域知识的模型给出相反效应，增加预测容量后仍无法区分。合理的下一步是什么？

解答：承认识别范围，报告相容效应界或对明确假设的敏感性，并判断哪些新增测量、工具、自然实验或随机化能区分关键机制。应说明每条新信息预计排除什么模型，而不是只要求更多同类样本。若必须决策，可在不确定性下比较稳健策略，但不能把决策需求当作识别证明。诚实界定已知与未知，比输出一个由未声明外推决定的精确数值更能支持研究。

<a id="causal-1-detail-66"></a>

## 11. 方法比较与继续学习

<a id="causal-1-detail-67"></a>

### 11.1 潜在结果与结构模型怎样互补

潜在结果语言善于明确处理对比、目标总体和缺失的反事实；结构模型语言善于表达机制、干预替换和路径。二者在恰当假设下可以连接，但并非所有反事实独立性都能由一张观察 DAG 完全说明。应在需要时写出结构方程与外生依赖，避免让读者误以为画图已经给出所有跨世界假设。

后门调整适合有充分处理前信息的总效应问题，前门适合满足严格中介路径条件的特定隐藏混杂结构，随机化依靠设计提供独立性，部分识别则接受数据与假设只能限定一个集合。它们不是按复杂度排成从差到好的工具。选择应由问题与可信条件决定，不应为了使用某个流行估计器倒推一个方便但缺依据的图。

<a id="causal-1-detail-68"></a>

### 11.2 从本章到后续两章

下一章在已识别的单次处理目标上推导倾向加权、结果回归和双重稳健，讨论辅助模型误差、交叉拟合与区间。再下一章把一次处理扩展为依赖历史的多步策略，区分行为概率、轨迹支持和策略选择。每一步增加的估计技术都保留本章的设计与识别前提，不能让复杂实现掩盖这些条件。

本章三个实验分别验证不可识别反例、合法调整估计和前门条件边界；没有下载真实数据，没有外部模型，也没有用人工真值选择实际研究结论。正式分析仍需新的领域证据、合适样本与独立审查。资料保留可独立运行的全部代码与明确数值，让读者能把公式落实到一个完整过程，再知道哪些部分需要在新问题中重新论证。

<a id="causal-1-detail-69"></a>

### 11.3 可检验含义与不可检验部分的边界

一张因果图可能蕴含观察条件独立，可以用数据检查其兼容性。例如仅有 $`X\to A\to Y`$ 且噪声独立的模型蕴含给定处理后基线与结果独立；若观察上明显违背，就需要重新考虑图、测量和模型。但没有拒绝不等于证实，有限样本检验功效、变量离散化和模型设定都会影响判断。更重要的是，一些不同方向的图有完全相同的观察独立含义，因此即使知道整个观察分布也不能据此唯一确定方向。

干预或跨环境信息能够提供额外约束，不过要说明环境改变了哪些机制。若不同地区同时改变分配、结果测量和人群，简单的稳定相关性不能独立定位因果方向。机制不变性方法仍依赖对变化位置与潜在混杂的假设。可检验限制帮助排除某些模型，不可检验假设则需要实质依据与敏感性分析，两者相互补充，不能把一种验证扩大成全部验证。

自然直接效应和控制直接效应也应区分。后者固定中介为指定值，前者让中介取同一单位在另一处理世界中的值，涉及跨世界组合。即使总效应已由随机化识别，这些中介问题也未必自动识别。若以后研究机制分解，应先写潜在中介和结果的反事实定义，列出中介结果混杂与处理诱发混杂条件，再讨论公式，而不能只把总效应减去一个调整后系数。

- [Pearl：Causal Diagrams for Empirical Research](https://bayes.cs.ucla.edu/R218-B.pdf)：结构干预、后门和前门的原论文；本章例子为独立构造。
- [Hernán 与 Robins：Causal Inference: What If](https://miguelhernan.org/whatifbook)：作者公开的完整教材，供核对设计、可交换性与标准化条件。
