# 因果推断与效应估计

从干预问题与识别出发，学习调整、加权、双重稳健及交叉拟合。

**先修知识：** 条件期望、回归、抽样与交叉验证；不要求先学完学习理论。

## 章节目录

| 章节 | 核心内容 | 深入讲解入口 |
| --- | --- | --- |
| [第 1 章 潜在结果、因果图与效应识别](01-潜在结果因果图与效应识别.md) | 潜在结果与调整条件；碰撞选择、前门及非识别；工具变量的局部效应与目标总体 | [进入讲解](01-潜在结果因果图与效应识别.md#deep-dive-2) |
| [第 2 章 倾向加权、双重稳健与交叉拟合](02-倾向加权双重稳健与交叉拟合.md) | IPW 与增广得分；乘积余项、交叉拟合和区间条件；ATE、ATT 与重叠目标 | [进入讲解](02-倾向加权双重稳健与交叉拟合.md#deep-dive-3) |
| [第 3 章 序贯决策、重要性采样与离策略评价](03-序贯决策重要性采样与离策略评价.md) | 轨迹与逐决策 IS；序贯 DR、独立策略选择及置信界；边际化的收益与状态充分性 | [进入讲解](03-序贯决策重要性采样与离策略评价.md#deep-dive-2) |

## 阅读顺序

第 1 章先区分目标、识别与估计，完成调整、前门和非识别反例；第 2 章再推加权、增广得分、二阶余项与交叉拟合；第 3 章在[MDP、回报和策略基础](../../ReinforcementLearning/MDP/README.md)上，把支持条件与双重稳健扩展到序贯评价。先确认因果假设，再判断估计器性质，最后讨论标准误和策略选择。遇到公式先复算低维例子，再进入实验设计；不要把局部数值检查当成算法整体效果证明。
