# 因果推断与效应估计

从干预问题与识别出发，学习调整、加权、双重稳健及交叉拟合。

**先修知识：** 条件期望、回归、抽样与交叉验证；不要求先学完学习理论。

## 章节与学习目标

| 章节 | 核心内容 | 深入讲解入口 |
| --- | --- | --- |
| [第 1 章 潜在结果、因果图与效应识别](01-潜在结果因果图与效应识别.md) | 预测问题与干预问题；从三个条件推导调整公式；用因果图决定哪些变量可调 | [进入讲解](01-潜在结果因果图与效应识别.md#deep-dive-2) |
| [第 2 章 倾向加权、双重稳健与交叉拟合](02-倾向加权双重稳健与交叉拟合.md) | 两类辅助函数；从条件期望推导逆概率加权；双重稳健得分及其两次核验 | [进入讲解](02-倾向加权双重稳健与交叉拟合.md#deep-dive-3) |
| [第 3 章 序贯决策、重要性采样与离策略评价](03-序贯决策重要性采样与离策略评价.md) | 目标策略与日志策略；从轨迹密度比推到两种 IS；序贯双重稳健递推 | [进入讲解](03-序贯决策重要性采样与离策略评价.md#deep-dive-2) |

## 阅读顺序与验收

第 1 章先区分目标、识别与估计，完成调整、前门和非识别反例；第 2 章再推加权、增广得分、二阶余项与交叉拟合；第 3 章在[MDP、回报和策略基础](../../ReinforcementLearning/MDP/README.md)上，把支持条件与双重稳健扩展到序贯评价。先确认因果假设，再判断估计器性质，最后讨论标准误和策略选择。遇到公式先复算低维例子，再进入实验设计；不要把局部数值检查当成算法整体效果证明。

**完成要求：** 写出处理、结果、目标总体与因果图；推导调整及 AIPW；用错设与缺重叠模拟区分估计失败和识别失败。在已知小 MDP 枚举真值，核对 IS、PDIS 与 DR，并解释长时域覆盖及策略选择偏差。

作答后再阅读各章解析。能够独立说明一个失效条件，并设计一个可区分竞争解释的对照实验，才算完成本主题的进阶学习。
