## 1. 格点、舍入和饱和分别改变什么

<a id="quant-systems-2"></a>

### 1.1 仿射量化是一个完整映射

取尺度 $s>0$、整数零点 $z$ 与整数边界 $q_{\min},q_{\max}$，定义 $q(x)=\operatorname{clip}(\operatorname{round}(x/s)+z,q_{\min},q_{\max})$，再令 $\hat x=s(q-z)$。一个量化方案至少需要说明尺度如何得到、舍入遇到正好半格怎样处理、整数范围是否对称、裁剪发生在哪里。只说四位或八位不足以确定数值输出。

对称有符号方案有时采用负七到正七，留一个四位编码不用；另一方案可用负八到正七，正负最大值不对称。它们不应在模拟与真实格式之间偷偷互换。仿射零点让实数零可精确映射到整数 $z$，对填充和稀疏计算有意义；但零点本身也有范围及存储要求，不能任意用浮点均值替代一个合法整数。

逐张量尺度让全部权重共享格距，逐输出通道尺度为每行单独选择，分组尺度在连续坐标组内共享。粒度细能适应不同范围，却增加元数据、解包和可能的对齐开销。某个方案数值误差更小，不自动意味着在目标硬件上更快；格式与内核必须能高效利用该粒度。

<a id="quant-systems-3"></a>

### 1.2 舍入界是局部条件结论

若最近格点没有发生饱和，则 $|\hat x-x|\le s/2$，因为每个格点的Voronoi单元半径是半个格距。这个界不依赖输入分布，但依赖最近舍入和未裁剪条件。超过表示端点时，误差随超出距离增加，不再被半格界控制。以较小尺度降低大多数舍入误差，会同时提高尾部饱和风险，这正是校准要处理的取舍。

若输入分布有密度，某格内的误差未必均匀，也未必零均值。把量化误差近似成独立均匀噪声是一种额外模型，需要高分辨率与分布平滑等条件。权重本身是确定训练结果，误差与激活也可能相关；不能从半格界直接推出独立噪声方差 $s^2/12$ 对所有网络严格成立。

<a id="quant-systems-4"></a>

### 1.3 整数路径和反量化模拟

反量化模拟用浮点存储 $\hat W$ 再调用普通矩阵乘，主要验证近似函数。真实整数路径还需要处理零点差、乘积累加、缩放重标定和输出饱和。若减零点在窄整型中先溢出，再转成宽类型已经太晚；应在能容纳差值的类型中相减。若只检查最终浮点误差而忽略这些规则，校准目标可能与部署函数不一致。

对长度 $K$ 的点积，若去零点后的整数绝对值分别不超过 $A,B$，则累加绝对值不超过 $KAB$。可以据此保守选择累加宽度，另加偏置范围；边界不紧不妨碍它成为安全条件。具体硬件也可能采用浮点混合累加，必须按真实内核说明，不能从文件里存了整数推断所有中间量都是同样位宽。

## 2. 校准几何决定输出误差

<a id="quant-systems-6"></a>

### 2.1 从线性层推导二阶形式

令输入按行存为 $X\in\mathbb R^{n\times d}$，权重为 $W\in\mathbb R^{k\times d}$，输出 $XW^T$。量化误差 $E=\hat W-W$ 给输出误差 $XE^T$，平均平方Frobenius误差为

$$
\frac1n\|XE^T\|_F^2=\operatorname{tr}(EGE^T),\qquad G=X^TX/n.
$$

这里 $G$ 是未中心化二阶矩，不一定是协方差。只有输入均值为零时二者相同；存在非零均值时遗漏均值外积就会改变目标。若包含偏置误差，可把常数一并入输入并扩大权重矩阵，让同一公式自然包含它，而不是把偏置当作与输入无关的小常数忽略。

逐权重平方误差对应以单位矩阵为几何，只有当 $G$ 与单位矩阵成比例时，才与层输出目标一致。高能方向的误差受到更多惩罚，相关坐标的交叉项可使两个权重误差相互抵消或放大。这解释了为什么不看激活的独立舍入不一定是重构最优，但并不意味着所有利用激活的方法都能泛化。

<a id="deep-dive-2"></a>

<a id="quant-systems-7"></a>

### 2.2 相同权重误差的两个相反结果

取一行误差 $e=(a,-a)$。输入为 $(1,1)$ 时输出误差为零，输入为 $(1,-1)$ 时为 $2a$。权重误差范数不变，差异完全来自输入方向。若校准集只含第一种方向，许多参数误差在该集不可见；独立部署输入出现第二种方向时，原本的零校准误差就没有保护作用。

更一般地，若校准矩阵秩不足，则 $G$ 有零特征值，相应方向的误差没有被惩罚。加入阻尼 $\lambda I$ 使矩阵可逆，有助于数值稳定，也惩罚不可见方向，但这相当于改变目标，不是从数据中识别出了缺失方向。阻尼大小、分组与校准范围应在开发阶段固定，不能反复根据最终任务测试选择。

<a id="sec-2-1"></a>

<a id="quant-systems-8"></a>

### 2.3 单坐标约束下的最小补偿

为说明二阶补偿原理，考虑一行权重改变量 $\delta$，最小化 $\delta^T G\delta$，约束第 $j$ 个坐标必须改变为 $\delta_j=d$。假设 $G$ 正定，引入乘子，得到 $2G\delta+\lambda e_j=0$。代入坐标约束可得

$$
\delta^*=\frac{dG^{-1}e_j}{(G^{-1})_{jj}},\qquad
\Delta L=\frac{d^2}{(G^{-1})_{jj}}.
$$

该公式中第 $j$ 坐标确实是 $d$，其他坐标被允许自由补偿。若定义损失带二分之一或Hessian带两倍，代价中的常数随之改变；补偿方向不因此变化。完整逐步量化还要冻结已量化坐标、更新剩余自由子空间并管理顺序，不能每次都在全部坐标上套同一个逆矩阵，重新改动已经固定的格点。

GPTQ类方法与此类局部重构和二阶信息有关，但本章实验只核对一个约束的解析身份，没有实现完整GPTQ批处理、分块补偿和模型转换。方法比较应区分原理验证和工程复现。高质量局部推导不等于已经得到了论文规模的压缩系统，也不能直接引用论文速度作为当前浮点模拟结果。

## 3. 从层误差到网络与任务误差

<a id="quant-systems-10"></a>

### 3.1 多层误差的递推界

令网络层为 $h_l=\sigma_l(W_lh_{l-1})$，近似层为 $\hat h_l=\sigma_l(\hat W_l\hat h_{l-1})$。若激活是 $L_l$-Lipschitz，则

$$
\|\hat h_l-h_l\|\le L_l\left(\|\hat W_l\|\|\hat h_{l-1}-h_{l-1}\|+\|E_l\|\|h_{l-1}\|\right).
$$

逐层展开得到每层误差被后续算子范数放大的和。这是一个通常较松的最坏情形界，显示误差传播并非各层MSE直接相加。残差连接、归一化与实际输入可能明显改变放大程度，应以真实模型结构分析，不能只把各层误差独立排序就决定端到端质量。

<a id="quant-systems-11"></a>

### 3.2 分类间隔给一个可判定条件

若原模型某样本最大logit与次大logit之差为 $m>0$，而每个logit绝对误差不超过 $\varepsilon$，则当 $m>2\varepsilon$ 时类别不变。证明是赢家最多下降 $\varepsilon$、对手最多上升 $\varepsilon$，剩余差仍正。该结论保护原预测是否改变，不保证原预测本来正确，也不说明概率校准、对数损失或其他功能保持。

靠近决策边界的样本更容易因小误差翻转，但错误翻转也可能把原来的错预测改对。因此量化后准确率偶尔提高，不必解释成量化发现了更优语义；需要固定测试与重复研究，区分偶然抵消、正则效果和真正稳健改进。报告原模型与量化模型的共同正确、共同错误和相互翻转，比单个准确率更能解释变化。

<a id="quant-systems-12"></a>

### 3.3 校准权限与代表性

无标签校准可以访问目标输入分布来选择尺度，但不意味着它没有使用额外信息。要记录输入来源、数量、长度与时间，并与训练及最终测试区分。层输出重构不需要标签，任务准确率选参则需要标签开发集；两者选择规则不同。测试标签不能参与任何尺度选择，也不应一边看到测试结果一边扩展候选集合。

同一个量化器在短输入与长输入、常见与罕见来源上可能遇到不同激活范围。只用平均重构误差会掩盖尾部饱和；应同时记录裁剪比例、分位误差和困难子组。若部署分布发生变化，重新校准是一个新版本及新信息协议，不能把使用新数据后的效果当作原校准方案天然具备的泛化保证。

## 4. 权重、激活和缓存的容量

<a id="quant-systems-14"></a>

### 4.1 元数据让有效位宽高于名义位宽

$P$ 个 $b$ 位权重的理想原始字节为 $Pb/8$。若每 $G$ 个权重保存一份 $s_b$ 字节尺度和 $z_b$ 字节零点，则额外元数据约为 $P(s_b+z_b)/G$，还未包含不足一组的填充、对齐、未量化层和格式索引。有效每权重位数为 $b+8(s_b+z_b)/G$。因此分组越小越不能忽略元数据占比。

例如四位权重、每三十二个共享两字节尺度且没有额外零点，理想有效位宽为四点五位，而不是四位。与十六位相比容量比例是十六除四点五，约三点五六倍，不是四倍。若少量层保留高精度、还保存结构和布局，实际比例会进一步改变；这里仍是紧凑存储预算，不能代替内存分配测量。

<a id="quant-systems-15"></a>

### 4.2 KV缓存是另一条增长轴

对 $L$ 层、每请求缓存长度 $T$、批量 $B$、KV头数 $h_{kv}$、每头维度 $d_h$、每元素 $s$ 字节，理想K与V总容量为 $2LBTh_{kv}d_hs$。查询头数不应机械代入KV头数；分组查询注意力共享KV时，两者可以不同。分页碎片、预留块和量化尺度要另外加入。

只压缩权重不能改变上述随并发与上下文线性增长的项。KV量化还可能影响注意力的点积与加权求和，误差发生位置不同于静态权重。评价应同时看长序列、不同上下文与独立任务，不能因为权重量化近似无损就推断缓存用同一位宽也安全。缓存管理策略还会改变实际同时存活量。

## 5. 算术强度与速度证据

<a id="quant-systems-17"></a>

### 5.1 一个有明确口径的roofline模型

对单个矩阵层，近似运算量为 $2Bdk$ FLOP，若每次至少读取 $dk$ 个权重，单请求小批时权重读取可能主导，理想算术强度约随批量增长。最简时间下界为计算量除峰值算力与搬运量除有效带宽两者最大；它假设可实现这些资源上限，不包括启动、解包和资源竞争，因此是理想下界，不是预测保证。

权重量化降低读取字节，但若原算子主要受计算或其他阶段限制，端到端收益有限；若反量化开销很大，甚至可能变慢。批处理提高权重复用，可能改变瓶颈；更长上下文增加缓存读取，又形成不同主导项。应分别说明prefill、decode、批量与上下文，而不是把所有服务负载压缩成单一每秒token数。

<a id="quant-systems-18"></a>

### 5.2 Amdahl约束与延迟口径

若原时间中只有比例 $f$ 可被某优化加速 $r$ 倍，其他完全不变，则理想总加速为 $1/(1-f+f/r)$。当可优化部分仅一半，即使局部无限快总加速也不超过二。实际量化还可能增加转换，因此需在式子外加入新增时间。文件变小是存储结论，不等于端到端可优化比例为一。

吞吐、首token延迟、逐token间隔和尾延迟分别受到批处理、排队与缓存影响。增加并发可能提升吞吐却让单个请求等待更久。性能验收必须固定到达负载或说明饱和测试口径，不能拿不同请求条件的数字推导用户体验改善。本章没有测服务性能，下面的时间数字仅是显式参数的代数模型。

w=np.array([.12,-.27,.68]);scale=.1

## 7. 实验二：单约束二阶补偿

```python
import numpy as np
G=np.array([[1.,.9],[.9,1.]])
inv=np.linalg.inv(G);j=0;d=.2
optimal=d*inv[:,j]/inv[j,j]
naive=np.array([d,0.])
assert np.allclose(optimal,[.2,-.18])
assert np.isclose(optimal@G@optimal,d*d/inv[j,j])
assert optimal@G@optimal<naive@G@naive
# 直接枚举剩余自由坐标验证同一个约束问题。
grid=np.linspace(-.5,.5,10001)
loss=G[0,0]*d*d+2*d*G[0,1]*grid+G[1,1]*grid**2
assert abs(grid[loss.argmin()]-optimal[1])<1e-10
# 在相关性反向的独立输入分布上，原补偿可能更差。
Gshift=np.array([[1.,-.9],[-.9,1.]])
assert optimal@Gshift@optimal>naive@Gshift@naive
print('compensation',optimal,'calibration cost naive/optimal',naive@G@naive,optimal@G@optimal)
print('shifted cost naive/optimal',naive@Gshift@naive,optimal@Gshift@optimal)
```

补偿在指定校准几何上严格降低局部二次损失，在反向相关的新分布上反而增大。这不是对二阶方法的普遍否定，而是对“校准重构最优必然部署更好”的反例。改变输入分布后，优化目标本来就变了；若要保护新分布，需额外覆盖、稳健目标或新校准信息。

## 8. 实验三：完整训练、无标签校准和独立测试

```python
import copy
import numpy as np
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1);torch.set_default_dtype(torch.float64)
def data(n,seed):
    g=torch.Generator().manual_seed(seed)
    x=torch.randn(n,6,generator=g)
    scores=torch.stack([x[:,0]+.4*x[:,2],-x[:,0]+.5*x[:,1],-x[:,1]-.3*x[:,2]],1)
    y=scores.argmax(1)
    x=x*torch.tensor([1.,1.,1.,4.,.2,2.])
    return x,y
train,yt=data(1200,671);cal,_=data(500,672);test,ys=data(3000,673)
torch.manual_seed(674)
model=nn.Sequential(nn.Linear(6,24),nn.ReLU(),nn.Linear(24,3))
opt=torch.optim.Adam(model.parameters(),lr=.015)
rng=torch.Generator().manual_seed(675)
for _ in range(700):
    ids=torch.randint(len(train),(128,),generator=rng)
    loss=F.cross_entropy(model(train[ids]),yt[ids])
    opt.zero_grad();loss.backward();opt.step()
model.eval()
def quantize(W,per_row,ratio):
    bound=W.abs().amax(1,keepdim=True) if per_row else W.abs().max()
    scale=(bound*ratio/7).clamp_min(1e-12)
    return (W/scale).round().clamp(-7,7)*scale
naive=copy.deepcopy(model);calibrated=copy.deepcopy(model)
choices=[]
with torch.no_grad():
    for layer in [0,2]:naive[layer].weight.copy_(quantize(model[layer].weight,False,1.))
    # 每层参考输入来自原模型；没有使用任何校准标签或测试数据。
    for layer in [0,2]:
        x=cal if layer==0 else model[:2](cal)
        W=model[layer].weight
        candidates=[]
        for row in [False,True]:
            for ratio in [1.,.9,.75,.5]:
                q=quantize(W,row,ratio)
                objective=float((x@(q-W).T).square().mean())
                candidates.append((objective,row,ratio,q))
        best=min(candidates,key=lambda a:a[0])
        calibrated[layer].weight.copy_(best[3]);choices.append(best[:3])
    predictions=[m(test) for m in [model,naive,calibrated]]
    accuracy=[float((a.argmax(1)==ys).double().mean()) for a in predictions]
    nll=[float(F.cross_entropy(a,ys)) for a in predictions]
    output_mse=[float((a-predictions[0]).square().mean()) for a in predictions]
assert accuracy[0]>.94 and np.isfinite(accuracy+nll+output_mse).all()
print('fixed 700 updates; selected on unlabeled calibration layer reconstruction',choices)
print('float/per-tensor/calibrated accuracy',accuracy)
print('NLL',nll,'logit reconstruction MSE',output_mse)
print('no test-based selection; floating dequantization, not low-bit kernel')
```

训练采用固定七百次更新，没有根据测试挑模型。每层候选共享预先固定的无标签校准输入，通过原模型层输出重构选择；后层校准使用原模型的输入，而非已经量化的前缀，因此还存在跨层分布差异。完整独立测试正是为了检查局部重构之后的整体行为，不预先断言校准方案在所有指标都更好。

## 11. 二十道进阶练习与详细答案

<a id="quant-systems-25"></a>

### 11.1 四位是否足以确定一个量化器

不够。还需要整数范围、尺度、零点、舍入规则、饱和与分组布局。负七到正七和负八到正七有不同端点，即使都用四位存储也不是同一映射。模拟、导出格式与实际内核必须一致，否则数值验证针对的是另一函数。文件位数只是系统定义的一部分。

<a id="quant-systems-26"></a>

### 11.2 半格误差界何时失效

最近格舍入且不饱和时才有尺度一半的界。超范围裁剪后，误差可以远大于半格；若使用截断舍入，局部界和偏差也不同。应分别统计舍入与饱和，不把小尺度一定更精确当作普遍结论。尾部会改变整体取舍。

<a id="quant-systems-27"></a>

### 11.3 零点为什么要合法整数

它代表实数零对应的编码，应位于指定整数范围。填充、稀疏与零值运算依赖这个语义。任意浮点均值不能直接代替整数零点，导出时的取整和边界也要明确。若零点处理与内核不符，误差不只是尺度略变，而是整体偏移。

<a id="quant-systems-28"></a>

### 11.4 为什么必须先转宽类型再减零点

窄无符号或有符号整数相减可能先发生溢出，随后转宽无法恢复原值。应在能容纳差值的类型中相减，再乘与累加。实数模拟不会自动暴露这一错误。长度与最大整数乘积给出保守累加界，偏置范围也应加入。

<a id="quant-systems-29"></a>

### 11.5 误差均匀独立是否定理

不是。它是特定高分辨率和平滑分布条件下的近似模型，确定权重、尾部饱和和激活相关都可能破坏。半格界只给局部幅度，不给零均值或独立性。应使用实际输入几何和独立测试，不用一个方便噪声模型替代数据证据。

<a id="quant-systems-30"></a>

### 11.6 为什么 G不是总叫协方差

G是输入未中心化二阶矩，等于协方差加均值外积。只有均值零才相同。忽略非零均值会改变输出重构目标，偏置误差还可通过常数特征纳入。先明确矩阵定义与轴，再讨论算法使用了什么统计。

<a id="quant-systems-31"></a>

### 11.7 权重 MSE小为何输出可能大

输出误差受输入高能方向与相关结构放大。相同误差向量在共线输入可抵消，在反向输入可叠加。逐权重误差对应单位几何，不普遍等于层输出目标。部署分布不同，校准优势也可能反转，第二实验给出明确例子。

<a id="quant-systems-32"></a>

### 11.8 二阶补偿是否已实现 GPTQ

没有。本章只求单坐标约束下允许其他坐标自由变化的解析问题。完整方法还要处理顺序、已冻结坐标、分块、阻尼和工程布局。原理核验不等于论文规模复现，更不能引用论文速度作为当前浮点模拟的实测结果。

<a id="quant-systems-33"></a>

### 11.9 阻尼是否补回缺失数据

不是。加单位阵改善正定与稳定，同时改变误差惩罚，不能从中获得校准从未观察的方向信息。阻尼是结构选择，需要开发验证与敏感性。若部署方向变化，应明确额外覆盖或稳健假设，不把可逆矩阵误当可识别模型。

<a id="quant-systems-34"></a>

### 11.10 校准无标签是否没有额外权限

仍使用了输入分布信息，来源、数量和时间都应记录。用标签任务分数选尺度又是更强开发权限。本章只按无标签层重构选择，独立测试不参与。公平比较需统一可用信息，不只统一模型权重。

<a id="quant-systems-35"></a>

### 11.11 校准重构更好为何准确率更差

重构目标与分类边界不同，平均 logit误差下降仍可能让少数小间隔样本翻转。不同层误差还会相互传播。本章校准 logit MSE较低却准确率更低，正是需要保留的负结果。它不否定校准，只否定局部指标自动保证任务改善。

<a id="quant-systems-36"></a>

### 11.12 分类间隔界保证什么

它在每个 logit误差受统一界控制且间隔超过两倍界时，保证原模型预测类别不变。原模型可能本来就错，也不保证概率校准或 NLL保持。不要把保持类别与保持全部模型能力混为一谈，评价应对应实际任务。

<a id="quant-systems-37"></a>

### 11.13 后层为何可能见到不同激活

本章候选用原模型前缀生成后层校准输入，部署时前缀已量化，输入分布改变。逐层重构独立最优不必端到端最优。可以研究量化前缀校准或联合重构，但要计额外成本与目标变化，不把现有代码说成已经实现。

<a id="quant-systems-38"></a>

### 11.14 权重量化是否减少所有内存

不。KV缓存、激活、工作区和元数据可能继续主导，长上下文与并发还会放大缓存。四位权重只是某一项存储，实际峰值需按同时存活张量和格式测量。只看文件大小无法推断部署是否能装下。

<a id="quant-systems-39"></a>

### 11.15 有效位宽为何超过名义位宽

分组尺度、零点、填充和未量化层都增加实际容量。本章四位加每三十二权重两字节尺度已是四点五位，未计其他开销。组越小元数据比例越高。数值粒度收益应与存储、解包和内核支持一起评价。

<a id="quant-systems-40"></a>

### 11.16 缓存公式为何用 KV头数

分组查询注意力可能让多个查询头共享键值，查询头数不等于 KV头数。容量由实际保存的 K与 V张量决定，还要加分页与量化元数据。机械代入查询头数会高估或错估。先画实际张量形状，比记一个无条件公式可靠。

<a id="quant-systems-41"></a>

### 11.17 文件缩小是否必然更快

不。瓶颈可能是计算、缓存读取、启动或排队，反量化和布局转换还会增加成本。真正收益需要支持该格式的内核与目标负载测量。浮点反量化模拟只验证近似函数，不证明低位执行速度。

<a id="quant-systems-42"></a>

### 11.18 局部四倍快为何总共仅一点六倍

若仅一半原时间能被优化，另一半保持不变，Amdahl公式给出一点六倍。新增转换还会降低它。局部内核、整层与端到端服务是不同分母，不能把最有利局部数值直接写成用户体验提升。

<a id="quant-systems-43"></a>

### 11.19 吞吐提高是否延迟下降

不一定。更大批次提高复用与吞吐，却可能增加排队和单请求等待。首 token、逐 token和尾延迟也不同。应固定负载、上下文和并发，明确测量口径。本章没有测服务性能，不把代数下界冒充本机速度。

<a id="quant-systems-44"></a>

### 11.20 一个可靠 PTQ报告需要什么

量化映射、粒度、校准权限、候选与选择规则、真实存储格式、内核和负载都需明确。质量需独立测试并保留负结果，系统需区分容量估算与实际测量。原理推导、浮点模拟和生产执行是三类证据，各自有范围。

<a id="quant-systems-45"></a>

## 12. 量化误差的进一步数学结构

<a id="quant-systems-46"></a>

### 12.1 裁剪与舍入应分开分析

可以先把输入裁到可表示区间，再做最近格点舍入。总误差由尾部裁剪差和区间内格点差组成，但平方误差含交叉项，不能在没有额外条件时简单把两项方差独立相加。真实分布接近边界时，偏差方向尤其重要。

较宽区间减少饱和却增大格距，较窄区间降低主体舍入误差却牺牲尾部。最优范围依赖输入分布和下游敏感性，不一定是最大绝对值，也不一定是某个固定分位数。校准搜索应预先定义目标与预算，避免测试调参。

<a id="quant-systems-47"></a>

### 12.2 误差相关与二阶矩

权重误差是训练权重与格点之间的确定差，激活由数据和前层决定。它们不天然独立。层输出误差二次型精确保留相关方向，因此比把每个误差当独立白噪声更能解释实际重构。若同时量化输入，乘积还包含权重误差与输入误差的交叉项。

设输入和权重分别改变，输出差可以展开成原输入乘权重误差、输入误差乘原权重，以及两误差乘积。低精度时最后项未必可忽略，多层还会继续传播。用一阶近似时应说明适用尺度，并以完整独立测试检验，而不是把所有交叉项都默认很小。

<a id="quant-systems-48"></a>

### 12.3 多坐标约束的补偿

把“由块结构决定”写成可计算结论。设 $C\in\mathbb R^{d\times r}$ 的列选择需要固定的 $r$ 个不同坐标，要求 $C^T\delta=b$；$b$ 是这些坐标相对于原权重的改变量。假设 $G\succ0$，考虑最小化 $\delta^TG\delta$。拉格朗日驻点满足 $2G\delta+C\lambda=0$，所以

$$
\delta=-\tfrac12G^{-1}C\lambda,\qquad
C^TG^{-1}C\lambda=-2b.
$$

由于 $C$ 满列秩，$M=C^TG^{-1}C\succ0$。因此唯一最优解及其代价为

$$
\delta^*=G^{-1}CM^{-1}b,\qquad
L^*=b^TM^{-1}b.
$$

这不仅是必要驻点：任意另一可行解可写成 $\delta^*+h$，其中 $C^Th=0$。最优解满足 $G\delta^*=CM^{-1}b$，故交叉项 $h^TG\delta^*=0$，总损失恰好增加 $h^TGh\ge0$，从而完成全局最优性证明。实际计算应解线性方程，公式中的逆矩阵主要表达结构，不要求显式求逆。

也可以按固定集合 $S$ 与自由集合 $F$ 分块。固定 $\delta_S=b$ 后，对自由坐标求导可得

$$
\delta_F^*=-G_{FF}^{-1}G_{FS}b,\qquad
L^*=b^T\bigl(G_{SS}-G_{SF}G_{FF}^{-1}G_{FS}\bigr)b.
$$

括号内是 Schur 补，等于 $[(G^{-1})_{SS}]^{-1}$。注意它一般不等于 $G_{SS}$：允许剩余坐标补偿，会降低固定误差的代价。若固定全部坐标，自由集合为空，就直接回到 $b^TGb$，不能再套含有非空自由块的写法。

**三坐标手算。** 取 $G=\begin{pmatrix}2&1&0\\1&2&1\\0&1&2\end{pmatrix}$，固定第一、三坐标改变量分别为 $1,-1$。自由坐标为第二坐标，其最优改变量是 $-(1-1)/2=0$，总代价为 $4$。若两个固定改变量都为 $1$，则第二坐标应为 $-(1+1)/2=-1$，损失为 $2$；把自由坐标保持为零的损失却为 $4$。差异来自相关方向的补偿，并非格点精度发生变化。

**逐步冻结为什么要更新几何。** 若剩余自由变量的逆几何为 $H$，下一步固定其中的坐标 $j$，则新自由集合 $R$ 上需要的逆块满足

$$
(G_{RR})^{-1}=H_{RR}-\frac{H_{Rj}H_{jR}}{H_{jj}}.
$$

这是块求逆恒等式。它解释了为何不能仅删除原逆矩阵的一行一列，也不能继续允许已经固定的坐标参与补偿。上述结果只解决“给定格点改变量”的连续子问题；格点本身如何共同选择仍是离散优化，顺序舍入不因此获得全局最优保证。阻尼后应把所有式子的 $G$ 一致替换成 $G+\lambda I$，并明确优化目标已经改变。

<a id="quant-systems-49"></a>

### 12.4 几何估计的有限样本误差

校准二阶矩来自有限输入，可能对罕见高能方向估计不足。更多样本通常提供更多信息，却不保证覆盖所有部署变化。不同长度、来源和条件应预设分层，不能只随机抽一小组常见输入就宣称代表所有任务。

阻尼、收缩和分组降低估计不稳定，同时引入偏好。它们可以有用，但需要记录。若真实几何未知，可以比较校准子集稳定性与独立重构，观察选择是否依赖少数异常样本。一个可逆矩阵不等于可靠总体几何。

<a id="quant-systems-50"></a>

## 13. 三类量化路线的准确区别

<a id="quant-systems-51"></a>

### 13.1 二阶局部重构

GPTQ类路线利用校准激活和近似二阶信息安排权重舍入与补偿，核心目标与本章二次几何相关。完整算法还有分块与高效实现设计。本章只验证最小子问题，没有执行大语言模型转换，也没有测对应内核。引用方法时应把原论文与当前完成范围分开。

局部层输出目标不需要标签，适合某些数据权限，但不能自动保持所有生成、推理或概率校准能力。不同任务对同样层误差有不同敏感性。应保留整体评价，尤其边界、长上下文与稀有来源，不能只靠重构分数宣布无损。

<a id="quant-systems-52"></a>

### 13.2 输入输出尺度重分配

对正可逆对角矩阵 D，线性层恒等式可以写成输入乘 D的逆、权重乘 D对应方向后，浮点输出保持不变。这个恒等变换允许在激活与权重范围之间转移难度，量化后误差则受新格点影响。变换前后浮点等价，不代表量化后也完全等价。

实现要核对矩阵存储约定与相邻层融合位置，不能只把某列权重放大而忘记输入逆缩放。若跨非线性或归一化移动尺度，是否仍成立需要相应结构条件。SmoothQuant路线提供一个有用研究方向，但具体变换应按模型结构与原论文核对，不把任意缩放都称同一方法。

<a id="quant-systems-53"></a>

### 13.3 激活感知的权重保护

某些权重方向因激活幅度与任务敏感性更值得保护，可以通过尺度搜索等设计改变舍入误差分配。AWQ类研究与这一动机相关，但高激活幅度不是所有任务敏感性的完整描述，相关方向与多层传播仍重要。不能把一项启发式统计当成全局最优证明。

比较时应固定校准数据、粒度、位宽与内核支持，记录额外尺度和搜索。方法名称并不自动决定速度和精度，工程布局与负载会改变实际收益。原论文报告的硬件结果是其设置下证据，不是当前浮点模拟的本地测试。

<a id="quant-systems-54"></a>

### 13.4 PTQ与 QAT

训练后量化在固定已训练模型上选择近似格式，量化感知训练则在训练或微调中引入伪量化影响。后者可能使用标签、梯度和更多数据，不能与无标签 PTQ不加说明地比较。额外训练预算与信息权限都应计入。

真实舍入映射几乎处处局部常数，普通导数不能直接提供有用训练信号，常见直通估计采用替代梯度。它是有意近似，不是精确求导，也不保证优化原离散目标。训练伪量化与部署格式仍需一致，尤其尺度、饱和和零点语义。

<a id="quant-systems-55"></a>

## 14. 从局部校准到部署风险的可检验条件

<a id="quant-systems-56"></a>

### 14.1 二阶矩迁移界及其证明

设某层权重误差为 E，校准和部署输入二阶矩分别为 Gc 与 Gt。二者都不减去均值，且必须按相同输入坐标和预处理定义。局部平均平方输出误差分别为 tr(E Gc Eᵀ) 和 tr(E Gt Eᵀ)。两者差为 tr(E ΔG Eᵀ)，其中 ΔG=Gt−Gc。把 E 的每一行记为 eᵢ，则差为各行 eᵢᵀΔG eᵢ之和。

对称矩阵的谱范数控制每个二次型的绝对值，所以绝对差不超过 ||ΔG||op Σᵢ||eᵢ||²，也就是 ||ΔG||op ||E||F²。推导只需有限二阶矩，既不要求输入服从高斯，也不要求舍入误差独立。这个界把输入分布变化与误差幅度分开，可以说明为什么在相同权重误差下，校准来源的改变会影响部署误差。

它并不是直接可用的任务风险证书。真实部署二阶矩通常未知，网络更深层输入还会随前面量化改变；谱范数界可能很松，且平方重构误差仍不是分类准确率。它的价值是明确额外假设，而不是把一个局部不等式包装成端到端无损承诺。

更强的相对条件是 Gt≼cGc，即 cGc−Gt 为半正定矩阵。此时对所有 E 都有部署误差不超过 c 倍校准误差，因为每一行对应的二次型都受该矩阵序控制。若部署分布在校准零空间中含有正能量，则任何有限 c 都无法满足这个条件。因此仅有校准误差很小，不能排除新方向上的任意大失真；补一个极小阻尼也不会使真实输入自动满足覆盖条件。

<a id="quant-systems-57"></a>

### 14.2 校准前缀选择改变了估计目标

本章分类器实验使用原浮点网络产生每层校准输入，然后独立选择该层的量化方案。这估计的是在原模型激活分布上的单层重构。实际部署到后一层时，它收到的是前面已经量化的激活。因此研究者需要区分原分布上的近似与量化前缀诱导分布上的近似，二者可能有不同最优尺度。

另一种流程是逐层量化，把已经转换的前缀固定，用它生成下一层输入。此时目标也必须写清：教师输出可以是原模型在原输入上的层激活，也可以是原浮点层作用在当前量化输入上的输出。前者试图补偿此前累计误差，后者只近似当前算子，数值上不是同一个监督信号。

逐层匹配输入能减少一种分布不一致，但仍不保证全局最优，因为局部输出的各方向对后续任务的重要性不同，早期决策也可能限制后续可行解。若用整网输出再选择配置，便增加了端到端搜索预算；若还使用标签，则数据权限发生变化。正确比较应明确教师、前缀、搜索空间和预算，不能只用“校准过”概括所有流程。

<a id="quant-systems-58"></a>

### 14.3 为什么 logit 重构会误导

考虑三分类 logit 向量 z，把同一常数 c 加到全部分量。softmax 分子与分母都乘 exp(c)，所以类别概率和预测类别完全不变，但 logit 平方误差会增加三个 c²。由此可知，原始 logit 均方误差会惩罚某些对分类概率无影响的方向，不能天然视作任务距离。

相反，在两个最大 logit 很接近的样本上，仅很小的相对扰动就可改变类别。若一种方案把很多容易样本的共同偏移修得很准，却在少数边界样本改变相对次序，整体均方误差下降而准确率仍可能下降。实验三出现重构更好、准确率更差，正与这种目标差异相容；但仅有汇总数值还不能断言具体机制已经被证明。

可以进一步记录逐样本浮点间隔、两个模型的类别是否改变、改变是否由对变错，以及去除每个样本 logit 均值后的重构误差。分析要预先规定分组，避免看到结果后不断挑有利切片。去均值误差减少共同平移影响，却仍不是正确率的充分统计量，也不能代替概率损失。

<a id="quant-systems-59"></a>

### 14.4 负对数似然和置信度的边界

对真实标签 y，负对数似然为 −z_y+log Σⱼexp(zⱼ)。其对 z 的梯度是预测概率向量减去标签独热向量。每个分量都依赖当前概率，说明相同 logit 扰动在不同样本上会有不同损失影响。准确率只看最大分量，似然还关心正确类获得多少概率，因此两项指标可以朝不同方向变化。

NLL 的评价需要标签，不能在“无标签校准”流程里悄悄用它挑量化尺度。报告独立带标签测试上的 NLL 是合理的，但一旦反复据此选择超参数，这个集合就已经参与模型选择。若需要概率温度校准，应另设有权限的验证集，并把额外参数和数据使用计入方法。

本章三种模型的 NLL 变化与准确率都说明任务性能存在损失；量化校准方法相对朴素方法的 logit 重构优势没有转化为这些任务指标优势。这个结论只属于给定人工任务与固定训练结果，不能外推为任何校准都无效，也不能删除不利种子后再报告改进。

<a id="quant-systems-60"></a>

## 15. 真正的整数执行需要哪些契约

<a id="quant-systems-61"></a>

### 15.1 单层重定标的完整代数

设输入实数近似 sx(qx−zx)，某输出通道权重近似 sw(qw−zw)，则点积近似 sx sw Σⱼ(qxⱼ−zx)(qwⱼ−zw)。其中求和是整数累加，尺度乘积可以放到累加之后。若还要输出到下一个整数格点 sy(qy−zy)，就需要对累加结果乘 sx sw/sy，加上按正确单位表示的偏置，再舍入、加输出零点和饱和。

这些步骤的先后顺序不能随意交换。偏置若存于累加整数单位，常见对应尺度是 sx sw；若偏置保持浮点，则融合边界不同。输出舍入与饱和也会产生新的误差，所以只核对权重反量化后矩阵乘法，尚未核对整数整层执行。推理框架的实际约定可能包括固定点乘子、移位与特定舍入规则，需要逐项对照。

对称权重令 zw=0 可以减少部分补偿；若权重零点非零，展开点积会出现输入和与权重和等修正项。数学上仍然成立，但算子是否高效支持这些项是工程问题。格式选择既影响近似误差，也影响可用内核，不能只比较格点数量。

<a id="quant-systems-62"></a>

### 15.2 逐通道尺度和逐组尺度的区别

若一个输出通道使用单独权重尺度 swᵢ，而输入共享尺度 sx，则该通道整个累加结果可乘同一个 sx swᵢ。这适合在归约结束后统一重定标。若同一输出通道的输入维度被拆成多个不同尺度的组，则各组部分和要按自己的尺度合并；把所有原始整数乘积先混在一起再乘一个尺度一般不正确。

这并不表示逐组量化不能高效实现，而是它需要支持该布局的实际执行方案，例如分组反量化或相应融合。教学中的浮点还原权重可以表达数值语义，却隐藏了解包、组边界、尺度读取和寄存器使用。若只测普通浮点矩阵乘法，就不能据此宣称已验证分组整数内核效率。

同样，逐 token 激活尺度通常意味着不同输入行有不同 sx，逐输入通道尺度则可能进入归约维度。二者粒度看似都更细，代数位置却不同。讨论某硬件支持“通道量化”时，还应明确是权重输出通道、激活输入通道还是其他轴，避免把一个轴的支持误当全部情况。

<a id="quant-systems-63"></a>

### 15.3 宽累加的保守范围

假设去零点后的输入整数绝对值不超过 A，权重绝对值不超过 B，归约长度 K。由三角不等式，累加绝对值至多 KAB。这是保守最坏界，真实数据可能有抵消，但不能依赖抵消保证不溢出。若偏置也在累加单位中，还必须加上偏置整数幅度，再与累加类型范围比较。

实际实现可能用更宽部分和、分块归约或硬件规定的饱和语义，这些都属于算子契约。溢出若按补码回绕，会使极大正数变成负值，并非普通小舍入误差。先在窄类型里相减，再提升类型，也可能已经丢失正确值。因此实验一在减零点之前提升类型，是数学与实现一致的必要细节。

最坏界不能直接预测实际准确率，也不证明每个满足界的内核都正确。它适合发现明显不安全的尺寸组合，然后再用边界向量核对真实实现。随机普通输入很少触及极限，故仅靠随机测试通过不足以检查累加边界。

<a id="quant-systems-64"></a>

### 15.4 训练模拟与部署一致性清单

要检验一种伪量化训练是否对应部署，先固定整数上下界、尺度来源、零点、舍入方式和饱和顺序，再固定每个张量的轴、组大小与尾组处理。然后对同一个小输入比较反量化基准、整数参考算子和目标后端输出。允许误差应由已知舍入差异解释，不应遇到差异就任意放宽容差。

若采用随机舍入，比较应包含随机数协议，单次逐元素相等通常不是目标；若部署是确定舍入，训练却随机舍入，则二者优化目标不完全一致。训练中估计尺度的移动平均也要在部署时冻结，否则线上批次会改变函数。某些动态量化确实运行时估计尺度，但那是另一种明确的算子定义。

本章实际完成的是权重舍入后恢复到浮点的数值模拟，没有实现上述全部整数契约。它足以检验重构与任务指标的关系，也足以展示分组尺度的数学作用；它不能给出实际硬件速度、带宽占用或溢出行为的结论。完成程度的准确描述是实验可信性的一部分。

<a id="quant-systems-65"></a>

## 16. 激活、缓存与长序列的误差传播

<a id="quant-systems-66"></a>

### 16.1 激活离群与尺度折中

当某个通道偶尔产生很大激活，全张量最大绝对值尺度会被该值决定，使常见小值只使用少数格点。缩小范围可以增加中心区域的分辨率，同时让尾部发生饱和。哪种方案更好取决于尾部出现频率、数值方向和后续任务敏感性，不取决于“离群值看上去不好”这一视觉印象。

可预先比较不同来源、长度和通道的分位数及饱和率，但这些统计必须与尺度选择集分开评价。很少发生的输入也可能决定关键任务成败，均值重构最优不保证稀有条件安全。逐通道或逐 token 尺度能改变这一折中，同时增加尺度元数据、计算或内核约束，不能把更细粒度当成免费的严格改进。

若使用固定范围，部署输入幅度漂移会增加饱和；若使用动态范围，极端 token 又可能影响同组其他数值分辨率。因而研究应同时记录饱和比例、不同幅度区间误差与任务切片，而不是只记录一个全局均方误差。

<a id="quant-systems-67"></a>

### 16.2 注意力中的键值误差不是同一种影响

注意力权重来自 softmax(qkᵀ/√d)，输出再加权值向量。键误差首先扰动打分和权重，值误差则在给定权重下扰动聚合。对单个键，打分改变量可由 ||q||·||δk||/√d 控制；若查询也量化，还会出现查询误差与键误差的交叉项。仅说缓存元素均方误差相同，无法判断输出影响相同。

softmax 雅可比为 diag(p)−ppᵀ，给出局部概率变化与打分变化的关系。它说明输出敏感性依赖当前注意力分布，但不能把局部线性近似无限扩展到大饱和误差。若原来两个重要位置的分数很近，小误差可能改变注意力侧重；若值向量方向差异很大，这种权重改变会明显影响输出。

**从局部雅可比到有限扰动界。** 固定一条查询，令原打分为 $z$，量化后的打分为 $z+h$，两组概率为 $p,p'$。沿路径 $p(t)=\operatorname{softmax}(z+th)$，有

$$
\frac{dp_i(t)}{dt}=p_i(t)\bigl(h_i-\mathbb E_{p(t)}h\bigr).
$$

因此导数的 $L_1$ 范数就是 $\mathbb E_{p(t)}|h-\mathbb E_{p(t)}h|$。设 $\operatorname{osc}(h)=\max_i h_i-\min_i h_i$；由 Cauchy–Schwarz 与有界变量的方差界，该期望至多 $\operatorname{osc}(h)/2$。对 $t\in[0,1]$ 积分，并利用两概率分布的 $L_1$ 距离至多 $2$，得到全局成立的界

$$
\|p'-p\|_1\le\min\{2,\operatorname{osc}(h)/2\}.
$$

方差界也可以直接验证：若 $h\in[a,b]$，则 $\mathbb E(h-a)(b-h)\ge0$，整理得到 $\operatorname{Var}(h)\le(\mathbb Eh-a)(b-\mathbb Eh)\le(b-a)^2/4$。这里使用打分扰动的振幅，自动忽略给所有位置加同一个常数的无效变化，比只看最大绝对打分误差更贴合 softmax 的平移不变性。

若原值向量为 $v_i$，值量化误差为 $e_i$，任选中心 $c$ 并定义 $R=\max_i\|v_i-c\|$、$\eta=\max_i\|e_i\|$，则输出差严格分解为 $\sum_i(p'_i-p_i)(v_i-c)+\sum_i p'_ie_i$，于是

$$
\|o'-o\|\le R\min\{2,\operatorname{osc}(h)/2\}+\eta.
$$

这把键造成的权重变化与值本身的误差分别控制，且不要求扰动足够小。中心可以选任意向量；选得接近值向量簇通常能收紧 $R$。若有掩码，比较必须在相同的有效位置集合上进行，不能把负无穷掩码当作普通有限扰动。

**两位置算例。** 原打分为 $(0,0)$，值为 $(0,2)$，输出是 $1$。令打分误差为 $(a,-a)$，值不变，则新输出为 $2/(1+e^{2a})$，误差绝对值恰为 $|\tanh a|$。选择中心 $c=1$ 得 $R=1$，上界为 $\min(2,|a|)$；$a=0.2$ 时真实误差约 $0.197375$，界为 $0.2$。若误差改成 $(0.2,0.2)$，振幅为零，输出精确不变。这说明缓存误差的相对方向比单一元素均方误差更能解释注意力变化。该界只控制本次聚合，后续层与生成步骤仍需另行分析。

缓存量化还会跨后续生成步骤重复影响计算，因此不能用一个孤立层的重构测试替代长序列评价。应该固定上下文与解码规则，分别观察不同长度和位置的任务结果，记录缓存位宽与尺度布局。长序列出现退化时，还要排除截断、位置编码和预算变化，避免把所有变化都归因于量化。

<a id="quant-systems-68"></a>

### 16.3 尺度重分配的精确形状条件

用本章输入矩阵 X 为 n×d、权重 W 为 k×d 的约定，线性输出为 XWᵀ。对正对角 d×d 矩阵 D，有 XWᵀ=(XD⁻¹)(WD)ᵀ，因为 D 对称且 D⁻¹D=I。这样输入第 j 列缩小 Djj 倍，权重第 j 列放大同一倍，浮点函数保持相同。

如果要把这个变化折叠进前一层，必须检查连接位置。正对角缩放与逐元素 ReLU 满足 ReLU(hD⁻¹)=ReLU(h)D⁻¹，所以在合适结构中可以同时改变前层权重与偏置来实现。若缩放跨过不具备这种交换性质的操作，则不能仅凭线性层恒等式声称整个网络不变。归一化、残差分支和共享张量的其他消费者都需要单独处理。

这个恒等式只给出可行变换族，没有告诉哪个 D 的量化后误差最好。若 D 太极端，会使权重或激活某一侧范围恶化，还可能造成有限浮点数值问题。实际搜索范围、分组粒度与部署支持才决定可用选择，因此应先检验浮点等价，再单独分析量化变化。

<a id="quant-systems-69"></a>

## 17. 可复现的性能研究与后续项目

<a id="quant-systems-70"></a>

### 17.1 容量公式中的边界和单位

理想有效位宽使用每 G 个元素配一份元数据的近似。若元素总数不是组大小的整数倍，应按实际组数向上取整，再考虑每个张量分组边界。多个小矩阵独立分组会比把全部参数连成一条数组产生更多尾组。打包格式也可能要求对齐，从而增加未使用的填充位。

四位数值常见一字节放两个格点，但符号编码、顺序和布局需要明确；它们本身不是可直接做普通浮点乘法的数据。元数据可能还包括零点、分块索引或混合精度例外，不能只统计尺度。本章四点五有效位的结果只对应明确写出的四位加每三十二元素两字节尺度，不代表任意四位模型文件大小。

内存单位也要统一：十进制 GB 与二进制 GiB 数值不同。文件大小、加载后权重占用、进程保留内存和运行峰值更是不同测量对象。若某后端加载后暂时展开权重，磁盘较小不代表峰值按同样比例下降。应在同一边界下比较，并说明是否包含加载、缓存、工作区和运行时分配。

<a id="quant-systems-71"></a>

### 17.2 批量改变算术强度与排队

对相同权重矩阵，多个输入一起计算可能复用一次读取的权重，使每字节承担更多算术操作。于是单 token 解码可能更受权重读取限制，而较大批量或预填充可能接近不同瓶颈。这个方向性解释来自数据复用，不构成某设备的速度预测，因为实际缓存、调度与融合会改变读取量。

即使吞吐提高，等待凑批也可能增加单请求延迟。服务评价应区分首 token 时间、后续 token 间隔、端到端延迟和总体吞吐，并固定并发与输入输出长度。只给一个最大 tokens/s 数字，会隐藏等待时间和长尾。若比较方法改变了批量容量，还应分别报告相同批量的执行收益与容量带来的服务收益。

Amdahl 模型中不可加速部分必须按目标负载定义。压缩矩阵乘法不一定加速采样、通信、数据搬运或应用逻辑，甚至可能增加解包。假设一半时间四倍加速得到一点六倍，只是一个计算例子。若真实可加速比例变化，这个值也随之变化，不能引用它作为本机基准。

<a id="quant-systems-72"></a>

### 17.3 项目一：校准来源迁移

在现有人工分类器上，可保持模型和所有候选量化配置固定，只改变校准输入第三到第六维的相关性或尺度，再在原分布与预先定义的迁移分布上评价。先提出假设：局部重构选择可能依赖输入二阶矩，且迁移方向能使原优势失效。该项目直接连接实验二的解析反例与实验三的完整网络。

评价应包括各层 G 的差异、局部输出误差、最终 logit 误差、准确率和 NLL。若只看任务分数，难以区分局部几何改变与后续层敏感性；若只看重构，又遗漏任务边界。固定多个数据种子并报告配对差异，所有候选选择仅用校准集。迁移测试不能反复用于选择最有戏剧性的尺度。

若结果没有显示预期失效，应如实报告，可能是模型对受影响方向不敏感或候选集合太相似。不能为了符合解析直觉而悄悄替换任务。解析例子证明“可能发生”，完整实验研究“给定设置是否发生”，二者证据角色不同。

<a id="quant-systems-73"></a>

### 17.4 项目二：原前缀和量化前缀消融

固定相同训练模型、校准样本、候选粒度、尺度比例与搜索次数，只改变后层校准输入来自原模型还是已量化前缀。明确教师目标后，记录两种选择是否相同，若不同，再比较独立局部误差与整体任务。可以预先规定额外一组去均值 logit 误差，但不能看到结果后无限增加指标寻找胜利。

这个消融检验一个具体实现选择，不应冠以完整新算法名称。若量化前缀方法更好，仍需检查优势是否来自不同教师或额外搜索；若更差，也不证明该原则总是无效，因为逐层贪心与目标错配可能同时存在。完整记录比只报告一个提升百分点更有助于下一步研究。

<a id="quant-systems-74"></a>

### 17.5 项目三：数值语义与真实执行分开验收

在具备实际支持的后端时，先使用小矩阵验证量化格点、零点、饱和和累加的参考输出，涵盖边界值及非整组尺寸。确认格式语义后，再用相同质量预算测试真实模型负载的延迟与内存，记录硬件、软件版本、预热、同步和重复次数。这是两个相关但独立的验收：数值正确不等于速度改善，速度改善也不证明任务质量保持。

本章没有运行该硬件项目，因此只能把它作为后续研究方案。已有四个 CPU 实验完成了量化代数、校准几何、完整人工任务和容量上限四种证据，不需要用虚构的低位内核计时填补缺口。阅读者能够清楚知道哪些结论已经实测，哪些依赖假设，哪些仍需部署环境验证。

<a id="quant-systems-75"></a>

### 17.6 本章结果应怎样进入实验报告

最终报告首先写明任务、浮点训练预算和固定数据划分，再写量化位宽、尺度粒度、候选集合、校准权限和目标。表中同时放浮点、朴素量化和校准量化结果，让读者看见校准对重构与任务产生不同影响。实际运行的浮点模拟不能使用“整数加速达到”这样的描述。

本章模型只训练一次，校准方案也只有固定人工设置，尚未量化跨训练种子的方差。测试样本之间共享同一个训练模型，不能把几千样本误当几千次独立模型实验。若要推断方法在随机训练下的稳定收益，应增加独立训练种子，并在每个种子内配对比较相同测试样本，分清数据不确定性与训练不确定性。

实际保存内容只需要 Markdown 中的定义、推导、代码和结果。临时脚本、权重或搜索日志并非这套学习资料的交付要求。可复现性来自完整可运行协议与真实执行证据，不来自堆积没有用途的生成文件。

<a id="quant-systems-76"></a>

### 17.7 一份可手算的结果归因记录

假设两个测试样本的浮点 logit 分别为第一样本的二点零与一点九，第二样本的十与零，真实类别都为第一类。方案甲只把第一样本改为一点八与一点九，第二样本不变；方案乙只把第二样本两个分量同时增加一。方案甲的总平方误差为零点零四，却造成一个错误；方案乙的总平方误差为二，类别与概率都不变。即使把总误差除以相同元素数，排序仍不变。这给出了重构指标与分类指标错序的完整有限例子。

若将方案乙每个样本的共同偏移先去掉，它的误差归零，说明评价中有些坐标方向本身不影响任务。但方案甲即便去均值后，误差仍然很小，却跨过了原来很窄的决策间隔。因此改造重构指标能够减少一种无关方向，并不消除所有任务目标差异。应分别解释这两层结论，而不能用一个反例否定所有重构方法。

还可以把两种误差放回二阶几何：输入方向决定哪些权重扰动被激活，输出方向决定这些扰动怎样影响类别相对差，后续非线性和任务分布再决定总体损失。局部输入二阶矩只描述其中一部分。完整研究若同时测输入几何、层误差和边界变化，就能区分失败发生在哪一段，而不是把所有负结果统称为量化噪声。

本章已运行实验保留固定种子和全部结果，未根据独立测试分数重新选择尺度、重训模型或更换数据。新增的手算例子只用于解释目标关系，并未被当作实际分类器失败机制的证据。后续若检查逐样本日志，应标注探索性分析，并用新独立数据确认提出的机制。
