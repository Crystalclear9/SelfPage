# 高效训练与推理系统

从状态与 I/O 预算理解分片、重计算、量化和实际推理瓶颈。

**先修知识：** PyTorch、设备计算、梯度累积与语言模型缓存；不要求具备多卡硬件才能完成算例。

## 章节与学习目标

| 章节 | 核心内容 | 深入讲解入口 |
| --- | --- | --- |
| [第 1 章 训练显存分解、分片与重计算](01-训练显存分解分片与重计算.md) | 峰值显存由哪些状态组成；数据并行为什么复制状态；状态分片的机制与边界 | [进入讲解](01-训练显存分解分片与重计算.md#deep-dive-2) |
| [第 2 章 量化误差、校准与推理瓶颈](02-量化误差校准与推理瓶颈.md) | 量化格点与多坐标补偿；校准几何与注意力误差界；权重、激活和缓存成本 | [进入讲解](02-量化误差校准与推理瓶颈.md#deep-dive-2) |

## 阅读顺序与验收

第 1 章先画状态所有权和存活时间，再核对有效 token 归约、分片更新、重计算及保存恢复；第 2 章先固定量化语义，再研究校准几何、误差传播、完整模型质量与执行瓶颈。两章中的字节预算、CPU 数值身份、完整小训练和真实硬件性能属于不同证据层次。遇到公式先复算低维例子，再进入实验设计；不要把局部数值检查当成算法整体效果证明。

**完成要求：** 列出训练内存预算；解释分片与峰值差距；复算量化输出误差；设计同时看质量、内存和延迟的测试。

作答后再阅读各章解析。能够独立说明一个失效条件，并设计一个可区分竞争解释的对照实验，才算完成本主题的进阶学习。

## 量化与推理的具体推导入口

第 2 章的[多坐标约束补偿](02-量化误差校准与推理瓶颈.md#quant-systems-48)将单坐标公式推进到线性约束、Schur 补和逐步冻结；先解给定格点改变量的连续子问题，再讨论离散选择。[注意力缓存误差界](02-量化误差校准与推理瓶颈.md#quant-systems-67)把键造成的权重变化与值误差分开。缓存容量计算可回看[GQA 共享结构](../../DeepLearning/Attention/04-注意力效率位置与解释实验.md#attention-4-gqa)，采样加速则转到[精确投机解码](../../AI-Domains/LargeLanguageModels/01-分词预训练与语言建模.md#llm-1-speculative)。
