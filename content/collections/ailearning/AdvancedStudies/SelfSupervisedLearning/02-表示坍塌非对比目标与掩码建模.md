## 1. 去掉负样本以后，问题并没有消失

非对比自监督方法不依靠显式负样本区分实例，可以使用双分支预测、停止梯度、动量目标、方差协方差约束或掩码重构。但“没有负样本”不是一个自动正确的目标定义。若损失只要求两视图输出相同，常数表示就可能达到最小；若只要求重构缺失部分，模型也可能优先学习背景、局部纹理或数据捷径。需要说明目标鼓励什么、退化在哪里、结构怎样改变优化。

本章把坍塌、停止梯度和掩码学习分别展开，再用可解析反例与完整人工训练连接。重点不是保证每种方法都成功，而是区分全局最优、驻点、有限训练动态与下游有用性。一个损失具有防退化项，不代表在完全坍塌点一定有非零梯度；一个表示每维方差非零，也不代表它具有足够秩或任务信息。

<a id="noncontrast-2"></a>

### 1.1 完全坍塌与维度坍塌

完全坍塌是所有样本映射成同一向量，无法区分任何输入。维度坍塌则可能仍有变化，但变化只占很少方向。若三个坐标都复制同一个标量，每维方差都很大，中心化表示矩阵却只有一维。坐标监控与谱监控应结合，不能只看一个标准差阈值。

即使满秩也不证明语义好，独立随机噪声具有高秩却可能与任务无关。坍塌诊断检验的是必要结构的一部分，下游独立评价检验另一部分。二者不可互换。低训练损失、非零方差和高任务成绩之间没有无需假设的统一等号。

<a id="noncontrast-3"></a>

### 1.2 目标坍塌与优化坍塌

某目标允许常数全局最优，是目标层面的退化；某目标不偏好常数却在常数点梯度为零，是优化层面的驻点问题；有限随机训练走向低秩或无语义表示，又是实际动态现象。分析时应明确是哪一层，不能一看到某个防坍塌项就宣布所有问题解决。

架构、初始化、归一化、预测头和优化器会影响动态，可能使某些坏点不容易到达，却不等于数学上不存在。论文经验有效与普遍保证是不同结论。人工最小模型可以把逻辑分清，再用完整训练检验给定设置下是否实际避开退化。

<a id="visual-selfsupervisedlearning-02"></a>
### 图解：仅靠视图一致性为何会坍塌

![仅靠视图一致性为何会坍塌：机制、算例与边界](images/02-concept.svg)

两个散点面板都令同一样本的两个视图得到完全相同的表示，因此视图一致性损失都为零。左边四个样本都映到 $`(0,0)`$，无法区分输入；中间四个样本分别映到 $`(-1,-1),(-1,1),(1,-1),(1,1)`$，仍然能完全满足一致性。两个面板使用相同横纵坐标单位，蓝点和橙圈只是重合的两视图标记，并不代表正负类别。

右图局部放大坍塌点附近的 VICReg **实际单分支标准差惩罚**；灰色短线为原点切线。以中间四点组成的矩阵 $`Z_0`$ 为基础，令 $`Z(a)=aZ_0`$，按批次样本方差的 $`n-1`$ 分母计算，则每一维方差为 $`\frac{4a^2}{3}`$。在 $`\gamma=1,\epsilon=10^{-4}`$ 时，
$`v(a)=\max\left(0,1-\sqrt{\frac{4a^2}{3}+10^{-4}}\right)`$。
所以坍塌点 $`a=0`$ 的惩罚为 0.99，而 $`a=1`$ 已不受方差惩罚；本例各维的样本协方差非对角项也为零。图只比较单分支项，不把它误当成包含各系数、两分支和协方差项的完整训练损失。

还要区分目标值与优化梯度：因为加入了正的 $`\epsilon`$，上式在 $`a=0`$ 的导数恰好为零。更一般地，当所有表示完全相同时，批次方差对每个表示的导数也为零。因此正方差惩罚能使完全坍塌不是本例的最优解，却不能仅凭这一点证明任何初始化都能立即逃离精确坍塌。实际训练还涉及初始化、扰动与其他目标项；后面的掩码建模图继续讨论另一种目标的条件均值边界。损失定义见 [VICReg 原论文第 4.1 节](https://arxiv.org/html/2105.04906v3#S4.SS1)，$`n-1`$ 方差与稳定项可对照 [官方实现](https://github.com/facebookresearch/vicreg/blob/main/main_vicreg.py)。

## 2. 停止梯度到底改变什么

<a id="sec-2-1"></a>

<a id="noncontrast-5"></a>

### 2.1 数值相等不代表梯度相同

对两分支输出 z 与 z'，停止梯度保留目标分支数值，却阻止当前损失沿它反传。它不是把目标设成零，也不是从损失删除目标。若一个共享编码器分别出现在在线与目标路径，更新来自允许的那条路径，和同时对两边求导不同。交换方向或平均双向损失时，需要分别说明每次分离哪一边。

目标网络可以由在线参数的移动平均更新，也可以共享权重但用分离操作。两者在状态与动态上不同，不能统称“目标不训练”。移动平均不是梯度下降，归一化运行统计也可能按其他规则变化。完整算法应说明权重、缓冲区、预测头与随机增强的更新路径。

<a id="deep-dive-2"></a>

<a id="noncontrast-6"></a>

### 2.2 常数仍可能是零损失点

若两分支都输出相同常数，平方差目标为零，允许反传的一边梯度也为零。停止另一边并不会凭空制造差异。因此 stop-gradient 本身不是所有架构和损失下排除常数解的定理。实际非对比方法依靠更完整结构与动态，不能只保留一个分离操作就期待复现其行为。

对余弦目标，归一化、零向量保护和预测头也影响退化点。相同非零常数向量可以使对齐很好，是否有其他项或动态不稳定它，需要具体分析。不能从“反向路径不对称”直接推出“所有坍塌驻点消失”，这跳过了最重要的梯度检查。

<a id="noncontrast-7"></a>

### 2.3 预测头与非对称性

预测头让在线表示经过额外变换去拟合目标，可能改变固定点和局部稳定性，也能把某些约束吸收到读取空间。但它并不保证原表示保留全部信息。移除头、共享头或改变归一化，都可能影响实际结果，应通过同预算消融验证，不能把任意非对称都视作同一算法。

分析小线性模型时，可以写出各矩阵的期望更新，研究哪些方向被放大或衰减。复杂非线性系统则更需要独立任务与谱诊断。经验上有效的设计可以使用，但结论要与假设和证据一致，而不是把一个实现技巧包装成无条件防坍塌证明。

## 3. 方差与协方差正则的机制

<a id="noncontrast-9"></a>

### 3.1 方差下限惩罚

常见方法对每个坐标的批次标准差施加下限，低于目标时惩罚，避免所有样本数值过于接近。标准差通常由方差加小常数再开根号，既影响数值也影响梯度。它鼓励每维有变化，但不直接要求不同维度提供不同信息，也不直接约束语义。

在所有样本完全相同时，方差关于表示的导数为零，因此即使惩罚值很高，平滑标准差惩罚的梯度仍可能为零。它可能使坍塌不是全局最优，却不自动移除该驻点。随机初始化、其他项和训练动态可以帮助避开，但不能把正损失本身误当成非零恢复力。

<a id="noncontrast-10"></a>

### 3.2 协方差去冗余

对中心化批次表示，协方差非对角项惩罚鼓励不同坐标少线性冗余。它与方差下限配合，可以抑制复制同一信号到多维的某些退化。单独协方差惩罚也偏好全零表示，因此不能替代方差项。各项权重、批次归一化和样本协方差分母都需要明确。

零协方差不等于统计独立，非线性依赖仍可能存在；有限批次协方差也带估计噪声。样本量小于维度时秩受到天然限制，过强去相关可能与可表示结构冲突。应结合样本量和数据内在因素解释，不要把所有非零协方差都视作错误。

<a id="noncontrast-11"></a>

### 3.3 不变性与信息量的折中

两视图一致项鼓励共同因素，方差项鼓励变化，协方差项鼓励分散变化。它们可能共同产生有用表示，也可能保留无关共同因素。若增强删除了任务信息，再多方差与去相关也无法恢复；若噪声在两视图共享，模型可能用它满足所有结构要求。

因此这些正则提供的是几何激励，语义仍来自数据与视图。应做目标项消融、增强消融与独立因素读出，而不是只报告总损失。总损失下降可能掩盖某项牺牲另一项，报告分项更有助于理解稳定性与任务收益。

<a id="visual-detail-selfsupervisedlearning-02"></a>

### 机制说明：零方差点可能受到惩罚却没有非零梯度

主图右上角已经给出相同的平滑方差惩罚曲线。

用平滑方差惩罚L(z)=(z²−1)²说明驻点问题：z=0处损失为1，导数却为零；z=±1处损失为零。正的防坍塌惩罚值本身不能保证优化器一定能离开完全对称的坍塌状态。

这是一个可复算的机制示例，不是所有防坍塌方法的实际损失；非平滑方差项、噪声和网络结构可能改变局部行为。

## 4. 可运行实验一：正惩罚也可以零梯度

这段独立代码检验三个明确反例：停止目标梯度的常数对齐仍为零损失；平滑方差下限在完全常数点有正惩罚却零梯度；复制同一信号的多维表示各维方差非零却秩一。它们不证明完整方法必然失败，只排除不加条件的简化保证。

```python
import torch
import torch.nn.functional as F

torch.set_num_threads(1)
z=torch.zeros(12,4,dtype=torch.float64,requires_grad=True)
target=torch.zeros_like(z,requires_grad=True)
alignment=(z-target.detach()).square().mean()
g1=torch.autograd.grad(alignment,z,retain_graph=True)[0]
std=(z.var(0,unbiased=False)+1e-4).sqrt()
variance=F.relu(1-std).mean()
g2=torch.autograd.grad(variance,z)[0]
assert alignment==0 and torch.all(g1==0) and target.grad is None
assert variance>0 and torch.all(g2==0)
t=torch.linspace(-2,2,20,dtype=torch.float64)
copy=t[:,None].repeat(1,4)
assert torch.all(copy.std(0,unbiased=False)>.5)
centered=copy-copy.mean(0)
assert int(torch.linalg.matrix_rank(centered))==1
cov=centered.T@centered/(len(copy)-1)
offdiag=cov-torch.diag(cov.diag())
assert offdiag.square().sum()>0
print('constant alignment/variance penalty/gradient norms',
      float(alignment.detach()),float(variance.detach()),g1.norm().item(),g2.norm().item())
print('copied signal coordinate std/rank',copy.std(0,unbiased=False).tolist(),
      int(torch.linalg.matrix_rank(centered)))
```

在完全常数点，协方差惩罚同样没有理由制造语义方向，它可能也具有零导数。实际训练从随机初始化开始，通常不会恰好位于这个点，但会不会向它靠近仍需实验。数学反例与经验轨迹应该并列，而不是用其中一种否定另一种有效证据。

## 5. 掩码建模的概率对象

<a id="noncontrast-14"></a>

### 5.1 只看可见部分预测缺失部分

掩码任务从样本中隐藏某些坐标或片段，编码器只接收可见部分及相应位置信息，解码器预测被隐藏目标。训练信号来自原始样本，但必须防止目标通过输入、位置编码或共享缓存泄露。是否只在掩码位置计算损失、是否归一化目标以及如何处理变长样本，都属于目标定义。

平方误差最优预测是缺失部分给定可见部分的条件均值，交叉熵则对应相应条件分布分类。若缺失信息与可见部分独立，模型无法恢复单次真实值，只能给条件平均或分布；残余误差不是一定容量不足。掩码率改变条件信息量，不能简单认为越高越高级。

<a id="noncontrast-15"></a>

### 5.2 信息丢失与不可恢复

如果任务标签只由被隐藏且独立的部分决定，可见表示不可能可靠预测标签。增加解码器规模不会创造不存在的条件信息。若训练与部署掩码规则不同，表示可用性也会变化。应明确评估时编码器看到完整输入还是同样掩码，避免把两个不同信息条件混合。

掩码重构也可能学到局部纹理、背景或设备偏差，而不是期望语义。只要这些因素对像素误差贡献大，优化器就有理由优先拟合。重构损失低不能自动证明下游表示好，需要冻结评价和因子消融。解码器能力还可能承担大量预测，使编码器本身信息不足。

<a id="noncontrast-16"></a>

### 5.3 编码器与解码器分工

可见片段输入较轻编码器、较大解码器补全，或相反结构，都会改变计算与表示压力。预训练解码器在部署时可能被丢弃，因此应评价实际保留的编码器输出，不要用完整重构系统成绩替代冻结表示。若换读取层或池化方式，应统一选择协议。

掩码 token 与位置编码提供缺失位置线索，但不能直接携带真实内容。结构化数据还需要考虑掩码是否符合真实缺失机制，随机遮挡与业务缺失未必相同。模型对某个训练掩码分布有效，不意味着适应任意缺失模式或对抗删除。

<a id="noncontrast-17"></a>

## 6. 可运行实验二：掩码条件均值与不可约误差

构造可见变量 X 与缺失变量 Y，后者等于两倍 X 加独立噪声。线性回归可以学到条件均值，却无法预测每次噪声。再构造一个与可见变量独立的二值任务标签，任何只用可见信息的理想分类器都只能达到先验多数类水平。实验用解析独立性与大样本模拟核对。

```python
import numpy as np
rng=np.random.default_rng(331)
n=100000
x=rng.normal(size=n);noise=.7*rng.normal(size=n)
y=2*x+noise
coef=(x@y)/(x@x)
pred=coef*x
mse=np.mean((pred-y)**2)
assert abs(coef-2)<.015 and abs(mse-.49)<.01
label=rng.integers(2,size=n)
# A fixed visible-only rule has no class information in this model.
visible_rule=(x>0).astype(int)
accuracy=np.mean(visible_rule==label)
assert abs(accuracy-.5)<.01
assert abs(np.corrcoef(x,label)[0,1])<.015
print('masked regression slope/MSE/noise variance',coef,mse,.49)
print('independent masked-label visible-rule accuracy',accuracy)
```

这不是用一个弱分类器失败证明所有分类器失败；总体结论来自明确独立生成机制，模拟只是核对。若真实数据中可见与缺失变量有关，当然可以预测一部分。研究者需要指出信息来源与不可约部分，而不能把所有重构误差都当成尚未训练足够。

## 7. 完整人工训练：几何正则与纯对齐消融

<a id="noncontrast-19"></a>

### 7.1 数据与比较对象

人工数据包含四类二维中心附近的连续变化，另有六维大幅无关噪声。两个视图保留前两维并轻微扰动，独立重抽其余噪声。比较同一编码器的两套目标：纯平方对齐，与对齐加方差下限和协方差正则。两者使用相同初始化、视图随机流和更新次数，类别标签只进入冻结后的评价。

这是受几何正则思想启发的明确小实现，不声称完整复现任何图像论文。纯对齐可能学到近常数但仍残留可读取信息，正则版本也可能只保留部分因素。实验同时报告标准差、奇异值和标准化线性探针，而不把低损失或单一准确率当成全部结论。

<a id="noncontrast-20"></a>

### 7.2 可运行实验三：真实训练与独立探针

```python
import numpy as np
import torch
from torch import nn
import torch.nn.functional as F

torch.set_num_threads(1)
centers=torch.tensor([[-1.,-1.],[-1.,1.],[1.,-1.],[1.,1.]])
def data(n,seed):
    g=torch.Generator().manual_seed(seed)
    y=torch.randint(4,(n,),generator=g)
    x=torch.cat([centers[y]+.15*torch.randn(n,2,generator=g),
                 3*torch.randn(n,6,generator=g)],1)
    return x,y
train,ytrain=data(768,341);test,ytest=data(512,342)
def run(regularized):
    torch.manual_seed(343)
    encoder=nn.Sequential(nn.Linear(8,32),nn.ReLU(),nn.Linear(32,8))
    opt=torch.optim.Adam(encoder.parameters(),lr=.002)
    rng=torch.Generator().manual_seed(344)
    def view(x):
        return torch.cat([x[:,:2]+.05*torch.randn(len(x),2,generator=rng),
                          3*torch.randn(len(x),6,generator=rng)],1)
    for _ in range(1300):
        ids=torch.randint(len(train),(128,),generator=rng)
        a,b=encoder(view(train[ids])),encoder(view(train[ids]))
        inv=(a-b).square().mean()
        std_a=(a.var(0,unbiased=False)+1e-4).sqrt()
        std_b=(b.var(0,unbiased=False)+1e-4).sqrt()
        var=(F.relu(1-std_a).mean()+F.relu(1-std_b).mean())/2
        ac=a-a.mean(0);bc=b-b.mean(0)
        ca=ac.T@ac/(len(a)-1);cb=bc.T@bc/(len(b)-1)
        offa=ca-torch.diag(ca.diag());offb=cb-torch.diag(cb.diag())
        cov=(offa.square().sum()+offb.square().sum())/(2*a.shape[1])
        loss=25*inv+(25*var+cov if regularized else 0)
        opt.zero_grad();loss.backward();opt.step()
    with torch.no_grad():
        ht=encoder(train).numpy();he=encoder(test).numpy()
        mean=ht.mean(0);scale=np.maximum(ht.std(0),1e-6)
        at=np.c_[(ht-mean)/scale,np.ones(len(ht))]
        ae=np.c_[(he-mean)/scale,np.ones(len(he))]
        target=np.eye(4)[ytrain.numpy()]
        w=np.linalg.solve(at.T@at+.1*np.eye(at.shape[1]),at.T@target)
        accuracy=float(np.mean((ae@w).argmax(1)==ytest.numpy()))
        singular=np.linalg.svd(ht-mean,compute_uv=False)/np.sqrt(len(ht))
        assert np.isfinite(ht).all() and np.isfinite(singular).all()
        print('regularized',regularized,'last inv/var/cov',
              float(inv.detach()),float(var.detach()),float(cov.detach()),
              'coordinate std',ht.std(0),'singular values',singular,
              'standardized frozen probe',accuracy)
for regularized in [False,True]:run(regularized)
```

<a id="noncontrast-21"></a>

### 7.3 为什么探针要同时说明尺度

如果纯对齐把幅度压得很小，未标准化探针的固定正则会更强地惩罚它，可能把尺度差异误当信息消失。这里训练统计标准化后再拟合，测试只用训练均值方差。它让读出比较更清楚，却也会放大极小残余信号，因此高探针不证明表示数值稳健。应同时看原始标准差、谱与扰动敏感性。

完全常数没有残余信息，任何标准化也无法恢复；近常数则可能在精确计算中仍保留线索。这两种情形不能混称。实际部署有限精度、噪声或正则可能让小幅信号不可用，研究者应明确最终使用条件，而不是只选择有利的探针预处理。

## 8. 完整掩码训练与背景因素

<a id="noncontrast-23"></a>

### 8.1 六维冗余观测

构造两个语义连续因素和一个大方差背景因素，每个因素各出现两次带噪观测。随机隐藏一半坐标，模型从可见值与掩码预测被隐藏坐标。背景方差较大，因此原始平方误差更重视背景。类别仅由第一语义因素符号决定，冻结探针检验编码是否便于读取该任务。

这个任务有明确可预测部分：某个因素的一份观测可帮助恢复另一份；也有不可约部分：同组两份都被遮住时，该独立因素没有可见证据。模型不应被要求无误恢复每个真实值。编码器和解码器都在代码中，评价使用独立样本、固定掩码与冻结表示，不只展示训练重构。

<a id="noncontrast-24"></a>

### 8.2 可运行实验四：从掩码到完整评价

```python
import numpy as np
import torch
from torch import nn

torch.set_num_threads(1);torch.manual_seed(351)
def data(n,seed):
    g=torch.Generator().manual_seed(seed)
    factors=torch.randn(n,3,generator=g)*torch.tensor([1.,1.,4.])
    x=factors.repeat_interleave(2,dim=1)+.1*torch.randn(n,6,generator=g)
    y=(factors[:,0]>0).long()
    return x,y
train,labels=data(1024,352);test,test_labels=data(512,353)
encoder=nn.Sequential(nn.Linear(12,24),nn.ReLU(),nn.Linear(24,4))
decoder=nn.Sequential(nn.Linear(4,24),nn.ReLU(),nn.Linear(24,6))
opt=torch.optim.Adam(list(encoder.parameters())+list(decoder.parameters()),lr=.003)
rng=torch.Generator().manual_seed(354)
ev_rng=torch.Generator().manual_seed(355)
eval_mask=(torch.rand(test.shape,generator=ev_rng)>.5).float()
def predict(x,mask):
    h=encoder(torch.cat([x*mask,mask],1))
    return decoder(h),h
def masked_loss(x,mask):
    prediction,_=predict(x,mask)
    missing=1-mask
    return ((prediction-x).square()*missing).sum()/missing.sum().clamp_min(1)
with torch.no_grad():before=float(masked_loss(test,eval_mask))
for _ in range(1600):
    ids=torch.randint(len(train),(128,),generator=rng)
    x=train[ids];mask=(torch.rand(x.shape,generator=rng)>.5).float()
    loss=masked_loss(x,mask)
    opt.zero_grad();loss.backward();opt.step()
with torch.no_grad():
    after=float(masked_loss(test,eval_mask))
    prediction,_=predict(test,eval_mask)
    per_coordinate=(((prediction-test).square()*(1-eval_mask)).sum(0)
                    /(1-eval_mask).sum(0).clamp_min(1))
    ht=predict(train,torch.ones_like(train))[1].numpy()
    he=predict(test,torch.ones_like(test))[1].numpy()
    mean=ht.mean(0);scale=np.maximum(ht.std(0),1e-6)
    a=np.c_[(ht-mean)/scale,np.ones(len(ht))]
    b=np.c_[(he-mean)/scale,np.ones(len(he))]
    target=np.eye(2)[labels.numpy()]
    w=np.linalg.solve(a.T@a+.1*np.eye(a.shape[1]),a.T@target)
    probe=np.mean((b@w).argmax(1)==test_labels.numpy())
assert np.isfinite([before,after,probe]).all() and after<before
print('independent fixed-mask reconstruction before/after',before,after)
print('per-coordinate masked MSE',per_coordinate.tolist(),'full-input frozen probe',probe)
```

<a id="noncontrast-25"></a>

### 8.3 评价信息条件必须明确

重构评价输入随机可见部分，表示探针输入完整观测加全可见掩码，这是两种明确不同的使用条件。完整输入读出是常见部署选择，但不能把它的高分说成在任意缺失模式下同样可靠。可以再用固定缺失比例做分层探针，检查任务信息缺失后表现如何下降。

背景坐标误差大可能只是尺度大，也可能说明它们占据主要优化资源。可以把目标逐坐标标准化或改变掩码组结构做消融，但这些变化重新定义目标权重与信息条件。应同时报告原尺度误差和任务读出，避免通过缩放让损失更低却没有改善真实目标。

## 9. 十六道进阶练习与详细答案

<a id="noncontrast-27"></a>

### 9.1 stop-gradient 是否删去目标分支

不删数值，只阻止当前损失沿该路径求导。目标仍决定误差并影响在线梯度。目标参数还可能通过移动平均或共享状态变化。必须分别说明数值、梯度与状态更新，不能只写一个“冻结”词就概括完整算法。

<a id="noncontrast-28"></a>

### 9.2 停止梯度是否排除所有常数解

不是。同一常数两边平方差为零，允许反传的一边也没有梯度。实际方法依靠完整结构与动态，不能只留一个分离操作就期待同样性质。应检查具体损失的驻点，再用完整训练评价，而不是从不对称直接推出普遍保证。

<a id="noncontrast-29"></a>

### 9.3 方差惩罚为正为何仍零梯度

平滑标准差由方差加常数开根，完全相同样本处方差对每个表示导数为零。链式法则使惩罚即使高也可能零导数。它排除某些全局最优，却未必移除驻点。随机初始化与其他项可能帮助避开，需要分清优化与目标层。

<a id="noncontrast-30"></a>

### 9.4 每维标准差非零是否满秩

不。多个坐标复制同一标量，每维都变化，矩阵仍秩一。应看中心化奇异值或协方差谱，并考虑样本量天然秩限制。满秩也不证明语义，因为随机噪声可以满秩。结构诊断与下游评价要同时存在。

<a id="noncontrast-31"></a>

### 9.5 协方差零是否独立

一般不是，只排除线性二阶关联。非线性依赖可以有零协方差。去相关是特定几何约束，不是恢复真实独立因素的证明。还要看数据结构、视图与任务。有限样本估计也有误差，不能把一张近对角矩阵当完整统计认证。

<a id="noncontrast-32"></a>

### 9.6 纯对齐低损失为何可能失败

常数输出可以忽略全部输入而让两视图一致，优化目标没有要求保留区分信息。近常数还可能留下微小残余，探针尺度处理会影响读出。应同时报告原始幅度、谱、扰动和独立任务，避免只挑一个成功指标。

<a id="noncontrast-33"></a>

### 9.7 标准化探针是否总公平

它能减少表示幅度对固定正则的影响，但会放大极小噪声或残余信号，不能替代数值稳健检查。训练统计只能从探针训练集拟合，测试保持冻结。应明确下限与正则，并同时报告原表示几何，而不是用标准化掩盖坍塌。

<a id="noncontrast-34"></a>

### 9.8 掩码率越高越好吗

不是。更高隐藏比例增加条件不确定性，可能删除任务信息；太低又可能让重构只靠局部复制。最优比例依赖冗余与目标。应固定预算比较，并明确评价输入条件，不把训练掩码变化后的损失直接按大小排序。

<a id="noncontrast-35"></a>

### 9.9 重构误差不能零是否容量不足

不一定。缺失部分可能含独立噪声或不可识别因素，条件均值仍有不可约误差。需要已知机制或独立参照区分。若强行记住训练噪声，可能降低训练误差却损害独立重构。应评价总体目标而非要求每条样本完美。

<a id="noncontrast-36"></a>

### 9.10 重构低误差是否语义有用

不自动。背景或局部纹理可能主导误差，解码器也可能承担大部分预测。应评价最终保留编码器，做因素读出与目标权重消融。类标签只在评价使用与用于训练修改目标是不同协议，需准确说明信息来源。

<a id="noncontrast-37"></a>

### 9.11 解码器大是否编码器一定更强

不保证。更强解码器可能减少编码压力，也可能帮助利用有限表示，效果依赖任务与结构。应比较冻结编码器与完整重构，固定预算并检查分工。不能用解码后结果好直接证明编码器全部信息已可读取。

<a id="noncontrast-38"></a>

### 9.12 随机掩码能否代表业务缺失

不一定。真实缺失可能依赖值、来源或目标，与独立随机遮挡不同。应按部署模式分层测试，必要时建模缺失机制。训练支持内高分不代表任意缺失鲁棒。信息被删除后，模型只能依赖明确先验或相关结构。

<a id="noncontrast-39"></a>

### 9.13 非对比是否不需要独立评价

仍需要。目标可以被无关共同因素满足，几何正则也不直接知道语义。应固定来源划分、读取层和探针预算，测试标签不参与调参。没有负样本只是训练机制差异，不是免除泛化与选择偏差检查的理由。

<a id="noncontrast-40"></a>

### 9.14 多个方法总损失能直接比吗

通常不能，权重、归一化和目标项不同，数值尺度也不同。应使用共同冻结任务、几何诊断与成本比较，并报告各自分项。更小总损失可能只是删掉一个难项，不能单独解释为更好表示。

<a id="noncontrast-41"></a>

### 9.15 目标移动平均是否无成本

需要额外参数状态与更新规则，可能增加键编码调用，陈旧与缓冲区处理也影响结果。它不通过普通梯度更新，不代表完全固定。应说明初始化、顺序、系数与运行统计，比较完整计算，而不只看在线网络参数量。

<a id="noncontrast-42"></a>

### 9.16 一个可信消融应该怎样做

固定数据、初始化、随机视图与预算，每次改变一个主要因素，保留全部种子。报告预训练目标、表示谱、冻结任务和成本，解释指标可能冲突。若改变探针或掩码条件，应独立标注。失败与负结果也是机制证据，不应被重跑成功覆盖。

<a id="noncontrast-43"></a>

## 10. 重构平方误差为什么选择条件均值

<a id="noncontrast-44"></a>

### 10.1 风险的正交分解

记可见信息为 V，被隐藏目标为 Y，任意确定预测为 f(V)。在平方可积条件下，平方误差期望可以分成 Y 到条件均值的不可约误差，加上 f 到条件均值的误差。交叉项在给定 V 后条件期望为零，因此最优预测是 $`E[Y\mid V]`$。这个结论说明训练误差的下限来自信息结构，而非网络容量。

若 Y 给定 V 仍多峰，条件均值可能位于两个模式中间，对某些视觉任务表现为平均化。更丰富的条件分布目标可以表达多个可能结果，但需要相应采样和评价，不能把一次点重构当作恢复真实单次来源。掩码预测与生成任务相关，却不是所有概率对象都相同。

<a id="noncontrast-45"></a>

### 10.2 掩码也是条件的一部分

如果掩码模式本身与数据值有关，模型看到“哪个位置缺失”就可能获得额外信息。独立随机掩码与依赖目标的缺失机制不同，条件期望也不同。训练时输入掩码可以合理，但应明确它是否在部署可用，以及是否通过设计意外泄露标签。只检查输入数值被置零还不够。

随机值替代、固定 token 和直接删除片段，都会改变可见信息结构。位置编码、序列长度与缓存也可能传递线索。完整检查应列出编码器实际接收的所有张量，并验证隐藏目标不通过其他路径进入。程序名称叫 masked 不构成真正遮蔽的证据。

<a id="noncontrast-46"></a>

### 10.3 坐标尺度怎样决定优化偏好

多维平方误差通常按坐标求和或平均，大方差维度对目标贡献更大。模型容量有限时，优先拟合背景可能比拟合小幅语义更容易降低总损失。逐坐标标准化可以重新分配权重，但也可能放大测量噪声，改变任务偏好。没有一种归一化脱离数据就绝对正确。

应同时报告原尺度与适当归一化误差，并用独立任务检验表示。若只是把背景单位从米改成毫米，总重构损失可能被放大百万倍，语义能力却完全没变。密度目标还需要相应尺度项，不能随意丢掉。目标单位是统计定义的一部分，不只是打印格式。

## 11. 可运行实验五：几乎全部重构收益来自背景

构造五个重复背景坐标和一个独立语义位。编码器只保留可见背景，四个缺失背景可以完美重构，隐藏语义永远输出零。相对于零预测基线，误差下降几乎百分之百，但表示与语义严格独立。这个有限笛卡尔积枚举让失败原因可解析，而不依靠某个弱探针没有学会的结果。

```python
import numpy as np
pairs=np.array([(background,label) for background in [-100.,100.]
                 for label in [-1.,1.]])
background=pairs[:,0];label=pairs[:,1]
# Only the first background coordinate is visible; the remaining five are masked.
visible=background[:,None]
target=np.column_stack([np.repeat(background[:,None],4,axis=1),label])
prediction=np.column_stack([np.repeat(visible,4,axis=1),np.zeros(len(label))])
mse=np.mean((prediction-target)**2)
zero_mse=np.mean(target**2)
relative=mse/zero_mse
assert np.isclose(mse,.2) and relative<3e-5
assert np.isclose(np.corrcoef(background,label)[0,1],0)
for value in [-100.,100.]:
    conditional_labels=label[background==value]
    assert np.array_equal(np.sort(conditional_labels),[-1.,1.])
print('masked MSE/zero baseline/relative residual',mse,zero_mse,relative)
print('every retained representation has exactly balanced semantic labels')
```

这里仍有零点二绝对误差，不能通过只报告相对下降掩盖它。若语义任务很重要，这个残余恰好包含全部任务信息损失。背景尺度越大，相对误差越小，而语义依然完全不可读。它直接说明重构改善百分比不是语义能力的通用代理。

## 12. 低秩、协方差与正则残差

<a id="noncontrast-49"></a>

### 12.1 从谱不等式得到限制

设中心化协方差 C 半正定、秩至多 r，迹为 t。对非零特征值使用 Cauchy 不等式，得到平方 Frobenius 范数至少为 t 平方除以 r。非对角平方和等于该范数减去对角平方和，因此若 d 个坐标方差都为一，秩 r 时非对角能量至少为 d 平方除以 r 减 d。

这个界解释为什么复制少数方向、却让每维标准差都接近一时，协方差惩罚可能仍然很大。方差项与去冗余项承担不同任务。如果样本数 B 很小，中心化经验协方差秩最多 B 减一，维度大于它时也不可能得到单位满秩矩阵。正则目标的可行性应结合样本量检查。

<a id="noncontrast-50"></a>

### 12.2 不要把流形维度误当协方差秩

二维潜在因素经过非线性映射，可以产生多个线性独立特征，经验协方差不必严格秩二。潜在流形维度、线性协方差秩与任务类别数是不同概念。只有额外线性或有限支持条件下，才能直接给出对应秩上界。不能看到数据由两个连续因素产生，就宣布任何网络八维输出都不可能满秩。

本章正则训练的前两个奇异值约二，其余明显更小，说明在这次结果里变化主要集中在两个方向；这是实测现象，不是所有该数据网络的数学必然。它也不妨碍四类探针满分。任务有用与几何全展开不同，应该分别报告，避免把单一谱目标当全部学习目的。

<a id="noncontrast-51"></a>

### 12.3 协方差梯度与尺度

协方差项关于表示通常具有高阶尺度依赖，表示整体乘小常数会使其迅速变小，所以单独最小化它容易偏好缩小。方差下限阻止某些缩小趋势，二者共同形成折中。若改变批次分母、维度平均或正则权重，实际平衡也会改变，不能只复用同一个参数数字。

完整实验中正则版本协方差项仍约二点八六，不应被省略或称为已经完全去相关。它与每维近单位方差和低有效秩一致。下一步可以研究更长训练、不同权重或更丰富视图，但应预先定义比较，不能为了让指标漂亮而临时改变目标后继续使用旧名称。

## 13. 正惩罚与零梯度的局部几何

<a id="noncontrast-53"></a>

### 13.1 常数点附近的展开

给出可以直接求导的局部模型。令一维批次输出为 $`z_i=c+t u_i`$，其中 $`B^{-1}\sum_i u_i=0`$、$`\nu=B^{-1}\sum_i u_i^2>0`$，本段使用分母 $`B`$ 的经验方差。取平滑常数 $`\epsilon>0`$、目标标准差 $`\tau>\sqrt\epsilon`$，单坐标方差惩罚为

$$
V(t)=\max\{0,\tau-\sqrt{\epsilon+\nu t^2}\}.
$$

在零点附近惩罚处于激活区，Taylor 展开得到

$$
\begin{aligned}
V(t) &=\tau-\sqrt\epsilon-\frac{\nu}{2\sqrt\epsilon}t^2+O(t^4),\\[6pt]
V'(0) &=0,\quad V''(0)=-\frac\nu{\sqrt\epsilon}<0.
\end{aligned}
$$

因此常数输出是该惩罚单独的驻点，但沿任何有正样本方差的扰动方向都存在局部负曲率。结论依赖阈值确实激活；若 $`\tau<\sqrt\epsilon`$，零点附近惩罚恒为零，就没有这项恢复力。若把平滑常数设为零，则变成 $`\max(0,\tau-\vert t\vert \sqrt\nu)`$，在零点不可微，不能继续使用同一个二阶导数结论。

把对齐项也放进来，才能判断总目标。若同一扰动方向的对齐损失为 $`a t^2`$，其中 $`a\ge0`$，方差项权重为 $`\beta>0`$，则总目标的二阶系数为

$$
a-\frac{\beta\nu}{2\sqrt\epsilon}.
$$

系数为负时，该方向对坍塌点不稳定；为正时，该方向局部收缩；等于零时必须看更高阶项。一个坐标的分析不涉及非对角协方差罚；多坐标中协方差随共同扰动幅度为二阶，其平方罚通常从四阶开始，仍应按具体参数化展开。表示空间中存在负曲率也不保证参数更新能够进入该方向，编码器雅可比可能限制可达扰动。

**手算一个局部对照。** 取 $`\nu=1,\epsilon=0.01,\tau=1,\beta=1`$，方差项的二阶系数为 $`-5`$。若对齐系数 $`a=2`$，总系数为 $`-3`$，$`t=0.01`$ 时目标约比零点低 $`0.000299`$；若 $`a=6`$，总系数为 $`1`$，同样扰动反而使目标约高 $`0.000101`$。正的方差惩罚和零的一阶梯度，在两种总目标中都存在，但局部行为相反。由此不能单看某一个损失数值判断整个训练是否会逃离坍塌。

<a id="noncontrast-54"></a>

### 13.2 噪声与初始化的作用

随机初始化、批次扰动和数值误差可能帮助系统离开某些不稳定驻点，但它们不是保证得到语义表示。噪声也可能放大无关方向或让训练发散。研究可以固定一个简化线性系统，扫描初始化幅度，记录输出方差和任务信息随时间变化，再与理论局部分析对照。

全零初始化在对称网络中还可能让多个单元永远相同，影响秩增长。不同初始化方法不仅改变损失起点，也改变对称性与梯度路径。消融应记录初始化并使用相同随机基准，避免把偶然初态收益全部归因于某个正则设计。

<a id="noncontrast-55"></a>

### 13.3 停止梯度改变的是向量场

同一个数值函数表达式，如果某一部分被视为常量，实际更新不一定等于原始对称函数的完整梯度。它可能有不同固定点稳定性与隐式偏好。分析应针对真实自动微分路径，而不是仅对表面数学式求全梯度。代码中的分离操作是算法的一部分，必须在公式或流程中明确。

这也解释为什么“损失一样”不代表训练一样。两个实现可以打印同样误差值，却对不同参数给出不同梯度。最小张量实验与参数变化检查非常重要，尤其共享权重、动量目标和多个方向平均时。先核对路径，再讨论宏观表征现象。

## 14. 完整人工训练的具体解读

<a id="noncontrast-57"></a>

### 14.1 纯对齐留下了什么

纯对齐最后不变性误差约四乘十的负五次方，方差惩罚约零点九八九。各坐标标准差约零点零零二到零点零零八，奇异值也很小，显示明显幅度收缩。标准化冻结探针仍约百分之六十点七，说明并非严格所有信息都消失，而是残余信息有限且幅度很小。

如果不说明探针标准化，读者可能把这组结果误读为完全坍塌或完全未坍塌。两者都过于粗糙。正确结论应包含原尺度、谱、任务与使用条件。进一步可以添加小测量噪声或低精度扰动，研究残余信息是否稳健，这比仅按一个阈值贴标签更有解释力。

<a id="noncontrast-58"></a>

### 14.2 几何正则成功与残余限制

正则版本各坐标标准差接近一，标准化探针为一，不变性误差约零点零零五，方差惩罚约零点零一六三。它避免了本次纯对齐的幅度收缩，并保留类别信息。但前两个奇异值约二，其余远小，协方差项约二点八六，明确存在强冗余与不完全展开。

这不是需要隐藏的坏消息，而是说明“每维有方差、类任务成功、全维去冗余”是三个不同要求。当前目标权重与视图给出一种折中。若任务只需四类，低有效维度未必有害；若需要更多连续因素，可能不足。后续评价应按任务增加，而非默认维度越满越好。

<a id="noncontrast-59"></a>

### 14.3 掩码结果的尺度与信息

固定独立掩码重构误差由约五点八五降到二点七八，语义坐标误差约零点五到零点六，背景坐标约七。背景绝对尺度更大，且当两份背景同时被遮住时不可恢复，残差符合这类信息限制。完整输入冻结探针约百分之九十七点七，说明这次编码仍保留了相关语义，但不证明所有缺失条件同样有效。

解析背景反例则表明，重构相对误差可以小到约二点五乘十的负五次方，而语义严格不可读。两个结果共同支持一个准确结论：掩码训练可以学有用表示，但是否学到期望因素取决于数据冗余、掩码和目标尺度，不能只看总重构下降。

## 15. 线性双视图模型中的全部机制

<a id="noncontrast-61"></a>

### 15.1 纯对齐为何偏好缩小

设两个视图为同一共享信号加各自独立零均值噪声，噪声协方差为 N，线性编码器为 W。两视图差中共享信号抵消，平方对齐的期望等于两倍 $`\operatorname{tr}(WNW^T)`$。若噪声在所有方向正定，零 W 是全局最小；若噪声只在部分方向变化，任何只读取其零空间的 W 都可达零，包括全零。

这个推导清楚显示纯对齐并不奖励共享信号幅度。它只惩罚随视图变化的部分，保留多少稳定信息没有唯一要求。非线性结构可能改变局部动态，但不能从目标名称抹去这个线性反例。若想保留区分能力，需要其他约束、结构或训练机制，并独立检验。

<a id="noncontrast-62"></a>

### 15.2 白化约束与共享信号选择

若额外要求输出协方差为单位阵，编码器不能再任意缩小。设共享信号协方差为 S，单视图总协方差为 S 加 N，约束为 $`W(S+N)W^T=I`$。在这个约束下最小化对齐等价于最大化 $`\operatorname{tr}(WSW^T)`$，即偏好共享方差占总方差比例高的方向。

把方向选择的推导补全。令 $`C=S+N\succ0`$，输出维数为 $`k\le d`$，定义 $`B=WC^{\frac{1}{2}}`$ 和 $`A=C^{-\frac{1}{2}}SC^{-\frac{1}{2}}`$。白化约束等价于 $`BB^T=I_k`$，而共享方差变为 $`\operatorname{tr}(BAB^T)`$。设 $`A`$ 的特征值按 $`\lambda_1\ge\cdots\ge\lambda_d`$ 排列，在特征基中令 $`\alpha_j=\Vert Be_j\Vert ^2`$，则

$$
\begin{aligned}
\operatorname{tr}(BAB^T) &=\sum_j\lambda_j\alpha_j,\\[6pt]
0 &\le\alpha_j\le1,\quad\sum_j\alpha_j=k.
\end{aligned}
$$

这些约束使加权和至多为前 $`k`$ 个特征值之和，取对应正交特征向量作 $`B`$ 的行即可达到。再换回 $`W`$，得到广义特征方程 $`Sv=\lambda Cv`$，并按 $`C`$ 内积归一化。最小对齐损失为 $`2[k-\sum_{j=1}^k\lambda_j]`$；因为 $`0\preceq S\preceq C`$，每个特征值都在零到一之间，对齐代价也非负。

**二维手算。** 令 $`S=\operatorname{diag}(9,1)`$、$`N=\operatorname{diag}(1,4)`$，故 $`C=\operatorname{diag}(10,5)`$。两方向的共享比例分别是 $`0.9,0.2`$。单维白化编码选 $`W=(\frac{1}{\sqrt{10}},0)`$ 时，对齐损失为 $`\frac{2}{10}=0.2`$；选 $`W=(0,\frac{1}{\sqrt5})`$ 时，代价为 $`\frac{8}{5}=1.6`$。后者虽也满足方差为一，却保留了更多独立视图噪声。若输出两维且严格白化，两个方向都必须保留，总代价为 $`1.8`$，不能把增加维度误解成同时免费增加不变信息。

这个线性结论连接了不变性、白化与相关分析，但要求协方差存在、总协方差可逆且约束可行。奇异 $`C`$ 应先限制到其正方差子空间；若 $`k`$ 超过其秩，白化约束无解。软惩罚也不等于严格约束，有限批次特征方向还受估计误差影响，因此该解析最优并非所有深度方法的完整证明。

<a id="noncontrast-63"></a>

### 15.3 维度与目标冲突

若稳定共享线性信号只有少数方向，却要求更多输出坐标都严格白化，额外坐标可能不得不读取视图噪声，损害不变性。软约束可以在方差、去相关与对齐之间折中，留下相关或低有效维度。这个现象可解释某些正则残差，不表示每个残差都是程序错误。

非线性函数可以从共享变量构造更多线性独立坐标，因此不能把该线性维度限制无条件迁移到 MLP。应明确分析模型与实际网络之间的差异，再用谱与任务结果检验。理论用于形成可证伪假说，不应被用于把任何结果都事后解释成必然。

<a id="noncontrast-64"></a>

### 15.4 为什么停止梯度需要独立分析

上面的目标能量推导针对对称完整平方对齐，停止一侧梯度后实际更新场不同。即使数值函数相同，不能继续直接把它当作这个对称能量的普通梯度。若要分析共享线性网络加预测头，应逐个矩阵写实际期望更新，检查固定点和稳定性，而不是从原损失最小值单独决定动态。

这也不意味着停止梯度会自动解决问题。常数反例仍存在，预测头、归一化和初始化可能改变其吸引性。一个成熟解释应同时说明目标允许什么、梯度怎样变化、哪些方向稳定，以及有限实验是否观察到对应现象。缺少任一层都容易把经验规律夸大为定理。

<a id="noncontrast-65"></a>

## 16. 高斯掩码条件分布的精确参照

<a id="noncontrast-66"></a>

### 16.1 从联合协方差得到条件均值

把完整变量分成可见 V 和隐藏 H，联合为高斯，协方差分块记为 VV、HH 和交叉块 HV。在可见协方差可逆时，隐藏条件均值为原均值加交叉协方差乘可见精度再乘可见偏移。条件协方差为隐藏协方差减去交叉项构成的 Schur 补。

这个结果给掩码任务一个精确参照：可预测部分来自交叉依赖，不可约误差来自条件协方差。若交叉块为零，独立高斯情形下可见信息完全不能预测隐藏变化，最优均值就是先验均值。若强冗余存在，条件方差可以很小，但测量噪声仍可能留下残差。

<a id="noncontrast-67"></a>

### 16.2 重复观测与两份同时缺失

本章每个因素有两份带噪观测。看到一份时，另一份可以通过共享因素预测；两份都被遮住时，若它与其他因素独立，就只能回到先验。训练总误差因此混合了不同掩码难度，不是单一重构能力。按掩码组分层能看出哪部分误差来自信息缺失，哪部分来自模型不足。

如果只报告总体平均，更多容易掩码会让分数变好，即使困难组没有改善。公平比较应固定掩码分布，或按共同预设分层汇总。改掩码率、改目标归一化和改模型容量是不同实验，不能同时改变后只归功于其中一个。

<a id="noncontrast-68"></a>

### 16.3 非高斯时不要机械套公式

非线性、多峰或离散数据的条件均值未必是线性函数，条件方差也可能依赖可见值。高斯 Schur 公式只是明确模型下的精确结果。可以用它验证代码和形成直觉，再用更丰富模型研究真实数据。不能把任意数据经验协方差代入就声称得到真实最优条件分布。

同样，平方误差只要求条件均值，不强制表示保留完整条件分布。如果应用需要不确定性、多样补全或罕见事件，应选择相应概率目标与评价。一个优秀点重构器不自动成为可靠生成器，任务不同，成功定义也要不同。

<a id="noncontrast-69"></a>

### 16.4 损失归一化决定样本权重

对每个样本先按隐藏坐标平均，再平均样本，与把全批隐藏误差总和除以全批隐藏数，一般不是同一权重。前者让隐藏少和隐藏多的样本总权相近，后者让每个隐藏坐标权重相近。本章代码采用后者，并对全批没有隐藏的极端情况作数值保护。

两种定义都可用于明确目标，但不能在比较中默默切换。变长序列、不同掩码率或多模态维数差异会放大这个区别。先标注样本轴、坐标轴与有效数，再写张量表达，能避免看似只是平均方式的小改动改变统计任务。

<a id="noncontrast-70"></a>

## 17. 动量目标与时间尺度

<a id="noncontrast-71"></a>

### 17.1 目标更新的实际含义

移动平均目标由旧参数与当前在线参数混合，不是从后验抽样，也不自动等于多个独立模型集成。它提供缓慢变化的参考，可能改善训练稳定，同时引入陈旧和额外状态。系数接近一时目标变化慢，等于一则可能完全固定；系数为零又对应立即复制，动态不同。

目标初始化如果与在线分支不同，早期任务也不同。归一化运行统计、随机层和预测头是否共享，会影响实际函数。应分别写出更新公式和执行顺序，不能只用“教师”这个拟人名称替代机制。复现时这些细节往往与主损失一样重要。

<a id="noncontrast-72"></a>

### 17.2 防止信息泄露与数值捷径

如果目标分支通过批统计、缓存或原始输入旁路泄露内容，模型可能轻松完成对齐或重构却没学到预期表示。掩码任务尤其要检查残差连接与 gather 索引，确认隐藏值真的未进入编码器。对比双分支也要检查是否意外共享增强噪声，让任务变成恒等匹配。

可以用故意打乱配对、替换隐藏值或固定可见信息的反事实检查，观察输出是否按理论改变。若隐藏目标改了但编码器输入按定义不应变，编码器表示也不应随之改变。这样的最小干预比只看训练曲线更直接，能够捕获细微信息流错误。

<a id="noncontrast-73"></a>

### 17.3 代价与部署部分

预训练使用双分支、目标状态和解码器，部署可能只保留一个编码器。比较预训练成本应计全部调用与状态，比较部署成本则计实际保留部分。不能一方面用完整重构成绩证明能力，另一方面只报小编码器成本，却不说明任务已经改变。

若下游需要完整解码器，评价就不能只看编码器探针。若只需要表征，解码器应作为训练工具与部署函数分开。清楚说明这两层，让不同用户能按自己的应用理解收益，而不是接受一个模糊的“更高效”结论。

<a id="noncontrast-74"></a>

## 18. 独立评价与稳健性检查

<a id="noncontrast-75"></a>

### 18.1 读出尺度与真实可用性

标准化探针可以读取近常数残余，但部署噪声、量化或有限精度可能让这些信息消失。可以在冻结表示上加入预设尺度扰动，比较原始与标准化读出的变化，并与满幅度表示对照。扰动必须与实际使用条件相关，不能事后挑一个让某方法失败的数值。

同时应检查多个任务因素。类别正确不保证连续偏移、位置或来源不变性，低重构误差也不保证隐变量可线性读取。独立任务的选择应提前定义，公开全部结果。多任务冲突是表示取舍证据，不需要强行合成一个绝对排名。

<a id="noncontrast-76"></a>

### 18.2 来源划分与标签阶段

同一来源的近重复若跨训练测试，编码器可能利用身份捷径，探针高分不代表新来源泛化。应按适当对象划分，并明确标签何时使用。预训练无标签、探针有标签是合理协议；根据测试标签反复选择增强、掩码与权重，则引入额外监督开发，需要独立确认。

各方法应有相同探针预算与数据量，特征均值方差只从训练部分拟合。完整输入、随机掩码输入和固定业务缺失应分别评价，不能用最有利输入条件替代全部使用场景。信息条件本身就是任务的一部分。

<a id="noncontrast-77"></a>

### 18.3 训练重复与负结果

固定编码器大量测试样本，主要减少该模型评价噪声，不代表重复训练稳定。目标权重、初始化与视图会影响结果，应使用多个预设种子，保留失败。若只运行本章固定种子，就把结论限定为机制演示，而不是宣布总体优越。

本章几何正则的低有效秩与掩码背景残差都被保留，没有调到所有指标都好看。后续若改权重或结构，应记录新实验，使用共同评价确认。准确的负结果能够指向下一步问题，比反复重跑挑一个完美输出更有研究价值。

<a id="sec-8"></a>

<a id="noncontrast-78"></a>

## 19. 三个可完成的进阶研究项目

<a id="noncontrast-79"></a>

### 19.1 常数点与局部稳定

在简化线性双视图模型中，从严格零、极小随机和普通随机三种初始化开始，比较纯对齐、方差项与完整几何目标。记录梯度、表示范数、谱和任务信息，核对常数零梯度与扰动增长是否符合局部分析。不要只看最后损失，过程能区分驻点存在与实际吸引性。

再逐项加入预测头和停止梯度，明确更新场怎样改变。每个变化都应有对应公式或小张量检查。若某设置恢复方差却没有语义，说明解决了一类退化但未解决信息选择，应该如实记录，而不是把方差恢复当全部成功。

<a id="noncontrast-80"></a>

### 19.2 掩码信息与背景权重

固定因素生成机制，比较独立坐标掩码、整组掩码和偏向背景的掩码；再比较原尺度与标准化目标。按每种缺失组计算重构误差和标签读取，检验收益来自信息增加还是权重改变。解析条件方差提供基准，不需要一开始使用大图像。

如果背景主导的目标改善总体误差却损害语义，可以进一步设计任务相关目标，但应标注引入了哪些知识。没有一种掩码规则对所有下游都最优，研究价值在于给出适用条件和取舍。独立确认样本与固定搜索预算能避免只挑支持结论的设置。

<a id="noncontrast-81"></a>

### 19.3 高维几何与非线性特征

改变输出维度和批次大小，比较坐标方差、协方差能量、奇异谱与多个任务读出。用有限样本秩界和固定秩谱界检查哪些目标理论上可行，再看实际网络是否接近。不要把非线性潜在维度与线性协方差秩混为一谈。

可以用人为共享编号反例检验高秩但无语义，也用纯对齐反例检验小幅残余。最终结论应同时描述几何与任务，而不是用一个满秩或标准差阈值宣布表征完全可靠。计算、存储和部署读出成本也应计入比较。

<a id="noncontrast-82"></a>

## 20. 对谱和残余误差保持准确命名

<a id="noncontrast-83"></a>

### 20.1 严格秩与有效秩不是同一个数

本章正则网络输出的八个奇异值在打印精度下都大于零，因此不能把它严格称为秩二。前两个方向约占绝大部分方差，正确说法是变化主要集中在两维、有效秩很低。严格矩阵秩还受数值容差影响，应注明阈值。这个区别避免把观察到的谱集中夸大成数学上不存在其他信息。

常见有效秩可以用协方差特征值归一化后的熵指数定义，也可以用迹平方除以平方迹的参与比。两者都描述谱分散，却不是同一统计量，数值也未必相等。若使用阈值累计解释方差，还要给阈值。报告一个没有定义的 rank 数字，容易让读者误解已经证明了什么。

<a id="noncontrast-84"></a>

### 20.2 低有效秩是否应该修复

取决于任务。若真实有用因素只有少数，集中表示可能简洁且可用；若多个任务需要更多独立信息，集中可能成为瓶颈。强制更多方向展开也可能只增加噪声。应把几何目标与下游需求对应，而不是默认所有输出维度都必须均等承载信息。

本章四类人工任务在两个主要方向上已经可分，因此高探针与谱集中可以同时成立。若要验证连续偏移、背景不变性或更多独立因子，应增加相应冻结读出。类别满分不是这些结论的替代证据，协方差残差也不是类别能力失败的直接证据。

<a id="noncontrast-85"></a>

### 20.3 有限重构误差与条件下限

随机掩码下，某个坐标被隐藏时，它的冗余伙伴可能可见也可能隐藏。伙伴可见时只剩测量噪声，伙伴也隐藏时独立因素不可恢复。总体期望是这些情况的加权混合。有限测试集还带样本方差，因此不能把一次背景误差七与理论尺度作逐位一致要求。

更严格研究可以按伙伴是否可见分层，分别计算条件误差，并与解析高斯条件方差对照。这样能够判断网络究竟缺少能力，还是任务本来没有信息。只看一个总体误差容易把两者混在一起，进而错误地增加解码器或训练时间。

<a id="noncontrast-86"></a>

## 21. 本章学习完成后的检查清单

能够独立推导纯线性对齐的缩小解、常数方差惩罚的零一阶梯度、固定秩协方差谱下界，以及平方重构的条件均值分解，说明已经掌握核心机制。还应能指出这些结论各自依赖线性、可积、固定秩或掩码信息条件，不能随意迁移到所有深度实现。

能够复现五段代码，并准确解释纯对齐残余、正则谱集中、掩码背景残差和语义独立反例，说明已把理论与实验连接起来。所有代码使用人工数据和普通 CPU，不依赖预训练权重或外部服务。它们验证的是清楚限定的机制，不冒充真实图像基准或生产能力。

下一步可以在新的数据结构中提出具体假说，例如某种掩码是否删除任务因素、某个目标状态是否泄露内容、某种正则是否只恢复无关方差。每个假说都应有独立参照、最小干预和预设评价。不断增加章节与技巧只有在这些连接清楚时才真正增长理解，而不只是积累缩写。

<a id="noncontrast-87"></a>

### 21.1 与上一章对比时怎样保持同一问题

上一章对比目标通过候选识别鼓励区分，本章几何正则通过对齐、方差与去冗余施加约束，掩码则要求预测隐藏内容。它们没有同一个可直接比较大小的训练损失。公平比较应冻结数据来源、编码读取、标签预算和资源，再使用共同任务，同时保留各自机制诊断。某种方法训练损失更低，可能只是目标更容易或权重更小。

本章完整双视图代码明确没有动量教师或停止梯度，检验的是几何正则消融；停止梯度结论来自单独可解析梯度实验。掩码代码是六维人工编码解码系统，不是大型图像模型复现。把这些完成范围写清，可以避免读者将一个机制实验误认为已经验证所有相关论文的完整训练动态。

如果后续实现双分支预测或动量目标，应补齐参数与缓冲区更新、优化顺序、分离路径和独立评价，再与本章相同人工结构对照。若变化只恢复方差却没有提高任务，应保留这种结果；若探针提高而重构下降，也应解释目标取舍。完整的认识来自可区分的证据，而不是要求所有方法在所有指标上同时胜出。

本章独立测试的训练前后重构只用于预先固定预算的效果核验，没有根据测试结果选择训练轮数、权重或结构。若继续开发，应另设验证来源，并在冻结后使用新的确认测试。方差项和协方差项使用的有限批次分母也已在代码中明确，迁移实现时不要无说明地更改它们。
