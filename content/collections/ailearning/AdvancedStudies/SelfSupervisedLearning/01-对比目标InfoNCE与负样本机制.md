## 1. 自监督目标先定义什么应被保留

自监督学习利用数据自身构造训练信号，不需要为每个训练样本提供外部标签，但这不意味着没有假设。选择两个视图、掩码规则、预测方向和负样本机制，都在规定哪些变化应被忽略，哪些信息应被保留。一个模型完全正确地优化实例识别目标，也可能丢掉下游任务需要的颜色或细粒度差异。因此评价应把预训练目标与下游能力分开。

本章重点研究对比学习：给定锚点，识别与它匹配的正样本，并与若干候选比较。InfoNCE 可以看成一个分类损失，也在特定抽样前提下与密度比和互信息下界联系。前提很重要，不能看到一个 softmax 公式就无条件把它称为真实互信息估计。完整理解需要连接抽样机制、最优判别函数、有限候选数、梯度与独立评价。

<a id="infonce-2"></a>

### 1.1 实例、语义与数据来源

一个源样本可以生成多个视图，正样本关系通常来自同源、时间邻近或跨模态配对。源样本是否真的共享下游语义，取决于任务。相邻视频帧可能跨事件，图像裁剪可能移除目标，文本片段可能包含不同主题。正样本不是自然真理，而是一个需要检验的构造假设。

同类不同实例在实例识别中仍可能被当作负样本，这并非公式自动错误，却与语义聚类目标存在冲突。应准确区分“对预训练索引任务是负例”与“对下游语义是不希望推远的假负例”。没有这个区分，很多关于负样本好坏的讨论会在不同任务对象之间滑动。

<a id="infonce-3"></a>

### 1.2 表示与投影头

编码器产生表示 h，投影头产生用于对比损失的 z。两者可以承担不同角色，最终下游评价常使用 h，但也应明确是否使用 z。投影头可能让损失在另一个空间吸收某些约束，却不保证 h 自然保留所有语义。比较时要固定读取层、归一化和探针协议，不能对不同方法事后挑最有利层。

冻结表示线性探针、最近邻分类与端到端微调回答不同问题。探针训练需要标签，但预训练没有使用标签仍可称自监督；必须清楚区分各阶段可用信息。若根据测试标签反复选择预训练超参数或表示层，独立评价就被污染，不能再把最终分数当无偏确认。

<a id="visual-selfsupervisedlearning-01"></a>
### 图解：InfoNCE 的正负样本竞争

![InfoNCE 的正负样本竞争：机制、算例与边界](images/01-concept.svg)

图使用第 4 节的可穷举二值模型，固定锚点 $`X=0`$，正样本条件概率为 $`(0.8,0.2)`$，负样本边缘为 $`(0.5,0.5)`$。候选数 $`N=2`$ 包含正样本。隐藏均匀索引 $`I`$ 后，候选集合的混合概率为

$$
Q(y_1,y_2)=\frac12p(y_1\mid X=0)p(y_2)
+\frac12p(y_1)p(y_2\mid X=0).
$$

例如候选为 $`(0,1)`$ 时，两项联合质量分别为 $`0.2`$ 和 $`0.05`$，总质量 $`0.25`$；因此第一个候选是正样本的后验概率为 $`\frac{0.2}{0.25}=0.8`$。等价地，用密度比 $`r(0)=1.6`$、$`r(1)=0.4`$ 归一化，也得到 $`\frac{1.6}{1.6+0.4}=0.8`$。候选相同时后验只能各半，模型再强也不能从相同观测中辨认索引。

按四种候选的混合质量加权索引条件熵，得到最优损失 $`L^*=0.596774802`$，所以 $`\log2-L^*=0.096372379`$。真实配对互信息却是 $`0.192744757`$ nat；本例中有限候选松弛恰好占去另一半。对称的 $`X=1`$ 给出相同结果。图中底部两段表示信息分解而非概率，详细恒等式在第 11 节证明。

图左每根柱子的两个颜色是隐藏索引的联合质量，四柱合计为1；右图逐柱除以对应混合质量，得到每柱总和为1的后验。两个面板的纵轴对象不同，不能把右侧等高柱误读成四种候选等概率。$`(0,0)`$ 最常见，但两个索引的贡献各为0.2，后验只能各半；$`(0,1)`$ 虽然总质量更小，却因0.2对0.05的不对称证据可以做到80%索引正确。候选常见与索引可分是不同问题。

最优交叉熵不是四个后验熵的等权平均，而是 $`0.4H_b(0.5)+0.25H_b(0.8)+0.25H_b(0.2)+0.1H_b(0.5)`$，其中 $`H_b`$ 用自然对数。逐项加权得到前述 $`0.596774802`$，再从 $`\log2`$ 中减去才形成下界。密度比候选识别的出发点见 [CPC原论文第2.3节及附录A.1](https://arxiv.org/pdf/1807.03748)，本例通过完整枚举把其中的联合分布、后验与期望分别展开。

这种画法把候选生成、最优概率和理论下界接到同一组数字上；温度引起的梯度变化由后面的独立图解说明，语义信息是否保留则由第 12 节二元反例单独检验。

## 2. InfoNCE 作为候选识别任务

<a id="infonce-5"></a>

### 2.1 明确的概率构造

令锚点 X 来自边缘分布，随机索引 I 在 N 个位置上均匀。给定 X 与 I，第 I 个候选来自条件分布 p(y|x)，其他候选独立来自边缘 p(y)，并与锚点无关。模型用分数 f(x,y)构成 softmax，损失是正确索引的负对数概率。N 包含一个正样本，而不是只数负样本。

这个抽样模型是密度比与互信息证明的基础。候选独立性、负样本边缘来源、正样本条件关系以及共享测度都需要明确。实际批内多视图、队列、难负样本和数据去重可能改变这些条件。它们仍可以作为有效训练准则，但原来简单下界证明不能不加修改地照搬。

<a id="infonce-6"></a>

### 2.2 密度比最优分数

相对于所有候选都来自边缘的基准分布，给定索引 I 的候选联合密度只多一个比率 $`r(x,y_I)=\frac{p(y_I\mid x)}{p(y_I)}`$。贝叶斯公式得到正确索引后验为该比率除以所有候选比率之和。因此在分数族足够表达、优化达到总体最优时，指数分数应与这个密度比成正比。

分数可以加一个只依赖锚点的常数而不改变 softmax，所以最优分数不是唯一绝对密度。余弦相似度除以温度是受限参数化，不保证能够精确表达任意对数密度比。有限网络、归一化约束和优化误差都会影响结果。把训练好的相似度直接解释成概率或精确互信息，会超出这个推导。

<a id="infonce-7"></a>

### 2.3 损失的梯度

对候选 logit 的导数为模型预测概率减正确索引指示。正样本受到提高相对分数的激励，负样本按其当前概率获得降低分数的激励。高分负样本通常梯度更大，但如果它实际上共享重要语义，这种激励可能不利于下游。梯度只服务当前候选识别任务，不自动知道语义好坏。

如果分数由归一化向量内积除以温度得到，表示梯度还要乘归一化雅可比与编码器雅可比。不能只从 logit 梯度断言某个样本在特征空间一定朝某固定方向移动。共享参数和批内相互作用会让完整动态更复杂，训练诊断应检查实际表示与独立任务结果。

## 3. 互信息下界的条件与证明

<a id="deep-dive-3"></a>

<a id="infonce-9"></a>

### 3.1 先从分类交叉熵开始

任何预测器的交叉熵不低于正确索引给定锚点和全部候选的条件熵，因此对数 N 减损失不超过该索引与候选集合在给定锚点后的互信息。这个结论首先是一个分类风险关系，成立对象是前面构造的索引识别问题，而不是任意现实语义信息。

再考虑候选集合给定锚点、但隐藏正确索引的混合分布。它相对于全部候选独立边缘基准的密度比为所有候选比率的平均。把索引互信息的对数后验展开，可以得到原始 X 与 Y 互信息减去这个混合分布到边缘乘积基准的平均 KL。后者非负，于是得到通常的 InfoNCE 下界。

<a id="infonce-10"></a>

### 3.2 两层松弛与有限候选上限

第一层松弛来自分数模型没有达到最优索引分类器，第二层来自有限候选混合分布与边缘乘积之间仍有差异。因此损失变化不只反映真实互信息变化，也可能反映分类器能力、候选数量或抽样机制变化。对数 N 减损失最多为对数 N，无法无上限识别很大的互信息。

增加候选数量可能放宽上限并改善某些估计，但也改变计算、梯度和假负例概率。有限批次里真实语义类别数量有限时，更多负样本未必一直帮助下游。不能把理论上界更大直接等同于表示更好，尤其当目标只是保留特定任务因素，而不是最大化所有输入共有信息。

<a id="infonce-11"></a>

### 3.3 批内多视图的限定

若一个批次包含多个源样本，每个源提供两个视图，同源正样本之外的候选可能两两共享另一个源，因而并非全部条件独立。实例无放回抽样也与理想独立边缘有差异。训练损失仍可以精确定义并实际有效，但前面的最简独立候选证明不应被当成该实现逐项无条件认证。

正确做法是区分优化准则与理论解释：说明实际候选机制，再标明哪部分结论需要额外假设或近似。不要为了套一个互信息故事而忽略真实代码。能够指出这层差别，反而更有助于理解不同批次、队列和负样本设计为什么表现不同。

<a id="infonce-12"></a>

## 4. 可运行实验一：有限离散模型的密度比与下界

构造两个二值变量，边缘均匀，匹配概率为零点八。所有候选组合可以穷举，直接计算真实互信息、最优索引损失和下界，不依赖神经网络优化。N 较小时下界严格低于互信息，验证有限候选松弛确实存在。

```python
import itertools
import numpy as np
conditional=np.array([[.8,.2],[.2,.8]])
marginal=np.array([.5,.5])
mi=sum(.5*conditional[x,y]*np.log(conditional[x,y]/marginal[y])
       for x in range(2) for y in range(2))
for N in [2,3,5]:
    loss=0.
    for x in range(2):
        for index in range(N):
            for ys in itertools.product(range(2),repeat=N):
                probability=.5/N
                for j,y in enumerate(ys):
                    probability*=conditional[x,y] if j==index else marginal[y]
                ratio=conditional[x,np.array(ys)]/marginal[np.array(ys)]
                predicted=ratio[index]/ratio.sum()
                loss-=probability*np.log(predicted)
    bound=np.log(N)-loss
    assert -1e-12<=bound<=mi+1e-12
    print('N/optimal loss/InfoNCE bound/true MI',N,loss,bound,mi)
```

真实互信息由固定联合分布决定，不随候选数变化；分类损失与下界却会变化。这个最小例子直接说明，比较不同批次或负样本数的损失值时不能简单断言学到了更多真实信息。应使用共同评价协议，并将候选机制作为实验设置报告。

## 5. 温度、负样本与表示几何

<a id="infonce-14"></a>

### 5.1 温度改变梯度尺度与选择性

较低温度使 softmax 更集中于少量高分候选，同时分数对相似度的导数包含温度倒数，影响梯度幅度。它可能强化困难比较，也可能放大假负例和数值问题。较高温度更平滑，但可能弱化区分。最合适温度与归一化、批次、表示维度和任务有关，不是一个跨数据固定常数。

计算交叉熵应使用稳定 logits 表达式，不要手动指数后再取对数。自相似项必须按损失定义排除，正样本索引必须与拼接顺序一致。许多实现错误不会立即报错，只是把网络训练成识别自己或错误配对。应先用小批次手工列出候选与正确索引，再运行完整训练。

<a id="infonce-15"></a>

### 5.2 假负例是任务相关概念

如果预训练按实例区分，同类不同实例被推开可能提高实例识别，却损害类级聚合。若下游需要区分同类内部身份，这种区分又可能有价值。没有一种负样本机制脱离任务就绝对正确。可以通过有标签诊断集估计同类碰撞，但标签仅用于评价还是用于构造损失，必须明确区分。

去除疑似假负例可能改善语义，也可能错误合并不同因素。难负样本挖掘尤其容易集中到语义相似对象，使这个问题更突出。应比较下游任务、类内变化和实例保留，而不是仅看预训练损失。任何新筛选器也有额外计算与自身错误，需计入系统。

<a id="infonce-16"></a>

### 5.3 对齐与分布扩散

正对齐鼓励同源视图接近，负样本比较常让表示分散。但全局分散不等于语义结构好，随机噪声表示也可以很分散；对齐过强则可能保留共同但无关因素或丢掉必要变化。应同时检查表示方差、距离结构和独立任务，不能只用一个“均匀”图说明成功。

归一化限制向量模长，避免仅通过放大范数降低损失，却也改变可表达分数族。零向量附近的归一化数值需要保护，保护下限应明确。对不同维度比较时，球面几何和距离分布也会变化，不能只调一个温度就假定完全可比。

<a id="visual-detail-selfsupervisedlearning-01"></a>

### 图解：温度改变同一组相似度的竞争强度

![温度改变同一组相似度的竞争强度](images/01-mechanism.svg)

每个面板都完整包含三个候选，固定相似度 $`s=(1,0.8,0)`$，只有第一项是真正配对的正样本。概率为 $`p_j=\frac{\exp(\frac{s_j}{\tau})}{\sum_k\exp(\frac{s_k}{\tau})}`$；对单个查询的损失 $`\ell=-\ln p_1`$，相似度梯度为

$$
\frac{\partial\ell}{\partial s_j}
=\frac{p_j-\mathbf1\{j=1\}}{\tau}.
$$

温度一时，概率约为 $`(0.457329,0.374429,0.168242)`$；温度零点一时，约为 $`(0.880762,0.119198,0.0000399865)`$。虽然低温把正样本概率推高，近负例的相似度梯度却从约 $`0.374429`$ 增到 $`1.191981`$，远负例梯度则从 $`0.168242`$ 降到 $`0.000399865`$。因此“温度低就使所有梯度更大”与“概率更尖锐就一定更好”都不成立。

图中数字是对相似度的导数；回到编码器参数时，还要继续乘相似度对参数的雅可比，批量均值也会引入额外分母。若使用归一化向量，相似度的几何约束同样需要参与反传。温度与难负例权重的关系可对照 [SimCLR 原论文第 5.1 节](https://arxiv.org/html/2002.05709v3#S5.SS1)，但语义假负例是否应被推远仍取决于任务。

## 6. 队列、动量编码器与梯度路径

<a id="sec-5-1"></a>

<a id="infonce-18"></a>

### 6.1 队列保存的是历史表示

队列增加候选数量而不要求同一步都保留完整计算图。常见做法把历史键表示分离，只更新当前查询分支；动量编码器缓慢跟随在线参数，减少键分布快速变化。它改善某些计算折中，却引入陈旧表示、额外状态和动量超参数，不是免费增加独立同分布负样本。

队列数据来源、更新顺序、长度与重复样本都影响实际候选分布。若包含同源或同类对象，假负例关系也改变。理论密度比解释需要重新看实际机制，而不能因为损失仍是交叉熵就忽略历史依赖。评价应把队列额外存储和编码调用计入成本。

<a id="infonce-19"></a>

### 6.2 分离梯度不等于没有训练影响

历史键没有梯度，仍通过分母影响当前查询梯度。停止梯度改变优化路径，而不是把该分支从损失中删除。如果两边都分离，编码器可能完全收不到信号；如果本应分离却保留旧图，可能造成跨步图复用与显存问题。应检查每类参数和张量是否有预期梯度。

动量更新通常不走优化器梯度，而按在线与旧动量参数的加权平均执行。它也需要明确初始化、更新先后和状态缓冲区处理。只冻结权重而不处理归一化运行统计，可能仍改变键函数。完整系统状态比一个参数数组更广，复现时应准确记录。

<a id="infonce-20"></a>

## 7. 可运行实验二：正样本索引与队列梯度

下面先检查一对查询键的交叉熵梯度，再验证历史键分离后没有梯度，而查询仍被完整分母影响。分离并不删除历史候选。代码还为双视图批次构造正确配对索引并屏蔽自相似，避免最常见的索引捷径。

```python
import torch
import torch.nn.functional as F

torch.set_num_threads(1)
torch.manual_seed(311)
query=torch.randn(3,4,dtype=torch.float64,requires_grad=True)
keys=torch.randn(5,4,dtype=torch.float64,requires_grad=True)
labels=torch.tensor([0,1,2])
logits=query@keys.detach().T/.7
loss=F.cross_entropy(logits,labels)
grad=torch.autograd.grad(loss,query,retain_graph=True)[0]
prob=logits.detach().softmax(1)
onehot=F.one_hot(labels,5).to(torch.float64)
manual=(prob-onehot)@keys.detach()/(3*.7)
assert torch.allclose(grad,manual)
assert keys.grad is None
loss.backward()
assert query.grad is not None and keys.grad is None
B=4
z=F.normalize(torch.randn(2*B,6,dtype=torch.float64),dim=1)
similarity=z@z.T/.2
similarity.fill_diagonal_(-torch.inf)
positive=(torch.arange(2*B)+B)%(2*B)
assert torch.all(positive!=torch.arange(2*B))
assert torch.all(positive[positive]==torch.arange(2*B))
assert torch.isfinite(F.cross_entropy(similarity,positive))
print('queue gradient and dual-view positive index checks passed')
```

人工索引测试只验证当前拼接约定，真实分布式实现还要确认跨设备顺序和标签偏移。分布式聚合是否支持梯度也会改变优化：某些接口只返回分离张量，不能默认所有键分支都参与反传。实现细节一旦改变梯度，就属于算法定义，应该在比较中说明。

## 8. 可运行实验三：同类碰撞随负样本数增加

若语义类别均匀且独立抽负样本，K 个候选中至少有一个与锚点同类的概率为一减一减类别倒数的 K 次方。它只描述语义碰撞，不自动等于损害程度；同类不同实例是否应推开取决于下游。实验同时给出公式与独立模拟，避免把更多负样本一概称为更干净监督。

```python
import numpy as np
rng=np.random.default_rng(312)
classes=8;runs=50000
for K in [1,4,16,64]:
    anchor=rng.integers(classes,size=(runs,1))
    negatives=rng.integers(classes,size=(runs,K))
    collision=np.any(anchor==negatives,axis=1).mean()
    theory=1-(1-1/classes)**K
    assert abs(collision-theory)<.015
    print('negatives/semantic collision empirical/theory',K,collision,theory)
```

实际类别不均衡时，应对锚点类别加权，常见类别碰撞更多；难负样本又可能进一步提高相似语义比例。不能直接把均匀独立公式用于所有队列。它的用途是提醒我们候选数同时影响统计上限、计算量和语义冲突，需要在同一任务下综合评价。

<a id="visual-extension-selfsupervisedlearning-01"></a>
### 机制说明：负样本越多，同类碰撞的机会越大

上面的八类实验对应给定锚点类别后，单个独立负样本同类概率 $`p_c=\frac18`$。若 $`K`$ 表示负样本数，则

$$
P(\text{至少一次同类碰撞}\mid c)=1-(1-p_c)^K.
$$

类别不均匀时，总体概率是 $`\sum_c p_c[1-(1-p_c)^K]`$，不能把平均类别概率先塞进幂函数。队列相关、同源重复或无放回抽样也会改变精确公式。同类对象是否应该分开由下游任务决定，碰撞概率本身不等于性能损害。

## 9. 完整人工表示学习实验

<a id="infonce-23"></a>

### 9.1 数据与视图假设

每个源样本有四类语义之一，语义在二维中心附近小幅变化，另有六维大幅无关噪声。增强保留该源的语义坐标并轻微扰动，同时独立重抽六维无关因素。这个规则明确告诉模型哪些因素跨视图稳定，是实验的结构假设。类标签只用于冻结后的独立评价，不进入预训练损失。

训练与测试源独立生成。编码器输出八维表示，投影头再输出八维对比向量，使用双向批内候选交叉熵。每个方向有一个正确同源配对，其他源视图作候选。它是一个具体人工对比目标，不把实际批内相关结构冒称为前面独立候选互信息证明的所有条件完全成立。

<a id="infonce-24"></a>

### 9.2 可运行实验四：训练与冻结评价

```python
import numpy as np
import torch
from torch import nn
import torch.nn.functional as F

torch.set_num_threads(1);torch.manual_seed(313)
centers=torch.tensor([[-1.,-1.],[-1.,1.],[1.,-1.],[1.,1.]])
def dataset(n,seed):
    g=torch.Generator().manual_seed(seed)
    labels=torch.randint(4,(n,),generator=g)
    sem=centers[labels]+.15*torch.randn(n,2,generator=g)
    x=torch.cat([sem,3*torch.randn(n,6,generator=g)],1)
    return x,labels
train,labels=dataset(768,314);test,test_labels=dataset(512,315)
encoder=nn.Sequential(nn.Linear(8,32),nn.ReLU(),nn.Linear(32,8))
head=nn.Sequential(nn.Linear(8,16),nn.ReLU(),nn.Linear(16,8))
opt=torch.optim.Adam(list(encoder.parameters())+list(head.parameters()),lr=.003)
rng=torch.Generator().manual_seed(316)
def views(x):
    semantic=x[:,:2]+.05*torch.randn(len(x),2,generator=rng)
    nuisance=3*torch.randn(len(x),6,generator=rng)
    return torch.cat([semantic,nuisance],1)
def objective(x):
    a=F.normalize(head(encoder(views(x))),dim=1)
    b=F.normalize(head(encoder(views(x))),dim=1)
    logits=a@b.T/.2
    target=torch.arange(len(x))
    return (F.cross_entropy(logits,target)+F.cross_entropy(logits.T,target))/2
with torch.no_grad():before=float(objective(train[:128]))
for _ in range(1400):
    ids=torch.randint(len(train),(128,),generator=rng)
    loss=objective(train[ids])
    opt.zero_grad();loss.backward();opt.step()
with torch.no_grad():
    after=float(objective(train[:128]))
    htrain=encoder(train);htest=encoder(test)
    a=F.normalize(htrain,dim=1);b=F.normalize(htest,dim=1)
    nearest=labels[(b@a.T).argmax(1)]
    knn=float((nearest==test_labels).float().mean())
    raw_nearest=labels[torch.cdist(test,train).argmin(1)]
    raw_knn=float((raw_nearest==test_labels).float().mean())
    # A frozen ridge linear probe; labels enter only here.
    ht=np.c_[htrain.numpy(),np.ones(len(train))]
    he=np.c_[htest.numpy(),np.ones(len(test))]
    target=np.eye(4)[labels.numpy()]
    ridge=np.linalg.solve(ht.T@ht+.1*np.eye(ht.shape[1]),ht.T@target)
    probe=float(np.mean((he@ridge).argmax(1)==test_labels.numpy()))
    std=htrain.std(0,unbiased=False)
assert np.isfinite([before,after,knn,probe]).all() and after<before
assert torch.isfinite(std).all()
print('contrastive loss before/after',before,after)
print('raw/representation nearest-neighbor accuracy',raw_knn,knn,'frozen ridge probe',probe)
print('representation coordinate std',std.tolist())
```

<a id="infonce-25"></a>

### 9.3 实验能证明什么

完整代码给出从数据、视图、损失、优化到冻结评价的链条。它可以证明这个明确增强假设下的小网络学到有用人工表示，不证明任意真实图像增强都保留语义。原始输入的线性可分结构也不是秘密，评价目的在于观察无关噪声被视图机制压低，而非创造一个难以解释的高分。

近邻与线性探针不同：前者直接检验表示距离，后者允许用训练标签拟合一个读出。探针标签没有进入预训练，但测试标签也不能用于选择训练步数和温度。若研究多组超参数，应另设验证集，冻结后才测试。输出标准差只检查部分坍塌信号，不代表语义一定正确。

## 10. 十六道进阶练习与详细答案

<a id="infonce-27"></a>

### 10.1 自监督是否没有先验

不是。视图、掩码、架构、配对与负样本都是结构假设。它们规定哪些信息稳定、哪些变化应忽略。没有人工标签不等于没有监督偏好。应检查这些偏好是否与下游一致，并用消融验证，而不是只凭自监督名称相信泛化。

<a id="infonce-28"></a>

### 10.2 InfoNCE 的 N包括正样本吗

包括。理论候选识别任务在 N 个位置中选一个正确索引，其最大索引熵为对数 N。只把负样本数当 N 会造成常数与上限错位。实际批内双视图还要排除自身，并正确映射正样本索引，最好用小批次手工核对。

<a id="infonce-29"></a>

### 10.3 最优分数是否唯一

不唯一，可以加只依赖锚点的常数而不改变候选 softmax。指数分数与条件边缘密度比成比例是在明确候选模型与足够表达能力下的总体最优结论。有限余弦网络不自动等于精确密度比，也不能把相似度当绝对概率。

<a id="infonce-30"></a>

### 10.4 更低损失是否更多真实互信息

不一定。损失还受候选数量、抽样机制、分类器表达和优化影响。真实联合分布固定时，改变 N 就能改变最优损失与下界。比较表示应使用共同下游和候选协议，准确区分训练准则与互信息估计，避免跨设置直接排序。

<a id="infonce-31"></a>

### 10.5 假负例是不是数学错误

对实例索引任务，同类不同实例仍是不同候选，公式可以完全正确；对语义聚合任务，它可能施加不利激励。应说明任务层次。去除疑似假负例也有误合并风险，需要独立评价，不是越多过滤越好。

<a id="infonce-32"></a>

### 10.6 温度越低越好吗

不是。低温强化少量高分比较并放大梯度，也可能放大假负例、噪声和数值不稳定。温度需与归一化、批次和任务共同选择。应比较实际独立任务与训练稳定性，不能只看损失值，因为损失尺度本身已经变化。

<a id="infonce-33"></a>

### 10.7 自相似为何要排除

若允许锚点把自己当候选，模型可能利用恒等关系取得捷径，而非识别另一个增强视图。具体是否排除由目标定义决定，常见双视图损失应屏蔽对角并保留对应正样本。索引错误可能静默运行，必须用断言核对。

<a id="infonce-34"></a>

### 10.8 队列键无梯度是否没作用

仍通过分母影响查询梯度。停止梯度只改变参数更新路径，不删除候选。若两边都分离可能断训练，若历史图未分离可能错误跨步反传。应检查查询、在线键与动量键各自预期梯度，不能只看损失有限。

<a id="infonce-35"></a>

### 10.9 更多负样本是否总帮助

不总。它提高候选难度和某些理论上限，也增加计算、历史陈旧和同类碰撞。下游可能受语义冲突影响。应固定预算比较并报告实际候选机制，而不是把数量当唯一质量旋钮。人工碰撞公式只是一个可解释诊断。

<a id="infonce-36"></a>

### 10.10 投影头能否保证 h不丢信息

不能。它提供另一个优化空间，可能帮助某些任务，但编码器仍由同一训练目标驱动。需要分别评价 h 和 z，固定读取与探针规则。事后对每个方法挑最佳层会增加选择预算，最终测试应独立确认。

<a id="infonce-37"></a>

### 10.11 线性探针是否仍是无标签评价

不是，探针使用标签，只是预训练不使用。这个协议合理，但必须分阶段说明。探针数据、正则与选择预算要固定，测试标签不能参与调参。端到端微调则是另一能力，不能与冻结探针混为同一成绩。

<a id="infonce-38"></a>

### 10.12 对齐很好是否表示有用

常数表示也能完美对齐，却没有区分信息。负样本可限制某些坍塌，但语义质量还需要独立任务。表示分散也不够，随机噪声可以分散。应结合方差、秩、距离结构和任务评价，不能只用单个几何现象证明成功。

<a id="infonce-39"></a>

### 10.13 难负样本为何要谨慎

它们梯度大但也更可能共享语义或来源。改变候选来源会改变最优密度比及理论解释。应说明采样分布与是否校正，检查下游、假负例与成本。困难不是天然有益属性，必须与任务相关。

<a id="infonce-40"></a>

### 10.14 同整数种子是否严格公平

不同方法会改变随机数消费、批次与更新，整数相同不等于轨迹相同。可以共享数据划分、预先安排视图或任务实例，明确配对层次。公平还包括计算、调参和探针预算，不由一个种子自动保证。

<a id="infonce-41"></a>

### 10.15 表示标准差非零是否排除坍塌

只排除全部常数的一部分情形。表示可能只沿一个方向变化，或主要编码无关噪声。应检查奇异值、有效秩与独立任务。维度坍塌和语义失败可以在各坐标标准差都不零时存在，不能把简单监控当完整认证。

<a id="infonce-42"></a>

### 10.16 一个可信对比学习报告最少写什么

数据独立单位、视图关系、候选机制、损失索引、温度、梯度路径、预算、读取层和评价协议都需明确。还要报告种子与失败、语义碰撞和成本。理论前提与实际实现的差异应直说，不把所有交叉熵都无条件叫互信息估计。

<a id="infonce-43"></a>

## 11. 把互信息证明写成完整概率等式

<a id="infonce-44"></a>

### 11.1 候选混合分布

本节的有限数值等式假设配对联合分布对边缘乘积分布绝对连续，且 $`I(X;Y)<\infty`$、相关分类交叉熵有限。于是条件密度比与后面各个差值有合法含义。离散有限且相关边缘质量为正的实跑例子满足这些条件；连续变量的无噪声确定性配对则未必满足，不能只因网络输出是实数就自动沿用密度比代数。

用 $`P_Y^N`$ 表示所有候选都独立来自边缘的基准分布。给定锚点 x 而隐藏正确索引时，候选集合密度为 $`Q_x(y_{1:N})=[N^{-1}\sum_ir(x,y_i)]\prod_jp(y_j)`$。它是一个真实归一化混合分布，因为每个比率在对应边缘下期望为一。这个定义使后面的非负项有清楚概率意义，而不是仅靠一句 Jensen 略过。

最优索引后验是 $`\frac{r_I}{\sum_jr_j}`$，所以索引互信息为期望对数 $`\frac{Nr_I}{\sum_jr_j}`$。其中对数 rI 的期望恰好是原始配对联合分布的互信息；对数平均比率的期望则是 $`E_XD_{\rm KL}(Q_X\Vert P_Y^N)`$。于是前面两者之差给出精确分解。

<a id="infonce-45"></a>

### 11.2 模型分类误差的额外间隙

任意模型分数的交叉熵还可以分解为真实索引条件熵，加上真实索引后验到模型 softmax 的条件 KL。把它与候选混合分解合并，便得到“真实互信息减下界”由两个非负项组成：有限候选混合项和分数模型分类项。这比把所有差距都叫估计误差更清楚。

例如 $`X`$ 在单位区间连续均匀、$`Y=X`$ 时，联合分布集中在对角线，而边缘乘积给该对角线概率零，互信息为无穷。把二者各自等宽离散成 $`m`$ 个格点后，互信息为 $`\log m`$；固定候选数的 InfoNCE 数值仍最多为 $`\log N`$。这说明有限候选分类目标不能数值恢复这种发散互信息，也不能把无穷互信息和无穷混合 KL 写成未经定义的相减。用于表示学习的有限分类损失仍可计算，但本节精确分解应在所述有限性条件下解释。

增加编码器容量可能减小分类项，却不自动消除有限候选项；增加候选数改变混合项，同时也改变分类难度与计算。改变视图则直接改变原始配对分布和真实互信息。三种操作影响不同层次，不能在一张损失曲线里不加区分地解释为同一种进步。

<a id="infonce-46"></a>

### 11.3 理论下界也可能为负

随机或很差的分类器损失可能大于对数 N，使对数 N 减损失为负。互信息本身非负，这并不矛盾，只说明这个下界很松。把负下界截成零可以作为展示选择，却改变统计量，不能据此声称估计器已经准确。训练初期的负值更不表示数据存在负互信息。

有限样本损失还带抽样波动，单批下界数值可能偶然超过某个真实参照；理论通常讨论相应总体期望和抽样条件，而非每个批次必然成立。离散实验通过穷举消除了这层波动，真实神经训练则需要独立重复与明确评价，不能把一个批次数值当作定理反例。

<a id="infonce-47"></a>

## 12. 视图设计与信息不可恢复

<a id="infonce-48"></a>

### 12.1 数据处理关系

如果视图由原始样本经过随机变换产生，表示又由视图确定，那么处理链限制可保留信息。某个任务标签信息若已经被视图删除，后面的编码器无法凭空恢复。增加网络规模或负样本数量不会改变这个基本事实。成功来自视图与任务结构合适，而不是自监督目标拥有超越数据的信息来源。

例如方向决定类别时，随机旋转并要求旋转不变，可能把不同类别合并。颜色决定病理或材料属性时，强颜色抖动也可能删除关键因素。常见图像增强的经验有效性依赖具体数据，不能从一个通用名称推出所有领域都安全。应构造任务相关反例并分层评价。

<a id="infonce-49"></a>

### 12.2 不变性与等变性

有些任务希望忽略变换，有些希望表示随变换按已知方式变化。把位置或方向全部压成不变，可能不适合检测、姿态或物理建模。可以设计等变目标、局部表示或多头结构，但它们有不同假设与成本。不能把分类表征的成功直接等同于所有空间任务的成功。

视图还可能只共享背景或设备特征，模型便容易利用这些捷径。正样本确实同源并不保证共享信息就是语义。需要检查表示对背景、来源与目标因素的敏感性，并用来源独立划分避免测试也保留同样捷径。仅随机切分图像文件可能让同一来源泄露到两侧。

<a id="infonce-50"></a>

### 12.3 增强强度的双重风险

过弱增强让实例细节与无关噪声跨视图稳定，容易学捷径；过强增强可能使正样本不再共享任务信息。最合适强度是数据与任务相关折中，而不是越难越好。可以逐项消融，记录预训练损失、表示几何和下游各类任务，观察收益究竟来自哪些变化。

如果根据测试集反复调增强，最终高分反映了监督开发，而不是完全独立自监督泛化。这并不使方法无用，但应准确记录选择过程。保持独立验证与测试，并给各方法相同搜索预算，才能让比较有清楚含义。

### 图解推导：增强保留一比特，为什么仍可能丢掉全部语义

![增强保留一比特，为什么仍可能丢掉全部语义](images/01-augmentation-semantic-information.svg)

令真实语义 $`Y`$ 和背景位 $`Z`$ 是两个独立公平硬币。第一种视图机制保留同一 $`Y`$，但独立重抽背景：$`V_1=(Y,Z_1)`$、$`V_2=(Y,Z_2)`$。两视图共享的只有一比特语义，所以 $`I(V_1;V_2)=H(Y)=1`$ bit。取共享表示 $`R=Y`$，左图只有两点，各占一半，语义可被无误读取。

第二种机制保留背景，却把语义坐标分别随机化：$`V_1=(Y_1,Z)`$、$`V_2=(Y_2,Z)`$，其中新随机位独立于原始真实标签。此时两视图互信息仍是一比特，来自 $`Z`$；取共同表示 $`R=Z`$，得到右图四个等概率点。给定任一表示值，真实标签仍各半，因此任何分类器的最佳错误率都是 $`0.5`$，不限于线性探针。

两机制拥有同样的视图互信息，却把不同因素留给一致性或对比目标。第二种机制甚至从输入视图中删掉了原标签信息：$`I(Y;V_i)=0`$。后续增加模型容量、负样本数或训练时长，都不能从独立变量恢复被删除的总体信息。图展示的是信息不可恢复，不是某次优化失败。

这也不意味着增强越弱越好。第一种若连背景也共享，会保留额外干扰；第二种过强增强则破坏任务。应把希望不变的因素、希望保留的因素及目标任务写清，再设计消融。视图选择依赖下游任务的机制见 [Tian 等《What Makes for Good Views for Contrastive Learning?》第 3—4 节](https://arxiv.org/html/2005.10243v3)，图的二元分布是可枚举的独立反例。

## 13. 负样本来源改变了什么

<a id="infonce-52"></a>

### 13.1 非边缘负分布的密度比

若负样本来自另一个独立参考分布 n(y)，索引分类的最优密度比变为条件正分布除以 n，而非除以真实边缘。对应目标仍可训练，但与原始互信息的关系多了参考分布差异。若 n 还依赖锚点，例如难负挖掘，候选联合机制更复杂，不能直接沿用简单独立边缘证明。

**把“多了分布差异”定量写出来。** 设负样本独立来自 $`n(y)`$，并且在正样本可能出现的地方 $`n(y)>0`$。沿用本章候选数 $`N`$ 包含一个正样本的约定，最优分类分数对应密度比 $`\frac{p(y\mid x)}{n(y)}`$。此时能够直接证明的是

$$
\log N-L_{N,n}\le D_{\mathrm{KL}}(P_{XY}\Vert P_Xn)
=I(X;Y)+D_{\mathrm{KL}}(P_Y\Vert n),
$$

其中 $`L_{N,n}`$ 是该候选生成机制下模型的总体交叉熵，单位为 nat。右端第二个等号来自 $`\log[\frac{p(y\mid x)}{n(y)}]=\log[\frac{p(y\mid x)}{p(y)}]+\log[\frac{p(y)}{n(y)}]`$ 后对联合分布取期望；假设相关散度有限，便可将两项分开。

第一个不等式也有完整来源。令 $`Q_j`$ 表示第 $`j`$ 个候选是正样本的联合分布，$`\bar Q=N^{-1}\sum_jQ_j`$，参考分布为 $`R=P_X\prod_i n(Y_i)`$。KL 的混合分解给出

$$
\frac1N\sum_jD_{\mathrm{KL}}(Q_j\Vert R)
=\frac1N\sum_jD_{\mathrm{KL}}(Q_j\Vert \bar Q)
+D_{\mathrm{KL}}(\bar Q\Vert R).
$$

左边等于 $`D_{\mathrm{KL}}(P_{XY}\Vert P_Xn)`$，右边第一项等于候选索引与全部观测的互信息。任意分类器的交叉熵不少于条件熵，因此 $`\log N-L_{N,n}`$ 不超过这个索引互信息；再舍去非负的最后一项，即得结论。可见推导仍然成立，只是它控制的散度已经改变。

**零互信息却出现正数的反例。** 让 $`X`$ 与二值 $`Y`$ 独立，$`P_Y=(0.5,0.5)`$，故 $`I(X;Y)=0`$；取 $`n=(0.9,0.1)`$，并令 $`N=2`$。两个类别的最优密度比分别为 $`\frac{5}{9}`$ 和 $`5`$。按“正样本类别、负样本类别”枚举，类别相同的总概率为 $`0.5`$，分类损失为 $`\log2`$；正零负一的概率为 $`0.05`$，正确索引概率为 $`0.1`$；正一负零的概率为 $`0.45`$，正确索引概率为 $`0.9`$。于是

$$
L^*_{2,n}=0.5\log2-0.05\log0.1-0.45\log0.9
\approx0.509115,
$$

故 $`\log2-L^*_{2,n}\approx0.184032>0`$。这不违反理论，因为 $`D_{\mathrm{KL}}(P_Y\Vert n)=\log(\frac{5}{3})\approx0.510826`$：分类器只需识别正负来源的边缘分布差异，就能优于随机选择，完全无需锚点信息。若仍把这个正数当成真实互信息下界，就会得出错误结论。

若已知边缘 KL，可以从上述界中扣掉它得到合法但可能很松的互信息下界；实际高维资料中这项通常也需要估计，不能默认免费已知。仅把分数改写成另一密度比，而不改变候选采样及归一化，也不自动恢复原来的候选机制。若负采样还依赖锚点，则必须重新定义完整条件生成分布与相应参考散度。

可以有意改变 n 以提高任务区分，但需明确是否进行校正，以及目标已经变成什么。难度与理论解释是不同问题：一个更有用工程目标不必强行维持同一个 MI 故事。准确说明分布变化，能帮助分析何时会过度强调少数相似对象或产生语义冲突。

<a id="infonce-53"></a>

### 13.2 类别不均衡与碰撞

类别概率不均匀时，给定锚点类别 c，K 个独立负样本至少一次同类的概率是一减一减该类概率的 K 次方；再按锚点类别概率加权得到总体。常见类别更容易碰撞，罕见类别则可能在候选和训练中证据不足。总体平均损失可能掩盖类间差异。

实际训练通常不知道真实语义标签，可以在独立诊断集上分析，而不把标签偷偷用于预训练过滤。若使用标签或伪标签改变目标，就明确方法已经加入额外信息与错误来源。伪标签可靠度、类别分布与确认偏差都需要评价，不能把它当免费消除假负例的工具。

<a id="infonce-54"></a>

### 13.3 去重与数据单位

同一记录的近重复、同一人的不同照片、同一文档切片可能在批次中互作负例，也可能泄露到评价两侧。数据清理与划分应围绕来源单位，不是只按文件名。去重规则本身需要固定，避免根据某方法结果事后删除不利数据。

无放回批次、跨设备聚合和队列中的重复访问都会影响候选依赖。规模大时可以把某些差异视作近似，但应说明何时近似合理，而不是声称完全独立。对理论与实现的准确区分，会让读者更容易理解结果范围与潜在失败条件。

<a id="infonce-55"></a>

## 14. 队列与动量的计算折中

<a id="infonce-56"></a>

### 14.1 历史分布与陈旧误差

队列键由过去参数编码，与当前查询函数存在偏差。动量更新让变化更平滑，但过慢也会增加滞后。队列更长增加候选和存储，也可能保留更陈旧分布。长度、动量与学习率应共同讨论，不能把每个历史键都当成当前网络独立采样的同等信息。

如果分数关于参数变化有合适局部稳定性，可以尝试界定陈旧表示带来的 logit 变化；但神经网络全局常数可能很松，不能只写一个 Lipschitz 词就宣称误差受控。实际诊断可以比较同一源当前与历史编码的相似度、年龄分层损失和下游结果，形成可检验假说。

<a id="infonce-57"></a>

### 14.2 更新顺序与状态

应明确先计算当前键再动量更新，还是先更新参数再编码，以及入队发生在损失前还是后。顺序改变可能使当前正样本重复进入候选，或让队列含有不同版本表示。初始化时空队列或随机队列也影响早期目标，不能省略。代码测试应包含队列未满、回绕与重复源情况。

归一化缓冲区、随机增强和分布式批统计也属于键函数状态。动量权重不代表所有状态自动平滑，冻结梯度不代表运行统计冻结。复现记录应包括这些细节。若不同实现使用不同状态路径，结果差异未必来自论文中强调的核心机制。

<a id="infonce-58"></a>

### 14.3 全成本比较

批内双向对比需要多个视图编码与相似度矩阵，矩阵内存随批次平方增长。队列减少某些保图需求，却增加历史存储与键编码。跨设备聚合还有通信。比较应报告源样本数、视图数、编码调用、候选数、更新数与硬件条件，不能只比较优化步数。

更大批次与更多负样本常同时改变训练统计、计算与优化日程。若某方法使用十倍资源后更好，应如实报告质量成本折中。采样与队列机制有价值，但没有一种设计可以把所有额外计算都视作免费理论收益。

<a id="infonce-59"></a>

## 15. 冻结表示评价的统计逻辑

<a id="infonce-60"></a>

### 15.1 线性探针的能力与限制

线性探针检验标签信息是否容易被线性读取，但它依赖训练标签量、正则、特征标准化和偏置项。一个强非线性下游模型可能恢复线性探针看不到的信息，端到端微调又会改变表示。三种协议都可以有价值，但不能混为一个表征质量真值。

探针正则应在验证集选择，特征标准化只用探针训练数据拟合。测试集用于最后确认，不参与挑读取层或训练轮数。若不同方法各自拥有不同探针搜索预算，最后最好分数不完全可比。应报告选择成本与完整协议，而非只列一个准确率。

<a id="infonce-61"></a>

### 15.2 来源独立与任务多样

随机样本划分可能让背景、身份或设备来源同时出现在训练和测试，使捷径看起来像泛化。来源组划分能够检验更严格外推，但也改变目标难度，应明确说明。多个下游任务有助于看到保留信息的取舍，不能从单一分类任务推断所有结构都学好了。

人工实验中标签由前两维中心决定，增强明确保留它们，因此高分是可解释预期。真实数据没有这么清楚的可分结构，需要领域约束与错误案例。不要把教学实验的满分当成通用表征学习已经解决，也不要因为原始数据简单就忽略它对实现验证的价值。

<a id="infonce-62"></a>

### 15.3 种子与评价样本

固定编码器后大量测试样本降低该模型准确率的估计噪声，不能代替多次独立预训练。训练种子、视图随机性和数据来源都可能改变结果。方法比较应保留多个预设运行，报告逐任务与种子差异，不删除失败。相同整数种子仅是记录手段，不自动解决配对依赖。

本章完整实验使用固定预设种子与末次网络，目的在于机制核验。若研究温度、负样本数或增强强度，应在独立开发集安排相同搜索预算，再用新训练种子和测试源确认。理论解释、实现检查与方法稳定性是不同证据层。

<a id="infonce-63"></a>

## 16. 可运行实验五：高互信息可以只来自无关因素

构造语义标签与来源编号独立，两个视图都只保留来源编号、完全删除标签。来源视图之间互信息很高，候选识别也容易，但语义信息严格为零。这个有限枚举反例不需要训练，直接反驳“对比目标成功就必然学到所需语义”。

```python
import numpy as np
M=16
# All class/identifier combinations are equally likely.
joint=np.full((2,M),1/(2*M))
p_class=joint.sum(1);p_identifier=joint.sum(0)
mi_class=sum(joint[c,u]*np.log(joint[c,u]/(p_class[c]*p_identifier[u]))
             for c in range(2) for u in range(M))
mi_views=-np.sum(p_identifier*np.log(p_identifier))
logits=12*np.eye(M)
log_denominator=np.log(np.exp(logits).sum(1))
loss=np.mean(log_denominator-np.diag(logits))
assert np.isclose(mi_class,0)
assert np.isclose(mi_views,np.log(M))
assert loss<.001
# Each identifier leaves the class exactly balanced.
assert np.allclose(joint/joint.sum(0),.5)
print('view MI/class MI/identifier contrastive loss',mi_views,mi_class,loss)
```

若数据划分让同一来源编号对应的标签偶然固定，探针可能在同源测试上表现很好，掩盖这种语义缺失。独立来源与明确因子生成是发现捷径的关键。这个反例也解释为什么需要同时审视视图和评价：仅优化损失或仅看一个泄露划分的下游分数都可能误导。

## 17. 表示几何与维度诊断

<a id="infonce-65"></a>

### 17.1 方差、协方差与有效秩

各坐标标准差非零不排除所有变化集中在一个方向。中心化表示矩阵的奇异值可以揭示低秩结构，协方差谱可看出是否少数方向主导。有效秩有多种定义，应注明归一化与阈值。它们描述表示分布几何，不直接证明语义可用，噪声也可能占据很多维。

样本量小于表示维度时，经验协方差天然秩亏，不能把所有零特征值都解释成训练坍塌。应固定样本量、特征尺度和中心化规则，并结合理论最大秩。比较不同维度时尤其要谨慎，维数越大不一定保留更多任务信息，也可能只增加无关方向。

<a id="infonce-66"></a>

### 17.2 距离与读取层

余弦、欧氏距离和归一化后的欧氏距离具有不同几何。训练在归一化 z 上进行，评价在未归一化 h 上近邻，二者并非同一空间。这个选择可以合理，但应明确。对某方法先选最有利距离、另一方法使用默认值，会增加不公平选择自由度。

距离可视化也有降维失真，二维图中簇分开不证明高维所有邻域关系准确。应以可复核数值与任务指标为主，图形作为辅助。看到混合不一定是失败，某些连续因素本来就应该连续；看到清晰簇也可能只是来源或背景分组。解释必须回到数据因素和目标。

<a id="infonce-67"></a>

### 17.3 正负关系的局部检查

可以记录正对相似度、同类不同源相似度、异类相似度以及来源相同但语义变化的案例。标签只用于诊断时应明确，不能偷偷把它反馈到预训练选择又称完全无监督。局部检查有助于发现假负例与捷径，但总体结论仍需要独立样本与预设协议。

若某增强使正对相似度提高却下游下降，应检查是否删掉任务因素；若负相似度降低却噪声敏感性变高，可能只是学会区分无关细节。指标矛盾可以转化为具体假说，而不是挑选有利项结束讨论。深入学习的关键在于理解这些机制之间的约束。

<a id="infonce-68"></a>

## 18. 三个逐步深入的研究项目

<a id="infonce-69"></a>

### 18.1 增强与语义保留

保持人工因子生成机制不变，分别重抽无关噪声、重抽部分语义、保留共享无关编号。比较预训练损失、近邻、冻结探针和来源独立测试。这样可以把视图是否保留任务信息与编码器优化分开。预先规定因素、评价与预算，避免看结果后再决定哪个因素叫语义。

进一步加入连续任务，例如预测中心偏移，检查类别满分是否掩盖细粒度丢失。一个增强可能改善类别不变性却损害位置或幅度估计，这是真实取舍，不需要强行判为某方法全面失败。报告应展示不同任务的能力边界，训练读者按应用选择表示。

<a id="infonce-70"></a>

### 18.2 候选数与碰撞折中

固定总编码调用预算，改变批内候选或队列长度，记录损失、同类碰撞、下游与存储。若候选更多但训练步数更少，结果反映资源折中，不应只归因于负样本数量。可以在已知类别分布下计算碰撞参照，再研究不均衡与难负样本。

若采用标签过滤作为理想上界，应清楚标成使用额外监督，不能与无标签方法不加说明地比较。伪标签过滤则需要记录错误和更新路径。最有价值问题是某机制在什么数据分布和预算下帮助，在哪些条件下引入新的语义冲突。

<a id="infonce-71"></a>

### 18.3 历史键与优化路径

比较当前双分支梯度、分离键、动量键与不同队列年龄，固定数据与相似度目标。检查各参数梯度、历史表示偏移、下游和全成本。先在小网络上完整记录，再扩展到复杂系统。若性能变化来自归一化状态或更新顺序，应把它作为发现，而非全部归给动量概念。

每个项目都应保留负结果和多个训练种子，采用固定开发与确认协议。一个看似简单的对比损失包含很多概率与工程选择，逐层消融比一次加入所有技巧更容易得到解释。研究不是让每个实验都成功，而是让证据能够支持或推翻具体假说。

<a id="infonce-72"></a>

## 19. 梯度、温度与归一化的进一步推导

<a id="infonce-73"></a>

### 19.1 相同表示也能得到更低损失

假设正相似度为零点八，唯一负相似度为零点六。温度零点二时，正确概率是 logistic 一，损失约零点三一三；温度零点一时，正确概率是 logistic 二，损失约零点一二七。表示完全没变，仅温度改变，损失已经显著下降。因此跨温度比较训练损失大小，不能直接解释为语义质量或信息量改善。

对相似度的梯度还包含温度倒数，但预测概率也随温度变化。上述例子中，正相似度梯度绝对值从约一点三四五变到一点一九二，反而略小。低温放大某个显式因子，不代表完整梯度必然更大。应同时看概率集中与缩放，这也是不能只凭一个链式因子解释整个训练动态的例子。

<a id="infonce-74"></a>

### 19.2 归一化的切空间梯度

对非零向量 h，归一化 u 为 h 除以模长，其雅可比为单位矩阵减外积 uu 转置，再除以模长。它把梯度投影到球面切空间，径向变化不直接改变相似度。模长仍会影响有效梯度尺度，所以未归一化表示范数不是完全无关的隐藏量。不同网络或优化器可能通过范数变化改变学习动态。

零向量附近使用数值下限会改变这条公式的局部行为，需要检查梯度而非仅看输出归一化成功。若参数全部为零，某些结构可能停在退化点；随机初始化与归一化并不构成全局避免坍塌证明。下一章将进一步讨论没有负样本时的退化与结构条件，本章也不能把负样本视为任意实现都不坍塌的保证。

<a id="infonce-75"></a>

### 19.3 单个负样本的作用依赖其他候选

某个负样本的 logit 梯度等于它在全部候选中的 softmax 概率，所以同样相似度在不同分母下贡献不同。增加大量低分候选与增加一个高分候选对梯度影响不同；重复候选也会增加相应区域总权重。负样本数量不是充分描述，还应考虑分数分布、重复与来源。

这有助于理解为什么队列陈旧、类不均衡和难负采样会改变结果。它们不只是让 N 更大，还改变分母中概率质量分配。分析时可以按候选类型汇总梯度权重，检验训练是否主要在推远某一类无关或同类对象，再通过独立任务确认这种作用是否有益。

<a id="infonce-76"></a>

## 20. 数据来源变化与可迁移性

<a id="infonce-77"></a>

### 20.1 同分布测试与来源外推

若训练和测试共享相同设备背景，模型可能依靠来源因素得到高分。来源独立测试更能检验是否保留目标语义，但难度与目标也随之改变。应同时说明训练来源、测试来源和允许的信息，不把一个划分上的收益扩大成所有域都有效。域外表现需要实际证据，而不是从自监督名称推导。

本章人工数据把无关六维在视图中独立重抽，明确帮助模型忽略它们。如果部署无关因素分布变化，表示可能比原始距离更稳，但这仍要通过预设扰动评价确认。若部署变化直接影响语义坐标，增强不一定有帮助。鲁棒性应按变化类型定义，不能只报一个总体词。

<a id="infonce-78"></a>

### 20.2 多任务与信息取舍

保留类别、身份、位置、颜色和细粒度幅度可能互有冲突，尤其表示维度有限或目标强制不变时。一个任务探针高分不证明所有因素都存在。可以构造多个已知因子任务，冻结同一编码器评价，展示哪些信息被保留、哪些被压低。这样更接近理解表示，而不是寻找一个绝对排名。

如果下游允许端到端微调，大量标签与计算可能弥补预训练缺失，但这又是另一预算与信息条件。应比较相同标签量与优化成本，报告从头训练基线。不能把微调后分数全部归因于自监督预训练，也不能忽略预训练本身的资源。

<a id="infonce-79"></a>

### 20.3 标签泄露与开发反馈

即使预训练损失没有直接标签，反复用测试标签选择增强、温度和训练轮数，也会间接引入监督反馈。正确做法是开发与确认分离，公开候选与选择预算。若任务就是利用少量标签指导自监督设计，可以明确称为相应协议，没有必要通过模糊术语掩盖信息来源。

数据去重、探针训练与特征标准化也可能泄露。只要某个统计量从测试来源拟合，就需要说明它是否在部署可获得。表示评价应把整个流程作为对象，而不只检查编码器那一行代码有没有读取标签。完整信息流是可靠比较的基础。

<a id="infonce-80"></a>

## 21. 五个实跑实验怎样相互补充

离散候选枚举中真实互信息约零点一九二七，候选数二、三、五的最优下界约零点零九六四、零点一二九五与零点一五五五。它们严格低于同一真实值，展示有限候选松弛。梯度实验通过解析查询导数、键分离与双视图索引检查，说明实现路径与定义一致，而不声称真实任务最优。

八类均匀语义下，负样本数一、四、十六、六十四的同类碰撞模拟分别约百分之十二点三、四十一点五、八十八点四和九十九点九九，接近理论。它不直接量化损害，却明确揭示更多负样本同时带来的语义冲突机会。实际不均衡与难负机制还需要重新计算。

人工完整训练的损失由约五点零三四五降到二点四七八六；原始输入近邻准确率约百分之五十六点八，冻结表示近邻与 ridge 探针在这次独立源测试上均为一。数据结构与增强清楚保留类别，因此满分是机制验证，不是现实图像基准。多个坐标方差非零只说明部分几何，不能替代已报告的独立任务。

无关编号反例则得到视图互信息约二点七七二六、语义互信息零、编号对比损失约零点零零零零九二。它与完整训练成功并不矛盾：两者视图保留的信息不同。这个对照说明，自监督的能力来自概率机制与任务结构的配合，而不是一个损失名字自动产生语义。

阅读后续论文时，可以先核对视图、候选与梯度，再看理论前提与实际实现差异，最后看独立评价、预算和失败。能够沿这条链条提出具体反例，才真正把 InfoNCE 从公式变成可理解、可实现和可质疑的研究工具。

<a id="infonce-81"></a>

## 22. 语义完美仍可能不是实例损失最优

<a id="infonce-82"></a>

### 22.1 同类候选造成的不可区分性

假设一个表示只保留类别，同类所有实例映射成完全相同向量。给定锚点，若候选里共有 m 个同类对象，其中仅一个被指定为正样本，那么任何仅使用这个类别表示的分数都无法区分它们。即使所有异类分数被压到极低，正样本概率也至多为一除以 m，对应损失至少为对数 m。

这说明一个在下游分类上已经完美的表示，仍可能通过保留同类实例细节继续降低对比损失。降低损失不一定意味着类别信息变得更多，也可能只是增加身份、纹理或连续偏移。若下游需要这些细节，可以有益；若希望更强语义不变性，则可能不是目标。训练与评价对象的差异在这里具有直接数学解释。

<a id="infonce-83"></a>

### 22.2 如何解释本章人工结果

人工源的语义坐标不仅含四类中心，还含每个源固定的小连续偏移，两个增强视图保留这个偏移。因此模型可以同时识别类别与部分源内细节，不能把全部损失下降解释为只学了四类。冻结分类满分只检验类别读取，尚未证明编码器完全抛弃所有无关噪声，也未全面量化连续因素保留。

进一步可以冻结编码器，分别对类别、连续偏移和六维原始噪声拟合读出，并用新源测试。这样能具体检验哪些因素被压低，而不是从一个好看的近邻分数推断所有内部机制。若增加此类探针，应固定正则与选择预算，避免因尝试很多读出后只报告最有利结果而制造解释偏差。

<a id="infonce-84"></a>

### 22.3 一个更成熟的结论方式

合理结论是：在明确保留类别和源偏移、重抽无关因素的视图机制下，这次小网络训练得到了可线性读取类别且距离结构有用的人工表示；同时，理论与反例显示目标可以依赖其他共有信息，实际应用必须验证视图假设。这样的表述既不否定实跑成功，也不把成功扩大为普遍语义保证。

本章五段代码分别检验理论候选、梯度索引、语义碰撞、完整训练和捷径反例。所有代码独立执行，不生成中间文件。先复现原设置再逐项修改，保留负结果，能够让后续问题沿着已经核对的逻辑继续展开，而不是停留在算法缩写与单一分数。

复现记录还应保留正样本生成时是否共享随机种子、源编号与增强参数。如果两个视图意外复用了全部噪声，它们可能几乎相同，训练便不再检验预期不变性；如果配对顺序被打乱，正样本可能完全无关。两种错误都可以产生有限损失，却对应不同任务。小批次逐对检查通常能很快发现。

最终报告不必展示每条内部日志，但应给出足够证据让人区分正确目标、有效优化和独立泛化。把这些层次整理清楚，能够满足深入学习的需要，也为下一章讨论非对比坍塌与掩码目标提供可靠参照：去掉负样本之后，仍需回答保留什么信息、如何防止退化以及怎样确认有用。

每个新的技巧都应对应一个明确失败机制，并通过独立消融核验。若证据只来自人工数据，就保留这一限定，不把解释性实验包装成真实领域结论。
