## 1. 流匹配先选择概率路径，再学习速度

流匹配从一个易抽样的起点分布走向目标数据分布，学习确定速度场，使一条常微分方程推动密度沿预设路径演化。训练不必逐次求解这条生成 ODE，而是从可计算条件路径抽时刻和位置，回归相应条件速度。生成时仍需要求解 ODE，不能把“训练无需模拟轨迹”误写成“生成无需积分”。

本章时间 t从零的噪声走向一的数据，与上一章前向扰动时间相反。不同方向本来都合法，但速度、端点和代码必须一致。我们以独立噪声与人工双峰数据的线性插值为主线，完整推导连续性方程、条件到边缘速度、平方回归目标和端点，再运行低维网络与独立采样。

<a id="flow-matching-2"></a>

### 1.1 密度路径不等于粒子配对

选择每个时间的边缘密度是一件事，选择哪一个起点粒子与哪一个终点样本配对是另一件事。不同耦合可以拥有相同两端分布，却产生不同中间路径、条件速度和回归难度。独立配对最容易抽样，不保证最短搬运；更有结构耦合可能减少某些速度方差，却需要额外计算或假设。

条件直线也不代表学到的边缘 ODE每条轨迹都是同一条直线。条件路径可能交叉，网络只看到当前位置和时间时，需要对各种来源速度取条件平均。实际确定流在适当唯一性条件下不能让同一时刻同一点分叉成两条不同未来。理解这个区别，是避免把训练可视化误当生成轨迹的关键。

<a id="flow-matching-3"></a>

### 1.2 速度、得分与噪声输出

速度描述密度怎样搬运，得分描述当前对数密度的空间梯度。某些高斯路径中二者可以通过明确时间系数联系，但不是同一个对象。网络输出变量不同，训练标签、时间权重与采样公式也不同，不能只替换名字。上一章概率流是从 SDE通量得到的一种速度，本章可以直接从条件路径构造速度。

“流”还可能指可逆离散网络、连续归一化流或一般概率路径，术语相似不等于完全同一模型。应先写出起点、目标、时间边缘、速度和密度变换，再讨论训练效率与质量。模型名称不能替代数学定义。

## 2. 连续性方程从守恒推导

<a id="flow-matching-5"></a>

### 2.1 测试函数形式

设粒子满足 $dX_t/dt=v_t(X_t)$，对光滑紧支撑测试函数 phi，链式法则给出期望变化率为期望下梯度 phi与速度的内积。把期望写成密度积分，再分部积分移走梯度，得到 $\partial_tp_t+\nabla\cdot(p_tv_t)=0$。边界通量和可交换条件需要适当控制。

这条方程表达概率质量守恒，不是说每个位置的密度不变。质量可以被压缩、扩张和搬运，总积分保持一。若边界有流出或密度不具普通光滑形式，需要弱解或相应边界条件，不能不加说明地使用最简单全空间推导。

<a id="flow-matching-6"></a>

### 2.2 沿轨迹密度变化

把连续性方程展开并沿粒子轨迹求导，得到对数密度导数为负散度。可逆光滑流因此通过累积局部体积变化连接两端密度。起点密度已知且积分准确时，可以评价该流定义的密度，但网络误差、散度估计和求解误差仍需考虑。

这个关系也说明一般速度不必是梯度场。只要它推动合适密度并满足流存在条件，就可定义生成机制。要求每个速度都等于某个对数密度梯度会不必要限制表达，也会混淆上一章的得分与本章的搬运速度。

<a id="flow-matching-7"></a>

### 2.3 非唯一速度与附加选择

同一密度路径可以容许多个速度，只要差异通量散度为零。某些附加准则如动能、轨迹长度或耦合结构可以选择其中一种。不能从“满足连续性方程”直接推出速度是唯一或最优。最优传输需要明确成本、空间和耦合条件，不是所有直线路径自动满足。

因此学习目标应说明它对应哪种条件构造与边缘速度。不同路径之间比较时，不能只看最终边缘相同就认为训练任务完全相同；也不能只因条件标签更简单就断言数值生成一定更容易。

## 3. 条件路径怎样产生边缘速度

<a id="deep-dive-3"></a>

<a id="flow-matching-9"></a>

### 3.1 混合密度与混合通量

设条件变量 C具有固定分布，每个条件路径密度 $p_t(x\mid c)$ 满足自己的连续性方程，条件速度为 u。对条件积分，边缘密度是条件密度平均，边缘通量是条件密度乘速度的平均。若密度和导数允许交换，就得到边缘速度

$$v_t(x)=E[u_t(X_t,C)\mid X_t=x].$$

权重是给定当前位置后的条件责任，不是简单对所有条件速度等权平均。某个位置更可能来自哪种条件，决定网络应该怎样组合速度。这个公式与高斯混合得分的责任加权相似，却描述不同向量对象。

<a id="flow-matching-10"></a>

### 3.2 条件回归与边缘回归等价

对任意候选场，条件速度平方误差可按给定当前位置的条件均值分解。第一项是候选场到边缘速度的误差，第二项是条件标签的不可约方差，与网络参数无关。因此直接回归可计算条件速度与回归未知边缘速度拥有同一总体最优。

这不意味着单次条件标签就是真实边缘速度，更不意味着训练误差必须为零。多个不同条件路径可以穿过同一点并给出不同方向，网络只能学习条件平均。过拟合有限配对标签可能降低训练误差却损害总体流，应使用独立配对与解析参照检查。

<a id="flow-matching-11"></a>

### 3.3 时间与损失权重

时间抽样分布和正权重决定各时刻误差被强调的程度。在每个时间均有正权重、表达无限且优化理想时，点态最优仍是同一条件均值；有限网络与有限预算下，权重会改变折中。若想保持某个积分目标而非均匀时间，应作相应抽样校正。

不能把不同时间权重的损失数值直接排序，也不能把更容易端点占比更高的低损失称为所有位置更准确。应分时间评价，并使用共同采样协议比较最终分布。训练目标、有限函数逼近与部署求解是三个需要分开的层次。

## 4. 独立端点的线性插值

<a id="flow-matching-13"></a>

### 4.1 从端点对直接构造标签

抽 $X_0$ 来自简单噪声、$X_1$ 来自数据，规定 $X_t=(1-t)X_0+tX_1$。给定端点对，路径导数为 $X_1-X_0$，无需运行生成 ODE。训练输入为当前位置和时间，标签为这条条件路径速度。端点耦合可以独立，也可以有结构，必须明确。

给定固定数据端点时，起点高斯使中间条件密度为均值 t乘端点、标准差一减 t的高斯。对应条件速度可写为端点减当前位置再除以一减 t；与端点对导数相同。但接近一时分母趋零，直接用端点差标签通常更稳定，不能因为形式上有除法就认为边缘速度必然发散。

<a id="flow-matching-14"></a>

### 4.2 高斯端点的解析边缘

若起点标准正态、目标为均值 m、方差 s平方的高斯，独立插值边缘均值为 tm，方差为一减 t的平方加 t平方乘 s平方。边缘速度为均值导数 m，加方差导数除以两倍方差乘当前位置偏离均值。它同时搬运均值与调整尺度，不只是固定向 m移动。

目标为高斯混合时，每个分量按这个公式演化，再按当前位置的分量责任平均速度。这个解析式可以验证条件回归与连续性方程，也能作为神经网络误差参照。全局平均分量速度会丢模式，正如上一章全局平均混合得分不正确。

<a id="flow-matching-15"></a>

### 4.3 两个端点的真实含义

在零端，边缘恰好是选定噪声；在一端，边缘恰好是目标数据，只要耦合确实具有这些边缘。条件密度在一端可能退化为点，但对数据端积分后的边缘仍可能光滑。条件表示奇异与边缘密度奇异不是同一概念，应逐个判断。

若目标本身是离散点或低维流形，光滑可逆流在有限时间内严格映射连续全维噪声到奇异目标，需要注意正则性与端点极限。训练可以近似这些对象，但不能同时无条件宣称全程 Lipschitz可逆且零误差到达奇异端点。

## 5. 可运行实验一：条件均值与连续性方程

下面用单高斯端点核对解析速度。联合高斯条件期望给出的端点差回归，与边缘均值方差速度形式一致。再对密度时间导数和通量空间导数做有限差分，检验连续性方程符号。每段代码独立执行，不依赖上一章变量。

```python
import numpy as np
m=1.5;s=.4
def density(x,t):
    mean=t*m;var=(1-t)**2+t*t*s*s
    return np.exp(-.5*(x-mean)**2/var)/np.sqrt(2*np.pi*var)
def velocity(x,t):
    mean=t*m;var=(1-t)**2+t*t*s*s
    derivative=-2*(1-t)+2*t*s*s
    return m+derivative/(2*var)*(x-mean)
x=np.linspace(-2,4,101);h=1e-5
for t in [.1,.5,.9]:
    var=(1-t)**2+t*t*s*s
    cov_ux=t*s*s-(1-t)
    conditional=m+cov_ux/var*(x-t*m)
    assert np.allclose(conditional,velocity(x,t))
    dt=(density(x,t+h)-density(x,t-h))/(2*h)
    dx=(density(x+h,t)*velocity(x+h,t)-density(x-h,t)*velocity(x-h,t))/(2*h)
    assert np.max(np.abs(dt+dx))<2e-6
assert np.allclose(density(x,0),np.exp(-x*x/2)/np.sqrt(2*np.pi))
print('conditional mean and continuity finite differences passed')
```

这个核验把条件标签、边缘速度与密度方程闭合起来。若采样结果不符，可以分别检查哪一层，而不是直接把所有偏差归到网络容量。有限差分只验证当前光滑例子和容差，端点或奇异数据仍需不同处理。

## 6. 可运行实验二：条件直线不等于边缘轨迹

起点与终点都为标准正态且独立，条件路径都是直线，中间边缘方差却先缩到二分之一再回到一。边缘速度在中点为零，单条条件路径速度仍有方差。确定 ODE可以把每个粒子先缩后放，最终回到自己的起点，而不是走向训练配对的那个独立终点。

```python
import numpy as np
rng=np.random.default_rng(411)
n=150000
x0=rng.normal(size=n);x1=rng.normal(size=n)
t=.5
xt=(1-t)*x0+t*x1;u=x1-x0
assert abs(xt.var()-.5)<.01
assert abs(np.mean(u))<.02
assert abs(np.mean(u*xt))<.02
assert abs(np.mean(u*u)-2)<.03
# An analytic marginal trajectory preserves its own ordering.
particle=np.array([-2.,-.4,1.,2.])
for time in [0.,.25,.5,.75,1.]:
    var=(1-time)**2+time**2
    transported=np.sqrt(var)*particle
    assert np.all(np.diff(transported)>0)
assert np.allclose(np.sqrt((1-1.)**2+1.**2)*particle,particle)
# Two conditional straight paths can cross with opposite velocities.
assert .5*(-1)+.5*1 == .5*1+.5*(-1) == 0
assert (1-(-1)) == 2 and (-1-1) == -2
print('midpoint variance/conditional-label MSE at zero predictor',xt.var(),np.mean(u*u))
print('marginal flow endpoint is identity, unlike arbitrary training pairs')
```

这个反例还说明条件回归最优损失不必为零。网络不看到端点身份，只看到当前位置和时间，相反来源速度会被条件平均。增加容量无法恢复不存在的来源信息；若把端点直接作为输入，训练任务又改变，不能再当作无条件生成场。

## 7. 完整人工流匹配训练

<a id="sec-5-1"></a>

<a id="flow-matching-19"></a>

### 7.1 数据、网络与独立评价

源为标准正态，目标为等权中心负二和正二、局部标准差零点三的混合。每步独立抽端点对和时间，直接回归端点差。网络只输入中间位置与时间特征，不看端点或类别。验证端点、时间固定且独立于训练随机流，训练预算预先固定，不依据测试选择轮数。

生成用同一网络从标准正态零端积分到一端，采用 Heun方法。报告模式占用、中心邻域、均值和二阶矩，同时保留偏差。目标分布已知，可以比较解析边缘速度，后续研究应分离学习误差和求解误差，而不是只要求样本看起来双峰。

<a id="flow-matching-20"></a>

### 7.2 可运行实验三：训练与生成全链条

```python
import math
import numpy as np
import torch
from torch import nn

torch.set_num_threads(1);torch.manual_seed(412)
class Velocity(nn.Module):
    def __init__(self):
        super().__init__()
        self.net=nn.Sequential(nn.Linear(4,48),nn.SiLU(),nn.Linear(48,48),
                               nn.SiLU(),nn.Linear(48,1))
    def forward(self,x,t):
        return self.net(torch.cat([x,t,torch.sin(math.pi*t),torch.cos(math.pi*t)],1))
model=Velocity();opt=torch.optim.Adam(model.parameters(),lr=.002)
rng=torch.Generator().manual_seed(413)
def batch(n,g):
    source=torch.randn(n,1,generator=g)
    sign=2*torch.randint(2,(n,1),generator=g)-1
    target=2*sign.float()+.3*torch.randn(n,1,generator=g)
    t=torch.rand(n,1,generator=g)
    return (1-t)*source+t*target,t,target-source
xv,tv,uv=batch(4096,torch.Generator().manual_seed(414))
def evaluate():
    with torch.no_grad():return float((model(xv,tv)-uv).square().mean())
before=evaluate()
for _ in range(4000):
    x,t,u=batch(256,rng)
    loss=(model(x,t)-u).square().mean()
    opt.zero_grad();loss.backward();opt.step()
after=evaluate()
with torch.no_grad():
    sample=torch.randn(3000,1,generator=torch.Generator().manual_seed(415))
    steps=200;h=1/steps
    for k in range(steps):
        t=torch.full_like(sample,k*h)
        first=model(sample,t)
        proposal=sample+h*first
        sample+=h*(first+model(proposal,t+h))/2
    positive=float((sample>0).float().mean())
    near=float(((sample.abs()-2).abs()<.8).float().mean())
assert math.isfinite(after) and after<before and torch.isfinite(sample).all()
print('fixed validation conditional velocity MSE',before,after)
print('sample positive/near/mean/second moment',positive,near,
      float(sample.mean()),float(sample.square().mean()))
print('target mean/second moment',0.,4.09,'network calls',2*steps)
```

<a id="flow-matching-21"></a>

### 7.3 训练误差的不可约部分

验证条件速度误差包含网络到边缘速度的误差，以及给定中间点后端点差仍不确定的方差。不能把最终 MSE全部解释成网络没学好。若有解析边缘场，可以直接计算前一项，再用二者差诊断不可约部分。不同耦合改变条件标签方差，因此条件损失跨耦合也不能简单排序。

每步从已知机制重新抽样是持续数据供应，和固定有限训练集不同。本实验不检验记忆或数据清洗，只检验定义清楚的函数学习与生成流程。若扩展真实数据，应另外处理来源划分、重复和任务评价，不把人工双峰结果夸成通用生成能力。

## 8. 密度与可逆性的解析核验

<a id="flow-matching-23"></a>

### 8.1 光滑有限时间流的限制

若速度足够正则、解唯一且存在于整个时间区间，确定流在合适条件下给出可逆映射。不同初始粒子不能在同一时刻合并后再按不同未来分开，因为那会违反唯一性。这与可交叉的条件训练路径不冲突，后者不是同一个边缘 ODE解族。

若目标严格奇异，映射可能需要端点极限、无限曲率或正则性失效。近似生成到窄高斯或正噪声数据通常避开部分问题，但应该准确说明。不能一方面要求全程有界 Lipschitz可逆，另一方面宣称有限时间把全维连续噪声精确压成有限点。

<a id="flow-matching-24"></a>

### 8.2 可运行实验四：高斯流密度与次序

对独立高斯端点路径，解析边缘轨迹是均值加标准差乘原始标准化坐标。散度积分等于标准差比对数，密度变化可精确核对。代码同时检查次序保持，说明边缘粒子映射不等于独立训练端点配对。

```python
import numpy as np
from scipy.integrate import quad
m=1.5;s=.4
def var(t):return (1-t)**2+t*t*s*s
def divergence(t):return (-(1-t)+t*s*s)/var(t)
source=np.array([-2.,-.5,0.,1.,3.])
target=m+s*source
lp0=-.5*np.log(2*np.pi)-.5*source**2
lp1=-.5*np.log(2*np.pi*s*s)-.5*((target-m)/s)**2
integral,error=quad(divergence,0,1,epsabs=1e-11)
assert np.isclose(integral,np.log(s))
assert np.allclose(lp1,lp0-integral)
assert np.all(np.diff(target)>0)
for t in [0.,.3,.8,1.]:
    point=t*m+np.sqrt(var(t))*source
    assert np.all(np.diff(point)>0)
print('divergence/log standard-deviation ratio',integral,np.log(s),
      'quadrature error estimate',error)
```

解析高斯的密度核验不代表已计算神经双峰网络的精确似然。一般神经流需要同步积分散度，高维常用随机迹估计，数值容差和初始密度也要计入。把“方法可评价密度”与“本实验实际评价了哪条密度”分开，是可靠报告的一部分。

## 9. 十六道进阶练习与详细答案

<a id="flow-matching-26"></a>

### 9.1 流匹配是否生成无需 ODE

不是。训练可从条件路径直接抽样，不必每步运行生成积分；采样仍要解学到的 ODE或使用另行训练的加速映射。训练方便不等于生成免费，需报告函数调用和求解器。把两个阶段混同会误导成本比较。

<a id="flow-matching-27"></a>

### 9.2 为什么时间与上一章相反

本章从噪声零端走向数据一端，上章先定义数据到噪声扰动。两种约定都正确，只要速度、端点和积分方向一致。比较公式前应先代入起点终点，不能仅凭正负号不同判断矛盾。代码应明确这一点。

<a id="flow-matching-28"></a>

### 9.3 条件速度能否等权平均

一般不能。边缘速度是给定当前位置后的条件期望，权重来自条件路径责任。简单全局平均可能抵消模式结构。高斯混合提供可解析反例，应先核对通量混合再实现网络，避免把每个条件出现概率误当当前位置责任。

<a id="flow-matching-29"></a>

### 9.4 条件 MSE为何不降到零

同一中间点可以对应不同端点对与速度，网络只看到位置和时间，无法识别单次来源。最优是条件平均，仍有不可约方差。应区分边缘场学习误差和条件标签噪声，不用零训练误差作为唯一正确性标准。

<a id="flow-matching-30"></a>

### 9.5 直线条件路径是否直线生成

不是。交叉条件路径在同一位置可能给相反速度，边缘 ODE回归其平均。确定流的唯一性约束与条件配对不同。本章相同标准正态两端例子中，边缘流先缩后放并回到自身，而非到训练随机终点。

<a id="flow-matching-31"></a>

### 9.6 独立耦合是否最优传输

不自动。它满足端点边缘，但搬运成本和路径方差可能很大。最优传输需要明确成本与可行耦合集。某些结构或重配对可改善特定准则，也有额外计算。不能把线性插值这个形式直接等同全局最优。

<a id="flow-matching-32"></a>

### 9.7 速度是否一定是得分

不是。速度描述搬运，得分是当前对数密度梯度。特定高斯路径下可用时间系数联系，但一般速度不必保守。换输出参数化要改目标与采样公式，不可只换变量名字。连续生成方法之间应按数学对象比较。

<a id="flow-matching-33"></a>

### 9.8 条件端点奇异是否边缘也奇异

不一定。给定数据点的条件路径在终点退化，但对连续数据端积分后边缘可以光滑。若数据本身离散或流形，情况又不同。需要逐层判断，不能从条件方差零直接推所有边缘理论失效，或反过来忽略真实奇异端点。

<a id="flow-matching-34"></a>

### 9.9 末端除一减 t是否一定发散

条件公式形式上有小分母，但沿一致端点对，分子也按相应方式缩小，标签可等于有限端点差。边缘速度是否有界取决于路径和目标。实现直接使用端点差可减少不必要数值消减，但不能替代对端点正则性的分析。

<a id="flow-matching-35"></a>

### 9.10 更小步长能否修复网络

只能更准确跟随当前学到的场，不能自动改正错误速度或耦合假设。应先冻结解析场检查求解，再固定求解研究学习。把网络、步数与路径同时改，结果难以归因。完整误差需要分层。

<a id="flow-matching-36"></a>

### 9.11 相同端点是否同样难学

不。不同中间路径与耦合改变速度幅度、条件方差、曲率和训练分布。最终目标相同不代表训练任务与有限求解成本相同。应比较共同预算与独立分布结果，不能只凭两端一致忽略路径选择。

<a id="flow-matching-37"></a>

### 9.12 低条件损失是否更好生成

跨耦合不一定，条件标签不可约方差本身会变化。某构造损失低可能只是标签更确定，最终场误差或求解仍不好。应使用边缘场参照和共同采样评价。指标对象清楚，才能解释真正收益。

<a id="flow-matching-38"></a>

### 9.13 可逆流能否任意合并粒子

在足够光滑唯一解条件下不能同一时刻合并后再分叉。奇异端点或非唯一场需要另行讨论。条件训练路径可以交叉，不是同一个边缘解族，所以不矛盾。把这两种轨迹混为一谈会产生错误直觉。

<a id="flow-matching-39"></a>

### 9.14 公式有密度是否实测似然

不。神经流还需积分散度，处理初始密度、数值和随机迹误差。本章高斯解析密度只是独立机制核验，完整双峰训练只报告采样统计。方法潜在接口与实际执行范围应分别说明。

<a id="flow-matching-40"></a>

### 9.15 模式均值正确够吗

不。错误单峰也可以均值零，需要模式占用、局部质量和二阶矩等补充。任何单指标都有盲区。已知人工真分布可以进一步测分位数或距离，真实应用还要条件与任务评价，不把一个好数字当全部证明。

<a id="flow-matching-41"></a>

### 9.16 一个可信流匹配报告写什么

端点分布、耦合、路径、条件速度、时间抽样、权重、网络输入、预算、求解与评价都需明确。保留训练种子和负结果，区分条件标签、边缘场、粒子轨迹与密度。每项结论应有对应证据，不能只用流这个名称概括全部机制。

<a id="flow-matching-42"></a>

## 10. 一般条件高斯路径与非零末端噪声

<a id="flow-matching-43"></a>

### 10.1 均值和尺度都可以选择

给定目标条件 z，构造 $X_t=\alpha(t)z+\sigma(t)\epsilon$，其中标准高斯噪声与条件独立。沿固定条件和噪声求导，速度为 alpha导数乘 z加 sigma导数乘噪声。在 sigma为正时，可用当前位置消去噪声，得到 sigma对数导数乘 x，加上修正后的 z系数。

这个公式展示路径选择怎样进入标签。均值插值相同但尺度日程不同，条件速度与边缘几何就不同。不能只报告“高斯路径”而省略 alpha、sigma和端点。若 sigma在端点为零，条件表达可能奇异，需要分析极限或使用原始端点差形式，而非随意裁掉分母。

<a id="flow-matching-44"></a>

### 10.2 末端小噪声改变目标分布

可以让末端 sigma保留一个正下限以改善数值。若末端 alpha为一，生成目标就变成数据与该高斯噪声的卷积，而不是严格原数据。对于方差已知人工目标，二阶矩会增加对应噪声方差；模式也会变宽。这个选择可以合理，但必须按实际平滑目标评价。

如果采样后再做去噪或投影，最终生成器又改变。条件均值去噪未必保留完整分布，硬投影可能堆积边界质量。应报告后处理及其失败、成本和目标，而不是用平滑路径理论解释另一个未经定义的结果。

<a id="flow-matching-45"></a>

### 10.3 时间重参数化

把旧时间记为 $t$，新时间记为 $s$，取严格递增、可微且 $\phi(0)=0,\phi(1)=1$ 的变换 $t=\phi(s)$。若原轨迹满足 $dX_t/dt=v_t(X_t)$，定义 $Y_s=X_{\phi(s)}$，链式法则给出

$$
\frac{dY_s}{ds}=w_s(Y_s),\qquad
w_s(x)=\phi'(s)v_{\phi(s)}(x),\qquad
\widetilde p_s=p_{\phi(s)}.
$$

它保持同一批粒子的几何轨迹与端点，只改变沿轨迹行进的快慢。条件训练标签也必须乘 $\phi'(s)$，只替换网络的时间输入而保留旧速度标签，通常就不是这条重新计时的路径。以下先假设 $\phi'(s)>0$，避免在零导数点直接相除。

训练目标的变化可以精确求出。若用 $\widehat w_s=\phi'(s)\widehat v_{\phi(s)}$ 参数化候选场，令 $E_t=E\|\widehat v_t-u_t\|^2$ 为原条件回归误差，则均匀抽新时间得到

$$
\int_0^1 E\|\widehat w_s-\phi'(s)u_{\phi(s)}\|^2ds
=\int_0^1\phi'(\phi^{-1}(t))E_t\,dt.
$$

因为平方误差带两次导数因子，而换元只抵消一次。若想精确保留原来的 $\int E_tdt$，应在新目标中再乘 $1/\phi'(s)$；如果网络参数化并非上述对应形式，还需重新核对函数族与优化。保留每个时刻的总体最优场，不等于保留有限容量网络对不同时刻的权衡。

**同一条直线的手算。** 原过程 $X_t=t$，速度恒为一。取 $\phi(s)=(s+s^2)/2$，新速度为 $w_s=1/2+s$，积分仍给终点一；但从零开始只做一次显式 Euler，旧时间得到一，新时间只得到 $1/2$。变化来自离散求解对时间日程的依赖，并非连续轨迹不等价。若原误差 $E_t$ 恰为常数 $c^2$，均匀新时间的损失为 $c^2\int_0^1(1/2+s)^2ds=13c^2/12$，再按上述权重校正才回到 $c^2$。

时间分配可以用于调整回归尺度和求解网格，但这三者应分别记录。所选日程的效率仍需在共同端点质量、函数调用与训练预算下比较；看到同一连续曲线，不能直接推断离散采样器的误差相同。

<a id="flow-matching-46"></a>

## 11. 耦合、最优传输与路径整直

<a id="flow-matching-47"></a>

### 11.1 一维高斯的两种明确耦合

源为标准正态，目标为均值 m、标准差 s的高斯。独立耦合把两个端点独立抽样，条件直线的平均平方位移为 m平方加一加 s平方。单调仿射耦合把目标设为 m加 s乘同一个源，则平均平方位移为 m平方加 s减一的平方，少了两倍 s。

两种耦合具有完全相同端点分布，却有不同中间方差与标签方差。在这个一维平方成本设置中，单调耦合具有最优传输意义；这来自明确成本与一维结构，而不是因为所有线性插值都最优。换成多维、多峰或受约束空间，需要重新说明相应条件。

<a id="flow-matching-48"></a>

### 11.2 条件直线与边缘动能

条件路径速度平方的期望不小于给定当前位置的平均速度平方期望，差正是条件速度方差。边缘平均会消去部分互相抵消运动，所以条件标签动能与实际边缘流动能也不相同。不能用训练端点差平均平方直接冒充生成轨迹的完整路径成本。

另一方面，任一确定轨迹的端点位移平方受积分速度平方控制，端点分布的最优搬运成本提供另一种下界。把这些层次区分开，才能判断某种耦合真正改善了什么：可能降低条件回归噪声，可能缩短边缘路径，也可能只是改变优化尺度。它们不应被混称为同一种“更直”。

<a id="flow-matching-49"></a>

### 11.3 一维相同终点映射仍可有不同中途轨迹

光滑一维确定流保持次序，给定连续源与目标时，单调端点映射由分位数关系决定。因此独立高斯插值学到的边缘流和仿射最优耦合可以拥有同样端点映射，却沿不同中间方差路径走。前者可能先缩后放，后者标准差线性变化。端点一致不代表轨迹成本一致。

这个例子帮助避免把“生成样本终点一样”解释成训练路径无关。有限网络、求解器和调用预算都会受到中间曲率影响。比较路径方法时，应同时看边缘场误差、条件方差和实际积分成本，而不是只看最终目标名称。

<a id="flow-matching-50"></a>

### 11.4 重新配对与 reflow的边界

可以用已学模型把源推到生成端，形成新的耦合，再用这些端点训练更整直路径。这类程序改变了训练配对与可能的数值难度，但新终点来自旧模型，不自动等于真实数据。若旧模型遗漏模式，重新配对不会凭空创造缺失质量，可能继续继承偏差。

路径更直也不等于一 Euler步必然足够。速度仍可能随位置与时间变化，网络近似和端点误差仍在。若另行蒸馏成少步或一步映射，应报告额外训练、目标与独立质量，而不是把原始流匹配直接称为免费一步生成。

<a id="flow-matching-51"></a>

## 12. 非唯一边缘速度的二维反例

<a id="flow-matching-52"></a>

### 12.1 静止正态与旋转正态

二维标准正态可以由零速度保持，也可以由一个反对称矩阵乘 x的旋转速度保持。旋转矩阵迹为零，速度与密度梯度内积也为零，因此概率通量散度为零。粒子不断旋转，密度却始终不变。这与上一章平稳 SDE和静止概率流不同，展示同一连续性方程本身也可能有不同确定速度。

零速度具有零动能，旋转速度有正动能，说明仅满足相同边缘并不代表最小成本。若额外要求梯度势、最小能量或特定耦合，才可能选出更特定解。理论结论应准确说明附加准则，不把一个自然构造误称唯一。

<a id="flow-matching-53"></a>

### 12.2 对训练目标的含义

条件路径决定的回归目标会选出某个特定边缘平均速度。即使其他速度也满足相同边缘方程，它们不一定最小化当前条件 MSE。目标定义因此不仅指定两端，也隐含中间运动方式。改变条件构造，是改变学习问题，而不是同一公式的无关实现替换。

在真实高维任务中，这种自由度可能带来效率机会，也可能让解释变难。应先在可解析模型中区分密度、通量与轨迹，再讨论复杂路径。只画从噪声到数据的箭头，无法表达这些重要差异。

<a id="flow-matching-54"></a>

### 12.3 边界条件与全局存在

局部光滑速度不保证所有轨迹在有限区间都存在，过快增长可能使解逃向无穷，边界也可能产生质量流失。连续性方程的形式计算需要配合增长、可积与边界条件。神经网络输出有限的几个测试点，不等于全局存在性已经认证。

实际采样可以监测非有限值和尾部，但这些是有限诊断。若使用裁剪、反射或投影保护，要明确它们改变了动力学。理论流与程序实际过程必须对应，否则密度评价与采样解释可能各自正确却不属于同一个系统。

<a id="flow-matching-55"></a>

## 13. 误差分解与确定流稳定性

<a id="flow-matching-56"></a>

### 13.1 五层误差

端点分布或数据模型不准确、条件路径构造改变目标、网络边缘速度逼近不足、ODE数值离散，以及有限样本评价，都是不同误差来源。训练更久只可能解决其中一部分。减小步长不能修正错误端点，改耦合也不自动改善网络表达。研究应先定位层次，再选择干预。

人工模型可以先用解析速度高精度求解，检验路径与求解；再用学习速度替换，观察新增误差；最后改变端点或耦合，研究构造差异。这样的顺序比一次换所有组件更容易得到可解释结论，也能保留负结果的研究价值。

<a id="flow-matching-57"></a>

### 13.2 轨迹误差的积分界

设近似速度满足合适状态 Lipschitz条件，比较真实与近似轨迹时，差的增长可由同一点速度差加 Lipschitz倍位置差控制。积分并应用 Gronwall，可得初值误差和沿参照路径速度误差的指数加权界。这个推导说明曲率与时间长度可能放大误差，但常数过大时界也可能很松。

训练 MSE是某个路径分布平均，不直接给出所有位置的统一误差界。若生成轨迹偏离训练常见区域，网络可能外推错误。要把平均训练误差转成分布保证，需要额外覆盖、稳定与可积条件，不能只引用一个积分不等式就宣称所有样本准确。

<a id="flow-matching-58"></a>

### 13.3 条件标签噪声与学习误差

条件回归目标分解中的不可约项依赖耦合和时间，不同路径可能天然有不同最低损失。因此比较最终训练 MSE时，应尽量用解析边缘场或共同下游分布指标补充。一个路径条件损失更小，不必然代表它的边缘场更准；一个更大损失也可能主要来自不可识别端点来源。

完整双峰实验的验证误差约二点三八五，不被解释为全部网络不足。下一步可以穷举或解析计算边缘速度，直接评估网络到它的误差，再与条件误差比较。这个诊断能把优化方向从盲目追求零损失转向真正相关的场精度。

<a id="flow-matching-59"></a>

## 14. 解析双峰边缘速度

<a id="flow-matching-60"></a>

### 14.1 每个分量的均值与尺度

记目标分量为 $X_1\sim N(m,\sigma^2)$，其中本章 $m=\pm2$、$\sigma^2=0.09$，源 $X_0\sim N(0,1)$ 与目标独立。线性插值 $X_t=(1-t)X_0+tX_1$ 的分量均值为 $m_t=tm$，方差为 $v_t=(1-t)^2+t^2\sigma^2$。分量速度可从条件均值直接求得，而不必先猜某个满足连续性方程的场。

令路径标签 $D=X_1-X_0$，则 $E[D]=m$，且 $\operatorname{Cov}(D,X_t)=t\sigma^2-(1-t)$。$D$ 与 $X_t$ 联合高斯，使用[高斯条件化](../../Mathematics/Probability/03-联合分布边缘化与条件期望.md)公式得到

$$
u_t^{(m)}(x)=E[D\mid X_t=x,m]
=m+\frac{t\sigma^2-(1-t)}{v_t}(x-tm)
=m+\frac{v_t'}{2v_t}(x-tm).
$$

最后一个等号使用 $v_t'=-2(1-t)+2t\sigma^2$，说明“均值速度加尺度变化速度”的表达与条件路径回归完全一致。取 $m=2,t=0.5$，有 $v_t=0.2725$，所以速度为 $2-1.66972477\ldots(x-1)$；分量均值处 $x=1$ 以速度二移动，偏离均值的粒子还受到尺度收缩项影响。只输出均值的导数二会漏掉分布方差的变化。

在 $t=0$ 时分量速度为 $m-x$；在 $t=1$ 且 $\sigma^2>0$ 时为 $x$，两个分量都有限。这也可由条件标签核对：在源端固定 $X_0=x$，独立目标均值为 $m$；在目标端固定 $X_1=x$，独立源均值为零。给定单个目标点的路径公式可能含 $1/(1-t)$，但对仍有正方差的整个目标分量条件化后，有限分母是 $v_t$，不能把前者的端点奇异性原样套到边缘速度。

边缘速度再按给定位置的混合责任加权。靠近某个分量时，它占主导；在中间区域，责任变化快，速度可具有较大空间导数。这个结构说明为什么模式分配与局部求解精度有关，也提供独立于训练的函数参照。

<a id="flow-matching-61"></a>

### 14.2 零端和一端的检查

零端所有分量位置分布相同，责任回到先验权重，边缘速度反映平均目标与源收缩。对于对称双峰，它在零端是负 x。接近一端，数据本身仍有正方差，边缘速度可以保持有限，即使给定单个目标点的条件方差趋零。不能把条件分母小直接当作边缘必发散的证明。

若目标方差也趋零，曲率和端点正则性会改变，需重新分析。小方差高斯近似离散数据不是完全相同对象。应说明最终评价针对哪一层平滑，避免把一个数值保护悄悄变成无关细节。

<a id="flow-matching-62"></a>

### 14.3 条件轨迹交叉的作用

独立配对会让许多直线穿过同一位置，速度标签冲突明显。边缘平均可以产生有序确定流，但局部条件方差很大。更结构化耦合可能降低冲突，也可能增加计算。不能从一张交叉图就断言方法无法学习，也不能从最终采样好看就忽略训练难度。

可以按时间统计条件速度方差，研究难度集中在何处，再设计抽样或权重。若改变权重，使用共同评价判断收益。理论直觉应变成可测量假说，而不是仅用图形替代证据。

<a id="flow-matching-63"></a>

## 15. 求解器、密度与实际调用

<a id="flow-matching-64"></a>

### 15.1 训练无需模拟不代表求解无误差

流匹配直接抽条件点，避免训练时每步穿过生成求解器；但生成仍要沿网络场积分。网络误差和求解误差相互作用，某些路径较直或平滑可能更省调用，但必须实际验证。不能只凭训练标签简单就推断采样一步足够。

Heun每步两次调用，Euler每步一次，自适应方法调用不固定。比较时报告实际函数评价数、批次和输出维度。相同循环数不代表相同成本，实际硬件时间还受网络结构与内存影响。一维 CPU数字不能直接外推到图像或大型模态系统。

<a id="flow-matching-65"></a>

### 15.2 密度追踪需要额外计算

要评价神经流密度，需要沿轨迹积分散度。高维雅可比迹可能用随机探针估计，带来方差；求解位置与密度状态的容差也要控制。起点密度与预处理雅可比必须一致。拥有密度公式不等于每个实验已经执行了完整似然评价。

本章高斯散度核验是解析机制测试，双峰网络只报告采样统计。若后续加入神经散度评价，应另列实现、探针数与数值稳定，不能沿用解析代码输出冒充网络精度。方法接口和实际结果的完成范围需要准确对应。

<a id="flow-matching-66"></a>

### 15.3 端点外推与时间网格

网络训练时间在零到一内，求解器的中间评价也应在定义范围内。某些高阶方法或错误步长可能越过端点，触发未训练外推。固定网格最后一步要精确落在一，不要因为浮点累计让时间略超。端点条件若特殊，应明确处理。

本章使用按整数步构造时间，Heun末点评价对应下一网格，保持范围。更复杂自适应设置也需要同样检查。数值保护可以合理，但不应掩盖模型在端点是否定义良好。

## 16. 与连续得分模型怎样比较

<a id="flow-matching-68"></a>

### 16.1 共同密度语言与不同监督

上一章从随机扰动和得分推导概率流，本章从条件路径速度回归。两者可以通过连续性方程在某些路径上联系，但训练标签、权重与端点未必相同。不能把一个未加权速度 MSE与噪声 MSE直接按数值比较，二者包含不同条件方差与时间尺度。

公平比较可以固定目标数据与资源，使用共同分布评价，再分别分析各自场误差。若起点先验或数据端平滑不同，也要说明。理论上可连接不代表实际代码是同一模型，更不代表任何一个自动支配另一种。

<a id="flow-matching-69"></a>

### 16.2 随机与确定路径的选择

一般流匹配生成是确定 ODE给定随机起点，上一章还包含沿途注入噪声的反向 SDE。随机性位置不同会改变路径耦合与数值误差，最终质量需要实际测量。不要把确定过程称为没有随机生成，它的起点本来就是随机。

条件引导、逆问题和约束生成还会改变速度或得分，必须重新说明目标。把原有场简单线性组合可能有单时刻解释，却不自动保证完整端点分布满足所想条件。边缘、路径与任务之间的连接需要逐层检查。

<a id="flow-matching-70"></a>

### 16.3 比较结论的适用范围

本章人工双峰训练数据持续供应，模型小、维度低，能明确验证基础公式与采样链。它不能证明真实图像质量、稀有类别覆盖或硬件速度。后续扩展要保留来源独立划分、多个种子与任务评价，不把教学满分或较好矩匹配当成普遍能力。

准确限定范围并不削弱研究，而是使可复核证据能够积累。每个复杂方法都可以先在小模型解释，再逐项增加困难。缺少这种层次，容易用更多术语掩盖基本对象尚未清楚的问题。

<a id="flow-matching-71"></a>

## 17. 条件路径奇异时仍可使用弱形式

<a id="flow-matching-72"></a>

### 17.1 固定端点对是一条点轨迹

若条件 C同时包含两个端点，给定 C后的当前位置是确定的，条件分布是点质量，不具有普通全空间密度。前面用密度写混合通量是一种方便展示，不能把这个条件退化忽略。更一般证明可以直接对光滑测试函数求期望导数，再对条件积分，无需每个条件都有光滑密度。

具体地，固定条件路径的测试函数变化率是其梯度乘条件速度，平均后再给定当前位置取条件期望，得到边缘速度的弱连续性方程。只要导数期望交换等条件成立，这条路线容许确定条件轨迹。若边缘本身光滑，就可进一步写成熟悉密度形式。分清弱与强表达，可以避免误以为端点对训练违反所有理论。

<a id="flow-matching-73"></a>

### 17.2 给定单个目标点与给定端点对

只给定数据端点、仍随机抽高斯源时，中间条件是非退化高斯；给定全部端点时，中间条件退化，但标签直接是路径导数。两种条件变量选择可导向同一边缘回归，证明表达却不同。实际代码使用端点对构造标签，不要求计算点质量对数密度。

这个区别也解释为什么流匹配训练无需评估条件密度或边缘似然。它利用可采样路径与可计算导数，最终密度评价是另一个可选过程。不要把无需训练密度解释成生成分布没有数学定义，也不要反过来认为每次训练都已经计算了完整似然。

<a id="flow-matching-74"></a>

### 17.3 混合权重随时间变化的额外项

条件边缘速度公式通常假设条件分布权重固定。如果人为让混合权重随时间变化，密度导数还包含权重导数乘条件密度，不能只平均原条件通量。这个额外质量重新分配需要相应构造，不能凭一条条件期望公式自动处理。

例如两个固定不动的分量之间逐渐转移混合权重，所有原条件速度都为零，但边缘密度明显变化。简单平均仍给零速度，显然不满足连续性方程。这个反例说明每个推导的抽样变量分布也属于条件，不是可以随意改变的背景设定。

<a id="flow-matching-75"></a>

## 18. 多维高斯路径的完整矩阵参照

<a id="flow-matching-76"></a>

### 18.1 独立端点的协方差

设 $X_0\sim N(m_0,C_0)$、$X_1\sim N(m_1,C_1)$ 独立，两个协方差正定。定义 $X_t=(1-t)X_0+tX_1$ 和条件速度标签 $D=X_1-X_0$，则

$$
m_t=(1-t)m_0+tm_1,\quad
C_t=(1-t)^2C_0+t^2C_1,\quad
H_t=\operatorname{Cov}(D,X_t)=tC_1-(1-t)C_0.
$$

协方差中交叉项消失用到了独立性；若端点相关，就不能继续使用这组三式。因为 $(D,X_t)$ 联合高斯，条件均值公式给出边缘速度

$$
v_t(x)=m_1-m_0+B_t(x-m_t),\qquad B_t=H_tC_t^{-1}.
$$

矩阵次序由“输出标签与输入位置的交叉协方差乘输入协方差逆”决定。除非有可交换结构，不能将 $H_tC_t^{-1}$ 改成 $C_t^{-1}H_t$。也可以通过让残差 $D-E[D]-B_t(X_t-m_t)$ 与 $X_t$ 不相关来推导：其交叉协方差为 $H_t-B_tC_t$，令它为零得到同一结果；联合高斯才把这种线性残差条件进一步提升为精确条件均值。

<a id="flow-matching-77"></a>

### 18.2 协方差动力学核验

对仿射流令 $Z_t=X_t-m_t$，其中心化动力学为 $\dot Z_t=B_tZ_t$。对 $E[Z_tZ_t^T]$ 求导，乘积法则给出

$$
\dot C_t=B_tC_t+C_tB_t^T.
$$

代入 $B_t=H_tC_t^{-1}$，利用 $C_t,H_t$ 均对称，右侧恰为 $H_t+H_t^T=2H_t$，与对 $(1-t)^2C_0+t^2C_1$ 直接求导完全一致。均值则满足 $\dot m_t=m_1-m_0$。所以核对的是整段高斯路径的矩演化，而不仅仅是两个端点。

**非对易的二维例子。** 取 $C_0=\operatorname{diag}(1,4)$、$C_1=\begin{pmatrix}2&1\\1&2\end{pmatrix}$，在 $t=1/2$ 有

$$
C_t=\frac14\begin{pmatrix}3&1\\1&6\end{pmatrix},\quad
H_t=\frac12\begin{pmatrix}1&1\\1&-2\end{pmatrix},\quad
B_t=\frac2{17}\begin{pmatrix}5&2\\8&-7\end{pmatrix}.
$$

$B_t$ 并不对称，但 $B_tC_t+C_tB_t^T=\begin{pmatrix}1&1\\1&-2\end{pmatrix}=\dot C_t$。若误把乘法次序交换，得到的速度系数转置了，却不再满足同一个协方差方程。这是能暴露错误的测试，而只选两个对角端点协方差时，两种写法会碰巧相同。

若端点相关，协方差还包含交叉耦合项，条件回归也随之变化。代码改用新的配对机制后，应先重算相应均值、协方差和交叉协方差，不能继续用独立端点公式作精确参照。正定条件同时保证每个时刻的逆有定义；奇异极限应另行限制支持子空间。

<a id="flow-matching-78"></a>

### 18.3 协方差正确仍不保证非高斯正确

高斯分布由均值协方差决定，因此矩核验在该模型中很强；对混合或其他非高斯，矩相同也可能模式完全不同。双峰实验需要额外占用与局部质量，不能只因二阶矩接近四点零九就宣称分布恢复。

可以构造与双峰同矩的单高斯作评价器反例，检查指标能否区分。这与生成评价章节的原则相同：每个指标都要知道它能看见什么、看不见什么。更多数字只有在对应不同失败方式时才增加解释力。

<a id="flow-matching-79"></a>

## 19. 从局部公式到全局流

<a id="flow-matching-80"></a>

### 19.1 解可能在有限时间逃逸

一个处处可微的速度也未必有全时间解。例如一维速度为 x平方，从正初值出发的解析解在有限时间分母变零。局部导数存在不保证粒子能够到达预定终点，更不保证概率总质量在全空间正常守恒。需要合适增长条件或其他全局控制。

常见有限参数网络在固定有限时间和合适激活下可能满足有用的增长与局部稳定条件，但若标签或系数含端点奇异因子，仍需检查。数值上看到若干样本有限，只是有限证据。理论正则与程序保护应共同说明，不能互相冒充。

<a id="flow-matching-81"></a>

### 19.2 体积压缩与密度增大

流可以把某区域体积压小，使密度增大，但总概率不凭空增加。对数密度沿轨迹的负散度积分表达这个关系。若末端压缩到严格低维集合，雅可比可能退化，普通可逆密度公式的条件就改变。不能既使用正则可逆公式，又无条件宣称精确产生奇异端点。

实际数据常通过小噪声、去量化或观测模型获得全维密度，这些处理有自己的含义。生成样本接近某流形不等于数学上密度就定义在该流形上。基准测度应明确，尤其涉及似然比较时，坐标单位与预处理雅可比都不能省略。

<a id="flow-matching-82"></a>

### 19.3 数值求解定义的实际映射

有限 Euler或 Heun更新组成一个离散映射，它未必在任意大步长下保持连续流的全部结构。某些步长可能造成次序翻转、局部不可逆或明显分布偏差。即使连续速度很好，也要通过步长收敛检查实际生成。求解器名称不是概率正确性的保证。

若为避免异常而裁剪输出，实际映射又改变。记录触发比例和尾部影响，才能知道保护是否仅处理机器异常，还是压掉了合法概率。后处理可以有用，但必须进入最终系统定义与评价，不应藏在图形展示之前。

<a id="flow-matching-83"></a>

## 20. 四个实跑实验的整体解释

解析单高斯条件均值、密度时间导数和通量空间导数通过有限差分核对，验证了连续性方程与速度符号。相同标准正态独立端点的中点方差约零点五零零三，条件速度零预测误差约一点九九零，清楚展示不可约标签冲突和边缘先缩后放，而不是端点配对直线照搬。

完整双峰网络验证 MSE从约五点零一七六降到二点三八五一。三千个生成样本正峰比例约百分之五十点四，中心零点八邻域比例约百分之九十七点九，均值约负零点零一九五，二阶矩约四点一四八，对照真值零与四点零九。结果显示学到了主要结构，同时仍有有限学习、求解与抽样偏差，不把它描述成精确分布一致。

解析高斯散度积分约负零点九一六三，与目标标准差零点四的对数吻合，两端密度和次序检查通过。这个结果只认证该解析流，不是神经双峰似然成绩。四段均由独立 Python进程运行，不依赖其他代码块的遗留变量或外部下载。

后续改动应保持证据层次：固定解析场看求解，固定求解看网络，固定网络看路径与耦合，最后才讨论真实任务。保留失败与不理想数字，能够让结果成为研究依据，而不只是一个必须成功的演示。

<a id="flow-matching-84"></a>

## 21. 小批次配对与全局耦合的区别

<a id="flow-matching-85"></a>

### 21.1 保留端点边缘不代表全局最优

在一个批次内重新排列目标，使总配对成本较小，仍保留该批次所有源与目标样本，所以经验端点边缘不变。但每个配对依赖整批组成，不是简单独立端点抽样。即使每批求得该有限匹配问题最优，也不等于已经计算总体分布间的全局最优传输。

批次大小、成本度量、近似求解与数据维度都会影响所得耦合。使用欧氏成本也不自动对应真实语义相似。可以把这种设计作为降低条件路径冲突的候选，但应评价边缘场、最终质量和额外配对计算，而不是只报告条件损失下降。

<a id="flow-matching-86"></a>

### 21.2 软耦合与附加正则

有些配对使用软权重或熵正则，增加平滑与计算便利，同时改变原始成本问题。正则强弱影响接近独立还是集中配对，不能只用最优两个字忽略这一折中。若从软权重抽样，实际概率应对应训练定义，不能一边用软目标一边按硬匹配解释路径。

将这些组件加入训练后，复现记录应包含成本、批次、求解精度与抽样方式。额外 CPU或加速器工作是总成本的一部分，不能只统计神经网络更新。更低标签方差可能换来更昂贵前处理，收益应按研究目标衡量。

<a id="flow-matching-87"></a>

### 21.3 理想参照与实际算法

一维已知分布可通过排序或解析分位数构造清楚耦合，它是很好的理想参照。高维未知数据未必能同样获得。若实验使用真实总体信息，应标注上界性质，不把它与仅见有限数据的方法无说明地比较。辅助知识与计算都影响公平性。

理想参照的价值在于定位潜在收益，而非保证真实系统能免费达到。先用它观察路径是否更直、速度方差是否更小，再研究近似实现损失了什么。这样的递进能让方法比较具有解释，而不只是增加复杂组件。

<a id="flow-matching-88"></a>

## 22. 三个可推进的研究项目

<a id="flow-matching-89"></a>

### 22.1 条件方差与边缘误差

在相同双峰端点下比较独立配对、预设结构配对与小批次匹配，记录条件标签方差和网络到解析或高精度边缘速度的误差。固定总网络调用与配对成本预算，再用共同 Heun协议采样。主要问题是低条件损失究竟来自标签更确定，还是边缘场真的学得更准。

如果某配对训练更容易却最终覆盖变差，应保留结果，检查有限数据和近似匹配。不要在看到样本后重新选择成本度量，再把最好结果称为预设方法。开发选择与确认分开，才能判断稳定收益。

<a id="flow-matching-90"></a>

### 22.2 端点噪声与奇异目标

从正方差双峰逐渐缩小局部方差，比较严格一端与保留小噪声路径。解析边缘允许检查曲率、求解调用与目标平滑差异。不能用平滑模型的好结果宣称严格离散目标已经精确实现，也不能把端点难度全部归给网络不足。

同时报告目标矩、模式邻域和密度定义，确保每个结果与实际生成端点对应。若使用末步去噪，另列后处理系统与成本。这个项目训练对概率测度、数值极限和应用质量的联合判断。

<a id="flow-matching-91"></a>

### 22.3 路径整直与少步采样

先在解析高斯中比较独立路径与仿射耦合的轨迹长度、动能和少步误差，再扩展到学习双峰网络。若使用模型生成端点重新配对，要分别测旧模型端点偏差与新路径求解收益，不把继承的目标误差隐藏。

固定函数评价次数比较质量，或固定质量比较资源，两种协议分别报告。少步不必天然更好，更多蒸馏或重配对训练也不免费。每个结论都应回答一个明确资源与任务问题，避免把所有连续流技巧概括成一步快速生成。

以本章解析高斯的均值一点五、标准差零点四为例，独立端点直线的平均平方位移是三点四一，单调仿射耦合是二点六一。这个差距来自配对，而不是两端分布变化。边缘平均速度又会通过条件平均减少一些互相抵消运动，所以独立条件标签动能不能直接当成边缘 ODE动能。

对任意绝对连续轨迹，端点位移等于速度积分，Cauchy不等式给出位移平方不超过单位时间内速度平方积分。再对源分布平均并考虑所有可行端点耦合，最优二阶搬运成本提供动能下界。这个推导说明为何讨论最短路径需要同时约束连续性方程与端点，而不是只画每个训练配对的直线。

一维高斯理想例子能够完整解释这些层次，真实数据则需要额外估计与计算。若某方法只展示条件标签更短，应继续检查它是否减少了实际网络误差与求解调用；若终点质量没有改善，也不应隐藏。把理论充分条件与有限实测分开，能避免一种漂亮几何叙述承担超出证据的结论。

复现时先保持四段代码原设置，确认端点、速度、连续性和采样都一致，再逐项改变耦合或日程。每次修改重新计算参照，保留负结果，不把旧最优数字复制到新任务。学习完成的标志是能解释这些变化为何影响结果，而不仅是能够运行同一段训练。

本章固定验证仅用于预设预算后的效果核验，没有据测试结果调整轮数、路径或求解器。若继续开发，应另设验证来源并使用新确认数据。明确这些信息流和选择规则，才能让一个完整人工实验成为后续研究的可靠基础，而不是只保留最好输出的演示。
