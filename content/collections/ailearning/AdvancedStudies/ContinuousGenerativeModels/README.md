# 连续生成与流匹配

连接去噪得分、反向动力学、概率流与条件路径速度，明确时间方向和误差来源。

**先修知识：** 扩散基础、条件期望、梯度与 ODE；SDE 部分先掌握记号和高斯特例。

## 章节与学习目标

| 章节 | 核心内容 | 深入讲解入口 |
| --- | --- | --- |
| [第 1 章 得分匹配、随机微分方程与概率流](01-得分匹配随机微分方程与概率流.md) | 得分不是生成质量分数；去噪目标为何能学习边缘得分；正向 SDE、反向 SDE 与时间方向 | [进入讲解](01-得分匹配随机微分方程与概率流.md#deep-dive-2) |
| [第 2 章 流匹配、连续性方程与路径选择](02-流匹配连续性方程与路径选择.md) | 从噪声到数据的方向约定；条件路径产生可监督目标；直线条件路径不保证边缘轨迹直 | [进入讲解](02-流匹配连续性方程与路径选择.md#deep-dive-3) |

## 阅读顺序与验收

第 1 章统一前向时间与反向时钟，从密度方程和去噪回归推得随机反向过程及概率流；第 2 章改从端点耦合与条件路径出发，推边缘速度、连续性方程和流匹配。两章均把解析参照、完整人工训练、采样求解与端点失配分别核对。遇到公式先复算低维例子，再进入实验设计；不要把局部数值检查当成算法整体效果证明。

**完成要求：** 从去噪回归得到得分；核对反向时间符号；推导线性高斯流速度；分离场拟合与积分误差。

作答后再阅读各章解析。能够独立说明一个失效条件，并设计一个可区分竞争解释的对照实验，才算完成本主题的进阶学习。
