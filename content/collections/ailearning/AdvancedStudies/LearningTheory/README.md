# 统计学习理论

从总体风险、容量与算法稳定性解释泛化，区分优化成功和统计有效。

**先修知识：** 概率、统计、凸优化；建议先完成机器学习基础与评估。

## 章节目录

| 章节 | 核心内容 | 深入讲解入口 |
| --- | --- | --- |
| [第 1 章 总体风险、一致收敛与模型选择](01-总体风险一致收敛与模型选择.md) | 学习目标与三种误差；从单模型集中到一致收敛；容量、样本与选择边界 | [进入讲解](01-总体风险一致收敛与模型选择.md#deep-dive-2) |
| [第 2 章 算法稳定性、插值与隐式偏置](02-算法稳定性插值与隐式偏置.md) | 稳定性研究算法而非单个模型；正则化怎样产生一个可推导的界；零训练误差为何仍可能有不同结果 | [进入讲解](02-算法稳定性插值与隐式偏置.md#deep-dive-2) |
| [第 3 章 PAC-Bayes、变分界与随机预测器](03-PACBayes变分界与随机预测器.md) | 预测对象是分布，不只是一个权重向量；从指数集中推到同时适用的泛化界；换测度、不独立先验与温度选择 | [进入讲解](03-PACBayes变分界与随机预测器.md#deep-dive-5) |
| [第 4 章 局部复杂度、快速率与数据依赖泛化](04-局部复杂度快速率与数据依赖泛化.md) | Bernstein 集中；低噪声与快速率；局部化；固定设计平方损失 | [进入讲解](04-局部复杂度快速率与数据依赖泛化.md#sec-2) |

## 阅读顺序

第 1 章建立风险、集中与统一量词后，可分支阅读：第 2 章研究算法稳定性与插值，第 3 章研究预测器分布和换测度，第 4 章研究超额损失的方差结构、局部化和快速率。第 4 章主要承接第 1 章的有限类集中，不要求先用 PAC-Bayes 得出快速率；四章应在同一任务与损失下比较。遇到公式先复算低维例子，再进入实验设计；不要把局部数值检查当成算法整体效果证明。
