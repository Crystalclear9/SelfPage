## 1. 先说清什么分布发生变化

<a id="uncertainty-2-detail-2"></a>

### 1.1 源域与目标域是两个联合分布

记训练来源联合分布为 P，部署联合分布为 Q。输入均值、类别比例或设备型号变化，只说明某些边缘统计改变，不直接决定结果机制是否保持。研究分布变化，需要明确哪些条件分布被假设不变、哪些标签可见，以及目标风险用什么损失评价。不同假设支持不同纠正方法，不能把所有域差异都交给一个密度比。

若目标域允许有标签开发数据，可以据此选择规则；若只有无标签输入，能识别的内容更少。若测试标签被反复用来估权重或调阈值，就不再是独立外部评价。数据权限本身是问题定义，不应只列一个源训练、目标测试名称却隐藏中间选择。

<a id="uncertainty-2-detail-3"></a>

### 1.2 协变量、标签与概念变化

协变量变化常指 Q(X)不同而 Q(Y 给定 X)与 P 相同。标签变化常指 Q(Y)不同而 Q(X 给定 Y)保持。更一般概念变化可以改变结果条件机制。二者不只是同一公式的不同写法，通常不能同时随意成立；它们提出不同可识别性假设，适合不同数据生成过程。

例如同一病情下设备测量分布变化，可能影响输入条件；疾病流行率改变而给定疾病的测量规律保持，更接近标签变化。现实可能两者一起变化，需要承认模型错设。只看到目标输入直方图和源不同，无法据此确认标签机制不变；同样输入分布也可以对应完全相反标签规则。

<a id="uncertainty-2-detail-4"></a>

### 1.3 无标签输入不能识别任意概念变化

设源与目标输入都均匀取零和一，源标签等于输入，目标可能仍等于输入，也可能完全取反。目标无标签输入分布相同，任何只看输入的漂移检测都无法区分两机制。算法可以利用领域先验，但不能无条件从无标签数据恢复任意新结果规则。这是信息限制，增加模型容量不改变。

因此分布检测和性能检测是不同任务。一个来源判别器无法区分域，不证明标签关系没变；判别器很容易区分域，也不证明预测性能必然下降。应同时追踪数据链路、可见标签和实际损失，将统计差异与决策影响分开解释。

<a id="visual-uncertaintyandrobustness-02"></a>
### 图解：重要性加权修正哪一种变化

![重要性加权修正哪一种变化：机制、算例与边界](images/02-concept.svg)

图使用第 8.1 节代码的同一生成机制。左侧源输入在 $`[-1,1]`$ 上均匀，密度 $`p(x)=\frac12`$；目标密度为 $`q(x)=\frac{1+0.8x}{2}`$，故已知重要性权重为 $`w(x)=1+0.8x`$。两个密度都积分为一，且目标更重视正输入。右侧真实条件均值仍是同一条 $`m(x)=x^2`$ 蓝线；这里只允许用 $`ax+b`$ 拟合，不能直接表示它。

平方风险的一阶条件给出

$$
a_Q=\frac{\mathbb E_Q[X^3]-\mathbb E_Q[X]\mathbb E_Q[X^2]}
{\mathbb E_Q[X^2]-(\mathbb E_Q[X])^2}
=\frac{\frac{0.8}{5}-\frac{0.8}{9}}
{\frac13-\frac{0.8^2}{9}}
\approx0.271186,
\qquad
b_Q=\frac13-\frac{0.8a_Q}{3}\approx0.261017.
$$

源分布对称，$`\mathbb E_P[X]=\mathbb E_P[X^3]=0`$，源最优直线因而是 $`a_P=0,b_P=\frac13`$。两条直线不同是因为受限模型必须重新分配误差，不是因为标签规律改变。独立的均值零、方差 $`0.01`$ 的噪声为两域平方风险都加上同一个常数，不改变这些总体最优系数。代码中的有限样本拟合应靠近这些线，而不要求逐位相同。

若把模型类扩成包含平方特征，真实条件均值可被准确表示，两域总体最优函数便可以相同；有限样本权重方差、正则及估计误差仍可能不同。该图假设目标支持被源覆盖；源零概率而目标正概率的区域不满足密度比前提，需要另外的数据或结构信息，不能用任意大有限权重补出标签。

## 2. 协变量变化下的风险重加权

<a id="uncertainty-2-detail-6"></a>

### 2.1 从联合积分推出密度比

若 Q(Y 给定 X)=P(Y 给定 X)，且 Q_X 相对 P_X 绝对连续，定义 $`w(x)=\frac{dQ_X}{dP_X}`$。对可积损失有

$$
R_Q(f)=E_Q[\ell(f(X),Y)]=E_P[w(X)\ell(f(X),Y)].
$$

证明把 Q 的联合积分按输入边缘与共同条件分布分解，再用密度比替换输入测度。条件机制保持和支持覆盖都必需。若目标在源从不出现区域有质量，普通有限权重不能恢复该区域结果。若条件标签机制改变，即使输入比精确，公式也不再表示真实目标风险。

<a id="uncertainty-2-detail-7"></a>

### 2.2 权重改变的是目标重视的位置

函数类能精确表示真实条件最优预测且数据无限时，某些损失下不加权也可得到相同条件最优函数。但有限样本、模型错设和正则化存在时，源与目标对不同区域的权衡不同，重要性加权可以改变最佳近似。不能一概说协变量变化一定需要重训，也不能一概说条件机制没变就没有任何影响。

一个简单回归例子是真实均值为平方函数，只允许直线拟合。源输入对称，最佳直线可能水平；目标偏向正输入，最佳直线斜率会改变。加权不是改变真实均值，而是在受限模型中重新分配误差。这类可手算例子比仅讲域适应术语更能说明方法为什么有用。

<a id="uncertainty-2-detail-8"></a>

### 2.3 普通加权与自归一化

已知权重时，样本平均 $`N^{-1}\sum_iw_i\ell_i`$ 对目标风险可无偏；自归一化比值 $`\frac{\sum_iw_i\ell_i}{\sum_iw_i}`$ 一般有限样本有偏，但可能稳定。两者都需要支持和可积条件，方差还依赖权重尾部。权重均值理论为一，不表示任何有限数据的总和恰好等于样本数。

截断极大权重可减少波动，却通常引入偏差。对有界非负损失，可以用被截掉权重质量控制相应目标偏差；实际权重又是估计值，需要另加估计误差。不能截断后继续宣称原无偏性质完整保留。方法取舍应结合风险、有效证据和下游决策，而非只看曲线更平稳。

## 3. 从来源判别器估计密度比

<a id="uncertainty-2-detail-10"></a>

### 3.1 训练采样先验不能漏掉

令 D 为来源指示，一表示目标、零表示源，构成来源判别训练混合的目标比例为 $`\rho`$。若判别器给真实后验 $`\eta(x)=P(D=1\mid X=x)`$，Bayes 公式给

$$
\frac{q_X(x)}{p_X(x)}=\frac{1-\rho}{\rho}\frac{\eta(x)}{1-\eta(x)}.
$$

这个 rho 是构造判别数据时的采样比例，不一定是现实两个域的流量。若人为平衡来源样本，就用平衡比例。判别准确率高不代表后验校准好，而密度比需要后验数值，不只是排序。温度、特征和模型族都会影响比值估计，接近一的后验还会放大误差。

<a id="uncertainty-2-detail-11"></a>

### 3.2 交叉拟合与评价独立

若同一批源样本既训练判别器又用估计比值评估风险，过拟合可能让权重偏向个体来源身份。可以用独立比值拟合数据或交叉拟合降低这种依赖，但不能自动得到精确有限样本无偏。拟合函数随机、模型错设与极端权重仍需分析。报告应把真实已知比和估计比实验分开。

目标无标签输入可以合法用于比值估计，在相应任务定义下属于适应信息；但目标测试标签不应参与。若利用整个测试输入集做无监督适应，应明确是转导式设定，而非单点完全未知目标输入。数据权限改变会影响比较，不能把额外目标样本隐藏在预处理里。

<a id="uncertainty-2-detail-12"></a>

### 3.3 支持、方差与有效样本量

权重集中时，常见有效样本量为权重和平方除以权重平方和。它小提示少量样本主导，却不能证明不存在没见到的关键区域；若重要目标区域源概率极小，有限样本可能根本没有记录，现有权重看起来仍平稳。有效样本量是诊断，不是支持认证。

还应报告最大权重、分位数、来源覆盖和目标风险对截断阈值的敏感性。若预测失误集中在高权重区域，方差会更大；若这些区域很少，单一总体误差无法说明可靠性。大数据量不等于大有效证据，尤其在强分布变化中。

## 4. 标签变化与混淆结构的可识别性

<a id="uncertainty-2-detail-14"></a>

### 4.1 固定预测器诱导线性方程

标签变化假设给定真实类别后的输入分布保持。固定分类器输出 H，定义 $`C_{ij}=P(H=i\mid Y=j)`$，列对应真实类、行对应预测类。目标预测边缘 $`q_i=Q(H=i)`$ 满足 $`q=C\pi_Q`$，其中 $`\pi_Q`$ 为目标类别先验。这个公式使用条件混淆矩阵，不是源域联合频率矩阵，不能混淆两者。

若 C 可逆且估计准确，可求目标先验；若列相同，不同类别产生相同预测分布，目标边缘无法识别先验。接近奇异时微小估计误差会被放大，直接求逆可能得到负概率。需要检查条件数、样本量和概率单纯形约束，不能只算一个逆矩阵就宣布漂移纠正成功。

<a id="uncertainty-2-detail-15"></a>

### 4.2 后验纠正还需要源概率质量

若已知真实源后验与源目标先验，可以用 $`Q(Y=j\mid x)`$ 正比于 $`\frac{P(Y=j\mid x)\pi_Q(j)}{\pi_P(j)}`$ 调整。这个步骤依赖标签变化及相应支持，源概率不准时仍可能错误。估计类别比例的混淆方法与后验概率校准是不同环节，不能因先验解出来就认为每个个体概率正确。

若源某类概率为零而目标有该类，就没有相应条件结构证据；如果新域出现全新类别，原有限类标签变化模型也不覆盖。开放集识别、概念变化与标签先验变化需要区分。研究结论应限定到真实假设，而不是把任何类别统计改变都称为可纠正标签变化。

<a id="visual-extension-uncertaintyandrobustness-02"></a>
### 图解：标签变化需要可识别的混淆结构

![标签变化需要可识别的混淆结构](images/02-extension.svg)

这里使用的是**预测任务的冻结标签分类器**，不是辨别样本来自哪个域的来源判别器。行表示预测标签，列表示真实标签；左侧条件混淆矩阵为 $`C=\begin{pmatrix}0.8&0.2\\0.2&0.8\end{pmatrix}`$。若目标真实标签一的比例为 $`\pi`$，预测为一的比例便是 $`q=0.2(1-\pi)+0.8\pi=0.2+0.6\pi`$。观测到 $`q=0.62`$ 时可解出 $`\pi=0.7`$。

右侧两列都为 $`(0.5,0.5)^{\mathsf T}`$，所有先验都产生相同预测边缘。图中 $`\pi=0.1`$ 和 $`0.9`$ 只是两个明确反例，实际上有无穷多个无法区分的比例。这里丢失的是识别信息，增加无标签样本也无法从同一个常数中恢复它。

当两列仅仅很接近时，问题虽然可逆，却高度敏感。例如改成第一行 $`(0.499,0.501)`$ 后，有 $`q=0.499+0.002\pi`$，预测比例误差 $`0.002`$ 就会带来一整单位的先验误差，甚至得到负概率。约束优化能保证输出合法，却不能凭空恢复丢失的信息。标签变化还要求给定真实标签后的输入分布、因而冻结分类器的条件行为保持；其识别公式见 [Lipton 等 BBSE 原论文](https://arxiv.org/pdf/1802.03916)。

## 5. 最坏群体目标与分布鲁棒

<a id="uncertainty-2-detail-17"></a>

### 5.1 从平均风险到最大组风险

设预先定义群体 g，各组条件风险为 $`R_g(f)`$。平均风险按群体比例加权，最坏群体目标最小化 $`\max_gR_g(f)`$。若未来仅改变群体混合比例而各组条件分布保持，那么任意混合的风险不超过最大组风险。这个保护范围非常具体，不包含组内机制任意变化或未定义新群体。

目标改变可能牺牲多数群体平均表现，换取少数难组改善。若只报告最好总体准确率，就看不到这种取舍；若只报最坏组，也可能掩盖大成本。应同时给每组、总体和样本量，说明组定义来自真实用途还是人为机制。公平与鲁棒相关，但不等于一个最大风险数字自动满足全部价值要求。

<a id="uncertainty-2-detail-18"></a>

### 5.2 对偶权重与训练动态

有限组最大值可写成在组权重单纯形上最大化加权风险。可用梯度更新模型、指数权重更新对手，强调当前高损失群体。但有限数据组风险有噪声，极小组可能被过拟合；强正则化、数据量和模型容量都会影响最坏组泛化。研究背景见[群体鲁棒原论文](https://arxiv.org/abs/1911.08731)。

训练组损失相同不保证测试组同样好，训练对偶权重也不是部署群体比例估计。它是优化关注程度，不能当成发现现实人群大小。组标签若训练时可见而部署不可见，模型仍可通过共享预测器运行，但数据要求和方法信息权限应明确。

<a id="sec-4"></a>

<a id="uncertainty-2-detail-19"></a>

### 5.3 平均与最坏的手算取舍

方法甲多数组错误百分之二、少数组百分之四十，若少数组占百分之五，总平均百分之三点九；方法乙两组错误百分之八，总平均百分之八却最坏明显更低。按源平均选甲，按最坏组选乙。没有脱离目标的绝对更好，关键是部署混合与错误成本是否符合需求。

若未来少数组占一半，甲平均变百分之二十一，乙仍百分之八。最坏组训练适合某类群体比例变化，却不能保证组内噪声突然增加时不退化。把组变化与任意分布鲁棒分开，才能解释什么变化被目标保护，什么需要新数据或更大不确定集合。

<a id="visual-detail-uncertaintyandrobustness-02"></a>

### 图解：平均风险改善可以掩盖最坏群体变差

![平均风险改善可以掩盖最坏群体变差](images/02-mechanism.svg)

设群体A占90%、B占10%。模型1的群体风险为0.1与0.5，平均0.14；模型2为0.05与0.6，平均降到0.105，但最坏群体风险由0.5升至0.6。不同目标可能给出不同模型排序。

这张图把同一组风险沿所有可能的部署混合展开。令 B 组比例为 $`\pi`$，则 $`R_1(\pi)=0.1+0.4\pi`$、$`R_2(\pi)=0.05+0.55\pi`$；风险差为 $`R_2-R_1=-0.05+0.15\pi`$，在 $`\pi=\frac13`$ 处换号。源比例 $`\pi=0.1`$ 位于交点左侧，故模型2平均风险较低；部署更多集中 B 组时，排序却会反转。纵坐标直接是总体风险，图中的连线来自精确的全概率公式，不是模拟的训练轨迹。

若允许的混合为整个 $`[0,1]`$，两条递增直线都在 $`\pi=1`$ 取最坏值，因此最坏组目标选模型1。若领域知识只允许 $`\pi\in[0,0.2]`$，最坏值分别变为 0.18 与 0.16，此时又会选模型2。保护集合本身决定取舍：扩大不确定集合不是没有代价的改进。这里假设组内条件机制保持，不保护新群体或组内任意标签变化。群体混合集合与最大组风险的关系见 [Sagawa 等原论文第2节](https://arxiv.org/pdf/1911.08731)。

群体风险还受每组样本量与标注质量影响，不能把小组不稳定估计当作确定事实；分布鲁棒集合的定义也不自动等同于这两个已知群体。

## 6. 分布鲁棒、对抗鲁棒与不确定集合

<a id="uncertainty-2-detail-21"></a>

### 6.1 不同扰动集合定义不同问题

分布鲁棒常在某个分布集合内取最坏风险，对抗鲁棒常限制每个输入的局部扰动。群体混合、密度比球、Wasserstein 球和像素范数球不是同一种不确定性。一个方法对小输入扰动稳健，不代表对新设备标签机制稳健；对群体比例变化有效，也不代表能处理任意对抗样本。

集合半径和语义决定保护范围与保守代价。半径太小漏掉真实变化，太大可能使任务变得无法有用预测。应通过领域机制与开发数据合理设定，不能看测试分数后随意挑最有利集合。鲁棒不是没有条件，而是把条件集中在明确的不确定集合上。

<a id="uncertainty-2-detail-22"></a>

### 6.2 证据可以分层但不能互相替代

输入来源判别显示某种边缘可分，标签变化线性关系检验某种条件假设，目标标签损失显示实际效果，最坏组风险提供预设集合内摘要。它们可以互补，却没有一个能独自证明所有外部泛化。真实变化还可能来自测量、缺失、选择和反馈，需要数据来源审计支持。

下一章会讨论拒答，分布变化下高置信错误尤其重要。风险认证在源域成立，也不能自动搬到任意目标域；若有已知密度比或组结构，可研究有条件迁移，但要重新推导。可靠性和鲁棒性不是把几个指标接在一起就获得的总保证。

<a id="uncertainty-2-detail-23"></a>

## 7. 风险估计的方差、偏差与误差账本

<a id="uncertainty-2-detail-24"></a>

### 7.1 无偏性不等于可用的精度

固定预测函数，记单点损失为 L，若已知权重且二阶矩存在，普通重要性估计满足

$$
\operatorname{Var}(\widehat R)=\frac{E_P[w^2L^2]-R_Q^2}{n}.
$$

推导只需独立样本平均的方差公式：每项是随机变量 wL，其期望为目标风险。关键是平方出现在权重上；目标概率只比源大十倍的区域，对二阶矩的放大可能达到百倍。目标风险有限并不推出这个方差有限，因此大数收敛所需可积条件与中心极限定理所需二阶条件应分别检查。

考虑源概率百分之一、目标概率一半的稀有区，区内损失恒一、区外零。权重在该区为五十，单样本加权损失为五十或零；目标风险为零点五，单样本方差为二十四点七五。即使源有一千条，标准误仍约零点一五七；这不是模型没拟合好，而是有效目标证据只有约十条。直接在目标抽一千条标签会有不同信息量，不能只比较总行数。

若稀有区源概率再降两个数量级，常见训练样本可能完全没有它。此时经验权重最大值看起来正常，经验方差甚至接近零，却遗漏目标重要区域。经验诊断应结合已知采样机制、支持知识与独立目标输入，而不能把观察到的平稳当成不存在尾部。风险可靠性首先是信息问题，其次才是优化问题。

<a id="uncertainty-2-detail-25"></a>

### 7.2 自归一化的展开与局限

令 $`A_n=n^{-1}\sum w_iL_i`$、$`B_n=n^{-1}\sum w_i`$，自归一化估计为 $`\frac{A_n}{B_n}`$。在相应联合中心极限定理及二阶矩条件下，对函数 a 除以 b 在真实点 $`(R_Q,1)`$ 作一阶展开，得到主要误差为 $`A_n-R_Q-R_Q(B_n-1)`$，也就是样本均值 $`w_i(L_i-R_Q)`$。因此其渐近方差为

$$
\sigma_{\rm SN}^2=E_P[w^2(L-R_Q)^2].
$$

它与普通估计的方差不是简单大小关系。当权重与损失共同变化时，归一化可能去掉有益或有害的波动。若损失恒为常数 c，自归一化只要权重和非零就精确给 c，普通估计仍随平均权重波动；但这不证明所有损失都受益。有限样本分母随机还产生比值偏差，不能用渐近表达代替精确无偏声明。

若所有权重被乘同一正数，自归一化风险和某些无正则加权经验最优解不变；普通目标风险数值却被放大，固定正则系数下的最优解也可能改变。由此，漏掉来源先验因子不是总能忽略的小事。即使排名没变，风险估计、置信界和正则强度仍可能错误，应明确算法是否依赖绝对尺度。

<a id="uncertainty-2-detail-26"></a>

### 7.3 截断误差可以写成公式

对 $`0\le L\le M`$ 及 $`w_c=\min(w,c)`$，有

$$
0\le R_Q-E_P[w_cL]=E_P[(w-c)_+L]\le M E_P[(w-c)_+].
$$

非负损失下普通截断向下偏，因此看起来更低的估计风险可能只是把难区权重删掉。若再自归一化，分母也改变，上述单向关系一般不保留。比较截断方案应同时给出目标性能和被截掉的质量；不能只拿更小经验加权损失当作更好的目标模型证据。

若使用估计权重 $`\widetilde w`$，固定预测器且损失有界时，分布层面的误差满足 $`\vert E_P[(\widetilde w-w)L]\vert \le M E_P\vert \widetilde w-w\vert `$。这只控制权重误差造成的偏移，样本误差、模型选择误差和假设错误还未包含。当同一数据拟合权重并计算风险时，不能直接把固定函数集中不等式套进去，需要条件化独立数据、交叉拟合分析或更强学习理论。

<a id="uncertainty-2-detail-27"></a>

### 7.4 四笔误差应分别记录

第一笔是迁移假设误差，即真实目标条件机制与源不同；第二笔是密度比或类别先验估计误差；第三笔是有限训练、受限函数类与正则造成的预测误差；第四笔是评价抽样与选择误差。四者影响不同，补更多源样本不一定修复第一笔，校准分类概率也不一定修复第二笔中的支持缺失。

一个可解释报告可以先在人工已知比值情形验证实现，再替换为估计比值检验实际估计代价，随后改变条件机制观察假设失效。把这些实验混成一张最佳分数表，会难以判断成功来自理论适用、偶然拟合还是额外标签权限。本章代码刻意保留机制可计算性，用于定位方法能解决哪一层问题。

## 8. 五个独立可复现实验

<a id="uncertainty-2-detail-29"></a>

### 8.1 实验一：受限直线在协变量变化下的训练与测试

真实条件均值是平方函数，模型只能输出直线。源输入均匀，目标输入密度按一加零点八倍输入倾斜；两域条件标签生成完全相同。训练、源风险估计与目标最终测试分别抽样，目标测试标签不参与任何拟合。已知权重用来隔离重加权机制，不假装已经解决实际密度比估计。

从目标矩可手算最优直线：输入均值为 kappa 除以三，二阶矩为三分之一，三阶矩为 kappa 除以五。因此斜率是三阶矩减均值乘二阶矩，再除输入方差，截距是二阶矩减斜率乘均值。普通源最优斜率为零；目标最优斜率约零点二七一。噪声方差相同，不会改变该最优条件均值投影。

```python
import numpy as np
from sklearn.linear_model import LinearRegression
rng=np.random.default_rng(701)
kappa=.8
x=rng.uniform(-1,1,5000)
y=x*x+.1*rng.normal(size=len(x))
plain=LinearRegression().fit(x[:,None],y)
weighted=LinearRegression().fit(x[:,None],y,sample_weight=1+kappa*x)
rv=np.random.default_rng(702)
xv=rv.uniform(-1,1,20000)
yv=xv*xv+.1*rv.normal(size=len(xv))
rt=np.random.default_rng(703)
bag=[]
while sum(map(len,bag))<30000:
    z=rt.uniform(-1,1,40000)
    bag.append(z[rt.random(len(z))<(1+kappa*z)/(1+kappa)])
xt=np.concatenate(bag)[:30000]
yt=xt*xt+.1*rt.normal(size=len(xt))
slope=(kappa/5-kappa/9)/(1/3-kappa*kappa/9)
intercept=1/3-slope*kappa/3
assert np.isclose(slope,.2711864406779661)
assert abs(weighted.coef_[0]-slope)<.04
assert abs(weighted.intercept_-intercept)<.03
for name,model in [('source_ERM',plain),('known_IW',weighted)]:
    lv=(model.predict(xv[:,None])-yv)**2
    direct=np.mean((model.predict(xt[:,None])-yt)**2)
    estimate=np.mean((1+kappa*xv)*lv)
    assert abs(estimate-direct)<.01
    print(name,'coef',model.coef_[0], 'intercept',model.intercept_,
          'source_weighted_estimate',estimate,'target_test',direct)
print('analytic_target',slope,intercept)
```

断言核对矩公式、估计系数邻近理论值及独立风险估计的一致量级。它没有断言任何有限数据下重加权必定优于普通训练；随机数据和模型约束改变时结果也会变。若换成包含平方特征的正确模型，两种权重在总体最优函数上可以一致，剩余差别主要是有限样本与正则，这正说明模型错设是本例主线的一部分。

<a id="uncertainty-2-detail-30"></a>

### 8.2 实验二：标签比例的可识别与近奇异失败

下面先用精确条件混淆矩阵恢复目标比例，再构造两列相同和两列近似相同的情况。第二种微小扰动会把无约束逆解推到概率单纯形外；投影或约束拟合只能给合法比例，不能凭空恢复丢失的信息。代码的精确矩阵是机制实验，不是对真实采样误差已经完成认证。

```python
import numpy as np
from scipy.optimize import minimize_scalar
C=np.array([[.9,.2],[.1,.8]])
prior=np.array([.3,.7])
q=C@prior
recovered=np.linalg.solve(C,q)
assert np.allclose(recovered,prior)
singular=np.array([[.6,.6],[.4,.4]])
assert np.allclose(singular@np.array([.1,.9]),singular@np.array([.9,.1]))
near=np.array([[.501,.499],[.499,.501]])
q_near=near@prior
perturbed=q_near+np.array([.002,-.002])
unstable=np.linalg.solve(near,perturbed)
assert (unstable<0).any()
fit=minimize_scalar(lambda a:np.sum((near@np.array([a,1-a])-perturbed)**2),
                    bounds=(0,1),method='bounded')
assert fit.success and 0<=fit.x<=1
print('identified',recovered,'condition_numbers',np.linalg.cond(C),np.linalg.cond(near))
print('unconstrained',unstable,'constrained',[fit.x,1-fit.x])
```

源标签比例与目标标签比例不同不会直接破坏条件混淆矩阵公式，但源每类必须有足够可用标签才能估计相应列。若源训练准确率非常高而某个小类验证只有几个样本，实际矩阵依然不确定。研究时应对列估计和目标边缘估计同时做敏感性分析，不能只报告一个矩阵条件数而忽略样本量。

<a id="uncertainty-2-detail-31"></a>

### 8.3 实验三：共享线性模型的群体鲁棒训练

人工输入有一个带噪声的因果相关特征和一个源域高度相关的捷径特征；训练中捷径与标签一致的概率为百分之九十五，最终测试把一致与冲突各占一半。群体由真实类别和是否冲突共同定义。模型部署只读取两个特征；组标记用于训练损失及评价，不能据此声称现实群体可自动识别。

两种算法使用同一训练样本、线性函数族、迭代预算与开发样本。普通方法按开发平均损失选择检查点，鲁棒方法按开发最大组损失选择，符合各自目标；这不是使用测试组性能调参。最终测试独立生成。实验采用全批量小数据优化而非大型图像基准，解释限于人工捷径机制。

```python
import numpy as np
import torch
import torch.nn.functional as F
torch.set_num_threads(1)
def data(seed,n,agree_prob):
    r=np.random.default_rng(seed)
    y=r.integers(0,2,n)
    sign=2*y-1
    agree=r.random(n)<agree_prob
    x=np.column_stack([sign+1.2*r.normal(size=n),
                       np.where(agree,sign,-sign)+.1*r.normal(size=n)])
    group=2*y+(~agree).astype(int)
    return torch.tensor(x,dtype=torch.float32),torch.tensor(y,dtype=torch.float32),torch.tensor(group)
x,y,g=data(711,2400,.95)
xd,yd,gd=data(712,2400,.95)
xt,yt,gt=data(713,20000,.5)
assert all((g==j).sum()>0 for j in range(4))
def group_loss(logits,labels,groups):
    losses=F.binary_cross_entropy_with_logits(logits,labels,reduction='none')
    return torch.stack([losses[groups==j].mean() for j in range(4)])
def fit(robust):
    model=torch.nn.Linear(2,1)
    torch.nn.init.zeros_(model.weight); torch.nn.init.zeros_(model.bias)
    opt=torch.optim.Adam(model.parameters(),lr=.03)
    logq=torch.zeros(4)
    best=float('inf'); saved=None
    for step in range(600):
        gl=group_loss(model(x).squeeze(1),y,g)
        if robust:
            with torch.no_grad():
                logq+=.05*gl.detach(); logq-=torch.logsumexp(logq,0)
            objective=(logq.exp()*gl).sum()
        else:
            objective=F.binary_cross_entropy_with_logits(model(x).squeeze(1),y)
        objective=objective+.01*model.weight.square().sum()
        opt.zero_grad(); objective.backward(); opt.step()
        if (step+1)%20==0:
            with torch.no_grad():
                dl=group_loss(model(xd).squeeze(1),yd,gd)
                criterion=dl.max().item() if robust else F.binary_cross_entropy_with_logits(model(xd).squeeze(1),yd).item()
            if criterion<best:
                best=criterion; saved={k:v.detach().clone() for k,v in model.state_dict().items()}
    model.load_state_dict(saved)
    with torch.no_grad():
        correct=(model(xt).squeeze(1)>=0)==yt.bool()
        acc=[correct[gt==j].float().mean().item() for j in range(4)]
    assert all(np.isfinite(acc))
    return model.weight.detach().numpy(),float(correct.float().mean()),acc
for name,robust in [('ERM',False),('group_DRO',True)]:
    w,a,ga=fit(robust)
    print(name,'weights',w,'test_mean',a,'groups',ga,'worst',min(ga))
```

这个优化并没有精确求解一般非凸极小极大问题；模型在本例为线性，训练仍采用有限步与开发选择。代码展示指数对手如何把学习重点移向冲突组，也展示开发集需要有这些组。若实际训练完全缺失冲突组，给不存在的组加权没有数据可学习；若组内机制另变，该实验也不给普遍保证。

### 8.4 实验四：来源先验、截断和支持的机制检查

本实验没有神经训练，独立检查两个容易被工程实现掩盖的代数边界。第一个从真实来源后验恢复已知输入比，验证漏掉采样先验会产生固定倍数错误。第二个在离散稀有区域计算截断后风险，说明稳定数值可能严重低估真实目标损失。计算精确，不把样本诊断等同于支持证明。

```python
import numpy as np
x=np.linspace(-1,1,101)
w=1+.8*x
rho=.2
eta=rho*w/(1-rho+rho*w)
recovered=(1-rho)/rho*eta/(1-eta)
wrong=eta/(1-eta)
assert np.allclose(recovered,w)
assert np.allclose(wrong,w/4)
p=np.array([.99,.01]); q=np.array([.5,.5]); loss=np.array([0.,1.])
ratio=q/p
truth=q@loss
raw=p@(ratio*loss)
clipped=p@(np.minimum(ratio,10)*loss)
assert np.isclose(truth,.5) and np.isclose(raw,.5) and np.isclose(clipped,.1)
print('prior_factor', (1-rho)/rho,'true_risk',truth,'clipped_risk',clipped)
print('population_weight_ESS_fraction',1/np.sum(p*ratio**2))
# 另构造真正缺失支持的源分布；上面的 p[1]=.01 只是稀有，并非零。
unsupported_source=np.array([1.,0.])
assert np.any((q>0)&(unsupported_source==0))
# 对任意有限权重，源分布零质量的第二个原子仍贡献零，无法恢复目标风险。
for finite_weight in (1.,10.,1e6):
    weighted_loss=unsupported_source@(np.array([1.,finite_weight])*loss)
    assert weighted_loss==0 and truth>0
```

没有目标标签时，来源分类器也许提示存在这类稀有区域，却仍不能告知该区域错误率。如果源概率恰为零，就连上面五十的有限比都不存在；用极大常数代替无穷不会制造标签信息。应将这种情况归为支持不足，选择收集目标标签、缩小服务范围或引入可辩护结构，而不是把权重参数继续增大。

### 8.5 实验五：来源判别训练、独立概率校准与风险评价

最后补一个完整的估计权重流程。源输入为标准正态，目标平移零点七；来源判别的真实后验属于线性 logit 族。预测回归器另在源标签训练集拟合，来源分类器用另一批带域标记的输入训练。将来源 logit 故意放大三倍后，在独立域标记校准集上学习温度，再在独立源风险样本计算重要性估计，最终目标标签仅用于最终测试。域标记不是任务标签，二者权限应分别记录。

校准数据的目标采样比例与来源训练一致，因此赔率校正用百分之二十。真实密度比可计算，作为估计误差参照；估计权重结果接近真实目标风险只是本次有限样本观察，不给出精确有限样本无偏证明。平方损失无界，本实验依赖人工正态模型具有所需矩，不套用前文零到一损失的 Hoeffding 界。

```python
import numpy as np
from scipy.special import expit
from scipy.optimize import minimize_scalar
from sklearn.linear_model import LogisticRegression,LinearRegression
def domain(seed):
    r=np.random.default_rng(seed)
    z=np.r_[r.normal(size=2000),r.normal(.7,1,500)]
    return z,np.r_[np.zeros(2000),np.ones(500)]
r=np.random.default_rng(721)
x=r.normal(size=3000); y=x*x+.2*r.normal(size=len(x))
predictor=LinearRegression().fit(x[:,None],y)
z,d=domain(722)
classifier=LogisticRegression(C=10).fit(z[:,None],d)
zc,dc=domain(723)
raw=3*classifier.decision_function(zc[:,None])
def nll(logT):
    v=raw/np.exp(logT)
    return np.mean(np.logaddexp(0,v)-dc*v)
fit=minimize_scalar(nll,bounds=(-3,3),method='bounded')
T=float(np.exp(fit.x))
assert fit.success and nll(fit.x)<=nll(0)
rv=np.random.default_rng(724)
xv=rv.normal(size=30000); yv=xv*xv+.2*rv.normal(size=len(xv))
odds=np.exp(3*classifier.decision_function(xv[:,None])/T)
w_hat=4*odds
w_true=np.exp(.7*xv-.7**2/2)
loss=(predictor.predict(xv[:,None])-yv)**2
rt=np.random.default_rng(725)
xt=rt.normal(.7,1,30000); yt=xt*xt+.2*rt.normal(size=len(xt))
direct=np.mean((predictor.predict(xt[:,None])-yt)**2)
assert np.isfinite(w_hat).all() and np.all(w_hat>0)
print('temperature',T,'domain_cal_NLL_raw',nll(0),'calibrated',nll(fit.x))
print('risk_known',np.mean(w_true*loss),'risk_estimated',np.mean(w_hat*loss),'target_test',direct)
```

这个流程把训练、校准与最终评价实际分开，但仍不能证明温度修复了全部密度比误差。若来源模型错设，单一温度只能修正有限形式的尺度误差；若目标尾部更远，权重方差会加剧。可继续在开发阶段比较概率校准与风险估计误差，最终测试保持冻结，以免用目标标签偷偷挑最合适密度比模型。

## 9. 标签变化的完整推导与识别反例

<a id="uncertainty-2-detail-35"></a>

### 9.1 两种混淆矩阵不能混用

令 $`J_{ij}=P(H=i,Y=j)`$ 表示源域联合频率矩阵，则 $`J=C\operatorname{diag}(\pi_P)`$。如果使用 J，未知量应是先验比例 $`\frac{\pi_Q(j)}{\pi_P(j)}`$，因为 $`q=Jr`$；如果使用条件矩阵 C，未知量就是目标先验本身。两个写法都可以正确，但把 J 当 C 求逆再把结果解释成先验，会系统性混淆源类别频率。

从全概率公式逐项推导：目标预测为 i 的概率等于对真实类别 j 求和，每项是目标给定 j 时预测 i 的条件概率乘目标先验。标签变化使前一个条件概率等于源对应列，因此得到线性系统。预测器必须在估计这些量前冻结；如果目标适应后又换了分类器，却沿用旧混淆矩阵，线性系统对应的随机变量已经不同。

例如完美分类器 C 为单位阵，但源类别比例为七比三，J 便为对角零点七、零点三。目标预测比例三比七应直接等于目标先验。若误将 J 逆乘目标预测边缘，得到约零点四二九与二点三三三；它们是比例因子而非概率，和并非一。随意再归一化会给另一个错误答案，不能替代重新理解未知量。

<a id="uncertainty-2-detail-36"></a>

### 9.2 后验纠正的分母与零概率边界

在标签变化下，目标联合密度为 $`p(x\mid y)\pi_Q(y)`$，源联合为 $`p(x\mid y)\pi_P(y)`$。只要相应源先验非零，Bayes 公式给

$$
Q(y\mid x)=\frac{\frac{P(y\mid x)\pi_Q(y)}{\pi_P(y)}}{\sum_j\frac{P(j\mid x)\pi_Q(j)}{\pi_P(j)}}.
$$

分母不是可省常数，它依赖输入。如果只乘比例却不归一化，输出不一定是概率，也无法直接用来计算校准指标或概率损失。对于目标密度为零的输入，条件概率值无需影响目标风险；对于目标有质量而源没有对应支持的输入，这个源后验表达无法凭空定义可识别标签规律。

二分类源后验为零点六、源先验为一半、目标正类比例为零点八时，正类未归一化质量零点九六，负类为零点一六，目标后验为 $`\frac67`$。它高于源后验并不说明模型更确信了同一总体，而是先验信息改变。若条件测量机制也变，代数仍可算出一个数，但该数不再自动等于真实目标概率。

<a id="uncertainty-2-detail-37"></a>

### 9.3 近奇异意味着真实的信息不足

对扰动线性系统，若 C 可逆且仅目标边缘有扰动，先验误差为 $`C^{-1}\Delta q`$。若 C 也由有限样本估计，一阶项还包含 $`-C^{-1}(\Delta C)\pi_Q`$。逆矩阵放大两种误差。增加目标无标签数量只压低其中一部分，源小类列的估计噪声可能仍主导；这解释为什么单方面扩充无标签池未必解决问题。

矩阵两列非常相近，意味着不同真实类别在固定预测器输出上几乎不可区分。可以尝试保留连续概率向量或更多特征统计，而不只使用硬分类结果；但相应矩估计和可识别条件仍要成立。更丰富统计可能增加信息，也可能提高维数和估计难度。不能把使用软输出等同于保证矩阵条件良好。

约束最小二乘在概率单纯形内求最接近解释，解决负数和总和问题，但没有消除不确定性。实验二的近奇异矩阵在目标边缘只变化千分之二时，无约束解从三比七跳到一点三比负零点三，约束解贴边。贴边应触发敏感性检查，不应包装成发现目标几乎全为某类的强证据。

<a id="uncertainty-2-detail-38"></a>

### 9.4 两种变化模型可能给出相反解释

同一个输入边缘改变，可以被不同潜在机制解释。标签变化把改变归因于先验，协变量变化把条件标签概率保持；对于一般分布，两种约束同时成立是很强的特殊情况。研究者应根据生成机制、可获得标记及可检验后果选择模型，而不是哪一种适应后测试分数高就事后宣称哪一种假设真实。

若有少量目标标签，最直接的价值之一是核查关键条件关系，而非全部用于再训练。可以比较各类别条件特征分布、校正前后的概率损失与预设群体风险，但检验不拒绝不表示严格相等。样本不足时应报告可识别范围有限；没有显著差异与有证据保证不变，在逻辑上完全不同。

## 10. 最坏组优化的统计与算法细节

<a id="uncertainty-2-detail-40"></a>

### 10.1 最大风险的单纯形表达

对有限 G 个实数 $`r_g`$，有 $`\max_gr_g=\max_{q\in\Delta_G}\sum_gq_gr_g`$。证明任何凸组合都不超过最大值，而把全部质量放到某个最大分量就取到等号。若未来分布仅在固定组条件分布之间混合，这个表达直接给出所有混合的最坏风险；它不是一个近似的机器学习直觉，而是有限维线性优化事实。

若部署组比例只可能在一个较小集合内变化，允许对手在整个单纯形自由集中可能过于保守。可以限制比例相对参考分布的偏离、规定每组上下界，或明确成本加权；这些都会改变最坏目标。修改集合应来自任务与开发协议，不应在测试后把真实不利群体移出集合以提高数字。

如果一个样本可属于多个重叠群体，最大组风险仍有定义，但“任意混合源组条件分布”不一定等于对原人群重分配一次权重，重叠可产生重复计算。应明确组风险是审计指标还是生成混合成分。把性别与年龄的交叉组构成互斥分区，可以得到更直接的混合解释，却会降低每组样本量。

<a id="uncertainty-2-detail-41"></a>

### 10.2 指数对手更新的来源

固定当前组损失，令旧对手权重为 q，考虑最大化 $`\eta\langle q',r\rangle-\operatorname{KL}(q'\Vert q)`$。加上权重和为一的拉格朗日约束，对每个正分量求导，得到新权重正比于旧权重乘 $`\exp(\eta r_g)`$。这是熵几何下的镜像上升，解释了实验三的对数权重更新。

零初始权重在乘法更新中永远为零，因此希望每组都可被关注时应从正权重开始。使用对数参数并减去 logsumexp 可避免指数溢出，不改变归一化权重。对手步长过大可能让注意力在噪声组之间剧烈摆动，过小又可能来不及纠正捷径。有限步结果应报告训练和开发动态，而非只宣称已经达到鞍点。

模型更新把对手权重视作当前固定权重，最小化加权组损失。若对手权重也参与同一次反向传播，代码可能优化出不同目标；实验中特意在无梯度上下文更新对手。组损失是每组内部平均，不是把全样本损失先乘组标签再除总样本数，否则小组的权重仍受频率稀释，与预期极小极大目标不一致。

<a id="uncertainty-2-detail-42"></a>

### 10.3 独立组验证的联合误差

冻结预测器后，设独立验证组 g 有 $`n_g`$ 个样本，损失在零到一之间。条件于组样本数量，对每组应用 Hoeffding，再对 G 组取联合界，可得以至少一减 delta 概率同时成立

$$
\vert \widehat R_g-R_g\vert \le\sqrt{\frac{\log(\frac{2G}{\delta})}{2n_g}}.
$$

因此真实最大组风险不超过各组经验风险加对应半径的最大值。小组半径更大；最大经验风险低，并不意味着最大真实风险也低。如果某组没有样本，上式无法提供非平凡界，零个观测不能解释为零风险。损失无界时需要别的尾部条件，不能直接沿用这个公式。

若在同一验证集上从 K 个事先冻结候选中选择模型，可以对候选与群体共 KG 个事件联合控制。若模型是根据验证标签连续自适应训练出来，有限候选联合界不能直接使用，除非另有复杂度或自适应分析。最终独立测试保留价值就在于阻断开发反馈，避免把选择后最漂亮组指标当作没有选择代价的证据。

<a id="uncertainty-2-detail-43"></a>

### 10.4 群体鲁棒与公平结论的距离

组错误率下降可能有实用意义，但不自动等于机会均等、校准一致或个体公平。不同准则条件化对象不同：按真实阳性计算漏判率，与按预测分数计算校准，不是相同分母。某个最大交叉组零一损失目标，也未必限制每类错误成本或每个部署环节的服务差异。

因此报告需给出目标为何符合用途、各组样本量、错误方向与拒答负担。若一组训练噪声很大，最大风险目标可能牺牲所有人的性能去拟合不可预测噪声，必须区分可修复捷径与本质噪声。目标选择需要业务或科学理由；优化算法只负责在明确目标下寻找解，不能替代目标本身的论证。

## 11. 十六道详细题解

<a id="uncertainty-2-detail-45"></a>

### 11.1 题一：只有目标输入为什么不够

题目设源输入在零一均匀、源标签等于输入，目标输入仍均匀，要求仅用无标签目标数据决定新标签是否取反。解答是不可识别：保留与取反两个目标机制产生完全相同的全部可见数据分布，但对同一分类器风险分别为零和一。任何数据函数在这两个世界中分布相同，不可能同时保证恢复正确机制。需要标签、结构或外部知识排除其中一个世界。

<a id="uncertainty-2-detail-46"></a>

### 11.2 题二：验证输入密度比

题目给源在负一到一区间均匀，目标密度为 $`\frac{(1+.8x)}{2}`$。解答先检查非负性：最小值零点一；再积分，常数部分积分一、奇函数项为零，确为概率密度。比值为一加零点八倍输入，范围零点二到一点八，源平均比为一。目标输入均值为零点八乘源二阶矩，即四除十五；无需拟合分类器便可精确算出。

<a id="uncertainty-2-detail-47"></a>

### 11.3 题三：直线错设下求目标投影

题目用直线拟合平方均值，求上一题目标最优参数。解答对平方风险求截距、斜率的一阶条件，得截距等于响应均值减斜率乘输入均值，斜率等于输入响应协方差除输入方差。响应均值三分之一，交叉矩零点八除五，代入得斜率约零点二七一一九、截距约零点二六一零二。源对称时交叉矩零，故源最优斜率为零；变化来自投影权衡而非标签机制。

<a id="uncertainty-2-detail-48"></a>

### 11.4 题四：无偏风险的稀有区方差

题目源稀有区概率百分之一、目标一半，损失只在区内为一。解答区内权重五十，区外损失为零，所以加权损失均值零点五、二阶矩二十五，方差二十四点七五。n 个独立样本均值方差除以 n。若 n 一千，标准误约零点一五七三；不能因为一千看起来很多，就把零点五估计宣称精确到百分之一。

<a id="uncertainty-2-detail-49"></a>

### 11.5 题五：截断后是否仍无偏

题目将上题权重截到十。解答普通截断风险均值变为百分之一乘十，即零点一，相对真实零点五低了零点四。偏差来自删掉区内四十倍权重，对应源质量百分之一。一般偏差正是 $`E[(w-c)_+L]`$，有界损失时受截尾质量约束。若做自归一化，还应重新计算分母，不能继续套用这个零点一。

<a id="uncertainty-2-detail-50"></a>

### 11.6 题六：来源先验因子

题目来源训练中目标占百分之二十，某输入的来源后验为三分之一，求密度比。解答后验赔率为二分之一，先验校正因子为四，乘积为二。若直接把后验赔率当密度比，得到零点五，差四倍。对于普通风险估计这会直接缩小四倍；对于带固定正则的训练也会改变损失与正则的相对力度。

<a id="uncertainty-2-detail-51"></a>

### 11.7 题七：有效样本量能否证明支持

题目某次源样本全部落在普通区，记录权重都相同，有效样本量等于样本数，是否可证明目标支持被覆盖？解答不能。源极稀有而目标重要的区域可能恰好没被抽到，经验记录无法显示缺失区域。有效样本量只描述已记录权重集中程度；支持来自测度关系和采样知识，不能由一个经验比值完全认证。

<a id="uncertainty-2-detail-52"></a>

### 11.8 题八：条件混淆矩阵求先验

题目给 C 两列分别为零点九与零点一、零点二与零点八，目标预测第一类比例零点四一。解答令目标第一类先验为 a，则零点四一等于零点九 a 加零点二乘一减 a，解得 a 零点三，另一类零点七。先检查列和为一、元素非负，再求解；不要把第一行和作为类别条件概率的归一标准，因为这里列才对应真实类别。

<a id="uncertainty-2-detail-53"></a>

### 11.9 题九：联合频率矩阵的未知量

题目源先验七比三，分类器完美，目标预测比例三比七，若使用源联合频率矩阵应求什么？解答矩阵为对角零点七、零点三，求解得到先验比例三除七与七除三。再分别乘源先验才恢复三比七。解向量不是概率，不需要和为一；若直接归一化它会改变正确含义，必须从模型方程辨认未知量。

<a id="uncertainty-2-detail-54"></a>

### 11.10 题十：标签变化后验纠正

题目源二类先验各半，某输入正类后验零点六，目标正类先验零点八。解答正类比例因子一点六、负类零点四；未归一化质量分别零点九六、零点一六，目标正类后验为零点九六除一点一二，约零点八五七一四。结论要求给定类的输入机制保持且源概率正确，不能只凭总类别比例改变就默认成立。

<a id="uncertainty-2-detail-55"></a>

### 11.11 题十一：奇异矩阵意味着什么

题目固定分类器对每个真实类别都以零点六概率输出第一类，目标输出第一类比例也是零点六，能否恢复先验？解答不能，C 两列相同，任意合法先验映射到相同输出边缘。无穷多个解都与可见数据相容。正则化可以选择其中一个，却是附加偏好而非数据识别；应报告欠识别，而非只输出一个看似精确的比例。

<a id="uncertainty-2-detail-56"></a>

### 11.12 题十二：平均与最坏目标的选择

题目甲两组错误率百分之二与四十，乙都百分之八，源少数组百分之五，求两种目标的选择。解答甲平均为零点九五乘零点零二加零点零五乘零点四，等于百分之三点九；乙百分之八，源平均选择甲。最坏错误甲百分之四十、乙百分之八，最大组目标选择乙。若部署组比例完全未知但组内固定，乙保护的混合范围更广。

<a id="uncertainty-2-detail-57"></a>

### 11.13 题十三：为什么对手权重不是人群比例

题目训练结束对手给某小组百分之八十权重，是否说明目标人群该组占八成？解答不是。指数对手权重由相对损失和优化历史决定，是在不确定集合内寻找不利组合的优化变量；真实组频率由采样与部署机制决定。两者可以偶然相近，但没有估计等式。报告中应分别列源频率、目标频率以及训练对手权重。

<a id="uncertainty-2-detail-58"></a>

### 11.14 题十四：组验证样本不足

题目独立验证有四个组，其中一组只有十条且零错误，可否宣布该组风险为零？解答经验风险为零，真实风险仍不确定。对有界损失，联合 Hoeffding 半径包含分母十，通常很宽；使用精确二项界也会得到显著正上界。若同时审计多组，还需联合控制。没有发生错误不等于错误概率消失，这是小组评估的主要统计代价。

<a id="uncertainty-2-detail-59"></a>

### 11.15 题十五：协变量变化能否破坏弱校准

题目两种输入的真实正类概率分别零点九与零点一，预测器两处均输出零点五。源两种输入各半，目标九比一，条件标签机制保持。解答源预测零点五的集合真实正率零点五，弱校准成立；目标同一预测集合正率零点八二，校准失败。条件概率函数未变，并不保证粗粒度校准性质在输入混合改变后保持；若输出恰是真实条件概率则是更强情形。

<a id="uncertainty-2-detail-60"></a>

### 11.16 题十六：测试标签参与权重选择

题目在十种截断阈值上看目标测试错误，挑最好再报同一测试分数，是否为独立评价？解答不是，测试标签已经进入选择。可以把这批数据明确改为目标开发集，另留最终测试；若比较固定候选且要选择后界，也可使用相应统一控制，但这仍不使旧测试恢复独立。数据名字叫测试不能改变它的实际信息流。

<a id="uncertainty-2-detail-61"></a>

## 12. 校准、保形与迁移之间的精确接口

<a id="uncertainty-2-detail-62"></a>

### 12.1 真条件概率与弱校准不同

若预测概率恰等于真实 $`P(Y=1\mid X)`$，在协变量变化且条件机制保持下，仍等于目标条件概率。再用塔式法则可得目标校准。这是非常强的点态正确性，实际温度缩放或可靠性图只验证较弱分组性质，不能凭一张校准图证明已经估计出每个输入的真实条件概率。

相反，弱校准只要求具有相同预测值的样本平均标签匹配。不同输入在一个分数层中混合时，源域恰好抵消的高估与低估可能在目标重新混合后不再抵消。题十五给出两点精确反例。因此不能说经过源温度校准的模型在任何协变量变化下仍校准；也不能说所有校准方法都必然失效，必须区分性质强弱和变化机制。

同样，整体 Brier 损失变化可以来自输入难度组合、概率误差或两者共同作用。即使真实条件概率预测完全正确，目标更集中在本质模糊输入上，最优 Brier 风险也可能上升。这不是校准退化的直接证据。诊断应同时看条件结构、分辨能力、校准与不可约噪声，而不是只根据一个总体分数推断机制。

<a id="uncertainty-2-detail-63"></a>

### 12.2 普通排名证明为何不能照搬

标准分割保形在校准与测试分数可交换时借助排名证明边缘覆盖。源校准、目标测试一般不再可交换，即使预测器固定也一样；源的残差分位数不能仅凭排名得到目标覆盖。一个简单情况是源很少出现高噪声区域、目标集中该区域，源阈值自然偏小，这与第一章异方差例子的群体差异有共同机制。

[加权保形原论文](https://arxiv.org/abs/1904.06019)讨论的方法在已知协变量比及相应结构下可重新构造权重分布，但不是把训练损失乘权重、再沿用普通源分位数。测试点本身的权重和相应无穷分数原子可能进入有效分位数，估计比值还带来额外误差。若没有给出完整构造与证明，不能把任意加权残差分位数称为有限样本覆盖定理。

本章只证明目标期望损失的重加权恒等式，不从它跳到所有分位数或选择后条件风险的自动保证。期望是线性泛函，分位数是非线性泛函；接受条件风险又是两个期望的比值。方法之间可以组合，但每次从线性风险走到集合覆盖或拒答条件风险，都需要重新处理随机阈值、分母与样本依赖。

<a id="uncertainty-2-detail-64"></a>

### 12.3 目标风险改善不等于个体可信

重要性加权使某个平均目标风险更贴近目标域，不表示每个高置信预测都可靠。群体鲁棒使预设组的平均表现改善，也不保证每个组内部所有子群体或每个输入都受保护。总体、预设组、接受子集和逐输入条件量，是四种不同对象，不能因前一个指标变好便把结论扩展到后几个。

在部署报告中，可以明确逐层证据：某些变化模型下目标平均估计可用；某个预设组集合上独立验证支持最大风险控制；某个冻结拒答规则在目标同分布认证样本下支持接受条件风险上界。这些结论各有适用分布，组合时共同前提必须成立。如果未来机制变化超出前提，旧证据需要重新评估，不能靠“鲁棒模型”标签延续。

<a id="uncertainty-2-detail-65"></a>

## 13. 研究项目与评价协议

<a id="uncertainty-2-detail-66"></a>

### 13.1 一个可拆解的迁移实验矩阵

可以以实验一为起点，分别改变倾斜强度、函数类和源样本量。先保持条件机制正确、使用真实比值，量化纯采样与错设；再用独立来源分类数据估计比值，量化权重估计；最后增加目标条件均值偏移，观察假设错误。每次只改变一个机制，才能解释风险曲线为何变化，而非将所有因素混在一个域编号中。

固定源样本预算时，更强倾斜可能减少目标重要区域证据；固定目标采样预算时，直接有标签目标学习又是另一种信息设定。比较方法应等标签预算、训练步数和可见目标数据，否则优势可能来自额外监督。真实比值应作为机制上限或诊断参照，不应与实际未知比值算法混作相同权限竞赛。

函数类从直线扩展到平方特征后，研究重点应转向有限样本方差和正则，而不是期待重演完全相同收益。若正确模型下加权反而稍差，这可能正是方差代价而非实现错误。应报告多次独立训练重复的分布、配对差值及失败实例，保留不利结果才能检验关于错设与方差的解释。

<a id="uncertainty-2-detail-67"></a>

### 13.2 标签变化项目的分阶段记录

先冻结分类器，用独立源标签集估计条件混淆矩阵；另用目标无标签样本估计输出边缘，再求先验。最终目标标签只用于评价先验估计、概率损失与分类风险。把目标真实比例直接代入的结果单列为已知先验参照，用来区分先验估计误差和后验模型误差，而不是当作可部署方法分数。

随后逐渐使混淆矩阵列接近、减少源小类样本、增加目标无标签样本，观察误差被哪一环节支配。再故意改变给定类别的特征机制，检查线性方程残差和真实比例误差。较小残差并不保证假设正确，因为不同机制可能产生相同低维预测边缘；这类相容反例也应纳入报告，避免把拟合成功误当成因果解释。

<a id="uncertainty-2-detail-68"></a>

### 13.3 群体训练的可重复基线

在实验三中，可加一个固定等组加权基线。它与自适应对手具有不同机制：等组基线相当于预设混合比例，群体鲁棒允许关注更难组。两者都应与普通训练使用同样函数族、正则搜索与开发权限。若仅给鲁棒方法更强正则或更多组标签，不能把全部改善归因于极小极大目标本身。

组定义在训练前冻结，开发与测试按相同定义计算；若想研究隐藏组发现，应另外划分发现集与审计集。对发现出的子组再用同一标签声称显著最差，会有搜索偏差。评价至少列平均、每组、最坏组、样本数、开发选择准则和计算预算；没有这些，漂亮的最坏数字很难复核。

<a id="uncertainty-2-detail-69"></a>

### 13.4 本章实际运行结果及其边界

实验一普通训练目标测试均方误差约零点一零零八六，已知比加权约零点零八零一二；独立源加权风险估计分别约零点一零零六二与零点零七九七四，与直接目标测试接近。加权斜率约零点二五八，靠近总体目标斜率零点二七一；有限样本不要求精确重合。这个结果支持受限投影解释，不证明任意模型或任何倾斜下都有同样收益。

实验二条件数从约一点四六升至五百，目标边缘微扰使先验逆解出现负分量。实验三普通模型测试平均准确率约零点五七八、最坏组约零点一六五；群体鲁棒约零点七九六、最坏约零点七八四，捷径权重相应大幅减少。这里只有单次固定人工数据运行，不能宣称真实应用或多种子优势已得到验证。

实验四完整权重目标风险零点五，截断后普通估计只有零点一，人口层面的有效样本量比例约零点零三九六。它说明偏差可以很大，也说明有效样本量下降的量级；不把这个人口计算冒充任何实际数据都能准确估计的诊断。前四段代码均独立导入依赖、独立进程执行，不读取外部数据或保存参数文件。

第五实验的温度约三点零一零，来源独立校准损失从约零点七六二下降至零点四六五。已知比风险估计约四点二六四，估计比约三点八八八，独立目标测试约三点九四七。已知比估计也有明显有限样本波动，不能把一次估计比更接近测试值解读为估计权重优于真实权重；该现象恰好提醒需要重复与方差分析。五段实验全部实际运行通过断言。

<a id="uncertainty-2-detail-70"></a>

### 13.5 阅读论文时追问什么

阅读协变量变化论文先找支持、权重已知或估计、模型错设及模型选择风险的定义；阅读标签变化论文先找矩阵条件、类别支持和预测器是否冻结；阅读群体鲁棒论文先找组定义、正则和训练与测试风险的区别。证明中的每项条件都对应可能失败的实验机制，按条件读比按算法缩写记忆更有价值。

当论文给出某种一致性或渐近正态结论，要问样本数是哪一部分趋于无穷、维数是否固定、哪些矩阵或权重有界。有限样本应用还需要对应数据规模与误差常数。理论结论、人工机制实验和真实域评价各有证据范围，能够清楚标注范围，本身就是可靠研究的核心技能。
