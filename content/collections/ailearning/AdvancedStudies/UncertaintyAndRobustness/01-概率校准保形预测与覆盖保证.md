## 1. 先区分概率、区间和保证中的随机对象

<a id="uncertainty-1-detail-2"></a>

### 1.1 三种输出回答三种问题

点预测选择一个类别或数值，概率预测描述结果分布，预测集合保留若干可能结果。回归均值的置信区间反映均值参数估计的不确定，单个未来观测的预测区间还必须包含观测噪声；即使均值已经知道得很准确，未来个体仍然随机。把二者都叫置信区间，会让使用者误解区间宽度和覆盖对象。

概率校准讨论某种概率陈述是否与相应频率一致，保形覆盖讨论未来标签是否落入数据构造的集合。一个模型概率不完美，仍可通过独立校准获得边缘集合覆盖；一个概率在总体上校准，也不表示每个个体或子群体都准确。学习本章时，应始终追问条件在什么上、概率对谁取、哪些数据已经冻结。

<a id="uncertainty-1-detail-3"></a>

### 1.2 随机训练、随机校准与随机测试点

训练数据拟合预测器，校准数据决定概率变换或集合阈值，测试点是未来待预测对象。某些保证可以在固定训练数据和模型条件下成立，却仍对校准集与未来点一起取概率。它不等于对每一份已经抽到的校准集，都能保证同样总体覆盖。抽到一份不幸校准集时，条件覆盖可以低于目标。

还要区分理论覆盖和一次测试集经验覆盖。理论是重复数据生成下的概率结论，经验覆盖是有限测试点上的比例，有抽样误差。不能要求每次有限测试都恰好不低于名义水平，也不能看到一次比例达标就说任意新分布都安全。数据交换性、独立性和使用顺序决定可以陈述的保证。

## 2. 概率校准的不同强度

<a id="uncertainty-1-detail-5"></a>

### 2.1 二分类校准与真实条件概率

二分类预测为$p(X)$，常见校准条件是$E[Y\mid p(X)]=p(X)$。真实条件概率为$\eta(X)=P(Y=1\mid X)$，若$p=\eta$则校准，但反向不成立。把所有输入都输出总体正类比例，也可以在该总体上校准，却完全没有区分个体的能力。校准与分辨力必须一起评价。

例如两个等大群体真实正类概率分别零点九与零点一，模型统一输出二分之一。总体正类比例二分之一，因此满足简单概率分组校准；但在两个群体内都偏差零点四。它也无法对高低风险个体排序。这个反例说明“校准良好”不是每个输入都获得真实概率的同义词。

<a id="uncertainty-1-detail-6"></a>

### 2.2 多分类的top-label与classwise

多分类向量为$p_1,\ldots,p_K$，令预测类别 $H=\arg\max_k p_k(X)$、最大置信度 $S=p_H(X)$，并固定并列处理。置信度校准（confidence calibration）要求 $P(Y=H\mid S)=S$；top-label 校准进一步要求 $P(Y=H\mid S,H)=S$，即在每个预测类别内也成立。二者不能混称：后者通过塔式法则推出前者，前者可能靠不同预测类别的正负误差抵消而成立。术语与定义可核对 [Gupta 与 Ramdas 原论文](https://arxiv.org/abs/2107.08353)。

classwise 校准分别要求 $P(Y=k\mid p_k(X))=p_k(X)$；完整向量校准则要求 $E[\mathbf1\{Y=k\}\mid p(X)]=p_k(X)$ 对每个类别成立。完整向量校准推出前述较弱性质，top-label 与 classwise 却分别关注选中类别与所有类别分量，不能未经证明就当作同一要求。不同定义检验不同对象，不能只写一个 ECE 就认为全部通过。

可以手算一个三分类反例：两类输入各占一半，分别固定输出 $(0.8,0.1,0.1)$ 与 $(0.1,0.8,0.1)$。第一类输入真实标签恒为第一类，因此正确率一；第二类输入的真实标签以零点六概率为第二类、零点四概率为第一类，因此正确率零点六。所有输入最大置信度都是零点八，总正确率 $(1+0.6)/2=0.8$，置信度校准成立；但给定预测类别后，正确率分别为一与零点六，都不等于报告的零点八，所以 top-label 校准失败。这个反例把“总体抵消”变成了可逐项复算的现象。

一个模型可在总体最大置信度上看似可靠，却对某一罕见类别系统性错配。概率向量还包含非最大类别的信息，集合预测和代价敏感决策可能使用这些分量。因此评价应说明具体校准对象，必要时按类别和预先指定群体分组，避免用一个总图掩盖重要错误。

<a id="uncertainty-1-detail-7"></a>

### 2.3 分箱ECE的限制

常用ECE按置信度分箱，累计各箱样本权重乘正确率与平均置信度差的绝对值。箱内偏差可能相互抵消，箱数与边界改变结果，少样本箱又有高方差。用同一数据反复调整箱边界后挑最小ECE，会进一步选择指标。它是诊断摘要，不是无条件概率正确证书。

可靠性图应同时给样本量和箱定义，配合NLL、Brier分数及分类表现。总体样本很多不代表尾部高置信区有足够证据，罕见类别也可能几乎没有。对真实决策，最重要的区间或群体可以预先单独报告，而不是事后只展示最平滑部分。

## 3. 适当评分规则与温度缩放

<a id="uncertainty-1-detail-9"></a>

### 3.1 Brier与NLL的条件分解

二分类Brier损失满足$E[(p-Y)^2\mid X]=(p-\eta)^2+\eta(1-\eta)$。第一项衡量预测偏差，第二项是该输入下不可约随机性。多分类Brier可逐类求和。对数损失的条件期望为真实分布熵加真实到预测的KL，因此在足够函数类中由真实概率最小化。这说明适当评分关注完整概率质量，不只是top-label正确。

不同测试分布的不可约噪声不同，原始分数不能脱离任务难度比较。NLL对给真实标签极小概率惩罚很大，数值实现需要稳定log-sum-exp或合理边界处理。截断概率可避免非有限值，但会改变报告细节，应说明阈值，不要用任意裁剪掩盖模型过度自信。

<a id="uncertainty-1-detail-10"></a>

### 3.2 温度缩放保留什么

固定logits$z_k(x)$，温度$T>0$给$p_k=\operatorname{softmax}(z/T)_k$。同一正温度保留每个样本的类别排序，所以通常不改变top-1动作与准确率，却改变概率尖锐程度。它不能修复错误类排序，也不能在任何分布上把模型变成真实条件概率。方法背景可参阅[概率校准原论文](https://arxiv.org/abs/1706.04599)。

温度应在独立概率校准集上选择，测试集用于冻结后评价。若接着做保形集合，应再使用独立集合校准样本，或采用有相应理论的复用方案。不能先用同一校准标签挑温度和分数，再假定这些分数是预先固定，直接套最简单split conformal证明。

<a id="uncertainty-1-detail-11"></a>

### 3.3 最优温度也可能伤害某些群体

总体NLL选择一个标量，是按总体频率权衡，可能主要改善多数群体。某小群体原本偏保守，统一升温可能让它更保守，另一群体仍过度自信。总体分数改善不保证每组改善，也不保证某个高置信接受集风险下降。第三章会将拒答认证作为独立问题，而不是从温度缩放自动继承。

应同时记录冻结前后NLL、Brier、准确率和预设群体诊断。温度拟合只是一参数优化，计算简单不代表不需要数据边界。小校准集可能选到不稳定温度，跨域更可能失效。任何调参都有选择误差，只是维度不同。

## 4. Split conformal的构造

<a id="uncertainty-1-detail-13"></a>

### 4.1 冻结分数再看独立校准标签

先用训练数据固定预测器和非符合度分数$s(x,y)$，数值越大表示候选标签越不符合。校准样本为$n$个独立或可交换数据对，分数$S_i=s(X_i,Y_i)$。给定错误率$\alpha$，取$k=\lceil(n+1)(1-\alpha)\rceil$，阈值为校准分数第k小值；若$k>n$，阈值定义为正无穷。

预测集合为$C(x)=\{y:s(x,y)\le q\}$。回归绝对残差给区间$[\hat f(x)-q,\hat f(x)+q]$；分类可用$1-p_y(x)$，保留概率不小于$1-q$的类别。分数影响效率，覆盖证明主要依赖校准与测试分数交换性，不要求基础模型完全正确。

<a id="uncertainty-1-detail-14"></a>

### 4.2 为什么是n加一的分位数

校准集有n个分数，但证明将未来真实标签分数一起放进来，共n加一个。使用普通经验百分位函数默认插值，可能给出不同阈值，尤其小样本时改变覆盖。应直接实现所需顺序统计量，明确一开始索引从一、代码从零，以及超过n时正无穷规则。

例如n为九、错误率零点一，k为九，取校准最大值；n为五、错误率零点一，k为六，必须用无穷。有限样本量不足时全空间集合是保守但合法结果，不是实现需要强行修成有限的异常。若希望更有效，需要更多校准数据或额外结构，而不是把k夹到n后继续宣称同样保证。

## 5. 排名证明与覆盖含义

<a id="uncertainty-1-detail-16"></a>

### 5.1 无并列时的均匀排名

固定训练数据和所有已冻结选择，设校准与未来点分数可交换，且几乎必然无并列。未来分数在n加一个分数中的排名均匀分布。若其排名不超过k，恰好落在校准第k顺序统计阈值之内，因此覆盖概率为$k/(n+1)$，至少名义的一减错误率。有限分位取整可能使它略高于名义水平。

若分数存在并列，用小于等于阈值的集合通常得到保守覆盖，可通过随机打破并列恢复相应精确随机化结论。不能在没有说明的情况下把等号改成严格小于，尤其离散分类分数和量化输出可能大量相同。证明中的排名约定必须与代码相符。

<a id="uncertainty-1-detail-17"></a>

### 5.2 边缘保证不等于每个x的保证

标准split conformal保证对随机校准集和未来点联合平均的覆盖。它不说给定某个输入x，覆盖一定达到目标，也不说每个群体都达到目标。难群体占比很小时，整体可以达标而几乎全部漏掉该群体。无限宽集合当然能覆盖，但想同时保持任意条件覆盖与实用效率，需要额外条件或放宽目标。

相关不可能性研究可参阅[条件预测推断边界论文](https://arxiv.org/abs/1903.04684)。准确表述不是保形完全没用，而是清楚它提供哪种保证，并根据用途增加预设分组、结构假设或其他认证。不能把边缘覆盖宣传为每个人都拥有同样可靠度。

<a id="deep-dive-3"></a>

<a id="uncertainty-1-detail-18"></a>

### 5.3 总体达标却集中遗漏的反例

设九成数据来自几乎无噪声群体，一成来自高噪声群体。固定宽度残差阈值可能把大多数预算用于覆盖容易群体，而高噪声群体覆盖很低。若总体目标九成，极端情况下覆盖全部容易群体就足够，即使困难群体全漏。这个例子与概率统一输出总体均值的反例类似，都说明平均约束可以隐藏异质性。

评价应同时报告总体和预先指定组覆盖、区间长度或集合大小、空集合与全类别集合比例。组间样本量不同，经验比例精度也不同；不能给一个十样本小组报九成覆盖，就说它与上万样本总体具有相同证据。统计范围应与随机单位和样本数对应。

<a id="uncertainty-1-detail-19"></a>

## 6. 手算阈值、区间与分类集合

<a id="uncertainty-1-detail-20"></a>

### 6.1 残差顺序统计量

校准残差为零点一、零点二、零点四、零点八、一点五，n为五，错误率三分之一，k为四，阈值零点八。若新点预测均值二，区间为一点二到二点八。它覆盖的是未来Y而不是未知均值参数，不能把区间解释为模型系数的置信区间。

若选择错误率零点一，k为六则区间全实线。若有人直接取校准最大一点五，会得到更短区间，但已不再是当前有限样本规则。精简实现最容易省略这个边界，教材必须把它作为主逻辑而不是脚注，因为它体现理论保证需要真实样本量支撑。

<a id="uncertainty-1-detail-21"></a>

### 6.2 分类集合可为空或多标签

若三类概率为零点六、零点三、零点一，阈值q为零点七五，分数一减概率小于等于q保留前两类。若阈值很小，全部类别都可能被排除；若很大，则全部保留。空集合不自动表示模型正确拒答，整体覆盖理论允许少量不覆盖事件，但决策系统还需定义怎样处理。

集合平均大小越小通常越便于使用，但只有在目标覆盖和任务条件相同时才有可比意义。人为删掉空集合或特别大的集合再报覆盖，会选择测试样本。保形集合不是免费把任意模型变得准确，而是以集合大小换取明确范围的可靠性声明。

<a id="sec-5"></a>

<a id="uncertainty-1-detail-22"></a>

## 7. 自适应分数提高效率但不偷换保证

<a id="uncertainty-1-detail-23"></a>

### 7.1 归一化残差与尺度模型

如果噪声随输入变化，可用训练阶段固定的正尺度$\hat\sigma(x)$，分数为$|y-\hat f(x)|/\hat\sigma(x)$，集合宽度随尺度变化。只要分数在校准前冻结并保持交换性，基础尺度不完美也仍可获得相应边缘覆盖。尺度更准可能提高分配合理性，但不是自动精确条件覆盖。

尺度不能在同一集合校准标签上反复选择后仍沿用最简单证明。可以在训练内部另分样本拟合均值和尺度，或者用独立开发数据选择。若尺度有零或负值，应明确定义正下界或模型形式，并冻结规则。数值稳定修正也属于分数定义，不能在测试看到异常后再按结果调整。

<a id="sec-5-1"></a>

<a id="uncertainty-1-detail-24"></a>

### 7.2 分位回归与CQR边界

可以训练上下条件分位预测，再取分数为下界减真实值与真实值减上界的最大值，校准后扩展或收缩区间。这类方法利用异方差结构，背景见[CQR原论文](https://arxiv.org/abs/1905.03222)。分位模型和分数在校准前固定，覆盖仍主要是边缘结论，不能因基础模型叫条件分位就自动把最终保证说成对每个x精确有效。

该分数可以为负，表示真实值在基础区间内部且离边界有余量，校准阈值也可能为负，产生收缩。若改用截零分数，是另一合法但通常更保守的规则，需要按实际定义实现。分位交叉、空区间和数值边界都应明确，不能只画一条漂亮带状图掩盖这些情况。

<a id="uncertainty-1-detail-25"></a>

## 8. 数据边界与评价协议

<a id="uncertainty-1-detail-26"></a>

### 8.1 至少分清训练、概率校准、集合校准与测试

若既拟合模型又温度缩放再做集合，四种角色最好清楚分开。训练拟合参数，概率校准选择温度，集合校准只计算已冻结分数阈值，测试最后评价。可以采用其他有理论支持的交叉或全保形方法，但不能在没有相应论证时随意复用标签。更多数据利用不等于所有独立性条件仍然成立。

多个候选分数和模型可先在开发阶段选择，再用独立校准阈值。若需要从同一认证数据中选规则，第三章会用有限冻结网格和联合界处理另一种风险目标。不能把那套选择保证与当前单分数排名证明混成一回事，每种方法都要追踪实际搜索范围。

<a id="uncertainty-1-detail-27"></a>

### 8.2 交换性与真实部署变化

同一人重复测量、时间序列和群体来源可能破坏逐行交换假设。随机打乱文件顺序不使真实依赖消失；按时间切分也不自动让未来与过去同分布。可以采用组单位或特定时序方法，但保证与效率要重新说明。测试域变化更不能仅靠原校准阈值自动获得分布无关保护。

第二章会讨论协变量与标签变化以及加权条件，本章先强调基础边界：分布无关不是没有任何假设，而是不要求具体参数分布形式，在交换性等条件下给出有限样本结论。把这句话讲清，比泛泛宣称任意模型任意数据都可靠更有帮助。

<a id="uncertainty-1-detail-28"></a>

## 9. 四个独立CPU实验

<a id="uncertainty-1-detail-29"></a>

### 9.1 实验一：枚举排名与并列保守性

用四个不同分数枚举全部排列，前三个视为校准，最后一个视为测试。错误率四分之一，阈值为校准最大值，恰有四分之三排列覆盖测试。这是有限对称性精确检查，没有Monte Carlo波动。再检查全并列时小于等于规则保守覆盖，以及样本不足时正无穷边界。

```python
import itertools
import math
import numpy as np

def threshold(scores, alpha):
    values = np.asarray(scores, dtype=float)
    k = math.ceil((len(values)+1)*(1-alpha))
    return np.inf if k > len(values) else float(np.partition(values, k-1)[k-1])

covered = []
for row in itertools.permutations([.1, .2, .7, 1.4]):
    q = threshold(row[:3], .25)
    covered.append(row[3] <= q)
assert np.mean(covered) == .75
assert threshold([1., 2., 3.], .1) == np.inf
assert all(0. <= threshold([0., 0., 0.], .25) for _ in range(3))
probability = np.array([.6, .3, .1])
assert np.array_equal(1-probability <= .75, [True, True, False])
print('exact permutation coverage/tiny-sample threshold:', np.mean(covered),
      threshold([1., 2., 3.], .1))
```

这个实验只验证排名逻辑，没有训练模型，因此把全部分数当作固定互异值是刻意简化。真正模型中分数随机，交换性让未来身份在联合排列中对称，才把这个计数转为覆盖结论。若模型或阈值选择偷偷依赖测试标签，对称性就不再来自同一构造。

<a id="uncertainty-1-detail-30"></a>

### 9.2 实验二：完整分类训练、温度与集合校准

人工二分类真实机制为线性logit，先训练逻辑回归，再故意把冻结logits放大三倍制造过度自信。独立概率校准集选择正温度，另一独立集合校准集计算非符合度阈值，测试最后只读评价。这个设计把四类数据角色分开，不把温度拟合数据再当独立集合校准。所有数据由独立随机流在内存生成。

```python
import math
import numpy as np
from scipy.special import expit
from scipy.optimize import minimize_scalar
from sklearn.linear_model import LogisticRegression

def generate(n, seed):
    rng = np.random.default_rng(seed)
    x = rng.normal(size=(n, 2))
    eta = expit(2*x[:, 0]-1.2*x[:, 1]+.4)
    y = (rng.random(n) < eta).astype(int)
    return x, y

def nll(logit, y):
    return float(np.mean(np.logaddexp(0., logit)-y*logit))

train_x, train_y = generate(1000, 501)
temp_x, temp_y = generate(800, 502)
conf_x, conf_y = generate(1200, 503)
test_x, test_y = generate(10000, 504)
model = LogisticRegression(C=10., max_iter=1000).fit(train_x, train_y)
coefficient = model.coef_.copy()
cal_logits = 3*model.decision_function(temp_x)
result = minimize_scalar(lambda log_t: nll(cal_logits/np.exp(log_t), temp_y),
                         bounds=(-3, 3), method='bounded')
candidates = [1., float(np.exp(result.x))]
temperature = min(candidates, key=lambda t: nll(cal_logits/t, temp_y))
assert temperature > 0
assert nll(cal_logits/temperature, temp_y) <= nll(cal_logits, temp_y)+1e-12
conf_probability = expit(3*model.decision_function(conf_x)/temperature)
conf_true = np.where(conf_y == 1, conf_probability, 1-conf_probability)
scores = 1-conf_true
alpha = .1
k = math.ceil((len(scores)+1)*(1-alpha))
q = np.inf if k > len(scores) else np.partition(scores, k-1)[k-1]
raw_test_logits = 3*model.decision_function(test_x)
probability = expit(raw_test_logits/temperature)
class_probability = np.stack([1-probability, probability], 1)
sets = 1-class_probability <= q
coverage = sets[np.arange(len(test_y)), test_y].mean()
assert np.array_equal(raw_test_logits >= 0, raw_test_logits/temperature >= 0)
assert np.array_equal(coefficient, model.coef_)
assert sets.shape == (10000, 2)
print({'temperature': temperature, 'test_nll_raw': nll(raw_test_logits, test_y),
       'test_nll_scaled': nll(raw_test_logits/temperature, test_y),
       'test_brier': float(np.mean((probability-test_y)**2)),
       'set_coverage': float(coverage), 'mean_set_size': float(sets.sum(1).mean()),
       'empty_fraction': float((sets.sum(1) == 0).mean())})
```

校准集目标改善是按其自身选择的预期结果，测试分数是否改善则是独立观察，不是所有温度缩放任务的保证。集合覆盖也不要求这一次测试比例恰好超过零点九，因为理论对校准与未来点联合平均。代码不以测试表现选择温度、阈值或重新训练。

<a id="uncertainty-1-detail-31"></a>

### 9.3 实验三：异方差回归的总体与组覆盖

输入均匀分布在负一到一，均值为二倍输入加正弦，最高一成输入区域噪声标准差一，其余为零点一。均值模型用训练集拟合，尺度用另一个训练内部样本按预定组估计，集合校准仍独立。比较固定绝对残差与归一化残差，报告总体和两组覆盖及长度。尺度是从数据估计，不调用真实测试噪声作为额外答案。

```python
import math
import numpy as np
from sklearn.linear_model import Ridge

def generate(n, seed):
    rng = np.random.default_rng(seed)
    x = rng.uniform(-1, 1, n)
    group = x > .8
    sigma = np.where(group, 1., .1)
    y = 2*x+np.sin(3*x)+sigma*rng.normal(size=n)
    return x, y, group

def features(x):
    return np.stack([x, np.sin(3*x)], 1)

def quantile(scores, alpha=.1):
    k = math.ceil((len(scores)+1)*(1-alpha))
    return np.inf if k > len(scores) else float(np.partition(scores, k-1)[k-1])

x, y, _ = generate(1000, 511)
model = Ridge(alpha=.01).fit(features(x), y)
sx, sy, sg = generate(600, 512)
scale_residual = np.abs(sy-model.predict(features(sx)))
scales = np.array([max(.01, float(scale_residual[sg == g].mean())) for g in [False, True]])
cx, cy, cg = generate(1000, 513)
cal_residual = np.abs(cy-model.predict(features(cx)))
plain_q = quantile(cal_residual)
scaled_q = quantile(cal_residual/scales[cg.astype(int)])
tx, ty, tg = generate(20000, 514)
residual = np.abs(ty-model.predict(features(tx)))
widths = {'plain': np.full(len(tx), plain_q), 'scaled': scaled_q*scales[tg.astype(int)]}
for name, radius in widths.items():
    included = residual <= radius
    result = {'method': name, 'coverage': float(included.mean()),
              'mean_length': float((2*radius).mean())}
    for group in [False, True]:
        mask = tg == group
        assert mask.any()
        result['hard' if group else 'easy'] = float(included[mask].mean())
    print(result)
assert np.all(scales > 0) and np.isfinite(scaled_q)
```

归一化分数可能重新分配长度，改善困难组覆盖，但标准排名证明仍只给边缘保证。它也未必在所有数据上缩短平均长度：固定宽度方法可能通过几乎忽略困难组得到短平均区间。效率比较必须在相同可靠性目标下进行，不能把覆盖不同群体的方案仅按平均长度排名。

<a id="uncertainty-1-detail-32"></a>

### 9.4 实验四：给定校准集的覆盖会波动

令分数独立均匀分布，校准十九条、错误率零点一，阈值为第十八顺序统计量。给定这份校准集，下一分数被覆盖概率就是阈值本身，它在不同校准集之间随机变化。重复模拟检查其平均接近零点九，并显示相当一部分校准集的条件覆盖低于零点八五。这个实验直接区分边缘覆盖与校准条件高概率保证。

```python
import numpy as np
from scipy.stats import beta

rng = np.random.default_rng(521)
n, k, repeats = 19, 18, 20000
scores = rng.uniform(size=(repeats, n))
threshold = np.partition(scores, k-1, axis=1)[:, k-1]
conditional_coverage = threshold
assert abs(conditional_coverage.mean()-.9) < .005
bad_fraction = float((conditional_coverage < .85).mean())
expected_bad = float(beta.cdf(.85, k, n+1-k))
assert abs(bad_fraction-expected_bad) < .015
assert bad_fraction > .05
print('marginal mean/low conditional fraction/theory:', conditional_coverage.mean(),
      bad_fraction, expected_bad)
```

这里条件是给定随机校准集，不是给定输入x的条件覆盖，两者又是不同概念。若希望以高概率保证固定校准后总体风险，需要容忍界、风险控制或其他专门构造，不能把标准九成排名覆盖直接当成九成置信的固定规则风险保证。第三章将采用冻结网格和联合认证明确处理。

## 10. 十六道进阶练习与详细解答

<a id="uncertainty-1-detail-34"></a>

### 10.1 校准为什么不等于有分辨力

题目：所有人都输出总体正类比例，是否可能校准？解答：可以，给定同一个预测概率后标签平均频率正好相符，但模型没有区分任何个体。若不同群体风险相反，组内还可能严重失配。应同时检查适当评分、排序能力和具体群体，而不是用一个校准标签替代全部质量判断。

<a id="uncertainty-1-detail-35"></a>

### 10.2 top-label是否检查所有概率分量

题目：最大置信度与总体正确率一致，能否推出 top-label 校准，或者每个类别概率都正确？解答：都不能。前一条件仅是置信度校准 $P(Y=H\mid S)=S$；top-label 校准还要求给定预测类别 $H$ 后成立，即 $P(Y=H\mid S,H)=S$，第 2.2 节的两群体反例说明总体误差可以抵消。即便后一个较强条件成立，也只约束被选类别的正确事件，未检查每个非最大类别的概率分量。classwise 与完整向量校准另有要求，集合构造和代价决策可能使用这些额外信息，不能把几种名称混用。

<a id="uncertainty-1-detail-36"></a>

### 10.3 温度缩放能否修复准确率

题目：正标量温度改变softmax，top-1通常会变吗？解答：不会，除数正值保留logit排序，平局规则一致时类别不变。它调整尖锐程度而不改错误排序。若测试准确率显著变化，应检查是否还有其他变换或数值平局。概率改善与分类改善是不同结论。

<a id="uncertainty-1-detail-37"></a>

### 10.4 为什么概率和集合校准要分开

题目：先在校准标签上选温度，再用同一标签算保形分位数，能否直接引用固定分数排名证明？解答：不能直接引用，因为分数函数已经依赖这些校准标签，未来点没有对称参与选择。可以用独立数据或有对应理论的复用构造。更多数据利用需要新论证，不能假定名称仍叫校准就保持全部条件。

<a id="uncertainty-1-detail-38"></a>

### 10.5 n加一分位为什么不可夹紧

题目：五条校准、错误率零点一，k为六，改用最大残差是否无害？解答：不无害，原规则取无穷才保留当前保证。夹到五得到有限区间，但其无并列排名覆盖最多对应五除以六，不达到九成。样本不足是真实信息限制，不是代码需要掩盖的异常。可以增加数据或改变目标。

<a id="uncertainty-1-detail-39"></a>

### 10.6 并列为什么用小于等于

题目：分数全部相同，严格小于阈值会怎样？解答：全部候选真实分数都不满足严格小于，可能导致零覆盖；小于等于则全部覆盖。离散分数不能忽略并列。若需要精确随机化，应明确额外随机规则并纳入证明，而不是任意改变比较符号。

<a id="uncertainty-1-detail-40"></a>

### 10.7 边缘九成能否每个人九成

题目：标准保形总体覆盖九成，能否承诺每个输入都九成？解答：不能。保证对校准集和未来点平均，困难小群体可能集中漏掉。精确条件覆盖与实用有限集合需要额外假设或放宽，不能自动从边缘结论推出。应按用途预设分组诊断或专门方法，并说明其不同目标。

<a id="uncertainty-1-detail-41"></a>

### 10.8 固定宽度更短是否更好

题目：异方差实验固定区间平均更短，能否直接说比尺度法高效？解答：不能，它难组覆盖很低，两个方案实际保护不同。平均长度只能在共同可靠性目标下比较，否则忽略困难群体也能人为缩短。应同时报告总体、组覆盖和长度，明确取舍而不只选好看的指标。

<a id="uncertainty-1-detail-42"></a>

### 10.9 尺度模型不准会失去什么

题目：归一化残差尺度估计不准，是否必然失去边缘覆盖？解答：只要尺度正、分数在独立校准前冻结并保持交换性，标准排名仍可给边缘保证；主要影响集合效率和分配。条件覆盖则没有自动保证。若尺度根据同一校准标签反复调整，冻结条件失效，需另行分析。

<a id="uncertainty-1-detail-43"></a>

### 10.10 CQR分数能否为负

题目：真实值位于基础分位区间内部，最大边界残差可以负吗？解答：可以，两项都负时最大值仍负，表示有内部余量。校准分位也可负，产生收缩。若截零分数，得到另一通常更保守定义。实现必须与证明对应，不能因不熟悉负分数就随意改掉。

<a id="uncertainty-1-detail-44"></a>

### 10.11 一次测试覆盖低于名义是否违规

题目：分类实验测试覆盖零点八九八四而目标零点九，是否证明方法错？解答：不能这样判断，有限测试比例随机，固定校准集条件覆盖也随机。理论平均结论不要求每次经验比例达标。需要检查条件和统计波动，而不是看到一个略低数字就修改阈值直到测试通过，后者反而破坏独立评价。

<a id="uncertainty-1-detail-45"></a>

### 10.12 交换性是否等于文件随机打乱

题目：时间序列打乱行顺序后就可引用独立保形吗？解答：不会，真实联合依赖与机制变化不因排序改变消失。需要适合组或时间结构的方法及对应保证。交换性是生成分布的性质，不是文件存储顺序。重复个体也应按真实单位设计校准与评价。

<a id="uncertainty-1-detail-46"></a>

### 10.13 条件在校准集和条件在x一样吗

题目：给定校准集后覆盖会波动，与给定输入的覆盖是否同一问题？解答：不是。前者固定随机阈值后对未来总体取概率，后者固定输入位置讨论标签不确定性。两者都不同于标准边缘联合平均，任何一个较强保证都需要相应构造，不能把术语中的条件二字混用。

<a id="uncertainty-1-detail-47"></a>

### 10.14 空分类集合能否删掉再报覆盖

题目：集合为空时系统转人工，评价只统计非空集合覆盖是否仍是原保形保证？解答：不是同一个目标，接受事件会选择测试点，条件覆盖需要另外分析。应报告全样本集合覆盖和空集合率，若评价转人工后的服务风险，还要定义审核成本与错误。第三章将单独研究拒答认证。

<a id="uncertainty-1-detail-48"></a>

### 10.15 多组阈值是否等于任意条件覆盖

题目：预设三组分别校准，是否获得每个x可靠？解答：没有，只在每组内平均，并对相应校准随机性取概率。组内仍可异质，极小组可能只能取无穷。若看标签后随意寻找坏组再认证，还涉及选择问题。组定义和保证范围都要事先明确。

<a id="uncertainty-1-detail-49"></a>

### 10.16 完整可靠性实验怎样验收

题目：最少应保留哪些结果？解答：训练与各类校准角色、冻结分数、分位数边界、交换假设、总体与预设组覆盖、集合大小及原始测试计数，再说明一次经验值与理论不同。代码应有手算和独立进程运行证据。只有这些对象对齐，才知道所谓可靠性到底保护了什么。

<a id="uncertainty-1-detail-50"></a>

## 11. 把排名证明补到可独立重建

<a id="uncertainty-1-detail-51"></a>

### 11.1 校准阈值与联合排名的事件对应

将n个校准分数和未来分数一起排序。无并列时，若未来分数在前k名中，那么删掉未来分数后，校准第k小值必不小于它；若未来分数排名超过k，则前k个全为更小校准分数，所以它超过阈值。两事件等价。交换性使每个身份占据每个排名的概率相同，得到覆盖k除以n加一。

这个计数证明不需要基础模型输出概率准确，也不需要残差服从高斯；但需要相同固定分数函数和联合交换。模型训练可先任意复杂，只要训练数据与校准未来按协议分离，就能在固定训练结果下应用。若测试分数和校准分数经过不同预处理或时间规则，事件虽还能排序，对称身份论证却没有相同基础。

<a id="uncertainty-1-detail-52"></a>

### 11.2 有并列的保守方向

若多个分数相等，可以想象附加独立连续随机数形成字典序，只为证明排名对称。实际集合使用原分数小于等于阈值，会至少包含随机打破并列规则覆盖的真实标签，因此覆盖不低于相应水平。它可能明显保守，例如所有分数相同则覆盖一，而非恰好名义值。

如果为了缩集合在并列处随机接受，需要把随机化纳入算法和保证，并明确部署能否接受同输入输出随机集合。固定严格小于不是同一件事。离散分类、小数截断和量化预测都会增加并列，所以它不是只在理论零概率事件上才重要的细节。

<a id="uncertainty-1-detail-53"></a>

### 11.3 分数单调变换何时保持集合

对所有样本和候选标签施加同一个严格递增变换，顺序统计阈值相应变换，集合不变。它说明分数数值单位本身可以调整，而关键排名保持。若变换依赖输入x，例如除以不同尺度，就改变跨样本排名，集合可不同，但只要规则独立冻结，仍可重新校准并建立相同类型边缘保证。

非严格变换可能制造并列，通常需要重新核对保守方向；对每组单独排序又变成组校准方法。不能因两个分数在每个样本内部类别排序相同，就认为最终保形集合相同，因为阈值由跨样本真实标签分数组成。温度缩放保留top-1排序，仍可能改变集合大小与阈值，这正是概率和集合不同层次的例子。

<a id="uncertainty-1-detail-54"></a>

### 11.4 模型选择为何破坏最简单对称性

假设有很多分数候选，观察校准标签后选择让校准残差特别小的一个。未来点没有参与这种选择，因此即使原始数据独立，选中函数下校准分数也不再像未来分数的对称样本。极端可以选择记住全部校准标签却对新点任意预测的函数，校准残差零不代表未来覆盖。

独立开发集选模型，再用新校准集算阈值，可以恢复固定函数条件。全保形等方法则让候选未来标签对称参与拟合，计算和推理对象不同。交叉保形、交叉验证残差与直接合并也各有条件，不能只因都用了交叉就继承同一精确公式。本章使用最清楚split方案，先把可证范围讲透。

<a id="uncertainty-1-detail-55"></a>

## 12. 校准条件风险与容忍保证

<a id="uncertainty-1-detail-56"></a>

### 12.1 连续分数的概率积分变换

固定训练模型，设分数分布函数F连续，校准分数独立同分布。当$1\le k\le n$且采用有限顺序统计量阈值时，$U_i=F(S_i)$独立均匀，$F(q)$是第k均匀顺序统计量，分布为$\operatorname{Beta}(k,n+1-k)$。给定校准集后，下一分数被阈值覆盖的概率正是F(q)，所以它本身随机，均值为k除以n加一。

若$k=n+1$，约定阈值为正无穷，覆盖概率恒为一，属于单点退化情形；不能把第二参数为零直接代入上述Beta分布。

这比只说边缘覆盖更具体：同一方法在不同校准集上会有波动。第四实验的n十九、k十八，约五分之一校准集条件覆盖低于零点八五，却与总体平均约零点九完全相容。概率论没有矛盾，错误来自把平均结论误读成每份校准数据的固定规则证书。

<a id="uncertainty-1-detail-57"></a>

### 12.2 从二项尾部选择更保守阈值

若希望以至少 $1-\delta$ 的校准抽样概率，让冻结阈值的未来覆盖不低于 $1-\alpha$，目标应写成

$$
\Pr_{\mathrm{cal}}\{F(q)\ge1-\alpha\}\ge1-\delta.
$$

这里继续要求固定分数、独立同分布校准与未来数据、连续分数分布；它比仅有交换性的边缘覆盖用了更强条件。设 $q=S_{(k)}$，连续性使严格与非严格边界的区别概率为零。事件 $F(S_{(k)})<1-\alpha$ 等价于至少 $k$ 个均匀值落在 $[0,1-\alpha)$ 内，故其概率精确等于

$$
\Pr\{\operatorname{Bin}(n,1-\alpha)\ge k\}
=\sum_{j=k}^{n}\binom nj(1-\alpha)^j\alpha^{n-j}.
$$

因此可事先选择满足这个尾和不超过 $\delta$ 的最小整数 $k\in\{1,\ldots,n\}$，以尽量减小集合。若没有有限 $k$ 满足，仍可采用无穷阈值，但不能把它报告成有用的有限预测区间。选择 $k$ 只使用预定的 $n,\alpha,\delta$；若再查看校准误差挑分数，需另行处理选择。

**先判断样本数够不够。** 对所有有限阈值中最大的 $k=n$，失败概率仍为 $(1-\alpha)^n$，因此存在有限阈值的充要条件是 $(1-\alpha)^n\le\delta$，即

$$
n\ge\left\lceil\frac{\log\delta}{\log(1-\alpha)}\right\rceil.
$$

例如目标未来覆盖百分之九十、外层置信水平百分之九十五，至少需要 $n=29$ 才可能获得这种有限顺序统计量证书。$n=19$ 即便取校准最大分数，失败概率也为 $0.9^{19}\approx0.135085$，超过 $0.05$。$n=29$ 取最大分数时，失败概率为 $0.9^{29}\approx0.047101$，终于达标。这里“至少二十九”仅针对允许取最大分数的这种构造，并未保证集合足够窄。

同样 $n=29$ 下，通常的边缘百分之九十覆盖取 $k=27$，其平均覆盖为 $27/30=0.9$，但条件覆盖低于 $0.9$ 的校准集比例为 $\Pr\{\operatorname{Bin}(29,0.9)\ge27\}\approx0.434960$，远高于外层允许的 $0.05$；不能因为平均等于目标就宣称更强目标达标。此例取最大分数时平均覆盖变成 $29/30$，体现更强保证付出的保守性。存在并列分数时，简单 Beta 等式需要修订；仅交换而非独立的数据也不能无条件保留独立二项尾和。

第三章的风险认证同样具有外层高概率结构，但保护的是接受条件错误率。本节保护完整预测集合的总体覆盖，两个事件及其有效样本数不同，不能仅凭都有二项分位数就互换公式。

<a id="uncertainty-1-detail-58"></a>

### 12.3 无分布形式不等于无信息代价

越强条件化、越小错误预算、越高外层置信度，都需要更大样本或更宽集合。若小组只有几条校准，想在高置信下保证极高覆盖，数据可能只支持全空间集合。把所有结果都修成有限漂亮区间，会掩盖真实证据不足。一个输出无穷或无法认证的规则有时反而是正确结论。

分布形式假设可以换取效率，例如可信高斯残差模型或已知尺度结构，但其正确性需验证。没有方法能无条件同时获得任意个体精确覆盖、短区间、极少校准和任意变化鲁棒。理解各项保证的资源代价，是研究不确定性的核心，而不是寻找一个能把所有条件都省掉的名称。

<a id="uncertainty-1-detail-59"></a>

## 13. 预先指定群体的覆盖

<a id="uncertainty-1-detail-60"></a>

### 13.1 分区式组校准的排名证明

设$g(x)$在校准前冻结，把输入划成若干互斥组。每组单独收集真实标签分数，按该组样本数$n_g$计算$k_g$和阈值$q_g$，新点使用所属组阈值。给定未来组别与相应样本数，组内分数在适当条件下交换，重复排名证明可得到该组的边缘覆盖。小样本组阈值可能无穷。

它保障的是组内平均，并对组校准随机性取概率，不是每个x条件覆盖，也不自动是全部组同时满足某固定校准条件覆盖的高概率事件。互斥分区下每个点只用一个组规则，单点组条件陈述和跨组同时认证是不同问题。若需要后者，应明确外层误差预算与联合界，而不是随意混用Bonferroni。

<a id="uncertainty-1-detail-61"></a>

### 13.2 组定义可以学，但要控制数据权限

可以用训练数据学习一个分区，再对独立校准数据冻结使用。此时条件于训练得到的分区应用组内证明，通常比看到校准失败后不断细分更清楚。如果按同一校准标签寻找最差区域，再为它声明独立组保证，搜索已经使用证据，需要新的数据或更强选择理论。

重叠群体也更复杂。一个点同时属于多个组，取所有集合交集可缩小集合，但不自动保留每组原覆盖，因为多个遗漏事件会合并；取并集较保守但变大。需要按具体目标分配错误预算或设计专门方法。不能把分区结论机械复制到任意交叠敏感属性组合。

<a id="uncertainty-1-detail-62"></a>

### 13.3 标签条件覆盖的另一种分组

分类时可按真实标签分校准分数，每个候选标签y使用该标签阈值$q_y$，集合包含满足$s(x,y)\le q_y$的候选。虽然预测时真实标签未知，但枚举候选时可以使用它自己的阈值，因此算法合法。在相应组内交换条件下，可得到给定真实标签类别的覆盖陈述。

这不等于给定预测类别或某标签被纳入集合后的正确率。前者条件是实际Y，后者条件是预测事件，概率方向不同。罕见类别样本不足仍会导致大集合或无穷阈值。若业务关心少数类召回型保护，标签条件可能有用；若关心接受某类后错误风险，则要另做相应认证。

<a id="uncertainty-1-detail-63"></a>

### 13.4 组覆盖与公平目标不是自动等价

不同群体同样覆盖，区间长度可能差很多，说明噪声或信息差异；相同长度也可能导致覆盖不同。公平应用还涉及错误成本、服务机会和拒答负担，不能只凭一个覆盖数字宣布全部公平。应把统计目标与价值判断分开，报告各项实质取舍。

总体覆盖的理论保护也不应被用于掩盖困难群体，本章异方差反例就是明确警示。分组评价有助发现问题，分组校准提供某类更强陈述，但并不消除组内异质性。选择分组粒度需要考虑用途、样本量和未知区域，而不是把组数无限增加后仍期待每组都有短区间。

<a id="uncertainty-1-detail-64"></a>

## 14. 分位、概率与集合效率的连接

<a id="uncertainty-1-detail-65"></a>

### 14.1 pinball损失与条件分位

分位回归常最小化$\rho_\tau(y-q)=(y-q)(\tau-\mathbf1[y<q])$。在连续条件分布下，对q的期望导数为$F(q)-\tau$，因此最小点是相应分位。若分布有原子，最优分位可以成区间，需要用次梯度条件。这个目标估计结果分布的某个位置，不是均值，也不直接提供有限样本覆盖。

用两个分位形成基础区间，再做独立保形校准，可以纠正某些整体偏差。若基础区间已适应噪声，校准修正可能较小；若分位模型错误，仍可边缘覆盖却集合很宽。分位损失、保形排名和最终区间效率是不同环节，每个都有独立假设与误差。

<a id="uncertainty-1-detail-66"></a>

### 14.2 温度目标的凸结构与局限

固定logits，令逆温度为$\beta=1/T>0$。单样本NLL为$\log\sum_k e^{\beta z_k}-\beta z_y$，一阶导为预测加权logit均值减真实类logit，二阶导为相应logit方差，非负。因此对逆温度的目标具有清楚凸结构，和任意深网络端到端训练不同。

但小维凸优化只保证在当前校准样本和模型族中找到合适值，不保证每组校准或测试域适用。若设置温度范围，还需要报告边界是否被选中；若校准集太小，最优可能极端。当前实验保留T为一作为候选，确保不因数值优化失败使校准NLL更差，但测试改善仍是实际观察而非选择条件。

<a id="uncertainty-1-detail-67"></a>

### 14.3 集合效率需要共同比较基准

可以比较平均长度、分位长度、空集合比例、全部类别比例和预设组长度。总体平均可能被大多数容易样本支配，尾部极宽对使用者仍很重要。不同错误率、不同条件保证或不同测试分布的集合不能直接按长度排名。先固定目标，再比较效率，才有明确含义。

当分布变化时，一个区间变短也可能只是覆盖掉了，集合变大又可能反映模型识别到真实困难。需要同时看覆盖与有用性，不能只追求宽或窄。训练更多复杂模型若没有改善这个共同可靠性目标，也不一定比简单基线更有价值。研究应保留原始单位，使区间大小能被实际任务理解。

<a id="uncertainty-1-detail-68"></a>

## 15. 常见误读的进一步反例

<a id="uncertainty-1-detail-69"></a>

### 15.1 分箱可以把相反误差抵消

设两组预测概率分别零点二和零点八，真实正类频率分别零点三和零点七，样本数量相等。若只用一个箱，平均预测和平均标签都是二分之一，分箱误差为零；分成两个箱，每箱都有零点一偏差。模型没有改变，指标却因分辨率变化而改变。这说明低ECE不能脱离分箱和样本量解释。

反过来，箱过细会使经验频率受噪声支配，有限样本绝对偏差通常有额外波动。可靠性图不是越多箱越真，应预先规定或报告敏感性，并关注真正使用的概率区间。不同论文ECE若箱定义不同，不能只比较小数直接排名。适当评分和独立决策评价提供互补证据。

<a id="uncertainty-1-detail-70"></a>

### 15.2 单标签集合不自动认证拒答风险

若系统只在保形集合恰好单标签时回答，回答错误必然意味着真实标签未被集合覆盖。因此在保形保证对应的联合随机分布下，错误且接受的概率不超过alpha。但接受条件错误率还要除以接受概率，至多得到alpha除以覆盖接受率的粗界，不是仍然不超过alpha。

而且标准保形概率对校准集随机性平均，这个粗界也不自动成为给定当前校准集后固定服务规则的高概率证书。要认证拒答后的错误风险，应直接定义接受事件与外层置信目标，第三章会处理。把预测集合包装成单标签拒答接口，不会凭外观自动获得另一种更强统计保证。

<a id="uncertainty-1-detail-71"></a>

### 15.3 均值估计很准仍需要宽预测区间

设真实结果为已知均值加独立标准高斯噪声，即使训练无限多、均值毫无估计误差，未来个体仍有单位尺度随机性。均值参数区间可极窄，预测区间不能在保持高覆盖同时任意缩为零。神经模型训练损失包含不可约噪声，区间宽也不一定意味着模型差。

如果另一个任务噪声更小，区间更短不能单独证明其算法更先进；如果同一任务增加合法信息解释部分噪声，则有可能真正缩短。评价应固定输入权限与生成机制，或者明确新增信息。数据质量、信息量和方法设计共同决定不确定性，不能把全部长度差都归因于模型名称。

<a id="uncertainty-1-detail-72"></a>

### 15.4 训练过拟合与校准泄漏是不同问题

一个复杂模型把训练残差压到零，并不必然破坏独立校准保形，新的校准残差仍可反映其泛化失败，代价可能是宽集合。相反，若模型记住的是同一校准标签，阈值会虚假变小，基础证明条件被破坏。过拟合影响效率，泄漏可能直接破坏保证，两者不应混称。

因此不应为了保形而禁止任何复杂训练，也不应因保形能容忍基础模型错误就允许任意数据复用。重点是分数生成与校准样本的关系。一个清楚的数据流图可以比一长串模型超参数更有效地说明方法是否合法，学习者应能追踪每个标签参与了哪一步选择。

<a id="uncertainty-1-detail-73"></a>

## 16. 实跑结果的具体解释

<a id="uncertainty-1-detail-74"></a>

### 16.1 分类概率改善而准确率不变

人工分类中温度约二点八六一，测试NLL从约零点六一一八降到零点四一八三，Brier约零点一三五二。由于正温度保留类别排序，top-1决策不变，改善来自概率尺度而非重新分类。生成器刻意用三倍logit制造过度自信，帮助机制解释，不代表真实网络总能被一个标量修复。

集合平均大小约一点二二六二，没有空集合，测试覆盖零点八九八四。它略低于名义九成，却与有限测试波动和校准条件波动相容，代码没有根据这个结果修改阈值。若把测试阈值调到经验九成再报告，就不再是同一冻结测试。保留真实数字比强制所有例子恰好达标更有教学价值。

<a id="uncertainty-1-detail-75"></a>

### 16.2 异方差中的真实取舍

固定宽度总体覆盖约零点九零九一，容易组约零点九八五三，困难组约零点一九七零，平均长度约零点四九九六。尺度法总体约零点九零六二，两组约零点九零七零和零点八九八一，平均长度约零点六三零八。后者明显改善困难组，但平均区间更长，不能只保留改善而隐去成本。

这个对比说明全局短区间有时靠牺牲少数难组实现。若目标仅是边缘九成，两种方法都可能合理；若用途要求组层面保护，应改变校准目标或分数与评价。尺度法此次组覆盖接近名义来自生成结构与估计效果，不是无条件每组有限样本保证。必须把实验观察和理论范围分别说清。

<a id="uncertainty-1-detail-76"></a>

### 16.3 校准条件波动的量化

均匀分数重复实验的平均条件覆盖约零点八九九五，低于零点八五的校准集比例约零点二零一一，Beta理论约零点一九八五。它不是一个罕见实现故障，而是标准边缘构造本来允许的校准波动。若产品需要一份上线固定规则的风险证书，需要专门更强构造和相应数据预算。

测试经验覆盖也有自己的波动。固定校准后的独立测试点可按相应伯努利覆盖指标评价，标准误与样本量相关；若测试点成组或相关，又需按实际独立单位处理。把大量同来源行当独立点，会夸大证据精度。统计说明应同时追踪校准和测试两层随机性。

<a id="uncertainty-1-detail-77"></a>

## 17. 可执行研究问题与交付边界

<a id="uncertainty-1-detail-78"></a>

### 17.1 比较分数而不偷用校准标签

可以在训练内部开发集比较绝对残差、尺度残差和分位区间分数，固定后各用独立校准，再在共同测试上比较覆盖与长度。也可以预先固定多个分数并分别报告，但若看校准结果选择最有利一个，必须考虑选择。最清楚方案是把模型分数选择与最终集合阈值计算分开。

研究时还可改变噪声比例和困难组权重，检验边缘覆盖如何分配遗漏。每次同时记录总体、组覆盖和长度，让结论可被反驳。不要只寻找一个平均更短配置，也不要把组定义不断细分直到得到想看的失败后再宣称预先保证。探索性分析可以有价值，只需如实标注。

<a id="uncertainty-1-detail-79"></a>

### 17.2 从概率到决策的下一步

概率校准、集合覆盖和拒答风险是相关但不同目标。一个温度可能改善NLL，却不改善错误排序；一个集合有边缘保证，却在接受子集风险很高；一个拒答规则可以认证低错误，却覆盖很少。完整系统应按用途同时报告必要指标，不强迫一个方法承担全部可靠性含义。

本章四段代码分别在独立Python进程实际执行，数据和模型均在内存，无外部下载或权重文件。正式资料保留推导、反例、代码和真实结果，不留生成脚本。继续后两章时，分布变化会挑战原交换条件，拒答则需要另立风险与置信目标；保持这条对象清楚的学习路线，才能让更进阶方法仍然可理解、可检验。

<a id="uncertainty-1-detail-80"></a>

### 17.3 Brier分解如何同时看校准与分辨力

令$m(p)=E[Y\mid p]$，先按预测概率条件分解，得到$E[(p-Y)^2]=E[(p-m(p))^2]+E[m(p)(1-m(p))]$。再用全方差公式，可写成总体标签方差加可靠性误差、减去分辨力项$\operatorname{Var}(m(p))$。因此校准误差小并不足够，模型能否把不同风险样本分开同样影响适当评分。

当模型完全校准，$m(p)=p$，可靠性项零，预测概率的合理分散可以提高分辨力。统一输出总体比例也校准，却没有这个收益。反过来，任意把概率变尖不保证变好，因为它可能增加可靠性误差。温度缩放调整的是这种权衡的一部分，而非直接制造新信息。这个分解把前面的反例与正式损失连接起来。

经验分箱版本只能近似这些条件期望，箱数和估计噪声仍有影响。不能把一个有限图上的柱高直接当作真实总体分解精确值。可以报告预设分箱下估计并与连续适当评分配合，保留样本量和独立评价。理论对象与可计算估计之间，也有需要认真说明的一层。

<a id="uncertainty-1-detail-81"></a>

### 17.4 排名覆盖不依赖方差存在

基础排名证明只需分数与数据的交换结构及相应可测定义，不需要残差正态，也不一定需要有限二阶矩。因此重尾结果下仍可能构造边缘覆盖集合，但平均区间长度、NLL或平方误差的期望可能不存在或估计很不稳定。不能从覆盖有效推导出所有评价指标都良好。

如果样本中出现极端大值，阈值可能很宽，正是数据对尾部不确定的反映。删除极端校准样本会改变分布，除非明确把目标限制到筛选后人群并重新分析。稳健训练可以改善基础预测，但最终集合仍要面对真实尾部。分布无关的优势与效率限制应同时呈现，而不是只强调不要求高斯这一句。

对于有单位的回归结果，宽度应按原始单位解释，必要时分组报告相对尺度。对分类集合，全部类别和空集合也应原样保留。保持输出含义具体，读者才能判断某个理论上有效的集合是否实际有用，或者是否需要更多信息、更多校准数据和不同可靠性目标。

<a id="uncertainty-1-detail-82"></a>

### 17.5 小样本容忍界的具体算例

若选校准最大分数作为阈值，连续分布下其总体覆盖小于零点九的概率为$0.9^n$，因为全部n个分数都落在总体前九成区域才发生。希望这个失败概率不超过零点零五，需要n至少二十九。此时边缘覆盖为二十九除以三十，明显高于九成，体现更强外层保证的保守代价。

十九条校准即使取最大分数，失败概率仍约零点一三五，达不到上述九成覆盖、九十五置信的要求。标准k十八又是另一较不保守边缘构造。几个规则都可合法，只是目标不同，不能挑最短阈值后同时宣称所有保证。写出这组简单幂次，比笼统说更多数据更可靠更能解释需要多少证据。

实际若分数有并列，最大阈值可能更保守，但不应利用某次并列现象省略理论条件。校准集越小，分位数可用层级越粗，结果就越需要保留无穷或大集合边界。学习者可以在不运行复杂模型的情况下先核对这些整数和概率，再决定实际应用需要何种目标与样本规模。

<a id="sec-8"></a>

最终应把保证写成完整句子，明确固定了训练过程、校准方法和分数，对哪种未来样本分布、哪一层随机性达到什么水平。不要只在结果表写九成可靠而省略这些对象。一个略长但准确的说明，能防止概率、覆盖、置信和拒答风险互相冒用；这也是后续研究分布变化和风险认证必须保留的基础。

只要每个阈值、样本角色和条件概率都可以独立复核，读者就能继续深入探索，同时清楚知道结论何时成立、何时需要新证据。
