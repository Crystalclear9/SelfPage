## 1. 覆盖、错误质量与条件风险

<a id="selective-detail-2"></a>

### 1.1 定义中不能省掉条件

固定预测器 $`f`$ 与分数 $`s`$，令 $`A_t(X)=\mathbf1\{s(X)\ge t\}`$ 表示接受。对零一错误 $`E=\mathbf1\{f(X)\ne Y\}`$，定义回答比例 $`C_t=P(A_t=1)`$、未归一化错误质量 $`N_t=E[A_tE]`$，以及选择性风险 $`R_t=\frac{N_t}{C_t}`$，最后一个定义要求 $`C_t>0`$。三个对象的分母不同，不能用同一个准确率名称替代。

在一千人中回答五百、答错五十，覆盖是二分之一，错误质量是百分之五，已回答错误率是百分之十。若拒绝所有人，错误质量为零，覆盖也为零，条件风险无定义。这不是证明系统已经完美可靠，而是系统没有产生可评价的自动回答。表格中应使用无定义标记，避免把缺少分母写成零错误率。

若错误代价有等级，错误指示可换成有界损失，但条件分母仍保留。若任务允许多个正确答案、工具执行结果或后续人工修改，需先规定怎样算错、在哪一时点评价。一个拒答流程可以改善自动回答风险而增加人工工作、延迟或遗漏，因此本章随后把这些成本与覆盖一并分析。

<a id="selective-detail-3"></a>

### 1.2 同一个覆盖词的不同含义

保形预测里的覆盖是预测集合包含真值的概率；选择性预测里的覆盖通常是回答比例。二者不是同一事件，尽管名称相近。若系统输出一个集合，再只在集合为单元素时回答，最终错误率是条件于这一筛选事件的新量，不能把原集合的边缘覆盖水平原样抄过来。

此外，训练覆盖或日志支持讨论输入动作是否被数据观察到，与回答比例也不同。跨章节阅读时应把概率事件完整写出，例如 $`P(Y\in\Gamma(X))`$、$`P(A=1)`$、$`P(E=1\mid A=1)`$。用符号区分不是形式主义，而是为了防止把保护一个事件的定理用于另一个事件。

<a id="selective-detail-4"></a>

### 1.3 风险覆盖曲线需要共同评价总体

对一系列阈值计算 $`(C_t,R_t)`$，得到风险覆盖曲线。它依赖基础预测器、分数、数据总体和阈值处理并列规则。比较两条曲线时，应该使用同一评价分布和损失，并说明工作点怎样确定。某模型在极低覆盖处风险很小，不意味着在相同回答量下仍有优势，更不意味着全部服务成本更低。

有限数据的曲线是估计，尤其低覆盖端分母很小，波动可能很大。把所有阈值扫描后最低的经验风险当作真实工作点，会叠加选择偏差。展示探索性曲线可以帮助诊断，但交付固定风险承诺需要独立认证或适合整个选择过程的同时结论。曲线画得平滑，也不能替代这种证据。

## 2. 自信排序什么时候有用

<a id="selective-detail-6"></a>

### 2.1 提高阈值不一定降低风险

构造一百个等概率对象，最高分二十个错十个，其余八十个全部正确。全部回答的风险是百分之十，只回答最高分二十个时风险为百分之五十。覆盖随阈值提高而下降，风险却上升。这完全符合条件概率定义，没有任何定理要求任意模型分数都能正确排序错误。

常见最大 softmax、logit 间隔、集成方差或证据完整性都可以作为候选分数，但名称不赋予保证。高分错误可能集中在稀有来源、伪相关或分布外输入中。研究分数需要独立检验排序和条件频率，不能因为它在训练时与准确率相关，就直接视为真实正确概率。

<a id="selective-detail-7"></a>

### 2.2 真条件风险给出理想排序

对固定预测器，令 $`r(x)=P(E=1\mid X=x)`$。在回答比例固定为 $`c`$ 的问题中，最小化 $`E[A(X)r(X)]`$，最优规则接受最小 $`r(x)`$ 的对象，在边界必要时随机化。交换论证很直接：若接受一个高风险点而拒绝同质量的低风险点，交换这两部分可保持覆盖并降低错误质量，因此原规则不可能最优。

这个论证假定能够知道真实条件风险、总体与可行规则类允许这样的交换。有限样本的估计分数并不自动恢复该排序，特征受限或群体容量约束也会改变可行集合。理论最优是理解目标的参照，不是对现成概率输出的无条件背书。离散总体若某风险层有正质量，精确达到给定覆盖通常需在该层随机接受。

<a id="selective-detail-8"></a>

### 2.3 精确校准能推出什么

如果分数 $`S`$ 满足精确的置信度校准 $`P(f(X)=Y\mid S)=S`$，且接受只由条件 $`S\ge t`$ 决定，那么 $`R_t=E[1-S\mid S\ge t]\le1-t`$。这是一个合法的总体结论，不能笼统说任何校准都与拒答风险无关。更强的 top-label 校准还条件于预测类别，能通过塔式法则推出这里所需的置信度校准；若只在某个预测类别内接受，需相应的类别内条件。但分箱 ECE 很小、某一类别分量校准或一个有限可靠性图，不等于已经建立上述严格条件。

若再按群体或另一个变量筛选，原来的分数条件校准通常不够，因为 $`E[E\mid S,G]`$ 可以随群体变化。精确总体校准也不保护任意分布变化。应该区分：若真知道相应条件概率，可直接推条件风险；实际只有有限校准证据时，需要量化误差或另做风险认证。这让理论和可执行方法之间的差距清楚可见。

## 3. 从代价到规则的推导

<a id="selective-detail-10"></a>

### 3.1 固定拒答代价下的逐点最优

设回答错误代价为 $`c_e>0`$，正确代价零，拒答固定代价为 $`c_r\ge0`$。给定输入，回答期望代价为 $`c_e r(x)`$，拒答为 $`c_r`$，因此当 $`r(x)\le\frac{c_r}{c_e}`$ 时回答更合算，边界按固定规则处理。若用真实正确概率 $`q=1-r`$，接受条件就是 $`q\ge1-\frac{c_r}{c_e}`$。

当拒答代价大于错误代价时，完全拒答通常没有成本优势；当拒答几乎免费时，规则会更保守。成本与单位应来自任务，不能为了得到漂亮覆盖任意调节后仍称原问题最优。若人工审核并非总正确，拒答分支应包含审核错误、等待和资源代价，而不是假定拒答后所有损失消失。

<a id="selective-detail-11"></a>

### 3.2 固定风险目标是一个比值约束

另一目标是在 $`R(A)\le\varepsilon`$ 下尽量增大 $`C(A)`$。对正覆盖规则，它等价于 $`E[A(r-\varepsilon)]\le0`$。这一形式将比值约束转成未归一化总体约束，但不能在零覆盖时忘记条件风险无定义。优化可允许全拒作为可行后备动作，同时明确它没有非空回答集的风险证书。

引入乘子 $`\lambda\ge0`$，可考虑最大化 $`E[A]-\lambda E[A(r-\varepsilon)]`$。逐点上接受正系数区域，形成真实风险阈值；最优乘子取决于总体风险分布。这并不意味着风险目标的数值阈值一定等于 $`\varepsilon`$：允许较高风险对象与较低风险对象混合后平均仍达标，因此最优接受边界可能高于目标平均。

<a id="selective-detail-12"></a>

### 3.3 容量和群体约束改变选择

若每天最多审核一定人数，拒答率不能任意提高；若要求各群体最低回答比例，还需对不同群体加入约束。这些条件可能与极低总体风险冲突，数据或模型能力不足时应报告不可行，而不是把某群体几乎全部排除后只展示总体准确率。优化对象应包含谁没有获得服务。

成本最优、固定覆盖最优和固定风险下最大覆盖，是相关但不同的问题。比较系统时必须选定同一个目标。某方法更会拒绝困难对象，可以降低已回答风险，却不一定改善带审核成本的总目标；另一个覆盖更高的方案，也可能违反规定的风险上限。不存在用一个裸准确率概括所有取舍的通用排序。

## 4. 冻结规则后才能认证什么

<a id="selective-detail-14"></a>

### 4.1 数据权限是证明的一部分

把训练数据用于学习预测器和分数，开发数据用于选择分数形式、候选阈值网格和风险目标，认证数据用于计算固定候选的证书，最终测试用于独立描述交付行为。并非所有任务都要机械分四份，但任何数据复用都需要与其选择过程相匹配的论证。本章采用分离角色，便于读者逐步重建证明。

认证标签看见之前，冻结 $`M`$ 个候选规则 $`A_1,\ldots,A_M`$ 及预测器。候选可以是不同阈值，也可以是不同分数与模型组合；总数要覆盖实际参与选择的全部候选。不能只报告最后留下的五个阈值，却把此前搜索的一百个模型和新分数当作从未发生。

<a id="selective-detail-15"></a>

### 4.2 接受数量是随机的

对 $`n`$ 个独立同分布认证样本，令 $`N_j=\sum_iA_j(X_i)`$，$`K_j=\sum_iA_j(X_i)E_i`$。对固定规则且总体覆盖正，条件于 $`N_j=m`$ 时，接受对象来自相应条件总体，二元错误数服从 $`\operatorname{Binomial}(m,R_j)`$。可以先条件于具体接受索引集合说明各对象独立，再利用对称性对索引混合，因此不需要接受数事先固定。

这个性质要求规则没有根据这些认证标签自适应改变。若先看某些对象错了，再改分数把它们排除，条件样本就不再对应一个事先固定接受集合。若数据有时间依赖、同用户多次观测或选择性缺标签，也不能未经证明直接视作独立二项样本。样本单位和获得标签机制都必须说明。

<a id="selective-detail-16"></a>

### 4.3 Hoeffding同时上界的完整步骤

设失败预算 $`\delta\in(0,1)`$。当 $`N_j>0`$，定义

$$
U_j^H=\min\left\{1,\frac{K_j}{N_j}+\sqrt{\frac{\log(\frac{M}{\delta})}{2N_j}}\right\}.
$$

当 $`N_j=0`$，令上界为一，不提供低风险证书。固定 $`m>0`$ 时，一侧 Hoeffding 给 $`P(R_j>U_j^H\mid N_j=m)\le\frac{\delta}{M}`$。对所有 $`m`$ 按其概率求和仍不超过该值；再对 $`M`$ 个候选取联合界，得到以至少 $`1-\delta`$ 的认证抽样概率，所有正覆盖候选同时满足 $`R_j\le U_j^H`$。

零样本边界没有造成额外失败，因为 $`R_j\le1`$ 本来恒成立；但它也没有提供有用认证。在总体覆盖本来为零的候选上，条件风险不存在，应该单独记作空规则。联合事件不要求候选错误数互相独立，阈值共享同一批样本完全可以，只需逐候选边界合法。

## 5. 精确二项上界与样本需求

<a id="selective-detail-18"></a>

### 5.1 反演一侧二项检验

对于固定接受数 $`m>0`$、错误数 $`k<m`$，令上界 $`U`$ 解 $`P_{\operatorname{Bin}(m,U)}(K\le k)=\alpha`$。随着假设错误率增加，观察到不超过 $`k`$ 个错误更罕见，因此这个方程给出一侧保守置信上界。可用 $`\operatorname{Beta}^{-1}(1-\alpha;k+1,m-k)`$ 计算；若 $`k=m`$ 或 $`m=0`$，取一。

这里 $`\alpha=\frac{\delta}{M}`$ 时可以与前面相同的条件化和联合界结合。置信水平是重复抽样程序的覆盖性质，不是给定数据后真风险随机落在区间的贝叶斯概率。它也不承诺恰好失败百分之五；二项离散性常使实际覆盖更保守。后面代码调用 SciPy 分位数，只用于这个明确定义的二项反演。

<a id="selective-detail-19"></a>

### 5.2 零错误的精确上界

当 $`k=0`$，方程变成 $`(1-U)^m=\alpha`$，于是 $`U=1-\alpha^{\frac{1}{m}}`$。观察零错误仍需足够 $`m`$ 才能给小上界。希望 $`U\le\varepsilon`$，需要 $`m\ge\frac{\log\alpha}{\log(1-\varepsilon)}`$，向上取整。两个对数都为负，除法方向应仔细核对。

如果只认证一个规则、失败预算百分之五、目标错误率百分之一，零错误仍需至少二百九十九个接受样本。若同时认证一百个候选，单候选预算更小，所需数量增加。样本数是接受后的数量，不是认证集总量；覆盖很低时，采集总量还要相应增大。不能拿五千认证对象中仅五个回答全对，宣称已经有五千个低风险证据。

<a id="selective-detail-20"></a>

### 5.3 不同上界不是任意挑最小

可以在开发阶段预先指定使用 Hoeffding 或二项反演；也可将不同统计方法纳入统一多重控制。看见认证结果后挑最小上界，若每个只按同一失败预算单独有效，组合后不自动保持原预算。不同合法证书之间选择仍是一个选择问题，不能因为它们都叫置信上界就忽略额外搜索。

本章完整训练实验事先使用二项同时上界，三候选手算采用 Hoeffding，分别标明。二者输出不同不矛盾，一个可能更保守；比较效率时应以共同风险目标、失败概率和候选范围为基准，而不是把宽窄不同的证书当作相同保证下的算法性能。

<a id="selective-detail-21"></a>

## 6. 从同时证书选择一个工作点

<a id="selective-detail-22"></a>

### 6.1 风险可选择，覆盖仍有估计误差

在联合事件上，任何通过 $`U_j\le\varepsilon`$ 的候选都安全，因此可以根据认证数据选择接受数最大的一个。选择依赖这些数据并不破坏风险结论，因为证明已经同时保护所有候选。不过它不保证选到了真实覆盖最大的安全候选；证书可能保守，经验覆盖也有噪声，实际最优规则还可能在候选网格外。

可以将联合承诺写成一个完整程序。事先把总失败预算分成 $`\delta_R+\delta_C=\delta`$，对 $`M`$ 个冻结候选，用前文方法在预算 $`\delta_R`$ 下同时构造风险上界 $`U_j`$。另令总认证样本量为固定的 $`n`$，$`\widehat C_j=\frac{N_j}{n}`$ 为候选的经验覆盖。一侧 Hoeffding 与联合界给出

$$
\begin{aligned}
L_j &=\max\left\{0,\widehat C_j-
\sqrt{\frac{\log(\frac{M}{\delta_C})}{2n}}\right\},\\[6pt]
\Pr(\exists j:C_j<L_j) &\le\delta_C.
\end{aligned}
$$

这次分母是认证对象总数 $`n`$，因为每个对象都贡献一个回答指示；风险证书的有效数量则是接受后的 $`N_j`$。两个证书即使由同一认证集计算，也不需要相互独立：直接对其失败事件取联合界，就以至少 $`1-\delta`$ 的概率，对所有候选同时有 $`R_j\le U_j`$、$`C_j\ge L_j`$。因而事后可从 $`U_j\le\varepsilon`$ 的候选中选择 $`L_j`$ 最大者；若没有候选通过，按预定失败流程处理。

**复算一个联合工作点。** 取 $`M=10,n=1000,\delta_R=0.04,\delta_C=0.01`$。某候选接受 $`800`$ 个对象且零错误，以 $`\frac{\delta_R}{M}=0.004`$ 作二项反演，风险上界为 $`1-0.004^{\frac{1}{800}}\approx0.006878`$。覆盖半径为 $`\sqrt{\frac{\log1000}{2000}}\approx0.058770`$，故其覆盖下界为 $`0.741230`$。若目标风险为百分之一，该候选通过；在全体候选的联合事件上，选择它后可同时声称风险至多百分之一、覆盖至少约百分之七十四点一二。证书只给出保证，不说明它就是总体覆盖最大的可行规则。

若只想描述最后规则的覆盖，也可以在独立测试集上估计；此时应说明描述性估计与正式认证的区别。不能风险已花完总预算，再无代价追加另一项同置信水平的承诺。最终保留接受数、错误数、风险上界和覆盖估计，并明确各数使用的数据角色与概率层次。

<a id="selective-detail-23"></a>

### 6.2 没有候选通过的正确动作

若所有候选都没有通过，应输出未获得目标风险认证，可以采用全拒后备，但不得把它称为正覆盖低风险规则。也可收集更多独立认证数据、改进分数并重新冻结，或在明确的新问题中修改目标。不能在原数据上不断添加阈值直到某个通过，再沿用最初的候选数。

全部拒答时服务仍需要后续处理。若人工容量不足，这个后备可能在业务上不可行，却仍是统计证据不足的真实反映。学习者应区分算法是否能返回一个结果与任务是否有可接受的可行解；在证据不足时返回无证书，比把经验零错误包装成严格保证更准确。

<a id="selective-detail-24"></a>

### 6.3 重复看数据和重复认证

若每增加一批认证数据就重新检验，固定样本界不自动同时覆盖所有查看时刻。可以预先给各次查看分配失败预算，使总和不超过 $`\delta`$；或者采用适当的置信序列和随时有效检验。需要控制的是整个实际停止策略，而不是只把最后一次样本量代入固定样本公式。

同理，重新训练模型后旧证书通常不能直接继承，因为错误指示和接受集合已改变。即使模型版本的平均准确率相近，也不说明每个接受子群相同。为便于复核，还应记录模型与数据版本、候选列表、边界并列处理、认证计数、未舍入上界及实际选择结果。

随机化接受时保留生成机制，独立测试不再更新候选。这样另一个读者可以从计数重建结论，也能判断后来部署的是否仍是同一条规则。证书应绑定预测器、分数、阈值、数据总体、损失定义和统计方法；任何决定这些对象的实质变更都需要重新分析。

## 7. 实验一：手算认证与高分错误反例

```python
import numpy as np
from scipy.stats import beta
accepted=np.array([900,400,40]);errors=np.array([90,12,0])
M,delta,target=3,.05,.12
upper=np.minimum(1.,errors/accepted+np.sqrt(np.log(M/delta)/(2*accepted)))
assert np.array_equal(upper<=target,[False,True,False])
zero=1-(delta/M)**(1/40)
assert np.isclose(zero,beta.ppf(1-delta/M,1,40))
score=np.r_[np.full(80,.7),np.full(20,.99)]
error=np.r_[np.zeros(80),np.ones(10),np.zeros(10)]
assert np.mean(error)==.1 and np.mean(error[score>.9])==.5
q=np.array([.99,.85,.55]);mass=np.array([.3,.4,.3])
ce,cr=1.,.2
answer=(1-q)*ce<=cr
cost=np.sum(mass*np.where(answer,(1-q)*ce,cr))
all_answer=np.sum(mass*(1-q)*ce)
assert np.array_equal(answer,[True,True,False]) and cost<all_answer
print('Hoeffding simultaneous bounds',upper)
print('zero error exact upper at accepted 40',zero)
print('risk all/high score',error.mean(),error[score>.9].mean())
print('cost chosen/all answer',cost,all_answer)
```

手算中四十个零错误给 Hoeffding 上界约百分之二十二点六，精确二项上界则约百分之九点七。它们分别是预先定义方法的输出，不应先观察结果再无代价挑更有利的一个。高分子群反例则完全是确定枚举，说明分数排序失败与认证样本不足是不同问题。

## 8. 实验二：完整训练、冻结候选、认证与独立测试

人工数据的标签由两个输入决定的逻辑概率生成，因此存在不可消除随机错误。训练逻辑回归后，以预测正确概率候选值作为分数，但不假定它已经精确校准。阈值网格在认证之前固定，对所有候选使用同一个二项联合预算，选经验覆盖最高的通过者，再只在独立测试上评价冻结规则。

```python
import numpy as np
from scipy.special import expit
from scipy.stats import beta

def data(n,seed):
    rng=np.random.default_rng(seed)
    x=rng.normal(size=(n,3))
    p=expit(2*x[:,0]-.8*x[:,1])
    y=(rng.random(n)<p).astype(int)
    return np.c_[x,np.ones(n)],y
x,y=data(1800,711)
w=np.zeros(x.shape[1]);ridge=.001
for _ in range(30):
    p=expit(x@w)
    gradient=x.T@(p-y)/len(y)+ridge*w
    hessian=x.T@((p*(1-p))[:,None]*x)/len(y)+ridge*np.eye(len(w))
    w-=np.linalg.solve(hessian,gradient)
assert np.linalg.norm(gradient)<1e-8
cal,yc=data(6000,712);test,yt=data(30000,713)
grid=np.linspace(.5,.98,25)
M,delta,target=len(grid),.05,.10
pc=expit(cal@w);sc=np.maximum(pc,1-pc);ec=(pc>=.5)!=yc
counts=[];errors=[];upper=[]
for threshold in grid:
    selected=sc>=threshold;m=int(selected.sum());k=int(ec[selected].sum())
    u=1. if m==0 or k==m else float(beta.ppf(1-delta/M,k+1,m-k))
    counts.append(m);errors.append(k);upper.append(u)
counts=np.array(counts);upper=np.array(upper)
qualified=np.flatnonzero(upper<=target)
if len(qualified):
    j=int(qualified[np.argmax(counts[qualified])]);threshold=float(grid[j])
    pt=expit(test@w);at=np.maximum(pt,1-pt)>=threshold;et=(pt>=.5)!=yt
    result={'threshold':threshold,'cal_accepted':int(counts[j]),'cal_errors':errors[j],
            'simultaneous_upper':float(upper[j]),'test_accepted':int(at.sum()),
            'test_coverage':float(at.mean()),'test_selective_risk':float(et[at].mean()) if at.any() else None,
            'test_all_answer_risk':float(et.mean())}
    assert upper[j]<=target and np.isfinite(w).all()
else:
    result={'status':'no certified nonempty candidate; abstain fallback','test_coverage':0.,'test_selective_risk':None}
print('fixed grid size',M,'fixed risk/total failure',target,delta)
print('fixed 30 Newton steps; test unused for training or threshold selection')
print(result)
```

如果某次独立测试经验风险略高于目标，不应直接判定认证定理失效：测试有抽样波动，证书本身也允许规定失败概率。反之，一次测试低于目标不能证明方法在所有校准集上都正确。应首先检查真实风险与经验值、外层置信与未来错误频率的不同层次，再讨论结果。

## 9. 实验三：多重搜索能把偶然低错误变成假象

构造一百个事先冻结的候选预测器，每个真实错误率都为百分之十一，均高于百分之十目标。每个预测器在二百条独立对象上观察错误；本实验令不同预测器的错误独立，便于精确计算“至少一个看似好”的概率。这种联合世界可以具体实现为一百维输入，各坐标独立为均值零点一一的 Bernoulli，标签恒零，第 j 个固定分类器读取第 j 个坐标且全部回答。真实候选通常相关，但联合上界无需这个独立条件，实验只用它来获得闭式参照。

```python
import numpy as np
from scipy.stats import beta,binom
n,M,true_r,target,delta=200,100,.11,.10,.05
k=np.arange(n+1)
upper=np.ones(n+1)
upper[:-1]=beta.ppf(1-delta/M,k[:-1]+1,n-k[:-1])
naive=k/n<=target
certified=upper<=target
single_naive=float(binom.pmf(k[naive],n,true_r).sum())
single_safe=float(binom.pmf(k[certified],n,true_r).sum())
any_naive=-np.expm1(M*np.log1p(-single_naive))
any_safe=-np.expm1(M*np.log1p(-single_safe))
assert any_safe<=delta and any_naive>.9
rng=np.random.default_rng(721)
observed=rng.binomial(n,true_r,size=(5000,M))
naive_rate=np.mean(naive[observed].any(1))
safe_rate=np.mean(certified[observed].any(1))
print('largest passing error count naive/simultaneous',int(k[naive].max()),int(k[certified].max()))
print('exact false-certification probability naive/simultaneous',any_naive,any_safe)
print('5000-trial observed probability',naive_rate,safe_rate)
# 零错误样本需求，单规则与一百候选。
for candidates in [1,100]:
    alpha=delta/candidates
    need=int(np.ceil(np.log(alpha)/np.log(1-.01)))
    assert 1-alpha**(1/need)<=.01+1e-14
    print('zero errors for one-percent risk; candidates/accepted needed',candidates,need)
```

这里没有任何候选真实达标，所有通过都属于错误认证。直接看经验错误率几乎必然找到看似好者；同时二项上界的精确错误认证概率保持在总预算内。蒙特卡洛频率只是对闭式概率的另一次有限抽样观察，不是用五千次实验代替证明。把真实风险设在目标附近，是刻意检验选择偏差而非真实业务性能。

## 10. 与保形、校准和分布外检测的边界

<a id="selective-detail-29"></a>

### 10.1 单元素集合的条件错误

若一个预测集合满足边缘遗漏概率不超过 $`\alpha`$，只在集合为单元素时回答，则“回答且错误”一定蕴含“真值未被集合包含”。因此在同一联合概率空间下 $`P(E\cap A)\le\alpha`$，进而 $`P(E\mid A)\le\frac{\alpha}{P(A)}`$，前提回答概率正。这通常比 $`\alpha`$ 大，覆盖很小时界甚至没有实用信息。

这里的概率还包括原保形保证所涉及的校准随机性；不能未经进一步论证就改成每一份固定校准集的条件风险证书。若集合有多个标签却再选一个回答，错误事件甚至不一定蕴含遗漏，因为真值可能本来在集合内。后处理改变输出定义，需要重新建立事件包含，而不是凭名称继承保证。

<a id="selective-detail-30"></a>

### 10.2 检测新分布与拒绝困难对象

选择性预测可以在原分布上拒绝高风险对象；分布外检测研究某种新分布输入能否被区分。二者可能共享分数，却不是同一任务。一个模型对原分布困难样本很保守，仍可能对某种新来源自信犯错；检测器能发现来源变化，也不表示它知道每个输入的预测错误概率。

任何可靠性线索都需与损失定义连接。检索证据齐全、工具返回成功或多个模型意见一致，可能提高分数排序，但不直接证明答案正确。若将这些线索作为接受规则的一部分，先冻结规则再独立认证其实际错误。任务变成开放世界事实核验时，标签获取与可测量性又是额外难题，不能由本章二元模拟替代。

<a id="selective-detail-31"></a>

### 10.3 分布迁移对条件比值的放大

设输入与标签联合认证分布为 $`P`$、未来联合分布为 $`Q`$，二者在 $`(X,Y)`$ 上的总变差距离不超过 $`\eta`$，采用固定规则和零一错误。按总变差定义，错误质量与覆盖各自变化至多 $`\eta`$。若 $`C_P>\eta`$ 且 $`R_P\le r`$，可得

$$
R_Q\le\min\left\{1,\frac{rC_P+\eta}{C_P-\eta}\right\}.
$$

当回答比例很低，分母让变化更敏感。源覆盖十分之一、风险十分之一、总变差百分之一时，这个上界约为九分之二，明显高于原风险。它是最坏情况界，不断言每种变化都如此糟，却说明低覆盖证书不能无条件迁移。未知变化大小时不能直接使用这个数字界。

## 11. 群体、审核与服务总目标

<a id="selective-detail-33"></a>

### 11.1 总体风险是接受组成的加权平均

按预先定义的群体 $`G`$ 分解，$`R=\sum_gP(G=g\mid A=1)R_g`$。权重是接受后组成，而非原总体比例。如果系统几乎不回答某个高风险群体，总体风险可能很好，但该群体获得自动服务的机会很少。报告每组覆盖、接受数和风险，有助于看清这种取舍。

若要同时认证 $`G_0`$ 个群体与 $`M`$ 个候选，可把失败预算分到这些群体候选对，条件于每组接受数建立边界。样本少的组可能无法认证，不能将其从表格中删去。群体若由认证错误临时挖掘出来，简单固定组联合界不覆盖整个搜索；需要独立发现数据或合适的复杂度控制。

<a id="selective-detail-34"></a>

### 11.2 审核不完美时的总损失

设自动接受错误损失为 $`c_e`$，拒答后审核有成本 $`c_h`$、错误概率 $`r_h(x)`$ 和额外错误损失 $`c_h^e`$。拒答分支的条件期望应为 $`c_h+c_h^e r_h(x)`$，还可加等待代价。最佳规则比较的是两个分支的真实条件期望，而不是一边用错误风险、一边把人工分支当免费全对。

人工容量限制还会引入排队，审核错误率也可能随负载变化。若一个方案把大量困难对象转给审核端，总体任务失败可能没有减少。拒答研究至少要报告自动与人工两部分对象流向，若没有测人工流程，就明确只证明自动回答部分的风险和覆盖，不扩展到完整服务可靠性。

<a id="selective-detail-35"></a>

### 11.3 拒答标签的可得性

如果系统只给已回答对象收集标签，就无法直接估计被拒者的错误与整体成本。新的训练又可能只看到已接受区域，形成反馈选择。应预先设计随机审核或其他合法抽样来覆盖被拒群体；已知抽样概率时可研究重加权，但支持缺失仍不能靠公式补出。

这与前两章的分布加权和因果选择问题相连。筛选改变了可见数据分布，平均数的解释要跟着改变。评价协议既要说明模型怎么输出，也要说明真实结果怎样被观察到，否则即使统计公式写得正确，输入它的错误标签计数也可能来自偏置样本。

<a id="selective-detail-36"></a>

## 12. 二十道进阶练习与详细解答

<a id="selective-detail-37"></a>

### 12.1 题一：两个分母

题目：一千条请求回答二百，错十条，给出三个指标。解析：覆盖为零点二，错误质量为零点零一，选择性风险为零点零五。若只报百分之一错误，会把所有请求当分母，不能据此说已回答错误率百分之一。把三个分母显式写出即可避免混淆。

<a id="selective-detail-38"></a>

### 12.2 题二：全拒答为何不是零风险

题目：所有对象均拒答，选择性风险多少？解析：条件事件概率零，定义无效。可把总体自动错误质量记零，但条件风险必须留无定义。服务是否可接受还要看拒答成本、人工容量和覆盖要求，不能由缺少错误事件推断解决了任务。

<a id="selective-detail-39"></a>

### 12.3 题三：理想成本阈值

题目：错误代价五，拒答代价一，真实正确概率多少以上应回答？解析：回答成本五乘一减 q，不超过一要求 q 至少零点八。边界两动作成本相同，可预先约定。若 q 只是未校准分数，算式仍说明理想规则，却不证明该分数决策已经成本最优。

<a id="selective-detail-40"></a>

### 12.4 题四：风险目标为何不是逐点上限

题目：接受对象一半风险零、一半风险零点二，是否违反零点一平均目标？解析：恰好不违反，条件平均为零点一。平均风险控制不禁止某些输入更危险，也不等于所有个体都有相同保护。若要求每个群体或每个输入达标，需要另加条件，代价通常更高。

<a id="selective-detail-41"></a>

### 12.5 题五：置信度与top-label校准的合法推论

题目：若严格有 $`P(f(X)=Y\mid S)=S`$，只按 $`S\ge0.9`$ 回答，能推出什么？这是否已经是 top-label 校准？解析：同总体中接受后错误率为 $`E[1-S\mid S\ge0.9]`$，不超过零点一。题设是置信度校准；top-label 校准还要求给定预测类别 $`H=f(X)`$ 后同样成立，因此比题设更强，并可通过塔式法则推出题设。这个推论不要求那一额外强条件，但也不自动延伸到按类别或群体进一步筛选、或者新分布。有限分箱误差小不能代替严格的总体条件，既不能夸大校准，也不能否认明确条件下的推论。

<a id="selective-detail-42"></a>

### 12.6 题六：随机接受数如何处理

题目：阈值固定但接受数事先未知，二项边界为何仍可用？解析：先条件于接受数和索引，已接受独立对象来自固定条件总体；对索引与计数混合，单候选失败概率仍受原预算控制。若阈值由这些错误标签临时改变，这个固定规则论证失去前提。

<a id="selective-detail-43"></a>

### 12.7 题七：零错误样本需求

题目：单候选、失败概率零点零五，欲认证风险不超过百分之一，零错误至少多少接受对象？解析：解一减零点零五的 m 分之一次方不超过零点零一，得 m 至少二百九十九。这里不是总请求数。若覆盖只有百分之一，收集这么多接受对象通常需要远多于二百九十九请求。

<a id="selective-detail-44"></a>

### 12.8 题八：为什么联合界允许共享样本

题目：相邻阈值接受集高度重合，会使 Bonferroni 联合界失效吗？解析：不会，联合界只用每个失败事件概率上界，不要求事件独立。相关性可能使界保守，但不取消有效性。反过来，利用独立公式计算至少一次失败概率时才需要相应独立条件，不能混用。

<a id="selective-detail-45"></a>

### 12.9 题九：看结果后发明阈值

题目：先试二十个阈值，再围绕最好者加一百个，只按二十修正可否？解析：不够，最终选择范围包含新增规则，且规则可能依据认证标签生成。可预先冻结全部有限网格并统一控制，或用独立数据作最终认证；不能只计报告中的候选而忽略实际搜索。

<a id="selective-detail-46"></a>

### 12.10 题十：风险认证是否选到了最佳覆盖

题目：在通过者中取接受数最多的规则，是否得到所有安全规则中真实覆盖最大者？解析：未必。经验覆盖有误差，证书保守，还只搜索有限候选。联合事件保障的是所选通过者风险不超目标，不是覆盖最优。独立评价与网格设计分别处理这两种局限。

<a id="selective-detail-47"></a>

### 12.11 题十一：零接受如何编码

题目：认证接受数零时，为何上界设一而非零？解析：没有来自该条件总体的错误观察，不能给非平凡低风险证据。设一使固定置信程序保守，并阻止空样本虚假通过低风险目标。若规则总体覆盖也零，条件风险本来无定义，应另标空规则，而不是解释为上界证明风险恰好一。

<a id="selective-detail-48"></a>

### 12.12 题十二：测试超过目标是否直接推翻定理

题目：证书上界零点一，测试经验错误零点一零二，是否矛盾？解析：不必，测试率是有限样本估计，真风险也允许认证程序少量失败。应报告测试接受数、区间和认证方法，若多次系统偏差再检查假设与实现。不能把任一单点偏差当作严格反证，也不能用允许失败掩盖持续错误。

<a id="selective-detail-49"></a>

### 12.13 题十三：单元素保形集合

题目：集合边缘遗漏至多零点一，回答比例零点二，仅凭事件包含能给条件错误什么界？解析：同一联合概率空间中至多零点一除零点二等于零点五，而非零点一。若想更低需要额外信息或直接认证选择性风险。原保证还包括校准随机性时，不能直接换成每份固定校准集结论。

<a id="selective-detail-50"></a>

### 12.14 题十四：每组都需要自己的证据

题目：总体接受一万条错一百，但某小组只接受五条，能否认证该组风险低于百分之一？解析：总体计数不替代组内样本。小组五条即使全对，上界仍很宽。要说明该组覆盖和样本不足，若要求所有组同时达标，需联合控制与足够各组数据。

<a id="selective-detail-51"></a>

### 12.15 题十五：置信和风险不是一个百分比

题目：九十五置信控制百分之十风险，是否表示每次回答有百分之九十五正确？解析：不是。九十五对应认证抽样中证书事件概率，百分之十对应固定接受规则在未来总体的错误频率，两者随机对象不同。正确描述应保留外层认证概率和内层选择性风险。

<a id="selective-detail-52"></a>

### 12.16 题十六：重复查看何时不合法

题目：每观察十个新标签就用同一个百分之五固定样本界，直到通过，有何问题？解析：总停止过程包含多次失败机会，单时刻保证不自动覆盖全部。可预设查看时刻并分配可求和预算，或使用随时有效工具。只在最后填入样本数没有控制数据依赖的停止。

<a id="selective-detail-53"></a>

### 12.17 题十七：总变差为什么会放大

题目：源覆盖零点一、源风险零点一，总变差界零点零一，求比值上界。解析：源错误质量零点零一，目标最多零点零二，目标覆盖至少零点零九，所以风险最多二除九，再与一取小。变化很小仍可能明显影响低覆盖子集，因为条件化放大了分布差异。

<a id="selective-detail-54"></a>

### 12.18 题十八：模型更新为何需重新认证

题目：新模型总体准确率相同，旧阈值证书能否保留？解析：不能仅凭平均数推断，接受集合与错误位置可能全部变化。证书绑定固定预测器与分数。若有另外的稳定性或分布差异定理可以研究迁移，否则应冻结新版本重新认证。

<a id="selective-detail-55"></a>

### 12.19 题十九：人工复核是否免费正确

题目：拒答一半后自动风险下降，怎样比较完整服务？解析：加上人工数量、审核错误、等待和成本，再计算总任务损失。若只观测自动部分，就只能给自动回答的风险结论。把未回答者从分母删除并假设他们都解决，不是完整评价。

<a id="selective-detail-56"></a>

### 12.20 题二十：新分数研究怎样验收

题目：设计一个新可靠性分数，怎样避免只挑偶然好工作点？解析：先用训练和开发确定分数及候选网格，固定风险与失败预算；用独立认证求同时上界并选择，再在独立测试报告覆盖、条件风险和群体组成。记录所有候选、失败与无证书结果，分开比较排序质量、认证效率和分布变化后的行为。

<a id="selective-detail-57"></a>

## 13. 研究设计与证据范围

<a id="selective-detail-58"></a>

### 13.1 分数质量与认证效率分开比较

两个分数可能有类似总体排序，却因阈值网格和接受数不同产生不同证书。应先在开发数据研究风险覆盖曲线，再固定共同风险目标与候选预算，比较获得认证后的独立覆盖。若一种方法使用更多标签、更多候选或额外模型，也把这些资源计入，而不是把全部收益归于分数公式。

认证只控制给定规则族中的错误选择，不修复分数本身。差分数可能只能在极低覆盖处通过，也可能没有规则通过；好分数在小样本下仍可能因为证据不足而失败。研究应该解释是排序能力有限、样本量不足还是选择预算过大，而不把所有失败都称作校准问题。

<a id="selective-detail-59"></a>

### 13.2 保留拒答后的对象与结果

记录被接受与被拒绝对象的来源、长度、难度、群体和后续处理，才能判断系统把什么风险移到哪里。若目标是节省人工，应报告真正减少的人工工作和新增自动错误；若目标是限制高代价错误，应使用对应损失，而非普通准确率。工作点必须对应事先提出的任务目标。

本章人工数据只验证统计机制和完整数值流程，不包含开放世界语言模型、真实审核人员或在线服务。代码没有调用外部 API，也没有输出实际应用可靠性承诺。扩展到具体场景时，首先重新定义错误标签与抽样单位，再检查证明前提，而不是直接复用某个阈值数字。


<a id="selective-detail-60"></a>

## 14. 进一步重建统计证明

<a id="selective-detail-61"></a>

### 14.1 从接受索引到二项分布

对固定规则令 $`I_i=A(X_i)`$。条件于完整接受指示向量时，不同样本仍独立：每个被接受对象的联合分布是原分布限制到 $`A=1`$ 后归一化。因为规则对每个对象相同，这些条件分布也相同，所以错误指示独立且都有均值 $`R`$。对所有大小为 $`m`$ 的索引集合求混合，不改变错误总数的同一个二项分布，于是 $`K\mid N=m\sim\operatorname{Bin}(m,R)`$。

不能把该论证误读成条件于所有输入特征后错误仍有相同概率。给定具体 $`X_i`$ 时，错误概率可能分别为 $`r(X_i)`$，其和一般是 Poisson 二项分布。我们的条件化只限制接受事件而不固定每个特征值，因而从同一条件总体抽样。这两个条件空间不同，解释清楚才知道二项边界为何在当前问题合法。

若对象成簇相关，例如同一用户的多个问题共享隐藏难度，条件于接受指示后错误也可能相关。此时计数几百条不代表几百个独立证据，可考虑按用户作为抽样单位、使用簇级损失和适合的集中界，或显式建模依赖。不能先忽略依赖得到很紧区间，再用一句数据可能相关作为脚注维持原保证。

<a id="selective-detail-62"></a>

### 14.2 一侧置信上界的反演证明

固定 $`m`$ 和真实风险 $`r`$。二项分布的下尾概率随 $`r`$ 增大而减小，而由反演构造的上界 $`U(k)`$ 随观察错误数增大而增大。事件 $`U(K)<r`$ 因此对应某个下尾集合 $`K\le k_*`$，该集合在参数 $`r`$ 下的概率不超过 $`\alpha`$。若没有任何错误数满足，则失败事件为空；离散跳跃导致实际概率可以严格小于预算。

对每个正接受数都得到同样失败预算，再按随机 $`N`$ 混合，仍有 $`P(R>U(K,N))\le\alpha`$。最后对候选联合，便能允许数据依赖地选择通过者。证明的顺序是固定规则、固定计数、对计数混合、对候选联合、在共同事件上选择；把最后的选择提前到第一步，却仍当作固定规则处理，正是常见漏洞。

数值求分位时，极小预算与极大计数可能有浮点问题，应使用可靠的生存函数或分位实现并核对边界。若为了好看把上界四舍五入到两位再比较目标，可能改变是否通过。应使用内部完整精度判定，展示时给足小数，并注明显示值经过舍入。统计有效性来自定义清楚的程序，也包括这些数值边界。

<a id="selective-detail-63"></a>

### 14.3 一个不直接估计比值的替代证书

固定目标 $`\varepsilon\in(0,1)`$，定义 $`Z_i=A_i(E_i-\varepsilon)`$。它取值在 $`[-\varepsilon,1-\varepsilon]`$，区间宽度为一，均值为 $`C(R-\varepsilon)`$。因此正覆盖下风险不超过目标等价于 $`E[Z]\le0`$。对固定候选可构造均值上界 $`\bar Z+\sqrt{\frac{\log(\frac{M}{\delta})}{(2n)}}`$，上界非正即得到风险结论。

这个方法不必先计算随机分母的区间，但仍需要规则冻结、独立样本与多重控制。它保护的是固定目标的不等式，不直接给每个候选一条可任意复用的风险数值上界。若看到结果后不断改变目标，又形成新的搜索范围。把条件比值写成均值不等式是有用工具，不会自动免除选择与数据权限问题。

与前面的接受条件 Hoeffding 相比，这个最简单无条件界往往更保守。后者通过 $`N`$ 个接受对象获得有效样本尺度，而前者把所有 $`n`$ 个对象用同一宽度界处理，忽略许多零值。可用方差敏感工具进一步改进，但需重新证明。两种路径说明相同风险目标可以有不同统计效率，不应把某个教学界误当最优方法。

<a id="selective-detail-64"></a>

### 14.4 未使用标签也可能改变规则身份

若根据认证输入的分数排序，把阈值设为该批第九十分位，即使没看标签，接受规则也依赖这些对象。对于新对象，它使用随机阈值；对认证对象，它们被迫满足一个次序选择条件。前面的固定接受集二项证明不能不加分析直接套用，因为条件于这个阈值与接受数后的训练对象，不一定是来自同一个固定条件总体的普通独立样本。

可以用独立开发输入决定分位阈值，再在新的认证数据上评估；或预先冻结一个有限数值网格，对所有网格点同时认证，最后选择；也可研究专门处理次序与数据复用的理论。这里强调的不是禁止利用无标签数据，而是利用方式也要与证明匹配。没有看标签比随意挖掘错误更受限，但不等于所有固定规则论证自动有效。

<a id="selective-detail-65"></a>

### 14.5 候选预算的设计与加权分配

联合界不要求每个候选都使用相同 $`\frac{\delta}{M}`$。可以预先分配 $`\alpha_j>0`$ 且总和不超过 $`\delta`$，对更有希望的候选给较大预算、其他候选给较小预算。这样每个固定证书仍满足自己的失败率，联合事件仍有效。预算分配应在认证数据之外决定，不能事后把好候选的预算放大却忘记重新核算其他搜索。

无限可数候选也可以用可求和权重分配，例如逐候选预算按几何级数衰减，但越后面的证书越保守。连续阈值若要统一控制，可以使用专门的经验过程或结构化多重检验，不由有限候选公式自然推出。本章给有限网格是为了使每一步可直接复算，而不是断言所有高效算法都必须使用相同形式。

<a id="selective-detail-66"></a>

## 15. 实跑结果的解释与反事实检查

<a id="selective-detail-67"></a>

### 15.1 固定训练和认证的实际工作点

完整分类实验只用一千八百训练对象拟合逻辑回归，固定三十次 Newton 更新；六千认证对象不参与模型拟合，三万独立测试对象不参与模型或阈值选择。二十五个阈值使用总失败预算零点零五，目标风险零点一。实际选中阈值约零点八二，认证接受二千八百八十五、错误二百二十七，同时风险上界约零点零九四一五四。

测试接受一万四千三百四十三，回答比例零点四七八一，选择性风险约零点零七六六九，全部回答风险约零点二零七四七。这个结果展示了自动回答可靠性与回答数量的取舍，不是免费提高全部请求准确率。被拒的约一半对象在模拟中没有后续审核，因此没有完整服务成功率或人工成本结论。

虽然数据生成机制是逻辑概率，训练带有限样本、额外特征和正则，因此没有把最大概率直接当作真条件正确率。独立认证是核心证据，而非把模型形式写对就宣称校准已精确。若读者改变标签噪声、来源或模型，阈值数值不应直接复用，应重新训练与认证，并保留新的随机协议。

<a id="selective-detail-68"></a>

### 15.2 搜索反例的精确概率

一百候选实验中，每个真实风险零点一一，都不满足零点一目标。直接以二百样本经验率达标选择，允许最多二十个错误；同时二项证书只允许最多七个错误。在候选错误独立的指定模型里，至少一个错误通过的精确概率，前者在显示精度内接近一，后者约零点零一零四四九。

五千次模拟观察到的对应比例为一和零点零一二二。后一个不是恰好等于理论概率，正常存在蒙特卡洛波动；理论值本身也低于零点零五而非恰等预算，源于离散性和联合界的保守。实验说明多重搜索的影响很大，同时也展示严谨证书需要牺牲一些通过率。

对百分之一风险目标，零错误下单规则至少二百九十九接受样本，一百候选至少七百五十七。额外搜索有明确统计成本，不能只从计算时间估计调参代价。若所有候选其实高度相似，可以研究利用相关结构提高效率；但这种改进需要新论证，不能直接删掉候选数。

<a id="selective-detail-69"></a>

### 15.3 怎样构造更难的研究对照

第一组对照保持模型与数据不变，故意打乱可靠性分数排序，观察曲线和可认证覆盖如何变化；第二组保持分数不变，改变认证量与候选数，研究统计效率；第三组冻结所有规则，改变测试群体组成或标签机制，研究迁移失效。三组分别改变排序、证据量和未来总体，能避免把所有差异归为模型能力。

对于第二组，应重复抽取独立认证集，使用已知人工总体真风险判断是否错误认证，同时记录无证书比例。对于第三组，先明确变化是否仍在原保证范围内；超出范围的失败可以说明局限，但不直接推翻原定理。研究报告最好同时给一个满足条件的正例和一个破坏条件的反例，使读者看到机制而非只看到结果排名。

<a id="selective-detail-70"></a>

### 15.4 有限样本证据与长期部署

认证面对的是指定总体下的固定规则，长期部署还涉及模型更新、数据漂移和服务流程变化。可预先确定重新认证触发条件与独立抽样计划，但在线监控本身也有重复查看问题，应使用相应时间控制。告警分数变化不是错误率已经变化的证明，却可以作为收集新结果标签的线索。

若真实错误标签延迟获得，当前风险估计反映的是已经成熟的结果，不能把未到期对象按正确计入分母。不同来源的标注一致性和人工判定误差也会影响损失定义。统计保证不会纠正输入标签的系统性错标；需要在数据协议中说明可观测目标与最终想保护的后果是否一致。

<a id="selective-detail-71"></a>

## 16. 补充推导练习

<a id="selective-detail-72"></a>

### 16.1 题二十一：误差质量的单调性

题目：阈值提高时，未归一化错误质量是否会增加？解析：对固定分数、同一预测器与非负损失，接受集嵌套缩小，因此 $`E[AE]`$ 不会增加；覆盖也不会增加。但两者比值仍可能增大，第一实验正是如此。应区分两个单调分子分母与一个未必单调比值，不能从子集更小直接推出条件风险更低。

<a id="selective-detail-73"></a>

### 16.2 题二十二：源目标比值推导

题目：如何从总变差定义得到迁移上界？解析：错误质量是事件 $`A=1,E=1`$ 的概率，覆盖是事件 $`A=1`$ 的概率，两者差分别至多 eta。因此目标分子不超过源分子加 eta，分母不少于源覆盖减 eta；分母正时相除，再代入源风险乘源覆盖。若源覆盖不大于 eta，分母界无用，只能保留风险至多一。

<a id="selective-detail-74"></a>

### 16.3 题二十三：不均等失败预算

题目：三个候选预算零点零一、零点零一和零点零三，总体保证怎样写？解析：每个上界按自己的单候选预算构造，联合失败不超过零点零五。第三个证书相对宽松，若分配在开发阶段固定便合法。若在看到哪个候选经验最好后才把零点零三给它，就需要分析这种重新分配过程，不能沿用预先固定预算证明。

<a id="selective-detail-75"></a>

### 16.4 题二十四：候选均拒与总体正覆盖

题目：认证样本没有接受者，是否证明总体覆盖零？解析：不是，低覆盖规则可能恰好在有限样本中一个都未接受。证书将其上界设一，是承认缺少条件风险证据，不是估计总体风险等于一或覆盖等于零。若希望约束总体覆盖，可另作二项区间；零接受只提供一个有限样本的覆盖上界。


<a id="selective-detail-76"></a>

## 17. 排序指标、并列和曲线研究

<a id="selective-detail-77"></a>

### 17.1 理想排序下的风险覆盖面积

设有限总体错误比例为 $`p\in(0,1)`$，理想排序把所有正确对象放在错误对象之前。连续质量模型中，接受比例 $`c\le1-p`$ 时风险为零；接受更多时新增对象都是错误，风险为 $`\frac{(c-1+p)}{c}`$。因此理想风险覆盖曲线面积为

$$
\int_0^1R(c)dc=p+(1-p)\log(1-p).
$$

推导只需在一减 p 到一积分一减一减 p 除以 c。若错误率为零点二，面积约零点零二一四九；随机排序在每个正覆盖处总体风险都为 p，面积为零点二。这个参照把错误排序的作用量化，同时提醒基础错误总量本身也影响面积。不同预测器之间比较面积，不能把全部差异都归为可靠性分数好坏。

经验 AURC 还涉及离散求和、并列排序与零覆盖端怎样定义，报告应写清口径。若改成超出理想面积的差值，可以部分分离基础错误率，但它仍不是风险上限证书，也不替代指定工作点。曲线面积好不保证某个特别关心的覆盖区间好，应用目标应先于聚合指标确定。

<a id="selective-detail-78"></a>

### 17.2 分数并列时的规则身份

量化概率或小模型常产生大量相同分数，阈值只能一次接受整层对象。为了达到精确覆盖，可以在边界分数层用独立随机数接受一部分，但这个随机机制也属于规则。认证与部署应使用同一概率与同一标签无关机制；如果认证阶段只保留边界里恰好正确者，那已经使用结果标签筛选，固定规则证明不成立。

可把额外随机数 U 与输入一起视作扩展对象，接受函数写成 A(X,U)。当未来 U 独立同分布且机制冻结，前面的条件二项证明仍可在扩展总体上使用。若使用跨请求共享的状态或随负载改变接受比例，则独立机制假设需要重新检查。随机化不是免费擦除并列的办法，而是需要明确记录的一部分决策协议。

<a id="selective-detail-79"></a>

### 17.3 曲线上的误差条与工作点证书

对一个冻结阈值作区间，与对整个数据选择曲线作同时带，要求不同。给每个阈值画一个各自百分之九十五区间，不意味着整条曲线同时有百分之九十五保护；挑最好一段看又增加选择。可以使用预设有限阈值的联合界画保守带，或研究利用嵌套结构的方法，但不能把图形连续性当作统计同时性。

自助法能帮助估计某些曲线统计量的波动，却需匹配样本单位、选择过程和适用条件。对极小接受数、零错误和边界风险，简单正态近似可能尤其不稳。教学和研究中应先用可精确枚举的人工模型检查覆盖，再把近似工具用于复杂数据；一个看起来漂亮的误差条并不自动比保守但清楚的边界更有证据。

<a id="selective-detail-80"></a>

### 17.4 证书陈述的完整句子

本章完整实验的合适陈述是：在固定训练结果与二十五个预设规则后，若认证和未来对象来自同一独立总体，所用二项同时程序以至少零点九五的认证抽样概率，让任一通过规则的未来接受条件错误率不超过零点一。还应单独报告选中规则在测试中的回答比例和经验错误，而非把所有数字揉成一个可靠率。

如果其中一个前提改变，先问它影响哪一步证明：模型更新影响固定规则，分布变化影响条件总体，簇依赖影响二项计数，重复查看影响失败预算，标签缺失影响观察到的错误。按这条链定位问题，可以把研究从泛泛担忧推进到具体可检查条件，也让读者知道下一步应收集什么新证据。
