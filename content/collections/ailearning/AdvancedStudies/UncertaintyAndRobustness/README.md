# 不确定性与分布鲁棒性

将校准、保形覆盖、分布加权和群体风险放在各自假设下比较。

**先修知识：** 统计推断、概率指标、重要性采样和独立评价；学习理论可作为后续深化。

**正文篇幅状态：** 本主题现有 3 章均已按长篇教材标准展开，逐章纯正文达到 12000–20000 汉字。全库进度见[长篇教材覆盖表](../../README.md#textbook-status)。

## 阅读顺序与验收

第 1 章区分概率校准、边缘集合覆盖和校准集外层保证；第 2 章固定分布变化类型，研究重加权、群体目标和稳健取舍；第 3 章再学习接受条件风险、冻结候选规则与联合有限样本认证。集合包含真值、回答比例和回答后的错误率是不同目标，不能互相替代。遇到公式先复算低维例子，再进入实验设计；不要把局部数值检查当成算法整体效果证明。

**完成要求：** 用秩推导保形覆盖；区分边缘与条件保证；复算分布加权；报告平均与最坏群体风险的取舍。冻结分数与阈值网格，复算拒答风险上界，同时报告回答比例和不同群体代价。

作答后再阅读各章解析。能够独立说明一个失效条件，并设计一个可区分竞争解释的对照实验，才算完成本主题的进阶学习。
