## 1. 先确定要计算哪个积分

给定观测数据后，后验密度记为 $`\pi(q)`$，关注量可以是参数均值、某事件概率或后验预测。目标积分为 $`E_\pi[f]=\int f(q)\pi(q)dq`$。MCMC 不是只负责生成一串看起来随机的数字，而是要让平均 $`f(q)`$ 对这个明确对象有可解释误差。不同函数会有不同相关性，参数均值采得好不代表稀有事件概率也已精确。

<a id="mcmc-2-detail-2"></a>

### 1.1 后验不确定性与计算误差分开

后验标准差反映在模型与数据给定后参数的分散；Monte Carlo 标准误反映有限计算对某个后验统计的近似误差。若数据很少，后验可以很宽，但计算均值的标准误仍很小；若链没有遍历，表面波动很小也可能只是停在局部区域。两类不确定性不能互相替代，更不能把链样本的标准差直接当作均值计算标准误。

还要区分后验模型是否适合现实。采样器即使完美达到目标，也只验证了计算层面，没有证明先验、似然和数据机制正确。可以在可解析模型中验证采样器，再通过后验预测、敏感性与独立数据检查建模。采样诊断、近似误差和模型检验是三项任务，各自需要证据。流畅的概率解释不能掩盖其中任何一层缺失。

<a id="mcmc-2-detail-3"></a>

### 1.2 未归一化目标为什么往往够用

设 $`\widetilde\pi(q)=p(y,q)`$，归一化常数为证据 $`Z`$，则 $`\pi=\frac{\widetilde\pi}{Z}`$。许多转移只用同一目标的密度比，常数会消去；HMC 使用 log 密度梯度，常数导数也为零。这使后验采样不必先求出通常困难的证据，但不表示所有计算都免费。目标仍需可求值，梯度仍需准确，尾部仍需可归一化。

如果目标本来不是正常概率分布，例如不适当先验加上不足数据导致后验积分发散，程序可能仍产生有限轨迹。稳定输出不构成后验存在性证明。同样，漏掉一个依赖参数的因子不是省略常数，而是改变目标。实现前应逐项标明哪些项与参数有关，单位、约束与变换也应纳入这一检查。

## 2. 不变性、可达性与有限时间精度

转移核 $`K(q,A)`$ 给出当前 $`q`$ 下一步进入集合 $`A`$ 的概率。不变性是 $`\int\pi(dq)K(q,A)=\pi(A)`$；若从目标抽初值，每一步边缘都保持目标。它只描述一种特殊初始分布下的保持性质，不保证从任意初值很快到达该分布。最简单反例是恒等核：永远原地不动，每个分布都不变，实际却没有探索。

<a id="mcmc-2-detail-5"></a>

### 2.1 有限链的行约定与收敛条件

有限状态转移矩阵采用行表示当前位置、列表示下一位置，分布为行向量，所以不变性为 $`\pi P=\pi`$。不可约意味着状态间可以通过有限步正概率路径到达，非周期性排除只能在固定余数时刻返回的振荡。有限不可约非周期链具有唯一不变分布并从任意初始分布趋近它，但收敛速度仍由具体转移结构决定。

连续空间需要更谨慎的不可约、再生和遍历条件，不能把有限矩阵定理逐字搬来。即使某个定理保证遍历平均收敛，也不自动给当前步数的有用误差界。要建立均值的中心极限定理，还需相应函数的矩和依赖控制。说“链遍历”之前，应明确是分布收敛、样本平均收敛还是渐近正态，以及它适用于哪些函数。

<a id="mcmc-2-detail-6"></a>

### 2.2 细致平衡是充分构造，不是唯一方式

有限情形细致平衡为 $`\pi_iP_{ij}=\pi_jP_{ji}`$。对 $`j`$ 固定并对 $`i`$ 求和，右侧等于 $`\pi_j`$ 乘转移行和，所以导出不变性。它要求每对状态的稳态流量对称，比总流入等于总流出更强。不满足细致平衡的定向循环也可能有合法不变分布，因此不能把可逆性误当所有 MCMC 的定义。

一个三状态循环每次沿同一方向移动，对均匀分布不变却有周期；加一部分原地等待后仍不变并可消除周期，但仍非可逆。构造方法可以利用非可逆流改善某些混合性质，需要独立分析。这里只用这个反例说明逻辑方向：细致平衡推出不变性，不变性不反推细致平衡，更不单独推出快速混合。

<a id="mcmc-2-detail-7"></a>

### 2.3 懒惰核怎样保留目标却改变效率

若 $`P`$ 保持目标，$`P_\lambda=\lambda I+(1-\lambda)P`$ 也保持目标。它将每个原特征值 $`\xi`$ 变为 $`\lambda+(1-\lambda)\xi`$。对于原本已可有效移动的方向，$`\lambda`$ 接近一会使特征值接近一，相关性和混合时间增加；对于周期振荡，适当等待又可能有益。因此“增加拒绝或等待”并非无条件好坏，需要看原核结构。

这个线性计算还解释接受率的局限。很高接受率可能来自很小提议，几乎不拒绝却只挪动极短距离；降低步长后接受率提高，不代表有效信息更多。应结合目标统计的相关、每次提议成本与实际移动，而不是将单一接受比例当作算法成绩。

## 3. Metropolis–Hastings 从通量推导

从当前 $`x`$ 按提议密度或概率 $`q(y\mid x)`$ 抽候选，采用

$$
\alpha(x,y)=\min\left(1,\frac{\widetilde\pi(y)q(x\mid y)}{\widetilde\pi(x)q(y\mid x)}\right).
$$

接受时移到 $`y`$，否则保留 $`x`$。在两个方向均有定义的区域，接受通量为两方向原始通量的最小值，因此对称。拒绝概率补回对角或原地质量，使整行概率为一。保留重复状态是算法的一部分，不能只保存接受样本再把它们当目标样本，后者通常形成有偏的跳链。

<a id="deep-dive-2"></a>

<a id="mcmc-2-detail-9"></a>

### 3.1 非对称提议为什么必须补反向概率

目标两状态各半，提议从零到一为零点九、从一到零为零点一。若只比较目标密度，两方向都接受，实际平稳质量为零点一与零点九。正确从零到一接受率为九分之一，反向为一，实际跨状态概率两边都为零点一。提议比补偿方向被尝试的频率，并不是可以忽略的归一化常数。

若正向可提议而反向概率为零，普通 MH 在正目标支持内对该方向接受率为零，这可能破坏可达性。约束边界、截断提议和状态相关方差尤其需要检查反向密度。把越界提议直接拒绝，与不断重抽直到落入边界内，是不同提议机制；后者有依赖当前状态的截断常数，不能沿用前者的简单对称比率。

<a id="mcmc-2-detail-10"></a>

### 3.2 在log尺度比较与零支持

常用接受条件为 $`\log U<\min(0,\log r)`$，避免先算极大或极小密度再相除。常数抵消仍成立，但候选 log 密度的每个参数相关项都要保留。当前状态应位于目标合法支持；若初始点密度为零，公式的普通比值可能未定义，需要合法初始化或明确扩展规则，而不是把非有限数替换成一个看似正常概率。

提议密度计算也必须对应真实采样器。连续高斯随机游走在固定协方差下对称，位置相关协方差、混合提议和边界重抽则通常不再如此。实现可以先用有限状态枚举核对通量，再做连续可解析目标。小例子不会证明所有代码正确，却能揭示哪些假设在真正执行时被改变。

### 3.3 实验一：精确核与错误目标

以下独立代码构造非对称两状态提议，对比正确 MH 和省略提议比的错误核。随后保留三状态旧算例并加入懒惰核、定向循环与周期反例，分别检查不变性、可逆性和移动速度。所有结论都可通过矩阵乘法直接复核，不依赖随机轨迹看起来是否平滑。

```python
import numpy as np
pi=np.array([.5,.5]);proposal=np.array([[.1,.9],[.1,.9]])
correct=np.zeros((2,2))
for i in range(2):
    for j in range(2):
        if i!=j:
            correct[i,j]=proposal[i,j]*min(1.,pi[j]*proposal[j,i]/(pi[i]*proposal[i,j]))
    correct[i,i]=1-correct[i].sum()
assert np.allclose(pi@correct,pi)
wrong=proposal.copy()
assert not np.allclose(pi@wrong,pi)
assert np.allclose(np.array([.1,.9])@wrong,[.1,.9])
pi3=np.array([.2,.3,.5]);p=np.zeros((3,3))
for i in range(3):
    for j in range(3):
        if i!=j:p[i,j]=.5*min(1.,pi3[j]/pi3[i])
    p[i,i]=1-p[i].sum()
assert np.allclose(pi3@p,pi3)
assert np.allclose(pi3[:,None]*p,(pi3[:,None]*p).T)
lazy=.99*np.eye(3)+.01*p
assert np.allclose(pi3@lazy,pi3) and lazy[0,0]>p[0,0]
cycle=np.array([[0.,1.,0.],[0.,0.,1.],[1.,0.,0.]])
assert np.allclose(np.ones(3)/3@cycle,np.ones(3)/3)
assert not np.allclose(cycle,cycle.T)
assert np.allclose(np.linalg.matrix_power(cycle,3),np.eye(3))
print('correct/wrong two-state stationary',pi@correct,pi@wrong)
print('base/lazy eigenvalues',np.linalg.eigvals(p),np.linalg.eigvals(lazy))
```

## 4. 参数坐标是目标的一部分

后验通常定义在正数、概率或相关矩阵等约束空间。变换到无约束坐标有利于提议，但变换后的密度需要体积修正。若 $`q=g(z)`$，目标变成 $`\pi(g(z))\vert \det J_g(z)\vert `$。这不是给同一个密度换变量名；它改变了每单位坐标体积对应的概率质量。漏掉 Jacobian 会让采样器忠实达到另一个分布。

<a id="mcmc-2-detail-13"></a>

### 4.1 Gamma例子的完整log目标

设正参数 $`\theta`$ 服从形状 $`k>0`$、率 $`\beta>0`$ 的 Gamma 目标，密度正比于 $`\theta^{k-1}e^{-\beta\theta}`$。令 $`z=\log\theta`$，因为 $`\frac{d\theta}{dz}=e^z`$，正确 log 目标为 $`kz-\beta e^z`$ 加常数。若漏修正，就使用 $`(k-1)z-\beta e^z`$，变回原坐标当 $`k>1`$ 时相当于形状减少一；当 $`k\le1`$ 时该错误目标还可能不可归一化，不能继续当作合法 Gamma 分布。它不是同一目标的无害近似。

当 $`k=3,\beta=2`$ 时，正确均值为一点五、方差为零点七五；漏项目标的均值为一、方差为零点五。两条链都可能有合理接受率与稳定轨迹，诊断本身不能识别你写错的目标。可解析分布和坐标往返检查因此是重要开发工具，不能只在最终复杂模型里看一个收敛指标。

<a id="mcmc-2-detail-14"></a>

### 4.2 实验二：有无Jacobian的两个真实采样目标

本段运行四条独立随机游走链，丢弃预先规定的预热，分别对正确和错误 log 目标采样。保留所有拒绝状态。数组中的每一行是一条链，不把它们拼接成一条连续路径计算相关。均值与方差用解析 Gamma 结果核对，容差只是本例预设检查，不构成任意目标的有限时间误差保证。

```python
import numpy as np

def run(include_jacobian):
    chains=[];acceptance=[]
    for index,start in enumerate([.3,.8,2.,5.]):
        rng=np.random.default_rng(301+index)
        z=np.log(start);kept=[];accepted=0
        coefficient=3. if include_jacobian else 2.
        def log_target(value):
            if value>700:return -np.inf
            return coefficient*value-2*np.exp(value)
        lp=log_target(z)
        for step in range(14000):
            candidate=z+.8*rng.normal();new=log_target(candidate)
            if np.log(rng.random())<min(0.,new-lp):
                z=candidate;lp=new
                if step>=2000:accepted+=1
            if step>=2000:kept.append(np.exp(z))
        chains.append(kept);acceptance.append(accepted/12000)
    return np.array(chains),np.array(acceptance)
correct,accept=run(True);wrong,wrong_accept=run(False)
assert correct.shape==(4,12000) and wrong.shape==(4,12000)
assert abs(correct.mean()-1.5)<.05 and abs(correct.var()-.75)<.08
assert abs(wrong.mean()-1.)<.05 and abs(wrong.var()-.5)<.08
assert abs(correct.mean()-wrong.mean())>.4
print('correct mean/variance/acceptance',correct.mean(),correct.var(),accept)
print('wrong mean/variance/acceptance',wrong.mean(),wrong.var(),wrong_accept)
```

### 4.3 边界和数值稳定不能改变模型

指数变换保证正数但可能在极端坐标溢出。示例对过大候选返回负无穷，等价于将机器可表示之外的极小目标区域拒绝，是具体有限精度处理；它没有宣称形式上完整覆盖任意正实数。真实程序还应检查梯度和非有限错误，避免无声地裁剪参数后仍按原提议密度接受，这通常会改变核。

概率向量常通过另一种坐标变换表示，还会涉及维度与冗余。不能把每个概率独立取 log 再假设得到自由的同维空间，因为和为一约束仍在。不同参数化可能改善几何，却要共同维护目标测度、梯度和约束。一个正确的变换说明应给出正向、逆向、Jacobian 及合法支持，而不是只展示数值范围变得方便。

<a id="mcmc-2-detail-16"></a>

## 5. HMC把位置与动量一起采样

随机游走往往在高相关后验中反复试探局部方向。HMC 引入辅助动量 $`p`$，将位置目标扩展为 $`\bar\pi(q,p)=\pi(q)N(p;0,M)`$，其中 $`M`$ 为固定对称正定质量矩阵。对 $`p`$ 积分后仍得到原位置目标，所以额外变量并没有改变需要估计的后验。它们的作用是构造沿几何结构移动的提议，而不是给模型增加新的未知科学参数。

<a id="mcmc-2-detail-17"></a>

### 5.1 Hamilton方程与能量守恒

令 $`U(q)=-\log\widetilde\pi(q)`$、$`T(p)=\tfrac12p^TM^{-1}p`$、$`H=U+T`$。Hamilton 方程为

$$
\begin{aligned}
\dot q &=M^{-1}p,\\[6pt]
\dot p &=-\nabla U(q).
\end{aligned}
$$

沿精确轨迹求导，$`\frac{dH}{dt}=\nabla U(q)^T M^{-1}p+(M^{-1}p)^T[-\nabla U(q)]=0`$。这证明能量守恒，但只在目标可微、动力学有适当解的条件下成立。计算机通常不能精确求该轨迹，因此不能把微分方程的恒等式直接当成数值提议的能量完全不变。

连续流还保持体积。其向量场散度为位置速度对位置的导数迹加动量速度对动量的导数迹，在固定可分离动能下两项均为零。能量守恒加体积保持解释了扩展目标为何与该动力学兼容。仅沿某条等能量线运动又不保证遍历整个分布，所以每次重新抽动量是完整算法的重要部分，而非可随意删除的装饰。

<a id="sec-3-1"></a>

<a id="mcmc-2-detail-18"></a>

### 5.2 Leapfrog的三步与结构证明

一步长度 $`\varepsilon`$ 的 leapfrog 先半步动量，再整步位置，再半步动量：

$$
p_{\frac{1}{2}}=p-\tfrac\varepsilon2\nabla U(q),\quad
q'=q+\varepsilon M^{-1}p_{\frac{1}{2}},\quad
p'=p_{\frac{1}{2}}-\tfrac\varepsilon2\nabla U(q').
$$

每个动量更新是固定位置下的平移，Jacobian 为对角块均为单位阵的三角矩阵；位置更新也是同类剪切，所以各步绝对行列式为一，组合仍保持体积。把步长换成负值并逆序执行，可恢复原点；对称的半步结构使这一逆过程具有同样形式。这些结构性质比“误差很小”更关键，因为它们决定简单 MH 校正是否合法。

设 $`\Phi`$ 为多步积分映射，$`R(q,p)=(q,-p)`$。在该可逆结构下 $`R\Phi R=\Phi^{-1}`$，故 $`F=R\Phi`$ 满足 $`F^2=I`$。把末端动量翻转后，确定性提议成为体积保持的对合，扩展空间的接受概率可以使用 $`\min(1,e^{-H(Fx)+H(x)})`$。拒绝时保留原位置；新一次再刷新动量。动量翻转不改二次动能，但在证明中不可被“能量一样”这句话替代。

<a id="mcmc-2-detail-19"></a>

### 5.3 为什么接受步骤能修正能量误差

对合将状态成对联系，绝对体积比为一，两方向目标通量取最小便得到平衡，与普通 MH 证明相同。因此有限积分误差主要影响接受率与效率，在这些前提下不必造成目标偏差。若换成非体积保持积分器，需要相应 Jacobian 修正；若提议不可逆或随机路径选择依赖当前状态却没纳入机制，简单能量差接受式就未必正确。

标准 HMC 的力来自实际势能梯度。若改用确定性近似力或裁剪力，就不再是在积分原 Hamilton 方程；不过，只要仍以同一确定性力构造可逆、体积保持的对称提议，并用完整真实能量做正确 MH 修正，目标不变性仍可能成立，代价主要体现为提议效率。

这是由前述映射证明得到的边界，不能笼统宣称所有不精确梯度必然引入目标偏差。随机小批力还涉及反向随机性，应另行设计完整机制；不能不加说明就当作标准 HMC。真正错误的反向或接受结构，即使局部误差小，也可能长期采到错误分布。

<a id="mcmc-2-detail-20"></a>

## 6. 几何、质量矩阵与积分预算

HMC 不是只需调一个步长。后验不同方向的曲率、质量矩阵、积分长度和参数坐标共同决定轨迹。如果某方向特别窄，稳定步长可能受它限制；沿其他宽方向移动又需要较长时间。结果是每个提议消耗很多梯度，但有效探索仍差。可解析相关高斯有助于把这些影响从复杂模型中分离出来。

<a id="mcmc-2-detail-21"></a>

### 6.1 高斯目标下质量约定必须写清

设目标协方差为 $`\Sigma`$，则 $`\nabla U=\Sigma^{-1}q`$，动力学满足 $`\ddot q=-M^{-1}\Sigma^{-1}q`$。本章约定动量协方差就是 $`M`$，动能使用 $`M^{-1}`$。在这一约定下，选择 $`M=\Sigma^{-1}`$ 使所有标准化频率相同；并非把目标协方差直接作为这个 $`M`$。一些软件使用逆质量或度量矩阵命名，比较实现时应回到动能公式，而不是凭名称判断。

若 $`M=I`$，目标协方差特征值为 $`\lambda`$ 的方向频率为 $`\frac{1}{\sqrt\lambda}`$；若误把 $`M`$ 取为 $`\Sigma`$，频率会变成 $`\frac{1}{\lambda}`$，可能进一步拉大方向差异。这个解析计算不是要求现实中知道真实协方差，真实采样通常需预热估计或重参数化。已知高斯中使用真实精度是一个理想几何对照，不能当作未知后验里免费的先验知识。

<a id="mcmc-2-detail-22"></a>

### 6.2 一维谐振子的稳定步长

对 $`U(q)=\frac{\omega^2q^2}{2}`$、单位质量，一步 leapfrog 的线性矩阵为

$$
\begin{pmatrix}
1-\frac{\varepsilon^2\omega^2}{2}&\varepsilon\\
-\varepsilon\omega^2(1-\frac{\varepsilon^2\omega^2}{4})&1-\frac{\varepsilon^2\omega^2}{2}
\end{pmatrix}.
$$

它的行列式为一，迹为 $`2-\varepsilon^2\omega^2`$。当 $`0<\varepsilon\omega<2`$ 时，两特征值在单位圆上，线性振荡保持有界；超过二会出现指数增长方向。边界等于二通常不是可放心使用的稳定点。可见步长相同并不代表对所有曲率同样合适，窄方向的高频会给出更严约束。

边界为什么不能只凭特征值模长判断？当 $`\varepsilon\omega=2`$ 时，矩阵变成 $`\left[\begin{smallmatrix}-1&\frac{2}{\omega}\\0&-1\end{smallmatrix}\right]`$，具有重复特征值负一，却有非零 Jordan 非对角项。第 $`n`$ 次幂为 $`(-1)^n\left[\begin{smallmatrix}1&-\frac{2n}{\omega}\\0&1\end{smallmatrix}\right]`$，因此一般初始动量会使位置幅度随 $`n`$ 线性增长。单位圆上的特征值只有配合适当可对角化条件才能保证所有矩阵幂有界；这里严格小于二的条件不能随手改成小于等于。

这个结论针对二次势与精确线性计算。一般后验曲率随位置变，局部稳定条件可能不同，舍入和极端尾部也会影响结果。过大能量误差被拒绝并不表示效率还能接受，复杂几何还可能产生需要进一步检查的数值警告。增加链长不能自动修复一个大部分时间无法移动的提议机制。

<a id="mcmc-2-detail-23"></a>

### 6.3 路径长度、共振与随机化

即使每步稳定，积分时间若恰好接近完整周期，轨迹可能回到原位置；接近半周期时可能产生负相关。高接受而几乎不动再次成为可能。预先从与当前状态无关的有限长度集合抽路径长度，可以构成多个合法核的混合，仍保持同一目标。状态相关的动态停止则要设计完整正确机制，不能只因平均路径短就沿用固定长度证明。

用精确高斯动力学还可以把“几乎不动”算出来。对单位质量的一维目标 $`q\sim N(0,\omega^{-2})`$，每次刷新 $`p\sim N(0,1)`$ 后积分时间 $`T`$，解析解为

$$
q'=q\cos(\omega T)+\frac p\omega\sin(\omega T).
$$

这来自 $`\ddot q=-\omega^2q`$ 及初始速度 $`\dot q(0)=p`$。处于平稳分布时，$`\operatorname{Corr}(q,q')=\cos(\omega T)`$，而中心化平方量满足 $`E[q'^2-\omega^{-2}\mid q]=\cos^2(\omega T)(q^2-\omega^{-2})`$。所以 $`T`$ 接近半周期时，位置均值可能获得强负相关，平方统计量却仍有强正相关；只看一个均值的 ESS 会漏掉另一项几乎不变的事实。

取 $`T=\frac{\pi}{\omega}`$，位置精确变为 $`-q`$，刷新动量也无法改变绝对位置，轨迹只在两个点之间往返；取完整周期则 $`q'=q`$。这两种精确提议都能保持目标分布，却不能从任意初值有效探索它。相反，四分之一周期 $`T=\frac{\pi}{(2\omega)}`$ 给 $`q'=\frac{p}{\omega}`$，在这个特殊已知高斯模型中恰好产生独立目标样本。这不是通用采样器的免费调参办法：多维频率通常不同、真实目标非二次且未知，有限步 leapfrog 还会产生相位和能量误差。它只是把积分时长、函数相关性和遍历性之间的区别用一个完整解展示出来。

NUTS 等方法处理动态路径构造，本章只讨论其动机，不实现生产版本或宣称跑过树深、发散诊断。手写固定或独立随机长度 HMC 足以核对基础结构。比较效率应计入梯度次数和实现成本；小型 Python 循环的实际时间不代表优化采样器或 GPU 服务的速度，公式性质与工程性能应分别报告。

<a id="mcmc-2-detail-24"></a>

## 7. 实验三：完整高斯HMC与几何对照

二维目标协方差的非对角为零点九五。先在单个状态验证积分往返和数值 Jacobian 体积，再运行单位质量与真实精度质量两个完整采样器。每次独立随机选八至十六步，固定步长零点一六；保留六千样本，预热一千步。该选择预先给定，不从测试结果挑最漂亮轨迹。

<a id="mcmc-2-detail-25"></a>

### 7.1 可运行代码及检查对象

样本均值与协方差有解析参照。接受比例和宽方向的一阶相关只作当前配置的机制观察，不作为普遍速度排名。数值 Jacobian 只在二维做有限差分，适合开发核对，不是高维 HMC 正常运行所需步骤。动量每次刷新，拒绝位置仍保留，扩展能量按同一质量计算。

```python
import numpy as np
sigma=np.array([[1.,.95],[.95,1.]])
precision=np.linalg.inv(sigma)

def leap(q,p,step,length,mass):
    q=q.copy();p=p.copy();inv=np.linalg.inv(mass)
    p-=.5*step*(precision@q)
    for index in range(length):
        q+=step*(inv@p)
        p-=(.5 if index==length-1 else 1.)*step*(precision@q)
    return q,p

def proposal(z,mass):
    q,p=leap(z[:2],z[2:],.16,11,mass)
    return np.r_[q,-p]

z=np.array([.4,-.2,.6,.1]);mass=precision
assert np.allclose(proposal(proposal(z,mass),mass),z,atol=1e-12)
eps=1e-6;jac=np.column_stack([(proposal(z+eps*np.eye(4)[i],mass)-
                            proposal(z-eps*np.eye(4)[i],mass))/(2*eps) for i in range(4)])
assert abs(abs(np.linalg.det(jac))-1)<1e-8

def run(mass,seed):
    rng=np.random.default_rng(seed);q=np.array([2.,-1.]);kept=[];accepted=0
    inv=np.linalg.inv(mass);root=np.linalg.cholesky(mass)
    def energy(q,p):return .5*q@precision@q+.5*p@inv@p
    for index in range(7000):
        p=root@rng.normal(size=2)
        candidate,newp=leap(q,p,.16,int(rng.integers(8,17)),mass)
        change=energy(candidate,newp)-energy(q,p)
        if np.log(rng.random())<min(0.,-change):
            q=candidate
            if index>=1000:accepted+=1
        if index>=1000:kept.append(q.copy())
    return np.array(kept),accepted/6000

for name,mass,seed in [('identity',np.eye(2),311),('precision',precision,312)]:
    samples,accept=run(mass,seed)
    mean=samples.mean(0);cov=np.cov(samples,rowvar=False)
    assert np.max(np.abs(mean))<.08
    assert np.max(np.abs(cov-sigma))<.12
    wide=samples.sum(1)/np.sqrt(2)
    rho=float(np.corrcoef(wide[:-1],wide[1:])[0,1])
    print(name,'mean',mean,'covariance',cov.tolist(),'acceptance',accept,'wide lag1',rho)
print('proposal absolute Jacobian determinant',abs(np.linalg.det(jac)))
```

### 7.2 接受率与相关可以朝不同方向变化

本例两种质量都保持同一目标，实际统计是否接近解析矩由代码检查。真实精度质量使用了目标已知几何，是有限机制对照；单位质量也可能通过不同步长与长度获得更好结果，所以不能从这一套参数宣布所有调参方案的优劣。负相关并不是采样失败，在适当条件下可以减少均值估计方差，后文将用精确公式解释。

动量翻转虽没有在只返回位置的采样代码中显式保存，能量因二次动能对符号不变而相同；正确性可以把提议理解为末端翻转的扩展映射。数值往返实验正是对该映射检查。实现说明应交代这一点，避免把“没有把动量留到下一次”误认为可以任意删除可逆性证明中的步骤。

## 8. 有效样本量从均值方差推导

设已经处于平稳分布，$`X_t=f(q_t)`$ 具有有限非零方差 $`\sigma_f^2`$，滞后相关为 $`\rho_k`$。将样本均值方差展开成全部协方差对，得到精确有限长度公式

$$
\operatorname{Var}(\overline X_N)=\frac{\sigma_f^2}{N}
\left[1+2\sum_{k=1}^{N-1}\left(1-\frac{k}{N}\right)\rho_k\right].
$$

滞后 $`k`$ 的协方差在双重求和里出现 $`2(N-k)`$ 次，除以 $`N^2`$ 后就得到该权重。它没有把相关样本硬说成独立，只是把二阶依赖完整计入。若初始化不平稳，协方差可能还依赖具体时刻，不能直接只用一个滞后序列；预热后的稳定性也是应用这个简化式的前提。

<a id="mcmc-2-detail-28"></a>

### 8.1 渐近方差、ESS与MCSE

以下自相关定义要求 $`0<\sigma_f^2<\infty`$；常数统计量的相关系数和按方差比定义的 ESS 不能直接套用。当自协方差绝对可和等条件成立时，括号趋向积分相关时间 $`\tau=1+2\sum_{k\ge1}\rho_k`$。若还满足相应 Markov 链中心极限定理，均值误差在适当缩放后近似正态，渐近方差为 $`\sigma_f^2\tau`$。可以定义均值有效样本量 $`N_{eff}=\frac{N}{\tau}`$，并用 $`\frac{\sigma_f}{\sqrt{N_{eff}}}`$ 表示相应标准误尺度。存在有限后验方差不自动保证所有这些依赖条件。

这里有限的通常渐近 ESS 表达还要求 $`\tau>0`$。若 $`\tau=0`$，相应中心极限定理可退化，不能把除零当作普通的有限误差证书。例如独立标准正态 $`\epsilon_t`$ 产生平稳统计序列 $`X_t=\epsilon_t-\epsilon_{t-1}`$，它可视为 Markov 状态 $`q_t=(\epsilon_t,\epsilon_{t-1})`$ 的函数，转移是抽取新独立正态并把原第一坐标移到第二坐标，因此并未脱离链上统计量的讨论。

其方差为二、滞后一相关为负二分之一，其余滞后相关为零，所以 $`\tau=0`$；但样本均值望远镜化为 $`\frac{(\epsilon_{N-1}-\epsilon_{-1})}{N}`$，有限样本方差恰为 $`\frac{2}{N^2}`$，并非零。此时应直接分析有限样本方差或使用适合的退化极限，不用常规非退化 ESS 公式替代。

每个函数的 $`\rho_k`$ 不同，平方、阈值指示和尾部分位数也会不同。因此不存在一项 ESS 可以完整概括整个后验。参数均值的 ESS 大，不意味着罕见故障概率的相对误差小；极少见事件即使独立抽样，也可能一次都没见过。应围绕实际报告的统计量计算误差，并给出有效观察数量，而不是只看某个最方便的参数。

<a id="mcmc-2-detail-29"></a>

### 8.2 AR(1)的正负相关手算

平稳过程 $`X_{t+1}=\phi X_t+\sqrt{1-\phi^2}\epsilon_t`$，其中 $`\vert \phi\vert <1`$ 且独立标准正态噪声，边缘方差为一，相关为 $`\phi^k`$。几何级数给出 $`\tau=\frac{(1+\phi)}{(1-\phi)}`$。当 $`\phi=0.9`$ 时为十九，一万步对均值约相当于五百二十六个独立标准正态样本；当 $`\phi=-0.5`$ 时为三分之一，同样链长的均值方差可以更小。

负相关下 ESS 超过原始样本数，表示该均值利用了相邻抵消，并不等于获得了同样多的独立整状态。把统计量换成平方即可看出区别。对边缘标准正态的两个链状态，设相关为 $`r=\phi^k`$，可以写成 $`Y=rX+\sqrt{1-r^2}Z`$，其中 $`X,Z`$ 独立标准正态。展开并用 $`E[X^4]=3`$，得到

$$
\begin{aligned}
E[X^2Y^2] &=3r^2+(1-r^2)=1+2r^2,\\[6pt]
\operatorname{Cov}(X^2,Y^2) &=2r^2.
\end{aligned}
$$

因为 $`\operatorname{Var}(X^2)=2`$，平方统计量的自相关为 $`\rho_k^{\mathrm{sq}}=\phi^{2k}`$，积分相关时间为

$$
\tau_{\mathrm{sq}}=\frac{1+\phi^2}{1-\phi^2}.
$$

当 $`\phi=-0.5`$，均值的 $`\tau=\frac{1}{3}`$，平方均值的 $`\tau_{\mathrm{sq}}=\frac{5}{3}`$。一万步对前者的渐近 ESS 为三万，对后者只有六千；估计的函数不同，结论就不同。平方不会保留正负抵消，因此链状态的交替并不自动改善后验方差或二阶矩的估计。

还应区分有限链与渐近近似。对这里方差一的平稳 AR(1)，有限 $`N`$ 的均值方差精确为

$$
\operatorname{Var}(\bar X_N)=\frac1N\left[
\frac{1+\phi}{1-\phi}-
\frac{2\phi(1-\phi^N)}{N(1-\phi)^2}\right].
$$

它来自 $`N^{-1}[1+2\sum_{k=1}^{N-1}(1-\frac{k}{N})\phi^k]`$ 对几何级数及其加权和求和。以 $`N=2,\phi=-0.5`$ 为例，精确方差为 $`\frac{1}{4}`$，有限方差比对应的 ESS 为四；直接代入渐近式却得到方差 $`\frac{1}{6}`$、ESS 为六。这个短链算例只是说明边界修正不能忽略，不是在推荐用两步估计软件的 ESS。

相关估计还需截断和稳定性处理，不能把短链上偶然出现的负相关全加起来制造无限大的 ESS。软件的 bulk、tail 或特定函数 ESS 对应各自定义；可结合[Stan 的后验分析说明](https://mc-stan.org/docs/reference-manual/analysis.html)区分估计对象，再检查当前链是否充分探索目标。

<a id="mcmc-2-detail-30"></a>

### 8.3 批均值与抽稀各做什么

批均值把长链分成若干连续块，先算每块平均，再用块间波动估计总体均值误差。块长要足够覆盖主要依赖，又要留下足够块数；很短链无法同时满足。不同块长的敏感性有诊断价值，但在结果出来后只挑最小标准误的块长同样是选择。多链还需保留链身份，不把跨链边界当正常相邻转移。

抽稀每隔若干步保留一次，通常会丢掉已经付出计算成本的信息。它可在存储受限或后处理特别昂贵时有工程价值，但不自动提高每单位梯度或环境计算的效率。相关性较小的保留样本可能更方便展示，不代表同样总预算下估计更精确。应比较最终统计的 Monte Carlo 误差和真实成本，而不是只比较抽稀前后单个相关系数。

<a id="mcmc-2-detail-31"></a>

## 9. 多链诊断的证据与盲区

多链从分散合法初值出发，可以暴露链间位置或尺度不一致。经典思路比较平均链内方差 $`W`$ 与结合链间差异的方差估计。将每链拆半还可对单链随时间漂移更敏感。它们在有限输出中寻找不一致，能够发现问题，不意味着某个数值接近理想就能证明所有区域均被访问。

<a id="mcmc-2-detail-32"></a>

### 9.1 一个可复算的经典split R-hat

对于 $`M`$ 条等长链、每条 $`N`$ 个保留样本，令链均值为 $`\bar x_m`$，总均值为 $`\bar x`$。经典量为 $`W=M^{-1}\sum_m s_m^2`$、$`B=N(M-1)^{-1}\sum_m(\bar x_m-\bar x)^2`$，再令 $`\widehat V=\frac{(N-1)W}{N}+\frac{B}{N}`$、$`\widehat R=\sqrt{\frac{\widehat V}{W}}`$。拆半后用相同公式，是本章实验使用的简化诊断。

现代方法还处理秩、尺度差异与尾部；读者可查原研究和成熟工具。本章没有把下面手写经典量冒充完整的 rank-normalized、folded 诊断或 bulk/tail ESS。无论采用哪种有限输出诊断，多条链若共同遗漏同一区域，都可能缺少揭示遗漏的信息。目标已知的多峰反例比一句“多链不保证收敛”更能说明这一点。

<a id="mcmc-2-detail-33"></a>

### 9.2 实验四：实际MH链共同困住

目标是两处相距十个单位、标准差零点四的等权高斯混合。局部随机游走提议标准差零点二五，四链都从左模式附近开始。在固定预算下它们可能彼此非常一致，却完全没到右模式。对照再从左右分散初始化，链间差异便很明显。这里运行的转移确实是正确对称 MH，不是伪造独立模式样本，但有限输出仍不能确认全局目标。

同一段代码另外核对 AR(1)的有限方差尺度。两部分分别检验计算误差与遗漏模式，不把 AR 相关公式直接当非线性 MH 链的真实 ESS。所有随机种子与步数固定，失败保留为结果，不延长运行直到出现一个跨模式事件才展示。

```python
import numpy as np

def split_rhat(chains):
    m,n=chains.shape;half=n//2
    z=np.concatenate([chains[:,:half],chains[:,n-half:]],axis=0)
    length=z.shape[1]
    within=z.var(axis=1,ddof=1).mean()
    between=length*z.mean(1).var(ddof=1)
    return float(np.sqrt(((length-1)/length*within+between/length)/within))

def mixture_chains(starts):
    result=[];rates=[]
    for index,start in enumerate(starts):
        rng=np.random.default_rng(321+index);x=float(start);kept=[];accepted=0
        def lp(z):return np.logaddexp(-.5*((z+5)/.4)**2,-.5*((z-5)/.4)**2)
        old=lp(x)
        for t in range(7000):
            candidate=x+.25*rng.normal();new=lp(candidate)
            if np.log(rng.random())<min(0.,new-old):
                x=candidate;old=new
                if t>=1000:accepted+=1
            if t>=1000:kept.append(x)
        result.append(kept);rates.append(accepted/6000)
    return np.array(result),rates

left,accept=mixture_chains([-5.2,-5.,-4.8,-4.9])
spread,_=mixture_chains([-5.,-4.8,5.,5.2])
assert np.all(left<0) and abs(left.mean())>4.5
assert split_rhat(left)<1.05 and split_rhat(spread)>5
print('same-mode mean/right fraction/split Rhat',left.mean(),(left>0).mean(),split_rhat(left))
print('spread starts split Rhat',split_rhat(spread),'same-mode acceptance',accept)

rng=np.random.default_rng(325);n=20000;phi=.9
x=np.empty(n);x[0]=rng.normal()
for t in range(1,n):x[t]=phi*x[t-1]+np.sqrt(1-phi**2)*rng.normal()
block=x.reshape(100,200).mean(1)
batch_mcse=np.sqrt(block.var(ddof=1)/len(block))
k=np.arange(1,n)
finite_tau=1+2*np.sum((1-k/n)*phi**k)
theory_mcse=np.sqrt(finite_tau/n)
assert abs(batch_mcse-theory_mcse)<.012
assert np.isclose((1+.9)/(1-.9),19)
assert np.isclose((1-.5)/(1+.5),1/3)
print('AR1 batch/theory MCSE',batch_mcse,theory_mcse,'asymptotic ESS',n/19)
```

<a id="mcmc-2-detail-34"></a>

### 9.3 为什么这个失败无法被局部精度修复

等权混合的真实均值为零、右模式概率为一半。若所有链只在左模式内移动，增加该模式内部的样本可以让局部均值估计越来越精确，却不会补回缺失质量。经典 split 指标只看到提供给它的输出；链间一致并不告诉它目标还有另一座峰。更稳健诊断能发现更多异常类型，也不能在没有相关证据时创造未访问区域的信息。

分散初值是有用对照，不是保证。若模式位置未知，随机初始化也可能全部落在同一吸引区域；若高维存在稀有结构，几个坐标看起来重叠仍不充分。可以结合领域结构、可解析子问题、不同参数化和独立算法，但每种证据有自己的假设。采样报告应该准确写成在已检查维度没有发现某类异常，而不是宣布有限诊断证明全局精确。

<a id="mcmc-2-detail-35"></a>

## 10. 难几何、重参数化与适应阶段

相关高斯只表现固定线性几何，层级后验还可能有随位置急剧改变的尺度。典型例子是一个尺度参数控制许多局部参数的波动：尺度小时局部方向很窄，尺度大时又很宽。单一质量矩阵未必同时适应所有区域。网络更大、链更长或接受率更高，都不自动消除这种局部几何差异。

<a id="mcmc-2-detail-36"></a>

### 10.1 中心化与非中心化为什么改变计算

若局部变量条件分布为 $`\theta_i\mid\mu,\tau\sim N(\mu,\tau^2)`$，可写成 $`\theta_i=\mu+\tau z_i`$、$`z_i\sim N(0,1)`$。这重新分配了先验与似然中的依赖，可能让某些弱数据问题的几何更平缓。强数据约束下中心化也可能更合适，不能把非中心化当无条件改进。两种表示应描述相同概率模型，并维护变换与密度；只改变量名不等于完成正确重参数化。

可在解析或小型层级模型中比较后验预测与 log 目标，再检查采样警告和目标函数的 MC 误差。若两种参数化预测不同，先调查模型定义、Jacobian 或计算近似，而不是马上宣称某种参数化发现了不同科学结论。坐标改变是计算设计，模型改变又是另一件事，二者应该可以被清楚地区分。

<a id="mcmc-2-detail-37"></a>

### 10.2 预热调参不等于固定核采样

预热阶段可调整步长和质量估计，随后冻结配置以便按已分析的固定核收集正式样本。自适应并非一概非法，但若持续调整，马尔可夫性与不变性论证都需要相应扩展条件，不能只证明每个冻结核正确就认为任意自适应规则自动正确。选择步长、停止时间与保留样本的角色也应明确记录。

本章 HMC 没有实现自动预热适应，丢弃前一千步只是预设的初始化处理，不是运行了成熟的步长或质量调节器。真实精度质量直接由人工目标提供。正式比较可以加入共同的适应预算，再按冻结规则评价，但那是额外实验。这样的范围说明让读者知道哪些代码已经做了，哪些只是方法讨论。

<a id="mcmc-2-detail-38"></a>

### 10.3 几何警告应连接具体计算

成熟 HMC 工具可以报告与能量误差、动态路径或探索范围相关的警告。调查时先检查目标有限性、梯度、尺度和参数化，再看步长与预算；不能只把警告阈值改得更宽就算解决。某些模型结构性困难需要改建模或表示，而非单纯延长同一条局部轨迹。

报告没有警告只说明当前检查未触发，不提供所有模式覆盖的保证。反过来，有警告也不应先删除对应样本再重算漂亮结果，因为它们可能集中在重要区域。应保留问题发生的位置、参数组合与敏感性，明确最终结论是否依赖这些区域。计算诊断的目的在于发现证据不足，不是给每个模型贴一个通过或不通过的单一标签。

<a id="mcmc-2-detail-39"></a>

## 11. 将初始化偏差、计算方差与预测分开

后验均值的均方误差由偏差与方差共同构成。平稳相关公式主要处理方差，若链还停在初始区域，它并不自动控制偏差。实际诊断通常无法给出已知的全局混合常数，因此应避免把估计标准误误写成全部误差保证。可解析小模型的用途之一，就是让这些量可以被独立比较，而不只是靠轨迹外观猜测。

<a id="mcmc-2-detail-40"></a>

### 11.1 全变差控制有界函数，不控制任意尾部

若两分布的全变差距离为 $`\delta`$，对绝对值不超过 $`B`$ 的函数有 $`\vert E_\mu f-E_\pi f\vert \le2B\delta`$。这是把正负部分或密度差积分的绝对值界出来。因而若确知 $`\Vert \mu K^t-\pi\Vert _{TV}\le C\rho^t`$，其中 $`C\ge0`$、$`0\le\rho<1`$，有限样本平均的初始化偏差可由各时刻误差平均控制：

$$
\left\vert E\left[\frac1N\sum_{t=0}^{N-1}f(q_t)\right]-E_\pi f\right\vert
\le\frac{2BC}{N}\sum_{t=0}^{N-1}\rho^t
\le\frac{2BC}{N(1-\rho)}.
$$

这里混合界是额外已知条件，不能从一次 R-hat 接近一就获得它。对无界函数，全变差小也可能因极少尾部巨大取值而有大均值差，需要矩或一致可积等额外控制。参数均值、方差和尾部风险不能只凭一个有界事件的误差界全部放行。证明中函数有界的位置，是结论能否迁移的关键。

<a id="mcmc-2-detail-41"></a>

### 11.2 后验预测可以减少额外抽样噪声

若要估计新事件概率，给定参数样本后可以计算 $`p_i=P(Y_{new}\in A\mid q_i)`$，也可以每次再抽一个新结果并记指示 $`I_i`$。两种平均在正确条件下估计同一后验预测概率，但后一种额外引入结果抽样。条件于整条参数链，若这些预测抽样独立，条件均值为 $`p_i`$，则全方差公式给出

$$
\operatorname{Var}\left(\frac1N\sum_iI_i\right)
=\operatorname{Var}\left(\frac1N\sum_ip_i\right)
+\frac1{N^2}\sum_iE[p_i(1-p_i)].
$$

这个等式允许参数链相关，因为条件于整条链后只要求新结果的随机数独立。直接平均可计算的条件概率可以减少该额外噪声，是一种具体条件期望替代。它不修复参数链遗漏模式，也不证明预测模型正确；若条件概率本身需要近似积分，还应计入其误差。减少一层噪声不等于消除了所有计算不确定性。

<a id="mcmc-2-detail-42"></a>

### 11.3 比较采样器时固定目标与估计任务

两个采样器应使用同一概率模型、坐标约定和目标统计，再比较达到给定 MC 误差所需资源。每步成本不同，ESS 每步与 ESS 每秒可以给出不同排序；预热和失败重试也属于成本。若某方法返回近似目标分布，不可只按表面 ESS 和精确 MCMC 直接比较，还需考虑近似偏差。相同链长并不是普遍公平标准。

如果改变参数化但保持模型一致，应对共同的原坐标预测或统计比较。只在各自方便坐标上给最佳 ESS，可能掩盖实际关心函数仍混合很差。现实目标未知时可以结合多种诊断与稳定性证据，人工模型则应尽量用解析积分核对。方法比较的核心是同一任务下的可解释误差与成本，而不是某个采样器名字更先进。

## 12. 二十四道进阶练习与详细解析

<a id="mcmc-2-detail-44"></a>

### 12.1 恒等核为什么是最简单的不变性反例

**题目：** 每一步都返回当前位置。为什么任何目标都不变，却不能从一个点获得目标样本？

**解析：** 初始分布经过恒等映射保持原样，所以从目标初始化就永远保持目标，满足不变性定义。但从固定点初始化只得到同一个点，不会逐渐生成其他区域。样本平均等于该点的函数值，通常不等于目标积分。这个例子直接区分保持性质和从任意初值的收敛，不需要复杂连续理论。证明了某个核保持后验以后，还必须检查可达性与实际混合，不能把第一步当全部采样正确性。

<a id="mcmc-2-detail-45"></a>

### 12.2 细致平衡是否必要

**题目：** 三状态定向循环保持均匀分布，却不满足两两通量相等，是否说明不变性检验错了？

**解析：** 没有。每个状态的总流入与总流出相等即可保持均匀分布，不要求每对状态的流量各自抵消。细致平衡是更强的充分条件。该循环还具有周期，分布可能振荡；加入适当原地概率可以改变周期但仍保留非可逆定向流。三个概念分别是全局流量守恒、成对流量对称和时间收敛性质，只有明确它们的逻辑关系，才不会把一个正确构造误判成非法核。

<a id="mcmc-2-detail-46"></a>

### 12.3 非对称提议漏比率会采到哪里

**题目：** 两状态目标各半，提议矩阵两行都是零点一与零点九，漏掉提议比会怎样？

**解析：** 因目标比为一，每次都接受，下一状态直接服从提议行，所以不变分布为零点一与零点九。正确修正使跨状态概率两边同为零点一，目标各半才成立。错误链可能很快稳定，接受率甚至为一，正好说明高接受和快速到某个稳定分布都不足。需要核对它到达的是哪一个分布，最好先用有限状态通量检查目标身份。

<a id="mcmc-2-detail-47"></a>

### 12.4 为什么拒绝样本也要保留

**题目：** 为节省存储只记录接受后的新状态，再平均这些状态，可以直接估计原目标吗？

**解析：** 通常不可以。原链在某状态等待多久，是稳态占据概率的一部分；删除拒绝会使容易离开的状态与难离开的状态权重改变，形成不同跳链。可以研究带等待权重的估计或适当抽样规则，但需重新推导。定期抽稀和只记录接受也是不同机制，前者按固定时间取样，后者按事件取样。节省存储不能无声改变统计单位和目标权重。

<a id="mcmc-2-detail-48"></a>

### 12.5 越界拒绝和边界内重抽是否一样

**题目：** 正参数随机游走产生负候选，一种实现原地等待，另一种不断抽到正数为止，能否共用对称接受率？

**解析：** 不一定。前者仍使用原本对称的全空间提议并拒绝非法点；后者实际从依赖当前点的截断分布抽候选，归一化常数通常随位置变化。反向提议密度不再自动相同，需要使用真实提议比。两种程序都只输出合法正数，形状检查不会揭示这个差异。必须先写采样机制再推接受式，不能从结果范围正确推断概率核正确。

<a id="mcmc-2-detail-49"></a>

### 12.6 Gamma坐标漏项的手算

**题目：** 形状三、率二的 Gamma，令参数为指数坐标。为什么漏 Jacobian 后均值从一点五变为一？

**解析：** 原 log 密度含两倍 log 参数和负二倍参数，变到 log 坐标后正确还要加一次坐标值，于是系数三。漏掉这一项后，变回原参数相当于形状二的 Gamma。其均值形状除以率为一，方差形状除以率平方为零点五。两种采样都可以非常稳定，所以解析矩是检验目标身份的独立证据，不能只靠接受比例判断哪条链正确。

<a id="mcmc-2-detail-50"></a>

### 12.7 HMC动量为什么不是新的模型先验

**题目：** 引入正态动量会不会改变需要推断的参数后验？

**解析：** 扩展目标是原后验乘一个归一化动量密度，对动量积分恰好得到原后验，所以只要扩展采样正确，位置边缘不变。质量矩阵改变提议几何和计算效率，不是给原参数加一个科学先验。若修改势能里的模型项，则属于另一个目标。区分辅助变量与建模变量，可以避免把改善采样的几何调节误解释成数据支持的后验变化。

<a id="mcmc-2-detail-51"></a>

### 12.8 能量守恒证明中哪里用了可分离结构

**题目：** 为什么本章 Hamilton 方程沿轨迹的能量导数为零，数值实现仍需接受步骤？

**解析：** 精确导数中势能梯度与动量速度的两个内积相互抵消。需要再辨清题目的前提：能量守恒本身不要求可分离。对一般不显含时间的可微 Hamilton 函数 $`H(q,p)`$，若动力学为 $`\dot q=\nabla_pH,\dot p=-\nabla_qH`$，则 $`\frac{dH}{dt}=\nabla_qH^T\nabla_pH-\nabla_pH^T\nabla_qH=0`$。本章采用 $`H=U(q)+T(p)`$ 的可分离结构，是为了把动力学拆成可精确执行的位置与动量剪切，从而得到第 5.2 节的简单显式 leapfrog；固定二次动能又给出线性的位置更新。

一般不可分离能量不能直接照搬这三步公式。计算机的离散轨迹通常不是连续方程的精确解，因此仍有能量差；正确的可逆、体积保持提议才使该误差可由 MH 校正。精确能量守恒与离散提议合法性是两层证明，不能互相替代。

<a id="mcmc-2-detail-52"></a>

### 12.9 为什么体积保持不足以独自证明HMC

**题目：** 任意一个绝对 Jacobian 为一的映射都能直接配能量差接受吗？

**解析：** 还需正确处理反向提议。对确定性映射，若反向机制不匹配，普通密度比的简单推导并不自动成立。本章用末端动量翻转把可逆积分变成对合，使两方向可以成对比较。其他合法构造也存在，但需要自己的完整机制。保持体积只解决 Jacobian 项，不解决目标、可达性和反向概率全部问题，不能把一个局部性质当成通用许可证。

<a id="mcmc-2-detail-53"></a>

### 12.10 质量矩阵为何容易记反

**题目：** 本章目标协方差为 Sigma，为什么理想高斯对照使用精度作为质量？

**解析：** 因为本章定义动量协方差为质量 M，位置速度为逆质量乘动量，二阶动力学为负逆质量乘目标精度再乘位置。令质量等于目标精度，就使频率矩阵为单位阵。若软件把逆质量叫度量或质量估计，名称可能不同。应写出动能和动量分布再比较，不能仅凭一句“用协方差预条件”把矩阵放错位置。真实目标中还需估计几何，不知道精度时这一理想对照不是免费算法。

<a id="mcmc-2-detail-54"></a>

### 12.11 Leapfrog稳定阈值怎样得到

**题目：** 一维高斯谐振子为何要求步长乘频率小于二，而不是只要步长为正？

**解析：** 一步矩阵行列式为一，迹为二减该乘积平方。要让两个特征值位于单位圆，迹绝对值需小于二，因此非零乘积需在零与二之间。超过二会出现模大于一的特征值，反复积分放大误差。等于二是边界，可能出现非平凡 Jordan 增长。这个线性结论能解释窄方向限制步长，却不保证一般非线性后验只需一个全局频率就完成稳定性分析。

<a id="mcmc-2-detail-55"></a>

### 12.12 为什么很长稳定轨迹也可能无效

**题目：** 积分器步长稳定且接受率很高，轨迹末点仍接近起点，有什么可能机制？

**解析：** 在近似周期动力学中，总积分时间接近完整周期会把状态带回附近。增加长度反而支付更多梯度却没有更多有效移动。半周期附近可能产生负相关，不一定有害；不同方向频率不同又使问题复杂。可以研究预设随机长度或正确动态路径方法，但状态相关停止需完整证明。高接受、低能量误差和高效率是相互关联却不等同的三个判断。

<a id="mcmc-2-detail-56"></a>

### 12.13 ESS为什么不是后验的固定属性

**题目：** 同一批链对参数均值有很高 ESS，对尾部事件却低，是否互相矛盾？

**解析：** ESS 取决于函数序列的方差和相关。平方、阈值指示和参数本身沿同一轨迹可以有不同依赖，尾部还可能只有极少命中。对某个均值近似等价的独立样本数，不是整条后验的唯一信息量。应直接评价关心统计的 Monte Carlo 误差，并在事件极少时报告支持数。一个漂亮总 ESS 不能替代所有预测、分位数和风险函数的检查。

<a id="mcmc-2-detail-57"></a>

### 12.14 负相关与超过链长的ESS

**题目：** 平稳 AR 过程系数负零点五时，一万步的均值 ESS 可以约为三万，这是不是计算错误？

**解析：** 在本例相关为该系数的幂，积分相关时间为三分之一，所以均值方差比独立同方差样本更小。ESS 只是方差等价尺度，并没有产生三万个独立观察。换成平方函数，负号消失，收益可能不同。有限样本相关估计也可能不稳定，不能把任意负估计相加后无限放大 ESS。先核对理论模型与统计函数，再解释数值，才不会把合理反相关误判为坏链或过度宣传。

<a id="mcmc-2-detail-58"></a>

### 12.15 为什么抽稀通常不提高计算效率

**题目：** 每隔十步保留一次后相关明显降低，是否证明估计更高效？

**解析：** 尚未比较总成本和丢掉的信息。原来十步的计算仍已发生，只是不再使用其中九个样本。应在相同总梯度与运行预算下比较最终目标统计的误差，而非只比较保留序列的相邻相关。存储或后处理昂贵时抽稀可以合理，但这属于另外的资源约束。一个更容易展示的序列不自动是更精确的积分估计，必须说明评价效率的分母。

<a id="mcmc-2-detail-59"></a>

### 12.16 split R-hat接近一为何仍会遗漏模式

**题目：** 本章四条链经典 split 指标约一点零零四，目标均值却估计成负五，原因是什么？

**解析：** 四链共同困在左模式，彼此均值与方差都很一致，诊断没有看到右模式证据。目标真实均值为零，局部一致不能消除整体偏差。分散初始化能在当前已知两峰例子中暴露问题，但模式未知时也不是严格保证。这个反例使用真正正确的 MH 转移，说明不变性与有限混合之间仍有距离；同时没有把手写经典量冒充成熟软件的完整现代诊断。

<a id="mcmc-2-detail-60"></a>

### 12.17 多链拼接为什么不能直接算一条自相关

**题目：** 将四链首尾连在一起计算滞后相关，有何问题？

**解析：** 拼接边界不是同一 Markov 转移，链初值与前一链末点没有算法上的邻接关系。边界可能人为制造跳跃或持续趋势，从而扭曲相关估计。多链方法应保留链身份，用适当的链内和链间信息组合。独立链可以帮助估计与检查，但不能仅靠数组变长就改变依赖定义。样本顺序、来源和统计单位都是误差分析的一部分。

<a id="mcmc-2-detail-61"></a>

### 12.18 预热丢弃是否等于自动调参

**题目：** 丢弃前一千步后，能否说已做步长和质量适应？

**解析：** 不可以。丢弃只是从报告估计中排除初始阶段，自动调参还需要明确更新规则和冻结条件。本章 HMC 直接使用预设步长与已知质量，未实现成熟适应器。预热长度合适与否也依赖混合，不能从固定数字保证。若持续适应，需额外理论条件，而不是只检查每个单独固定核都保持目标。准确说明执行过程，才能让读者知道实验验证的范围。

<a id="mcmc-2-detail-62"></a>

### 12.19 非中心化为什么不是无条件更好

**题目：** 层级正态变量改写成均值加尺度乘标准正态后，是否所有数据条件下都更容易采样？

**解析：** 不一定。弱数据时它可能减轻先验尺度造成的漏斗，强数据时似然又可能在新坐标引入强依赖。应保持同一概率模型，再比较共同预测与计算效率。若两种写法的目标不同，先排查密度与变换，不能把模型差异当采样优势。重参数化改变几何而不必改变后验问题，但优劣取决于数据提供的信息与先验共同形成的结构。

<a id="mcmc-2-detail-63"></a>

### 12.20 小MCSE为什么不能证明模型可靠

**题目：** 参数均值的计算标准误很小，是否足以证明后验适合新数据？

**解析：** 它最多描述当前链和估计条件下积分的计算精度，不检查先验、似然与采样数据的真实性。若链遗漏模式，标准误甚至可能只反映局部波动；若模型错设，即使精确后验也可能预测很差。应分别做采样诊断、已知参照校验和后验预测或敏感性。不同证据服务不同问题，不能把最容易算的一个数字替代整个推断过程。

<a id="mcmc-2-detail-64"></a>

### 12.21 全变差很小为何不控制所有均值

**题目：** 两分布只在极少尾部质量上不同，为什么参数均值仍可能差很多？

**解析：** 无界函数可以在那一点小质量上取极大值，概率差虽小，积分差却很大。有界函数的二倍上界乘全变差公式明确使用了函数幅值上界。要推广到无界均值，需要额外矩、尾部或一致可积控制。讨论收敛时因此应说明度量和函数类，而不笼统说所有统计都会一样精确。尾部风险尤其不能由一个中心区域指标自动认证。

<a id="mcmc-2-detail-65"></a>

### 12.22 条件预测平均为什么减少额外噪声

**题目：** 估事件概率时，直接平均每个参数样本下的事件概率，与各抽一个事件指示再平均，差在哪里？

**解析：** 条件于整条参数链，后者还有 Bernoulli 抽样方差，前者没有。全方差公式给出额外项是各次条件方差期望之和除以样本数平方，所以直接条件平均不增加这层噪声。参数链可以相关，关键是额外预测随机数按声明条件独立。但若参数链遗漏模式，两者都可能偏离目标；若条件概率是近似算的，还要另记误差。减少一层方差不等于解决所有推断问题。

<a id="mcmc-2-detail-66"></a>

### 12.23 高接受率和快混合哪个先检查

**题目：** 将随机游走步长缩得非常小，接受率从六成变成九成九，是不是已经改进？

**解析：** 先确认目标与核正确，再比较所需统计的移动与误差。步长小使提议更接近当前点，容易接受却可能需要很久才能走过目标尺度。相同链长下有效样本量可能下降，按秒或梯度成本比较又有不同结果。接受率是调参线索之一，不是独立目标。应保留共同目标、预算和估计任务，避免只挑一个能被简单操纵的指标。

<a id="mcmc-2-detail-67"></a>

### 12.24 怎样公平比较变分与MCMC

**题目：** 变分近似独立抽样 ESS 很高，能否直接据此认定比 MCMC 更精确？

**解析：** 独立样本可能来自带结构偏差的近似分布，ESS 衡量围绕其抽样目标的方差，不修复目标差异。比较应围绕同一后验统计或预测，分别估计近似偏差、有限计算误差与成本。可解析高斯能提供真值，复杂问题则需要多种独立证据。MCMC 也可能有限时间未混合，因此方法名字不自动决定胜负。将误差来源拆开，才有可以延伸到新任务的判断依据。

## 13. 一份可复核的采样研究报告

记录概率模型、参数支持、log 目标和梯度实现、变换与 Jacobian、提议机制、随机种子、初值、预热、保留长度和实际计算成本。每条链保留身份，重复状态与失败触发按规则保存。对关键统计给均值、后验不确定性与 Monte Carlo 误差，说明每个诊断的具体实现，而不只写一个没有定义的 ESS 或收敛通过。

<a id="mcmc-2-detail-69"></a>

### 13.1 本章实际实验结果

非对称两状态中，正确核保持各半，漏比率核把各半一步变成零点一与零点九。懒惰三状态核仍保持同一目标，非平凡特征值接近零点九八七与零点九九。Gamma 正确变换的样本均值约一点四九二二、方差零点七四五四；漏 Jacobian 分别约零点九九五九和零点四八九七。稳定轨迹可以对应错误目标，这一结论由解析分布直接支持。

高斯 HMC 单位质量的接受率约零点九七零二，精度质量约零点九九七五；宽方向一阶相关分别约零点二三三五与负零点三二一一。两组均值与协方差均通过预设解析检查，提议数值绝对 Jacobian 约为一。多峰 MH 四链在本次预算内右模式命中为零，均值约负五点零二二，经典 split 指标却约一点零零三九；左右分散初值对照约十三点五一二。AR 批均值标准误约零点零三三六，与理论零点零三零八属于同一尺度。

这些是固定人工目标和预设种子的实际输出，不是 Stan、NUTS、复杂层级模型或真实领域数据的基准。四段代码全部独立 CPU 执行，使用内存中的人工目标，不依赖下载权重或外部采样器。更换种子会改变有限数值，性质与合理误差范围比逐位复现更重要。输出中的失败保留为诊断案例，不以所有方法都成功为目标。

<a id="mcmc-2-detail-70"></a>

### 13.2 从解析模型到复杂后验的研究路径

先用有限 MH 与 Gamma 坐标检查目标身份，再用相关高斯验证 HMC 结构和已知矩，最后加入多峰、尺度层级或有约束参数。每次只改变一个主要因素，区分目标变化、参数化变化和采样机制变化。若某种改进减少警告却增加总成本，报告两者；若均值稳定但尾部概率仍无支持，继续调查该统计，不用中心分数掩盖未测区域。

与上一章连接时，可以在同一相关高斯上比较 mean-field 结构偏差与 MCMC 计算方差，进一步比较线性预测的不同方向。参数边缘方差近似差，不代表每种预测都同样差；某些预测方向可能抵消误差，另一些可能放大。研究应明确最终要回答的问题，并将结论限定在已有证据上。可靠的进阶推断需要理解目标、算法、计算与模型之间的每一层连接。
